# 본오동 현관 손잡이가 예전 같지 않다면
본오동은 상록수역 쪽 생활권으로 아파트 단지와 빌라, 단독주택이 골고루 섞인 안산 상록구의 동네입니다. / 오래 산 집이 많아 같은 도어락 손잡이를 오랫동안 매일 돌려 온 현관도 흔합니다.
손잡이는 도어락에서 사람 손을 가장 많이 타는 부분입니다. / 처음에는 살짝 덜렁거리다가, 어느새 아래로 처지고, 결국 돌려도 문이 안 열리는 헛돎으로 이어집니다.
이 글은 본오동에서 도어락 손잡이가 헐겁거나 헛돌 때 집에서 볼 수 있는 곳과 손대지 말아야 할 곳, [안산 출장열쇠](ansan.html)를 부를 때를 정리했습니다.
@ 본오동 현관 도어락 손잡이 헐거움

# 헐거움과 헛돎은 다른 증상입니다
손잡이 문제는 크게 두 가지로 나뉩니다. / 어느 쪽인지에 따라 급한 정도가 완전히 다릅니다.
손잡이를 돌리면서 문 옆면의 걸쇠를 함께 지켜보면 어느 쪽인지 바로 알 수 있습니다. / 헐거움은 손잡이가 흔들리거나 처지지만 돌리면 걸쇠는 움직이는 상태입니다. / 불편하지만 문은 열리니 시간을 두고 손볼 수 있습니다.
헛돎은 손잡이는 빙글빙글 도는데 걸쇠가 꿈쩍 않는 상태입니다. / 바깥에서 이렇게 되면 문을 열 수 없어 바로 연락 주셔야 합니다.

# 손잡이가 흔들리기 시작했다면
안쪽 손잡이 몸체를 고정하는 나사가 조금씩 풀린 경우가 가장 많습니다. / 매일 같은 방향으로 돌리다 보면 나사가 서서히 풀립니다.
안쪽 도어락 몸체 아래나 옆을 보면 작은 나사가 보입니다. / 손잡이 바로 아래에 숨은 고정 나사가 있는 제품도 있습니다.
맞는 드라이버로 살살 조여 보세요. / 끝까지 꽉 조이면 나사산이 뭉개지거나 플라스틱 부분이 갈라질 수 있으니 흔들림이 멈추는 정도까지만 조이시면 됩니다.
@ 본오동 도어락 안쪽 고정 나사 조이기

# 손잡이가 아래로 처져 있다면
레버형 손잡이는 안쪽 스프링이 손잡이를 수평으로 되돌려 놓습니다. / 이 스프링이 약해지거나 끊어지면 손잡이가 처진 채 돌아오지 않습니다.
처진 손잡이는 걸쇠를 반쯤 당긴 상태로 머물러 문이 덜 닫히게 만들기도 합니다. / 문을 닫았는데 잠기지 않거나 자동 잠금 경고음이 난다면 이 경우일 수 있습니다.
스프링은 겉에서 조일 수 있는 부품이 아니라서 부품을 바꿔야 합니다. / 처짐이 보이면 헛돌기 전에 미리 점검받으시는 게 좋습니다.

# 헛돌 때 안에서는 무슨 일이 생겼을까
손잡이와 걸쇠 사이에는 네모난 쇠막대 축이 들어 있습니다. / 손잡이를 돌리면 이 축이 같이 돌면서 걸쇠를 당깁니다.
축은 손잡이 안쪽 홈에 끼워져 있을 뿐이라, 고정 나사가 풀리면 조금씩 밀려 나옵니다. / 헛돎은 대부분 이 축이 빠졌거나, 닳아서 모서리가 둥글어졌거나, 손잡이 안쪽 홈이 갈라진 경우입니다. / 겉으로는 멀쩡해 보여도 안쪽에서 연결이 끊긴 겁니다.
안쪽 손잡이는 되는데 바깥 손잡이만 헛도는 경우도 있습니다. / 이럴 때 집 안에 사람이 있다면 안쪽에서 열어 줄 수 있으니 먼저 연락해 보세요.

# 바깥에서 헛돌아 못 들어갈 때
집 안에 아무도 없고 바깥 손잡이가 헛돌면 손잡이로는 문을 열 수 없습니다. / 이때 손잡이를 세게 당기거나 위아래로 비틀면 축이 더 빠지거나 손잡이가 부러질 수 있습니다.
번호를 눌러 도어락이 풀렸는데 손잡이가 헛도는 것인지, 도어락 자체가 안 풀리는 것인지 구분해 주세요. / 풀리는 소리가 나는데 문이 안 열린다면 손잡이 연결 문제일 가능성이 큽니다.
푸시풀 방식처럼 손잡이를 밀고 당겨 여는 도어락이라면 손잡이를 끝까지 밀었는지 다시 확인해 보세요. / 반쯤 밀다 멈추면 걸쇠가 덜 빠져 헛도는 것처럼 느껴지기도 합니다.

# 집에서 하지 않는 게 나은 것
- 손잡이를 잡고 문을 흔들며 당기기
- 헛도는 손잡이를 빼내 축을 손으로 돌리기
- 순간접착제로 손잡이를 축에 붙이기
- 바깥 손잡이 쪽 나사를 억지로 풀기
접착제는 한두 번 버티다가 결국 떨어지고, 나중에 부품을 바꿀 때 손잡이를 빼기 어렵게 만듭니다. / 바깥 쪽 나사는 방범 때문에 일부러 풀리지 않게 만든 경우가 많습니다.

# 방문 손잡이와는 구조가 다릅니다
방문 손잡이가 헛돌면 손잡이만 사서 바꾸는 분이 많습니다. / 현관 도어락 손잡이는 도어락 몸체와 한 덩어리로 만들어진 경우가 많아 손잡이만 따로 맞추기 어려운 제품도 있습니다.
제품 이름을 알면 맞는 부품이 있는지 확인할 수 있습니다. / 안쪽 몸체 옆이나 배터리 칸 안쪽에 적힌 제품 이름을 사진으로 찍어 보내 주세요.
@ 본오동 도어락 제품 이름 손잡이 부품 확인

# 아이와 어르신이 있는 집이라면
아이들은 손잡이에 매달리거나 세게 내려 누르는 일이 많습니다. / 어르신은 손잡이에 몸을 기대며 문을 여시곤 합니다.
이런 집은 손잡이 축과 스프링이 더 빨리 닳습니다. / 흔들림이 느껴지면 미루지 말고 한 번 조여 두시고, 처짐이 보이면 점검을 받아 두세요. / 아이에게는 손잡이에 매달리지 않도록 한 번씩 일러 주시는 것만으로도 부품 수명이 꽤 늘어납니다.

# 출장을 부를 때 알려 주실 것
흔들리는지, 처지는지, 헛도는지 중 어느 쪽인지 먼저 말씀해 주세요. / 안쪽과 바깥 중 어느 손잡이인지, 지금 집 안에 들어갈 수 있는지도 함께 알려 주세요.
손잡이와 도어락 전체가 나오게 사진 한 장, 제품 이름이 보이게 한 장을 보내 주시면 맞는 부품을 챙겨 갈 수 있습니다. / 아파트라면 동과 호수, 빌라라면 건물 이름도 함께 말씀해 주세요.

# 확인과 금액 안내
문을 여는 상황이라면 신분증 주소, 주소가 적힌 우편물, 관리사무소 세대 확인 중 하나로 사시는 분인지 먼저 확인합니다. / 손잡이 상태를 본 뒤 조이기로 끝날지, 부품을 바꿔야 할지 작업 전에 금액을 먼저 말씀드립니다.
동의하셔야 시작하고, 끝내 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에, 문 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 고칠지 바꿀지 정하는 기준
축이나 스프링 같은 부품만 바꿔 다시 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 진행합니다. / 대부분은 이쪽으로 해결됩니다.
손잡이와 몸체가 함께 닳았거나 부품이 더 이상 나오지 않는 제품이라면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 바꾸게 되면 기존 문 구멍에 맞는 제품을 골라 드립니다.
@ 본오동 도어락 손잡이 축 교체 수리

# 본오동 외 안산 다른 동네
고잔동, 초지동, 선부동, 와동, 원곡동, 사동, 이동, 월피동, 성포동, 대부동까지 안산 어디든 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 본오동 손잡이 문제, 이렇게 기억하세요
흔들리면 안쪽 나사를 살살, 처지면 점검을, 헛돌면 억지로 당기지 말고 바로 연락 주세요. / 일찍 손볼수록 부품 하나로 끝날 가능성이 커집니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 다닙니다. / 손잡이가 헛돌아 문 앞에 서 계시다면 010-3664-5455로 연락 주세요.
