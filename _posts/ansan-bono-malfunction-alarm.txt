# 본오동 현관에서 도어락이 갑자기 소리를 낸다면
본오동은 상록수역 생활권에 아파트 단지와 빌라, 주택가가 함께 있는 안산 상록구의 동네입니다. / 조용한 저녁에 현관 쪽에서 도어락이 삐삐 울리기 시작하면 집 안 사람도, 이웃도 깜짝 놀라게 됩니다.
도어락은 문제가 생기면 대부분 소리로 먼저 알려 줍니다. / 그런데 소리 종류가 여러 가지라 무엇을 뜻하는지 몰라 그냥 두거나, 반대로 배터리를 다 빼 버리는 분도 있습니다.
이 글은 본오동에서 도어락이 경고음을 내거나 모터 소리만 날 때 소리별로 원인을 읽는 법을 정리했습니다. / 문이 안 열리거나 소리가 멈추지 않으면 [안산 출장열쇠](ansan.html)를 부르시면 됩니다.
@ 본오동 도어락 경고음 모터 소리 오작동

# 먼저 소리의 모양을 기억해 두세요
경고음은 길이와 반복 방식이 다르면 뜻도 다릅니다. / 전화로 설명하실 때도 "어떤 소리였는지"가 원인을 짚는 가장 큰 단서가 됩니다.
- 짧은 삑삑이 번호 누를 때마다 섞여 나옴
- 문을 열어 둔 채 일정 간격으로 울림
- 길고 날카로운 소리가 멈추지 않고 이어짐
- 번호를 누르면 윙 하는 모터 소리만 나고 걸쇠가 그대로임
- 아무도 안 만졌는데 혼자 철컥거리거나 삑 소리를 냄
휴대폰으로 소리를 짧게 녹음해 두시면 더 좋습니다. / 녹음 파일을 보내 주시면 통화로 설명하는 것보다 훨씬 정확합니다.

# 번호 누를 때 섞여 나오는 짧은 소리
번호를 누를 때마다 평소와 다른 짧은 경고음이 섞여 나온다면 배터리가 약하다는 알림인 경우가 많습니다. / 아직 문은 잘 열려도 며칠 안에 꺼질 수 있다는 뜻입니다.
이 소리가 들리면 그날 안에 배터리를 모두 새것으로 바꿔 주세요. / 일부만 바꾸면 경고음이 금방 다시 납니다.

# 문을 열어 둔 채 일정하게 울릴 때
문이 열린 상태에서 주기적으로 울리는 소리는 문이 제대로 닫히지 않았다는 알림입니다. / 자동 잠금 기능이 있는 도어락은 문이 닫혀야 걸쇠를 내보낼 수 있어서 이렇게 알려 줍니다.
문을 닫았는데도 울린다면 문이 끝까지 닫히지 않은 겁니다. / 문틀에 무엇이 끼었는지, 문이 처져 걸쇠 자리가 어긋났는지 살펴보세요.
@ 본오동 현관문 덜 닫힘 도어락 알림

# 길고 날카로운 소리가 멈추지 않을 때
가장 놀라운 소리가 이 경우입니다. / 많은 도어락은 바깥에서 억지로 열려는 충격이 오거나, 안쪽에서 비정상적인 움직임이 감지되면 경보를 울립니다.
누군가 문을 세게 흔들었거나, 아이가 안쪽 손잡이를 이상한 방향으로 돌렸을 때도 울릴 수 있습니다. / 이웃이 문을 잘못 알고 번호를 여러 번 눌렀을 때도 마찬가지입니다.
경보를 끄는 방법은 제품마다 다르지만, 보통 안쪽에서 손잡이를 한 번 열고 닫거나 바깥에서 맞는 번호를 누르면 멈춥니다. / 그래도 멈추지 않으면 안쪽 배터리를 잠깐 빼서 끄고, 바로 연락 주세요.
일부 제품은 주변 온도가 크게 오르면 경보를 울리고 문을 풀어 주는 기능이 있습니다. / 집 안에 탄 냄새나 연기가 있다면 도어락보다 119가 먼저입니다.

# 모터만 윙 돌고 걸쇠가 꿈쩍 않을 때
번호는 맞는데 모터 소리만 나고 문이 안 열린다면 모터가 걸쇠를 끝까지 당기지 못하고 있는 겁니다. / 걸쇠가 문틀에 눌려 있거나, 안쪽 기어가 닳았거나, 배터리 힘이 부족할 때 이렇게 됩니다.
문을 안쪽으로 살짝 밀면서 다시 번호를 눌러 보세요. / 걸쇠가 받는 힘이 줄어 열리기도 합니다.
그래도 안 되면 배터리를 의심해 비상 단자에 9V 건전지를 대고 다시 해 보세요. / 두세 번 해서 같으면 기어나 모터 문제일 가능성이 높으니 멈추시고 연락 주세요.

# 혼자 철컥거리거나 삑 소리를 낼 때
아무도 안 만졌는데 도어락이 혼자 열리거나 잠기는 소리를 내는 경우가 있습니다. / 번호판 안쪽 접점이 상했거나 습기, 이물질 때문에 버튼이 눌린 것으로 잘못 읽히는 경우입니다.
이런 증상은 그냥 두면 안 됩니다. / 문이 혼자 풀려 있는 상태로 집을 비우게 될 수도 있어 가능한 빨리 점검받으시는 게 좋습니다.

# 배터리를 통째로 빼기 전에
경고음이 시끄럽다고 배터리를 다 빼 두는 분이 있습니다. / 소리는 멈추지만 도어락이 꺼져 있는 상태라 바깥에서는 번호로 열 수 없게 됩니다.
특히 혼자 사시는 분이 배터리를 뺀 채 외출하시면 돌아와서 문을 못 엽니다. / 소리를 멈추려고 뺐다면 새 배터리를 넣거나 점검을 받은 뒤에 외출하세요.

# 밤에 경보가 울려 이웃이 걱정된다면
본오동 아파트나 빌라에서 밤에 경보가 울리면 계단을 따라 소리가 크게 번집니다. / 우선 안쪽에서 경보를 멈추고, 멈추지 않으면 배터리를 잠시 빼 두세요.
이웃이 놀라 문을 두드리면 상황을 짧게 설명해 주시면 됩니다. / 밤이라도 24시간 전화를 받으니 그다음 일은 연락 주시고 정하시면 됩니다.

# 하지 않는 게 나은 것
- 번호판을 손으로 세게 두드리기
- 바깥 번호판 나사를 풀어 안쪽 들여다보기
- 모터 소리가 날 때 손잡이를 힘껏 당기기
- 경보가 울릴 때 번호를 마구 눌러 보기
모터가 돌 때 손잡이를 당기면 기어에 무리가 가 고장이 커집니다. / 번호를 마구 누르면 입력 제한까지 걸려 상황이 더 꼬입니다.

# 전화부터 작업 시작까지
어떤 소리인지, 문이 열리는지 안 열리는지, 집 안에 사람이 있는지부터 말씀해 주세요. / 녹음한 소리나 도어락 사진을 함께 보내 주시면 준비가 정확해집니다.
아파트인지 빌라인지, 동과 호수, 공동현관 번호가 있는지도 알려 주세요.
도착하면 신분증 주소, 주소가 적힌 우편물, 관리사무소 세대 확인 중 하나로 사시는 분인지 먼저 확인합니다. / 소리 원인과 도어락 상태를 본 뒤 작업 전에 금액을 먼저 말씀드립니다.
동의하시면 시작하고, 문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에, 문 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 원인에 따라 수리와 교체를 나눕니다
배터리나 접점 문제라면 닦고 바꾸는 것으로 끝나는 경우가 많습니다. / 기어나 모터가 닳았다면 부품을 바꿔 [도어락 수리](doorlock-repair.html)로 다시 쓸 수 있는지 먼저 봅니다.
번호판 안쪽 회로가 상했거나 부품이 더 이상 나오지 않는 제품이라면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 바꿀지 고칠지는 들어 보시고 정하시면 됩니다.
@ 본오동 도어락 모터 기어 점검 수리

# 본오동 말고 안산 다른 동네도
고잔동, 초지동, 선부동, 와동, 원곡동, 사동, 이동, 월피동, 성포동까지 다니고, 대부동은 도착 시간을 미리 말씀드립니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
@ 안산 본오동 24시 출장열쇠 도어락 경보

# 도어락 소리, 이런 걸 많이 물으십니다
? 짧은 삑 소리가 섞여 나는데 바로 바꿔야 하나요? | 배터리가 약하다는 알림인 경우가 많습니다. 그날 안에 모두 새것으로 바꿔 주세요.
? 경보가 안 멈춰요. 어떻게 끄나요? | 안쪽 손잡이를 한 번 열고 닫거나 바깥에서 맞는 번호를 눌러 보세요. 그래도 안 되면 배터리를 잠시 빼고 연락 주세요.
? 모터 소리만 나고 안 열려요. | 문을 살짝 밀면서 번호를 눌러 보시고, 비상 건전지도 대 보세요. 같으면 기어 문제일 수 있습니다.
? 혼자 열렸다 잠겼다 해요. | 접점이나 버튼 문제일 수 있어 빨리 점검받으시는 게 좋습니다. 문이 풀린 채 외출하지 마세요.
? 못 열면 비용이 드나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.

# 본오동 도어락이 울릴 때
소리의 모양을 기억하고, 가능하면 녹음해 두세요. / 짧은 소리는 배터리, 주기적인 소리는 문 닫힘, 긴 소리는 경보, 모터 소리만 나면 걸쇠 쪽입니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 다닙니다. / 소리가 멈추지 않거나 문이 안 열리면 010-3664-5455로 연락 주세요.
