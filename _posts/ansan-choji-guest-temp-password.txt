# 내가 없는 집에 누군가 들어와야 할 때
여행을 가 있는 동안 반려동물 밥을 챙겨 줄 친구, 집 안 수리를 맡긴 기사, 아이를 돌봐 주는 선생님까지 집에 다른 사람이 드나들 일은 생각보다 자주 생깁니다. / 초지역 주변 초지동처럼 아파트가 많은 동네에서는 현관 도어락 번호 하나로 이 일을 해결하는 집이 대부분입니다.
문제는 가족이 쓰는 번호를 그대로 알려 주는 것입니다. / 일이 끝난 뒤 번호를 바꾸는 걸 잊으면 그 번호는 계속 다른 사람 손에 남게 됩니다.
이 글은 초지동에서 다른 사람이 집에 드나들 때 임시 번호를 어떻게 만들고 언제 지우면 좋은지, 상황별로 나눠 정리했습니다. / 설정하다 막히면 [안산 출장열쇠](ansan.html)에서 도와드립니다.
@ 초지동 아파트 도어락 임시 비밀번호 설정

# 먼저 우리 도어락이 무엇을 할 수 있는지
도어락마다 들어 있는 기능이 다릅니다. / 설명서나 제품 뒷면 모델명을 보고 아래 기능이 있는지 확인해 보세요.
- 가족 번호 말고 번호를 하나 더 등록하는 기능
- 한 번 쓰면 사라지는 일회용 번호
- 카드나 태그를 한 장씩 따로 등록하고 지우는 기능
- 휴대폰 앱으로 문을 열거나 출입 기록을 보는 기능
모델명을 알면 제조사 안내에서 설정 방법을 찾을 수 있습니다. / 찾기 어렵다면 도어락 사진을 보내 주시면 어떤 기능이 있는지 알려 드립니다.

# 여행 중 반려동물을 봐 줄 지인에게
며칠 동안 하루 한두 번 들르는 경우라면 일회용 번호보다 따로 등록하는 보조 번호가 편합니다. / 여행이 끝나는 날 그 번호만 지우면 가족 번호는 그대로 쓸 수 있습니다.
떠나기 전날 지인과 함께 문 앞에서 한 번 직접 열어 보게 해 주세요. / 막상 혼자 왔을 때 번호판 켜는 방법을 몰라 헤매는 일이 생각보다 많습니다.
보조 번호 기능이 없다면 가족 번호를 잠깐 바꿔 알려 주고, 돌아와서 다시 새 번호로 바꾸는 방법도 있습니다.
도어락 배터리도 떠나기 전에 확인해 두세요. / 집을 비운 사이 번호판이 꺼지면 지인이 문 앞에서 막히고, 멀리 있는 나는 해 줄 수 있는 것이 없습니다.

# 수리 기사나 설치 기사가 오는 날
집에 있을 수 없는 날 기사가 와야 한다면 일회용 번호가 가장 깔끔합니다. / 한 번 문을 열면 사라지기 때문에 따로 지울 필요가 없습니다.
다만 작업 중에 자재를 가지러 나갔다 들어와야 하는 경우도 있습니다. / 이럴 땐 문을 열어 둔 채 작업하도록 미리 이야기하거나, 그날 하루만 쓸 보조 번호를 정해 두세요.
일이 끝나면 문이 제대로 잠겼는지 사진을 보내 달라고 부탁해 두면 마음이 놓입니다.

# 정기적으로 오시는 돌봄 선생님께
매주 정해진 요일에 오시는 분이라면 그분 전용 번호나 카드를 하나 등록해 드리는 것이 좋습니다. / 가족 번호를 바꿀 때마다 따로 알려 드리지 않아도 되고, 그만두실 때 그분 것만 지우면 됩니다.
카드를 드린다면 카드 앞면에 집 주소나 동 호수를 적지 마세요. / 잃어버렸을 때 주운 사람이 어느 집 카드인지 알 수 없어야 합니다.
아이를 맡기는 경우라면 선생님이 들어오신 뒤 안쪽 걸쇠를 거실지, 열어 두실지도 미리 정해 두세요. / 부모가 일찍 돌아왔을 때 걸쇠 때문에 집에 못 들어가는 일도 생길 수 있습니다.
@ 초지동 돌봄 선생님 전용 카드 등록

# 부모님이나 친척이 며칠 머무실 때
가족이라도 며칠만 머무시는 경우라면 우리 집 가족 번호를 그대로 쓰셔도 큰 문제는 없습니다. / 다만 어르신이 번호를 종이에 적어 지갑에 넣어 다니시는 경우가 많으니, 가신 뒤에는 번호를 한 번 바꿔 두는 것이 좋습니다.
번호를 누르기 어려워하시면 카드를 한 장 등록해 드리는 것도 방법입니다. / 돌아가실 때 돌려받고 등록을 지우면 됩니다.
머무시는 동안 번호판 켜는 법과 안쪽에서 여는 법을 한 번씩 직접 해 보시게 하면 혼자 계실 때도 덜 당황하십니다.

# 앱으로 원격 열림을 쓴다면
휴대폰 앱으로 문을 열 수 있는 도어락이라면 번호를 아예 알려 주지 않고 손님이 도착했을 때 원격으로 열어 주는 방법도 있습니다. / 출입 기록이 남는 제품이라면 누가 언제 드나들었는지 확인할 수도 있습니다.
다만 집 인터넷이나 휴대폰 연결이 끊기면 원격 열림이 안 될 수 있습니다. / 앱만 믿지 말고 예비로 일회용 번호를 하나 준비해 두세요.

# 번호를 알려 줄 때 지킬 것
- 문자로 보냈다면 일이 끝난 뒤 그 문자를 지워 달라고 부탁하기
- 단체 대화방에는 번호를 올리지 않기
- 번호와 함께 동 호수를 한 문장에 적지 않기
- 언제까지 쓰는 번호인지 분명히 알려 주기
번호를 알려 준 날과 지울 날을 달력에 같이 적어 두면 잊어버리지 않습니다.
번호를 정할 때는 가족 번호와 앞자리가 겹치지 않게 전혀 다른 숫자로 만드세요. / 임시 번호를 보고 가족 번호를 짐작할 수 없어야 합니다.

# 일이 끝나면 지우는 것까지가 한 세트
임시로 만든 번호나 카드는 쓰임이 끝난 날 바로 지우는 것이 가장 중요합니다. / 미뤄 두면 어떤 번호가 남아 있는지 나중에는 아무도 모르게 됩니다.
지우는 방법이 헷갈린다면 가족 번호까지 한 번에 초기화하고 다시 등록하는 방법도 있습니다. / 이때는 가족 모두에게 새 번호를 다시 알려 주세요.

# 설정하다 문이 안 열리게 됐다면
번호를 등록하다 잘못 눌러 가족 번호까지 지워지는 일이 가끔 있습니다. / 문이 열린 상태에서 설정하면 이런 일을 막을 수 있습니다.
이미 문이 닫혀 들어갈 수 없게 됐다면 연락 주세요. / 사시는 분인지 신분증 주소나 우편물, 관리사무소 확인으로 확인한 뒤 문을 열고 번호를 다시 등록해 드립니다.

# 비용과 진행은 미리 말씀드립니다
문을 여는 일이든 번호 등록을 도와드리는 일이든 무엇을 할지와 금액을 먼저 알려 드리고 시작합니다. / 끝내 문을 열지 못하면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 안산 출장열쇠 초지동 도어락 번호 등록

# 이런 기능이 없는 도어락이라면
보조 번호도 일회용 번호도 없는 오래된 도어락이라면 손님이 올 때마다 가족 번호를 바꾸는 수밖에 없습니다. / 드나드는 사람이 자주 바뀌는 집이라면 이런 기능이 있는 제품으로 바꾸는 것도 생각해 볼 만합니다.
지금 문에 맞는지는 [도어락 교체](doorlock-replace.html)에서 상담하실 수 있고, 기존 제품 설정이 자꾸 꼬인다면 [도어락 수리](doorlock-repair.html)로 먼저 점검해 보셔도 됩니다.

# 초지동 말고 안산 다른 동네도
고잔동, 선부동, 와동, 원곡동, 본오동, 사동, 이동, 월피동, 성포동, 대부동까지 안산 전 지역 다닙니다. / 동네 목록은 [안산시 출장열쇠](ansan.html), 다른 지역은 [출장 지역](area.html)에서 보세요.
