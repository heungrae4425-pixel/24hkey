# 대부동 대문 앞에서 열쇠가 안 돌아갈 때
대부동은 대부도 일대를 포함하는 지역으로 단독주택과 펜션, 별장처럼 대문이 따로 있는 집이 많습니다. / 아파트 현관문과 달리 대문과 현관문 두 군데를 모두 열어야 집에 들어갈 수 있는 구조도 흔합니다.
오랫동안 비바람과 바다 쪽 습기를 맞은 철문 자물쇠는 쉽게 뻑뻑해지거나 녹이 슬어서 열쇠가 안 돌아가기도 합니다. / 이 글은 [안산 출장열쇠](ansan.html)를 부르기 전에 확인해 볼 것과 거리가 있는 지역에서 도착까지 어떻게 진행되는지를 정리했습니다.
대문이 안 열려서 집 안에 들어가지 못하는 상황이라면 아래 내용을 차례로 확인해 보세요.
@ 대부동 대문 철문 자물쇠 출장열쇠 개문

# 대문 자물쇠가 안 열리는 이유
대문은 야외에 그대로 노출되어 있어서 현관문 도어락보다 상태가 더 빨리 나빠집니다. / 흔한 원인은 아래와 같습니다.
- 열쇠 구멍에 먼지나 모래, 녹이 쌓여 열쇠가 끝까지 안 들어가는 경우
- 오래 써서 열쇠 이가 닳아 실린더 핀이 맞지 않는 경우
- 대문이 처지거나 문기둥이 기울어 빗장이 팽팽하게 걸린 경우
- 비 오고 습한 계절 뒤에 철문이 부풀어 잠금장치가 빡빡해진 경우
- 열쇠를 돌릴 때 힘을 너무 주다 열쇠가 구멍 안에서 부러진 경우
어느 경우든 억지로 돌리면 상황이 악화됩니다. / 열쇠가 돌아가지 않을 때 힘으로 비트는 것이 가장 위험합니다.

# 열쇠를 돌리기 전에 먼저 살펴보세요
열쇠를 세게 돌리기 전에 몇 가지를 눈으로 확인해 보세요.
열쇠 이가 닳았거나 구부러진 곳은 없는지 봅니다. / 휘어진 열쇠를 계속 쓰면 열쇠 구멍 안쪽이 상할 수 있습니다.
열쇠 구멍 안에 이물질이 보이는지 확인합니다. / 먼지가 있다면 입으로 불거나 마른 솔로 털어내는 정도만 해 주세요.
열쇠를 끝까지 넣은 뒤 아주 살짝 뒤로 뺐다가 돌려 보면 맞는 경우가 있습니다. / 이때도 힘을 주지 않고 가볍게 시도해 보세요.
@ 대부동 열쇠 구멍 이물질 확인 철문 자물쇠

# 기름칠을 해도 될까요
열쇠가 뻑뻑할 때 아무 기름이나 뿌리는 분들이 있습니다. / 일반 식용유나 끈적이는 기름은 먼지를 달라붙게 해서 나중에 더 심하게 막힙니다.
쓰신다면 열쇠 구멍 전용 윤활제를 아주 조금만 쓰는 편이 안전합니다. / 그래도 안 돌아가면 반복하지 말고 점검을 받으세요.
겨울에 물기가 얼어붙어서 열쇠가 안 돌아가는 경우도 있습니다. / 이때는 뜨거운 물을 붓지 말고 서서히 녹을 때까지 기다리거나 따뜻한 바람을 조심스럽게 쓰세요.

# 열쇠가 부러졌을 때는 이렇게 하세요
열쇠가 구멍 안에서 부러졌다면 더 이상 만지지 말고 그대로 두세요. / 핀셋이나 바늘로 빼내려다 파편이 더 깊이 들어가 일이 커집니다.
부러진 열쇠 반쪽은 버리지 말고 보관해 주세요. / 같은 열쇠 모양으로 다시 만들거나 교체할 때 도움이 됩니다.
도어락이 아닌 대문 자물쇠는 구조가 단순해서 부러진 조각을 안전하게 빼내는 경우가 많습니다. / 먼저 사진을 문자로 보내주시면 필요한 장비를 챙겨 갑니다.

# 대문과 현관문을 구분해서 알려주세요
대부동처럼 대문이 따로 있는 집은 어느 문이 잠겼는지를 알려주셔야 합니다.
- 대문(철문, 대문 자물쇠)만 안 열리는지
- 현관문 도어락까지 안 열리는지
- 대문에 도어락이 붙어 있는지, 열쇠만 쓰는지
- 담장 안쪽에 사람이 있는지
대문 사진과 자물쇠 사진을 같이 보내주시면 챙겨 가는 장비가 정확해집니다. / 자물쇠 모양이 특이하다면 가까이서 한 장 더 찍어 주세요.

# 거리가 있는 지역은 이렇게 진행합니다
대부동은 안산 시내와 거리가 있어서 도착까지 시간이 걸릴 수 있습니다. / 그래서 전화를 받으면 위치를 정확히 확인하고 예상 도착 시간을 먼저 말씀드립니다.
섬 쪽이나 외곽은 길을 못 찾는 경우도 있습니다. / 지도 앱의 현재 위치를 문자로 보내주시면 가장 정확합니다.
도착이 오래 걸릴 것 같으면 기다리는 동안 안전한 곳에서 대기하시도록 안내합니다. / 늦은 밤 도로가 어두운 곳이라면 차량이나 실내에서 기다려 주세요.
먼 곳이라도 문을 못 열면 비용은 받지 않는다는 원칙은 똑같습니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인하는 절차가 있습니다. / 신분증 주소나 주소가 적힌 우편물, 관리하시는 분 확인으로 진행합니다.
펜션이나 별장은 주인이거나 예약자인지 확인이 필요합니다. / 대신 요청하실 때는 주인 되시는 분과 통화로 확인할 수 있어야 합니다.
신분증이 집 안에 있다면 휴대폰 속 공과금 고지서나 계약서를 먼저 말씀해 주세요. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
자물쇠 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 자물쇠를 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 대부동 24시 출장열쇠 철문 개문 비용 안내

# 문을 여는 방법
철문과 대문 자물쇠는 상하지 않게 여는 방법부터 차례로 시도합니다. / 자물쇠 종류에 따라 걸리는 시간이 다릅니다.
열쇠가 돌아가지 않는 경우에는 구멍 속 이물질이나 핀 상태를 먼저 확인합니다. / 필요하면 자물쇠를 안 상하게 분해해서 여는 방법을 씁니다.
작업 중에 교체가 필요해 보이면 손대기 전에 말씀드립니다. / 자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 열고 난 뒤 같이 점검하는 것
문이 열리면 자물쇠가 부드럽게 돌아가는지 여러 번 확인합니다. / 열쇠 구멍에 이상이 있으면 청소하거나 부품을 교체할지 여쭤봅니다.
오래된 자물쇠는 한 번 열렸을 때 새것으로 바꾸는 편이 안심되는 경우도 있습니다. / 이때는 [출장 열쇠](key-call.html) 쪽에서 새 열쇠 복사나 교체를 같이 도와드립니다.
대문이 처졌다면 경첩과 빗장 위치도 같이 살펴봅니다. / 현관 쪽 도어락이 있다면 [도어락 수리](doorlock-repair.html) 여부도 함께 봅니다.

# 바닷바람 맞는 자물쇠 관리법
바다와 가까운 지역은 공기 중 염분과 습기 때문에 금속이 쉽게 녹이 습니다. / 그래서 자물쇠 관리가 더 중요합니다.
- 열쇠 구멍에는 평소 먼지가 들어가지 않게 덮개를 닫아 두기
- 비가 지나간 뒤 대문 자물쇠 주변 물기 닦기
- 반년에 한 번쯤 열쇠를 돌려 보며 뻑뻑한 정도 확인하기
- 열쇠는 한두 개 더 만들어 따로 보관하기
미리 한 번 점검해 두면 문 앞에서 낭패 볼 일을 많이 줄일 수 있습니다.

# 대부동 말고 안산 어디든 갑니다
고잔동, 초지동, 선부동, 와동, 원곡동, 본오동, 사동, 이동, 월피동, 성포동까지 안산 전 지역 24시간 출동합니다. / 대부동은 거리가 있어 위치를 받고 도착 시간을 미리 말씀드립니다.
안산에서 다니는 동네는 [안산시 출장열쇠](ansan.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
