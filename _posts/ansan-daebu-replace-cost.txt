# 대부도 현관 도어락, 바꿀 때가 됐나 싶다면
대부동은 안산 단원구에 속한 대부도 일대로, 시내 아파트와는 달리 단독주택과 펜션, 주말에만 머무는 집이 섞여 있는 곳입니다. / 바다와 가까워 짠 바람과 습기를 늘 맞다 보니 도어락이 시내보다 빨리 지치는 편입니다.
번호판 글자가 흐려지고, 손잡이가 뻑뻑해지고, 배터리를 갈아도 금방 경고음이 나면 교체를 생각하게 됩니다. / 그런데 대부동은 거리도 있고 집 형태도 다양해서 바꾸기 전에 확인할 것이 시내보다 조금 많습니다.
이 글은 대부동에서 도어락을 바꾸기 전에 따져 볼 것과, [안산 출장열쇠](ansan.html)에서 비용을 어떤 순서로 안내드리는지 정리했습니다.
@ 대부동 주택 펜션 도어락 교체 상담

# 정말 바꿔야 하는지 먼저 가려 봅니다
도어락이 말썽이라고 다 바꿔야 하는 건 아닙니다. / 배터리 접점이 녹슬었거나 걸쇠에 이물질이 낀 정도라면 손보는 것으로 다시 쓸 수 있습니다.
반대로 아래 같은 상태라면 고쳐도 오래 못 가는 경우가 많습니다. / 이럴 때 교체를 권해 드립니다.
- 번호판 안쪽까지 녹이 번져 버튼이 따로 놂
- 배터리 칸 접점이 삭아 새 배터리도 금방 닳음
- 모터 소리가 약하고 걸쇠가 반쯤만 움직임
- 부품이 더 이상 나오지 않는 오래된 제품
상태를 보고 수리로 될 일이면 수리를 먼저 말씀드립니다. / 수리와 교체의 차이는 [도어락 수리](doorlock-repair.html)와 [도어락 교체](doorlock-replace.html)에 정리해 두었습니다.

# 바닷바람이 도어락에 남기는 흔적
짠 바람은 눈에 잘 안 보이게 도어락을 상하게 합니다. / 겉면은 멀쩡해 보여도 나사 머리, 손잡이 축, 배터리 칸 쪽에 하얀 가루나 붉은 녹이 생깁니다.
바깥 번호판이 해와 바람을 정면으로 받는 문이라면 이런 흔적이 더 빨리 나타납니다. / 교체를 생각하신다면 이 부분을 사진으로 찍어 보내 주세요. / 녹이 어디까지 번졌는지만 봐도 고쳐 쓸지 바꿀지 판단이 한결 빨라집니다.
@ 대부동 바닷바람 도어락 녹 염분 흔적

# 새 도어락은 바깥 환경부터 고릅니다
대부동처럼 바깥 공기를 직접 맞는 현관이라면 제품을 고를 때 방수와 녹에 강한지를 먼저 봐야 합니다. / 기능이 많은 것보다 바깥 환경을 잘 버티는 것이 오래 쓰는 데 더 중요합니다.
번호판 위에 비가리개를 함께 다는 것도 방법입니다. / 지붕이 없는 대문이나 바다 쪽을 보는 현관에서는 특히 차이가 큽니다.
지문 기능은 손이 젖은 채 드나드는 일이 많은 집이라면 번호나 카드와 함께 쓰는 쪽이 편합니다. / 어떤 방식이 맞을지는 사는 분들의 생활을 듣고 함께 정합니다.

# 문과 구멍 상태가 제품을 정합니다
도어락은 문에 맞아야 제대로 섭니다. / 문 두께와 재질, 기존 구멍 크기와 위치를 먼저 봐야 어떤 제품이 들어갈 수 있는지 정해집니다.
- 철문인지 나무문인지, 유리가 들어간 문인지
- 문 두께와 기존 도어락 구멍 크기
- 위쪽에 보조키가 있는지, 남길지 뗄지
- 문이 처지거나 문틀이 녹슬어 걸쇠가 잘 안 맞는지
오래된 주택은 문틀이 녹슬거나 틀어져 새 도어락을 달아도 걸쇠가 안 맞는 경우가 있습니다. / 이때는 받이쇠나 문틀을 함께 손봐야 하니 미리 말씀드립니다.

# 펜션은 객실 수와 운영 방식부터
펜션 객실 여러 곳을 한꺼번에 바꾸려는 경우가 있습니다. / 이럴 때는 객실 수, 문 종류가 모두 같은지, 손님 출입 방식을 어떻게 할지부터 정해야 합니다.
손님마다 번호를 바꿔 주는 운영이라면 임시 번호나 카드 기능이 있는 제품이 편합니다. / 객실 문 종류가 서로 다르면 제품도 나눠 골라야 할 수 있습니다.
객실 사진을 한 곳씩 보내 주시면 미리 살펴보고 어떤 순서로 바꿀지 상의드립니다. / 손님이 없는 날로 일정을 맞추면 영업에 지장이 덜합니다.

# 비워 두는 집이라면 이것도 생각하세요
주말에만 쓰는 집이나 오래 비워 두는 별장은 배터리가 다 돼도 바로 알 수 없습니다. / 도착해서야 문이 안 열리는 걸 알게 되면 대부동까지 다시 와야 하니 더 번거롭습니다.
배터리 잔량을 알려 주는 기능이나 비상 열쇠가 있는 제품을 고르시는 게 좋습니다. / 앱 연동은 신호가 잘 닿는 집인지 먼저 확인해야 합니다. / 관리해 주는 이웃이 있다면 그분 몫의 카드나 번호를 따로 정해 두는 것도 생각해 보세요.

# 비용은 이런 순서로 안내드립니다
처음 전화나 사진으로는 어떤 작업이 될지 대략적인 방향을 말씀드립니다. / 정확한 금액은 현장에서 문과 도어락 상태를 직접 본 뒤, 작업 전에 먼저 말씀드립니다.
제품을 고르실 때는 몇 가지를 견주어 보여 드리고 각각 무엇이 다른지 설명드립니다. / 들으시고 정하시면 그때 시작합니다.
문틀이나 받이쇠처럼 따로 손봐야 할 곳이 생기면 그 부분도 손대기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 거리가 있어 일정을 먼저 맞춥니다
대부동은 시내에서 거리가 있어 교체 작업은 미리 날짜와 시간을 정하고 가는 편이 좋습니다. / 전화 주시면 도착까지 걸리는 시간을 먼저 말씀드립니다.
제품을 정해 두면 한 번에 챙겨 갈 수 있어 다시 오가는 일이 줄어듭니다. / 사진과 문 치수를 미리 보내 주시면 준비가 훨씬 정확해집니다.
급하게 문이 안 열리는 상황이라면 교체보다 문 여는 일이 먼저입니다. / 이때는 [현관문 개문](door-open.html)부터 진행하고 교체는 나중에 정하셔도 됩니다.

# 견줘 볼 때 금액만 보지 마세요
도어락 교체는 같은 제품이라도 문 상태에 따라 손이 가는 정도가 다릅니다. / 금액만 비교하기보다 기존 구멍을 어떻게 처리하는지, 보조키를 어떻게 할지, 바깥 환경에 맞는 제품인지 함께 물어보세요.
설치 뒤에 문제가 생기면 어떻게 하는지도 미리 들어 두시면 좋습니다. / 대부동처럼 먼 곳은 이 부분이 더 중요합니다.

# 교체 당일 확인과 마무리
작업 전에 사시는 분이나 운영하시는 분인지 신분증, 주소가 나온 우편물, 사업자등록증 등으로 확인합니다. / 별장처럼 주소지가 다른 집이라면 등기나 계약 관련 서류 사진으로 확인하기도 합니다.
새 도어락을 단 뒤에는 번호와 카드, 지문 등록을 함께 하고, 문을 여러 번 열고 닫으며 걸쇠가 잘 맞는지 봅니다. / 문 여는 상황에서 끝내 못 열면 비용은 받지 않는 원칙은 교체 상담 때도 똑같습니다.
@ 대부동 새 도어락 설치 후 작동 점검
