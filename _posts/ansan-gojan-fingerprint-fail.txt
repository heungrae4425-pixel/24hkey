# 고잔동 아파트 현관에서 "다시 시도하세요"만 반복된다면
고잔동은 고잔역과 중앙역 생활권에 아파트 단지와 상가, 오피스텔이 모여 있는 동네입니다. / 맞벌이 가정과 아이 키우는 집이 많아 번호 대신 손가락 하나로 여는 지문 도어락을 단 현관도 흔합니다.
편하자고 단 지문 도어락이 어느 날부터 자꾸 헛손질을 하면 오히려 번거롭습니다. / 아침에는 잘 되다가 저녁 운동을 마치고 오면 안 되고, 아이 손가락은 몇 번을 대도 안 읽히는 식입니다.
이 글은 고잔동에서 지문 인식이 잘 안 될 때 상황별로 원인을 나누고, 집에서 다시 잘 읽히게 만드는 요령을 정리했습니다. / 문이 아예 열리지 않는다면 [안산 출장열쇠](ansan.html)를 부르시면 됩니다.
@ 고잔동 아파트 지문 도어락 인식 실패

# 언제 안 되는지부터 적어 보세요
지문 인식 실패는 "늘 안 된다"보다 "이럴 때 안 된다"인 경우가 대부분입니다. / 며칠만 지켜보면 원인이 드러납니다.
- 운동하고 돌아왔을 때나 여름처럼 땀이 날 때
- 설거지나 손을 씻은 직후
- 특정 가족, 특히 아이 손가락만
- 날씨와 상관없이 점점 더 안 될 때
앞의 세 가지는 손 상태나 등록 방식 문제인 경우가 많고, 마지막은 센서나 배터리 쪽일 가능성이 큽니다.

# 땀 묻은 손가락은 센서를 흐리게 합니다
땀이 많은 손가락을 대면 센서 위에 얇은 물막이 생깁니다. / 센서는 이 물막 너머로 지문 결을 읽지 못해 실패를 반복합니다.
옷자락이나 손수건에 손가락 끝을 한 번 닦고 대 보세요. / 그래도 안 되면 센서 표면도 함께 닦아야 합니다.
운동을 자주 하신다면 땀이 덜 나는 다른 손가락을 하나 더 등록해 두시는 것도 방법입니다. / 왼손 검지처럼 평소 덜 쓰는 손가락이 오히려 잘 읽히는 경우가 있습니다.

# 손을 씻은 직후에도 비슷합니다
쓰레기를 버리고 손을 씻고 돌아오면 손끝이 쪼글쪼글해져 있습니다. / 물에 불은 손가락은 지문 결 모양이 평소와 달라 인식이 떨어집니다.
목욕을 하고 나오거나 비 오는 날 우산 없이 걸어온 뒤에도 같은 일이 생깁니다. / 몇 분 지나 손끝이 원래대로 돌아오면 다시 잘 읽힙니다. / 급하다면 다른 방법으로 열고, 지문은 나중에 다시 써 보세요.
@ 고잔동 지문 센서 물기 땀 닦기

# 아이 손가락은 자라면서 달라집니다
아이 지문은 손가락이 자라면서 크기와 모양이 조금씩 바뀝니다. / 몇 해 전 등록한 아이 지문이 지금은 잘 안 읽히는 건 자연스러운 일입니다.
아이 손가락은 작아서 센서 가운데에 정확히 올리기도 어렵습니다. / 등록할 때 어른이 아이 손을 살짝 잡아 가운데에 맞춰 주시면 훨씬 잘 됩니다.
초등학교 저학년 정도 아이라면 해가 바뀔 때쯤 한 번씩 다시 등록해 주세요. / 아이가 혼자 귀가하는 집이라면 지문 외에 번호도 함께 알려 두셔야 합니다.

# 센서는 이렇게 닦아 주세요
가족 여럿이 매일 쓰는 센서에는 손때와 화장품, 핸드크림이 쌓입니다. / 겉으로는 깨끗해 보여도 비스듬히 비춰 보면 뿌연 막이 보이는 경우가 많습니다.
부드러운 안경 닦이나 마른 극세사 천으로 가볍게 닦아 주세요. / 알코올이나 세정제를 직접 뿌리는 건 틈으로 스며들 수 있어 피하시는 게 좋습니다.
닦은 뒤에는 바로 대지 말고 센서가 완전히 마를 때까지 잠깐 기다리세요. / 센서 위에 보호 필름이 붙어 있다면 그것도 확인해 보세요. / 설치 때 떼지 않은 필름이나 나중에 붙인 필름이 인식을 방해하기도 합니다.

# 등록할 때 이것만 바꿔도 달라집니다
등록할 때 손가락을 한 자세로만 여러 번 대면, 조금만 각도가 달라져도 실패합니다. / 등록 과정에서 손가락을 조금씩 기울이고 돌려 가며 대면 다양한 각도가 함께 저장됩니다.
- 손가락 끝만이 아니라 첫 마디 가운데까지 대기
- 등록 중 손가락을 살짝 위아래로 옮겨 가며 대기
- 한 사람당 두세 손가락 등록
- 자주 쓰는 손가락은 두 번 등록
등록할 수 있는 지문 수는 제품마다 정해져 있습니다. / 가족이 많다면 꼭 필요한 손가락부터 정해 두세요. / 더 이상 같이 살지 않는 가족이나 예전 세입자의 지문이 남아 있다면 이참에 지워 자리를 비워 두는 것도 좋습니다.
@ 고잔동 도어락 지문 재등록 각도

# 점점 더 안 된다면 배터리와 센서를 의심하세요
손 상태와 상관없이 날이 갈수록 인식이 떨어진다면 배터리가 약해지고 있을 수 있습니다. / 지문 센서는 번호 버튼보다 전기를 많이 써서 배터리가 약해지면 가장 먼저 티가 납니다.
배터리를 모두 새것으로 바꿨는데도 그대로라면 센서 자체를 봐야 합니다. / 센서 표면이 긁혔거나 안쪽 부품이 상했다면 [도어락 수리](doorlock-repair.html)로 점검받으시는 게 좋습니다.

# 지문 하나에만 기대지 마세요
지문 도어락이라도 번호나 카드를 꼭 하나 함께 살려 두세요. / 손을 다치거나 밴드를 붙인 날, 장갑을 낀 겨울에는 지문만으로 들어갈 수 없습니다.
번호를 너무 오래 안 써서 잊어버리는 분도 많습니다. / 한 달에 한 번쯤은 일부러 번호로 열어 보시면 급할 때 기억이 납니다. / 카드키는 현관 안쪽이 아니라 가방이나 지갑처럼 늘 들고 다니는 곳에 넣어 두셔야 쓸모가 있습니다.

# 문 앞에서 하지 않는 게 나은 것
- 센서를 손톱으로 긁어 닦기
- 같은 손가락으로 수십 번 연달아 시도하기
- 센서에 입김을 잔뜩 불어 물기 만들기
- 바깥 덮개를 열어 안쪽을 만지기
여러 번 실패하면 제품에 따라 한동안 입력이 막히기도 합니다. / 서너 번 해서 안 되면 다른 방법으로 넘어가세요.

# 끝내 열리지 않을 때
지문도, 번호도, 카드도 안 된다면 출장을 부르셔야 합니다. / 몇 동 몇 호인지, 어느 방법까지 해 봤는지, 번호판이 켜지는지 알려 주세요.
도착하면 신분증 주소나 주소가 적힌 우편물, 관리사무소 세대 확인으로 사시는 분인지 먼저 봅니다. / 도어락 상태를 확인한 뒤 작업 전에 금액을 먼저 말씀드리고, 끝내 못 열면 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html)에, 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 열린 뒤 함께 해 드리는 것
배터리를 확인하고, 센서를 닦고, 가족 지문을 다시 등록하는 것까지 함께 해 드립니다. / 아이 손가락 등록도 그 자리에서 맞춰 드립니다.
센서가 오래돼 인식이 계속 떨어진다면 지문 인식이 더 좋은 제품으로 [도어락 교체](doorlock-replace.html)를 상의드릴 수 있습니다. / 바꾸지 않고 고쳐 쓸 수 있다면 그쪽을 먼저 말씀드립니다.
@ 고잔동 지문 도어락 센서 점검 교체 상담

# 고잔동 외 안산 다른 동네
초지동, 선부동, 와동, 원곡동, 본오동, 사동, 이동, 월피동, 성포동까지 다니고, 대부동은 도착 시간을 미리 말씀드립니다. / 다른 지역은 [출장 지역](area.html)에서 보세요.

# 지문 인식, 고잔동에서 들은 질문들
? 운동만 하고 오면 안 읽혀요. | 땀 때문인 경우가 많습니다. 손끝을 닦고 대 보시고, 땀이 덜 나는 손가락을 하나 더 등록해 두세요.
? 아이 지문이 예전엔 됐는데 지금은 안 돼요. | 아이 손가락이 자라면서 달라진 겁니다. 다시 등록하면 대부분 해결됩니다.
? 센서를 물티슈로 닦아도 되나요? | 물기가 틈으로 들어갈 수 있어 마른 천을 권합니다.
? 지문을 몇 개까지 넣을 수 있나요? | 제품마다 다릅니다. 안쪽 몸체 제품 이름을 알려 주시면 확인해 드립니다.
? 못 열면 비용이 나오나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.

# 고잔동 지문 도어락 정리
땀과 물기는 닦고, 아이 손가락은 다시 등록하고, 점점 나빠지면 배터리부터 바꿔 보세요. / 그래도 안 되면 센서를 점검받으시면 됩니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 다닙니다. / 지문으로 안 열리는 문 앞이라면 010-3664-5455로 연락 주세요.
