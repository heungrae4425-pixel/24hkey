# 고잔동 현관 앞, 손가락이 기억하던 번호가 틀렸다고 나올 때
고잔동은 고잔역과 중앙역 사이로 아파트 단지와 상가, 오피스텔이 모여 있는 안산 단원구의 주거 중심지입니다. / 단지가 크고 세대가 많다 보니 저녁 퇴근 시간이면 현관 앞에서 번호를 다시 누르는 분들을 종종 보게 됩니다.
매일 누르던 번호가 갑자기 틀렸다는 소리를 내면 머릿속이 하얘집니다. / 내가 잊은 건지, 누가 바꾼 건지부터 헷갈립니다.
이 글은 고잔동에서 비밀번호 때문에 문이 안 열릴 때 기억을 되살리는 방법, 가족에게 확인하는 순서, 그래도 안 되면 [안산 출장열쇠](ansan.html)를 부르는 방법을 정리했습니다.
@ 고잔동 아파트 도어락 비밀번호 분실

# 틀렸다는 소리가 몇 번째인지 세어 보세요
도어락은 비밀번호를 연달아 틀리면 일정 시간 입력을 막습니다. / 막히는 횟수와 시간은 제품마다 다르지만, 대개 서너 번이 넘어가면 잠시 멈추는 경우가 많습니다.
지금 몇 번 틀렸는지 먼저 세어 보시고, 세 번째쯤에서 손을 떼세요. / 막힌 상태에서 계속 누르면 막히는 시간이 늘어나는 제품도 있어 오히려 늦어집니다.
경고음이 길게 이어진다면 이미 막힌 상태입니다. / 몇 분 기다렸다가 번호를 차분히 떠올린 뒤 다시 해 보세요.

# 머리보다 손이 기억하는 경우가 있습니다
매일 누르던 번호는 숫자보다 손가락 움직임으로 남아 있는 경우가 많습니다. / 번호를 떠올리려 애쓰기보다, 휴대폰 화면이나 손바닥 위에 평소처럼 눌러 보는 시늉을 해 보세요.
번호판 배열을 떠올리며 "위에서 아래로, 다시 왼쪽으로" 하는 식의 모양을 기억해 내는 분도 있습니다. / 숫자가 떠오르면 그때 천천히 눌러 보시면 됩니다.
번호 끝에 별표나 샵을 누르는 제품인지, 그냥 번호만 누르면 되는 제품인지도 다시 생각해 보세요. / 마지막 버튼 하나 때문에 맞는 번호가 틀린 것처럼 되는 일도 있습니다.

# 집안에서 누가 바꿨을지 짚어 보기
번호가 바뀐 경우라면 대부분 집안 누군가가 바꾼 것입니다. / 아래 경우를 하나씩 떠올려 보세요.
- 배우자나 다른 가족이 최근에 바꾸고 말을 깜빡한 경우
- 아이가 안쪽 설정 버튼을 만지다 번호가 바뀐 경우
- 배터리를 갈다가 설정이 초기화된 경우
- 이사 온 뒤 처음 정한 번호를 아직 그대로 쓰는 줄 알았던 경우
아이가 있는 집이라면 두 번째 경우를 꼭 생각해 보세요. / 안쪽 몸체의 버튼은 아이 손에 닿기 쉬워 장난처럼 눌렀다가 번호가 바뀌는 일이 생깁니다.
@ 고잔동 도어락 안쪽 설정 버튼 아이 장난

# 연락은 이 순서로 해 보세요
가족 중 마지막으로 번호를 만졌을 법한 사람에게 먼저 연락하세요. / 연락이 안 되면 가족 단체 대화방에 번호 이야기가 올라온 적이 없는지 위로 올려 보세요.
멀리 출장 중이거나 해외에 있는 가족이라 바로 연락이 안 될 수도 있습니다. / 이럴 때는 문자를 남겨 두고, 기다릴 수 있는 상황인지 먼저 판단하세요.
집 안에 아이만 있다면 아이에게 안쪽 손잡이를 돌려 문을 열어 달라고 할 수 있습니다. / 아이가 놀라지 않게 천천히 말해 주시고, 아이가 어려 문을 열 수 없다면 그대로 연락 주세요.

# 관리사무소가 대신 열어 주지는 않습니다
고잔동처럼 큰 단지에 사시면 관리사무소에 먼저 가 보시는 분이 많습니다. / 하지만 관리사무소는 세대 도어락 번호를 알지 못하고, 대신 열어 주는 곳도 아닙니다.
대신 관리사무소에서는 이 집에 사시는 분이 맞는지 확인해 줄 수 있습니다. / 신분증이 집 안에 있을 때 이 확인이 큰 도움이 되니, 출장을 부르기 전에 미리 들러 두시면 좋습니다.

# 번호 대신 열 수 있는 방법이 남아 있는지
번호만 생각하다 보면 다른 방법을 잊기 쉽습니다. / 아래 중 쓸 수 있는 게 있는지 확인해 보세요.
- 지갑이나 휴대폰 케이스 안의 카드키
- 등록해 둔 지문
- 도어락 바깥의 비상 열쇠 구멍과 그 열쇠
- 휴대폰 앱으로 여는 기능 (연동해 둔 경우)
카드나 지문이 등록돼 있다면 번호를 몰라도 문은 열립니다. / 열고 들어간 뒤 천천히 번호를 정리하시면 됩니다.

# 고잔동 오피스텔이라면 관리 규정도 보세요
고잔동 오피스텔 중에는 호실 도어락을 관리 쪽에서 일괄로 달아 둔 곳도 있습니다. / 이런 곳은 비밀번호 초기화나 도어락 교체에 따로 정해 둔 방법이 있을 수 있습니다.
관리실에 한 번 물어보시고, 따로 정한 게 없다면 그때 연락 주세요. / 세입자라면 임대인에게도 알려 두시는 게 나중에 편합니다.

# 하지 않는 게 나은 것
- 생각나는 번호를 몽땅 차례로 눌러 보기
- 번호판을 떼어 내거나 나사를 풀기
- 배터리 덮개를 바깥에서 억지로 열기
- 문틈에 카드를 넣어 걸쇠를 밀기
막힌 도어락을 억지로 다루면 번호 문제였던 일이 고장 문제로 바뀝니다. / 그러면 문을 연 뒤에도 손볼 게 늘어납니다.

# 출장을 부를 때 이렇게 말씀해 주세요
몇 동 몇 호인지와 함께, 번호를 잊은 건지 누가 바꾼 건지 말씀해 주세요. / 경고음으로 입력이 막혀 있는지, 카드나 지문은 안 되는지도 알려 주시면 됩니다.
도어락 바깥 모습을 사진으로 보내 주시면 맞는 장비를 챙겨 가기 좋습니다. / 집 안에 아이나 반려동물이 있다면 꼭 먼저 말씀해 주세요.

# 확인부터 하고 금액을 말씀드립니다
도착하면 신분증 주소, 주소가 적힌 우편물, 관리사무소 세대 확인 중 하나로 사시는 분인지 먼저 봅니다. / 가족 명의 집이라면 그 가족과 통화로 확인하는 방법도 있습니다.
도어락 종류와 상태를 보고 작업 전에 금액을 먼저 말씀드립니다. / 동의하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html)에, 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 문이 열린 뒤 번호를 정리하는 법
문이 열리면 안쪽에서 새 번호를 등록하고, 예전 번호가 남아 있지 않은지 함께 확인합니다. / 가족 모두가 새 번호로 한 번씩 직접 열어 보는 것까지 하셔야 끝입니다.
번호를 바꾸는 사람은 한 사람으로 정해 두세요. / 바꾸면 그날 바로 가족 대화방에 알리는 것까지 규칙으로 삼으시면 같은 일이 줄어듭니다.
아이 손이 닿는 설정 버튼이 걱정된다면 덮개가 있는 제품인지 보시고, 없다면 [도어락 교체](doorlock-replace.html) 때 함께 따져 보세요. / 고장 기미가 보이면 [도어락 수리](doorlock-repair.html)로 먼저 손볼 수 있습니다.
@ 고잔동 도어락 새 비밀번호 등록

# 고잔동 말고 안산 다른 동네도
초지동, 선부동, 와동, 원곡동, 본오동, 사동, 이동, 월피동, 성포동까지 안산 어디든 다닙니다. / 대부동은 거리가 있어 도착 시간을 미리 말씀드리고, 다른 지역은 [출장 지역](area.html)에서 확인하세요.
@ 안산 고잔동 24시 출장열쇠 비밀번호

# 고잔동에서 번호 때문에 많이 묻는 것
? 관리사무소에서 번호를 알 수 있나요? | 아닙니다. 다만 사시는 분 확인은 도와줄 수 있어 미리 들러 두시면 좋습니다.
? 아이가 번호를 바꾼 것 같은데 원래 번호로 돌릴 수 있나요? | 문이 열린 뒤 안쪽에서 새로 등록하면 됩니다. 원하시면 예전 번호로 다시 정해도 됩니다.
? 입력이 막혔는데 얼마나 기다려야 하나요? | 제품마다 다릅니다. 몇 분 기다렸다가 다시 해 보시고, 계속 막히면 연락 주세요.
? 세입자인데 번호를 바꿔도 되나요? | 번호는 사시는 분이 바꿔 쓰셔도 됩니다. 도어락을 바꾸는 건 임대인과 먼저 이야기하세요.
? 못 열면 비용이 드나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.

# 고잔동 문 앞에서 기억할 것
세 번 틀렸으면 멈추고, 손이 기억하는 번호와 가족에게 연락하는 것부터 해 보세요. / 카드나 지문이 있다면 그것으로 먼저 들어가시면 됩니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 다닙니다. / 그래도 안 열리면 010-3664-5455로 연락 주세요.
