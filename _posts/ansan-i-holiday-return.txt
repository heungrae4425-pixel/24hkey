# 긴 연휴 끝, 문 앞에서 멈춘 발걸음
며칠 집을 비웠다가 짐 가방과 선물 꾸러미를 들고 돌아왔는데 현관문이 열리지 않으면 피로가 한꺼번에 몰려옵니다. / 상록구 이동은 주택과 아파트, 상가가 어우러진 동네라 명절이면 고향에 다녀오는 집도, 가족을 맞는 집도 있습니다.
연휴 뒤 문 잠김은 대부분 집을 비운 동안 생긴 작은 변화 때문입니다. / 배터리가 그사이 다 됐거나, 나갈 때 평소와 다르게 잠갔거나, 날씨가 바뀌어 문이 뻑뻑해진 경우입니다.
이 글은 이동에서 연휴나 여행 뒤 현관문이 안 열릴 때 짐을 내려놓고 차례로 해 볼 것을 적었습니다. / 해결이 안 되면 [안산 출장열쇠](ansan.html)로 연락 주세요.
@ 이동 명절 연휴 후 현관문 안 열림

# 짐부터 내려놓고 한숨 돌리기
양손에 짐을 든 채 번호를 누르다 보면 실수가 잦아지고 입력이 막히기 쉽습니다. / 짐은 문 옆에 가지런히 내려놓고, 아이가 있다면 한쪽에 앉혀 두세요.
엘리베이터 앞이나 계단에 짐을 오래 두면 이웃이 지나가기 불편할 수 있습니다. / 문 옆 벽 쪽으로 붙여 두시면 됩니다.
가족이 여럿이라면 한 사람은 문을 맡고, 다른 사람은 짐과 아이를 챙기는 식으로 역할을 나누세요. / 냉장 보관해야 하는 명절 음식이 있다면 기다리는 동안 차 안 그늘이나 이웃집에 잠시 맡겨 두는 것도 방법입니다. / 모두가 문 앞에 몰려 있으면 오히려 더 정신없어집니다.

# 집을 비운 동안 배터리가 다 됐을 때
도어락은 아무도 안 쓰는 동안에도 조금씩 전기를 씁니다. / 떠나기 전에 이미 배터리가 약했다면 며칠 사이 완전히 바닥날 수 있습니다.
번호판을 눌러도 불이 안 켜진다면 바깥쪽 비상 단자에 9V 건전지를 대 보세요. / 휴게소나 동네 편의점에서 미리 사 두셨다면 바로 쓰실 수 있습니다.
건전지를 댄 채로 번호를 끝까지 눌러야 열립니다. / 중간에 건전지가 떨어지면 처음부터 다시 해야 하니 한 손으로 단단히 잡고 하세요.
문이 열리면 짐을 들이기 전에 안쪽 배터리부터 모두 새것으로 바꿔 주세요. / 연휴 피로에 미뤘다가 다음 날 아침 출근길에 또 막히는 일이 생깁니다.

# 나갈 때 보조키를 잠갔다면
평소에는 번호키만 쓰다가 오래 집을 비운다고 보조키까지 잠그고 나가는 분이 많습니다. / 그런데 그 보조키 열쇠를 어디 뒀는지 기억나지 않는 경우가 생깁니다.
열쇠를 가방 안주머니나 차 안에 넣었는지 차분히 찾아보세요. / 고향 집이나 여행지 숙소에 두고 왔다면 가족에게 연락해 확인해 보시는 것도 방법입니다.
보조키 열쇠가 끝내 없다면 번호키는 열려도 문은 안 열립니다. / 이때는 보조키 쪽을 출장으로 열어야 합니다. / 보조키 모양을 사진으로 찍어 보내 주시면 맞는 장비를 챙겨 가서 시간을 아낄 수 있습니다.
@ 이동 현관 보조키 잠금 연휴 후

# 날씨가 바뀌어 문이 뻑뻑할 때
연휴 동안 비가 왔거나 기온이 크게 떨어졌다면 문짝과 문틀이 살짝 변해 걸쇠가 꽉 물릴 수 있습니다. / 번호는 맞고 모터 소리도 나는데 문이 안 열리는 경우가 이렇습니다.
문을 안쪽으로 살짝 밀면서 번호를 다시 누르거나 손잡이를 돌려 보세요. / 걸쇠에 걸린 힘이 빠지면서 열리는 경우가 있습니다.
집 안이 오래 닫혀 있어 습기가 찼다면 문을 연 뒤 환기부터 해 주세요. / 보일러를 끄고 나갔다면 집 안이 차가워 문 안쪽에 결로가 생기기도 합니다. / 도어락 안쪽 몸체에 물기가 보이면 마른 천으로 닦아 둡니다.

# 비밀번호가 헷갈린다면
며칠 안 쓰다 보면 매일 누르던 번호도 손에서 잊히는 일이 있습니다. / 특히 떠나기 직전에 번호를 바꿨다면 더 그렇습니다.
몇 번 틀리면 입력이 막히니 서너 번 해 보고 안 되면 멈추세요. / 함께 사는 가족에게 번호를 다시 확인하고, 카드키나 지문이 등록돼 있다면 그쪽으로 시도해 보세요. / 번호를 휴대폰 메모에 적어 두셨다면 그 메모부터 한 번 찾아보세요.

# 문 앞에 쌓인 택배와 우편물
연휴 동안 택배가 문 앞에 쌓여 있다면 문 여는 동안 한쪽으로 옮겨 두세요. / 상자가 문 앞을 막으면 문이 끝까지 안 열려 짐을 들이기 불편합니다.
쌓인 우편물 중에는 이 집 주소가 적힌 고지서가 있을 겁니다. / 신분증이 없거나 주소가 다를 때 사시는 곳을 확인하는 자료로 쓸 수 있으니 챙겨 두세요. / 며칠 집을 비운 사실을 이웃이 알고 있다면 그분의 확인도 도움이 됩니다.

# 이럴 땐 바로 연락 주세요
- 9V 건전지를 대도 번호판이 켜지지 않을 때
- 보조키 열쇠가 끝내 없을 때
- 번호는 맞는데 손잡이가 헛돌 때
- 아이나 어르신이 오래 기다리기 힘든 상황일 때
늦은 밤 도착했다면 시간을 신경 쓰지 말고 전화 주세요. / 연휴 끝 무렵에는 귀경길 차량이 몰려 도착이 평소보다 조금 늦어질 수 있어서, 위치를 받으면 대략 언제쯤 갈 수 있는지 먼저 말씀드립니다. 그동안 아이와 어르신은 차 안이나 따뜻한 곳에서 기다리시게 해 주세요. / 연휴 마지막 날 밤에도 출동합니다.

# 도착하면 이렇게 진행합니다
문을 열기 전에 사시는 분인지 확인합니다. / 신분증 주소, 문 앞 우편물이나 고지서, 관리사무소 확인 중 하나면 됩니다.
문 상태를 보고 금액을 먼저 말씀드린 뒤 동의하시면 시작합니다. / 끝내 열지 못하면 비용은 받지 않습니다. 진행 순서는 [이용안내](guide.html), 여는 방법은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 열고 나서 함께 확인할 것
배터리가 원인이었다면 새 배터리로 바꾼 뒤 안팎에서 여러 번 열고 닫아 봅니다. / 보조키를 열었다면 보조키 열쇠를 새로 할지, 아예 떼어 낼지 같이 정합니다.
도어락이 오래돼 반응이 느리다면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 봅니다. / 고쳐 쓰기 어려울 만큼 낡았다면 [도어락 교체](doorlock-replace.html)를 그때 말씀드립니다.
@ 안산 이동 도어락 배터리 교체 점검

# 다음 연휴 전 체크리스트
- 떠나기 하루 전 도어락 배터리를 새것으로 바꾸기
- 보조키를 잠근다면 열쇠는 지갑이나 휴대폰 케이스에 넣어 가기
- 9V 건전지 하나를 여행 가방에 넣어 두기
- 떠나기 직전에는 번호를 바꾸지 않기
- 택배는 연휴 동안 보관함이나 가족 집으로 받기
이 몇 가지만 챙겨도 돌아온 날 문 앞에서 막힐 일이 크게 줄어듭니다. / 체크리스트를 현관 거울 옆에 붙여 두면 떠날 때 잊지 않습니다. / 휴대폰 달력에 연휴 전날 알림을 하나 걸어 두는 것도 좋습니다.

# 이동 말고 안산 어디든
고잔동, 초지동, 선부동, 와동, 원곡동, 본오동, 사동, 월피동, 성포동까지 안산 전 지역을 다닙니다. / 대부동은 거리가 있어 도착 시간을 먼저 말씀드립니다. 서울, 경기 전 지역 24시간이며 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.
