# 이삿날 도어락은 늘 뒷전이 됩니다
이동은 상록구에 속한 동네로 주택과 아파트, 상가가 어우러져 있어 이사 들고 나는 집이 꾸준합니다. / 이삿날에는 짐과 잔금, 청소에 정신이 팔려 현관 도어락은 번호만 받고 넘어가기 쉽습니다.
그런데 도어락 문제는 꼭 이사하고 며칠 뒤에 드러나거나, 나갈 때 집주인과 이야기가 엇갈리면서 불거집니다. / 들어갈 때 한 번, 나갈 때 한 번만 챙겨 두면 피할 수 있는 일들입니다.
이 글은 이동에서 입주하는 날과 퇴거하는 날 도어락에서 볼 것을 나눠 적었습니다. / 점검하다 문제가 보이면 [안산 출장열쇠](ansan.html)를 부르시면 됩니다.
@ 이동 입주 퇴거 도어락 점검

# 입주하는 날 1. 문을 연 채로 작동 확인
짐이 들어오기 전, 문을 활짝 연 상태에서 도어락을 여러 번 잠갔다 열어 보세요. / 문을 연 채로 해야 혹시 이상이 있어도 밖에 갇히지 않습니다.
- 번호판이 바로 켜지고 버튼이 고르게 눌리는지
- 잠글 때 걸쇠가 끝까지 나오고, 열 때 끝까지 들어가는지
- 바깥 손잡이와 안쪽 손잡이가 헐겁지 않은지
- 안쪽 수동 레버나 잠금 버튼이 잘 움직이는지
이 가운데 하나라도 이상하다면 그 자리에서 집주인이나 부동산에 알리세요. / 살기 시작한 뒤에 말하면 언제부터 그랬는지 따지기 어려워집니다.
점검은 오 분이면 끝납니다. / 이삿짐 차가 도착하기 전 비어 있는 집에서 하면 문 앞이 붐비지 않아 훨씬 차분하게 볼 수 있습니다.

# 입주하는 날 2. 문을 닫고 한 번 더
문을 연 채로 괜찮았다면 이번에는 문을 닫고 바깥에서 번호로 열어 보세요. / 문틀과 걸쇠가 어긋나 있으면 닫은 상태에서만 걸리는 경우가 있습니다.
이때 문이 끝까지 부드럽게 닫히는지, 쾅 하고 세게 닫히지는 않는지도 함께 봅니다. / 문 위쪽 닫힘 장치가 너무 세거나 약하면 도어락에도 무리가 갑니다.
@ 이동 주택 현관 도어락 입주 점검

# 입주하는 날 3. 사진과 영상으로 남기기
점검이 끝나면 도어락 바깥과 안쪽, 문틀 쪽 걸쇠 자리를 사진으로 찍어 두세요. / 잠갔다 여는 모습을 짧은 영상으로 남겨 두면 나중에 상태를 설명할 때 가장 확실합니다.
찍은 날짜가 남도록 휴대폰 사진첩에 이사 날짜로 따로 앨범을 만들어 두시면 좋습니다. / 긁힌 자국이나 덮개가 깨진 부분도 이때 함께 찍어 두세요.

# 입주하는 날 4. 넘겨받은 것 세어 보기
번호 말고도 카드, 태그, 비상용 기계 열쇠, 보조키 열쇠를 몇 개 받았는지 세어 적어 두세요. / 나갈 때 돌려줘야 하는 것이라면 받은 개수가 기준이 됩니다.
그다음 전에 살던 분의 번호와 카드를 지우는 초기화를 하시면 됩니다. / 초기화 순서는 이사 후 재설정 글에 따로 정리해 두었고, 막히면 연락 주셔도 됩니다.

# 입주하는 날 5. 건전지와 비상 단자 위치
건전지 덮개를 열어 언제 갈았는지 알 수 없다면 새것으로 모두 바꿔 두세요. / 새집에서 첫 주에 번호판이 꺼지는 일은 대개 이렇게 생깁니다.
바깥쪽 9V 비상 단자가 어디 있는지도 이때 확인해 두면 좋습니다. / 이동 주택처럼 현관이 바깥과 바로 닿는 집이라면 단자 덮개가 잘 닫히는지도 봐 두세요.

# 직접 도어락을 달고 싶다면
들어가는 집 도어락이 마음에 들지 않아 새로 달고 싶다면 먼저 집주인과 이야기해 주세요. / 나갈 때 원래 제품으로 돌려놓을지, 새로 단 것을 두고 갈지 미리 정해 두면 뒷말이 없습니다.
떼어 낸 원래 도어락은 상자에 넣어 잘 보관해 두세요. / 돌려놓기로 했다면 나갈 때 그대로 다시 달 수 있어야 합니다.
나사와 작은 부품은 지퍼 봉투에 따로 담아 상자 안에 같이 넣어 두면 잃어버리지 않습니다. / 설명서나 처음 받은 카드가 있다면 그것도 함께 보관해 주세요.
@ 이동 아파트 도어락 교체 집주인 의논

# 공동현관과 우편함도 함께 보기
아파트나 다세대라면 집 현관 말고도 공동현관 카드, 우편함 열쇠처럼 따로 받는 것이 있습니다. / 입주하는 날 이것들도 받았는지, 제대로 되는지 함께 확인해 두세요.
공동현관 카드는 관리사무소에서 등록하는 경우가 많아 입주 신고를 하면서 물어보면 됩니다. / 우편함 열쇠가 없다면 그날 바로 집주인에게 말해 두는 것이 좋습니다.
나갈 때도 이 두 가지를 잊고 들고 가는 일이 흔합니다. / 현관 카드와 함께 한 봉투에 모아 두면 빠뜨리지 않습니다.

# 퇴거하는 날 1. 돌려줄 것 챙기기
입주할 때 적어 둔 개수대로 카드와 열쇠를 챙겨 집주인이나 부동산에 돌려 드리세요. / 잃어버린 것이 있다면 숨기지 말고 미리 말씀드리는 편이 낫습니다.
잃어버린 카드는 등록 목록에서 지워 두면 다음 사람이 쓰기에 안전합니다. / 지우는 방법을 모르겠다면 모델명을 알려 주세요.

# 퇴거하는 날 2. 번호를 어떻게 넘길지
나갈 때 쓰던 번호를 그대로 둘지, 집주인과 정한 번호로 바꿔 둘지, 초기화해 둘지는 집주인과 정하시면 됩니다. / 어떤 방법이든 우리 식구 번호와 지문이 그대로 남지 않게 정리하는 것이 기본입니다.
지문을 등록해 쓰셨다면 꼭 지워 주세요. / 번호는 바꾸면 그만이지만 지문은 내 몸의 일부라 남겨 두고 가기 찜찜합니다.

# 퇴거하는 날 3. 마지막 상태 기록
짐을 다 뺀 뒤 입주 때처럼 문을 연 채로 작동을 확인하고 사진과 영상을 남겨 두세요. / 들어올 때와 나갈 때 상태를 나란히 보여 줄 수 있으면 대화가 훨씬 쉬워집니다.
그동안 고장이 나서 고친 적이 있다면 그 사실도 함께 정리해 두세요. / 고친 날짜와 내용을 기억해 두면 설명하기 편합니다.
마지막으로 문을 닫고 나오기 전, 집 안에 두고 가는 카드나 열쇠가 없는지 서랍과 신발장을 한 번 훑어보세요. / 다음 사람이 그것을 주워 쓰게 되면 초기화를 해도 빈틈이 남습니다.

# 점검하다 문제가 보이면
입주 점검에서 걸쇠가 덜 나오거나 손잡이가 헐겁다면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 봅니다. / 너무 오래된 제품이라면 집주인과 의논한 뒤 [도어락 교체](doorlock-replace.html)를 함께 알아볼 수 있습니다.
이삿날 문이 잠겨 들어가지 못하는 상황이라면 계약서나 관리사무소 확인으로 사시는 분인지 먼저 보고 [현관문 개문](door-open.html)을 진행합니다. / 금액은 손대기 전에 먼저 말씀드리고, 끝내 열지 못하면 비용은 받지 않으며 전체 흐름은 [이용안내](guide.html)에 있습니다.

# 이동 말고 안산 어디든
이동과 가까운 사동, 본오동, 월피동, 성포동은 물론 고잔동, 초지동, 선부동, 와동, 원곡동까지 다닙니다. / 대부동은 거리가 있어 도착 시간을 먼저 말씀드리며, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
