# 사동 현관, 문이 열리다 말고 탁 멈췄다면
사동은 한대앞역 쪽 생활권에 아파트와 주택, 상가가 어우러진 안산 상록구의 동네입니다. / 가족이 함께 사는 집이 많아 밤이면 안쪽 걸쇠까지 걸어 두는 현관이 흔합니다.
번호를 누르니 도어락은 철컥 풀렸는데, 문이 손바닥 하나 들어갈 만큼만 열리고 탁 멈추는 일이 있습니다. / 안쪽에 건 걸쇠나 도어가드, 체인이 문을 붙잡고 있는 겁니다.
이 글은 사동에서 안쪽 걸쇠 때문에 문이 막혔을 때 집 안에 사람이 있는지에 따라 무엇을 해야 하는지, 걸쇠 종류별로 무엇을 확인하면 되는지 정리했습니다. / 혼자 풀기 어렵다면 [안산 출장열쇠](ansan.html)를 부르시면 됩니다.
@ 사동 현관문 안쪽 걸쇠 도어가드 막힘

# 첫 번째 질문은 "집 안에 누가 있나"입니다
안쪽 걸쇠는 집 안에서만 걸 수 있는 잠금입니다. / 그래서 걸쇠가 걸려 있다는 건 대부분 지금 집 안에 누군가 있다는 뜻입니다.
가족이 먼저 들어와 습관처럼 걸쇠를 걸고 잠들었거나, 샤워 중이라 못 듣는 경우가 가장 흔합니다. / 문틈으로 이름을 부르고, 휴대폰으로 여러 번 전화를 걸어 보세요.
이웃집에 같은 가족 번호를 아는 분이 있다면 대신 전화를 걸어 달라고 부탁하는 방법도 있습니다. / 초인종을 몇 번 누르는 것도 좋습니다. / 깊이 잠든 가족도 초인종 소리에는 잘 깨는 편입니다.

# 불러도 대답이 없다면
집 안에 사람이 있을 텐데 아무리 불러도 대답이 없다면 걱정이 앞섭니다. / 특히 어르신이나 몸이 불편한 가족이 혼자 계셨다면 더 그렇습니다.
문틈으로 집 안에 불이 켜져 있는지, TV 소리나 인기척이 있는지 살펴보세요. / 쓰러지신 건 아닌지 걱정되는 상황이라면 출장보다 119에 먼저 연락하시는 게 맞습니다.
119가 오는 동안에도 저희에게 함께 연락 주셔도 됩니다. / 상황을 들으면 가능한 빨리 움직입니다.

# 집에 아무도 없는데 걸쇠가 걸렸다면
드물지만 집이 비어 있는데 걸쇠가 걸리는 경우도 있습니다. / 문을 세게 닫을 때 도어가드가 저절로 넘어가 걸쇠 자리에 걸린 겁니다.
특히 U자 모양 도어가드는 문을 활짝 열어 벽에 부딪히거나 쾅 닫히는 충격에 접혀 들어가기 쉽습니다. / 외출하면서 문을 세게 닫은 기억이 있다면 이 경우일 가능성이 큽니다. / 바람이 센 날 창문을 열어 둔 채 나가면 맞바람에 문이 쾅 닫히며 이런 일이 생기기도 합니다.
이때는 집 안에 사람이 없으니 서두르지 않으셔도 됩니다. / 다만 혼자 풀려고 문틈에 손이나 도구를 넣으면 다칠 수 있으니 조심하세요.

# 걸쇠 모양에 따라 다릅니다
문틈으로 보이는 걸쇠 모양을 확인해 보세요. / 모양에 따라 바깥에서 풀 수 있는 방법이 다릅니다.
- U자나 막대 모양으로 접혀 걸리는 도어가드
- 쇠사슬로 연결된 체인 걸쇠
- 문 위쪽이나 옆에 따로 단 밀어 거는 걸쇠
- 손으로 돌려 거는 안쪽 보조 잠금 꼭지
휴대폰 손전등으로 문틈을 비춰 사진을 한 장 찍어 보내 주시면 맞는 방법을 미리 정할 수 있습니다. / 문을 억지로 더 밀어 틈을 벌리지는 마세요.
@ 사동 현관 걸쇠 종류 문틈 사진

# 문틈으로 손을 넣지 마세요
틈이 보이니 손을 넣어 걸쇠를 풀어 보려는 분이 많습니다. / 그런데 손이 끼인 상태에서 문이 닫히면 크게 다칠 수 있습니다.
옷걸이나 긴 막대를 넣어 걸쇠를 밀어 보는 것도 권하지 않습니다. / 걸쇠가 더 단단히 걸리거나 문틀 칠이 벗겨지는 경우가 많고, 도어가드 받침이 휘기도 합니다.
아이에게 틈으로 손을 넣어 풀어 달라고 하는 것도 피해 주세요. / 아이 손이 끼일 위험이 어른보다 큽니다.

# 문을 한 번 닫았다가 다시 열기
걸쇠가 걸린 채로 문을 계속 당기고 있으면 걸쇠가 팽팽해져 안에서도 풀기 어려워집니다. / 집 안 사람이 풀어 주려 할 때는 문을 먼저 끝까지 닫아 주세요.
문이 닫혀야 걸쇠에 걸린 힘이 빠져 안쪽에서 쉽게 젖힐 수 있습니다. / 이걸 모르고 서로 밀고 당기느라 시간이 걸리는 경우가 의외로 많습니다.
문을 닫으면 도어락이 다시 잠길 수 있으니, 걸쇠가 풀린 뒤에 번호를 다시 누르시면 됩니다. / 집 안 사람이 걸쇠를 젖혔다고 말해 주면 그때 바깥에서 번호를 누르는 식으로 순서를 맞추세요.

# 아이가 안에서 걸쇠를 걸었다면
집 안에 아이만 있고 아이가 걸쇠를 건 경우라면 아이에게 천천히 풀어 달라고 말해 보세요. / "문 위에 걸린 쇠를 옆으로 밀어 봐"처럼 아이가 알아듣기 쉬운 말로 하시면 됩니다.
아이 키가 닿지 않거나 무서워한다면 억지로 시키지 마세요. / 이런 상황은 통화 첫마디에 말씀해 주시면 먼저 움직입니다.

# 출장을 부를 때 알려 주실 것
- 집 안에 사람이 있는지, 대답이 있는지
- 걸쇠 모양 (도어가드, 체인, 밀어 거는 걸쇠)
- 아파트인지 주택인지, 동과 호수
- 도어락은 풀린 상태인지
문틈 사진을 보내 주시면 준비가 훨씬 정확해집니다. / 안에 어르신이나 아이가 계신다면 꼭 먼저 말씀해 주세요.

# 확인과 금액 안내
도착하면 신분증 주소, 주소가 적힌 우편물, 관리사무소 세대 확인 중 하나로 사시는 분인지 확인합니다. / 집 안에 가족이 있다면 문이 열린 뒤 가족과도 직접 확인합니다.
걸쇠 종류와 문 상태를 본 뒤 작업 전에 금액을 먼저 말씀드립니다. / 동의하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html)에, 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 걸쇠가 상했다면 이렇게 정리합니다
걸쇠를 풀다 휘거나 받침이 헐거워졌다면 그대로 쓰지 말고 바꾸시는 게 좋습니다. / 휜 도어가드는 다음에 또 저절로 넘어가 같은 일이 생길 수 있습니다.
걸쇠만 바꾸는 작업은 간단하게 끝나는 편입니다. / 문틀 쪽 받침 나사 구멍이 넓어졌다면 자리를 살짝 옮겨 단단히 박아 드립니다. / 도어락까지 함께 보고 싶으시면 [도어락 수리](doorlock-repair.html)를 함께 상의하세요.
@ 사동 현관 도어가드 걸쇠 교체

# 같은 일이 다시 없게 하는 습관
- 가족 중 마지막에 들어오는 사람이 걸쇠를 걸기로 정하기
- 늦게 들어올 가족이 있으면 걸쇠는 걸지 않기
- 문을 세게 닫지 않기 (도어가드가 접혀 들어감)
- 도어가드가 헐거우면 미리 바꾸기
걸쇠는 마음을 놓이게 하는 장치지만, 가족끼리 약속이 없으면 문 앞에서 기다리게 만드는 장치가 되기도 합니다. / 현관 방범이 걱정된다면 [도어락 교체](doorlock-replace.html) 때 함께 상의하셔도 됩니다.
@ 사동 가족 걸쇠 습관 현관 관리

# 사동 말고 안산 어디든
고잔동, 초지동, 선부동, 와동, 원곡동, 본오동, 이동, 월피동, 성포동까지 다니고, 대부동은 도착 시간을 미리 말씀드립니다. / 다른 지역은 [출장 지역](area.html)에서 보세요.

# 사동에서 걸쇠에 막혔을 때
집 안에 누가 있는지부터 확인하고, 있다면 문을 닫은 뒤 안에서 풀어 달라고 하세요. / 아무도 없거나 대답이 없으면 억지로 손대지 말고 연락 주시면 됩니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 다닙니다. / 걸쇠에 막힌 문 앞이라면 010-3664-5455로 연락 주세요.
