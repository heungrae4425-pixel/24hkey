# 안 열린다는 말 안에 여러 사정이 있습니다
사동은 상록구에 속한 동네로 한대앞역 생활권을 따라 아파트와 주택, 상가가 이어집니다. / 문이 안 열린다는 연락은 늘 똑같이 들리지만, 실제로 문 앞에 가 보면 원인은 집마다 제각각입니다.
번호판이 아예 꺼진 집, 띠리릭 소리는 나는데 꿈쩍 않는 집, 손잡이만 빙빙 도는 집이 모두 다른 이유로 막혀 있습니다. / 원인을 먼저 좁혀 두면 혼자 해결할 수 있는 경우도 있고, 전화로 상황을 설명하기도 훨씬 쉬워집니다.
이 글은 사동 현관에서 흔히 보는 증상을 하나씩 나눠 원인과 해 볼 것을 적었습니다. / 지금 문 앞이라면 내 증상에 맞는 부분부터 보시고, 막히면 [안산 출장열쇠](ansan.html)로 연락 주세요.
@ 사동 현관문 안 열림 증상별 확인

# 증상 하나, 번호판에 불이 안 들어온다
번호판을 손으로 덮거나 눌러도 아무 반응이 없다면 배터리가 다 됐을 가능성이 가장 큽니다. / 며칠 전부터 경고음이 났는데 미뤘다면 거의 확실합니다.
바깥쪽 아래나 옆면에 작은 단자 두 개가 있는지 찾아보세요. / 9V 건전지를 단자에 맞대고 있으면 잠시 전원이 들어와 번호를 누를 수 있습니다.
단자가 없는 제품이거나 건전지를 대도 반응이 없다면 다른 고장일 수 있습니다. / 이때는 더 시도하지 말고 연락 주세요. / 문이 열리면 안쪽 배터리를 모두 새것으로 바꿔야 같은 일이 며칠 뒤 되풀이되지 않습니다.

# 증상 둘, 소리는 나는데 걸쇠가 안 빠진다
번호를 누르면 맞았다는 소리와 함께 모터가 도는 소리가 나는데 문은 그대로인 경우입니다. / 모터는 움직였지만 걸쇠가 문틀에 꽉 눌려 있거나 안쪽 부품이 헛돌고 있는 상태입니다.
이럴 때는 문을 안쪽으로 살짝 밀거나 바깥쪽으로 당기면서 번호를 다시 눌러 보세요. / 걸쇠에 걸린 힘이 빠지면서 열리는 경우가 꽤 있습니다.
여러 번 해도 같은 소리만 난다면 모터나 기어 쪽 고장일 수 있습니다. / 배터리가 약해 모터 힘이 모자란 경우도 있어 9V 건전지를 대고 한 번 더 해 보셔도 됩니다.
@ 사동 도어락 모터 소리 걸쇠 확인

# 증상 셋, 경고음이 길게 울리고 입력이 막힌다
번호를 여러 번 틀리면 도어락이 일정 시간 입력을 막고 경고음을 냅니다. / 이 시간 동안은 맞는 번호를 눌러도 열리지 않습니다.
경고음이 멈출 때까지 기다린 뒤 천천히 다시 눌러 보세요. / 급하게 연달아 누르면 막히는 시간이 더 길어질 수 있습니다.
가족이 최근 번호를 바꿨을 수도 있으니 연락해 확인해 보세요. / 카드키나 지문이 등록돼 있다면 번호 대신 그쪽으로 열어 보는 것도 방법입니다. / 그래도 번호가 맞는지 확신이 안 서면 서너 번 이상은 누르지 않는 게 좋습니다.

# 증상 넷, 손잡이가 헛돈다
손잡이를 돌리거나 눌러도 아무 저항 없이 움직이기만 한다면 손잡이와 걸쇠 사이 연결이 빠졌거나 부러진 것입니다. / 번호가 맞아도, 배터리가 새것이어도 이 상태에서는 문이 안 열립니다.
손잡이를 세게 비틀면 남은 연결까지 망가질 수 있습니다. / 안쪽 손잡이는 멀쩡하고 바깥쪽만 헛도는 경우도 있으니, 집 안에 사람이 있다면 안에서 열어 달라고 해 보세요. 한쪽만 헛돈다는 건 전화로 꼭 알려 주시면 원인 짐작에 도움이 됩니다. / 한두 번 시도해 보고 안 되면 그대로 두고 연락 주세요.

# 증상 다섯, 열쇠가 안 돌아간다
보조키나 기계식 자물쇠라면 열쇠를 꽂았는데 돌아가지 않는 경우가 있습니다. / 열쇠 끝이 닳았거나 열쇠 구멍 안에 먼지가 쌓였거나, 겨울이라면 안쪽이 얼었을 수도 있습니다.
열쇠를 끝까지 넣었다가 아주 살짝 빼서 돌려 보세요. / 힘을 주기보다 위치를 맞추는 게 중요합니다.
세게 돌리다 열쇠가 부러지면 구멍 안에 조각이 남아 일이 더 커집니다. / 기름이나 식용유를 넣는 것도 먼지를 엉기게 해 오히려 상태를 나쁘게 만듭니다.

# 증상 여섯, 안에서 걸쇠가 걸려 있다
문이 손가락 몇 개 들어갈 만큼만 열리고 더 안 열린다면 안쪽 걸쇠나 체인이 걸린 상태입니다. / 집 안에 가족이 있다면 풀어 달라고 하면 되지만, 아무도 없는데 걸려 있다면 사정이 다릅니다.
나가면서 걸쇠가 저절로 걸리는 구조는 드물어서 누가 안에 있는지 먼저 확인해 보세요. / 아무도 없는 게 확실하다면 문틈으로 억지로 풀려 하지 말고 연락 주시는 게 낫습니다.

# 증상 일곱, 문이 문틀에 끼어 꿈쩍 않는다
도어락은 다 풀린 것 같은데 문이 무겁게 안 열린다면 문틀이 처지거나 문짝이 틀어져 끼인 경우입니다. / 오래된 문, 여름철 습기, 겨울철 수축으로 생기기도 합니다.
손잡이를 돌린 상태로 문 위쪽이나 아래쪽 중 걸리는 곳을 살짝 밀어 보세요. / 힘을 한곳에 모아 세게 차거나 밀면 문틀이 상하니 조금씩 해 보는 게 좋습니다. / 이런 문은 열고 난 뒤에도 닫을 때마다 끼이기 쉬워 경첩 높이를 다시 맞춰야 할 수 있습니다.

# 전화하실 때 증상 번호로 말씀해 주세요
위 증상 중 어디에 해당하는지 말씀해 주시면 필요한 장비를 챙겨 갈 수 있습니다. / 사동 어느 쪽인지, 아파트라면 동과 호수, 주택이라면 건물 이름이나 큰길 기준 위치를 함께 알려 주세요.
집 안에 아이나 반려동물이 있다면 그것도 먼저 말씀해 주세요. / 상황에 따라 서둘러 갑니다. / 어느 증상인지 확실하지 않다면 보이는 그대로, 들리는 소리 그대로 말씀해 주셔도 충분합니다.

# 도착 후 진행
문을 열기 전에 사시는 분인지 신분증 주소, 이 집 주소가 나온 우편물, 관리사무소 확인으로 먼저 봅니다. / 그다음 증상과 문 상태를 보고 금액을 먼저 말씀드리며, 동의하실 때만 시작합니다.
덜 상하는 방법부터 차례로 시도하고, 끝내 열지 못하면 비용은 받지 않습니다. / 자세한 진행은 [현관문 개문](door-open.html)과 [이용안내](guide.html)에 있습니다.

# 열린 뒤 원인에 맞게 손보기
배터리 문제였다면 전부 새것으로 바꾸고, 걸쇠나 모터 문제였다면 부품을 점검합니다. / 고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 마무리하고, 너무 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문틀이 처진 경우라면 도어락보다 경첩 조정이 먼저입니다. / 원인을 그대로 두면 같은 일이 금방 되풀이됩니다. / 어떤 증상이었는지 메모해 두시면 다음에 비슷한 일이 생겼을 때 판단이 빨라집니다.
@ 안산 사동 도어락 걸쇠 수리 점검

# 사동 말고 안산 어디든
고잔동, 초지동, 선부동, 와동, 원곡동, 본오동, 이동, 월피동, 성포동까지 안산 전 지역을 다닙니다. / 대부동은 거리가 있어 도착 시간을 먼저 말씀드립니다. 서울, 경기 전 지역 24시간이며 다른 곳은 [출장 지역](area.html)에서 보세요.

? 경고음이 계속 울려요. | 번호를 여러 번 틀려 입력이 막힌 상태일 수 있습니다. 멈출 때까지 기다린 뒤 천천히 다시 눌러 보세요.

? 못 열면 비용이 나오나요? | 아닙니다. 끝내 못 열면 받지 않습니다.
