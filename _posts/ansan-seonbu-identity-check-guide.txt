# 선부동 문 앞에서 신분증 보여 달라는 말에 당황하셨다면
선부동은 초지동, 와동과 이웃한 안산의 주거 동네로 아파트와 빌라, 다세대가 이어져 있습니다. / 문이 안 열려 급하게 출장열쇠를 불렀는데 도착하자마자 신분증을 보여 달라는 말을 들으면 조금 서운하게 느껴질 수도 있습니다.
하지만 이 확인 절차는 사시는 분을 의심해서가 아니라 사시는 분을 지키기 위한 것입니다. / 확인 없이 문을 열어 주는 곳이라면 남이 우리 집 문을 열어 달라고 해도 똑같이 열어 줄 수 있기 때문입니다.
이 글은 선부동에서 출장열쇠를 부르셨을 때 거치는 신분 확인이 어떤 순서로 이뤄지는지, 상황별로 무엇을 준비하면 되는지 적었습니다. / 지금 문 앞이시라면 [안산 출장열쇠](ansan.html)로 먼저 연락 주세요.
@ 선부동 출장열쇠 문 열기 전 신분 확인

# 확인하는 것은 딱 하나입니다
신분 확인에서 보는 것은 한 가지입니다. / 지금 열어 달라는 문이 이분이 사시는 집, 이분이 쓰시는 공간이 맞느냐는 것입니다.
그래서 이름보다 주소가 중요합니다. / 신분증 사진과 얼굴이 같은지, 주소가 지금 문 앞 주소와 같은지를 함께 봅니다.
확인한 내용은 그 자리에서 보는 것으로 끝납니다. / 신분증을 따로 찍어 가거나 보관하지 않으니 걱정하지 않으셔도 됩니다.

# 가장 간단한 방법: 주소가 나온 신분증
지갑에 신분증이 있다면 가장 빠르게 끝납니다. / 주민등록증이나 운전면허증처럼 주소가 적힌 신분증이면 됩니다.
주소를 옮긴 지 얼마 안 돼 신분증 주소가 예전 집이라면 다른 서류를 함께 보여 주세요. / 주소 이전 확인이 되는 서류나 임대차 계약서, 이 집 주소로 온 우편물이 도움이 됩니다.
모바일 신분증을 쓰신다면 휴대폰 화면으로 보여 주셔도 됩니다. / 다만 휴대폰도 집 안에 있다면 아래 방법으로 넘어가면 됩니다.

# 신분증이 집 안에 있다면
가장 흔한 경우가 신분증이 지갑째 집 안에 있는 경우입니다. / 이때는 아래 방법 가운데 하나로 확인합니다.
- 아파트라면 관리사무소나 경비실의 세대 확인
- 빌라라면 건물주나 관리인과의 통화 확인
- 같이 사는 가족이 밖에 있다면 가족의 신분증
- 문을 연 직후 집 안에 있는 신분증이나 우편물 확인
마지막 방법은 문을 연 뒤 바로 안으로 들어가 신분증을 가져와 보여 주시는 방식입니다. / 이때는 작업자가 현관 앞에서 기다리며 확인이 끝날 때까지 자리를 뜨지 않습니다.

# 세입자라면 집주인 허락이 필요할까
세입자분들이 자주 묻는 질문입니다. / 문을 여는 일은 그 집에 사시는 분인지만 확인되면 집주인 허락 없이도 진행할 수 있습니다.
다만 도어락을 바꾸거나 문에 구멍을 새로 내는 일처럼 집에 변화가 생기는 작업은 이야기가 다릅니다. / 이런 작업은 집주인과 미리 상의하시는 것이 순서입니다.
임대차 계약서가 휴대폰에 사진으로 있다면 그것도 확인에 도움이 됩니다. / 계약서 주소와 문 앞 주소가 같은지 봅니다.
@ 선부동 빌라 세입자 임대차 계약서 확인

# 가족이 대신 부르는 경우
부모님 댁이나 자녀 집 문을 대신 열어 달라고 연락하시는 경우도 있습니다. / 이때도 그 집에 사시는 분의 확인이 필요합니다.
사시는 분과 통화가 되면 통화로 확인하고, 문을 연 뒤 집 안 신분증을 함께 봅니다. / 사시는 분과 연락이 전혀 안 된다면 관리사무소 확인이 꼭 필요합니다.
연락이 안 되는 이유가 걱정되는 상황이라면 문보다 119나 112에 먼저 연락하시는 것이 맞습니다. / 사람의 안전이 걸린 일은 그쪽이 훨씬 빠르게 움직입니다.

# 같이 사는 사람의 방은 따로 확인합니다
친구나 동료와 같이 사는 집에서 다른 사람 방을 열어 달라는 요청은 받지 않습니다. / 같은 집에 산다는 것만으로는 그 방을 쓰는 분이 맞는지 알 수 없기 때문입니다.
그 방을 쓰는 분이 직접 연락하시거나 통화로 동의하셔야 합니다. / 서로 불편한 일이 생기지 않도록 하는 기본 원칙입니다.
헤어진 연인이나 다툰 가족의 집 문을 열어 달라는 요청도 같은 이유로 받지 않습니다. / 지금 그 집에 사는 분의 동의가 없으면 어떤 사정이 있어도 문을 열지 않습니다.

# 상가와 사무실 문이라면
상가나 사무실 출입문은 주소 대신 그 공간을 쓰는 분인지 확인합니다. / 사업자등록증이나 임대차 계약서, 건물 관리인 확인이 필요합니다.
직원이 대신 부르는 경우라면 대표나 관리 책임자와의 통화로 확인합니다. / 서류가 안에 있다면 문을 연 직후 확인하는 방법도 있습니다.

# 외국인 거주자도 똑같이 진행합니다
안산 곳곳에는 외국인 이웃도 함께 살고 있습니다. / 외국인 거주자분도 거주 확인만 되면 똑같은 절차로 진행합니다.
외국인 등록증이나 이 집 주소로 온 우편물, 임대차 계약서 가운데 하나를 준비해 주세요. / 말이 잘 통하지 않으면 같은 건물 이웃이나 지인에게 통화를 부탁하셔도 됩니다.

# 확인이 안 되면 어떻게 되나요
어떤 방법으로도 사시는 분인지 확인되지 않으면 문을 열 수 없습니다. / 야박하게 느껴지실 수 있지만 이 원칙이 있어야 다른 집도 지켜집니다.
이 경우 출장 비용은 받지 않습니다. / 확인할 방법이 생기면 그때 다시 연락 주시면 됩니다.
실제로는 확인이 끝내 안 되는 경우가 드뭅니다. / 통화 한 통, 서랍 속 우편물 한 장으로도 대부분 해결되니 처음부터 포기하지 마시고 상황을 말씀해 주세요.

# 미리 준비해 두면 좋은 것
급한 순간이 오기 전에 몇 가지를 해 두면 확인이 훨씬 빨라집니다. / 큰 준비는 아니고 휴대폰 안에 넣어 두면 되는 것들입니다.
- 임대차 계약서나 분양 계약서를 휴대폰에 사진으로 저장
- 관리사무소나 건물주 연락처를 휴대폰에 저장
- 주소가 바뀌었다면 신분증 주소 이전 미리 해 두기
- 가족 중 한 명은 집 주소가 나온 서류를 갖고 있기
@ 선부동 아파트 관리사무소 세대 확인

# 확인 뒤의 진행과 비용
확인이 끝나면 문과 도어락 상태를 보고 비용을 먼저 말씀드립니다. / 들어 보시고 괜찮을 때만 작업을 시작합니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에, 문 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.
연 뒤 도어락에 손볼 곳이 있다면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 꼭 필요할 때만 [도어락 교체](doorlock-replace.html)를 권해 드립니다.

# 선부동 말고 안산 어디든 갑니다
선부동 가까운 초지동, 와동, 원곡동부터 고잔동, 본오동, 사동, 이동, 월피동, 성포동까지 다닙니다. / 대부동은 거리가 있어 도착 시간을 미리 말씀드립니다.
다니는 지역은 [안산시 출장열쇠](ansan.html)와 [출장 지역](area.html)에서 보실 수 있습니다.

? 지갑이 통째로 집 안에 있어요. | 관리사무소 세대 확인이나 문을 연 직후 집 안 신분증 확인으로 진행할 수 있습니다.
