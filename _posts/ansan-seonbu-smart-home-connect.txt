# 선부동 집 도어락, 앱에서만 조용해졌다면
선부동은 안산 단원구에서 아파트와 빌라, 다세대가 이어진 주거 동네입니다. / 맞벌이 가정이나 아이가 먼저 하교하는 집이 많아, 휴대폰으로 현관 출입 알림을 받는 도어락을 쓰는 집도 늘었습니다.
그런데 어느 날부터 아이가 들어왔는데도 알림이 안 오고, 앱에서 원격 열기를 눌러도 반응이 없습니다. / 문은 번호로 잘 열리는데 앱만 조용한 상태입니다.
이 글은 선부동에서 도어락 앱 연동이 끊겼을 때 집에서 차례로 확인할 순서를 정리했습니다. / 앱 문제로 문이 아예 안 열린다면 [안산 출장열쇠](ansan.html)를 부르시면 됩니다.
@ 선부동 도어락 앱 알림 연동 끊김

# 끊긴 날 무엇이 바뀌었는지부터
연동이 갑자기 끊겼다면 그 무렵 집이나 휴대폰에 바뀐 게 있는 경우가 대부분입니다. / 아래 중 해당하는 게 있는지 떠올려 보세요.
- 인터넷 공유기를 바꿨거나 와이파이 비밀번호를 바꿨다
- 휴대폰을 새로 바꿨거나 앱을 지웠다 다시 깔았다
- 휴대폰 운영체제를 업데이트했다
- 도어락 배터리를 갈았거나 경고음이 났었다
- 가족 중 누가 앱 설정을 만졌다
바뀐 게 하나라도 있다면 그 부분부터 보시면 됩니다. / 아무것도 바뀐 게 없다면 배터리와 신호 세기를 먼저 의심해 보세요.

# 공유기를 바꿨다면 다시 등록해야 합니다
도어락은 처음 연결할 때의 와이파이 이름과 비밀번호를 기억합니다. / 공유기를 바꾸거나 비밀번호를 바꾸면 도어락은 예전 네트워크를 찾다가 연결을 놓칩니다.
이 경우는 앱에서 기기를 새 와이파이에 다시 연결하는 과정을 거쳐야 합니다. / 메뉴 이름은 제품마다 다르지만 기기 설정이나 네트워크 설정 쪽에 있는 경우가 많습니다.
공유기 이름과 비밀번호를 예전과 똑같이 맞춰 두면 다시 등록하지 않아도 되는 경우도 있습니다. / 인터넷 설치 기사에게 미리 부탁해 두시면 편합니다.

# 현관까지 신호가 닿는지 보세요
공유기가 거실 안쪽이나 방에 있으면 현관까지 신호가 약하게 닿는 집이 있습니다. / 선부동 빌라나 다세대처럼 벽이 두꺼운 집은 더 그렇습니다.
현관 앞에서 휴대폰 와이파이 표시가 한두 칸이라면 도어락도 같은 상황일 수 있습니다. / 공유기를 현관 쪽으로 옮기거나 신호를 넓혀 주는 장치를 다는 것을 생각해 보세요.
따로 연결 장치(허브)를 쓰는 도어락이라면 그 장치가 현관 가까이 콘센트에 꽂혀 있는지, 전원이 켜져 있는지도 확인하세요. / 청소하다 플러그가 빠져 있는 경우가 의외로 많습니다.
@ 선부동 현관 도어락 와이파이 신호 허브 위치

# 휴대폰을 바꿨다면 권한부터
새 휴대폰에 앱을 깔고 로그인만 하면 다 될 것 같지만, 알림과 백그라운드 권한이 꺼져 있는 경우가 많습니다. / 휴대폰 설정에서 앱 알림이 켜져 있는지, 절전 모드에서 앱이 제한되지 않는지 확인하세요.
예전 휴대폰이 기기 관리자로 등록돼 있었다면 새 휴대폰을 관리자로 다시 지정해야 할 수 있습니다. / 예전 휴대폰을 초기화하기 전에 이 부분을 먼저 정리해 두시면 좋습니다.

# 가족 공유가 풀렸을 때
관리자 계정을 가진 가족이 앱을 지웠거나 계정을 바꾸면 다른 가족의 공유가 함께 풀리기도 합니다. / 관리자가 누구였는지 먼저 확인하고, 그분 휴대폰에서 다시 공유를 보내 주세요.
아이 휴대폰에 알림만 받게 해 두었다면 권한이 제대로 남아 있는지도 함께 보세요. / 공유 목록에 이사 간 가족이나 예전 가사도우미 계정이 남아 있다면 이참에 지워 두는 것이 좋습니다.

# 도어락 배터리가 약하면 통신이 먼저 끊깁니다
배터리가 약해지면 도어락은 문을 여닫는 데 남은 힘을 먼저 씁니다. / 그래서 번호로는 잘 열리는데 앱 연결부터 끊기는 일이 생깁니다.
배터리 경고음이 났었거나 교체한 지 오래됐다면 모두 새것으로 바꾸고 앱을 다시 열어 보세요. / 의외로 이것만으로 연결이 돌아오는 집이 많습니다.
배터리를 바꾼 뒤에도 연결이 안 되면 도어락 쪽 통신 부품을 점검해 볼 필요가 있습니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)로 상태를 보는 게 순서입니다.
@ 선부동 스마트 도어락 배터리 교체 연결 복구

# 앱만 믿고 다른 방법을 없애지 마세요
원격 열기가 편해서 번호를 잊어버리거나 카드를 서랍에 넣어 두는 분이 있습니다. / 그러다 휴대폰 배터리가 꺼지거나 인터넷이 끊기면 문 앞에서 아무것도 할 수 없게 됩니다.
번호와 카드 중 하나는 꼭 살려 두세요. / 아이에게도 앱 대신 쓸 수 있는 번호를 하나 알려 두시는 게 안전합니다.

# 초기화 버튼은 마지막에
- 연결이 안 된다고 도어락 초기화 버튼을 바로 누르기
- 바깥 번호판을 열어 통신 부품을 만지기
- 정체를 모르는 앱이나 설정 방법을 따라 하기
- 여러 가족이 동시에 설정을 바꾸기
초기화를 하면 등록된 번호, 카드, 지문이 함께 지워지는 제품이 많습니다. / 초기화는 집 안에 있을 때, 다른 방법이 다 안 될 때 마지막으로 하세요.

# 제조사에 물을 것과 출장으로 볼 것
앱 로그인, 계정, 서버 접속 문제는 제조사 고객센터에서 확인하는 게 빠릅니다. / 앱 안 공지에 서버 점검 안내가 떠 있는지도 한 번 보세요.
도어락 본체나 배터리 칸, 통신 부품, 문 상태 문제는 출장으로 직접 보는 게 맞습니다. / 앱 문제로 문이 안 열려 들어가지 못하는 상황이라면 그때는 바로 연락 주세요.

# 되는 것과 안 되는 것을 나눠 말씀해 주세요
번호, 카드, 앱 중 어느 것이 되고 어느 것이 안 되는지 말씀해 주세요. / 공유기나 휴대폰을 바꿨는지, 배터리를 언제 갈았는지도 알려 주시면 됩니다.
도착하면 신분증 주소, 주소가 적힌 우편물, 관리사무소 세대 확인 중 하나로 사시는 분인지 확인합니다. / 상태를 본 뒤 작업 전에 금액을 먼저 말씀드리고, 문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html)에, 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 연동이 잦게 끊긴다면 바꿀 때일 수도
같은 문제가 계속되고 부품도 더 이상 나오지 않는다면 [도어락 교체](doorlock-replace.html)를 생각해 볼 수 있습니다. / 바꾸게 되면 집 와이파이 환경과 가족 구성에 맞는 제품을 함께 고릅니다.
꼭 앱 기능이 필요한지도 다시 따져 보세요. / 알림만 필요하다면 더 단순한 방식이 오히려 편할 수 있습니다.
@ 선부동 스마트 도어락 교체 상담

# 선부동 말고 안산 다른 동네도
고잔동, 초지동, 와동, 원곡동, 본오동, 사동, 이동, 월피동, 성포동까지 다니고, 대부동은 도착 시간을 미리 말씀드립니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 도어락 앱 연동, 선부동에서 들은 질문
? 공유기를 바꿨더니 알림이 안 와요. | 도어락을 새 와이파이에 다시 연결해야 합니다. 앱의 기기 설정에서 네트워크를 다시 잡아 주세요.
? 번호로는 열리는데 앱만 안 돼요. | 배터리가 약하면 통신이 먼저 끊깁니다. 배터리를 모두 바꿔 보시고, 그래도 안 되면 점검을 받으세요.
? 새 휴대폰에서 알림이 안 와요. | 휴대폰 설정에서 앱 알림과 절전 예외를 켜 주시고, 관리자 계정도 다시 확인하세요.
? 초기화하면 해결되나요? | 등록된 번호와 카드까지 지워질 수 있어 마지막 방법으로 남겨 두세요.
? 앱 때문에 문이 안 열려 불렀는데 못 열면요? | 끝내 못 열면 비용은 받지 않습니다.

# 선부동 도어락 연동 정리
바뀐 것부터 떠올리고, 공유기, 휴대폰 권한, 배터리 순서로 확인해 보세요. / 번호와 카드는 앱과 별개로 꼭 살려 두시면 됩니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 다닙니다. / 앱 문제로 문 앞에서 막혔다면 010-3664-5455로 연락 주세요.
