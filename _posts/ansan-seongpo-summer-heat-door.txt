# 봄에는 멀쩡하던 문이 여름만 되면
성포동은 상록구에 속한 동네로 아파트 단지와 주택이 이어져 있고, 한 번 입주하면 오래 사는 분들이 많습니다. / 오래 산 집일수록 계절 따라 문 상태가 달라지는 걸 몸으로 느끼게 됩니다.
여름이 되면 현관문이 끝까지 안 닫히거나, 닫혀도 도어락 걸쇠가 덜 들어가 잠금이 한 번에 안 되는 집이 있습니다. / 날이 선선해지면 다시 괜찮아져서 그냥 넘기다가 이듬해 여름에 또 같은 일을 겪습니다.
지금은 날이 식었어도 내년 여름이 오기 전에 원인을 알아 두면 손보기가 훨씬 쉽습니다. / 이 글은 더위와 습기가 문에 어떤 영향을 주는지, 어디를 확인하고 언제 [안산 출장열쇠](ansan.html)를 부를지 정리했습니다.
@ 성포동 여름 현관문 뻑뻑함 출장열쇠 점검

# 열기와 습기가 문에 하는 일
쇠로 된 현관문과 문틀은 뜨거워지면 아주 조금씩 늘어납니다. / 눈에 보일 만큼은 아니어도 걸쇠가 들어가는 틈이 빡빡해지기에는 충분합니다.
나무문이나 나무 문틀이라면 습기를 먹어 부풀기도 합니다. / 장마철에 방문이 문틀에 끼어 잘 안 닫히는 것과 같은 이유입니다.
여기에 문틀 고무 패킹이 열에 말랑해지면서 문을 밀어내는 힘이 커집니다. / 세 가지가 겹치면 봄가을에는 없던 뻑뻑함이 여름에만 나타납니다.
문 자체가 고장 난 것이 아니라 틈이 조금 줄어든 것뿐인 경우도 많습니다. / 그래서 처음부터 도어락을 바꾸기보다 문과 문틀이 맞물리는 자리를 먼저 보는 게 순서입니다.

# 해가 드는 현관이라면 더 그렇습니다
복도에 햇빛이 오래 드는 집이나 바깥과 바로 맞닿은 주택 현관은 문 표면이 한낮에 꽤 뜨거워집니다. / 오후에만 문이 뻑뻑하고 아침저녁에는 괜찮다면 열 때문일 가능성이 큽니다.
번호판이 해를 정면으로 받는 자리라면 한낮에 버튼 반응이 굼뜨기도 합니다. / 그늘이 진 뒤 다시 눌러 보면 정상으로 돌아오는지 확인해 보세요.

# 먼저 언제 뻑뻑한지 적어 보세요
원인을 짚으려면 하루 중 언제, 어떤 날씨에 그런지 아는 것이 가장 중요합니다. / 며칠만 메모해 두면 전화로 설명하기도 쉬워집니다.
- 한낮에만 그런지, 비 온 다음 날에도 그런지
- 문이 안 닫히는 건지, 닫히는데 잠금이 안 되는 건지
- 문을 세게 밀면 잠기는지
- 문 위쪽과 아래쪽 중 어디가 문틀에 닿는지
@ 성포동 아파트 현관 도어락 걸쇠 여름 점검

# 문을 밀어야 잠긴다면 걸쇠 자리를 보세요
문을 손으로 꾹 밀어야 도어락이 잠긴다면 걸쇠와 문틀 쪽 홈이 살짝 어긋난 것입니다. / 문틀 쪽 쇠판에 걸쇠가 긁고 지나간 자국이 있는지 살펴보세요.
긁힌 자국이 홈 한쪽에만 몰려 있다면 위치가 어긋났다는 신호입니다. / 이럴 때 억지로 계속 밀어 잠그면 도어락 모터에 부담이 쌓여 고장이 앞당겨집니다.

# 문 위쪽이 닿는다면 처짐도 함께
문 위 모서리가 문틀에 스치거나 닿는다면 여름 팽창에 더해 문이 조금 처진 상태일 수 있습니다. / 오래 산 집은 경첩이 조금씩 느슨해져 문 끝이 내려앉기도 합니다.
문 아래쪽이 바닥이나 문턱에 끌린다면 같은 이유일 가능성이 큽니다. / 바닥에 반달 모양으로 긁힌 자국이 생겼는지 한 번 살펴보세요.
이런 경우는 여름이 지나도 완전히 좋아지지 않는 편입니다. / 경첩 쪽 점검이 함께 필요하니 출장을 부르실 때 이 부분을 꼭 말씀해 주세요.

# 집에서 해 볼 수 있는 것
한낮에 문이 뻑뻑하다면 해가 진 뒤 다시 여닫아 보세요. / 그때 괜찮다면 당장 큰 문제는 아니고, 걸쇠 자리를 조금 손보는 정도로 좋아지는 경우가 많습니다.
문틀 고무 패킹이 끈적하게 녹아 있다면 마른 천으로 가볍게 닦아 주세요. / 패킹이 들뜨거나 찢어졌다면 떼어 내지 말고 그대로 두는 게 낫습니다.
걸쇠 부분에 먼지가 쌓였다면 마른 솔로 털어 주세요. / 식용유나 일반 기름은 먼지를 붙잡아 오히려 더 뻑뻑해집니다.
@ 성포동 주택 현관문 문틀 고무 패킹 확인

# 에어컨을 켠 날 생기는 일
한여름 에어컨을 세게 켜면 집 안은 차갑고 바깥 복도는 뜨거워 현관문 안쪽에 물방울이 맺히기도 합니다. / 이 물기가 도어락 안쪽 몸체로 스며들면 버튼이 잘 안 먹거나 잠금 소리가 이상해질 수 있습니다.
현관 중문이 있다면 닫아 두는 것만으로 온도 차이를 줄일 수 있습니다. / 물방울이 맺힌 날은 도어락 주변을 마른 수건으로 한 번 닦아 주세요.

# 이럴 땐 여름이 끝나길 기다리지 마세요
문이 아예 안 잠기거나 잠긴 뒤 안 열리는 상황이라면 계절을 탓하며 미루지 마세요. / 아래 같은 경우는 바로 연락 주시는 편이 낫습니다.
- 잠금이 될 때까지 문을 여러 번 쾅 닫아야 하는 경우
- 도어락 모터 소리가 길게 이어지다 멈추는 경우
- 열리긴 하는데 손잡이를 아주 세게 돌려야 하는 경우
- 문을 닫고 나가도 잠겼는지 확신이 안 서는 경우
이런 상태로 계속 쓰면 어느 날 문 앞에서 막히게 됩니다. / [도어락 수리](doorlock-repair.html)로 걸쇠와 몸체를 함께 손보는 편이 비용과 수고를 줄입니다.

# 내년 여름을 위해 지금 해 둘 것
날이 식은 지금이 오히려 문을 손보기 좋은 때입니다. / 문이 제자리에 있을 때 걸쇠와 홈 위치를 맞춰 두면 여름에 늘어나도 여유가 생깁니다.
도어락 건전지는 여름 전에 한 번 새것으로 갈아 두세요. / 뻑뻑한 문을 잠그느라 모터가 힘을 더 쓰면 건전지도 평소보다 빨리 닳습니다.
현관 앞에 햇빛을 가릴 수 있는 구조라면 블라인드나 가림막을 생각해 보셔도 좋습니다. / 문 표면 온도가 덜 오르면 번호판과 패킹도 오래갑니다.

# 출장 때는 사시는 분인지 먼저
점검이든 문 열기든 그 집에 사시는 분인지 먼저 확인합니다. / 주소가 적힌 신분증이나 우편물, 관리사무소 확인 가운데 하나면 됩니다.
문을 열어야 하는 상황이면 [현관문 개문](door-open.html) 방식으로 덜 상하게 엽니다. / 전체 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 비용은 원인을 확인하고 나서
걸쇠 자리만 맞추면 되는지, 경첩까지 봐야 하는지에 따라 하는 일이 달라집니다. / 원인을 보고 금액을 먼저 말씀드린 뒤 괜찮다고 하실 때만 손을 댑니다.
문이 잠겨 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 도어락이 너무 오래돼 고쳐도 같은 일이 반복될 것 같으면 그때 [도어락 교체](doorlock-replace.html)를 의논합니다.

# 성포동 말고 안산 어디든
성포동과 가까운 월피동, 이동, 사동, 본오동은 물론 고잔동, 초지동, 선부동, 와동, 원곡동까지 안산 어디든 갑니다. / 대부동은 거리가 있어 도착 시간을 먼저 말씀드리며, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
