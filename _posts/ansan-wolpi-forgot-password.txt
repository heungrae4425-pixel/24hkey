# 월피동 문 앞에서 번호가 떠오르지 않을 때
월피동은 상록구 안에서 아파트와 빌라, 단독주택이 골고루 있는 동네입니다. / 퇴근하고 집에 왔는데 평소 누르던 번호가 갑자기 생각나지 않아 당황하는 일은 누구에게나 생길 수 있습니다.
가족이 번호를 바꿨는데 알려 주지 않았거나, 이사 직후라 새 번호를 헷갈리는 경우도 많습니다. / 이럴 때 억지로 번호를 이것저것 눌러 보면 도어락이 잠시 입력을 막아 버립니다.
이 글은 월피동에서 비밀번호를 잊었을 때 먼저 해볼 것, 그리고 [안산 출장열쇠](ansan.html)가 와서 문을 열고 번호를 다시 정하는 순서를 적었습니다.
@ 월피동 도어락 비밀번호 분실 출장열쇠

# 번호를 연달아 누르면 생기는 일
많은 도어락은 틀린 번호를 몇 번 이상 입력하면 일정 시간 동안 번호 입력을 막습니다. / 도난을 막으려는 기능이지만 정작 본인이 문 앞에서 막히는 원인이 되기도 합니다.
막힌 상태에서는 맞는 번호를 눌러도 반응하지 않습니다. / 이때는 몇 분 쉬었다가 다시 시도하거나, 열쇠나 카드 같은 다른 방법을 써야 합니다.
그래서 서너 번 눌러 보고 안 되면 멈추는 것이 좋습니다. / 더 누른다고 번호가 생각나지도 않고 잠금 시간만 길어집니다.
입력이 막혔을 때 문 앞에서 오래 기다리기 힘들다면 가족이나 이웃에게 먼저 연락해 보세요. / 늦은 밤에 도어락이 막혀 문 앞에서 한참 서 계시다 전화 주시는 분도 많으니 너무 오래 혼자 버티지 않으셔도 됩니다.
추운 날이나 비 오는 날에는 무리해서 시도하기보다 바람을 피할 곳으로 옮겨 계시다가 연락 주시는 것이 더 안전합니다.

# 먼저 떠올려 볼 만한 번호들
번호가 안 날 때는 아래 순서로 천천히 떠올려 보세요.
- 이사하기 전에 쓰던 집 번호
- 가족이 자주 쓰는 번호 조합
- 도어락을 바꾸거나 배터리를 교체한 직후에 새로 정한 번호
- 같이 사는 가족에게 최근에 번호를 바꿨는지 물어보기
가족과 통화가 되면 번호를 직접 물어보는 것이 가장 빠릅니다. / 휴대폰 메모나 가족 단체방에 번호를 적어 둔 적이 없는지도 찾아보세요.

# 카드나 열쇠가 있는지 확인하세요
번호를 잊었더라도 다른 방법으로 열 수 있는 도어락이 많습니다. / 카드키를 같이 쓰는 제품이라면 지갑이나 가방 속 카드가 있는지 먼저 찾아보세요.
열쇠 구멍이 있는 도어락이라면 비상용 열쇠를 어디 두었는지 떠올려 보세요. / 이웃이나 부모님 댁에 맡겨 둔 열쇠가 있을 수도 있습니다.
휴대폰으로 열리는 제품이라면 앱을 열어 보세요. / 앱에서 번호를 확인하거나 문을 열 수 있는 경우가 있습니다.
@ 월피동 카드키 열쇠 비상 방법 확인

# 가족이 집 안에 있다면 이렇게 하세요
집 안에 가족이 있다면 안쪽에서 문을 열어 달라고 부탁하는 것이 제일 간단합니다. / 안쪽 손잡이는 번호가 필요 없는 제품이 대부분입니다.
인터폰이나 전화가 닿지 않을 때는 문을 두드리거나 이웃에게 연락을 부탁해 보세요. / 아이나 어르신이 혼자 있다면 놀라지 않도록 문 너머로 계속 이야기해 주세요.
집 안에 아무도 없다면 이제는 열쇠집을 부르는 방법이 남습니다. / 위치와 상황을 알려주시면 바로 출동 여부를 말씀드립니다.

# 비밀번호를 잊은 경우 열쇠집이 하는 일
비밀번호 자체를 알아내는 것이 아니라 문을 열고 새 번호를 등록하는 방식입니다. / 도어락 종류에 따라 열 수 있는 방법과 걸리는 시간이 다릅니다.
문과 도어락이 상하지 않도록 덜 상하는 방법부터 시도합니다. / 어떤 방법으로 열지는 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.
문을 연 다음에는 이전 번호를 지우고 새 번호를 등록합니다. / 비밀번호를 한 번 잊은 집은 새 번호를 정하는 요령도 같이 안내해 드립니다.

# 전화하실 때 알려주실 내용
짧게 정리해서 말씀해 주시면 도착이 빨라집니다.
- 월피동 어디쯤인지, 건물 이름이나 앞에 보이는 큰 건물
- 몇 층 몇 호인지
- 번호판이 켜지는지, 번호를 누르면 소리가 나는지
- 도어락 모양 (손잡이 일체형, 버튼형, 밀고 당기는 형)
- 집 안에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다. / 위치는 지도 앱 현재 위치를 보내주셔도 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
번거로우시겠지만 이웃과 입주자 모두를 위한 절차입니다. / 확인이 어려우면 작업을 진행하지 못하니 미리 챙겨 두시면 좋습니다.
신분증이 집 안에 있다면 휴대폰 속 공과금 고지서나 계약서로 확인할 수 있는지 먼저 말씀해 주세요. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용은 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 월피동 24시 출장열쇠 현관문 개문 비용 안내

# 열린 뒤 새 번호를 이렇게 정하세요
문이 열린 뒤에는 새 번호를 가족과 같이 정하는 것이 좋습니다. / 아래 정도만 지켜도 다시 잊어버릴 일이 줄어듭니다.
- 생일이나 전화번호 뒷자리처럼 쉽게 추측되는 번호는 피하기
- 가족이 함께 기억할 수 있는 규칙으로 정하기
- 번호는 휴대폰 메모에 보관하되 도어락 근처에는 적어 두지 않기
- 카드나 열쇠를 한 개 따로 보관해 두기
새 번호를 등록한 뒤에는 문을 닫고 다시 열어 보면서 제대로 작동하는지 꼭 확인하세요. / 안쪽 레버로도 열리는지 같이 보면 좋습니다.

# 같은 일이 반복되지 않게 하는 요령
비밀번호는 정하는 순간 가족 모두가 알아야 합니다. / 한 사람만 알고 있으면 그 사람이 없을 때 문 앞에서 막히게 됩니다.
번호를 바꿀 때마다 가족 단체방에 공지하는 습관을 들이세요. / 이전 번호는 삭제하고 새 번호만 남겨야 안전합니다.
도어락 배터리가 방전되면 번호가 초기화되는 제품도 있어서 배터리는 해가 바뀔 때쯤 한 번에 교체하세요. / 경고음이 나면 그날 바로 교체하는 것이 좋습니다.
[도어락 수리](doorlock-repair.html)가 필요한 증상이 같이 있다면 이때 함께 점검을 받으면 편합니다.

# 월피동 말고 안산 어디든 갑니다
고잔동, 초지동, 선부동, 와동, 원곡동, 본오동, 사동, 이동, 성포동까지 안산 전 지역 24시간 출동합니다. / 대부동은 거리가 있어 위치를 받고 도착 시간을 미리 말씀드립니다.
안산에서 다니는 동네는 [안산시 출장열쇠](ansan.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
