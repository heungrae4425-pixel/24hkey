# 모터는 도는데 문이 그대로라면
원곡동은 단원구에 속한 동네로 다세대주택과 원룸 건물이 촘촘하게 붙어 있습니다. / 오래된 철문에 도어락을 여러 번 바꿔 단 집이 많아 문과 도어락이 딱 맞지 않는 경우도 종종 봅니다.
번호를 누르면 윙 하는 소리는 나는데 문이 열리지 않거나, 문을 닫고 잠금을 눌러도 덜컥 소리만 나고 잠기지 않는 일이 생깁니다. / 이럴 때 범인은 대개 도어락 옆면에서 튀어나와 문틀로 들어가는 굵은 쇠막대, 데드볼트입니다.
이 글은 원곡동 다세대와 원룸 현관에서 데드볼트가 말썽일 때 어디를 보고 언제 [안산 출장열쇠](ansan.html)를 부를지 정리했습니다.
@ 원곡동 도어락 데드볼트 걸림 출장열쇠

# 데드볼트와 문틀 홈의 관계
데드볼트는 잠글 때 도어락에서 나와 문틀 쪽 쇠판의 홈으로 들어가고, 열 때 다시 도어락 안으로 들어갑니다. / 이 왕복이 매끄러우려면 볼트와 홈의 높이, 깊이가 맞아야 합니다.
문이나 문틀이 아주 조금만 어긋나도 볼트가 홈 가장자리에 걸립니다. / 그러면 모터가 힘을 써도 볼트가 끝까지 움직이지 못합니다.
도어락은 볼트가 끝까지 움직였는지 스스로 알아차리지 못하는 제품도 있습니다. / 그래서 잠김 소리는 났는데 실제로는 볼트가 반만 나와 있는 일도 생기니, 외출할 때 손잡이를 한 번 당겨 보는 습관이 도움이 됩니다.

# 증상부터 둘로 나눠 보세요
안 잠기는 경우와 안 풀리는 경우는 원인도, 급한 정도도 다릅니다. / 지금 어느 쪽인지부터 정리해 두세요.
- 문은 닫히는데 잠금 소리만 나고 볼트가 덜 나오는 경우
- 볼트가 나오다 문틀에 부딪혀 멈추는 경우
- 잠긴 상태에서 번호를 눌러도 볼트가 안 들어가는 경우
- 안쪽 손잡이나 레버를 돌려도 볼트가 꿈쩍 않는 경우
위의 두 가지는 문이 열린 채라 당장 들어갈 수는 있습니다. / 아래 두 가지는 문이 잠긴 채 막힌 상황이라 출장이 필요한 경우가 많습니다.

# 문을 살짝 밀거나 당긴 채 다시 해 보기
볼트가 홈에 꽉 물려 있으면 문짝을 문틀 쪽으로 조금 밀거나, 반대로 몸 쪽으로 당긴 상태에서 번호를 다시 눌러 보세요. / 볼트를 누르던 힘이 잠깐 풀리면서 들어가는 경우가 있습니다.
어느 쪽이 맞는지는 문마다 달라서 양쪽으로 한 번씩만 해 보면 됩니다. / 몸무게를 실어 세게 밀거나 손잡이를 잡고 흔드는 건 피해 주세요.
@ 원곡동 다세대 철문 도어락 걸쇠 문틀

# 문틀 쇠판 홈을 들여다보세요
문이 열려 있는 상태라면 문틀 쪽 쇠판의 홈을 손전등으로 비춰 보세요. / 오래된 다세대는 홈 안에 먼지와 녹, 페인트 덩어리가 끼어 있는 경우가 있습니다.
홈 가장자리에 반짝이는 긁힌 자국이 한쪽으로 몰려 있다면 볼트가 그쪽에 부딪히고 있다는 뜻입니다. / 위쪽에 몰려 있으면 문이 처졌을 가능성, 아래쪽이면 문틀이 내려앉았을 가능성을 의심해 볼 수 있습니다.
홈 안의 먼지는 마른 솔이나 이쑤시개로 살살 털어 내도 됩니다. / 쇠판을 망치로 두드려 넓히는 건 문틀을 상하게 하니 하지 마세요.

# 원곡동 다세대 문이 어긋나기 쉬운 이유
건물이 오래되면 문틀이 조금씩 틀어지고 문짝은 경첩 쪽으로 처집니다. / 여기에 도어락을 다른 제품으로 바꿔 달면서 볼트 높이가 예전 홈과 조금 다른 위치가 되는 일도 있습니다.
복도 바람이 세게 드는 건물에서는 문이 쾅 닫히면서 충격이 반복되기도 합니다. / 그때마다 볼트와 홈이 조금씩 닳아 처음엔 없던 걸림이 생깁니다.

# 기름보다 먼저 확인할 것
뻑뻑하면 기름부터 뿌리고 싶어지지만, 일반 기름은 먼지를 붙잡아 홈을 더 끈적하게 만듭니다. / 특히 도어락 몸체 틈으로 기름이 흘러 들어가면 안쪽 부품까지 상할 수 있습니다.
먼지를 털어 내도 그대로라면 위치가 어긋난 것이니 윤활로 해결되지 않습니다. / 이 단계에서는 점검을 받는 편이 낫습니다.
@ 원곡동 원룸 현관 데드볼트 홈 먼지 청소

# 안쪽에 수동 레버가 있는지
집 안에 계신 상태로 볼트가 안 풀린다면 안쪽 몸체를 둘러보세요. / 많은 도어락은 안쪽에 손으로 돌리거나 밀어서 볼트를 움직이는 레버나 손잡이가 있습니다.
레버를 돌릴 때도 문을 살짝 밀거나 당긴 상태에서 해 보면 덜 뻑뻑합니다. / 그래도 꿈쩍 않으면 무리하게 비틀지 말고 연락 주세요.

# 문이 열린 채 안 잠긴다면 밤을 어떻게 보낼까
볼트가 안 나와 문이 안 잠긴다면 당장 들어갈 수는 있지만 그날 밤이 걱정입니다. / 보조키나 안쪽 걸쇠가 있다면 그것으로 우선 잠가 두세요.
다만 안쪽 걸쇠만 걸어 두면 외출할 때는 문을 잠글 방법이 없습니다. / 다음 날 외출 전까지는 점검을 받으시는 게 좋습니다.
늦은 밤이라 혼자 있는 게 불안하시다면 그날 바로 연락 주셔도 됩니다. / 문이 열려 있는 상태라 점검과 손보기가 오히려 수월한 편입니다.

# 전화로 알려 주시면 좋은 것
원곡동은 비슷한 건물이 이어져 있어 건물 이름과 호수, 들어오는 골목을 알려 주시면 헤매지 않고 갑니다. / 상황은 아래처럼 말씀해 주시면 됩니다.
- 문이 지금 열려 있는지, 잠긴 채인지
- 번호를 누르면 모터 소리가 나는지
- 문을 밀거나 당기면 달라지는지
- 도어락을 바꾼 지 얼마나 됐는지
도어락 옆면과 문틀 홈 사진을 함께 보내 주시면 원인을 미리 가늠할 수 있습니다. / 문이 잠겨 있어 홈이 안 보인다면 바깥 번호판 사진 한 장이면 충분합니다.

# 사시는 분 확인과 비용 안내
문을 열거나 도어락에 손을 대기 전에 그 집에 사시는 분인지 먼저 확인합니다. / 주소가 적힌 신분증이나 우편물, 집주인이나 건물 관리인 확인 중 하나면 됩니다.
원인을 본 뒤 손볼 범위와 금액을 먼저 말씀드리고, 동의하실 때만 시작합니다. / 잠긴 문을 끝내 열지 못하면 비용은 받지 않으며, 진행 순서는 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 적어 두었습니다.

# 손보는 범위는 원인에 따라
홈 위치가 조금 어긋난 정도라면 문틀 쪽 쇠판 위치를 맞추는 것으로 끝나는 경우가 많습니다. / 문이 처졌다면 경첩 쪽도 함께 손봅니다.
볼트를 움직이는 모터나 부품이 상했다면 [도어락 수리](doorlock-repair.html) 범위를 먼저 설명드립니다. / 오래된 제품이라 부품을 구하기 어려우면 그때 [도어락 교체](doorlock-replace.html)를 의논하되, 세입자라면 집주인과 먼저 이야기해 주세요.

# 원곡동 말고 안산 어디든
원곡동과 가까운 선부동, 초지동, 고잔동, 와동은 물론 본오동, 사동, 이동, 월피동, 성포동까지 다닙니다. / 대부동은 거리가 있어 도착 시간을 먼저 말씀드리며, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
