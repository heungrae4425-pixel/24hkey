# 원곡동 원룸 문이 잠겼을 때, 먼저 숨부터 고르세요
원곡동은 다세대주택과 원룸 건물이 촘촘하게 붙어 있는 동네입니다. / 비슷하게 생긴 건물이 이어져 있어 같은 골목에서도 문 앞에 서면 어느 건물인지 헷갈릴 때가 있습니다.
열쇠를 안에 두고 나왔거나 번호판이 꺼진 상태로 문 앞에 서 있으면 마음이 급해집니다. / 이 글은 그럴 때 전화하기 전에 해볼 것과 [안산 출장열쇠](ansan.html)가 오는 순서를 차례대로 적었습니다.
원룸은 공동 현관과 호실 문이 따로 있는 경우가 많아서 어느 문이 잠겼는지부터 구분해야 합니다. / 아래 내용을 읽고 상황에 맞는 부분부터 확인해 보세요.
@ 원곡동 원룸 출입문 24시 출장열쇠 현관문 개문

# 공동 현관인지 호실 문인지 먼저 나눠 보세요
같은 건물 안에서도 잠기는 문은 두 곳입니다. / 건물 입구의 공동 현관과 각 호실 앞의 현관문이 그것입니다.
- 공동 현관: 번호나 카드, 열쇠로 건물 안으로 들어가는 문
- 호실 문: 내 방 앞에서 쓰는 도어락이나 열쇠 문
- 안쪽 방문: 화장실이나 방 안에서 잠긴 문
어느 문인지 알려주시면 챙겨 가는 장비가 달라집니다. / 공동 현관은 건물 관리하는 분의 동의가 필요할 수 있어서 전화로 미리 말씀해 주세요.

# 원룸 도어락이 잠기는 흔한 이유
원룸은 쓰는 사람이 자주 바뀌고 도어락도 오래 쓰는 경우가 많습니다. / 그래서 아래 같은 이유로 잠김 연락이 옵니다.
- 배터리가 다 돼서 번호판이 아예 반응하지 않는 경우
- 열쇠를 방 안에 둔 채 문이 닫혀 자동으로 잠긴 경우
- 이전에 살던 사람이 바꿔 둔 번호를 모르는 경우
- 번호는 맞는데 안쪽 레버나 걸쇠가 풀리지 않는 경우
자동으로 잠기는 도어락은 문이 닫히는 순간 바로 잠깁니다. / 쓰레기를 버리러 잠깐 나왔다가 닫히는 것도 이 경우에 해당합니다.

# 건물 위치를 이렇게 알려주시면 빨라집니다
원곡동은 골목이 좁고 건물이 비슷해서 위치를 정확히 알려주시는 게 제일 중요합니다. / 아래 순서로 말씀해 주시면 도착이 훨씬 빨라집니다.
- 건물 이름이나 건물 앞에 보이는 간판
- 도로 이름이나 근처 편의점·큰 건물
- 몇 층 몇 호인지
- 공동 현관 비밀번호를 아는지 여부
지도 앱에서 현재 위치를 문자로 보내주셔도 됩니다. / 건물에 주소 표지판이 있으면 사진을 찍어서 같이 보내주세요.
@ 안산 원곡동 다세대 건물 입구 열쇠집 출장

# 문 앞에서 하지 말아야 할 행동
급한 마음에 문을 세게 당기거나 어깨로 미는 분들이 있습니다. / 이러면 문틀이 상하고 도어락 안쪽 부품이 어긋나서 수리할 것이 늘어납니다.
카드나 칼로 문틈을 벌리려는 시도도 피해 주세요. / 걸쇠 부분이 긁히면 나중에 문이 깔끔하게 잠기지 않을 수 있습니다.
비밀번호는 서너 번 눌러 보고 안 되면 멈추는 게 좋습니다. / 여러 번 틀리면 도어락이 한동안 입력을 막는 제품이 있습니다.

# 9V 건전지로 비상 전원을 넣어 보세요
번호판이 꺼진 도어락은 바깥쪽 아래에 9V 건전지를 대는 단자가 있는 제품이 많습니다. / 건전지를 대고 있는 동안 번호를 누르면 열리는 경우가 있습니다.
근처 편의점에서 9V 건전지를 구할 수 있습니다. / 단자가 없거나 건전지를 대도 반응이 없으면 그때 전화 주세요.
문이 열리면 안쪽 배터리를 모두 새것으로 바꿔 두세요. / 일부만 바꾸면 얼마 안 가 같은 일이 반복됩니다.

# 전화 한 통에 알려주시면 좋은 내용
전화로 상황을 설명하실 때는 이 정도만 말씀해 주세요. / 길게 설명하지 않아도 됩니다.
- 어느 문이 잠겼는지 (공동 현관, 호실 문, 방문)
- 번호판이 켜지는지, 소리가 나는지
- 열쇠나 카드가 안에 있는지
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다. / 집 안에서 불이나 가스를 쓰고 있는 상황이면 꼭 먼저 말씀해 주세요.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 적힌 우편물, 건물 관리하시는 분 확인 중 하나면 충분합니다.
번거로우시겠지만 이웃과 입주자 모두를 위한 절차입니다. / 확인이 어려우면 작업을 진행하지 못하니 미리 챙겨 두시면 좋습니다.
신분증이 방 안에 있다면 휴대폰에 저장된 계약서나 공과금 고지서로 확인할 수 있는지 먼저 여쭤보세요. / 어려운 경우 건물 관리하시는 분께 거주 확인을 부탁하는 방법도 있습니다.
자세한 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 원곡동 출장열쇠 비파손 개방 도어락 점검

# 최대한 안 상하게 여는 순서
문을 여는 방법은 여러 가지가 있고, 덜 상하는 방법부터 차례로 해봅니다. / 문과 도어락이 상하지 않는 것이 가장 먼저입니다.
도어락 종류와 문 상태에 따라 걸리는 시간은 다릅니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.
자세한 방법은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 열고 난 뒤에는 도어락을 같이 점검합니다
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새 배터리로 바꿨는지도 함께 봅니다.
이전 입주자가 쓰던 번호가 남아 있을 수 있어서 새 번호를 등록하고 기존 번호는 지우는 것까지 도와드립니다. / 원룸은 사람이 바뀔 때 이 과정을 거치는 게 안전합니다.
고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 원룸 도어락 오래 쓰는 관리 요령
원룸 도어락은 한 번 설치하면 오래 쓰는 만큼 작은 습관이 중요합니다. / 아래 정도만 지켜도 잠김 연락을 많이 줄일 수 있습니다.
- 경고음이 나면 그날 바로 배터리 교체
- 배터리는 건전지를 모두 한 번에 교체
- 열쇠나 카드는 방 안 말고 가방이나 지갑에 한 개 더 보관
- 문이 덜 닫히면 경첩과 문틀 점검
비상용 9V 건전지 하나를 가방에 넣어 두는 것도 방법입니다. / 번호판이 꺼졌을 때 바로 시도해 볼 수 있어서 마음이 편합니다.

# 원곡동 말고 안산 어디든 갑니다
고잔동, 초지동, 선부동, 와동, 본오동, 사동, 이동, 월피동, 성포동까지 안산 전 지역 24시간 출동합니다. / 대부동은 거리가 있어서 위치를 받으면 도착 시간을 미리 말씀드립니다.
안산에서 다니는 동네는 [안산시 출장열쇠](ansan.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
