# 문 앞에서 무엇부터 봐야 할지 모를 때
현관문이 안 열리면 머릿속에 여러 가지 원인이 한꺼번에 떠올라 무엇부터 해야 할지 막막해집니다. / 안성 시내와 가까운 아양동은 주택과 빌라가 이어진 동네라 집마다 도어락과 보조키 구성이 조금씩 다릅니다.
원인은 달라도 확인하는 순서는 정해 둘 수 있습니다. / 전기가 들어오는지, 번호가 맞는지, 기계가 움직이는지, 문이 걸리는지, 안쪽 잠금이 걸렸는지를 차례로 보는 것입니다.
이 글은 아양동에서 현관문이 안 열릴 때 이 다섯 단계를 하나씩 짚어 보는 방법과 [안성 출장열쇠](anseong.html)를 부를 때를 정리했습니다.
@ 아양동 현관문 안 열림 원인 확인

# 첫째, 번호판에 전기가 들어오나
번호판을 손바닥으로 덮거나 눌러 불이 켜지는지 봅니다. / 아무 반응이 없다면 안쪽 배터리가 다 됐을 가능성이 가장 큽니다.
바깥 아래쪽이나 옆면에 비상 전원 단자가 있다면 9V 건전지를 대 보세요. / 건전지를 댄 채로 번호를 누르고, 문이 열릴 때까지 떼지 않는 것이 요령입니다.
불이 켜졌다 금방 꺼지거나 깜빡이기만 한다면 배터리가 거의 바닥난 상태입니다. / 이때도 비상 전원을 먼저 시도해 보시면 됩니다.

# 둘째, 번호와 카드가 맞게 들어가나
불은 켜지는데 삑삑 짧은 소리가 반복된다면 입력이 틀렸다는 뜻인 경우가 많습니다. / 천천히 한 번 더 누르고, 가족이 최근에 번호를 바꾸지 않았는지 물어보세요.
카드나 태그로 여는 집이라면 카드를 번호판 위 정해진 자리에 천천히 대 보세요. / 지갑에 다른 카드와 겹쳐 있으면 인식이 안 될 수 있어 카드 한 장만 따로 꺼내 대는 것이 좋습니다.
여러 번 틀리면 일정 시간 입력이 막힙니다. / 막혔다면 잠시 기다렸다가 확실한 번호로 한 번만 다시 눌러 보세요.

# 셋째, 모터와 잠금쇠가 움직이나
번호가 맞다는 소리가 나고 모터 소리도 나는데 문이 안 열린다면 잠금쇠가 끝까지 빠지지 않은 것입니다. / 문 옆면 잠금쇠가 문틀에 눌려 있으면 약해진 모터가 당기지 못합니다.
문을 안쪽으로 살짝 밀거나 몸 쪽으로 살짝 당기면서 번호를 다시 눌러 보세요. / 어느 한쪽으로 힘을 주었을 때 열린다면 잠금쇠와 문틀 위치가 어긋나 있다는 신호입니다.
모터 소리조차 나지 않고 딸깍 소리만 난다면 안쪽 부품 문제일 수 있습니다. / 이 경우는 같은 동작을 반복하지 말고 연락 주시는 것이 좋습니다.
@ 아양동 도어락 잠금쇠 문틀 걸림 점검

# 넷째, 문과 문틀이 걸려 있나
오래된 주택과 빌라 현관은 경첩이 조금씩 처지면서 문이 내려앉는 경우가 있습니다. / 이렇게 되면 잠금이 풀려도 문 끝이 문틀에 걸려 잘 안 열립니다.
문 위쪽과 아래쪽 틈을 살펴보세요. / 한쪽 틈이 유난히 넓거나 좁다면 문이 기울어진 것이고, 손잡이를 돌린 채 문을 살짝 들어 올리듯 밀면 열리기도 합니다.
여름 장마철이나 한겨울에는 문과 문틀이 습기나 추위로 조금씩 늘었다 줄었다 해서 걸림이 심해지기도 합니다. / 계절마다 같은 증상이 반복된다면 점검을 받아 두는 편이 좋습니다.

# 다섯째, 안쪽 잠금이 걸려 있나
도어락은 멀쩡한데 안쪽에서 보조키나 걸쇠가 걸려 있으면 바깥에서는 열 수 없습니다. / 집 안에 가족이 있다면 문 너머로 걸쇠를 풀어 달라고 부탁해 보세요.
아이가 장난으로 걸쇠를 걸었거나 어르신이 습관처럼 잠그신 경우가 많습니다. / 집 안에 아이 혼자 있다면 놀라지 않게 계속 말을 걸어 주시고, 전화 주실 때 이 상황을 먼저 말씀해 주세요.
집이 비어 있는데 안쪽 잠금이 걸린 것 같다면 나가기 전에 누가 마지막으로 문을 닫았는지 떠올려 보세요.

# 보조키를 열쇠로 잠근 집이라면
도어락과 따로 열쇠식 보조키를 쓰는 집은 도어락이 열려도 보조키가 잠겨 있으면 문이 안 열립니다. / 오늘 나갈 때 보조키를 잠갔는지 먼저 떠올려 보세요.
보조키 열쇠가 끝까지 안 돌아간다면 문을 살짝 밀거나 당기며 천천히 돌려 봅니다. / 그래도 꿈쩍하지 않으면 열쇠를 비틀지 말고 멈추는 편이 좋습니다.

# 단계마다 하지 말아야 할 것
- 번호판을 손으로 세게 두드리기
- 손잡이를 힘껏 당기거나 문을 발로 차기
- 문틈에 드라이버나 카드 밀어 넣기
- 배터리 덮개나 몸체를 바깥에서 뜯어 보기
이런 시도는 대부분 문을 여는 데 도움이 되지 않고, 고칠 곳만 늘립니다. / 다섯 단계를 차례로 확인해 보고 그래도 안 되면 그 자리에서 멈추는 것이 가장 좋습니다.

# 아양동에서 연락 주실 때 말씀해 주실 것
- 아양동 위치와 주택인지 빌라인지, 몇 층인지
- 다섯 단계 가운데 어디서 막혔는지
- 번호판 상태와 들리는 소리
- 집 안에 사람이나 반려동물이 있는지
어느 단계에서 막혔는지만 알려 주셔도 원인이 많이 좁혀집니다. / 도어락 사진을 함께 보내 주시면 장비를 맞춰 챙길 수 있습니다.
가스불이나 다리미를 켜 둔 채 나왔다면 그 이야기부터 해 주세요. / 순서를 앞당겨 출발하고, 필요하면 이웃이나 집주인에게도 바로 알리시도록 안내드립니다.

# 도착하면 거주 확인부터
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 집주인이나 관리인 확인 가운데 하나면 됩니다.
신분증이 집 안에 있다면 문을 연 직후 보여 주시는 방식으로 진행할 수 있습니다.

# 금액을 먼저 듣고 정하세요
도어락 종류와 문 상태를 보고 어떻게 열지와 금액을 시작 전에 말씀드립니다. / 괜찮으실 때만 진행하고, 아니시면 그대로 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다. / 진행 방식은 [이용안내](guide.html), 여는 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 안성 출장열쇠 아양동 현관문 개방

# 열린 뒤에는 막힌 단계부터 손봅니다
배터리 때문이었다면 전부 새것으로 바꾸고, 번호 때문이었다면 새 번호를 등록합니다. / 잠금쇠나 문틀 때문이었다면 받이 위치나 경첩을 맞춰 같은 일이 생기지 않게 합니다.
모터나 안쪽 부품이 지쳐 있다면 [도어락 수리](doorlock-repair.html)로 부품만 바꿀 수 있는지 먼저 봅니다. / 오래돼 부품을 구하기 어려우면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 아양동 이웃 동네도 갑니다
석정동, 당왕동, 공도읍과 대덕면, 미양면, 보개면, 금광면, 일죽면, 죽산면까지 다닙니다. / 안성 다른 곳은 [안성시 출장열쇠](anseong.html), 서울과 경기 다른 곳은 [출장 지역](area.html)에서 확인하세요.
