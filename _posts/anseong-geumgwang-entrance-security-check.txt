# 걱정보다 점검이 먼저입니다
금광면은 마당이 있는 단독주택과 농가, 전원주택이 띄엄띄엄 이어진 동네입니다. / 이웃집과 거리가 있다 보니 현관 문단속을 한 번쯤 다시 생각해 보게 되는 분들이 많습니다.
방범이라고 하면 비싼 장비부터 떠올리기 쉽지만, 실제로는 이미 있는 문과 잠금장치를 제대로 쓰는 것만으로도 많은 부분이 해결됩니다. / 막연히 불안해하기보다 우리 집 문을 하나씩 살펴보는 편이 훨씬 도움이 됩니다.
이 글은 금광면 주택에서 대문부터 현관까지 집에서 직접 해 볼 수 있는 점검 순서와, [안성 출장열쇠](anseong.html)에 점검을 맡길 때 무엇을 보는지 정리했습니다.
@ 금광면 단독주택 현관 대문 방범 점검

# 바깥에서 집을 한 바퀴 돌아보기
점검은 집 밖에서 시작합니다. / 대문 앞에 서서 집으로 들어오는 길을 따라 걸으며 아래를 살펴보세요.
- 대문이 저절로 닫히고 잠기는지, 살짝 열린 채 멈추지 않는지
- 현관까지 가는 길에 밤에 불이 켜지는지
- 현관 옆 창문이나 뒷문에 잠금장치가 제대로 걸리는지
- 창고나 보일러실 문이 늘 열려 있지 않은지
문 하나만 튼튼해도 다른 쪽이 늘 열려 있으면 의미가 줄어듭니다. / 드나드는 곳 전체를 한 번에 보는 것이 점검의 기본입니다.
낮에 한 번, 해가 진 뒤에 한 번 돌아보면 더 좋습니다. / 밤에는 현관 앞이 생각보다 어둡거나, 외등이 나가 있다는 걸 그제야 알게 되는 경우가 많습니다.
마당 일을 하다 잠깐 밭에 다녀오는 동안 현관을 열어 두는 습관이 있는지도 돌아보세요. / 짧은 시간이라도 문을 닫고 나가는 것만으로 많은 걱정이 줄어듭니다.

# 대문은 닫히는 모습부터
대문이 바람에 흔들리거나 끝까지 닫히지 않는다면 경첩이나 잠금 고리 높이가 어긋난 것일 수 있습니다. / 이럴 때는 잠금장치를 바꾸기 전에 문짝이 제자리에 닿는지부터 맞춰야 합니다.
열쇠로 여는 대문 자물쇠가 녹슬어 뻑뻑하다면 매일 쓰기 귀찮아 아예 안 잠그게 되기 쉽습니다. / 손이 덜 가는 상태로 손봐 두면 잠그는 습관도 자연스럽게 따라옵니다.

# 현관 도어락이 정말 잠기고 있는지
도어락은 잠금음이 났다고 꼭 잠긴 것은 아닙니다. / 문이 덜 닫힌 채로 잠금쇠만 나오면 문틀 구멍에 들어가지 못해 밀면 열리는 상태가 됩니다.
외출하면서 문을 닫은 뒤 손잡이를 한 번 당겨 보세요. / 문이 꿈쩍하지 않으면 제대로 잠긴 것이고, 살짝이라도 움직이면 문틀과 잠금쇠 위치를 봐야 합니다.
자동 잠금 기능이 꺼져 있는 도어락도 있습니다. / 잊고 나가는 일이 잦다면 자동 잠금을 켜 두는 것이 좋습니다.
문과 문틀 사이 틈이 넓어 바깥에서 잠금쇠가 보일 정도라면 그 부분도 함께 봐야 합니다. / 문이 처져 틈이 벌어진 경우가 많아 경첩을 맞추면 틈이 줄어듭니다.
@ 금광면 현관 도어락 잠금 확인 점검

# 번호판에 남는 흔적 살펴보기
자주 누르는 숫자만 번호판 표면이 닳거나 손자국이 진하게 남는 경우가 있습니다. / 번호판을 비스듬히 비춰 보면 어떤 숫자가 눈에 띄는지 알 수 있습니다.
가끔 마른 천으로 닦아 주고, 번호 앞뒤로 다른 숫자를 덧붙여 누르는 기능이 있다면 활용해 보세요. / 번호를 바꾼 지 오래됐다면 이참에 새로 정하는 것도 방법입니다.
마을 분들이나 일을 도와주시는 분이 번호를 알고 계신다면, 누가 알고 있는지 한 번 정리해 두는 것만으로도 충분합니다.

# 열쇠를 숨겨 두는 자리
마당이 있는 집은 화분 밑, 우편함 안, 신발장 위처럼 여분 열쇠를 숨겨 두는 경우가 많습니다. / 가족끼리는 편하지만 누구나 먼저 찾아보는 자리이기도 합니다.
여분 열쇠는 집 밖에 두기보다 가까운 가족이나 믿을 만한 이웃에게 맡겨 두는 편이 낫습니다. / 대문 도어락이나 현관 도어락을 쓴다면 번호로 대신할 수도 있습니다.

# 보조키는 쓰는 날을 정해 두면
보조키가 달려 있어도 매일 쓰지 않는 집이 많습니다. / 늘 쓰기 어렵다면 집을 하루 이상 비울 때만큼은 꼭 잠근다는 식으로 정해 두세요.
보조키 열쇠가 너무 뻑뻑해 쓰기 싫어진 경우라면 실린더 상태를 손보는 것만으로 다시 쓰기 편해집니다. / 열쇠를 몇 개 갖고 있는지도 이번에 한 번 세어 보세요.
예전에 일을 도와주던 분이나 이사 나간 가족에게 건넨 열쇠가 아직 남아 있다면 돌려받거나, 실린더를 바꾸는 것도 생각해 볼 수 있습니다.

# 집을 오래 비울 때 챙길 것
- 도어락 배터리를 떠나기 전에 새것으로 바꾸기
- 대문, 현관, 창고 문 잠금을 한 번에 확인하기
- 가까운 이웃이나 가족에게 비우는 기간 알리기
- 우편물이나 택배가 쌓이지 않게 미리 정리하기
집을 비우는 동안 배터리가 다 되면 돌아왔을 때 문 앞에서 막히게 됩니다. / 방범과 편의 둘 다를 위해 출발 전 배터리 확인은 꼭 해 두세요.

# 점검을 맡기면 보는 것
현장에서는 대문과 현관 잠금이 제대로 맞물리는지, 문틀과 경첩이 처지지 않았는지 먼저 봅니다. / 도어락은 잠금쇠 길이와 받이 구멍, 배터리 상태, 자동 잠금 설정을 확인합니다.
본 내용을 그대로 말씀드리고, 손볼 곳이 있으면 왜 필요한지와 함께 알려 드립니다. / 굳이 바꾸지 않아도 되는 것은 바꾸시라고 권하지 않습니다.

# 금광면에서 연락 주실 때
- 마을 이름이나 큰길 기준 위치
- 대문, 현관, 창고 가운데 어디를 보고 싶은지
- 도어락과 보조키 사진
- 집에 계실 수 있는 시간
집이 큰길에서 떨어져 있으면 들어오는 길을 함께 알려 주세요. / 위치를 받으면 도착 시간을 먼저 말씀드립니다.

# 확인과 비용 안내
점검을 위해 방문할 때도 사시는 분인지 신분증 주소나 우편물로 확인합니다. / 문이 잠겨 열어야 하는 상황이라면 더 꼼꼼히 확인한 뒤 진행합니다.
점검이나 부품 교체 모두 무엇을 할지와 금액을 먼저 말씀드리고, 괜찮으실 때만 시작합니다. / 문을 열어야 하는 경우 끝내 열지 못하면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 손볼지, 바꿀지 고르는 기준
잠금쇠 위치나 경첩만 맞추면 되는 경우가 많아 대개는 [도어락 수리](doorlock-repair.html)로 충분합니다. / 오래돼 부품이 없거나 자동 잠금 같은 기능이 꼭 필요하다면 [도어락 교체](doorlock-replace.html)를 함께 상의합니다.
보조키를 새로 달고 싶다면 문 두께와 기존 구멍을 먼저 보고 [도어락 설치](doorlock-install.html) 가능 여부를 알려 드립니다.

# 금광면 말고 안성 다른 곳도
보개면, 미양면, 대덕면, 일죽면, 죽산면 주택과 공도읍, 석정동, 당왕동, 아양동까지 다닙니다. / 안성 안내는 [안성시 출장열쇠](anseong.html), 다른 지역은 [출장 지역](area.html)에서 보세요.
