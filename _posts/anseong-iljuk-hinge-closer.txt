# 일죽면 주택 현관, 문이 마지막 한 뼘을 못 닫을 때
일죽면은 안성 시내에서 떨어진 곳에 단독주택과 전원주택이 자리한 동네입니다. / 마당을 지나 들어오는 현관이 많아 아파트 복도와 달리 바람과 햇볕, 기온 차이를 현관문이 고스란히 받습니다.
그래서 주택 현관에서는 문이 끝까지 닫히지 않고 살짝 떠 있거나, 반대로 바람이 불 때 쾅 하고 세게 닫히는 일이 잦습니다. / 둘 다 그냥 두면 도어락 걸쇠와 경첩에 무리가 쌓입니다.
이 글은 일죽면 주택에서 현관문이 덜 닫히거나 세게 닫힐 때 경첩과 도어클로저를 어떻게 살피고 조절하는지, [안성 출장열쇠](anseong.html)를 부를 때는 언제인지 정리했습니다.
@ 일죽면 전원주택 현관문 경첩 도어클로저 점검

# 덜 닫힘이 도어락에 주는 문제
문이 끝까지 안 닫히면 도어락 걸쇠가 문틀 구멍에 다 들어가지 못합니다. / 그러면 잠금 소리는 났는데 실제로는 걸쇠가 반만 걸려 있거나, 도어락이 잠금 실패 경고음을 내게 됩니다.
외출할 때 이걸 모르고 나가면 문이 잠기지 않은 채로 집이 비게 됩니다. / 마당이 있는 주택이라 지나가는 사람 눈에 잘 안 띄는 만큼, 잠금이 확실한지가 더 중요합니다.
반대로 걸쇠가 반쯤 걸린 상태로 오래 지내면 걸쇠 끝이 닳아 나중에는 문이 안 열리는 고장으로 이어지기도 합니다.
고칠 때까지는 외출할 때 문을 닫은 뒤 손잡이를 한 번 당겨 보는 습관을 들여 주세요. / 당겼을 때 문이 덜컥 움직이면 잠금이 덜 걸린 것이니 손으로 밀어 다시 닫으면 됩니다.

# 원인은 경첩일까 클로저일까
문을 반쯤 열고 손을 떼 보세요. / 문이 스스로 닫히다가 마지막에 멈춘다면 도어클로저 쪽, 손으로 밀어도 마지막에 툭 걸린다면 경첩이나 문틀 쪽일 가능성이 큽니다.
- 닫히는 속도가 마지막에 너무 느려진다 → 클로저 끝 구간 조절
- 닫히다가 중간에 멈춘다 → 클로저 힘 부족이나 기름 샘
- 손으로 밀어도 걸린다 → 경첩 처짐이나 문틀 어긋남
- 문 아래가 바닥이나 문지방을 긁는다 → 경첩 처짐
이 구분만 해 두셔도 전화로 상황을 설명하기 쉬워집니다. / 문을 여닫는 모습을 옆에서 짧게 찍어 보내 주시면 더 정확합니다.

# 도어클로저 속도 조절 나사 찾기
문 위쪽에 달린 클로저 몸통 옆이나 아래를 보면 작은 조절 나사가 한두 개 있습니다. / 하나는 전체 닫히는 속도, 다른 하나는 마지막 구간 속도를 맡는 경우가 많습니다.
마지막 한 뼘을 못 닫는다면 끝 구간 나사를 아주 조금 풀어 속도를 올려 보세요. / 한 번에 많이 돌리지 말고 조금씩 돌린 뒤 문을 닫아 보며 맞추는 게 요령입니다.
조절 나사를 너무 많이 풀면 안의 기름이 새어 나올 수 있습니다. / 어느 쪽인지 헷갈리면 사진을 보내 주세요.
@ 일죽면 주택 현관 도어클로저 속도 조절

# 바람에 쾅 닫히는 현관이라면
주택 현관은 앞이 트여 있어 바람이 불 때 문이 손에서 빠져나가 쾅 닫히기도 합니다. / 이 충격이 반복되면 경첩 나사가 풀리고 도어락 안쪽 부품도 흔들립니다.
클로저의 전체 속도 나사를 조금 조여 닫히는 속도를 늦추면 바람의 영향을 덜 받습니다. / 클로저가 아예 없는 문이라면 클로저를 새로 다는 것도 방법입니다.
현관 앞에 바람막이 중문이나 차양이 있는 집은 이런 일이 훨씬 덜합니다. / 겨울 북서풍이 정면으로 들어오는 현관이라면 한 번쯤 생각해 볼 만합니다.

# 겨울 아침에만 덜 닫힌다면
낮에는 잘 닫히는데 추운 아침에만 문이 마지막에 멈추는 집이 있습니다. / 클로저 안 기름이 추위에 되직해져서 움직임이 느려지기 때문입니다.
이럴 때는 겨울 동안만 끝 구간 속도를 살짝 올려 두고, 날이 풀리면 다시 맞추는 방법이 있습니다. / 해마다 겨울마다 심해진다면 클로저 자체가 지친 것이라 교체를 생각하시는 게 좋습니다.

# 경첩 처짐은 틈과 바닥 자국으로
문을 닫고 문과 문틀 사이 틈을 보세요. / 손잡이 쪽 위가 넓고 아래가 좁다면 문 끝이 내려앉은 겁니다.
문 아래 바닥이나 문지방에 반달 모양으로 긁힌 자국이 있어도 처짐을 의심할 수 있습니다. / 주택 현관문은 아파트 문보다 크고 무거운 경우가 있어 경첩이 더 빨리 지치기도 합니다.
경첩 나사가 헐거우면 맞는 드라이버로 조여 보세요. / 나사가 헛돌거나 경첩 자체가 휘었다면 혼자 고치기 어렵습니다.

# 기름칠은 어디에, 어떻게
경첩에서 삐걱 소리가 나면 경첩 축 위쪽에 윤활제를 조금 넣어 주면 좋아집니다. / 문을 몇 번 열었다 닫았다 하면 안쪽까지 스며듭니다.
도어락 걸쇠나 번호판에는 윤활제를 뿌리지 마세요. / 전자 부품에 들어가면 고장의 원인이 되고, 먼지가 달라붙어 더 뻑뻑해집니다.
클로저 몸통에 기름이 번들거리며 새어 나와 있다면 기름을 넣어 고치는 게 아니라 클로저를 바꿀 때가 된 것입니다.

# 이럴 때는 직접 하지 마세요
- 문을 경첩에서 떼어 내야 하는 작업
- 클로저 팔을 몸통에서 분리하는 작업
- 문틀 받이를 떼어 옮기는 작업
- 사다리 없이 문 위 클로저를 만지는 작업
현관문은 무게가 있어 혼자 떼다 다치기 쉽고, 클로저 팔은 힘이 걸려 있어 갑자기 튈 수 있습니다. / 이런 작업은 맡기시는 게 안전합니다.

# 일죽면은 도착 시간을 먼저 안내합니다
일죽면은 안성 시내에서 거리가 있는 편이라 위치를 받으면 예상 도착 시간을 먼저 말씀드립니다. / 마을 이름이나 지번 주소, 큰길에서 들어오는 길, 대문이 따로 있는지를 알려 주세요.
문 사진과 클로저 사진을 보내 주시면 맞는 부품을 챙겨 갈 수 있습니다. / 문이 닫혀 열어야 하는 상황이면 신분증이나 우편물로 사시는 분인지 먼저 확인합니다.

# 비용과 작업 안내
경첩 조정, 클로저 조절, 클로저 교체 가운데 무엇이 필요한지 보고 비용을 손대기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작합니다.
잠긴 문을 여는 경우 끝내 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html), 문 여는 방식은 [현관문 개문](door-open.html)에 있습니다.
걸쇠가 이미 닳았다면 [도어락 수리](doorlock-repair.html)를, 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.
