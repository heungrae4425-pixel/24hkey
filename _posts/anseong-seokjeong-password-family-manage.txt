# 번호를 바꿨는데 가족 한 명이 모르고 있었다
누군가 비밀번호를 새로 바꿨는데 그 소식을 못 들은 가족이 늦은 밤 문 앞에서 막히는 일은 의외로 자주 생깁니다. / 안성 시내 쪽 석정동처럼 주택과 상가 건물이 섞인 동네에서는 가게 일과 집안일이 겹쳐 가족마다 귀가 시간이 제각각인 집도 많습니다.
번호를 바꾸는 일보다 어려운 것은 바꾼 번호를 모두가 제때 알게 하는 일입니다. / 이 글은 석정동 가정에서 도어락 비밀번호를 언제 바꾸면 좋은지, 어떻게 나누고 기록할지 집안 규칙을 만드는 방법을 정리했습니다.
문 앞에서 이미 막혔다면 [안성 출장열쇠](anseong.html)로 연락 주시면 됩니다.
@ 석정동 가족 도어락 비밀번호 변경 공유

# 번호를 바꾸면 좋은 때
아무 일 없이 몇 해씩 같은 번호를 쓰는 집도 많습니다. / 아래 같은 일이 있었다면 그때가 번호를 바꾸기 좋은 때입니다.
- 공사나 수리로 다른 사람에게 번호를 알려 준 뒤
- 함께 살던 가족이 독립하거나 이사 나간 뒤
- 번호판 특정 숫자만 유난히 닳아 보일 때
- 누군가 뒤에서 번호를 보고 있었던 것 같을 때
꼭 정해진 주기가 있는 것은 아닙니다. / 계절이 바뀔 때나 배터리를 갈 때처럼 집안에서 기억하기 쉬운 때를 정해 두면 잊지 않고 챙길 수 있습니다.

# 바꾸는 사람을 한 명으로 정하기
가족 누구나 번호를 바꿀 수 있으면 서로 모르는 사이에 번호가 바뀌는 일이 생깁니다. / 번호 변경은 한 사람이 맡고, 바꾸기 전에 가족에게 미리 알리는 것을 규칙으로 정해 두세요.
맡은 사람이 바꾸는 날은 가능하면 가족이 대부분 집에 있는 날로 잡습니다. / 저녁 식사 자리에서 새 번호를 함께 정하면 따로 알리지 않아도 됩니다.
출장이나 야간 근무로 그날 집에 없는 가족이 있다면 그 사람이 돌아오는 날까지 바꾸기를 미루는 것도 방법입니다. / 하루 이틀 늦어지는 것보다 한 사람이 문 앞에서 막히는 편이 훨씬 번거롭습니다.

# 새 번호는 이렇게 정합니다
새 번호는 가족 모두가 기억할 수 있으면서 남이 짐작하기 어려워야 합니다. / 집 주소, 전화번호 뒷자리, 생일, 같은 숫자를 늘어놓은 번호는 피해 주세요.
가족만 아는 일과 이어진 숫자를 고르면 기억하기 쉽습니다. / 예를 들어 함께 간 여행지의 기억이나 가족끼리만 아는 숫자를 조합하는 방식입니다.
번호 앞뒤로 아무 숫자나 붙여 눌러도 열리는 기능이 있다면 가족 모두에게 알려 주세요. / 번호판에 남는 손자국을 흐려 주는 데 도움이 됩니다.
@ 석정동 도어락 새 비밀번호 가족 회의

# 새 번호를 알리는 방법
가족 단체 대화방에 번호를 그대로 올리는 것은 피하는 편이 좋습니다. / 휴대폰을 잃어버리거나 대화방에 다른 사람이 들어오면 번호까지 함께 퍼집니다.
직접 얼굴을 보고 말해 주거나, 꼭 문자로 보내야 한다면 받은 사람이 외운 뒤 지우도록 부탁하세요. / 번호와 집 주소를 한 메시지에 함께 적지 않는 것도 중요합니다.
번호를 알렸다면 받은 사람이 알았다고 답을 하도록 해 두세요. / 누가 아직 모르는지 한눈에 보여서 빠뜨리는 사람이 없습니다.

# 어르신과 아이에게 알릴 때
어르신은 새 번호에 익숙해지기까지 시간이 걸리십니다. / 바꾼 첫 주에는 함께 문 앞에서 몇 번 직접 눌러 보시게 하면 혼자 계실 때 당황하지 않으십니다.
아이에게 번호를 알려 줄 때는 친구에게 말하지 않기로 약속해 두세요. / 친구와 함께 들어올 때는 번호판을 손으로 가리고 누르는 습관도 같이 알려 주면 좋습니다.
번호를 자꾸 잊는 아이라면 번호 대신 카드나 지문을 함께 쓰는 것도 방법입니다.

# 기록은 집 안 한곳에만
번호를 잊을까 걱정되면 종이에 적어 두는 것도 괜찮습니다. / 다만 현관 근처, 신발장, 지갑처럼 번호와 집이 함께 떠오르는 곳은 피하고 집 안 서랍처럼 정해 둔 한곳에만 두세요.
지난 번호는 바꾼 뒤 바로 지워 두는 것이 좋습니다. / 옛 번호와 새 번호가 함께 적혀 있으면 오히려 헷갈립니다.
휴대폰 메모에 적는다면 메모 제목에 도어락이나 현관 같은 말을 쓰지 마세요. / 가족만 알아볼 수 있는 이름으로 저장해 두는 정도면 충분합니다.

# 바꾼 날 꼭 확인할 것
- 문을 열어 둔 채로 번호를 바꾸기
- 바꾼 뒤 밖에서 새 번호로 직접 열어 보기
- 예전 번호가 정말 안 먹히는지 확인하기
- 가족 모두에게 알렸는지 한 번 더 확인하기
문을 닫은 채로 번호를 바꾸다 잘못 누르면 바깥에서 들어갈 방법이 사라질 수 있습니다. / 바꾸기 전에 배터리가 충분한지도 함께 보세요.

# 가게와 집을 같이 쓰는 경우
건물 아래층이 가게이고 위층이 집인 경우 가게 직원이 집 번호를 알게 되는 일이 생기기도 합니다. / 가게 출입문과 집 현관 번호는 꼭 다르게 정해 두세요.
직원이 바뀔 때마다 가게 번호를 바꾸는 규칙을 따로 두면 집 번호는 자주 바꾸지 않아도 됩니다.
가게 일을 마치고 계단으로 집에 올라가는 구조라면 가게 번호를 누르던 손이 집 번호를 헷갈리기도 합니다. / 두 번호의 자릿수나 시작 숫자를 다르게 해 두면 덜 헷갈립니다.

# 막혔을 때 연락 주시면
새 번호를 못 들어서, 혹은 바꾸다 꼬여서 문이 안 열린다면 연락 주세요. / 아래 내용을 알려 주시면 맞춰 준비합니다.
- 석정동 위치와 주택, 빌라, 상가 위층 중 어떤 집인지
- 번호를 언제 누가 바꿨는지
- 번호판 상태와 도어락 사진
가족과 연락이 닿는다면 새 번호를 다시 물어보는 것이 가장 빠릅니다. / 그래도 안 되면 문을 열고 새 번호 등록까지 함께 도와드립니다.

# 거주 확인과 금액 안내
문을 열기 전에 사시는 분인지 신분증 주소, 주소가 적힌 우편물, 집주인 확인 가운데 하나로 확인합니다. / 가족이라도 확인 절차는 똑같이 거칩니다.
무엇을 할지와 금액은 시작 전에 말씀드리고, 끝내 열지 못하면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html), 여는 방법은 [현관문 개문](door-open.html)에 있습니다.

# 번호 관리가 계속 어렵다면
가족이 많고 귀가 시간이 제각각이라 번호 관리가 늘 번거롭다면 사람마다 카드나 지문을 따로 등록하는 방식이 편할 수 있습니다. / 지금 도어락에 그런 기능이 없다면 [도어락 교체](doorlock-replace.html)를 상의해 보세요.
번호 등록이 자꾸 실패하거나 설정이 저절로 지워진다면 [도어락 수리](doorlock-repair.html)로 먼저 점검을 받아 보시는 게 좋습니다.

# 석정동 이웃 동네도 다닙니다
