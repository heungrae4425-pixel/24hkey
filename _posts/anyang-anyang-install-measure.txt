# 안양동에서 도어락을 달기 전에
안양동은 안양역 가까이 오래된 건물과 주택이 많고, 문 종류도 집마다 다릅니다. / 도어락을 사 두었는데 막상 달려고 보니 문에 안 맞는 일이 생각보다 자주 있습니다.
이 글은 설치 전에 직접 확인해 볼 수 있는 항목과 [도어락 설치](doorlock-install.html)를 맡길 때 알려주면 좋은 정보를 정리했습니다. / 사기 전에 읽으시면 헛걸음을 줄일 수 있습니다.
@ 안양동 도어락 설치 전 확인 출장열쇠

# 제일 먼저 문 두께를 확인하세요
도어락은 문 두께에 따라 맞는 제품이 다릅니다. / 문이 너무 얇거나 두꺼우면 부속이 모자라거나 헐겁게 달립니다.
줄자로 문 옆면의 두께를 재 보시고 숫자를 메모해 두세요. / 같은 건물이라도 층마다 문이 다를 수 있으니 우리 집 문을 직접 재시는 게 정확합니다.
정확한 숫자를 모르시면 문 옆 사진을 찍어 보내주셔도 됩니다.

# 문 재질을 알아 두세요
철문인지 나무문인지, 안이 비어 있는 문인지에 따라 달리는 방식이 다릅니다. / 오래된 건물은 나무문과 철문이 섞여 있습니다.
문을 손으로 두드려 소리가 울리는지 묵직한지 확인해 보세요. / 확실하지 않으면 사진으로 보여주셔도 알아봅니다.
재질에 따라 구멍을 새로 뚫어야 할 수도 있어서 미리 알려주시면 준비가 수월합니다.

# 보조키와 문 안쪽 구멍 확인
기존에 보조키가 있는지, 손잡이형 잠금이 있는지 확인하세요. / 기존 구멍 위치에 따라 새 도어락이 그대로 들어갈 때도 있고 안 맞을 때도 있습니다.
안쪽 손잡이와 바깥 손잡이가 한 몸인 형태인지 따로 달린 형태인지도 봐 주세요. / 이 정보를 알려주시면 맞는 제품을 추천해 드립니다.
@ 안양동 현관문 도어락 설치 출장

# 문틀과 문 사이 간격 보기
문이 닫힐 때 문틀과 맞는지, 틈이 너무 크지는 않은지 확인해 보세요. / 문이 처져 있으면 새 도어락을 달아도 잠금이 어긋납니다.
이 경우 설치와 함께 경첩 점검을 같이 하는 게 좋습니다. / 설치만 하고 나서 문제가 남는 일을 줄여 줍니다.
문이 닫힐 때 걸림이 있다면 전화로 먼저 말씀해 주세요.

# 어떤 방식이 맞는지 고르는 기준
번호만 쓸지, 카드나 지문까지 쓸지는 가족 구성과 생활 습관에 따라 다릅니다. / 아이가 있거나 짐이 많은 집은 손을 쓰기 어려워 카드나 지문이 편합니다.
처음 달아 보는 분이라면 번호 방식과 카드 방식을 함께 쓰는 제품을 많이 고릅니다. / 자세한 건 [도어락 교체](doorlock-replace.html) 페이지에도 적어 두었습니다.

# 사 둔 제품이 있을 때
이미 구입한 제품이 있으면 모델명과 사진을 보내주세요. / 문에 맞는지 먼저 확인해 드립니다.
맞지 않으면 설치 전에 말씀드리고 다른 방법을 안내합니다. / 안 맞는 제품을 억지로 달지는 않습니다.
사 두신 제품이 없으면 어떤 방식이 좋을지부터 상담해 드립니다.

# 전화하실 때 알려주실 것
문 사진과 두께, 기존 도어락 유무를 알려주시면 좋습니다. / 몇 층이고 어느 동네인지도 함께 말씀해 주세요.
- 문 두께와 재질
- 기존 도어락이 있는지 보조키 위치
- 원하는 방식(번호, 카드, 지문)
- 사 둔 제품이 있는지
- 방문 희망 시간

# 방문하면 이렇게 진행합니다
먼저 문 상태를 보고 설치가 가능한지 확인합니다. / 가능하면 비용을 먼저 말씀드리고 괜찮다고 하시면 시작합니다.
기존 도어락을 떼어 내고 새 도어락을 달아 번호와 카드를 등록합니다. / 등록이 끝나면 여러 번 열고 잠가 보며 확인합니다.
설치가 어려운 문이면 이유를 설명하고 다른 방법을 안내합니다.

# 설치가 끝나면 같이 해 보는 일
문을 열고 닫으며 잠금이 정확히 들어가는지 확인합니다. / 번호는 가족과 함께 정하고 카드나 지문을 등록합니다.
새 배터리를 확인하고 경고음이 나는 상황도 설명해 드립니다. / 안내가 끝나야 설치가 끝난 것이라고 생각합니다.
@ 안양동 24시 출장열쇠 도어락 설치 후 확인

# 문을 못 열어 설치가 불가능한 경우
오래된 문은 구멍이 너무 크거나 문 자체가 상해 있기도 합니다. / 그럴 땐 억지로 달지 않고 보강이나 다른 방법을 말씀드립니다.
문 때문에 막힐 때는 [도어락 수리](doorlock-repair.html)나 문 점검을 먼저 권하기도 합니다. / 끝내 설치할 수 없는 상황이면 비용은 받지 않습니다.

# 설치 뒤에 오래 쓰는 법
배터리는 해가 바뀔 때 한 번에 교체하고 경고음이 나면 바로 바꿉니다. / 번호는 가족 외에 알려주지 않고, 바꿀 때는 새 번호만 남깁니다.
카드는 하나를 따로 보관해 두면 만약의 경우에 도움이 됩니다. / 가끔 번호판을 닦아 주면 반응이 깨끗하게 유지됩니다.

# 안양동 말고 안양 어디든
안양동 옆 석수동, 박달동, 비산동, 평촌동까지 24시간 다닙니다. / 안양역 근처가 아니어도 안양 안이면 위치만 알려주세요.
[안양시 출장열쇠](anyang.html)에서 다니는 동네를 볼 수 있습니다. / [출장 지역](area.html) 지도에서 다른 지역도 확인하세요.
