# 어제까지 되던 앱이 갑자기 먹통일 때
안양동은 안양역을 끼고 출퇴근하는 분이 많아 외출이 잦은 동네입니다. / 집을 비운 사이에도 문이 열렸는지 휴대폰으로 확인하려고 앱 연동 도어락을 쓰는 가정이 늘었습니다.
그런데 어느 날부터 알림이 안 오거나 앱에서 문이 응답하지 않으면 당황스럽습니다. / 이 글은 안양동에서 연동이 끊겼을 때 집에서 직접 해볼 수 있는 순서를 정리한 것입니다.
먼저 문 자체가 열리는지부터 확인하세요. / 번호나 카드로 정상적으로 열린다면 잠금 기능은 멀쩡하고 통신 쪽만 문제인 경우가 대부분입니다.
@ 안양동 도어락 앱 연동 알림 오류 점검

# 문이 열리는지와 앱이 되는지는 별개입니다
앱 연동 도어락은 두 부분으로 나뉩니다. / 문을 실제로 잠그고 여는 도어락 본체와 그 상태를 휴대폰에 전해 주는 통신 부분입니다.
통신이 끊겨도 번호키와 카드는 그대로 작동하는 것이 보통입니다. / 그래서 앱이 안 된다고 해서 당장 문이 안 열릴 걱정을 하실 필요는 없습니다.
퇴근길 안양역에서 앱으로 문을 확인하려다 안 될 때도 일단 숨부터 돌리세요. / 집에 도착해서 번호로 열리는지 보는 것이 가장 빠른 확인입니다.
반대로 번호판 자체가 반응이 없으면 앱 문제가 아니라 배터리나 본체 문제입니다. / 이때는 연동 점검보다 도어락 전원을 먼저 확인하세요.

# 와이파이 공유기부터 의심해 보기
현관문 도어락은 집 안 공유기에 직접 붙거나 별도의 중계 장치를 거칩니다. / 공유기를 껐다 켰거나 인터넷 회사 점검이 있었다면 연결이 풀렸을 수 있습니다.
- 집 안 다른 기기는 와이파이가 잘 되는지
- 공유기 이름이나 암호를 최근에 바꾸지 않았는지
- 중계 장치의 불빛이 정상으로 켜져 있는지
- 공유기와 현관문 사이가 너무 멀지 않은지
현관은 집 끝에 있고 문이 철이라 신호가 약해지기 쉽습니다. / 중계 장치를 현관 가까운 콘센트에 꽂아 두면 안정적인 경우가 많습니다.

# 배터리가 줄어들면 통신부터 약해집니다
연동 기능은 일반 번호키보다 전기를 더 씁니다. / 배터리가 줄어들면 문 여는 기능은 버텨도 통신 쪽이 먼저 불안정해질 수 있습니다.
저전압 경고음이 한 번이라도 들렸다면 배터리를 새것으로 바꿔 보세요. / 배터리를 바꾼 뒤에 연동이 저절로 돌아오는 경우가 있습니다.
이때 일부만 바꾸지 말고 전부 같은 새 제품으로 바꾸는 게 좋습니다. / 오래된 것과 섞으면 전압이 맞지 않아 같은 일이 되풀이됩니다.
@ 도어락 배터리 교체 후 앱 재연결

# 휴대폰 쪽 설정도 같이 보세요
앱이 되지 않는 이유가 도어락이 아니라 휴대폰에 있는 경우도 꽤 있습니다. / 특히 휴대폰을 바꾸거나 업데이트한 직후라면 더 그렇습니다.
- 앱이 최신 버전인지
- 알림 권한이 꺼져 있지 않은지
- 절전 모드나 백그라운드 제한이 걸려 있지 않은지
- 같은 계정으로 로그인되어 있는지
알림만 안 오고 문은 앱으로 열린다면 십중팔구 알림 설정입니다. / 설정에서 해당 앱의 알림을 다시 허용해 보세요.

# 등록을 지우고 다시 하기 전에 알아둘 것
앱에서 기기를 삭제하고 다시 등록하면 해결되는 경우가 많습니다. / 하지만 방법에 따라 기존에 저장해 둔 가족 번호나 카드가 함께 지워질 수 있습니다.
도어락 본체에서 초기화까지 하면 등록된 번호가 모두 없어지는 제품도 있습니다. / 어떤 단계가 무엇을 지우는지 설명서나 안내를 확인하고 진행하세요.
확신이 없으면 앱 재등록 전에 번호키로 열리는지 먼저 확인하고, 필요한 번호는 따로 적어 두세요. / 안쪽에서 문이 열릴 수 있는 상태에서만 시도하는 게 안전합니다.

# 문 안에서 시도하세요, 문 밖에서는 안 됩니다
연동 설정을 만지다가 잘못되면 문이 잠긴 채 응답이 없는 상황이 생길 수 있습니다. / 그래서 설정은 되도록 집 안에서, 문을 열어 둔 채 하는 것이 좋습니다.
문을 닫고 밖에서 초기화 작업을 하다가 번호가 사라져 못 들어가는 일도 있습니다. / 이런 경우 열쇠나 다른 수단이 없다면 [현관문 개문](door-open.html)이 필요해집니다.
설정을 바꿀 때는 문을 한 번 열어 둔 상태에서 비상 수단을 손에 쥐고 하세요.

# 알림이 너무 많이 오거나 아예 안 올 때
알림 설정이 지나치게 민감하면 하루에도 수십 번 울려 결국 꺼 버리게 됩니다. / 반대로 모든 알림을 꺼 두면 정작 필요한 순간 모릅니다.
꼭 받고 싶은 것만 남기는 편이 오래갑니다. / 예를 들어 외출 중 문 열림과 배터리 부족 알림 정도면 충분한 경우가 많습니다.
여러 명이 같은 도어락을 쓰면 알림이 누구에게 가는지도 확인해야 합니다. / 가족 한 명만 받고 있었다면 그 사람 휴대폰이 바뀌었을 때 갑자기 안 오게 됩니다.

# 직접 해도 안 되면 이런 신호입니다
위 순서를 다 해봤는데도 안 된다면 본체나 통신 모듈의 고장일 수 있습니다. / 이 경우는 부품을 보고 판단해야 하니 사진과 증상을 전화로 먼저 알려주세요.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 먼저 [도어락 수리](doorlock-repair.html) 가능한지 보고, 너무 오래된 제품일 때만 교체를 말씀드립니다.
비용은 작업 전에 먼저 말씀드리고, 마음에 안 드시면 그냥 돌아갑니다.

# 문이 안 열리는 지경이라면
앱도 안 되고 번호도 안 먹힌다면 위치와 상황을 알려주세요. / 아파트 동 호수, 안양역 쪽인지 반대편인지, 번호판 상태를 말씀해 주시면 됩니다.
문을 열기 전에 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 연동을 다시 맞추는 것까지 같이 봐드립니다.
@ 안양동 출장열쇠 도어락 연동 복구

# 연동이 오래 가게 하는 평소 습관
연동 도어락은 한 번 설정해 놓고 잊어버리기 쉽습니다. / 그래서 몇 가지 습관만 들여도 먹통이 되는 일이 줄어듭니다.
- 배터리는 경고음이 나기 전에 해가 바뀔 때 한꺼번에 교체
- 공유기를 바꾸면 도어락 연결도 바로 확인
- 휴대폰을 바꾸기 전에 도어락 앱 계정을 정리
- 연동이 되든 안 되든 번호키 비상 수단은 항상 확보
설정 방법은 사진으로 찍어 두거나 메모해 두면 나중에 편합니다. / 가족이 함께 쓴다면 누가 어떤 번호와 계정을 쓰는지도 한 번 정리해 두세요. / 사용자가 늘고 줄 때마다 등록을 정리하는 습관이 불필요한 오류를 막아 줍니다.

# 안양동 말고 안양 어디든 갑니다
안양동 옆 석수동, 박달동, 비산동, 호계동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
동네별 안내는 [안양시 출장열쇠](anyang.html) 페이지에, 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에 있습니다. / 진행 순서는 [이용안내](guide.html)에서 볼 수 있습니다.
