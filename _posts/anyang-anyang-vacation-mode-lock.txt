# 번호는 맞는데 문이 안 열린다면 모드를 의심하세요
안양동은 안양역 가까이에서 오가는 분들이 많은 동네이고, 빌라와 오피스텔, 주택이 섞여 있습니다. / 번호를 정확히 눌렀는데도 문이 안 열리고 경고음만 나면 고장이라 생각하기 쉽습니다.
그런데 도어락 중에는 외출 모드, 휴가 모드, 잠금 유지 모드 같은 기능이 있어서 켜져 있으면 바깥 번호판으로는 열리지 않습니다. / 이 글은 안양동에서 이런 모드 때문에 문이 안 열릴 때 해제하는 방법과 [안양 출장열쇠](anyang.html)를 부르는 순서를 정리한 것입니다.
@ 안양동 도어락 외출 모드 표시등이 켜진 모습

# 외출 모드와 휴가 모드가 뭔가요
외출 모드는 집을 비울 때 바깥 번호 입력을 막아 두는 기능입니다. / 휴가 모드나 장기 부재 모드도 비슷하게, 일정 기간 번호로 못 열게 하고 열쇠나 관리자 방법으로만 열리게 합니다.
- 가족이 모르고 켜 놓고 나간 경우
- 아이가 버튼을 눌러 켜 버린 경우
- 앱으로 설정해 두었다가 잊은 경우
- 여행 전에 켜 두고 돌아와서 해제하지 않은 경우
제품마다 이름과 표시 방식이 다릅니다.
어떤 제품은 모드가 켜지면 안쪽에서도 손잡이로만 열리고 바깥 번호는 완전히 막힙니다. / 그래서 안에 사람이 없으면 열쇠나 관리자 방법 없이는 들어가기 어렵습니다.

# 모드가 켜졌는지 알아보는 방법
- 번호판에 평소와 다른 표시등이 켜져 있는지
- 번호를 눌렀을 때 짧은 경고음이나 안내 음성이 나오는지
- 안쪽 손잡이 근처에 모드 버튼이 있는지
- 앱 알림에 외출·휴가 모드 표시가 남아 있는지
모드가 켜진 도어락은 번호가 맞아도 열리지 않고 같은 소리만 반복하는 경우가 많습니다.

# 해제 방법은 제품마다 다릅니다
많은 제품은 바깥에서 관리자 번호나 마스터 코드로 모드를 풀 수 있습니다. / 열쇠 구멍이 있는 제품은 열쇠로 문을 연 뒤 안쪽에서 모드 버튼을 끄면 됩니다.
카드나 지문으로 해제가 되는 제품도 있으니 설명서에서 모드 해제 항목을 확인해 보세요. / 설명서가 없으면 제조사와 모델 이름을 알려 주시면 방법을 안내해 드립니다.

# 번호를 계속 누르면 오히려 막힙니다
열리지 않는다고 번호를 여러 번 입력하면 오입력 횟수가 쌓여 입력이 한동안 잠깁니다. / 모드가 원인이었다면 추가로 잠금이 걸려 더 복잡해집니다.
서너 번 해보고 안 되면 멈추고 표시등이나 소리를 살펴 주세요. / 문을 세게 당기거나 흔드는 것도 걸쇠에 무리를 줍니다.
모드가 켜진 상태는 도어락이 정상적으로 일하고 있는 것이라 힘으로 풀려 하면 오히려 문과 부품이 상합니다. / 표시등이 어떤 모양인지만 기억해 두셔도 상담이 빨라집니다.
@ 안쪽 손잡이 근처 모드 설정 버튼

# 가족에게 먼저 확인해 보세요
집 안에 있는 가족이 안쪽에서 문을 열 수 있는지 먼저 확인해 보세요. / 안에서 열리면 모드 때문인지 고장인지 구분이 쉬워지고 바로 해제할 수 있습니다.
가족이 같은 모드를 켠 적이 있다면 이름이나 방법을 물어보는 것이 가장 빠릅니다. / 함께 사는 사람들끼리 모드 사용 규칙을 정해 두면 재발이 줄어듭니다.
오피스텔이나 빌라처럼 출입 횟수가 많은 집은 가족이 서로 모드를 켠 줄 모르고 나가는 일이 흔합니다. / 현관에 작은 메모를 붙여 두는 것도 소박하지만 확실한 방법입니다.

# 건전지가 약하면 모드처럼 보일 수 있습니다
건전지가 거의 다 되면 번호판이 불규칙하게 반응해 모드 오류처럼 보일 수 있습니다. / 번호판이 어둡거나 경고음이 평소보다 잦으면 건전지부터 의심해 보세요.
9V 건전지를 비상 단자에 대면 임시로 전원이 들어와 번호를 누를 수 있는 제품도 있습니다. / 단자가 없거나 건전지를 대도 반응이 없으면 연락 주세요.

# 출장열쇠에 연락할 때 알려주실 것
- 안양동 어느 방향 어느 건물인지, 몇 층 몇 호인지
- 번호판 표시등과 소리 (켜짐, 깜박임, 경고음)
- 최근에 모드나 설정을 만진 사람이 있는지
- 열쇠 구멍 유무
- 집 안에 아이나 반려동물이 있는지
번호판 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다. / 문을 여는 방식은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지부터 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로워도 이웃과 본인 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙고, 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 상하지 않게 열고 모드를 정리합니다
모드가 원인이면 도어락을 손상시키지 않고 열고 해제하는 것을 먼저 시도합니다. / 문이 열린 뒤에는 모드를 끄고 번호가 정상으로 열리는지 함께 확인합니다.
제품이 오래돼 모드 설정 자체가 불안정하면 [도어락 수리](doorlock-repair.html)로 먼저 점검하고, 필요할 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 모드를 해제한 도어락 번호판 점검

# 모드 때문에 다시 막히지 않게 하려면
한 번 겪고 나면 다음에는 훨씬 침착하게 대처할 수 있습니다. / 아래 습관은 어떤 제품에서도 쓸 수 있는 기본기입니다.
제품 설명서는 버리지 말고 사진으로 찍어 휴대폰에 저장해 두면 모드 해제 방법을 바로 찾을 수 있습니다. / 새 제품을 설치할 때는 모드 사용법을 가족 모두에게 한 번씩 알려 주세요.
- 외출 모드를 쓰는 가족은 사용 규칙을 정해 두기
- 모드 표시등이 어떤 모양인지 가족이 함께 확인
- 앱 알림에서 모드 변경 기록을 가끔 보기
- 휴가 모드를 켰다면 돌아오는 날 해제 일정 적어 두기
- 비상용 열쇠 위치를 모든 가족이 알아 두기
특히 연휴나 여행 뒤에 돌아와 문이 안 열릴 때 모드를 먼저 떠올리면 시간을 아낄 수 있습니다.

# 안양동 말고 안양 어디든 갑니다
안양동 가까이 석수동, 부흥동, 박달동, 호계동, 비산동도 다닙니다. / 안양 안이면 어느 동네든 24시간 출동합니다.
다니는 곳은 [안양시 출장열쇠](anyang.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
