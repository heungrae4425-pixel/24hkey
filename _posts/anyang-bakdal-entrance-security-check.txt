# 불안해하기보다 한 번 점검해 보세요
박달동은 안양역을 이용하는 분들이 많은 생활권이라 출퇴근 시간대에 집이 비는 가구가 많습니다. / 집을 비운 사이 현관이 안전한지 궁금해지는 것은 자연스러운 마음입니다.
이 글은 겁을 주려는 글이 아닙니다. / 현관문을 직접 확인해 볼 수 있는 항목을 차분하게 순서대로 정리한 점검표입니다.
혼자 해결하기 어려운 부분은 [안양 출장열쇠](anyang.html)에 문의하시는 방법도 마지막에 적었습니다.

# 문을 닫고 한 번 당겨 보는 습관
퇴근길이든 외출길이든 문을 닫은 뒤 손잡이를 한 번 당겨 보는 습관이 가장 간단한 점검입니다. / 문이 완전히 닫혀 잠겼는지 눈으로 보는 것보다 손으로 확인하는 편이 정확합니다.
자동으로 잠기는 제품이라도 문이 덜 닫히면 잠금이 되지 않을 수 있습니다. / 잠금 소리를 들었다면 확실히 잠긴 것입니다.
반대로 소리가 평소보다 작거나 짧다면 모터 힘이 약해졌다는 뜻일 수 있습니다. / 한 번 더 확인해 보고 이상하면 건전지부터 바꿔 보세요.
@ 박달동 현관문 도어락과 잠금 확인

# 도어락이 보내는 이상 신호들
도어락은 고장 나기 전에 작은 신호를 먼저 보냅니다.
- 평소보다 번호 입력 반응이 느려졌다
- 잠금이나 해제 소리가 달라졌다
- 번호를 눌렀는데 가끔씩 한 번 더 눌러야 열린다
- 건전지를 갈았는데도 경고음이 난다
이런 신호를 지나치지 않는 것이 점검의 핵심입니다.
신호가 한 번 보였다고 바로 고장이라고 단정할 필요는 없습니다. / 같은 증상이 사나흘 이어지는지 지켜보고, 건전지를 새것으로 갈아 본 뒤에도 그대로라면 점검을 요청하세요. / 오작동하는 도어락은 문을 잠그고 나가도 제대로 잠기지 않았을 수 있습니다.
그래서 외출 전에 한 번 더 확인하는 습관이 더욱 중요합니다. / 잠금 표시등이 켜졌는지 눈으로 보는 것도 방법입니다.

# 문틀과 걸쇠가 맞물리는 부분 살펴보기
문 옆면의 쇠 막대가 문틀 구멍에 깊이 들어가야 잠금이 단단합니다. / 문이 처지거나 틀어지면 막대가 구멍에 얕게 걸리게 됩니다.
문틀 구멍 쪽에 긁힌 자국이 있는지, 막대가 닿는 위치가 한쪽으로 쏠려 있는지 살펴보세요.
문과 문틀 사이 틈이 위아래로 고른지도 함께 보면 좋습니다. / 틈이 고르지 않다면 [도어락 수리](doorlock-repair.html) 때 함께 손볼 수 있습니다.
문을 닫을 때 손잡이를 위로 들어야만 잠긴다면 이미 막대가 구멍 가장자리에 걸리고 있다는 뜻입니다. / 이런 습관이 몸에 배면 문제를 모른 채 지나가므로 가족에게도 알려주세요.

# 번호 노출을 줄이는 작은 방법
번호판에 손가락 자국이 남아 자주 누르는 숫자가 드러나는 경우가 있습니다. / 가끔 마른 천으로 번호판을 닦아 주면 좋습니다.
번호를 누를 때 손으로 가리는 습관도 도움이 됩니다. / 엘리베이터 앞이나 복도에서 누군가 뒤에 서 있을 때는 잠시 기다렸다가 누르세요.
오래 쓴 번호는 한 번씩 바꿔 주세요. / 번호를 바꾼 뒤에는 가족 모두에게 알리는 것을 잊지 마세요.

# 열쇠 구멍과 보조키, 쓰임을 정해 두기
번호키만 쓰고 열쇠 구멍은 거의 쓰지 않는 집이 많습니다. / 열쇠 구멍은 비상용이니 열쇠가 어디에 있는지 가족이 알고 있는 것이 중요합니다.
보조키는 집에 있을 때와 장시간 외출할 때 쓰는 용도를 정해 두면 잠금 사고가 줄어듭니다.
- 외출 시에는 주 도어락만 사용
- 밤에는 보조키까지 잠그기
- 아침에 보조키 푸는 것을 잊지 않기
@ 열쇠 구멍과 보조키 점검

# 현관 주변 환경도 같이 보세요
문 주변이 어두우면 불안한 마음이 커집니다. / 센서등을 달거나 전구를 밝은 것으로 바꾸는 것만으로도 체감이 달라집니다.
현관 앞에 우편물이나 광고지가 쌓여 있으면 집이 오래 비었다는 인상을 줄 수 있습니다. / 여행 중에는 이웃이나 가족에게 치워 달라고 부탁해 두세요.
문 안쪽에 모르는 사이 붙은 스티커나 표시가 없는지도 가끔 확인합니다. / 이상한 점이 있으면 관리사무소에 알리세요.
현관 중문이나 신발장 위에 열쇠나 카드키를 놓아 둔 위치가 바깥에서 보이지 않는지도 생각해 보세요. / 현관 센서등이나 우편함 주변의 밝기도 함께 확인하면 좋습니다.

# 이런 경우에는 점검을 부탁하세요
스스로 확인해 봐도 잘 모르겠거나 고쳐야 할 것 같으면 전문가의 눈이 필요합니다.
- 문이 닫혔는데도 잠금 소리가 안 난다
- 도어락 덮개가 헐겁거나 흔들린다
- 열쇠 구멍에 열쇠가 뻑뻑하게 들어간다
- 이사 후 전 주인이 쓰던 번호가 남아 있을 수 있다
이런 경우에는 점검을 맡기는 편이 마음이 편합니다. / 필요한 것만 말씀드리고 과한 교체는 권하지 않습니다.
점검 결과는 눈에 보이는 상태로 하나씩 설명드립니다. / 문제가 없다면 없다고 솔직하게 말씀드리고 돌아갑니다.

# 점검을 부탁하실 때 알려주실 내용
- 박달동 어느 쪽인지, 건물 이름과 층, 호수
- 도어락 종류(번호키, 카드키 등)
- 이상하다고 느낀 증상과 시작된 시기
- 사진 한두 장
상담만 해도 되고, 점검이 필요하면 방문하는 시간을 정할 수 있습니다. / 급하지 않은 일이라면 낮 시간에 맞춰 보겠습니다.
도어락 사진을 미리 보내주시면 필요한 부품을 챙겨 가기 쉽습니다. / 안양 어디든 같은 방식으로 진행합니다.

# 방문하면 먼저 사시는 분인지 확인합니다
문과 도어락을 만지는 일이라 거주자 확인이 필요합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소의 세대 확인 중 하나면 됩니다.
이 절차는 이웃과 거주자 모두를 위한 것이라 반드시 거칩니다. / 어려우시면 관리사무소에 문의해 주세요.
@ 점검 전 신분 확인

# 비용은 점검 전에 먼저 말씀드립니다
점검과 수리가 어떤 범위인지 먼저 설명드리고 비용을 말씀드립니다. / 동의하시면 진행하고, 아니면 그냥 돌아갑니다.
문을 열어야 하는 상황에서 끝내 열지 못하면 비용은 받지 않습니다. / 작업 중 부품이 필요하면 바꾸기 전에 다시 여쭙습니다.
진행 순서는 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 점검 뒤 습관으로 이어 가는 법
- 건전지는 해마다 한 번 전부 교체
- 번호는 가족과 합의해 정기적으로 변경
- 문 닫힘과 잠금 소리를 가끔 귀 기울여 듣기
- 도어락 덮개 나사가 풀렸는지 눈으로 확인
- 낯선 소리나 경고음은 그날 바로 확인
한꺼번에 다 하려 하지 말고 한 가지씩 습관으로 만들어 보세요. / 몇 달이면 자연스러워집니다.
가족 모두가 같은 기준으로 움직이도록 현관 안쪽에 점검 메모를 붙여 두는 방법도 있습니다. / 아이가 있는 집은 아이와 함께 문 닫는 습관을 만들어 보세요.

# 박달동 밖 안양 어디든 갑니다
박달동 가까이 석수동, 비산동, 안양동, 호계동도 다닙니다. / 안양 안이면 24시간 어느 동네든 출동합니다.
동네 정보는 [안양시 출장열쇠](anyang.html)에 있고, 서울과 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
