# 박달동 이사 날, 문 앞에서 제일 먼저 할 일
박달동으로 이사 들어오는 날은 짐이 많고 정신이 없어서 현관문 점검이 맨 뒤로 밀립니다. / 그런데 새 집에서 가장 먼저 만지는 물건이 현관문이라, 이날 한 번만 봐 두면 나중에 문 앞에서 당황할 일이 크게 줄어듭니다.
이 글은 박달동에서 입주하거나 퇴거할 때 도어락과 열쇠를 어떻게 정리하면 좋은지 순서대로 적었습니다. / 이사 중에 문이 잠겨 버렸을 때 [안양 출장열쇠](anyang.html)를 부르는 방법도 뒤쪽에 넣어 두었습니다.
@ 박달동 이사 입주 도어락 확인 출장열쇠

# 입주 전에 도어락을 먼저 보는 이유
전에 살던 분이 쓰던 번호가 그대로 남아 있을 수 있습니다. / 번호를 모르는 사람이 열 수 있는 상태로 새 생활을 시작하는 것은 불안하니, 입주 첫날 새 번호로 바꿔 두는 것이 기본입니다.
도어락이 오래됐거나 부품이 낡았다면 이사한 첫 주에 고장 나는 경우도 있습니다. / 짐을 다 들인 뒤에 문제가 생기면 오가기 불편하니, 입주 전에 점검해 두면 훨씬 편합니다.
관악산 자락이나 범계역 방향으로 오가는 길이 멀다면 더 그렇습니다. / 한 번 문제가 생기면 다시 나갔다 들어오는 데 시간이 꽤 드니까요.

# 이전 거주자가 등록한 번호와 카드 지우기
도어락에는 비밀번호뿐 아니라 카드키와 태그, 지문이 따로 등록되어 있을 수 있습니다. / 번호만 바꾸고 카드나 지문을 그대로 두면 이전 거주자의 카드로 열리는 경우가 생깁니다.
대부분의 도어락은 설정 모드에서 등록 정보를 모두 지우고 새로 등록할 수 있습니다. / 방법은 제품마다 다르니 설명서나 도어락 안쪽 덮개 안의 안내를 먼저 확인해 보세요.
설명서가 없고 방법을 모르겠다면 사진을 찍어 두었다가 전화 주시면 됩니다. / 초기화하는 순서를 같이 확인해서 말씀드립니다.

# 열쇠가 몇 개인지 먼저 세어 보세요
도어락 아래에 열쇠구멍이 있는 제품은 비상 열쇠가 함께 오기도 합니다. / 입주할 때 받은 열쇠가 몇 개인지, 모두 문에 맞는지 한 번씩 꽂아 보세요.
열쇠가 하나도 없는 경우도 있습니다. / 비상 열쇠 없이 쓰는 도어락이라면 배터리가 나갔을 때 방법이 한정되니, 9V 건전지를 비상용으로 챙겨 두는 것이 좋습니다.

# 배터리는 입주 날 새것으로 바꿔 두기
남은 배터리가 얼마나 되는지는 겉으로 알기 어렵습니다. / 비어 있던 집이라면 그동안 조금씩 닳았을 수 있어서 새것으로 한 번에 갈아 두는 편이 마음 편합니다.
일부만 바꾸면 며칠 안에 경고음이 다시 울릴 수 있으니 전부 같은 종류로 같이 바꿔 주세요. / 교체한 날짜를 배터리 덮개 안쪽에 적어 두면 다음 교체 때 헷갈리지 않습니다.

# 문틀과 경첩, 잠금 상태 눈으로 확인
문이 끝까지 닫히는지, 닫았을 때 걸쇠가 문틀 구멍에 부드럽게 들어가는지 봅니다. / 걸쇠가 문틀에 걸려 뻑뻑하게 들어가면 문이 처졌다는 신호일 수 있습니다.
경첩 쪽에 헐거운 나사나 삐걱이는 소리가 있는지도 같이 들어 보세요. / 이런 문제는 도어락을 새로 바꿔도 계속 따라오니 입주 때 알아 두면 좋습니다.
@ 박달동 도어락 문틀 경첩 점검 안양 출장열쇠

# 새 비밀번호를 등록하는 순서
먼저 관리자나 설정 모드로 들어갑니다. / 이어서 기존 번호와 카드를 지우고, 새 번호를 등록한 뒤 몇 번 시험해 봅니다.
문을 열어 둔 채로 시험하는 것이 중요합니다. / 닫힌 상태에서 시험하다 번호가 안 맞으면 집 안팎에서 막히는 일이 생길 수 있으니, 문을 연 채 번호를 눌러 잠금과 해제를 확인해 주세요.
등록이 끝나면 새 번호를 가족에게 알려 주고, 한 사람씩 직접 눌러 보게 하면 확실합니다. / 이사 첫날 가족 중 한 명이라도 번호를 모르면 그 사람이 문 앞에서 기다리게 됩니다.

# 비밀번호는 이렇게 정하세요
생일이나 전화번호 뒷자리처럼 남이 짐작하기 쉬운 번호는 피합니다. / 가족이 외우기 쉬우면서도 외부 사람이 알기 어려운 조합이 좋습니다.
같은 번호를 여러 곳에서 쓰는 것도 피하는 편이 안전합니다. / 가족과 번호를 공유할 때는 문자 대신 직접 말해서 알려 주는 방법이 낫습니다.
@ 박달동 도어락 새 비밀번호 등록 24시 출장열쇠

# 퇴거할 때 정리할 것
나가는 날에는 내가 등록한 번호와 카드, 지문을 모두 지우는 것이 좋습니다. / 그래야 다음에 들어오는 분과 나 모두에게 안전합니다.
배터리는 빼지 않고 그대로 두고 나가는 것이 보통입니다. / 다만 도어락과 열쇠 처리는 집을 계약한 쪽과 미리 이야기해 두는 것이 안전하니, 임대인이나 중개한 곳에 먼저 물어보세요.

# 열쇠와 카드를 넘길 때 주의
열쇠와 카드를 넘길 때는 몇 개를 넘겼는지 사진이나 메모로 남겨 두세요. / 나중에 몇 개가 어디 있는지 서로 기억이 다를 때 확인하기 좋습니다.
복사해 둔 열쇠가 있다면 같이 넘기거나 정리해야 합니다. / 어디에 몇 개를 맡겼는지 기억나지 않으면 도어락 자체를 바꾸는 방법도 있습니다.
퇴거하는 날에는 도어락 앞면과 문 안쪽 모습을 사진으로 한 장씩 남겨 두세요. / 나중에 문 상태를 두고 이야기가 엇갈릴 때 확인할 자료가 됩니다.

# 도어락이 많이 낡았다면
이사 때 도어락이 너무 오래됐다면 고쳐 쓰기보다 새로 바꾸는 것이 마음 편할 때도 있습니다. / 이 판단은 직접 보고 말씀드리는 것이 정확하니 사진을 보내 주세요.
교체와 수리의 차이는 [도어락 교체](doorlock-replace.html)와 [도어락 수리](doorlock-repair.html) 페이지에 정리해 두었습니다. / 고쳐서 쓸 수 있으면 바꾸라고 권하지 않습니다.

# 이사 중에 문이 잠겨 버렸다면
짐을 나르다 문이 닫혀 열쇠도 번호도 통하지 않는 일이 이삿날에는 흔합니다. / 새로 등록한 번호를 적어 두지 않았거나, 배터리가 이미 다 닳은 경우가 많습니다.
이럴 때는 박달동 위치와 건물 상황, 번호판 상태를 알려 주세요. / 사시는 분이라는 확인을 어떤 자료로 할 수 있는지 전화로 같이 정합니다.
[현관문 개문](door-open.html) 방식은 문과 도어락이 상하지 않게 여는 쪽부터 해봅니다. / 짐이 쌓여 있어도 문 앞 공간만 비워 주시면 작업할 수 있습니다.

# 신분 확인과 비용 안내
입주하는 날이라 신분증 주소가 아직 예전 집일 수 있습니다. / 이 경우 계약서나 관리사무소 확인처럼 새 집에 사는 것을 알 수 있는 자료를 같이 보여 주시면 됩니다.
문을 열기 전에 비용을 먼저 말씀드립니다. / 못 열면 비용은 받지 않고, 열고 나서 말없이 붙는 비용도 없습니다. 자세한 순서는 [이용안내](guide.html)에 있습니다.
@ 박달동 퇴거 열쇠 카드 정리 안양 24시 출장열쇠

# 마무리

이사 중에 문이 잠기거나 도어락이 이상하면 24시출장열쇠로 전화 주세요. / 서울, 경기 전 지역 24시간, 010-3664-5455입니다. 다른 동네는 [출장 지역](area.html)에서 확인하세요.
