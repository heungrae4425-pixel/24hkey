# 박달동 룸메이트가 나가고 나서 제일 먼저 할 일
박달동에서 둘이나 셋이 같이 지내다가 한 명이 먼저 이사를 나가는 일은 흔합니다. / 안양역이나 인덕원역 쪽으로 출퇴근하며 방을 나눠 쓰던 분들이 특히 그렇습니다.
짐은 다 뺐는데 도어락에는 그 사람이 쓰던 번호와 카드가 그대로 남아 있습니다. / 이 글은 안양 박달동에서 룸메이트가 나간 뒤 비밀번호를 정리하는 순서를 적었습니다.
의심해서가 아니라 깔끔하게 마무리하기 위한 절차라고 생각하시면 마음이 편합니다. / 문이 안 열려 곤란하다면 [안양시 출장열쇠](anyang.html)에도 바로 연락하실 수 있습니다.
@ 박달동 룸메이트 퇴실 후 도어락 번호 정리

# 번호를 바꾸는 일은 예의 없는 게 아닙니다
같이 살던 사람에게 번호를 바꾼다고 말하기가 어색할 수 있습니다. / 하지만 사는 사람이 달라지면 출입 번호도 새로 정하는 것이 보통입니다.
나간 사람도 번호가 계속 살아 있으면 오히려 불편할 수 있습니다. / 집에 문제가 생겼을 때 괜한 오해를 받지 않기 위해서라도 정리해 두는 편이 서로 좋습니다.
나가는 쪽에서도 새 번호를 모르는 편이 오히려 홀가분합니다. / 집에 일이 생겨도 자기와는 상관없다고 말할 수 있기 때문입니다.
이사 나가는 날 짐을 옮기는 동안은 문을 자주 여닫으니 번호 정리는 짐이 다 빠진 뒤에 하는 편이 낫습니다. / 중간에 바꾸면 짐 나르는 사람이 문 앞에서 막히기 쉽습니다.

# 등록된 번호가 몇 개인지 먼저 파악하세요
도어락은 보통 번호를 여러 개 등록해 둘 수 있습니다. / 나간 룸메이트 번호 하나만 지우면 되는지, 공용 번호를 쓰고 있었는지부터 확인해야 합니다.
- 공용 번호 하나를 함께 쓰던 경우
- 사람마다 개인 번호를 따로 등록한 경우
- 카드키나 태그를 각자 하나씩 가진 경우
- 지문이나 스마트폰 연동을 쓰던 경우
어떤 방식이었는지에 따라 정리하는 방법이 달라집니다. / 모르겠으면 설명서나 제품 모델명을 먼저 찾아 보세요.
모델명은 보통 안쪽 본체 옆면이나 배터리 덮개 안쪽에 적혀 있습니다. / 사진으로 찍어 두면 전화로 상담할 때도 훨씬 빠릅니다.
같이 살던 사람들이 번호를 어떻게 정했는지 기억나지 않으면, 지금 쓰는 번호만 확실히 아는 상태에서 시작해도 됩니다. / 관리자 모드에 들어가는 방법만 알면 나머지는 순서대로 정리할 수 있습니다.

# 공용 번호 하나를 같이 썼다면
번호가 하나뿐이라면 통째로 새 번호로 바꾸는 방법밖에 없습니다. / 새 번호는 남은 사람들끼리만 알고 있도록 메시지 대신 직접 말해 알려 주세요.
생일이나 호수처럼 남이 짐작하기 쉬운 번호는 피하는 것이 좋습니다. / 이전 번호와 앞뒤 숫자만 바꾼 비슷한 번호도 아쉬운 선택입니다.

# 개인 번호를 따로 썼다면
개인 번호가 따로 있는 제품은 나간 사람 번호만 삭제할 수 있습니다. / 제품 설명서의 관리자 모드 항목에서 번호 삭제 순서를 확인하세요.
삭제하고 나서는 그 번호를 눌러 정말 열리지 않는지 한 번 시험해 보세요. / 시험할 때는 문을 열어 둔 채로 확인해야 만약의 경우에도 잠기지 않습니다.
@ 박달동 도어락 등록 번호 삭제 확인

# 카드키와 태그는 돌려받았는지 확인
카드키는 번호를 바꿔도 따로 등록이 남아 있을 수 있습니다. / 나간 사람이 가져간 카드가 있다면 돌려받거나 등록 자체를 지워야 합니다.
카드를 돌려받지 못했다면 전체 카드를 지우고 남은 사람 카드만 다시 등록하는 방법이 있습니다. / 이 과정은 제품마다 달라서 설명서대로 천천히 진행하세요.
카드를 잃어버렸을 때의 일반적인 방법은 [출장열쇠 부르기](key-call.html) 안내에도 정리했습니다.

# 현관 열쇠와 보조키도 잊지 마세요
번호만 신경 쓰다가 일반 열쇠 복사본이 나간 사람에게 있는 경우가 의외로 많습니다. / 보조키나 예전 열쇠를 같이 돌려받았는지 확인해 주세요.
돌려받지 못했거나 몇 개를 복사했는지 모르겠다면, 잠금장치 속을 바꾸는 방법도 있습니다. / 필요한 범위만 바꾸고 불필요한 교체는 권하지 않습니다.

# 새 룸메이트가 들어온다면
빈 방에 새 사람이 들어오면 번호를 한 번 더 정리해야 합니다. / 이전 사람과 새 사람의 번호가 섞이지 않도록 입주일에 맞춰 바꾸는 편이 깔끔합니다.
입주 첫날은 문을 자주 드나들기 때문에 임시 번호를 쓰다가 며칠 뒤 정식 번호로 바꿔도 됩니다. / 임시 번호를 쓴 사람이 있다면 쓴 뒤 바로 지워 주세요.

# 계약 관련 부분은 따로 이야기하세요
집주인이나 계약상 이야기는 도어락과는 별개입니다. / 보증금 정리나 계약 명의는 당사자끼리 먼저 풀어야 할 문제입니다.
도어락은 지금 그 집에 살고 있는 사람들이 안전하게 출입하기 위한 문제로 접근하면 대화가 부드럽습니다. / 저희는 법적인 판단은 하지 않고 문 열기와 도어락 정리만 도와드립니다.

# 비밀번호를 못 바꾸고 문이 안 열릴 때
번호를 바꾸려다 관리자 모드를 잘못 눌러 도어락이 먹통이 되는 경우가 있습니다. / 번호판이 안 켜지면 우선 9V 건전지를 비상 단자에 대 보세요.
그래도 안 열리면 억지로 두드리지 말고 연락 주세요. / 도어락 설정이 꼬였다면 [도어락 수리](doorlock-repair.html) 쪽으로 점검합니다.

# 새 번호를 정할 때는 이렇게
남은 사람들이 외우기 쉬우면서 짐작은 어려운 번호가 좋습니다. / 새로 들어오는 룸메이트가 있다면 그 사람에게도 입주 날 직접 알려 주세요. / 숫자를 여섯 개나 여덟 개처럼 길게 쓰는 제품은 가능한 한 길게 설정하세요.
- 번호는 서로 직접 말로 알리기
- 메모장이나 단체 대화방에 평문으로 올려 두지 않기
- 새 번호로 문이 잠기고 열리는지 두 번 이상 확인
- 석 달 정도 뒤에 한 번 더 바꿀지 정하기
방문하는 친구에게는 임시 번호를 따로 줄 수 있는 제품이면 그렇게 쓰는 편이 안전합니다.

# 오셔서 도와드릴 때는 이렇게 진행합니다
먼저 도어락 모델과 등록 상태를 보고 바꿔야 할 범위를 말씀드립니다. / 비용은 문 열기나 작업 전에 먼저 말씀드립니다.
문이 잠겨 안 열린다면 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 자세한 절차는 [이용안내](guide.html)에 있습니다.
@ 박달동 출장열쇠 도어락 비밀번호 재설정

# 박달동 말고 안양 어느 동네든 갑니다
평촌동, 비산동, 관양동, 호계동, 귀인동, 부흥동, 안양동, 석수동까지 다닙니다. / 범계역이나 평촌역 근처에서 연락 주셔도 같은 방식으로 진행합니다.
다른 지역은 [출장 지역](area.html)에서 확인해 보세요.
