# 문 앞에서 갑자기 울리는 삑 소리
비산동에서 범계역이나 안양역 쪽을 오가다 보면 퇴근 시간에 집 문 앞에서 도어락이 갑자기 울리는 일이 생깁니다. / 소리가 길게 나는지 짧게 나는지에 따라 뜻이 다르다는 걸 모르고 지나치는 분이 많습니다.
이 글은 도어락 경고음을 소리 모양별로 나눠서 무슨 뜻인지 정리한 글입니다. / 제품마다 조금씩 다르다는 점을 먼저 말씀드립니다.
소리를 구분해 두면 전화할 때 상황을 훨씬 정확하게 전달할 수 있습니다. / 전화 한 통으로 해결될지 직접 가서 봐야 할지도 빨리 가려집니다.

# 제품마다 소리 규칙이 다릅니다
도어락 소리는 제조사와 모델에 따라 의미가 조금씩 달라집니다. / 같은 두 번 울림이라도 어떤 제품은 잠김, 어떤 제품은 입력 오류를 뜻합니다.
아래 내용은 흔히 쓰이는 방식을 기준으로 한 것이니 참고용으로 읽어 주세요. / 정확한 뜻은 설명서나 안쪽 덮개 안의 안내 스티커에서도 확인할 수 있습니다.
설명서가 없다면 모델명이 적힌 부분만 사진으로 보내 주셔도 도움이 됩니다. / 문자로 사진을 받으면 맞는 부품을 챙겨 가기 좋습니다.

# 짧은 소리가 한 번 나는 경우
번호나 카드를 대고 짧게 삑 소리가 한 번 나면 대부분 입력이 들어갔다는 뜻입니다. / 문이 열리는 소리가 이어지면 정상이고, 열림 소리가 없으면 입력만 되고 모터가 안 돌았을 수 있습니다.
이때 손잡이를 돌려 보아 아무 반응이 없다면 걸쇠 쪽을 의심해 볼 수 있습니다. / 문을 안쪽으로 살짝 밀면서 다시 돌리면 풀릴 때도 있습니다.
같은 소리가 계속 반복되면 버튼이 눌린 상태로 걸려 있는지도 봐 주세요. / 번호판에 이물질이 끼어 눌려 있으면 실제로는 누르지 않았는데 소리가 날 수 있습니다.
@ 비산동 도어락 경고음 확인 출장

# 길게 이어지는 소리의 뜻
삐이 하고 길게 이어지는 소리는 보통 경고에 가깝습니다. / 배터리가 부족하다는 알림이거나 비밀번호를 여러 번 틀려 잠시 입력을 막았다는 알림인 경우가 많습니다.
배터리 부족이면 번호를 누를 때마다 같은 경고가 함께 나옵니다. / 이때는 문이 열리더라도 그날 바로 건전지를 새것으로 바꾸는 것이 좋습니다.
입력 잠금이면 한동안 기다린 뒤 다시 눌러야 합니다. / 급하다고 계속 누르면 잠금 시간이 오히려 길어질 수 있으니 잠시 멈춰 주세요.

# 여러 번 짧게 빠르게 울릴 때
삐삐삐 하고 짧게 여러 번 이어지는 소리는 제품에 따라 입력 오류나 문이 덜 닫혔다는 알림입니다. / 문이 끝까지 닫히지 않았는데 잠금을 시도했을 때 이 소리가 나는 경우가 있습니다.
문이 실제로 닫혔는지 한 번 더 확인하고, 문틀에 걸쇠가 걸리는지 보세요. / 경첩이 처져서 문이 조금씩 덜 닫히는 집이라면 이런 소리가 자주 납니다.
이 경우는 도어락보다 문 상태를 먼저 점검하는 쪽이 맞습니다. / 반복된다면 [도어락 수리](doorlock-repair.html) 전에 문틀부터 보는 것도 방법입니다.

# 모터 소리만 윙 하고 나는 경우
번호는 맞게 눌렀는데 안에서 윙 하고 돌아가는 소리만 날 때가 있습니다. / 모터는 도는데 걸쇠가 빠지지 않는 상태일 수 있습니다.
이때 손잡이를 억지로 꺾거나 문을 흔들어 보는 분이 있지만 부품이 더 상하기 쉽습니다. / 윙 소리가 나면 도어락은 살아 있다는 뜻이니 힘을 빼고 한 번 쉬었다가 다시 시도해 주세요.
몇 번 해도 같다면 내부 부품이나 문 상태 문제일 가능성이 있습니다. / 그때는 무리하지 말고 전화 주세요.

# 아무 소리도 나지 않는 경우
번호판은 켜지는데 눌러도 소리가 나지 않을 때는 스피커나 입력부 문제일 수 있습니다. / 불빛도 전혀 안 들어오면 배터리가 완전히 방전된 상태가 가깝습니다.
이때는 바깥쪽 아래에 9V 건전지를 대는 비상 단자가 있는지 확인해 보세요. / 단자가 있으면 건전지를 댄 채로 번호를 눌러 문을 열 수 있습니다.
건전지를 대도 반응이 없으면 도어락 쪽 문제일 수 있으니 그때 연락 주시면 됩니다. / 소리가 났다가 사라졌다는 이야기도 판단에 큰 도움이 됩니다.
@ 안양 비산동 도어락 소리 점검

# 경고음을 끄고 싶을 때
밤늦게 들어올 때 삑 소리가 이웃에게 신경 쓰인다는 분이 계십니다. / 많은 제품은 설정에서 음량이나 무음을 고를 수 있습니다.
다만 경고음을 아예 꺼 두면 배터리가 부족하다는 알림도 못 듣게 되니 주의가 필요합니다. / 입력음만 줄이고 경고음은 살려 두는 모델도 있으니 설명서를 먼저 보세요.
설정 방법은 모델마다 달라 전화로 안내해 드릴 수 있습니다. / 모델명만 알려주시면 대략적인 순서는 말씀드립니다.

# 소리를 기록해 두면 도움이 됩니다
전화하기 전에 아래 정도만 메모해 두시면 상황이 빨리 정리됩니다.
- 소리가 길었는지 짧았는지, 몇 번 났는지
- 소리가 났을 때 번호판 불빛이 어땠는지
- 문 쪽에서 윙 하는 소리가 같이 났는지
- 최근에 건전지를 바꾼 시기
휴대폰으로 소리를 녹음해 보내 주시는 분도 계신데 판단에 도움이 됩니다. / 영상이 어렵다면 소리를 말로 흉내 내서 설명해 주셔도 충분합니다.
@ 안양 도어락 경고음 상담 출장

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이 필요한 상황이라면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어렵다면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.
문을 여는 일 없이 소리 점검만 하는 경우에도 상황을 먼저 보고 필요한 작업을 말씀드립니다.

# 비용은 시작하기 전에 말씀드립니다
소리의 원인을 확인한 뒤 어떤 작업이 필요한지, 비용이 어느 정도인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 소리가 났던 도어락, 뒤에 해둘 점검
원인이 정리되면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새 건전지를 전부 같이 교체해 두는 것이 좋습니다.
일부만 바꾸면 며칠 안에 같은 경고음이 다시 나는 일이 많습니다. / 건전지는 같은 종류와 같은 날짜 제품으로 맞춰 쓰시길 권합니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 비산동 말고 안양 어디든 갑니다
비산동 바로 옆 호계동, 평촌동, 관양동, 부흥동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있고, 문 열기 과정은 [현관문 개문](door-open.html)에 자세히 적어 두었습니다.

# 자주 묻는 질문
? 삑 소리가 길게 나면 고장인가요? | 꼭 고장은 아닙니다. 배터리 부족이나 입력 잠금 알림인 경우가 많으니 소리와 불빛 상태를 먼저 확인해 주세요.
? 소리를 완전히 꺼도 되나요? | 가능한 모델이 많지만 경고음까지 끄면 배터리 부족을 놓칠 수 있어 입력음만 줄이는 쪽을 권합니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에도 전화해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 세입자인데 신분 확인은 어떻게 하나요? | 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
