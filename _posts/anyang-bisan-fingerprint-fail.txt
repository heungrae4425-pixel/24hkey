# 비산동에서 지문 도어락이 말을 안 들을 때
비산동은 비산사거리 주변으로 아파트와 빌라가 늘어선 동네입니다. / 지문 인식 도어락을 쓰는 집이 많아서 지문이 안 읽힌다는 연락도 꾸준히 옵니다.
분명히 어제까지 잘 열렸는데 오늘은 몇 번을 대도 "삑" 하고 거절되는 일이 있습니다. / 손이 젖은 날, 추운 날, 아이를 안고 있는 날에 유독 잘 생깁니다.
이 글은 지문 인식이 잘 안 될 때 원인별로 먼저 해볼 것을 정리했습니다. / 그래도 안 되면 [안양 출장열쇠](anyang.html)가 어떻게 점검하는지도 함께 적었습니다.
@ 비산동 지문 인식 도어락 안 열림 출장열쇠

# 지문이 안 읽히는 가장 흔한 이유
지문 센서는 손가락 끝의 무늬를 읽는 장치라 손 상태의 영향을 크게 받습니다. / 이유를 모르고 자꾸 눌러서 실패 횟수만 늘리는 경우가 많습니다.
- 손가락이 젖었거나 너무 건조한 경우
- 손가락에 이물질이나 로션이 묻은 경우
- 센서 표면에 먼지나 기름이 낀 경우
- 손가락에 상처나 굳은살이 생긴 경우
- 지문을 처음 등록할 때 한쪽 각도만 읽어 둔 경우
이 가운데 한 가지만 해결해도 다시 잘 읽히는 경우가 많습니다. / 센서를 부드러운 천으로 닦고 손을 닦은 뒤 다시 대 보세요.

# 센서 닦기만으로 풀리는 경우
센서 표면에 기름이나 먼지가 쌓이면 지문이 흐릿하게 읽혀 인식률이 떨어집니다. / 부드러운 마른 천으로 센서를 가볍게 닦아 주세요.
물이나 알코올을 직접 뿌리는 것은 권하지 않습니다. / 내부로 스며들면 센서가 상할 수 있습니다.
닦고 난 뒤 같은 손가락을 같은 각도로 한 번 더 대 보세요. / 손가락을 너무 세게 누르거나 너무 가볍게 닿기만 하면 인식이 안 될 수 있습니다.
@ 비산동 지문 센서 닦기 도어락 점검

# 손가락 상태가 달라졌을 때
겨울에는 손이 건조해지고 여름에는 땀이 나서 지문이 평소와 다르게 읽힙니다. / 아이는 손가락이 작아 센서에 꽉 닿지 않을 때도 있습니다.
어르신은 지문이 옅어져 인식이 어려운 경우가 있습니다. / 이럴 때는 지문 대신 번호나 카드 같은 다른 방법을 같이 쓰도록 설정해 두면 편합니다.
한 손가락만 등록해 두기보다 여러 손가락을 여러 각도로 등록해 두면 훨씬 안정적입니다. / 사용하는 사람마다 두세 개씩 등록해 두는 것을 권합니다.

# 배터리가 약해도 지문이 안 읽힙니다
지문 센서는 번호판보다 전력을 더 쓰기 때문에 배터리가 약해지면 가장 먼저 증상이 나타납니다. / 번호는 눌러지는데 지문만 안 읽힌다면 배터리를 의심해 보세요.
- 지문 인식이 갑자기 느려졌는지
- 번호판 불빛이 평소보다 어두운지
- 경고음이 짧게 울리는 일이 있었는지
배터리를 전부 새것으로 바꾸면 증상이 사라지는 경우가 많습니다. / 일부만 바꾸지 말고 전부 바꿔 주세요.
배터리가 완전히 방전되면 9V 건전지로 비상 전원을 넣어 번호로 열 수 있는 도어락도 있습니다. / 모델마다 다르니 [현관문 개문](door-open.html)이 필요한지 전화로 먼저 말씀해 주세요.

# 지문 등록을 다시 해야 하는 경우
센서가 오래되어 이전 등록 정보가 흐릿해졌거나 등록을 한 번만 해 둔 경우에는 다시 등록하는 것이 가장 좋습니다. / 기존 지문을 모두 지우고 새로 등록하면 인식률이 눈에 띄게 올라갑니다.
등록할 때는 손가락 한 개를 여러 번, 각도를 조금씩 바꿔 가며 대 주세요. / 한 번에 너무 정확히만 대 두면 오히려 인식 범위가 좁아집니다.
다른 사람이 쓰던 지문 정보가 남아 있다면 이 기회에 삭제하는 것이 안전합니다. / 이사 오신 분이나 가족이 바뀐 경우에는 꼭 확인해 주세요.

# 도어락 자체 문제일 때
센서 닦기, 배터리 교체, 지문 재등록을 모두 해 봐도 안 되면 센서나 내부 기판의 문제일 수 있습니다. / 이때는 직접 분해하지 말고 점검받으시는 것이 안전합니다.
- 번호는 되는데 지문만 계속 안 되는 경우
- 센서에서 불빛이 안 켜지는 경우
- 비 온 뒤부터 증상이 시작된 경우
- 문이 열리긴 하지만 느려진 경우
센서만 바꿀 수 있는 모델이면 [도어락 수리](doorlock-repair.html)로 해결합니다. / 너무 오래된 제품이라 부품이 없다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 출장열쇠가 와서 보는 순서
도착하면 도어락 종류, 센서 상태, 배터리 상태를 먼저 확인합니다. / 간단한 원인이면 현장에서 바로 고치고, 부품이 필요하면 설명드린 뒤 진행합니다.
문이 안 열려 들어가지 못하는 상황이면 문을 먼저 상하지 않게 엽니다. / 이후에 지문 문제를 점검하고 지문을 다시 등록해 드립니다.
작업이 끝나면 가족 모두의 지문이 잘 열리는지 한 번씩 같이 확인합니다. / 번호나 카드 같은 대체 방법도 함께 점검합니다.

# 신분 확인과 비용 안내
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다. / 지문 문제로 문밖에 계신 경우라도 같은 절차를 거칩니다.
비용은 일을 시작하기 전에 상태를 보고 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 비산동 위치는 이렇게 알려주세요
비산동은 단지가 많아 위치를 정확히 알려주시면 도착이 빨라집니다. / 비산사거리나 가까운 큰 길에서 어느 쪽인지 말씀해 주세요.
- 건물 형태와 동, 호수
- 번호판 상태와 경고음 여부
- 지문이 안 읽히기 시작한 시점
- 집 안에 사람이 있는지
도어락 모델 표시를 찍은 사진을 문자로 보내주시면 맞는 부품을 챙겨 가기 좋습니다. / 문밖에 계시다면 꼭 먼저 말씀해 주세요.
@ 비산동 24시 지문 도어락 점검 수리 안양

# 지문 도어락 오래 쓰는 방법
지문 센서는 깨끗하게 쓸수록 오래갑니다. / 가끔 마른 천으로 닦아 주기만 해도 인식률이 오래 유지됩니다.
- 센서는 부드러운 천으로만 닦기
- 배터리는 해가 바뀔 때 전부 교체
- 가족 지문은 두세 개씩 여러 각도로 등록
- 번호 비밀번호도 함께 설정해 두기
작은 습관이 문 앞에서 막히는 일을 많이 줄여 줍니다. / 이상한 점이 생기면 그날 바로 확인받으세요.

# 비산동 말고 안양 어디든 갑니다
비산동 옆 호계동, 평촌동, 관양동, 안양동, 석수동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
안양에서 다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
