# 비 오는 날 장바구니 들고 지문이 안 읽힐 때
비산동은 평촌역과 범계역 사이를 오가며 생활하는 분이 많아, 장을 보고 들어오거나 퇴근하며 비를 맞는 일이 흔합니다. / 손이 젖은 채 도어락에 손가락을 대면 평소엔 잘 되던 지문이 갑자기 안 읽힙니다.
반대로 겨울에 손이 바싹 마르거나 핸드크림을 바른 뒤에도 같은 일이 생깁니다. / 지문은 그대로인데 센서가 읽지 못하는 상황입니다.
이 글은 손 상태 때문에 지문이 안 읽힐 때의 원인과 집 앞에서 해볼 수 있는 방법, 그리고 [안양 출장열쇠](anyang.html)를 부를 때를 적었습니다.
@ 비산동 젖은 손으로 지문 인식하는 도어락

# 지문 센서는 손가락의 무엇을 읽나
도어락 지문 센서는 손가락 끝의 골과 마루 모양을 읽습니다. / 방식에 따라 빛으로 보거나 전기 신호의 차이로 읽는 제품이 있습니다.
어느 쪽이든 손가락 표면이 일정한 상태여야 정확합니다. / 물기가 있으면 골 사이가 물로 메워져 마루와 구분이 흐려집니다.
손이 너무 건조하면 접촉이 약해져 신호가 약하게 잡힙니다. / 그래서 손이 젖거나 건조한 두 경우 모두 읽기가 어려워집니다.

# 손이 젖었을 때 먼저 해볼 일
가장 간단한 방법은 손가락을 닦는 것입니다. / 옷자락에 쓱 닦는 것보다 마른 수건이나 휴지로 손가락 끝을 눌러가며 닦는 편이 낫습니다.
- 손가락 끝의 물기를 마른 천으로 충분히 닦기
- 센서 표면에 물방울이 있다면 같이 닦기
- 한 손가락으로 두세 번만 천천히 시도하기
- 안 되면 번호 입력으로 바꾸기
빠르게 여러 번 대면 오류가 쌓여 입력이 잠시 막히는 제품도 있습니다. / 두세 번이면 충분하니 그 이상은 하지 마세요.

# 손이 건조할 때는 오히려 이렇게
겨울철이나 설거지, 소독 뒤에 손이 푸석하면 지문이 흐려집니다. / 손가락 끝을 입김으로 살짝 데우거나 손으로 비벼 약간 따뜻하게 하면 도움이 됩니다.
센서에 대기 전에 손가락 끝을 손바닥에 가볍게 눌러 부드럽게 만드는 분도 있습니다. / 핸드크림은 바른 직후보다 어느 정도 흡수된 뒤에 대는 편이 낫습니다.
너무 세게 누르면 센서 표면이 눌려 오히려 못 읽는 일이 있습니다. / 평소 등록할 때 쓰던 정도의 힘으로 손가락 면을 고르게 대세요.
@ 건조한 겨울 손가락과 지문 센서 접촉

# 센서 표면의 오염도 같이 보세요
손 상태만 탓하기 쉽지만 센서 표면이 더러운 경우도 흔합니다. / 손기름과 먼지, 화장품이 쌓여 있으면 정확도가 떨어집니다.
센서 표면은 부드러운 마른 천으로 가볍게 닦아 주세요. / 알코올이나 세정제를 직접 뿌리면 틈으로 들어가 고장 날 수 있으니 피하세요.
긁힌 자국이 눈에 띄거나 금이 간 센서는 닦아도 소용이 없습니다. / 이런 경우에는 부품 점검이 필요합니다.

# 등록할 때 이렇게 해 두면 덜 막힙니다
지문 인식이 불안정한 이유 중 하나는 등록을 한 번만 해 두었기 때문입니다. / 같은 손가락을 여러 각도와 위치로 나눠 등록하면 인식률이 올라갑니다.
- 한 손가락을 두세 번 나눠서 등록
- 검지와 중지처럼 두 손가락 이상 등록
- 양손 모두 등록
- 손이 젖은 상태와 마른 상태 둘 다 한 번씩 시도
제품마다 가능한 횟수가 다르니 설명서를 확인하거나 [도어락 수리](doorlock-repair.html) 때 함께 봐달라고 하셔도 됩니다.

# 지문이 안 되는 날을 대비한 다른 수단
지문만 쓰고 있으면 이런 날 곤란합니다. / 번호와 카드키를 같이 쓰도록 해 두면 막히는 일이 훨씬 줄어듭니다.
번호는 가족 모두가 아는 것으로 하되 너무 단순한 숫자는 피하세요. / 카드키는 지갑 한 곳에만 넣지 말고 가방 안에도 하나씩 두면 좋습니다.
비밀번호를 잊어서 막히는 상황이 걱정되면 가족 사이에 안전하게 공유하는 방법을 정해 두세요. / 그래야 지문이 안 읽히는 날에도 번호 하나로 해결됩니다.

# 지문 센서 자체가 고장 났을 때의 신호
손을 닦고 센서도 닦았는데도 계속 안 읽히면 센서나 기판 문제일 수 있습니다. / 어제까지 잘되던 지문이 갑자기 한 손가락도 안 되면 의심해 볼 만합니다.
- 모든 손가락이 갑자기 읽히지 않음
- 센서에 불은 들어오는데 반응이 없음
- 읽는 소리 없이 무반응
- 비가 오면 심해지고 마르면 괜찮아짐
마지막 증상은 틈으로 습기가 스며들었을 가능성을 알려줍니다. / 상태를 사진으로 찍어 두면 설명할 때 도움이 됩니다.

# 문 앞에서 막혔다면 전화 전에 이것만
번호도 카드도 쓸 수 없고 지문만 쓰던 제품이라면 비상 수단을 확인하세요. / 바깥쪽 아래의 비상 단자에 건전지를 대는 방법이나 열쇠 구멍이 있는지 봅니다.
건전지가 약해서 지문이 읽히지 않는 경우도 있어 번호판 불빛이 약하지 않은지 같이 보세요. / 약하면 건전지를 새것으로 바꾸는 것만으로 돌아오기도 합니다.
집 안에 가족이 있다면 안쪽에서 열어 달라고 부탁하는 것이 가장 빠릅니다.

# 비산동 위치와 증상은 이렇게 알려주세요
정확히 알려주시면 도착이 빨라집니다.
- 건물 형태와 동, 호수
- 평촌역이나 범계역 방면 등 대략 어느 쪽인지
- 지문 말고 쓸 수 있는 수단이 있는지
- 번호판 불빛과 소리 상태
- 집 안에 아이나 반려동물이 있는지
지문 센서 사진을 문자로 보내주시면 필요한 부품을 챙겨 가기 좋습니다.

# 출장 오면 신분과 비용부터 말씀드립니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두시면 수월합니다.
확인이 어려우면 작업을 할 수 없습니다. / 이웃과 집 주인 모두를 지키기 위한 절차입니다.

센서 상태와 문 상태를 보고 비용을 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니라고 하시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었고, 문 여는 방법은 [현관문 개문](door-open.html)에서 볼 수 있습니다.
@ 비산동 지문 센서 점검과 도어락 작업

# 고쳐 쓸지 바꿀지 정하는 기준
센서 표면만 닦아도 되는 경우에는 교체를 권하지 않습니다. / 센서가 실제로 상했다면 센서 부품만 바꿀 수 있는지 먼저 봅니다.
제품이 너무 오래됐거나 부품 구하기가 어렵다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 어떤 제품이 좋을지 모르겠다면 [도어락 설치](doorlock-install.html) 때 지문과 번호, 카드를 같이 쓰는 제품을 안내해 드립니다.
바꿀지 말지는 반드시 먼저 여쭤보고 정합니다.

# 안양 전 동네에서 부르실 수 있습니다
비산동 가까운 평촌동, 관양동, 호계동, 귀인동, 부흥동도 다닙니다. / 안양동, 석수동, 박달동과 인덕원역, 안양역 쪽도 24시간 출동합니다.
안양에서 다니는 동네는 [안양시 출장열쇠](anyang.html)에 정리해 두었고, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.

? 지문 센서만 바꿀 수 있나요? | 제품에 따라 다릅니다. 열어 보고 가능한지 먼저 말씀드립니다.
