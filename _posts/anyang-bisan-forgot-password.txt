# 비산동에서 비밀번호가 갑자기 안 떠오를 때
비산동은 아파트와 빌라, 주택이 함께 있어 도어락 종류도 제각각입니다. / 번호가 기억나지 않아 문 앞에서 멈추는 일은 어느 집에서나 생깁니다.
오래 쓰던 번호인데 손이 안 움직이거나, 가족이 몰래 바꿨다는 걸 뒤늦게 알게 되기도 합니다. / 이 글은 안양 비산동에서 그런 일이 생겼을 때의 순서를 적었습니다.
@ 비산동 도어락 비밀번호 분실 출장열쇠

# 먼저 숨을 한 번 돌리세요
급하게 계속 눌러 보면 틀린 횟수만 쌓입니다. / 몇 번 틀리면 도어락이 한동안 입력을 막는 제품이 많습니다.
서너 번 해보고 안 되면 멈추시고, 아래부터 차례로 확인해 주세요.

# 가족에게 먼저 전화해 보세요
같이 사는 분이 번호를 바꿨는데 말을 못 들은 경우가 가장 흔합니다. / 휴대폰이 있다면 가족에게 먼저 물어보는 게 제일 빠릅니다.
- 같이 사는 가족이 번호를 바꾼 적이 있는지
- 집에 누가 있는지, 안에서 열어줄 수 있는지
- 관리사무소나 경비실에 비상 연락이 되는지
집 안에 사람이 있다면 안쪽에서 열어 주는 것으로 끝나기도 합니다.

# 다른 열림 방법이 있는지 확인
번호만 쓰는 도어락은 많지 않습니다. / 카드, 지문, 열쇠 구멍이 같이 달린 제품이 많습니다.
- 등록해 둔 카드키나 태그가 지갑에 있는지
- 지문이 등록돼 있다면 손가락을 바꿔서 시도
- 손잡이 아래쪽에 열쇠 구멍이 있는지, 열쇠가 근처에 있는지
카드 하나가 지갑 깊숙이 있는 경우도 많으니 한 번 찾아보세요.
@ 비산 열쇠집 비밀번호 도어락 개문

# 번호가 맞는데 안 열린다면
기억이 맞는데도 안 열리는 경우가 있습니다. / 이럴 때는 번호가 아니라 다른 이유일 수 있습니다.
- 안쪽 보조키가 잠겨 있는 경우
- 배터리가 약해 번호판이 반쯤만 켜지는 경우
- 방범 기능으로 한동안 입력이 막혀 있는 경우
번호판이 꺼져 있으면 [도어락 배터리](anyang.html) 문제부터 보시는 게 맞습니다.

# 번호를 틀리면 무슨 일이 생기나
틀린 번호를 반복해 누르면 한동안 입력을 막는 제품이 있습니다. / 막히는 시간은 제품마다 다르고, 시간이 지나면 풀립니다.
그동안 계속 누르면 막히는 시간이 더 길어질 수 있으니 기다리세요. / 억지로 열려고 문을 당기거나 두드리는 건 피해 주세요.

# 전화하실 때 알려주면 좋은 것
출동 전에 상황을 알면 맞는 장비를 챙겨 갈 수 있습니다. / 아래 정도만 말씀해 주세요.
- 위치(아파트 이름 대신 가까운 건물, 동과 호수)
- 도어락 모양과 번호판 상태
- 열쇠 구멍 유무와 열쇠를 가지고 있는지
- 집 안 사람이나 반려동물 유무
도어락 사진을 문자로 보내 주시면 더 빠릅니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우시겠지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 문은 최대한 안 상하게 엽니다
번호를 모르는 도어락은 덜 상하는 방법부터 차례로 시도합니다. / 도어락과 문틀 외관이 상하지 않게 하는 것이 먼저입니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 먼저 말씀드립니다. / 자세한 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.
@ 비산동 현관문 도어락 개문 작업

# 비용은 문 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.

# 열고 난 뒤에 번호를 새로 정합니다
문이 열리면 안쪽에서 새 번호를 등록하는 것까지 도와드립니다. / 예전 번호는 지우고 새 번호만 남겨 둡니다.
번호를 정할 때는 기억하기 쉽지만 생일이나 전화번호 끝자리는 피하세요. / 가족과 번호를 같이 정하고 카드 하나는 따로 보관하면 좋습니다.

# 같은 일이 다시 생기지 않게
번호를 자주 바꾸는 집이라면 가족끼리 공유하는 방법을 정해 두세요. / 메모는 집 밖이나 휴대폰 메모처럼 남이 볼 수 있는 곳을 피하세요.
번호를 바꾸는 날에는 가족 모두에게 바로 알리는 것이 가장 확실합니다. / 가끔 카드키로 열어 보며 쓰는 습관을 들이면 번호를 잊을 일이 줄어듭니다.

# 자주 묻는 질문
? 번호를 몰라도 새로 등록할 수 있나요? | 문을 연 뒤 안쪽에서 새 번호를 등록해 드립니다.
? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 우편물을 준비해 주세요.
? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 도어락을 바꿔야 하나요? | 비밀번호를 잊은 것만으로는 바꿀 필요가 없습니다. 고장이 있으면 따로 말씀드립니다.
