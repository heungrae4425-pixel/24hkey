# 김장하다 문이 잠기는 일은 생각보다 흔합니다
비산동에서 김장철이 되면 베란다나 현관 앞에서 배추를 씻고 절이는 집이 많습니다. / 평촌역이나 안양역 쪽 시장에서 재료를 사 와 한꺼번에 작업하다 보면 잠깐 나갔다가 문이 닫히는 일이 생깁니다.
이 글은 김장이나 베란다 작업 중에 문이 잠겼을 때 확인할 것과 [안양 출장열쇠](anyang.html)를 부르는 순서를 정리했습니다.
손이 젖고 집안이 어수선한 상황에서 침착하게 대처하는 데 도움이 되면 좋겠습니다.
@ 비산동 김장철 베란다 작업 중 문 잠김

# 이런 상황이 자주 생깁니다
김장은 하루에 끝나지 않고 절이기, 씻기, 버무리기까지 이어지는 일이라 문을 여러 번 드나듭니다. / 그만큼 문이 닫히는 순간도 많아지고 지치면 더 잊기 쉽습니다.
특히 집에서 가족과 이웃이 모여 일하는 날은 서로 누가 문을 잡고 있는지 모르는 채 닫히는 경우가 많습니다.
- 베란다에서 작업하다 바람에 방충망이나 문이 닫힌 경우
- 쓰레기와 재료를 들고 현관 밖으로 나왔다가 문이 닫힌 경우
- 물 묻은 손으로 도어락을 만지다 번호가 틀린 경우
- 베란다 문이 안에서 잠겨 다시 들어가지 못하는 경우
각각 대처가 다르므로 어느 쪽 문이 잠겼는지부터 확인하세요.

# 베란다 문과 현관문을 구분하세요
베란다 쪽에서 작업하다가 안쪽 거실로 들어가는 문이 닫히며 잠긴 경우도 있습니다. / 이럴 때는 어느 문 쪽에 계신지 정확히 말씀해 주셔야 알맞게 준비합니다.
베란다 문은 대개 미닫이로, 안쪽에서 크레센트 같은 잠금장치로 잠깁니다. / 현관문은 도어락과 걸쇠로 잠깁니다.
베란다에 갇혔다면 안쪽에서 잠겼을 가능성이 높고, 현관 밖에 나왔다면 문이 닫히면서 자동 잠금이 걸렸을 가능성이 높습니다.
어느 쪽인지에 따라 [현관문 개문](door-open.html) 여부가 달라집니다.

# 베란다 문이 안에서 잠긴 경우
바깥으로 나왔는데 베란다 미닫이가 안에서 잠겨 있다면 억지로 흔들지 마세요. / 유리가 깨지거나 레일이 상할 수 있습니다.
잠금장치가 반쯤 걸려 있을 때는 문을 살짝 들어 올리며 밀어 보면 풀리기도 합니다. / 유리를 두드리거나 깨뜨리려 하지 마세요.
@ 비산동 베란다 미닫이 잠금장치

# 젖은 손은 먼저 닦으세요
김장 중이라 손에 양념이나 물이 묻어 있으면 번호판이 오작동합니다. / 지문 인식은 더 영향을 받습니다.
마른 수건으로 손과 번호판을 닦고 다시 눌러 보세요. / 의외로 이것만으로 열리는 일이 많습니다.
그래도 안 되면 여러 번 시도하기보다 잠시 멈추는 것이 좋습니다.

# 번호를 틀리면 잠시 막힙니다
양념이 묻은 장갑을 낀 채 번호판을 누르다 번호판에 양념이 묻어 이후 버튼이 안 눌리는 경우도 있습니다. / 이럴 땐 마른 천으로 가볍게 닦고 물을 직접 뿌려 닦지는 마세요.
비밀번호를 여러 번 틀리면 도어락이 입력을 막는 경우가 있습니다. / 서너 번 해보고 안 되면 멈추고 시간을 두세요.
당황하면 평소 쓰는 번호도 헷갈립니다. / 물을 한 모금 마시고 숨을 고른 뒤 한 번만 정확히 눌러 보세요.

# 휴대폰과 열쇠를 안에 두고 나왔다면
절임 배추를 씻는 물을 틀어 둔 채로 나왔다면 물이 넘칠 수 있어서 급한 상황입니다. / 이럴 때는 이웃이나 관리사무소에도 알려 두면 도움이 됩니다.
이웃에게 전화를 빌리거나 근처 가게에서 연락하세요. / 연락할 번호를 외우고 있지 않다면 이웃 도움을 받는 것이 가장 빠릅니다.
집 안에 가스 불이나 전기 제품이 켜져 있다면 먼저 말씀해 주세요. / 급한 상황은 우선해서 움직입니다.
김장 양념이나 절인 배추가 상할 수 있는 상황이라면 그 점도 알려주세요.

# 출장 요청할 때 알려주실 것
김장철에는 현관 앞에 큰 통이나 상자를 쌓아 두는 일이 많습니다. / 도착했을 때 문 앞 동선이 막혀 있으면 작업이 늦어지니 가능하면 정리해 주시면 좋습니다.
- 비산동 건물 위치와 가까운 큰길
- 현관문인지 베란다 문인지
- 번호판 상태와 들리는 소리
- 집 안 가스나 전기 제품이 켜져 있는지
- 집 안에 사람이나 반려동물이 있는지
사진을 문자로 보내 주시면 맞는 장비를 챙겨 갑니다.
@ 비산동 도어락 번호판 젖은 손 확인

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 이웃이 보증해 주는 방식은 쓰지 않으니 이 점 알아 주세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 베란다 문 종류도 고려해 말씀드리니 놀라지 않으셔도 됩니다. / 먼저 도어락과 문틀이 상하지 않는 방법부터 차례로 해보고, 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다. 베란다 문도 유리와 레일이 다치지 않게 조심합니다.
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

먼저 도어락과 문틀이 상하지 않는 방법부터 차례로 해봅니다. / 베란다 문도 유리와 레일이 다치지 않게 조심합니다.
작업 중 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.

# 열린 뒤에는 하던 일로 돌아가기 전에
김장 때문에 현관 앞과 베란다에 물기가 많았다면 도어락 틈새에 물이 들어갔을 수 있습니다. / 마른 수건으로 닦고 며칠은 번호판이 정상인지 지켜보세요.
문이 열리면 도어락 번호판이 젖어 있지 않은지 닦고 잠금이 정상인지 확인합니다. / 배터리가 약하다면 이 기회에 바꿔 두는 것이 좋습니다.
고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고 오래돼 교체가 필요하면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 김장철에 문 앞에서 막히지 않으려면
김장이 끝난 뒤 현관과 베란다를 정리할 때도 문 열쇠나 번호를 다시 한 번 확인하세요. / 몸이 지친 뒤라 평소 번호를 헷갈리거나 열쇠를 어디 뒀는지 잊는 일이 의외로 많습니다.
김장 김치를 이웃과 나누려고 문 밖을 오갈 때도 문이 닫히지 않게 고정해 두면 안심입니다.
- 현관문을 나올 때 문 끼움 장치나 고정 고리 사용
- 베란다 문 잠금은 작업 중에 풀어 두기
- 휴대폰은 주머니나 앞치마에 넣어 두기
- 번호판은 젖은 손으로 만지지 않기
- 가족 중 한 명에게는 나갔다 오는 시간을 알려 두기
이런 습관이 김장 날의 당황스러운 일을 막아 줍니다.

# 비산동 말고 안양 어디든 갑니다
비산동 옆 평촌동, 관양동, 호계동, 부흥동, 안양동, 귀인동, 석수동, 박달동도 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
