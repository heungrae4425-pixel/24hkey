# 비산동 원룸 앞에서 막혔을 때
비산동 쪽에는 혼자 사는 분들이 쓰는 원룸과 오피스텔이 꽤 있습니다. / 이런 건물은 방마다 도어락이 달려 있고 층마다 구조도 비슷해서 문이 잠기면 어디서부터 봐야 할지 막막해집니다.
이 글은 비산동에서 원룸이나 오피스텔 문이 안 열릴 때 전화 전에 확인할 것을 적었습니다. / 그다음 [안양 출장열쇠](anyang.html)가 어떻게 오는지도 순서대로 적어 두었습니다.
@ 비산동 원룸 오피스텔 출장열쇠 문 열기

# 원룸·오피스텔 문이 자주 잠기는 이유
방이 작다 보니 쓰레기를 버리거나 택배를 받으러 잠깐 나가는 일이 많습니다. / 그때 문이 닫히면서 자동으로 잠기는 도어락이면 그대로 갇혀 버립니다.
휴대폰을 방 안에 두고 나온 날이 제일 곤란합니다. / 이웃에게 전화만 빌려도 해결이 되니 너무 당황하지 않으셔도 됩니다.

# 집주인에게 연락하기 전에 확인할 것
관리인이나 집주인이 마스터키를 가지고 있는 건물도 있습니다. / 연락이 바로 닿으면 그쪽이 빠르고, 안 닿는 늦은 시간이면 저희를 부르시면 됩니다.
계약서에 도어락 관련 내용이 따로 있는지도 한 번 떠올려 보세요. / 건물 규정이 있으면 전화로 먼저 말씀해 주시면 맞춰서 진행합니다.

# 공동현관과 방문은 따로 봐야 합니다
오피스텔은 건물 입구 공동현관이 있고 그 안쪽에 내 방문이 있습니다. / 어느 문이 안 열리는지에 따라 하는 일이 달라지니 전화로 먼저 알려주세요.
공동현관은 건물 관리 쪽 허락이 필요할 수 있습니다. / 방문만 문제라면 비교적 간단하게 정리되는 경우가 많습니다.

# 이럴 땐 하지 마세요
문틈에 카드를 밀어 넣거나 손잡이를 세게 비틀면 걸쇠가 더 물립니다. / 도어락 외관이 상하면 나중에 고치는 비용이 더 들 수 있습니다.
옆집 문이나 복도 소화전 쪽으로 올라가 창문으로 들어가려는 시도도 위험합니다. / 높은 층이면 더더욱 그대로 두고 전화 주세요.
@ 비산동 도어락 원룸 현관 출장 개문

# 전화로 알려주실 것
정확한 건물 이름과 호수, 몇 층인지를 알려주시면 찾아가기 쉽습니다. / 공동현관 비밀번호가 있으면 그것도 함께 알려주세요.
- 건물 위치(큰길 쪽인지 골목 안쪽인지)
- 층과 호수
- 도어락 모양(번호 버튼, 터치형, 지문 등)
- 번호판 불이 들어오는지 여부
- 안에 반려동물이 있는지

관리실이나 경비실이 있으면 먼저 상황을 말씀드려 보세요. / 세대 확인을 도와주거나 출입 기록을 알려주는 곳도 있습니다.
다만 관리실에서 문을 열어주지 않는 건물도 많습니다. / 그럴 땐 기다리지 말고 전화 주시면 사시는 분 확인 후 진행합니다.
복도에 CCTV가 있는 건물이면 작업하는 모습이 찍힐 수 있습니다. / 그래서 사시는 분이 맞는지 서로 확인하는 일이 더 중요합니다.

# 세입자도 문을 열 수 있습니다
집주인이 아니어도 지금 사는 분이면 문을 열어 드립니다. / 사시는 분인지 확인하는 방법이 따로 있습니다.
신분증에 주소가 나와 있거나, 그 주소로 온 우편물이나 계약서 중 하나면 됩니다. / 확인이 어려우면 작업이 어려우니 미리 챙겨 두시면 좋습니다.

# 혼자 사는 분이 꼭 알아 두면 좋은 것
혼자 살면 문이 잠겼을 때 도와줄 사람이 바로 없습니다. / 그래서 평소에 믿을 만한 연락처 한두 개와 열쇠집 번호를 휴대폰에 저장해 두는 게 좋습니다.
급한 마음에 아무 번호나 눌러 연락하면 비용 설명이 부족한 곳을 만날 수 있습니다. / 전화로 대략의 상황을 듣고 도착 전에 비용 안내 방식까지 말해 주는 곳인지 확인하세요.
저희는 문을 열기 전에 먼저 말씀드리고, 못 열면 비용을 받지 않습니다. / 이 두 가지는 어느 동네에서나 똑같이 지킵니다.

# 도착하면 이렇게 진행됩니다
먼저 사시는 분인지 확인하고 도어락 상태를 봅니다. / 비용은 문을 열기 전에 먼저 말씀드리고, 괜찮다고 하시면 시작합니다.
끝내 못 열면 비용은 받지 않습니다. / 문을 여는 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 새벽에 퇴근하고 나서 막혔다면
야근이나 교대 근무가 끝나고 늦게 돌아오면 건물이 조용합니다. / 문 앞에서 오래 소리 내지 않아도 되도록 전화로만 조용히 상황을 말씀해 주세요.
저희는 24시간 전화를 받습니다. / 시간 때문에 망설이지 마시고 위치만 정확히 알려주세요.
건물 입구에서 방까지 가는 길이 복잡하면 몇 층 어느 쪽 복도인지도 말씀해 주세요. / 이웃에게 방해가 되지 않게 조용히 작업하는 것도 신경 씁니다.

# 문이 열린 뒤에 같이 보는 것
열고 나면 도어락이 다시 잘 잠기고 열리는지 확인합니다. / 배터리 문제였다면 새 배터리를 넣는 것까지 봐 드립니다.
고장이 잦은 도어락이면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 무조건 바꾸라고 하지 않습니다.

# 원룸 도어락 오래 쓰는 습관
번호판에 지문이 많이 묻는 도어락은 가끔 마른 천으로 닦아 주세요. / 오래 안 닦으면 반응이 둔해지는 경우가 있습니다.
- 경고음이 나면 그날 바로 배터리 교체
- 문을 닫을 때 끝까지 닫혔는지 한 번 확인
- 집 안 눈에 안 띄는 곳에 비상 열쇠나 9V 건전지 보관
- 나갈 때 휴대폰, 지갑, 열쇠 순서로 손으로 확인
작은 습관이 문 앞에서 막히는 날을 많이 줄여 줍니다. / 원룸은 문 하나가 곧 집 전체라서 도어락 관리가 더 중요합니다.
@ 비산동 24시 출장열쇠 문 앞 확인

# 비산동 말고 안양 어디든 갑니다
비산동 옆 평촌동, 호계동, 관양동, 안양동까지 24시간 다닙니다. / 안양 안이면 동네와 상관없이 위치만 알려주시면 됩니다.
안양에서 다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 있고, 서울·경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
