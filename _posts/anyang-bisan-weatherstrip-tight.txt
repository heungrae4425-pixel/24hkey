# 비산동에서 겨울맞이 문풍지를 붙였더니 문이 안 닫힙니다
비산동은 인덕원역과 평촌역 사이에서 아파트와 빌라가 섞여 있는 생활권입니다. / 찬바람이 들기 시작하면 현관 틈새를 막으려고 문풍지를 새로 붙이는 집이 늘어납니다.
그런데 붙이고 나서 문이 잘 안 닫히거나, 닫혀도 도어락이 걸쇠를 못 넣는 일이 생깁니다. / 틈이 줄어든 만큼 문이 닫히는 거리도 같이 줄어들기 때문입니다.
이 글은 문풍지와 고무 패킹이 두꺼울 때 생기는 증상과 점검 순서를 정리했습니다. / 직접 해결이 어려우면 [안양 출장열쇠](anyang.html)가 도와드립니다.
@ 비산동 현관 문풍지 고무 패킹 두께

# 이런 증상이면 패킹이 원인일 수 있습니다
문풍지를 붙인 시기와 증상이 겹치는지 먼저 떠올려 보세요.
- 문을 닫으면 반동으로 살짝 튕겨 나오는 경우
- 도어락이 잠기는 소리가 나지 않거나 반쯤만 나는 경우
- 걸쇠가 문틀 구멍에 맞지 않고 스치는 느낌이 나는 경우
- 번호판이 닫힘 신호를 인식하지 못해 경고음이 나는 경우
이 중 하나라도 해당하면 문풍지부터 의심해 볼 만합니다. / 반대로 붙이기 전에도 같은 증상이 있었다면 다른 원인이 있는 것입니다.

# 패킹이 두꺼우면 걸쇠가 닿지 못합니다
문틀과 문 사이에는 원래 적당한 틈이 있습니다. / 여기에 두꺼운 고무나 스펀지 패킹을 붙이면 문이 닫힐 때 패킹이 반발력으로 밀어냅니다.
그러면 걸쇠가 문틀 구멍 앞까지는 가지만 완전히 들어가지 못합니다. / 도어락 모터는 잠그려 하는데 걸쇠가 닿지 않아 소리만 나고 멈추기도 합니다.
이런 상황에서 문을 세게 닫으면 걸쇠가 구멍 가장자리에 부딪혀 도어락이 상할 수 있습니다.

# 붙이기 전에 두께를 확인하세요
문풍지를 고를 때는 문틀과 문 사이의 틈을 먼저 살펴보세요. / 틈이 얼마나 되는지 손가락이나 얇은 종이로 가늠할 수 있습니다.
종이 한 장이 간신히 들어가는 정도라면 얇은 제품이 맞습니다. / 틈이 큰 집은 두꺼운 제품이 맞을 수 있으니 문마다 다르게 판단해야 합니다.
문 위쪽, 경첩 쪽, 아래쪽을 따로 재 보면 좋습니다. / 오래된 문일수록 위치마다 틈이 다릅니다.
@ 비산동 문틀 틈새 두께 확인

# 지금 붙인 패킹을 떼어 보세요
증상이 패킹 때문인지 확인하는 가장 빠른 방법은 떼어 보는 것입니다. / 문 윗부분이나 걸쇠 쪽 패킹 한 부분만 먼저 떼고 닫아 보세요.
떼고 나서 문이 가볍게 닫히고 도어락이 제대로 잠기면 원인이 확실합니다. / 이때는 더 얇은 제품으로 바꾸거나 위치를 조정하면 됩니다.
접착제가 남으면 문이나 문틀 도장이 상할 수 있으니 천천히 떼어 주세요. / 남은 접착 자국은 부드러운 천으로 닦아냅니다.

# 모든 곳에 다 붙이지 않아도 됩니다
바람이 새는 곳은 대개 문 아래와 경첩 쪽, 문틀 모서리입니다. / 걸쇠가 닿는 쪽 문틀에는 패킹을 붙이지 않아도 되는 경우가 많습니다.
걸쇠와 데드볼트 주변은 비워 두고 나머지 부분만 붙이면 문이 잘 닫히면서도 틈을 줄일 수 있습니다. / 문 아래 틈은 따로 얇은 바람막이를 대는 방법이 있습니다.
어디에 어떻게 붙이는 것이 맞는지 모르겠다면 문 상태를 사진으로 찍어 보내 주셔도 됩니다.

# 닫혔는데도 안 잠기면 전화 전에 이것부터
문을 다시 열었다 닫아도 잠기지 않을 때는 아래를 확인해 보세요.
- 문을 닫을 때 걸쇠가 문틀 구멍에 맞는지 눈으로 확인
- 문을 살짝 눌러 닫은 채 번호를 눌러 보기
- 패킹을 일부 떼어 보고 다시 시도
- 도어락 안쪽 손잡이가 정상적으로 도는지 확인
세게 닫는 것은 피해 주세요. / 걸쇠 받이가 휘거나 문틀이 상할 수 있습니다.

이미 문을 닫고 나왔는데 도어락이 제대로 안 잠긴 채 어긋나 있는 경우가 있습니다. / 이럴 때는 번호가 맞아도 모터가 걸쇠를 잘못 잡아 열리지 않을 수 있습니다.
문을 살짝 밀거나 당긴 채로 번호를 눌러 보세요. / 패킹 때문에 문이 눌려 있는 상태를 풀어 주면 열리기도 합니다.
그래도 안 되면 억지로 힘을 주지 말고 전화 주세요. / 문과 도어락이 상하지 않게 여는 방법으로 진행합니다.

# 전화하실 때 이렇게 알려주세요
비산동은 아파트 단지와 빌라가 이어져 있어 건물 정보와 호수를 정확히 알려 주시면 빠릅니다. / 인덕원역 쪽인지 평촌역 쪽인지도 덧붙여 주세요.
- 주소와 호수
- 문풍지를 붙인 시기와 위치
- 문이 닫히는 정도와 도어락 반응
- 집 안에 아이나 반려동물이 있는지
문 틈 사진을 같이 보내 주시면 원인을 가늠하는 데 큰 도움이 됩니다.
@ 비산동 문풍지 때문에 안 닫히는 현관문

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 먼저 그 집에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃을 위한 절차이기도 합니다. / 신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁해 보세요.

# 비용은 문을 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 손대기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 문 상태가 원인이면 같이 점검합니다
패킹을 떼도 문이 잘 닫히지 않는다면 문 자체가 처졌을 수 있습니다. / 경첩 나사가 풀렸거나 문이 휘면 걸쇠 위치가 어긋납니다.
이 경우에는 도어락 문제가 아니라 문 정렬 문제라 [경첩과 도어클로저 점검](doorlock-repair.html)이 필요할 수 있습니다.
문이 열린 뒤 걸쇠 받이를 조금 옮기거나 경첩을 조이는 것만으로 해결되는 일도 있습니다. / 교체가 꼭 필요한 경우에만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 겨울 문풍지를 오래 쓰는 요령
처음에 잘 고르면 해마다 붙였다 뗐다 하지 않아도 됩니다.
- 붙이기 전에 문틀을 닦고 마르게 하기
- 걸쇠 주변은 비워 두고 붙이기
- 두께가 다른 제품이 있으면 작은 구간에서 먼저 시험하기
- 시간이 지나 눌려 납작해진 패킹은 새로 교체하기
- 봄이 되면 떼어 먼지를 털고 정리하기
도어락 배터리도 겨울에는 더 빨리 닳으니 같이 점검해 주세요.

# 비산동 말고 안양 어디든 갑니다
평촌동, 관양동, 호계동, 귀인동, 부흥동, 안양동, 석수동, 박달동도 다닙니다. / 안양 안이면 24시간 받습니다.
다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.

문풍지를 붙인 뒤 처음 며칠은 문이 닫히는 느낌이 달라질 수 있어 두세 번 여닫으며 적응시켜 보세요. / 그래도 걸쇠가 문틀에 스치는 소리가 난다면 두께를 줄이는 것이 맞습니다.
비산동처럼 아파트와 빌라가 섞인 곳은 문 두께와 틀이 제각각이라 같은 제품도 집마다 결과가 다릅니다. / 사진으로 상태를 보내 주시면 방법을 같이 찾아봅니다.
