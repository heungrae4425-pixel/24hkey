# 문이 열렸다고 끝난 게 아닙니다
부흥동은 범계역과 평촌역 사이 생활권이라 퇴근 시간대 이동이 많은 동네입니다. / 문 앞에서 한참 씨름하다 겨우 열리면 안도감에 그대로 들어가 버리기 쉽습니다.
하지만 문이 안 열린 데에는 이유가 있었고, 그 이유를 그대로 두면 또 같은 일이 생깁니다. / 이 글은 문을 연 직후부터 며칠 사이에 점검할 것을 순서대로 적었습니다.
열린 순간이 사실 가장 좋은 점검 시간입니다. / 문제가 있었던 바로 그 상태를 눈으로 볼 수 있기 때문입니다. / 평소에는 문제가 없다가 딱 한 번 안 열리는 경우가 많아서, 증상을 확인할 기회가 흔치 않습니다. / 그래서 열자마자 바로 살피는 편이 이득입니다.
@ 부흥동 현관문 개방 후 도어락 점검

# 열린 직후 5분 안에 해볼 확인
들어가자마자 문을 열어 둔 채로 도어락을 몇 번 작동해 보세요. / 안쪽 손잡이로 잠그고 푸는 동작이 부드러운지 먼저 봅니다.
- 안쪽 잠금 손잡이가 끝까지 돌아가는지
- 문을 닫았을 때 걸쇠가 문틀 구멍에 맞게 들어가는지
- 번호판이나 지문 센서가 한 번에 반응하는지
- 열고 잠글 때 모터 소리가 평소와 같은지
이상이 하나라도 있다면 원인이 아직 남아 있다는 뜻입니다. / 괜찮아 보여도 안심하지 말고 두세 번은 반복해서 눌러 보세요. / 간헐적으로만 나타나는 증상은 한 번 해서는 잡히지 않습니다. / 메모해 두었다가 점검하는 사람에게 그대로 알려주세요.

# 원인이 배터리였다면 이렇게 마무리
번호판이 꺼져서 열지 못했다면 배터리가 원인이었을 가능성이 큽니다. / 이때는 임시로 건전지를 대서 연 경우가 많아 본격적인 교체가 남아 있습니다.
교체할 때는 모든 건전지를 같은 새 제품으로 한 번에 바꾸세요. / 일부만 바꾸면 얼마 못 가 경고음이 다시 울립니다.
교체한 날짜를 배터리 덮개 안쪽이나 휴대폰 일정에 적어 두면 잊지 않습니다. / 경고음이 울리면 그날 바로 바꾸는 습관도 같이 들이세요.

# 비밀번호가 원인이었다면 번호를 새로 정하기
번호를 몰라서 연 경우에는 새 번호를 정하는 것이 사실상 마무리입니다. / 기존 번호를 누가 알고 있는지 모르는 상태로 계속 쓰는 건 찜찜하기 때문입니다.
새 번호는 생일이나 집 호수처럼 쉽게 짐작되는 숫자를 피하세요. / 가족이 기억하기 쉬우면서 남이 맞히기 어려운 조합이 좋습니다.
등록한 번호는 안쪽에서 문을 연 채로 몇 번 눌러 확인합니다. / 이전 번호가 더 이상 안 먹히는지도 같이 눌러 보세요.
@ 도어락 비밀번호 재설정 확인

# 문틀과 경첩도 같이 살펴보기
도어락은 멀쩡한데 문이 틀에 걸려서 안 열린 경우도 있습니다. / 이 경우는 도어락이 아니라 문이 처진 것이 원인이라 도어락만 바꿔서는 소용없습니다.
문을 천천히 닫으면서 걸쇠 위치와 문틀 구멍이 맞는지 봅니다. / 문 윗부분 틈이 한쪽만 좁거나 문을 닫을 때 바닥에 쓸리는 소리가 나면 경첩 처짐을 의심하세요.
오래 쓴 문은 이런 변화가 서서히 오기 때문에 평소에는 눈치채기 어렵습니다. / 걸린 이유를 모른 채 넘어가면 다음에는 더 단단히 걸립니다.

# 보조키와 걸쇠 습관 돌아보기
안쪽 보조키를 잠근 채 나가서 못 들어온 경우라면 도어락 문제가 아닙니다. / 습관과 동선의 문제라서 점검할 곳이 다릅니다.
쓰레기를 버리러 나갈 때나 택배를 받으러 나갈 때는 보조키를 풀어 두는 습관이 필요합니다. / 문이 닫힐 때 걸쇠가 나온 채 닫히지 않게 확인하는 것도 중요합니다.
문 안쪽에 눈에 띄는 메모를 붙여 두는 방법도 있습니다. / 단순하지만 아침 출근 때 실수를 막아 줍니다.

# 열쇠 위치와 예비 수단 정하기
문이 한 번 안 열렸다면 그때 느낀 불안을 예비 수단으로 바꿔 두세요. / 비상 열쇠를 집 밖 믿을 수 있는 곳에 두거나 가족에게 맡겨 두는 방법이 있습니다.
- 가족 중 한 명에게 예비 열쇠 맡기기
- 9V 건전지를 가방이나 차에 한 개 넣어 두기
- 카드키가 있다면 한 장은 따로 보관
- 도어락 모양과 위치를 사진으로 찍어 두기
이 정도만 해도 같은 상황이 닥쳤을 때 훨씬 침착하게 움직일 수 있습니다. / 예비 수단을 한곳에 몰아 두지 않는 것이 요령입니다. / 열쇠를 집 안에 두고 나와 잠긴 경우를 대비해 집 밖에도 하나는 있어야 합니다.

# 기록을 남겨 두면 다음에 훨씬 편합니다
이번에 어떤 증상이었고 무엇을 했는지 간단히 적어 두세요. / 휴대폰 메모 한 줄이면 충분합니다.
언제 배터리를 바꿨는지, 번호를 언제 새로 정했는지, 문이 어떤 소리를 냈는지가 들어가면 좋습니다. / 나중에 비슷한 증상이 생겼을 때 비교하기 쉽고 전화로 설명할 때도 정확해집니다.
가족이 함께 쓰는 집이라면 이 메모를 공유 앨범이나 대화방에 올려 두는 것도 방법입니다. / 혼자 알고 있던 정보가 가족 전체의 대비가 됩니다.

# 고쳐 쓸지 바꿀지 판단하는 기준
점검 결과 부품이 약해졌다면 수리와 교체 중에서 골라야 합니다. / 판단 기준은 얼마나 자주 말썽을 부렸는지와 제품이 얼마나 오래됐는지입니다.
한두 번 있었던 일이고 제품이 아직 쓸 만하면 [도어락 수리](doorlock-repair.html)로 충분합니다. / 반복되거나 부품 구하기가 어려운 제품이면 [도어락 교체](doorlock-replace.html)를 검토합니다.
어느 쪽이든 비용은 작업 전에 말씀드리고 동의하신 다음에만 진행합니다. / 고쳐서 쓸 수 있는데 굳이 바꾸자고 권하지는 않습니다.

# 사시는 분 확인은 개방 때처럼 이어집니다
문을 열 때 신분을 확인한 것처럼 점검과 번호 재설정도 사시는 분이 직접 하는 것이 원칙입니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번호를 새로 정하는 단계에서는 옆에서 알려드리되 번호 자체는 본인이 입력합니다. / 새 번호는 제가 알 필요가 없는 정보이기 때문입니다.
처음 문을 열 때 이미 확인이 끝났다면 점검 단계에서 다시 번거롭게 하지 않습니다.
@ 부흥동 출장열쇠 개방 후 재발 방지

# 며칠 뒤 한 번 더 확인할 것
점검을 마쳤어도 사나흘 지나면 한 번 더 문을 살펴보세요. / 처음에는 괜찮아 보여도 며칠 쓰다 보면 드러나는 증상이 있기 때문입니다.
문을 닫을 때 평소보다 힘이 드는지, 번호판 반응이 느려지지 않았는지 봅니다. / 이상한 소리가 새로 나기 시작했는지도 귀 기울여 보세요.
이때 이상이 보이면 처음 연락한 곳에 그대로 알리면 이어서 봐드립니다. / 한 번 연 문은 끝까지 책임진다는 생각으로 마무리합니다.

# 부흥동 말고 안양 전 지역이 가능합니다
부흥동 옆 평촌동, 호계동, 비산동, 귀인동, 관양동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
지역별 안내는 [안양시 출장열쇠](anyang.html)에 있고, 진행 방식은 [이용안내](guide.html)에 정리했습니다. / 문 여는 방식은 [현관문 개문](door-open.html) 페이지에서 볼 수 있습니다.

# 자주 묻는 질문

? 점검만 해도 비용이 드나요? | 작업 전에 먼저 말씀드립니다. 동의하신 것만 진행합니다.
? 비밀번호는 누가 정하나요? | 본인이 직접 입력합니다. 저는 번호를 알지 못합니다.
? 문을 못 열면 어떻게 되나요? | 끝내 못 열면 비용은 받지 않습니다.
? 새벽에도 오시나요? | 24시간 받습니다. 시간 상관없이 전화 주세요.

# 마무리
문이 열린 그 순간이 재발을 막을 가장 좋은 기회입니다. / 배터리, 번호, 문틀, 습관 순서로 하나씩 짚어 보세요.
24시출장열쇠는 부흥동을 비롯한 안양 어디서든 24시간 전화를 받습니다. / 서울, 경기 전 지역, 전화 010-3664-5455로 연락 주세요.
