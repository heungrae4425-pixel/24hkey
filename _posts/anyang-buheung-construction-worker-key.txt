# 공사 시작 전날 걸려오는 전화
부흥동은 범계역과 평촌역 사이 생활권이라 집수리나 인테리어를 하는 집이 꾸준히 있습니다. / 공사가 잡히면 가장 먼저 부딪히는 문제가 현관 열쇠를 어떻게 맡기느냐입니다.
출근한 사이에 작업자가 들어와야 하는데 집에 사람이 없으면 곤란해집니다. / 열쇠를 건네자니 불안하고 매일 문을 열어 주자니 시간이 안 맞습니다.
이 글은 공사 인력에게 출입 수단을 맡길 때 확인할 것을 정리했습니다. / 문제가 생겼을 때 [안양 출장열쇠](anyang.html)를 부르는 기준도 함께 적었습니다.
@ 부흥동 인테리어 공사 전 현관 도어락 점검

# 열쇠를 그대로 건네면 생기는 일
실물 열쇠나 카드를 그대로 주면 공사가 끝난 뒤에도 사본이 어디 있는지 알기 어렵습니다. / 작업자가 바뀌는 공사라면 더 그렇습니다.
복사 여부를 일일이 확인할 방법도 마땅치 않습니다. / 그래서 되도록 회수 가능한 방식으로 맡기는 게 좋습니다.
- 실물 열쇠는 사본이 생겨도 알 수 없다는 점
- 카드키는 분실하면 누가 줍는지 모른다는 점
- 번호 하나를 여러 사람이 돌려 쓰면 누가 들어왔는지 구분이 안 된다는 점

# 임시 번호가 되는 도어락인지 먼저 확인
도어락 중에는 기본 번호 외에 손님용 번호를 따로 만들 수 있는 제품이 있습니다. / 설명서나 제품 뒷면 안내를 보면 몇 개까지 등록되는지 알 수 있습니다.
기능이 있다면 공사용 번호를 새로 하나 만들어 주는 것이 가장 깔끔합니다. / 공사가 끝나면 그 번호만 지우면 되기 때문입니다.
기능이 없는 도어락이라면 기존 번호를 바꾸기 전 가족에게 먼저 알려야 합니다. / 그래야 나중에 우리 식구가 문 앞에서 막히지 않습니다.

# 번호는 공사 기간에만 쓰도록 정하기
임시 번호는 시작일과 끝나는 날을 정해 놓고 쓰는 습관이 필요합니다. / 달력에 지울 날짜를 적어 두면 잊지 않습니다.
공사 일정이 길어지면 중간에 번호를 한 번 바꾸는 것도 방법입니다. / 작업 팀이 교체되었을 때는 특히 새 번호로 바꿔 주세요.
번호는 문자로 보내기보다 전화로 직접 알려주는 편이 흔적이 덜 남습니다. / 받는 사람도 메모하지 말고 외우도록 부탁하면 좋습니다.

# 작업자 확인은 이렇게 하세요
공사 업체가 보낸 사람이 맞는지는 업체와 먼저 연락해 확인하세요. / 이름과 연락처를 미리 받아 두면 출입 기록을 맞춰 보기 쉽습니다.
처음 방문하는 날은 가능하면 집주인이 직접 만나 문을 열어 주는 게 좋습니다. / 그날 도어락 사용법과 문 닫는 법도 같이 알려 주세요.
같은 번호로 계속 드나들더라도 누가 어느 날 들어왔는지 업체에서 정리하도록 요청해 두면 편합니다. / 서로 책임을 분명히 하는 데도 도움이 됩니다.

# 공사 중 도어락이 상하는 흔한 경우
공사 중에는 자재를 나르다 문이 손잡이에 부딪히거나 번호판이 가려지는 일이 생깁니다. / 먼지가 번호판 틈으로 들어가 반응이 둔해지기도 합니다.
- 자재가 문 모서리를 쳐서 문틀이나 경첩이 틀어짐
- 먼지와 이물질이 번호판 사이에 낌
- 문을 열어 둔 채 고정하느라 도어락 걸쇠를 눌러 둠
- 임시 보호 테이프가 틈새를 막아 걸쇠가 덜 나옴
이런 일이 보이면 공사 마무리 때 도어락이 잘 잠기는지 꼭 확인해 주세요. / 공사 중에도 이상하면 바로 말씀해 주시는 게 낫습니다.
@ 부흥동 공사 중 현관문 도어락 보호 작업

# 문 보호 작업은 도어락을 가리지 않게
현관문에 보호 비닐이나 테이프를 붙이는 작업이 많습니다. / 도어락 번호판과 손잡이까지 덮어 버리면 임시 번호를 쓸 수 없게 됩니다.
번호판 앞면만 얇게 가리고 터치 부분은 열어 두라고 미리 요청하세요. / 작업자가 터치 부분을 만지기 어려우면 출입이 막힙니다.
작업이 끝난 뒤 테이프 접착제가 남았다면 마른 수건으로 가볍게 닦아 주세요. / 세게 문지르면 도어락 표면이 상할 수 있습니다.

# 공사 중에 문이 안 열릴 때
작업자가 문이 안 열린다고 연락해 올 때는 혼자 판단하지 말고 현장 상황부터 물어보세요. / 번호판이 꺼졌는지, 소리가 나는지만 확인해도 원인이 좁혀집니다.
배터리가 다 되었거나 먼지가 낀 경우가 많습니다. / 급하다고 작업자가 문을 억지로 열게 두면 문과 도어락이 상합니다.
사시는 분이 직접 오기 어렵다면 위치와 상황을 알려 주시고 출장열쇠를 부르셔도 됩니다. / 이때는 신분 확인이 필요하니 서류를 미리 준비해 주세요.

# 신분 확인은 집주인 기준으로 합니다
공사 중인 집의 문을 열 때는 요청하신 분이 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
작업자가 대신 부탁하는 경우에는 먼저 집주인과 직접 통화해 확인합니다. / 번거롭더라도 이웃과 집주인 모두를 위한 절차입니다.
확인이 어렵다면 작업을 할 수 없으니 이 점 양해 부탁드립니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니라면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에서 볼 수 있고, 문을 여는 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 부흥동 출장열쇠 도어락 비파손 개방

# 공사가 끝난 날 해야 할 일
공사가 끝나면 그날 안에 임시 번호부터 지우세요. / 사용하지 않는 번호를 남겨 두면 나중에 불안이 생깁니다.
- 공사용으로 만든 번호 삭제
- 기존 번호를 쓰던 가족에게 변경 여부 알림
- 도어락 잠김과 열림이 정상인지 확인
- 건네준 열쇠와 카드키 회수 확인
- 번호판 주변 먼지와 접착제 닦기
도어락이 불안정해졌다면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 너무 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 공사 전에 알아 두면 좋은 습관
공사를 시작하기 전에 도어락 배터리를 새것으로 바꿔 두면 작업 중 꺼지는 일을 줄일 수 있습니다. / 공사 기간 내내 자주 열리고 닫히기 때문에 평소보다 배터리를 더 씁니다.
비상용 9V 건전지를 하나 갖춰 두는 것도 도움이 됩니다. / 번호판이 꺼졌을 때 비상 단자에 대 볼 수 있습니다.
공사 업체와는 출입 방법과 책임 범위를 미리 정해 두세요. / 서로 확인한 내용을 한 줄이라도 적어 두면 좋습니다.

# 부흥동 말고 안양 어디든 갑니다
부흥동 가까운 평촌동, 호계동, 관양동, 비산동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html)에 정리해 두었고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 공사 업체 직원이 문이 안 열린다고 부르면 열어 주나요? | 집주인과 직접 통화해 사시는 분이 맞는지 확인한 뒤에 진행합니다.
? 공사 중에 임시 번호를 따로 만들어도 되나요? | 도어락이 지원하면 가능합니다. 끝나는 날 바로 지우시길 권합니다.
? 문을 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 비용은 언제 알 수 있나요? | 문 열기 전에 먼저 말씀드리고 동의하시면 시작합니다.
? 공사 끝난 뒤 번호 정리도 해 주나요? | 네, 새 번호 등록과 지울 번호 정리까지 같이 도와드립니다.

# 마무리
공사 인력에게 열쇠를 맡길 때는 회수 가능한 방식과 끝나는 날짜를 정해 두세요. / 그것만 지켜도 공사 끝난 뒤 불안한 마음이 크게 줄어듭니다.
도어락이 안 열리거나 번호 정리가 필요하면 24시출장열쇠가 안양 전 지역에서 도와드립니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
