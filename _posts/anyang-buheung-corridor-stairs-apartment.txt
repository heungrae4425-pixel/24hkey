# 같은 아파트인데 문이 겪는 날씨는 다릅니다
부흥동은 평촌역과 범계역 사이 생활권에 여러 형태의 아파트가 모여 있습니다. / 복도식과 계단식은 같은 아파트라도 현관문이 받는 바람, 습기, 먼지가 크게 다릅니다.
환경이 다르니 도어락이 먼저 아픈 곳도 다릅니다. / 이 글은 복도식과 계단식 현관의 차이를 짚고, 각각 어떤 고장이 잦은지, 문이 안 열릴 때 [안양 출장열쇠](anyang.html)가 어떻게 살피는지 적었습니다.
@ 부흥동 복도식 계단식 아파트 현관 도어락

# 복도식 현관은 바람과 비를 그대로 받습니다
복도식 아파트는 현관문이 한쪽으로 길게 늘어선 바깥 복도에 면해 있습니다. / 복도가 바깥으로 열려 있으면 비바람과 눈이 문 앞까지 들이칩니다.
이런 환경에서는 번호판 틈새로 습기가 들어가 오작동이 생기기 쉽습니다. / 겨울에는 복도 찬 바람 때문에 배터리가 평소보다 빨리 줄어들기도 합니다.
복도 쪽으로 난 창문과 문이 마주 보는 구조라 바람이 세게 부는 날 문이 덜 닫히는 경우도 있습니다.

# 계단식 현관은 먼지와 사람 손길이 문제입니다
계단식 아파트는 한 층에 두세 집이 계단 홀을 같이 쓰는 구조입니다. / 복도식보다 바람은 덜 들지만 계단실을 오가는 사람이 많아 문이 자주 열리고 닫힙니다.
현관 앞 공간이 좁아 택배나 자전거, 짐을 쌓아 두는 집이 많습니다. / 문이 끝까지 열리지 않거나 닫히는 중에 물건에 걸려 래치가 어긋나는 일도 생깁니다.
계단실의 먼지가 도어락 틈새에 쌓여 버튼이 뻑뻑해지는 경우도 흔합니다.

# 환경별로 자주 보이는 증상
두 환경에서 자주 연락을 받는 증상을 정리하면 다음과 같습니다.
- 복도식: 비 온 뒤 번호판 오작동, 한파에 배터리 급감, 바람에 문이 덜 닫힘
- 계단식: 문 앞 물건에 걸려 래치 어긋남, 먼지로 버튼 끈적임, 이웃 소음에 놀라 보조키를 습관처럼 잠금
- 공통: 배터리 방전, 비밀번호 분실, 보조키 잠금
증상이 어느 쪽에 가까운지만 알아도 전화로 설명하기가 훨씬 쉬워집니다.
@ 부흥동 복도식 아파트 현관문 점검
복도식은 이웃 현관문과 가까워서 문을 세게 닫는 소리가 서로에게 다 들립니다. / 문이 쾅 닫히는 습관은 도어락 래치에도 부담을 주니 손으로 잡고 천천히 닫는 편이 좋습니다.

# 복도식 집은 이렇게 점검하세요
비가 많이 오는 철이나 눈이 온 다음 날에는 번호판 주변을 마른 천으로 닦아 주세요. / 물방울이 맺힌 채로 누르면 인식이 엇나갑니다.
문틀 아래쪽 문턱 부분에 낙엽이나 흙이 끼지 않았는지도 봅니다. / 래치가 걸리는 위치에 이물질이 있으면 문이 끝까지 닫히지 않습니다.
배터리는 겨울이 오기 전에 미리 바꿔 두면 한파에도 안심입니다.
복도 쪽 전등이 꺼져 있으면 번호판이 보이지 않아 헛눌러서 입력이 막히는 경우가 있으니 휴대폰 불빛을 활용하세요.
계단식은 한 층에 두세 집이 있어 이웃과 현관 앞 공간을 나누어 씁니다. / 문 앞 신발장이나 자전거가 문 열림 각도를 줄이지 않는지 한 번쯤 둘러보세요.

# 계단식 집은 이렇게 점검하세요
현관 앞에 놓은 짐이 문을 막고 있지 않은지 먼저 확인하세요. / 문이 닫히는 길에 물건이 걸리면 래치와 문틀 구멍이 맞지 않게 됩니다.
도어락 버튼 사이 먼지는 마른 면봉이나 부드러운 솔로 털어내면 됩니다. / 물이나 알코올을 흠뻑 묻히는 것은 피하세요.
계단실에서 문을 세게 닫는 습관이 있다면 도어클로저 상태도 같이 점검해 보세요. / 이 부분은 [도어락 수리](doorlock-repair.html) 안내에서 더 자세히 볼 수 있습니다.

# 문 앞에서 막혔을 때 먼저 확인할 것
어느 환경이든 문이 안 열릴 때는 같은 순서로 살펴보면 좋습니다.
- 번호판에 불이 들어오는지와 열림 소리가 나는지
- 보조키나 걸쇠를 잠가 두지 않았는지
- 문이 문턱이나 물건에 걸려 있지 않은지
- 9V 건전지를 비상 전원 단자에 대면 반응하는지
이 네 가지를 해 보고도 안 되면 그때 전화 주세요.

# 전화할 때 이렇게 알려주세요
부흥동은 평촌역 쪽에서 들어오는 길이 가까워서 방향만 알려주셔도 도착이 빠릅니다. / 복도식인지 계단식인지, 몇 층인지도 말씀해 주시면 엘리베이터와 이동 경로를 미리 가늠할 수 있습니다.
- 도로명 주소와 동, 호수
- 복도식인지 계단식인지, 층수
- 번호판 상태와 소리 여부
- 안에 아이나 반려동물이 있는지
도어락 사진을 보내 주시면 맞는 장비를 챙겨 가기 좋습니다.

# 도착하면 사시는 분인지 확인합니다
어떤 구조의 집이든 문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 찍힌 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있으면 경비실이나 관리사무소에 세대 확인을 부탁하세요. / 늦은 시간이면 미리 말해 두면 수월합니다.
이 절차를 거치지 않고 열어 드리는 일은 없습니다.

# 비용은 열기 전에, 못 열면 받지 않습니다
문 상태와 도어락 종류를 보고 비용이 얼마쯤인지 시작하기 전에 말씀드립니다. / 괜찮다고 하셔야 작업을 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 상하지 않게 열고 환경도 같이 봅니다
도어락과 문틀이 상하지 않는 방법으로 먼저 엽니다. / 연 뒤에는 왜 문제가 생겼는지 현관 환경까지 함께 봅니다.
복도식은 습기가 들어간 흔적, 계단식은 래치가 걸리는 위치를 중점으로 살핍니다. / 필요하면 고정 나사와 문틀 상태도 살펴봅니다.
방법은 [현관문 개문](door-open.html) 페이지에서 확인하실 수 있습니다.
@ 부흥동 아파트 현관 비파손 개방 작업
어느 쪽이든 문 두께와 보조키 위치를 먼저 확인해야 새 제품이 제대로 맞습니다. / 이 확인은 [도어락 설치](doorlock-install.html) 안내에 정리해 두었습니다.

# 환경에 맞는 도어락 고르기
교체를 생각한다면 환경에 맞는 제품을 고르는 게 좋습니다. / 바람과 습기가 많은 복도식은 번호판 방수 구조가 튼튼한 제품이 유리합니다.
계단식은 문이 자주 여닫히니 걸쇠와 래치가 튼튼한 제품이 오래 갑니다. / 선택 기준은 [도어락 교체](doorlock-replace.html)에 정리해 두었습니다.
꼭 새로 바꾸지 않아도 수리로 해결되는 경우가 많으니 먼저 상태를 보고 말씀드립니다.

# 부흥동 말고 안양 어디든 갑니다
부흥동 근처 평촌동, 호계동, 비산동, 관양동, 귀인동은 물론 안양동, 석수동, 박달동도 다닙니다. / 인덕원역, 범계역, 안양역 쪽도 같은 방식입니다.
[안양시 출장열쇠](anyang.html) 페이지와 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
