# 아이가 집에 들어왔는지 궁금한 저녁
학원이나 학교에서 돌아올 시간인데 연락이 없으면 마음이 쓰입니다. / 부흥동처럼 안양역과 범계역 쪽을 오가는 가족이 많은 동네에서는 귀가 시간이 제각각이라 더 그렇습니다.
이럴 때 도어락의 출입 기록 기능이 도움이 됩니다. / 누가 몇 시에 문을 열었는지 남는 제품이 있기 때문입니다.
이 글은 출입 기록을 어떻게 확인하고 어떤 점을 조심해야 하는지 정리한 것입니다. / 제품이 달라 방법은 다르지만 큰 틀은 비슷합니다.
설정 방법은 제품 설명서에 있으니 설명서를 못 찾겠다면 도어락 앞면의 모양과 상표 표시를 사진으로 보내 주세요. / 어떤 메뉴로 들어가는지 안내해 드립니다.
@ 부흥동 도어락 출입 기록 확인

# 출입 기록 기능이란
문이 열리고 닫힌 시각과 방법을 도어락이 기억해 두는 기능입니다. / 번호로 열었는지, 카드로 열었는지, 안쪽 손잡이로 열었는지가 구분되는 제품도 있습니다.
모든 도어락에 있는 기능은 아닙니다. / 기본형 번호키에는 없는 경우가 많고, 스마트 도어락에 주로 들어 있습니다.

# 기록을 보는 두 가지 방식
첫째는 도어락 본체에서 직접 보는 방식입니다. / 안쪽 설정 메뉴에 들어가 최근 기록을 화면이나 음성으로 확인합니다.
음성 안내가 나오는 제품은 숫자 버튼을 눌러 메뉴를 고르는 방식이 흔합니다. / 처음에는 낯설어도 한두 번 해 보면 금방 익숙해집니다.
둘째는 휴대폰 앱과 연동해서 보는 방식입니다. / 밖에 있어도 알림으로 받을 수 있지만 연동이 끊기면 알림이 오지 않기도 합니다.
앱이 안 맞을 때의 해결은 이 글보다 [도어락 수리](doorlock-repair.html) 쪽 상담이 빠릅니다. / 연동 오류는 제품별 차이가 커서 사진을 보고 말씀드립니다.

# 개별 번호를 나눠 줘야 기록이 쓸모 있습니다
가족 모두가 같은 번호를 쓰면 기록에는 "번호로 열림"만 남습니다. / 누가 열었는지 알고 싶다면 가족마다 다른 번호나 카드를 등록해야 합니다.
- 아이는 아이 전용 번호를 쓰기
- 부모님은 카드나 지문을 따로 등록하기
- 가사 도우미나 손님은 임시 번호로 구분하기
- 퇴실한 사람의 번호는 바로 삭제하기
번호를 개인별로 나누는 일은 보안에도 도움이 됩니다. / 누가 번호를 알고 있는지 관리하기도 쉬워집니다.
가족이 많을수록 번호를 하나만 쓰는 편이 편해 보이지만, 문제가 생겼을 때 원인을 찾기는 어렵습니다. / 번호가 퍼졌다고 느껴질 때 한 사람 것만 바꾸면 되는 점도 장점입니다.

# 시각이 틀리면 기록도 틀립니다
도어락 안의 시계가 어긋나 있으면 기록된 시각이 실제와 다릅니다. / 배터리를 완전히 빼 두었다가 끼운 뒤에는 시간이 초기화되는 제품이 있습니다.
기록을 믿고 쓰려면 먼저 시계를 맞춰 두어야 합니다. / 설정 메뉴에 시각 맞춤 항목이 있는지 설명서를 확인해 보세요.
하루에 몇 분씩 어긋나는 제품도 있으니 가끔 휴대폰 시계와 비교해 보세요. / 기록에 찍힌 시각이 이상하다면 먼저 시계부터 의심해 보시면 됩니다.
@ 도어락 시각 설정 확인

# 기록이 사라지는 경우
저장 개수가 정해져 있어서 오래된 기록부터 지워지는 제품이 많습니다. / 한 달 전 기록을 보려 했는데 남아 있지 않은 일이 생깁니다.
배터리가 완전히 방전되었다가 교체하면 기록이 사라지기도 합니다. / 중요한 기록은 앱 쪽에 따로 쌓이는 제품을 고르는 편이 낫습니다.
기록은 참고용이지 증거 자료로 단정하기는 어렵습니다. / 그날 문 열린 시각을 대략 파악하는 용도로 쓰시기를 권합니다.
정확한 사실 확인이 필요한 일이 생기면 기록에만 의존하지 말고 관리사무소나 주변 확인도 함께 하시는 편이 낫습니다. / 도어락 기록은 어디까지나 보조 도구입니다.

# 어르신 안부 확인에 쓸 때
혼자 사시는 부모님 댁이라면 하루 한 번쯤 문을 여닫은 흔적이 있는지 보는 용도로 쓸 수 있습니다. / 갑자기 오랜 시간 기록이 없으면 안부 전화를 해 보는 계기가 됩니다.
다만 부모님께 이 기능을 쓴다는 점을 미리 말씀드리는 것이 좋습니다. / 감시처럼 느껴지지 않도록 가족끼리 정해 두고 쓰세요.
어르신이 쓰기 편한 설정은 [도어락 설치](doorlock-install.html) 상담 때 같이 말씀드립니다.

# 아이 귀가 알림, 이렇게 설정하세요
앱이 있는 제품은 특정 번호가 사용되면 알림이 오도록 정할 수 있습니다. / 아이 번호로 문이 열리면 부모 휴대폰에 알림이 뜨게 해 두는 식입니다.
알림이 안 올 때는 휴대폰의 앱 알림 허용과 절전 모드 설정부터 보세요. / 도어락 쪽 문제가 아니라 휴대폰이 알림을 막고 있는 경우가 많습니다.
아이가 번호를 친구에게 알려 주지 않도록 한 번쯤 이야기해 두는 것도 필요합니다.
번호를 친구가 알게 되었다면 그날 바로 새 번호로 바꾸는 습관을 들이세요. / 번호를 바꾸는 일은 몇 분이면 끝납니다.
@ 아이 귀가 알림 설정 화면

# 개인정보와 공유 범위 확인
출입 기록은 가족의 생활 시간이 드러나는 정보입니다. / 앱 계정을 여러 사람이 같이 쓰거나 기록을 공유하는 설정이면 범위를 점검해 보세요.
이사나 세입자 변경이 있을 때는 이전 사용자의 계정 연결을 끊어야 합니다. / 설정을 지우는 일은 [도어락 교체](doorlock-replace.html)나 초기화 때 함께 하기도 합니다.

# 이럴 때는 출입 기록이 안 맞을 수 있어요
문을 열고 바로 닫지 않았거나, 닫힘이 불완전하면 기록이 두 번 남기도 합니다. / 안쪽에서 열고 나간 것도 한 번의 기록이 되는 제품이 있습니다.
따라서 기록 하나하나를 정확한 사실로 받아들이기보다 흐름을 보는 용도로 쓰세요. / 이상해 보이는 기록이 있어도 너무 놀라지 않으셔도 됩니다.

# 기록 확인이 안 될 때 전화 전 점검
- 배터리가 충분한지
- 본체 화면이나 음성이 정상으로 나오는지
- 앱과 도어락의 연결 상태 표시가 켜져 있는지
- 최근에 배터리를 뺀 적이 있는지
이 네 가지를 보고 말씀해 주시면 원인을 빨리 좁힐 수 있습니다. / 문이 아예 안 열려 급하다면 먼저 [현관문 개문](door-open.html)부터 문의해 주세요.

# 점검이나 교체가 필요하다면
출입 기록 기능이 필요한데 지금 도어락에 없으면 새 제품으로 바꾸는 방법이 있습니다. / 현장에서 문 두께와 기존 구멍을 보고 맞는 제품을 말씀드립니다.
비용은 작업 전에 먼저 말씀드리고, 마음에 안 드시면 그대로 돌아갑니다. / 문을 열어 드리는 출장에서 못 열면 비용은 받지 않습니다.
작업 전에는 사시는 분인지 신분증, 우편물, 관리사무소 확인을 합니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 부흥동 말고 안양 어디든 갑니다
부흥동 옆 귀인동, 안양동, 비산동, 평촌동도 다닙니다. / [안양 출장열쇠](anyang.html)에서 지역을 확인하시고, 다른 지역은 [출장 지역](area.html) 지도를 보세요.
