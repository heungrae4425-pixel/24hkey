# 부흥동 현관문이 끝까지 안 닫힌다면
부흥동은 범계역과 가까운 주택가와 아파트가 이어져 있어 출입문을 하루에도 여러 번 여닫는 집이 많습니다. / 문이 천천히 닫히다가 끝에서 멈추거나 반대로 쾅 닫히는 증상은 도어락이 아니라 문 쪽 문제일 때가 많습니다.
이 글은 문이 덜 닫히거나 쾅 닫힐 때 점검할 곳과 [안양 출장열쇠](anyang.html)가 어디까지 봐 드리는지 정리했습니다. / 도어락 고장과 구별하는 요령도 적었습니다.
@ 부흥동 현관문 도어클로저 경첩 점검 출장열쇠

# 도어락 문제와 문 문제는 이렇게 구별합니다
번호는 맞고 소리도 나는데 문이 안 닫히거나 걸린다면 문 쪽 문제를 의심합니다. / 반대로 번호판이 꺼지거나 입력이 안 되면 도어락 쪽 문제입니다.
문을 닫을 때 걸쇠가 문틀 구멍에 안 들어가면 문과 문틀의 높이가 어긋난 것입니다. / 이 경우 도어락을 바꿔도 같은 증상이 계속됩니다.

# 도어클로저가 하는 일
도어클로저는 문 위쪽에 달린 팔 모양 장치로 문이 천천히 닫히게 잡아 줍니다. / 오래되면 기름이 새거나 힘이 약해져 문이 끝까지 안 닫히거나 한꺼번에 닫힙니다.
팔 쪽에 기름이 번져 있거나 닫히는 속도가 달라졌다면 점검할 때가 된 것입니다. / 조절 나사로 속도를 맞추는 경우가 많지만 새것으로 바꿔야 할 때도 있습니다.

# 경첩이 헐거워졌을 때 생기는 일
문 옆 경첩 나사가 풀리면 문이 아래로 처지고 틀에 닿습니다. / 닫을 때 바닥 쪽이 긁히거나 윗부분이 안 맞는 소리가 납니다.
경첩 나사가 헐거우면 구멍이 닳아 나사가 계속 풀립니다. / 이때는 나사만 조이지 않고 구멍을 보강하거나 경첩을 바꾸는 방법을 씁니다.
@ 부흥동 현관문 경첩 처짐 24시 출장

# 문틀에 걸쇠가 안 맞을 때
걸쇠가 들어가는 문틀 구멍 위치가 어긋나면 닫혔는데도 잠기지 않습니다. / 이런 문은 겉으로는 닫힌 것처럼 보여 위험합니다.
처음에는 힘주어 밀면 잠기다가 어느 날부터 안 잠기게 됩니다. / 그 전에 점검받으시는 편이 훨씬 수월합니다.

# 밤에 쾅 닫히는 문 때문에 고민이라면
도어클로저 속도가 너무 빠르면 이웃 사이에 소음 문제가 생깁니다. / 닫히는 속도를 조금만 줄여도 한결 조용해집니다.
손으로 문을 잡아 천천히 닫아 보고 소리가 어디서 나는지 확인해 보세요. / 문틀 모서리 소리인지 장치 소리인지 알면 전화 상담이 훨씬 빨라집니다.

# 전화하실 때 알려주실 것
문이 안 닫히는지 안 열리는지부터 말씀해 주세요. / 위치와 도어락 모양, 도어클로저 유무도 함께 알려주세요.
- 문이 끝까지 닫히는지 걸리는지
- 닫을 때 어디가 긁히는지
- 도어클로저가 달려 있는지
- 번호판은 정상인지
- 사진을 보낼 수 있는지

# 문이 안 닫혀 집을 비우기 곤란할 때
문이 덜 닫히면 외출하기 불안합니다. / 이럴 땐 문을 임시로 닫아 두고 열쇠나 비상 방법으로 잠가 두시고 점검을 연락 주세요.
무리하게 힘으로 문을 눌러 닫으면 경첩이 더 틀어집니다. / 그대로 두고 연락 주시는 게 낫습니다.

# 사시는 분인지 확인하고 시작합니다
작업 전에 신분증 주소나 우편물 등으로 사시는 분인지 확인합니다. / 집 안에 들어가는 일이라 꼭 필요한 절차입니다.
확인 후에 문 상태를 보고 비용을 문을 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.

# 문을 못 여는 상황이라면
문이 틀에 끼어 아예 안 열리는 경우도 있습니다. / 그럴 땐 [현관문 개문](door-open.html)처럼 덜 상하는 방법부터 차례로 해 봅니다.
끝내 못 열면 비용은 받지 않습니다. / 열고 나서 말 없이 붙는 비용도 없습니다.

# 점검 후 같이 확인하는 것
문이 끝까지 닫히는지, 잠기고 풀리는 소리가 정상인지 확인합니다. / 도어락이 문틀과 잘 맞는지도 같이 봅니다.
도어락 자체가 문제라면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드리고 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 권합니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.
@ 부흥동 24시 출장열쇠 도어락 문 점검

# 문을 오래 쓰는 생활 습관
문을 세게 닫거나 문 앞에 짐을 기대 두면 경첩에 무리가 갑니다. / 가끔 문을 열고 닫으며 소리와 걸리는 곳을 확인해 보세요.
- 경첩 나사가 풀렸는지 한 번씩 확인
- 도어클로저 팔에 기름이 번졌는지 보기
- 문틀 모서리 긁힘이 생겼는지 보기
- 문이 뻑뻑해지면 미루지 말고 점검

# 부흥동 말고 안양 어디든
부흥동 옆 귀인동, 평촌동, 호계동, 비산동까지 24시간 다닙니다. / 범계역 근처가 아니어도 안양 안이면 위치만 알려주세요.
[출장 지역](area.html) 지도에서 다른 지역도 확인할 수 있습니다.
