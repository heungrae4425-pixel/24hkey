# 부흥동에서 열림 버튼을 눌렀는데 문이 꿈쩍 않을 때
부흥동은 범계역에서 가까워 아파트와 빌라, 상가가 이어진 생활권이라 인터폰으로 손님을 맞는 집이 많습니다. / 택배나 가족이 왔는데 열림 버튼을 눌러도 문이 안 열리면 서로 당황하기 쉽습니다.
이 글은 인터폰 열림 버튼이 먹히지 않을 때 어디서 막힌 것인지 좁혀 보는 순서를 정리했습니다. / 정리한 내용으로도 안 풀리면 [안양 출장열쇠](anyang.html)를 부르면 됩니다.
@ 부흥동 인터폰 열림 버튼과 공동현관

# 어느 문이 안 열리는지부터 나눠 보세요
열림 버튼은 공동현관 문을 여는 것과 세대 현관을 여는 것이 다릅니다. / 어느 쪽이 안 열리는지 알아야 원인이 보입니다.
- 건물 공동현관만 안 열리는 경우
- 세대 현관문 도어락만 안 열리는 경우
- 둘 다 안 열리는 경우
- 어떤 때는 열리고 어떤 때는 안 열리는 경우
공동현관과 세대 현관은 관리 주체가 다른 경우가 많아서 연락할 곳도 달라집니다.

# 인터폰 소리와 화면은 정상인가요
버튼을 눌렀을 때 인터폰에서 어떤 소리가 나는지 들어 보세요. / 딸깍 하는 소리가 나는데 문이 안 열리면 전기는 들어가는데 문 쪽 장치가 반응하지 않는 경우입니다.
아무 소리도 나지 않고 화면도 꺼져 있으면 인터폰 전원이나 배선 쪽 문제를 의심해야 합니다. / 소리는 나는데 상대방 목소리가 안 들리면 통화 쪽 문제일 수 있습니다.
증상을 구체적으로 알려 주시면 원인 추정이 빨라집니다.

# 열림 버튼이 하는 일은 생각보다 단순합니다
인터폰의 열림 버튼은 전기 신호를 보내 문의 전기식 잠금 장치를 잠깐 풀어 주는 방식입니다. / 그래서 신호가 가는 길 중 어디 한 군데만 문제가 생겨도 문이 안 열립니다.
- 인터폰 본체의 버튼 접점 불량
- 배선 중간의 접촉 불량이나 끊어짐
- 문 쪽 전기 잠금장치 자체의 고장
- 문이 문틀에 눌려 잠금이 풀려도 못 열리는 경우
이 가운데 문틀에 눌리는 경우는 잠금장치가 풀려도 문이 열리지 않아 헷갈립니다.
@ 부흥동 전기 잠금장치와 문틀 상태 확인

# 문을 살짝 밀면서 눌러 보세요
전기 잠금장치는 문이 틀에 세게 눌려 있으면 풀려도 걸림이 남을 수 있습니다. / 열림 버튼을 누르는 순간 문을 안쪽으로 살짝 밀어 주면 열리기도 합니다.
이때 문을 세게 당기거나 흔들면 오히려 장치가 망가질 수 있습니다. / 가볍게 힘을 주고 버튼을 눌러 보세요.
날씨가 더워 문이 팽창했거나 비가 와서 문틀이 부풀었을 때도 이런 증상이 생깁니다. / 계절에 따라 반복된다면 문틀 처짐과 연관이 있을 수 있습니다.

# 공동현관 쪽 문제일 때는 관리사무소가 먼저입니다
공동현관 전기 잠금은 건물 공용 설비라 개인이 손대기 어렵습니다. / 관리사무소나 경비실에 먼저 알리는 것이 순서입니다.
- 어느 동, 어느 출입구에서 증상이 있는지
- 언제부터 안 열렸는지
- 다른 세대도 같은 증상인지
- 입주민 카드나 번호로는 열리는지
공용 설비 문제는 건물 전체의 일이라 혼자 해결하려 하면 시간만 더 걸립니다.

# 세대 현관문 도어락이 같이 안 열릴 때
인터폰 쪽은 정상인데 세대 현관 도어락이 안 열린다면 배터리나 걸쇠 문제일 수 있습니다. / 번호판이 켜지는지, 번호를 누르면 소리가 나는지 먼저 확인하세요.
인터폰으로 열어 주는 방식에 익숙해지면 평소 번호를 쓸 일이 줄어 번호를 잊는 경우도 생깁니다. / 번호를 모를 때는 억지로 여러 번 시도하지 마세요.
번호판이 안 켜지면 배터리를 확인하고, 9V 단자가 있는 제품이면 임시 전원으로 한 번 시도해 볼 수 있습니다. / 그래도 안 되면 전화 주세요.

하지 말아야 할 일도 있습니다.
- 버튼을 오래 계속 눌러 대기
- 인터폰 본체 덮개를 열어 선을 직접 만지기
- 문 틈에 드라이버를 넣어 벌리기
- 공용 현관 문을 발로 차거나 힘으로 열기
인터폰 배선에는 낮은 전기가 흐르지만 선을 임의로 이으면 합선이 날 수 있습니다. / 공용 설비를 상하게 하면 책임 문제가 생길 수 있으니 조심하세요.

# 출장 요청할 때 알려 주실 내용
부흥동은 범계역 쪽과 주택가가 섞여 있어 건물 입구가 여러 군데인 곳이 있습니다. / 아래 내용을 알려 주시면 준비가 빨라집니다.
- 동, 호수와 건물 출입구 특징
- 공동현관인지 세대 현관인지
- 열림 버튼을 눌렀을 때 소리나 불빛의 반응
- 집 안에 사람이 있는지, 급한 사정이 있는지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙기기 좋습니다. / 접수 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 신분 확인은 이렇게 합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
인터폰으로 열어 주는 관계라도 내 집인지 확인하는 절차는 같습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.
@ 부흥동 신분증과 우편물로 거주 확인

# 비용은 문을 열기 전에 말씀드립니다
문 상태와 장치 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
인터폰 자체나 공용 설비 수리는 해당 관리 주체에게 요청해야 할 수 있습니다. / 출장열쇠는 문을 여는 것과 도어락 쪽 점검을 맡습니다.
문 여는 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 열고 난 뒤에는 문 쪽 상태를 같이 봅니다
문이 열리면 도어락과 걸쇠, 문틀 위치를 확인합니다. / 문이 눌려 있다면 경첩이나 문틀 쪽을 손봐야 하는 경우도 있습니다.
도어락이 원인이면 [도어락 수리](doorlock-repair.html)로 먼저 점검하고, 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
인터폰 쪽 문제는 관리 주체에게 알리도록 안내해 드립니다.

# 평소에 해두면 좋은 것
- 인터폰 열림 버튼이 평소 잘 눌리는지 가끔 확인
- 공동현관 번호나 카드는 가족과 같이 알아 두기
- 도어락 번호는 인터폰에만 의존하지 않고 외워 두기
- 배터리는 해마다 정해진 시기에 교체
- 문이 덜 닫히거나 눌리면 경첩 점검
인터폰이 열어 주는 편의에 익숙해져도 비상시를 위한 방법은 따로 챙겨 두세요.

# 부흥동 말고 안양 어디든 갑니다
부흥동 가까운 평촌동, 관양동, 호계동, 비산동, 귀인동과 안양동, 석수동, 박달동도 다닙니다. / 안양 안이면 24시간 출동합니다.
[안양시 출장열쇠](anyang.html) 페이지와 [출장 지역](area.html)에서 확인하실 수 있습니다.
