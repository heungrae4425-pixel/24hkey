# 부흥동에서 도어락을 바꾸려 할 때
부흥동은 아파트와 빌라, 상가 건물이 섞여 있어 문 종류가 다양한 동네입니다. / 그래서 같은 도어락이어도 집마다 달라지는 경우가 많습니다.
인터넷에서 마음에 드는 제품을 골랐는데 우리 집 문에 맞는지 몰라 고민하시는 분이 많습니다. / 이 글은 안양 부흥동에서 도어락을 바꾸기 전에 확인할 것을 적었습니다.
@ 부흥동 도어락 교체 비용 안내 출장열쇠

# 먼저 고쳐 쓸 수 있는지부터 봅니다
도어락이 말썽이라고 바로 새것으로 바꿔야 하는 건 아닙니다. / 배터리나 걸쇠, 센서 같은 부품이 문제라면 고쳐서 쓸 수 있습니다.
- 번호판이 간헐적으로 안 켜진다
- 열리는 소리가 약하다
- 카드는 되는데 번호가 안 먹는다
이런 경우는 [도어락 수리](doorlock-repair.html)로 먼저 확인하는 것이 순서입니다.

# 바꾸는 게 나은 경우
수리해도 다시 고장 나는 오래된 제품이나 부품이 더는 나오지 않는 제품은 교체가 낫습니다. / 걸쇠나 모터가 닳은 도어락도 마찬가지입니다.
이럴 때는 [도어락 교체](doorlock-replace.html) 이야기를 말씀드립니다. / 바꿔야 하는 이유를 먼저 설명해 드립니다.

# 우리 집 문 두께 확인
도어락은 문 두께가 맞아야 달 수 있습니다. / 대부분 일반 아파트 현관문은 비슷한 두께지만 오래된 문이나 방화문은 다를 수 있습니다.
줄자로 문 옆면의 두께를 재서 메모해 두세요. / 정확하지 않아도 사진으로 보내 주시면 같이 확인해 드립니다.

# 기존 구멍 규격과 보조키
도어락을 떼어 낸 자리에 새 제품이 맞아야 합니다. / 구멍 크기가 다르면 문을 손봐야 할 수도 있습니다.
- 도어락 위나 아래에 보조키가 달려 있는지
- 문 안쪽 판 크기와 손잡이 위치
- 문 옆면의 걸쇠 위치
사진 두세 장이면 필요한 부분을 대부분 확인할 수 있습니다.
@ 부흥 열쇠집 도어락 교체 설치

# 어떤 종류를 쓸지 가족과 정하세요
번호, 카드, 지문 등 어떤 방식이 필요한지 먼저 가족과 이야기해 보세요. / 아이가 있거나 어르신이 계신다면 쓰기 쉬운 방식이 우선입니다.
- 번호만 쓸지, 카드나 지문도 같이 쓸지
- 문을 열고 닫는 방향과 손잡이 모양
- 정전이 났을 때 열 수 있는 방법이 있는지
사용하는 사람이 편한 게 가장 오래 씁니다.

# 비용은 이렇게 안내합니다
비용은 문 상태와 도어락 종류에 따라 달라집니다. / 그래서 미리 숫자로 말씀드리지 않고 문을 확인한 뒤 먼저 말씀드립니다.
괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다. / 하고 난 뒤에 말없이 붙는 비용은 없습니다.

# 제품은 직접 사 두셔도 됩니다
이미 사 두신 제품이 있다면 모델명을 알려 주세요. / 우리 집 문에 맞는지 먼저 확인해 드립니다.
맞지 않는 제품을 설치하면 문이 상하니 사시기 전에 한 번 물어보셔도 좋습니다. / 제품 선택이 어렵다면 문 사진만 보내 주세요.

# 설치 순서는 이렇습니다
도착하면 기존 도어락을 먼저 확인하고 문에 맞는지 봅니다. / 이상이 없으면 기존 제품을 떼고 새 제품을 다는 순서입니다.
- 기존 도어락 상태와 문 확인
- 비용 안내 후 동의
- 기존 제품 제거와 문 정리
- 새 제품 설치와 작동 확인
- 번호와 카드 등록
설치 방식은 [도어락 설치](doorlock-install.html) 페이지에도 적어 두었습니다.

# 설치 후 꼭 확인할 것
- 번호와 카드가 모두 정상으로 열리는지
- 문을 닫을 때 걸쇠가 한 번에 걸리는지
- 안쪽 잠금과 보조키가 같이 잘 도는지
- 배터리 덮개가 단단히 닫히는지
이상이 있으면 그 자리에서 바로 말씀해 주세요.
@ 부흥동 도어락 교체 설치 완료 확인

# 이런 경우는 교체 전에 문부터
문이 처졌거나 문틀이 어긋난 집은 도어락만 바꿔도 같은 문제가 이어집니다. / 이 경우는 경첩이나 문틀 상태를 먼저 점검합니다.
문 상태 때문에 안 맞는 경우에는 어떻게 하는 게 좋은지 먼저 말씀드립니다. / 무리하게 바꾸자고 하지 않습니다.

# 처음 쓰는 사람을 위한 관리
- 번호는 가족과 함께 정하고 생일은 피하기
- 배터리 교체 날짜를 안쪽 덮개에 적어 두기
- 카드 하나는 집 밖 가방에 따로 두기
- 비밀번호는 자주 바꾸지 않아도 이사 때는 꼭 바꾸기
처음 쓸 때 익숙해지도록 한 번씩 눌러 보세요.

# 견적을 받을 때 물어볼 것
교체 비용을 알아볼 때는 한 가지만 묻지 말고 여러 가지를 같이 물어보세요. / 같은 제품이라도 문 상태에 따라 작업이 달라질 수 있습니다.
- 문을 보고 나서 비용을 말해 주는지
- 설치비와 제품값이 따로인지
- 문을 손봐야 할 때 추가가 있는지
- 설치 후 문제가 생기면 어떻게 하는지
전화로 정확히 말하기 어려운 부분은 문을 확인한 뒤에 말씀드립니다.

# 교체한 뒤 기존 도어락은
떼어 낸 기존 도어락은 가지고 가실지, 처리해 드릴지 미리 정해 두세요. / 번호나 카드 정보가 남아 있는 제품은 그냥 버리지 않는 것이 좋습니다.
요청하시면 기존 제품의 정보는 지우고 처리해 드립니다. / 필요한 부품이 쓸 만하다면 알려 드립니다.
