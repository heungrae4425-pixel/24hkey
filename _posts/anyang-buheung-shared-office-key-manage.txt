# 여러 사람이 쓰는 문은 관리가 다릅니다
부흥동에서 범계역이나 평촌역 쪽으로 이동하며 공동 사무실이나 공유 공간을 쓰는 분들이 있습니다. / 혼자 쓰는 집과 달리 문 하나를 여러 사람이 쓰면 열쇠와 번호 관리가 금세 복잡해집니다.
입주자가 들고 나는 일이 잦으면 누가 어떤 번호를 아는지 잊어버리기 쉽습니다. / 이 글은 그런 공간에서 문 관리 기준을 세우는 방법을 정리했습니다.
특히 계약 기간이 짧은 회원이 섞여 있는 곳은 번호 관리가 허술해지기 쉽습니다. / 한 번 정리해 두면 이후는 훨씬 가벼워집니다.
문이 막혔을 때는 [안양 출장열쇠](anyang.html)가 도와드립니다.
@ 부흥동 공유 사무실 출입문

# 먼저 누가 관리자인지 정합니다
공동 공간의 가장 큰 문제는 문제가 생겼을 때 누구에게 말해야 하는지 모호하다는 점입니다. / 관리자 한 사람, 가능하면 대리인 한 사람까지 정해 두면 대부분 정리됩니다.
관리자는 번호를 바꾸고 카드를 등록하는 권한을 가집니다. / 다른 사람이 임의로 번호를 바꾸지 않도록 서로 약속해 두세요.
관리자가 바뀔 때는 인수인계 메모를 남겨 두세요. / 어떤 번호와 카드가 쓰이는지 정리한 목록이 있어야 다음 사람이 당황하지 않습니다.
건물 전체를 관리하는 주인이나 관리 회사가 따로 있다면 그 관계도 정리해 둡니다. / 어디까지 우리가 결정하고 어디부터 건물 쪽 허락이 필요한지를 알아 두면 헤맬 일이 줄어듭니다.

# 번호는 사람별로 나누는 것이 좋습니다
모두가 같은 번호 하나를 쓰면 누가 들어왔는지 알 수 없고 한 사람이 나갈 때 모두의 번호를 바꿔야 합니다. / 사용자별 번호나 카드를 등록할 수 있는 제품이면 그 기능을 쓰는 편이 낫습니다.
번호를 메신저 단체방에 그대로 올리면 나간 사람의 휴대폰에도 남습니다. / 가능하면 직접 말로 전하거나 개별로 알려 주는 방식을 권합니다.
사람별 등록이 안 되는 제품이라면 최소한 입주 시기마다 번호를 바꾸세요. / 바꾼 날짜와 알려 준 사람을 관리자가 적어 둡니다.
- 입주 때: 새 번호 또는 새 카드 등록
- 퇴실 때: 해당 번호나 카드 삭제
- 분실 때: 그 즉시 삭제 후 재등록
- 정기적으로: 사용하지 않는 번호 정리
@ 공유 공간 도어락 번호 관리

# 열쇠를 복사할 때의 원칙
복사 열쇠는 누구에게 몇 개를 주었는지 기록해 두어야 합니다. / 기록이 없으면 나중에 몇 개가 돌아다니는지 알 수 없습니다.
복사는 관리자의 허락을 받고 하는 규칙을 만들면 안전합니다. / 퇴실하는 사람은 받은 열쇠를 반드시 반납하도록 합니다.
열쇠를 복사한 가게에 복사본이 더 있을 가능성도 있으니 분실이 확실하면 잠금 자체를 바꾸는 편이 마음 편합니다. / 그 판단도 상황을 보고 같이 정리해 드립니다.
열쇠가 없어졌을 때 알리는 것을 꺼리지 않도록 분위기를 만들어 두세요. / 숨기고 지나가면 문제가 커집니다.

# 퇴실 직후 가장 중요한 일
사람이 떠난 뒤에 번호나 열쇠가 그대로 남아 있으면 보안이 취약해집니다. / 나간 날 바로 해당 번호를 지우는 습관이 가장 중요합니다.
공유 공간은 회원이 자주 바뀌므로 매번 번호 전체를 바꾸기보다 개별 삭제가 가능한 제품이 편합니다. / 필요하면 [도어락 교체](doorlock-replace.html)로 사용자별 관리가 되는 제품을 알아볼 수 있습니다.
상황에 맞는 선택은 현장을 보고 말씀드립니다. / 불필요한 교체는 권하지 않습니다.
퇴실이 잦은 곳은 매번 바꾸는 번거로움을 줄이는 방향을 먼저 고민해 보는 편이 좋습니다.

# 늦게까지 일하는 공간의 문 사용
야근이나 늦은 작업이 잦은 공간은 마지막 사람이 문을 잠그는 규칙이 필요합니다. / 누가 마지막에 나갔는지 모르면 문이 열린 채 방치되기 쉽습니다.
늦은 밤 문이 안 열리는 상황도 생기는데, 이때는 건물 관리자와 먼저 연락이 닿는지 보세요. / 연락이 닿지 않으면 출장을 요청하셔도 됩니다.
도어락 배터리는 공유 공간일수록 사용 횟수가 많아 더 빨리 닳습니다. / 일반 가정보다 짧은 주기로 점검하는 편이 좋습니다.
경고음은 한 번 울린 뒤 계속 기다리지 말고 그날 바로 전부 교체하세요. / 손님이 많은 공간일수록 문이 막히면 여러 사람이 영향을 받습니다.

# 문이 안 열릴 때 구분해서 확인
번호판이 꺼졌는지, 번호는 켜지는데 안 되는지 먼저 확인합니다. / 누군가 번호를 바꾼 것은 아닌지 관리자에게 바로 물어보세요.
출입문이 유리문이거나 자동문 방식이면 구조가 달라 확인할 것이 다릅니다. / 어떤 형태인지 전화로 말씀해 주세요.
문을 억지로 열려다 파손하면 책임을 가리기 어려워집니다. / 건물 소유자와 입주자 사이에서 문제가 되지 않도록 무리하지 마세요.
출입문 안에 귀중품이나 서류가 있는 공간이라면 더더욱 비파손으로 여는 것이 낫습니다.

# 출장을 요청할 때 알려 주실 것
공유 공간은 건물 이름이 같고 호실이 많아 위치를 정확히 알려야 합니다. / 몇 층 몇 호인지, 건물 입구와 사무실 문 중 어느 문인지 말씀해 주세요.
- 건물 공용 현관인지 사무실 출입문인지
- 도어락 종류와 번호판 상태
- 관리자나 건물 주인에게 연락했는지
- 안에 사람이 있는지
요청하시는 분이 해당 공간을 쓰는 분임을 확인할 수 있어야 합니다.
공간 이름이나 간판 사진이 있으면 보내 주세요. / 찾아가는 시간이 줄어듭니다.

# 도착하면 확인하는 것
문을 여는 일이라 사용하는 분인지 먼저 확인합니다. / 사업자 정보가 나온 서류, 계약서, 주소가 찍힌 우편물, 건물 관리 쪽 확인 중 하나면 됩니다.
개인 신분증과 함께 사무실 사용을 보여 줄 수 있는 자료를 준비해 주세요. / 건물 관리사무소의 확인을 받아 주셔도 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 시간이 줄어듭니다.
공유 공간은 계약자와 실제 이용자가 다를 수 있으니 누가 요청하는지도 함께 말씀해 주세요.
@ 부흥동 출장열쇠 출입문 확인

# 비용은 열기 전에, 못 열면 없습니다
현장에서 문과 도어락을 보고 비용을 먼저 말씀드립니다. / 동의하신 뒤에 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
비용을 공동으로 나누는 곳이라면 누가 결제하는지 미리 정해 두면 정리가 쉽습니다. / 진행 방식은 [이용안내](guide.html)에도 정리했습니다.

# 열린 뒤 바로 하면 좋은 정리
문이 열리면 배터리 상태를 확인하고 필요하면 같이 바꿉니다. / 번호가 문제였다면 새 번호를 등록하고 이전 번호는 지웁니다.
등록된 카드와 번호 목록을 한번 훑어보고 이미 나간 사람의 것은 삭제하세요. / 목록을 보는 방법은 제품마다 달라서 현장에서 같이 확인해 드립니다.
[현관문 개문](door-open.html) 방식도 참고해 보세요. / 고장이 반복되면 [도어락 수리](doorlock-repair.html)를 먼저 권해 드립니다.

# 사무실 열쇠 관리 점검표
한 달에 한 번이라도 아래 정도만 보면 큰 사고를 막을 수 있습니다. / 어렵지 않은 항목이라 관리자가 돌아가며 맡아도 됩니다.
- 현재 쓰는 번호와 카드 사용자 목록 대조
- 나간 사람의 열쇠 회수 여부
- 배터리 잔량과 경고음
- 문 닫힘과 잠금 상태
- 비상 연락처 최신화

# 부흥동 말고 안양 곳곳으로 갑니다
평촌동, 비산동, 관양동, 호계동, 귀인동, 안양동, 석수동, 박달동도 다닙니다. / 인덕원역과 안양역 근처까지 안양 안이면 24시간 출동합니다.
[출장 지역](area.html)에서 다른 지역도 확인할 수 있습니다.
