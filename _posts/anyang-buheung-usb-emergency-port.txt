# 부흥동 도어락, 바깥에 USB 단자가 있다면
부흥동에서 집으로 들어가려는데 번호판이 꺼져 있으면 가장 먼저 배터리를 떠올립니다. / 안양역이나 범계역 쪽에서 늦게 돌아오는 날이면 더 막막합니다.
요즘 도어락 중에는 9V 건전지 단자 대신 USB 단자가 달린 제품이 있습니다. / 이 글은 그 단자로 비상 전원을 넣는 법과 안 될 때 어떻게 하는지 정리했습니다.
끝까지 안 되면 [안양 출장열쇠](anyang.html)를 부르시면 됩니다. / 그 전에 해볼 수 있는 것을 순서대로 적었습니다.
@ 부흥동 도어락 USB 비상 전원 단자

# USB 단자는 어디에 있나
단자는 대개 손잡이 아래쪽이나 번호판 옆, 또는 외부 덮개 안쪽에 있습니다. / 작은 덮개를 밀거나 손톱으로 살짝 열어야 보이는 제품도 있습니다.
USB 단자가 아니라 9V 건전지용 접점인 경우도 있어서 모양을 잘 봐야 합니다. / 접점이 두 개의 금속 단자처럼 보이면 건전지용입니다.
어떤 모양인지 모르겠다면 사진을 찍어 문자로 보내 주셔도 확인해 드립니다.

# 보조배터리와 케이블 준비
케이블은 짧은 것보다 어느 정도 길이가 있는 것이 편합니다. / 단자가 낮은 위치에 있으면 보조배터리를 바닥에 둘 수 있어야 손이 편합니다.
보조배터리 잔량이 거의 없으면 전류가 모자라 제품이 반응하지 않을 수 있습니다. / 충전 표시등이 몇 칸 남았는지 확인하고 연결하세요.
필요한 것은 보조배터리와 케이블 하나입니다. / 휴대폰 충전용 케이블이 단자 모양과 맞으면 그대로 쓸 수 있습니다.
- 충전이 되어 있는 보조배터리
- 도어락 단자 모양에 맞는 케이블
- 단자 방향을 확인할 휴대폰 손전등
보조배터리가 없으면 근처 편의점이나 이웃에게 빌려 보세요. / 자동차에 있다면 차량 충전 단자에 연결해 쓸 수도 있습니다.

# 연결하고 반응이 오는지 보기
연결한 채로 손을 떼면 케이블이 빠지는 구조라면 보조배터리를 문 아래 바닥에 세워 두고 한 손으로 케이블을 받쳐 주세요. / 접촉이 순간적으로 끊기면 번호 입력 도중 꺼질 수 있습니다.
처음에는 번호판에 아무 숫자나 한 번 눌러 깨우는 제품도 있고, 손바닥으로 덮어 깨우는 제품도 있습니다. / 제품마다 방식이 다르니 평소 어떻게 켜는지 떠올려 보세요.
케이블을 천천히 꽂고 번호판을 눌러 보세요. / 불이 들어오면 비상 전원이 들어온 것입니다.
불이 들어와도 바로 번호를 누르지 말고 한 박자 기다려 주세요. / 도어락이 켜지는 데 잠깐 시간이 걸리는 제품이 많습니다.
번호를 누를 때 평소처럼 삑 소리가 나는지 들어 보세요. / 소리가 난다면 번호를 천천히 한 번 입력해 보시면 됩니다.

# 연결해도 반응이 없을 때
반응이 없다면 단자 방향이나 케이블 접촉을 다시 확인하세요. / 케이블이 반만 들어간 경우도 흔합니다.
보조배터리가 일정 전류 이하일 때 꺼지는 제품도 있어서 다른 보조배터리로 바꿔 보는 것도 방법입니다. / 그래도 안 되면 배터리 문제가 아니라 내부 부품 문제일 수 있습니다.
이럴 때는 억지로 여러 번 꽂기보다 상황을 정리해 전화 주시는 편이 낫습니다.
@ 부흥동 보조배터리로 도어락 전원 연결

# 불은 켜졌는데 문이 안 열린다면
문이 한 번 열리면 바로 닫지 말고 안쪽에서 번호를 새로 등록하거나 배터리를 교체할 때까지 문을 열어 두세요. / 다시 닫았다가 같은 일이 반복되면 더 번거로워집니다.
전원은 들어왔는데 번호를 눌러도 반응이 없거나 모터 소리만 난다면 다른 원인입니다. / 번호가 바뀌었거나 걸쇠가 문틀에 눌려 있을 수 있습니다.
비밀번호를 여러 번 틀리면 도어락이 잠시 입력을 막습니다. / 서너 번 해보고 안 되면 멈추고 잠시 뒤에 다시 하세요.
안쪽 보조키가 잠겨 있다면 번호가 맞아도 열리지 않으니 이때는 [현관문 개문](door-open.html)으로 진행해야 합니다.

# USB 단자에서 하지 말아야 할 것
- 단자에 맞지 않는 케이블을 억지로 밀어 넣기
- 젖은 손이나 물기 있는 상태에서 연결하기
- 단자를 핀이나 클립으로 쑤시기
- 충전기를 콘센트에 연결해 쓰려고 도어락 문을 뜯기
단자가 휘면 비상 전원이 아예 안 들어가서 일이 커집니다. / 급해도 단자는 곱게 다뤄 주세요.

# 문이 열리면 배터리부터 바꾸기
교체할 때는 건전지 방향을 정확히 맞추고 덮개가 완전히 닫혔는지 확인하세요. / 덮개가 살짝 들떠 있으면 접촉이 불안정해 또 꺼질 수 있습니다.
오래 쓴 제품이라면 새 배터리를 넣어도 얼마 못 가는 경우가 있는데, 이때는 내부 전원부 문제일 수 있으니 미루지 말고 점검받으세요.
비상 전원으로 문이 열렸다면 안쪽 배터리 덮개를 열어 새 건전지로 모두 교체하세요. / 일부만 바꾸면 며칠 안에 같은 일이 생깁니다.
배터리를 바꿨는데도 번호판이 자꾸 꺼진다면 내부 접점이나 도어락 자체 문제일 수 있습니다. / 이때는 [도어락 수리](doorlock-repair.html)를 먼저 알아보시면 좋습니다.
교체한 날짜를 배터리 칸 안쪽에 적어 두면 다음 시기를 놓치지 않습니다.

# 부흥동 위치와 상황은 이렇게
부흥동은 골목이 이어지고 건물 입구가 비슷해 보이는 곳이 있어서 입구 모양을 함께 말씀해 주시면 헤매지 않고 찾아갑니다. / 건물 앞 주차 상황이나 출입 방법도 알려주시면 도움이 됩니다.
부흥동에서 출장을 요청하실 때는 건물 위치와 도어락 상태를 함께 알려주세요. / 아래 정보만 있어도 도착이 빨라집니다.
- 건물 이름이 아닌 도로 이름이나 근처 큰길
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- USB 단자나 건전지 단자가 보이는지
- 이미 해본 것 (보조배터리 연결 등)
사진을 문자로 보내 주시면 맞는 장비를 챙겨 갈 수 있습니다.
@ 부흥동 도어락 번호판 상태 사진

# 도착하면 사시는 분인지 확인합니다
주소가 나온 우편물은 현관 우편함에 있는 고지서나 택배 상자도 가능합니다. / 신분증을 가진 가족이 오고 있다면 도착을 기다렸다 진행해도 됩니다.
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두면 수월합니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하는 경우도 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# USB 단자가 있는 제품을 쓸 때 습관
- 보조배터리 하나를 가방이나 차에 넣어 두기
- 케이블도 같은 곳에 함께 두기
- 단자 위치를 평소에 한 번 확인해 두기
- 가족에게도 비상 전원 쓰는 법 알려주기
이렇게만 해도 번호판이 꺼진 날 훨씬 침착하게 대처할 수 있습니다. / 새 도어락을 고르는 중이라면 [도어락 설치](doorlock-install.html)에서 비상 전원 방식도 같이 확인하세요.

# 부흥동 말고 안양 어디든 갑니다
부흥동 바로 옆 안양동, 비산동, 호계동, 평촌동, 관양동, 귀인동, 석수동, 박달동도 다닙니다. / 안양 안이면 24시간 출동합니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 문 열고 나서 건전지도 바꿔 주시나요? | 네, 배터리 교체와 작동 확인까지 같이 해드립니다.
