# 전화를 끊고 나면 막상 할 일이 없습니다
부흥동에서 평촌역 쪽으로 나가던 길이든 퇴근해 돌아오던 길이든, 전화를 걸고 나면 도착까지 기다리는 시간이 생깁니다. / 그 시간에 무엇을 하느냐에 따라 작업이 쉬워지기도 하고 어려워지기도 합니다.
이 글은 기사가 오기 전 문 앞에서 해두면 좋은 일을 시간 순서로 적었습니다. / 특별한 도구는 필요 없고 휴대폰만 있으면 됩니다.
막막한 마음을 조금 가라앉히는 데도 도움이 되도록 쓰려고 했습니다.

# 통화가 끝난 직후, 문자부터 확인
통화에서 안내받은 내용이 있으면 메모해 두세요. / 도착 예정 시간과 연락받을 번호를 휴대폰에 따로 적어 두면 편합니다.
기사가 문자로 사진을 요청했다면 지금 바로 찍어서 보내 주세요. / 도어락 전체 모습과 번호판 상태, 열쇠 구멍이 있으면 그 부분이면 충분합니다.
사진이 먼저 도착해 있으면 현장에서 시간이 줄어듭니다. / 어두운 곳이면 손전등을 켜고 찍어 주세요.
@ 부흥동 출장열쇠 도착 전 준비

# 건물 입구까지 길을 열어 두기
공동현관 비밀번호가 필요한 곳이라면 기사가 들어올 수 있게 도와주셔야 합니다. / 문 앞에 계시기 어렵다면 현관 안쪽에서 기다리다가 도착할 때 열어 주세요.
관리사무소나 경비실이 있는 곳이면 방문 사실을 미리 알려 두면 편합니다. / 주차 문제로 입구를 못 찾는 경우도 있어 대략 어디로 오라고 알려 주세요.
엘리베이터가 오래 걸리는 곳이면 몇 층 어느 쪽 복도인지도 말씀해 주시면 좋습니다. / 이런 작은 정보가 도착 후 첫 몇 분을 크게 줄여 줍니다.
가능하면 기사가 도착할 즈음 건물 앞으로 내려가 기다려 주시면 가장 빠릅니다. / 길을 헤매는 시간이 줄어들고 바로 신분 확인으로 넘어갈 수 있습니다.

# 신분 확인에 쓸 것 미리 꺼내 두기
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 휴대폰에 저장된 우편물 사진이나 고지서가 도움이 될 수 있습니다. / 가능하면 관리사무소에 세대 확인을 부탁해 두는 것도 방법입니다.
기사가 도착한 뒤 이 과정에서 시간을 쓰지 않도록 미리 준비해 두세요. / 확인이 어려우면 작업을 할 수 없으니 이 부분은 꼭 챙겨 주세요.
@ 부흥동 출장열쇠 신분 확인 준비
세입자나 자취하는 분은 계약서 대신 우편물 한 장으로 충분한 경우가 많습니다. / 집주인에게 연락할 수 있다면 알려 주셔도 도움이 되지만 필수는 아닙니다.
같이 사는 가족이 있다면 그분의 신분증이나 연락처로도 확인을 도울 수 있습니다. / 어떤 방법이 가능한지는 도착해서 함께 정리합니다.

# 기다리는 동안 해도 되는 일
손대지 않고 할 수 있는 일들로 시간을 쓰면 됩니다. / 아래는 기다리는 동안 해도 괜찮은 것들입니다.
- 가까운 가족이나 룸메이트에게 상황 알리기
- 비상 연락이 필요한 곳에 연락해 두기
- 기다리는 곳 주변 안전 확인하고 앉을 자리 찾기
- 집 안에 있는 사람이 있다면 문 너머로 계속 말 걸기
누군가가 안에 있다면 안심시키는 말을 건네 주세요. / 아이나 반려동물이면 목소리만 들려도 훨씬 차분해집니다.

# 기다리는 동안 하면 안 되는 일
급한 마음에 이것저것 시도하다 일이 커지는 경우가 많습니다. / 아래는 꼭 피해 주세요.
- 드라이버나 카드로 문틈을 벌리는 것
- 손잡이를 세게 당기거나 문을 발로 차는 것
- 비밀번호를 끝없이 반복해서 누르는 것
- 도어락을 분해하려고 해보는 것
이런 시도는 문틀과 도어락 외관이 상하고 부품이 휘어 작업이 어려워집니다. / 그대로 두고 기다리시는 것이 가장 빠른 길입니다.

# 비밀번호를 여러 번 틀렸다면
기다리는 동안 번호를 눌러 보는 분이 많습니다. / 여러 번 틀리면 도어락이 한동안 입력을 막는 경우가 있습니다.
입력이 막혀 있는 동안은 번호가 맞아도 열리지 않으니 잠시 멈추는 것이 좋습니다. / 기사가 도착한 뒤에 몇 번 눌렀는지만 말씀해 주시면 됩니다.
뭔가를 시도하셨다면 숨기지 말고 있는 그대로 알려 주세요. / 무엇을 해보셨는지가 원인을 찾는 단서가 됩니다.
@ 안양 부흥동 도어락 점검 현장

# 날씨가 추울 때나 더울 때
한겨울이나 한여름에는 기다리는 시간이 길게 느껴집니다. / 가능하면 건물 로비나 실내 쉼터 같은 곳으로 옮겨 계시다 도착 시간에 맞춰 나오세요.
추운 날은 번호판이 얼어 반응이 느려질 수 있어 문 앞에서 계속 시도하는 건 도움이 되지 않습니다. / 손으로 따뜻하게 감싸 주면 반응이 돌아오는 경우도 있습니다.
더운 날은 문틀이 늘어나 문이 뻑뻑해져서 안 열릴 때도 있습니다. / 이럴 때는 문을 살짝 밀면서 손잡이를 돌려 보세요.

# 비용 이야기는 도착 후 문 열기 전에
기사가 문과 도어락을 보고 방법과 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 작업이 시작되면 이렇게 도와주세요
작업 중에는 옆에서 지켜보셔도 되고 잠시 떨어져 계셔도 됩니다. / 다만 궁금한 점은 그때그때 물어보세요.
문이 열린 직후에 배터리와 잠금 상태를 같이 확인하니 바로 들어가기보다 잠깐 기다려 주세요. / 원인이 정리되면 [현관문 개문](door-open.html) 과정에 따라 마무리합니다.
다음에 같은 일이 없도록 하는 방법도 이때 같이 알려 드립니다. / 질문은 얼마든지 편하게 하셔도 됩니다.
작업 소리가 이웃에게 방해되지 않을까 걱정하는 분이 계신데, 문을 상하지 않게 여는 방식은 크게 시끄럽지 않습니다. / 늦은 시간이라면 최대한 조용히 진행하겠습니다.
작업이 길어질 것 같으면 중간에 상황을 먼저 말씀드립니다. / 예상과 달라지는 부분이 있으면 임의로 진행하지 않고 반드시 여쭙니다.

# 끝난 뒤 5분 점검
문이 열리면 도어락이 다시 잘 잠기고 열리는지 몇 번 확인해 보세요. / 비밀번호를 새로 등록했다면 그 번호가 맞는지도 눌러 보세요.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 고장이 반복되면 [도어락 수리](doorlock-repair.html)를 먼저 생각해 보시고, 너무 낡았다면 그때 교체를 말씀드립니다.
건전지 교체일이나 설정을 휴대폰에 적어 두면 다음에 편합니다.

# 부흥동 말고 안양 어디든 갑니다
부흥동 바로 옆 평촌동, 귀인동, 관양동, 호계동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 기다리는 동안 직접 열어 봐도 되나요? | 권하지 않습니다. 도어락이나 문틀이 상하면 일이 더 커질 수 있으니 그대로 기다려 주세요.
? 사진은 꼭 보내야 하나요? | 필수는 아니지만 미리 보내 주시면 장비를 맞춰 챙겨 갈 수 있어 빨라집니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에도 전화해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 세입자인데 신분 확인은 어떻게 하나요? | 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.

# 마무리
기다리는 시간도 문제를 푸는 과정의 일부입니다. / 부흥동에서 문 앞에 서 계시다면 사진과 신분 확인 준비만 해두고 편히 기다려 주세요.
24시출장열쇠는 평촌역 근처 늦은 밤에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
