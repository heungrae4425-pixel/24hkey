# 관양동에서 문이 열린 뒤가 더 중요합니다
문이 열리면 한시름 놓고 바로 집 안으로 들어가고 싶어집니다. / 하지만 문이 안 열린 원인을 그대로 두면 며칠 뒤 같은 일이 또 생깁니다.
이 글은 관양동에서 [안양 출장열쇠](anyang.html)로 문을 연 뒤, 무엇을 점검해야 같은 일이 반복되지 않는지 순서대로 정리했습니다. / 이미 문이 열린 분이라면 바로 아래 체크리스트부터 따라 하셔도 됩니다.

# 먼저 도어락이 정상으로 돌아왔는지 확인
문이 열렸다고 도어락이 정상이라는 뜻은 아닙니다. / 문을 연 상태로 번호를 눌러 잠금과 해제가 한 번에 되는지 몇 번 시험해 보세요.
소리가 정상인지도 같이 듣습니다. / 모터가 힘없이 돌거나 평소와 다른 소리가 나면 고장이 진행 중일 수 있습니다.
시험은 반드시 문을 열어 둔 채로 하세요. / 닫힌 상태에서 시험하다 다시 막히는 일이 없도록 하는 것입니다.
현관 안쪽 손잡이로 문을 열고 잠가 보는 것도 잊지 마세요. / 바깥에서는 되는데 안쪽에서 막히는 경우도 있어서 양쪽을 모두 확인해야 합니다.

# 배터리를 새것으로 바꿨는지 확인
문이 안 열린 가장 흔한 원인이 배터리입니다. / 원인이 배터리였다면 일부만 바꾸지 말고 전부 같은 종류로 새것으로 바꿔 주세요.
다른 원인이었더라도 이참에 배터리를 같이 점검해 두면 안심이 됩니다. / 교체한 날짜를 덮개 안쪽에 적어 두면 다음 교체 시기를 잊지 않습니다.
@ 관양동 도어락 배터리 교체 점검 24시 출장열쇠

# 비밀번호와 등록 정보 정리
번호를 잊어서 연 경우에는 새 번호를 등록하는 것까지 해야 일이 끝납니다. / 기존 번호는 지우고 새 번호만 남겨 두는 것이 안전합니다.
카드나 지문이 같이 등록되어 있다면 지금도 필요한 것만 남기고 정리하세요. / 쓰지 않는 카드나 잃어버린 카드가 남아 있으면 그것으로 문이 열릴 수 있습니다.
새 번호는 가족과 직접 공유하고, 한 사람씩 눌러 보게 하면 확실합니다. / 번호를 휴대폰 메모에 그대로 적어 두는 것은 피하는 편이 좋습니다.
가족 구성이 달라졌다면 지금 쓰는 번호를 그대로 두기보다 새로 정하는 것이 좋습니다. / 이사 간 가족이나 더 이상 오지 않는 사람이 알고 있는 번호는 지워 두세요.

# 열쇠와 보조키 확인
열쇠가 있는 문이라면 열쇠가 잘 들어가고 부드럽게 돌아가는지 확인합니다. / 뻑뻑하거나 걸리는 느낌이 있다면 도어락이나 열쇠구멍 쪽에 문제가 생기고 있을 수 있습니다.
보조키가 있다면 그것도 한 번씩 잠그고 열어 봅니다. / 평소 잘 쓰지 않던 보조키가 제대로 작동하는지 모르는 경우가 많습니다.
열쇠가 하나뿐이라면 이참에 여분을 만들어 두세요. / 어디에 보관할지도 가족과 정해 두면 좋습니다.
열쇠를 잃어버려서 문을 연 경우라면 열쇠 구멍 자체를 바꾸는 것도 방법입니다. / 어느 정도까지 바꿔야 안심되는지는 상황에 따라 다르니 먼저 말씀해 주세요.

# 문틀과 경첩 점검
문이 안 열린 원인이 도어락이 아니라 문틀이나 경첩일 수도 있습니다. / 문이 끝까지 닫히는지, 걸쇠가 문틀 구멍에 부드럽게 들어가는지 확인하세요.
경첩 나사가 헐겁거나 문이 아래로 처져 있으면 같은 일이 다시 생깁니다. / 이 경우 [도어락 수리](doorlock-repair.html) 쪽에서 문 상태까지 같이 봅니다.
관양동 오래된 주택이나 빌라일수록 문이 조금씩 처지는 경우가 많습니다. / 작은 변화도 놓치지 말고 눈으로 확인해 두세요.

# 번호판과 외관 확인
번호판이 깨끗한지, 물기가 남아 있지 않은지 봅니다. / 습기나 먼지가 번호판 안쪽에 들어가면 오작동의 원인이 됩니다.
외관에 흠집이나 눌린 자국이 생기지 않았는지도 같이 확인하세요. / 비파손 개방이라면 열기 전과 같은 모습이어야 합니다.
@ 관양동 도어락 번호판 외관 확인 출장열쇠
번호판 버튼을 한 번씩 눌러 모든 숫자가 정상으로 입력되는지 확인하세요. / 몇 개 버튼이 잘 눌리지 않으면 내부 접촉이 약해진 신호일 수 있습니다.

# 재발 방지: 비상 건전지 준비
9V 건전지 하나를 가방이나 차에 넣어 두세요. / 번호판이 꺼졌을 때 비상 단자에 대 보는 것만으로도 문이 열리는 경우가 많습니다.
건전지는 오래 두면 방전되니 가끔 상태를 보세요. / 집 근처 편의점에서 쉽게 구할 수 있습니다.
집 앞에 비상 건전지를 숨겨 두는 방법은 권하지 않습니다. / 남도 찾을 수 있는 곳이면 오히려 위험하니 가방이나 차에 두는 편이 낫습니다.

# 재발 방지: 배터리 교체 주기 정하기
해가 바뀔 때처럼 일정한 날을 정해 두고 배터리를 한꺼번에 바꾸는 방법이 있습니다. / 경고음이 한 번이라도 울렸다면 미루지 말고 그날 바로 바꾸는 것이 좋습니다.
여행이나 출장으로 오래 집을 비우기 전에는 배터리 상태를 한 번 보고 나가세요. / 비어 있는 동안에도 도어락은 조금씩 전기를 씁니다.
교체 주기를 달력 앱에 알림으로 걸어 두면 잊지 않습니다. / 가족 모두가 볼 수 있는 곳에 교체 날짜를 같이 적어 두는 것도 좋습니다.

# 재발 방지: 문 닫기 습관
택배를 받거나 쓰레기를 버리러 나갈 때 문이 닫히는 일이 가장 흔합니다. / 문에 작은 문 고정 장치를 끼워 두거나 열쇠나 카드를 현관 근처에 두는 습관을 들이면 좋습니다.
가족 모두가 같은 번호와 같은 방법을 알고 있어야 합니다. / 아이가 안에서 잠그는 상황까지 생각해 두면 더 안심됩니다.

# 고쳐서 쓸지, 바꿀지 판단하기
문을 열고 난 뒤 점검하다 보면 도어락이 너무 낡았다는 것을 알게 되기도 합니다. / 고장이 잦거나 부품이 단종되었다면 교체가 나을 수 있습니다.
이 판단은 직접 보고 말씀드리는 것이 정확합니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않고, 필요하다면 [도어락 교체](doorlock-replace.html)로 안내합니다.
판단하기 어려우면 도어락 사진과 문제 증상을 먼저 보내 주세요. / 보고 나서 고쳐서 쓸 수 있는지 말씀드립니다.

# 비용 안내와 서비스 확인
문을 열기 전에 비용을 먼저 말씀드렸고, 열고 난 뒤에 말없이 붙는 비용은 없습니다. / 점검 중에 부품을 바꿔야 하는 일이 생기면 바꾸기 전에 따로 여쭤봅니다.
궁금한 점이 있으면 작업이 끝난 뒤에도 전화로 물어보셔도 됩니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
점검 결과를 간단히 메모로 남겨 두시면 다음에 도움이 됩니다. / 배터리 교체 날짜, 새로 등록한 번호의 종류 정도만 적어도 충분합니다.
