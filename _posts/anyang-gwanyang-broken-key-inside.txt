# 딱 소리와 함께 열쇠가 반 토막 났을 때
관양동은 인덕원역 쪽 주택가와 상가가 이어져 열쇠로 여는 문과 도어락이 섞여 있는 동네입니다. / 열쇠를 돌리던 중 딱 하는 소리와 함께 손에는 열쇠 머리만 남고 나머지는 구멍 안에 박혀 버리는 일이 생깁니다.
이 순간 머릿속이 하얗게 되는 분이 많습니다. / 하지만 지금부터 어떻게 행동하느냐에 따라 문을 그대로 살릴 수도, 구멍을 통째로 바꿔야 할 수도 있습니다.
이 글은 관양동에서 열쇠가 부러졌을 때 가장 먼저 하셔야 할 것과 절대 하지 말아야 할 것을 정리했습니다. / 그다음 [안양 출장열쇠](anyang.html)가 어떻게 조각을 꺼내는지 적었습니다.
@ 관양동 부러진 열쇠 조각 구멍 안 출장열쇠

# 1단계는 멈추는 것입니다
열쇠가 부러졌다면 가장 먼저 모든 시도를 멈추세요. / 남은 조각을 다시 꽂아 돌려 보거나 흔들어 보는 일이 상황을 가장 크게 악화시킵니다.
구멍 안에 남은 조각은 아직 잡을 수 있는 위치에 있을 수도, 더 깊이 들어가 있을 수도 있습니다. / 건드릴수록 깊이 밀려 들어가면 꺼내는 일이 훨씬 어려워집니다.
손에 남은 열쇠 머리 부분은 버리지 말고 따로 보관해 주세요. / 부러진 단면 모양을 보면 조각이 얼마나 남았는지 짐작하는 데 도움이 됩니다.

# 해서는 안 되는 행동 네 가지
급한 마음에 아래 행동을 하는 경우가 많습니다. / 모두 문을 더 상하게 하는 방법입니다.
- 이쑤시개나 철사로 조각을 파내려 하는 것
- 접착제로 열쇠 조각을 붙여 보려는 것
- 펜치로 남은 조각 끝을 잡고 비트는 것
- 구멍에 기름을 잔뜩 부어 미끄러지게 해 보려는 것
특히 접착제는 구멍 안 핀에 번져 굳으면 구멍 전체를 바꿔야 할 수 있습니다. / 어떤 이유로도 구멍 안에 이물질을 더 넣지 않는 것이 원칙입니다.

# 조각이 어디까지 남았는지 살펴보기
스마트폰 손전등으로 구멍 입구를 비춰 보세요. / 조각이 입구에 보일 정도로 나와 있는지, 안쪽으로 들어갔는지 확인할 수 있습니다.
조각 끝이 보여도 손이나 도구로 직접 잡으려 하지는 마세요. / 상태만 사진으로 찍어 전화로 알려주시는 것이 가장 좋습니다.
사진이 어려우면 구멍에서 조각이 어느 정도 보이는지를 말로 설명해 주셔도 충분합니다. / 도착 전에 필요한 도구를 정하는 데 큰 도움이 됩니다.
@ 관양동 열쇠 부러짐 구멍 점검 인덕원역

# 문이 열려 있는지 닫혀 있는지가 중요합니다
부러진 상황에서 문이 이미 열려 있다면 급하지 않습니다. / 집 안에서 안전하게 기다리시고 천천히 연락 주셔도 됩니다.
반대로 문이 잠긴 채 열쇠가 부러졌다면 집에 들어갈 방법이 막힌 것입니다. / 이때는 조각을 빼는 일과 문을 여는 일을 함께 판단해야 합니다.
집 안에 아이나 반려동물이 있거나 불과 가스를 켜 둔 상황이면 꼭 먼저 말씀해 주세요. / 그런 경우에는 순서를 바꿔 문을 여는 일부터 진행합니다.

# 번호가 되는 도어락이 같이 있다면
관양동 일부 집은 도어락과 보조 열쇠 구멍을 함께 쓰고 있습니다. / 이런 문은 부러진 열쇠가 보조 구멍에 있고 번호로는 열릴 수도 있습니다.
번호를 눌러 보고 되면 일단 들어가서 상황을 정리하는 것이 먼저입니다. / 들어간 뒤 구멍 안 조각은 나중에 천천히 처리하면 됩니다.
번호까지 안 되면 [현관문 개문](door-open.html) 쪽으로 이어서 진행합니다. / 어느 쪽인지 모르겠다면 전화로 문 사진부터 보여주세요.

# 출장열쇠는 이런 순서로 조각을 뺍니다
구멍 안 상태와 조각 위치를 확인한 뒤 가장 덜 손대는 방법부터 차례로 진행합니다. / 입구 가까이 조각이 있으면 전용 도구로 잡아 꺼낼 수 있습니다.
깊이 들어갔다면 구멍을 분해해 안쪽에서 꺼내야 할 수도 있습니다. / 이때도 문과 구멍을 되도록 살리는 방향으로 먼저 시도합니다.
부품을 바꿔야 한다는 판단이 서면 손대기 전에 설명드리고 허락을 받은 뒤 진행합니다. / 말없이 바꾸거나 일을 키우는 일은 없습니다.
꺼낸 조각과 남은 열쇠 모양을 보고 새 열쇠도 함께 만들어 드릴 수 있습니다. / 열쇠 복사와 수리는 [출장 열쇠](key-call.html) 페이지에도 적어 두었습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문과 구멍을 만지는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
세입자라면 계약서나 우편물로도 확인이 가능한지 현장에서 안내해 드립니다. / 늦은 시간이면 경비실에 먼저 말해 두시면 수월합니다.

# 비용은 시작하기 전에 말씀드립니다
조각이 어디까지 들어갔는지, 구멍을 살릴 수 있는지 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 일이 끝난 뒤 말없이 붙는 비용도 없습니다.
부러진 열쇠 때문에 구멍을 바꿔야 하는 경우에는 바꾸기 전에 꼭 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 관양동 부러진 열쇠 제거 출장열쇠 작업

# 부러진 뒤에 새 열쇠를 만들 때
부러진 열쇠로는 복사가 어렵거나 부정확할 수 있습니다. / 남은 조각과 구멍 모양을 보고 새로 깎아 드릴 수 있는지 확인합니다.
복사본을 한 번 더 복사한 열쇠는 오차가 쌓여 구멍에 무리가 갑니다. / 새로 만들 때는 원본 열쇠가 있다면 그것을 기준으로 하는 것이 좋습니다.
스페어 열쇠를 하나 더 만들어 두면 같은 상황에서 훨씬 편합니다. / 가족이 있다면 한 개씩 나눠 보관해 두세요.

# 열쇠가 약해지는 신호
열쇠는 부러지기 전에 신호를 줍니다. / 아래 모습이 보이면 부러지기 전에 새로 만들어 두는 것이 좋습니다.
- 열쇠 머리와 몸통 사이가 살짝 휘어 있는 경우
- 돌릴 때 평소보다 뻑뻑해 힘을 주게 되는 경우
- 열쇠 날 홈이 닳아 모서리가 둥글어진 경우
- 열쇠고리에 무거운 장식을 여러 개 달고 쓰는 경우
특히 겨울 추위에는 금속이 더 잘 부러집니다. / 추운 날 열쇠가 뻑뻑하면 힘을 주지 말고 조금 데운 뒤 다시 시도해 주세요.

# 열쇠가 부러진 날 밤이라면
관양동에서 늦은 시간에 열쇠가 부러지면 열쇠집이 닫혀 있어 막막하기 쉽습니다. / 이럴수록 조각을 건드리지 않고 그대로 두는 것이 낮이든 밤이든 가장 중요합니다.
구멍 입구 사진 한 장과 문 전체 사진 한 장이면 전화로 상황을 설명하기에 충분합니다. / 사진을 보면 도착 전에 어떤 도구가 필요한지 대략 정할 수 있어 출동이 빨라집니다.
추운 날이라면 문밖에서 오래 기다리지 않도록 이웃이나 관리사무소에 잠시 머물 곳을 부탁해 보세요. / 도착 예상 시간은 위치를 받으면 전화로 먼저 말씀드립니다.

# 관양동 말고 안양 어디든 갑니다
관양동 바로 옆 평촌동, 비산동, 호계동, 귀인동, 부흥동, 석수동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
