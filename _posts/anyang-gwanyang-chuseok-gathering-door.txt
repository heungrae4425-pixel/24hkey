# 명절이면 현관문이 가장 바빠집니다
관양동은 인덕원역 쪽으로 오가는 분들이 많은 주거 동네입니다. / 명절이 되면 멀리 사는 친척들이 한꺼번에 찾아와 집이 북적이고 현관문도 평소보다 훨씬 자주 열리고 닫힙니다.
어른들은 먼저 와 계시고 아이들은 들락거리고 누군가는 장을 보러 나갔다 돌아옵니다. / 이럴 때 비밀번호를 어떻게 알려 드릴지, 문이 잠기면 어떻게 할지가 고민이 됩니다.
이 글은 명절에 친척이 모였을 때 도어락 번호를 공유하는 요령과 문이 잠겼을 때 [관양동 출장열쇠](anyang.html)를 부르는 순서를 적었습니다.
@ 관양동 명절 손님맞이 현관 도어락

# 번호를 알려 주기 전에 생각할 것
집 번호를 가족 모두에게 알려 줄지 잠깐 생각해 보세요. / 명절 며칠만 오는 친척에게 평소 쓰는 번호를 그대로 알려 주면 나중에 바꾸기 번거롭습니다.
- 며칠만 쓸 임시 번호를 따로 등록할 수 있는지
- 가족 번호와 손님 번호를 나눌 수 있는 제품인지
- 번호를 알려 줄 사람이 누구인지 정리했는지
임시 번호 등록이 가능한 제품이면 명절 동안만 만들어 쓰고, 끝난 뒤 지우면 됩니다. / 가능한지는 제품 설명서나 모델명으로 확인할 수 있습니다.

# 번호는 문자 대신 직접 전달하기
단체 대화방에 번호를 올리면 그 방에 있는 모든 사람이 볼 수 있습니다. / 방에 들어 있지만 직접 올 일이 없는 사람까지 알게 되는 것이 부담스러울 수 있습니다.
꼭 필요한 사람에게만 따로 전화나 개인 문자로 알려 주는 것이 좋습니다. / 알려 준 문자는 사용 후 지우도록 부탁하면 더 안심입니다.
어르신께는 번호를 종이에 크게 적어 드리고 현관 안쪽에서 보관하게 하는 방법도 있습니다. / 밖에 붙여 두는 것은 하지 마세요.

아이들은 번호판 누르기를 재미있어 합니다. / 틀린 번호를 여러 번 누르면 도어락이 입력을 잠시 막아 어른도 못 들어가는 일이 생깁니다.
아이들에게는 문 앞에서 번호판을 장난으로 누르지 않도록 미리 이야기해 주세요. / 어른이 문을 열 때만 함께 가도록 하면 좋습니다.
혹시 막혔다면 몇 분 기다린 뒤 다시 시도해 보세요.
@ 관양동 아이들이 번호판 누르는 현관

# 한꺼번에 들어오면 생기는 일
여러 명이 같이 들어오면 마지막 사람이 문을 닫으며 잠그는 순서가 헷갈립니다. / 누군가 나가면서 문을 확실히 안 닫아 열려 있는 경우도 있습니다.
반대로 자동 잠김이 켜져 있으면 짐을 들고 오가다가 문이 닫혀 잠겨 버리기도 합니다. / 장보러 간 사람이 돌아왔는데 안에서 못 듣고 문이 안 열리는 일도 있습니다.
명절 동안에는 문을 열어 두는 경우와 잠그는 경우를 가족끼리 정해 두면 편합니다.

잠깐 나가는 분은 휴대폰과 번호를 반드시 확인하세요. / 번호를 기억하지 못하고 나가면 돌아와서 문 앞에서 막히게 됩니다.
- 번호를 아는 사람이 안에 남아 있는지
- 자동 잠김 상태인지, 문이 닫히면 바로 잠기는지
- 휴대폰으로 안에 있는 가족과 바로 연락 가능한지
이 세 가지만 확인하고 나가도 문 앞에서 서성이는 일이 크게 줄어듭니다.

# 번호 입력이 이상하다면
번호를 누르고 문이 안 열리면 우선 천천히 다시 눌러 보세요. / 급할 때는 손가락이 번호판 위에서 미끄러져 한 칸 놓치기 쉽습니다.
여러 번 틀려 입력이 막히면 잠시 기다린 뒤 다시 하시면 됩니다. / 번호판이 아예 꺼져 있으면 배터리 문제이니 바깥쪽 비상 단자에 9V 건전지를 대 보세요.
명절에 사람이 많이 드나든 뒤에는 배터리가 평소보다 빨리 닳기도 합니다. / 열린 뒤에는 배터리 상태를 같이 확인해 두세요.

# 문이 잠겨 들어가지 못할 때 순서
먼저 집 안에 있는 가족에게 전화해서 열어 달라고 부탁하세요. / 명절 집에는 보통 누군가 안에 있으니 가장 빠른 방법입니다.
안에 아무도 없고 번호도 안 맞는다면 그때 출장열쇠를 부르면 됩니다. / 억지로 문을 두드리거나 손잡이를 세게 당기지는 마세요.
어른이 아니라 아이나 어르신만 남아 계신다면 문 너머로 차분히 말을 걸어 주세요. / 이 경우는 꼭 먼저 말씀해 주시면 우선 출동합니다.

# 전화할 때 알려주실 내용
친척이 많이 모인 상황이라 정신이 없어도 아래 정도만 말씀해 주시면 됩니다.
- 관양동 주소와 호수
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 안에 사람이 있는지, 아이나 어르신이 있는지
- 도어락 모양과 사진을 보낼 수 있는지
도어락 사진을 문자로 보내주시면 필요한 장비를 챙기기 좋습니다. / [출장열쇠 이용 안내](key-call.html)에 자세히 적어 두었습니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
명절에는 방문한 친척이 문을 대신 부탁하는 경우도 있는데 이때도 사시는 분이 확인되어야 합니다. / 집주인이 전화로 상황을 알려주시고 안에서 확인해 주시면 진행이 쉬워집니다.
신분증이 집 안에 있다면 경비실이나 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.
@ 관양동 출장열쇠 도착 후 거주 확인

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다. / 부품을 바꿔야 하면 바꾸기 전에 여쭤봅니다.

# 열고 난 뒤 번호부터 정리하세요
명절이 끝나면 손님용으로 알려 준 번호를 정리해야 합니다. / 임시 번호는 지우고 평소 번호만 남기는 것이 좋습니다.
기존 번호가 널리 퍼졌다면 새 번호로 바꾸는 것도 방법입니다. / 도어락 안쪽에서 번호를 바꾸는 방법은 제품마다 달라 문이 열린 뒤 같이 봐 드릴 수 있습니다.
[도어락 수리](doorlock-repair.html)가 필요한 증상이 있으면 그때 함께 말씀드립니다. / 문 여는 방식은 [현관문 개문](door-open.html) 페이지에서도 보실 수 있습니다.

# 다음 명절을 위한 준비
한 번 겪고 나면 다음에는 이렇게 해 두는 분들이 많습니다.
- 명절 전에 도어락 배터리를 한 번에 새것으로 교체
- 임시 번호가 되는지 미리 확인하기
- 집 안에 번호를 아는 가족이 항상 남아 있도록 하기
- 비상용 열쇠나 카드를 믿을 만한 가족에게 맡기기
미리 해 두면 북적이는 날에도 문 앞이 한결 조용합니다.

# 관양동 말고 안양 어디든 갑니다
관양동 가까이 평촌동, 비산동, 호계동, 부흥동, 귀인동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
