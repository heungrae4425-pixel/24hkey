# 문틈으로 들어오는 바람이 신호일 때
관양동은 인덕원역 방향을 이용하는 분들이 많고 겨울 아침 바람이 찬 동네로 느껴지기도 합니다. / 현관문 아래나 옆으로 바람 소리가 난다면 문이 제자리에 닫히지 않는다는 뜻일 수 있습니다.
틈새 바람은 단순히 춥고 시끄러운 문제에서 끝나지 않습니다. / 문이 덜 닫히면 걸쇠가 제대로 물리지 않아 잠금이 헐거워지거나 도어락에 무리가 갈 수 있습니다.
이 글은 집에서 먼저 확인할 수 있는 점검 순서를 정리했습니다. / 직접 해결이 어려우면 [안양 출장열쇠](anyang.html)가 문 상태를 같이 봐 드립니다.
점검이라고 해서 어려운 도구가 필요하지는 않습니다. / 손바닥과 얇은 휴지, 십자 드라이버 정도면 대부분 확인할 수 있습니다.
@ 관양동 현관문 틈새 점검

# 바람 소리가 나는 위치부터 찾습니다
손바닥을 문 가장자리에 천천히 대면서 바람이 느껴지는 곳을 찾아봅니다. / 위쪽, 아래쪽, 경첩 쪽, 손잡이 쪽 중 어디에서 가장 센지 구분합니다.
촛불이나 얇은 휴지를 쓰는 방법도 있지만 안전을 위해 불은 쓰지 않는 편이 좋습니다. / 얇은 휴지를 문틈에 대 보면 흔들리는 곳을 쉽게 알 수 있습니다.
- 아래쪽만 새면 문턱 틈이나 하단 고무 쪽 문제일 가능성
- 경첩 쪽이 새면 문이 처졌거나 경첩이 헐거울 가능성
- 손잡이 쪽이 새면 걸쇠 위치가 맞지 않을 가능성
모서리 네 군데를 모두 확인한 뒤에 가장 센 곳을 기준으로 삼으세요.

# 문을 닫을 때 소리를 들어 봅니다
정상이라면 문이 닫히며 한 번에 철컥 하는 소리가 납니다. / 쿵 하고 부딪히거나 두 번 끊겨 닫히면 어딘가가 어긋난 것입니다.
문을 끝까지 밀어야 겨우 잠기거나 걸쇠가 문틀 구멍 가장자리에 걸린다면 문틀과 문이 서로 맞지 않는 상태입니다. / 이렇게 쓰는 시간이 길수록 도어락과 문틀이 같이 닳습니다.
문이 닫힐 때 손잡이 쪽이 먼저 닿는지 위쪽이 먼저 닿는지도 보세요.
닫을 때 문과 문틀 사이로 종이를 끼워 보고 빠지는 곳과 빡빡한 곳을 비교하는 방법도 있습니다. / 한쪽만 꽉 낀다면 그쪽이 처졌다는 뜻입니다.

# 걸쇠와 문틀 구멍의 위치 확인
문을 닫았을 때 걸쇠가 나오는 자리와 문틀 구멍이 같은 높이에 있는지 확인합니다. / 구멍 가장자리에 긁힌 자국이 있다면 오래전부터 조금씩 어긋나 있었다는 증거입니다.
문틀 쪽 금속판이 헐거워졌는지 손으로 살짝 눌러 봅니다. / 나사가 풀려 있으면 드라이버로 조여 주는 것만으로 나아지는 경우도 있습니다.
다만 나사를 너무 세게 조이면 오히려 문틀이 상할 수 있으니 힘을 조절하세요.
문틀 금속판이 심하게 눌려 있거나 휘었다면 나사만으로 해결되지 않습니다. / 이럴 때는 문틀 맞춤이 필요합니다.
@ 문틀 걸쇠 구멍 위치 확인

# 경첩이 헐거워진 건 아닌지
문을 열고 위쪽 경첩 근처를 살짝 들어 올려 흔들림을 느껴 봅니다. / 흔들림이 있다면 경첩 나사가 풀렸거나 문이 무게로 처졌을 수 있습니다.
경첩에서 삐걱 소리가 나면 윤활이 필요한 경우가 많습니다. / 기름을 아무거나 쓰면 먼지가 붙을 수 있으니 문 전용으로 얇게 바르는 편이 낫습니다.
문이 한쪽으로 기울어 아래 모서리가 바닥에 닿는다면 직접 고치려고 하지 마세요.
경첩 나사는 한 번에 하나씩 조이고, 모두 풀어 버리면 문이 쓰러질 수 있으니 주의하세요. / 문 무게가 상당해 혼자 들기 어렵다면 반드시 둘이서 작업하세요.

# 하단 고무와 문틈 마감
문 아래나 문틀 안쪽에 붙은 고무 패킹이 닳으면 바람이 샙니다. / 오래되면 딱딱하게 굳거나 찢어지는데 눈으로 보면 바로 알 수 있습니다.
패킹을 새로 붙이는 일은 집에서도 가능하지만 두께가 맞지 않으면 문이 안 닫힐 수 있습니다. / 사기 전에 기존 것의 폭과 두께를 재서 맞춰 보세요.
방풍 테이프를 문틀 전체에 붙이면 문이 안 닫히는 경우도 있으니 한 부분만 시험해 보는 편이 안전합니다.
틈을 막는 데 집중하다가 환기까지 막아 버리면 곰팡이나 결로가 생길 수 있으니 적당히 막는 것이 좋습니다.

# 도어클로저가 있는 문이라면
문 위쪽에 붙은 도어클로저가 너무 세거나 약해도 닫힘 상태가 달라집니다. / 너무 세면 쿵 하고 닫히고, 너무 약하면 잠금 위치까지 못 갑니다.
조절 나사를 돌려 속도를 맞추는 제품이 많지만 한 번에 많이 돌리지 마세요. / 반 바퀴씩 돌리며 닫혀 보는 것이 안전합니다.
기름이 새어 나오거나 팔이 휘었다면 점검이 필요합니다. / 자세한 상담은 [도어락 수리](doorlock-repair.html) 쪽으로 문의하시면 됩니다.
닫히는 속도가 지나치게 느려 문이 열려 있는 시간이 길면 방범상 불안합니다. / 이 경우 속도를 조금 높여 보세요.

# 소리와 바람이 같이 문제라면
문이 덜 닫히면 외부 소음도 함께 들어옵니다. / 계단 소리, 이웃 문 닫는 소리가 크게 들린다면 틈이 있다는 신호일 수 있습니다.
공동현관이나 복도가 가까운 집일수록 이 차이를 더 크게 느낍니다. / 소음과 바람을 한 번에 줄이려면 닫힘 상태부터 바로잡는 것이 먼저입니다.
밤에 소리가 더 크게 들리는 것도 주변이 조용해서이지 문이 갑자기 나빠진 것은 아닌 경우가 많습니다.

# 이럴 땐 점검을 맡기세요
문이 처졌거나 문틀이 휘었다면 직접 고치기 어렵습니다. / 억지로 만지면 더 어긋날 수 있습니다.
도어락이 닫힘 때마다 소리가 나거나 걸쇠가 안 빠지고 문이 갑자기 안 열리는 일이 생겼다면 서둘러 연락 주세요. / 상황에 따라 [현관문 개문](door-open.html)이 먼저 필요할 수 있습니다.
문 상태를 사진으로 찍어 보내 주시면 맞는 장비를 챙겨 갑니다.
문 안쪽과 바깥 틈새 사진을 각각 찍어 두면 상담이 훨씬 빨라집니다.
@ 관양동 문 닫힘 점검 출장

# 문이 아예 안 열리게 됐다면
틈과 걸쇠 어긋남이 쌓이다 보면 어느 날 문이 안 열리기도 합니다. / 그럴 땐 힘으로 당기지 말고 위치와 상황을 알려 주세요.
도착하면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
비용은 문 열기 전에 먼저 말씀드리고, 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 점검 뒤 계절별로 지켜볼 것
겨울에는 문과 문틀이 수축하고 여름에는 팽창해 닫힘이 달라지기도 합니다. / 계절이 바뀔 때 한 번씩 닫힘 소리와 바람을 확인하는 습관이 도움이 됩니다.
문이 갑자기 달라졌다면 이사 짐을 옮기다 부딪쳤는지, 최근에 무거운 물건을 문에 걸었는지 떠올려 보세요. / 원인을 알면 점검 범위를 줄일 수 있습니다.

# 관양동 말고 안양 어디든 갑니다
평촌동, 비산동, 호계동, 귀인동, 부흥동, 안양동, 석수동, 박달동도 다닙니다. / 안양 안이면 24시간 출동합니다.
[출장 지역](area.html)에서 다른 지역도 확인하세요.
