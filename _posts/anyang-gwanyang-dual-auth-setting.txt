# 관양동에서 이중 인증을 찾는 분들이 늘어난 이유
관양동은 인덕원역 쪽으로 오가는 분이 많고, 아파트와 빌라, 오피스텔이 한 동네에 섞여 있습니다. / 사는 방식이 다양하다 보니 도어락을 좀 더 단단하게 쓰고 싶다는 문의도 다양하게 들어옵니다.
요즘 자주 듣는 말이 "번호만 누르면 열리는 게 마음에 걸린다"는 이야기입니다. / 번호 하나로 열리는 방식이 불안하다면 번호와 카드를 둘 다 거치게 하는 이중 인증을 생각해 볼 수 있습니다.
이 글은 번호와 카드를 함께 쓰는 설정이 무엇인지, 어떤 도어락에서 되는지, 하다가 막혔을 때 어떻게 하는지를 순서대로 적었습니다. / 직접 해보다가 문 앞에서 막히는 경우까지 같이 다뤘습니다.
@ 관양동 도어락 번호 카드 이중 인증 설정

# 번호와 카드를 함께 쓴다는 게 어떤 뜻인지
이중 인증은 번호 입력과 카드 태그, 두 가지를 모두 해야 문이 열리게 하는 방식입니다. / 번호만 알아도, 카드만 주워도 열리지 않는다는 점이 가장 큰 차이입니다.
모든 도어락에 이 기능이 있는 건 아닙니다. / 제품마다 이름이 다르고, 번호와 카드를 따로따로 허용하는 기본 설정만 있는 모델도 많습니다.
사용설명서에 복합 인증, 이중 인증, 2단계 인증 같은 말이 적혀 있는지 먼저 찾아보세요. / 모델명은 번호판 안쪽이나 배터리 덮개 근처 스티커에서 확인하실 수 있습니다.

# 우리 집 도어락이 지원하는지 확인하는 순서
먼저 안쪽 몸체 스티커의 모델명을 사진으로 찍어 둡니다. / 그다음 제조사 설명서나 고객센터 안내에서 인증 방식 항목을 찾아보시면 됩니다.
- 카드 등록 기능이 있는지(카드 태그 부분이 있는 모델인지)
- 설정 메뉴에 인증 방식을 고르는 항목이 있는지
- 관리자 번호나 마스터 카드를 따로 쓰는 구조인지
카드 태그 부분이 아예 없는 모델이라면 설정만으로는 이중 인증이 안 됩니다. / 이런 경우는 카드가 되는 모델로 바꾸는 쪽을 생각해 보셔야 합니다.

# 설정하기 전에 꼭 챙길 두 가지
첫째는 새 배터리입니다. / 설정 도중에 전원이 나가면 반만 저장돼서 오히려 문이 안 열리는 일이 생길 수 있습니다.
둘째는 등록할 카드를 미리 여러 장 준비하는 것입니다. / 카드가 한 장뿐이면 잃어버리는 순간 번호만으로는 못 여는 상태가 됩니다.
그리고 설정은 문을 열어 둔 상태에서 하세요. / 문 밖에 사람이 서 있는 상태에서 안쪽 설정을 바꾸는 건 피하는 게 안전합니다.

# 이중 인증을 켜는 일반적인 흐름
제품마다 버튼 순서는 다르지만 큰 흐름은 비슷합니다. / 관리자 모드로 들어가 카드를 등록하고, 인증 방식을 복합으로 바꾸고, 저장하는 순서입니다.
- 안쪽 번호판 버튼으로 관리자 모드 진입
- 사용할 카드를 한 장씩 태그해 등록
- 인증 방식 항목에서 번호와 카드 동시 사용 선택
- 문을 연 채로 바깥에서 번호와 카드 순서대로 시험
시험할 때는 번호만 눌러 보고 열리지 않는지, 카드만 대 보고 열리지 않는지도 확인해 보세요. / 둘 중 하나로 열린다면 설정이 제대로 저장되지 않은 것입니다.
@ 도어락 카드 태그 등록과 인증 방식 선택 화면
어떤 제품은 번호를 먼저 누르고 카드를 대야 하고, 어떤 제품은 반대입니다. / 순서를 틀리면 오류음이 나고 몇 번 반복되면 입력이 잠시 막히기도 합니다.
처음 설정한 날 가족 모두에게 순서를 알려 주세요. / 종이에 적어 현관 안쪽에 붙여 두면 잘 헷갈리지 않습니다.

# 카드를 잃어버렸을 때가 가장 곤란합니다
이중 인증의 약점은 카드를 잃으면 번호를 알아도 못 연다는 점입니다. / 그래서 설정과 함께 예비 카드를 어디에 둘지까지 정해 두셔야 합니다.
예비 카드는 집 안 현관 근처와 직장 책상 서랍처럼 서로 다른 곳에 한 장씩 나눠 두는 방법이 있습니다. / 한곳에 모아 두면 한 번에 같이 잃을 수 있습니다.
카드를 잃었다면 일단 기존 카드를 삭제하고 새로 등록하는 게 맞습니다. / 이 작업은 문이 열려 있을 때만 가능하니, 이미 잠긴 상태라면 아래 순서로 연락 주세요.

# 문 앞에서 인증이 안 될 때 먼저 볼 것
이중 인증으로 바꾼 뒤 갑자기 안 열린다는 연락이 오면 확인하는 순서가 있습니다. / 대부분은 고장이 아니라 인증 순서나 카드 상태 문제입니다.
- 번호판이 켜지는지, 카드를 댔을 때 소리가 나는지
- 카드를 대는 위치와 시간이 맞는지(너무 빨리 떼지 않았는지)
- 카드 여러 장을 지갑에 겹쳐 두어 서로 간섭하지 않는지
- 번호 입력 후 정해진 시간 안에 카드를 댔는지
지갑에 교통카드와 같이 두면 어느 카드가 읽혔는지 헷갈릴 때가 있습니다. / 도어락 카드만 한 장 꺼내서 대 보시면 원인이 금방 갈립니다.

# 이중 인증이 꼭 필요한 집은 따로 있습니다
모든 집에 이중 인증이 어울리는 건 아닙니다. / 아이나 어르신이 혼자 출입하는 집이라면 오히려 불편이 커질 수 있습니다.
반대로 비워 두는 시간이 길거나 여러 사람이 번호를 알고 있는 집이라면 도움이 됩니다. / 가사도우미나 지인에게 번호를 알려 준 적이 있다면 카드까지 있어야 열리게 하는 것이 마음 편할 수 있습니다.
우리 집 식구 구성에 맞는지부터 따져 보시는 것이 순서입니다. / 불필요하게 복잡하게 만들면 정작 가족이 문 앞에서 막힙니다.

# 직접 안 되면 관양동으로 출장열쇠를 부르는 때
설정 중에 반응이 없거나 모드에서 빠져나오지 못하는 경우가 있습니다. / 초기화 방법을 몰라 헤매다 배터리를 다 쓰는 일도 생깁니다.
관양동에서 [안양 출장열쇠](anyang.html)를 부르실 때는 모델명 사진과 번호판 상태, 지금 어디까지 눌렀는지를 말씀해 주세요. / 그 정보만으로도 챙겨 갈 것을 정하기 쉬워집니다.
이미 문이 잠겨 들어갈 수 없는 상황이면 [현관문 개문](door-open.html)부터 진행합니다. / 문을 열고 난 뒤에 인증 설정을 바로잡는 것까지 같이 합니다.
@ 출장열쇠가 번호판 모델명과 인증 상태를 확인하는 모습

# 도착하면 신분부터 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
카드와 번호를 함께 쓰는 집이라도 이 절차는 같습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 이중 인증이 안 되는 모델이면 바꿀지 고쳐 쓸지
기능이 없는 모델은 설정을 아무리 해도 되지 않습니다. / 이럴 때는 카드가 되는 제품으로 바꾸는 방법이 있고, 설치 전에 문 두께와 보조키 위치를 먼저 봐야 합니다.
새로 달고 싶으시면 [도어락 설치](doorlock-install.html)에서 확인할 것을 보실 수 있습니다. / 고장이 원인이라면 [도어락 수리](doorlock-repair.html)로 먼저 살펴보고, 너무 오래된 제품일 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 설정 뒤에 주기적으로 해볼 점검
이중 인증은 한 번 켜고 잊어버리면 문제가 되기 쉽습니다. / 몇 달에 한 번씩 등록된 카드와 번호가 지금 상황에 맞는지 살펴보세요.
- 안 쓰는 카드가 남아 있지 않은지
- 이사 간 사람이나 그만둔 도우미의 번호가 지워졌는지
- 배터리 경고음이 나지 않는지
카드는 장수가 많을수록 관리가 어렵습니다. / 꼭 필요한 만큼만 남기는 것이 좋습니다.

# 관양동 말고 안양 어디든 갑니다
관양동 가까이 평촌동, 비산동, 호계동, 귀인동, 부흥동, 안양동, 석수동, 박달동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에, 다른 지역은 [출장 지역](area.html) 지도에 정리해 두었습니다.
