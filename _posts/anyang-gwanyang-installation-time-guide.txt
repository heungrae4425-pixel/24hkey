# 관양동 도어락 설치, 얼마나 걸릴까요
인덕원역과 평촌역 사이를 오가며 지내는 관양동 생활권에서도 도어락을 새로 달거나 바꾸려는 분들이 꾸준히 문의를 주십니다. / 가장 많이 물으시는 말이 시간이 얼마나 걸리는지, 그날 일정을 비워야 하는지입니다.
이 글은 도어락 설치에 시간이 걸리는 이유와 준비해 두면 빨라지는 것들을 순서대로 정리했습니다. / 정확한 시간은 문 상태에 따라 달라서 현장에서 먼저 말씀드립니다.
@ 관양동 도어락 설치 전 현관문 확인

# 설치 시간은 문 상태에 따라 달라집니다
같은 도어락이라도 기존 문에 이미 맞는 구멍이 있느냐에 따라 시간이 달라집니다. / 기존 도어락을 떼고 같은 규격의 새 제품을 다는 경우가 가장 단순합니다.
열쇠식에서 디지털로 처음 바꾸는 경우나 구멍 규격이 다른 경우는 조정할 일이 늘어납니다. / 이런 문은 구멍을 맞추는 작업이 더해져 시간이 더 걸릴 수 있습니다.
그래서 시간을 숫자로 약속하기보다 문을 보고 말씀드리는 방식으로 안내합니다.

# 기존 도어락이 있는 문과 없는 문
기존에 번호식 도어락이 달린 문이라면 규격을 확인하고 맞는 제품을 고르면 됩니다. / 제거하고 새로 다는 순서가 단순해 비교적 부담이 적습니다.
열쇠만 쓰던 문에 처음 도어락을 다는 경우는 문 두께와 보조키 구멍 위치를 먼저 확인해야 합니다. / 맞지 않는 제품을 사 두면 설치 자체가 어려울 수 있습니다.
어느 쪽이든 문 사진을 보내주시면 가능 여부를 먼저 알려드립니다.

# 방문 전에 준비해 두면 빨라지는 것
- 새로 달 도어락 제품, 구입처에서 받은 설명서와 부속품 일체
- 지금 문에 달린 도어락 모양과 열쇠 구멍 사진
- 문 두께와 안쪽 보조키 위치를 확인할 수 있는 사진
- 현관 앞 작업 공간, 신발장이나 짐 정리
- 새로 쓸 비밀번호 후보와 카드키 보관 계획
준비 목록이 길어 보이지만 대부분 사진 몇 장과 정리가 전부입니다. / 이 정도만 준비해 두셔도 작업이 매끄럽습니다.
@ 도어락 설치 부속품과 설명서 준비

# 도어락을 직접 사 두셨다면 확인할 것
인터넷에서 미리 사신 제품이 문에 맞는지가 가장 큰 변수입니다. / 문이 얇거나 두꺼우면 부속품 길이가 달라지고, 문에 따라 지원하지 않는 모델도 있습니다.
박스와 설명서는 버리지 말고 같이 두세요. / 설치 중 부품이 맞지 않아 교환이 필요할 때 포장이 있어야 수월합니다.
구입 전에 먼저 전화로 문을 설명해 주시면 어떤 규격이 맞는지 안내해 드릴 수 있습니다. / 이미 구입하셨다면 제품명만 알려주셔도 호환 여부를 먼저 살펴봅니다.

# 문 두께와 보조키, 왜 미리 보나요
도어락은 문을 관통하는 부품이라 문 두께가 맞지 않으면 고정이 불안정해집니다. / 보조키는 문틀 쪽 위치와 맞물려야 해서 단순히 도어락만 바꾸는 일이 아닐 때가 있습니다.
설치 전에 두 가지를 확인하면 작업 중간에 멈추는 일이 줄어듭니다. / 자세한 설명은 [도어락 설치](doorlock-install.html) 페이지에 정리해 두었습니다.

# 설치 당일 진행 순서
도착하면 먼저 문과 기존 장치를 살피고 설치 가능한 제품인지 확인합니다. / 이상이 없으면 기존 장치를 떼고 구멍을 정리한 뒤 새 도어락을 고정합니다.
고정 후에는 문을 열고 닫으며 걸쇠가 잘 움직이는지 확인합니다. / 배터리를 끼워 전원이 들어오고 번호와 카드가 인식되는지 함께 점검합니다.
마지막으로 사용 방법을 알려드리고 비밀번호를 등록합니다. / 중간에 부품 교체가 필요해 보이면 손대기 전에 먼저 말씀드립니다.

# 작업이 오래 걸릴 수 있는 경우
- 문 구멍을 새로 조정해야 하는 경우
- 오래된 문이라 철판이 뒤틀려 부품이 안 맞는 경우
- 문틀이 처져 보조키와 맞물림이 어긋나는 경우
- 구입한 제품이 문에 맞지 않아 교환이 필요한 경우
이런 경우는 현장에서 사정을 설명드리고 계속할지 여쭙니다. / 무리하게 끼워 맞추지 않습니다.
@ 도어락 구멍 규격과 문 두께 확인

# 일정은 이렇게 잡으면 편합니다
출근이나 외출 직전에 급하게 맞추기보다 여유 있는 시간대를 고르시는 편이 좋습니다. / 작업이 끝난 뒤 문을 여러 번 열고 닫아 보며 확인할 시간이 필요하기 때문입니다.
이사 날짜에 맞추려는 경우라면 짐이 들어오기 전에 설치하는 것이 가장 수월합니다. / 현관 앞에 상자가 쌓여 있으면 작업 공간이 좁아져 시간이 늘어납니다.
설치 전 사시는 분인지 확인하는 절차가 있어 신분증이나 주소가 나온 우편물을 챙겨 두시면 좋습니다. / 이 확인이 끝나야 작업을 시작할 수 있습니다.
오전과 오후 중 편한 때를 전화로 말씀해 주시면 가능한 시간을 맞춰 안내드립니다. / 일정이 바뀌어도 미리 알려주시면 다시 조정해 드립니다.

# 설치 중에 집에 계셔야 하나요
작업 시작할 때와 끝날 때는 계셔야 합니다. / 시작할 때는 사시는 분인지 확인하고, 끝날 때는 비밀번호 등록과 사용법 설명이 필요하기 때문입니다.
중간에 잠깐 자리를 비우는 정도는 괜찮지만 문이 열린 채로 오래 두기는 어렵습니다. / 집에 아무도 없을 일정은 미리 말씀해 주세요.

문을 다루는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.

# 비용은 시작하기 전에 먼저 말씀드립니다
문을 보고 제품과 작업 내용을 정한 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하셔야 시작하고 마음에 안 드시면 그냥 돌아갑니다.
열고 난 뒤 말없이 더해지는 비용은 없습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭙니다. 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 설치가 끝난 뒤 챙길 것
설치 후에는 문을 닫은 채로 바깥에서 번호와 카드를 한 번씩 눌러 확인해 보세요. / 안쪽 버튼으로 잠그고 푸는 것도 해보시면 좋습니다.
기본 번호는 반드시 바꾸고, 사용하지 않는 카드나 번호는 지워 둡니다. / 설명서와 제품 박스는 보관해 두시고 배터리 교체일을 메모해 두세요.
오래 써 온 문이라 고장이 잦다면 새로 설치하는 것 말고 [도어락 수리](doorlock-repair.html)로 먼저 해결할 수도 있습니다. / 같은 규격으로 바꾸는 경우는 [도어락 교체](doorlock-replace.html) 안내를 참고하세요.

# 관양동 말고 안양 어디든 갑니다
관양동 옆 평촌동, 비산동, 호계동은 물론 귀인동, 부흥동, 안양동, 석수동, 박달동까지 안양 안이면 24시간 출동합니다. / 인덕원역, 범계역, 평촌역, 안양역 어느 쪽이든 편하게 위치만 알려주세요.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
