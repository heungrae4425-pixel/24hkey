# 들어갈 때와 나올 때 도어락은 다르게 봐야 합니다
관양동은 인덕원역과 평촌역 사이 생활권이라 전세와 월세로 오가는 분이 많은 동네입니다. / 집을 옮기는 일은 짐이 우선이라 현관 도어락은 늘 뒷전이 되기 쉽습니다.
그런데 들어갈 때와 나올 때 도어락에서 챙길 것은 서로 다릅니다. / 들어갈 때는 이전 흔적을 지우는 일이고, 나올 때는 내 흔적을 깨끗이 정리하는 일입니다.
이 글은 입주와 퇴거 두 장면으로 나눠 챙길 것을 정리했습니다. / 지금 어느 쪽인지 해당 부분부터 읽으셔도 됩니다.
@ 관양동 입주 퇴거 현관 도어락 인계

# 입주 첫날 도어락에서 가장 먼저 할 일
새집에 들어가 열쇠를 받으면 바로 번호부터 바꾸세요. / 이전에 살던 사람이나 집주인, 중개 관련자 중 누가 번호를 알고 있는지 알 수 없기 때문입니다.
번호를 바꿀 때는 문을 연 상태에서 안쪽 버튼으로 등록하고, 바깥에서 새 번호가 열리는지 꼭 확인하세요. / 이전 번호는 지워지고 새 번호만 남았는지도 눌러서 확인합니다.
배터리도 입주 때 새것으로 바꿔 두면 안심됩니다. / 전 입주자가 쓰던 배터리가 얼마나 남았는지 알 수 없습니다.

# 받은 열쇠와 카드의 수를 세어 보기
계약할 때 인계받는 열쇠와 카드키의 수를 그 자리에서 확인하세요. / 몇 개를 받았는지 적어 두면 퇴거 때 같은 수를 돌려줄 때 편합니다.
- 현관 열쇠와 보조키 열쇠 각각 몇 개인지
- 카드키나 태그, 리모컨이 있다면 몇 개인지
- 공동 현관이나 우편함 열쇠도 따로 있는지
- 인계받은 날짜와 받은 사람 이름
수를 모르는 채로 입주하면 나중에 분실 책임을 두고 곤란해질 수 있습니다. / 휴대폰으로 열쇠를 한꺼번에 찍어 두는 것도 좋은 기록이 됩니다.

# 입주 때 이미 문제가 있다면
들어가자마자 문이 뻑뻑하거나 번호판 반응이 늦다면 그날 바로 이야기해 두세요. / 입주 후 한참 지나서 이야기하면 누가 만든 문제인지 가리기 어렵습니다.
도어락 상태를 사진과 짧은 영상으로 남기고 집주인이나 관리 쪽에 알립니다. / 누구 비용으로 고칠지는 집마다 사정이 다르니 서로 이야기해서 정하세요.
고쳐서 쓸 수 있으면 교체까지 하지 않아도 됩니다. / 먼저 [도어락 수리](doorlock-repair.html)로 해결되는지 확인하세요.
@ 입주 때 도어락 상태 사진 기록

# 퇴거를 앞두고 한 달 전부터 할 일
나가는 날이 정해졌다면 도어락 정리도 일정에 넣어야 합니다. / 마지막 날 한꺼번에 하면 놓치기 쉽습니다.
먼저 내가 추가로 등록한 번호와 카드, 지문이 있는지 정리합니다. / 가족이 쓰던 지문이나 카드는 등록을 지워야 나가는 사람의 흔적이 남지 않습니다.
도어락을 내가 직접 설치한 것이라면 두고 갈지 가져갈지 집주인과 미리 이야기하세요. / 가져간다면 원래 있던 잠금장치를 되돌려 놓아야 하는지도 같이 정해 두세요.

# 퇴거 당일 문 앞에서 확인할 순서
이삿짐이 모두 빠지고 마지막으로 집을 나서기 전에 도어락을 점검합니다. / 배터리가 남아 있고 경고음이 없는지, 문이 부드럽게 열리고 닫히는지 봅니다.
내 번호를 지우고 초기화할지는 집주인과 합의한 내용에 따릅니다. / 임의로 초기화하면 다음 입주자와 집주인이 곤란해질 수 있습니다.
받았던 열쇠와 카드의 수를 맞춰 보고 전달할 사람에게 직접 건네세요. / 우편함이나 현관 앞에 두고 나오는 것은 분실 위험이 있습니다.

# 관리비 정산과 함께 챙기면 좋은 것
퇴거 때는 관리비와 공과금 정산, 청소, 원상복구 이야기로 마음이 분주합니다. / 이때 도어락 인계도 한 줄 체크 목록에 넣어 두면 빠뜨리지 않습니다.
관리사무소에 등록해 둔 출입 카드나 공동 현관 키가 있다면 그것도 반납 대상입니다. / 반납 확인서를 받거나 문자로 확인을 받아 두세요.
이사 가는 곳의 도어락도 같은 방식으로 미리 알아 두면 양쪽이 한 번에 정리됩니다. / 날짜가 겹치는 이사일수록 이중으로 챙길 것이 많다는 점을 기억하세요.

# 인계 사진을 남겨 두는 이유
나가는 날 도어락과 현관문 상태를 다시 한번 사진으로 남기세요. / 입주 때 찍어 둔 사진과 비교하면 원래 상태가 어땠는지 분명해집니다.
후에 문제가 생겼을 때 누구 책임인지 가리는 근거가 되기도 합니다. / 정확한 판단은 서로 이야기하고 필요하면 계약서를 확인해서 정해야 합니다.
열쇠를 돌려준 날짜와 시간을 문자로 남기면 더 확실합니다. / 구두로만 주고받는 것보다 기록이 나중에 도움이 됩니다.

# 열쇠를 잃어버린 채 나가야 할 때
퇴거할 때 열쇠 하나를 못 찾는 경우가 의외로 많습니다. / 이때는 없는 열쇠를 숨기지 말고 집주인에게 사실대로 말씀드리세요.
분실된 열쇠가 있는 집은 다음 입주자 입장에서 불안한 요소입니다. / 그래서 이런 경우에는 열쇠가 필요 없는 상태로 바꾸는 방법을 같이 의논하게 됩니다.
번호키라면 번호를 새로 정하고 등록된 카드를 지우는 것으로 충분한 경우가 많습니다. / 열쇠 방식이라면 [도어락 교체](doorlock-replace.html)나 [열쇠 복사](key-call.html) 같은 대안을 의논합니다.

# 입퇴거 날 문이 갑자기 안 열릴 때
이삿날은 정신이 없어 열쇠를 집 안에 둔 채 문이 닫히는 일이 많습니다. / 짐을 나르다 문이 닫혀 이삿짐 업체까지 대기하게 되는 곤란한 상황이 생깁니다.
이럴 때는 위치와 호수, 번호판 상태를 알려주세요. / 문을 열기 전에 사시는 분 확인을 하는데 신분증 주소, 우편물, 관리사무소 확인 중 하나면 됩니다.
입주 직전이거나 퇴거 직전이라 주소가 맞는 서류가 없다면 계약서나 관리사무소 확인을 활용하세요. / 문을 끝내 못 열면 비용은 받지 않고, 비용은 문 열기 전에 먼저 말씀드립니다.

# 열고 나서 번호 정리까지 한 번에
문이 열린 뒤 번호를 새로 정하고 배터리를 바꾸는 것까지 같은 방문에서 마무리할 수 있습니다. / 입주 직후라면 이전 흔적을 지우는 좋은 기회입니다.
개방 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다. / 가능하면 문과 도어락이 상하지 않는 방법부터 시도합니다.
번호는 본인이 직접 입력하고 저는 번호를 알 수 없도록 합니다.

# 입주 퇴거 한눈에 정리
마지막으로 들어갈 때와 나올 때 체크할 것을 간단히 모았습니다. / 이 목록을 사진으로 저장해 두고 이사철마다 꺼내 보세요.
- 입주: 번호 변경, 배터리 교체, 열쇠 수 확인, 도어락 상태 기록
- 퇴거: 내 번호 정리, 열쇠 수 맞추기, 상태 기록, 인계 날짜 기록
- 공통: 문이 부드럽게 닫히는지, 경고음은 없는지
세부 순서는 [이용안내](guide.html)에서도 확인할 수 있습니다.
@ 관양동 입주 퇴거 도어락 체크

# 관양동 말고 안양 어디든 갑니다
관양동 옆 비산동, 평촌동, 부흥동, 호계동, 귀인동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
동네별 안내는 [안양시 출장열쇠](anyang.html)에, 다른 지역은 [출장 지역](area.html) 지도에 있습니다.

? 퇴거할 때 도어락을 초기화해도 되나요? | 집주인과 합의한 대로 하세요. 임의로 하면 다음 입주자가 곤란할 수 있습니다.
? 열쇠를 하나 잃어버렸어요. | 숨기지 말고 집주인에게 알리고 번호 정리나 교체 같은 방법을 같이 정하세요.
? 이삿날 문이 안 열려도 오시나요? | 네, 24시간 출동합니다. 사시는 분 확인이 필요합니다.
? 못 열면 비용을 내나요? | 끝내 못 열면 비용은 받지 않습니다.
