# 관리사무소 불이 꺼진 저녁에 문 앞에서
귀인동은 범계역에서 걸어 들어가는 길에 아파트와 빌라가 이어져 있어 퇴근 시간대에 귀가하는 분이 많습니다. / 그런데 열쇠도 번호도 말을 듣지 않는 날은 꼭 관리사무소가 문을 닫은 저녁에 찾아옵니다.
평소에는 있는 줄도 몰랐던 사무실이 막상 필요한 순간에는 불이 꺼져 있습니다. / 경비실이 비어 있거나 야간 근무자가 순찰을 나간 시간이면 더 막막합니다.
이 글은 관리사무소가 퇴근한 뒤 문이 잠겼을 때 무엇을 먼저 하고 누구에게 확인받을 수 있는지 정리했습니다. / [안양 출장열쇠](anyang.html)를 부르기 전에 읽어 두시면 한결 빠릅니다.
@ 귀인동 퇴근 후 관리사무소 불 꺼진 아파트 입구

# 사무실이 닫혔을 때 생기는 불편 세 가지
관리사무소가 열려 있는 낮에는 세대 확인도, 예비 열쇠 문의도 쉽게 해결됩니다. / 문제는 퇴근 이후에 같은 일을 해야 할 때입니다.
- 세대 주민이 맞는지 확인해 줄 사람이 없다는 점
- 공용 출입문이나 현관 번호를 모를 때 물어볼 곳이 없다는 점
- 이웃에게 부탁하려 해도 늦은 시간이라 망설여진다는 점
이 세 가지가 겹치면 문 하나 여는 일이 괜히 크게 느껴집니다. / 하나씩 대안을 알아 두면 생각보다 간단히 풀립니다.

# 먼저 공용 출입구부터 따져 보세요
집 현관문이 문제인지, 아파트 공동 현관이 문제인지 먼저 나눠야 합니다. / 같은 잠김이라도 부르는 곳과 순서가 다르기 때문입니다.
공동 현관 비밀번호가 바뀐 거라면 이웃이 문을 열고 나올 때 같이 들어가면 됩니다. / 그 뒤 우리 집 현관문 앞에서 다시 상황을 보시면 됩니다.
현관문 자체가 안 열린다면 번호판 불빛, 소리, 손잡이 움직임을 차례로 살펴보세요. / 전화로 설명하기 쉬워지고 맞는 장비를 챙겨 가기 좋습니다.

# 경비실과 야간 근무자가 있다면 이렇게
단지에 야간 경비 근무자가 있다면 가장 먼저 찾아가 볼 곳입니다. / 세대 확인과 공용부 출입을 도와줄 수 있는 경우가 있습니다.
다만 단지마다 야간 운영 방식이 다르니 가능한 일과 불가능한 일은 직접 물어보셔야 합니다. / 안 된다고 하면 더 붙잡지 말고 다음 단계로 넘어가는 편이 낫습니다.
경비 근무자에게는 몇 동 몇 호 거주자인지, 문이 어떤 상태인지만 짧게 말씀드리면 충분합니다. / 출장열쇠가 도착했을 때 확인을 거들어 달라고 부탁해 두면 더 좋습니다.

# 신분 확인은 이런 것으로 대신할 수 있습니다
문을 열기 전에는 사시는 분인지 확인하는 것이 원칙입니다. / 관리사무소가 닫았다면 다른 방법으로 대신하면 됩니다.
- 현재 주소가 적힌 신분증
- 집 주소가 찍힌 우편물이나 고지서
- 휴대폰에 저장된 임대차 서류나 주소가 나오는 앱 화면
- 경비 근무자가 해 주는 세대 확인
이 중 하나만 있어도 진행이 가능한 경우가 많습니다. / 모두 집 안에 있다면 전화로 먼저 상황을 말씀해 주세요. 가능한 방법을 같이 찾아 봅니다.

# 열쇠 맡겨 둔 곳이 있는지 떠올려 보기
퇴근 후 사무실이 닫혔을 때를 대비해 열쇠를 가까운 사람에게 맡겨 둔 분도 있습니다. / 가족, 가까운 친구, 회사 동료가 가진 예비 열쇠가 있는지 먼저 떠올려 보세요.
가까이 있는 사람이라면 열쇠를 받아 오는 게 가장 간단한 경우도 많습니다. / 멀리 있다면 이동 시간과 늦은 시간을 생각해 출장열쇠가 더 빠를 수 있습니다.
어느 쪽이 나을지는 상황마다 다릅니다. / 망설여지면 전화로 물어보셔도 됩니다.

# 억지로 열려다 문을 상하게 하는 경우
시간이 늦고 추워지면 마음이 급해져 문틈에 카드나 도구를 넣어 보는 분이 계십니다. / 하지만 이러면 걸쇠나 문틀 고무가 상해 오히려 일이 커집니다.
손잡이를 있는 힘껏 돌리거나 문을 어깨로 미는 것도 피해 주세요. / 도어락 안쪽 부품이 틀어지면 고치는 데 손이 더 갑니다.
번호를 계속 틀리게 누르면 일정 시간 입력이 막히는 도어락도 많습니다. / 서너 번 해 보고 안 되면 멈추고 기다리는 편이 안전합니다.
@ 귀인동 현관문 도어락 번호판 상태 확인

# 전화할 때 이 정보를 말씀해 주세요
통화할 때 필요한 정보는 많지 않습니다. / 아래를 알려주시면 출동 여부와 도착 시간을 말씀드리기 쉽습니다.
- 귀인동 어느 건물인지, 동과 호수
- 범계역 쪽에서 오는 길인지 등 대략적인 방향
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 도어락 모양과 보조키 유무
- 안에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 챙길 장비를 정하기 좋습니다. / 안에 사람이 혼자 있는 상황이면 가장 먼저 말씀해 주세요.

# 도착 후 진행과 비용 안내
도착하면 먼저 신분을 확인하고 문 상태를 봅니다. / 그런 다음 문을 열기 전에 비용부터 말씀드립니다.
괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하는 경우도 바꾸기 전에 먼저 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 자세히 적어 두었습니다.

# 문을 여는 방법은 덜 상하는 순서대로
최대한 문과 도어락이 상하지 않는 방법부터 해 봅니다. / 도어락 종류와 문 상태에 따라 걸리는 시간은 다릅니다.
현관문 개문 방식이 궁금하시면 [현관문 개문](door-open.html) 페이지를 보시면 됩니다. / 현장에서도 어떻게 진행하는지 중간중간 설명드립니다.
@ 귀인동 출장열쇠 비파손 문 열기 작업

# 열고 난 뒤 같이 점검할 것
문이 열리면 다시 잠기고 열리는지 함께 확인합니다. / 배터리가 원인이었다면 새것으로 바꿨는지도 봅니다.
번호를 잊었던 경우에는 안쪽에서 새 번호를 등록하고 기존 번호는 지웁니다. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 정리하고, 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 다음에 막히지 않도록 미리 해둘 일
관리사무소가 열리는 시간과 야간 연락 방법을 한 번 확인해 두세요. / 휴대폰에 번호를 저장해 두면 필요한 순간에 바로 쓸 수 있습니다.
- 사무실 운영 시간과 야간 경비 유무 확인
- 예비 열쇠나 카드키를 믿을 만한 사람에게 맡기기
- 배터리는 연말쯤 한 번에 교체
- 출장열쇠 연락처를 휴대폰에 저장
- 신분증 사진 대신 실제 주소가 나온 서류를 챙겨 두기
이 정도만 해 두어도 퇴근 후 막히는 일이 크게 줄어듭니다. / 작은 준비가 늦은 밤의 당황을 덜어 줍니다.

# 귀인동 옆 동네도 다닙니다
귀인동 가까운 평촌동, 비산동, 호계동, 관양동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
안양에서 다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문

? 신분 확인은 꼭 해야 하나요? | 네, 사시는 분이 맞는지 신분증, 우편물, 관리사무소 확인 중 하나로 확인합니다.
? 신분증이 집 안에 있으면 어떻게 하나요? | 우편물이나 주소가 나오는 서류, 경비 근무자 확인 등으로 대신할 수 있는지 전화로 먼저 의논해 주세요.
? 문을 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 비용은 언제 알려주시나요? | 문을 열기 전에 먼저 말씀드리고, 동의하셔야 시작합니다.

# 마무리
관리사무소가 퇴근한 뒤 문이 잠기면 억지로 열려 하지 마시고 상태부터 확인해 주세요. / 신분 확인할 서류가 있는지만 떠올리시면 나머지는 전화로 안내해 드립니다.
24시출장열쇠는 귀인동을 포함한 안양 전 지역에서 늦은 밤에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
