# 문 앞에서 가장 먼저 나오는 질문
문이 안 열리면 전화를 걸자마자 "언제쯤 올 수 있어요?"가 먼저 나옵니다. / 귀인동처럼 안양역이나 인덕원역 쪽으로 오가는 분이 많은 동네에서는 밤늦게 귀가하다 이런 일을 겪는 경우가 많습니다.
도착 시간은 가장 궁금한 정보이면서 가장 정확히 답하기 어려운 정보이기도 합니다. / 왜 그런지, 그리고 어떻게 물으면 더 믿을 만한 답을 받는지 적어 보았습니다.
@ 귀인동 출장열쇠 도착 시간 문의

# 왜 시간을 딱 잘라 말하기 어려울까
출장 기사님이 다른 집에서 작업을 하고 있으면 그 작업이 끝나야 출발할 수 있습니다. / 문 하나가 생각보다 오래 걸리는 일도 있어서 앞선 작업이 늘어지기도 합니다.
특히 밤늦은 시간이나 비 오는 날에는 요청이 한꺼번에 몰리기도 합니다. / 그럴 때일수록 현재 상황을 솔직하게 말씀드리는 것이 서로 편합니다.
도로 사정도 변수입니다. / 퇴근 시간대나 비 오는 밤에는 같은 거리도 시간이 달라집니다.
그래서 "정확히 몇 분"보다는 "대략 어느 정도, 늦어지면 다시 연락"이라는 답이 더 솔직한 답입니다. / 무조건 빨리 간다는 말만 하는 곳은 한 번 의심해 보셔도 좋습니다.
그래서 24시출장열쇠도 먼저 지금 상황을 듣고, 갈 수 있는 시간을 있는 그대로 말씀드립니다. / 늦어질 것 같으면 숨기지 않고 미리 알려 드립니다.

# 전화로 이렇게 물어보세요
- 지금 출발 가능한 상태인지
- 출발하면 대략 얼마쯤 걸릴 것 같은지
- 늦어지면 다시 연락을 주는지
- 도착 전에 제가 준비할 것이 있는지
네 가지를 차례로 물으면 답이 훨씬 구체적으로 돌아옵니다. / 마지막 질문은 신분 확인 서류를 미리 챙길 시간을 벌어 줍니다.
전화를 끊기 전에 도착 전 연락을 받을 번호가 지금 걸고 있는 번호가 맞는지도 확인해 두세요. / 휴대폰 배터리가 얼마 남지 않았다면 그 점도 같이 말씀해 주시는 게 좋습니다.

# 위치를 정확히 알려줄수록 빨라집니다
귀인동은 골목과 건물 이름이 비슷해서 길을 헷갈리기 쉽습니다. / 지도 앱에서 보이는 건물 이름, 동과 호수, 출입구 방향을 같이 말씀해 주세요.
공동현관 비밀번호가 있다면 그 방법도 알려 주셔야 올라가는 시간이 줄어듭니다. / 공동현관이 닫혀 있으면 아래서 기다리느라 시간이 새는 일이 많습니다.
휴대폰 위치를 문자로 보내 주시면 길 찾는 시간이 크게 줄어듭니다. / 주차할 곳이 마땅치 않은 골목이라면 그 점도 알려 주세요.
건물 앞에 공사나 행사로 길이 막혀 있다면 그 이야기도 도움이 됩니다. / 가까운 큰길 이름을 같이 알려 주시면 길 안내가 쉬워집니다.

# 도착 전 문 앞에서 해 볼 수 있는 것
기다리는 동안 그냥 서 있기보다 상태를 살펴 두면 도착해서 바로 일이 됩니다. / 번호판이 켜지는지, 누르면 어떤 소리가 나는지만 확인해도 충분합니다.
번호를 눌렀을 때 삑 소리가 한 번인지 여러 번인지, 불빛이 붉은색인지 푸른색인지 정도를 기억해 두세요. / 이렇게 전해 주시면 전화로도 원인을 어느 정도 가늠하고 알맞은 장비를 챙길 수 있습니다.
@ 도착 전 번호판 상태 확인

# 하지 말아야 할 것, 기다리는 동안
시간이 길게 느껴지면 손잡이를 세게 당기거나 문을 두드려 보게 됩니다. / 이러면 걸쇠가 더 꽉 물리고 손잡이 축이 상할 수 있습니다.
카드나 칼로 문틈을 벌리는 것도 피해 주세요. / 문과 도어락이 흠집이 나면 나중에 손볼 일이 늘어납니다.
번호를 여러 번 틀리면 도어락이 입력을 한동안 막기도 합니다. / 서너 번 해 보고 안 되면 멈추고 기다리는 게 낫습니다.
기다리는 동안 문에 귀를 대 보면 모터 소리가 나는지 알 수 있습니다. / 소리가 나는지 여부도 도착 전에 전화로 말씀해 주시면 도움이 됩니다.

# 추운 날, 비 오는 날 기다리는 방법
복도나 공동현관 안쪽에서 기다릴 수 있다면 그곳이 가장 안전합니다. / 건물 밖에서 기다려야 한다면 근처 편의점이나 상가 안에서 기다리다가 도착 시간에 맞춰 나오세요.
이웃에게 양해를 구해 잠깐 앉아 있는 방법도 있습니다. / 밤늦은 시간에는 경비실이 있는 건물이라면 먼저 말씀해 두면 편합니다.
두꺼운 외투를 입고 있다면 주머니에 휴대폰 충전기가 있는지도 확인해 보세요. / 기다리는 동안 휴대폰이 꺼지지 않게 하는 것이 가장 중요합니다.

# 집 안에 사람이 있다면 먼저 말씀해 주세요
어린 아이나 반려동물이 집 안에 있다면 이야기가 달라집니다. / 이런 경우 일반적인 순서보다 우선해서 움직입니다.
문 너머로 계속 말을 걸어 아이가 놀라지 않게 해 주시고, 전화할 때 꼭 먼저 알려 주세요. / 불이나 가스를 켜 둔 채 나온 경우도 같습니다.
이런 사정이 있으면 도착 시간이 다른 요청보다 우선순위가 됩니다. / 숨기지 말고 사실 그대로 말씀해 주세요.
@ 귀인동 집 안 상황 먼저 알리기

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 본인 모두를 위한 절차입니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하시면 됩니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도착해서 문과 도어락을 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
출장 진행 방식은 [이용안내](guide.html)에, 개문 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다. / 읽어 보시면 도착 후 흐름이 그려질 겁니다.

# 열고 난 뒤 확인하는 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이면 새것으로 바꾸고, 번호를 잊은 경우는 새 번호 등록을 도와드립니다.
자주 같은 일이 생기면 [도어락 수리](doorlock-repair.html)로 먼저 손보는 쪽을 권합니다. / 너무 오래된 제품일 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 같은 일을 줄이는 습관
- 배터리 교체일을 달력에 적어 두기
- 가족 중 한 명은 비상 열쇠나 카드키를 따로 보관하기
- 외출 전 휴대폰, 열쇠, 카드 챙겼는지 현관에서 한 번 보기
- 자주 쓰는 출장열쇠 번호를 휴대폰에 저장해 두기

번호를 미리 저장해 두면 급할 때 검색하는 시간이 줄어듭니다. / 문 앞에서 쓰는 몇 분이 길게 느껴지는 법입니다.

# 귀인동 말고 안양 어디든 갑니다
귀인동 옆 부흥동, 안양동, 석수동, 박달동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에, 다른 지역은 [출장 지역](area.html)에 있습니다.

# 자주 묻는 질문
? 도착 시간을 정확히 말씀해 주실 수 있나요? | 상황에 따라 달라져서 대략의 시간으로 말씀드리고, 늦어지면 다시 연락드립니다.
? 위치는 어떻게 알려드려야 하나요? | 건물 이름, 동과 호수, 출입구 방향을 말씀해 주시고 휴대폰 위치도 보내 주시면 좋습니다.
? 기다리는 동안 제가 할 일이 있나요? | 번호판 상태를 확인하고 신분증이나 우편물을 챙겨 두시면 됩니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 새벽에도 전화받나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.

24시출장열쇠는 늦은 밤에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
