# 귀인동 문 앞에서 손잡이가 안 돌아갈 때
귀인동은 아파트와 빌라, 주택이 섞여 있어 문 종류도 집마다 다릅니다. / 같은 현관문이라도 원인이 다르면 해법이 달라서 먼저 어떤 증상인지 구별하는 게 중요합니다.
이 글은 번호판 상태, 소리, 손잡이 느낌에 따라 원인을 나눠 정리했습니다. / 맞는 항목을 찾아 읽으시면 전화로 설명하기도 쉬워집니다.
@ 귀인동 현관문 안 열림 출장열쇠 원인 확인

# 증상 1, 번호판이 아예 꺼져 있다
버튼을 눌러도 불이 안 들어오면 대개 배터리가 다 된 경우입니다. / 오래 집을 비웠다 돌아온 날이나 경고음을 무시하고 지낸 뒤에 자주 생깁니다.
도어락 아래쪽 단자에 9V 건전지를 대 보면 잠깐 전원이 들어옵니다. / 그래도 반응이 없으면 전선이나 부품 문제일 수 있어 연락 주세요.

# 증상 2, 번호는 눌리는데 문이 안 풀린다
삑 소리는 나고 모터 소리도 나는데 걸쇠가 안 빠진다면 안쪽 걸림을 의심합니다. / 문이 문틀에 눌려 있으면 도어락 모터가 힘을 못 씁니다.
문을 살짝 밀거나 당기면서 번호를 눌러 보세요. / 이렇게 해서 열리면 문틀과 경첩 점검이 필요합니다.

# 증상 3, 경고음만 길게 난다
틀린 번호를 여러 번 누르면 입력이 잠시 막힙니다. / 이럴 땐 몇 분 기다렸다가 천천히 다시 눌러 보세요.
경고음이 짧게 반복되면 배터리 부족 신호인 경우도 많습니다. / 번호가 맞는데도 계속 소리만 나면 점검이 필요합니다.
@ 귀인동 도어락 경고음 번호판 점검

# 증상 4, 열쇠가 안 돌아가거나 안쪽에서 잠겼다
열쇠를 넣었는데 걸리거나 중간에 멈춘다면 억지로 돌리지 마세요. / 열쇠가 부러지면 일이 더 커집니다.
오래 쓴 열쇠는 닳았거나 잠금 장치 안에 먼지가 쌓였을 수 있습니다. / 이럴 땐 그대로 두고 전화 주시는 게 가장 안전합니다. / 윤활제를 급하게 뿌리는 분도 있는데 오히려 먼지가 엉겨 붙는 경우가 있어 권하지 않습니다.

안쪽 보조키나 걸쇠를 잠근 채 문을 닫고 나오는 일이 있습니다. / 이 경우 밖에서는 번호가 맞아도 열리지 않습니다.
집 안에 가족이 있는지 먼저 확인하세요. / 안에서 열어 줄 수 있으면 가장 빨리 해결됩니다. / 아이가 안에서 잠갔다면 놀라지 않게 문 너머로 계속 말을 걸어 주세요.

# 귀인동 오래된 집에서 자주 보는 원인
오래된 집은 문틀이 조금씩 처지거나 경첩이 헐거워져 문이 걸립니다. / 처음에는 가끔 뻑뻑하다가 어느 날 아예 안 열리게 됩니다.
그래서 문을 열고 나서 경첩과 문틀을 같이 보는 게 중요합니다. / 문이 닫힐 때 틀 모서리에 닿는 소리가 나면 이미 처짐이 시작된 신호입니다.
귀인동처럼 오래된 집이 섞인 곳은 계절이 바뀔 때 문이 더 뻑뻑해지기도 합니다. / 습기나 온도 때문에 문이 살짝 부풀거나 줄어드는 경우가 있습니다. / 도어락만 바꿔서는 해결되지 않는 경우가 꽤 있습니다.

# 전화로 알려주실 것
증상 번호와 함께 위치와 층, 도어락 모양을 말씀해 주세요. / 안에 아이나 반려동물이 있는지도 꼭 알려주세요.
- 위치와 호수
- 번호판 불이 들어오는지
- 어떤 소리가 나는지
- 열쇠를 사용했는지 여부
- 가족이 안에 있는지

# 사시는 분인지 확인합니다
도착하면 먼저 신분증 주소나 주소가 나온 우편물을 확인합니다. / 관리사무소 확인으로 대신할 수도 있습니다.
번거로우셔도 이웃과 우리 모두를 위한 절차입니다. / 서류가 안 챙겨졌다면 전화로 먼저 상황을 말씀해 주세요.

# 비용은 문 열기 전에 말씀드립니다
증상과 도어락 종류를 확인하고 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 말 없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적혀 있습니다.

# 최대한 안 상하게 엽니다
문 여는 방법이 여러 가지라 덜 상하는 것부터 차례로 해 봅니다. / 도어락과 문틀 외관을 지키는 게 먼저입니다. / 급하다고 아무 도구나 쓰지 않고 문 상태에 맞는 방법을 고릅니다.
[현관문 개문](door-open.html) 페이지에 방법을 설명해 두었습니다. / 작업 중 부품 교체가 필요해 보이면 손대기 전에 말씀드립니다.
@ 귀인동 24시 출장열쇠 현관문 개문 작업

# 열린 뒤에 확인하는 것
도어락이 다시 잘 잠기고 풀리는지 확인합니다. / 배터리가 원인이었으면 새것으로 전부 바꾸는 게 좋습니다.
문이 걸리는 증상이 있었다면 경첩과 문틀도 같이 봅니다. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드리고, 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 권합니다.

# 같은 일이 또 생기지 않게
배터리 교체 날짜를 도어락 안쪽에 적어 두세요. / 경고음이 나면 그날 바로 바꾸는 게 좋습니다.
- 번호는 가족과 같이 정하기
- 문이 뻑뻑하면 경첩 먼저 점검
- 보조키 잠금 습관은 나갈 때 한 번 더 확인
- 비상용 9V 건전지 하나 보관

# 귀인동 말고 안양 어디든
귀인동 옆 부흥동, 평촌동, 비산동, 호계동까지 24시간 다닙니다. / 안양 안이면 위치만 알려주세요.
[안양시 출장열쇠](anyang.html)에서 다니는 동네를 볼 수 있고 [출장 지역](area.html) 지도에서 다른 지역도 확인할 수 있습니다.
