# 집을 비운 사이 누가 들어와야 할 때
귀인동은 안양 중심가와 가까운 주택과 공동주택이 이어진 동네입니다. / 맞벌이 가정이나 어르신이 계신 집에서는 가사도우미나 돌봄 인력이 대신 집에 들어오는 일이 흔합니다.
이럴 때 가장 먼저 고민되는 것이 도어락 비밀번호를 어떻게 알려줘야 하는가입니다. / 가족이 쓰는 번호를 그대로 알려주면 나중에 일이 끝나도 계속 그 번호가 살아 있게 됩니다.
이 글은 귀인동에서 손님이나 외부 인력에게 도어락 번호를 알려줄 때 안전하게 쓰는 방법을 정리했습니다. / 번호 정리가 필요하면 [안양 출장열쇠](anyang.html)가 도와드립니다.
@ 귀인동 도어락 임시 비밀번호 설정 출장열쇠

# 가족 번호를 그대로 알려주면 생기는 일
가족이 매일 쓰는 번호를 알려주면 일이 끝난 뒤에도 그 번호로 문이 열립니다. / 도우미가 바뀌거나 계약이 끝나도 번호를 바꾸지 않으면 이전 사람이 계속 들어올 수 있습니다.
번호가 다른 사람에게 다시 전해지는 일도 생길 수 있습니다. / 누가 언제 들어왔는지 확인하기도 어렵습니다.
의심해서가 아니라 서로 편하기 위해서라도 번호를 구분해 두는 게 좋습니다. / 처음부터 방법을 정해 두면 나중에 서로 마음 쓸 일이 줄어듭니다.

# 도어락이 지원하는 방식부터 확인하세요
도어락마다 임시 번호를 만드는 방식이 다릅니다. / 사용 설명서나 도어락 안쪽 번호 설정 방법을 먼저 확인해 보세요.
- 번호를 여러 개 등록할 수 있는 제품
- 하루나 몇 번만 쓰고 사라지는 일회용 번호를 지원하는 제품
- 카드나 태그를 따로 발급해 줄 수 있는 제품
- 휴대폰 앱에서 기간을 정해 번호를 줄 수 있는 제품
어떤 기능이 있는지 모르시면 사진을 문자로 보내주세요. / 어떤 방법이 가능한지 먼저 알려드립니다.

# 번호 따로, 가족 번호 따로 쓰는 방법
가능하면 가사도우미나 손님에게는 가족과 다른 번호를 따로 등록해 주세요. / 이렇게 하면 일이 끝났을 때 그 번호만 지우면 됩니다.
번호를 등록할 수 있는 칸이 한 개뿐인 제품이라면 일이 끝날 때마다 번호를 바꿔 주세요. / 번호를 새로 정하고 가족에게 새 번호를 알려 주면 됩니다.
카드나 태그를 쓸 수 있다면 번호보다 카드로 주는 편이 더 간단할 때도 있습니다. / 카드를 돌려받거나 등록을 지우면 되니 관리가 쉽습니다.
@ 귀인동 도어락 번호 등록 관리

# 번호를 정할 때 피해야 할 것
생일, 전화번호 뒷자리, 같은 숫자 반복, 1234 같은 쉬운 번호는 피해 주세요. / 외우기 쉬운 번호는 다른 사람도 알아맞히기 쉽습니다.
가족 번호와 한두 자리만 다른 번호도 좋지 않습니다. / 완전히 다른 번호로 정하는 게 안전합니다.
번호를 메모해서 문 근처나 우편함 근처에 붙여 두지 않도록 해 주세요. / 이런 메모는 다른 사람 눈에 띄기 쉽습니다.

# 번호를 알려줄 때 지켜야 할 방법
번호는 문자나 메신저 대화로 보낼 때 그 대화방에 오래 남지 않게 정리하는 게 좋습니다. / 일이 끝나면 대화방에서 번호를 지우도록 부탁드려 보세요.
전화로 직접 불러주는 방법도 있습니다. / 이 경우 받는 사람이 번호를 적어 두는지 확인해 주세요.
가능하면 처음 만나는 날 집 앞에서 같이 번호를 눌러 보는 것을 권합니다. / 서로 확인하고 가야 나중에 안 열리는 일이 생기지 않습니다.

# 일이 끝나면 꼭 번호를 지우세요
도우미 계약이 끝났거나 손님이 돌아간 뒤에는 번호를 바로 정리해 주세요. / 일회용 번호가 아니라면 직접 지우거나 새 번호로 바꿔야 합니다.
- 계약 종료일에 번호 정리하는 날을 미리 정해 두기
- 정리했다는 사실을 가족이 같이 확인하기
- 번호를 지운 뒤 한 번 열려 보고 정상 작동하는지 확인하기
정리를 깜빡하는 일이 가장 많으니 달력에 적어 두면 좋습니다. / 작은 습관이지만 가장 효과가 큰 방어입니다.

# 이런 상황에서 출장열쇠를 부르세요
번호를 등록하는 방법을 모르겠거나 도어락이 지원하는지 확신이 없을 때가 있습니다. / 비밀번호를 바꿨더니 가족이 못 들어오는 일도 생길 수 있습니다.
등록한 번호가 안 먹히거나 일회용 번호 설정 후 도어락이 이상하게 반응할 때도 연락 주세요. / 이런 경우는 안에서 설정을 정리해 드립니다.
번호를 초기화해야 하거나 가족 번호를 전부 새로 정하고 싶을 때도 도와드립니다. / 자세한 방식은 [도어락 수리](doorlock-repair.html) 페이지에도 정리해 두었습니다.

# 출장열쇠가 오면 이렇게 진행됩니다
전화로 도어락 모양과 번호판 상태를 간단히 말씀해 주세요. / 사진을 같이 보내주시면 맞는 방법을 미리 준비해 갑니다.
도착하면 도어락 설정 방식을 확인하고 번호 정리 방법을 설명드립니다. / 번호를 지우고 새로 등록하는 과정은 보시는 앞에서 진행합니다.
번호를 모르는 상태에서 문이 잠겨 있다면 먼저 문 개방이 필요합니다. / 이때는 [현관문 개문](door-open.html) 순서에 따라 덜 상하는 방법부터 해봅니다.

# 사시는 분인지 확인하는 절차
문을 여는 일이라 도착하면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번호 정리만 하는 경우에도 집 안 도어락 설정을 만지는 일이라 같은 확인을 합니다. / 번거로우실 수 있지만 안전을 위한 절차입니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다. / 이웃과 가족 모두를 위한 절차입니다.

# 비용은 시작하기 전에 먼저 말씀드립니다
도어락 종류와 작업 내용을 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 작업이 끝난 뒤에 말없이 붙는 비용도 없습니다.
부품 교체가 필요한 경우 하기 전에 따로 여쭤봅니다. / 도어락 자체를 바꾸는 것이 나을 때만 [도어락 교체](doorlock-replace.html) 안내를 드립니다.
@ 귀인동 출장열쇠 도어락 번호 정리

# 돌봄 인력이 오는 집이라면 더 신경 쓸 것
어르신이나 아이를 돌보는 인력이 매일 드나드는 집은 번호를 다루는 방식이 더 중요합니다. / 집 안 귀중품은 보관 장소를 따로 정해 두는 편이 안전합니다.
같은 건물 이웃에게 누가 드나드는지 미리 알려 두면 서로 안심이 됩니다. / 갑자기 모르는 사람이 들어간다고 오해받지 않게 하는 방법입니다.
도어락에서 기록을 확인할 수 있는 기능이 있으면 활용해 보세요. / 없더라도 일이 끝났을 때 가족이 확인하는 습관이 도움이 됩니다.

# 귀인동 말고 안양 어디든 갑니다
귀인동 바로 옆 평촌동, 관양동, 호계동, 비산동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
안양에서 다니는 동네는 [안양 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
진행 방식이 궁금하시면 [이용안내](guide.html)를 읽어 보세요. / 처음 부르시는 분도 부담 없이 보실 수 있게 적어 두었습니다.
