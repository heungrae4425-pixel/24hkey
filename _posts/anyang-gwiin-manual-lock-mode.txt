# 번호가 맞는데 문이 반응하지 않을 때
번호판에 불이 들어오는데도 문이 안 열리면 더욱 헷갈립니다. / 배터리가 문제라면 불도 안 들어오는 경우가 많기 때문입니다.
귀인동은 평촌역과 안양역 사이를 오가는 분들이 많은 동네입니다. / 퇴근길에 번호를 정확히 눌렀는데도 문이 꿈쩍하지 않으면 고장이라고 생각하기 쉽습니다.
그런데 의외로 고장이 아니라 잠금 모드가 켜져 있어서 생기는 경우가 있습니다. / 이 글은 수동 잠금 모드가 무엇인지, 어떻게 확인하고 풀어 보는지 적었습니다.
문 앞에서 이미 오래 서 계시다면 [귀인동 출장열쇠](anyang.html) 안내도 같이 보세요.
@ 귀인동 도어락 잠금 모드 확인

# 수동 잠금 모드란
어떤 제품은 한 번 누르면 켜지고 다시 누르면 꺼지는 방식이고, 어떤 제품은 레버를 돌려 걸어 두는 방식입니다. / 두 방식 모두 밖에서는 확인하기 어렵다는 점이 공통입니다.
그래서 문 앞에서는 고장처럼 느껴지지만, 안쪽 사정을 알면 간단히 풀리는 일도 많습니다.
도어락에는 밖에서 번호나 카드를 받지 않도록 막는 기능이 있는 제품이 많습니다. / 이름은 제품마다 다르게 부르지만 안쪽 스위치나 버튼으로 켜고 끄는 방식이 흔합니다.
집 안에서 쉬거나 잠들 때 외부 입력을 막으려는 목적입니다. / 그래서 안에 있던 분이 켜 두고 나갔다면 밖에서는 열리지 않게 됩니다.

# 이런 순간에 모드가 켜집니다
특히 아이가 있는 집에서는 안쪽 손잡이 옆에 반짝이는 버튼이 있으면 눌러 보고 싶어 합니다. / 놀다가 눌러 놓고 잊어버리는 일이 흔합니다.
밤에 가족이 잠자기 전에 켜 두고 아침에 다른 가족이 먼저 나가면 밖에서 열리지 않는 일도 생깁니다.
- 안쪽 손잡이 근처 버튼을 아이가 눌렀을 때
- 잠금 레버를 돌려 놓은 채 문을 닫고 나왔을 때
- 청소나 정리 중 스위치를 스친 경우
- 가족 누군가 잠자기 전에 켜 두고 풀지 않은 경우
집에 아이나 반려동물이 있으면 한 번쯤 생기는 일입니다.

# 밖에서 구분하는 단서
소리와 불빛이 평소와 같은데 열리지 않는다면 번호가 틀린 것이 아니라 입력을 받지 않는 상태라는 뜻입니다. / 이 차이를 알면 불필요하게 번호를 계속 누르지 않게 됩니다.
번호판이 켜지는데 번호를 눌러도 열리는 소리가 없다면 모드 가능성을 보아야 합니다. / 완전히 꺼져 있다면 배터리 쪽이 먼저입니다.
- 번호를 누르면 평소와 다른 소리가 나는지
- 불빛 색이 평소와 다른지
- 카드나 지문도 똑같이 막히는지
입력 방식 모두가 막히면 모드 쪽을 의심할 근거가 됩니다.
@ 귀인동 번호판 반응과 불빛 확인

# 안에 사람이 있다면
안에 있는 분이 아이라면 차분하게 말해 주세요. / "손잡이 옆 작은 버튼을 한 번만 눌러 줄래"처럼 한 가지씩 부탁하면 됩니다.
문 너머로 계속 말을 걸어 주시면 아이도 불안해하지 않습니다.
집 안에 가족이 있다면 가장 쉽게 해결됩니다. / 전화로 안쪽 스위치나 레버 위치를 살펴보라고 부탁하세요.
안쪽에서 레버를 돌리거나 버튼을 한 번 더 누르면 풀리는 제품이 많습니다. / 말로 설명이 어려우면 영상통화로 보여 주며 같이 확인하는 방법도 있습니다.

# 아무도 없을 때 해볼 수 있는 것
가능하면 잠시 숨을 고르고 처음부터 차근차근 되짚어 보세요. / 외출 전에 안쪽 스위치를 만졌는지 기억을 떠올려 보는 것만으로도 단서가 됩니다.
같이 사는 가족이나 룸메이트에게 메시지를 남겨 두는 것도 방법입니다. / 답이 오면 안쪽 상태를 사진으로 받아 보세요.
모드는 안쪽에서 풀어야 하는 경우가 대부분이라 밖에서 할 수 있는 일은 많지 않습니다. / 다만 열쇠가 있으면 열쇠 구멍으로 열리는 제품도 있어 먼저 시도해 볼 만합니다.
보조키가 따로 있는 집은 보조키가 잠겨 있지 않은지 같이 보세요. / 열쇠구멍이 숨은 덮개 안쪽에 있는 제품도 있으니 덮개가 움직이는지 살펴보세요.

# 여러 번 눌러 보는 일은 피하세요
모드가 켜진 상태에서는 번호가 맞아도 입력 기록만 쌓이고 열리지 않습니다. / 시도 횟수만 늘면 문 앞에서 시간만 흘러갑니다.
안 열린다고 번호를 계속 반복해 누르면 오류 차단까지 겹쳐 더 막막해집니다. / 서너 번 해 보고 안 되면 멈추는 쪽이 안전합니다.
문을 흔들거나 손잡이를 세게 당기는 것도 피해 주세요. / 모드 문제는 힘으로 풀리지 않고 걸쇠만 상하게 합니다.

# 전화할 때 이 세 가지만 알려주세요
안쪽 스위치 모양을 모르겠다면 가족에게 사진을 부탁해서 보내 주셔도 됩니다. / 그 사진 한 장이 방법을 정하는 데 큰 도움이 됩니다.
- 도어락 앞면의 모양과 표시등 상태
- 집 안에 사람이 있는지, 아이나 반려동물이 있는지
- 최근에 문 쪽을 만진 사람이 있었는지
사진을 한 장 보내 주시면 맞는 방법을 미리 준비하기 좋습니다. / 문 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 도착 후 사시는 분인지 확인합니다
문을 여는 작업이라 신분증, 주소가 적힌 우편물, 관리사무소 확인 중 하나가 필요합니다. / 귀가가 늦어 신분증을 집 안에 두었다면 관리사무소나 경비실에 먼저 확인을 요청해 보세요.
번거롭지만 모두를 위한 절차입니다.
@ 귀인동 출장열쇠 신분 확인 안내

# 비용은 문 열기 전에 말씀드립니다
상태를 본 뒤 비용부터 먼저 알려드리고, 괜찮다고 하시면 시작합니다. / 끝내 열지 못하면 비용은 받지 않습니다.
부품을 바꿔야 할 때도 바꾸기 전에 따로 여쭙니다. / 자세한 진행 방식은 [이용안내](guide.html)에 있습니다.

# 해제한 뒤 같이 확인하는 것
안쪽에서 눌렀을 때 켜졌다는 표시가 분명히 나오는지도 같이 봅니다. / 표시가 흐릿하면 알아채기 어려워 같은 일이 되풀이될 수 있습니다.
필요하면 가족이 쉽게 알 수 있도록 안쪽 스위치 옆에 작은 표시를 해 두시는 방법도 있습니다. / 표시는 도어락 본체를 상하지 않는 스티커 정도가 좋습니다.
모드를 풀고 나면 번호, 카드, 열쇠 모두 다시 되는지 하나씩 눌러 봅니다. / 스위치가 너무 가볍게 눌리는 제품이면 설정 방법도 같이 설명드립니다.
스위치가 헐겁거나 레버가 제대로 안 돌아간다면 [도어락 수리](doorlock-repair.html)로 손볼 수 있습니다. / 버튼 자체가 잘못 눌리는 구조라면 [도어락 교체](doorlock-replace.html)를 권해 드릴 때도 있습니다.

# 가족이 같이 알아 두면 좋은 것
명절이나 손님이 오는 날에는 평소 안 만지던 스위치를 누르는 일이 늘어납니다. / 그런 날은 외출 전 한 번 더 확인하는 습관이 도움이 됩니다.
- 안쪽 잠금 스위치가 어떤 모양인지
- 켜 두고 나가면 밖에서 안 열린다는 사실
- 아이가 만지기 쉬운 높이인지 여부
- 모드 해제 방법을 메모로 붙여 두기
작은 안내문 하나가 문 앞에서 서성이는 일을 줄여 줍니다.

# 마무리
번호를 아는데도 열리지 않는 답답함은 의외로 작은 스위치 하나에서 시작되는 일이 많습니다. / 차분히 순서대로 확인하면 대부분 풀립니다.
귀인동에서 번호가 맞는데 문이 안 열린다면 고장보다 잠금 모드가 켜져 있는지 먼저 떠올려 보세요. / 안에 사람이 있으면 안쪽에서 풀어 달라고 하시면 됩니다.
