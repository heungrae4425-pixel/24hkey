# 비 오는 날 문이 잠기면 마음이 더 급해집니다
귀인동은 범계역과 안양역 사이를 오가며 생활하는 분들이 많은 동네입니다. / 우산 없이 나왔다가 비를 맞고 집 앞에 도착했는데 문이 안 열리면 몸도 마음도 힘들어집니다.
비 오는 날은 도착하는 사람도, 기다리는 사람도 평소보다 조심해야 하는 날입니다. / 이 글은 귀인동에서 비 오는 날 [안양 출장열쇠](anyang.html)를 부를 때 미리 준비하면 좋은 것들을 정리한 것입니다.
기다리는 동안의 안전과 도착 후 진행이 매끄러워지도록 순서대로 적었습니다.
비가 오는 날은 어두워지는 시간도 빨라서 골목이 평소보다 낯설게 느껴집니다. / 혼자 계신다면 더욱 밝고 사람이 오가는 곳에서 기다리시길 권합니다.
@ 귀인동 빗속에서 현관 앞에 서 있는 모습

# 기다릴 곳부터 정하세요
문 앞에 계속 서 있으면 비를 맞고 몸이 식어 감기에 걸리기 쉽습니다. / 가까운 건물 입구, 1층 복도, 상가 처마 아래처럼 비를 피할 곳을 먼저 정해 주세요.
단, 위치는 너무 멀지 않게 하고 출장 기사에게 어디서 기다리는지 알려 주세요. / 이웃집이 아는 사이라면 잠깐 양해를 구하는 것도 방법입니다.
낯선 곳에서 오래 기다려야 할 때는 가족이나 친구에게 지금 위치를 알려 두는 것도 안전에 도움이 됩니다. / 출장 기사가 도착하면 전화로 먼저 연락드리니 주변에서 기다려 주세요.

# 연락할 때는 위치를 정확하게
비 오는 날은 간판과 길이 평소와 다르게 보이고, 기사 입장에서도 찾기 어렵습니다. / 아래 내용을 알려 주시면 도착이 훨씬 빨라집니다.
- 귀인동 어느 쪽인지 (큰길 방향, 가까운 역 쪽, 건물 모양)
- 건물 형태와 층, 호수
- 기다리는 위치 (예: 1층 현관 안쪽)
- 도어락 모양과 번호판 상태
- 연락이 잘 되는 휴대폰 번호
건물 이름이 불분명하면 길 건너 눈에 띄는 표지를 말씀해 주셔도 됩니다.

# 휴대폰 배터리와 우산도 확인
비 오는 날 문이 안 열려 허둥대다 보면 휴대폰 배터리가 얼마 안 남은 경우가 있습니다. / 통화 중에 꺼지지 않도록 가능한 한 가까운 곳에서 충전하거나 아끼며 연락해 주세요.
우산이 없으면 잠깐 근처 편의점이나 상가에서 구하는 것도 괜찮습니다.
젖은 서류나 신분증은 글자가 번질 수 있으니 비닐에 한 번 감싸 두세요. / 휴대폰도 방수 파우치가 없다면 옷 안쪽 주머니에 넣어 두는 편이 안전합니다. / 몸이 젖은 채 오래 기다리지 않는 게 무엇보다 중요합니다.

# 도어락이 젖었다면 먼저 닦기
번호판이 비에 젖어 반응이 느리거나 안 눌린다면 마른 수건으로 물기를 닦고 잠시 기다려 보세요. / 젖은 상태로 번호를 계속 누르면 입력이 막히는 경우가 있습니다.
비를 가려 줄 우산이나 큰 비닐을 번호판 위에 씌워 두는 것도 도움이 됩니다. / 전원 단자에 건전지를 대는 것은 물기가 완전히 마른 뒤에만 시도해 주세요.
@ 우산으로 도어락 번호판을 가려 둔 모습

# 비 오는 날 출장이 평소보다 걸릴 수 있는 이유
도로 사정과 이동 시간이 평소와 다를 수 있어 도착 예상 시간은 연락 시 먼저 알려드립니다. / 도착 시간이 길어질 것 같으면 대신 기다리는 동안 할 수 있는 일을 안내해 드립니다.
집 안에 아이나 반려동물이 있는 급한 상황이면 꼭 먼저 말씀해 주세요. / 급한 정도에 따라 안내와 진행 방식이 달라집니다.

# 안전하게 작업하기 위해 하는 일
빗물이 문틀과 도어락 안으로 들어가지 않도록 작업 중에는 우산이나 덮개를 씌우고 진행합니다. / 젖은 손으로 만지면 부품이 상할 수 있어 물기를 닦고 장비를 사용합니다.
복도나 계단이 미끄러울 수 있으니 이동할 때 장비와 신발 바닥을 먼저 닦습니다. / 작업 공간이 어두우면 조명을 쓰고 안전하게 진행합니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지부터 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 비 오는 날 서류가 젖지 않게 비닐 등에 담아 챙겨 두면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙고, 진행 방식은 [이용안내](guide.html)에 있습니다.

# 최대한 상하지 않게 엽니다
문 여는 방법은 여러 가지가 있고 덜 상하는 방법부터 차례로 시도합니다. / 비로 문틀이 불어 있거나 팽창해 있다면 그 상태도 같이 봅니다.
방법이 정해지면 중간에 바뀌는 사항은 그때그때 말씀드립니다. / 자세한 방식은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.
@ 비 오는 날 현관문 작업 중인 모습

# 열린 뒤에는 물기를 먼저 정리합니다
집 안으로 들어서면 현관 바닥의 빗물도 바로 닦아 두세요. / 젖은 우산을 문 가까이 두면 문틀 아래로 물이 스며들 수 있습니다.
문이 열리면 도어락 번호판과 건전지 칸에 물이 들어갔는지 확인합니다. / 젖은 부분은 닦고 필요하면 건전지를 새것으로 바꿉니다.
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 해결하고, 오래돼 물이 자주 스며들면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
집 안으로 들어가시면 젖은 옷은 바로 갈아입으셔야 몸이 덜 상합니다.

# 비 오는 날을 대비해 두면 좋은 것
비 오는 날의 잠김은 미리 준비하면 절반은 해결됩니다. / 특별한 도구가 필요한 일은 없고 습관 몇 가지면 충분합니다.
문 앞에서 허둥대다 휴대폰이나 서류를 떨어뜨려 젖는 일도 흔하니 가방 속 정리를 평소에 해 두는 것도 좋습니다. / 가족에게 출장열쇠 번호를 공유해 두면 혼자 연락이 어려울 때도 도움이 됩니다.
- 가방에 접이식 우산이나 가벼운 우의 넣어 두기
- 비상용 9V 건전지 하나를 따로 보관
- 번호판 위에 짧은 가림판이나 차양 설치 고려
- 출장열쇠 번호를 휴대폰에 저장해 두기
- 도어락 건전지 교체 날짜를 적어 두기
미리 준비해 두면 비 오는 날에도 문 앞에서 당황하는 일이 줄어듭니다.

# 귀인동 말고 안양 어디든 갑니다
귀인동 가까이 평촌동, 호계동, 부흥동, 안양동, 석수동도 다닙니다. / 안양 안이면 어느 동네든 24시간 출동합니다.
다니는 곳은 [안양시 출장열쇠](anyang.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.

? 세입자도 요청할 수 있나요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.

# 마무리
비 오는 날일수록 서두르다 다치지 않는 것이 가장 중요합니다. / 천천히 안전하게, 필요한 정보만 전달해 주시면 나머지는 저희가 챙기겠습니다.
귀인동 어디든 위치만 정확하다면 빗길에도 찾아갑니다. / 연락이 닿는 번호를 꼭 확인해 두세요.
귀인동에서 비 오는 날 문이 잠겼다면 비 피할 곳부터 정하고 위치를 정확히 알려 주세요. / 나머지는 상황을 듣고 가능한 한 빠르고 안전하게 진행하겠습니다.
