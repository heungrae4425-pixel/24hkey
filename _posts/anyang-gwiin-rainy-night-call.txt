# 비가 오는 밤에는 문 앞이 더 막막합니다
귀인동은 범계역과 평촌역을 오가며 퇴근하는 분들이 많은 생활권입니다. / 비 오는 밤 우산을 접고 집 앞에 섰는데 문이 안 열리면 평소보다 훨씬 춥고 난감합니다.
젖은 손으로 번호판을 누르니 반응이 둔하고, 가방은 젖고, 휴대폰 배터리도 얼마 안 남은 때가 많습니다. / 이럴 때 전화를 어떻게 하느냐에 따라 기다리는 시간이 꽤 달라집니다.
이 글은 비 오는 밤 귀인동에서 출장열쇠를 부를 때 알려두면 좋은 것과 기다리는 동안 할 일을 정리했습니다. / 문 앞에 서 계시다면 3번부터 보셔도 됩니다.
@ 귀인동 비 오는 밤 출장열쇠 요청

# 먼저 몸부터 안전한 곳으로
문이 안 열리는 것도 문제지만 비를 맞고 오래 서 있는 것은 더 문제입니다. / 급한 마음에 문 앞에서 버티지 말고 비를 피할 수 있는 곳으로 먼저 이동하세요.
공동 현관 안쪽이나 1층 입구, 건물 처마 아래처럼 마른 곳이 좋습니다. / 휴대폰은 젖지 않게 주머니에 넣고 통화할 때만 꺼내 쓰세요.
빌라나 주택이라면 가까운 편의점이나 카페 같은 열린 곳에서 통화하는 것도 방법입니다. / 도착 시간을 안내받은 뒤 시간에 맞춰 돌아와도 늦지 않습니다.

# 번호판이 젖어서 안 눌리는 것일 수도 있습니다
비가 오는 날에는 번호판이나 손끝에 물기가 있어 반응이 달라지기도 합니다. / 이런 경우 고장이 아닐 수 있으니 무작정 불안해하지 마세요.
마른 손수건이나 옷 안쪽으로 번호판과 손끝을 닦고 잠시 뒤 다시 눌러 보세요. / 한 번에 되지 않더라도 서너 번 이상 반복해서 틀린 번호를 누르면 입력이 잠기니 거기서 멈추는 게 좋습니다.
소리가 평소와 다르거나 번호판이 아예 꺼져 있으면 배터리를 의심하세요. / 9V 건전지를 비상 단자에 대 보는 방법은 [도어락 배터리 안내](guide.html)에서도 같이 봅니다.

# 전화로 가장 먼저 말씀해 주실 것
전화를 받으면 인사 다음에 아래 순서로 말씀해 주시면 빠릅니다. / 모든 걸 한꺼번에 설명하려 하지 말고 핵심부터 말씀하세요.
- 지금 서 있는 정확한 위치와 건물 이름 또는 번지
- 몇 동 몇 호인지, 공동 현관은 들어올 수 있는지
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집 안에 사람이나 반려동물이 있는지
위치는 지도 앱에서 현재 위치를 문자로 보내시면 가장 정확합니다. / 비 오는 밤은 길이 막히거나 어두워 주소만으로 찾기 어려운 곳이 많습니다.
@ 귀인동 도어락 상태 설명과 위치 공유

# 공동 현관이 잠겨 있으면 미리 알려주세요
비 오는 밤에는 건물 입구 자체가 잠겨 있어 못 들어가는 경우도 있습니다. / 공동 현관 비밀번호를 모르면 들어가기 전부터 막힙니다.
경비실이나 관리사무소가 있다면 먼저 사정을 말해 두면 훨씬 수월합니다. / 늦은 시간이면 경비 근무자에게 출장열쇠가 올 것을 미리 알려주세요.
빌라처럼 공동 현관 비밀번호가 있는 경우는 도착 전에 번호를 알려주셔야 합니다. / 이웃에게 부탁해 문을 열어 달라고 하는 방법도 있습니다.

# 집 안에 사람이나 반려동물이 있을 때
집 안에 아이나 노약자, 반려동물이 있다면 바로 말씀해 주세요. / 비 오는 밤 혼자 남겨진 가족이 걱정되는 것은 당연합니다. / 이런 경우는 순서를 앞당겨 서둘러 이동합니다.
문 너머로 말을 걸어 안심시키되 안에서 위험한 행동을 하지 않게 안내하세요. / 불이나 가스 불이 켜져 있다면 그 사실도 꼭 알려주셔야 합니다.
위급해 보이는 상황이면 119에 먼저 연락하는 것이 우선입니다. / 출장열쇠는 그다음 보조로 부르는 것이 안전합니다.

# 신분 확인 서류는 젖지 않게 준비
문을 열기 전에 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
비 오는 날 신분증을 지갑에서 꺼내다 젖을 수 있으니 미리 비닐이나 지퍼백에 넣어 두세요. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.
밤이라 관리사무소가 닫혀 있으면 경비실에 먼저 물어보세요. / 확인이 어려우면 작업을 할 수 없으니 방법을 미리 정해 두면 좋습니다.

# 기다리는 동안 하지 말아야 할 것
오래 기다리다 보면 직접 열어 보고 싶은 마음이 듭니다. / 하지만 손잡이를 세게 당기거나 문틈에 도구를 넣으면 문과 도어락이 상합니다.
발로 차거나 어깨로 밀면 문틀이 휘어 일이 더 커질 수 있습니다. / 기다리는 동안은 그냥 두는 편이 작업이 훨씬 수월합니다.
번호를 이것저것 마구 눌러 보는 것도 피하세요. / 여러 번 틀리면 입력이 한동안 막혀 확인이 더 어려워집니다.

# 도착하면 이렇게 진행됩니다
도착하면 먼저 문과 도어락을 살펴보고 상태를 확인합니다. / 어떤 방법으로 열지, 비용은 얼마가 될지를 문 열기 전에 먼저 말씀드립니다.
괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
비 오는 날은 바닥이 젖어 있어 문 앞에 장비를 놓을 때도 조심합니다. / 현관 바닥이 젖지 않게 신경 쓰는 것도 작업의 일부입니다. / 열고 닫는 과정은 [현관문 개문](door-open.html)에 자세히 있습니다.
@ 귀인동 현관문 개방 작업 모습

# 우산과 짐 때문에 생기는 실수들
비 오는 날은 양손이 우산과 짐으로 가득해 열쇠를 어디에 뒀는지 놓치기 쉽습니다. / 가방 바닥에 떨어져 있는 열쇠를 못 찾고 잠긴 줄 알고 전화하는 경우도 있습니다.
전화하기 전에 가방과 주머니, 겉옷 안쪽을 한 번씩 천천히 확인해 보세요. / 우산을 접어 세워 두고 짐을 내려놓은 다음에 찾으면 훨씬 빨리 나옵니다.
택배나 장본 물건을 문 앞에 두고 열쇠를 찾다가 문이 닫혀 버리는 경우도 있습니다. / 이런 때는 자동으로 잠기는 도어락이면 번호 없이는 다시 들어갈 수 없다는 점을 기억하세요.

# 열린 뒤에는 원인부터 확인
문이 열리면 배터리, 번호, 문틀 순서로 원인을 같이 봅니다. / 비 때문에 번호판에 물이 스며든 경우라면 건조가 필요할 수 있습니다.
같은 일이 반복되지 않게 [도어락 수리](doorlock-repair.html)가 필요한지도 판단해 드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
비 오는 날 문 앞에서 오래 서 있지 않으려면 평소에 비상 수단을 마련해 두는 게 좋습니다.

# 비 오는 날을 대비한 평소 준비
미리 해 두면 비 오는 날 부담이 많이 줄어듭니다. / 작은 준비지만 막상 닥쳤을 때 큰 차이를 만듭니다.
- 휴대폰에 24시출장열쇠 번호를 저장해 두기
- 우산 속이나 가방에 9V 건전지 하나 넣어 두기
- 번호판 주변에 물이 고이지 않는지 점검하기
- 가까운 이웃이나 가족에게 예비 열쇠 맡기기

# 귀인동 말고 안양 어디든 갑니다
귀인동 옆 평촌동, 부흥동, 비산동, 호계동, 관양동도 다닙니다. / 안양 안이면 비 오는 밤이라도 24시간 출동합니다.
동네별 안내는 [안양시 출장열쇠](anyang.html) 페이지에, 다른 지역은 [출장 지역](area.html) 지도에 있습니다.

# 자주 묻는 질문
? 비 오는 밤에도 출동하나요? | 네, 24시간 출동합니다. 날씨와 시간에 상관없이 전화 주세요.
? 기다리는 동안 무엇을 하면 되나요? | 비를 피할 수 있는 마른 곳에서 대기하시고 위치를 문자로 보내 주세요.
? 신분증이 집 안에 있으면요? | 주소가 나온 우편물이나 관리사무소 확인으로 대신할 수 있습니다.
? 비용은 언제 알려주나요? | 문 열기 전에 먼저 말씀드립니다.
? 못 열면 비용을 내나요? | 끝내 못 열면 비용은 받지 않습니다.

# 마무리
비 오는 밤에는 몸을 먼저 피하고, 위치와 상황을 짧게 정리해 전화하는 것이 가장 빠른 길입니다. / 억지로 문을 열려고 하지 않는 것도 중요합니다.
24시출장열쇠는 귀인동을 비롯한 안양 전 지역에서 24시간 전화를 받습니다. / 서울, 경기 전 지역, 전화 010-3664-5455로 연락 주세요.
@ 귀인동 24시 출장열쇠 010-3664-5455
