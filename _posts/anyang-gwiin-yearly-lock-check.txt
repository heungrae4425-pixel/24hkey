# 귀인동에서 도어락을 일 년에 한 번 보자는 이야기
귀인동은 평촌역과 안양역 생활권 사이에서 주택과 아파트, 빌라가 어우러진 동네입니다. / 오래 사신 집도 있고 최근에 이사 온 집도 있어서 도어락 나이가 제각각입니다.
도어락은 매일 쓰는데도 고장 나기 전에는 들여다보지 않는 물건입니다. / 그러다 어느 날 번호판이 꺼진 채 문 앞에서 막히는 일이 생깁니다.
이 글은 일 년에 한 번, 날을 정해 도어락을 살펴볼 수 있는 점검표입니다. / 따라 하는 데 20분이면 충분하게 순서대로 적었습니다.
@ 귀인동 도어락 연 1회 점검표 확인

# 점검하는 날을 하나 정해 두세요
점검은 기억하기 쉬운 날에 하는 것이 좋습니다. / 해가 바뀌는 연말이나 이사 온 날, 보일러 점검하는 날과 묶어 두면 잊지 않습니다.
달력에 일 년에 한 번 반복 일정으로 넣어 두면 됩니다. / 배터리 칸에 교체한 날짜를 적어 두면 다음 점검 때 비교하기 쉽습니다.

# 1단계 배터리부터 전부 새것으로
점검표의 첫 줄은 배터리입니다. / 전지가 아직 남아 있어도 점검 때 한꺼번에 새것으로 바꾸는 것이 가장 속 편한 방법입니다.
- 건전지는 종류를 섞지 않고 같은 제품으로 전부 교체
- 건전지 접점이 하얗게 부식되지 않았는지 확인
- 덮개를 닫을 때 헐겁지 않은지 확인
저가 건전지를 쓰면 도중에 전압이 떨어져 번호판이 깜빡이기도 합니다. / 도어락에는 믿을 만한 제품을 쓰는 편이 마음 편합니다.

# 2단계 번호판과 버튼을 눌러 봅니다
번호판의 모든 숫자를 하나씩 눌러 보고 소리와 불이 제대로 들어오는지 봅니다. / 특정 숫자만 반응이 느리다면 그 부분에 먼지나 습기가 쌓인 것일 수 있습니다.
번호판 틈에 쌓인 먼지는 마른 솔이나 부드러운 천으로 털어 냅니다. / 겨울을 지나고 나면 특히 먼지와 물기가 섞여 끼기 쉽습니다.
마른 천으로 가볍게 닦되 물이나 알코올을 번호판에 직접 뿌리지 마세요. / 틈으로 들어간 물기가 기판을 상하게 할 수 있습니다.
자주 쓰는 숫자 버튼만 닳아 있으면 번호 노출이 쉬워집니다. / 오래 쓴 번호는 이 기회에 바꾸는 것도 방법입니다.

# 3단계 문을 열고 닫으며 걸쇠를 봅니다
문을 열어 둔 채 옆면의 걸쇠와 데드볼트를 눈으로 살펴봅니다. / 걸쇠가 부드럽게 들어갔다 나오는지, 번호를 눌러 열 때 데드볼트가 끝까지 들어가는지 확인합니다.
문틀 받침판 구멍에 닿은 자국이 한쪽으로 치우쳐 있으면 문이 처졌다는 신호입니다. / 이런 징후는 일찍 발견할수록 간단히 손볼 수 있습니다.
@ 문 옆면 걸쇠와 데드볼트 움직임 점검

# 4단계 열쇠 구멍과 비상 열쇠도 확인합니다
번호만 쓰다 보면 열쇠 구멍은 몇 년 동안 쓰지 않게 됩니다. / 막상 비상 때 열쇠가 안 돌아가면 가장 곤란한 순간에 막힙니다.
- 비상 열쇠가 어디에 있는지
- 열쇠가 실제로 돌아가는지(문이 열려 있을 때 시험)
- 열쇠 구멍에 먼지나 이물질이 끼지 않았는지
비상 열쇠는 도어락 안쪽에 두지 말고 집 밖 믿을 만한 곳이나 가족에게 한 벌 나눠 두세요. / 문 안에 두고 잠기면 열쇠가 있어도 쓸 수 없습니다.
열쇠가 뻑뻑하면 힘으로 돌리지 마세요. / 부러지면 일이 커지니 점검을 받는 쪽이 낫습니다.

# 5단계 문틀과 경첩, 문이 닫히는 높이
도어락이 멀쩡해도 문이 처지면 같은 증상이 나옵니다. / 문을 반쯤 열어 두었다가 놓았을 때 저절로 닫히는 속도가 일정한지 봅니다.
문 윗부분 모서리가 문틀에 스치거나 닫을 때 소리가 커졌다면 경첩 나사가 풀렸을 수 있습니다. / 나사만 조여도 좋아지는 경우가 많습니다.
조여도 계속 스치거나 문이 눈에 띄게 기울어 있다면 경첩 자체가 문제일 수 있습니다. / 이럴 때는 도어락보다 문 쪽을 먼저 보아야 하니 사진을 찍어 두세요.

# 6단계 등록된 번호와 카드를 정리합니다
점검하는 날 현재 등록된 번호와 카드를 같이 살펴보세요. / 이사 간 사람, 일을 그만둔 도우미, 이제 안 쓰는 카드가 그대로 남아 있을 수 있습니다.
가족 모두의 카드가 어디 있는지 확인하는 것도 이때 하면 좋습니다. / 한 장이 비면 바로 삭제하고 새로 등록하는 것이 안전합니다.
번호도 일 년에 한 번쯤은 새로 정하는 것이 좋습니다. / 오래 같은 번호를 쓰면 지문처럼 자주 누르는 숫자가 닳아 번호가 짐작되기도 합니다.

# 점검표를 한 장으로 정리하면
위 순서를 한 번에 볼 수 있게 줄여 보면 다음과 같습니다. / 휴대폰 메모에 붙여 두고 해마다 같은 날 체크해 보세요.
- 배터리 전부 교체, 접점 상태 확인
- 번호판 버튼 전체 눌러 보기, 표면 닦기
- 걸쇠와 데드볼트 동작 확인
- 비상 열쇠 시험
- 문틀과 경첩 나사 확인
- 번호와 카드 정리
각 줄에 날짜를 적어 두면 어느 해에 무엇을 했는지 알 수 있습니다.
점검표를 현관 안쪽 신발장 문에 붙여 두는 집도 있습니다. / 가족이 같이 보고 함께 챙길 수 있어 한 사람에게만 맡기지 않아도 됩니다.
전부 하기 부담스럽다면 배터리와 걸쇠 두 가지만이라도 해마다 챙기세요. / 이 둘만 지켜도 문 앞에서 당황하는 일이 많이 줄어듭니다.

# 점검하다 이상을 발견했을 때
작동이 느리거나 소리가 평소와 다르다면 억지로 쓰지 말고 상태를 메모해 두세요. / 어떤 증상이 언제부터 생겼는지가 원인을 찾는 가장 중요한 단서입니다.
귀인동에서 직접 보기 어려운 상태면 [안양 출장열쇠](anyang.html)에 사진과 함께 알려 주세요. / 문이 아직 열리는 상태라면 서두르지 않고 점검만 받을 수도 있습니다.
점검 결과 고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 손보고, 너무 오래된 제품일 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 점검 중에 문이 잠겨 버렸다면
점검하다 문이 닫히면서 번호판이 먹통이 되는 경우도 드물게 있습니다. / 배터리를 빼 놓은 채 문이 닫히면 번호판에 전원이 없어 열 수 없습니다.
이럴 때는 도어락 아래쪽 단자에 9V 건전지를 대 보세요. / 단자가 없거나 반응이 없으면 [현관문 개문](door-open.html)으로 연락 주세요.
@ 출장열쇠가 닫힌 현관문 도어락을 확인하는 모습

# 도착하면 신분부터 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
비용은 문 상태를 보고 문 열기 전에 먼저 말씀드립니다. / 문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 귀인동 말고 안양 어디든 갑니다
귀인동 가까이 평촌동, 관양동, 비산동, 호계동, 부흥동, 안양동, 석수동, 박달동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에, 다른 지역은 [출장 지역](area.html) 지도에 정리해 두었습니다.
