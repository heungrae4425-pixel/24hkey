# 가을은 이사가 몰리는 계절입니다
호계동은 범계역과 안양역 사이를 오가는 분이 많아 이사 오가는 일이 잦은 동네입니다. / 날씨가 선선해지는 가을에는 이사 일정이 몰려 도어락을 손볼 시간을 놓치기 쉽습니다.
이삿짐 정리에 정신이 없다 보면 현관 도어락은 마지막으로 미뤄지곤 합니다. / 그러다 이사 당일 새벽에 번호가 맞지 않아 당황하는 일도 생깁니다.
이 글은 호계동 이사철에 도어락 일정을 어떻게 맞출지, 날짜별로 정리한 순서입니다. / 계약서에 도장을 찍은 날부터 하나씩 따라가시면 됩니다.
@ 호계동 이사철 도어락 일정 점검

# 이사 날짜가 정해지면 가장 먼저 할 일
날짜가 확정되면 현관문 사진부터 찍어 두세요. / 이삿짐 계약이나 청소 예약보다 도어락이 늦게 챙겨지는 경우가 많으니 같은 날 함께 처리하면 좋습니다. / 바깥쪽, 안쪽, 문 옆면과 지금 달려 있는 도어락 모양이 모두 보이게 찍습니다.
새집 도어락을 그대로 쓸지, 바꿀지 판단하는 데 이 사진이 가장 중요한 자료가 됩니다. / 입주 전에 집을 볼 수 있다면 한 번 더 확인하는 게 좋습니다.
집주인이나 이전 입주자에게 현재 도어락의 비밀번호와 카드키 수량을 물어 두세요. / 어디까지 인계받는지 미리 정해 두면 당일에 덜 헤맵니다.

# 기존 도어락을 쓸지 바꿀지 정하는 기준
이사 오는 집의 도어락은 이전 사람이 쓰던 상태 그대로입니다. / 누가 번호를 알고 있었는지 확인이 어렵기 때문에 처음 한 번은 정리해 두는 것이 안심됩니다.
- 비밀번호만 새로 설정하면 충분한 경우
- 카드키나 리모컨을 모두 회수하거나 재등록해야 하는 경우
- 배터리와 부품이 많이 낡아 교체가 나은 경우
- 열쇠 방식이라 번호키 설치를 고민하는 경우
교체와 수리 사이 선택은 [도어락 교체](doorlock-replace.html) 페이지에 판단 요령을 적어 두었습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 이사 비용이 이미 큰 시기이니 꼭 필요한 부분만 손보는 게 현명합니다.

# 이삿날 전에 하는 일과 당일에 하는 일
이삿날은 짐을 옮기는 사람이 계속 드나들어 도어락을 만질 틈이 없습니다. / 전날까지 정리가 안 되면 당일 아침에는 번호만 겨우 맞추고 지나가게 됩니다. / 그래서 되도록 이삿날 전에 도어락 작업을 끝내 두는 것이 좋습니다.
입주 며칠 전 빈집일 때 교체나 초기화를 하면 짐이 없어 작업이 수월하고 시간도 단축됩니다. / 이삿날에는 새 번호를 가족에게 알리고 짐을 나르는 동선에서 문이 닫히지 않게 고정해 둔 뒤 이삿짐 업체에게 임시 출입 방법을 정해 주면 됩니다.
이사 직전에 일정이 몰리면 당일 아침에 서두르다 실수하기 쉽습니다. / 한 번에 몰아서 하지 말고 이삼 일 여유를 두세요.
@ 호계동 이사 전 도어락 교체 작업

# 초기화와 비밀번호 재설정의 차이
초기화는 저장된 번호와 카드를 모두 지우고 공장 상태로 되돌리는 작업입니다. / 비밀번호 재설정은 현재 등록된 번호만 새로 바꾸는 것입니다.
제품에 따라 초기화 방법이 다르고 초기화하면 연동된 앱이나 카드가 같이 지워질 수 있습니다. / 이사 때는 이전 흔적을 지우기 위해 초기화가 필요할 때가 많습니다.
안쪽에서 문이 열리는 상태에서 작업해야 안전합니다. / 문을 닫은 채 초기화하다가 번호가 사라져 못 들어가는 일은 피해야 합니다.

# 이삿짐이 드나들 때는 임시 방법을 정하기
이삿짐센터 직원이 문을 계속 드나들 때 매번 번호를 눌러 줄 수는 없습니다. / 이때 문을 잠깐 열어 둘지, 임시 번호를 쓸지 미리 정해 두세요.
임시 번호를 만들었다면 이삿날이 끝난 뒤 바로 지우는 것을 잊지 마세요. / 임시 번호가 오래 남아 있으면 보안에 구멍이 생깁니다.
현관문을 열어 둔 채 짐을 옮길 때는 문이 갑자기 닫히지 않게 고정해 두세요. / 열쇠를 안에 둔 채 문이 닫히면 이삿날부터 곤란해집니다.

# 이사 일정 속에서 날짜를 잡는 요령
가을에는 같은 날 이사가 몰려 도어락 작업 일정도 빨리 찹니다. / 이삿날이 확정되면 바로 작업 날짜를 잡는 것이 좋습니다.
평일 낮 시간이 비교적 여유가 있고 주말과 월말에는 일정이 몰리는 편입니다. / 시간을 지정하고 싶다면 하루 이틀 앞서 연락 주세요.
이사 전 퇴실 점검과 겹치면 집주인과 약속 시간을 같이 맞춰야 합니다. / 이전 집의 도어락도 반납하거나 정리해야 하는지 확인해 두세요.
@ 호계동 이사 일정에 맞춘 도어락 작업

# 가족 번호와 카드키 정리하기
새집의 번호를 정할 때는 가족 모두가 같이 정하는 것이 좋습니다. / 누가 어떤 방식으로 쓰는지에 따라 번호와 카드의 개수가 달라집니다.
아이나 어르신이 있다면 외우기 쉬운 번호와 카드키 둘 다 마련하는 것을 권합니다. / 번호는 쉽게 짐작되는 생일이나 호수를 피하세요.
카드키는 가족 수만큼만 등록하고 남는 것은 하나 정도 다른 곳에 보관합니다. / 분실에 대비한 대안은 미리 마련해 두는 편이 안전합니다.

# 이사 당일에 문이 안 열릴 때
이삿날 아침 번호가 맞지 않거나 문이 안 열려서 전화하는 경우가 있습니다. / 이전 입주자가 번호를 바꿨거나 배터리가 다 되어 있는 경우가 흔합니다.
이럴 때는 이삿짐 업체 일정이 걸려 있어 서둘러야 합니다. / 위치와 상황을 알려주시면 가장 빠른 순서로 출동합니다.
문을 열기 전에는 사시는 분 확인이 필요한데, 이사 당일이면 주소가 나온 서류가 아직 없을 수 있습니다. / 계약서나 입주 안내문, 관리사무소 확인이 쓰이니 미리 챙겨 두세요.

# 신분 확인에 쓸 수 있는 서류
신분증 주소가 이사 전 주소라면 새 주소 증명이 어렵습니다. / 이때는 주소가 나온 계약서나 관리사무소 확인 같은 다른 방법을 씁니다.
주소가 나온 우편물이나 입주 확인서도 도움이 됩니다. / 아직 아무것도 없다면 관리사무소나 집주인 연락을 활용할 수 있습니다.
문을 끝내 못 열면 비용은 받지 않고, 비용은 문 열기 전에 먼저 말씀드립니다. / 개방 방식은 [현관문 개문](door-open.html)에서 볼 수 있습니다.

# 이사 후 일주일 안에 점검할 것
이사를 마쳤다면 일주일 안에 도어락을 다시 한 번 살펴보세요. / 정신없는 와중에 놓친 설정이 없는지 확인하는 시간입니다.
- 새 번호가 안쪽과 바깥쪽 모두에서 잘 입력되는지
- 배터리가 새것이고 경고음이 없는지
- 문이 부드럽게 닫히고 걸쇠가 잘 들어가는지
- 이전 번호나 카드가 더 이상 작동하지 않는지
이상이 있으면 미루지 말고 [도어락 수리](doorlock-repair.html)로 바로 손보는 편이 낫습니다.

# 호계동 말고 안양 어디든 갑니다
호계동 옆 비산동, 평촌동, 부흥동, 안양동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
동네별 안내는 [안양시 출장열쇠](anyang.html)에 정리했고, 진행 순서는 [이용안내](guide.html)에서 볼 수 있습니다. / 다른 지역은 [출장 지역](area.html) 지도를 확인하세요.
