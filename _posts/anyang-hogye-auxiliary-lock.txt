# 호계동에서 보조키가 잠겨 있을 때
호계동은 범계역 쪽 아파트와 상가, 오래된 주택이 어우러진 동네입니다. / 출입문 도어락 위에 따로 보조키가 달린 집이 많아서 이 문제도 자주 생깁니다.
번호는 맞게 눌렀는데 문이 꿈쩍도 하지 않는다면 보조키가 잠긴 경우가 많습니다. / 이 글은 안양 호계동에서 그런 일이 생겼을 때 보시면 됩니다.
@ 호계동 보조키 잠김 현관문 출장열쇠

# 보조키란 무엇인가
도어락 위나 아래에 달린 작은 잠금 장치를 보조키라고 부릅니다. / 열쇠 구멍이 있거나 안쪽에서 돌리는 손잡이 형태가 많습니다.
도어락이 열려도 보조키가 잠겨 있으면 문은 열리지 않습니다. / 그래서 번호가 맞아도 안 열리는 일이 생깁니다.

# 이런 상황에서 가장 많이 생깁니다
보조키는 안에서 한 번 돌리면 잠기는 구조가 대부분입니다. / 아래 같은 상황에서 잠긴 채 나오는 경우가 많습니다.
- 늦은 밤 들어와서 보조키까지 잠근 채로 아침에 나간 경우
- 아이가 안에서 장난으로 돌려 둔 경우
- 가족 중 누군가가 늦게 잠그고 나간 경우
- 오랫동안 쓰지 않던 보조키를 갑자기 잠근 경우

# 먼저 번호판과 손잡이 소리를 들어 보세요
번호를 눌렀을 때 열리는 소리가 나는지 먼저 들어 보세요. / 소리는 나는데 문이 안 열리면 보조키나 걸쇠가 걸려 있다는 뜻입니다.
소리가 아예 나지 않으면 보조키가 아니라 배터리 문제일 가능성이 큽니다. / 이 경우는 [도어락 수리](doorlock-repair.html) 쪽부터 보셔야 합니다.

# 열쇠가 있는데 헛돌 때
보조키 열쇠를 돌려도 헛도는 경우가 있습니다. / 이럴 때는 열쇠를 세게 비틀지 말고 천천히 돌려 보세요.
- 열쇠를 끝까지 넣었다가 반 칸 빼서 돌려 보기
- 문을 살짝 안쪽으로 밀면서 돌려 보기
- 방향을 반대로 돌려 보기
열쇠가 구멍 안에서 걸리면 부러질 수 있으니 힘을 주지 마세요.
@ 호계 열쇠집 보조키 도어락 개문

# 열쇠를 억지로 돌리면 생기는 일
힘으로 돌리다가 열쇠가 부러지면 일이 훨씬 커집니다. / 부러진 조각이 구멍 안에 박히면 열쇠 구멍 전체를 바꿔야 할 수 있습니다.
조금 돌려 보고 안 되면 그대로 두고 전화 주세요. / 부러진 열쇠도 풀 수 있으니 놀라지 마세요.

# 걸쇠가 문틀에 걸린 경우
문이 오래되어 처졌거나 문틀과 틈이 어긋나면 걸쇠가 걸립니다. / 이럴 때는 문을 살짝 들어 올리듯 밀면서 열면 풀리기도 합니다.
이런 문은 도어락만 바꿔서는 해결되지 않는 경우가 많습니다. / 문틀과 경첩 상태를 같이 봐야 합니다.

# 전화하실 때 알려주세요
- 위치(가까운 건물이나 역, 동과 호수)
- 보조키가 어떤 모양인지(열쇠 구멍, 안쪽 손잡이)
- 번호를 눌렀을 때 소리가 나는지
- 열쇠가 있는지, 안에 사람이 있는지
사진을 문자로 보내 주시면 맞는 장비를 챙겨 갈 수 있습니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우시겠지만 이웃과 손님 모두를 위한 절차입니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 보조키 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.

# 보조키는 상하지 않게 엽니다
보조키는 구조를 보고 덜 상하는 방법부터 시도합니다. / 구멍이나 문틀에 흠이 남지 않게 하는 것이 먼저입니다.
자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 부품을 바꿔야 하면 바꾸기 전에 꼭 먼저 여쭙니다.
@ 호계동 현관문 보조키 개문 작업

# 열고 난 뒤 같이 점검합니다
문이 열리면 보조키와 도어락이 다시 잘 잠기고 열리는지 확인합니다. / 걸쇠가 뻑뻑하다면 위치를 손봅니다.
오래되어 헛도는 보조키는 교체를 권해 드릴 때도 있습니다. / [도어락 교체](doorlock-replace.html)가 필요하면 그때 따로 말씀드립니다.

# 보조키 쓰는 요령
- 보조키는 밤에 잘 때만 잠그기
- 외출할 때는 보조키를 열쇠로 확인하고 잠그기
- 열쇠는 따로 하나 더 보관
- 아이가 만지는 높이라면 안쪽 손잡이 사용 주의
보조키는 평소에 한 번씩 돌려 보며 뻑뻑한지 확인해 두면 좋습니다.

? 열쇠가 부러졌어요 | 억지로 빼지 마시고 전화 주세요. 부러진 열쇠도 풀 수 있습니다.

? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 보조키도 교체해야 하나요? | 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
