# 삐익 소리가 그치지 않는 밤
범계역 가까운 호계동은 늦게 퇴근하는 분이 많아서, 집에 들어서는 순간 도어락이 울기 시작하면 이웃 눈치가 먼저 보입니다. / 소리가 멈추지 않으면 문을 열 수 있는지보다 어떻게 끌지가 더 급해집니다.
이 글은 경고음이 계속될 때 소리 유형을 나누어 보는 법과, 직접 해도 되는 것, 전화가 필요한 때를 순서대로 적었습니다.
문이 함께 안 열리는 상황이라면 [호계동 출장열쇠](anyang.html) 안내도 같이 보세요.
@ 호계동 도어락 경고음 확인

# 경고음은 고장 신호만은 아닙니다
소리를 들을 때는 길이와 간격을 같이 기억해 두세요. / 짧게 세 번인지, 길게 한 번인지, 계속 이어지는지에 따라 전화로 설명할 때 단서가 됩니다.
설명서가 남아 있다면 소리 표를 찾아보는 것도 좋은 방법입니다. / 없다면 제품 앞면의 이름을 사진으로 남겨 두세요.
도어락은 여러 이유로 소리를 냅니다. / 배터리 부족 알림, 문 열림 알림, 비밀번호 오류 알림이 서로 다른 박자로 울립니다.
제품마다 소리 패턴이 달라서 몇 번 울리면 어떤 뜻이라고 일률적으로 말씀드릴 수는 없습니다. / 그래서 소리를 들으며 상황을 구분해 보는 것이 첫 단계입니다.

# 소리가 나는 때를 먼저 적어 보세요
메모장에 시간과 상황을 간단히 적어 두면 훨씬 정리됩니다. / 예를 들어 비 온 뒤에 시작했는지, 건전지를 간 뒤에 시작했는지만 알아도 원인 범위가 확 줄어듭니다.
언제 울리는지를 알면 원인이 크게 좁혀집니다.
- 문을 닫자마자 울리는지
- 번호를 누르는 동안만 울리는지
- 아무것도 안 했는데 혼자 울리는지
- 손잡이를 돌릴 때만 울리는지
혼자 울리는 경우가 가장 신경 쓰이지만, 대개 전원이나 센서 쪽 이야기입니다.

# 배터리 부족이 가장 흔한 이유입니다
건전지를 갈 때는 칸 안쪽의 극 방향 표시를 보고 끼워야 합니다. / 반대로 끼우면 소리가 이어지거나 아예 켜지지 않습니다.
새 건전지라도 오래 진열된 것이면 힘이 약할 수 있어, 같은 포장의 건전지를 함께 쓰시는 것이 안정적입니다.
배터리가 줄면 열 때마다 짧은 경고가 반복됩니다. / 그냥 두면 어느 날 번호판이 꺼지면서 문 앞에 서게 됩니다.
소리가 난다는 것은 아직 열 수 있다는 뜻이기도 합니다. / 그날 안으로 건전지를 전부 새것으로 바꾸는 편이 안전합니다.
일부만 바꾸면 비슷한 소리가 며칠 뒤 다시 납니다.

# 문이 덜 닫히면 소리가 이어집니다
문이 살짝 떠 있거나 걸쇠가 끝까지 안 들어가면 도어락이 열림 상태로 알고 경고를 계속 낼 수 있습니다. / 문을 안쪽으로 한 번 더 붙여 닫아 보세요.
- 문틈에 신발이나 문턱 이물질이 끼지 않았는지
- 문 모서리가 문틀에 스치지 않는지
- 문을 닫았을 때 걸쇠 소리가 또렷한지
@ 호계동 문 닫힘 상태와 걸쇠 확인

# 비밀번호를 여러 번 틀린 뒤의 소리
가족이 몰래 번호를 바꾸었거나 손님용 번호가 지워진 뒤에 같은 일이 생기기도 합니다. / 마지막으로 열었던 사람이 누구인지 떠올려 보세요.
술에 취했거나 피곤한 밤에는 평소 번호도 헷갈리기 쉽습니다. / 그럴 때는 무리하게 누르지 말고 잠시 숨을 고르세요.
번호를 잇달아 틀리면 도어락이 입력을 막고 경고를 냅니다. / 이때 계속 누르면 차단 시간이 길어집니다.
몇 분 쉬었다가 천천히 한 번만 눌러 보세요. / 그래도 막혀 있으면 비밀번호가 바뀐 것은 아닌지 가족에게 먼저 확인해 보시는 게 좋습니다.

# 충격 감지나 번호판 이상일 때
아이가 번호판을 두드리며 놀았거나 짐을 들다 부딪힌 일이 있었는지 가족에게 물어보세요. / 원인이 짐작되면 전화로 설명하기도 쉽습니다.
세게 닫거나 부딪힌 뒤에 울리기 시작했다면 충격을 감지했거나 내부 연결이 흔들렸을 수 있습니다. / 번호판 버튼이 눌린 채 걸려도 같은 증상이 나옵니다.
번호판 전체를 손바닥으로 가볍게 훑어 눌려 있는 버튼이 없는지 보세요. / 습기가 찬 날에도 비슷한 소리가 날 수 있어 마른 수건으로 닦는 것도 방법입니다.

# 하지 말아야 할 것
귀를 막고 싶어 문 앞에서 오래 실랑이하면 이웃에게 더 소란이 됩니다. / 소리가 길어지면 먼저 전화로 상황을 정리하는 편이 낫습니다.
소리가 거슬린다고 배터리를 빼 버리고 방치하면 문이 갑자기 안 열릴 수 있습니다. / 도어락 안쪽 덮개를 억지로 열거나 선을 만지는 것도 피해 주세요.
드라이버로 이곳저곳 눌러 보는 일도 권하지 않습니다. / 소리 하나 끄려다 정작 잠금 기능까지 못 쓰게 되는 경우가 있습니다.

# 이럴 땐 바로 전화 주세요
집 안에 아이가 혼자 있다면 그 사실을 가장 먼저 말씀해 주세요. / 우선순위를 정해 가장 빨리 움직입니다.
늦은 밤이라 이웃에게 소리가 걱정된다면 상황을 빨리 말씀해 주세요. / 소리가 계속되는 동안은 도어락이 비정상 상태일 수 있으니 문이 잠겨 있는지만 우선 확인해 두세요.
- 배터리를 모두 바꿨는데도 계속 울릴 때
- 소리와 함께 문이 열리지 않을 때
- 모터가 돌다 멈추기를 반복할 때
- 번호판 불빛이 깜빡이며 입력을 받지 않을 때
소리의 박자를 입으로 따라 해서 알려주셔도 괜찮습니다. / 전화로 설명이 어려우면 번호판 사진을 문자로 보내 주세요.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 열거나 안쪽을 열어 보는 작업이라 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나는 필요합니다. / 번거로워 보여도 이웃을 위한 절차입니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 주시면 빠릅니다.
@ 호계동 출장 점검 중 신분 확인

# 비용은 시작 전에 먼저 말씀드립니다
소리의 원인을 보고 수리인지 교체인지부터 설명드립니다. / 비용은 문 열기 전에 먼저 말씀드리고, 동의하시면 그때 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에서도 보실 수 있습니다.

# 고칠지 바꿀지는 이렇게 판단합니다
센서나 접점 문제처럼 일부만 상한 경우는 [도어락 수리](doorlock-repair.html)로 정리되는 일이 많습니다. / 소리가 매번 반복되고 모터까지 약해졌다면 [도어락 교체](doorlock-replace.html)를 말씀드릴 수도 있습니다.
무조건 바꾸라고 권하지는 않습니다. / 쓸 수 있으면 그대로 쓰시게 안내합니다.

# 소리를 미리 줄이는 습관
가족 모두가 도어락 소리의 의미를 한 번쯤 같이 확인해 두면 문 앞에서 허둥대는 일이 줄어듭니다. / 배터리 교체 담당을 정해 두는 것도 좋은 방법입니다.
- 경고음이 처음 난 날 배터리 교체하기
- 비 오는 날 번호판 물기 닦기
- 문이 끝까지 닫히는지 가끔 확인하기
- 낯선 소리가 나면 사진이나 영상으로 소리 남겨 두기
소리를 녹음해 두면 설명할 때 큰 도움이 됩니다.
