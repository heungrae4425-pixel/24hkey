# 호계동에서 얼굴로 여는 도어락을 알아보는 분들께
호계동은 범계역과 평촌역 생활권을 오가는 분이 많은 동네입니다. / 출퇴근길에 양손이 짐으로 가득한 날이 많다 보니 얼굴 인식 도어락에 관심을 두는 분이 늘었습니다.
다만 얼굴 인식은 지문이나 번호키와 달리 문 앞 환경의 영향을 많이 받습니다. / 사 놓고 후회하지 않으려면 들이기 전에 확인할 것이 꽤 있습니다.
이 글은 호계동에서 얼굴 인식 도어락을 고민하실 때 살펴볼 순서를 정리한 것입니다. / 설치가 필요하면 [안양 출장열쇠](anyang.html)로 문의하셔도 됩니다.
@ 호계동 얼굴 인식 도어락 설치 전 점검

# 얼굴 인식은 어떤 원리로 문을 여나
도어락 바깥쪽에 작은 카메라가 있어 등록해 둔 얼굴과 지금 얼굴을 견줍니다. / 맞으면 모터가 걸쇠를 풀고, 맞지 않으면 번호나 카드 같은 다른 수단으로 넘어갑니다.
그래서 제품마다 얼굴 말고 비밀번호, 카드, 열쇠 중 몇 가지를 함께 쓸 수 있게 만들어 둡니다. / 얼굴만 되는 제품인지 보조 수단이 있는지는 꼭 확인할 대목입니다.
카메라가 켜지는 방식도 제품마다 달라서, 사람이 다가오면 자동으로 켜지는 것과 버튼을 눌러야 켜지는 것이 있습니다. / 자동으로 켜지는 제품은 편하지만 그만큼 전기를 더 씁니다.

# 우리 집 문 앞이 얼굴 인식에 맞는지
복도가 어둡거나 햇빛이 문 앞으로 곧장 들어오면 인식이 흔들릴 수 있습니다. / 새벽이나 해 질 녘에 역광이 생기는 집이라면 특히 따져 봐야 합니다.
- 문 앞에 센서등이나 복도등이 있는지
- 오후에 햇빛이 정면으로 들어오는지
- 키가 다른 가족이 함께 쓰는지
- 문 앞에 우산, 자전거 같은 물건이 쌓여 있는지
카메라 높이는 제품마다 정해져 있어서 아이나 어르신은 얼굴이 잘 안 잡히기도 합니다. / 가족 모두가 쓸 수 있는지를 기준으로 고르셔야 합니다.
현관 앞이 좁아 한 걸음 물러설 수 없는 구조라면 얼굴이 카메라에 다 담기지 않을 수도 있습니다. / 실제로 설 자리를 가늠해 보고 고르세요.

# 마스크, 안경, 모자를 쓴 날은 어떨까
마스크를 쓰고 있으면 인식이 안 되는 제품이 있고, 일부는 눈 주변만으로 구분하기도 합니다. / 겨울에 목도리까지 두르는 날을 떠올려 보세요.
안경을 바꾸거나 머리 모양을 크게 바꿔도 처음 등록 때와 달라 보일 수 있습니다. / 이럴 때를 대비해 번호 입력 같은 두 번째 방법을 반드시 살려 두시길 권합니다.

# 문 두께와 도어락 자리 확인
얼굴 인식 도어락은 일반 번호키보다 본체가 크고 무거운 편입니다. / 문 두께, 기존 구멍 크기, 보조키 위치가 맞지 않으면 설치가 어려울 수 있습니다.
호계동은 오래된 건물과 비교적 새 건물이 섞여 있어 문 규격이 제각각입니다. / 사진 한 장만 보내 주셔도 맞는지 먼저 말씀드릴 수 있습니다.
@ 현관문 두께와 구멍 크기 확인

# 전원 방식과 배터리 관리
카메라와 화면이 있어 일반 도어락보다 전기를 더 씁니다. / 배터리 교체 주기가 짧아질 수 있으니 구입 전에 어떤 배터리를 몇 개 넣는지 봐 두세요.
비상 전원 단자가 있는 제품인지도 중요합니다. / 배터리가 다 되었을 때 밖에서 잠깐 전원을 대 줄 수 있어야 문 앞에서 막히지 않습니다.
배터리 부족 알림이 얼마나 일찍 오는지도 물어보면 좋습니다. / 알림을 놓치는 가족이 있다면 달력에 교체일을 적어 두는 편이 안전합니다.

# 가족 얼굴 등록은 이렇게 해 두세요
등록은 문 앞에서 하루 중 다른 시간대에 두세요. / 낮과 밤의 조명이 다르기 때문에 한 번만 등록하면 저녁에 안 열릴 수 있습니다.
- 정면과 살짝 고개를 든 모습으로 나눠 등록
- 안경을 쓰는 가족은 쓴 모습과 벗은 모습 모두 등록
- 아이는 성장하면 다시 등록
- 손님 출입은 얼굴이 아닌 임시 번호로 안내
등록한 얼굴 정보가 도어락 안에만 저장되는지, 외부 서버를 거치는지도 설명서에서 확인해 보세요. / 정보가 어디에 저장되는지 알고 쓰는 것이 마음 편합니다.

# 인식이 안 될 때를 위한 비상 수단
얼굴 인식이 늘 완벽하지는 않다는 점을 알고 시작하셔야 합니다. / 조명, 각도, 카메라 렌즈의 먼지 같은 사소한 이유로 한두 번 실패할 수 있습니다.
카메라 렌즈를 마른 천으로 자주 닦아 주면 인식률이 좋아지기도 합니다. / 그래도 안 열리는 날을 대비해 번호키나 열쇠 구멍이 남아 있는 제품이 안심됩니다.
특히 이사 직후나 외출에서 돌아오는 밤처럼 얼굴이 피곤해 보이는 날, 또는 눈이 내려 모자를 눌러 쓴 날에는 평소보다 실패가 잦을 수 있습니다. / 그런 날에도 문 앞에서 오래 서 있지 않도록 번호를 외워 두세요.
@ 비상 번호 입력과 열쇠 구멍 확인

# 기존 도어락을 바꿀 때 알아 둘 것
이미 쓰는 도어락이 있다면 떼어 내고 새 제품을 다는 작업이 됩니다. / 문에 난 구멍이 새 제품과 어긋나면 문틀 쪽을 손봐야 할 때도 있습니다.
교체 과정은 [도어락 교체](doorlock-replace.html)에 적어 두었고, 처음 다는 경우는 [도어락 설치](doorlock-install.html)에 안내돼 있습니다. / 상황을 알려 주시면 어느 쪽에 해당하는지 먼저 말씀드립니다.

# 비용은 시작 전에 말씀드립니다
제품 종류와 문 상태에 따라 작업 내용이 달라집니다. / 현장에서 확인한 뒤 얼마인지 문 열기 전, 작업 시작 전에 먼저 말씀드립니다.
마음에 들지 않으시면 그대로 돌아갑니다. / 문을 못 여는 출장이라면 못 열었을 때 비용은 받지 않습니다.
설치 도중 문틀 보강처럼 추가 작업이 필요해 보이면 손대기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에서도 보실 수 있습니다.

# 사는 분 확인은 설치에도 필요합니다
도어락을 바꾸거나 열어 드리는 일은 집의 출입을 다루기 때문에 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
세입자라면 집주인과 도어락 교체에 대해 미리 이야기해 두는 것이 좋습니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

# 설치 뒤에 꼭 해 볼 시험
달고 나면 문을 연 상태에서 얼굴, 번호, 카드를 하나씩 시험해 보세요. / 문이 열려 있을 때 시험해야 잠겨 버릴 걱정이 없습니다.
- 낮과 밤 조명 아래에서 각각 인식해 보기
- 가족 모두 한 번씩 열어 보기
- 일부러 틀린 번호를 입력해 경고가 나오는지 보기
- 문을 닫았을 때 자동으로 잠기는지 확인
이 과정에서 이상이 있으면 그날 바로 말씀해 주세요. / 고장이 잦아지면 [도어락 수리](doorlock-repair.html)로 먼저 점검해 드립니다.

# 호계동 말고도 안양 곳곳에 갑니다
호계동 옆 평촌동, 비산동, 관양동, 부흥동, 귀인동도 다닙니다. / 안양 안이면 어느 동네든 24시간 출동합니다.
다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다. / 급한 문 문제는 [현관문 개문](door-open.html) 페이지에도 정리해 두었습니다.
