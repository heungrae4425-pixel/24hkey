# 호계동 공장 사무동, 밤에 문이 안 열리면
호계동은 범계역 방향 주거지와 가까이 작은 공장과 작업장, 사무실이 함께 있는 동네입니다. / 낮에는 사람이 오가던 사무동 출입문이 밤이나 주말에는 한동안 잠겨 있다가 갑자기 문제가 생기기도 합니다.
야근하러 돌아왔거나 주말에 급히 서류를 가지러 왔는데 도어락이 반응하지 않는 경우입니다. / 공장은 작업동과 사무동의 출입문이 따로인 곳이 많아 어느 문이 문제인지부터 가려야 합니다.
이 글은 공장 사무동 출입문이 야간에 안 열릴 때 확인할 것과 [호계동 출장열쇠](anyang.html)를 부르는 순서를 정리했습니다.
@ 호계동 공장 사무동 출입문 도어락

# 작업동 문과 사무동 문은 다릅니다
공장 건물은 안쪽 구조가 나뉘어 있습니다. / 철문으로 된 작업동 출입구, 유리문으로 된 사무동 출입구, 창고 문이 서로 다른 열쇠로 잠기는 경우가 많습니다.
- 사무동 현관: 도어락이나 열쇠로 잠긴 일반 출입문
- 작업동 출입구: 큰 철문이나 셔터
- 창고, 보관실: 별도의 잠금장치
어느 문 앞에 서 있는지 먼저 알려주셔야 필요한 장비를 정확히 챙길 수 있습니다. / 셔터는 다른 종류의 작업이라 전화로 먼저 상황을 확인합니다.

# 야간에 막히는 흔한 원인
오래 잠가 둔 문이 밤에 갑자기 안 열리는 데는 이유가 있습니다. / 평일 낮에는 사람이 계속 드나들어 눈에 띄지 않던 문제가 퇴근 뒤 한꺼번에 드러나기도 합니다.
- 도어락 배터리가 낮 동안 이미 약해져 있었던 경우
- 비밀번호를 담당자가 바꿨는데 공유가 안 된 경우
- 출입 카드나 태그가 인식되지 않는 경우
- 열쇠 구멍에 먼지와 기름때가 쌓여 돌아가지 않는 경우
- 문틀 쪽 마그네틱이나 센서가 어긋난 경우
공장 주변은 먼지가 많아 열쇠 구멍이 막히기 쉽습니다.

# 문 앞에서 먼저 확인할 것
번호판이 켜지는지, 눌렀을 때 소리가 나는지를 먼저 보세요. / 카드나 태그를 쓰는 문이라면 같은 카드를 한 번 더 천천히 대 보세요.
번호판이 꺼져 있으면 배터리 문제일 가능성이 큽니다. / 바깥쪽 비상 단자가 있다면 9V 건전지를 대 보는 방법이 있습니다.
여러 번 틀려서 입력이 막혔다면 잠시 기다린 뒤 다시 시도하세요. / 서너 번 안 되면 멈추는 것이 좋습니다.
@ 호계동 사무동 출입문 번호판과 카드 인식부 확인

# 담당자와 먼저 연락해 보세요
출입 비밀번호나 열쇠는 보통 담당자가 관리합니다. / 대표나 관리 담당자에게 번호가 바뀌었는지 먼저 물어보는 것이 가장 빠를 수 있습니다.
사무실 안에 누군가 남아 있다면 안에서 열어 달라고 부탁할 수도 있습니다. / 야간 보안 담당이 있는 곳이라면 먼저 연락해 보세요.
연락이 닿지 않을 때만 출장열쇠를 부르는 것이 순서에 맞습니다.

사무동에는 출입문 외에도 서랍과 사물함, 금고 같은 잠금장치가 있습니다. / 이번 글은 출입문 중심이라 금고처럼 따로 안내가 필요한 것은 전화로 상황을 들어 보고 가능 여부를 말씀드립니다.
출입문이 열렸다고 해서 내부 잠금까지 한꺼번에 해결되는 것은 아닙니다. / 어떤 문제가 있는지 구체적으로 알려 주세요.

# 직원이 여러 명일 때 생기는 일
직원이 여러 명이면 번호를 아는 사람이 많아지고 누가 마지막으로 문을 잠갔는지 알기 어려워집니다. / 이 때문에 아침에 출근했더니 문이 열려 있거나, 밤에 돌아왔더니 번호가 바뀌어 있는 일이 생깁니다.
- 마지막 퇴근자가 문을 잠그고 확인하는 순서를 정하기
- 번호를 바꿀 때는 담당자가 모두에게 알리기
- 퇴사한 직원의 번호나 카드는 바로 정리하기
작은 규칙만 있어도 야간 곤란이 크게 줄어듭니다.

# 전화할 때 알려주실 내용
밤에 공장 지대에서는 길이 어둡고 건물이 비슷해 찾기 어려울 수 있습니다. / 아래 정도를 짧게 말씀해 주시면 도착이 빨라집니다.
- 호계동 주소와 건물 입구 특징
- 어느 문인지 (사무동 현관, 작업동, 창고)
- 번호판 상태, 카드 인식 여부
- 현재 안에 사람이 있는지
- 주차나 차량 진입이 가능한지
도어락 사진과 위치 점을 함께 보내 주시면 더 좋습니다. / [출장열쇠 이용 안내](key-call.html)에 자세히 정리해 두었습니다.

# 도착하면 확인하는 것
영업장이라고 해도 문을 여는 일이라 먼저 확인하는 절차가 있습니다. / 사업자 정보가 있는 서류, 사무실 주소가 나온 우편물, 관리하는 분의 확인 중 하나면 됩니다.
번거로우실 수 있지만 건물 안의 물건을 지키기 위한 절차입니다. / 대표나 담당자가 아닌 분이 오셨다면 담당자와 전화로 확인하는 시간이 필요할 수 있습니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 먼저 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 호계동 사무동 출입문 개방 작업 준비

사무동 출입문은 손님이 보는 얼굴이라 문과 도어락이 상하지 않는 것이 중요합니다. / 그래서 힘으로 하는 방법보다 덜 상하는 방법부터 차례로 합니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 먼저 말씀드립니다. / 자세한 개방 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 열고 난 뒤에 정리할 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 함께 확인합니다. / 배터리가 원인이었다면 새 배터리로 바꾸고 상태도 같이 봅니다.
출입 번호를 새로 정리하는 것도 도와드릴 수 있습니다. / 기존 번호는 지우고 필요한 사람에게만 새 번호를 알리도록 정리합니다.
사무실 도어락은 자주 쓰므로 고장이 반복되면 [도어락 수리](doorlock-repair.html)를 먼저 권하고, 너무 오래되었을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 야간 출입을 편하게 하는 평소 관리
공장 사무동은 낮에는 바쁘고 밤에는 비는 곳이라 평소 관리가 더 필요합니다.
- 배터리는 일정을 정해 한 번에 교체
- 열쇠 구멍 먼지는 마른 솔이나 천으로 가끔 털기
- 출입 카드 분실 시 바로 보고하는 규칙
- 야간 연락 가능한 담당자 번호를 문 안쪽에 정리
- 번호 변경 내역을 기록해 두기
작은 정리가 야간 출입 문제를 줄이는 가장 쉬운 방법입니다.

# 호계동 말고 안양 어디든 갑니다
호계동 가까이 평촌동, 비산동, 관양동, 귀인동, 부흥동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
