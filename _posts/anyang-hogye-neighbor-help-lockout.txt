# 문 앞에서 가장 먼저 떠오르는 사람은 이웃
호계동은 범계역과 안양역 사이를 오가는 주민이 많은 동네입니다. / 아파트든 빌라든 한 건물에 여러 세대가 모여 사는 집이 많아 이웃이 가까이 있습니다.
문이 안 열리면 누구나 옆집이나 아랫집을 먼저 떠올리게 됩니다. / 도움을 받는 일이 나쁠 것은 없지만 방식에 따라 서로 기분이 달라지기도 합니다.
도움을 청하는 일은 부끄러운 일이 아니고, 이웃도 비슷한 일을 겪었을 가능성이 큽니다. / 다만 상대가 부담스럽지 않게 하는 마음만 챙기면 됩니다.
이 글은 이웃과 경비실에 어떻게 도움을 청하면 좋은지, 그래도 안 될 때 [안양 출장열쇠](anyang.html)를 어떻게 부르면 되는지 순서대로 정리했습니다.
@ 호계동 이웃에게 도움 청하기

# 먼저 숨을 고르고 상황을 정리합니다
문 앞에서 당황하면 해야 할 말도 뒤섞입니다. / 열쇠가 없는 건지, 번호가 안 먹히는 건지, 번호판이 꺼진 건지 한 문장으로 정리해 보세요.
이웃에게 부탁하는 말이 간단할수록 상대도 응하기 편합니다. / 무엇이 필요한지 정하고 나서 찾아가는 것이 좋습니다.
- 전화를 잠깐 빌리고 싶은 건지
- 건전지나 도구를 빌리고 싶은 건지
- 경비실 연락처를 알고 싶은 건지
- 잠시 앉아 기다릴 곳이 필요한 건지

# 시간대를 먼저 생각합니다
늦은 밤이나 새벽에 갑자기 초인종을 누르면 이웃이 놀랄 수 있습니다. / 이런 시간이면 문을 두드리기보다 문자나 전화로 먼저 연락하는 편이 낫습니다.
저녁 식사 시간이나 아이들이 자는 시간도 피하면 좋습니다. / 급하더라도 상대의 사정을 한 번만 헤아려 주세요.
낮 시간이라면 비교적 부탁하기 쉽지만 집에 없는 경우가 많습니다. / 한두 집에서 응답이 없으면 더 두드리지 않고 다음 방법으로 넘어갑니다.
현관 앞에 서성이며 계속 초인종을 누르면 오히려 불안감을 줄 수 있으니 횟수를 정해 두세요.

# 부탁은 짧게, 감사는 분명하게
처음 보는 이웃이라면 간단히 인사부터 합니다. / 같은 층에 사는 사람인데 문이 잠겼다는 한 문장이면 충분합니다.
전화를 빌릴 때는 필요한 통화만 하고 바로 돌려드립니다. / 번호는 내 휴대폰 번호를 불러 주지 말고 직접 걸어 달라고 부탁하는 것이 서로 편합니다.
도움을 받은 뒤에는 짧게 감사 인사를 남깁니다. / 나중에 음료수 한 병 정도 전하는 마음이면 충분합니다.
@ 경비실 앞에서 상황 설명

# 경비실이나 관리사무소를 쓰는 방법
경비실이 있는 곳이면 근무자에게 세대와 이름을 말하고 도움을 요청합니다. / 경비실은 세대 확인과 연락처 안내까지는 도와줄 수 있지만 문을 열어 주는 일은 보통 하지 않습니다.
관리사무소가 열려 있으면 세대 정보를 확인받아 신분 확인에 쓸 수 있습니다. / 이 확인은 나중에 출장열쇠가 도착했을 때 사시는 분인지 입증하는 데 도움이 됩니다.
근무자가 자리를 비운 시간이면 안내 문구에 있는 연락처를 확인해 보세요.
경비실에 맡겨 둔 가족 열쇠가 있는지 확인하는 것도 방법입니다. / 평소에 그런 약속을 해 둔 적이 있다면 이때 도움이 됩니다.

# 이웃에게 부탁하면 안 되는 것
창문이나 베란다를 통해 들어가 달라는 부탁은 위험하니 하지 마세요. / 사고가 날 수 있고 이웃에게 책임을 지우게 됩니다.
다른 사람의 집 도어락 번호를 알려 달라고 하거나 남의 열쇠를 빌려 시험해 보는 것도 안 됩니다. / 이웃의 안전과 사생활을 지키는 일이 먼저입니다.
옆집 문을 통해 외벽으로 건너가는 방법도 절대 피해 주세요.

# 이웃이 도와줄 수 있는 현실적인 것
9V 건전지가 있다면 빌려서 비상 단자에 대 볼 수 있습니다. / 이웃도 건전지가 없다면 호계동 근처 편의점에서 구하는 방법이 있습니다.
충전기나 휴대폰이 없는 상황이면 전화만 빌려도 큰 도움입니다. / 가족에게 번호를 확인하거나 출장 연락을 할 수 있기 때문입니다.
집 안에 가족이 있다는 걸 이웃이 알고 있다면 그 가족에게 연락해 줄 수도 있습니다.
이웃이 직접 문을 두드려 보는 일은 부탁하지 않는 편이 좋습니다. / 필요한 도움이 전화 한 통이라면 그 정도만 청하세요.

# 그래도 안 되면 전화로 출동 요청
이웃과 경비실 도움을 받아도 풀리지 않으면 더 오래 버티지 마세요. / 위치와 상황을 알려 주시면 출동 여부를 바로 말씀드립니다.
빌린 전화로 걸었다면 이웃 번호가 아니라 지금 계신 위치를 말씀해 주세요. / 호계동 안이면 동네 상관없이 24시간 출동합니다.
집 안에 아이나 반려동물이 있다면 꼭 먼저 알려 주세요. / 이 경우는 우선해서 안내합니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
이웃이 증인이 되어 주어도 신분증이나 우편물을 대신할 수는 없습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.
신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁하세요.
낮에는 관리사무소가 열려 있으니 그때 신분 확인용 서류를 발급받을 수 있는지도 물어보세요.

# 비용은 문 열기 전에, 못 열면 없습니다
현장에서 문 상태와 도어락을 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 갑자기 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 정리했습니다.
@ 호계동 출장열쇠 현관문 개방

# 열린 뒤 이웃에게 다시 인사를
문이 열리면 도움을 준 이웃에게 한마디 건네는 것이 좋습니다. / 큰 일이 아니었다는 걸 알리면 상대도 마음이 놓입니다.
문 앞이 소란스러웠다면 이웃에게 양해를 구하는 것도 방법입니다. / 서로 얼굴을 아는 사이가 되면 다음에 도움이 필요할 때도 부탁하기 쉬워집니다.

# 재발을 줄이는 작은 준비
믿을 수 있는 이웃이나 가족에게 비상 연락처를 서로 교환해 두면 좋습니다. / 열쇠를 대신 맡아 달라고 하기보다 연락만 닿으면 되는 관계가 부담이 덜합니다.
배터리는 정기적으로 바꾸고, 경고음이 나면 그날 바로 교체합니다. / 고장이 반복되면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 낡았다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
믿을 만한 이웃이 있다면 번호판이 꺼졌을 때 건전지를 빌릴 수 있는지 평소에 물어봐 두는 정도로도 충분합니다.
문을 여는 구체적인 방식은 [현관문 개문](door-open.html) 페이지에 있습니다.

# 호계동 말고 안양 곳곳으로 갑니다
평촌동, 비산동, 관양동, 귀인동, 부흥동, 안양동, 석수동, 박달동도 다닙니다. / 인덕원역 방향까지 안양 안이면 24시간 출동합니다.
[출장 지역](area.html)에서 다른 지역도 확인해 보세요.

? 경비실에서 문을 열어 주나요? | 보통은 연락과 세대 확인을 도와줄 뿐 문을 열어 주지는 않습니다.
