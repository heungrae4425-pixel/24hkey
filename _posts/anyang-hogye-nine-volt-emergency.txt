# 호계동 현관 앞에서 번호판이 꺼졌다면
호계동은 범계역 쪽 상권과 주택가가 가까이 이어져 있어 늦게 귀가하는 분도 많은 동네입니다. / 퇴근하고 현관 앞에 섰는데 번호판에 불이 안 들어오면 순간 머릿속이 하얘집니다.
이럴 때 많이들 떠올리는 것이 9V 건전지로 임시 전원을 넣는 방법입니다. / 이 글은 그 방법을 어떻게 쓰는지, 어디까지 되고 어디서부터 안 되는지를 정리했습니다.
@ 호계동 도어락 하단 9V 비상 단자

# 9V 비상 전원이 하는 일
도어락이 꺼진 이유가 배터리 방전이라면, 바깥에서 전원을 잠시 이어 주어 문을 열 수 있게 하는 것이 비상 전원의 역할입니다. / 문을 여는 동안만 전기를 공급하는 임시 방편이라는 점을 먼저 기억해 두세요.
이 방법이 통하는 경우는 대체로 아래와 같습니다.
- 안쪽 배터리가 완전히 방전돼 번호판이 아예 꺼진 경우
- 모터를 돌릴 힘만 모자란 상태
- 비밀번호는 알고 있는 경우
번호를 모르거나 도어락 자체가 고장 난 경우는 비상 전원을 대도 소용이 없습니다.
가족이 번호를 바꾼 줄 모르는 경우도 이 방법으로는 해결되지 않습니다. / 이럴 때는 번호 문제인지 전원 문제인지 먼저 가려야 합니다.
번호판이 꺼진 이유가 방전이 아닌 정전이라면 건물 전체 상태도 같이 확인해 보세요. / 이웃 집 불이 들어오는지 보는 것만으로도 단서가 됩니다.

# 비상 단자는 어디에 있을까
제품마다 위치가 다르지만 바깥쪽 번호판 아래쪽이나 옆쪽에 작은 접점 두 개가 있는 경우가 많습니다. / 덮개가 있는 제품도 있어 덮개를 열어야 보이는 경우가 있습니다.
어떤 제품은 단자가 건전지 모양으로 되어 있고, 어떤 제품은 접점이 평평하게 되어 있습니다. / 없는 제품도 있으니 찾기 어렵다면 무리하게 찾지 말고 사진을 찍어 두세요.
위치를 모를 때는 도어락 하단과 측면을 손전등으로 비춰 보면 접점이 보이기도 합니다.
@ 호계동 손전등으로 도어락 하단 접점 찾기
접점 주변이 먼지나 물기로 지저분하면 마른 천으로 가볍게 닦은 뒤 시도하세요. / 접점이 더러우면 전원이 제대로 전달되지 않는 경우가 있습니다.

# 9V 건전지를 대는 순서
건전지를 구했다면 아래 순서대로 해보세요.
- 건전지 양쪽 단자가 접점에 닿는 방향을 확인하기
- 건전지를 접점에 꾹 눌러 붙이기
- 누른 상태에서 번호판에 불이 들어오는지 보기
- 불이 들어오면 건전지를 떼지 말고 비밀번호 입력
- 열리면 안쪽 배터리를 곧바로 교체
방향이 반대로 닿으면 아무 반응이 없을 수 있으니 한 번 뒤집어서 다시 대 보세요. / 건전지를 떼는 순간 다시 꺼지므로 누른 채로 입력해야 합니다.

# 이럴 땐 9V를 대도 안 열립니다
비상 전원으로 해결되지 않는 경우도 분명히 있습니다. / 아래 같은 경우에는 건전지를 대도 해결되지 않습니다.
- 도어락 내부 기판이나 모터가 고장 난 경우
- 번호가 맞는데 걸쇠가 문틀에 걸려 움직이지 않는 경우
- 안쪽 보조키를 잠근 채 문을 닫고 나온 경우
- 문틀이 처져 데드볼트가 구멍에 눌려 있는 경우
- 비상 단자가 없는 제품
이런 때는 건전지를 계속 바꿔 가며 시도하기보다 전화로 상황을 알려 주시는 편이 빠릅니다.
@ 호계동 9V 건전지로 임시 전원을 넣어 번호판 켜기

# 건전지를 새로 살 때 확인할 것
급히 사려다 보면 규격이 다른 건전지를 집어 오기 쉽습니다. / 9V 직사각형 건전지를 찾아야 하고, 일반 AA나 AAA와 혼동하지 않도록 포장 표시를 보세요.
유효기간이 오래 지난 건전지는 힘이 약해서 모터를 돌리지 못할 수 있습니다. / 편의점에서 사더라도 표면이 부풀거나 녹슬지 않았는지 한 번 살펴보세요.
호계동처럼 상가가 가까운 곳은 밤에도 구하기 쉬운 편이지만 그래도 없다면 전화 주시면 됩니다.

# 서너 번 시도해도 반응이 없으면 멈추세요
번호판이 켜지지 않는데 계속 건전지를 눌러 대는 것은 도움이 되지 않습니다. / 접점이 지저분하거나 기판 문제라면 같은 시도를 되풀이해도 결과가 같습니다.
번호를 여러 번 틀리면 도어락이 입력을 한동안 막는 제품도 있습니다. / 이때 시간이 지나기를 기다려야 해서 오히려 더 늦어집니다.
세 번 정도 해보고 안 되면 전화하시는 게 낫습니다. / 상태를 말씀해 주시면 다음 순서를 안내해 드립니다.

# 비상 전원 쓸 때 조심할 것
- 건전지를 접점이 아닌 다른 곳에 닿게 하지 않기
- 습기가 있는 날은 접점을 마른 천으로 닦은 뒤 사용
- 건전지를 오래 눌러 열이 나면 즉시 떼기
- 도어락 앞판을 뜯어 선을 직접 이어 보지 않기
전기를 다루는 일이라 무리하게 만지면 도어락이 상할 수 있습니다. / 문이 열리지 않아 급한 마음이 들어도 정해진 방법만 써 주세요.

# 출장 요청할 때 알려 주실 것
호계동은 범계역과 안양 쪽으로 이어지는 도로 주변에 건물이 모여 있어 위치 설명이 정확하면 도착이 빨라집니다. / 아래 내용을 알려 주세요.
- 건물 이름 대신 길가에서 보이는 특징과 동, 호수
- 번호판 상태와 비상 단자 유무
- 9V를 대 봤다면 어떻게 반응했는지
- 집 안에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙기기 좋습니다. / 접수 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 신분 확인이 먼저입니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 문을 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
문 여는 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 열고 나서는 배터리부터 전부 교체
9V로 임시로 열었다면 그 순간부터 안쪽 배터리를 새것으로 바꿔야 합니다. / 일부만 바꾸면 며칠 안에 같은 일이 다시 생깁니다.
배터리 종류와 개수는 도어락마다 다르니 뚜껑을 열어 확인하세요. / 부식된 흔적이 있다면 접점도 같이 닦아야 합니다.
반복해서 방전된다면 도어락 쪽 문제일 수 있어 [도어락 수리](doorlock-repair.html)로 먼저 점검합니다. / 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 호계동 말고 안양 어디든 갑니다
호계동 가까운 평촌동, 관양동, 비산동, 귀인동, 부흥동과 안양동, 석수동, 박달동도 다닙니다. / 안양 안이면 24시간 출동합니다.
[안양시 출장열쇠](anyang.html) 페이지와 [출장 지역](area.html)에서 확인하실 수 있습니다.
