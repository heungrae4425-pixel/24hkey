# 불이 나갔는데 문은 열릴까요
호계동은 안양역과 범계역 사이에서 아파트와 빌라가 이어진 주거지입니다. / 단지 전기 점검이나 공사로 하루 종일 전기가 끊긴다는 안내문을 받아 보신 분이 많을 것입니다.
그때 가장 많이 나오는 질문이 번호키는 전기가 없어도 열리느냐는 것입니다. / 이 글은 정전이 났을 때 도어락이 어떻게 반응하는지를 설명합니다.
문 앞에서 막혔을 때는 [안양 출장열쇠](anyang.html)에 연락하는 순서도 적었습니다.

# 대부분의 번호키는 건전지로 움직입니다
가정용 번호키는 집의 전기와 별개로 안에 들어 있는 건전지로 작동하는 제품이 많습니다. / 그래서 집 전체가 정전이 되어도 번호키 자체는 평소처럼 쓸 수 있습니다.
다만 모든 제품이 그런 것은 아닙니다. / 전원선을 따로 연결해 쓰는 제품이나 일부 공용 출입문 장치는 전기가 끊기면 반응하지 않기도 합니다.
우리 집 도어락이 어느 쪽인지 건전지 칸이 있는지 한 번 확인해 두세요.
@ 호계동 정전 시 도어락 건전지 칸

# 정전이 길어질 때 건전지가 달라집니다
정전이 며칠씩 이어지는 일은 드뭅니다. / 하지만 번호키를 자주 눌러 쓰면 평소보다 건전지가 빨리 닳을 수 있습니다.
- 번호판을 계속 눌러 불을 켜 보는 습관
- 문을 자주 여닫는 상황
- 오래된 건전지를 그대로 쓰는 경우
정전 전에 건전지 상태가 좋은지 확인해 두는 것이 가장 안전합니다. / 경고음이 한 번이라도 났다면 바로 새것으로 갈아 두세요.

# 엘리베이터와 공용 출입문은 따로 생각하세요
단지 전기 점검 때는 엘리베이터가 멈추고 공동 현관 출입문 전자 장치도 꺼질 수 있습니다. / 이럴 때는 층계로 올라와야 하고, 공동 현관은 관리사무소가 열어 주거나 수동으로 열어 둡니다.
관리사무소에 점검 시간대를 미리 확인해 보세요. / 공동 현관이 잠겨 있으면 입주민 확인 후 열어 주는 방식이 많습니다.
공동 현관 장치는 개별 세대 도어락과 달라서 관리사무소가 관리하는 영역입니다.
점검 시간 동안 택배나 배달이 오면 받기 어려울 수 있으니 미리 가까운 이웃에게 부탁해 두는 방법도 있습니다. / 어르신이 계신 집은 층계 이동이 어려우니 점검 시간을 피해 장을 보거나 외출을 마치도록 도와드리세요.

# 전기가 돌아온 뒤 도어락이 이상할 때
정전에서 복귀하는 순간 전압이 흔들려 도어락이 오작동하는 일이 가끔 있습니다. / 번호판 불빛이 깜빡이거나 소리가 이상하게 나기도 합니다.
이럴 때는 서둘러 번호를 누르기보다 잠시 기다렸다가 다시 눌러 보세요. / 몇 분 안에 안정되는 경우가 많습니다.
계속 이상하다면 건전지를 잠시 빼고 다시 끼우는 방법이 있습니다. / 다만 설정이 지워질 수 있는 제품도 있으니 설명서를 먼저 확인하세요.
@ 전기 복귀 뒤 번호판 반응 확인

# 비상 전원 단자를 알아 두세요
많은 번호키는 바깥쪽 아래 부분에 9V 건전지를 댈 수 있는 단자가 있습니다. / 집 건전지가 다 돼서 번호판이 꺼졌을 때 임시로 전원을 넣는 방법입니다.
단자가 보이지 않는다면 번호판 아래 작은 덮개를 밀어 보세요. / 제품에 따라 바닥 쪽 구멍 두 개가 단자인 경우도 있습니다.
정전과 관계없이 건전지가 방전되는 일은 따로 생기니, 한 번씩 단자 위치를 알아 두면 좋습니다.
편의점이나 마트가 문을 닫은 한밤중에는 건전지를 구하기 어렵습니다. / 9V 건전지를 현관 서랍에 하나 넣어 두면 든든합니다.

# 정전 때 열쇠를 못 찾을 때
번호키를 믿고 열쇠를 어디 뒀는지 잊어버린 경우가 많습니다. / 정전이 나고 번호키가 안 열리는 상황이라면 열쇠 구멍이 있는지, 열쇠가 어디 있는지 바로 떠올려야 합니다.
열쇠 구멍은 번호판 아래 덮개 안쪽에 숨겨진 제품도 있습니다. / 덮개를 밀어 보거나 살짝 눌러 보세요.
가족 중 열쇠를 가진 사람에게 연락하는 것도 방법입니다.

정전이 나면 현관이 깜깜해 번호판을 보기 어렵습니다. / 휴대폰 손전등으로 번호판을 비춰 보세요.
손전등을 비출 때 빛이 번호판에 반사되어 숫자가 안 보이면 각도를 살짝 옆으로 돌려 보세요. / 한 손으로 비추고 한 손으로 누르기 어려우면 다른 가족에게 불을 들어 달라고 부탁하세요.
정전 때 급하게 열려다 번호를 잘못 눌러 입력 제한이 걸리는 일도 있습니다. / 어두울 때일수록 천천히 눌러야 합니다.
정전과 겹쳐서 오작동이 일어나면 정전 탓이라고 생각하기 쉽지만, 실제로는 건전지가 약해졌거나 센서가 문제인 경우도 많습니다. / 전기가 돌아왔는데도 계속 안 열린다면 도어락 자체를 점검해야 합니다.


# 전화하실 때 알려 주실 내용
- 호계동 어느 쪽인지, 건물 이름과 층, 호수
- 정전이 있었는지, 지금 전기가 들어오는지
- 번호판 상태(꺼짐, 깜빡임, 경고음)
- 도어락 종류와 열쇠 구멍 유무
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 보내주시면 필요한 장비를 챙기기 좋습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 거주자인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소의 세대 확인 중 하나면 됩니다.
정전 중이라 공용 장치가 꺼져 있다면 경비실 확인이 어려울 수 있으니 미리 준비해 주세요.
확인이 어려우면 작업할 수 없습니다.

# 비용은 열기 전에 말씀드립니다
도어락 상태를 본 뒤 작업 전에 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
끝내 문을 열지 못하면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
진행 순서는 [이용안내](guide.html)에, 문을 상하지 않게 여는 방법은 [현관문 개문](door-open.html)에 정리했습니다.

# 열린 뒤 점검과 정전 대비
문이 열리면 건전지 교체, 번호 재등록, 작동 점검을 같이 합니다. / 정전에 취약한 제품이라면 비상 전원 방법을 알려드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 낡아서 정전마다 문제가 반복되면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드리고, 정말 필요할 때만 [도어락 교체](doorlock-replace.html)를 안내합니다.
@ 점검을 마친 도어락과 건전지

# 정전에 대비하는 작은 준비
- 건전지는 해마다 한 번 전부 교체
- 9V 건전지 하나를 현관 서랍에 비치
- 열쇠가 있는 도어락은 열쇠 위치를 가족이 알기
- 휴대폰 손전등을 쓸 수 있게 충전해 두기
- 점검 공지를 받으면 건전지 상태 먼저 확인
이 정도만 준비해도 정전에 문 앞에서 당황하는 일이 크게 줄어듭니다.

# 호계동 밖 안양 어디든 갑니다
호계동 가까이 부흥동, 평촌동, 비산동, 박달동도 다닙니다. / 안양 안이면 24시간 어느 동네든 출동합니다.
동네 정보는 [안양시 출장열쇠](anyang.html)에 있고, 서울과 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 밤에도 오시나요? | 24시간 전화를 받고 안양 전 지역을 다닙니다.
