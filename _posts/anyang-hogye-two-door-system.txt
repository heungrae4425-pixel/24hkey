# 호계동 현관이 이중문일 때 더 막막한 이유
호계동은 범계역 쪽을 오가며 생활하는 분들이 많은 동네입니다. / 현관에 방화문과 방풍문이 겹쳐 달린 집은 문이 한 겹일 때보다 상황이 복잡해집니다.
방화문은 도어락으로, 방풍문은 따로 달린 잠금장치로 잠겨 있는 경우가 많습니다. / 둘 중 어느 쪽이 안 열리는지 모르면 시작부터 헷갈립니다.
이 글은 안양 호계동에서 이중문이 잠겼을 때 문제를 가려내는 순서를 적었습니다. / 지금 문 앞에 서 계시다면 아래부터 차례로 보세요.
@ 호계동 방화문과 방풍문 이중 현관

# 이중문은 두 문이 따로 움직입니다
바깥쪽 문과 안쪽 문은 서로 다른 잠금장치를 씁니다. / 한쪽만 열리고 다른 쪽이 안 열리는 경우도 많습니다.
방풍문은 바람과 소음을 막기 위한 문이라 가벼운 잠금장치가 달려 있는 경우가 보통입니다. / 방화문은 도어락과 보조키가 달린 본 현관문인 경우가 많습니다.
방풍문은 입주할 때 따로 설치하거나 건물에 처음부터 달려 있기도 해서 열쇠 관리가 소홀해지기 쉽습니다. / 방화문 열쇠만 챙기고 방풍문 열쇠는 잃어버리는 일이 흔합니다.
겨울에는 방풍문이 바람을 막아 주는 만큼 자주 닫아 두고 지내는 집이 많습니다. / 그러다 보니 한밤에 문이 닫혀 잠기는 상황도 생깁니다.

# 어느 문에서 막혔는지부터 구분하세요
바깥쪽 문을 열고 들어왔는데 안쪽 문이 안 열리는 것과, 바깥쪽 문부터 안 열리는 것은 해결이 다릅니다. / 먼저 어느 문까지 열렸는지 정리해 보세요.
- 바깥 방풍문부터 안 열리는지
- 방풍문은 열렸는데 안쪽 방화문이 안 열리는지
- 번호판은 켜지는데 걸쇠만 안 빠지는지
- 방풍문과 방화문 사이 공간에 갇혀 있는지

# 방풍문 열쇠 구멍이 막혔을 때
방풍문 잠금장치는 열쇠로 여는 단순한 형태가 흔합니다. / 오래 쓰면 먼지와 녹으로 열쇠가 잘 안 돌아갑니다.
이럴 때 무리하게 힘을 주면 열쇠가 휘거나 구멍 안에서 부러질 수 있습니다. / 한 번 부러지면 해결이 어려워지니 돌아가지 않으면 멈추세요.
열쇠를 꽂았는데 반 정도만 들어가고 더 안 들어가면 구멍 안에 이물질이 있는 경우입니다. / 열쇠를 여러 번 빼고 꽂는 사이 먼지가 더 밀려들어가 막히기도 하니 반복은 피하세요.
방풍문이 열쇠 대신 걸쇠 형태라면 문을 살짝 들어 올리듯 밀어 보는 것도 방법입니다. / 걸쇠가 문틀에 눌려 빠지지 않는 경우에 효과가 있기도 합니다.
@ 호계동 방풍문 열쇠 구멍 점검

# 방풍문과 방화문 사이 보조키
두 문 사이에서 방화문의 보조키가 잠겨 있는 경우가 있습니다. / 안쪽에서 보조키를 잠그고 나왔다면 바깥 번호가 맞아도 문이 열리지 않습니다.
보조키가 걸려 있는지 확인하려면 번호를 입력했을 때 모터 소리가 나는지 들어보세요. / 모터는 돌아가는데 문이 안 열리면 보조키를 의심할 수 있습니다.
보조키 관련 내용은 [출장열쇠 부르기](key-call.html)에서도 상황별로 볼 수 있습니다.

# 이중문 사이에 갇혔을 때
방풍문이 닫혀 뒤에서 잠기고 안쪽 방화문도 안 열려 두 문 사이에 서 있게 되는 일이 있습니다. / 이럴 때 가장 중요한 것은 당황하지 않고 폰이 있는지 확인하는 것입니다.
폰이 있다면 연락해서 상황과 위치를 알려 주세요. / 폰이 집 안에 있다면 이웃에게 부탁해 전화를 빌려 연락해도 됩니다.
혼자 문틈을 벌리거나 힘으로 밀지 마세요. / 문틀과 잠금장치가 상하면 열고 나서도 고쳐야 합니다.
두 문 사이 공간은 좁고 어두워 휴대폰 손전등을 켜고 문 상태를 살피면 도움이 됩니다. / 어디가 걸렸는지 눈으로 보고 설명하면 상담이 훨씬 수월합니다.

# 하지 말아야 할 것
두 문 모두 한꺼번에 힘으로 당기거나 발로 차는 분이 있습니다. / 문이 휘고 도어락이 틀어져 해결이 더 어려워집니다.
드라이버나 카드로 방풍문 틈을 벌리는 일도 피해 주세요. / 방풍문 틀은 얇아서 쉽게 상합니다.
비밀번호를 여러 번 틀리면 방화문 도어락이 입력을 막을 수 있습니다. / 서너 번 해보고 안 되면 멈추는 게 좋습니다.

# 전화하실 때 알려 주실 것
이중문은 상황 설명이 구체적일수록 준비가 빨라집니다. / 어느 문에서 막혔는지, 두 문 사이에 있는지를 꼭 알려 주세요.
- 아파트나 빌라의 동과 호수
- 방풍문이 안 열리는지, 방화문이 안 열리는지
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 방풍문 잠금장치가 열쇠식인지 걸쇠식인지
- 집 안에 아이나 반려동물이 있는지
사진을 보내 주시면 맞는 장비를 챙겨 가기 좋습니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두면 수월합니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
이중문은 두 곳을 모두 볼 수 있으니 어디까지 작업해야 하는지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)와 [현관문 개문](door-open.html)에도 적어 두었습니다.
@ 호계동 출장열쇠 이중문 개방 작업

# 열고 난 뒤 이중문 점검
문이 열리면 두 문이 각각 제대로 잠기고 열리는지 확인합니다. / 방풍문 잠금장치가 낡았다면 고쳐 쓸 수 있는지 먼저 봅니다.
방화문 도어락이 말썽이면 [도어락 수리](doorlock-repair.html)를 권하고, 너무 오래된 경우에만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
방풍문 열쇠는 한 벌 더 만들어 두면 급할 때 도움이 됩니다.

# 이중문 집에서 평소 해 둘 것
- 방풍문 열쇠 복사본을 가족이 각자 하나씩 갖기
- 방풍문 열쇠 구멍에 먼지가 끼지 않게 가끔 닦기
- 문 사이 공간에 물건을 쌓아 두지 않기
- 보조키를 잠그고 나가는 습관이 있다면 가족에게 알리기
- 방화문 도어락 배터리를 해마다 갈기
문 사이 공간은 신발이나 우산이 쌓이기 쉬운데 이것이 문 닫힘을 방해하기도 합니다.
방풍문이 바람에 세게 닫히며 잠기는 구조라면 문 밖에 나갈 때 문을 살짝 잡아 두는 습관도 도움이 됩니다. / 열쇠를 들고 나가는지 한 번 더 확인하는 것도 잊지 마세요.
가족 모두가 이중문 구조를 알고 있도록 한 번쯤 같이 점검해 보시길 권합니다.

# 호계동 말고 안양 어디든 갑니다
평촌동, 비산동, 관양동, 귀인동, 부흥동, 안양동, 석수동, 박달동까지 안양 전 지역을 다닙니다. / 평촌역이나 인덕원역 근처에서도 24시간 연락 주실 수 있습니다.
다니는 곳은 [안양시 출장열쇠](anyang.html)와 [출장 지역](area.html)에서 볼 수 있습니다.
