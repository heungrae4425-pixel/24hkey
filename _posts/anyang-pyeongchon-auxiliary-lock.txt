# 평촌동 현관에서 문이 한 뼘도 안 움직일 때
평촌동은 범계역과 평촌역 사이로 생활권이 이어져서 퇴근 시간이면 문 앞에서 열쇠를 꺼내는 사람이 많은 동네입니다. / 번호를 눌러 도어락이 열리는 소리가 났는데 문이 움직이지 않는다면 보조키나 걸쇠를 먼저 의심해 보세요.
도어락은 멀쩡한데 문이 꿈쩍도 안 하는 경우가 생각보다 흔합니다. / 이 글은 평촌동에서 그런 일이 생겼을 때 보조키가 어떻게 잠기는지, 어디까지 직접 해볼 수 있는지, 언제 [안양 출장열쇠](anyang.html)를 부르면 되는지를 순서대로 적었습니다.
@ 평촌동 보조키 잠김 현관문 출장열쇠

# 보조키와 걸쇠는 서로 다른 장치입니다
현관문에는 보통 두 겹의 잠금이 있습니다. / 손잡이 아래쪽 도어락이 주 잠금이고, 그 위나 아래에 붙은 작은 열쇠 구멍이나 돌림 손잡이가 보조키입니다.
걸쇠는 문을 열어 둔 채로 고정하거나 반쯤 열린 상태에서 막아 주는 체인 형태의 장치입니다. / 안에서만 걸 수 있는 구조라서 밖에서 번호를 눌러도 해제되지 않습니다.
두 장치를 구분하면 문이 왜 안 열리는지 훨씬 빨리 알 수 있습니다. / 전화로 설명할 때도 어느 쪽이 걸렸는지 말해 주시면 챙겨 갈 장비가 달라집니다.

# 나갈 때 보조키를 잠가 버리는 순간
집을 나서면서 습관처럼 보조키를 돌려 잠그는 분이 있습니다. / 열쇠를 들고 나왔다면 문제가 없지만, 열쇠 없이 번호만 믿고 나왔다가 문 앞에서 막히는 일이 생깁니다.
아이를 안고 나오거나 택배를 들고 서두르다 보면 손이 먼저 움직여 잠가 버리기도 합니다. / 이런 경우 도어락은 정상이라 번호판이 불이 들어오고 소리도 나는데 문만 안 열립니다.
보조키가 잠긴 걸 확인하는 방법은 간단합니다. / 번호를 누르고 손잡이를 돌렸을 때 문이 아주 살짝 덜컥거리다 멈추면 윗부분 보조키가 걸려 있을 가능성이 큽니다.

# 번호는 맞는데 안 열린다면 이 순서로
급할수록 순서를 지키는 게 좋습니다. / 아래 항목을 차례로 확인하면 불필요하게 문을 건드리는 일을 줄일 수 있습니다.
- 번호를 한 번 더 천천히 눌러 보고 열림 소리가 나는지 확인
- 손잡이를 돌리면서 문을 안쪽으로 살짝 밀어 보기
- 문틈으로 윗부분과 아랫부분 어느 쪽이 걸리는지 눈으로 보기
- 보조키 구멍에 맞는 열쇠가 가방이나 주머니에 있는지 찾기
열쇠가 있다면 보조키 구멍에 넣어 돌려서 풀면 끝납니다. / 열쇠가 없다면 더 이상 힘을 주지 말고 다음 단계로 넘어가세요.

# 힘으로 당기면 오히려 일이 커집니다
문틈에 얇은 카드를 넣어 걸쇠를 밀어 보려는 분이 있습니다. / 도어락 쪽 걸쇠는 모양이 달라서 카드로 열리지 않고, 문틀 도장이 벗겨지거나 카드만 부러지기 쉽습니다.
손잡이를 세게 잡아당기면 래치가 비틀려서 나중에는 평소에도 뻑뻑해집니다. / 발로 차는 방법은 문틀을 휘게 하니 절대 피해 주세요.
@ 평촌동 현관문 걸쇠 걸림 비파손 개방

# 안에 사람이 있는데 걸쇠가 걸렸다면
가족이 집 안에 있는데 걸쇠가 걸려 밖에서 못 들어가는 상황도 있습니다. / 이때는 안에 있는 분께 걸쇠를 풀어 달라고 부탁하는 것이 가장 빠릅니다.
안에 계신 분이 거동이 불편하거나 아이만 있다면 말로 설명하기 어렵습니다. / 그런 경우에는 문을 상하지 않게 여는 방법을 쓰니 상황을 그대로 알려주세요.
특히 안에서 연락이 안 되면 바로 119가 필요한 상황일 수도 있으니 먼저 안부를 확인하는 게 우선입니다.

# 평촌동 위치와 상황을 알려주는 요령
평촌동은 범계역 쪽과 평촌역 쪽에서 들어가는 길이 달라서 대략적인 방향을 알려주시면 도착이 빨라집니다. / 전화로는 아래 정보만 알려주셔도 충분합니다.
- 아파트나 빌라 이름이 아닌 도로명 주소와 동, 호수
- 범계역 쪽인지 평촌역 쪽인지 대략적인 방향
- 보조키가 잠겼는지, 걸쇠가 걸렸는지, 둘 다인지
- 번호판이 켜지는지와 열림 소리가 나는지
도어락과 보조키가 같이 보이는 사진을 문자로 보내 주시면 장비를 정확히 챙겨 갈 수 있습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
보조키까지 잠긴 문을 여는 일이니 사시는 분이 맞는지 꼭 먼저 확인합니다. / 신분증 주소, 주소가 찍힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있다면 휴대폰으로 받은 고지서나 택배 송장 주소도 참고가 됩니다. / 그래도 어렵다면 관리사무소나 경비실에 세대 확인을 부탁하는 방법이 있습니다.
이 절차 없이 문을 열어드리는 일은 없습니다. / 이웃의 집을 지키는 일이기도 하니 이해 부탁드립니다.

# 열기 전에 비용부터, 못 열면 비용 없음
현관문과 보조키 상태를 보고 어떻게 열지, 비용이 얼마쯤인지 열기 전에 먼저 말씀드립니다. / 괜찮다고 하셔야 작업을 시작합니다.
끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 설명 없이 더해지는 항목도 없습니다.
교체가 필요한 부품이 보이면 손대기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 보조키는 이렇게 비파손으로 풉니다
보조키는 구조가 단순한 편이라 문과 잠금장치가 상하지 않는 방법을 먼저 씁니다. / 손잡이와 문틀 사이 간격, 잠금 방향을 살펴본 뒤 가장 덜 건드리는 방법부터 차례로 시도합니다.
걸쇠가 문틀 쪽에 걸린 경우는 문 틈새 각도를 조정하며 풀어 줍니다. / 문틀에 긁힌 자국이 남지 않게 보호하면서 진행합니다.
어떤 순서로 여는지는 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.
@ 평촌동 보조키 비파손 개방 작업

# 연 뒤에 꼭 확인하는 세 가지
문이 열린 다음에는 보조키와 도어락이 제대로 움직이는지 함께 봅니다. / 한 번 무리가 간 장치는 며칠 뒤에 다시 문제가 되기도 합니다.
- 보조키가 걸림 없이 돌아가는지
- 도어락 래치가 문틀에 정확히 맞물리는지
- 걸쇠 고정 부분의 나사가 헐거워지지 않았는지
보조키 열쇠를 잃어버려 열린 경우에는 [열쇠 분실 출장](key-call.html) 안내를 참고해 새 열쇠를 만드는 방법도 말씀드립니다. / 도어락 자체에 이상이 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.

# 보조키로 막히는 일을 줄이는 습관
짧은 외출이라도 보조키는 열쇠를 가지고 있을 때만 잠그는 걸 습관으로 삼으면 좋습니다. / 열쇠를 도어락 번호와 똑같이 하나의 물건처럼 챙기는 것도 방법입니다.
가족이 여럿이라면 현관 안쪽에 보조키를 잠그는 규칙을 정해 두세요. / 누가 마지막에 나가는지에 따라 잠금 여부가 달라지면 서로 헷갈립니다.
현관 근처에 잘 보이는 곳에 열쇠를 걸어 두거나 가방에 스페어 하나를 항상 넣고 다니는 것도 도움이 됩니다.

# 평촌동 말고 안양 곳곳도 갑니다
평촌동뿐 아니라 비산동, 관양동, 호계동, 귀인동, 부흥동, 안양동, 석수동, 박달동도 다닙니다. / 인덕원역 쪽과 안양역 쪽 모두 같은 방식으로 출동합니다.
안양 전체 안내는 [안양시 출장열쇠](anyang.html)에서, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
