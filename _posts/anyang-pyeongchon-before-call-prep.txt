# 전화를 걸기 전 3분이 도착 시간을 줄입니다
평촌동은 평촌역과 범계역을 오가는 분이 많은 생활권입니다. / 퇴근길이나 밤늦은 시간에 문 앞에서 막히면 마음이 급해져 설명이 뒤죽박죽 되기 쉽습니다.
출장열쇠를 부를 때는 전화 한 통에 얼마나 정확히 상황을 전하느냐가 도착과 작업 시간을 좌우합니다. / 이 글은 전화하기 전에 준비해 두면 좋은 것들을 순서대로 정리한 글입니다.
급하실 때는 위쪽 항목만 보고 바로 전화하셔도 괜찮습니다. / 나머지는 시간이 있을 때 천천히 읽어 보세요.

# 가장 먼저 지금 계신 곳이 안전한지 보세요
문 앞이 어두운 계단이거나 비가 오는 날이라면 먼저 안전한 곳을 찾으세요. / 건물 로비나 1층 공동현관 안쪽처럼 앉을 수 있는 곳이 좋습니다.
짐이 많거나 아이를 안고 있다면 이웃이나 경비실에 잠시 맡겨도 됩니다. / 기다리는 시간이 길어질수록 몸이 지치니 편한 자세부터 만들어 주세요.
휴대폰 배터리가 얼마 안 남았다면 통화를 짧게 하고 문자를 활용하는 게 좋습니다. / 충전 가능한 곳이 가까이 있으면 연락 전에 먼저 충전해 두세요.
@ 평촌동 출장열쇠 부르기 전 준비

# 잠긴 상태를 한 줄로 말해 보기
전화할 때 가장 도움이 되는 건 지금 어떤 상태인지 한 줄로 정리하는 것입니다. / 예를 들어 번호판이 꺼졌다, 번호는 맞는데 안 열린다, 열쇠를 안에 두고 나왔다처럼 짧게 말씀하시면 됩니다.
원인을 몰라도 괜찮습니다. / 보이는 대로만 말씀하시면 나머지는 질문하면서 좁혀 가겠습니다.
- 번호판 불이 켜지는지 꺼졌는지
- 눌렀을 때 소리가 나는지
- 열쇠를 안에 두었는지 잃어버렸는지
- 안쪽에서 보조키를 잠갔을 가능성이 있는지

# 도어락 사진은 이렇게 찍어 주세요
문자로 사진을 보내 주시면 장비를 맞춰 챙겨 가기 쉽습니다. / 어렵게 생각하지 마시고 아래 정도만 찍어 보내 주세요.
- 문 바깥에서 도어락 전체가 보이는 사진
- 번호판과 손잡이를 가까이서 찍은 사진
- 제품명이나 모델명이 보이면 그 부분
- 열쇠 구멍이 있으면 구멍이 보이게 찍은 사진
어두운 곳이라면 휴대폰 손전등을 켜고 찍어 주세요. / 흔들려도 괜찮으니 일단 보내 주시면 됩니다.

# 위치는 건물 이름보다 찾아가는 길로
평촌동은 건물이 많아 입구가 여러 개인 곳이 있습니다. / 정확한 동과 호수는 기본이고, 어느 입구로 들어오면 되는지 한마디 더해 주시면 도착이 빨라집니다.
공동현관 비밀번호가 필요한 곳이면 미리 알려 주시거나 문을 열어 줄 수 있는 분을 알려 주세요. / 공동현관에서 막히면 문 앞까지 오는 데 시간이 걸립니다.
평촌역이나 범계역 쪽에서 오는 방향인지, 반대편인지도 알려 주시면 길 안내에 도움이 됩니다. / 지도 앱의 위치를 문자로 보내 주시는 것도 좋은 방법입니다.

# 집 안에 사람이나 동물이 있는지
아이나 반려동물이 안에 있다면 꼭 먼저 말씀해 주세요. / 일반 상황보다 우선해서 움직이게 됩니다.
가스 불이나 전기 제품을 켜 둔 채 나왔다면 그것도 알려 주세요. / 이 경우는 지체하지 말고 상황을 짚어 드려야 합니다.
혼자 사시는 분이 다른 가족에게 연락할 수 있는지도 같이 확인하면 좋습니다. / 신분 확인이나 주소 확인에 도움이 될 때가 있습니다.

# 신분 확인 준비물을 미리 챙겨 두세요
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있는 경우가 많습니다. / 그럴 때는 휴대폰에 있는 우편물 사진이나 관리사무소 연락처를 준비해 주세요.
세입자라면 계약서보다 우편물이나 관리사무소 확인이 더 빠를 때가 많습니다. / 확인이 어려우면 작업이 어려운 점은 미리 말씀드립니다.
@ 평촌역 근처 출장열쇠 신분 확인

# 하지 말아야 할 것 몇 가지
기다리는 동안 괜히 손대서 일이 커지는 경우가 있습니다. / 아래만 피해 주시면 됩니다.
- 드라이버나 카드로 문틈을 벌리는 것
- 손잡이를 세게 당기거나 문을 발로 차는 것
- 비밀번호를 계속 반복해서 누르는 것
- 인터넷에서 본 방법을 문에 시험해 보는 것
이런 시도는 도어락과 문틀이 상할 수 있어 나중에 수리가 더 커집니다. / 전화부터 주시는 편이 훨씬 낫습니다.

# 비용은 시작하기 전에 말씀드립니다
문 상태와 도어락 종류를 확인한 뒤 비용을 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
전화로 대략적인 방향은 말씀드릴 수 있지만 정확한 비용은 문을 직접 보고 정해집니다. / 같은 도어락이라도 문 두께, 잠금 방식, 걸린 정도에 따라 작업이 달라지기 때문입니다.
미리 알려 주신 정보가 많을수록 현장에서 달라지는 부분이 적어집니다. / 그래서 위의 사진과 상태 설명이 비용 안내에도 도움이 됩니다.
@ 평촌동 도어락 개문 비용 안내

# 도착하면 이런 순서로 진행합니다
도착하면 먼저 신분 확인을 하고 문과 도어락 상태를 눈으로 봅니다. / 그다음 방법과 비용을 말씀드리고 동의하시면 작업을 시작합니다.
문이 상하지 않는 방법부터 차례로 해보고, 작업 중에 바꿔야 할 부품이 보이면 미리 말씀드립니다. / 문을 여는 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
열린 뒤에는 도어락이 다시 잘 잠기는지, 건전지는 괜찮은지 같이 확인합니다. / 필요하면 새 번호도 등록해 드립니다.

# 열고 난 뒤 다음에 대비할 것
문이 열렸다고 끝내지 말고 같은 일이 다시 생기지 않게 정리해 두세요. / 건전지 교체일 적어 두기, 비상 열쇠 위치 정하기 같은 작은 일들입니다.
고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 손볼 수 있는지 봅니다. / 너무 오래된 제품이라면 그때 교체를 말씀드립니다.
집을 비우는 가족이 있다면 번호를 함께 다시 정해 두는 것도 좋습니다. / 공유하는 사람이 많을수록 정기적으로 정리하는 것이 안전합니다.
이번 일을 겪으셨다면 휴대폰 메모에 도어락 모델명과 건전지 종류를 적어 두세요. / 다음에 같은 일이 생겨도 전화 한 통으로 훨씬 빨리 정리됩니다.

# 평촌동 말고 안양 어디든 갑니다
평촌동 바로 옆 관양동, 비산동, 귀인동, 호계동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
