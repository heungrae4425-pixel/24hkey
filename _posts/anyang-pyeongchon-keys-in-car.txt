# 열쇠는 차 안에, 나는 현관 앞에
평촌동은 범계역과 평촌역 생활권이라 차를 타고 장을 보거나 아이를 데리러 오가는 일이 흔한 동네입니다. / 장을 보고 돌아와 주차를 하고 짐을 내리다 보면 열쇠를 차 안에 두는 일이 생각보다 자주 있습니다.
차 문이 닫히면서 같이 잠겨 버리면 집 열쇠도, 차 열쇠도 한꺼번에 막힙니다. / 이 글은 그런 날 집 현관 쪽을 어떻게 풀어야 하는지 순서대로 정리했습니다.
차 문 개방은 자동차 서비스 쪽 일이고, 여기서는 집 현관문 대응에 집중합니다. / 현관이 막혀 급하시면 [안양 출장열쇠](anyang.html)에 먼저 전화해도 됩니다.
@ 평촌동 차 안 열쇠 현관 잠김

# 먼저 숨을 고르고 상황을 나눠 보세요
같은 열쇠 문제처럼 보여도 상황은 세 가지로 나뉩니다. / 어느 쪽인지에 따라 해야 할 일이 달라집니다.
- 집 열쇠만 차 안에 있고 현관은 도어락 번호로 열 수 있는 경우
- 집 열쇠와 도어락 카드가 모두 차 안에 있는 경우
- 현관 보조키까지 잠그고 나와 열쇠 없이는 못 들어가는 경우
첫 번째라면 사실 열쇠가 필요 없는 상황이니 현관은 해결된 것입니다. / 두 번째와 세 번째가 본문의 중심입니다.

# 번호키로 열 수 있는지부터 눌러 보기
요즘 현관은 번호나 지문으로 열리는 곳이 많습니다. / 열쇠가 없어도 번호를 누르면 되는지부터 확인하세요.
번호는 알지만 열쇠로 열던 분이라면 오랜만에 번호를 눌러 보며 헷갈릴 수 있습니다. / 천천히 한 글자씩 눌러 보고 서너 번 안 되면 멈추세요.
번호판이 꺼져 있으면 배터리 문제일 수 있으니 바깥 아래쪽 비상 단자에 9V 건전지를 대 보는 방법이 있습니다.

# 가족에게 열쇠가 있는지 연락하기
가장 빠른 길은 집에 있는 가족이 문을 열어 주는 것입니다. / 같은 동네에 사는 가족이 여분 열쇠를 가지고 있다면 전달받는 방법도 있습니다.
연락이 닿는 사람이 없을 때는 관리사무소나 경비실에 도움을 청해 보세요. / 세대 확인 정도는 해 주는 곳이 많습니다.
이웃과 가볍게 인사를 나눈 사이라면 전화를 한 통 빌리는 것도 방법입니다.

# 차 문을 따로 열 방법 알아보기
차 문은 보험 가입 시 긴급출동 서비스로 처리해 주는 경우가 많습니다. / 먼저 본인 보험사나 자동차 제조사의 긴급 서비스 번호를 확인해 보세요.
차 열쇠를 꺼내면 집 열쇠도 같이 해결되므로, 차 문을 먼저 해결하는 것이 빠른 경우도 있습니다. / 다만 시간이 걸린다면 현관 쪽을 먼저 진행해도 괜찮습니다.
차 문을 억지로 열려다 유리나 문틀을 상하게 하는 일은 피하세요.
차 안에 아이나 반려동물이 있다면 지체하지 말고 바로 119나 긴급 서비스에 연락하세요. / 이 경우는 현관보다 차가 먼저입니다.
@ 평촌동 현관 열쇠 분실 대응

# 현관을 먼저 열어야 하는 이유
차 열쇠를 꺼내는 데 시간이 걸린다면 집 안에서 기다리는 것이 편한 날이 많습니다. / 추운 겨울이나 비 오는 날에는 더 그렇습니다.
집 안에는 휴대폰 충전기, 여분 열쇠, 신분증이 있을 수 있어 차 문 문제도 쉽게 풀리는 경우가 있습니다. / 현관을 연 뒤에 차 문을 처리하는 것이 순서가 편하기도 합니다.
아이나 반려동물이 집 안에 있다면 현관 쪽이 우선입니다. / 이 경우는 전화로 꼭 먼저 말씀해 주세요.

# 하면 안 되는 급한 행동
열쇠가 없어 막막하면 이웃의 사다리를 빌려 베란다로 올라가려는 분도 있습니다. / 아주 위험하니 절대 하지 마세요.
- 현관문을 발로 차거나 어깨로 밀기
- 문틈에 카드나 얇은 철사를 넣어 비틀기
- 도어락을 분해하려고 나사 풀기
- 번호를 계속 바꿔 연속으로 누르기
문과 도어락이 상하면 열쇠 문제보다 비용이 더 커질 수 있습니다. / 안전하게 여는 방법이 따로 있으니 멈추는 것이 맞습니다.

# 출장열쇠를 부를 때 알려주실 것
전화로 몇 가지만 알려주시면 도착이 빨라집니다. / 현관 앞 상황을 짧게 말씀해 주세요.
- 평촌동 안에서 대략 어느 쪽인지와 건물 입구 위치
- 도어락 모양(손잡이 일체형, 푸시풀형, 번호키 외 보조키 유무)
- 지금 번호판이 켜지는지, 소리가 나는지
- 집 안에 사람이나 반려동물이 있는지
- 차는 어디에 세웠는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙기기 좋습니다.

# 도착하면 먼저 확인하는 것
24시출장열쇠는 도착하면 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 차 안에 있어서 못 보여주는 경우가 이 상황의 가장 흔한 어려움입니다. / 관리사무소에 세대 확인을 부탁하거나 가족이 사진으로 주소를 보여주는 방법도 상의해 드립니다.
확인이 어려우면 작업을 할 수 없으니 미리 방법을 떠올려 두세요.

# 비용과 방식은 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 그때 시작하고, 아니라면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
도어락이나 문을 덜 상하게 여는 방법부터 차례로 하고, 부품을 바꿔야 하면 바꾸기 전에 여쭙니다. / 방법은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.
@ 평촌동 24시 출장열쇠 현관문 개문

# 문이 열린 뒤 다시 막히지 않게
문이 열리면 안에서 여분 열쇠가 어디 있는지 먼저 찾아 보세요. / 한 개는 가족에게, 한 개는 집 안 서랍에 두는 것이 안전합니다.
열쇠를 자주 차 안에 두는 습관이 있다면 열쇠고리를 차 키와 분리하는 방법도 있습니다. / 차에서 내릴 때 휴대폰과 열쇠를 손에 쥐는 습관이 가장 간단합니다.
도어락 카드는 지갑에, 열쇠는 가방 안주머니처럼 두 곳에 나눠 두면 한 곳을 놓쳐도 곤란이 줄어듭니다.
열쇠가 따로 필요하다면 [열쇠 출장](key-call.html) 안내를 참고해 여분 열쇠에 대해서도 물어보세요.
여분 열쇠는 한 번 만들어 두면 이런 날 가장 든든합니다. / 만들 때는 원본 열쇠 모양이 상하지 않았는지도 같이 확인합니다.

# 번호키로 바꾸는 것도 고려해 볼 만합니다
열쇠를 들고 다니는 일이 번거롭다면 번호나 카드로 여는 도어락도 선택지입니다. / 열쇠가 필요 없으니 이런 상황이 훨씬 줄어듭니다.
교체 전에는 문 두께와 보조키 위치를 먼저 확인해야 합니다. / 자세한 순서는 [도어락 설치](doorlock-install.html)와 [도어락 교체](doorlock-replace.html) 페이지에서 확인할 수 있습니다.

# 평촌동 말고 안양 어디든 갑니다
평촌동 근처 관양동, 비산동, 호계동, 귀인동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
[출장 지역](area.html)과 [이용안내](guide.html)에서 지역과 진행 방식을 볼 수 있습니다.

# 자주 묻는 질문
? 차 문도 열어 주나요? | 현관문과 집 안 문 위주로 안내드립니다. 차 문은 보험사나 자동차 서비스 확인이 먼저입니다.
? 신분증이 차 안에 있는데 괜찮을까요? | 주소가 나온 우편물이나 관리사무소 확인으로도 가능합니다. 상황을 말씀해 주세요.
? 밤에 주차장에서 연락해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 못 열면 비용은 어떻게 되나요? | 끝내 못 열면 비용은 받지 않습니다.
? 열쇠가 없는데 문이 상하나요? | 덜 상하는 방법부터 차례로 하고, 바꿔야 할 부품이 있으면 먼저 말씀드립니다.

혼자 문을 상하게 하며 버티지 마시고 전화 주시면 됩니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455입니다.
