# 평촌동에서 문이 닫히다 마는 경우
평촌동은 평촌역과 범계역 사이를 오가는 분들이 많은 아파트 생활권입니다. / 현관문을 하루에도 여러 번 여닫는 집이 많다 보니 문이 덜 닫히는 증상도 자주 접수됩니다.
문을 밀어 닫았는데 철컥 소리 없이 튕겨 나오거나, 닫힌 것 같은데 손잡이를 돌리면 그냥 열리는 경우입니다. / 대개 문 옆면에서 나왔다 들어갔다 하는 래치(걸쇠)가 제대로 움직이지 않아서 생깁니다.
이 글은 래치가 들어가지 않을 때 확인할 순서와 [평촌 출장열쇠](anyang.html)를 부르는 때를 정리했습니다.
@ 평촌동 현관문 옆면 래치 걸쇠 상태

# 래치가 무엇이고 왜 걸리는지
래치는 문 옆면에 튀어나온 사선 모양의 금속 부품입니다. / 문이 닫힐 때 문틀의 받침 구멍에 맞춰 들어갔다가 다시 나와 문을 붙잡아 줍니다.
이 부품이 들어가지 않으면 문이 닫히지 않고, 나온 채로 걸리면 문을 열 수 없습니다. / 그래서 같은 래치 문제가 두 가지 증상으로 나타납니다.
- 래치가 안 들어가서 문이 닫히지 않는다
- 래치가 안 나와서 문이 저절로 열린다
- 래치가 걸려서 손잡이를 돌려도 안 열린다

# 눈으로 보고 손으로 눌러 보기
문을 열어 둔 채 옆면의 래치를 손가락으로 눌러 보세요. / 부드럽게 들어갔다가 스스로 튀어나오면 래치 자체는 괜찮은 편입니다.
눌러도 뻑뻑하거나 안 들어가면 내부 스프링이나 먼지, 이물질 문제일 수 있습니다. / 눌렀는데 들어간 채로 안 나오면 부품이 걸린 것입니다.
무리하게 드라이버로 비틀면 래치 머리가 구부러질 수 있으니 힘을 주지 마세요.

# 문틀 쪽 받침 구멍도 같이 봅니다
래치만 보지 말고 문틀 쪽 구멍도 같이 확인해야 합니다. / 문이 조금 처져서 래치와 구멍의 높이가 어긋나면 래치가 닿아도 들어가지 못합니다.
문틀의 받침판에 페인트나 먼지가 쌓여 구멍이 좁아진 경우도 있습니다. / 마른 휴지로 닦아 내고 다시 닫아 보면 가볍게 해결되기도 합니다.
받침판의 위치가 래치와 어긋나 보이면 문이 처진 것이니 경첩 상태를 봐야 합니다.
@ 평촌동 현관 문틀 받침판 구멍 위치

# 닫으면서 손잡이를 같이 눌러 보기
문을 닫을 때 손잡이를 아래로 누른 상태로 닫아 보세요. / 래치가 완전히 들어간 상태에서 문이 닫히므로 걸림이 있는지 알 수 있습니다.
이때 닫히면 래치나 구멍이 약간 어긋난 것이고, 그래도 안 닫히면 문이 많이 처졌거나 부품이 상한 것입니다.
손잡이를 놓았을 때 래치가 문틀 구멍에 부드럽게 들어가야 정상입니다. / 이 과정에서 걸리는 소리가 나면 어디서 걸리는지 기억해 두었다가 알려주세요.

# 문 안쪽에 갇혔거나 밖에서 못 들어갈 때
래치가 안 들어가거나 안 나오는 상태로 문이 걸려 열리지 않는 일도 있습니다. / 이럴 때는 손잡이를 돌리며 문을 앞뒤로 살짝 밀고 당기면 풀리기도 합니다.
그래도 안 열리면 더 힘을 주지 마세요. / 래치가 문틀 구멍에 끼어 있으면 힘을 줄수록 더 꽉 끼게 됩니다.
문 안쪽에 아이가 혼자 있는 상황이라면 놀라지 않게 문 너머로 계속 말을 걸어 주세요. / 이 경우는 꼭 먼저 말씀해 주시면 우선 출동합니다.

# 도어락 때문인지 문 때문인지 구분하기
래치가 걸리는 원인은 도어락 몸체 쪽일 수도, 문과 문틀 쪽일 수도 있습니다. / 구분하는 요령을 알면 어느 쪽을 손봐야 하는지 가닥이 잡힙니다.
- 번호를 눌렀을 때 모터 소리가 나는지
- 열쇠로 돌리면 래치가 들어가는지
- 손잡이를 돌려도 래치가 같이 움직이는지
- 문을 약간 들어 올리듯 당기면 닫히는지
열쇠로는 들어가는데 손잡이로는 안 들어가면 손잡이 쪽 연결이 헐거운 경우입니다.

급한 마음에 카드를 틈새에 넣어 래치를 밀려는 분이 있습니다. / 도어락 외관이 긁히고 래치 머리가 상할 수 있습니다.
문틀 받침판을 망치로 두드리거나 문을 발로 차는 것도 피해 주세요. / 문틀이 틀어지면 처음보다 일이 커집니다.
기름을 많이 뿌리는 것도 좋지 않습니다. / 먼지가 엉겨 붙어 더 뻑뻑해질 수 있으니 그대로 두고 연락 주세요.

# 출장열쇠를 불러야 하는 때
혼자 눌러 보고 닦아 봐도 래치가 움직이지 않으면 부품 문제일 가능성이 큽니다. / 문이 닫히지 않는 채로 집을 비워 두기는 불안하니 되도록 빨리 연락 주세요.
전화로 래치가 안 들어가는지, 안 나오는지, 문이 열리는지 안 열리는지를 알려주시면 좋습니다. / 도어락 모양과 문 옆면 사진을 문자로 보내 주시면 준비하는 데 도움이 됩니다.
[출장열쇠 이용 안내](key-call.html)에서 전화할 때 알려주실 내용을 정리해 두었습니다.

# 도착하면 사시는 분인지 확인합니다
문을 열거나 손보는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 경비실이나 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문과 래치 상태를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우에는 바꾸기 전에 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 평촌동 래치 점검 작업 모습

# 래치를 고칠지 도어락을 바꿀지
래치만 닳았거나 걸린 경우에는 해당 부분만 손보면 되는 일이 많습니다. / 도어락 전체를 바꾸는 것은 마지막 선택입니다.
도어락이 너무 오래되었거나 내부 부품까지 상했다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 먼저 [도어락 수리](doorlock-repair.html)로 해결되는지부터 봅니다.
문이 처져서 생긴 문제라면 도어락을 바꿔도 같은 일이 되풀이되니 문 쪽을 같이 봐야 합니다.

# 열고 난 뒤 확인할 것과 관리
문이 닫히고 잠기고 열리는 것을 몇 번 반복해서 확인합니다. / 래치가 매끄럽게 들락거리는지 소리와 감각으로도 함께 봅니다.
평소 관리 요령도 적어 둡니다.
- 문 옆면 래치 부근을 마른 천으로 가끔 닦기
- 문이 덜 닫히기 시작하면 바로 점검
- 문을 세게 닫지 말고 끝까지 부드럽게 닫기
- 이상한 소리가 나면 미루지 않고 연락
[문 여는 방식](door-open.html) 안내도 함께 보시면 도움이 됩니다.

# 평촌동 말고 안양 어디든 갑니다
평촌동 가까이 비산동, 관양동, 호계동, 귀인동, 부흥동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
