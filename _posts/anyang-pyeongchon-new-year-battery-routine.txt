# 평촌동 현관 앞에서 막히기 전에
평촌동은 평촌역과 범계역 사이 생활권으로 출퇴근하는 분들이 많은 동네입니다. / 아침에 서두르다 보면 도어락 상태를 눈여겨볼 틈이 별로 없습니다.
도어락은 갑자기 고장 나는 것처럼 보여도 대부분 미리 신호를 보냅니다. / 그 신호를 놓치지 않게 달력에 점검일을 정해 두자는 것이 이 글의 요지입니다.
[안양 출장열쇠](anyang.html)를 부르는 일이 줄어드는 것이 가장 좋은 결과입니다. / 그래서 이번 글은 고장 난 뒤가 아니라 고장 나기 전의 습관을 다룹니다.
@ 평촌동 도어락 점검 루틴 안내

# 왜 하필 연초와 분기인가
한 해의 첫 주는 다른 일정이 정리되는 때라 점검일로 잡기 좋습니다. / 마음먹기 쉬운 날을 기준 삼으면 습관이 오래 갑니다.
여기에 분기마다 한 번씩 가볍게 보는 날을 더하면 사이가 너무 벌어지지 않습니다. / 계절이 바뀌는 때와 맞추면 기억하기도 쉽습니다.
- 연초: 배터리 전체 교체와 비밀번호 정리
- 봄: 겨울 동안 쌓인 먼지와 습기 흔적 확인
- 여름: 장마 전에 번호판과 문틈 물기 확인
- 가을: 한파 오기 전에 배터리 잔량과 반응 속도 확인

# 연초에 하는 일은 배터리 전체 교체

건전지는 한두 개만 바꾸면 남은 것이 먼저 다시 떨어집니다. / 새것으로 전부 같이 갈아 끼우는 것이 가장 단순하고 확실합니다.
제조사가 다른 건전지를 섞어 쓰는 것도 피하는 편이 좋습니다. / 같은 종류를 한 번에 사서 교체한 날짜를 배터리 칸 뚜껑 안쪽에 적어 둡니다.
교체하고 나면 번호를 눌러 열고 닫는 것을 문을 연 상태에서 여러 번 해봅니다. / 문이 열린 채로 시험해야 만에 하나 잘못돼도 갇히지 않습니다.
교체한 뒤 안쪽 손잡이와 바깥 번호판을 번갈아 써 보며 소리가 평소와 같은지도 들어 보세요. / 모터 소리가 유난히 길거나 힘겹게 들리면 점검 목록에 따로 적어 둡니다.

# 경고음이 이미 울렸다면 점검일을 기다리지 마세요
점검 루틴이 있어도 도어락이 낮은 배터리 경고음을 내면 그날 바로 바꾸는 것이 맞습니다. / 경고음 뒤에도 며칠은 버티는 경우가 많지만 언제까지인지는 알 수 없습니다.
퇴근길에 평촌역 근처 편의점에 들러 건전지를 사 오는 정도의 수고면 충분합니다. / 미루다가 문 앞에서 번호판이 꺼지면 그때는 비상 전원을 찾아야 합니다.
@ 도어락 배터리 교체 전 분기 점검

# 번호판과 버튼 감도 확인법
숫자 버튼을 하나씩 눌러 보며 반응이 둔한 곳이 없는지 봅니다. / 특정 숫자만 잘 안 눌린다면 그 부분만 오래 닳았다는 뜻입니다.
번호판 주변이 얼룩져 있으면 마른 수건으로 닦아 줍니다. / 알코올이나 세제를 직접 뿌리면 안으로 스며들 수 있으니 천에 묻혀 쓰지 않는 편이 안전합니다.
지문 인식형은 센서 표면을 부드러운 천으로 닦아 주면 인식이 한결 나아집니다. / 손이 건조하거나 젖은 날 인식이 안 되는 것은 고장이 아닌 경우가 많습니다.
등록한 지문이 오래돼 잘 안 맞는다면 같은 손가락을 한 번 더 등록해 두는 것도 방법입니다. / 사용자 등록 방법은 제품마다 달라서 설명서를 함께 보시면 됩니다.

# 문 닫힘과 걸쇠 움직임도 같이 보세요
도어락이 멀쩡해도 문이 덜 닫히면 걸쇠가 문틀 구멍에 맞지 않아 잠금이 어긋납니다. / 문을 가볍게 밀어 닫았을 때 한 번에 철컥 하고 잠기는지 봅니다.
걸쇠가 나왔다 들어가는 모습이 뻑뻑하거나 소리가 달라졌다면 문틀이 조금 움직였을 수 있습니다. / 이런 경우는 [도어락 수리](doorlock-repair.html) 쪽에서 문틀 맞춤까지 같이 봐 드립니다.
문을 닫을 때 평소보다 세게 밀어야 한다면 그것도 신호입니다. / 억지로 닫는 습관이 쌓이면 걸쇠와 문틀이 함께 닳습니다.

# 비밀번호는 한 해에 한 번 정리
오래 쓴 번호에는 예전 세입자, 가사 도움을 준 분, 지나간 손님이 알던 번호가 섞여 있을 수 있습니다. / 연초에 새 번호로 바꾸면 그런 걱정을 한 번에 덜 수 있습니다.
가족에게는 바뀐 번호를 같은 날 알려 주세요. / 한 사람만 모르고 있으면 밤늦게 문 앞에서 헤매는 일이 생깁니다.
번호를 메신저에 그대로 남기기보다 말로 전하거나 종이에 적어 각자 보관하는 편이 안전합니다. / 아이가 쓰는 번호는 외우기 쉬우면서도 생일처럼 뻔하지 않게 정해 보세요.

# 비상 전원 단자와 예비 건전지 위치
도어락 아래쪽에 9V 건전지를 대는 단자가 있는지 이번 기회에 눈으로 확인해 둡니다. / 모양이 도어락마다 달라서 평소에 한 번 봐 두면 급할 때 헤매지 않습니다.
예비 건전지는 현관 서랍이나 가방에 하나씩 나눠 두는 것이 좋습니다. / 집 안에만 두면 문이 안 열릴 때 꺼낼 수 없습니다.
새 건전지는 접점이 닿는 쪽이 눌리지 않게 따로 포장해 보관합니다. / 서로 닿으면 방전될 수 있으니 한꺼번에 느슨하게 넣어 두지 않는 편이 좋습니다.

# 점검한 날 남기는 간단한 기록
복잡한 표는 필요 없습니다. / 오래 이어 가려면 쉬워야 하기 때문입니다. / 휴대폰 달력에 반복 일정으로 연초와 분기 알림을 넣고, 메모에는 교체한 건전지 종류만 적어 두면 됩니다.
이사나 도어락 교체를 한 해라면 설치한 날을 같이 적어 둡니다. / 나중에 [도어락 교체](doorlock-replace.html)를 고민할 때 얼마나 썼는지 가늠하는 기준이 됩니다.
@ 평촌동 달력에 적어 둔 도어락 점검일

# 그래도 문이 안 열렸다면 이렇게 전화하세요
루틴을 지켜도 문 앞에서 막히는 날은 올 수 있습니다. / 그런 날 자책하실 필요는 없습니다. / 이때는 번호판 상태, 경고음 여부, 집 안에 사람이 있는지를 먼저 말씀해 주시면 됩니다.
도착하면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분하니 미리 준비해 두세요.
비용은 문을 열기 전에 먼저 말씀드리고, 끝내 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 점검에서 문제가 보였을 때의 선택
배터리를 새로 넣어도 반응이 늦다면 모터나 회로 쪽 문제일 수 있습니다. / 이때는 바로 교체를 권하기보다 고쳐서 쓸 수 있는지 먼저 봅니다. / 손잡이 방향이나 문 두께가 맞는지도 이때 같이 살핍니다.
고장이 잦고 부품도 구하기 어려운 오래된 제품이면 그때 교체를 말씀드립니다. / 문이 안 열리는 상황에서의 대응은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 평촌동 말고 안양 어디서든 가능합니다
평촌동 가까이 비산동, 관양동, 호계동, 귀인동, 부흥동, 안양동, 석수동, 박달동도 다닙니다. / 인덕원역과 안양역 근처까지 안양 안이면 24시간 출동합니다.
다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
