# 정문 말고 뒷문이 말썽일 때
평촌동은 범계역과 평촌역 사이에 상가와 주택, 학원가가 섞여 있어 건물마다 뒷문이나 쪽문을 따로 쓰는 곳이 많습니다. / 정문은 자주 점검하지만 뒷문은 신경 쓰지 못하는 사이 고장 나 있는 경우가 흔합니다.
쓰레기를 버리러 나가거나 배달을 받는 문이라 하루에도 여러 번 여닫는데, 막상 잠그려고 하면 안 잠기고 열려고 하면 안 열립니다.
이 글은 뒷문과 쪽문, 후문에서 자주 생기는 증상과 확인 방법을 적었습니다. / 해결이 어려울 때는 [안양 출장열쇠](anyang.html)에 연락하는 순서도 마지막에 정리했습니다.

# 뒷문은 정문과 구조가 다릅니다
뒷문은 대개 두께가 얇고 가벼운 철문이나 알루미늄 문입니다. / 바깥쪽에 비바람과 먼지가 그대로 닿아 부품이 빨리 부식됩니다.
정문처럼 번호키가 달린 곳도 있지만, 오래된 열쇠 구멍 손잡이나 빗장, 걸쇠가 붙은 문도 많습니다.
- 열쇠 구멍이 있는 원통형 손잡이 잠금
- 문 안쪽에서만 돌려 잠그는 빗장 형태
- 위아래로 끼우는 걸쇠나 쇠 고리형 잠금
- 번호나 카드로 여닫는 전자식 도어락
어떤 방식인지에 따라 점검 방법이 달라집니다.
@ 평촌동 건물 뒷문 쪽문 잠금장치

# 열쇠가 뻑뻑하고 잘 안 돌아갈 때
밖으로 노출된 뒷문 열쇠 구멍에는 먼지와 습기가 쌓입니다. / 겨울에는 얼기도 하고, 여름에는 녹이 슬어 열쇠가 뻑뻑해집니다.
이런 때 열쇠를 힘으로 돌리면 부러질 위험이 큽니다. / 열쇠를 반쯤 꽂은 채로 살살 앞뒤로 움직이며 천천히 돌려 보세요.
그래도 안 되면 억지로 돌리지 마세요. / 부러진 열쇠는 빼내는 데 시간이 훨씬 더 걸립니다.
겨울에 열쇠 구멍이 얼어 안 들어가는 경우에는 열쇠를 손으로 잠시 데웠다가 다시 꽂아 보세요. / 뜨거운 물을 붓는 방법은 얼었다가 다시 얼 수 있어 권하지 않습니다.

# 문이 덜 닫혀서 안 잠기는 경우
뒷문은 문 자체가 가벼워 바람에 따라 틈이 생기기 쉽습니다. / 문이 반만 닫힌 채로 있으면 잠금 막대가 구멍에 닿지 않습니다.
문 아래 바닥이 울퉁불퉁하거나 문턱에 쓰레기가 끼어 있지 않은지 살펴보세요. / 문틈에 돌멩이나 낙엽이 끼어 있어도 이런 증상이 생깁니다.
도어클로저가 달려 있다면 팔이 늘어졌거나 기름이 샌 것은 아닌지도 확인합니다.
클로저 뒷면의 조절 나사를 아무렇게나 돌리면 문이 쾅 닫히거나 아예 안 닫힐 수 있으니 반 바퀴씩만 돌려 보며 확인하세요. / 어느 쪽으로 돌렸는지 기억해 두면 되돌리기 쉽습니다.

# 빗장이나 걸쇠가 안에서 걸려 버린 경우
안쪽 빗장이 걸려 있으면 바깥에서는 열쇠로도 열 수 없습니다. / 나갈 때 빗장을 잠가 놓은 줄 모르고 앞문으로 나왔다면 뒷문으로는 못 들어갑니다.
이런 상황은 건물 안에 사람이 없을 때 생기기 쉽습니다. / 정문으로 들어가는 방법이 있는지 먼저 생각해 보세요.
정문도 열리지 않는 경우에는 건물 구조를 보고 어느 문이 가장 상하지 않게 열 수 있는지 판단해야 합니다.

# 자동으로 잠기는 뒷문에서 조심할 점
자동 잠금 장치가 달린 뒷문은 나갔다 돌아올 때 열쇠나 카드가 없으면 못 들어갑니다. / 쓰레기를 버리거나 담배를 피우러 나갔다가 갇히는 일이 흔합니다.
- 문 고정 장치를 쓸 수 있는지 확인
- 나가기 전에 열쇠나 카드키를 주머니에 확인
- 문틈에 닫힘 방지용 물건을 임시로 끼워 두기
소방 규정과 관련된 문은 임의로 고정하면 안 되는 경우가 있습니다. / 건물 관리 규정을 먼저 확인하는 것이 좋습니다.
건물 안에 여러 입주자가 있으면 뒷문 열쇠를 누가 가지고 있는지도 정리해 두세요. / 열쇠가 여러 개 돌아다니다 보면 어느 것이 어느 문 것인지 헷갈립니다.

# 비상구 역할을 하는 뒷문이라면
뒷문이 대피로 역할을 겸하는 건물도 있습니다. / 이런 문은 안에서 항상 쉽게 열려야 하는 것이 기본입니다.
평소에 문이 뻑뻑하다면 위급한 때 큰일이 될 수 있으니 미루지 말고 점검하세요. / 문 앞에 물건을 쌓아 두는 것도 피해야 합니다.
@ 비상 출입구 역할을 하는 뒷문 점검

# 도착하기 전에 알려 주실 내용
- 평촌동 어느 쪽인지, 건물 이름과 뒷문 위치
- 열쇠식인지 번호키인지 빗장형인지
- 문 재질(철문, 알루미늄, 목재)과 안쪽에서 열리는지
- 건물에 다른 입주자가 있는지
- 문 전체와 잠금장치를 찍은 사진
건물 관리인이나 소유주와 연락이 되는지도 알려 주세요. / 뒷문은 여러 사람이 쓰는 경우가 많아 확인이 필요합니다.
뒷문 앞에 주차된 차나 쌓인 물건이 있으면 작업에 방해가 되니 가능하면 미리 치워 주세요. / 어두운 시간이라면 주변 조명이 어디서 켜지는지도 알려주시면 좋습니다.

# 도착 후 확인하는 순서
문을 여는 일이라 거주자나 사용자 확인을 먼저 합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 또는 건물 관리인의 확인 중 하나면 됩니다.
상가나 사무실이라면 사업자 관련 서류나 임대 관련 서류를 확인하는 경우도 있습니다.
확인이 어려우면 작업할 수 없습니다. / 미리 건물주나 관리인에게 확인을 부탁해 두시면 수월합니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 잠금장치를 보고 작업 전에 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 들면 그냥 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 부품을 바꿔야 하는 상황이면 바꾸기 전에 다시 여쭙습니다.
진행 순서는 [이용안내](guide.html)에, 문을 상하지 않게 여는 방법은 [현관문 개문](door-open.html)에 정리했습니다.

# 열고 난 뒤 같이 점검하는 것
문이 열리면 여닫는 느낌, 잠금 막대의 길이, 구멍 위치를 같이 봅니다. / 문이 가볍고 흔들린다면 경첩과 문틀 고정부를 확인합니다.
녹이 슬었으면 닦고 기름칠을 해 두는 것만으로도 한동안 편해집니다. / 부식이 심한 부품은 바꿔야 하는 시기를 말씀드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 낡아서 안전하지 않을 때만 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 안내합니다.
@ 점검을 마친 뒷문 잠금장치

# 뒷문 잠금장치를 오래 쓰는 방법
- 일 년에 한두 번 열쇠 구멍과 경첩에 기름 소량 바르기
- 문 아래 문턱의 먼지와 쓰레기 치우기
- 문을 세게 닫지 않고 천천히 닫기
- 안쪽 빗장을 걸 때 문이 완전히 닫혔는지 확인
- 비 오는 날 번호판이나 열쇠 구멍에 물이 고이지 않게 닦기
비가 자주 들이치는 방향에 있는 뒷문이라면 지붕이나 가림판을 달아 주는 것도 방법입니다.

# 평촌동 밖 안양 어디든 갑니다
평촌동 가까이 관양동, 비산동, 호계동, 부흥동도 다닙니다. / 안양 안이면 24시간 어느 동네든 출동합니다.
동네 정보는 [안양시 출장열쇠](anyang.html)에 있고, 서울과 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
