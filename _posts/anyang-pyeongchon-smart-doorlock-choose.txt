# 평촌동에서 스마트 도어락을 알아볼 때
평촌동은 오래 살아온 가족이 많고 집을 새로 고쳐 쓰는 집도 많은 동네입니다. / 열쇠를 쓰다가 번호나 지문 도어락으로 바꾸려는 분들이 꾸준히 문의합니다.
막상 고르려면 종류가 많아 뭘 기준으로 해야 할지 막막합니다. / 이 글은 안양 평촌동에서 스마트 도어락을 고를 때 볼 기준을 가족 구성별로 적었습니다.
@ 평촌동 스마트 도어락 선택 지문 카드

# 열림 방식은 크게 네 가지입니다
스마트 도어락은 열리는 방식으로 먼저 나뉩니다. / 한 가지만 되는 제품보다 두세 가지가 되는 제품이 흔합니다.
- 번호: 키패드에 번호를 눌러 연다
- 카드·태그: 등록한 카드를 대서 연다
- 지문: 등록한 손가락을 대서 연다
- 열쇠: 비상용으로 열쇠 구멍이 달린 경우
어떤 걸 주로 쓸지 정하는 것이 첫 단계입니다.

# 아이가 있는 집
아이가 어릴 때는 번호를 외우거나 열쇠를 챙기기 어렵습니다. / 카드나 지문처럼 손쉬운 방식이 있으면 편합니다.
다만 어린아이가 지문이나 카드를 만지다 잘못 쓸 수도 있습니다. / 아이가 문을 열고 닫는 습관까지 같이 생각하면 좋습니다.

# 부모님이 계신 집
어르신은 새 기계에 익숙해지는 데 시간이 걸립니다. / 버튼이 크고 소리가 분명한 번호 방식이 편한 경우가 많습니다.
지문은 손가락이 건조하면 인식이 어려울 수 있어 번호나 카드를 같이 쓰도록 권합니다. / 처음 설치할 때는 같이 눌러 보며 익숙해지는 시간을 가져 주세요.
@ 평촌 열쇠집 스마트 도어락 번호 지문

# 혼자 사는 집
혼자 산다면 열쇠를 안 챙겨도 되는 것이 가장 큰 장점입니다. / 번호 하나와 카드 하나면 충분한 경우가 많습니다.
- 퇴근길에 장 본 짐이 많아도 쉽게 열 수 있는지
- 배터리가 떨어지기 전에 알려주는지
- 비상 단자나 열쇠 구멍이 있는지
혼자 있을 때 막히면 도와줄 사람이 없으니 비상 수단이 중요합니다.

# 맞벌이·여러 명이 쓰는 집
여러 사람이 쓰는 집은 사용자 등록 수가 중요합니다. / 가족 모두의 카드나 지문을 등록할 수 있는지 확인하세요.
출입 기록이 필요한 집이라면 기록 기능이 있는 제품을 알아보세요. / 단, 기능이 많을수록 설정과 관리가 복잡해집니다.

# 지문 방식 쓸 때 알아 둘 것
지문은 편하지만 만능은 아닙니다. / 손이 젖었거나 건조하거나 다쳤을 때는 인식이 잘 안 될 수 있습니다.
그래서 번호나 카드를 같이 쓸 수 있는 제품이 안심됩니다. / 지문만 되는 제품은 신중히 고르세요.

# 정전과 배터리 걱정
전기로 움직이는 제품이라 배터리와 비상 상황을 같이 생각해야 합니다. / 비상 단자에 9V 건전지를 댈 수 있는지 확인하세요.
배터리가 약해지면 알려주는 소리가 나는 제품이 대부분입니다. / 그 소리를 놓치지 않는 것이 가장 중요합니다.
@ 평촌동 도어락 설치 전 확인

# 우리 집 문에 맞는지 먼저 확인
마음에 든다고 바로 사기 전에 문 두께와 기존 구멍 규격을 확인하세요. / 오래된 문에는 안 맞을 수 있습니다.
사진 두세 장과 문 두께를 보내 주시면 맞는지 확인해 드립니다. / 설치 방식은 [도어락 설치](doorlock-install.html) 페이지를 참고하세요.

# 가격만 보고 고르지 마세요
싼 제품이 나쁜 건 아니지만 쓰는 사람에게 맞는지가 먼저입니다. / 오래 쓰려면 배터리, 소리, 보조 열림 방법을 같이 보세요.
- 번호판이 밝고 눌렀을 때 반응이 확실한지
- 설명서가 알기 쉽고 도움받을 곳이 있는지
- 부품이 오래 나오는 제품인지
설치 후 문제가 생겼을 때 관리가 되는지도 중요합니다.

# 설치 후 첫 일주일
- 번호와 카드를 가족 모두 한 번씩 써 보기
- 비상 열쇠나 단자를 어디에 두는지 확인
- 배터리 교체 날짜를 적어 두기
- 소리가 이상하면 바로 연락하기
처음 며칠은 익숙해지는 시간이니 잘 안 되는 부분은 바로 말씀하세요.

# 비용은 문 열기 전에 말씀드립니다
제품과 문 상태에 따라 다르기 때문에 먼저 확인한 뒤에 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 여는 경우에는 비용을 받지 않습니다. / 바꾸기 전에는 꼭 먼저 여쭙니다.

# 지금 도어락이 고장 난 경우
스마트 도어락을 알아보게 된 이유가 고장이라면 [도어락 교체](doorlock-replace.html) 이야기부터 하는 게 맞습니다. / 단순히 배터리 문제라면 새 제품이 필요 없습니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 먼저 상태를 보고 말씀드립니다.

# 제품 소개만 믿지 말고 직접 만져 보세요
광고에는 좋은 점만 나오지만 실제로 눌러 보면 느낌이 다릅니다. / 번호판의 크기와 누르는 느낌, 소리가 가족에게 맞는지 확인하세요.
가능하면 비슷한 제품을 쓰는 지인 집에서 한 번 눌러 보는 것도 방법입니다. / 설치 후에는 바꾸기 어려우니 고르기 전에 충분히 살펴보세요.

# 방범 기능과 비상 상황, 알아 둘 것
스마트 도어락에는 잘못된 번호를 여러 번 누르면 한동안 막히는 방범 기능이 들어 있는 경우가 많습니다. / 이 기능은 도움이 되지만 가족이 자주 틀린다면 불편할 수 있습니다.
문제가 생겼을 때 [출장 열쇠](key-call.html)를 부르면 제품 상태를 보고 설정을 같이 확인해 드립니다. / 열고 난 뒤에는 방범 기능 설정도 같이 알려 드립니다.
