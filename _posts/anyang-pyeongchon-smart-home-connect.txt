# 평촌동에서 도어락 앱이 갑자기 먹통일 때
평촌동처럼 오래 살아온 집과 새로 단장한 집이 섞인 동네는 도어락도 구형과 신형이 함께 쓰입니다. / 요즘 도어락은 휴대폰 앱과 연결해 알림을 받고, 멀리서 문 상태를 보는 제품이 늘었습니다.
그런데 어느 날 알림이 안 오거나 앱에서 도어락이 연결되지 않는다는 문구가 뜨는 경우가 있습니다. / 이 글은 그럴 때 직접 해볼 수 있는 확인과, [안양 출장열쇠](anyang.html)를 부르는 기준을 적었습니다.
@ 평촌동 스마트 도어락 앱 연동 출장열쇠

# 연동 도어락이 하는 일
연동 도어락은 문이 열리고 닫힐 때의 기록을 휴대폰으로 보내 줍니다. / 도어락 본체와 휴대폰이 직접 연결되는 제품도 있고, 중간에 작은 중계기를 거쳐 와이파이로 연결되는 제품도 있습니다.
어느 방식인지에 따라 확인할 곳이 달라집니다. / 우선 내 도어락이 어떤 방식인지 설명서나 앱 안내에서 확인해 두세요.

# 먼저 휴대폰 쪽부터 확인하기
앱 알림이 안 올 때는 도어락보다 휴대폰 설정이 원인인 경우가 많습니다. / 알림을 꺼 두었거나, 절전 모드가 앱을 멈춰 놓았거나, 방해금지 모드가 켜져 있을 수 있습니다.
휴대폰의 알림 설정에서 도어락 앱이 허용으로 되어 있는지 보세요. / 블루투스를 쓰는 제품이라면 블루투스가 꺼져 있지 않은지도 같이 봅니다.

# 와이파이와 중계기 확인
와이파이로 연결되는 제품이라면 집 공유기가 정상인지 먼저 봅니다. / 공유기 전원이 한 번 꺼졌다 켜진 뒤 연결이 풀리는 경우가 흔합니다.
중계기가 따로 있다면 전원 램프가 켜져 있는지 확인하세요. / 램프가 꺼져 있거나 깜빡이면 전원 어댑터를 다시 꽂아 보는 것부터 시작합니다.
도어락과 중계기 사이가 너무 멀거나 문 두께 때문에 신호가 약한 경우도 있습니다. / 중계기를 현관문 가까이로 옮겨 보면 나아지기도 합니다.
@ 평촌동 도어락 중계기 와이파이 점검 안양 출장열쇠

# 배터리가 약하면 알림이 먼저 끊깁니다
연동 기능은 일반 잠금보다 전기를 더 씁니다. / 그래서 배터리가 약해지면 문은 열리는데 알림이나 연동만 먼저 끊기는 일이 생깁니다.
앱에서 배터리 잔량을 볼 수 있다면 확인해 보세요. / 잔량 표시가 없는 제품이라면 마지막으로 교체한 시기를 떠올려 보고, 오래됐다면 전부 새것으로 바꿔 보는 것이 가장 빠릅니다.
배터리를 바꾼 뒤에는 앱에 다시 연결해야 하는 제품도 있습니다. / 연결 안내가 뜨면 순서대로 따라가면 됩니다.

# 앱 업데이트와 로그인 다시 하기
앱이 오래된 버전이면 도어락과 맞지 않아 연결이 끊길 수 있습니다. / 앱 스토어에서 업데이트가 있는지 보고, 있다면 먼저 업데이트하세요.
그래도 안 되면 앱에서 로그아웃했다가 다시 로그인해 봅니다. / 이때 비밀번호를 모르면 곤란하니 계정 정보를 먼저 확인해 두세요.
계정을 다시 만들어야 하는 상황이라면 기존 등록 정보가 사라질 수 있습니다. / 도어락 안의 등록 정보를 먼저 확인한 뒤에 진행하세요.

# 연동이 안 돼도 문은 열리는지 확인
가장 먼저 확인할 것은 연동이 아니라 문이 열리느냐입니다. / 번호나 열쇠, 카드로 문이 열린다면 급한 일은 아니니 천천히 원인을 찾아도 됩니다.
번호판이 안 켜지거나 번호를 눌러도 반응이 없다면 연동이 아니라 도어락 자체 문제입니다. / 이 경우는 [도어락 수리](doorlock-repair.html) 쪽을 보셔야 합니다.
문이 아예 안 열리는 상태라면 연동이 아니라 문 앞에서 막힌 상황이니 [현관문 개문](door-open.html) 쪽부터 보셔야 합니다. / 이럴 때는 전화로 위치와 번호판 상태를 먼저 알려 주세요.

# 연동을 다시 등록하는 순서
앱에서 기존에 등록된 도어락을 삭제하고 새로 추가하는 방법이 보통입니다. / 제품마다 순서가 달라서 도어락 쪽에서도 연결 모드를 켜야 하는 경우가 있습니다.
연결 모드는 도어락 안쪽 덮개 안의 버튼이나 관리자 메뉴로 들어갑니다. / 어디에 있는지 모르면 설명서를 보거나, 사진을 보내 주시면 확인해서 말씀드립니다.
등록하는 동안에는 문을 열어 둔 채로 진행하는 것이 안전합니다. / 중간에 설정이 꼬이더라도 집 안팎에서 막힐 일이 없습니다.

# 공유기를 바꿨거나 인터넷 회사를 바꿨을 때
공유기를 새로 바꾸면 와이파이 이름이나 비밀번호가 달라져 도어락이 연결을 잃습니다. / 이 경우 중계기를 새 와이파이에 다시 연결해야 합니다.
같은 이름과 비밀번호로 설정해 두면 그대로 다시 붙는 제품도 있습니다. / 다만 주파수 방식이 달라 안 붙는 제품도 있으니 설명서를 확인하세요.
공유기 위치를 옮기거나 새 공유기로 바꾼 날은 도어락 알림이 끊기지 않았는지 한 번 확인해 보세요. / 문을 한 번 열고 닫아 보면 앱에 기록이 뜨는지 바로 알 수 있습니다.

# 휴대폰을 바꾸거나 잃어버렸을 때
새 휴대폰으로 바꾸면 앱에 도어락이 등록되어 있지 않을 수 있습니다. / 이전 휴대폰의 등록을 먼저 지우고 새 휴대폰에서 다시 등록하는 순서가 안전합니다.
휴대폰을 잃어버렸다면 그 휴대폰으로 문이 열리지 않게 해 두는 것이 우선입니다. / 도어락에서 해당 기기의 등록을 지우거나 비밀번호를 새로 바꿔 두세요.

# 이런 증상이면 도어락 쪽 문제입니다
앱, 와이파이, 배터리를 모두 확인했는데도 연결이 안 되는 경우가 있습니다. / 연결 부품이 고장 났거나, 오래된 모델이라 지원이 끊겼을 수 있습니다.
- 앱을 다시 설치해도 도어락을 찾지 못함
- 배터리를 새것으로 바꿨는데도 연결 모드가 켜지지 않음
- 번호판은 켜지는데 모터가 힘없이 돌거나 소리만 남
- 최근 물이나 습기가 들어간 적이 있음
이런 경우는 직접 만지기보다 사진을 보내 주세요. / 어떤 부품이 문제인지 먼저 말씀드리고, 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 평촌동 도어락 연동 오류 점검 24시 출장열쇠

# 평촌동에서 출장을 부를 때 알려 주실 것
위치와 함께 도어락 모양, 제품 이름, 앱 이름을 알려 주세요. / 문이 열리는 상태인지 안 열리는 상태인지도 먼저 말씀해 주시면 준비해서 갑니다.
- 도어락 앞면 사진과 제품 이름이 적힌 부분
- 앱에서 뜨는 오류 문구 화면
- 배터리를 마지막으로 바꾼 시기
- 공유기나 중계기를 바꾼 적이 있는지
화면을 캡처해 두면 전화로 설명하기가 훨씬 쉽습니다.
@ 평촌동 도어락 앱 화면 캡처 출장 준비

# 신분 확인과 비용 안내
문이 잠긴 상황이 아니라 연동 문제라면 집 안에서 작업하는 경우가 많습니다. / 그래도 사시는 분인지 확인한 뒤에 작업합니다.
고치기 전에 비용을 먼저 말씀드리고, 동의하시면 시작합니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 자주 묻는 질문
? 알림이 안 오는데 도어락이 고장 난 건가요? | 휴대폰 설정, 와이파이, 배터리 순서로 먼저 확인해 보세요. 그래도 안 되면 사진을 보내 주세요.
? 앱을 다시 설치하면 번호도 지워지나요? | 번호는 도어락 안에 저장되는 경우가 많지만 제품마다 다릅니다. 지우기 전에 먼저 문의해 주세요.
? 연동이 안 되는데 문은 열려요. 급한가요? | 문이 열리면 급하지 않습니다. 천천히 원인을 찾으시고 필요할 때 연락 주세요.
? 중계기를 옮기면 좋아지나요? | 현관문 가까이로 옮기면 신호가 나아지는 경우가 있습니다.
? 연동 기능이 없는 도어락으로 바꾸는 게 나은가요? | 쓰는 방식에 따라 다릅니다. 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.

24시출장열쇠는 도어락 연동 문제도 봐 드립니다. / 서울, 경기 전 지역 24시간, 010-3664-5455로 연락 주세요. 다른 동네는 [출장 지역](area.html)에서 확인하세요.
