# 석수동에서 현관문 말고 베란다 문이 안 열릴 때
석수동은 석수역 주변으로 빌라와 오래된 주택, 아파트가 이어져 있는 동네입니다. / 현관문만 문제가 되는 줄 아시지만 베란다 문이나 방문 잠금이 말썽인 집도 꽤 많습니다.
베란다 샷시는 매일 여닫지 않아서 평소에는 문제를 눈치채지 못하다가 환기하려는 날 갑자기 안 열립니다. / 반대로 밤에 잠그려는데 걸쇠가 안 들어가 불안해지는 경우도 있습니다.
이 글은 베란다 미닫이문, 방문, 샷시 잠금장치에서 생기는 문제를 상황별로 정리했습니다. / 안양 석수동에서 [안양 출장열쇠](anyang.html)를 부르기 전에 읽어 보시면 설명하기가 쉬워집니다.
@ 석수동 베란다 미닫이문 잠금장치 안 열림

# 먼저 어떤 종류의 잠금인지 구별하세요
베란다와 방 문의 잠금장치는 모양이 여러 가지라서 이름부터 헷갈립니다. / 전화로 설명하실 때 아래 중 어느 쪽에 가까운지만 말씀하셔도 충분합니다.
- 반달 모양 걸쇠를 위로 올려 잠그는 샷시 반달 잠금
- 손잡이를 돌려 잠그는 크레센트 잠금
- 문틀 위나 아래에 달린 보조 잠금 막대
- 방문 손잡이에 달린 누름식 또는 돌림식 잠금 버튼
- 열쇠를 꽂는 베란다 문 잠금
모양을 알면 어떤 부품이 닳았는지 짐작하기 쉽습니다. / 사진을 한 장 찍어 두시면 가장 확실합니다.

# 샷시 반달 잠금이 안 열리는 흔한 이유
반달 걸쇠는 오래 쓰면 걸림쇠와 받침쇠 사이가 어긋납니다. / 문이 살짝 처지면 걸쇠가 받침쇠에 꽉 물려 손으로 올려도 빠지지 않습니다.
이럴 때는 문 전체를 손바닥으로 위로 살짝 들어 올리면서 걸쇠를 풀어 보세요. / 무게가 실려 있던 문이 올라가며 걸림이 풀리는 경우가 있습니다.
억지로 세게 당기면 걸쇠가 휘거나 유리 틀이 틀어질 수 있습니다. / 두세 번 해보고 안 되면 멈추는 것이 안전합니다.

# 문이 레일에서 뻑뻑하게 걸릴 때
미닫이문은 바닥 레일에 먼지와 이물질이 쌓이면 바퀴가 제대로 구르지 못합니다. / 이 경우 잠금장치 문제로 오해하는 분들이 많습니다.
레일 안의 먼지를 빼고 마른 걸레로 닦은 뒤 문을 다시 밀어 보세요. / 바퀴가 심하게 닳았거나 레일이 눌려 있으면 부품을 바꿔야 할 수 있습니다.
윤활제를 과하게 뿌리면 오히려 먼지가 더 달라붙기도 합니다. / 마른 상태에서 먼저 확인하시길 권합니다.
@ 석수동 샷시 레일 바퀴 잠금 점검 출장

# 방문이 안에서 안 열리거나 밖에서 안 잠길 때
방문 손잡이는 현관문 도어락보다 구조가 단순하지만 오래 쓰면 속 부품이 마모됩니다. / 손잡이가 돌아가기만 하고 걸쇠가 움직이지 않는 일이 가장 흔합니다.
이때는 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 문틀이 처져서 걸쇠가 눌려 있는 경우에는 이 방법으로 풀리기도 합니다.
방문이 안에서 잠겨 사람이 갇힌 경우는 [현관문 개문](door-open.html)보다 급할 수 있습니다. / 아이나 어르신이 안에 있다면 먼저 말씀해 주세요.

# 이런 소리가 나면 부품이 닳은 겁니다
소리는 부품 상태를 알려주는 가장 쉬운 단서입니다. / 아래 소리가 들리면 오래 쓰지 말고 점검받으시는 편이 좋습니다.
- 잠글 때 "드르륵" 갈리는 소리: 걸쇠와 받침쇠가 어긋남
- 손잡이를 돌릴 때 "헛도는" 느낌: 내부 스프링이나 축이 마모됨
- 문 닫을 때 "탁" 하고 튕기는 소리: 걸쇠가 문틀에 부딪힘
- 열쇠를 돌릴 때 걸리는 느낌: 실린더 안에 이물질이 있음
소리가 처음 났을 때 확인하면 부품 하나만 바꿔도 해결되는 경우가 많습니다. / 미루다가 완전히 안 열리면 문을 열어야 하는 일이 더 커집니다.

# 직접 해보기 전에 피해야 할 것
드라이버로 잠금장치를 억지로 풀려다가 샷시 틀이나 유리가 깨지는 일이 있습니다. / 베란다 유리는 특히 큰 사고로 이어질 수 있어서 조심해야 합니다.
윤활유를 너무 많이 넣으면 내부에 찌꺼기가 엉겨 나중에 더 뻑뻑해집니다. / 소량만 쓰고 닦아 내는 정도로 충분합니다.
높은 곳에 있는 잠금장치는 의자에 올라가서 만지다 넘어지는 경우도 있습니다. / 무리하지 마시고 전화 주시는 것이 안전합니다.

# 출장열쇠가 와서 보는 순서
도착하면 먼저 문과 잠금장치의 모양, 닳은 정도를 봅니다. / 어느 부품이 원인인지 눈으로 확인한 뒤 어떻게 할지 말씀드립니다.
부품 하나만 바꾸면 되는지, 잠금장치 전체를 바꿔야 하는지 구별해서 설명합니다. / [도어락 수리](doorlock-repair.html)로 해결되는 일이면 교체는 권하지 않습니다.
문이 걸려 안 열리는 경우에는 샷시나 문을 상하지 않게 풀어서 엽니다. / 열고 난 뒤 다시 잘 잠기고 열리는지 같이 확인합니다.
@ 석수동 방문 샷시 잠금 수리 출장열쇠

# 신분 확인은 이렇게 합니다
출장열쇠는 문이나 샷시를 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
현장에서 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 석수동 위치는 이렇게 알려주세요
석수동은 골목과 빌라가 많아서 위치를 정확히 알려주시면 도착이 빨라집니다. / 건물 이름이나 눈에 띄는 가게, 석수역에서 어느 쪽인지를 말씀해 주세요.
- 건물 형태와 몇 층인지
- 문제가 생긴 곳 (베란다, 방, 현관)
- 잠금장치 모양과 소리
- 집 안에 사람이나 반려동물이 있는지
문제 부분을 찍은 사진을 문자로 보내주시면 맞는 부품을 챙겨 가기 좋습니다. / 집 안에 아이가 있는 경우에는 꼭 먼저 말씀해 주세요.

# 평소에 이렇게 관리하면 오래 씁니다
베란다 문은 계절이 바뀔 때 한 번씩 열고 닫아 보면 문제를 미리 찾을 수 있습니다. / 레일 청소를 한 번 해 주는 것만으로도 부담이 크게 줄어듭니다.
- 해가 바뀔 때 레일 먼지 빼기
- 잠금 걸쇠가 뻑뻑하면 그날 바로 확인
- 장마철에는 습기 닦아 주기
- 방문 손잡이가 헛돌면 미루지 않기
작은 습관이 문 앞에서 막히는 일을 많이 줄여 줍니다. / 이상 소리가 나면 그때 한 번 불러 주셔도 됩니다.

# 석수동 말고 안양 어디든 갑니다
석수동 옆 박달동, 안양동, 비산동, 호계동, 평촌동, 관양동, 귀인동, 부흥동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
안양에서 다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
