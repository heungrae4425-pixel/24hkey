# 문은 닫았는데 도어락은 열려 있다고 말할 때
석수동은 석수역 주변으로 빌라와 아파트가 이어진 동네입니다. / 문을 닫았는데 도어락이 계속 삑삑 울리거나 자동으로 잠기지 않는다는 연락이 가끔 옵니다.
문은 분명히 닫혀 있는데 도어락은 닫힌 줄 모르는 것입니다. / 닫힘 센서가 상황을 잘못 읽을 때 생기는 일입니다.
이 글은 센서와 걸쇠가 어떻게 문 닫힘을 판단하는지, 집에서 확인할 수 있는 것과 [안양 출장열쇠](anyang.html)가 살펴보는 순서를 적었습니다.
@ 석수동 도어락 닫힘 센서 오인식 점검

# 도어락은 문이 닫힌 걸 어떻게 알까
문틀 쪽에는 작은 자석이나 스위치가 붙어 있고, 도어락 쪽에는 이를 읽는 센서가 있습니다. / 문이 닫히면 두 부품이 맞닿아 닫힘으로 인식합니다.
이 신호를 받아야 자동으로 잠기고, 열린 채로 있으면 경고음을 냅니다. / 센서가 신호를 못 받으면 문이 닫혀도 열린 상태로 착각합니다.
센서가 틀어지거나 더러워지면 이런 증상이 생깁니다. / 문 자체나 도어락이 고장 난 것이 아닌 경우가 많습니다.

# 센서가 헷갈릴 때 나타나는 모습
- 문이 닫혔는데 몇 초마다 경고음이 계속 울림
- 자동 잠금이 안 되고 수동으로 눌러야 잠김
- 잠금 소리는 나는데 앞에서 보면 문이 덜 닫혀 있음
- 문을 세게 닫아야만 잠기고 살살 닫으면 안 잠김
- 문을 열었는데 열림 상태가 풀리지 않고 불이 켜져 있음
이런 증상이 반복되면 닫힘 신호 쪽을 의심해 보세요.

# 걸쇠가 문틀 구멍에 안 맞는 경우
문이 닫히면 도어락의 걸쇠가 문틀 구멍으로 들어가 문을 잡아 줍니다. / 이때 걸쇠와 구멍 위치가 조금 어긋나면 완전히 들어가지 못하고 걸립니다.
문이 처지거나 경첩이 헐거워지면 이런 어긋남이 생깁니다. / 센서는 닫힘 신호를 받았지만 걸쇠는 못 들어간 상태가 되기도 합니다.
문틀 구멍 주변에 긁힌 자국이 보이면 위치가 어긋났다는 증거입니다.
문을 닫을 때 손잡이를 돌린 채로 닫는지, 놓고 닫는지도 영향을 줍니다. / 손잡이를 놓은 상태에서 닫아야 걸쇠가 제 위치로 나옵니다.
이 정도 확인만으로도 원인이 좁혀지는 경우가 있어 한 번씩 해보시길 권합니다.

# 집에서 해볼 수 있는 확인
문을 닫은 뒤 손으로 문을 안쪽으로 살짝 밀어 보세요. / 문이 약간 움직이면서 걸쇠가 들어가는 소리가 나면 위치가 어긋난 것입니다.
문틀의 센서 자리나 도어락 옆 틈에 먼지나 이물질이 끼지 않았는지도 봅니다. / 마른 천으로 가볍게 닦는 정도는 해볼 만합니다.
배터리가 약해도 센서 신호가 불안정해질 수 있어 배터리를 새것으로 바꿔 보는 것도 방법입니다.
@ 석수동 현관문 걸쇠 문틀 어긋남 확인
경고음이 울린다는 건 도어락이 문제를 알리고 있다는 신호입니다. / 소리를 끄는 데만 신경 쓰지 말고 왜 울리는지를 먼저 찾는 것이 순서입니다.
소리가 나는 때를 기록해 두면 큰 도움이 됩니다. / 문을 닫은 직후인지, 시간이 지난 뒤인지, 특정 방향으로 문을 밀 때인지 메모해 두세요.

# 하면 안 되는 대처
센서를 가리켜 보려고 테이프를 붙이거나 자석을 임의로 바꾸는 분이 있습니다. / 센서가 영구적으로 틀어지거나 문이 닫혀도 안전하게 잠기지 않게 될 수 있습니다.
경고음이 싫다고 배터리를 빼 두는 것은 가장 위험합니다. / 문이 안 잠긴 채로 지내게 될 수 있습니다.
문을 세게 쾅 닫아서 억지로 맞추는 것도 좋지 않습니다. / 래치와 경첩에 부담이 쌓여 더 큰 고장으로 이어집니다.

# 문이 안 열릴 때와 구분하기
센서가 오인식하면 문이 안 잠기는 것뿐 아니라 안 열리는 일도 생깁니다. / 도어락이 이미 열려 있다고 착각해 잠금 해제 동작을 무시하는 것입니다.
번호는 맞고 소리도 나는데 손잡이가 안 돌아가면 보조키나 걸쇠도 함께 확인해 보세요. / 집안에서 쓰는 방법으로 안 풀리면 억지로 힘을 쓰지 말고 연락 주세요.
석수역 근처라면 위치 설명도 간단히 하실 수 있습니다.

# 전화할 때 말씀해 주실 내용
어떤 증상인지 구체적으로 알려주시면 점검이 빨라집니다.
- 석수동 도로명 주소와 호수
- 경고음이 어떤 때 나는지, 계속인지 가끔인지
- 문이 완전히 닫히는지, 덜 닫히는지
- 최근 문을 세게 닫았거나 문 상태가 변했는지
도어락과 문틀의 걸쇠 부분이 보이는 사진을 보내 주시면 도움이 됩니다.
빌라처럼 관리사무소가 없는 곳은 우편물이나 고지서에 찍힌 주소가 가장 확실합니다. / 임대로 사시는 분은 계약서 사본도 참고가 됩니다.

# 방문하면 신분부터 확인합니다
문 점검이든 개방이든 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 안에 있다면 경비실이나 관리사무소에 세대 확인을 부탁하세요. / 확인이 어려우면 작업이 어려우니 미리 챙겨 두시면 좋습니다.

# 비용은 열기 전에, 못 열면 받지 않습니다
점검 결과를 먼저 말씀드리고 비용이 얼마쯤인지도 시작 전에 알려드립니다. / 괜찮다고 하시면 작업합니다.
문이 안 열리는 상황에서 끝내 열지 못하면 비용은 받지 않습니다. / 말없이 늘어나는 비용은 없습니다.
부품을 바꾸기 전에는 반드시 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 센서와 걸쇠를 이렇게 바로잡습니다
먼저 문이 닫히는 길을 살펴 경첩과 문틀 구멍 위치를 확인합니다. / 어긋남이 작으면 문틀 쪽 구멍 위치를 손봐서 걸쇠가 맞게 합니다.
센서가 문제라면 위치를 다시 맞추거나 접점을 정리합니다. / 부품 자체가 불량일 때만 교체를 말씀드립니다.
문이 안 열리는 경우의 개방은 [현관문 개문](door-open.html)에서 자세히 볼 수 있습니다.
@ 석수동 닫힘 센서 걸쇠 조정 작업

작업이 끝나면 문이 정상으로 닫히고 잠기는지 여러 번 확인합니다. / 한 번 잘 되는 것만으로는 부족하기 때문입니다.
- 가볍게 닫아도 걸쇠가 문틀에 들어가는지
- 자동 잠금이 제때 되고 경고음이 멈추는지
- 열 때 손잡이가 걸림 없이 돌아가는지
고장이 되풀이되면 [도어락 수리](doorlock-repair.html)를, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 센서 오작동을 줄이는 생활 습관
문을 닫을 때 손으로 잡고 끝까지 천천히 닫는 습관이 좋습니다. / 세게 닫으면 센서와 걸쇠 모두 충격을 받습니다.
문틀 센서 주변에 스티커나 장식을 붙이지 않는 것이 좋습니다. / 문 앞에 짐을 쌓아 문이 끝까지 닫히지 않게 하는 것도 피해 주세요.
배터리는 해가 바뀔 때쯤 한꺼번에 새것으로 교체해 두면 신호가 안정적입니다.

# 석수동 말고 안양 어디든 갑니다
석수동 근처 박달동, 안양동은 물론 호계동, 비산동, 부흥동, 귀인동, 관양동, 평촌동도 다닙니다. / 안양역, 석수역, 인덕원역 쪽 모두 같은 방식입니다.
[안양시 출장열쇠](anyang.html)와 [출장 지역](area.html)에서 확인하세요.
