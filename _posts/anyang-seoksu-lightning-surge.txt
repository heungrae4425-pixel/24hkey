# 천둥번개가 지나간 다음 날 아침의 도어락
석수동은 안양역 쪽 생활권과 이어져 있어 출퇴근 때 오가는 사람이 많은 동네입니다. / 여름 소나기나 가을 끝자락의 갑작스러운 번개 뒤에 도어락이 평소와 다르게 반응한다는 연락이 간혹 들어옵니다.
어제까지 멀쩡하던 번호판이 오늘 아침에 켜지지 않거나, 번호를 눌러도 엉뚱한 소리가 나는 경우입니다. / 출근 시간은 다가오는데 문 앞에서 이러면 마음이 급해집니다.
이 글은 낙뢰나 전기 서지가 의심될 때 도어락 상태를 어떤 순서로 보면 되는지 적었습니다. / 직접 해볼 수 있는 것과 [안양 출장열쇠](anyang.html)에 맡겨야 하는 것을 나눠 두었습니다.
@ 석수동 낙뢰 뒤 도어락 번호판 점검

# 서지란 무엇이고 도어락에는 어떤 영향이 있나
서지는 번개나 정전 복구 때 전선으로 순간적으로 들어오는 높은 전압을 말합니다. / 건전지로 도는 도어락은 전선과 직접 이어지지 않아 대체로 영향이 적습니다.
다만 현관 쪽에 전기선이 연결된 제품이 있습니다. / 인터폰이나 월패드와 이어진 제품, 문 옆 전원 어댑터를 쓰는 제품, 도어 센서가 배선으로 연결된 제품이 그렇습니다.
이런 선을 타고 들어온 순간 전압이 회로 기판을 상하게 하면 번호판이 꺼지거나 스스로 재부팅을 반복할 수 있습니다. / 어떤 제품이 어떤 영향을 받았는지는 열어 보기 전에는 단정하기 어렵습니다.

# 낙뢰 뒤 나타나기 쉬운 증상
증상은 제품마다 다르지만 비슷하게 나타나는 모양이 있습니다.
- 번호판이 켜지지 않거나 일부 숫자 버튼만 불이 들어옴
- 번호를 눌렀는데 소리 없이 아무 반응이 없음
- 켜졌다 꺼지기를 반복하며 시작음이 계속 울림
- 모터가 돌다 멈추고 열림과 잠김이 맞지 않음
- 도어락 앱이나 인터폰 연동이 갑자기 끊김
한 가지만 보이면 일시적인 오류일 수 있고, 여러 개가 겹치면 부품 손상을 의심해 볼 만합니다.

# 먼저 집 전체 전기부터 확인하세요
도어락만 보지 마시고 같은 시각에 다른 기기가 어땠는지 떠올려 보세요. / 두꺼비집 차단기가 내려갔거나 공유기, 인터폰이 꺼져 있다면 집 전체에 영향이 있었다는 뜻입니다.
이럴 때는 차단기를 올려 전기가 정상으로 돌아온 뒤에 도어락을 다시 확인하는 게 순서입니다. / 전기가 불안정한 상태에서 도어락만 계속 만지면 원인을 가리기 어렵습니다.
안 들어가는 상황이라면 이 단계는 문 안쪽 가족에게 부탁하거나 관리사무소에 단지 전체 정전이 있었는지 물어보는 정도로 하시면 됩니다.

# 건전지를 뺐다 끼우는 간단한 재시작
전자 기기가 오작동할 때 가장 먼저 해볼 수 있는 방법이 전원을 껐다 켜는 것입니다. / 도어락은 문 안쪽 덮개를 열고 건전지를 모두 뺀 뒤 잠시 기다렸다가 다시 끼우면 됩니다.
문이 열려 있고 안쪽에서 작업할 수 있을 때만 하세요. / 건전지를 뺀 동안은 번호로 못 여는 상태가 되니 반드시 문을 열어 둔 채 시도해야 합니다.
극 방향을 맞춰 끼우고, 가능하면 새 건전지를 쓰는 편이 낫습니다. / 서지 때문이 아니라 마침 건전지가 약해진 경우도 이 방법에서 같이 해결되곤 합니다.
@ 건전지를 빼고 다시 끼우는 도어락 재시작

# 문 밖에서 번호판이 먹통일 때
밖에서 문 앞에 서 있는데 번호판이 전혀 반응하지 않으면 바깥쪽 아래의 비상 단자를 확인합니다. / 건전지를 대면 일시적으로 전원이 들어오는 제품이 많습니다.
서지로 회로가 손상된 경우에는 비상 전원을 대도 반응이 없을 수 있습니다. / 그때는 열쇠 구멍이 있는 제품이면 열쇠로 열고, 열쇠도 없다면 전화를 주세요.
번호판이 반쯤 켜졌다 꺼지는 상태에서 무리하게 여러 번 누르면 오류 잠금이 걸리기도 합니다. / 두세 번 시도해서 안 되면 멈추는 게 좋습니다.

# 이럴 때는 만지지 말고 기다리세요
천둥번개가 아직 치고 있는 중이라면 문 앞에서 오래 서 있지 마시고 건물 안쪽으로 들어가 계세요. / 도어락 때문에 안전을 놓칠 이유는 없습니다.
젖은 손으로 금속 부분을 만지거나 덮개를 열어 보는 것도 피해야 합니다. / 물기가 기판에 들어가면 멀쩡하던 부분까지 상할 수 있습니다.
연기 냄새가 나거나 도어락 주변이 뜨겁게 느껴지면 즉시 사용을 멈추고 건전지를 분리한 뒤 알려 주세요. / 이런 경우는 흔하지 않지만 보이면 바로 말씀해 주셔야 합니다.

# 열쇠로 여는 방법이 살아 있는지 점검
평소에 열쇠를 안 쓰다 보면 열쇠 구멍 덮개가 어디 있는지도 잊게 됩니다. / 이번 기회에 비상 열쇠가 어디에 있고 실제로 돌아가는지 확인해 두시면 좋습니다.
열쇠 구멍이 없는 제품은 비상 전원과 카드, 비밀번호가 전부입니다. / 이런 제품은 서지 뒤 먹통이 되면 문 앞에서 막히는 일이 더 쉽게 생깁니다.
열쇠가 보조키와 도어락 구멍 두 군데에서 쓰이는지, 어느 쪽이 안 돌아가는지도 같이 보세요. / 상황을 전화로 설명할 때 큰 도움이 됩니다.

# 석수동 위치와 증상은 이렇게 알려주세요
석수동은 주택과 빌라, 아파트가 섞여 있어 건물 형태를 알려주시면 도착 준비가 쉬워집니다.
- 건물 형태와 동, 호수, 몇 층인지
- 번개나 정전이 있었던 시각과 지금 번호판 상태
- 도어락에 전원선이나 인터폰 연결이 있는지
- 열쇠 구멍이 있는지, 열쇠가 지금 손에 있는지
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 필요한 장비를 챙겨 가기 좋습니다.

# 신분 확인과 비용 안내는 문을 열기 전에
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 늦은 시간이라면 경비실에 먼저 말해 두시면 수월합니다.
번거로운 절차지만 이웃과 집 주인 모두를 지키는 방법이라 생략하지 않습니다.

도어락 종류와 문 상태, 부품을 바꿔야 하는지를 보고 비용을 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니라고 하시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었고, 문 여는 방법은 [현관문 개문](door-open.html) 페이지에서 볼 수 있습니다.
@ 석수동 문 개방 전 도어락 상태 확인

# 열고 난 뒤 어디까지 고칠지 정하는 법
문이 열리면 재부팅 뒤 정상 동작하는지, 번호 등록과 삭제가 되는지, 잠김 소리가 정상인지를 함께 봅니다. / 한 번 정상으로 돌아온 듯 보여도 하루 이틀 뒤 다시 문제가 생기는 경우가 있어 며칠은 지켜보시는 게 좋습니다.
회로가 상한 것이 분명하면 [도어락 수리](doorlock-repair.html)로 가능한 범위인지 먼저 살핍니다. / 수리가 어렵거나 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
보험이나 제조사 보증이 적용되는지는 제 쪽에서 단정할 수 없습니다. / 사진과 교체 전 상태를 남겨 두시면 확인할 때 도움이 됩니다.

# 앞으로 번개철에 대비하는 습관
번개가 잦은 계절에는 인터폰이나 월패드 같은 연결 기기의 전원 어댑터를 꽂고 사는지 한 번 살펴보세요. / 오래 집을 비울 때 불필요한 전원선을 뽑아 두는 것도 기기를 지키는 방법입니다.
- 건전지는 늘 새것으로, 한 번에 모두 교체
- 비상 전원용 건전지를 가방이나 차에 하나 보관
- 열쇠 구멍이 있다면 보조 열쇠를 집 밖 믿을 만한 곳에 보관
- 이상한 시작음이 한 번이라도 나면 그날 바로 확인
오래 쓴 도어락일수록 작은 이상 신호를 놓치기 쉽습니다. / 평소에 알림 소리를 기억해 두시면 평소와 다른 소리를 알아차리기 좋습니다.

# 석수동 밖 안양 지역 출동
석수동 가까운 박달동, 비산동, 안양동은 물론 평촌동, 관양동, 호계동, 귀인동, 부흥동까지 다닙니다. / 범계역, 평촌역, 인덕원역 쪽도 24시간 출동합니다.
안양에서 다니는 동네는 [안양시 출장열쇠](anyang.html)에 정리해 두었고, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다. / 열쇠를 잃어버렸다면 [출장열쇠 부르기](key-call.html)도 참고하세요.

# 낙뢰 도어락 자주 묻는 질문
? 번개 맞은 도어락도 수리가 되나요? | 부품 상태에 따라 다릅니다. 열어 보고 수리가 가능한지 먼저 말씀드립니다.
? 건전지만 새로 넣으면 해결될 수도 있나요? | 네, 건전지가 약해서 생긴 증상이면 교체만으로 돌아오기도 합니다.
? 문을 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에도 전화해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.

# 번개철 도어락, 이것만 기억하세요
번개나 정전 뒤 도어락이 이상하면 일단 집 전체 전기를 보고, 건전지를 새로 끼워 재시작해 보세요. / 그래도 문 앞에서 막히면 억지로 열지 마시고 상태만 알려주세요.
24시출장열쇠는 석수동을 포함한 안양 전 지역에서 밤늦게도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
@ 석수동 24시 출장열쇠 010-3664-5455
