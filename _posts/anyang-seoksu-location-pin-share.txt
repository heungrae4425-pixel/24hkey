# 석수동에서 길 설명이 길어지는 이유
석수동은 안양역 방향으로 오가는 길과 안양천 쪽 길, 골목 주택가가 섞여 있는 동네입니다. / 같은 번지 근처라도 큰길에서 들어가는 입구가 여러 곳이라 말로만 설명하면 엇갈리기 쉽습니다.
문이 잠겨 마음이 급한 상황에서는 주소를 불러 주는 것도 쉽지 않습니다. / 이럴 때 휴대폰 위치 공유를 보내 주시면 말보다 훨씬 정확하게 전달됩니다.
이 글은 [안양 출장열쇠](anyang.html)를 부를 때 위치를 어떻게 보내면 좋은지 차근차근 적었습니다.
@ 석수동 휴대폰 지도 위치 공유 화면

# 위치 공유를 보내면 좋은 점
출발한 뒤에 길을 되묻는 전화가 줄어들면 그만큼 도착이 빨라집니다. / 문 앞에 계신 분도 설명하느라 애쓰지 않아도 됩니다.
- 골목 입구가 여러 곳이어도 같은 지점으로 찾아갈 수 있음
- 주소 번지수를 잘못 말해도 지도 위치로 바로잡을 수 있음
- 긴장해서 말이 꼬여도 정확한 장소가 전달됨
지도 위치가 있어도 호수나 층은 알 수 없으니 그 부분은 문자로 함께 적어 주세요.
특히 한 건물에 여러 세대가 사는 곳에서는 호수가 빠지면 도착해서도 한 번 더 확인해야 합니다. / 위치와 호수를 한 번에 보내 두면 그 시간을 아낄 수 있습니다.
메신저가 익숙하지 않다면 일반 문자로 지도 링크를 복사해 보내셔도 됩니다. / 받는 쪽에서 링크를 열면 같은 지점이 지도에 표시됩니다.

# 휴대폰으로 위치 보내는 방법
지도 앱이나 메신저의 위치 보내기 기능을 쓰면 됩니다. / 기기마다 화면이 조금 다르지만 순서는 비슷합니다.
- 메신저 대화창에서 더하기 버튼을 누릅니다
- 위치 또는 현재 위치 보내기를 고릅니다
- 지도에 찍힌 점이 지금 서 있는 곳과 맞는지 확인합니다
- 보내기를 누르고 이어서 호수를 문자로 적습니다
위치 기능이 꺼져 있으면 점이 엉뚱한 곳에 찍힙니다. / 설정에서 위치를 켜 두었는지 먼저 보시면 좋습니다.

# 점이 건물 옆 도로에 찍혔다면
건물이 빽빽한 곳에서는 지도의 점이 실제 위치에서 조금 벗어나기도 합니다. / 이때는 점을 손가락으로 직접 끌어 건물 위에 놓고 다시 보내시면 됩니다.
정확하지 않은 점 때문에 길 건너편으로 가는 일을 막으려면 건물 이름 대신 눈에 보이는 특징을 문자로 덧붙여 주세요. / 건물 색깔이나 입구 옆에 보이는 가게 간판 같은 것이면 충분합니다.
@ 석수동 골목 건물 입구와 지도 점 확인

# 휴대폰 배터리가 얼마 안 남았을 때
문 앞에서 오래 기다리면 휴대폰 배터리도 줄어듭니다. / 위치를 보냈다면 화면 밝기를 낮추고 불필요한 앱은 닫아 두세요.
배터리가 거의 없을 때는 위치를 먼저 보내고 통화는 짧게 하는 편이 좋습니다. / 전원이 꺼져도 이미 받은 위치는 그대로 남아 있습니다.
휴대폰이 아예 없는 상황이라면 이웃에게 전화를 잠깐 빌려 연락 주셔도 됩니다. / 그때는 위치 대신 주소와 눈에 띄는 건물 특징을 말씀해 주세요.

# 이웃 전화로 연락할 때는 이렇게
남의 전화를 빌리면 오래 쓰기 미안해서 말이 급해지기 쉽습니다. / 먼저 주소와 호수, 문 상태 세 가지만 짧게 말씀해 주세요.
나머지는 문자로 받으면 되니 번호를 남겨 달라고 하시면 됩니다. / 통화가 끊겨도 문자가 남아 있으면 다시 이어서 확인할 수 있습니다.
이웃 전화로 위치를 보내기 어렵다면 그분 휴대폰 화면의 지도를 함께 보며 현재 위치를 읽어 주셔도 됩니다. / 빌린 전화번호가 도착 연락을 받을 번호가 될 수 있으니 이웃분께 양해를 구해 두세요.

# 위치와 함께 문자에 적어 주면 좋은 것
위치 점만으로는 문 상태를 알 수 없습니다. / 짧게 아래 정도만 적어 주시면 준비가 훨씬 수월해집니다.
- 몇 층 몇 호인지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 도어락 모양 (손잡이 일체형, 버튼형 등)
- 안에 아이나 반려동물이 있는지
- 건물 입구에 공동 현관이 있는지
도어락이 보이게 사진을 한 장 찍어 보내 주시면 필요한 장비를 챙기는 데 도움이 됩니다.

# 위치를 보낸 뒤에는 이렇게 기다려 주세요
위치를 보냈다면 한자리에 머물러 주시는 것이 좋습니다. / 이리저리 움직이면 지도의 점과 실제 위치가 달라져 서로 헷갈립니다.
겨울이나 비 오는 날이면 처마나 건물 입구 안쪽처럼 바람을 피할 수 있는 곳에 서 계셔도 괜찮습니다. / 다만 위치를 보낸 곳에서 너무 멀리 벗어나지는 마시고, 자리를 옮겼다면 위치를 한 번 더 보내 주세요.
밝고 사람 다니는 곳에 서 계시고, 출발했다는 연락을 받으면 그때부터 건물 입구 쪽에서 맞이해 주세요. / 도착 시간은 거리와 길 상황에 따라 달라지니 출발할 때 먼저 말씀드립니다.

# 도착하면 신분 확인부터 합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 떠올려 두시면 좋습니다.
신분증이 집 안에 있다면 휴대폰에 있는 계약서 사본이나 고지서 사진이 도움이 되기도 합니다. / 이 경우 어떤 것이 가능한지는 도착 전에 전화로 먼저 안내해 드립니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
현관문 상태와 도어락 종류를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에서도 보실 수 있습니다.
@ 석수동 현관 도어락 개문 작업 전 확인

# 열고 난 뒤에 확인하는 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 함께 봅니다. / 원인이 배터리였다면 새것으로 바꾸고, 비밀번호 문제였다면 안쪽에서 새 번호를 등록합니다.
자주 같은 증상이 생긴다면 [도어락 수리](doorlock-repair.html)로 먼저 손보는 쪽을 권합니다. / 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문 여는 방식에 대해서는 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.

# 평소에 해 두면 좋은 준비
급할 때를 대비해 평소에 몇 가지만 해 두면 마음이 훨씬 편합니다.
- 집 주소와 호수를 메모장에 적어 휴대폰에 저장
- 가까운 사람에게 우리 집 도어락 모양을 알려 두기
- 도어락 사진을 휴대폰에 한 장 저장해 두기
- 즐겨 쓰는 지도 앱에 집을 즐겨찾기로 등록
- 배터리는 해가 바뀔 때 한 번에 교체
집을 즐겨찾기로 등록해 두면 위치 공유를 보낼 때 몇 번 누르지 않아도 됩니다.

# 석수동 말고 안양 어디든 갑니다
석수동 가까이 안양동, 박달동, 비산동, 호계동, 평촌동, 관양동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

# 마무리
