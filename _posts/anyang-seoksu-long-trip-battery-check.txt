# 길게 집을 비우기 전에 석수동 현관부터
석수동은 안양역 쪽으로 오가는 생활권에 사는 분들이 장기 출장이나 긴 여행을 떠나는 일이 잦은 동네입니다. / 짐 싸기에 정신이 없다 보면 현관 도어락까지 챙기지 못하고 떠나게 됩니다.
몇 주 뒤 돌아왔는데 문 앞에서 번호판이 꺼져 있으면 피곤한 몸으로 더 힘든 시간을 보내게 됩니다. / 출발 전에 십 분만 투자하면 대부분 막을 수 있는 일입니다.
이 글은 장기간 집을 비우기 전에 점검할 배터리와 보조키 체크리스트를 정리한 것입니다. / 돌아와서 문이 안 열리면 [안양 출장열쇠](anyang.html)를 어떻게 부르면 되는지도 함께 담았습니다.
@ 석수동 출발 전 현관 점검

# 비어 있는 동안에도 도어락은 전기를 씁니다
집을 비워도 도어락은 문이 잠겨 있는지 감지하고 번호판 대기 전력을 조금씩 씁니다. / 그래서 사람이 없는 기간이 길수록 배터리가 소모되는 시간도 길어집니다.
평소에는 몇 달 버티던 배터리도 오래 비우면 돌아올 때쯤 거의 바닥나 있을 수 있습니다. / 특히 경고음이 이미 났던 도어락은 장기 부재에 가장 취약합니다.
배터리 칸에 교체한 날짜를 적어 두었다면 이 시점에서 한 번 확인하세요. / 날짜 기록이 없다면 오래된 것으로 보고 바꾸는 것이 안전합니다.

# 출발 전날 배터리를 이렇게 점검하세요
먼저 번호판을 눌러 반응 속도가 평소와 같은지 봅니다. / 숫자가 느리게 켜지거나 눌렀을 때 소리가 작아졌다면 배터리가 약해졌다는 신호입니다.
경고음이 한 번이라도 났다면 장기 출장 전에 반드시 교체합니다. / 건전지는 반드시 새것으로 전부 한꺼번에 갈아 끼우세요.
교체할 때는 새 건전지의 방향을 확인하고 덮개를 끝까지 닫습니다. / 덮개가 덜 닫히면 접점이 흔들려 나중에 전원이 끊기기도 합니다.

# 건전지를 새로 넣은 뒤 확인할 것
새 건전지를 넣은 다음 문을 열고 닫으며 번호로 잠금과 열림이 되는지 직접 해보세요. / 문을 열어 놓은 채 한두 번 더 눌러 보고 소리가 정상인지 확인합니다.
등록된 번호나 카드가 지워지지 않았는지도 같이 봅니다. / 제품에 따라 건전지를 빼면 설정이 초기화되는 경우가 있습니다.
설정이 바뀌었다면 출발 전에 다시 등록해 두는 것이 안전합니다.
@ 석수동 도어락 배터리 교체 점검

# 보조키는 열쇠로 직접 돌려 봅니다
보조키가 있는 집은 출발 전에 열쇠로 한 번 잠그고 풀어 보세요. / 오래 쓰지 않아 뻑뻑해진 보조키는 막상 필요한 날 안 돌아가는 일이 있습니다.
열쇠가 뻑뻑하게 돌아간다면 억지로 힘을 쓰지 말고 전문가에게 점검받는 편이 낫습니다. / 열쇠 구멍에 기름을 뿌리는 것은 권하지 않습니다.
보조키를 잠그고 떠날지는 상황에 따라 다릅니다. / 오래 비울 때는 잠그고 가는 경우가 많지만, 대신 열쇠 위치를 확실히 알아 두어야 합니다.

장기 출장 중에 집에 관리를 부탁할 사람이 있다면 열쇠를 맡길 사람을 정해야 합니다. / 우편물이나 택배를 가져가 주는 이웃이나 가족이 있으면 번호나 열쇠를 안전하게 공유하세요.
번호를 알려줄 때는 메신저 대화방에 오래 남겨 두지 말고 확인 후 삭제하세요. / 돌아온 뒤에는 번호를 새로 바꿔 두는 것이 좋습니다.
열쇠를 현관 근처 화분이나 우편함에 숨겨 두고 가는 것은 하지 마세요. / 방범에도 좋지 않고 가장 먼저 찾아보는 자리입니다.

# 출발 직전 체크리스트
- 도어락 배터리를 새것으로 전부 교체했는가
- 번호와 카드가 정상 등록되어 있는가
- 보조키를 직접 돌려 열쇠가 잘 맞는가
- 문이 끝까지 닫히고 걸쇠가 걸리는지 소리로 확인했는가
- 비상 열쇠와 9V 건전지를 어디 둘지 정했는가
- 가족이나 이웃에게 연락처를 남겼는가
하나라도 비어 있다면 출발 전에 채워 두세요. / 돌아온 날 문 앞에서 생길 곤란한 일을 상당히 줄입니다.

# 장기 부재 중 문이 평소와 달라지는 일
오래 비우는 동안 겨울에는 결로와 한파, 여름에는 습기와 열기가 번호판에 영향을 줄 수 있습니다. / 비어 있는 집은 환기가 안 되어 문틀에 습기가 차기도 합니다.
그래서 돌아오면 문이 뻑뻑하거나 번호판 반응이 느린 경우가 생깁니다. / 마른 천으로 번호판을 닦고 잠시 뒤 다시 눌러 보세요.
문틀이 변형되면 걸쇠가 덜 들어가 문이 잘 안 열리기도 합니다. / 이럴 때는 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보면 열리기도 합니다.

# 돌아왔는데 문이 안 열릴 때 확인 순서
먼저 번호판에 불이 들어오는지 봅니다. / 안 들어오면 바깥쪽 비상 단자에 9V 건전지를 대어 보세요.
불이 들어오는데 번호가 안 맞는 느낌이면 오래 비운 사이 입력을 잊은 것일 수 있으니 천천히 다시 눌러 보세요. / 서너 번 해도 안 되면 멈추는 것이 좋습니다.
보조키가 잠겨 있다면 열쇠를 꽂아 방향을 확인합니다. / 억지로 힘을 쓰지 말고 열쇠가 안 돌아가면 전화하세요.

# 전화로 알려주실 내용
석수동 어디인지, 가까운 역 방향과 건물 이름을 말씀해 주세요. / 번호판 상태, 경고음 여부, 도어락 모양을 짧게 알려주시면 됩니다.
얼마나 오래 비웠는지 알려주시면 원인을 좁히는 데 도움이 됩니다. / 사진을 문자로 보내 주시면 더 빠릅니다. [열쇠 출장 요청](key-call.html) 페이지에도 준비할 것을 적어 두었습니다.

# 도착하면 먼저 신분을 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
긴 여행에서 막 돌아왔다면 가방 안에 신분증이 있는지 먼저 보세요. / 짐 안에 있어도 바로 보여주실 수 있게 꺼내 두시면 수월합니다.
@ 석수동 신분 확인과 개문 준비

# 비용은 열기 전에 말씀드립니다
문 종류와 상태를 보고 먼저 비용을 말씀드리고, 괜찮다고 하시면 시작합니다. / 끝내 못 열면 비용은 받지 않습니다.
열고 난 뒤 말없이 붙는 비용도 없습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열린 뒤 점검과 수리
문이 열리면 도어락이 잘 작동하는지와 배터리 상태를 같이 봅니다. / 배터리가 원인이었다면 새 배터리로 바꿔 드립니다.
고장이 반복되면 [도어락 수리](doorlock-repair.html)로 먼저 손볼 수 있는지 보고, 너무 낡았다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 문 여는 방식은 [현관문 개문](door-open.html)에서도 볼 수 있습니다.

# 석수동 말고 안양 어디든 갑니다
석수동 옆 안양동, 박달동, 비산동을 비롯해 안양 안이면 동네 상관없이 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
