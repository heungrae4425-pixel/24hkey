# 석수동으로 이사 오셨다면 문부터
석수동은 빌라와 주택, 아파트가 섞여 있어 이사가 잦은 동네입니다. / 이사하고 나서 짐 정리에 바쁘다 보면 현관문은 가장 나중에 챙기게 됩니다.
하지만 이사 직후가 도어락 관리의 가장 좋은 타이밍입니다. / 이 글은 안양 석수동으로 이사한 뒤 문을 정리하는 순서를 적었습니다.
@ 석수동 이사 후 도어락 초기화 비밀번호

# 이사 온 집 도어락, 누가 알고 있을까
전에 살던 사람이 쓰던 번호와 카드가 그대로 남아 있을 수 있습니다. / 이사할 때 번호를 지우고 간다는 보장은 없습니다.
- 전 입주자가 쓰던 번호
- 중개나 청소, 인테리어를 도운 사람이 아는 번호
- 이사 당일 임시로 쓰던 번호
이런 번호를 새 번호로 바꿔 두는 것이 안심됩니다.

# 가장 먼저 비밀번호를 새로 등록하세요
새 번호는 이사 당일에 바로 등록하는 것이 좋습니다. / 그날 안에 하지 못하면 이사 업체 번호는 꼭 바꿔 주세요.
번호를 등록하는 방법은 제품마다 다릅니다. / 안쪽 덮개를 열고 설정 버튼이나 안내 소리에 따라 하면 됩니다.

# 카드키와 태그도 모두 새로
이전 입주자의 카드가 남아 있을 수 있습니다. / 카드를 모두 지우고 새 카드만 등록하세요.
- 기존 카드 모두 삭제
- 새 카드 가족 수만큼 등록
- 카드 하나는 집 밖에 따로 보관
카드 등록 방법은 제품 설명서에 나옵니다.
@ 석수 열쇠집 이사 도어락 점검

# 초기화는 제품마다 방법이 다릅니다
초기화 버튼을 누르는 방법이 제품마다 달라 한 번 확인이 필요합니다. / 잘못 누르면 설정이 엉키기도 합니다.
방법이 어렵다면 문 앞에서 전화 주시면 같이 보며 안내해 드립니다. / 제조사 이름이 보이면 알려 주세요.

# 열쇠도 챙기세요
현관문에 열쇠 구멍이 있다면 이전 열쇠가 몇 개 있는지 확인하세요. / 중개 사무소나 집주인에게 받은 열쇠의 개수를 세어 보세요.
열쇠가 부족하거나 전 입주자가 몇 개를 가지고 있는지 모르면 불안하게 됩니다. / 이럴 때는 열쇠 구멍(실린더) 교체를 권해 드립니다.

# 열쇠 구멍을 바꿔야 할 때
- 열쇠 개수를 정확히 모르는 경우
- 이전 입주자와 연락이 어려운 경우
- 열쇠가 많이 닳아 돌리기 불편한 경우
- 이사 후 집을 오래 비워 둘 예정인 경우
교체가 필요한 경우 [출장 열쇠](key-call.html)에서 실린더 교체를 도와드립니다.

# 이삿날 자주 생기는 일
짐을 나르다가 문이 닫혀 잠기는 일이 의외로 많습니다. / 이삿짐 차량이 오기 전에는 문을 열어 둔 채로 두세요.
이삿날은 비밀번호와 카드가 정리되지 않은 시기라 문이 잠기면 당황하기 쉽습니다. / 이럴 때를 대비해 새 번호를 가족에게 바로 알려 두세요.

# 사시는 분인지 확인합니다
이사 당일에도 문이 잠겨서 전화하는 경우가 있습니다. / 사시는 분인지 확인이 필요하니 계약서나 우편물 등을 준비해 주세요.
신분증과 주소가 맞지 않는 경우 계약서나 관리사무소 확인으로 대신할 수 있습니다. / 확인 방법은 전화로 먼저 안내해 드립니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
@ 석수동 도어락 번호 초기화 설정

# 도어락이 오래됐다면 교체도 생각해 보세요
이사 온 집의 도어락이 오래된 제품이라면 이 기회에 점검해 보세요. / 배터리가 약하거나 소리가 이상하면 [도어락 수리](doorlock-repair.html)로 먼저 확인합니다.
제품이 너무 오래되어 수리가 어렵다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 바꾸기 전에는 먼저 여쭙니다.

# 이사 후 체크리스트
- 새 비밀번호 등록, 이전 번호 삭제
- 카드와 열쇠 정리, 개수 확인
- 배터리 새것으로 교체
- 보조키가 있으면 작동 확인
- 가족에게 새 번호 알리기
한꺼번에 하면 30분이면 끝납니다.

# 자주 묻는 질문

? 이사 당일에도 오시나요? | 시간 상관없이 24시간 받습니다. 위치만 알려 주세요.
? 열쇠 구멍도 바꾸나요? | 열쇠 개수가 불확실하면 교체를 권해 드립니다. 먼저 여쭙고 진행합니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 사 둔 도어락도 달아 주시나요? | 모델명을 알려 주시면 우리 집 문에 맞는지 먼저 확인합니다.
