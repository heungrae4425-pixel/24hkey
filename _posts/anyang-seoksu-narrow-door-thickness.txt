# 석수동 도어락, 제품보다 문 두께부터 보세요
석수동에서 도어락을 새로 달려는 분들은 보통 디자인이나 기능부터 비교합니다. / 그런데 막상 설치하는 날 문이 너무 얇거나 두꺼워서 제품이 안 맞는 일이 생각보다 자주 있습니다.
안양역 쪽으로 오가는 분들 가운데 오래된 빌라나 다세대에 사시는 경우 문 두께가 제각각입니다. / 그래서 이 글은 안양 석수동에서 문 두께에 맞춰 도어락을 고르는 순서를 정리했습니다.
사려고 마음먹은 제품이 있어도 먼저 문 두께를 재 보시면 헛걸음을 줄일 수 있습니다. / 설치는 [도어락 설치](doorlock-install.html) 안내에도 기본 순서를 적어 두었습니다.
@ 석수동 도어락 설치 전 문 두께 측정

# 문 두께가 왜 중요한가
도어락은 문의 바깥쪽 본체와 안쪽 본체를 연결 봉과 나사로 이어서 고정합니다. / 이 연결 부품의 길이가 문 두께와 맞아야 양쪽이 단단히 조여집니다.
문이 너무 얇으면 부품이 남아서 헐겁게 흔들리고, 너무 두꺼우면 부품이 모자라 아예 닿지 않습니다. / 억지로 끼우면 당장은 되는 것 같아도 몇 달 안에 손잡이가 처지거나 잠금이 뻑뻑해집니다.

# 줄자로 재는 위치는 문 옆면입니다
문을 열어 놓고 걸쇠가 튀어나온 옆면에서 문 앞뒤 간격을 재면 됩니다. / 문틀에 가려진 곳이 아니라 문이 맨눈으로 보이는 단면에서 재야 정확합니다.
문 가장자리가 둥글게 마감된 경우 가장 두툼한 지점을 기준으로 삼아 주세요. / 한 번만 재지 말고 위, 가운데, 아래 세 군데를 재서 같은지 확인하면 더 안전합니다.
- 줄자는 눈금이 분명한 것으로 준비
- 문 단면의 위, 가운데, 아래 세 군데를 측정
- 숫자는 휴대폰 메모에 적어 두기
- 문 단면을 사진으로도 찍어 두기

# 얇은 문에서 자주 생기는 일
석수동처럼 빌라와 연립이 섞인 동네에는 철판이 얇은 현관문이 꽤 있습니다. / 얇은 문은 도어락 뒷판이 문 안쪽에서 덜그럭거리기 쉽습니다.
이럴 때는 얇은 문용 연결 부품을 쓰거나 스페이서를 끼워 간격을 맞춥니다. / 이런 부품은 제품마다 따로 정해져 있어서 미리 구해 두면 설치가 빨라집니다.
문이 얇다고 해서 도어락을 못 다는 것은 아닙니다. / 다만 제품 설명서에 적힌 문 두께 범위를 꼭 확인해야 합니다.
문 두께가 범위의 맨 끝에 걸리는 경우에는 제품이 맞는다고 해도 조임이 빡빡하거나 헐거울 수 있습니다. / 범위 한가운데에 들어오는 제품을 고르는 편이 오래 쓰기에 좋습니다.
같은 건물에서도 층마다 문 두께가 다른 경우가 있어서, 옆집 이야기를 듣고 고르면 어긋날 때가 있습니다. / 내 문은 내 줄자로 재 보는 것이 가장 정확합니다.

# 두꺼운 문은 이런 점을 봅니다
방화문이나 단열을 위해 속이 꽉 찬 문은 두께가 상당히 나갑니다. / 이런 문에는 일반 규격의 연결 봉이 짧아 연장형 부품이 필요할 수 있습니다.
문이 두꺼우면 바깥 본체와 안쪽 본체가 멀어져서 배선도 팽팽해집니다. / 선이 당겨지면 접촉이 불안정해지니 여유 있는 길이의 제품인지 확인해 주세요.
문을 여닫을 때 선이 문틈에 끼이지 않는 구조인지도 함께 보면 좋습니다. / 두꺼운 문일수록 손잡이 축이 길어져 회전이 무거워질 수 있어서, 달고 나서 손잡이를 여러 번 돌려 느낌을 확인합니다.
@ 석수동 두꺼운 방화문 도어락 연결 봉 길이

# 문 두께 말고 같이 재야 하는 것
두께만큼 중요한 것이 문 끝에서 도어락 중심까지의 거리입니다. / 기존 구멍과 새 제품이 맞지 않으면 문에 새로 구멍을 내야 하는 상황이 됩니다.
보조키와 본키 사이의 간격도 제품마다 다릅니다. / 간격이 달라서 구멍을 넓혀야 한다면 문 표면이 상할 수 있으니 미리 알려 주세요.
기존 도어락을 떼기 전에 어떤 형태였는지 사진으로 남겨 두시면 비교하기 좋습니다. / 손잡이형인지 푸시풀형인지, 문 옆에 걸쇠만 있는지 함께 알려 주시면 됩니다.

# 기존 구멍 모양이 다르면
오래전 쓰던 열쇠식 손잡이를 떼면 문에 큰 원형 구멍이 남아 있습니다. / 이 구멍을 그대로 쓸 수 있는 제품과 가림판이 필요한 제품이 따로 있습니다.
가림판으로 가려지는 크기인지, 아니면 문을 손봐야 하는지는 직접 문을 봐야 정확히 알 수 있습니다. / 사진을 먼저 보내 주시면 대략 어떤 경우인지 말씀드립니다.
구멍 둘레에 페인트가 벗겨졌거나 녹이 올라온 자국이 있다면 그 부분도 같이 찍어 주세요. / 가림판이 그 자국을 덮을 수 있는지에 따라 제품 선택이 달라집니다.

# 전화로 문의할 때 알려 주실 것
문 두께와 사진, 기존 제품 모양만 알려 주셔도 상담이 훨씬 수월합니다. / 숫자를 모르겠으면 사진만 보내셔도 됩니다.
- 문 옆면에서 잰 두께 숫자
- 기존 도어락 앞뒤 사진
- 보조키가 있는지, 몇 개인지
- 문이 철문인지 나무문인지
- 사시는 동네와 대략의 위치
문의는 [도어락 교체](doorlock-replace.html) 안내를 먼저 보시고 전화 주셔도 좋습니다.

# 이런 건 하지 마세요
제품을 먼저 사 놓고 문에 억지로 끼워 맞추는 것은 피해 주세요. / 반품이 어렵거나 문에 구멍이 더 나면 되돌릴 수 없습니다.
드릴로 문에 직접 구멍을 넓히는 일도 권하지 않습니다. / 철문은 한 번 뚫으면 되돌릴 수 없고, 구멍이 어긋나면 문 한쪽을 새로 막아야 합니다.
설명서의 문 두께 범위를 보지 않고 포장 문구만 보고 고르는 것도 위험합니다. / 같은 이름의 제품이라도 두께에 따라 부품이 다르게 들어 있기 때문입니다.

# 배터리 방전으로 문이 안 열릴 때와는 다릅니다
설치 문제와 별개로 도어락이 안 열려 급히 연락 주시는 경우도 많습니다. / 이럴 때는 두께 이야기보다 먼저 번호판이 꺼졌는지부터 확인합니다.
9V 건전지를 비상 단자에 대 보고 안 되면 전화 주세요. / 문을 열어야 하는 일은 [현관문 개문](door-open.html) 페이지에 방법을 적어 두었습니다.

# 오셔서 하는 일은 이렇게 진행됩니다
먼저 문 두께와 구멍 상태를 직접 보고 맞는 제품과 부품을 말씀드립니다. / 비용은 작업 전에 먼저 말씀드리고 동의하시면 시작합니다.
문을 열어야 하는 상황이면 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에서도 볼 수 있습니다.
@ 석수동 도어락 교체 작업 전 상담

다니는 동네는 [안양시 출장열쇠](anyang.html)에 정리했습니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.
