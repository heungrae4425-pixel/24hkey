# 새 도어락을 사기 전에 재야 하는 두 가지
석수동은 안양역 쪽 생활권에서 주택과 아파트, 빌라가 함께 있는 동네입니다. / 지은 시기가 다른 건물이 섞여 있어서 문 규격도 집마다 조금씩 다릅니다.
도어락을 새로 사려고 알아보다 보면 걸쇠 폭, 백셋, 문 두께 같은 낯선 말이 나옵니다. / 이 값들이 맞지 않으면 새 제품이 문에 안 들어가거나 헐겁게 달립니다.
이 글은 집에서 줄자 하나로 걸쇠 폭과 백셋을 재는 법과, 재지 않고 샀을 때 생기는 일을 정리했습니다. / 자신이 없을 때 출장열쇠가 어떻게 확인하는지도 적었습니다.
@ 석수동 도어락 걸쇠 폭과 백셋 측정

# 걸쇠 폭과 백셋이 무엇인지부터
걸쇠 폭은 문 옆면에서 튀어나와 문틀에 걸리는 부품이 놓인 판의 너비입니다. / 문 옆면 판을 따라 위에서 보았을 때 가로 길이를 말합니다.
백셋은 문 옆면 끝에서 손잡이나 도어락 구멍 중심까지의 거리입니다. / 어느 쪽에서 재느냐에 따라 값이 달라지니 기준점을 정확히 잡아야 합니다.
이 두 가지가 규격에 맞아야 새 도어락 본체가 구멍에 제대로 앉고 걸쇠가 문틀과 높이를 맞춥니다.

# 줄자와 사진만 있으면 됩니다
준비물은 간단합니다. / 긴 줄자나 자, 휴대폰, 메모할 종이면 충분합니다.
작업 전에 문을 열어 둔 채로 고정해 두세요. / 문이 흔들리면 측정값이 틀어집니다.
측정은 두 번 해서 같은 값이 나오는지 확인하세요. / 줄자 끝을 문 모서리에 정확히 대지 않으면 몇 밀리미터씩 틀어지기 쉽습니다.
숫자를 메모하면서 사진도 같이 찍어 두면 나중에 제품을 고르거나 전화로 설명할 때 훨씬 편합니다.

# 문 옆면 판을 열어서 걸쇠 폭 재기
문이 열린 상태에서 문 옆면의 걸쇠 쪽 금속판을 보세요. / 판 가운데에 걸쇠가 있고 위아래로 나사가 있습니다.
- 판의 가로 폭을 줄자 눈금 하나하나 읽어서 기록
- 판의 세로 길이도 같이 기록
- 걸쇠 머리가 둥근지 네모인지 모양도 기록
숫자보다 사진이 더 정확할 때가 있습니다. / 줄자를 판 옆에 붙여 놓고 정면에서 한 장 찍어 두세요.

# 백셋은 옆면 끝에서 구멍 중심까지
백셋은 문 옆면 끝(문틀 쪽 모서리)에서 손잡이 구멍 중심까지의 거리로 잽니다. / 구멍 가장자리가 아니라 정확히 가운데를 보아야 합니다.
이미 달린 도어락을 떼기 어렵다면 문 안쪽 면에서 구멍 지름의 가운데를 어림해 같이 보세요. / 정밀하게 하기 어렵다면 사진을 보내 주시는 것도 방법입니다.
제품 설명서에는 이 값이 가까운 규격으로 적혀 있는 경우가 많습니다. / 우리 집 값과 가장 가까운 규격을 찾으면 됩니다.
@ 줄자로 문 옆면 끝에서 손잡이 구멍 중심까지 재는 모습

# 문 두께도 같이 확인하세요
걸쇠 폭과 백셋만큼 중요한 것이 문 두께입니다. / 문 옆면에서 앞뒤 두께를 한 번 재 보면 됩니다.
문이 두꺼우면 도어락 연결봉이 짧아서 안 맞고, 너무 얇으면 헐겁게 달립니다. / 오래된 문일수록 두께가 다른 경우가 많습니다.
- 문 옆면 앞뒤 두께
- 문 가장자리에 덧댄 판이 있는지
- 문 가운데가 불룩하게 튀어나왔는지
덧댄 판이나 장식이 있으면 본체 위치가 바뀔 수 있습니다.

# 규격이 맞지 않으면 생기는 일
치수를 재지 않고 제품부터 사면 문에 맞지 않는 일이 생깁니다. / 설치한 뒤에야 알게 되면 반품이 어렵고 문에 낸 구멍이 쓸모없어지기도 합니다.
- 걸쇠가 문틀 구멍에 맞지 않아 문이 덜 닫힘
- 손잡이가 한쪽으로 쏠리거나 헛돔
- 본체가 문 안쪽에서 헐겁게 흔들림
- 보조키 위치와 겹쳐 설치 자체가 불가능
이런 문제는 조금만 미리 확인하면 대부분 피할 수 있습니다.
특히 보조키 위치와 새 본체가 겹치는지는 설치 전에 문을 보고 판단해야 합니다. / 사진으로 보내 주시면 겹칠 가능성이 있는지 같이 봐 드립니다.

# 같은 사이즈라도 걸쇠 모양이 다를 수 있습니다
폭이 같아 보여도 걸쇠 머리 모양과 판 두께가 다르면 그대로 쓸 수 없습니다. / 판이 얇은 제품은 문 옆면 홈과 높이가 어긋납니다.
기존 걸쇠를 그대로 쓰는 제품이 있고, 새 걸쇠를 함께 쓰는 제품이 있습니다. / 어떤 쪽인지 설명서에서 먼저 확인해 보세요.
제품 설명서에서 적용 문 두께와 적용 백셋을 먼저 보고 사시는 것이 순서입니다.

# 오래된 석수동 주택 문은 특히 조심하세요
오래된 집일수록 문을 한 번 이상 수리하거나 덧댄 흔적이 있을 수 있습니다. / 이럴 때는 기존 구멍이 규격과 다르게 가공된 경우도 있습니다.
문틀이 처졌거나 문이 뒤틀렸다면 규격을 맞춰도 설치 뒤 걸리는 일이 생깁니다. / 설치 전에 문이 제대로 닫히는지도 같이 봐야 합니다.
문 가장자리가 부풀어 오르거나 페인트가 여러 겹 칠해진 문도 측정값이 달라 보일 수 있습니다. / 이런 때는 칠이 두껍게 쌓인 부분을 피해서 재세요.
이런 문은 규격을 재는 것만으로는 부족하고, 문 상태 전체를 같이 보아야 할 때가 많습니다.

# 석수동에서 출장열쇠를 부르면 이렇게 확인합니다
석수동에서 [안양 출장열쇠](anyang.html)를 부르시면 먼저 기존 도어락을 떼고 걸쇠 폭과 백셋, 문 두께를 직접 확인합니다. / 맞는 제품 범위를 알려 드린 뒤 설치 여부를 결정하시게 합니다.
사진과 치수를 먼저 보내 주시면 전화로 가능한 범위를 가늠해 드릴 수 있습니다. / 새로 다는 일은 [도어락 설치](doorlock-install.html)에서 확인할 것을 보실 수 있습니다.
@ 출장열쇠가 걸쇠 폭과 백셋을 확인하는 모습

# 신분 확인과 비용 안내
문을 여는 일이 있을 때는 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
비용은 문 상태와 제품 종류를 보고 문 열기 전에, 설치 전에 먼저 말씀드립니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 교체할지 고쳐 쓸지도 같이 생각해 보세요
기존 도어락이 규격이 맞고 고장이 가벼우면 [도어락 수리](doorlock-repair.html)로 해결될 수도 있습니다. / 꼭 바꿔야 한다면 지금 재 둔 값이 기준이 됩니다.
정말 오래되어 부품 구하기가 어렵거나 안쪽이 많이 상했다면 [도어락 교체](doorlock-replace.html)를 권해 드립니다. / 교체 전에 알아 두면 좋은 것은 안내 페이지에 정리해 두었습니다.

# 석수동 말고 안양 어디든 갑니다
석수동 가까이 평촌동, 관양동, 비산동, 호계동, 귀인동, 부흥동, 안양동, 박달동도 다닙니다. / 안양 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [안양시 출장열쇠](anyang.html) 페이지에, 다른 지역은 [출장 지역](area.html) 지도에 정리해 두었습니다.
