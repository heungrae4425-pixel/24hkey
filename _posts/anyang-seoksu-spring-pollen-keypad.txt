# 봄만 되면 번호판이 말을 안 듣는다면
처음에는 가끔 한 번 더 눌러야 하는 정도라 넘기기 쉽지만, 그대로 두면 점점 심해집니다. / 눈치채는 순간 가볍게 닦아 두는 것이 가장 좋은 대처입니다.
석수동은 안양역 쪽으로 오가며 산책길과 가까워, 봄이면 창을 열어 두는 집이 많습니다. / 그렇게 지내다 보면 어느 날부터 번호판 버튼이 깊이 눌리지 않거나 눌려도 반응이 늦는 일이 생깁니다.
꽃가루와 황사는 눈에 보이지 않는 사이 버튼 틈새에 쌓입니다. / 이 글은 그런 상태를 알아보고 안전하게 정리하는 방법을 적었습니다.
문이 안 열릴 만큼 심하다면 [석수동 출장열쇠](anyang.html) 안내도 함께 보세요.
@ 석수동 번호판 버튼 틈새 먼지

# 왜 봄에 유독 심할까
번호판이 바깥쪽 복도나 계단에 노출된 구조라면 먼지가 더 직접적으로 닿습니다. / 반대로 문 앞이 닫힌 공간이면 비교적 덜하지만, 신발과 옷에 묻어 들어오는 가루가 쌓입니다.
꽃가루는 끈적한 성분이 있어 습기와 만나면 버튼 가장자리에 달라붙습니다. / 황사는 아주 고운 가루라 틈새로 파고들어 쌓입니다.
이 둘이 섞이면 버튼이 눌린 채 걸리거나 눌려도 접점에 닿지 못합니다. / 비 오는 날과 맑은 날을 오가는 봄 날씨가 문제를 더 키웁니다.

# 이런 증상이면 의심해 보세요
한쪽 열의 버튼만 안 눌린다면 먼지가 한 줄로 쌓였을 수 있습니다. / 이런 위치 단서도 전화로 알려주시면 점검 방향을 잡는 데 큰 도움이 됩니다.
증상이 날씨 좋은 날에는 괜찮다가 비 오는 날에만 심해진다면 습기가 가세했다는 뜻입니다. / 이런 패턴을 기억해 두면 설명하기도 쉽습니다.
- 특정 숫자만 유독 안 눌린다
- 누르면 딸깍 대신 뻑뻑한 느낌이 난다
- 두세 번 눌러야 입력된다
- 번호는 맞는데 열림 소리가 늦다
증상이 한두 숫자에 몰려 있다면 그 버튼 둘레에 먼지가 쌓였을 가능성이 큽니다. / 전체가 안 켜지는 경우는 배터리 쪽을 먼저 보세요.

# 가장 먼저 마른 천으로
닦는 동안에는 문이 닫히지 않게 한 손으로 잡거나 안쪽에서 확인하는 사람이 있으면 편합니다. / 문이 잠긴 채라면 천을 대는 것만으로 충분합니다.
부드러운 마른 천이나 안경 닦는 천으로 번호판 표면을 쓸어 보세요. / 힘주어 문지르지 말고 가볍게 한 방향으로 닦습니다.
표면 먼지만 걷혀도 반응이 돌아오는 경우가 많습니다. / 천에 약품을 묻히는 것은 지금 단계에서는 필요 없습니다.
@ 석수동 마른 천으로 번호판 닦기

# 틈새는 부드러운 솔로
작업은 밝은 곳에서 하시고, 눈에 먼지가 들어가지 않게 얼굴을 너무 가까이 대지 마세요. / 마스크를 쓰면 먼지를 마시는 것도 막을 수 있습니다.
버튼 사이 가장자리는 천이 닿지 않습니다. / 칫솔처럼 부드러운 솔이나 화장 솔로 틈새를 살살 털어 내세요.
- 솔은 털이 부드러운 것으로
- 먼지를 안쪽으로 밀어 넣지 않게 비스듬히
- 버튼을 하나씩 눌러 가며 털기
- 작은 먼지는 바람을 약하게 불어 날리기
센 바람이나 압축 공기는 먼지를 안으로 밀어 넣을 수 있어 권하지 않습니다.

# 물기가 있는 천은 이렇게만
끈적임이 남아 있으면 물에 적신 천을 아주 꽉 짠 뒤 표면만 닦고 바로 마른 천으로 마무리합니다. / 물이 번호판 틈으로 흘러들면 안쪽 기판이 상할 수 있으니 특히 조심하세요.
도어락에 물이나 세정제를 직접 뿌리는 일은 하지 마세요. / 알코올 같은 약품은 표면 코팅을 상하게 할 수 있어 권하지 않습니다.

# 하지 말아야 할 것
치약이나 연마제로 문질러 닦는 방법을 인터넷에서 본 분들도 있는데, 번호판 표면이 긁혀 숫자가 지워질 수 있습니다. / 표면 글자가 닳으면 다시 되돌릴 수 없습니다.
- 버튼을 송곳이나 이쑤시개로 후비기
- 번호판 덮개를 억지로 열기
- 버튼을 세게 반복해서 눌러 풀어 보기
- 스프레이 윤활제를 틈새에 뿌리기
윤활제는 먼지를 더 끌어당겨 나중에 더 심하게 눌어붙게 합니다. / 급한 마음에 한 일이 고장을 키우는 경우가 많습니다.

# 닦았는데도 안 눌린다면
계속 눌러 보는 사이 오류 차단이 걸리면 한동안 입력이 막힙니다. / 안 되면 몇 분 쉬었다가 천천히 다시 시도하세요.
먼지가 안쪽까지 들어갔거나 접점이 습기를 먹었을 수 있습니다. / 이럴 때는 며칠 두고 보는 것보다 점검을 받는 편이 낫습니다.
문이 잠긴 상태라면 비상 전원 단자를 먼저 확인해 보세요. / 단자가 없거나 그래도 안 열리면 상태만 알려주세요.

# 전화할 때 알려주실 것
봄철 먼지가 원인이라 짐작되면 그렇게 말씀해 주셔도 됩니다. / 최근에 청소를 시도했다면 어떤 방법을 썼는지도 알려주시면 좋습니다.
- 어느 숫자 버튼이 안 눌리는지
- 눌렀을 때 소리나 불빛이 나는지
- 문이 잠겨 있는지, 안에 사람이 있는지
- 도어락 모양
번호판 사진을 한 장 보내 주시면 큰 도움이 됩니다. / 문 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 석수동 도어락 번호판 점검

# 도착하면 사시는 분인지 확인합니다
신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나가 필요합니다. / 번거롭지만 문을 여는 일이라 반드시 거치는 절차입니다.
신분증이 집 안에 있으면 관리사무소나 경비실에 먼저 부탁해 보세요.

# 비용은 시작 전에 먼저 말씀드립니다
버튼 청소로 되는지, 부품을 봐야 하는지 상태를 보고 설명드립니다. / 비용은 문 열기 전에 먼저 말씀드리고 동의하시면 시작합니다.
끝내 못 열면 비용은 받지 않으며, 부품을 바꿀 때도 미리 여쭙니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 수리로 될지 교체가 나을지
처음부터 교체를 권하지는 않고, 닦아서 쓸 수 있는지를 먼저 봅니다.
접점이 깨끗해진 뒤에도 몇 달 지나 같은 증상이 반복된다면 내부 밀봉이 약해진 제품일 수 있습니다. / 그런 경우를 구분해서 설명드립니다.
청소와 접점 정리로 돌아오면 [도어락 수리](doorlock-repair.html) 안에서 끝납니다. / 번호판 코팅이 닳고 버튼이 계속 눌어붙는 제품은 [도어락 교체](doorlock-replace.html)를 말씀드릴 수 있습니다.
선택은 사시는 분이 하시고 억지로 권하지 않습니다.

# 봄이 오기 전에 해 둘 관리
가을에 한 번 번호판 틈새를 정리해 두면 봄에 쌓일 양이 적습니다. / 시기를 정해 두면 잊지 않고 챙기게 됩니다.
- 꽃가루가 심한 날은 창을 닫고 환기하기
- 외출복을 현관 밖에서 털고 들어오기
- 주말마다 번호판 표면 마른 천으로 닦기
- 비 온 뒤 물기 남지 않았는지 확인
작은 관리 몇 가지만으로도 버튼이 눌어붙는 일을 많이 줄일 수 있습니다.

# 자주 묻는 질문
먼지 문제는 눈에 잘 띄지 않아서 발견이 늦습니다. / 아래 답변은 많이 받는 질문을 정리한 것입니다.

? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
