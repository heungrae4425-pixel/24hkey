# 범박동에서 전화 한 통을 짧게 끝내려면
범박동은 역곡동과 가까운 생활권에 아파트와 빌라, 새로 지은 단지가 함께 있는 동네입니다. / 문 앞에서 급하게 전화를 걸면 무엇부터 말해야 할지 몰라 같은 말을 여러 번 하게 되기 쉽습니다.
통화가 길어지면 그만큼 출발이 늦어집니다. / 말할 순서만 정해 두면 삼십 초 안에 필요한 내용이 다 전해집니다.
이 글은 범박동에서 [부천 출장열쇠](bucheon.html)에 전화하기 전에 정리해 두면 좋은 내용과 통화 순서, 기다리는 동안 할 일을 담았습니다.
@ 범박동 아파트 빌라 출장열쇠 전화 준비

# 통화 첫 삼십 초에 말할 순서
아래 순서대로 말씀해 주시면 받는 쪽에서 되묻는 일이 거의 없습니다. / 종이에 적을 필요 없이 이 순서만 기억해 두세요.
- 어디인지: 범박동, 단지 이름이나 건물 번지, 동과 호수
- 어느 문인지: 내 집 현관인지, 공동현관인지
- 어떤 상태인지: 번호판 불빛과 소리
- 누가 어디 있는지: 지금 문 밖인지, 안에 누가 있는지
- 급한 사정: 아이, 반려동물, 켜 둔 불
마지막 다섯 번째는 해당될 때만 말씀하시면 됩니다. / 해당된다면 맨 처음에 말씀해 주셔도 좋습니다.

# 단지와 동, 이렇게 말하면 빨리 찾습니다
범박동 아파트는 단지 안에 동이 여러 개라 동 번호를 정확히 알려 주시는 게 중요합니다. / 정문, 후문 가운데 어느 쪽으로 들어오면 가까운지도 알려 주시면 좋습니다.
빌라라면 건물 이름이 작게 붙어 있거나 아예 없는 경우가 있습니다. / 이럴 때는 도로명 주소와 1층 모습, 주변에 보이는 큰 건물을 함께 말씀해 주세요.
휴대폰 지도 앱으로 현재 위치를 보내 주시는 방법도 있습니다. / 위치를 받으면 예상 도착 시간을 먼저 말씀드립니다.

# 도어락 상태를 표현하는 말
도어락 상태는 아래 말 가운데 가까운 것을 골라 주시면 됩니다. / 어려운 용어를 쓰실 필요는 없습니다.
"불이 아예 안 들어와요"는 전원 쪽, "번호가 틀렸다고 해요"는 비밀번호 쪽입니다. / "열리는 소리는 나는데 안 열려요"는 걸쇠나 모터, "조금 열리다 걸려요"는 안쪽 걸쇠 쪽으로 짐작합니다.
"삐삐 소리가 계속 나요", "위잉 소리만 나요"처럼 소리를 흉내 내 주셔도 충분히 알아듣습니다. / 소리가 이상하다면 짧은 영상을 문자로 보내 주시면 더 정확합니다.
@ 범박동 도어락 번호판 상태 확인

# 도어락 모양은 세 가지 중 하나로
현관 도어락 모양도 알려 주시면 맞는 장비를 고르기 쉽습니다. / 대부분 아래 셋 가운데 하나입니다.
- 손잡이를 밀거나 당겨서 여는 형
- 레버 손잡이와 번호판이 한 몸인 형
- 번호판만 따로 있고 손잡이는 별도인 형
새 단지는 밀고 당기는 형이 많고, 오래된 빌라는 번호판과 손잡이가 따로인 경우가 흔합니다. / 모르시면 사진 한 장으로 충분합니다.
도어락 위나 아래에 열쇠 구멍이 있는 보조키가 따로 달려 있는지도 한 번 봐 주세요. / 보조키까지 잠겨 있다면 챙길 장비가 하나 더 늘어납니다.

# 갖고 있는 것과 없는 것
통화하실 때 지금 손에 있는 것과 없는 것을 함께 말씀해 주세요. / 열쇠, 카드, 휴대폰, 신분증 네 가지만 생각하시면 됩니다.
카드나 비상 열쇠가 있다면 전화를 끊기 전에 한 번 써 보시라고 말씀드리기도 합니다. / 그것만으로 해결되면 출장이 필요 없으니까요.
신분증이 없다면 확인 방법을 통화 중에 같이 정합니다. / 아파트라면 관리사무소, 빌라라면 집주인이나 이 주소로 온 우편물이 대신할 수 있습니다.

# 전화를 끊기 전에 해 둘 것
전화를 끊기 전에 다시 연락받을 번호를 한 번 확인해 주세요. / 이웃 휴대폰을 빌려 거셨다면 그 번호로 다시 연락해도 되는지 여쭤보는 게 좋습니다.
도착 예정 시간을 들으셨다면 그 시간을 휴대폰 메모나 머릿속에 정확히 기억해 두세요. / 기다리는 동안 다른 곳에 가 계셔도 그 시간에 맞춰 돌아오시면 됩니다.

# 가족이 대신 전화해 주는 경우
문 앞에 계신 분이 휴대폰이 없거나 연세가 있으셔서 자녀분이 대신 연락 주시는 일도 있습니다. / 이럴 때는 문 앞에 계신 분의 연락처나 함께 있는 이웃의 번호를 꼭 알려 주세요.
대신 거시는 분이 현장 상태를 정확히 모르셔도 괜찮습니다. / 위치와 계신 분 연락처만 주시면 현장과 직접 통화해 상태를 여쭤봅니다.
사시는 분 확인은 문 앞에 계신 분 기준으로 하니, 신분증이나 우편물이 그분께 있는지 미리 여쭤봐 주시면 도착 뒤가 빨라집니다.

# 기다리는 동안 하지 않을 것
도착을 기다리는 동안 비밀번호를 계속 눌러 보거나 손잡이를 흔드는 분이 많습니다. / 입력 잠금이 길어지거나 걸쇠가 더 꽉 물려 작업 시간이 늘어날 수 있습니다.
드라이버나 카드로 문틈을 벌리는 것도 피해 주세요. / 문 테두리와 고무 패킹이 상하면 나중에 바람이 새는 문이 됩니다.
9V 비상 전원 단자가 있다면 건전지를 대 보는 정도까지만 하시면 됩니다. / 그 이상은 도착해서 함께 보는 편이 낫습니다.

# 기다리는 동안 해 두면 좋은 것
- 공동현관 비밀번호나 출입 방법 확인
- 아파트라면 경비실이나 관리사무소에 상황 알리기
- 아이가 있다면 따뜻한 곳으로 옮기기
- 신분증이 있다면 꺼내 두기
경비실에 미리 말해 두시면 공동현관 통과와 세대 확인이 함께 수월해집니다. / 늦은 밤에는 특히 도움이 됩니다.

# 도착하면 이렇게 이어집니다
도착하면 먼저 사시는 분인지 확인합니다. / 그다음 문과 도어락 상태를 보고 어떻게 열지, 비용이 어떻게 되는지 손대기 전에 말씀드립니다.
괜찮다고 하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 정리돼 있습니다.

# 열린 뒤 통화 때 말한 원인 확인
문이 열리면 통화 때 짐작한 원인이 맞았는지 함께 확인합니다. / 건전지였다면 모두 바꾸고, 번호였다면 새 번호를 등록하고, 걸쇠나 모터라면 상태를 보여 드립니다.
부품만 손보면 되는 경우는 [도어락 수리](doorlock-repair.html), 바꾸는 게 나은 경우는 [도어락 교체](doorlock-replace.html)로 나눠 말씀드립니다.
@ 부천 범박동 출장열쇠 현관 개문

# 범박동 근처와 부천 전역
범박동과 가까운 역곡동은 물론 옥길동, 송내동, 소사동, 심곡동, 중동, 상동, 원종동, 고강동까지 부천 어디든 다닙니다. / 서울, 경기 전 지역 24시간 출동합니다.
부천에서 다니는 동네는 [부천 출장열쇠](bucheon.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
