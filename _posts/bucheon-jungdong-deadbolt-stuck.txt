# 중동 아파트 현관, 잠금 소리가 끝까지 안 날 때
중동은 신중동역과 부천시청역 주변으로 신도시 아파트가 모인 동네입니다. / 현관은 대부분 무거운 철제 방화문이라 도어클로저가 문을 세게 당기고, 그만큼 잠금쇠가 문틀과 맞물리는 힘도 큽니다.
문을 닫으면 드르륵 하고 잠금쇠가 나오다 중간에 멈추거나, 번호를 눌렀는데 잠금쇠가 안 들어가 문이 그대로인 경우가 있습니다. / 이 잠금쇠를 데드볼트라고 부르는데, 아파트 현관은 단독주택과는 조금 다른 이유로 걸리곤 합니다.
이 글은 중동 아파트에서 데드볼트가 걸릴 때 따져 볼 원인과 확인 순서, [부천 출장열쇠](bucheon.html)를 부를 때를 정리했습니다.
@ 중동 아파트 현관 데드볼트 걸림

# 아파트 현관이 유독 잘 걸리는 이유
방화문은 무겁고 두꺼워서 경첩에 걸리는 무게가 큽니다. / 오래 쓰면 경첩 쪽이 조금씩 내려앉아 데드볼트 높이와 문틀 구멍이 어긋나기 쉽습니다.
도어클로저도 영향을 줍니다. / 닫히는 힘이 너무 세면 문이 문틀에 꽉 눌린 채로 잠기고, 너무 약하면 끝까지 닫히지 않아 데드볼트가 문틀 모서리에 부딪힙니다.
여기에 복도와 집 안 사이 바람이 더해지기도 합니다. / 창문을 열어 둔 날 현관문이 안쪽이나 바깥쪽으로 빨려 들듯 눌리면 데드볼트가 구멍 벽에 끼어 잘 움직이지 않습니다.

# 덜 나와서 안 잠길 때 확인할 것
문을 닫았는데 잠금 소리가 짧게 끊기고 경고음이 난다면 데드볼트가 끝까지 못 나온 경우입니다. / 아래 순서로 원인을 좁혀 보세요.
- 문을 연 채로 잠금 버튼을 눌러 데드볼트가 허공에서 끝까지 나오는지 보기
- 허공에서는 잘 나오면 문틀 구멍과 높이가 어긋난 것
- 허공에서도 덜 나오면 배터리나 도어락 안쪽 문제
- 문이 끝까지 닫혔는지, 손으로 살짝 밀면 잠기는지 보기
손으로 문을 살짝 밀었을 때 잠금이 제대로 된다면 도어클로저가 문을 덜 당기는 경우가 많습니다. / 클로저 조정만으로 해결되기도 합니다.
@ 부천 중동 방화문 도어클로저 닫힘 점검

# 안 들어가서 안 열릴 때 문 앞에서
밖에서 번호를 눌렀는데 모터 소리만 나고 문이 그대로라면 데드볼트가 문틀에 눌려 있을 가능성이 큽니다. / 문을 몸 쪽으로 살짝 당기거나 안쪽으로 밀면서 다시 번호를 눌러 보세요.
집 안 창문이 열려 있어 바람이 문을 누르고 있다면 그것도 원인이 됩니다. / 가족이 안에 있다면 창문을 잠시 닫아 달라고 해 보세요.
두세 번 해도 안 되면 멈추는 게 좋습니다. / 계속 누르면 모터와 기어가 상하고, 배터리도 빨리 닳아 문 열기가 더 어려워집니다.

# 배터리가 약해도 비슷해 보입니다
데드볼트를 밀고 당기는 건 도어락 모터의 힘입니다. / 배터리가 약해지면 평소에는 괜찮다가 문틀에 조금만 눌려도 끝까지 움직이지 못합니다.
잠금 소리가 예전보다 느리고 힘없게 들린다면 배터리부터 바꿔 보세요. / 같은 날 산 새 배터리로 한 번에 다 바꾸는 게 좋습니다.
바꿨는데도 그대로라면 배터리 문제는 아닌 것으로 보고 다음 확인으로 넘어가면 됩니다.

# 문틀 구멍 안을 들여다보기
문이 열린 상태라면 문틀 쪽 데드볼트가 들어가는 구멍을 손전등으로 비춰 보세요. / 먼지 덩어리, 떨어진 나사, 페인트 덩어리가 구멍을 막고 있는 경우가 있습니다.
이사하거나 인테리어를 하면서 문틀을 다시 칠했다면 구멍 안쪽이 좁아졌을 수 있습니다. / 이런 경우 구멍을 다듬는 작업으로 바로 좋아집니다.
@ 중동 현관 문틀 데드볼트 구멍 확인

# 잠긴 줄 알았는데 덜 잠긴 상태라면
데드볼트가 반쯤만 나온 채 멈추면 문은 닫혀 보여도 실제로는 제대로 잠기지 않은 상태입니다. / 바깥에서 손잡이를 당겼을 때 문이 덜컥 움직인다면 이 경우일 수 있습니다.
외출할 때 잠금 소리가 끝까지 났는지 한 번 귀 기울여 들어 보세요. / 경고음이 짧게 울렸다면 다시 열고 닫아 확인하는 습관이 좋습니다.
이런 일이 며칠 이어진다면 방범을 위해서라도 미루지 말고 점검받으시길 권합니다. / 처음 증상이 보일 때 손보면 작업도 간단합니다.

# 드라이버와 클로저 나사는 조심
문틈에 일자 드라이버를 넣어 데드볼트를 밀어 보려는 건 소용이 없고 문틀만 상합니다. / 방화문 문틀은 한 번 휘면 바로잡기 어렵습니다.
도어클로저 조절 나사를 이리저리 돌려 보는 것도 조심해 주세요. / 너무 돌리면 문이 쾅 닫히거나 반대로 닫히지 않게 되고, 안에 든 기름이 새기도 합니다.
데드볼트에 일반 기름을 뿌리는 것도 권하지 않습니다. / 먼지가 엉겨 붙어 나중에 더 뻑뻑해집니다.

# 중동에서 연락 주실 때
아파트 단지가 많은 동네라 동, 호수, 공동현관 출입 방법을 정확히 알려주세요. / 신중동역이나 부천시청역 기준으로 어느 쪽인지 말씀해 주셔도 좋습니다.
- 데드볼트가 안 나오는지, 안 들어가는지
- 문이 지금 열려 있는지, 잠겨 있는지
- 창문을 열어 두었는지, 바람 부는 날인지
- 배터리를 언제 갈았는지
- 도어락 옆면과 문틀 구멍 사진 (문이 열려 있다면)

# 현장에서는 이 순서로 봅니다
문이 잠긴 상태라면 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 세대 확인 중 하나면 됩니다.
비용은 문과 도어락을 보고 작업 전에 말씀드립니다. / 동의하실 때 [현관문 개문](door-open.html)으로 열고, 못 열면 비용은 받지 않습니다.
문이 열리면 경첩, 도어클로저, 문틀 구멍, 도어락을 차례로 보면서 어디가 원인인지 찾습니다. / 원인이 문 쪽이면 도어락은 그대로 두고 문만 손봅니다.

# 수리는 대개 이 세 가지
- 경첩 높이와 나사 조정으로 문 처짐 바로잡기
- 도어클로저 속도와 힘 조정
- 문틀 쇠판 위치 옮기기, 구멍 다듬기
대부분 이 정도로 끝나고 도어락을 바꿀 일은 많지 않습니다. / 도어락 안쪽 기어가 닳았다면 [도어락 수리](doorlock-repair.html)로 부품을 보고, 부품이 없으면 [도어락 교체](doorlock-replace.html)를 함께 상의합니다.
@ 부천 중동 현관문 경첩 문틀 조정 수리

# 계절 따라 다시 걸린다면
여름에는 문이 조금 늘고 겨울에는 줄어들어 같은 문이라도 계절마다 맞물림이 달라집니다. / 한 계절에만 걸린다면 문틀 구멍에 여유를 조금 더 두는 식으로 손봅니다.
환기할 때 현관 쪽으로 바람이 세게 부는 집은 잠그기 전에 창문을 조금 닫는 습관도 도움이 됩니다. / 작은 습관이지만 데드볼트 걸림을 꽤 줄여 줍니다.

# 중동 말고 부천 어디든
중동과 가까운 상동, 심곡동, 송내동은 물론 소사동, 역곡동, 원종동, 오정동, 고강동, 옥길동, 범박동까지 다닙니다. / 진행 방식은 [이용안내](guide.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 창문을 열면 현관이 잘 안 잠겨요. | 바람이 문을 눌러 데드볼트가 구멍에 끼는 경우라 잠글 때 창문을 조금 닫아 보시고, 계속되면 문틀 쪽을 손봅니다.
? 손으로 밀어야만 잠겨요. | 도어클로저가 문을 끝까지 당기지 못하는 경우가 많아 클로저 조정을 권합니다.
? 방화문은 문틀 조정이 어렵나요? | 무거워서 경첩 처짐이 잦지만 높이와 나사 조정으로 대부분 바로잡힙니다.
? 데드볼트가 허공에서도 덜 나와요. | 배터리를 먼저 바꿔 보시고, 그래도 같으면 도어락 안쪽 점검이 필요합니다.
? 도어클로저 나사를 직접 돌려도 되나요? | 조금씩은 괜찮지만 많이 돌리면 문이 세게 닫히거나 기름이 샐 수 있어 조심해 주세요.
