# 중동 아파트, 아무도 안 눌렀는데 삑삑
밤에 거실에 앉아 있는데 현관 쪽에서 짧은 신호음이 들립니다. / 나가 보면 아무도 없고, 번호판에 불만 잠깐 들어왔다 꺼져 있습니다.
중동은 신중동역과 부천시청역 사이로 신도시 아파트 단지가 길게 이어진 동네입니다. / 현관은 대부분 무거운 철제 방화문이고, 이 철문이 바깥 복도와 집 안의 온도와 습도를 한 몸으로 받아 냅니다.
철문은 온도 변화에 민감해서 장마철에는 눅눅해지고 겨울에는 안쪽에 물방울이 맺히기 쉽습니다. / 이 글은 중동 아파트 현관에서 습기 때문에 생기는 오작동을 복도 구조와 계절로 나눠 살펴보고, 계절별로 할 일을 메모처럼 정리했습니다.
@ 중동 아파트 철제 현관문 습기 도어락

# 우리 동 복도는 어떤 구조인가요
같은 중동 아파트라도 복도 구조에 따라 습기가 들어오는 길이 다릅니다. / 먼저 우리 동이 어느 쪽인지 떠올려 보세요.
복도식은 현관 앞이 바깥 공기와 바로 닿아 있습니다. / 비가 들이치거나 찬바람이 그대로 번호판에 닿아 바깥쪽 영향이 큽니다.
계단식은 현관 앞이 실내에 가깝지만 계단실과 엘리베이터 홀의 공기가 잘 안 바뀝니다. / 장마철에는 홀 전체가 눅눅해지고, 겨울에는 집 안 따뜻한 공기가 문 안쪽에 결로를 만듭니다.
저층과 고층도 조금 다릅니다. / 저층은 1층 출입문으로 들어오는 바깥 습기를 자주 받고, 고층 복도식은 바람이 세서 빗물이 옆으로 들이치기 쉽습니다.
이 차이를 알면 어디를 먼저 닦고 말릴지 정하기 쉽습니다.

# 혼자 울리는 소리는 이렇게 생깁니다
번호판 안쪽에는 손을 감지하는 부분과 버튼 접점이 있습니다. / 표면에 물기가 얇게 덮이거나 틈으로 습기가 들어가면 손이 닿은 것처럼 잘못 알아차리는 일이 생깁니다.
그래서 아무도 없는데 불이 켜지거나, 짧은 신호음이 나거나, 누르지 않은 숫자가 입력되는 모습이 보입니다. / 손으로 누를 때 다른 숫자가 함께 눌리는 것처럼 느껴지기도 합니다.
이런 증상이 습한 날에만 나타나고 맑은 날에는 사라진다면 습기 쪽 가능성이 큽니다. / 반대로 날씨와 상관없이 계속된다면 회로나 배터리 쪽을 봐야 합니다.

# 장마철 메모, 현관 앞을 마르게
장마철 아파트 현관 앞은 젖은 우산, 비 맞은 신발, 택배 상자로 금세 눅눅해집니다. / 우산은 현관 밖 복도가 아니라 집 안 욕실이나 베란다에서 말려 주세요.
현관 신발장 안에 습기 제거제를 두는 것도 도움이 됩니다. / 신발장과 현관문이 붙어 있는 구조라면 문 안쪽 습도도 함께 낮아집니다.
복도식이라면 비가 그친 뒤 번호판 위아래를 마른 천으로 눌러 닦아 주세요. / 번호판 아래쪽 이음새에 물이 남아 있기 쉽습니다.
@ 중동 아파트 장마철 현관 우산 습기 관리

# 겨울 메모, 문 안쪽 물방울 닦기
겨울 아침 현관 철문 안쪽을 만져 보세요. / 축축하거나 물방울이 흘러내린 자국이 있다면 결로가 생기고 있는 것입니다.
결로는 도어락 안쪽 몸체 아래나 배터리 칸 주변으로 모입니다. / 아침마다 마른 수건으로 문 안쪽을 한 번 훑어 주고, 배터리 칸은 가끔 열어 습기가 차 있지 않은지 확인하세요.
현관 중문이 있다면 겨울에는 닫아 두는 것이 좋습니다. / 욕실 문을 열고 샤워한 뒤 김이 현관까지 퍼지는 집은 환풍기를 충분히 돌려 주세요.

# 환절기 메모, 건전지와 접점 보기
봄과 가을처럼 낮과 밤 온도 차가 큰 계절에도 문 안쪽에 물기가 생깁니다. / 이때 배터리 칸 접점이 조금씩 녹슬면 습기와 상관없는 날에도 반응이 나빠집니다.
계절이 바뀔 때 건전지를 꺼내 접점을 살펴보세요. / 하얀 가루나 초록빛 녹이 보이면 마른 천으로 닦고, 건전지는 같은 날 산 새것으로 한꺼번에 바꿉니다.
@ 중동 도어락 배터리 칸 접점 녹 확인

# 밤에 울리는 소리, 이웃과 나에게 모두 신경 쓰입니다
습기 때문에 번호판이 밤마다 깨어나면 짧은 소리라도 잠을 설치게 됩니다. / 옆집에서 무슨 소리냐고 물어보는 일도 생깁니다.
그날 밤은 배터리를 잠시 빼 두는 분도 있지만, 그러면 바깥에서 들어올 방법이 없어집니다. / 집에 사람이 있을 때만, 그리고 다음 날 다시 넣는다는 전제로만 하세요.
울린 시각과 날씨를 며칠 적어 두면 점검할 때 큰 도움이 됩니다. / 습한 날에만 울리는지, 매일 같은 시간에 울리는지에 따라 손볼 곳이 달라집니다.
@ 중동 아파트 밤마다 도어락 신호음 기록

# 번호판이 엇나갈 때 문 앞에서
번호를 눌렀는데 다른 숫자가 들어가는 것 같다면 계속 누르지 말고 멈추세요. / 틀린 입력이 몇 번 쌓이면 도어락이 한동안 입력을 막습니다.
마른 수건으로 번호판을 눌러 닦고 몇 분 기다린 뒤, 한 자리씩 천천히 다시 누릅니다. / 번호판이 꺼졌다면 9V 건전지를 바깥 비상 단자에 대 볼 수 있는데, 이때 단자에 물기가 없는지 꼭 보세요.
드라이기는 약한 바람으로 멀리서 잠깐만 쓰고, 뜨거운 바람을 오래 대지는 마세요. / 철문이 갑자기 데워지면 안쪽에 오히려 물방울이 더 맺힐 수 있습니다.

# 이럴 땐 말리지 말고 연락을
- 한나절이 지나도 혼자 울리는 소리가 계속될 때
- 번호판 안쪽에 김이 서린 것처럼 뿌옇게 보일 때
- 배터리를 새로 넣어도 불이 켜졌다 꺼지기를 반복할 때
- 밤마다 경고음이 울려 잠을 설칠 때
중동에서 연락 주실 때는 단지 이름과 동, 호수, 복도식인지 계단식인지 알려 주세요. / 증상이 나는 순간을 짧게 영상으로 찍어 보내 주시면 원인을 짐작하기 훨씬 쉽습니다.

# 도착하면 확인과 금액 안내부터
문을 열어야 하는 상황이면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 세대 확인 중 하나면 됩니다.
도어락 상태를 본 뒤 손대기 전에 금액을 말씀드리고, 동의하실 때만 진행합니다. / 끝내 못 열면 비용은 받지 않으며, 진행 순서는 [이용안내](guide.html)에, 문 여는 과정은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 닦아도 안 되면 수리부터
물기가 회로까지 들어가 접점이 상했다면 말려도 증상이 남습니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)로 번호판이나 기판을 먼저 손봅니다.
몇 해째 장마와 겨울마다 같은 증상이 반복되고 제품도 많이 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 함께 상의해도 늦지 않습니다. / 교체를 서둘러 권하지는 않습니다.

# 중동에서 부천 다른 동네까지
중동과 맞닿은 상동, 심곡동, 송내동은 물론 소사동, 역곡동, 원종동, 오정동, 고강동, 옥길동, 범박동까지 다닙니다. / 부천 안내는 [부천 출장열쇠](bucheon.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 계단식 아파트도 습기 영향을 받나요? | 받습니다. 바깥보다 문 안쪽 결로와 홀 습기 영향이 더 큽니다.

? 번호판을 물티슈로 닦아도 되나요? | 물기가 남을 수 있어 마른 천으로 닦는 편이 낫습니다.

# 마무리
중동 아파트 현관 도어락이 습한 날마다 제멋대로 울린다면 복도식은 바깥 번호판을, 계단식은 문 안쪽 결로를 먼저 살펴 주세요. / 장마철에는 현관 앞을 마르게, 겨울에는 문 안쪽 물방울을, 환절기에는 접점을 챙기면 됩니다.
