# 오정동, 손잡이가 손 안에서 따로 논다
오정동은 부천 북쪽에 주택과 빌라, 다세대가 모여 있고 작은 공장과 창고도 가까운 동네입니다. / 집 현관뿐 아니라 작업장 출입문, 창고 문처럼 하루에도 여러 번 거칠게 여닫는 문이 많습니다.
손잡이를 잡았는데 덜렁 흔들리거나, 돌렸는데 안쪽에서 아무것도 걸리지 않고 빙글 도는 느낌이 들 때가 있습니다. / 처음에는 조금 불편한 정도지만 그대로 두면 어느 날 문이 안 열리는 일로 이어집니다.
이 글은 오정동에서 손잡이가 헐겁거나 헛돌 때 손잡이 종류에 따라 무엇을 보면 되는지 정리했습니다. / 이미 문이 안 열린다면 [부천 출장열쇠](bucheon.html)로 바로 연락 주세요.
@ 오정동 현관 손잡이 헐거움 점검

# 우리 집 손잡이는 어떤 모양인가
손잡이 모양에 따라 헐거워지는 곳과 손보는 방법이 다릅니다. / 먼저 아래 중 어디에 가까운지 보세요.
- 둥근 공 모양에 가운데 열쇠 구멍이 있는 원통형 손잡이
- 아래로 눌러 여는 막대 모양 레버 손잡이
- 도어락 몸체와 붙어 있는 밀고 당기는 손잡이
- 작업장 문에 흔한 큰 막대형 손잡이와 따로 붙은 자물쇠
오정동 오래된 주택과 창고 문에는 원통형과 레버형이 많고, 빌라 현관은 도어락 일체형이 많습니다.
모양을 잘 모르겠다면 바깥과 안쪽 손잡이를 한 장씩 찍어 두세요. / 같은 레버형이라도 손잡이 목 둘레에 나사가 보이는 제품과 감춰진 제품이 있어 사진이 있으면 설명이 쉬워집니다.

# 흔들림과 헛돎은 다른 문제입니다
손잡이가 흔들리기만 하고 돌리면 문이 열린다면 고정 나사가 풀린 경우가 많습니다. / 비교적 간단하게 손볼 수 있습니다.
돌려도 걸쇠가 움직이지 않고 빙글 돈다면 손잡이와 걸쇠를 잇는 안쪽 축이 닳았거나 빠진 것입니다. / 이 경우는 문을 열기 어려워질 수 있어 더 서둘러야 합니다.
- 흔들리지만 열린다 → 고정 나사 풀림
- 돌리면 뻑뻑하다가 갑자기 헐렁해졌다 → 축 마모 시작
- 돌려도 걸쇠가 꼼짝 않는다 → 축 빠짐이나 부러짐

# 문이 열려 있을 때 해 둘 일
손잡이가 헛도는데 지금 문이 열려 있다면 당분간 문을 완전히 닫지 마세요. / 닫는 순간 걸쇠가 걸린 채 다시 열 수 없게 될 수 있습니다.
문이 바람에 닫히지 않게 고임목을 받쳐 두거나, 걸쇠가 튀어나오지 않게 테이프로 눌러 두는 방법도 있습니다. / 작업장이라면 퇴근할 때 어떻게 잠글지 미리 생각해 두셔야 합니다.

# 원통형, 레버형 손잡이 조이는 요령
원통형과 레버형은 대개 안쪽 손잡이 목 부분에 작은 나사나 누름 핀이 있습니다. / 이 나사가 풀리면 손잡이가 덜렁거립니다.
나사가 보이면 맞는 드라이버로 천천히 조여 보세요. / 나사가 보이지 않으면 손잡이 목 둘레의 작은 구멍을 찾아보세요. 핀을 누르며 손잡이를 빼는 구조일 수 있습니다.
조일 때는 안팎 손잡이를 같이 잡고 수평이 맞는지 보면서 조금씩 조여야 합니다. / 한쪽만 세게 조이면 걸쇠가 비뚤어져 뻑뻑해집니다.
조인 뒤에는 문을 열어 둔 채 손잡이를 여러 번 돌려 걸쇠가 끝까지 들어갔다 나오는지 확인하세요. / 걸쇠가 반쯤만 움직인다면 너무 세게 조인 것이니 조금 풀어 맞춥니다.
@ 부천 오정동 레버 손잡이 고정 나사

# 도어락 일체형 손잡이라면
빌라 현관의 도어락 일체형 손잡이는 안쪽 몸체를 고정한 볼트가 풀려 흔들리는 경우가 많습니다. / 안쪽 몸체 덮개를 열면 고정 볼트가 보이는 제품이 많습니다.
덮개를 열기 전에 건전지를 빼야 하는 제품도 있으니 설명서를 먼저 확인해 주세요. / 볼트를 조여도 손잡이가 헛돈다면 안쪽 부품 문제라 점검이 필요합니다.
밀고 당기는 손잡이는 구조가 복잡해 몸체를 분해하지 않는 편이 좋습니다. / 덜렁거림이 심하다면 [도어락 수리](doorlock-repair.html)로 봐 드립니다.

# 작업장 문은 왜 빨리 헐거워질까
작업장과 창고 문은 짐을 들고 몸으로 밀어 여는 일이 많습니다. / 손잡이에 무게가 실리고, 장갑 낀 손으로 세게 돌리다 보니 나사가 빨리 풀립니다.
손잡이에 작업복이나 공구 가방을 걸어 두는 습관도 축을 휘게 합니다. / 걸어 둘 곳은 따로 마련해 두시길 권합니다.
작업장 문은 퇴근 뒤 잠그는 일이 중요해서 손잡이가 헐거워지면 곧바로 손보는 게 좋습니다. / 다음 날 아침 문이 안 열려 일을 시작하지 못하는 경우도 있습니다.

# 해서는 안 되는 임시방편
헛도는 손잡이를 펜치로 잡아 억지로 돌리는 분이 있습니다. / 남은 축까지 부러뜨려 문을 열기 더 어려워질 수 있습니다.
순간접착제로 손잡이를 붙이거나 철사로 묶어 두는 것도 권하지 않습니다. / 잠깐은 버티지만 나중에 부품을 빼낼 때 시간이 더 걸립니다.

# 이미 문이 안 열린다면
손잡이가 헛돌아 문이 안 열린다면 무리하게 돌리지 말고 연락 주세요. / 문 안쪽에 사람이 있다면 안쪽 손잡이로 열 수 있는지 먼저 확인해 보세요.
집이라면 사시는 분인지 신분증이나 우편물로, 작업장이라면 사업자등록증이나 임대계약서로 확인합니다. / 확인이 되지 않으면 작업하지 않습니다.
@ 오정동 작업장 출입문 손잡이 헛돎

# 사진 한 장과 함께 알려 주실 것
아래를 말씀해 주시면 맞는 부품을 챙겨 갈 수 있습니다. / 사진 한 장이면 손잡이 종류를 바로 알 수 있습니다.
- 집 현관인지, 작업장이나 창고 문인지
- 손잡이 모양
- 흔들리기만 하는지, 헛도는지
- 지금 문이 열린 상태인지 닫힌 상태인지
오정동은 주택과 작업장이 섞인 골목이 많아 가까운 큰길이나 건물 특징을 알려 주시면 찾기 쉽습니다.

# 비용과 작업 순서
도착해서 손잡이와 문 상태를 본 뒤 비용을 먼저 말씀드립니다. / 동의하실 때만 시작하고, 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
문이 닫힌 상태라면 먼저 문을 열고 손잡이를 손봅니다. / 끝내 열지 못하면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 있습니다.

# 고칠까, 바꿀까
나사가 풀린 정도라면 조이는 것으로 끝납니다. / 축이 닳았거나 손잡이 안쪽이 부러졌다면 손잡이 세트를 바꾸는 편이 낫습니다.
손잡이를 바꾸는 김에 열쇠 대신 번호식으로 바꾸고 싶다면 [도어락 교체](doorlock-replace.html)를 함께 보시면 됩니다. / 작업장 문처럼 여럿이 쓰는 문은 번호나 카드 방식이 관리하기 편할 수 있습니다.

# 오정동 말고 부천 어디든
오정동과 가까운 원종동, 고강동은 물론 중동, 상동, 심곡동, 소사동, 역곡동, 송내동, 옥길동, 범박동까지 부천 어디든 갑니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 도어락 일체형 손잡이를 직접 분해해도 되나요? | 구조가 복잡해 권하지 않습니다. 안쪽 고정 볼트 조이기 정도만 해 보세요.
