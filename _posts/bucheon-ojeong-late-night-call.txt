# 오정동 한밤에 문 앞에서 막혔을 때
오정동은 주택과 빌라, 작은 공장과 창고가 가까이 있는 동네입니다. / 야간 근무를 마치고 새벽에 들어오거나 늦은 밤 귀가하다 문이 안 열리는 일이 생기면 주변이 어두워 더 막막합니다.
이런 시간에는 열쇠집이 문을 닫은 곳이 많고, 급한 마음에 아무 곳이나 전화하게 되기 쉽습니다. / 이 글은 [부천 출장열쇠](bucheon.html)로 오정동에서 밤 시간 문의를 받으며 정리한 순서와 요령입니다.
@ 오정동 24시 출장열쇠 한밤 새벽 문 열기 출동

# 먼저 안전한 곳에서 기다리세요
문 앞이 어둡거나 인적이 드문 곳이라면 건물 입구나 밝은 곳으로 자리를 옮기세요. / 늦은 시간에는 문 앞에서 오래 서 있는 것 자체가 위험할 수 있습니다.
혼자 계신 경우에는 가까운 가족이나 지인에게 위치를 알려 두는 것이 좋습니다. / 출장 기사가 도착하는 동안 안전하게 기다릴 수 있도록 통화 상태를 유지하세요.
추위나 비가 심한 날은 건물 현관 안쪽에서 기다리시고, 필요하면 이웃이나 경비실 도움을 받으세요.

# 전화할 때 알려 주실 것
밤 시간에는 길을 찾는 시간이 늘어나서 위치를 정확히 알려 주시는 것이 가장 중요합니다. / 아래 네 가지만 알려 주셔도 출발이 빨라집니다.
- 건물 이름이나 큰 가게 이름, 가까운 길 이름
- 몇 층 몇 호인지, 건물 입구 번호가 있는지
- 지금 증상(번호판이 꺼짐, 번호가 안 맞음, 열쇠가 안 돌아감)
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 챙겨 갈 장비를 정하기 쉽습니다.

# 밤에 많은 상황은 이렇습니다
퇴근하고 돌아왔는데 번호판이 꺼져 있는 경우, 술이나 피곤 때문에 번호를 틀리게 눌러 도어락이 막힌 경우, 열쇠를 집 안에 두고 나온 경우가 많습니다. / 새벽에 응급 상황으로 나갔다가 열쇠를 잃어버리는 일도 있습니다.
- 번호판이 아예 꺼진 경우: 배터리 방전 가능성
- 번호를 여러 번 틀려 막힌 경우: 잠시 기다려야 풀림
- 열쇠를 두고 나온 경우: 사시는 분 확인 후 개문
번호를 여러 번 틀려 도어락이 막혔다면 몇 분 기다린 뒤 다시 시도하는 것이 좋습니다.
@ 오정동 한밤 현관문 도어락 번호판 꺼짐

# 9V 건전지가 있다면 먼저 시도해 보세요
많은 도어락은 바깥쪽 아래에 9V 건전지를 대는 비상 단자가 있습니다. / 건전지를 대고 있는 동안 번호를 눌러 문을 열 수 있습니다.
가까운 편의점이 열려 있다면 9V 건전지를 구할 수 있지만 모든 제품에 있는 것은 아닙니다. / 단자가 없거나 건전지를 대도 반응이 없으면 그때 전화 주세요.
문이 열리면 안쪽 배터리를 전부 새것으로 바꿔 주세요. / 일부만 바꾸면 며칠 안에 같은 일이 다시 생깁니다.

# 늦은 밤에는 이웃 배려가 필요합니다
밤에는 문을 두드리거나 소리를 내는 것이 이웃에게 큰 소음이 됩니다. / 문을 억지로 흔들거나 발로 차는 행동은 소음뿐 아니라 문을 상하게 합니다.
출장열쇠 기사도 밤 시간에는 최대한 조용히 작업합니다. / 작업 소리가 걱정되신다면 미리 말씀해 주시면 조용한 방법부터 시도합니다.
공동 현관 비밀번호를 모를 때는 늦은 시간이라도 이웃이나 경비실에 도움을 청하는 것이 좋습니다.

# 도착하면 사시는 분 확인을 합니다
문을 여는 일이라 새벽이라도 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리인 확인 중 하나면 됩니다.
번거로운 시간이지만 이웃과 집 주인 모두를 위한 절차입니다. / 신분증이 집 안에 있다면 관리인이나 집주인 확인으로 대신할 수 있는지 말씀해 주세요.

# 비용은 문 열기 전에 말씀드립니다
밤 시간이라고 해서 말없이 비용이 늘어나지 않습니다. / 문 상태와 도어락 종류를 보고 먼저 말씀드리고, 괜찮다고 하시면 시작합니다.
마음에 안 드시면 그냥 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문은 최대한 안 상하게 엽니다
문 여는 방법은 여러 가지가 있고 덜 상하는 방법부터 차례로 해봅니다. / 밤에는 확인할 시간이 부족해 서두르기 쉬운데 서두르지 않고 순서대로 진행합니다.
도어락 종류와 문 상태에 따라 걸리는 시간이 다릅니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.
방법은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.

# 열고 난 뒤에는 이것만 확인하세요
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 늦은 밤이라면 문을 잠그고 다시 열어 보는 것까지 하고 자세한 점검은 다음 날로 미루셔도 됩니다.
배터리가 원인이면 새 배터리로 바꾸고, 번호를 잊었다면 안쪽에서 새 번호를 등록해 드립니다. / 도어락이 고장이라면 [도어락 수리](doorlock-repair.html) 순서로 점검합니다.

# 야간 근무하는 분께 미리 권하는 준비
야간 근무가 잦은 분들은 문 앞에서 막히는 일이 일반 가정보다 훨씬 위험하고 피곤합니다. / 작은 준비를 해 두면 늦은 밤 문제가 크게 줄어듭니다.
- 도어락 배터리 교체일을 달력에 적어 두기
- 가방에 9V 건전지 하나 넣어 두기
- 여벌 열쇠를 믿을 수 있는 곳에 맡기기
- 출장열쇠 전화번호를 휴대폰에 저장해 두기

# 안에 사람이나 동물이 있을 때는 먼저 말씀해 주세요
집 안에 어린 아이나 반려동물이 있는데 문이 안 열리는 상황이라면 가장 먼저 알려 주세요. / 순서를 바꿔 가장 빠른 방법으로 진행합니다.
아이가 놀라지 않게 문 너머로 계속 말을 걸어 주세요. / 안에서 열 수 있는 방법이 있다면 전화로 같이 알려 드립니다.

# 전화를 끊은 뒤 기다리는 동안
전화를 끊고 나면 도착 예정 시간을 들으셨을 테니 그 시간 동안 할 일을 정해 두세요. / 휴대폰 배터리가 부족하면 연락이 끊길 수 있으니 절전 모드로 바꿔 두는 것이 좋습니다.
사시는 분 확인에 쓸 신분증이나 우편물이 가방에 있는지 미리 찾아 두세요. / 공동 현관이 잠겨 있다면 기사가 들어올 수 있게 이웃이나 경비실에 미리 부탁해 두면 빠릅니다.
도착 전에 문을 계속 만지거나 열쇠를 여러 번 돌려 보는 일은 하지 마세요. / 상태가 더 나빠지면 열 수 있는 방법이 줄어듭니다.
기사가 가까이 오면 전화로 위치를 다시 한번 확인합니다. / 어두운 골목에서는 휴대폰 불빛을 켜고 손을 흔들어 알려 주시면 찾기 쉽습니다. / 주변에 눈에 띄는 간판이나 가로등 번호가 있으면 함께 알려 주세요. 길을 헤매는 시간이 줄어듭니다.

# 오정동 말고 부천 어디든 갑니다
원종동, 고강동, 심곡동, 소사동 등 부천 전역을 24시간 다닙니다. / 늦은 시간에도 같은 방식으로 받습니다.
다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.

# 마무리

24시출장열쇠는 부천 전역에서 밤낮 구분 없이 현관문 개문과 도어락 점검을 받습니다. / 전화 010-3664-5455로 연락 주세요.
