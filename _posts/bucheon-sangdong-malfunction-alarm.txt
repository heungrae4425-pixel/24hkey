# 상동 아파트, 도어락이 평소와 다른 소리를 낼 때
상동은 신도시 아파트가 넓게 자리한 동네라 밀고 당기는 형이나 레버형 번호키를 쓰는 집이 대부분입니다. / 매일 듣던 짧은 열림 소리 대신 낯선 경고음이 이어지거나, 안에서 모터만 위잉 돌고 문이 꼼짝 안 하면 불안해집니다.
같은 소리라도 언제 나는지에 따라 뜻이 꽤 다릅니다. / 외출하려고 문을 닫을 때인지, 들어오려고 번호를 누를 때인지, 아무도 안 만졌는데 혼자 울리는지부터 나눠 보면 원인이 좁혀집니다.
이 글은 상동에서 도어락 경고음이나 모터 소리가 이상할 때 상황별로 구분하는 법과 [부천 출장열쇠](bucheon.html)에 연락하기 전에 확인할 것을 정리했습니다.
@ 상동 아파트 도어락 경고음 모터 소리

# 소리는 녹음해 두는 게 가장 정확합니다
경고음은 막상 설명하려면 "삐삐요" 말고는 표현이 어렵습니다. / 소리가 날 때 휴대폰으로 십 초 정도 녹음하거나 영상을 찍어 두세요.
짧게 끊어지는지 길게 이어지는지, 몇 번 반복되는지, 모터 소리가 끝까지 가는지 중간에 멈추는지가 모두 단서가 됩니다. / 같은 소리가 반복되면 처음 한 번만 찍으면 충분합니다.

# 나갈 때, 문을 닫았는데 경고음이 난다
외출하려고 문을 닫았더니 잠금 소리 대신 경고음이 나는 경우입니다. / 대부분 걸쇠가 문틀 구멍에 끝까지 들어가지 못해 잠금에 실패했다는 신호입니다.
문을 손으로 한 번 더 꾹 밀어 닫아 보세요. / 그래서 정상으로 잠기면 문이 처졌거나 도어클로저가 마지막에 힘이 약한 상태입니다.
밀어도 계속 울린다면 문틀 받이 구멍에 이물질이 끼었는지 손전등으로 비춰 보세요. / 작은 돌이나 종이 조각 하나로도 걸쇠가 막힙니다.

# 들어올 때, 번호를 눌렀는데 모터만 돈다
번호가 맞아 열림 소리나 모터 소리는 나는데 손잡이를 밀어도 문이 안 열리는 경우입니다. / 모터가 걸쇠를 끝까지 당기지 못하고 헛도는 상황입니다.
건전지가 약하면 모터 힘이 부족해져 이런 일이 먼저 생깁니다. / 번호판 불빛이 평소보다 흐리거나 반응이 느리다면 건전지를 의심하세요.
문을 몸 쪽으로 살짝 당겨 걸쇠에 걸린 힘을 덜어 준 뒤 다시 번호를 눌러 보세요. / 그래도 모터만 돈다면 안쪽 부품 문제라 혼자서는 해결이 어렵습니다.
@ 상동 밀고 당기는 도어락 모터 헛돌 때

# 아무도 안 만졌는데 혼자 울린다
밤중이나 낮에 아무도 안 건드렸는데 도어락이 혼자 울리면 깜짝 놀라게 됩니다. / 원인은 몇 가지로 나뉩니다.
- 건전지가 거의 다 돼 주기적으로 알리는 소리
- 번호판에 물기나 결로가 맺혀 버튼이 눌린 것처럼 인식
- 누군가 바깥에서 번호를 여러 번 틀려 울리는 경보
- 문이 덜 닫힌 채로 시간이 지나 울리는 알림
번호판에 물방울이 맺혀 있다면 마른 천으로 닦고 잠시 기다려 보세요. / 바깥에서 누가 번호를 눌렀던 게 의심된다면 문을 열지 말고 문 너머로 확인하거나 경비실에 먼저 알려 주세요.

# 건전지 경고음인지 먼저 가리기
경고음의 상당수는 건전지가 약하다는 알림입니다. / 번호를 누를 때마다 같은 짧은 경고음이 덧붙어 나고 문은 정상으로 열린다면 거의 이 경우입니다.
이때는 건전지를 모두 새것으로 바꾸면 끝납니다. / 경고음이 난 뒤에도 며칠은 버티는 제품이 많지만, 미루다가 완전히 멈추면 문 밖에서 막히게 되니 그날 바로 바꿔 주세요.
건전지를 바꿨는데도 같은 소리가 난다면 건전지 칸 접점이나 기판 쪽을 의심해야 합니다.

# 안쪽 몸체 표시도 같이 보기
안쪽 몸체에 작은 불빛이나 화면이 있는 제품이라면 소리가 날 때 거기에 어떤 표시가 뜨는지 봐 주세요. / 건전지 모양, 자물쇠 모양, 느낌표처럼 제품마다 다른 표시로 원인을 알려 주기도 합니다.
표시의 뜻은 설명서에 나와 있습니다. / 설명서가 없다면 표시가 뜬 모습을 사진으로 찍어 보내 주세요.

# 비 오는 날이나 추운 아침에만 그렇다면
오작동이 특정 날씨에만 몰려 있다면 습기와 기온을 의심해 볼 만합니다. / 아파트 복도는 바깥보다 덜하지만, 창이 열린 복도나 계단 쪽 세대는 결로가 생기기도 합니다.
비 오는 날 번호판이 혼자 눌리는 듯 울리거나, 한겨울 아침에만 모터 힘이 약해진다면 이쪽입니다. / 번호판을 마른 천으로 닦고, 건전지가 오래됐다면 함께 바꿔 보세요.
날씨가 풀리면 괜찮아졌다가 다시 반복된다면 번호판 틈새 패킹이 낡았을 수 있어 점검을 받아 두시는 게 좋습니다.

# 집 안에 있을 때 해볼 수 있는 것
안에서 문이 안 열리면 안쪽 열림 버튼이나 수동 손잡이를 써 보세요. / 전기 없이 걸쇠를 움직이는 수동 장치가 있는 제품이 많습니다.
수동 장치로 열렸다면 문을 열어 둔 채로 건전지를 갈고 잠금과 열림을 몇 번 해 봅니다. / 문이 열린 상태에서 시험해야 갇히는 일이 없습니다.

# 하지 말아야 할 대처
경고음이 시끄럽다고 건전지를 뺀 채로 두면 바깥에서 문을 열 방법이 사라집니다. / 외출 중이라면 특히 피해 주세요.
번호판이나 몸체를 두드리거나, 틈새에 윤활유를 뿌리는 것도 전자 부품을 상하게 합니다. / 모터가 헛돌 때 손잡이를 세게 미는 것도 걸쇠를 더 꽉 물리게 할 뿐입니다.

# 통화로 전해 주시면 좋은 내용
단지 이름과 동, 호수를 알려 주시고, 소리가 나는 상황이 나갈 때인지 들어올 때인지 혼자 울리는지 말씀해 주세요. / 녹음이나 영상이 있다면 문자로 보내 주시면 됩니다.
지금 문 밖에 계신지, 안에 계신지도 꼭 알려 주세요. / 밖에서 문이 안 열리는 상황이면 순서를 앞당겨 움직입니다.

# 거주 확인 뒤 비용부터 안내
문을 열어야 하는 상황이면 신분증, 우편물, 관리사무소 세대 확인 가운데 하나로 사시는 분인지 먼저 확인합니다. / 소리와 증상을 보고 원인과 비용을 손대기 전에 말씀드린 뒤 시작합니다.
끝내 못 열면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 있습니다.
모터나 기판 쪽이면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 연식이 오래된 제품은 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.
@ 부천 상동 도어락 오작동 수리 출장

# 상동 이웃 동네와 부천 어디든
상동과 함께 중동, 송내동, 심곡동, 소사동, 원종동, 오정동, 고강동, 역곡동, 범박동, 옥길동까지 부천 전 지역을 다닙니다. / 서울, 경기 전 지역 24시간 출동합니다.
부천에서 다니는 동네는 [부천 출장열쇠](bucheon.html), 다른 지역은 [출장 지역](area.html)에서 보세요.

# 자주 묻는 질문
? 문을 닫으면 잠기지 않고 경고음이 나요. | 걸쇠가 문틀 구멍에 다 안 들어간 경우가 많습니다. 손으로 한 번 더 밀어 닫아 보시고, 받이 구멍에 이물질이 없는지 봐 주세요.
? 번호는 맞는데 모터만 돌아요. | 건전지가 약하거나 걸쇠가 문틀에 눌린 경우입니다. 문을 살짝 당긴 뒤 다시 눌러 보시고, 안 되면 연락 주세요.
? 밤에 도어락이 혼자 울려요. | 건전지 알림, 번호판 물기, 바깥 입력 실패 경보 가운데 하나일 수 있습니다. 바깥이 의심되면 문을 열지 말고 경비실에 먼저 알리세요.
? 시끄러워서 건전지를 빼 둬도 될까요? | 외출 중에는 바깥에서 문을 열 수 없게 되니 피해 주세요. 새 건전지로 바꾸는 게 맞습니다.
? 소리 때문에 불렀는데 문을 못 열면 어떻게 되나요? | 못 열면 비용은 받지 않습니다.
