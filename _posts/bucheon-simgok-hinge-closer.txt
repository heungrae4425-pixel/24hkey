# 심곡동, 문을 닫았는데 손을 떼면 다시 벌어진다
심곡동은 부천역 주변으로 빌라와 다세대, 1층에 가게를 둔 상가 건물이 촘촘히 붙어 있는 동네입니다. / 집 현관문뿐 아니라 계단으로 들어가는 건물 출입문까지, 하루에도 여러 사람이 여닫는 문이 많습니다.
닫았다고 생각하고 돌아섰는데 문이 손가락 한 마디쯤 벌어진 채 서 있는 일이 있습니다. / 닫히긴 하는데 문틀에 부딪혀 툭 되튕기거나, 끝에서 끼익 소리를 내며 멈추기도 합니다.
이 글은 심곡동에서 문이 꼭 닫히지 않을 때 어디서부터 봐야 하는지 순서를 잡아 정리했습니다. / 손보기 어려우면 [부천 출장열쇠](bucheon.html)로 사진을 보내 주세요.
@ 심곡동 빌라 현관문 덜 닫힘 점검

# 문이 덜 닫히면 생기는 일
문이 끝까지 닫히지 않으면 도어락 걸쇠가 문틀 홈에 들어가지 못합니다. / 자동 잠금 소리가 나도 실제로는 잠기지 않은 상태일 수 있습니다.
덜 닫힘을 알려 주는 도어락이라면 경고음이 울리지만, 그렇지 않은 제품도 많습니다. / 외출 뒤 문이 살짝 열려 있었다는 이야기를 들었다면 이 부분을 꼭 점검해 보세요.
상가 건물 계단 출입문이 덜 닫히면 밤새 건물 입구가 열려 있게 됩니다. / 위층에 사는 세대 모두와 관련된 일이라 미루지 않는 게 좋습니다.

# 가장 먼저, 문틀 고무 패킹
의외로 흔한 원인이 문틀 둘레에 붙은 고무 패킹입니다. / 바람과 소음을 막으려고 새로 두꺼운 패킹을 붙였다면 문이 그만큼 밀려 끝까지 닫히지 않습니다.
패킹 한쪽이 떨어져 접히거나 뭉친 자리가 있는지 손으로 문틀을 따라 훑어 보세요. / 걸쇠 쪽 패킹이 두꺼우면 걸쇠가 홈까지 닿지 못합니다.
패킹을 손본 것만으로 해결되는 일이 꽤 있습니다. / 도어클로저나 경첩을 만지기 전에 먼저 확인해 볼 만합니다.

# 바닥과 문 아래 틈도 보세요
문 아래에 두꺼운 매트를 깔았거나 신발이 걸려 있으면 문이 끝까지 가지 못합니다. / 현관 바닥 타일을 새로 깔았다면 바닥이 높아져 문 끝이 긁히기도 합니다.
문 아래 끝에 긁힌 자국이 길게 나 있는지 살펴보세요. / 자국이 있다면 문이 처졌거나 바닥이 높아진 경우입니다.

# 도어클로저, 몸통과 팔을 나눠서
문 위에 달린 도어클로저는 몸통과 꺾이는 팔로 나뉩니다. / 문제가 어느 쪽에 있는지에 따라 손볼 곳이 다릅니다.
- 몸통 아래로 기름이 흘러내린 자국 → 몸통 안쪽 문제
- 팔 관절이 흔들리고 닫힐 때 덜컥 소리 → 팔 연결 나사 문제
- 팔이 문틀 쪽 받침에서 빠져 있음 → 고정 위치 문제
- 문을 일정 각도에서 세워 두는 기능이 켜져 있음 → 정지 기능 설정
상가 건물 출입문은 짐을 나를 때 문을 세워 두려고 정지 기능을 켰다가 끄지 않는 경우가 있습니다. / 이럴 때는 문이 일정 각도에서 멈춰 버립니다.
@ 부천 심곡동 상가 출입문 도어클로저 팔

# 조절 나사는 표시를 해 두고
도어클로저 몸통에는 닫히는 속도를 정하는 조절 나사가 있습니다. / 돌리기 전에 지금 위치를 유성펜으로 표시해 두면 잘못 돌렸을 때 원래대로 돌아갈 수 있습니다.
조금 돌리고 문을 서너 번 닫아 본 뒤 다시 조금 돌리는 식으로 맞춥니다. / 한 번에 많이 풀면 안쪽 기름이 새어 나올 수 있어 조심해야 합니다.
공용 출입문이라면 혼자 돌리기보다 관리하는 분과 먼저 상의해 주세요. / 무거운 문은 너무 빨라지면 아이나 어르신이 다칠 수 있습니다.

# 경첩에서 나는 소리와 처짐
문을 여닫을 때 경첩에서 끼익 소리가 난다면 마른 상태입니다. / 경첩 축 위쪽에 윤활제를 조금 뿌리고 문을 여러 번 움직여 주면 소리가 줄어듭니다.
소리보다 처짐이 더 문제입니다. / 문을 반쯤 열고 손잡이 쪽을 위로 들어 봤을 때 덜컥 움직이면 경첩 나사가 풀렸을 가능성이 큽니다.
나사가 헛돈다면 구멍이 넓어진 것이라 그냥 조여서는 해결되지 않습니다. / 이 경우는 점검을 받는 편이 낫고, 문이 완전히 막혀 열리지 않는다면 [현관문 개문](door-open.html)부터 진행합니다.

# 걸쇠 받이 쇠판이 어긋났다면
문은 끝까지 닫히는데 걸쇠가 홈에 걸려 되튕긴다면 문틀 쪽 받이 쇠판 위치를 보세요. / 문이 조금 처지면 걸쇠와 쇠판 홈 높이가 어긋납니다.
쇠판 홈 위나 아래에 걸쇠가 긁고 지나간 자국이 있다면 이 경우입니다. / 쇠판을 살짝 옮기거나 홈을 넓혀 맞추는 작업이 필요합니다.
이 상태로 계속 쓰면 걸쇠 끝이 닳고 도어락 모터도 매번 힘을 더 쓰게 됩니다. / 문을 닫을 때마다 손으로 한 번 더 밀어야 잠긴다면 그때가 점검할 시기입니다.

# 계절과 바람에 따라 달라질 때
겨울에는 도어클로저 안쪽 기름이 걸쭉해져 문이 느리게 닫히고, 여름에는 빨라집니다. / 계절 바뀔 때 한두 번 다시 맞춰 주면 됩니다.
심곡동처럼 건물이 붙어 있는 골목은 계단실 안팎으로 바람이 세게 드나들기도 합니다. / 창문을 열어 둔 날만 문이 덜 닫힌다면 바람 영향일 수 있습니다.
@ 심곡동 현관 경첩 처짐 확인

# 누가 손볼 문인지 정하기
우리 집 현관문은 세대에서, 건물 출입문은 건물을 관리하는 쪽에서 맡는 경우가 많습니다. / 세입자라면 집 현관이라도 집주인에게 먼저 알려 두는 것이 좋습니다.
상가 건물 1층 가게 문이라면 가게 쪽과 건물주 중 누가 맡는지 계약 내용을 한 번 확인해 보세요. / 정한 내용은 문자로 남겨 두면 나중에 헷갈리지 않습니다.

# 점검을 부탁하실 때
아래를 함께 알려 주시면 맞는 부품을 챙겨 갈 수 있습니다. / 사진 두세 장이면 대부분 가늠됩니다.
- 집 현관인지, 건물 출입문인지, 가게 문인지
- 도어클로저 몸통과 팔 사진
- 문을 닫았을 때 벌어지는 틈 사진
- 덜 닫힌 뒤 도어락이 잠기는지 여부
도착하면 사시는 분이나 사용하시는 분인지 먼저 확인합니다. / 상태를 본 뒤 비용을 손대기 전에 말씀드리고, 동의하실 때 시작합니다. / 진행 순서는 [이용안내](guide.html)에 있습니다.

# 손보고 난 뒤
문을 여러 번 닫아 보며 걸쇠가 한 번에 들어가는지 확인합니다. / 도어락 자동 잠금이 제대로 걸리는지도 함께 봅니다.
도어락 걸쇠나 모터가 힘이 약해졌다면 [도어락 수리](doorlock-repair.html)로 함께 손봅니다. / 도어클로저가 너무 낡아 바꿔야 한다면 바꾸기 전에 먼저 여쭤보고, 도어락까지 오래됐다면 [도어락 교체](doorlock-replace.html)도 상의드립니다.

# 심곡동 말고 부천 어디든
심곡동과 가까운 소사동, 중동, 송내동부터 상동, 역곡동, 원종동, 오정동, 고강동, 옥길동, 범박동까지 부천 어디든 갑니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 고무 패킹을 새로 붙인 뒤 문이 덜 닫혀요. | 패킹이 두꺼워 문을 밀어내는 경우가 많습니다. 걸쇠 쪽 패킹부터 확인해 보세요.
? 도어클로저 나사를 돌렸다가 더 이상해졌어요. | 원래 위치를 모르면 사진을 보내 주세요. 많이 풀었다면 기름이 샜는지도 봐야 합니다.
? 경첩에서 소리만 나는데 손봐야 하나요? | 소리만이라면 윤활로 줄어듭니다. 문이 들썩이면 나사 점검이 필요합니다.
? 건물 출입문도 점검해 주시나요? | 네, 관리하는 분과 이야기된 경우 출입문 도어클로저와 경첩도 봐 드립니다.
? 문이 덜 닫혀도 도어락은 잠긴 건가요? | 걸쇠가 홈에 들어가지 않으면 잠긴 게 아닙니다. 손으로 당겨 꼭 확인해 주세요.

# 마무리
