# 심곡동, 한 집에 여러 사람이 드나드는 경우
심곡동은 부천역 주변으로 빌라와 다세대, 1층에 가게를 둔 상가 건물이 촘촘히 붙어 있는 동네입니다. / 역과 가까워 학생이나 사회초년생이 방 하나씩 나눠 쓰는 쉐어하우스나 큰 빌라 세대에서 함께 사는 경우도 있습니다.
여러 사람이 한 현관을 쓰다 보면 번호를 누가 알고 있는지, 언제 바뀌었는지가 금방 흐려집니다. / 각자 방문까지 잠그는 집이라면 잠금장치가 두 겹이 되어 막히는 경우의 수도 늘어납니다.
이 글은 심곡동에서 쉐어하우스나 방을 나눠 쓰는 집에 사는 분들이 출입문을 어떻게 관리하면 좋은지, 막혔을 때 어떻게 하면 되는지 정리했습니다. / 급할 때는 [부천 출장열쇠](bucheon.html)로 연락 주셔도 됩니다.
@ 심곡동 쉐어하우스 현관 도어락 번호 공유

# 한 집 안의 잠금, 몇 겹인지 그려 보기
쉐어하우스는 보통 아래처럼 세 겹으로 잠깁니다. / 어느 문을 누가 관리하는지 그려 두면 문제가 생겼을 때 덜 헤맵니다.
- 건물 공동 출입문: 건물 관리인이나 집주인
- 세대 현관문: 운영자 또는 함께 사는 사람 모두
- 각자 방문: 방을 쓰는 사람 각자
현관 번호는 운영자가 정하고, 방문 열쇠는 각자 갖는 구조가 흔합니다. / 계약할 때 이 구조를 운영자에게 확인해 두세요.

# 현관 번호는 한 사람이 맡아 바꾸기
여러 사람이 각자 번호를 바꾸면 반드시 누군가 모르는 채로 남습니다. / 현관 번호는 운영자나 대표 한 사람이 맡아 바꾸는 게 원칙처럼 정해 두면 좋습니다.
바꿀 때는 같이 사는 사람 모두에게 같은 시간에 알립니다. / 단체 대화방에 올리고 모두 확인했다는 답을 받은 뒤 바꾸면 밤늦게 문 앞에서 막히는 사람이 생기지 않습니다.
번호를 알려 줄 때는 대화방 공지에 오래 남기기보다 개인 메시지로 보내는 편이 낫습니다. / 대화방에 사람이 들고 나며 예전 번호가 남아 돌기 때문입니다.

# 사람이 들고 날 때마다 번호 정리
쉐어하우스는 계약 기간이 짧아 사람이 자주 바뀝니다. / 누군가 나가는 날에는 그날 저녁 현관 번호를 바꾸는 것을 기본으로 정해 두세요.
카드키나 태그를 쓰는 집이라면 나가는 사람의 카드를 돌려받고, 도어락에서도 그 카드를 지워야 합니다. / 돌려받은 카드라도 지우지 않으면 등록 정보는 남아 있습니다.
새로 들어오는 사람에게는 바뀐 번호만 알려 줍니다. / 예전 번호는 처음부터 몰라도 됩니다.
@ 부천 심곡동 쉐어하우스 카드키 정리

# 각자 방문 잠금장치 다루기
방문에 손잡이 잠금이나 작은 도어락을 쓰는 집이 많습니다. / 개인 공간을 지켜 주지만, 열쇠를 방 안에 두고 문이 닫히면 혼자서는 열 수 없습니다.
운영자가 여벌 방 열쇠를 갖고 있는지 입주할 때 물어 두세요. / 여벌이 있다면 막혔을 때 운영자에게 먼저 연락하면 됩니다.
방문 도어락은 운영자 허락 없이 바꾸지 않는 게 좋습니다. / 나갈 때 원래대로 돌려놓아야 하는 경우가 많기 때문입니다.

# 공용 공간을 오갈 때 생기는 일
쉐어하우스에서는 부엌, 욕실, 세탁실을 오가며 방문을 자주 여닫습니다. / 잠깐 씻으러 나간 사이 방문이 저절로 잠기는 손잡이라면 열쇠를 손목에 거는 습관이 가장 확실합니다.
잠금 버튼을 눌러 둔 채 문을 닫으면 그대로 잠기는 손잡이도 있습니다. / 공용 공간에 갈 때는 버튼이 눌려 있지 않은지 한 번 보고 나오세요.

# 하우스메이트와 미리 정해 둘 약속
함께 사는 사람끼리 몇 가지만 정해 두면 출입문 문제가 크게 줄어듭니다. / 처음 모일 때 한 번 이야기해 두세요.
- 밤 몇 시 이후에는 안쪽 걸쇠를 걸지 않기
- 현관 도어락 경고음이 나면 들은 사람이 바로 알리기
- 건전지는 누가 언제 갈지 정해 두기
- 친구를 데려올 때 번호를 직접 알려 주지 않기
특히 안쪽 걸쇠는 먼저 들어온 사람이 습관처럼 걸어 두면 늦게 오는 사람이 들어오지 못합니다. / 걸쇠 사용 시간을 정해 두는 것만으로도 새벽 연락이 줄어듭니다.

# 현관이 막혔을 때 먼저 할 일
현관 번호가 틀렸다고 나오면 번호가 바뀌었는지 대화방부터 확인해 보세요. / 집 안에 다른 사람이 있다면 전화해 열어 달라고 하는 것이 가장 빠릅니다.
번호판이 꺼져 있다면 건전지 문제일 가능성이 큽니다. / 바깥 몸체 아래 비상 단자에 9V 건전지를 대고 번호를 눌러 보세요.
안에 사람이 있는데 걸쇠가 걸려 있다면 연락이 닿을 때까지 기다리는 게 좋습니다. / 연락이 안 되는데 걱정되는 상황이라면 그 사정을 전화로 말씀해 주세요.

# 내 방문만 막혔을 때
현관은 지났는데 내 방문이 열리지 않는다면 운영자에게 여벌 열쇠가 있는지 먼저 물어보세요. / 하우스메이트에게 방 열쇠를 맡겨 두었다면 그것도 방법입니다.
방문은 얇아서 힘을 주면 쉽게 상합니다. / 어깨로 밀거나 카드로 문틈을 건드리지 말고 연락을 기다려 주세요.
@ 심곡동 방문 잠금 손잡이 열쇠

# 전화 주실 때는 어느 문인지부터
쉐어하우스는 막힌 문이 어느 문인지 설명하는 것이 중요합니다. / 아래를 짧게 말씀해 주세요.
- 심곡동 어느 쪽인지, 건물 이름과 층, 호수
- 막힌 문이 건물 입구, 세대 현관, 내 방문 중 어디인지
- 집 안에 다른 사람이 있는지
- 운영자와 연락이 됐는지
비슷한 빌라가 이어진 골목이라 건물 이름이나 1층 가게를 함께 알려 주시면 찾기 쉽습니다.

# 함께 사는 집의 거주 확인
쉐어하우스는 신분증 주소가 지금 사는 곳과 다른 경우가 많습니다. / 입주 계약서, 월세 이체 기록, 운영자와의 문자 중 하나로 사시는 분인지 확인합니다.
방문을 열 때는 그 방을 쓰는 분이 맞는지까지 확인합니다. / 하우스메이트라도 다른 사람 방을 대신 열어 달라는 요청은 받지 않습니다.
확인이 끝나면 비용을 먼저 말씀드리고, 동의하실 때 시작합니다. / 끝내 열지 못하면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 열린 뒤 집 안에서 정리할 것
건전지가 원인이었다면 그 자리에서 모두 새것으로 바꾸고 다음 교체 담당을 정해 두세요. / 번호 때문이었다면 운영자에게 알리고 새 번호를 모두에게 다시 공유합니다.
현관 도어락이 자주 말썽이라면 운영자와 상의해 [도어락 수리](doorlock-repair.html)를 받아 보세요. / 사람마다 번호를 따로 쓸 수 있는 제품으로 바꾸고 싶다면 [도어락 교체](doorlock-replace.html)에서 방식을 살펴볼 수 있습니다.
여는 과정이 궁금하시면 [현관문 개문](door-open.html)을 보시면 됩니다.

# 심곡동 말고 부천 어디든
심곡동과 가까운 소사동, 중동, 송내동은 물론 상동, 역곡동, 원종동, 오정동, 고강동, 옥길동, 범박동까지 부천 어디든 갑니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 사람마다 다른 번호를 쓰는 도어락이 있나요? | 여러 번호를 등록할 수 있는 제품이 있습니다. 운영자와 상의해 바꾸실 수 있습니다.
? 운영자와 연락이 안 되는 밤에도 와 주시나요? | 네, 24시간 받습니다. 거주 확인 자료만 준비해 주세요.
