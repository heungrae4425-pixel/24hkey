# 소사동 빌라, 계단 몇 칸 내려간 사이 철컥
부천 소사동 골목의 빌라와 다세대에서는 1층 현관 앞에 놓인 택배를 가지러 가거나, 골목 분리수거 자리에 재활용을 내놓으러 잠깐 내려가는 일이 하루에도 몇 번씩 있습니다. / 빌라 사이사이 작은 가게가 섞여 있는 동네이기도 합니다.
문을 살짝 닫아 두고 나왔는데 등 뒤에서 철컥 소리가 나면 그때부터 상황이 달라집니다. / 손에는 빈 상자나 쓰레기봉투뿐이고 휴대폰과 지갑은 집 안에 있는 경우가 대부분입니다.
이 글은 소사동에서 이렇게 잠깐 나왔다 문이 잠겼을 때 연락 수단부터 찾는 방법과 [부천 출장열쇠](bucheon.html)에 연락하는 순서, 다음을 막는 습관까지 정리했습니다.
@ 소사동 빌라 택배 분리수거 중 문 잠김

# 왜 잠깐 사이에 잠길까
요즘 도어락은 대부분 문이 닫히면 저절로 잠기는 자동 잠금이 켜져 있습니다. / 문이 끝까지 닫히는 순간 걸쇠가 나오기 때문에, 살짝 닫아 둔 줄 알았던 문도 도어클로저나 바람에 밀려 그대로 잠깁니다.
계단실 창문이 열려 있거나 아래층 공동현관이 열려 있으면 바람이 통하면서 문이 더 쉽게 닫힙니다. / 그래서 "분명히 열어 놨는데"라는 말이 가장 많이 나오는 상황이기도 합니다.
문 아래에 신발이나 상자를 대충 괴어 두는 것도 믿을 만하지 않습니다. / 클로저 힘에 밀려 받침이 빠지거나, 지나가던 이웃이 문이 열려 있는 줄 알고 닫아 주는 일도 있습니다. / 괴어 둘 거라면 바닥에 단단히 끼우는 고무 문 받침을 쓰시는 편이 낫습니다.

# 우선 번호와 다른 열 방법 떠올리기
번호키를 쓰는 집이라면 비밀번호를 눌러 들어가면 끝입니다. / 문제는 평소 지문이나 카드로만 드나들어 번호를 잘 모르는 경우입니다.
천천히 떠올려 보고, 확신이 서지 않으면 서너 번 안에서 멈춰 주세요. / 여러 번 틀리면 입력이 잠겨 가족이 와서 번호를 눌러도 한동안 안 열립니다.
집에 다른 식구가 있다면 문을 두드리거나 이름을 불러 보세요. / 방에서 이어폰을 끼고 있거나 잠들어 있어 모를 수도 있습니다.

# 전화 빌릴 곳 찾기
휴대폰이 없으면 가장 먼저 연락 수단을 구해야 합니다. / 소사동처럼 골목에 상가가 섞여 있는 동네라면 가까운 가게에 사정을 말씀드리고 잠깐 전화를 빌리는 게 빠릅니다.
같은 건물 이웃에게 부탁하는 방법도 있습니다. / 평소 인사 나누던 이웃이라면 휴대폰을 빌려 쓰는 동안 잠시 들어와 기다리라고 해 주실 수도 있습니다.
늦은 밤이라 가게도 닫고 이웃에게도 부탁하기 어렵다면 가까운 편의점을 찾아보세요. / 직원에게 사정을 말씀드리고 짧은 통화만 부탁해 보세요.
@ 소사동 골목 상가 전화 빌려 연락하기

# 빌린 전화로 누구에게 먼저 걸까
외우는 번호가 몇 개 없다면 순서를 정해 거는 게 좋습니다. / 아래 순서를 권합니다.
- 번호나 카드를 가진 가족
- 예비 열쇠를 가진 집주인이나 가까운 친척
- 출장열쇠
가족이 가까이 있고 금방 올 수 있다면 그게 가장 간단합니다. / 가족이 멀리 있거나 연락이 안 되면 바로 출장을 부르는 편이 기다리는 시간을 줄입니다.
출장열쇠 번호를 모르신다면 빌린 휴대폰으로 동네 이름과 출장열쇠를 검색해 주세요. / 통화가 끝나면 빌린 분께 다시 연락이 올 수 있다고 미리 양해를 구해 두시면 좋습니다.

# 집 안에 불이나 물이 켜져 있다면
가스레인지에 냄비를 올려 두었거나 세탁기, 수도꼭지를 틀어 둔 채 나왔다면 통화하실 때 맨 먼저 말씀해 주세요. / 순서를 앞당겨 움직입니다.
타는 냄새나 연기가 느껴진다면 출장보다 119에 먼저 연락하셔야 합니다. / 안에 아이나 반려동물이 있다는 사실도 꼭 알려 주세요.

# 출장을 부를 때 짧게 전할 것
빌린 전화라 통화를 오래 하기 어려우니 필요한 것만 짧게 말씀해 주세요. / 소사동 건물 이름이나 번지, 층과 호수, 지금 어디에서 기다리실지면 충분합니다.
다시 연락받을 번호가 없다면 기다릴 장소를 정확히 정해 두는 게 중요합니다. / 예를 들어 "건물 1층 현관 앞"이나 "길 건너 편의점 안"처럼 말씀해 주시면 그 자리로 찾아갑니다.
위치를 받으면 예상 도착 시간을 먼저 말씀드립니다.

# 슬리퍼 차림으로 기다릴 때
분리수거하러 나온 차림 그대로라면 겨울에는 금방 몸이 식습니다. / 계단실이나 골목에 서 계시기보다 이웃집이나 가게 안처럼 따뜻한 곳에서 기다려 주세요.
도착 예정 시간이 되면 정한 자리로 나와 계시면 됩니다. / 기다리는 동안 문을 계속 당기거나 번호를 여러 번 누르는 건 피해 주세요.

# 신분증이 집 안에 있다면
잠깐 나온 상황이라 신분증도 집 안에 있는 게 보통입니다. / 이럴 때는 집주인이나 같은 건물 이웃의 확인, 가족과의 통화로 사시는 분인지 확인합니다.
문을 연 직후 집 안의 신분증을 바로 보여 주시는 방식으로 진행하기도 합니다. / 어떤 방식으로 할지는 문 열기 전에 미리 말씀드리고 동의를 받습니다.

# 비용 안내와 문 열기
도어락 종류와 잠긴 상태를 보고 어떻게 열지, 비용이 어떻게 되는지 손대기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작합니다.
문과 도어락이 덜 상하는 방법부터 해 보고, 끝내 못 열면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 있습니다.

# 다음에는 이렇게 막아 보세요
- 지문이나 카드만 쓰더라도 번호 하나는 꼭 외워 두기
- 잠깐 나갈 때는 문 아래에 문 받침을 끼워 두기
- 휴대폰은 주머니에 넣고 나가는 습관 들이기
- 가족 번호 하나, 가까운 사람 번호 하나는 외워 두기
- 자동 잠금 끄는 방법이 있는 제품이라면 미리 알아 두기
자동 잠금을 꺼 두면 편하지만 외출할 때 잠그는 걸 잊기 쉬우니 짧게 나갈 때만 쓰는 게 좋습니다. / 기능이 있는지, 어떻게 켜고 끄는지는 [도어락 수리](doorlock-repair.html) 점검 때 함께 알려 드립니다.
번호 없이 카드나 지문만 되는 오래된 제품이라면 번호도 함께 쓸 수 있는 제품으로 [도어락 교체](doorlock-replace.html)를 생각해 볼 만합니다.
@ 부천 소사동 잠깐 외출 문 잠김 개문 출장

부천에서 다니는 곳은 [부천 출장열쇠](bucheon.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
