# 역곡동 자취방에서 문이 안 열릴 때
역곡동은 역곡역 근처로 원룸과 자취방, 작은 다세대 건물이 많아 혼자 사는 분들이 많은 동네입니다. / 시험 기간이나 야간 아르바이트 때문에 늦게 들어오는 날 문이 안 열리면 더 당황스럽습니다.
혼자 사는 곳은 열어 줄 식구가 없어서 문 앞에서 혼자 해결해야 합니다. / 이 글은 [부천 출장열쇠](bucheon.html)로 역곡동에서 자취방 문 문의를 받으며 자주 나오는 상황과 순서를 적은 것입니다.
@ 역곡동 24시 출장열쇠 원룸 자취방 현관문 개문

# 자취방 문이 잠기는 흔한 경우
자취방에서 문 앞에 막히는 상황은 크게 몇 가지로 나뉩니다. / 어떤 경우인지에 따라 집주인에게 먼저 연락할지, 바로 출장열쇠를 부를지가 달라집니다.
- 열쇠나 카드를 방 안에 두고 나온 경우
- 번호를 눌러도 열리지 않거나 번호판이 꺼진 경우
- 새 입주 후 이전 입주자의 번호가 남아 있는 경우
- 방문을 잠가 놓고 외출했다가 열쇠를 잃은 경우
- 건물 공동 현관문 번호를 모르는 경우

# 집주인이나 관리인에게 먼저 물어보세요
원룸 건물은 집주인이나 관리인이 여벌 열쇠와 마스터 번호를 갖고 있는 경우가 많습니다. / 연락이 바로 닿는다면 가장 빠르고 비용이 들지 않는 방법입니다.
다만 한밤이거나 연락이 안 되는 경우, 또는 번호를 알려 주지 않는 경우에는 출장열쇠를 부르는 수밖에 없습니다. / 이때는 집주인에게 문을 열었다는 사실을 나중에 알려 두시는 것이 좋습니다.
건물 공용 현관문 번호는 집주인과 이웃이 아는 경우가 많으니 이웃에게 먼저 물어보는 것도 방법입니다.

# 학생이나 사회초년생이 흔히 하는 실수
급한 마음에 휴대폰으로 인터넷에서 열쇠집을 검색하다가 출장 비용을 높게 부르는 곳에 연락하는 일이 있습니다. / 전화로 비용 범위와 출장비 포함 여부를 먼저 물어보는 것이 좋습니다.
24시출장열쇠는 문을 열기 전에 비용을 먼저 말씀드리고, 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용은 없습니다.
카드키나 휴대폰 앱으로 여는 방식이라면 배터리 부족이나 앱 오류가 원인인 경우도 많습니다.

# 이사 직후에는 번호부터 바꾸세요
자취방에 처음 들어갈 때 이전 입주자가 쓰던 번호가 그대로 남아 있을 수 있습니다. / 이전 입주자나 친구, 방문자가 아직 번호를 알고 있을 수 있어서 입주하자마자 바꾸는 것이 안전합니다.
집주인이 정해 준 번호는 계약 기간 동안 바꿀 수 있는지 먼저 확인하세요. / 바꿔도 된다면 새 번호를 등록하고 집주인에게 필요한 경우에만 알려 드립니다.
번호를 바꾸는 방법은 [도어락 수리](doorlock-repair.html)에서 자주 묻는 부분이니 어려우면 전화 주세요.
@ 부천 역곡동 자취방 도어락 비밀번호 변경

# 출장 요청은 이렇게 하세요
전화하실 때 건물 이름이나 가까운 역, 몇 층 몇 호인지 알려주세요. / 역곡동은 건물이 비슷해서 위치를 정확히 알려주시는 것이 가장 중요합니다.
도어락 모양과 번호판 상태, 지금 어떤 증상인지 말씀해 주시면 챙겨 갈 장비를 정할 수 있습니다. / 문 앞에서 찍은 사진을 문자로 보내주시면 더 정확합니다.
혼자 계신다면 안전하게 건물 입구나 밝은 곳에서 기다려 주세요.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 임대차 계약서, 집주인 확인 중 하나면 됩니다.
이사 온 지 얼마 안 되어 신분증 주소가 이전 주소라면 계약서나 집주인 문자가 도움이 됩니다. / 확인이 어려우면 작업할 수 없으니 미리 준비해 두세요.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
부품을 바꿔야 하는 경우에는 손대기 전에 먼저 여쭙습니다. / 세입자이시면 부품 비용을 누가 부담할지 집주인과 이야기해 보시는 것이 좋습니다.

# 문은 최대한 안 상하게 엽니다
문 여는 방법은 여러 가지가 있고 덜 상하는 방법부터 차례로 해봅니다. / 원룸 건물 문은 집주인 소유라서 문이 상하지 않는 것이 더 중요합니다.
방법은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다. / 도어락이나 문틀이 상할 가능성이 있는 경우에는 미리 말씀드립니다.

# 열고 난 뒤에 확인할 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이면 새 배터리로 바꾸고, 번호를 잊은 경우에는 안쪽에서 새 번호를 등록합니다.
고쳐서 쓸 수 있으면 교체를 권하지 않습니다. / 너무 오래돼 고장이 잦은 제품은 [도어락 교체](doorlock-replace.html) 쪽을 말씀드립니다.

# 혼자 사는 분이 미리 해두면 좋은 것
방 안과 밖에 비상 연락처를 적어 둔 종이를 따로 두세요. / 집주인과 이웃 한두 분의 연락처를 휴대폰에 저장해 두면 문 앞에서 막혔을 때 빨리 연락할 수 있습니다.
- 도어락 배터리 교체일을 달력에 적어 두기
- 비상용 9V 건전지 하나를 가방에 넣어 두기
- 믿을 수 있는 사람에게 여벌 열쇠 맡겨 두기
- 건물 공동 현관 번호와 집 번호를 메모해 두기
작은 준비만 해도 늦은 밤 문 앞에서 막히는 일이 크게 줄어듭니다.

# 룸메이트나 친구와 같이 지낼 때
쉐어하우스나 룸메이트와 함께 쓰는 집이라면 번호를 아는 사람이 여럿입니다. / 누가 나가거나 새로 들어올 때마다 번호를 바꾸는 규칙을 처음에 정해 두면 다툼이 줄어듭니다.
한 사람이 문을 잠그고 나가 다른 사람이 못 들어오는 일도 흔합니다. / 이럴 때는 계약자 한 명이 사시는 분으로 확인되면 문 여는 작업은 가능합니다. 룸메이트에게 미리 연락해 두시면 확인 절차가 훨씬 빨라집니다.
공용 공간 문과 각자 방문이 따로 있다면 어느 문인지 정확히 알려주세요. / 방문 잠금장치도 같은 방식으로 열어 드립니다.

# 시험 기간과 야간 근무 때 특히 조심하세요
피곤한 상태에서는 번호를 잘못 누르거나 열쇠를 두고 나오는 일이 잦습니다. / 문 닫기 전에 열쇠와 휴대폰을 만지는 습관을 만들어 두면 좋습니다.
늦게 귀가하는 날에는 배터리 상태를 미리 확인해 두세요. / 경고음이 울린 날 바로 바꾸지 않으면 꼭 가장 바쁜 날에 멈춥니다.
