# 보산동 원룸에서 문 앞에 멈춰 섰을 때
동두천 보산동은 보산역 주변으로 원룸과 오피스텔, 상가 건물이 많이 모여 있는 동네입니다. / 혼자 사시는 분이 많아 문이 안 열리면 도와줄 사람이 바로 없는 경우가 많습니다.
번호를 눌러도 반응이 없거나, 열쇠가 안 돌아가거나, 문을 잠그고 나온 걸 문 앞에서야 알게 되는 일이 생깁니다. / 이런 때일수록 순서를 정해 하나씩 확인하는 것이 빠릅니다.
이 글은 보산동 원룸과 오피스텔에서 현관문이 안 열릴 때 전화하기 전에 해볼 것을 정리했습니다. / 마지막에는 [동두천 출장열쇠](dongducheon.html)가 어떤 순서로 오는지도 적었습니다.
@ 보산동 원룸 오피스텔 현관문 출장열쇠

# 먼저 문 앞에서 확인할 것
번호판이 켜지는지, 켜진다면 눌렀을 때 소리가 나는지부터 보세요. / 아무 반응이 없으면 배터리가 방전된 경우가 가장 흔합니다.
번호를 평소와 다르게 누르고 있지는 않은지도 확인합니다. / 급할 때는 익숙한 번호도 헷갈립니다.
문을 안쪽으로 살짝 밀면서 눌러 보면 걸쇠가 풀리는 경우가 있습니다. / 힘은 주지 말고 가볍게만 시도하세요.

# 건물 관리실과 관리인에게 먼저 연락
오피스텔과 큰 원룸 건물은 관리실에서 공용 출입문과 세대 확인을 도와주는 경우가 있습니다. / 관리실에서 신분 확인을 대신해 주면 작업이 훨씬 빨라집니다.
주인이 따로 사는 원룸이라면 집주인이나 관리인이 여분 열쇠나 번호를 갖고 있을 수도 있습니다. / 연락이 닿는 시간이면 먼저 물어보세요.
공용 현관이 잠겨 있어 건물에 못 들어가는 상황이라면 그 사정을 같이 말씀해 주세요. / 건물 안에 들어가는 방법부터 안내해 드립니다.
@ 보산동 오피스텔 공용 현관 도어락

# 배터리와 비상 전원 확인
번호판 아래나 문 바깥쪽에 비상 전원 단자가 있는 제품이 많습니다. / 9V 건전지를 잠깐 대고 번호를 누르면 열리는 경우가 있습니다.
단자를 못 찾겠거나 반응이 없을 때는 더 시도하지 않는 것이 좋습니다. / 접점이 상하면 수리 범위가 커집니다.
원룸은 문 안쪽 배터리 덮개가 눌려 닫혀 있는 구조도 있어 억지로 열면 외관이 상합니다. / 안 보이면 그대로 두고 연락 주세요.

# 해서는 안 되는 일
창문이나 베란다로 넘어 들어가려는 분이 있는데 층이 높은 건물에서는 매우 위험합니다. / 옆집과 아래층 사람에게도 놀라움을 줍니다.
문틈에 카드나 도구를 넣어 억지로 여는 것도 권하지 않습니다. / 문과 잠금 장치가 상해서 나중에 수리가 더 커집니다.
문을 발로 차거나 어깨로 미는 것은 부상은 물론 소음 문제까지 생깁니다. / 이웃과 마찰이 생기기 전에 그대로 두고 연락 주세요.

# 이럴 땐 바로 연락 주세요
가족이나 관리인과 연락이 안 닿고 여분이 없다면 오래 붙잡고 있을 이유가 없습니다. / 특히 밤늦거나 춥고 비가 오는 날은 일찍 연락 주시는 것이 낫습니다.
집 안에 반려동물이 있거나 가스, 전기를 켜 둔 상태라면 먼저 말씀해 주세요. / 급한 순서를 정해 출동합니다.
24시간 받습니다. / 위치와 상황을 말씀해 주시면 출동 여부와 도착 시간을 먼저 말씀드립니다.

# 보산동에서는 이렇게 위치를 알려 주세요
보산동은 건물이 비슷비슷하게 늘어서 있어 건물 이름만으로 찾기 어려운 곳이 있습니다. / 보산역에서 어느 방향인지, 근처에 눈에 띄는 가게가 무엇인지 같이 말씀해 주세요.
- 건물 종류(원룸, 오피스텔, 상가 위층)와 몇 층 몇 호인지
- 보산역 쪽인지 같은 대략적인 방향
- 문 종류(번호 도어락, 열쇠, 혼합)
- 집 안에 반려동물이 있는지
문 사진을 문자로 보내 주시면 챙겨 갈 장비를 정하는 데 도움이 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 임대차계약서, 관리실 확인 중 하나면 됩니다.
번거로우실 수 있지만 같은 건물 이웃과 집 주인을 모두 지키는 절차입니다. / 확인이 어려우면 작업할 수 없으니 미리 준비해 두세요.
신분증이 집 안에 있다면 휴대폰에 저장된 계약서나 공과금 고지서도 도움이 됩니다. / 관리실에서 세대 확인을 대신해 주면 더 빠릅니다.
@ 보산동 24시 출장열쇠 신분 확인

# 문은 최대한 덜 상하게 엽니다
문과 잠금 장치 상태를 먼저 살핀 뒤 흠집이 가장 적은 방법부터 해봅니다. / 원룸 문은 얇은 경우가 많아 힘을 쓰면 문이 휠 수 있어 더 조심합니다.
도어락 종류와 문 상태에 따라 걸리는 시간은 다릅니다. / 작업 중 부품이 상한 것이 보이면 손대기 전에 말씀드립니다.
방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다. / 못 열면 비용은 받지 않습니다.

# 비용은 열기 전에 먼저 말씀드립니다
현관문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
열고 난 뒤에 말 없이 붙는 비용은 없습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 난 뒤에는 원인을 같이 확인합니다
문이 열리면 배터리, 모터, 번호판 상태를 순서대로 살펴 왜 안 열렸는지 확인합니다. / 배터리 문제라면 새것으로 바꾸는 것으로 끝납니다.
부품이 상했다면 고쳐서 쓸 수 있는지 먼저 봅니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)로 해결합니다.
고장이 심해 바꿔야 한다면 문 규격에 맞는 제품을 안내합니다. / 방식은 [도어락 교체](doorlock-replace.html)에 정리해 두었습니다.

세 들어 사는 집은 도어락을 바꾸거나 열쇠를 새로 만들 때 집주인 허락이 필요한 경우가 있습니다. / 계약서에 원상복구 조건이 있는지 한 번 확인해 두세요.
사용자 과실이 아닌 노후 고장이라면 집주인이 수리비를 부담하는 경우도 있습니다. / 이 부분은 집주인과 직접 상의하시는 것이 맞습니다.
이사 직후에는 전 세입자가 쓰던 번호나 열쇠가 남아 있을 수 있어 새로 정하는 것이 안전합니다. / 필요하면 번호만 바꾸는 것도 안내해 드립니다.

# 앞으로 막히지 않게 하는 습관
- 배터리 알림이 처음 들리면 그날 바로 교체하기
- 비상용 9V 건전지를 현관 서랍이나 가방에 넣어 두기
- 여분 열쇠나 카드를 믿을 만한 곳에 맡겨 두기
- 번호를 가끔 바꾸고 혼자 외우기
- 외출 전 휴대폰과 열쇠, 카드를 한 번에 확인하기
이 정도만 해두어도 문 앞에서 막히는 일이 크게 줄어듭니다.

# 보산동 말고 동두천 어디든 갑니다
생연동, 지행동, 송내동, 상패동, 광암동까지 동두천 전 지역을 다닙니다. / 시내와 가까워서 위치를 받으면 도착 시간을 바로 말씀드립니다.
동두천에서 다니는 지역은 [동두천시 출장열쇠](dongducheon.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
