# 광암동으로 이사 가는 날, 문부터 확인하세요
동두천 광암동은 주택과 빌라, 마을이 섞여 있어 이사 오가는 분들이 꾸준한 동네입니다. / 이삿짐이 들어오기 전에 현관문 잠금 상태를 점검해 두면 훨씬 마음이 편합니다.
이사 직후에는 전 입주자가 쓰던 번호나 열쇠가 그대로 남아 있을 수 있습니다. / 누가 그 번호를 아는지 알 수 없는 상태로 지내는 것은 불안한 일입니다.
이 글은 광암동에서 이사 전후에 도어락과 열쇠를 어떻게 정리해야 하는지 순서대로 정리했습니다. / 마지막에는 [동두천 출장열쇠](dongducheon.html)가 어떻게 돕는지도 적었습니다.
@ 광암동 이사 도어락 열쇠 교체 출장열쇠

# 이사 전에 꼭 해야 하는 이유
전 입주자는 물론 이전 집주인, 청소 업체, 인테리어 업체가 번호나 열쇠를 알고 있었을 수 있습니다. / 새로 들어가는 사람이 모르는 사이에 접근 가능한 사람이 여럿일 수 있습니다.
도어락 번호는 초기화해서 내가 정한 번호로 바꾸는 것이 가장 기본입니다. / 열쇠를 쓰는 문이라면 실린더를 교체하는 것도 방법입니다.
비용 걱정으로 미루는 분이 있지만 이사 당일 한 번에 정리하는 것이 마음이 편합니다. / 이삿짐이 들어오고 나면 시간 잡기가 더 어렵습니다.
@ 광암동 이사 입주 현관문 점검

# 도어락 번호 초기화 순서
제품마다 방식은 다르지만 보통 안쪽 덮개를 열고 초기화 버튼을 누르는 방식입니다. / 설명서가 있으면 먼저 확인하는 것이 좋습니다.
초기화 후에는 새 번호를 정해 등록하고 한두 번 열어 보며 확인합니다. / 생일이나 전화번호 같은 번호는 피하세요.
설명서가 없거나 방식을 모르겠다면 무리하지 말고 연락 주세요. / 잘못 만지면 번호 등록이 꼬이는 경우도 있습니다.

# 열쇠를 쓰는 문이라면
이전 입주자가 복사한 열쇠가 몇 개인지 알 수 없습니다. / 불안하다면 자물쇠 안쪽을 교체하는 것이 가장 깔끔합니다.
실린더만 바꾸면 문 전체를 교체하지 않아도 됩니다. / 열쇠가 새로 나오기 때문에 이전 열쇠는 쓸 수 없게 됩니다.
이 부분은 [출장 열쇠](key-call.html) 페이지에서 자세히 볼 수 있습니다. / 바꾸기 전에는 꼭 먼저 여쭙고 진행합니다.

# 세입자라면 집주인과 먼저 상의하세요
세 들어 사는 집은 도어락을 교체하거나 구멍을 가공하면 원상복구 문제가 생길 수 있습니다. / 계약서에 관련 조항이 있는지 확인해 두세요.
번호 초기화나 열쇠 교체는 보통 문제가 적지만 집주인이 알고 있는 편이 서로 편합니다. / 새 열쇠를 집주인에게 맡길지도 미리 정해 두세요.
이사 나갈 때는 새로 만든 열쇠와 카드를 모두 돌려주거나 초기화해 두는 것이 좋습니다. / 그래야 나중에 분쟁이 생기지 않습니다.

# 이사 나가는 날 해두면 좋은 것
번호는 초기화해서 비우고 카드와 열쇠는 모두 모아 두세요. / 다음 입주자나 집주인이 헷갈리지 않습니다.
도어락 배터리는 새것으로 바꿔 두면 인수인계가 깔끔합니다. / 방전된 채로 넘기면 다음 사람이 문 앞에서 곤란해집니다.
현관 번호판과 문 상태를 사진으로 남겨 두면 원상복구 문제가 생겼을 때 도움이 됩니다. / 이사 당일 한 번만 찍어 두면 됩니다.

# 이사 날 문이 안 열리는 경우
이삿짐센터가 도착했는데 문이 안 열리는 일이 생기기도 합니다. / 이때는 마음이 급하지만 침착하게 순서대로 확인하세요.
배터리를 확인하고 비상 전원을 대 보세요. / 안 되면 억지로 시도하지 말고 연락 주세요.
이삿짐 일정이 걸려 있다면 먼저 말씀해 주세요. / 급한 순서를 정해 출동합니다.

# 광암동에서는 이렇게 위치를 알려 주세요
광암동은 마을과 주택이 이어져 있어 길 설명이 도착 시간을 좌우합니다. / 큰길에서 들어오는 방향이나 눈에 띄는 건물을 같이 말씀해 주세요.
- 건물 종류(주택, 빌라, 아파트)와 몇 층인지
- 큰길에서 어느 쪽으로 들어오는지
- 문 종류(번호 도어락, 열쇠, 혼합)
- 이사 일정이 급한지 여부
문 사진을 문자로 보내 주시면 챙겨 갈 장비를 정하는 데 도움이 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 다루는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 임대차계약서 중 하나면 됩니다.
이사 직후라 주소가 아직 바뀌지 않았다면 계약서 사진이나 전입 신청 안내가 도움이 됩니다. / 집주인 확인으로 대신할 수 있는 경우도 있습니다.
번거로우실 수 있지만 이웃과 집 주인을 모두 지키는 절차입니다. / 확인이 어려우면 작업할 수 없으니 미리 준비해 두세요.
@ 광암동 24시 출장열쇠 이사 도어락 설정

# 작업은 이런 순서로 진행합니다
문과 기존 도어락 상태를 먼저 보고 초기화로 충분한지, 교체가 필요한지 판단합니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
번호 등록, 카드 등록, 열쇠 확인까지 한 번에 마무리하고 사용법을 알려 드립니다. / 방식은 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.
문이 안 열리는 상태라면 먼저 [현관문 개문](door-open.html)으로 열고 난 뒤 순서를 진행합니다. / 못 열면 비용은 받지 않습니다.

# 비용은 시작하기 전에 먼저 말씀드립니다
문 상태와 도어락 종류, 작업 범위를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
작업이 끝난 뒤에 말 없이 붙는 비용은 없습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 이사한 뒤 일주일 안에 해두면 좋은 것
- 번호를 정하고 가족과 공유하기
- 카드나 보조키를 하나 더 만들어 두기
- 비상용 건전지를 현관 서랍에 넣어 두기
- 배터리 알림 소리를 한 번 들어 보며 확인하기
- 열쇠 사본을 믿을 만한 곳에 맡겨 두기
이 정도만 정리해 두면 새 집에서 문 때문에 곤란한 일이 거의 없습니다.

# 광암동 말고 동두천 어디든 갑니다
생연동, 지행동, 송내동, 보산동, 상패동까지 동두천 전 지역을 다닙니다. / 위치를 받으면 도착 시간을 바로 말씀드립니다.
동두천에서 다니는 지역은 [동두천시 출장열쇠](dongducheon.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

이사 시기에는 이삿짐 일정이 촉박해 문 문제를 뒤로 미루기 쉽습니다. / 하지만 입주 첫날 번호와 열쇠를 정리해 두면 한동안 신경 쓸 일이 없습니다.
이전 입주자에게 연락이 닿으면 열쇠를 몇 개 만들었는지 한 번 물어보는 것도 방법입니다. / 답을 알기 어렵다면 처음부터 새로 정리하는 쪽이 마음이 편합니다.
