# 송내동 원룸, 도와줄 사람이 문 안쪽에 없을 때
혼자 사는 집 문이 잠기면 가족이 사는 집과는 사정이 다릅니다. / 안에서 문을 열어 줄 사람이 없고, 열쇠나 번호를 아는 사람도 나 하나뿐인 경우가 많습니다.
동두천 송내동은 아파트가 중심인 동네지만, 혼자 지내는 원룸이나 오피스텔 세대도 있습니다. / 이런 건물은 건물 출입문, 층 복도, 내 방 현관문까지 문이 여러 겹이라 어느 문에서 막혔는지에 따라 연락할 곳이 달라집니다.
이 글은 원룸이나 오피스텔에서 문이 잠겼을 때 출장열쇠보다 건물 관리인이나 집주인을 먼저 찾아보는 이유, 그리고 그다음 순서를 정리했습니다. / 지행역 쪽에서 퇴근해 오다 막히셨다면 아래 순서대로 차분히 따라와 보세요.
@ 송내동 원룸 오피스텔 현관문 잠김

# 이유 하나, 여분 열쇠나 번호를 가진 사람
원룸이나 오피스텔은 집주인이나 관리인이 여분 열쇠, 마스터 카드, 초기 비밀번호를 갖고 있는 경우가 있습니다. / 이 경우 출장을 부르지 않고도 문이 바로 열릴 수 있습니다.
관리인이 건물에 상주하지 않더라도 1층 출입문이나 엘리베이터 옆에 연락처가 붙어 있는 건물이 많습니다. / 입주할 때 받은 계약서나 문자에도 집주인 연락처가 있으니 먼저 찾아보세요.
다만 집주인이 여분을 갖고 있어도 사는 분의 동의 없이 들어오는 것은 곤란하다고 생각하는 분도 있습니다. / 이번 기회에 여분 열쇠를 어떻게 관리할지 이야기해 두시면 좋습니다.

# 이유 둘, 건물 출입문은 내 문이 아닙니다
밤에 건물 출입문이 먼저 잠겨 들어가지 못하는 경우가 있습니다. / 이 문은 여러 세대가 함께 쓰는 문이라 관리인이나 집주인 확인 없이 출장으로 열기 어렵습니다.
이럴 때는 같은 건물 사는 이웃에게 연락하거나, 관리인에게 출입을 부탁하는 것이 순서입니다. / 건물 안에 들어간 뒤 내 방 현관이 문제라면 그때 저희가 도와드립니다.
@ 송내동 오피스텔 건물 출입문 관리인 연락

# 이유 셋, 관리 규정이 있는 건물도 있습니다
오피스텔 중에는 현관 도어락을 건물에서 정한 제품으로 쓰거나, 교체할 때 관리실에 알려야 하는 곳이 있습니다. / 문을 연 뒤 도어락을 바꿀 일이 생기면 이 규정을 미리 알아 두는 편이 좋습니다.
관리실과 통화가 되면 이런 내용도 함께 물어보세요. / 저희도 작업 전에 확인하고 진행합니다.

# 관리인도 집주인도 연락이 안 되면
늦은 밤이나 주말에는 관리인과 집주인 모두 연락이 안 되는 일이 흔합니다. / 몇 번 연락해 보고 안 되면 문자를 남겨 두고 출장을 부르셔도 됩니다.
문자에는 "문이 잠겨 출장열쇠를 부릅니다"처럼 짧게 사정을 남겨 두세요. / 나중에 집주인이 놀라지 않고, 도어락을 손봐야 할 때 이야기하기도 쉽습니다.

# 문 앞에서 먼저 확인할 것
- 번호판에 불이 들어오는지, 완전히 꺼졌는지
- 카드키를 쓰는 문이라면 카드를 댔을 때 반응이 있는지
- 열쇠를 쓰는 문이라면 열쇠가 돌아가는지
- 안쪽 걸쇠를 걸고 나온 건 아닌지
원룸 현관은 번호식, 카드식, 열쇠식이 섞여 있습니다. / 어떤 방식인지에 따라 해볼 수 있는 것이 다르니 먼저 확인해 주세요.

# 번호판이 꺼졌다면 9V 건전지
번호판이 아예 꺼졌다면 바깥 비상 단자에 9V 건전지를 대 볼 수 있습니다. / 건물 1층에 편의점이 있거나 근처에 문을 연 가게가 있다면 하나 구해 보세요.
건전지를 대고 있는 동안에만 전원이 들어오니 번호를 다 누를 때까지 떼지 마세요. / 열리면 그날 바로 안쪽 건전지를 전부 새것으로 바꿔야 합니다.

# 하면 안 되는 것
혼자라 마음이 급해도 아래는 피해 주세요.
- 문틈에 카드나 드라이버를 넣어 걸쇠를 밀기
- 번호를 이것저것 계속 눌러 보기
- 창문이나 베란다로 들어가려고 하기
특히 높은 층 창문으로 들어가려는 시도는 정말 위험합니다. / 문은 다시 열 수 있지만 다치면 되돌릴 수 없습니다.
@ 송내동 원룸 혼자 사는 집 문 잠김 주의

# 출장열쇠에 연락할 때
- 건물 이름이나 주소, 몇 층 몇 호
- 건물 출입문은 열려 있는지
- 번호식, 카드식, 열쇠식 중 어떤 문인지
- 관리인이나 집주인에게 연락해 봤는지
같은 층에 문이 여러 개 나란히 있는 건물은 호수 표시가 작거나 없는 경우도 있습니다. / 엘리베이터에서 내려 몇 번째 문인지 함께 알려 주시면 헷갈리지 않습니다.

# 도착하면 확인과 금액 안내
문을 열기 전에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 임대차 계약서, 집주인이나 관리인 확인 중 하나면 됩니다. 세입자라면 집주인 허락은 따로 필요 없습니다.
문 상태를 본 뒤 금액을 먼저 말씀드리고, 동의하시면 시작합니다. / 끝내 못 열면 비용은 받지 않으며, 진행 순서는 [이용안내](guide.html), 문 여는 과정은 [현관문 개문](door-open.html)에 있습니다.

# 문이 열린 뒤 혼자 사는 집이라면
문이 열리면 원인을 확인하고 도어락이 다시 잘 잠기는지 봅니다. / 건전지라면 새것으로 바꾸고, 번호를 잊었다면 새 번호를 등록해 드립니다.
혼자 사는 집은 다른 열림 수단 하나를 더 두는 것이 좋습니다. / 번호와 함께 카드를 등록하거나, 믿을 만한 가족에게 번호를 알려 두는 식입니다. 도어락이 낡았다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 집주인과 상의해 보세요.
@ 송내동 원룸 도어락 개방 후 점검

# 송내동에서 동두천 어디든
송내동과 가까운 지행동, 생연동은 물론 보산동, 상패동, 광암동까지 다닙니다. / 동두천 안내는 [동두천 출장열쇠](dongducheon.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 오피스텔 건물 출입문도 열어 주시나요? | 여러 세대가 쓰는 문이라 관리인이나 집주인 확인 없이 열기 어렵습니다. 건물 안에 들어간 뒤 내 방 문은 도와드립니다.
? 집주인에게 연락이 안 되면 그냥 불러도 될까요? | 네, 사정을 문자로 남겨 두고 부르시면 됩니다.
