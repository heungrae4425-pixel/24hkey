# 송내동에서 도어락을 바꿔야 하나 고민될 때
동두천 송내동은 아파트와 빌라, 주택이 섞인 동네로 도어락을 오래 쓴 집이 많습니다. / 번호판 반응이 느려지거나 소리가 이상하면 새로 바꿔야 하나 고민하게 됩니다.
도어락은 한 번 달면 몇 년을 쓰기 때문에 급하게 정하면 후회하는 일이 생깁니다. / 교체 전에 알아 둘 것을 먼저 확인하면 실수가 줄어듭니다.
이 글은 송내동에서 도어락을 교체하기 전에 확인할 것을 정리했습니다. / 비용이 어떻게 정해지고 안내되는지도 [동두천 출장열쇠](dongducheon.html) 방식으로 적었습니다.
@ 송내동 도어락 교체 전 확인 출장열쇠

# 교체가 꼭 필요한 경우와 아닌 경우
번호판이 반응하지 않거나 모터가 헛돌고 배터리를 바꿔도 같은 증상이 계속되면 교체를 고려할 수 있습니다. / 제품이 너무 오래돼서 부품을 구하기 어려운 경우도 있습니다.
반대로 배터리만 바꾸면 되는 문제나 걸쇠 위치만 맞추면 되는 문제인데 교체를 권유받는 일이 있습니다. / 원인을 정확히 확인하는 것이 먼저입니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 먼저 [도어락 수리](doorlock-repair.html)로 해결될지 살펴봅니다.

# 교체 전에 꼭 확인할 문 규격
도어락은 문 두께, 문 안쪽 구멍 크기, 걸쇠 위치가 맞아야 달 수 있습니다. / 이 규격이 안 맞으면 제품을 샀더라도 달 수 없거나 문을 가공해야 합니다.
특히 오래된 문은 구멍 간격이 요즘 제품과 다른 경우가 많습니다. / 기존 도어락 모델명이나 사진을 미리 찍어 두면 도움이 됩니다.
문이 철문인지 나무 문인지, 보조키가 따로 있는지도 확인해야 합니다. / 설치 방식은 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.
@ 송내동 도어락 문 규격 확인

# 어떤 방식의 도어락이 맞을까
번호만 쓰는 제품, 카드나 태그를 쓰는 제품, 지문을 쓰는 제품이 대표적입니다. / 가족 구성에 따라 편한 방식이 다릅니다.
아이나 어르신이 있다면 번호와 카드를 함께 쓰는 제품이 편합니다. / 손이 자주 젖거나 거친 일을 하시는 분은 지문 인식이 불편할 수 있습니다.
화려한 기능보다 안정적으로 오래 쓰는 것이 우선입니다. / 기능이 많을수록 고장 날 부분도 늘어납니다.

# 배터리와 전원 방식
도어락 대부분은 건전지를 쓰고 비상 전원 단자가 있는 제품이 많습니다. / 비상 단자가 있는지 미리 확인하면 배터리가 방전됐을 때 안심입니다.
배터리 교체 알림이 소리와 불빛으로 나오는 제품이 편합니다. / 알림이 약하면 방전된 걸 모르고 지나치게 됩니다.
전기를 직접 쓰는 방식은 집 구조에 맞아야 해서 사전 점검이 필요합니다. / 대부분의 가정은 건전지 방식으로 충분합니다.

# 보안은 숫자보다 습관이 좌우합니다
번호를 생일이나 전화번호로 하면 아무리 좋은 제품도 소용이 없습니다. / 가족끼리만 아는 조합으로 정하고 주기적으로 바꾸세요.
번호판에 손자국이 한곳에 몰려 있으면 번호가 드러날 수 있습니다. / 가끔 번호판을 닦아 주세요.
이중 잠금이 가능한 제품이나 보조키를 같이 쓰면 더 안전합니다. / 필요에 맞게 말씀해 주시면 같이 안내해 드립니다.

# 비용은 이렇게 안내해 드립니다
제품과 문 상태, 설치 방식에 따라 달라져서 전화로 정확한 금액을 말씀드리기 어려운 경우가 있습니다. / 먼저 문 사진과 기존 도어락 사진을 보내 주시면 대략적인 범위를 안내해 드립니다.
방문해서 문 규격과 상태를 직접 확인한 뒤 제품과 설치 비용을 함께 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
설치가 끝난 뒤에 말 없이 붙는 비용은 없습니다. / 부품을 더 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.

# 전화로 이렇게 알려 주세요
송내동은 아파트와 주택이 섞여 있어 건물 종류를 말씀해 주시면 좋습니다. / 몇 동 몇 호인지, 건물 이름 대신 근처에서 알아볼 수 있는 곳을 말씀해 주세요.
- 건물 종류와 대략 어느 쪽인지
- 기존 도어락 모양과 증상
- 새로 원하는 방식(번호, 카드, 지문 등)
- 보조키가 따로 있는지
문과 도어락 사진을 같이 보내 주시면 챙겨 갈 제품과 장비를 정하는 데 도움이 됩니다.

# 방문하면 먼저 사시는 분인지 확인합니다
교체나 설치는 문을 다루는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집 주인을 모두 지키기 위한 절차입니다. / 확인이 어려우면 작업할 수 없으니 미리 준비해 두세요.
세입자라면 집주인에게 교체해도 되는지 먼저 확인하시는 것이 좋습니다. / 원상복구 조건이 있을 수 있기 때문입니다.
@ 송내동 24시 출장열쇠 도어락 교체 설치

# 교체 작업은 이런 순서로 진행합니다
기존 도어락을 분리하고 문 구멍 크기와 걸쇠 위치를 확인합니다. / 새 제품을 문에 맞춰 달고 작동을 몇 번 점검합니다.
번호 등록과 카드 등록을 마친 뒤 비상 열쇠나 카드를 사용하는 방법도 알려 드립니다. / 사용 방법을 같이 확인하면 나중에 헷갈리지 않습니다.
교체가 끝난 뒤 문이 부드럽게 닫히고 걸쇠가 제대로 들어가는지 마지막으로 확인합니다. / 교체 방식은 [도어락 교체](doorlock-replace.html)에 정리해 두었습니다.

# 문이 안 열리는 상황이라면 먼저 열어야 합니다
도어락이 고장 나서 문이 아예 안 열리는 상태에서 교체를 알아보는 경우도 있습니다. / 이때는 먼저 문을 열고 난 뒤 교체나 수리를 상의합니다.
문을 상하지 않게 여는 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다. / 못 열면 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html)에서도 보실 수 있습니다.

# 교체한 뒤에 오래 쓰는 방법
- 배터리는 해가 바뀔 때쯤 한꺼번에 새것으로 교체하기
- 경고음이 나면 그날 바로 확인하기
- 비밀번호는 가끔 바꾸고 가족과 함께 정하기
- 문이 덜 닫히면 경첩과 걸쇠를 함께 점검하기
- 카드나 보조키는 따로 한 곳에 보관하기
이런 습관이 있으면 새 도어락을 오래 편하게 쓸 수 있습니다.

# 송내동 말고 동두천 어디든 갑니다
생연동, 지행동, 보산동, 상패동, 광암동까지 동두천 전 지역을 다닙니다. / 시내와 가까워서 위치를 받으면 도착 시간을 바로 말씀드립니다.
동두천에서 다니는 지역은 [동두천시 출장열쇠](dongducheon.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
