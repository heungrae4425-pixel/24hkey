# 북면 문 앞에서 번호가 안 맞을 때
늘 누르던 번호인데 틀렸다는 소리가 나면 머릿속이 하얘집니다. / 내가 잘못 누른 건지, 누가 번호를 바꾼 건지부터 헷갈립니다.
가평 북면처럼 주택과 주말에 쓰는 집이 있는 곳은 가족 여러 명이 번갈아 드나드는 경우가 많습니다. / 지난번에 다녀간 가족이 번호를 바꿔 놓고 말하는 걸 잊는 일이 생각보다 흔합니다.
이 글은 북면에서 도어락 번호를 잊었거나 가족이 바꾼 번호를 모를 때 차분히 풀어 가는 순서를 정리했습니다. / 연락이 안 닿고 급하다면 [가평 출장열쇠](gapyeong.html)로 전화 주세요.
@ 북면 도어락 비밀번호 분실 가족 변경

# 먼저 세 번만 누르고 멈추세요
번호가 틀렸다는 소리가 나면 대부분 다시, 또다시 누르게 됩니다. / 그런데 도어락은 몇 번 연달아 틀리면 잠시 입력을 막아 버립니다.
막힌 상태에서 계속 누르면 막히는 시간이 늘어나는 제품도 있습니다. / 세 번쯤 해 보고 안 되면 손을 떼고 다른 방법을 찾는 게 오히려 빠릅니다.
누를 때는 손가락을 천천히 하나씩 떼며 눌러 보세요. / 급하게 누르면 버튼 하나가 덜 눌리거나 두 번 눌려 틀리는 일이 많습니다.

# 내가 헷갈린 건지 먼저 확인
예전 번호와 지금 번호가 섞여 기억나는 경우가 있습니다. / 마지막에 별표나 샵 같은 확인 버튼을 눌러야 하는 제품인지, 번호만 누르면 되는 제품인지도 떠올려 보세요.
가족 생일, 예전 집 번호, 휴대폰 끝자리처럼 평소 쓰는 숫자 조합을 한두 개만 골라 시도해 보세요. / 아무 번호나 이어서 누르는 건 입력 제한만 늘립니다.
휴대폰 메모나 가족 대화방에 예전에 남겨 둔 번호가 있는지도 찾아보세요. / 사진첩에 도어락 설명서를 찍어 둔 적이 있다면 그것도 단서가 됩니다.

# 가족에게 연락하는 순서
마지막으로 다녀간 사람이 누구인지부터 떠올려 보세요. / 그 사람이 번호를 바꿨을 가능성이 가장 큽니다.
연락이 닿으면 번호를 소리 내어 불러 달라고 하기보다 문자로 받는 편이 정확합니다. / 비슷한 숫자를 잘못 듣는 일이 생각보다 많습니다.
가족 누구와도 연락이 안 된다면 그때 출장을 부르시면 됩니다. / 늦은 밤 부모님이나 형제에게 연락하기 어려운 사정도 있으니 무리하지 않으셔도 됩니다.
@ 가평 북면 가족 연락 도어락 번호 확인

# 번호판이 꺼져 있다면 번호 문제가 아닐 수도
번호가 틀렸다는 게 아니라 아예 아무 반응이 없다면 배터리 방전일 가능성이 큽니다. / 오래 비워 둔 집이라면 더 그렇습니다.
이때는 9V 건전지를 바깥 비상 단자에 대고 번호를 눌러 보세요. / 전원이 들어온 뒤에도 틀렸다는 소리가 나면 그때 번호 문제를 생각하면 됩니다.

# 비상 열쇠, 지문, 카드 중 남은 길
도어락 중에는 바깥쪽에 비상 열쇠 구멍이 숨어 있는 제품이 있습니다. / 번호판 아래나 덮개 안쪽에 작은 구멍이 있는지 살펴보세요.
비상 열쇠를 가족 누군가 갖고 있다면 그것으로 열 수 있습니다. / 처음 도어락을 달 때 받은 작은 열쇠가 서랍이나 차 안에 있지 않은지 떠올려 보세요.
@ 북면 도어락 비상 열쇠 구멍 위치
지문이나 카드를 같이 쓰는 제품이라면 번호 대신 그쪽으로 열어 보세요. / 번호만 바뀌고 지문과 카드 등록은 그대로인 경우가 많습니다.
카드가 집 안에 있다면 아쉽지만 다른 방법을 써야 합니다. / 지문은 손을 닦고 천천히 대 보세요.
차 열쇠고리에 도어락 태그를 같이 달아 두는 집도 있습니다. / 주말 집처럼 오가는 곳이라면 이 방법이 번호 분실에 대비하는 가장 쉬운 길이 됩니다.
번호를 바꾼 가족이 지문이나 카드 등록까지 지웠을 수도 있습니다. / 모두 안 된다면 등록 정보가 통째로 초기화된 경우일 수 있으니 무리하지 말고 연락 주세요.

# 문을 연 뒤 번호를 정리하는 방법
문이 열리면 안쪽에서 새 번호를 등록하고 예전 번호를 지웁니다. / 제품마다 등록 버튼 위치가 달라 어렵다면 출장 때 같이 해 드립니다.
새 번호를 정할 때는 집을 쓰는 가족 모두가 기억하기 쉬우면서 남이 짐작하기 어려운 조합으로 하세요. / 생일이나 같은 숫자 반복은 피하는 게 좋습니다.
번호를 바꾼 사람은 그날 바로 다른 가족에게 알리는 규칙을 정해 두세요. / 이 규칙 하나로 같은 일이 크게 줄어듭니다.

# 가족이 여럿 쓰는 집이라면
주말 집이나 부모님 집처럼 여러 가족이 드나드는 집은 번호 관리를 한 사람이 맡는 게 편합니다. / 번호를 바꿀 사정이 생기면 그 사람에게 알리고, 그 사람이 모두에게 전하는 식입니다.
임시 번호 기능이 있는 제품이라면 손님이나 일을 도와주는 분께는 임시 번호를 쓰세요. / 기본 번호를 바꾸지 않아도 돼 가족이 헷갈리지 않습니다.
@ 북면 주말 주택 도어락 번호 관리

# 하지 말아야 할 일
- 번호판 덮개를 뜯어 배선을 만지는 것
- 드라이버로 문틈을 벌려 걸쇠를 밀어 보는 것
- 입력 제한이 걸린 상태에서 계속 누르는 것
도어락을 뜯으면 다시 맞추기가 어렵고 고장으로 이어집니다. / 결국 교체까지 가는 일이 생기니 그대로 두고 연락 주세요.
번호를 바꾼 가족을 탓하기보다, 다음부터 어떻게 알릴지 정하는 쪽이 마음도 덜 상합니다. / 문 앞에서 기다리는 시간도 그만큼 짧아집니다.

# 북면에서 전화하실 때
북면은 가평 안에서도 거리가 있는 곳이 많습니다. / 위치를 받으면 도착 시간을 먼저 말씀드립니다.
- 도로명 주소나 가까운 큰길, 눈에 띄는 표지
- 번호가 틀렸다고 나오는지, 아예 반응이 없는지
- 비상 열쇠, 지문, 카드 중 쓸 수 있는 게 있는지
- 집 안에 사람이나 반려동물이 있는지
도어락 앞면 사진을 보내주시면 맞는 장비를 미리 챙길 수 있습니다.

# 사시는 분인지 확인합니다
번호를 몰라 여는 경우일수록 사시는 분인지 꼭 확인합니다. / 신분증 주소, 주소가 적힌 고지서, 집주인이나 가족 통화 확인 중 하나면 됩니다.
부모님 집이나 가족 소유의 주말 집이라면 소유하신 분과 통화로 확인할 수 있습니다. / 확인이 어려우면 열지 않는다는 점은 미리 양해 부탁드립니다.

# 비용은 열기 전에
도어락 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 동의하실 때 시작하고, 끝내 못 열면 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다. / 등록 기능이 고장 나 번호가 안 바뀐다면 [도어락 수리](doorlock-repair.html)를, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 함께 봐 드립니다.

# 북면 말고 가평 어디든 갑니다
가평읍, 청평면, 설악면, 상면, 조종면도 다닙니다. / 다니는 곳은 [가평군 출장열쇠](gapyeong.html), 그 밖의 지역은 [출장 지역](area.html)에 있습니다.

# 자주 묻는 질문
? 번호를 몇 번 틀렸더니 아예 안 눌려요. | 입력 제한이 걸린 상태입니다. 몇 분 기다렸다가 천천히 다시 해 보시고, 계속 누르지는 마세요.
? 동생이 번호를 바꿨는데 연락이 안 돼요. | 다른 가족에게 먼저 물어보시고, 아무도 모르면 연락 주세요. 확인 후 열고 새 번호를 등록해 드립니다.
? 비상 열쇠 구멍은 어디에 있나요? | 번호판 아래나 덮개 안쪽에 숨어 있는 제품이 많습니다. 없는 제품도 있습니다.
? 새 번호 등록도 같이 해 주시나요? | 네, 문을 연 뒤 새 번호 등록과 예전 번호 삭제까지 함께 해 드립니다.
? 못 열면 비용을 내나요? | 내지 않습니다. 열지 못하면 받지 않습니다.
