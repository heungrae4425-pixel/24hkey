# 가평 설악면, 대문이 먼저 막히는 집
설악면은 아파트 단지보다 단독주택과 전원주택, 펜션이 많이 보이는 지역입니다. / 이런 집은 현관문 앞에 대문이나 철문이 한 번 더 있는 경우가 많습니다.
도어락은 멀쩡한데 대문 열쇠가 안 돌아가서 집에 못 들어가는 일이 생깁니다. / 마당이 있는 집일수록 집 안과 밖 사이 문이 두세 개라 어디가 막혔는지부터 가려야 합니다.
이 글은 설악면에서 대문이나 철문이 안 열릴 때 먼저 확인할 것을 정리했습니다. / 그다음 [가평 출장열쇠](gapyeong.html)를 부르면 어떻게 진행되는지 적었습니다.
@ 가평 설악면 대문 철문 열쇠 출장열쇠

# 대문 열쇠가 안 돌아가는 흔한 원인
철문과 대문은 비바람을 그대로 맞는 문입니다. / 열쇠 구멍 안쪽에 녹이나 먼지가 쌓이면 열쇠가 뻑뻑해지다가 끝내 안 돌아갑니다.
- 열쇠 구멍 안쪽에 녹이나 먼지가 쌓인 경우
- 겨울에 구멍 안쪽이 얼어붙은 경우
- 열쇠가 닳아서 홈이 맞지 않는 경우
- 문이 처져서 빗장이나 걸쇠에 힘이 걸린 경우
어느 쪽인지에 따라 직접 해볼 수 있는 일이 달라집니다. / 억지로 돌리다가 열쇠가 부러지는 일이 가장 흔한 사고입니다.

# 열쇠를 돌리기 전에 해 볼 것
문이 처져서 걸리는 경우는 문을 살짝 들어 올리듯이 밀면서 돌리면 열리기도 합니다. / 문짝을 약간 안쪽으로 밀어 걸쇠의 힘을 풀어 주는 방식입니다.
열쇠를 꽂았을 때 뻑뻑하면 한 번 뺐다가 다시 꽂아 보세요. / 같은 각도로 계속 힘을 주기보다 위아래로 조금씩 움직이며 돌려 봅니다.
그래도 안 되면 힘으로 돌리지 말고 멈추세요. / 열쇠가 구멍 안에서 부러지면 열기가 훨씬 어려워집니다.
윤활제는 기름이 아닌 건조형 열쇠구멍용을 쓰는 편이 안전합니다. / 기름이 먼지와 엉겨 오히려 구멍을 막는 경우가 있습니다.

# 겨울에 열쇠 구멍이 얼었다면
가평은 겨울 아침에 바깥 기온이 많이 내려갑니다. / 눈이나 서리가 열쇠 구멍에 들어가 얼어붙으면 열쇠가 들어가지 않거나 돌아가지 않습니다.
뜨거운 물을 부으면 순간은 풀리지만 다시 얼어 상황이 더 나빠질 수 있습니다. / 열쇠를 라이터 등으로 가열해 꽂는 방법은 열쇠가 휘거나 구멍이 상할 수 있어 권하지 않습니다.
얼었다고 판단되면 따뜻한 곳에서 열쇠를 데운 뒤 가볍게 시도해 보세요. / 안 되면 전화 주시는 편이 문이 덜 상합니다.
@ 설악면 철문 열쇠 구멍 점검

# 대문과 현관 도어락이 따로일 때
마당을 지나 현관까지 들어가는 구조라면 막힌 곳이 대문인지 현관인지 먼저 구분해야 합니다. / 대문이 열렸는데 현관 도어락이 안 되는 경우도 있고, 그 반대도 있습니다.
- 대문 열쇠가 따로 있는지, 도어락과 같은 열쇠인지
- 대문에 번호키나 자동 개폐 장치가 달려 있는지
- 현관 도어락 배터리 상태는 어떤지
- 집 안에 사람이 있으면 인터폰이나 전화로 열 수 있는지
이 네 가지를 알려주시면 챙겨 갈 장비가 정확해집니다.

# 펜션이나 세컨드하우스라면
설악면에는 주말에만 쓰는 집이나 펜션도 있습니다. / 몇 주 비워 둔 집은 도어락 배터리가 나가 있는 경우가 많습니다.
도착했는데 대문 열쇠를 안 가져왔거나 위치를 잊었다면 먼저 집 주변에 숨겨 둔 비상 열쇠가 있는지 확인하세요. / 가족이나 관리를 맡은 분께 열쇠 위치를 물어보는 것도 방법입니다.
펜션 손님이 못 들어가는 상황이라면 주인께서 직접 연락 주시면 됩니다. / 손님이 나가고 난 뒤 번호를 바꿔 두는 습관은 [도어락 수리](doorlock-repair.html)보다 미리 할 수 있는 관리입니다.

# 철문이 처졌을 때
오래된 철문은 경첩이 닳아 문짝이 아래로 처집니다. / 문이 처지면 걸쇠가 문틀에 걸려 열쇠가 돌아가도 문이 안 열립니다.
이럴 때는 열쇠 문제로 보이지만 실은 문 정렬 문제입니다. / 열쇠 구멍만 손봐서는 해결되지 않고, 경첩이나 문틀을 같이 봐야 합니다.
문이 처졌는지 보려면 닫았을 때 위쪽 틈과 아래쪽 틈이 같은지 보세요. / 한쪽만 좁다면 처진 것입니다.

# 무리하게 열다가 커지는 일
급한 마음에 철물이나 쇠막대로 대문을 비틀어 여는 분이 있습니다. / 그러면 문과 문틀이 휘고 잠금 부품이 상해 수리비가 더 듭니다.
열쇠가 구멍에서 부러졌는데 젓가락이나 핀으로 빼려다 구멍이 막히는 일도 있습니다. / 부러진 조각은 전용 도구로 빼야 열쇠 구멍이 상하지 않습니다.
무리하게 열지 말고 그대로 두고 연락 주세요. / 전화로 상황을 알려주시면 방법을 먼저 안내해 드립니다.

# 전화하실 때 알려주실 것
설악면은 거리가 있는 곳이 많아 위치를 정확히 알려주셔야 도착 시간을 말씀드릴 수 있습니다.
- 설악면 안에서 대략 어느 방향인지, 가까운 큰길이나 가평역 방향인지
- 대문이 막힌 것인지 현관이 막힌 것인지
- 문 재질 (철, 알루미늄, 나무)과 잠금 방식
- 열쇠를 꽂았을 때 들어가는지, 안 돌아가는지
- 집 안에 사람이나 반려동물이 있는지
사진을 문자로 보내주시면 훨씬 빨리 준비할 수 있습니다.
@ 가평 설악면 24시 출장열쇠 현장

문을 여는 일이라 사시는 분이나 관리하시는 분이 맞는지 먼저 확인합니다. / 신분증 주소나 우편물, 관리 계약 문서 중 하나면 됩니다.
펜션이나 세컨드하우스라면 소유 확인이 되는 자료를 알려주세요. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 문을 열기 전에 말씀드립니다
상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 난 뒤에 할 일
열쇠가 안 돌아간 원인을 같이 봅니다. / 열쇠가 닳았다면 복사나 교체를, 구멍이 상했다면 부품 교체를 말씀드립니다.
대문 잠금은 [출장 열쇠](key-call.html) 쪽에서 열쇠 복사와 교체까지 같이 처리합니다. / 현관 도어락이 같이 오래됐다면 [도어락 교체](doorlock-replace.html)도 상담해 드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 오래 쓰는 관리법
- 열쇠 구멍에 건조형 윤활제를 계절 바뀔 때 한 번
- 겨울이 오기 전에 구멍 안의 먼지 털기
- 열쇠를 복사해 한 개는 따로 보관
- 문이 처졌다면 경첩 점검을 일찍
- 대문 번호키가 있으면 배터리도 같이 교체
작은 습관으로 문 앞에서 막히는 일이 크게 줄어듭니다.

# 설악면 말고 가평 어디든 갑니다
가평읍, 청평면, 상면, 조종면, 북면도 다닙니다. / 거리가 먼 곳이 많아 위치를 받으면 도착 시간을 먼저 말씀드립니다.
가평에서 다니는 곳은 [가평군 출장열쇠](gapyeong.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
현관문 개문 방법은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.

? 열쇠가 부러져 구멍에 박혔어요. | 억지로 빼려 하지 마세요. 전용 도구로 조각을 빼고 열쇠를 새로 맞춰 드립니다.

? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
