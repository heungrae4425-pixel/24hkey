# 고촌읍 주택, 도어락은 열렸다는데 문이 꿈쩍 않을 때
고촌읍은 김포 안에서도 오래 살아온 단독주택이 모인 주택가가 이어진 읍 지역입니다. / 이런 집에서 문이 안 열린다는 연락을 받고 가 보면, 도어락은 멀쩡한데 철문과 문틀이 원인인 경우가 꽤 많습니다.
철문은 무게가 있어 세월이 지나면 조금씩 아래로 처지고, 문틀은 집이 오래되면서 미세하게 틀어집니다. / 이 작은 변화가 쌓이면 어느 날 열림 소리는 나는데 문이 문틀에 꽉 물려 움직이지 않게 됩니다.
이 글은 문과 문틀에 남은 긁힌 자국과 틈 모양으로 원인을 찾는 방법, 문 앞에서 해 볼 응급 요령, 손봐야 할 곳을 정리했습니다. / 지금 문이 안 열린다면 '문 앞에서 해 볼 것'부터 보세요.
@ 고촌읍 오래된 주택 현관 철문 문틀 걸림

# 긁힌 자국이 원인을 알려 줍니다
문이 열려 있을 때 문틀 안쪽과 문 가장자리를 손전등으로 비춰 보세요. / 페인트가 벗겨지거나 반짝이게 닳은 곳이 문과 문틀이 서로 부딪히는 자리입니다.
- 문틀 위쪽 경첩 반대편이 닳았다면 문이 기울어진 것
- 문 아래쪽 모서리와 문턱이 긁혔다면 문이 처진 것
- 걸쇠 받침판 아래쪽만 닳았다면 걸쇠 높이가 내려간 것
- 문틀 경첩 쪽이 닳았다면 경첩이 헐거워진 것
자국이 한 곳에만 있으면 손볼 곳도 한 곳인 경우가 많습니다. 사진으로 찍어 두면 설명하기도 쉽습니다. / 여러 곳에 자국이 있다면 문 전체가 틀어진 것이라 조정할 곳이 늘어납니다.

# 닫힌 문의 틈 모양도 살펴보세요
문을 닫은 상태에서 문과 문틀 사이 틈을 위에서 아래로 훑어보세요. / 틈이 위아래로 고르게 같다면 문 모양은 괜찮은 편입니다.
위쪽 틈은 넓은데 아래쪽 틈이 거의 없다면 문이 경첩 반대편으로 처진 것입니다. / 반대로 아래가 넓고 위가 좁다면 위쪽 경첩이 문을 당기지 못하고 있는 것입니다.
틈 사이로 바깥 빛이 한쪽에서만 새어 들어온다면 패킹이 떨어졌거나 문이 비틀린 신호입니다. / 겨울에 그 틈으로 찬바람이 들어온다면 점검을 더 미루지 않는 편이 좋습니다.
@ 고촌읍 현관문 틈 모양 처짐 확인

# 철문 아래쪽 녹도 원인이 됩니다
오래된 주택 철문은 아래쪽 모서리부터 녹이 슬기 쉽습니다. / 비와 눈이 문턱에 고이면서 그 부분이 부풀어 오르면 문턱과 닿아 문이 끌리게 됩니다.
녹이 부풀어 문턱을 긁고 있다면 문을 열고 닫을 때마다 힘이 더 듭니다. / 이 상태가 오래 이어지면 경첩에도 무리가 가서 처짐이 더 빨라집니다.
문턱 쪽에 물이 고이지 않게 비 온 뒤 한 번씩 닦아 주는 것만으로도 녹이 번지는 속도를 늦출 수 있습니다. / 이미 녹이 부풀었다면 그 부분을 정리하고 녹 방지 칠을 해 두는 방법도 있습니다.

# 문 앞에서 해 볼 것
도어락 열림 소리는 났는데 문이 안 열린다면 아래를 차례로 해 보세요.
- 문을 몸 쪽으로 살짝 당긴 채 손잡이를 돌리거나 밀기
- 문 위쪽을 손바닥으로 지그시 밀면서 다시 열기
- 문 아래쪽을 발끝으로 가볍게 받치듯 들며 열기
걸쇠를 누르던 힘이 잠깐 풀리면 쉽게 열리는 경우가 많습니다. / 어떤 동작에서 열렸는지 기억해 두시면 나중에 손볼 곳을 바로 찾을 수 있습니다.
두세 번 해 보고 안 되면 그만 멈추세요. / 세게 밀어붙일수록 걸쇠가 더 꽉 물려 버립니다.

# 이런 시도는 피해 주세요
문을 어깨로 밀거나 발로 차면 철문은 버텨도 문틀과 경첩이 상합니다. / 문틈에 지렛대처럼 도구를 넣어 벌리는 것도 문틀을 휘게 해 나중에 문이 아예 맞지 않게 됩니다.
녹슨 경첩에 아무 기름이나 붓는 것도 권하지 않습니다. / 먼지와 섞여 끈적해지면 오히려 문이 더 무거워집니다. / 경첩에 쓸 때는 건조형 윤활제를 아주 조금만 쓰는 것이 맞습니다.

# 경첩만 손봐도 되는 경우
긁힌 자국이 경첩 쪽에 있고 틈이 위아래로 다르다면 경첩 나사부터 확인합니다. / 나사가 헐거워진 정도라면 조이는 것만으로 문 높이가 돌아옵니다.
나사 구멍이 닳아 헛돌고 있다면 구멍을 메우고 다시 고정하거나 조금 굵은 나사로 바꿉니다. / 경첩 자체가 닳아 흔들린다면 경첩을 바꾸는 쪽이 낫습니다. / 철문은 무거워서 경첩을 바꿀 때 문을 받쳐 줄 사람이 필요하니 혼자 하지 마세요.
경첩을 손본 뒤에는 문을 여러 번 여닫으며 틈이 고르게 돌아왔는지 다시 확인합니다.

# 받침판을 옮겨야 하는 경우
문이 처진 상태로 굳어 버렸다면 문을 원래대로 들어 올리기 어렵습니다. / 이럴 때는 걸쇠가 들어가는 문틀 받침판 위치를 문에 맞춰 옮기는 방법을 씁니다.
받침판을 옮기면 잠김이 다시 부드러워지고 도어락 모터에 걸리는 힘도 줄어듭니다. / 손잡이형 오래된 도어락이라면 걸쇠 길이도 함께 확인합니다. 옮긴 뒤에는 바깥과 안쪽에서 몇 번씩 잠가 보며 마무리합니다.
@ 고촌읍 문틀 받침판 위치 조정 작업

# 도어락까지 상했다면
문이 오래 걸린 채로 쓰이면 도어락 모터와 걸쇠도 같이 지칩니다. / 모터 소리가 길어지거나 걸쇠가 반쯤만 나온다면 도어락도 함께 봐야 합니다.
고칠 수 있는 부분은 [도어락 수리](doorlock-repair.html)로 손보고, 부품을 구하기 어려울 만큼 오래된 제품이라면 [도어락 교체](doorlock-replace.html)를 따로 여쭤봅니다. / 새 제품을 달 때는 문 두께와 예전 구멍 위치를 [도어락 설치](doorlock-install.html) 기준으로 확인합니다.

# 출장을 부르실 때
문이 열려 있다면 문틀 긁힌 자리와 닫힌 문의 틈 사진을 보내 주세요. / 문이 안 열린다면 바깥에서 문 전체가 보이는 사진 한 장이면 됩니다.
고촌읍 주택은 골목 안쪽에 있는 집이 많아 큰길에서 들어오는 길을 함께 알려 주시면 좋습니다. / 대문이 따로 있다면 대문은 열리는지도 말씀해 주세요. / 차를 세울 곳이 마땅치 않은 골목이라면 가까운 공터나 큰길 쪽 위치를 알려 주셔도 됩니다.

# 거주 확인과 작업 전 금액 안내
문을 여는 경우에는 사시는 분인지 신분증, 주소가 나온 우편물, 집주인 통화 중 하나로 확인합니다. / 연 다음 원인을 보여 드리고 조정할지, 부품을 바꿀지 말씀드립니다.
비용은 작업 전에 먼저 말씀드리고 동의하실 때만 진행합니다. / 문을 끝내 못 열면 비용은 받지 않습니다. 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 있습니다.

# 고촌읍에서 통진, 양촌까지 김포 전역
사우동, 풍무동, 걸포동, 장기동, 운양동, 구래동, 마산동은 물론 통진읍, 양촌읍까지 김포 전 지역을 다닙니다. / 김포 출장 동네는 [김포시 출장열쇠](gimpo.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 오래된 철문, 자주 묻는 질문
? 문턱이 긁히는데 문을 깎아야 하나요? | 대부분 경첩 조정이나 받침판 이동으로 해결됩니다. 문을 깎는 일은 드뭅니다.
? 도어락은 풀렸다고 하는데 철문이 안 밀려요. | 문이 처져 걸쇠가 문틀에 눌린 경우가 많습니다. 문을 살짝 당기거나 위를 밀면서 다시 열어 보세요.
? 철문 아래 녹은 어떻게 하나요? | 녹이 부풀어 문턱을 긁는다면 그 부분을 정리하고, 문 높이를 함께 맞춥니다.
? 겨울에만 더 뻑뻑해요. | 추위에 문과 문틀이 조금씩 움직여서 그렇습니다. 해마다 반복되면 받침판 조정을 권합니다.
? 오래된 문이라 못 열면 비용을 따로 받나요? | 아닙니다. 열지 못하면 비용은 받지 않습니다.

# 마무리
