# 이사 오자마자 가장 먼저 할 일은 도어락입니다
이삿짐을 풀기 전에 현관 도어락부터 점검하는 것이 마산동 이사 날의 첫 순서입니다. / 이전 입주자가 쓰던 번호나 카드가 그대로 남아 있을 수 있기 때문입니다.
등록돼 있던 번호, 카드, 지문을 그대로 두고 지내면 방범상 불안합니다. / 이 글은 이사 후 도어락을 새로 쓰기 위한 순서를 차례대로 적었습니다.
막혔을 때 [김포 출장열쇠](gimpo.html)에 연락해야 하는 기준도 마지막에 함께 정리했습니다. / 하나씩 따라 하면 대부분 직접 처리할 수 있습니다.
@ 마산동 이사 도어락 비밀번호 초기화

# 전 입주자 정보는 반드시 지웁니다
도어락에는 이전에 등록된 비밀번호와 카드가 남아 있을 수 있습니다. / 이사 업체 직원, 집주인, 부동산에서 번호를 알고 있을 수도 있으니 모두 정리하세요.
방법은 크게 두 가지입니다. / 하나는 등록된 번호만 지우는 방법, 다른 하나는 도어락 전체를 초기 상태로 되돌리는 방법입니다.
초기 상태로 되돌리면 기존 카드와 지문도 함께 지워지는 제품이 많습니다. / 다시 등록하는 데 시간이 걸리니 처음부터 전체 초기화를 권합니다.

# 초기화 버튼은 보통 안쪽 배터리 칸 근처에 있습니다
도어락 안쪽 덮개를 열면 작은 버튼이나 구멍이 있는 모델이 많습니다. / 이 버튼을 누른 채 전원을 넣거나 일정 시간 눌러 초기화하는 방식이 흔합니다.
제품마다 방법이 달라서 설명서가 없으면 정확한 순서를 알기 어렵습니다. / 모델명이 보이면 사진을 찍어 두면 문의할 때 도움이 됩니다.
같은 순서를 흉내만 내서 눌렀다가 오히려 잠금 상태가 되기도 합니다. / 무리해서 여러 번 시도하지 말고 안 되면 멈추는 것이 좋습니다.

# 새 비밀번호는 이렇게 정합니다
생일이나 전화번호 끝자리처럼 쉽게 짐작되는 번호는 피해 주세요. / 이전 집 번호를 그대로 쓰는 것도 권하지 않습니다.
가족이 외우기 쉬우면서 남이 짐작하기 어려운 조합이 가장 좋습니다. / 정한 번호는 가족에게 직접 알려 주고 문자나 메신저에 남기지 마세요.
번호 길이는 제품이 허용하는 범위에서 조금 길게 정하는 것이 안전합니다. / 번호를 등록한 뒤에는 안쪽과 바깥쪽에서 각각 한 번씩 열어 보며 확인합니다.
@ 마산동 새 비밀번호 등록 도어락

# 카드와 지문도 새로 등록합니다
초기화 후에는 가족 카드와 지문을 새로 등록해야 합니다. / 카드는 두세 장 등록해 하나는 비상용으로 따로 보관하세요.
아이 카드는 분실 위험이 크니 가방에 단단히 달아 주는 방법을 같이 알려 주세요. / 잃어버렸다면 바로 삭제할 수 있도록 방법을 알아 둡니다.
지문 등록은 손가락을 여러 각도로 인식시켜야 잘 열립니다. / 건조한 겨울에도 쓰려면 같은 손가락을 두 번 등록하는 방법도 있습니다.

# 이사 날 흔히 겪는 문제 세 가지
첫째, 이전 입주자 번호를 모른 채 문이 안 열리는 경우입니다. / 이때는 집주인이나 부동산에 먼저 연락해 보고, 연락이 안 되면 출장열쇠를 부르시면 됩니다.
둘째, 배터리가 방전돼 번호판이 꺼진 경우로 빈집이 오래 비어 있던 곳에서 자주 생깁니다. / 9V 건전지를 바깥 단자에 대 보고 안 되면 연락 주세요.
셋째, 새로 단 도어락과 문틀이 맞지 않아 걸쇠가 걸리는 경우입니다. / 문을 세게 닫아야 잠긴다면 문틀과 경첩을 점검해야 합니다.

# 이삿짐 정리 전에 이것만은 점검하세요
도어락 초기화가 끝나면 현관 주변의 다른 잠금장치도 같이 확인합니다. / 보조키, 문 안쪽 걸쇠, 우편함과 공동현관 열쇠가 모두 제대로 있는지 봅니다.
이전 입주자가 쓰던 열쇠가 남아 있다면 새로 받은 열쇠와 구분해 정리해 주세요. / 열쇠가 여러 개 돌고 있는 집이라면 열쇠 구멍 자체를 교체하는 방법도 있습니다.
문을 열고 닫을 때 걸쇠가 뻑뻑하게 걸리지 않는지도 한 번씩 확인합니다. / 이삿짐을 옮기느라 문을 활짝 열어 둔 날은 경첩과 문틀에 무리가 가기 쉽습니다.
문제가 보이면 짐이 풀리기 전에 연락 주시는 편이 일정 맞추기에 좋습니다. / 신도시 아파트든 오래된 주택가든 같은 방식으로 점검해 드립니다.
@ 마산동 이사 현관문 점검 출장열쇠

# 마산동 신분 확인은 이렇게 합니다
이사 직후에는 아직 주소가 옮겨지지 않았을 수 있습니다. / 이때는 임대차 계약서나 입주 확인이 가능한 서류도 같이 보여 주시면 됩니다.
문을 여는 일이라 사시는 분인지 먼저 확인하는 절차는 꼭 거칩니다. / 확인이 안 되면 안타깝지만 작업을 할 수 없습니다.
이삿짐 업체가 함께 있다면 번거롭게 기다리지 않도록 일정을 먼저 말씀해 주세요. / 도착 시간도 위치를 받고 먼저 안내해 드립니다.

# 비용은 열기 전에 먼저 말씀드립니다
도어락 상태와 필요한 작업을 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 이사 때 도어락을 아예 바꾸는 것도 방법입니다
이전 입주자가 오래 쓴 도어락은 배터리가 약하거나 내부가 낡았을 수 있습니다. / 이사 비용에 비해 교체 부담이 크지 않다면 새 제품이 마음 편합니다.
먼저 [도어락 수리](doorlock-repair.html)로 고칠 수 있는지 보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 권해 드립니다. / 무조건 교체를 권하지는 않습니다.
처음 설치하는 새 제품이라면 [도어락 설치](doorlock-install.html) 안내도 참고하세요. / 입주 시기에 맞춰 일정을 잡아 두면 이사 당일 번거로움이 줄어듭니다.

# 마산동 말고 김포 어디든 갑니다
마산동 가까이는 장기동, 구래동, 운양동도 다닙니다. / 김포 안이면 동네 상관없이 24시간 출동합니다.
통진, 양촌처럼 거리가 있는 곳은 위치를 받고 도착 시간을 먼저 말씀드립니다. / 김포 지역 전체는 [김포시 출장열쇠](gimpo.html) 페이지에서 보실 수 있습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요. / 어디서든 먼저 전화 주시면 출동 가능 여부를 말씀드립니다.

# 자주 묻는 질문
? 이사 와서 전 입주자 번호를 모르는데 문을 열 수 있나요? | 네, 사시는 분인지 확인한 뒤 열어 드립니다. 신분증이나 계약서를 준비해 주세요.
? 도어락을 초기화하면 카드도 다 지워지나요? | 제품마다 다르지만 전체 초기화는 카드와 지문도 함께 지워지는 경우가 많습니다.
? 이사 당일 아침 일찍도 오시나요? | 24시간 받으니 이른 시간에도 연락 주세요. 위치를 받고 도착 시간을 말씀드립니다.
? 번호만 새로 등록해 주실 수도 있나요? | 네, 도어락 상태를 보고 필요한 만큼만 작업합니다.
? 못 열면 비용을 받나요? | 문을 열러 간 경우 못 열면 비용은 받지 않습니다.

# 이사 직후 번호와 열쇠를 정리하는 순서
이사한 날에는 짐 정리에 정신이 없어 도어락 번호 변경을 미루기 쉽습니다. / 하지만 이전 입주자가 알던 번호가 그대로 남아 있을 수 있어 첫날 바로 바꾸는 것이 좋습니다.
새 번호를 정한 뒤에는 가족 모두가 직접 눌러 열어 보고, 남아 있던 카드나 열쇠가 있다면 모두 회수하거나 삭제합니다. / 이 과정에서 막히는 부분이 있으면 사진과 함께 문의해 주세요.
이삿짐 업체 직원이 문을 계속 여닫는 날이라 배터리가 평소보다 빨리 닳기도 합니다. / 이사가 끝난 뒤 배터리 상태도 한 번 확인해 두면 좋습니다.
