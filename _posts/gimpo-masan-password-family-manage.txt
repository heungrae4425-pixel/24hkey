# 마산동 아파트, 아이가 먼저 집에 오는 집이라면
마산동은 구래동과 이웃한 한강신도시 생활권으로 아파트 단지가 많은 동네입니다. / 젊은 가족이 많아 부모가 출근한 사이 아이가 먼저 학교에서 돌아와 혼자 현관문을 여는 집도 흔합니다.
이런 집은 비밀번호 관리가 조금 더 섬세해야 합니다. / 아이가 외우기 쉬워야 하고, 친구가 옆에서 보고 따라 외우지 않아야 하며, 돌봄 선생님이나 조부모님이 드나들 때도 문제가 없어야 하기 때문입니다.
이 글은 맞벌이 가족을 기준으로 도어락 비밀번호를 정하고 나누고 바꾸는 방법을 정리했습니다. / 번호가 꼬여 문이 안 열리는 상황이라면 [김포 출장열쇠](gimpo.html)로 연락 주세요.
@ 마산동 아파트 현관 도어락 아이 귀가

# 아이용 번호는 이렇게 정해 보세요
아이에게 너무 긴 번호를 주면 문 앞에서 헷갈려 여러 번 틀리기 쉽습니다. / 몇 번 틀리면 도어락이 한동안 입력을 막아 아이가 밖에서 기다리게 됩니다.
아이와 함께 의미 있는 숫자를 정해 보세요. / 다만 아이 생일, 학년 반 번호, 아파트 동 호수처럼 친구들도 아는 숫자는 피하는 게 좋습니다.
번호를 정하면 주말에 아이와 함께 문 앞에서 몇 번 연습해 보세요. / 실제로 손으로 눌러 봐야 평일 오후에 막히지 않습니다.

# 친구들이 옆에서 볼 때를 대비하세요
아이들은 하교길에 친구와 함께 집 앞까지 오는 경우가 많습니다. / 친구가 옆에 있을 때 번호를 그대로 누르면 숫자가 쉽게 보입니다.
번호 앞뒤에 아무 숫자를 덧붙여 눌러도 열리는 기능이 있는지 확인해 보세요. / 진짜 번호를 다른 숫자 사이에 섞어 누르는 습관을 아이에게 알려 주면 좋습니다.
번호판을 손으로 살짝 가리고 누르는 것도 습관으로 만들어 주세요. / 어른도 같이 하면 아이가 자연스럽게 따라 합니다.
@ 마산동 도어락 번호판 가리고 누르기 습관

# 아이에게 카드나 지문을 주는 방법도 있습니다
번호를 외우기 어려워하는 아이라면 카드나 태그를 가방 안쪽 고리에 달아 주는 방법이 있습니다. / 대기만 하면 열려서 아이가 편해합니다.
다만 카드는 잃어버리면 주운 사람도 열 수 있다는 점을 기억해 두세요. / 분실하면 바로 등록을 지울 수 있도록 카드가 몇 장 등록돼 있는지 적어 두시면 좋습니다.
지문은 아이 손이 작고 자주 젖어 인식이 잘 안 될 수 있습니다. / 지문을 쓰더라도 번호나 카드를 함께 알려 주세요.

# 돌봄 선생님이나 도우미가 드나든다면
돌봄 선생님이 아이 하교 시간에 맞춰 오신다면 가족 번호를 그대로 알려 드리기보다 따로 번호를 만드는 편이 낫습니다. / 사용자 번호를 여러 개 등록할 수 있는 제품이라면 선생님 번호를 따로 두세요.
일정 기간만 쓰는 임시 번호 기능이 있다면 더 좋습니다. / 돌봄이 끝나거나 선생님이 바뀌면 그 번호만 지우면 됩니다.
이런 기능이 없는 제품이라면 선생님이 바뀔 때마다 가족 번호를 바꾸셔야 합니다. / 번거롭다면 기능이 있는 제품으로 바꾸는 것도 생각해 볼 만합니다.

# 조부모님이 가끔 오신다면
주말이나 방학에 조부모님이 아이를 봐 주러 오시는 집도 많습니다. / 어르신께는 번호를 종이에 적어 드리기보다 카드를 하나 드리는 쪽이 편하실 수 있습니다.
번호를 알려 드려야 한다면 오시기 전날 전화로 한 번, 오시는 날 문 앞에서 한 번 함께 눌러 보세요. / 어르신 혼자 문 앞에서 막히시는 일을 줄일 수 있습니다.
방학이 끝나면 조부모님께 드린 카드나 번호를 그대로 둘지 정리할지 정해 두세요.
조부모님 댁이 멀어 자주 오지 않으신다면 다음 방문 때 다시 등록하는 쪽이 오히려 깔끔합니다. / 쓰지 않는 카드가 서랍 어딘가에 굴러다니는 것보다 낫습니다.
@ 마산동 조부모 방문용 도어락 카드 등록

# 번호는 언제 바꾸면 좋을까
- 학년이 바뀌거나 아이 친구 관계가 크게 바뀔 때
- 돌봄 선생님이나 도우미가 바뀌었을 때
- 아이가 친구에게 번호를 알려 줬다고 말할 때
- 이사, 수리, 인테리어 공사로 외부인이 드나든 뒤
- 버튼 닳은 자국이 눈에 띌 때
바꿀 때는 아이가 학교에 가 있는 시간이 아니라 함께 집에 있는 시간에 바꾸세요. / 바꾼 번호를 모른 채 하교하는 일이 생기면 안 되기 때문입니다.

# 번호를 바꾼 뒤 꼭 할 일
새 번호를 등록하면 문을 연 상태에서 바깥 번호판으로 직접 눌러 확인하세요. / 마지막 저장 단계를 빠뜨려 예전 번호가 그대로인 경우가 종종 있습니다.
아이에게는 바꾼 번호를 말로 알려 주고, 휴대폰 메모나 가방 안 쪽지에는 적지 않도록 해 주세요. / 아이 휴대폰이나 가방을 잃어버리면 번호까지 함께 새어 나갑니다.
가족 단체 대화방에 번호를 올리는 것도 피하는 게 좋습니다.
@ 김포 마산동 새 비밀번호 등록 후 바깥 확인

# 앱 알림으로 아이 귀가를 확인한다면
도어락 앱 연동을 쓰면 아이가 문을 열 때 부모 휴대폰으로 알림이 옵니다. / 맞벌이 가족에게는 꽤 든든한 기능입니다.
다만 알림이 안 왔다고 바로 걱정하기 전에 도어락 건전지나 공유기 상태를 먼저 의심해 보세요. / 연동이 끊기는 일은 생각보다 흔합니다.
알림에 의존하기보다 아이가 집에 들어오면 짧게 전화나 문자를 하도록 약속해 두는 것도 함께 하시길 권합니다.

# 아이가 번호를 잊어 문 앞에 있다면
아이에게 이웃집이나 경비실처럼 기다릴 곳을 미리 정해 주세요. / 부모가 바로 오기 어렵다면 전화로 아이가 기다리는 곳을 알려 주시고 연락 주시면 됩니다.
아이가 번호를 몇 번 틀려 도어락이 입력을 막았다면 잠시 기다린 뒤 다시 시도할 수 있다는 것도 미리 알려 주세요. / 막힌 상태에서 계속 누르면 막히는 시간이 길어지는 제품도 있습니다.
도착하면 보호자와 통화로 확인하고, 신분증 주소나 우편물, 관리사무소 세대 확인으로 사시는 분인지 확인한 뒤 엽니다. / 비용은 손대기 전에 먼저 말씀드리고, 못 열면 받지 않습니다.
문 여는 방법은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 있습니다.

# 도어락 기능이 부족하다면
사용자 번호를 여러 개 못 두거나 임시 번호 기능이 없는 오래된 제품이라면 관리가 번거로워집니다. / 고장이 아니라면 굳이 바꿀 필요는 없지만, 가족 상황에 안 맞는다면 교체를 생각해 볼 수 있습니다.
지금 제품을 손볼 수 있으면 [도어락 수리](doorlock-repair.html), 기능 때문에 바꾸신다면 [도어락 교체](doorlock-replace.html)를 참고하세요.

# 마무리
마산동 맞벌이 가족이라면 아이가 외우기 쉽고, 친구는 알기 어렵고, 돌봄 인력은 따로 관리할 수 있는 번호 체계를 만들어 두세요. / 바꿀 때는 꼭 아이와 함께 있는 시간에 바꾸시면 됩니다.
마산동 외에 구래동, 장기동, 운양동, 풍무동, 사우동까지 김포 전 지역을 다니며, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455.
