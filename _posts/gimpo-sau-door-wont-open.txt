# 사우동 현관 앞에서 문이 꿈쩍하지 않을 때
사우동은 주택과 빌라, 아파트가 골고루 섞인 동네라 현관문도 집마다 모양이 다릅니다. / 오래된 철문에 손잡이형 도어락을 단 집도 있고, 새로 바꾼 밀고 당기는 형 도어락을 쓰는 집도 있습니다.
문이 안 열리는 이유도 그만큼 여러 갈래입니다. / 원인을 대충이라도 가려 두면 혼자 해결할 수 있는 일인지, 바로 [김포 출장열쇠](gimpo.html)를 불러야 하는 일인지 금방 정할 수 있습니다.
이 글은 사우동에서 현관문이 안 열릴 때 눈에 보이는 것, 귀에 들리는 것, 손에 느껴지는 것으로 원인을 나누는 방법을 정리했습니다.
@ 사우동 현관문 안 열림 원인 확인

# 먼저 다섯 갈래로 나눠 봅니다
문 앞에서 아래 다섯 가지 중 어디에 해당하는지부터 봅니다. / 하나만 골라도 다음 순서가 정해집니다.
- 화면: 번호판이 켜지는가, 꺼져 있는가
- 소리: 번호를 누르면 어떤 소리가 나는가
- 손잡이: 돌아가는가, 헛도는가, 꽉 막혔는가
- 열쇠: 열쇠를 쓰는 문이라면 들어가고 돌아가는가
- 안쪽: 보조키나 걸쇠를 걸고 나왔을 가능성이 있는가
이렇게 정리해 두면 전화로 설명할 때도 한두 문장이면 됩니다.

# 화면이 아예 안 켜질 때
번호판을 손바닥으로 덮거나 눌러도 아무 불빛이 없다면 배터리가 다 됐을 가능성이 가장 큽니다. / 며칠 전 경고음이나 평소와 다른 멜로디를 들은 기억이 있다면 거의 확실합니다.
바깥쪽 아래나 옆면에 9V 건전지를 대는 단자가 있는지 찾아보세요. / 가까운 편의점에서 9V 건전지를 사서 단자에 댄 채 번호를 누르면 열리는 경우가 많습니다.
건전지를 대도 반응이 없다면 회로 쪽 문제일 수 있으니 그때 연락 주세요. / 문이 열렸다면 안쪽 건전지를 모두 새것으로 한꺼번에 바꿔야 며칠 뒤 같은 일이 되풀이되지 않습니다.

# 화면은 켜지는데 번호가 틀렸다고 나올 때
번호를 누르면 짧게 틀렸다는 소리가 나며 안 열린다면 번호 문제일 가능성이 큽니다. / 가족 중 누가 최근에 번호를 바꾸지 않았는지 먼저 물어보세요.
특정 버튼이 잘 안 눌려 번호가 틀리는 경우도 있습니다. / 버튼을 하나씩 천천히 눌러 보며 삑 소리가 매번 나는지 확인해 보세요.
여러 번 연달아 틀리면 도어락이 한동안 입력을 막습니다. / 서너 번 해 보고 안 되면 멈추는 편이 낫습니다.

# 번호는 맞는데 모터 소리만 날 때
번호가 맞았다는 소리와 함께 위잉 하는 모터 소리가 나는데 문이 안 열린다면 걸쇠가 빠지지 못하는 상태입니다. / 걸쇠가 문틀에 눌려 있거나 모터 힘이 약해진 경우가 많습니다.
문을 안쪽으로 살짝 밀면서 다시 열어 보세요. / 걸쇠에 걸린 힘이 풀리면 열리는 경우가 꽤 있습니다.
모터 소리가 힘없이 늘어진다면 배터리가 거의 다 된 것일 수도 있습니다. / 이럴 때도 9V 비상 전원을 대면 힘이 붙어 열리기도 합니다.
@ 사우동 도어락 모터 소리 걸쇠 걸림 확인

# 손잡이가 헛돌거나 꽉 막혔을 때
손잡이형 도어락에서 번호가 맞았는데 손잡이가 헛돌기만 한다면 안쪽 연결 부품이 닳았거나 빠진 것입니다. / 이 경우는 바깥에서 할 수 있는 게 거의 없어 출장이 필요합니다. / 손잡이가 며칠 전부터 흔들렸다면 그 사실도 같이 알려 주세요. / 원인을 좁히는 데 큰 도움이 됩니다.
손잡이가 아예 안 돌아가고 꽉 막혀 있다면 잠금 상태가 풀리지 않은 것입니다. / 손잡이를 세게 비틀면 부품이 부러질 수 있으니 멈춰 주세요.

# 열쇠가 안 들어가거나 안 돌 때
보조키나 열쇠로 여는 문이라면 열쇠가 끝까지 들어가는지부터 봅니다. / 중간에 걸린다면 열쇠가 휘었거나 구멍 안에 이물질이 있을 수 있습니다.
끝까지 들어갔는데 안 돈다면 실린더 안쪽이 닳았거나 다른 열쇠일 수도 있습니다. / 열쇠 꾸러미에 비슷한 열쇠가 여러 개라면 하나씩 다시 확인해 보세요.
열쇠를 억지로 돌리다 부러지면 일이 커집니다. / 안 돌면 힘주지 말고 빼서 연락 주시면 됩니다.

# 안쪽 보조키나 걸쇠를 의심할 때
번호판도 정상이고 모터 소리도 나는데 문이 조금만 열리고 멈춘다면 안쪽 걸쇠나 체인이 걸린 것입니다. / 집 안에 식구가 있다면 걸쇠를 풀어 달라고 하면 됩니다.
아무도 없는데 걸쇠가 걸려 있다면 문을 닫을 때 진동으로 넘어간 경우입니다. / 이럴 때는 문틈으로 손을 넣지 마시고 그대로 연락 주세요.

# 오래된 문이라면 문틀도 함께
사우동 주택과 빌라처럼 오래 쓴 현관문은 문이 조금씩 처져 걸쇠가 문틀 구멍과 어긋나기도 합니다. / 이 경우 번호는 맞는데 문이 꽉 끼어 안 열리는 느낌이 듭니다.
날씨에 따라 열렸다 안 열렸다 한다면 이 가능성이 큽니다. / 문 아래쪽이 바닥에 끌린 자국이나 문틀 쇠판의 새 긁힘도 같은 신호입니다. / 문을 연 뒤 경첩과 문틀을 같이 봐야 다시 생기지 않습니다.

# 기다리는 동안 하지 않으면 좋은 것
- 드라이버나 카드로 문틈을 벌리는 것
- 번호판 커버를 억지로 떼는 것
- 손잡이에 몸무게를 실어 당기는 것
- 열쇠 구멍에 기름이나 접착제가 든 것을 넣는 것
이런 시도는 문을 덜 상하게 여는 방법을 쓰기 어렵게 만듭니다. / 날이 춥거나 늦은 시간이라면 가까운 실내에서 기다리셔도 되니 만날 곳만 알려 주세요.

# 전화로 이렇게 말씀해 주세요
위 다섯 갈래 중 어디였는지 한 문장으로 말씀해 주시면 됩니다. / 예를 들어 "화면은 켜지는데 모터 소리만 나요"처럼요.
- 주택인지 빌라인지 아파트인지, 몇 층인지
- 대문이나 공동현관이 따로 있는지
- 도어락 앞쪽 사진
- 안에 아이나 반려동물이 있는지
도어락 사진이 있으면 맞는 장비를 챙기기 쉽습니다. / 휴대폰이 집 안에 있다면 이웃에게 잠시 전화를 빌려도 괜찮습니다.

# 확인, 비용 안내, 그리고 개방
도착하면 사시는 분인지 신분증, 주소가 나온 우편물, 관리사무소나 집주인 확인으로 먼저 확인합니다. / 그다음 문 상태를 보고 비용을 먼저 말씀드리고, 동의하시면 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 문은 덜 상하는 방법부터 차례로 시도하며, 자세한 과정은 [현관문 개문](door-open.html)과 [이용안내](guide.html)에 정리했습니다.
문이 열린 뒤 원인이 도어락이면 [도어락 수리](doorlock-repair.html), 너무 낡았으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 사우동 출장열쇠 현관문 개방 진행

# 사우동 말고 김포 어디든
사우동 옆 풍무동, 걸포동부터 장기동, 운양동, 구래동, 마산동, 고촌읍, 통진읍, 양촌읍까지 김포 전 지역 다닙니다. / 통진과 양촌처럼 거리가 있는 곳은 도착 시간을 먼저 말씀드리고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 모터 소리는 나는데 안 열려요. | 문을 안쪽으로 살짝 밀면서 다시 열어 보세요. 그래도 안 되면 연락 주세요.

? 원인을 몰라도 전화해도 되나요? | 됩니다. 화면과 소리만 말씀해 주셔도 충분합니다.
? 못 열면 비용을 내나요? | 열지 못하면 받지 않습니다.
