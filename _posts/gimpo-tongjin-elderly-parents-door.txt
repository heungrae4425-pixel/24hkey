# 부모님 댁 도어락, 언제 마지막으로 점검하셨나요
통진읍에 계신 부모님 댁을 오랜만에 찾았을 때 현관 도어락 상태까지 살펴보는 분은 많지 않습니다. / 하지만 어르신 혼자 지내는 집일수록 문이 안 열리는 상황은 훨씬 큰 일이 됩니다.
번호가 기억나지 않거나 배터리 경고음을 무시하다가 문 앞에서 오래 헤매는 일이 의외로 흔합니다. / 이 글은 통진읍 부모님 댁 도어락을 점검하고 편하게 쓸 수 있도록 설정하는 방법을 정리했습니다.
문이 안 열려 급한 상황이라면 바로 [김포 출장열쇠](gimpo.html)로 연락 주세요. / 통진은 거리가 있는 편이라 위치를 받고 도착 시간을 먼저 말씀드립니다.
@ 통진읍 부모님 댁 도어락 점검 설정

# 어르신 댁에서 문제가 되는 세 가지
첫째, 배터리 경고음을 못 듣거나 무슨 소리인지 몰라 그냥 두는 경우입니다. / 둘째, 번호를 자주 바꾸다 보니 어르신이 기억하지 못하는 경우입니다.
셋째, 지문이나 카드 같은 새 기능이 낯설어 아예 쓰지 않고 번호만 누르다 잘못 입력하는 경우입니다. / 이 세 가지만 정리해도 문 앞의 곤란이 크게 줄어듭니다.
어르신의 불편은 기기가 어려워서라기보다 설정이 복잡해서 생기는 경우가 많습니다. / 쓰는 방식을 단순하게 만들어 드리는 것이 가장 좋은 점검입니다.

# 번호는 외우기 쉽고 바꾸지 않는 것이 낫습니다
자주 바꾸는 번호는 방범에는 좋아도 어르신에게는 부담이 될 수 있습니다. / 외우기 쉬우면서 남이 짐작하기 어려운 번호를 정해 되도록 오래 쓰는 것이 낫습니다.
생일이나 집 전화번호 같은 뻔한 번호는 피하되 가족만 아는 의미 있는 조합이 좋습니다. / 번호를 종이에 적어 현관 근처에 붙여 두는 일은 하지 마시고, 안전한 곳에 따로 적어 두세요.
자녀와 가까운 이웃에게는 번호를 알려 두어 급할 때 도움을 받을 수 있게 합니다. / 번호가 바뀌면 가족 모두에게 같은 방식으로 바로 알려 주세요.
@ 통진읍 어르신 도어락 번호 설정

# 배터리는 자녀가 일정을 정해 교체합니다
어르신은 경고음이 나도 어떻게 해야 할지 몰라 그냥 두는 일이 많습니다. / 방문하는 날을 기준으로 해마다 같은 시기에 배터리를 전부 새것으로 바꾸는 방식이 가장 확실합니다.
건전지는 하나만 바꾸지 말고 모두 같은 새것으로 교체해야 오래 갑니다. / 교체한 날짜를 배터리 칸이나 현관 안쪽에 적어 두면 다음 교체 시기를 놓치지 않습니다.
비상용 9V 건전지를 부모님 댁 서랍에 하나 두고 어디 있는지 알려 드리면 좋습니다. / 사용법도 한 번 같이 해 보시면 급할 때 큰 도움이 됩니다.

# 경고음과 소리 설정을 점검합니다
도어락은 작동음 크기와 경고음 설정이 제품마다 다릅니다. / 어르신은 청력이 약한 경우가 많아 소리가 너무 작으면 경고를 못 듣기도 합니다.
반대로 소리가 너무 커서 불편하다면 조절할 수 있는지 확인해 보세요. / 제품마다 설정 방법이 달라서 설명서나 모델명을 확인하면 도움이 됩니다.
소리 대신 번호판 불빛으로 알리는 기능이 있는 제품도 있습니다. / 어르신이 무엇을 보고 어떻게 알아차리는지 직접 해 보며 점검해 보세요.

# 안쪽 잠금 방식도 확인합니다
문 안쪽 손잡이와 보조키가 어르신이 쓰기에 무리가 없는지 봅니다. / 힘이 약해 돌리기 어렵거나 잘못 잠가 문이 안 열리는 경우도 있습니다.
혼자 지내는 분이 안에서 쓰러지거나 다쳤을 때 밖에서 도움이 들어올 수 있는지도 생각해야 합니다. / 이런 경우를 대비해 이웃이나 가족이 비상 열쇠나 번호를 알고 있는 것이 안전합니다.
문이 안에서 잠겨 있는데 연락이 되지 않는다면 먼저 안전을 확인해야 합니다. / 위급한 상황이면 119에 먼저 연락하세요.

# 문이 안 열릴 때 이렇게 해 보세요
번호판 불이 들어오는지, 소리가 나는지부터 확인합니다. / 불이 꺼져 있다면 9V 건전지를 바깥 단자에 대 보고 번호를 눌러 보세요.
번호를 잊었다면 가족에게 연락해 번호를 확인하거나 이웃이 알고 있는지 물어봅니다. / 그래도 안 되면 억지로 시도하지 말고 연락 주세요.
혼자 계신 어르신이 문 앞에서 오래 서 있지 않도록 안전한 곳에서 기다리게 해 주세요. / 겨울에는 추위, 여름에는 더위에 지치지 않게 하는 것이 먼저입니다.
@ 통진읍 어르신 댁 문 안 열림 출장열쇠

# 전화하실 때 알려주시면 좋은 것
통진은 주택이 많고 위치에 따라 길이 복잡할 수 있어서 설명을 자세히 해 주시면 도움이 됩니다. / 주소와 함께 눈에 띄는 건물이나 큰 길 이름을 말씀해 주세요.
- 어르신이 집 안에 계신지, 문 밖에 계신지
- 번호판 상태와 문 상태
- 건강 상태나 급한 사정이 있는지
- 도어락 모양과 가능하면 사진
자녀분이 멀리 계시다면 전화로 연결해 현장에 계신 분과 통화할 수 있게 해 주세요. / 어르신 혼자 설명하기 어려운 상황도 같이 정리해 드립니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 가족의 확인 중 하나면 됩니다.
어르신이 신분증을 찾기 어려우시다면 가족과 통화하거나 다른 방법을 같이 찾아 드립니다. / 번거로우실 수 있지만 이웃과 거주자를 지키는 절차입니다.
확인이 어렵다면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다. / 자녀분이 대신 연락하는 경우에도 같은 절차를 거칩니다.

# 비용은 문을 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
어르신께는 천천히 쉬운 말로 설명드리고, 자녀분께도 필요한 내용을 같이 알려 드립니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문은 최대한 안 상하게 엽니다
문을 여는 방법은 여러 가지이고 덜 상하는 방법부터 차례로 해 봅니다. / 도어락과 문틀이 상하지 않게 하는 것이 먼저입니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다. / 개문 과정은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
열고 나서는 어르신이 편하게 쓸 수 있는 설정으로 같이 정리해 드립니다. / 번호와 경고음, 안쪽 잠금까지 확인합니다.

# 오래된 도어락이라면 고칠지 바꿀지 판단합니다
어르신 댁 도어락이 오래돼 반응이 느리거나 경고음이 잦다면 상태를 봅니다. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
너무 낡았거나 부품이 없는 제품이라면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 이때도 어르신이 쓰기 쉬운 방식을 우선으로 안내합니다.
복잡한 기능보다 단순하고 튼튼한 번호키 중심 제품이 어르신 댁에는 잘 맞습니다. / 새로 다는 경우의 순서는 [도어락 설치](doorlock-install.html)에 적어 두었습니다.

# 통진읍 말고 김포 어디든 갑니다
통진읍 가까이는 양촌읍, 고촌읍도 다니고 장기동, 구래동 같은 신도시도 갑니다. / 김포 안이면 동네 상관없이 24시간 출동합니다.
거리가 있는 곳은 위치를 받고 도착 시간을 먼저 말씀드립니다. / 김포 전체는 [김포시 출장열쇠](gimpo.html) 페이지에서 확인하세요.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 부모님 댁이 다른 지역이라면 먼저 전화로 문의해 주세요.
