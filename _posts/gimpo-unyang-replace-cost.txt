# 운양동, 입주 때 달린 도어락을 바꿀 때가 됐다면
운양동 한강신도시 아파트는 대부분 밀고 당기는 푸시풀 도어락이 입주 때부터 달려 있습니다. / 처음엔 편했던 도어락도 해가 지나면서 반응이 느려지거나 소리가 달라지는 집이 생깁니다.
교체를 마음먹으면 가장 먼저 궁금한 게 비용입니다. / 그런데 비용은 제품 하나 값만으로 정해지지 않고, 우리 집 문 상태와 원하는 기능에 따라 달라집니다.
이 글은 운양동 아파트에서 도어락을 바꾸기 전에 챙길 것과 비용이 어떤 요소로 정해지는지, 그리고 24시출장열쇠가 비용을 어떤 순서로 안내하는지 정리했습니다. / 교체 안내는 [도어락 교체](doorlock-replace.html) 페이지에도 있습니다.
@ 운양동 아파트 푸시풀 도어락 교체 상담

# 정말 바꿔야 하는지부터
교체 상담을 받다 보면 고쳐서 더 쓸 수 있는 도어락도 꽤 많습니다. / 아래 같은 경우라면 교체보다 수리를 먼저 생각해 보셔도 됩니다.
- 배터리를 새것으로 바꾸면 증상이 사라진다
- 특정 버튼 하나만 잘 안 눌린다
- 손잡이가 헐겁지만 잠금은 잘 된다
- 걸쇠가 문틀에 걸리는데 도어락 자체는 정상이다
반대로 회로 고장이 반복되거나, 부품을 구할 수 없는 오래된 제품이거나, 원하는 기능이 없다면 교체가 맞습니다. / 판단이 어렵다면 [도어락 수리](doorlock-repair.html) 점검을 먼저 받아 보세요.

# 상담 전에 사진 네 장 찍어 두기
전화 상담이 짧고 정확해지려면 사진이 가장 중요합니다. / 아래 네 장이면 대부분의 상황을 미리 파악할 수 있습니다.
- 바깥쪽 도어락 전체
- 안쪽 도어락 전체
- 문 옆면, 걸쇠가 나오는 부분
- 문틀 쪽 걸쇠가 들어가는 쇠판
보조키가 따로 있다면 그 사진도 한 장 더 보내 주세요. / 모델명 스티커가 보이면 가까이 찍어 두시면 좋습니다.

# 문 두께와 기존 구멍이 비용을 좌우합니다
새 도어락이 기존 구멍에 그대로 맞으면 작업이 간단해집니다. / 구멍 위치나 크기가 다르면 문을 새로 가공하거나 덮개를 덧대야 해서 작업 항목이 늘어납니다.
신도시 아파트는 같은 단지라면 문 규격이 비슷한 편입니다. / 그래도 집마다 한 번씩 바꾼 이력이 있을 수 있어 직접 확인하는 게 정확합니다.
문 두께는 문을 열어 둔 상태에서 옆면을 줄자로 재면 됩니다. / 재기 어렵다면 사진만으로도 대략 파악할 수 있습니다.

# 비용을 정하는 다섯 가지 요소
도어락 교체 비용은 대체로 아래 요소가 합쳐져 정해집니다. / 어느 항목이 우리 집에 해당하는지 알면 안내받을 때 이해가 쉽습니다.
- 제품: 번호만 쓰는지, 카드와 지문, 앱 연동까지 쓰는지
- 문 가공: 기존 구멍을 그대로 쓰는지, 새로 맞추는지
- 보조키: 그대로 두는지, 떼고 막는지, 새로 다는지
- 철거: 기존 도어락을 떼어 내는 작업
- 시간대와 거리: 급한 출동인지, 약속한 시간에 가는지
기능이 많을수록 제품 값이 올라가고, 문 가공이 필요하면 작업이 늘어납니다. / 그래서 같은 제품이라도 집마다 비용이 조금씩 다릅니다.
@ 운양동 도어락 교체 문 두께 기존 구멍 확인

# 보조키를 어떻게 할지 미리 정하기
입주 때부터 도어락 위나 아래에 보조키가 따로 달린 집이 있습니다. / 새 도어락으로 바꾸면서 보조키를 그대로 둘지, 떼고 구멍을 막을지, 디지털 보조키로 바꿀지 정해야 합니다.
보조키를 떼면 문 앞이 깔끔해지지만 구멍을 막는 마감이 필요합니다. / 그대로 두면 열쇠를 계속 챙겨야 하고, 새로 달면 그만큼 작업 항목이 늘어납니다.
식구들이 보조키를 실제로 얼마나 쓰는지 떠올려 보면 답이 쉽게 나옵니다.

# 기능은 꼭 쓸 것만 고르세요
푸시풀 도어락은 기능이 다양합니다. / 지문, 카드, 얼굴 인식, 앱 원격 열림, 방문자 알림까지 고를 수 있지만 모두 매일 쓰는 건 아닙니다.
식구가 실제로 쓸 방식 하나와 예비 방식 하나를 먼저 정해 보세요. / 그 두 가지가 들어간 제품군 안에서 고르면 비용도 합리적으로 맞출 수 있습니다.
앱 연동이 필요하다면 집 와이파이 환경도 함께 확인해야 합니다. / 연동 설정까지 원하시면 상담 때 미리 말씀해 주세요.

# 24시출장열쇠가 비용을 안내하는 순서
- 전화나 문자로 사진과 원하시는 기능을 듣고 맞는 제품군을 먼저 말씀드립니다.
- 현장에 도착하면 문 두께, 구멍, 보조키 상태를 직접 확인합니다.
- 제품과 작업 항목을 하나씩 짚어 비용을 먼저 말씀드립니다.
- 동의하시면 그때 작업을 시작합니다.
- 작업 중 예상 못 한 부분이 나오면 손대기 전에 다시 여쭤봅니다.
설명만 듣고 그 자리에서 결정하지 않으셔도 괜찮습니다. / 가족과 상의한 뒤 다시 연락 주셔도 됩니다.

# 비교할 때 물어볼 질문
다른 곳과 비교해 보실 때는 금액만 보지 말고 아래도 함께 물어보세요.
- 기존 도어락 철거와 문 가공이 포함된 안내인지
- 보조키 처리는 어떻게 하는지
- 설치 후 등록까지 같이 해 주는지
- 고장이 나면 어디로 연락하면 되는지
같은 조건으로 비교해야 정확합니다. / 항목이 빠진 안내는 나중에 비용이 달라질 수 있습니다.

# 잠긴 상태에서 교체를 원하실 때
문이 안 열려서 연락 주셨다가 이참에 교체하고 싶다고 하시는 분도 있습니다. / 이 경우 먼저 문을 연 뒤 교체를 진행합니다.
문을 열기 전에는 사시는 분인지 신분증, 주소가 나온 우편물, 관리사무소 확인으로 먼저 확인합니다. / 개방과 교체 비용을 각각 먼저 말씀드리며, 끝내 열지 못하면 비용은 받지 않습니다. / 여는 과정은 [현관문 개문](door-open.html)에 정리했습니다.

# 아파트라면 관리사무소에도 한 번
아파트에 따라 현관문 쪽 작업을 할 때 관리사무소에 미리 알리도록 안내하는 곳이 있습니다. / 엘리베이터 사용이나 작업 시간처럼 단지 규칙이 있을 수 있으니 한 번 물어보시면 편합니다.
공동현관 출입 방법도 함께 알려 주시면 약속 시간에 맞춰 바로 올라갈 수 있습니다.

# 교체 후 함께 확인하는 것
- 문을 닫았을 때 자동 잠김이 한 번에 되는지
- 밖에서 번호, 카드, 지문이 모두 잘 열리는지
- 안쪽 수동 잠금과 이중 잠금 기능이 잘 되는지
- 배터리 칸과 비상 전원 단자 위치
식구 수대로 번호와 카드, 지문 등록까지 그 자리에서 함께 해 드립니다. / 설명서는 잘 보이는 곳에 보관해 두세요.
@ 운양동 새 도어락 설치 후 등록 확인

# 운양동 말고 김포 어디든
운양동 옆 장기동, 구래동, 마산동부터 걸포동, 사우동, 풍무동, 고촌읍, 통진읍, 양촌읍까지 김포 전 지역 다닙니다. / 김포 안내는 [김포 출장열쇠](gimpo.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 기존 구멍에 맞는 제품만 고를 수 있나요? | 네, 문 가공을 줄이고 싶으시면 기존 구멍에 맞는 제품으로 추려 드립니다.

? 잠긴 문을 못 열면 비용은요? | 열지 못하면 받지 않습니다.
