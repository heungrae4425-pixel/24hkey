# 앱이 안 되는 건 문이 고장 난 게 아닐 수 있습니다
운양동 한강신도시 아파트에는 휴대폰 앱과 연동되는 스마트 도어락을 쓰는 집이 많습니다. / 어느 날 갑자기 앱이 열리지 않거나 알림이 오지 않으면 도어락이 망가졌다고 생각하기 쉽습니다.
하지만 앱 연동 문제는 도어락 자체보다 와이파이와 기기 연결, 휴대폰 설정에서 시작되는 경우가 많습니다. / 번호나 카드로는 문이 열린다면 크게 걱정하지 않으셔도 됩니다.
이 글은 운양동에서 앱 연동이 끊겼을 때 집에서 확인할 수 있는 것과 연락해야 하는 때를 나눠 적었습니다. / 문이 아예 안 열리는 상황이라면 [김포 출장열쇠](gimpo.html)에 바로 전화 주세요.
@ 운양동 스마트 도어락 앱 연동 알림 오류

# 먼저 문이 번호나 카드로 열리는지 봅니다
앱이 안 돼도 번호나 카드, 지문으로 열린다면 도어락의 기본 기능은 살아 있다는 뜻입니다. / 이럴 때는 급할 것이 없으니 천천히 연결 문제를 점검하면 됩니다.
반대로 번호도 안 눌리고 번호판이 꺼져 있다면 앱이 아니라 배터리나 전원 문제입니다. / 이 경우는 9V 건전지를 바깥 단자에 대 보고, 그래도 안 되면 연락 주시는 것이 맞습니다.
앱만 믿고 번호나 카드 등록을 지워 두셨다면 이번 기회에 보조 방법을 하나 남겨 두세요. / 연동 기능은 편리하지만 언제든 끊길 수 있다는 점을 염두에 두는 것이 좋습니다.

# 연결이 끊기는 흔한 원인 네 가지
첫째, 공유기를 바꾸거나 비밀번호를 바꿔서 도어락이 새 네트워크를 찾지 못하는 경우입니다. / 둘째, 도어락과 와이파이를 이어 주는 중계 장치의 전원이 빠진 경우입니다.
셋째, 휴대폰 앱이 업데이트되면서 권한이나 로그인이 풀린 경우입니다. / 넷째, 도어락 배터리가 약해져 통신 기능이 먼저 꺼진 경우입니다.
이 가운데 배터리는 가장 간과하기 쉬운 원인입니다. / 번호 입력은 되지만 앱 알림만 안 온다면 건전지부터 새것으로 바꿔 보세요.

# 와이파이와 중계 장치부터 봅니다
도어락이 직접 와이파이에 붙는 제품도 있고 별도의 작은 중계 장치를 거치는 제품도 있습니다. / 중계 장치가 있다면 전원 코드가 꽂혀 있는지, 불빛이 들어오는지부터 봅니다.
공유기를 재부팅한 뒤에는 중계 장치도 한 번 껐다 켜 주면 다시 연결되는 경우가 많습니다. / 공유기 이름이나 비밀번호를 바꿨다면 도어락 쪽 설정도 새로 맞춰 주어야 합니다.
집 안쪽에서 현관까지 신호가 약한 구조라면 공유기를 현관 가까이로 옮겨 보는 것도 방법입니다. / 신호가 안정되면 알림 지연도 대부분 줄어듭니다.
@ 운양동 도어락 와이파이 중계 장치 점검

# 앱을 다시 설정할 때 주의할 점
앱을 지웠다가 다시 설치하면 도어락과의 등록이 풀릴 수 있습니다. / 먼저 앱 안에서 로그아웃과 다시 로그인을 해 보고, 그래도 안 되면 재설치를 고려하세요.
재설치 전에 도어락에 등록된 번호와 카드가 따로 지워지지 않는지 확인해 두면 안전합니다. / 관리자 번호나 연동 비밀번호를 적어 두지 않았다면 먼저 확인이 필요합니다.
알림 권한이 꺼져 있어서 알림이 안 오는 경우도 있으니 휴대폰 설정의 알림과 배터리 절약 모드를 같이 보세요. / 절전 모드가 앱을 강제로 종료하는 일도 흔합니다.

# 앱 없이도 열리게 해 두는 것이 안전합니다
연동 기능은 편리하지만 꼭 필요한 순간에 안 되면 가장 곤란합니다. / 번호, 카드, 비상 열쇠 중 최소 두 가지는 항상 쓸 수 있게 해 두세요.
가족이 앱 대신 번호로 여는 집이라면 연동이 끊겨도 생활에 지장이 없습니다. / 반대로 앱으로만 열던 집은 이번 일을 계기로 번호도 등록해 두시길 권합니다.
휴대폰을 잃어버렸을 때는 앱에 로그인된 기기를 바로 해제하는 방법도 알아 두세요. / 그래야 남이 앱으로 문을 열 수 없습니다.

# 이럴 땐 출장열쇠를 부르세요
번호도 카드도 안 되고 번호판이 꺼져 있을 때는 바로 연락 주세요. / 문이 열리지 않는 상황은 앱이 아니라 도어락 본체나 전원 문제입니다.
앱 설정을 아무리 해도 도어락 쪽이 응답하지 않거나, 등록된 기기를 지워야 하는데 방법이 막힌 경우도 현장 점검이 필요합니다. / 이때 도어락 모델과 증상을 알려 주시면 준비해서 갑니다.
급한 상황이 아니라면 낮에 방문해 연동 설정까지 같이 정리하는 방법도 있습니다. / 일정은 전화로 편하게 말씀해 주세요.

# 전화하실 때 알려주시면 좋은 것
운양동은 단지와 동, 호수가 많아서 위치를 정확히 알려 주셔야 도착이 빨라집니다. / 아파트 이름과 동, 호수, 지금 상황을 짧게 말씀해 주세요.
- 번호나 카드로 열리는지, 아예 안 열리는지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 앱 증상 (연결 안 됨, 알림 안 옴, 로그인 풀림)
- 도어락 모양과 제조사가 보이면 사진
도어락 사진을 문자로 보내 주시면 필요한 부품을 챙겨 가기 좋습니다. / 집 안에 아이가 혼자 있다면 꼭 먼저 말씀해 주세요.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 입주민 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두시면 훨씬 수월합니다.
@ 운양동 24시 출장열쇠 도어락 점검

# 비용은 작업 전에 먼저 말씀드립니다
도어락 상태를 보고 필요한 작업과 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 연동 도어락은 이렇게 관리하세요
- 배터리 경고음이 나면 그날 바로 모두 교체
- 공유기를 바꿀 때 도어락 연결 설정도 같이 바꾸기
- 앱 업데이트 후 한 번 열어 보고 알림 확인
- 가족 구성이 바뀌면 등록된 번호와 기기 정리
정기적으로 점검하면 앱이 갑자기 끊겨 당황하는 일을 줄일 수 있습니다. / 연동 기능이 오래된 제품은 고쳐서 쓸 수 있는지 먼저 봅니다.
수리가 어렵거나 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드리고, 고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 새로 설치하는 경우는 [도어락 설치](doorlock-install.html) 안내도 참고하세요.

# 운양동 말고 김포 어디든 갑니다
운양동 가까이는 장기동, 구래동, 마산동도 다닙니다. / 김포 안이면 동네 상관없이 24시간 출동합니다.
김포에서 다니는 동네는 [김포시 출장열쇠](gimpo.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
