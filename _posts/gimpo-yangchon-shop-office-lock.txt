# 사업장 문이 안 열리면 하루 장사가 멈춥니다
양촌읍은 공장과 창고, 작은 사무실과 상가가 많아 아침 일찍 문을 여는 분이 많은 지역입니다. / 이런 곳에서 출입문이 잠기거나 열쇠가 없어지면 직원들이 문 앞에서 기다리게 되고 납품 일정도 흔들립니다.
주택 현관문과 달리 사업장 출입문은 유리문, 철제 셔터, 샷시 문 등 종류가 다양합니다. / 이 글은 양촌읍 사업장 문이 안 열릴 때 확인할 순서와 연락할 때 알려 주시면 좋은 정보를 정리했습니다.
급하시면 먼저 [김포 출장열쇠](gimpo.html)로 전화 주세요. / 양촌은 거리가 있는 편이라 위치를 받고 도착 시간을 먼저 말씀드립니다.
@ 양촌읍 사업장 출입문 잠김 출장열쇠

# 사업장 문에서 자주 생기는 일
첫째, 마지막으로 퇴근한 사람이 열쇠를 가져가 버려 아침에 다른 직원이 못 들어오는 경우입니다. / 둘째, 오래 쓴 열쇠가 닳아 잠금 장치 안에서 돌아가지 않거나 부러지는 경우입니다.
셋째, 직원이 그만두면서 열쇠를 돌려받지 못해 보안이 걱정되는 경우입니다. / 넷째, 유리문 하단 잠금이나 샷시 문 잠금이 어긋나 열리지 않는 경우입니다.
각각 필요한 작업이 달라서 전화로 상황을 정확히 말씀해 주시면 장비를 알맞게 챙겨 갑니다. / 어떤 문인지 사진을 한 장 보내 주시면 더 빨라집니다.

# 먼저 사업장 안에 사람이 남아 있는지 확인합니다
문 안쪽에 직원이 있다면 안에서 열 수 있는지 먼저 확인합니다. / 안쪽 잠금장치를 풀기만 하면 되는 상황이라면 출동 없이 해결될 수 있습니다.
마지막으로 문을 잠근 사람에게 연락해 열쇠가 어디 있는지 물어보세요. / 열쇠가 다른 직원이나 사장님 차량에 있을 가능성도 생각해 봅니다.
공장 안쪽에 기계가 가동 중이거나 불을 쓰는 설비가 켜져 있다면 그 사실을 꼭 말씀해 주세요. / 이런 경우는 열어야 하는 순서가 달라집니다.

# 열쇠가 부러졌거나 잠금 장치 안에서 안 돌아간다면
열쇠를 넣었는데 한쪽으로만 돌아가거나 중간에 걸린다면 무리하게 돌리지 마세요. / 억지로 돌리면 열쇠가 부러져 구멍 안에 남을 수 있습니다.
열쇠가 부러졌다면 남은 조각을 빼내는 작업이 먼저 필요합니다. / 이 경우 잠금 장치를 통째로 바꾸지 않고도 해결되는 경우가 많습니다.
윤활제를 임의로 많이 뿌리면 오히려 먼지가 엉겨 붙어 상태가 나빠질 수 있습니다. / 상황을 보고 말씀해 주시면 필요한 처치를 안내드립니다.
@ 양촌읍 상가 공장 열쇠 파손 개문

# 유리문과 샷시 문은 다르게 접근합니다
유리문은 바닥이나 상단에 잠금 장치가 있고, 열쇠가 아닌 별도 부품으로 잠기는 경우가 많습니다. / 외관이 비슷해도 내부 구조가 달라 현장에서 확인한 뒤 작업합니다.
샷시 문이나 알루미늄 문은 틀이 얇아 무리하게 힘을 주면 쉽게 휘거나 상합니다. / 이런 문은 열기 전에 어떤 방식으로 열지 먼저 말씀드립니다.
철제 셔터는 전동식과 수동식이 있고, 전원이 꺼진 경우와 잠금이 걸린 경우를 구분해야 합니다. / 셔터 종류와 현재 상태를 알려 주시면 도움이 됩니다.

# 퇴사자가 열쇠를 가지고 있다면 교체를 생각합니다
직원이 그만뒀는데 열쇠나 카드를 돌려받지 못했다면 잠금 장치를 바꾸는 것이 안전합니다. / 특히 창고나 사무실에 재고와 서류가 있는 곳은 한 번 점검해 두시는 것이 좋습니다.
전체를 바꾸지 않아도 내부 부품만 교체하는 방법으로 비용을 줄일 수 있는 경우도 있습니다. / 어느 방식이 맞을지 현장에서 보고 말씀드립니다.
교체 상담은 [도어락 교체](doorlock-replace.html) 페이지에 정리했고, 고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)부터 권해 드립니다. / 필요 없는 교체는 권하지 않습니다.

# 전화하실 때 알려주시면 좋은 것
양촌읍은 공장 단지와 주택이 섞여 있어 길이 복잡할 수 있어서 위치 설명이 중요합니다. / 주소와 함께 눈에 띄는 간판이나 큰 길 이름을 말씀해 주세요.
- 어떤 문인지 (유리문, 샷시 문, 철문, 셔터)
- 열쇠 방식인지 번호키인지
- 안에 사람이나 가동 중인 설비가 있는지
- 열쇠를 분실했는지, 부러졌는지, 문이 걸려 안 열리는지
사업장은 시간이 곧 비용이라 도착 시간을 가장 먼저 안내드립니다. / 사장님이 현장에 없다면 직원분이 대신 연락하셔도 됩니다.

# 도착하면 사업장 주인이나 직원인지 먼저 확인합니다
사업장 문을 여는 일이라 사시는 분, 일하시는 분이 맞는지 먼저 확인합니다. / 사업자등록증, 임대차계약서, 명함이나 건물 관리인 확인 중 하나면 됩니다.
직원분이 연락하셨다면 사장님과 통화해 허락을 확인하는 절차를 거칩니다. / 번거로우실 수 있지만 사업장 보안과 주인의 재산을 지키는 절차입니다.
건물주가 따로 있다면 임차인임을 확인할 서류가 있으면 시간이 줄어듭니다. / 야간이나 휴일이라 서류가 없다면 확인 가능한 방법을 같이 찾아 드립니다.

# 비용은 문을 열기 전에 말씀드립니다
문 종류와 잠금 장치를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문은 최대한 안 상하게 엽니다
사업장 문은 영업에 바로 쓰는 것이라 외관이 상하면 가게 이미지에도 영향을 줍니다. / 그래서 덜 상하는 방법부터 차례로 해 봅니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다. / 개문 과정은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
열고 난 뒤에는 문이 다시 잘 잠기고 열리는지 시험해 보고 열쇠 상태도 같이 점검합니다. / 필요하면 여벌 열쇠를 안내해 드립니다.
@ 양촌읍 24시 출장열쇠 사업장 개문 작업

# 사업장 열쇠 관리 습관 다섯 가지
- 열쇠를 가진 사람의 명단을 만들어 두기
- 퇴사자가 생기면 열쇠 회수 여부를 확인하고 필요하면 교체
- 여벌 열쇠를 안전한 곳에 한 개 이상 보관
- 열쇠가 뻑뻑해지면 부러지기 전에 점검 받기
- 번호키라면 퇴사자가 생길 때 번호 변경
이 정도만 챙겨도 아침에 문 앞에서 멈추는 일이 크게 줄어듭니다. / 작은 관리가 하루 매출을 지켜 줍니다.

# 양촌읍 말고 김포 어디든 갑니다
양촌읍 가까이는 통진읍, 고촌읍도 다니고 구래동, 장기동 같은 신도시도 갑니다. / 김포 안이면 동네 상관없이 24시간 출동합니다.
거리가 있는 곳은 위치를 받고 도착 시간을 먼저 말씀드립니다. / 김포 전체는 [김포시 출장열쇠](gimpo.html) 페이지에서 확인하세요.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 사업장이 다른 지역이라면 먼저 전화로 문의해 주세요.
