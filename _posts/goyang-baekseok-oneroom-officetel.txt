# 백석동 오피스텔 문 앞에서 막혔을 때
백석동은 백석역 주변으로 오피스텔과 업무용 건물, 주거용 건물이 가깝게 붙어 있는 동네입니다. / 퇴근이 늦거나 외출이 잦은 분이 많아서 호실 문이 잠겨 곤란해지는 연락이 밤낮 가리지 않고 들어옵니다.
오피스텔은 아파트와 달리 건물 출입문과 호실 문, 두 겹으로 막혀 있는 경우가 많습니다. / 어느 문에서 막혔는지에 따라 부르는 방법이 달라지니 이 글에서 먼저 구분해 보겠습니다.
[고양 출장열쇠](goyang.html)로 연락하실 때 알아두면 좋은 내용도 함께 적었습니다. / 지금 문 앞이라면 2번과 3번 항목부터 읽으셔도 됩니다.
@ 백석동 오피스텔 도어락 출장열쇠 현관 개문

# 건물 출입문인가, 호실 문인가
먼저 어디에서 막혔는지 확인해 주세요. / 건물 1층 공동 출입문이 안 열리는 경우와 내 호실 문이 안 열리는 경우는 해결 방법이 완전히 다릅니다.
건물 공동 출입문은 건물 관리 쪽 소관이라 관리실이나 관리 업체에 먼저 연락하는 게 순서입니다. / 호실 문은 입주자 본인 확인이 되면 도어락 상태를 보고 바로 진행할 수 있습니다.
전화로 말씀하실 때 "호실 문이 안 열린다"처럼 어디인지만 분명히 알려주셔도 출동 준비가 한결 빨라집니다.

# 호실 도어락이 말을 안 듣는 흔한 경우
오피스텔 도어락은 하루에도 여러 번 여닫기 때문에 배터리가 빨리 닳는 편입니다. / 번호판에 불이 안 들어오거나 반응이 느려졌다면 배터리부터 의심해 볼 수 있습니다.
- 번호판이 아예 꺼져 있고 소리도 없는 경우
- 번호는 눌리는데 모터 소리만 나고 열리지 않는 경우
- 카드나 태그만 인식이 안 되는 경우
- 안쪽 잠금 버튼이 눌린 채로 문을 닫고 나온 경우
이 중 어디에 해당하는지만 말씀해 주셔도 가져갈 장비가 달라집니다.

# 건전지를 구하기 어려운 시간이라면
많은 도어락은 바깥쪽 아래에 9V 건전지를 대는 비상 단자가 있습니다. / 건전지를 대고 있는 동안 번호판이 켜져서 비밀번호를 누를 수 있는 구조입니다.
백석역 근처 편의점에서 9V 건전지를 구할 수 있으면 직접 해보셔도 좋습니다. / 단자가 없거나 건전지를 대도 반응이 없으면 더 만지지 말고 전화 주세요.
문이 열린 뒤에는 안쪽 배터리를 전부 새것으로 바꿔 두시는 걸 권합니다.

# 문틈으로 카드나 도구를 넣어 보지 마세요
급한 마음에 신용카드나 칼날을 문틈에 넣는 분이 있습니다. / 이러면 문틀과 도어락 외관이 상하고, 걸쇠가 더 깊이 물려 오히려 어려워지기도 합니다.
오피스텔 문은 방화 기능이 있는 두꺼운 철문인 경우가 많아 억지로 힘을 쓰면 문이 변형될 수 있습니다. / 상한 문은 퇴실이나 원상 복구 때 문제가 되니 손대지 않고 기다리시는 게 낫습니다.
@ 백석역 근처 오피스텔 문 잠김 24시 출장

# 전화하실 때 알려주실 것
위치와 상황이 정확할수록 도착이 빨라집니다. / 아래 항목을 차례로 말씀해 주세요.
- 건물 이름이 아닌 동 이름과 몇 층인지
- 건물 출입이 가능한지, 출입 비밀번호를 알고 계신지
- 도어락 모양과 번호판 상태(꺼짐, 켜짐, 경고음)
- 집 안에 사람이나 반려동물이 있는지
- 지금 계신 곳이 문 앞인지 다른 곳인지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙기기 좋습니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 본인 확인은 꼭 거칩니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
오피스텔은 주소지가 사업자 등록이나 전입과 다를 수도 있어서, 계약서나 관리비 고지서 같은 서류로 확인하는 경우도 있습니다. / 신분증이 집 안에 있다면 관리사무소에 입주 확인을 부탁해 보세요.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 알려드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용은 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 최대한 안 상하게 여는 방식
문을 여는 방법은 여러 가지이고, 덜 상하는 방법부터 차례로 해봅니다. / 오피스텔 문은 원상 복구가 중요한 만큼 도어락과 문틀 모두 흠이 안 가게 하는 것을 우선합니다.
도어락 종류와 문 상태에 따라 걸리는 시간은 달라집니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 먼저 말씀드립니다.
자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.
@ 비파손 개방 오피스텔 도어락 점검

# 열린 뒤 도어락 상태 같이 보기
문이 열리면 다시 잘 잠기고 열리는지 함께 확인합니다. / 배터리가 원인이었다면 새 배터리로 바꿨는지, 경고음 설정이 켜져 있는지도 봅니다.
비밀번호를 잊어서 연 경우에는 새 번호를 등록하는 것까지 도와드립니다. / 기존 번호는 지우고 새 번호만 남겨 두는 걸 권합니다.
고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 오피스텔에서 문 잠김을 줄이는 습관
짧게 나갔다 올 때가 오히려 가장 위험합니다. / 쓰레기나 택배를 위해 잠깐 나가는 순간 문이 닫혀 잠기는 일이 가장 흔합니다.
- 현관 안쪽에 임시 문 고정용 도구를 두거나 문이 닫히지 않게 확인하기
- 휴대폰 케이스 안에 카드키 한 장을 따로 넣어 두기
- 배터리는 해가 바뀔 때쯤 한꺼번에 교체하기
- 경고음이 나면 그날 바로 교체하기
- 비밀번호는 가족이나 믿을 만한 사람과 한 번 공유해 두기
작은 습관이 한밤의 곤란함을 많이 줄여 줍니다.

# 관리실에 미리 알려 두면 좋은 것
오피스텔은 관리실이 있는 곳이 많아서, 출동 요청을 하시기 전에 관리실에 한 번 알리면 흐름이 매끄럽습니다. / 외부 사람이 건물에 들어와야 하니 방문 사실을 알려 두면 출입에서 지체되지 않습니다.
입주 확인이 필요할 때 관리실에서 확인해 주면 신분증이 집 안에 있어도 절차를 마칠 수 있습니다. / 야간에는 경비나 당직자에게 먼저 말씀해 두시길 권합니다.
건물 규정상 외부 작업이 어려운 경우도 있으니, 그런 규정이 있는지도 함께 물어봐 주세요.

# 백석동 바로 옆 동네도 다닙니다
백석동에서 가까운 마두동, 장항동, 주엽동, 대화동 쪽도 같은 방식으로 다닙니다. / 고양 안이라면 동네와 상관없이 24시간 출동합니다.
고양에서 다니는 동네는 [고양시 출장열쇠](goyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
