# 대화동 부모님 댁, 현관문도 함께 늙어 갑니다
대화역 주변 일산 신도시 아파트에는 한 집에서 오래 지내 오신 어르신들도 계십니다. / 집은 익숙하지만 일산 쪽 오래된 단지는 처음 달았던 도어락을 그대로 쓰거나 한 번쯤 바꾼 뒤 다시 오래된 경우가 많습니다.
부모님은 불편해도 "아직 잘 된다"고 하시는 경우가 많습니다. / 그래서 자녀가 방문할 때 한 번씩 직접 확인해 드리는 게 가장 확실합니다.
이 글은 대화동에 혼자 지내시는 부모님 댁을 찾을 때 자녀가 챙기면 좋은 현관 점검 목록을 정리했습니다. / 급하게 문이 안 열린다면 [고양 출장열쇠](goyang.html)로 연락 주세요.
@ 대화동 부모님 댁 현관 도어락 점검

# 점검 전에 부모님께 여쭤볼 세 가지
목록을 들고 바로 만지기보다 부모님께 먼저 여쭤보세요. / 평소 불편하셨던 점이 가장 정확한 점검 항목이 됩니다.
- 문 앞에서 번호를 누를 때 잘 안 보이시는지
- 문이 무겁거나 너무 세게 닫히지는 않는지
- 요즘 이상한 소리가 나거나 경고음이 울린 적이 있는지
"괜찮다"고 하셔도 괜찮습니다. / 아래 목록을 하나씩 같이 해 보시면 됩니다.

# 목록 하나, 번호판 숫자가 잘 보이는지
오래 쓴 번호판은 자주 누르는 숫자만 닳아 하얗게 지워지기도 합니다. / 숫자가 흐려지면 어르신은 손 감각만으로 누르다 틀리기 쉽습니다.
저녁에 복도 불이 어두울 때 번호판 불빛이 숫자를 잘 비추는지도 확인해 보세요. / 숫자가 잘 안 보인다면 번호판을 바꾸거나 숫자가 큰 제품으로 바꾸는 걸 생각해 볼 때입니다.
닳은 숫자는 번호를 짐작하게 만드는 단서가 되기도 합니다. / 이 점에서도 오래된 번호판은 손봐 드리는 편이 낫습니다.

# 목록 둘, 배터리 상태와 교체 날짜
배터리 덮개를 열어 교체한 날짜가 적혀 있는지 보세요. / 적혀 있지 않다면 이번에 새것으로 모두 바꾸고 날짜를 적어 두세요.
부모님은 경고음이 나도 무슨 뜻인지 모르고 넘기시는 경우가 많습니다. / "삐삐 소리가 평소와 다르면 바로 전화해 달라"고 말씀드려 두면 좋습니다.
비상용 9V 건전지 하나를 신발장 안처럼 부모님이 찾기 쉬운 곳에 두고 쓰는 법을 한 번 보여 드리세요.
@ 대화동 어르신 댁 도어락 배터리 교체 날짜

# 목록 셋, 문 닫히는 힘과 속도
현관문이 너무 세게, 너무 빠르게 닫히면 어르신이 짐을 들고 들어오시다 문에 부딪히거나 손이 끼일 수 있습니다. / 문을 열었다 놓았을 때 쾅 소리가 크다면 문 위 도어클로저 속도를 늦춰야 합니다.
반대로 문이 너무 무거워 여시기 힘들어하신다면 그것도 도어클로저 조절로 나아질 수 있습니다. / 도어클로저에서 기름이 샌다면 교체가 필요합니다.

# 목록 넷, 손잡이와 잠금 방식
손잡이를 돌리는 방식이라면 손잡이가 헐겁지 않은지, 돌릴 때 힘이 너무 들지 않는지 보세요. / 손목 힘이 약해지신 분께는 돌리는 손잡이보다 밀고 당기는 방식이 편할 수 있습니다.
안쪽에 보조키, 체인, 걸쇠가 여러 개 달려 있다면 실제로 쓰시는지 여쭤보세요. / 쓰지 않는 잠금장치가 실수로 걸리면 밖에서 아무도 들어갈 수 없게 됩니다.
특히 혼자 지내시는 분이라면 안에서 걸쇠를 걸었을 때 위급한 상황에 가족이 들어갈 방법이 없다는 점을 함께 이야기해 보세요.

# 목록 다섯, 보조키 열쇠는 어디에
오래된 아파트는 도어락과 별도로 열쇠식 보조키가 달린 집이 많습니다. / 그 열쇠를 부모님만 갖고 계시다면 잃어버리셨을 때 곤란해집니다.
여벌 열쇠를 자녀가 하나 갖고 있는지 확인하세요. / 없다면 [출장 열쇠](key-call.html)로 맞춰 두시는 게 좋습니다.
보조키를 거의 안 쓰신다면 아예 쓰지 않는 쪽으로 정리하는 것도 방법입니다. / 열쇠 꾸러미가 무거우면 어르신이 외출할 때 두고 나오시기도 하니 꼭 필요한 열쇠만 남겨 드리세요.

# 목록 여섯, 자녀가 들어갈 수 있는지
부모님 댁 번호를 자녀가 알고 있는지, 혹은 자녀 카드가 등록돼 있는지 확인하세요. / 전화를 안 받으실 때 바로 가서 들어갈 수 있어야 마음이 놓입니다.
안에서 잠그면 밖에서 번호로도 안 열리는 이중 잠금 기능이 켜져 있다면 부모님과 상의해 끄는 것도 생각해 보세요. / 관리사무소에 자녀 연락처를 남겨 두는 것도 함께 하시면 좋습니다.

# 목록 일곱, 문 앞 바닥과 조명
현관 바닥에 걸려 넘어질 만한 매트나 신발이 없는지 보세요. / 문턱이 높은 집은 문을 열면서 발이 걸리기 쉽습니다.
복도 센서 조명이 잘 켜지는지도 함께 확인해 주세요. / 조명이 늦게 켜지거나 꺼져 있다면 관리사무소에 알려 두면 됩니다. / 어두우면 번호를 잘못 누르거나 열쇠 구멍을 찾기 어려워지십니다.

# 점검한 내용은 형제와 함께 나누기
부모님 댁을 번갈아 찾는 형제가 있다면 점검한 내용을 대화방에 짧게 남겨 두세요. / 배터리를 언제 바꿨는지, 번호를 바꿨는지, 손볼 곳이 있었는지만 적어도 충분합니다.
그래야 다음에 찾는 사람이 같은 일을 두 번 하지 않고, 놓친 곳을 이어서 볼 수 있습니다. / 부모님께 번호를 새로 알려 드렸다면 형제 모두가 알고 있어야 급할 때 누구든 들어갈 수 있습니다.
점검 날짜를 정해 두면 잊지 않습니다. / 명절이나 생신처럼 가족이 모이는 날에 맞춰 하면 자연스럽게 습관이 됩니다.

# 이럴 때는 교체를 생각해 보세요
- 번호판 숫자가 지워지고 불빛이 약하다
- 배터리를 바꿔도 경고음이 계속된다
- 손잡이가 헐겁고 부품을 구하기 어렵다
- 부모님이 지금 방식을 계속 어려워하신다
고칠 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 그게 어렵다면 버튼이 크고 소리가 분명한 제품으로 [도어락 교체](doorlock-replace.html)를 상의해 보세요. / 교체할 때는 부모님이 직접 몇 번 써 보신 뒤 결정하시는 게 좋습니다.

# 부모님이 문 앞에서 막히셨을 때
부모님이 문을 못 여신다면 경비실이나 관리사무소에서 기다리시게 해 주세요. / 연락 주실 때는 아파트 동과 호수, 부모님 연락처, 자녀분이 오실 수 있는지 알려 주시면 됩니다.
도착하면 사시는 분인지 신분증이나 주소가 나온 우편물, 관리사무소 세대 확인으로 먼저 확인합니다. / 비용은 문 상태를 보고 먼저 말씀드리며 자녀분께 통화로 설명드릴 수도 있습니다. / 끝내 열지 못하면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
@ 대화동 부모님 댁 문 열림 출장열쇠 안내

# 대화동 말고 고양 어디든
대화동이 있는 일산서구 주엽동, 탄현동, 일산동, 덕이동은 물론 일산동구 백석동, 마두동, 장항동, 덕양구 화정동, 행신동, 삼송동까지 고양 전 지역 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 자주 묻는 질문
? 점검만 따로 받아도 되나요? | 네, 문이 열린 상태에서 도어락과 도어클로저 점검만 원하셔도 됩니다.
? 부모님이 새 도어락에 적응하실 수 있을까요? | 설치 후 그 자리에서 부모님과 여러 번 같이 써 보며 익히시게 도와드립니다.
? 이중 잠금은 꼭 꺼야 하나요? | 집마다 사정이 달라 정답은 없습니다. 혼자 지내신다면 가족과 상의해 정하시길 권합니다.
? 자녀가 멀리 살아도 진행할 수 있나요? | 됩니다. 통화로 상황을 함께 확인하며 진행합니다.
? 못 열면 비용이 나오나요? | 열지 못하면 받지 않습니다.
