# 대화동, 작은 열쇠 하나가 사라졌을 때
대화역 주변 아파트 1층에는 세대마다 우편함이 줄지어 있습니다. / 이사 올 때 받은 작은 우편함 열쇠는 쓸 일이 드물어 어디 뒀는지 잊어버리기 쉽습니다.
고지서나 등기 안내문이 우편함에 꽂혀 있는데 열쇠가 없으면 손가락으로 겨우 꺼내 보다 포기하게 됩니다. / 운동하러 다니는 곳의 사물함, 아파트 상가 창고, 아이 학원 가방 자물쇠처럼 작은 잠금장치 문제도 비슷하게 생깁니다.
이 글은 대화동에서 우편함과 사물함 열쇠 문제가 생겼을 때 누구에게 먼저 물어보고, 언제 [고양 출장열쇠](goyang.html)를 부르면 되는지 정리했습니다.
@ 대화동 아파트 우편함 열쇠 분실

# 우편함은 누구 것인지부터
아파트 우편함은 세대가 쓰지만 시설 자체는 단지 공용 설비인 경우가 많습니다. / 그래서 자물쇠를 바꾸거나 열 때 관리사무소의 안내를 먼저 받는 곳이 있습니다.
관리사무소에 따라 여벌 열쇠를 보관하거나, 우편함 자물쇠를 일괄로 관리하기도 합니다. / 먼저 전화 한 통으로 물어보는 게 가장 빠른 길일 수 있습니다.
관리사무소에서 직접 처리하지 않는다고 하면 그때 출장열쇠로 연락 주시면 됩니다. / 이때 관리사무소에서 들은 안내, 예를 들어 같은 규격 자물쇠로 바꿔 달라는 말이 있었다면 함께 전해 주세요.

# 우편함 자물쇠 종류 알아 두기
- 작은 열쇠를 꽂아 돌리는 원통형 자물쇠
- 숫자 다이얼을 돌려 맞추는 번호 자물쇠
- 손잡이에 걸어 두는 작은 맹꽁이 자물쇠
같은 단지 안에서도 세대마다 자물쇠를 따로 바꿔 단 경우가 있어 옆집 것과 모양이 다를 수 있습니다. / 종류에 따라 여는 방법도, 바꾸는 방법도 다릅니다. / 사진 한 장만 보내 주셔도 어떤 것인지 바로 알 수 있습니다.

# 열쇠를 잃어버렸다면 먼저 찾아볼 곳
우편함 열쇠는 이사 때 받은 열쇠 꾸러미에 섞여 있는 경우가 가장 많습니다. / 현관 비상 열쇠, 보조키 열쇠와 함께 서랍 한쪽에 들어가 있는지 보세요.
이전 세입자가 열쇠를 넘기지 않고 이사했을 수도 있습니다. / 이럴 때는 집주인이나 중개 쪽에 한 번 물어보세요.
그래도 없다면 열쇠를 새로 맞추기보다 자물쇠 자체를 바꾸는 쪽이 깔끔할 수 있습니다. / 전에 살던 사람이 여벌을 갖고 있을 수 있기 때문입니다.

# 번호 자물쇠가 안 열릴 때
번호 자물쇠는 번호를 잊었거나, 다이얼이 뻑뻑해 숫자가 정확히 맞지 않아 안 열리는 경우가 있습니다. / 다이얼을 돌릴 때 숫자가 딱 맞는 자리에서 멈추는지 확인해 보세요.
가족 중 누가 번호를 바꿨을 수도 있으니 먼저 물어보세요. / 번호를 모르는 상태에서 숫자를 하나씩 돌려 보는 건 시간이 오래 걸리고 다이얼만 닳습니다.
@ 대화동 우편함 번호 자물쇠 다이얼 확인

# 열쇠는 있는데 안 돌아갈 때
열쇠가 들어가는데 돌아가지 않는다면 자물쇠 안이 녹슬었거나 먼지가 찬 경우가 많습니다. / 1층 우편함은 바깥 공기와 습기를 받아 생각보다 쉽게 녹이 습니다.
열쇠를 넣은 채 살살 앞뒤로 조금씩 움직여 보는 정도는 괜찮습니다. / 열쇠를 억지로 돌리면 작은 열쇠는 금방 휘거나 부러집니다. / 부러지면 조각이 안에 박혀 꺼내기 어려워지니 힘을 주지 마세요.
식용유나 일반 기름을 넣는 것도 피해 주세요. / 먼지가 엉겨 다음엔 아예 안 돌아갑니다.

# 사물함 열쇠도 비슷하게 봅니다
운동하러 다니는 곳, 회사, 학교 사물함은 대부분 그곳 관리자가 여벌 열쇠를 갖고 있습니다. / 사물함이 안 열리면 관리자에게 먼저 말씀하시는 게 순서입니다.
개인 사물함에 직접 단 자물쇠라면 사정이 다릅니다. / 내가 산 자물쇠의 열쇠나 번호를 잃어버렸다면 자물쇠를 끊거나 여는 방법을 상의할 수 있습니다.
남의 사물함이나 공용 시설은 허락 없이 열 수 없습니다. / 그곳 관리자의 확인이 꼭 필요합니다.

# 창고, 상가 보관함, 무인 택배함
대화동 아파트 가운데에는 지하나 층마다 세대 창고가 있는 곳도 있습니다. / 창고 자물쇠 열쇠를 잃어버렸다면 우편함과 마찬가지로 관리사무소에 먼저 물어보세요.
상가에서 가게 수납장이나 물품 보관함 열쇠를 잃어버렸다면 상가 관리 쪽 확인이 먼저입니다. / 가게 주인이 직접 단 자물쇠라면 사업자 확인 후 진행할 수 있습니다.
아파트 무인 택배함이 안 열리거나 비밀번호가 맞지 않는다면 대부분 택배함을 관리하는 쪽에서 처리합니다. / 화면에 안내된 연락처나 관리사무소로 먼저 연락하세요.
택배함은 전자 장치라 출장열쇠가 임의로 열 수 없는 경우가 많습니다. / 관리 쪽에서 출장을 요청하는 경우에만 함께 봅니다.

# 출장을 부르실 때 알려 주실 것
- 우편함인지, 사물함인지, 창고인지
- 자물쇠 사진 한 장 (가까이)
- 열쇠를 잃어버렸는지, 열쇠가 안 도는지, 번호를 잊었는지
- 관리사무소나 관리자에게 이미 물어봤는지
작은 자물쇠는 종류가 많아 사진이 있으면 맞는 부품을 챙겨 가기 쉽습니다. / 우편함만 보는 일이라면 약속한 시간에 맞춰 1층에서 만나는 식으로 짧게 끝낼 수 있습니다.

# 확인 절차와 비용 안내
우편함이나 창고처럼 세대에 딸린 시설은 그 세대에 사시는 분인지 먼저 확인합니다. / 신분증, 주소가 나온 우편물, 관리사무소 세대 확인 중 하나면 됩니다.
사물함은 사용자 본인임을 보여 줄 수 있는 것이나 관리자 확인이 필요합니다. / 확인이 되면 상태를 보고 비용을 먼저 말씀드리며, 동의하실 때 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에서 보실 수 있습니다.

# 열고 나서 어떻게 할지
열쇠를 잃어버렸다면 자물쇠를 새로 바꾸고 열쇠를 두세 개 받아 두세요. / 하나는 열쇠 꾸러미에, 하나는 집 서랍에 두면 다음에 찾기 쉽습니다.
여벌 열쇠만 필요하다면 [출장 열쇠](key-call.html)로 맞출 수 있습니다. / 현관 보조키나 도어락 비상 열쇠도 함께 정리하고 싶다면 [도어락 수리](doorlock-repair.html) 안내를 참고하세요.
@ 대화동 우편함 자물쇠 교체 여벌 열쇠

# 작은 열쇠를 잃어버리지 않는 습관
- 우편함, 창고, 보조키 열쇠는 한 꾸러미에 모으고 이름표 달기
- 이사할 때 받은 열쇠 개수를 사진으로 남겨 두기
- 번호 자물쇠 번호는 휴대폰 메모에 알아볼 수 있는 말로 적기
- 우편함은 일주일에 한 번은 열어 열쇠를 써 보기
자주 쓰는 열쇠일수록 잃어버릴 일이 줄어듭니다. / 오래 안 쓴 자물쇠는 녹이 슬기 쉬우니 가끔이라도 돌려 주세요.

# 대화동 말고 고양 다른 동네
대화동 옆 주엽동, 탄현동, 덕이동, 일산동부터 백석동, 마두동, 장항동, 화정동, 행신동, 삼송동, 원흥동까지 고양 전 지역 갑니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
