# 덕이동 현관, 네모난 쇠막대가 말을 안 들을 때
도어락이 잠길 때 문 옆면에서 튀어나와 문틀 구멍으로 들어가는 네모난 쇠막대를 데드볼트라고 부릅니다. / 손잡이를 돌리면 들어가는 비스듬한 걸쇠와 달리, 데드볼트는 모터나 손잡이 레버로만 움직입니다.
일산서구 덕이동 집에서 "문은 닫혔는데 잠기지가 않는다", "번호는 맞는데 쇠막대가 안 빠져서 문이 안 열린다"는 연락이 오면 대부분 이 데드볼트 문제입니다. / 두 증상은 비슷해 보여도 대처가 완전히 다릅니다.
이 글은 덕이동에서 데드볼트가 안 나오거나 안 들어갈 때, 지금 문이 열린 상태인지 닫힌 상태인지에 따라 무엇을 해 볼지 나눠 정리했습니다. / 집에 들어갈 수 없는 상황이라면 [고양 출장열쇠](goyang.html)로 연락 주세요.
@ 덕이동 도어락 데드볼트 걸림 확인

# 먼저 지금 상태를 둘 중 하나로
- 문이 열려 있는데 데드볼트가 안 나오거나 끝까지 안 나온다
- 문이 닫혀 있는데 데드볼트가 안 들어가 문이 안 열린다
첫 번째는 집 안에 들어와 있는 상태라 급하지 않지만 문단속이 안 됩니다. / 두 번째는 밖에서 들어가지 못하거나 안에서 나가지 못하는 상태라 훨씬 급합니다.
둘 중 어디인지에 따라 아래에서 해당하는 부분만 보셔도 됩니다. / 헷갈린다면 문을 살짝 밀어 봤을 때 움직이는지만 확인해 보세요. / 움직이면 첫 번째, 꿈쩍하지 않으면 두 번째에 가깝습니다.

# 문이 열린 채로 데드볼트가 안 나올 때
문을 연 상태에서 안쪽 잠금 버튼을 눌러 보세요. / 모터 소리가 나면서 데드볼트가 나오다 멈추는지, 아예 소리가 없는지 들어 봅니다.
소리가 없다면 배터리나 전원 쪽, 소리는 나는데 안 나온다면 데드볼트 자체나 안쪽 톱니 쪽을 의심합니다. / 배터리를 새것으로 모두 바꾼 뒤 다시 해 보면 원인이 좁혀집니다.
수동 레버가 있는 제품이라면 레버를 손으로 돌려 데드볼트가 부드럽게 나오는지도 확인해 보세요. / 손으로도 뻑뻑하다면 기계 쪽 문제입니다.

# 반만 나오고 멈춘다면
데드볼트가 중간까지만 나오고 멈추는 경우는 데드볼트 주변에 먼지나 이물질이 끼었거나, 모터 힘이 약해진 경우가 많습니다. / 문 옆면의 데드볼트 구멍 주변을 마른 솔이나 천으로 털어 내 보세요.
기름을 뿌려 넣는 건 피해 주세요. / 도어락 안쪽으로 흘러 들어가 회로를 상하게 하거나 먼지를 엉기게 합니다.
털어 낸 뒤에도 같다면 모터나 톱니가 닳았을 수 있어 [도어락 수리](doorlock-repair.html)로 점검을 받는 게 좋습니다.

# 문을 닫으면 잠금 실패 소리가 날 때
문을 열어 둔 상태에서는 잘 나오는데 닫으면 삐삐 소리와 함께 잠기지 않는다면 데드볼트가 문틀 구멍에 부딪히는 것입니다. / 문이 처졌거나 문틀 쇠판이 어긋나 구멍 위치가 맞지 않는 경우입니다.
문을 닫은 뒤 손으로 문을 살짝 밀거나 들어 올린 채 잠가 보세요. / 그렇게 해서 잠긴다면 거의 확실히 위치가 어긋난 것입니다.
이 상태를 오래 두면 데드볼트 끝이 닳고 모터가 계속 힘을 쓰다 지칩니다. / 문틀 쇠판 위치를 조정하면 해결되는 경우가 많습니다.
@ 덕이동 데드볼트 문틀 쇠판 어긋남

# 문이 닫힌 채로 안 열릴 때
번호를 맞게 눌렀는데 모터 소리만 나고 문이 안 열린다면 데드볼트가 문틀 구멍 안에서 눌려 빠지지 못하는 상태일 수 있습니다. / 이때는 문을 안쪽으로 살짝 밀거나 바깥쪽으로 살짝 당기면서 다시 번호를 눌러 보세요.
데드볼트에 걸린 압력이 풀리면 빠져나오는 경우가 꽤 있습니다. / 손잡이에 몸무게를 싣거나 문을 세게 흔드는 건 데드볼트를 더 휘게 할 수 있어 피해 주세요.
모터 소리가 힘없이 늘어진다면 배터리가 약한 것일 수도 있습니다. / 바깥쪽에 9V 비상 전원 단자가 있다면 건전지를 대고 다시 시도해 보세요.

# 안에 있는데 문이 안 열린다면
집 안에서 나가려는데 데드볼트가 안 들어간다면 안쪽 수동 레버나 잠금 해제 버튼을 먼저 써 보세요. / 레버를 돌릴 때 문을 살짝 밀어 주면 더 잘 들어갑니다.
그래도 안 되면 무리하게 레버를 비틀지 마시고 연락 주세요. / 안에 계신 상태라면 사시는 분 확인도 수월해 진행이 빠릅니다.
급하게 나가야 하는 사정이 있다면 그 사실도 함께 말씀해 주세요.

# 겨울과 여름에 더 잘 생기는 이유
문과 문틀은 기온에 따라 아주 조금씩 늘었다 줄었다 합니다. / 그래서 데드볼트와 문틀 구멍 사이 여유가 적은 집은 한겨울이나 한여름에만 걸리는 일이 생깁니다.
덕이동처럼 오래 산 집과 새로 지은 건물이 함께 있는 곳에서는 문 상태도 집마다 제각각이라 같은 계절에도 증상이 다르게 나타납니다. / 계절이 바뀔 때마다 비슷한 증상이 반복된다면 쇠판 위치를 한 번 조정해 두는 게 좋습니다. / 여유를 조금만 만들어 줘도 일 년 내내 편해집니다.

# 데드볼트가 손으로 밀려 들어간다면
잠근 상태에서 문 틈으로 데드볼트를 눌렀을 때 쑥 들어간다면 데드볼트를 잡아 주는 안쪽 부품이 상한 것입니다. / 이 상태는 문이 잠긴 것처럼 보여도 제대로 잠긴 게 아닙니다.
이런 증상은 미루지 말고 점검을 받으세요. / 부품 교체로 해결되지 않으면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.

# 하지 않으면 좋은 것
- 드라이버로 문틈의 데드볼트를 밀어 넣는 것
- 문을 발로 차거나 어깨로 미는 것
- 도어락 몸체에 기름이나 물을 뿌리는 것
- 잠금 버튼을 연달아 계속 누르는 것
특히 버튼을 계속 누르면 모터가 과열되거나 톱니가 상할 수 있습니다. / 두세 번 해 보고 안 되면 멈추는 게 좋습니다.

# 연락 주실 때 알려 주실 것
- 문이 열린 상태인지 닫힌 상태인지
- 모터 소리가 나는지, 데드볼트가 어디까지 나오는지
- 계절이나 시간대에 따라 달라지는지
- 도어락 앞뒤 사진과 문 옆면 사진
문 옆면 사진이 있으면 데드볼트 모양과 크기를 미리 알 수 있어 맞는 부품을 챙기기 좋습니다.

# 확인 절차와 비용 안내
밖에서 들어가지 못하는 상황이라면 도착 후 사시는 분인지 신분증, 주소가 나온 우편물, 관리사무소 확인으로 먼저 확인합니다. / 그다음 문과 도어락 상태를 보고 비용을 먼저 말씀드리며, 동의하실 때 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 정리했습니다.
@ 덕이동 출장열쇠 데드볼트 수리 점검
