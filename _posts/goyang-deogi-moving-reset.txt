# 새집에 들어가기 전에 먼저 할 일
덕이동은 새 아파트와 빌라, 오래된 주택이 이어진 동네라 이사 오고 가는 일이 잦습니다. / 새집 문을 열 때 이전에 살던 사람의 번호가 그대로 남아 있는 경우가 많습니다.
열쇠를 받았다고 안심하면 안 됩니다. / 이전 입주자나 중개 과정에서 번호를 아는 사람이 여럿일 수 있기 때문입니다.
이 글은 덕이동에서 이사한 뒤 도어락을 안전하게 정리하는 방법을 담았습니다. / [고양 출장열쇠](goyang.html)가 초기화와 교체를 어떻게 돕는지도 함께 적었습니다.
@ 덕이동 이사 도어락 비밀번호 초기화 출장열쇠

# 이전 번호가 남아 있는 이유
도어락은 새 주인이 입주해도 저절로 번호를 지우지 않습니다. / 이전 입주자의 번호, 카드, 지문이 그대로 등록된 채 남아 있습니다.
집을 보여주던 중개인이나 청소, 이삿짐을 맡은 사람도 번호를 알 수 있습니다. / 악의가 없더라도 여러 사람이 아는 번호는 안전하지 않습니다.
그래서 이사한 당일 번호를 바꾸는 것이 가장 중요한 습관입니다.

# 직접 초기화해 보는 방법
제품마다 초기화 방법이 다르지만 대부분 안쪽 배터리 칸에 작은 버튼이 있습니다. / 이 버튼을 길게 누르면 등록된 정보가 모두 지워지는 방식이 많습니다.
- 안쪽 덮개를 열고 배터리 칸 근처의 초기화 버튼 찾기
- 설명서나 제품 이름으로 방법 확인하기
- 초기화 후 새 번호를 바로 등록하기
- 카드와 지문도 필요한 것만 다시 등록하기
잘 모르겠으면 억지로 누르지 말고 연락 주세요.

# 초기화가 안 되거나 번호를 모를 때
이전 번호를 몰라 문이 안 열리거나, 초기화 버튼이 보이지 않는 경우도 있습니다. / 이럴 때 무리하게 분해하면 도어락이 상합니다.
새집 문 앞에서 이삿짐 업체를 기다리고 있다면 더 급해집니다. / 이런 경우 연락 주시면 현장에서 안전하게 열고 정리해 드립니다.
열쇠 구멍이 있는 제품이면 보조키가 있는지부터 확인해 보세요.
@ 덕이동 이사 도어락 번호 초기화 현장

# 이사 때 흔히 하는 실수
새집 열쇠를 받은 뒤 그대로 두고 이사하는 분이 많습니다. / 며칠 뒤에 바꾸겠다고 미루다가 잊는 경우도 흔합니다.
이전 입주자가 보조키 열쇠를 가지고 있을 수도 있습니다. / 번호만 바꾸고 열쇠 구멍은 그대로 두면 반쪽짜리 대비가 됩니다.
입주 청소 업체나 인테리어 공사 때 문 번호를 알려준 뒤 안 바꾸는 경우도 있습니다.

# 전화하실 때 알려주실 것
상황에 맞게 준비하려면 몇 가지 정보가 필요합니다. / 아래 내용을 알려주시면 현장에서 헤매지 않습니다.
- 덕이동 어디쯤인지와 건물 종류, 층수
- 이사 날짜와 지금 문이 열리는지 여부
- 도어락 방식(번호, 카드, 지문, 열쇠 구멍)
- 초기화 버튼을 찾았는지와 해본 결과
- 집 안에 사람이나 반려동물이 있는지
도어락이나 문 사진 한 장이면 충분합니다.
급하실 때는 문자로 위치와 사진만 먼저 보내주셔도 됩니다. / 통화가 어려운 곳에 계시면 문자로 상황을 적어 보내주세요. / 확인하는 대로 바로 연락드립니다.

# 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소나 집주인 확인 중 하나면 됩니다.
덕이동에서도 신분증이 집 안에 있는 경우가 많습니다. / 관리사무소에 세대 확인을 부탁하거나 우편물로 대신할 수 있으니 방법을 같이 찾아드립니다.
확인이 어려우면 작업을 할 수 없어서 미리 말씀해 주시면 방법을 안내합니다.
이 절차는 다른 사람이 몰래 들어가는 일을 막기 위한 것이라 양해 부탁드립니다. / 사시는 분께는 몇 분이면 끝나는 간단한 과정입니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 알려드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없고, 부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다.
출동 전에 전화로 상황을 듣고 대략의 방향을 말씀드립니다. / 현장에서 상태를 확인한 뒤 정확한 내용을 다시 알려드리니 중간에 놀라실 일이 없습니다.
진행 순서는 [이용안내](guide.html)에도 정리해 두었습니다.

# 문과 도어락을 상하지 않게 엽니다
부수지 않고 여는 방법부터 차례로 해봅니다. / 문과 도어락을 살려야 이후 비용도 줄어듭니다.
작업 중에 바꿔야 할 부품이 보이면 만지기 전에 말씀드립니다. / 원래 상태로 다시 조립할 수 있게 진행합니다.
어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
문 틈에 흠집이 나거나 도어락 외관이 상하지 않았는지 작업 뒤에 함께 확인해 보여드립니다.
@ 비파손 개방 덕이동 도어락 출장 작업

# 열린 뒤에 하는 점검
문이 열리면 도어락 상태와 등록된 정보를 확인합니다. / 남아 있는 이전 번호와 카드는 모두 지워 새 번호만 등록합니다.
보조키 열쇠 구멍이 오래됐다면 새로 맞추는 방법도 안내합니다. / 번호 정리와 열쇠 정리를 한 번에 끝내면 편합니다.
고장이 의심되면 [도어락 수리](doorlock-repair.html)로 점검하고, 너무 오래됐으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 이사 후 보안 점검표
이사한 날 아래 항목을 한 번에 정리해 두면 마음이 편합니다.
- 도어락 비밀번호를 새 번호로 바꾸기
- 이전 카드와 지문 등록 모두 지우기
- 보조키 열쇠 구멍을 새로 맞출지 판단하기
- 현관 외에 베란다 문과 창문 잠금도 확인하기
- 배터리를 새것으로 바꾸고 날짜 적어 두기
새 번호는 생일이나 전화번호 끝자리처럼 쉬운 숫자를 피하세요. / 가족끼리만 알 수 있는 번호로 정하는 것이 좋습니다.

# 교체가 나은 경우
이전 입주자가 쓰던 도어락이 너무 오래됐거나 부품이 낡았다면 초기화보다 교체가 낫습니다. / 같은 고장이 반복될 제품이라면 처음부터 바꾸는 편이 오래 갑니다.
교체할지 말지는 현장에서 상태를 보고 솔직하게 말씀드립니다. / 꼭 필요하지 않은 교체는 권하지 않습니다.
새 제품을 고를 때는 문 두께와 보조키 위치를 먼저 확인해야 합니다.

# 덕이동 말고 고양 어디든 갑니다
덕이동 가까운 일산동, 탄현동, 대화동, 풍동 쪽도 같은 방식으로 다닙니다. / 고양 안이라면 동네 상관없이 24시간 출동합니다.
고양에서 다니는 동네는 [고양시 출장열쇠](goyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
위치만 알려주시면 가장 가까운 기사님이 출발하고, 도착 예상 시간도 미리 말씀드립니다. / 길이 막히거나 늦어질 때는 중간에 먼저 연락드립니다.

# 자주 묻는 질문

? 초기화하면 모든 번호가 지워지나요? | 대부분 제품은 등록된 번호와 카드가 모두 지워집니다. 새 번호를 바로 등록하셔야 합니다.
? 세입자인데 도어락을 바꿔도 되나요? | 집주인 동의를 받아 두시길 권합니다. 연락이 닿으면 통화 확인도 도와드립니다.
? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
