# 번호가 갑자기 떠오르지 않는 날
행신역 근처로 퇴근하는 길에 손은 번호판 앞에 있는데 머릿속이 하얘지는 날이 있습니다. / 어제까지 눈 감고도 누르던 숫자가 오늘은 한 글자도 생각나지 않으면 당황하는 게 당연합니다.
이 글은 행신동에서 번호를 잊었을 때 조급해하지 않고 순서대로 해 볼 일을 모아 둔 것입니다. / 끝까지 안 풀리면 [고양 출장열쇠](goyang.html)가 문을 열어 드립니다.
@ 행신동 도어락 비밀번호 잊어버렸을 때

# 숨부터 고르고 손가락에게 맡겨 보기
번호는 머리보다 손이 먼저 기억하는 경우가 많습니다. / 번호판 앞에서 눈을 감고 평소처럼 천천히 눌러 보면 의외로 열릴 때가 있습니다.
- 서두르면 앞자리가 꼬이니 한 글자씩 또박또박 누르기
- 자주 쓰던 번호를 두세 가지 떠올려 한 번씩만 시도하기
- 틀린 번호를 같은 모양으로 반복해서 누르지 않기
- 마지막에 별표나 샵 버튼을 눌러야 하는 제품인지 확인하기
틀린 횟수가 쌓이면 잠시 입력이 막히는 제품이 대부분입니다. / 막히면 그대로 몇 분 기다리세요.

# 몇 번 틀리면 잠기는지 알아 두기
도어락은 무작위로 눌러 보는 시도를 막으려고 일정 횟수 이상 틀리면 번호판을 잠가 버립니다. / 이때 경고음이 울리거나 불빛이 색을 바꾸기도 합니다.
이미 막힌 뒤에 계속 누르면 시간만 늘어납니다. / 잠시 손을 떼고 다른 방법으로 넘어가는 편이 빠릅니다.

# 가족에게 먼저 한 통
번호를 바꾼 사람이 가족 중에 있을 수 있습니다. / 아이가 학원에서 돌아와 번호를 바꿨거나 배우자가 어제 비밀번호를 정리했을 수도 있습니다.
메신저로 새 번호가 올라와 있는지 대화방을 한번 훑어보세요. / 가까운 사람에게 전화 한 통만 해도 해결되는 일이 의외로 많습니다.
@ 행신동 번호 확인 가족 연락

# 번호 말고 다른 길이 열려 있는지
번호판만 보지 말고 현관을 한 바퀴 살펴보세요. / 카드나 지문도 같이 등록된 제품이라면 번호 없이도 들어갈 수 있습니다.
- 지갑이나 가방에 카드 태그가 들어 있는지 찾아보기
- 지문 인식을 등록해 둔 손가락으로 센서를 대 보기
- 열쇠 구멍이 있다면 보조키나 예비 열쇠가 어디 있는지 떠올리기
- 집 안에 가족이 있다면 안에서 열어 달라고 부탁하기
열쇠 구멍이 있는 현관이라면 예비 열쇠가 해결책이 되기도 합니다. / 열쇠를 어디에 두었는지 모르겠다면 아래 순서로 넘어가세요.

# 집 안에서 풀 수 있는 방법이 있다면
집 안에서는 안쪽 손잡이로 쉽게 열립니다. / 밖에서 안 열리는 것과 안에서 안 열리는 것은 전혀 다른 문제입니다.
밖에서 잠겼을 때는 안쪽에 있는 사람의 도움이 가장 빠릅니다. / 베란다 쪽이나 다른 출입구가 있는 구조라면 그쪽을 안전하게 쓸 수 있는지 살펴보세요.
무리하게 창을 넘거나 난간을 타는 것은 위험합니다. / 높은 층이라면 더더욱 하지 마세요.

# 번호를 알 만한 곳을 한번 훑어보기
이사 때 받은 서류나 입주 안내문에 처음 번호가 적혀 있는 집이 있습니다. / 임대차 계약을 정리한 중개 쪽에서 초기 번호를 알고 있을 때도 있습니다.
오랜만에 돌아온 집이라면 가장 먼저 쓰던 번호부터 떠올려 보세요. / 몇 번 바꾼 적이 있다면 가장 최근에 바꾼 날이 언제인지 기억하는 것이 단서가 됩니다.
@ 행신동 도어락 번호 단서 찾기

# 그래도 안 열린다면 이렇게 전화하세요
통화가 되면 위치부터 알려 주세요. / 행신동 안 어디쯤인지, 건물 이름 대신 근처 역이나 큰길을 말씀하시면 됩니다.
- 번호식인지 카드식인지, 열쇠 구멍이 있는지
- 번호판이 켜지는지 꺼져 있는지
- 지금 입력이 막힌 상태인지
- 집 안에 사람이나 반려동물이 있는지
- 도착할 때까지 어디서 기다리실 수 있는지
문 사진이 있으면 문자로 보내 주세요. / 어떤 방식으로 열지 미리 정해 두면 도착해서 바로 시작할 수 있습니다.

# 열기 전에 확인하는 것들
남의 집 현관을 여는 일이라 이 집에 사시는 분인지 먼저 확인합니다. / 신분증 주소, 집 주소가 적힌 우편물, 관리사무소 확인 중 하나만 있으면 됩니다.
확인이 어렵다면 다른 방법을 같이 찾습니다. / 예를 들어 같은 집 가족과 통화하거나 계약 관련 서류를 보여 주시는 방법이 있습니다.
비용은 상태를 보고 작업 전에 먼저 말씀드립니다. / 못 열면 비용은 받지 않습니다.
@ 행신동 출장열쇠 신분 확인 후 개방

# 어떤 방법으로 열까요
문이나 도어락을 상하지 않게 여는 방법부터 씁니다. / 그 방법이 통하지 않을 때만 부품을 건드리고, 그 전에 반드시 먼저 설명드립니다.
자세한 원칙은 [현관문 개문](door-open.html) 안내에 따로 적어 두었습니다. / 급해서 억지로 열려다 문틀이 휘는 일은 정말 피하고 싶습니다.
- 번호판이 살아 있으면 초기화 쪽부터 확인
- 열쇠 구멍이 있다면 그쪽으로 먼저 접근
- 어느 쪽도 어렵다면 문 구조를 보고 방법 결정

# 문이 열린 다음 번호는 이렇게
열리고 나면 새 번호를 바로 등록해 드립니다. / 이전 번호를 계속 쓰고 싶으면 그대로 두어도 되지만, 잊을 정도였다면 이번 기회에 바꾸는 것도 좋습니다.
외우기 쉽다고 생일이나 전화번호 뒷자리를 쓰면 가까운 사람이 짐작할 수 있습니다. / 기억하기 쉬우면서 남이 추측하기 어려운 조합을 같이 찾아봅니다.
[도어락 설치](doorlock-install.html)나 교체까지 필요하다면 그때 따로 상담하면 됩니다.

# 다음에 또 잊지 않으려면
번호를 종이에 적어 현관 근처에 붙여 두는 것은 오히려 위험합니다. / 믿을 만한 가족에게 암호를 알려 주고, 비밀번호 관리 앱을 쓰는 방법이 낫습니다.
석 달에 한 번쯤 번호를 바꾼다면 바꾼 날짜를 달력에 적어 두세요. / 날짜만 적고 번호는 적지 않는 습관이 좋습니다.
가족이 함께 쓰는 집이라면 번호를 바꿀 때 한 명이 전담하고 나머지에게 알리는 규칙을 정해 두세요. / 서로 다른 번호를 바꿔 버리는 일이 줄어듭니다.

# 자주 묻는 질문
? 번호를 몇 번 틀리면 도어락이 망가지나요? | 망가지지 않고 일정 시간 입력이 막힐 뿐입니다. 막힌 동안은 기다렸다가 다시 시도하세요.
? 번호를 몰라도 문을 상하지 않고 열 수 있나요? | 대부분 가능합니다. 문과 도어락 상태를 보고 작업 전에 방법을 설명드립니다.
? 이전 번호를 다시 써도 되나요? | 쓸 수 있습니다. 다만 한 번 잊었다면 새로 정하는 편을 권합니다.
? 못 열면 비용을 내야 하나요? | 못 열면 비용을 받지 않습니다. 작업 전에 비용을 먼저 말씀드립니다.
? 한밤중에 연락해도 되나요? | 24시간 받습니다. 새벽이어도 편하게 전화하세요.

# 행신동 어디든 가겠습니다
번호를 잊은 것은 누구에게나 있는 일이니 너무 자책하지 마세요. / 사진 한 장과 위치만 알려 주시면 됩니다.
고양 안이면 동네를 가리지 않고 출동하고, 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다. / 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.
