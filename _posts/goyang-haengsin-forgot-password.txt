# 번호가 갑자기 생각나지 않을 때
행신동은 행신역과 가까워 출퇴근하는 분이 많은 동네입니다. / 피곤한 퇴근길이나 오랜만에 돌아온 날 문 앞에서 번호가 떠오르지 않는 일이 생깁니다.
당황하면 더 기억나지 않으니 먼저 숨을 고르세요. / 이 글은 번호를 잊었을 때 해볼 방법과 안 될 때의 순서를 정리했습니다.
[고양 출장열쇠](goyang.html)는 문을 상하지 않게 열고 번호를 새로 등록해 드립니다.
@ 행신동 도어락 비밀번호 분실 출장열쇠 개문

# 먼저 기억을 되살리는 방법
최근에 바꾼 번호와 예전 번호를 헷갈리는 경우가 많습니다. / 이전에 쓰던 번호도 한 번씩 눌러 보세요.
가족에게 전화해서 번호를 물어보는 것이 가장 빠릅니다. / 가족이 집 안에 있으면 문을 열어달라고 하면 됩니다.
휴대전화 메모나 사진첩에 번호를 적어 둔 적이 없는지도 찾아보세요.

# 너무 많이 틀리면 생기는 일
도어락은 번호를 여러 번 틀리면 일정 시간 입력을 막습니다. / 서너 번 눌러 보고 안 되면 잠시 쉬었다가 다시 해보세요.
계속 누르면 막힌 시간이 늘어나거나 경고음이 울릴 수 있습니다. / 한밤중이라면 이웃에게 소리가 퍼질 수도 있습니다.
번호를 모르는 채로 여러 번 시도하는 것은 도움이 되지 않습니다.
@ 행신동 도어락 비밀번호 분실 개방 점검

# 열쇠 구멍이 있는 제품이라면
많은 도어락에는 비상용 열쇠 구멍이 숨어 있습니다. / 번호판 아래 덮개를 열면 보이는 경우가 많습니다.
보조 열쇠를 가지고 있다면 이 구멍으로 문을 열 수 있습니다. / 열쇠가 없다면 전화 주시면 됩니다.
열쇠 구멍을 억지로 열려다 덮개가 부러지는 일이 있으니 천천히 확인하세요.

# 해서는 안 되는 행동
문을 발로 차거나 도구로 틈을 벌리는 것은 가장 피해야 할 행동입니다. / 문틀과 도어락 모두 상하게 되어 번호만 잊었을 뿐인데 큰 수리가 됩니다.
번호를 추측해서 수십 번 눌러 보는 것도 막힘만 길어집니다. / 한두 번 확인한 뒤 멈추는 것이 안전합니다.
유튜브에서 본 방법으로 도어락을 분해하는 것도 위험합니다.

# 전화하실 때 알려주실 것
상황에 맞게 준비하려면 몇 가지 정보가 필요합니다. / 아래 내용을 알려주시면 현장에서 헤매지 않습니다.
- 행신동 어디쯤인지와 건물 종류, 층수
- 도어락 방식(번호, 지문, 카드)과 모양
- 열쇠 구멍이나 보조키가 있는지
- 집 안에 사람이나 반려동물이 있는지
- 최근에 번호를 바꾼 적이 있는지
도어락이나 문 사진 한 장이면 충분합니다.
급하실 때는 문자로 위치와 사진만 먼저 보내주셔도 됩니다. / 통화가 어려운 곳에 계시면 문자로 상황을 적어 보내주세요. / 확인하는 대로 바로 연락드립니다.

# 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소나 집주인 확인 중 하나면 됩니다.
행신동에서도 신분증이 집 안에 있는 경우가 많습니다. / 관리사무소에 세대 확인을 부탁하거나 우편물로 대신할 수 있으니 방법을 같이 찾아드립니다.
확인이 어려우면 작업을 할 수 없어서 미리 말씀해 주시면 방법을 안내합니다.
이 절차는 다른 사람이 몰래 들어가는 일을 막기 위한 것이라 양해 부탁드립니다. / 사시는 분께는 몇 분이면 끝나는 간단한 과정입니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 알려드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없고, 부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다.
출동 전에 전화로 상황을 듣고 대략의 방향을 말씀드립니다. / 현장에서 상태를 확인한 뒤 정확한 내용을 다시 알려드리니 중간에 놀라실 일이 없습니다.
진행 순서는 [이용안내](guide.html)에도 정리해 두었습니다.

# 문과 도어락을 상하지 않게 엽니다
부수지 않고 여는 방법부터 차례로 해봅니다. / 문과 도어락을 살려야 이후 비용도 줄어듭니다.
작업 중에 바꿔야 할 부품이 보이면 만지기 전에 말씀드립니다. / 원래 상태로 다시 조립할 수 있게 진행합니다.
어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
문 틈에 흠집이 나거나 도어락 외관이 상하지 않았는지 작업 뒤에 함께 확인해 보여드립니다.
@ 비파손 개방 행신동 도어락 출장 작업

# 열린 뒤에 하는 점검
점검 후에는 새 번호를 가족에게 어떻게 알릴지, 카드나 지문을 함께 등록할지도 같이 정리해 드립니다. / 한 번 정리해 두면 다음에 같은 일이 생겨도 당황하지 않습니다.
문이 열리면 도어락의 현재 상태와 배터리를 확인합니다. / 기존 번호는 지우고 새 번호를 등록합니다.
번호 입력이 자주 막히거나 반응이 이상하다면 내부 문제도 의심해 봅니다. / 점검 결과에 따라 수리나 교체 여부를 안내합니다.
고장이 의심되면 [도어락 수리](doorlock-repair.html)로 점검하고, 너무 오래됐으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 번호를 잊지 않는 습관
몇 가지만 지켜도 같은 일을 훨씬 줄일 수 있습니다.
- 가족 한 명 이상과 번호를 공유해 두기
- 지문이나 카드를 함께 등록해 두기
- 번호를 바꾼 날짜를 메모해 두기
- 비상용 열쇠를 믿을 만한 곳에 맡겨 두기
- 너무 어렵거나 쉬운 숫자 피하기
번호를 종이에 적어 현관 근처에 두는 것은 가장 위험합니다.

# 새 번호를 정하는 요령
문을 연 뒤에는 새 번호를 정해 바로 등록합니다. / 생일이나 전화번호처럼 알아내기 쉬운 숫자는 피하는 것이 좋습니다.
기억하기 쉬우면서 남이 맞히기 어려운 숫자가 좋습니다. / 가족 모두 쉽게 기억할 수 있는 규칙을 만들어 두세요.
카드나 지문이 지원되는 제품이면 함께 등록해 두면 다음에 번호를 잊어도 열 수 있습니다.
번호를 바꾼 뒤에는 문을 열어 둔 채로 새 번호가 실제로 작동하는지 두세 번 확인하세요. / 문이 닫힌 뒤에 안 열리는 일을 막는 가장 기본적인 방법입니다.

# 행신동 말고 고양 어디든 갑니다
행신동 가까운 화정동, 원흥동, 삼송동, 백석동 쪽도 같은 방식으로 다닙니다. / 고양 안이라면 동네 상관없이 24시간 출동합니다.
고양에서 다니는 동네는 [고양시 출장열쇠](goyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
위치만 알려주시면 가장 가까운 기사님이 출발하고, 도착 예상 시간도 미리 말씀드립니다. / 길이 막히거나 늦어질 때는 중간에 먼저 연락드립니다.

? 새 번호도 바로 등록해 주나요? | 네, 문을 연 뒤 새 번호를 등록하고 사용법도 설명해 드립니다.
? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.

? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.

# 마무리
행신동에서 이런 일이 생기면 서두르지 마시고 위치와 상황부터 알려주세요. / 문과 도어락을 상하지 않게 해결하는 쪽으로 안내합니다.
혼자 해결하려다 문이나 도어락을 상하게 하는 것이 가장 아쉬운 경우입니다. / 한 번 시도하고 안 되면 멈추고 연락 주시는 것이 결국 시간과 비용을 아낍니다.
