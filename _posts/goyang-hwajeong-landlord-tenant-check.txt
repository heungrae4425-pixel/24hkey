# 고장 난 건 하나인데 연락할 사람은 둘
화정동은 화정역을 중심으로 덕양구 아파트 단지와 상가가 모여 있는 동네입니다. / 역이 가까워 전세나 월세로 들어와 사는 분도 적지 않습니다.
세 들어 사는 집 도어락이 고장 나면 문을 여는 일과 별개로 고민이 하나 더 생깁니다. / "이건 내가 고쳐야 하나, 집주인께 말씀드려야 하나"입니다.
누가 비용을 낼지는 계약 내용과 두 분의 이야기로 정할 일이라 이 글에서 정답을 드리지는 않습니다. / 다만 화정동 집에서 이야기를 순하게 풀어 가는 데 도움이 되는 순서와 메모 거리를 적어 두었습니다.
@ 화정동 전월세 아파트 도어락 고장 정리

# 이 메모는 세입자와 집주인 모두를 위한 것입니다
도어락 고장은 대부분 누구의 잘못도 아닌 일입니다. / 오래 쓰면 닳고, 계절이 바뀌면 말썽을 부립니다.
그런데 기록 없이 말로만 오가면 서로 기억이 다르고, 사소한 일이 서운한 일로 번지기 쉽습니다. / 아래 순서대로 메모를 남겨 두면 세입자는 설명하기 쉽고, 집주인은 판단하기 쉬워집니다.

# 첫 번째 메모, 언제 어떤 증상이었는지
고장을 처음 알아챈 날과 증상을 적어 두세요. / "며칠 전부터 번호가 한 번에 안 먹었고, 오늘 아침 완전히 안 열렸다"처럼 시간 순서로 쓰면 됩니다.
- 처음 이상하다고 느낀 날
- 경고음이나 이상한 소리가 났는지
- 배터리를 언제 마지막으로 갈았는지
- 비가 오거나 추운 날에만 그랬는지
이 메모는 원인을 짐작하는 데도 그대로 쓰입니다. / 출장 기사에게 보여 주셔도 도움이 됩니다.

# 두 번째 메모, 사진과 짧은 영상
도어락 앞면과 안쪽 몸체 사진, 번호를 눌렀을 때 소리가 나는 짧은 영상을 찍어 두세요. / 문이 덜 닫히거나 걸린다면 여닫는 모습도 한 번 찍어 둡니다.
입주할 때 찍어 둔 현관 사진이 있다면 같이 모아 두세요. / 입주 때와 지금이 어떻게 달라졌는지 보여 주는 자료가 됩니다.
사진은 날짜가 남는 휴대폰 기본 카메라로 찍는 것이 좋습니다. / 찍은 사진은 앨범 하나에 모아 두면 나중에 찾기 쉽습니다.
@ 화정동 아파트 도어락 고장 사진 영상 기록

# 세 번째 메모, 원인이 어느 쪽에 가까운지
도어락 고장은 크게 세 갈래로 나눠 볼 수 있습니다. / 어느 쪽에 가까운지 적어 두면 이야기의 방향이 잡힙니다.
- 소모품: 배터리가 다 됐거나 약해진 경우
- 노후: 오래 써서 모터, 손잡이, 번호판이 닳은 경우
- 파손: 떨어뜨리거나 부딪히거나 물이 들어간 경우
배터리는 쓰는 사람이 가는 소모품으로 보는 경우가 많습니다. / 노후나 파손은 원인과 계약 내용에 따라 달라지니 출장 기사가 본 상태를 그대로 전하시면 됩니다.
기사는 원인을 보이는 대로 설명해 드릴 뿐, 누가 책임질지는 말씀드리지 않습니다. / 그건 두 분이 정할 일이기 때문입니다.

# 연락은 문자로 한 번 남기세요
집주인께 전화로 말씀드렸더라도 같은 내용을 문자로 한 번 보내 두세요. / 앞에서 정리한 증상 메모와 사진을 함께 보내면 됩니다.
문자로 남기면 언제 알렸는지가 분명해지고, 집주인도 나중에 다시 확인하기 편합니다. / 답이 늦으면 하루 이틀 기다렸다가 한 번 더 정중히 여쭤 보세요.

# 문이 안 열리는 급한 상황이라면
문이 아예 안 열려 집에 못 들어가는 상황이라면 기다릴 수 없습니다. / 이럴 때는 집주인께 상황을 문자로 알린 뒤 먼저 문을 여는 것이 현실적입니다.
도착하면 사시는 분인지 신분증 주소나 우편물, 임대차 계약서, 관리사무소 확인으로 봅니다. / 전입 전이라 신분증 주소가 다르다면 계약서 사진을 준비해 주세요.
문은 [현관문 개문](door-open.html) 방식 가운데 덜 상하는 쪽부터 씁니다. / 끝내 못 열면 비용은 받지 않습니다.

# 비용 안내는 두 분께 같은 내용으로
문을 열거나 고치기 전에 무엇을 할지와 비용을 먼저 말씀드립니다. / 원하시면 같은 내용을 집주인께도 전화나 문자로 그대로 설명드릴 수 있습니다.
같은 설명을 두 분이 같이 들으면 오해가 줄어듭니다. / 바로 정하기 어렵다면 그날은 문만 열고, 수리나 교체는 두 분이 이야기한 뒤 다시 잡으셔도 됩니다.
@ 화정동 집주인 세입자 함께 듣는 비용 안내

# 고칠지 바꿀지 정할 때 볼 것
고쳐서 쓸 수 있는 상태라면 [도어락 수리](doorlock-repair.html)가 먼저입니다. / 부품만 바꾸면 되는 경우도 많습니다.
도어락이 오래돼 부품을 구하기 어렵거나 같은 고장이 되풀이된다면 [도어락 교체](doorlock-replace.html)를 생각해 볼 때입니다. / 교체로 정했다면 어떤 제품으로 할지, 기존 문 구멍에 맞는지도 함께 정하셔야 합니다.
세입자가 원하는 기능이 따로 있다면 그 부분은 미리 이야기해 두세요. / 예를 들어 지문 기능을 더 원한다면 차액을 어떻게 할지까지 정해 두면 깔끔합니다.

# 바꾼 뒤 번호와 카드는 누가 갖나요
새 도어락을 달면 번호와 카드, 지문 등록을 새로 합니다. / 사는 동안은 세입자가 번호를 정하고, 집주인은 번호를 따로 갖지 않는 경우가 많습니다.
비상시를 위해 집주인께 무엇을 맡겨 둘지는 서로 정하시면 됩니다. / 맡긴다면 그 내용도 문자로 남겨 두세요.

# 집주인이 계약 때 미리 해 두면 좋은 것
고장이 난 뒤에 정하려면 서로 어색합니다. / 계약할 때 도어락 이야기를 한 줄만 넣어 두어도 나중이 훨씬 편해집니다.
- 지금 도어락 제품 이름과 달아 둔 시기 알려 주기
- 배터리는 누가 갈지 미리 말해 두기
- 고장 나면 어디로 먼저 연락할지 정하기
- 입주 날 현관 사진을 함께 찍어 나눠 갖기
세입자 입장에서도 이 정도가 정해져 있으면 고장이 났을 때 망설이지 않고 연락할 수 있습니다. / 작은 것부터 정해 두는 것이 서로를 배려하는 방법입니다.
집을 여러 채 내주시는 분이라면 집마다 도어락 제품과 교체 시기를 한 장에 적어 두세요. / 세입자에게서 연락이 왔을 때 어떤 제품인지 바로 답할 수 있습니다.
@ 화정동 임대 계약 때 도어락 정보 공유

# 퇴거하는 날 다시 볼 것
이사 나가는 날에는 등록한 지문과 카드를 지우고, 번호를 정한 대로 돌려 둡니다. / 받은 카드와 열쇠는 처음 받은 개수대로 돌려 드립니다.
입주 때 사진과 퇴거 때 사진을 나란히 남겨 두면 정리가 쉽습니다. / 집주인이라면 다음 세입자가 들어오기 전 빈 집일 때 등록 정리와 배터리 교체를 해 두시면 좋습니다.

# 화정동 말고 고양 어디든
덕양구 행신동, 원흥동, 삼송동, 지축동부터 일산동구 백석동, 식사동, 일산서구 주엽동, 대화동까지 고양 전 지역을 다닙니다. / 다니는 동네는 [고양시 출장열쇠](goyang.html)에, 진행 순서는 [이용안내](guide.html)에, 다른 지역은 [출장 지역](area.html)에 있습니다.

? 집주인 연락이 안 되는데 문이 안 열려요. | 상황을 문자로 남기신 뒤 연락 주세요. 거주 확인 후 먼저 문을 열어 드립니다.
