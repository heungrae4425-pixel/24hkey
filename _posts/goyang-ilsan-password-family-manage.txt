# 일산동 우리 집, 번호를 바꾸면 꼭 한 명이 문 앞에서 막힌다
일산역 주변으로 주택과 빌라, 상가가 어우러진 일산동은 오래 산 가족이 많은 동네입니다. / 부모님과 자녀가 함께 살거나, 따로 사는 자녀가 자주 드나드는 집도 흔합니다.
이런 집에서 현관 번호를 바꾸면 거의 매번 비슷한 일이 생깁니다. / 바꾼 사람은 알렸다고 생각하는데, 누군가 한 명은 그 소식을 못 듣고 저녁에 문 앞에서 막힙니다.
번호를 자주 바꾸는 것도 중요하지만, 그보다 먼저 식구끼리 정할 규칙이 있습니다. / 이 글은 일산동에서 도어락 번호를 바꾸고 나눌 때 정해 두면 좋은 규칙을 정리했습니다. / 막힌 상황이라면 [고양 출장열쇠](goyang.html)로 연락 주세요.
@ 일산동 현관 도어락 가족 비밀번호 관리

# 번호 담당을 한 사람으로
식구 모두가 번호를 바꿀 수 있으면 누가 언제 바꿨는지 아무도 모르게 됩니다. / 번호를 바꾸는 사람은 한 사람으로 정해 두세요.
담당은 집에 가장 오래 있는 사람보다 연락을 잘 챙기는 사람이 맞습니다. / 바꾼 뒤 식구 모두에게 알렸는지 끝까지 확인하는 역할까지 맡기 때문입니다.
담당이 아닌 식구는 번호를 바꾸고 싶을 때 담당에게 말하기로 정하면 됩니다. / 이 규칙 하나로 몰래 바뀐 번호 때문에 막히는 일이 크게 줄어듭니다. / 담당이 출장이나 여행으로 오래 집을 비운다면 그동안만 대신 맡을 사람을 정해 두세요.

# 바꾸는 날은 달력에 적어 두기
날을 정하지 않으면 번호 바꾸기는 한없이 미뤄집니다. / 가족 달력이나 휴대폰 공유 일정에 바꾸는 날을 적어 두세요.
- 계절이 바뀌는 달 첫 주말
- 도어락 배터리를 바꾸는 날
- 집에 수리 기사나 업체가 다녀간 다음 날
- 식구 중 누가 열쇠나 카드를 잃어버린 날
바꾸는 날을 미리 알면 식구들이 그날 저녁에는 새 번호를 물어볼 준비를 하고 들어옵니다.

# 새 번호는 이렇게 알리기
가족 단체 대화방에 번호를 그대로 올리는 집이 많습니다. / 편하긴 하지만 대화방은 오래 남고, 휴대폰을 잃어버리면 번호도 함께 새어 나갈 수 있습니다.
가능하면 얼굴을 보고 직접 알려 주거나, 전화로 불러 주세요. / 문자로 보내야 한다면 받은 사람이 외운 뒤 바로 지우도록 정해 두세요.
알린 뒤에는 각자 직접 한 번씩 문을 열어 보게 하는 것까지가 담당의 일입니다. / 말로만 듣고 손으로 눌러 보지 않으면 숫자 하나를 잘못 기억하는 일이 생깁니다.
@ 일산동 도어락 새 번호 가족 직접 확인

# 어르신이 계신 집의 규칙
부모님이 함께 사신다면 새 번호가 손에 익을 때까지 시간이 걸립니다. / 바꾸기 며칠 전에 미리 새 번호를 알려 드리고 함께 연습해 보세요.
숫자가 너무 길면 외우기 어려우시니 자릿수는 적당히, 대신 짐작하기 어려운 숫자로 정합니다. / 지갑 속에 숫자를 그대로 적어 두시기보다 가족만 아는 힌트로 적어 두시는 게 낫습니다.
번호가 자꾸 헷갈리신다면 어르신 몫으로 카드나 지문을 함께 등록해 드리는 것도 방법입니다.

# 아이에게 번호를 줄 때
아이가 혼자 하교해 문을 열 나이가 되면 번호를 알려 줘야 합니다. / 이때 친구에게 말하지 않기, 누르는 동안 손으로 가리기 두 가지를 약속으로 정해 두세요.
아이가 번호를 친구에게 알려 줬다고 말하면 혼내기보다 그날 번호를 바꾸는 날로 정하면 됩니다. / 그래야 다음에도 숨기지 않고 말해 줍니다.

# 따로 사는 가족의 번호
따로 사는 자녀나 형제가 가끔 들르는 집이라면 그분들도 번호를 압니다. / 번호를 바꿀 때마다 그분들께도 알려야 하는지 미리 정해 두세요.
자주 오지 않는다면 그분 몫은 손님 번호처럼 따로 두는 편이 편합니다. / 가족 번호를 바꿔도 그분 번호는 그대로 쓸 수 있어 연락을 빠뜨릴 걱정이 없습니다.
기숙사나 군대에서 몇 달 만에 돌아오는 자녀도 있습니다. / 돌아오는 날 미리 새 번호를 알려 주거나, 도착 시간에 맞춰 집에 누가 있도록 해 두세요.
따로 사는 가족이 번호를 메모해 두었다면 그 메모가 어디 있는지도 한 번 물어보세요. / 지갑이나 휴대폰 메모에 집 주소와 함께 적혀 있다면 따로 보관하도록 부탁드리는 게 좋습니다.

# 일산동 주택이라면 대문 번호도 함께
대문과 현관이 따로 있는 주택은 번호가 두 개입니다. / 현관 번호만 바꾸고 대문 번호는 그대로 두는 집이 많은데, 둘을 같이 관리하는 편이 낫습니다.
다만 두 번호를 같게 정하면 하나가 알려질 때 둘 다 열립니다. / 서로 다른 번호로 두고, 바꾸는 날은 같은 날로 맞추면 관리가 쉬워집니다.

# 번호를 바꾸는 순서
- 문을 활짝 열어 둔 상태에서 시작하기
- 안쪽 몸체 등록 버튼을 눌러 새 번호 입력
- 문을 연 채로 바깥에서 새 번호 눌러 보기
- 문을 닫고 다시 한 번 새 번호로 열어 보기
- 예전 번호가 지워졌는지 확인하기
문을 닫은 채 바꾸다 순서가 꼬이면 밖에서 들어올 방법이 사라질 수 있습니다. / 제품마다 버튼 위치가 다르니 처음이라면 제품 이름으로 사용법을 먼저 찾아보세요.

# 그래도 문 앞에서 막혔다면
새 번호를 못 들은 식구가 문 앞에 섰다면 먼저 담당에게 전화해 보세요. / 여러 번 틀리면 도어락이 입력을 한동안 막으니 서너 번에서 멈추는 게 좋습니다.
담당과 연락이 안 되고 집 안에 아무도 없다면 그때 연락 주세요. / 일산동구, 일산서구 중 어디인지와 건물 이름이나 번지, 일산역에서 어느 쪽인지 알려 주시면 도착이 빨라집니다.

# 거주 확인과 비용 안내
문을 열어야 하는 경우 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 집주인이나 관리하시는 분 확인 중 하나면 됩니다.
도어락 상태를 보고 비용을 먼저 말씀드린 뒤, 동의하실 때 시작합니다. / 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 있습니다.

# 번호 관리가 어려운 도어락이라면
번호를 하나만 넣을 수 있거나 등록 버튼이 잘 안 눌리는 오래된 제품이라면 관리가 번거롭습니다. / 고장이라면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 기능이 모자라면 식구별 번호나 카드를 넣을 수 있는 제품으로 [도어락 교체](doorlock-replace.html)를 생각해 볼 만합니다.
@ 고양 일산동 가족 번호 도어락 교체 상담
