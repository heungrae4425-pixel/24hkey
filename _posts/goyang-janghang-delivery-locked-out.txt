# 잠깐 나왔을 뿐인데 문이 닫혀 버렸다면
장항동은 정발산역과 가까운 일산 쪽 주거지로, 아파트와 빌라, 근린상가가 이어진 동네입니다. / 현관 앞에서 택배를 받거나 분리수거를 하러 나온 사이 문이 닫혀 곤란해졌다는 연락이 꾸준히 옵니다.
슬리퍼 차림에 휴대폰도 집 안에 두고 나온 상황이면 더 막막합니다. / 이 글은 그런 상황에서 당황하지 않고 순서대로 움직일 수 있게 정리했습니다.
[고양 출장열쇠](goyang.html)로 연락하기 전에 이웃이나 가족에게 연락할 방법이 있는지부터 떠올려 보세요.
@ 장항동 문 잠김 출장열쇠 현관 개문

# 제일 먼저 확인할 것
문이 정말 잠겼는지 손잡이를 한 번 더 돌려보세요. / 도어락 중에는 문이 닫히면 자동으로 잠기는 방식이 많아서, 닫히는 순간 잠금이 걸린 것일 수 있습니다.
번호 키가 달려 있다면 비밀번호를 아는 분이 계신지 생각해 보세요. / 가족이 번호를 알고 있다면 가장 빠르게 해결되는 길입니다.
열쇠를 이웃이나 가족에게 맡겨 둔 적이 있는지도 떠올려 보시면 좋습니다.

# 휴대폰이 없는 경우
이웃에게 전화를 빌리거나 관리사무소에 부탁하는 방법이 있습니다. / 이웃집 초인종을 누르는 게 부담스러우면 경비실이나 상가 가게에서 전화를 빌려도 됩니다.
번호를 외우고 있다면 전화를 거는 게 가장 간단합니다. / 010-3664-5455는 적어 두기 쉬운 번호입니다.
이웃에게 전화를 빌릴 때는 위치(동 이름, 건물, 층)를 그대로 말해 주시면 됩니다.

# 문 앞에서 하지 말아야 할 행동
잠긴 문을 흔들거나 발로 차는 분이 있는데, 문틀이 상하고 걸쇠가 더 깊이 물립니다. / 문이 상하면 열쇠집 비용보다 수리 비용이 더 커질 수 있습니다.
신용카드나 얇은 도구로 문틈을 벌리는 것도 도어락 외관을 상하게 합니다. / 열린다고 해도 도어락이 한 번 상한 상태에서는 또 같은 일이 생기기 쉽습니다.
창문이나 베란다를 통해 들어가려는 시도는 사고 위험이 있어서 권하지 않습니다.
@ 장항동 도어락 현관 문 잠김 24시 출동

# 이런 상황이 가장 많습니다
장항동에서는 이런 경우가 자주 있습니다. / 해당되는 상황을 말씀해 주시면 준비가 정확해집니다.
- 택배를 받으러 현관 밖으로 나왔다가 문이 닫힌 경우
- 쓰레기를 버리러 나갔다가 문이 잠긴 경우
- 아이를 데리러 잠깐 나갔는데 열쇠가 집 안에 있는 경우
- 강아지 산책 후 현관 번호가 기억나지 않는 경우
이 중 어디에 해당하든 순서는 비슷합니다. / 위치와 도어락 모양만 알려주시면 됩니다.

# 집 안에 아이나 반려동물이 있다면
이 경우는 가장 먼저 말씀해 주세요. / 아이가 혼자 있거나 가스 불을 켜 둔 상황이면 안전이 우선이라 순서를 바꿔서 움직입니다.
문 너머로 아이에게 계속 말을 걸어 안심시켜 주세요. / 아이가 문을 만지다가 안에서 보조키를 잠그는 일도 있어서 침착하게 안내해 주시는 것이 좋습니다.
정말 위급하다면 119에 먼저 연락하시고, 그다음 저희에게 위치를 알려주세요.

# 전화하실 때 알려주실 것
위치와 상황이 정확할수록 도착이 빨라집니다. / 아래 순서로 말씀해 주시면 됩니다.
- 장항동 어디쯤인지(정발산역 방향인지, 호수공원 방향인지)
- 건물 종류(아파트, 빌라, 상가)와 몇 층인지
- 도어락 모양(번호판형, 지문형, 손잡이 일체형)
- 번호판 상태(켜짐, 꺼짐, 경고음)
- 집 안에 사람이나 동물이 있는지
도어락이 보이는 사진을 문자로 보내주시면 준비가 훨씬 정확해집니다.

# 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증을 집 안에 두고 나온 경우가 가장 많은데, 이때는 관리사무소에 세대 확인을 부탁해 보세요. / 늦은 시간에는 경비실에 먼저 말씀해 두시면 수월합니다.
확인이 어려우면 작업을 할 수 없어서 방법을 함께 찾아드립니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 알려드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용은 없습니다.
부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 최대한 안 상하게 엽니다
문 여는 방법은 여러 가지이고 덜 상하는 방법부터 차례로 해봅니다. / 현관문과 도어락, 문틀이 상하지 않게 하는 것이 먼저입니다.
도어락 종류와 문 상태에 따라 걸리는 시간은 달라집니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 말씀드립니다.
어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
@ 비파손 개방 장항동 도어락 출장

# 문이 열린 뒤에 해둘 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 함께 확인합니다. / 자동으로 잠기는 방식이라면 잠금 모드 설정도 같이 살펴봅니다.
잠금을 자동에서 수동으로 바꿀 수 있는 제품이면 이번 기회에 설정을 바꿔 두는 걸 권합니다. / 그러면 잠깐 나가는 일이 훨씬 마음이 편해집니다.
다만 수동으로 바꾸면 나갈 때 직접 잠가야 하니, 가족 모두가 같은 방식으로 쓰는지 한 번 이야기해 보세요. / 설정 방법은 제품마다 달라서 현장에서 화면이나 버튼 구성을 보고 알려드립니다.
어르신이나 아이가 함께 사는 집이라면 어떤 방식이 더 쓰기 편한지도 같이 고민해 드립니다.
고장이 있다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 같은 일이 다시 생기지 않게
조금만 습관을 바꾸면 문 앞에서 막히는 일이 많이 줄어듭니다. / 가장 쉬운 것은 나가기 전에 주머니 확인하기입니다.
- 현관을 나설 때 휴대폰과 열쇠, 카드키를 같이 챙기기
- 택배를 받을 때는 문이 완전히 닫히지 않게 잠깐 고정하기
- 비밀번호를 가족과 공유해 두기
- 여분 카드키 한 장을 믿을 만한 곳에 맡겨 두기
- 현관 안쪽에 임시 번호를 등록해 두는 기능이 있는지 확인하기
어렵지 않은 습관인데 한밤중에 겪는 곤란함을 많이 막아 줍니다.

# 장항동 말고 고양 어디든 갑니다
장항동 바로 옆 마두동, 백석동, 주엽동, 대화동 쪽도 같은 방식으로 다닙니다. / 고양 안이라면 동네 상관없이 24시간 출동합니다.
고양에서 다니는 동네는 [고양시 출장열쇠](goyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
