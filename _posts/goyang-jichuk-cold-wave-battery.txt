# 영하로 떨어진 아침, 번호판이 깜깜합니다
지축역 부근은 겨울 아침에 바람이 유난히 매섭게 느껴지는 곳입니다. / 출근길에 번호판을 눌렀는데 불이 들어오지 않거나 반응이 한참 늦으면 마음이 급해집니다.
이 글은 한파 때 도어락이 말을 안 듣는 이유와 집에서 해 볼 일, 그리고 출장 요청 전 준비를 겨울 상황에 맞춰 적은 것입니다. / 도움이 필요하면 [고양 출장열쇠](goyang.html)로 연락 주세요.
@ 지축동 한파 도어락 먹통

# 추우면 배터리가 먼저 약해집니다
건전지는 온도가 떨어지면 내는 힘이 눈에 띄게 줄어듭니다. / 평소엔 멀쩡하던 배터리도 영하에서는 번호판 불을 켜는 힘이 모자랄 수 있습니다.
따뜻한 집 안에서는 멀쩡하다가 밖에서만 안 된다면 이 때문일 가능성이 높습니다. / 이런 증상은 날이 풀리면 돌아오기도 합니다.

# 번호판이 늦게 반응할 때 해 볼 것
밖에서 번호판이 느리게 켜진다면 서두르지 말고 몇 가지를 해 보세요.
- 손으로 번호판을 감싸 잠시 데운 뒤 다시 누르기
- 번호를 천천히 한 글자씩 누르기
- 한 번 실패했다면 몇 초 쉬었다가 다시 시도하기
- 비상 전원 단자가 있다면 보조 배터리로 잠깐 전원 넣기
비상 단자가 있는 제품은 겉에 작은 접점이 있습니다. / 방법을 모르겠다면 무리하지 마세요.
@ 지축동 번호판 데워서 다시 누르기

# 문이 얼어붙어서 안 열리는 경우
번호는 눌렸고 모터 소리도 나는데 문이 안 열릴 때가 있습니다. / 문틀과 문 사이에 결로가 얼어붙었거나 문 가장자리 고무가 달라붙은 경우입니다.
- 억지로 잡아당기지 말고 손바닥으로 문 가장자리를 가볍게 눌러 보기
- 따뜻한 수건으로 얼어붙은 부분을 감싸 녹이기
- 끓는 물을 붓는 것은 피하기 (문틀과 부품이 상할 수 있음)
뜨거운 물은 금속이 급하게 늘어나 변형될 위험이 있고, 다시 얼어 더 단단히 붙기도 합니다. / 천천히 데우는 방법이 안전합니다.

# 열쇠 구멍이 얼었다면
열쇠 구멍 속 수분이 얼면 열쇠가 들어가지 않거나 돌아가지 않습니다. / 열쇠를 억지로 돌리면 부러질 수 있으니 힘을 주지 마세요.
열쇠를 손으로 잠시 따뜻하게 하고 천천히 넣어 보는 정도가 안전한 시도입니다. / 그래도 안 되면 [출장 열쇠](key-call.html)를 요청해 상태를 확인받으세요.
부러진 열쇠 조각이 안에 남으면 일이 커지니 조심하세요.
@ 지축동 얼어붙은 열쇠 구멍

# 집 안에서는 열리는데 밖에서만 안 될 때
안쪽 손잡이로 열리는지 확인해 보세요. / 안에서는 열리고 밖에서만 안 된다면 전원이나 번호판 문제일 가능성이 큽니다.
안에서도 안 열린다면 문 자체가 얼어붙었거나 데드볼트 쪽에 문제가 있는 것입니다. / 이 경우는 억지로 하지 말고 연락 주세요.

# 새 배터리로 바꿀 때 주의할 점
겨울에는 배터리 선택도 중요합니다. / 추위에 강한 제품이 있고 약한 제품이 있습니다.
- 오래 보관한 배터리는 쓰지 않기
- 새 배터리 여러 개를 한꺼번에 같은 종류로 맞추기
- 쓰던 것과 새것을 섞지 않기
- 극 방향을 확인하고 단단히 끼우기
교체 후 번호판이 켜지는지, 문이 잘 열리고 잠기는지 시험해 보세요. / 문을 연 채로 시험해야 안전합니다.
@ 지축동 도어락 배터리 교체

# 한파 전에 미리 해 두면 좋은 것
- 배터리 잔량 알림이 뜨면 미루지 않고 바꾸기
- 비상 전원 단자 위치를 미리 확인하고 보조 배터리 챙겨 두기
- 열쇠 구멍이 있다면 예비 열쇠를 안전한 곳에 두기
- 문틀 고무가 딱딱해졌다면 부드러운 윤활제로 관리하기
- 가족에게 한파 때 도어락이 느려질 수 있다고 알려 두기
이 정도만 해 두어도 새벽에 문 앞에서 떠는 일이 많이 줄어듭니다.

# 새벽에 연락할 때 알려 주세요
추운 날 밖에서 오래 기다리는 일은 몸에 좋지 않습니다. / 연락하시면 위치와 상황을 짧게 여쭙고 빠르게 출동합니다.
- 지축동 안 위치와 건물 종류
- 번호판이 켜지는지 꺼져 있는지
- 열쇠 구멍이 있는지, 열쇠가 있는지
- 집 안에 사람이나 반려동물이 있는지
- 지금 어디서 몸을 녹일 수 있는지
어디서 기다리실 수 있는지 알려 주시면 도착 시간에 맞춰 연락드리겠습니다.

# 문을 열기 전에 확인하는 것
추운 날에도 사시는 분인지 확인하는 절차는 빼지 않습니다. / 신분증 주소나 우편물, 관리사무소 확인으로 충분합니다.
확인이 끝나면 어떤 방법으로 열지 설명드리고, 비용은 그때 먼저 말씀드립니다. / 못 열면 비용을 받지 않습니다.
[이용안내](guide.html)에 진행 순서를 정리해 두었습니다.

# 열린 뒤에 같이 보는 것
열리고 나면 배터리를 새로 바꿔 드립니다. / 추위로 번호판이나 모터가 이상해진 것은 아닌지도 같이 살펴봅니다.
부품이 상했다면 [도어락 수리](doorlock-repair.html) 쪽으로, 너무 오래되었다면 [도어락 교체](doorlock-replace.html) 쪽으로 안내해 드립니다. / 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.
문을 상하지 않게 여는 방법부터 쓰고, 그게 어려울 때만 다른 방법을 설명드리고 진행합니다.

# 자주 묻는 질문
? 추우면 도어락이 왜 느려지나요? | 배터리가 추위에 약해지고, 문틀 고무와 부품이 굳기 때문입니다.
? 얼어붙은 문에 끓는 물을 부어도 되나요? | 권하지 않습니다. 부품이 상하거나 다시 얼 수 있어 따뜻한 수건이 안전합니다.
? 비상 단자는 어디에 있나요? | 번호판 아래나 옆에 작은 접점이 있는 제품이 있습니다. 모델 번호를 알려 주시면 확인해 드립니다.
? 배터리를 바꿨는데도 느리면요? | 부품 문제일 수 있으니 점검을 요청하세요.
? 못 열면 비용은 어떻게 되나요? | 못 열면 비용을 받지 않으며, 작업 전에 먼저 말씀드립니다.

# 지축동 추운 날에도 24시간
한파는 도어락에게도 가혹한 계절입니다. / 문이 안 열릴 때는 무리하지 말고 연락 주세요.
고양 안이면 동네를 가리지 않고 출동하고, 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다. / 문이 아예 안 열리는 상황이라면 [현관문 개문](door-open.html) 안내도 도움이 됩니다.
24시출장열쇠 전화는 010-3664-5455입니다.
