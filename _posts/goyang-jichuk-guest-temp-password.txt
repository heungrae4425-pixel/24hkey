# 지축동 새집 현관, 번호를 누구에게 얼마 동안 줄까
지축역 가까이 덕양구 새 아파트가 들어선 지축동은 입주한 지 오래되지 않은 집이 많습니다. / 입주하면서 앱 연동이나 방문자 번호 기능이 있는 도어락을 쓰게 된 집도 흔합니다.
새집에 살다 보면 생각보다 많은 사람이 현관을 드나들어야 합니다. / 가구와 가전 설치 기사, 출장 중 고양이를 봐 주는 펫시터, 맞벌이 부부 대신 손주를 봐 주시는 부모님까지 다양합니다.
이 글은 지축동에서 이런 분들께 가족 번호 대신 기간을 정한 임시 번호를 주고, 일이 끝나면 거둬들이는 방법을 정리했습니다. / 설정이 막히거나 문이 잠겼다면 [고양 출장열쇠](goyang.html)로 연락 주세요.
@ 지축동 아파트 도어락 임시 방문자 번호

# 우리 도어락에 있는 기능부터 확인
요즘 도어락은 같은 임시 번호라도 쓸 수 있는 방식이 제품마다 다릅니다. / 앱이나 설명서에서 아래 기능이 있는지 먼저 확인해 보세요.
- 한 번 쓰면 사라지는 일회용 번호
- 정한 날짜와 시간에만 열리는 기간 번호
- 정한 요일에만 쓰는 반복 번호
- 방문자 번호만 따로 지우는 기능
- 누가 언제 열었는지 남는 출입 알림
기능 이름은 제조사마다 조금씩 달라서 헷갈릴 수 있습니다. / 도어락 안쪽 몸체에 붙은 제품 이름을 사진으로 찍어 두면 사용법을 찾기 쉽습니다.

# 가구, 가전 설치 기사에게는 당일 한정
입주 초기에는 내가 집에 없는 시간에 설치 기사가 와야 하는 일이 생깁니다. / 이럴 때는 설치 당일 정해진 시간에만 열리는 번호나 일회용 번호가 가장 알맞습니다.
번호는 설치 시작 직전에 문자로 보내고, 설치가 끝났다는 연락을 받으면 바로 지우세요. / 출입 알림이 오는 제품이라면 기사가 들어가고 나간 시간도 함께 확인할 수 있습니다.
일회용 번호는 문을 한 번 열면 사라지니, 기사가 중간에 짐을 가지러 나갔다 들어와야 하는 경우에는 기간 번호가 낫습니다.

# 출장 중 고양이를 봐 주는 펫시터
며칠 집을 비우는 동안 펫시터가 하루 한두 번 드나드는 경우에는 기간 번호가 편합니다. / 출장 첫날부터 돌아오는 날까지만 열리게 맞춰 두면 따로 지우지 않아도 기간이 끝나면 쓸 수 없게 됩니다.
펫시터가 들어갈 때마다 출입 알림이 오면 반려동물을 잘 챙겨 주고 있는지도 안심하고 볼 수 있습니다. / 돌아온 날에는 기간 번호가 정말 끝났는지 앱에서 한 번 더 확인하세요.
@ 지축동 펫시터 기간 한정 도어락 번호

# 손주 봐 주시는 부모님
매주 정해진 요일에 오셔서 아이를 봐 주시는 부모님이라면 요일 반복 번호를 드리는 방법이 있습니다. / 다만 부모님은 가족이니 가족 번호를 그냥 알려 드리는 집도 많습니다.
부모님께 번호를 드릴 때는 번호를 바꾸는 날 함께 알려 드려야 한다는 점만 기억해 두세요. / 번호를 바꾸고 깜빡해서 부모님이 아이를 데리고 문 앞에서 기다리시는 일이 생각보다 많습니다.
번호 누르는 게 번거로우시다면 카드나 태그를 하나 등록해 드리는 것이 더 편할 수 있습니다.

# 가사도우미와 청소 서비스
입주 청소나 정기 청소 서비스를 부르는 집이라면 담당자가 바뀔 수 있다는 점을 생각해야 합니다. / 같은 업체라도 오는 사람이 바뀌면 그때마다 번호를 새로 드리는 것이 깔끔합니다.
요일 반복 번호를 쓰고 있다면 서비스를 그만두는 날 그 번호를 바로 지우세요. / 업체와 계약을 끝낸 뒤에도 번호가 살아 있으면 정리가 안 된 상태입니다.

# 임시 번호를 보낼 때 지킬 것
- 번호는 쓸 사람에게만, 문자로 따로 보내기
- 가족 단체방에 방문자 번호를 올리지 않기
- 동 호수와 번호를 같은 문자에 함께 적지 않기
- 쓰고 나면 받은 분께 문자를 지워 달라고 부탁하기
- 공동현관 출입이 필요한지 미리 확인하기
지축동 새 아파트는 공동현관을 번호나 호출로 여는 곳이 많습니다. / 방문자가 공동현관에서 막히지 않게 출입 방법도 함께 알려 주시거나, 도착 시간에 맞춰 호출을 열어 주세요.

# 앱 연동이 끊겼을 때를 대비하기
기간 번호나 원격 열림은 휴대폰과 도어락 연결이 살아 있어야 바로 쓸 수 있는 경우가 많습니다. / 와이파이가 끊기거나 허브 전원이 빠지면 방문자 앞에서 문이 안 열리는 일이 생깁니다.
중요한 방문이 있는 날에는 하루 전에 앱에서 도어락 연결 상태를 확인해 두세요. / 연결이 불안하다면 앱 대신 도어락 본체에서 방문자 번호를 직접 등록해 두는 편이 확실합니다.

# 방문이 끝난 뒤 정리하는 순서
- 방문자 번호나 기간 번호 지우기
- 출입 알림에서 마지막 출입 시간 확인
- 맡겼던 카드나 태그 돌려받기
- 앱에서 공유했던 사용자 권한 끊기
- 돌려받지 못한 태그가 있으면 태그 전체를 지우고 가족 것만 다시 등록
지우는 걸 자꾸 잊는다면 번호를 만들 때 지우는 날을 휴대폰 알림으로 함께 맞춰 두세요.

# 설정하다 문이 잠겼다면
본체에서 번호를 등록하다가 순서가 꼬여 가족 번호까지 안 먹히는 경우가 가끔 있습니다. / 등록은 문을 열어 둔 상태에서 하고, 닫기 전에 가족 번호와 방문자 번호를 모두 한 번씩 시험해 보세요.
이미 밖에서 막혔다면 서너 번만 시도하고 멈춘 뒤 연락 주세요. / 동과 호수, 지축역에서 어느 쪽인지, 공동현관 출입 방법을 알려 주시면 도착이 빨라집니다.

# 거주 확인과 비용 안내
문을 열거나 도어락 설정을 바꾸는 일은 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다. / 입주 직후라 신분증 주소가 예전 집이라면 분양 계약서나 임대차 계약서로도 됩니다.
펫시터나 도우미 혼자 계실 때는 문 열기를 진행하지 않습니다. / 사시는 분과 통화로 확인이 되어야 시작합니다.
하는 일을 보고 비용을 먼저 말씀드리고 동의하실 때 진행합니다. / 문을 열어야 하는데 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 있습니다.

# 기능이 없는 도어락이라면
방문자 번호를 따로 넣을 수 없는 제품이라면 방문이 있을 때마다 가족 번호를 바꿔야 합니다. / 고장이라면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 기능이 아예 없다면 [도어락 교체](doorlock-replace.html)를 생각해 볼 만합니다.
@ 고양 지축동 방문자 번호 도어락 교체 상담

# 지축동 말고 고양 어디든
지축동과 맞닿은 삼송동, 원흥동부터 화정동, 행신동, 식사동, 일산 쪽 주엽동, 백석동까지 고양 어디든 24시간 출동합니다.
고양에서 다니는 동네는 [고양시 출장열쇠](goyang.html), 그 밖의 지역은 [출장 지역](area.html)에서 보세요.
