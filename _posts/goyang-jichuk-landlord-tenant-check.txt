# 지축동 전월세 집, 도어락 이야기는 누가 먼저 꺼낼까
지축역 가까이 덕양구 새 아파트가 들어선 지축동에는 집주인이 따로 살고 세입자가 사는 전월세 집도 많습니다. / 입주 때 달려 있던 도어락을 그대로 쓰다 고장이 나거나, 세입자가 다른 기능의 도어락으로 바꾸고 싶어지는 때가 옵니다.
이럴 때 누가 부르고 누가 비용을 낼지를 두고 서로 말을 꺼내기 어색해하는 경우가 많습니다. / 미리 몇 가지만 맞춰 두면 고장이 난 날에도 서로 마음 상할 일이 줄어듭니다.
이 글은 지축동 전월세 집에서 집주인과 세입자가 도어락 문제를 정리할 때 확인해 두면 좋은 것을 적었습니다. / 비용 부담이나 원상 복구 같은 부분은 계약 내용과 서로의 합의에 따라 다르니, 여기서는 정리하는 순서만 다룹니다. / 문이 잠긴 급한 상황이라면 [고양 출장열쇠](goyang.html)로 바로 연락 주세요.
@ 지축동 전월세 아파트 도어락 집주인 세입자

# 입주 날 현관 사진 한 장
세입자가 들어오는 날 현관 도어락 앞면과 안쪽 몸체를 사진으로 남겨 두세요. / 번호판이 바랬는지, 몸체에 금이 갔는지, 잠금이 한 번에 되는지를 날짜와 함께 기록해 두는 것입니다.
집주인도 같은 사진을 받아 두면 좋습니다. / 나중에 고장이 났을 때 입주 때부터 그랬는지, 사는 동안 생겼는지를 두고 서로 기억에만 기대지 않아도 됩니다.
도어락 제품 이름과 함께 받은 카드, 비상 열쇠 개수도 함께 적어 두세요. / 문을 열고 닫는 짧은 영상 하나를 더해 두면 잠금 소리까지 남길 수 있습니다.

# 계약서에 도어락 이야기가 있는지
계약서 특약에 현관 도어락이나 시설물 수리에 관한 내용이 있는지 먼저 살펴보세요. / 있다면 그 내용에 따르면 되고, 없다면 고장이 나기 전에 짧게라도 이야기를 나눠 두는 게 좋습니다.
어떻게 정할지는 집마다 다릅니다. / 애매한 부분은 중개하신 분께 물어보시거나 서로 문자로 정리해 남겨 두면 나중에 확인하기 쉽습니다.

# 고장이 났을 때 연락하는 순서
문이 잠겨 들어가지 못하는 상황이라면 집에 들어가는 게 먼저입니다. / 세입자가 직접 출장을 부르셔도 되고, 들어간 뒤 집주인께 상황을 알리면 됩니다.
문은 열리지만 고장 기미가 있다면 바로 고치기보다 집주인께 먼저 알리는 편이 서로 편합니다. / 이때 아래 내용을 함께 보내 주세요.
- 언제부터 어떤 증상이 있었는지
- 증상이 보이는 사진이나 짧은 영상
- 배터리를 바꿔 봤는지
- 점검이나 수리를 누가 부를지 의견
사진과 증상이 함께 가면 집주인도 판단이 쉬워집니다.
@ 지축동 도어락 고장 사진 집주인 연락

# 점검 결과는 그 자리에서 공유
출장 기사가 와서 점검하면 원인이 무엇인지 그 자리에서 설명을 들으실 수 있습니다. / 배터리 문제인지, 부품이 닳은 것인지, 문틀이 어긋난 것인지 들은 내용을 집주인께 그대로 전해 주세요.
필요하면 기사와 집주인이 직접 통화하도록 연결해 드릴 수도 있습니다. / 수리로 갈지 교체로 갈지 정하기 전에 비용을 먼저 말씀드리니, 그 내용을 함께 들으시고 결정하시면 됩니다.

# 세입자가 도어락을 바꾸고 싶을 때
지문이나 앱 연동이 되는 제품으로 바꾸고 싶은 세입자도 있습니다. / 이럴 때는 바꾸기 전에 집주인께 먼저 말씀드리고, 떼어 낸 원래 도어락을 어떻게 할지 정해 두세요.
원래 도어락을 보관했다가 퇴거할 때 되돌려 다는 방식을 택하는 집도 있습니다. / 이 경우 원래 도어락과 부속, 나사를 한 봉투에 담아 두면 다시 달 때 수월합니다.
새 도어락이 기존 구멍에 그대로 맞는지도 확인해야 합니다. / 구멍을 더 내야 한다면 문에 흔적이 남으니 집주인과 꼭 미리 이야기하세요. / 확인 방법은 [도어락 설치](doorlock-install.html)에 적어 두었습니다.

# 번호와 카드는 누가 관리하나
세입자가 사는 동안 현관 번호는 세입자가 정하고 관리하는 게 보통입니다. / 집주인이 번호를 알고 있어야 하는지는 서로 정하기 나름이지만, 사는 사람의 입장에서는 모르는 쪽이 마음 편할 수 있습니다.
급할 때를 대비해 집주인이 번호를 알고 싶어 하신다면 비상 열쇠만 맡겨 두는 방법도 있습니다. / 번호는 세입자가 바꾸고, 비상 열쇠는 집주인이 갖는 식입니다.

# 집주인이 빈집 문을 열어야 할 때
세입자가 살고 있는 집이라면 집주인이라도 세입자와 연락이 닿아야 문을 엽니다. / 출장열쇠도 이 경우 세입자 확인 없이 문을 열지 않습니다.
세입자가 나간 뒤 빈집이라면 집주인임을 보여 주는 서류로 확인하고 진행합니다.
다음 세입자가 들어오기 전 빈집 상태라면 이때가 도어락을 점검하거나 바꾸기 좋은 때입니다. / 전 세입자 번호와 카드를 모두 지우고, 새 세입자에게는 깨끗한 상태로 넘겨 주세요.
새 세입자가 들어오는 날 현관 사진을 다시 남기면 처음 이야기한 기록이 그대로 이어집니다.

# 퇴거할 때 함께 확인할 것
- 세입자 가족 지문과 카드 등록 지우기
- 번호를 집주인과 정한 번호로 바꾸거나 초기 상태로
- 받았던 카드와 비상 열쇠 개수 맞춰 돌려주기
- 앱 연동 제품이라면 세입자 계정 연결 끊기
- 바꿔 달았던 도어락이 있다면 정한 대로 원래 것 되돌리기
퇴거 날 집주인과 함께 문을 닫고 새 번호로 한 번 열어 보면 확인이 끝납니다.

# 거주 확인은 이렇게
문을 열어야 하는 경우 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 임대차 계약서, 관리사무소 확인 중 하나면 됩니다.
세입자라면 집주인 허락을 따로 받으실 필요는 없습니다. / 지금 사는 분인지만 확인되면 됩니다.

# 비용 안내 방식
문 상태와 도어락을 보고 비용을 먼저 말씀드립니다. / 들으시고 괜찮을 때 시작하고, 문을 열어야 하는데 끝내 못 열면 비용은 받지 않습니다.
누가 비용을 낼지는 집주인과 세입자가 정하신 대로 하시면 됩니다. / 진행 방식은 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.
부품만 손보면 되는 경우는 [도어락 수리](doorlock-repair.html)로, 오래돼 바꿔야 한다면 [도어락 교체](doorlock-replace.html)로 안내합니다.
@ 고양 지축동 전월세 집 도어락 수리 교체 안내

# 지축동 말고 고양 어디든
지축동과 맞닿은 삼송동, 원흥동부터 화정동, 행신동, 풍동, 일산 쪽 마두동, 대화동까지 고양 어디든 24시간 출동합니다.
고양에서 다니는 동네는 [고양시 출장열쇠](goyang.html), 그 밖의 지역은 [출장 지역](area.html)에서 보세요.
