# 주엽동 상가 건물, 여러 사람이 드나드는 문
주엽역을 중심으로 아파트 단지가 넓게 펼쳐진 주엽동에는 역 가까이 학원과 사무실, 작은 병원이 층마다 들어선 상가 건물이 많습니다. / 이런 곳의 출입문은 한 사람이 아니라 원장, 강사, 직원, 청소하시는 분까지 여럿이 함께 씁니다.
여러 사람이 쓰는 문은 고장보다 관리가 엉켜서 막히는 일이 더 잦습니다. / 누가 번호를 바꿨는지, 카드가 몇 장 나갔는지 아무도 정확히 모르는 상태가 되기 쉽습니다.
이 글은 주엽동 상가 건물 속 학원과 사무실 출입문이 안 열리거나 관리가 엉켰을 때 확인할 것을 정리했습니다. / 출입문이 막혔다면 [고양 출장열쇠](goyang.html)로 연락 주세요.
@ 주엽동 상가 건물 학원 사무실 출입문 도어락

# 아침 첫 출근자가 막혔을 때
가장 먼저 출근한 사람이 문 앞에서 막히는 경우가 가장 흔합니다. / 먼저 아래 세 가지를 확인해 보세요.
- 번호판에 불이 들어오는지
- 어제 마지막에 나간 사람이 누구인지
- 그 사람이 보조 잠금이나 안쪽 걸쇠를 걸었는지
번호판이 꺼져 있다면 배터리 방전일 가능성이 큽니다. / 바깥 아래쪽 비상 단자에 9V 건전지를 대고 번호를 눌러 보세요.
번호판은 켜지는데 안 열린다면 어제 마감한 사람에게 먼저 전화해 보세요. / 마감 때 무엇을 잠갔는지 들으면 원인이 바로 나오는 경우가 많습니다.

# 상가 건물 출입문의 사정
상가 건물 사무실 문은 철제 방화문에 도어락을 단 경우가 많습니다. / 방화문은 무겁고 도어클로저 힘이 세서 잠금쇠가 문틀에 꽉 물린 채 닫히기도 합니다.
번호는 맞는데 모터 소리만 나고 안 열린다면 문을 문틀 쪽으로 살짝 밀면서 다시 눌러 보세요. / 잠금쇠에 걸린 힘이 풀리면 열리는 경우가 있습니다.
유리문을 쓰는 학원이나 병원이라면 바닥이나 위쪽에 따로 잠금이 있는지도 함께 봐야 합니다.
@ 주엽동 사무실 방화문 도어락 잠금쇠 걸림

# 번호를 누가 바꿨는지 모를 때
여러 사람이 쓰는 문에서 번호가 갑자기 안 먹힌다면 누군가 번호를 바꿨을 가능성이 있습니다. / 관리 권한을 가진 사람이 정해져 있지 않으면 이런 일이 생깁니다.
직원 단체방에 최근 번호를 바꾼 사람이 있는지 물어보세요. / 서너 번 틀리면 입력이 막히니 여러 사람이 돌아가며 눌러 보는 건 피해 주세요.

# 카드가 몇 장 나갔는지 모른다면
학원이나 사무실은 직원마다 카드를 한 장씩 나눠 주는 곳이 많습니다. / 직원이 바뀔 때 카드를 돌려받지 못하거나, 잃어버린 카드를 지우지 않으면 지금 몇 장이 살아 있는지 알 수 없게 됩니다.
카드만 골라 지울 수 없는 제품이라면 전체를 지우고 지금 일하는 사람 몫만 다시 등록해야 합니다. / 이때 모두의 카드를 한자리에 모아 놓고 진행하세요.
등록할 때 몇 번째 카드가 누구 것인지 적어 두면 다음에 정리하기 쉽습니다. / 카드에 이름 대신 작은 번호 스티커를 붙여 두면 잃어버려도 누구 것인지 남에게 드러나지 않습니다.

# 출입 관리 담당을 정해 두기
번호 변경, 카드 등록과 삭제는 한 사람이 맡도록 정해 두는 게 좋습니다. / 담당이 아닌 사람은 바꾸지 않기로 하면 아침에 막히는 일이 줄어듭니다.
- 번호는 정해진 날에만, 담당이 바꾸기
- 바꾼 번호는 직원에게 직접 알리기
- 퇴사자가 생기면 그날 카드 회수와 삭제
- 카드 목록을 종이에 적어 금고나 서랍에 보관
- 청소하시는 분처럼 외부 인력은 따로 번호나 카드 두기

# 늦은 밤 마감 뒤 다시 들어가야 할 때
학원 수업이 끝나고 문을 잠근 뒤 휴대폰이나 지갑을 두고 나온 걸 알아채는 일도 있습니다. / 번호로 열리는 문이라면 다시 열고 들어가면 되지만, 안쪽 보조 잠금까지 걸었다면 밖에서 열 수 없습니다.
마감할 때 보조 잠금을 쓰는 곳이라면 나가기 직전 한 번 더 소지품을 확인하는 습관을 들이세요.
마감 담당이 요일마다 바뀌는 곳이라면 무엇을 어떤 순서로 잠그는지 문 안쪽에 짧게 적어 붙여 두면 좋습니다. / 누구는 보조 잠금까지 걸고 누구는 안 거는 식으로 습관이 다르면 다음 날 아침 첫 출근자가 헷갈립니다.
학생이 남아 있는지 확인하지 않고 잠그는 일이 없도록 마지막 교실 확인도 그 순서에 넣어 두세요.

# 건물 관리실과 먼저 이야기할 것
상가 건물은 관리실 운영 시간이 정해져 있는 경우가 많습니다. / 공용 출입문이나 엘리베이터가 밤에 잠기는 건물이라면 출동 기사가 사무실 앞까지 가기 어려울 수 있습니다.
연락 주실 때 건물 출입이 되는지, 누가 내려와 맞아 줄 수 있는지 함께 알려 주세요. / 건물 관리실에 미리 말해 두시면 확인도 수월합니다. / 주말에 관리실이 쉬는 건물이라면 비상 연락처를 사무실 밖에도 저장해 두세요.

# 주엽동에서 연락 주실 때
- 일산서구 주엽동, 건물 위치와 층, 호수
- 주엽역에서 어느 출구 쪽인지
- 문 종류가 방화문인지 유리문인지
- 번호판 상태, 카드도 안 되는지
- 수업이나 진료 시작 시각
문과 도어락 사진을 보내 주시면 맞는 장비를 챙겨 가기 쉽습니다.

# 사업장 확인은 서류로
사무실이나 학원 문도 쓰시는 분이 맞는지 먼저 확인합니다. / 사업자등록증, 상가 임대차 계약서, 건물 관리실 확인 중 하나면 됩니다.
직원이 연락하셨다면 대표나 원장과 통화가 되어야 진행합니다. / 서류가 안에 있다면 문을 연 뒤 바로 보여 주셔도 됩니다.

# 비용은 문을 보고 먼저 안내
문 종류와 도어락 상태를 보고 비용을 먼저 말씀드립니다. / 동의하실 때 시작하고, 끝내 못 열면 비용은 받지 않습니다.
카드 재등록이나 번호 정리만 필요한 경우에도 작업 전에 먼저 안내합니다. / 진행 방식은 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 사람이 자주 바뀌는 곳에 맞는 도어락
드나드는 사람이 많은데 카드나 번호를 하나씩 지울 수 없는 제품이라면 관리가 계속 번거롭습니다. / 고장이라면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 기능이 모자라면 사용자별로 지우고 등록할 수 있는 제품으로 [도어락 교체](doorlock-replace.html)를 생각해 볼 만합니다.
방화문 두께와 기존 구멍은 [도어락 설치](doorlock-install.html)에 적은 방법으로 미리 확인해 보실 수 있습니다.
