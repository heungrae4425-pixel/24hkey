# 마두동 현관을 천천히 한 바퀴 둘러보는 날
마두동은 정발산역 주변으로 일산 신도시 초기에 들어선 아파트와 오피스텔, 상가가 함께 있는 동네입니다. / 오래 산 집일수록 현관문은 매일 쓰면서도 가만히 들여다볼 일이 거의 없습니다.
도어락을 몇 번 바꿨는지, 지금 등록된 카드가 몇 장인지, 안전고리가 제대로 걸리는지 바로 대답하기 어려운 분이 많습니다. / 그래서 한 번쯤 날을 잡아 현관을 차분히 둘러보는 것을 권합니다.
이 글은 마두동 집 현관을 과장 없이, 생활 속에서 살펴볼 수 있는 부분만 골라 정리한 것입니다.
@ 마두동 아파트 현관 방범 점검

# 점검은 불안해서가 아니라 오래 쓰려고
현관 점검이라고 하면 뭔가 큰일이 날 것 같은 느낌이 들 수 있습니다. / 하지만 대부분은 문과 도어락을 오래, 편하게 쓰기 위한 관리에 가깝습니다.
잠금이 덜 걸리는 문, 헐거워진 안전고리, 정리 안 된 카드는 대개 작은 손질로 해결됩니다. / 미리 알아 두면 고장이 크게 번지기 전에 손볼 수 있습니다.
아래 내용을 한 번에 다 하지 않아도 괜찮습니다. / 생각날 때 하나씩 확인해 보세요.

# 문을 닫고 잠금이 한 번에 걸리는지
문을 평소처럼 닫은 뒤 잠금 소리가 한 번에 나는지 들어 보세요. / 소리가 늦거나 두세 번 걸리는 소리가 나면 잠금쇠와 문틀이 조금 어긋났을 수 있습니다.
닫힌 문을 바깥에서 가볍게 당겨 보는 것도 좋습니다. / 덜컹거림이 크다면 잠금쇠가 문틀 구멍에 깊이 들어가지 않은 것입니다.
오래된 문은 경첩이 내려앉으면서 이런 일이 생깁니다. / 경첩과 받침쇠를 조금 조정하면 다시 단단히 맞물리는 경우가 많습니다.
자동 잠금이 켜져 있는지도 이때 같이 확인해 보세요. / 문을 닫고 몇 초 지나도 잠금 소리가 없다면 설정이 꺼져 있거나 문이 끝까지 닫히지 않은 것입니다.
문이 저절로 닫히게 하는 장치가 달린 집이라면 닫히는 속도도 봐 주세요. / 마지막에 힘없이 멈춰 버리면 잠금이 걸리지 않은 채 문이 살짝 떠 있을 수 있습니다.

# 오래된 문의 작은 구멍과 틈
입주가 오래된 집 현관문에는 예전 열쇠 자리나 쓰지 않는 작은 투입구가 남아 있기도 합니다. / 도어락을 바꾸면서 생긴 빈 구멍을 덮개로만 막아 둔 집도 있습니다.
이런 자리가 헐겁게 막혀 있지 않은지 손으로 눌러 보세요. / 덮개가 흔들리거나 틈이 보이면 단단히 고정해 두는 것이 좋습니다.
문과 문틀 사이 틈이 한쪽만 유난히 넓다면 문이 틀어졌을 수 있습니다. / 바람이 새는 소리가 나는지도 함께 들어 보세요.
문 가운데 바깥을 내다보는 작은 렌즈가 있다면 헐겁게 돌아가지 않는지도 손으로 살짝 만져 보세요. / 흔들리면 안쪽에서 조여 주는 것만으로 충분한 경우가 많습니다.
@ 마두동 현관문 틈 안전고리 확인

# 안전고리와 보조 걸쇠 상태
안쪽 안전고리나 보조 걸쇠는 평소에 잘 안 쓰다 보니 나사가 풀려 있는 경우가 많습니다. / 걸어 보고 흔들어서 덜렁거리면 나사를 조여 주세요.
걸쇠가 끝까지 걸리지 않거나 걸었는데도 쉽게 빠진다면 위치가 어긋난 것입니다. / 이때는 위치를 다시 맞추거나 부품을 바꾸는 편이 낫습니다.
다만 걸쇠를 건 채로 식구가 밖에 있으면 들어올 수 없습니다. / 밤에 잘 때나 혼자 있을 때만 쓰고, 가족이 밖에 있을 때는 풀어 두세요.

# 등록된 번호와 카드 정리하기
오래 산 집일수록 누가 어떤 카드를 갖고 있는지 흐려집니다. / 예전에 이사 도와준 사람, 집을 고쳐 준 사람에게 번호를 알려 준 적이 있을 수도 있습니다.
지금 쓰는 카드를 모두 모아 개수를 세어 보세요. / 모자란 카드가 있다면 전체를 지우고 남은 카드만 다시 등록하는 것이 깔끔합니다.
번호도 이참에 한 번 바꿔 두면 좋습니다. / 식구가 다 같이 있는 날 바꾸고, 문을 연 채로 몇 번 시험해 본 뒤 닫으세요.

# 번호판에 남는 손자국
매일 같은 숫자를 누르면 그 버튼에만 손자국이나 닳은 자국이 남습니다. / 번호판을 비스듬히 비춰 보면 자주 누른 숫자가 보이기도 합니다.
가끔 마른 천으로 닦아 주고, 번호 앞뒤로 아무 숫자를 덧붙여 누르는 습관을 들여 보세요. / 많은 도어락이 이렇게 눌러도 맞는 번호가 들어 있으면 열립니다.
번호판 덮개가 있는 제품이라면 번호를 누른 뒤 덮개를 닫아 두는 것도 방법입니다.

# 오피스텔 현관은 이것을 더
마두동 오피스텔은 건물 출입문과 엘리베이터, 호실 문까지 단계가 여러 개입니다. / 건물 출입 카드를 잃어버렸다면 관리실에 알려 그 카드를 지워 달라고 하세요.
호실 문은 전에 살던 사람이 쓰던 번호나 카드가 남아 있지 않은지 확인하는 것이 먼저입니다. / 입주하면서 정리하지 않았다면 지금이라도 초기화하고 새로 등록하세요.
방법이 어렵다면 방문해서 함께 정리해 드립니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 집을 오래 비울 때
여행이나 출장으로 며칠 집을 비울 때는 떠나기 전에 배터리 상태부터 보세요. / 경고음이 날 듯한 배터리라면 미리 바꿔 두어야 돌아와서 문 앞에서 막히지 않습니다.
비상용 9V 건전지 하나를 가방에 넣어 두면 돌아온 날 번호판이 꺼져 있어도 바로 대 볼 수 있습니다. / 현관 앞에 택배나 전단이 쌓이지 않게 가까운 가족이나 이웃에게 부탁해 두면 좋습니다. / 배송을 잠시 멈추거나 보관 장소를 바꿔 두는 것도 방법입니다.

# 이상이 보이면 어떻게
점검하다 잠금이 덜 걸리거나 걸쇠가 헐겁다면 미루지 말고 손보시는 것이 좋습니다. / 혼자 조이기 어렵다면 [고양 출장열쇠](goyang.html)로 연락 주세요.
도어락 자체가 너무 오래돼 부품을 구하기 어렵다면 [도어락 교체](doorlock-replace.html)를 함께 상의드립니다. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)를 먼저 권합니다.
@ 고양 마두동 도어락 카드 등록 정리

# 점검 방문은 이렇게
문이 안 열리는 급한 상황이 아니어도 점검으로 방문합니다. / 편한 시간을 정해 연락 주시면 맞춰 갑니다.
방문하면 사시는 분인지 먼저 확인하고, 문과 도어락 상태를 보며 무엇을 손볼지 설명드립니다. / 비용은 작업 전에 먼저 말씀드리고, 동의하실 때만 진행합니다.
불필요하게 불안을 키우거나 꼭 필요하지 않은 교체를 권하지 않습니다. / 지금 상태 그대로 써도 되는 부분은 그렇다고 말씀드립니다.

# 마두동 말고 고양 곳곳
마두동과 가까운 백석동, 장항동, 주엽동과 일산서구 대화동, 탄현동, 덕양구 화정동, 원흥동, 삼송동도 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
