# 마두동 겨울 아침, 현관문 안쪽이 축축하다면
마두동은 정발산역 주변으로 일산 신도시 아파트와 오피스텔, 상가 건물이 모여 있는 동네입니다. / 입주한 지 오래된 단지가 많아 처음 달았던 도어락을 아직 쓰거나, 한 번 바꾼 뒤로 오래 쓴 집도 적지 않습니다.
날이 추워지면 현관문 안쪽 철판에 물방울이 송골송골 맺히는 집이 있습니다. / 그 물기가 도어락 몸체로 흘러내리면서 번호판이 깜빡이거나 혼자 삑삑 울리기 시작합니다.
이 글은 마두동 집에서 결로와 습기 때문에 도어락이 이상해졌을 때 구분하는 법과 말리는 요령, [고양 출장열쇠](goyang.html) 점검을 받을 시점을 정리했습니다.
@ 마두동 현관문 결로 도어락 습기

# 결로는 어디서 생기나
겨울에는 바깥은 차갑고 집 안은 따뜻합니다. / 그 경계에 있는 현관문이 차가워지면 집 안의 따뜻하고 습한 공기가 문에 닿아 물방울로 변합니다.
요리를 많이 하거나 빨래를 집 안에서 말리는 날에는 결로가 더 심해집니다. / 현관 바로 옆에 욕실이 있는 구조라면 샤워 뒤에 문이 더 축축해지기도 합니다.
복도가 바깥 공기와 바로 닿는 건물은 문이 더 차가워 결로가 잘 생깁니다. / 같은 마두동이라도 건물 구조에 따라 차이가 꽤 납니다.
오피스텔처럼 방이 작고 환기가 적은 집은 습기가 빠져나갈 곳이 적어 더 그렇습니다. / 창을 잠깐씩 열어 공기를 바꿔 주기만 해도 문에 맺히는 물이 줄어듭니다.

# 습기가 도어락에 남기는 흔적
도어락 안에는 전자 회로와 모터, 배터리가 들어 있습니다. / 물기가 스며들면 접점끼리 엉뚱하게 이어지거나 배터리 단자에 녹이 슬기 시작합니다.
바깥 번호판은 장마철 비바람에, 안쪽 몸체는 겨울 결로에 더 시달립니다. / 그래서 계절마다 고장 모양이 조금 다르게 나타납니다.
물기가 마르면 대부분 다시 정상으로 돌아옵니다. / 다만 같은 일이 해마다 되풀이되면 안쪽 부품이 조금씩 상해 가는 것이라 한 번은 점검이 필요합니다.

# 증상으로 습기 탓인지 가려보기
아래 증상이 있다면 습기를 먼저 의심해 볼 만합니다.
- 아침에만 번호가 잘 안 눌리고 낮이 되면 괜찮아짐
- 아무도 안 눌렀는데 혼자 소리가 남
- 번호판 불이 켜졌다 꺼졌다 반복됨
- 배터리를 바꾼 지 얼마 안 됐는데 경고음이 남
- 문 안쪽 도어락 아래에 물 자국이 있음
반대로 날씨와 상관없이 늘 같은 증상이라면 습기보다 부품 고장일 가능성이 큽니다. / 언제 증상이 나오는지 며칠 지켜보고 알려 주시면 원인을 짚기 쉽습니다.

# 문 앞에서 바로 해 볼 일
번호판과 도어락 몸체를 마른 수건으로 가볍게 닦아 주세요. / 물기가 맺힌 철판도 함께 닦아 더 흘러내리지 않게 합니다.
닦은 뒤 몇 분 기다렸다가 다시 눌러 보세요. / 그사이 현관 중문이 있다면 열어 두어 공기가 통하게 하는 것도 도움이 됩니다.
번호판이 아예 꺼졌다면 바깥 아래쪽 비상 단자에 9V 건전지를 대고 번호를 눌러 보세요. / 정발산역 주변 편의점에서 건전지를 구할 수 있습니다.
@ 마두동 도어락 번호판 마른 수건 닦기

# 말릴 때 피해야 할 것
빨리 말리려고 드라이기 뜨거운 바람을 가까이 대는 분이 있습니다. / 번호판 플라스틱이 휘거나 안쪽 부품에 무리가 갈 수 있어 권하지 않습니다.
꼭 쓰셔야 한다면 찬바람이나 약한 바람으로, 멀리서 잠깐씩만 대 주세요. / 물을 뿌려 닦거나 알코올을 많이 묻혀 문지르는 것도 피해 주세요.
배터리 칸을 열어 말리는 것은 괜찮습니다. / 이때 배터리를 빼 두었다가 완전히 마른 뒤 새것으로 넣으면 더 좋습니다.

# 장마철 마두동 현관
장마철에는 며칠씩 습한 날이 이어져 도어락 안쪽까지 눅눅해집니다. / 젖은 우산을 현관문에 기대 두거나 젖은 신발을 문 바로 앞에 두면 습기가 더 머뭅니다.
상가와 붙어 있는 건물이나 1층 현관은 빗물이 문 아래로 튀기도 합니다. / 비가 그친 뒤 번호판 아래쪽을 한 번 닦아 주는 습관이 도움이 됩니다.
장마가 끝나면 배터리 칸 접점 색이 변하지 않았는지 확인해 보세요. / 녹이 보이면 닦아 쓰기보다 점검을 받는 편이 안전합니다.

# 오래 쓴 도어락은 틈부터 약해집니다
오래된 도어락은 번호판과 몸체 사이 틈을 막는 고무가 굳어 물기를 잘 못 막습니다. / 그래서 같은 습기에도 새 제품보다 고장이 쉽게 납니다.
마두동처럼 입주가 오래된 단지에서는 이런 경우를 자주 봅니다. / 고무 부분만 손봐서 되는 경우도 있고, 부품을 구하기 어려우면 교체 이야기가 나오기도 합니다.
교체를 먼저 권하지는 않습니다. / [도어락 수리](doorlock-repair.html)로 되는지 먼저 보고, 어려울 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 말려도 안 될 때 연락하는 시점
아래 상황이라면 더 말리지 말고 연락 주세요.
- 하루 이상 말려도 같은 증상이 계속됨
- 번호판 안쪽에 김이 서리거나 물이 찬 것처럼 보임
- 문이 아예 안 열려 들어갈 수 없음
- 손잡이가 헛돌거나 잠금쇠가 반쯤만 나옴
위치와 증상을 짧게 알려 주시면 됩니다. / 오피스텔이라면 건물 출입이 되는지도 같이 말씀해 주세요.

# 출동하면 확인부터, 비용은 그다음
문을 열어야 하는 상황이면 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
습기가 원인이면 말리고 닦는 점검만으로 끝나는 경우도 많습니다. / 부품을 바꿔야 할 때는 바꾸기 전에 먼저 말씀드리고, 끝내 못 열면 비용은 받지 않습니다.
@ 고양 마두동 도어락 습기 오작동 점검

# 열고 나서 보는 곳
문이 열리면 번호판 반응과 모터 소리, 잠금쇠 움직임을 여러 번 시험합니다. / 배터리 칸 접점과 몸체 아래쪽 물 자국도 같이 봅니다.
물기가 남아 있으면 닦고 말린 뒤 새 배터리를 넣어 드립니다. / 결로가 심한 집이라면 문 안쪽 관리 요령도 함께 말씀드립니다.
진행 순서는 [이용안내](guide.html)에, 문 여는 과정은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 현관 습기 줄이는 생활 요령
- 겨울 아침 현관문 안쪽 물방울을 마른 수건으로 닦기
- 요리나 샤워 뒤 환기를 잠깐이라도 하기
- 젖은 우산과 신발은 문에서 떨어뜨려 두기
- 장마 전과 겨울 전에 배터리를 한꺼번에 교체
- 경고음이 나면 그날 바로 배터리 갈기
작은 습관이지만 해마다 반복되는 습기 고장을 꽤 줄일 수 있습니다.

# 마두동에서 일산, 덕양까지
마두동 옆 백석동, 장항동, 주엽동, 대화동 같은 일산 쪽과 화정동, 행신동, 삼송동 같은 덕양구도 다닙니다. / 고양에서 다니는 동네는 [고양시 출장열쇠](goyang.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
