# 걱정보다 확인, 풍동 현관 한 바퀴
풍동은 일산동구에 속한 동네로, 신도시 아파트 단지와 오래된 단독주택, 빌라가 함께 있는 곳입니다. / 같은 동네라도 아파트는 현관문 하나, 주택은 대문과 현관과 창문까지 챙길 곳이 다릅니다.
현관 방범이라고 하면 거창하게 들리지만 실제로 할 일은 단순합니다. / 문이 제대로 닫히고 잠기는지, 번호가 새어 나가지 않는지, 생활 습관에 빈틈이 없는지 보는 정도입니다.
이 글은 풍동 집에서 문 안쪽 5분, 문 바깥 5분, 집 둘레 5분으로 나눠 직접 둘러보는 순서를 정리했습니다. / 대단한 장비 없이 손과 눈으로 하는 점검입니다.
@ 풍동 현관 방범 셀프 점검

# 시작 전에, 지금 우리 집 문을 떠올려 보세요
점검을 시작하기 전에 우리 집 현관이 어떤 구성인지 적어 두면 빠뜨릴 일이 없습니다.
- 도어락 방식: 번호만, 번호와 카드, 지문
- 보조키나 안전 걸쇠가 있는지
- 주택이라면 대문 잠금 방식과 담 높이
도어락을 언제 달았는지도 대략 떠올려 보세요. / 오래 쓴 제품은 기능보다 부품 상태를 더 신경 써서 봐야 합니다.

# 안쪽 5분, 문이 끝까지 닫히는지
문을 활짝 열었다가 손을 떼고 저절로 닫히게 두세요. / 끝까지 닫히고 잠기는 소리가 나는지 귀를 기울입니다.
마지막에 툭 걸려서 살짝 떠 있다면 도어클로저 속도나 경첩 처짐 문제입니다. / 겉으로는 닫힌 것 같아도 걸쇠가 덜 들어가 있으면 잠긴 게 아닙니다.
풍동 주택가처럼 오래된 문은 처짐이 조금씩 진행되니 한 번에 확인해 두세요. / 문을 닫은 뒤 손잡이를 바깥에서 살짝 당겨 보아 꿈쩍하지 않으면 제대로 잠긴 것입니다.

# 안쪽 5분, 자동 잠금과 이중 잠금 설정
대부분 도어락은 문이 닫히면 저절로 잠기는 자동 잠금이 있습니다. / 이사하거나 배터리를 갈면서 수동으로 바뀌어 있는 집도 있으니 확인해 보세요.
밤에 잘 때나 혼자 있을 때 쓰는 이중 잠금 기능도 찾아보세요. / 안에서 버튼을 누르면 밖에서 번호를 눌러도 열리지 않게 하는 기능입니다.
다만 이중 잠금은 가족이 모두 들어온 뒤에만 쓰세요. / 늦게 오는 가족이 있는데 걸어 두면 그 가족이 문 앞에서 막힙니다.
@ 풍동 아파트 현관 도어락 자동 잠금 설정 확인

# 안쪽 5분, 등록된 번호와 카드 세기
도어락에 등록된 번호와 카드가 몇 개인지 알고 계신가요. / 이사 온 뒤 정리하지 않았다면 이전에 살던 분 것이 남아 있을 수 있습니다.
카드나 태그를 쓰는 집이라면 지금 갖고 있는 장수를 세어 보세요. / 잃어버린 것이 있다면 등록을 모두 지우고 남은 것만 다시 넣는 것이 깔끔합니다.
가족 외에 번호를 아는 사람이 있었다면 이참에 번호를 바꾸세요. / 바꾼 뒤에는 가족이 모두 한 번씩 눌러 보게 합니다.

# 바깥 5분, 번호판과 열쇠 구멍 보기
이제 문을 닫고 밖으로 나가 보세요. / 번호판을 비스듬히 비춰서 몇몇 숫자만 손때가 짙게 남았는지 확인합니다.
손자국이 한쪽에 몰려 있다면 번호판을 닦고, 앞뒤에 아무 숫자를 더 눌러도 열리는 기능이 있는지 찾아보세요. / 손자국만으로 번호를 짐작하기 어렵게 만드는 방법입니다.
보조키 열쇠 구멍 둘레에 긁힌 자국이 새로 생겼는지도 봐 둡니다. / 대부분은 열쇠를 넣다 생긴 평범한 자국이지만 평소와 다르다고 느껴지면 사진을 남겨 두세요.

# 바깥 5분, 문틈과 걸쇠 자리
문이 닫힌 상태에서 문과 문틀 사이 틈을 위에서 아래로 훑어봅니다. / 한쪽만 유난히 벌어져 있다면 문이 처졌거나 틀어진 것입니다.
틈이 넓으면 걸쇠가 문틀 구멍에 깊이 들어가지 못합니다. / 이런 문은 [도어락 수리](doorlock-repair.html)나 경첩 조정으로 맞춰 두는 것이 좋습니다.
문 아래쪽 틈으로 바깥 빛이 크게 보이는지도 함께 보세요. / 방범보다는 단열 문제지만 문이 틀어졌다는 신호이기도 합니다.

# 집 둘레 5분, 주택이라면 대문과 창
풍동 단독주택이라면 현관만큼 대문과 1층 창문이 중요합니다. / 대문이 끝까지 닫히는지, 잠금 걸쇠가 녹슬어 헐겁지 않은지 봐 주세요.
1층 창문은 잠금 레버가 끝까지 걸리는지 확인합니다. / 레버가 헛돌거나 반만 걸린다면 창 잠금장치를 손볼 때입니다.
담이나 대문 옆에 발 디딜 만한 물건을 쌓아 두지 않는 것도 작은 대비가 됩니다. / 화분이나 상자는 담에서 조금 떨어뜨려 두세요.
@ 풍동 단독주택 대문 창문 잠금 점검

# 집 둘레 5분, 아파트라면 생활 습관
아파트는 현관 밖 복도와 공동현관을 같이 씁니다. / 택배 상자가 문 앞에 며칠씩 쌓여 있으면 집이 비어 있다는 표시가 됩니다.
- 택배는 되도록 그날 들여놓기
- 현관문 옆에 번호를 적은 메모 붙이지 않기
- 공동현관 번호를 아무에게나 알려 주지 않기
- 오래 집을 비울 땐 가까운 가족에게 한 번씩 들러 달라고 부탁하기
겁먹을 일은 아니고, 한 번 습관이 들면 따로 신경 쓸 필요가 없는 것들입니다.

# 오래 집을 비우기 전날 할 일
여행이나 명절로 며칠 집을 비운다면 떠나기 전날 현관을 한 번 더 봐 주세요. / 배터리가 얼마 남지 않았다면 이때 갈아 두는 것이 가장 좋습니다.
비어 있는 동안에도 도어락은 조금씩 전기를 써서, 돌아온 날 번호판이 꺼져 있는 일이 생깁니다. / 지갑에 9V 건전지 하나를 넣어 가면 돌아와서 당황할 일이 줄어듭니다.
가까운 가족에게 집을 비운다는 것과 돌아오는 날을 알려 두세요. / 우편물이나 택배를 대신 들여놓아 달라고 부탁하면 문 앞이 깔끔하게 유지됩니다.
@ 풍동 여행 전 현관 도어락 배터리 점검

# 점검하다 손볼 곳이 보이면
배터리 경고음이 나면 그날 모두 새것으로 갈아 주세요. / 번호판 일부가 잘 안 눌리거나 잠금 소리가 약하다면 부품을 점검받을 때입니다.
도어락이 너무 오래됐거나 원하는 기능이 없다면 [도어락 교체](doorlock-replace.html)를 생각해 볼 수 있습니다. / 다만 고쳐 쓸 수 있는 것은 먼저 고쳐 쓰는 쪽을 권합니다.
문이 처져서 걸쇠가 덜 들어간다면 경첩부터 맞추는 것이 순서입니다.

# 점검 방문은 이렇게 진행됩니다
직접 보기 어렵다면 점검만 요청하셔도 됩니다. / 방문하면 사시는 분인지 신분증이나 우편물로 먼저 확인하고, 문과 도어락 상태를 함께 봅니다.
손볼 곳이 있으면 무엇을 할지와 비용을 손대기 전에 말씀드립니다. / 동의하실 때만 진행하고, 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.
문이 잠겨서 부르신 경우라면 [현관문 개문](door-open.html) 방식으로 덜 상하게 열고, 끝내 못 열면 비용은 받지 않습니다.

# 풍동 말고 고양 어디든
일산동구 식사동, 백석동, 마두동, 장항동부터 덕양구 화정동, 행신동, 일산서구 주엽동, 대화동까지 고양 전 지역을 다닙니다. / 다니는 동네는 [고양시 출장열쇠](goyang.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
