# 풍동 오래된 집 현관문이 말을 안 들을 때
풍동은 일산 신도시 아파트 단지와 오래된 단독주택, 빌라가 함께 섞여 있는 동네입니다. / 주택가 쪽 집들은 현관문이 십 년 이상 같은 자리에서 쓰이는 경우가 많습니다.
문이 처음엔 가볍게 열리다가 어느 날부터 손잡이를 돌려도 걸쇠가 안 빠지고, 밀거나 당겨야 열리는 일이 생깁니다. / 이럴 때는 도어락 고장이 아니라 문틀과 경첩이 처진 것이 원인인 경우가 많습니다.
이 글은 풍동에서 오래된 문이 말을 안 들을 때 확인할 것과 [고양 출장열쇠](goyang.html)가 점검하는 순서를 정리했습니다.
@ 풍동 오래된 현관문 문틀 처짐 점검 출장열쇠

# 문이 처지는 이유부터 알아봅니다
현관문은 매일 몇 번씩 여닫히며 경첩에 무게가 실립니다. / 경첩 나사가 조금씩 헐거워지면 문이 아래로 내려앉아 문틀과 맞는 위치가 틀어집니다.
여름에는 습기로 문이 부풀고 겨울에는 마르면서 틈이 생기는 일도 반복됩니다. / 이런 계절 변화가 쌓이면 걸쇠가 문틀 구멍에 정확히 들어가지 않게 됩니다.
문이 한쪽으로 기운 상태에서 억지로 닫으면 도어락 속 부품까지 상하게 됩니다.
문틀이 처졌다는 걸 모르고 도어락만 여러 번 바꾸는 경우도 있어서, 원인을 먼저 찾는 일이 중요합니다. / 처짐 정도가 가벼우면 나사 조정만으로 해결되는 경우도 많습니다.

# 문틀 처짐을 알아보는 방법
집 안에서 스스로 확인할 수 있는 간단한 신호가 있습니다. / 아래 항목을 하나씩 살펴보세요.
- 문을 닫았을 때 위쪽 틈이 아래쪽보다 넓거나 좁은지
- 문 아랫부분이 바닥이나 문턱에 끌리는지
- 걸쇠가 문틀 구멍에 걸리는 소리가 나는지
- 경첩 나사가 튀어나오거나 헐거워 보이는지
- 문을 열 때 삐걱 소리가 크게 나는지
이 중 두세 가지 이상 해당되면 문 자체가 틀어진 경우일 가능성이 큽니다.

# 문을 밀면서 열어 보세요
문틀이 처져 걸쇠가 걸린 경우에는 문을 살짝 안쪽으로 밀면서 손잡이를 돌리면 열리기도 합니다. / 걸쇠에 걸린 힘이 풀리면서 빠지는 원리입니다.
반대로 문을 당기면서 돌려 보는 것도 방법입니다. / 어느 방향이 더 잘 맞는지는 집마다 다르니 두 가지를 차분하게 번갈아 해보세요.
이렇게 해서 열리면 그날 바로 경첩과 문틀 점검을 받아 두는 걸 권합니다. / 그냥 두면 같은 일이 점점 더 자주 생기고, 어느 날은 열리지 않게 됩니다.

# 억지로 열려다 생기는 문제
화가 나서 손잡이를 세게 돌리거나 문을 발로 차는 분이 있습니다. / 이러면 도어락 안의 걸쇠 축이 휘거나 부러져 도어락을 통째로 바꿔야 하는 상황이 됩니다.
쇠 막대나 드라이버로 틈을 벌리면 문틀이 파이고 페인트가 벗겨집니다. / 문틀이 상하면 복구 비용이 커지니 손대지 마시고 기다려 주세요.
@ 풍동 주택 현관문 도어락 점검 출장 개문

# 오래된 도어락과 문의 궁합
오래된 문에 나중에 새로 단 도어락이 맞지 않아 헐거운 경우도 많습니다. / 문 두께나 구멍 위치가 달라 억지로 맞춰 단 제품은 오래 못 갑니다.
손잡이 일체형 도어락은 무게가 있어서 문이 처지는 데 영향을 주기도 합니다. / 이런 경우 도어락만 바꾸는 것보다 문 상태를 함께 보는 것이 중요합니다.
문 두께와 보조키 구멍은 [도어락 설치](doorlock-install.html) 안내에 정리해 두었습니다.

# 전화하실 때 말씀해 주실 것
오래된 주택은 구조가 제각각이라 상황 설명이 정확할수록 준비가 빨라집니다. / 아래 정보를 말씀해 주세요.
- 풍동 어디쯤인지와 건물 종류(단독주택, 빌라, 연립)
- 문이 어느 쪽으로 처졌는지 대략적인 느낌
- 열쇠 구멍이 있는 방식인지, 번호 방식인지
- 지금 열리는지, 안 열리는지, 걸리는 정도인지
- 문 안쪽에 사람이나 반려동물이 있는지
문 전체와 경첩 쪽을 찍은 사진을 문자로 보내주시면 도움이 됩니다.

# 사시는 분인지 확인합니다
문을 여는 일이라 확인 절차는 건너뛰지 않습니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소나 집주인 확인 중 하나면 됩니다.
주택은 관리사무소가 없는 곳이 많아서 우편물이나 공과금 고지서로 확인하는 경우가 많습니다. / 신분증이 집 안에 있다면 가까운 이웃이나 집주인의 확인도 방법입니다.
확인이 어려우면 방법을 함께 찾아드립니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 알려드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없고, 경첩이나 문틀 보수가 필요하면 시작하기 전에 따로 여쭙습니다.
진행 순서는 [이용안내](guide.html)에도 정리해 두었습니다.

# 문과 문틀을 최대한 상하지 않게 엽니다
문이 처진 경우에도 덜 상하는 방법부터 차례로 시도합니다. / 걸쇠를 풀고 문 위치를 조금씩 맞춰 가며 여는 방식을 먼저 써봅니다.
도어락을 분해해야 할 때도 원래 상태로 다시 조립할 수 있게 진행합니다. / 작업 중에 바꿔야 할 부품이 보이면 만지기 전에 말씀드립니다.
어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
@ 비파손 개방 풍동 문틀 도어락 점검

# 열린 뒤에 하는 점검
문이 열리면 경첩 나사 상태와 문틀과의 간격을 같이 봅니다. / 걸쇠가 문틀 구멍 한가운데 들어가는지 확인하고 필요하면 위치를 조정합니다.
경첩 나사만 조여서 해결되는 경우도 많고, 구멍이 헐거워 나사가 못 박히면 더 굵은 나사로 바꾸는 방법도 있습니다. / 어떤 쪽이 맞는지는 현장에서 보고 말씀드립니다.
도어락이 이미 노후했다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 비교해서 안내합니다.

# 문을 오래 쓰는 관리 요령
작은 관리만 해도 문틀 처짐이 훨씬 늦춰집니다. / 계절이 바뀔 때 한 번씩 점검하는 습관이 좋습니다.
- 경첩 나사를 1년에 한두 번 조여 주기
- 경첩에 윤활제를 소량만 바르기
- 문 아랫부분이 바닥에 끌리는지 가끔 확인하기
- 도어락 배터리를 해가 바뀔 때 전부 교체하기
- 문이 덜 닫힐 때는 방치하지 않고 바로 점검 받기
특히 문이 덜 닫히는 증상을 그냥 두면 어느 날 갑자기 열리지 않게 됩니다.

# 풍동 말고 고양 어디든 갑니다
풍동 가까운 식사동, 마두동, 장항동, 일산동 쪽도 같은 방식으로 다닙니다. / 고양 안이라면 동네 상관없이 24시간 출동합니다.
고양에서 다니는 동네는 [고양시 출장열쇠](goyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
