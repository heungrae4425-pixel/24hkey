# 삼송동에서 전화 버튼 누르기 전 한숨 돌리기
삼송동은 삼송역을 중심으로 새로 지은 아파트가 모여 있고, 바깥쪽으로 상가 건물과 덕양구 주택가가 이어지는 동네입니다. / 문이 막힌 순간에는 마음이 급해 일단 전화부터 걸게 됩니다.
그런데 통화 전에 몇 가지만 정리해 두면 설명이 짧아지고, 맞는 장비를 챙겨 가서 도착 뒤 작업도 빨라집니다. / 길어야 몇 분이면 되는 준비입니다.
이 글은 삼송동 집이나 가게 문이 막혔을 때 [고양 출장열쇠](goyang.html)를 부르기 전에 챙겨 두면 좋은 것을 순서대로 적었습니다.
@ 삼송동 출장열쇠 요청 전 준비

# 지금 막힌 문에 이름 붙이기
먼저 어떤 문이 막혔는지 한마디로 정리해 보세요. / 집 현관인지, 아파트 공동현관인지, 주택 대문인지, 가게 출입문인지에 따라 준비가 다릅니다.
같은 집 안에서도 현관 도어락인지 보조키인지 방문인지 나눠 주시면 좋습니다. / "현관 도어락이 안 열려요"와 "현관 보조키가 잠겼어요"는 챙겨 가는 장비가 다릅니다.
공동현관처럼 여러 세대가 쓰는 문은 관리하는 쪽 확인이 먼저일 때가 많습니다. / 이 경우는 관리사무소에 먼저 연락해 보시는 편이 빠릅니다.

# 번호판을 한 번 만져 보고 말로 옮기기
번호판에 손을 대 보고 불이 들어오는지 확인하세요. / 켜지는지, 안 켜지는지, 켜졌다 꺼지는지를 그대로 말씀해 주시면 됩니다.
번호를 눌렀을 때 나는 소리도 기억해 두세요. / 맞는 번호인데 모터 소리만 나는지, 틀렸다는 경고음이 나는지, 아무 소리도 없는지가 원인을 짚는 단서가 됩니다.
여러 번 눌러 보지는 마세요. / 서너 번 틀리면 입력이 막혀 기다려야 하는 시간이 생깁니다.
카드나 지문을 함께 쓰는 제품이라면 그쪽도 반응이 없는지 한 번만 확인해 주세요. / 모든 방식이 다 안 된다면 전원 쪽, 하나만 안 된다면 그 부품 쪽을 먼저 의심합니다.

# 도어락 사진은 앞과 옆 두 장
휴대폰이 있다면 도어락 바깥 모습을 정면에서 한 장 찍어 주세요. / 번호판 모양과 손잡이 형태가 잘 보이면 됩니다.
가능하면 비스듬히 옆에서 한 장 더 찍어 주세요. / 도어락 두께와 보조키가 같이 보이면 준비가 훨씬 정확해집니다.
복도가 어두우면 휴대폰 손전등을 켜고 찍으시면 됩니다. / 사진을 못 찍어도 괜찮으니 모양만 말로 알려 주세요.
@ 삼송동 도어락 사진 문자 전송

# 새 아파트라면 공동현관과 차량 등록
삼송동 새 아파트는 공동현관과 주차장 출입이 따로 관리되는 경우가 많습니다. / 기사가 공동현관을 지나야 집 앞까지 올 수 있으니 출입 방법을 미리 알려 주세요.
방문 차량을 미리 등록해야 하는 단지라면 통화할 때 말씀해 주세요. / 관리사무소나 경비실에 미리 알려 두시면 정문에서 기다리는 시간이 줄어듭니다.
단지 이름과 동, 호수를 정확히 알려 주시는 것이 가장 중요합니다. / 동 번호가 많은 단지는 삼송역 쪽인지 반대쪽인지 방향을 함께 말씀해 주셔도 좋습니다.

# 주택가라면 대문과 골목 설명
주택가는 대문을 지나야 현관이 나오는 집이 많습니다. / 대문이 열려 있는지, 대문도 잠겼는지 먼저 알려 주세요.
골목이 좁아 차가 들어가기 어렵다면 차를 댈 수 있는 큰길이나 눈에 띄는 건물을 같이 알려 주시면 좋습니다. / 집 앞에 나와 계실 수 있다면 그 자리를 말씀해 주세요.
상가 건물이라면 건물 이름과 층, 셔터가 있는지도 함께 알려 주세요. / 가게 문이라면 영업을 시작해야 하는 시각을 말씀해 주시면 그에 맞춰 서두릅니다.
가게 문은 사장님이나 임차인이라는 확인이 필요합니다. / 사업자 등록증 사진이나 임대 계약서를 휴대폰에서 미리 찾아 두세요.

# 집 안 사정은 가장 먼저
아이가 혼자 안에 있거나, 반려동물만 있거나, 불이나 가스레인지를 켜 두고 나왔다면 통화 첫마디에 말씀해 주세요. / 이런 경우는 순서를 앞당겨 서둘러 출동합니다.
아이가 안에 있다면 문 너머로 계속 말을 걸어 안심시켜 주세요. / 위급하다고 느껴지면 119에 먼저 연락하시는 것이 맞습니다.
어르신이 혼자 계신 집 문이 안 열린다며 가족이 대신 연락하시는 경우도 있습니다. / 안에서 대답이 없거나 몸이 불편하신 것 같다면 그 역시 119에 먼저 알리시고, 그다음 저희에게 연락 주세요.

# 확인 자료가 어디 있는지
문을 열기 전에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 그렇다고 미리 말씀해 주세요. / 문을 연 직후 바로 보여 주시는 방식으로 진행합니다.
새로 입주해 신분증 주소가 바뀌지 않았다면 계약서 사진이나 입주 안내 문자도 쓸 수 있습니다. / 휴대폰에서 미리 찾아 두면 현장에서 시간이 줄어듭니다.

# 기다리는 동안 해도 되는 일
번호판이 꺼져 있다면 9V 건전지를 구해 바깥 비상 단자에 대 보는 것은 괜찮습니다. / 삼송역 주변이나 단지 상가 편의점에서 구할 수 있습니다.
가족에게 연락해 번호를 바꿨는지, 여분 카드가 있는지 물어보는 것도 좋습니다. / 기다리는 사이 해결되면 연락 주시면 됩니다.
추운 날이나 늦은 밤이라면 경비실이나 가까운 가게 안에서 기다리셔도 됩니다. / 도착하면 전화드립니다.

# 기다리는 동안 하지 않을 일
드라이버나 카드로 문틈을 벌리는 일은 피해 주세요. / 문틀과 도어락이 상하면 덜 상하게 여는 방법을 쓰기 어려워집니다.
손잡이를 세게 당기거나 문을 발로 차는 것도 좋지 않습니다. / 걸쇠가 더 꽉 물리거나 손잡이 안쪽이 상할 수 있습니다.

# 도착 뒤 진행 순서
도착하면 사시는 분 확인, 문 상태 확인, 비용 안내, 동의, 작업 순서로 진행합니다. / 비용은 손대기 전에 먼저 말씀드리고, 끝내 못 열면 받지 않습니다.
여는 방법은 덜 상하는 방법부터 차례로 시도합니다. / 자세한 과정은 [현관문 개문](door-open.html), 전체 진행은 [이용안내](guide.html)에 적어 두었습니다.
@ 고양 삼송동 현관문 개문 진행 순서

# 열린 뒤 챙길 것
문이 열리면 배터리 상태와 번호 등록, 잠금이 한 번에 걸리는지를 같이 확인합니다. / 원인이 고장이라면 [도어락 수리](doorlock-repair.html)로 먼저 손보는 방법을 말씀드립니다.
이번에 찍은 도어락 사진은 지우지 말고 남겨 두세요. / 다음에 문제가 생겼을 때 바로 보내 주실 수 있습니다.
배터리 칸에 교체 날짜를 적어 두고, 비상용 9V 건전지 하나를 가방이나 차에 챙겨 두면 같은 일로 다시 전화하실 일이 줄어듭니다.

# 삼송동 말고 고양 어디서나
삼송동 옆 지축동, 원흥동과 화정동, 행신동 같은 덕양구, 백석동, 마두동, 주엽동 같은 일산 쪽도 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 사진이 꼭 있어야 출동하나요? | 아닙니다. 도어락 모양과 번호판 반응을 말로 알려 주셔도 준비해서 갑니다.
? 방문 차량 등록은 제가 해야 하나요? | 단지마다 다르니 관리사무소나 경비실에 미리 말씀해 두시면 가장 빠릅니다.
? 단지 이름만 말해도 찾아오시나요? | 동과 호수까지 알려 주셔야 헤매지 않습니다. 삼송역 기준 방향도 도움이 됩니다.
? 기다리다가 가족이 와서 열리면 어떻게 하나요? | 바로 연락 주시면 됩니다. 출발 전이든 이동 중이든 편하게 말씀해 주세요.
? 늦은 밤 공동현관을 못 지나가면요? | 경비실에 미리 말해 두시거나 공동현관 앞까지 나와 계시면 됩니다.

# 마무리
삼송동에서 출장열쇠를 부르기 전에는 막힌 문 종류, 번호판 상태, 사진 두 장, 출입 방법, 확인 자료만 정리해 두세요. / 이 몇 가지가 도착 시간과 작업 시간을 모두 줄여 줍니다.
24시출장열쇠는 늦은 밤에도 차분히 상황을 들어 드립니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
