# 앱에서 도어락이 사라졌다면
삼송역 일대에는 새로 지은 건물이 많아서 스마트폰으로 여는 도어락을 쓰는 집이 늘고 있습니다. / 그런데 어느 날 앱을 켰더니 도어락이 오프라인으로 나오거나 아예 목록에서 사라진 경우가 있습니다.
이 글은 연결이 끊겼을 때 집에서 직접 해 볼 수 있는 확인과, 출장 점검이 필요한 경우를 나눠 정리한 것입니다. / 도움이 필요하면 [고양 출장열쇠](goyang.html)에 연락 주세요.
@ 삼송동 스마트 도어락 앱 연결 끊김

# 연결이 끊기는 길은 크게 셋
증상이 언제부터 시작되었는지 기억하면 원인을 좁히기 쉽습니다. / 공유기를 만졌던 날, 앱을 업데이트한 날, 배터리를 갈았던 날 중 하나와 겹치는 경우가 많습니다.
앱과 도어락 사이에는 보통 공유기나 중계 장치가 끼어 있습니다. / 끊김은 도어락 자체, 중계 장치, 스마트폰 앱 중 한 곳에서 생깁니다.
어디가 문제인지 가려내면 해결이 훨씬 빨라집니다. / 순서대로 하나씩 제외해 나가 보세요.

# 먼저 도어락 문부터 열리는지 확인
앱으로 열리지 않는 날을 대비해 번호나 카드를 평소에도 한 가지는 기억해 두세요. / 스마트 제품일수록 기본 방법을 잊기 쉽습니다.
앱이 안 되더라도 번호나 카드로 문이 열리는지 먼저 시험해 보세요. / 열린다면 도어락 본체는 정상이고 연결만 끊긴 상태입니다.
번호판도 반응이 없다면 연결 문제가 아니라 전원이나 부품 문제입니다. / 그 경우는 [도어락 수리](doorlock-repair.html) 쪽으로 보시면 됩니다.

# 와이파이 공유기를 살펴보기
공유기 위치가 현관에서 멀수록 신호가 약해집니다. / 현관문이 철문이면 전파가 더 막히니 중계 장치를 현관 쪽에 가깝게 두는 방법도 있습니다.
중계 장치가 와이파이에 붙어 있다면 공유기가 먼저 의심 대상입니다. / 집 안 다른 기기도 인터넷이 안 되는지 확인해 보세요.
- 공유기 전원을 껐다가 잠시 뒤에 다시 켜기
- 와이파이 이름이나 비밀번호를 최근에 바꾼 적이 있는지 떠올리기
- 2.4GHz만 지원하는 기기를 5GHz에 붙이려 한 건 아닌지 보기
- 중계 장치와 공유기 사이 거리가 너무 먼지 확인하기
공유기를 바꾸었거나 이름을 바꾸었다면 도어락 쪽 연결을 다시 설정해야 합니다.
@ 삼송동 공유기와 중계 장치 확인

# 월패드와 묶여 있는 집이라면
입주한 지 오래되지 않은 건물이라면 시공 때 연동이 제대로 설정되지 않은 경우도 있습니다. / 관리 쪽 기록을 먼저 확인하면 헛걸음을 줄일 수 있습니다.
월패드와 도어락이 연동된 집이라면 월패드 쪽 점검도 필요합니다. / 월패드에서 도어락 상태가 안 보이거나 외출 모드에 연동되지 않는다면 연동 정보가 끊긴 것일 수 있습니다.
이 부분은 건물 관리 쪽 설정과 얽혀 있어 임의로 바꾸기 어렵습니다. / 먼저 관리사무소에 월패드 연동 상태를 문의해 보시는 것도 방법입니다.
도어락 쪽 문제라고 판단되면 그때 출장 점검을 요청하세요.

# 스마트폰 앱도 의심해 보기
알림이 안 와서 연결이 끊긴 줄 모르고 지내는 경우도 있습니다. / 앱의 알림 권한이 꺼져 있지 않은지 같이 확인해 보세요.
도어락이 정상이어도 앱이 말썽일 수 있습니다. / 앱 업데이트 직후에 연결이 끊기는 일이 종종 있습니다.
- 앱을 완전히 종료했다가 다시 실행하기
- 앱 권한(위치, 블루투스, 알림)이 꺼져 있지 않은지 보기
- 폰을 바꾸었다면 새 폰에서 다시 로그인해야 하는지 확인하기
- 같은 계정으로 다른 폰에 로그인되어 있지는 않은지 보기
폰 설정에서 절전 모드가 앱을 억지로 끄는 일도 있으니 예외로 지정해 두세요.
@ 삼송동 스마트폰 앱 설정 점검

# 블루투스로 쓰는 제품이라면
현관 앞에서만 잡히고 집 안에서는 안 잡히는 것이 정상인 제품도 많습니다. / 제품이 어떤 거리를 지원하는지 설명서를 먼저 읽어 보세요.
와이파이 없이 블루투스로만 연결되는 제품은 거리 제한이 있습니다. / 현관 바로 앞에서도 안 잡힌다면 폰의 블루투스 목록에서 기기를 지우고 다시 연결해 보세요.
이때 도어락 쪽에서 등록 모드를 켜야 하는 제품이 많습니다. / 방법은 모델마다 달라서 설명서를 보거나 모델 번호를 알려 주시면 같이 찾아드립니다.

# 배터리가 약하면 통신부터 끊깁니다
통신 기능은 전기를 많이 씁니다. / 배터리가 줄면 문은 열리는데 앱만 먹통이 되는 증상이 먼저 나옵니다.
새 배터리로 교체하고 연결을 다시 잡아 보세요. / 이것만으로 해결되는 경우가 생각보다 많습니다.

# 직접 해도 안 풀릴 때
현장에서는 도어락의 등록 정보와 통신 상태를 하나씩 비교하며 어디서 끊기는지 찾아봅니다. / 한 번에 해결되지 않더라도 원인을 설명드리고 다음 방법을 같이 정합니다.
위 과정을 해도 연결이 안 되면 도어락 쪽 통신 부품이나 등록 정보 문제일 수 있습니다. / 이 경우는 현장에서 직접 확인하는 편이 빠릅니다.
연락하실 때 아래를 정리해 두시면 좋습니다.
- 도어락 제조사와 모델 번호
- 앱 이름과 마지막으로 연결된 시점
- 공유기를 바꾸었는지 여부
- 월패드와 연동된 제품인지 여부
- 번호나 카드로는 문이 열리는지
사진을 보내 주시면 출동 전에 어느 정도 가늠할 수 있습니다.

# 사시는 분인지부터, 비용은 작업 전에
점검을 위해 문과 도어락을 만지는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소나 우편물, 관리사무소 확인이면 충분합니다.
작업 전에 어떤 부분을 어떻게 확인할지 설명하고, 비용은 그때 먼저 말씀드립니다. / 해결하지 못하면 비용은 받지 않습니다.
@ 삼송동 출장열쇠 스마트 도어락 점검

# 연동이 오래 안 맞는 제품은
제품이 너무 오래되어 앱이 더 이상 업데이트되지 않는 경우도 있습니다. / 이럴 때는 아무리 설정을 바꿔도 연결이 안 됩니다.
새 제품으로 바꾸는 편이 나을 때는 [도어락 교체](doorlock-replace.html)를 안내해 드립니다. / 고쳐서 쓸 수 있는 것을 굳이 바꾸자고 하지는 않습니다.
교체 전에 문 두께와 보조키, 기존 구멍 크기를 먼저 확인해야 합니다. / 이 부분은 [도어락 설치](doorlock-install.html) 안내에 정리해 두었습니다.

# 연결을 오래 안정적으로 쓰는 요령
공유기를 바꿀 계획이 있다면 도어락 연결을 다시 잡아 줄 사람을 미리 정해 두세요. / 이사나 인터넷 업체 변경 때 끊기는 경우가 가장 많습니다.
- 공유기 이름과 비밀번호를 바꿀 일이 생기면 도어락 연결을 같이 다시 잡기
- 배터리 알림이 뜨면 미루지 말고 바로 교체하기
- 앱은 자동 업데이트 대신 업데이트 후 연결부터 시험하기
- 가족 계정과 임시 비밀번호는 따로 정리하기
작은 습관만으로도 연결 끊김은 상당히 줄어듭니다.

# 자주 묻는 질문

? 공유기를 바꾸었는데 도어락은 어떻게 하나요? | 새 와이파이로 다시 연결해야 합니다. 방법은 제품마다 달라 모델 번호를 알려 주세요.
? 월패드와 연동이 끊겼는데 직접 고칠 수 있나요? | 건물 설정과 얽혀 있어 관리사무소 확인이 먼저입니다.
? 배터리만 바꿔도 연결이 돌아오나요? | 배터리가 약해서 통신만 끊긴 경우라면 돌아옵니다.
? 점검 후 못 고치면 비용을 내야 하나요? | 못 열거나 해결하지 못하면 비용을 받지 않는 기준입니다. 작업 전에 먼저 설명드립니다.
