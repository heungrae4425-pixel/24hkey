# 앱으로 열던 도어락이 갑자기 연결되지 않을 때
삼송동은 삼송역 주변으로 신축 아파트와 오피스텔이 많아 스마트 기기를 쓰는 집이 많습니다. / 휴대전화 앱이나 월패드와 연동된 도어락이 어느 날 연결되지 않아 당황하는 일이 생깁니다.
연결 문제는 대부분 도어락이 아니라 와이파이나 앱, 설정에서 시작됩니다. / 먼저 확인할 것을 순서대로 짚어 보면 해결되는 경우가 많습니다.
이 글은 삼송동에서 스마트 도어락 연결이 안 될 때 해볼 것과 [고양 출장열쇠](goyang.html)의 점검 순서를 정리했습니다.
@ 삼송동 스마트 도어락 앱 연결 점검 출장열쇠

# 먼저 와이파이부터 확인하세요
스마트 도어락은 집 와이파이나 별도의 연결 장치를 통해 앱과 이어집니다. / 공유기를 껐다 켰거나 비밀번호를 바꾸면 연결이 끊어집니다.
공유기가 정상인지 다른 기기로 인터넷이 되는지 먼저 확인해 보세요. / 공유기를 껐다 켠 뒤 몇 분 기다리면 저절로 이어지는 경우도 있습니다.
도어락이 와이파이를 멀리서 받는 위치라면 신호가 약해 자주 끊길 수 있습니다.

# 앱과 휴대전화 설정 점검
앱이 오래된 버전이면 연결 오류가 생기기도 합니다. / 앱을 최신 버전으로 업데이트하고 다시 로그인해 보세요.
휴대전화의 블루투스나 위치 권한을 꺼 둔 경우에도 연결이 안 됩니다. / 앱이 요구하는 권한을 모두 켜 두었는지 확인하세요.
휴대전화를 바꿨다면 새 기기에 도어락을 다시 연결해야 하는 제품도 있습니다.
@ 삼송동 스마트 도어락 앱 연결 월패드 점검

# 월패드와 연동되는 경우
아파트 월패드와 연동된 도어락은 단지 설정과도 이어져 있습니다. / 관리사무소에서 시스템을 점검하거나 업데이트하면 연동이 끊길 수 있습니다.
월패드에서는 열리는데 도어락 번호는 안 되는 경우도 있고 반대인 경우도 있습니다. / 어느 쪽이 안 되는지 알려주시면 원인을 좁히기 쉽습니다.
단지 공용 시스템 문제는 관리사무소에 먼저 문의해 보세요.

# 연결이 안 되어도 문은 열려야 합니다
스마트 도어락은 연결이 끊겨도 번호나 카드, 비상 열쇠로 열 수 있어야 정상입니다. / 앱에만 의존해서 번호를 기억하지 못하면 문 앞에서 막힙니다.
배터리가 약하면 연결 기능이 먼저 약해지는 제품이 많습니다. / 연결 오류와 함께 경고음이 난다면 배터리를 먼저 갈아 보세요.
비상용으로 번호 하나쯤은 기억해 두는 것이 좋습니다.

# 전화하실 때 알려주실 것
상황에 맞게 준비하려면 몇 가지 정보가 필요합니다. / 아래 내용을 알려주시면 현장에서 헤매지 않습니다.
- 삼송동 어디쯤인지와 아파트인지 오피스텔인지
- 앱이나 월패드 중 무엇과 연동하는지
- 언제부터 연결이 안 되는지와 공유기를 바꾼 적이 있는지
- 번호나 카드로는 문이 열리는지
- 집 안에 사람이나 반려동물이 있는지
도어락이나 문 사진 한 장이면 충분합니다.
급하실 때는 문자로 위치와 사진만 먼저 보내주셔도 됩니다. / 통화가 어려운 곳에 계시면 문자로 상황을 적어 보내주세요. / 확인하는 대로 바로 연락드립니다.

# 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소나 집주인 확인 중 하나면 됩니다.
삼송동에서도 신분증이 집 안에 있는 경우가 많습니다. / 관리사무소에 세대 확인을 부탁하거나 우편물로 대신할 수 있으니 방법을 같이 찾아드립니다.
확인이 어려우면 작업을 할 수 없어서 미리 말씀해 주시면 방법을 안내합니다.
이 절차는 다른 사람이 몰래 들어가는 일을 막기 위한 것이라 양해 부탁드립니다. / 사시는 분께는 몇 분이면 끝나는 간단한 과정입니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 알려드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없고, 부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다.
출동 전에 전화로 상황을 듣고 대략의 방향을 말씀드립니다. / 현장에서 상태를 확인한 뒤 정확한 내용을 다시 알려드리니 중간에 놀라실 일이 없습니다.
진행 순서는 [이용안내](guide.html)에도 정리해 두었습니다.

# 문과 도어락을 상하지 않게 엽니다
부수지 않고 여는 방법부터 차례로 해봅니다. / 문과 도어락을 살려야 이후 비용도 줄어듭니다.
작업 중에 바꿔야 할 부품이 보이면 만지기 전에 말씀드립니다. / 원래 상태로 다시 조립할 수 있게 진행합니다.
어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
문 틈에 흠집이 나거나 도어락 외관이 상하지 않았는지 작업 뒤에 함께 확인해 보여드립니다.
@ 비파손 개방 삼송동 도어락 출장 작업

# 열린 뒤에 하는 점검
문이 열리면 도어락의 연결 상태와 배터리를 확인합니다. / 와이파이와 앱 설정을 다시 맞춰 실제로 연결되는지 여러 번 확인합니다.
연결이 계속 끊긴다면 통신 부분을 점검합니다. / 점검 결과에 따라 수리나 교체 여부를 안내합니다.
고장이 의심되면 [도어락 수리](doorlock-repair.html)로 점검하고, 너무 오래됐으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 연결 문제를 줄이는 평소 관리
작은 습관만 들여도 연결이 끊기는 일이 줄어듭니다.
- 공유기 비밀번호를 바꾸면 도어락 연결도 다시 확인하기
- 앱은 자동 업데이트를 켜 두기
- 배터리를 해가 바뀔 때 교체하기
- 번호나 카드 같은 대체 수단을 항상 준비하기
- 단지 점검 공지가 있으면 미리 확인하기
연결 기능은 편의 기능일 뿐 열쇠를 대신하지 못한다는 점을 기억하세요.

# 교체나 재설정이 필요한 경우
여러 방법을 써도 연결이 안 되면 도어락의 통신 부분이 고장 났거나 설정을 처음부터 다시 해야 할 수 있습니다. / 현장에서 상태를 보고 재설정으로 되는지 부품 교체가 필요한지 말씀드립니다.
오래된 제품은 앱 서비스가 종료되어 연결이 아예 불가능한 경우도 있습니다. / 이럴 때는 다른 방식으로 바꾸는 방법을 안내합니다.
연결 기능이 꼭 필요하지 않다면 단순한 제품으로 바꾸는 선택도 있습니다.

# 삼송동 말고 고양 어디든 갑니다
삼송동 가까운 원흥동, 지축동, 화정동, 행신동 쪽도 같은 방식으로 다닙니다. / 고양 안이라면 동네 상관없이 24시간 출동합니다.
고양에서 다니는 동네는 [고양시 출장열쇠](goyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
위치만 알려주시면 가장 가까운 기사님이 출발하고, 도착 예상 시간도 미리 말씀드립니다. / 길이 막히거나 늦어질 때는 중간에 먼저 연락드립니다.
