# 식사동 1층 우편함 앞에서 열쇠가 안 맞을 때
식사동은 일산동구에 속한 동네로 아파트 단지와 주택가가 함께 있는 곳입니다. / 현관 도어락만큼 자주 쓰지는 않지만, 1층 우편함이나 동네 운동 시설 사물함 열쇠가 말썽을 부리면 은근히 신경이 쓰입니다.
우편함 열쇠는 작고 쓸 일이 드물어 어디 뒀는지 잊어버리기 쉽습니다. / 번호식 자물쇠라면 처음 정한 번호가 기억나지 않는 일도 흔합니다.
이 글은 식사동 집에서 우편함과 사물함 잠금이 문제일 때 누구에게 먼저 연락하고, 어떻게 풀면 좋은지 정리했습니다.
@ 식사동 아파트 우편함 열쇠 분실

# 우편함과 사물함 잠금은 생김새가 단순합니다
우편함과 사물함에는 대개 작은 열쇠를 꽂아 반 바퀴 돌리는 잠금이나, 숫자 바퀴를 맞추는 번호식 자물쇠가 달려 있습니다. / 현관 도어락보다 구조가 단순한 대신 힘에 약한 편입니다.
열쇠 구멍 모양과 열쇠에 새겨진 번호를 알면 같은 열쇠를 만들기 쉬운 경우도 있습니다. / 남은 열쇠가 하나라도 있다면 버리지 말고 챙겨 두세요.
번호식 자물쇠는 바퀴 개수와 걸쇠 모양에 따라 여는 방법이 다릅니다. / 사진을 찍어 두면 상담할 때 도움이 됩니다.

# 열쇠를 잃어버린 경우
우편함 열쇠를 잃어버렸다면 먼저 집 안 서랍, 현관 열쇠 걸이, 차 안 동전함을 찾아보세요. / 이사 올 때 받은 서류 봉투에 함께 들어 있는 경우도 많습니다.
그래도 없다면 아래 순서로 정리해 보시면 됩니다.
- 아파트라면 관리사무소에 여분 열쇠가 있는지 확인
- 집주인이 따로 있다면 집주인에게 여분이 있는지 확인
- 둘 다 없으면 자물쇠를 바꾸거나 열쇠를 새로 맞추기
우편물이 급하게 필요하다면 그 사정도 관리사무소에 말씀해 보세요. / 확인 후 꺼내 주는 경우도 있습니다.

# 번호식 자물쇠 번호를 잊었을 때
번호식 자물쇠는 처음 정한 번호를 잊으면 열 방법이 막막해집니다. / 가족 생일, 집 호수, 전화번호 뒷자리처럼 자주 쓰는 숫자를 먼저 떠올려 보세요.
이전 세입자가 정한 번호를 그대로 쓰고 있었다면 관리사무소나 집주인이 알고 있을 수도 있습니다. / 입주 때 받은 안내문을 다시 찾아보는 것도 방법입니다.
숫자를 하나씩 모두 돌려 보는 것은 시간이 오래 걸리고 자물쇠도 닳습니다. / 짐작 가는 번호 몇 개를 해 보고 안 되면 다른 방법을 찾는 편이 낫습니다.
@ 식사동 번호식 우편함 자물쇠

# 열쇠가 들어가는데 안 돌아갈 때
열쇠는 맞는데 돌아가지 않는다면 구멍 안에 먼지나 녹이 쌓였을 수 있습니다. / 1층 우편함은 현관 바람과 먼지를 그대로 맞아 생각보다 쉽게 뻑뻑해집니다.
열쇠를 끝까지 넣은 뒤 우편함 문을 살짝 누르면서 돌려 보세요. / 문이 휘어 걸쇠가 눌려 있던 것이라면 이렇게 하면 돌아가기도 합니다.
그래도 안 되면 힘을 빼고 멈춰 주세요. / 작은 열쇠는 쉽게 휘거나 부러져 구멍 안에 박힐 수 있습니다.

# 단지 우편함은 관리사무소에 먼저
아파트 단지 우편함은 건물 시설이라 관리사무소가 관리하는 경우가 많습니다. / 열쇠 분실이나 고장은 관리사무소에 먼저 알려 주세요.
관리사무소에서 자물쇠를 일괄로 관리한다면 같은 제품으로 바꿔 주기도 합니다. / 따로 바꾸면 다른 세대와 모양이 달라질 수 있어 먼저 물어보시는 편이 좋습니다.
관리사무소에서 개인이 바꿔도 된다고 하면 그때 연락 주세요. / 우편함 크기와 구멍에 맞는 자물쇠를 챙겨 갑니다.

# 무인 택배함이 안 열릴 때
단지에 무인 택배함이 있다면 그 잠금은 대부분 관리 시스템과 연결돼 있습니다. / 택배함이 안 열리면 화면에 나오는 관리 연락처나 관리사무소로 먼저 연락하세요.
이런 택배함은 개인이 자물쇠를 손대는 대상이 아닙니다. / 저희도 관리 쪽 요청과 확인이 있을 때만 봐 드립니다.

# 주택 우편함과 대문 우편함
식사동 주택가에는 대문이나 담장에 우편함을 단 집도 있습니다. / 바깥에 그대로 드러나 있어 비와 눈에 녹이 슬기 쉽습니다.
작은 자물쇠가 녹으로 굳었다면 무리하게 돌리지 마세요. / 녹이 심하면 자물쇠를 새것으로 바꾸는 편이 낫습니다.
대문 열쇠와 우편함 열쇠를 같은 꾸러미에 달아 두면 한 번에 잃어버리기 쉽습니다. / 우편함 열쇠는 여분을 하나 만들어 집 안에 따로 두세요.

# 운동 시설·상가 사물함
동네 운동 시설이나 상가 사물함 열쇠를 잃어버렸다면 그곳 관리자에게 먼저 알리세요. / 대부분 여분 열쇠나 관리용 열쇠를 갖고 있습니다.
개인이 산 자물쇠를 걸어 둔 사물함이라면 이야기가 다릅니다. / 사물함을 쓰는 본인이라는 확인과 시설 관리자 동의가 있으면 자물쇠를 풀어 드릴 수 있습니다.

# 억지로 비틀면 생기는 일
드라이버로 우편함 문을 벌리거나 자물쇠를 비틀면 우편함 문이 휘어 다시 잘 닫히지 않습니다. / 여러 세대가 나란히 쓰는 우편함은 옆 칸까지 상할 수 있습니다.
작은 열쇠를 펜치로 잡고 세게 돌리는 것도 피해 주세요. / 열쇠가 부러지면 조각을 빼내는 일까지 더해집니다.
구멍에 기름이나 접착 성분이 있는 스프레이를 많이 뿌리는 것도 좋지 않습니다. / 먼지가 엉겨 붙어 다음에는 열쇠가 아예 안 들어갈 수 있습니다.

# 자물쇠를 바꿀 때 고를 것
열쇠를 자주 잃어버린다면 번호식 자물쇠가 편할 수 있습니다. / 반대로 번호를 잘 잊는다면 열쇠식에 여분 열쇠를 두는 편이 낫습니다.
우편함 문 두께와 구멍 크기에 맞는 제품을 골라야 헐겁지 않습니다. / 사진과 함께 구멍 크기를 알려 주시면 맞는 것을 챙겨 갑니다.
새 자물쇠로 바꾼 뒤에는 열쇠 하나를 집 안 정해진 자리에 두고, 번호식이라면 번호를 식구끼리 알 수 있게 정해 두세요. / 이사할 때는 관리사무소에 열쇠나 번호를 넘겨 다음 세대가 같은 일을 겪지 않게 해 주시면 좋습니다.
@ 고양 식사동 우편함 자물쇠 교체

# 확인과 비용
우편함과 사물함도 그 칸을 쓰는 분이 맞는지 확인합니다. / 아파트라면 동, 호수가 나온 신분증이나 우편물, 관리사무소 확인이면 됩니다.
비용은 자물쇠 상태를 보고 손대기 전에 먼저 말씀드리고, 동의하실 때만 진행합니다. / 현관 도어락도 같이 봐 달라고 하시면 함께 점검해 드립니다.
열쇠 관련 작업은 [열쇠 출장](key-call.html), 현관 문제는 [현관문 개문](door-open.html)과 [도어락 수리](doorlock-repair.html)에 정리해 두었습니다.

# 식사동 말고 고양 어디든
