# 탄현동 현관, 번호판을 눌러도 아무 소리가 없다면
탄현역 주변으로 아파트와 빌라, 주택이 이어진 탄현동은 저녁이면 퇴근길 발걸음이 골목마다 이어지는 동네입니다. / 현관 앞에서 번호판을 손으로 덮었는데 불도 안 들어오고 삑 소리도 없다면 배터리가 다 됐을 가능성이 가장 큽니다.
배터리 방전은 도어락 문제 중 가장 흔하고, 가장 쉽게 풀리는 편이기도 합니다. / 다만 비상 전원 자리를 몰라 문 앞에서 한참을 헤매거나, 들어가서 배터리를 갈았는데 며칠 만에 또 꺼지는 일이 생깁니다.
이 글은 탄현동에서 번호판이 꺼졌을 때 비상 전원을 찾는 법과 배터리를 갈 때 자주 하는 실수를 정리했습니다. / 해 봐도 안 되면 [고양 출장열쇠](goyang.html)로 연락 주세요.
@ 탄현동 도어락 배터리 방전 번호판 꺼짐

# 정말 배터리 때문인지 가려 보기
번호판이 꺼진 이유가 배터리만은 아닙니다. / 아래를 보면 배터리 탓인지 대략 알 수 있습니다.
- 며칠 전부터 경고음이나 배터리 표시가 있었다
- 번호를 누를 때 소리가 평소보다 늘어졌다
- 지난번 배터리를 간 지 꽤 오래됐다
- 모터 소리가 약해지고 잠금이 한 번에 안 됐다
이런 신호가 있었다면 배터리일 가능성이 큽니다. / 아무 신호 없이 갑자기 꺼졌다면 습기나 회로 쪽도 함께 생각해 봐야 합니다.

# 비상 전원 자리는 제품마다 다릅니다
배터리가 다 됐을 때 바깥에서 잠깐 전기를 넣어 주는 비상 전원 자리가 대부분의 도어락에 있습니다. / 그런데 그 자리가 제품마다 달라서 처음 찾는 분은 잘 보이지 않습니다.
- 번호판 아래 바닥 쪽에 작은 돌기 두 개가 있는 9V 단자
- 번호판 옆이나 아래의 작은 덮개 안 단자
- 요즘 제품에 있는 USB 단자
휴대폰 손전등으로 번호판 둘레와 아래쪽을 비춰 보세요. / 9V 단자라면 건전지 머리를 대고, USB 단자라면 휴대폰 보조배터리를 케이블로 이어 주면 됩니다.
@ 탄현동 도어락 비상 전원 9V USB 단자

# 비상 전원을 넣고 번호 누르기
9V 건전지는 단자에 꾹 대고 있는 동안만 전원이 들어옵니다. / 한 손으로 건전지를 대고, 다른 손으로 번호를 눌러야 해서 조금 번거롭습니다.
번호판에 불이 들어오면 평소처럼 번호를 누르고 문을 엽니다. / 탄현역 근처나 골목 편의점에서 9V 건전지를 구할 수 있습니다.
보조배터리를 USB 단자에 이을 때는 케이블 끝 모양이 맞는지 먼저 보세요. / 연결하고 몇 초 기다리면 번호판이 켜지는 제품이 많습니다.

# 집 안에서는 배터리가 없어도 열립니다
배터리가 다 됐어도 안쪽에서는 손잡이나 수동 레버로 문을 열 수 있는 제품이 대부분입니다. / 집 안에 가족이 있다면 안에서 열어 달라고 하는 것이 가장 빠릅니다.
아이가 혼자 집에 있다면 문 너머로 안쪽 손잡이를 어떻게 돌리는지 천천히 알려 주세요. / 아이가 손이 닿지 않거나 무서워하면 무리하게 시키지 말고 연락 주시면 됩니다.
반대로 혼자 사는 집이라면 외출 전에 배터리 경고가 났는지 꼭 확인하고 나가세요. / 나갈 때는 문제없이 나갔는데 돌아올 때 막히는 경우가 가장 흔합니다.

# 새 배터리를 넣을 때 흔한 실수
문이 열려 들어갔다면 그날 바로 배터리를 바꿉니다. / 이때 아래 실수 때문에 며칠 만에 다시 꺼지는 집이 많습니다.
- 네 개 중 두 개만 새것으로 바꾼 경우
- 집에 굴러다니던 오래된 건전지를 섞어 넣은 경우
- 충전지를 넣었는데 전압이 모자란 경우
- 극 방향을 하나 거꾸로 넣은 경우
- 배터리 칸 접점에 녹이 슬어 있는데 그대로 둔 경우
배터리는 같은 날 산 같은 종류로 전부 바꾸는 것이 원칙입니다. / 설명서에 맞는 종류가 적혀 있다면 그대로 따르시면 됩니다.

# 배터리 칸 접점 살펴보기
배터리 칸을 열었을 때 금속 접점에 하얀 가루나 초록빛 녹이 보이면 마른 천으로 닦아 주세요. / 녹이 심하면 새 배터리를 넣어도 전기가 제대로 흐르지 않습니다.
배터리가 새어 칸 안이 끈적하다면 닦기만으로 부족할 수 있습니다. / 이 경우 접점 부품 교체가 필요할 수 있으니 점검을 받아 보세요.
배터리를 끼울 때 스프링 쪽 접점이 눌려 납작해져 있지 않은지도 보세요. / 스프링이 약하면 문을 닫는 충격에 배터리가 잠깐 떨어지며 도어락이 혼자 꺼졌다 켜지기도 합니다.
배터리 칸 뚜껑이 헐거워 잘 안 닫힌다면 테이프로 대충 붙이기보다 뚜껑 걸쇠를 손보는 편이 낫습니다.

# 배터리를 갈아도 안 켜진다면
새 배터리를 바르게 넣었는데도 번호판이 꺼져 있다면 배터리 탓이 아닙니다. / 번호판과 몸체를 잇는 선이나 회로, 번호판 자체에 문제가 있을 수 있습니다.
탄현동처럼 계절마다 습기가 드는 집이라면 번호판 안쪽에 물기가 들어간 것은 아닌지도 의심해 봅니다. / 이럴 때는 더 만지지 말고 점검을 받아 주세요.

# 바꾼 날짜를 적어 두기
배터리 칸 뚜껑 안쪽에 바꾼 날짜를 적어 두세요. / 다음에 언제 바꿨는지 몰라 헤매지 않아도 됩니다.
경고음이 처음 난 날에는 미루지 말고 그날 바꾸세요. / 경고음이 난 뒤에도 며칠은 버티지만, 그 며칠 안에 꺼지는 날이 꼭 집을 비운 날이 됩니다.
9V 건전지 하나를 가방이나 차 안에 넣어 두면 번호판이 꺼진 날 바로 쓸 수 있습니다.

# 탄현동에서 전화로 알려 주실 것
- 아파트는 동과 호수, 빌라와 주택은 건물 이름이나 번지
- 탄현역에서 어느 쪽인지
- 비상 전원을 넣어 봤는지, 반응이 있었는지
- 도어락 앞면과 번호판 아래쪽 사진
- 집 안에 아이나 반려동물이 있는지
비상 전원 자리를 못 찾겠다면 사진을 보내 주세요. / 어디를 보면 되는지 먼저 알려 드립니다.

# 확인 절차와 비용, 이렇게 진행합니다
문을 열어야 하는 경우 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
도어락 상태를 보고 비용을 먼저 말씀드리고, 동의하실 때 시작합니다. / 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.
연 뒤 회로나 접점에 문제가 보이면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 고양 탄현동 도어락 배터리 교체 점검
