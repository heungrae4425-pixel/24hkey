# 원흥동 현관에서 문이 한 뼘만 열리고 멈췄다면
원흥동은 덕양구에 새 아파트가 들어서며 아이를 키우는 젊은 가족이 많은 동네입니다. / 번호를 맞게 누르고 문을 당겼는데 한 뼘쯤 열리다 덜컥 멈추는 일이 있습니다.
안쪽에서 누군가 안전고리를 걸어 둔 것입니다. / 도어락은 풀렸는데 보조 잠금이 남아 있어 들어갈 수 없는 상황입니다.
이 글은 원흥동 집에서 안전고리, 도어락 이중 잠금, 따로 달린 보조키 때문에 막혔을 때 종류별로 무엇을 확인하고 누구에게 연락할지 정리했습니다.
@ 원흥동 현관 안전고리 걸림

# 보조 잠금은 크게 세 갈래
현관을 한 번 더 잠그는 장치는 크게 세 가지입니다. / 어떤 것이 걸렸는지에 따라 풀어 가는 방법이 다릅니다.
- 문 안쪽 위에 다는 안전고리나 말굽 모양 걸쇠
- 도어락 안쪽 버튼으로 켜는 이중 잠금 기능
- 도어락과 따로 열쇠로 여는 보조키
새 아파트는 안전고리와 이중 잠금이 기본으로 있는 경우가 많습니다. / 보조키는 예전 집에서 많이 쓰던 방식이라 새 아파트에서는 드뭅니다.

# 안전고리가 걸린 채 문이 살짝 열렸을 때
문이 한 뼘 정도 열리고 더는 안 열린다면 안전고리일 가능성이 큽니다. / 문틈으로 쇠고리나 걸쇠가 보이는지 확인해 보세요.
집 안에 식구가 있다면 전화나 초인종으로 불러 고리를 풀어 달라고 하는 것이 가장 빠릅니다. / 자고 있다면 몇 번 더 연락해 보세요.
문을 다시 닫았다 열어 보는 것도 방법입니다. / 다만 세게 당겼다 놓기를 반복하면 고리와 문틀 나사가 상할 수 있습니다.

# 안에서 누가 걸쇠를 걸었는지 떠올리기
먼저 집 안에 누가 있는지 생각해 보세요. / 먼저 귀가한 가족이 습관처럼 걸쇠를 걸었거나, 아이가 장난으로 걸었을 수 있습니다.
아이가 안에 있다면 문틈으로 차분히 말을 걸어 고리를 풀 수 있는지 물어보세요. / 손이 닿지 않는 높이라면 무리하게 의자를 딛고 올라가지 않게 해 주세요.
아무도 없는데 걸쇠가 걸려 있다면 문을 닫을 때 고리가 저절로 걸쳐진 경우일 수 있습니다. / 이럴 때는 억지로 열지 말고 연락 주시는 편이 낫습니다.
@ 원흥동 아파트 현관 보조 걸쇠 점검

# 도어락 이중 잠금이 켜져 있을 때
많은 도어락에는 안쪽에서 버튼을 누르거나 손잡이를 돌려 바깥 번호 입력을 막는 기능이 있습니다. / 이 기능이 켜져 있으면 번호를 맞게 눌러도 문이 열리지 않습니다.
번호를 눌렀을 때 평소와 다른 소리가 나거나, 번호판에 잠금 표시가 뜬다면 이중 잠금을 의심해 보세요. / 안에 있는 식구가 켜 둔 것이라면 풀어 달라고 연락하면 됩니다.
아무도 없는 집에서 이중 잠금이 켜져 있다면 나가면서 실수로 눌렀을 수 있습니다. / 이 경우는 바깥에서 풀기 어려워 출장이 필요한 경우가 많습니다.

# 보조 열쇠가 따로 있는 문
도어락 위나 아래에 열쇠로 여는 보조키가 따로 달린 집도 있습니다. / 평소에 안 잠그다가 오랜만에 잠갔는데 열쇠가 어디 있는지 모르는 일이 생깁니다.
보조키 열쇠는 처음 받은 그대로 서랍 깊숙이 넣어 두는 경우가 많습니다. / 입주 때 받은 열쇠 꾸러미를 통째로 어딘가 보관해 두었다면 그 상자부터 찾아보세요. / 신발장 위 칸이나 공구함에서 나오는 경우도 있습니다. / 식구 중 누가 갖고 있는지, 차 열쇠 꾸러미에 달려 있지 않은지 확인해 보세요.
열쇠가 들어가는데 안 돌아간다면 문을 살짝 밀거나 당기면서 돌려 보세요. / 문이 눌려 잠금쇠가 걸려 있으면 열쇠가 무겁게 돕니다.

# 열쇠를 잃어버린 보조키
보조키 열쇠를 아예 잃어버렸다면 문이 잠긴 상태에서는 출장이 필요합니다. / 문이 열린 상태라면 급하지 않으니 편한 때 연락 주셔서 열쇠를 새로 맞추거나 보조키를 바꾸시면 됩니다.
보조키를 거의 안 쓴다면 이참에 떼어 내고 남은 구멍을 막는 방법도 있습니다. / 새 아파트라면 하자 보수나 관리 규칙을 먼저 확인해 보세요.

# 문틈으로 손이나 도구를 넣지 마세요
문이 한 뼘 열려 있으면 손을 넣어 고리를 벗기고 싶어집니다. / 하지만 문이 갑자기 움직이면 손가락이 끼일 수 있어 위험합니다.
옷걸이나 막대를 넣어 고리를 밀어 보는 것도 권하지 않습니다. / 고리가 휘거나 문틀 나사가 빠지면 다시 걸 수 없게 됩니다.
문을 어깨로 밀어 고리를 끊어 내려는 분도 있습니다. / 고리 나사가 문틀째 뜯겨 나가면 문틀 보수까지 해야 하고, 문이 갑자기 열리며 넘어질 수도 있습니다.
문이 열린 채로 오래 기다려야 한다면 틈으로 찬바람이나 벌레가 들어오지 않게 신경 써 주세요. / 아이나 반려동물이 틈 쪽으로 다가오지 않도록 안에 있는 식구에게 알려 주시면 좋습니다.

# 사람이 안에 있는데 대답이 없다면
식구가 안에 있는 게 분명한데 전화와 초인종에 대답이 없다면 조금 더 신경 써야 합니다. / 깊이 잠든 것일 수도 있지만, 몸이 불편한 상황일 수도 있습니다.
걱정되는 상황이라면 기다리지 말고 119에 먼저 연락하세요. / 안전이 확인된 뒤 문 문제는 그다음에 풀어도 늦지 않습니다.

# 연락과 진행
가족 연락이 안 되고 직접 풀 수 없다면 [고양 출장열쇠](goyang.html)로 전화 주세요. / 문이 한 뼘 열린 상태인지, 완전히 닫힌 상태인지, 집 안에 사람이 있는지 알려 주시면 됩니다.
도착하면 사시는 분인지 신분증, 주소가 적힌 우편물, 관리사무소 확인으로 먼저 봅니다. / 비용은 상태를 보고 손대기 전에 말씀드리고, 끝내 못 열면 받지 않습니다.
여는 과정은 [현관문 개문](door-open.html), 열쇠 관련 작업은 [열쇠 출장](key-call.html)에 정리해 두었습니다.
@ 고양 원흥동 보조키 이중 잠금 출장

# 걸쇠를 다시 걸기 전에 보는 것
문이 열리면 안전고리와 걸쇠 나사가 헐겁지 않은지 함께 봅니다. / 억지로 당겨진 흔적이 있으면 나사를 다시 조이거나 부품을 바꿉니다.
이중 잠금 기능이 쉽게 눌리는 위치라면 실수로 켜지지 않게 쓰는 방법을 알려 드립니다. / 보조키가 낡았다면 [도어락 수리](doorlock-repair.html)와 함께 정리해 드립니다.

# 식구끼리 정해 둘 약속
- 안전고리와 이중 잠금은 식구가 모두 집에 있을 때만
- 먼저 들어온 사람은 가족 귀가 시간을 확인한 뒤 걸기
- 아이 손이 닿는 걸쇠는 쓰는 법을 같이 알려 주기
- 보조키 열쇠는 정해진 자리에 하나 두기
이 약속만 지켜도 문이 한 뼘 열리고 멈추는 일을 대부분 막을 수 있습니다.

# 원흥동 말고 고양 다른 동네
원흥동 옆 삼송동, 지축동과 화정동, 행신동 같은 덕양구, 백석동, 마두동, 주엽동, 탄현동 같은 일산 쪽도 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
