# 원흥동 새 집, 현관 말고 집 안 잠금이 말썽일 때
원흥동은 덕양구에 새 아파트가 들어서며 젊은 가족이 많이 사는 동네입니다. / 새 집이라 현관 도어락은 멀쩡한데, 오히려 베란다 창이나 미닫이 중문, 아이 방문 잠금이 말썽을 부리는 경우가 있습니다.
집 안 잠금장치는 평소 신경 쓸 일이 적어서 막상 안 풀리면 어떻게 해야 할지 모르는 분이 많습니다. / 아이가 방문을 잠그고 못 나오거나, 베란다에 나갔다가 문이 잠겨 버리면 더 당황스럽습니다.
이 글은 원흥동 새 아파트에서 자주 보는 집 안 잠금장치를 종류별로 나누고, 집에서 확인해 볼 것과 점검이 필요한 때를 정리했습니다.
@ 원흥동 아파트 베란다 창 잠금장치

# 새 아파트 집 안 잠금은 종류가 다릅니다
요즘 아파트는 예전 집과 잠금장치 모양이 꽤 다릅니다. / 창은 손잡이를 돌려 잠그는 방식이 많고, 현관에는 미닫이 중문을 단 집도 많습니다.
- 손잡이를 아래로 돌려 잠그는 베란다 창
- 창틀 가운데 반달 모양으로 거는 잠금
- 현관 미닫이 중문 잠금
- 버튼을 눌러 잠그는 방문과 화장실 손잡이
- 드레스룸이나 수납 공간의 미닫이 문 잠금
어떤 잠금인지 알면 해 볼 수 있는 것과 하면 안 되는 것이 분명해집니다.

# 창 손잡이를 돌려 잠그는 베란다 창
창에 달린 손잡이를 돌려 잠그는 방식은 손잡이 방향에 따라 잠김과 열림이 나뉩니다. / 손잡이가 끝까지 돌아가지 않으면 창이 반쯤 걸린 채 안 열리기도 합니다.
이럴 때는 창을 살짝 몸 쪽으로 누르거나 밀면서 손잡이를 돌려 보세요. / 창이 틀에 꽉 눌려 있으면 손잡이가 무겁게 돌아갑니다.
손잡이가 헐겁게 덜렁거린다면 안쪽 고정 나사가 풀렸을 수 있습니다. / 새 집은 입주 초기 몇 달 사이에 이런 일이 종종 생깁니다.
손잡이 아래 덮개를 살짝 돌리거나 들어 올리면 나사가 보이는 제품이 있습니다. / 창을 연 상태에서 나사를 살짝 조여 주면 흔들림이 줄어듭니다.
겨울에 창틀 고무가 굳으면 손잡이가 평소보다 뻑뻑해지기도 합니다. / 창을 한 번 끝까지 닫았다 다시 열어 보면 나아지는 경우가 많습니다.

# 반달 모양 잠금이 헐렁하게 걸릴 때
미닫이 창 가운데에 다는 반달 모양 잠금은 두 창이 겹치는 자리에서 서로 물리도록 돼 있습니다. / 창이 끝까지 닫히지 않으면 반달이 반만 걸리고 헐렁합니다.
창을 끝까지 밀어 닫은 뒤 다시 돌려 보세요. / 창틀 레일에 먼지나 작은 돌이 끼어 끝까지 안 닫히는 경우가 많습니다.
레일을 마른 솔로 쓸어 주기만 해도 다시 잘 걸리기도 합니다. / 그래도 헐겁다면 받침 쪽 위치를 조금 맞춰야 합니다.
@ 원흥동 미닫이 창 반달 잠금 점검

# 현관 미닫이 중문이 잠겨 버렸다면
현관과 거실 사이에 미닫이 중문을 단 집이 많습니다. / 중문에 잠금을 달아 둔 집은 아이가 장난으로 잠그거나, 바람에 밀려 걸쇠가 걸리는 일이 생깁니다.
현관 쪽에 서 있는데 중문이 잠겨 거실로 못 들어간다면 먼저 문을 레일 방향으로 살짝 흔들어 보세요. / 걸쇠가 덜 걸린 상태라면 풀리기도 합니다.
중문 잠금 구조는 제품마다 달라서 억지로 당기면 레일에서 문이 빠질 수 있습니다. / 유리가 들어간 중문이라면 더 조심해 주세요.

# 방문 버튼 잠금, 아이가 눌렀을 때
아이 방문이나 화장실 손잡이는 안쪽 버튼을 누르면 잠기는 방식이 많습니다. / 아이가 들어가서 버튼을 누르고 문을 닫으면 밖에서 열기 어렵습니다.
바깥 손잡이 가운데를 보면 작은 구멍이나 홈이 있는 경우가 많습니다. / 여기에 곧은 막대나 동전 같은 것을 넣어 돌리거나 누르면 풀리도록 만든 제품이 많습니다.
먼저 문 너머로 아이를 안심시키고, 버튼을 다시 눌러 보라고 차분히 말해 주세요. / 아이가 놀라서 울고 있다면 억지로 서두르지 말고 연락 주시면 됩니다.

# 드레스룸·수납 공간 미닫이 문
드레스룸이나 수납 공간에 단 미닫이 문은 작은 걸쇠나 자석 잠금이 있는 경우가 있습니다. / 아이가 안에 들어가 놀다가 문이 닫히는 일도 있으니 잠금이 있는지 한 번 확인해 두세요.
자주 쓰지 않는 잠금이라면 아예 쓰지 않도록 풀어 두는 것도 방법입니다. / 필요 없는 잠금은 사고의 원인이 되기도 합니다.
미닫이 문이 레일 끝에서 툭 걸려 안 열린다면 아래쪽 바퀴나 레일에 물건이 끼었는지 먼저 보세요. / 옷걸이나 작은 장난감이 끼어 있는 경우가 의외로 많습니다.

# 베란다에 혼자 갇혔을 때
베란다에 빨래를 널러 나갔는데 아이가 안쪽에서 문을 잠그는 일이 있습니다. / 휴대폰이 있다면 가족에게 먼저 연락하고, 없다면 이웃이 볼 수 있게 창 쪽에서 도움을 구하세요.
아이가 안에 있다면 문 너머로 잠금을 다시 풀어 보라고 차분히 알려 주세요. / 겨울이나 여름에 오래 갇혀 있으면 위험할 수 있으니 무리하게 기다리지 마세요.
급하다고 느껴지면 119에 먼저 연락하시는 것이 맞습니다. / 집 안에서 현관을 열 사람이 없다면 [고양 출장열쇠](goyang.html)로 연락 주셔도 됩니다.

# 아이 안전 잠금을 더할 때 볼 것
아이가 있는 집은 베란다 창에 안전 잠금을 더 다는 경우가 많습니다. / 이때 어른은 쉽게 풀 수 있고 아이는 못 푸는 위치와 방식인지 확인해 주세요.
급할 때 어른도 못 풀 만큼 복잡한 잠금은 오히려 위험합니다. / 식구 모두가 푸는 방법을 알고 있어야 합니다.
새 아파트는 창과 문틀에 구멍을 뚫기 전에 하자 처리나 관리 규칙을 먼저 확인해 보세요.

# 혼자 고쳐도 되는 범위
레일 청소, 손잡이 겉 나사 조이기, 반달 잠금 위치를 손으로 맞춰 보는 정도는 집에서 해도 괜찮습니다. / 문을 연 상태에서 하시는 것이 안전합니다.
반면 중문을 레일에서 빼거나, 창 손잡이 안쪽을 분해하는 일은 피해 주세요. / 무거운 유리문은 빠지면 다칠 수 있습니다.
입주한 지 얼마 안 됐다면 하자 보수 기간에 해당하는지도 먼저 확인해 보세요.

# 점검 요청과 비용
어느 잠금인지, 지금 잠긴 상태인지, 헐거운 상태인지 알려 주시면 맞는 부품을 챙겨 갑니다. / 사진을 보내 주시면 더 좋습니다.
비용은 상태를 보고 손대기 전에 먼저 말씀드리고, 동의하실 때만 진행합니다. / 현관 도어락도 같이 봐 달라고 하시면 함께 점검합니다.
현관 문제는 [현관문 개문](door-open.html)과 [도어락 수리](doorlock-repair.html), 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
