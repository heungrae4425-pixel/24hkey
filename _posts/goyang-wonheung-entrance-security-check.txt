# 원흥동 새 아파트 현관, 한 번쯤 둘러보기
원흥동은 덕양구에 새 아파트가 들어서며 젊은 가족이 많이 사는 동네입니다. / 새 집이라 현관 도어락도 비교적 최근 제품인 경우가 많아 따로 신경 쓸 일이 없다고 여기기 쉽습니다.
하지만 좋은 도어락도 설정과 쓰는 습관에 따라 제 역할을 하기도, 못 하기도 합니다. / 입주하면서 정신없이 넘어간 설정이 그대로 남아 있는 집도 있습니다.
이 글은 원흥동 집 현관을 직접 살펴볼 수 있는 다섯 가지를 정리했습니다. / 걱정을 키우자는 이야기가 아니라 한 번 둘러보고 마음 편히 지내자는 이야기입니다. 궁금한 점은 [고양 출장열쇠](goyang.html)에 물어보세요.
@ 원흥동 아파트 현관 방범 점검 다섯 가지

# 점검은 걱정보다 습관입니다
현관 점검이라고 하면 거창하게 들리지만 실제로는 십 분이면 끝나는 일입니다. / 배터리 갈 때나 계절이 바뀔 때 한 번씩 둘러보는 정도면 충분합니다.
아래 다섯 가지는 특별한 도구 없이 집에서 바로 확인할 수 있는 것들입니다. / 하나씩 해 보고 이상한 점이 있으면 그 부분만 손보시면 됩니다.
식구가 함께 둘러보면 더 좋습니다. / 누가 어떤 번호와 카드를 쓰는지 서로 확인하는 기회도 되고, 아이도 현관을 어떻게 다뤄야 하는지 자연스럽게 익힙니다.

# 하나, 문이 끝까지 닫히고 잠기는지
가장 기본은 문이 끝까지 닫히고 도어락이 제대로 잠기는지입니다. / 문을 닫은 뒤 바깥에서 손잡이를 당겨 보고, 문이 덜컹하지 않는지 확인해 보세요.
도어클로저 속도가 너무 느리면 문이 끝에서 멈춰 잠금 쇠가 문틀에 안 걸립니다. / 바쁜 아침에 문이 덜 닫힌 채 나가는 일이 생길 수 있으니 문이 닫히는 소리를 한 번 들어 보는 습관을 들여 주세요.
잠글 때 모터 소리가 길게 끌리거나 경고음이 난다면 잠금 쇠가 문틀에 걸리는 것입니다. / 이럴 땐 문틀 쇠판 위치를 점검받는 것이 좋습니다.

# 둘, 자동 잠금 설정과 이중 잠금
대부분의 도어락은 문이 닫히면 저절로 잠기는 자동 잠금이 있습니다. / 입주 청소나 이사 때 수동으로 바꿔 둔 뒤 그대로 둔 집이 있으니 지금 설정을 확인해 보세요.
안에서 한 번 더 잠그는 이중 잠금 기능이 있는 제품도 많습니다. / 밤에 잘 때나 집에 혼자 있을 때 쓰면 바깥에서 번호를 눌러도 열리지 않습니다.
다만 이중 잠금을 건 채 식구가 밖에 있으면 그 식구도 못 들어오니, 쓰는 때를 가족끼리 정해 두세요.
@ 원흥동 도어락 자동 잠금 이중 잠금 설정 확인

# 셋, 번호판 손자국과 등록된 번호·카드
번호판에 손자국이 진하게 남아 있지 않은지 보세요. / 자주 누르는 숫자가 드러날 수 있으니 마른 천으로 가끔 닦아 주면 됩니다.
도어락에 등록된 번호와 카드, 지문이 지금 식구 것만 남아 있는지도 확인해 보세요. / 입주 때 업체에 알려 준 번호나 예전에 등록한 카드가 그대로일 수 있습니다.
- 번호는 입주 뒤 한 번 이상 바꿨는지
- 카드는 지금 식구 수만큼만 등록돼 있는지
- 지문은 지금 사는 사람 것만 남았는지
- 허수 입력 기능을 쓰고 있는지
정리 방법은 설명서에 있고, 찾기 어려우면 [도어락 수리](doorlock-repair.html) 상담으로 같이 정리해 드립니다.

# 넷, 보조 걸쇠와 문틈
안쪽 걸쇠나 도어가드가 단단히 고정돼 있는지 손으로 흔들어 보세요. / 나사가 헐거우면 제 역할을 못 하니 조여 두는 것이 좋습니다. / 아이 손이 닿는 높이라면 장난으로 걸지 않도록 미리 이야기해 두세요.
문을 닫은 상태에서 문과 문틀 사이 틈이 고른지도 살펴봅니다. / 한쪽만 유난히 벌어져 있다면 경첩 점검을 받아 보시길 권합니다.
문 아래 틈으로 빛이 많이 새어 들어온다면 바람막이를 붙이는 것도 방법입니다. / 방범보다는 소음과 냉난방에 더 도움이 되지만 현관 상태를 함께 살피는 계기가 됩니다.

# 다섯, 현관 주변 생활 습관
- 현관 앞 신발장 위에 여분 열쇠나 카드를 두지 않기
- 비밀번호를 현관 근처에 메모해 두지 않기
- 번호를 누를 때 손으로 살짝 가리기
- 엘리베이터에서 내린 뒤 주변을 한 번 보고 번호 누르기
- 문을 연 채로 오래 두지 않기
대단한 일은 아니지만 습관이 되면 따로 신경 쓰지 않아도 됩니다. / 아이가 있는 집이라면 아이에게도 번호를 누를 때 가리는 습관을 알려 주세요.

# 택배·우편물 쌓임 줄이기
현관 앞에 택배 상자가 며칠씩 쌓여 있으면 보기에도 좋지 않습니다. / 받은 날 바로 들여놓고, 상자에 붙은 이름과 주소 스티커는 떼어서 버리세요.
우편함에 우편물이 오래 쌓이지 않게 하는 것도 같은 맥락입니다. / 바쁘다면 가족 중 한 명이 정해서 챙기면 됩니다. / 공동 현관 출입 태그를 택배 상자 위에 올려 둔 채 잊는 일도 있으니 태그는 늘 정해진 자리에 두세요.

# 오래 집을 비울 때
여행이나 명절로 집을 비우기 전에는 도어락 배터리를 새것으로 바꿔 두세요. / 돌아왔을 때 번호판이 꺼져 있는 일을 막을 수 있습니다.
집을 봐 줄 분에게는 식구 번호가 아닌 임시 번호를 주고, 돌아와서 바로 지우세요. / 택배는 기간 동안 보관 서비스를 이용하거나 가까운 가족에게 부탁해 두면 좋습니다.

# 점검 중 이상이 보이면
점검하다 문이 덜 닫히거나, 잠금 소리가 끌리거나, 걸쇠가 흔들린다면 그 부분만 손보시면 됩니다. / 새 아파트라도 입주 뒤 문이 자리를 잡으면서 조금 틀어지는 일이 있습니다. / 처음 한두 해 사이에 문 닫힘이 달라졌다면 이런 경우일 수 있습니다.
도어락 자체가 자주 오작동한다면 점검을 받아 보시고, 고칠 수 있으면 고쳐 씁니다. / 바꿀 필요가 있을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 원흥동 현관 문틀 걸쇠 점검 조정

# 점검 방문은 이렇게 진행합니다
점검을 원하시면 도어락 사진과 궁금한 점을 먼저 보내 주세요. / 방문하면 문 닫힘, 잠금, 설정, 걸쇠를 차례로 보고 손볼 곳이 있는지 설명드립니다.
문을 열거나 부품을 손보는 작업이라 사시는 분인지 신분증 주소나 우편물, 관리사무소 확인으로 먼저 봅니다. / 비용은 작업 전에 먼저 말씀드리고, 동의하실 때만 진행합니다.
문이 잠겨 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 원흥동 말고 고양
원흥동과 가까운 삼송동, 지축동, 화정동, 행신동 등 덕양구 전체를 다닙니다. / 주엽동, 대화동, 탄현동 같은 일산서구와 백석동, 마두동, 식사동 같은 일산동구도 출동합니다.
다른 지역은 [출장 지역](area.html)에서 확인해 주세요.
