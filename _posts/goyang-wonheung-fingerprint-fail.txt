# 어제까지 되던 지문이 오늘 안 될 때
원흥동은 새 아파트와 신축 단지가 많아 지문 도어락을 쓰는 집이 많은 동네입니다. / 편하게 쓰던 지문이 어느 날 인식되지 않으면 문 앞에서 당황하게 됩니다.
지문 오류는 대부분 도어락이 고장 나서가 아니라 손이나 센서의 상태 때문에 생깁니다. / 먼저 간단한 것부터 확인해 보면 해결되는 경우가 많습니다.
이 글은 원흥동에서 지문이 안 될 때 확인할 것과 [고양 출장열쇠](goyang.html)의 점검 순서를 정리했습니다.
@ 원흥동 지문 도어락 인식 오류 출장열쇠 점검

# 손 상태부터 확인하세요
손가락이 젖었거나 땀이 많으면 인식이 떨어집니다. / 겨울에 손이 건조해 갈라지거나 로션이 묻어 있어도 잘 안 됩니다.
손을 마른 수건으로 닦고 다시 대 보세요. / 손가락을 센서 한가운데 평평하게 올려 충분히 닿게 하는 것도 중요합니다.
설거지나 청소를 오래 한 뒤에는 지문이 불어서 일시적으로 달라질 수 있습니다.

# 센서가 더러워졌을 수 있습니다
센서 표면에 기름때나 먼지가 쌓이면 지문을 제대로 읽지 못합니다. / 부드러운 마른 천으로 가볍게 닦아 주세요.
물이나 알코올을 많이 묻혀 닦으면 오히려 센서가 상할 수 있습니다. / 약하게 닦고 마를 때까지 기다리는 것이 안전합니다.
센서에 긁힌 자국이 있으면 인식이 잘 안 되므로 점검이 필요합니다.
@ 원흥동 지문 도어락 센서 인식 오류 점검

# 배터리가 약해도 지문이 안 됩니다
배터리가 약해지면 지문 센서가 먼저 힘을 잃는 제품이 많습니다. / 번호는 되는데 지문만 안 된다면 배터리 부족을 의심해 보세요.
배터리를 새것으로 바꿔도 안 되면 지문 정보를 다시 등록해야 할 수 있습니다. / 한 번 등록한 지문도 시간이 지나면 손이 변하면서 오차가 생깁니다.
경고음이 나기 시작하면 바로 교체하는 습관이 좋습니다.

# 지문을 다시 등록하는 요령
지문은 같은 손가락을 여러 각도로 여러 번 등록하면 인식률이 올라갑니다. / 손가락 가운데와 양옆을 조금씩 달리해서 등록해 보세요.
아이는 손가락이 작고 지문이 자주 변해서 번호나 카드를 함께 쓰는 것이 좋습니다. / 어르신도 지문이 옅어지기 쉬워서 번호를 같이 두는 것을 권합니다.
등록 방법은 제품마다 달라 설명서를 확인하거나 전화로 문의해 주세요.

# 전화하실 때 알려주실 것
상황에 맞게 준비하려면 몇 가지 정보가 필요합니다. / 아래 내용을 알려주시면 현장에서 헤매지 않습니다.
- 원흥동 어디쯤인지와 건물 종류, 층수
- 번호는 되는지, 지문만 안 되는지
- 센서에 불이 들어오는지와 경고음 여부
- 최근 배터리를 바꾼 시기
- 집 안에 사람이나 반려동물이 있는지
도어락이나 문 사진 한 장이면 충분합니다.
급하실 때는 문자로 위치와 사진만 먼저 보내주셔도 됩니다. / 통화가 어려운 곳에 계시면 문자로 상황을 적어 보내주세요. / 확인하는 대로 바로 연락드립니다.

# 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소나 집주인 확인 중 하나면 됩니다.
원흥동에서도 신분증이 집 안에 있는 경우가 많습니다. / 관리사무소에 세대 확인을 부탁하거나 우편물로 대신할 수 있으니 방법을 같이 찾아드립니다.
확인이 어려우면 작업을 할 수 없어서 미리 말씀해 주시면 방법을 안내합니다.
이 절차는 다른 사람이 몰래 들어가는 일을 막기 위한 것이라 양해 부탁드립니다. / 사시는 분께는 몇 분이면 끝나는 간단한 과정입니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 알려드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없고, 부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다.
출동 전에 전화로 상황을 듣고 대략의 방향을 말씀드립니다. / 현장에서 상태를 확인한 뒤 정확한 내용을 다시 알려드리니 중간에 놀라실 일이 없습니다.
진행 순서는 [이용안내](guide.html)에도 정리해 두었습니다.

# 문과 도어락을 상하지 않게 엽니다
부수지 않고 여는 방법부터 차례로 해봅니다. / 문과 도어락을 살려야 이후 비용도 줄어듭니다.
작업 중에 바꿔야 할 부품이 보이면 만지기 전에 말씀드립니다. / 원래 상태로 다시 조립할 수 있게 진행합니다.
어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
문 틈에 흠집이 나거나 도어락 외관이 상하지 않았는지 작업 뒤에 함께 확인해 보여드립니다.
@ 비파손 개방 원흥동 도어락 출장 작업

# 열린 뒤에 하는 점검
지문을 다시 등록한 뒤에는 가족 모두가 직접 대어 보고 잘 열리는지 확인하시길 권합니다. / 손가락마다 인식 정도가 달라서 잘 안 되는 손가락은 한 번 더 등록해 둡니다.
문이 열리면 센서 표면과 배터리 접점 상태를 먼저 봅니다. / 지문 정보를 다시 등록해 인식이 잘 되는지 여러 번 확인합니다.
센서 오류가 반복된다면 내부 점검이 필요할 수 있습니다. / 점검 결과에 따라 수리나 교체 여부를 안내합니다.
고장이 의심되면 [도어락 수리](doorlock-repair.html)로 점검하고, 너무 오래됐으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 지문 도어락을 오래 쓰는 습관
몇 가지만 지켜도 오류가 훨씬 줄어듭니다.
- 센서를 가끔 마른 천으로 닦기
- 번호나 카드를 함께 등록해 두기
- 배터리를 해가 바뀔 때 교체하기
- 젖은 손으로 센서를 누르지 않기
- 같은 손가락을 여러 번 나눠 등록하기
지문 하나에만 의존하지 않는 것이 가장 중요합니다.

# 센서 자체가 고장 났을 때
손과 배터리를 다 확인해도 안 되면 센서나 내부 회로가 고장 난 것일 수 있습니다. / 이 경우 부품을 교체하거나 제품 자체를 바꾸는 방법이 있습니다.
현장에서 상태를 보고 수리가 나은지 교체가 나은지 솔직하게 말씀드립니다. / 꼭 필요하지 않은 교체는 권하지 않습니다.
문이 안 열려 급한 경우에는 상하지 않게 여는 것이 먼저입니다.

# 원흥동 말고 고양 어디든 갑니다
원흥동 가까운 삼송동, 지축동, 행신동, 화정동 쪽도 같은 방식으로 다닙니다. / 고양 안이라면 동네 상관없이 24시간 출동합니다.
고양에서 다니는 동네는 [고양시 출장열쇠](goyang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
위치만 알려주시면 가장 가까운 기사님이 출발하고, 도착 예상 시간도 미리 말씀드립니다. / 길이 막히거나 늦어질 때는 중간에 먼저 연락드립니다.

# 자주 묻는 질문
? 지문만 안 되고 번호는 되는데 고장인가요? | 대부분 손 상태나 센서, 배터리 문제입니다. 확인해 보시고 안 되면 점검받으세요.
? 지문을 다시 등록하면 해결되나요? | 네, 인식률이 떨어진 경우 다시 등록하면 나아지는 경우가 많습니다.
? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 센서만 따로 고칠 수 있나요? | 제품에 따라 다릅니다. 현장에서 확인한 뒤 가능 여부를 말씀드립니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.

혼자 해결하려다 문이나 도어락을 상하게 하는 것이 가장 아쉬운 경우입니다. / 한 번 시도하고 안 되면 멈추고 연락 주시는 것이 결국 시간과 비용을 아낍니다.
