# 부곡동에서 집을 내놓았다면 열쇠부터 정리하세요
부곡동은 군포역이나 금정역을 오가며 출퇴근하는 분들이 많은 생활권입니다. / 전세나 매매로 집을 내놓으면 중개인이 손님을 데리고 집을 보러 오는 일이 잦아집니다.
집주인이 매번 따라나서기 어려우니 열쇠나 비밀번호를 중개인에게 맡기는 경우가 흔합니다. / 편한 방법이지만 맡기는 방식에 따라 나중에 번거로운 일이 생기기도 합니다.
이 글은 부곡동에서 집 열쇠를 맡길 때 미리 확인할 것과, 거래가 끝난 뒤 도어락을 정리하는 순서를 적었습니다. / [군포 출장열쇠](gunpo.html)로 연락 주시는 분들께 자주 드리는 말씀을 모았습니다.
@ 부곡동 중개인 열쇠 맡기기 도어락 점검

# 열쇠를 맡기는 방식은 크게 세 가지입니다
집 열쇠나 번호를 넘기는 방법은 보통 세 가지로 나뉩니다. / 어느 쪽이든 장단점이 있어서 집 사정에 맞게 고르면 됩니다.
- 실물 열쇠나 카드키를 중개 사무실에 두고 가는 방식
- 도어락 비밀번호를 알려 주고 필요할 때만 쓰게 하는 방식
- 집주인이 약속 시간에 맞춰 직접 문을 열어 주는 방식
실물을 맡기면 분실 위험이 있고, 번호를 알려 주면 누가 아는지 관리가 어려워집니다. / 직접 열어 주는 방식이 가장 안전하지만 시간을 맞추기가 힘듭니다.

# 맡기기 전에 누가 가지고 있는지 적어 두세요
열쇠가 몇 개이고 누구 손에 있는지 종이에 적어 두면 나중에 큰 도움이 됩니다. / 가족이 가진 것, 중개 사무실에 둔 것, 집 안에 둔 것을 따로 구분해 적습니다.
중개인에게 맡길 때는 언제 돌려받기로 했는지도 말로만 두지 말고 문자로 남기는 편이 좋습니다. / 서로 기억이 달라 곤란해지는 일을 막아 줍니다.
사무실 직원이 바뀌는 경우도 있으니 누가 받아 갔는지 이름까지 적어 두세요.

맡기기 전에 지금 쓰는 번호가 쉬운 숫자 배열은 아닌지도 한번 돌아보세요. / 집을 보러 오는 사람이 늘수록 번호를 아는 사람도 함께 늘어나기 때문입니다.
집을 비운 사이 누가 다녀갔는지 알고 싶다면 출입 기록을 보여 주는 모델인지도 확인해 보세요. / 기록 기능이 있으면 맡긴 번호가 언제 쓰였는지 짐작할 수 있어 안심이 됩니다.

# 번호를 알려 줄 땐 임시 번호를 따로 만드세요
도어락에 임시 비밀번호나 손님용 번호를 만들 수 있는 모델이 많습니다. / 평소 쓰는 번호는 그대로 두고 중개인용 번호만 따로 등록하면 거래가 끝난 뒤 그 번호만 지우면 됩니다.
임시 번호 기능이 없는 모델이라면 번호를 통째로 바꿔야 해서 가족에게 다시 알려야 합니다. / 이런 점은 [도어락 설치](doorlock-install.html) 전에 제품을 고를 때도 참고할 만합니다.
생일이나 전화번호 뒷자리처럼 쉬운 번호는 피하시는 게 좋습니다.

# 집을 보여 줄 때 집주인이 챙길 것
손님이 오기 전에 귀중품과 서류는 눈에 안 띄는 곳에 정리해 두세요. / 집을 보는 동안 중개인과 손님이 같이 다니지만 작은 물건은 늘 조심하는 편이 낫습니다.
현관문이 뻑뻑하거나 도어락 반응이 느리면 손님 앞에서 문이 안 열려 곤란해집니다. / 미리 배터리를 새것으로 바꾸고 문이 부드럽게 열리고 닫히는지 한 번 확인해 두세요.
@ 부곡동 현관 도어락 배터리와 문 상태 확인

# 손님이 문을 못 열어 연락이 오는 경우
중개인이 손님과 함께 왔는데 번호를 눌러도 문이 안 열리는 일이 있습니다. / 번호를 잘못 전달했거나 배터리가 약해졌거나, 집주인이 그사이 번호를 바꿨는데 말하지 않은 경우입니다.
이럴 때 중개인이 문을 억지로 열려고 하다가 도어락을 상하게 하는 일이 생길 수 있습니다. / 집주인에게 먼저 연락해 번호를 다시 확인하는 것이 순서입니다.
집주인과도 연락이 닿지 않으면 24시간 받는 전화로 상황을 알려 주세요. / 이때 신분 확인이 필요하니 집주인이 본인 확인을 도와줄 수 있는지 먼저 알아보시면 좋습니다.

# 누가 문을 열어 달라고 할 때는 신분 확인이 먼저입니다
저희는 문을 열기 전에 사시는 분이 맞는지 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
중개인이나 지인이 대신 연락한 경우에도 집주인이나 거주자 확인이 돼야 작업을 할 수 있습니다. / 번거롭게 느껴질 수 있지만 남의 집 문을 함부로 열지 않기 위한 절차입니다.
[이용안내](guide.html)에 이 절차를 따로 적어 두었으니 미리 읽어 보셔도 됩니다.

집을 보는 동안 현관문이 활짝 열려 있어 신경이 쓰인다면 중개인에게 문을 닫고 확인해 달라고 부탁하세요. / 가볍게 한마디 해 두는 것이 서로 편합니다.
특히 외출 중에 보여 주는 집이라면 보조키와 걸쇠 상태를 돌아올 때 한 번 더 살펴보세요. / 나올 때 누가 어떻게 잠갔는지 모르면 막상 돌아와서 문이 안 열리는 일도 생깁니다.

# 열쇠를 잃어버렸다면 거래 중이라도 바로 알리세요
맡긴 열쇠를 분실했다면 말하기 민망해도 바로 집주인에게 알려야 합니다. / 늦게 알릴수록 누가 어디서 주웠는지 알 수 없는 시간이 길어집니다.
열쇠 분실이 확실하면 번호키 교체나 실린더 교체를 생각해 볼 수 있습니다. / 상황에 맞춰 어떤 방법이 맞는지 [도어락 교체](doorlock-replace.html) 안내를 보시고 연락 주세요.
누가 책임질지는 당사자끼리 풀 문제이니 저희가 정해 드릴 수 없습니다.

# 거래가 끝나면 임시 번호는 바로 지우세요
계약이 끝나거나 열쇠를 돌려받으면 중개인용 임시 번호를 삭제합니다. / 번호를 따로 만들지 않았다면 이때 전체 번호를 새로 바꾸세요.
실물 열쇠나 카드키는 돌려받은 개수를 처음 적어 둔 숫자와 맞춰 봅니다. / 하나라도 비면 어디 있는지 확인하고, 확인이 안 되면 번호키 쪽을 바꾸는 편이 마음 편합니다.
@ 부곡동 거래 후 도어락 번호 재설정

# 세입자가 바뀔 때는 도어락도 같이 정리합니다
세입자가 이사 나가고 들어올 때 이전 세입자 번호나 카드가 남아 있는지 확인해야 합니다. / 새로 들어오는 분이 번호를 새로 등록하면 이전 기록은 자연히 사라집니다.
도어락이 오래돼 반응이 느리거나 소리가 이상하면 [도어락 수리](doorlock-repair.html)로 먼저 손볼 수 있는지 봅니다. / 고쳐 쓸 수 있으면 교체까지 하지 않아도 됩니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
출장 요청을 하시면 문 상태와 도어락 종류를 확인한 뒤 얼마인지 먼저 안내합니다. / 괜찮다고 하시면 그때 작업을 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다.

# 부곡동 말고 군포 어디든 갑니다
부곡동 가까운 당정동, 산본동, 금정동, 당동, 오금동, 대야미동도 다닙니다. / 군포 안이면 24시간 출동합니다.
다니는 지역은 [출장 지역](area.html) 페이지에서 확인하실 수 있습니다.
