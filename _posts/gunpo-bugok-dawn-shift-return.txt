# 부곡동 새벽 귀가길, 번호판이 꺼져 있을 때
부곡동은 군포역 쪽 생활권으로 오가며 새벽 근무를 마치고 돌아오는 분이 있는 동네입니다. / 동이 트기 전 조용한 시간에 집 앞에 도착했는데 번호판이 반응하지 않으면 당황스럽고 지칩니다.
가족이 자고 있는 시간이라 큰 소리를 내기도 어렵고, 가까운 가게도 열려 있지 않아 마음이 급해집니다. / 이 글은 [군포 출장열쇠](gunpo.html) 입장에서 새벽 귀가 때 번호판이 반응하지 않을 때 순서를 정리했습니다.
@ 부곡동 새벽 현관 앞에서 번호판을 확인하는 모습

# 먼저 숨 고르고 상태를 구분하세요
새벽에 일하고 돌아오면 몸이 피곤해 작은 일도 크게 느껴집니다. / 번호판이 반응하지 않는 상태도 사실 몇 가지로 나뉘니 구분부터 해 보세요.
- 번호판에 불이 아예 들어오지 않는 경우
- 불은 들어오는데 번호를 눌러도 소리가 없는 경우
- 소리는 나지만 문이 안 열리는 경우
- 경고음이 길게 나고 입력이 막히는 경우
어느 쪽인지에 따라 다음 행동이 달라집니다. / 확실하지 않으면 손으로 번호판을 한 번 덮어 불이 들어오는지 보세요.

# 불이 아예 안 들어올 때
가장 흔한 이유는 배터리 방전입니다. / 퇴근 전후 시간에 갑자기 꺼지는 경우가 많은데, 사람 드나듦이 많은 집일수록 소모가 빠릅니다.
바깥쪽에 9V 건전지를 대는 비상 단자가 있다면 새벽에도 구할 방법이 있는지 생각해 보세요. / 24시간 편의점이 가까우면 건전지를 사서 대어 볼 수 있습니다.
USB 단자가 있는 제품이라면 보조배터리로도 번호판을 켤 수 있습니다. / 단자가 없거나 시도해도 반응이 없으면 그때 연락 주시면 됩니다.

# 불은 들어오는데 번호가 안 먹을 때
밤샘 근무 뒤라 번호를 순간적으로 헷갈릴 수 있습니다. / 한 자리씩 천천히 누르고, 누르는 소리가 나는지 들어 보세요.
평소 쓰던 번호가 아니라 가족이 며칠 전에 바꿨는데 모르고 있는 경우도 있습니다. / 가족이 깨어 있다면 문자로 먼저 확인해 보세요.
서너 번 틀리면 입력이 한동안 막힙니다. / 막힌 상태에서 계속 누르면 상태만 길어지니 멈추고 잠시 기다리세요.
@ 한 자리씩 천천히 번호를 누르는 손

# 가족이 안에서 자고 있다면
문을 두드리거나 벨을 누르면 소리가 크게 울려 이웃이 깨기도 합니다. / 먼저 문자나 메시지로 가족에게 조용히 알려 보세요.
안에서 열어 줄 수 있다면 가장 빠르고 문을 상하게 하지 않는 방법입니다. / 가족이 안에서 보조키만 풀어 주어도 해결되는 경우가 많습니다.
전화벨 소리에 놀라 깨는 가족이 있다면 진동으로 두고 짧게 메시지를 보내세요. / 가족이 깨지 못하는 상황이면 그때 출장을 요청하세요.

# 안쪽 보조키가 잠긴 경우
새벽에 가족이 나가며 안쪽 보조키를 잠가 두었거나, 문을 닫고 나가며 걸쇠를 건 경우가 있습니다. / 번호판이 정상인데 문이 안 열릴 때는 이쪽을 의심해 볼 수 있습니다.
보조키가 안쪽에서 잠기면 밖에서 번호를 눌러도 소용없습니다. / 이럴 때는 안에서 열어 줄 사람이 있는지부터 확인하세요.
안에 아무도 없다면 보조키를 밖에서 여는 작업이 필요합니다. / 이 경우 [현관문 개문](door-open.html)을 요청하시면 문을 덜 상하게 방법부터 시도합니다.

# 새벽 시간대에 하지 말아야 할 것
급하게 해결하려다 일을 키우는 경우가 많습니다. / 아래는 새벽에 특히 피해야 하는 행동들입니다.
- 졸린 상태에서 손잡이를 세게 당기거나 발로 차는 것
- 드라이버나 카드로 문틈을 벌리는 것
- 비밀번호를 계속 바꿔 누르며 시도하는 것
- 이웃의 문을 두드려 도구를 빌리는 것
이웃은 한밤중에 놀라기 쉽고 서로 불편한 일이 생길 수 있습니다. / 도구를 잘못 쓰면 문과 도어락이 상해 교체해야 하는 상황이 되기도 합니다.

# 조용히 기다릴 장소 정하기
출장을 요청하고 기다리는 동안 추운 현관 앞에 서 있기는 어렵습니다. / 군포역 쪽이나 24시간 문을 여는 곳이 있다면 잠시 몸을 녹일 수 있는지 생각해 보세요.
기온이 내려가는 시기에는 새벽 바깥 대기가 특히 힘듭니다. / 아파트라면 1층 공동 현관의 따뜻한 공간에서 기다릴 수 있는지 확인하세요.
이웃에게 폐가 되지 않게 복도에서 큰 소리로 전화하지 않는 것도 중요합니다. / 문자로 위치와 상황을 보내면 통화를 줄일 수 있습니다.
@ 건물 입구에서 휴대폰으로 상황을 정리해 문자를 보내는 모습

# 새벽에도 같은 순서로 진행합니다
시간이 늦어도 사시는 분인지 확인하는 절차는 줄지 않습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 경비실에 세대 확인을 먼저 부탁하는 방법도 있습니다. / 새벽 시간에는 경비실에 먼저 사정을 말해 두면 수월합니다.
비용은 문을 열기 전에 먼저 말씀드리고, 괜찮다고 하시면 그때 시작합니다. / 끝내 못 열면 비용은 받지 않습니다.

# 도착 후에는 소리부터 줄입니다
새벽에 일하는 분들은 가족의 잠을 아는 만큼 소음에 민감합니다. / 작업 중에도 소리가 작은 방법부터 시도하고, 이웃을 깨우지 않도록 조심합니다.
도어락 종류와 문 상태에 따라 걸리는 시간은 달라집니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.
문 열기 방법은 최대한 상하지 않게 하는 쪽을 먼저 택합니다. / 자세한 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 문이 열린 뒤 확인할 것
문이 열렸다면 번호판 상태와 배터리를 가장 먼저 확인합니다. / 배터리가 원인이었다면 새것으로 모두 교체하세요.
번호를 잊거나 가족이 바꾼 것을 몰라 문제가 된 경우에는 새 번호를 같이 정하고 가족에게 알립니다. / 기존 번호는 지우고 새 번호만 남겨 두면 헷갈림이 줄어듭니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 증상이 반복되면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 새벽 근무자가 미리 해 두면 좋은 준비
일이 시작되면 시간 여유가 없으니 평소에 준비해 두는 것이 가장 쉽습니다. / 아래 항목만 지켜도 새벽 문 앞에서 막히는 일이 크게 줄어듭니다.
- 배터리는 계절이 바뀔 때 한 번에 전부 교체
- 가방이나 차에 9V 건전지나 보조배터리 하나 넣어 두기
- 번호가 바뀌면 가족과 메시지로 바로 공유
- 퇴근 후 경고음이 나면 그날 안에 교체
그리고 믿을 만한 가족 한 명에게는 새벽에도 연락이 닿게 부탁해 두세요. / [열쇠 출장](key-call.html) 안내를 미리 읽어 두면 급할 때 덜 헤맵니다.

# 부곡동 말고 군포 어디든 갑니다
부곡동 가까운 산본동, 금정동, 당동, 당정동, 오금동, 대야미동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
방문 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
