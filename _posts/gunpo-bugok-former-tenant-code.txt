# 이사 온 첫날, 도어락 번호는 누가 알고 있을까
새 집에 들어가 짐을 풀다 보면 도어락 번호가 과연 나만 아는 번호인지 문득 궁금해집니다. / 이전 세입자나 집주인, 청소하러 온 사람이 쓰던 번호가 그대로일 수 있기 때문입니다.
군포역 쪽에서 부곡동으로 이사 오는 분들께 가장 먼저 권하는 것도 이 확인입니다. / 이 글은 군포 부곡동에서 이사 후 이전 번호가 남아 있는지 살펴보고 정리하는 순서입니다.
@ 부곡동 이사 후 도어락 번호 등록 확인

# 왜 이전 번호가 남아 있을 수 있나
도어락은 번호를 일부러 지우지 않으면 등록된 상태로 계속 남습니다. / 이사가 끝났다고 자동으로 초기화되는 것은 아닙니다.
- 이전 세입자가 마지막으로 쓴 번호가 그대로 남은 경우
- 집을 보여 주려고 임시로 공유한 번호가 남은 경우
- 인테리어나 청소 업체에 알려 준 번호가 남은 경우
- 카드키나 지문을 여러 개 등록해 두고 정리하지 않은 경우
누군가를 의심하자는 이야기가 아니라 관리 차원에서 한 번 정리하자는 취지입니다.
새로 이사한 집의 문은 아직 우리 집 생활 방식에 맞춰지지 않은 상태입니다. / 번호, 카드, 배터리 상태를 한 번에 정리해 두면 이후가 편합니다.

# 입주하자마자 해 보면 좋은 첫 확인
이사 당일에 해 둘 수 있는 일은 많지 않지만 효과는 큽니다. / 먼저 집주인이나 중개를 맡은 쪽에 번호를 어떻게 관리했는지 묻는 것부터 시작합니다.
- 문을 열 때 쓰는 번호가 몇 개인지
- 카드키나 리모컨이 몇 개 있는지
- 임시 번호 같은 기능을 사용했는지
확실하지 않다면 안전하게 전부 새로 정하는 쪽이 낫습니다. / 기존 정보를 비우고 새로 시작하면 걱정할 일이 줄어듭니다.

# 도어락에서 등록 정보를 확인하는 일반적인 방법
제품마다 방식은 다르지만 흐름은 비슷합니다. / 관리자 모드에 들어가 등록된 번호나 카드 목록을 보거나, 한꺼번에 지우는 메뉴를 쓰는 식입니다.
- 번호 목록을 보여 주는 제품은 몇 개가 등록됐는지 알려 줍니다
- 일부 제품은 목록 확인 대신 전체 삭제만 제공합니다
- 음성 안내가 나오는 제품은 안내에 따라 단계별로 진행합니다
설명서를 보면 기본 설정 방법이 적혀 있습니다. / 설명서가 없다면 제품 이름을 사진으로 찍어 알려 주세요.
@ 부곡동 도어락 관리자 모드 설정 메뉴

# 마스터 번호나 관리자 번호는 따로 있을 수 있어요
일부 도어락에는 일반 번호와 별개로 관리자 번호가 설정되어 있습니다. / 이전 사용자가 이 번호를 바꾸지 않고 두었다면 설정 메뉴에 들어갈 수 있는 사람이 이전 사용자일 수 있습니다.
관리자 번호를 모르는 상태에서 설정을 건드리기는 어렵습니다. / 이럴 때는 억지로 풀기보다 현장에서 제품을 보고 방법을 정하는 편이 안전합니다.
관리자 번호도 새로 정해 두면 앞으로 관리가 훨씬 편해집니다.
새로 정한 관리자 번호는 일반 번호와 다르게 정하고 가족 중 한두 명만 알도록 하는 편이 좋습니다. / 메모할 때는 번호를 그대로 적기보다 자신만 아는 방식으로 남기세요.

# 초기화는 신중하게 해야 합니다
모든 등록 정보를 지우는 가장 확실한 방법은 초기화입니다. / 하지만 방법을 잘못 알고 시도하면 오히려 문이 안 열리는 일이 생길 수 있습니다.
- 초기화 뒤에 기본 번호로 돌아가는지, 아예 등록이 비는지 제품마다 다름
- 초기화 직후 새 번호 등록을 못 하면 문이 열린 채로 둘 수 있음
- 문이 안에서 잠겨 있는 상태에서 초기화하면 곤란해질 수 있음
초기화는 문을 열어 둔 채로, 새 번호를 바로 등록할 수 있는 상태에서 하는 것이 안전합니다.

# 임대차 관련 확인은 서로 소통으로
세입자와 집주인이 번호 관리에 대해 이야기해 두면 오해가 줄어듭니다. / 입주 전에 번호를 바꾸는 것이 괜찮은지 미리 알리면 좋습니다.
계약 내용에 따라 도어락 교체나 수리 책임이 다를 수 있어서 이 글에서는 따로 판단하지 않습니다. / 궁금하면 계약서를 보거나 집주인과 상의하세요.
번호를 바꿨다면 집주인이 필요할 때 연락할 수 있는 방법만 서로 정해 두면 충분합니다.

# 번호를 모르거나 안 열릴 때
이사 당일 번호를 알려 받았는데도 문이 안 열리는 일도 있습니다. / 번호를 잘못 받았거나 이전 사용자가 이미 바꿔 둔 경우입니다.
먼저 집주인에게 번호를 다시 확인하세요. / 그래도 안 되면 번호판 상태(불이 들어오는지, 소리가 나는지)를 알려 주시면 됩니다.
배터리가 방전된 집이라면 바깥쪽 비상 단자에 9V 건전지를 대는 방법이 통하기도 합니다. / 단자가 없거나 안 되면 연락 주세요.
@ 부곡동 이사 날 현관문 앞 번호 입력

# 하지 말아야 할 행동
번호를 여러 번 틀리면 입력이 잠시 막히는 제품이 있습니다. / 서너 번 해 보고 안 되면 멈추는 게 좋습니다.
문틈에 카드나 도구를 끼워 열려는 시도도 하지 마세요. / 이사한 집의 새 문을 처음부터 흠집 내게 됩니다.
이전 사용자를 찾아가 번호를 직접 묻거나 따지는 일도 피하세요. / 중개를 맡은 쪽이나 집주인을 통해 확인하는 것이 맞습니다.

# 전화하실 때 말씀해 주세요
위치와 상황을 간단히 정리해 주시면 됩니다.
- 부곡동 어느 쪽인지와 건물 종류, 호수
- 이사한 날짜와 번호를 받은 경위
- 번호판 상태(켜짐, 꺼짐, 경고음)
- 도어락 모양과 제품명 사진
사진을 보내 주시면 제품에 맞는 정리 방법을 먼저 안내해 드릴 수 있습니다. / [군포 출장열쇠](gunpo.html)로 편하게 연락 주세요.

문이 안 열려 출장을 요청하셨다면 사시는 분인지 확인부터 합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
막 이사하셔서 주소가 아직 바뀌기 전이라면 임대차 서류나 집주인 확인도 참고할 수 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.

# 신분 확인과 비용 안내는 문 열기 전에
도어락 종류와 작업 범위를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭙니다.
진행 방식은 [이용안내](guide.html)에, 번호 새로 등록하는 설치 관련은 [도어락 설치](doorlock-install.html)에서 볼 수 있습니다.

# 정리가 끝난 뒤 가족과 번호 공유 방법
번호를 새로 정했다면 가족끼리만 공유하고 메모는 안전한 곳에 둡니다. / 문 앞에 붙여 두거나 공유 채팅에 그대로 남기는 일은 피하세요.
카드키는 하나쯤 따로 보관하면 배터리 문제가 생겼을 때 도움이 됩니다. / 손님이나 가사도우미에게는 오래 쓰지 않을 임시 번호를 쓰는 방법도 있습니다.
제품이 너무 낡았거나 등록 방식이 불편하다면 [도어락 교체](doorlock-replace.html)를 상담받아 보셔도 됩니다.

# 부곡동 말고 군포 어디든 갑니다
산본동, 금정동, 당동, 당정동, 대야미동, 오금동도 24시간 다닙니다. / 군포 안이면 동네 구분 없이 연락 주세요. / 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.

# 자주 묻는 질문
? 이사 오자마자 번호를 꼭 바꿔야 하나요? | 꼭은 아니지만 이전 사용자 번호가 남아 있을 수 있어 바꾸는 쪽을 권합니다.
? 초기화하면 문이 안 열릴 수 있나요? | 방법을 잘못 하면 그럴 수 있어 문을 열어 둔 상태에서 새 번호를 바로 등록하는 순서가 안전합니다.
? 관리자 번호를 모르는데요? | 제품을 보고 방법을 정해야 해서 사진이나 현장 확인이 필요합니다.
? 못 열면 비용을 받나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.
? 밤에도 오시나요? | 24시간 받습니다. 시간 걱정 없이 전화 주세요.
