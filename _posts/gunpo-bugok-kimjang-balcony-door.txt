# 김장철, 잠깐 나왔다가 문이 닫혔다면
부곡동은 금정역과 군포역 사이 생활권에서 주택과 아파트 단지가 이어진 동네입니다. / 11월 김장철에는 배추를 나르고 양념을 버무리느라 현관과 베란다를 오가는 일이 많아집니다.
쓰레기를 버리러 나갔다가 문이 닫혔거나, 베란다에서 일하다 문이 잠겨 버렸다는 연락도 이 시기에 늘어납니다.
이 글은 김장과 베란다 작업 중 문이 잠긴 상황에서 순서대로 할 일을 적었습니다.
@ 부곡동 김장철 현관과 베란다 작업

# 어느 쪽에서 막혔는지 먼저 정리
같은 잠김이라도 위치에 따라 해결이 다릅니다. / 어느 쪽인지 정리해 보세요.
- 현관 밖으로 나왔는데 문이 닫혀 못 들어가는 경우
- 베란다에 나갔다가 미닫이 문이 잠긴 경우
- 집 안은 열려 있는데 양손에 짐을 든 채 번호를 못 누르는 경우
- 안에서 보조키를 잠근 채 나갔다 오는 경우
위치만 알려 주셔도 전화로 안내가 가능합니다.
김장철에는 사람이 많이 오가고 문을 여러 번 열고 닫아서 평소엔 없던 잠김이 생깁니다. / 급할수록 어느 문에서 막혔는지, 안에 사람이 있는지부터 짧게 정리하세요.
그 두 가지만 알려 주셔도 통화가 빨라집니다.

# 현관 밖에서 닫힌 경우 먼저 확인할 것
먼저 도어락 번호판에 손을 대 보세요. / 양념 묻은 손으로 누르면 번호가 제대로 인식되지 않을 수 있습니다.
수건으로 손과 번호판을 닦고 다시 눌러 보면 열리는 일이 많습니다. / 장갑을 낀 채라면 벗고 눌러야 정확히 입력됩니다.
그래도 안 열린다면 비밀번호를 여러 번 틀리지 않도록 멈추는 것이 좋습니다.
@ 양념 묻은 손과 도어락 번호판

# 베란다에 갇혔다면 안전이 먼저
베란다에서 문이 잠겨 못 들어가는 상황은 급하지 않아 보여도 날씨가 찬 때는 위험할 수 있습니다. / 몸을 따뜻하게 하고 휴대폰이 있는지 먼저 확인하세요.
휴대폰이 없다면 창문 너머 이웃에게 도움을 청하거나 가족에게 연락해 달라고 부탁합니다. / 난간이나 창틀로 이동하는 위험한 시도는 절대 하지 마세요.
베란다 바닥이 젖어 있는 김장철에는 미끄러짐도 조심해야 합니다. / 손에 양념이나 기름기가 있다면 닦고, 움직이기 전에 균형을 잡으세요.
오래 기다려야 할 것 같으면 두꺼운 겉옷을 먼저 챙겨 달라고 가족에게 부탁하세요.

# 미닫이 잠금이 걸린 원리
베란다 미닫이 문은 안쪽 레버나 돌림 잠금으로 잠깁니다. / 바깥에서 문을 밀다 보면 흔들림 때문에 잠금이 저절로 걸리는 경우가 있습니다.
오래된 창은 잠금 고리가 헐거워져서 더 잘 걸립니다. / 문을 살짝 들었다 내리거나 흔들면 풀리는 경우도 있지만 유리가 깨지지 않게 조심하세요.
관련 부품 점검은 [도어락 수리](doorlock-repair.html)와 비슷한 방식으로 봐 드립니다.
베란다 문 바닥 레일에 배추 부스러기나 물기가 끼면 문이 한쪽으로 쏠려 잠금 고리가 잘못 걸리기도 합니다. / 김장 뒤에는 레일을 한 번 닦아 주면 이런 일이 줄어듭니다.
잠금이 걸려도 문에 억지로 힘을 주지 말고 살살 좌우로 움직여 보며 상태를 확인하세요.

# 하지 말아야 할 것
급하다고 유리를 두드리거나 창틀을 발로 차면 다칠 수 있습니다. / 김장 도구인 칼이나 철 도구로 틈을 벌리는 것도 위험합니다.
- 문틈에 칼이나 드라이버를 끼우기
- 이웃집 베란다나 배관을 타고 이동하기
- 문을 세게 밀거나 당겨 유리가 깨지게 하기
- 번호를 계속 틀려 입력 잠금이 걸리게 하기
무리하게 열려다 다치면 그것이 가장 큰 손해입니다.

# 김장하는 날 생기는 흔한 장면
배추 절임 물을 버리러 나갔다가 문이 닫힌 경우가 있습니다. / 양념 묻은 손에 집 열쇠가 없어 문 앞에서 서성이는 상황입니다.
온 가족이 모여 있는데 현관 문이 안에서 보조키로 잠긴 일도 있습니다. / 어린아이가 장난으로 잠그는 경우도 있어 문 너머로 계속 말을 걸어 주세요.
집 안에 가스 불이나 전열 기구가 켜진 채라면 반드시 먼저 말씀해 주세요.
대가족이 모이는 날에는 여러 사람이 드나들어 누가 현관을 잠갔는지 모르는 일도 생깁니다. / 이럴 땐 집 안에 있는 사람이 열 수 있는지 먼저 물어보세요.
한 사람이 안쪽 보조키를 돌려 둔 것뿐인 경우도 많아 불러야 할지 판단하기 쉽습니다.

# 가스불이나 전열기가 켜져 있다면
김장 중에는 육수나 보쌈 삶는 불을 켜 둔 경우가 많습니다. / 이럴 때는 안전이 가장 급한 문제입니다.
집 안에 사람이 있다면 그분께 불을 끄게 하고, 아무도 없다면 바로 전화로 알려 주세요. / 이웃과 관리사무소에도 상황을 알려 두면 도움이 됩니다.
@ 현관 앞 김장 짐과 닫힌 문

# 출장열쇠에 요청하는 법
위치와 어느 문인지, 집 안에 사람이나 켜 둔 기구가 있는지 알려 주세요. / 도어락 종류를 알면 장비를 정확히 챙길 수 있습니다.
문을 열 때는 최대한 도어락과 문틀이 상하지 않게 작업합니다. / 자세한 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다.
[열쇠 출장](key-call.html) 안내도 함께 보시면 어떤 상황에 어떻게 부르는지 알 수 있습니다.
통화하면서 작업 전에 확인할 것들을 안내해 드리니 당황하지 않으셔도 됩니다. / 김장 재료가 밖에 쌓여 있다면 상하지 않도록 옮길 수 있는 사람이 곁에 있으면 좋습니다.
도착 시간은 거리에 따라 달라 통화 때 알려 드립니다.

# 도착하면 신분을 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
짐이 모두 집 안이라 신분증도 없는 경우에는 관리사무소에 세대 확인을 부탁하는 방법이 있습니다. / 확인이 어려우면 작업을 할 수 없으니 이웃이나 경비실에 미리 이야기해 두세요.

# 비용 안내
작업 전에 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않으며 열린 뒤에 말없이 붙는 비용도 없습니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 김장철 전에 해 둘 준비
도어락 배터리를 김장철 전에 한 번 점검해 두면 좋습니다. / 문 앞에 집 열쇠를 숨겨 두는 것은 권하지 않습니다.
- 현관 근처에 여분 열쇠나 카드키를 가족 한 명이 따로 보관하기
- 베란다 미닫이 잠금이 헐거운지 미리 확인하기
- 짐을 나르는 동안 현관문을 고정해 둘 도어스토퍼 쓰기
쓰레기를 버리러 나갈 때 휴대폰을 주머니에 넣는 습관만으로도 해결이 쉬워집니다.
도어스토퍼가 있으면 짐을 나르는 동안 문이 닫히지 않아 잠길 위험이 크게 줄어듭니다. / 현관 문턱에 두꺼운 수건을 말아 끼워 두는 방법도 임시로 쓸 만합니다.
문이 저절로 닫히는 속도가 빠른 집이라면 이 준비가 특히 도움이 됩니다.

# 부곡동에서 부르실 때
부곡동 어느 쪽인지, 금정역이나 군포역에서 어느 방향인지만 알려 주세요. / 24시간 전화를 받습니다.
산본동, 금정동, 당동, 당정동, 대야미동, 오금동도 다닙니다. / 지역은 [군포시 출장열쇠](gunpo.html)와 [출장 지역](area.html)에서 확인하세요.
