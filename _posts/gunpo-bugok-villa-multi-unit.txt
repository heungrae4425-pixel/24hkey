# 부곡동 빌라에서 문이 두 개라 더 헷갈립니다
부곡동은 금정역 쪽 생활권과 가까워 빌라와 다세대 주택에 사시는 분이 많은 동네입니다. / 아파트와 달리 건물 입구에 공동 출입문이 있고, 그 안쪽에 우리 집 현관문이 또 있는 구조가 흔합니다.
그래서 "문이 안 열린다"는 말 한마디에 실제로는 전혀 다른 두 가지 상황이 섞여 있습니다. / 건물 입구가 안 열리는 건지, 집 현관이 안 열리는 건지부터 갈라야 합니다.
이 글은 부곡동 빌라와 다세대 주택에서 두 문을 각각 어떻게 확인하고, [군포 출장열쇠](gunpo.html)에 연락할 때 무엇을 먼저 말하면 좋은지 적었습니다.
@ 부곡동 빌라 공동 출입문 잠금 출장열쇠

# 먼저 어느 문에서 막혔는지 구분하세요
빌라 문제는 위치에 따라 해결하는 사람이 달라집니다. / 순서를 잘못 잡으면 시간만 길어집니다.
- 건물 입구 공동 출입문이 안 열리는 경우
- 입구는 들어왔는데 우리 집 현관문이 안 열리는 경우
- 계단 중간이나 옥상 출입문처럼 공용 공간 문이 잠긴 경우
- 우편함이나 공용 창고 같은 부속 시설이 잠긴 경우
공동 출입문은 건물 전체가 함께 쓰는 문이라 임의로 손대기 어려운 면이 있습니다. / 반면 우리 집 현관문은 사시는 분 확인만 되면 바로 진행할 수 있습니다.

# 공동 출입문이 안 열릴 때 확인할 것
공동 현관은 대개 번호키나 카드키, 또는 열쇠를 함께 씁니다. / 평소와 다르게 반응이 없다면 아래부터 살펴보세요.
- 번호판에 불이 들어오는지, 눌렀을 때 소리가 나는지
- 최근에 건물 비밀번호가 바뀌었다는 공지가 있었는지
- 다른 입주민이 같은 시간에 들어가고 있는지
- 문이 내려앉아 바닥이나 문틀에 걸리는 느낌은 없는지
빌라는 관리사무소가 없는 곳이 많아서 건물주나 대표 입주민에게 먼저 물어보는 게 빠릅니다. / 같은 층 이웃에게 비밀번호를 물어보는 것도 현실적인 방법입니다.

# 건물 공용 문은 누구 허락이 필요한가
공동 출입문은 한 집의 소유가 아니라서 입주민 사이의 합의가 중요합니다. / 건물주나 관리를 맡은 분이 있다면 그분 의견을 먼저 확인하는 게 순서입니다.
저희는 이 문제를 법적으로 단정해서 말씀드리지는 않습니다. / 다만 현장에서 입주민 확인이 되지 않으면 작업을 미루고 먼저 연락을 돌려 보시길 권합니다.
급한 사정이 있어 지금 당장 들어가야 한다면 상황을 솔직히 말씀해 주세요. / 가능한 방법과 필요한 확인 절차를 같이 설명드립니다.
@ 부곡동 다세대 주택 현관 도어락 점검

# 우리 집 현관문이 안 열릴 때는 원인이 단순한 편입니다
건물 안으로 들어왔다면 이제부터는 일반 현관문 문제로 보시면 됩니다. / 배터리, 비밀번호, 보조키, 걸쇠 순서로 나눠 보면 대부분 정리됩니다.
번호판이 꺼져 있으면 배터리부터 의심합니다. / 도어락 아래쪽 비상 단자에 9V 건전지를 대 보면 번호가 들어가기도 합니다.
번호는 눌러지는데 모터 소리만 나면 걸쇠 쪽을 봐야 합니다. / 이럴 때는 문을 살짝 안쪽으로 밀면서 손잡이를 돌려 보세요.
빌라 현관문은 철문이 많고, 오래되면 문이 조금씩 처져 문틀에 닿는 경우가 있습니다. / 문을 들어 올리듯 당기면서 돌리면 풀리기도 합니다.

# 계단과 복도가 좁아서 생기는 일
빌라는 복도가 좁고 계단이 가파른 곳이 많습니다. / 문을 억지로 당기거나 발로 차면 이웃에게 소리가 크게 퍼지고, 문 자체도 상합니다.
밤에는 작은 소리도 건물 전체에 울립니다. / 늦은 시간이라면 조용히 해결할 수 있는 방법을 우선하는 게 서로에게 좋습니다.
작업 중에는 복도에 공구를 펼쳐 놓아야 해서 이웃 통행을 막지 않도록 신경 씁니다. / 계단참이나 문 앞 공간이 좁으면 미리 알려주셔도 됩니다.

# 위치와 건물 상태를 이렇게 알려주세요
빌라는 건물 이름이 없거나 같은 골목에 비슷한 건물이 이어지는 경우가 많습니다. / 지도 앱의 도로명 주소와 눈에 띄는 가게, 가까운 역 방향을 함께 말씀해 주시면 찾기 쉽습니다.
- 도로명 주소와 호수, 몇 층인지
- 금정역, 군포역 등 어느 쪽에서 오는 길이 가까운지
- 건물 입구 문이 열리는 상태인지, 아직 밖에 계신지
- 우리 집 도어락의 모양과 번호판 상태
- 집 안에 사람이나 반려동물이 있는지
사진을 문자로 보내주시면 장비를 맞춰 가기 좋습니다. / 입구와 현관문 모두 찍어 주시면 더 좋습니다.

# 도착하면 사시는 분인지 먼저 확인합니다
빌라는 이웃 간 거리가 가까워서 확인 절차가 더 중요합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소나 건물 관리인 확인 가운데 하나면 됩니다.
세입자이신 경우에는 임대차 계약서나 공과금 고지서가 도움이 되기도 합니다. / 서류가 집 안에 있다면 휴대폰으로 찍어 둔 사진이 있는지 찾아보세요.
확인이 되지 않으면 작업을 할 수 없습니다. / 번거로우셔도 서로를 지키는 절차라 양해 부탁드립니다.

# 비용은 열기 전에 먼저 말씀드립니다
문 종류와 상태를 보고 얼마가 드는지 작업 전에 말씀드립니다. / 괜찮다고 하셔야 시작하고, 아니라고 하시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열린 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다. / 자세한 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
@ 군포 부곡동 빌라 현관문 개방 작업

# 열쇠 방식 현관이라면 이런 점이 다릅니다
빌라에는 아직 열쇠로 여는 현관문이 많이 남아 있습니다. / 열쇠가 돌아가지 않거나 안에서 열쇠를 꽂아 둔 채 닫힌 경우도 따로 확인해야 합니다.
열쇠가 뻑뻑하게 돌아가면 억지로 힘을 주지 마세요. / 열쇠가 부러지면 실린더 안쪽에서 빼내는 일이 훨씬 어려워집니다.
열쇠 방식은 도어락보다 배터리 걱정이 없는 대신 실린더 마모가 문제가 됩니다. / 자세한 내용은 [현관문 개문](door-open.html) 안내를 참고해 주세요.

# 열고 난 뒤에 해두면 좋은 점검
문이 열렸다면 다시 잠기고 열리는지 한 번 더 시험해 봅니다. / 안쪽 손잡이, 보조키, 걸쇠가 모두 제대로 움직이는지 같이 봅니다.
비밀번호를 잊어서 연 경우에는 새 번호를 등록하고 이전 번호는 지웁니다. / 가족에게 새 번호를 알려 주는 것까지 해두시면 같은 일이 반복되지 않습니다.
도어락 자체가 오래돼 자주 말썽이면 [도어락 수리](doorlock-repair.html)를 먼저 권해 드립니다. / 고쳐서 쓰기 어려울 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 빌라 생활에서 문 앞 실수를 줄이는 습관
작은 습관 몇 가지가 문 앞에서 막히는 일을 많이 줄여 줍니다.
- 건물 입구 비밀번호가 바뀌면 가족 모두에게 바로 알리기
- 열쇠 하나는 믿을 만한 곳에 따로 맡겨 두기
- 도어락 배터리는 해가 바뀔 때 한꺼번에 교체하기
- 택배나 분리수거로 잠깐 나갈 때도 휴대폰은 꼭 챙기기
- 문이 덜 닫히거나 걸쇠가 뻑뻑하면 미루지 말고 점검하기
공동 출입문이 고장 나면 건물 전체에 불편이 갑니다. / 이상 증상을 먼저 본 사람이 건물주나 이웃에게 알려 두는 것만으로도 큰 도움이 됩니다.

# 부곡동 밖 군포 어디든 갑니다
부곡동 옆 산본동, 금정동, 당동, 당정동, 대야미동, 오금동도 모두 다닙니다. / 군포 안이라면 동네와 상관없이 24시간 출동합니다.
다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에, 서울과 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 건물 관리인이 없는 빌라도 가능한가요? | 가능합니다. 신분증이나 주소가 적힌 우편물로 사시는 분인지 확인합니다.

? 문 열고 나서 비밀번호도 바꿔 주시나요? | 네, 새 번호 등록과 배터리 교체까지 같이 해드립니다.
