# 분명히 닫았는데 자꾸 문이 열려 있다고 합니다
대야미역을 이용하는 대야미동 주민들은 출퇴근 시간에 문을 서둘러 닫고 나가는 일이 많습니다. / 그런데 도어락이 문이 열려 있다고 경고음을 내거나 자동으로 잠기지 않아 불안해하는 경우가 있습니다.
문은 분명 닫혀 있는데 도어락만 아니라고 말하는 상황입니다. / 이럴 때 원인은 대개 닫힘을 감지하는 센서나 걸쇠의 위치에 있습니다.
이 글은 대야미동에서 이런 증상을 만났을 때 직접 확인할 수 있는 것과, 점검을 맡기는 시점을 정리했습니다.
@ 대야미동 도어락 닫힘 센서 점검

# 도어락은 문이 닫혔는지 어떻게 알까
도어락 안쪽에는 문이 닫혔는지 알려주는 작은 센서나 스위치가 있습니다. / 문틀에 있는 받침판과 걸쇠가 맞물릴 때 이 신호가 들어갑니다.
신호가 제대로 들어가야 자동 잠금이 작동하고 잠금 표시가 켜집니다. / 신호가 어긋나면 문이 닫혀 있어도 열림으로 판단합니다.
그래서 도어락 본체가 멀쩡해도 문과 문틀 사이가 조금만 틀어지면 이런 증상이 나올 수 있습니다.

# 경고음의 종류로 대략 짐작해 보기
소리를 잘 들어보면 원인을 좁히는 데 도움이 됩니다. / 제품마다 소리는 다르지만 경향은 비슷합니다.
- 문을 닫아도 짧게 반복되는 삑 소리: 열림 감지가 계속 되는 경우
- 잠금 소리는 나는데 표시등이 안 바뀌는 경우: 센서 쪽 문제
- 모터는 도는데 걸쇠가 나오지 않는 경우: 구동부 점검 필요
어떤 소리인지 영상이나 녹음으로 남겨 두면 설명이 쉬워집니다. / 전화로 말로 설명하는 것보다 훨씬 정확합니다.

# 문을 한 번 더 확실히 닫아 보기
가장 간단한 방법은 문을 평소보다 조금 더 힘 있게 닫아 보는 것입니다. / 걸쇠가 받침판 구멍에 끝까지 들어가지 못해 센서가 작동하지 않았을 수 있습니다.
문 손잡이를 아래로 누른 채 닫고, 손잡이를 놓으면서 문을 살짝 밀어 보세요. / 이때 철컥 소리와 함께 잠금 표시가 켜지면 일시적인 어긋남이었던 것입니다.
다만 이런 일이 며칠 계속된다면 문틀이나 경첩이 틀어졌을 가능성을 의심해야 합니다.

# 문틈과 받침판 위치 살펴보기
문을 닫은 상태에서 문틈을 가만히 살펴보세요. / 위쪽과 아래쪽 틈의 간격이 다르면 문이 한쪽으로 처진 것입니다.
받침판이 걸쇠와 어긋나 있으면 걸쇠 끝이 구멍 모서리에 닿는 흔적이 남기도 합니다. / 받침판에 반짝이는 긁힌 자국이 있다면 오래전부터 위치가 맞지 않았다는 뜻입니다.
이런 흔적은 사진으로 찍어 두면 점검할 때 큰 도움이 됩니다. / 문 가장자리를 따라 한 장, 걸쇠 쪽을 가까이서 한 장 찍어 주시면 충분합니다. / 눈으로 확인하기 어려운 부분은 무리해서 손대지 마세요.
@ 군포 출장열쇠 대야미동 걸쇠 받침판

# 이물질이 센서를 막는 경우
의외로 흔한 원인이 먼지입니다. / 문틈에 쌓인 먼지나 작은 이물질이 걸쇠 주변에 들어가 센서를 가리기도 합니다.
도장이 두꺼워서 받침판 구멍이 좁아지거나, 붙인 스티커나 테이프가 걸쇠에 걸리는 경우도 있습니다. / 이 경우는 청소만으로 해결되기도 합니다.
마른 천으로 걸쇠 끝과 받침판 구멍을 닦고, 면봉으로 구석을 살짝 닦아 주세요. / 기름이나 물을 뿌리는 것은 오히려 고장의 원인이 되니 피하세요.

# 건전지가 약할 때도 비슷한 증상이 나옵니다
배터리가 약하면 센서 신호를 정확히 읽지 못하는 제품이 있습니다. / 평소에는 괜찮다가 아침저녁으로 증상이 달라진다면 의심해 볼 만합니다.
건전지를 전부 새것으로 바꾸고 증상이 사라지면 원인은 전원이었던 겁니다. / 일부만 바꾸거나 오래된 것과 섞어 쓰면 같은 증상이 다시 나옵니다.
교체 후에도 변화가 없다면 센서나 걸쇠 쪽을 살펴볼 차례입니다.
건전지는 제품에 맞는 규격을 쓰고, 극 방향을 맞춰 끼웠는지 한 번 더 보세요. / 방향이 반대로 끼워져 있으면 반응이 불안정하거나 아예 켜지지 않습니다.

# 겨울과 장마철에 심해지는 이유
추운 날에는 금속이 수축하고 문틀이 미세하게 움직입니다. / 그 사이 받침판과 걸쇠의 위치가 달라져 센서가 흔들릴 수 있습니다.
장마철에는 습기로 문이 부풀어 걸쇠가 꽉 물리기도 합니다. / 계절에 따라 증상이 오락가락한다면 문 자체의 변형이 원인일 수 있습니다.
이럴 때는 도어락보다 문틀과 경첩 점검이 먼저입니다. / 자세한 내용은 [도어락 수리](doorlock-repair.html) 페이지에 정리해 두었습니다.

# 이럴 땐 직접 분해하지 마세요
안쪽 도어락을 열어 센서를 만지고 싶은 마음이 들 수 있습니다. / 하지만 선이 얇고 부품이 작아 한번 건드리면 되돌리기 어렵습니다.
나사를 풀었다가 다시 조립하지 못해 문을 못 잠그는 상황이 더 곤란합니다. / 특히 밖에서 열리지 않게 되는 사고가 나기도 합니다.
설명서에 없는 부품은 만지지 말고 증상을 기록해 두세요. / 언제부터 어떤 소리가 나는지 적어 두면 충분합니다.
아이가 있는 집이라면 도어락 커버를 아이 손이 닿지 않게 두고, 반복되는 경고음을 가볍게 넘기지 마세요. / 대야미동처럼 출퇴근으로 문을 서둘러 닫는 집일수록 확실히 닫는 습관이 도움이 됩니다.

# 점검을 맡길 때 알려주실 것
출장을 요청하실 때는 아래 내용을 알려주시면 좋습니다. / [군포 출장열쇠](gunpo.html)로 연락하시면 상황에 맞는 장비를 준비해 갑니다.
- 대야미동 어디쯤인지, 대야미역 방향인지
- 경고음의 종류와 시작된 시점
- 문이 열리는지, 잠기지 않는지, 안 열리는지
- 도어락 사진이나 영상
문이 아예 안 열리는 상황이라면 [현관문 개문](door-open.html)이 먼저 필요합니다.

# 신분 확인과 비용 안내는 문 열기 전에
점검만 하더라도 사시는 곳이 맞는지 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 끝나면 문 상태를 본 뒤 비용을 먼저 말씀드립니다. / 동의하신 뒤에 시작하며, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않고, 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
@ 대야미동 도어락 점검 출장 비용 안내

# 고쳐 쓸지 바꿀지 판단하는 기준
센서 오작동은 걸쇠 위치 조정이나 받침판 교체로 해결되는 경우가 많습니다. / 이럴 때는 도어락 전체를 바꿀 필요가 없습니다.
다만 같은 증상이 반복되거나 제품이 오래되어 부품이 맞지 않을 때는 교체를 말씀드립니다. / 그때도 먼저 상태와 이유를 설명드립니다.
점검이 끝나면 다음에 비슷한 증상이 나타났을 때 어디를 먼저 볼지도 알려드립니다. / 한 번 알아 두면 같은 일에 덜 놀라게 됩니다.
교체를 선택하시면 [도어락 교체](doorlock-replace.html)에서 기준을 확인하실 수 있습니다. / 억지로 권하지 않습니다.

# 대야미동에서 군포 어디든
대야미동 바로 옆 산본동, 당동, 당정동, 금정동, 부곡동, 오금동도 24시간 출동합니다. / 군포 안이면 동네와 관계없이 가능합니다.
군포에서 다니는 동네는 [군포시 출장열쇠](gunpo.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
