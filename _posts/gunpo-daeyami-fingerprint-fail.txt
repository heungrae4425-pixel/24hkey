# 어제까지 되던 지문이 갑자기 안 먹을 때
대야미역에서 내려 집 앞에 서서 지문을 대는데 삑 하는 실패음만 반복되면 속이 탑니다. / 번호를 따로 외워 두지 않고 지문만 믿고 지내던 분이라면 더 그렇습니다.
지문 인식은 편하지만 손 상태와 센서 상태에 따라 결과가 달라지는 방식입니다. / 이 글은 대야미동에서 지문이 안 먹을 때 확인할 것을 순서대로 정리했습니다.
@ 대야미동 지문 도어락 인식 실패

# 지문이 실패하는 흔한 이유
지문 인식이 갑자기 나빠졌다면 센서보다 손 쪽 이유가 먼저인 경우가 많습니다.
- 손이 젖었거나 아주 건조해서 지문 골이 흐려진 경우
- 로션, 핸드크림, 먼지가 묻은 경우
- 손가락 끝이 다치거나 굳은살이 생긴 경우
- 센서 표면에 얼룩이나 기름때가 낀 경우
- 등록할 때와 다른 각도로 대는 경우
이 중 하나만 해결해도 다시 되는 일이 많습니다. / 하나씩 확인해 보세요.

# 손부터 정리하고 다시 대 보세요
손을 마른 수건으로 닦고 잠시 숨을 돌린 뒤 다시 대 보세요. / 너무 차가운 손도 지문 인식이 잘 안 되니 주머니에 넣어 따뜻하게 한 뒤 시도하세요.
겨울에는 손이 건조해 지문이 평평해집니다. / 핸드크림은 바르고 바로 대지 말고 잘 스며든 다음에 쓰는 게 좋습니다.
센서에 대는 손가락은 지문 중앙이 센서 중심에 오도록 평평하게 대고 잠깐 멈춰 주세요. / 대자마자 떼면 읽는 시간이 모자랍니다.

# 센서 표면 닦는 요령
센서에 기름때가 쌓이면 인식률이 떨어집니다. / 부드러운 마른 천이나 안경 닦는 천으로 살살 닦아 주세요.
알코올이나 세정제를 직접 뿌리는 것은 권하지 않습니다. / 센서 틈으로 스며들면 오히려 고장이 날 수 있습니다.
도어락 표면을 날카로운 것으로 긁어 닦는 것도 금물입니다. / 센서 코팅이 상하면 인식이 영영 나빠질 수 있습니다.
@ 군포 지문 센서 닦는 방법

# 등록을 다시 하면 좋아지는 경우
처음 등록할 때 지문을 한 번만 대고 끝낸 경우 인식이 들쑥날쑥합니다. / 같은 손가락을 각도를 바꿔 여러 번 등록하면 훨씬 안정적입니다.
- 같은 손가락을 중앙, 왼쪽, 오른쪽으로 나눠 등록
- 두 손가락 이상 등록해 두기
- 손이 건조한 계절과 습한 계절에 한 번씩 재등록
- 아이나 어르신은 지문이 얕으니 번호나 카드도 같이 쓰기
등록한 지 오래된 지문일수록 손 모양이 달라졌을 수 있습니다. / 등록 방법은 제품마다 다르니 사용설명서를 먼저 확인해 보세요.

# 번호나 카드로 먼저 들어가는 방법
지문이 안 될 때를 대비해 번호와 카드를 같이 등록하는 집이 많습니다. / 번호가 기억난다면 먼저 번호로 들어가고, 안에서 지문을 다시 등록하면 됩니다.
번호도 모르고 카드도 없다면 아래 순서로 판단해 보세요. / 배터리가 문제라면 번호판 불빛이 아예 안 들어옵니다.
번호판이 꺼져 있으면 바깥 아래의 비상 단자에 9V 건전지를 대 볼 수 있습니다. / 대고 있는 동안 번호를 누르는 방식입니다.

# 센서가 고장 난 것 같을 때 확인할 점
다음 증상이 있으면 센서나 본체를 의심해 보세요.
- 어떤 손가락으로 해도 아예 반응하지 않는다
- 센서에 불이 안 들어오거나 깜빡이기만 한다
- 지문 표면이 갈라지거나 금이 가 있다
- 전에 없던 경고음이 반복된다
분해해서 안쪽을 보겠다고 나사를 푸는 분도 계시는데 연결선이 끊기기 쉽습니다. / 이런 경우는 스스로 분해하지 마세요. / 안쪽 연결부가 상하면 [도어락 수리](doorlock-repair.html)가 더 길어집니다.

급하면 손잡이를 세게 당기거나 문틈에 도구를 넣는 분이 계십니다. / 걸쇠가 더 물리거나 문틀이 상할 수 있습니다.
급하다고 손잡이를 세게 당기거나 문틈에 도구를 넣는 것은 피해 주세요. / 걸쇠가 더 물리거나 문틀이 상합니다.
지문을 여러 번 틀리면 도어락이 입력을 한동안 막는 제품이 많습니다. / 서너 번 안 되면 멈추고 잠시 기다린 뒤 번호를 시도하세요.
센서에 물을 뿌리거나 도어락을 두드리지 마세요. / 안쪽 회로가 상할 수 있습니다.

# 전화할 때 알려주시면 좋은 정보
대야미동 어느 쪽이고 대야미역에서 가까운지 위치를 알려주시고 아래도 함께 말씀해 주세요.
- 지문이 아예 안 되는지, 가끔 안 되는지
- 번호나 카드로는 열리는지
- 번호판 불빛과 경고음 상태
- 도어락 앞면 사진
- 집 안에 아이나 반려동물이 있는지
지문만 되는 제품이라 번호가 없다면 먼저 말씀해 주세요. / 열기 방식이 달라집니다.

# 도착하면 신분 확인을 합니다
문이 안 열리는 집에 들어가는 일이라 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소나 경비실 확인을 부탁해 보세요. / 확인이 어려우면 작업할 수 없습니다.
이 절차는 모두에게 똑같이 적용합니다.

# 비용은 말씀드리고 시작합니다
도어락과 문 상태를 보고 문 열기 전에 비용을 먼저 말씀드립니다. / 동의하시면 시작하고, 아니시면 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 하기 전에 한 번 더 여쭙니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
작업은 덜 상하는 방법부터 차례로 합니다. / 지문 도어락은 안쪽 부품이 정교해서 힘을 쓰면 쉽게 상하기 때문입니다.

지문 도어락은 안쪽 부품이 정교해서 힘을 쓰면 쉽게 상합니다. / 덜 상하는 방법부터 차례로 하고 도어락과 문을 지키는 것을 우선합니다.
자세한 방식은 [현관문 개문](door-open.html) 페이지에서 볼 수 있습니다.
@ 대야미동 출장열쇠 지문 도어락 개문

# 열린 뒤 센서와 설정 정리
문이 열리면 센서가 정상인지, 등록이 남아 있는지 함께 확인합니다. / 필요하면 지문을 다시 등록하고 번호와 카드도 같이 정리합니다.
고쳐서 쓸 수 있으면 교체를 권하지 않습니다. / 너무 낡거나 반응이 반복해서 나쁘면 [도어락 교체](doorlock-replace.html)를 상담해 드립니다.
문이 열린 후에 센서 상태를 같이 점검하므로 따로 시간을 내지 않으셔도 됩니다. / 스마트 도어락 고르는 기준을 알고 싶다면 상담 때 편하게 물어보세요.

# 지문 도어락 오래 쓰는 습관
- 센서는 주 1회 마른 천으로 가볍게 닦기
- 배터리는 지문 반응이 느려지기 전에 교체
- 번호나 카드를 비상용으로 꼭 같이 등록
- 비상용 9V 건전지를 집이나 가방에 하나 두기
- 손이 젖은 채 대지 않기
작은 습관이 인식률을 오래 지켜 줍니다. / 식구 중 지문이 얕은 분이 있다면 번호를 함께 쓰도록 안내해 두세요.
어르신이나 아이가 쓴다면 지문만 의지하지 말고 카드 한 장을 따로 지니게 하면 안심입니다.

# 대야미동 말고 군포 어디든 갑니다
대야미동 가까이 산본동, 금정동, 당동, 당정동, 부곡동, 오금동도 다닙니다. / 군포 안이면 24시간 출동합니다.
[군포시 출장열쇠](gunpo.html)에 정리해 두었고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 센서만 따로 바꿀 수 있나요? | 제품에 따라 다릅니다. 직접 보고 말씀드립니다.
? 새벽에도 오시나요? | 24시간 전화를 받습니다.
