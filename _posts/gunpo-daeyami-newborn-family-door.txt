# 아기가 잠든 사이 문이 닫혀 버렸다면
대야미동에서 갓 태어난 아기를 키우는 집이라면 밤낮이 없는 하루를 보내고 있을 겁니다. / 그런 생활 속에서 현관 문 문제까지 생기면 마음이 철렁 내려앉습니다.
대야미역을 오가며 장을 보거나 병원을 다니는 일이 잦은 시기라 문을 여닫는 횟수도 늘어납니다. / 짐을 들고 아기를 안고 있으면 문을 확인할 여유가 없어 실수가 생기기도 합니다.
이 글은 신생아와 영유아가 있는 집에서 도어락을 쓸 때 주의할 점과, 문이 잠겼을 때의 대처를 정리했습니다. / 놀라지 않고 순서대로 움직일 수 있게 쓰려고 했습니다.
@ 대야미동 영유아 가정 현관 도어락

# 아기를 안고 문을 열 때 생기는 일
양손이 모두 바쁜 상황에서 번호를 누르다 보면 오타가 잦아집니다. / 몇 번 틀리면 도어락이 입력을 잠시 막아 기다려야 합니다.
아기가 칭얼거리는 상황이라면 마음이 급해져 더 실수하기 쉽습니다. / 이럴 때는 짐을 잠깐 내려놓고 숨을 고른 뒤 천천히 누르는 편이 오히려 빠릅니다.
문 앞에 작은 선반이나 놓을 자리가 있으면 도움이 됩니다. / 장바구니와 가방을 놓아야 손이 자유로워집니다.
유모차를 밀고 들어오는 날에는 문이 닫히는 속도에도 신경이 쓰입니다. / 문이 너무 빨리 닫히면 도어클로저를 점검해 보는 것도 방법입니다.

# 번호판을 아기 손이 닿지 않게
아이가 자라 걷기 시작하면 손이 닿는 번호판이 호기심의 대상이 됩니다. / 눌러 보다가 경고음이 울리거나 입력이 막히기도 합니다.
안쪽 잠금 손잡이와 보조키도 아이가 장난으로 돌릴 수 있는 위치에 있습니다. / 가능하면 아이 키보다 높은 위치로 관리하세요.
문 안쪽에 아이가 열 수 없게 하는 보조 잠금을 쓰는 집도 있습니다. / 이럴 때는 어른도 바깥에서 열리지 않는 경우가 있으니 가족이 잘 알고 있어야 합니다.

# 안쪽 보조키는 누가 언제 잠그는지 정해 두기
아기가 자는 밤에는 안쪽 보조키를 잠가 두는 집이 많습니다. / 그런데 새벽에 가족이 먼저 나가거나 늦게 들어오는 날에 이 보조키가 문제를 일으킵니다.
번호를 맞게 눌러도 문이 안 열려서 당황하는 경우가 대부분 이 상황입니다. / 가족끼리 보조키를 잠그는 시간과 푸는 시간을 정해 두면 이런 일이 확 줄어듭니다.
조용히 하려고 벨을 누르지 않고 기다리는 분도 계신데, 이때는 전화를 먼저 해 보세요. / 아기가 깰까 봐 망설여도 문 앞에서 오래 기다리는 것보다 낫습니다. / 가족이 일어나 문을 열어 주는 것이 가장 빠릅니다.

# 아기와 둘만 있는데 문이 안 열릴 때
혼자 아기를 보고 있는데 문이 열리지 않으면 불안이 큽니다. / 먼저 아기가 안전한 곳에 있는지 확인하세요.
그다음 도어락 상태를 살핍니다. / 번호판이 꺼졌다면 배터리 문제이고, 켜지는데 안 열리면 보조키나 걸쇠를 의심해 봅니다.
안쪽에서는 보통 손잡이를 돌려 열 수 있으니, 외출이 급하지 않으면 문을 연 채로 상황을 확인해도 됩니다. / 다만 이때도 억지로 힘을 쓰지 마세요.

# 아기가 안에 있고 나는 밖일 때
택배를 받으러 잠깐 나왔다가 문이 닫힌 경우가 대표적입니다. / 아기가 안에 있다는 사실이 가장 크게 마음을 압박합니다.
이런 때는 이웃이나 경비실에 먼저 상황을 알리고 전화를 빌려 [군포 출장열쇠](gunpo.html)에 연락하세요. / 안에 아기가 혼자 있다고 가장 먼저 말씀해 주시면 순서를 앞당겨 정합니다.
문 너머로 아기에게 계속 말을 걸어 안심시켜 주세요. / 소리를 들려주면 아기도 덜 놀랍니다.
@ 군포 출장열쇠 대야미동 아기 안에 있을 때 문 개방

# 가장 먼저 해야 할 말, 전화로 이렇게
통화는 짧고 분명하게 하는 것이 좋습니다. / 아래 내용을 순서대로 알려주세요.
- 대야미동 위치와 건물, 동, 호수
- 집 안에 아기가 혼자 있는지, 다른 사람이 있는지
- 아기가 깨어 있는지, 자고 있는지
- 도어락이 켜지는지 여부
이 정보로 우선순위를 판단하고 가장 빠른 방법을 안내합니다. / 119나 다른 도움이 필요한 상황이라고 판단되면 그것도 함께 말씀드립니다.

# 문 열기 전에 신분 확인은 꼭 합니다
급한 상황이어도 사시는 분인지 확인은 필요합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁하세요. / 이웃에게 부탁해 확인 요청을 먼저 해 두면 시간이 줄어듭니다.
아기가 안에 있는 상황이라도 확인이 끝나기 전에는 작업이 어렵다는 점을 양해해 주세요. / 이 절차는 모두를 지키기 위한 것입니다.

# 비용은 먼저 설명드리고 시작합니다
급한 상황에서도 비용은 먼저 말씀드립니다. / 문 상태와 도어락 종류를 본 뒤 설명하고, 동의하신 뒤에 시작합니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 더해지는 항목은 없고, 부품 교체는 따로 여쭙습니다.
진행 순서는 [이용안내](guide.html)에 정리해 두었고, 개방 방식은 [현관문 개문](door-open.html)에서 보실 수 있습니다.

# 문 여는 동안 아기를 덜 놀라게 하려면
작업 중에는 문 쪽에서 소리가 날 수 있습니다. / 안에 있는 아기에게 갑작스러운 소리가 들리지 않도록 문 너머로 목소리를 계속 들려주세요.
가능하면 안에 보호자나 이웃이 있도록 조율하는 것도 좋습니다. / 작업은 가능한 한 조용하고 빠르게 마치도록 진행합니다.
문이 열리면 아기부터 안아 안심시키고, 도어락 점검은 그다음에 합니다. / 급하게 서두르지 않으셔도 됩니다.

# 열린 뒤 아기 있는 집 도어락 점검
문이 열리면 원인을 짚어 드립니다. / 배터리 문제라면 새것으로 전부 바꾸고, 자동 잠금이 원인이라면 설정 방법을 같이 살핍니다.
한밤중에 아기가 깨지 않도록 조용한 모드로 설정하는 제품도 있습니다. / 소리 설정도 가족 상황에 맞게 정해 보세요.
자동 잠금은 편리하지만 아기를 안고 있을 때는 문이 닫혀 잠기는 순간을 놓치기 쉽습니다. / 가족 상황에 맞게 설정을 바꾸는 것이 도움이 됩니다.
고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 해결하고, 너무 낡았다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 대야미동 도어락 점검 아기 있는 집

# 영유아 가정에서 미리 챙길 것
작은 준비가 큰 위기를 막아 줍니다. / 아래 정도만 챙겨 두세요.
- 현관 근처에 9V 건전지를 따로 보관
- 배터리 교체일을 정해 도어락 안쪽에 메모
- 가족 중 한 명은 항상 번호를 알고 연락 가능하게
- 택배 받으러 나갈 때 열쇠나 휴대폰을 같이 들기
- 관리사무소와 이웃 연락처를 휴대폰에 저장
쓰레기를 버리러 나갈 때도 문이 완전히 닫히기 전에 손으로 잡는 습관이 효과적입니다.

# 대야미동 말고 군포 어디든
대야미동 바로 옆 산본동, 당동, 당정동, 금정동, 부곡동, 오금동도 24시간 출동합니다. / 군포 안이면 동네와 관계없이 갑니다.
군포에서 다니는 동네는 [군포시 출장열쇠](gunpo.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
