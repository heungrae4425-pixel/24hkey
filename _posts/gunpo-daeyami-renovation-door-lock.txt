# 공사가 시작되면 현관부터 몰라보게 변합니다
대야미동에서 집 안을 고치기 시작하면 가장 먼저 사람이 드나드는 곳이 현관입니다. / 대야미역에서 오가는 길에 공사 인부들이 자재를 들고 수십 번 문을 열고 닫습니다.
이때 도어락이 먼지와 페인트, 테이프 자국에 시달리기 쉽습니다. / 공사가 끝났는데 문이 안 열려 곤란해지는 일도 드물지 않습니다.
이 글은 인테리어나 리모델링을 앞둔 분이 현관 도어락을 미리 보호하고 공사 중에 쓰는 방법, 끝난 뒤 점검할 것을 정리했습니다. / 문제가 생기면 [군포 출장열쇠](gunpo.html)에 연락하시면 됩니다.
@ 대야미동 인테리어 공사 현관 도어락 보호

# 공사 전에 미리 정해 둘 것
시작하기 전에 도어락을 어떻게 쓸지 업체와 정해 두세요. / 이 한 번의 대화가 공사 내내 훨씬 마음을 편하게 합니다.
- 공사 기간 동안 현관 번호를 누가 알아도 되는지
- 일과가 끝나면 문을 잠그는 책임이 누구에게 있는지
- 도어락을 떼어 두고 할지, 그대로 둘지
- 문이 열린 채 자재가 오가는 동안 도어락 앞을 비워둘지
도어락을 그대로 둔다면 번호를 하나 새로 만들어 인부 전용으로 쓰는 방법이 가장 흔합니다.

# 공사 전용 번호를 따로 만드세요
가족이 쓰는 번호를 업체에 알려주면 공사가 끝난 뒤에도 그 번호가 남아 걱정됩니다. / 공사 기간만 쓰는 번호를 따로 등록하세요.
번호를 여러 개 등록할 수 있는 도어락이라면 간단합니다. / 하나만 저장되는 제품은 공사 중에만 번호를 바꾸고 끝나면 새 번호로 다시 바꾸는 방식이 됩니다.
공사 끝나는 날 이 번호를 지우는 약속을 담당자와 문자로 남겨 두세요.

# 먼지와 페인트, 도어락이 가장 싫어합니다
도어락 번호판과 틈새에 분진이 들어가면 센서가 둔해지고 모터가 뻑뻑해집니다. / 페인트나 퍼티가 튀어 굳으면 닦아도 흔적이 남습니다.
공사 전에 도어락 앞면과 손잡이를 비닐과 마스킹 테이프로 감싸 주세요. / 단, 번호판 부분을 꽉 막으면 인부가 번호를 못 누르니 필요할 때 열 수 있게 하세요.
테이프는 오래 붙여 두면 끈끈이가 남습니다. / 며칠 단위로 한 번씩 확인해 필요하면 교체하세요.
@ 대야미동 리모델링 도어락 마스킹 보양

# 문을 새로 칠하거나 교체할 때
현관문 표면을 시트지나 페인트로 바꾸는 경우 도어락 주변이 가장 신경 쓰입니다. / 도어락을 떼어내고 작업하는 편이 마감이 깔끔하다는 말을 듣기도 합니다.
도어락을 뗄 때는 나사와 부품이 섞이지 않게 작은 통에 모아 두세요. / 제대로 다시 달려면 순서와 방향이 중요합니다.
문 자체를 교체한다면 도어락도 새 문에 맞는지 확인해야 합니다. / 두께와 보조키 위치는 [도어락 설치](doorlock-install.html)에서 안내합니다.

# 도어락을 떼어 두었다면 임시 잠금은 어떻게
공사 중 도어락을 떼어 두면 문이 잠기지 않는 상태가 됩니다. / 빈집이나 부분 공사에서는 문이 열려 있는 시간이 길어질 수 있어 신경이 쓰입니다.
이럴 때는 임시 잠금을 따로 마련하는 방법을 업체와 의논하세요. / 공사 중에는 열쇠를 가진 담당자만 출입하게 하는 곳도 있습니다.
하루 일과가 끝나면 마지막으로 나가는 사람이 문이 잠겼는지 확인하는 약속이 필요합니다. / 확인했다는 사진 한 장을 보내 달라고 요청하는 곳도 있습니다.
귀중품이나 서류는 공사 전에 미리 다른 곳으로 옮겨 두세요. / 현관을 여러 사람이 오가는 기간에는 집 안에 두는 물건이 적을수록 마음이 편합니다.

# 공사 중 잠기거나 안 열리는 일
공사 중에는 평소와 다른 일이 생깁니다. / 자재가 문에 닿아 문틀이 눌리거나 걸쇠가 걸리는 경우도 있습니다.
인부가 번호를 눌렀는데 안 열린다고 연락이 오면 아래를 확인하세요.
- 번호판에 먼지가 쌓이거나 테이프가 눌려 있지는 않은지
- 배터리가 약해지지 않았는지
- 문 아래나 틈에 자재가 걸려 문이 틀어지지 않았는지
- 번호를 틀리게 여러 번 눌러 입력이 막힌 상태는 아닌지
확인해도 안 되면 억지로 힘을 쓰지 말고 연락 주세요. / 문을 힘으로 당기거나 도구로 비집으면 문틀이 상해서 공사 마감까지 다시 해야 할 수 있습니다.

# 배터리는 공사 전에 한 번 갈아 두세요
공사 기간에는 문을 하루에도 수십 번 여닫습니다. / 평소보다 배터리를 훨씬 빨리 씁니다.
시작 전에 새 건전지로 모두 바꿔 두면 공사 중간에 꺼지는 일을 줄일 수 있습니다. / 건전지는 일부만이 아니라 전부 같이 교체하는 것이 좋습니다.
공사 중간에 경고음이 울리면 바로 갈아 주세요. / 비상용 9V 건전지를 하나 챙겨 두면 안심이 됩니다.

# 열쇠집을 부르는 때
인부가 못 들어가거나, 내가 못 들어가는 상황이 되면 연락 주세요. / 집 주인이 직접 부르는 것이 원칙입니다.
공사 중이라 현장에 사람이 많고 위치가 어수선할 수 있으니 전화할 때 현장 상황을 같이 말씀해 주세요. / 문을 상하게 하지 않고 여는 방식은 [현관문 개문](door-open.html) 안내에 있습니다.
공사 담당자가 대신 연락하는 경우라도 집 주인의 확인이 필요합니다.

# 열기 전에 확인하는 것
문을 열기 전에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나가 필요합니다.
공사 중인 집은 빈집처럼 보일 수 있어 확인을 더 꼼꼼히 합니다. / 이웃과 집 주인을 지키는 절차로 예외 없이 진행합니다.
@ 대야미동 출장열쇠 현관문 개방 신분 확인

# 비용은 열기 전에, 못 열면 받지 않습니다
문과 도어락 상태를 본 뒤 먼저 비용을 말씀드립니다. / 괜찮으시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 여쭙니다.
진행 순서는 [이용안내](guide.html)에서도 확인하세요.

# 공사가 끝난 뒤 점검 목록
공사가 끝나면 도어락을 한 번에 점검하세요. / 아래를 순서대로 해보면 문제를 일찍 알아챌 수 있습니다.
- 번호판 표면에 페인트나 먼지가 남아 있지 않은지
- 문을 닫을 때 걸쇠가 매끄럽게 들어가는지
- 공사 전용 번호를 지웠는지
- 배터리를 새로 바꿨는지
- 보조키와 열쇠가 모두 정상인지
이 중 하나라도 이상하면 [도어락 수리](doorlock-repair.html)로 점검을 받으세요.

# 아예 새 도어락으로 바꾸고 싶다면
공사 김에 도어락을 바꾸는 집이 많습니다. / 문이나 마감이 달라졌다면 지금이 교체하기 좋은 때입니다.
새 제품을 고르기 전에 문 두께와 보조키 위치를 확인하세요. / 교체 전 확인할 점은 [도어락 교체](doorlock-replace.html)에 정리해 두었습니다.
비용은 설치하기 전에 먼저 말씀드립니다. / 마음에 안 들면 안 하셔도 됩니다.

# 자주 묻는 질문
? 공사 중 번호를 인부에게 알려줘도 되나요? | 공사 기간만 쓰는 번호를 따로 만들어 주고, 끝나면 지우는 편이 안전합니다.
? 도어락을 떼어 놓고 공사해도 되나요? | 가능하지만 임시 잠금을 업체와 의논하고, 다시 달 때 방향과 부품을 확인해야 합니다.
? 페인트가 튀었는데 어떻게 닦나요? | 굳기 전에 마른 천으로 닦고, 굳었다면 번호판 틈에 무리하게 문지르지 말고 점검받으세요.
? 못 열면 돈을 내야 하나요? | 못 열면 비용은 받지 않습니다.
? 공사 끝나고 번호도 바꿔 주나요? | 네, 번호 정리와 배터리 교체까지 같이 도와드립니다.
