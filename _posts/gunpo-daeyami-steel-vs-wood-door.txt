# 도어락은 문 재질에 따라 맞는 제품이 달라요
대야미동에서 도어락을 바꾸려고 알아보다 보면 가장 먼저 막히는 질문이 있습니다. / 우리 집 문이 철문인지 목문인지에 따라 고를 수 있는 제품이 달라진다는 점입니다.
대야미역 쪽 주택가나 빌라, 작은 사무실 출입문까지 문 모양이 제각각이라 같은 제품을 모두에게 권하기 어렵습니다. / 이 글은 군포 대야미동에서 철문과 목문을 기준으로 도어락을 고르는 순서를 정리한 것입니다.
@ 대야미동 철문 도어락 설치 전 문 재질 확인

# 우리 집 문이 철문인지 목문인지 구분하는 법
겉으로는 도장이 되어 있어 헷갈릴 때가 많습니다. / 문 옆면을 손가락으로 두드려 보면 소리로 구분할 수 있습니다.
- 맑고 차가운 소리가 나고 자석이 붙으면 철문입니다
- 둔탁하고 따뜻한 소리가 나며 자석이 붙지 않으면 목문입니다
- 겉은 나무 무늬인데 자석이 붙으면 철문에 필름을 입힌 경우입니다
구분이 어렵다면 문 옆면 사진을 한 장 찍어 두세요. / 전화로 보내 주시면 재질을 같이 봐 드립니다.
철문 위에 목재 느낌의 시트를 붙인 집이 의외로 많습니다. / 이런 문을 목문으로 착각하고 제품을 고르면 고정 방식이 맞지 않을 수 있습니다.

# 철문에 도어락을 달 때 보는 것
철문은 속이 비어 있는 구조가 많아서 도어락을 고정하는 힘이 좋은 편입니다. / 대신 문 두께와 안쪽 보강판 위치에 따라 맞는 제품이 갈립니다.
문 가장자리의 모양도 중요합니다. / 문틀과 맞닿는 부분이 평평한지, 턱이 있는지에 따라 걸쇠 길이가 달라집니다.
오래된 철문은 기존 구멍을 그대로 쓰는 경우가 많습니다. / 이때는 새 제품의 몸통 크기가 기존 구멍에 들어가는지가 핵심입니다.
구멍이 너무 크거나 작으면 가림판을 쓰거나 위치를 조정하는 방법을 먼저 설명해 드립니다. / 문에 큰 구멍을 새로 내야 하는 작업은 꼭 사전에 말씀드리고 진행합니다.

# 목문에 도어락을 달 때 달라지는 점
목문은 철문보다 얇은 곳이 있고 나무 결이 있어 구멍 위치가 조금만 어긋나도 티가 납니다. / 습기를 먹으면 문이 부풀기 때문에 여유를 두고 설치해야 합니다.
나무 문은 오래 쓰면 나사 구멍이 헐거워지기도 합니다. / 이런 문에 무거운 제품을 달면 처짐이 생길 수 있어 몸통 무게도 함께 봅니다.
목문은 문 안쪽 틈이 작아 걸쇠가 문틀에 닿는 정도가 민감합니다. / 설치 뒤 문을 여러 번 여닫아 걸쇠가 부드럽게 들어가는지 꼭 확인합니다.
장마철을 한 번 지나고 나면 목문이 달라지는 경우도 있어서, 처음에는 문틀과 약간 여유를 두는 편이 안전합니다. / 이 부분은 현장에서 문 상태를 보고 판단합니다.

# 문 두께는 줄자로 직접 재 보세요
도어락을 고를 때 빠지지 않는 항목이 문 두께입니다. / 문을 열고 경첩 쪽이 아닌 손잡이 쪽 옆면에서 앞뒤 면 사이를 재면 됩니다.
두께를 정확히 모르면 제품이 맞지 않아 다시 가져가는 일이 생깁니다. / 대략 수치와 함께 문 사진을 보내 주시면 맞는 제품 후보를 좁혀 드립니다.
@ 대야미동 목문 두께 줄자로 재는 모습

# 철문 도어락 고를 때 내구성 쪽을 살펴보세요
철문은 바깥 현관으로 쓰는 경우가 많아 비바람과 먼지를 그대로 받습니다. / 번호판 틈새로 물이 스며들지 않는 구조인지, 외부 커버가 단단한지 보는 게 좋습니다.
바깥쪽에 노출되는 부분이 많은 집이라면 실내 전용으로 만든 제품은 피하는 편이 낫습니다. / 대야미동처럼 들판이나 산이 가까운 곳은 먼지와 습기 영향도 함께 생각해야 합니다.

# 목문 도어락은 무게와 고정 방식을 확인합니다
목문은 지지하는 힘이 철문보다 약해서 앞뒤 몸통이 서로 단단히 조여지는지가 중요합니다. / 긴 고정 볼트가 문 가운데를 관통하는 방식인지 확인해 두면 좋습니다.
문이 얇은 경우에는 안쪽 몸통이 크게 튀어나오지 않는 제품이 어울립니다. / 문을 열었을 때 벽이나 신발장에 몸통이 닿지 않는지도 같이 봅니다.

# 지문·번호·카드, 재질과는 상관없을까
인식 방식은 문 재질과 크게 상관이 없습니다. / 오히려 가족 구성과 생활 습관에 따라 고르는 편이 만족도가 높습니다.
- 아이가 열쇠 대신 번호를 쓰는 집은 번호 방식이 편합니다
- 손이 자주 젖거나 거친 일을 하면 지문 인식이 불안정할 수 있습니다
- 어르신이 있다면 큰 숫자판과 또렷한 음성 안내를 보세요
스마트 도어락 선택 기준은 [도어락 설치](doorlock-install.html) 페이지에 더 적어 두었습니다.

# 보조키와 걸쇠는 문 종류에 따라 다릅니다
도어락 위쪽에 보조키가 따로 있는지, 문틀에 걸리는 걸쇠가 어떤 모양인지도 문마다 다릅니다. / 철문과 목문 모두 보조키 위치를 맞추지 못하면 문이 닫혀도 잠기지 않는 일이 생깁니다.
기존 보조키를 그대로 쓸지 같이 바꿀지는 문 상태를 보고 정합니다. / 한꺼번에 바꾸는 게 좋은 경우와 따로 두어도 되는 경우를 설명해 드립니다.
보조키가 멀쩡한데 굳이 바꾸자고 권하지는 않습니다. / 필요한 부분만 손보는 쪽을 먼저 말씀드립니다.

# 설치 전에 사진으로 미리 알려 주시면 좋은 것
출장을 나가기 전에 아래 사진을 보내 주시면 맞는 제품을 챙겨 갈 수 있습니다.
- 문 전체와 도어락이 보이는 사진
- 문 옆면과 문틀 쪽에서 본 사진
- 지금 도어락 뒷면(안쪽) 사진
- 문 두께를 잰 줄자 사진
사진이 어렵다면 말씀만 해 주셔도 됩니다. / 현장에서 같이 확인하며 진행합니다.
@ 대야미역 근처 주택 현관문 도어락 교체 상담

# 기존 도어락을 떼고 바로 교체할 때의 순서
교체는 보통 기존 제품을 분리하고 구멍 상태를 확인한 뒤 새 제품을 맞추는 순서로 합니다. / 구멍이 맞지 않으면 억지로 끼우지 않고 먼저 말씀드립니다.
교체 후에는 문을 열고 닫으면서 걸쇠와 보조키가 제대로 작동하는지 함께 봅니다. / 비밀번호 등록과 사용법 설명까지 마치고 마무리합니다.
[도어락 교체](doorlock-replace.html) 진행 방식은 해당 페이지에서도 볼 수 있습니다.

# 비용은 시작 전에 먼저 말씀드립니다
문 재질과 선택한 제품, 작업 범위를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 작업을 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 작업 도중 추가 부품이 필요해 보이면 손대기 전에 먼저 여쭤봅니다.
신분 확인은 문을 여는 경우에 필요합니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나를 준비해 주세요.

# 군포 다른 동네도 같은 방식으로 찾아갑니다
대야미동 옆으로 산본동, 금정동, 당동, 당정동, 부곡동, 오금동까지 군포 안이면 모두 다닙니다. / 동네 구분 없이 24시간 연락을 받습니다.
다니는 곳은 [군포시 출장열쇠](gunpo.html) 페이지와 [출장 지역](area.html)에서 볼 수 있습니다. / 이용 순서는 [이용안내](guide.html)에 정리해 두었습니다.
