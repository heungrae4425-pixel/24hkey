# 아무도 안 만졌는데 번호판이 삑삑거립니다
대야미동은 대야미역을 중심으로 주택과 빌라, 아파트가 나뉘어 있고 한적한 골목도 많은 동네입니다. / 밤에 조용한 시간이면 현관 쪽에서 나는 작은 소리가 더 크게 들립니다.
현관문 앞을 지나는데 아무도 없는데도 도어락이 삑, 삑 소리를 내거나 번호판 불이 혼자 켜졌다 꺼진다는 연락이 있습니다. / 터치 패널이 스스로 눌린 것처럼 움직이는 증상입니다.
이 글은 대야미동에서 이런 증상이 생겼을 때 원인을 어떻게 나눠 보는지, 어디까지 직접 해보고 언제 [군포 출장열쇠](gunpo.html)를 부르면 되는지 순서대로 적었습니다. / 문이 안 열리는 상황이 아니라 아직 열리는 단계라면 더 여유 있게 읽으셔도 됩니다.
@ 대야미동 도어락 터치 패널 혼자 눌림 오작동

# 터치 패널은 어떻게 눌림을 알아채는지
터치식 번호판은 버튼을 누르는 대신 손가락이 닿을 때 생기는 전기적 변화를 읽습니다. / 그래서 실제로 누르지 않아도 다른 이유로 변화가 생기면 눌린 것으로 착각할 수 있습니다.
센서는 아주 예민하게 만들어져 있습니다. / 물기, 먼지, 정전기, 전원 부족이 모두 영향을 줄 수 있다는 뜻입니다.
먼저 증상이 언제 생기는지 기억해 보세요. / 비 오는 날만인지, 밤에만인지, 문을 세게 닫은 직후인지에 따라 원인이 달라집니다.

# 번호판 표면에 물기와 습기가 맺힌 경우
가장 흔한 원인은 표면의 물기입니다. / 아침저녁 기온 차가 큰 계절에는 현관 바깥쪽 번호판에 이슬처럼 습기가 맺힙니다.
대야미동처럼 산과 들이 가까운 곳은 새벽 습기가 많은 날이 있습니다. / 그럴 때 센서가 물방울을 손가락으로 읽어 혼자 눌리는 소리를 낼 수 있습니다.
마른 부드러운 천으로 번호판을 닦고 잠시 지켜보세요. / 닦은 뒤 조용해진다면 물기가 원인이었던 겁니다.

# 먼지와 끈적임, 보호 필름이 원인일 때
오래 쓴 번호판에는 손기름과 먼지가 얇게 쌓입니다. / 이 막이 센서의 기준을 흔들어 놓으면 반응이 들쭉날쭉해집니다.
번호판에 붙여 둔 보호 스티커나 투명 필름이 들떠 있는 경우도 있습니다. / 필름 아래로 공기나 습기가 들어가면 눌린 것처럼 읽히기도 합니다.
- 마른 천이나 안경 닦는 천으로 가볍게 닦기
- 물을 직접 뿌리거나 알코올을 흠뻑 묻히지 않기
- 들뜬 필름은 떼어 내고 다시 확인하기

# 배터리가 약해졌을 때도 비슷한 증상이 납니다
의외지만 전원이 부족하면 센서가 불안정해집니다. / 전압이 떨어지면 기준값이 흔들려서 아무도 안 눌렀는데 입력이 들어가는 일이 생깁니다.
이럴 때는 보통 낮은 경고음이나 배터리 부족 안내가 같이 나옵니다. / 안내 소리가 들린다면 오작동보다 먼저 배터리를 전부 새것으로 바꾸어 보세요.
일부만 바꾸면 전압이 맞지 않아 같은 증상이 남기도 합니다. / 새 배터리를 넣고도 계속되면 다음 단계로 넘어가면 됩니다.
@ 도어락 배터리 교체 후 번호판 반응 확인

# 정전기와 가까이 있는 물체도 의심해 보세요
건조한 날씨에는 정전기가 번호판에 영향을 주기도 합니다. / 문을 만지거나 옷이 스칠 때마다 삑 소리가 나는 경우가 이에 해당합니다.
현관문 바깥쪽에 걸어 둔 장식이나 우편물 꽂이, 택배 보관함이 번호판에 닿아 있지 않은지도 봐 주세요. / 바람에 흔들리는 물건이 번호판을 건드려 소리를 낼 때가 있습니다.
비닐이나 종이가 문틈에 끼어 번호판을 누르고 있는 일도 드물게 있습니다. / 눈으로 볼 수 있는 원인은 이렇게 먼저 지워 가는 게 순서입니다.

# 이럴 땐 하지 마세요
번호판을 뜯어서 안을 열어 보는 분이 있습니다. / 회로가 드러나면 오히려 다시 쓰지 못하게 되는 경우가 많으니 그대로 두세요.
증상이 있다고 해서 번호판에 물을 뿌려 닦거나 드라이기를 오래 대는 것도 좋지 않습니다. / 열이나 물이 센서와 기판에 남아 고장을 키울 수 있습니다.
혼자 눌리는 소리가 난다고 해서 배터리를 아예 빼 두는 것도 권하지 않습니다. / 그러면 문이 잠긴 채로 번호를 못 눌러 못 들어오는 일이 생길 수 있습니다.

# 오작동이 오래가면 생기는 일
혼자 눌리는 입력이 쌓이면 도어락이 비밀번호를 여러 번 틀렸다고 판단합니다. / 그러면 일정 시간 입력을 막아 정작 필요할 때 문이 안 열릴 수 있습니다.
밤새 소리가 반복되면 배터리도 빨리 닳습니다. / 아침에 출근하려는데 번호판이 완전히 꺼져 있는 상황으로 이어지기도 합니다.
그래서 증상이 보이면 미루기보다 그날 안에 원인을 가려 보는 편이 안전합니다. / 문이 아직 열릴 때 점검하면 훨씬 간단합니다.

# 직접 해봐도 그대로라면 전화 주세요
닦고, 배터리를 바꾸고, 문 주변 물건을 치웠는데도 증상이 계속된다면 센서나 기판 쪽 문제일 수 있습니다. / 이때는 눈으로 확인하기 어려우니 방문 점검이 빠릅니다.
전화로 증상이 언제 나는지, 어떤 소리가 나는지 말씀해 주시면 됩니다. / 가능하면 번호판 사진과 도어락 앞면 사진을 문자로 보내 주세요.
점검은 [도어락 수리](doorlock-repair.html) 쪽에서 보고, 부품을 바꿔야 하면 바꾸기 전에 먼저 여쭤봅니다. / 문 열기 전과 마찬가지로 비용은 일을 시작하기 전에 먼저 말씀드립니다.
@ 출장열쇠 기사가 도어락 센서 점검하는 모습

# 대야미동 위치는 이렇게 알려주세요
대야미동은 골목이 갈라지는 곳이 많아 대략의 위치 설명이 큰 도움이 됩니다. / 대야미역에서 어느 쪽인지, 주변에 눈에 띄는 건물이 있는지 알려주세요.
- 주택·빌라·아파트 중 어떤 건물인지
- 현관문이 건물 안쪽인지 바깥쪽인지
- 증상이 시작된 때와 소리가 나는 상황
- 지금도 번호로 문이 열리는지 여부
문이 아직 열리는 상태라면 급하게 서두르지 않으셔도 됩니다. / 시간이 편한 때를 말씀해 주시면 맞춰서 방문합니다.

# 방문하면 먼저 확인하는 것
문을 여는 일이 아니더라도 사시는 분이 맞는지는 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
확인이 끝나면 번호판 겉면부터 안쪽 배터리 칸, 연결 부분까지 차례로 봅니다. / 어디가 원인인지 설명해 드린 다음 어떻게 할지 함께 정합니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 너무 오래돼서 같은 증상이 반복될 것 같다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

오작동 때문에 입력이 막혀 문 앞에서 멈춘 경우도 있습니다. / 그때는 번호 입력을 계속 시도하지 말고 잠시 기다린 뒤 한두 번만 다시 눌러 보세요.
그래도 안 열리면 [현관문 개문](door-open.html)을 요청하시면 됩니다. / 문을 최대한 상하지 않게 여는 방법부터 차례로 해봅니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.

# 평소에 해두면 좋은 습관
번호판은 한 달에 한 번 정도 마른 천으로 가볍게 닦아 주세요. / 센서 표면이 깨끗해야 반응이 일정합니다.
- 배터리는 해가 바뀔 때쯤 한 번에 전부 교체
- 번호판에 접착식 장식이나 스티커 붙이지 않기
- 비 온 날이나 이슬 맺힌 날에는 물기 닦아 주기
- 평소와 다른 소리가 나면 그날 증상을 메모해 두기
메모해 두면 전화할 때 원인을 좁히기 쉽습니다. / 작은 기록 하나가 점검 시간을 줄여 줍니다.

# 대야미동 말고 군포 어디든 갑니다
대야미동에서 가까운 산본동, 금정동, 당동, 당정동, 부곡동, 오금동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 연락받습니다.
다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
