# 당동에서 번호도 앱 비밀번호도 기억 안 날 때
당동은 군포역과 금정역을 오가며 생활하는 분들이 많은 동네입니다. / 퇴근하고 현관 앞에 섰는데 도어락 번호가 떠오르지 않고 앱에 로그인하려니 비밀번호마저 생각나지 않으면 머리가 하얘집니다.
평소에 앱 하나로만 열던 분일수록 이런 상황이 갑자기 찾아옵니다.
이 글은 당동에서 도어락 앱 비밀번호까지 잊었을 때 순서대로 시도해 볼 방법과 안 될 때 연락하는 방법을 적었습니다.
@ 당동 도어락 앱 비밀번호 분실

# 두 가지를 잊은 것은 생각보다 흔합니다
특히 당동처럼 집에서 가까운 역과 일터를 오가는 분들은 하루 대부분을 밖에서 보내 도어락 번호를 누르는 횟수가 적어 쉽게 잊습니다. / 번호보다 얼굴이나 앱 알림에 익숙해져 있으면 더 그렇습니다.
이럴 때 가장 중요한 것은 당황하지 않는 것입니다. / 차분히 하나씩 확인하면 대부분 길이 보입니다.
도어락 번호는 문 앞에서만 누르니 가끔 헷갈리고, 앱 비밀번호는 한 번 로그인하면 오래 안 쓰게 됩니다. / 휴대폰이 바뀌거나 앱이 자동 로그아웃된 날 둘 다 기억나지 않는 일이 생깁니다.
가족이 번호를 바꿨는데 전달받지 못한 경우와도 구분해야 합니다. / 먼저 어떤 경우인지 가려보세요.
- 번호와 앱 비밀번호 모두 기억이 안 남
- 번호는 아는데 가족이 바꾼 것 같음
- 앱은 로그인되어 있는데 도어락 연결이 끊김
- 앱 계정 자체가 기억나지 않음

# 앱 비밀번호 재설정부터 해볼 수 있습니다
재설정 메일이 오지 않으면 스팸함도 확인해 보세요. / 문자 인증은 통신이 잘 잡히는 곳에서 요청하는 것이 좋습니다.
도어락 앱에는 보통 비밀번호 찾기 기능이 있습니다. / 가입한 이메일이나 휴대폰 번호로 인증해서 새 비밀번호를 만드는 방식입니다.
이메일 주소가 가물가물하면 평소 쓰던 메일 서너 개를 떠올려 보세요. / 인증 문자가 오는 번호가 지금 쓰는 번호인지도 확인하세요.
재설정이 되면 앱으로 도어락을 열 수 있는 경우가 많습니다. / 이 방법이 가장 빠르니 먼저 시도해 볼 만합니다.

# 도어락 번호는 어디에 적어 뒀는지 떠올려 보기
이사한 직후나 도어락을 달 때 번호를 따로 메모해 둔 곳이 있는지 떠올려 보세요. / 설명서 뒷면, 휴대폰 메모, 가족 단체방 같은 곳입니다.
가족에게 전화해 번호를 물어보는 것도 가장 간단한 방법입니다. / 혹시 임시 번호를 따로 만들어 둔 기록이 앱 안에 있는지도 확인해 보세요.
틀린 번호를 반복해서 누르면 도어락이 입력을 막습니다. / 두세 번 시도하고 안 되면 멈추는 게 좋습니다.
@ 당동 도어락 번호 입력 시도

# 로그인이 안 될 때 하지 말아야 할 일
앱에 연달아 틀린 비밀번호를 입력하면 계정이 일시적으로 잠길 수 있습니다. / 잠금이 풀릴 때까지 한참 기다려야 해서 더 늦어집니다.
다른 사람의 휴대폰에 내 계정을 입력해 로그인하는 것도 주의하세요. / 로그인 기록이 남아 보안상 좋지 않습니다.
도어락 번호판을 분해하거나 문틈을 벌리는 일은 하지 마세요. / 문과 도어락에 흠집이 생기면 나중에 더 큰 수리가 됩니다.

# 가족 공유 앱이라면 가족에게 부탁하세요
가족 계정이 없는 1인 가구라면 이웃이나 친구에게 부탁해서 내 계정의 인증 메일이나 문자를 대신 받아 달라고 하기보다는, 인증 가능한 본인 기기를 찾는 쪽이 안전합니다. / 인증번호는 다른 사람에게 알려주지 마세요.
도어락 앱은 가족 구성원을 추가해 함께 쓰는 경우가 많습니다. / 가족 중 누군가의 휴대폰에서 문을 열 수 있는지 먼저 물어보세요.
원격 열림 기능이 있는 모델이면 가족이 대신 열어 줄 수 있습니다. / 이웃에게 전화를 빌려 가족에게 연락하면 됩니다.
가족 모두가 같은 상황이라면 그때 출장열쇠를 부르시면 됩니다.

# 당동에서 연락할 때 말씀해 주세요
전화로 간단히 상황을 알려주시면 도움이 됩니다. / 군포역 쪽인지 금정역 쪽인지 정도만 말씀하셔도 위치를 가늠하기 쉽습니다.
- 동, 호수와 대략적인 방향
- 도어락 종류(앱 전용, 번호 겸용, 카드 겸용)
- 번호판 반응(켜짐, 꺼짐, 경고음)
- 집 안에 사람이나 반려동물이 있는지

# 본인 확인은 반드시 합니다
문을 여는 일이라 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나가 필요합니다.
앱 비밀번호를 모른다고 증명하는 것이 아니라 그 집에 사는 분인지를 보는 것입니다. / 번거롭더라도 이웃과 손님 모두를 위한 절차입니다.
확인이 어려우면 작업할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 확인하고 먼저 얼마인지 말씀드립니다. / 동의하시면 그때 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 나서 이유 없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 최대한 안 상하게 엽니다
앱 연동 도어락은 전자 부품이 많아 덜 건드리는 방식으로 진행합니다. / 문과 도어락 외관이 상하지 않는 방법부터 차례로 시도합니다.
작업 중 바꿔야 할 부품이 보이면 먼저 말씀드립니다. / 일반적인 순서는 [현관문 개문](door-open.html)에도 적어 두었습니다.
@ 당동 도어락 비파손 개문 작업

# 열고 난 뒤 번호와 앱을 정리하세요
문이 열린 뒤에는 도어락 번호를 새로 정하고 앱 계정도 정리합니다. / 비밀번호는 가족이 함께 아는 방식으로 정해 두세요.
앱 계정의 이메일과 휴대폰 번호가 최신인지 확인해 두면 다음에 재설정이 쉬워집니다. / 앱 하나에만 의존하지 말고 번호와 카드도 같이 등록해 두세요.
번호 등록이 자주 꼬이거나 동작이 불안정하면 [도어락 수리](doorlock-repair.html)로 점검받을 수 있고, 아주 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 비밀번호를 잊지 않는 습관
이 습관들은 당동뿐 아니라 어느 동네에서든 도움이 됩니다. / 특히 가족 중 앱을 쓰는 사람이 한 명뿐이라면 그 사람의 휴대폰이 바뀔 때를 가장 조심해야 합니다.
한 번에 다 바꾸기 어렵다면 번호 공유부터 시작해 보세요. / 가장 쉽고 효과가 큽니다.
- 도어락 번호는 외우기 쉬운 규칙으로 가족과 공유
- 앱 비밀번호는 비밀번호 관리 기능이나 가족만 아는 메모에 기록
- 카드키 하나는 지갑 밖에 별도 보관
- 휴대폰을 바꿀 때 앱 로그인 정보를 미리 확인
- 일 년에 한 번 번호를 바꾸며 가족과 다시 공유
기억에 기대지 않는 체계를 만들어 두면 문 앞에서 막히는 일이 줄어듭니다.

# 당동 밖 군포 어디든 갑니다
당동 가까이 산본동, 금정동, 당정동, 부곡동, 대야미동, 오금동도 다닙니다. / 군포 안이라면 24시간 출동합니다.
[군포시 출장열쇠](gunpo.html)에서 동네별 안내를 보시고, 다른 지역은 [출장 지역](area.html)을 확인해 주세요.

# 자주 묻는 질문
? 앱 비밀번호 재설정이 되면 출장열쇠는 필요 없나요? | 네, 앱으로 열리면 문제가 풀립니다. 안 될 때만 연락 주세요.
? 번호도 모르고 앱도 안 되는데 열어 주나요? | 네, 본인 확인 후 상태를 보고 진행합니다.
? 문을 못 열면 비용이 드나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 앱 도어락이라도 문이 상하나요? | 문과 잠금 부품이 덜 상하는 방법부터 시도합니다.
? 새 번호도 등록해 주나요? | 네, 문이 열린 뒤 새 번호 등록을 도와드립니다.

# 마무리
당동에서 도어락 앱 비밀번호까지 잊었다면 앱 재설정과 가족 확인부터 해보세요. / 그래도 안 되면 위치와 상황만 알려주시면 됩니다.
24시출장열쇠는 늦은 밤에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
