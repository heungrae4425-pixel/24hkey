# 문이 혼자 잠겨서 곤란했던 적 있으신가요
택배를 받으러 현관문을 열어 두고 잠깐 나갔는데 어느새 문이 잠겨 버린 경험이 있으실 겁니다. / 요즘 도어락은 문이 닫히면 몇 초 뒤 저절로 잠기는 기능이 기본인 제품이 많습니다.
금정역 방면으로 출퇴근하는 당동 주민분들 중에는 아침마다 급하게 나가다 이 기능 때문에 곤란했다는 분도 있습니다. / 이 글은 군포 당동에서 자동 잠김 시간 설정이 헷갈릴 때 확인할 것을 정리했습니다.
@ 당동 현관 도어락 자동 잠김 설정 확인

# 자동 잠김이란 어떤 기능인가
문이 닫힌 뒤 일정 시간이 지나면 걸쇠가 알아서 나오며 잠그는 기능입니다. / 열쇠를 돌려 잠그지 않아도 문이 닫히면 보안이 유지되는 장점이 있습니다.
하지만 사람이 문밖에 서 있는데도 작동한다는 점이 문제가 됩니다. / 잠깐 나갔다가 들어오려 할 때 문이 이미 잠겨 있으면 번호를 눌러야 합니다.
- 켜 둔 상태: 문이 닫히면 자동으로 잠금
- 꺼 둔 상태: 직접 잠금 동작을 해야 잠김
- 시간 설정이 있는 제품: 닫힌 뒤 몇 초 만에 잠글지 선택

# 어디서 시간을 조절하는지 찾기
제품마다 설정 방식이 달라 정답이 하나는 아닙니다. / 대체로 안쪽 몸통의 설정 버튼이나 번호판의 관리자 모드로 들어갑니다.
설정 메뉴가 음성 안내로 나오는 제품도 있습니다. / 안내가 나올 때 천천히 듣고 차례대로 따라가면 됩니다.
어떤 제품은 자동 잠김 설정을 켜고 끄는 것만 가능하고 시간 조절은 되지 않습니다. / 설명서를 확인해 시간 조절이 되는 제품인지 먼저 봅니다.

# 시간이 너무 짧으면 생기는 일
잠금 시간이 짧게 설정되어 있으면 쓰레기를 버리러 나갔다가 문이 곧바로 잠깁니다. / 번호를 아는 사람이라면 바로 열 수 있지만, 배터리가 약하거나 번호를 잊었다면 곤란합니다.
특히 아이가 문을 열고 잠깐 밖에 나갔을 때 자동으로 잠겨 못 들어오는 일이 흔합니다. / 아이에게 번호를 알려 줄 것인지도 가족이 함께 정해야 합니다.
어린 아이가 있는 집이라면 문이 닫히는 소리를 듣고 놀라는 일도 있습니다. / 아이와 함께 나갈 때는 어른이 먼저 문을 잡고 있는 습관이 도움이 됩니다.
@ 당동 현관 앞 택배 받으러 나간 사이 잠긴 문

# 시간이 너무 길면 생기는 일
반대로 잠금 시간이 너무 길면 문이 닫혔는데도 한참 동안 잠기지 않습니다. / 이때는 방범 측면에서 불안해질 수 있습니다.
문이 닫힌 줄 알고 나왔는데 실제로는 잠기지 않은 상태로 두게 되는 것입니다. / 나중에 확인해 보니 문이 열려 있었다는 일이 생기기도 합니다.
적당한 간격은 생활 방식에 따라 다릅니다. / 짧은 외출이 많으면 조금 여유 있게, 방범이 우선이면 짧게 두는 식으로 가족과 의논해 정해 보세요.
한 번 정한 시간은 며칠 써 보고 불편하면 다시 조정하면 됩니다. / 처음부터 완벽하게 맞추려 하지 않아도 괜찮습니다.

# 자동 잠김 때문에 갇히는 상황 막는 법
설정을 바꾸기 전이라도 습관으로 줄일 수 있는 일들이 있습니다.
- 잠깐 나갈 때도 휴대폰과 열쇠는 항상 챙기기
- 문 앞에 서서 택배를 받을 때는 문을 손으로 잡거나 괴어 두기
- 번호가 기억나지 않을 때를 대비해 카드키를 지갑에 넣어 두기
- 가까운 가족에게 번호나 카드를 맡겨 두기
이 정도 습관만으로도 문 앞에서 막히는 일이 많이 줄어듭니다.
집을 나서기 전에 문 손잡이를 잡고 한 번 뒤돌아보는 것만으로도 놓고 나온 물건을 떠올릴 수 있습니다. / 열쇠와 휴대폰, 카드 세 가지만 확인하는 습관이면 충분합니다.

# 이미 잠겨서 안 열릴 때 먼저 할 것
문이 잠겼는데 번호를 모를 때는 당황하지 말고 차례로 확인합니다. / 먼저 번호판에 불이 들어오는지 봅니다.
- 불이 켜지고 번호가 맞는데 안 열리면 걸쇠 쪽 문제일 수 있음
- 불이 아예 안 켜지면 배터리 방전 가능성이 높음
- 소리는 나는데 반응이 없으면 모터나 설정을 확인해야 함
바깥쪽 아래에 9V 건전지를 대는 단자가 있는 제품은 이 방법을 먼저 써 볼 수 있습니다. / 그래도 안 되면 억지로 힘을 쓰지 말고 연락 주세요.

# 하지 말아야 할 행동
문을 세게 당기거나 발로 차면 자동으로 나온 걸쇠가 문틀에 더 꽉 물립니다. / 도어락과 문틀 모두 상하기 쉬워 비용이 더 드는 결과가 생깁니다.
카드로 문틈을 밀어 보는 방법은 일부 영상에 나오지만 문 모양에 따라 소용이 없고 손상만 남기기도 합니다. / 안전하게 여는 방법이 아니므로 권하지 않습니다.
자동 잠김을 아예 풀어 달라는 요청은 문을 연 뒤에 도와드릴 수 있습니다. / 열기 전에는 먼저 문부터 안전하게 엽니다.
설정 메뉴를 잘못 만지다 다른 기능까지 바뀌는 경우도 있습니다. / 모르는 메뉴에서는 함부로 번호를 누르지 말고, 안 풀리면 그 상태 그대로 알려 주세요.

# 전화하실 때 말씀해 주세요
위치와 상황만 간단히 알려 주시면 됩니다.
- 당동 어느 쪽인지와 아파트 동, 호수 또는 주택 위치
- 문이 언제부터 안 열렸는지
- 번호판 상태(켜짐, 꺼짐, 경고음)
- 집 안에 사람이나 반려동물이 있는지
사진을 문자로 보내 주시면 제품에 맞는 방법을 먼저 안내해 드릴 수 있습니다. / [군포 출장열쇠](gunpo.html)로 편하게 연락 주세요.
@ 당동 도어락 번호판 상태 사진

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 신분 확인부터 합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭙니다.
개문 방식은 [현관문 개문](door-open.html), 전체 순서는 [이용안내](guide.html)에서 볼 수 있습니다.

# 열고 난 뒤 설정을 같이 맞춰 드립니다
문을 연 뒤에는 자동 잠김 설정이 지금 가족 생활에 맞는지 같이 살펴봅니다. / 시간 조절이 되는 제품이면 원하시는 길이로 맞춥니다.
배터리가 약했다면 새것으로 바꾸고, 필요한 경우 번호도 새로 등록합니다. / 제품이 너무 불편하거나 낡았다면 [도어락 교체](doorlock-replace.html) 이야기를 드립니다.
설정이 헷갈리는 정도의 문제라면 [도어락 수리](doorlock-repair.html) 없이 설정만 정리해도 충분한 경우가 많습니다.

# 당동 말고 군포 어디든 갑니다
산본동, 금정동, 당정동, 부곡동, 대야미동, 오금동도 24시간 다닙니다. / 군포 안이면 동네 구분 없이 연락 주세요. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
