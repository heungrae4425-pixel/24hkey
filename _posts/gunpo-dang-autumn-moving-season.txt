# 가을 이사철은 문 앞 일정이 먼저 꼬입니다
가을이 되면 군포역과 산본역 생활권인 당동에도 이삿짐 차가 부쩍 늘어납니다. / 짐 싸는 일에 정신이 팔려 도어락 챙기는 건 마지막으로 밀리기 쉽습니다.
막상 이삿날 새집 문 앞에서 번호를 모르거나 이전 사람 번호가 남아 있으면 하루가 통째로 어긋납니다. / 이 글은 도어락 때문에 이사 일정이 꼬이지 않게 순서를 정리한 것입니다.
[군포 출장열쇠](gunpo.html)를 부르는 시점도 함께 적었으니 달력을 보면서 읽어 주세요.
@ 당동 이사철 도어락 일정 점검

# 이사 날짜가 정해지면 제일 먼저 할 일
날짜가 정해졌다면 도어락 이야기를 같이 꺼내 두세요. / 임대인이나 전 주인에게 확인할 것이 몇 가지 있습니다.
- 도어락을 그대로 두고 갈 것인지, 떼어 갈 것인지
- 비밀번호나 카드키를 몇 개 받을 수 있는지
- 보조키 열쇠가 몇 개 있는지
- 공동 현관 출입 방법이 따로 있는지
이 네 가지만 알아도 이삿날 문 앞에서 막히는 일이 크게 줄어듭니다. / 대화 내용은 문자로 남겨 두면 나중에 서로 편합니다.

# 입주 전에 도어락을 바꿀지 말지
이전 사람이 쓰던 도어락을 그냥 쓰면 번호 기록이 남아 있을 수 있습니다. / 초기화만 해도 대부분 정리되지만, 제품이 많이 낡았다면 교체가 나을 때도 있습니다.
무조건 새것을 권하지는 않습니다. / 문 상태를 보고 초기화로 충분한지, 고쳐서 쓸지, 바꿔야 할지를 나눠서 말씀드립니다.
고민되면 [도어락 교체](doorlock-replace.html) 페이지에서 교체 전에 보는 것들을 먼저 읽어 보세요.

# 이삿날 전날까지 끝내 두면 좋은 것
이삿날 당일에는 일꾼분들이 문을 계속 드나듭니다. / 도어락 작업까지 겹치면 서로 불편해집니다.
가능하면 이삿날 하루 이틀 전에 빈집일 때 작업해 두는 게 가장 깔끔합니다.
- 기존 번호와 카드 전부 삭제하기
- 새 번호 등록 후 열고 닫기 시험
- 배터리 새것으로 교체
- 보조키 열쇠 개수 확인
그렇게 해두면 짐 나르는 날에는 새 번호로 편하게 드나들 수 있습니다.

# 이삿날 아침에 번호판이 꺼져 있다면
오래 비어 있던 집은 도어락 배터리가 약해져 있는 경우가 있습니다. / 이삿짐 차가 도착했는데 문이 안 열리면 모두가 기다리게 됩니다.
바깥쪽 아래의 비상 단자에 9V 건전지를 대면 전원이 들어오는 제품이 많습니다. / 이삿날 주머니에 건전지 하나를 넣어 두면 든든합니다. / 편의점이나 마트에서 쉽게 구할 수 있습니다.
안 되면 바로 연락 주세요. / 이삿짐 일정이 걸려 있다고 말씀해 주시면 우선 챙겨 보겠습니다.

# 가족 번호를 새로 정할 때 요령
새 집 번호는 이전 집과 같은 번호를 쓰고 싶은 마음이 듭니다. / 하지만 기억이 편하다고 생일이나 전화번호 뒷자리를 그대로 쓰는 건 피하는 편이 좋습니다.
가족이 함께 외울 수 있는 규칙을 하나 정해 두세요. / 번호를 바꿀 때는 식구 모두에게 같은 날 알리면 헷갈리지 않습니다.
@ 당동 이사 후 비밀번호 새로 등록

# 이사 당일 문이 갑자기 안 열릴 때
짐이 많으면 문을 발로 괴어 두고 오갑니다. / 이때 문이 갑자기 닫혀 열쇠도 번호도 안 닿는 곳에 갇히는 일이 있습니다.
이삿날일수록 열쇠와 휴대폰은 몸에 지니고 있어야 합니다. / 짐 속에 넣어 두었다가 잠기는 사고가 가장 흔합니다.
그래도 잠기면 문을 두드리거나 당기지 말고 위치만 알려주세요. / 상황에 맞춰 출동 여부를 말씀드립니다.

# 전화할 때 이렇게 말씀해 주세요
이사철에는 연락이 몰리는 날이 있습니다. / 아래 내용을 한 번에 알려주시면 일정을 짜기 쉽습니다.
- 당동 어느 쪽인지와 건물 형태
- 원하는 작업 날짜와 시간대
- 초기화인지 교체인지, 아직 모르는지
- 현재 도어락 사진
- 입주 전인지 이미 입주했는지
확정이 안 됐어도 괜찮습니다. / 일단 상담만 하셔도 됩니다. / 작업 날짜를 못 정한 상태에서도 가능한 시간대를 같이 찾아 드립니다.

# 처음 오는 곳이라 신분 확인은 꼭 합니다
이사 직후에는 집 주소가 적힌 서류가 아직 없는 경우가 많습니다. / 그래도 사시는 분이 맞는지는 확인해야 문을 열어 드릴 수 있습니다.
계약서, 이사 확인 서류, 주소가 적힌 우편물, 신분증 중 하나를 보여 주세요. / 관리사무소나 임대인 확인으로 대신하기도 합니다.
이 절차는 이웃을 지키기 위한 것이라 늘 같게 적용합니다. / 서류를 아직 못 받았다면 임대인에게 사진으로 받아 두거나 관리사무소에 미리 문의해 두세요. / 이삿날 아침에 챙길 것 목록에 신분증을 꼭 넣어 주시면 됩니다.

# 비용은 시작 전에 말하고 못 열면 받지 않습니다
도어락 종류와 작업 내용을 보고 문 열기 전에 먼저 말씀드립니다. / 말씀드린 내용에 동의하시면 시작합니다.
문을 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 하기 전에 한 번 더 여쭤봅니다.
이사철에는 일정이 급해서 고르기 힘들 수 있지만, 비교해 보고 정하셔도 괜찮습니다. / 일하는 순서는 [이용안내](guide.html)에서도 보실 수 있습니다.

# 전 주인 열쇠와 카드가 남아 있다면
이사 오고 나서 전에 쓰던 열쇠가 서랍에서 나오는 일이 있습니다. / 몇 개가 어디에 있는지 정확히 알 수 없으면 마음이 개운하지 않습니다.
보조키 안쪽 부품을 바꾸면 이전 열쇠는 더 이상 맞지 않게 됩니다. / 문 전체를 바꿀 필요는 없으니 [열쇠 출장](key-call.html) 상담에서 방법을 물어보세요.
@ 군포 이사철 열쇠 번호 정리

# 이사 후 일주일 안에 점검할 것
짐 정리가 끝나면 도어락을 한 번 더 점검합니다. / 여러 번 오가면서 생긴 이상이 이때 보이기도 합니다.
- 문이 끝까지 닫히는지
- 번호를 눌렀을 때 소리가 정상인지
- 안쪽에서 잠금 해제가 자연스러운지
- 보조키와 걸쇠가 문제없는지
이삿짐을 풀다가 문 쪽에서 평소와 다른 소리가 나면 그냥 넘기지 마세요. / 이상이 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 그래도 어려우면 그때 바꿉니다.


이사 한두 주 전에 확인, 하루 이틀 전에 작업, 당일에는 점검만. / 이 순서만 지켜도 이삿날 아침이 훨씬 편합니다.
이사 전후로는 여분 열쇠나 카드를 서로 다른 가방에 나눠 넣어 두세요. / 한곳에 모아 두었다가 통째로 못 찾는 일을 막아 줍니다.
만약 일정이 촉박해도 포기하지 마세요. / 같은 날에 가능한지 전화로 물어보시면 바로 답해 드립니다.
출입문 개문 방법이 궁금하면 [현관문 개문](door-open.html) 페이지에서 보실 수 있습니다.

# 당동 말고 군포 어디든 갑니다
당동 가까이 산본동, 금정동, 당정동, 부곡동, 대야미동, 오금동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
다른 지역은 [출장 지역](area.html)에서 확인해 주세요.

# 자주 묻는 질문

? 초기화와 교체 중 어떤 게 나은가요? | 도어락 상태를 보고 말씀드립니다. 초기화로 충분하면 교체를 권하지 않습니다.
? 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 세입자인데 도어락을 바꿔도 되나요? | 임대인과 먼저 이야기해 두시길 권합니다. 합의 내용은 문자로 남기면 좋습니다.
? 신분 확인은 어떻게 하나요? | 신분증, 계약서, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
