# 당동 현관문, 잠금이 두 개라서 더 헷갈립니다
당동은 금정역과 군포역 생활권 사이에서 집과 가게가 섞여 있는 군포의 주거 동네입니다. / 오래 사신 집일수록 도어락 위에 보조키가 하나 더 달려 있는 현관문이 많습니다.
잠금이 두 개이면 안전하다고 느끼지만, 문이 안 열릴 때는 어느 쪽이 문제인지 가려내기가 어렵습니다. / 도어락은 열렸는데 문이 안 열리거나, 보조키만 잠긴 줄 모르고 도어락만 만지는 경우가 많습니다.
이 글은 당동에서 두 잠금을 같이 쓰는 집의 점검 순서를 차례로 정리했습니다. / 순서대로 따라가시면 [군포 출장열쇠](gunpo.html)를 부를지 말지 판단하기 쉬워집니다.
@ 당동 현관문 위쪽 보조키와 아래쪽 도어락이 함께 달린 모습

# 먼저 두 잠금의 역할을 구분하세요
도어락은 손잡이 높이에 있고 번호나 카드, 지문으로 엽니다. / 보조키는 문 위나 아래쪽에 따로 달려 있고 열쇠나 돌리는 손잡이로 엽니다.
도어락은 걸쇠와 데드볼트를, 보조키는 별도의 데드볼트나 빗장을 움직입니다. / 하나가 풀려도 다른 하나가 잠겨 있으면 문은 열리지 않습니다.
그래서 안 열릴 때 가장 먼저 해야 할 일은 어느 잠금이 걸려 있는지 확인하는 것입니다.

# 점검 순서 1단계, 보조키부터 확인
도어락 번호를 누르기 전에 보조키 쪽을 먼저 봅니다. / 열쇠 구멍이 있다면 열쇠를 꽂아 돌려 보고, 돌리는 손잡이식이라면 방향을 확인합니다.
보조키가 잠긴 채 나왔다면 열쇠로만 풀립니다. / 열쇠를 안 가지고 있다면 이 단계에서 이미 전화 상담이 필요한 상황입니다.
열쇠가 있는데 안 돌아가면 힘주지 말고 멈추세요. / 이물질이 끼었거나 열쇠가 닳았을 수 있습니다.

# 점검 순서 2단계, 도어락 번호판 상태
보조키가 풀렸다고 판단되면 도어락을 확인합니다. / 번호판에 손바닥을 대어 불이 들어오는지, 번호를 누르면 소리가 나는지 봅니다.
불도 소리도 없으면 배터리일 가능성이 큽니다. / 많은 도어락은 바깥쪽 비상 단자에 9V 건전지를 대면 일시적으로 전원이 들어옵니다.
소리는 나는데 안 열리면 모터나 걸쇠 쪽을 의심합니다. / 이 부분은 증상에 따라 다음 단계로 이어집니다.

# 점검 순서 3단계, 문과 문틀의 관계
두 잠금 모두 풀렸는데 문이 안 열리면 문틀과 문이 서로 끼어 있을 수 있습니다. / 당동처럼 오래 쓴 문은 경첩이 처져 걸쇠나 데드볼트가 문틀에 눌려 있는 경우가 있습니다.
문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 눌림이 풀리면서 열리는 일이 있습니다.
이때도 세게 당기거나 흔들면 부품이 휘니 가볍게 시도하세요.
@ 당동 오래된 현관문 틀과 보조키 데드볼트가 만나는 부분

# 보조키 때문에 생기는 대표 사례
- 가족이 나가면서 보조키를 돌려 잠갔는데 남은 가족이 모르고 도어락만 열려고 한 경우
- 안쪽 보조키 손잡이를 돌려 둔 채 문을 닫고 나온 경우
- 열쇠 구멍에 먼지가 끼어 열쇠가 헛도는 경우
- 보조키 빗장이 문틀 구멍보다 벗어나 걸린 경우
도어락만 열리면 되는 줄 알았는데 문이 꿈쩍도 안 한다면 보조키를 의심해 보세요. / 한 가정에서 이런 일이 반복된다면 평소 잠그는 습관을 가족과 맞추는 것이 좋습니다.

# 도어락 때문에 생기는 대표 사례
- 배터리가 방전되어 번호판이 꺼진 경우
- 비밀번호를 가족이 바꾼 걸 모르는 경우
- 모터 소리는 나는데 걸쇠가 안 빠지는 경우
- 습기나 결로로 번호판이 오작동하는 경우
이런 일은 도어락 자체 점검으로 해결되는 때가 많습니다. / 배터리가 문제라면 비상 전원으로 한 번 열고 안쪽에서 새 배터리로 바꾸면 됩니다.

# 하지 말아야 할 것
급하다고 보조키를 힘으로 비틀거나 도어락을 두드리는 것은 피하세요. / 두 잠금이 함께 달린 문은 한쪽이 상하면 다른 쪽까지 영향을 받습니다.
드라이버로 문틈을 벌리는 방법도 문틀과 도어락 외관을 상하게 합니다. / 비밀번호를 여러 번 틀리면 도어락이 입력을 막으니 서너 번 후에 멈추세요.
열쇠가 부러져 박혔다면 더 건드리지 말고 그대로 알려 주세요.

# 출장열쇠에 알려 주실 내용
전화하실 때 아래를 말씀해 주시면 상황 판단이 빨라집니다.
- 당동 안 대략적인 위치와 건물 형태
- 보조키 종류(열쇠 구멍식인지 손잡이식인지)
- 도어락 번호판 상태와 소리
- 열쇠를 가지고 있는지
- 집 안에 아이나 반려동물이 있는지
보조키와 도어락이 함께 찍힌 사진을 문자로 보내 주시면 챙길 장비를 정하기 좋습니다. / 요청 절차는 [열쇠 출장](key-call.html) 페이지에 있습니다.

도착하면 문을 열기 전에 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집 주인 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.
신분증이 집 안에 있다면 휴대폰에 저장된 고지서나 계약서 사진도 도움이 됩니다. / 늦은 시간이면 경비실이나 관리사무소에 먼저 말해 두시면 수월합니다.
두 잠금이 달린 문은 하나만 열고 끝내지 않고, 열린 뒤 둘 다 정상인지까지 같이 봅니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
두 잠금을 모두 열어야 하는 문이라 작업 범위를 먼저 보고 비용을 말씀드립니다. / 괜찮다고 하실 때 시작하고, 아니라면 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 여쭙습니다.
@ 당동 출장열쇠 보조키와 도어락 함께 여는 작업

# 열고 난 뒤 두 잠금을 같이 점검합니다
문이 열린 뒤 보조키와 도어락이 각각 잘 잠기고 풀리는지 확인합니다. / 어느 한쪽이 뻑뻑하면 빗장이나 걸쇠 위치를 조정합니다.
[도어락 수리](doorlock-repair.html)로 해결되면 교체는 권하지 않습니다. / 보조키까지 낡았다면 [도어락 교체](doorlock-replace.html)와 함께 말씀드립니다.
배터리와 비밀번호도 한 번에 정리하면 같은 일이 다시 생길 확률이 줄어듭니다.

# 두 잠금을 오래 쓰는 가족 약속
- 마지막으로 나가는 사람이 보조키 잠금 여부를 말로 공유하기
- 보조키 열쇠는 도어락 열쇠와 분리해 두 곳에 보관하기
- 한 달에 한 번 보조키와 도어락을 모두 열고 닫아 보기
- 배터리 교체 날짜를 도어락 옆에 적어 두기
특히 아이가 있는 집은 아이가 안쪽 보조키를 돌려 잠글 수 있다는 점을 알아 두세요. / 이런 상황은 먼저 말씀해 주시면 더 조심해서 진행합니다.

# 당동 말고 군포 어디든 갑니다
당동 가까이 산본동, 금정동, 당정동, 부곡동, 대야미동, 오금동도 다닙니다. / 군포 안이라면 시간 상관없이 24시간 출동합니다.
다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 확인하세요.
