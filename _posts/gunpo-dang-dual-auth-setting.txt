# 번호만으로는 불안하다는 분들이 늘었습니다
당동은 군포역과 금정역 쪽 생활권을 오가는 사람이 많은 주거지입니다. / 번호만 알면 누구나 열 수 있다는 점이 마음에 걸려 고민하시는 분이 계십니다.
그래서 번호와 카드키를 함께 요구하는 이중 인증 설정에 관심을 갖게 됩니다. / 이 글은 어떤 제품에서 가능한지, 설정할 때 무엇을 조심할지 적었습니다.
문이 안 열려 급할 때는 [군포 출장열쇠](gunpo.html)에 연락해 주세요.
@ 당동 번호와 카드 함께 쓰는 도어락

# 이중 인증이란 무엇인가
문을 열 때 두 가지 방법을 동시에 확인하는 방식입니다. / 번호를 누르고 카드를 대야 열리는 식으로 한 가지만으로는 열리지 않게 합니다.
모든 도어락에 있는 기능은 아닙니다. / 제품 설명서에서 복합 인증이나 이중 잠금 같은 이름으로 안내되는 경우가 많습니다.
- 번호와 카드를 함께 쓰는 방식
- 번호와 지문을 함께 쓰는 방식
- 낮에는 한 가지, 밤에는 두 가지를 쓰는 방식

# 우리 집 도어락이 가능한지 확인하기
먼저 제품 모델명을 확인해야 합니다. / 안쪽 배터리 칸 근처나 몸체에 모델명이 적혀 있는 경우가 많습니다.
설명서가 없다면 모델명을 인터넷에서 검색해 기능 목록을 확인해 보세요. / 확인이 어려우면 사진을 보내주시면 함께 봐 드릴 수 있습니다.
기능이 없는 제품이라면 설정을 바꿔서는 안 되고, 새 제품을 고르는 방법이 있습니다. / 이때는 [도어락 교체](doorlock-replace.html) 안내를 참고해 주세요.

# 설정하기 전에 꼭 준비할 것
설정을 바꾸다 실수하면 문이 안 열릴 수 있어서 준비가 중요합니다. / 아래 항목을 먼저 챙기고 시작하세요.
- 카드키 2장 이상(한 장은 분실 대비)
- 현재 쓰는 번호를 기록해 둘 곳
- 문을 열어 둔 채로 설정 진행
- 새 배터리로 바꾼 뒤 시작
문을 닫고 설정하다가 잠기면 안에서만 열리는 경우가 생길 수 있습니다. / 반드시 문을 열어 둔 상태에서 끝까지 진행하세요.

# 설정 순서는 대략 이렇습니다
제품마다 다르지만 큰 흐름은 비슷합니다. / 정확한 순서는 설명서를 따라야 합니다.
먼저 관리자 모드로 들어가 카드를 등록합니다. / 그다음 인증 방식 메뉴에서 번호와 카드 동시 사용을 선택합니다.
설정이 끝나면 문을 연 채로 시험해 봅니다. / 번호만 눌러서 열리지 않는지, 번호와 카드를 같이 썼을 때 열리는지 확인합니다.
@ 당동 도어락 카드 등록 화면

# 가족이 있는 집은 더 신경 써야 합니다
이중 인증은 가족이 많을수록 불편해질 수 있습니다. / 아이나 어르신이 카드를 챙기지 못하면 집에 들어오지 못합니다.
그래서 모든 사람에게 같은 방식을 적용하기보다 필요한 시간대만 쓰는 편이 현실적입니다. / 예를 들어 밤에만 이중 인증을 켜고 낮에는 번호만 쓰는 방법도 있습니다.
카드는 가방이나 지갑에 항상 넣고 다니는 습관이 필요합니다. / 휴대폰 케이스 뒤에 붙여 두는 분도 있지만 인식이 약해지는 경우가 있어 먼저 시험해 보세요. / 하나쯤은 집 밖의 믿을 만한 곳에 따로 보관해 두세요.

# 카드를 잃어버렸을 때가 가장 문제입니다
이중 인증을 쓰는 집에서 카드가 없으면 번호만으로 열리지 않을 수 있습니다. / 그래서 카드 분실은 일반 도어락보다 훨씬 곤란한 상황이 됩니다.
카드를 잃어버리면 즉시 해당 카드를 삭제해야 합니다. / 문이 안에서는 열리니 일단 안에 들어가 있을 때 설정을 바꿔야 합니다.
밖에서 문이 안 열리는 상황이라면 [현관문 개문](door-open.html) 안내를 먼저 보고 연락 주세요. / 사시는 분 확인 후 진행합니다.

# 번호는 맞는데 안 열린다면
이중 인증 상태에서는 번호가 맞아도 카드가 인식되지 않으면 열리지 않습니다. / 카드를 대는 위치와 순서를 한 번 더 확인해 보세요.
- 카드를 번호판 가까이 정확히 댔는지
- 번호를 먼저 누르는지 카드를 먼저 대는지 순서가 맞는지
- 카드가 구부러지거나 닳지 않았는지
- 배터리가 충분한지
순서를 바꾸면 열리는 경우가 있습니다. / 그래도 안 되면 억지로 시도하지 말고 연락 주세요.

# 배터리가 약해지면 카드 인식이 먼저 흔들립니다
카드 인식은 전력이 필요해서 배터리가 약해지면 가장 먼저 반응이 둔해집니다. / 번호는 눌리는데 카드가 안 읽히면 배터리부터 의심해 보세요.
새 건전지로 전부 바꾸고 다시 시도해 보면 풀리는 일이 많습니다. / 일부만 바꾸면 곧 같은 증상이 반복됩니다.
비상용 9V 건전지 하나를 두면 번호판이 꺼졌을 때도 대처할 수 있습니다.

문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
이중 인증이 걸려 있어도 신분 확인 절차는 똑같습니다. / 번거롭지만 이웃과 의뢰하신 분 모두를 위한 절차입니다.

# 신분 확인과 비용 안내
현관문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 당동 출장열쇠 도어락 점검 작업

# 설정을 도움받고 싶을 때
설정이 어렵거나 불안하면 현장에서 같이 하는 편이 안전합니다. / 방문해서 모델을 확인하고 가능한 방식을 설명드립니다.
기능이 없는 제품이면 억지로 만들지 않고 가능한 대안을 말씀드립니다.
설정 중에 번호가 꼬여 문이 안 열리게 된 경우에도 먼저 연락 주시면 순서대로 풀어 드립니다. / 혼자 여러 번 시도하다 잠금 상태가 길어지는 것보다 빨리 상담받는 편이 낫습니다. / 새 제품 설치가 필요하면 [도어락 설치](doorlock-install.html) 안내를 참고해 주세요.

# 이중 인증을 오래 쓰는 습관
- 카드는 최소 두 장, 한 장은 따로 보관
- 배터리는 해가 바뀔 때쯤 전부 교체
- 번호는 주기적으로 바꾸고 가족과 공유
- 카드 분실 즉시 삭제 후 재등록
보안을 높이려다 불편이 커지지 않게 우리 집에 맞는 수준을 정하세요.
당동처럼 출퇴근 시간이 서로 다른 가족이 함께 사는 집은 특히 사전에 합의해 두는 것이 좋습니다. / 누가 카드를 갖고 다니는지, 분실하면 누구에게 먼저 알릴지까지 정해 두면 막상 일이 터져도 당황하지 않습니다.
이중 인증을 설정한 뒤 첫 일주일은 평소보다 자주 시험해 보며 불편한 점을 적어 두세요. / 불편이 크면 시간대별 설정으로 조정하는 것도 방법입니다.
손님이나 가사 도우미가 드나드는 집이라면 임시 번호를 따로 쓸 수 있는지도 같이 확인하세요. / 이중 인증과 임시 번호가 함께 동작하는지는 제품마다 달라서 미리 시험해 보는 것이 좋습니다.

# 당동 말고 군포 어디든 갑니다
당동 가까운 산본동, 금정동, 당정동, 부곡동, 오금동, 대야미동도 다닙니다. / 군포 안이면 24시간 출동합니다.
다른 지역은 [출장 지역](area.html)에서 확인해 주세요.
