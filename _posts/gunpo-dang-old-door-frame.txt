# 도어락은 멀쩡한데 문이 안 열리는 집
당동에서 군포역 쪽으로 오가며 오래 사신 댁에서 가끔 이런 연락을 받습니다. / 도어락은 새로 바꿨는데도 문이 뻑뻑하고, 어떤 날은 안 열리고 어떤 날은 잘 열린다는 이야기입니다.
이런 경우 원인은 도어락이 아니라 문 자체인 경우가 많습니다. / 오랜 시간 쓰는 사이 문이 아주 조금씩 내려앉았기 때문입니다.
이 글은 문이 처졌는지 스스로 알아보는 방법과, 그 상태에서 안 열릴 때 어떻게 하면 좋은지 정리했습니다.
@ 당동 오래된 현관문 처짐 점검

# 문이 처졌다는 신호
처짐은 눈으로 한눈에 보이지 않는 경우가 대부분입니다. / 대신 문을 쓰는 감각에서 먼저 신호가 나타납니다.
- 문을 닫을 때 끝에서 한 번 걸리거나 힘을 줘야 닫힘
- 문 아래쪽이 바닥이나 문턱을 긁는 소리
- 잠금 소리가 날 때와 안 날 때가 번갈아 있음
- 문이 닫힌 상태에서 위쪽 틈과 아래쪽 틈이 눈에 띄게 다름
이 중 두세 가지가 겹치면 처짐을 의심해 볼 만합니다.
처짐은 한 번에 오는 것이 아니라 몇 달, 몇 해에 걸쳐 조금씩 진행됩니다. / 그래서 가족이 매일 쓰는 동안에는 오히려 눈치채기 어렵고, 오랜만에 방문한 사람이 먼저 "문이 좀 이상하다"고 말하기도 합니다.
장마가 지나거나 겨울에 난방을 세게 틀고 나서 증상이 도드라지는 집도 있습니다. / 습도와 온도가 문과 문틀을 미세하게 움직이기 때문입니다.

# 종이 한 장으로 해보는 간단 진단
문을 닫고 문과 문틀 사이 가장자리에 얇은 종이를 끼워 보세요. / 위쪽과 아래쪽, 손잡이 쪽에서 종이가 꽉 끼는 정도를 비교합니다.
어느 한쪽이 유독 꽉 끼거나 쑥 빠진다면 문이 기울어진 것입니다. / 이 방법은 문이나 도어락을 전혀 상하게 하지 않습니다.
종이를 끼우기 전에 문이 닫혀도 잠기지 않도록 안쪽 잠금이 풀려 있는지 확인하세요. / 혼자 있다면 휴대폰은 꼭 지니고 하세요.

# 경첩이 헐거워지는 이유
경첩은 문 무게를 오랫동안 받치는 부품입니다. / 나사가 풀리거나 나사 구멍이 닳으면 문이 아래로 내려앉습니다.
문을 세게 닫는 습관, 문에 무거운 것을 걸어 두는 습관이 헐거워지는 속도를 앞당깁니다. / 아이가 문에 매달리는 일도 영향을 줍니다.
경첩 나사를 눈으로 보아 머리가 튀어나와 있거나 구멍이 커져 보이면 풀림의 흔적입니다. / 간단히 조여 볼 수도 있지만 힘을 과하게 주지는 마세요.

# 경첩 나사를 조일 때 지킬 점
문을 열어 둔 상태에서 문이 움직이지 않게 받쳐 놓고 시작하세요. / 한 번에 모든 나사를 풀지 말고 하나씩 조입니다.
나사가 헛돌면 구멍이 이미 커진 것이어서 더 조여도 소용이 없습니다. / 이 경우는 억지로 하지 말고 점검을 받는 것이 낫습니다.
문이 열린 채 혼자 문을 닫고 나가면 잠길 수 있으니 문 앞을 벗어날 때는 카드키나 열쇠를 꼭 챙기세요. / 특히 번호판 문이라면 더 조심해야 합니다.

# 문이 처져서 안 열릴 때의 증상
처짐이 심해지면 걸쇠와 데드볼트가 문틀 구멍과 어긋납니다. / 그러면 번호가 맞고 모터가 돌아도 문이 열리지 않습니다.
문을 안쪽으로 살짝 들어 올리듯 밀면서 손잡이를 돌리면 열리는 경우가 있습니다. / 이 방법은 임시일 뿐 근본적으로 고친 것이 아닙니다.
@ 군포 당동 문틀 경첩 조정 필요한 문

# 도어락만 바꾸면 해결될까
문이 처진 상태에서 도어락만 교체하면 얼마 못 가 같은 문제가 다시 생길 수 있습니다. / 새 도어락의 볼트도 어긋난 구멍에 걸리기 때문입니다.
그래서 교체를 권하기 전에 문과 문틀 상태를 먼저 봅니다. / [도어락 교체](doorlock-replace.html)가 정말 필요한지를 가르는 것이 먼저입니다.
문 쪽을 조정하면 기존 도어락을 그대로 쓸 수 있는 경우가 많습니다. / 불필요한 교체를 피하는 것이 결과적으로 낫습니다.

# 문틀 구멍 위치 확인
문틀에 볼트가 들어가는 구멍 가장자리에 눌린 자국이나 긁힌 흔적이 있는지 보세요. / 자국이 한쪽으로 치우쳐 있다면 문이 그 방향으로 기울어 닿고 있다는 뜻입니다.
이 흔적은 문 처짐의 방향을 알려주는 증거가 됩니다. / 사진으로 찍어 두면 상담할 때 도움이 됩니다.
구멍 위치가 크게 틀어졌다면 금속 부품을 약간 손보는 방식이 필요할 수도 있습니다. / 이런 작업은 전문 장비로 하는 편이 안전합니다.

# 하지 말아야 할 일
문이 안 열린다고 문틀에 쐐기를 박거나 지렛대로 벌리지 마세요. / 문과 문틀이 모두 상하고 수리가 커집니다.
문을 발로 차 보거나 몸으로 밀어 열려는 시도도 피하세요. / 처진 문은 이미 힘을 받고 있어 더 틀어질 수 있습니다.
기름을 많이 뿌려 해결하려는 것도 효과가 없습니다. / 오히려 먼지가 붙어 굳을 수 있습니다.
경첩에서 나는 삐걱 소리는 윤활로 잠깐 잦아들 수 있지만 처짐 자체가 고쳐진 것은 아닙니다. / 소리가 사라졌다고 안심하지 말고 문이 닫히는 느낌이 달라졌는지도 같이 확인해 보세요.

# 당동에서 출장을 부르실 때
문이 처져서 안 열린다고 하시면 아파트 이름, 동, 호수와 증상이 시작된 시기를 알려주세요. / 문 전체 사진과 경첩 부분 사진을 보내주시면 준비가 쉬워집니다.
[군포 출장열쇠](gunpo.html)는 당동을 포함해 군포 어디든 24시간 연락을 받습니다. / 급한 상황이 아니면 낮에 점검을 예약하는 방법도 있습니다.
문이 아직 열리고 닫히는 상태라면 서두를 필요는 없습니다. / 다만 열렸다 안 열렸다 하는 문은 어느 날 갑자기 안 열릴 수 있으니 너무 오래 미루지는 마세요.
문 여는 방식은 [현관문 개문](door-open.html)에서, 점검 방식은 [도어락 수리](doorlock-repair.html)에서 볼 수 있습니다.

# 사시는 분인지 확인합니다
문을 열기 전 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나로 확인합니다. / 신분증이 집 안에 있다면 관리사무소 세대 확인을 부탁하세요.
확인이 어려우면 작업은 할 수 없습니다. / 이웃과 내 집을 함께 지키는 절차입니다.
비용은 문을 열기 전에 먼저 말씀드리고, 못 열면 비용은 받지 않습니다. / 부품을 바꾸는 경우는 바꾸기 전에 따로 여쭙습니다.

# 문을 조정한 뒤 점검할 것
작업이 끝나면 문이 가볍게 닫히고 걸쇠와 볼트가 문틀 구멍에 정확히 들어가는지 확인합니다. / 닫힌 문을 당겨 보아 흔들림이 없는지도 봅니다.
위쪽과 아래쪽 틈이 고르게 보이는지 종이 한 장 방식으로 다시 확인해 보세요. / 며칠 쓰다가 느낌이 달라지면 다시 점검합니다.
[이용안내](guide.html)에 진행 순서가 적혀 있습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 당동 24시 출장열쇠 문 조정 마무리

# 당동 밖 군포 다른 동네도 갑니다
산본동, 금정동, 당정동, 부곡동, 대야미동, 오금동도 24시간 다닙니다. / 서울과 경기 다른 지역은 [출장 지역](area.html)에서 확인하세요.
