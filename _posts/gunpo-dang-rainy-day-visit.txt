# 비 오는 날 당동 집 앞에서 문이 안 열리면
군포역 쪽에서 당동 집까지 우산을 쓰고 걸어왔는데 번호판이 반응하지 않으면 마음이 더 무겁습니다. / 비에 젖은 채로 문 앞에 서 있으면 시간이 길게 느껴지고 몸도 쉽게 지칩니다.
비 오는 날은 도어락도 평소와 다르게 반응할 때가 있습니다. / 이 글은 비 오는 날 문이 안 열릴 때 확인할 것과 [군포 출장열쇠](gunpo.html)를 부를 때 미리 준비하면 좋은 것을 정리했습니다.
출동하는 쪽도 비 오는 날은 길이 막히고 시간이 더 걸릴 수 있어 미리 알려주시면 도움이 됩니다. / 함께 순서를 보시죠.
@ 당동 비 오는 날 현관 번호판 물기

# 비가 오면 문이 왜 더 말을 안 들을까
번호판과 손잡이에 빗물이나 습기가 닿으면 입력이 엉키는 일이 있습니다. / 터치식 번호판은 물기를 손가락으로 오인해서 아무 숫자나 눌린 것처럼 받아들이기도 합니다.
문틀과 문이 습기를 머금고 살짝 부풀어 평소보다 뻑뻑해질 수도 있습니다. / 평소엔 잘 닫히던 문이 비 오는 날만 걸린다면 이 영향일 가능성이 있습니다.
건전지 칸이나 연결 부위에 습기가 들어가 접촉이 약해지는 경우도 있습니다. / 전기가 약해지는 것과 비슷한 증상이라 건전지 문제로 오해하기 쉽습니다.

# 문 앞에서 먼저 해볼 수 있는 일
- 마른 수건이나 손수건으로 번호판과 손잡이의 물기를 닦기
- 번호를 한 번 눌러 보고 삑 소리가 나는지 확인하기
- 번호를 급하게 누르지 말고 한 번에 한 숫자씩 천천히 누르기
- 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보기
- 바깥쪽 아래 비상 단자가 있다면 9V 건전지를 대 보기
비를 맞은 채 무리하게 여러 번 시도하지 말고 몸을 먼저 피하는 것이 좋습니다. / 우산 아래나 건물 입구 쪽으로 자리를 옮겨 편하게 확인하세요.

# 물기가 있을 때 조심할 것
비에 젖은 번호판에 건전지를 대는 것은 피해 주세요. / 물기를 먼저 닦고 마른 상태에서 해야 합니다.
드라이버나 칼날로 번호판 주변을 열려는 시도는 습기가 안으로 더 들어가게 합니다. / 열어 본다고 해결되지 않는 경우가 많습니다.
헤어드라이어로 열을 쏘이는 방법도 알려져 있지만 뜨거운 바람은 부품을 상하게 할 수 있어 권하지 않습니다. / 자연스럽게 마르기를 기다리거나 마른 수건으로 닦는 정도로 충분합니다.
@ 당동 빗속 도어락 비상 전원 확인

# 기다리는 동안 안전하게 서 있는 법
출장열쇠가 도착할 때까지 시간이 걸리면 비를 피할 수 있는 곳에서 기다리세요. / 계단 아래나 건물 입구 안쪽이 좋습니다.
어두운 밤이라면 출입구 밝은 곳에 자리를 잡고, 가능하면 혼자보다 가족이나 이웃과 통화하며 기다리세요. / 휴대폰 배터리가 부족하면 아끼기 위해 통화를 짧게 하세요.
아이가 함께 있다면 젖지 않게 하고 따뜻하게 챙겨 주세요. / 아이가 먼저 힘들어하면 가까운 가게나 건물 입구에서 잠시 쉬는 방법도 있습니다.

# 전화하기 전에 미리 준비할 것
비 오는 날은 도착 시간이 길어질 수 있으니 전화할 때 정보를 정확히 주시면 도움이 됩니다.
- 당동 안의 대략적인 위치와 건물 입구 모양
- 번호판이 켜지는지, 소리만 나는지
- 비에 젖었는지, 물기를 닦은 뒤 반응이 어떤지
- 보조키가 잠겼을 가능성
- 연락 가능한 전화번호와 서 계실 위치
건물 입구가 여러 군데라면 어디에서 기다리고 계신지 알려 주세요. / 우산을 쓰고 기다리는 분을 찾기가 의외로 어렵기 때문입니다.

# 도어락 사진을 미리 찍어 두면 좋습니다
비 오는 날은 번호판이 어떻게 보이는지가 큰 단서입니다. / 켜져 있는지 꺼져 있는지, 빨간 불이 들어오는지 사진 한 장이면 충분합니다.
사진을 문자로 보내주시면 맞는 부품을 챙기기가 쉬워집니다. / 가능하면 문 전체와 도어락 부분을 따로 찍어 주세요.
휴대폰 화면이 젖었다면 먼저 닦고 찍으세요. / 사진이 어려우면 말로만 설명해도 됩니다.

# 젖은 서류 대신 확인할 수 있는 방법
비가 오더라도 문을 여는 일이라 신분 확인은 꼭 거칩니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
젖은 서류가 망가질 수 있으니 비닐에 넣어 두거나 우산 아래서 꺼내 주세요. / 신분증이 집 안에 있으면 관리사무소 확인으로 대신할 수 있는지 상의해 드립니다.
@ 당동 출장열쇠 비 오는 날 도착

# 궂은 날씨에도 비용은 열기 전에 안내
비가 온다는 이유로 설명 없이 진행되는 일은 없습니다. / 도어락과 문을 보고 얼마가 드는지 먼저 말씀드린 뒤 동의하시면 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다. 자세한 순서는 [이용안내](guide.html)에서 확인하실 수 있습니다.

# 비 오는 날 문 열기에서 신경 쓰는 점
문을 열 때 빗물이 도어락 안으로 들어가지 않게 가리면서 작업합니다. / 문과 도어락은 덜 상하는 방법부터 차례로 해봅니다.
문틀이 젖어 부풀었으면 무리하게 밀지 않고 상태를 보며 조절합니다. / 어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 문이 열린 뒤 점검해 둘 것
들어가신 뒤에는 젖은 번호판과 손잡이를 마른 수건으로 다시 닦아 둡니다. / 건전지 칸이 눅눅하면 건전지를 빼서 말리고 새 건전지로 넣는 것이 좋습니다.
같은 일이 반복되면 [도어락 수리](doorlock-repair.html)로 방수 틈새나 접점 상태를 확인합니다. / 너무 오래돼 자주 오작동하면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
평소 현관 앞에 작은 수건을 걸어 두는 습관도 도움이 됩니다. / 비 오는 날 문 앞에서 막히는 일이 줄어듭니다.

# 비 오는 날을 대비한 평소 습관
- 건전지는 장마철이 오기 전에 한 번 점검하기
- 비 오는 날 번호판 닦을 작은 수건을 현관 근처에 두기
- 우산을 세워 두는 자리에서 번호판까지 물이 튀지 않게 하기
- 문이 덜 닫히면 경첩과 문틀 틈새를 미리 보기
- 9V 건전지를 가방이나 차에 하나 넣어 두기
이 정도만 해도 비 오는 날의 불편이 많이 줄어듭니다.
장마철처럼 비가 며칠 이어질 때는 번호판 주변에 물방울이 맺히는 일이 잦습니다. / 그럴 때는 외출 전후로 한 번씩 닦아 주는 것만으로도 오작동이 눈에 띄게 줄어듭니다.
현관 위에 처마가 없는 구조라면 우산을 접는 위치를 문에서 조금 떨어진 곳으로 정해 두세요. / 우산에서 떨어지는 물이 번호판으로 튀지 않게 하는 작은 배려입니다.
비 오는 날 늦게 귀가하는 가족이 있다면 번호와 비상 연락처를 미리 공유해 두면 좋습니다. / 문 앞에서 오래 서 있는 일을 줄여 줍니다.

# 당동 주변 군포 전 지역 출동
당동 말고 산본동, 금정동, 당정동, 부곡동, 대야미동, 오금동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
서울·경기 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.
