# 한밤에 울리는 경고음, 이웃 눈치까지 보이게 됩니다
당정동은 금정역과 군포역 쪽으로 오가는 길목에 주택과 빌라가 모여 있는 동네입니다. / 복도식 건물이 많은 곳에서는 도어락 경고음이 건물 전체에 들리기도 합니다.
삐익 소리가 멈추지 않으면 문을 못 여는 것보다 소리 때문에 더 마음이 급해집니다. / 이 글은 경고음 유형별 원인과 해볼 순서를 정리했습니다.
소리의 종류를 구분하는 것만으로도 원인의 절반은 좁혀집니다. / 급하게 건전지부터 뽑거나 문을 두드리기 전에 한 번 차분히 들어 보세요.
해결이 안 되면 [군포 출장열쇠](gunpo.html)에 연락해 주세요.
@ 당정동 도어락 경고음 울리는 번호판

# 먼저 소리 패턴을 기억해 보세요
경고음은 짧게 반복되는지, 길게 계속 울리는지에 따라 원인이 다릅니다. / 전화로 말씀해 주시면 상담이 훨씬 쉬워집니다.
- 짧은 삑 소리가 반복되는 경우
- 길게 삐익 하고 계속 울리는 경우
- 번호를 누를 때마다 다른 소리가 나는 경우
- 소리와 함께 불빛이 깜빡이는 경우
제품마다 소리의 의미가 달라서 설명서에 적힌 안내와 함께 보시는 것이 정확합니다.

# 가장 흔한 원인은 배터리 부족입니다
배터리가 약해지면 도어락이 교체 경고음을 내기 시작합니다. / 이 소리가 몇 번 나다가 계속 울리기도 합니다.
이 경고를 무시하고 지내면 어느 날 번호판이 꺼지면서 문이 안 열릴 수 있습니다. / 경고음이 처음 나는 날 바로 교체하는 것이 가장 안전합니다.
새 건전지로 전부 바꾸면 경고음이 멈추는 경우가 많습니다. / 일부만 바꾸면 곧 같은 소리가 반복됩니다.

# 번호를 여러 번 틀려서 울리는 경우
번호를 연속으로 틀리면 도어락이 입력을 막고 경고음을 내는 제품이 많습니다. / 주변에 침입 시도가 있었다고 판단하는 보호 기능입니다.
이때는 일정 시간이 지나면 풀리거나 올바른 인증을 하면 해제됩니다. / 풀리기 전에 계속 누르면 대기 시간이 더 길어질 수 있어요.
서너 번 틀렸다면 잠시 멈추고 번호를 차분히 떠올려 보세요. / 가족에게 최근에 번호를 바꾼 사람이 있는지 물어보는 것도 좋습니다.

# 문이 덜 닫혀서 울리는 경우
문이 끝까지 닫히지 않으면 도어락이 이상을 감지하고 소리를 낼 수 있습니다. / 걸쇠가 문틀에 걸려 들어가지 못하는 경우가 대표적입니다.
문을 안쪽으로 살짝 밀면서 닫아 보고 소리가 멈추는지 확인하세요. / 문틀이나 경첩이 처졌다면 같은 일이 반복됩니다.
이 경우는 도어락보다 문 상태를 먼저 점검해야 합니다. / [도어락 수리](doorlock-repair.html) 안내를 참고해 주세요.
@ 당정동 현관문 걸쇠와 문틀 점검

# 보조키나 안쪽 잠금 때문에 울리는 경우
보조키를 잠근 채로 번호를 누르면 모터가 돌다 멈추고 경고음이 울리기도 합니다. / 안쪽 잠금 레버가 눌려 있어도 같은 현상이 생깁니다.
아이가 장난으로 레버를 돌렸을 수도 있어 안쪽 상태를 먼저 확인하세요. / 밖에서는 확인하기 어려우니 안에 있는 가족에게 보조키가 풀려 있는지 물어봐 주세요.
- 안쪽 보조키 위치
- 문 손잡이 레버의 방향
- 걸쇠 고리가 걸려 있는지

# 습기나 물기가 들어가서 울리는 경우
비가 오거나 습한 날 번호판에 물기가 스며들면 오작동으로 경고음이 울릴 수 있습니다. / 특히 비가 들이치는 복도에서 자주 생깁니다.
마른 수건으로 번호판을 닦고 잠시 두면 멈추는 경우가 있습니다. / 헤어드라이어 열풍을 가까이 대는 것은 부품이 상할 수 있어 권하지 않습니다.
같은 증상이 비 올 때마다 반복되면 점검이 필요합니다.

# 소리를 멈추려고 건전지를 빼도 될까
급한 마음에 배터리를 빼면 소리가 일단 멈출 수 있습니다. / 하지만 잠금 상태를 모르는 채로 빼면 문이 안 열릴 위험이 있습니다.
문이 열려 있는 상태에서 배터리를 뺐다가 다시 끼우는 것은 괜찮은 경우가 많습니다. / 그러나 문이 닫힌 상태라면 먼저 열 수 있는 방법을 확인하세요.
도어락 몸체를 억지로 분해하는 것은 하지 마세요. / 부품이 손상되면 수리 범위가 커집니다.

경고음이 오래 울리면 이웃에게 소음이 됩니다. / 먼저 짧게 사정을 알리면 이해해 주는 경우가 많습니다.
소리를 줄이려고 도어락에 수건을 덮거나 막는 것은 오히려 위험할 수 있습니다. / 열이 갇히거나 오작동이 심해질 수 있어요.
출장열쇠가 도착할 때까지 시간이 걸린다면 문자로 도착 시간을 확인해 두세요. / 복도식 건물이라면 옆집뿐 아니라 위아래 층에도 소리가 울릴 수 있습니다.
늦은 시간일수록 짧은 사과 한마디가 큰 도움이 됩니다. / 소리가 멈춘 뒤에 다시 인사를 남기면 이웃 관계도 편안하게 이어집니다.

# 전화할 때 알려주시면 좋은 것
- 당정동 어느 쪽인지(금정역 방향, 군포역 방향 등)
- 소리가 어떤 모양인지
- 번호판 불빛 상태
- 문을 열 수 있는지 없는지
- 최근에 배터리를 바꿨는지
사진이나 짧은 영상을 보내주시면 소리와 상태를 이해하기 쉽습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두시면 수월합니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 증상을 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 당정동 출장열쇠 경고음 점검

점검 후 경고음의 원인이 부품 고장이라면 고쳐서 쓸 수 있는지 먼저 봅니다. / 너무 오래되었거나 부품 구하기가 어려우면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문이 안 열리는 상황이면 먼저 [현관문 개문](door-open.html)부터 진행합니다.

# 경고음이 다시 울리지 않게 하는 습관
- 배터리는 해가 바뀔 때쯤 전부 교체
- 경고음이 나면 그날 바로 확인
- 비 오는 날 번호판의 물기를 닦기
- 번호를 바꾼 사람은 가족에게 바로 알리기
작은 소리 하나가 큰 고장의 신호일 수 있으니 미루지 마세요. / 경고음이 며칠에 한 번씩 짧게 울리다 마는 정도라도 그냥 두면 어느 날 길게 울리기 시작합니다.
집을 오래 비울 때는 출발 전에 배터리 상태를 한 번 확인하고, 돌아온 뒤 번호판 반응을 시험해 보세요. / 비어 있는 동안에도 도어락은 조금씩 전기를 쓰기 때문에 장기간 외출 후 소리가 나는 일이 흔합니다.

# 당정동 말고 군포 어디든 갑니다
당정동 가까운 산본동, 금정동, 당동, 부곡동, 오금동, 대야미동도 다닙니다. / 군포 안이면 24시간 출동합니다.
다른 지역은 [출장 지역](area.html)에서 확인해 주세요.
