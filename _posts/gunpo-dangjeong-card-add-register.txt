# 카드키가 하나 더 필요해졌을 때
당정역 가까이 사는 가족이 늘거나 자녀가 등하교를 시작하면 카드키가 하나 더 필요해집니다. / 처음 도어락을 달 때 받은 카드가 두세 장뿐이라 모자라는 일도 흔합니다.
이 글은 도어락에 카드키나 태그를 추가로 등록하는 순서와, 분실 후 전부 지우고 다시 등록하는 요령을 정리했습니다. / 등록이 막히거나 문이 안 열릴 때는 [군포 출장열쇠](gunpo.html)로 연락하세요.
@ 당정동 도어락 카드키 태그 등록

# 카드키 방식은 크게 두 가지
도어락의 카드 인식 방식은 제품마다 조금씩 다릅니다. / 어떤 방식인지 알면 등록 방법을 떠올리기 쉽습니다.
- 카드를 번호판 위에 대고 인식시키는 접촉식
- 열쇠고리나 팔찌 모양 태그를 가까이 대는 근접식
- 휴대폰을 카드처럼 쓰는 방식(제품이 지원할 때만)
카드가 아닌 팔찌형 태그를 쓰는 집도 많습니다. / 방식이 달라도 등록 흐름은 비슷합니다.

# 등록 전에 이것부터 확인
등록을 시작하기 전에 몇 가지를 준비하세요.
- 새로 등록할 카드나 태그가 이 도어락과 맞는 종류인지
- 도어락 안쪽의 설정 버튼 위치
- 지금 등록된 카드 개수와 최대 저장 개수
- 배터리 상태 (등록 중 꺼지면 설정이 꼬일 수 있습니다)
카드 종류가 맞지 않으면 아무리 대도 인식되지 않습니다. / 구입 전에 도어락 모델과 호환되는지 확인하세요.

# 추가 등록 기본 순서
정확한 버튼 조합은 제품마다 다르지만 흐름은 대체로 같습니다.
- 문을 열어 둔 채 안쪽 설정 버튼을 눌러 등록 모드로 들어갑니다.
- 카드 등록 메뉴를 선택합니다.
- 새 카드를 번호판에 가까이 대고 안내음을 기다립니다.
- 등록 완료음이 나면 문을 닫고 바깥에서 카드로 열어 확인합니다.
등록하는 동안 문을 열어 둔 상태에서 하는 것이 중요합니다. / 새 카드가 여러 장이면 한 장씩 등록음을 확인하고 다음 카드로 넘어가세요. / 문이 닫힌 채 설정하다 오류가 나면 문 앞에 갇힐 수 있습니다.
@ 당정동 도어락 설정 버튼 카드 등록 순서

# 관리자 번호가 필요한 제품
어떤 도어락은 설정 메뉴에 들어갈 때 관리자 번호나 기존 번호를 요구합니다. / 이 번호를 모르면 새 카드를 등록할 수 없습니다.
이사 전에 살던 사람이 정한 관리자 번호가 남아 있는 경우도 있습니다. / 그럴 때는 번호를 모르는 상태에서 설정을 풀어야 할 수 있습니다.
혼자 해결이 안 될 때는 무리하지 말고 전화 주세요. / 초기화부터 다시 등록까지 도와드립니다.

# 카드를 잃어버렸다면 추가가 아니라 정리
분실한 카드는 누가 주워도 쓸 수 있습니다. / 새 카드를 하나 더 만드는 것으로 끝내면 분실한 카드가 계속 유효합니다.
이럴 때는 기존 카드를 모두 지우고 필요한 카드만 다시 등록하는 것이 안전합니다. / 이 작업을 보통 카드 초기화라고 합니다. / 초기화한 뒤에는 쓰던 카드도 다시 등록해야 하니 가지고 있는 카드를 전부 모아 두세요.
자녀가 카드를 잃어버렸다면 야단보다 빠르게 알려달라고 일러 주는 게 좋습니다. / 알려야 바로 지울 수 있기 때문입니다.
카드 분실 상황은 [카드키 분실 대처](door-open.html)와 같은 원리로 문을 열고 난 뒤 정리합니다.

# 초기화하면 무엇이 지워지나
초기화에는 범위가 있습니다. / 모르고 전체 초기화를 누르면 번호까지 사라질 수 있으니 주의하세요.
- 카드만 지우는 메뉴가 따로 있는 제품
- 번호와 카드를 함께 지우는 제품
- 공장 초기화로 모든 설정이 되돌아가는 제품
카드만 지운다면 번호는 그대로 쓸 수 있습니다. / 어느 쪽인지 모르겠다면 설명서를 보거나 연락 주세요.

# 전체를 지우기 전에 해둘 일
초기화 전에는 가족 모두에게 알리세요. / 아침에 출근하는 가족이 번호가 지워진 사실을 모르면 문 앞에서 당황합니다.
초기화한 뒤에는 번호도 새로 등록해야 하는 경우가 있습니다. / 새 번호를 미리 정해 두면 설정이 빠릅니다. / 번호는 생일이나 전화번호처럼 추측하기 쉬운 숫자를 피하세요.
초기화 중에 문을 닫지 마세요. / 문이 열린 상태를 유지하고 천천히 진행하세요.

# 등록했는데 인식이 안 될 때
등록 완료음이 났는데 막상 카드를 대도 반응이 없는 경우가 있습니다. / 아래를 순서대로 살펴보세요.
- 카드를 대는 위치가 맞는지 (번호판 한가운데나 표시된 곳)
- 카드가 너무 빨리 스쳐 지나가지는 않았는지
- 카드 두 장을 겹쳐서 대지는 않았는지
- 배터리가 약해서 인식이 약해진 건 아닌지
금속 케이스나 두꺼운 지갑 안에서는 인식이 약해질 수 있습니다. / 카드를 꺼내서 대면 해결되는 경우가 많습니다. / 휴대폰 케이스에 카드를 같이 꽂아 두었다면 휴대폰과 카드가 서로 간섭할 수도 있어 따로 대 보세요.

# 문 안 열릴 때 열쇠집을 부르는 경우
등록하다 문을 닫아 번호도 카드도 안 먹는 상황이 가장 흔합니다. / 이때는 억지로 설정을 반복하지 말고 연락 주세요.
문을 상하게 하지 않는 개방 방법은 [현관문 개문](door-open.html)에서 안내합니다. / 문이 열린 뒤에 등록 설정까지 이어서 도와드립니다.

# 열기 전에 사시는 분인지 확인합니다
문을 열기 전에 신분을 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
카드를 새로 등록하는 일은 곧 누가 집에 드나드는지를 정하는 일이라 확인이 더욱 중요합니다. / 집 안에 서류가 있다면 경비실이나 관리사무소에 세대 확인을 부탁해 보세요. / 가족이 대신 요청하는 경우에도 현장에서 본인 확인이 가능한 방법을 같이 찾습니다.

# 비용은 열기 전에, 못 열면 받지 않습니다
도어락 종류와 작업 범위를 본 뒤 먼저 비용을 말씀드립니다. / 괜찮으시면 진행하고 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 반드시 여쭙니다.
전체 진행 방식은 [이용안내](guide.html)에서 볼 수 있습니다.
@ 당정동 출장열쇠 도어락 카드 초기화

# 카드키 관리 습관
카드는 번호보다 잃어버리기 쉽습니다. / 몇 가지만 지켜도 훨씬 안전합니다.
- 카드에 집 주소나 호수를 적지 않기
- 가족별로 카드를 나누고 누가 가졌는지 기록하기
- 분실하면 즉시 해당 카드 삭제하기
- 여분 카드 하나는 집 밖의 믿을 수 있는 곳에 보관하기
카드가 낡거나 갈라지면 인식률이 떨어집니다. / 상태가 나쁘면 새 카드로 바꾸세요.
도어락 자체가 카드 인식이 약해졌다면 [도어락 수리](doorlock-repair.html)로 점검받는 게 좋습니다.

카드 기능이 아쉬워 바꾸고 싶다면 이렇게 보세요. / 카드 저장 개수가 적거나 인식이 자주 틀리는 제품도 있습니다. / 가족이 많은 집이라면 더 많이 저장되는 제품을 고려해 볼 만합니다.
교체를 생각한다면 [도어락 교체](doorlock-replace.html)에서 확인할 점을 먼저 살펴보세요. / 문 두께와 보조키 위치를 먼저 보는 것이 순서입니다.
