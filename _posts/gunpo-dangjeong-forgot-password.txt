# 당정동에서 비밀번호가 갑자기 생각나지 않을 때
평소엔 손이 알아서 눌렀던 번호가 막상 문 앞에서는 떠오르지 않는 일이 있습니다. / 당정동에서도 이런 연락이 한 번씩 옵니다.
오래 쓴 번호가 아니라 최근에 바꾼 번호이거나, 가족 중 누군가 바꿔 놓고 말하지 않은 경우가 많습니다. / 이 글은 그럴 때 어떻게 해야 문을 안전하게 열 수 있는지 적었습니다.
상황별 대처를 보시고 안 되면 [군포 출장열쇠](gunpo.html)로 전화 주세요. / 문 앞에서 이 글을 보고 계시면 아래 목차에서 필요한 부분만 보셔도 됩니다.
@ 당정동 도어락 비밀번호 분실 출장열쇠

# 먼저 떠올려 볼 번호 후보
번호를 바로 포기하지 말고 아래 순서로 떠올려 보세요. / 대부분은 이 안에 있습니다.
- 가족 생일이나 전화번호 뒷자리 중 최근에 쓰던 것
- 이사 직후 처음 등록했던 번호
- 가족이 함께 정했다고 했던 번호
- 공동현관 비밀번호와 헷갈린 번호
- 배우자나 자녀가 마지막으로 바꿨다고 말한 번호
이 중 두세 개만 시도해 보고 안 되면 멈추는 게 좋습니다. / 너무 많이 틀리면 도어락이 일정 시간 입력을 막습니다.

# 가족에게 먼저 물어보세요
같이 사는 가족에게 전화나 문자로 물어보는 게 가장 빠릅니다. / 가족이 번호를 바꾼 걸 깜빡했다면 바로 해결됩니다.
번호를 문자로 받으면 그대로 입력하기 전에 앞뒤 자리를 한 번 더 확인하세요. / 한 자리만 틀려도 열리지 않습니다.
집 안에 가족이 있다면 안쪽 손잡이로 열어 달라고 부탁하는 방법도 있습니다. / 이 경우 비밀번호는 문이 열린 뒤에 새로 정하면 됩니다.

# 입력을 막았을 때는 기다리세요
번호를 여러 번 틀리면 도어락이 몇 분간 잠기고 경고음을 냅니다. / 이때 계속 누르면 대기 시간이 길어질 수 있습니다.
잠시 쉬었다가 다시 입력하면 풀리는 모델이 많습니다. / 그래도 안 되면 번호를 찾는 대신 문을 여는 방법으로 넘어가는 게 낫습니다.
@ 당정동 도어락 번호 입력 막힘 출장

# 비밀번호를 모를 때 문 여는 방법
번호를 모르는 채로 문을 여는 일은 도어락 종류와 문 상태에 따라 방법이 달라집니다. / 덜 상하는 방법부터 차례로 해봅니다.
열고 난 뒤에는 기존 번호를 지우고 새 번호를 등록하는 것까지 합니다. / 이렇게 해야 같은 일이 반복되지 않습니다.
문 여는 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 도어락 자체가 고장난 게 아니라면 부품을 바꿀 일은 많지 않습니다.

# 전화하실 때 알려주세요
당정동에서 상황을 알려주시면 도착이 빨라집니다. / 아래 정도만 말씀해 주세요.
- 당정동 어느 건물이고 몇 호인지
- 번호판 불이 들어오는지, 소리가 나는지
- 도어락 종류 (번호만, 번호와 카드, 번호와 지문)
- 집 안에 아이나 반려동물이 있는지
사진을 문자로 보내주시면 장비를 더 정확히 챙겨 갑니다. / 급하게 말씀하셔도 괜찮으니 편하게 전화 주세요.

# 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요. / 이 절차가 어려우면 작업을 할 수 없습니다.

# 비용은 열기 전에 말씀드립니다
문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 열고 나서 새 번호 정하는 순서
문이 열리면 안쪽에서 새 번호를 등록하는 것까지 도와드립니다. / 번호를 정할 때는 아래 기준을 권합니다.
- 생일이나 전화번호 같은 쉬운 번호는 피하기
- 가족이 모두 알 수 있는 방법으로 공유하기
- 번호를 바꾸면 가족 단체방에 바로 알리기
- 카드키가 있다면 하나는 집 밖에 따로 보관하기
번호를 새로 정하는 김에 기존에 등록된 번호는 모두 지웁니다. / 이전 번호가 남아 있으면 보안상 좋지 않습니다.
@ 군포 출장열쇠 도어락 새 비밀번호 등록

# 같은 일을 또 겪지 않으려면
비밀번호를 휴대폰 메모에 그대로 적어 두는 건 권하지 않습니다. / 대신 힌트만 적어 두거나 가족과만 아는 방식으로 정하세요.
- 번호를 바꾸는 날짜를 정해 두고 가족에게 알리기
- 분실에 대비해 열쇠나 카드키를 하나 더 두기
- 같은 번호를 여러 곳에 쓰지 않기
도어락이 오래돼서 번호 입력이 잦게 실패한다면 [도어락 수리](doorlock-repair.html)도 생각해 보세요. / 번호판이 닳아서 눌러도 입력이 안 되는 일도 있습니다.

# 당정동 말고 군포 어디든
당정동 바로 옆 금정동, 산본동, 당동, 부곡동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
군포에서 다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 열고 나서 새 번호도 정해 주나요? | 네, 새 번호 등록까지 같이 해드립니다.

? 기존 번호는 계속 남아 있나요? | 새 번호를 등록하면서 이전 번호는 지웁니다.
? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
