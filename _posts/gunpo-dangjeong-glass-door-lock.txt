# 가게 문 아래 잠금장치 하나에 영업이 멈춥니다
당정동은 군포역 주변으로 가게와 사무실이 모여 있어 아침마다 셔터를 올리고 문을 여는 분이 많은 동네입니다. / 개점 준비를 하는데 유리문이 안 열리면 하루 장사가 늦어집니다.
상가 유리문에는 문 아래쪽 바닥 가까이에 잠금장치가 달린 경우가 많습니다. / 허리를 굽혀야 보이는 위치라 평소에는 신경을 안 쓰다가 문제가 생기면 당황하게 됩니다.
이 글은 당정동 상가에서 유리문 하단 잠금장치가 안 풀릴 때 어떻게 확인하고, 언제 [군포 출장열쇠](gunpo.html)를 부르면 되는지 정리했습니다. / 점주님과 직원분이 같이 읽어 두면 도움이 됩니다.
@ 당정동 상가 유리문 하단 잠금장치

# 유리문 하단 잠금장치는 어떻게 생겼나
유리문 아래쪽에는 바닥 쪽으로 걸쇠가 박히는 방식의 잠금장치가 흔합니다. / 열쇠를 돌리면 걸쇠가 올라가거나 내려가 문을 고정합니다.
유리 가장자리에 금속 틀이 붙어 있고, 그 틀 안에 잠금 부품이 들어 있는 모양도 있습니다. / 어떤 방식인지에 따라 열기 방법과 필요한 준비가 다릅니다.
문이 한 짝인지 두 짝인지도 중요합니다. / 두 짝 문은 한쪽만 고정되고 다른 쪽은 고정된 문 쪽에 맞물리는 구조도 있습니다.

# 안 풀릴 때 가장 먼저 확인할 것
열쇠가 돌아가는지, 아니면 아예 안 들어가는지부터 구분하세요. / 열쇠가 헛돌면 안쪽 부품 문제이고 안 들어가면 구멍에 이물질이나 열쇠 모양 문제일 수 있습니다.
- 올바른 열쇠인지(비슷한 열쇠를 섞어 쓰는 경우가 많음)
- 열쇠 구멍에 먼지나 이물질이 있는지
- 문이 한쪽으로 처져 걸쇠가 바닥에 눌려 있지는 않은지
- 안쪽에서 별도의 걸이나 빗장을 걸어 둔 건 아닌지
상가는 열쇠가 여러 개인 경우가 많아 다른 문 열쇠를 꽂고 있는 일도 많습니다. / 열쇠에 표시해 두면 이런 혼동이 줄어듭니다.

# 문이 처졌을 때 생기는 일
유리문은 무게가 있어서 시간이 지나면 한쪽으로 조금씩 처집니다. / 처진 문은 걸쇠가 바닥 구멍과 어긋나 꽉 물려서 열쇠를 돌려도 풀리지 않습니다.
이럴 때 문을 살짝 들어 올리듯이 하면서 열쇠를 돌리면 풀리는 경우가 있습니다. / 한 사람이 문을 받쳐 주고 다른 사람이 열쇠를 돌리면 도움이 됩니다.
유리문이라 무리하게 힘을 쓰면 유리가 깨질 위험이 있습니다. / 몇 번 해보고 안 되면 멈추세요.

# 이 행동은 피해 주세요
열쇠를 억지로 돌려 부러뜨리는 일이 가장 흔합니다. / 부러진 조각이 구멍 안에 남으면 잠금장치를 통째로 손봐야 할 수도 있습니다.
유리문을 발로 차거나 어깨로 밀어붙이는 것도 매우 위험합니다. / 유리가 깨지면 다칠 수 있고 수리 범위가 훨씬 커집니다.
드라이버로 하단 틀을 벌리려는 시도도 권하지 않습니다. / 틀이 휘면 문이 제대로 닫히지 않게 됩니다.
기름이나 윤활제를 급하게 뿌리는 것도 도움이 되지 않을 수 있습니다. / 먼지가 엉겨 나중에 더 뻑뻑해지기도 합니다.
@ 유리문 하단 잠금장치 열쇠 구멍 이물질 확인

# 셔터와 유리문이 같이 있는 가게라면
당정동 상가에는 바깥 셔터와 안쪽 유리문을 함께 쓰는 곳이 있습니다. / 어느 쪽이 안 열리는지 정확히 구분해서 말씀해 주세요.
셔터가 문제인지 유리문이 문제인지에 따라 필요한 장비와 방법이 달라집니다. / 전화로 상황을 알려주시면 챙겨 갈 준비를 하기 쉽습니다.
출입문이 두 개 이상이라면 다른 문으로 들어갈 수 있는지도 확인해 보세요. / 직원 출입구가 열린다면 안쪽에서 확인하는 것이 빠릅니다.

# 열쇠를 잃어버렸다면
상가 열쇠는 여러 사람이 가지고 있다가 어디 있는지 모르게 되는 경우가 많습니다. / 직원이 그만두고 열쇠를 안 돌려준 경우에도 문제가 됩니다.
열쇠가 없으면 문 열기와 함께 잠금장치를 어떻게 할지 결정해야 합니다. / 열쇠를 새로 맞출지, 잠금장치를 바꿀지는 문 상태를 보고 말씀드립니다.
한번 정리하는 김에 [열쇠 출장](key-call.html) 페이지에서 어떤 경우에 부르는지 확인해 보세요. / 열쇠 관리를 다시 세우는 계기가 됩니다.

# 전화하실 때는 이렇게 알려주세요
당정동은 군포역을 기준으로 위치를 말씀해 주시면 찾기 쉽습니다. / 건물 층수와 가게가 도로변인지 골목 안쪽인지도 알려주세요.
- 문이 한 짝인지 두 짝인지
- 하단 잠금장치의 모양(사진 첨부)
- 열쇠가 돌아가는지, 안 들어가는지, 없는지
- 영업 시작 시간이나 급한 사정
사진 한 장이면 필요한 장비를 챙기기 좋습니다. / 비용은 문 열기 전에 먼저 말씀드리고 동의하셔야 시작합니다.

# 도착하면 사업장 관계부터 확인합니다
상가도 문을 여는 일이라 요청하시는 분이 가게를 운영하거나 관리하는 분인지 확인합니다. / 신분증과 함께 가게 운영을 알 수 있는 서류나 우편물, 건물 관리인 확인 중 하나면 됩니다.
건물 임대 관계 때문에 확인이 어려울 때는 건물 관리인에게 연락해 두시면 수월합니다. / 확인이 어려우면 작업을 할 수 없는 점은 양해 부탁드립니다.
이 절차는 다른 사람이 무단으로 문을 여는 것을 막기 위한 것입니다. / 점주님 가게를 지키는 일이기도 합니다.
@ 당정동 출장열쇠 상가 유리문 개방 작업

# 유리문을 상하지 않게 여는 방법
유리문은 깨지면 위험하고 비용도 커서 가장 조심해서 다룹니다. / 문과 유리, 하단 틀이 상하지 않는 방법부터 차례로 해봅니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 먼저 말씀드립니다. / 괜찮다고 하셔야 진행합니다.
[현관문 개문](door-open.html) 페이지에 문 여는 원칙을 적어 두었습니다. / 문을 끝내 못 열면 비용은 받지 않습니다.

# 잠금장치를 고치거나 바꿀 때
열고 나서 잠금장치가 낡았거나 자꾸 걸린다면 수리를 먼저 검토합니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
[도어락 수리](doorlock-repair.html)로 손볼 수 있는지 먼저 보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 열쇠 방식을 번호나 카드 방식으로 바꾸고 싶다면 문 구조를 먼저 확인해야 합니다.
유리문은 구멍을 낼 수 없는 경우가 많아 설치 가능한 제품이 정해져 있습니다. / 새로 다는 계획이 있으면 먼저 사진을 보내 주세요.

# 가게 문을 오래 안 걸리게 쓰는 관리법
유리문 하단 잠금장치는 아래쪽에 있어 먼지가 잘 낍니다. / 청소할 때 바닥 홈과 걸쇠 주변을 같이 닦아 주세요.
- 열쇠마다 표시해서 문별로 구분하기
- 열쇠 구멍은 가끔 마른 솔로 먼지 털기
- 문이 처지는 느낌이 들면 일찍 점검받기
- 여분 열쇠는 정해진 한 곳에 보관
직원이 바뀔 때 열쇠를 돌려받는 습관도 필요합니다. / 이 작은 정리가 갑자기 문이 안 열리는 날의 부담을 줄여 줍니다.

# 당정동 말고 군포 어디든 갑니다
당정동 옆 산본동, 금정동, 당동, 부곡동, 오금동, 대야미동도 다닙니다. / 군포 안이면 동네와 상관없이 24시간 연락받습니다.
다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에 있고 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다. / 진행 방식은 [이용안내](guide.html)에서도 확인하세요.
