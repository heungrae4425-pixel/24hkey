# 당정동 자석식 잠금장치, 문이 붙어서 안 떨어질 때
당정동에서 군포역이나 금정역 쪽으로 오가다 보면 작은 사무실, 학원, 상가 건물 출입문에 자석으로 붙는 잠금장치가 달린 곳을 자주 봅니다. / 문틀 위쪽에 긴 막대 모양 본체가 있고 문짝에 철판이 맞닿아 붙는 방식입니다.
평소에는 조용히 잘 쓰다가 어느 날 문이 안 떨어지거나 반대로 저절로 풀려 버리면 당황하게 됩니다. / 이 글은 자석식 출입문 잠금장치가 이상할 때 먼저 볼 것과 전화가 필요한 때를 순서대로 적었습니다.
열쇠로 여는 문과 원리가 달라서 열쇠집에 연락해도 되는지 망설이는 분이 많습니다. / 결론부터 말씀드리면 [군포 출장열쇠](gunpo.html)에서 이런 문도 상태를 보고 안내해 드립니다.
@ 당정동 자석식 출입문 잠금장치 점검

# 자석 잠금장치는 어떻게 문을 붙잡고 있나
문틀 쪽 본체에 전기가 흐르면 자석이 되고, 문짝에 붙은 철판을 끌어당겨 문을 잠급니다. / 전기가 끊기면 자석 힘이 사라져서 문이 풀리는 구조가 일반적입니다.
그래서 열쇠 구멍이나 걸쇠가 없는 경우가 많고, 밖에서는 카드나 번호, 안에서는 버튼으로 여는 형태가 흔합니다. / 문이 닫혀 있다는 사실과 잠겨 있다는 사실이 같지 않다는 점도 이 장치의 특징입니다.
전원 공급 장치, 열림 버튼, 카드 리더기, 자석 본체와 철판이 하나로 이어져 움직입니다. / 어느 한 곳이 흔들리면 증상은 비슷하게 보여서 순서대로 짚어야 원인이 나옵니다.

# 증상별로 먼저 의심해 볼 곳
증상이 어떻게 나타나는지에 따라 의심할 곳이 달라집니다. / 아래 표처럼 나눠 보시면 전화로 설명하기도 쉽습니다.
- 문이 안 떨어지고 꽉 붙어 있다: 열림 버튼 배선, 전원 장치, 제어기 오류
- 문이 닫혀도 그냥 밀면 열린다: 철판이 어긋났거나 자석 면에 이물질이 낀 경우
- 붙었다 떨어졌다 반복한다: 전원이 불안정하거나 접점이 헐거운 경우
- 윙 하는 낮은 소리가 크게 난다: 철판과 자석 면이 정확히 맞닿지 않는 경우
- 카드를 대도 반응이 없다: 리더기 전원이나 제어기 쪽 문제
증상이 둘 이상 겹치면 전원 장치부터 의심하는 게 보통입니다. / 다만 눈으로 보이는 것만으로 단정하지 말고 아래 확인 순서를 따라가 보세요.

# 먼저 문 앞에서 해볼 수 있는 확인
공구 없이 해볼 수 있는 것만 적습니다. / 안쪽에서 열림 버튼을 누르는 방식이면 버튼부터 손으로 눌러 봅니다.
- 열림 버튼을 누르는 동안 문틀 위쪽에서 딸깍하는 작은 소리가 나는지 듣기
- 카드 리더기나 번호판에 불이 들어와 있는지 보기
- 문을 앞뒤로 살짝 흔들어 철판이 자석에 어떻게 붙어 있는지 보기
- 같은 전원 줄을 쓰는 다른 기기가 꺼져 있지 않은지 확인하기
- 건물 분전함의 차단기가 내려가 있지 않은지 보기(건물 관리자가 있다면 먼저 문의)
불이 전혀 들어오지 않으면 전원 쪽, 불은 들어오는데 문이 안 풀리면 제어나 버튼 쪽일 가능성이 큽니다. / 이 구분만 알려주셔도 출동할 때 챙길 부품이 달라집니다.

# 자석 면과 철판에 낀 먼지·녹도 원인이 됩니다
자석과 철판은 평평하게 맞닿아야 힘이 제대로 걸립니다. / 그 사이에 먼지, 테이프 자국, 얇은 녹이 끼면 소리가 나거나 문이 헐겁게 붙을 수 있습니다.
마른 천으로 가볍게 닦는 정도는 괜찮지만 물을 뿌리거나 기름칠을 하는 것은 피해 주세요. / 전기가 흐르는 장치라 물기가 들어가면 고장이 더 커집니다.
철판이 문짝에 고정된 나사가 풀려 기울어졌다면 직접 조이기보다 위치를 맞춰야 합니다. / 조금만 어긋나도 붙는 힘이 크게 달라지기 때문입니다.
@ 당정동 문틀 자석 본체와 철판 확인

# 하지 말아야 할 것, 힘으로 떼거나 선 건드리기
문이 붙어서 안 열린다고 문짝을 세게 당기거나 발로 차는 분이 있습니다. / 자석은 힘으로 떼면 철판이 휘고 문틀 본체가 틀어져서 나중에 더 크게 고치게 됩니다.
전원 장치의 덮개를 열고 선을 뽑거나 다시 꽂는 것도 권하지 않습니다. / 선이 바뀌어 꽂히면 장치가 오작동하거나 다른 기기까지 영향을 받을 수 있습니다.
빠른 해결을 위해 자석 본체를 통째로 떼어내려는 시도도 하지 마세요. / 문틀 위쪽은 높고 전기가 있는 곳이라 다칠 위험도 있습니다.

# 정전이 되면 문은 어떻게 되나
자석식은 전기가 끊기면 풀리는 방식과 반대로 정전에도 잠김을 유지하는 방식이 있습니다. / 설치 형태에 따라 다르기 때문에 우리 건물이 어느 쪽인지 평소에 알아 두면 좋습니다.
정전 때 문이 풀리는 형태라면 방범상 비어 있는 문이 되고, 유지되는 형태라면 안에 있는 사람이 나가기 어려울 수 있습니다. / 비상 상황에서 사람이 나가는 길이 막히지 않아야 하므로 이 점은 꼭 확인해야 합니다.
건물 관리자나 설치하신 분께 비상 시 어떻게 열리는지 물어 두시면 급할 때 시간이 줄어듭니다. / 모르는 상태라면 현장에서 구조를 먼저 보고 말씀드립니다.

# 자석식과 일반 도어락 중 무엇이 맞을까
자석식은 문이 자주 열리고 닫히는 출입구, 사람이 많이 드나드는 사무실에 편한 방식입니다. / 반면 열쇠가 없어서 정전이나 제어기 고장에 취약한 면도 있습니다.
집 현관처럼 가족끼리 쓰는 문이라면 일반 도어락과 보조키가 단순해서 관리가 쉽습니다. / 어떤 문에 어떤 방식이 맞는지는 문 용도에 따라 달라집니다.
바꾸는 것까지 고민된다면 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html) 페이지를 먼저 보셔도 좋습니다. / 비용은 현장을 보고 작업 전에 먼저 안내해 드립니다.

# 전화하실 때 알려주면 좋은 것
자석식 잠금장치는 모양이 비슷해도 제어 방식이 제각각입니다. / 아래 내용을 알려주시면 출동 준비가 빨라집니다.
- 문이 지금 붙어 있는지, 헐겁게 풀려 있는지
- 열림 버튼과 카드 리더기의 불이 들어오는지
- 문틀 위 본체에서 소리가 나는지
- 건물에 관리인이나 관리사무실이 있는지
- 문 안쪽에 사람이나 동물이 갇혀 있지는 않은지
가능하면 문틀 위쪽 본체와 안쪽 버튼 사진을 문자로 보내주세요. / 사진 한 장이 긴 설명보다 훨씬 정확합니다.

# 장치를 열기 전에 쓰시는 분인지부터 확인합니다
문을 여는 일이라 해당 장소를 쓰는 분인지 확인하는 절차가 있습니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
상가나 사무실이라면 건물 관리인에게 확인을 부탁하는 방법도 있습니다. / 확인이 어려우면 작업을 해드릴 수 없으니 미리 준비해 두시면 좋습니다.
@ 당정동 출입문 장치 확인 후 작업 안내

# 작업 방법과 비용은 장치를 본 뒤 먼저 안내합니다
장치를 직접 보고 어디가 문제인지 확인한 뒤 얼마가 드는지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 작업 도중 부품 교체가 필요해 보이면 손대기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다. / 보통은 기존 장치를 살리는 쪽을 먼저 찾아봅니다.

# 고친 뒤에는 이렇게 같이 확인합니다
문이 열리면 닫았을 때 철판이 제대로 붙는지, 버튼을 눌렀을 때 시원하게 풀리는지 몇 번 반복해 봅니다. / 카드나 번호가 있는 곳은 등록된 것이 모두 정상으로 읽히는지도 함께 봅니다.
고쳐서 쓸 수 있는 장치는 수리를 먼저 권해 드립니다. / 자주 반복되는 증상이면 [도어락 수리](doorlock-repair.html)로 손볼지, 장치 자체를 바꿀지 상의합니다.
평소 점검은 문이 한 번씩 헐겁게 붙을 때 철판 나사부터 보는 것으로 충분합니다. / 계절이 바뀔 때 먼지를 마른 천으로 닦아 두는 것도 도움이 됩니다.

# 당정동 인근 군포 전 지역 출동
당정동 바로 옆 산본동, 금정동, 당동, 부곡동, 대야미동, 오금동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에, 서울·경기 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다. / 자석식이든 일반 도어락이든 상태를 보고 알려드립니다.

# 자주 묻는 질문

? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 정전이 났는데 문이 안 열려요. | 건물 관리자에게 비상 해제 방법을 먼저 물어보시고, 안 되면 상황과 사진을 알려주세요.
? 상가 임차인인데 건물주 허락이 필요한가요? | 해당 장소를 쓰는 분인지만 확인됩니다. 신분증이나 우편물, 관리사무소 확인을 준비해 주세요.
? 밤늦게나 새벽에도 전화해도 되나요? | 24시간 받습니다. 시간 걱정 말고 연락 주세요.
