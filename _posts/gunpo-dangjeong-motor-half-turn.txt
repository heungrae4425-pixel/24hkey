# 윙 소리만 나고 반쯤 돌다 멈추는 도어락
당정동은 군포역과 금정역을 오가는 분들이 많은 군포 생활권의 주거 동네입니다. / 퇴근길에 번호를 눌렀는데 윙 하는 소리가 나다가 중간에서 뚝 멈추는 경험을 하신 분이 적지 않습니다.
처음에는 번호가 틀렸나 싶어 다시 눌러 보지만, 모터는 매번 비슷한 자리에서 멈춥니다. / 문은 손잡이를 돌려도 열리지 않아 점점 불안해집니다.
이 증상은 도어락 전체가 고장 난 경우보다 걸쇠나 데드볼트 쪽에서 막히는 경우가 많습니다. / 이 글은 당정동에서 이 증상이 생겼을 때 원인, 확인 순서, [군포 출장열쇠](gunpo.html)를 부를 때의 흐름을 정리했습니다.
@ 당정동 도어락 모터가 반쯤 돌다 멈춘 현관문 앞

# 모터가 반쯤 돈다는 건 어떤 상태인가
도어락은 번호가 맞으면 안에 든 작은 모터가 돌면서 데드볼트를 당겨 줍니다. / 이 모터가 끝까지 돌아야 문이 열리는데, 중간에서 멈추면 데드볼트가 반만 들어간 상태가 됩니다.
소리가 나는 것을 보면 번호 인식과 전원은 살아 있다는 뜻입니다. / 그러므로 배터리가 아예 죽은 경우와는 원인이 다르게 접근해야 합니다.
모터가 힘이 모자라는 상황인지, 막히는 상황인지를 가려내는 것이 첫 단계입니다.

# 가장 흔한 원인 1, 배터리 전압이 모자랄 때
배터리가 완전히 방전되기 직전에는 번호판은 켜지지만 모터에 힘을 줄 만큼은 안 되는 때가 있습니다. / 이럴 때 윙 하고 시작하다가 반쯤에서 멈추는 증상이 나옵니다.
새 배터리로 바꾸면 거짓말처럼 돌아오는 경우가 많습니다. / 바깥쪽 비상 단자가 있다면 9V 건전지를 대고 다시 눌러 보세요.
다만 같은 증상이 건전지를 대도 반복되면 다른 원인일 가능성이 커집니다.

# 가장 흔한 원인 2, 문과 문틀이 서로 눌릴 때
문이 처져 있으면 데드볼트가 문틀 구멍 가장자리에 비스듬히 닿아 힘을 받습니다. / 모터가 그 압력을 이기지 못해 반쯤에서 멈추게 됩니다.
문을 안쪽으로 살짝 밀면서 번호를 눌러 보세요. / 눌림이 줄어들며 열리면 문틀과 경첩 쪽 문제입니다.
겨울에는 문이 수축하고 여름에는 팽창해 계절에 따라 증상이 바뀌는 집도 많습니다.
@ 당정동 문틀 받음판 구멍과 데드볼트 위치가 어긋난 모습

# 가장 흔한 원인 3, 내부 부품이 마모된 경우
오래 쓴 도어락은 모터 기어나 걸쇠 연결 부품이 닳아 힘이 전달되지 않습니다. / 소리는 나는데 움직임이 약하고 점점 반쯤에서 멈추는 횟수가 늘어납니다.
이 경우에는 배터리를 바꿔도 잠깐 좋아졌다가 다시 나빠집니다. / 시간이 지나 증상이 잦아졌다면 부품 상태를 직접 점검받는 것이 좋습니다.
직접 분해하면 부품이 풀리고 조립 순서를 놓치기 쉬우니 열어 보지 않는 편이 안전합니다.

# 지금 문 앞에서 할 수 있는 확인 순서
- 번호판에 손바닥을 대어 불이 들어오는지 확인
- 번호 입력 때 나는 소리가 평소와 다른지 확인
- 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보기
- 9V 건전지를 비상 단자에 대고 다시 시도
- 기계식 열쇠 구멍이 있으면 열쇠로 열어 보기
이 중 열쇠 구멍을 쓰는 방법은 모터와 상관없이 데드볼트를 직접 움직입니다. / 열쇠가 있다면 모터가 말을 안 들어도 열 수 있으니 가장 확실합니다.
열쇠가 없다면 억지로 흔들지 말고 아래 항목을 확인한 뒤 전화 주세요.

# 하지 말아야 할 것
같은 번호를 연속으로 계속 누르는 것은 피하세요. / 모터가 막힌 상태로 계속 힘을 쓰면 열이 나고 부품이 더 빨리 상합니다.
손잡이를 세게 당기거나 문을 두드리는 것도 도움이 안 됩니다. / 걸쇠가 문틀에 더 꽉 물려 열기 어려워집니다.
드라이버로 도어락을 뜯거나 문틈을 벌리는 것은 문과 도어락 모두 상하게 합니다.

# 출장열쇠에 알려 주실 내용
전화하실 때 아래를 알려 주시면 도착 전에 필요한 장비를 정하기 좋습니다.
- 당정동 안 대략적인 위치와 건물 형태
- 번호를 누를 때 나는 소리와 모터가 멈추는 시점
- 배터리를 바꿨는지, 비상 전원을 대 봤는지
- 기계식 열쇠를 가지고 있는지
- 집 안에 아이나 반려동물이 있는지
도어락 전체 사진을 문자로 보내 주시면 도움이 됩니다. / 요청 절차는 [열쇠 출장](key-call.html) 페이지에도 정리했습니다.

도착하면 문을 열기 전에 거주하시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집 주인 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 증상, 필요한 작업 범위를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니라면 그대로 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에서 확인하세요.

# 문은 최대한 상하지 않게 엽니다
모터가 막힌 문은 억지로 힘을 쓰면 안쪽 부품이 더 상합니다. / 덜 상하는 방법부터 차례로 해보고 도어락과 문틀 외관을 지킵니다.
걸리는 시간은 도어락 종류와 문 상태에 따라 다릅니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.
개문 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.
@ 당정동 출장열쇠 도어락 모터 점검과 비파손 개방

# 열고 난 뒤 원인을 가려 처리합니다
문이 열리면 모터가 끝까지 도는지부터 몇 번 시험합니다. / 배터리 전압이 원인이었다면 새 배터리로 바꾸고, 문틀이 눌리는 것이라면 받음판 위치를 조정합니다.
내부 부품이 닳았다면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 너무 낡아 반복된다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
고쳐 쓸 수 있으면 교체는 권하지 않습니다.

# 같은 증상이 다시 오지 않게 하는 습관
- 배터리는 해가 바뀔 때 전부 새것으로 교체
- 경고음이 나면 미루지 말고 그날 확인
- 문이 처지는 느낌이 있으면 경첩부터 점검
- 번호판에 물기가 남지 않게 닦기
- 비상용 9V 건전지 하나를 가방이나 차에 두기
증상이 한 번 나왔다면 다음에 또 올 가능성이 높으니 미루지 마세요. / 한 번 점검받아 두면 문 앞에서 당황하는 일이 훨씬 줄어듭니다.

# 당정동 말고 군포 어디든 갑니다
당정동 가까이 산본동, 금정동, 당동, 부곡동, 대야미동, 오금동도 다닙니다. / 군포 안이라면 시간 상관없이 24시간 출동합니다.
다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 확인하세요.
