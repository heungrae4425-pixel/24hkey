# 금정동에서 열쇠가 부러졌다면
열쇠를 돌리다가 뚝 하는 느낌과 함께 손에 잡힌 열쇠가 짧아지는 순간이 있습니다. / 열쇠 머리만 손에 남고 나머지는 열쇠구멍 안에 박혀 있으면 머릿속이 하얘집니다.
금정역 근처에서 퇴근하다가 이런 일을 겪고 연락 주시는 분이 있습니다. / 먼저 말씀드리고 싶은 것은 당황할 필요는 없다는 점입니다.
부러진 조각은 정해진 방법으로 빼내면 대부분 문을 상하게 하지 않고 해결됩니다. / 다만 잘못 건드리면 조각이 더 깊이 들어가니 순서가 중요합니다.
이 글은 금정동에서 열쇠가 부러졌을 때 해도 되는 일과 하면 안 되는 일, [군포 출장열쇠](gunpo.html)의 진행 순서를 정리했습니다.
@ 금정동 출장열쇠 부러진 열쇠 제거

# 열쇠가 왜 부러질까
부러지는 열쇠는 대부분 갑자기 부러진 것이 아니라 오래 쌓인 피로 끝에 부러집니다. / 복사를 거듭한 열쇠나 오래 쓴 열쇠는 금속이 약해져 있습니다.
열쇠가 뻑뻑해졌는데 힘으로 돌리다가 부러지는 경우가 가장 흔합니다. / 겨울에 금속이 차가워졌을 때나 문이 처져 걸쇠가 눌려 있을 때도 마찬가지입니다.
열쇠고리에 무거운 물건을 달아 두면 열쇠구멍에 하중이 걸려 열쇠가 휘기도 합니다. / 이런 열쇠는 부러지기 전에 한 번 바꿔 주는 편이 낫습니다.

# 부러진 조각이 보이면 이렇게 하세요
조각이 밖으로 조금이라도 나와 있는지 먼저 눈으로 확인해 보세요. / 나와 있다면 손톱이나 얇은 핀셋으로 잡아 살살 당겨서 빠지는 경우가 있습니다.
조각이 안으로 완전히 들어가 보이지 않는다면 그때는 건드리지 않는 것이 맞습니다. / 철사나 바늘로 후벼서 꺼내려고 하면 조각이 더 깊이 들어갑니다.
손에 남은 열쇠 머리 쪽은 버리지 말고 가지고 계세요. / 부러진 단면이 남아 있으면 열쇠를 새로 만들 때 도움이 됩니다.

# 접착제는 절대 쓰지 마세요
부러진 열쇠를 붙여서 빼 보겠다고 순간접착제를 쓰는 분이 있습니다. / 이것은 가장 피해야 하는 방법입니다.
접착제가 열쇠구멍 안으로 흘러들어가면 내부가 굳어 문 전체를 바꿔야 하는 경우가 생깁니다. / 한 번 굳으면 되돌릴 수 없습니다.
이미 접착제를 써 보셨다면 말씀해 주세요. / 상태에 맞춰 작업 방식을 정해야 하기 때문입니다.
@ 군포 금정동 부러진 열쇠 열쇠구멍

# 문이 열려 있는지 먼저 확인하세요
열쇠가 부러졌어도 안쪽에서 잠금이 풀려 있거나 도어락 번호로 열 수 있는 문이 있습니다. / 열쇠구멍과 번호판이 같이 있는 도어락이라면 번호로 먼저 열어 보세요.
번호로 열리면 급한 문제는 해결되고 부러진 조각은 나중에 천천히 빼도 됩니다. / 이 경우 조각이 구멍에 박힌 채로 외출하지 않도록 조심하세요.
번호판이 없는 열쇠 전용 문이라면 조각을 빼면서 문을 같이 열어야 합니다. / 이때는 전화로 문 종류를 알려 주시면 준비해서 갑니다.

# 출장열쇠가 하는 조각 제거 순서
도착하면 조각이 어디까지 들어가 있는지 확인합니다. / 조각이 보이는 위치와 열쇠구멍 종류에 따라 쓰는 도구가 달라집니다.
조각을 빼는 전용 도구로 열쇠구멍을 상하지 않게 조각만 뽑아냅니다. / 한 번에 안 빠지는 경우에도 순서를 바꿔 다시 시도합니다.
조각이 빠지면 열쇠구멍이 정상인지 확인하고, 열쇠가 돌아가는지 봅니다. / 구멍이 상했다면 그 부분만 교체하는 방법부터 말씀드립니다.

# 문을 열어야 할 때는 이렇게
조각을 빼도 열쇠가 부러져 문을 열 열쇠가 없다면 문을 열어야 합니다. / [현관문 개문](door-open.html) 방식으로 최대한 안 상하게 엽니다.
문을 연 뒤에는 새 열쇠를 만들거나 잠금장치를 손봅니다. / 열쇠 작업은 [출장 열쇠](key-call.html) 안내에 정리해 두었습니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.

# 신분 확인 절차를 먼저 거칩니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집 주인 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 비용은 작업 전에 말씀드립니다
조각이 얼마나 들어갔는지, 열쇠구멍이 상했는지에 따라 작업이 달라집니다. / 그래서 상태를 보고 난 뒤 얼마인지 먼저 말씀드립니다.
괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다. / 부품을 바꿔야 할 때도 바꾸기 전에 따로 여쭤봅니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 낡아서 계속 문제가 되는 잠금장치만 교체를 말씀드립니다.

# 열쇠가 부러지기 전에 바꿔야 하는 신호
- 열쇠가 예전보다 뻑뻑하게 돌아가는 느낌이 들 때
- 열쇠 끝이나 홈이 눈에 띄게 닳아 둥글어졌을 때
- 열쇠가 약간 휘어 있을 때
- 복사본이 여러 번 복사된 열쇠일 때
- 겨울에 열쇠가 유난히 안 돌아갈 때
이런 열쇠는 부러지기 전에 새로 만들어 두면 문 앞에서 당황할 일이 줄어듭니다. / 열쇠 하나 만드는 일은 문 앞에서 부러진 열쇠를 빼는 일보다 훨씬 간단합니다.
@ 금정동 열쇠 복사 교체 출장

# 금정동 말고 군포 어디든 갑니다
금정동 바로 옆 산본동, 당동, 당정동, 부곡동, 대야미동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
군포 전체 출장 안내는 [군포시 출장열쇠](gunpo.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
