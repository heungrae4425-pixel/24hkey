# 금정동 카페 오픈 직전에 문이 안 열린다면
금정동은 금정역을 오가는 사람이 많아 아침 일찍부터 문을 여는 가게가 많은 동네입니다. / 카페는 오픈 시간이 곧 약속이라서 문이 안 열리면 하루 시작이 통째로 흔들립니다.
원두를 내리고 손님을 맞을 준비가 한창인데 출입문 앞에서 막히면 마음이 급해집니다. / 이 글은 그럴 때 침착하게 확인할 순서를 적었습니다.
직접 해결이 안 되면 [군포 출장열쇠](gunpo.html)로 연락 주세요. / 오픈 시간이 임박했다면 상황부터 말씀하시는 게 좋습니다.
@ 금정동 카페 출입문 오픈 전 점검

# 가게 문이 안 열리는 이유는 집과 조금 다릅니다
카페 출입문은 유리문이거나 문 위아래에 잠금이 달린 경우가 많습니다. / 여기에 셔터나 도어락, 시건장치가 겹치기도 해서 어느 쪽이 걸렸는지 먼저 살펴야 합니다.
- 전날 마감하면서 잠금 위치를 다르게 돌린 경우
- 도어락 배터리가 약해져 번호판이 꺼진 경우
- 열쇠 끝이 닳거나 자물쇠가 뻑뻑해진 경우
- 문이 틀에 눌려서 데드볼트가 안 빠지는 경우
가정집보다 문을 여닫는 횟수가 훨씬 많아 부품이 빨리 닳는 편입니다.

# 열쇠를 꽂기 전에 문 상태부터 봅니다
열쇠를 돌려도 안 되면 문을 안쪽으로 살짝 밀면서 다시 돌려 보세요. / 문이 눌려 있으면 잠금 걸쇠가 빠지지 않는 경우가 많습니다.
셔터가 내려져 있다면 셔터 자물쇠와 문 열쇠가 서로 다른지 구분해야 합니다. / 같은 열쇠 뭉치에 여러 개가 걸려 있으면 헷갈리기 쉽습니다.
열쇠가 반쯤 들어가다 걸린다면 억지로 돌리지 말고 빼서 상태를 보세요.

유리문의 경우 바닥 쪽 잠금이 따로 있어서 위쪽만 확인하고 지나치는 일이 있습니다. / 위아래 잠금을 모두 살펴보는 습관을 들이면 헛걸음이 줄어듭니다.
문 앞에 쌓인 눈이나 물기 때문에 문턱이 얼어붙어 걸리는 경우도 있습니다. / 추운 날 이른 아침이라면 이쪽도 의심해 보세요.

# 전날 마감한 사람에게 먼저 확인하세요
직원이 여럿이면 마감을 맡은 사람이 잠금을 어떻게 했는지 아는 것이 가장 빠른 단서입니다. / 문자 한 통으로 해결되는 경우가 의외로 많습니다.
번호를 바꿨는데 공유가 안 된 경우도 있으니 최근에 번호를 바꾼 적이 있는지도 물어봅니다. / 열쇠를 가진 사람이 따로 있는지도 같이 확인하세요.
이런 일이 반복되면 마감 후 확인 목록을 정해 두는 편이 좋습니다.

# 번호판이 꺼졌다면 비상 전원으로
상점 도어락도 9V 건전지를 대는 비상 단자가 있는 경우가 많습니다. / 가게 안에 여분이 없다면 금정역 근처 편의점에서 구하는 방법도 있습니다.
건전지를 대고 불이 들어오면 번호를 눌러 열고, 열린 뒤에는 배터리를 전부 새것으로 바꾸세요. / 단자가 없거나 반응이 없다면 다음 단계로 넘어갑니다.
@ 금정동 상가 도어락 비상 전원 확인

# 오픈 시간이 임박했을 때의 선택
문 앞에서 오래 씨름할수록 시간이 지나 손님이 먼저 도착할 수 있습니다. / 5분 안에 풀리지 않으면 빠르게 전문가를 부르는 쪽이 더 이득인 경우가 많습니다.
그동안 손님에게 양해를 구하는 안내문을 붙이거나 매장 SNS에 공지를 남기는 것도 방법입니다. / 사정을 솔직히 알리면 대부분 이해해 줍니다.
이럴 때 문을 급하게 부수거나 유리에 충격을 주는 것은 절대 피하세요. / 수리가 훨씬 커집니다.

# 출장을 부르실 때 알려 주실 것
가게 위치와 층, 문 종류(유리문, 철문, 셔터 포함 여부)를 알려 주세요. / 도어락 사진이나 자물쇠 사진을 문자로 보내시면 필요한 장비를 챙기기 쉽습니다.
- 금정동 어느 쪽이고 몇 층인지
- 오픈 희망 시간과 지금 시각
- 번호판 상태와 소리
- 열쇠를 돌렸을 때 걸리는 느낌이 어떤지
상황을 알면 도착 전에 대략의 작업 방식을 정해 둘 수 있어 시간이 단축됩니다.

# 가게 주인 확인은 이렇게 합니다
문을 열기 전에 해당 가게를 운영하는 분인지 확인합니다. / 사업자 정보가 있는 서류, 계약서, 건물 관리 쪽 확인 중에서 가능한 것을 보여 주시면 됩니다.
직원이 대신 연락했다면 대표나 임차인 확인이 필요할 수 있습니다. / 번거로워도 남의 가게 문을 함부로 열지 않기 위한 절차입니다.
건물 관리인이 있는 경우 관리인이 확인을 도와줄 수도 있습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 비용은 열기 전에 먼저 말씀드립니다
문 종류와 잠금 방식을 본 뒤에 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니라면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다.
상가 문 개방 방식은 [현관문 개문](door-open.html)에도 정리해 두었습니다.
@ 금정동 카페 출입문 개방 작업

문이 열렸다면 매장 안으로 들어가 안쪽에서도 잠금이 부드럽게 풀리는지 확인해 보세요. / 안에서 열리지 않는 상태라면 영업 중에 손님이 갇힐 수 있어 위험합니다.
오픈 이후에도 문이 말썽을 부릴 때를 대비해 연락처를 계산대 근처에 붙여 두세요.

# 열린 뒤에는 바로 점검하세요
문이 열리면 도어락과 자물쇠가 정상으로 작동하는지 몇 번 열고 닫아 확인합니다. / 오픈 전에 다시 잠겨 곤란해지지 않게 하기 위해서입니다.
원인이 열쇠 마모라면 새 열쇠를 만들거나 실린더 교체를 이야기합니다. / 필요하면 [도어락 수리](doorlock-repair.html)를 먼저 봅니다.
번호를 바꿀 때는 직원 중 누가 알아야 하는지 정리하고, 퇴사자가 있으면 번호도 함께 바꾸세요.

가게는 퇴근 때마다 사람이 바뀔 수 있어 열쇠나 번호 인수인계 기록을 남겨 두는 것이 좋습니다. / 누가 열쇠를 가졌는지 한눈에 알아볼 수 있으면 사고가 줄어듭니다.
정기적으로 자물쇠에 이상이 없는지 가볍게 점검하는 것도 좋은 습관입니다.

# 같은 일을 줄이는 오픈 전 습관
오픈 30분 전에 미리 도착해 문을 열어 보는 것만으로도 여유가 생깁니다. / 안 열려도 대처할 시간이 있기 때문입니다.
- 도어락 배터리를 정해진 날짜에 교체하기
- 여분 열쇠를 안전한 곳에 하나 두기
- 비상 연락처를 매장 안과 휴대폰에 저장하기
- 마감 시 잠금 방식을 직원끼리 통일하기
장기적으로 문이 자주 말썽이면 [도어락 교체](doorlock-replace.html)를 상담해 보셔도 됩니다.

# 금정동 말고 군포 어디든 갑니다
금정동 가까운 산본동, 당동, 당정동, 부곡동, 오금동, 대야미동도 다닙니다. / 군포 안이면 24시간 출동하니 이른 아침 오픈도 걱정 없이 연락 주세요.
다니는 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
