# 금정동 문 아래에서 끽끽 소리가 난다면
금정동은 금정역을 중심으로 출퇴근하시는 분이 많은 군포의 생활권입니다. / 하루에도 몇 번씩 여닫는 현관문이라 작은 불편이 오래 쌓입니다.
문을 열고 닫을 때 아래쪽이 바닥에 끽 하고 쓸린다면 문이 조금 처졌다는 신호입니다. / 그냥 두면 도어락이 맞지 않아 어느 날 문이 안 열리는 일로 이어지기도 합니다.
이 글은 문 아래가 쓸리는 증상의 원인과 집에서 보는 순서, 그리고 부를 때를 정리했습니다.

# 문이 쓸리는 건 보통 경첩에서 시작됩니다
문은 위쪽과 아래쪽 경첩에 매달려 있습니다. / 오래 쓰면 위쪽 경첩이 느슨해지면서 문 전체가 앞쪽으로 기울어집니다.
기울면 문 반대쪽 아래 모서리가 바닥에 닿고 걸쇠 위치도 문틀과 어긋납니다. / 소리가 나는 쪽이 어디인지가 원인 찾기의 첫 단서입니다.
소리는 열 때보다 닫을 때 더 크게 나는 경우가 많습니다. / 천천히 열고 닫으며 소리가 나는 지점을 귀로 찾아보세요.
문 자체의 무게 때문에도 생기고, 아이가 문에 매달리거나 세게 닫는 일이 쌓여도 생깁니다.
계절이 바뀔 때 특히 심해진다면 습기로 문이 부풀었다가 마르는 과정에서 틈이 달라지는 것일 수 있습니다. / 이 경우는 날씨가 좋아지면 증상이 줄기도 합니다.
반대로 날씨와 상관없이 점점 심해진다면 경첩이나 문틀이 원인일 가능성이 높습니다.
@ 금정동 현관문 아래 바닥 쓸림 경첩 처짐

# 쓸리는 곳이 어디인지 먼저 확인
문을 열고 닫으며 어느 부분이 닿는지 손가락 두 마디 정도 거리에서 살펴보세요. / 닫을 때 문 아래 모서리가 바닥에 스치는지, 문틀 모서리에 스치는지도 봅니다.
- 바닥 쪽 손잡이 반대편 아래가 닿는다: 위쪽 경첩 처짐 가능성
- 문틀 위쪽 모서리에 닿는다: 아래 경첩 문제나 문틀 변형
- 문 전체가 뻑뻑하다: 계절 습기로 문이 부풀었을 가능성
닿는 자국이 바닥에 생겼다면 사진으로 남겨 두세요.

# 위아래 틈으로 처짐 정도를 가늠
문을 닫았을 때 위쪽 틈과 아래쪽 틈이 같은지 봅니다. / 한쪽이 확연히 좁다면 그쪽으로 문이 쏠린 것입니다.
옆 틈도 보세요. / 손잡이 쪽 틈이 위는 넓고 아래는 좁으면 문이 비스듬히 매달린 상태입니다.
종이 한 장을 틈에 넣어 보면 어디가 빡빡한지 대략 알 수 있습니다. / 눈으로 안 보이는 차이도 이렇게 확인됩니다.
바닥에 문턱이나 매트가 있다면 그것 때문에 쓸리는 것일 수도 있습니다. / 매트를 치우고 다시 여닫아 보면 원인이 가려집니다.
@ 금정동 문 아래 모서리 바닥 닿는 부분 확인

# 직접 해볼 수 있는 간단한 조치
경첩의 나사가 헐거워져 있다면 맞는 드라이버로 가볍게 조여 보세요. / 문을 반쯤 연 상태에서 한 군데씩 순서대로 조입니다.
나사 구멍이 닳아 계속 헛돌면 더 세게 돌리지 마세요. / 구멍이 넓어진 상태라 조여도 곧 풀립니다.
틈이나 소리가 달라졌는지 문을 몇 번 여닫으며 확인합니다. / 개선이 없으면 혼자 오래 붙잡지 않는 게 낫습니다.
[도어락 설치](doorlock-install.html) 때 문 두께와 걸쇠 위치를 같이 맞추는 이유도 이런 처짐 때문입니다. / 새 도어락을 달기 전에 문이 제 위치에 있는지 먼저 보면 설치 후 문제가 줄어듭니다.

# 이렇게 하면 오히려 악화됩니다
문 아래 모서리를 칼이나 사포로 깎아내는 분들이 있습니다. / 처짐의 원인은 그대로 둔 채 문만 깎으면 틈이 커져 바람이 들어오고 방범에도 좋지 않습니다.
경첩 나사를 무리하게 세게 조여 나사산이 뭉개지면 고치기가 더 어려워집니다.
문이 쓸린 채로 계속 쓰면 경첩 쪽에 더 큰 무게가 걸려 처짐이 빨라집니다. / 가능하면 증상이 보일 때 바로 한 번 점검해 주세요.
문이 닫힐 때 걸쇠가 문틀 구멍에 잘 안 들어가는데도 억지로 세게 닫으면 도어락이 상합니다.
@ 금정동 문 높이 틈 점검 경첩 나사 확인

# 도어락과 걸쇠 위치가 어긋나는 문제
문이 처지면 걸쇠가 문틀의 받침 구멍과 맞지 않게 됩니다. / 그러면 번호를 눌러 잠금이 풀려도 문이 꽉 물려 열리지 않는 일이 생깁니다.
이런 증상이 생기면 문을 안쪽으로 살짝 밀며 손잡이를 돌려 보세요. / 그렇게 열리는 집은 이미 처짐이 어느 정도 진행된 상태입니다.
[도어락 수리](doorlock-repair.html)가 필요한지, 경첩 조정만으로 충분한지는 보고 판단합니다.

# 문이 쓸리다 안 열릴 때
어느 날 아침 문이 바닥에 걸려 열리지 않을 수도 있습니다. / 이럴 때는 손잡이를 세게 당기기보다 문을 살짝 들어 올리듯이 밀어 보세요.
번호판이 꺼진 문제와는 증상이 다릅니다. / 번호는 맞는데 열리지 않는다면 걸쇠가 문틀에 물린 것입니다.
그래도 안 되면 드라이버로 틈을 벌리지 마시고 [현관문 개문](door-open.html) 안내를 보고 전화 주세요.

# 전화로 알려 주면 좋은 정보
처짐 증상은 사진 한두 장이 말 열 마디보다 낫습니다.
- 문을 닫은 상태에서 위, 아래 틈이 보이게 찍은 사진
- 바닥에 쓸린 자국이 있는 곳
- 소리가 나는 때(열 때, 닫을 때)
- 도어락 모양과 번호판 상태
- 대략 금정역 쪽인지 군포역 쪽인지 같은 위치
증상이 시작된 시점도 말씀해 주시면 원인을 좁히기 좋습니다.

# 고치는 순서는 이렇게 진행합니다
먼저 문이 어디까지 처졌는지 보고 경첩 상태를 확인합니다. / 나사 조정으로 되는지, 경첩 자체가 닳았는지 구분합니다.
도어락이 문과 어긋나 있으면 걸쇠 위치도 같이 맞춥니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.
경첩을 새로 달아야 하는 경우도 있습니다. / 이때는 같은 규격인지 확인하고 나사 위치가 기존 구멍과 맞는지 살펴 진행합니다.
고친 뒤에는 문을 열고 닫으며 틈과 소리를 함께 확인합니다. / 바닥에 쓸린 자국이 더 이상 늘지 않는지 며칠 지켜보는 것도 좋습니다.
문 자체를 깎는 방법은 최후에만 생각합니다.

# 오는 길에 사시는 분인지 확인
문을 여는 일이라 먼저 사시는 분이 맞는지 봅니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 가운데 하나면 됩니다.
번거로우실 수 있지만 모두를 위한 절차입니다. / 확인이 어려우면 작업이 어려울 수 있으니 미리 준비해 주세요.

# 비용은 시작 전에 먼저 말씀드립니다
문 상태를 보고 얼마인지 먼저 안내합니다. / 괜찮다고 하시면 시작하고 아니면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭙니다.
진행 방식은 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 금정동 말고 군포 어디든 갑니다
금정동 옆 산본동, 당정동, 당동, 부곡동 등 군포 안 어디든 다닙니다. / 금정역, 산본역, 군포역, 대야미역 쪽도 24시간 전화를 받습니다.
[군포시 출장열쇠](gunpo.html) 페이지에서 동네를 확인하세요.
