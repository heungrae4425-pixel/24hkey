# 금정동 상가 출입문이 버튼을 눌러도 안 열릴 때
금정동은 금정역을 중심으로 환승객이 오가는 상가와 사무실이 모여 있는 생활권입니다. / 이런 건물에는 안에서 버튼을 누르거나 비밀번호를 누르면 문이 풀리는 전기 걸쇠 출입문이 흔합니다.
어느 날 버튼을 눌러도 '딸깍' 소리만 나고 문이 안 열리면 출근하는 사람들이 모두 밖에 서게 됩니다. / 이 글은 전기 걸쇠 문이 안 풀릴 때 확인할 순서와 하지 말아야 할 것을 정리했습니다.
@ 금정동 전기 걸쇠 출입문 점검

# 전기 걸쇠가 무엇인지부터 알아 둡니다
흔히 전기정이라고 부르는 장치는 문틀에 달린 작은 걸쇠를 전기 신호로 풀어 주는 방식입니다. / 도어락처럼 문짝이 움직이는 것이 아니라 문틀 쪽의 받침이 풀리는 구조입니다.
출입 버튼이나 인터폰, 비밀번호 키패드, 카드 리더와 연결되어 있습니다. / 그래서 이 중 어디가 문제인지에 따라 고치는 방법이 다릅니다.
구조를 알면 전화로 설명하기도 쉽고, 어떤 점검이 필요한지 판단하는 데 도움이 됩니다.

# 소리가 나는지 먼저 들어 보세요
버튼을 눌렀을 때 문틀 쪽에서 '찰칵' 소리가 나는지 확인하세요. / 소리가 난다면 전기는 들어가고 있다는 뜻이고, 걸쇠가 물리적으로 걸려 있을 수 있습니다.
소리가 전혀 안 나면 전원이나 배선, 버튼 쪽을 의심해야 합니다. / 이 구분만 되어도 원인의 절반은 좁혀집니다.
- 소리가 나는데 문이 안 열림: 문이 걸쇠를 누르는 경우
- 소리가 아예 없음: 전원이나 신호 쪽 문제
- 약하게 소리가 나다 말다 함: 접촉 불량 가능성

# 문이 걸쇠를 누르고 있는 경우
버튼을 누르는 순간 문을 안쪽으로 살짝 밀어 주면 열리는 경우가 있습니다. / 문이 문틀 쪽으로 눌려 있으면 걸쇠가 풀려도 빠지지 않기 때문입니다.
문이 처지거나 경첩이 느슨해져 있으면 이런 현상이 자주 생깁니다. / 한 번 풀릴 때만 밀어 주고 넘어가지 말고, 반복되면 경첩 점검도 같이 해야 합니다.
반대로 당기는 문이라면 버튼을 누르는 동시에 문을 당겨 보세요.

# 전원 공급이 끊겼을 때
전기 걸쇠는 대부분 별도의 전원 장치에서 전기를 받습니다. / 정전이 났거나 전원 장치가 꺼졌다면 평소 작동하던 문이 갑자기 멈춥니다.
어떤 방식은 전원이 없으면 잠기고, 어떤 방식은 전원이 없으면 열리는 구조라서 건물마다 다릅니다. / 같은 층의 다른 전기 기구가 작동하는지 먼저 확인해 보세요.
분전반을 함부로 만지지는 말고, 건물 관리하시는 분께 먼저 확인을 부탁드리는 게 좋습니다.

# 버튼이나 키패드가 문제일 때
출입 버튼이 눌리다 말다 하면 버튼 안쪽의 접점이 닳은 경우가 많습니다. / 비밀번호 키패드가 반응이 없으면 배터리나 연결 상태를 봐야 합니다.
- 버튼을 여러 번 눌러도 반응 없음
- 키패드 불은 켜지는데 문이 안 풀림
- 카드를 대도 경고음만 반복됨
이런 경우에는 걸쇠 자체보다 앞단의 장치가 원인일 때가 많습니다. / 현장에서 순서대로 짚으며 어느 부분이 문제인지 확인합니다.
@ 금정동 사무실 출입문 키패드 버튼

# 하지 말아야 할 것
문이 안 열린다고 문짝을 세게 당기거나 어깨로 밀면 걸쇠 받침이 휘어질 수 있습니다. / 문틀이 상하면 작은 문제가 큰 수리로 커집니다.
공구로 문틈을 벌리거나 걸쇠 부분을 두드리는 것도 피해 주세요. / 외관이 상하면 나중에 건물 관리 쪽에도 설명할 일이 생깁니다.
전선이 보인다고 해서 직접 뽑거나 이어 붙이지 마세요. / 감전이나 다른 장치 고장의 원인이 됩니다.

# 안쪽에 사람이 있거나 급한 상황일 때
문이 안 열리는데 안쪽에 사람이 있다면 먼저 말씀해 주세요. / 어린이나 고령자가 있는 경우는 더 서두르게 됩니다.
다른 출입구나 비상구가 있다면 그쪽 이용을 먼저 생각해 보세요. / 안쪽에서 수동으로 풀 수 있는 손잡이가 있는 문도 있습니다.
급하신 경우는 전화로 위치와 상황을 짧게 말씀해 주시면 됩니다.

# 위치를 알려주실 때 도움이 되는 정보
금정동은 역 주변에 건물이 많아서 정확한 위치 설명이 필요합니다. / 건물 이름 대신 도로 방향과 눈에 띄는 가게로 알려주셔도 됩니다.
- 금정역에서 어느 쪽 출구 방향인지
- 문이 있는 층과 출입문 모양
- 버튼이나 키패드가 있는지
- 문틀 쪽에 보이는 장치 사진
사진을 문자로 보내주시면 필요한 부품을 챙겨 가기 좋습니다. / 건물 관리자 연락처를 알려주시면 확인이 빨라지기도 합니다.

# 도착하면 먼저 사용하시는 분인지 확인합니다
사무실이나 상가는 사용자 확인이 더 중요합니다. / 신분증, 사업장 주소가 나온 우편물이나 계약서, 건물 관리하시는 분의 확인 중 하나면 됩니다.
번거로우셔도 다른 사람의 공간을 함부로 열지 않기 위한 절차입니다. / 확인이 어려우면 작업할 수 없으니 미리 준비해 두세요.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 장치 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우엔 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 금정동 출입문 걸쇠 수리 작업

문이 열리고 나면 걸쇠가 매끄럽게 풀리고 다시 물리는지 몇 번 확인합니다. / 문틀과 문짝의 높이가 맞는지도 같이 봅니다.
수리로 해결되는 경우가 많으니 [도어락 수리](doorlock-repair.html)를 먼저 권하고, 부품이 너무 낡았다면 교체를 말씀드립니다. / 교체가 필요하면 [도어락 교체](doorlock-replace.html) 페이지를 참고해 주세요.
문 여는 일 자체는 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 오래 잘 쓰는 관리 요령
- 출입 버튼을 세게 누르거나 오래 누르지 않기
- 문틀 쪽 걸쇠 주위에 먼지가 끼면 닦아 주기
- 문이 처지면 경첩 나사를 조여 두기
- 정전 뒤에는 문이 정상 작동하는지 확인
- 키패드 배터리를 정해진 시기에 교체
문이 닫힐 때 걸쇠에 정확히 물리는지도 가끔 봐주세요. / 닫히는 소리가 이상하면 이미 어긋나기 시작한 신호입니다.

전기 걸쇠 문은 여러 사람이 하루에도 수십 번 쓰기 때문에 부품이 닳는 속도가 집 현관과 다릅니다. / 같은 문제가 반복된다면 임시로 넘기지 말고 원인이 되는 부분을 한 번에 정리하는 편이 낫습니다.
문제가 생기기 전에 출입 시간대와 쓰는 사람 수를 떠올려 보면 어느 부품이 먼저 닳을지 짐작하기 쉽습니다.

# 금정동 말고 군포 어디든 갑니다
금정동 가까운 산본동, 당정동, 당동, 부곡동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에 있습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
