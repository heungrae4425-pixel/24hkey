# 새해 첫 주에 해볼 만한 작은 일
금정역에서 집으로 돌아오는 길, 연말이나 연초가 되면 집 안 점검거리가 하나둘 떠오릅니다. / 보일러, 소화기, 비상 연락처와 함께 도어락도 한 번 들여다보면 좋습니다.
도어락은 평소에 잘 돌아가다가 어느 날 갑자기 멈추는 물건이어서 정해진 날에 점검하는 습관이 필요합니다. / 이 글은 연초나 분기마다 어렵지 않게 할 수 있는 도어락 점검 루틴을 정리했습니다.
점검하다 문제를 발견하면 [군포 출장열쇠](gunpo.html)로 연락하세요.
@ 금정동 도어락 연초 점검 배터리 교체

# 왜 날짜를 정해야 하나
도어락은 배터리가 줄어도 한동안 티가 나지 않다가 갑자기 꺼집니다. / 그래서 느낌이 아니라 날짜로 챙기는 것이 안전합니다.
달력이나 휴대폰 알림에 연 4회 정도 점검일을 정해 두세요. / 이사한 날이나 새해 첫 주처럼 기억하기 쉬운 날이 좋습니다.
한 번 점검하는 데 10분이면 충분합니다. / 점검은 문을 열어 둔 채로, 가족이 집에 있을 때 하는 것이 안전합니다.
점검일에는 새 건전지와 마른 천, 작은 드라이버를 미리 한곳에 모아 두세요. / 준비물이 흩어져 있으면 그날 점검을 미루게 됩니다.
점검 순서를 정해 두면 빠뜨리는 일이 줄어듭니다.

순서를 정해 두면 빠뜨리는 일이 줄어듭니다.
- 먼저 번호판 반응과 소리 확인
- 배터리 교체 시기 판단
- 문이 닫히고 잠기는 소리 듣기
- 보조키와 열쇠 구멍 점검
- 등록된 번호와 카드 정리
이 순서대로 하면 처음부터 끝까지 한 번에 훑어볼 수 있습니다.

# 번호판 반응부터 봅니다
문을 열어 둔 채 번호판에 손을 가져다 대 보세요. / 불이 들어오는 속도와 밝기가 평소와 비슷한지 봅니다. / 불이 늦게 켜지거나 어두워졌다면 배터리가 약해졌다는 첫 번째 신호입니다.
숫자를 눌렀을 때 소리가 나는지, 눌러도 반응이 둔한 숫자는 없는지 확인합니다. / 특정 숫자만 반응이 없다면 부품이 닳은 것일 수 있습니다.
습기나 먼지가 번호판 틈에 있다면 마른 천으로 가볍게 닦아 주세요. / 물을 직접 뿌리지 마세요.

# 배터리는 연말에 한꺼번에
배터리가 아직 남았더라도 연초에 전부 새로 갈아 두면 마음이 편합니다. / 일부만 바꾸면 새것이 오래된 것에 끌려 빨리 닳습니다.
건전지는 같은 상표와 같은 시기에 산 것으로 맞춰 쓰세요. / 도어락 전용으로 정한 건전지를 따로 사 두는 것도 방법입니다.
교체한 날짜를 도어락 안쪽 덮개에 작게 적어 두세요. / 다음 점검 때 기억을 더듬지 않아도 됩니다. / 안쪽 덮개를 열 때는 부품을 잃어버리지 않게 작은 접시나 통에 담아 두세요.
건전지 방향을 반대로 끼우면 작동하지 않으니 극 표시를 확인하며 끼우세요.
@ 금정동 도어락 건전지 전체 교체

# 경고음은 미루지 마세요
배터리가 약해지면 문을 열 때마다 경고음이 울립니다. / 소리가 몇 번 들렸다면 그날 바로 교체해 주세요.
미루면 어느 아침 갑자기 번호판이 꺼진 채로 문 앞에서 막힙니다. / 특히 출근 전 바쁜 시간대에 꺼지면 더 난감합니다.
점검일이 아니어도 경고음은 점검 신호입니다. / 비상용 9V 건전지를 가방이나 차에 넣어 두면 번호판이 꺼진 날에도 임시로 열 수 있습니다.

# 문이 닫히는 소리를 들어 보세요
문을 열고 닫으면서 소리를 귀담아들어 보세요. / 평소와 달리 쿵 하고 걸리거나 끼익 소리가 난다면 경첩이나 문틀에 변화가 생긴 것입니다.
문이 끝까지 닫히지 않으면 도어락이 정상이어도 잠기지 않습니다. / 이런 문제는 [도어락 수리](doorlock-repair.html)로 문 쪽까지 같이 점검받는 것이 좋습니다.
경첩 나사가 헐거워져 있다면 드라이버로 살짝 조여 주기만 해도 좋아집니다. / 너무 세게 조이면 나사산이 망가지니 조심하세요.

보조키와 열쇠 구멍도 한 번씩 보세요. / 평소 거의 쓰지 않는 열쇠 구멍은 먼지가 쌓이거나 굳어 있기 쉽습니다. / 연 1회 정도 열쇠를 꽂아 돌려 보며 매끄러운지 확인하세요.
뻑뻑하다면 열쇠 구멍 전용 윤활제를 소량 쓰는 방법이 있습니다. / 일반 기름은 먼지를 끌어당겨 오히려 막힐 수 있습니다.
여분 열쇠가 어디 있는지도 이때 확인하세요. / 위치를 모르면 필요한 날 찾느라 시간을 씁니다.

# 등록된 번호와 카드 정리
오래 쓰다 보면 더 이상 쓰지 않는 번호와 카드가 남아 있습니다. / 이사 간 가족, 예전 도우미, 잃어버린 카드가 대표적입니다.
쓰지 않는 번호는 연초에 한꺼번에 지우세요. / 새로 정한 번호는 가족에게 바로 알립니다.
번호를 바꾸는 김에 추측하기 쉬운 숫자가 아닌지도 점검해 보세요. / 생일이나 전화번호 뒷자리는 피하는 편이 좋습니다.

# 점검하다 문제를 발견했다면
점검 중에 번호가 안 먹히거나 문이 걸리는 일이 생길 수 있습니다. / 이때 당황해서 설정을 마구 바꾸지 마세요.
문이 열려 있는 상태에서 점검하는 중이라면 그 자리에서 다시 확인해 보는 것이 안전합니다. / 문이 닫힌 채 안 열리면 억지로 힘을 쓰지 말고 연락 주세요.
문을 상하게 하지 않고 여는 방식은 [현관문 개문](door-open.html)에 설명해 두었습니다.

# 문이 안 열리면 사시는 분 확인부터
도움을 요청하면 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
점검일에 맞춰 신분증과 우편물 한 장을 눈에 띄는 곳에 챙겨 두는 것도 좋은 습관입니다. / 필요한 순간에 시간을 아낄 수 있습니다. / 관리사무소 연락처도 같이 저장해 두면 신분 확인이 필요한 날 빠르게 대응할 수 있습니다.

# 비용은 열기 전에, 못 열면 받지 않습니다
도어락과 문 상태를 본 뒤 먼저 비용을 말씀드립니다. / 괜찮으시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품이 필요하면 바꾸기 전에 반드시 여쭙니다.
진행 방식은 [이용안내](guide.html)에 정리했습니다.
@ 금정동 출장열쇠 도어락 점검 수리

# 점검 결과로 교체를 고민할 때
점검해 보니 반응이 계속 둔하거나 경고음이 자주 울린다면 도어락 수명이 다 된 신호일 수 있습니다. / 수리로 충분한지 교체가 나은지는 상태를 본 뒤에 말씀드립니다.
고쳐서 쓸 수 있으면 교체를 권하지 않습니다. / 교체가 필요하다면 [도어락 교체](doorlock-replace.html)에서 확인할 점을 먼저 보세요.
교체 전에는 문 두께와 보조키를 확인합니다.

# 한눈에 보는 분기별 점검표
분기마다 같은 표로 점검하면 기억이 쉬워집니다.
- 1월 초: 배터리 전체 교체, 번호와 카드 정리
- 4월 초: 번호판 청소, 경첩 나사 확인
- 7월 초: 장마 전 습기 점검, 번호판 물기 닦기
- 10월 초: 겨울 대비 배터리 상태 확인, 열쇠 구멍 윤활
일정이 맞지 않으면 집에 맞게 바꿔도 됩니다. / 중요한 건 정해진 날에 반복하는 것입니다.
