# 금정동 원룸에서 문이 잠겼을 때
금정동은 금정역을 중심으로 원룸, 오피스텔, 빌라가 촘촘하게 모여 있는 동네입니다. / 혼자 사시는 분이 많다 보니 문이 잠기면 안에서 열어줄 사람이 없어 더 막막합니다.
편의점에 잠깐 다녀오다 문이 닫혔거나, 퇴근하고 왔는데 번호판이 반응하지 않는 일이 흔합니다. / 이 글은 금정동 원룸과 오피스텔에서 문이 안 열릴 때 순서대로 해볼 것을 정리했습니다.
급하시면 3번 항목부터 보시고 바로 전화 주셔도 됩니다. / 위치만 알려주시면 [군포 출장열쇠](gunpo.html)가 출동 가능한지 먼저 말씀드립니다.
@ 금정동 원룸 오피스텔 출입문 개문

# 금정역 주변 건물은 구조가 다양합니다
금정역 쪽은 오래된 빌라와 새로 올라간 오피스텔이 한 골목에 섞여 있습니다. / 같은 동네라도 건물마다 도어락 종류와 문 두께가 제각각입니다.
오래된 원룸은 열쇠 구멍이 있는 문에 도어락을 나중에 덧단 경우가 많습니다. / 오피스텔은 처음부터 디지털 도어락이 달려 있고 비상 열쇠가 따로 없는 모델도 있습니다.
어느 쪽인지 알려주시면 출발 전에 챙길 장비를 정할 수 있습니다.

# 건물 공동현관과 내 방 문은 다릅니다
건물 입구 공동현관이 안 열리는 것과 내 방 문이 안 열리는 것은 해결 방법이 전혀 다릅니다. / 공동현관은 건물 관리 주체의 허락이 있어야 열 수 있는 경우가 많습니다.
내 방 문이라면 사시는 분 확인만 되면 바로 작업할 수 있습니다. / 전화하실 때 어느 문 앞인지 먼저 말씀해 주세요.

# 전화 전에 관리실이나 집주인부터
관리실이 있는 건물이면 마스터키나 예비 키를 보관하는 곳이 있을 수 있습니다. / 집주인과 연락이 닿는다면 예비 열쇠가 있는지 한 번 물어보는 것도 방법입니다.
다만 늦은 밤이라 연락이 안 되면 기다리지 마시고 바로 전화 주세요. / 24시간 받습니다.
- 관리실 불이 켜져 있는지, 연락처가 붙어 있는지
- 집주인이나 중개한 곳에 예비 열쇠가 있는지
- 휴대폰 충전이 얼마나 남았는지
- 문 앞에서 기다릴 수 있는 안전한 곳이 있는지

# 원룸 도어락에서 자주 생기는 일
원룸은 문을 하루에도 여러 번 여닫다 보니 도어락 소모가 빠릅니다. / 배터리 경고음을 못 듣고 지나쳤다가 어느 날 번호판이 꺼지는 일이 가장 많습니다.
문틀과 문이 어긋나 걸쇠가 문틀에 걸리는 경우도 있습니다. / 번호는 맞게 눌렀는데 모터 소리만 나고 안 열린다면 이쪽을 의심해 볼 수 있습니다.
택배함이나 현관 앞에 비밀번호를 적어 두는 분도 있는데, 번호가 노출되면 오히려 위험하니 피하시는 게 좋습니다.

# 오피스텔 방문 앞에서 막혔을 때
오피스텔은 카드키, 지문, 번호를 함께 쓰는 복합 도어락이 많습니다. / 카드키를 잃었는데 번호도 기억나지 않는다면 먼저 사시는 분 확인부터 진행합니다.
스마트 도어락은 앱 연동이 걸려 있기도 합니다. / 앱으로 열 수 있는지 한 번 확인해 보시고, 안 되면 전화 주세요.
무리하게 문틈을 벌리거나 카드를 끼워 넣으면 문틀이 상할 수 있어 권하지 않습니다.
@ 금정역 오피스텔 도어락 카드키 번호

# 전화로 이 정도만 알려주세요
정확하게 알려주실수록 도착이 빨라지고 준비할 장비도 정확해집니다.
- 건물 이름 대신 도로명이나 금정역에서 어느 쪽인지
- 몇 층 몇 호인지, 공동현관은 열려 있는지
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 도어락 모양(손잡이형, 푸시풀형, 카드키형)
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙기기 좋습니다.

# 세입자도 열 수 있습니다
세입자시라고 집주인 허락이 꼭 필요한 것은 아닙니다. / 지금 그 집에 사시는 분이라는 것만 확인되면 됩니다.
신분증 주소, 주소가 찍힌 우편물, 계약서 같은 것 중 하나면 충분합니다. / 신분증이 방 안에 있다면 휴대폰에 저장된 계약서나 공과금 문자도 도움이 됩니다.
확인이 어려우면 작업할 수 없으니 미리 챙겨 주세요. / 이웃과 건물 전체를 위한 절차입니다.

# 비용은 문을 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭙니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문은 최대한 안 상하게 엽니다
원룸이나 오피스텔은 나중에 퇴실할 때 문 상태를 확인받는 경우가 많습니다. / 그래서 도어락과 문틀에 흠이 나지 않게 여는 방법부터 차례로 시도합니다.
어떤 방법이 맞을지는 도어락 종류에 따라 달라집니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 말씀드립니다.
방법은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.
@ 금정동 문 열기 출장열쇠 작업

# 열고 난 뒤에는 이렇게 점검합니다
문이 열리면 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새것으로 모두 바꿨는지도 봅니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 자주 고장 나는 제품이면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드리고, 너무 낡았으면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
방 안쪽에서 비밀번호를 새로 등록하는 것까지 도와드립니다.

# 계약 만기나 퇴실 때 도어락도 챙기세요
전 세입자가 쓰던 번호가 그대로 남아 있지 않은지 이사 온 날 바로 확인하는 것이 좋습니다. / 이사 나가실 때는 등록한 번호와 카드를 모두 지우고 나가야 뒷말이 없습니다.
도어락을 직접 달았다면 퇴실 때 원래 상태로 되돌려야 하는지 계약서를 확인해 보세요. / 이런 부분은 집주인과 미리 이야기해 두면 편합니다.

# 금정동 말고 군포 어디든 갑니다
금정동 바로 옆 산본동, 당정동, 당동, 부곡동, 오금동, 대야미동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
군포에서 다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
