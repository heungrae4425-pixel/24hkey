# 금정동 집, 비밀번호는 누가 알고 있나요
금정동은 금정역 인근 아파트와 빌라에서 가족, 세입자, 가끔 오는 손님까지 같은 현관문을 드나드는 집이 많습니다. / 도어락 번호는 한 번 정해 두고 오래 쓰기 쉬워서 누가 알고 있는지 점점 모호해집니다.
이 글은 도어락 번호를 어떻게 정하고, 누구와 공유하고, 언제 바꾸면 좋은지를 정리했습니다. / 번호를 잊었을 때 어떻게 해야 하는지도 마지막에 적었습니다.
[군포 출장열쇠](gunpo.html)가 현장에서 자주 받는 질문을 기준으로 썼습니다.
@ 금정동 도어락 비밀번호 관리

# 좋은 번호의 조건
생일, 전화번호 뒷자리, 1234 같은 번호는 피하세요. / 이런 번호는 누구나 쉽게 짐작할 수 있어 오래 쓰기에 좋지 않습니다.
기억하기 쉬우면서 남이 짐작하기 어려운 조합이 좋습니다. / 도어락이 지원하는 자릿수 안에서 가능한 한 길게 정하세요.
번호판에 손자국이 남아 자주 누르는 숫자가 드러날 수 있으니 가끔 닦아 주세요.

# 가족과 공유할 때
같은 집에 사는 가족끼리는 번호를 똑같이 쓰는 경우가 대부분입니다. / 누군가 번호를 바꾸면 반드시 가족 모두에게 알려야 합니다.
아이가 있는 집은 번호를 종이에 적어 가방에 넣어 두는 일이 있는데, 그러면 잃어버렸을 때 위험합니다. / 번호는 머릿속에 두고, 카드키는 따로 하나를 챙겨 두세요.
번호를 바꾼 날짜를 가족 대화방에 남겨 두면 헷갈릴 일이 줄어듭니다.

# 가끔 오는 손님에게는 임시 번호
도어락에 임시 번호나 일회용 번호 기능이 있으면 그것을 쓰세요. / 청소하러 오는 분이나 수리 기사님에게 원래 번호를 알려주면 이후에도 계속 열 수 있게 됩니다.
임시 번호 기능이 없다면 방문이 끝난 뒤 번호를 바꾸는 것이 좋습니다. / 번거로워도 한 번 해 두면 마음이 편합니다.
@ 금정동 도어락 임시 번호 가족 공유

# 번호를 언제 바꿔야 할까
번호를 반드시 바꿔야 하는 순간이 있습니다.
- 이사 와서 전 입주자 번호가 남아 있을 때
- 세입자가 바뀌었을 때
- 번호를 아는 사람이 더는 같이 살지 않을 때
- 번호가 노출됐다고 느낄 때
- 도어락을 처음 설치한 직후
이 다섯 가지에 해당하면 바로 바꾸세요.

# 주기적으로 바꾸는 기준
정해진 규칙은 없지만 일 년에 한두 번 바꾸는 정도가 부담 없고 안전합니다. / 배터리를 갈 때 같이 바꾸면 기억하기 쉽습니다.
너무 자주 바꾸면 오히려 가족이 헷갈려 문 앞에서 막히는 일이 생깁니다. / 바꿀 때는 가족 모두에게 알린 뒤에 바꾸세요.

# 번호를 잊었을 때 먼저 해볼 것
번호를 잊거나 가족이 바꾼 걸 모를 때는 우선 가족에게 물어보세요. / 이전에 쓰던 번호를 두세 번 눌러 보되 많이 틀리면 도어락이 잠시 막힙니다.
카드키나 지문이 등록돼 있다면 그것으로 열어 보세요. / 이런 방법이 모두 안 통하면 전화 주세요.

# 번호를 모를 때 문을 여는 순서
사시는 분 확인이 먼저입니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 되면 도어락과 문 상태를 보고 덜 상하는 방법부터 시도합니다. / 열린 뒤에는 새 번호를 등록하고 기존 번호는 지웁니다.
비용은 문을 열기 전에 먼저 말씀드리고, 못 열면 비용은 받지 않습니다.
@ 금정동 비밀번호 분실 문 열기

# 열고 난 뒤 새 번호 정하기
문이 열리면 안쪽에서 새 번호를 같이 등록합니다. / 이때 가족 모두가 함께 있다면 한 번씩 눌러 보게 하는 것이 좋습니다.
기존 번호가 도어락에 남지 않도록 지우는 것까지 확인합니다. / 방법은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.
비밀번호를 정했다면 어디에도 기록해 두지 마시고 머릿속에 두세요.

# 번호 말고 다른 방법도 함께 쓰기
번호만 쓰다 보면 잊었을 때 막막합니다. / 카드키나 지문이 지원되는 도어락이라면 두 가지 이상을 등록해 두세요.
열쇠로 여는 보조키가 있는 문이면 예비 열쇠를 믿을 수 있는 곳에 따로 보관하세요. / 한 가지 방법이 막혀도 다른 방법으로 열 수 있어야 합니다.
이 정도만 해두면 문 앞에서 당황하는 일이 크게 줄어듭니다.

# 배터리 관리도 같이
번호를 잘 관리해도 배터리가 다 되면 열리지 않습니다. / 경고음이 나면 그날 바로 전부 새것으로 교체하세요.
해가 바뀔 때 한 번에 갈면 잊지 않습니다. / 배터리 칸에 교체한 날짜를 적어 두세요.
고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 금정동 말고 군포 어디든 갑니다
금정동 바로 옆 산본동, 당정동, 당동, 부곡동, 오금동, 대야미동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.
