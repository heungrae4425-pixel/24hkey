# 여름만 되면 문이 뻑뻑해지는 집
금정역 근처에서 더운 날 퇴근해 현관문을 열려는데 평소보다 뻑뻑하게 느껴질 때가 있습니다. / 어제까지 부드럽던 문이 갑자기 달라지니 당황스럽습니다.
계절 때문에 생기는 문제는 대개 다시 돌아오지만, 방치하면 도어락과 경첩에 부담이 쌓입니다. / 이 글은 금정동에서 여름 열기와 습기로 문이 말썽일 때 확인할 것을 정리했습니다.
혼자 해결이 어려울 때는 [군포 출장열쇠](gunpo.html)에 요청하시면 됩니다.
@ 금정동 여름 현관문 뻑뻑함 점검

# 더위와 습기가 문에 하는 일
나무와 철은 더위와 습기에 아주 조금씩 부풀고 늘어납니다. / 문짝이 문틀 쪽으로 붙으면 이전보다 마찰이 커져 뻑뻑해집니다.
장마 뒤 습기가 빠지지 않은 집에서는 문 아래쪽 모서리가 먼저 영향을 받는 경우가 많습니다.
도어락 안쪽은 습기에 약한 부품이 있어서 번호 반응이 느려지거나 걸쇠가 느리게 움직일 수 있습니다. / 열기가 심한 한낮에는 더 두드러집니다.

# 증상별로 보는 원인
무엇이 뻑뻑한지에 따라 원인이 갈립니다.
- 문을 닫을 때 문틀과 쓸리는 소리가 난다 → 문짝 부풂이나 경첩 처짐
- 열쇠가 잘 안 돌아간다 → 열쇠 구멍 안 먼지, 습기
- 번호를 눌러도 반응이 늦다 → 번호판 습기, 배터리 약화
- 손잡이를 돌려도 걸쇠가 느리게 빠진다 → 안쪽 부품 마찰
문이 뻑뻑한 정도를 하루 중 언제 가장 심한지 메모해 두면 원인을 좁히는 데 도움이 됩니다. / 증상이 두 가지 이상 같이 오면 한 곳이 아니라 문 전체가 영향을 받았을 가능성이 큽니다.

# 문틈에 종이를 끼워 보세요
문을 닫은 채 문틈에 종이를 끼워 위아래로 훑어 보세요. / 특정 위치에서만 빡빡하다면 그곳이 쓸리는 자리입니다.
문틀과 문짝 가장자리에 광택이 나는 자국이 있다면 오래 쓸린 부분입니다. / 이 자국의 위치를 기억해 두세요. / 휴대폰으로 가까이 찍어 두면 상담할 때 편합니다.
날이 서늘해지고 습기가 빠지면 저절로 풀리기도 합니다. / 그래도 계속되면 경첩이 원인일 수 있으니 점검이 필요합니다.
@ 군포 금정동 문틀 쓸림 확인

# 번호판이 열기에 약해지는 경우
직사광선이 바로 닿는 현관은 한낮에 번호판이 뜨거워집니다. / 이때 터치 반응이 둔해지거나 일시적으로 꺼질 수 있습니다.
문 앞을 그늘지게 하거나 시원한 때 다시 눌러 보면 돌아오는 경우가 많습니다. / 번호판을 물수건으로 닦는 것은 피하고 마른 천을 쓰세요. / 번호판 둘레 틈으로 물기가 스며들 수 있기 때문입니다. / 에어컨 바람을 직접 쐬게 하는 것도 결로를 만들어 피하는 편이 좋습니다.
번호판에 얼룩이 오래 가거나 숫자가 흐려지면 [도어락 수리](doorlock-repair.html) 점검을 받아 보시는 게 좋습니다.

# 열쇠가 잘 안 돌아갈 때 주의점
습기와 먼지가 섞이면 열쇠 구멍 안이 끈적해집니다. / 이 상태에서 힘으로 돌리면 열쇠가 휘거나 부러질 수 있습니다.
열쇠 머리가 손에 땀이나 물기로 미끄러워 힘이 잘 전달되지 않을 때도 있으니 손을 닦고 다시 시도해 보세요. / 부러진 열쇠가 안에 남으면 문을 여는 일이 훨씬 어려워집니다. / 평소와 다르다고 느끼면 힘을 주지 말고 멈추세요.
식용유나 아무 스프레이를 뿌리는 방법은 권하지 않습니다. / 먼지가 엉겨 상태를 더 나쁘게 만드는 경우가 있습니다.

# 문이 안 열릴 때 하면 안 되는 것
더운 날 마음이 급하면 어깨로 문을 밀거나 발로 차는 분이 있습니다. / 문이 휘거나 걸쇠가 문틀에 박히면 수리가 커집니다.
문틈에 카드를 넣거나 드라이버로 벌리는 것도 피해 주세요. / 문틀과 도어락 외관이 상하고 나중에 틈새 바람이 생깁니다.
번호를 여러 번 틀리면 도어락이 입력을 잠시 막습니다. / 서너 번 해보고 안 되면 멈추는 게 좋습니다.

# 전화로 알려주시면 좋은 정보
금정동 어느 쪽이고 금정역에서 가까운지 위치를 먼저 말씀해 주세요. / 이어서 아래 항목을 알려주시면 준비해서 갑니다.
- 문이 뻑뻑한지, 아예 안 열리는지
- 열쇠 구멍, 번호판, 손잡이 중 어디가 문제인지
- 장마나 더위가 심한 날 증상이 심해졌는지
- 도어락 사진과 문 모양
- 집 안에 아이나 반려동물이 있는지
더위 속에 사람이나 동물이 안에 있다면 꼭 먼저 말씀해 주세요. / 여름철 닫힌 집 안은 온도가 빠르게 오릅니다.

# 도착하면 신분 확인부터
문이 열리지 않는 집에 들어가는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있어도 관리사무소에서 세대 확인을 해주는 곳이 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두세요.
이 절차는 모든 분께 똑같이 적용합니다. / 세입자이시면 계약서나 임대인과의 문자도 참고가 됩니다. / 확인이 안 되면 작업할 수 없으니 미리 서류를 챙겨 주세요.

# 비용은 말씀드리고 시작합니다
상태를 보고 필요한 작업이 정해지면 문 열기 전에 비용을 먼저 말씀드립니다. / 동의하시면 시작하고, 아니시면 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 한다면 하기 전에 한 번 더 여쭙니다.
진행 방식은 [이용안내](guide.html)에서도 보실 수 있습니다.

# 문 상하지 않게 풀어 드립니다
뻑뻑한 문은 힘을 쓰기 쉽지만, 힘을 줄수록 문이 상합니다. / 문틀과 도어락을 덜 상하게 하는 방법부터 차례로 합니다.
문이 부풀어 쓸리는 경우에는 쓸리는 면의 상태를 보고 경첩 높이를 조정하는 방법도 말씀드립니다. / 열고 난 뒤 쓸리는 자리와 경첩, 걸쇠를 함께 살펴봅니다. / 열쇠 구멍 안쪽이 문제라면 [열쇠 출장](key-call.html)으로 속을 손봅니다.
자세한 개문 방식은 [현관문 개문](door-open.html) 페이지에 있습니다.
@ 금정동 출장열쇠 문 점검 작업

# 문제가 해결된 뒤 이렇게 관리하세요
- 장마철이나 덥고 습한 날 현관을 환기하기
- 번호판은 마른 천으로만 닦기
- 경첩 나사가 풀렸는지 가끔 만져 보기
- 열쇠 구멍에 먼지가 쌓이지 않게 주기적으로 열쇠 꽂아 돌려 보기
- 배터리는 계절이 바뀔 때 점검
도어락이 너무 낡아 매년 같은 증상이 나타난다면 [도어락 교체](doorlock-replace.html)도 상담할 수 있습니다.

늦가을이 되어도 낮에는 햇볕을 받는 쪽 현관은 한낮에 따뜻해집니다. / 아침저녁 기온 차가 크면 문이 줄었다 늘었다 합니다.
계절 변화가 문에 주는 영향은 눈에 잘 보이지 않지만 쌓입니다. / 건조한 가을이 되어도 햇볕이 드는 자리의 문은 한낮에 열을 받습니다. / 이상이 느껴지면 문이 완전히 말을 안 듣기 전에 연락 주시는 게 가볍게 끝납니다.

# 금정동 말고 군포 어디든 갑니다
금정동 가까이 산본동, 당동, 당정동, 부곡동, 대야미동, 오금동도 다닙니다. / 군포 안이면 24시간 출동합니다.
다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
