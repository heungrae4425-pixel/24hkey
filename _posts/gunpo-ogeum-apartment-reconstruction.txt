# 오금동 오래된 건물, 문은 어디까지 손볼까
오금동은 산본역과 금정역을 오가는 군포 생활권 안에 있는 동네입니다. / 오래된 건물이 많아 재건축이나 재개발 이야기를 한 번쯤 들어 보신 분도 계실 것입니다.
언제 바뀔지 모르는 집이라면 문을 어디까지 고쳐야 하는지 고민이 됩니다. / 비용을 들이자니 아깝고, 그냥 두자니 문이 불편하고 불안하기 때문입니다.
이 글은 일정이 정해지지 않은 상태에서 현관문과 도어락을 어떻게 판단할지 정리했습니다. / 특정 건물의 사업 진행 상황은 제가 알 수 없으니 일반적인 기준만 적었습니다.

# 먼저 지금 문의 상태를 숫자 아닌 눈으로 확인
문이 닫히는 소리, 걸쇠가 들어가는 느낌, 열쇠를 돌릴 때의 뻑뻑함을 떠올려 보세요. / 기능이 멀쩡한 부분은 그대로 쓰는 것이 합리적입니다.
다음 세 가지 중 둘 이상이 해당된다면 손볼 때가 된 것입니다.
- 문이 처져서 닫을 때 바닥이나 문틀에 긁힌다
- 열쇠가 자꾸 걸리거나 도어락이 가끔 반응하지 않는다
- 바람이 들어오거나 문틈으로 빛이 보인다
하나만 해당되면 임시 보수로 충분한 경우가 많습니다.
체크할 때는 낮 시간에 밝은 곳에서 문을 열고 닫아 보세요. / 밤에는 소리와 느낌으로만 판단하게 되어 놓치는 부분이 생깁니다.
기록해 두면 나중에 수리를 상담할 때 훨씬 빠릅니다. / 사진 한두 장과 증상 메모만 있어도 충분합니다.

# 임시로 버틸 때와 새로 바꿀 때를 가르는 기준
기준은 간단합니다. / 앞으로 얼마나 더 살 것인지와 고장이 났을 때 불편이 얼마나 큰지입니다.
짧게 더 살 계획이고 문이 대체로 멀쩡하다면 [도어락 수리](doorlock-repair.html)나 배터리, 경첩 조정으로 버티는 방법이 있습니다.
오래 더 살 가능성이 있거나 고장이 잦다면 한 번에 바꾸는 편이 오히려 덜 번거롭습니다. / 이때는 [도어락 교체](doorlock-replace.html) 기준을 먼저 읽어 보세요.
@ 오금동 오래된 건물 현관문 상태 점검

# 이사 갈 때 가져갈 수 있는 도어락인지 확인
도어락은 설치 방식에 따라 이전이 가능한 제품과 어려운 제품이 있습니다. / 문 두께와 보조키 위치가 맞아야 다른 집 문에 달 수 있습니다.
새 도어락을 사서 달았다가 이사 가며 남겨 두고 가는 것이 아깝다면 처음부터 이전을 염두에 두세요. / 설치 전에 문 두께와 홀 위치를 재 두면 나중에 다시 달기 쉽습니다.
설치 전 확인할 것은 [도어락 설치](doorlock-install.html) 페이지에 적어 두었습니다.
이전을 염두에 둔다면 설치할 때 원래 문에 남는 구멍이 커지지 않는 제품인지 보는 것도 방법입니다. / 모델마다 요구하는 문 두께와 구멍 위치가 다르니 구입 전에 문의해 주세요.
모든 도어락이 이전이 쉬운 것은 아니라는 점만 기억해 두시면 됩니다.

# 세입자라면 집주인과 이렇게 정리해 두세요
세입자는 문을 마음대로 바꾸기 부담스러울 수 있습니다. / 고장 원인이 낡은 부품인지, 사용 중 파손인지를 사진으로 남겨 두면 대화가 쉬워집니다.
누가 부담할지는 계약 내용과 협의에 따라 다르므로 여기서 단정할 수 없습니다. / 서로 합의한 내용은 문자나 메모로라도 남겨 두는 것이 좋습니다.
도어락을 바꿀 때는 이전 상태를 사진으로 찍어 두세요. / 나갈 때 원상 복구 이야기가 나올 때 도움이 됩니다.
오래 살던 집일수록 문 상태를 기억에만 의존하게 됩니다. / 입주 당시와 지금의 모습을 비교할 수 있게 해 두면 서로 오해가 줄어듭니다.
고친 내용과 날짜도 같이 적어 두면 다음 사람에게 설명하기 쉽습니다.

# 이웃이 하나둘 이사 나간 뒤 현관 방범
건물이 한산해지는 시기에는 평소보다 현관 방범에 신경을 쓰게 됩니다. / 다만 불안을 키울 필요는 없고 기본을 챙기면 충분합니다.
- 보조키와 걸쇠가 제대로 잠기는지 확인
- 도어락 비밀번호를 한 번 바꾸고 이전 번호 정리
- 문틈이나 현관 앞에 가림 없이 우편물이 쌓이지 않게 두기
- 외출이 길면 이웃이나 가족에게 알려 두기
과하게 보강할 필요는 없습니다. / 현재 문이 제 기능을 하는지가 가장 중요합니다.
문 안쪽 걸이나 보조 잠금을 쓰는 습관만 들여도 기본 방범은 충분히 챙길 수 있습니다. / 새 장치를 늘리기 전에 이미 달린 장치부터 제대로 쓰는지 점검해 보세요.

# 문틀과 경첩은 도어락보다 먼저 봅니다
오래된 건물은 문틀 자체가 휘거나 경첩이 느슨해진 경우가 많습니다. / 이 상태에서 새 도어락만 달면 걸쇠가 문틀에 맞지 않아 같은 문제가 반복됩니다.
문이 처졌는지는 닫았을 때 위쪽과 아래쪽 틈이 같은지로 확인합니다. / 틈이 한쪽으로 쏠려 있으면 경첩을 조정하거나 문틀 쪽 걸쇠 구멍을 손봐야 할 수 있습니다.
도어락 교체 전에 문이 제대로 닫히는지부터 보는 순서가 맞습니다.
철문 표면이 부식되거나 페인트가 벗겨졌다면 도어락 주변 나사가 헐거워졌을 수 있습니다. / 그 상태에서 도어락만 바꾸면 얼마 안 가 다시 흔들립니다.
오래 살 수 있는지가 불확실하다면 문 전체를 손보기보다 핵심 부분만 먼저 점검하는 쪽이 현명합니다.
@ 오금동 오래된 철문 경첩과 도어락 고정 나사 확인

# 문이 안 열려서 급할 때는 이렇게
오래된 문은 갑자기 걸쇠가 문틀에 물려 안 열리는 일이 있습니다. / 이럴 때는 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요.
번호판이 꺼졌다면 비상 전원 단자에 9V 건전지를 대 봅니다. / 그래도 안 되면 드라이버나 카드로 문틈을 벌리지 마시고 전화 주세요.
무리하게 열면 문틀이 상해서 앞으로 더 오래 쓰기 어려워집니다.
@ 오금동 낡은 문틀 걸쇠 맞춤 확인

# 연락 주실 때 알려주면 좋은 것
오금동은 건물마다 구조가 달라 상태를 알면 더 정확히 준비할 수 있습니다.
- 건물 이름 대신 대략 위치와 동·호수
- 문의 재질(철문인지 목재인지)
- 도어락 모양과 번호판 상태
- 열쇠가 따로 있는지
도어락 사진을 보내주시면 맞는 장비를 챙겨 가기 좋습니다. / 아이나 반려동물이 안에 있다면 꼭 먼저 말씀해 주세요.

# 도착하면 거주 확인부터 합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 봅니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 가운데 하나면 됩니다.
건물에 관리사무소가 없다면 우편물이나 신분증으로 확인합니다. / 확인이 어려우면 작업이 어려울 수 있으니 미리 챙겨 두세요.

# 비용은 열기 전에 먼저 말씀드립니다
오래된 문일수록 상태가 제각각이라 보고 나서 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고 아니면 그대로 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에서도 볼 수 있습니다.

# 오금동 말고 군포 전 지역 갑니다
오금동에서 가까운 산본동, 금정동, 당동 등 군포 안 어디든 다닙니다. / 산본역, 금정역, 군포역 쪽도 24시간 출동 가능 여부를 바로 말씀드립니다.
지역 안내는 [군포시 출장열쇠](gunpo.html)에서, 다른 지역은 [출장 지역](area.html)에서 보세요.

? 도어락을 이사 때 가져가도 되나요? | 문 두께와 홀 위치가 맞으면 가능한 경우가 있습니다. 설치 전에 확인하세요.
? 세입자가 고쳐도 되나요? | 계약과 협의에 따라 다릅니다. 집주인과 먼저 이야기하고 기록을 남기세요.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.

판단이 어렵다면 상태만 전화로 말씀해 주세요. / 24시출장열쇠는 군포 전 지역 24시간, 전화 010-3664-5455입니다.
