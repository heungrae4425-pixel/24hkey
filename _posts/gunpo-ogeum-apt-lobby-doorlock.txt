# 오금동에서 문이 안 열린다는 전화, 어느 문인지부터
오금동 아파트에 사시는 분들이 가장 자주 하는 말이 "문이 안 열려요"입니다. / 그런데 이 말이 1층 공동현관을 뜻하는지, 우리 집 현관문을 뜻하는지에 따라 해결 방법이 완전히 달라집니다.
산본역이나 군포역 쪽에서 걸어 들어와 단지 입구에 서 있는 상황이라면 더욱 헷갈립니다. / 이 글은 군포 오금동에서 공동현관과 세대 현관을 구분해 확인하는 순서를 정리했습니다.
@ 오금동 아파트 공동현관 출입 비밀번호 키패드

# 공동현관과 세대 현관은 주인이 다릅니다
공동현관은 단지 전체가 함께 쓰는 설비이고, 세대 현관문은 우리 집 것입니다. / 관리하는 주체가 다르기 때문에 고치는 방법도 다릅니다.
- 공동현관: 관리사무소나 단지 관리 업체가 맡는 설비
- 세대 현관문: 거주자가 관리하는 우리 집 도어락
공동현관 비밀번호나 카드 인식이 안 되는 문제는 대개 단지 쪽 설정과 연결되어 있습니다. / 24시출장열쇠가 직접 만지는 것은 세대 현관문 쪽이라는 점을 먼저 알려드립니다.


혼란스러울 때는 위치를 한 문장으로 말해 보면 정리가 됩니다. / "1층 공동현관에서 막혔다"와 "우리 층 현관문 앞에서 막혔다"는 전혀 다른 이야기입니다.
이웃의 도움으로 공동현관은 들어왔는데 집 앞에서 안 열린다면 이제 세대 도어락 문제입니다. / 반대로 집 문은 문제없는데 1층에서 막힌다면 단지 쪽에 먼저 문의해야 합니다.

# 공동현관 비밀번호가 안 먹힐 때 확인할 것
공동현관 번호는 단지 사정에 따라 바뀌기도 합니다. / 번호가 달라졌다는 공지를 놓친 경우가 의외로 많습니다.
- 게시판이나 단지 공지에 최근 변경 안내가 있었는지
- 누르는 동안 숫자 사이를 너무 오래 끌지 않았는지
- 다른 입구에서는 같은 번호가 되는지
- 이웃이 지금 같은 번호로 들어가는지 물어볼 수 있는지
이 정도를 보고도 안 되면 관리사무소에 번호 확인을 요청하는 것이 가장 빠릅니다.

# 카드나 태그가 인식되지 않을 때
카드가 반응하지 않을 때는 카드 쪽 문제인지 리더기 쪽 문제인지를 나눠 봐야 합니다. / 가족의 다른 카드로 찍어서 열리면 내 카드가 문제이고, 모두 안 되면 리더기 쪽을 의심합니다.
카드를 지갑에 여러 장 같이 넣고 대면 서로 간섭해서 읽히지 않기도 합니다. / 한 장만 꺼내 가까이 대고 잠깐 기다려 보세요.
카드가 휘었거나 오래 써서 마모된 경우도 있습니다. / 이럴 땐 관리사무소에서 재발급 절차를 알려 줍니다.

# 공동현관은 관리사무소에 먼저 연락하세요
공동현관 설비는 24시출장열쇠가 임의로 손댈 수 있는 부분이 아닙니다. / 단지 관리 쪽 허락 없이 공용 설비를 건드리면 오히려 문제가 커질 수 있습니다.
관리사무소가 닫힌 늦은 시간이면 경비실이나 야간 연락처를 확인해 보세요. / 이웃에게 인터폰으로 열어 달라고 부탁하는 방법도 흔히 씁니다.
@ 오금동 단지 관리사무소 공동현관 확인 안내

# 공동현관 통과 후 집 앞에서 막혔다면
1층을 지나 우리 층 현관문 앞에 왔는데 번호판이 꺼져 있거나 반응이 없다면 이제부터가 세대 도어락 문제입니다. / 이때는 24시출장열쇠가 도울 수 있는 영역입니다.
먼저 번호판에 손바닥을 대 보아 불이 들어오는지 봅니다. / 소리가 나는지, 경고음이 나는지도 전화로 말씀해 주세요.
배터리 방전이 의심되면 바깥쪽 비상 단자에 9V 건전지를 대는 방법이 있는 제품도 있습니다. / 단자가 없거나 그래도 안 되면 그때 연락 주시면 됩니다.

# 공동현관은 열렸는데 세대 문만 안 열리는 흔한 이유
오금동처럼 아파트가 중심인 동네에서는 아래 같은 원인이 반복됩니다.
- 배터리가 다 되어 번호판이 아예 꺼진 경우
- 번호를 가족이 바꿨는데 모르고 있는 경우
- 보조키를 안쪽에서 잠근 채 나온 경우
- 문이 덜 닫혀 걸쇠가 풀리지 않는 경우
원인이 무엇인지 모르겠다면 방금 전에 일어난 일을 떠올려 보세요. / 마지막에 문을 닫은 때의 상황이 힌트가 되는 경우가 많습니다.

# 문 앞에서 하지 말아야 할 행동
급하다고 공동현관 문을 억지로 당기거나 세대 문 손잡이를 세게 흔들면 위험합니다. / 부품이 휘거나 고정 나사가 헐거워져 나중에 수리가 더 커집니다.
카드나 드라이버로 틈을 벌려 열려는 시도도 권하지 않습니다. / 이웃 눈에는 이상하게 보일 수 있고 문과 도어락 외관도 상합니다.
번호를 여러 번 틀리면 일정 시간 입력이 막히는 제품이 있습니다. / 서너 번 해 보고 안 되면 멈추고 연락 주세요.

# 전화로 이렇게 설명해 주세요
위치가 아파트라면 몇 가지만 정리해서 말씀해 주시면 빠릅니다.
- 오금동 어느 쪽 단지인지, 동과 호수
- 지금 있는 곳이 공동현관인지 우리 층 현관인지
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집 안에 사람이나 반려동물이 있는지
공동현관 때문에 들어가는 것이 어려운 경우에는 방문 가능 여부를 먼저 상의드립니다. / 관리사무소나 이웃을 통해 입구를 열어 주실 수 있는지도 같이 여쭙니다.

# 도착하면 사시는 분인지 먼저 확인합니다
세대 현관문을 여는 일이라 신분 확인이 먼저입니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에서 세대 확인을 해 주는 방법이 있습니다. / 확인이 어려우면 작업을 할 수 없다는 점은 미리 알려드립니다.
@ 오금동 세대 현관 도어락 신분 확인 후 개문

# 비용은 문 열기 전에 먼저 말씀드립니다
현관문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요해 보이면 바꾸기 전에 따로 여쭙습니다.
[이용안내](guide.html)에 진행 순서를 적어 두었고, 개문 방식은 [현관문 개문](door-open.html)에서 볼 수 있습니다.

# 같은 일이 반복되지 않게 정리해 두세요
공동현관 번호와 세대 비밀번호를 따로 메모해 두면 헷갈릴 일이 줄어듭니다. / 가족 모두가 같은 번호를 알고 있는지도 한 번 점검해 보세요.
공용 카드는 하나쯤 따로 보관하면 분실했을 때 큰 도움이 됩니다. / 세대 도어락 배터리는 새 것으로 한꺼번에 바꾸는 편이 좋습니다.
고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 상태를 보고, 너무 낡았다면 그때 교체를 말씀드립니다.

# 오금동 말고 군포 어디든 갑니다
산본동, 금정동, 당동, 당정동, 부곡동, 대야미동도 24시간 다닙니다. / 군포 안이면 동네 구분 없이 연락 주세요.
다니는 곳은 [군포시 출장열쇠](gunpo.html)와 [출장 지역](area.html)에서 확인하실 수 있습니다.
