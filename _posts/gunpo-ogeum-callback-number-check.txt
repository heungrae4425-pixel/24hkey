# 오금동에서 문이 잠긴 밤, 전화부터 걸게 됩니다
오금동은 산본역 생활권과 가까워 퇴근길에 집 앞까지 왔다가 문이 안 열려 당황하는 분이 적지 않습니다. / 휴대폰 검색창에 열쇠집을 치면 비슷한 이름과 번호가 한꺼번에 나와 어디에 걸어야 할지 망설이게 됩니다.
급할수록 첫 번째 번호를 누르게 되지만 그 번호가 어떤 곳인지 모르고 맡기면 나중에 곤란해질 수 있습니다. 그래서 통화하는 1분 동안 통화하는 1분 동안 몇 가지만 확인해도 훨씬 안심하고 맡길 수 있습니다. / 이 글은 [군포 출장열쇠](gunpo.html)를 포함해 어느 열쇠집에 전화하든 쓸 수 있는 확인 요령입니다.
@ 오금동 열쇠집에 전화하는 모습

# 전화를 받으면 먼저 상호를 들어 보세요
받자마자 어느 업체인지 밝히는지가 첫 번째 기준입니다. / "열쇠집입니다"처럼 뭉뚱그려 받는다면 한 번 더 상호를 물어보셔도 실례가 아닙니다.
저희는 24시출장열쇠라고 밝히고 시작합니다. / 상호를 말하지 않거나 질문을 피한다면 일단 통화를 끊고 다른 곳과 비교해도 늦지 않습니다.

# 통화 중에 번호를 눌러 본 화면도 확인하세요
검색 화면에 보이던 번호와 지금 통화 연결된 번호가 같은지 보는 습관을 들이면 좋습니다. / 휴대폰 화면 위쪽에 표시되는 번호를 한 번 읽어 보세요.
통화 도중에 "방금 이 번호로 오시는 거 맞죠?" 하고 되물어 보면 상대가 어떻게 답하는지도 알 수 있습니다. / 저희는 010-3664-5455 번호로 통화하고, 같은 번호로 문자와 연락을 드립니다.

# 물어보면 좋은 질문 다섯 가지
- 상호가 어떻게 되는지
- 지금 위치에서 어느 정도 걸리는지
- 문을 열기 전에 비용을 먼저 알려주는지
- 문을 못 열면 어떻게 되는지
- 도착 후 신분 확인은 어떻게 하는지
이 질문들은 불친절해 보일까 걱정하실 필요가 없습니다. / 문을 맡기는 일이니 확인하는 것은 당연한 권리입니다.
이 다섯 가지에 막힘없이 답한다면 대체로 믿고 기다려도 되는 곳입니다. / 반대로 "가서 봐야 안다"는 말만 반복하면서 비용 이야기를 피한다면 조심하셔야 합니다.
@ 오금동 통화 중 확인할 질문 메모

# 도착 시간은 대략으로만 듣고 기다리세요
문이 잠긴 상황에서 가장 궁금한 것은 언제 오느냐입니다. / 그래서 통화 초반에 위치를 말씀드리고 도착 예상을 여쭙는 것이 자연스럽습니다.
교통 상황이나 앞선 일정에 따라 도착 시간이 달라질 수 있어 정확한 분 단위 약속은 어렵습니다. / 대신 출발했을 때 한 번 더 연락을 받는지 물어보면 기다리기가 훨씬 수월합니다.
오금동에서 기다리는 동안 건물 입구나 밝은 곳에 계시면 서로 찾기 편합니다. / 어두운 계단 앞이라면 휴대폰 불빛을 켜 두세요.

# 전화로 비용을 확답하기 어려운 이유와 방식
통화에서 가장 흔한 오해가 이 부분입니다. / 문 사진 없이 금액을 단정하는 곳은 현장에서 말이 달라지기 쉽습니다.
도어락 종류와 문 상태를 보기 전에는 정확한 비용을 말씀드릴 수 없는 경우가 있습니다. / 그래서 현장에 도착해 문을 확인한 뒤, 문을 열기 전에 먼저 말씀드립니다.
괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
통화에서 이 순서를 분명히 설명하는지가 중요합니다. / 열고 난 뒤에야 비용을 말하는 곳은 피하는 편이 안전합니다.

# 도착한 사람이 통화했던 곳 맞는지 봅니다
전화한 곳과 다른 사람이 다른 이름으로 오면 확인하셔도 됩니다. / 먼저 상호를 다시 말해 달라고 하고, 통화했던 번호로 연락이 오는지 보세요.
이상하다 싶으면 문 앞에서 작업을 시작하게 두지 말고 잠시 멈춰도 괜찮습니다. / 정당한 업체라면 확인 요청을 불쾌해하지 않습니다.

# 저희도 신분 확인을 요청합니다
의뢰하시는 분만 확인하는 것이 아니라 저희도 확인받는 쪽입니다. / 동시에 저희는 문을 여는 분이 사시는 분인지 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나로 확인합니다.
서로 확인하는 절차가 번거로워 보여도 이웃의 집을 지키는 일이기도 합니다. 문 앞에서 낯선 사람에게 집 주소와 호수를 알리는 일이니 양쪽 모두 확인이 오가는 것이 자연스럽습니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법을 안내해 드립니다.

# 통화 중 알려주면 좋은 정보
상호와 번호를 확인한 다음에는 상황을 차분히 전달하는 것이 좋습니다. / 길게 설명하려 하지 않아도 아래 정도면 충분합니다.
- 오금동 어느 길 근처인지, 건물 이름은 말하기 어려우면 눈에 띄는 가게나 정류장
- 번호판 상태와 도어락 모양
- 열쇠, 신분증, 휴대폰이 어디 있는지
- 집 안에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 필요한 준비를 해 가기 좋습니다. / 사진 전송이 어렵다면 말씀만으로도 괜찮습니다.

# 문 여는 방법도 물어보세요
방법을 설명하면서 시간이 걸린다고 하는 곳보다, 간단하게라도 순서를 말해 주는 곳이 믿음이 갑니다. / 설명이 너무 어렵다면 쉽게 말해 달라고 하셔도 됩니다.
문을 어떻게 여는지 물어보는 것은 당연한 일입니다. / 문이나 도어락을 부수는 방법인지, 상하지 않게 여는 방법인지를 확인해 두세요.
저희는 덜 상하는 방법부터 차례로 시도하고, 부품 교체가 필요해 보이면 손대기 전에 먼저 여쭙습니다. / 자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 통화가 끝난 뒤 해둘 일
전화를 끊고 나면 문 앞에서 기다리는 시간이 가장 길게 느껴집니다. / 이때 해둘 수 있는 일이 몇 가지 있습니다.
통화 후에는 상호와 번호를 휴대폰에 저장해 두세요. / 나중에 도어락 점검이 필요할 때 다시 찾기 쉽습니다.
출발 연락이 왔는지, 문자가 같은 번호로 오는지 확인하시면 됩니다. / 이용 방식이 궁금하면 [이용안내](guide.html)를 참고하세요.
@ 오금동 열쇠집 번호 저장

# 열고 난 뒤에도 점검할 부분
문이 열렸다고 바로 끝내지 않고, 왜 잠겼는지 원인을 같이 이야기하는 것이 좋은 마무리입니다. / 원인을 모르고 지나가면 같은 밤이 다시 올 수 있습니다.
문이 열린 뒤에는 도어락이 다시 잘 잠기고 열리는지 함께 확인합니다. / 배터리가 문제였다면 새것으로 바꿨는지도 같이 봅니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 고장이 잦다면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드리고, 정말 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 안내합니다.

# 오금동 말고 군포 어디든 갑니다
전화를 걸 때 동네 이름을 먼저 말씀해 주시면 출동 가능 여부를 바로 안내해 드립니다. / 오금동에서 가까운 산본동이나 금정동도 같은 방식으로 움직입니다.
산본동, 금정동, 당동, 당정동, 부곡동, 대야미동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [출장 지역](area.html)에서 확인하실 수 있습니다.
