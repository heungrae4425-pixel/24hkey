# 어제까지 누르던 번호가 오늘은 낯설 때
퇴근하고 오금동 집 앞에 서서 번호판을 보는데 손가락이 멈추는 순간이 있습니다. / 매일 누르던 번호인데 급하거나 피곤할 때는 머릿속이 하얘지기도 합니다.
집 가까이 대야미역이나 군포역 쪽에서 돌아오는 길이었다면 더 맥이 빠집니다. / 이 글은 번호가 생각나지 않을 때 서두르지 않고 순서대로 해볼 것을 정리했습니다.
끝까지 안 되면 [군포 출장열쇠](gunpo.html)에 연락하는 방법도 적어 두었습니다.
@ 오금동 도어락 비밀번호 분실

# 서두를수록 번호는 더 안 떠오릅니다
마음이 급할수록 기억은 달아납니다. / 번호판 앞에서 숨을 한 번 고르고 2~3분 쉬었다가 다시 시도해 보세요.
손으로 누르던 리듬은 머리보다 손가락이 기억하는 경우가 많습니다. / 번호를 떠올리려 하기보다 평소 문 앞에서 하던 동작대로 천천히 눌러 보면 의외로 맞기도 합니다.
가방을 내려놓고 양손을 비운 채 눌러 보는 것도 도움이 됩니다. / 손가락 위치가 틀어지면 맞는 번호도 틀리게 입력되곤 합니다.
번호판이 어두운 곳이라면 휴대폰 불빛을 비춰 숫자 위치를 확인하세요.

# 한 번 틀렸다고 계속 누르지 마세요
도어락은 틀린 번호를 몇 번 연속으로 누르면 일정 시간 입력을 막습니다. / 이 잠금 시간에는 맞는 번호도 먹히지 않습니다.
세 번 정도 틀리면 멈추고 몇 분 뒤에 다시 하세요. / 틀린 번호를 반복할수록 잠금 시간이 길어지는 제품도 있습니다.
경고음이 길게 울린다면 입력을 막았다는 신호입니다. / 그 상태에서는 문 앞에서 기다리는 것이 가장 빠른 길입니다. / 기다리는 동안 휴대폰으로 가족에게 번호를 물어보는 연락을 해 두면 시간이 아깝지 않습니다.

# 이 중에 있는지 떠올려 보기
번호를 직접 정하신 분이라면 비슷한 습관을 가진 번호일 수 있습니다. / 아래를 하나씩 떠올려 보세요.
- 이전 도어락에서 쓰던 번호
- 지금 집에 이사 오면서 처음 정한 번호
- 가족과 같이 쓰자고 약속한 번호
- 휴대폰이나 다른 기기에서 쓰는 비슷한 숫자
자주 쓰는 번호끼리 섞여 헷갈리는 경우가 가장 많습니다. / 하나씩 순서대로 누르되 세 번을 넘기지 마세요. / 어느 번호를 눌렀는지 손가락으로 세어 두면 같은 번호를 두 번 누르는 실수를 막을 수 있습니다.
비밀번호 끝에 별표나 샵 같은 확인 버튼을 누르는 제품이라면 이 단계를 빼먹지 않았는지도 보세요.

# 가족에게 먼저 물어보세요
함께 사는 가족이 번호를 바꿔 놓고 알려주지 않았을 수 있습니다. / 배터리를 교체하면서 번호를 같이 바꾼 경우도 종종 있습니다.
전화로 한 줄만 물어보면 풀리는 일이 많습니다. / 연락이 안 되면 가까운 가족이나 이웃에게도 문자를 남겨 보세요.
자녀가 번호를 바꾼 상태라면 가족 대화방에 번호 변경 기록이 남아 있는지 확인해 보세요.
@ 오금동 가족이 바꾼 도어락 번호 확인

# 카드키, 지문, 열쇠가 같이 있는 제품이라면
번호만 모를 뿐이라면 다른 방법으로 열릴 수 있습니다. / 지문 등록을 해두었거나 카드키를 가지고 계신다면 먼저 그쪽을 써보세요.
안쪽 열쇠구멍이 숨은 제품은 바깥에 덮개를 열면 열쇠 구멍이 나옵니다. / 구형은 열쇠를 가지고 계신다면 그대로 열릴 수 있습니다.
이런 수단이 하나도 없다면 다음 단계로 넘어가야 합니다. / 현관 옆 창문이나 이웃집 쪽 틈을 통해 들어가려는 시도는 위험하니 절대 하지 마세요.

# 이 도어락에는 번호를 알려주는 기능이 없습니다
도어락은 보안상 저장된 번호를 보여주는 기능이 없습니다. / 따라서 번호를 알아내는 것이 아니라 문을 연 뒤 새 번호로 바꾸는 방식이 됩니다.
번호를 알아내 준다는 곳이 있다면 의심해 보시는 게 좋습니다. / 정상적인 방법은 문을 열고 번호를 지운 뒤 새로 등록하는 것뿐입니다.

# 열쇠집을 부르는 때
위 방법으로 안 되고 집 안에 들어가야 한다면 연락 주세요. / 억지로 도어락 덮개를 열거나 건전지 칸을 헤집다가 고장 내는 경우가 많습니다.
도어락을 상하게 하지 않고 여는 방식은 [현관문 개문](door-open.html) 페이지에서 설명하고 있습니다. / 오금동 위치와 도어락 모양을 알려주시면 가는 시간도 말씀드립니다. / 번호판이 켜지는지, 경고음이 나는지도 함께 알려주시면 전화로 먼저 확인할 수 있습니다.

# 열기 전 사시는 분인지 확인합니다
문을 여는 일이라 먼저 확인이 필요합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나를 준비해 주세요.
가족이 번호를 바꿨는데 연락이 닿지 않는 경우에도 같은 절차를 거칩니다. / 집 주인이 아닌 가족이 대신 연락했다면 본인 확인 방법을 따로 안내해 드립니다.
확인 서류가 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁해 보세요.

# 비용은 열기 전, 못 열면 받지 않습니다
도어락 종류와 문 상태를 보고 먼저 비용을 말씀드립니다. / 괜찮으시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 나서 갑자기 붙는 비용도 없습니다.
번호 변경 외에 부품 교체가 필요하면 반드시 따로 여쭙니다. / 전체 흐름은 [이용안내](guide.html)에도 있습니다. / 새 번호를 등록하는 시간은 길지 않으니 문이 열린 뒤에는 천천히 하셔도 됩니다.
@ 오금동 출장열쇠 도어락 번호 재설정

# 문이 열린 뒤 바로 새 번호로
문이 열리면 안쪽 설정 버튼으로 기존 번호를 지우고 새 번호를 등록합니다. / 이때 가족에게도 새 번호를 알려 두세요.
제품에 따라 번호가 여러 개 저장되는 경우가 있어 예전 번호가 남아 있지 않게 모두 정리합니다. / 이전에 알려준 번호가 있었다면 한꺼번에 지우는 것이 안전합니다.
배터리도 같이 점검합니다. / 번호가 기억나지 않는 날이 번호판이 꺼진 날과 겹치는 경우도 있습니다. / 새 배터리로 바꾸고 나면 번호가 정상 저장되었는지 문을 닫고 한 번 눌러 확인합니다.
문을 열어둔 채로 번호를 눌러 보고, 닫은 뒤에도 같은 번호로 열리는지 꼭 확인해 주세요. / 안쪽에서 설정만 하고 바깥에서 안 열리면 다시 잠겨 나올 수 있기 때문입니다.

# 번호를 기억 못 하는 일 줄이는 법
번호는 자주 바꾸는 것보다 한 번 정할 때 외우기 쉬운 규칙으로 정하는 편이 좋습니다. / 단, 생년월일이나 전화번호 뒷자리처럼 남이 추측할 수 있는 건 피하세요.
번호를 종이에 적어 현관 근처에 붙여 두는 건 피하세요. / 대신 휴대폰의 보안 메모처럼 잠금이 걸린 곳에 보관하세요.
가족이 같이 쓰는 번호는 바뀔 때마다 대화방에 적어 알리는 약속을 해 두세요. / 지문이나 카드키를 하나 더 등록하면 번호를 잊은 날에도 집에 들어갈 수 있습니다. / 열쇠를 쓰는 보조 수단이 있는 제품이라면 열쇠 하나를 가까운 가족이나 직장 서랍에 맡겨 두는 것도 방법입니다.
오래돼 입력이 둔한 도어락이라면 [도어락 수리](doorlock-repair.html)로 점검을 받아 보세요.

# 오금동 말고도 군포 전역
오금동 옆 산본동, 금정동, 당동, 당정동, 부곡동, 대야미동도 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
