# 오금동 맞벌이 집의 도우미 출입 고민
오금동은 산본역과 금정역 어느 쪽으로도 오갈 수 있는 생활권이라 출퇴근하는 가정이 많습니다. / 집을 비운 사이 가사도우미가 오시는 경우, 현관 번호를 어떻게 알려드릴지가 늘 고민입니다.
처음에는 우리 집 번호를 그대로 알려드리지만, 시간이 지나면 불안해지기 마련입니다. / 이 글은 요일별로 도우미가 오는 집에서 임시 번호를 쓰는 방법을 정리했습니다.
번호가 꼬여서 문 앞에서 막혔을 때 어떻게 하는지도 함께 적었습니다.
@ 오금동 도어락 임시 비밀번호 설정

# 우리 집 번호를 그대로 알려주면 생기는 일
가족이 쓰는 번호를 알려드리면 도우미가 그만두신 뒤에도 번호가 남습니다. / 번호를 바꾸자니 가족들에게 다시 알려야 해서 미루다 보면 그대로 두게 됩니다.
도우미가 가족의 번호를 다른 사람에게 말하지 않았더라도 마음은 편치 않습니다. / 그래서 별도의 번호를 만들어 따로 관리하는 방법이 낫습니다.
의심해서가 아니라 서로 편하자고 하는 일이라고 말씀드리면 대부분 이해해 주십니다.

# 도어락에 임시 번호를 등록하는 방식
많은 도어락은 가족 번호 외에 손님용 번호를 추가로 등록할 수 있습니다. / 일부 제품은 번호 개수 제한이 있어서 설명서를 먼저 보셔야 합니다.
- 관리자 번호로 설정 모드에 들어가기
- 추가 번호 등록 메뉴 선택
- 새 번호 입력 후 한 번 더 확인
- 문 밖에서 새 번호로 열리는지 시험
제품마다 순서가 다르니 설정 모드 진입 방법은 설명서나 안쪽 안내 스티커를 보세요. / 모델 이름을 알려주시면 전화로 순서를 같이 짚어 드릴 수도 있습니다.

# 요일별로 번호를 나누는 현실적인 방법
월요일과 목요일처럼 오시는 요일이 정해져 있다면, 번호를 하나 만들어 두고 오시는 주기에 맞춰 바꾸는 방법이 있습니다. / 매번 바꾸기 번거롭다면 한 달에 한 번 바꾸는 식으로 정해도 됩니다.
시간 제한이 되는 제품은 오시는 시간대만 열리게 설정할 수 있습니다. / 이 기능이 없는 제품이라면 방문 전날 바꾸고 방문 다음 날 지우는 식으로 하면 됩니다.
업체에서 보내는 도우미가 매번 바뀌는 경우에는 방문 때마다 번호를 새로 알려드리는 쪽이 안전합니다.

# 번호는 이렇게 만드는 게 좋습니다
생일이나 전화번호 뒷자리처럼 알아맞히기 쉬운 번호는 피해야 합니다. / 같은 숫자를 반복하거나 1234처럼 연속된 번호도 마찬가지입니다.
- 가족 번호와 겹치지 않게 만들기
- 다음에 바꿀 날짜를 휴대폰 알림으로 적어 두기
- 번호를 문자로 보낸 뒤 대화를 지우기
- 같은 번호를 다른 곳에서 쓰지 않기
도우미에게 번호를 알려드릴 때는 직접 통화로 말씀드리거나, 메신저로 보낸 뒤 확인하고 지우는 편이 좋습니다.

# 번호가 꼬여서 도우미가 문 앞에서 기다릴 때
번호를 바꿨는데 도우미에게 전달이 안 되어 문 앞에서 전화가 오는 일이 있습니다. / 이럴 때는 먼저 어떤 번호가 등록되어 있는지 기억을 더듬어 보세요.
가족 중 누군가가 번호를 바꾸고 말하지 않았을 수도 있습니다. / 몇 번 틀리면 도어락이 입력을 막는 제품이 많아서, 서너 번 해보고 멈추는 게 좋습니다.
아이를 학교나 학원에 보낸 사이에 문제가 생기면 집 안에 누가 있는지 먼저 확인하세요.
@ 오금동 가사도우미 방문 현관 출입

# 집주인이 없는데 문을 열어야 하는 경우
도우미만 문 앞에 있고 집주인은 멀리 있다면 신분 확인이 가장 큰 숙제가 됩니다. / 문을 여는 일이라 사시는 분의 확인이 되어야만 작업할 수 있습니다.
집주인이 전화로 상황을 알려주고, 확인 가능한 서류나 우편물을 문자로 보내주시면 상의드릴 수 있습니다. / 경비실이나 관리사무소에서 세대 확인을 해주는 경우도 있으니 먼저 알아보세요.
확인이 안 되면 작업을 할 수 없으니, 집주인이 돌아오실 때까지 기다리시는 게 안전합니다.

# 도어락 번호를 한꺼번에 정리하고 싶을 때
도우미가 바뀌거나 그만두셨다면 임시 번호를 지우는 것은 당연한 일입니다. / 그런데 어떤 번호들이 등록되어 있는지 헷갈리는 집이 의외로 많습니다.
전체 초기화를 하면 모든 번호가 지워지니 가족 모두에게 새 번호를 알려야 한다는 점만 기억하세요. / 일부 제품은 번호 목록을 하나씩 지우는 메뉴가 있어 그쪽이 더 간편합니다.
정리가 어려우면 [도어락 수리](doorlock-repair.html)나 설정 지원을 요청해 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
출장열쇠가 도착하면 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나를 요청드립니다. / 번거로워도 이웃과 가정을 지키는 절차입니다.
신분증이 집 안에 있다면 휴대폰에 저장된 계약서나 고지서 사진도 참고가 됩니다. / 본인 확인이 어려우면 작업할 수 없다는 점은 미리 알아 두세요.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 상태를 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 더 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우엔 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 열고 난 뒤 같이 점검하는 것
문이 열린 뒤에는 등록된 번호가 어떻게 되어 있는지 같이 살펴봅니다. / 필요 없는 번호는 지우고 새 번호를 정리해 드립니다.
배터리가 약한 상태였다면 새것으로 바꾸는 것을 권합니다. / 번호 관리 기능이 부족한 오래된 제품이라면 [도어락 교체](doorlock-replace.html)를 말씀드릴 수 있습니다.
교체는 꼭 필요할 때만 권하고, 고쳐서 쓸 수 있으면 그렇게 합니다.
@ 오금동 도어락 번호 정리 점검

# 평소에 해두면 좋은 관리 습관
- 도우미용 번호는 가족 번호와 다르게 유지
- 방문 요일과 번호 변경일을 달력에 함께 적기
- 분기마다 등록된 번호 목록을 한 번 점검
- 비상용으로 열쇠나 카드키 하나는 따로 보관
- 도우미가 바뀌면 그날 바로 이전 번호 삭제
번호를 정리한 날짜를 적어 두면 나중에 헷갈리지 않습니다. / 가족과 함께 규칙을 정해 두면 서로 번호를 바꾸고 말하지 않는 일이 줄어듭니다.

도우미 분께도 번호를 알려드릴 때 사용 규칙을 같이 말씀해 두면 오해가 줄어듭니다. / 예를 들어 문을 닫을 때 소리가 나는지 확인하고 가시게 하거나, 나가실 때 보조키를 건드리지 않도록 안내하는 식입니다.
집에 아이나 반려동물이 있다면 도우미가 드나들 때 문이 완전히 닫히는지도 알려주세요. / 서로 불편하지 않게 규칙을 정해 두면 번호 문제도 훨씬 덜 생깁니다.

# 오금동 말고 군포 어디든 갑니다
오금동 가까운 산본동, 금정동, 당정동, 부곡동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
군포에서 다니는 곳은 [군포시 출장열쇠](gunpo.html) 페이지에 있습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인해 보세요.

# 자주 묻는 질문
? 도우미에게 알려드린 번호만 따로 만들 수 있나요? | 제품에 따라 다르지만 추가 번호 등록이 되는 도어락이 많습니다. 모델을 알려주시면 가능 여부를 안내합니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 집주인이 없고 도우미만 문 앞에 있어도 열어 주나요? | 사시는 분의 확인이 되어야 합니다. 집주인과 통화하고 확인 서류를 보내주시면 상의드립니다.
? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 등록된 번호를 모두 정리해 주시나요? | 네, 문을 연 뒤 필요 없는 번호를 지우고 새 번호를 등록하는 것까지 도와드립니다.
