# 이삿짐보다 먼저 챙길 것
오금동으로 이사해 새 집 문 앞에 서면 짐을 들일 생각에 마음이 바쁩니다. / 하지만 짐이 들어오기 전에 현관 도어락부터 정리하는 것이 순서입니다.
이전 거주자나 중개인, 공사 인부가 알고 있는 번호가 그대로 남아 있을 수 있기 때문입니다. / 대야미역이나 군포역 쪽에서 이사 온 분이라면 이 점이 더 낯설게 느껴질 수 있습니다.
이 글은 이사한 날 도어락을 초기화하고 새 비밀번호를 정하는 순서를 정리했습니다. / 문이 안 열리거나 설정이 막히면 [군포 출장열쇠](gunpo.html)에 연락하세요.
@ 오금동 이사 도어락 초기화 비밀번호 재설정

# 이전 번호가 남아 있는 이유
도어락은 한 번 등록한 번호를 스스로 지우지 않습니다. / 이사하는 날 전 세입자가 번호를 지우고 나갔다고 믿는 것은 위험합니다.
- 전 거주자가 쓰던 번호
- 중개 담당자가 방문하며 쓰던 임시 번호
- 이사나 청소 업체가 받은 번호
- 카드키나 태그로 등록된 출입 수단
이 중 하나라도 남아 있으면 내가 모르는 사람이 현관을 열 수 있습니다. / 불안을 키우자는 이야기가 아니라 새 집의 기본 정리라고 생각하시면 됩니다.
입주 전 청소나 도배 때문에 다녀간 사람이 있었다면 더더욱 정리가 필요합니다.

# 열쇠도 마찬가지입니다
번호 외에 열쇠도 확인해야 합니다. / 이전 거주자가 복사해 둔 열쇠가 어딘가에 있을 수 있습니다.
받은 열쇠 개수와 열쇠가 맞는 문이 모두 다른지 확인하세요. / 보조키나 열쇠 구멍이 있는 문이라면 열쇠 구멍까지 같이 점검하는 편이 낫습니다.
열쇠가 걱정된다면 실린더만 바꾸는 방법도 있습니다. / 상황에 맞춰 선택은 설명을 들은 뒤에 하시면 됩니다.

# 이사 당일 해야 할 순서
순서를 정해 두면 허둥대지 않습니다.
- 먼저 문이 열리는지 확인하고, 열려 있다면 문을 닫지 않기
- 배터리를 새것으로 교체
- 기존 번호와 카드를 모두 삭제하거나 초기화
- 새 번호 등록 후 바깥에서 열어 확인
- 가족에게 새 번호 공유
가장 중요한 건 문을 열어 둔 채로 설정하는 것입니다. / 이사 날은 짐이 오가니 문이 열려 있기 마련이라 오히려 설정하기 좋은 때입니다.
@ 오금동 새 집 도어락 번호 삭제

# 배터리부터 새것으로
이사 오기 전부터 비어 있던 집은 도어락 배터리가 많이 닳아 있을 수 있습니다. / 새 번호를 등록하다 배터리가 꺼지면 설정이 꼬입니다.
건전지는 모두 새것으로 바꾸세요. / 전에 쓰던 건전지가 남아 있다면 따로 모아 버립니다.
극 방향을 확인하며 끼우고, 뚜껑이 제대로 닫혔는지 봅니다. / 배터리를 넣었는데 번호판이 켜지지 않는다면 접촉이 헐거운 것일 수 있으니 한 번 더 끼워 보세요.

# 초기화와 번호 삭제는 다릅니다
도어락에는 두 가지 방식이 있습니다. / 어느 쪽을 쓸지 먼저 정하세요.
- 번호만 지우고 새로 등록하는 방식: 설정 일부만 바뀝니다.
- 전체 초기화: 번호, 카드, 지문, 부가 설정이 모두 사라지고 공장 상태로 돌아갑니다.
이사 직후라면 이전 설정이 무엇이 있는지 알 수 없으니 전체 초기화가 마음 편합니다. / 단, 초기화 방법이 제품마다 달라 설명서를 보며 진행하세요.

# 초기화 버튼 위치
많은 도어락은 안쪽 배터리 칸 근처나 덮개 안쪽에 작은 초기화 버튼이 있습니다. / 이 버튼을 누른 채 전원을 넣는 등 특정 조작이 필요한 제품도 있습니다.
설명서가 없다면 도어락 제품명이나 모델명을 휴대폰으로 사진 찍어 두세요. / 전화로 설명을 들으면 방법을 찾기 쉽습니다.
무리하게 덮개를 뜯으면 부품이 상할 수 있으니 조심하세요. / 이사 날은 서두르기 쉬우니 설정이 한 번에 안 된다면 짐을 먼저 들이고 천천히 다시 해도 괜찮습니다.

# 새 번호 정하는 요령
새 번호는 남이 추측하기 어려운 숫자로 정하세요. / 전에 살던 집 번호를 그대로 쓰는 것도 좋지 않습니다.
- 생일, 전화번호 뒷자리, 연속된 숫자는 피하기
- 가족이 외우기 쉬운 규칙으로 정하기
- 번호 자릿수는 제품이 허용하는 범위에서 길게
- 번호를 쓴 메모는 현관 근처에 붙이지 않기
번호를 정한 뒤에는 문을 닫고 바깥에서 한 번 열어 확인하세요. / 안쪽에서만 설정하고 확인을 안 하면 밖에서 안 열리는 일이 생깁니다.

# 설정하다 문이 닫혀 버렸을 때
이사 날 정신이 없다 보면 문이 닫히면서 번호가 꼬이는 경우가 흔합니다. / 새 번호가 저장됐는지 불확실한 상태로 문 밖에 서 있게 될 수 있습니다.
기존 번호와 새 번호 모두 안 먹는다면 입력이 막힌 것일 수 있습니다. / 몇 분 기다린 뒤에도 안 되면 억지로 반복하지 마세요.
이런 때는 [현관문 개문](door-open.html)으로 문을 상하게 하지 않고 열어 드립니다. / 이사 날 새 집을 부수는 일은 없어야 합니다.

# 전 거주자가 관리자 번호를 걸어 둔 경우
일부 도어락은 설정 메뉴에 들어갈 때 관리자 번호를 요구합니다. / 이전 사람이 정해 둔 번호를 모르면 초기화가 막힙니다.
이럴 때는 문을 열고 난 뒤에 별도 절차로 초기화를 진행하게 됩니다. / 직접 해결이 안 되면 전화로 모델을 알려주세요.
집주인이나 중개인에게 이전 관리자 번호를 물어보는 방법도 있습니다. / 모른다고 해서 포기할 필요는 없고, 문을 연 뒤에 안전하게 정리할 방법이 있습니다.

# 이사한 집이라도 신분 확인은 합니다
문을 여는 일이라 사시는 분인지 확인합니다. / 이사한 지 얼마 안 된 분은 신분증 주소가 예전 주소일 때가 많습니다.
이럴 때는 새 집 계약서, 관리비 고지서, 이사 날짜가 확인되는 서류를 준비해 주세요. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나로 안내합니다.
관리사무소에서 입주 확인을 받아 두면 이후에도 편합니다.
입주 직후라 서류가 아직 정리되지 않았다면 그 사정을 먼저 말씀해 주세요. / 현장에서 확인 가능한 방법을 함께 찾아 드립니다.
이삿짐 업체가 문 앞에서 기다리는 상황이라면 더 서두르고 싶겠지만 확인 절차는 줄이지 않습니다.
@ 오금동 이사 후 출장열쇠 신분 확인

# 비용은 열기 전에, 못 열면 받지 않습니다
도어락과 문 상태를 본 뒤 먼저 비용을 말씀드립니다. / 괜찮으시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품이나 실린더를 바꿔야 하면 바꾸기 전에 반드시 여쭙니다.
진행 순서는 [이용안내](guide.html)에서 확인하세요.

# 도어락 자체가 낡았다면
이사하면서 보니 번호판이 둔하거나 소리가 이상하다면 점검받는 편이 좋습니다. / 간단한 문제는 [도어락 수리](doorlock-repair.html)로 해결됩니다.
너무 오래된 제품이거나 기능이 불편하다면 [도어락 교체](doorlock-replace.html)를 고려해 보세요. / 새로 달기 전에 문 두께와 보조키 위치를 먼저 봅니다.
이사 전에 미리 확인하면 짐 들이는 날과 겹치지 않습니다. / 계약 후 입주 전에 집을 한 번 둘러볼 기회가 있다면 도어락을 같이 확인해 두세요.
