# 오금동에서 도어락을 바꿔야 할지 고민될 때
도어락이 가끔 말썽을 부려도 바로 바꾸자니 아깝고, 그냥 두자니 불안합니다. / 오금동에서도 이런 문의가 꾸준합니다.
교체가 정말 필요한 경우와 고쳐서 쓸 수 있는 경우는 생각보다 다릅니다. / 이 글은 바꾸기 전에 확인할 것과 비용 이야기를 어떻게 풀어 가는지 적었습니다.
궁금한 건 [군포 출장열쇠](gunpo.html)로 전화 주셔도 됩니다. / 상담만 하셔도 부담 없습니다.
@ 오금동 도어락 교체 비용 안내 출장열쇠

# 교체가 필요한 경우와 아닌 경우
도어락이 한 번 오작동했다고 무조건 바꿔야 하는 건 아닙니다. / 아래처럼 나눠 보면 판단이 쉬워집니다.
- 배터리만 바꾸면 되는 경우: 번호판이 흐리거나 경고음이 날 때
- 수리로 충분한 경우: 모터, 센서, 손잡이 부품 문제
- 교체가 나은 경우: 부품 구하기 어렵거나 문이 오래돼 오작동이 반복될 때
처음부터 교체를 권하는 곳보다 먼저 점검하는 곳을 고르시는 게 좋습니다. / 점검만으로 해결되면 비용이 훨씬 줄어듭니다.

# 교체 전에 문을 먼저 보세요
도어락은 문과 짝이 맞아야 잘 작동합니다. / 문이 처졌거나 문틀이 어긋나 있으면 새 도어락을 달아도 같은 문제가 생깁니다.
문 두께, 문틀 깊이, 기존 구멍 크기를 먼저 확인합니다. / 맞지 않는 제품을 고르면 설치가 안 되거나 문을 가공해야 합니다.
확인 방법은 [도어락 설치](doorlock-install.html) 페이지에 적어 두었습니다. / 사진을 보내주시면 먼저 봐 드립니다.
@ 오금동 도어락 교체 전 문 상태 확인

# 어떤 도어락이 맞는지
쓰는 사람과 집 구조에 따라 맞는 제품이 다릅니다. / 무조건 비싼 게 좋은 것도 아닙니다.
- 아이나 어르신이 많은 집: 번호 입력이 쉽고 카드나 태그가 있는 모델
- 출입이 잦은 집: 지문이나 카드 인식 모델
- 단순하게 쓰는 집: 번호 방식 기본 모델
- 문이 오래된 집: 문틀을 덜 건드리는 설치 방식
제품 이야기를 길게 하기보다 쓰시는 모습을 먼저 여쭙습니다. / 맞는 쪽으로 간단하게 안내해 드립니다.

# 비용은 이렇게 안내합니다
어떤 업체든 처음에 가장 궁금한 것이 비용입니다. / 저희는 문 상태와 제품을 보고 열기 전에 총액을 먼저 말씀드립니다.
추가 비용이 생길 수 있는 부분이 있으면 그 이유까지 같이 설명합니다. / 하겠다고 하시기 전에는 아무것도 시작하지 않습니다.
마음에 안 드시면 그냥 돌아갑니다. / 작업을 못 하게 된 경우에도 출장비를 따로 받지 않습니다.
@ 오금동 출장열쇠 비용 먼저 안내

# 전화나 문자로 먼저 알려주시면 좋은 것
정확한 안내를 위해 아래 정도만 알려주세요. / 사진 한두 장이면 더 정확합니다.
- 지금 쓰는 도어락의 모양과 대략 쓴 기간
- 어떤 증상이 있는지, 얼마나 자주인지
- 문이 철문인지 나무문인지
- 바꾸고 싶은 방식 (번호, 지문, 카드 등)
- 오금동 어느 건물인지, 방문 가능한 시간
모르는 부분은 모른다고 하셔도 괜찮습니다. / 현장에서 보고 말씀드립니다.

# 교체하지 않고 고치는 방법
도어락이 느리거나 가끔 안 열리는 정도라면 수리로 해결되는 경우가 많습니다. / [도어락 수리](doorlock-repair.html)에 자세히 적어 두었습니다.
배터리, 모터, 센서, 손잡이 부품을 차례로 봅니다. / 한 곳만 바꿔도 새것처럼 작동하는 일이 많습니다.
수리를 먼저 권하는 이유는 비용 때문만이 아닙니다. / 쓰던 도어락이 맞는 사람에게는 새 제품이 오히려 불편할 수도 있기 때문입니다.

# 교체를 권하는 경우
수리가 어려운 경우만 교체를 말씀드립니다. / 아래와 같은 때입니다.
- 부품을 구할 수 없는 오래된 모델
- 문 자체가 휘어서 도어락이 계속 어긋날 때
- 번호판이나 몸통이 깨져 안전이 걱정될 때
- 보안 기능이 필요한데 기존 모델에 없을 때
이럴 때는 어떤 제품이 맞는지 먼저 설명드리고 정하시게 합니다. / [도어락 교체](doorlock-replace.html)에서 순서를 볼 수 있습니다.

# 교체 작업은 이렇게 진행됩니다
방문하면 먼저 문과 기존 도어락 상태를 확인합니다. / 그다음 비용과 걸리는 시간을 말씀드리고 시작합니다.
기존 도어락을 떼고 새 제품을 달고 나면 문이 부드럽게 열리고 잠기는지 같이 확인합니다. / 새 번호를 등록하고 사용법도 간단히 설명드립니다.
작업 후 정리까지 하고 돌아갑니다. / 이전 도어락은 가져가기를 원하시면 따로 챙겨 드립니다.

# 사시는 분인지 확인합니다
문을 다루는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우시겠지만 이웃을 지키는 절차입니다.

# 설치 후 관리 요령
새 도어락도 관리에 따라 수명이 달라집니다. / 아래 습관을 권합니다.
- 해가 바뀔 때쯤 배터리 전체 교체
- 경고음이 나면 그날 바로 점검
- 번호는 가족과 정해서 주기적으로 변경
- 물이나 세정제를 직접 뿌리지 않기
- 문이 덜 닫히면 경첩 먼저 확인
@ 군포 출장열쇠 오금동 도어락 설치

# 오금동 말고 군포 어디든
오금동 바로 옆 산본동, 부곡동, 대야미동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
군포 전체 정리는 [군포시 출장열쇠](gunpo.html)에 있고, 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
