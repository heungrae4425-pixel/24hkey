# 오금동 셔터 옆 쪽문, 왜 이렇게 자주 말썽일까
오금동은 군포 생활권 안에서 가게와 작은 사무실, 창고가 주택가와 이어져 있는 동네입니다. / 셔터를 내린 가게라면 출입은 대개 옆의 작은 쪽문으로 합니다.
이 쪽문은 하루에도 여러 번 여닫는 문이라 열쇠 구멍과 자물쇠가 쉽게 닳습니다. / 먼지와 비, 찬 바람을 그대로 맞는 자리라 더 그렇습니다.
이 글은 셔터 옆 쪽문 열쇠가 안 맞거나 안 돌아갈 때 어떻게 확인하고 누구에게 연락할지 적었습니다. / 급할 때 [군포 출장열쇠](gunpo.html)를 부르는 순서도 함께 정리했습니다.
@ 오금동 셔터 옆 쪽문 열쇠 구멍

# 셔터 열쇠와 쪽문 열쇠는 다른 물건입니다
셔터에는 바닥 쪽 자물쇠나 전동 스위치가 있고, 쪽문에는 따로 문 자물쇠가 달려 있습니다. / 열쇠 하나로 둘 다 열리는 곳은 많지 않습니다.
열쇠 꾸러미에서 비슷한 열쇠를 잘못 꽂고 억지로 돌리다가 휘는 경우가 많습니다. / 돌리다 걸리면 힘으로 밀지 말고 일단 빼서 열쇠 모양부터 확인해 보세요.
- 셔터 열쇠는 길고 납작한 모양인 경우가 많음
- 쪽문 열쇠는 일반 현관용과 비슷한 모양인 경우가 많음
- 열쇠 머리에 표시를 해 두면 헷갈리지 않음

# 열쇠가 들어가긴 하는데 안 돌아갈 때
열쇠가 끝까지 들어가는데 돌아가지 않으면 구멍 안쪽 핀이 막혔을 수 있습니다. / 쪽문 자물쇠는 먼지가 쌓이거나 오래 써서 마모된 경우가 많습니다.
이럴 때 열쇠를 좌우로 세게 흔들면 핀이 상하고 열쇠까지 부러질 수 있습니다. / 한두 번 살살 돌려 보고 걸리면 멈추는 것이 안전합니다.
열쇠 구멍에 아무 기름이나 뿌리는 것도 조심해야 합니다. / 먼지와 엉겨 오히려 더 뻑뻑해질 수 있어서 권하지 않습니다.

# 문틀과 쪽문이 어긋나서 안 열리는 경우
셔터 옆 쪽문은 철제 문이 많아서 시간이 지나면 문틀이 틀어지기도 합니다. / 열쇠는 돌아가는데 문이 안 빠진다면 걸쇠가 문틀에 눌려 있을 수 있습니다.
문을 안쪽으로 살짝 밀면서 열쇠를 돌리면 걸쇠가 풀리면서 열리기도 합니다. / 세게 발로 차거나 어깨로 밀면 문틀과 자물쇠가 같이 상하니 피해 주세요.
@ 오금동 가게 쪽문 자물쇠와 문틀

# 출근하자마자 쪽문이 안 열릴 때
아침에 가게를 열어야 하는데 쪽문이 안 열리면 영업 시작이 늦어집니다. / 마음이 급해지지만 몇 가지만 침착하게 확인하면 원인이 좁혀집니다.
- 어제 퇴근할 때 열쇠를 다른 것으로 잠갔는지
- 안쪽에서 빗장이나 보조 고리를 걸어 두었는지
- 날씨가 추워진 뒤 갑자기 뻑뻑해졌는지
- 열쇠 모양이 닳거나 휘지 않았는지
가게 안에 사람이 먼저 들어가 있다면 안쪽에서 열어 달라고 하는 것이 가장 빠릅니다. / 직원이 먼저 도착했는지 확인하고, 안에서 걸쇠나 보조 고리를 풀어 줄 수 있는지 물어보세요.
혼자 여는 가게라면 열쇠를 꽂은 채로 사진을 한 장 찍어 두었다가 상담 때 보여주시면 설명이 쉽습니다. / 열쇠 모양, 구멍 상태, 문틀 틈이 보이면 원인을 훨씬 빨리 짚을 수 있습니다.

# 열쇠를 복사하기 전에 알아둘 것
닳은 열쇠로 복사본을 만들면 복사본은 더 안 맞는 경우가 많습니다. / 그래서 열쇠가 헐거워졌다면 원본 상태부터 점검하는 것이 좋습니다.
쪽문이 자주 막히는 가게라면 자물쇠를 통째로 교체하는 편이 오히려 낫습니다. / 교체를 권하는 상황과 고쳐 쓰는 상황은 현장에서 보고 말씀드립니다.
자물쇠를 바꿀 때는 [도어락 교체](doorlock-replace.html) 안내에서 확인 순서를 먼저 보셔도 좋습니다.

# 사업장이면 소유 확인을 먼저 합니다
가게 문을 여는 일이라 영업하는 분이 맞는지 먼저 확인합니다. / 사업자 서류, 주소가 나온 우편물, 건물 관리인 확인 중 가능한 것이면 됩니다.
임차인이라면 계약서나 건물주 연락처를 알려주셔도 됩니다. / 번거롭지만 가게와 이웃 모두를 위한 절차입니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 위치와 문 상태를 알려주세요
오금동은 가게 골목이 비슷해 보여서 위치 설명이 정확해야 합니다. / 사진을 문자로 보내주시면 챙겨 갈 장비를 고르기 쉽습니다.
- 가게 주변에서 보이는 큰길이나 건물
- 셔터 옆 쪽문의 모양(철문, 유리문, 나무문)
- 열쇠 구멍 모양과 도어락 유무
- 열쇠가 돌아가는지, 아예 안 들어가는지
- 안에 사람이나 반려동물이 있는지
@ 오금동 출장열쇠 쪽문 개문 준비

# 비용은 문 열기 전에 말씀드립니다
문 상태와 자물쇠 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 최대한 안 상하게 여는 방법
철문은 한 번 상하면 모양을 되돌리기 어렵습니다. / 그래서 문과 자물쇠를 덜 상하게 하는 방법부터 차례로 해봅니다.
작업 중에 교체할 부품이 보이면 손대기 전에 먼저 말씀드립니다. / 개문 방법은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.

# 열고 난 뒤 점검과 재발 방지
문이 열리면 열쇠가 부드럽게 돌아가는지 같이 확인합니다. / 이상이 있으면 그 자리에서 이유를 설명해 드립니다.
고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 낡았다면 교체를 말씀드립니다. / 쪽문에 맞는 자물쇠 종류는 문 두께와 모양을 보고 정해야 합니다.

# 쪽문을 오래 쓰는 관리 습관
가게 쪽문은 영업이 끝나면 마지막으로 잠그는 문이고, 아침에 가장 먼저 여는 문입니다. / 그래서 고장이 나면 하루 일정 전체가 흔들립니다.
관리는 어렵지 않고, 아래 몇 가지만 해 두어도 막히는 일이 눈에 띄게 줄어듭니다.
- 열쇠 구멍 주변을 마른 수건으로 가끔 닦기
- 비나 눈이 들이치지 않게 문 아래 틈 확인
- 예비 열쇠는 가게 밖이 아닌 믿을 만한 곳에 보관
- 열쇠가 뻑뻑하면 부러지기 전에 점검
- 셔터와 쪽문 열쇠에 서로 다른 표시 달기
문이 덜 닫히거나 걸쇠가 헐거우면 바로 보는 것이 좋습니다. / 작은 이상을 미루면 영업 시간에 문제가 터집니다. / 열쇠가 평소보다 뻑뻑해졌다고 느낄 때가 점검하기 가장 좋은 때입니다.
겨울에는 금속이 수축해 여름보다 더 뻑뻑하게 느껴질 수 있으니 날씨가 바뀔 때 한 번씩 살펴보세요. / 쪽문 주변이 젖어 있다면 물기를 닦고 말린 뒤 다시 열쇠를 넣어 보는 것만으로도 풀리는 경우가 있습니다.
출입문이 하나뿐인 가게라면 쪽문 상태를 더 자주 확인하시길 권합니다.

# 오금동 말고 군포 어디든 갑니다
오금동 가까운 산본동, 금정동, 당동, 당정동, 부곡동, 대야미동도 다닙니다. / 군포 안이면 24시간 출동합니다.
다른 지역은 [출장 지역](area.html) 지도에서 확인해 주세요.
