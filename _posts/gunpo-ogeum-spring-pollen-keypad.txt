# 오금동 도어락 번호판, 봄만 되면 뻑뻑해지는 이유
오금동은 산본역과 군포역을 오가며 지내는 분들이 많은 주거 생활권입니다. / 봄철 외출이 늘면서 현관 앞에서 번호판 버튼이 잘 안 눌린다는 전화가 이 무렵에 늘어납니다.
겨우내 멀쩡하던 도어락이 꽃가루가 날리고 황사가 지나간 뒤 갑자기 말썽을 부리는 경우가 있습니다. / 고장이 아니라 먼지와 습기가 버튼 사이에 낀 것일 때가 많습니다.
이 글은 오금동에서 봄철 번호판이 눌리지 않을 때 직접 해볼 수 있는 청소와 점검, 불러야 하는 때를 정리했습니다.
@ 오금동 도어락 번호판 버튼 먼지 점검

# 꽃가루와 황사가 번호판에 하는 일
번호판 버튼 사이에는 눈에 보이지 않는 틈이 있습니다. / 꽃가루와 황사 먼지는 입자가 곱고 끈적여서 그 틈에 달라붙기 쉽습니다.
비가 오거나 아침 이슬이 맺히면 먼지가 습기를 머금고 굳습니다. / 굳은 먼지가 버튼 아래 접점을 막으면 눌러도 반응이 약하거나 아예 먹통이 됩니다.
특히 현관문이 복도 바깥 쪽으로 열려 있는 구조에서는 바람이 직접 닿아 쌓이는 속도가 빠릅니다.

# 버튼이 안 눌릴 때 나타나는 증상 구분
같은 버튼 증상이라도 원인이 다를 수 있습니다. / 아래처럼 나누어 보면 무엇부터 할지 정하기 쉽습니다.
- 몇 개 버튼만 눌림이 둔한 경우: 먼지가 낀 것일 가능성
- 모든 버튼이 눌러도 소리가 안 나는 경우: 전원 문제 가능성
- 눌릴 때 소리는 나는데 입력이 안 되는 경우: 접점이나 기판 문제 가능성
- 버튼을 누른 채 돌아오지 않는 경우: 이물질이 눌어붙은 가능성
소리가 아예 없으면 먼저 배터리를 의심해야 합니다. / 이 경우는 청소보다 전원 확인이 먼저입니다.

# 마른 천으로 시작하는 청소 순서
가장 먼저 부드러운 마른 천으로 번호판 표면을 닦아 주세요. / 겉에 쌓인 가루를 털어 내는 것만으로도 눌림이 좋아지는 경우가 있습니다.
그다음 칫솔이나 부드러운 붓으로 버튼 사이 틈을 가볍게 쓸어 줍니다. / 힘을 주어 박박 문지르지 말고 먼지를 끄집어낸다는 느낌이면 충분합니다.
사용 중인 도어락에 물이나 세정제를 직접 뿌리는 것은 피해 주세요. / 액체가 틈으로 흘러들면 기판이 젖어 상태가 더 나빠집니다.
알코올이 약간 묻은 천으로 가볍게 닦는 정도는 괜찮지만 버튼 틈으로 들어가지 않게 조심해 주세요.

# 에어 스프레이 쓸 때 주의할 점
버튼 틈의 먼지는 압축 공기를 짧게 불어서 털어내는 방법도 있습니다. / 바로 가까이서 길게 쏘면 습기가 맺힐 수 있으니 멀리서 짧게 끊어 쓰는 편이 좋습니다.
스프레이를 쓴 뒤에는 잠시 두어 물기가 날아가게 합니다. / 곧바로 버튼을 눌러 보면 남은 습기 때문에 오입력이 날 수 있습니다.
청소 전에 도어락 안쪽 문을 열어 둔 상태에서 하시면 밖에서 문이 잠겨 곤란해지는 일이 없습니다. / 반드시 문이 열려 있고 집 안에 사람이 있는 상태에서 해 보세요.

# 청소해도 안 되면 배터리부터 다시 보세요
봄에 버튼이 둔해졌다고 생각했는데 사실은 배터리 전압이 떨어진 경우도 많습니다. / 전압이 낮으면 번호판이 어둡고 반응이 늦어집니다.
- 번호판 불빛이 평소보다 어두운지
- 버튼 소리가 전보다 작거나 느린지
- 문이 열릴 때 모터 소리가 약한지
이런 증상이 있으면 건전지 전체를 새것으로 바꿔 보세요. / 일부만 바꾸면 얼마 못 가 같은 증상이 돌아옵니다.
@ 오금동 도어락 번호판 청소 배터리 교체

# 하지 말아야 할 것
번호판 덮개를 임의로 분해하는 분들이 있습니다. / 나사를 풀고 안쪽을 닦으려다 방수 패킹이나 고무가 틀어져 오히려 빗물이 들어가기 쉬워집니다.
뾰족한 도구로 버튼 사이를 긁는 것도 피해야 합니다. / 표면 코팅이 벗겨지면 숫자가 지워지고 접점이 상합니다.
비밀번호를 여러 번 틀리면 도어락이 한동안 입력을 막습니다. / 눌림이 약해서 번호가 잘못 들어가고 있다면 몇 번 시도해 보고 멈추는 게 좋습니다.

# 문 앞에서 막혔을 때 전화 주세요
청소를 해도 버튼이 안 눌려서 문 앞에서 막혔다면 [군포 출장열쇠](gunpo.html)에 연락 주세요. / 전화로 번호판 상태와 소리를 말씀해 주시면 원인을 좁힐 수 있습니다.
- 오금동 어느 건물인지, 동·호수
- 안 눌리는 버튼이 일부인지 전부인지
- 소리와 불빛이 있는지
- 도어락 모양과 가능하면 사진
- 문 안에 누가 있는지
도어락 사진이 있으면 맞는 부품과 도구를 챙겨 갈 수 있습니다.

# 도착하면 신분 확인부터 합니다
문을 열기 전에 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
번거로우셔도 이웃을 위한 절차이니 이해해 주세요. / 신분증이 집 안에 있으면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다.

# 비용은 문 열기 전에 말씀드립니다
번호판과 문 상태를 본 뒤 비용을 먼저 말씀드리고, 동의하시면 시작합니다. / 마음에 안 드시면 그냥 돌아가셔도 됩니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭙니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 문을 연 뒤 번호판 상태를 같이 확인합니다
문이 열리면 버튼 하나하나 눌림과 소리, 불빛을 함께 확인합니다. / 청소만으로 돌아온다면 교체를 권하지 않습니다.
접점이 닳았거나 번호판이 노후한 경우에는 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 먼저 봅니다. / 그래도 어렵다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문을 연 방법이 궁금하면 [현관문 개문](door-open.html) 안내도 참고하세요.
@ 오금동 출장열쇠 번호판 점검 후 도어락 확인

# 봄이 오기 전에 해두는 관리 습관
꽃가루가 날리기 시작하는 시기를 기준으로 번호판을 한 번 닦아 두면 좋습니다. / 쌓이기 전에 닦으면 굳기 전이라 쉽게 떨어집니다.
- 이른 봄 한 번, 황사가 심한 날 직후 한 번 마른 천으로 닦기
- 현관 앞에 비가 들이치지 않는지 확인
- 번호판 아래 모서리의 물기 닦기
- 배터리는 해가 바뀔 때쯤 한 번에 교체
- 경고음이 울리면 그날 바로 확인
이 정도만 해도 번호판이 먹통이 되는 일은 많이 줄어듭니다.
가족이 함께 쓰는 집이라면 청소한 날짜를 메모해 두고 서로 알려 주세요. / 누가 언제 닦았는지 알면 이상이 생겼을 때 원인을 찾기 쉽습니다.

# 오금동 말고 군포 어디든 갑니다
오금동 가까운 산본동, 금정동, 당동, 당정동, 부곡동, 대야미동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에 정리해 두었고, 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
