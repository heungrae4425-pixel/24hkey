# 현관이 아니라 집 안쪽 문이 막히는 날
산본동 집에서 문 문제라고 하면 대개 현관문을 떠올립니다. / 하지만 베란다 문, 미닫이문, 방문 잠금장치가 말썽을 부리는 경우도 적지 않습니다.
산본역에서 가까운 생활권이고, 오래 쓴 집이라면 안쪽 문의 잠금장치도 세월을 타기 마련입니다. / 현관문처럼 급하지 않아 보여도 막상 안 열리면 생활이 불편해집니다.
이 글은 베란다와 미닫이, 방문 잠금이 안 열리거나 안 잠길 때 확인할 것을 정리했습니다. / 직접 해볼 수 있는 선과 맡겨야 하는 선을 나누어 적었습니다.
@ 산본동 베란다 미닫이문 잠금장치

# 문마다 잠금 방식이 다릅니다
같은 집 안에서도 문마다 잠금장치의 종류가 다릅니다. / 베란다 문은 보통 위아래 걸이나 돌리는 손잡이형, 방문은 버튼형이나 돌리는 형을 많이 씁니다.
미닫이문은 옆으로 미는 방식이라 고리나 걸림쇠가 걸리는 모양이 또 다릅니다. / 어떤 방식인지 모르면 설명이 어려우니 먼저 눈으로 구조를 확인하세요.
안쪽에서만 잠기는 것과 바깥에서도 열쇠로 열 수 있는 것이 있습니다. / 이 차이가 열 수 있는 방법을 결정합니다.

# 베란다 문이 안 열릴 때
베란다 문은 햇볕과 비바람을 직접 받아 틀이 변하기 쉽습니다. / 잠금 걸이가 처져서 문틀 구멍과 맞지 않는 경우가 가장 흔합니다.
손잡이를 돌려도 걸이가 빠지지 않는다면 문을 살짝 위로 들어 올리듯 밀면서 돌려 보세요. / 처진 문이 제 위치로 올라오면 걸이가 빠지기도 합니다.
겨울에는 금속이 수축하고 여름에는 문이 팽창해서 계절마다 잠금 위치가 조금씩 달라지기도 합니다. / 같은 시기마다 반복된다면 틀의 변형을 의심해 보세요.
유리를 세게 두드리거나 문틀을 치는 일은 절대 피하세요. / 유리가 깨지면 다치기 쉽고 원인 해결도 오히려 어려워집니다.

# 미닫이문 레일 점검
미닫이문이 뻑뻑하고 잠금이 안 맞는 이유는 레일 때문인 경우가 많습니다. / 바닥 레일에 쌓인 먼지와 머리카락이 바퀴를 막기도 합니다.
레일을 청소기로 빨아들이고 마른 천으로 닦은 뒤 문을 밀어 보세요. / 이것만으로 잠금 위치가 맞아지기도 합니다.
윤활제를 많이 뿌리면 먼지가 더 달라붙으니 소량만 쓰는 편이 낫습니다. / 바퀴가 닳았거나 파손된 경우는 부품 교체가 필요합니다. / 문을 억지로 밀면 레일에서 이탈해 유리문이 넘어질 수 있으니 조심하세요.

# 방문이 안에서 잠겨 버렸을 때
방문 잠금은 대부분 비상 해제 구멍이 있습니다. / 손잡이 바깥쪽에 작은 구멍이나 홈이 있는지 보세요.
가는 막대나 비상 핀으로 해제하는 방식이 있지만, 맞는 도구가 아니면 잠금 부품이 상할 수 있습니다. / 집에 해제 도구가 따로 있다면 그것으로 해보세요.
아이가 안에 있을 때는 놀라지 않게 문 너머로 계속 말을 걸어 주세요. / 이 경우는 꼭 먼저 말씀해 주시면 순서를 서둘러 맞춥니다.
@ 군포 출장열쇠 산본동 방문 잠금 해제

# 헛돌거나 걸리는 소리가 날 때
손잡이를 돌려도 반응이 없고 헛돈다면 내부 축이나 스프링이 빠진 것일 수 있습니다. / 이 경우 억지로 돌리면 부품이 더 망가집니다.
걸림 소리가 나면서 중간에 멈춘다면 걸쇠가 구멍에 끼었을 가능성이 있습니다. / 문을 살짝 밀거나 당기면서 돌려 위치를 바꿔 보세요.
손잡이가 아예 빠져 버렸다면 그대로 두고 연락하시는 편이 안전합니다. / 빠진 손잡이를 억지로 다시 끼우면 안쪽 부품이 밀려 들어가 문제가 커집니다. / 파편이 보이면 사진으로 남겨 주세요.

# 직접 해볼 수 있는 것과 아닌 것
직접 해볼 만한 것은 청소, 문 살짝 들어올리기, 비상 해제 구멍 사용 정도입니다. / 그 이상은 전문 도구가 필요합니다.
- 해볼 것: 레일 청소, 문을 위로 들어올리며 돌려 보기, 비상 해제 구멍 확인
- 하지 말 것: 망치 두드리기, 문틈에 칼이나 카드 넣기, 유리 두드리기
- 사진 찍기: 잠금장치 전체 모양과 문틈
모양이 낯설거나 힘이 들어간다면 멈추세요. / 무리하는 순간 고칠 부분이 늘어납니다.

# 연락하실 때 알려주실 것
[군포 출장열쇠](gunpo.html)에 문의하실 때는 아래를 알려주세요. / 어느 문인지만 정확해도 장비를 맞춰 갈 수 있습니다.
- 산본동 위치와 가까운 역 방향
- 베란다, 미닫이, 방문 중 어느 문인지
- 안쪽에서 잠겼는지 바깥에서 닫혔는지
- 사진과 증상(헛돎, 걸림, 소리)
집 안에 사람이 갇힌 건 아닌지도 꼭 말씀해 주세요. / 상황에 따라 우선순위가 바뀝니다.

# 사시는 분 확인은 여기서도 합니다
현관이 아닌 안쪽 문이어도 집에 들어가는 일이라 확인이 필요합니다. / 신분증 주소, 우편물, 관리사무소 확인 중 하나면 됩니다.
이미 집 안에 계신 상태에서 방문만 문제인 경우는 확인이 간단합니다. / 현관이 열려 있으면 거주 여부는 대화로도 어느 정도 확인됩니다.
그래도 증빙은 한 가지 준비해 두시면 서로 편합니다. / 집에 아무도 없고 현관까지 잠긴 상태라면 현관 개방부터 진행하게 됩니다.

# 비용은 시작하기 전에 말씀드립니다
문 상태와 잠금 종류를 본 뒤 먼저 비용을 말씀드립니다. / 동의하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 여쭙습니다.
자세한 진행 방식은 [이용안내](guide.html)에 있고, 문 개방은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 고쳐서 쓸지 바꿔야 할지
방문이나 베란다 잠금장치는 부품만 바꿔도 해결되는 경우가 많습니다. / 걸이 하나, 스프링 하나만 바꾸면 되는 일에 전체 교체를 권하지 않습니다.
문틀이 처졌다면 잠금이 아니라 경첩과 틀부터 맞춰야 합니다. / 이때는 [도어락 수리](doorlock-repair.html)로 상담하시는 게 좋습니다.
정말 낡았다면 [도어락 교체](doorlock-replace.html)로 새 제품을 말씀드립니다. / 이유를 먼저 설명드리고 선택은 맡깁니다.
@ 산본동 미닫이문 방문 잠금장치 수리

# 집 안 문을 오래 쓰는 방법
안쪽 문은 눈에 띄지 않아 방치하기 쉽습니다. / 한 해에 한두 번만 살펴도 큰 고장을 막을 수 있습니다.
- 베란다 문 레일과 손잡이 주변 청소
- 방문 손잡이가 헐겁지 않은지 점검
- 아이가 있는 집은 안에서 잠그는 장난을 함께 이야기하기
- 비상 해제 도구를 한 곳에 정해 두기
겨울 전에 한 번, 장마 전에 한 번 레일과 걸이를 닦아 주면 뻑뻑함이 훨씬 덜합니다. / 소리가 나기 시작하는 시점이 점검하기 가장 좋은 때입니다.
특히 어린 아이가 있다면 방문 잠금의 비상 해제 방법을 미리 알아 두세요. / 급할 때 허둥대지 않게 됩니다.

# 산본동 말고 군포 어디든
산본동 바로 옆 금정동, 당동, 당정동, 부곡동, 대야미동, 오금동도 24시간 출동합니다. / 군포 안이면 동네와 관계없이 갑니다.
군포에서 다니는 동네는 [군포시 출장열쇠](gunpo.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
