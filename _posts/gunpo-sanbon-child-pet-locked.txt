# 산본동에서 집 안에 아이만 있는 채로 문이 잠겼다면
택배를 받으러 잠깐 나왔다가 문이 닫혔는데, 집 안에는 아이가 혼자 있는 상황입니다. / 가장 급하고 가장 무서운 경우입니다.
이런 때는 문을 여는 방법보다 먼저 안에 있는 사람을 안심시키는 것이 중요합니다. / 이 글은 그 순서를 적었습니다.
반려동물이 안에 있는 경우도 같은 방식으로 판단하시면 됩니다. / 전화는 [군포 출장열쇠](gunpo.html)로 바로 주세요.
@ 산본동 아이 반려동물 문 잠김 출장열쇠

# 가장 먼저 할 일
침착하게 아래 순서를 따라 주세요. / 숨을 한 번 고르고 시작하시면 됩니다.
- 문 너머로 아이에게 계속 말을 걸어 안심시키기
- 아이가 있는 위치와 상태 확인하기
- 안에서 문을 열 수 있는 나이인지 판단하기
- 위급 상황이면 먼저 119에 연락하기
열쇠집을 부르는 것보다 안에 있는 아이가 위험한 상태인지가 먼저입니다. / 연기, 가스, 아이의 울음이 멈추지 않는 등의 신호가 있다면 119가 우선입니다.

# 아이가 안에서 열 수 있다면
아이가 어느 정도 컸다면 안쪽 손잡이를 돌려 열어 달라고 알려 줄 수 있습니다. / 안쪽에서는 열쇠 없이 돌려서 열 수 있는 문이 많습니다.
보조키나 걸이가 걸려 있다면 그걸 먼저 풀어야 합니다. / 문 너머로 한 가지씩 천천히 설명하세요.
조급하게 재촉하면 아이가 더 놀라 아무것도 못 하기도 합니다. / 칭찬하며 말을 이어 가세요.
@ 산본동 아이 혼자 있는 집 문 열기

# 아이가 너무 어린 경우
아직 말귀를 잘 못 알아듣는 아이라면 직접 열 수 없습니다. / 이럴 땐 시간을 지체하지 말고 바로 출장을 부르는 것이 좋습니다.
전화로 아이 나이와 집 안 상황을 먼저 말씀해 주세요. / 우선순위를 두고 가장 빨리 갈 수 있는 방법으로 안내드립니다.
아이를 놀라게 하지 않는 것이 중요하니 문을 두드리거나 소리를 크게 내는 건 피해 주세요. / 문 너머로 낮은 목소리로 계속 말해 주세요.

# 반려동물만 있을 때
반려동물만 있는 경우 급하지는 않지만 더운 날이나 추운 날엔 시간이 중요합니다. / 물이나 난방 상태도 생각해 보세요.
강아지는 문 앞에서 짖거나 긁어서 문이나 도어락이 손상되기도 합니다. / 문 안쪽에서 번호판을 건드릴 일은 드뭅니다.
고양이는 문 앞에 가까이 와서 소리를 내는 경우가 많습니다. / 주인 목소리를 들려 주면 안정이 되는 경우가 많습니다.

# 하지 말아야 할 것
창문이나 베란다로 넘어 들어가려는 시도는 매우 위험합니다. / 저층이라도 추락 사고가 날 수 있습니다.
문을 발로 차거나 세게 밀지 마세요. / 문이 휘어 오히려 더 안 열리고 아이가 놀랍니다.
드라이버로 문틈을 벌리는 일도 하지 마세요. / 도어락과 문틀이 상하고 안에서도 더 위험해질 수 있습니다.
이웃에게 도움을 청하는 건 괜찮습니다. / 여분 열쇠를 맡겨 둔 곳이 있다면 가장 빠릅니다.

# 전화하실 때 꼭 알려주세요
산본동 어느 건물이고 몇 호인지 알려주세요. / 먼저 아이나 반려동물 이야기부터 해 주세요.
- 안에 누가 있는지 (아이 나이, 반려동물 종류)
- 안에서 소리가 나는지, 조용한지
- 문이 잠긴 지 얼마나 됐는지
- 번호판과 도어락 상태
- 지금 바로 도착 가능한 위치인지
이 정보를 먼저 들으면 가장 빠르게 출동 순서를 정할 수 있습니다.

# 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 급한 상황이라도 이 절차는 꼭 필요합니다.

# 비용은 열기 전에 말씀드립니다
상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
@ 군포 출장열쇠 산본동 문 열기

# 안전하게 여는 방법
문을 열 때는 안에 있는 사람이 놀라지 않게 하는 것이 먼저입니다. / 소리를 크게 내거나 급하게 힘을 쓰지 않습니다.
덜 상하는 방법부터 차례로 해봅니다. / 도어락 종류에 따라 시간이 달라질 수 있습니다.
문이 열린 뒤에는 아이를 먼저 확인하시고 놀란 마음을 풀어 주세요. / 문 열기 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 열고 난 뒤에 할 일
문이 열리면 도어락이 정상인지 같이 확인합니다. / 아이가 안에서 보조키를 돌려 잠근 것이라면 그 위치와 높이를 점검합니다.
아이 손이 닿는 곳에 보조키 레버가 있다면 높이를 바꾸거나 덮개를 다는 것을 권합니다. / 같은 일이 반복되지 않도록 도와드립니다.
도어락에 오작동이 있었다면 [도어락 수리](doorlock-repair.html)로 점검합니다.

# 같은 일을 막는 방법
집 밖에 잠깐 나갈 때도 습관을 정해 두면 도움이 됩니다. / 아래 방법을 권합니다.
- 문을 닫기 전에 열쇠나 카드를 손에 쥐고 나가기
- 현관 밖에 짐을 둘 때 문을 완전히 닫지 않고 문고리에 고정하기
- 아이가 혼자 있을 땐 보조키를 잠그지 않기
- 가까운 가족이나 이웃에게 여분 열쇠를 맡기기
- 스마트폰으로 열 수 있는 방식도 고려하기

# 산본동 말고 군포 어디든
산본동 바로 옆 금정동, 당정동, 당동, 부곡동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
군포 전체 정리는 [군포시 출장열쇠](gunpo.html)에 있고, 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
