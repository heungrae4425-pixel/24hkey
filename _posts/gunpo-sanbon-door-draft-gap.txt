# 문을 닫았는데 바람 소리가 들린다면
날이 쌀쌀해지는 11월이면 산본역에서 돌아와 현관에 들어서자마자 찬 기운이 느껴지는 집이 있습니다. / 문을 닫아도 틈새로 쌩 하는 바람 소리가 난다면 문 상태를 한번 살펴볼 때입니다.
틈새 바람은 단순히 춥다는 문제에서 끝나지 않고, 소음과 먼지, 문 잠김 불량까지 이어지기도 합니다.
이 글은 산본동 현관문 틈새와 닫힘 상태를 집에서 점검하는 방법과, 손보는 일이 필요할 때 [군포 출장열쇠](gunpo.html)에 요청하는 순서를 적었습니다.
@ 산본동 현관문 틈새 바람 점검

# 틈새가 생기는 흔한 이유
현관문 틈은 한 가지 이유로만 생기지 않습니다. / 아래 중 어디에 가까운지 보면 손볼 곳이 보입니다.
- 오래 쓰며 경첩이 처져 문이 한쪽으로 기운 경우
- 문틀 가장자리의 고무 패킹이 굳거나 떨어진 경우
- 걸쇠가 받이 홈에 끝까지 들어가지 않는 경우
- 문틀이 계절에 따라 줄었다 늘었다 한 경우
가장 쉽게 눈에 띄는 것은 고무 패킹입니다. / 갈라지거나 납작하게 눌려 있으면 틈을 막아 주는 역할이 줄어든 상태입니다.

# 종이 한 장으로 틈을 확인하는 법
도구가 없어도 간단히 확인할 수 있습니다. / A4 종이 한 장을 문틈에 끼우고 문을 닫아 보세요.
종이가 쑥 빠지면 그 자리가 헐겁다는 뜻이고, 팽팽하게 물려 있으면 괜찮습니다. / 위쪽, 가운데, 아래쪽, 경첩 쪽을 돌아가며 해 보세요.
종이로 확인한 결과를 메모해 두면 전화할 때 도움이 됩니다. / 한 곳만 헐렁하면 경첩이나 걸쇠 위치를 의심하고, 전체가 다 헐렁하면 패킹 문제일 가능성이 큽니다.
@ 군포 문틈 종이 확인 문 닫힘 점검

밤에는 문 안쪽에 서고 바깥에서 손전등을 비춰 달라고 부탁해 보세요. / 빛이 새어 들어오는 곳이 곧 틈입니다.
혼자라면 현관 바깥 복도 등이 켜진 상태에서 안쪽 불을 끄고 보면 됩니다. / 아래쪽 문턱 쪽으로 빛이 새는 경우도 많습니다.
빛이 새는 곳과 바람이 들어오는 곳이 같은지 비교해 보면 원인이 더 분명해집니다.

# 문이 덜 닫히고 걸쇠가 툭 걸린다면
문을 밀어 닫았는데 걸쇠가 끝까지 안 들어가고 중간에 걸리는 경우가 있습니다. / 이럴 때는 번호를 눌러도 잠금이 어정쩡해 보입니다.
문틀 받이 홈이 닳았거나 경첩이 처져 걸쇠 높이가 어긋난 경우가 대부분입니다. / 억지로 세게 닫는 습관이 오래되면 도어락 쪽에도 부담이 갑니다.
- 문을 닫고 손잡이를 돌려 걸쇠가 들어가는 소리가 나는지
- 문을 닫은 상태에서 밀면 덜컹거리는지
- 문 끝이 문틀에 닿아 긁힌 자국이 있는지
문 가장자리에 칠이 벗겨진 자리가 있다면 그곳이 닿는 곳입니다. / 이 세 가지를 확인하면 전화 상담이 훨씬 쉬워집니다.

# 틈새 바람과 소음이 도어락에 미치는 영향
찬바람이 계속 들어오면 번호판 안쪽에 결로가 생기기 쉽습니다. / 결로가 반복되면 번호 반응이 둔해지거나 오작동이 생깁니다.
문이 흔들리면서 도어락 나사가 조금씩 풀리기도 합니다. / 손잡이가 헐거워졌다면 [도어락 수리](doorlock-repair.html)로 먼저 확인해 보세요.
현관에 서서 복도 소리가 얼마나 들리는지 들어 보면 닫힘 상태를 가늠할 수 있습니다. / 소음도 비슷합니다. / 복도 소리가 그대로 들어오는 집은 대개 닫힘 상태가 헐거운 경우입니다.

# 집에서 해볼 수 있는 응급 조치
전문적인 작업 전에 해볼 수 있는 간단한 방법이 있습니다.
- 굳은 패킹은 물걸레로 먼지를 닦아 주기
- 느슨한 도어락 나사는 맞는 드라이버로 살짝 조이기
- 문턱 아래 틈에는 시중 문풍지를 임시로 붙이기
- 문이 잘 안 닫히면 경첩 나사 조임 상태 보기
나사를 너무 세게 조이면 오히려 상하니 손에 느껴질 만큼만 조여 주세요. / 어렵게 느껴지면 손대지 말고 연락 주시는 게 안전합니다. / 임시로 붙인 문풍지는 나중에 점검할 때 떼기 쉬운 종류로 고르세요. / 접착제가 문틀에 남으면 닦기 힘듭니다.

# 하지 않는 편이 좋은 것
틈이 크다고 문 옆에 두꺼운 테이프를 겹겹이 붙이는 방법은 오래 못 갑니다. / 문 닫을 때 걸려 오히려 걸쇠 위치를 더 어긋나게 합니다.
문틀을 칼로 깎거나 걸쇠 받이를 무리해서 늘리는 것도 피해 주세요. / 한 번 깎은 문틀은 되돌릴 수 없습니다.
문이 안 닫혀서 열쇠로 잠가 두는 분도 있는데, 이러면 비상시 문이 안 열리는 사고로 이어집니다.

# 점검을 요청할 때 알려주실 것
산본동 어느 방향이고 산본역에서 가까운지 등 위치를 알려주시고, 아래도 같이 말씀해 주세요.
- 틈이 생긴 곳 (위, 아래, 경첩 쪽, 손잡이 쪽)
- 바람, 소음, 덜컹거림 중 어떤 증상인지
- 문을 닫을 때 걸쇠 소리가 나는지
- 도어락 종류와 사진
- 문이 최근에 처졌는지, 오래전부터인지
사진은 문을 닫은 상태에서 틈이 보이는 곳을 가까이 찍어 보내주시면 좋습니다.

# 도착하면 신분 확인을 합니다
문 점검이라도 집에 들어가는 일이라 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업할 수 없으니 미리 준비해 두시면 좋습니다. / 신분증이 집 안에 있다면 경비실에 확인을 부탁해 보세요.
@ 산본동 출장열쇠 문 닫힘 점검

# 비용은 점검 후 시작 전에 말씀드립니다
문을 직접 보고 어떤 작업이 필요한지 정한 뒤 얼마인지 먼저 말씀드립니다. / 괜찮으시면 시작하고, 아니시면 그냥 돌아갑니다.
작업 중 다른 부품이 필요하면 하기 전에 다시 여쭙니다. / 말없이 붙는 비용은 없습니다.
점검만으로 정리되는 경우에는 부품 교체를 권하지 않습니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 틈새 점검 후 문이 안 열릴 때를 대비해서
문을 손보는 중에 걸쇠 위치가 바뀌면 안쪽에서 열리지 않는 일이 간혹 있습니다. / 이런 경우 [현관문 개문](door-open.html) 방법으로 문을 상하지 않게 엽니다.
문을 못 열면 비용은 받지 않는 원칙은 같습니다.
문을 만지다 보면 번호판 쪽 이상이 같이 발견되기도 하니 도어락 상태도 함께 말씀해 주세요. / 도어락까지 새로 달고 싶다면 [도어락 교체](doorlock-replace.html)에서 교체 전에 보는 것들을 먼저 읽어 보세요.

# 겨울 오기 전에 해두면 좋은 습관
- 환기하면서 문틈 주위 먼지와 물기 닦기
- 한 달에 한 번 경첩 나사 손으로 만져 보기
- 도어락 건전지를 겨울 전에 새것으로 바꾸기
- 문 닫을 때 손으로 받치며 천천히 닫기
겨울 전에 한 번 닦고 조여 두는 것만으로도 올겨울이 훨씬 따뜻합니다. / 작은 점검이 쌓이면 문이 오래 갑니다. / 틈새 바람은 바로 고치면 간단하지만 미루면 도어락까지 번집니다.

# 산본동 말고 군포 어디든 갑니다
산본동 가까이 금정동, 당동, 당정동, 부곡동, 대야미동, 오금동도 다닙니다. / 군포 안이면 24시간 출동합니다.
다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
