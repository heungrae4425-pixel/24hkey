# 산본동에서 문을 열기 전에 꼭 확인하는 것
산본동은 산본역 일대 아파트 단지와 빌라가 넓게 이어진 동네입니다. / 사는 분이 많은 만큼 문이 안 열려 연락 주시는 일도 꾸준합니다.
출장열쇠가 도착하면 문을 열기 전에 반드시 한 가지를 확인합니다. / 지금 문을 열어 달라고 하시는 분이 그 집에 사는 분이 맞는지 하는 것입니다.
처음 들으면 번거롭다고 느끼실 수 있지만 모두를 위한 절차입니다. / 이 글은 [군포 출장열쇠](gunpo.html)가 왜 이 확인을 하는지, 무엇을 준비하면 되는지 적었습니다.
@ 산본동 출장열쇠 신분 확인 안내

# 신분 확인을 하는 이유
문을 여는 일은 잘못 하면 남의 집에 들어가게 도와주는 일이 될 수 있습니다. / 그래서 아무리 급한 상황이어도 사는 분인지 확인하는 과정을 건너뛰지 않습니다.
확인 절차는 문 앞에서 거짓말을 하는 사람을 막기 위한 것만은 아닙니다. / 실제로 사는 분이 문 앞에서 막혔을 때 이웃이 불안해하지 않도록 하는 의미도 있습니다.
산본동처럼 이웃과 가까운 단지에서는 낯선 사람이 문을 만지고 있으면 신고가 들어오기도 합니다. / 신분 확인을 하고 시작하면 이런 오해를 줄일 수 있습니다.

# 인정되는 서류는 이런 것들입니다
가장 간단한 것은 주소가 적힌 신분증입니다. / 주민등록증이나 운전면허증처럼 주소 확인이 가능한 것이면 됩니다.
신분증에 현재 주소가 없다면 다른 서류로 보충할 수 있습니다. / 아래 중 하나만 있어도 확인이 진행되는 경우가 많습니다.
- 현재 주소가 나온 우편물이나 고지서
- 관리사무소에서 해주는 세대 확인
- 휴대폰에 저장된 주소 확인 서류
- 임대차 계약서와 신분증을 함께 확인
어떤 서류가 인정되는지는 현장 상황에 따라 안내해 드립니다. / 가능한 방법을 같이 찾아 드리니 처음부터 걱정하지 않으셔도 됩니다.

# 신분증이 집 안에 있다면
문이 안 열려서 신분증도 집 안에 두고 나온 분이 꽤 많습니다. / 이럴 때 가장 먼저 해볼 수 있는 방법은 관리사무소에 세대 확인을 부탁하는 것입니다.
산본동 아파트 단지는 대부분 관리사무소에서 입주민 확인이 가능합니다. / 늦은 시간이라면 경비실에 먼저 말해 두시면 확인이 수월합니다.
휴대폰 안에 신분증 사진이나 모바일 신분증이 있다면 그것도 확인에 도움이 됩니다. / 가능한 범위를 현장에서 설명드립니다.
@ 산본동 문 열기 신분 확인 관리사무소

# 세입자인 경우에도 확인은 같습니다
세입자 분들이 집주인 허락이 필요한지 자주 물으십니다. / 사시는 분이 맞는지만 확인되면 됩니다.
임대차 계약서가 있다면 신분증과 함께 보여 주시면 확인이 더 쉽습니다. / 계약서를 못 찾더라도 우편물이나 관리사무소 확인으로 대신할 수 있습니다.
집주인이 문을 열어 달라고 요청하는 경우에는 사는 분이 직접 오거나 동의했는지를 확인합니다. / 세입자가 사는 집을 집주인이 임의로 열게 하는 것은 곤란하기 때문입니다.

# 확인이 어려울 때는 어떻게 하나요
서류를 하나도 구하지 못하는 경우도 있습니다. / 이런 때는 작업을 서두르지 않고 가능한 방법을 같이 찾습니다.
가족이 서류를 가지고 올 수 있는지, 경비실이나 관리사무소에서 도와줄 수 있는지 먼저 봅니다. / 그래도 확인할 방법이 없다면 문을 열지 않고 돌아갈 수 있습니다.
이 경우에도 문을 못 열었으므로 비용은 받지 않습니다. / 안전을 위해 확인이 끝난 뒤에만 작업한다는 점을 이해해 주세요.

# 신분 확인에 쓴 정보는 어떻게 하나요
확인을 위해 보여 주신 신분증이나 서류는 사시는 분인지 알아보는 데만 씁니다. / 필요 이상으로 사진을 찍거나 보관하지 않습니다.
이름이나 주소를 다른 용도로 쓰는 일은 없습니다. / 불안하시면 현장에서 어떻게 확인하는지 직접 물어보셔도 좋습니다.
확인 방식은 [이용안내](guide.html)에도 적어 두었습니다. / 미리 한 번 읽어 보시면 막상 문 앞에서 당황하지 않습니다.
@ 군포 출장열쇠 산본동 문 열기 상담

# 이웃이 지나가며 물어보면
단지에서는 문 앞에서 작업을 하는 동안 이웃이 지나가며 무슨 일인지 묻기도 합니다. / 이럴 때 사시는 분이 직접 상황을 설명해 주시면 오해가 금방 풀립니다.
신분 확인을 마친 상태라면 저희도 떳떳하게 작업 내용을 설명드릴 수 있습니다. / 이웃이 걱정하는 것은 당연한 일이니 서운해하지 않으셔도 됩니다.
필요하면 관리사무소나 경비실에 작업 사실을 미리 알려 두는 방법도 좋습니다. / 그러면 늦은 시간에도 불필요한 연락이 오가지 않습니다.

# 미리 해두면 좋은 준비
평소에 신분증 사진을 휴대폰에 저장해 두면 급할 때 도움이 됩니다. / 다만 이런 사진은 다른 사람에게 함부로 보여 주지 않도록 관리하세요.
집 주소가 찍힌 우편물 한 장을 가방에 넣어 다니는 분도 계십니다. / 번거롭다면 관리사무소 연락처만이라도 저장해 두세요.
가족 중 한 명이 집에 있다면 그 가족에게 서류를 가져다 달라고 부탁할 수도 있습니다. / 문을 사이에 두고 전화로 이야기하면서 준비하시면 됩니다.

# 전화할 때 알려 주실 것
연락 주실 때 산본동 어느 쪽인지, 단지나 건물 이름, 동과 호수를 말씀해 주세요. / 신분 확인 방법도 함께 상의하면 도착 후 시간이 줄어듭니다.
번호는 010-3664-5455입니다. / 24시간 받으니 새벽이라도 편하게 연락 주세요.
통화가 끝나면 예상 도착 시간을 말씀드립니다. / 상황이 바뀌면 바로 알려 주시길 바랍니다.

# 확인이 끝나면 비용부터 안내합니다
신분 확인이 끝나면 문과 도어락 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 현관문 개문 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 개방 뒤에는 이렇게 마무리합니다
문이 열리면 도어락이 잘 작동하는지 같이 확인합니다. / 비밀번호를 잊어서 연 경우라면 새 번호 등록까지 도와드립니다.
기존 번호는 지우고 새 번호만 남겨 둡니다. / 배터리가 문제였다면 새것으로 바꿨는지도 확인합니다.
고장이 잦다면 [도어락 수리](doorlock-repair.html)를 먼저 권하고, 너무 오래됐다면 그때 교체를 말씀드립니다. / 무리하게 새 제품을 권하지 않습니다.

# 산본동 말고 군포 어디든 갑니다
산본동 바로 옆 금정동, 당동, 당정동, 부곡동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
군포에서 다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
