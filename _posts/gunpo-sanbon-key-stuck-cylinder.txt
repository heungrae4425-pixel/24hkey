# 산본동에서 열쇠가 안 돌아갈 때
열쇠를 꽂았는데 반쯤 돌다가 걸리거나, 아예 꿈쩍도 하지 않는 일이 있습니다. / 더 곤란한 경우는 열쇠를 돌리다 보니 이번에는 빠지지 않는 상황입니다.
산본역에서 집까지 걸어와 문 앞에 서서 이런 일을 겪으면 마음이 급해집니다. / 이럴수록 힘을 쓰기보다 상태를 먼저 보는 편이 결과가 좋습니다.
이 글은 산본동에서 열쇠가 안 돌아가거나 안 빠질 때 해도 되는 일과 하면 안 되는 일을 나눠 적었습니다. / 그다음 [군포 출장열쇠](gunpo.html)가 어떻게 진행하는지도 정리했습니다.
지금 열쇠를 꽂은 채 서 계신다면 열쇠를 돌리던 손부터 놓아 주세요. / 2번부터 읽으시면 바로 쓸 수 있습니다.
@ 산본동 출장열쇠 열쇠 안 돌아감

# 먼저 열쇠에서 손을 떼세요
열쇠가 걸린 상태에서 계속 돌리면 열쇠가 휘거나 부러질 수 있습니다. / 열쇠가 안에서 부러지면 일이 한 단계 더 커집니다.
힘을 주는 방향도 중요합니다. / 열쇠를 돌리는 힘과 같은 방향으로 더 세게 밀어붙이면 내부 부품에 무리가 갑니다.
한 번 숨을 돌리고 열쇠를 살짝 뒤로 당겼다가 다시 천천히 꽂아 보세요. / 이 정도로 돌아가는 경우도 있으니 먼저 한 번만 시도하세요.

# 안 돌아가는 흔한 원인 네 가지
첫째는 열쇠 자체가 닳은 경우입니다. / 복사본을 여러 번 복사해서 쓰면 홈이 조금씩 달라져 잘 안 돌아갑니다.
둘째는 열쇠구멍 안에 먼지와 이물질이 쌓인 경우입니다. / 오래 쓴 문은 안쪽에 쌓인 먼지가 핀을 눌러 걸리게 합니다.
셋째는 문이 처져서 걸쇠가 문틀에 눌려 있는 경우입니다. / 이때는 열쇠가 문제가 아니라 문 위치가 문제입니다.
넷째는 안쪽 보조키나 잠금 장치가 이미 잠겨 있는 경우입니다. / 밖에서 열쇠를 돌려도 안쪽 장치가 막고 있으면 열리지 않습니다.

# 문을 살짝 밀면서 돌려 보세요
걸쇠가 문틀에 눌려 있으면 열쇠를 돌릴 때 힘이 더 듭니다. / 이럴 때 문을 안쪽으로 살짝 밀면서 열쇠를 돌리면 걸쇠가 풀리며 쉽게 돌아갈 수 있습니다.
반대로 문을 당기면서 돌리면 오히려 더 꽉 물립니다. / 방향을 바꿔 가며 두 번 정도만 시도하고, 그래도 안 되면 멈추세요.
산본동처럼 오래된 단지는 문이 조금씩 처진 집이 많아 이 방법이 통할 때가 종종 있습니다. / 억지로 힘을 쓰지 않는 선에서만 해 보세요.
@ 군포 산본동 열쇠구멍 현관 도어락

# 기름과 이물질은 조심하세요
열쇠구멍에 일반 기름을 넣는 분이 많습니다. / 처음엔 부드러워지는 것 같지만 먼지가 달라붙어 나중에 더 심하게 걸립니다.
전용 윤활제도 많이 뿌리면 내부에서 굳을 수 있습니다. / 쓰시더라도 아주 소량만 쓰고, 도어락 전자 부품 쪽에는 닿지 않게 하세요.
바늘이나 철사 같은 것을 열쇠구멍에 넣어 보는 것은 하지 마세요. / 안에 걸려 빠지지 않거나 내부 부품이 상해 교체까지 가는 경우가 있습니다.

# 열쇠가 안 빠질 때는 더 신중하게
열쇠가 돌아간 상태에서 빠지지 않는다면 열쇠를 원래 위치로 돌려 놓고 빼 보세요. / 돌아간 위치에서는 열쇠 홈이 핀을 누르고 있어 빠지지 않는 구조가 많습니다.
원위치에서도 안 빠지면 열쇠를 위아래로 아주 살짝 흔들면서 당겨 보세요. / 이때도 힘을 세게 주지 말고 살살 시도해야 합니다.
펜치로 열쇠를 잡고 당기는 분도 있는데, 열쇠가 부러질 위험이 큽니다. / 부러지면 구멍 안에 조각이 남으니 어느 정도 해 보고 안 되면 전화 주세요.

# 이런 경우는 바로 전화 주세요
- 열쇠를 돌리자 딱 소리가 나고 이후로 아예 움직이지 않는 경우
- 열쇠가 휘었거나 끝이 상한 것이 눈에 보이는 경우
- 열쇠구멍이 헐거워서 열쇠가 구멍 안에서 흔들리는 경우
- 안쪽에 아이나 반려동물이 있어 빨리 열어야 하는 경우
- 열쇠를 돌려도 문은 그대로인데 잠금 소리만 들리는 경우
이런 상황에서는 시도할수록 상태가 나빠집니다. / 상황을 말씀해 주시면 출동 여부와 걸리는 시간을 바로 알려드립니다.

# 출장열쇠가 오면 이렇게 진행합니다
도착하면 열쇠와 열쇠구멍 상태를 먼저 눈으로 확인합니다. / 어디서 걸리는지 보고 열쇠 문제인지 잠금장치 문제인지 가립니다.
열쇠가 원인이면 맞는 열쇠를 새로 만들어 쓸 수 있는지 봅니다. / 열쇠 쪽 작업은 [출장 열쇠](key-call.html) 안내에 적어 두었습니다.
잠금장치 쪽이 원인이면 문을 최대한 안 상하게 연 뒤 부품을 손봅니다. / 개문 방식은 [현관문 개문](door-open.html) 페이지에 설명해 두었습니다.

# 문을 열기 전에 신분을 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집 주인 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두면 수월합니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 열쇠 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열쇠 문제를 줄이는 평소 습관
열쇠를 복사할 때는 원본에서 복사하고, 복사본에서 또 복사하지 않는 것이 좋습니다. / 복사를 거듭할수록 홈이 미세하게 달라져 잘 안 돌아가게 됩니다.
열쇠가 뻑뻑해지기 시작하면 완전히 안 돌아가기 전에 점검받으세요. / 그때 손보면 시간도 짧고 문도 덜 상합니다.
열쇠고리에 열쇠를 너무 많이 달아 두면 무게 때문에 열쇠구멍이 닳기도 합니다. / 현관 열쇠는 따로 빼 두는 것도 방법입니다.
@ 산본동 열쇠 복사 출장 24시

# 산본동 말고 군포 어디든 갑니다
산본동 바로 옆 금정동, 당동, 당정동, 부곡동, 대야미동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
군포 전체 출장 안내는 [군포시 출장열쇠](gunpo.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 열쇠가 부러져 박힌 경우도 오시나요? | 네, 부러진 조각을 빼는 작업도 합니다. 억지로 빼지 말고 그대로 연락 주세요.
? 늦은 밤에도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.

? 열쇠를 새로 만들어 주시나요? | 네, 열쇠 상태를 보고 필요하면 새로 만들어 드립니다.
