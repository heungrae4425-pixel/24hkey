# 산본동 전월세 집에서 도어락이 말썽일 때
산본동은 산본역을 중심으로 아파트와 빌라가 이어진 동네라 전월세로 사는 분들도 많습니다. / 그만큼 도어락이 갑자기 고장 났을 때 누가 어떻게 처리해야 하는지 몰라 당황하는 일도 자주 생깁니다.
집주인에게 먼저 말해야 할지, 내가 바로 열쇠집을 불러도 되는지 헷갈리는 분이 많습니다. / 이 글은 문 앞에서 막혔을 때 순서를 어떻게 잡으면 좋은지 정리한 글입니다.
특정 상황의 책임을 가려 드리는 글은 아닙니다. / 계약서에 적힌 내용과 집주인과의 합의가 우선이라는 점을 먼저 말씀드립니다.
급하게 문이 안 열리는 상황이라면 아래 순서대로 보시면 됩니다. / 군포 안에서는 [군포 출장열쇠](gunpo.html)로 24시간 연락 주셔도 됩니다.
@ 산본동 출장열쇠 전월세 도어락 점검

# 지금 문이 안 열린다면 먼저 할 일
문 앞에 서 있는 상황에서는 책임 문제보다 문을 여는 일이 먼저입니다. / 집 안에 아이나 반려동물, 불을 켜 둔 가스레인지가 있는지부터 떠올려 보세요.
번호판 불이 아예 꺼져 있으면 배터리 문제일 가능성이 큽니다. / 편의점에서 9V 건전지를 구해 비상 단자에 대 보시고, 그래도 안 되면 전화 주세요.
무리하게 손잡이를 당기거나 문틈에 도구를 넣으면 문과 도어락이 상합니다. / 나중에 원상복구 이야기가 나올 수 있으니 상하지 않게 여는 것이 세입자에게도 이롭습니다.

# 계약서와 집주인 연락처 먼저 챙기기
도어락 고장이 단순 배터리가 아니라 부품 문제라면 수리나 교체가 필요합니다. / 이때 비용을 누가 낼지는 계약서 특약과 집주인과의 협의에 따라 달라집니다.
그래서 작업을 시작하기 전에 집주인에게 상황을 알리고 의견을 들어 두면 나중에 다툴 일이 줄어듭니다. / 문을 먼저 열어 두고 이야기하는 편이 마음이 편하다는 분도 많습니다.
- 계약서에 적힌 수리·교체 관련 내용이 있는지
- 집주인이나 관리인의 연락처가 휴대폰에 있는지
- 도어락이 처음부터 달려 있던 것인지, 세입자가 달았던 것인지
- 최근에 고장 신호(경고음, 느린 반응)가 있었는지

# 고장 원인을 나눠서 보면 정리가 쉽습니다
배터리가 다 된 경우는 소모품이라 보통 사시는 분이 교체합니다. / 메인 부품이 오래돼서 고장 난 경우는 수리나 교체 이야기가 필요합니다.
세입자가 잘못 만져 생긴 고장인지, 오래 써서 낡은 것인지에 따라 서로의 입장이 다를 수 있습니다. / 그래서 작업 전에 도어락 상태를 사진으로 남겨 두면 설명이 쉬워집니다.
출장열쇠 기사에게 "원인이 무엇으로 보이는지" 물어보셔도 좋습니다. / 눈으로 확인한 범위에서 알려드리고, 확실하지 않은 부분은 단정하지 않습니다.

# 문 열기 전 사시는 분 확인
세입자든 집주인이든 문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
임대차 계약서와 신분증을 같이 보여주시면 확인이 더 빠릅니다. / 집주인이 현장에 오지 못하더라도 거주 사실만 확인되면 작업할 수 있습니다.
확인이 어려운 상황이면 작업을 하지 못할 수 있습니다. / 미리 챙겨 두시면 늦은 시간에도 순조롭습니다.
@ 산본역 근처 출장열쇠 현관문 개문

# 비용은 열기 전에 먼저 말씀드립니다
현관문 상태와 도어락 종류를 보고 비용을 먼저 안내해 드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 집주인과 상의가 필요하다면 그 시간을 기다려 드립니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 문을 상하지 않게 여는 이유
전월세 집은 퇴거할 때 원상태를 확인하는 일이 있어서 문과 도어락에 흠이 생기면 곤란합니다. / 그래서 덜 상하는 방법부터 차례로 해보는 것이 기본입니다.
도어락 종류와 문 상태에 따라 시간이 다르고, 작업 중 부품 교체가 필요해 보이면 손대기 전에 말씀드립니다. / 어떤 방식으로 여는지는 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

도어락이 꼭 새것이어야 하는 것은 아닙니다. / 배터리 접점, 모터, 버튼 등 일부만 손봐도 다시 잘 쓰는 경우가 있습니다.
집주인 입장에서도 수리로 해결되면 부담이 적습니다. / 그래서 [도어락 수리](doorlock-repair.html)로 먼저 점검하고, 너무 오래돼서 불안하면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
교체를 하더라도 새 제품을 누가 정할지, 기존 제품은 누가 보관할지 미리 이야기해 두면 좋습니다.

# 세입자가 도어락을 직접 달고 싶을 때
세입자가 도어락을 새로 달고 싶은 경우에는 먼저 집주인의 동의를 받아 두는 편이 안전합니다. / 나중에 퇴거할 때 기존 도어락을 되돌려 달라는 이야기가 나올 수 있기 때문입니다.
기존 도어락과 문 구멍 규격이 맞는지도 확인해야 합니다. / 자세한 점검 포인트는 [도어락 설치](doorlock-install.html) 페이지에 적어 두었습니다.
기존 제품을 떼어 낸 뒤 보관해 두면 퇴거 때 편합니다.

# 퇴거할 때 도어락 정리
이사를 나갈 때는 내 비밀번호와 카드키를 모두 지우고 나가야 마음이 편합니다. / 등록해 둔 지문이나 카드가 남아 있으면 다음 사람과의 문제가 될 수 있습니다.
비밀번호를 초기화하는 방법을 모른다면 퇴거 전에 미리 문의해 주세요. / 도어락 종류마다 방식이 달라서 모델명을 알려주시면 안내가 빠릅니다.
열쇠와 카드키를 몇 개 받았는지, 몇 개를 돌려주는지 기록해 두면 오해가 줄어듭니다.

# 산본동에서 위치는 이렇게 알려주세요
산본동은 단지와 동 번호가 많아서 위치를 정확히 알려주시면 도착이 빨라집니다. / 아파트 이름이나 건물 이름, 동, 호수와 함께 지금 상황을 짧게 말씀해 주세요.
- 건물 이름과 동, 호수
- 산본역에서 어느 방향인지
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집주인에게 연락이 되었는지
- 집 안에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다.

# 집주인에게 연락할 때 이렇게 말씀드리세요
"도어락이 안 열려서 출장열쇠를 부르려고 합니다. 문을 상하지 않게 여는 방식이고, 수리나 교체가 필요하면 말씀드리고 정하겠습니다." 정도로 간단히 전하면 충분합니다. / 늦은 밤이라 연락이 어려우면 문자를 남기고 먼저 문을 여는 것도 방법입니다.
문 여는 비용과 부품 교체 비용을 어떻게 나눌지는 나중에 이야기해도 됩니다. / 작업 전 안내받은 내용과 작업 후 안내를 사진이나 메모로 남겨 두면 도움이 됩니다.

# 산본동 도어락 오래 쓰는 관리법
오래된 단지일수록 도어락보다 문틀과 경첩 상태가 고장에 더 영향을 줍니다. / 문이 덜 닫히거나 툭 걸리면 경첩부터 보는 것이 좋습니다.
- 배터리는 해가 바뀔 때쯤 한 번에 전부 교체
- 경고음이 나면 미루지 말고 그날 바로 교체
- 비 오는 날 번호판에 물기가 남지 않게 닦기
- 카드키 하나는 따로 보관
- 이상한 소리가 나면 사진이나 영상으로 기록
작은 습관만으로 문 앞에서 막히는 일이 많이 줄어듭니다. / 세입자와 집주인 모두에게 이득이 되는 관리법입니다.
@ 군포 산본동 24시 출장열쇠 상담

# 산본동 말고 군포 어디든 갑니다
산본동 바로 옆 금정동, 당동, 당정동, 부곡동, 대야미동, 오금동도 다닙니다. / 군포 안이면 동네 상관없이 24시간 출동합니다.
군포에서 다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
