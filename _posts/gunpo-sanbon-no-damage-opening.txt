# 문을 안 부수고 열 수 있다는 말이 낯설다면
문이 잠겼다고 하면 문짝을 부수거나 도어락을 뜯어낸다고 생각하는 분이 많습니다. / 산본역 근처 아파트에 사시는 분들도 "열고 나서 문이 멀쩡할까요" 하는 걱정을 가장 먼저 하십니다.
비파손 개방은 문이나 도어락에 흠집을 내지 않고 잠금을 푸는 방식을 말합니다. / 이 글은 산본동에서 비파손 개방이 무엇인지, 언제 가능하고 언제 어려운지를 쉽게 풀어 적었습니다.
[군포 출장열쇠](gunpo.html)에 연락하시기 전에 읽어 두시면 통화가 한결 편해집니다.
@ 산본동 비파손 개방 현관문 도어락 무손상

# 비파손 개방은 이런 뜻입니다
말 그대로 문을 부수지 않고 엽니다. / 도어락 내부 구조를 이해하고 잠금 장치가 풀리는 방식을 이용해 열기 때문에 외관이 그대로 남습니다.
- 문짝에 구멍이나 긁힌 자국이 남지 않는다
- 도어락 본체를 뜯어내지 않아도 된다
- 열린 뒤 기존 도어락을 그대로 계속 쓸 수 있는 경우가 많다
- 소리가 크지 않아 이웃에게 부담이 적다
모든 경우에 가능한 것은 아니지만, 가능한 한 이 방식을 먼저 시도합니다.

# 문을 부수는 방식과 무엇이 다른가
부수는 방식은 빠르지만 문과 도어락을 새로 달아야 하는 경우가 많습니다. / 흠집이 남고 이웃에게도 소리가 크게 퍼집니다.
비파손은 상대적으로 시간이 더 걸릴 수 있지만 문을 그대로 쓸 수 있습니다. / 도어락이 멀쩡히 작동하는데 단순히 잠긴 경우라면 특히 이쪽이 맞습니다.
문을 부순 뒤에 새로 단다면 그만큼 부품과 작업이 늘어납니다. / 가능하다면 처음부터 덜 상하는 방법을 고르는 것이 합리적입니다.
@ 산본동 현관문 흠집 없이 개방하는 모습

# 어떤 경우에 비파손 개방이 잘 되는가
잠금 장치 자체가 고장 난 것이 아니라 단순히 닫혀 있거나 걸린 경우가 가장 잘 맞습니다.
- 열쇠를 집 안에 두고 나와 문이 잠긴 경우
- 보조키나 걸쇠가 안에서 걸린 경우
- 비밀번호를 잊어 번호키로 못 여는 경우
- 건전지가 방전돼 번호판이 꺼진 경우
- 열쇠 방식 문에서 열쇠를 잃어버린 경우
이런 경우는 도어락 구조에 맞는 방법으로 잠금을 풀면 대개 문이 상하지 않습니다. / 문을 연 뒤에도 도어락은 그대로 쓰게 되니 따로 새 제품을 살 필요가 없습니다.
특히 열쇠를 안에 두고 나온 경우처럼 도어락이 멀쩡하면 비파손이 가장 합리적입니다. / 산본동처럼 이웃이 가까운 공동주택에서는 소음이 적다는 점도 장점입니다.

# 어려운 경우도 있습니다
솔직하게 말씀드리면 비파손이 어려운 경우도 있습니다. / 이럴 땐 미리 설명드리고 선택하실 수 있게 합니다.
- 열쇠가 안에서 부러져 박힌 경우
- 도어락 내부 부품이 이미 망가진 경우
- 문이나 문틀이 심하게 뒤틀려 힘으로 눌려 있는 경우
- 다른 사람이 억지로 열려다 잠금이 손상된 경우
이런 경우에도 가능한 한 손상을 줄이는 방법을 찾습니다. / 그 방법이 어렵다면 어떤 부분을 바꾸거나 교체해야 하는지 열기 전에 먼저 말씀드립니다.

# 도어락 종류별로 방식이 달라집니다
번호키는 번호판과 모터, 걸쇠 구조를 이해해 푸는 방법이 있습니다. / 열쇠 방식 문은 실린더 구조에 맞는 방법을 씁니다.
같은 번호키라도 제조 방식과 오래된 정도에 따라 걸리는 시간이 다릅니다. / 사진을 먼저 보내주시면 도착 전에 대략 어떻게 할지 가늠할 수 있습니다.
오래된 문이나 처진 문은 힘이 한쪽에 쏠려 있어 풀기가 더 까다롭기도 합니다. / 그래서 현장에서 문을 먼저 살펴보는 시간이 필요합니다.

# 진행 순서는 이렇습니다
도착해서 도어락과 문 상태를 눈으로 살핍니다. / 사시는 분인지 확인하고, 방법과 비용을 안내합니다.
승낙하시면 덜 상하는 방법부터 차례로 시도합니다. / 작업 중 문제가 생겨 방식을 바꿔야 한다면 반드시 먼저 말씀드립니다.
열린 뒤에는 도어락이 다시 잘 잠기는지, 열리는지 같이 확인합니다. / 진행 방식 전체는 [이용안내](guide.html)에 정리해 두었습니다.

# 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 가장 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로울 수 있지만 이웃을 지키고 본인을 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요. / 늦은 시간이면 경비실에 미리 말해 두면 수월합니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 먼저 안내합니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품 교체가 필요한 상황이면 바꾸기 전에 따로 여쭤봅니다. / 비파손이 어렵다는 판단이 서면 그 이유도 같이 설명드립니다.

# 비파손이라도 지켜주시면 좋은 점
작업이 잘 되려면 문을 건드리지 않은 상태가 좋습니다. / 드라이버나 카드로 먼저 시도하셨다면 그 사실을 알려주세요.
이미 문틈에 도구를 넣어 흠집이 났다면 걸쇠가 더 꽉 물려 있을 수 있습니다. / 이 경우에도 방법이 있으니 숨기지 말고 말씀해 주세요.
비밀번호를 연속으로 틀려 입력이 막혀 있는 상태도 알려주시면 도움이 됩니다. / 작업자가 순서를 바꿔서 접근할 수 있습니다.
@ 산본동 도어락 비파손 개방 작업 후 확인

# 열린 뒤에는 원인을 같이 잡습니다
열기만 하고 끝내지 않고 왜 잠겼는지 원인도 확인합니다. / 건전지가 원인이면 전부 새것으로 바꾸고, 번호를 잊었다면 새로 등록합니다.
같은 증상이 반복된다면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 수명이 다한 제품은 [도어락 교체](doorlock-replace.html)를 설명드리지만 강요하지 않습니다.
현관문 개방에 관한 일반적인 안내는 [현관문 개문](door-open.html) 페이지에도 있습니다.

# 문이 상하지 않게 하는 평소 습관
평소에 문을 거칠게 다루지 않는 것만으로도 개방이 필요한 상황이 줄어듭니다.
- 문을 닫을 때 세게 밀지 않고 부드럽게 닫기
- 도어락에 물기가 닿지 않도록 비 오는 날 닦아 주기
- 건전지는 해가 바뀔 때 전부 한꺼번에 교체하기
- 경고음이 나면 그날 바로 확인하기
- 열쇠 하나는 항상 믿을 만한 곳에 따로 보관하기
이런 습관은 비파손 개방이 필요한 상황 자체를 줄여 줍니다.

# 산본동 밖 군포 어디든 갑니다
산본동 옆 금정동, 당동, 당정동, 부곡동, 대야미동, 오금동도 다닙니다. / 군포 안이면 24시간 출동합니다.
다니는 동네는 [군포시 출장열쇠](gunpo.html)에, 다른 지역은 [출장 지역](area.html)에 정리돼 있습니다.
