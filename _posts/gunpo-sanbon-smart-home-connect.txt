# 산본동 스마트 도어락, 앱이 갑자기 안 될 때
산본동은 신도시 아파트가 오래 자리 잡은 곳이라 최근 도어락을 스마트형으로 바꾼 집이 많습니다. / 앱으로 문 상태를 보고 알림을 받는 편리함 때문에 인기가 많습니다.
그런데 어느 날 갑자기 앱 알림이 안 오거나, 앱으로 연결이 안 된다는 문의가 이어집니다. / 문 자체는 번호로 잘 열리는데 앱만 안 될 때가 대부분입니다.
이 글은 스마트 도어락의 앱 연동과 알림 문제를 직접 확인하는 순서를 정리했습니다. / 문이 아예 안 열리는 상황이라면 바로 [군포 출장열쇠](gunpo.html)로 연락 주세요.

# 스마트 도어락이 앱과 연결되는 방식
스마트 도어락은 보통 블루투스나 와이파이 중계기를 통해 앱과 연결됩니다. / 도어락과 중계기, 공유기, 휴대폰이 모두 정상이어야 앱이 작동합니다.
어느 한 곳이라도 문제가 생기면 앱 알림이 끊기거나 원격 열기가 안 됩니다. / 그래서 원인을 순서대로 좁혀 가는 것이 중요합니다.
먼저 도어락 자체는 번호로 열리는지부터 확인하세요. / 문은 열리는데 앱만 안 된다면 연결 쪽 문제입니다.

# 가장 먼저 휴대폰 쪽부터 확인
앱이 최신 버전인지, 휴대폰 운영체제 업데이트 이후에 오류가 생기지 않았는지 보세요. / 알림 권한이 꺼져 있으면 앱은 정상인데 알림만 안 올 수 있습니다.
휴대폰 설정에서 앱의 알림 권한과 배터리 절전 예외를 확인해 보세요. / 절전 모드가 앱을 강제로 종료시키는 경우도 많습니다.
앱을 완전히 종료했다가 다시 켜거나 휴대폰을 재부팅해 보세요. / 의외로 이 방법만으로 해결되는 경우가 많습니다.
@ 군포 산본동 스마트 도어락 알림 설정

# 공유기와 중계기를 확인하세요
와이파이 방식은 집 공유기가 꺼져 있거나 비밀번호가 바뀌면 연결이 끊깁니다. / 공유기를 교체했거나 비밀번호를 바꿨다면 도어락 중계기도 다시 연결해야 합니다.
중계기가 있는 제품은 중계기 전원이 꽂혀 있는지, 표시등이 정상인지 확인하세요. / 콘센트가 빠져 있어서 알림이 안 온 사례도 종종 있습니다.
공유기 위치가 도어락과 너무 멀면 신호가 약해질 수 있습니다. / 현관 가까이에 중계기를 두면 안정적입니다.

# 도어락 배터리가 약해도 연결이 끊깁니다
통신 기능이 들어간 도어락은 배터리를 더 빨리 씁니다. / 배터리가 약해지면 통신 기능부터 꺼지는 제품이 있습니다.
번호는 열리는데 앱만 안 되는 경우, 경고음이 없어도 배터리가 약한 것일 수 있습니다. / 새 배터리로 전부 바꿔 보세요.
배터리를 갈고 나서 앱을 다시 연결해야 하는 제품도 있으니 설명서를 확인하세요. / 모르겠다면 모델명을 알려주시면 방법을 안내해 드립니다.

# 앱 연동을 다시 설정해야 할 때
오래 쓰다 보면 연결 정보가 꼬여서 초기화가 필요한 경우가 있습니다. / 이때는 앱에서 도어락을 삭제하고 새로 등록하는 과정을 거칩니다.
초기화하면 등록된 비밀번호와 지문이 모두 지워지는 제품이 있어 미리 알아 두어야 합니다. / 초기화 전에 가족과 비밀번호를 다시 정해 두세요.
초기화 방법은 제품마다 달라서 함부로 시도하지 않는 것이 좋습니다. / 점검이 필요하면 전화로 먼저 상담해 주세요.

# 하지 말아야 할 것들
도어락 본체를 열어 내부 회로를 만지는 행동은 피해 주세요. / 통신 모듈이 손상되면 수리가 어려워집니다.
앱에서 비밀번호를 바꾸다가 오류가 났는데 다시 시도하면서 여러 번 반복하는 것도 좋지 않습니다. / 한 번 오류가 나면 멈추고 도어락 번호가 정상인지 확인하세요.
보안과 관련된 정보라 도어락 사진이나 앱 화면을 SNS에 올리지 않는 것이 좋습니다.

- 앱에서 도어락 초기화를 했는데 문이 안 열리는 경우
- 배터리를 갈아도 번호판이 켜지지 않는 경우

# 산본동에서 위치는 이렇게 알려주세요
산본동은 단지와 동 번호가 많아서 위치를 정확히 알려주시면 도착이 빨라집니다. / 아파트 이름이나 건물 이름, 동, 호수와 함께 지금 상황을 짧게 말씀해 주세요.
- 건물 이름과 동, 호수
- 산본역에서 어느 방향인지
- 번호판 상태와 앱 연결 상태
- 도어락 제품명이나 모양
- 집 안에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다.

# 문 열기 전 사시는 분 확인
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
스마트 도어락은 앱 정보로 거주 확인이 되는 경우도 있지만 기본 확인 절차는 동일합니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 비용을 먼저 안내해 드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품이나 통신 모듈을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 상하지 않게 열고 연결 상태를 확인합니다
문 여는 방법은 여러 가지가 있고, 덜 상하는 방법부터 차례로 해봅니다. / 스마트 도어락은 내부 회로가 민감해서 특히 조심해서 다룹니다.
문이 열린 뒤에는 앱 연결이 안 된 원인을 같이 살펴봅니다. / 현관문 개문 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 고쳐서 쓸 수 있으면 교체는 권하지 않습니다
앱 연동 문제는 배터리, 재설정, 중계기 위치 조정 같은 간단한 방법으로 풀리는 경우가 많습니다. / 그런 경우에는 새 제품을 권하지 않습니다.
통신 모듈이 고장났거나 너무 오래된 제품이라 앱 지원이 끝났다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 새로 고르실 때는 [도어락 설치](doorlock-install.html) 페이지도 참고해 주세요.

# 스마트 도어락 오래 쓰는 관리법
- 앱 알림 권한과 절전 예외 설정 확인
- 공유기를 바꾸면 도어락 연결도 같이 점검
- 배터리는 해가 바뀔 때쯤 전부 교체
- 앱 없이도 열 수 있는 번호와 열쇠는 따로 보관
- 도어락 펌웨어 업데이트 알림이 오면 확인
스마트 기능은 편리하지만 기본 열림 방식을 항상 알아 두는 것이 중요합니다. / 앱이 안 돼도 문 앞에서 막히지 않도록 대비해 두세요.
