# 번호판이 끈적끈적해졌다면 부엌 때문일 수 있습니다
산본동은 산본역 주변으로 아파트와 빌라가 이어진 동네이고, 집집마다 현관과 주방이 가까운 구조가 많습니다. / 저녁에 생선이나 고기를 굽고 환기가 부족하면 기름기가 현관 쪽까지 퍼집니다.
어느 날부터 도어락 버튼이 끈적하고 먼지가 달라붙은 듯 느껴지거나 손잡이가 미끌거리는 분이 있습니다. / 이런 경우 주방 기름 연기가 원인일 수 있습니다.
이 글은 산본동에서 도어락이 기름기로 끈적일 때 직접 닦는 방법과 하면 안 되는 일, [군포 출장열쇠](gunpo.html)에 점검을 맡길 시점을 정리했습니다. / 문이 안 열리기 전에 막는 데 초점을 맞췄습니다.
@ 산본동 현관 도어락 기름때 끈적임 점검

# 기름 연기가 도어락까지 오는 길
요리할 때 나온 기름은 아주 작은 입자로 공기 중에 떠다닙니다. / 이 입자는 환기가 약하면 현관 쪽으로 천천히 이동해 표면에 달라붙습니다.
안쪽 번호판과 손잡이는 매일 만지는 곳이라 기름과 손기름이 겹쳐 쌓입니다. / 처음에는 약간 미끌거리는 정도이지만 먼지가 붙으면 점점 끈적해집니다.
특히 주방과 현관이 가까운 집, 요리를 자주 하는 집에서 눈에 띕니다. / 겨울에는 창문을 닫고 요리하는 시간이 늘어 더 쌓이기 쉽습니다.

# 끈적임이 오래되면 생기는 증상
버튼이 한 번에 안 눌리거나 눌렀다가 천천히 올라오는 느낌이 날 수 있습니다. / 번호판이 터치식이라면 센서 표면의 막 때문에 반응이 느려집니다.
손잡이 쪽에는 먼지가 엉겨 붙어 회전이 뻑뻑해지기도 합니다. / 잠금 걸쇠가 움직이는 틈에 끼면 소리만 나고 덜 열리는 느낌이 생길 수도 있습니다.
물론 모든 끈적임이 고장으로 이어지는 건 아닙니다. / 초기에 닦아 주면 대부분 깨끗하게 돌아옵니다.

# 닦기 전에 먼저 준비할 것
무엇으로 어떻게 닦느냐가 중요합니다. / 잘못 닦으면 도어락 표면 코팅이 벗겨지거나 안으로 물이 들어갑니다.
- 부드러운 마른 천이나 안경 닦는 천
- 미지근한 물에 중성세제를 아주 조금 푼 물
- 마른 면봉(틈새용)
- 닦은 뒤 물기를 닦아 낼 마른 천 한 장
배터리를 뺄 필요는 없지만 닦는 동안 번호판을 마구 누르지 않도록 주의하세요. / 번호를 여러 번 잘못 눌러 입력이 잠기는 일을 막기 위해서입니다.

# 안전하게 닦는 순서
천에 세제 푼 물을 아주 약간만 묻혀 꼭 짜세요. / 물이 뚝뚝 떨어지는 천은 쓰지 않습니다.
번호판 위에서 아래로 한 방향으로 가볍게 문질러 기름기를 걷어 냅니다. / 그다음 마른 천으로 같은 방향으로 한 번 더 닦아 물기를 없앱니다.
버튼 사이 틈은 면봉에 물기를 거의 남기지 않고 살살 닦아 주세요. / 틈에 물이 스며들지 않도록 힘을 주지 않는 게 요령입니다.
손잡이는 같은 방법으로 닦되 물기가 안쪽으로 흐르지 않게 합니다. / 마무리는 마른 천으로 꼭 닦아 주세요.
@ 중성세제 푼 물로 도어락 번호판 닦는 순서

# 이런 것으로 닦으면 안 됩니다
기름때가 안 지워진다고 강한 세정제를 쓰는 분이 있습니다. / 알코올이나 락스, 시너, 주방용 강한 기름 제거제는 표면 코팅을 상하게 합니다.
스프레이를 번호판에 직접 뿌리는 것도 피해 주세요. / 틈으로 들어간 액체는 기판에 남아 오작동의 원인이 됩니다.
거친 수세미나 때밀이 같은 건 표면에 흠집을 냅니다. / 한 번 긁히면 번호판 글자가 닳아 보이기도 합니다.
기름칠이나 윤활제를 뿌려 잘 돌게 하려는 시도도 권하지 않습니다. / 먼지가 더 붙어서 시간이 지나면 더 뻑뻑해질 수 있습니다.

# 키 구멍과 걸쇠 틈은 어떻게 하나
열쇠 구멍 안쪽에 기름 먼지가 들어갔다면 닦는 방법이 다릅니다. / 천이나 면봉이 닿지 않는 곳이어서 직접 깊이 손대지 않는 것이 안전합니다.
열쇠를 꽂을 때 뻑뻑하다면 무리하게 돌리지 말고 몇 번 넣었다 빼 보세요. / 그래도 안 되면 억지로 돌리다가 열쇠가 부러지기 전에 전화 주세요.
걸쇠가 나오는 문 옆 틈에 먼지와 기름이 엉겨 있다면 마른 면봉으로 보이는 부분만 닦습니다. / 안쪽까지 파고드는 청소는 점검을 맡기는 쪽이 낫습니다.

# 닦았는데도 끈적이거나 반응이 느리다면
닦고 나서 몇 시간 지켜보세요. / 센서 표면이 완전히 마르면 반응이 돌아오는 경우가 많습니다.
- 버튼이 눌린 채 올라오지 않는 느낌이 계속되는지
- 번호를 눌러도 소리가 한 박자 늦게 나는지
- 손잡이를 돌릴 때 걸리는 구간이 있는지
이 중 하나라도 계속된다면 안쪽에 기름이 스며든 것일 수 있습니다. / 이때는 [도어락 수리](doorlock-repair.html) 점검으로 안쪽을 보는 것이 맞습니다.
점검하면 어디까지 닦고 어디부터 부품을 손봐야 하는지 알려드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 문이 안 열리는 상황까지 갔다면
끈적임이 심해 번호가 안 먹거나 걸쇠가 안 빠져서 문이 안 열릴 수도 있습니다. / 이때는 힘으로 당기거나 드라이버로 틈을 벌리지 마세요.
산본 열쇠집을 찾기보다 [현관문 개문](door-open.html) 페이지를 먼저 보시고 상황을 알려주세요. / 최대한 문과 도어락이 상하지 않게 여는 방법부터 차례로 해봅니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.

# 전화하실 때는 이렇게 알려주세요
산본동은 단지와 건물이 많아 위치를 구체적으로 알려주시면 도착이 빨라집니다. / 산본역 기준으로 어느 쪽인지도 같이 말씀해 주세요.
- 아파트나 빌라 이름 대신 동, 호수와 현관 위치 설명
- 버튼이 끈적이는지, 손잡이가 뻑뻑한지, 열쇠 구멍이 막혔는지
- 요리를 자주 하는 집인지, 환기 상태
- 번호판과 도어락 앞면 사진
사진 한 장이면 필요한 부품이 있는지 미리 가늠하기 좋습니다. / 비용은 문을 열거나 손대기 전에 먼저 말씀드립니다.
@ 산본동 도어락 안쪽 기름때 점검과 청소

# 방문하면 신분부터 확인합니다
점검만 하는 방문이라도 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 끝나면 도어락 겉면부터 안쪽 상태까지 보여 드리며 설명합니다. / 어디에 기름이 쌓였는지 직접 보시면 관리 습관을 바꾸기도 쉽습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 끈적임을 줄이는 생활 습관
기름 연기를 아예 없애기는 어렵지만 줄일 수는 있습니다. / 요리할 때 후드를 켜고 현관과 가까운 쪽 문은 닫아 두세요.
- 요리 중 후드를 먼저 켜고 끝난 뒤에도 잠시 더 켜 두기
- 주방과 현관 사이 문이나 가림막 활용하기
- 일주일에 한 번 번호판과 손잡이 가볍게 닦기
- 닦은 뒤에는 꼭 마른 천으로 물기 제거
도어락이 아주 오래돼서 기름때 때문에 자주 말썽이라면 [도어락 교체](doorlock-replace.html)를 생각해 볼 때도 있습니다. / 그전에 수리로 해결되는지 먼저 봅니다.

# 산본동 말고 군포 어디든 갑니다
산본동 옆 금정동, 당동, 당정동, 부곡동, 오금동, 대야미동도 다닙니다. / 군포 안이면 동네와 상관없이 24시간 연락받습니다.
다니는 동네는 [군포시 출장열쇠](gunpo.html) 페이지에 있고 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다. / 급하지 않은 점검도 편하게 문의하세요.

# 자주 묻는 질문
? 물티슈로 닦아도 되나요? | 물기가 많지 않은 순한 물티슈는 괜찮지만 알코올이 들어간 제품은 피해 주세요. 닦은 뒤에는 마른 천으로 마무리하시길 권합니다.
? 기름때 때문에 도어락을 교체해야 하나요? | 대부분 닦거나 안쪽 점검으로 해결됩니다. 교체는 꼭 필요할 때만 말씀드립니다.
? 점검만 받아도 오시나요? | 네, 문이 열리는 상태에서도 점검 방문이 가능합니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤에 연락해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.

# 마무리
산본동에서 도어락이 끈적이면 중성세제 푼 물을 짠 천으로 닦고 마른 천으로 마무리하는 것부터 해보세요. / 강한 세정제와 스프레이만 피해도 고장을 많이 막을 수 있습니다.
닦아도 그대로이거나 문이 안 열리는 단계라면 억지로 하지 마시고 전화 주세요. / 24시출장열쇠는 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 받습니다.
