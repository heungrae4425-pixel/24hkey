# 산본동 분리수거장 문이 잠겨 있다면
산본동은 산본역을 중심으로 공동주택이 모여 있어서 단지마다 분리수거장과 쓰레기실이 따로 있습니다. / 저녁에 쓰레기를 들고 나갔는데 수거장 문이 잠겨 있으면 난감합니다.
이 글은 분리수거장이나 쓰레기실 문이 잠겼을 때, 또는 열쇠가 안 맞을 때 확인할 순서를 적었습니다. / 단지 공용 시설이라 개인 현관문과는 접근 방법이 다릅니다.
[군포 출장열쇠](gunpo.html)로 연락 주시기 전에 누가 열쇠를 갖고 있는지부터 짚어 보세요.

# 공용 시설은 주인이 따로 있습니다
분리수거장은 입주민 개인 것이 아니라 단지 전체의 시설입니다. / 그래서 문을 바꾸거나 열쇠를 정하는 권한이 관리 쪽에 있습니다.
혼자 판단해서 자물쇠를 건드리면 나중에 책임 문제로 번질 수 있습니다. / 먼저 관리사무소나 경비실에 알리는 것이 순서입니다.
관리 쪽이 모르는 사이 누군가 자물쇠를 새로 달아 둔 경우도 있어 확인이 필요합니다.

쓰레기실은 지하나 건물 한쪽 구석에 있어 습기와 냄새, 먼지가 많은 편입니다. / 그래서 자물쇠나 번호판이 일반 현관보다 빨리 상하는 경우가 많습니다.
최근에 문을 새로 칠했거나 보수했다면 그 과정에서 자물쇠가 바뀐 경우도 있어 관리 쪽 공지를 한번 확인해 보세요.

# 문이 잠기는 흔한 이유
분리수거장 문이 잠기는 이유는 대체로 정해져 있습니다.
- 정해진 시간 외에는 일부러 잠가 두는 경우
- 열쇠로 잠그는 방식인데 담당자가 퇴근한 경우
- 비밀번호나 카드로 여는 방식인데 배터리가 다 된 경우
- 문이 틀에 걸려 뻑뻑하게 닫힌 경우
단지마다 운영 방식이 달라서 먼저 어느 방식인지부터 알면 해법이 좁혀집니다.

# 열쇠가 안 맞을 때 먼저 볼 것
지난주에 되던 열쇠가 갑자기 안 맞는다면 자물쇠가 바뀌었을 가능성이 있습니다. / 게시판이나 안내문에 열쇠 교체 공지가 붙어 있는지 확인해 보세요.
열쇠 끝이 닳았거나 휘어서 안 맞는 경우도 있습니다. / 무리하게 돌리면 열쇠가 부러져 박힐 수 있으니 힘을 주지 마세요.
자물쇠에 이물질이나 먼지가 많아 뻑뻑하다면 마른 천으로 열쇠를 닦고 다시 꽂아 보세요.

# 관리사무소에는 이렇게 문의합니다
동과 호수, 지금 상황을 짧게 전하세요. / "분리수거장 열쇠가 안 맞는데 담당자 확인을 부탁드립니다"처럼 말하면 충분합니다.
언제 잠겼는지, 어제까지는 되었는지도 말해 주면 관리 쪽이 원인을 빨리 짚을 수 있습니다. / 늦은 시간이면 경비실이 대신 연락해 주는 경우가 많습니다.

# 시간 외에는 쓰레기를 어디에 둘까
잠겨 있다고 문 앞에 쌓아 두면 냄새와 위생 문제가 생깁니다. / 이웃 눈치도 보이고 관리 쪽에서 곤란해질 수 있습니다.
급하지 않은 쓰레기는 집으로 가져가 다음 수거 시간까지 둡니다. / 음식물은 밀폐해서 두거나 지정된 방식대로 처리하세요.
임시로 놓아야 한다면 관리사무소에 먼저 허락을 구하는 것이 맞습니다.

# 비밀번호식인데 안 열릴 때
수거장 문에 번호판이 달려 있다면 배터리나 입력 방식부터 봅니다. / 번호가 바뀌었는지 안내문을 확인하고, 안 되면 서너 번 시도 후 멈추세요.
번호판이 아예 꺼져 있으면 배터리가 다 된 것일 수 있습니다. / 이 경우는 관리 쪽에서 교체해야 하니 연락을 남기세요.
개인 현관 도어락처럼 9V 비상 단자가 있는 모델도 있으니 관리 쪽에 물어보면 방법을 알려 줍니다.

# 업체가 문을 열어 주기 전에 필요한 것
공용 시설은 누구든 열어 달라고 한다고 열 수 없습니다. / 관리 주체의 요청이 있어야 작업할 수 있고, 그래서 관리사무소의 확인이 가장 중요합니다.
관리 쪽이 의뢰하는 경우에는 담당자 이름과 연락처, 단지 위치를 알려 주세요. / 어떤 자물쇠인지 사진을 보내 주시면 도움이 됩니다.
개인이 입주민 자격으로 요청해도 단지 허락을 받았는지 확인합니다.
작업은 문이나 자물쇠가 최대한 덜 상하게 진행하고, 방식은 [현관문 개문](door-open.html) 안내와 크게 다르지 않습니다.

교체가 필요한 경우에도 입주민이 개별적으로 업체를 부르기보다 관리사무소가 접수하고 비용 처리 방식을 정하는 편이 일반적입니다. / 우리가 개인적으로 판단해 진행하지 않는 이유입니다.
공용 자물쇠는 여러 사람이 매일 쓰는 만큼 튼튼하고 열기 쉬운 모델을 고르는 것이 좋습니다.
열쇠를 나눠 갖는 범위도 이참에 함께 정리해 보세요. / 열쇠 수가 많아질수록 관리가 어려워집니다.

# 자물쇠 교체나 열쇠 복제가 필요할 때
열쇠를 잃어버렸거나 자물쇠가 낡았다면 교체를 이야기할 수 있습니다. / 이럴 때도 관리사무소와 의논한 뒤 진행해야 합니다.
공용 열쇠를 개인이 복제하면 보안상 문제가 될 수 있어 관리 허락이 필요합니다. / 교체 안내는 [도어락 교체](doorlock-replace.html)를 참고하세요.
@ 산본동 공용 자물쇠 점검과 교체 상담

# 신분 확인과 비용은 이렇게 진행합니다
저희는 요청하시는 분이 해당 단지 입주자나 관리 쪽 담당자인지 먼저 확인합니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
비용은 작업 전에 먼저 말씀드리고, 문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 같은 일이 반복되지 않게
수거 시간과 열쇠 방식을 한 번 메모해 두세요. / 이웃과 같이 확인하면 단체방이나 게시판으로 공유하기도 쉽습니다.
열쇠가 닳았거나 자물쇠가 뻑뻑하다는 신호가 보이면 관리사무소에 미리 알립니다. / 완전히 못 쓰게 되기 전에 손보면 모두가 편합니다.

# 산본동 말고 군포 어디든 갑니다
