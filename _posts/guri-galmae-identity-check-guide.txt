# 갈매동 현관 앞에서 먼저 여쭙는 한 가지
갈매동은 갈매역 주변으로 새 아파트가 모여 있어 입주한 지 오래되지 않은 집이 많은 동네입니다. / 새 집에 막 자리 잡은 가족이 많다 보니 집 주소가 아직 서류에 다 옮겨지지 않은 경우도 흔합니다.
문이 안 열려 출장열쇠를 부르면 기사는 작업 전에 꼭 사시는 분이 맞는지 확인합니다. / 이 절차가 낯설거나 번거롭게 느껴지실 수 있어서, 갈매동 집에서 흔한 상황별로 무엇을 준비하면 되는지 미리 정리했습니다.
미리 알고 계시면 확인은 몇 분이면 끝납니다.
@ 갈매동 새 아파트 문 열기 전 거주 확인

# 왜 꼭 확인을 거칠까요
아파트는 같은 모양 현관문이 층마다 똑같이 이어집니다. / 문 앞에 선 사람이 그 집 사람인지는 문만 봐서는 알 수 없습니다.
확인 없이 문을 연다면 우리 집뿐 아니라 이웃집 문도 같은 방식으로 열릴 수 있습니다. / 거주 확인은 연락 주신 분의 집을 지키는 동시에 같은 동에 사는 모든 이웃의 집을 지키는 일입니다.
그래서 시간이 늦어도, 상황이 급해도 이 순서는 건너뛰지 않습니다. / 확인을 마친 기사만 문에 손을 댈 수 있습니다.

# 기본은 주소가 같은 신분증 하나
가장 빠른 방법은 이 집 주소가 적힌 신분증입니다. / 주민등록증이나 운전면허증에 동과 호수까지 맞으면 바로 끝납니다.
모바일 신분증을 쓰고 계시다면 그것도 확인에 쓸 수 있습니다. / 다만 휴대폰이 집 안에 있다면 다른 방법을 찾아야 합니다.
여권처럼 주소가 적히지 않은 신분증은 이름 확인에는 쓰이지만 이 집에 사는지는 보여 주지 못합니다. / 이럴 때는 주소가 나온 다른 자료를 하나 더 여쭙게 됩니다.

# 입주한 지 얼마 안 돼 주소가 예전 집일 때
갈매동에서 가장 흔한 경우입니다. / 이사는 했지만 전입신고를 아직 안 했거나, 했어도 신분증 뒷면 주소를 바꾸지 않은 경우입니다.
이럴 때는 아래 가운데 하나를 더 보여 주시면 됩니다.
- 이 집 분양 계약서나 임대차 계약서 사진
- 이 주소로 온 우편물, 관리비 고지서
- 관리사무소의 입주 세대 확인
새 아파트 관리사무소는 입주 때 세대 정보를 받아 두는 경우가 많습니다. / 낮 시간이라면 관리사무소에 전화 한 통으로 확인이 끝나기도 합니다.
@ 갈매동 입주 초기 계약서 관리비 고지서 확인

# 신분증이 집 안에 있을 때
쓰레기를 버리러 나왔다가, 택배를 가지러 1층에 내려갔다가 문이 잠기면 지갑도 휴대폰도 집 안에 있습니다. / 이럴 때는 이름과 생년월일, 동과 호수를 먼저 여쭙고 문을 엽니다.
문이 열리면 들어가셔서 신분증이나 우편물을 바로 보여 주시면 됩니다. / 그동안 기사는 현관 밖에서 기다립니다.
집 안에서 확인할 것이 하나도 나오지 않는다면 관리사무소나 경비실 확인을 부탁드립니다.

# 배우자나 가족 신분증 주소가 다를 때
부부 가운데 한 분만 전입을 마쳤거나, 한 분은 직장 때문에 주소를 따로 두는 집도 있습니다. / 문 앞에 계신 분의 신분증 주소가 다르다면 함께 사는 가족에게 전화로 확인을 부탁드립니다.
가족관계를 보여 줄 수 있는 자료가 있다면 도움이 됩니다. / 그래도 애매하면 관리사무소 확인으로 넘어갑니다.
함께 사는 가족이 집 안에서 잠들어 있는 경우라면 전화나 초인종으로 깨우는 것이 가장 빠릅니다. / 문을 여는 것보다 안에서 열어 주는 쪽이 비용도 들지 않습니다.

# 부모님 댁이나 자녀 집 문을 대신 열 때
"부모님 댁에 왔는데 부모님이 안 계세요"처럼 사시는 분이 그 자리에 없는 경우가 있습니다. / 이때는 사시는 분과 직접 통화가 돼야 하고, 관리사무소나 경비실 확인까지 받아야 진행합니다.
연락은 누가 하셔도 괜찮지만, 문을 여는 데 동의하고 확인해 줄 분은 그 집에 사는 분이어야 합니다. / 비어 있는 집 문을 여는 일이라 다른 경우보다 더 조심합니다.

# 아이가 혼자 집 안에 있을 때
아이가 안에서 문을 잠갔거나, 아이만 집에 있는데 보호자가 밖에서 막힌 경우가 있습니다. / 보호자 신분증 주소가 이 집이면 바로 확인되고, 다르면 위의 방법을 함께 씁니다.
아이가 안에 있다는 것을 통화 때 먼저 말씀해 주세요. / 확인은 그대로 하되 순서를 서둘러 진행합니다.
@ 갈매동 아이 혼자 있는 집 거주 확인

# 반려동물만 집에 있을 때
갈매동 새 아파트에는 강아지나 고양이를 키우는 집도 많습니다. / 보호자가 밖에서 막혔고 반려동물만 안에 있다면 통화 때 그것도 함께 말씀해 주세요.
문을 열 때 반려동물이 놀라 복도로 뛰어나가는 일이 생길 수 있습니다. / 확인이 끝나고 문을 열 때는 보호자가 먼저 들어가 반려동물을 붙잡을 수 있도록 순서를 맞춥니다.
안에 있는 반려동물이 짖거나 문을 긁어도 거주 확인 순서는 같습니다. / 대신 확인할 자료를 미리 꺼내 두시면 기다리는 시간이 줄어듭니다.
@ 갈매동 반려동물 있는 집 현관 개방 순서

# 확인이 끝나지 않으면 작업하지 않습니다
어떤 방법으로도 그 집에 사시는 분이라는 것이 확인되지 않으면 문을 열지 않습니다. / 기사도 사정이 딱한 것을 알지만 이 원칙만큼은 같습니다.
이럴 때는 관리사무소가 문을 여는 시간이나 가족 연락이 닿을 때까지 기다렸다가 다시 불러 주세요. / 문을 열지 않았다면 비용은 받지 않습니다.

# 전화 주실 때 미리 말씀해 주세요
통화할 때 아래를 알려 주시면 도착해서 확인이 훨씬 짧아집니다.
- 갈매동 몇 동 몇 호인지, 갈매역에서 어느 쪽인지
- 신분증이 지금 손에 있는지, 주소가 이 집과 같은지
- 계약서 사진이나 우편물 같은 다른 자료가 있는지
- 집 안에 아이나 반려동물이 있는지
도어락 앞면 사진도 함께 보내 주시면 맞는 장비를 챙겨 갑니다. / 공동현관을 통과해야 하는 단지라면 기사가 들어올 수 있게 1층에서 기다려 주실지, 경비실에 미리 말해 두실지도 정해 주세요.

# 확인 다음은 비용 안내입니다
거주 확인이 끝나면 문과 도어락 상태를 보고 무엇을 할지, 비용이 어떻게 되는지 손대기 전에 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 끝내 못 열면 비용은 받지 않습니다.
문은 [현관문 개문](door-open.html) 방식 가운데 덜 상하는 쪽부터 씁니다. / 열고 나서 부품을 손봐야 하면 [도어락 수리](doorlock-repair.html)를 먼저 보고, 꼭 필요할 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
전체 흐름은 [이용안내](guide.html)에 정리해 두었습니다.

# 갈매동 말고 구리 어디든
인창동, 교문동 아파트와 수택동 주택가, 토평동, 아천동까지 구리 전 지역을 다닙니다. / 다니는 동네는 [구리시 출장열쇠](guri.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
