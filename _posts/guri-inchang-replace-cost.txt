# 인창동에서 교체 금액부터 묻게 되는 이유
구리역에서 멀지 않은 인창동에는 아파트 단지와 주택가가 함께 모여 있습니다. / 입주 때 달았던 도어락을 오래 써 온 집이 많아, 고장이 잦아지면 자연스럽게 교체를 알아보게 됩니다.
그런데 전화로 얼마냐고 물으면 문을 봐야 안다는 답을 듣는 경우가 많습니다. / 답답하게 느껴질 수 있지만, 문 상태에 따라 작업 범위가 정말 달라지기 때문입니다.
이 글은 도어락 교체 금액이 어떤 순서로 정해지는지, 무엇이 금액을 달라지게 하는지 정리했습니다. / 숫자 대신 안내 방식을 먼저 알고 계시면 상담을 받을 때 무엇을 물어야 할지 분명해집니다.
@ 인창동 아파트 현관 도어락 교체 상담

# 금액은 세 단계를 거쳐 정해집니다
24시출장열쇠는 교체 금액을 한 번에 말씀드리기보다 단계를 거쳐 좁혀 갑니다. / 첫 통화, 사진 확인, 현장 확인 순서입니다.
첫 통화에서는 원하시는 기능과 지금 증상을 듣고 어느 정도 범위가 될지 대략 말씀드립니다. / 사진을 받으면 문에 맞는 제품을 몇 가지로 추리고, 그에 맞춰 범위를 더 좁힙니다.
현장에서 문 두께와 구멍을 직접 재 본 뒤 작업 전에 금액을 확정해 말씀드립니다. / 괜찮다고 하실 때만 시작하며, 확정한 뒤에 말없이 더해지는 항목은 없습니다.

# 같은 제품인데 금액이 다른 까닭
같은 도어락을 달아도 집마다 금액이 다를 수 있습니다. / 제품값 말고도 작업 범위가 함께 들어가기 때문입니다.
- 기존 구멍을 그대로 쓸 수 있는지, 새로 뚫어야 하는지
- 보조키를 남길지, 떼고 마감할지
- 문이 철문인지, 마감재가 덧대진 문인지
- 떼어 낸 예전 도어락을 정리해야 하는지
기존 구멍과 새 제품 크기가 잘 맞으면 작업이 간단해집니다. / 반대로 크기가 많이 다르면 덮개를 대거나 구멍을 손봐야 해서 시간과 재료가 더 듭니다.

# 기능을 고르는 순서
지문, 카드, 번호, 휴대폰 알림까지 기능이 많을수록 제품값이 올라갑니다. / 기능 목록부터 보기보다 집에서 누가 어떻게 드나드는지부터 떠올려 보세요.
혼자 사시거나 맞벌이 부부라면 번호와 카드 정도로 충분한 경우가 많습니다. / 아이가 있다면 카드나 태그를, 손이 자주 젖거나 건조한 가족이 있다면 지문은 보조로만 쓰는 쪽을 권해 드립니다.
쓰지 않을 기능을 빼면 금액도 줄고, 설정할 것도 적어 관리가 편해집니다.

# 상담 때 물어보시면 좋은 질문
금액을 들을 때 몇 가지를 함께 물어보시면 나중에 오해가 생기지 않습니다. / 아래 질문은 어느 업체에 상담을 받든 쓸모가 있습니다.
- 말씀하신 금액에 철거와 설치가 모두 들어가는지
- 구멍을 새로 뚫게 되면 어떻게 달라지는지
- 작업 뒤 이상이 생기면 어떻게 연락하면 되는지
- 기존 카드나 지문은 새로 등록해야 하는지
이 질문에 막힘없이 답해 주는지만 봐도 상담이 믿을 만한지 어느 정도 가늠할 수 있습니다. / 저희도 이 내용은 작업 전에 먼저 말씀드립니다.

# 사진은 이렇게 보내 주세요
사진이 정확할수록 첫 안내와 최종 금액의 차이가 줄어듭니다. / 아래 네 장이면 대부분 판단할 수 있습니다.
- 바깥에서 본 도어락 전체
- 안쪽 몸체 전체와 배터리 칸
- 문을 열었을 때 옆면 걸쇠 부분
- 보조키가 있다면 보조키 부분
문 옆면 두께를 줄자로 잰 숫자를 같이 적어 주시면 더 좋습니다. / 줄자가 없다면 옆면 사진에 동전 하나를 대고 찍어 주셔도 대략 짐작할 수 있습니다.
@ 인창동 도어락 안쪽 몸체 사진 상담

# 교체 전에 고쳐 쓸 수 있는지도 봅니다
상담을 받다 보면 교체보다 수리가 나은 경우도 꽤 있습니다. / 배터리 단자 녹, 걸쇠 위치 어긋남, 헐거운 고정 나사는 손보면 다시 잘 쓰는 일이 많습니다.
이럴 때는 교체를 권하지 않고 [도어락 수리](doorlock-repair.html)로 안내해 드립니다. / 다만 부품을 구하기 어려운 오래된 제품이라면 수리와 교체를 나란히 놓고 차이를 설명해 드린 뒤 고르시게 합니다.

# 인창동 아파트 현관에서 특히 보는 것
아파트 현관은 방화문인 경우가 많아 구멍을 새로 뚫을 때 조심해야 합니다. / 문 안쪽 구조를 보고 무리 없이 달 수 있는 제품을 먼저 추립니다.
현관 옆에 신발장이나 벽이 가까이 있으면 손잡이가 큰 밀고 당기는 형은 걸릴 수 있습니다. / 문을 활짝 연 사진이 있으면 이런 부분을 미리 확인할 수 있습니다.
인창동 주택가의 오래된 문이라면 문틀 처짐도 함께 봅니다. / 문틀이 처진 상태에서 새 도어락만 달면 같은 걸림이 다시 생기기 때문입니다.

# 세입자라면 확인해 둘 것
전월세로 사시는 집이라면 교체 전에 집주인과 한 번 이야기해 두시는 게 좋습니다. / 누가 비용을 낼지, 이사 갈 때 그대로 둘지는 집마다 약속이 다릅니다.
작업 전과 후 사진, 바꾼 제품, 작업 날짜를 남겨 두시면 나중에 이야기할 때 편합니다. / 원하시면 작업 내용을 문자로 정리해 드립니다.
집주인 쪽에서 원하는 제품이 따로 있다면 그 제품이 문에 맞는지부터 먼저 확인해 드립니다.

# 교체 당일 순서
도착하면 문 상태를 다시 보고 금액을 확정해 말씀드립니다. / 동의하시면 기존 도어락을 떼고, 새 제품을 달고, 안팎에서 여러 번 열고 닫아 봅니다.
새 번호 등록과 카드, 지문 등록까지 함께 마무리합니다. / 사용법을 가족 모두가 알 수 있게 천천히 설명해 드립니다.
비상 단자 위치와 배터리 바꾸는 방법도 이때 같이 알려 드립니다. / 설명서는 찾기 쉬운 서랍에 넣어 두시면 나중에 번호를 바꿀 때 도움이 됩니다.
교체 과정은 [도어락 교체](doorlock-replace.html)와 [이용안내](guide.html)에 자세히 적어 두었습니다.

# 교체 후 첫 달 지켜볼 것
새 도어락은 처음 몇 주 동안 문과 맞물림이 자리 잡는 시기입니다. / 자동 잠금이 제때 걸리는지, 문을 닫을 때 끝에서 걸리지 않는지 지켜봐 주세요.
어색한 부분이 생기면 위치 조정으로 대부분 풀립니다. / 배터리는 새 제품에 들어 있는 것을 쓰다가 경고음이 나면 한꺼번에 바꿔 주세요.
@ 구리 인창동 새 도어락 작동 확인

# 급하게 문이 안 열린 상태라면
교체를 알아보던 중에 문이 아예 안 열리는 상황이 되기도 합니다. / 이때는 먼저 문을 열고, 그다음 교체 여부를 차분히 정하시면 됩니다.
문을 열 때는 사시는 분인지 신분증 주소나 우편물, 관리사무소 확인으로 먼저 확인합니다. / 끝내 열지 못하면 비용은 받지 않고, 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 인창동 말고 구리 어디든
교문동, 수택동, 토평동, 갈매동, 아천동까지 구리라면 어디든 갑니다. / 지역 안내는 [구리 출장열쇠](guri.html), 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.
