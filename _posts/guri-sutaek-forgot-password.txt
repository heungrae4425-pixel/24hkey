# 손가락이 기억하던 번호가 멈춰 버린 날
수택동은 구리 시내에서 주택과 빌라가 촘촘하게 모여 있고 오래 사신 분이 많은 동네입니다. / 대문과 현관에 각각 번호 도어락을 단 집, 빌라 1층 공동 출입문과 집 현관 번호가 따로인 집도 흔합니다.
몇 년을 손가락이 알아서 누르던 번호가 어느 날 갑자기 떠오르지 않을 때가 있습니다. / 한 번 틀리고 나면 대문 번호였는지 현관 번호였는지까지 헷갈리기 시작합니다.
이 글은 수택동 집에서 번호가 생각나지 않을 때 무엇부터 해 볼지, 가족이 번호를 바꾼 경우에는 어떻게 할지, 끝내 안 되면 어떻게 연락하면 되는지 차례로 적었습니다.
@ 수택동 도어락 비밀번호 분실

# 세 번 틀렸다면 일단 손을 멈추세요
대부분 도어락은 번호를 여러 번 틀리면 한동안 입력을 받지 않습니다. / 그 사이에 계속 누르면 잠기는 시간이 더 길어지기도 합니다.
세 번쯤 틀렸다면 손을 내리고 잠시 숨을 고르세요. / 기다리는 동안 아래 내용을 차례로 떠올려 보는 것이 더 빠릅니다.
경고음이 길게 울리며 입력이 막혔다면 몇 분 지나 저절로 풀리는 경우가 많습니다. / 풀린 뒤에도 바로 누르지 말고 번호를 먼저 정리한 다음 누르세요.

# 대문 번호와 현관 번호를 나눠 적어 보세요
주택이나 빌라는 문마다 번호가 달라서 섞이기 쉽습니다. / 휴대폰 메모나 종이에 떠오르는 번호를 모두 적어 보세요.
- 대문이나 공동 출입문 번호
- 집 현관 번호
- 예전에 쓰던 번호
- 다른 곳에서 자주 쓰는 비밀번호
적어 놓고 보면 "이건 대문 거였지" 하고 정리되는 경우가 꽤 있습니다. / 현관에 대문 번호를 누르고 있었던 경우도 드물지 않습니다.

# 손 모양으로 떠올려 보기
숫자는 생각나지 않아도 손이 움직이던 모양은 남아 있을 수 있습니다. / 허공에 번호판을 그리고 평소처럼 손가락을 움직여 보세요.
처음 누르는 숫자가 위쪽이었는지 아래쪽이었는지, 마지막에 별표를 눌렀는지 같은 작은 기억이 실마리가 됩니다. / 번호판을 직접 누르지 말고 허공에서 먼저 연습해 보세요.
@ 수택동 현관 번호판 손 모양으로 번호 떠올리기

# 가족이 번호를 바꾼 건 아닐까
어제까지 잘 열렸는데 오늘 갑자기 안 된다면 누군가 번호를 바꿨을 가능성도 있습니다. / 함께 사는 가족, 자주 드나드는 자녀에게 먼저 연락해 보세요.
수택동처럼 부모님이 사시는 집에 자녀가 들러 도어락을 새로 손봐 드리는 일도 있습니다. / 그때 번호를 바꿔 두고 미처 알리지 못했을 수 있습니다.
빌라라면 공동 출입문 번호를 집주인이 바꾼 경우도 있습니다. / 건물 단체 연락방이나 우편함 근처 안내문을 확인해 보세요.
가족에게 물을 때는 "번호 바꿨어?"보다 "오늘 현관 번호가 안 먹는데 혹시 손댄 적 있어?"처럼 상황을 함께 말하는 편이 답이 빠릅니다. / 배터리를 갈다가 설정이 바뀌었을 수도 있어 바꾼 사람이 본인도 모르는 경우가 있기 때문입니다.
연락이 닿은 가족이 번호를 문자로 보내 준다면 확인 뒤 바로 지워 두세요. / 휴대폰을 잃어버리면 번호도 함께 드러납니다.
@ 수택동 가족이 바꾼 현관 번호 확인

# 번호 말고 다른 길이 있는지
번호만 생각하기 쉽지만 다른 방법으로 열 수 있는 도어락이 많습니다. / 지금 가지고 있는 것을 확인해 보세요.
- 지문이 등록된 도어락이라면 손가락
- 카드나 태그가 되는 도어락이라면 지갑 속 카드
- 비상 열쇠 구멍이 있다면 받아 둔 비상 열쇠
- 휴대폰 앱이 연결된 도어락이라면 앱
비상 열쇠는 처음 설치할 때 받아 서랍 깊숙이 넣어 두는 경우가 많습니다. / 집에 있는 가족에게 찾아 달라고 하거나, 다음을 위해 집 밖 믿을 만한 곳에 하나 맡겨 두세요.

# 집 안에 사람이 있다면
집 안에 가족이 있는데 잠들었거나 소리를 못 듣는 상황이라면 전화를 계속 걸어 보세요. / 초인종과 함께 휴대폰 진동이 겹치면 깨어나는 경우가 많습니다.
안에 어르신 혼자 계신데 오래 대답이 없다면 기다리지 말고 연락 주세요. / 건강이 걱정되는 상황이라면 119에 먼저 연락하는 것이 맞습니다.

# 그래도 안 열리면 이렇게 연락하세요
번호도, 다른 방법도 다 안 될 때 연락 주시면 됩니다. / 아래 내용을 알려 주시면 도착이 빨라집니다.
- 수택동 어느 골목인지, 건물 이름이나 번지
- 대문 쪽인지 현관 쪽인지, 둘 다인지
- 도어락이 번호만 되는지, 지문이나 카드도 되는지
- 번호를 잊은 건지, 가족이 바꾼 건지
수택동 주택가는 골목이 이어져 있어 근처 큰길이나 눈에 띄는 건물을 같이 말씀해 주시면 좋습니다. / 도어락 앞면 사진을 보내 주시면 맞는 장비를 챙겨 갑니다.

# 사시는 분인지 먼저 확인합니다
번호를 몰라 여는 문이라 사시는 분인지 확인이 꼭 필요합니다. / 신분증 주소나 이 주소로 온 우편물, 빌라라면 집주인 확인으로 진행합니다.
부모님 댁 문을 자녀가 대신 여는 경우라면 부모님과 통화가 돼야 합니다. / 신분증이 집 안에 있다면 문을 연 뒤 바로 보여 주시면 됩니다.

# 비용 안내 후 덜 상하게 엽니다
문과 도어락 상태를 보고 비용을 손대기 전에 말씀드립니다. / 동의하실 때만 시작하고, 끝내 못 열면 비용은 받지 않습니다.
문은 [현관문 개문](door-open.html) 방식 가운데 덜 상하는 쪽부터 씁니다. / 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.
@ 수택동 주택 현관 도어락 비파손 개방

# 열린 다음, 번호는 이렇게 정리하세요
문이 열리면 안쪽에서 새 번호를 등록하는 것까지 도와드립니다. / 대문과 현관 번호가 섞여 헷갈렸다면 이참에 두 번호를 확실히 다르게, 하지만 각각 기억하기 쉽게 정해 보세요.
새 번호는 문을 열어 둔 채 바깥에서 두세 번 눌러 확인합니다. / 가족에게는 그날 바로 알리고, 각자 한 번씩 직접 눌러 보게 하세요.
도어락 버튼이 잘 안 눌려 번호가 틀렸던 것이라면 [도어락 수리](doorlock-repair.html)로 번호판을 손봅니다. / 너무 오래돼 글자가 닳았다면 [도어락 교체](doorlock-replace.html)를 생각해 볼 때입니다.

# 다음에 또 잊지 않으려면
- 번호를 종이에 적어 집 밖 믿을 만한 가족에게 맡기기
- 대문과 현관 번호를 서로 다른 규칙으로 정해 헷갈리지 않게
- 지문이나 카드를 함께 등록해 두기
- 번호를 바꾼 사람이 가족 모두에게 알리기로 약속하기
번호를 바꾼 날은 달력에 적어 두면 "언제 바꿨더라" 하고 헷갈릴 일이 줄어듭니다.

# 수택동 말고 구리 어디든
인창동, 교문동 아파트부터 토평동, 아천동, 갈매동까지 구리 전 지역을 다닙니다. / 다니는 동네는 [구리시 출장열쇠](guri.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

# 자주 묻는 질문
? 번호를 여러 번 틀렸더니 아무것도 안 눌려요. | 입력 제한이 걸린 것입니다. 몇 분 기다리면 대개 풀리니 그동안 번호를 정리해 보세요.
? 대문 번호와 현관 번호가 섞였어요. | 떠오르는 번호를 모두 적고 어느 문 것인지 나눠 보세요. 그래도 안 되면 연락 주세요.
? 자녀가 번호를 바꿨는데 연락이 안 돼요. | 사시는 분 확인 후 문을 열고 새 번호를 등록해 드립니다.
? 비상 열쇠가 있는데 어디 꽂나요? | 번호판 아래나 옆 덮개 안에 열쇠 구멍이 숨어 있는 경우가 많습니다. 사진을 보내 주시면 알려 드립니다.
? 못 열면 비용이 드나요? | 아닙니다. 못 열면 비용은 받지 않습니다.

# 마무리
수택동에서 번호가 생각나지 않으면 세 번에서 멈추고, 대문과 현관 번호를 나눠 적어 보세요. / 가족에게 연락하고 다른 열쇠나 카드를 찾아본 뒤에도 안 되면 그때 연락 주시면 됩니다.
24시출장열쇠는 수택동 골목 안 주택과 빌라까지 찾아갑니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
