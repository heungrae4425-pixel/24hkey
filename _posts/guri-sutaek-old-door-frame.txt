# 수택동 오래된 현관문이 말썽을 부리는 이유
수택동은 구리 시내에서 주택과 빌라가 촘촘하게 모여 있고 오래 사신 집이 많은 동네입니다. / 건물이 오래되면 도어락은 멀쩡한데 문 자체가 틀어져서 문제를 일으키는 일이 많아집니다.
문이 한 번에 안 닫히고 툭 걸리거나, 잠글 때마다 문을 들어 올려야 한다면 이미 문틀이 처지기 시작한 것입니다. / 이때 도어락을 바꾸는 것만으로는 해결되지 않는 경우도 많습니다.
이 글은 수택동에서 문틀 처짐이나 경첩 문제로 현관문이 안 열리거나 안 잠길 때 확인할 것과, [구리 출장열쇠](guri.html)를 부르면 어떻게 진행되는지를 정리했습니다.
@ 구리 수택동 오래된 현관문 문틀 처짐 경첩 출장열쇠

# 문틀이 처지면 생기는 증상
문은 시간이 지나면 자기 무게 때문에 아래로 조금씩 내려앉습니다. / 처음에는 눈에 띄지 않다가 어느 날부터 걸쇠가 문틀 구멍과 맞지 않기 시작합니다.
증상은 보통 이렇게 나타납니다.
- 문을 닫을 때 도어락이 걸리는 소리가 정확하지 않은 경우
- 문을 살짝 들어야 잠기거나 열리는 경우
- 문 아래쪽이나 옆쪽이 바닥, 문틀과 닿아 긁히는 경우
- 번호는 맞는데 모터가 돌다가 걸쇠가 안 빠지는 경우
- 비가 오거나 습한 날에 증상이 더 심해지는 경우
이런 증상이 있다면 문 자체가 틀어졌을 가능성이 큽니다. / 나무문은 습기로 부풀고, 철문은 경첩이 헐거워져서 같은 증상이 나타납니다.

# 도어락 고장과 구별하는 법
같은 증상처럼 보여도 도어락 고장과 문 문제는 다릅니다. / 간단히 구별하는 방법이 있습니다.
문이 열린 상태에서 도어락 번호를 눌러 걸쇠가 들어갔다 나오는지 보세요. / 열려 있을 때는 잘 움직이는데 문을 닫으면 안 된다면 문과 문틀의 어긋남이 원인입니다.
반대로 문이 열려 있어도 걸쇠가 안 움직이면 도어락 쪽 문제입니다. / 번호판은 켜지는데 걸쇠가 꼼짝 않는다면 모터나 내부 부품을 의심해 볼 수 있습니다.
어느 쪽인지 확신이 안 서면 상태를 있는 그대로 말씀해 주세요. / 전화로 먼저 가능성을 좁혀 드립니다.
@ 수택동 현관문 걸쇠 문틀 어긋남 점검

# 문 앞에서 시도해 볼 수 있는 것
문이 안 열릴 때 힘으로 당기면 걸쇠가 더 꽉 물립니다. / 오히려 문을 살짝 안쪽으로 밀어 걸쇠의 압력을 풀어 준 상태에서 손잡이를 돌려 보세요.
문을 약간 들어 올리듯이 밀면서 열면 열리는 경우도 많습니다. / 이는 처진 문이 걸쇠를 누르던 힘을 잠깐 덜어 주기 때문입니다.
열쇠식 보조키가 있는 문이라면 보조키를 돌려서 풀리는지도 확인해 보세요. / 그래도 안 되면 억지로 힘을 쓰지 말고 전화 주세요.
도어락이나 문틀 모서리를 공구로 벌리려고 하면 외관이 상하고 나중에 비용이 더 들 수 있습니다.

# 문 앞에서 피해야 할 행동
급한 마음에 문을 발로 차거나 쇠막대로 비트는 분들이 계십니다. / 그러면 문틀이 더 틀어지고 경첩이 상해서 간단히 끝날 일이 문 전체를 손봐야 하는 일로 커집니다.
드라이버나 카드로 문틈을 벌리는 것도 문과 도어락 외관을 상하게 합니다. / 열쇠 구멍에 기름이나 세제를 뿌리는 것도 먼지를 엉겨 붙게 만드니 피해 주세요.
비밀번호를 여러 번 틀리면 도어락이 입력을 막아 버립니다. / 서너 번 해보고 안 되면 멈추는 것이 좋습니다.

# 경첩과 문틀을 손보는 방법
경첩 나사가 헐거워지면 문이 아래로 처집니다. / 경첩 나사를 단단히 조이는 것만으로 문이 제자리를 찾는 경우도 많습니다.
나사 구멍이 닳아서 헛돌 때는 조금 더 긴 나사를 쓰거나 구멍을 메우는 방법이 필요합니다. / 이런 작업은 문 상태를 직접 보고 판단하는 것이 정확합니다.
걸쇠가 들어가는 문틀 구멍(받침) 위치를 살짝 옮겨 주어야 하는 경우도 있습니다. / 문 쪽을 고치기 어려운 오래된 집에서는 받침 쪽을 조정하는 것이 더 쉬울 수 있습니다.

# 전화하실 때 알려 주세요
수택동은 건물 이름이 없는 주택과 빌라가 많아서 위치를 정확히 알려 주시는 것이 중요합니다.
- 큰길이나 구리역 방향 같은 대략적인 위치와 건물 모양
- 몇 층 몇 호인지, 대문이 따로 있는지
- 문이 안 열리는지, 안 잠기는지, 문이 걸리는지
- 문이 철문인지 나무문인지, 도어락 모양
- 차를 세울 곳이 있는지
사진을 문자로 보내 주시면 맞는 장비를 챙겨 가기 좋습니다. / 골목 안쪽이라면 입구에서 만날 수 있는지도 알려 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라서 그 집에 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 이웃이나 집주인의 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집주인 모두를 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 비용은 문을 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마가 드는지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 경첩이나 받침만 손봐도 되는 일에 도어락 교체를 권하지 않습니다.

# 문을 최대한 안 상하게 엽니다
문 여는 방법은 여러 가지가 있고 덜 상하는 방법부터 차례로 해봅니다. / 오래된 문이라도 도어락과 문틀이 상하지 않게 하는 것이 먼저입니다.
걸리는 시간은 문 상태에 따라 다릅니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.
문을 여는 방법은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
@ 구리 수택동 현관문 개문 경첩 점검

# 열린 뒤에는 문이 제자리를 찾도록 같이 봅니다
문이 열리면 도어락이 다시 잘 잠기고 열리는지 확인하고, 문이 부드럽게 닫히는지도 같이 봅니다. / 걸쇠가 문틀에 정확히 들어가는지 보고 필요하면 받침 위치를 조정합니다.
도어락에 문제가 있는 경우에는 [도어락 수리](doorlock-repair.html)로 먼저 손을 보고, 많이 낡았다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문 자체가 크게 틀어져서 목수나 문 업체가 필요한 경우에는 솔직하게 말씀드립니다.

# 오래된 문 오래 쓰는 관리법
수택동처럼 오래된 주택은 문 관리가 도어락 관리만큼 중요합니다.
- 경첩 나사는 해마다 한 번 조여 주기
- 문 아래와 옆이 닿으면 긁히는 자국 확인
- 장마철에는 문이 부풀지 않게 환기
- 문을 닫을 때 걸쇠 소리가 평소와 다르면 바로 점검
- 도어락 배터리는 해가 바뀔 때 한 번에 교체
작은 습관이 문을 오래 쓰게 만듭니다. / 문이 걸리기 시작할 때 손보면 비용도 시간도 훨씬 적게 듭니다.

# 수택동 말고 구리 어디든 갑니다
구리는 범위가 넓지 않아 위치만 알려 주시면 빨리 갑니다. / 골목 안쪽 주택도 24시간 출동합니다.
구리에서 다니는 동네는 [구리시 출장열쇠](guri.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 경첩만 손봐도 되는지 알 수 있나요? | 현장에서 문 상태를 보고 경첩, 받침, 도어락 중 어디가 문제인지 먼저 설명드립니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.
