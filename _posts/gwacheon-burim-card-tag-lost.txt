# 작은 카드 한 장이 사라졌을 뿐인데
별양동과 더불어 과천의 아파트 단지가 모여 있는 곳이 부림동입니다. / 새로 지은 단지가 많아 번호보다 카드나 태그를 대서 드나드는 집이 흔합니다.
카드키는 작고 가벼워서 잃어버려도 금방 알아채지 못합니다. / 며칠 뒤 문 앞에서 지갑을 뒤지다 그제야 없다는 걸 아는 경우도 많습니다.
카드키를 잃어버리면 새 카드를 구하는 것보다 잃어버린 카드를 못 쓰게 만드는 일이 먼저입니다. / 이 글은 부림동에서 카드키, 태그, 리모컨을 잃어버렸을 때 종류별로 무엇을 하면 되는지 정리했습니다.
@ 부림동 아파트 도어락 카드키 분실

# 잃어버린 게 어떤 종류인지부터
도어락에 등록해 쓰는 출입 수단은 생김새가 여러 가지입니다. / 무엇을 잃어버렸는지에 따라 정리하는 방법이 조금씩 다릅니다.
- 지갑에 넣는 신용카드 크기 카드키
- 휴대폰 뒤에 붙이는 얇은 스티커 태그
- 열쇠고리에 다는 작은 태그
- 버튼을 눌러 여는 도어락 리모컨
카드와 태그는 대부분 같은 방식으로 등록되고 지워집니다. / 리모컨은 따로 연결하는 방식을 쓰는 제품이 많아 지우는 순서가 다를 수 있습니다.
언제 마지막으로 썼는지도 떠올려 보세요. / 어제 저녁까지 쓴 기억이 분명하다면 집 안이나 차 안에 있을 가능성이 크고, 며칠째 안 썼다면 밖에서 잃어버렸을 가능성을 더 생각해야 합니다.

# 문 앞이라면 다른 수단으로 먼저
카드만 쓰고 있었다면 문 앞에서 당황하기 쉽습니다. / 대부분의 도어락은 카드와 함께 번호 기능이 있으니, 처음 설치할 때 정한 번호가 있는지 떠올려 보세요.
가족 중 다른 카드를 가진 사람이 곧 들어온다면 기다리는 것도 방법입니다. / 번호도 모르고 다른 카드도 없다면 연락 주세요. 단지 이름과 동, 호수, 도어락 사진을 보내 주시면 맞는 장비를 챙겨 갑니다.

# 하나만 지울 수 있는 제품인지 확인
도어락마다 카드를 지우는 방식이 다릅니다. / 잃어버린 카드 하나만 골라 지울 수 있는 제품도 있고, 등록된 카드를 전부 지운 뒤 다시 등록해야 하는 제품도 있습니다.
안쪽 몸체 덮개를 열어 보면 등록 버튼과 설정 순서가 적힌 스티커가 붙어 있는 경우가 많습니다. / 설명서가 있다면 카드 삭제 항목을 먼저 찾아보세요.
어느 방식인지 모르겠다면 안쪽 몸체 사진을 보내 주세요. / 제품 모양을 보고 전화로 순서를 안내해 드립니다.

# 전체 삭제 전에 남은 카드 모으기
전체를 지우는 방식이라면 지우기 전에 집에 있는 카드를 모두 모아 두세요. / 지우고 나면 남은 카드도 다시 대야 쓸 수 있기 때문입니다.
가족이 들고 나간 카드가 있다면 그 사람이 돌아온 뒤에 함께 하시는 게 좋습니다. / 한 장이라도 빠지면 그 카드만 다시 등록해야 하는 번거로움이 생깁니다.
다시 등록할 때는 카드마다 누구 것인지 작은 스티커로 표시해 두면 나중에 또 정리할 때 편합니다.
@ 부림동 도어락 카드 전체 삭제 후 재등록

# 리모컨을 잃어버렸을 때
도어락 리모컨은 문 가까이에서 버튼만 누르면 열리는 편리한 수단입니다. / 그만큼 누가 주우면 바로 쓸 수 있어 빨리 연결을 끊어야 합니다.
리모컨 연결을 지우는 방법은 제품마다 다릅니다. / 안쪽 몸체의 설정 버튼으로 연결된 리모컨을 모두 지우고 남은 리모컨만 다시 연결하는 경우가 많습니다.
리모컨을 쓰지 않아도 불편하지 않다면 이번에 리모컨 기능을 꺼 두는 것도 방법입니다. / 쓰는 수단이 줄어들수록 관리할 것도 줄어듭니다.

# 단지 공동현관 카드는 따로
도어락 카드와 단지 공동현관 카드가 같은 카드인 경우도 있고, 따로인 경우도 있습니다. / 공동현관이나 주차장 출입 카드는 관리사무소에서 관리하니 그쪽에도 알려 주세요.
관리사무소에서 잃어버린 카드를 막고 새 카드를 내주는 절차가 따로 있는 경우가 많습니다. / 절차는 단지마다 달라 관리사무소 안내를 따르시면 됩니다.
도어락 카드와 공동현관 카드가 한 장으로 겸용이라면 두 곳 모두에서 지워야 하니 빠뜨리지 않게 챙겨 주세요.

# 새 카드는 이렇게 마련합니다
도어락에 쓰는 카드는 아무 카드나 되는 게 아닙니다. / 같은 제품에 맞는 방식의 카드여야 등록이 됩니다.
제품 이름을 알면 맞는 카드를 고르기 쉽습니다. / 모르겠다면 지금 쓰고 있는 카드와 도어락 사진을 함께 보내 주시면 맞는 카드인지 확인해 드립니다.
새 카드를 몇 장 더 마련해 두면 다음에 잃어버려도 덜 막막합니다. / 다만 너무 많이 만들어 두면 관리가 어려워지니 가족 수에 한두 장 정도가 적당합니다.

# 직접 하기 어렵다면 출장으로
설정 순서가 복잡하거나 관리자 번호를 잊었다면 혼자 하기 어려울 수 있습니다. / 이럴 때는 방문해서 카드 삭제와 재등록, 새 카드 등록까지 한 번에 정리해 드립니다.
문이 열려 있는 상태에서 하는 정리는 [도어락 수리](doorlock-repair.html) 상담과 함께 진행합니다. / 문이 닫혀 들어가지 못하는 상황이라면 [현관문 개문](door-open.html)부터 합니다.

# 사용자 확인과 작업 전 금액
문을 열거나 등록을 바꾸는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
작업 범위를 보고 시작 전에 금액을 먼저 말씀드리며, 괜찮다고 하실 때만 진행합니다. / 문을 끝내 열지 못하면 비용은 받지 않습니다. 진행 흐름은 [이용안내](guide.html)에 있습니다.

# 카드가 자꾸 사라진다면
카드를 자주 잃어버린다면 수단을 바꿔 보는 것도 방법입니다. / 아이들이 카드를 자주 잃어버리는 집이라면 휴대폰 뒤 스티커 태그나 번호로 바꾸는 쪽이 나을 수 있습니다.
지문이나 휴대폰 연동 기능이 있는 제품으로 바꾸고 싶다면 [도어락 교체](doorlock-replace.html)에서 문에 맞는 제품을 먼저 확인해 보세요. / 다만 기능을 늘리기보다 가족이 실제로 쓸 방식 하나를 정하는 게 더 중요합니다.
@ 과천 부림동 스티커 태그 등록

# 등록 목록을 적어 두는 습관
카드를 등록할 때마다 언제 누구 카드를 넣었는지 적어 두세요. / 휴대폰 메모 한 줄이면 충분합니다.
몇 장이 등록돼 있는지 알고 있으면 잃어버렸을 때 무엇을 지워야 할지 바로 압니다. / 이사 나갈 때나 들어올 때도 이 기록이 큰 도움이 됩니다.
카드를 지갑 한 곳에만 넣어 두지 말고, 쓰지 않는 여분 카드는 집 안 정해진 서랍에 따로 보관해 두세요. / 여분이 어디 있는지 가족 모두 알고 있으면 급할 때 덜 헤맵니다.

# 부림동 말고 과천 어디든
별양동, 원문동, 중앙동, 갈현동, 문원동까지 과천이라면 어디든 갑니다. / 지역 안내는 [과천 출장열쇠](gwacheon.html), 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.

? 잃어버린 카드만 골라 지울 수 있나요? | 제품에 따라 다릅니다. 안 되는 제품은 전체를 지우고 남은 카드를 다시 등록합니다.
? 아무 카드나 사서 등록하면 되나요? | 같은 제품에 맞는 방식이어야 합니다. 사진을 보내 주시면 맞는지 확인해 드립니다.
? 리모컨도 지워야 하나요? | 리모컨을 잃어버렸다면 연결을 지우고 남은 리모컨만 다시 연결하는 게 좋습니다.
? 퇴근이 늦어 밤에만 시간이 돼요. | 밤에도 방문해 카드 정리를 해 드립니다. 편한 시간을 말씀해 주세요.
