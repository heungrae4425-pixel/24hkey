# 부림동에서 새 집 문을 열기 전에
과천 부림동은 아파트 단지와 주택, 상가가 어우러져 이사가 활발한 동네입니다. / 새 집에 들어가는 날 가장 먼저 만지게 되는 것이 현관문 도어락입니다.
이사를 마치고 나면 짐 정리에 정신이 없어 도어락 번호는 전 입주자 그대로 두는 경우가 많습니다. / 누가 그 번호를 알고 있는지 모르는 상태로 지내게 됩니다.
이 글은 부림동에서 이사 후 도어락 번호를 다시 정하고 열쇠를 정리하는 순서를 적었습니다. / 현장에서 돕는 방식은 [과천 출장열쇠](gwacheon.html)를 기준으로 설명했습니다.
@ 부림동 이사 후 도어락 번호 재설정

# 이사 후 바로 해야 하는 이유
전 입주자와 가족, 이사 업체, 청소 업체가 번호나 열쇠를 알고 있을 가능성이 있습니다. / 새 입주자가 모르는 사이에 접근 가능한 사람이 있는 상태입니다.
번호를 바로 바꿔 두면 이런 걱정을 한 번에 정리할 수 있습니다. / 별로 어렵지 않으니 이삿짐을 풀기 전에 먼저 하는 것이 좋습니다.
이사 직후에는 문 상태도 같이 확인해 두면 나중에 문제가 생겼을 때 구분이 쉽습니다. / 문 안쪽과 바깥쪽 사진을 남겨 두세요.
@ 부림동 현관 도어락 번호 변경

# 번호 재설정은 이렇게 합니다
제품마다 다르지만 보통 안쪽 덮개를 열고 초기화 버튼을 누른 뒤 새 번호를 등록합니다. / 설명서가 있으면 먼저 읽어 보시는 것이 좋습니다.
새 번호는 예측하기 어려운 조합으로 정하고 가족과 공유하세요. / 등록 후에는 문을 열어 닫고 한두 번 확인합니다.
설명서가 없거나 방식이 어렵다면 무리하지 말고 연락 주세요. / 잘못 만지면 등록이 꼬일 수 있습니다.

# 열쇠를 쓰는 문이라면 실린더도 고민
전 입주자가 복사한 열쇠가 몇 개인지 알 수 없습니다. / 불안하다면 자물쇠 안쪽만 교체하는 방법이 있습니다.
실린더를 바꾸면 문 전체를 바꾸지 않아도 되고 이전 열쇠는 쓸 수 없게 됩니다. / 이 부분은 [출장 열쇠](key-call.html) 페이지에서 자세히 볼 수 있습니다.
교체가 꼭 필요한지는 상황을 듣고 말씀드립니다. / 바꾸기 전에는 꼭 먼저 여쭙고 진행합니다.

# 배터리도 새것으로
이사 오면서 도어락 배터리가 얼마나 남았는지 알 수 없습니다. / 새 입주 때 한꺼번에 교체하면 몇 년 동안 편합니다.
일부만 바꾸면 얼마 안 가 같은 일이 다시 생기기 쉽습니다. / 알림이 약한 제품은 더 신경 써서 확인하세요.
비상용 9V 건전지 하나를 현관 서랍에 두는 것도 좋은 방법입니다. / 방전 때 비상 단자에 대면 문을 열 수 있습니다.

# 세입자라면 알아 둘 것
세 들어 사는 집은 도어락을 교체하거나 구멍을 가공하면 원상복구 문제가 생길 수 있습니다. / 계약서에 관련 조항이 있는지 확인해 두세요.
번호 재설정 정도는 문제가 적지만 집주인이 알고 있는 편이 서로 편합니다. / 새 열쇠를 집주인에게 맡길지도 미리 정해 두세요.
이사 나갈 때는 카드와 열쇠를 모두 돌려주거나 초기화해 두는 것이 좋습니다. / 그래야 나중에 분쟁이 생기지 않습니다.

# 이사 당일 문이 안 열릴 때
이삿짐센터가 도착했는데 문이 안 열리는 일이 생기기도 합니다. / 마음이 급하지만 배터리와 비상 전원부터 확인하세요.
비상 전원을 대도 안 열리면 억지로 시도하지 말고 연락 주세요. / 이삿짐 시간이 걸려 있다면 먼저 말씀해 주세요.
급한 순서를 정해 출동합니다. / 24시간 받으니 시간 걱정 없이 전화 주세요.

# 부림동에서는 이렇게 위치를 알려 주세요
부림동은 단지와 건물이 많아 정확한 동 번호와 호수가 중요합니다. / 단지 이름 대신 근처 눈에 띄는 건물을 같이 말씀해 주세요.
- 건물 종류와 몇 동 몇 호인지
- 문 종류(번호 도어락, 열쇠, 혼합)
- 이사 일정이 급한지 여부
- 기존 도어락 증상 유무
문 사진을 문자로 보내 주시면 챙겨 갈 장비를 정하는 데 도움이 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 다루는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 임대차계약서, 관리사무소 확인 중 하나면 됩니다.
이사 직후라 주소가 아직 바뀌지 않았다면 계약서 사진이나 전입 안내가 도움이 됩니다. / 집주인 확인으로 대신할 수 있는 경우도 있습니다.
번거로우실 수 있지만 이웃과 집 주인을 모두 지키는 절차입니다. / 확인이 어려우면 작업할 수 없으니 미리 준비해 두세요.
@ 부림동 24시 출장열쇠 신분 확인

# 작업은 이런 순서로 진행합니다
문과 기존 도어락 상태를 먼저 보고 초기화로 충분한지, 교체가 필요한지 판단합니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
번호 등록, 카드 등록, 열쇠 확인까지 한 번에 마무리하고 사용법을 알려 드립니다. / 방식은 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.
문이 안 열리는 상태라면 먼저 [현관문 개문](door-open.html)으로 열고 난 뒤 진행합니다. / 못 열면 비용은 받지 않습니다.

# 비용은 시작하기 전에 먼저 말씀드립니다
문 상태와 도어락 종류, 작업 범위를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
작업이 끝난 뒤에 말 없이 붙는 비용은 없습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 이사 후 일주일 안에 해두면 좋은 것
- 번호를 정하고 가족과 공유하기
- 카드나 보조키를 하나 더 만들어 두기
- 비상용 건전지를 현관 서랍에 넣어 두기
- 배터리 알림 소리를 한 번 들어 보며 확인하기
- 여분 열쇠를 믿을 만한 곳에 맡겨 두기
이 정도만 정리해 두면 새 집에서 문 때문에 곤란한 일이 거의 없습니다.

# 부림동 말고 과천 어디든 갑니다
별양동, 원문동, 중앙동, 갈현동, 문원동까지 과천 전 지역을 다닙니다. / 위치를 받으면 도착 시간을 바로 말씀드립니다.
과천에서 다니는 지역은 [과천시 출장열쇠](gwacheon.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

이사 직후에는 도어락 말고도 우편함 열쇠, 공동 현관 비밀번호, 창고 열쇠 같은 것도 함께 정리해 두면 좋습니다. / 전 입주자에게 받은 열쇠가 어디에 쓰이는지 하나씩 확인해 보세요.
모르는 열쇠가 있다면 따로 봉투에 모아 두고 관리사무소에 문의하면 쉽게 정리됩니다. / 필요한 경우 열쇠 제작이나 교체도 함께 안내해 드립니다.
짐 정리가 끝나기 전에 한 번만 점검해 두면 입주 후 몇 년 동안 마음이 편합니다.

입주 첫날에는 번호를 바꾼 뒤 문을 닫은 상태에서 한 번 더 열어 보고, 가족 모두 번호를 알고 있는지 확인해 두세요. / 이삿짐을 나르는 동안 문이 열려 있었다면 마지막에 잠금 상태도 꼭 점검하세요.
