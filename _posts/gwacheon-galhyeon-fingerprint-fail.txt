# 입주 몇 달 만에 지문이 말을 안 들을 때
갈현동은 과천에서 새 아파트와 주택가가 함께 있는 동네로, 입주하면서 지문 도어락을 처음 써 보는 집이 많습니다. / 처음 몇 주는 신기할 만큼 잘 열리다가 어느 순간부터 두세 번씩 손가락을 대야 열리는 경우가 생깁니다.
지문 인식이 나빠지면 대부분 도어락이 고장 났다고 생각합니다. / 하지만 실제로는 센서 표면, 처음 등록한 방식, 계절에 따른 손 상태가 원인인 경우가 훨씬 많습니다.
이 글은 갈현동 새 아파트에서 지문 도어락이 손가락을 잘 못 알아볼 때 무엇부터 보고 어떻게 다시 등록하면 되는지 순서대로 정리했습니다. / 순서대로 해 봐도 안 되면 그때 점검을 부르셔도 늦지 않습니다.
@ 갈현동 새 아파트 지문 도어락 인식 실패

# 먼저 센서 표면을 들여다보기
지문 센서는 손가락이 닿는 작은 창입니다. / 이 창에 얇은 막이 남아 있거나 손때가 쌓이면 인식이 확 떨어집니다.
입주 때 붙어 있던 보호 필름이 일부 남아 있는 경우가 생각보다 많습니다. / 센서 가장자리를 불빛에 비춰 보고 들뜬 막이 보이면 조심스럽게 떼어 주세요.
손때는 마른 안경닦이 같은 부드러운 천으로 가볍게 닦으면 됩니다. / 알코올이나 세정제를 뿌리면 센서 코팅이 상할 수 있어 피해 주세요.

# 손가락을 대는 자세가 달라졌는지
처음 등록할 때와 평소 대는 자세가 다르면 인식이 잘 안 됩니다. / 등록할 때는 정면에서 손가락 끝을 댔는데, 평소에는 장바구니를 든 채 옆으로 비스듬히 대는 식입니다.
손가락 끝이 아니라 첫 마디 가운데가 센서 한가운데에 오도록 대 보세요. / 누르듯 힘을 주기보다 살짝 얹은 채 일 초쯤 기다리는 게 좋습니다.
이렇게만 해도 잘 열린다면 도어락은 정상이고 자세 문제였던 겁니다. / 그래도 들쭉날쭉하면 아래처럼 다시 등록하는 쪽이 낫습니다.

# 등록은 여러 각도로 넉넉하게
지문을 한 번에 빨리 등록하면 손가락의 일부만 저장되는 경우가 있습니다. / 제품이 여러 번 대라고 할 때 매번 각도를 조금씩 바꿔 대 주세요.
- 정면, 왼쪽으로 살짝, 오른쪽으로 살짝
- 손가락 끝 쪽, 가운데, 마디 쪽
- 평소 문 앞에 서는 자세 그대로 한 번 더
같은 손가락을 두 번 등록하거나 양손에서 하나씩 등록해 두면 한쪽이 안 될 때 다른 쪽으로 열 수 있습니다. / 짐을 들고 다니는 손 반대쪽 손가락을 하나 넣어 두면 특히 편합니다.
@ 갈현동 지문 센서 여러 각도 재등록

# 등록 지우고 다시 넣는 순서
인식이 안 되는 지문을 그대로 둔 채 새로 넣으면 저장 칸이 금방 찹니다. / 오래된 지문은 지우고 다시 등록하는 게 깔끔합니다.
대부분 안쪽 몸체 덮개를 열면 등록 버튼이 있고, 관리자 번호를 넣은 뒤 지문 삭제와 등록을 고를 수 있습니다. / 제품마다 순서가 달라 설명서를 먼저 확인해 주세요.
설명서를 찾기 어렵다면 안쪽 몸체 사진을 보내 주시면 전화로 순서를 안내해 드립니다. / 다시 등록하는 동안에는 문을 열어 둔 채 집 안에서 해야 갑자기 잠겨 갇히는 일이 없습니다.

# 겨울 건조와 여름 땀
계절이 바뀌면 손가락 상태도 달라집니다. / 겨울에는 손이 건조해 지문 골이 얕아지고, 여름에는 땀이나 물기 때문에 센서가 지문을 흐리게 읽습니다.
겨울에는 손을 살짝 비비거나 입김을 한 번 불고 대 보세요. / 여름에는 옷에 손을 한 번 닦고 대면 훨씬 잘 됩니다.
계절마다 인식이 크게 달라진다면 그 계절에 한 번 더 등록해 두는 것도 방법입니다. / 손가락 하나를 계절용으로 남겨 두면 편합니다.
핸드크림을 바른 직후에는 기름기 때문에 오히려 인식이 떨어지니, 문을 열고 나서 바르는 습관을 들여 보세요.

# 지문 말고 다른 수단도 꼭 켜 두기
지문은 편하지만 손을 다치거나 밴드를 붙였을 때는 쓸 수 없습니다. / 번호와 카드 중 하나는 늘 쓸 수 있게 켜 두시길 권합니다.
아이나 어르신은 지문이 잘 안 맞는 경우가 있어 카드나 번호를 주로 쓰는 편이 낫습니다. / 지문은 보조 수단으로만 두면 문 앞에서 막히는 일이 줄어듭니다.
번호를 오래 안 써서 잊었다면 이번에 다시 정해 가족과 나눠 두세요.

# 가족마다 손가락을 정해 두기
여럿이 함께 사는 집이라면 누가 어느 손가락을 등록했는지 적어 두시면 관리가 쉬워집니다. / 나중에 인식이 나빠진 지문만 골라 지우고 다시 넣을 수 있기 때문입니다.
이사 온 뒤 손님이나 친척이 잠깐 지문을 등록했다면 이번에 함께 정리해 주세요. / 쓰지 않는 지문이 남아 있으면 저장 칸만 차지하고 관리도 헷갈립니다.
등록 목록을 정리한 날짜를 적어 두면 다음 정리 때 기준이 됩니다. / 계절이 바뀔 때 한 번씩 보시면 충분합니다.

# 센서에 불이 안 들어오거나 반응이 늦다면
손가락을 대도 센서에 불이 안 들어오거나 반응이 한참 늦다면 배터리가 약해진 신호일 수 있습니다. / 지문 센서는 번호판보다 전기를 더 써서 배터리가 약해지면 먼저 둔해집니다.
배터리를 한꺼번에 전부 새것으로 바꾸고 다시 대 보세요. / 그래도 반응이 없다면 센서 쪽 연결이나 부품 문제일 수 있어 점검이 필요합니다.

# 문 밖에서 지문이 끝내 안 될 때
지문이 안 되고 번호도 잊었다면 문 밖에서 막히게 됩니다. / 이때는 손가락을 계속 대지 말고 잠시 멈춰 주세요. 여러 번 실패하면 한동안 입력이 막히는 제품도 있습니다.
카드키가 집 안에 있거나 가족이 멀리 있다면 연락 주세요. / 단지 이름과 동, 호수, 도어락 사진을 보내 주시면 맞는 장비를 챙겨 갑니다.

# 개문이 필요할 때의 절차
문을 열어야 할 때는 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 찍힌 우편물, 관리사무소 확인 중 하나면 됩니다.
도어락 상태를 보고 작업 전에 금액을 먼저 말씀드리며, 괜찮다고 하실 때만 시작합니다. / 끝내 열지 못하면 비용은 받지 않습니다. 진행 흐름은 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 있습니다.

# 센서가 상했다면 수리부터
센서 창에 흠집이 깊게 났거나 금이 갔다면 닦거나 다시 등록해도 나아지지 않습니다. / 이럴 때는 센서 부품을 손보는 [도어락 수리](doorlock-repair.html)를 먼저 봅니다.
부품을 구하기 어렵거나 다른 고장까지 겹쳤다면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다. / 새 아파트 문은 신형 도어락이 많아 대부분 같은 구멍에 맞는 제품을 고를 수 있습니다.
@ 과천 갈현동 지문 센서 점검 수리

별양동, 부림동, 원문동, 중앙동, 문원동까지 과천이라면 어디든 갑니다. / 지역 안내는 [과천 출장열쇠](gwacheon.html), 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.
