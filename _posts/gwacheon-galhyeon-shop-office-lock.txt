# 갈현동 새 공간에 들어왔다면 출입문부터 정리
갈현동은 새로 입주한 단지가 가까이 모인 과천 동네로, 새 건물 안 상가나 사무 공간에 들어오는 분들도 있습니다. / 입주 첫 주에는 간판, 집기, 인터넷 설치로 바빠서 출입문 도어락은 받은 그대로 쓰기 쉽습니다.
그런데 새 공간의 출입문에는 인테리어 업체, 이전 임차인, 분양 관계자가 쓰던 번호가 남아 있을 수 있습니다. / 출입문 관리를 처음에 한 번 정리해 두면 나중에 직원이 바뀌거나 문이 안 열릴 때 훨씬 수월합니다.
이 글은 갈현동 상가와 사무실에서 출입문 도어락을 정리하는 순서와, 마감 때 잠금이 안 걸리거나 아침에 문이 안 열릴 때 대처를 적었습니다. / 현장 작업이 필요하면 [과천 출장열쇠](gwacheon.html)로 연락 주세요.
@ 갈현동 새 상가 사무실 출입문 도어락

# 입주 첫날 지워야 할 것들
새 공간을 넘겨받으면 출입문 도어락에 등록된 번호와 카드를 전부 지우고 다시 시작하는 것이 좋습니다. / 누가 등록했는지 모르는 번호를 남겨 둘 이유가 없습니다.
- 인테리어 공사 때 쓰던 작업용 번호
- 이전 임차인이나 분양 관계자가 쓰던 번호와 카드
- 건물 관리 쪽에서 등록해 둔 관리자 번호가 있는지 확인
- 기본 출고 번호가 바뀌지 않고 남아 있는지 확인
건물 관리 규정상 관리실 번호를 남겨 둬야 하는 곳도 있습니다. / 지우기 전에 관리실에 한 번 여쭤보세요.

# 직원 번호는 사람마다 따로
여러 명이 드나드는 가게나 사무실은 직원마다 번호나 카드를 따로 주는 방식이 관리하기 쉽습니다. / 한 사람이 그만둘 때 그 번호 하나만 지우면 되기 때문입니다.
- 대표나 점장: 관리자 번호
- 정직원: 개인 번호 또는 개인 카드
- 아르바이트나 단기 근무자: 근무 기간용 번호
- 청소나 설비 업체: 방문 날만 쓰는 번호
누구에게 어떤 번호와 카드를 줬는지 간단한 표로 정리해 두세요. / 도어락 화면에는 이름이 나오지 않아 기록이 없으면 무엇을 지울지 알기 어렵습니다.

# 마감할 때 잠금이 안 걸린다면
문을 닫고 나왔는데 잠김 소리가 나지 않거나 손잡이를 당기면 열리는 경우가 있습니다. / 사람이 많이 드나드는 출입문은 집 현관보다 문틀과 걸쇠가 빨리 어긋납니다.
- 문이 끝까지 닫히지 않고 멈추는지
- 걸쇠가 문틀 받침판에 걸려 반만 나오는지
- 도어락이 수동 잠금으로 설정이 바뀌어 있는지
- 배터리가 약해 모터 힘이 모자란지
마감 직후에 손잡이를 한 번 당겨 보는 습관을 들이시면 이런 문제를 바로 알아챌 수 있습니다. / 잠김이 불안하다면 그날 바로 연락 주세요.
@ 갈현동 상가 마감 잠금 확인

# 유리문은 잠금 구조가 다릅니다
상가 출입문이 유리문이라면 일반 현관 도어락과 구조가 다릅니다. / 문 아래나 위쪽에 잠금 장치가 따로 있거나, 유리문 전용 도어락을 쓰는 경우가 많습니다.
유리문 아래 바닥에 들어가는 잠금쇠가 있다면 바닥 구멍에 먼지나 이물질이 차서 잘 안 들어가기도 합니다. / 구멍을 청소하는 것만으로 나아지는 일이 있습니다.
유리문 전용 도어락은 문 두께와 프레임 모양에 맞는 제품을 써야 합니다. / 교체할 때는 유리문 구조를 먼저 보고 맞는 제품을 말씀드립니다.

# 셔터와 출입문이 함께 있다면
가게 앞에 셔터를 따로 내리는 곳은 셔터 열쇠나 리모컨과 출입문 도어락을 함께 관리해야 합니다. / 셔터는 건물 설비로 관리실에서 다루는 경우가 많아, 고장이 나면 관리실에 먼저 알리는 것이 순서입니다.
셔터를 올린 뒤 안쪽 출입문이 안 열리는 상황이라면 그쪽은 저희가 볼 수 있습니다. / 셔터 열쇠와 출입문 카드를 한 고리에 달아 두셨다면 하나를 잃어버렸을 때 둘 다 정리해야 한다는 점도 기억해 두세요.
마감 순서를 직원끼리 정해 두면 실수가 줄어듭니다. / 출입문 잠금 확인, 셔터 내림, 손잡이 당겨 보기 순서로 정해 두는 곳이 많습니다.

# 사무실 안쪽 문도 함께 보기
사무실은 출입문 말고도 창고, 회의실, 서류 보관실처럼 따로 잠그는 문이 있습니다. / 안쪽 문 열쇠를 누가 갖고 있는지 정리하지 않으면 담당자가 휴가 간 날 문을 못 여는 일이 생깁니다.
안쪽 문 열쇠는 개수를 세어 두고, 여분 하나는 관리자만 아는 곳에 보관하세요. / 열쇠를 잃어버렸다면 실린더만 바꾸는 방법도 있습니다.

# 아침에 출입문이 안 열린다면
영업 시작 전이나 출근 시간에 출입문이 안 열리면 하루 일정이 모두 밀립니다. / 먼저 번호판이 켜지는지, 번호를 누르면 어떤 소리가 나는지 확인해 보세요.
번호판이 꺼졌다면 바깥 비상 단자에 9V 건전지를 대 보세요. / 소리는 나는데 안 열린다면 걸쇠가 문틀에 눌려 있을 수 있으니 문을 안쪽으로 살짝 밀면서 다시 열어 보세요.
그래도 안 되면 무리하지 말고 연락 주세요. / [현관문 개문](door-open.html)과 같은 방식으로 덜 상하게 여는 방법부터 씁니다.
@ 갈현동 사무실 출입문 아침 개문

# 사용 권한 확인 서류
상가나 사무실 문을 열 때는 그 공간을 쓰는 분이 맞는지 확인합니다. / 아래 가운데 하나를 준비해 주시면 됩니다.
- 사업자등록증 (주소가 해당 공간인 것)
- 임대차 계약서
- 건물 관리실 확인
- 직원이라면 대표나 관리자와의 통화 확인
직원 혼자 연락하신 경우에는 대표나 관리자와 통화가 되어야 진행합니다. / 번거로우시겠지만 공간을 지키기 위한 절차입니다.

# 영업 중 작업과 시간 맞추기
출입문 도어락을 바꾸거나 손보는 작업은 손님이 드나드는 시간에는 하기 어렵습니다. / 영업 전 이른 시간이나 마감 후로 일정을 잡으면 영업에 방해가 덜 됩니다.
작업 시간대와 문 종류, 바꿀 범위를 보고 작업 전에 비용을 먼저 말씀드립니다. / 동의하실 때만 시작하며, 문을 열지 못하면 비용은 받지 않습니다. 진행 방식은 [이용안내](guide.html)에 있습니다.

# 출입 기록이 필요하다면
누가 언제 문을 열었는지 확인해야 하는 사무실이라면 출입 기록 기능이 있는 도어락을 고려해 보세요. / 직원 수가 많거나 귀중한 물건을 보관하는 곳이라면 쓸모가 있습니다.
다만 기능이 많을수록 관리할 것도 늘어납니다. / 실제로 기록을 확인할 사람이 있는지 먼저 정한 뒤 고르시는 게 좋습니다.

# 수리와 교체 판단
잠김이 불안하거나 번호판이 자주 먹통이라면 [도어락 수리](doorlock-repair.html)로 먼저 점검합니다. / 사람이 많이 드나들어 부품이 심하게 닳았거나 문 구조에 맞지 않는 제품이라면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 갈현동 말고 과천 어디든
별양동, 부림동, 원문동, 중앙동, 문원동까지 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 유리문 도어락도 손봐 주시나요? | 네, 유리문 구조를 보고 맞는 방법으로 점검하고 교체합니다.
