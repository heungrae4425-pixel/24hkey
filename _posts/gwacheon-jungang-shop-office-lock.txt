# 과천 중앙동 상가 문이 안 열릴 때
중앙동은 과천역과 가까운 상가와 사무실이 모여 있는 동네입니다. / 아침 일찍 문을 여는 가게일수록 출입문이 안 열리면 하루 장사가 통째로 걸립니다.
사무실 도어락은 집보다 사용 횟수가 훨씬 많습니다. / 여러 사람이 하루에도 수십 번 쓰다 보니 고장이 나는 순서도 집과 조금 다릅니다.
이 글은 과천 중앙동에서 상가나 사무실 출입문이 안 열릴 때 먼저 확인할 것을 정리했습니다. / 그다음 [과천 출장열쇠](gwacheon.html)를 부르면 어떻게 진행되는지 적었습니다.
@ 과천 중앙동 상가 사무실 출입문 출장열쇠

# 상가 출입문이 막히는 흔한 경우
문이 안 열리는 이유는 크게 네 가지로 나뉩니다. / 어느 쪽인지에 따라 직접 해볼 수 있는 일이 달라집니다.
- 번호 도어락 배터리가 닳아서 번호판이 꺼진 경우
- 직원이 비밀번호를 바꿨는데 공유가 안 된 경우
- 셔터나 유리문 하단 잠금장치가 걸려 열쇠가 안 돌아가는 경우
- 전날 마감하면서 보조키를 이중으로 잠근 경우
가게는 마감 담당과 오픈 담당이 다른 일이 많습니다. / 그래서 비밀번호나 열쇠 전달이 한 번 빠지면 아침에 문 앞에서 막히게 됩니다.

# 오픈 시간 전에 이것부터 확인하세요
전화하기 전에 몇 가지만 보시면 상황을 훨씬 빨리 설명할 수 있습니다.
- 번호판에 손을 대면 불이 들어오는지
- 번호를 누를 때 소리가 나는지, 경고음이 나는지
- 열쇠를 꽂았을 때 들어가는지, 돌아가지 않는지
- 문틈으로 안쪽 잠금이 걸려 있는지
불이 전혀 안 들어오면 배터리일 가능성이 큽니다. / 소리는 나는데 안 열리면 모터나 걸쇠 쪽을 의심합니다.

# 배터리가 원인일 때 비상 전원
많은 도어락은 바깥쪽 아래에 9V 건전지를 대는 비상 단자가 있습니다. / 건전지를 대고 있는 동안 번호판에 불이 들어와 번호를 누를 수 있습니다.
과천역 쪽 편의점이나 근처 상점에서 9V 건전지를 구할 수 있습니다. / 단자가 없는 제품이거나 대 봐도 반응이 없으면 전화 주시면 됩니다.
문이 열리면 가게에 있는 모든 도어락의 배터리를 날짜를 적어 한 번에 바꿔 두세요. / 하나만 바꾸면 며칠 뒤 다른 문에서 같은 일이 생깁니다.
@ 과천 상가 도어락 배터리 비상 전원

# 무리하게 열다가 커지는 일
급한 마음에 문을 흔들거나 공구로 문틈을 벌리는 분이 있습니다. / 유리문이나 알루미늄 문틀은 한 번 휘면 도어락 위치가 틀어져 일이 커집니다.
카드나 얇은 판으로 걸쇠를 밀다가 부러뜨리는 경우도 많습니다. / 걸쇠 조각이 안에 남으면 열쇠로도 못 여는 상황이 됩니다.
비밀번호를 여러 번 틀리면 도어락이 입력을 한동안 막습니다. / 서너 번 해보고 안 되면 멈추는 쪽이 낫습니다.

# 직원이 여럿인 가게라면
출입문을 여는 사람이 여럿이면 비밀번호 관리가 가장 먼저 문제가 됩니다. / 그만둔 직원이 번호를 아는 상태로 남아 있는 가게도 흔합니다.
번호를 바꿀 때는 가게 안에서 누가 알고 있어야 하는지부터 정리해 두면 좋습니다. / 그 기준대로 새 번호를 등록하고 이전 번호는 지웁니다.
열쇠와 카드키를 쓰는 곳이라면 몇 개가 나가 있는지 적어 두세요. / 분실이 의심되면 잠금 쪽을 새로 맞추는 것도 방법입니다.

# 사무실 출입문과 가게 문은 어떻게 다른가
사무실 문은 방화문이나 철문이 많아 문이 무겁습니다. / 문이 처지면 걸쇠가 문틀에 걸려서 안 빠지는 일이 생깁니다.
가게 유리문은 하단 바닥 잠금과 도어락이 같이 걸려 있는 경우가 많습니다. / 한쪽만 풀어서는 안 열리니 두 곳을 모두 확인해야 합니다.
어느 쪽이든 문 종류를 알려주시면 챙겨 가는 장비가 정확해집니다. / 사진을 문자로 보내주시면 가장 빠릅니다.

# 전화할 때 알려주실 것
위치를 정확히 알려주시면 도착이 빨라집니다. / 건물 이름이 없어도 근처 역이나 큰길 방향을 말씀해 주시면 찾아갑니다.
- 어느 건물 몇 층인지, 출입문이 건물 입구인지 가게 문인지
- 과천역, 정부과천청사역 중 어느 쪽에 가까운지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 도어락 모양과 문 재질 (유리, 철, 나무)
- 영업 시작까지 남은 시간
사진을 먼저 보내주시면 장비를 맞춰 출발할 수 있습니다. / 급한 사정이 있으면 꼭 먼저 말씀해 주세요.
@ 과천 중앙동 24시 출장열쇠 현장

문을 여는 일이라 이 가게의 사람이 맞는지 먼저 확인합니다. / 사업자등록증 사본, 명함, 건물 관리실 확인 중 하나면 됩니다.
번거로우시겠지만 문을 여는 일은 확인이 먼저라야 합니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다.
건물 관리실이 있다면 먼저 말씀해 두세요. / 관리실 확인으로 대신할 수 있는 경우도 있습니다.

# 비용은 문을 열기 전에 말씀드립니다
문 종류와 도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 연 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 최대한 안 상하게 엽니다
문 여는 방법은 여러 가지가 있고, 덜 상하는 방법부터 차례로 해봅니다. / 유리문과 문틀이 상하지 않게 하는 것이 먼저입니다.
작업 중 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다. / 현관문 개문 방법은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.

# 문이 열린 뒤에 할 일
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새 배터리로 바꿨는지도 함께 봅니다.
번호를 잊어서 연 경우에는 새 번호 등록까지 도와드립니다. / 기존 번호는 지우고 새 번호만 남겨 둡니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 고장이 잦으면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 상가 도어락 오래 쓰는 관리법
사용 횟수가 많은 만큼 정기 점검이 중요합니다.
- 배터리는 분기마다 날짜를 적어 한 번에 교체
- 경고음이 나면 그날 바로 교체
- 마감할 때 보조키 잠금 여부를 같이 확인
- 직원이 바뀌면 비밀번호도 같이 변경
- 문이 덜 닫히면 경첩과 문틀 처짐 점검
점검표를 문 안쪽에 붙여 두면 담당이 바뀌어도 이어집니다. / 작은 습관으로 오픈 시간에 문 앞에서 막히는 일을 많이 줄일 수 있습니다.

# 중앙동 말고 과천 어디든 갑니다
별양동, 부림동, 원문동, 갈현동, 문원동도 다닙니다. / 과천 안이면 동네 상관없이 24시간 출동합니다.
과천에서 다니는 동네는 [과천시 출장열쇠](gwacheon.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
