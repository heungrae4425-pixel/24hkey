# 번호는 풀렸는데 문이 안 열린다면
문원동은 과천에서 주택가와 새 아파트가 함께 있는 동네입니다. / 새 아파트는 신형 도어락에 안전 걸쇠를 기본으로 단 집이 많고, 주택가는 번호키 위에 열쇠식 보조키를 따로 단 집이 많습니다.
번호를 눌러 도어락은 분명 풀렸는데 문이 안 열리거나, 조금 열리다 덜컥 걸리는 경우가 있습니다. / 이럴 때는 도어락이 아니라 보조 잠금장치가 문을 잡고 있는 겁니다.
보조 잠금은 종류마다 풀 수 있는 방법이 다릅니다. / 이 글은 문원동 현관에서 흔히 보이는 세 가지 보조 잠금을 나눠, 어떤 경우인지 알아보는 법과 푸는 순서를 정리했습니다.
@ 문원동 현관 보조키 안전 걸쇠 걸림

# 세 가지 중 어느 것인지 먼저 알기
현관 보조 잠금은 크게 세 가지입니다. / 문을 조금 열어 보거나 바깥 모양만 봐도 어느 쪽인지 짐작할 수 있습니다.
- 열쇠로 여닫는 보조키, 문이 전혀 안 움직임
- 안쪽에 거는 말굽형이나 줄형 안전 걸쇠, 문이 한 뼘쯤 열리고 멈춤
- 도어락 안쪽의 이중 잠금 버튼, 번호를 눌러도 경고음만 남
문이 전혀 안 움직이면 보조키나 이중 잠금을, 조금 열리다 멈추면 안전 걸쇠를 의심하시면 됩니다. / 이 구분만으로도 통화가 훨씬 짧아집니다.

# 열쇠식 보조키가 잠겨 있을 때
보조키는 밖에서 열쇠로 잠그고 여는 장치입니다. / 평소엔 안 쓰다가 여행 갈 때나 가족이 습관처럼 잠그고 나가서 문제가 됩니다.
열쇠가 있다면 끝까지 넣고 천천히 돌려 보세요. / 뻑뻑하면 문을 살짝 밀거나 당기면서 돌리면 걸쇠에 걸린 힘이 빠져 돌아가는 경우가 많습니다.
열쇠가 없거나 어디 있는지 모른다면 억지로 열려고 하지 마세요. / 실핀이나 다른 열쇠를 넣으면 안쪽 핀이 상해 여는 시간이 더 길어집니다.

# 말굽형 안전 걸쇠가 걸렸을 때
문이 한 뼘쯤 열리고 덜컥 멈춘다면 안쪽의 안전 걸쇠가 걸려 있는 겁니다. / 새 아파트에서 흔한 말굽 모양 걸쇠는 문을 닫을 때 저절로 넘어가 걸리는 경우도 있습니다.
집 안에 가족이 있다면 문을 한 번 완전히 닫은 뒤 걸쇠를 풀어 달라고 부탁하세요. / 걸쇠가 팽팽하게 당겨진 상태에서는 안에서도 잘 안 풀리기 때문에, 문을 닫아 여유를 만드는 게 먼저입니다.
집 안에 아무도 없는데 걸쇠가 걸렸다면 문틈으로 손이나 도구를 넣지 마세요. / 걸쇠가 휘거나 손을 다칠 수 있고, 문틀에도 자국이 남습니다.
@ 문원동 새 아파트 말굽형 안전 걸쇠

# 줄형 걸쇠는 조금 다릅니다
오래된 주택에는 줄로 된 안전 걸쇠를 단 집도 있습니다. / 줄형은 말굽형보다 여유가 조금 더 있어 문이 더 넓게 열리기도 합니다.
그만큼 문틈으로 손을 넣어 보려는 분이 많은데, 줄 고정판이 문틀에서 뜯기는 경우가 있습니다. / 한 번 뜯긴 고정판은 다시 달 때 문틀 보수가 필요할 수 있어 피해 주세요.
줄형 걸쇠가 걸린 채 문이 열려 있다면 그 상태로 문을 오래 두지 말고 일단 닫아 두세요. / 바람에 문이 흔들리며 줄이 당겨지면 고정 나사가 더 헐거워집니다.

# 도어락 이중 잠금이 켜졌을 때
신형 도어락 중에는 안쪽에 버튼이나 레버로 이중 잠금을 거는 기능이 있습니다. / 이게 켜져 있으면 밖에서 번호를 맞게 눌러도 경고음만 나고 열리지 않습니다.
집 안에 있던 가족이 밤에 켜 두고 그대로 나간 경우가 흔합니다. / 이중 잠금 표시가 바깥 번호판에 뜨는 제품도 있으니 번호판을 잘 살펴보세요.
이 기능은 밖에서 풀 수 없게 만든 장치라 번호를 계속 누르면 입력만 막힙니다. / 이럴 때는 연락 주시면 도어락 종류에 맞는 방법으로 엽니다.

# 문원동에서 해 보기 전에 지킬 것
보조 잠금은 대부분 밖에서 쉽게 열리지 않도록 만든 장치입니다. / 그래서 무리하게 열수록 장치와 문이 상하기 쉽습니다.
- 문틈에 카드, 옷걸이, 드라이버 넣지 않기
- 문을 발로 밀거나 어깨로 치지 않기
- 번호를 여러 번 바꿔 누르지 않기
- 걸쇠를 끊으려고 하지 않기
이 네 가지만 지키셔도 기사가 도착했을 때 훨씬 빨리, 덜 상하게 열 수 있습니다.

# 연락 주실 때 알려 주시면 좋은 것
어떤 보조 잠금인지 알려 주시면 맞는 장비를 챙겨 갈 수 있습니다. / 아래 내용을 함께 말씀해 주세요.
- 문이 전혀 안 움직이는지, 한 뼘쯤 열리는지
- 보조키가 있다면 사진, 열쇠가 있는지
- 번호를 누르면 어떤 소리가 나는지
- 단지 이름과 동, 호수 또는 주소
집 안에 아이나 어르신, 반려동물이 있다면 꼭 먼저 말씀해 주세요. / 안에 있는 분이 걸쇠를 풀 수 있게 전화로 함께 안내해 드리기도 합니다.

# 거주 확인과 금액 안내
문을 열기 전에 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
보조 잠금 종류와 문 상태를 보고 작업 전에 금액을 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하며, 끝내 열지 못하면 비용은 받지 않습니다. 진행 흐름은 [이용안내](guide.html)에 정리해 두었습니다.

# 종류에 맞춰 덜 상하게 엽니다
보조키는 열쇠 구멍 쪽으로, 안전 걸쇠는 걸쇠 쪽으로, 이중 잠금은 도어락 구조에 맞춰 각각 다른 방법을 씁니다. / 어느 경우든 문과 장치가 덜 상하는 방법부터 차례로 시도합니다.
여는 방식은 [현관문 개문](door-open.html)에 자세히 적어 두었습니다. / 작업 시간은 종류에 따라 달라 도착해서 보고 먼저 말씀드립니다.

# 열린 뒤 다시 걸리지 않게
문이 열리면 왜 걸렸는지 함께 확인합니다. / 말굽형 걸쇠가 저절로 넘어간 거라면 걸쇠 위치나 각도를 손보고, 보조키가 뻑뻑했다면 실린더 상태를 봅니다.
보조키를 거의 안 쓰신다면 이번에 떼어 내고 번호키 하나로 정리하는 방법도 있습니다. / 구멍 마감까지 함께 하려면 [도어락 설치](doorlock-install.html)에서 문 상태를 먼저 확인해 보세요.
도어락 이중 잠금 버튼이 너무 쉽게 눌리는 구조라면 [도어락 수리](doorlock-repair.html)로 손보거나 사용법을 다시 알려 드립니다.
@ 과천 문원동 보조키 실린더 상태 점검

# 가족끼리 정해 두면 좋은 약속
보조 잠금 때문에 막히는 일은 대부분 습관에서 생깁니다. / 가족끼리 몇 가지만 정해 두면 같은 일이 크게 줄어듭니다.
안전 걸쇠는 집에 사람이 있을 때만 걸고, 마지막에 나가는 사람이 걸쇠와 이중 잠금을 꼭 풀어 두기로 정해 보세요. / 보조키를 잠그고 나가는 날은 가족 모두에게 알리는 것도 좋은 습관입니다.
현관 안쪽에 작은 메모를 붙여 두면 나가기 전에 한 번 더 떠올리게 됩니다.

# 문원동 말고 과천 어디든
갈현동, 별양동, 부림동, 원문동, 중앙동까지 과천이라면 어디든 갑니다. / 지역 안내는 [과천 출장열쇠](gwacheon.html), 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.
