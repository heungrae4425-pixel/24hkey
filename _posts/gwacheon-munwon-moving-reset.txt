# 과천 문원동 이사 첫날, 도어락부터
이사한 날은 짐 풀기에 정신이 없어서 도어락은 뒤로 미뤄지기 쉽습니다. / 그런데 새 집 도어락에는 이전 주인이나 이사 업체가 쓰던 번호가 남아 있을 수 있습니다.
문원동은 과천에서도 비교적 새로 입주한 집이 많은 동네입니다. / 새 집일수록 이전 사용자 기록이 어떻게 남아 있는지 한 번 정리하고 시작하는 게 좋습니다.
이 글은 문원동으로 이사하고 나서 도어락 번호를 새로 정할 때 순서를 정리했습니다. / 직접 해볼 수 있는 부분과 [출장 열쇠](key-call.html)를 부르면 좋은 부분을 나눠 적었습니다.
@ 과천 문원동 이사 후 도어락 초기화

# 이전 번호가 남아 있다는 게 왜 문제일까
이사를 나간 사람이 번호를 알고 있을 수 있습니다. / 일부러 들어오지 않더라도 불안한 상태로 사는 것은 좋지 않습니다.
이사 업체나 입주 청소 업체가 번호를 받아 간 일도 있습니다. / 일이 끝난 뒤에 번호를 바꿨다는 확인을 못 받았다면 그대로일 수 있습니다.
카드키나 지문도 같습니다. / 등록된 카드나 지문이 몇 개인지 먼저 확인해야 합니다.

# 직접 해볼 수 있는 확인
도어락 안쪽 덮개를 열면 설정 버튼이 있는 제품이 많습니다. / 제품 설명서에 나온 방법으로 등록된 번호와 카드를 확인하거나 삭제할 수 있습니다.
- 안쪽 덮개를 열고 설정 버튼 위치 확인
- 등록된 번호 개수와 카드 개수 확인
- 삭제 방법이 설명서에 있는지 확인
- 관리자 번호가 따로 있는지 확인
설명서가 없으면 제품 이름과 모델명을 적어 두세요. / 제조사 안내문을 찾는 데 쓰입니다.

# 초기화가 안 될 때는
초기화 방법은 제품마다 다릅니다. / 전원을 뺐다 꽂는 방식도 있고, 안쪽 버튼을 길게 누르는 방식도 있습니다.
방법을 잘못 따라 하면 번호는 지워졌는데 새로 등록이 안 되는 상황이 생기기도 합니다. / 그러면 문 안과 밖이 모두 막힐 수 있습니다.
혼자 해 보다가 잘 안 되면 번호판에 손대기 전에 연락 주세요. / 이미 막혔다면 [현관문 개문](door-open.html) 순서로 진행합니다.

# 문 안에 사람이 있는 상태에서 하세요
도어락 초기화나 번호 변경은 문 안에서 하는 게 안전합니다. / 문이 열려 있는 상태에서 새 번호로 열고 닫아 보며 확인해야 하기 때문입니다.
밖에서 번호를 바꿨는데 제대로 등록이 안 되면 들어갈 방법이 없습니다. / 그래서 작업은 문을 열어 둔 채로, 가능하면 두 사람이 같이 합니다.
새 번호를 정했으면 안쪽에서 열고 잠그기를 최소 두세 번 해 보세요.
@ 문원동 도어락 새 번호 등록 확인

# 새 번호를 정할 때
생일이나 전화번호 뒷자리처럼 남이 짐작하기 쉬운 번호는 피하세요. / 같은 숫자가 반복되거나 순서대로 이어지는 번호도 쉽게 알려집니다.
- 너무 짧지 않게, 가능한 한 길게
- 이전에 쓰던 번호와 겹치지 않게
- 가족이 외우기 쉬운 규칙으로
- 문 밖에서 누를 때 손가락 자국이 남지 않게 가끔 닦기
번호를 정하고 나서는 종이에 적어 도어락 근처에 붙이지 마세요. / 가족과 안전하게 공유하는 방법을 정해 두는 것이 낫습니다.

# 카드와 지문도 같이 정리합니다
카드키는 이전 사용자가 쓰던 카드가 아직 등록되어 있을 수 있습니다. / 모든 카드를 지우고 새로 등록하는 것이 가장 확실합니다.
지문은 여러 명 등록이 가능한 제품이 많습니다. / 이전에 등록된 지문이 있다면 새 사람 지문만 남도록 전체 삭제부터 합니다.
지우고 나면 처음에 열쇠로 한 번 열어서 문이 정상인지 확인하세요. / 비상 열쇠가 있는 제품이면 열쇠 보관 위치도 정해 두세요.

# 보조키와 열쇠도 확인하세요
도어락과 별도로 문 위쪽에 보조키가 달린 집이 많습니다. / 보조키 열쇠를 이전 사용자가 갖고 있을 수 있습니다.
열쇠를 몇 개 받았는지, 복사본은 없는지 입주 때 확인해 두면 좋습니다. / 열쇠를 모두 받지 못했다면 잠금 쪽을 새로 맞추는 방법도 있습니다.
현관문 열쇠를 바꾸는 일은 [출장 열쇠](key-call.html) 쪽에서 같이 처리합니다.
@ 과천 보조키 열쇠 교체 출장열쇠

# 출장열쇠를 부르면 이렇게 합니다
방문해서 도어락 종류를 보고 초기화가 되는 제품인지부터 확인합니다. / 이전 번호와 카드를 모두 지우고 새 번호를 등록해 드립니다.
등록이 끝나면 문을 열고 닫아 보며 정상인지 같이 확인합니다. / 필요하면 새 배터리도 같이 갈아 드립니다.
도어락이 너무 오래되었다면 [도어락 교체](doorlock-replace.html)를 말씀드릴 수 있습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 이사 당일 시간을 아끼는 순서
이삿짐센터가 도착하기 전에 도어락 번호부터 정리해 두면 짐 나르는 동안 문 앞에서 막히지 않습니다. / 가능하면 이사 전날이나 당일 아침에 먼저 들러서 확인하세요.
- 이전 번호가 남아 있는지 확인
- 배터리를 새것으로 바꾸기
- 열쇠 개수와 보조키 확인
- 문이 처지지 않았는지 보기
- 카드나 지문 등록 여부 확인
짐을 나르는 동안 문을 열어 둔 채로 두면 번호를 바꾸는 동안 안전합니다. / 짐을 다 들인 뒤 마지막에 문을 닫고 새 번호로 열리는지 바깥에서 한 번 더 확인하세요.
이삿짐 업체 직원에게 임시 번호를 알려줄 때는 작업이 끝난 뒤 반드시 지우는 습관을 들이세요. / 이사 날에 잠깐 쓰고 지우지 않는 번호가 가장 흔한 보안 구멍입니다.

# 비용은 시작 전에 말씀드립니다
작업을 시작하기 전에 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
말없이 붙는 비용은 없고, 부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문원동 말고 과천 어디든 갑니다
별양동, 부림동, 원문동, 중앙동, 갈현동도 다닙니다. / 과천 안이면 동네 상관없이 24시간 출동합니다.
과천 지역 정보는 [과천시 출장열쇠](gwacheon.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

문원동은 과천역과 대공원역 사이에서 오가는 분이 많아 이사 철에는 낮 시간대 문의가 몰리는 편입니다. / 이사 일정이 정해지면 미리 연락해 두시면 시간을 맞추기 수월합니다.
이사 직후에는 짐 정리에 바빠 도어락을 잊기 쉽지만, 첫 주 안에 한 번 점검해 두면 오래 편합니다. / 사소한 이상도 일찍 알려주시면 좋습니다.
