# 원문동에서 지문이 갑자기 인식되지 않을 때
과천 원문동은 주택과 빌라, 아파트가 어우러진 조용한 주거 동네입니다. / 어제까지 잘 열리던 지문 도어락이 오늘은 계속 실패한다는 연락이 가끔 들어옵니다.
손가락을 올려도 삑 소리만 나거나, 아예 반응이 없거나, 여러 번 해야 겨우 열리는 증상이 대표적입니다. / 원인은 손가락 쪽일 수도 있고 도어락 쪽일 수도 있어 구분해 보는 것이 좋습니다.
이 글은 원문동에서 지문 인식이 안 될 때 전화하기 전에 해볼 것을 정리했습니다. / 마지막에는 [과천 출장열쇠](gwacheon.html)가 오는 순서도 적었습니다.
@ 원문동 지문 도어락 인식 실패 출장열쇠

# 손가락 상태부터 확인
손이 젖었거나 너무 건조하면 지문이 흐릿하게 읽힙니다. / 로션을 바른 직후나 설거지 직후에는 더 그렇습니다.
손가락에 상처가 났거나 지문이 닳은 경우도 인식률이 떨어집니다. / 겨울철 건조한 날씨에도 같은 증상이 늘어납니다.
손을 마른 수건으로 닦고 다른 손가락으로 시도해 보세요. / 등록해 둔 다른 손가락이 있다면 그쪽이 잘 될 수도 있습니다.
@ 원문동 지문 센서 손가락 인식

# 센서 표면도 확인
지문을 읽는 부분에 먼지, 기름, 물때가 쌓이면 인식이 둔해집니다. / 부드러운 마른 천으로 가볍게 닦아 주세요.
센서에 스크래치가 났거나 이물질이 끼어 있지는 않은지 살펴보세요. / 손톱이나 날카로운 도구로 긁지는 마세요.
센서 주변이 습기로 젖어 있지 않은지도 확인합니다. / 물기를 닦고 잠시 뒤 다시 시도해 보세요.

# 배터리가 약해도 지문이 안 됩니다
지문 센서는 번호판보다 전력을 더 쓰는 편이라 배터리가 약하면 먼저 반응이 느려집니다. / 번호 입력은 되는데 지문만 안 된다면 배터리를 의심해 볼 만합니다.
번호판 아래쪽 비상 단자에 9V 건전지를 대고 번호로 여는 방법이 있습니다. / 열린 뒤에는 배터리를 모두 새것으로 바꿔 주세요.
일부만 바꾸면 며칠 안에 같은 증상이 다시 생기기 쉽습니다. / 알림이 약한 제품은 더 신경 써서 확인하세요.

손가락이 오래 쓰이거나 상처가 나면 처음 등록한 지문과 달라질 수 있습니다. / 아이들은 손이 자라면서 인식률이 떨어지는 일이 많습니다.
이럴 때는 지문을 다시 등록하면 해결됩니다. / 같은 손가락을 여러 각도로 두세 번 등록해 두면 더 잘 읽힙니다.
등록 방법은 제품마다 달라 설명서를 보는 것이 좋습니다. / 어렵다면 무리하지 말고 연락 주세요.

# 해서는 안 되는 일
지문 센서를 분해하거나 날카로운 도구로 청소하려는 분이 있습니다. / 센서가 상하면 부품 교체가 필요해질 수 있습니다.
알코올이나 세정제를 직접 뿌리는 것도 권하지 않습니다. / 안쪽으로 스며들어 회로가 상할 수 있습니다.
인식이 안 된다고 번호판을 억지로 열려는 것도 위험합니다. / 그대로 두고 연락 주시는 것이 안전합니다.

# 이럴 땐 바로 연락 주세요
번호와 지문 모두 안 되고 비상 전원도 소용없을 때입니다. / 문 앞에서 오래 기다리고 계시는 경우도 마찬가지입니다.
집 안에 아이나 반려동물이 혼자 있거나 가스, 전기를 켜 둔 상태라면 먼저 말씀해 주세요. / 급한 순서를 정해 출동합니다.
24시간 받습니다. / 위치와 상황을 말씀해 주시면 출동 여부와 도착 시간을 먼저 말씀드립니다.

# 전화할 때 알려 주실 내용
원문동은 주택과 빌라, 아파트가 섞여 있어 건물 종류를 알려 주시면 도착이 빨라집니다. / 근처에서 눈에 띄는 건물을 함께 말씀해 주세요.
- 건물 종류와 몇 층인지
- 지문만 안 되는지, 번호도 안 되는지
- 배터리 교체를 해보았는지
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 챙겨 갈 부품을 정하는 데 도움이 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집 주인을 모두 지키는 절차입니다. / 확인이 어려우면 작업할 수 없으니 미리 준비해 두세요.
신분증이 집 안에 있다면 휴대폰에 저장된 서류도 도움이 됩니다. / 관리사무소가 있다면 세대 확인을 부탁하는 방법도 있습니다.
@ 원문동 24시 출장열쇠 도어락 점검

# 먼저 문을 열고 원인을 확인합니다
문을 상하지 않게 여는 방법부터 차례로 해봅니다. / 열고 나서는 센서, 배터리, 회로 상태를 순서대로 살핍니다.
원인이 센서 오염이나 배터리라면 정리하고 바꾸는 것으로 끝나는 일이 많습니다. / 방식은 [현관문 개문](door-open.html)에 자세히 적어 두었습니다.
못 열면 비용은 받지 않습니다. / 문 열기 전에 비용을 먼저 말씀드립니다.

# 비용은 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
열고 난 뒤에 말 없이 붙는 비용은 없습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 수리할지 교체할지 판단하는 기준
센서 오염, 배터리, 등록 문제는 대부분 간단히 고쳐서 쓸 수 있습니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)로 해결합니다.
센서 자체가 상했거나 제품이 너무 오래됐다면 교체를 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
교체할 때는 문 규격에 맞는 제품을 고르는 것이 중요합니다. / [도어락 교체](doorlock-replace.html) 페이지에 방식을 정리해 두었습니다.

# 지문 인식을 오래 잘 쓰는 습관
- 번호 입력 수단을 항상 함께 쓰도록 등록해 두기
- 센서를 가끔 마른 천으로 닦아 주기
- 같은 손가락을 여러 각도로 두세 번 등록해 두기
- 배터리는 한꺼번에 새것으로 바꾸기
- 비상용 9V 건전지를 현관 서랍에 넣어 두기
작은 습관만으로 문 앞에서 막히는 일이 크게 줄어듭니다.

# 원문동 말고 과천 어디든 갑니다
별양동, 부림동, 중앙동, 갈현동, 문원동까지 과천 전 지역을 다닙니다. / 위치를 받으면 도착 시간을 바로 말씀드립니다.
과천에서 다니는 지역은 [과천시 출장열쇠](gwacheon.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

지문 인식은 편한 만큼 날씨와 손 상태에 영향을 많이 받는 방식입니다. / 그래서 번호나 카드 같은 다른 수단을 꼭 함께 등록해 두라고 안내해 드립니다.
여러 번 실패하면 일정 시간 입력이 막히는 제품도 있어 잠시 기다린 뒤 다시 시도하는 것이 좋습니다.
