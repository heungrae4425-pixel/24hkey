# 언제 울리는지가 가장 큰 단서입니다
원문동은 과천에서 아파트와 주택가가 함께 있는 동네로, 재건축 뒤 신형 도어락을 쓰는 집이 많습니다. / 신형 제품은 알림 기능이 많은 만큼 소리로 알려 주는 경우도 많아, 낯선 소리에 놀라는 분들이 적지 않습니다.
도어락이 울릴 때 소리 모양을 기억하기는 어렵지만, 언제 울렸는지는 대부분 또렷하게 떠올릴 수 있습니다. / 문을 닫은 직후인지, 한밤중인지, 번호를 누를 때인지만 알아도 원인이 꽤 좁혀집니다.
이 글은 원문동 현관 도어락이 울리거나 헛도는 오작동을 울리는 때에 따라 나눠 정리했습니다. / 해당하는 때만 골라 읽으셔도 됩니다.
@ 원문동 아파트 도어락 경고음 오작동

# 문을 닫은 직후 계속 울린다면
문을 닫았는데 경고음이 그치지 않으면 대부분 문이 덜 닫혔거나 자동 잠금이 제대로 안 걸린 경우입니다. / 도어락이 잠금이 안 됐다고 알려 주는 소리입니다.
문을 한 번 더 끝까지 밀어 닫아 보세요. / 그래도 울리면 걸쇠가 문틀 구멍에 들어가다 걸렸거나, 문 닫힘을 알아보는 센서가 자석과 어긋나 있을 수 있습니다.
도어클로저가 약해져 문이 마지막에 덜 닫히는 집에서 자주 생깁니다. / 이런 집은 문을 손으로 끝까지 밀어 주면 멈추는데, 매번 그래야 한다면 클로저와 경첩 점검이 필요합니다.

# 외출 중에 휴대폰으로 알림이 왔다면
앱과 연결된 도어락은 문이 열린 채로 있거나 여러 번 틀린 입력이 있으면 휴대폰으로 알려 줍니다. / 외출 중에 갑자기 알림이 오면 놀랄 수밖에 없습니다.
먼저 집에 가족이 있는지 연락해 보세요. / 가족이 문을 열어 둔 채 짐을 옮기고 있었거나, 아이가 번호를 잘못 누른 경우가 많습니다.
아무도 없는데 알림이 반복된다면 문이 덜 닫혀 있을 수 있습니다. / 가까운 이웃이나 관리사무소에 문 상태를 봐 달라고 부탁해 보시고, 걱정되면 연락 주세요.

# 한밤중에 혼자 울린다면
아무도 손대지 않았는데 밤에 울리면 대부분 번호판에 맺힌 물기나 먼지 때문입니다. / 바깥과 집 안의 온도 차가 커지는 늦가을부터 겨울 사이에 특히 잦습니다.
마른 천으로 번호판을 닦고 잠시 두어 보세요. / 물티슈나 젖은 걸레는 물기를 더 남기니 피해 주세요.
안쪽 몸체에 경보 기능이 켜져 있는 제품이라면 문에 충격이 가해졌을 때도 울릴 수 있습니다. / 바람에 문이 흔들리는 날 울린다면 이 기능이 너무 예민하게 맞춰져 있는지 확인해 보세요.
@ 원문동 도어락 번호판 물기 닦기

# 번호를 누를 때만 경고음이 난다면
번호를 누르면 삐삐 하는 경고음과 함께 열리긴 하는데 소리가 계속 난다면 배터리가 약해졌다는 신호인 경우가 많습니다. / 제품이 아직 열 힘은 있지만 곧 멈출 수 있다고 알려 주는 겁니다.
이 소리가 나기 시작하면 그날 바로 배터리를 전부 새것으로 바꿔 주세요. / 며칠 미루다 번호판이 완전히 꺼지면 문 밖에서 막히게 됩니다.
배터리를 새로 넣었는데도 같은 소리가 난다면 배터리 방향이 하나 바뀌었거나 단자가 녹슬었을 수 있습니다. / 배터리 칸을 열어 하나씩 확인해 보세요.

# 문을 열 때 모터만 헛돈다면
번호를 맞게 눌렀는데 모터가 위잉 하고 돌기만 하고 걸쇠가 안 빠진다면 걸쇠가 문틀에 눌려 있거나 안쪽 연결 부품이 헐거워진 경우입니다. / 문을 살짝 밀거나 당기면서 다시 눌러 보세요.
그래도 헛돌기만 한다면 모터와 걸쇠를 잇는 부품이 닳았을 수 있습니다. / 이 경우 손잡이를 세게 비틀면 부품이 더 상하니 그대로 두고 연락 주세요.

# 이사나 입주 뒤 바로 생긴 오작동
입주하고 얼마 안 돼 오작동이 생겼다면 설정이 처음 상태와 다르게 바뀌어 있을 수 있습니다. / 이전에 살던 분이나 시공 때 켜 둔 기능이 그대로 남아 있는 경우입니다.
자동 잠금 시간, 경보 기능, 소리 크기처럼 설정할 수 있는 항목을 설명서에서 한 번 훑어보세요. / 설정만 바꿔도 대부분의 불편한 소리가 사라집니다.

# 직접 손대면 안 되는 것
오작동이 계속되면 안쪽 몸체를 열어 보고 싶어집니다. / 하지만 배선을 건드리면 회로가 상해 수리가 어려워질 수 있습니다.
- 안쪽 몸체 나사를 풀어 열기
- 소리를 끄려고 배터리를 넣었다 뺐다 반복하기
- 번호판에 물이나 세정제 뿌리기
- 모터가 헛돌 때 손잡이를 세게 돌리기
배터리 교체와 번호판 닦기까지만 해 보시고, 그다음은 점검을 받는 편이 안전합니다.

# 연락 주실 때 알려 주시면 좋은 것
원문동은 단지와 동이 많아 단지 이름과 동, 호수를 먼저 여쭙니다. / 아래 내용을 함께 말씀해 주시면 맞는 장비를 챙겨 갈 수 있습니다.
- 언제 울리는지, 문을 닫은 직후인지 밤중인지
- 배터리는 언제 바꿨는지
- 앱 알림이 함께 오는지
- 지금 문 밖인지 안인지
울리는 소리를 짧게 녹음해 보내 주시면 원인을 좁히는 데 도움이 됩니다.
집 안에 갇혀 문이 안 열리는 상황이라면 그 점부터 먼저 말씀해 주세요. / 안쪽에서 해 볼 수 있는 방법을 전화로 먼저 안내해 드립니다.

# 거주 확인과 금액 안내
문을 열어야 하는 상황이면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
점검 뒤 작업 전에 금액을 먼저 말씀드리고, 괜찮다고 하실 때만 시작합니다. / 끝내 열지 못하면 비용은 받지 않습니다. 진행 흐름은 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 있습니다.

# 고치는 쪽을 먼저 봅니다
걸쇠 위치 조정, 문 닫힘 센서 맞추기, 설정 정리만으로 끝나는 경우가 많습니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)로 마무리합니다.
모터나 회로가 닳아 같은 고장이 반복된다면 수리와 교체를 나란히 놓고 차이를 말씀드립니다. / 바꾸기로 하시면 [도어락 교체](doorlock-replace.html) 순서로 문에 맞는 제품을 고릅니다.
@ 과천 원문동 도어락 문 닫힘 센서 점검

# 오작동을 덜 겪는 생활 습관
작은 습관 몇 가지로 오작동을 많이 줄일 수 있습니다. / 어렵지 않은 것들입니다.
- 경고음이 나면 그날 바로 배터리 전부 교체
- 비 온 뒤나 추운 아침엔 번호판 물기 한 번 닦기
- 문을 닫을 때 손으로 끝까지 밀어 닫기
- 가족이 설정을 바꾸면 서로 알리기
오래 집을 비울 때는 떠나기 전날 배터리를 새로 넣고, 경보 기능이 너무 예민하게 맞춰져 있지 않은지 한 번 확인해 두세요. / 비어 있는 집에서 밤새 울리면 이웃이 먼저 놀라 연락을 주시는 경우도 있습니다.

# 원문동 말고 과천 어디든
별양동, 부림동, 중앙동, 갈현동, 문원동까지 과천이라면 어디든 갑니다. / 지역 안내는 [과천 출장열쇠](gwacheon.html), 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.
