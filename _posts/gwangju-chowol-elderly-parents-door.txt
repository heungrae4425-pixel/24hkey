# 초월읍 부모님 댁에서 문 연락이 오면
멀리 사는 자녀분이 전화를 받고서야 부모님 댁 문 문제를 알게 되는 일이 많습니다. / 초월읍은 주택과 빌라, 연립이 섞여 있어 도어락 종류도 집마다 제각각입니다.
어르신은 불편해도 참고 지내시다가 문이 아예 안 열려서야 연락하시는 경우가 많습니다. / 그래서 안 열리기 전에 한 번 점검해 두는 것이 가장 좋습니다.
이 글은 초월읍 부모님 집 도어락을 점검할 때 눈여겨볼 곳과 어르신이 쓰기 편한 설정을 정리했습니다. / 문이 이미 안 열리는 상황이라면 [광주 출장열쇠](gwangju.html)에 바로 연락 주셔도 됩니다.
@ 초월읍 부모님 집 도어락 점검 출장열쇠

# 어르신 집 도어락에서 가장 흔한 불편
도어락 문제는 기계 고장보다 사용 습관에서 시작되는 일이 많습니다.
- 작은 번호 버튼이 잘 안 보여서 틀리게 누르는 경우
- 비밀번호를 여러 번 틀려 한동안 입력이 막히는 경우
- 경고음이 나도 무슨 뜻인지 몰라 그냥 두는 경우
- 열쇠를 어디 뒀는지 몰라 번호만 믿다가 낭패를 보는 경우
기계를 탓하시기 전에 어르신이 실제로 어떻게 누르시는지 한 번 지켜보시면 원인이 바로 보입니다.

# 건전지 경고음을 어르신이 놓치지 않게
도어락은 건전지가 약해지면 문을 열 때마다 소리로 알려 줍니다. / 그런데 소리가 작거나 귀가 어두우시면 못 들으시고 지나치기 쉽습니다.
가족 중 한 명이 건전지 교체일을 달력에 적어 두고 해마다 같은 날 바꿔 드리면 좋습니다. / 해가 바뀔 때 전부 새것으로 바꾸는 방식이 가장 단순합니다.
건전지를 일부만 바꾸면 며칠 안에 또 약해집니다. / 남은 건전지가 섞이지 않게 전부 한꺼번에 교체하세요.

# 비밀번호는 기억하기 쉽되 너무 뻔하지 않게
어르신이 외우기 쉽도록 생일이나 전화번호 끝자리를 쓰는 경우가 많습니다. / 하지만 집 주변 사람이 짐작하기 쉬운 번호는 방범에 좋지 않습니다.
자녀분과 함께 정하되 어르신이 손에 익은 숫자 배열을 고르는 정도가 알맞습니다. / 번호는 종이에 적어 현관 근처가 아닌 안전한 곳에 따로 보관하세요.
번호를 바꿀 때는 어르신이 직접 새 번호를 눌러서 열리는지 두세 번 확인해 보시길 권합니다. / 처음 며칠은 가족이 전화로 한 번씩 물어봐 주시면 틀리는 일이 줄어듭니다.

# 열쇠와 카드, 비상 수단을 하나씩
번호가 기억나지 않을 때를 대비해 열쇠나 카드를 하나 따로 두면 훨씬 안심됩니다. / 다만 현관문 위나 화분 아래처럼 뻔한 곳에는 두지 않는 게 좋습니다.
가까운 이웃이나 믿을 만한 가족에게 비상 열쇠를 맡겨 두는 방법도 있습니다. / 연락처를 현관 안쪽 잘 보이는 곳에 적어 두면 급할 때 도움이 됩니다.
카드를 쓰는 도어락이면 카드를 잃어버렸을 때 등록을 지우는 방법도 알아 두세요.

# 문이 잘 안 닫히거나 걸쇠가 헛돈다면
오래 쓴 문은 경첩이 헐거워져 닫힐 때 걸쇠가 문틀에 정확히 들어가지 않을 수 있습니다. / 도어락은 잠겼다고 소리가 나는데 실제로는 덜 잠긴 상태인 경우도 있습니다.
문을 닫은 뒤 손잡이를 한 번 당겨 보게 하는 습관이 도움이 됩니다. / 문이 끝까지 안 닫히면 [도어락 수리](doorlock-repair.html)로 경첩과 걸쇠를 함께 봐 드립니다.
@ 초월읍 도어락 건전지 비밀번호 설정 점검

# 어르신 혼자 계실 때 문이 안 열리면
집 안에 어르신이 계시는데 밖에서 문이 안 열리면 가장 먼저 어르신의 안전이 걱정됩니다. / 연락이 닿는지 먼저 확인해 보세요.
전화를 받지 않으시거나 안에서 응답이 없고 몸이 불편한 상황이 의심되면 119에 먼저 연락하시는 것이 맞습니다. / 구조가 필요한 상황은 열쇠 작업보다 먼저입니다.
안전에 이상이 없고 단순히 문만 안 열리는 상황이라면 그때 연락 주세요. / 문 너머 어르신께 말을 걸어 안심시키면서 진행하겠습니다.

# 자녀분이 대신 연락하실 때 알려주세요
멀리 계신 자녀분이 대신 전화하는 경우가 많아서 몇 가지만 알려주시면 진행이 빨라집니다.
- 부모님 댁 주소와 대략적인 위치, 가까운 역이나 큰 건물
- 지금 집 안에 어르신이 계신지, 몇 분이나 계신지
- 도어락 모양과 번호판 상태(꺼짐, 켜짐, 경고음)
- 현장에서 연락 가능한 가족이나 이웃의 전화번호
어르신께 도착 사실을 미리 알려 놀라지 않으시게 하는 것도 도움이 됩니다.

# 사시는 분인지는 이렇게 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 어르신 신분증, 주소가 나온 우편물, 이웃이나 관리하는 분의 확인 중 하나면 됩니다.
자녀분이 대신 연락하셨다면 부모님 댁이라는 점을 확인할 수 있는 방법을 함께 말씀드립니다. / 어르신과 통화가 가능하면 그 자리에서 동의를 받는 방식이 가장 확실합니다.
번거로우셔도 이웃과 어르신 모두를 위한 절차입니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 어르신이 괜찮다고 하셔야 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에서 미리 보실 수 있습니다.

# 문을 열고 나서 같이 해두면 좋은 것
어르신 댁은 문을 열고 끝내기보다 같이 손봐 두는 편이 낫습니다.
- 건전지를 새것으로 바꾸고 교체일을 적어 두기
- 번호를 어르신이 외우기 쉬운 것으로 다시 정하기
- 경고음이 나는 상황을 어르신께 한 번 들려 드리기
- 비상용 열쇠나 카드가 있는지 확인하기
- 문이 덜 닫히는지, 걸쇠가 잘 들어가는지 보기
새 도어락이 필요하면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 초월읍 24시 출장열쇠 어르신 도어락 개방

# 초월읍 말고 광주 어디든 갑니다
곤지암읍, 퇴촌면, 오포읍, 경안동까지 광주 안이면 어디든 출동합니다. / 24시간 연락 받습니다.
서울, 경기 다른 지역에 계신 부모님 댁은 [출장 지역](area.html) 지도에서 찾아보세요.

24시출장열쇠는 늦은 밤 초월읍에서도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
초월읍처럼 부모님이 따로 지내시는 집은 자녀가 멀리 있을 때가 많습니다. / 그래서 평소에 번호를 쉽게 쓸 수 있게 정하고, 건전지 교체 날짜를 달력에 적어 드리는 것만으로도 큰 도움이 됩니다.
문 앞에서 막혔을 때 부모님이 직접 전화하기 어려우면 자녀분이 대신 연락 주셔도 됩니다. / 이 경우 부모님과 통화로 확인하는 방법을 안내드립니다.
전화하실 때 지금 계신 곳과 문 상태를 짧게만 알려주셔도 충분합니다. / 나머지는 통화하면서 천천히 여쭙겠습니다. 급할수록 천천히 숨을 고르고 연락 주세요.
