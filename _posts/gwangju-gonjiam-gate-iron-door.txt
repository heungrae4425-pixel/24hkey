# 곤지암읍에서 대문이 안 열리면 먼저 보셔야 할 것
곤지암읍은 단독주택과 전원주택이 많아 아파트와 달리 대문이 따로 있는 집이 흔합니다. / 현관문보다 대문이 먼저 말썽을 부리는 일도 잦습니다.
밖에서 대문 앞에 서 있는데 열쇠가 헛돌거나 아예 들어가지 않으면 당황스럽습니다. / 해가 지고 나면 곤지암역 쪽 불빛에서 멀어져 더 막막하게 느껴지기도 합니다.
이 글은 곤지암읍 대문, 철문이 안 열릴 때 전화하기 전에 해볼 수 있는 것을 먼저 적었습니다. / 그다음 [광주 출장열쇠](gwangju.html)를 부르면 어떻게 진행되는지 순서대로 이어서 적었습니다.
급하시면 3번과 5번만 먼저 보셔도 됩니다.
@ 곤지암읍 대문 철문 출장열쇠 24시간

# 곤지암읍 주택은 대문과 현관이 따로 잠깁니다
아파트는 현관문 하나만 열면 되지만 단독주택은 대문, 현관, 때로는 창고 문까지 열쇠가 여러 개입니다. / 어느 문이 문제인지부터 가려야 전화로 설명하기 쉽습니다.
대문은 비바람과 먼지를 그대로 맞기 때문에 현관문보다 빨리 낡습니다. / 열쇠구멍 안쪽에 녹이나 먼지가 쌓이면 열쇠가 뻑뻑해집니다.
대문 자물쇠는 열쇠를 쓰는 형태도 있고 번호나 카드를 쓰는 형태도 있습니다. / 어떤 형태인지 사진으로 보내주시면 챙겨 갈 장비가 달라집니다.

# 대문 열쇠가 안 돌아가는 흔한 이유
열쇠를 꽂았는데 돌아가지 않을 때는 대개 세 가지 중 하나입니다.
- 열쇠구멍 안에 먼지나 녹이 껴서 핀이 걸리는 경우
- 오래 써서 열쇠 홈이 닳아 핀을 끝까지 밀어 올리지 못하는 경우
- 대문이 처져서 걸쇠가 문틀 구멍과 어긋난 경우
세 번째는 열쇠를 돌리는 손에 힘을 주면 더 꽉 물립니다. / 문을 위로 살짝 들어 올리면서 돌려 보면 열리는 때도 있습니다.

# 전화하기 전에 대문 앞에서 1분만 보세요
아래 세 가지를 보시면 원인이 훨씬 빨리 좁혀집니다.
- 열쇠가 끝까지 들어가는지, 중간에서 막히는지
- 열쇠를 돌릴 때 걸리는 느낌인지, 헛도는 느낌인지
- 대문을 안쪽으로 밀거나 들어 올리면 느낌이 달라지는지
끝까지 안 들어가면 구멍 안이 막혔을 가능성이 있고, 헛돌면 내부 부품이 마모됐을 가능성이 있습니다. / 이 말씀만 해주셔도 출장 전에 대략 짐작이 갑니다.

# 철문이 처졌다면 열쇠 문제가 아닐 수 있습니다
오래된 철문은 경첩이 닳으면서 문짝이 아래로 처집니다. / 그러면 잠금 걸쇠와 문틀 구멍이 어긋나서 열쇠는 멀쩡한데 열리지 않습니다.
문이 바닥에 긁히는 소리가 나거나 닫을 때 위쪽 틈이 아래보다 넓다면 처짐을 의심해 볼 만합니다. / 이럴 때는 열쇠를 바꾸는 것보다 경첩을 손보는 쪽이 먼저입니다.
[도어락 수리](doorlock-repair.html)에 경첩과 걸쇠를 함께 보는 방식이 적혀 있습니다.

# 열쇠를 억지로 돌리지 마세요
급한 마음에 열쇠를 세게 비틀면 열쇠가 부러져 구멍 안에 남을 수 있습니다. / 그러면 문 열기보다 먼저 부러진 조각을 빼내는 일이 생깁니다.
펜치로 열쇠 머리를 잡고 흔들거나 망치로 두드리는 것도 피하셔야 합니다. / 자물통 내부 부품이 틀어지면 교체할 범위가 넓어집니다.
기름을 잔뜩 뿌리는 방법도 권하지 않습니다. / 먼지가 엉겨 붙어 나중에 더 뻑뻑해지고, 안쪽 부품을 닦는 데 시간이 더 듭니다.
@ 곤지암 철문 자물쇠 열쇠 안 돌아감 출장

# 대문 잠금장치 종류별로 증상이 다릅니다
같은 대문이라도 잠금장치에 따라 문제가 나타나는 모습이 다릅니다.
- 열쇠식 자물통은 구멍이 막히거나 열쇠 홈이 닳는 증상이 많습니다
- 번호식은 건전지가 다 돼 번호판이 꺼지는 증상이 많습니다
- 카드식은 카드를 대도 반응이 없거나 소리만 나는 증상이 많습니다
- 걸어 잠그는 빗장형은 빗장이 휘거나 구멍이 어긋나는 증상이 많습니다
어떤 종류인지 모르시면 문 바깥쪽을 사진으로 찍어 보내 주세요. / 모양만 봐도 맞는 장비를 챙겨 갈 수 있습니다.

# 곤지암읍 들어오는 길은 이렇게 알려주세요
읍내와 주택가, 산자락 쪽 집은 길이 다르고 마을 안쪽 골목은 차가 들어오기 어려울 수 있습니다. / 어디서 출발하든 정확히 찾아가려면 위치 설명이 중요합니다.
- 곤지암역이나 읍내 큰길에서 어느 쪽으로 들어오는지
- 대문이 길가에 바로 붙어 있는지, 마당 안쪽인지
- 차를 세울 곳이 있는지, 골목 입구에서 걸어야 하는지
- 집 앞에 눈에 띄는 표지나 색깔
지도 앱 위치를 문자로 보내주시면 도착 시간을 먼저 말씀드립니다. / 늦은 밤이라도 같은 방식으로 알려 주시면 됩니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 이웃이나 가족 확인 중 하나면 됩니다.
번거로우실 수 있지만 집을 지키기 위한 절차입니다. / 확인이 어려우면 작업을 시작할 수 없습니다.
신분증이 집 안에 있다면 휴대폰에 저장된 주소 서류나 공과금 고지서도 도움이 됩니다. / 부모님 댁에서 자녀분이 연락 주신 경우에는 가족 확인 방법을 따로 말씀드립니다.

# 비용은 문 열기 전에 말씀드립니다
대문 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 꼭 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 되도록 안 상하게 열어 봅니다
철문과 자물통은 한번 상하면 고치는 데 손이 많이 갑니다. / 그래서 덜 상하는 방법부터 차례로 시도합니다.
열쇠가 구멍에 들어가는 상태라면 구멍 안을 먼저 살펴보고, 부품이 걸린 위치를 확인합니다. / 걸쇠가 어긋난 경우에는 문을 받쳐서 틈을 만든 뒤 잠금을 풉니다.
어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 더 자세히 적어 두었습니다.
@ 광주 곤지암읍 출장열쇠 비파손 개방

# 열고 난 뒤에는 대문을 같이 점검합니다
문이 열리면 대문이 다시 부드럽게 잠기고 열리는지 확인합니다. / 구멍 안 청소나 윤활이 필요한지, 열쇠 복사본이 닳았는지도 봅니다.
열쇠를 새로 만들어야 하면 원본을 보고 [출장 열쇠](key-call.html)로 바로 복사해 드릴 수 있습니다. / 자물통을 아예 바꿔야 한다면 바꾸기 전에 먼저 말씀드립니다.
경첩이 헐거워진 경우에는 조여서 처짐을 바로잡고, 그래도 안 되면 그때 교체를 말씀드립니다.

# 대문 오래 쓰는 관리법
대문은 매일 비바람을 맞는 문이라 조금만 신경 써도 수명이 크게 달라집니다.
- 계절이 바뀔 때 열쇠구멍 먼지를 털고 마른 천으로 닦기
- 경첩 쪽에서 삐걱 소리가 나면 그날 바로 점검하기
- 열쇠 복사본 하나는 집 밖의 믿을 만한 곳에 따로 보관하기
- 번호식이면 해가 바뀔 때 건전지를 한꺼번에 새것으로 교체하기
- 문이 처지는 느낌이 들면 닫히는 위치부터 확인하기
마당 쪽에서 대문을 자주 여닫는 집이라면 철문 아랫부분이 땅에 닿지 않는지도 가끔 보세요. / 흙과 낙엽이 쌓이면 문이 덜 닫히는 원인이 되기도 합니다.

# 곤지암읍 말고 광주 어디든 갑니다
읍내 바깥쪽 마을과 초월읍, 퇴촌면, 오포읍까지 광주 안이면 어디든 출동합니다. / 시간대와 상관없이 24시간 연락 받습니다.
광주에서 다니는 지역은 [광주시 출장열쇠](gwangju.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
