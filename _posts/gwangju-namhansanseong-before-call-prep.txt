# 남한산성면에서 출장을 부를 때 먼저 정리할 것
남한산성면은 산자락을 따라 집과 가게가 흩어져 있어 위치 설명이 도착 시간을 크게 좌우합니다. / 길이 좁고 굽은 곳이 많아서 처음 가는 길은 더 그렇습니다.
문이 안 열려 당황하신 상태에서 전화하면 필요한 이야기를 빠뜨리기 쉽습니다. / 그래서 연락하기 전에 몇 가지만 정리해 두시면 훨씬 빨라집니다.
이 글은 남한산성면에서 [광주 출장열쇠](gwangju.html)를 부를 때 미리 챙기면 좋은 정보를 순서대로 정리했습니다.
@ 남한산성면 출장열쇠 부르기 전 준비

# 준비 1. 지금 서 계신 위치
가장 중요한 정보는 위치입니다. / 주소가 정확하지 않아도 대략 어느 길, 어느 마을인지만 알려주셔도 큰 도움이 됩니다.
- 지도 앱에서 현재 위치를 문자로 보내기
- 가까운 큰길, 마을 입구, 눈에 띄는 건물 이름
- 길가에 바로 붙은 집인지, 골목이나 마당 안쪽인지
- 처음 오는 사람이 헷갈릴 만한 갈림길이 있는지
위치를 받으면 도착 시간을 먼저 말씀드립니다.

# 준비 2. 문 사진 한 장
문 바깥쪽과 잠금장치를 사진으로 찍어 문자로 보내 주세요. / 모양만 봐도 어떤 장비를 챙길지 짐작이 갑니다.
도어락 전체와 번호판, 열쇠구멍이 한 장에 나오면 좋습니다. / 대문이나 철문이라면 자물통 부분과 문 전체를 따로 찍으시면 더 좋습니다.
사진이 어려우면 말로 설명하셔도 됩니다. / 번호판 모양, 손잡이 모양, 열쇠구멍 위치만 말씀해 주세요.

# 준비 3. 지금 어떤 증상인지
문이 안 열리는 모습은 상황마다 다릅니다. / 증상을 정확히 말씀해 주시면 원인을 좁히는 시간이 줄어듭니다.
- 번호판이 꺼져 있는지, 켜져 있는지
- 번호를 누르면 소리가 나는지, 어떤 소리인지
- 열쇠가 들어가는지, 돌아가는지
- 문이 처졌거나 걸쇠가 걸린 느낌이 있는지
- 안쪽에서 잠근 채 닫고 나왔는지
상황이 복잡해 보여도 보이는 대로만 말씀해 주시면 됩니다.

# 준비 4. 집 안에 있는 사람과 동물
집 안에 아이나 어르신, 반려동물이 있는지 꼭 알려주세요. / 그 경우에는 작업 순서와 서두르는 정도가 달라집니다.
가스불이나 전열기구가 켜져 있는지도 말씀해 주세요. / 안전과 관련된 일이면 문 열기보다 먼저 119에 연락하셔야 할 수도 있습니다.
집 안에 사람이 있고 응답이 없는 상황이라면 지체하지 말고 119에 먼저 연락하세요.
@ 남한산성면 문 사진 위치 설명 출장 준비

# 준비 5. 사시는 분인지 확인할 방법
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 이웃 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 휴대폰에 저장된 서류나 가족 확인 방법도 안내드립니다. / 전화하시기 전에 어떤 방법이 가능한지 생각해 두시면 현장에서 빠릅니다.
확인이 안 되면 작업을 시작할 수 없다는 점은 미리 알고 계셔 주세요. / 이웃과 집 주인 모두를 위한 절차입니다.

# 준비 6. 연락 가능한 전화번호
도착 직전에 길을 안내해 드리려면 계속 통화가 되는 번호가 필요합니다. / 휴대폰 배터리가 얼마 안 남았다면 충전기를 찾거나 다른 분의 번호를 알려 주세요.
산자락은 통화가 끊기는 곳도 있어서 문자도 함께 보내 두시면 좋습니다. / 길이 헷갈릴 때 지도 위치를 다시 보내시면 됩니다.

# 전화하면 이렇게 진행됩니다
전화를 주시면 위치와 증상, 문 종류를 간단히 여쭙고 도착 예상 시간을 먼저 말씀드립니다. / 상황에 따라 해볼 수 있는 것이 있으면 그것도 알려 드립니다.
현장에 도착하면 사시는 분인지 확인하고 문을 살핀 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 작업을 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 꼭 따로 여쭤봅니다.
자세한 순서는 [이용안내](guide.html)에서 보실 수 있습니다.

# 비용은 이렇게 안내합니다
문 종류와 상태를 보고 먼저 말씀드립니다. / 열고 난 뒤에 말없이 붙는 비용은 없습니다.
도어락 교체나 수리가 필요하다고 판단되면 그 이유와 함께 선택지를 설명합니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
출장 거리가 먼 곳은 도착 시간과 함께 안내해 드립니다. / 괜찮으신지 확인하신 뒤에 출발합니다.

# 현장에서 문을 여는 방법
도어락 종류와 문 상태를 보고 문과 장비가 덜 상하는 방법부터 차례로 시도합니다. / 번호판이 꺼진 경우에는 비상 전원 단자를 먼저 확인합니다.
열쇠식이라면 구멍 안 상태를 보고, 걸쇠가 걸린 경우라면 걸쇠 위치를 확인해서 풉니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.
어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 더 자세히 적어 두었습니다.
@ 광주 남한산성면 출장열쇠 비파손 개방

# 문이 열린 뒤에는 이것도 확인합니다
도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 건전지를 갈아야 하면 전부 새것으로 바꿔 드립니다.
열쇠 복사나 추가가 필요하면 [출장 열쇠](key-call.html)로 바로 처리합니다. / 비밀번호를 잊어서 열린 경우에는 새 번호를 등록하는 것까지 도와드립니다.
같은 일이 반복되지 않게 원인을 말씀드립니다.

# 미리 해두면 다음에 안 헤매는 것
남한산성면처럼 길이 복잡한 곳은 평소에 위치 정보를 정리해 두면 급할 때 큰 도움이 됩니다.
- 집 주소와 큰길에서 들어오는 길을 메모해 두기
- 문과 도어락 사진을 휴대폰에 저장해 두기
- 도어락 건전지 교체일을 달력에 적어 두기
- 가족 연락처와 비상 열쇠 보관 위치를 같이 알아 두기
이 정도만 해두셔도 다음에 문이 안 열릴 때 훨씬 침착하게 대처하실 수 있습니다.

# 남한산성면 말고 광주 어디든 갑니다
곤지암읍, 초월읍, 퇴촌면, 오포읍까지 광주 안이면 어디든 출동합니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
24시간 연락 받습니다.

문 앞에서 기다리기 어려운 날씨라면 따뜻한 곳에서 기다리시다가 도착 전에 나와 주셔도 됩니다.
