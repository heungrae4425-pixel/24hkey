# 산자락 집 대문 앞, 손에 열쇠 머리만 남았을 때
남한산성면은 산자락을 따라 전원주택과 주택이 흩어져 있는 면 지역입니다. / 시내보다 쇠 열쇠를 쓰는 대문, 창고, 현관 보조키가 많이 남아 있어 열쇠가 부러지는 일도 종종 생깁니다.
산바람과 비를 그대로 맞는 자물쇠는 안쪽에 녹이 끼기 쉽습니다. / 그런 자물쇠에 오래된 열쇠를 넣고 힘주어 돌리다 보면 어느 순간 열쇠가 버티지 못하고 부러집니다.
이 글은 남한산성면 집에서 열쇠가 자물쇠 안에서 부러졌을 때 조각 상태에 따라 무엇을 하면 되는지, [경기 광주 출장열쇠](gwangju.html)는 어떻게 처리하는지 정리했습니다.
@ 남한산성면 전원주택 자물쇠 부러진 열쇠

# 어디에서 부러졌는지가 먼저입니다
전원주택에는 잠금장치가 여러 곳에 있습니다. / 부러진 곳이 어디냐에 따라 급한 정도가 다릅니다.
- 현관 보조키: 잠긴 상태라면 집에 못 들어가니 가장 급합니다
- 길가 대문이나 쪽문: 다른 출입구가 있으면 조금 여유가 있습니다
- 창고나 보일러실 자물쇠: 당장 급하지 않다면 낮에 처리해도 됩니다
- 자물통처럼 걸어 잠그는 자물쇠: 고리 쪽을 따로 볼 수 있습니다
급하지 않은 곳이라면 무리하게 혼자 빼려다 일을 키우기보다 낮에 점검을 잡는 편이 낫습니다. / 현관이 막혔다면 바로 연락 주세요.

# 조각이 보이면, 안 보이면
휴대폰 불빛으로 열쇠 구멍을 비춰 보세요. / 조각 끝이 구멍 밖으로 살짝 나와 있다면 작은 집게로 잡아 곧게 당겨 볼 수 있습니다.
당길 때는 비틀지 말고 열쇠가 들어간 방향 그대로 천천히 빼야 합니다. / 한두 번 해서 안 나오면 그만두세요.
조각이 구멍 안으로 쑥 들어가 끝이 안 보인다면 집에서 뺄 방법은 거의 없습니다. / 이때 무언가를 더 넣으면 조각이 안쪽 핀 사이에 끼어 빼기가 훨씬 어려워집니다.

# 녹슨 자물쇠에서 더 조심할 것
남한산성면처럼 습기와 바람이 많은 곳은 자물쇠 안에 녹 가루가 쌓입니다. / 녹 때문에 조각이 안쪽 벽에 붙어 버린 경우도 있습니다.
이럴 때 윤활제를 잔뜩 뿌리면 녹 가루가 엉겨 진흙처럼 됩니다. / 조각이 더 단단히 박히는 원인이 되니 뿌리지 말고 그대로 두세요.
대문 자물쇠가 비에 젖어 있다면 마른 천으로 겉의 물기만 닦아 두시면 됩니다. / 구멍 안쪽은 건드리지 않는 게 좋습니다.
@ 경기 광주 남한산성면 대문 자물쇠 녹 점검

# 열쇠가 부러지기 전 보내는 신호
돌이켜 보면 부러지기 전부터 조짐이 있었던 경우가 많습니다. / 열쇠를 꽂을 때 끝까지 잘 안 들어가거나, 돌릴 때 중간에 턱 걸리는 느낌이 있었을 겁니다.
겨울 아침에만 유난히 뻑뻑했다면 자물쇠 안 습기가 얼었던 것일 수 있습니다. / 이럴 때 힘으로 돌리면 열쇠에 금이 가고, 다음 번에 부러집니다.
열쇠 몸통을 불빛에 비춰 보면 가늘게 금이 간 자국이 보이기도 합니다. / 그런 열쇠는 오늘이라도 쓰지 말고 여분 열쇠로 바꿔 쓰세요.

# 하지 않는 게 좋은 시도들
- 접착제를 묻힌 철사로 조각을 붙여 당기기
- 다른 열쇠를 꽂아 조각을 밀어 넣기
- 드릴이나 망치로 자물쇠를 부수기
- 자물쇠 구멍에 불을 대어 녹을 녹이려 하기
자물쇠를 부수면 문이나 대문까지 상하는 경우가 많습니다. / 조각만 빼면 그대로 쓸 수 있었던 자물쇠를 통째로 버리게 되니 꼭 피해 주세요.

# 전화하실 때 말씀해 주실 것
남한산성면은 길이 좁고 굽어 처음 가는 집은 찾는 데 시간이 걸립니다. / 위치는 도로명 주소와 함께 들어오는 큰길, 마지막 갈림길에서 어느 쪽인지 알려 주시면 됩니다.
상황은 아래 순서로 말씀해 주세요.
- 어느 문 자물쇠인지 (현관 보조키, 대문, 창고)
- 돌리기 전에 부러졌는지, 돌리다 부러졌는지
- 조각 끝이 밖으로 보이는지
- 여분 열쇠가 있는지
부러진 열쇠 머리와 구멍 사진을 문자로 보내 주시면 맞는 도구를 챙겨 출발합니다. / 위치를 받으면 도착 시간을 먼저 말씀드립니다.

# 기다리는 동안
산자락이라 해가 지면 기온이 빨리 떨어집니다. / 현관이 막혀 들어갈 곳이 없다면 차 안이나 이웃 집처럼 따뜻한 곳에서 기다려 주세요.
집 안에 반려동물이 있거나 난방기를 켜 둔 상태라면 통화할 때 꼭 알려 주세요. / 상황에 맞춰 순서를 정합니다.
부러진 열쇠 머리는 버리지 말고 봉투에 넣어 챙겨 두세요. / 박힌 조각과 맞춰 보면 원래 열쇠 모양을 알 수 있어 새 열쇠를 맞출 때 쓰입니다.
기다리는 사이 자물쇠 구멍에 빗물이 들어가지 않게 비닐로 살짝 덮어 두시면 작업이 한결 수월합니다.

# 도착하면 확인부터 합니다
문을 열어야 하는 상황이라면 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 계약서 중 하나면 됩니다.
전원주택은 우편물이 대문 우편함에 꽂혀 있는 경우가 많으니 한 번 살펴보세요. / 자료가 집 안에 있다면 문을 연 직후 보여 주시는 방식으로 진행합니다.
그다음 자물쇠 상태를 보고 얼마인지 먼저 말씀드립니다. / 동의하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에 있습니다.

# 조각을 빼는 과정
전용 도구를 열쇠 구멍 안쪽에 넣어 조각의 홈에 걸고 천천히 끌어냅니다. / 자물쇠 안쪽 핀을 상하지 않게 하는 것이 가장 중요합니다.
조각이 녹에 붙어 있으면 먼저 녹을 살살 떼어 내고 빼냅니다. / 조각을 빼낸 뒤에는 여분 열쇠를 넣어 부드럽게 도는지 확인합니다.
현관이 잠겨 조각을 빼도 바로 열리지 않는 상황이라면 덜 상하는 방법으로 문을 엽니다. / 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 남한산성면 현관 보조키 열쇠 조각 빼기

# 자물쇠를 살릴지, 바꿀지
조각을 뺀 뒤에도 열쇠가 뻑뻑하게 돈다면 자물쇠 안쪽이 이미 닳았거나 녹이 심한 것입니다. / 그대로 쓰면 새 열쇠도 또 부러질 수 있습니다.
현관 보조키라면 실린더만 바꾸는 방법이 있고, 대문이라면 이참에 비에 강한 번호식 대문 도어락으로 바꾸는 집도 있습니다. / 상태를 보고 [도어락 수리](doorlock-repair.html)로 갈지 [도어락 교체](doorlock-replace.html)로 갈지 설명드린 뒤 정하시면 됩니다.

# 산자락 집 자물쇠 관리
- 겨울 오기 전에 대문, 창고 자물쇠에 열쇠 전용 윤활제를 조금 넣기
- 열쇠가 뻑뻑하게 돌기 시작하면 힘으로 돌리지 말고 점검받기
- 오래 쓴 열쇠는 금이 가기 전에 새로 맞추기
- 자물쇠 위에 비가 직접 떨어지지 않게 작은 덮개 달기
비어 있는 시간이 긴 전원주택은 자물쇠를 오래 안 써서 굳는 일도 있습니다. / 한 달에 한 번쯤은 모든 자물쇠를 한 번씩 돌려 주세요.

# 자주 묻는 질문
? 창고 자물쇠에 열쇠가 부러졌는데 밤에 불러야 하나요? | 급하지 않다면 낮에 처리해도 됩니다. 현관이 막힌 경우라면 바로 연락 주세요.
? 녹슨 자물쇠에 윤활제를 뿌려도 되나요? | 조각이 박힌 상태에서는 녹이 엉겨 더 어려워집니다. 그대로 두세요.
? 조각을 빼면 자물쇠를 그대로 쓸 수 있나요? | 안쪽이 상하지 않았다면 그대로 씁니다. 뻑뻑하면 실린더 교체를 권합니다.
? 남한산성면 안쪽 집도 오시나요? | 네, 위치를 받고 도착 시간을 먼저 말씀드립니다.
? 멀리까지 왔는데 못 열면 비용을 내나요? | 아닙니다. 열지 못하면 받지 않습니다.
