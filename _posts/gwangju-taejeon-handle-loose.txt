# 태전동 현관 손잡이가 덜렁거리거나 헛돌 때
태전동은 경기 광주에서 아파트가 많이 모여 있는 동네라 손잡이 일체형 도어락이나 밀고 당기는 형 도어락을 쓰는 집이 많습니다. / 매일 수십 번 잡아당기는 손잡이라 오래 쓰다 보면 어느 순간 흔들리기 시작합니다.
처음엔 살짝 덜렁거리는 정도라 그냥 쓰게 되지만, 그대로 두면 손잡이를 돌려도 걸쇠가 안 빠지는 헛돎으로 넘어가기도 합니다. / 그때는 문이 안 열리거나 안에서 못 나오는 상황이 됩니다.
이 글은 태전동에서 현관 손잡이가 헐겁거나 헛돌 때 원인을 나눠 보고, 직접 손볼 수 있는 것과 [광주 출장열쇠](gwangju.html)에 맡길 것을 정리했습니다.
@ 태전동 아파트 현관 손잡이 헐거움 헛돎

# 헐거움과 헛돎은 다른 증상입니다
헐거움은 손잡이를 잡고 흔들면 덜컹거리지만, 돌리면 걸쇠는 제대로 빠지는 상태입니다. / 대개 손잡이나 몸체를 붙잡는 나사가 풀린 것입니다.
헛돎은 손잡이를 돌리면 힘없이 빙빙 돌기만 하고 걸쇠가 움직이지 않는 상태입니다. / 손잡이와 걸쇠를 이어 주는 안쪽 축이나 부품이 빠졌거나 닳은 겁니다.
헐거운 단계에서 손보면 나사 조이기로 끝나는 경우가 많습니다. / 헛도는 단계까지 가면 부품을 바꿔야 할 수도 있습니다.

# 손잡이 일체형과 밀고 당기는 형의 차이
손잡이 일체형 도어락은 레버 손잡이를 아래로 눌러 여는 방식입니다. / 레버를 누르는 힘이 축을 통해 걸쇠로 전달되기 때문에 축 쪽이 닳으면 헛돎이 생깁니다.
밀고 당기는 형은 손잡이를 밀거나 당기면 안쪽 걸쇠가 빠지는 구조입니다. / 이 방식은 손잡이 고정부가 헐거워지면 밀어도 걸쇠까지 힘이 덜 전달됩니다.
어떤 형인지에 따라 살펴볼 곳이 다르니 전화 주실 때 사진을 함께 보내 주시면 좋습니다.
도어락과 따로 달린 보통 문손잡이가 있는 집도 있습니다. / 이 경우는 손잡이 자체의 고정 나사와 안쪽 래치 뭉치를 따로 봐야 합니다.

# 고정 나사가 풀렸을 때
실내 쪽 도어락 몸체를 보면 문에 고정하는 나사가 보이거나 덮개 안쪽에 숨어 있습니다. / 손잡이가 흔들리면서 몸체까지 같이 움직인다면 이 나사가 풀린 겁니다.
레버 손잡이라면 손잡이 아래쪽에 작은 고정 나사가 있는 제품도 있습니다. / 육각 렌치나 작은 드라이버로 살짝 조이면 흔들림이 줄어듭니다.
나사를 조여도 금방 다시 풀린다면 나사 구멍이 닳은 상태입니다. / 이 경우는 같은 자리에 다시 조이는 것만으로 해결이 안 됩니다.
@ 태전동 도어락 손잡이 고정 나사 점검

# 헛돈다면 안쪽 축을 의심합니다
손잡이를 돌려도 저항 없이 빙빙 돈다면 손잡이와 걸쇠를 잇는 네모난 축이 빠졌거나 모서리가 닳았을 가능성이 큽니다. / 오래 쓰거나 손잡이에 체중을 실어 당기는 습관이 있으면 이 축이 먼저 상합니다.
축이 닳으면 바깥 손잡이와 안쪽 손잡이 중 한쪽만 헛도는 경우가 생깁니다. / 안에서는 열리는데 밖에서는 안 열리거나, 그 반대가 되는 겁니다.
이 부분은 몸체를 열어야 볼 수 있어서 혼자 하시기는 어렵습니다. / 무리하게 분해하면 걸쇠 쪽 부품이 어긋나 조립이 안 되기도 합니다.

# 한쪽 손잡이만 헛돌 때와 잠금 버튼
안에서는 잘 열리는데 밖에서 손잡이가 헛돈다면 바깥 쪽 축이나 연결부 문제입니다. / 반대로 밖에서는 되는데 안에서 헛돈다면 실내 손잡이 쪽을 봐야 합니다.
일부 도어락은 안쪽 잠금 버튼이나 수동 잠금이 걸려 있으면 바깥 손잡이가 헛돌게 되어 있습니다. / 고장이 아니라 잠금 상태일 수 있으니 안쪽 버튼 위치를 먼저 확인해 보세요.
안쪽에서도 손잡이가 헛돌아 밖으로 나갈 수 없는 상황이라면 위험할 수 있습니다. / 불이 나거나 급히 나가야 할 때를 생각해 미루지 말고 바로 점검을 받아 주세요.

# 헛도는 채로 문이 닫혔다면
밖에서 손잡이가 헛도는데 문이 닫혀 버렸다면 번호가 맞아도 문이 안 열립니다. / 모터는 걸쇠를 풀었는데 손잡이로 문을 당길 수 없거나, 손잡이를 돌려야 걸쇠가 빠지는 구조라 막히는 겁니다.
이때 손잡이를 세게 비틀거나 잡아 빼려 하면 축이 완전히 부러집니다. / 그대로 두고 연락 주시면 손잡이를 거치지 않고 여는 방법부터 봅니다.

# 집에서 해볼 수 있는 조이기 요령
- 문을 열어 둔 상태에서 작업하기
- 드라이버는 나사 머리에 꼭 맞는 크기 쓰기
- 꽉 조이기보다 흔들림이 없어질 만큼만 조이기
- 조인 뒤 안팎 손잡이를 여러 번 돌려 확인하기
나사를 너무 세게 조이면 손잡이가 뻑뻑해지거나 플라스틱 덮개가 갈라집니다. / 조였는데도 뻑뻑하거나 소리가 나면 다시 살짝 풀어 주세요.

# 하지 말아야 할 것
- 헛도는 손잡이를 힘으로 비틀기
- 손잡이에 매달리듯 체중 싣기
- 덮개를 억지로 뜯어 내부 보기
- 접착제로 손잡이를 붙이기
특히 접착제는 나중에 부품을 바꿀 때 몸체까지 상하게 합니다. / 임시방편보다 점검을 받는 쪽이 결국 시간과 비용을 아낍니다.

# 연락하실 때 알려주실 것
태전동 아파트라면 단지 이름과 동, 호수를, 빌라라면 건물 이름이나 번지를 알려주세요. / 단지 출입 방법도 함께 말씀해 주시면 기다리는 시간이 줄어듭니다.
손잡이가 헐거운지 헛도는지, 안과 밖 어느 쪽인지, 지금 문이 열린 상태인지 닫힌 상태인지 말씀해 주세요. / 손잡이와 몸체 사진을 보내 주시면 맞는 부품을 챙겨 갑니다.

# 사시는 분 확인과 비용 안내
문이 닫혀 열어야 하는 상황이라면 도착 후 사시는 분인지 먼저 확인합니다. / 신분증 주소나 우편물, 관리사무소 세대 확인 중 하나면 됩니다.
손잡이 상태를 보고 조이기로 끝날지, 부품을 바꿀지, 비용은 어떻게 되는지를 손대기 전에 말씀드립니다. / 동의하실 때만 진행하고, 문을 끝내 못 열면 비용은 받지 않습니다. 순서는 [이용안내](guide.html), 여는 과정은 [현관문 개문](door-open.html)에 있습니다.

# 고칠까, 바꿀까
나사 풀림이나 축 하나만 닳은 경우라면 [도어락 수리](doorlock-repair.html)로 충분합니다. / 같은 손잡이가 여러 번 헛돌았거나 몸체까지 금이 갔다면 부품을 바꿔도 금방 다시 생깁니다.
그럴 때는 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다. / 고쳐서 쓸 수 있는데 굳이 바꾸자고 하지는 않습니다.
@ 태전동 손잡이 헛돎 도어락 수리 광주 출장열쇠

# 태전동 말고 광주 어디든 갑니다
태전동 가까이 오포읍, 경안동, 쌍령동, 송정동은 물론 초월읍, 곤지암읍, 퇴촌면, 남한산성면까지 광주 전 지역을 다닙니다. / 서울, 경기 전 지역 24시간 출동합니다.
광주 안에서 다니는 곳은 [광주시 출장열쇠](gwangju.html)에, 다른 지역은 [출장 지역](area.html)에 정리했습니다.
