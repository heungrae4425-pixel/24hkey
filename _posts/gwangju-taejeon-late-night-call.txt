# 늦은 시간에 문이 안 열리면 더 불안합니다
태전동은 아파트 단지와 빌라가 많아 밤늦게 귀가하는 분도 많은 동네입니다. / 야근이나 모임을 마치고 돌아와 문이 안 열리면 졸음과 피로, 불안이 한꺼번에 몰려옵니다.
게다가 새벽 시간에는 도와줄 사람도 마땅치 않고 이웃에게 피해를 줄까 걱정도 됩니다. / 이 글은 한밤중이나 새벽에 문이 잠겼을 때 차분히 해결하는 순서를 정리했습니다.
야간 출동이 처음이라 불안하시다면 읽고 나서 [광주 출장열쇠](gwangju.html)에 전화 주세요. / 늦은 시간에도 같은 방식으로 안내해 드립니다.
@ 태전동 한밤중 새벽 문 잠김 출장열쇠

# 우선 안전한 장소에서 기다립니다
밤에는 복도나 계단, 현관 앞이 어둡고 위험할 수 있습니다. / 가능하면 밝고 안전한 곳에서 기다리고, 혼자라면 가족이나 지인에게 현재 위치를 알려 두세요.
술에 취했거나 몸이 많이 피곤한 상태라면 문 앞에서 무리하게 시도하지 마세요. / 번호를 반복해서 틀리면 오히려 도어락이 입력을 막을 수 있습니다.
추운 날에는 오래 서 있으면 건강에 좋지 않으니 아파트 공동 현관이나 계단 아래 따뜻한 곳에서 기다리면 좋습니다. / 도착 예정 시간을 먼저 안내해 드리니 그 시간에 맞춰 나오시면 됩니다.

# 이웃에게 피해 없이 해결하는 방법
문을 두드리거나 큰 소리로 말하면 새벽에는 이웃이 놀라거나 잠을 설칩니다. / 되도록 조용히 전화로 도움을 요청하는 것이 좋습니다.
작업 중에도 소음을 최대한 줄이는 방법부터 시도합니다. / 아파트라면 복도가 울리는 구조라 더 신경 써서 진행합니다.
이웃에게 양해를 구해야 하는 상황이라면 짧게 사정을 말씀드리면 대부분 이해해 주십니다. / 작업이 끝나면 정리하고 조용히 마무리합니다.

# 번호판이 안 켜질 때 먼저 해 볼 것
번호판이 꺼져 있다면 배터리가 다 된 경우가 많습니다. / 바깥쪽 아래에 9V 건전지를 대는 단자가 있는 모델이라면 건전지를 대고 번호를 눌러 보세요.
편의점이 닫혀 있고 건전지를 구하기 어렵다면 이 방법은 포기하고 바로 연락 주세요. / 밤에 건전지를 찾아 돌아다니는 것보다 출동을 부르는 것이 시간이 덜 걸립니다.
번호는 누르는데 소리만 나고 문이 안 열린다면 안쪽 보조키가 잠겼는지도 떠올려 보세요. / 상황을 말씀해 주시면 전화로 가늠해 드립니다.

# 열쇠를 안에 두고 나왔다면
쓰레기를 버리러 잠깐 나왔다가 문이 닫혀 버리는 일이 새벽에도 자주 있습니다. / 자동으로 잠기는 도어락이라면 문이 닫히는 순간 잠깁니다.
이때 휴대폰도 집 안에 있다면 이웃이나 경비실 전화를 빌려 연락 주셔도 됩니다. / 전화번호만 말씀해 주시면 위치를 확인하고 출동합니다.
창문이나 베란다로 넘어가려는 시도는 특히 야간에 위험하니 절대 하지 마세요. / 아파트 고층이라면 추락 위험이 크고 어둡기까지 합니다.
@ 태전동 열쇠 안에 두고 나와 문 잠김

# 전화하실 때 알려주시면 좋은 것
태전동은 단지가 크고 동과 호수 번호가 복잡해서 위치를 정확히 알려 주셔야 도착이 빨라집니다. / 아파트 이름과 동, 호수, 어느 출입구 쪽인지 말씀해 주세요.
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 도어락 모양 (번호키, 카드키, 열쇠 방식)
- 단지 정문이나 지하 주차장 출입 방법
- 지금 계신 위치와 안전한지 여부
야간에는 단지 출입이 제한되는 곳이 있어 경비실 연락 방법도 알려 주시면 좋습니다. / 도착하면 전화로 알려 드리고 만나서 안내받겠습니다.

# 도착하면 사시는 분인지 먼저 확인합니다
한밤중이라도 문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 경비실 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 경비실이나 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 야간에는 관리사무소가 닫혀 있을 수 있어 경비실에 먼저 말해 두시면 수월합니다.
번거로우실 수 있지만 이웃과 거주자를 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 방법을 미리 같이 찾아 드립니다.

# 비용은 문을 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 늦은 시간이라고 해서 설명 없이 높은 비용을 붙이지 않습니다.
괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문은 최대한 안 상하게 엽니다
문 여는 방법은 여러 가지이고, 덜 상하고 소리가 적은 방법부터 차례로 해 봅니다. / 도어락과 문틀이 상하지 않게 하는 것이 먼저입니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다. / 개문 과정은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
열고 난 뒤에는 도어락이 정상인지, 배터리와 번호는 괜찮은지 같이 확인합니다. / 문제가 있다면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드립니다.
@ 태전동 24시 출장열쇠 야간 도어락 개문

# 다음에 같은 일이 없도록 준비해 둘 것
- 비상용 9V 건전지 하나를 가방이나 차에 두기
- 열쇠나 카드를 가족 한 명에게 따로 맡기기
- 도어락 배터리 경고음이 나면 그날 바로 교체
- 출장열쇠 번호를 휴대폰에 저장해 두기
- 늦은 귀가 때는 집 앞에서 열쇠와 번호를 미리 확인
이 정도만 준비해 두어도 야간에 문 앞에서 오래 헤매는 일이 크게 줄어듭니다. / 도어락이 자주 이상하다면 [도어락 교체](doorlock-replace.html)도 상담해 보세요.

# 태전동 말고 광주 어디든 갑니다
태전동 가까이는 오포읍, 경안동, 쌍령동도 다닙니다. / 광주 안이면 동네 상관없이 24시간 출동합니다.
곤지암, 초월, 퇴촌처럼 거리가 있는 곳은 위치를 받고 도착 시간을 먼저 말씀드립니다. / 광주 전체는 [광주시 출장열쇠](gwangju.html) 페이지에서 확인하세요.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 어디서든 먼저 전화 주시면 출동 가능 여부를 말씀드립니다.

# 야간에 연락 주실 때 한 가지만 더 알려 주세요
밤에는 길과 단지 출입구가 낮과 다르게 보여 찾기 어려울 수 있습니다. / 아파트 정문 이름이나 가까운 편의점, 눈에 띄는 간판을 말씀해 주시면 훨씬 빨리 만날 수 있습니다.
도착하면 전화로 알려 드리니 휴대폰 배터리를 아껴 두시고 통화가 가능한 상태를 유지해 주세요. / 휴대폰 배터리가 얼마 남지 않았다면 미리 말씀해 주시면 연락 방식을 맞춰 드립니다.
작업이 끝나면 문이 잘 잠기는지 같이 확인하고 안전하게 들어가실 때까지 확인합니다. / 늦은 시간일수록 마무리까지 차분히 챙기겠습니다.
