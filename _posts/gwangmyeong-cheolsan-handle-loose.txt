# 철산동, 손잡이가 말을 안 들을 때
철산동은 철산역 주변으로 대단지 아파트가 이어진 동네입니다. / 입주한 지 오래된 단지가 많아 도어락도 여러 해를 버틴 집이 흔하고, 그중에서도 손잡이가 먼저 지치는 경우가 많습니다.
아침 출근길에 손잡이를 내렸는데 걸쇠가 안 빠지고 손잡이만 툭 떨어지듯 돌면 순간 머리가 하얘집니다. / 반대로 퇴근하고 들어오려는데 바깥 손잡이가 헛돌아 문 앞에 서 있게 되는 일도 있습니다.
이 글은 철산동 아파트에서 손잡이가 헐겁거나 헛돌 때 집에서 볼 수 있는 것과 맡기는 게 나은 것을 나눠 적었습니다. / 바로 출동이 필요하면 [광명 출장열쇠](gwangmyeong.html)로 전화 주세요.
@ 철산동 아파트 도어락 손잡이 헛돎

# 우리 집 손잡이는 어떤 방식인가요
손잡이 문제를 보려면 먼저 집 도어락 손잡이가 어떤 구조인지 알아야 합니다. / 철산동 아파트에서 흔히 보는 방식은 대략 세 가지입니다.
- 번호판과 손잡이가 한 몸인 레버형 도어락
- 손잡이 없이 밀고 당기는 푸시풀형 도어락
- 도어락은 따로 있고 아래에 별도 손잡이가 달린 방식
레버형은 손잡이 축이 걸쇠와 바로 이어져 있어 헛돌면 문이 안 열립니다. / 푸시풀형은 손잡이 안쪽 스프링과 연결 부품이 지치면 밀어도 걸쇠가 안 빠집니다.
별도 손잡이 방식이라면 손잡이만 고장 나고 도어락은 멀쩡한 경우도 많습니다.

# 증상을 짧게 기록해 두세요
손잡이 고장은 하루에 생기지 않고 며칠, 몇 주에 걸쳐 진행됩니다. / 언제부터 어떤 느낌이었는지 떠올려 두면 원인을 찾는 데 큰 도움이 됩니다.
처음엔 손잡이가 축 처져서 원래 자리로 늦게 돌아왔는지, 아니면 갑자기 헛돌기 시작했는지 생각해 보세요. / 서서히 나빠졌다면 스프링이나 나사 문제, 갑자기 그랬다면 연결 부품이 부러진 경우가 많습니다.
안쪽과 바깥쪽 중 어느 쪽이 먼저 이상했는지도 중요합니다. / 한쪽만 이상하다면 그쪽 손잡이 고정부를, 양쪽이 같이 이상하다면 가운데 몸체를 의심해 볼 수 있습니다.
@ 철산동 레버형 도어락 손잡이 구조

# 문이 열려 있을 때 해 볼 확인
지금 문이 열려 있다면 아래를 차례로 보세요. / 닫힌 상태에서는 하지 않는 게 안전합니다.
안쪽 몸체의 건전지 덮개를 열면 위아래로 고정 나사가 보이는 제품이 많습니다. / 이 나사가 헐거우면 손잡이 전체가 흔들리니 맞는 드라이버로 살짝만 조여 주세요.
손잡이 아래쪽이나 옆면에 작은 육각 나사가 있다면 그것도 확인합니다. / 이 나사가 빠지면 손잡이가 축에서 미끄러져 헛돕니다.
조였는데도 헛돎이 그대로라면 안쪽 연결 부품 문제라 집에서 더 할 일은 없습니다.

# 닫힌 채 손잡이가 헛돈다면
문이 닫힌 상태에서 손잡이만 돈다면 걸쇠를 당기는 힘이 중간에서 끊긴 것입니다. / 이럴 때 손잡이를 위로 들어 올리거나 반대로 꾹 누르면서 천천히 돌려 보세요.
축이 완전히 끊어지지 않았다면 각도에 따라 걸리면서 걸쇠가 빠지기도 합니다. / 다만 서너 번 해서 안 되면 거기서 멈추셔야 합니다.
힘을 줄수록 남은 부품까지 부러지고, 손잡이 축이 휘면 문을 연 뒤에도 수리가 커집니다.

# 철산동 오래된 단지에서 자주 보는 원인
오래 쓴 도어락은 손잡이 안쪽 복원 스프링이 지쳐 손잡이가 아래로 처지는 일이 많습니다. / 처진 상태로 계속 쓰면 걸쇠가 덜 빠지고, 결국 헛도는 단계로 넘어갑니다.
현관문 자체가 조금 내려앉은 경우도 있습니다. / 문이 처지면 걸쇠가 문틀 받이에 눌려 손잡이를 돌리는 데 힘이 더 들고, 그 힘이 손잡이 연결 부품에 그대로 쌓입니다.
가족이 많은 집은 손잡이를 쓰는 횟수가 그만큼 많습니다. / 아이들이 손잡이에 매달리거나 가방을 걸어 두는 습관도 수명을 줄입니다.

# 손잡이 고장 때 하지 말 것
급한 마음에 해 보는 행동이 고장을 키우는 경우가 많습니다. / 아래만 피해 주셔도 수리 범위가 훨씬 줄어듭니다.
- 손잡이를 발로 차거나 망치로 두드리기
- 문틈에 카드나 드라이버를 넣어 걸쇠를 밀기
- 손잡이 나사를 다 풀어 손잡이를 빼 보기
- 헛도는 손잡이를 반대 방향으로 세게 돌리기
특히 문이 닫힌 상태에서 나사를 풀면 손잡이가 빠지면서 안팎 어디서도 열 수 없게 될 수 있습니다.
@ 철산동 손잡이 고장 하지 말 것

# 광명 출장 요청할 때 알려 주실 것
철산동은 단지가 크고 동이 많아 위치를 정확히 알려 주시면 도착이 빨라집니다. / 아래 정도를 말씀해 주세요.
- 단지 이름과 동, 호수
- 손잡이 방식(레버형, 푸시풀형, 별도 손잡이)
- 안쪽과 바깥쪽 중 어디가 헛도는지
- 지금 문이 닫혀 있는지, 집 안에 사람이 있는지
- 도어락 앞뒤 사진
집 안에 가족이 있다면 안쪽 손잡이 상태를 사진으로 찍어 보내 달라고 부탁해 보세요. / 맞는 부품을 챙겨 가는 데 큰 도움이 됩니다.

# 작업 전에 확인하는 것
잠긴 문을 열 때는 그 집에 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 세대 확인 가운데 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 미리 말씀해 두시면 확인이 빨리 끝납니다. / 늦은 밤이라 관리사무소가 닫혀 있다면 문을 연 직후 신분증을 보여 주셔도 됩니다.

# 비용과 진행
손잡이 상태를 보고 나사 보강으로 될지, 부품 교체가 필요한지 먼저 말씀드립니다. / 금액을 듣고 괜찮다고 하실 때만 시작합니다.
닫힌 문을 끝내 열지 못하면 비용은 받지 않습니다. / 진행 방법은 [이용안내](guide.html)에, 잠긴 문 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 수리할지 바꿀지
손잡이 부품만 지쳤고 번호판과 모터가 멀쩡하다면 [도어락 수리](doorlock-repair.html)로 충분합니다. / 같은 제품 부품을 구할 수 없거나 번호판까지 낡았다면 [도어락 교체](doorlock-replace.html)를 함께 안내합니다.
교체를 고르신다면 손잡이 고장이 잦았던 점을 생각해 푸시풀형을 고르는 분도 있습니다. / 문 두께와 기존 구멍을 보고 맞는 제품만 말씀드립니다.

# 손잡이 오래 쓰는 법
- 손잡이에 짐이나 우산을 걸어 두지 않기
- 손잡이가 처지기 시작하면 바로 점검받기
- 문이 내려앉아 무겁게 열리면 경첩도 함께 확인
- 건전지 갈 때 고정 나사 흔들림도 같이 보기
작은 흔들림일 때 손보면 부품을 갈지 않아도 되는 경우가 많습니다. / 손잡이에서 평소와 다른 딸깍 소리가 나기 시작하면 그때가 점검하기 좋은 때입니다.

# 철산동 말고 광명 어디든
철산동과 가까운 하안동, 광명동은 물론 소하동, 일직동, 학온동까지 광명 전 지역에 갑니다. / 광명 안내는 [광명 출장열쇠](gwangmyeong.html)에, 서울과 경기 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
