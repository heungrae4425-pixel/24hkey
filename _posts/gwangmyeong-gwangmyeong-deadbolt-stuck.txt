# 광명동 빌라 현관, 잠금 막대가 말을 안 들을 때
광명동은 광명사거리역 주변으로 빌라와 다가구 주택, 오래된 주택가가 넓게 이어진 동네입니다. / 문을 단 지 오래된 집이 많아 문틀과 도어락이 조금씩 어긋나는 일이 생깁니다.
도어락에서 철컥 하고 튀어나와 문틀 구멍에 들어가는 굵은 금속 막대를 데드볼트라고 합니다. / 이 막대가 끝까지 안 들어가면 문이 잠기지 않고, 나온 채로 안 빠지면 문이 열리지 않습니다.
이 글은 광명동에서 데드볼트가 걸렸을 때 어디를 보면 되는지 정리했습니다. / 지금 문이 안 열리는 상황이라면 [광명 출장열쇠](gwangmyeong.html)에 바로 연락 주세요.
@ 광명동 빌라 도어락 데드볼트 걸림 점검

# 데드볼트와 걸쇠는 다릅니다
문 옆면을 보면 금속이 두 군데 튀어나와 있는 경우가 많습니다. / 비스듬히 깎인 작은 쪽이 걸쇠(래치), 네모나고 굵은 쪽이 데드볼트입니다.
걸쇠는 문을 닫기만 해도 저절로 들어가 문을 붙잡아 둡니다. / 데드볼트는 번호를 누르거나 잠금 버튼을 눌렀을 때 모터나 손잡이로 나왔다 들어갑니다.
그래서 "문은 닫히는데 잠기지 않는다"면 데드볼트 쪽, "문이 덜 닫혀 흔들린다"면 걸쇠 쪽을 먼저 봅니다. / 두 증상이 같이 있다면 문 자체가 기울었을 가능성이 큽니다.

# 데드볼트가 구멍에 안 들어갈 때
잠금 소리는 나는데 문이 덜컹거린다면 데드볼트가 문틀 구멍 가장자리에 막혀 반쯤만 나온 상태입니다. / 도어락이 잠금 실패 경고음을 내기도 합니다.
가장 흔한 이유는 문이 처져 데드볼트와 문틀 구멍 높이가 어긋난 것입니다. / 오래된 문일수록 경첩이 닳아 문 손잡이 쪽이 조금씩 내려앉습니다.
문틀 구멍 안에 먼지나 페인트 덩어리, 작은 돌이 끼어 막는 경우도 있습니다. / 손전등으로 구멍 안쪽을 비춰 보면 확인할 수 있습니다.
이물질이 보인다면 문을 연 상태에서 마른 솔이나 면봉으로 살살 털어 내 보세요. / 깊이 박혀 있다면 송곳 같은 뾰족한 도구로 후비지 말고 그대로 두는 편이 낫습니다.

# 나온 채로 안 빠질 때
문이 잠긴 뒤 번호를 눌러도 모터 소리만 나고 열리지 않는다면 데드볼트가 문틀에 꽉 눌려 빠지지 못하는 상태일 수 있습니다. / 문이 바깥쪽이나 안쪽으로 밀린 채 잠기면 데드볼트 한쪽 면이 문틀에 짓눌립니다.
이럴 때는 문을 안쪽으로 살짝 밀거나 바깥으로 살짝 당기면서 번호를 다시 눌러 보세요. / 눌림이 풀리는 순간 데드볼트가 빠지면서 열리는 일이 많습니다.
건전지가 약해 모터 힘이 모자란 경우도 같은 증상이 나옵니다. / 경고음을 들은 기억이 있다면 비상 단자에 9V 건전지를 대고 다시 시도해 보세요.
@ 광명동 도어락 데드볼트 문틀 구멍 확인

# 문 옆면과 문틀 구멍을 비교해 보세요
문을 연 상태에서 잠금 버튼을 눌러 데드볼트를 내보낸 뒤, 문틀 구멍과 위치를 눈으로 비교해 보세요. / 데드볼트가 구멍보다 아래나 위에 있다면 문이 처졌거나 문틀이 틀어진 것입니다.
문틀 구멍 주변에 긁힌 자국이나 반짝이는 자리가 있다면 데드볼트가 그곳을 매번 긁고 있다는 뜻입니다. / 자국이 위쪽에 있으면 문이 올라간 것이고, 아래쪽에 있으면 문이 내려앉은 것입니다.
이 정보를 사진으로 보내 주시면 필요한 부품과 조정 방법을 미리 가늠할 수 있습니다.

# 계절에 따라 달라지는 집
여름에는 문과 문틀이 늘어나 데드볼트가 빡빡하게 들어가고, 겨울에는 줄어들어 헐겁게 들어가기도 합니다. / 계절마다 증상이 바뀐다면 그 사실을 통화 때 말씀해 주세요.
주택 현관처럼 바깥 공기에 바로 닿는 문은 이 차이가 더 큽니다. / 이런 집은 한쪽 계절에 딱 맞추기보다 여유를 두고 맞추는 편이 좋습니다.

# 이렇게 하면 데드볼트가 상합니다
데드볼트가 덜 들어간다고 문을 세게 쾅 닫으면 데드볼트 끝이 문틀에 부딪혀 휘거나 닳습니다. / 안쪽 모터 기어에도 충격이 가서 나중에 모터가 헛돌 수 있습니다.
나온 데드볼트를 펜치로 잡아당기거나 망치로 두드리는 것도 피해 주세요. / 도어락 안쪽 부품이 어긋나 결국 교체까지 가게 됩니다.
문틀 구멍을 혼자 줄로 넓히면 잠깐은 편해도 문이 헐겁게 잠겨 흔들리게 됩니다.
데드볼트에 기름을 잔뜩 바르는 것도 권하지 않습니다. / 먼지가 엉겨 붙어 시간이 지나면 더 뻑뻑해지고, 기름이 도어락 안쪽으로 흘러 들어갈 수 있습니다.

# 광명동 위치 알려주실 때
광명동은 비슷한 빌라 골목이 많아 건물 이름이나 번지를 먼저 알려주세요. / 광명사거리역에서 어느 방향인지, 근처에 눈에 띄는 큰 건물이 있는지도 말씀해 주시면 좋습니다.
몇 층인지, 계단으로 올라가는 건물인지도 알려주세요. / 공동현관 번호가 있다면 미리 알려주시면 도착 후 시간이 줄어듭니다.

# 도착하면 확인하고 설명합니다
문이 닫혀 있는 상황이라면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소나 주소가 적힌 우편물, 세입자라면 계약서 사진도 됩니다.
데드볼트 상태와 문틀을 보고 어떤 작업이 필요한지, 비용은 어떻게 되는지 작업 전에 말씀드립니다. / 끝내 열지 못하면 비용은 받지 않습니다. 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 데드볼트가 물린 문을 여는 방법
데드볼트가 문틀에 눌린 상태라면 문을 살짝 밀거나 들면서 눌림을 먼저 풉니다. / 그래도 안 되면 손상이 적은 방법부터 차례로 시도합니다.
여는 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 여쭤봅니다.

# 열고 나서 맞추는 순서
먼저 경첩 나사를 조이고 문 높이를 맞춰 기울기를 바로잡습니다. / 그다음 문틀 구멍과 받이 위치를 데드볼트에 맞게 조정합니다.
구멍 안 이물질은 깨끗이 털어 내고, 데드볼트가 부드럽게 들어가고 빠지는지 여러 번 시험합니다. / 자동 잠금 제품이라면 문을 닫았을 때 한 번에 잠기는지도 확인합니다.
데드볼트 끝이 휘었거나 모터 기어가 닳았다면 [도어락 수리](doorlock-repair.html)로 손보고, 고치기 어려우면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 광명 광명동 데드볼트 문틀 받이 조정

# 세입자라면 함께 알아 둘 것
광명동은 세를 놓은 빌라와 주택이 많습니다. / 데드볼트 문제는 문틀이나 경첩처럼 집 자체와 관련된 경우가 많아서, 큰 작업이라면 집주인과 미리 이야기해 두시길 권합니다.
작업 내용과 원인은 자세히 설명드리니 그대로 전달하시면 됩니다. / 비용을 누가 부담할지는 두 분이 정하실 일이라 저희가 판단하지 않습니다.

? 모터 소리만 나고 문이 안 열려요. | 데드볼트가 문틀에 눌렸을 수 있습니다. 문을 살짝 밀면서 다시 눌러 보세요.
? 문틀 구멍을 넓혀도 되나요? | 혼자 넓히면 문이 헐겁게 잠깁니다. 위치를 맞추는 편이 낫습니다.
? 못 열면 비용이 나오나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.
