# 집 문보다 바깥 문이 먼저 막힐 때
광명동은 광명사거리역 주변으로 빌라와 주택, 다가구 건물이 촘촘하게 모여 있는 동네입니다. / 이런 건물은 우리 집 현관 말고도 건물 공동 출입문이나 길가 철대문을 하나 더 지나야 집에 닿습니다.
그 바깥 문이 막히면 집 열쇠가 멀쩡해도 들어갈 수 없습니다. / 반대로 공동 출입문이 잠기지 않아 밤새 열려 있으면 건물 전체가 불안해집니다.
바깥 문은 여러 세대가 함께 쓰는 문이라 해결 순서도 집 문과 조금 다릅니다. / 이 글은 문 종류에 따라 무엇을 먼저 보고 누구에게 알리면 되는지, [광명 출장열쇠](gwangmyeong.html)를 부르면 어떻게 진행되는지 적었습니다.
@ 광명동 빌라 공동 출입문 번호키 철문

# 우리 건물 바깥 문은 어떤 종류인가요
광명동 건물 바깥 문은 대략 세 가지로 나뉩니다. / 어떤 문이냐에 따라 고장 나는 곳도 다릅니다.
- 빌라 공동 출입문: 유리나 철 프레임 문에 번호키나 카드 리더기가 달린 문
- 다가구 1층 철문: 계단 입구를 막는 철문에 열쇠나 번호키를 단 문
- 주택 철대문: 길가에서 마당으로 들어가는 쇠 대문, 열쇠나 빗장식 잠금
전화하실 때 이 가운데 어느 쪽인지 말씀해 주시면 맞는 장비를 챙겨 갈 수 있습니다. / 사진이 있다면 더 좋습니다.

# 공동 출입문이 안 열릴 때 먼저 볼 것
빌라 공동 출입문은 번호판이나 카드 리더기가 전기로 움직이는 경우가 많습니다. / 번호판에 불이 안 들어오면 건전지가 다 됐거나 전원이 끊긴 것일 수 있습니다.
불은 들어오는데 안 열린다면 번호가 바뀌었는지부터 확인해 보세요. / 공동 출입문 번호는 관리하는 분이 바꾸고 공지했는데 못 보고 지나치는 일이 많습니다.
문 위쪽에 전기로 문을 잡아 두는 장치가 달린 문도 있습니다. / 정전이나 고장으로 이 장치가 풀리지 않으면 번호를 맞게 눌러도 안 열립니다.

# 공동 출입문이 안 닫히거나 안 잠길 때
문이 끝까지 닫히지 않으면 잠금이 걸리지 않습니다. / 문 위 도어클로저 속도가 너무 느리거나, 문이 처져 문틀에 걸리는 경우가 흔합니다.
여러 세대가 하루에도 여러 번 여닫는 문이라 집 현관보다 빨리 지칩니다. / 문이 쾅 닫히거나 반대로 툭 멈추기 시작했다면 고장 직전이라는 신호입니다.
이런 문은 개인이 마음대로 조절하기보다 관리를 맡은 분께 먼저 알리는 것이 순서입니다. / 연락처를 모르면 출입문 근처 게시판이나 우편함 쪽 안내문을 살펴보세요.
@ 광명동 다가구 공동현관 도어클로저 처짐

# 다가구 1층 철문은 녹과 처짐이 문제
다가구 건물 1층 철문은 바깥에 나 있어 비바람을 그대로 맞습니다. / 열쇠 구멍 안쪽에 녹이 끼면 열쇠가 뻑뻑하게 돌다 멈추곤 합니다.
철문이 무거워 경첩이 조금씩 처지면 문 아래가 바닥에 끌리고 잠금 위치가 어긋납니다. / 문을 살짝 들어 올리면서 열쇠를 돌리면 열리는 경우가 바로 이 상태입니다.
열쇠가 뻑뻑하다고 힘을 주면 부러지기 쉽습니다. / 두세 번 해서 안 되면 멈추고 연락 주세요.

# 주택 철대문은 빗장과 자물쇠를 함께 보세요
광명동 골목 주택 가운데에는 오래된 쇠 대문을 그대로 쓰는 집이 있습니다. / 이런 대문은 열쇠 자물쇠와 안쪽 빗장이 함께 달린 경우가 많습니다.
열쇠는 돌아가는데 문이 안 열린다면 안쪽 빗장이 걸려 있는지 확인해 보세요. / 집 안에 있던 가족이 습관처럼 빗장을 걸어 두는 일이 흔합니다.
대문 아래가 바닥에 닿아 긁힌 자국이 있다면 처짐 때문에 문이 무거워진 것입니다. / 자물쇠만 바꿔서는 해결되지 않고 경첩을 함께 봐야 합니다.

# 전화하기 전에 문 앞에서 볼 세 가지
바깥 문 앞에서 아래 세 가지만 확인해 두시면 통화가 짧아집니다. / 어두운 시간이라면 휴대폰 불빛으로 비춰 보세요.
첫째, 번호판이나 카드 리더기에 불이 들어오는지 봅니다. / 불이 안 들어오면 전원 쪽, 들어오면 번호나 잠금 장치 쪽입니다.
둘째, 문을 살짝 밀거나 당겨 봤을 때 덜컹거리며 조금이라도 움직이는지 봅니다. / 움직이면 걸쇠가 걸린 것이고, 꿈쩍도 안 하면 빗장이나 전기 잠금이 잡고 있는 것일 수 있습니다.
셋째, 같은 건물 다른 세대도 같은 문제를 겪고 있는지 봅니다. / 이웃도 못 들어가고 있다면 공용 설비 고장이 확실하니 관리 쪽에 바로 알리는 것이 먼저입니다.

# 이런 시도는 피해 주세요
바깥 문이 막혔을 때 급한 마음에 아래처럼 하시는 분들이 있습니다. / 여러 사람이 쓰는 문이라 망가지면 건물 전체가 불편해집니다.
- 공동 출입문 유리를 밀거나 흔들기
- 철문 틈에 공구를 넣고 벌리기
- 대문을 넘어 들어가기
- 번호판을 뜯어 전선을 만지기
특히 담이나 대문을 넘다 다치는 일이 있습니다. / 문은 고치면 되지만 사람은 그렇지 않으니 무리하지 마세요.

# 누가 부르고, 누구에게 알릴까
공동 출입문과 다가구 철문은 건물 공용 설비입니다. / 잠겨서 들어가지 못하는 상황이라면 사는 분이 직접 부르셔도 되지만, 집주인이나 관리를 맡은 분께 상황을 함께 알려 두시는 편이 좋습니다.
고장이 났지만 출입은 되는 상황이라면 관리 쪽에서 일정을 잡는 것이 자연스럽습니다. / 주택 철대문은 그 집 문이니 사는 분이 판단하시면 됩니다.
@ 광명동 주택 철대문 빗장 자물쇠 점검

# 도착하면 확인부터 합니다
바깥 문이라도 그 건물이나 집에 사는 분인지 먼저 확인합니다. / 신분증 주소나 그 주소로 온 우편물, 집주인이나 건물 관리하는 분과의 통화 가운데 하나면 됩니다.
공동 출입문만 열면 되는 경우에도 확인은 똑같이 거칩니다. / 여러 세대가 사는 건물이라 오히려 더 중요합니다.
확인 뒤 문 상태를 보고 여는 방법과 비용을 손대기 전에 먼저 말씀드립니다. / 동의하시면 시작하고, 끝내 열지 못하면 비용은 받지 않습니다.

# 열고 나서 함께 보는 것
문이 열리면 왜 막혔는지 짚어 봅니다. / 번호판 건전지, 도어클로저 속도, 경첩 처짐, 자물쇠 녹 가운데 어디가 원인이었는지 설명해 드립니다.
열쇠 자물쇠라면 [열쇠 출장](key-call.html) 방식으로 실린더를 정리하고, 번호키라면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 상황에 맞게 말씀드립니다. / 우리 집 현관까지 잠긴 상태라면 [현관문 개문](door-open.html)으로 이어서 진행합니다.

# 바깥 문을 오래 쓰려면
여러 사람이 쓰는 문일수록 작은 관리가 큰 고장을 막습니다. / 아래 정도만 해 두셔도 훨씬 오래 갑니다.
- 공동 출입문 번호판 건전지는 정해진 달에 교체
- 비 온 뒤 철문 열쇠 구멍 물기 털기
- 대문과 철문 경첩 나사는 계절마다 확인
- 공동 출입문 번호가 바뀌면 세대마다 확실히 알리기
진행 방식 전체는 [이용안내](guide.html)에 정리해 두었습니다.

# 자주 묻는 질문
? 공동 출입문 번호를 몰라서 못 들어가요. | 먼저 집주인이나 이웃에게 물어보시고, 번호판 고장이라면 그때 연락 주세요.
? 공동 출입문 고장인데 세입자가 불러도 되나요? | 잠겨서 못 들어가는 상황이라면 진행할 수 있고, 집주인께도 함께 알려 두시길 권합니다.
? 철대문이 처져서 바닥에 끌리는데 이것도 보시나요? | 네, 경첩 처짐과 잠금 위치를 함께 봅니다.
? 빗장이 안에서 걸린 것 같은데 열 수 있나요? | 대문 구조를 보고 방법을 정합니다. 사진을 먼저 보내 주시면 준비가 빠릅니다.
? 바깥 문과 우리 집 현관을 한 번에 열 수 있나요? | 같은 분이 사시는 곳이라면 확인 한 번으로 이어서 진행합니다.

# 마무리
광명동에서 공동 출입문이나 철대문이 말을 안 들을 때는 먼저 문 종류를 정리하고, 관리하는 분께 알릴 일인지 생각해 보세요. / 들어갈 길이 막혔다면 위치와 사진만 보내 주시면 됩니다.
