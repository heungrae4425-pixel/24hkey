# 하안동 현관 앞, 반쪽짜리 열쇠를 들고 있다면
하안동은 대단지 아파트가 넓게 자리 잡은 동네로, 철산동과 이웃해 있습니다. / 현관에 도어락을 쓰면서도 보조키 실린더나 수동 걸쇠 자물쇠를 함께 달아 둔 집이 꽤 있습니다.
평소 잘 안 쓰던 보조키를 오랜만에 돌리다가, 혹은 손이 미끄러져 비틀다가 열쇠가 똑 부러지는 일이 생깁니다. / 손에는 손잡이 부분만 남고 나머지는 구멍 안에 그대로 박혀 버립니다.
이럴 때 서두르면 조각이 더 깊이 들어가 꺼내기 어려워집니다. / 이 글은 하안동에서 열쇠가 부러졌을 때 조각을 빼기 전에 먼저 할 일을 정리했습니다. 직접 빼기 어렵다면 [광명 출장열쇠](gwangmyeong.html)로 연락 주세요.
@ 하안동 현관 보조키 부러진 열쇠

# 남은 반쪽은 버리지 마세요
손에 남은 열쇠 머리 쪽은 꼭 챙겨 두세요. / 부러진 단면과 남은 톱니 모양이 실린더 안쪽 상태를 짐작하는 데 도움이 됩니다.
나중에 같은 열쇠를 다시 맞출 때도 남은 부분이 참고가 됩니다. / 비닐봉지나 지갑에 넣어 잃어버리지 않게 해 두세요.
부러진 쪽 단면이 깨끗한지, 휘어서 끊어졌는지도 한 번 봐 두세요. / 휘어서 끊어졌다면 그동안 열쇠가 계속 무리하게 돌아가고 있었다는 뜻입니다.

# 조각이 어디쯤 있는지 보기
휴대폰 손전등으로 열쇠 구멍을 비춰 조각 끝이 어디 있는지 살펴보세요. / 위치에 따라 해 볼 수 있는 일이 달라집니다.
- 구멍 밖으로 조금 튀어나와 손톱에 걸리는 경우
- 구멍 입구와 거의 같은 높이에 있는 경우
- 구멍 안쪽으로 깊이 들어가 끝이 잘 안 보이는 경우
밖으로 튀어나와 있다면 조심스럽게 빼 볼 여지가 있습니다. / 입구와 같은 높이거나 더 깊다면 손대지 않는 편이 낫습니다.

# 실린더가 돌아간 상태인가요
부러지기 직전에 열쇠가 얼마나 돌아갔는지도 중요합니다. / 열쇠 구멍 모양이 원래 세로였는데 지금 비스듬하다면 실린더가 돌아간 채로 멈춘 것입니다.
돌아간 상태라면 조각이 안쪽 핀에 걸려 있어 그냥 당겨도 안 빠집니다. / 이때는 실린더를 원래 자리로 되돌린 뒤 빼야 해서 도구가 필요합니다.
원래 자리 그대로라면 조각을 빼기가 훨씬 수월합니다. / 전화 주실 때 구멍이 어느 방향으로 서 있는지 말씀해 주세요.
@ 하안동 열쇠 구멍 손전등 비춰 보기

# 조각이 튀어나와 있을 때만
조각 끝이 밖으로 보일 만큼 나와 있다면 족집게처럼 끝이 가는 도구로 살살 집어 똑바로 당겨 보세요. / 비틀거나 위아래로 흔들지 말고 들어간 방향 그대로 빼는 게 요령입니다.
한두 번 해서 안 나오면 그만두세요. / 계속 집다가 미끄러지면 조각을 오히려 안으로 밀어 넣게 됩니다.
조각이 빠졌다면 남은 반쪽과 맞춰 보고 원래 모양이 다 있는지 확인하세요. / 끝부분이 조금이라도 모자라면 작은 조각이 안에 남은 것입니다.

# 이렇게 하면 일이 커집니다
부러진 열쇠를 빼려고 해 보는 방법 중에는 실린더를 망가뜨리는 것들이 많습니다. / 아래는 피해 주세요.
- 순간접착제를 남은 반쪽에 발라 붙인 뒤 당기기
- 핀이나 클립을 구멍에 넣어 조각을 긁어내기
- 다른 열쇠를 꽂아 조각을 밀어 넣기
- 기름이나 세정제를 잔뜩 뿌리기
접착제가 구멍 안으로 흘러 들어가면 실린더 안쪽이 굳어 버립니다. / 그때는 조각을 빼는 게 아니라 실린더를 통째로 들어내야 합니다.

# 도어락으로는 들어갈 수 있나요
부러진 게 보조키라면 도어락은 멀쩡할 수 있습니다. / 보조키가 잠긴 상태가 아니라면 번호나 카드로 그냥 들어가실 수 있습니다.
문제는 보조키를 잠근 채 외출했다가 돌아와서 부러진 경우입니다. / 이때는 도어락이 열려도 보조키 잠금 때문에 문이 안 열립니다.
가족이 집 안에 있다면 안쪽에서 보조키 손잡이를 돌려 열어 달라고 부탁하세요. / 안쪽에서 열리면 조각 빼는 일은 급하지 않게 됩니다.

# 하안동 출장 요청할 때 말씀해 주실 것
하안동은 단지가 넓고 동 번호가 많아 위치를 자세히 알려 주시면 헤매지 않습니다. / 아래만 말씀해 주시면 됩니다.
- 단지 이름과 동, 호수
- 부러진 열쇠가 보조키인지, 도어락 비상 열쇠인지
- 조각이 밖으로 나와 있는지, 안으로 들어갔는지
- 열쇠 구멍이 세로인지 비스듬한지
- 지금 문이 잠겨 있는지, 집 안에 가족이 있는지
열쇠 구멍을 가까이 찍은 사진과 남은 반쪽 사진을 함께 보내 주시면 준비가 빨라집니다.
@ 하안동 출장열쇠 부러진 열쇠 사진

# 문을 열기 전에 확인합니다
잠긴 문을 열거나 실린더를 손볼 때는 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 세대 확인 중 하나면 됩니다.
신분증을 집 안에 두고 나오셨다면 관리사무소에 미리 연락해 두시면 확인이 수월합니다. / 이웃과 입주민 모두를 위한 절차이니 너그럽게 봐 주세요.

# 비용은 조각 상태를 보고
조각이 어디 있는지, 실린더가 돌아갔는지에 따라 작업 방법이 달라집니다. / 현장에서 상태를 본 뒤 조각만 빼면 되는지, 실린더까지 바꿔야 하는지 나눠서 먼저 말씀드립니다.
듣고 괜찮다고 하실 때 시작하며, 잠긴 문을 열지 못하면 비용은 받지 않습니다. / 자세한 진행은 [이용안내](guide.html)에, 잠긴 문 여는 방법은 [현관문 개문](door-open.html)에 있습니다.

# 조각을 뺀 다음 정리할 것
조각을 빼고 나면 실린더 안쪽 핀이 상하지 않았는지 열쇠를 꽂아 몇 번 돌려 봅니다. / 뻑뻑하거나 걸리는 느낌이 남아 있다면 실린더를 바꾸는 게 오래 보면 편합니다.
부러진 열쇠가 복사본이었다면 원래 열쇠로 새로 복사하시길 권합니다. / 복사를 여러 번 거친 열쇠일수록 모양이 조금씩 달라져 실린더에 무리를 줍니다.
보조키를 거의 안 쓰신다면 이번 기회에 떼어 내고 도어락만 쓰거나, [도어락 설치](doorlock-install.html)로 보조 잠금이 되는 제품으로 정리하는 방법도 있습니다. / 기존 도어락을 손보고 싶다면 [도어락 수리](doorlock-repair.html)도 함께 봐 드립니다.

# 열쇠가 부러지지 않게
- 열쇠가 뻑뻑하게 돌면 억지로 돌리지 말고 점검받기
- 열쇠고리에 무거운 장식을 많이 달지 않기
- 원래 열쇠는 보관해 두고 그것으로 복사하기
- 오래 안 쓴 보조키는 가끔 돌려서 굳지 않게 하기
부러지기 전에는 대개 열쇠가 뻑뻑해지는 신호가 먼저 옵니다. / 그 신호를 놓치지 않는 것이 가장 좋은 예방입니다.

# 하안동 말고 광명 전역
하안동과 가까운 철산동, 소하동, 광명동은 물론 일직동, 학온동까지 광명 어디든 갑니다. / 광명 안내는 [광명 출장열쇠](gwangmyeong.html)에서, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
