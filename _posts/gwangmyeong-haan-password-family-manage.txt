# 하안동 집 비밀번호, 마지막으로 바꾼 게 언제인가요
하안동은 대단지 아파트가 많아 한 집에 여러 가족이 같은 비밀번호를 쓰는 경우가 흔합니다. / 입주할 때 정한 번호를 몇 년째 그대로 쓰는 집도 많습니다.
번호가 오래될수록 아는 사람은 늘어납니다. / 가족, 친척, 예전에 오가던 분들까지 번호를 아는 상태가 됩니다.
이 글은 하안동에서 비밀번호를 바꾸는 시기와 가족이 번호를 같이 관리하는 방법을 정리했습니다. / 번호를 잊어 문이 안 열린다면 [광명 출장열쇠](gwangmyeong.html)에 바로 연락 주세요.
@ 하안동 도어락 비밀번호 관리 출장열쇠

# 비밀번호를 바꿔야 하는 때
번호는 정해진 날짜보다 상황이 바뀔 때 바꾸는 것이 효과적입니다.
- 이사를 오거나 도어락을 새로 달았을 때
- 가사도우미, 공사 인력 등 외부 사람에게 번호를 알려준 뒤
- 가족 구성이 바뀌었을 때(독립, 이별, 새 식구)
- 번호를 누르는 모습을 누군가 봤을 수 있다고 느꼈을 때
- 마지막으로 바꾼 지 한참 지났을 때
특별한 일이 없어도 해마다 한 번쯤 바꾸는 습관이 있으면 마음이 편합니다.

# 어떤 번호가 좋을까요
생일, 전화번호 끝자리, 1234 같은 번호는 짐작하기 쉬워서 피하시는 게 좋습니다. / 가족 모두가 기억하기 쉬우면서 남이 짐작하기 어려운 번호가 알맞습니다.
숫자를 규칙 없이 섞기보다 가족만 아는 의미를 담는 방식이 오래 기억됩니다. / 다만 그 의미가 겉으로 드러나지 않게 하세요.
번호 자릿수는 도어락이 허용하는 만큼 길게 하는 편이 낫습니다. / 대신 외우기 어려워 자꾸 틀리면 오히려 불편하니 가족과 상의해서 정하세요.

# 가족이 같이 쓸 때 지킬 것
번호를 바꾸면 가족 모두에게 같은 시점에 알려야 합니다. / 한 명만 모르고 있으면 그 사람이 문 앞에서 막힙니다.
번호를 문자나 메신저에 그대로 적어 보내면 기록이 남습니다. / 휴대폰을 잃어버렸을 때를 생각하면 말로 전하는 방법이 더 안전합니다.
어르신이나 아이가 있는 집은 번호를 바꾼 뒤 직접 눌러서 열어 보게 하세요. / 처음 며칠은 틀리는 일이 흔하니 한 번씩 확인해 주세요.

# 외부 사람에게 알려줄 때
택배나 청소, 돌봄으로 사람이 드나드는 집은 번호를 임시로 쓰는 것이 좋습니다. / 도어락에 임시 번호나 일회용 번호 기능이 있으면 일정이 끝난 뒤 지울 수 있습니다.
그런 기능이 없다면 일이 끝난 날 바로 번호를 새로 바꾸는 방법이 있습니다. / 번거로워 보여도 가장 확실합니다.
알려 준 번호를 다른 사람에게 다시 알려 주지 않도록 한 번 당부해 두세요.
@ 하안동 가족 공유 도어락 비밀번호 변경

# 번호를 바꾸는 방법은 도어락마다 다릅니다
대부분의 도어락은 안쪽 문에서 등록 버튼을 눌러 새 번호를 넣는 방식입니다. / 제품에 따라 마스터 번호가 필요한 경우도 있습니다.
설명서가 없거나 마스터 번호를 모르면 초기화가 필요할 수 있습니다. / 초기화는 기존 번호가 모두 지워지니 가족 모두가 새 번호를 다시 받아야 합니다.
어떻게 하는지 모르겠다면 사진을 보내 주세요. / 도어락 모양을 보고 번호 바꾸는 방법을 안내해 드립니다.

# 비밀번호를 잊어 문이 안 열릴 때
가족이 바꾼 번호를 모르거나 오랜만에 눌러서 틀리는 경우도 있습니다. / 몇 번 틀리면 도어락이 입력을 막기도 하니 서너 번 해보고 안 되면 멈추세요.
집 안에 가족이 있다면 먼저 전화로 번호를 물어보세요. / 아무도 연락이 안 되면 그때 연락 주시면 됩니다.
문을 여는 방법은 도어락과 문이 덜 상하는 것부터 차례로 시도합니다. / 자세한 방법은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우시겠지만 이웃과 집을 지키기 위한 절차입니다. / 확인이 어려우면 작업을 시작할 수 없습니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

# 비용은 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
번호를 새로 등록하는 작업까지 같이 하면 한 번에 끝납니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 광명 하안동 출장열쇠 비밀번호 재설정

# 번호를 바꾼 뒤에 같이 확인하세요
번호를 바꾼 뒤에는 몇 가지를 꼭 확인해 두면 좋습니다.
- 새 번호로 문이 열리는지 두세 번 직접 눌러 보기
- 이전 번호가 지워졌는지 눌러 보기
- 카드나 지문이 있다면 그대로 쓸 수 있는지 확인하기
- 건전지가 약하지 않은지 확인하고 필요하면 새것으로 교체하기
- 가족 모두에게 새 번호를 알렸는지 확인하기
번호만 바꾸고 건전지를 그대로 두면 며칠 뒤에 번호판이 꺼지는 일이 생길 수 있습니다.

# 하안동에서 위치는 이렇게 알려주세요
대단지라 단지 이름과 동, 호수를 알려주시면 가장 빠릅니다. / 어느 출입구로 들어오는지도 알려주시면 도착이 빨라집니다.
- 아파트 단지 이름과 동, 호수
- 도어락 모양과 번호판 상태
- 집 안에 사람이나 반려동물이 있는지
- 지금 문 앞인지, 다른 곳인지
도어락 사진을 보내 주시면 맞는 방법을 안내하기 쉽습니다.

# 비밀번호 관리, 이것만은 피하세요
편해서 하는 습관이 문제가 되는 경우가 많습니다.
- 번호를 현관문 근처나 우편함에 적어 두기
- 오래전 번호를 전혀 바꾸지 않고 쓰기
- 번호를 알려 준 사람이 많은데 그대로 두기
- 번호를 틀리면 화내며 여러 번 연속으로 누르기
번호를 적어 두어야 한다면 집 밖이 아닌 안전한 곳에 하나만 보관하세요.

# 하안동 말고 광명 어디든 갑니다
철산동, 소하동, 광명동, 일직동, 학온동까지 광명 안이면 어디든 출동합니다. / 24시간 연락 받습니다.
광명에서 다니는 지역은 [광명시 출장열쇠](gwangmyeong.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
