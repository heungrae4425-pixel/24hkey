# 학온동, 손에 남은 건 열쇠 손잡이뿐
학온동은 광명역이 있는 일직동과 이웃한 동네로, 도어락뿐 아니라 열쇠로 여는 대문, 창고, 보조 자물쇠를 함께 쓰는 집이 적지 않습니다. / 열쇠를 오래 쓰다 보면 어느 날 돌리는 순간 똑 하고 부러지는 일이 생깁니다.
손에는 열쇠 머리만 남고 나머지 반쪽은 열쇠 구멍 안에 박혀 버립니다. / 문은 안 열리고, 구멍은 막혀서 다른 열쇠도 꽂을 수 없게 됩니다.
이 글은 학온동에서 열쇠가 부러져 구멍에 박혔을 때 혼자 빼려다 일이 커지는 경우와 안전하게 해결하는 순서를 정리했습니다. / 지금 문 앞에서 막혀 있다면 [광명 출장열쇠](gwangmyeong.html)로 바로 연락 주세요.
@ 학온동 열쇠 부러짐 열쇠 구멍 박힘 출장열쇠

# 열쇠는 왜 부러질까
열쇠가 부러지는 건 대부분 한 번의 실수가 아니라 오랫동안 쌓인 무리 때문입니다. / 안에서 이미 금이 가 있던 열쇠가 마지막에 힘을 받으며 끊어집니다.
- 자물쇠 안이 녹슬거나 먼지가 쌓여 뻑뻑했던 경우
- 문이 처져 열쇠를 돌릴 때 힘이 많이 들던 경우
- 복사한 열쇠가 원래 열쇠와 미세하게 달랐던 경우
- 열쇠를 꽂은 채로 문을 당기거나 열쇠고리에 무거운 것을 달아 둔 경우
그동안 열쇠가 잘 안 돌아가서 힘을 주던 기억이 있다면 자물쇠 쪽도 함께 손봐야 합니다. / 부러진 열쇠만 빼고 끝내면 같은 일이 반복됩니다.

# 박힌 조각, 이렇게 하면 더 깊어집니다
가장 흔한 실수는 남은 열쇠 머리를 다시 구멍에 대고 밀어 넣는 것입니다. / 조각이 안쪽으로 더 밀려 들어가 꺼내기가 훨씬 어려워집니다.
드라이버나 송곳, 실핀으로 후비는 것도 피해 주세요. / 조각이 옆으로 비틀리면서 자물쇠 안쪽 핀에 끼어 버립니다.
순간접착제를 이쑤시개에 묻혀 붙여 빼려는 분도 있습니다. / 접착제가 자물쇠 안에 흐르면 굳어서 자물쇠 전체를 바꿔야 하는 일이 생깁니다.

# 조각이 바깥으로 얼마나 나와 있나요
손전등으로 열쇠 구멍을 비춰 조각 끝이 어디쯤 있는지 보세요. / 이 정보가 해결 방법을 정합니다.
조각 끝이 구멍 바깥으로 살짝 튀어나와 있다면 비교적 쉽게 뺄 수 있는 상태입니다. / 이때도 펜치로 세게 잡아당기면 조각이 부서질 수 있으니 무리하지 마세요.
구멍 입구와 나란하거나 안쪽으로 들어가 있다면 전용 공구가 필요합니다. / 이 상태에서는 혼자 할 수 있는 일이 거의 없습니다.
@ 학온동 열쇠 구멍 조각 위치 손전등 확인

# 자물쇠가 돌아간 상태인지도 중요합니다
열쇠가 돌리는 도중에 부러졌는지, 꽂는 순간 부러졌는지에 따라 상황이 다릅니다. / 돌리다 부러졌다면 자물쇠가 반쯤 돌아간 채 멈춰 있을 수 있습니다.
반쯤 돌아간 상태라면 조각을 빼기 전에 자물쇠를 원래 위치로 돌려 놓아야 하는 경우가 있습니다. / 이 부분은 상태를 직접 봐야 판단할 수 있습니다.
통화할 때 "돌리다 부러졌다", "꽂다가 부러졌다"처럼 말씀해 주시면 준비가 빨라집니다.
부러지기 직전에 열쇠가 평소보다 뻑뻑했는지, 갑자기 걸렸는지도 기억나는 대로 알려주세요. / 자물쇠 안쪽 상태를 짐작하는 데 도움이 됩니다.

# 대문과 창고 자물쇠라면
바깥에 있는 대문이나 창고 자물쇠는 비바람을 맞아 녹이 잘 슬고, 열쇠도 같이 약해집니다. / 그래서 현관보다 부러지는 일이 더 흔합니다.
녹이 심한 자물쇠는 조각을 빼더라도 다시 쓰기 어려운 경우가 많습니다. / 이런 경우에는 조각을 빼고 자물쇠를 새것으로 바꾸는 편이 낫습니다.
창고 안에 급한 물건이 있다면 그 사정도 말씀해 주세요. / 순서를 정할 때 참고합니다.

# 현관 보조키라면 도어락으로 먼저 들어가 보세요
도어락과 보조키를 함께 쓰는 현관이라면 보조키를 잠그지 않은 상태인지 확인해 보세요. / 보조키가 풀려 있다면 도어락 번호로 들어갈 수 있습니다.
들어간 뒤에는 안쪽에서 보조키 상태를 볼 수 있어 작업이 훨씬 쉬워집니다.
집 안에서 보조키 손잡이를 돌려 풀어 두면 바깥 조각을 빼는 작업도 덜 급해집니다. / 이 경우는 날이 밝은 뒤 편한 시간에 불러 주셔도 됩니다. / 보조키가 잠긴 상태라면 바깥에서 조각을 빼고 여는 작업이 필요합니다.

# 학온동 위치 알려주실 때
주소와 함께 집 형태를 알려주세요. / 주택이라면 대문 위치, 창고라면 집에서 어느 쪽에 있는지 말씀해 주시면 좋습니다.
가까운 큰길이나 눈에 띄는 건물을 알려주시면 찾기가 쉬워집니다. / 차를 댈 곳이 있는지도 함께 말씀해 주세요.
열쇠 구멍과 부러진 열쇠 머리를 찍은 사진을 보내 주시면 맞는 공구를 챙겨 갑니다. / 부러진 머리 쪽은 버리지 말고 꼭 보관해 주세요. 새 열쇠를 맞출 때 필요할 수 있습니다.

# 도착하면 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 가족과의 통화 중 하나면 됩니다.
창고처럼 따로 떨어진 공간이라면 그 땅이나 건물을 쓰시는 분인지 확인합니다. / 이웃과 소유자 모두를 위한 절차입니다.

# 비용은 시작 전에 말씀드립니다
조각 위치와 자물쇠 상태를 보고 어떤 작업이 필요한지, 비용은 어떻게 되는지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작합니다.
끝내 해결하지 못하면 비용은 받지 않습니다. / 자물쇠를 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 조각을 빼고 여는 순서
먼저 자물쇠 위치를 확인하고, 조각이 더 들어가지 않게 조심스럽게 꺼냅니다. / 조각이 나오면 자물쇠 안쪽 상태를 보고 다시 쓸 수 있는지 판단합니다.
조각을 뺄 수 없을 만큼 깊이 박혔다면 손상을 줄이는 다른 방법으로 문을 엽니다. / 여는 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.

# 그다음 자물쇠와 열쇠 정리
자물쇠가 멀쩡하면 안쪽을 청소하고 새 열쇠를 맞춰 드립니다. / 녹이 심하거나 핀이 상했다면 실린더나 자물쇠를 바꾸는 편이 낫습니다.
열쇠 때문에 자주 고생하셨다면 현관은 번호식 도어락으로 바꾸는 것도 생각해 볼 만합니다. / 설치 전 확인할 것은 [도어락 설치](doorlock-install.html)에, 지금 도어락 손보는 일은 [도어락 수리](doorlock-repair.html)에 정리해 두었습니다.
@ 광명 학온동 자물쇠 실린더 교체 새 열쇠

# 열쇠 오래 쓰는 습관
- 열쇠가 뻑뻑하면 힘으로 돌리지 말고 그때 점검받기
- 열쇠고리에 무거운 것을 많이 달지 않기
- 복사 열쇠가 잘 안 맞으면 원래 열쇠로 다시 복사하기
- 바깥 자물쇠는 비 온 뒤 물기를 닦고 가끔 덮개 씌우기
열쇠에 금이 보이거나 휘어 있다면 부러지기 전에 새로 맞춰 두세요.
