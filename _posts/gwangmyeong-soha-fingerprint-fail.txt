# 소하동 지문 도어락, 처음엔 잘 되던 그 지문
소하동은 광명 남쪽에 아파트 단지와 주택가가 함께 있는 동네로, 일직동 광명역 쪽과 생활권이 이어집니다. / 맞벌이 가정과 아이 있는 집이 많아 열쇠 없이 드나들 수 있는 지문 도어락을 쓰는 집이 흔합니다.
설치한 날에는 손가락만 대면 착착 열리던 문이 어느새 두세 번에 한 번꼴로 실패합니다. / 손을 닦고 센서를 닦아 봐도 그대로라면 등록 상태를 의심해 볼 차례입니다.
이 글은 소하동에서 지문 실패가 잦을 때 등록된 지문과 설정을 하나씩 다시 점검하는 방법을 정리했습니다. / 지문도 번호도 안 돼 문 앞에 서 계시다면 [광명 출장열쇠](gwangmyeong.html)로 먼저 연락 주세요.
@ 소하동 지문 도어락 등록 상태 점검

# 실패가 잦다면 등록부터 의심하는 이유
지문 도어락은 등록할 때 읽은 지문 정보와 지금 댄 손가락을 비교합니다. / 처음 등록할 때 정보가 부족하게 저장됐다면, 손 상태가 조금만 달라져도 실패합니다.
급하게 설치하면서 한 번씩만 대고 넘어간 경우가 대표적입니다. / 손이 젖어 있거나 차가운 날 등록한 지문도 평소 상태와 차이가 나서 실패가 잦습니다.
그래서 닦고 말려도 나아지지 않는다면 지문을 지우고 새로 등록하는 것만으로 해결되는 일이 많습니다.
특히 가족 중 한두 사람만 실패가 잦다면 그 사람의 등록 정보가 부족했을 가능성이 큽니다. / 반대로 모두가 같이 실패한다면 등록보다 센서나 전원 쪽을 먼저 보는 편이 맞습니다.

# 우리 집 도어락에 지문이 몇 개 들어 있나요
지문 도어락은 저장할 수 있는 지문 개수가 정해져 있습니다. / 이사 오기 전 사람의 지문이나 예전에 등록한 손님 지문이 자리를 차지하고 있을 수도 있습니다.
- 지금 쓰는 가족 지문이 몇 개인지
- 이전 거주자나 손님 지문이 남아 있는지
- 같은 손가락을 여러 번 등록해 둔 것은 없는지
- 관리자 지문이 따로 있는 제품인지
제품에 따라 전체를 한꺼번에 지우거나 하나씩 지울 수 있습니다. / 하나씩 지우는 방법이 없는 제품이라면 전체를 지우고 가족 지문을 다시 넣어야 합니다.

# 관리자 지문과 일반 지문
일부 제품은 처음 등록한 지문을 관리자로 삼아 설정을 바꿀 때 그 지문을 요구합니다. / 관리자 지문을 가진 분이 손을 다쳤거나 집에 없으면 설정 변경이 막힐 수 있습니다.
관리자로 등록된 분이 누구인지 가족끼리 미리 알아 두세요. / 관리자 지문은 실패가 적은 손가락으로 두 개 이상 등록해 두는 편이 안전합니다.
제품에 따라서는 관리자 비밀번호가 따로 있기도 합니다. / 설치할 때 정해 둔 관리자 번호를 잊었다면 설정 변경 전에 먼저 찾아 두세요.

# 다시 등록하기 전에 꼭 할 일
지문을 지우는 작업은 문이 열린 상태에서, 안쪽에서 하세요. / 실수로 번호까지 초기화되면 바깥에서 들어올 방법이 없어집니다.
지금 쓰는 비밀번호를 가족 모두 알고 있는지 먼저 확인합니다. / 지문만 믿고 번호를 잊고 지내던 분이 생각보다 많습니다.
설명서가 없다면 안쪽 몸체 덮개에 붙은 안내나 제품 이름으로 제조사 설명을 찾아보세요. / 버튼 순서를 짐작으로 누르다 보면 엉뚱한 설정이 바뀝니다.
@ 소하동 도어락 안쪽 몸체 등록 버튼

# 등록할 때 이렇게 하세요
손을 씻고 물기를 충분히 말린 뒤 실내 온도에 손이 익었을 때 등록하세요. / 외출하고 막 들어와 손이 찬 상태는 피하는 편이 좋습니다.
같은 손가락이라도 가운데, 조금 위, 조금 아래, 살짝 기울인 상태처럼 여러 자세로 나눠 대 주세요. / 그러면 급하게 아무렇게나 대도 읽힐 확률이 올라갑니다.
센서가 위에서 누르는 방식인지, 옆으로 쓸어내리는 방식인지에 따라 대는 법도 다릅니다. / 쓸어내리는 방식은 너무 빠르거나 느리면 실패하니 일정한 속도로 연습해 보세요.

# 손가락 고르는 요령
가족마다 양손 검지나 중지처럼 자주 쓰는 손가락을 두 개 이상 넣어 두세요. / 한 손에 장바구니를 들어도 다른 손으로 열 수 있습니다.
요리나 손 쓰는 일을 많이 하는 분은 상처가 잘 생기는 손가락은 피하는 것이 좋습니다. / 엄지는 지문 면적이 넓어 잘 읽히는 편이라 하나쯤 넣어 두면 든든합니다.
아이는 자라면서 지문이 달라지니 학년이 바뀔 때쯤 한 번씩 다시 등록해 주세요.

# 등록을 다시 해도 실패한다면
새로 등록한 지문도 자꾸 실패한다면 센서 자체를 봐야 합니다. / 센서 표면에 긁힘이나 금이 가 있으면 등록할 때와 열 때 모두 정보가 흐릿하게 읽힙니다.
건전지가 약해도 센서가 제 힘을 못 냅니다. / 경고음이 난 적이 있다면 새것으로 한꺼번에 바꾼 뒤 다시 시도해 보세요.
그래도 같다면 센서 수리나 교체를 생각해 볼 시점입니다.
센서 주변 테두리가 들떠 있거나 번호판과 센서 사이에 틈이 벌어졌다면 안쪽에 먼지나 물기가 들어갔을 수 있습니다. / 이 경우는 닦아서 해결되지 않으니 사진을 찍어 보내 주세요.

# 소하동에서 문 밖에 막혔다면
지문도 번호도 안 되면 문을 여는 일이 먼저입니다. / 단지 이름과 동, 호수, 또는 주택이라면 가까운 큰길을 알려주세요.
지문 센서와 번호판 상태, 집 안에 아이나 반려동물이 있는지도 함께 말씀해 주세요. / 아이가 혼자 집에 있다면 가장 먼저 알려주셔야 합니다.

# 사시는 분 확인과 비용
도착하면 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나로 사시는 분인지 먼저 봅니다. / 이웃과 입주자 모두를 위한 절차입니다.
어떤 작업을 할지와 비용은 시작 전에 먼저 말씀드립니다. / 끝내 열지 못하면 비용은 받지 않습니다. 자세한 진행은 [이용안내](guide.html)에 있습니다.

# 문을 열고 나서 함께 하는 것
문을 여는 방식은 손상이 적은 방법부터 차례로 시도합니다. / 자세한 내용은 [현관문 개문](door-open.html)에 적어 두었습니다.
열고 나면 등록된 지문을 정리하고 가족 지문을 다시 넣는 것까지 도와드립니다. / 관리자 지문을 누구로 할지도 이때 함께 정하시면 좋습니다.
센서가 상했다면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 오래돼 고치기 어렵다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 광명 소하동 지문 재등록 센서 점검

# 지문 도어락 관리 메모
- 등록된 지문과 등록한 날짜를 가족끼리 적어 두기
- 관리자 지문은 두 사람 이상 알 수 있게 하기
- 지문만 믿지 말고 번호도 주기적으로 눌러 보기
- 아이 지문은 해마다 한 번 다시 등록하기
이 정도만 챙겨도 문 앞에서 손가락을 몇 번씩 대는 일이 줄어듭니다.
가족 중 손을 다쳐 붕대를 감은 분이 있다면 그동안은 번호나 카드로 드나들게 해 주세요.

? 관리자 지문이 뭔가요? | 설정을 바꿀 때 필요한 지문입니다. 누가 관리자로 등록됐는지 미리 알아 두세요.
