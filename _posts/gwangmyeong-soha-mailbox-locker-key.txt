# 작은 칸 하나가 안 열려도 하루가 꼬입니다
소하동은 아파트 단지와 상가가 함께 있는 동네입니다. / 단지 1층에는 세대별 우편함이 줄지어 있고, 요즘은 택배 보관함까지 따로 놓인 곳이 많습니다.
상가 쪽에는 가게나 사무실 직원들이 쓰는 사물함, 서류함이 있습니다. / 모두 크기는 작지만 안에 든 물건이 급하면 현관문 못지않게 애가 탑니다.
이런 작은 잠금장치는 누가 관리하느냐에 따라 해결 순서가 달라집니다. / 이 글은 소하동에서 자주 마주치는 세 가지 경우를 나눠 적었고, 출장이 필요하면 [광명 출장열쇠](gwangmyeong.html)로 연락 주시면 됩니다.
@ 소하동 아파트 1층 세대별 우편함 열쇠

# 아파트 우편함은 관리사무소부터
아파트 세대 우편함은 대개 관리사무소가 예비 열쇠나 자물쇠 정보를 갖고 있습니다. / 열쇠를 잃어버렸다면 먼저 관리사무소에 들러 여쭤보는 것이 가장 빠릅니다.
예비 열쇠가 없다고 하면 자물쇠를 새로 다는 방법이 있습니다. / 이때 관리사무소에서 정해 둔 자물쇠 규격이 있는지도 함께 물어보세요.
단지 전체가 같은 모양의 자물쇠를 쓰는 경우가 많아, 마음대로 다른 자물쇠를 달면 보기에 어색하고 나중에 관리하기도 불편합니다. / 규격이 있으면 그에 맞춰 바꿔 드립니다.

# 우편함 열쇠가 안 돌아갈 때
열쇠는 있는데 우편함 자물쇠가 돌아가지 않는다면 안쪽에 먼지가 쌓였거나 녹이 슨 경우가 많습니다. / 1층 출입구 쪽은 바깥 공기와 먼지가 드나들어 생각보다 빨리 뻑뻑해집니다.
열쇠를 살살 넣었다 빼기를 몇 번 반복해 보세요. / 그래도 안 되면 힘을 주지 말고 멈추는 것이 좋습니다.
우편함 열쇠는 얇아서 조금만 비틀어도 휘거나 부러집니다. / 부러진 조각이 안에 남으면 자물쇠를 통째로 바꿔야 할 수도 있습니다.

# 택배 보관함이 안 열릴 때
택배 보관함은 대개 문자로 받은 번호나 세대 카드로 엽니다. / 번호를 맞게 눌렀는데도 안 열린다면 보관함 쪽 시스템 문제일 가능성이 큽니다.
이런 보관함은 단지에서 관리하는 설비라 열쇠를 다루는 쪽에서 함부로 열지 않습니다. / 관리사무소나 보관함에 적힌 고객센터에 먼저 연락하시는 것이 맞습니다.
보관함 칸 옆에 비상 연락처가 붙어 있는 경우가 많으니 확인해 보세요. / 급한 물건이라면 그 사정을 함께 말씀하시면 됩니다.
@ 소하동 단지 택배 보관함 칸 안 열림 관리사무소 문의

# 상가 직원 사물함은 누가 관리하나요
소하동 상가에서 일하시는 분들의 사물함은 가게나 사무실이 직접 관리하는 경우가 대부분입니다. / 열쇠를 잃었다면 먼저 사장님이나 관리 담당자에게 예비 열쇠가 있는지 여쭤보세요.
예비 열쇠가 없거나 잃어버린 사람이 관리자라면 그때 출장을 부르시면 됩니다. / 사물함 앞면 번호나 제조사 각인이 있으면 사진으로 함께 보내 주세요.
같은 줄 사물함 열쇠가 서로 맞는지도 확인해 보세요. / 맞는다면 잃어버린 열쇠 하나로 여러 칸이 열릴 수 있다는 뜻이라 자물쇠를 바꾸는 편이 낫습니다.

# 번호식 사물함과 우편함
번호를 돌려 맞추는 다이얼식이나 버튼식 사물함도 많습니다. / 번호를 잊었다면 처음 설정한 사람이 누구인지부터 떠올려 보세요.
번호를 하나씩 돌려 보는 방법은 시간이 오래 걸리고 다이얼을 헐겁게 만듭니다. / 번호를 아는 사람이 없다면 안쪽에서 번호를 새로 맞추는 작업을 하는 편이 빠릅니다.

# 이사 들어온 집 우편함이라면
새로 이사 온 집은 우편함 열쇠를 넘겨받지 못한 경우가 꽤 많습니다. / 전 세입자가 열쇠를 챙겨 갔거나, 처음부터 아무도 쓰지 않아 열쇠 행방을 모르는 경우입니다.
이럴 때는 전에 살던 분이나 집주인께 먼저 물어보시고, 관리사무소에도 예비 열쇠가 있는지 확인해 보세요. / 셋 다 없다면 이번 기회에 자물쇠를 바꿔 두는 편이 마음 편합니다.
예전 열쇠가 어딘가 남아 있으면 우리 집으로 온 우편물을 다른 사람이 꺼낼 수도 있습니다. / 이사 직후에 한 번 정리해 두면 그런 걱정이 사라집니다.

# 이런 방법은 칸을 망가뜨립니다
작은 칸이라 쉽게 열 수 있을 것 같지만, 힘으로 열면 문짝이 휘어 다시 잠기지 않게 됩니다. / 아래 방법은 피해 주세요.
- 일자 드라이버로 문틈을 벌리기
- 자물쇠를 망치로 두드리기
- 옆 칸 열쇠를 억지로 끝까지 넣기
- 택배 보관함 문을 손으로 잡아당기기
특히 아파트 우편함은 여러 칸이 한 판에 붙어 있어 한 칸이 휘면 옆 칸까지 영향을 받습니다. / 이웃 우편함까지 망가뜨리면 일이 커집니다.

# 출장을 부르실 때 알려 주실 것
작은 자물쇠라도 미리 알고 가면 한 번에 끝낼 수 있습니다. / 아래 내용을 함께 보내 주세요.
- 우편함인지, 사물함인지, 서류함인지
- 자물쇠 앞면 사진
- 예비 열쇠가 없다는 것을 관리 쪽에서 확인했는지
- 자물쇠만 열면 되는지, 새 열쇠나 새 자물쇠까지 원하시는지
소하동 단지 이름과 동, 상가라면 건물과 층을 알려 주시면 됩니다.
@ 소하동 상가 직원 사물함 열쇠 분실 출장

# 열기 전에 확인을 거칩니다
우편함과 사물함에는 다른 사람의 물건이 들어 있을 수 있어 열기 전 확인이 필요합니다. / 우편함은 그 세대에 사는 분인지 신분증이나 우편물, 관리사무소 확인으로 여쭙습니다.
상가 사물함은 그 가게나 사무실을 운영하는 분 또는 관리 담당자의 확인을 받습니다. / 직원 혼자 부르시는 경우에는 대표나 관리자와 통화가 되어야 합니다.
확인이 되면 자물쇠 상태를 보고 방법과 비용을 손대기 전에 먼저 말씀드립니다. / 동의하시면 시작하고, 끝내 열지 못하면 비용은 받지 않습니다.

# 연 다음 고를 수 있는 것
자물쇠를 열고 나면 상황에 맞춰 방법을 고르시면 됩니다. / 자물쇠가 멀쩡하면 새 열쇠만 맞추고, 열쇠가 어디서 사라졌는지 모르면 자물쇠 부품을 바꿔 예전 열쇠로 안 열리게 합니다.
녹이 심하거나 문짝과 맞지 않게 낡았다면 자물쇠를 통째로 바꾸는 편이 낫습니다. / 열쇠 작업은 [열쇠 출장](key-call.html)에, 가게 출입문까지 함께 봐야 하면 [도어락 수리](doorlock-repair.html)에 안내를 적어 두었습니다.

# 다시 잃어버리지 않으려면
작은 열쇠는 따로 두면 금방 사라집니다. / 집 열쇠 꾸러미나 가게 열쇠 꾸러미에 같이 걸어 두는 습관이 가장 확실합니다.
- 예비 열쇠는 관리하는 쪽 한 곳에만 보관
- 사물함 열쇠 목록을 칸 번호와 함께 정리
- 번호식은 번호를 정한 사람과 날짜를 메모
- 우편함 열쇠가 뻑뻑해지면 바로 점검
현관문이 잠긴 상황이라면 [현관문 개문](door-open.html), 진행 방식은 [이용안내](guide.html)에서 보실 수 있습니다.
