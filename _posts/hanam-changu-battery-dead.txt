# 창우동 현관, 손을 댔는데 번호판이 캄캄하다
창우동은 하남검단산역과 가까운 하남 동네입니다. / 퇴근길에 현관 앞에 섰는데 번호판에 불이 안 들어오면 가장 먼저 배터리를 의심하게 됩니다.
도어락 배터리는 한꺼번에 뚝 끊기기보다 며칠 전부터 신호를 보냅니다. / 경고음을 몇 번 듣고도 미뤘다가 결국 꺼지는 경우가 대부분입니다.
이 글은 번호판이 꺼졌을 때 문 앞에서 할 수 있는 일과, 들어간 뒤 배터리를 제대로 갈아 넣는 요령을 정리했습니다. / 비상 전원으로도 안 된다면 [하남 출장열쇠](hanam.html)로 연락 주세요.
@ 창우동 도어락 배터리 방전 번호판 꺼짐

# 정말 배터리 문제일까
번호판이 꺼진 이유가 꼭 배터리만은 아닙니다. / 아래를 보면 배터리 쪽인지 다른 쪽인지 대략 가를 수 있습니다.
- 며칠 전부터 띠리릭 하는 경고음이 났다
- 최근 번호판 반응이 느리고 불빛이 흐렸다
- 문 여는 모터 소리가 평소보다 힘이 없었다
이 중 하나라도 해당하면 배터리 방전일 가능성이 높습니다. / 반대로 어제까지 멀쩡하다 갑자기 꺼졌고 경고음도 없었다면 물기나 부품 문제일 수도 있습니다.

# 비상 단자 찾기
대부분의 도어락은 바깥쪽 번호판 아래나 옆에 9V 건전지를 대는 작은 단자 두 개가 있습니다. / 동그란 금속점 두 개이거나, 덮개 안에 숨어 있기도 합니다.
덮개가 있다면 손톱으로 살짝 들어 올리면 열립니다. / 단자가 안 보이면 번호판 아래쪽을 손가락으로 훑어 보세요.
단자가 아예 없는 제품도 있습니다. / 이 경우는 비상 전원을 쓸 수 없으니 바로 연락 주시는 편이 빠릅니다.
어떤 제품은 단자 대신 작은 USB 단자를 두어 휴대폰 보조배터리로 전원을 넣게 해 두었습니다. / 번호판 아래에 작은 구멍이 보인다면 그 방식일 수 있으니 사진을 보내 주세요.

# 9V 건전지 대는 순서
9V 건전지는 네모난 모양에 위쪽에 단자 두 개가 달린 건전지입니다. / 편의점에서 쉽게 살 수 있습니다.
건전지 위쪽 단자 두 개를 도어락 비상 단자 두 개에 맞춰 꾹 대세요. / 방향이 맞으면 번호판에 불이 들어오거나 삑 소리가 납니다.
불이 안 들어오면 건전지를 뒤집어 다시 대 보세요. / 건전지를 댄 채로 번호를 누르거나 카드를 대면 문이 열립니다.
- 건전지를 단자에 꾹 붙인 채 손을 떼지 않기
- 불이 들어오면 바로 번호 입력
- 열린 뒤에야 건전지를 떼기
@ 창우동 9V 건전지 비상 단자 연결

# 건전지를 대도 반응이 없다면
새 9V 건전지인데도 반응이 없다면 다른 원인을 생각해 봐야 합니다. / 단자 쪽이 녹슬었거나 안쪽 회로가 문제일 수 있습니다.
단자에 먼지나 물기가 있으면 마른 천으로 닦고 다시 대 보세요. / 그래도 안 되면 계속 시도하지 말고 연락 주세요.
번호판에 불은 들어오는데 문이 안 열린다면 모터 힘이 부족한 경우입니다. / 9V 건전지 하나로는 모터를 끝까지 돌리지 못하는 제품도 있습니다.

# 들어간 뒤 배터리 갈아 넣기
문이 열렸다면 그날 바로 안쪽 배터리를 새것으로 바꿔야 합니다. / 비상 전원은 한 번 여는 용도일 뿐 배터리를 채워 주지 않습니다.
안쪽 몸체의 배터리 덮개를 열고 건전지를 모두 꺼냅니다. / 몇 개만 바꾸지 말고 전부 같은 날 산 새 건전지로 바꾸세요.
- 같은 종류, 같은 회사 건전지로 통일
- 더하기, 빼기 방향 확인하며 넣기
- 넣은 뒤 번호판 반응과 잠김 확인
- 배터리 칸 안쪽에 교체 날짜 적어 두기
헌 건전지와 새 건전지를 섞으면 헌 것이 새것의 힘까지 빨리 깎아 먹습니다. / 며칠 만에 다시 경고음이 나는 이유가 대부분 이것입니다.

# 건전지 칸 접점도 살펴보세요
건전지를 꺼냈을 때 칸 안쪽 금속 접점에 하얀 가루나 녹이 보이면 건전지 액이 샌 흔적입니다. / 마른 면봉으로 살살 닦아 내고 새 건전지를 넣으세요.
녹이 심해 닦아도 접점이 거뭇하다면 접촉이 불안정해집니다. / 이 경우는 [도어락 수리](doorlock-repair.html)로 점검을 받는 편이 좋습니다.

# 경고음이 들리면 그날 바로
대부분의 도어락은 배터리가 얼마 남지 않으면 문을 열 때마다 경고음을 냅니다. / 이 소리가 들리기 시작하면 남은 기간이 길지 않습니다.
추운 날에는 배터리 힘이 더 떨어져서 경고음 뒤 금방 꺼지기도 합니다. / 겨울 들어서는 경고음을 듣는 즉시 바꾸시는 게 안전합니다.
경고음 소리를 잘 모르겠다면 제품 설명서를 한 번 찾아보세요. / 평소 문 열 때와 다른 짧은 멜로디가 섞여 나오면 대개 배터리 알림입니다.

# 오래 집을 비운 뒤라면
여행이나 출장으로 며칠 집을 비우면 그동안에도 도어락은 조금씩 전기를 씁니다. / 돌아왔을 때 꺼져 있는 일이 생기는 이유입니다.
길게 비우기 전에는 건전지를 새것으로 바꿔 두세요. / 가방에 9V 건전지 하나를 챙겨 두는 것도 좋은 습관입니다.
명절처럼 가족이 모두 집을 비우는 때라면 가까이 사는 친척에게 비상 단자 위치를 알려 두는 것도 방법입니다. / 돌아오는 날 먼저 와서 확인해 줄 수 있습니다.

# 비상 전원으로도 안 될 때 연락하는 법
- 창우동 주소와 동, 호수 또는 집 모양
- 비상 단자가 있는지, 건전지를 대 봤는지
- 번호판 반응 (전혀 없음, 잠깐 켜짐)
- 도어락 앞면 사진
집 안에 아이나 반려동물이 있다면 꼭 먼저 말씀해 주세요. / 그만큼 서둘러 움직이겠습니다.
휴대폰 배터리도 얼마 남지 않았다면 주소부터 말씀해 주세요.

# 도착 후 진행 순서
도착하면 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 가운데 하나로 사시는 분인지 확인합니다. / 확인이 안 되면 문을 열지 않습니다.
문과 도어락을 보고 얼마인지 먼저 말씀드리고, 동의하시면 시작합니다. / 못 열면 비용은 받지 않습니다. 진행 방식은 [이용안내](guide.html)에 있습니다.
여는 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다. / 연 뒤에는 새 배터리로 바꾸고 잘 잠기는지까지 확인해 드립니다.
@ 창우동 출장열쇠 배터리 교체 확인

# 배터리가 너무 빨리 닳는다면
새 건전지로 바꿨는데 몇 주 만에 또 경고음이 난다면 도어락 쪽 문제일 수 있습니다. / 모터가 힘들게 돌거나 문이 처져 걸쇠에 힘이 많이 걸리면 전기를 많이 씁니다.
이럴 때는 걸쇠와 문틀 위치를 맞추면 배터리 수명이 돌아오기도 합니다. / 오래된 제품이라면 [도어락 교체](doorlock-replace.html)도 함께 생각해 보세요.

# 창우동 말고 하남 어디든
천현동, 덕풍동, 신장동 같은 가까운 동네와 미사동, 풍산동, 위례동, 감일동까지 갑니다. / 하남 안이면 24시간 출동합니다.
하남 지역 안내는 [하남시 출장열쇠](hanam.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 건전지 몇 개만 바꿔도 되나요? | 전부 같은 날 산 새것으로 바꾸시는 게 좋습니다. 섞으면 금방 닳습니다.
