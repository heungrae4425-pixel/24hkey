# 창우동 대문과 철문 열쇠가 안 돌아갈 때
창우동에서 대문이 있는 집에 사신다면 현관문보다 대문 자물쇠가 먼저 말썽을 부리는 경험을 해 보셨을 겁니다. / 열쇠를 꽂았는데 뻑뻑하게 걸리거나 돌아가다 멈추면 마음이 급해집니다.
대문은 밖에 그대로 노출되어 있어 비와 먼지, 추위를 고스란히 맞습니다. / 그래서 같은 연식의 현관 도어락보다 상태가 먼저 나빠지는 경우가 많습니다.
이 글은 [하남 출장열쇠](hanam.html)를 부르시기 전에 해 볼 수 있는 것과 부르면 어떻게 진행되는지를 정리했습니다. / 지금 대문 앞에 서 계시다면 6번 소제목부터 보시면 됩니다.
@ 창우동 대문 철문 열쇠 출장열쇠

# 대문 자물쇠와 현관 도어락은 서로 다릅니다
대문은 열쇠로 여는 실린더형이나 오래된 빗장 자물쇠를 쓰는 집이 많습니다. / 현관은 번호나 카드로 열리는 도어락을 쓰는 집이 대부분이라 고장 증상도 다릅니다.
열쇠형은 부품이 닳거나 녹이 슬면 돌아가지 않고, 전자식은 배터리와 회로가 문제가 됩니다. / 어느 쪽이 안 열리는지만 구분해 주셔도 준비가 훨씬 정확해집니다.
대문과 현관이 모두 막혀 있는 경우도 있으니 상황을 있는 그대로 말씀해 주세요. / 그에 맞춰 챙겨 가는 장비가 달라집니다.

# 철문이 안 열리는 흔한 원인 네 가지
- 열쇠구멍 안에 먼지와 녹이 쌓여 열쇠가 끝까지 들어가지 않는 경우
- 열쇠가 오래 닳아 돌려도 걸림이 잡히지 않는 경우
- 철문이 처져 걸쇠가 문틀 구멍과 맞지 않는 경우
- 자물쇠 속 스프링이 약해져 되돌아오지 않는 경우
네 가지 중 어느 쪽인지에 따라 해야 하는 일이 완전히 다릅니다. / 열쇠를 바꾸면 되는 일이 있고 자물쇠 전체를 열어 손봐야 하는 일도 있습니다.
같은 열쇠를 여러 벌 복사해 쓴 집은 복사본이 원본보다 더 빨리 닳아 문제가 생기기도 합니다.

# 비 온 뒤와 추운 아침에 더 잦은 이유
비를 맞은 철문은 열쇠구멍 속에 물기가 남아 녹이 생기기 쉽습니다. / 겨울에는 그 물기가 얼어 열쇠가 꿈쩍 않는 일도 생깁니다.
이럴 때 뜨거운 물을 붓는 분들이 있는데 금속이 변형되거나 다시 얼 수 있어 권하지 않습니다. / 따뜻한 손으로 열쇠를 감싸 잠깐 데운 뒤 다시 천천히 넣어 보는 정도로 두세요.
날씨가 풀리면 저절로 풀리는 경우도 있지만 문이 급하다면 기다리기 어렵습니다. / 그럴 때는 상황을 알려주세요.

# 열쇠를 억지로 돌리면 안 되는 이유
안 돌아가는 열쇠를 힘으로 돌리면 열쇠가 부러져 구멍에 박히는 일이 생깁니다. / 그러면 열쇠 하나 문제였던 것이 자물쇠 분해가 필요한 일로 커집니다.
펜치로 돌리거나 망치로 두드리는 것도 자물쇠 안쪽 핀을 상하게 합니다. / 열쇠가 끼어 빠지지 않을 때는 더 건드리지 말고 그대로 연락 주세요.
이미 부러졌다면 부러진 조각을 버리지 말고 보관해 두세요. / 어떤 열쇠인지 알면 맞는 열쇠를 만들기가 수월합니다.

# 대문 앞에서 먼저 해 볼 것
열쇠를 뽑아 모양이 휘거나 닳은 곳이 없는지 먼저 봅니다. / 다른 복사본이 있다면 그것으로 다시 시도해 보세요.
열쇠구멍 속에 먼지가 보이면 입으로 가볍게 불어내는 정도는 괜찮습니다. / 액체나 오일을 마구 뿌리면 오히려 먼지가 엉켜 더 뻑뻑해질 수 있습니다.
대문이 약간 처져 있다면 문을 살짝 들어 올리듯 밀면서 열쇠를 돌려 보세요. / 걸쇠 위치가 맞으면 의외로 부드럽게 돌아가기도 합니다.
@ 창우동 철문 자물쇠 하남 열쇠 점검

# 대문이 안 열려도 집 안에서 나올 수 있나요
안쪽에서 대문 빗장이나 잠금을 풀 수 있는 구조라면 집 안 사람이 먼저 열 수 있습니다. / 그런 구조가 아니라면 안쪽에서도 같은 열쇠가 필요한 집이 있어 확인이 필요합니다.
급히 나가야 하는 사정이 있으시다면 처음 연락하실 때 그 점부터 말씀해 주세요. / 순서를 정해서 가장 급한 문부터 처리하겠습니다.
병원이나 출근처럼 시간이 정해진 일이 있다면 그것도 함께 알려주시면 좋습니다. / 도착 예상 시간을 정확히 말씀드려 그 사이에 다른 방법을 준비하실 수 있게 돕습니다.

# 전화하실 때 이것만 알려주세요
- 대문, 현관 중 어느 문이 안 열리는지
- 열쇠형인지 번호 도어락인지
- 열쇠가 부러졌는지, 돌아가다 멈추는지
- 집 안에 사람이나 반려동물이 있는지
- 대문 앞에 차를 세울 자리가 있는지
사진을 문자로 보내주시면 맞는 장비를 챙기기 쉽습니다. / 골목이 좁아 차가 못 들어가는 경우도 알려주시면 도착 방법을 미리 정합니다.

# 도착하면 사시는 분인지 먼저 확인합니다
대문이든 현관이든 문을 여는 일이라 먼저 사시는 분이 맞는지 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 이웃이나 관리인 확인 중 하나면 됩니다.
세입자시라면 임대 계약서나 공과금 고지서도 도움이 됩니다. / 확인이 어려우면 작업을 하지 못하니 미리 챙겨 두시면 좋습니다.

# 비용은 열기 전에 말씀드립니다
자물쇠 상태와 작업 방법을 보고 얼마가 드는지 먼저 말씀드립니다. / 괜찮으시면 시작하고 아니면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 설명 없이 붙는 비용도 없습니다.
자물쇠를 바꿔야 하는 일이라면 바꾸기 전에 따로 여쭙습니다. / 이용 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 열고 난 뒤 하는 일
문이 열리면 자물쇠가 다시 부드럽게 돌아가는지 같이 확인합니다. / 열쇠가 닳았다면 새 열쇠를 만드는 일은 [출장 열쇠](key-call.html) 쪽에서 같이 도와드립니다.
자물쇠가 너무 낡았다면 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html)를 말씀드릴 수 있습니다. / 고쳐서 더 쓸 수 있으면 바꾸자고 하지 않습니다.
현관이 번호식이라면 배터리 상태도 함께 봅니다. / 문 열기 방식은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.
@ 창우동 철문 대문 열쇠 교체 출장

# 대문 열쇠를 오래 쓰는 관리법
- 열쇠구멍에 맞는 전용 윤활제를 한 해에 한두 번만 가볍게
- 열쇠 복사본은 원본에서 다시 복사하지 않고 처음 만든 곳에서 다시 만들기
- 비가 들이치는 자리라면 가림막으로 물기 막기
- 열쇠가 뻑뻑해지는 느낌이 들면 미루지 않고 점검하기
작은 관리 몇 가지로 한겨울 아침에 대문 앞에서 서성이는 일을 줄일 수 있습니다. / 여분 열쇠 한 벌은 집 밖이 아닌 믿을 만한 곳에 맡겨 두세요.

# 창우동 말고 하남 어디든 갑니다
창우동 가까운 천현동, 신장동, 덕풍동은 물론 미사, 위례, 감일까지 출동합니다. / 하남시 안이라면 시간 상관없이 24시간 연락을 받습니다.
[하남시 출장열쇠](hanam.html) 페이지에 다니는 동네를 모아 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
