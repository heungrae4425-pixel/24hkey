# 천현동에서 열쇠가 꽂힌 채 안 돌아갈 때
열쇠를 넣었는데 돌아가지 않고 빠지지도 않으면 문 앞에서 가장 난감한 순간이 됩니다. / 천현동처럼 집마다 대문과 현관문, 창고 문까지 열쇠를 쓰는 곳이 있으면 이런 일이 더 잦습니다.
가볍게 보다가 열쇠를 부러뜨려 일이 커지는 경우가 많아서 먼저 이 글을 정리했습니다. / [하남 출장열쇠](hanam.html)를 부르기 전에 안전하게 해 볼 수 있는 것을 순서대로 적었습니다.
급하시면 3번과 5번 소제목부터 보셔도 됩니다.
@ 천현동 열쇠 안 돌아감 하남 출장열쇠

# 열쇠가 걸리는 증상, 크게 세 가지입니다
첫째는 열쇠가 끝까지 들어가지 않고 중간에서 막히는 경우입니다. / 둘째는 들어가기는 하는데 돌리면 뻑뻑하거나 딱딱 걸리는 경우입니다.
셋째는 돌아가긴 하는데 걸쇠가 움직이지 않아 문이 안 열리는 경우입니다. / 어느 쪽이냐에 따라 열쇠가 문제인지 자물쇠가 문제인지가 갈립니다.
열쇠가 구멍에서 아예 안 빠지는 경우도 따로 있어 이때는 더 조심해야 합니다.
세 가지가 섞여 나타나는 집도 많아서 증상이 헷갈린다면 있는 그대로 말씀해 주셔도 충분합니다. / 도착해서 직접 보고 어느 쪽인지 가려 드립니다.

# 열쇠 자체가 닳은 경우부터 의심해 보세요
오래 쓴 열쇠는 톱니 모양이 닳아 자물쇠 속 핀을 제대로 밀어 올리지 못합니다. / 처음에는 가끔 걸리다가 점점 안 돌아가는 식으로 진행되는 경우가 많습니다.
여분 열쇠가 있다면 그것으로 바꿔 꽂아 보세요. / 여분은 잘 돌아가는데 쓰던 열쇠만 안 된다면 쓰던 열쇠가 닳은 것입니다.
이때는 문을 손댈 필요 없이 열쇠를 새로 만들면 해결되는 경우가 많습니다. / 열쇠가 하나뿐이라면 닳은 열쇠를 더 쓰지 말고 미리 복사해 두세요.

# 열쇠구멍 속 이물질과 녹을 확인하세요
열쇠구멍 속에 먼지, 낙엽 부스러기, 녹이 끼면 열쇠가 깊이 들어가지 않습니다. / 겨울철에는 물기가 얼어 같은 증상이 생기기도 합니다.
- 열쇠를 뽑아 끝에 묻어 나오는 것이 있는지 보기
- 구멍 안쪽이 어둡고 막혀 보이는지 보기
- 플래시를 비춰 안쪽에 낀 것이 보이는지 보기
이물질이 보여도 뾰족한 도구로 후비면 핀을 망가뜨릴 수 있습니다. / 그냥 두고 연락 주시는 것이 안전합니다.

# 열쇠가 안 빠질 때는 절대 비틀지 마세요
열쇠가 구멍에 끼어 안 빠질 때 좌우로 세게 비틀면 열쇠가 부러집니다. / 부러진 조각이 구멍 안에 남으면 자물쇠를 열어 빼내는 작업이 필요해집니다.
열쇠를 살짝 위아래로만 움직이면서 가볍게 당겨 보고 안 되면 멈추세요. / 계속 당기기보다는 지금 상태를 그대로 두고 연락 주시는 것이 낫습니다.
이미 부러졌다면 조각을 함께 모아 두세요. / 어떤 모양인지 알면 맞는 열쇠를 만들기가 쉽습니다.
@ 천현동 열쇠 끼임 출장 열쇠 제거

# 윤활제를 뿌려도 되나요
열쇠구멍 전용 윤활제를 소량 쓰는 것은 괜찮지만 아무 기름이나 쓰면 안 됩니다. / 식용유나 일반 오일은 먼지를 끌어들여 나중에 더 뻑뻑해지는 원인이 됩니다.
번호식 도어락이 같이 달려 있다면 번호판 쪽으로 액체가 들어가지 않게 조심하세요. / 어느 쪽이든 잘 모르겠다면 뿌리지 말고 그대로 연락 주세요.

# 이럴 때는 바로 연락 주세요
- 열쇠가 안 빠지는데 집 안에 사람이나 반려동물이 있는 경우
- 열쇠가 부러져 일부가 구멍에 남은 경우
- 돌아가긴 하는데 걸쇠가 안 움직이는 경우
- 출근이나 약속 때문에 시간이 급한 경우
이런 경우는 혼자 오래 붙잡고 있어도 상황이 좋아지기 어렵습니다. / 처음부터 전문가와 함께 보는 편이 시간도 문도 덜 상합니다.

# 전화하실 때 알려주실 것
어느 문인지, 열쇠가 꽂혀 있는지, 부러졌는지를 먼저 말씀해 주세요. / 도어락 모양과 문 종류를 사진으로 보내주시면 챙길 장비가 정확해집니다.
천현동 안에서 대략 어느 쪽인지, 차를 세울 곳이 있는지도 알려주세요. / 위치를 받으면 예상 도착 시간을 먼저 말씀드립니다.
열쇠가 여러 개라면 어느 열쇠가 어느 문 것인지 알려주시면 헷갈리지 않습니다. / 지금 열쇠가 꽂혀 있는 문 사진이 있으면 더 좋습니다.
연락이 닿는 번호와 이름도 함께 알려주시면 도착 직전에 미리 전화를 드립니다.

# 도착하면 신분을 먼저 확인합니다
사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리인 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없어 미리 챙겨 두시면 좋습니다. / 이웃과 집을 함께 지키기 위한 절차입니다.

# 비용은 손대기 전에 말씀드립니다
열쇠가 낀 위치와 자물쇠 상태를 보고 얼마가 드는지 먼저 알려드립니다. / 동의하시면 시작하고 아니면 그대로 돌아갑니다.
열쇠를 빼지 못하거나 문을 못 열면 비용은 받지 않습니다. / 자물쇠를 바꿔야 하는 상황이면 바꾸기 전에 다시 여쭙습니다.
진행 순서는 [이용안내](guide.html)에서도 볼 수 있습니다. / 일반적인 열기 방식은 [현관문 개문](door-open.html)에 정리했습니다.
@ 천현동 자물쇠 열쇠 교체 하남 출동

# 빼낸 뒤에는 이렇게 마무리합니다
열쇠를 빼내면 자물쇠가 다시 부드럽게 돌아가는지 같이 확인합니다. / 새 열쇠가 필요하면 [출장 열쇠](key-call.html)로 같이 만들어 드립니다.
자물쇠가 닳아 같은 일이 또 생길 것 같다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 쓸 수 있는 것을 바꾸자고 하지는 않습니다.
열쇠에서 번호 도어락으로 바꾸고 싶으시다면 [도어락 설치](doorlock-install.html)도 상담해 드립니다.

# 열쇠를 오래 쓰려면
- 여분 열쇠는 원본에서 다시 복사하지 않고 처음 만든 곳에서 다시 만들기
- 열쇠고리에 무거운 것을 많이 달지 않기
- 뻑뻑함이 느껴지면 그날 바로 점검하기
- 열쇠구멍은 닦아 두되 오일은 아무거나 뿌리지 않기
무거운 열쇠고리는 열쇠구멍에 계속 힘이 실려 자물쇠를 빨리 닳게 합니다. / 작은 습관이 한 해의 고장을 줄여 줍니다. / 열쇠 상태가 의심스럽다면 문이 막히기 전에 먼저 새로 만들어 두는 것이 가장 부담이 적습니다.
열쇠를 오래 쓴 집일수록 한 번쯤 새 열쇠를 만들어 두면 마음이 편합니다. / 새로 만든 열쇠는 처음에 잘 맞는지 문 앞에서 바로 확인해 보세요.

# 천현동 말고 하남 어디든 갑니다
천현동 가까운 창우동, 신장동, 덕풍동은 물론 미사, 위례, 감일 신도시까지 출동합니다. / 하남시 안이면 24시간 언제든 연락을 받습니다.
다니는 동네는 [하남시 출장열쇠](hanam.html) 페이지에 모아 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
