# 천현동 우리 집 번호, 몇 사람이 알고 있나요
천현동은 아파트와 함께 대문이 있는 주택도 적지 않은 하남 동네입니다. / 대문과 현관에 각각 번호식 잠금을 달아 둔 집은 외워야 할 번호가 둘이 되고, 가족이 많을수록 관리가 복잡해집니다.
처음 정한 번호를 몇 해씩 그대로 쓰다 보면 가족뿐 아니라 친척, 예전에 일을 봐 준 분까지 번호를 아는 상태가 되기 쉽습니다. / 그렇다고 아무 때나 바꾸면 가족 중 누군가 문 앞에서 막히게 됩니다.
이 글은 천현동에서 집 비밀번호를 언제, 어떻게 바꾸고 가족끼리 어떻게 나누면 좋은지 정리했습니다. / 번호 때문에 문이 안 열리면 [하남 출장열쇠](hanam.html)로 연락 주세요.
@ 천현동 대문 현관 도어락 비밀번호 관리

# 번호를 바꾸면 좋은 때
정해진 주기가 꼭 있는 것은 아니지만, 아래 같은 일이 있었다면 바꿀 때가 된 것입니다. / 계절이 바뀔 때마다 한 번씩 떠올려 보세요.
- 집수리나 이사 도움처럼 가족 외의 사람이 번호를 알게 됐을 때
- 함께 살던 가족이 분가하거나 독립했을 때
- 번호판 특정 숫자만 닳아 보이기 시작했을 때
- 번호를 누르는 모습을 누가 본 것 같아 마음에 걸릴 때
아무 일이 없더라도 반년이나 일 년에 한 번쯤은 바꾸는 집이 많습니다. / 날짜를 정해 두면 잊지 않습니다.

# 대문과 현관 번호, 같게 할까 다르게 할까
대문과 현관 번호를 같게 하면 외우기는 편하지만, 하나가 알려지면 둘 다 열리게 됩니다. / 다르게 하면 조금 번거로워도 한쪽이 알려졌을 때 다른 쪽이 지켜집니다.
손님이나 배달 기사님께 대문만 열어 드려야 하는 일이 잦다면 다르게 두는 편이 낫습니다. / 대문 번호는 조금 더 자주 바꾸고 현관 번호는 가족만 알게 하는 방식을 쓰는 집도 있습니다.
어르신이 함께 사신다면 너무 복잡하게 나누기보다 가족이 함께 정해 무리 없이 외울 수 있는 정도로 맞추세요.
@ 천현동 주택 대문 번호식 잠금

# 어떤 번호가 좋을까요
남이 짐작하기 어렵고 가족은 잊지 않는 번호가 가장 좋습니다. / 아래는 피하시길 권합니다.
- 생일, 결혼기념일, 집 주소처럼 남도 알 수 있는 숫자
- 1234, 0000처럼 순서대로 이어지거나 같은 숫자 반복
- 휴대폰 번호 뒷자리
- 차 번호
여섯 자리 이상이면 더 좋고, 가족끼리만 아는 이야기에서 숫자를 따오면 잊어버리지도 않습니다. / 예를 들어 가족이 함께 기억하는 어떤 일의 숫자를 섞어 만드는 식입니다.

# 바꿀 때 순서 정하기
번호를 바꾸는 일 자체보다 가족에게 알리는 순서가 더 중요합니다. / 바꾼 사람만 알고 다른 가족이 모르면 그날 저녁 문 앞에서 문제가 생깁니다.
- 바꾸기 전에 가족에게 바꿀 날짜를 먼저 알리기
- 되도록 가족이 다 있는 날 저녁에 함께 바꾸기
- 바꾼 뒤 한 사람씩 직접 눌러 보며 확인하기
- 외출 중인 가족에게는 직접 통화로 알리기
문자로 번호를 보낼 때는 다른 사람이 볼 수 있는 단체 대화방보다 직접 전화가 낫습니다.

# 번호를 바꾸는 방법은 제품마다 다릅니다
대부분 도어락은 건전지 덮개 안쪽에 등록 버튼이 있고, 그 버튼을 누른 뒤 새 번호를 넣는 방식입니다. / 다만 순서와 확인음은 제품마다 달라서 설명서를 보고 하시는 게 안전합니다.
등록 버튼을 잘못 누르면 카드나 지문이 함께 지워지는 제품도 있습니다. / 처음 해 보신다면 문을 열어 둔 상태에서 하세요.
대문 번호식 잠금은 현관 도어락과 방법이 전혀 다를 수 있습니다. / 방법이 헷갈리면 무리하지 말고 상담을 받으세요.
@ 천현동 도어락 등록 버튼 번호 변경

# 손님에게 번호를 알려야 할 때
집안일을 도와주시는 분, 아이를 봐 주시는 분처럼 가족 외의 사람이 드나들 때가 있습니다. / 이럴 때 가족 번호를 그대로 알려 주기보다 임시 번호 기능이 있는지 확인해 보세요.
임시 번호가 없다면 그분이 다녀간 뒤 번호를 바꾸는 것이 가장 깔끔합니다. / 대문만 열어 드려도 되는 경우라면 대문 번호만 알려 드리는 방법도 있습니다.

# 어르신과 아이를 위한 배려
어르신은 새 번호를 외우는 데 시간이 걸리고, 아이는 번호를 친구 앞에서 누르기도 합니다. / 그래서 번호 외에 다른 방법을 함께 마련해 두면 좋습니다.
어르신께는 카드키를 하나 드리고, 아이에게는 번호를 누를 때 손으로 가리는 습관을 알려 주세요. / 지문 기능이 있다면 아이와 어르신은 손가락 두 개씩 등록해 두시면 실패가 줄어듭니다.

# 번호를 잊어 문이 안 열린다면
번호를 바꾼 지 얼마 안 돼 헷갈리는 일은 흔합니다. / 몇 번 틀리면 도어락이 입력을 막으니 확실하지 않은 번호를 계속 누르지는 마세요.
가족에게 먼저 확인하고, 카드나 지문 같은 다른 방법으로 들어갈 수 있는지 보세요. / 그래도 안 되면 그때 출장을 부르시면 됩니다.
대문은 열렸는데 현관만 막혔다면, 혹시 대문 번호를 현관에 누르고 있는 건 아닌지도 한 번 떠올려 보세요. / 두 번호를 따로 쓰는 집에서 바꾼 직후에 이런 일이 자주 생깁니다.

# 출장 부르실 때 알려 주실 것
- 주택인지 아파트인지, 대문까지 잠겼는지
- 도어락이 번호만 되는지, 카드나 지문도 되는지
- 입력이 잠겨 있는지
- 도어락 앞면 사진
주택은 대문 위치와 들어오는 길을 알려 주시면 빨리 찾아갑니다. / 차를 댈 곳이 있는지도 함께 말씀해 주세요.

# 확인과 비용
문을 열거나 번호를 다시 등록할 때는 사시는 분인지 먼저 확인합니다. / 신분증 주소나 이름과 주소가 함께 적힌 우편물, 아파트라면 관리사무소 확인이면 됩니다.
작업 전에 무엇을 할지와 비용을 먼저 말씀드리고 동의하시면 시작합니다. / 열지 못하면 비용은 받지 않습니다. 진행 순서는 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html)에 있습니다.

# 관리가 너무 번거롭다면
번호 바꾸기가 복잡하거나 등록 버튼이 잘 안 먹힌다면 [도어락 수리](doorlock-repair.html)로 점검받아 보세요. / 대문에 열쇠만 쓰고 있어 관리가 어렵다면 [도어락 설치](doorlock-install.html)로 번호식을 다는 방법도 있습니다.
오래된 제품이라 임시 번호나 카드 기능이 없어 불편하다면 [도어락 교체](doorlock-replace.html)도 함께 안내해 드립니다.

# 천현동 말고 하남 어디든
천현동과 가까운 창우동, 신장동, 덕풍동은 물론 풍산동, 미사동, 위례동, 감일동까지 하남 전 지역에 출동합니다. / 하남 안내는 [하남 출장열쇠](hanam.html)에, 서울과 경기 다른 곳은 [출장 지역](area.html)에 있습니다.
