# 덕풍동 오래된 집에서 문이 말을 안 들을 때
덕풍동은 오래된 주택과 빌라, 다세대 건물이 많은 동네라 문틀과 문이 세월을 많이 견딘 집이 흔합니다. / 문이 뻑뻑하거나 도어락이 잘 안 잠기는 일은 도어락 문제가 아니라 문과 문틀 문제인 경우가 많습니다.
도어락만 새것으로 바꿨는데도 같은 증상이 계속된다면 문이나 문틀이 틀어졌을 가능성을 생각해 볼 필요가 있습니다. / 원인을 제대로 짚어야 헛돈을 쓰지 않습니다.
이 글은 덕풍동에서 오래된 문과 문틀 때문에 도어락이 이상할 때 점검하는 순서를 정리했습니다. / 문이 지금 안 열리는 상황이라면 [하남 출장열쇠](hanam.html)에 먼저 연락 주세요.
@ 덕풍동 오래된 문틀 도어락 점검 출장열쇠

# 문틀이 틀어지면 어떤 일이 생기나요
문이 오래되면 경첩이 헐거워지고 문이 아래로 처지면서 문과 문틀이 서로 맞지 않게 됩니다. / 이렇게 되면 도어락의 걸쇠가 문틀 구멍에 정확히 들어가지 않습니다.
그 결과 문이 안 잠기거나, 잠긴 뒤 열기 힘들거나, 억지로 밀어야만 닫히는 증상이 나타납니다. / 도어락 자체는 멀쩡한데 문이 안 맞아서 생기는 문제입니다.
이럴 때는 도어락을 바꿔도 해결이 되지 않고 문 쪽을 같이 봐야 합니다.

# 문과 문틀 문제 때 흔히 보이는 증상
다음과 같은 증상이 있다면 문이나 문틀 쪽을 의심해 볼 수 있습니다.
- 문을 닫을 때 위쪽이나 아래쪽이 문틀에 닿는 느낌이 나는 경우
- 걸쇠가 들어가지 않아 문이 살짝 열려 있는 경우
- 열쇠나 번호로 열려도 문을 당겨야 열리는 경우
- 문 위쪽과 아래쪽의 틈 간격이 서로 다른 경우
- 문을 닫을 때마다 쾅 소리가 크게 나는 경우
이런 증상은 날씨나 계절에 따라 더 심해졌다가 덜해지기도 합니다.
@ 덕풍동 처진 문 걸쇠 어긋남 점검

# 억지로 닫거나 밀지 마세요
문이 안 닫힌다고 세게 밀거나 발로 차는 것은 피하세요. / 도어락 안쪽 부품과 문틀이 같이 상하면 수리 범위가 훨씬 커집니다.
잠기지 않은 채 외출하는 것은 보안상 좋지 않으니 일단 문이 잠겼는지 꼭 확인하세요. / 잠기지 않는다면 임시로 안쪽 보조키나 다른 방법으로 잠그는 것이 낫습니다.
문이 어느 쪽으로 어긋났는지 눈으로 확인하고 사진을 찍어 두면 상담에 도움이 됩니다.

# 경첩 쪽도 같이 확인합니다
오래된 문은 경첩 나사가 헐거워지면서 문이 처지는 경우가 많습니다. / 나사를 조이는 것만으로 좋아지는 경우도 있습니다.
경첩 자체가 휘었거나 닳았다면 교체가 필요할 수 있습니다. / 경첩만 바꿔도 문이 다시 제자리로 돌아오는 경우가 많습니다.
어느 쪽이 원인인지 확인하는 일이 먼저입니다. / 자세한 점검 순서는 [도어락 수리](doorlock-repair.html)에서도 안내하고 있습니다.

# 도어락 걸쇠와 문틀 구멍의 맞춤
도어락 걸쇠는 문틀에 있는 구멍이나 받침쇠에 들어가면서 잠깁니다. / 이 위치가 조금이라도 어긋나면 걸쇠가 헛돌거나 걸리지 않습니다.
받침쇠 위치를 조정하거나 문틀 구멍을 정리하는 방법으로 해결되는 경우가 있습니다. / 이 작업은 도어락을 바꾸는 것보다 부담이 훨씬 작습니다.
문과 문틀이 많이 틀어졌다면 도어락만이 아니라 문의 높이와 위치를 함께 조정하는 방법을 말씀드립니다.

# 덕풍동에서 위치는 이렇게 알려주세요
주택과 빌라는 건물 이름이 없는 경우가 많아 위치를 구체적으로 알려주셔야 합니다.
- 도로명 주소나 지번, 대문이나 건물 입구 사진
- 몇 층 몇 호인지, 건물 공동현관이 따로 있는지
- 문이 안 열리는 상태인지, 잠기지 않는 상태인지
- 문과 문틀의 사진
사진을 문자로 보내 주시면 어떤 작업이 필요한지 먼저 가늠해 드릴 수 있습니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 이웃이나 관리인 확인 중 하나면 됩니다.
번거로우시겠지만 집과 이웃을 지키기 위한 절차입니다. / 확인이 어려우면 작업을 시작할 수 없습니다.
세입자라면 임대차 계약서나 입주 사실을 보여 주는 서류도 도움이 됩니다.

# 비용은 열기 전에 말씀드립니다
문과 도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 하남 덕풍동 출장열쇠 비파손 개방

# 오래된 문도 덜 상하게 엽니다
오래된 문은 목재나 얇은 철판 문이 많아서 억지로 열면 문 자체가 상하기 쉽습니다. / 그래서 덜 상하는 방법부터 차례로 시도합니다.
문틀이 틀어져 걸쇠가 팽팽하게 걸려 있는 경우에는 걸쇠 위치를 확인하면서 천천히 풉니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 말씀드립니다.
자세한 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 문을 바꿔야 할 때와 고쳐 쓸 때
문이 많이 틀어졌다고 해서 꼭 문을 새로 바꿔야 하는 것은 아닙니다. / 경첩 조정, 받침쇠 위치 변경, 문틀 정리로 해결되는 경우가 많습니다.
문 자체가 뒤틀렸거나 부식이 심해 도어락이 제대로 고정되지 않는다면 그때는 문 교체를 같이 생각해야 합니다. / 이런 경우는 도어락 교체보다 문 상태를 먼저 설명드립니다.
도어락만 새것으로 바꿔도 해결되는 경우라면 [도어락 교체](doorlock-replace.html)로 안내드립니다.

# 해마다 한 번 점검해 두면 좋은 것
오래된 집일수록 해마다 한 번 문과 도어락을 점검해 두면 갑작스러운 불편을 줄일 수 있습니다.
- 경첩 나사가 헐거워지지 않았는지 확인하기
- 문을 닫을 때 걸쇠가 부드럽게 들어가는지 확인하기
- 문 위쪽과 아래쪽 틈이 균일한지 보기
- 도어락 건전지를 전부 새것으로 교체하기
- 열쇠구멍에 먼지가 쌓이지 않았는지 확인하기
습도가 높은 여름과 건조한 겨울에는 문이 조금씩 변할 수 있으니 계절이 바뀔 때 한 번씩 보세요.

# 덕풍동 말고 하남 어디든 갑니다
미사동, 위례동, 감일동, 풍산동까지 하남 안이면 어디든 출동합니다. / 24시간 연락 받습니다.
하남에서 다니는 지역은 [하남시 출장열쇠](hanam.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
