# 감일동 현관 앞, 번호가 틀렸다는 소리만
감일동은 하남에서도 새로 들어선 아파트가 많은 동네입니다. / 입주하면서 달린 도어락을 그대로 쓰는 집이 대부분이라, 번호 설정이나 등록 방법을 아직 손에 익히지 못한 분도 많습니다.
그러다 보니 가족 중 한 사람이 번호를 바꿔 놓고 미처 알리지 못하거나, 오랜만에 바꾼 번호가 기억나지 않아 문 앞에 서는 일이 생깁니다. / 번호를 누를 때마다 틀렸다는 소리가 나면 누가 바꿨는지부터 궁금해집니다.
이 글은 감일동에서 비밀번호 때문에 문이 안 열릴 때 가족끼리 엇갈림을 푸는 순서를 정리했습니다. / 끝내 안 열리면 [하남 출장열쇠](hanam.html)로 전화 주세요.
@ 감일동 아파트 도어락 비밀번호 틀림

# 최근 일주일을 떠올려 보세요
번호가 갑자기 안 맞는다면 대개 최근에 무슨 일이 있었던 경우가 많습니다. / 아래 중 해당하는 일이 있는지 생각해 보세요.
- 집에 인테리어나 가전 설치 기사님이 다녀감
- 아이를 봐 주러 부모님이나 친척이 오가셨음
- 가족 중 누군가 번호가 노출된 것 같다며 바꾸자고 했음
- 도어락 건전지를 갈다가 설정 버튼을 잘못 눌렀음
이런 일이 있었다면 번호가 바뀌었을 가능성이 큽니다. / 바꾼 사람이 누구인지 짐작이 가면 그분께 먼저 연락하는 것이 가장 빠릅니다.

# 가족 대화방부터 확인
요즘은 가족 대화방에 번호를 남겨 두는 집이 많습니다. / "번호 바꿨어" 같은 메시지가 지나가 있지 않은지 대화방을 위로 올려 찾아보세요.
배우자가 회사에 있어 통화가 어렵다면 문자를 남겨 두세요. / 답을 기다리는 동안 다른 방법을 함께 해 보면 됩니다.
아이가 번호를 아는 나이라면 학교나 학원이 끝난 뒤 물어보는 것도 방법입니다. / 아이들이 오히려 번호를 정확히 기억하는 경우가 꽤 있습니다.

# 번호 말고 다른 열림 방법
입주할 때 받은 카드키나 태그가 열쇠고리에 달려 있는지 보세요. / 번호가 바뀌었어도 카드는 그대로 등록돼 있는 경우가 많습니다.
지문이나 휴대폰 앱으로 여는 기능이 있는 도어락이라면 그것도 시도해 보세요. / 앱 연동을 해 둔 가족이 있다면 그분께 원격으로 열어 달라고 부탁할 수도 있습니다.
이 중 하나라도 되면 안에 들어가서 차분히 번호를 다시 정하면 됩니다.
카드를 대도 반응이 없다면 건전지가 약해 번호판 반응까지 떨어진 상태일 수 있습니다. / 번호판 불빛이 흐리거나 깜빡인다면 9V 건전지를 바깥쪽 비상 단자에 대고 다시 해 보세요.
공동현관 출입 태그와 집 도어락 카드가 다른 경우도 있으니 열쇠고리에 달린 것을 하나씩 대 보시는 것도 방법입니다.
@ 감일동 도어락 카드키 태그 열림

# 몇 번 틀리면 잠깐 멈추는 이유
번호를 여러 번 연속으로 틀리면 도어락은 한동안 입력을 받지 않습니다. / 낯선 사람이 아무 번호나 눌러 보는 것을 막기 위한 장치라 고장이 아닙니다.
입력이 막히면 경고음이 울리기도 하는데, 이웃 집에도 들릴 만큼 클 때가 있습니다. / 이럴 때는 몇 분 기다렸다가 확실한 번호만 다시 눌러 보세요.
짐작으로 이것저것 누르다 보면 잠기는 시간이 점점 길어집니다. / 세 번쯤 해 보고 안 되면 다른 방법으로 넘어가시는 게 좋습니다.

# 건전지 갈다가 번호가 바뀐 경우
건전지 덮개 안쪽에는 등록 버튼이나 설정 버튼이 함께 있는 제품이 많습니다. / 건전지를 갈다가 이 버튼을 눌러 버리면 번호 등록 모드에 들어가 버리기도 합니다.
이때 아무 숫자나 눌렸다면 새 번호로 바뀌었을 수 있습니다. / 최근에 건전지를 간 사람이 있다면 그때 어떤 버튼을 눌렀는지 물어보세요.
번호가 이렇게 바뀐 경우는 누구도 새 번호를 모르는 상태라서 문을 연 뒤 다시 등록해야 합니다.

# 해 보면 안 되는 방법
번호를 몰라서 문이 안 열릴 때 하지 말아야 할 일도 있습니다. / 새 도어락은 외관이 상하면 고치는 범위가 커지니 아래는 피해 주세요.
- 번호판 틈에 카드나 공구를 넣어 벌리기
- 인터넷에서 본 초기화 방법을 바깥에서 따라 하기
- 번호판을 손바닥으로 세게 두드리기
- 문을 당기거나 발로 밀기
초기화 버튼은 대부분 문 안쪽에 있어서 바깥에서는 할 수 없습니다.

# 하남 출장 부를 때 알려 주실 것
감일동은 단지와 동이 많으니 위치를 정확히 알려 주시면 빨리 도착할 수 있습니다. / 아래만 짧게 말씀해 주세요.
- 단지 이름과 동, 호수
- 도어락이 번호만 되는지, 카드나 지문도 되는지
- 지금 입력이 잠겨 있는지
- 집 안에 아이나 반려동물이 있는지
- 도어락 앞면 사진
@ 감일동 출장열쇠 도어락 위치 안내

# 문 열기 전 본인 확인
번호를 모르는 상황일수록 그 집에 사시는 분인지 확인하는 절차가 꼭 필요합니다. / 신분증 주소, 이름과 주소가 함께 적힌 우편물, 관리사무소 세대 확인 가운데 하나면 됩니다.
새로 입주해서 아직 주소 변경을 안 하셨다면 분양이나 임대 계약서 사진도 도움이 됩니다. / 관리사무소에 전화해 미리 세대 확인을 부탁해 두셔도 좋습니다.

# 비용은 시작하기 전에
도어락 종류와 상태를 본 뒤 비용을 먼저 말씀드리고, 동의하실 때만 진행합니다. / 문을 연 뒤 번호를 새로 등록하는 일도 함께 안내해 드립니다.
열지 못하면 비용은 받지 않습니다. / 진행 방법은 [이용안내](guide.html)에, 문 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 가족 모두 모인 자리에서 새 번호
문이 열리면 기존 번호를 지우고 새 번호를 등록합니다. / 이번에는 가족이 모두 있는 자리에서 함께 정하시길 권합니다.
- 번호는 한 사람이 바꾸되 바꾸기 전에 꼭 가족에게 알리기
- 가족 대화방에 바꾼 날짜만 남기고 번호는 직접 말로 전하기
- 아이와 어르신이 외우기 쉬우면서 남이 짐작하기 어려운 번호 고르기
- 카드나 지문도 가족마다 하나씩 등록해 두기
번호를 바꾸는 주기와 가족끼리 나누는 방법을 정해 두면 같은 일이 되풀이되지 않습니다.

# 번호 등록이 자꾸 헷갈린다면
새 아파트 도어락은 기능이 많은 만큼 설정 순서도 복잡한 편입니다. / 설명서를 잃어버렸다면 제품 이름을 확인해 두시면 나중에 찾기 쉽습니다.
버튼을 눌러도 등록이 안 되거나 기능이 이상하게 동작한다면 [도어락 수리](doorlock-repair.html)로 점검받으세요. / 기존 제품이 너무 불편하면 [도어락 교체](doorlock-replace.html)로 쓰기 편한 제품을 고르는 방법도 있습니다.

# 감일동 말고 하남 전역
감일동과 가까운 위례동은 물론 미사동, 풍산동, 덕풍동, 신장동, 창우동, 천현동까지 하남 어디든 출동합니다. / 하남 안내는 [하남 출장열쇠](hanam.html)에서, 서울과 경기 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.
