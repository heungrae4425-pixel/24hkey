# 미사동 새 현관, 그래도 점검이 필요한 이유
미사동은 미사역 주변으로 신도시 아파트와 오피스텔이 넓게 자리 잡은 동네입니다. / 입주 때 달린 도어락이 아직 새것인 집이 많아서 현관 방범은 따로 신경 쓰지 않아도 된다고 생각하기 쉽습니다.
하지만 도어락이 새것이어도 설정이 어떻게 돼 있는지, 번호를 누가 알고 있는지는 집마다 다릅니다. / 방범은 비싼 장비보다 이미 있는 장치를 제대로 쓰는 데서 시작합니다.
이 글은 미사동 아파트와 오피스텔에서 불안해하지 않으면서 현관을 점검하는 방법을 정리했습니다. / 손볼 곳이 보이면 [하남 출장열쇠](hanam.html)로 상담하셔도 됩니다.
@ 미사동 아파트 현관 도어락 점검

# 불안보다 확인이 먼저
현관 방범 이야기를 하면 걱정부터 커지는 분이 많습니다. / 하지만 대부분은 몇 가지 확인만으로 충분히 마음이 놓이는 수준입니다.
아래 항목을 하나씩 보면서 우리 집은 어떤지 체크해 보세요. / 다 괜찮다면 지금처럼 쓰시면 되고, 하나둘 걸리는 것만 손보면 됩니다.
장비를 더 다는 것은 마지막에 생각해도 늦지 않습니다. / 먼저 지금 가진 것을 잘 쓰는 것이 순서입니다.

# 자동 잠금이 켜져 있나요
요즘 도어락은 문이 닫히면 저절로 잠기는 자동 잠금 기능이 있습니다. / 그런데 이사 들어올 때나 짐을 옮길 때 이 기능을 꺼 두고 다시 켜지 않은 집이 있습니다.
문을 닫고 몇 초 뒤 잠기는 소리가 나는지 들어 보세요. / 소리가 없다면 수동 잠금으로 설정돼 있을 수 있습니다.
수동 잠금이 편해서 일부러 쓰신다면 나갈 때마다 잠금 버튼을 누르는 습관을 꼭 들여 주세요. / 아이들이 먼저 나가는 집이라면 자동 잠금이 더 낫습니다.

# 번호판 손자국 살펴보기
번호를 오래 쓰면 자주 누르는 숫자에만 손자국이나 광이 남습니다. / 불빛을 비스듬히 비춰 보면 어떤 숫자를 누르는지 대충 보이기도 합니다.
번호를 누른 뒤 손바닥으로 번호판을 한 번 쓸어 주면 이런 흔적이 줄어듭니다. / 일부 도어락은 실제 번호 앞뒤에 아무 숫자를 더 눌러도 열리는 기능이 있으니 설명서를 확인해 보세요.
번호판 위에 보호 덮개가 있는 제품이라면 누를 때 덮개로 손을 가리는 것도 방법입니다.
@ 미사동 도어락 번호판 손자국 확인

# 번호를 아는 사람 정리하기
입주 청소, 가구 설치, 인테리어처럼 새 아파트에는 사람이 많이 드나듭니다. / 그때 알려 준 번호를 그대로 쓰고 있지 않은지 떠올려 보세요.
- 입주 때 업체에 알려 준 번호를 바꿨는지
- 이전에 집을 봐 주던 분이 알던 번호가 그대로인지
- 가족 외에 번호를 아는 사람이 몇 명인지
하나라도 애매하면 번호를 바꾸는 것이 가장 쉽고 확실한 정리입니다. / 손님이 자주 오는 집이라면 임시 번호 기능이 있는지도 확인해 보세요.

# 택배와 현관 앞 물건
미사동 아파트와 오피스텔은 택배가 많이 오가는 동네입니다. / 현관 앞에 택배 상자가 며칠씩 쌓여 있으면 집을 비웠다는 신호로 보일 수 있습니다.
받은 상자는 되도록 빨리 들여놓고, 주소와 이름이 적힌 송장은 떼어서 버리세요. / 오래 집을 비운다면 택배를 맡아 줄 곳을 정해 두는 것도 좋습니다.
현관 앞에 신발이나 우산을 계속 내놓는 것도 피하시면 좋습니다. / 이웃에게도 깔끔해 보이고 복도도 넓게 쓸 수 있습니다.

# 오피스텔이라면 더 볼 것
오피스텔은 같은 층에 세대가 많고 사람이 자주 바뀝니다. / 이전 입주자가 쓰던 카드나 번호가 남아 있지 않은지 입주할 때 꼭 정리하세요.
건물 공동현관 카드와 세대 도어락 카드가 다르다면 둘 다 확인해 보세요. / 세대 도어락에 등록된 카드 수가 내가 가진 카드보다 많다면 전체를 지우고 다시 등록하는 게 좋습니다.
@ 미사동 오피스텔 도어락 카드 정리

# 문 닫힘과 걸쇠 확인
도어락이 잠겨도 문이 끝까지 안 닫혀 있으면 소용이 없습니다. / 도어클로저가 약해져 마지막 몇 센티에서 멈추는 문이 의외로 많습니다.
나갈 때 손잡이를 한 번 당겨서 덜컥거리지 않는지 확인하는 습관이 좋습니다. / 집에 있을 때는 안쪽 걸쇠나 보조 잠금을 함께 걸어 두면 더 든든합니다.
문이 끝까지 닫히는데도 걸쇠가 반만 들어가는 느낌이라면 문틀 쪽 받이 위치가 조금 어긋난 것일 수 있습니다. / 새 아파트라도 입주 뒤 몇 해가 지나면 문이 미세하게 자리를 잡으면서 이런 일이 생깁니다.
닫힐 때 쾅 하는 소리가 커졌다면 도어클로저 속도도 함께 봐 주세요. / 너무 빠르게 닫히는 문은 손이 끼일 수 있어 아이가 있는 집이라면 더 챙길 부분입니다.

# 긴 외출 전에 할 일
여행이나 명절로 며칠 집을 비운다면 떠나기 전에 몇 가지만 챙기세요. / 돌아왔을 때 문이 안 열리는 일도 함께 막을 수 있습니다.
- 도어락 건전지를 새것으로 바꾸기
- 자동 잠금이 켜져 있는지 확인
- 택배는 맡아 줄 곳으로 미리 돌려 두기
- 앱 알림이 되는 도어락이라면 알림이 오는지 확인
가스 밸브와 창문 잠금을 확인하는 김에 베란다 쪽 잠금장치도 한 번 걸어 두세요. / 고층이라도 베란다 창 잠금을 챙겨 두면 집을 비우는 동안 마음이 한결 편합니다.
돌아오는 날 늦은 밤에 도착한다면 9V 건전지 하나를 가방에 넣어 두는 것도 좋습니다.

# 손볼 곳이 보이면
문 닫힘이 약하거나 잠금이 덜 걸린다면 도어클로저나 잠금쇠 조정이 필요합니다. / 도어락 기능이 제대로 안 된다면 [도어락 수리](doorlock-repair.html)로 먼저 점검하세요.
번호 기능이 단순한 제품이라 불편하다면 [도어락 교체](doorlock-replace.html)로 보조 기능이 있는 제품을 고르는 방법도 있습니다. / 문이 잠겨 못 들어가는 상황이라면 [현관문 개문](door-open.html)부터 진행합니다.

# 점검 상담 받으실 때
아래를 알려 주시면 무엇이 필요한지 미리 가늠할 수 있습니다. / 도어락 사진을 보내 주시면 더 좋습니다.
- 아파트인지 오피스텔인지, 단지 이름과 동, 호수
- 걱정되는 부분이 번호인지, 카드인지, 문 닫힘인지
- 도어락 제품 사진
점검만 받고 싶으시다면 편한 시간을 미리 정해 주셔도 됩니다.

# 확인과 비용
설정을 바꾸거나 부품을 손볼 때도 사시는 분인지 먼저 확인합니다. / 신분증 주소나 우편물, 관리사무소 확인 가운데 하나면 됩니다.
점검한 뒤 손볼 곳과 금액을 먼저 말씀드리고, 고르신 것만 진행합니다. / 바꿀 필요가 없는 부분은 그대로 두시라고 말씀드립니다. 자세한 흐름은 [이용안내](guide.html)에 있습니다.

# 미사동 말고 하남 어디든
미사동과 가까운 풍산동, 덕풍동은 물론 신장동, 창우동, 천현동, 위례동, 감일동까지 하남 전 지역에 출동합니다. / 하남 안내는 [하남 출장열쇠](hanam.html), 다른 지역은 [출장 지역](area.html)에서 보세요.
