# 신장동에서 도어락 손잡이가 헐겁게 돌아갈 때
신장동은 오래 살아온 주택과 빌라가 모여 있어 현관문도 세월이 느껴지는 집이 많습니다. / 손잡이가 흔들리거나 헛도는 증상은 하루아침에 생기지 않고 조금씩 진행됩니다.
어느 날 손잡이를 돌렸는데 걸쇠가 움직이지 않아 문이 안 열리면 그때서야 문제를 알게 됩니다. / 이 글은 그런 순간에 [하남 출장열쇠](hanam.html)를 부르기 전에 확인할 것을 정리했습니다.
지금 문 밖에 계시다면 4번과 6번 소제목부터 보셔도 됩니다. / 안쪽에 계신다면 문이 열려 있을 때 점검할 수 있어 훨씬 여유가 있습니다.
@ 신장동 도어락 손잡이 헐거움 출장열쇠

# 손잡이가 헛도는 증상은 이렇게 생깁니다
손잡이를 돌릴 때 손에 걸리는 느낌이 없고 헛돌면 손잡이와 걸쇠를 잇는 부품이 풀렸을 수 있습니다. / 나사가 느슨해진 정도라면 조이는 것으로 끝나지만 속 부품이 닳았다면 교체가 필요합니다.
눌러서 여는 형, 밀고 당기는 형, 레버형 손잡이 모두 오래 쓰면 같은 증상이 나타납니다. / 문을 하루에도 여러 번 여닫는 집일수록 진행이 빠릅니다.
손잡이가 아래로 처져 있거나 돌린 뒤 제자리로 돌아오지 않는 것도 같은 증상의 앞 단계입니다. / 이럴 때 미리 손보면 문이 잠겨 버리는 일을 막을 수 있습니다.

# 전화하기 전에 30초만 살펴보세요
아래 네 가지를 보면 전화로 설명하기가 쉬워지고 챙겨 가는 장비도 맞출 수 있습니다.
- 손잡이를 돌렸을 때 걸쇠가 같이 움직이는지
- 손잡이 아래나 옆에 보이는 나사가 풀려 있는지
- 열쇠나 번호로 잠금은 풀리는데 손잡이만 돌아가지 않는지
- 문을 안쪽으로 살짝 밀면서 돌리면 움직이는지
잠금은 풀리는데 손잡이만 헛돈다면 손잡이 쪽 부품 문제일 가능성이 큽니다. / 번호가 먹히지 않는다면 도어락 쪽 문제일 수 있으니 구분해서 알려주시면 좋습니다.

# 손잡이 나사는 이렇게만 조여 보세요
손잡이 옆이나 안쪽 덮개 아래에 작은 나사가 있는 모델이 많습니다. / 맞는 크기의 드라이버로 살살 조여 보되 힘을 과하게 주지는 마세요.
나사가 헛돌거나 머리가 뭉개져 있다면 더 시도하지 말고 그대로 두는 게 낫습니다. / 무리하게 돌리면 나사 구멍이 망가져 고정할 자리가 없어집니다.
조인 뒤에도 헐겁다면 속 부품이 문제이니 거기서 멈추고 연락 주세요. / 문이 열려 있는 상태라면 문틈에 고정할 것을 끼워 두어 저절로 닫히지 않게 해 두세요.

# 손잡이만 헛돌 때 문이 잠겨 버리는 경우
손잡이가 헛돌면 걸쇠가 빠지지 않아 문이 열리지 않는 일이 생깁니다. / 안쪽에서는 열리는데 바깥에서만 안 열리는 경우도 있어 상황이 제각각입니다.
이때 손잡이를 더 세게 돌리거나 문을 흔들면 걸쇠가 문틀에 더 깊이 물릴 수 있습니다. / 그대로 두고 연락을 주시는 편이 문과 도어락을 모두 지킵니다.
집 안에 사람이 있는지, 아이나 반려동물이 혼자 있는지도 같이 알려주세요. / 그런 사정이 있으면 도착해서 하는 순서가 달라집니다.

# 이렇게 하면 오히려 고장이 커집니다
급한 마음에 손잡이를 힘껏 당기거나 문을 발로 차는 분들이 있습니다. / 그러면 손잡이 축이 휘고 문틀까지 상해 고칠 곳이 늘어납니다.
카드나 칼로 문틈을 벌리려는 시도도 문과 도어락 외관에 흠을 남깁니다. / 나중에 교체해야 할 때 비용이 더 커질 수 있으니 하지 않는 게 좋습니다.
윤활제를 구멍마다 뿌리는 것도 권하지 않습니다. / 기름이 번호판 안으로 들어가면 오작동이 생길 수 있습니다.
@ 신장동 손잡이 고장 하남 도어락 점검

# 신장동 주택과 빌라에서 이 증상이 잦은 이유
신장동처럼 오래된 주택가는 문 자체가 무겁고 경첩이 처진 집이 많아 손잡이에 힘이 많이 실립니다. / 문이 덜 닫혀 세게 밀어 닫는 습관이 쌓이면 손잡이 부품도 같이 닳습니다.
빌라 공동 출입문과 개인 현관문을 함께 쓰는 집은 하루 여닫는 횟수가 더 많습니다. / 그만큼 손잡이 점검 주기도 짧게 잡는 편이 좋습니다.
겨울에 문이 얼고 여름에 부풀면 손잡이 움직임이 달라지기도 합니다. / 계절이 바뀔 때 한 번씩 흔들림을 살펴보시면 도움이 됩니다.

# 출장열쇠를 부르면 이렇게 진행됩니다
먼저 위치와 도어락 모양, 손잡이 상태를 전화로 여쭙니다. / 사진을 문자로 보내주시면 맞는 부품을 챙겨 가기 좋습니다.
도착하면 문과 손잡이를 살피고 열 수 있는 방법부터 덜 상하는 순서로 시도합니다. / 열고 난 뒤에는 헛도는 원인을 확인하고 조여서 되는지, 부품을 바꿔야 하는지 보여드립니다.
[현관문 개문](door-open.html) 방식은 따로 정리해 두었습니다. / 손잡이 쪽 문제로 연 경우에는 같은 날 [도어락 수리](doorlock-repair.html)까지 이어서 하실 수 있습니다.

# 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 이웃과 집주인 모두를 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 손대기 전에 말씀드립니다
문과 손잡이 상태를 보고 얼마가 드는지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 고쳐 쓸지 바꿀지는 이렇게 가립니다
나사만 풀린 경우는 조여서 끝납니다. / 속 부품이 닳았다면 해당 부품만 바꾸는 방법도 있습니다.
도어락 전체가 오래돼 번호판이나 모터까지 불안하다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐서 더 쓸 수 있는데 바꾸라고 권하지는 않습니다.
교체를 하시게 되면 문 두께와 보조키 위치를 먼저 확인해 맞는 제품을 고릅니다. / 새로 다는 일은 [도어락 설치](doorlock-install.html) 페이지에서도 보실 수 있습니다.
@ 신장동 도어락 수리 교체 하남 출장

# 손잡이가 헐거워지지 않게 쓰는 법
문을 닫을 때 손잡이를 잡고 세게 당기는 습관은 부품을 빨리 닳게 합니다. / 문이 덜 닫힌다면 손잡이를 탓하기 전에 경첩과 문틀부터 보세요.
- 석 달에 한 번 손잡이 나사를 가볍게 조이기
- 손잡이에 가방이나 봉지를 걸어 두지 않기
- 흔들림이 느껴지면 그날 바로 점검하기
- 열쇠나 카드는 따로 한 벌 더 보관하기
작은 점검이 문 앞에서 막히는 일을 크게 줄여 줍니다.

# 신장동 말고 하남 어디든 갑니다
신장동 바로 옆 덕풍동, 창우동, 천현동은 물론 미사, 위례, 감일 신도시까지 출동합니다. / 하남시 안이면 동네와 시간에 상관없이 24시간 연락을 받습니다.
하남에서 다니는 동네는 [하남시 출장열쇠](hanam.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
