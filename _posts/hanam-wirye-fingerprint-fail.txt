# 위례동 지문 도어락이 갑자기 말을 안 들을 때
위례동은 새 아파트가 많아 지문 인식 도어락을 처음부터 쓰는 집이 흔합니다. / 잘 되던 지문이 어느 날부터 자꾸 실패하면 고장이 났다고 생각하기 쉽습니다.
하지만 지문 인식 실패는 손 상태나 센서에 묻은 오염, 건전지 부족 같은 흔한 원인에서 시작하는 일이 많습니다. / 원인을 하나씩 짚어 보면 그 자리에서 해결되는 경우도 적지 않습니다.
이 글은 위례동에서 지문 인식이 실패할 때 확인할 것과 [하남 출장열쇠](hanam.html)가 진행하는 순서를 정리했습니다.
@ 위례동 지문 도어락 인식 실패 출장열쇠

# 지문 인식은 어떻게 이뤄질까요
도어락 센서에 손가락을 대면 센서가 지문의 모양을 읽어 등록된 정보와 비교합니다. / 읽는 방식은 제품마다 다르지만 센서 표면이 깨끗하고 손가락이 제대로 닿아야 한다는 점은 같습니다.
센서 표면에 먼지나 기름기가 쌓이면 읽는 정확도가 떨어집니다. / 센서가 긁혔거나 습기가 들어가면 더 심해질 수 있습니다.
그래서 원인은 크게 손, 센서, 도어락 내부 상태로 나눠 볼 수 있습니다.

# 손 상태 때문에 실패하는 경우
손의 상태는 지문 인식에 생각보다 큰 영향을 줍니다.
- 손이 젖었거나 땀이 많은 경우
- 손이 심하게 건조하거나 갈라진 경우
- 로션이나 핸드크림이 묻어 미끄러운 경우
- 겨울에 손이 차갑고 굳어 있는 경우
- 손가락이 다치거나 굳은살이 생겨 지문이 달라진 경우
손을 가볍게 닦거나 따뜻하게 한 뒤 다시 대 보세요. / 손가락을 센서에 평평하게 대고 잠깐 기다리는 것이 중요합니다.

# 센서 쪽에서 확인할 것
센서 표면을 보고 먼지나 손때가 묻어 있는지 확인하세요. / 마른 부드러운 천으로 가볍게 닦아 주세요.
물이나 알코올을 흠뻑 묻혀 닦는 것은 피하는 편이 좋습니다. / 습기가 센서 안으로 스며들면 오히려 문제가 커집니다.
센서 표면에 흠집이 있거나 일부가 깨져 있다면 점검이 필요합니다.
@ 위례동 지문 센서 오염 점검

# 건전지가 약해도 지문이 실패합니다
지문 인식은 전력을 꽤 씁니다. / 건전지가 약해지면 번호는 되는데 지문만 안 되는 증상이 먼저 나타나는 경우가 있습니다.
경고음이 울리거나 번호판이 평소보다 어둡다면 건전지부터 새것으로 바꿔 보세요. / 한 개만 바꾸지 말고 전부 같이 바꾸는 편이 안전합니다.
건전지를 바꾼 뒤에는 시간을 조금 두고 다시 시도하세요.

# 번호나 카드로 먼저 들어가세요
지문이 안 읽힐 때 포기하지 말고 번호나 카드로 먼저 들어가세요. / 대부분의 지문 도어락은 번호와 카드를 같이 지원합니다.
번호가 기억나지 않거나 카드가 없는 경우에는 문 앞에서 막힐 수 있습니다. / 이럴 때 연락 주시면 덜 상하는 방법으로 열어 드립니다.
문이 열린 뒤에 센서와 등록 상태를 천천히 점검하면 됩니다.

# 지문을 다시 등록하는 것이 필요할 수도 있습니다
등록할 때 손가락 위치가 제대로 읽히지 않았다면 인식률이 낮을 수 있습니다. / 이런 경우에는 지문을 지우고 다시 등록하는 것이 효과적입니다.
등록할 때는 손가락 중심, 가장자리, 약간 돌린 각도까지 여러 번 읽혀 주면 인식률이 올라갑니다. / 같은 손가락을 두세 번 나누어 등록하는 방법도 있습니다.
아이와 어르신은 지문이 변하는 경우가 있으니 가끔 인식이 잘 되는지 확인하세요.

# 위례동에서 위치는 이렇게 알려주세요
신도시 단지는 출입이 까다로울 수 있어서 위치를 구체적으로 알려주셔야 합니다.
- 단지 이름과 동, 호수
- 방문차량 출입 방법과 연락처
- 지하주차장 출입 가능 여부
- 지문이 안 되는 도어락의 사진과 증상
문 앞에 계신다면 번호판이 켜지는지, 소리가 나는지도 알려주세요.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우시겠지만 같은 단지 이웃을 지키기 위한 절차입니다. / 확인이 어려우면 작업을 시작할 수 없습니다.
앱에 가입된 계정이 있다면 이름과 주소를 보여 주시는 방법도 있습니다.

# 비용은 열기 전에 말씀드립니다
도어락 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 하남 위례동 출장열쇠 지문 도어락 점검

# 센서를 고쳐 쓸 수 있는지 먼저 봅니다
센서가 문제라고 해서 바로 도어락을 통째로 바꾸지는 않습니다. / 센서만 닦거나 연결을 점검하는 것으로 해결되는 경우가 있습니다.
먼저 [도어락 수리](doorlock-repair.html)로 점검하고 부품 교체가 가능한지 확인합니다. / 너무 오래돼서 부품을 구하기 어렵다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
고쳐 쓰는 방법과 새로 바꾸는 방법의 차이를 설명드리고 선택은 직접 하시면 됩니다.

# 지문 도어락을 오래 쓰는 습관
조금만 신경 쓰면 인식 실패를 많이 줄일 수 있습니다.
- 센서는 마른 천으로 가끔 닦기
- 손에 물기나 크림이 있을 때는 닦고 대기
- 건전지는 해가 바뀔 때 한꺼번에 교체
- 번호와 카드 같은 비상 수단 항상 준비
- 어린아이는 성장하면서 지문이 변하니 가끔 다시 등록
이런 습관만으로도 문 앞에서 당황할 일이 확 줄어듭니다.

# 위례동 말고 하남 어디든 갑니다
미사동, 감일동, 풍산동, 덕풍동까지 하남 안이면 어디든 출동합니다. / 24시간 연락 받습니다.
하남에서 다니는 지역은 [하남시 출장열쇠](hanam.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
