# 위례동 오피스텔 복도에 혼자 서 있다면
위례동은 하남 쪽 위례 신도시 아파트가 중심인 동네로, 출입 카드를 쓰는 오피스텔과 원룸형 세대도 생활권 안에 함께 있습니다. / 혼자 살거나 집을 작업 공간으로 같이 쓰는 분이 많아서, 문이 잠겼을 때 안에서 열어 줄 사람이 없는 경우가 대부분입니다.
낮에는 관리실에 도움을 청할 수 있지만, 밤늦게나 주말에는 관리실 불이 꺼져 있기도 합니다. / 복도에 혼자 서서 휴대폰 배터리를 확인하는 순간이 가장 막막합니다.
이 글은 위례동 오피스텔과 원룸에서 관리실이 닫힌 시간에 세대 문이 잠겼을 때 차분히 움직이는 순서를 적었습니다. / 바로 출동이 필요하면 [하남 출장열쇠](hanam.html)로 연락 주세요.
@ 위례동 오피스텔 복도 세대 도어락 잠김

# 휴대폰 배터리부터 아끼세요
문 앞에서 이것저것 검색하다 보면 휴대폰 배터리가 금방 줄어듭니다. / 연락이 끊기면 그다음이 더 어려워지니 화면 밝기를 낮추고 꼭 필요한 연락만 하세요.
출장을 부를 생각이라면 먼저 전화 한 통으로 상황을 알리고, 그다음 도어락 사진을 보내는 순서가 좋습니다. / 배터리가 얼마 안 남았다면 그 사실도 꼭 말씀해 주세요.
휴대폰까지 안에 두고 나왔다면 같은 층 이웃이나 1층 상가에 잠깐 전화를 빌려 보세요. / 번호 하나만 기억하면 됩니다.

# 건물 출입이 되는 상태인지 확인
위례동 오피스텔은 건물 입구나 엘리베이터에 출입 카드가 필요한 곳이 있습니다. / 지금 세대 문 앞까지는 와 있는지, 아니면 건물 입구에서 막혔는지 먼저 정해 주세요.
세대 문 앞이라면 저희가 도착했을 때 건물에 들어올 방법이 있어야 합니다. / 공동 출입문 번호를 알고 계시거나, 도착할 때 내려와 열어 주실 수 있는지 미리 말씀해 주세요.
건물 입구부터 막혔다면 관리실 비상 연락처가 출입문 옆에 붙어 있는지 확인해 보세요. / 공동 출입 장치는 건물 관리 쪽 소관이라 저희가 임의로 손대지 않습니다.

# 세대 문 앞에서 볼 세 가지
문 앞에서는 아래 세 가지를 차례로 확인해 보세요. / 원인을 좁히면 해결 방법도 빨리 정해집니다.
- 번호판을 손으로 덮었을 때 불이 들어오는지
- 번호를 누르면 틀렸다는 소리가 나는지, 아무 반응이 없는지
- 카드키를 대면 반응이 있는지
불이 아예 안 들어오면 건전지 문제, 틀렸다는 소리가 나면 번호 문제, 카드만 안 되면 카드 등록 문제일 가능성이 큽니다. / 이 내용을 그대로 전화로 말씀해 주시면 됩니다.
@ 위례동 원룸 도어락 번호판 상태 확인

# 번호판이 꺼졌다면 비상 전원
오피스텔 세대 도어락도 대부분 바깥쪽에 9V 건전지 비상 단자가 있습니다. / 단자 위치는 번호판 아래나 옆면, 작은 덮개 안쪽일 수 있으니 손으로 더듬어 찾아보세요.
건물 1층 편의점이 열려 있다면 9V 건전지를 구해 대 보세요. / 건전지를 대는 동안 평소 번호를 누르면 열리는 경우가 많습니다.
문이 열리면 안쪽 건전지를 모두 새것으로 바꿔 주세요. / 비상 전원은 잠깐 여는 용도일 뿐입니다.

# 번호가 바뀌었다면
입주한 지 얼마 안 됐다면 관리 쪽이나 이전 거주자 정리 과정에서 번호가 초기화됐을 수 있습니다. / 계약하면서 받은 번호가 맞는지 문자나 계약 서류를 다시 확인해 보세요.
집을 함께 쓰는 사람이 있다면 그분께 번호를 바꿨는지 물어보세요. / 연락이 닿지 않으면 출장으로 문을 연 뒤 새 번호를 등록하시면 됩니다.
번호를 여러 번 틀리면 도어락이 한동안 입력을 막으니, 확실하지 않은 번호를 계속 눌러 보지는 마세요. / 입력이 막힌 상태라면 전화 주실 때 그 사실도 함께 알려 주세요.
카드키는 되는데 번호만 안 되는 경우라면 카드로 들어가 안쪽에서 번호를 다시 정하시면 끝납니다.

# 작업 공간으로 쓰는 세대라면
오피스텔을 사무실이나 작업실로 쓰는 경우, 안에 장비나 서류가 있어서 더 급해지기 마련입니다. / 이런 경우에도 문을 여는 절차는 같고, 사용하시는 분인지 확인한 뒤 진행합니다.
사업자 명의로 계약했다면 사업자 등록증이나 임대 계약서 사진, 명함처럼 확인할 수 있는 자료를 준비해 주세요. / 대표자가 아닌 직원이라면 대표자와 통화 연결이 도움이 됩니다.

# 혼자 사는 분이 미리 해 둘 것
혼자 사는 집은 문이 잠겼을 때 대신 열어 줄 사람이 없습니다. / 아래 몇 가지를 해 두면 같은 일이 생겨도 덜 당황합니다.
- 관리실 비상 연락처를 휴대폰과 지갑에 함께 적어 두기
- 카드키 하나는 믿을 만한 가족이나 친구에게 맡기기
- 번호는 휴대폰 말고도 기억할 수 있는 방식으로 정하기
- 건전지는 입주한 날 한 번, 이후 해마다 교체
@ 위례동 혼자 사는 집 도어락 대비

# 출장 요청 때 말씀해 주실 것
신도시는 길이 반듯해도 건물 입구가 여러 방향으로 나 있는 경우가 있어서, 어느 쪽 입구로 들어가야 하는지 알려 주시면 헤매지 않습니다. / 아래를 짧게 말씀해 주세요.
- 건물 이름과 층, 호수
- 건물 입구와 엘리베이터에 출입 카드가 필요한지
- 번호판 상태와 도어락 모양
- 휴대폰 배터리가 얼마나 남았는지
- 주차할 곳이 있는지
늦은 시간이라 건물 앞에서 기다리기 불편하시면 가까운 편의점처럼 밝은 곳에 계시다가 도착 연락을 받으셔도 됩니다.

# 문을 열기 전 확인
작업 전에 그 세대에 사시는 분이나 사용하시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 택배 송장이나 우편물, 임대 계약서 사진 가운데 하나면 됩니다.
신분증이 안에 있으면 문을 연 직후 보여 주셔도 괜찮습니다. / 관리실이 열려 있는 시간이라면 관리실 확인도 가능합니다.

# 비용과 진행 순서
도착해서 도어락 상태를 본 뒤 금액을 먼저 말씀드리고, 괜찮다고 하시면 시작합니다. / 들어 보시고 원치 않으시면 그대로 돌아갑니다.
열지 못하면 비용은 받지 않습니다. / 진행 방법은 [이용안내](guide.html)에, 문 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 들어간 뒤 정리
문이 열리면 건전지 교체, 번호 재등록, 카드 정리를 함께 해 두시길 권합니다. / 이전 거주자가 쓰던 카드가 남아 있을 수 있으니 전체를 지우고 내 카드만 다시 등록하세요.
도어락이 자주 말썽이면 [도어락 수리](doorlock-repair.html)로 점검하고, 고치기 어려우면 집주인이나 관리 쪽과 상의해 [도어락 교체](doorlock-replace.html)를 이야기합니다.

# 위례동 말고 하남 어디든
위례동과 가까운 감일동은 물론 미사동, 풍산동, 덕풍동, 신장동, 창우동, 천현동까지 하남 전 지역에 출동합니다. / 하남 안내는 [하남 출장열쇠](hanam.html)에, 다른 지역은 [출장 지역](area.html)에 있습니다.
