# 명절에 내려가 보니 도어락이 낯설었다면
동탄 반송동에 부모님이 사시거나 자주 들르신다면 현관 도어락을 한 번 눈여겨보시길 권합니다. / 동탄역에서 가까운 생활권이라 자녀들이 오가기 편하지만 정작 도어락 상태는 챙기기 어렵습니다.
부모님은 불편해도 말씀을 안 하시는 경우가 많습니다. / 이 글은 연세 드신 분이 쓰기 편하게 도어락을 점검하고 설정하는 방법을 적었습니다.
@ 반송동 부모님 집 도어락 점검 출장열쇠

# 부모님이 불편해하시는 지점
어르신들이 도어락 앞에서 힘들어하는 데는 이유가 있습니다. / 젊은 사람에게는 사소한 것이 하루에도 몇 번씩 쌓입니다.
특히 어두운 저녁에 번호판이 잘 안 보이면 열쇠를 찾으려다 가방을 뒤지게 됩니다. / 번호판 조명이 약하면 그것만으로도 큰 불편이 됩니다.
- 번호판 숫자가 작아 잘 안 보인다
- 버튼을 약하게 눌러 입력이 안 된다
- 경고음이 나도 무슨 뜻인지 모른다
- 번호를 자주 바꾸라는 말에 오히려 잊어버린다
부모님께 직접 한 번 열어 보시게 하고 옆에서 지켜보세요. / 말로 묻는 것보다 실제 모습이 훨씬 많은 걸 알려줍니다.

# 비밀번호는 기억하기 쉽되 추측은 어렵게
어르신들은 생일이나 전화번호 뒷자리를 많이 쓰십니다. / 쉽지만 남이 알아맞히기도 쉬운 번호라서 걱정이 됩니다.
기억하기 쉬운 번호 중에서도 집 주소나 가족 생일 순서가 아닌 조합을 같이 정해 보세요. / 종이에 적어 현관 근처에 붙이는 건 피하셔야 합니다.
번호를 자주 바꾸게 하기보다 한 번 정하면 오래 쓰고, 가족 중 한 명이 기억해 두는 쪽이 낫습니다. / 잊었을 때 자녀가 알려줄 수 있어야 합니다.
번호를 바꾸는 날에는 부모님 앞에서 직접 몇 번 눌러 보며 손에 익히게 해 드리세요. / 한 번 알려드린 걸로 끝내면 다음 주에 다시 막히는 일이 많습니다.

# 배터리 경고음이 나면 자녀에게 알려지게
부모님 집 도어락의 가장 흔한 문제는 건전지 방전입니다. / 경고음이 몇 번 나도 어르신은 그냥 지나치는 경우가 많습니다.
- 해가 바뀔 때 자녀가 방문해 건전지를 한꺼번에 교체
- 교체한 날짜를 배터리 칸 뚜껑에 적어 두기
- 경고음이 들리면 바로 전화하라고 미리 말씀드리기
- 9V 비상 건전지를 현관 서랍에 넣어 두기
방문하기 어려우면 근처에서 사람을 보낼 수도 있습니다. / 이때 부모님이 낯선 사람을 경계하시니 미리 연락을 드려 주세요.
방문 전에 누가 언제쯤 가는지 부모님께 알려 두면 문을 열어 주시기 편합니다. / 24시출장열쇠가 가는 경우에도 전화를 먼저 드리고 신분을 확인한 뒤 들어갑니다.

# 혼자 계실 때 문이 안 열리면
부모님 혼자 계실 때 도어락이 먹통이 되면 크게 놀라십니다. / 밖에 계시든 안에 계시든 침착하게 전화할 수 있도록 순서를 알려 두세요.
- 번호판이 켜지는지만 보고 억지로 문을 당기지 않기
- 연락할 가족 번호와 이 번호를 눈에 띄는 곳에 적어 두기
- 문밖에서 기다릴 때는 계단이나 복도에서 앉아 있기
연세가 있으신 분이 추운 복도에서 오래 기다리면 건강에 좋지 않습니다. / 겨울에는 특히 관리사무소나 이웃에게 먼저 알리라고 말씀해 두세요.
옆집과 가볍게 인사를 나누며 비상시 서로 연락할 수 있는 사이면 든든합니다.
@ 동탄 반송동 어르신 도어락 설정

# 지문이나 카드가 꼭 좋은 건 아닙니다
편리해 보여서 지문 인식 도어락을 권하는 경우가 많습니다. / 그런데 손끝이 건조하거나 주름이 많은 어르신은 인식이 잘 안 될 수 있습니다.
카드나 태그는 잃어버리기 쉽고 챙기는 습관이 없으면 불편합니다. / 오히려 큰 버튼의 번호 입력이 가장 편한 분도 많습니다.
부모님이 평소 쓰던 방식과 손 상태를 보고 정하는 게 좋습니다. / 고르는 법은 [도어락 설치](doorlock-install.html) 페이지에도 적어 두었습니다.

# 안에서 잠그는 장치도 쉬워야 합니다
도어락만이 아니라 보조키와 걸쇠도 어르신 손에 맞는지 보세요. / 너무 뻑뻑하거나 작은 손잡이는 돌리기 힘들어 안 잠그고 지내게 됩니다.
반대로 보조키를 잠가 놓고 잊으신 채 외출하시면 가족이 들어갈 수 없습니다. / 이런 일이 생기면 먼저 전화 주세요.
평소 나가고 들어올 때 순서를 가족이 같이 정해 두면 실수가 줄어듭니다.
나갈 때 문을 닫고 한 번 당겨 보는 습관만 들여도 덜 닫힌 문 때문에 겪는 일이 줄어듭니다. / 이 습관은 어르신뿐 아니라 가족 모두에게 도움이 됩니다.

# 응급 상황에서 문이 걸림돌이 되지 않게
부모님이 집 안에서 쓰러지셨는데 문이 안에서 잠겨 있으면 119도 들어가기 어렵습니다. / 이런 경우에는 지체하지 말고 119에 먼저 연락하시고 상황을 알려 주세요.
문 개방이 필요하면 신분 확인 후 최대한 빠르게 진행합니다. / 가족 한 명이 비밀번호를 알아 두는 것이 가장 확실한 대비입니다.

# 출장 요청할 때 알려주세요
반송동은 단지와 동이 많으니 위치를 정확히 알려주시면 도착이 빨라집니다. / 아래 정보를 알려주세요.
- 아파트 단지 이름과 동, 호수
- 도어락 모양과 번호판 상태
- 집 안에 어르신이 계신지, 몸 상태는 어떠신지
- 연락 가능한 가족 번호
어르신이 안에 계시다면 문 너머로 계속 말을 걸어 안심시켜 주세요. / 이 경우는 꼭 먼저 말씀해 주시면 우선으로 챙기겠습니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
자녀가 요청하셨다면 부모님 신분이나 가족관계를 확인할 수 있는 방법을 알려드립니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부모님 집이라 고쳐 쓰는 편이 나을지 바꾸는 편이 나을지 따로 설명드립니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 반송동 24시 출장열쇠 도어락 점검

# 고치는 게 먼저, 바꾸는 건 그다음
오래 쓴 도어락이라도 먼저 고쳐 쓸 수 있는지 봅니다. / 번호판 반응이 둔하거나 모터 소리가 이상할 때는 [도어락 수리](doorlock-repair.html)로 해결되는 경우가 많습니다.
수리가 어려울 정도로 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 어르신 손에 맞는 제품인지 같이 보고 정합니다.

# 반송동 말고도 화성 어디든 갑니다
동탄 다른 동네와 병점, 봉담, 향남, 남양 등 화성 안이면 24시간 출동합니다. / 지역별 안내는 [화성시 출장열쇠](hwaseong.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서, 문 여는 방법은 [현관문 개문](door-open.html)에서 보실 수 있습니다.
