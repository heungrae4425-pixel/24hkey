# 어제까지 되던 지문이 오늘은 안 됩니다
동탄 반송동에서 동탄역을 오가며 지문으로 문을 열던 분이 어느 날 갑자기 인식이 안 되는 경험을 합니다. / 비밀번호가 기억나지 않는 순간이 아니라 손가락이 말을 안 듣는 순간이라 당황스럽습니다.
이 글은 지문 인식이 실패하는 이유를 손, 센서, 등록 상태로 나눠 점검하는 순서를 적었습니다. / 풀리지 않을 때는 [화성 출장열쇠](hwaseong.html)로 연락하는 방법도 이어서 적었습니다.
@ 반송동 도어락 지문 인식 실패


지문 센서는 손가락의 굴곡 모양을 읽어 미리 등록한 모양과 비교합니다. / 비교가 맞으면 문이 열리고 맞지 않으면 실패음이 납니다.
그래서 손가락의 상태나 센서 표면, 대는 각도가 조금만 달라도 결과가 달라질 수 있습니다. / 실패는 고장이 아니라 비교 조건이 달라진 경우가 많습니다.

# 가장 먼저 의심할 것, 손가락 상태
손이 너무 건조하거나 물기가 있으면 인식이 잘 안 됩니다. / 겨울철에 갑자기 인식이 안 되는 분이 많은 이유입니다.
- 손이 젖었을 때는 마른 천에 닦고 시도
- 손이 너무 건조할 때는 손가락을 살짝 비벼서 온기를 준 뒤 시도
- 로션이나 핸드크림이 묻어 있으면 닦아내고 시도
- 상처나 굳은살로 지문이 닳았다면 다른 손가락으로 시도
손 상태가 원인이면 이것만으로 바로 열리는 경우가 많습니다.

# 센서 표면을 닦아 보세요
센서 유리에 기름이나 먼지가 쌓이면 읽는 힘이 약해집니다. / 마른 부드러운 천이나 안경닦이로 가볍게 닦아 주세요.
물이나 알코올을 직접 뿌리는 것은 피하세요. / 틈으로 들어가면 오작동이 생길 수 있습니다.
센서 표면에 긁힘이 많다면 읽는 능력이 떨어진 상태일 수 있습니다. / 이런 경우는 센서 부분 점검이 필요합니다.
센서를 닦을 때는 한 방향으로 가볍게 훑듯이 닦고, 손톱이나 날카로운 도구로 긁지 마세요. 표면이 긁히면 인식이 더 어려워집니다.

# 손가락을 대는 방법을 바꿔 보세요
센서에 손가락 끝만 살짝 대면 읽는 면적이 부족합니다. / 지문 중심이 센서 한가운데 오도록 평평하게 대고, 짧게 누르지 말고 잠깐 머물러 주세요.
너무 세게 누르면 지문이 눌려 모양이 달라지고, 너무 가볍게 대면 읽히지 않습니다. / 적당한 힘으로 일정하게 대는 습관이 중요합니다.
같은 손가락을 매번 다른 각도로 대면 인식률이 흔들립니다. / 등록할 때와 비슷한 각도로 맞춰 보세요.

# 등록은 한 손가락을 여러 각도로 해 두면 좋습니다
많은 도어락은 한 손가락을 여러 번 나눠 등록하는 방식입니다. / 한 번에 한 각도만 등록하면 평소 다른 각도로 댔을 때 실패할 수 있습니다.
같은 손가락을 중앙, 약간 왼쪽, 약간 오른쪽으로 나눠 등록하면 인식률이 올라가는 경우가 많습니다. / 제품마다 방식이 다르니 설명서를 확인해 주세요.
엄지와 검지처럼 자주 쓰는 손가락 두세 개를 등록해 두면 하나가 안 될 때 다른 걸로 열 수 있습니다.

# 아이와 어르신은 인식이 더 어렵습니다
아이는 지문이 작고 성장하며 모양이 바뀌어 인식이 안 되는 경우가 있습니다. / 어르신은 피부가 건조하거나 지문이 얕아져 읽기 어려운 경우가 있습니다.
이런 가족이 있다면 지문만 믿지 말고 카드나 번호를 함께 쓰는 방식을 권합니다. / 번호 입력은 눈에 잘 보이는 큰 숫자판이 있는 제품이 편합니다.
@ 반송동 가족 지문 등록 확인


지문 센서는 전기를 비교적 많이 씁니다. / 배터리가 약해지면 번호판은 켜져도 지문 읽기가 먼저 불안정해질 수 있습니다.
최근 인식 속도가 느려졌다면 배터리를 새것으로 갈아 보세요. / 일부만 바꾸지 말고 전부 한꺼번에 바꾸는 것이 좋습니다.
경고음이 나는데 방치했다면 지금이 교체할 때입니다.
동탄역에서 먼 길을 걸어 퇴근한 날 이런 일이 생기면 더 지치니, 인식 속도가 느려졌다고 느끼는 즈음에 미리 바꿔 두세요.

# 센서에 문제가 생겼다는 신호
손과 배터리, 등록 방법을 모두 점검해도 안 된다면 센서 자체에 문제가 있을 수 있습니다. / 아래 같은 증상이 보이면 점검이 필요합니다.
- 어떤 손가락을 대도 반응 소리조차 없다
- 센서 표면에 눈에 띄는 균열이나 변색
- 비가 온 뒤 갑자기 인식이 사라졌다
- 센서 주변 틈으로 물기가 들어간 흔적
이럴 때는 계속 시도하지 말고 번호나 카드로 문을 열고 연락 주세요.


지문에만 의존하다 번호를 잊어버리는 일이 의외로 흔합니다. / 평소에 번호를 눌러 보는 습관을 들이면 대비가 됩니다.
문 앞에서 지문도 번호도 안 되는 상황이라면 비상 단자에 9V 건전지를 대 보시고, 그래도 안 되면 연락 주세요. / 억지로 열려고 하면 입력이 한동안 막힐 수 있습니다.
전화로는 증상과 도어락 모양을 같이 알려 주세요.
지문이 안 될 때 어떤 손가락으로 시도했는지, 몇 번 시도했는지도 말씀해 주시면 원인을 좁히기 쉽습니다.

# 전화하실 때 알려주세요
- 도어락 모양과 지문 센서 위치
- 지문을 대면 어떤 소리가 나는지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 최근에 배터리를 바꿨는지
- 안에 아이나 반려동물이 있는지
사진을 보내 주시면 맞는 장비를 챙기기 좋습니다.

# 오시면 신분 확인을 먼저 합니다
문을 여는 일이라 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소나 경비실에 거주 확인을 부탁해 주세요. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.

# 비용은 열기 전에 말씀드립니다
문과 도어락 상태를 보고 비용을 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 한다면 바꾸기 전에 다시 여쭙습니다. 진행 방식은 [이용안내](guide.html)에서 볼 수 있습니다.

# 열고 난 뒤 지문 재등록까지
문이 열리면 센서 상태를 같이 확인합니다. / 필요하면 기존 지문을 지우고 여러 각도로 다시 등록하는 것까지 도와드립니다.
센서만 문제라면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
지문 방식이 맞지 않는 가족이 있다면 카드나 번호 중심으로 쓰는 방법도 같이 상담합니다.
@ 반송동 지문 재등록 후 문 열림 확인

# 지문 도어락 오래 쓰는 관리법
- 센서 표면은 마른 천으로 가끔 닦기
- 배터리는 해가 바뀔 때 한꺼번에 교체
- 번호나 카드를 함께 등록해 대비하기
- 겨울철에는 손을 비벼 온기를 준 뒤 대기
- 센서 주변에 물기가 남지 않게 관리
지문 방식에만 기대지 않고 두 가지 이상의 열기 방법을 갖춰 두는 것이 문 앞에서 막히지 않는 방법입니다.

# 반송동 말고 화성 다른 동네도 갑니다
반송동 가까이의 능동, 청계동, 영천동, 목동은 물론 병점, 봉담, 향남, 남양까지 화성 안이면 다닙니다. / 24시간 전화를 받습니다.
다니는 곳은 [화성시 출장열쇠](hwaseong.html)에, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
