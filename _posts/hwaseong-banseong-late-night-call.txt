# 시계가 두 시를 가리키는데 문이 안 열린다
막차에서 내려 집까지 걸어왔는데 번호판이 반응하지 않습니다. / 동탄역에서 반송동 쪽으로 들어오는 밤길은 조용하고, 그래서 문 앞의 막막함이 더 크게 느껴집니다.
이런 시간에는 어디에 전화해야 할지, 무엇부터 말해야 할지 생각이 잘 나지 않습니다. / 이 글은 한밤이나 새벽에 연락할 때 어떤 순서로 말하면 되는지를 통화 흐름 그대로 적었습니다.
[화성 출장열쇠](hwaseong.html)에 전화하기 전에 한 번 훑어보시면 좋습니다.
@ 반송동 한밤의 현관문 앞

# 전화를 걸기 전 삼십 초 준비
통화가 길어지면 휴대폰 배터리와 체력이 함께 닳습니다. / 걸기 전에 삼십 초만 써서 상황을 정리해 두세요.
- 번호판에서 소리가 나는지, 불이 들어오는지 확인하기
- 휴대폰 배터리가 얼마나 남았는지 보기
- 지금 서 있는 곳의 가까운 큰길이나 편의점 위치 떠올리기
- 문 사진을 한 장 찍어 두기
이 네 가지가 준비되면 통화 시간이 짧아지고 출동도 빨라집니다.

# 첫 마디는 이렇게 시작하세요
전화가 연결되면 인사 뒤에 바로 상황을 말씀해 주세요. / 예를 들어 이렇게 시작하면 충분합니다.
"반송동인데 현관문이 안 열려요. 번호판이 꺼져 있습니다."
긴 사정은 나중에 말씀하셔도 됩니다. / 숨이 차거나 말이 엉켜도 괜찮으니 천천히 말씀해 주세요. / 처음에는 장소, 문제, 지금 상태 세 가지만 말하면 됩니다.
잘 모르는 부분은 모른다고 하셔도 괜찮습니다. / 필요한 건 저희가 차근차근 여쭙겠습니다.

# 위치는 건물 이름보다 길과 역으로
한밤에는 건물 이름을 정확히 모르는 경우가 많습니다. / 그럴 때는 가까운 큰길, 동탄역 방향, 편의점이나 공원 같은 눈에 띄는 곳으로 말씀해 주세요.
휴대폰 지도 앱의 현재 위치를 문자로 보내 주시면 가장 정확합니다. / 문자는 통화 중에도 보낼 수 있습니다.
도착할 때 어디서 만날지 정해 두면 헛걸음이 줄어듭니다.
@ 휴대폰 지도로 위치를 보내는 모습

# 도어락 상태를 설명하는 방법
도어락 종류를 몰라도 보이는 대로 말하면 됩니다.
- 번호판이 아예 꺼졌다 / 불은 켜지는데 삑 소리만 난다
- 번호는 맞게 눌렀는데 모터 소리만 나고 안 열린다
- 문 안쪽 보조키가 잠긴 것 같다
- 손잡이가 헛돌거나 움직이지 않는다
사진이 있으면 문자로 보내 주세요. / 번호판 앞쪽과 손잡이 쪽이 나오면 맞는 장비를 고르는 데 큰 도움이 됩니다.

# 새벽에는 소리와 이웃을 조금 더 생각합니다
깊은 밤에는 작은 소리도 복도에 크게 울립니다. / 번호를 반복해서 누르거나 문을 두드리는 것은 이웃의 잠을 깨울 수 있습니다.
도착한 뒤에도 가능한 한 소리가 적은 방법을 먼저 씁니다. / 엘리베이터 소리와 대화 소리도 낮춰 주시면 도움이 됩니다.
이웃이 놀라 나왔다면 사정을 간단히 설명해 주시면 됩니다. / 대부분은 사정을 알면 이해해 주십니다.
술을 마셨거나 많이 피곤한 상태라면 번호를 잘못 기억하는 일도 흔합니다. / 그럴 때는 무리해서 맞추려 하지 말고 잠시 쉬었다가 다시 눌러 보세요.

# 기다리는 동안 하지 말아야 할 일
기다리는 시간이 길게 느껴져도 문을 건드리지 마세요. / 한밤에는 특히 마음이 급해져 평소에 안 하던 행동을 하게 됩니다.
- 손잡이를 반복해서 세게 당기기
- 번호를 계속 틀려서 입력이 막히게 하기
- 카드나 철사를 문틈에 넣기
- 창문이나 베란다로 넘어가기
이런 행동은 도어락이나 문틀을 상하게 하거나 다칠 위험이 있습니다. / 기다리면서 따뜻한 곳을 찾아 앉아 계시는 편이 낫습니다.

# 추운 밤이라면 기다릴 자리도 챙기세요
한겨울 새벽에 밖에서 기다리면 몸이 빠르게 식습니다. / 건물 로비나 가까운 편의점처럼 따뜻한 곳에서 기다리다가 도착 시간에 맞춰 문 앞으로 오셔도 됩니다.
도착 예상 시간을 전화로 확인하고 그에 맞춰 움직이세요. / 길이 막히거나 날씨가 나쁘면 시간이 달라질 수 있어 통화 중에 연락처를 확인해 둡니다. / 어린 아이나 어르신이 같이 있다면 전화할 때 먼저 말씀해 주세요.
@ 건물 로비에서 출장 기사를 기다리는 모습

# 도착하면 신분 확인이 먼저입니다
늦은 시간이라도 사시는 분인지 확인하는 절차는 똑같습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 경비실에 세대 확인을 부탁하는 방법도 있습니다. / 밤에는 확인할 곳이 적으니 전화하면서 미리 어떻게 할지 같이 정해 두는 게 좋습니다.
확인이 어렵다면 작업을 할 수 없는 점은 양해 부탁드립니다. / 이웃과 집을 지키는 최소한의 절차입니다.

# 비용 이야기도 밤이라고 달라지지 않습니다
도착해서 문 상태를 보고 비용을 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 슬그머니 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

문을 여는 방법은 덜 상하는 것부터 차례로 시도합니다. / 소리가 작고 도어락이 그대로 보존되는 방식이 우선입니다.
작업 중에 중간 상황을 말씀드리고, 변경이 필요하면 먼저 여쭙니다. / 개문 방식은 [현관문 개문](door-open.html) 페이지에서 자세히 보실 수 있습니다.

# 열린 뒤 해두면 좋은 일
문이 열리면 도어락이 정상으로 돌아왔는지 같이 확인합니다. / 배터리가 원인이면 새것으로 바꾸고, 번호가 문제였다면 다시 등록합니다.
다음 날 아침에 한 번 더 번호를 눌러 보시면 좋습니다. / 잠그고 열고를 두세 번 해 보면 걸쇠가 매끄럽게 움직이는지 알 수 있습니다. / 밤새 이상이 있었다면 바로 알 수 있습니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 증상이 반복되면 [도어락 수리](doorlock-repair.html)로 점검 범위를 먼저 확인하세요.

# 밤에 다시 막히지 않게 미리 해둘 것
- 비상용 9V 건전지를 가방이나 차에 하나 두기
- 가족 중 한 명에게 집 열쇠나 카드키 맡겨 두기
- 번호판이 느려지면 그날 바로 배터리 교체하기
- 출장열쇠 전화번호를 휴대폰에 저장해 두기
- 늦게 들어오는 가족에게 비상 단자 위치 알려주기
번호를 저장해 두면 한밤에도 바로 연락할 수 있습니다. / 전화번호는 글 마지막에 있습니다.

# 반송동 밖에서도 화성 어디든
야간 출동이라고 해서 확인 절차나 안내가 줄어들지 않습니다. / 낮과 똑같이 신분 확인, 사전 비용 안내, 못 열면 무료 원칙을 지킵니다.
반송동과 가까운 능동, 청계동, 영천동, 오산동, 목동, 산척동, 장지동도 다닙니다. / 병점동, 진안동, 봉담읍, 향남읍, 남양읍까지 화성 전체가 출동 범위입니다.
다니는 동네는 [출장 지역](area.html)에서 확인하실 수 있습니다.
