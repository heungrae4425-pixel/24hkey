# 반송동에서 헤어진 뒤 문이 마음에 걸릴 때
동탄역 생활권인 반송동에서도 연인이나 동거인과 헤어진 뒤 문 걱정을 하시는 분들이 있습니다. / 상대가 현관 번호나 열쇠를 알고 있다는 사실이 마음에 걸리는 것은 자연스러운 일입니다.
이 글은 누구를 의심하자는 글이 아닙니다. / 내 집 문을 내가 다시 관리하는 상태로 돌려놓는 현실적인 방법을 정리했습니다.
[화성 출장열쇠](hwaseong.html)를 부르기 전에 직접 해볼 수 있는 것부터 순서대로 보시면 됩니다.
@ 반송동 현관 도어락 번호 변경 점검

# 불안할 때 가장 먼저 할 일은 번호 바꾸기
번호키라면 현관 번호를 바꾸는 것이 가장 빠르고 확실한 첫걸음입니다. / 설명서에 나온 방법대로 안쪽 버튼으로 등록 모드에 들어가 새 번호를 넣습니다.
이때 예전에 쓰던 번호는 삭제하고, 생일이나 전화번호 뒷자리처럼 상대가 짐작할 수 있는 숫자는 피하세요. / 가족과 함께 사는 경우 새 번호를 어떻게 공유할지도 같이 정해야 합니다.
번호를 바꾼 뒤에는 문을 닫고 새 번호로 몇 번 열어 보며 제대로 되는지 확인합니다. / 한 번만 해보고 끝내면 문이 잠긴 채 못 들어오는 일이 생길 수 있습니다.

# 번호 말고 확인해야 할 것들
도어락은 번호 한 가지로만 열리지 않는 제품이 많습니다. / 아래 항목을 하나씩 살펴보세요.
- 열쇠 구멍에 쓰는 보조 열쇠가 몇 개인지
- 카드키나 태그가 등록되어 있다면 누구에게 있는지
- 지문이나 스마트폰 앱 등록 목록에 모르는 항목이 있는지
- 안쪽 보조키나 걸쇠를 별도로 쓰는지
- 공동 현관 번호나 열쇠를 알려 준 적이 있는지
카드나 지문이 등록되는 제품은 목록에서 필요 없는 것을 지울 수 있는 경우가 많습니다. / 제품마다 방법이 다르니 설명서나 제조사 안내를 먼저 보세요.

# 열쇠를 돌려받지 못했을 때
상대가 가진 열쇠를 돌려받기 어려운 경우가 있습니다. / 연락이 편하지 않다면 억지로 요구하기보다 열쇠를 못 쓰게 하는 쪽을 생각해 볼 수 있습니다.
열쇠 구멍 부분을 바꾸는 것을 실린더 교체라고 합니다. / 문과 도어락 전체를 바꾸지 않아도 이 부분만 바꾸면 예전 열쇠는 맞지 않게 됩니다.
도어락 자체를 새것으로 교체하는 방법도 있습니다. / 어느 쪽이 맞는지는 문과 제품 상태를 보고 설명드립니다.
@ 열쇠 구멍 부분을 교체하는 작업

# 지금 혹시 문이 잠겨 들어가지 못한다면
번호를 잊었거나 바뀐 번호를 몰라 못 들어가는 상황일 수도 있습니다. / 이 경우에는 번호판 상태와 소리를 먼저 살펴보세요.
함께 살던 사람이 번호를 바꿨을 가능성도 있습니다. / 이럴 때는 임의로 문을 열기 전에 사시는 분 본인 확인이 꼭 필요합니다.
신분증 주소나 주소가 적힌 우편물, 관리사무소 확인 같은 자료가 있으면 준비해 주세요. / 같이 살던 상대 명의의 집이라면 본인 확인이 어려울 수 있어, 상황을 솔직히 말씀해 주시는 것이 좋습니다.

# 법적인 판단은 대신해 드릴 수 없습니다
집이 누구 명의인지, 누가 거주할 권리가 있는지는 저희가 가려 드릴 수 있는 일이 아닙니다. / 갈등이 있는 상황이라면 필요한 경우 경찰이나 법률 상담처럼 알맞은 곳의 도움을 받으시길 권합니다.
저희는 사시는 분임이 확인되는 경우에만 문을 열고 잠금장치를 손봅니다. / 확인이 어려우면 작업을 할 수 없습니다.
위협을 느끼거나 안전이 걱정되는 상황이라면 열쇠보다 안전한 장소로 이동하는 것이 먼저입니다. / 긴급할 때는 주저하지 말고 112에 연락하세요.

# 반송동 위치는 이렇게 알려주세요
위치와 상황을 짧게 알려 주시면 준비가 빨라집니다. / 사적인 사정은 자세히 말씀하지 않으셔도 됩니다.
- 건물 종류와 층, 호수
- 현재 번호판이 켜지는지와 소리 여부
- 도어락 모양과 열쇠 구멍 유무
- 번호 변경인지, 열쇠 교체인지, 문 열기인지
- 집 안에 사람이나 반려동물이 있는지
번호 변경 방법만 알고 싶으시다면 방문해서 안내만 드리는 경우도 있습니다. / 필요한 범위까지만 말씀해 주세요.
전화로 상황을 설명하는 일 자체가 부담스러우시면 문자로 사진과 위치만 보내 주셔도 괜찮습니다. / 그 뒤에 어떤 작업이 필요한지 차분히 안내드립니다.
번호를 바꾼 뒤 며칠은 문 앞에서 새 번호가 손에 익을 때까지 천천히 눌러 보세요. / 급하게 누르다 오류가 반복되면 입력이 잠시 막힐 수 있습니다.
열쇠를 새로 만들 때는 복사본이 몇 개인지 기억해 두시는 것이 좋습니다. / 개수를 알면 나중에 누가 가지고 있는지 따져 보기 쉽습니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
이 절차는 반대로 내 집이 아닌 곳을 누군가 열어 달라고 할 때를 막기 위한 것이기도 합니다.

# 비용은 문 열기 전에 말씀드립니다
작업 내용이 번호 변경인지, 실린더 교체인지, 도어락 교체인지에 따라 다릅니다. / 상태를 보고 얼마인지 먼저 말씀드립니다.
괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
열고 난 뒤에 말없이 붙는 비용도 없습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 교체와 수리 중 무엇이 맞을까
열쇠만 걱정이라면 실린더 교체로 충분한 경우가 많습니다. / 번호와 카드, 지문까지 모두 새로 시작하고 싶다면 도어락 교체가 깔끔합니다.
제품이 아직 쓸 만하다면 번호를 새로 바꾸고 등록 정보를 정리하는 것으로 끝낼 수도 있습니다. / 불필요한 교체를 권하지 않습니다.
새 제품을 고민하시면 [도어락 교체](doorlock-replace.html)와 [도어락 설치](doorlock-install.html) 페이지를 참고하세요. / 고장이 있으면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드립니다.
@ 새 도어락 설치 후 번호를 등록하는 모습

# 교체 후에 챙길 마무리
- 새 번호를 가족과만 공유하고 메모에 남기지 않기
- 새 열쇠는 개수를 확인하고 보관 위치를 정해 두기
- 등록된 카드, 지문, 앱 목록을 한 번 더 확인
- 공동 현관 번호도 필요하면 관리하는 분과 상의
- 몇 달에 한 번 번호를 바꾸는 습관 만들기
번호 공유 방식은 [도어락 가이드](guide.html)에서 설명하는 원칙과 함께 정하면 편합니다. / 필요 없는 불안을 줄이는 것이 목적입니다.

# 반송동 말고 화성 어디든 갑니다
반송동 옆 동탄 쪽 생활권, 병점동, 봉담읍, 향남읍까지 화성 안이면 24시간 출동합니다. / 거리에 따라 도착 시간이 달라 위치를 먼저 알려 주세요.
다니는 동네는 [화성시 출장열쇠](hwaseong.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
