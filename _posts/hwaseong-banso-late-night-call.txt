# 새벽 두 시, 반송동 현관문 앞에서
동탄 반송동은 동탄역 가까이 아파트와 상가가 이어진 곳이라 밤늦게까지 사람이 오갑니다. / 그래도 새벽에 문 앞에서 막히면 주변이 조용해서 더 막막하게 느껴집니다.
이 글은 한밤이나 새벽에 현관문이 안 열릴 때 무엇부터 해야 하는지, 전화할 때 어떻게 말하면 빠른지를 적었습니다. / [화성 출장열쇠](hwaseong.html)를 부르는 상황을 기준으로 정리했습니다.
@ 동탄 반송동 새벽 출장열쇠 현관문 개문

# 우선 숨부터 고르세요
문이 안 열리면 몸이 먼저 급해집니다. / 손잡이를 세게 당기거나 문을 두드리는 건 도움이 되지 않습니다.
번호를 여러 번 틀리면 도어락이 잠시 입력을 막기도 합니다. / 서너 번 해보고 안 되면 멈추는 것이 좋습니다.

# 밤에 자주 생기는 경우
밤에는 평소와 달리 몸이 피곤하고 술을 마셨거나 급하게 나오는 일이 많아서 실수가 늘어납니다.
- 번호를 한 자리씩 헷갈려 눌러 입력이 막힌 경우
- 배터리가 다 돼서 번호판이 꺼져 있는 경우
- 안쪽 보조키를 잠그고 나온 경우
- 열쇠나 카드를 어디에 두었는지 모르는 경우

# 위험한 곳에 서 있지 않기
계단이나 복도에서 오래 기다리는 건 안전하지 않습니다. / 건물 1층 현관이나 밝은 공용 공간으로 이동해 기다려 주세요.
혼자라면 가족이나 친구에게 지금 위치를 알려두는 것도 방법입니다. / 출장열쇠가 도착하기 전까지 연락이 닿는 사람이 있으면 마음이 훨씬 편합니다.

# 1분 안에 해볼 수 있는 것
시간이 늦었어도 아래 세 가지는 바로 해볼 수 있습니다.
- 번호판을 손으로 덮고 불이 들어오는지 보기
- 문을 안쪽으로 살짝 밀면서 손잡이 돌려 보기
- 9V 건전지를 비상 단자에 대고 번호 눌러 보기
편의점이 가까이 있으면 건전지를 구해 오는 것도 방법입니다. / 해보고도 안 되면 그때 전화 주시면 됩니다.
@ 반송동 아파트 현관 도어락 비상 건전지

# 전화하면 이렇게 말씀해 주세요
짧게 핵심만 말씀해 주시면 도착이 빨라집니다.
- 반송동 안에서 어디쯤인지(건물 이름 대신 길, 역 방향도 괜찮습니다)
- 동과 호수
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집 안에 아이나 반려동물, 켜 둔 불이나 가스가 있는지
집 안에 사람이 있는데 응답이 없는 상황이면 가장 먼저 말씀해 주세요. / 이런 경우는 다른 순서로 진행합니다.

# 한밤에 오는 사람이 누구인지 확인하세요
밤늦은 시간이니 오시는 분이 누구인지 미리 확인해 두면 좋습니다. / 전화 통화로 이름과 도착 예상 시간을 말씀드립니다.
도착하면 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 경비실 확인 중 하나면 됩니다.

# 새벽이라 경비실만 확인 가능한 경우
신분증이 집 안에 있어서 보여드릴 방법이 없을 수 있습니다. / 이럴 때는 경비실이나 관리사무소에 세대 확인을 부탁해 두시면 됩니다.
야간 경비 근무자가 있으면 입주민 확인을 도와주는 곳이 많습니다. / 미리 말씀해 두면 도착한 뒤 지체 없이 진행됩니다.

# 비용은 문을 열기 전에 말씀드립니다
밤이라고 해서 말없이 비용이 늘어나지는 않습니다. / 상태를 보고 얼마인지 먼저 말씀드린 뒤에 시작합니다.
괜찮다고 하시면 진행하고, 아니면 그냥 돌아갑니다. / 문을 못 열면 비용은 받지 않습니다.
@ 반송동 야간 출장열쇠 도어락 작업

# 소음 신경 쓰는 방법
한밤에는 이웃 잠을 깨우지 않는 것이 중요합니다. / 소리가 크게 나지 않는 방법부터 차례로 해봅니다.
작업 중 큰 소리가 날 수 있는 상황이면 미리 말씀드립니다. / 아파트에서는 복도 소리가 의외로 멀리 퍼지기 때문입니다.

# 문이 열린 뒤에 할 일
도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리 문제였다면 새 배터리로 전부 바꿔 둡니다.
같은 일이 반복되면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)가 필요한지 말씀드립니다. / 필요 없으면 권하지 않습니다.

# 다음에 또 밤에 막히지 않으려면
비상용 9V 건전지 하나를 가방이나 차에 두는 습관이 좋습니다. / 도어락 경고음이 나면 그날 바로 배터리를 바꾸세요.
가족과 번호를 같이 정하고 카드 하나는 따로 보관해 두면 새벽 연락이 줄어듭니다. / 평소 [이용안내](guide.html)를 한 번 읽어 두는 것도 도움이 됩니다.

# 반송동 말고 동탄 어디든
반송동 옆 능동, 청계동, 영천동, 오산동, 목동까지 동탄 전역과 화성 전체를 다닙니다. / 시간 상관없이 24시간 전화를 받습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있고, 문 여는 방식은 [현관문 개문](door-open.html) 페이지에 있습니다. / 새벽이어도 부담 갖지 말고 전화 주세요.

# 자주 묻는 질문
? 새벽 세 시에도 오시나요? | 네, 24시간 전화를 받고 위치를 받으면 출동 여부와 시간을 바로 말씀드립니다.
? 이웃에게 소음이 가지 않나요? | 소리가 적은 방법부터 하고, 큰 소리가 날 때는 미리 말씀드립니다.
? 신분증이 집 안에 있으면 어떡하나요? | 경비실이나 관리사무소 세대 확인으로 대신할 수 있는 경우가 많습니다.
? 혼자 있으면 위험하지 않을까요? | 밝은 공용 공간에서 기다리시고, 가족에게 위치를 알려두시면 안심됩니다.
? 못 열면 비용이 드나요? | 아닙니다. 못 열면 비용은 받지 않습니다.

24시출장열쇠는 서울, 경기 전 지역 24시간 전화를 받습니다. / 010-3664-5455로 연락 주세요.
