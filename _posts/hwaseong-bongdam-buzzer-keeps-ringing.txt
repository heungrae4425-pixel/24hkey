# 봉담읍 도어락이 멈추지 않고 울릴 때 먼저 할 일
봉담읍은 주택과 아파트, 상가가 넓게 퍼져 있고 봉담 생활권에서 차를 타고 오가는 분들이 많습니다. / 밤늦게 집에 돌아왔는데 현관에서 삐삐 소리가 계속 울리면 당황스럽고 이웃에게도 미안해집니다.
소리는 도어락이 보내는 신호이고 어떤 소리인지에 따라 원인이 다릅니다. / 이 글은 소리를 구분하는 법과 멈추는 순서, 그리고 [화성 출장열쇠](hwaseong.html)를 부르는 기준을 정리했습니다.
@ 봉담읍 현관 도어락 경고음 확인

# 소리부터 구분해 보세요
도어락 소리는 크게 짧은 반복음, 긴 연속음, 모터 소리로 나뉩니다. / 제품마다 의미가 조금 다르니 설명서를 볼 수 있다면 먼저 확인하세요.
- 짧게 삐삐 반복: 보통 배터리가 약하다는 알림
- 길게 이어지는 경고음: 문이 덜 닫혔거나 강제 조작을 감지한 경우
- 번호를 누를 때마다 길게 우는 소리: 비밀번호 입력 오류가 쌓인 경우
- 위잉 모터만 돌고 안 열림: 걸쇠가 문틀에 걸렸거나 모터가 약한 경우
소리 모양을 말해주시면 전화 상담이 훨씬 빨라집니다. / 흉내 내서 알려주셔도 괜찮습니다. / 소리가 언제부터 났는지, 문을 열고 닫을 때만 나는지 계속 나는지도 같이 알려주시면 좋습니다.

# 배터리 알림이라면 이렇게
배터리가 약해지면 문을 열 때마다 경고음이 나는 도어락이 많습니다. / 이 소리는 갑자기 멈추지 않고 문을 쓸 때마다 반복됩니다.
안쪽 건전지 덮개를 열고 건전지를 모두 새것으로 바꿔 주세요. / 일부만 바꾸면 곧 같은 알림이 다시 올라옵니다.
바꾼 뒤에도 소리가 이어진다면 건전지 방향이 맞는지, 접점에 때가 없는지 확인하세요.

# 문이 덜 닫혀서 울릴 수도 있습니다
도어락은 문이 완전히 닫혔는지 감지하는 센서가 있습니다. / 문이 반쯤만 닫혀 있거나 걸쇠가 문틀 홈에 맞지 않으면 계속 경고가 납니다.
문을 안쪽으로 한 번 더 밀어 닫아 보세요. / 문틀 쪽 걸쇠 홈에 이물질이 끼어 있지 않은지도 살펴보세요.
문이 처져서 걸쇠 위치가 어긋났다면 닫을 때마다 다시 울립니다. / 이 경우는 도어락보다 문의 정렬을 먼저 손봐야 합니다.

# 비밀번호를 여러 번 틀렸을 때
번호를 몇 번 틀리면 도어락이 입력을 잠시 막고 경고음을 냅니다. / 이때는 계속 누르지 말고 몇 분 기다렸다가 다시 눌러 보세요.
가족이 번호를 바꿨는데 모르고 계속 누르면 이 상태가 반복됩니다. / 먼저 가족에게 연락해 번호를 확인하는 것이 빠릅니다.
@ 도어락 번호 입력 오류 경고 후 대기 상태

# 소리가 너무 커서 이웃이 신경 쓰인다면
소리를 일시적으로 멈추려면 도어락 안쪽 배터리를 잠시 빼는 방법이 있습니다. / 건전지를 뽑았다가 다시 끼우면 경고 상태가 풀리는 제품이 있습니다.
다만 이렇게 하면 설정이 초기화되는 제품도 있으니 번호를 기억해 두세요. / 모르겠다면 무리하게 하지 말고 연락 주시는 것이 낫습니다.
스피커 부분을 막거나 손으로 누르는 것은 피해 주세요. / 소리가 안 나는 것과 문제가 풀린 것은 다릅니다.

# 하지 말아야 할 것
소리가 계속 난다고 도어락 본체를 두드리거나 뜯는 일은 피하세요. / 안쪽 회로가 상하면 소리 하나로 끝날 일이 부품 교체로 커집니다.
드라이버로 번호판 틈을 벌려 보는 것도 좋지 않습니다. / 외관이 상하고 물이 스며들 수 있습니다.
경고음을 무시하고 며칠 두는 것도 위험합니다. / 배터리가 완전히 방전되어 문이 잠긴 채로 안 열리는 상황이 생길 수 있습니다.

# 문이 안 열리면서 울릴 때는 이렇게 연락 주세요
소리가 계속 나고 번호를 눌러도 문이 안 열린다면 억지로 계속 누르지 마세요. / 이럴 땐 연락 주시고 상황을 말해 주세요.
- 소리가 어떻게 나는지(짧은지 긴지)
- 번호판에 불이 들어오는지
- 문이 완전히 닫혀 있는지
- 최근에 배터리를 갈았는지
[출장열쇠 요청](key-call.html) 방법에도 안내가 있습니다.

문을 여는 일이라 도착하면 먼저 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나로 확인합니다. / 신분증이 집 안에 있으면 관리사무소나 경비실의 세대 확인을 부탁하는 방법도 있습니다.
번거롭지만 이웃과 집을 지키는 절차입니다. / 확인이 어려우면 작업할 수 없는 점 양해 부탁드립니다. / 한밤에 경고음이 울리는 상황이라 마음이 급하시겠지만 이 절차는 꼭 거치고 있습니다. / 신분증이 없으면 우편물 사진이나 관리사무소 확인으로 대신할 수 있는지 먼저 상의해 보세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
상태를 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 그때 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 작업 도중에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 원인에 따라 이렇게 손봅니다
배터리가 원인이면 건전지를 바꾸고 접점을 닦은 뒤 시험합니다. / 센서 문제라면 문과 걸쇠의 정렬을 확인하고 조정합니다.
모터가 약해졌거나 안쪽 부품이 고장 난 경우에는 부품을 바꾸는 이야기를 하게 됩니다. / 바꾸기 전에 어떤 부품인지, 왜 필요한지 먼저 설명드립니다.
고쳐서 쓸 수 있다면 교체는 권하지 않습니다. / 자세한 범위는 [도어락 수리](doorlock-repair.html)를 참고해 주세요.
@ 경고음 원인 점검 중인 도어락 안쪽 모터와 배터리

# 너무 오래된 도어락이라면
경고음이 자주 나고 잠금이 한 번에 안 되는 도어락은 수명이 다해 가는 경우가 많습니다. / 고쳐도 같은 문제가 반복되면 바꾸는 쪽이 편합니다.
교체가 필요하다고 판단하면 이유를 설명드리고 선택은 직접 하시면 됩니다. / 교체 안내는 [도어락 교체](doorlock-replace.html)에 정리해 두었습니다.

# 경고음을 줄이는 평소 습관
- 건전지는 해가 바뀔 때쯤 한 번에 전부 교체
- 경고음이 처음 났을 때 바로 새것으로 바꾸기
- 문을 닫을 때 끝까지 닫혔는지 한 번 확인
- 번호는 가족끼리 바뀌면 바로 공유
- 비 오는 날 번호판 물기는 마른 천으로 닦기
작은 소리 하나도 처음 났을 때 확인해 두면 한밤에 크게 울릴 일이 줄어듭니다. / 이웃이 많은 건물일수록 한밤의 경고음은 민원으로 이어지기 쉬워, 미리 잡아 두면 서로 편합니다. / 소리가 나는 날짜를 메모해 두는 것도 도움이 됩니다.

# 봉담읍 말고 화성 어디든 갑니다
봉담읍 외에도 향남읍, 남양읍과 병점동, 진안동, 반송동, 능동 등 화성 안이면 24시간 출동합니다. / 대략의 위치만 알려주시면 됩니다.
다니는 동네는 [화성시 출장열쇠](hwaseong.html)에 있고 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

24시출장열쇠는 봉담읍을 포함한 화성 전 지역에서 24시간 전화를 받습니다. / 서울, 경기 어디든 전화 010-3664-5455로 연락 주세요.
