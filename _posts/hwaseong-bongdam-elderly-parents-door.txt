# 봉담읍 부모님 댁 문, 마지막으로 언제 봤나요
봉담읍은 아파트와 주택, 연립이 섞여 있어서 부모님 세대가 오래 살아오신 집도 많습니다. / 도어락은 한 번 달면 신경 쓰지 않게 되는 물건이라 몇 년씩 점검 없이 쓰는 경우가 흔합니다.
자녀가 멀리 살거나 바쁘면 부모님 집 문이 어떤 상태인지 모르고 지나가기 쉽습니다. / 어느 날 연락이 와서 문이 안 열린다고 하면 그제야 상황을 알게 됩니다.
이 글은 봉담읍 부모님 댁 도어락을 점검할 때 볼 것과, 어르신이 쓰기 편하게 설정하는 방법을 정리했습니다. / 문이 안 열리는 상황이 생기면 [화성 출장열쇠](hwaseong.html)로 연락 주세요.
@ 봉담읍 부모님 집 도어락 점검 출장열쇠

# 어르신 집에서 문이 말썽을 부리는 이유
고령이신 분들은 도어락 경고음을 듣고 지나치는 경우가 많습니다. / 배터리가 부족하다는 소리를 소음으로 여겨 그냥 두다가 어느 날 문이 아예 안 열리는 일이 생깁니다.
비밀번호를 자주 쓰다가도 한 번 혼란이 오면 다시 떠올리기 어렵기도 합니다. / 스마트폰 앱이나 카드키처럼 새로 익혀야 하는 방식은 더 어려울 수 있습니다.
열쇠를 쓰시던 분이 도어락으로 바꾼 지 얼마 안 되면 사용법이 익숙하지 않아 실수가 잦습니다. / 문제는 기기가 아니라 쓰는 방식과 환경에서 생기는 경우가 많습니다.

# 가장 먼저 배터리부터 점검하세요
부모님 댁에 갈 때마다 도어락 배터리를 새것으로 교체해 드리는 것이 가장 확실한 예방법입니다. / 해가 바뀔 때쯤 한 번에 전부 갈아 두면 잊어버리지 않습니다.
배터리 칸에 교체한 날짜를 적어 두면 다음 시기를 가늠하기 쉽습니다. / 경고음이 나면 부모님이 자녀에게 전화하는 습관을 만들어 두는 것도 좋습니다.
건전지를 일부만 바꾸면 며칠 안에 같은 일이 다시 생깁니다. / 번호판 안쪽 건전지는 반드시 전부 한꺼번에 바꿔 주세요.
@ 봉담읍 도어락 배터리 교체 어르신 댁

# 비밀번호는 쉬운 규칙으로, 그래도 가족과 공유하세요
부모님이 외우기 쉬운 번호를 쓰는 것이 우선입니다. / 다만 생일이나 전화번호처럼 누구나 알기 쉬운 번호는 안전상 피하는 편이 좋습니다.
번호가 잊혀질 때를 대비해 자녀 한 명 이상이 번호를 알고 있어야 합니다. / 종이에 적어 현관 근처에 두는 방법은 위험해 권하지 않습니다.
번호를 잊어버렸을 때 연락할 곳을 부모님 눈에 띄는 곳에 적어 두세요. / 자녀 전화번호와 함께 [이용안내](guide.html)에 적힌 연락 방법을 알려 드려도 좋습니다.

# 열쇠를 같이 쓰는 방식도 고려해 보세요
번호와 열쇠를 함께 쓰는 도어락이라면 열쇠 한 벌을 부모님이 가까운 곳에 보관하게 해주세요. / 번호를 잊거나 배터리가 다 되었을 때 열쇠가 마지막 수단이 됩니다.
열쇠는 현관 밖에 두지 말고 이웃이나 가까운 가족이 가지고 있는 방식이 안전합니다. / 가까이 사는 가족이 있다면 보조 열쇠를 맡겨 두세요.
카드키 방식은 분실 위험이 있어서 고령자에게는 번호와 열쇠 위주를 권합니다. / 이미 카드키를 쓰고 있다면 잃어버렸을 때 대처 방법을 같이 알려 드리세요.

# 문이 안 열릴 때를 대비해 부모님과 정해 두세요
부모님이 혼자 계실 때 문이 안 열리면 당황하셔서 힘을 쓰다 다치는 경우가 있습니다. / 어떻게 해야 하는지를 미리 정해 두면 훨씬 안전합니다.
- 번호를 두세 번만 눌러 보고 안 되면 멈추기
- 건전지를 대 보는 방법은 가족이 알려 드린 경우에만 하기
- 자녀나 이웃에게 먼저 전화하기
- 급하면 119나 관리사무소에 도움 요청하기
- 문을 억지로 열려 하지 않기
특히 힘이 약하신 분이 문을 발로 차거나 어깨로 미는 것은 매우 위험합니다. / 안전이 최우선이니 이 약속을 꼭 해두세요.

# 집 안에 혼자 계실 때 문 앞에서 쓰러졌다면
어르신이 집 안에서 쓰러지신 것 같거나 연락이 닿지 않는 경우는 열쇠집이 아니라 119가 먼저입니다. / 119 대원이 현장에서 문을 열어 주는 경우가 많으니 먼저 도움을 요청하세요.
열쇠집은 안전이 확인된 뒤 문 점검이나 교체가 필요할 때 부르시면 됩니다. / 이런 순서가 중요한 이유는 시간이 곧 안전이기 때문입니다.
자녀가 먼 곳에 있다면 이웃이나 관리사무소에 연락해 문 앞 상황을 확인해 달라고 부탁해 보세요. / 전화 연결이 되지 않을 때를 대비해 가까운 이웃의 연락처도 알아 두면 좋습니다.

# 봉담읍에서 위치를 알려주는 방법
부모님 댁에 문제가 생겨 연락하실 때 위치를 정확히 알려주시면 도착이 빨라집니다. / 봉담읍은 아파트 단지와 주택가가 섞여 있어서 도로명보다 건물 위치를 먼저 말씀해 주시면 편합니다.
- 건물 형태(아파트, 빌라, 단독주택)와 층, 호수
- 문 앞 상황(번호판 켜짐/꺼짐, 경고음)
- 집 안에 사람이 있는지, 연락이 닿는지
- 부모님 상태(몸이 불편하신지 여부)
도어락 사진을 문자로 보내주시면 장비를 맞춰 가기 좋습니다. / 부모님 연락이 되지 않는 상황이면 꼭 먼저 말씀해 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
부모님 댁에서도 사시는 분이 맞는지 먼저 확인합니다. / 부모님이 계신 경우에는 부모님의 신분증이나 우편물, 관리사무소 확인으로 진행합니다.
자녀가 요청했는데 부모님이 현장에 없다면 전화 연결로 확인해야 할 수 있습니다. / 이 경우 자녀분이 부모님과 통화되는 상태를 만들어 주시면 수월합니다.
번거로워도 모든 집에 똑같이 하는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
@ 봉담읍 출장열쇠 신분 확인 어르신 댁 현관문

# 비용은 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 열기 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 고령자에게 맞는 도어락으로 바꿀 때
너무 많은 기능이 들어간 도어락은 오히려 어르신께 어렵습니다. / 버튼이 크고 번호판이 잘 보이며 소리가 분명한 제품이 쓰기 편합니다.
잘 안 쓰는 기능은 끄고, 필요한 기능만 남기는 설정이 좋습니다. / 지문 인식은 손이 건조하거나 주름이 있으면 실패가 잦아 상황에 따라 맞지 않을 수 있습니다.
바꾸기 전에 지금 쓰는 도어락이 고칠 수 있는 상태인지 먼저 확인합니다. / 고장이 잦다면 [도어락 수리](doorlock-repair.html)를 보고, 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 자녀가 한 번 해두면 좋은 점검 목록
방문하는 길에 십 분만 투자하면 해결되는 일이 많습니다.
- 배터리 전부 교체와 날짜 기록
- 문이 부드럽게 닫히는지 확인
- 번호판 버튼이 제대로 눌리는지 확인
- 열쇠 한 벌 위치 확인
- 자녀 연락처를 도어락 근처 안쪽에 적어 두기
문이 뻑뻑하거나 소리가 나면 사진을 찍어 보내 주세요. / 어디를 보면 되는지 알려드리고 필요하면 출동합니다.

# 봉담읍 말고 화성 어디든 갑니다
봉담읍뿐 아니라 동탄, 병점, 향남, 남양까지 화성 전 지역으로 출동합니다. / 화성은 넓어서 위치를 먼저 알려주시면 도착 시간을 정확히 말씀드립니다.
동네별 안내는 [화성시 출장열쇠](hwaseong.html)에, 서울·경기 다른 지역은 [출장 지역](area.html) 지도에 있습니다.
