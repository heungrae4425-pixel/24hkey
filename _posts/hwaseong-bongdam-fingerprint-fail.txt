# 지문이 안 읽혀 문 앞에서 서성이게 될 때
화성 봉담읍은 새 단지와 주택가가 함께 있고 지문 인식 도어락을 쓰는 집도 많습니다. / 평소에는 손만 대면 열리던 문이 어느 날부터 자꾸 실패하면 당황스럽습니다.
이 글은 봉담읍에서 지문 인식이 잘 안 될 때 먼저 확인할 것을 순서대로 정리했습니다. / 대부분은 고장이 아니라 손 상태나 센서 오염 때문이라 직접 해볼 수 있는 것이 있습니다.
번호나 카드키로도 문이 안 열리는 상황이라면 5번과 6번부터 보세요. / 지문만 안 되는 것과 문 전체가 안 열리는 것은 대응이 다릅니다.
@ 화성 봉담읍 도어락 지문 인식 실패 출장열쇠

# 먼저 손을 살펴봅니다
지문은 손가락 끝 피부의 미세한 무늬를 읽는 방식이라 손 상태에 민감합니다. / 손이 젖었거나 너무 건조하거나 로션이 묻어 있으면 인식이 잘 안 됩니다.
겨울철에는 손이 건조해져 지문 골이 얕아지는 경우가 많습니다. / 손에 입김을 한 번 불거나 살짝 문질러 촉촉하게 한 뒤 다시 대 보세요.
손가락을 다쳤거나 밴드를 붙였다면 다른 손가락이나 등록한 다른 지문으로 열어 보세요. / 주로 쓰는 손가락 하나만 등록해 두었다면 불편함이 커집니다.

# 센서 표면을 닦아 줍니다
지문 센서에는 매일 손이 닿아 기름때와 먼지가 쌓입니다. / 마른 부드러운 천으로 가볍게 닦아 주는 것만으로도 인식이 좋아지는 경우가 많습니다.
물을 직접 뿌리거나 세제로 닦으면 센서가 상할 수 있어 권하지 않습니다. / 알코올 소독포를 쓸 때도 센서 부분이 물기에 오래 젖지 않게 하세요.
센서가 긁히거나 금이 갔다면 닦아도 소용없습니다. / 이 경우는 센서 부품 교체가 필요할 수 있습니다.

# 손가락을 대는 방법을 바꿔 봅니다
손가락 끝만 살짝 대지 말고 지문 중심이 센서에 평평하게 닿게 하세요. / 너무 세게 누르면 오히려 지문이 번져 읽히지 않습니다.
손가락을 센서 위에서 움직이지 말고 한 번에 대고 잠시 유지합니다. / 제품마다 읽는 시간이 다르니 소리가 날 때까지 기다리세요.
등록할 때와 같은 각도와 위치로 대는 것이 가장 정확합니다. / 처음 등록할 때 여러 각도로 등록해 두면 이후에 훨씬 잘 됩니다.
@ 봉담읍 도어락 지문 센서 점검 닦기

# 지문 등록을 다시 해야 할 때
시간이 지나면 손가락 피부가 변해 처음 등록한 지문과 달라질 수 있습니다. / 특히 아이들은 손가락이 자라면서 지문이 점점 달라져 인식이 떨어집니다.
같은 손가락을 두세 번 나눠 다시 등록하면 인식률이 올라가는 경우가 많습니다. / 등록 방법은 제품마다 다르니 설명서나 안쪽 버튼을 확인해 보세요.
관리자 번호나 카드키가 있어야 등록이 되는 제품도 있습니다. / 번호를 잊어서 등록을 못 하는 상황이면 연락 주세요.

# 지문만 안 되는 것과 문 전체가 안 열리는 것은 다릅니다
지문이 안 돼도 번호나 카드, 열쇠로 열 수 있는 도어락이 대부분입니다. / 일단 다른 방법으로 문을 열 수 있는지부터 시도해 보세요.
번호판 전체가 꺼져 있다면 지문 문제가 아니라 배터리 문제일 가능성이 큽니다. / 9V 건전지를 비상 단자에 대면 임시로 전원이 들어오는 제품도 많습니다.
번호도 지문도 카드도 다 안 되고 소리만 난다면 모터나 걸쇠 쪽을 의심해야 합니다. / 이 경우는 직접 하기 어려우니 연락 주세요.

# 배터리가 약해도 지문이 안 읽힐 수 있습니다
지문 센서는 전력을 많이 쓰는 부품이라 배터리가 약해지면 가장 먼저 반응이 둔해집니다. / 번호는 눌리는데 지문만 느리거나 자주 실패한다면 배터리를 먼저 의심해 보세요.
배터리는 일부만 바꾸지 말고 전부 새것으로 바꿔 주세요. / 일부만 바꾸면 며칠 안에 같은 일이 다시 생깁니다.
교체 날짜를 배터리 칸에 적어 두면 잊지 않고 관리할 수 있습니다.

# 출장열쇠가 해드리는 일
지문 센서 점검, 손 상태 확인, 등록 정리, 배터리 교체까지 한 번에 봐 드립니다. / 센서가 고장 난 것이면 센서만 바꿀 수 있는지 부품 상태를 확인합니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 지문 센서가 아예 먹통이라 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
먼저 [도어락 수리](doorlock-repair.html)로 어디까지 되는지 보고 결정하시면 됩니다. / 바꾸기 전에는 반드시 먼저 여쭤봅니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 열거나 도어락을 만지는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
지문 등록은 개인 정보와 연결되는 일이라 확인을 더 신중하게 합니다. / 번거로우실 수 있지만 이웃과 집 모두를 지키는 절차입니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 작업 전에 말씀드립니다
증상과 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 봉담읍 도어락 지문 센서 교체 비용 안내

# 지문 인식을 오래 잘 쓰는 관리법
- 센서를 마른 천으로 가끔 닦기
- 손이 건조한 계절에는 핸드크림을 바른 직후에는 피하기
- 같은 지문을 여러 번 나눠 등록해 두기
- 아이는 성장에 맞춰 지문을 다시 등록하기
- 배터리는 해마다 한 번에 전부 교체하기
번호와 카드키를 같이 등록해 두면 지문이 안 되는 날에도 문 앞에서 막히지 않습니다. / 지문만 믿지 말고 대체 수단을 늘 준비해 두세요.

# 봉담읍 말고 화성 어디든 갑니다
봉담읍 바로 옆 동탄, 병점, 향남, 남양까지 화성 안이면 24시간 출동합니다. / 화성에서 다니는 동네는 [화성시 출장열쇠](hwaseong.html) 페이지에 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 현관문 개문은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
