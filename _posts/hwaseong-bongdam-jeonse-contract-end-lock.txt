# 봉담읍 전세 계약이 끝나갈 때 도어락부터
봉담읍은 봉담 생활권에서 이사 오가는 분들이 꾸준히 있는 동네입니다. / 전세 계약이 끝나는 시기가 다가오면 가구와 보증금 이야기에 밀려 도어락 문제는 뒤로 미루기 쉽습니다.
그런데 이사 당일 문 앞에서 비밀번호 때문에 서로 곤란해지는 일이 의외로 많습니다. / 나가는 세입자와 들어오는 사람, 집주인 모두에게 걸린 문제이기 때문입니다.
이 글은 전세 계약이 끝날 때 도어락 비밀번호와 카드를 어떻게 인계하고 정리하면 좋은지 순서대로 적었습니다. / 법적인 판단이 아니라 현장에서 편하게 정리하는 요령입니다.
@ 봉담읍 전세 퇴거 현관 도어락 인계

# 도어락은 누구의 것인지 먼저 확인하세요
잘 모르겠으면 집주인에게 짧게 물어보는 것이 가장 빠릅니다. / 모르는 채 진행하면 나중에 되돌리기 어렵습니다.
도어락이 집에 원래 달려 있던 것인지 세입자가 직접 단 것인지에 따라 정리 방식이 다릅니다. / 계약서나 입주 때 이야기를 떠올려 보세요.
집주인이 설치한 것이라면 그대로 두고 비밀번호만 정리하면 됩니다. / 세입자가 직접 단 것이라면 가져갈지 두고 갈지 미리 이야기해야 합니다.
이 부분을 말로만 정해 두면 나중에 서로 기억이 다릅니다. / 문자나 메시지로 한 줄 남겨 두면 편합니다.

# 퇴거 전에 정리할 목록
이사 날짜가 정해지면 아래를 미리 점검해 보세요.
- 등록된 비밀번호가 몇 개인지
- 카드키나 태그가 몇 장인지
- 공동현관이나 공용 출입 카드가 따로 있는지
- 임시 비밀번호나 손님용 번호가 남아 있는지
가족 모두가 쓰던 번호와 도우미, 지인에게 알려준 번호가 있을 수 있습니다. / 한꺼번에 다 지우는 편이 가장 깔끔합니다.

# 비밀번호는 언제 바꿔야 할까
나가는 날 이사를 마친 뒤에 지우는 것이 안전합니다. / 이사 도중에는 짐을 옮기는 분들이 드나들어야 해서 번호가 필요합니다.
집이 비워지고 열쇠와 카드를 넘긴 뒤 번호를 초기화하거나 새로 정하세요. / 집주인이나 다음 세입자가 번호를 직접 정하게 하는 방법도 있습니다.
어느 쪽이 정할지 미리 합의해 두면 당일 헤맬 일이 없습니다.

# 인계하는 방식은 세 가지가 있습니다
봉담읍처럼 이사 시기가 겹치는 곳은 업체와 날짜가 맞물려 번호 인계 타이밍이 어긋나기 쉽습니다. / 이삿날 아침에 한 번 더 확인하시길 권합니다.
- 번호를 알려주고 새 사람이 들어와서 바꾸게 하기
- 초기화해서 아무 번호도 없는 상태로 넘기기
- 새 번호를 정해 적어서 전달하기
번호를 그대로 알려주는 방식은 편하지만 이전 사용자가 계속 번호를 알고 있다는 점이 마음에 걸립니다. / 가능하면 인수받는 쪽이 입주 날 직접 바꾸는 것을 권합니다.
초기화는 제품마다 방법이 다르니 설명서나 모델 이름을 확인해 두세요.
@ 봉담읍 도어락 초기화와 번호 인계

# 카드키와 열쇠는 꼭 세어서 넘기세요
넘기는 사람과 받는 사람이 같이 보면서 장수를 세면 가장 확실합니다. / 사진으로 한 장 남겨 두면 더 좋습니다.
카드는 나갈 때 몇 장인지 세어서 넘기는 것이 좋습니다. / 입주 때 받은 장수와 비교해 보면 어디 있는지 알 수 있습니다.
잃어버린 카드가 있다면 그 사실을 알려주고 등록을 지워야 합니다. / 이 과정을 건너뛰면 나중에 불안이 남습니다.
보조키 열쇠도 같은 방식으로 정리하세요. / 복사해 둔 열쇠가 있다면 그 위치까지 알려주는 것이 좋습니다.

# 이사 당일 문 앞에서 생기는 일들
계약 마지막 날은 정신이 없어서 작은 문제가 크게 느껴집니다.
- 번호를 이미 지웠는데 이사 업체가 아직 짐을 옮기는 중
- 새 번호를 정했는데 가족이 몰라서 못 들어옴
- 카드를 이삿짐 상자에 넣고 포장해 버림
- 방금 번호를 바꿨는데 모터가 반응하지 않음
이런 일은 순서만 정해 두면 대부분 피할 수 있습니다.

# 배터리와 점검은 인계 전에
인계 당일 아침에 건전지를 확인해 두면 문 앞에서 막히는 일을 막을 수 있습니다. / 새 건전지는 네 개 모두 같은 종류로 넣어 주세요.
인계하기 전에 건전지를 새것으로 바꿔 주면 서로 마음이 편합니다. / 방전이 임박한 상태로 넘기면 입주 첫날부터 문 앞에서 막힐 수 있습니다.
도어락이 잘 열리고 잠기는지, 경고음이 나지 않는지 한 번 점검해 보세요. / 고장이 있다면 누구 쪽에서 손볼지 미리 이야기해 두면 좋습니다.
고쳐서 쓸 수 있는 제품은 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.

# 번호를 잊어서 막혔다면
번호는 문자 한 줄로 나에게 보내 두는 정도면 충분합니다. / 다만 번호가 담긴 메시지는 오래 남기지 말고 정리하세요.
이사 당일 인계받은 번호를 잊어버려 문이 안 열리는 경우가 있습니다. / 새 번호를 수첩이나 메시지로 남겨 두지 않았기 때문입니다.
이럴 때는 억지로 열지 마시고 전화 주세요. / 신분 확인 후 문을 열고 새 번호를 등록해 드립니다.
출장 요청을 하실 때 알려주실 것은 위치, 도어락 사진, 집 안 상태입니다. / 봉담 쪽에서 오시는 중이라면 그것도 말씀해 주세요.

# 신분 확인을 거친 뒤 비용을 먼저 말씀드립니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 이사 날은 세입자와 집주인 중 누구의 확인이 필요한지 애매할 수 있어 미리 알려주세요.
신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다. / 계약서만으로는 확인이 부족할 수 있습니다.
확인이 끝나면 비용을 먼저 말씀드리고, 괜찮다고 하시면 시작합니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
자세한 진행은 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 적어 두었습니다.

# 집주인과 세입자가 같이 보면 좋은 점
도어락을 둘러싼 이야기는 감정이 상하기 쉬운 부분입니다. / 서로 확인한 내용을 간단히 적어 두면 오해가 줄어듭니다.
누가 비밀번호를 지울지, 배터리는 누가 바꿀지, 고장은 어떻게 할지 세 가지만 정해 두세요. / 정리하는 과정은 법적 판단이 아니라 서로 편하게 넘기기 위한 약속입니다.
@ 봉담읍 이사 날 도어락 점검과 확인

# 새 도어락으로 바꾸고 싶을 때
봉담 쪽 오래된 집은 문 두께가 달라 맞는 제품이 제한되기도 합니다. / 설치 전에 문 두께와 보조키 위치를 꼭 확인하세요.
인계하는 김에 도어락을 새로 바꾸고 싶다는 분도 있습니다. / 이럴 때는 문 두께와 보조키 위치를 먼저 확인합니다.
[도어락 교체](doorlock-replace.html)와 [도어락 설치](doorlock-install.html) 안내에 확인할 점을 적어 두었습니다. / 비용은 문 상태를 보고 작업 전에 먼저 말씀드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 봉담읍 말고 화성 어디든 갑니다
봉담읍 가까운 새솔동은 물론 동탄, 병점, 향남까지 다닙니다. / 다니는 곳은 [화성시 출장열쇠](hwaseong.html) 페이지에 정리해 두었습니다.
다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 자주 묻는 질문
? 이사 나갈 때 비밀번호를 꼭 지워야 하나요? | 법적 의무가 아니라 서로 안심하기 위한 정리입니다. 지우거나 바꾸는 편을 권합니다.
? 집주인이 도어락 초기화를 부탁하면 되나요? | 사시는 분 확인이 되면 초기화와 새 번호 등록을 도와드립니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 이사 당일 밤늦게 전화해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 카드가 한 장 없어졌어요. | 분실한 카드 등록을 지우고 새 카드를 등록하면 됩니다.
