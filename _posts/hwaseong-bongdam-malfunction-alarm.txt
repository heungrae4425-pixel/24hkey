# 봉담읍에서 도어락이 이상한 소리를 낼 때
봉담읍은 단지와 주택, 학교 주변 생활권이 이어진 곳이라 아침저녁 현관 앞 출입이 잦습니다. / 그만큼 도어락이 이상한 소리를 내면 바로 불편이 생깁니다.
삑삑 경고음이 나거나 모터 소리만 윙 하고 문이 안 열릴 때 먼저 볼 것을 적었습니다. / 직접 해결이 어려우면 [화성 출장열쇠](hwaseong.html)를 부르는 순서도 이어서 적었습니다.
@ 봉담읍 도어락 경고음 모터 소리 출장열쇠

제품 설명서에 경고음 종류가 적혀 있는 경우가 많습니다. / 설명서가 없다면 제품 모델명을 확인해 사진으로 보내주세요. 모델마다 경고음의 뜻이 다를 수 있습니다.
봉담읍에서 오래 쓰신 제품이라면 소리 종류가 요즘 제품과 다를 수도 있어 어느 소리가 어떤 뜻인지 단정하기 어렵습니다. / 그럴 때일수록 소리를 영상으로 남겨 두면 원인을 훨씬 빨리 짐작할 수 있습니다.

# 소리마다 뜻이 다릅니다
같은 삑 소리라도 길이와 횟수에 따라 뜻이 다릅니다. / 제품마다 다르지만 대략 이렇게 나눠 볼 수 있습니다.
- 짧게 한 번: 정상 입력 확인
- 길게 여러 번: 번호가 틀렸거나 입력이 잠시 막힘
- 반복해서 삑삑: 배터리 부족 경고
- 윙 소리만 나고 열림 소리가 없음: 모터나 걸쇠 쪽 문제

# 배터리 경고가 가장 흔합니다
경고음이 한동안 나다가 어느 날 문이 안 열리는 경우가 많습니다. / 먼저 배터리를 새것으로 바꿔 보고, 안 되면 다음 단계로 넘어가세요.
번호판이 꺼졌다면 9V 건전지를 바깥쪽 단자에 대고 열어 보세요. / 열린 뒤에는 안쪽 배터리를 전부 새 건전지로 교체하는 것이 좋습니다.

# 모터 소리만 날 때는 걸쇠를 봅니다
모터는 도는데 걸쇠가 안 빠지는 경우입니다. / 문이 문틀에 눌려 걸쇠가 움직이지 못할 때도 있습니다.
문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 이래도 안 되면 억지로 당기지 마시고 그대로 두세요.
@ 봉담읍 모터 소리만 나는 도어락 걸쇠

# 번호를 눌러도 반응이 없을 때
번호판 터치 면에 물기나 먼지가 있으면 눌러도 반응이 둔해집니다. / 마른 수건으로 닦고 잠시 뒤 다시 눌러 보세요.
비 오는 날이나 환기를 많이 한 날 번호판 안쪽에 습기가 차는 일도 있습니다. / 이 경우는 마르면 돌아오기도 합니다.

# 입력이 막힌 상태라면
번호를 몇 번 틀리면 도어락이 일정 시간 입력을 막습니다. / 이럴 때 계속 누르면 막힌 시간이 늘어날 수 있습니다.
조용히 잠시 기다린 뒤 한 번만 정확히 눌러 보세요. / 번호가 확실하지 않다면 가족에게 먼저 확인하세요.

# 이럴 때는 바로 전화 주세요
- 건전지를 새로 넣어도 소리만 나고 안 열릴 때
- 경고음이 멈추지 않고 계속 날 때
- 번호판에서 타는 냄새가 나거나 뜨거울 때
- 문이 반쯤 잠긴 채로 걸려 있을 때

# 전화로 알려주실 것
- 봉담읍 위치, 동과 호수, 가까운 큰길
- 어떤 소리가 어떻게 나는지 (영상이나 설명)
- 번호판 상태와 도어락 모양
- 집 안에 사람이나 반려동물이 있는지
소리를 말로 설명하기 어렵다면 짧은 영상을 보내주셔도 좋습니다. / 맞는 부품과 장비를 챙기는 데 도움이 됩니다.

# 도착하면 먼저 확인부터 합니다
사시는 분인지 신분증 주소나 우편물, 관리사무소 확인으로 먼저 확인합니다. / 이 절차를 거쳐야 작업을 시작할 수 있습니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요. / 늦은 시간이면 경비실에 미리 알려 두세요.

# 문을 열고 원인을 찾습니다
먼저 문을 상하지 않게 열고, 그다음에 도어락 안을 봅니다. / 배터리인지, 모터인지, 걸쇠인지 원인을 말씀드립니다.
고쳐서 쓸 수 있으면 교체를 권하지 않습니다. / 부품을 바꿔야 할 때는 바꾸기 전에 먼저 여쭙니다.
@ 봉담읍 출장열쇠 24시간 현관문 개문

# 비용은 열기 전에 말씀드립니다
상태를 보고 비용을 먼저 말씀드리고, 동의하시면 시작합니다. / 마음에 안 들면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 이용 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 고쳐 쓸지 바꿀지 판단 기준
오래된 도어락이라도 부품만 갈면 한동안 더 쓸 수 있습니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
고장이 잦고 부품이 단종된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 무조건 새 제품을 권하지 않습니다.

소리가 나지 않고 그냥 불이 안 들어오는 경우는 전원이나 연결선 문제일 수도 있습니다. / 문을 여닫을 때마다 안쪽 문짝과 문틀 사이를 지나는 전선이 오래 쓰면 닳아 끊어지기도 합니다.
이때는 건전지를 새로 넣어도 반응이 없으니 전선 상태까지 봐야 합니다. / 겉으로는 알 수 없는 부분이라 도어락과 문을 열고 확인합니다.
봉담읍처럼 가족이 자주 드나드는 집은 문을 여닫는 횟수가 많아 이런 연결 부분이 먼저 약해집니다. / 그래서 오래 쓴 제품일수록 경고음이 나면 미루지 말고 점검받으세요.

# 경고음을 방치하지 마세요
경고음이 나는데 며칠 넘기다 새벽에 문이 안 열리는 경우가 가장 많습니다. / 경고가 나는 그날 배터리를 바꾸는 습관이 제일 좋은 예방입니다.
평소와 다른 소리가 나면 잠금이 완전히 멈추기 전에 점검받으세요. / 멈춘 뒤에 고치는 것보다 비용 부담도 덜합니다.

# 봉담읍 말고 화성 어디든 갑니다
봉담, 향남, 남양은 물론 병점, 진안, 동탄까지 화성 전 지역을 다닙니다. / 24시간 출동하니 시간은 신경 쓰지 말고 연락 주세요.
다니는 동네는 [출장 지역](area.html) 지도에서 보실 수 있고, 현관문이 아예 열리지 않을 때는 [현관문 개문](door-open.html)을 참고하세요.
