# 어제까지 폰으로 잘 열리던 문이 오늘은 반응이 없을 때
봉담읍은 봉담 생활권에서 출퇴근하는 분들이 많아 스마트 도어락 사용도 늘어난 동네입니다. / 폰을 대면 열리던 문이 어느 날 갑자기 반응하지 않으면 당황스럽습니다.
이 글은 봉담읍에서 NFC나 블루투스로 문을 열다가 막혔을 때, 폰 쪽과 도어락 쪽을 나누어 확인하는 순서를 정리했습니다. / 직접 해결이 어려울 때 [화성 출장열쇠](hwaseong.html)가 어떻게 오는지도 뒤에 적었습니다.
@ 봉담읍 스마트폰 NFC 블루투스 도어락 열림 안 됨

# NFC와 블루투스는 열리는 방식이 다릅니다
NFC는 폰을 도어락 가까이에 대면 짧은 거리에서 신호를 주고받는 방식입니다. / 블루투스는 조금 떨어진 거리에서 폰과 도어락이 연결된 상태로 열리는 방식입니다.
그래서 증상도 다르게 나타납니다. / NFC는 폰 뒷면 안테나 위치와 케이스가 영향을 주고, 블루투스는 연결 상태와 앱 권한이 영향을 줍니다.
어떤 방식을 쓰고 있는지부터 떠올려 보시면 확인할 곳이 좁아집니다.

# 폰 쪽에서 가장 먼저 보는 설정
많은 경우는 도어락 고장이 아니라 폰 설정이 바뀐 것입니다. / 아래 항목만 봐도 풀리는 경우가 흔합니다.
- NFC 기능이 꺼져 있지 않은지
- 블루투스가 켜져 있는지
- 도어락 앱이 백그라운드에서 막히지 않았는지
- 위치 권한이나 알림 권한이 해제되지 않았는지
운영체제 업데이트 후 권한이 초기화되는 일도 있습니다. / 앱 설정에서 권한을 다시 켜고 폰을 한 번 껐다 켜 보세요.

# 폰 케이스와 충전 상태가 변수일 수 있습니다
NFC는 폰 뒷면 안테나로 신호를 보냅니다. / 두꺼운 케이스나 카드 수납 케이스, 금속 부착물이 있으면 신호가 약해집니다.
케이스를 벗기고 도어락 태그 위치에 폰 뒷면 중앙을 가만히 대 보세요. / 폰마다 안테나 위치가 달라서 위아래로 조금씩 옮겨 보는 것도 방법입니다.
배터리 절전 모드가 켜져 있으면 블루투스 연결이 끊기는 일도 있습니다. / 절전 모드를 꺼 보고 다시 시도해 보세요.
@ 봉담읍 도어락 NFC 태그 위치 폰 대기

# 도어락 쪽에서 의심할 것
폰 설정을 모두 확인했는데도 안 열리면 도어락 쪽을 살펴봅니다. / 먼저 번호판이나 키패드는 정상인지 보세요.
- 번호판이 켜지는지, 번호를 누르면 소리가 나는지
- 도어락 배터리가 약해져 통신만 먼저 불안정해진 건 아닌지
- 앱에 도어락이 연결됨으로 표시되는지
- 경고음이나 저전압 안내 음성이 나온 적이 있는지
스마트 기능은 배터리가 줄면 통신부터 약해지는 모델이 있습니다. / 번호판은 켜지는데 폰만 안 된다면 배터리 교체로 풀리는 경우가 많습니다.

# 폰이 아닌 다른 방법으로 열 수 있는지 확인
스마트 도어락은 대개 번호, 카드, 열쇠 같은 다른 열림 방법을 함께 둡니다. / 폰이 안 되면 그 방법으로 먼저 열어 보세요.
번호를 아는 상태라면 번호판으로 열고, 카드가 있다면 카드를 대 보세요. / 열쇠 구멍이 숨겨져 있는 제품은 덮개를 밀어 열쇠로 열 수 있습니다.
어느 방법도 안 되면 배터리가 완전히 방전된 상태일 수 있습니다. / 이때는 9V 건전지 비상 전원을 대 보는 방법도 있습니다.

# 폰을 바꿨거나 앱을 다시 깔았을 때
새 폰으로 바꾸면 이전 폰의 등록 정보가 사라져 있습니다. / 앱을 다시 설치했을 때도 도어락과 다시 짝을 맞추어야 할 수 있습니다.
도어락의 사용자 등록 모드로 들어가야 해서 안쪽 설정 버튼이나 관리자 번호가 필요한 경우가 많습니다. / 관리자 번호를 모르면 등록이 막혀 진행이 안 됩니다.
가족이 설치해 준 도어락이라면 그 가족에게 관리자 정보가 있는지 먼저 물어보세요.

# 억지로 건드리면 안 되는 것
스마트 도어락은 편한 만큼 설정이 쌓여 있어서, 한 번 지워진 정보는 다시 만들기까지 시간이 걸립니다. / 급해도 지금 상태를 사진으로 남기고 천천히 진행하는 편이 낫습니다.
앱 안내 문구나 오류 번호를 메모해 두면 통화할 때 원인을 찾는 속도가 훨씬 빨라집니다.
초기화 버튼이 보여서 무심코 누르는 경우가 있습니다. / 초기화하면 등록된 번호와 카드가 모두 지워질 수 있어서 신중해야 합니다.
- 설명서 확인 없이 초기화 버튼 누르기
- 번호판이나 덮개를 뜯어 보기
- 블루투스 앱을 여러 번 삭제하고 재설치하기
번호를 여러 번 틀리면 한동안 입력이 막힐 수도 있습니다. / 서너 번 해보고 안 되면 멈추는 게 좋습니다.

# 이런 상황에서 출장열쇠를 부릅니다
직접 확인했는데도 해결이 안 될 때 연락 주세요. / 아래 같은 경우가 특히 많습니다.
- 폰과 번호, 카드 모두 안 열리는 경우
- 번호는 맞는데 모터 소리만 나는 경우
- 관리자 번호를 몰라 폰을 새로 등록할 수 없는 경우
- 앱 문제인지 도어락 문제인지 판단이 안 서는 경우
통화할 때 도어락 모양과 번호판 상태, 어떤 방법을 쓰고 있었는지 알려 주세요. / 앱 화면 사진을 보내 주셔도 도움이 됩니다.
@ 봉담읍 스마트 도어락 앱 연결 오류 출장열쇠

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 해당 집에 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)와 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.

# 열린 뒤 앱 연결과 배터리 점검
문이 열리면 폰 등록과 앱 연결을 같이 점검합니다. / 배터리가 원인이었다면 새 건전지로 전부 교체합니다.
통신 모듈이 불안정한 제품은 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
스마트 기능을 새로 쓰고 싶다면 [도어락 설치](doorlock-install.html) 때 문 두께와 보조키부터 확인합니다.

# 봉담읍 말고 화성 어디든 갑니다
봉담읍뿐 아니라 동탄역 쪽, 병점역 쪽, 향남까지 화성 안이면 24시간 출동합니다. / 동네별 안내는 [화성시 출장열쇠](hwaseong.html) 페이지에서 볼 수 있습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
