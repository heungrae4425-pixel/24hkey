# 봉담읍 가게 문이 아침에 안 열린다면
봉담읍은 주거 단지 사이사이에 상가와 사무실이 많이 있는 곳입니다. / 아침에 가게 문을 열려는데 도어락이 반응하지 않으면 그날 장사가 통째로 흔들립니다.
이 글은 봉담읍 상가·사무실 출입문이 안 열릴 때 확인할 것과 출장열쇠를 부르는 요령을 적었습니다. / 주택 현관문과는 다른 점이 몇 가지 있어서 따로 정리했습니다.
@ 봉담읍 상가 사무실 출입문 도어락 출장

# 가게 문이 집 현관문과 다른 점
상가 문은 유리문이나 얇은 철문이 많고 바닥 잠금이나 별도 잠금장치가 함께 달린 경우가 있습니다. / 어느 장치가 잠겨 있는지 구분하는 것이 먼저입니다.
사람이 자주 드나들어 도어락을 하루에도 수십 번 쓰다 보니 부품이 먼저 닳는 곳이기도 합니다. / 그래서 배터리 소모가 빠르고 고장 주기도 짧은 편입니다.

# 영업 전에 확인할 세 가지
급할수록 아래 세 가지를 먼저 보면 시간을 아낄 수 있습니다.
- 번호판이나 카드 인식부에 불이 들어오는지
- 문 아래나 위에 따로 잠긴 잠금장치가 없는지
- 어제 마감할 때 평소와 다르게 문을 닫지는 않았는지

# 배터리와 전원 연결부터 보세요
상가 도어락은 건전지 방식과 전원 연결 방식이 섞여 있습니다. / 건전지 방식이면 비상 단자에 9V 건전지를 대 보는 방법이 있습니다.
전원을 연결해서 쓰는 제품이라면 건물 전기가 나갔는지도 같이 봐야 합니다. / 가게 안 다른 전기는 들어오는데 문만 안 열리면 도어락 문제입니다.

# 직접 해보지 않는 편이 나은 것들
급한 마음에 유리문을 밀거나 문틀을 벌리면 유리가 깨지거나 문틀이 휘기도 합니다. / 가게 문은 손상되면 수리 시간이 길어지는 경우가 많습니다.
도구로 억지로 여는 것보다 상하지 않게 여는 편이 결국 빠릅니다. / 전화 주시면 문 상태를 듣고 필요한 장비를 챙겨 갑니다.
@ 봉담읍 상가 유리문 도어락 개문

# 전화할 때 알려주시면 좋은 정보
위치와 문 종류를 알려주시면 도착 시간이 줄어듭니다.
- 상가가 있는 건물 위치와 층
- 문 종류(유리문, 철문, 목문)
- 도어락 모양과 번호판 상태
- 안쪽에 사람이나 돈, 물건 때문에 급한 사정이 있는지

# 가게 주인인지 확인하는 방법
문을 여는 일이라 가게 주인이나 직원인지 먼저 확인합니다. / 사업자등록증, 임대차계약서, 건물 관리인 확인 중 하나면 됩니다.
직원이 대신 연락했다면 사장님과 통화로 확인하는 방법도 있습니다. / 미리 준비해 두면 도착한 뒤 지체 없이 진행할 수 있습니다.

# 비용은 시작 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮으면 시작하고, 아니면 돌아갑니다.
못 열면 비용은 받지 않습니다. / 작업 중 부품 교체가 필요하면 바꾸기 전에 다시 여쭤봅니다.
@ 봉담읍 사무실 도어락 점검 출장열쇠

# 장사를 쉬는 시간 줄이기
가게는 문이 열려야 매출이 생기는 곳이라 시간이 곧 돈입니다. / 출장 연락을 먼저 하고, 기다리는 동안 안에서 할 수 있는 준비를 같이 해 두세요.
영업 시작 전이라면 손님이 오기 전에 마무리할 수 있도록 도착 시간을 먼저 말씀드립니다. / 작업이 길어질 것 같으면 임시로 잠그고 나중에 다시 점검하는 방법도 상담해 드립니다.
@ 봉담읍 가게 문 열기 작업

# 마감할 때 습관 하나
문을 닫고 나갈 때 도어락이 제대로 잠겼는지 한 번만 확인해 보세요. / 번호판 불빛이 꺼지고 걸쇠가 들어가는 소리가 나는지 보면 됩니다.
카드나 번호를 쓰는 가게라면 마감 때 사용자 기록이 남는지도 알아 두면 좋습니다. / 이런 작은 확인이 아침에 문 앞에서 막히는 일을 줄여 줍니다.

# 열린 뒤에는 가게 도어락 점검까지
문이 열려도 원인을 모르면 내일 같은 일이 생깁니다. / 열고 나서 번호판, 모터, 걸쇠 상태를 같이 봅니다.
부품 하나만 고치면 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 정리합니다. / 너무 오래돼서 불안하면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 직원이 여럿인 가게의 비밀번호 관리
직원이 자주 바뀌는 가게는 번호를 한 번 정하고 계속 쓰기 쉽습니다. / 그만둔 직원이 번호를 알고 있다면 바꾸는 편이 안전합니다.
번호 변경 날짜를 달력에 적어 두고 분기마다 점검하면 편합니다. / 카드나 지문을 쓰는 제품이면 퇴사자 등록을 지우는 것도 잊지 마세요.

# 봉담읍 말고 화성 전역 다닙니다
봉담읍 안은 물론 향남, 남양, 동탄, 병점까지 화성 전역을 다닙니다. / 새벽이나 한밤 가게 문 문제도 24시간 전화를 받습니다.
다니는 동네는 [화성시 출장열쇠](hwaseong.html)에서 보실 수 있고, 진행 방식은 [이용안내](guide.html)에 있습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도를 참고해 주세요.

? 영업시간 중에도 오시나요? | 24시간 받습니다. 영업 중이어도 전화 주시면 최대한 빨리 가겠습니다.
? 못 열면 비용이 드나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 가게 주인이 아니라 직원인데 괜찮나요? | 사장님과 확인이 되면 진행할 수 있습니다. 연락처를 준비해 주세요.
? 도어락 교체도 같이 가능한가요? | 네, 열고 난 뒤 상태를 보고 말씀드린 다음에 진행합니다.

# 마무리
봉담읍에서 가게 문이 안 열리면 억지로 열지 마시고 번호판과 잠금 위치부터 확인해 주세요. / 확인해도 안 되면 위치와 문 종류만 알려주시면 바로 말씀드립니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 전화를 받습니다. / 급하시면 010-3664-5455로 연락 주세요.
