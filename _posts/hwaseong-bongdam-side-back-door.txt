# 앞문보다 뒷문이 더 자주 방치됩니다
봉담읍에서 집이나 가게를 쓰다 보면 앞문은 매일 쓰지만 뒷문과 쪽문은 가끔만 열게 됩니다. / 그래서 막상 열려고 하면 뻑뻑하거나 열쇠가 어디 있는지 모르는 일이 생깁니다.
이 글은 뒷문, 쪽문, 후문 잠금장치가 말썽일 때 원인별로 확인할 것과 [화성 출장열쇠](hwaseong.html)를 부르는 요령을 적었습니다.
@ 봉담읍 뒷문 쪽문 잠금장치 출장열쇠

# 뒷문의 종류부터 구분해 보세요
뒷문이라고 해도 형태가 여러 가지입니다. / 어떤 문인지에 따라 잠금장치와 고장 원인이 다릅니다.
- 주택이나 상가 뒤쪽의 철제 문
- 계단 쪽으로 나가는 방화문 성격의 문
- 마당이나 베란다로 이어지는 유리 미닫이
- 가게 직원이 쓰는 후문
- 다세대주택의 쪽문 대문
문 종류를 알면 전화 한 통으로 필요한 장비를 정리할 수 있습니다.
봉담읍처럼 주택과 상가가 함께 있는 생활권에서는 같은 건물 안에서도 앞문과 뒷문의 잠금 방식이 다른 경우가 많습니다.

# 안 쓰던 문은 녹과 먼지가 먼저 막습니다
오래 열지 않은 뒷문은 열쇠 구멍에 먼지가 쌓이거나 안쪽이 녹슬어 있는 경우가 많습니다. / 열쇠가 들어가긴 하는데 돌아가지 않는 상태가 흔합니다.
이때 무리하게 힘을 주면 열쇠가 부러질 수 있습니다. / 살짝 돌려 보고 뻑뻑하면 멈추고, 열쇠에 흑연 가루 같은 마른 윤활제를 소량 쓰는 방법도 있습니다.
기름 스프레이는 먼지를 끌어들여 오히려 나중에 더 막힐 수 있으니 권하지 않습니다.
열쇠 자체가 휘었거나 닳았는지도 보세요. 오래된 복사본 열쇠는 처음부터 모양이 정확하지 않아 잘 돌아가지 않기도 합니다.

# 열쇠가 돌아가지 않을 때 먼저 할 일
열쇠를 꽂은 채 살짝 위아래로 흔들며 돌려 보세요. / 문이 문틀에 눌려 있으면 열쇠가 걸리는 경우가 있습니다.
문을 안쪽으로 살짝 밀면서 돌리면 걸쇠 압력이 줄어들어 풀리기도 합니다. / 그래도 안 되면 억지로 돌리지 말고 그대로 두세요.
열쇠가 부러지면 일이 커지므로 몇 번 시도해서 안 되면 멈추는 게 좋습니다.

# 안 잠기는 뒷문은 문틀 쪽 걸쇠를 봅니다
열리는 것 못지않게 안 잠기는 것도 불편합니다. / 닫아도 걸쇠가 문틀 구멍에 맞지 않아 헛도는 경우가 많습니다.
문이 처졌거나 경첩이 느슨해지면 문틀 구멍과 위치가 어긋납니다. / 경첩 나사를 조여 보고 문이 평평하게 닫히는지 확인해 보세요.
계절에 따라 문이 부풀거나 줄어드는 철문도 있어서, 여름과 겨울의 닫힘이 다를 수 있습니다.
바닥 쪽이 긁히는 흔적이 있다면 문이 처졌다는 증거입니다. 이 경우 잠금장치만 바꿔서는 해결되지 않고 경첩 위치를 함께 봐야 합니다.

# 후문 도어락을 쓰는 가게와 사무실
직원 출입용 후문에 도어락을 달아 둔 곳은 번호가 오래 바뀌지 않는 경우가 많습니다. / 일하던 사람이 떠났는데 번호가 그대로면 보안에 빈틈이 생깁니다.
번호를 바꾸는 일은 길어야 몇 분이면 끝납니다. / 번호를 바꾸는 순서는 [도어락 설치](doorlock-install.html) 안내를 참고하세요.
후문은 평소 눈에 덜 띄어 배터리 교체도 잊기 쉽습니다. / 앞문과 같은 날 교체 날짜를 정해 두세요.


영업 중에 뒷문이 막히면 손님이 불편하지 않게 앞문을 먼저 정리해야 합니다. / 쓰레기를 내놓으러 나갔다가 뒷문이 닫혀 버린 경우가 가장 흔합니다.
이럴 때 문 사이에 작은 받침을 끼워 두는 습관이 도움이 됩니다. / 이미 닫혔다면 뒷문 쪽 상황을 그대로 설명해 주세요.
주방처럼 불이 켜진 상태라면 먼저 알려 주세요. 안전을 위해 작업 순서를 조정합니다.
영업이 끝난 뒤 문을 닫고 나오는 분들은 마지막에 뒷문을 한 번 더 확인하는 습관이 있으면 좋습니다.

# 마당 쪽문과 대문형 쪽문은 따로 봅니다
단독주택이나 다세대주택에서 마당으로 이어지는 쪽문은 바깥 날씨를 그대로 맞습니다. / 비와 햇빛에 노출되어 부식이나 변형이 빨리 옵니다.
잠금장치가 걸려 있는 부분이 뻑뻑하면 문이 휘어 있을 수도 있습니다. / 이런 철제 쪽문은 문틀을 다시 맞춰야 하는지 보고 판단합니다.
대문 종류의 점검은 [도어락 수리](doorlock-repair.html)에서 어떤 방식으로 진행하는지 볼 수 있습니다.
@ 봉담읍 쪽문 철문 걸쇠 확인

# 전화하실 때 알려주세요
뒷문은 위치가 헷갈리기 쉬워서 설명이 정확해야 합니다. / 아래를 같이 알려 주세요.
- 건물 뒤쪽 어느 방향인지, 골목 이름 대신 눈에 띄는 표지
- 문의 재질(철문, 나무문, 유리문)과 잠금 방식
- 열쇠를 쓰는지 번호 방식인지
- 안에 사람이 있는지, 불이 켜져 있는지
- 사진 한두 장
사진은 문 전체와 잠금장치 가까이를 한 장씩 보내 주시면 좋습니다.
밤이라 어두우면 휴대폰 손전등으로 비춰 찍어 주세요. 잠금장치 모양이 보이면 준비가 훨씬 정확해집니다.

# 사시는 분이나 운영하시는 분인지 확인합니다
뒷문이든 앞문이든 열기 전에 확인 절차는 같습니다. / 신분증 주소, 주소가 나온 우편물, 사업자 관련 서류, 관리사무소 확인 중 가능한 것을 준비해 주세요.
상가라면 임대 계약서나 영업과 관련된 서류를 보여 주시면 수월합니다. / 임대인과 임차인이 다르면 해당 문을 관리하는 분의 확인도 필요할 수 있습니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 잠금장치를 보고 비용을 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 다시 여쭙습니다. 진행 방식은 [이용안내](guide.html)에서 볼 수 있습니다.

# 열고 난 뒤 같이 점검하는 곳
문이 열리면 잠금장치가 매끄럽게 움직이는지 같이 확인합니다. / 안 잠기는 문이라면 문틀 구멍과 걸쇠 위치도 맞춰 봅니다.
고쳐 쓸 수 있으면 교체는 권하지 않습니다. / 너무 낡아 믿기 어려운 잠금장치라면 [도어락 교체](doorlock-replace.html) 안내를 따로 드립니다.
뒷문은 눈에 덜 띄는 만큼 잠금이 약하면 불편함이 커지니 이 기회에 점검해 두세요.
@ 봉담읍 후문 잠금장치 점검 후 정상

# 뒷문 오래 쓰는 관리법
- 석 달에 한 번 열쇠를 꽂아 돌려 보며 뻑뻑함 확인
- 경첩과 문틀 나사를 계절이 바뀔 때 점검
- 비 오는 날 문 아래쪽 물빠짐 상태 확인
- 쓰는 열쇠는 누가 가졌는지 정리
쓰지 않는 문일수록 열려 있는 상태로 두지 말고 가끔 잠금과 해제를 반복해 두세요. / 오래 멈춘 부품은 한 번 움직이는 것만으로도 뻑뻑함이 줄어듭니다.

# 봉담읍 말고 화성 다른 동네도 갑니다
봉담읍 가까이의 기배동, 새솔동, 남양읍은 물론 향남읍, 병점, 동탄까지 화성 안이면 다닙니다. / 24시간 전화를 받습니다.
다니는 곳은 [화성시 출장열쇠](hwaseong.html)에, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
