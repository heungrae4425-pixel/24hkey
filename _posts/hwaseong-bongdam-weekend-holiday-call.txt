# 쉬는 날에 하필 문이 안 열립니다
봉담읍은 평일엔 출퇴근으로 바쁘다가 주말이면 가족 나들이로 집을 비우는 분이 많은 곳입니다. / 그런 쉬는 날에 도어락이 먹통이 되면 어디에 연락해야 하나 막막합니다.
관공서도 쉬고 관리사무소도 연락이 잘 안 닿는 날이 있어 더 난감합니다. / 이 글은 주말과 공휴일에 문이 안 열릴 때 침착하게 연락하는 순서를 적었습니다.
@ 봉담읍 주말 공휴일 출장열쇠 현관문

# 쉬는 날이라도 먼저 확인할 세 가지
전화를 걸기 전에 지금 상태를 간단히 살펴보세요. / 원인이 단순하면 전화 한 통으로 해결되기도 합니다.
- 번호판에 불이 들어오는지
- 비밀번호를 눌렀을 때 소리가 나는지
- 문을 살짝 밀면서 손잡이를 돌리면 움직이는지
이 세 가지만 알려 주셔도 전화 상담이 훨씬 빨라집니다. / 확인하는 동안 손잡이를 억지로 꺾지 않는 것만 기억해 주세요. / 불이 안 들어오면 배터리, 소리는 나는데 안 열리면 모터나 걸쇠 쪽일 가능성이 큽니다.

# 연휴 직전에 문제가 몰리는 이유
연휴 앞뒤로 집을 오래 비우면 도어락 배터리가 방전된 걸 모르고 나갔다가 돌아와서 알게 되는 일이 있습니다. / 비어 있는 동안에도 도어락은 조금씩 전기를 쓰기 때문입니다.
반대로 명절에 가족이 모이면 평소 안 쓰던 비밀번호를 여러 사람이 눌러 대다가 입력 제한이 걸리기도 합니다. / 이런 경우 잠시 기다리면 풀리는 제품이 많습니다.
쉬는 날일수록 사람이 오가는 일이 많다는 점을 염두에 두세요.
손님이 오가는 집이라면 누가 마지막에 문을 잠갔는지, 안쪽 보조키를 누가 눌렀는지도 떠올려 보세요. / 가족 중 한 명이 이미 집 안에 있을 수도 있으니 전화부터 돌려 보는 것도 방법입니다.

# 전화 주실 때 이 순서로 말씀해 주세요
급할수록 한 번에 많이 말하기보다 순서대로 알려 주시는 편이 좋습니다. / 아래 순서면 통화가 짧게 끝납니다.
- 위치, 단지 이름과 동, 호수
- 문 상태, 번호판이 어떤지
- 지금 문 앞인지, 어디서 기다리는지
- 집 안에 사람이나 반려동물이 있는지
통화하는 동안 문 앞에서 기다리기 어렵다면 근처 편안한 곳에서 기다리셔도 됩니다. / 도착 시간은 전화로 먼저 안내드립니다.
연락이 끊기지 않도록 휴대폰 배터리가 얼마 남았는지도 확인해 두세요. / 통화가 끊기면 같은 번호로 다시 걸어 주시면 됩니다.

# 봉담읍 위치 설명은 생활권으로 충분합니다
봉담읍은 범위가 넓어서 어느 쪽인지 대략 알려 주시면 길 안내가 수월합니다. / 정확한 주소는 문자로 받을 수 있으니 말이 어렵다면 문자를 보내 주세요.
가까운 큰 도로나 마트, 정류장처럼 눈에 띄는 곳을 하나 말씀해 주시면 헤매지 않고 찾아갈 수 있습니다. / 건물 입구에 공동현관 비밀번호가 있다면 그것도 미리 알려 주세요.
공동현관이 안 열려서 못 들어간다면 경비실이나 이웃에게 먼저 도움을 청해 보는 방법도 있습니다.

# 배터리 문제라면 편의점에서 해결되기도 합니다
번호판이 꺼졌다면 9V 건전지를 바깥쪽 비상 단자에 대 보세요. / 대고 있는 동안 전원이 들어와 번호를 누를 수 있는 제품이 많습니다.
공휴일에도 편의점은 대부분 열려 있어서 건전지를 사기는 어렵지 않습니다. / 단자가 안 보이거나 대도 반응이 없으면 그때 전화 주세요.
문이 열리면 안쪽 배터리를 전부 새것으로 교체하는 것까지 해 두세요.
@ 봉담 도어락 배터리 비상 전원 9V

# 급하다고 문을 세게 다루지 마세요
쉬는 날 약속이 있어 급한 마음에 문을 당기거나 두드리는 분이 있습니다. / 이러면 걸쇠가 더 꽉 물리거나 손잡이 축이 틀어질 수 있습니다.
드라이버나 카드를 문틈에 넣는 것도 문틀과 도어락 외관을 상하게 합니다. / 그대로 두고 전화 주시는 게 결과적으로 더 빠릅니다.
비밀번호를 여러 번 틀리면 입력이 한동안 막히니, 몇 번 해 보고 안 되면 멈추는 게 좋습니다.

# 사시는 분 확인은 쉬는 날에도 똑같습니다
문을 여는 일이라 주말이든 공휴일이든 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있는 경우가 문제인데, 그럴 때는 관리사무소나 경비실에 세대 확인을 부탁해 보세요. / 쉬는 날이라 관리사무소가 닫혔다면 경비실이 도움이 될 수 있습니다.
휴대폰에 저장된 공과금 고지서나 택배 내역 같은 것도 참고가 되니 함께 알려 주세요.
확인 절차가 길어 보여도 사시는 분을 지키는 일이라 생략하지 않습니다. / 미리 준비해 두면 도착하자마자 바로 작업에 들어갈 수 있습니다.

# 비용은 문 열기 전에 말씀드립니다
쉬는 날이라고 다른 기준을 쓰는 것은 아닙니다. / 현관문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다.
괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다. / 못 열면 비용은 받지 않습니다.
부품을 바꿔야 할 때는 바꾸기 전에 다시 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 최대한 상하지 않게 열어 드립니다
도어락과 문틀을 상하지 않게 하는 방법부터 차례로 시도합니다. / 문 종류에 따라 시간이 달라지니 도착 후에 예상 시간을 알려 드립니다.
작업 중에 교체가 필요한 부품이 보이면 손대기 전에 먼저 말씀드립니다. / 쉬는 날이라 바쁜 일정이 있으시면 먼저 말씀해 주세요. 가능한 범위에서 맞춰 보겠습니다. / 개방 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 열린 뒤 쉬는 날에 마무리할 것
문이 열리면 다시 잠기고 열리는지 함께 확인합니다. / 배터리가 원인이었다면 새것으로 바꾸고 날짜를 적어 두세요.
비밀번호를 잊었다면 새 번호를 등록하고 예전 번호는 지웁니다. / 가족이 번호를 모르면 또 문 앞에서 막히니 같이 공유해 두세요.
고장이 반복된다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래됐을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 봉담읍 도어락 점검 열쇠집 24시

# 연휴 전에 미리 해 두면 좋은 점검
연휴 시작 전에 도어락을 한 번 점검하면 쉬는 날 문 앞에서 막히는 일을 줄일 수 있습니다.
- 배터리 잔량 표시가 있는 제품이라면 확인
- 경고음이 났다면 연휴 전에 교체
- 열쇠를 가진 사람이 누구인지 확인
- 비상용 9V 건전지를 가방이나 차에 한 개 준비
- 보조키와 걸쇠가 잘 움직이는지 확인
여행을 갈 때는 도어락 알림 설정이나 비밀번호를 가족과 같이 정해 두세요.

# 봉담읍 말고 화성 어디든 갑니다
봉담읍 옆 향남읍, 남양읍, 병점동, 새솔동, 동탄 지역도 다닙니다. / 화성 안이면 요일과 시간 상관없이 24시간 출동합니다.
[화성시 출장열쇠](hwaseong.html) 페이지에 다니는 동네가 있고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 새벽에도 전화해도 되나요? | 물론입니다. 시간 신경 쓰지 말고 전화 주세요.
