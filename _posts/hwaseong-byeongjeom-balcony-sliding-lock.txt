# 현관이 아니어도 문은 잠깁니다
병점동은 병점역을 중심으로 출퇴근하는 분들이 많은 동네입니다. / 현관문 고장은 다들 신경 쓰지만 베란다 문이나 방문이 잠겨서 곤란한 경우도 의외로 많습니다.
빨래를 널러 나갔다가 미닫이문이 닫히며 잠금이 걸리거나, 방문 손잡이가 안쪽에서 돌아가지 않는 일이 대표적입니다. / 현관과 달리 구조가 단순해 보여도 원인을 잘못 짚으면 문이나 창틀이 상합니다.
이 글은 병점동에서 베란다, 미닫이, 방문의 잠금장치가 말을 듣지 않을 때를 정리한 글입니다. / 현관이 잠긴 상황은 [화성 출장열쇠](hwaseong.html)에서 따로 보실 수 있습니다.
@ 병점동 베란다 미닫이문 잠금장치

# 어떤 잠금장치인지부터 구분해 보세요
집 안의 잠금은 이름은 같아도 구조가 서로 다릅니다. / 어느 유형인지에 따라 쓰는 방법이 완전히 달라집니다.
- 베란다 미닫이문의 크레센트 방식 걸이쇠
- 창틀 위쪽에 달린 보조 잠금이나 안전 고리
- 방문에 달린 버튼식, 돌림식 손잡이 잠금
- 욕실 문에 있는 동전이나 작은 홈으로 푸는 잠금
유형을 말씀해 주시면 전화 통화만으로 대략의 난이도를 가늠할 수 있습니다. / 사진을 문자로 보내 주시면 정확도가 더 올라갑니다.

# 베란다 문이 바깥에서 잠겼을 때
베란다에 나가 있는 동안 바람에 문이 닫히고 걸이쇠가 내려오는 경우가 있습니다. / 이럴 때 급해서 유리를 두드리거나 창틀을 밀면 유리가 깨질 위험이 있습니다.
먼저 휴대폰이 있는지 확인하고 가족이나 이웃에게 연락해 안쪽에서 열어 달라고 부탁해 보세요. / 걸이쇠는 안쪽에서 위로 올리기만 하면 되는 경우가 대부분입니다.
혼자 갇힌 상황이라면 실외기 쪽이나 난간 가까이로 몸을 숙이지 마세요. / 잠깐 불편한 것보다 안전이 먼저입니다.

# 레일이 틀어져 문이 안 밀릴 때
잠금이 아니라 문이 레일에서 빠졌거나 롤러가 닳아 안 밀리는 경우도 많습니다. / 문을 한쪽으로 밀 때 걸리는 느낌이 있고 소리가 거칠다면 레일 쪽 이물질이 원인일 수 있습니다.
- 레일 홈에 쌓인 먼지와 머리카락을 칫솔로 먼저 쓸어내기
- 문짝을 살짝 들어 올리며 밀어 보기
- 롤러가 한쪽만 닳은 것처럼 문이 기울어 보이는지 보기
억지로 밀면 롤러 축이 휘거나 유리 끼움 틀이 어긋납니다. / 청소해도 그대로면 그 자리에서 멈추고 문의해 주세요.

# 방문 잠금이 풀리지 않는 흔한 상황
방문 손잡이에는 작은 구멍이나 홈이 있는 것이 많습니다. / 안쪽 잠금 버튼을 누른 채 닫혀서 밖에서 열기 위한 비상 구멍이 대부분 있습니다.
가느다란 핀이나 동전으로 홈을 돌리면 풀리는 경우도 있으니 먼저 확인해 보세요. / 손잡이 형태가 눌러서 푸는 방식이면 얇은 막대를 구멍에 똑바로 밀어 넣어 보시는 방법도 있습니다.
손잡이가 아예 헛돌면 힘으로 문을 밀지 마세요. / 방문 틀은 현관 틀보다 얇아서 쉽게 갈라집니다.
@ 병점역 근처 방문 손잡이 잠금 해제

# 아이가 방 안에서 잠근 경우
아이가 방 안에서 버튼을 눌러 잠그고 못 여는 경우도 있습니다. / 아이가 울거나 당황해 있으면 무엇보다 문 너머에서 침착하게 말을 걸어 주세요.
손잡이 아래쪽 버튼을 다시 눌러 보라고 천천히 안내하는 것도 방법입니다. / 그래도 안 되면 아이를 안심시키며 바로 연락 주세요. 이 경우는 가장 먼저 출동 순서를 잡습니다.
방 안에 아이만 있다면 창문이나 베란다 쪽이 열려 있는지도 같이 알려주셔야 합니다. / 안전 확인이 먼저이기 때문입니다.

# 병점동 위치와 상황 전달 요령
병점동은 병점역 서쪽과 동쪽의 생활권이 나뉘어 길 설명이 헷갈리기 쉽습니다. / 아파트나 빌라 건물 형태와 동, 호수를 말씀하시고 병점역 어느 쪽인지 덧붙여 주세요.
- 잠긴 곳이 베란다인지, 방문인지, 화장실 문인지
- 문이 밀리는지 아예 안 움직이는지
- 잠금 버튼이나 걸이쇠가 어느 위치에 있는지
- 문 너머에 사람이나 반려동물이 있는지
- 유리가 깨졌거나 금이 간 부분이 있는지
유리에 금이 갔다면 그 부분은 만지지 마시고 그대로 말씀해 주세요. / 작업 방법이 달라지기 때문입니다.

# 도착하면 가장 먼저 신분 확인
집 안 문이라도 남의 집 문을 여는 일이라는 점은 같습니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나는 꼭 필요합니다.
세입자나 가족 모두 같은 절차를 거칩니다. / 확인이 안 되면 작업할 수 없다는 점을 미리 알아 두시면 좋겠습니다.

# 비용은 문을 보고 먼저 말씀드립니다
잠금 부품만 풀면 되는지, 교체까지 해야 하는지에 따라 달라집니다. / 현장에서 상태를 보고 시작하기 전에 먼저 말씀드립니다.
마음에 안 드시면 그냥 돌아가시라고 해도 괜찮습니다. / 끝내 못 열면 비용은 받지 않습니다.
작업 중 새 부품이 필요하면 따로 여쭙니다. / 자세한 진행은 [이용안내](guide.html)에 있습니다.

# 문과 틀을 안 상하게 여는 순서
미닫이문과 방문은 부품이 작고 틀이 얇아서 힘을 쓰면 바로 흔적이 남습니다. / 그래서 틀에 닿지 않는 방법부터 시도하고 정 안 되면 그다음 방식을 고릅니다.
유리문이라면 유리에 압력이 가지 않는 쪽을 먼저 고려합니다. / 방문은 손잡이 구멍과 래치의 위치를 보고 맞는 도구를 고릅니다.
현관 쪽 개방 방식은 [현관문 개문](door-open.html)에서 읽어 보실 수 있고 원리는 비슷합니다. / 모든 작업에서 파손 없이 여는 것을 우선합니다.
@ 병점동 미닫이 방문 잠금 비파손 개방

# 열린 뒤 확인할 점
문이 열리면 잠금장치가 제대로 걸리고 풀리는지 몇 번 더 눌러 확인합니다. / 걸이쇠의 맞물림이 느슨하면 바람에 쉽게 풀리거나 다시 걸립니다.
레일 롤러가 닳았다면 [도어락 수리](doorlock-repair.html)와는 별개로 부품 교체가 필요할 수 있습니다. / 필요한 경우 구체적인 방법은 현장에서 말씀드립니다.
방문 손잡이를 새로 바꾸는 경우에는 문 두께와 구멍 크기가 맞는지 살펴야 합니다. / 이 부분은 [도어락 설치](doorlock-install.html)에서 자세히 설명해 두었습니다.

# 자주 잠기는 집에서 해둘 수 있는 일
같은 문이 반복해서 잠긴다면 습관이나 구조에 원인이 있습니다. / 아래를 한 번 확인해 보세요.
- 베란다 문 걸이쇠가 헐거운지 한 번씩 확인
- 레일 청소는 계절이 바뀔 때마다 한 번
- 방문 비상 핀을 눈에 띄는 서랍에 보관
- 아이 방 잠금은 아이 손이 닿는 높이인지 점검
작은 부품 하나가 느슨해지면서 잠금이 엇갈리는 경우가 많습니다. / 일찍 손보면 큰 작업이 필요 없습니다.

# 병점동 밖으로도 화성 전역 출동
병점동 옆으로 진안동, 기배동, 새솔동은 물론 동탄 쪽 반송동, 능동, 청계동도 다닙니다. / 봉담읍, 향남읍, 남양읍까지 화성 어디든 가능합니다.
동네 목록은 [화성시 출장열쇠](hwaseong.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
