# 병점역 앞에서 번호가 떠오르지 않을 때
병점동은 병점역을 중심으로 오래된 주택과 아파트가 함께 있는 동네입니다. / 오랜만에 부모님 댁이나 이사 온 집에 들어가려는데 번호가 안 떠오르는 일이 생각보다 흔합니다.
이 글은 병점동에서 비밀번호를 잊었을 때 먼저 해볼 것과, 안 될 때 [화성 출장열쇠](hwaseong.html)가 어떻게 문을 여는지 순서대로 적었습니다. / 급하시면 3번부터 보셔도 됩니다.
@ 병점동 도어락 비밀번호 분실 출장열쇠

# 번호를 모르게 되는 흔한 경우
번호를 잊는 이유는 몇 가지로 나뉩니다. / 이유에 따라 방법이 달라지니 먼저 어디에 해당하는지 보세요.
- 새 번호로 바꾼 지 얼마 안 돼 헷갈리는 경우
- 가족이 바꾼 번호를 전달받지 못한 경우
- 오래 비운 집이라 기억이 흐려진 경우
- 번호를 몇 번 틀려 입력이 막힌 경우

병점동에는 가족이 오래 같이 산 집이 많아 번호를 누가 바꿨는지 기억이 엇갈리는 일도 많습니다. / 부모님 댁이라면 어머니와 아버지, 형제가 각자 다른 번호를 기억하고 있기도 합니다.
먼저 가족에게 한 번씩 물어보고, 서로 다른 번호가 나오면 차례대로 한 번씩만 눌러 보세요. / 한 사람의 번호만 계속 누르는 것보다 훨씬 안전합니다.

# 몇 번만 더 눌러 보는 건 괜찮습니다
기억나는 후보가 있다면 두세 번까지는 눌러 보셔도 됩니다. / 하지만 계속 틀리면 도어락이 입력을 막고 경고음을 내기도 해서 그만두는 게 좋습니다.
생일, 전화번호 뒷자리, 이전 집 번호처럼 가족이 흔히 쓰는 조합을 떠올려 보세요. / 다만 한 번 막히면 풀릴 때까지 기다려야 합니다.

# 집 안에 사람이 있으면 가장 쉽습니다
가족이 집에 있다면 전화로 안쪽에서 열어 달라고 하시는 게 제일 빠릅니다. / 안쪽에서는 손잡이를 돌리면 열리기 때문에 번호가 필요 없습니다.
- 전화나 문자로 가족에게 알리기
- 공동현관 비밀번호가 필요하면 함께 확인하기
- 관리사무소나 경비실에 도움 요청하기

# 번호 대신 열쇠나 카드가 있는지 보세요
키 구멍이 있는 도어락은 덮개 아래 열쇠 구멍으로 열 수 있습니다. / 카드키나 태그가 있는 제품이면 가방이나 지갑 안에 하나쯤 있을 수 있습니다.
비상용 열쇠를 이웃이나 부모님께 맡겨 둔 분도 많습니다. / 전화 한 통으로 해결될 수 있으니 한 번 떠올려 보세요.
@ 병점역 근처 도어락 열쇠 카드 확인

# 그래도 안 열리면 출장열쇠를 부르세요
위 방법이 모두 어렵다면 억지로 열려고 하지 마시고 전화 주세요. / 도어락과 문틀이 상하지 않게 덜 상하는 방법부터 차례로 해봅니다.
상황과 도어락 모양만 알려주시면 출동 여부를 바로 말씀드립니다. / 사진을 보내주시면 맞는 장비를 챙겨 가기 쉽습니다.

# 전화로 이 정도만 알려주세요
- 병점동 어디쯤인지 (동, 호수, 가까운 역 방향)
- 도어락 모양 (손잡이 일체형, 버튼형, 푸시풀형)
- 번호판이 켜지는지, 경고음이 나는지
- 집 안에 아이나 반려동물이 있는지

병점동 오래된 주택은 공동현관이 없고 대문이 따로 있는 경우도 많습니다. / 대문 열쇠와 현관 도어락 번호를 둘 다 모르는 상황이면 대문부터 열어야 하니 미리 알려 주세요.
대문이 잠겨 있는지, 인터폰으로 열리는지, 함께 말씀해 주시면 출동 준비가 한결 빨라집니다. / 가족에게 누가 대문 열쇠를 갖고 있는지 먼저 확인해 보시는 것도 방법입니다.

# 사시는 분인지 확인하는 절차가 있습니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
이웃과 손님을 지키기 위한 절차라 양해 부탁드립니다. / 확인이 안 되면 작업을 할 수 없습니다.

# 비용은 열기 전에 먼저 말씀드립니다
문 상태를 본 뒤 비용을 먼저 말씀드리고, 동의하시면 시작합니다. / 마음에 안 드시면 그냥 돌아가도 됩니다.
문을 못 열면 비용은 받지 않습니다. / 열고 나서 붙는 추가 비용도 없습니다.
@ 병점동 출장열쇠 24시간 현관문 개문

# 열고 나면 새 번호부터 등록합니다
번호를 잊어서 연 경우에는 안쪽에서 새 번호를 등록하는 것까지 같이 합니다. / 기존 번호는 지우고 새 번호만 남겨 둡니다.
새 번호는 가족이 모두 아는 것으로, 너무 쉬운 숫자 나열은 피하세요. / 도어락 사용법도 짧게 알려드립니다.

새로 정한 번호는 숫자 자체보다 떠올리는 방법을 하나 정해 두면 오래 갑니다. / 예를 들어 가족이 함께 아는 날짜를 변형하는 식으로 규칙을 만들어 두세요.
다만 그 규칙을 문 앞이나 현관 메모에 그대로 적어 두는 것은 피하셔야 합니다. / 남이 짐작하지 못하면서 가족은 떠올릴 수 있는 정도가 가장 좋습니다.

# 번호를 다시 잊지 않는 방법
- 가족 단체방에 번호를 적어 두지 말고 따로 기억해 둘 수 있게 정하기
- 비상용 카드키나 열쇠 하나를 믿을 만한 곳에 맡겨 두기
- 번호를 바꿀 때는 가족 모두에게 같은 날 알리기
- 어른 둘 이상이 아는 번호를 쓰기

# 병점동 말고 화성 어디든 갑니다
병점동 바로 옆 진안동, 기배동, 동탄까지 다니고, 봉담, 향남, 남양도 갑니다. / 시간 상관없이 24시간 출동합니다.
다니는 동네는 [출장 지역](area.html) 지도에 있고, 문 여는 방식은 [현관문 개문](door-open.html)에 적었습니다. / 번호만 바꾸고 싶다면 [도어락 수리](doorlock-repair.html)나 [이용안내](guide.html)를 참고하세요.

? 도어락이 망가지나요? | 덜 상하는 방법부터 하며, 부품을 바꿔야 하면 바꾸기 전에 먼저 말씀드립니다.
? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다.
? 열고 나서 번호도 바꿔 주나요? | 네, 새 번호 등록까지 같이 합니다.
