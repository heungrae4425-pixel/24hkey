# 병점동 원룸 문 앞에서 막혔을 때
병점동은 병점역을 중심으로 원룸과 오피스텔이 모여 있어 혼자 사는 분이 많은 동네입니다. / 퇴근하고 돌아왔는데 방문 앞에서 문이 안 열리면 "이 시간에 누구에게 연락하지" 하는 생각부터 듭니다.
이 글은 병점동 원룸·오피스텔 출입문이 잠겼을 때 전화하기 전에 확인할 것을 순서대로 적었습니다. / 그다음 [화성 출장열쇠](hwaseong.html)를 부르면 어떻게 진행되는지도 함께 정리했습니다.
@ 병점동 원룸 오피스텔 출입문 출장열쇠

# 원룸·오피스텔 문이 잠기는 흔한 경우
작은 방이라 문 하나가 곧 전부입니다. / 그래서 문이 잠기면 생활이 바로 멈춥니다.
- 열쇠나 카드를 방 안에 두고 문을 닫은 경우
- 도어락 배터리가 다 돼서 번호판이 꺼진 경우
- 번호를 눌러도 반응이 없거나 경고음만 나는 경우
- 문이 덜 닫힌 채로 걸쇠가 걸려 버린 경우

# 건물 공동 현관과 내 방 문은 따로입니다
오피스텔은 건물 현관, 엘리베이터, 내 방 문이 각각 따로 잠깁니다. / 어디서 막혔는지 먼저 구분해 주시면 필요한 장비가 달라집니다.
공동 현관은 관리사무소나 경비실에서 열어 주는 경우가 많습니다. / 내 방 문이 문제라면 그때부터 출장열쇠가 필요합니다.

# 전화하기 전 확인할 세 가지
아래 세 가지만 보셔도 상황을 설명하기가 훨씬 쉬워집니다.
- 번호판에 손을 대면 불이 들어오는지
- 번호를 누를 때 삑 소리가 나는지
- 문손잡이가 헐겁게 돌아가는지, 아예 안 돌아가는지

# 관리실이나 집주인에게 먼저 물어볼 것
오피스텔과 원룸은 마스터키나 여분 키를 관리실에 맡겨 둔 곳이 있습니다. / 계약할 때 받은 안내문에 그런 내용이 있었는지 한 번 떠올려 보세요.
여분 키가 있으면 열쇠집을 부르지 않아도 됩니다. / 없거나 연락이 안 되는 시간이면 바로 전화 주시면 됩니다.

# 비밀번호 도어락이면 배터리부터
원룸 도어락은 번호판 아래에 9V 건전지를 대는 비상 단자가 있는 제품이 많습니다. / 병점역 근처 편의점에서도 9V 건전지를 구할 수 있는 경우가 많습니다.
건전지를 대고 번호를 눌러 열리면 안쪽 배터리를 전부 새것으로 바꿔 주세요. / 반응이 전혀 없다면 그때 연락 주시면 됩니다.

# 방 안에 휴대폰이 있는 경우
휴대폰과 열쇠가 모두 방 안에 있으면 연락할 방법부터 막힙니다. / 이웃에게 전화를 잠깐 빌려 연락하셔도 괜찮습니다.
번호는 010-3664-5455입니다. / 건물 이름과 호수, 대략적인 상황만 말씀해 주세요.
@ 병점동 원룸 현관문 도어락 개문

# 세입자도 열 수 있습니다, 본인 확인은 필수
세입자라서 집주인 허락이 꼭 있어야 하는 것은 아닙니다. / 대신 그 방에 사는 분이 맞는지 현장에서 확인합니다.
신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다. / 신분증이 방 안에 있다면 관리실에 세대 확인을 부탁해 두시면 수월합니다.

# 도착하면 이렇게 진행합니다
도착하면 도어락 종류와 문 상태를 먼저 봅니다. / 상하지 않게 여는 방법부터 차례로 해보는 것이 기본입니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 먼저 말씀드립니다. / 개문 방식은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.

# 비용은 열기 전에 말씀드립니다
상태를 보고 얼마인지 먼저 알려드린 뒤에 시작합니다. / 마음에 안 드시면 그냥 돌아가도 됩니다.
못 열면 비용은 받지 않습니다. / 열고 난 뒤에 갑자기 붙는 비용도 없습니다.
@ 병점역 근처 원룸 도어락 출장 점검

# 문을 열고 난 다음 점검
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새것으로 바꿨는지도 함께 봅니다.
자주 막히는 도어락이면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 쓸 수 있는데 바꾸라고 권하지는 않습니다.

# 퇴실할 때 도어락 정리
원룸은 사는 사람이 자주 바뀌어서 이전 세입자 번호가 남아 있는 경우가 있습니다. / 입주하자마자 번호를 새로 등록하는 것이 안전합니다.
퇴실할 때는 등록한 번호와 카드를 지우고 나가는 습관도 좋습니다. / 집주인과 번호 인수인계 방식을 미리 정해 두면 다툴 일이 줄어듭니다.

# 병점동 말고 화성 어디든 갑니다
병점동 옆 진안동, 기배동, 동탄 지역과 봉담, 향남까지 화성 전역을 다닙니다. / 늦은 밤이나 새벽이어도 24시간 전화를 받습니다.
화성에서 다니는 동네는 [화성시 출장열쇠](hwaseong.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

# 자주 묻는 질문
? 병점동 원룸 문도 열어 주나요? | 네, 원룸과 오피스텔 방문 모두 출동합니다. 건물 호수와 상황만 알려주세요.
? 밤늦게나 새벽에도 오나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 집주인에게 먼저 연락해야 하나요? | 꼭 그렇지는 않습니다. 사시는 분인지 확인되면 진행할 수 있습니다.
? 열고 나서 번호도 바꿔 주나요? | 네, 새 번호 등록과 배터리 교체까지 같이 해드립니다.

# 마무리
병점동에서 방문이 안 열리면 억지로 당기거나 두드리지 마시고 번호판 상태부터 확인해 주세요. / 확인해도 안 되면 건물과 호수만 알려주시면 바로 출동 여부를 말씀드립니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 전화를 받습니다. / [이용안내](guide.html)를 먼저 보셔도 좋고, 급하시면 010-3664-5455로 바로 연락 주세요.
