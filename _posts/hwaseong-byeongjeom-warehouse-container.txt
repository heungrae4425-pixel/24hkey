# 병점동 창고와 컨테이너 사무실 문, 주택과 뭐가 다를까
병점동은 병점역을 중심으로 주택가와 상가, 작은 작업 공간이 가까이 있는 동네입니다. / 그래서 창고나 컨테이너 사무실처럼 주택과 다른 출입문 문의도 함께 들어옵니다.
이런 문은 비바람과 먼지를 직접 맞고 열쇠를 쓰는 횟수도 많아 아파트 현관문과는 고장 모양이 다릅니다. / 이 글은 병점동의 창고·컨테이너 사무실 출입문에서 생기는 문제를 정리했습니다.
@ 병점동 컨테이너 사무실 출입문 외관

# 컨테이너 문의 구조부터 알아 두기
컨테이너 사무실의 문은 얇은 철판 문에 문틀이 용접된 경우가 많고, 창고용 문은 큰 철제 문짝에 걸이 방식 잠금이 달려 있기도 합니다. / 일반 현관문처럼 도어락 하나로 끝나는 구조가 아닌 경우가 많습니다.
- 손잡이 일체형 열쇠 잠금
- 문 바깥에 달린 자물쇠와 걸이 방식
- 컨테이너 특유의 막대 잠금장치
- 사무실용으로 개조해 단 번호키 도어락
어떤 방식인지에 따라 열 때 쓰는 방법과 준비물이 달라집니다.

# 비바람과 녹이 문제를 만듭니다
컨테이너나 창고는 여름에는 직사광선으로 달궈지고 겨울에는 얼어붙는 일이 반복됩니다. / 이런 온도 변화가 반복되면 문틀이 미세하게 뒤틀려 잠금이 어긋나기도 합니다.
야외에 있는 문은 비와 습기로 열쇠 구멍 안쪽부터 녹이 습니다. / 처음에는 열쇠가 뻑뻑하다가 어느 날 아예 안 돌아가는 일이 생깁니다.
겨울에는 구멍에 물이 얼어 열쇠가 들어가지 않기도 합니다. / 이때 뜨거운 물을 부으면 금세 다시 얼어 더 나빠지니 피해 주세요.
번호키라면 비가 번호판으로 스며들어 오작동이 생길 수 있습니다. / 마른 수건으로 닦고 잠시 두면 돌아오는 경우가 있습니다.

# 문이 안 열릴 때 먼저 확인할 것
- 열쇠가 끝까지 들어가고 돌아가는지
- 문틈에 박스나 물건이 눌려 문이 끼어 있지는 않은지
- 자물쇠가 걸이에서 풀렸는지
- 안쪽에서 누군가 걸어 잠근 건 아닌지
- 번호키라면 번호판이 켜지는지
작업장이라 여러 사람이 드나든다면 마지막으로 문을 잠근 사람에게 먼저 연락해 보세요. / 열쇠를 그분이 갖고 있을 수도 있습니다.

# 하지 말아야 할 것
급하다고 근처에서 빌린 공구를 쓰기 시작하면 상황이 더 복잡해집니다. / 시도한 방법이 있다면 숨기지 말고 먼저 말씀해 주세요.
열쇠가 돌아가지 않을 때 힘으로 비틀면 부러져 안에 박히는 경우가 있습니다. / 그러면 열쇠 구멍을 먼저 정리해야 해서 시간이 더 걸립니다.
자물쇠를 망치로 두드려 부수거나 절단하면 문과 걸이도 같이 상할 수 있습니다. / 잠금장치를 새로 달아야 하는 상황까지 갈 수 있습니다.
기름을 구멍에 많이 뿌리는 것도 먼지가 엉겨 더 막히게 하니 조심하세요.
@ 병점동 창고 출입문 자물쇠와 걸이 점검

# 창고라면 안에 든 물건도 생각하세요
창고 문은 한 번 열리면 안의 물건이 그대로 드러나는 곳입니다. / 그래서 문을 열 때 누가 입회하는지가 특히 중요합니다.
창고에는 재고나 장비, 서류가 들어 있는 경우가 많습니다. / 문을 어떻게 열지에 따라 안의 물건이 위험해질 수 있어 신중하게 접근해야 합니다.
문을 열기 전에 안에 사람이 있는지, 가스나 약품처럼 조심할 물건이 있는지도 알려주시면 좋습니다. / 안전하게 진행하는 데 필요한 정보입니다. / 문을 연 뒤에는 안에서 사라진 물건이 없는지 사용하시는 분이 직접 확인해 주세요. / 입회하는 분이 한 명이라도 있어야 서로 오해가 생기지 않습니다.

# 전화하실 때 알려주실 내용
창고나 컨테이너는 현장마다 모양이 달라 사진이 큰 도움이 됩니다. / 문자로 문 전체와 잠금장치 가까이 사진을 보내주시면 필요한 장비를 챙겨 갑니다.
- 병점동 어느 쪽인지, 병점역에서 어느 방향인지
- 문이 철문인지 일반 문인지
- 열쇠 구멍, 자물쇠, 번호키 중 어떤 방식인지
- 지금 어떤 상태인지 (열쇠 분실, 안 돌아감, 녹슴 등)
- 몇 시까지 문이 열려야 하는지

# 도착하면 먼저 확인하는 것
창고나 사무실 문은 이 공간을 쓰는 분이 맞는지가 특히 중요합니다. / 사업자 정보나 임대 계약서, 주소가 나온 우편물, 건물주나 관리 담당자와의 통화 확인 중 가능한 것으로 확인합니다.
확인이 어려우면 작업할 수 없으니 미리 서류를 챙기시면 좋습니다. / 임차해서 쓰는 곳이라면 건물주께 연락해 두는 것도 방법입니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
창고나 사무실은 문이 크고 구조가 달라 현장을 보고 나서야 정확한 작업을 말씀드릴 수 있습니다. / 그래서 사진으로 먼저 어림해 드리고, 도착해서 직접 보고 다시 확인해 드립니다.
문 종류와 잠금 방식을 보고 어떤 작업이 필요한지 설명드립니다. / 먼저 안내를 드리고 동의하시면 시작합니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 자물쇠나 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. 진행 방식은 [이용안내](guide.html)에 있습니다.

# 문을 상하지 않게 엽니다
얇은 철문은 한번 휘면 다시 맞추기 어렵습니다. / 문틀과 문짝이 한 몸처럼 용접된 컨테이너 문은 특히 조심해야 합니다. / 그래서 덜 상하는 방법부터 시도하고 설명드린 뒤 진행합니다.
방식은 [현관문 개문](door-open.html) 페이지에서 보실 수 있습니다. / 상가·사무실 문에 관한 안내는 같은 페이지에 함께 정리되어 있습니다.

# 열고 나서 잠금장치 손보기
문이 열린 뒤에는 같은 일이 반복되지 않도록 잠금 상태를 점검합니다. / 녹이 심하면 실린더 교체나 번호키로 바꾸는 방법을 말씀드립니다.
- 열쇠 구멍에 녹이나 이물질이 있는지
- 자물쇠가 헐거워 위치가 틀어지지 않았는지
- 문틀과 문짝 사이 틈이 일정한지
- 번호키라면 습기 막이가 되어 있는지
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 해결하고, 많이 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 야외 문을 오래 쓰는 관리법
- 열쇠 구멍에 먼지가 쌓이지 않게 덮개나 캡 사용
- 비 온 뒤에는 번호판 물기 닦기
- 겨울에는 구멍에 물이 스미지 않게 주의
- 열쇠는 한 벌만 따로 보관하고 복사는 필요한 만큼만
- 문이 처지지 않게 문 아래 받침과 경첩 확인
작업장이 여러 명이 쓰는 곳이라면 열쇠 보유자를 적어 두는 것도 좋습니다. / 퇴근하는 사람이 마지막으로 잠그는 순서를 정해 두면 누가 잠갔는지 몰라 헤매는 일이 줄어듭니다. / 열쇠를 잃어버렸을 때 바로 실린더를 바꿀지, 임시로 쓸지도 미리 정해 두면 당황하지 않습니다.
@ 병점동 야외 출입문 녹과 습기 점검

# 병점동 말고 화성 어디든 갑니다
병점동 가까운 진안동, 기배동, 반송동, 능동은 물론 오산동, 장지동, 봉담읍, 향남읍, 남양읍까지 다닙니다. / 화성 안이면 24시간 연락 받습니다.
다니는 동네는 [화성시 출장열쇠](hwaseong.html)와 [출장 지역](area.html)에서 보실 수 있습니다.
