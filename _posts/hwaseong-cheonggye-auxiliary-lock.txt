# 청계동에서 번호는 맞는데 문이 안 열릴 때
동탄 청계동은 비교적 새 단지가 많아 도어락도 최신형이 대부분입니다. / 번호가 맞고 모터 소리도 나는데 문이 안 열리면 보조키나 걸쇠가 걸린 경우가 많습니다.
이 글은 청계동에서 보조키 때문에 문이 안 열릴 때 확인할 것을 정리했고, 안 될 때 [화성 출장열쇠](hwaseong.html)가 어떻게 여는지도 적었습니다. / 지금 문 앞이시면 3번부터 보세요.
@ 청계동 보조키 잠김 현관문 안 열림 출장열쇠

# 보조키가 뭔지부터 짚고 갑니다
현관문 위쪽이나 아래쪽에 도어락과는 별도로 달린 잠금 장치를 보조키라고 부릅니다. / 안쪽에서 돌려 잠그는 형태라 잠가 두고 나오면 바깥에서는 번호를 눌러도 열리지 않습니다.
요즘은 도어락 한 대로 충분하다고 보조키를 빼는 집도 있지만, 남아 있다면 한 번쯤 점검해 두세요. / 보조키 하나가 문을 못 열게 만드는 일이 의외로 잦습니다.

# 이런 소리가 나면 보조키를 의심하세요
- 번호는 맞다고 뜨고 모터가 도는데 문이 안 움직인다
- 열림 소리는 나는데 문이 꿈쩍하지 않는다
- 문을 밀거나 당기면 위쪽이나 아래쪽이 걸린 느낌이 든다
- 평소와 달리 문이 아주 단단하게 닫혀 있다

# 안쪽에서 보조키를 돌리고 나온 경우
출근길에 서두르다 보조키까지 잠그고 나오는 일이 가끔 있습니다. / 가족 중 누군가 안에서 잠근 줄 모르고 나가는 경우도 있습니다.
집 안에 사람이 있다면 전화로 보조키를 풀어 달라고 하세요. / 아무도 없다면 이 경우는 직접 열기 어려워 전화 주시는 게 낫습니다.

# 걸쇠가 문틀에 걸려 있을 수도 있습니다
번호를 누르면 걸쇠는 빠졌는데 문틀에 끼어 문이 안 열리는 경우가 있습니다. / 문이 조금 처졌거나 문틀과 걸쇠가 어긋났을 때 그렇습니다.
이때는 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 한두 번 시도해도 안 되면 세게 당기지 말고 그만두세요.
@ 청계동 걸쇠 문틀 걸림 도어락

# 세게 당기거나 걷어차지 마세요
급한 마음에 손잡이를 세게 당기면 걸쇠와 손잡이 축이 휘어 일이 커집니다. / 문을 걷어차는 것도 문틀과 경첩을 상하게 합니다.
드라이버로 문틈을 벌리는 것도 도어락 외관과 문틀을 망가뜨립니다. / 나중에 교체 비용이 더 들 수 있으니 그대로 두고 전화 주세요.

# 전화로 알려주실 것
- 청계동 위치, 동과 호수, 가까운 큰길이나 동탄역 방향
- 번호를 누르면 어떤 소리가 나는지
- 보조키를 잠갔을 가능성이 있는지
- 집 안에 사람이나 반려동물이 있는지

# 도착하면 먼저 확인부터 합니다
사시는 분인지 신분증 주소나 우편물, 관리사무소 확인으로 먼저 확인합니다. / 이 절차를 거쳐야 작업을 시작할 수 있습니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요. / 늦은 시간이라면 경비실에 미리 말씀해 두면 수월합니다.

# 보조키는 이렇게 엽니다
보조키는 종류에 따라 여는 방법이 다릅니다. / 문과 보조키가 상하지 않게 덜 상하는 방법부터 차례로 해봅니다.
작업 전에 비용을 먼저 말씀드리고 시작합니다. / 부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다.
자세한 진행은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.
@ 동탄 청계동 출장열쇠 24시간 현관문 개문

# 비용은 열기 전에 말씀드립니다
문을 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
이용 방식은 [이용안내](guide.html)에 정리해 두었습니다. / 모르는 부분은 전화로 먼저 물어보세요.

# 열린 뒤 점검할 것
- 도어락이 정상으로 잠기고 열리는지
- 보조키가 문제였다면 계속 쓸지, 빼도 되는지
- 걸쇠가 걸릴 만큼 문이 처졌다면 경첩 점검
- 가족에게 보조키 사용 규칙 공유하기

# 보조키를 쓰는 집이라면 이렇게
보조키는 밤에만 쓰고 아침에는 풀어 두는 습관이 안전합니다. / 나갈 때는 도어락 번호만 누르고 나가고 보조키는 안에서만 쓰는 식으로 정해 두세요.
문에 붙여 두는 작은 메모도 의외로 도움이 됩니다. / 가족 모두 같은 규칙을 지키면 문 앞에서 막히는 일이 줄어듭니다.

# 청계동 말고 화성 어디든 갑니다
동탄 반송동, 능동, 영천동은 물론 병점, 봉담, 향남까지 화성 전 지역을 다닙니다. / 24시간 출동하니 시간은 신경 쓰지 마세요.
다니는 동네는 [출장 지역](area.html) 지도에 있고, 고장이 잦으면 [도어락 수리](doorlock-repair.html)로 점검할 수 있습니다. / 필요하면 교체도 말씀드립니다.
