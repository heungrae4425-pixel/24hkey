# 동탄 청계동에서 잠깐 나왔다가 잠긴 문
동탄 청계동은 새 아파트와 상가가 이어져 있어 택배와 분리수거를 하러 잠깐 문 밖으로 나가는 일이 흔합니다. / 문을 살짝 닫고 나왔는데 철컥 소리와 함께 잠기는 순간이 있습니다.
휴대폰도 집 안에 있고 열쇠도 없다면 정말 난감합니다. / 슬리퍼 차림에 아무것도 들고 있지 않은 상태라면 더 그렇습니다.
이 글은 동탄 청계동에서 잠깐 나왔다가 문이 잠겼을 때 먼저 확인할 것과, 그다음 [화성 출장열쇠](hwaseong.html)를 부르는 순서를 정리했습니다. / 지금 문 앞에 계시다면 3번과 4번부터 보셔도 됩니다.
@ 동탄 청계동 문 잠김 택배 분리수거 출장열쇠

# 문이 자동으로 잠기는 도어락이 많습니다
요즘 도어락은 문이 닫히면 자동으로 걸쇠가 잠기는 방식이 많습니다. / 편리하지만 손에서 놓은 순간 번호 없이는 열리지 않는 구조라는 뜻이기도 합니다.
오토락 기능이 켜져 있는지 몰랐다가 처음 갇히는 분도 많습니다. / 한 번 겪고 나서야 설정을 찾아보는 경우가 대부분입니다.
문이 닫히는 순간을 막는 방법도 있습니다. / 나가기 전에 문 틈에 얇은 물건을 끼워 두는 정도의 습관만으로도 잠기는 일을 줄일 수 있습니다.

# 지금 해볼 수 있는 방법부터
가장 먼저 번호 입력이 되는지 확인합니다. / 비밀번호를 기억하고 있다면 문 앞에서 그냥 열 수 있는 경우가 대부분입니다.
번호를 모른다면 가족에게 연락해 보세요. / 이웃의 휴대폰을 잠깐 빌려 가족이나 연락처에 전화를 걸 수 있다면 가장 빠른 방법이 됩니다.
아직 문이 잠기지 않았다면 문턱 쪽에서 살짝 밀어 보세요. / 완전히 잠긴 소리가 났다면 힘으로 열려 하지 말고 다음 방법으로 넘어가세요.
@ 동탄 청계동 문 앞에서 번호 입력 확인

# 이런 시도는 하지 마세요
급한 마음에 문틈에 카드나 드라이버를 넣어 열어 보려는 분들이 많습니다. / 그러면 문틀과 도어락 외관이 상하고 오히려 열기가 어려워질 수 있습니다.
창문으로 들어가려다 다치는 경우도 있습니다. / 저층이든 고층이든 무리해서 난간이나 외벽을 타지 마세요.
문을 발로 차거나 어깨로 미는 것도 피해 주세요. / 문과 문틀이 상하면 열 수 있던 문도 교체해야 할 수 있습니다.
혼자 해결하기 어렵다고 생각되면 그 시점에서 멈추고 전화 주시는 편이 훨씬 안전합니다.
비밀번호가 기억나지 않아도 너무 많이 눌러 보지는 마세요. / 여러 번 틀리면 도어락이 한동안 입력을 막아 버려 기다려야 하는 시간이 길어집니다.

# 안에 사람이나 불이 켜져 있다면 꼭 먼저 말씀해 주세요
집 안에 어린 아이나 거동이 불편한 분이 혼자 있다면 상황이 달라집니다. / 가스불을 켜 둔 채 나왔다면 시간이 더 중요해집니다.
이런 경우에는 열쇠집을 부르는 것과 함께 필요하면 안전을 위해 관리사무소나 119에도 연락하셔야 합니다. / 아이가 안에서 울고 있다면 문 너머로 계속 말을 걸어 안심시켜 주세요.
통화할 때 이 사실을 맨 처음에 말씀해 주시면 출동 순서를 바꿔 움직입니다. / 먼저 말씀해 주시는 것이 가장 중요합니다.

# 동탄 청계동에서 위치를 알려주는 방법
단지와 동이 많은 지역이라 위치를 정확히 알려주시면 도착이 빨라집니다. / 아파트 이름, 동, 호수와 함께 지금 서 있는 층을 말씀해 주세요.
- 건물 이름(또는 큰 건물 기준 방향), 동과 호수
- 현재 있는 층과 엘리베이터 위치
- 번호판 상태 (켜짐, 꺼짐, 경고음)
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 장비를 맞춰 가기 좋습니다. / 휴대폰이 집 안에 있다면 이웃의 전화를 빌려 연락하셔도 됩니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
문제는 신분증도 집 안에 있는 경우입니다. / 이때는 관리사무소에 세대 확인을 부탁하거나, 가족이 연락처와 주소를 확인해 주는 방법이 있습니다.
번거로워 보여도 이웃과 집주인을 모두 지키는 절차입니다. / 확인이 되지 않으면 작업을 할 수 없으니 미리 방법을 생각해 두시면 좋습니다.

# 비용은 문을 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 동탄 청계동 24시 출장열쇠 현관문 개문

# 최대한 문을 안 상하게 엽니다
문 여는 방법은 여러 가지가 있고, 덜 상하는 방법부터 차례로 해봅니다. / 새 아파트 문일수록 도어락과 문틀 마감이 곱기 때문에 상처가 나지 않게 신경 씁니다.
도어락 종류와 문 상태에 따라 걸리는 시간은 다릅니다. / 열릴 때까지 무리하게 시간을 끌지 않고 진행 상황을 말씀드립니다.
방식에 대한 자세한 설명은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 열린 뒤에는 오토락 설정을 확인하세요
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 부족했다면 새것으로 바꾸고 상태를 함께 봅니다.
자동 잠금이 불편하다면 설정을 바꿀 수 있는지 알려드립니다. / 제품에 따라 자동 잠금을 끌 수 있거나 시간을 늘릴 수 있습니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 고장이 반복된다면 [도어락 수리](doorlock-repair.html)를 먼저 보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 같은 일이 또 생기지 않게 해두면 좋은 습관
한 번 갇히고 나면 다음엔 막고 싶어집니다. / 어렵지 않은 습관 몇 가지면 충분합니다.
- 나갈 때 휴대폰을 주머니에 넣기
- 현관 밖 가까운 곳에 비상 열쇠나 카드키 보관(안전한 곳으로)
- 가족과 비밀번호 공유
- 쓰레기를 버리러 갈 때도 문 틈을 확인하는 습관
- 도어락 자동 잠금 설정 확인
택배가 많은 집이라면 현관 앞에 잠깐 놓아두는 물건을 정해 두는 것도 방법입니다. / 작은 습관이 문 앞에서 막히는 일을 많이 줄여 줍니다.

# 청계동 말고 화성 어디든 갑니다
청계동뿐 아니라 동탄 전 지역과 병점, 봉담, 향남, 남양까지 화성 전 지역으로 출동합니다. / 화성은 넓어서 위치를 먼저 알려주시면 도착 시간을 정확히 말씀드립니다.
동네별 안내는 [화성시 출장열쇠](hwaseong.html)에, 서울·경기 다른 지역은 [출장 지역](area.html) 지도에 있습니다.
