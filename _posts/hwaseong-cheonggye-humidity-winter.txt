# 날씨가 바뀌면 문 앞이 먼저 알려줍니다
동탄 청계동에서 아침에 나서려는데 번호판이 깜빡이거나 반응이 한 박자 늦은 적이 있으신가요. / 장마가 시작될 때나 한겨울 바깥 공기가 차가운 날에 유독 그런 일이 잦습니다.
동탄역 방향으로 출근하는 분들은 바쁜 아침에 이런 일을 겪으면 곤란합니다. / 이 글은 습기와 결로가 도어락에 어떤 영향을 주는지, 직접 해볼 만한 것과 부를 때를 나눠 적었습니다.
@ 청계동 도어락 습기 결로 오작동 출장열쇠

# 도어락 속으로 물기가 들어가는 길
도어락은 겉으로 보기엔 튼튼해 보여도 틈이 있습니다. / 번호판 가장자리와 손잡이 축, 열쇠구멍 주위로 수분이 스며듭니다.
장마철에는 공기 중 습도가 높아서 아무것도 하지 않아도 내부에 이슬이 맺힙니다. / 겨울에는 바깥은 영하인데 집 안은 따뜻해서 문 안쪽 표면에 물방울이 생깁니다.
이 물기가 기판의 접점에 닿으면 숫자를 누르지 않았는데 눌린 것처럼 인식되기도 합니다. / 그래서 오작동처럼 보이는 증상이 나타납니다.

# 습기가 만드는 흔한 증상
증상은 제품마다 조금씩 다르지만 비슷한 모양으로 나타납니다.
- 번호판 불빛이 깜빡이거나 숫자가 일부만 켜짐
- 눌러도 반응이 없다가 한참 뒤에 입력됨
- 경고음이 이유 없이 울림
- 문은 열렸는데 잠금이 한 번에 안 됨
- 비 오는 날만 증상이 생기고 맑은 날엔 멀쩡함
날씨와 연관되어 나타났다 사라지면 습기를 먼저 의심해 볼 만합니다. / 날씨와 상관없이 계속되면 다른 고장일 수 있습니다.
아침에만 그렇고 낮에는 괜찮다면 밤사이 생긴 결로일 가능성이 큽니다. / 언제 그런지 기록해 두면 원인을 찾기가 훨씬 쉬워집니다.

# 겨울 결로는 안쪽에서 생깁니다
겨울에 문 안쪽 도어락 몸체에 물방울이 맺힌 걸 본 적이 있을 겁니다. / 철문은 열을 잘 전달해서 바깥 냉기가 안쪽 표면까지 닿기 때문입니다.
이 물이 흘러 도어락 틈새로 들어가면 건전지 접점이 젖습니다. / 건전지를 갈아도 안 되고, 말려 놓으면 다시 되는 일이 반복됩니다.
결로가 심한 현관이라면 문틈 단열과 환기도 같이 살펴보는 게 좋습니다.
현관 앞 신발장이 문에 바짝 붙어 있으면 공기가 잘 안 돌아 물기가 오래 남습니다. / 가끔 현관문을 열어 환기시켜 주는 것만으로도 도움이 됩니다.

# 직접 해볼 수 있는 안전한 처치
먼저 마른 수건으로 번호판과 손잡이 둘레를 닦아 주세요. / 잠시 기다렸다가 다시 눌러 보면 돌아오는 경우가 많습니다.
- 안쪽 건전지 덮개를 열어 물기가 있으면 닦기
- 건전지를 뺐다가 한 번 다시 끼워 접점 확인
- 드라이어를 쓸 때는 약한 바람으로 멀리서 짧게
- 뜨거운 바람을 가까이 대거나 세제를 뿌리는 건 금지
뜨거운 바람은 플라스틱 부품을 휘게 하고 내부 부품을 상하게 합니다. / 급해도 약하게, 멀리서만 하세요.

# 장마철 문 앞에서 하면 안 되는 것
비가 오는 날 번호판에 젖은 손으로 계속 누르면 물이 더 들어갑니다. / 우산에서 떨어지는 물도 번호판 틈으로 흘러듭니다.
알코올이나 접점 부활제를 아무 데나 뿌리는 것도 권하지 않습니다. / 잘못 쓰면 번호판 코팅이 상하고 오작동이 더 심해질 수 있습니다.
증상이 반복되면 말려서 쓰는 걸로는 한계가 있습니다. / 한 번 점검받는 편이 오래 갑니다.
습기가 쌓인 채로 두면 접점이 녹슬어 나중에는 건전지를 새로 넣어도 반응하지 않습니다. / 녹이 슬기 전에 손보는 것이 부품도 아끼고 마음도 편합니다.
@ 동탄 청계동 도어락 번호판 물기 닦기

# 번호는 맞는데 안 열린다면
습기 때문에 모터가 느리게 돌거나 걸쇠가 얼어붙는 경우도 있습니다. / 한겨울 아침에 걸쇠가 얼어 안 빠지는 일은 의외로 흔합니다.
이럴 때는 문을 안쪽으로 살짝 밀어 걸쇠가 문틀에서 떨어지게 하고 손잡이를 돌려 보세요. / 그래도 안 되면 억지로 힘을 쓰지 말고 전화 주세요.
얼어붙은 걸쇠를 칼이나 드라이버로 두드려 푸는 건 하지 마세요. / 문틀과 도어락 둘 다 상할 수 있습니다.

# 출장 요청 때 알려주시면 좋은 정보
청계동은 단지와 동이 구분되니 위치를 정확히 알려주시면 도착이 빨라집니다. / 날씨 때문에 생기는 문제는 상황 설명이 해결의 절반입니다.
- 아파트 단지 이름과 동, 호수
- 비가 오는 날이나 추운 날만 증상이 생기는지
- 번호판 상태 (깜빡임, 꺼짐, 경고음)
- 건전지를 최근에 갈았는지
- 집 안에 아이나 반려동물이 있는지
증상이 나타날 때 영상을 짧게 찍어 보내주시면 큰 도움이 됩니다.
증상이 지나가 버렸다면 언제 어떻게 그랬는지만 말씀해 주셔도 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로워도 이웃과 집을 지키기 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 열기 전에 말씀드립니다
도어락 상태와 문 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 말리고 점검한 뒤에도 문제가 남을 때
젖은 기판은 겉만 닦아서는 풀리지 않는 경우가 있습니다. / 안쪽을 열어 접점을 살펴보고 필요한 부분만 손봅니다.
[도어락 수리](doorlock-repair.html)로 해결되는 경우가 많고, 이미 부식이 심하다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐 쓸 수 있으면 교체를 권하지 않습니다.
문 개방이 필요하면 도어락이 상하지 않게 하는 방법부터 씁니다. / 작업 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 계절 타는 도어락을 덜 힘들게 하는 습관
- 장마 들기 전에 건전지를 새것으로 교체
- 번호판 둘레 틈에 물이 고이지 않는지 확인
- 겨울에는 문 안쪽 물방울을 아침에 닦아내기
- 비 오는 날 우산을 번호판 위에서 털지 않기
- 경고음이 울리면 날씨 탓하지 말고 그날 점검
도어락은 계절을 타는 기계라고 생각하시면 편합니다. / 계절이 바뀌는 때에 한 번 확인하는 습관이면 충분합니다.
@ 청계동 24시 출장열쇠 도어락 점검

# 청계동 말고도 화성 어디든 갑니다
동탄 다른 동네와 병점, 봉담, 향남, 남양 등 화성 안이면 24시간 출동합니다. / 지역별 안내는 [화성시 출장열쇠](hwaseong.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
