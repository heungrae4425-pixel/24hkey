# 함께 살던 사람이 짐을 빼고 떠난 다음 날
청계동은 동탄역 생활권이라 직장이나 학업 때문에 방을 나눠 쓰는 분들이 많은 동네입니다. / 같이 살던 룸메이트가 계약이 끝나 먼저 나가면 집은 그대로인데 도어락에는 그 사람의 흔적이 남습니다.
번호를 알고 있고 카드키도 쥐고 있으니 마음만 먹으면 언제든 들어올 수 있는 상태입니다. / 대부분은 그럴 일이 없지만 정리해 두면 서로 마음이 편해집니다.
이 글은 청계동에서 룸메이트가 나간 뒤 도어락을 어떤 순서로 정리하면 되는지 적었습니다. / 번호가 헷갈려 문이 안 열리는 경우의 대처와 [화성 출장열쇠](hwaseong.html) 이용 방식도 함께 담았습니다.
@ 청계동 함께 쓰던 집 현관 도어락

# 먼저 도어락에 무엇이 등록돼 있는지 적어 보기
정리를 시작하기 전에 지금 등록된 것이 무엇인지 목록으로 적어 보세요. / 비밀번호 몇 개, 카드키 몇 장, 지문이 등록되어 있는지부터 파악해야 합니다.
- 공용으로 쓰던 비밀번호
- 룸메이트 개인 번호를 따로 등록했는지
- 나눠 가진 카드키나 태그의 수
- 지문 등록 여부
제품마다 등록 화면이 달라 설명서나 제조사 안내를 보면 도움이 됩니다. / 설명서가 없으면 도어락 모델 이름을 사진으로 찍어 두면 나중에 확인하기 쉽습니다. / 안쪽 덮개에 붙은 작은 스티커에 모델명이 적혀 있는 경우가 많습니다.

# 돌려받을 것부터 챙기기
나간 사람에게 카드키와 열쇠를 돌려받는 일이 우선입니다. / 이삿날 짐 정리하다 보면 현관 열쇠를 깜빡하고 가져가는 경우가 흔합니다.
부탁할 때는 메시지로 남겨 두는 편이 서로 기억하기 좋습니다. / 말투는 부드럽게 해도 되고, 반납 날짜만 분명히 하면 됩니다.
만나서 받기 어렵다면 우편함이나 지정한 장소에 두고 가게 하는 방법도 있습니다. / 이때도 받았다는 사실은 메시지로 남겨 두세요.
받은 카드키는 장수를 세어서 처음 받았던 수와 맞는지 확인해 보세요. / 모자라면 그 카드는 분실로 보고 등록을 지우는 쪽이 안전합니다.

# 비밀번호 바꾸는 가장 쉬운 순서
많은 도어락은 안쪽 덮개를 열면 등록 버튼이나 설정 단추가 있습니다. / 먼저 관리자 번호나 기존 번호로 설정 모드에 들어갑니다.
그다음 새 번호를 등록하고 이전 번호를 지우는 단계로 이어집니다. / 새 번호가 정상적으로 열리는지 문을 연 상태에서 두세 번 시험해 보세요.
- 새 번호 등록 후 문이 열린 상태에서 시험
- 문을 닫고 바깥에서 새 번호로 열어 보기
- 이전 번호가 더 이상 안 먹히는지 확인
이 순서를 지키면 새 번호를 잘못 눌러 문 밖에 갇히는 일을 막을 수 있습니다.

# 번호를 바꿨는데 문이 안 열릴 때
새 번호를 등록한 직후 열리지 않는 사고가 의외로 많습니다. / 등록할 때 누른 자릿수와 열 때 누르는 자릿수가 다르거나, 마지막에 확인 버튼을 빼먹은 경우입니다.
제품에 따라 등록 후 잠시 기다려야 저장되는 모델도 있습니다. / 설정을 마칠 때 완료음이 나는지 꼭 귀로 확인하세요.
문 밖에서 안 열리면 억지로 여러 번 누르지 마세요. / 입력 제한이 걸려 몇 분간 아무 반응이 없을 수 있습니다.
새 번호는 생일이나 전화번호처럼 남이 짐작하기 쉬운 숫자를 피하는 것이 좋습니다. / 함께 살던 사람이 알 만한 숫자와도 겹치지 않게 정해 두세요.
@ 청계동 도어락 비밀번호 재등록 확인

# 룸메이트의 번호가 자꾸 살아 있는 것 같을 때
번호를 지웠는데도 이전 번호로 열렸다는 이야기가 가끔 있습니다. / 이런 경우는 지운 것이 아니라 새 번호를 추가만 해서 기존 번호가 남아 있던 상황이 대부분입니다.
도어락에 따라서는 한 번에 여러 개의 번호를 저장하기 때문에 삭제 단계를 따로 거쳐야 합니다. / 설명서의 전체 삭제 기능을 쓰면 정리가 한 번에 끝납니다.
자신 없으면 무리하지 말고 연락 주세요. / 현장에서 등록된 번호와 카드를 확인해 드립니다.

# 문 안쪽에 남은 보조키와 열쇠는 어떻게
도어락과 별개로 열쇠로 여는 보조 장치가 달린 문도 있습니다. / 이 열쇠를 룸메이트가 복사해 갔는지는 확인하기 어렵습니다.
마음이 걸린다면 열쇠 구멍 부분을 바꾸는 방법이 있습니다. / 필요한지 여부는 현장에서 문을 보고 말씀드리며, 불필요한 교체는 권하지 않습니다.
집주인이 있는 집이라면 도어락 정리 전에 한번 알려 두는 편이 마찰이 적습니다. / 법적으로 무엇이 맞는지는 계약 내용에 따라 다르니 임대 조건을 먼저 확인해 보세요.

# 문이 안 열려서 전화하기 전에 확인할 것
- 번호판이 켜지는지, 눌렀을 때 소리가 나는지
- 최근에 번호나 카드 설정을 바꾼 적이 있는지
- 안쪽 보조키나 걸쇠가 잠긴 채인지
- 배터리 교체 시기가 지나지 않았는지
번호판이 꺼져 있으면 9V 건전지를 비상 단자에 대 보세요. / 동탄역 주변 편의점에서 구할 수 있습니다.

# 위치와 상황은 이렇게 알려주세요
청계동 안 대략적인 위치와 동, 호수를 먼저 말씀해 주세요. / 건물 이름 대신 가까운 큰길이나 동탄역 방향 정도로 설명해도 됩니다.
번호판 상태와 도어락 사진을 같이 보내 주시면 맞는 장비를 챙겨 갑니다. / 함께 사는 사람이 아직 남아 있다면 그 사람이 안에 있는지도 알려 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
룸메이트 사이에서는 누가 계약자인지 헷갈리는 경우가 있습니다. / 문 열기 전에 현재 이 집에 사는 분이 맞는지 신분증 주소, 주소가 나온 우편물, 관리사무소 확인으로 점검합니다.
계약자와 거주자가 다르면 사정을 솔직히 말씀해 주세요. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
@ 현관 앞 신분 확인과 개방 작업

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
[도어락 수리](doorlock-repair.html)로 해결되면 교체는 권하지 않고, 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 정리를 끝낸 뒤 점검 목록
번호를 바꾸고 나면 마지막으로 한 번에 점검해 두세요. / 아래 항목이 모두 되면 정리가 끝난 것입니다.
- 새 번호로 바깥에서 열림
- 이전 번호와 이전 카드는 열리지 않음
- 안쪽 손잡이로 쉽게 열림
- 배터리 새것 확인
새로 들어올 사람이 정해져 있다면 그 사람에게는 처음부터 별도 번호나 카드를 주는 편이 관리가 쉽습니다. / 나갈 때 그 번호만 지우면 되니 다음 정리가 훨씬 간단해집니다.
방 안의 개인 물건을 두고 간 것이 있는지도 연락으로 정리해 두세요. / 서로 연락이 끊기기 전에 한 번에 마무리하는 편이 나중에 편합니다.
