# 복도에 나갔다가 방화문이 쾅 닫혔을 때
기배동은 동탄역이나 병점역 쪽으로 나가실 때 이용하는 분들이 많은 생활권입니다. / 아파트나 빌라에서 쓰레기를 들고 복도로 나갔다가 계단실 방화문이 닫히며 잠긴 경험을 하는 분이 적지 않습니다.
방화문은 불이 번지는 걸 막으려고 저절로 닫히도록 만든 문입니다. / 그래서 일부러 닫으려 한 게 아닌데도 닫히고, 반대편에서는 열리지 않는 경우가 생깁니다.
이 글은 기배동에서 방화문이 닫혀 곤란할 때의 대처와, 현관문이 같이 잠긴 경우의 순서를 정리했습니다. / 도움이 필요하면 [화성 출장열쇠](hwaseong.html)를 부르는 방법도 뒤에 적었습니다.
@ 기배동 계단실 방화문 닫힘 잠김

# 방화문은 왜 한쪽에서만 열릴까
방화문은 문이 항상 닫혀 있도록 도어클로저가 달려 있습니다. / 손을 떼면 저절로 닫히고, 닫히면 걸쇠가 물립니다.
어떤 문은 안쪽에서는 손잡이를 돌려야 열리고, 바깥쪽에서는 열쇠나 번호가 있어야 열립니다. / 계단실 쪽 문이 한쪽만 열리게 되어 있어 복도에서 나가면 되돌아오기 어려운 경우도 있습니다.
건물마다 구조가 달라서 어떤 방식인지는 직접 눈으로 보고 판단해야 합니다. / 그래서 통화로 상태를 정확히 설명해 주시는 게 중요합니다.

# 문 앞에서 먼저 해볼 수 있는 것
당황하지 말고 손잡이나 바 형태의 레버가 움직이는지부터 보세요. / 문틈으로 걸쇠 위치가 보인다면 사진을 찍어 두면 도움이 됩니다.
- 손잡이나 레버가 끝까지 내려가는지
- 문이 문틀에 꽉 맞물려 있는지, 약간 밀리는지
- 문에 번호판이나 카드 리더가 있는지
- 건물 관리사무소나 경비실에 연락이 되는지
관리사무소가 열려 있는 시간이라면 먼저 문의하는 것이 가장 빠를 수 있습니다. / 건물 공용 부분은 관리 주체가 따로 있는 경우가 많기 때문입니다.

# 문을 발로 차거나 억지로 열려는 건 위험합니다
방화문은 일반 현관문보다 무겁고 단단하게 만들어져 있습니다. / 발로 차거나 어깨로 밀면 다치기 쉽고, 문이 휘어 오히려 더 안 열릴 수 있습니다.
도어클로저를 억지로 당기면 장치가 빠지거나 파손될 수 있습니다. / 공용 시설을 상하게 하면 나중에 일이 커질 수 있으니 조심해야 합니다.
카드나 드라이버로 문틈을 벌리는 것도 피해 주세요. / 문틀과 걸쇠가 상하면 방화문 역할 자체가 약해집니다.

# 현관문도 같이 잠겼는지 먼저 확인하세요
복도에 나온 상태에서 내 집 현관문도 닫혀 있다면 두 가지를 구분해야 합니다. / 현관문은 번호를 알면 열 수 있지만, 방화문은 건물 관리 영역이라 해결 방식이 다릅니다.
번호를 눌러 열리면 현관은 해결이니 일단 집 안으로 들어가 전화를 쓰세요. / 번호판이 꺼졌거나 번호가 기억나지 않으면 그때는 도움이 필요합니다.
휴대폰이 집 안에 있다면 이웃에게 전화를 빌려 연락 주셔도 됩니다. / 이웃이 없으면 관리사무소나 경비실에 부탁하는 방법도 있습니다.
@ 기배동 복도 현관문 도어락 번호판 확인

# 어떤 경우에 출장열쇠를 부르나
상황이 아래에 해당하면 혼자 붙잡지 말고 연락 주시는 편이 낫습니다. / 특히 방화문 자체가 아니라 내 집 현관문이 문제일 때는 도움이 됩니다.
- 방화문이 닫혔는데 복도 쪽으로 열쇠나 번호가 필요한 구조일 때
- 현관 번호가 기억나지 않거나 번호판이 꺼졌을 때
- 문이 반쯤 닫혀 걸쇠가 걸린 듯 움직이지 않을 때
- 아이나 반려동물을 집 안에 두고 나와 잠긴 경우
방화문 같은 건물 공용 문은 소유와 관리가 달라서 처리 전에 확인이 필요할 수 있습니다. / 현장에서 상태를 보고 가능한 범위를 먼저 말씀드립니다.

# 위치와 상황을 이렇게 알려 주세요
기배동은 건물 구조가 다양해서 주소만으로는 상황이 잘 그려지지 않습니다. / 아래 내용을 알려 주시면 도착이 빨라집니다.
- 건물 이름 대신 동, 호수와 몇 층인지
- 방화문이 어느 쪽에 있고 어떻게 닫혔는지
- 현관 번호판 상태와 도어락 모양
- 집 안에 사람이나 동물이 있는지
가능하면 문 사진을 문자로 보내 주세요. / 어떤 장비가 맞을지 가늠하는 데 큰 도움이 됩니다.

# 밤이나 새벽에 방화문이 닫혔을 때
쓰레기를 버리려고 잠깐 나온 한밤에 이런 일이 생기면 더 곤란합니다. / 엘리베이터 홀이나 계단 쪽에서 오래 기다리면 추위와 불안이 커집니다.
옷차림이 얇다면 가까운 이웃에게 도움을 청하는 것도 방법입니다. / 어려우면 경비실이나 야간 관리 인력이 있는지 먼저 문의하세요.
전화는 24시간 받으니 시간 걱정 말고 연락 주세요. / 통화가 끝나면 집 앞에서 안전한 곳에 서서 기다려 주시면 됩니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 해당 집에 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태를 보고 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 최대한 문을 상하지 않게 엽니다
먼저 도어락과 문틀이 덜 상하는 방법부터 차례로 시도합니다. / 방화문처럼 구조가 특수한 문은 손대기 전에 어떻게 진행할지 설명드립니다.
개문 방식이 궁금하시면 [현관문 개문](door-open.html) 페이지에서 자세히 보실 수 있습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.
@ 기배동 출장열쇠 비파손 방화문 현관 개문

# 열린 뒤 재발을 막는 점검
문이 열린 뒤에는 도어클로저와 걸쇠가 정상으로 동작하는지 함께 봅니다. / 너무 세게 닫히거나 약하게 닫히면 문제가 반복될 수 있습니다.
현관 도어락이 불안하다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 낡았다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 아직 쓸 수 있는 제품은 바꾸라고 권하지 않습니다.
쓰레기를 버리러 나갈 때는 휴대폰을 주머니에 넣고, 현관문이 닫히지 않게 임시로 괴어 두는 습관이 도움이 됩니다.

# 기배동 말고 화성 어디든 갑니다
기배동뿐 아니라 동탄역 쪽, 병점역 쪽, 봉담, 향남까지 화성 안이면 24시간 출동합니다. / 동네별 안내는 [화성시 출장열쇠](hwaseong.html) 페이지에서 볼 수 있습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
