# 기배동 현관문 손잡이가 헐겁게 흔들릴 때
기배동은 병점역과 가깝고 주택과 빌라, 작은 상가가 이어져 있는 동네입니다. / 오래 쓴 현관문이 많아서 손잡이가 헐거워졌다는 연락이 심심치 않게 옵니다.
손잡이를 잡으면 덜렁덜렁 흔들리거나, 돌렸는데 문이 안 열리고 손잡이만 헛도는 경우가 있습니다. / 처음에는 불편한 정도지만 어느 날 아침 손잡이가 문에서 빠져 버리는 일로 이어질 수 있습니다.
이 글은 기배동에서 손잡이 문제가 생겼을 때 어떤 증상이 어떤 의미인지, 임시로 해볼 수 있는 것과 [화성 출장열쇠](hwaseong.html)가 수리하는 순서를 정리했습니다.
@ 화성 기배동 현관문 손잡이 헐거움 출장 수리

# 증상별로 보면 원인이 보입니다
손잡이 문제는 비슷해 보여도 원인이 여러 가지입니다. / 어떤 쪽인지 알면 해결 방법도 달라집니다.
- 손잡이가 위아래로 덜렁거리는 경우: 손잡이를 고정하는 나사가 풀린 경우
- 손잡이를 돌려도 문이 안 열리고 헛도는 경우: 손잡이 축과 안쪽 연결부가 마모되었거나 부러진 경우
- 손잡이가 돌아가다 걸리는 경우: 안쪽 부품이 뒤틀렸거나 이물질이 낀 경우
- 안쪽과 바깥쪽 손잡이가 따로 노는 경우: 두 손잡이를 이어 주는 축이 이탈한 경우
전화로 이 중 어느 쪽인지만 말씀해 주셔도 챙겨 갈 부품을 정하기 쉽습니다.

# 나사 하나만 풀렸을 가능성
손잡이가 헐겁다는 증상의 가장 흔한 원인은 고정 나사가 풀린 것입니다. / 손잡이 아래나 옆에 작은 나사 구멍이 보이면 이 나사가 풀렸을 수 있습니다.
맞는 드라이버로 살살 조여 보고 흔들림이 사라지면 해결된 것입니다. / 다만 나사가 헛돌거나 구멍이 뭉개져 있다면 힘을 주지 말고 멈춰 주세요.
나사를 한 번에 세게 돌리면 구멍이 완전히 망가져 더 큰 작업이 됩니다. / 조금씩 확인하며 조이는 것이 중요합니다.

# 손잡이가 헛돌 때는 문이 잠겨 있을 수 있습니다
손잡이를 돌렸는데 아무 저항 없이 헛돈다면 손잡이와 걸쇠를 연결하는 부분이 끊어진 상태일 수 있습니다. / 이때 문이 이미 닫혀 잠겨 있다면 손잡이로는 열 수 없습니다.
이럴 때 힘으로 문을 당기거나 발로 차는 것은 가장 피해야 합니다. / 문과 문틀이 상하면 손잡이 교체 외에도 수리할 곳이 늘어납니다.
번호나 열쇠로 열리는지는 따로 확인해 보세요. / 도어락 잠금은 열리는데 손잡이만 안 움직이는 경우도 있습니다.

# 문 안쪽에서 손잡이가 빠졌다면
안쪽 손잡이가 빠져 문을 열고 나올 수 없는 상황이 가장 곤란합니다. / 특히 아이나 어르신이 혼자 있을 때는 더 서둘러야 합니다.
이런 경우에는 안쪽에서 문 쪽 보조 장치로 열 수 있는지 먼저 살펴보시고, 안 되면 바로 연락 주세요. / 안에 계신 분을 안심시키기 위해 전화로 상황을 함께 설명해 드립니다.
바깥에서 열 수 있는 경우에는 [현관문 개문](door-open.html) 방식으로 먼저 문을 열고 나서 손잡이를 고칩니다. / 문을 연 뒤에 손잡이를 점검하는 순서가 안전합니다.
@ 기배동 도어락 손잡이 점검 출장열쇠

# 출장 오면 이렇게 진행합니다
도착하면 사시는 분인지 확인합니다. / 신분증 주소나 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
손잡이 상태를 보고 나사만 조이면 되는지, 내부 부품을 바꿔야 하는지 먼저 말씀드립니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
고치고 나면 손잡이를 여러 번 돌려 문이 한 번에 열리고 잠기는지 같이 확인합니다. / 진행 순서는 [이용안내](guide.html)에도 있습니다.

# 수리가 좋은지 교체가 좋은지
손잡이가 낡아서 헐거워진 경우 부품만 바꾸면 해결되는 경우가 많습니다. / 도어락 전체를 바꿀 필요가 없는 경우에는 교체를 권하지 않습니다.
반대로 도어락 본체까지 오래되어 여러 곳이 같이 말썽이라면 [도어락 교체](doorlock-replace.html)를 말씀드릴 수 있습니다. / 어느 쪽이든 하기 전에 이유를 설명드리고 선택은 사시는 분이 하십니다.
수리가 가능한 상태인데 교체를 권하는 일은 없습니다. / 확실하지 않을 때는 먼저 점검만 받아 보셔도 됩니다.

# 문틀과 경첩도 같이 봅니다
손잡이가 자꾸 헐거워지는 집은 문 자체가 처져서 손잡이에 무리가 가는 경우도 있습니다. / 문이 처지면 걸쇠가 문틀에 눌려서 손잡이를 돌릴 때 큰 힘이 들어갑니다.
이 경우에는 손잡이만 고치면 몇 달 뒤 같은 일이 반복될 수 있습니다. / 그래서 손잡이를 점검할 때 경첩과 문틀 상태도 같이 눈으로 확인합니다.
[도어락 수리](doorlock-repair.html) 페이지에 문 쪽 점검 내용도 적어 두었습니다.

# 전화 주시기 전 확인해 주세요
- 손잡이가 안쪽인지 바깥쪽인지, 둘 다인지
- 헐거운 정도(약간 흔들림, 아예 빠짐)
- 지금 문이 열려 있는지, 닫혀 잠겨 있는지
- 도어락 모양(손잡이 일체형, 버튼형 등)과 사진
- 기배동 안에서 대략 어디쯤인지
집 안에 아이나 반려동물, 몸이 불편한 분이 있다면 꼭 먼저 말씀해 주세요. / 상황에 맞춰 우선순위를 정해 출동합니다.
@ 기배동 현관문 손잡이 교체 24시간

# 손잡이를 오래 쓰는 요령
손잡이는 매일 수십 번씩 쓰는 부품입니다. / 작은 습관만으로도 수명이 눈에 띄게 달라집니다.
- 문을 닫을 때 손잡이를 잡은 채로 세게 밀지 않기
- 장바구니나 가방을 손잡이에 걸어 두지 않기
- 반년에 한 번 고정 나사를 가볍게 점검하기
- 손잡이가 돌아갈 때 걸리는 느낌이 있으면 일찍 점검받기
손잡이에 무거운 물건을 거는 습관만 바꿔도 헐거워지는 속도가 크게 느려집니다. / 가족이 같이 쓰는 문이라면 이 점을 한 번 알려 주세요.

# 이미 손잡이가 빠졌다면 부품을 챙겨 두세요
손잡이가 통째로 빠졌다면 빠진 손잡이와 함께 나사, 작은 금속 조각을 모두 모아 두시는 것이 좋습니다. / 부품이 하나라도 없으면 맞는 것을 찾는 데 시간이 더 걸립니다.
빠진 부품은 비닐봉지에 담아 문 가까이에 두시고, 도어락 모델 이름이 적힌 스티커가 있다면 사진으로 찍어 보내주세요. / 모델을 알면 필요한 부품을 미리 챙겨 올 수 있어 한 번에 끝낼 확률이 높아집니다.
손잡이가 빠진 자리에 보이는 네모난 축은 만지지 않는 것이 좋습니다. / 안쪽 부품이 함께 빠질 수 있기 때문입니다.
@ 기배동 도어락 손잡이 부품 교체 출장

# 기배동 말고 화성 어디든 갑니다
병점동, 진안동, 새솔동은 물론 동탄 쪽 반송동, 능동, 청계동, 목동, 봉담읍, 향남읍, 남양읍까지 화성 안이라면 24시간 출동합니다. / 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
늦은 밤이나 새벽에도 전화를 받습니다. / 위치를 알려주시면 예상 도착 시간을 먼저 말씀드립니다.
