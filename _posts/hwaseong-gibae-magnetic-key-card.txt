# 기배동에서 카드키가 사라졌다면
기배동은 병점역과 동탄 쪽으로 오가며 생활하는 분들이 많은 동네입니다. / 출퇴근길에 카드키를 어디선가 흘렸다는 연락이 가끔 옵니다.
자석 카드키는 작고 얇아서 지갑이나 주머니에서 쉽게 빠집니다. / 휴대 열쇠는 열쇠고리에 달려 있어도 가방 속에서 잃어버리기 쉽습니다.
이 글은 자석 카드키와 휴대 열쇠를 잃어버렸을 때 집이 안전한지, 먼저 무엇을 해야 하는지 정리했습니다.
@ 기배동 자석 카드키 분실 현관 점검

# 자석 카드키는 어떤 방식으로 열리나요
오래된 카드와 새 카드가 섞여 있는 집도 있어서 가족이 몇 장을 쓰는지 알아두면 좋습니다. / 분실 때 몇 장이 남았는지 세어 보는 것이 첫걸음입니다.
도어락에 카드를 대면 안에 든 자석 정보를 읽어 문이 열립니다. / 번호를 누르지 않아도 되어 아이나 어르신이 편하게 씁니다.
카드는 도어락에 미리 등록된 것만 열 수 있습니다. / 등록하지 않은 카드는 갖고 있어도 열리지 않습니다.
그래서 분실했을 때 중요한 것은 그 카드가 누구 손에 들어갔는지 모른다는 점입니다. / 주운 사람이 우연히 이 집을 찾을 가능성은 낮지만 안심하긴 어렵습니다.

# 잃어버렸다고 바로 문을 바꿀 필요는 없습니다
많은 분들이 카드키를 잃어버리면 도어락 전체를 교체해야 하나 걱정합니다. / 대부분은 그럴 필요가 없습니다.
도어락에서 분실한 카드의 등록을 지우고 새 카드를 다시 등록하면 됩니다. / 이렇게 하면 잃어버린 카드는 더 이상 쓸 수 없는 물건이 됩니다.
제품에 따라 카드를 한 장씩 지우기도 하고 전체를 초기화한 뒤 남은 카드만 다시 등록하기도 합니다. / 어느 방식인지는 도어락 설명서나 모델에 따라 다릅니다.

# 먼저 확인할 것 네 가지
기배동 집들은 출퇴근 동선이 길어 카드를 여러 곳에서 꺼내 쓰는 경우가 많습니다. / 지나온 길을 거꾸로 되짚으면 의외로 가까운 곳에서 찾기도 합니다.
카드키가 없다고 바로 속단하지 말고 아래부터 보세요.
- 코트, 가방 안쪽 주머니, 차 안 수납함을 다시 뒤져 보기
- 마지막으로 카드를 쓴 곳과 시간을 떠올리기
- 집 안에 다른 가족이 가진 카드가 있는지 확인하기
- 번호로도 여는 도어락이라면 번호가 가능한지 시험하기
번호와 카드를 같이 쓰는 도어락이라면 카드만 없어져도 번호로 들어갈 수 있습니다. / 카드만 쓰는 제품이면 이야기가 달라집니다.

# 카드만 쓰는 도어락이라면 막막합니다
번호판이 없는 카드 전용 도어락은 카드를 잃으면 문 앞에서 막힙니다. / 이 경우에는 열쇠가 따로 달려 있는지 먼저 확인해 보세요.
많은 제품은 문 바깥쪽 아래나 위쪽에 열쇠 구멍이 숨어 있습니다. / 덮개를 밀거나 뽑으면 보이는 경우가 있습니다.
열쇠도 없고 카드도 없다면 신분 확인 후 문을 여는 방법이 필요합니다. / 문과 도어락이 상하지 않는 방법부터 시도합니다.
@ 기배동 카드 전용 도어락 현관 개문

# 휴대 열쇠를 잃어버렸을 때는 사정이 다릅니다
열쇠는 복사된 열쇠가 어딘가에 돌아다니면 누구든 쓸 수 있다는 점이 다릅니다. / 열쇠에 집 주소가 적혀 있다면 더 신경 써야 합니다.
열쇠만 쓰는 문이라면 열쇠를 바꿔야 마음이 놓입니다. / 도어락과 열쇠를 같이 쓰는 문이라면 열쇠 부분만 새로 교체하는 방법도 있습니다.
잃어버린 장소가 분명히 집 안이라면 서둘러 바꿀 필요는 없습니다. / 하지만 밖에서 잃었다면 오늘 안에 조치하시길 권합니다.

# 주운 사람이 알 수 있는 정보를 줄이세요
분실물 센터나 지나온 가게에 문의해 두는 것도 한 방법입니다. / 하루이틀 안에 찾지 못하면 등록 삭제를 서두르세요.
카드나 열쇠에 이름이나 집 주소를 적어 두었다면 이제 지우는 게 좋습니다. / 새로 만들 때는 겉에 아무것도 적지 않는 편이 안전합니다.
열쇠고리에 달린 현관 출입 카드나 공동현관 카드는 같이 잃어버렸는지 확인하세요. / 건물 관리사무소에 말하면 해당 카드를 정지할 수 있습니다.
차 열쇠와 집 열쇠를 한 꾸러미에 달았다면 차량 쪽 조치도 필요합니다.

# 전화하기 전에 준비하면 좋은 것
출장 요청을 하실 때 아래를 알려주시면 판단이 빠릅니다.
- 카드만 잃었는지, 열쇠도 같이 잃었는지
- 도어락 앞면 사진과 모델 이름
- 문이 지금 잠겨 있는지 열려 있는지
- 집 안에 사람이나 반려동물이 있는지
기배동 어느 쪽인지 대략 알려주시면 도착 시간을 말씀드립니다. / 병점역 쪽에서 오시는 중이라면 그것도 알려주세요.

# 도착하면 사시는 분인지 먼저 확인합니다
카드를 잃은 상황에서는 신분 확인이 특히 중요합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증을 같은 지갑에 넣어 두고 잃어버린 경우가 많습니다. / 그럴 때는 관리사무소에서 세대 확인을 받는 방법을 안내해 드립니다.
확인이 어려우면 작업을 할 수 없으니 방법을 미리 생각해 두세요.

# 비용은 작업 전에 먼저 말씀드립니다
등록 삭제로 끝날지 부품이 필요한지 보고 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 말없이 붙는 비용도 없습니다.
이용 흐름은 [이용안내](guide.html)에 적어 두었습니다. / 문 여는 방법은 [현관문 개문](door-open.html) 페이지에서 보실 수 있습니다.

# 열린 뒤 카드 등록을 정리합니다
등록 삭제와 새 등록이 끝나면 분실한 카드로 열어 보려 해서 열리지 않는지 확인하는 방법도 있습니다. / 새 카드가 정상으로 읽히는지는 문을 닫은 채로 두세 번 시험하세요.
문이 열리면 먼저 분실한 카드 등록을 지웁니다. / 새 카드를 등록하고 문을 닫았다 열어 보며 잘 읽히는지 확인합니다.
남은 카드가 있다면 그것도 한 번씩 대 보게 해 드립니다. / 가족 수만큼 카드가 있는지 세어 보는 것도 좋습니다.
카드 방식이 불편하다면 번호나 지문으로 바꾸는 이야기도 할 수 있습니다. / 필요하면 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html) 안내를 참고하세요.
@ 기배동 새 카드 등록과 도어락 점검

# 카드를 덜 잃어버리는 습관
- 카드를 열쇠고리나 교통카드 지갑에 고정해 두기
- 여분 카드를 믿을 만한 가족에게 맡기기
- 카드 한 장에 의존하지 않고 번호도 함께 쓰기
- 분실한 날 바로 등록을 지우기
작은 습관 하나로 잃어버려도 침착하게 대응할 수 있습니다.

# 기배동 말고 화성 어디든 갑니다
기배동 가까운 병점동, 진안동은 물론 동탄, 봉담, 향남까지 다닙니다. / 다니는 곳은 [화성시 출장열쇠](hwaseong.html) 페이지에 정리해 두었습니다.
다른 지역은 [출장 지역](area.html)에서 확인할 수 있습니다.
