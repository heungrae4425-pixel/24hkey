# 기배동 한겨울 밤, 문이 잠겨 밖에 서 있다면
기배동은 병점역 쪽으로 오가며 퇴근하는 분들이 많은 동네입니다. / 한겨울 늦은 밤 집 앞에서 문이 안 열리면 열쇠 걱정보다 추위가 먼저 몸에 닥칩니다.
바람이 센 복도, 얼어붙은 계단 앞에서 오래 서 있으면 손발이 금세 굳어 번호를 누르기도 어려워집니다. / 이 글은 문이 열릴 때까지 기다리는 동안 몸을 지키는 방법을 먼저 정리했습니다.
@ 기배동 한겨울 밤 현관 앞 대기

# 추운 밤에 문이 잠기면 더 서두르게 됩니다
몸이 떨리고 손이 곱으면 마음이 급해져 무리한 시도를 하기 쉽습니다. / 문을 세게 당기거나 도어락을 두드리다 오히려 고장을 내는 경우가 있습니다.
먼저 몸부터 보호하세요. / 겨울밤에는 바람이 불면 체감 온도가 크게 내려가 같은 기온에서도 훨씬 춥게 느껴집니다. / 장갑이나 목도리가 없다면 가방이나 외투 소매로라도 손과 목을 감싸 주세요. / 문은 전문가가 와서 열면 되지만 저체온이나 동상은 되돌리기 어렵습니다.

# 기다리는 동안 몸을 지키는 순서
- 바람을 막아 주는 곳으로 이동하기 (건물 1층 현관, 계단 아래 등)
- 가까운 편의점이나 24시간 가게가 있으면 들어가 몸 녹이기
- 목, 손, 귀를 가리고 손은 주머니나 겨드랑이에 넣기
- 따뜻한 음료 마시기, 가능하면 술은 피하기
- 가만히 서 있지 말고 제자리에서 가볍게 몸 움직이기
문 앞을 꼭 지킬 필요는 없습니다. / 도착 시간에 맞춰 내려와 만나면 됩니다.

# 위험 신호가 보이면 문보다 먼저입니다
몸 떨림이 멎고 말이 어눌해지거나 졸음이 쏟아지면 저체온 위험 신호일 수 있습니다. / 이때는 문 여는 일을 잠시 미루고 119에 먼저 연락하세요.
열쇠집은 구급 대응을 하지 못합니다. / 손발이 하얗게 변하거나 감각이 없을 때도 마찬가지로 몸을 먼저 챙기세요.
집 안에 사람이 있는데 응답이 없다면 119와 함께 저에게도 상황을 알려 주세요.

# 집 안에 아이나 어르신, 반려동물이 있을 때
겨울에 보일러를 꺼 둔 채 비운 집이나 난방이 약한 집은 안에 있는 사람도 추위에 노출됩니다. / 특히 혼자 계신 어르신이나 어린 아이라면 문 열기를 서둘러야 합니다.
이런 상황은 전화로 꼭 먼저 말씀해 주세요. / 순서를 앞당겨 출동하고 문 너머로 안부를 확인하는 방법도 안내해 드립니다.
난방이 켜져 있는지, 창이 닫혀 있는지 아는 만큼 알려주시면 도움이 됩니다.
@ 기배동 집 안 어르신 아이 있는 겨울밤 상황 안내

# 추운 날 도어락이 말썽인 이유
한겨울에는 건전지가 추위에 약해져 전압이 떨어지고 번호판이 늦게 반응합니다. / 평소 멀쩡하던 도어락이 갑자기 꺼지거나 경고음을 내는 것도 같은 이유입니다.
호주머니에 손을 넣어 체온으로 건전지를 데운 뒤 비상 전원을 대 보면 되살아나는 경우도 있습니다. / 열쇠 구멍에 습기가 얼어붙어 열쇠가 안 들어가는 일도 있습니다.
얼어붙은 구멍에 뜨거운 물을 붓지는 마세요. / 입김을 불거나 손난로를 잠깐 대 주는 정도는 괜찮지만 불로 데우는 것은 위험합니다. / 금세 다시 얼어 더 나빠집니다.

# 전화하기 전에 확인할 것
몸이 견딜 만할 때 아래를 확인해 보세요. / 확인한 내용을 알려주시면 도착이 빨라집니다.
- 번호판을 터치하면 불이 들어오는지
- 번호를 눌렀을 때 소리가 나는지
- 도어락 아래 비상 전원 단자가 있는지
- 문 틈새가 얼어붙은 건 아닌지
9V 건전지가 있다면 비상 단자에 대 볼 수 있지만, 추운 밤에 오래 붙잡고 있기보다 먼저 전화를 주세요.

위치를 설명하실 때는 아래도 같이 알려주세요.
- 기배동 어느 건물 몇 층, 병점역 쪽에서 어느 방향인지
- 지금 계신 곳이 바람을 피한 곳인지
- 집 안에 사람이나 동물이 있는지
- 문이 잠겼는지, 얼어서 안 열리는지
- 번호판 상태와 도어락 모양
눈이나 빙판이 있는 날은 이동 시간이 평소보다 걸릴 수 있어 도착 예상 시간을 미리 말씀드립니다.

# 도착하면 먼저 사시는 분인지 확인합니다
추운 밤이라도 신원 확인은 빠뜨리지 않습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 가능한 것이면 됩니다.
신분증이 집 안에 있다면 경비실이나 관리사무소를 통해 세대 확인을 받으시면 됩니다. / 밖에서 오래 기다리지 않도록 서류는 미리 준비해 두세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
추운 밤에 길게 설명을 듣는 것도 힘드니 핵심만 먼저 짧게 말씀드립니다. / 자세한 내용은 따뜻한 곳에서 편하게 물어보셔도 됩니다.
문 상태와 도어락 종류를 보고 어떤 작업이 필요한지 먼저 설명드립니다. / 괜찮다고 하시면 시작하고, 아니면 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다. 진행 방식은 [이용안내](guide.html)에서 보실 수 있습니다.

# 문을 상하지 않게 엽니다
추워도 서두르다 문을 상하게 하는 방법은 쓰지 않습니다. / 덜 상하는 방법부터 차례로 시도하고 필요하면 설명드립니다.
문이 얼어 붙은 경우에는 문틀을 상하지 않게 조심하며 풉니다. / 개문 방식은 [현관문 개문](door-open.html) 페이지에 자세히 정리했습니다.

# 열린 뒤에는 몸을 녹이고 도어락을 점검하세요
얼었던 몸이 갑자기 따뜻한 곳에 들어가면 손발이 저리고 아플 수 있습니다. / 뜨거운 물에 바로 담그지 말고 미지근한 곳에서 천천히 녹이세요.
문이 열리면 따뜻한 곳에서 먼저 몸을 녹이세요. / 몸이 풀린 뒤 도어락과 배터리 상태도 함께 봅니다.
- 배터리를 모두 새것으로 교체
- 번호판에 습기나 얼음이 남지 않았는지
- 문틈 고무 패킹이 얼어 떨어진 곳은 없는지
- 새 번호가 필요하면 안쪽에서 등록
배터리 문제가 계속되면 [도어락 수리](doorlock-repair.html)를 먼저 알아보고, 많이 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 겨울 밤에 문 앞에서 떨지 않으려면
- 겨울 오기 전에 도어락 배터리 교체
- 비상용 9V 건전지를 가방에 하나 넣어 두기
- 열쇠 구멍이 있다면 열쇠를 믿을 만한 곳에 한 벌 보관
- 외출 때 휴대폰, 열쇠, 카드 다시 확인
- 문틈 고무 패킹에 물이 고이지 않게 닦기
- 눈이 오는 날에는 현관 앞 발판 물기를 털어 문 아래 얼음이 생기지 않게 하기
- 퇴근이 늦는 날에는 가족에게 도착 시간을 미리 알려 두기
건전지는 밖에 오래 두면 더 빨리 닳으니 현관 안쪽이나 실내에 보관하는 편이 낫습니다. / 미리 준비하면 추운 밤에 문 앞에서 시간을 보내는 일이 크게 줄어듭니다.

@ 기배동 따뜻한 곳에서 출장열쇠 도착 기다리기

# 기배동 말고 화성 어디든 갑니다
기배동 가까운 병점동, 진안동, 반송동, 능동은 물론 오산동, 장지동, 봉담읍, 향남읍, 남양읍까지 다닙니다. / 화성 안이면 24시간 연락 받습니다.
[화성시 출장열쇠](hwaseong.html)와 [출장 지역](area.html)에서 다니는 동네를 확인하세요.

? 몸이 너무 추운데 먼저 어떻게 하나요? | 바람을 피할 곳으로 이동하세요. 떨림이 멎거나 정신이 흐리면 119에 먼저 연락하세요.

# 마무리
한겨울 밤에 문이 잠기면 문보다 먼저 내 몸을 지키는 것이 중요합니다. / 바람을 피한 곳에서 기다리며 상황만 알려주시면 문은 상하지 않게 열겠습니다.
24시출장열쇠는 기배동을 포함한 화성 전 지역에서 24시간 전화를 받습니다. / 전화 010-3664-5455로 연락 주세요.
