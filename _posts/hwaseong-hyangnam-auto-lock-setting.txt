# 문이 저절로 잠겨서 곤란했던 경험
향남읍은 향남 생활권에서 출퇴근하는 분들이 많은 동네입니다. / 짐을 들고 나가다 문이 철컥 하고 잠겨 버리거나, 반대로 문이 안 잠겨서 불안했던 경험을 하는 분이 있습니다.
많은 도어락에는 문이 닫히면 일정 시간 뒤 저절로 잠기는 자동 잠김 기능이 있습니다. / 이 시간 설정이 헷갈리면 이런 일이 반복됩니다.
이 글은 향남읍에서 자동 잠김 설정 때문에 생기는 문제와 확인 순서를 정리했습니다. / 직접 해결이 어려울 때 [화성 출장열쇠](hwaseong.html)를 부르는 방법도 뒤에 적었습니다.
@ 향남읍 도어락 자동 잠김 시간 설정

# 자동 잠김이 하는 일
자동 잠김은 문이 닫힌 뒤 정해진 시간이 지나면 모터가 걸쇠를 내보내는 기능입니다. / 손으로 따로 잠그지 않아도 잠기니 편한 대신 놓치기 쉬운 부분이 있습니다.
도어락마다 시간이 다르고, 아예 끄는 설정이 있는 제품도 있습니다. / 어떤 모델은 몇 초 단위로, 어떤 모델은 문을 열고 닫는 순간 바로 잠깁니다.
그래서 같은 집에서 이전 도어락과 달리 반응해 당황하는 일이 생깁니다.

# 이런 상황에서 문제가 생깁니다
자동 잠김 때문에 곤란해지는 순간은 정해져 있습니다. / 아래 같은 경우가 가장 많습니다.
- 택배를 받으려고 문만 열고 나왔다가 문이 닫혀 잠긴 경우
- 쓰레기를 버리러 나갔는데 열쇠나 폰을 두고 나온 경우
- 아이가 문을 닫고 나가 나중에 잠겨 있는 것을 몰랐던 경우
- 문을 열어 두려고 했는데 잠김 시간이 짧아 닫히며 잠긴 경우
특히 번호를 외우지 못한 상태에서 나가면 혼자 막히기 쉽습니다.

# 설정 방식은 모델마다 다릅니다
자동 잠김 설정은 안쪽 설정 버튼이나 관리자 번호로 들어가는 제품이 많습니다. / 음성 안내를 따라가며 시간을 고르는 방식도 있습니다.
- 설정 모드에 들어가는 버튼 위치가 모델마다 다름
- 시간 항목이 번호로 나뉘어 있어 선택이 헷갈림
- 관리자 번호를 설정하지 않은 상태에서는 접근이 안 되는 경우
설명서가 없으면 모델명 뒷면 스티커를 확인해 사진으로 보내 주세요. / 어떤 방식인지 확인해 드립니다.
@ 향남읍 도어락 안쪽 설정 버튼 자동 잠김

# 잠김 시간이 너무 짧을 때
문을 닫고 짐을 정리하는 사이에 이미 잠겨 버린다면 설정이 짧은 것입니다. / 이런 집은 나갈 때 항상 번호를 알고 폰과 열쇠를 챙겨야 합니다.
시간을 늘릴 수 있는 모델이면 조금 여유 있게 바꿔 보세요. / 그 대신 잠김이 늦어져 문이 열린 채 오래 둘 수 있으니 습관을 함께 들여야 합니다.
시간을 바꾸는 설정이 없는 제품이라면 외출할 때 문을 완전히 닫고 소리를 확인하는 습관이 좋습니다.

# 잠김 시간이 너무 길거나 꺼져 있을 때
반대로 문을 닫았는데 한참 안 잠겨서 불안한 경우도 있습니다. / 자동 잠김이 꺼져 있거나 시간이 길게 설정된 상태일 수 있습니다.
외출할 때 문을 닫고 나서 손잡이를 위로 올리거나 잠금 버튼을 눌러야 하는 모델이 있습니다. / 잠겼는지 확인하는 소리나 불빛을 눈여겨보세요.
방문 손님이나 아이가 드나드는 집이라면 자동 잠김이 켜져 있는 편이 낫습니다. / 불안하면 [현관 방범 점검](guide.html) 요령을 이용안내 페이지에서 참고하세요.

자동 잠김이 작동했는데 안쪽에서 보조키까지 돌려 둔 경우 문이 안 열릴 수 있습니다. / 번호가 맞는데도 문이 꿈쩍하지 않는다면 이 경우를 의심해 보세요.
보조키를 푼 다음 손잡이를 돌려야 열리는 구조의 문도 있습니다. / 안에 가족이 있다면 먼저 보조키를 풀어 달라고 부탁해 보세요.
혼자 계신 상황이라면 억지로 당기지 마세요. / 걸쇠와 문틀이 상하면 일이 커집니다.

# 문 앞에서 먼저 해볼 수 있는 확인
자동 잠김이 켜진 집은 외출 전에 폰과 열쇠를 챙겼는지 현관에서 한 번 더 보는 습관이 도움이 됩니다. / 잠깐 나갈 때도 마찬가지입니다.
잠겨 버린 문 앞에서 아래 세 가지를 먼저 보세요. / 상황을 알면 전화 설명도 쉬워집니다.
- 번호판에 불이 들어오는지
- 번호를 눌렀을 때 소리가 나는지 경고음이 나는지
- 열쇠 구멍이 있다면 열쇠가 집 안에 있는지
번호판이 안 켜지면 배터리가 다 됐을 수 있습니다. / 이 경우 9V 건전지 비상 전원으로 번호판을 깨울 수 있는 모델이 있습니다.
@ 향남읍 도어락 자동 잠김 문 앞 확인

# 억지로 열려는 시도는 피해 주세요
자동 잠김으로 닫힌 문을 급하게 열려다 손잡이를 세게 당기는 분들이 있습니다. / 그러면 걸쇠가 더 꽉 물리거나 손잡이 축이 휘어 고장이 커집니다.
드라이버나 카드로 문틈을 벌리는 것도 피해 주세요. / 문틀과 도어락 외관이 상하면 나중에 교체 부담이 커질 수 있습니다.
번호를 여러 번 틀리면 잠금이 한동안 막히니 서너 번 해보고 멈추세요.

# 이런 상황에서 출장열쇠를 부릅니다
번호를 모르거나 열쇠가 집 안에 있다면 도움이 필요합니다. / 아래 같은 경우에 연락 주세요.
- 자동 잠김으로 문이 닫혔는데 번호가 기억나지 않을 때
- 번호는 맞는데 모터 소리만 날 때
- 배터리가 나가 비상 전원도 안 될 때
- 안에 아이나 반려동물이 있을 때
통화할 때 도어락 모양과 번호판 상태를 알려 주세요. / 사진을 문자로 보내 주시면 더 빠릅니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 해당 집에 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 본 뒤 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)와 [현관문 개문](door-open.html) 페이지에서 확인하실 수 있습니다.

# 열린 뒤 자동 잠김 시간 같이 맞춰 드립니다
문이 열리면 자동 잠김 시간이 지금 생활에 맞는지 같이 확인합니다. / 필요하면 안쪽에서 설정을 바꾸는 방법도 알려 드립니다.
설정이 잘 안 먹거나 모터가 약하면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 너무 낡은 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 향남읍 말고 화성 어디든 갑니다
향남읍뿐 아니라 동탄역 쪽, 병점역 쪽, 봉담까지 화성 안이면 24시간 출동합니다. / 동네별 안내는 [화성시 출장열쇠](hwaseong.html) 페이지에서 볼 수 있습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
