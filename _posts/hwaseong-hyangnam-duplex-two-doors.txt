# 향남읍 복층·투룸, 문이 여러 개라 더 막막합니다
향남 생활권에는 원룸보다 넓은 투룸이나 복층 구조의 집도 적지 않습니다. / 이런 집은 현관문 말고도 방문, 다락 문, 화장실 문처럼 잠기는 문이 여러 개입니다.
현관문이 안 열리는 것도 당황스러운데 안쪽 방문까지 잠겨 있으면 상황이 더 복잡해집니다. / 어느 문이 어떤 이유로 잠겼는지 구분해 보는 일이 우선입니다.
이 글은 [화성 출장열쇠](hwaseong.html)를 부르기 전에 향남읍 투룸·복층 집에서 문이 겹쳐 잠겼을 때 살펴볼 순서를 적었습니다.
@ 향남읍 복층 구조 투룸 현관과 방문

# 문이 겹쳐 잠기는 대표적인 경우
복층이나 투룸에서는 이런 상황이 의외로 자주 생깁니다. / 하나씩 대조해 보시면 지금 상태를 짐작할 수 있습니다.
- 현관문을 나서며 닫았는데 방문까지 안에서 잠가 둔 채였던 경우
- 아이가 방 안에서 문 고리를 눌러 잠그고 현관도 잠긴 경우
- 복층 위층 방문이 아래층에서 보면 잠겨 있고 열쇠가 어디 있는지 모르는 경우
- 현관은 열렸는데 안방이나 작은방 문이 안에서 안 풀리는 경우
- 출입문 번호가 바뀌고 방문 열쇠도 따로 관리되던 경우
방문 잠금은 현관 도어락과 구조가 달라서 같은 방법으로 풀리지 않습니다. / 그래서 두 문을 나눠서 설명해 주시는 게 좋습니다.

# 먼저 현관문부터 해결해야 하는 이유
방문이 잠긴 상황에서도 일단 집 안으로 들어가야 풀 수 있는 경우가 대부분입니다. / 현관문이 열리지 않으면 방문 작업을 시작할 수 없습니다.
현관문은 번호판 상태를 가장 먼저 보세요. / 불이 안 들어오면 배터리, 소리만 나면 모터나 걸쇠를 의심해 볼 수 있습니다.
현관이 열린 뒤에 방문 상태를 다시 살펴보고 필요한 방법을 정합니다. / 두 번 따로 부르실 필요 없이 한 번 오셨을 때 같이 봅니다.
투룸은 방마다 문 두께와 손잡이 종류가 다른 경우가 있습니다. / 한 방은 버튼형이고 다른 방은 돌림형이라면 방법도 방마다 달라집니다.
복층은 계단참이나 중간 문이 있는 집도 있어 층마다 따로 확인해야 합니다. / 아래층에서 해결되면 위층 문도 이어서 점검합니다.

# 방문 잠금장치는 어떤 종류인지 보세요
집 방문에는 눌러서 잠그는 고리형, 돌려 잠그는 돌림형, 열쇠 구멍이 있는 형이 있습니다. / 종류에 따라 비상 해제 방법이 다릅니다.
안쪽에서 누르는 버튼형은 바깥 손잡이 가운데에 작은 구멍이 있는 경우가 많습니다. / 이 구멍에 가는 막대를 넣으면 풀리는 제품도 있습니다.
돌림형은 바깥쪽에 일자 홈이 있는 제품이 있어 동전이나 작은 드라이버로 돌려 푸는 경우도 있습니다. / 무리하게 힘을 주면 손잡이나 문짝이 상할 수 있어 조심하셔야 합니다.
@ 방문 손잡이 가운데 비상 해제 구멍

# 아이나 반려동물이 방 안에 있다면
방문이 안에서 잠겼는데 아이가 안에 있다면 서두르지 않는 게 먼저입니다. / 문 너머로 계속 말을 걸어 안심시켜 주세요.
아이가 직접 풀 수 있는 제품이면 손잡이 위치를 천천히 알려 주는 방법도 있습니다. / 어린아이라면 억지로 풀게 하지 말고 바로 연락 주시길 권합니다.
반려동물이 있는 경우에도 문을 세게 두드리거나 흔들면 더 놀랄 수 있습니다. / 이럴 때는 먼저 말씀해 주세요, 우선순위로 진행합니다.

# 복층 구조에서 위층 문이 잠긴 경우
복층에서는 위층으로 오르는 계단 입구나 다락방 문이 따로 있는 집이 있습니다. / 위층에 짐을 두고 입구를 잠가 둔 경우 열쇠가 어디 있는지부터 떠올려 보세요.
같이 사는 분이 열쇠를 가지고 나갔는지, 서랍이나 현관 선반에 있는지 확인해 보시면 좋습니다. / 보관 위치를 찾으면 의외로 해결이 빠릅니다.
못 찾았다면 문 종류와 높이, 위치를 알려 주세요. / 사다리나 장비가 필요할 수 있어 미리 알려 주시면 준비해 갑니다.

# 향남읍 위치는 이렇게 알려주세요
향남읍은 단지와 주택가가 다양해 대략적인 위치만 알려 주셔도 도움이 됩니다. / 아래 항목을 함께 말씀해 주세요.
- 건물 형태와 층, 호수
- 현관문과 방문 중 어느 쪽이 잠겼는지
- 현관 도어락 모양과 번호판 상태
- 방문 손잡이 종류(버튼형, 돌림형, 열쇠형)
- 방 안에 아이나 반려동물이 있는지
방문 손잡이 사진을 찍어 문자로 보내 주시면 챙길 장비를 정하기 쉽습니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
세입자라면 계약서 사본이나 집주인 확인도 참고가 됩니다.

# 하지 말아야 할 일
문이 안 열린다고 문짝을 어깨로 밀거나 발로 차는 건 피하세요. / 문틀이 틀어지고 걸쇠가 더 꽉 물리는 경우가 많습니다.
방문 틈에 신용카드를 끼워 억지로 밀면 카드가 부러지거나 문틈이 벌어집니다. / 얇은 방문은 손잡이 부품이 쉽게 상합니다.
도어락 번호를 여러 번 틀리면 입력이 잠시 막힐 수 있습니다. / 서너 번 해보고 안 되면 멈추는 게 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
현관문과 방문 상태, 도어락 종류를 보고 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 방문 손잡이 비상 개방 작업 모습

# 문을 최대한 상하지 않게 엽니다
얇은 방문은 현관문보다 훨씬 쉽게 상합니다. / 그래서 손잡이와 문틀이 남도록 비파손 방식부터 해봅니다.
현관 개문 과정은 [현관문 개문](door-open.html) 페이지에 자세히 적었습니다. / 방문은 구조가 단순해 오래 걸리지 않는 경우가 많습니다.
이미 손잡이가 망가진 문이라면 열고 난 뒤 교체 여부를 같이 정합니다.

# 열고 난 뒤 확인하고 정리할 것
문이 열리면 현관과 방문이 다시 정상으로 잠기고 풀리는지 확인합니다. / 방문 비상 해제 방법을 가족에게도 알려 두면 다음에 도움이 됩니다.
번호를 잊어서 연 경우에는 새 번호 등록까지 같이 합니다. / 손잡이가 헐거워졌으면 [도어락 수리](doorlock-repair.html)로 손볼 수 있습니다.
잠금장치가 너무 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 향남읍 말고 화성 어디든 갑니다
향남읍 옆으로 봉담읍, 남양읍, 병점동, 동탄 쪽까지 화성 안이면 24시간 출동합니다. / 거리에 따라 도착 시간이 달라 위치를 먼저 알려 주세요.
다니는 동네는 [화성시 출장열쇠](hwaseong.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
