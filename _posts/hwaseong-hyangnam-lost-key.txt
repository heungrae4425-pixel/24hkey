# 향남읍 단지 앞에서 열쇠가 없다는 걸 알았을 때
향남읍은 단지와 상가, 주택이 넓게 퍼져 있어 집을 나설 때와 돌아올 때 이동 거리가 긴 편입니다. / 그래서 열쇠를 어디서 놓쳤는지 되짚기도 쉽지 않습니다.
열쇠를 잃어버렸거나 집 안에 두고 나와 문이 닫혀 버렸을 때 먼저 해볼 것을 정리했습니다. / 이어서 [화성 출장열쇠](hwaseong.html)가 어떤 순서로 여는지도 적었습니다.
@ 향남읍 열쇠 분실 문 잠김 출장열쇠

# 먼저 둘을 구분하세요
열쇠를 잃어버린 것과 집 안에 두고 나온 것은 대처가 다릅니다. / 어느 쪽인지에 따라 문을 열고 난 뒤 해야 할 일도 달라집니다.
- 집 안에 두고 나왔다면 문만 열면 끝나는 경우
- 어딘가에서 잃어버렸다면 열고 난 뒤 잠금 장치를 점검해야 하는 경우

# 잃어버린 경우, 먼저 찾아볼 곳
마지막으로 쓴 곳을 짚어 보세요. / 차 안, 가방 속, 직장 책상, 마지막으로 들른 가게가 흔한 후보입니다.
카드키나 키링이 따로 달려 있다면 그쪽도 같이 확인하세요. / 집 가까이에서 떨어뜨렸다면 현관 앞 계단과 엘리베이터도 한 번 보세요.

# 열쇠가 남의 손에 있을 수 있다면
집 주소가 알려지는 물건을 잃어버렸다면 문을 열고 난 뒤 잠금 장치를 바꾸는 게 안전합니다. / 도어락이라면 번호 변경으로, 열쇠 방식이라면 실린더 교체로 대응합니다.
꼭 바꿔야 하는 건 아니고 상황에 따라 말씀드립니다. / 그대로 써도 되는 경우에는 교체를 권하지 않습니다.

# 집 안에 열쇠를 두고 나온 경우
택배를 받으러 잠깐 나왔는데 문이 닫혀 버린 일이 가장 흔합니다. / 자동으로 잠기는 도어락은 문이 닫히는 순간 잠깁니다.
휴대폰도 집 안에 있다면 이웃에게 전화를 빌리거나 관리사무소에 연락해 주세요. / 이럴 때는 전화번호를 하나쯤 외워 두면 좋습니다.
@ 향남읍 자동 잠김 도어락 열쇠 두고 나옴

# 절대 하지 말아야 할 것
급한 마음에 문틈에 카드를 끼우거나 드라이버로 벌리는 분이 있습니다. / 문틀과 도어락 외관이 상하고 오히려 열기 어려워집니다.
창문으로 넘어가려다 다치는 경우도 있어 위험합니다. / 높은 층이라면 더더욱 하지 마세요.

# 전화하면 이렇게 진행됩니다
위치와 도어락 모양, 열쇠를 두고 나왔는지 잃어버렸는지만 알려주시면 됩니다. / 출동 여부와 도착 예상 시간을 먼저 말씀드립니다.
도착 후에는 사시는 분인지 확인하고, 비용을 먼저 말씀드린 뒤 시작합니다. / 마음에 안 드시면 시작하지 않고 돌아갑니다.

# 사시는 분인지 확인합니다
신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다. / 신분증도 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요.
번거로우시겠지만 이웃과 손님 모두를 지키기 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없습니다.

# 문 여는 방법은 최대한 덜 상하게
문을 여는 방법은 여러 가지가 있고, 덜 상하는 방법부터 차례로 해봅니다. / 현관문 종류와 도어락에 따라 걸리는 시간이 다릅니다.
자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 부품을 바꿔야 할 때는 손대기 전에 먼저 여쭤봅니다.
@ 향남읍 출장열쇠 24시간 현관문 개문

향남읍 상가 주택이나 다세대처럼 열쇠를 쓰는 집이라면 문을 연 뒤 열쇠를 새로 만들 수 있는지도 함께 봐 드립니다. / 오래된 열쇠 구멍은 현장에서 맞는 열쇠를 만들기 쉬운 경우가 많습니다.
열쇠를 잃어버렸는데 집 주소가 적힌 물건과 함께 잃어버렸다면 문을 연 뒤 잠금 장치를 바꾸는 쪽을 권해 드립니다. / 그렇지 않은 경우에는 그대로 써도 되는지 솔직하게 말씀드립니다.
여러 가족이 열쇠를 나눠 쓰는 집이라면 열쇠 수를 먼저 세어 보시고 연락 주세요. / 몇 개 중 몇 개가 없는지 알면 어떻게 할지 판단하기 쉽습니다.

# 못 열면 비용은 받지 않습니다
도착해서 문을 끝내 열지 못하면 비용은 받지 않습니다. / 열었더라도 처음 말씀드린 비용 외에 붙는 것은 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다. / 모르는 부분은 전화로 편하게 물어보세요.

# 열고 난 뒤 점검할 것
- 도어락이 다시 잘 잠기고 열리는지
- 열쇠를 잃어버렸다면 번호나 실린더를 바꿀지
- 여분 열쇠를 어디에 둘지
- 문이 자동 잠금이라면 나갈 때 휴대폰과 열쇠 챙기는 습관 만들기

# 다음에 같은 일이 없게
현관 안쪽에 열쇠를 두는 자리를 정해 두면 나갈 때 한 번 더 보게 됩니다. / 비상용 열쇠나 카드를 믿을 수 있는 곳에 하나 맡겨 두는 것도 방법입니다.
자주 잠그고 나온다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)로 자동 잠금 기능을 점검해 볼 수 있습니다. / 필요 없는 기능은 끄는 것도 가능합니다.

# 향남읍 말고 화성 어디든 갑니다
향남, 남양, 봉담은 물론 병점, 진안, 동탄까지 화성 전 지역에 출동합니다. / 24시간 받으니 시간은 신경 쓰지 말고 전화 주세요.
다니는 동네는 [출장 지역](area.html) 지도에서 확인하실 수 있습니다. / 다른 시, 군도 가능한 곳이 많습니다.
