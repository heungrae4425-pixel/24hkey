# 불이 나가면 문 앞도 같이 멈춥니다
향남읍에서 저녁에 갑자기 집 전체가 어두워지는 일은 누구나 겪을 수 있습니다. / 향남 생활권에서 퇴근해 현관 앞에 서 보니 번호판까지 꺼져 있으면 당황스럽습니다.
대부분의 디지털 도어락은 집 전기가 아니라 자체 건전지로 움직입니다. / 그래서 정전 자체가 문을 막는 경우는 생각보다 많지 않습니다.
문제는 정전과 겹쳐서 다른 원인이 드러날 때입니다. / 이 글은 향남읍에서 정전이나 전기 점검 뒤에 문이 안 열릴 때 순서대로 확인할 것을 적었습니다.
@ 향남읍 정전 도어락 먹통 출장열쇠

# 정전과 도어락은 어떤 관계일까
건전지로 쓰는 도어락은 정전이 나도 번호를 누르면 정상으로 열립니다. / 그러니 번호판이 꺼져 있다면 정전보다 건전지 문제를 먼저 의심하는 게 맞습니다.
다만 아래 같은 경우는 정전이 직접 영향을 줍니다.
- 집 전기에서 전원을 따로 받는 방식의 도어락
- 공동현관이나 출입 시스템과 연결된 장치
- 복도 센서등과 함께 켜지는 번호판 조명
전기가 돌아온 순간 순간적인 전압 변화로 도어락이 먹통이 되는 일도 드뭅니다만 생길 수 있습니다. / 이때는 건전지를 뺐다가 다시 끼우면 돌아오기도 합니다.

# 전기 점검 안내문이 붙었던 날이라면
단지에서 전기 설비 점검을 한다고 안내문이 붙는 날이 있습니다. / 몇 시간 전기가 끊긴다는 공지를 보고도 잊고 외출하는 분이 많습니다.
점검이 끝나 전기가 들어올 때 현관 쪽 장치가 한 번 꺼졌다 켜집니다. / 그때 도어락이 설정을 잃거나 오류 소리를 내는 경우가 있습니다.
먼저 번호판을 손바닥으로 덮었다 떼며 불이 들어오는지 보세요. / 불이 들어오면 정전이 아니라 입력 방식이나 모터 문제일 수 있습니다.

# 번호판이 안 켜질 때 비상 전원부터
바깥쪽 아래에 9V 건전지를 대는 단자가 있는 제품이 많습니다. / 건전지를 대고 있는 동안은 전원이 들어와 번호를 누를 수 있습니다.
정전이 길어지는 밤에는 편의점도 불이 꺼져 건전지를 사기 어렵습니다. / 집에 쓰던 9V 건전지가 있다면 가방이나 차에 하나 넣어 두면 든든합니다.
단자가 보이지 않거나 건전지를 대도 반응이 없으면 그때 전화를 주세요. / 문 앞에서 오래 버티지 않으셔도 됩니다.

# 어두울 때 무리하게 만지면 생기는 일
어두운 현관에서 휴대폰 불빛으로 손잡이를 만지다 보면 힘이 들어가기 쉽습니다. / 손잡이를 세게 돌리거나 문을 흔들면 걸쇠가 더 깊이 물립니다.
카드나 얇은 도구를 문틈에 넣는 것도 권하지 않습니다. / 문틀 도장이 벗겨지고 도어락 안쪽 부품이 상할 수 있습니다.
비밀번호를 연달아 틀리면 도어락이 입력을 잠시 막습니다. / 두세 번 시도해서 안 되면 멈추고 숨을 돌리는 편이 낫습니다.

# 휴대폰 배터리도 같이 아껴 두세요
밖에서 기다리는 시간이 길어질 수 있다는 점도 생각해 두세요. / 향남읍처럼 밤에 인적이 드문 길목이라면 밝은 곳에서 기다리는 게 안전합니다.
정전이 나면 휴대폰을 손전등 대신 쓰다가 배터리가 빠르게 줄어듭니다. / 전화를 걸어야 할 때 꺼져 버리면 상황이 더 꼬입니다.
문 앞에 서기 전에 불빛은 최소한으로 쓰고 통화 가능한 배터리를 남겨 두세요. / 이웃에게 잠깐 전화를 빌리는 것도 방법입니다.
@ 화성 향남 정전 현관 도어락 비상 전원

# 출장 요청 때 알려주시면 좋은 정보
정전 상황에서는 위치를 말로 설명하기가 더 어렵습니다. / 아래 정보만 짧게 알려주시면 도착이 빨라집니다.
- 향남읍 안에서 대략 어느 쪽인지와 동, 호수
- 동네 전체가 정전인지 우리 집만 그런지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 도어락 모양 (손잡이 일체형, 버튼형, 밀고 당기는 형)
- 집 안에 아이나 반려동물, 켜 둔 가스불이 있는지
사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다. / 집 안에 어르신이나 아이가 계시면 꼭 먼저 말씀해 주세요.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
정전이면 관리사무소도 연결이 어려울 수 있어 우편물 사진이나 신분증을 미리 챙겨 두시면 좋습니다. / 확인이 어려우면 작업을 할 수 없으니 이 점은 양해 부탁드립니다.

# 비용은 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 열기 전에 상한 곳이 생기지 않게 합니다
어두운 현관에서는 작업 불빛을 따로 비추고 문과 도어락 외관을 먼저 살핍니다. / 덜 상하는 방법부터 차례로 해보고 안 될 때만 다음 방법으로 넘어갑니다.
정전이 원인이면 문을 열고 안쪽 건전지부터 새것으로 바꿔 드립니다. / 작업 방식은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.
@ 향남읍 출장열쇠 도어락 건전지 교체

# 전기가 돌아온 뒤 해둘 점검
전기가 들어오면 도어락 번호를 한 번 새로 눌러 정상으로 열리고 잠기는지 확인합니다. / 소리가 평소와 다르거나 모터가 느리면 그냥 쓰지 말고 점검받는 편이 낫습니다.
정전을 계기로 설정이 지워진 경우에는 등록된 번호를 다시 정리합니다. / 고장이 반복되면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
수리로 해결되는데 굳이 교체를 권하지는 않습니다. / 정전 한 번으로 멀쩡한 도어락을 바꿀 이유는 없습니다.

# 다음 정전을 대비한 습관
- 해가 바뀔 때쯤 건전지를 전부 새것으로 교체
- 9V 건전지 한 개를 현관 서랍이나 차에 보관
- 열쇠 키 하나는 집 밖 믿을 만한 곳에 따로 보관
- 단지 안내문의 전기 점검 날짜를 달력에 표시
- 경고음이 울리면 미루지 말고 그날 교체
정전은 예고 없이 오기도 하지만 준비해 둔 집은 덜 당황합니다. / 가족 모두가 비상 단자 위치를 알고 있으면 누가 먼저 도착해도 대처할 수 있습니다. / 작은 습관이 밤에 문 앞에서 막히는 일을 많이 줄여 줍니다.

# 향남읍 말고도 화성 어디든
향남읍 옆 동네와 병점, 봉담, 남양, 동탄까지 화성 안이면 24시간 출동합니다. / 지역별 안내는 [화성시 출장열쇠](hwaseong.html)에 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 페이지에서 보실 수 있습니다.
