# 향남읍에서 건전지가 꺼졌는데 예비가 집 안에 있다면
향남읍은 향남 생활권 안에서 출퇴근하고 장 보러 다니는 분들이 많은 동네입니다. / 집 앞에 도착했는데 도어락 번호판이 꺼져 있고 예비 건전지는 집 안 서랍에 있다면 참 난감합니다.
건전지 자체보다 예비를 어디에 두었느냐가 막상 닥쳤을 때 더 중요합니다. / 이 글은 향남읍에서 예비 건전지를 보관할 위치를 고르는 기준을 적었습니다.
위치를 정해 두어도 급한 상황이 생기면 [화성 출장열쇠](hwaseong.html)에서 도울 수 있습니다. / 예방과 비상 대응을 같이 다루었습니다.
@ 향남읍 도어락 예비 건전지 보관 위치

# 예비 건전지가 필요한 이유
도어락은 건전지가 약해지면 경고음으로 먼저 알려주는 제품이 많습니다. / 하지만 그 소리를 못 듣고 지나치면 어느 날 갑자기 꺼집니다.
예비를 미리 갖춰 두면 경고음이 났을 때 바로 교체할 수 있습니다. / 교체를 미루다 번호판이 완전히 꺼지기 전에 해결하는 것이 가장 쉬운 방법입니다.
꺼진 뒤에는 바깥쪽 비상 단자에 9V 건전지를 대는 방법이 있지만, 그 건전지를 가진 사람은 많지 않습니다.

# 집 안에만 두면 안 되는 이유
가장 흔한 실수는 예비 건전지를 집 안 서랍에 넣어 두는 것입니다. / 문이 잠긴 상황에서는 집 안에 있는 예비가 무용지물입니다.
집 안에 두는 건 교체용으로는 좋지만, 비상용으로는 따로 하나를 더 갖는 게 필요합니다. / 두 개를 서로 다른 장소에 나누어 두면 어느 한쪽이 막혀도 대응할 수 있습니다.
특히 혼자 사는 분은 문이 잠기면 다른 도움을 구하기 어려우니 더 중요합니다.

# 밖에 두는 보관 위치 후보
비상용은 문이 잠겼을 때도 손이 닿는 곳에 있어야 합니다. / 아래 후보를 각자 생활에 맞게 골라 보세요.
- 가방이나 지갑 속 작은 파우치
- 자동차 글러브박스나 문 쪽 수납칸
- 직장 책상 서랍
- 가까운 가족이나 믿을 만한 지인에게 맡겨 두기
집 앞 화분이나 신발장 위처럼 누구나 볼 수 있는 곳에 두는 것은 권하지 않습니다.

# 규격이 맞는지 먼저 확인하세요
도어락마다 쓰는 건전지 규격이 다릅니다. / 안쪽 덮개를 열어 AA 건전지인지, 다른 규격인지 확인해 두세요.
비상 단자용 9V 건전지와 몸체에 넣는 일반 건전지는 서로 다른 것입니다. / 둘 다 갖추면 가장 안전하지만, 하나만 둘 수 있다면 몸체 규격이 우선입니다.
모델명을 사진으로 찍어 두면 나중에 살 때 헷갈리지 않습니다.
@ 향남읍 도어락 건전지 규격 확인

# 건전지를 오래 두면 생기는 문제
예비로 사 둔 건전지도 시간이 지나면 힘이 약해집니다. / 사 둔 지 오래된 건전지는 새것처럼 힘을 못 내기도 합니다.
뜨겁거나 습한 곳에 두면 더 빨리 약해지니 보관 장소를 가려야 합니다. / 여름철 차 안은 온도가 크게 올라가므로 건전지 보관에 적합하지 않을 수 있습니다.
교체할 때마다 예비를 새것으로 바꿔 순환시키는 습관을 들이세요. / 예전 것을 먼저 쓰고 새것을 채워 두면 낭비가 줄어듭니다.

교체할 때 일부만 새것으로 바꾸고 나머지는 그대로 두면 오히려 문제가 됩니다. / 전압이 서로 달라 도어락이 불안정하게 동작할 수 있습니다.
모두 같은 종류로 한꺼번에 새것으로 바꾸는 것이 좋습니다. / 남은 건전지는 다른 리모컨이나 시계에 쓰고, 도어락에는 새것만 넣으세요.
포장을 뜯은 건전지를 낱개로 주머니에 넣고 다니면 서로 닿아 소모될 수 있습니다. / 작은 지퍼백이나 케이스에 따로 담아 두면 안전합니다.

# 위치를 정해도 가족이 모르면 소용없습니다
예비를 어디에 뒀는지 가족이 모르면 정작 필요한 때 찾지 못합니다. / 위치를 정했다면 가족 대화방에 한 줄로 남겨 두세요.
아이가 있는 집이라면 건전지는 삼키지 않도록 손이 닿지 않는 곳에 보관해야 합니다. / 비상용이라도 아이 눈에 띄는 곳은 피하는 것이 안전합니다.
부모님 댁이라면 직접 같이 정하고 눈에 보이는 메모를 붙여 드리면 좋습니다.
건전지를 넣어 둔 곳이 어디인지 한 번 같이 꺼내 보는 연습을 해 두면 막상 필요할 때 당황하지 않습니다. / 위치를 정한 날을 기억해 두었다가 해마다 한 번 상태를 같이 점검하세요.

# 문이 꺼진 뒤에 해볼 순서
예비를 챙겼다면 아래 순서로 시도해 보세요. / 급하다고 순서를 건너뛰면 오히려 시간이 더 걸립니다.
- 번호판에 손을 대 불이 들어오는지 확인
- 바깥쪽 아래의 비상 단자 위치 찾기
- 9V 건전지를 단자에 대고 번호 입력
- 열리면 안쪽에서 건전지를 전부 새것으로 교체
단자가 없는 제품이나 건전지를 대도 반응이 없으면 다음 단계로 가야 합니다.

모든 도어락에 비상 단자가 있는 것은 아닙니다. / 단자가 없는 제품은 외부에서 전원을 넣을 방법이 없어서 열쇠 구멍이 있는지 먼저 확인해야 합니다.
열쇠 구멍도 보조키도 없다면 문 자체를 여는 방법을 찾아야 합니다. / 이때는 억지로 힘을 쓰지 말고 전화로 상황을 설명해 주세요.

# 출장열쇠에 알려주실 것
건전지 때문에 문이 안 열릴 때 아래만 알려주셔도 충분합니다. / 도착 전에 필요한 장비를 정할 수 있습니다.
- 향남읍 어느 동네 쪽인지, 건물 이름 대신 동과 호수
- 번호판이 켜지는지, 소리가 나는지
- 비상 단자가 있는지, 열쇠 구멍이 있는지
- 집 안에 아이나 반려동물이 있는지
도어락 사진을 같이 보내주시면 상황 파악이 더 빨라집니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로워도 이웃과 집 주인 모두를 지키는 절차입니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁할 수 있습니다.

# 비용은 문을 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에서도 볼 수 있습니다.
@ 향남읍 비상 단자에 9V 건전지 대는 모습

# 열린 뒤에는 건전지를 점검하고 습관을 만듭니다
문이 열리면 건전지를 전부 새것으로 바꾸고 교체 날짜를 안쪽에 적어 둡니다. / 건전지만 갈았는데도 이상하다면 [도어락 수리](doorlock-repair.html)가 필요한지 같이 봅니다.
오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드리고, 현관문을 여는 과정은 [현관문 개문](door-open.html)에서 확인하실 수 있습니다. / 필요하지 않으면 교체를 권하지 않습니다.
