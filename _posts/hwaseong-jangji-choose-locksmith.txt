# 급할 때 고른 열쇠집이 문제가 되기도 합니다
동탄 장지동에서 문이 잠겨 급하게 검색해 보면 열쇠집이 수없이 나옵니다. / 마음이 급하니 가장 위에 뜬 곳에 바로 전화하게 되는데, 그 한 통이 결과를 크게 좌우합니다.
전화 한 번에 빨리 해결되는 경우도 있지만 설명과 다르게 일이 커질 가능성도 있습니다. / 그래서 연락하기 전에 몇 가지만 물어보면 훨씬 안심할 수 있습니다.
이 글은 열쇠집을 고를 때 볼 기준과 전화로 확인할 것들을 정리했습니다.
@ 동탄 장지동 열쇠집 고르는 기준

# 전화 받는 태도에서 먼저 드러납니다
전화를 받았을 때 상호와 통화 가능한 사람이 분명한지 보세요. / 상황을 차분히 묻고 이해하려는 태도인지가 첫 번째 기준입니다.
무조건 빨리 가겠다고만 하면서 물어보는 것이 없다면 한 번 더 생각해 보세요. / 문 상태를 묻지도 않고 확신하는 것은 오히려 이상한 일입니다.
통화하면서 메모를 하고 있는지, 말투가 불편하지 않은지도 중요합니다.
여러 곳에 전화해 보고 비교하는 것을 미안해하지 마세요. / 급해도 두세 곳은 물어봐야 차이가 보입니다.
상호가 분명하지 않거나 사업장 정보를 묻자 얼버무리는 곳은 피하는 편이 안전합니다.

# 전화로 꼭 물어볼 것 다섯 가지
통화할 때 아래 다섯 가지를 확인하면 대부분의 걱정이 정리됩니다.
- 지금 있는 곳까지 얼마나 걸리는지
- 문 열기 전에 비용을 먼저 말해 주는지
- 못 열었을 때 비용이 어떻게 되는지
- 사시는 분 확인을 하는지
- 문과 도어락을 상하지 않게 여는지
이 질문에 막힘없이 대답하는 곳이면 믿을 만하다고 봐도 됩니다. / 대답을 흐리거나 현장에 가서 말씀드린다는 말만 반복하면 조심하세요.

# 비용을 먼저 말해 주는지가 핵심입니다
가장 많이 문제가 되는 것은 문을 열고 난 뒤에 갑자기 비용이 늘어나는 상황입니다. / 그래서 작업 전에 비용을 먼저 말해 주는지가 중요합니다.
전화로 정확한 비용이 어려울 때도 있지만, 현장에서 상태를 본 뒤 시작 전에 말해 주는 곳이어야 합니다. / 작업을 시작해 놓고 나중에 금액을 올리는 방식은 피하세요.
저희는 문 열기 전에 먼저 말씀드리고 괜찮으실 때만 시작합니다.

# 못 열었을 때의 약속도 확인하세요
문이 끝내 안 열렸을 때 비용을 받는지 물어보세요. / 이 질문에 분명하게 답하는 곳이 드뭅니다.
24시출장열쇠는 못 열면 비용을 받지 않습니다. / 열기 전 말씀드린 내용 외에 말없이 붙는 비용도 없습니다.
상대가 이 부분을 분명히 하지 않는다면 다른 곳을 알아보는 것도 방법입니다.
열지 못했는데도 출장비 같은 이름으로 비용을 청구하는 곳이 있는지 미리 물어보면 좋습니다. / 대답이 애매하면 결과를 기대하기 어렵습니다.
@ 장지동 열쇠집 비용 사전 안내 출장

# 사시는 분 확인을 하는 곳인지 봅니다
문을 여는 일은 남의 집에도 쓰일 수 있는 일이라 신분 확인이 꼭 필요합니다. / 확인 없이 바로 열어 주겠다고 하는 곳은 오히려 위험합니다.
신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나는 요구하는 곳이어야 합니다. / 번거롭게 느껴져도 이웃과 본인 모두를 지키는 절차입니다.
저희도 도착하면 사시는 분인지 먼저 확인한 뒤에 작업을 시작합니다.
신분증이 집 안에 있다면 관리사무소나 경비실 확인을 부탁하는 방법도 안내드립니다. / 이 절차를 번거롭다고 빼 달라고 하셔도 지킬 수밖에 없는 점 이해 부탁드립니다.

# 현장 도착 후 이런 모습이면 믿어도 됩니다
도착하면 문과 도어락 상태를 먼저 살펴보고 설명해 주는지 보세요. / 설명 없이 바로 공구부터 꺼낸다면 한 번 멈추고 물어봐도 됩니다.
문을 상하지 않게 열 방법을 먼저 이야기하는지도 중요한 단서입니다. / 문이나 도어락을 부수고 나서 교체를 권하는 방식은 경계해야 합니다.
작업 중 궁금한 것을 물어봤을 때 성실하게 대답해 주는 모습을 보세요.
작업이 끝난 뒤 문이 잘 잠기고 열리는지 같이 확인하자고 하는지도 좋은 단서입니다. / 확인 없이 서둘러 돌아가는 모습은 아쉬운 부분입니다.

# 너무 쉽게 교체를 권하는 곳은 조심하세요
멀쩡한 도어락을 바로 바꾸자고 하는 곳은 주의가 필요합니다. / 열고 나서 고쳐 쓸 수 있는지 먼저 확인하는 것이 순서입니다.
- 열고 난 뒤 교체만 권하는 경우
- 왜 바꿔야 하는지 설명하지 못하는 경우
- 여러 번 말을 바꾸는 경우
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 해결하고, 오래돼서 어려울 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 장지동에서 위치를 정확히 알려야 하는 이유
동탄 장지동은 단지가 나뉘어 있어 정확한 위치를 알려 주셔야 빨리 도착합니다. / 동탄역 방향인지, 가까운 큰길이 어디인지 하나만 덧붙여 주세요.
- 단지 이름과 동, 호수
- 번호판 상태와 도어락 모양
- 집 안에 아이나 반려동물이 있는지
- 지금 어디서 기다리고 있는지
위치를 정확히 알려 주는 일이 도착 시간을 가장 크게 줄여 줍니다.
공동현관 비밀번호나 주차 안내가 필요한 곳이면 그것도 미리 말씀해 주세요. / 도착해서 건물에 들어가지 못하면 시간이 그만큼 늘어납니다.

# 사진을 보내 달라고 하는 곳이 좋습니다
도어락 사진을 먼저 보내 달라고 하는 곳은 준비를 하겠다는 뜻입니다. / 사진을 보면 어떤 장비가 필요한지 가늠할 수 있어 헛걸음을 줄입니다.
사진을 못 보내도 괜찮지만, 보내면 통화가 훨씬 짧아집니다. / 번호판 전체와 손잡이 모양이 나오게 찍어 두세요.
@ 장지동 도어락 사진 전송 출장열쇠 상담

# 이용 후기보다 설명 방식을 믿으세요
후기가 많다고 모두 믿을 수 있는 것은 아닙니다. / 후기는 참고만 하고, 통화에서 느낀 설명의 명확함을 더 믿는 편이 낫습니다.
숫자나 기록을 내세우기보다 진행 방식을 구체적으로 설명하는 곳이 낫습니다. / 저희도 진행 순서는 [이용안내](guide.html)에 그대로 적어 두었습니다.

# 문을 여는 방식도 물어볼 수 있습니다
상하지 않게 여는 방식을 쓰는지 한 번 물어보세요. / 방식은 [현관문 개문](door-open.html)에 자세히 적어 두었습니다.
어떤 방법을 쓰는지 대략 설명할 수 있는 곳이라면 믿을 수 있습니다. / 모든 걸 공개하기는 어렵더라도 문을 부수지 않는다는 점은 분명해야 합니다.
도어락 종류와 문 상태에 따라 시간이 달라지니 예상 시간도 물어보세요.

# 장지동 말고 화성 어디든 갑니다
장지동 옆 산척동, 반송동, 청계동, 영천동 등 동탄 지역과 병점동, 봉담읍, 향남읍도 다닙니다. / 화성 안이면 동네 상관없이 24시간 출동합니다.
[화성시 출장열쇠](hwaseong.html) 페이지에 다니는 동네가 있고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
