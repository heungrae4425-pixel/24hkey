# 장지동 현관문이 쾅 닫히거나 덜 닫힐 때
장지동은 동탄역 생활권에서 출퇴근하는 분이 많은 동네입니다. / 현관문이 자꾸 쾅 닫히거나 반대로 끝까지 안 닫혀 도어락이 잠기지 않는다는 문의가 이어집니다.
대부분 문 위쪽의 도어클로저 속도가 맞지 않아서 생기는 일입니다. / 도어락 고장으로 오해하고 교체까지 생각하는 분도 있는데, 원인은 다른 곳에 있는 경우가 많습니다.
이 글은 도어클로저 속도가 너무 빠르거나 느릴 때 어떻게 살펴볼지 정리했습니다. / 스스로 해볼 수 있는 것과 맡겨야 하는 것을 나눠 적었습니다.
@ 장지동 도어클로저 속도 조절 점검

# 도어클로저가 하는 일부터 알아두세요
도어클로저는 문이 열린 뒤 천천히 제자리로 돌려놓는 장치입니다. / 안에 기름이 들어 있어서 문이 닫히는 속도를 조절합니다.
문이 닫히는 구간은 크게 두 단계입니다. / 처음 넓게 닫히는 구간이 있고, 문틀 가까이에서 마지막으로 걸리는 구간이 있습니다.
이 두 구간의 속도가 따로 맞춰지지 않으면 이상하게 느껴집니다. / 문이 천천히 오다가 마지막에 쾅 하는 경우가 그렇습니다.

# 너무 빠르게 닫힐 때 생기는 일
문이 빠르게 닫히면 소음이 커지고 문틀이 울립니다. / 아이나 어르신이 손을 다칠 수 있어 가장 조심해야 하는 증상입니다.
도어락 본체에도 충격이 반복됩니다. / 오래 쓰면 나사가 풀리고 걸쇠가 헐거워질 수 있습니다.
- 닫히는 소리가 복도에 크게 울림
- 문을 놓으면 튕기듯 닫힘
- 장바구니를 든 채 들어오다 문에 부딪힘
이런 증상이 있다면 속도를 줄이는 쪽으로 조절이 필요합니다.

# 너무 느릴 때는 도어락이 잠기지 않습니다
반대로 문이 너무 천천히 닫히면 걸쇠가 문틀에 걸리기 전에 멈추기도 합니다. / 문이 닫힌 것처럼 보여도 도어락이 잠기지 않은 상태가 됩니다.
자동 잠금 도어락은 문이 닫혀야 잠기는데, 살짝 열려 있으면 번호판이 계속 울리기도 합니다. / 경고음이 나는 원인이 도어락이 아니라 클로저일 수 있다는 뜻입니다.
밤에 문을 닫고 나왔는데 잠기지 않아 불안했다는 분도 있습니다. / 이런 일은 속도를 조금 올리는 것만으로 해결되는 경우가 많습니다.

# 조절 나사는 어디에 있나요
도어클로저 몸체 옆면이나 끝에 작은 나사 구멍이 있습니다. / 보통 구간마다 하나씩 있고 제품에 따라 숫자나 화살표가 표시되어 있습니다.
조절 나사는 돌린 만큼 속도가 바뀝니다. / 한 번에 많이 돌리면 오히려 다시 맞추기 어려워집니다.
작은 드라이버로 사분의 일 바퀴씩만 돌리고 문을 열어 닫아 보세요. / 한 번 돌린 뒤 몇 번 열고 닫으며 느낌을 보는 것이 요령입니다.
@ 장지동 문 위 도어클로저 조절 나사

# 직접 해볼 때 지켜야 할 것
나사를 완전히 풀어 버리면 안에 든 기름이 샐 수 있습니다. / 한 번 샌 클로저는 속도 조절이 되지 않고 교체해야 합니다.
어느 나사를 돌렸는지 기억해 두세요. / 처음 상태에서 돌린 횟수를 적어 두면 되돌리기 쉽습니다.
조절 중에는 문 앞에 사람이 서 있지 않게 해 주세요. / 속도가 갑자기 달라지면 문이 튕길 수 있습니다.
기름이 묻어 있거나 몸체가 눌려 있다면 조절이 아니라 교체를 봐야 합니다.

# 속도가 안 맞는 다른 이유
조절해도 느낌이 안 바뀌면 다른 곳을 봐야 합니다. / 문이 처졌거나 경첩이 헐거운 경우 클로저가 제 힘을 못 냅니다.
문틀 모서리와 문이 스치는 소리가 난다면 경첩 나사를 확인해 보세요. / 문틀 안쪽에 칠이 벗겨진 흔적이 있으면 처짐의 신호입니다.
계절에 따라 속도가 달라지기도 합니다. / 겨울에는 안의 기름이 굳어 느려지고 여름에는 묽어져 빨라지는 경향이 있습니다.
이런 변화는 정상이니 계절이 바뀔 때 한 번 다시 맞춰 주면 됩니다.

# 장지동 집에서 실제로 자주 보는 모습
문을 열어 둔 채 짐을 들이는 일이 많은 집은 클로저가 쉽게 지칩니다. / 이사 날이나 택배가 많은 날 문을 오래 열어 두면 팔 부분에 무리가 갑니다.
현관에 발매트를 두면 문 하단과 부딪혀 속도가 달라지는 경우도 있습니다. / 문 아래 틈에 낀 이물질이 원인인 일도 흔합니다.
문을 열고 중간에 멈춰 세웠을 때 저절로 닫히는 위치가 있다면 속도 구간이 잘못 맞춰진 것입니다. / 한 번 확인해 보시고 그 위치를 전화로 알려주시면 판단이 쉽습니다.
@ 장지동 현관문 하단 틈과 매트 확인

# 이런 모습이면 점검 출장을 불러 주세요
- 조절 나사를 돌려도 속도가 변하지 않음
- 몸체에서 기름이 번져 나옴
- 문을 열었을 때 팔이 구부러져 있음
- 문이 닫힐 때 문틀과 부딪히는 소리가 남
위 증상은 혼자 만지면 더 나빠지는 경우가 많습니다. / [도어클로저 경첩 점검](doorlock-repair.html) 같은 수리 안내를 먼저 보시고 전화 주셔도 됩니다.
출장 전화를 하실 때 문 위쪽을 사진으로 찍어 보내시면 부품 준비가 빨라집니다.

# 도어락과 같이 봐야 하는 경우
동탄역 쪽에서 퇴근해 밤에 들어오는 집은 문이 잠겼는지 확인할 겨를이 없어 더 신경 써야 합니다. / 자동 잠금 소리가 나는지 한 번 귀 기울여 보세요.
클로저가 느려서 문이 안 닫히면 도어락이 잠금 상태가 되지 못합니다. / 이 상태로 지내면 배터리도 빨리 닳습니다.
도어락이 계속 모터를 돌리려 하기 때문입니다. / 클로저 문제인지 도어락 문제인지 구분이 안 되면 두 가지를 함께 봐드립니다.
이용 흐름은 [이용안내](guide.html)에 적어 두었습니다.

# 문이 닫혀 갇히는 일에 대비하세요
클로저를 새로 달았거나 속도를 바꾼 직후에는 한동안 문이 평소보다 빨리 닫힐 수 있습니다. / 몸을 문틈에 둔 채 짐을 정리하는 습관은 피하세요.
클로저가 잘 작동하면 문이 항상 닫히기 때문에 열쇠 없이 나갔다가 못 들어오는 일이 생깁니다. / 쓰레기를 버리러 잠깐 나왔다가 잠기는 경우가 흔합니다.
그럴 때는 신분 확인 후 문을 열어 드립니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
[현관문 개문](door-open.html) 안내에 순서를 적어 두었습니다. / 문을 못 열면 비용은 받지 않습니다.

# 비용은 점검 전에 먼저 말씀드립니다
점검은 문 위쪽 클로저, 경첩, 도어락 순으로 차례로 봅니다. / 어느 쪽이 원인인지 확인한 뒤에 필요한 작업만 말씀드립니다.
문 상태를 보고 조절로 끝날지 부품이 필요한지 먼저 설명합니다. / 얼마인지 말씀드린 뒤 괜찮다고 하셔야 시작합니다.
부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다. / 말없이 붙는 비용은 없습니다.

# 장지동 말고 화성 어디든 갑니다
급하게 문이 안 닫혀 불안한 밤이라면 늦은 시간이라도 전화 주세요. / 임시로 문을 고정하는 방법부터 안내해 드립니다.
장지동 가까운 동탄 쪽 동네는 물론 병점, 봉담, 향남까지 다닙니다. / 다니는 곳은 [화성시 출장열쇠](hwaseong.html) 페이지에서 볼 수 있습니다.
다른 지역은 [출장 지역](area.html)에서 확인하시면 됩니다.
