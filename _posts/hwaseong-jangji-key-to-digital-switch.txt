# 열쇠 하나로 버티던 문을 바꿔 볼까 생각할 때
동탄 장지동은 동탄역을 오가는 생활권이라 도어락 이야기를 접할 기회가 많습니다. / 그래도 아직 열쇠로만 여는 문을 쓰는 집이 있고, 한 번쯤 번호키로 바꾸고 싶다는 생각을 하게 됩니다.
열쇠를 잃어버리거나 챙기지 못한 날이 반복되면 더욱 그렇습니다. / 그런데 막상 바꾸려고 하면 어떤 제품이 내 문에 맞는지 막막해집니다.
이 글은 장지동에서 열쇠 방식의 문을 번호키로 바꾸기 전에 알아 둘 점을 순서대로 정리했습니다. / 이미 열쇠 문제로 곤란하다면 [화성 출장열쇠](hwaseong.html)를 먼저 확인하셔도 좋습니다.
@ 장지동 열쇠 문 번호키 교체

# 바꾸면 무엇이 달라질까
가장 큰 차이는 열쇠를 들고 다니지 않아도 된다는 점입니다. / 잃어버릴 열쇠가 없으니 문 앞에서 잠기는 일이 크게 줄어듭니다.
- 번호나 카드로 열 수 있어 두 손이 바빠도 편함
- 열쇠 복사본이 돌아다닐 걱정이 줄어듦
- 가족별로 방식을 다르게 쓸 수 있음
대신 전기를 쓰는 제품이므로 배터리 관리가 새로운 일이 됩니다. / 그래서 비상용 열쇠 구멍이 있는 제품을 고르는 분이 많습니다.

# 내 문에 맞는지 먼저 재 보세요
도어락은 문에 걸맞은 규격이어야 설치됩니다. / 가장 먼저 문 두께를 재야 합니다.
문 옆면에서 앞뒤 면까지의 두께와 문틀 형태를 확인해 보세요. / 방화문처럼 두꺼운 문은 설치 가능한 제품이 제한됩니다.
기존 자물통 구멍의 위치와 크기도 중요합니다. / 같은 구멍을 활용하면 문에 새 구멍을 내지 않고 바꿀 수 있는 경우가 많습니다.
측정이 어려우면 문 옆면과 기존 손잡이 부분을 찍어서 보내 주세요. / 사진만으로도 대략의 가능성을 말씀드릴 수 있습니다.

# 보조키는 그대로 두는 경우도 있습니다
많은 집의 현관문에는 주 잠금과 별도로 보조키가 달려 있습니다. / 번호키로 바꿀 때 보조키까지 바꿀지, 기존 것을 그대로 쓸지 선택합니다.
보조키가 열쇠 방식으로 남아 있으면 열쇠를 아예 없애지는 못합니다. / 그래도 일상은 번호로 쓰고 보조키는 장기 외출 때만 쓰는 방식이 흔합니다.
설치 방식은 [도어락 설치](doorlock-install.html)에 정리해 두었으니 함께 읽어 보세요.

# 번호, 카드, 지문 중 어떤 방식이 어울릴까
쓰는 사람의 생활에 맞춰 고르는 것이 가장 좋습니다. / 주로 누가 쓰는지, 자주 드나드는지에 따라 달라집니다.
번호는 별도 물건이 필요 없어 간단하지만 번호를 잊거나 노출될 수 있습니다. / 카드는 빠르지만 잃어버릴 수 있어 여분을 따로 보관해야 합니다.
지문은 손에 짐이 있어도 편하나 손이 젖거나 거칠면 인식이 약해질 수 있습니다. / 처음 바꾸는 집은 번호와 카드를 함께 쓰는 제품을 고르는 경우가 많습니다.
@ 장지동 번호 카드 지문 도어락 선택

# 제품 고를 때 확인할 항목들
광고만 보고 고르기보다 실제로 필요한 기능을 정하세요. / 아래 항목을 하나씩 확인해 보면 선택이 쉬워집니다.
- 문 두께와 보조키 규격에 맞는지
- 배터리 방식과 교체 방법
- 비상 전원 단자나 비상 열쇠가 있는지
- 열림 소리 크기와 경고음 설정이 가능한지
- 이후 수리와 부품을 구하기 쉬운 제품인지
가격이 높다고 모두 좋은 것은 아니고, 싸다고 모두 나쁜 것도 아닙니다. / 쓰는 가족에게 맞는지가 먼저입니다.

# 설치 전에 정해 두면 좋은 것
교체 당일 현장에서 허둥대지 않으려면 미리 정리해 두세요. / 몇 가지만 정해도 작업이 빨라집니다.
처음 쓸 비밀번호는 생일이나 전화번호 같은 쉬운 조합을 피하세요. / 가족이 기억하기 쉬우면서 남이 짐작하기 어려운 번호가 좋습니다.
카드를 몇 장 쓸지, 누가 가질지도 정해 두면 좋습니다. / 아이가 쓴다면 잃어버렸을 때 쓸 방법도 같이 정해 두세요.

# 장지동 위치와 문 상태를 알려 주는 법
장지동은 단지 간격이 넓어서 동 번호가 헷갈리는 경우가 있습니다. / 건물 동, 호수와 함께 동탄역 방향을 덧붙여 말씀해 주세요.
- 현재 문의 열쇠 구멍과 보조키 위치 사진
- 문 두께와 문 재질(철문, 방화문 등)
- 번호키로 바꾸고 싶은 이유
- 원하는 방식(번호, 카드, 지문)
- 설치 희망 날짜와 시간대
정보가 많을수록 방문 전에 준비할 제품과 장비를 맞추기 쉽습니다.

# 작업 전에 하는 신분 확인
도어락을 교체하는 일도 문 안으로 들어가는 일과 이어집니다. / 사시는 분인지 확인하는 절차는 설치할 때도 같습니다.
신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나를 준비해 주세요. / 세입자라면 집주인에게 교체 여부를 먼저 알려 두는 것이 좋습니다.
확인이 되지 않으면 작업을 시작할 수 없습니다.

# 비용은 시작 전에 먼저 말씀드립니다
제품과 설치 상태에 따라 달라지므로 문을 보고 먼저 말씀드립니다. / 괜찮다고 하시면 진행하고, 아니면 그대로 돌아가셔도 됩니다.
열쇠가 없어 문을 열어야 하는 상황이라면 못 열 경우 비용은 받지 않습니다. / 부품이나 제품을 추가해야 하면 작업 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에서 확인하실 수 있습니다.

# 설치가 끝난 뒤에 확인할 것
설치 후에는 번호 등록, 카드 등록, 열림과 잠김 동작을 하나씩 점검합니다. / 비상 열쇠가 있다면 정상적으로 돌아가는지도 확인합니다.
기존 열쇠로 들어올 수 있는 길은 막아 두는지, 복사 열쇠는 어떻게 처리하는지도 상의합니다. / 열쇠 방식 구멍이 남아 있다면 사용 여부를 정하세요.
오래된 문이라면 문이 잘 닫히는지, 경첩이 처지지 않았는지도 함께 봅니다. / 이 부분은 [현관문 개문](door-open.html)에서 다루는 문 상태 점검과도 이어집니다.
@ 장지동 번호키 도어락 설치 완료

# 바꾼 뒤에 오래 쓰는 법
처음 몇 주는 사용법이 익숙하지 않아 실수가 잦습니다. / 가족 모두 한 번씩 번호와 카드를 눌러 보면서 익히는 것이 좋습니다.
- 배터리 교체 시기를 달력에 표시하기
- 경고음이 나면 그날 바로 교체하기
- 비상 열쇠나 카드는 집 밖의 다른 장소에 하나 보관
- 번호는 가끔 바꾸고 가족과 공유 방식을 정해 두기
이후 문제가 생기면 [도어락 수리](doorlock-repair.html)로 먼저 확인할 수 있고, 아주 낡았다면 [도어락 교체](doorlock-replace.html)를 살펴보세요.

# 장지동 밖의 화성 어디든
장지동 옆 오산동, 목동, 청계동, 영천동, 능동, 반송동, 산척동도 다닙니다. / 병점동, 진안동, 기배동, 새솔동, 봉담읍, 향남읍, 남양읍도 같은 방식으로 갑니다.
[화성시 출장열쇠](hwaseong.html)와 [출장 지역](area.html)에 정리해 두었습니다.
