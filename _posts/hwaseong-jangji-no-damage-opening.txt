# 문을 안 부수고 연다는 말, 정확히 무슨 뜻일까
동탄 장지동 쪽은 동탄역을 오가는 분들이 많아 늦은 귀가 뒤 문이 안 열리는 일도 드물지 않습니다. / 그럴 때 열쇠집에 연락하면 흔히 듣는 말이 비파손 개방입니다.
이름은 익숙한데 정확히 어떤 작업인지, 왜 중요한지는 잘 모르는 분이 많습니다. / 이 글은 장지동에서 문이 잠겼을 때 알아 두면 좋은 비파손 개방의 뜻을 풀어 설명한 글입니다.
급한 상황이라면 [화성 출장열쇠](hwaseong.html)에서 출동 안내부터 보셔도 좋습니다. / 아래는 시간이 있을 때 천천히 읽어 보세요.
@ 장지동 비파손 개방 현관문

# 비파손 개방의 기본 개념
비파손 개방은 문이나 도어락을 부수거나 자르지 않고 원래 모양 그대로 여는 방식을 말합니다. / 열고 난 뒤에도 같은 도어락을 계속 쓸 수 있는 상태로 두는 것이 목표입니다.
반대로 파손 개방은 도어락을 뜯거나 문틀에 흠집을 내서 열고 나중에 새로 갈아 끼우는 것을 전제로 합니다. / 두 방식은 결과도, 뒤에 드는 일도 크게 다릅니다.
어떤 방법이든 사시는 분인지 확인한 뒤에 시작하는 절차는 같습니다. / 열 수 있느냐 못 여느냐는 도어락 종류와 문 상태에 따라 달라집니다.

# 왜 부수지 않는 방법을 먼저 쓸까
문을 상하게 하면 열었어도 그다음 문제가 생기기 때문입니다. / 도어락이 파손되면 새로 달아야 하고 문틀 흠집은 보기에도 불편합니다.
- 도어락을 계속 쓸 수 있어 불필요한 교체를 줄일 수 있습니다
- 문과 문틀의 외관이 남아 있어 이후 보수가 필요 없습니다
- 방범상으로도 문이 열린 흔적이 남지 않습니다
- 이웃에게 소리나 소란을 덜 줍니다
그래서 처음부터 부술 수밖에 없다고 말하기보다 가능한 방법을 순서대로 시도합니다.

# 어떤 문이 비파손으로 열기 쉬울까
도어락 구조와 문 상태가 가장 큰 변수입니다. / 연식이 오래돼서 내부가 정형화된 제품은 방법이 많지만 최신 제품은 보호 장치가 강한 경우도 있습니다.
같은 모델이라도 설치 상태와 문 두께, 손잡이의 마모에 따라 난이도가 달라집니다. / 그래서 전화로는 가능성만 말씀드리고 확정은 현장에서 하는 편입니다.
문이 한 번 힘으로 밀리거나 잠금 부품이 휘어 있으면 난이도가 올라갑니다. / 이미 시도하신 일이 있다면 숨기지 말고 미리 알려 주세요.
예를 들어 번호를 몇 번 눌러 봤는지, 손잡이를 세게 돌렸는지만 알려 주셔도 방법을 고르는 데 큰 도움이 됩니다. / 말씀해 주신 내용은 문제를 탓하려는 것이 아니라 작업을 안전하게 하려는 용도입니다.
빈 집이 아니라 집 안에 사람이 있다면 그 점도 함께 알려 주세요. / 안쪽에서 도와줄 수 있는 상황이면 열리는 방법이 하나 더 늘어납니다.

# 도착해서 하는 일의 순서
처음부터 도구를 꺼내지 않고 상황을 보는 단계가 앞섭니다. / 현장에서는 대체로 아래 순서로 진행합니다.
- 사시는 분인지 신분 확인
- 도어락 종류와 잠긴 상태 확인
- 문 상태와 틈, 걸쇠 위치 살피기
- 가능한 방법을 고르고 비용 먼저 말씀드리기
- 동의하시면 작업 시작
전 과정에서 문에 닿는 도구도 흔적이 남지 않는 것부터 사용합니다. / 중간에 방법을 바꿔야 하면 그때도 먼저 설명드립니다.
@ 동탄 장지동 도어락 비파손 작업 순서

# 하지 말아야 할 행동
스스로 문을 열어 보려다 오히려 비파손이 불가능해지는 경우가 있습니다. / 아래 행동은 가능하면 피해 주세요.
카드나 철사를 문틈에 넣어 걸쇠를 밀면 틈새가 벌어지거나 방화문 고무가 상합니다. / 드라이버로 도어락 외관을 뜯으면 되돌릴 수 없는 흠이 생깁니다.
문을 어깨로 밀거나 발로 차면 문틀이 휘어 비파손 방법이 통하지 않게 됩니다. / 이런 경우에는 파손 개방 말고는 선택지가 줄어들 수 있습니다.
비밀번호를 여러 번 틀려 잠금 상태가 된 경우도 억지로 계속 누르지 말고 멈추세요.

# 비파손이 어려운 경우도 있습니다
모든 문을 부수지 않고 열 수 있다고 약속하지는 않습니다. / 안쪽 부품이 이미 부서졌거나 문틀이 크게 변형된 경우는 한계가 있습니다.
이럴 때는 도어락을 어떻게 처리할지 현장에서 말씀드리고 사시는 분이 직접 고르시게 합니다. / 설명 없이 부수는 일은 없습니다.
파손이 불가피하다고 판단되면 먼저 이유와 이후에 필요한 작업을 설명해 드립니다. / 이 경우에도 비용은 열기 전에 먼저 말씀드립니다.

# 비용은 시작 전에 정하고 못 열면 받지 않습니다
작업 방식과 도어락 종류를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니라면 그대로 돌아가셔도 됩니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말없이 더해지는 항목도 없습니다.
부품 교체가 필요할 때는 작업 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에서 자세히 보실 수 있습니다.

# 신분 확인이 먼저인 이유
비파손으로 흔적 없이 열 수 있다는 것은 반대로 아무 문이나 열 수 있다는 뜻이기도 합니다. / 그래서 사시는 분인지 확인하는 절차가 더 중요합니다.
신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나를 준비해 주세요. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다.
확인이 되지 않으면 문을 열 수 없습니다. / 이웃과 거주자 모두를 위한 기준입니다.
@ 장지동 신분 확인 후 도어락 개방

# 장지동에서 요청할 때 알려 주실 것
문 앞에서 전화하실 때 아래 내용을 알려 주시면 출동이 빨라집니다. / 장지동은 동탄역 방향과 단지가 나뉘어 있어서 위치를 구체적으로 말씀해 주시는 편이 좋습니다.
- 건물 동과 호수, 가까운 역이나 큰길 방향
- 도어락 모양과 번호판 상태
- 이미 시도한 방법이 있는지
- 집 안에 아이나 반려동물이 있는지
- 문 틈이나 열쇠 구멍 상태
도어락 사진을 보내 주시면 방법을 미리 좁힐 수 있습니다.

# 열고 나서 해 두는 점검
문이 열리면 도어락 동작을 여러 번 확인합니다. / 배터리가 원인이었다면 새것으로 교체하는 것까지 함께 챙깁니다.
비밀번호를 잊어서 연 경우에는 새 번호를 등록하고 이전 번호를 지웁니다. / 필요하면 [도어락 수리](doorlock-repair.html)로 고장 부분을 잡아 두고, 너무 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
방법에 대한 보다 자세한 설명은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 장지동 밖의 화성 어디든
동탄 장지동 옆 오산동, 목동, 청계동, 영천동, 능동, 반송동, 산척동도 다닙니다. / 병점동, 진안동, 기배동, 새솔동, 봉담읍, 향남읍, 남양읍도 같은 방식으로 출동합니다.
지역 목록은 [화성시 출장열쇠](hwaseong.html)에, 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.
