# 장지동에서 일 년에 한 번 현관 점검을 하는 이유
장지동은 동탄역 생활권으로 출퇴근과 등하교로 현관문을 하루에도 여러 번 여닫는 집이 많은 동네입니다. / 그만큼 도어락과 문은 조용히 닳고 있어서, 고장 나기 전에 한 번씩 살펴보면 문 앞에서 당황하는 일이 줄어듭니다.
점검이라고 해서 거창한 도구가 필요하지는 않습니다. / 해가 바뀔 즈음이나 이사 철, 계절이 바뀌는 때 하루 잡아 15분 정도면 충분합니다.
이 글은 연 1회 직접 해볼 수 있는 점검표와, 이상한 신호를 봤을 때 언제 [화성 출장열쇠](hwaseong.html)에 연락하면 좋은지를 적었습니다.
@ 장지동 연 1회 도어락 점검표 체크

# 점검은 날을 정해서 하면 잊지 않습니다
점검은 하려고 마음먹으면 미루게 됩니다. / 연말이나 생일, 이사한 날처럼 해마다 돌아오는 날을 하나 정해 두세요.
달력이나 휴대폰 알림에 현관 점검이라고 적어 두면 잊지 않습니다. / 가족이 함께 있는 주말 오전이 좋습니다.
점검을 한 해 하고 나면 다음 해부터는 훨씬 빨리 끝납니다. / 순서가 몸에 익기 때문입니다.

# 1단계, 배터리와 경고음 이력
가장 먼저 배터리를 봅니다. / 도어락이 한 번이라도 낮은 배터리 경고음을 냈다면 그 시점이 교체 신호입니다.
점검일에는 경고음이 없었더라도 한꺼번에 전부 새것으로 바꾸는 편이 낫습니다. / 일부만 바꾸면 며칠 안에 또 신호가 올 수 있습니다.
배터리 칸에 교체한 날짜를 적어 두세요. / 다음 해 점검 때 얼마나 버텼는지 알 수 있습니다.

# 2단계, 번호판과 버튼 반응
번호판을 눌러 보면서 눌림이 둔하거나 반응이 늦는 버튼이 없는지 확인합니다. / 특정 숫자만 잘 안 눌린다면 그 부분이 닳았다는 신호입니다.
번호판 표면을 마른 수건으로 닦아 주면 손기름이나 먼지로 인한 오작동을 줄일 수 있습니다. / 물이나 세정제를 직접 뿌리지는 마세요.
번호판 불이 일부만 켜지거나 깜빡이면 속 부품 문제일 수 있습니다. / 이 경우는 점검 목록에 표시해 두고 아래 단계에서 판단합니다.
@ 장지동 도어락 번호판 버튼 반응 점검

# 3단계, 잠금 소리와 걸쇠 움직임
문을 연 상태에서 도어락의 잠금 장치를 눌러 걸쇠가 매끄럽게 나왔다 들어가는지 봅니다. / 잠길 때 소리가 평소와 다르게 길어지거나 둔탁해졌다면 모터나 걸쇠가 힘들어하고 있을 수 있습니다.
걸쇠가 문틀에 있는 받침판 구멍에 정확히 들어가는지도 확인합니다. / 걸쇠가 한쪽으로 쏠려 긁히는 흔적이 있다면 문이 처졌다는 뜻입니다.
이런 흔적을 찾으면 억지로 힘줘 닫지 말고 메모해 두세요. / 문이 덜 닫히는 문제는 경첩 점검이 먼저입니다.

# 4단계, 경첩과 문틀 상태
도어락이 멀쩡해도 문 자체가 처지면 문이 잘 안 열리거나 안 닫힙니다. / 경첩 나사가 헐거워지지 않았는지 드라이버로 가볍게 조여 보세요.
문을 반쯤 열어 두었을 때 스스로 움직이면 문이 기울었다는 신호입니다. / 문 가장자리와 문틀 사이의 틈이 위아래 폭이 다른지도 눈으로 확인합니다.
나사를 조이다 헛돌면 억지로 힘주지 말고 표시만 해 두세요. / 구멍이 넓어진 상태라 별도 보강이 필요합니다.

# 5단계, 도어클로저와 문 닫히는 속도
도어클로저가 달린 문이라면 닫히는 속도를 확인합니다. / 너무 빠르게 쾅 닫히거나 끝에서 덜 걸리면 조절이 필요합니다.
기름이 새어 나온 흔적이 있다면 클로저 자체가 수명이 다한 것입니다. / 이 부분은 손대기 전에 사진을 찍어 두세요.
문이 완전히 닫히는지 확인하려면 손잡이를 잡지 않은 채 가볍게 밀어 닫아 봅니다. / 걸리는 소리가 나야 정상입니다.

# 6단계, 보조키와 열쇠
많은 집에서는 도어락 말고 보조키와 열쇠를 같이 씁니다. / 열쇠를 꽂았을 때 뻑뻑하거나 걸리는 느낌이 있다면 속에 먼지가 쌓였을 수 있습니다.
열쇠가 부드럽지 않은 상태에서 억지로 돌리면 부러질 위험이 있습니다. / 이상하면 돌리지 말고 점검표에 적어 두세요.
- 예비 열쇠가 어디 있는지
- 열쇠가 꽂힐 때 걸리는 느낌이 있는지
- 보조키가 가볍게 돌아가는지
예비 열쇠는 현관 근처 밖이 아닌 믿을 만한 가까운 사람에게 맡기는 쪽이 낫습니다.

# 7단계, 번호와 등록 정보 정리
일 년 동안 번호를 알려 준 사람이 있다면 정리할 때입니다. / 손님이나 공사하신 분, 도우미에게 알려 준 번호가 남아 있지 않은지 확인하세요.
가족 번호는 일 년에 한 번쯤 바꿔 주면 좋습니다. / 바꿀 때는 가족 모두가 새 번호를 외웠는지 확인한 뒤에 마무리하세요.
카드키나 태그를 쓴다면 몇 개가 어디 있는지도 점검합니다. / 잃어버린 것이 있다면 등록에서 지워 두는 것이 안전합니다.

# 점검표에 쓰는 한 줄 요약
항목마다 정상, 주의, 연락 필요 세 가지로 간단히 표시해 보세요. / 한눈에 보이면 올해 무엇을 해야 하는지 바로 알 수 있습니다.
- 배터리: 교체 날짜
- 번호판: 반응 이상 여부
- 걸쇠: 소리와 움직임
- 경첩: 나사와 기울기
- 열쇠: 걸림 여부
- 번호: 정리한 날짜
이 여섯 줄이면 한 해 점검이 끝납니다.

# 주의 표시가 나왔을 때 판단하는 기준
주의 표시가 한두 개라면 다음 점검 전에 미리 손보면 됩니다. / 급하게 서두를 일은 아닙니다.
다만 번호판이 간헐적으로 꺼지거나, 모터 소리만 나고 열림이 안 되는 증상은 미루지 마세요. / 어느 날 갑자기 문 앞에서 막히는 일로 이어질 수 있습니다.
고쳐서 쓸 수 있다면 [도어락 수리](doorlock-repair.html)로 먼저 해결합니다. / 너무 오래돼 부품이 맞지 않으면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 장지동 도어락 점검 주의 표시 수리 상담

# 점검하다 문이 안 열리게 된 경우
점검 중에 도어락 설정을 만지다가 번호가 안 먹히는 일이 가끔 생깁니다. / 설명서를 보며 천천히 하면 대부분 돌릴 수 있습니다.
그래도 열리지 않으면 힘으로 해결하려 하지 말고 [현관문 개문](door-open.html)을 요청해 주세요. / 요청 방법은 [출장 요청 안내](key-call.html)에 적어 두었습니다.
문을 열기 전에 사시는 분이 맞는지 신분 확인을 먼저 합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 되고, 비용은 문 열기 전에 먼저 말씀드립니다. 못 열면 비용은 받지 않습니다.
자세한 진행 방식은 [이용안내](guide.html)에 있습니다.

# 장지동 말고 화성 어디든 갑니다
장지동 바로 옆 산척동, 목동, 오산동, 영천동도 다닙니다. / 화성 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [화성시 출장열쇠](hwaseong.html) 페이지에 정리해 두었고, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
