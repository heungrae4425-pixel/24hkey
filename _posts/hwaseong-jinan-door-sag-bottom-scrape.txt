# 진안동 현관문, 열 때마다 바닥이 쓸린다면
진안동은 병점역 생활권으로 오가는 분들이 많은 동네입니다. / 문을 열 때마다 문 아래가 바닥에 닿아 드르륵 소리가 나는 집도 생각보다 적지 않습니다.
처음에는 소리만 나지만 그대로 두면 바닥에 자국이 생기고 문이 점점 더 뻑뻑해집니다. / 어느 날은 아예 문이 안 열리는 일로 이어지기도 합니다.
이 글은 문 아래가 바닥에 쓸릴 때 원인과 직접 확인해 볼 순서를 정리한 것입니다.
@ 진안동 현관문 아래 바닥 쓸림 자국

# 문 아래가 쓸리는 증상, 어떤 모습일까
문 아래가 쓸리는 증상은 몇 가지 모습으로 나타납니다. / 어느 쪽인지 보면 원인을 좁히기 쉽습니다.
- 문을 열 때만 바닥에서 드르륵 소리가 나는 경우
- 문을 끝까지 열기 전에 중간에 걸리는 경우
- 문을 닫을 때 걸쇠가 문틀에 비스듬히 맞는 경우
- 바닥에 반원 모양 긁힌 자국이 선명한 경우
반원 자국이 있다면 문이 처진 채 호를 그리며 바닥을 쓸었다는 뜻입니다.

# 가장 흔한 원인은 경첩 쪽 처짐입니다
현관문은 무게가 상당해서 오래 쓰면 경첩이 느슨해지고 문이 한쪽으로 조금씩 처집니다. / 경첩 나사가 풀리거나 경첩 자체가 닳으면 문의 손잡이 쪽 아랫부분이 내려앉습니다.
이렇게 되면 문 아랫부분이 바닥이나 문턱에 닿습니다. / 위쪽 경첩을 단단히 잡고 있는 나사가 헐거워지는 경우가 가장 많습니다.
방치하면 문틀 쪽 걸쇠 위치까지 어긋나 문이 잠기지 않는 단계까지 갑니다.

# 다른 원인도 있습니다
경첩 말고도 바닥 쓸림의 원인은 있습니다. / 원인에 따라 해결 방법이 완전히 다르니 구분이 필요합니다.
- 바닥에 새로 깐 장판이나 매트가 두꺼워진 경우
- 문턱이 올라오거나 바닥이 부풀어 오른 경우
- 습기로 문짝이 부풀어 아래가 퍼진 경우
- 도어클로저가 문을 세게 당겨 경첩에 무리가 간 경우
- 문 아래 고무 패킹이 헐거워 끌리는 경우
문 아래 고무 패킹이나 문턱 보호 패드가 닳아 끌리는 경우도 흔합니다. / 이런 경우는 부품만 바꿔도 소리가 사라집니다.
특히 장마철이 지난 뒤 갑자기 쓸린다면 습기가 원인일 수 있습니다. / 건조해지면 저절로 나아지기도 합니다.

# 1분 안에 해볼 수 있는 확인
공구 없이도 할 수 있는 확인이 몇 가지 있습니다.
- 문을 반쯤 열고 손잡이 쪽 끝을 살짝 들어 올려 흔들림이 있는지
- 경첩 나사가 튀어나오거나 돌아가는지
- 문과 문틀 사이 틈이 위아래로 일정한지
- 바닥에 닿는 부분이 문 아래 전체인지 손잡이 쪽만인지
손잡이 쪽만 닿는다면 경첩 처짐일 가능성이 큽니다. / 문 전체가 닿는다면 바닥이나 습기를 의심해 보세요.

# 하지 말아야 할 것
문이 쓸린다고 문 아래를 칼이나 대패로 깎아내는 분들이 있습니다. / 원인이 처짐이라면 깎은 부분만큼 틈이 커져 바람이 들어오고 되돌릴 수도 없습니다.
경첩 나사를 무작정 최대한 세게 조이면 나사 구멍이 뭉개져 더 헐거워집니다. / 나사가 헛돈다면 억지로 돌리지 마세요.
문을 발로 차거나 어깨로 밀어 열면 걸쇠가 부러지거나 문틀이 휘어 일이 커집니다.
@ 진안동 현관문 경첩 나사와 문 처짐 확인

# 쓸림을 방치하면 생기는 일
처음에는 소리뿐이지만 시간이 지나면 문이 점점 무거워집니다. / 어느 날 아침 문이 바닥에 걸려 안 열리는 상황을 맞을 수도 있습니다.
도어락이 문틀과 어긋나 번호는 맞는데 모터 소리만 나는 일도 생깁니다. / 문 안쪽에 있다가 나가려는데 문이 안 열리는 것도 같은 원인일 수 있습니다.
바닥 자국은 이사 나갈 때 원상복구 문제로 이어질 수 있으니 일찍 손보는 쪽이 낫습니다.

# 전화하실 때 알려주실 내용
증상을 구체적으로 알려주시면 필요한 부품을 챙겨 갈 수 있습니다. / 사진이 있으면 더 좋습니다.
- 진안동 어느 건물 몇 층인지, 병점역에서 어느 방향인지
- 문을 열 때와 닫을 때 중 언제 쓸리는지
- 쓸리는 위치가 문 아래 전체인지 손잡이 쪽인지
- 문이 안 열려 갇혀 있는지, 열리는데 소리만 나는지
- 장판이나 문턱을 최근에 바꿨는지

# 도착하면 먼저 사시는 분인지 확인합니다
문 점검 작업이라도 집에 들어가는 일이라 신원을 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 가능한 것이면 됩니다.
세입자라면 집주인께 미리 알려 두는 것이 좋습니다. / 경첩 교체 같은 작업은 집 구조와 관련될 수 있기 때문입니다.

# 비용은 작업 전에 먼저 말씀드립니다
문을 보고 원인을 말씀드린 뒤 어떤 작업이 필요한지 설명드립니다. / 비용은 작업 전에 먼저 안내하고 동의하시면 시작합니다.
문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. 진행 방식은 [이용안내](guide.html)에 있습니다.

# 점검과 조정은 이렇게 진행합니다
먼저 문을 살펴 어느 경첩이 얼마나 처졌는지 확인합니다. / 나사가 풀렸다면 조이는 것으로 끝나기도 합니다.
나사 구멍이 닳았다면 구멍을 보강하거나 경첩을 바꿉니다. / 문이 많이 처졌다면 걸쇠 받이의 위치도 같이 맞춥니다.
문 아래 쓸림은 문 한 장만의 문제가 아니라 문틀, 경첩, 도어락이 함께 어긋난 결과인 경우가 많습니다. / 그래서 한 곳만 고치고 끝내지 않고 세 곳의 맞물림을 같이 봅니다.
문이 안 열려 갇힌 상황이라면 먼저 문을 상하지 않게 여는 일이 우선입니다. / 개문 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.


작업이 끝나면 문을 여러 번 열고 닫으며 확인합니다.
- 문을 열 때 바닥에 닿지 않는지
- 문과 문틀 틈이 위아래로 고른지
- 도어락 걸쇠가 문틀 구멍에 정확히 들어가는지
- 도어클로저가 있다면 닫히는 속도가 알맞은지
도어락이 같이 틀어졌다면 [도어락 수리](doorlock-repair.html)로 손보고, 낡았다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 쓸림을 예방하는 습관
- 1년에 한 번쯤 경첩 나사 조임 확인
- 문에 무거운 물건을 걸어 두지 않기
- 문을 세게 닫거나 활짝 열어 벽에 부딪히지 않기
- 장마철 뒤에 문이 뻑뻑해졌는지 확인
- 바닥 재료를 바꿀 때 문 높이도 같이 확인
조금 이상하다 싶을 때 손보는 것이 가장 쉽습니다. / 쓸린 자국이 얕을 때 손보면 바닥도 문도 거의 상하지 않습니다. / 이미 자국이 깊다면 문을 조정한 뒤에도 바닥 보수는 따로 필요할 수 있으니 미리 알아 두세요.
@ 진안동 점검 후 문과 바닥 사이 틈 확인

# 진안동 말고 화성 어디든 갑니다
진안동 가까운 병점동, 기배동, 반송동, 능동은 물론 오산동, 장지동, 봉담읍, 향남읍, 남양읍까지 다닙니다. / 화성 안이면 24시간 연락 받습니다.
[화성시 출장열쇠](hwaseong.html)와 [출장 지역](area.html)에서 다니는 동네를 볼 수 있습니다.
