# 진안동 도어락 설치, 시간이 얼마나 걸리는지부터
진안동은 병점역과 동탄역 사이를 오가며 생활하는 분들이 많은 동네입니다. / 이사 철이나 새 도어락을 사 둔 뒤에 설치를 맡기려는 분들이 시간을 가장 많이 물어보십니다.
설치는 문 하나에 보통 한 번 방문으로 끝나지만, 문 상태에 따라 걸리는 시간이 달라집니다. / 이 글은 어떤 단계에서 시간이 걸리는지와 미리 준비해 두면 빨라지는 것을 적었습니다.
새로 달 계획이라면 [화성 출장열쇠](hwaseong.html)에 전화하기 전에 아래 순서를 한번 읽어 보세요.
@ 진안동 도어락 설치 작업 전 문 상태 확인

# 설치 시간은 이렇게 나뉩니다
도어락 설치는 크게 네 단계로 나뉩니다. / 각 단계에서 걸리는 시간이 문마다 다릅니다.
- 현장 확인: 문 두께, 기존 장치 종류, 보조키 위치 보기
- 기존 장치 철거: 오래된 도어락이나 열쇠 손잡이 떼어내기
- 새 장치 설치: 몸체와 손잡이 위치를 맞춰 고정하기
- 등록과 점검: 번호나 카드 등록, 여러 번 열고 닫아 확인하기
미리 준비가 되어 있으면 철거와 점검이 간단해지지만, 문 구멍이 맞지 않으면 손이 더 갑니다.

# 기존 도어락이 있는 문과 없는 문의 차이
이미 도어락이 달린 문을 바꾸는 경우에는 구멍 위치가 맞는 제품이면 빠르게 끝납니다. / 같은 규격으로 만든 제품끼리라면 새 몸체를 걸어 고정하기만 하면 됩니다.
열쇠로 여는 문에 처음 도어락을 다는 경우는 사정이 다릅니다. / 문에 구멍을 새로 맞춰야 하거나 기존 잠금장치를 정리해야 해서 시간이 더 필요합니다.
어느 쪽인지 모르겠다면 문 안쪽과 바깥쪽 사진을 찍어 보내주시면 됩니다. / 사진만 봐도 예상 시간을 대략 말씀드릴 수 있습니다.

# 문 두께와 보조키가 시간을 가릅니다
도어락마다 맞는 문 두께가 정해져 있습니다. / 두께가 맞지 않으면 연장 부품이 필요할 수 있어, 미리 확인해 두지 않으면 작업이 중간에 멈춥니다.
보조키가 문 위쪽에 따로 있으면 도어락과 함께 쓸 수 있는지 봐야 합니다. / 이 부분은 [도어락 설치](doorlock-install.html) 페이지에 설치 흐름과 함께 적어 두었습니다.
줄자로 문 옆면 두께를 재서 알려주시면 전화 상담이 빨라집니다. / 정확히 모르면 사진으로 보내주셔도 됩니다.

# 방문 전에 준비해 두면 좋은 것
설치 날에 미리 해 두시면 작업이 한결 수월해집니다. / 큰 준비는 없고 간단한 것들입니다.
- 새 도어락 상자와 구성품(몸체, 손잡이, 설명서, 열쇠)
- 건전지가 들어 있는지, 없다면 새 건전지 준비
- 문 앞 신발장이나 짐을 한쪽으로 치워 작업 공간 확보
- 가족이 등록할 비밀번호, 카드 개수 미리 정하기
구성품이 빠졌는지 상자를 먼저 열어 보시면 좋습니다. / 부품이 모자라면 중간에 작업을 멈춰야 합니다.

# 제품을 직접 구입했을 때 확인할 것
온라인으로 도어락을 사 두신 분도 많습니다. / 구입한 제품이 내 문에 맞는지는 문 두께와 기존 구멍 규격에 달려 있습니다.
설치 전에 제품 모델명을 알려주시면 호환 여부를 먼저 봐 드립니다. / 맞지 않는 제품을 설치하다 보면 문에 불필요한 흔적이 남을 수 있어 사전 확인이 중요합니다.
제품이 아직 없다면 문에 맞는 종류부터 같이 보고 고르셔도 됩니다.
@ 진안동 새 도어락 구성품 확인 모습

# 시간이 더 걸리는 경우
아래 같은 상황에서는 예상보다 시간이 늘어납니다. / 미리 알아 두시면 일정을 여유 있게 잡으실 수 있습니다.
오래된 문은 구멍 주변이 닳거나 문틀이 처져서 몸체가 딱 맞게 걸리지 않을 수 있습니다. / 이럴 때는 위치를 조금씩 조정하며 맞추느라 시간이 필요합니다.
기존 장치가 녹슬거나 오래 눌러붙어 있으면 빼는 데 시간이 걸립니다. / 무리하게 빼면 문이 상하므로 천천히 작업합니다.
문이 철문이나 방화문이면 재질 때문에 작업이 더 까다로울 수 있습니다.

# 설치 중에 하지 말아야 할 것
작업하는 동안 문을 열고 닫거나 기대지 말아 주세요. / 위치를 맞추는 중에 문이 움직이면 다시 맞춰야 합니다.
등록이 끝나기 전에 번호를 마음대로 눌러 보는 것도 피해 주세요. / 임시로 눌린 번호가 남아 오작동하는 경우가 있습니다.
아이나 반려동물이 문 앞에서 서성이면 작업 공구에 다칠 수 있으니 다른 방에서 보호해 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
문 장치를 바꾸는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로워도 세입자와 집 주인 모두를 지키기 위한 절차입니다. / 신분증이 없다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

# 비용은 설치 전에 먼저 말씀드립니다
문 상태와 제품 종류를 보고 비용을 먼저 말씀드린 다음 시작합니다. / 괜찮다고 하시면 작업하고, 마음에 안 들면 그대로 돌아갑니다.
부품을 바꿔야 하는 상황이 생기면 바꾸기 전에 따로 여쭤봅니다. / 열고 난 뒤 말없이 붙는 비용은 없습니다.
기존 장치를 새 것으로 바꾸는 흐름은 [도어락 교체](doorlock-replace.html) 페이지에 정리해 두었습니다.

# 설치가 끝나면 이렇게 점검합니다
몸체를 고정한 뒤에는 번호나 카드를 등록하고 여러 번 열고 닫아 봅니다. / 걸쇠가 문틀에 정확히 들어가는지, 문이 덜 닫히지 않는지 확인합니다.
가족이 쓸 번호를 함께 입력하고 쓰는 방법을 알려드립니다. / 처음 쓰시는 분은 안쪽 버튼 위치, 소리 설정, 경고음의 의미를 같이 익혀 두세요.
설치 후에는 사용법을 아시는 분이 집에 계시는 것이 좋습니다. / 가능하면 가족 한 분이 같이 옆에서 보시면 이후 관리가 편합니다.
@ 진안동 도어락 설치 후 번호 등록과 점검

# 설치 당일 일정은 이렇게 잡으세요
문이 며칠씩 걸리는 작업은 아니지만 하루 중 시간을 넉넉히 비워 두시면 좋습니다. / 작업 중에는 문이 열린 채로 있어서 집을 비우기 어렵습니다.
출근 전이나 퇴근 직후에 맡기시는 분도 많은데, 시간이 빡빡하면 마음이 급해집니다. / 여유가 있는 날을 잡거나 전화로 시간대를 미리 상담해 주세요.
이사 날에 맞춰 설치하는 경우라면 짐이 들어오기 전에 끝내는 것이 가장 수월합니다.

# 설치 후 한 달 안에 한 번 더 확인
새 제품은 처음에는 괜찮다가 며칠 뒤 문이 살짝 처지면서 어긋나기도 합니다. / 이상이 느껴지면 [도어락 수리](doorlock-repair.html)로 연락 주셔도 됩니다.
- 번호 입력 반응이 한 번에 되는지
- 걸쇠가 끝까지 들어가는지
- 경고음이나 건전지 표시가 생기지 않는지
- 안쪽 손잡이를 돌릴 때 걸림이 없는지
이상이 있으면 그냥 두지 마시고 사진과 함께 알려주세요.
