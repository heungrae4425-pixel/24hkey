# 열쇠가 없는 걸 문 앞에서 알았을 때
진안동은 병점역과 가까운 생활권이라 퇴근길에 집 앞에서 열쇠가 없다는 걸 깨닫는 분들이 계십니다. / 주머니와 가방을 몇 번씩 뒤져 봐도 없으면 머릿속이 하얘집니다.
열쇠를 집 안에 두고 문을 닫은 경우와 어딘가에서 잃어버린 경우는 대처가 조금 다릅니다. / 이 글은 진안동에서 열쇠를 분실했을 때 순서대로 무엇을 하면 좋은지 정리했습니다.
문 열기 자체는 [화성 출장열쇠](hwaseong.html)에서 안내하며, 아래는 그 전후로 챙기면 좋은 내용입니다. / 침착하게 하나씩 따라오시면 됩니다.
열쇠를 찾는 데 오래 쓰기보다 일정 시간을 정해 두고 안 되면 연락하는 편이 좋습니다. / 예를 들어 가방과 주머니를 두 번 확인했는데도 없다면 더 찾지 말고 다음 단계로 넘어가세요.
날씨가 춥거나 비가 오는 날, 아이를 데리고 있는 날은 특히 빨리 판단하는 것이 낫습니다. / 문 앞에서 오래 기다리지 않도록 가까운 안전한 곳을 정해 두세요.
휴대폰 배터리가 얼마 남지 않았다면 먼저 연락부터 하시고 그다음에 열쇠를 찾아도 늦지 않습니다. / 통화가 끊기지 않게 위치를 먼저 알려 주세요.
@ 진안동 열쇠 분실 현관 앞

# 먼저 숨을 고르고 마지막 기억을 되짚기
열쇠가 어디 있는지 알면 반은 해결된 셈입니다. / 마지막으로 열쇠를 본 곳이 어디였는지 차근차근 떠올려 보세요.
- 오늘 아침 문을 잠그고 나올 때 손에 있었는지
- 가방이나 외투 안주머니를 샅샅이 뒤졌는지
- 차 안, 직장 사물함, 마지막으로 들른 가게에 둔 것은 아닌지
- 가족이 가져갔거나 집 안에 있을 가능성은 없는지
가족 중 집에 있는 사람이 있으면 문을 열어 달라고 부탁하는 것이 가장 간단합니다. / 연락이 닿지 않으면 다음 단계로 넘어가세요.

# 집 안에 두고 나온 경우
이 경우는 문을 열면 열쇠가 바로 나옵니다. / 열쇠가 집 안에 있다는 것이 확실하면 걱정이 훨씬 줄어듭니다.
다만 보조키를 잠갔는지, 문이 단순히 닫힌 상태인지에 따라 작업이 달라집니다. / 단순히 닫힌 문은 비교적 쉽게 열 수 있지만 보조키까지 걸렸다면 조금 더 걸립니다.
문틈에 카드를 넣거나 문을 흔드는 시도는 하지 마세요. / 방화문은 틈새에 고무가 있어 쉽게 상합니다.
@ 진안동 집 안에 열쇠 두고 나온 문

# 밖에서 잃어버렸다면 의심해 볼 곳
정말 잃어버렸다면 열쇠가 어디 있든 누군가 주울 수 있습니다. / 그래서 문을 열고 난 뒤에 어떻게 할지를 미리 생각해 두면 좋습니다.
열쇠고리에 집 주소나 호수를 적어 두었다면 더 신경이 쓰입니다. / 그런 경우는 문을 열고 난 뒤 잠금 장치를 새로 바꾸는 쪽을 권해 드립니다.
주소를 적어 두지 않았다면 열쇠가 쓰일 가능성은 낮지만 안전을 위해 점검은 해 두는 편이 좋습니다. / 선택은 사시는 분이 하시도록 상황을 설명해 드립니다.

# 진안동에서 연락할 때 말씀해 주실 것
진안동은 병점역을 기준으로 방향을 설명하면 이해가 쉽습니다. / 건물 동과 호수, 역에서 어느 쪽인지 알려 주세요.
- 열쇠를 두고 나온 건지 잃어버린 건지
- 도어락이 열쇠 방식인지 번호키인지
- 보조키를 잠갔는지 알 수 없는지
- 집 안에 사람이나 반려동물이 있는지
- 지금 문 앞에서 얼마나 기다릴 수 있는지
도어락 사진을 보내 주시면 방문 전에 필요한 준비를 할 수 있습니다. / 사진이 어려우면 말로 모양을 알려 주셔도 됩니다.

# 도착하면 신분 확인이 먼저
열쇠가 없는 상황에서도 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
지갑은 있고 열쇠만 없는 경우가 많아서 이 절차는 대부분 순조롭습니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다.
확인이 안 되면 열 수 없다는 점은 모든 분께 똑같이 적용됩니다.

# 비용은 열기 전에 먼저 말씀드립니다
문 종류와 잠금 상태를 보고 시작 전에 비용을 말씀드립니다. / 괜찮다고 하시면 진행하고 아니라면 그냥 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 설명 없이 더해지는 항목은 없습니다.
부품 교체가 필요한 경우 작업 전에 따로 여쭙습니다. / 전체 절차는 [이용안내](guide.html)에 적어 두었습니다.

# 문을 상하지 않게 여는 방식
열쇠를 잃었다고 문을 부수는 일은 없습니다. / 도어락과 문틀을 그대로 두고 여는 비파손 방식을 먼저 씁니다.
[현관문 개문](door-open.html)에 자세한 방식이 적혀 있습니다. / 방법은 문과 도어락 종류에 따라 달라집니다.
정말 불가피해서 파손이 필요한 경우는 이유를 먼저 설명드리고 동의를 구합니다. / 허락 없이 부수는 일은 없습니다.

# 문이 열린 직후에 하실 일
문이 열렸다고 바로 안심하기보다 열쇠 문제를 정리하고 가시는 것이 좋습니다. / 잃어버린 열쇠가 걸리면 같은 일이 반복될 수 있습니다.
- 집 안에서 다른 열쇠가 있는지 찾아 두기
- 여분 열쇠를 가족이나 믿을 만한 곳에 하나 맡겨 두기
- 잃어버린 열쇠가 쓰일 우려가 있으면 자물통 교체 상담
- 번호키 방식으로 바꿀지 검토
분실이 확실하다면 같은 열쇠가 맞는 자물통을 계속 쓰는 것은 권하지 않습니다. / 이럴 때는 [도어락 교체](doorlock-replace.html)를 살펴보세요.
@ 진안동 열쇠 분실 후 자물통 점검

# 잠금 장치를 새로 바꿀 때 보는 기준
열쇠를 잃은 경우 자물통 속만 바꾸는 방법과 도어락 전체를 바꾸는 방법이 있습니다. / 문이 낡았거나 열쇠를 자주 잃는 편이라면 번호키로 가는 분이 많습니다.
자물통 속만 바꾸면 기존 문과 손잡이를 그대로 쓸 수 있습니다. / 이때는 [도어락 수리](doorlock-repair.html)에서 어떤 점검을 하는지도 참고해 보세요.
번호키로 바꾼다면 문 두께와 보조키부터 확인합니다. / [도어락 설치](doorlock-install.html)에 순서를 적어 두었습니다.

# 열쇠를 다시 잃지 않는 작은 습관
같은 일이 반복되지 않으려면 열쇠가 머무는 자리를 정하세요.
- 집에 들어오자마자 같은 자리에 걸어 두기
- 문을 닫기 전 주머니를 한 번 두드려 확인하기
- 키링에 연락처 대신 용도만 알 수 있게 표시하기
- 여분 열쇠는 문 근처 눈에 띄는 곳이 아닌 믿을 수 있는 곳에 맡기기
습관 하나가 새벽 문 앞의 당황을 막아 줍니다.

# 진안동 밖의 화성 어디든
진안동 옆으로 병점동, 기배동, 새솔동, 봉담읍은 물론 동탄 반송동, 능동, 청계동, 영천동도 다닙니다. / 향남읍, 남양읍까지 화성 전 지역이 대상입니다.
[화성시 출장열쇠](hwaseong.html)와 [출장 지역](area.html)에서 확인해 주세요.
