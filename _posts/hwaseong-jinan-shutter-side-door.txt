# 셔터는 열리는데 쪽문이 말썽일 때
진안동에서 가게나 창고를 하시는 분들은 큰 셔터 옆에 작은 쪽문을 따로 쓰는 경우가 많습니다. / 드나들 때는 셔터를 올리지 않고 쪽문만 쓰기 때문에 하루에도 여러 번 열고 닫게 됩니다.
그러다 열쇠가 안 맞거나 돌아가지 않으면 장사를 시작하지 못하는 난감한 상황이 됩니다. / 병점역 쪽에서 출근하는 분이라면 시간이 더 촉박하게 느껴집니다.
이 글은 쪽문 열쇠 문제를 원인별로 정리하고 [화성 출장열쇠](hwaseong.html)를 부르는 요령을 적은 것입니다.
@ 진안동 셔터 옆 쪽문 열쇠 구멍

# 쪽문은 왜 더 자주 고장 날까
셔터 옆 쪽문은 얇은 철판으로 만든 경우가 많고, 문이 가벼워 세게 닫는 일이 잦습니다. / 그때마다 문틀과 잠금장치에 작은 충격이 쌓입니다.
바깥에 놓여 있어 비와 먼지, 여름 열기에도 계속 노출됩니다. / 열쇠 구멍 안에 이물질이 들어가거나 녹이 생기기 쉬운 환경입니다.
또 셔터가 내려오면서 쪽문 틀을 조금씩 밀어 위치가 틀어지는 일도 있습니다. / 이런 사정을 알면 원인을 짐작하기 쉽습니다.
가게 앞을 지나는 손님이나 배송 차량 때문에 문 주변이 자주 부딪히는 곳이라면 더 그렇습니다. / 작은 접촉이 쌓여 어느 날 갑자기 열쇠가 말을 안 듣게 됩니다.
그래서 쪽문은 안쪽 상태까지 같이 보아야 정확한 원인이 나옵니다.

# 상황 하나, 열쇠가 구멍에 안 들어갈 때
열쇠가 끝까지 들어가지 않으면 구멍 안에 먼지나 이물질이 있을 가능성이 큽니다. / 억지로 밀어 넣으면 열쇠가 휘거나 부러질 수 있습니다.
우선 열쇠 날을 눈으로 보세요. / 구부러졌거나 닳아 있다면 열쇠 자체가 문제일 수 있습니다.
복사한 열쇠라면 원본과 모양이 미세하게 다른 경우도 있습니다. / 몇 번 쓰다 보면 날이 닳아 점점 안 맞게 되기도 합니다. / 원본 열쇠가 있다면 번갈아 꽂아 비교해 보세요.

# 상황 둘, 들어가는데 안 돌아갈 때
열쇠는 들어가는데 돌아가지 않는다면 문이 위치가 틀어져 잠금 쪽이 눌려 있는지 의심합니다. / 문을 손바닥으로 바깥쪽에서 살짝 당기면서 열쇠를 돌려 보세요.
반대로 안쪽으로 밀면서 돌려야 열리는 경우도 있습니다. / 이렇게 해서 돌아간다면 열쇠 구멍보다 문 위치가 원인이라는 뜻입니다.
힘을 줘서 돌리다 열쇠가 부러지면 일이 두 배로 커집니다. / 두세 번 시도해서 안 되면 멈추는 게 좋습니다.
@ 쪽문 열쇠를 돌려 보는 손동작

# 상황 셋, 한쪽으로만 돌고 헛돌 때
열쇠가 한 바퀴 이상 헛돌면서 걸쇠가 안 움직인다면 내부 부품이 빠졌을 가능성이 있습니다. / 이럴 때는 계속 돌리지 마세요.
안쪽의 연결 부품이 닳거나 부러진 경우라 바깥에서 할 수 있는 일이 거의 없습니다. / 상황을 말씀해 주시면 장비를 챙겨 갑니다.
헛도는 소리가 나면서 열쇠를 뺄 때 뭔가 걸리는 느낌이 있다면 같이 알려주세요. / 내부 부품 상태를 짐작하는 데 큰 도움이 됩니다.
쪽문을 열려다 열쇠가 헛돌고 안쪽에서 걸쇠가 풀리지 않는 모습은 철문 쪽문에서 특히 자주 보는 현상입니다. / 당황하지 말고 그 자리에서 멈추는 것이 가장 좋은 대처입니다.

# 윤활제를 뿌려도 되는지
열쇠 구멍에 기름을 아무거나 뿌리면 먼지가 엉겨 더 뻑뻑해질 수 있습니다. / 급한 마음에 식용유나 일반 기름을 쓰는 것은 권하지 않습니다.
흑연 가루처럼 열쇠 구멍에 맞는 제품이 따로 있습니다. / 그래도 부러진 열쇠나 헛도는 문제는 윤활로 해결되지 않습니다.
문틀과 경첩에만 소량 바르는 것이 안전합니다. / 이물질이 의심되면 직접 빼려 하지 말고 불러 주세요.

# 셔터와 쪽문 열쇠를 같이 쓰는 경우
셔터 열쇠와 쪽문 열쇠가 따로 있는 가게도 있고, 한 열쇠로 같이 쓰는 가게도 있습니다. / 어느 쪽인지 평소에 알아 두면 문제가 생겼을 때 구분하기 쉽습니다.
셔터가 열려 있다면 그쪽으로 들어가 쪽문을 안쪽에서 확인할 수도 있습니다. / 안에서 보면 걸쇠와 잠금 상태가 눈에 들어옵니다.
셔터까지 잠겨 있고 쪽문만 열쇠로 드나들어야 한다면 쪽문 하나에 가게 전체 출입이 달려 있습니다. / 이런 경우 예비 열쇠를 따로 보관하는 게 중요합니다.

# 전화하기 전에 알려주시면 좋은 것
진안동에서 연락 주실 때 아래 내용을 알려주세요. / 준비 장비가 달라져서 도착해 헤매는 시간이 줄어듭니다.
- 가게나 창고의 대략적인 위치와 가까운 큰 길
- 쪽문 열쇠 구멍 사진과 문 전체 모습
- 열쇠가 안 들어가는지, 안 돌아가는지, 헛도는지
- 안쪽에서 걸어 잠그는 장치가 있는지
- 안에 귀중품이나 냉장 보관품이 있어 급한지
냉장고나 식자재가 안에 있다면 꼭 먼저 말씀해 주세요. / 시간 순서를 조절하는 데 큰 도움이 됩니다.

# 도착해서 먼저 확인합니다
가게나 창고 문을 여는 일이라 운영하시는 분이 맞는지 확인합니다. / 사업자 관련 서류, 주소가 적힌 우편물, 건물주나 관리 쪽 확인 중 하나면 됩니다.
임차인이라면 임대 관계를 확인할 서류를 챙겨 두시면 수월합니다. / 번거로워도 안전을 위한 절차입니다.

# 비용은 시작하기 전에 말씀드립니다
쪽문 상태와 잠금장치 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 손대기 전에 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html)에 적어 두었습니다.
@ 쪽문 잠금장치를 점검하는 모습

# 고칠지 바꿀지는 상태가 정합니다
열쇠 구멍 내부 부품만 문제면 [도어락 수리](doorlock-repair.html)로 해결되기도 합니다. / 문이 심하게 틀어졌다면 잠금장치만 바꿔서는 소용이 없을 수 있습니다.
잠금장치가 너무 낡았거나 열쇠를 복사하기 어려운 모양이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
쪽문에 번호식 잠금을 달고 싶다면 문 두께와 재질이 맞는지 먼저 봐야 합니다. / 가능한 경우에는 [도어락 설치](doorlock-install.html) 순서대로 진행합니다.

# 쪽문을 오래 쓰는 습관
- 쪽문은 밀어서 닫고, 쾅 닫지 않기
- 열쇠 구멍에 먼지가 쌓이지 않게 가끔 털어내기
- 예비 열쇠를 가게 밖 다른 안전한 곳에 한 개 보관
- 열쇠가 뻑뻑하다고 느껴지면 그날 바로 점검
- 셔터가 내려올 때 쪽문 틀에 닿지 않는지 가끔 확인
뻑뻑함을 한 달 넘게 참는 것이 가장 흔한 실수입니다. / 완전히 멈추기 전에 손보면 훨씬 간단하게 끝납니다.

# 진안동 말고 화성 어디든 갑니다
진안동 가까이 병점동, 기배동, 반송동, 능동까지 다니며 화성 안이면 어디든 24시간 출동합니다. / 가게 문 문제는 아침 일찍이나 밤늦게 생기는 일이 많아 시간 걱정 없이 전화 주셔도 됩니다.
동네별 안내는 [화성시 출장열쇠](hwaseong.html)에, 다른 지역은 [출장 지역](area.html)에 있습니다.
