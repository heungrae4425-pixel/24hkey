# 매일 누르던 번호가 갑자기 떠오르지 않을 때
동탄 목동에서 동탄역을 거쳐 집에 돌아오는 길, 도어락 앞에서 번호가 순간 기억나지 않는 일이 있습니다. / 늘 외우던 번호라도 피곤하거나 급할 때는 손가락이 길을 잃습니다.
번호를 가족이 바꿔 놓고 알려 주지 않아서 못 들어가는 경우도 흔합니다. / 이 글은 번호를 잊었을 때 침착하게 떠올려 볼 방법과, 끝내 안 될 때의 순서를 적었습니다.
@ 동탄 목동 도어락 비밀번호 분실

# 먼저 시도를 멈추고 숨을 고릅니다
번호가 떠오르지 않아 아무 숫자나 계속 누르면 도어락이 입력을 한동안 막아 버립니다. / 그러면 기억이 났을 때도 바로 시도할 수 없어 더 답답해집니다.
서너 번 틀렸다면 잠시 손을 떼고 벽에 기대 쉬어 보세요. / 시간이 지나면 막힘이 풀리는 제품이 많습니다.
물 한 모금 마시고 오늘 하루 어떤 일이 있었는지 떠올리다 보면 번호가 생각나기도 합니다. / 너무 몰아붙이면 오히려 머릿속이 하얘집니다.
번호가 기억나지 않을 땐 손가락이 기억하는 경우도 있으니 번호판을 보며 천천히 손을 움직여 보세요.

# 번호를 떠올리는 몇 가지 단서
처음 정할 때 어떤 기준으로 정했는지 되짚어 보면 도움이 됩니다.
- 이사하면서 새로 정한 번호인지, 이전 집 번호를 그대로 쓴 것인지
- 가족 모두 공통으로 쓰는 번호인지
- 최근에 누군가 번호를 바꾸겠다고 말했는지
- 번호를 메모해 둔 곳이 어디인지
이 중에서 하나라도 떠오르면 순서대로 눌러 보세요. / 단, 틀려도 여러 번 이어서 시도하지는 마세요.
이사 직후라면 예전 집 번호와 새 집 번호가 섞여 헷갈리는 일이 가장 흔합니다. / 두 개 이상 떠오르면 가장 최근에 정한 번호부터 한 번씩만 눌러 보세요.

# 가족이 바꿨다면 연락부터
번호가 갑자기 달라졌다면 가족 중 누군가 바꾼 경우가 많습니다. / 먼저 집에 있는 가족이나 번호를 아는 가족에게 전화를 걸어 보세요.
통화가 안 되면 문자나 메신저로 "현관 번호 알려 줘"라고 남겨 두면 나중에 확인됩니다. / 가족이 번호를 알고 있는지부터 확인하는 것이 가장 빠른 길입니다.
번호를 알려 줄 때는 주변에 사람이 있는지 보고 안전한 방법으로 전달하세요.
가족이 일하는 중이라 전화를 받지 못하면 잠시 기다렸다가 다시 걸어 보세요. / 연락이 닿기 전에 시간이 오래 걸릴 것 같으면 출장열쇠를 부르는 편이 낫습니다.

# 보조 수단이 있는지 확인합니다
번호가 안 되더라도 다른 방법으로 열 수 있는 제품이 많습니다. / 열쇠 구멍, 카드키, 지문, 리모컨, 앱 등 등록된 수단이 있는지 떠올려 보세요.
- 도어락 아래쪽 열쇠 구멍 덮개를 열어 열쇠 사용
- 카드키나 태그가 가방에 있는지 확인
- 지문이 등록되어 있다면 손가락 대 보기
- 앱이나 리모컨이 연결되어 있는지 확인
이런 수단이 하나도 없거나 전부 집 안에 있을 때 출장열쇠를 부르면 됩니다.
@ 동탄 목동 도어락 열쇠 카드키 대체 수단

# 번호 대신 초기화를 생각해도 될까
도어락에는 등록된 번호를 지우고 새로 설정하는 초기화 기능이 있습니다. / 하지만 대부분 문이 열린 상태에서 안쪽 버튼으로 하는 방식이라 문 밖에서는 쓸 수 없습니다.
바깥에서 초기화 버튼에 접근할 수 있는 제품은 드물고 그렇게 만들지도 않습니다. / 누구나 밖에서 초기화할 수 있으면 방범에 구멍이 생기기 때문입니다.
그래서 번호를 잊은 채 문 밖에 있다면 문을 먼저 열고 난 뒤에 초기화하는 것이 순서입니다.

# 하지 말아야 할 일
번호 조합을 하나씩 모두 눌러 보는 방식은 시간만 걸리고 입력 제한이 걸립니다. / 지문이나 카드가 있다고 해서 번호판을 세게 눌러 대지도 마세요.
문을 발로 차거나 도어락을 두드리는 행동은 부품을 상하게 합니다. / 괜히 해서 번호를 아는 상황에서도 열리지 않게 되는 일이 생깁니다.
이웃에게 문을 열어 달라고 도구를 빌려 시도하는 것도 권하지 않습니다. / 열쇠 구멍이 있다고 철사나 클립으로 돌려 보는 것도 피하세요. / 부품이 상하면 번호가 기억나더라도 문이 열리지 않게 됩니다.

# 사시는 분 확인은 꼭 필요합니다
번호를 모르는 채 문을 여는 일이라 사시는 분인지 확인이 특히 중요합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요. / 늦은 시간에는 경비실에 먼저 말씀해 두시면 수월합니다.
확인이 어려우면 작업을 시작할 수 없으니 미리 준비해 두면 좋습니다.

# 동탄 목동에서 위치를 알려 주세요
목동은 동탄역을 오가는 생활권이라 가까운 출구나 큰길을 하나 말씀해 주시면 찾기 쉽습니다. / 단지 이름과 동, 호수를 함께 알려 주세요.
- 단지 이름과 동, 호수
- 번호를 몇 번 틀렸는지
- 열쇠 구멍이나 카드키가 있는지
- 집 안에 아이나 반려동물이 있는지
도어락 사진을 보내 주시면 맞는 방법을 미리 정할 수 있습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 필요한 작업을 먼저 설명드립니다. / 그 뒤 비용을 말씀드리고 괜찮으실 때만 시작합니다.
못 열면 비용은 받지 않습니다. / 열린 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 있습니다. / 부품을 바꿔야 하면 바꾸기 전에 다시 여쭙습니다.

# 문을 연 뒤에는 번호부터 새로 정합니다
문이 열리면 안쪽에서 새 번호를 등록하고 이전 번호는 지웁니다. / 가족과 함께 번호를 정하고 모두가 알고 있는지 확인합니다.
새 번호는 쉬운 숫자를 피하고, 가족이 기억하기 쉬운 조합을 고르세요. / 메모를 남길 때는 문 근처에 두지 말고 휴대폰 잠금 메모처럼 안전한 곳에 두세요.
번호 변경은 [도어락 교체](doorlock-replace.html) 없이 설정만으로 끝나는 경우가 대부분입니다.
@ 동탄 목동 도어락 새 번호 등록 개문

# 다시 잊지 않으려면
번호를 잊는 일은 누구에게나 생기지만 몇 가지 습관으로 줄일 수 있습니다.
- 가족 단체 메시지방에 번호를 직접 쓰지 않고 안전한 방식으로 공유
- 카드키나 열쇠 하나는 가방과 별도로 보관
- 번호를 바꾸면 그날 바로 가족에게 알리기
- 도어락 배터리 교체일에 번호도 함께 점검
번호 바꾼 사실을 알리는 연락을 잊지 말아야 합니다. / 이 한 번의 연락이 문 앞의 곤란을 크게 줄여 줍니다.

# 동탄 목동 말고 화성 어디든 갑니다
목동 옆 능동, 청계동, 영천동, 오산동 등 동탄 지역과 병점동, 봉담읍, 향남읍도 다닙니다. / 화성 안이면 동네 상관없이 24시간 출동합니다.
[화성시 출장열쇠](hwaseong.html) 페이지에 다니는 동네가 있고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다. / 고장이 반복된다면 [도어락 수리](doorlock-repair.html) 안내도 참고하세요.
