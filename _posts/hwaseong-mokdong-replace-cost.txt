# 바꿔야 할지 고쳐도 될지 고민될 때
동탄 목동에서 도어락이 말썽을 부리면 한 번쯤 새로 달아야 하나 고민하게 됩니다. / 동탄역 가까운 생활권에서 오래 살다 보면 도어락도 나이를 먹습니다.
교체가 꼭 필요한 경우도 있고 고쳐 쓰는 편이 나은 경우도 있습니다. / 이 글은 교체하기 전에 확인할 것과 비용을 어떤 방식으로 안내받는지 순서대로 적었습니다.
@ 목동 도어락 교체 전 확인 사항

# 교체까지 가지 않아도 되는 경우
증상이 가벼우면 부품 하나로 끝나는 일이 많습니다.
- 건전지만 바꾸면 해결되는 번호판 꺼짐
- 접점을 닦으면 돌아오는 반응 둔함
- 손잡이 나사를 조이면 되는 헐거움
- 설정 초기화로 풀리는 오류
이런 경우에는 새 제품을 사기 전에 먼저 상태를 확인해 보세요. / 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.

# 교체를 생각해볼 만한 신호
고쳐도 계속 같은 증상이 반복된다면 교체를 고려할 때입니다.
- 부품 단종으로 수리가 어려운 경우
- 모터나 기판이 오래되어 고장이 잦은 경우
- 번호판 일부가 영구적으로 안 눌리는 경우
- 열쇠 대신 지문이나 카드키를 쓰고 싶은 경우
- 보안이 걱정되어 방식을 바꾸고 싶은 경우
오래 썼다는 이유만으로 바꿀 필요는 없습니다. / 증상이 반복되는지, 안전한지로 판단하세요.
한 번 고장 났다고 곧바로 바꾸면 멀쩡한 제품을 버리게 됩니다. / 건전지와 접점부터 확인한 뒤에 결정해도 늦지 않습니다.

# 문 두께와 보조키부터 확인합니다
새 도어락은 아무거나 달 수 없습니다. / 현관문 두께와 구멍 크기가 맞아야 합니다.
문에 이미 뚫린 구멍 위치가 제품마다 다릅니다. / 맞지 않으면 문에 새로 구멍을 내야 해서 일이 커집니다.
보조키가 따로 있는지, 어떤 종류인지도 같이 봅니다. / 보조키를 떼고 하나로 합치는 경우와 그대로 두는 경우가 있습니다.
문이 오래되어 보조키 구멍이 이미 닳았다면 그 상태도 함께 확인합니다.
설치 전 확인할 점은 [도어락 설치](doorlock-install.html) 페이지에도 적어 두었습니다.

# 사진 몇 장이면 사전 확인이 쉬워집니다
전화로 문의하실 때 사진이 있으면 정확한 안내가 가능합니다. / 아래 사진을 준비해 보세요.
- 현관문 바깥 도어락 전체
- 안쪽 도어락과 보조키
- 문 옆면의 걸쇠가 나오는 부분
- 도어락 뒷면 제품명이나 모델 표시
모델명이 있으면 부품이 있는지 먼저 확인할 수 있습니다. / 사진만으로 답이 어려우면 방문해서 보고 말씀드립니다.
문 옆면에 걸쇠가 나오는 판이 있는데 그 모양에 따라 맞는 제품이 달라집니다. / 사진을 찍기 어려우면 문을 열어 둔 채 설명해 주셔도 됩니다.
@ 목동 도어락 교체 전 문 두께 확인

# 비용은 이렇게 안내받습니다
비용은 제품 종류, 설치 방식, 기존 도어락 철거 여부에 따라 달라집니다. / 그래서 글에 숫자를 적기보다 안내하는 순서를 설명드립니다.
- 문과 도어락 상태를 먼저 보고
- 고쳐서 쓸 수 있는지, 바꿔야 하는지 설명하고
- 선택지가 있으면 비교해서 말씀드리고
- 작업을 시작하기 전에 총 비용을 먼저 말씀드립니다
괜찮다고 하실 때만 시작하고, 마음에 안 드시면 그냥 돌아갑니다. / 작업 도중 말없이 비용이 늘어나는 일은 없습니다.
부품을 바꿔야 하는 상황이 생기면 그 자리에서 이유를 설명하고 다시 여쭤봅니다. / 동의하지 않으시면 하던 일을 멈추고 원래 상태로 돌려 놓습니다.

# 비교할 때 이것만 물어보세요
여러 곳에 문의하실 때 같은 기준으로 비교하셔야 합니다. / 아래 질문을 같이 해 보세요.
- 제품 가격과 설치 작업이 따로인지 한꺼번에인지
- 기존 도어락 철거와 정리가 포함인지
- 설치 후 이상이 생겼을 때 어떻게 처리하는지
- 보조키 처리 방식이 어떤지
- 총액이 정해진 뒤에 추가 비용이 생길 수 있는지
질문에 막힘없이 답하는 곳이 믿을 만합니다. / 정확히 말해 주지 않고 현장에서 보자고만 한다면 한 번 더 따져 보세요.

# 지문이나 카드키를 고를 때
스마트 도어락은 편하지만 생활 방식에 맞아야 합니다. / 손이 자주 젖는 분이나 어르신이 있는 집은 번호 입력이 더 편할 수도 있습니다.
카드키는 잃어버릴 경우를 대비해 여분이 있어야 합니다. / 지문 인식이 잘 안 되는 가족이 있는지도 미리 확인하세요.
비밀번호 방식만 쓰는 것과 여러 방식을 겹쳐 쓰는 것의 차이를 설명드립니다. / 필요 이상의 기능은 권하지 않습니다.
집 안 사람 수와 생활 시간대에 맞게 꼭 필요한 기능만 짚어 드립니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
교체 작업 때도 같은 확인을 합니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.

# 문이 안 열려서 교체까지 필요한 상황이라면
도어락 고장으로 문이 안 열리는 경우에는 먼저 문부터 엽니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
열고 난 뒤에 교체가 필요한지 같이 보고 정합니다. / 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.
급한 마음에 한 번에 결정하지 마시고 상태를 본 뒤에 선택하셔도 됩니다. / 진행 순서는 [이용안내](guide.html)에서도 확인하실 수 있습니다.
@ 목동 24시 출장열쇠 도어락 교체 상담

# 수리와 교체를 나눠서 보는 법
[도어락 수리](doorlock-repair.html)는 고장 난 부분만 손보는 방식입니다. / 교체는 제품 전체를 새로 다는 방식이라 선택하기 전에 이유가 분명해야 합니다.
교체를 하더라도 [도어락 교체](doorlock-replace.html) 페이지에서 보는 순서처럼 문과 기존 구멍부터 확인합니다. / 비용이 부담되면 수리로 먼저 시도해 보고 안 될 때 바꿔도 늦지 않습니다.
교체를 미루다가 한밤에 문이 안 열리는 일을 겪는 것보다 미리 점검받는 편이 마음이 편합니다.

# 교체한 뒤에 꼭 하실 일
- 새 비밀번호를 가족과 같이 정하고 외우기
- 건전지 교체 시기를 달력에 표시
- 여분 열쇠나 카드를 믿을 만한 곳에 따로 보관
- 설치 후 문이 잘 잠기고 열리는지 직접 몇 번 시험
- 사용 설명서는 버리지 말고 보관
처음 며칠은 평소와 다른 소리나 반응이 없는지 신경 써서 보세요. / 이상이 있으면 바로 알려주셔야 정확히 조치할 수 있습니다.
건전지 방전 표시가 평소보다 일찍 뜬다면 설치 상태나 제품 문제일 수 있습니다. / 설치한 날짜와 함께 기억해 두면 상담이 쉬워집니다.
새 제품이라고 해서 처음부터 끝까지 문제가 없는 것은 아니니 가볍게 살펴보는 습관이 좋습니다.

# 목동 말고도 화성 어디든 갑니다
동탄 다른 동네와 병점, 봉담, 향남, 남양 등 화성 안이면 24시간 출동합니다. / 지역별 안내는 [화성시 출장열쇠](hwaseong.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 고칠 수 있는데 교체를 권하시지는 않나요? | 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.
? 문을 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 사진만 보내도 상담이 되나요? | 네, 도어락 전체와 문 옆면 사진이 있으면 대략 안내가 가능합니다.
? 밤에도 상담과 출장이 되나요? | 24시간 전화를 받습니다.
