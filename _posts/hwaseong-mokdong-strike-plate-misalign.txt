# 문은 닫히는데 잠기지 않는다면
목동은 동탄역 생활권에 속해 입주 시기가 서로 다른 건물이 이어져 있는 동네입니다. / 오래 살다 보면 문을 닫을 때 걸쇠가 문틀에 부딪히는 소리가 달라졌다고 느끼는 집이 있습니다.
도어락은 멀쩡한데 문이 덜 닫히거나, 번호를 눌러도 잠기는 소리가 불완전하게 들립니다. / 이럴 때 의심해 볼 곳이 문틀에 박힌 받음쇠입니다.
이 글은 목동에서 받음쇠 위치가 어긋났을 때 알아보는 법과 직접 해볼 수 있는 점검, 부르는 기준을 정리했습니다. / [화성 출장열쇠](hwaseong.html)가 현장에서 어떻게 보는지도 함께 적었습니다.
@ 목동 현관문 걸쇠와 문틀 받음쇠

# 받음쇠가 무엇이고 왜 어긋나는지
받음쇠는 문틀 쪽에 붙은 작은 금속판으로, 걸쇠와 잠금 볼트가 들어가는 구멍이 뚫려 있습니다. / 문이 닫힐 때 걸쇠가 이 구멍에 정확히 들어가야 잠깁니다.
문이 조금씩 처지거나 문틀이 뒤틀리면 걸쇠와 구멍의 높이가 어긋납니다. / 경첩이 헐거워지거나 문이 계절 따라 부풀었다 줄어드는 것도 원인입니다.
- 문을 닫을 때 걸쇠가 금속판 윗부분에 걸림
- 손잡이를 세게 눌러야 겨우 닫힘
- 잠금 볼트가 반만 나가고 멈춤
- 닫을 때마다 쿵 소리나 긁히는 소리가 남

# 가장 쉬운 확인, 립스틱 자국 같은 표시 보기
걸쇠 끝에 얇게 마커나 색연필로 칠을 해서 문을 닫았다 열어 보세요. / 문틀 쪽 금속판에 묻은 자국을 보면 걸쇠가 구멍 어디에 닿는지 알 수 있습니다.
구멍 한가운데가 아니라 위나 아래, 또는 가장자리에 자국이 있다면 어긋난 것입니다. / 이 방법은 도구 없이 위치만 가늠하는 용도로 충분합니다.
어느 방향으로 얼마나 어긋났는지 사진으로 남기면 나중에 설명하기 좋습니다. / 걸쇠 끝이 금속판의 위쪽 가장자리에 자국을 남겼다면 문이 처진 쪽, 아래쪽에 남겼다면 문틀이 내려앉았거나 문이 들린 쪽입니다.
자국이 매번 다른 곳에 찍힌다면 문이 닫히는 속도나 힘이 일정하지 않은 것일 수도 있습니다. / 도어클로저가 있는 문이라면 닫히는 속도도 같이 살펴보세요.

# 틈 간격으로 문이 처졌는지 살펴보기
문을 닫은 상태에서 문과 문틀 사이 틈을 위, 가운데, 아래에서 비교해 보세요. / 한쪽이 좁고 한쪽이 넓다면 문이 기울어 있는 것입니다.
문틀 윗모서리 쪽 틈이 문 손잡이 쪽에서 더 좁아지면 처짐을 의심합니다. / 이 경우는 받음쇠만 손볼 것이 아니라 경첩 쪽 나사 상태도 봐야 합니다.
경첩 나사를 손으로 돌려 보아 헐거운 것이 있는지만 확인하세요. / 세게 조이면 오히려 나사 구멍이 닳을 수 있어 조금씩만 해야 합니다.
@ 목동 문틈 간격 확인

# 문이 덜 닫힌 채 번호를 눌러도 되나
덜 닫힌 상태에서 잠금 버튼을 누르면 모터가 헛돌 수 있습니다. / 모터가 계속 돌면 배터리도 빨리 닳고 부품에 무리가 갑니다.
외출 전에 문이 완전히 닫혔는지 손으로 한 번 밀어 확인하는 습관이 좋습니다. / 문이 닫히지 않은 채 잠금 경고음이 나는 도어락도 있습니다.
돌아와서 번호를 눌렀는데 열리는 소리 없이 모터만 돌면 걸쇠가 받음쇠에 눌려 있는 경우입니다. / 이때는 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요.

# 직접 해볼 수 있는 간단한 조정
받음쇠를 고정하는 나사가 헐거워진 경우 드라이버로 조금 조여 보는 정도는 해볼 수 있습니다. / 다만 위치를 옮기는 작업은 정확하지 않으면 문이 아예 안 닫히게 될 수 있습니다.
문틀 구멍 크기를 줄칼로 깎아 넓히는 방법도 있지만 집에서 하기엔 권하지 않습니다. / 금속 가루와 흠집으로 문틀이 상하기 때문입니다.
조정한 뒤에는 문을 닫았다 열었다 몇 번 반복해 걸리는 곳이 없는지 확인하세요. / 한 번 괜찮아도 계절이 바뀌면 다시 어긋날 수 있습니다.

# 이런 건 하지 말아 주세요
- 문을 세게 쾅 닫아서 억지로 걸쇠를 넣기
- 걸쇠 끝을 줄로 갈아서 줄이기
- 받음쇠를 임의로 떼어 내기
- 문틀을 망치로 두드려 모양 맞추기
이런 행동은 당장은 닫힐 수 있어도 문틀과 걸쇠를 상하게 합니다. / 나중에 잠금이 완전히 안 돼 방범에도 허술해질 수 있습니다.

# 문이 안 열릴 때와 구분하기
받음쇠가 문제인 문은 닫을 때뿐 아니라 열 때도 걸립니다. / 손잡이를 돌려도 걸쇠가 풀리지 않는다면 걸쇠가 받음쇠에 끼어 있는 경우입니다.
이때는 문을 안쪽으로 밀어 눌림을 풀어 준 상태에서 열어 보세요. / 문을 잡아당기면 더 꽉 물립니다.
아무리 해도 안 열리면 억지로 힘주지 말고 연락 주세요. / 문과 문틀 모두 상하지 않게 여는 방법을 먼저 씁니다.

# 전화 주실 때 이렇게 말씀해 주세요
- 목동 안 대략적인 위치와 동, 호수
- 닫힐 때 걸리는지 열릴 때 걸리는지
- 걸쇠가 얼마나 나오는지(손으로 눌러 본 느낌)
- 문틈 사진 (위, 가운데, 아래)
- 도어락 종류와 번호판 상태
문틈 사진 두세 장이면 어떤 공구를 챙길지 가늠하기 좋습니다. / 동탄역 방향 어느 쪽인지만 알려 주셔도 위치 파악이 빨라집니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
잠기지 않는 문이라고 확인 없이 만지지는 않습니다. / 집을 지키기 위한 절차이니 양해 부탁드립니다.
@ 목동 문틀 받음쇠 위치 조정

# 비용은 문 열기 전에 말씀드립니다
받음쇠 조정으로 끝날지, 경첩까지 손봐야 할지는 현장에서 보고 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 있고, 문을 어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 현장에서는 이렇게 맞춥니다
먼저 걸쇠가 닿는 위치를 확인하고 받음쇠가 얼마나 어긋났는지 가늠합니다. / 몇 밀리미터의 차이로도 문이 걸리는 만큼 작은 조정이 많습니다.
받음쇠를 옮기거나 구멍을 정리하고, 필요하면 경첩 쪽을 함께 점검합니다. / 도어락 본체가 문제라면 [도어락 수리](doorlock-repair.html)로 연결합니다.
오래돼 틀이 크게 처진 경우에는 받음쇠만으로 안 될 수 있습니다. / 그때는 솔직하게 말씀드리고 가능한 방법을 같이 정합니다.

# 어긋나지 않게 오래 쓰는 습관
- 계절이 바뀔 때 문을 닫고 틈 간격 확인
- 경첩 나사가 헐거워지면 그때그때 조이기
- 문에 무거운 것을 걸어 두는 습관 줄이기
- 문을 쾅 닫지 않기
작은 변화를 일찍 알아채는 것이 가장 큰 예방입니다. / 여름 장마가 지나거나 겨울 난방을 시작한 뒤에는 문 크기가 미세하게 달라져 걸림이 새로 생기기도 합니다. / 문이 달라졌다고 느껴지면 소리와 느낌을 메모해 두세요.

? 문이 안 닫히는데 집에 못 들어갈 수 있나요? | 닫혀 있는데 안 열리는 경우라면 연락 주세요. 문을 상하지 않게 엽니다.
