# 목동에서 혼자 하교하는 아이의 현관문
목동은 동탄역 생활권으로 아이 키우는 가정이 많이 사는 동네입니다. / 부모가 일하는 시간에는 아이가 학교나 학원을 마치고 혼자 집에 들어오는 일이 흔합니다.
열쇠는 잃어버리기 쉽고 목에 걸고 다니는 것도 아이가 부담스러워하니 요즘은 대부분 번호로 들어옵니다. / 그런데 번호도 잊고, 입력이 어긋나고, 배터리가 닳으면 아이가 문 앞에서 막히게 됩니다.
이 글은 아이가 쓰는 도어락 번호를 어떻게 정하고 관리하면 좋은지, 문이 안 열리면 어떻게 하는지 적었습니다. / 급한 상황이면 [화성 출장열쇠](hwaseong.html)로 바로 연락 주셔도 됩니다.
@ 목동 하교 후 혼자 도어락 번호로 현관 들어가는 모습

# 번호는 아이가 외울 수 있어야 합니다
어른이 보기에 안전한 번호가 아이에게는 어려울 수 있습니다. / 외우기 어려우면 현관 앞에서 막히고 결국 번호를 메모해 가방에 넣게 됩니다.
아이가 기억하기 쉬운 규칙을 같이 만들어 보세요. / 단, 생일이나 전화번호처럼 남이 짐작하기 쉬운 숫자는 피하는 쪽이 낫습니다.
외우기 쉽고 남이 짐작하기 어려운 번호를 정한 뒤 아이와 같이 몇 번 연습해 보세요. / 문 앞에서 누르는 연습이 머릿속에 오래 남습니다.

# 번호를 메모하지 않도록 돕기
아이가 번호를 자주 잊는다면 메모를 하게 됩니다. / 문제는 메모가 가방이나 책상에서 다른 사람 눈에 띌 수 있다는 점입니다.
메모하더라도 번호 그대로 적지 말고 아이만 알아볼 수 있는 단서로 적도록 도와주세요. / 예를 들어 무슨 날짜의 숫자처럼 부모와 아이만 아는 힌트를 쓰는 방법입니다.
번호를 알려 주는 날은 꼭 친구가 곁에 없을 때로 하세요. / 번호를 말로 정리하는 연습 자체가 아이에게 보안 습관이 됩니다.

# 친구가 놀러 올 때 번호는 어떻게
하교 후 친구를 집에 데려오는 일은 자연스럽습니다. / 이때 번호를 눌러 문을 여는 모습을 친구들이 보게 됩니다.
번호를 누를 때 손으로 가리는 습관을 알려 주세요. / 친구를 의심하는 게 아니라 번호를 지키는 법을 가르치는 것입니다.
친구가 자주 오는 집이라면 일정 기간마다 번호를 바꾸는 방법도 있습니다. / 바꿀 때마다 아이와 번호 연습을 같이 하면 됩니다.

# 아이용 번호를 따로 두는 방법
가족이 쓰는 번호와 별개로 아이용 번호를 하나 더 등록할 수 있는 도어락이 많습니다. / 아이가 번호를 잊었을 때 부모 번호는 그대로 두고 아이용만 바꾸면 됩니다.
성장하면서 아이가 쓰는 번호를 바꿀 일이 생기는데, 그때마다 가족 번호까지 건드릴 필요가 없습니다. / 번호 등록과 삭제는 설명서 순서대로 하면 됩니다.
기능이 부족한 도어락이라면 [도어락 교체](doorlock-replace.html)를 알아볼 수도 있습니다. / 고쳐 쓸 수 있는 정도면 먼저 [도어락 수리](doorlock-repair.html)로 손보는 쪽을 권합니다.

# 아이가 번호를 누르는데 안 열릴 때
아이가 전화로 문이 안 열려요 하면 부모는 놀랍니다. / 먼저 아이에게 번호판이 켜지는지, 삑 소리는 나는지만 물어보세요.
번호를 한두 번 틀리면 잘못 누른 게 아니라 손에 땀이 나서 미끄러진 경우도 있습니다. / 차분히 처음부터 천천히 누르도록 안내해 주세요.
여러 번 틀리면 도어락이 잠시 입력을 막는 기종이 많습니다. / 서너 번 해 보고 안 되면 멈추고 기다리라고 알려 주세요.
@ 목동 아이 현관 도어락 번호판 불 켜짐 확인

# 번호판이 꺼진 경우, 아이에게 시키지 말 것
번호판이 아예 꺼져 있다면 배터리가 다 됐을 가능성이 큽니다. / 비상 단자에 9V 건전지를 대는 방법이 있지만 아이에게 직접 시키지 않는 것이 좋습니다.
아이가 서툴게 만지다 단자를 헷갈리거나 도어락을 눌러 부수는 일을 막기 위해서입니다. / 부모가 올 수 있다면 부모가 하는 쪽이 안전합니다.
배터리 교체는 계절이 바뀔 때쯤 부모가 미리 하는 습관을 들이세요. / 경고음이 한 번이라도 났다면 그날 바로 바꾸는 것이 좋습니다.

# 아이가 혼자 문 앞에서 기다릴 때의 안전
부모가 바로 오지 못하는 날, 아이가 문 앞에서 오래 기다릴 수 있습니다. / 아이에게 낯선 사람에게 문 때문에 막혔다고 말하지 않도록 이야기해 주세요.
믿을 만한 이웃이나 학원, 가까운 가족에게 갈 수 있는지를 미리 정해 두면 좋습니다. / 아이가 기다릴 안전한 장소를 한 곳 정해 두세요.
- 부모에게 바로 전화할 수 있는 번호
- 문 앞에서 기다리는 대신 갈 수 있는 곳
- 낯선 사람이 도와주겠다고 할 때의 대처
이렇게 정리해 아이와 한 번 이야기해 두는 것이 가장 도움이 됩니다.
학년이 올라가면 귀가 시간이 불규칙해지는 때가 많습니다. / 시험 기간이나 방과 후 활동이 있는 날은 도착 시간을 문자로 알려 달라고 약속해 두세요.
아이가 도착했다는 한 줄 연락이 오면 부모도 안심하고, 도착이 늦으면 바로 확인할 수 있습니다. / 번호를 쓰는 습관과 연락하는 습관이 함께 자리 잡으면 문 앞 사고가 크게 줄어듭니다.

# 출장열쇠를 부를 때 아이와 통화 요령
아이가 문 앞에 있는 상황에서 열쇠 도움이 필요하면 부모가 먼저 연락해 주세요. / 아이를 통해서만 이야기하면 확인이 늦어질 수 있습니다.
도어락 종류와 번호판 상태, 아이 이름과 나이 정도를 알려 주시면 도움이 됩니다. / [출장 요청 안내](key-call.html)에 어떤 걸 말씀하시면 좋은지 정리해 두었습니다.
아이가 놀라지 않게 문 앞에서 계속 말을 걸어 주세요. / 집 안에 아이가 있는지, 밖에 있는지도 꼭 먼저 말씀해 주세요.

# 문을 열기 전 신분 확인이 먼저입니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
아이만 현장에 있고 부모가 멀리 있다면 부모와 전화로 먼저 연결해 주세요. / 아이 혼자서는 작업을 진행하기 어렵기 때문입니다.
관리사무소에서 세대 확인을 받는 방법도 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 두면 좋습니다.

# 비용은 먼저 말씀드리고, 못 열면 없습니다
[현관문 개문](door-open.html) 전에 문과 도어락 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.
@ 목동 출장열쇠 아이 현관 도어락 점검

# 목동 말고 화성 어디든 갑니다
목동 바로 옆 오산동, 영천동, 산척동, 장지동도 다닙니다. / 화성 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [화성시 출장열쇠](hwaseong.html) 페이지에 있고, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
