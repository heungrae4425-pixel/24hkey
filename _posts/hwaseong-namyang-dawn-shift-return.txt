# 남양읍 새벽 퇴근길, 번호판이 먹통일 때
남양읍은 화성 서부 쪽에서 향남이나 봉담 방향으로 이어지는 생활권이라 교대 근무나 야간 일을 마치고 새벽에 들어오는 분이 많습니다. / 지친 몸으로 현관에 서서 번호를 눌렀는데 아무 반응이 없으면 그 순간이 가장 막막합니다.
이 글은 새벽에 번호판이 반응하지 않을 때 직접 해볼 수 있는 확인 순서와, 이웃을 깨우지 않고 [화성 출장열쇠](hwaseong.html)를 부르는 요령을 정리했습니다.
@ 남양읍 새벽 퇴근 후 도어락 번호판 반응 없음

# 반응 없음에도 종류가 있습니다
번호판이 아예 꺼져 있는지, 켜지긴 하는데 눌러도 안 열리는지 먼저 구분해 보세요. / 같은 먹통이어도 원인이 다릅니다.
- 손바닥으로 덮어도 불이 안 들어옴: 배터리 방전 가능성이 큼
- 불은 들어오는데 숫자가 안 눌림: 번호판 습기, 물기, 오염 가능성
- 눌러서 소리는 나는데 안 열림: 번호 오류, 모터, 걸쇠 쪽 문제
- 눌렀더니 잠깐 켜졌다 꺼짐: 배터리 전압이 거의 바닥
이 구분만 되면 전화로 설명하기 훨씬 쉬워집니다. / 새벽에는 머리가 잘 안 돌아가니 휴대폰 메모에 이 네 가지를 적어 두는 것도 방법입니다. / 어느 쪽인지 모르겠다면 보이는 대로 말씀해 주시면 됩니다.

# 배터리가 원인이라면 9V 건전지를 먼저
새벽에 편의점이 열려 있다면 9V 건전지를 구해 보세요. / 도어락 바깥쪽 아래에 이 건전지를 대는 비상 단자가 있는 제품이 많습니다.
건전지의 두 단자를 도어락 단자에 맞춰 눌러 붙이고 그대로 번호를 누르면 전원이 들어옵니다. / 건전지를 대고 있는 동안에만 작동하니 손을 떼지 말고 입력하세요.
열리면 안쪽 건전지를 모두 새것으로 바꿔야 합니다. / 일부만 바꾸면 곧 같은 일이 생깁니다.
@ 9V 건전지를 도어락 비상 단자에 대고 번호 입력

# 일하고 와서 손이 젖었거나 추웠다면
야외에서 일하고 돌아온 손이 젖거나 차가우면 터치 번호판이 반응을 못 할 때가 있습니다. / 손과 번호판을 마른 수건으로 닦고 다시 눌러 보세요.
추운 새벽에는 번호판이 늦게 반응하기도 합니다. / 손으로 잠시 덮어 온기를 주고 천천히 눌러 보면 돌아오는 경우가 있습니다.
장갑을 낀 채로 누르면 인식이 안 되는 방식도 있으니 장갑은 벗고 시도해 보세요.

# 번호를 눌렀는데 안 열릴 때
피곤한 상태에서는 평소 쓰던 번호도 헷갈립니다. / 천천히 한 자리씩 눌러 보세요.
번호를 여러 번 틀리면 도어락이 입력을 잠시 막습니다. / 서너 번 해보고 안 되면 멈추고 몇 분 쉬는 편이 낫습니다.
가족이 낮에 번호를 바꿨을 수도 있으니 연락이 닿으면 확인해 보세요. / 새벽이라 연락이 어렵다면 아래 순서로 넘어가시면 됩니다.

# 새벽에 하면 안 되는 것
졸린 상태에서는 판단이 흐려져 무리한 방법을 쓰기 쉽습니다. / 졸린 상태로 문을 세게 두드리거나 발로 차는 일은 피하세요. / 문이 상할 뿐 아니라 이웃이 놀라 신고로 이어질 수도 있습니다.
도어락 틈에 드라이버를 넣거나 번호판을 뜯어 보는 것도 하지 마세요. / 안쪽 회로가 상하면 배터리 문제가 부품 문제로 커집니다.
급한 마음에 배터리를 빼고 다시 끼우는 일을 반복하는 것도 좋지 않습니다. / 접점이 닳거나 설정이 초기화될 수 있고, 약한 건전지는 끼웠다 빼도 힘이 돌아오지 않습니다. / 한두 번 시도해 보고 반응이 없으면 연락하는 편이 훨씬 빠릅니다.

# 조용히 연락 주시는 방법
새벽이라 큰 소리를 내기 어려운 상황이면 문자로 먼저 상황을 보내셔도 됩니다. / 전화를 받으면 위치와 상태를 짧게 말씀해 주세요.
- 읍 안의 대략적인 위치와 건물 모양
- 번호판이 꺼졌는지, 켜졌는지, 소리가 나는지
- 도어락 사진이 가능하면 문자로
- 집 안에 가족이나 반려동물이 있는지
[출장열쇠 요청](key-call.html) 안내에 요청 방법을 적어 두었습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나로 확인합니다. / 일터에서 막 돌아온 길이라면 신분증이 지갑에 있을 가능성이 큽니다.
신분증이 집 안에 있다면 우편물이나 관리사무소 확인으로 대신할 수 있는지 상의해 드립니다. / 확인이 어려우면 작업을 할 수 없는 점 양해 부탁드립니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
상태를 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 그때 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 작업 도중에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 이웃이 자는 시간에는 이렇게 작업합니다
새벽 작업은 소리가 크면 이웃 불편이 큽니다. / 가능한 한 조용한 방법부터 시도하고 도어락과 문이 덜 상하는 방법을 먼저 씁니다.
작업 중에 어떤 소리가 날 수 있는지 미리 말씀드립니다. / 개문 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.
문이 열리면 도어락이 다시 잘 잠기고 열리는지까지 확인합니다. / 피곤하신 상태라 설명이 길지 않게, 고친 부분과 앞으로 주의할 점만 간단히 알려드립니다.
@ 새벽 시간 조용히 진행하는 도어락 개문 작업

# 열고 난 뒤 꼭 확인하는 것
배터리가 원인이었다면 건전지를 모두 바꾸고 번호판 반응을 다시 시험합니다. / 번호판이 습기나 오염 때문이었다면 닦은 뒤에도 같은 증상이 반복되는지 봅니다.
번호를 잊은 거라면 새 번호를 등록하고 기존 번호는 지웁니다. / 회로나 모터 문제가 보이면 바꾸기 전에 어떤 부품인지 설명드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 자세한 범위는 [도어락 수리](doorlock-repair.html)를 참고하세요.

# 야간 근무가 잦은 분들께 권하는 습관
- 건전지는 계절이 바뀔 때쯤 한 번에 모두 교체
- 퇴근 전에 번호판 반응이 느려졌는지 기억해 두기
- 가방에 비상용 9V 건전지와 여분 열쇠 하나 넣어 두기
- 새벽에 들어올 때는 손을 닦은 뒤 번호 누르기
- 가족이 번호를 바꾸면 바로 공유받기
새벽에 문 앞에서 막히면 해결할 방법이 제한되니 평소 준비가 중요합니다. / 열쇠를 쓰지 않는 도어락이라면 비상 열쇠를 따로 보관해 두세요.
오래 쓴 제품이라 반응이 자꾸 느려진다면 [도어락 교체](doorlock-replace.html)도 고려해 볼 만합니다.

# 남양읍 말고 화성 어디든 갑니다
남양읍 외에도 향남읍, 봉담읍과 병점동, 진안동, 반송동, 능동 등 화성 안이면 24시간 출동합니다. / 대략의 위치만 알려주시면 됩니다.
다니는 동네는 [화성시 출장열쇠](hwaseong.html)와 [출장 지역](area.html)에 있습니다.

# 마무리

24시출장열쇠는 남양읍을 포함한 화성 전 지역에서 24시간 전화를 받습니다. / 서울, 경기 어디든 전화 010-3664-5455로 연락 주세요.
