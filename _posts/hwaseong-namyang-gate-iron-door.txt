# 아파트 현관과는 다른 문들
남양읍은 주택가와 상가, 단독이나 다가구 건물이 이어진 곳이 많습니다. / 그래서 현관 도어락뿐 아니라 대문, 철문, 공동 출입문 문제로 연락하시는 분도 적지 않습니다.
이런 문은 오래 쓰는 만큼 녹이 슬거나 경첩이 처지고, 열쇠가 닳아 잘 안 돌아가기도 합니다. / 아파트 도어락과 달리 단순한 구조라서 오히려 작은 이물질 하나가 큰 문제가 됩니다.
이 글은 남양읍에서 대문과 철문, 공동 출입문이 안 열릴 때를 중심으로 정리했습니다. / 지역 전체 안내는 [화성 출장열쇠](hwaseong.html)에서 먼저 보셔도 됩니다.
@ 남양읍 대문 철문 열쇠 출장

# 철문과 대문의 흔한 고장 모양
증상을 말로 정리해 보면 크게 네 가지입니다. / 어느 쪽에 가까운지 먼저 떠올려 보세요.
- 열쇠가 들어가긴 하는데 끝까지 돌아가지 않는 경우
- 열쇠를 돌려도 문이 걸린 듯 당겨지지 않는 경우
- 자물통이 헛돌거나 잠김이 풀리지 않는 경우
- 문이 처져서 바닥이나 문틀에 닿는 경우
철문은 무게가 있어서 경첩이 조금만 처져도 잠금 위치가 어긋납니다. / 그럴 때는 열쇠가 멀쩡해도 안 돌아갑니다.

# 열쇠가 뻑뻑하게 돌아갈 때
오래된 자물통은 안쪽에 먼지와 녹이 쌓여 열쇠가 걸리듯 돌아갑니다. / 이럴 때 힘을 더 주면 열쇠가 휘거나 부러져 안에 박힐 수 있습니다.
열쇠를 꽂은 채 문을 살짝 안쪽으로 밀거나 당긴 상태에서 돌려 보면 의외로 쉽게 돌아가기도 합니다. / 문이 처지면 잠금 볼트가 문틀과 일직선이 아니기 때문입니다.
그래도 안 되면 억지로 돌리는 것을 멈추고 연락 주세요. / 열쇠가 부러지면 작업이 훨씬 번거로워집니다.

# 공동 출입문은 따로 챙길 것이 있습니다
다세대나 다가구 건물의 공동 현관은 여러 세대가 같이 쓰는 문입니다. / 한 집만의 사정으로 함부로 자물통을 바꾸거나 열 수 없습니다.
- 관리인이나 건물주에게 먼저 상황을 알리기
- 같은 건물에 사는 다른 세대가 안에서 열어 줄 수 있는지 확인
- 공동 현관의 비밀번호나 열쇠를 아는 사람이 있는지 찾기
이런 절차를 거치지 않고 문을 열면 나중에 불필요한 오해가 생길 수 있습니다. / 현장에서도 사시는 분이 맞는지 한 번 더 확인합니다.

# 처진 철문이 안 닫히고 안 열릴 때
철문은 시간이 지나면서 경첩 쪽이 헐거워지고 문 끝이 아래로 내려옵니다. / 문 아래가 바닥에 끌리는 소리가 나면 이미 처짐이 시작된 것입니다.
문틀과 문 사이 틈이 위쪽은 넓고 아래쪽은 좁다면 처진 상태입니다. / 이럴 때는 열쇠를 돌리기 전에 문을 살짝 들어 올리면 열리기도 합니다.
처짐은 두면 갈수록 심해지고 결국 자물통과 문틀이 모두 상합니다. / 경첩 조정이 필요한지는 현장에서 봐야 알 수 있습니다.
@ 남양읍 철문 경첩 처짐 확인

# 비가 오고 나면 더 안 열리는 이유
철제 대문은 비를 맞은 뒤 습기가 차서 자물통 안쪽이 부풀어 오르기도 합니다. / 겨울에는 얼어붙어 열쇠가 들어가지 않는 일도 있습니다.
뜨거운 물을 붓는 방법을 쓰는 분들이 있는데 이는 오히려 녹을 부추기고 다시 얼 수 있어 권하지 않습니다. / 마른 수건으로 열쇠 구멍 주변의 물기를 닦고 잠시 기다려 보는 편이 낫습니다.
윤활제를 뿌리면 일시적으로 풀리지만 먼지가 달라붙어 나중에 더 뻑뻑해집니다. / 뿌리기 전에 상담을 먼저 받으시길 권합니다.

# 남양읍에서 위치를 알려주는 방법
남양읍은 골목이 이어진 구역이 많아서 도로명 주소만으로는 정확한 대문을 찾기 어려울 때가 있습니다. / 대문 색깔이나 건물 모양, 근처의 눈에 띄는 가게 간판 방향까지 말씀해 주시면 빨라집니다.
- 정확한 주소와 어느 쪽 문인지
- 대문 재질(철제, 알루미늄, 나무)
- 자물통이 열쇠형인지 번호형인지
- 문이 한쪽만 열리는지 양쪽 열림인지
- 안에 사람이 있는지 비어 있는지
문과 자물통을 정면에서 찍은 사진을 보내 주시면 챙길 장비를 정하기 쉽습니다. / 가까운 큰길 방향도 함께 알려주세요.

# 도착 후 신분 확인
문을 열기 전에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 관리인 확인 중 하나면 됩니다.
임대로 거주하는 세입자는 계약서보다 우편물이나 신분증 주소로 확인하는 편이 간단합니다. / 건물 소유자라면 등기 관련 서류가 아닌 신분증과 주소 확인이면 충분합니다.
확인이 어려우면 작업이 불가하다는 점을 이해해 주세요.

# 비용은 열기 전에 먼저
문 열기만 하면 되는지, 자물통이나 경첩까지 손봐야 하는지 보고 먼저 말씀드립니다. / 괜찮으면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 설명 없이 붙는 항목은 없습니다.
부품 교체가 필요하면 작업 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 철문을 상하지 않게 여는 방법
철문은 힘으로 밀면 틀이 휘어 영구적으로 틈이 생깁니다. / 그래서 잠금 구조를 확인하고 자물통 쪽에서 해결하는 방법을 먼저 씁니다.
자물통을 부수는 방식은 마지막 수단이고, 그 전에 여러 방법을 시도합니다. / 부수게 될 상황이면 반드시 사전에 말씀드립니다.
[현관문 개문](door-open.html)에서 비파손 개방의 기본 방침을 읽어 보실 수 있습니다.
@ 남양읍 대문 자물통 비파손 개방

# 열고 난 뒤 같이 점검하는 곳
문이 열리면 열쇠가 부드럽게 돌아가는지 몇 번 확인합니다. / 자물통이 닳았다면 교체 의견을 말씀드리고, 쓸 만하면 청소만 해 드립니다.
대문을 번호키로 바꾸고 싶다면 [도어락 설치](doorlock-install.html)에서 철문에 맞는 방식을 살펴보세요. / 철문은 두께와 문틀 구조에 따라 맞는 제품이 한정됩니다.
열쇠를 새로 만들거나 복사한 키가 맞는지도 같이 봅니다. / 이미 닳은 복사 열쇠는 자물통을 더 빨리 상하게 합니다.

# 대문과 철문 오래 쓰는 요령
대문은 매일 쓰면서도 점검은 거의 하지 않는 부분입니다. / 아래 몇 가지만 챙겨도 갑작스러운 고장이 줄어듭니다.
- 경첩 부분에 녹이나 소리가 있는지 계절마다 보기
- 자물통 구멍에 이물질이 들어가지 않게 덮개 확인
- 복사 열쇠는 깨끗한 원본으로 다시 만들기
- 문이 처지는 느낌이 들면 미루지 말고 점검
작은 변화를 일찍 알아차리면 수리가 간단해집니다. / 문이 닫힐 때 소리가 달라졌다면 그것이 신호입니다.

# 남양읍 밖으로도 갑니다
