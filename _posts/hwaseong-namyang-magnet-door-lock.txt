# 남양읍에서 자석식 출입문이 말을 안 들을 때
남양읍은 주택과 작은 건물이 섞여 있어 공동 현관이나 상가 출입문을 자석식 잠금장치로 쓰는 곳이 있습니다. / 동탄역이나 병점역을 오가며 일하는 분이 많아 늦은 시간에 문이 말썽이면 곤란한 일이 생깁니다.
자석식 잠금장치는 문틀에 붙은 전자석이 문 쪽 철판을 붙잡아 문을 잠그는 방식입니다. / 전기가 끊기면 풀리거나, 반대로 전기가 들어와도 안 풀리는 문제가 생기기도 합니다.
이 글은 남양읍에서 자석식 출입문이 이상할 때 점검하는 순서를 적었습니다. / 직접 해결이 어려우면 [화성 출장열쇠](hwaseong.html)를 부르는 방법까지 이어집니다.
@ 남양읍 자석식 출입문 잠금장치 점검

# 자석식 잠금장치는 이렇게 작동합니다
문틀 위쪽에 긴 막대 모양의 본체가 붙어 있고, 문 쪽에는 철판이 달려 있습니다. / 전기가 들어오면 본체가 철판을 강하게 끌어당겨 문을 잠급니다.
출입 버튼을 누르거나 카드를 대면 전기가 잠깐 끊겨서 문이 풀립니다. / 그래서 전기 상태와 문이 맞닿는 위치가 모두 잘 맞아야 정상 동작합니다.
열쇠로 잠그는 일반 도어락과는 구조가 달라서 확인할 것도 다릅니다.

# 문이 안 열릴 때 나타나는 증상
증상마다 원인이 다르니 어떤 경우인지 먼저 구분해 보세요. / 증상을 정확히 말씀해 주시면 출장 전에 대비할 수 있습니다.
- 버튼을 눌러도 문이 계속 잠겨 있는 경우
- 카드를 대면 소리는 나는데 문이 안 풀리는 경우
- 문을 닫아도 붙는 느낌이 약해 쉽게 열리는 경우
- 문이 풀렸는데도 다시 붙어서 계속 열리지 않는 경우
- 전원이 아예 들어오지 않는 듯한 경우
각각 전원, 접점, 문 위치, 출입 장치 중 어디가 문제인지 달라집니다.

# 먼저 전원이 들어오는지 봅니다
자석식 잠금장치는 전원이 없으면 자석이 약해져 문이 풀릴 수 있습니다. / 반대로 전원이 계속 들어와 있으면 힘이 강해서 안 풀리는 문제가 생깁니다.
가까운 건물 내 분전함이나 전원 공급 장치의 불이 켜져 있는지 확인하세요. / 일부 건물은 정전 때 문이 풀리거나 반대로 잠기도록 설계되어 있으니 건물 관리 측에 확인이 필요합니다.
건물 관리인이 있다면 먼저 전원 이상이 있었는지 물어보세요.

# 문과 철판이 정확히 맞닿는지 확인
자석이 힘을 쓰려면 문 쪽 철판이 본체에 딱 붙어야 합니다. / 문이 조금만 처지거나 틀어져도 접촉면이 어긋나 잠금이 약해집니다.
문을 닫았을 때 본체와 철판 사이에 틈이 보이면 위치 조정이 필요한 상태입니다. / 틈이 작아도 자석 힘이 크게 줄어드니 육안으로 한 번 확인해 보세요.
철판 나사가 느슨해졌거나 한쪽이 휘어 있지 않은지도 눈으로 봅니다.
@ 남양읍 출입문 자석과 철판 맞닿는 부분

접촉면에 먼지나 녹, 페인트 자국이 있으면 자석이 제대로 붙지 않습니다. / 마른 천으로 가볍게 닦아 보는 것만으로 개선되는 경우도 있습니다.
오래된 건물이거나 습기가 많은 곳은 녹이 슬기 쉬워서 정기적인 점검이 필요합니다. / 거친 물건으로 문지르면 표면이 상할 수 있으니 부드럽게 닦으세요.
접촉면에 테이프나 종이 등을 붙여 임시로 해결하려 하지 마세요. / 오히려 틈이 생겨 더 약해질 수 있습니다.

# 출입 버튼과 카드 리더 점검
문이 안 열릴 때 의외로 많은 원인이 출입 버튼이나 카드 리더입니다. / 버튼이 눌리는 느낌이 둔하거나 소리가 안 나면 입력 장치 문제일 수 있습니다.
카드 리더는 카드를 대었을 때 불빛이나 소리가 나는지 확인합니다. / 반응이 없다면 카드 문제인지 리더 문제인지 다른 카드로 한 번 더 시도해 보세요.
여러 카드가 모두 안 되면 리더나 전원 쪽 문제일 가능성이 큽니다.

# 하지 말아야 할 것
급하다고 문을 세게 당기거나 어깨로 밀면 문틀과 철판이 휘어 일이 커집니다. / 특히 자석이 강하게 붙은 상태에서 당기면 접점에 무리가 갑니다.
전선이나 전원 장치를 직접 만지는 것은 위험합니다. / 감전이나 합선 위험이 있으니 반드시 전문가에게 맡기세요.
인터넷에서 본 방법이라며 자석에 다른 금속을 붙이는 행동은 오히려 고장을 부릅니다.

# 안에 사람이 있을 때는 안전 먼저
출입문이 안 열려 사람이 건물 안에 갇힌 상황이라면 안전이 우선입니다. / 비상 해제 장치나 비상구가 있는지 침착하게 확인하세요.
문 너머로 계속 말을 걸어 안심시키고, 지체 없이 전화로 알려주세요. / 사람이 있는 상황은 먼저 말씀해 주시면 우선해서 움직입니다.
소방 설비와 연결된 문일 수 있으니 임의로 장치를 조작하지 마세요.

# 출장열쇠에 알려주실 정보
건물 출입문은 구조가 다양해서 사진이 큰 도움이 됩니다. / 아래 항목을 알려주세요.
- 남양읍 어느 쪽 건물인지, 건물 이름 대신 층과 위치
- 문이 안 열리는지, 안 닫히는지 어느 쪽인지
- 전원이 들어오는지와 최근 정전이나 공사 여부
- 출입 방식(버튼, 카드, 번호)
- 문틀 위쪽 본체와 철판 사진
사진이 있으면 필요한 부품을 미리 가늠해 시간을 줄일 수 있습니다.

# 도착하면 이용하시는 분인지 확인합니다
문을 여는 일이라 이 건물을 쓰시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 건물 관리인 확인 중 하나면 됩니다.
번거로워도 건물을 쓰는 모든 분을 지키는 절차입니다. / 서류가 없다면 건물 관리인에게 확인을 부탁하는 방법도 있습니다.

# 비용은 작업 전에 먼저 말씀드립니다
문 상태와 장치 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 작업이 끝난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 남양읍 자석식 장치 위치 조정과 점검

# 점검 후에 해 두는 일
문이 풀리고 다시 붙는 동작을 여러 번 시험해 봅니다. / 처음 한 번만 되는 것이 아니라 계속 안정적인지 확인하는 것이 중요합니다.
접촉면이 심하게 닳았거나 본체가 약해졌다면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 먼저 살피고, 교체가 맞다면 [도어락 교체](doorlock-replace.html)를 따로 말씀드립니다. / 새로 설치하는 경우는 [도어락 설치](doorlock-install.html)에 흐름이 있습니다.

자석식 장치는 눈에 띄지 않게 서서히 약해지기 쉽습니다. / 한 달에 한 번 정도 문이 잘 붙는지 손으로 확인하는 습관이 도움이 됩니다.
- 문이 닫혔을 때 틈이 없는지 보기
- 접촉면을 마른 천으로 가볍게 닦기
- 카드 리더 소리와 불빛 확인
- 정전 뒤에는 문 동작을 한 번 시험
문이 이상하게 늦게 풀리거나 가끔 안 풀린다면 완전히 멈추기 전에 연락 주세요.
