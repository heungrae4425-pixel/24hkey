# 남양읍 오래된 집에서 문이 말썽일 때
남양읍에는 오래된 주택과 빌라가 많고, 현관문도 세월이 지나며 조금씩 뒤틀립니다. / 도어락은 멀쩡한데 문이 안 열리거나 안 닫히는 일이 그래서 생깁니다.
이 글은 남양읍처럼 오래된 문에서 도어락이 아니라 문과 문틀 때문에 안 열릴 때 확인할 것을 정리했습니다. / 직접 해결이 어려우면 [화성 출장열쇠](hwaseong.html)를 부르시면 됩니다.
@ 남양읍 오래된 현관문 문틀 처짐 출장열쇠

# 도어락 문제가 아닌 이유부터
번호가 맞고 모터도 돌아 걸쇠는 빠지는데 문이 안 열리면 문과 문틀이 맞닿아 있는 경우가 많습니다. / 문이 처지거나 문틀이 기울면 걸쇠가 문틀에 눌려 빠지지 않습니다.
이때 도어락을 바꿔도 문제가 그대로라 헛돈이 드는 일이 생깁니다. / 원인을 먼저 가려내는 것이 중요합니다.

# 이런 증상이면 문 처짐을 의심하세요
- 문을 닫을 때 위나 아래쪽이 문틀에 쓸린다
- 겨울이나 여름에만 문이 뻑뻑해진다
- 손잡이를 돌려도 걸쇠가 문틀에 걸려 느껴진다
- 문을 안쪽으로 밀어야만 열린다

# 경첩이 헐거워진 경우
오래 쓴 문은 경첩 나사가 풀려 문이 아래로 처집니다. / 이럴 때 문을 살짝 들어 올리며 열어 보면 열리기도 합니다.
경첩 나사를 조이는 것만으로도 좋아지는 경우가 있습니다. / 다만 문이 무거워 직접 하기 위험하니 무리하지 마세요.
@ 남양읍 경첩 헐거움 현관문 점검

# 문틀이 틀어진 경우
건물이 오래되면 문틀이 미세하게 기울어 문과 맞지 않게 됩니다. / 이때는 걸쇠 받이 위치를 조정해 해결하기도 합니다.
문틀 자체를 건드리는 일은 크게 번질 수 있어 먼저 상태를 보고 말씀드립니다. / 꼭 필요한 만큼만 손봅니다.

# 계절에 따라 문이 변합니다
목재가 섞인 문은 습한 장마철에 부풀어 뻑뻑해집니다. / 겨울에는 문틀이 수축해 오히려 헐거워지기도 합니다.
같은 문인데 계절마다 열리는 느낌이 다르다면 문 상태의 신호입니다. / 한 번 점검받아 두면 계절이 바뀌어도 마음이 편합니다.

# 세게 당기거나 걷어차지 마세요
오래된 문에 힘을 주면 경첩이 더 휘고 문틀이 갈라집니다. / 드라이버로 틈을 벌리는 것도 도어락과 문틀 모두 상하게 합니다.
급해도 힘으로 해결하려 하지 마시고 상황만 알려 주세요. / 오히려 더 큰 수리가 필요해질 수 있습니다.

# 전화로 알려주실 것
- 남양읍 위치, 주택인지 빌라인지, 몇 층인지
- 번호를 누르면 어떤 소리가 나는지
- 문을 밀면 반응이 있는지
- 문이 처지거나 쓸리는 부분이 있는지
문틀과 문 사이 틈 사진을 보내주시면 상태를 가늠하기 좋습니다.

# 도착하면 먼저 확인부터 합니다
사시는 분인지 신분증 주소나 우편물로 먼저 확인합니다. / 주택이라면 우편함이나 가스 고지서도 괜찮습니다.
신분증이 집 안에 있다면 이웃이나 관리인의 확인으로 대신할 수 있는지 말씀해 주세요. / 이 절차를 거쳐야 작업이 가능합니다.

# 문을 열고 나서 원인을 봅니다
먼저 문과 문틀이 상하지 않게 여는 것이 우선입니다. / 열린 뒤에는 경첩, 문틀, 걸쇠 받이 위치를 차례로 봅니다.
고칠 수 있는 정도면 그 자리에서 손보고, 큰 작업이 필요하면 먼저 말씀드립니다. / 필요하지 않은 교체는 권하지 않습니다.
@ 남양읍 출장열쇠 24시간 현관문 개문

# 비용은 열기 전에 말씀드립니다
상태를 보고 비용을 먼저 말씀드리고 동의하시면 시작합니다. / 마음에 안 드시면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 추가 작업이 필요한 경우에도 시작 전에 따로 여쭙니다.
[현관문 개문](door-open.html) 페이지에 진행 방식이 있고, 문 수리 상담은 [도어락 수리](doorlock-repair.html)에서 보세요.

# 걸쇠 받이만 조정해도 해결될 때
문틀 쪽에 걸쇠가 끼는 판이 있는데, 위치가 살짝 어긋나면 걸쇠가 눌립니다. / 이 판을 조금만 옮기거나 다듬어 줘도 문이 부드럽게 열리는 경우가 많습니다.
도어락 전체를 바꿀 일이 아닌 경우가 의외로 많습니다. / 그래서 먼저 상태를 보고 말씀드립니다.

# 도어락도 같이 점검합니다
문이 처진 상태로 오래 쓰면 도어락 내부에도 무리가 갑니다. / 문을 바로잡은 뒤 도어락이 정상으로 잠기고 열리는지 함께 봅니다.
상태가 좋지 않으면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 문과 도어락을 같이 봐야 같은 일이 다시 생기지 않습니다.

계절이 바뀔 때 문이 평소와 다르게 느껴지면 미리 점검해 두면 겨울이나 장마 때 큰일을 줄일 수 있습니다. / 특히 남양읍 오래된 주택은 현관문 아래쪽 틈과 문턱 높이가 달라 문이 쓸리기도 합니다.
문턱 쪽이 닳아 문이 걸린다면 문 아래쪽 높이를 조정해 해결하는 경우도 있습니다. / 이런 작은 조정으로 문이 다시 부드럽게 움직이면 도어락을 바꿀 필요가 없습니다.

# 오래된 문을 오래 쓰는 관리법
- 경첩 나사를 가끔 조여 주기
- 경첩에 윤활제를 소량 발라 뻑뻑함 줄이기
- 문 아래쪽이 바닥에 쓸리지 않는지 보기
- 문이 덜 닫히면 미루지 말고 바로 점검받기

# 남양읍 말고 화성 어디든 갑니다
남양읍 근처 향남, 봉담은 물론 병점, 진안, 동탄까지 화성 전 지역을 다닙니다. / 오래된 주택과 빌라 문도 환영합니다.
다니는 동네는 [출장 지역](area.html) 지도에서 확인하세요. / 진행 방식은 [이용안내](guide.html)에 있습니다.
