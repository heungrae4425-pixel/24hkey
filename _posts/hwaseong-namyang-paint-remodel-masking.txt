# 남양읍 도배·페인트 뒤 도어락이 이상해졌다면
남양읍에서 향남이나 봉담 쪽으로 오가며 사는 분들 중에 이사 전후로 도배나 페인트 작업을 하는 경우가 많습니다. / 작업이 끝나고 보니 도어락이 뻑뻑하거나 열쇠가 안 들어간다는 이야기가 가끔 있습니다.
원인은 대부분 도어락 틈이나 열쇠 구멍에 페인트, 풀, 실리콘, 먼지가 들어간 경우입니다. / 작업자가 도어락을 가리지 않고 칠했거나 마스킹 테이프를 늦게 뗐을 때 생깁니다.
이 글은 [화성 출장열쇠](hwaseong.html)를 부르기 전에 남양읍에서 살펴볼 수 있는 것과 손대지 말아야 할 것을 적었습니다.
@ 남양읍 도어락 틈에 굳은 페인트 자국

# 이런 증상이면 이물질을 의심해 볼 만합니다
작업 직후 갑자기 생긴 불편이라면 먼저 의심해 볼 수 있습니다. / 아래 증상과 맞는지 확인해 보세요.
- 번호 버튼이 눌린 채 올라오지 않거나 느리게 올라옴
- 열쇠 구멍에 열쇠가 끝까지 들어가지 않음
- 손잡이가 뻑뻑하게 움직이거나 중간에 걸림
- 문틀 쪽 걸쇠에 하얀 가루나 굳은 얼룩이 보임
- 도어락 외관 틈새로 굳은 페인트 선이 보임
이런 증상은 배터리와 상관없이 기계 쪽에서 나옵니다. / 건전지를 갈아도 나아지지 않는 경우가 많습니다.

# 도배풀이나 페인트는 어디로 스며들까
도어락은 겉보기엔 막혀 있어도 버튼 주변과 손잡이 축, 열쇠 구멍에 미세한 틈이 있습니다. / 이 틈으로 액체가 스며들어 굳으면 부품이 달라붙습니다.
벽지를 붙일 때 쓰는 풀은 마르면 딱딱해지고 끈적이는 막이 남습니다. / 페인트도 마르는 동안 흘러 들어가 걸쇠나 데드볼트에 굳기도 합니다.
문 옆 벽을 작업하다 문을 열어 둔 채 하는 경우 문틀 쪽 홈에 가루가 쌓이기도 합니다. / 작은 입자가 모여 걸쇠가 끝까지 들어가지 못하게 만듭니다.

# 마스킹을 하고 작업했는데도 생기는 이유
작업자가 도어락에 비닐을 씌우고 테이프를 붙였더라도 완벽히 막히지는 않습니다. / 테이프를 오래 붙여 둔 채 두면 접착 성분이 남기도 합니다.
테이프를 뗄 때 같이 당겨져 도어락 외관이 상하는 일도 있습니다. / 비닐 아래에 습기가 차서 번호판 쪽 접점에 영향을 주는 경우도 있습니다.
도배 후 마르는 동안 실내 습도가 올라가는 점도 영향을 줍니다. / 한동안 환기를 충분히 해 주는 것이 좋습니다.
@ 도어락에 마스킹 테이프를 붙인 도배 작업 현장

# 직접 해볼 수 있는 것과 하지 말 것
겉에 묻은 얼룩은 마른 천으로 가볍게 닦아도 됩니다. / 굳은 자국은 미지근한 물을 살짝 적신 천으로 눌러 불린 뒤 닦아 보세요.
시너, 아세톤, 알코올을 도어락에 직접 뿌리는 것은 권하지 않습니다. / 도어락 안쪽 플라스틱이나 기판이 상할 수 있습니다.
칼이나 드라이버로 굳은 페인트를 긁어내면 도어락 외관에 흠집이 납니다. / 열쇠 구멍에 얇은 철사를 넣어 파내는 것도 내부를 상하게 합니다.
윤활제를 많이 뿌리면 가루와 섞여 더 끈적해집니다. / 상태를 모르면 건드리지 말고 먼저 연락 주세요.

# 문이 잠겨 있는데 열쇠가 안 들어갈 때
번호가 먹지 않고 열쇠도 안 들어가면 안쪽에서 걸쇠가 막혔을 수 있습니다. / 이때는 무리하게 열쇠를 넣으려 하면 열쇠가 부러질 수 있습니다.
열쇠가 구멍에 반쯤 들어갔다면 억지로 돌리지 말고 천천히 빼 보세요. / 안 빠지면 그대로 두고 전화 주세요.
사진을 찍어 두면 구멍 안쪽에 이물질이 보이는지 확인하기 좋습니다. / 휴대폰 손전등으로 비춰 찍으면 더 잘 보입니다.

# 남양읍 위치는 이렇게 알려주세요
남양읍은 주택, 상가, 아파트가 섞여 있어 건물 형태를 알려 주시면 도움이 됩니다. / 아래 정보를 함께 말씀해 주세요.
- 건물 종류와 층, 호수
- 도배나 페인트 작업이 끝난 시점
- 번호판 상태와 열쇠가 들어가는지 여부
- 눈에 보이는 얼룩이나 굳은 자국
- 집 안에 사람이나 반려동물이 있는지
작업 업체와 연락이 되신다면 어떤 제품을 썼는지 물어봐 주시면 참고가 됩니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
새로 이사 오셔서 우편물이 아직 없다면 계약서나 관리사무소 확인을 같이 알아봅니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문을 열고 이물질을 정리하는 순서
먼저 문을 상하지 않게 여는 방법부터 시도합니다. / 현관문 개문의 자세한 과정은 [현관문 개문](door-open.html) 페이지에 적었습니다.
문이 열리면 도어락을 분해해 굳은 이물질을 부드럽게 제거할 수 있는지 봅니다. / 가벼운 경우는 청소만으로 돌아옵니다.
부품이 이미 굳어 붙었다면 해당 부품만 교체하거나 [도어락 수리](doorlock-repair.html)로 손볼 수 있습니다. / 완전히 상했을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 도어락을 분해해 굳은 이물질을 제거하는 모습

# 앞으로 도배·페인트 작업할 때 미리 알려둘 것
- 작업 시작 전 도어락 번호판과 열쇠 구멍을 비닐로 감싸 달라고 요청
- 마스킹 테이프는 작업이 끝나면 되도록 빨리 제거
- 가능하면 도어락 외관을 잠시 떼어 두고 작업하기
- 작업이 끝난 날 열쇠와 번호가 정상 작동하는지 확인
- 문제가 있으면 작업자가 있을 때 바로 이야기하기
작업 직후에 확인하면 책임을 이야기하기도 쉽습니다. / 시간이 지나면 원인을 가리기 어려워집니다.
이사 전 도어락을 새로 달 계획이라면 도배·페인트가 끝난 뒤에 설치하는 것이 안전합니다. / 설치 관련 내용은 [도어락 설치](doorlock-install.html)에도 있습니다.

# 남양읍 말고 화성 어디든 갑니다
남양읍 옆으로 향남읍, 봉담읍, 병점동, 동탄 쪽까지 화성 안이면 24시간 출동합니다. / 거리에 따라 도착 시간이 달라 위치를 먼저 알려 주세요.
다니는 동네는 [화성시 출장열쇠](hwaseong.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
