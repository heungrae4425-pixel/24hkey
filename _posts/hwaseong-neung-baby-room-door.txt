# 능동 아기방 문이 안에서 잠겼을 때
능동은 동탄역 생활권으로 오가는 가족들이 많은 동네입니다. / 아이가 있는 집에서는 아기방 문이 안에서 잠겨 버렸다는 연락이 생각보다 자주 옵니다.
아이가 방 안에서 혼자 울고 있는데 문이 안 열리면 누구라도 마음이 급해집니다. / 이 글은 그럴 때 가장 먼저 할 일과 해서는 안 되는 것을 순서대로 적었습니다.
[화성 출장열쇠](hwaseong.html)에 연락하시기 전에 읽어두시면 전화로 상황을 설명하기 쉬워집니다.
@ 능동 아기방 문 잠김 출장열쇠

# 가장 먼저 아이 상태를 확인하세요
문 앞에서 이름을 부르고 대답이나 울음소리가 있는지 확인합니다. / 소리가 있으면 일단 숨은 쉬고 있다는 뜻이니 침착하게 다음 단계로 가세요.
아무 소리도 없거나 아이가 위험해 보이는 상황이라면 지체하지 말고 119에 먼저 연락하세요. / 열쇠 작업보다 아이 안전이 늘 먼저입니다.
전화하실 때는 아이 나이와 방 안 상황을 먼저 말씀해 주세요. / 그에 맞춰 도착하는 대로 가장 안전한 순서로 진행합니다.

# 방문이 안에서 잠기는 흔한 경우
- 아기방 문손잡이에 달린 안쪽 잠금 버튼이 눌린 경우
- 문을 세게 닫으면서 잠금이 저절로 걸린 경우
- 걸어 다니는 아이가 호기심에 버튼을 돌린 경우
- 문틀과 문이 맞지 않아 래치가 걸려 버린 경우
방문 손잡이의 잠금은 대개 바깥쪽에 작은 구멍이 있어 비상 해제가 가능합니다. / 현관문 도어락과는 구조가 달라 열기가 쉬운 편입니다.
다만 구멍에 맞는 도구가 없다면 억지로 하기보다 전화 주시는 편이 안전합니다.

# 아이에게 문 안쪽에서 해줄 수 있는 말
아이가 돌이 지났다면 문 너머에서 천천히 말을 걸어 주세요. / 손잡이를 돌려 보라고 하는 것보다 문 가까이 와서 이야기하게 하는 것이 먼저입니다.
아이가 울고 있으면 노래를 불러 주거나 좋아하는 소리를 내서 달래 주세요. / 울음이 잦아들면 문 앞에서 멀리 있게 해 주는 것이 좋습니다.
"문 열어줄게", "곧 들어갈게" 같은 짧은 말을 반복해 주면 아이가 덜 불안해합니다. / 문이 열릴 때 아이가 문 바로 앞에 서 있지 않도록 이야기해 두세요. / 아직 말을 못 하는 아기라면 부모님 목소리를 계속 들려주는 것만으로도 도움이 됩니다.
옆방에 다른 가족이 있다면 창문이나 다른 통로로 아이를 볼 수 있는지도 확인해 보세요. / 다만 창문 쪽으로 무리해서 나가거나 위험하게 접근하는 것은 하지 마세요.

# 급하다고 문을 세게 밀거나 부수지 마세요
문을 몸으로 밀면 문틀이 상하고, 안에 있는 아이가 문 쪽으로 다가와 있다면 다칠 수도 있습니다. / 특히 문 바로 뒤에 아이가 서 있을 때 위험합니다.
송곳이나 칼 같은 도구로 손잡이 틈을 벌리는 것도 좋지 않습니다. / 손이 다치기 쉽고 잠금 장치가 더 꼬일 수 있습니다.
문을 그냥 두드리거나 흔드는 것도 소음 때문에 아이를 더 놀라게 합니다.
@ 아기방 문 앞 침착하게 상황 확인

# 집에 있는 도구로 해볼 수 있는 것
방문 손잡이 바깥쪽 가운데에 작은 구멍이나 홈이 있는지 보세요. / 있다면 가는 일자 드라이버나 동전으로 돌려 보는 방법이 있습니다.
돌릴 때는 힘을 세게 주지 말고 천천히 방향을 바꿔 가며 해보세요. / 안 돌아가면 억지로 하지 말고 멈추는 게 좋습니다.
구멍이 없는 제품이거나 손잡이가 헛도는 경우는 도구로 해결되지 않습니다. / 이럴 때는 [현관문 개문](door-open.html)과 비슷하게 상태를 보고 방법을 정해야 합니다.

# 전화하실 때 알려주실 내용
능동은 동, 호수와 가까운 큰길만 알려주셔도 찾아갈 수 있습니다. / 상황을 짧게 정리해서 말씀해 주세요.
- 동, 호수와 방 위치 (현관에서 어느 쪽인지)
- 아이 나이와 지금 울고 있는지 여부
- 손잡이 모양과 바깥쪽 구멍 유무
- 방 안에 위험한 물건이나 창문 열림 여부
손잡이 사진을 문자로 보내주시면 맞는 공구를 챙겨 가기 좋습니다. / 문 안쪽 상황이 걱정되시면 그 부분도 꼭 먼저 말씀해 주세요.
밤중이라면 이웃에게 소음 양해를 구해 두면 작업이 한결 편안합니다. / 아이가 자고 있는 다른 방은 문을 닫아 두세요.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
아이 일로 마음이 급하시더라도 이 절차는 이웃과 가족 모두를 위한 것입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.
신분증이 방 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

# 비용은 문 열기 전에 말씀드립니다
방문 손잡이 종류와 상태를 보고 비용을 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 자세한 방식은 [이용안내](guide.html)에 있습니다.
@ 방문 손잡이 비상 해제 작업

# 문을 열 때 아이가 놀라지 않게
문을 열기 전 아이에게 이제 열린다고 한 번 더 이야기해 줍니다. / 작업 소리가 나면 아이가 겁낼 수 있어서 부모님이 문 앞에서 계속 말을 걸어 주시면 좋습니다.
문이 열리면 먼저 아이를 안아 주시고, 도구와 작업은 잠시 뒤로 미뤄도 괜찮습니다. / 필요하면 저는 한쪽에서 기다립니다.

# 열고 난 뒤 손잡이 점검
문이 열리면 잠금이 다시 정상적으로 걸리고 풀리는지 확인합니다. / 어린아이가 있는 집이라 잠금이 쉽게 걸리는 손잡이라면 방법을 안내해 드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 자주 잠긴다면 [도어락 수리](doorlock-repair.html)에서 말씀드린 방식으로 부품을 먼저 손보고, 너무 낡았으면 [도어락 교체](doorlock-replace.html)를 설명드립니다.

# 아기방 문 잠김 재발 막는 습관
- 아이 방 문에 문 닫힘 방지 쿠션이나 고무 스토퍼 붙이기
- 안쪽 잠금 버튼은 아이 손이 닿지 않는 높이 확인
- 비상 해제용 도구를 손쉬운 서랍에 두기
- 문을 세게 닫지 않도록 가족끼리 이야기하기
- 손잡이가 헐거워지면 미루지 말고 점검
비상 해제 도구를 어디 두었는지 가족이 모두 알고 있으면 정작 그때 당황하지 않습니다. / 방문 손잡이는 생각보다 단순해서 미리 한 번 구조를 살펴 두면 도움이 됩니다.
아이가 걷기 시작하는 시기에는 방문 안쪽 잠금이 없는 손잡이로 바꾸는 방법도 있습니다. / 그런 경우는 [도어락 설치](doorlock-install.html) 페이지에서 설명한 순서로 상담해 드립니다.

# 능동 말고 화성 어디든 갑니다
능동 옆 반송동, 청계동, 영천동은 물론 병점이나 봉담, 향남까지 화성 안이면 24시간 출동합니다. / 다니는 동네는 [화성시 출장열쇠](hwaseong.html) 페이지에 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인하세요.
