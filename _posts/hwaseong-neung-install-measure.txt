# 능동에서 도어락을 새로 달기 전에
동탄 능동은 신도시 아파트와 주택이 함께 있어 도어락을 새로 바꾸거나 처음 다는 집이 꾸준합니다. / 제품을 먼저 사 놓고 설치하려다 안 맞아서 낭패를 보는 일이 의외로 많습니다.
이 글은 능동에서 도어락을 설치하기 전에 문 두께, 보조키, 문 종류를 확인하는 방법을 정리했습니다. / 알아 두시면 제품 고르기도 설치 요청도 훨씬 쉬워집니다.
@ 동탄 능동 도어락 설치 전 문 확인

# 제품부터 사기 전에 문을 먼저 보세요
도어락은 문에 맞아야 달 수 있습니다. / 문 두께나 구멍 위치가 다르면 같은 제품이어도 설치가 안 되거나 추가 작업이 필요합니다.
인터넷에서 마음에 드는 제품을 골랐더라도 먼저 문 상태를 확인하세요. / 설치 가능 여부는 전화로 문 사진을 보여 주시면 대부분 알 수 있습니다.

# 확인할 것 한눈에 보기
- 문 두께(문을 열고 옆면 두께 재기)
- 현재 달린 잠금장치 종류(손잡이형, 도어락, 열쇠식)
- 보조키가 있는지, 몇 개인지
- 문 재질(철문, 목문)
- 문틀 쪽 걸쇠 구멍 위치와 크기

# 문 두께는 이렇게 잽니다
문을 열고 문 옆면의 두께를 자로 재면 됩니다. / 문마다 두께가 달라 제품이 맞는 범위가 정해져 있습니다.
두께가 얇거나 두꺼우면 전용 부속이 필요할 수 있습니다. / 숫자를 메모해서 상담할 때 알려주시면 됩니다.
@ 능동 현관문 두께 측정 도어락 설치

# 보조키가 있는지 확인하세요
도어락 위나 아래에 작은 잠금장치가 따로 있다면 보조키입니다. / 보조키는 도어락과 별개로 달려 있어서 같이 교체할지 정해야 합니다.
없는 집도 있고, 두 개 달린 집도 있습니다. / 사진을 찍어 두시면 설명이 쉽습니다.

# 문 재질을 알려주세요
철문과 목문은 구멍을 뚫는 방식과 작업 시간이 다릅니다. / 방화문처럼 두껍고 무거운 문도 따로 확인합니다.
문 안쪽에 철판이 있는지, 단열재가 들어 있는지에 따라 설치 방식이 달라집니다. / 문 종류를 정확히 모르면 사진을 보내 주세요.

# 기존 도어락의 구멍을 그대로 쓸 수 있는지
같은 위치에 새 도어락을 달면 새로 구멍을 뚫지 않아도 되는 경우가 많습니다. / 구멍 위치와 크기가 맞는 제품을 고르면 작업이 간단합니다.
위치가 다르면 문을 가공해야 해서 시간이 더 걸립니다. / 문이 상하는 정도도 달라집니다.
@ 능동 아파트 도어락 설치 전 구멍 위치 확인

# 어떤 제품이 좋은지는 쓰는 사람 따라 다릅니다
아이가 있는 집은 지문이나 카드가 편할 수 있고, 어르신이 계신 집은 큰 번호판이 편합니다. / 가족이 자주 쓰는 방법을 먼저 생각해 보세요.
제품 종류와 선택 요령은 [도어락 설치](doorlock-install.html) 페이지에 정리해 두었습니다. / 이미 사 둔 제품이 있다면 모델명만 알려주세요.

# 사 둔 제품이 있다면
이미 구입한 제품도 설치 가능한지 먼저 확인합니다. / 맞지 않으면 어떤 부속이 필요한지 알려드립니다.
설치만 맡기셔도 되고, 제품 상담부터 맡기셔도 됩니다. / 어느 쪽이든 작업 전에 비용을 먼저 말씀드립니다.

# 전화할 때 알려주시면 좋은 정보
미리 알려주시면 챙겨 갈 부속이 정해집니다.
- 동과 호수, 위치
- 문 두께와 재질, 보조키 유무
- 사 둔 제품 모델명(있다면)
- 바꾸는 것인지 처음 다는 것인지

# 설치 당일 진행 순서
도착해서 문 상태를 확인하고 비용을 먼저 말씀드립니다. / 동의하시면 기존 도어락을 떼고 새 도어락을 답니다.
설치 후에는 잠기고 열리는지, 번호와 카드가 제대로 등록되는지 같이 확인합니다. / 사용법도 간단히 알려드립니다.

# 설치할 때 같이 챙기면 좋은 것
- 새 배터리(새 제품에는 기본 포함인 경우가 많습니다)
- 카드키나 리모컨 여분
- 가족 구성원이 쓸 번호를 미리 정해 두기
작업 전에 번호를 정해 두시면 현장에서 시간을 아낄 수 있습니다. / 처음 쓰는 번호는 너무 단순하지 않게 정하는 것이 좋습니다.

# 문 안쪽 마감과 흠집
도어락을 떼고 나면 기존 구멍 주변에 자국이 남을 수 있습니다. / 새 제품이 이 자국을 덮을 만큼 큰지도 미리 생각해 두면 좋습니다.
문을 다시 칠하거나 보수하는 것까지는 하지 않지만 상태를 보고 알려드립니다. / 눈에 띄는 흠집이 걱정되면 작업 전에 말씀해 주세요.
@ 능동 도어락 설치 후 문 마감 확인

# 설치 후 사용법 확인
설치가 끝나면 번호와 카드를 하나씩 등록하고 열고 닫아 봅니다. / 가족이 모두 쓸 수 있도록 같이 확인합니다.
경고음이 나는 상황과 배터리 교체 방법도 알려드립니다. / 모르는 부분은 그 자리에서 물어보셔도 됩니다.

# 교체와 설치는 다릅니다
처음 다는 것은 새로 구멍을 맞추는 작업이 중심입니다. / 이미 있던 도어락을 바꾸는 것은 기존 구멍을 활용합니다.
바꾸는 경우라면 [도어락 교체](doorlock-replace.html)를 참고해 주세요. / 수리로 해결될 것 같으면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드립니다.

# 능동 말고 화성 어디든
능동 옆 반송동, 청계동, 영천동, 오산동, 목동까지 동탄 전역과 화성 전체를 다닙니다. / 설치 상담도 24시간 전화로 받습니다.
다니는 동네는 [화성시 출장열쇠](hwaseong.html)에 있고, 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 이용 방식은 [이용안내](guide.html)에 적어 두었습니다.

? 문 두께는 어떻게 재나요? | 문을 열고 옆면 두께를 자로 재서 숫자를 알려주시면 됩니다.
? 보조키도 같이 바꿔야 하나요? | 상태를 보고 말씀드립니다. 꼭 같이 바꿀 필요는 없습니다.
? 설치에 시간이 얼마나 걸리나요? | 문과 제품에 따라 다릅니다. 도착해서 문을 본 뒤 말씀드립니다.
? 설치비는 어떻게 안내하나요? | 작업 전에 먼저 말씀드리고 동의를 받은 뒤에 시작합니다.
