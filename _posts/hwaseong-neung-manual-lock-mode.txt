# 능동 현관문, 번호는 맞는데 안 열린다면 수동 잠금부터
능동은 동탄역 생활권으로 오가는 분이 많은 동네이고, 신축 아파트와 상가 주택이 함께 있습니다. / 최신 도어락을 쓰는 집이 많아서 기능 설정 때문에 안 열리는 일도 생깁니다.
번호를 정확히 눌렀는데 삑 소리만 나고 열리지 않는다면 고장이 아니라 수동 잠금 모드가 켜져 있을 수 있습니다. / 외출 중에 가족이 눌렀거나, 아이가 안쪽 버튼을 만지면서 켜지는 경우가 있습니다.
이 글은 능동에서 수동 잠금 모드로 안 열릴 때 확인할 것과 [화성 출장열쇠](hwaseong.html)를 부르는 순서를 정리했습니다.
@ 능동 도어락 수동 잠금 모드 안쪽 버튼

# 수동 잠금 모드란 무엇일까
수동 잠금 모드는 밖에서 번호나 카드로 열리지 않게 막는 기능입니다. / 제조사마다 이름은 다르지만 안쪽에서 켜면 바깥 입력이 막히는 방식은 비슷합니다.
- 안쪽 손잡이 근처 버튼을 눌러 켜는 방식
- 안쪽 잠금 레버나 다이얼을 돌려 켜는 방식
- 번호판에서 특정 번호를 눌러 켜는 방식
- 앱이나 리모컨으로 켜는 방식
집 안에서 잘 때나 아이가 있을 때 쓰라고 만든 기능입니다. / 그런데 밖에서 돌아왔을 때 가족이 안에 없으면 아무도 풀어 줄 수 없습니다.
보통은 안쪽에 있던 사람이 문을 닫고 나가면서 풀지 않은 채 두는 경우가 많습니다. / 한밤에 수동 잠금을 켜고 자다가 아침에 서둘러 나가면서 그대로 두는 일이 대표적입니다.
능동처럼 아이 키우는 가족이 많은 동네에서는 아이가 안쪽 버튼을 장난으로 눌러 켜지는 경우도 흔합니다. / 이런 이유라면 고장이 아니니 도어락을 새로 바꿀 필요는 없습니다.

# 이런 신호가 있으면 수동 잠금을 의심하세요
번호를 눌렀을 때 평소와 다른 소리가 나면 수동 잠금일 가능성이 있습니다.
- 번호가 맞아도 "잠금 상태"라는 안내가 나오는 경우
- 번호판이 켜지는데 모터 소리가 아예 나지 않는 경우
- 손잡이가 위로만 올라가고 문이 안 빠지는 경우
- 평소와 다르게 낮은 경고음이 길게 나는 경우
번호판이 완전히 꺼져 있다면 배터리 문제를 먼저 의심해야 합니다. / 수동 잠금은 번호판이 켜지는 것이 특징입니다.

# 밖에서 해볼 수 있는 해제 방법
먼저 바깥 번호판에서 관리자 번호나 기본 해제 번호를 눌러 보는 방법이 있습니다. / 제품마다 해제 방식이 달라서 설명서를 알고 있다면 그대로 해 보세요.
- 번호판을 한 번 눌러 깨운 뒤 비밀번호 입력
- 등록된 카드나 태그를 가까이 대 보기
- 설명서에 적힌 해제 순서가 있으면 그대로 따라 하기
- 열쇠를 쓰는 제품이면 기계식 열쇠로 열어 보기
설명서가 없으면 제품 이름 스티커를 사진으로 찍어 두세요. / 스티커는 보통 문 안쪽 도어락 본체나 배터리 덮개 근처에 붙어 있습니다. / 전화로 말씀해 주시면 해제 순서를 아는 범위에서 안내드립니다.

# 집 안에 누가 있다면 이렇게 부탁하세요
안에 가족이 있으면 가장 빠른 방법은 안쪽에서 해제해 달라고 하는 것입니다. / 안쪽 버튼이나 레버를 반대로 돌리면 해제되는 제품이 많습니다.
아이나 어르신이라면 전화로 천천히 위치를 알려 주세요. / "손잡이 옆 작은 버튼을 한 번 눌러 봐"처럼 쉬운 말로 알려 주세요.
@ 능동 현관문 안쪽 잠금 레버 해제

# 억지로 번호 입력을 반복하면 생기는 일
수동 잠금 상태에서 번호를 계속 눌러도 열리지 않습니다. / 오히려 여러 번 틀리면 입력이 한동안 막혀 더 오래 기다려야 합니다.
손잡이를 세게 당기면 안쪽 걸쇠나 모터에 무리가 갑니다. / 드라이버로 번호판을 열려고 하면 외관이 상해 나중에 교체 비용이 더 들 수 있습니다.
서너 번 시도해서 안 되면 멈추고 전화 주시는 편이 낫습니다.

# 전화할 때 알려주시면 좋은 정보
수동 잠금 모드인지 고장인지에 따라 챙겨 갈 장비가 달라집니다. / 아래 내용을 알려주시면 도움이 됩니다.
- 번호판이 켜지는지, 불이 들어오는지
- 번호를 눌렀을 때 나는 소리가 어떤지
- 도어락 모양과 제품 이름 스티커 사진
- 집 안에 아이나 반려동물이 있는지
- 능동 어느 방향인지와 몇 층, 몇 호인지
사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다. / 수동 잠금이 켜진 것이 확실하면 해제에 필요한 순서를 미리 확인하고 출발할 수 있습니다.
안쪽 상태를 모르는 경우에는 안에 마지막으로 있던 사람이 누구인지도 알려주세요. / 그 사람이 설정을 만졌는지 알면 원인을 빨리 좁힐 수 있습니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집주인 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
설정만 풀면 되는 경우도 있어 부품 교체 없이 끝나는 일이 많습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 안 상하게 열고 해제까지 해 둡니다
수동 잠금 모드는 도어락을 상하지 않게 여는 방법이 먼저입니다. / 제품 설정을 풀어서 열 수 있으면 문이나 도어락에 손대지 않고 끝납니다.
현관문 개문 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
@ 능동 도어락 설정 해제 후 정상 작동 확인

# 열고 난 뒤 재발 방지 설정
문이 열리면 수동 잠금이 어떻게 켜졌는지 같이 살펴봅니다. / 아이가 만진 것인지, 가족이 실수로 눌렀는지 확인해 알려드립니다.
외출할 때는 수동 잠금을 쓰지 않도록 설정을 안내합니다. / 필요 없는 기능은 꺼 두는 것이 안전합니다.
설정이 자주 꼬이면 [도어락 수리](doorlock-repair.html)로 먼저 점검하고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 능동에서 평소에 해 두면 좋은 습관
- 수동 잠금 기능을 쓰는 가족이 누구인지 정하기
- 외출 전에 안쪽 버튼이 눌려 있지 않은지 확인하기
- 기계식 열쇠를 가방이나 차에 하나 따로 두기
- 설명서나 제품 이름을 사진으로 휴대폰에 저장하기
- 아이가 있는 집은 안쪽 버튼 높이를 확인하기
작은 습관이지만 문 앞에서 막히는 일이 크게 줄어듭니다.

# 능동 말고 화성 어디든 갑니다
능동과 가까운 반송동, 청계동, 영천동도 다닙니다. / 화성 안이면 동네 상관없이 24시간 출동합니다.
화성에서 다니는 동네는 [화성시 출장열쇠](hwaseong.html)에 정리해 두었고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
