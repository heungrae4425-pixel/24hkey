# 아기가 있는 집의 현관은 다릅니다
동탄 능동은 동탄역과 가까운 생활권이라 아기를 키우는 가정도 현관 문제로 연락하시는 경우가 있습니다. / 아기가 태어나면 현관문은 어른만 쓰던 때와 전혀 다른 곳이 됩니다.
유모차를 밀고 나가거나 아기를 안은 채 비밀번호를 누르는 일이 하루에도 몇 번씩 생깁니다. / 그 사이 문이 닫히고 열쇠가 집 안에 있는 상황이 되면 마음이 급해집니다.
이 글은 능동의 신생아, 영유아 가정이 현관을 쓸 때 미리 알아 두면 좋은 점을 정리한 글입니다. / 문이 이미 잠긴 상황이라면 [화성 출장열쇠](hwaseong.html)에서 출동 안내를 먼저 보세요.
@ 능동 영유아 가정 현관 도어락

# 두 손이 바쁜 순간이 가장 위험합니다
아기를 안고 짐까지 든 채 문을 열면 손잡이를 놓치기 쉽습니다. / 이럴 때 문이 닫히며 보조키가 걸리는 일이 의외로 흔합니다.
- 안쪽 보조키는 아기를 안고 나갈 때 걸리지 않게 열어 두기
- 번호를 누르는 동안 짐은 먼저 바닥에 내려 두기
- 문이 자동으로 닫히지 않도록 신발이나 고정 장치로 잠깐 괴기
- 스마트폰과 열쇠는 아기 가방 바깥 주머니에 따로 담기
작은 준비가 문 앞에서의 당황을 많이 줄여 줍니다. / 특히 비 오는 날은 우산 때문에 더 서두르게 되니 한 번 더 확인하세요.

# 아기가 집 안에 있는데 문이 닫혔다면
가장 중요한 것은 아기가 안전한지입니다. / 안에 아기만 혼자 있다면 문 열기가 가장 급한 순서가 됩니다.
먼저 집 안에 아기를 돌볼 수 있는 가족이 있는지, 전화를 받을 수 있는지 확인하세요. / 가족이 있다면 안쪽에서 문을 열 수 있는지 먼저 말해 보세요.
아기가 혼자일 때는 지체하지 말고 바로 연락 주시고 그 상황을 첫마디에 알려 주세요. / 출동 순서를 가장 앞으로 잡고 문 상태를 전화로 함께 살펴보겠습니다.
이 경우 경비실이나 관리사무소에도 알려 두면 도움을 받을 수 있는 경우가 있습니다.

# 문 너머로 아기를 달래는 요령
문이 닫혀 소리가 들리는 상황이라면 계속 말을 걸어 주세요. / 아기가 깨어 있어도 엄마나 아빠 목소리가 들리면 조금 진정됩니다.
문을 두드리거나 손잡이를 세게 흔드는 소리는 아기를 더 놀라게 할 수 있습니다. / 차분하게 이름을 부르며 곧 열린다고 알려 주세요.
아기가 자고 있다면 깨우지 않도록 소리가 작은 방법이 있는지 현장에서 함께 보겠습니다. / 작업 소리는 최대한 줄여서 진행합니다.
@ 동탄 능동 아기 있는 집 문 열기

# 번호판과 소리, 아기 수면 시간에 맞추기
도어락의 열림 소리와 경고음이 크면 아기가 깨는 원인이 됩니다. / 소리 크기를 조절하거나 무음으로 바꿀 수 있는 제품이 많습니다.
다만 완전히 소리를 끄면 배터리가 부족하다는 경고도 못 듣게 됩니다. / 열림 소리만 줄이고 배터리 경고음은 켜 두는 설정이 안전합니다.
설정 방법은 제품마다 다르므로 [도어락 수리](doorlock-repair.html)를 참고하거나 설명서를 먼저 확인해 보세요. / 모르는 상태에서 눌러 보다가 초기화되는 일도 있습니다.

# 보조키와 걸쇠, 아이가 만지지 못하게
아기가 걷기 시작하면 보조키가 눈높이에 들어옵니다. / 호기심에 돌려 잠그거나 열어 버리면 어른이 밖에서 곤란해집니다.
보조키가 손에 닿는 높이라면 쓰지 않는 시간대에는 잠금 상태를 확인하는 습관을 들이세요. / 걸쇠를 아이가 만질 수 있다면 그 자리를 막아 두는 방법도 있습니다.
안쪽 손잡이를 돌려 잠그는 버튼이 있는 도어락은 특히 주의가 필요합니다. / 아이가 놀다가 눌러 문이 잠긴 채 닫히는 일이 생깁니다.

# 능동에서 위치를 알려 주는 방법
능동은 단지가 크고 길이 넓어서 동 번호가 헷갈리는 경우가 있습니다. / 건물 번호, 호수와 함께 동탄역 어느 방향인지 덧붙여 주세요.
- 건물 동, 호수와 단지 입구 방향
- 지금 아기가 안에 있는지 밖에 있는지
- 번호판 상태와 보조키가 걸렸는지
- 집 안에 다른 가족이 있는지
- 유모차나 짐이 문 앞에 있는지
유모차가 문 앞에 있다면 접어서 길을 비워 두시면 작업이 수월합니다. / 아기를 안고 계신다면 가까운 안전한 곳에서 기다리시기를 권합니다.

# 도착하면 먼저 신분 확인
문을 열기 전에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
아기를 안고 계셔서 신분증을 꺼내기 어려우면 사진이나 우편물로 하셔도 됩니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 주세요.
번거롭더라도 모든 분께 같은 기준으로 확인하는 절차입니다.

# 비용은 열기 전에 먼저, 못 열면 받지 않습니다
도어락 종류와 문 상태를 본 뒤 비용을 먼저 말씀드립니다. / 동의하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 부품을 바꿔야 하면 작업 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다. / 아기가 있는 집이라고 달라지는 기준은 없습니다.

# 문을 상하지 않게 조용하게 엽니다
아기가 자고 있을 때는 소리와 진동이 적은 방식이 중요합니다. / 문과 도어락을 상하지 않게 여는 방식은 대체로 조용한 편입니다.
문을 부수거나 큰 힘을 주는 방법은 마지막 수단입니다. / 먼저 [현관문 개문](door-open.html)에 적힌 비파손 방식으로 접근합니다.
작업 중에도 아기가 놀라지 않도록 필요하면 잠시 멈추고 상황을 살핍니다.
@ 능동 조용한 비파손 문 열기

# 열린 뒤에 해 둘 일
문이 열리면 도어락 상태를 점검하고 배터리를 새것으로 바꿉니다. / 배터리가 약해서 소리가 불안정했다면 그 자리에서 바로 해결됩니다.
비밀번호가 너무 단순하거나 가족 외 사람이 알고 있다면 새로 정하는 것도 방법입니다. / 아이가 눌러도 열리지 않도록 번호를 정하는 것도 중요합니다.
도어락이 너무 낡았다면 [도어락 설치](doorlock-install.html)에서 문에 맞는 제품 규격을 살펴보세요. / 아기가 있는 집은 사용이 쉬운 제품을 고르는 편이 편합니다.

# 영유아 가정에서 지키면 좋은 습관
몇 가지 습관만 들여도 문 앞에서 막히는 일이 줄어듭니다.
- 외출할 때 열쇠나 카드를 아기 가방에도 하나 넣어 두기
- 문이 닫히는 속도를 확인하고 너무 빨리 닫히면 점검받기
- 도어락 배터리는 계절이 바뀔 때 한꺼번에 교체
- 번호를 아기에게 가르치지 않고 가족끼리 공유 방법을 정하기
- 주변 이웃이나 가족에게 비상시 연락할 번호 알려 두기
이 중 하나만이라도 오늘 해 두시면 급한 날 도움이 됩니다.

# 능동 밖으로도 화성 전역 출동
능동 옆 반송동, 산척동, 청계동, 영천동, 오산동, 목동, 장지동도 다닙니다. / 병점동, 진안동, 기배동, 새솔동, 봉담읍, 향남읍, 남양읍도 같은 방식으로 갑니다.
[화성시 출장열쇠](hwaseong.html)에 정리해 두었고 다른 지역은 [출장 지역](area.html)에서 확인할 수 있습니다.
