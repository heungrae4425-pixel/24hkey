# 능동에서 현관 앞이 잘 안 보인다면
동탄역 생활권으로 이어지는 능동 쪽 집에서도 현관문에 도어 아이나 초인종 카메라를 쓰는 집이 늘고 있습니다. / 밖에 누가 왔는지 확인하는 작은 장치지만 안 보이면 불안이 커집니다.
도어 아이는 문에 뚫린 작은 구멍에 렌즈를 끼운 것입니다. / 초인종 카메라는 전원과 통신이 필요한 전자 제품이라 원인이 다릅니다.
이 글은 [화성 출장열쇠](hwaseong.html)를 부르기 전에 능동에서 직접 확인할 수 있는 점검 순서를 적었습니다.
@ 능동 현관문 도어 아이 렌즈 점검

# 도어 아이가 뿌옇거나 어두워 보일 때
도어 아이는 렌즈가 여러 장 겹친 구조입니다. / 먼지, 습기, 손자국만으로도 뿌옇게 보일 수 있습니다.
- 바깥쪽 렌즈에 먼지나 얼룩이 앉았는지
- 안쪽 렌즈에 김이 서리거나 습기가 찼는지
- 렌즈가 헐거워져 돌아가거나 빠지지 않았는지
- 문이 처져서 구멍 위치가 어긋났는지
- 렌즈 안쪽에 벌레나 이물질이 들어갔는지
마른 안경 천으로 양쪽 렌즈를 가볍게 닦아 보세요. / 세제나 알코올을 뿌리면 렌즈 코팅이 상할 수 있어 권하지 않습니다.

# 도어 아이가 헐거워졌을 때
렌즈 통이 돌아가거나 덜그럭거리면 고정 나사나 너트가 풀렸을 수 있습니다. / 문 안쪽에서 돌려 조이는 구조가 많습니다.
너무 세게 조이면 렌즈가 깨지거나 문 표면이 눌립니다. / 손으로 살짝 돌려 걸리는 정도에서 멈추세요.
문 두께와 맞지 않는 제품이라면 계속 헐거워질 수 있습니다. / 이때는 규격이 맞는 제품으로 교체하는 것이 낫습니다.
@ 도어 아이 고정 너트를 조이는 작업

# 초인종 카메라가 켜지지 않는다면
전원이 들어오는지부터 확인합니다. / 건전지식은 건전지 상태, 전선식은 전원선이나 변압기 연결을 먼저 봅니다.
건전지 방식이라면 전용 건전지가 방전되었는지, 접점이 깨끗한지 보세요. / 겨울에는 추위로 건전지가 빨리 닳아 반응이 느려지기도 합니다.
전선식이라면 퓨즈나 차단기 문제, 접속부 헐거움이 원인일 수 있습니다. / 전기 배선은 안전을 위해 직접 만지지 말고 전문가에게 맡기세요.

# 카메라는 켜지는데 영상이 끊기거나 연결이 안 될 때
영상이 끊기면 와이파이 신호가 약한 경우가 많습니다. / 공유기와 카메라 사이 거리, 문 재질에 따른 신호 약화를 생각해 볼 수 있습니다.
앱에서 기기를 다시 등록하거나 공유기를 재부팅하면 풀리는 경우도 있습니다. / 이 부분은 제품 설명서나 제조사 안내를 먼저 보는 것이 맞습니다.
도어락과 연동하는 제품이라면 [도어락 알림이 안 올 때](doorlock-repair.html)처럼 연결 설정 점검이 필요할 수 있습니다. / 어떤 제품인지 알려 주시면 확인이 쉽습니다.

# 문과 구멍 위치가 어긋났다면
문이 처지면 도어 아이의 시야가 틀어지거나 렌즈가 문틀에 가려집니다. / 경첩이 헐거워졌거나 문짝이 내려앉은 경우입니다.
이 경우는 도어 아이 문제가 아니라 문 자체의 점검이 필요합니다. / 문이 끝까지 닫히지 않거나 걸쇠가 걸리는 증상이 같이 있는지 확인해 보세요.
경첩 나사를 조이는 것만으로 나아지는 경우도 있습니다. / 심하면 문 높이를 맞추는 작업이 필요합니다.

# 능동 위치는 이렇게 알려주세요
위치와 증상을 알려 주시면 준비가 빨라집니다. / 아래 정보를 함께 말씀해 주세요.
- 건물 종류와 층, 호수
- 도어 아이인지 초인종 카메라인지
- 어떤 증상(뿌옇다, 안 켜진다, 헐겁다, 연결 끊김)
- 제품 모양과 설치된 위치 사진
- 도어락도 함께 이상한지 여부
문 앞 전체와 카메라 부분을 각각 사진으로 보내 주시면 좋습니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문 앞 작업이라도 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
카메라처럼 영상이 오가는 장치는 특히 거주 확인이 중요합니다.

# 비용은 작업 전에 말씀드립니다
문 상태와 장치 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 도어 아이 교체나 설치를 고려할 때
기존 구멍 크기와 문 두께를 먼저 확인해야 합니다. / 맞지 않는 제품을 억지로 끼우면 문에 흠집이 납니다.
시야각이 넓은 제품이나 디지털 방식도 있지만, 문에 맞는지가 먼저입니다. / 현관문 종류와 소방문 여부에 따라 선택이 달라질 수 있습니다.
도어락을 같이 바꿀 계획이라면 [도어락 설치](doorlock-install.html) 때 한 번에 정리하는 방법도 있습니다. / 필요한 것만 하시도록 상태를 보고 말씀드립니다.
@ 새 도어 아이를 문에 설치한 모습

# 현관 앞이 잘 보이는 것과 방범은 조금 다릅니다
도어 아이와 카메라는 누가 왔는지 확인하는 보조 수단입니다. / 문 잠금이 잘 되는지, 문틀이 튼튼한지도 함께 봐야 합니다.
카메라가 있다고 해서 문 열림 걱정이 줄어드는 것은 아닙니다. / 도어락이 부드럽게 잠기고 풀리는지도 같이 점검해 보세요.
불안을 키우기보다 필요한 점검을 차분히 하자는 이야기입니다. / 문이 걱정되면 [도어락 수리](doorlock-repair.html) 안내를 참고하세요.

# 직접 점검 체크리스트
- 렌즈 양쪽을 마른 천으로 닦기
- 도어 아이가 헐거우면 손으로 살짝 조이기
- 카메라 건전지 교체 시기 확인
- 공유기 재부팅 후 앱에서 다시 연결
- 문이 처지거나 안 닫히는지 확인
그래도 이상하면 억지로 분해하지 말고 연락 주세요. / 작은 구멍 하나를 잘못 건드리면 문 표면까지 상할 수 있습니다.
카메라 앱의 알림이 갑자기 오지 않는 경우 휴대폰의 알림 허용 설정도 한 번 보세요. / 앱을 업데이트한 뒤 설정이 바뀌는 일이 있습니다.
도어 아이 구멍으로 밖이 안 보이는 대신 스티커나 가림막을 붙여 둔 집도 있습니다. / 필요할 때만 가리는 방식이라면 가림막이 헐거워지지 않았는지 보세요.
렌즈를 닦은 뒤에도 가장자리가 어둡다면 렌즈 자체가 오래된 것일 수 있습니다. / 이럴 때는 교체가 닦는 것보다 빠릅니다.

# 능동 말고 화성 어디든 갑니다
능동 옆 동탄 쪽 생활권, 병점동, 봉담읍, 향남읍까지 화성 안이면 24시간 출동합니다. / 거리에 따라 도착 시간이 달라 위치를 먼저 알려 주세요.
다니는 동네는 [화성시 출장열쇠](hwaseong.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
