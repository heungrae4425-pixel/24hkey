# 오산동 도어락 외관 흠집과 타공 자국이 신경 쓰일 때
오산동은 병점역과 동탄역 쪽으로 오가며 사는 분들이 많은 동네입니다. / 도어락을 오래 쓰다 보면 외관 흠집이 생기고, 교체할 때는 문에 남은 구멍 자국이 눈에 걸립니다.
문이 열리고 잠기는 데는 문제가 없는데 번호판 주변에 긁힌 자국이 많으면 보기에 아쉽습니다. / 새 제품으로 바꿨는데 이전 제품 구멍이 보이면 더 신경 쓰입니다.
이 글은 도어락 외관 흠집을 줄이는 법과 교체할 때 남는 타공 자국을 어떻게 처리하는지 정리했습니다. / [화성 출장열쇠](hwaseong.html)에 문의하실 때 도움이 될 내용입니다.
@ 오산동 도어락 외관 흠집 확인

# 도어락 외관이 흠집 나는 흔한 이유
- 열쇠나 카드를 꽂다가 긁힌 경우
- 이삿짐이나 택배 상자에 부딪힌 경우
- 급하게 열려다 드라이버로 문틈을 벌린 경우
- 오래 쓰며 번호판 코팅이 닳은 경우
- 청소 중 거친 수세미로 닦은 경우
외관 흠집은 대부분 사용 중에 서서히 생기는 것입니다. / 작동에는 문제가 없는 경우가 많아서 기능과 외관을 따로 보셔야 합니다.

# 외관 흠집이 기능에 영향을 주는지 보는 법
번호판 주변이 긁혔더라도 버튼이 잘 눌리고 소리가 정상이면 기능은 괜찮은 경우가 많습니다. / 반대로 버튼이 눌리지 않거나 잘 안 돌아가면 내부를 점검해야 합니다.
- 버튼을 눌렀을 때 소리가 나는지
- 손잡이가 부드럽게 도는지
- 문이 닫힐 때 걸쇠가 자연스럽게 들어가는지
- 물이 스며든 흔적이 있는지
이 네 가지가 모두 정상이라면 흠집만 가리는 쪽으로 생각하셔도 됩니다.

# 흠집을 키우지 않는 청소법
도어락 표면은 부드러운 마른 천이나 살짝 적신 천으로 닦으세요. / 알코올이나 유기용제는 코팅을 벗길 수 있으니 조심해야 합니다.
거친 수세미나 연마제는 잔 흠집을 더 만들 수 있어서 피하는 게 좋습니다. / 번호판 사이에 낀 먼지는 부드러운 붓이나 면봉으로 털어내세요.
물이 많이 닿으면 안으로 스며들 수 있어서 물을 뿌려 닦지 마세요.
@ 도어락 번호판 부드러운 천 청소

# 도어락 교체하면 남는 타공 자국
도어락을 새것으로 교체하면 문에 뚫린 구멍이 이전 제품과 다를 수 있습니다. / 새 도어락 크기가 작아지면 이전 제품이 있던 자리가 그대로 드러납니다.
문에 보조키 자리나 이전 손잡이 구멍이 남아 있으면 새 제품으로 가려지지 않는 경우도 있습니다. / 이럴 때 교체 전에 어떤 자국이 남을지 미리 말씀드립니다.
새 제품이 이전 구멍 크기를 모두 덮는지가 제품을 고르는 기준이 될 수도 있습니다.

# 타공 자국을 가리는 방법
- 이전 제품보다 큰 몸체의 도어락을 고르는 방법
- 구멍에 맞는 커버나 마감 덮개를 쓰는 방법
- 문 색상에 맞는 마감 스티커나 필름으로 정리하는 방법
- 열린 구멍 위에 보조 플레이트를 덧대는 방법
문 재질이나 색에 따라 어울리는 방법이 다릅니다. / 현장에서 문 상태를 보고 가장 자연스러운 방법을 말씀드립니다.
문 자체를 새로 도장하거나 교체해야 하는 경우는 도어락 작업 범위를 넘으니 따로 안내드립니다.

# 교체 전에 확인하는 문 두께와 보조키
도어락을 바꾸기 전에 문 두께와 보조키 위치를 확인합니다. / 이 두 가지가 맞지 않으면 새 제품이 달리지 않거나 구멍이 더 생길 수 있습니다.
- 문 두께와 속 재질
- 이전 도어락의 구멍 위치와 크기
- 보조키 사용 여부
- 문 안쪽 마감 상태
사진을 문자로 보내주시면 사전에 어떤 자국이 남을지 어느 정도 말씀드릴 수 있습니다. / 교체가 꼭 필요한지도 함께 봅니다.
@ 도어락 교체 전 문 두께와 구멍 확인

# 흠집만 있다면 교체는 권하지 않습니다
도어락이 정상 작동하는데 외관만 긁혔다면 교체는 권하지 않습니다. / 기능이 멀쩡한 제품을 바꾸면 그만큼 새 구멍과 마감 문제가 생길 수 있습니다.
외관만 신경 쓰이는 정도라면 마감 덮개나 스티커로 정리하는 쪽이 부담이 적습니다. / 고장이 잦거나 부품이 낡았을 때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
고쳐서 쓸 수 있는 경우는 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.

# 문을 열 때 외관이 상하지 않게
문이 안 열려 출장을 부를 때는 외관이 더 상하지 않는지도 걱정되실 겁니다. / 덜 상하는 방법부터 차례로 해보는 것이 저희 기본입니다.
드라이버나 지렛대 없이 도어락과 문틀 표면이 남도록 작업하는 것을 먼저 생각합니다. / 작업 전에 어떤 방법으로 열지, 외관에 영향이 있을지도 미리 말씀드립니다.
[현관문 개문](door-open.html) 페이지에 방법을 자세히 적어 두었습니다.

오산동에서 전화하실 때는 동, 호수와 가까운 큰길을 말씀해 주시면 됩니다.
- 외관 흠집이 있는 부분 사진
- 교체를 고민하는지, 외관 마감 위주인지
- 도어락 모양과 번호판 상태
- 이전 제품의 구멍 자국이 있는지
사진 한두 장이 있으면 전화 상담이 훨씬 구체적으로 가능합니다. / 흠집이 난 부위를 가까이서 한 장, 문 전체가 보이게 한 장이면 충분합니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문 관련 작업이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 가족 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

# 비용은 문 열기 전에 말씀드립니다
외관 마감이든 교체든 비용은 작업 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 작업 후에 말없이 붙는 비용도 없습니다.
부품이나 마감재를 추가해야 하면 하기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 오래 깔끔하게 쓰는 관리 습관
- 열쇠나 카드를 꽂을 때 구멍 방향 확인
- 짐을 들 때 도어락 쪽을 벽처럼 쓰지 않기
- 정기적으로 부드러운 천으로 먼지 닦기
- 번호판 사이에 이물질이 끼면 바로 털기
- 교체 때 문 구멍 크기와 새 제품 크기 확인
작은 습관만으로도 외관 흠집을 많이 줄일 수 있습니다. / 이삿날에는 도어락 주변에 보양 테이프를 붙여 두는 것도 방법입니다.
흠집이 이미 났더라도 깊지 않으면 마감 필름이나 덮개로 충분히 눈에 덜 띄게 할 수 있습니다. / 먼저 사진을 보내주시면 그 정도인지 같이 봅니다.

# 오산동 말고 화성 어디든 갑니다
오산동 가까운 병점, 반송동, 능동, 청계동은 물론 봉담, 향남까지 화성 안이면 24시간 출동합니다. / [화성시 출장열쇠](hwaseong.html) 페이지에 다니는 동네를 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
