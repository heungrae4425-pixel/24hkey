# 밤 열한 시, 아이가 문 앞에서 전화를 겁니다
학원이나 독서실에서 늦게 돌아오는 아이가 현관 앞에서 전화를 걸어 옵니다. / 번호가 안 맞는다고 하거나, 문이 열리지 않는다고 합니다.
부모는 직장에 있거나 잠깐 외출 중이라 바로 달려갈 수 없는 경우도 많습니다. / 동탄 오산동은 동탄역과 학원가를 오가며 생활하는 가정이 많은 곳이라 이런 상황이 낯설지 않습니다.
이 글은 수험생이나 학원에 다니는 자녀가 늦게 귀가할 때 문 때문에 막히지 않도록 미리 해둘 일과, 막혔을 때 부모가 할 일을 적었습니다. / 도움이 필요하면 [화성 출장열쇠](hwaseong.html)로 연락하실 수 있습니다.
@ 오산동 늦은 밤 귀가한 학생이 서 있는 현관문

# 시험을 앞두고 문이 가장 큰 변수가 되는 이유
시험이 가까운 시기에는 아이의 컨디션이 중요합니다. / 문이 안 열려 밖에서 오래 기다리면 피로와 불안이 한꺼번에 쌓입니다.
작은 일이지만 수면 시간을 깎고 다음 날 공부에 영향을 줄 수 있습니다. / 그래서 이 시기에는 도어락을 한 번 더 살펴 두는 것이 좋습니다.
부모가 먼저 챙기면 아이가 문 걱정을 하지 않고 공부에 집중할 수 있습니다.
특히 기말이나 모의고사, 입시 일정이 몰린 시기에는 귀가 시간이 불규칙해집니다. / 평소보다 늦게 들어오는 날이 많아지는 만큼 문 앞에서 쓰는 시간이 곧 잠자는 시간입니다.

# 귀가 전에 부모가 먼저 확인할 것
저녁 일찍 시간을 내어 아래를 살펴보세요.
- 도어락 건전지를 전부 새것으로 바꿨는지
- 아이가 쓰는 번호나 카드키가 잘 등록되어 있는지
- 번호판이 어두운 밤에도 잘 보이는지
- 비상 단자 위치를 아이도 알고 있는지
- 부모가 연락이 안 될 때 연락할 사람이 정해져 있는지
이 다섯 가지가 해결되면 대부분의 상황은 문 앞에서 끝납니다.
점검은 아이와 같이 하면 더 좋습니다. / 직접 눌러 보고 소리를 들어 보면 평소와 다른 점을 아이가 먼저 알려 주기도 합니다.

# 번호는 아이가 쉽게 외울 수 있게
생일이나 전화번호 뒷자리처럼 남이 짐작하기 쉬운 번호는 피하는 것이 좋습니다. / 대신 가족만 아는 규칙을 하나 정하면 외우기도 쉽습니다.
너무 복잡한 번호는 피곤한 밤에 틀리기 쉽습니다. / 적당히 외우기 쉽고 남이 추측하기 어려운 정도가 알맞습니다.
번호를 바꿨다면 아이에게 바로 알리고 직접 눌러 보게 하세요. / 알려 놓고도 한 번 확인하지 않아 문 앞에서 틀리는 경우가 있습니다.
@ 도어락 번호를 가족과 함께 확인하는 모습

# 카드키와 열쇠는 두 곳에 나눠 보관
번호를 잊거나 배터리가 꺼질 때를 대비해 두 번째 수단을 마련해 두세요. / 카드키나 보조 열쇠를 아이 가방 안쪽 주머니에 넣어 두는 방법이 있습니다.
다만 학교나 학원에서 잃어버릴 수 있으니 하나만 믿지 마시고, 믿을 만한 이웃이나 가족에게 하나를 맡겨 두면 좋습니다.
학교 사물함이나 학원 가방에 카드키를 넣고 다니다 잃어버리는 일이 가장 흔합니다. / 잃어버린 사실을 알면 바로 부모에게 알리도록 평소에 말해 두세요.
카드키를 잃어버렸다면 바로 등록을 지워야 합니다. / 방법은 [도어락 설치](doorlock-install.html) 정보에 정리해 두었습니다.

# 문이 안 열릴 때 아이에게 알려줄 순서
아이가 전화로 알려 오면 부모가 차분하게 안내해 주세요.
- 번호판에 불이 들어오는지 먼저 확인하기
- 천천히 번호를 한 번 더 눌러 보기
- 안 되면 문을 억지로 당기거나 두드리지 말고 부모에게 전화하기
- 건물 로비처럼 따뜻하고 안전한 곳에서 기다리기
부모의 목소리가 차분하면 아이도 안정됩니다. / 아이가 이미 지친 상태라면 혼내기보다 먼저 안심시켜 주세요. / 급한 상황에서도 순서대로 하나씩 말해 주세요.

# 밤길 안전도 같이 생각하세요
늦은 시간에 어린 학생이 혼자 낯선 사람을 기다리는 일은 부모로서 신경이 쓰입니다. / 가능하면 아이는 건물 안 안전한 곳이나 이웃집에서 기다리게 하세요.
출장 기사가 도착할 때는 부모나 어른이 함께 있는 것이 좋습니다. / 부모가 멀리 있다면 전화로 기사와 통화해 상황을 확인해 두세요.
확인이 끝나기 전에는 아이 혼자 낯선 사람에게 문을 열어 주지 않도록 일러 주세요.

# 부모가 멀리 있을 때의 연락 방법
부모가 직장이나 출장 중이라 바로 못 간다면 전화로 접수하셔도 됩니다. / 이때는 아이의 위치, 문 상태, 부모와 아이의 관계를 알려 주세요.
거주자가 맞는지는 신분증, 주소가 나온 우편물, 관리사무소 확인 같은 방법으로 확인합니다. / 아이에게 신분증이 없으면 부모가 전화로 확인하고 관리사무소의 도움을 받는 방법이 있습니다.
성인 거주자의 확인 없이는 작업이 어려울 수 있는 점은 양해 부탁드립니다. / 집을 지키기 위한 절차입니다.

# 비용과 진행은 문을 열기 전에 설명합니다
도착하면 문 상태를 보고 비용을 먼저 말씀드립니다. / 부모나 보호자가 동의하셔야 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 슬그머니 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에서 보실 수 있습니다.
@ 도어락을 상하지 않게 점검하는 출장 기사

# 열고 나서 같이 확인하는 것
문이 열리면 도어락이 다시 잘 작동하는지 확인합니다. / 아이가 쓰는 번호나 카드키가 제대로 등록돼 있는지도 같이 봅니다.
배터리가 원인이었다면 새것으로 교체하고 교체 시기를 알려 드립니다. / 방법은 [현관문 개문](door-open.html)과 함께 안내해 드립니다.
아이에게도 문이 열리는 모습을 보여 주면 다음에 같은 일이 생겼을 때 덜 놀랍니다.

# 자주 막히는 이유를 미리 피하는 방법
- 번호를 바꾼 뒤 아이에게 알리지 않은 경우
- 겨울철 번호판에 결로가 생긴 경우
- 카드키를 잃어버린 경우
- 문이 덜 닫혀 자동 잠금이 걸린 경우
- 배터리 경고음을 무시하고 며칠 지난 경우
이 중 다수가 미리 확인하면 피할 수 있습니다. / 한 번만 같이 점검해 두면 한 학기 동안 마음이 편합니다.

# 수험생 가정이 도어락을 오래 쓰는 법
시험이 끝난 뒤에도 도어락 관리는 계속됩니다. / 고장이 잦거나 오래된 제품이라면 [도어락 교체](doorlock-replace.html)를 고려해 볼 수 있습니다.
다만 고쳐서 쓸 수 있으면 교체를 먼저 권하지 않습니다. / 점검 결과를 보고 판단하시면 됩니다.
귀가 시간이 불규칙한 가정일수록 현관 불빛이나 번호판 밝기도 점검할 만합니다. / 어두운 밤에 번호가 잘 안 보이면 오입력이 늘기 때문입니다.
시험 기간만이라도 비상 연락처와 열쇠 보관처를 가족이 함께 알고 있으면 충분히 든든합니다.

# 오산동 말고 동탄과 화성 전역
오산동과 가까운 반송동, 능동, 청계동, 영천동, 목동, 산척동, 장지동도 다닙니다. / 병점동, 진안동, 봉담읍, 향남읍, 남양읍까지 화성 전체를 24시간 돌고 있습니다.
다니는 동네는 [출장 지역](area.html)에서 확인하실 수 있습니다.
