# 새솔동 현관에서 지문이 갑자기 안 읽힐 때
새솔동은 봉담 생활권으로 오가는 분들이 많은 동네입니다. / 아이를 데리러 갔다 오거나 장을 보고 들어올 때 손이 젖은 채 현관에 서는 일이 잦습니다.
어제까지 잘 되던 지문이 오늘은 계속 실패하면 도어락이 고장 난 줄 알고 놀랍니다. / 하지만 대부분은 손 상태가 달라서 생기는 일입니다.
이 글은 손이 젖었거나 건조할 때 지문이 안 읽히는 이유와 문 앞에서 해볼 수 있는 방법을 정리했습니다.
@ 새솔동 현관 지문 인식 손 상태

# 지문 센서는 어떻게 읽을까요
센서 크기가 작은 제품은 손가락 끝만 닿아도 되지만 가운데가 닿지 않으면 읽지 못합니다. / 처음 등록할 때 손가락을 어떻게 얹었는지도 영향을 줍니다.
센서는 손가락 끝 피부의 미세한 굴곡을 읽습니다. / 지문의 골과 마루가 또렷하게 닿아야 정확하게 인식됩니다.
광학식은 빛으로, 반도체식은 전기 신호로 지문을 읽는 방식입니다. / 두 방식 모두 손가락 표면 상태에 영향을 받습니다.
손이 젖으면 골에 물이 차서 마루와 구분이 흐려집니다. / 너무 마르면 피부가 센서에 밀착하지 못해 신호가 약해집니다.

# 손이 젖었을 때 생기는 증상
물기가 있으면 센서가 지문 모양을 번져서 읽습니다. / 그래서 등록된 지문과 비교하면 일치율이 떨어집니다.
- 손을 씻은 직후나 비 오는 날에 유난히 실패함
- 땀이 많은 여름에 오전보다 오후에 더 안 됨
- 센서에 물기가 남아 얼룩이 보임
이럴 때는 손과 센서 모두를 마른 수건으로 닦아 주세요. / 한 번 닦고 나서 손가락을 평평하게 대면 대개 열립니다.

# 손이 건조할 때는 반대로 막힙니다
환절기에는 갑자기 피부가 건조해져 평소 잘 되던 지문이 안 되는 일도 있습니다. / 이 시기에는 보조 수단인 번호를 같이 익혀 두세요.
겨울이나 난방이 센 집에서는 손끝이 말라 갈라집니다. / 피부가 거칠어지면 센서에 닿는 면적이 줄어듭니다.
설거지와 청소를 자주 하는 손, 종이를 많이 만지는 손도 지문이 흐려질 수 있습니다. / 이런 경우에는 지문 자체가 평소와 조금 달라져 있습니다.
핸드크림을 바른 직후에도 센서가 미끄러워 읽지 못합니다. / 바르고 잠시 지난 뒤에 대 보시는 게 좋습니다.
@ 새솔동 건조한 손끝과 센서 접촉

# 문 앞에서 바로 해볼 수 있는 방법
당황하지 말고 순서대로 해보세요.
1. 손가락을 닦아 물기와 크림을 없앤다
2. 센서 표면을 마른 천으로 가볍게 닦는다
3. 손가락 한가운데를 센서에 평평하게 얹는다
4. 너무 세게 누르거나 문지르지 말고 잠시 가만히 둔다
5. 안 되면 다른 손가락이나 등록해 둔 다른 지문으로 시도한다
센서 위치를 알면 손끝의 중심이 닿도록 맞추기 쉽습니다. / 손가락을 비스듬히 대면 잘 읽히지 않습니다.

# 지문이 안 될 때를 위한 보조 수단
여러 번 틀렸다고 도어락이 한동안 입력을 막는 경우도 있습니다. / 서너 번 시도해도 안 되면 잠시 멈추고 다른 수단으로 바꿔 보세요.
지문만 쓰는 도어락은 많지 않고 보통 번호나 카드, 비상 열쇠 구멍이 함께 있습니다. / 지문이 안 되면 번호부터 눌러 보세요.
번호가 기억나지 않을 때를 대비해 가족에게 번호를 알려두는 것이 좋습니다. / 지문만 믿으면 이런 날 문 앞에서 막힙니다.
배터리가 약할 때도 지문 센서가 먼저 불안정해집니다. / 번호판 불빛이 어둡거나 경고음이 나면 건전지 교체를 같이 보셔야 합니다.

# 센서 자체에 문제가 있는 경우
센서가 상했는지는 다른 가족의 지문도 같이 안 되는지로 가늠할 수 있습니다. / 한 사람만 안 된다면 손 상태나 등록 문제일 가능성이 큽니다.
손을 잘 닦고 몇 번 시도해도 계속 실패한다면 센서를 의심합니다. / 오염이 쌓였거나 긁힘, 습기 침투가 원인일 수 있습니다.
- 센서 표면에 기름때나 먼지가 두껍게 낌
- 손가락을 대도 아무 반응이 없음
- 일부 가족 지문만 인식되고 나머지는 안 됨
센서를 알코올이나 거친 도구로 닦지 마세요. / 코팅이 벗겨지면 오히려 더 안 읽힙니다.

# 지문을 다시 등록하면 좋아집니다
오래전에 등록한 지문은 손이 변하면서 일치율이 떨어질 수 있습니다. / 아이의 손은 자라면서 크기가 달라져 다시 등록해야 합니다.
같은 손가락을 두세 번 각도를 조금씩 바꿔 등록하면 인식이 좋아집니다. / 젖은 손과 마른 손을 모두 고려해 여러 손가락을 등록하는 것도 방법입니다.
등록은 도어락 안쪽 버튼으로 진행하는 제품이 많습니다. / 방법을 모르겠으면 전화로 안내해 드리거나 방문해 같이 해드립니다.

# 새솔동에서 전화하실 때 알려주세요
봉담 쪽 생활권에서 퇴근 시간대에 연락이 몰릴 때도 있습니다. / 상황을 짧게 말씀해 주시면 순서를 잡아 드립니다.
- 지문이 안 되는 사람이 한 명인지 전원인지
- 번호나 카드로는 열리는지
- 번호판 불빛과 경고음 상태
- 도어락 모델이나 앞면 사진
- 집 안에 아이나 반려동물이 있는지
봉담 쪽에서 오시는 중이라면 그것도 말씀해 주세요. / 도착 예상 시간을 맞추는 데 도움이 됩니다.

# 신분 확인을 거친 뒤 비용을 먼저 말씀드립니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
확인이 끝나면 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 말없이 붙는 비용도 없습니다.
이용 방법은 [이용안내](guide.html)에 적어 두었습니다.

# 열린 뒤 센서와 등록을 점검합니다
문이 열리면 센서를 닦고 등록된 지문을 한 번씩 다시 대 봅니다. / 인식이 약한 지문은 지우고 새로 등록하시길 권합니다.
센서 불량이 확인되면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
문 여는 과정은 [현관문 개문](door-open.html)에 적어 두었습니다.
@ 새솔동 지문 센서 청소와 재등록

# 평소 지문 인식률 높이는 습관
운동 후나 목욕 직후처럼 손이 달라진 상태에서는 잠시 기다렸다 대 보세요. / 손이 안정되면 대개 바로 읽힙니다.
- 손을 닦은 뒤 잠깐 말리고 센서에 대기
- 센서 표면을 주 1회 마른 천으로 닦기
- 겨울에는 핸드크림을 바른 뒤 시간이 지나고 사용
- 가족 구성원마다 여러 손가락 등록
- 번호나 열쇠 같은 대체 수단 항상 기억
습관 몇 가지로 문 앞에서 막히는 일이 크게 줄어듭니다.

# 새솔동 말고 화성 어디든 갑니다
새솔동 가까운 봉담읍은 물론 동탄, 병점, 향남까지 다닙니다. / 다니는 곳은 [화성시 출장열쇠](hwaseong.html) 페이지에 정리해 두었습니다.
다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
