# 휴가 마지막 날 가장 먼저 만나는 문
새솔동에서 며칠씩 집을 비우고 돌아오는 날, 현관 앞에서 도어락이 반응하지 않으면 피로가 한꺼번에 몰려옵니다. / 공항이나 터미널에서 동탄역 쪽으로 돌아와 짐을 든 채 서 있는 상황이라면 더 막막합니다.
이 글은 여름휴가 같은 장기 부재 뒤에 문이 안 열릴 때의 원인과 확인 순서를 정리했습니다. / 직접 해볼 수 있는 것부터, [화성 출장열쇠](hwaseong.html)를 부르는 때까지 이어서 적었습니다.
@ 새솔동 휴가 후 현관문 앞

# 집을 비운 동안 도어락에 생기는 일
도어락은 사람이 없어도 대기 상태로 조금씩 전기를 씁니다. / 며칠이 아니라 몇 주를 비워 두면 배터리가 바닥나는 일이 생깁니다.
여름 열기와 습기 역시 번호판이나 내부 부품에 영향을 줄 수 있습니다. / 비어 있는 집은 환기가 안 돼 문 주변에 습기가 고이기도 합니다.
출발할 때는 멀쩡했는데 돌아오니 안 열리는 이유는 대부분 이런 누적된 영향 때문입니다.
특히 장마철이 낀 휴가였다면 습기의 영향이 더 클 수 있습니다. / 번호판 주변에 물기가 맺혔는지 가볍게 살펴보세요.
집을 비운 동안 택배나 광고지가 문 앞에 쌓여 있다면 문 상태와 무관한 것은 아닙니다. / 문 주변이 어떻게 변했는지 눈여겨보는 것도 원인을 찾는 단서가 됩니다.

# 확인 첫째, 번호판에 불이 들어오는지
번호판을 손바닥으로 한 번 덮었다 떼 보세요. / 불이 들어오면 전원은 살아 있다는 뜻입니다.
아무 반응이 없다면 배터리 방전 가능성이 큽니다. / 이때는 비상 전원 단자가 있는지 도어락 아래쪽을 살펴보세요.
소리는 나는데 안 열리면 배터리가 약해 모터가 힘을 못 쓰는 상태일 수 있습니다. / 번호가 맞는지도 한 번 더 천천히 눌러 보세요.

# 확인 둘째, 9V 건전지로 비상 전원 대기
많은 도어락은 바깥쪽 아래에 9V 건전지를 대는 비상 단자가 있습니다. / 건전지를 대고 있는 동안만 전원이 들어옵니다.
건전지 접점을 단자에 정확히 맞추고, 대고 있는 채 번호를 누르세요. / 휴가 중이라 건전지가 없다면 근처 편의점에서 구할 수 있는지 알아보세요.
열리면 바로 안쪽 배터리를 모두 새것으로 바꿔 주세요. / 일부만 바꾸면 며칠 안에 또 같은 일이 생깁니다.
@ 도어락 비상 단자에 건전지를 대는 모습

# 확인 셋째, 문이 뻑뻑한 경우
번호는 맞는데 문이 열리지 않을 때는 걸쇠가 문틀에 걸려 있을 수 있습니다. / 여름 습기에 문이 부풀거나 문틀이 미세하게 틀어졌을 수 있습니다.
문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 걸림이 풀려 열리는 일이 있습니다.
반대로 당기면서 돌리는 것이 맞을 때도 있으니 두 방향 모두 가볍게 시도해 보세요. / 세게 힘주는 것은 금물입니다.

# 안쪽 보조키나 걸쇠를 잠그고 나갔을 수 있습니다
출발 전 안쪽 보조키를 돌려 놓고 나간 경우도 있습니다. / 안쪽 상태는 밖에서 확인할 수 없어서 번호가 맞아도 문이 안 열립니다.
출발 때 서두르다 무심코 잠그는 일은 생각보다 흔합니다. / 같이 사는 가족이 나중에 나갔다면 그분이 잠갔을 수도 있습니다.
이 경우에는 번호로 아무리 눌러도 해결되지 않으니 억지로 시도하지 마세요.

# 비밀번호가 기억나지 않을 때
오랜만에 돌아오면 평소 쓰던 번호가 갑자기 생각나지 않기도 합니다. / 가족이 바꿔 놓았는데 전달받지 못한 경우도 있습니다.
먼저 가족에게 연락해 최근에 번호를 바꿨는지 확인하세요. / 틀린 번호를 반복해서 누르면 도어락이 입력을 잠시 막습니다.
서너 번 해 보고 안 되면 멈추고 연락 주세요. / 확인 후 안전하게 여는 방법을 안내합니다.

# 하지 말아야 할 행동
- 문 틈에 카드나 드라이버를 넣어 억지로 벌리기
- 도어락을 분해하거나 배터리 칸을 억지로 열기
- 손잡이를 세게 비틀거나 문을 발로 차기
- 번호를 계속 반복 입력해 잠금 상태로 만들기
짐이 많은 날 짜증이 나는 마음은 이해하지만, 이런 행동은 문제를 더 키웁니다. / 잠깐 앉아서 숨을 돌리고 순서대로 해 보세요.

# 전화하실 때 알려주시면 좋은 것
새솔동에서 연락 주시면 아래 내용을 알려주세요. / 상황을 알면 맞는 준비를 해서 갑니다.
- 아파트 동·호수와 가까운 큰길
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 비상 건전지를 대 봤는지와 결과
- 몇 박을 비웠는지, 비운 사이 누가 드나들었는지
- 집 안에 반려동물이나 화분 같은 급한 것이 있는지
식물이나 반려동물이 안에 있는 경우에는 꼭 먼저 말씀해 주세요. / 순서를 조절하는 데 도움이 됩니다.

문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
짐 속에 신분증이 있다면 미리 꺼내 두시면 빠릅니다. / 휴가 중 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 손대기 전에 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html)에 정리했습니다.
@ 휴가 후 도어락 상태를 확인하는 모습

# 열고 난 뒤 점검할 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 확인합니다. / 배터리가 원인이었다면 새 배터리로 교체한 뒤 경고음이 사라졌는지도 봅니다.
습기 흔적이 있다면 번호판과 문틈을 마른 천으로 닦고 환기를 시켜 주세요. / 반복되면 [도어락 수리](doorlock-repair.html)로 먼저 점검하는 편이 낫습니다.
너무 오래돼 계속 문제를 일으킨다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 휴가 가기 전에 해 둘 일
- 출발 전에 배터리 경고음이 나지 않았는지 확인
- 안쪽 보조키는 잠그지 않았는지 마지막에 점검
- 비밀번호를 가족 모두가 알고 있는지 확인
- 비상용 9V 건전지를 가방에 한 개 넣어 두기
- 오래 비울 땐 믿을 만한 가족에게 상황을 알려 두기
출발 전 1분 점검이 돌아오는 날의 30분을 지켜 줍니다. / 특히 비상용 건전지는 가방 속에 넣어 두면 든든합니다.
돌아오는 날 도착 시간을 가족에게 미리 알려 두면 문제가 생겨도 도움을 청하기 쉽습니다. / 집 열쇠나 카드키를 가진 가족이 가까이 있는지도 확인해 보세요.

# 새솔동 말고 화성 어디든 갑니다
새솔동 주변 반송동, 능동, 청계동, 영천동, 병점동은 물론 봉담읍, 향남읍까지 다닙니다. / 화성 안이면 24시간 출동합니다.
다니는 동네는 [화성시 출장열쇠](hwaseong.html)에서 보실 수 있고, 다른 지역은 [출장 지역](area.html)에서 확인하세요.
