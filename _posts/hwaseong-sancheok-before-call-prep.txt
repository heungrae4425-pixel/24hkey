# 전화하기 전에 1분만 준비하면 달라집니다
화성 동탄 산척동은 새로 지은 건물과 주택이 섞여 있어 위치를 설명하기가 의외로 어려운 동네입니다. / 급한 마음에 전화를 걸면 무엇부터 말해야 할지 머릿속이 하얘지는 경우가 많습니다.
이 글은 산척동에서 출장열쇠를 부르기 전에 미리 준비해 두면 좋은 것들을 순서대로 정리했습니다. / 준비물은 많지 않고, 대부분 휴대폰으로 바로 해결됩니다.
문 앞에서 이미 시간이 많이 지났다면 4번과 5번만 먼저 보셔도 됩니다. / 위치와 도어락 상태만 알려 주셔도 출동 여부를 바로 말씀드릴 수 있습니다.
@ 화성 동탄 산척동 출장열쇠 부르기 전 준비

# 먼저 안전을 확인합니다
문이 안 열리는 상황에서 가장 먼저 봐야 할 것은 집 안에 사람이 갇혀 있지 않은지입니다. / 아이나 몸이 불편한 가족, 반려동물이 안에 있다면 바로 말씀해 주세요.
가스불을 켜 두고 나왔거나 안에서 위험한 상황이 있을 때는 열쇠집보다 119가 먼저입니다. / 안전에 문제가 없다고 판단되면 그다음 순서로 출장을 부르시면 됩니다.
급한 상황일수록 전화에서 이 부분을 먼저 말씀해 주시면 출동을 앞당길 수 있습니다. / 저희가 순서를 정리해서 안내해 드립니다.

# 지금 있는 위치를 정확하게 정리합니다
산척동은 비슷한 모양의 건물이 줄지어 있어 위치 설명이 가장 중요합니다. / 건물 이름이나 도로 이름, 눈에 띄는 가게를 하나 정해 두세요.
휴대폰 지도 앱에서 현재 위치를 공유하면 가장 빠릅니다. / 문자로 위치 링크를 보내 주시면 도착 시간을 더 정확하게 말씀드릴 수 있습니다.
동과 호수, 몇 층인지도 같이 적어 두세요. / 엘리베이터가 없는 건물이면 계단으로 가야 해서 미리 알려 주시면 준비해서 갑니다.

# 도어락 사진을 한 장 찍어 둡니다
출장을 부르기 전에 도어락 앞면과 손잡이 쪽을 휴대폰으로 찍어 두세요. / 제조사나 모양, 손잡이 형태만 알아도 챙겨 갈 장비를 고르기 좋습니다.
번호판이 켜지는지 꺼져 있는지도 같이 확인합니다. / 어떤 소리가 나는지, 경고음이 나는지도 기억해 두세요.
사진은 문자로 보내 주시면 전화 설명이 훨씬 짧아집니다. / 어려우시면 말로만 설명해 주셔도 괜찮으니 무리하지 마세요.
@ 산척동 도어락 사진 상태 확인

# 어떤 상황인지 한 줄로 정리합니다
전화할 때는 지금 상황을 한두 문장으로 정리해 두면 좋습니다. / 예를 들면 번호판이 꺼져서 안 열린다, 번호를 눌러도 소리만 난다, 안쪽 보조키가 잠겼다 정도입니다.
언제부터 그랬는지, 처음인지 반복되는지도 같이 말씀해 주세요. / 반복되는 증상이면 원인을 찾는 데 도움이 됩니다.
직접 해 본 것이 있다면 그것도 알려 주세요. / 건전지를 대 봤는지, 번호를 몇 번 눌러 봤는지 알면 같은 시도를 반복하지 않아도 됩니다.

# 신분 확인에 쓸 것을 챙깁니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 휴대폰 속 택배 내역이나 고지서 사진이 도움이 될 때가 있습니다. / 이런 것이 인정되는지는 상황에 따라 다르니 전화로 먼저 물어보세요.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 시간이 줄어듭니다. / 번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다.

# 도착 시간을 위한 준비
출장 시간이 길어지는 가장 큰 이유는 위치를 못 찾거나 건물에 들어가지 못해서입니다. / 공동현관 번호나 호출 방법을 미리 알려 주세요.
주차가 어려운 곳이라면 차를 세울 만한 자리도 같이 알려 주시면 좋습니다. / 산척동은 건물 앞에 차를 세우기 어려운 곳이 있어 미리 알아 두면 시간을 아낍니다.
도착 전에 연락이 갈 수 있으니 휴대폰은 가까이 두세요. / 위치를 다시 한 번 확인해야 할 때가 있습니다.

# 전화로 이야기하는 순서
전화를 걸면 이름보다 위치와 상황을 먼저 말씀해 주시면 됩니다. / 건물 이름, 동과 호수, 도어락 상태, 집 안에 사람이 있는지 순서로 말씀하시면 깔끔합니다.
그다음에 비용이 궁금하시면 먼저 물어보세요. / 비용은 현관문 상태와 도어락 종류를 보고 작업 전에 먼저 말씀드립니다.
괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다. / 못 열면 비용은 받지 않습니다.
@ 산척동 출장열쇠 전화 위치 상황 정리

# 출장을 부르기 전에 해 볼 수 있는 것
번호판이 꺼져 있다면 9V 건전지를 도어락 바깥 아래쪽 비상 단자에 대 보세요. / 건전지를 대고 있는 동안 전원이 들어와 번호를 누를 수 있습니다.
단자가 없거나 건전지를 대도 반응이 없으면 그때 전화 주시면 됩니다. / 드라이버나 카드로 문틈을 벌리거나 손잡이를 세게 당기는 일은 피해 주세요.
문이 상하면 나중에 교체 비용이 더 들 수 있습니다. / 억지로 열려다 일이 커지는 경우가 많습니다.
비밀번호를 여러 번 틀리면 도어락이 한동안 입력을 막습니다. / 서너 번 해 보고 안 되면 멈추는 게 좋습니다.

# 산척동 위치는 이렇게 알려주세요
산척동에서 출장을 부를 때 아래 항목을 알려 주시면 도착이 빨라집니다.
- 건물 이름이나 근처 눈에 띄는 가게
- 동과 호수, 몇 층인지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 도어락 모양 (손잡이 일체형, 버튼형, 밀고 당기는 형)
- 집 안에 아이나 반려동물이 있는지
이 다섯 가지를 한 번에 말씀해 주시면 통화가 짧게 끝납니다. / 급할수록 정확하게 말씀해 주시는 것이 가장 빠릅니다.

# 준비 없이 전화하셔도 괜찮습니다
이 글을 읽고도 준비하기 어려운 상황일 수 있습니다. / 문 앞에서 당황하셨다면 아무 준비 없이 바로 전화해도 괜찮습니다.
위치와 상황만 말씀해 주시면 나머지는 통화하면서 하나씩 여쭤보겠습니다. / 준비물은 빠르게 만들기 위한 것이지 조건이 아닙니다.
휴대폰 배터리가 얼마 남지 않았다면 먼저 위치만 문자로 보내 주세요. / 전화가 끊겨도 위치는 남습니다.

# 도착하면 이렇게 진행합니다
도착하면 먼저 사시는 분인지 확인하고 도어락과 문 상태를 봅니다. / 문 여는 방법은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않고, 필요하면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 산척동 말고 화성 어디든 갑니다
동탄 산척동 옆 청계동, 영천동, 목동과 병점, 봉담, 향남, 남양까지 화성 안이면 24시간 출동합니다. / 동네가 달라도 도착 시간을 먼저 말씀드립니다.
화성에서 다니는 동네는 [화성시 출장열쇠](hwaseong.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
