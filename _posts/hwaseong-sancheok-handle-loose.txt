# 손잡이가 덜렁거리기 시작했다면
동탄 산척동은 동탄역을 오가는 분들이 많은 생활권이라 아침저녁 현관문을 여닫는 횟수가 많습니다. / 하루에도 여러 번 잡고 돌리는 손잡이는 어느 순간부터 조금씩 헐거워지기 마련입니다.
처음에는 흔들리는 느낌만 있다가 어느 날 돌려도 걸쇠가 움직이지 않는 일이 생깁니다. / 손잡이만 헛돌고 문은 그대로 잠겨 있는 상태가 되면 출근길이 막막해집니다.
이 글은 산척동에서 도어락 손잡이가 헐겁거나 헛돌 때 무엇을 살펴야 하는지 정리한 것입니다. / 급하게 문이 안 열리는 상황이라면 [화성 출장열쇠](hwaseong.html) 안내를 함께 보셔도 됩니다.
@ 산척동 도어락 손잡이 헐거움 점검

# 헐거운 것과 헛도는 것은 다른 증상입니다
겉으로는 비슷해 보여도 원인이 다릅니다. / 어느 쪽인지 알면 전화로 설명하기도 쉽고 조치도 빨라집니다.
- 손잡이를 잡고 흔들면 덜걱거리는 경우는 고정 나사가 풀린 것입니다
- 돌릴 때 저항 없이 빙빙 돌기만 하면 안쪽 축과 걸쇠 연결이 빠진 것입니다
- 돌리면 걸쇠는 들어가는데 손을 놓아도 손잡이가 처진 채 있으면 내부 스프링이 약해진 것입니다
첫 번째는 간단히 조일 수 있는 경우가 많습니다. / 두 번째와 세 번째는 내부를 열어봐야 해서 손대기 전에 판단하는 편이 낫습니다.

# 나사만 조이면 되는 경우
손잡이 아래나 옆면에 작은 고정 나사나 육각 홈이 보이면 풀린 것일 수 있습니다. / 맞는 크기의 드라이버나 육각 렌치로 천천히 조여 보세요.
너무 세게 조이면 나사산이 뭉개져서 다시는 고정되지 않습니다. / 손에 걸리는 느낌이 올 때까지만 돌리고 손잡이를 흔들어 확인해 주세요.
나사 구멍이 이미 헐거워 계속 헛돈다면 억지로 조이지 마시고 그대로 두는 것이 낫습니다. / 이 경우는 부품을 교체하거나 고정 방식을 바꿔야 합니다.

# 문 안쪽에서 헛도는 소리가 난다면
문 바깥은 멀쩡한데 안쪽 손잡이만 헛돈다면 안쪽 몸체의 고정이 풀린 경우가 있습니다. / 안쪽 덮개를 열어 보면 축을 잡는 부품이 닳아 있기도 합니다.
이때 손잡이를 억지로 세게 돌리면 남아 있던 연결마저 끊어집니다. / 그러면 안에서도 밖에서도 문이 안 열리는 상황이 됩니다.
살짝 돌려 보고 걸쇠가 움직이는지만 확인한 뒤 그만두세요. / 움직이지 않으면 문을 연 상태로 고정해 두고 연락 주시는 편이 안전합니다.

# 현관문을 열어 둔 채로 먼저 확인할 것
손잡이가 이상하다고 느끼면 문을 완전히 닫지 마세요. / 닫는 순간 걸쇠가 들어가고 손잡이가 헛돌면 밖에서 열기가 어려워집니다.
택배 상자나 신발을 문틈에 괴어 두고 안쪽에서 손잡이를 몇 번 돌려 상태를 봅니다. / 이때 걸쇠가 매끄럽게 나왔다 들어가는지가 핵심입니다.
집 안에 있을 때 증상을 발견하는 것이 가장 다행스러운 경우입니다. / 밖에 나와 있다면 아래 절차를 참고해 주세요.
@ 동탄 산척동 현관 손잡이 걸쇠 확인

# 이미 잠겨 버렸다면 힘으로 밀지 마세요
손잡이가 헛도는 채로 문이 닫혔다면 걸쇠는 문틀에 물려 있는 상태입니다. / 몸으로 밀거나 문틈에 카드를 넣는 행동은 도어락과 문틀 모두에 흠집을 냅니다.
손잡이를 흔들거나 위아래로 당겨 봐도 소용없으면 거기서 멈추는 것이 좋습니다. / 번호 입력이 되는 도어락이라면 번호 쪽 열림 신호가 모터로 연결되는지 소리부터 들어 보세요.
번호를 누르면 모터 소리가 나고 문이 열리는 경우도 있습니다. / 손잡이 축만 문제이고 전자 부분이 정상이라는 뜻이라 수리 범위가 줄어듭니다.

# 산척동에서 위치와 상태를 알려주는 방법
산척동은 동탄역 방향으로 가는 길목이라 단지 이름만으로는 입구가 헷갈릴 수 있습니다. / 동과 호수를 말씀해 주시고 가까운 큰길이나 역 방향을 덧붙여 주시면 찾아가기 쉽습니다.
- 손잡이가 헐거운지 헛도는지, 한쪽만 그런지 양쪽 다 그런지
- 번호나 카드로 열림 소리가 나는지
- 문이 지금 열려 있는지 닫혀 있는지
- 도어락 모양과 제조사 표시가 보이면 사진
- 집 안에 아이나 반려동물이 있는지
손잡이 부분을 가까이서 찍은 사진 한 장이면 챙길 부품을 정하는 데 큰 도움이 됩니다. / 문자로 보내 주시면 도착 전에 대략 어떤 작업인지 말씀드릴 수 있습니다.

# 도착하면 먼저 확인하는 것
작업에 앞서 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 주세요. / 확인이 되지 않으면 문을 열 수 없으니 미리 준비해 두시면 좋습니다.
손잡이 문제는 급해 보이지 않아도 잠긴 문 앞에서는 같은 절차를 따릅니다. / 모든 분께 똑같이 적용하는 기준입니다.

# 비용은 시작 전에 정해서 말씀드립니다
손잡이만 조이면 되는지, 축과 부품을 바꿔야 하는지에 따라 달라집니다. / 문을 보고 어떤 작업인지 정한 뒤 시작하기 전에 먼저 말씀드립니다.
괜찮다고 하시면 작업하고, 아니면 그대로 돌아갑니다. / 문을 끝내 열지 못하면 비용은 받지 않습니다.
작업 중에 부품 교체가 필요해 보여도 말씀 없이 진행하지 않습니다. / 전체 흐름은 [이용안내](guide.html)에 적어 두었습니다.

# 손잡이 수리와 도어락 교체, 어디서 나누나
손잡이 부품만 새로 맞추면 되는 경우와 도어락 전체가 오래된 경우는 판단이 다릅니다. / 몸체 안쪽까지 닳았거나 같은 부위가 반복해서 고장 나면 부분 수리의 의미가 줄어듭니다.
먼저 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 살펴보고, 어려우면 그때 교체를 말씀드립니다. / 아직 쓸 만한 제품을 바꾸라고 권하지는 않습니다.
교체가 맞다면 [도어락 교체](doorlock-replace.html)에서 문 두께와 보조키 규격을 어떻게 보는지 확인해 보세요. / 같은 규격이면 문에 새 구멍을 내지 않고 바꿀 수 있는 경우가 많습니다.
@ 산척동 도어락 손잡이 수리 작업

# 손잡이를 오래 쓰는 습관
손잡이를 쓰는 방식이 수명을 크게 좌우합니다. / 작은 습관 몇 가지만 바꿔도 헐거워지는 속도가 눈에 띄게 느려집니다.
- 장바구니나 가방을 손잡이에 걸어 두지 않기
- 문을 닫을 때 손잡이를 잡은 채 세게 당겨 닫지 않기
- 걸쇠가 문틀에 걸리면 손잡이를 억지로 돌리지 말고 문 위치부터 보기
- 아이가 매달리지 않게 높이와 방법을 알려 주기
몇 달에 한 번 손잡이를 흔들어 보고 덜걱거림이 없는지 확인해 보세요. / 작은 흔들림 단계에서 조이면 큰 수리로 번지지 않습니다.

# 열고 난 뒤 같이 보는 곳
문이 열린 뒤에는 손잡이를 여러 번 돌려 걸쇠가 끝까지 들어갔다 나오는지 봅니다. / 도어락의 번호 입력과 열림, 잠김 소리도 함께 확인합니다.
배터리 잔량이 부족해 보이면 같이 교체하시길 권합니다. / 손잡이와 상관없어 보여도 전원이 약하면 모터가 힘을 못 내서 비슷한 증상이 나옵니다.
필요하다면 [현관문 개문](door-open.html) 페이지에서 비파손 개방이 어떤 순서로 진행되는지도 읽어 보세요. / 문과 손잡이를 상하지 않게 여는 것이 기본 방침입니다.

# 산척동 외에도 화성 곳곳으로 출동합니다
동탄 산척동 옆으로 반송동, 능동, 청계동, 영천동, 오산동, 목동, 장지동도 다닙니다. / 병점동, 진안동, 봉담읍, 향남읍, 남양읍 등 화성 전역이 대상입니다.
다니는 동네는 [화성시 출장열쇠](hwaseong.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.
