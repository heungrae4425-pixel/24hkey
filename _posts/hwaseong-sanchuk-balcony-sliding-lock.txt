# 현관문이 아니라 베란다 문이 말썽일 때
동탄 산척동은 동탄 신도시 안에서도 비교적 조용한 주거 지역이라 베란다가 있는 집이 많습니다. / 현관 도어락은 멀쩡한데 베란다 문이나 방 미닫이 문의 잠금장치가 안 풀리는 일도 의외로 자주 있습니다.
이 글은 산척동에서 베란다 문, 샷시 잠금, 미닫이 방문이 말을 안 들을 때 먼저 확인할 것을 정리했습니다. / 현관문과는 구조가 달라 원인도 다르니, 순서대로 보시면 도움이 됩니다.
문이 안 열려 안에 갇히거나 밖에 나가 있어 못 들어가는 상황이라면 4번부터 읽어 주세요. / 안전이 걸린 일은 혼자 오래 붙잡고 있지 않는 것이 좋습니다.
@ 동탄 산척동 베란다 미닫이 문 잠금장치 출장열쇠

# 베란다 문 잠금은 어떤 종류가 있는지부터 봅니다
베란다 문에는 크게 세 가지 잠금이 쓰입니다. / 문틀에 달린 걸쇠형, 손잡이를 위아래로 돌리는 크레센트형, 열쇠로 돌리는 실린더형입니다.
어떤 형태인지에 따라 풀리지 않는 이유가 다릅니다. / 사진을 한 장 찍어 두면 전화로 설명하기 쉽습니다.
요즘 신축 단지는 크레센트형이 많고, 오래된 건물은 실린더형이 같이 달린 경우가 많습니다. / 열쇠가 필요한 형태라면 열쇠 보관 위치도 같이 확인해 보세요.

# 잠금이 안 풀릴 때 흔한 원인
첫째는 문이 처져서 잠금 부품이 서로 맞물려 빠지지 않는 경우입니다. / 샷시 문은 바퀴가 닳으면 아래로 처지고, 그러면 잠금이 억지로 걸립니다.
둘째는 먼지와 이물질이 걸쇠 홈에 껴서 움직임이 뻑뻑해진 경우입니다. / 베란다는 먼지가 쌓이기 쉬워 겉보기보다 안쪽이 막혀 있는 일이 있습니다.
셋째는 잠금 부품 자체가 마모되거나 부러진 경우입니다. / 손잡이가 헛돌거나 한쪽만 움직이는 느낌이면 이 경우를 의심해 볼 수 있습니다.

# 직접 해볼 수 있는 것, 손잡이를 세게 돌리지 마세요
문을 살짝 들어 올리듯이 밀어 주면서 손잡이를 돌려 보세요. / 처진 문은 이렇게 하중이 풀리면 잠금이 쉽게 풀리기도 합니다.
이물질이 의심되면 마른 솔이나 면봉으로 걸쇠 홈을 가볍게 털어 줍니다. / 기름이나 윤활제를 급하게 뿌리면 먼지가 엉겨 더 뻑뻑해지는 일이 있어 권하지 않습니다.
힘으로 확 돌리면 손잡이 축이 부러지거나 유리가 깨질 수 있습니다. / 안 되면 멈추고 전화 주시는 것이 결과적으로 비용도 덜 듭니다.

# 베란다에 나갔다가 문이 잠겨 못 들어올 때
빨래를 널거나 환기를 하려고 나갔다가 문이 닫히고 잠금이 걸려 버리는 일이 있습니다. / 바람이 세게 부는 날이나 문이 헐거운 집에서 자주 생깁니다.
이때는 먼저 휴대폰이 어디 있는지 확인하세요. / 베란다에 휴대폰이 없다면 이웃이나 경비실을 통해 연락하는 방법을 생각해 봅니다.
높은 층이거나 날이 춥다면 오래 기다리지 마시고 바로 연락 주세요. / 안전이 걸린 상황은 가장 먼저 말씀해 주시면 우선해서 움직입니다.
@ 산척동 베란다 문 잠김 출장열쇠 점검

# 방 미닫이 문과 샷시 문이 안 움직일 때
방문이나 파티션 미닫이는 레일에 이물질이 끼거나 바퀴가 부러져 움직이지 않는 일이 많습니다. / 레일을 청소하고 문을 살짝 들어 바퀴를 맞춰 주면 돌아오기도 합니다.
잠금장치가 달린 미닫이는 걸쇠가 문틀 홈에 걸려 있을 수 있습니다. / 문을 반대 방향으로 조금 밀어 걸쇠가 빠지게 하고 손잡이를 돌려 보세요.
문틀이 뒤틀린 경우는 직접 해결이 어렵습니다. / 억지로 당기면 문과 틀이 같이 상하니 그대로 두고 알려 주세요.

# 출장열쇠가 베란다 문에서 해드릴 수 있는 일
잠금장치가 걸려 문이 안 열릴 때는 파손 없이 푸는 방법부터 시도합니다. / 샷시나 유리, 문틀이 상하지 않게 진행하는 것이 가장 중요합니다.
잠금 부품이 부러졌거나 마모됐다면 부품 교체 가능 여부를 같이 봅니다. / 제품 규격이 다양해서 사진을 먼저 보내 주시면 맞는 부품을 챙겨 가기 쉽습니다.
교체가 필요하면 바꾸기 전에 설명하고 여쭤본 뒤에 진행합니다. / 열고 난 뒤 말없이 붙는 비용은 없습니다.
자세한 방식은 [출장 열쇠](key-call.html) 페이지에 정리해 두었습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 베란다 문도 집 안으로 들어가는 문이라 똑같이 확인합니다.
베란다에 갇혀 있는 상황이라면 안에서 신분증을 보여 드리기 어려울 수 있습니다. / 이럴 때는 가족이나 이웃, 경비실을 통해 확인하는 방법을 함께 찾습니다.

# 비용은 문 열기 전에 말씀드립니다
문 형태와 잠금 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 산척동 베란다 샷시 잠금 수리 비용 안내

# 잠금이 자주 말썽이라면 샷시 점검도 같이
베란다 문이 한두 번이 아니라 자주 뻑뻑하다면 잠금장치만의 문제가 아닐 수 있습니다. / 바퀴, 레일, 문틀이 같이 낡았다면 잠금만 바꿔도 곧 같은 일이 생깁니다.
이런 부분은 샷시 전문 업체가 필요한 경우도 있습니다. / 어디까지가 열쇠로 해결되는 일인지 현장에서 솔직하게 말씀드립니다.
무리해서 고치려다 유리나 문틀을 깨는 일이 가장 큰 손해입니다. / 확실하지 않으면 먼저 사진을 보내 주세요.

# 베란다 문 잠금을 오래 쓰는 관리법
- 계절이 바뀔 때 레일과 걸쇠 홈의 먼지를 털어 주기
- 문이 처진 느낌이 들면 바퀴 상태를 일찍 점검하기
- 손잡이를 돌릴 때 걸리는 느낌이 있으면 힘주지 말고 바로 확인하기
- 바람 센 날 문이 닫히지 않게 고정해 두기
- 열쇠형 잠금이면 여분 열쇠를 집 안과 밖에 나눠 보관하기
작은 습관이지만 문 앞에서 막히는 일을 많이 줄여 줍니다. / 특히 환기를 자주 하는 집일수록 효과가 큽니다.

# 현관문 도어락도 같이 점검해 드릴 수 있습니다
베란다 문 때문에 방문하는 김에 현관 도어락 상태도 같이 봐 드립니다. / 배터리 잔량이나 번호판 반응처럼 눈으로 확인되는 것은 간단히 안내합니다.
고쳐서 쓸 수 있는 것은 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 원하지 않으시면 하지 않아도 됩니다.

# 산척동 말고 화성 어디든 갑니다
산척동 바로 옆 동탄 신도시 여러 동네와 병점, 봉담, 향남, 남양까지 화성 안이면 24시간 출동합니다. / 화성에서 다니는 동네는 [화성시 출장열쇠](hwaseong.html) 페이지에 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 현관문 개문은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
