# 번호만으로는 불안하다는 분들께
동탄 산척동은 동탄역을 오가는 분들이 많이 사는 동네이고, 현관 보안에 신경 쓰는 분들의 문의도 있습니다. / 번호 하나만 알면 열리는 방식이 마음에 걸려 번호와 카드를 함께 쓰는 설정을 찾아보시는 경우입니다.
이 글은 이중 인증이 무엇인지, 어떤 도어락에서 가능한지, 설정할 때와 쓸 때 어떤 점을 조심할지 정리했습니다. / 제품마다 방식이 달라 일반적인 흐름 위주로 적었습니다.
@ 산척동 도어락 번호와 카드 이중 인증

# 이중 인증이란 정확히 무엇인가
말 그대로 두 가지 방법을 모두 맞춰야 문이 열리는 설정입니다. / 예를 들어 카드를 먼저 대고, 이어서 번호를 눌러야 열립니다.
카드만 주워도 안 열리고, 번호를 어깨너머로 봐도 안 열립니다. / 그래서 한 가지 수단이 새어 나가도 바로 뚫리지 않는다는 점이 장점입니다.
다만 모든 도어락이 이 기능을 지원하지는 않습니다. / 있다 해도 이름과 설정 방식이 제품마다 다릅니다.

# 우리 집 도어락이 지원하는지 확인하는 법
먼저 설명서나 안쪽 본체의 안내 스티커를 확인해 보세요. / 제품 모델명이 적혀 있으면 사진으로 남겨 두면 편합니다.
- 카드 대는 부분이 있는 제품인지
- 번호판과 카드 인식부가 모두 있는지
- 안내 음성이나 설정 메뉴에 인증 방식 선택이 있는지
카드 인식부가 없다면 이중 인증은 어렵습니다. / 이럴 때는 [도어락 교체](doorlock-replace.html) 쪽을 고려해야 할 수 있지만, 필요 없는 교체는 권하지 않습니다.

# 설정은 안쪽 본체에서 진행합니다
대부분 문 안쪽 본체의 덮개를 열고 등록 버튼이나 설정 키를 누르며 시작합니다. / 이 과정에서 기존 마스터 번호를 알아야 하는 제품도 많습니다.
마스터 번호를 모르면 설정 메뉴에 들어갈 수 없는 경우가 있습니다. / 그럴 때는 임의로 초기화하기보다 먼저 문의해 주세요.
설정 중에는 문을 열어 둔 상태에서 진행하세요. / 설정이 꼬여 문이 잠기면 밖으로 나가는 순간 곤란해질 수 있기 때문입니다.
@ 산척동 도어락 안쪽 설정 버튼과 카드 등록

# 카드는 몇 장 등록하는 것이 좋은가
이중 인증이면 카드가 곧 열쇠 한 쪽이 됩니다. / 한 장만 등록해 두고 잃어버리면 곧바로 문 앞에서 막힙니다.
- 가족 수에 맞춰 등록하되 여분 카드를 하나 따로 보관
- 카드마다 누구 것인지 겉에 표시 없이 가족끼리만 알기
- 지갑 속 카드와 집 근처에 두는 카드를 분리해 두기
카드를 잃어버렸을 때를 위해 [카드키·태그 분실](key-call.html) 상황에서 어떻게 하는지도 미리 알아 두면 좋습니다.

# 번호와 카드의 순서를 헷갈리지 않는 법
제품에 따라 카드를 먼저 대는 방식과 번호를 먼저 누르는 방식이 다릅니다. / 설정 후 반드시 문 안쪽에서 여러 번 시험해 보세요.
- 가족이 한 번씩 직접 해 보기
- 순서를 틀렸을 때 어떤 소리가 나는지 확인
- 시간 제한이 있는 제품이면 몇 초 안에 눌러야 하는지 확인
처음에는 가족 모두가 불편해합니다. / 며칠 쓰면 익숙해지지만 어르신이 계시면 [현관문 개문](door-open.html)이 필요한 상황이 생기기 쉬우니 천천히 연습하는 게 좋습니다.

# 이중 인증이 어울리는 집과 아닌 집
혼자 사는 분이나 귀중품을 보관하는 집, 사무실 겸용 공간에는 잘 맞는 편입니다. / 반대로 어린 자녀가 혼자 드나드는 집이나 고령의 부모님이 사는 집은 오히려 불편할 수 있습니다.
카드 한 장을 늘 챙기는 일이 습관이 되지 않으면 문 앞에서 막히는 일이 늘어납니다. / 보안과 편의 사이에서 우리 집에 맞는 균형을 고르는 게 중요합니다.
출입이 잦은 집이면 평소에는 번호만 쓰고 장기 외출 때만 이중 인증을 켜는 제품도 있습니다. / 이런 기능이 있는지 모델 설명서에서 찾아보세요.

# 배터리가 약해지면 이중 인증이 더 불편해집니다
두 단계를 거치므로 전력도 조금 더 쓰고, 반응이 느려지면 오류가 나기 쉽습니다. / 배터리 경고음이 나면 바로 교체해야 하는 이유입니다.
번호판이 꺼진 상태에서는 비상 전원을 대도 카드 인증이 안 되는 제품이 있습니다. / 이 경우 기계식 열쇠 구멍이 있는지 먼저 확인해 보세요.
@ 산척동 도어락 배터리와 비상 전원 단자

# 문이 열리지 않을 때 먼저 해 볼 것
이중 인증을 설정한 뒤 문이 안 열리면 대개 순서나 카드 문제입니다.
- 카드를 대는 위치와 시간을 바꿔 보기
- 번호를 천천히 한 번 더 누르기
- 다른 카드로 시도하기
- 배터리 경고음이 있었는지 떠올리기
그래도 안 되면 억지로 시도하지 마시고 전화 주세요. / 여러 번 틀리면 도어락이 입력을 한동안 막을 수 있습니다.

# 가족이 설정을 바꿨을 때
이중 인증 설정을 한 가족이 다른 가족에게 알리지 않으면 문 앞에서 혼란이 생깁니다. / 설정을 바꾼 날에는 가족 메신저 방에 사용 순서만 간단히 남겨 두세요.
번호 자체는 메신저에 남기지 않는 편이 안전합니다. / 순서만 알려주고 번호는 직접 말로 전해 주세요.

# 출장열쇠가 도와드리는 범위
전화 주시면 도어락 종류를 먼저 여쭤봅니다. / 모델 사진을 문자로 받으면 어떤 방식이 가능한지 알려드립니다.
설정이 막혀서 문이 잠긴 경우에는 신분 확인 후 문을 엽니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
비용은 작업 전에 먼저 말씀드립니다. / 문을 못 열면 비용은 받지 않습니다. 자세한 흐름은 [이용안내](guide.html)에 있습니다.
[도어락 설치](doorlock-install.html) 페이지에서 새 제품을 달 때의 순서도 볼 수 있습니다.

# 산척동 말고 어디든 갑니다
산척동에서 가까운 청계동, 반송동, 영천동, 장지동은 물론 화성 병점동, 봉담읍, 향남읍까지 다닙니다. / 동탄역과 병점역 생활권이면 어디든 연락 주세요.
[화성시 출장열쇠](hwaseong.html) 페이지에서 지역 안내를 보실 수 있습니다.
이중 인증 설정이 낯설어 막혔다면 혼자 오래 붙잡지 마시고 모델명과 사진을 보내 주세요. / 설정 순서를 전화로 안내해 드리거나, 필요하면 직접 가서 같이 등록해 드립니다.
설정을 마친 뒤에는 가족 모두가 문 안쪽에서 한 번씩 열어 보는 시험까지 끝내야 안심할 수 있습니다. / 이 시험을 건너뛰면 다음 날 아침 출근길에 문 앞에서 막히는 일이 생기기 쉽습니다.
카드를 대는 위치가 헷갈리면 번호판 옆 표시나 불빛을 기준으로 익혀 두세요. / 어르신이 쓰실 집이라면 카드 대는 자리를 스티커 없이 손가락 위치로 알려 드리는 것도 도움이 됩니다.
이중 인증을 쓰다가 불편해지면 언제든 한 가지 방식으로 되돌릴 수 있는 제품도 많습니다. / 처음부터 끝까지 고집하기보다 생활에 맞게 조절하세요.
손님이나 가사도우미가 드나드는 집이라면 임시 번호 기능과 함께 쓰는 방법도 물어보세요. / 방문이 끝나면 해당 번호만 지우면 되어 관리가 편합니다.

# 자주 묻는 질문
? 이중 인증은 모든 도어락에서 되나요? | 아닙니다. 번호와 카드 인식부를 모두 갖춘 제품 중 일부만 지원합니다.
? 카드를 잃어버리면 문을 못 여나요? | 신분 확인 후 문을 열고 새 카드를 등록해 드립니다. 못 열면 비용은 받지 않습니다.
? 마스터 번호를 몰라도 설정할 수 있나요? | 제품에 따라 다릅니다. 모르는 경우에는 먼저 상황을 말씀해 주세요.
? 설정하다 문이 잠기면 어떻게 하나요? | 억지로 시도하지 말고 전화 주세요. 사시는 분 확인 후 개방합니다.
? 비용은 언제 알려주시나요? | 작업 전에 먼저 말씀드리고 동의하시면 시작합니다.
