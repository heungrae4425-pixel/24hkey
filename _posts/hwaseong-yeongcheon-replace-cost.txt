# 영천동에서 도어락을 바꿔야 하나 고민될 때
동탄 영천동에서 입주한 지 몇 해가 지나면 도어락이 한두 번 말썽을 부리기 시작합니다. / 그때 고쳐 쓸지 새로 바꿀지 판단하기가 가장 어렵습니다.
이 글은 영천동에서 도어락 교체를 고민하는 분을 위해 바꾸기 전에 확인할 것과 비용을 안내받는 방식을 정리했습니다. / 설치 진행은 [화성 출장열쇠](hwaseong.html)가 어떻게 하는지도 적었습니다.
@ 영천동 도어락 교체 출장열쇠

# 꼭 바꿔야 하는 경우와 고쳐도 되는 경우
모든 고장이 교체로 이어지는 것은 아닙니다. / 증상에 따라 수리로 충분한 경우가 많습니다.
- 배터리만 갈면 되는 문제는 교체가 필요 없음
- 부품 하나 문제면 수리로 해결되기도 함
- 여러 번 같은 증상이 반복되면 교체를 고려
- 제품이 너무 오래되어 부품을 구하기 어려우면 교체

# 교체를 권하는 신호
도어락 수명은 사용 환경에 따라 다르지만 공통으로 보이는 신호가 있습니다. / 아래 중 두세 가지가 겹치면 교체를 한 번 생각해 볼 때입니다.
- 번호 입력 반응이 자주 늦거나 안 먹는다
- 문이 한 번에 잠기지 않는다
- 새 배터리를 넣어도 금방 방전된다
- 손잡이 쪽에서 헐거운 소리가 난다

# 바꾸기 전에 먼저 확인할 세 가지
도어락은 문에 맞아야 달 수 있습니다. / 문 두께와 기존 구멍 모양, 안쪽 보조키 유무에 따라 달 수 있는 제품이 달라집니다.
사진 몇 장을 보내주시면 맞는 제품을 미리 골라 갈 수 있습니다. / 이렇게 하면 현장에서 안 맞아 다시 가는 일이 줄어듭니다.
@ 영천동 도어락 교체 전 문 두께 확인

한 번 정한 방식은 몇 해 쓰게 되니 지금 편한 것보다 몇 해 뒤에도 편할 것을 생각해 보세요. / 아이가 자라면 카드가, 부모님이 함께 사시면 번호가 편할 수 있습니다.
가족이 모두 쓰는 현관문이라면 가장 불편한 사람을 기준으로 고르는 것이 가장 안전합니다. / 그 사람이 쉽게 열 수 있으면 나머지 가족은 대개 문제가 없습니다.

# 방식을 먼저 고르세요
번호식, 카드식, 지문식, 푸시풀식처럼 방식이 나뉩니다. / 가족 구성과 사용 습관에 따라 편한 방식이 다릅니다.
아이가 있으면 카드나 번호가, 짐이 많은 분은 지문이 편하다는 식으로 정리해 보세요. / 어떤 방식이 맞는지 모르겠으면 전화로 물어보셔도 됩니다.

# 비용은 이렇게 안내받으세요
교체 비용은 제품과 문 상태에 따라 달라서 현장을 보고 말씀드립니다. / 숫자를 먼저 못 박는 대신 어디에 비용이 드는지를 풀어서 설명해 드립니다.
- 제품 가격과 설치비가 따로 나뉘는지
- 기존 도어락 철거가 포함되는지
- 문 가공이 필요한지
- 추가로 붙는 부품이 있는지

# 이런 안내는 조심하세요
전화로는 낮은 비용만 말하고 현장에서 늘리는 경우를 조심하셔야 합니다. / 비용은 작업 시작 전에 말씀드리고 동의를 받은 뒤 시작하는 게 정상입니다.
시작 후에 말없이 비용이 붙으면 그때 거절하셔도 됩니다. / 24시출장열쇠는 열기 전에 먼저 말씀드리고, 마음에 안 드시면 그냥 돌아갑니다.

# 전화로 알려주실 것
- 영천동 위치, 동과 호수
- 지금 쓰는 도어락 사진 (앞면, 안쪽 면)
- 어떤 증상이 있는지
- 바꾸고 싶은 방식이 있는지

# 방문하면 이렇게 진행됩니다
도착해서 문과 기존 도어락을 먼저 확인합니다. / 맞는 제품과 비용을 말씀드리고 동의를 받으면 작업을 시작합니다.
기존 제품을 떼고 새 제품을 달고, 번호와 카드를 등록하는 것까지 함께 합니다. / 사용법은 쓰시는 분이 이해할 때까지 설명해 드립니다.
@ 동탄 영천동 출장열쇠 도어락 설치

# 교체 후 꼭 해볼 것
- 문을 열고 닫으며 잠금이 잘 되는지 여러 번 확인
- 새 번호를 가족 모두에게 알렸는지
- 카드나 열쇠를 가족 수만큼 챙겼는지
- 배터리 칸 위치와 교체 방법 확인

교체하러 온 날 문 쪽에 문제가 보이는 경우도 있습니다. / 예를 들어 기존 구멍이 지나치게 커져 있거나 문 안쪽이 상해 있으면 새 도어락이 헐겁게 붙을 수 있습니다.
그럴 때는 작업 전에 어떻게 보완할지 먼저 말씀드립니다. / 말없이 문을 가공하거나 부품을 추가하는 일은 하지 않습니다.
동탄 영천동처럼 입주 연차가 비슷한 단지는 같은 시기에 도어락이 같이 노후되기도 합니다. / 이웃끼리 같은 증상이 있다면 같은 방문에서 점검해 드릴 수 있는지 문의해 보세요.

# 기존 도어락은 어떻게 하나요
떼어낸 기존 도어락은 가져가 달라고 하시거나 두고 쓰셔도 됩니다. / 쓸 만한 부품이 남은 제품은 보관하셔도 괜찮습니다.
개인 정보가 들어 있는 지문 제품은 등록 정보를 지운 뒤 처리하는 것이 안전합니다. / 필요하시면 같이 말씀해 주세요.

# 설치만 따로 맡길 수도 있습니다
직접 제품을 사 두셨다면 설치만 요청하셔도 됩니다. / 그 경우 문에 맞는 제품인지 먼저 사진으로 확인해 드립니다.
[도어락 설치](doorlock-install.html) 페이지에 설치 진행 방식을 적어 두었습니다. / 교체 진행은 [도어락 교체](doorlock-replace.html) 페이지를 참고하세요.

# 영천동 말고 화성 어디든 갑니다
동탄 반송동, 능동, 청계동은 물론 병점, 봉담, 향남까지 화성 전 지역에 갑니다. / 문 열기가 아닌 교체와 설치도 24시간 연락 주셔도 됩니다.
다니는 동네는 [출장 지역](area.html) 지도에서 확인하세요. / 진행 방식은 [이용안내](guide.html)에 있습니다.
