# 사람이 늘수록 열쇠는 흐려집니다
동탄 영천동에서 사무실을 나눠 쓰거나 공유 공간을 운영하다 보면 문 열쇠는 어느새 누구 것인지 알 수 없게 됩니다. / 동탄역 근처로 출퇴근하는 팀이 드나드는 곳일수록 더 그렇습니다.
이 글은 여러 사람이 같은 문을 쓸 때 열쇠와 비밀번호를 어떻게 관리하면 좋은지 정리했습니다. / 문이 막히는 날을 대비해 [화성 출장열쇠](hwaseong.html)를 부르는 방법도 같이 적었습니다.
@ 영천동 공유 사무실 출입문 열쇠 관리

# 누가 열쇠를 갖고 있는지부터 적어 보세요
관리의 시작은 현재 상태를 아는 것입니다. / 문을 쓰는 사람 이름 옆에 열쇠, 카드, 비밀번호 중 무엇을 갖고 있는지 적은 표를 만들어 보세요.
처음 적어 보면 퇴사한 사람이 아직 번호를 알고 있거나, 복사본 열쇠가 어디 있는지 아무도 모르는 경우가 드러납니다. / 이런 빈틈은 사고가 나기 전에 정리해야 합니다.
표에는 받은 날짜와 돌려받은 날짜를 함께 적어 두면 좋습니다.
종이로 적어도 되고 공유 문서로 관리해도 되지만, 번호 자체는 표에 적지 말고 누가 알고 있는지만 남기세요.

# 비밀번호 하나를 모두가 쓰는 방식의 한계
작은 사무실은 하나의 번호를 다 같이 쓰는 경우가 많습니다. / 편하긴 하지만 누가 언제 들어왔는지 알 수 없고, 한 명이 나가면 모두에게 새 번호를 알려야 합니다.
번호를 바꿀 때마다 공유방에 올리는 건 위험합니다. / 번호는 오래 남는 메신저 대신 얼굴을 보고 전하는 편이 낫습니다.
사용자별로 번호를 따로 등록할 수 있는 도어락이라면 이 문제를 크게 줄일 수 있습니다.
@ 동탄 영천동 공동 출입 도어락 사용자 등록

# 사람마다 다른 번호나 카드를 주는 방법
여러 사용자를 등록할 수 있는 제품이라면 한 명에 하나씩 번호나 카드를 주세요. / 누가 나가면 그 사람 것만 지우면 됩니다.
- 상근 인원은 개인 번호와 카드
- 자주 오지 않는 사람은 기간 한정 번호
- 청소나 점검 인력은 방문 때만 쓰는 임시 번호
기능이 있는지는 제품 설명서로 확인할 수 있습니다. / 모르겠으면 도어락 사진을 보내 주시면 어떤 방식이 되는지 말씀드립니다.

# 퇴사나 탈퇴가 있을 때 해야 할 일
사람이 나가는 날 바로 해야 할 일이 세 가지입니다. / 번호 삭제, 카드 회수, 복사한 열쇠 반납입니다.
공유 번호 하나만 쓰는 곳이라면 번호 전체를 바꾸고 남은 사람에게 새로 알려야 합니다. / 귀찮다고 미루면 이전 사람이 계속 출입할 수 있는 상태가 이어집니다.
작은 절차지만 반복해 두면 조직이 바뀌어도 문이 흔들리지 않습니다.
특히 짧은 기간 같이 쓰다 떠나는 사람이 많은 공유 공간일수록, 입주 첫날 받는 물건과 마지막 날 돌려줄 물건을 안내문으로 만들어 두면 편합니다.

# 열쇠 복사본은 여러 개 만들지 않는 것이 낫습니다
열쇠 수가 늘어나면 잃어버릴 가능성도 같이 늘어납니다. / 누가 잃어버렸는지 알 수 없으면 문 전체를 바꿔야 할 수도 있습니다.
공동 공간이라면 열쇠 복사는 책임자 한 명만 허락하는 규칙을 만드세요. / 열쇠 보관함을 두는 곳은 보관함 번호도 정기적으로 바꿔 주세요.
열쇠가 하나 사라졌다고 해서 바로 모든 걸 바꿀 필요는 없지만 상황을 보고 판단할 수 있게 기록해 두면 좋습니다.

# 문이 안 열릴 때 누구에게 연락하는지 정해 두기
공유 공간은 문제가 생겼을 때 서로 미루다 시간이 흘러가는 일이 잦습니다. / 연락 순서를 미리 정해 두세요.
첫 번째는 책임자나 관리 담당자, 두 번째는 건물 관리실, 세 번째는 출장 열쇠입니다. / 전화번호는 공유 게시판이나 문 안쪽에 붙여 두면 급할 때 도움이 됩니다.
밤이나 주말에 문제가 생기면 책임자가 연락이 안 될 수도 있으니, 대신 판단할 사람도 한 명 더 정해 두세요.


공유 오피스는 건물 입구, 층 복도, 사무실 문이 따로 잠기는 경우가 많습니다. / 어느 문이 문제인지 알아야 엉뚱한 곳에 전화하지 않습니다.
건물 입구가 안 열리면 관리실이나 건물주 쪽 연락처를 먼저 찾아야 합니다. / 사무실 도어락 자체가 막혔다면 바로 출장을 요청하실 수 있습니다.

# 전화하실 때 알려주세요
위치와 상황이 정확하면 도착이 빨라집니다. / 사무실이라면 아래 항목을 함께 알려주세요.
- 건물 이름 대신 길에서 보이는 모습과 층, 호수
- 도어락 모양과 번호판 상태
- 평소 몇 명이 쓰는지
- 요청하시는 분이 책임자인지 이용자인지
- 안에 중요한 장비나 사람이 있는지
사진을 먼저 보내 주시면 필요한 장비를 챙기기 좋습니다.
건물 입구가 안 열리는 상황이라면 관리실이나 건물 쪽 연락처를 먼저 찾아야 합니다. 사무실 도어락 자체가 막힌 경우는 바로 요청하셔도 됩니다.

# 신분 확인은 사무실도 똑같습니다
사무실 문이라고 해서 확인 절차가 달라지지 않습니다. / 요청하는 분이 그 공간을 쓰는 사람인지 확인한 뒤에 엽니다.
임대차 계약서, 사업장 관련 서류, 건물 관리실의 확인, 신분증 중에서 가능한 것을 준비해 주세요. / 책임자가 아니라면 책임자의 확인 문자가 있으면 수월합니다.
확인이 어려우면 열 수 없으니 미리 챙겨 두시는 편이 좋습니다.

# 비용은 열기 전에 말씀드립니다
문과 도어락 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 돌아갑니다.
못 열면 비용은 받지 않으며, 열고 나서 말없이 더 붙는 비용도 없습니다. / 부품 교체가 필요하면 바꾸기 전에 다시 여쭙습니다.
진행 방식은 [이용안내](guide.html)에서도 볼 수 있습니다.
여러 명이 쓰는 문이라 결제나 확인 담당이 다르면 미리 한 분을 정해 두셔야 진행이 매끄럽습니다.

# 열고 나서 번호와 사용자 정리
문이 열리면 등록된 번호와 카드를 같이 정리해 드립니다. / 쓰지 않는 번호는 지우고 지금 쓰는 사람의 번호만 남기는 것이 좋습니다.
공유 번호를 쓰던 곳이라면 이번 기회에 사용자별 번호로 바꿀지 상담해 보세요. / 설치 방식은 [도어락 설치](doorlock-install.html)에 안내해 두었습니다.
@ 영천동 사무실 도어락 사용자 정리

# 정기 점검 일정을 정해 두면 좋습니다
석 달이나 반년에 한 번, 번호와 카드 목록을 같이 훑어보는 날을 정해 두세요. / 오래 쓰지 않은 번호는 지우고 배터리 상태도 같은 날 확인합니다.
출입이 잦은 문은 부품이 빨리 닳으니 문이 덜 닫히거나 걸쇠가 뻑뻑하면 [도어락 수리](doorlock-repair.html)로 먼저 손보세요. / 문제가 커지기 전에 고치면 업무가 멈추는 일이 줄어듭니다.

# 영천동 말고 화성 다른 동네도 갑니다
동탄 영천동 근처 반송동, 능동, 청계동, 산척동은 물론 병점, 봉담, 향남, 남양까지 화성 안이면 다닙니다. / 24시간 전화를 받습니다.
다니는 곳은 [화성시 출장열쇠](hwaseong.html)에, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
