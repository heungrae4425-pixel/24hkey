# 관고동 현관, 잠금쇠가 말을 안 들을 때
문을 닫고 잠그려는데 드르륵 소리만 나고 잠기지 않거나, 반대로 잠긴 채로 풀리지 않는 일이 있습니다. / 이때 문제를 일으키는 부품이 문 옆면에서 튀어나왔다 들어가는 굵은 잠금쇠, 데드볼트입니다.
관고동은 이천 시내에서 아파트와 주택이 섞여 있는 동네입니다. / 오래된 주택은 문틀이 처진 경우가, 아파트는 도어락을 여러 번 바꾸며 받침쇠 위치가 어긋난 경우가 흔합니다.
이 글은 관고동에서 데드볼트가 안 들어가거나 안 빠질 때 원인을 하나씩 짚는 방법을 정리했습니다. / 문 앞에서 막혔다면 [이천 출장열쇠](icheon.html)로 바로 연락 주셔도 됩니다.
@ 관고동 현관 도어락 데드볼트 걸림

# 데드볼트와 걸쇠는 다릅니다
문 옆면을 보면 비스듬한 모양의 걸쇠와 네모난 굵은 잠금쇠가 따로 있는 경우가 많습니다. / 비스듬한 걸쇠는 문이 닫힌 상태를 잡아 주고, 네모난 데드볼트는 실제로 문을 잠그는 역할을 합니다.
도어락이 잠길 때 모터가 데드볼트를 밀어 내 문틀 구멍에 넣습니다. / 열 때는 반대로 모터가 데드볼트를 끌어당깁니다.
그래서 데드볼트가 문틀 구멍과 조금만 어긋나도 모터가 밀거나 당기지 못하고 멈춥니다. / 대부분의 데드볼트 문제는 여기서 시작됩니다.

# 안 들어가는지, 안 빠지는지 먼저 구분
잠그려는데 데드볼트가 안 나오거나 끝까지 안 들어간다면 문틀 구멍 위치가 어긋났거나 구멍 안에 무언가 막혀 있는 경우입니다. / 문을 연 상태에서 잠금을 눌러 보면 데드볼트가 끝까지 나오는지 확인할 수 있습니다.
열려는데 데드볼트가 잠긴 채로 안 빠진다면 데드볼트가 문틀 구멍 가장자리에 눌려 있는 경우가 많습니다. / 이 경우 문을 밀거나 당겨 눌린 힘을 풀어 주면 빠지기도 합니다.
- 열린 상태에서도 안 나옴: 도어락 안쪽 문제
- 열린 상태에서는 잘 나오는데 닫으면 안 들어감: 문틀 구멍 어긋남
- 잠긴 채 안 빠짐: 눌림, 모터 힘 부족, 부품 걸림

# 문이 처져 구멍이 어긋난 경우
무거운 철문은 시간이 지나면서 경첩 반대쪽으로 조금씩 처집니다. / 문이 몇 밀리만 내려가도 데드볼트가 구멍 아래쪽 테두리에 걸립니다.
문을 닫고 문 위쪽과 아래쪽 틈을 비교해 보세요. / 위가 넓고 아래가 좁다면 문이 처진 것입니다.
문틀 구멍 테두리에 긁힌 자국이나 반짝이는 부분이 있다면 데드볼트가 계속 거기에 닿고 있다는 뜻입니다. / 받침쇠 위치를 맞추거나 경첩을 조정해야 합니다.
@ 이천 관고동 문틀 받침쇠 데드볼트 구멍

# 받침쇠가 헐거워진 경우
문틀 쪽에 데드볼트가 들어가는 구멍을 감싸는 금속판이 받침쇠입니다. / 문이 세게 닫힐 때마다 충격을 받아 고정 나사가 조금씩 풀립니다.
받침쇠가 흔들리면 구멍 위치가 미세하게 움직여 어느 날은 잘 되고 어느 날은 안 되는 식이 됩니다. / 손가락으로 눌러 봐서 흔들린다면 나사를 조여 주세요.
조였는데도 금방 다시 풀린다면 나사 구멍이 닳은 것입니다. / 이때는 위치를 조금 옮기거나 다른 방법으로 고정해야 합니다.

# 구멍 안에 무언가 막혀 있을 때
문틀 구멍 안에 먼지, 페인트 찌꺼기, 작은 돌이 쌓이면 데드볼트가 끝까지 들어가지 못합니다. / 공사나 페인트칠을 한 뒤에 이런 일이 자주 생깁니다.
문을 열고 손전등으로 구멍 안을 들여다보세요. / 무언가 보이면 이쑤시개나 작은 솔로 털어 냅니다.
구멍 안에 기름을 뿌리는 건 피해 주세요. / 기름에 먼지가 붙어 오히려 더 막히게 됩니다.

# 모터 힘이 부족한 경우
건전지가 약하면 모터가 데드볼트를 끝까지 밀거나 당기지 못합니다. / 문이 조금이라도 눌려 있으면 더 힘이 들어 중간에 멈춥니다.
최근 경고음이 났다면 건전지를 전부 새것으로 바꿔 보세요. / 그래도 같은 증상이면 모터나 기어 쪽이 약해졌을 수 있습니다.
도어락 안에서 갈리는 소리가 나면서 데드볼트가 움직이지 않는다면 안쪽 기어가 닳았을 가능성이 있습니다. / 이 경우는 [도어락 수리](doorlock-repair.html)로 점검을 받아 보세요.

# 보조키 데드볼트가 걸렸을 때
열쇠로 잠그는 보조키에도 데드볼트가 있습니다. / 열쇠를 돌렸는데 끝까지 안 돌아가고 중간에 걸린다면 데드볼트가 문틀 구멍에 걸린 경우가 많습니다.
문을 살짝 밀거나 당긴 상태에서 열쇠를 다시 돌려 보세요. / 그래도 안 되면 열쇠를 억지로 돌리지 마세요. 열쇠가 부러지면 일이 더 커집니다.

# 잠긴 채 안 빠져 문 앞에 서 있다면
번호는 맞는데 데드볼트가 안 빠져 문이 안 열린다면 먼저 문을 안쪽으로 살짝 밀면서 번호를 다시 눌러 보세요. / 당기는 문이라면 손잡이를 몸 쪽으로 살짝 당긴 채로 해 봅니다.
두세 번 해서 안 되면 멈추세요. / 계속 작동시키면 모터와 기어에 무리가 갑니다.
- 문을 발로 차거나 어깨로 밀지 않기
- 문틈에 도구를 넣어 데드볼트를 밀지 않기
- 번호를 반복해서 누르지 않기

# 연락 주실 때 알려 주실 것
- 관고동 아파트 동, 호수 또는 주택 주소
- 데드볼트가 안 들어가는지, 안 빠지는지
- 문이 열린 상태인지 닫힌 상태인지
- 도어락인지 보조키인지
- 최근 건전지를 바꿨는지
문 옆면 데드볼트와 문틀 받침쇠 사진이 있으면 원인을 짐작하는 데 큰 도움이 됩니다.

# 확인 절차와 비용 안내
문이 닫힌 채 안 열리는 상황이라면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
상태를 보고 비용을 손대기 전에 말씀드리고, 못 열면 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 있습니다.
@ 관고동 데드볼트 걸림 현관문 개문

# 열고 난 뒤 바로잡는 것
문이 열리면 데드볼트가 문틀 구멍에 정확히 들어가도록 받침쇠 위치를 맞춥니다. / 문이 처졌다면 경첩도 함께 조정합니다.
도어락이 너무 오래돼 부품이 닳았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 받침쇠만 맞춰도 해결되는 경우가 많아 무조건 바꾸자고 하지 않습니다.

# 관고동 말고 이천 어디든
관고동은 물론 중리동, 증포동, 송정동과 부발읍, 장호원읍, 마장면, 신둔면, 백사면까지 이천 전 지역을 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
