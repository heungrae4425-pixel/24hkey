# 관고동, 집 현관보다 바깥문에서 먼저 막혔다면
관고동은 이천 시내와 가까워 주택, 상가주택, 빌라가 골목마다 섞여 있는 동네입니다. / 이런 동네는 집 현관에 닿기 전에 대문이나 계단 입구 철문을 한 번 더 지나야 하는 집이 많습니다.
현관 도어락은 멀쩡한데 바깥 철문이 안 열려 골목에 서 있게 되면 생각보다 막막합니다. / 담 너머로 집이 보이는데 들어갈 수가 없으니까요.
이 글은 관고동에서 바깥문이 막혔을 때 문 종류별로 무엇을 먼저 볼지 정리했습니다. / 누가 관리하는 문인지에 따라 연락할 곳이 달라지는 점도 함께 적었습니다.
@ 관고동 주택 대문 철문 공동 출입문 출장열쇠

# 관고동 바깥문은 대개 세 가지입니다
같은 철문이라도 쓰임에 따라 잠금 방식과 관리하는 사람이 다릅니다. / 우리 집 바깥문이 어느 쪽인지 먼저 떠올려 보세요.
- 단독주택 대문: 집주인 가족만 쓰고, 번호키나 열쇠 자물쇠가 달린 경우가 많음
- 상가주택 계단 입구 철문: 1층 가게 옆으로 위층 집에 올라가는 문
- 빌라 공동 출입문: 여러 세대가 함께 쓰고, 번호키나 인터폰으로 여는 문
대문이라면 내가 직접 관리하는 문이고, 공동 출입문은 건물 관리하시는 분이 따로 있는 경우가 많습니다.

# 누가 관리하는 문인지 먼저 가리기
여러 집이 함께 쓰는 문은 내 마음대로 자물쇠를 바꾸거나 손볼 수 없습니다. / 상가주택 계단 철문은 건물주가, 빌라 공동 출입문은 집주인이나 관리하시는 분이 맡는 경우가 대부분입니다.
이런 문이 막혔다면 같은 건물 이웃이나 관리하시는 분께 먼저 연락해 보세요. / 번호가 바뀌었는데 공지를 못 받았을 수도 있습니다.
저희가 공용 문을 열 때는 관리하시는 분 확인을 거칩니다. / 확인이 어려운 늦은 밤이라면 상황을 먼저 말씀해 주세요.

# 대문 번호키가 꺼졌을 때
대문 번호키는 비바람을 직접 맞아 현관 도어락보다 배터리가 빨리 닳고 고장도 잦은 편입니다. / 번호판이 아예 안 켜진다면 배터리부터 의심해 보세요.
대문 번호키에도 바깥 아래쪽에 비상 전원 단자가 있는 제품이 많습니다. / 9V 건전지를 대고 번호를 누르면 열리는 경우가 있으니 손전등으로 단자 위치를 찾아보세요.
단자가 녹슬어 있거나 건전지를 대도 반응이 없다면 그때 연락 주세요. / 열린 뒤에는 배터리를 모두 새것으로 바꾸고 접점을 닦아 둡니다.

# 철문 손잡이 자물쇠가 헛돌 때
상가주택 계단 철문에는 손잡이와 열쇠 구멍이 한 몸인 자물쇠가 많습니다. / 열쇠는 도는데 문이 안 열리거나 손잡이가 힘없이 헛돈다면 안쪽 연결 부품이 빠졌거나 닳은 것입니다.
이럴 때는 손잡이를 세게 돌리거나 당기지 마세요. / 남은 부품마저 상하면 여는 데 시간이 더 걸립니다.
열쇠가 안 들어가거나 끝까지 안 돈다면 열쇠 구멍에 먼지나 녹이 찼을 수 있습니다. / 마른 윤활제를 조금 넣어 보고, 그래도 안 되면 힘을 더 주지 마세요.
@ 관고동 상가주택 계단 철문 자물쇠 점검

# 오래된 철문이 끝까지 안 닫힐 때
오래 쓴 철문은 무게 때문에 경첩 쪽이 처지면서 바닥에 끌리거나 문틀에 걸립니다. / 끝까지 안 닫히면 자물쇠가 걸리지 않아 문이 잠기지 않습니다.
빌라 공동 출입문이 이렇게 덜 닫힌 채 있으면 다른 세대도 불편을 겪습니다. / 관리하시는 분께 알리고 경첩과 도어클로저 점검을 함께 받는 것이 좋습니다.
대문이라면 문 아래 바닥에 긁힌 자국이 있는지 보세요. / 자국이 있다면 처짐이 꽤 진행된 것입니다.
문을 들어 올리듯 손잡이를 살짝 위로 당기면서 닫으면 걸리지 않고 닫히는지도 확인해 보세요. / 그렇게 해서 닫힌다면 경첩 쪽 처짐이 원인이라는 뜻입니다.

# 인터폰으로 여는 공동 출입문
인터폰 버튼으로 여는 공동 출입문은 전기로 잠금이 풀리는 장치가 달려 있습니다. / 정전이 되거나 이 장치가 고장 나면 인터폰을 눌러도 문이 안 열립니다.
이런 문은 건물 전체 설비라 관리하시는 분이 업체를 정해 손보는 경우가 많습니다. / 저희는 당장 들어가셔야 하는 상황이라면 확인을 거쳐 문을 여는 쪽을 맡습니다.

# 겨울을 앞둔 철문
날이 추워지면 비에 젖은 철문 자물쇠 안쪽이 밤새 얼어 아침에 열쇠가 안 들어가는 일이 생깁니다. / 손으로 감싸 녹이거나 해가 들 때까지 기다리면 풀리는 경우가 많습니다.
드라이기 따뜻한 바람을 자물쇠 구멍 쪽에 잠깐 대 주는 방법도 있습니다. / 뜨거운 물을 붓는 것은 피해 주세요. / 잠깐 녹아도 물이 다시 얼어 더 단단하게 막히고, 녹이 빨리 슨다는 문제도 있습니다.
겨울 전에 자물쇠 구멍에 마른 윤활제를 조금 넣어 두면 얼어붙는 일을 줄일 수 있습니다.

# 담 넘기와 문 흔들기는 그만
담이나 대문 위로 넘어가려는 생각은 접어 주세요. / 대문 위 장식이나 철망에 걸려 다치기 쉽고, 이웃에게 오해를 살 수도 있습니다.
철문을 앞뒤로 세게 흔드는 것도 좋지 않습니다. / 걸쇠가 받침에 더 깊이 물리고 경첩 나사가 풀려 처짐이 심해집니다.

# 위치 알려 주실 때
관고동 골목은 비슷한 주택이 이어져 있어 번지와 함께 눈에 띄는 표시를 알려 주시면 찾기 쉽습니다. / 아래 내용을 같이 말씀해 주세요.
- 대문, 계단 철문, 공동 출입문 중 어떤 문인지
- 1층 가게 이름 대신 업종이나 간판 색 같은 표시
- 번호키인지, 열쇠 자물쇠인지, 인터폰 문인지
- 차를 세울 수 있는 곳이 있는지
문 사진을 먼저 보내 주시면 맞는 장비를 챙겨 갑니다.

# 확인과 비용
대문은 사시는 분이 맞는지 신분증이나 주소가 나온 우편물로 확인합니다. / 공용 출입문은 관리하시는 분 확인까지 거칩니다.
비용은 문 상태를 보고 시작 전에 먼저 말씀드리고, 끝내 못 열면 받지 않습니다. / 진행 순서는 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.
@ 관고동 대문 번호키 비상 전원 확인 후 열기

# 연 뒤에 손보면 좋은 것
대문 번호키가 오래돼 자주 꺼진다면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 부품을 구하기 어려우면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 열쇠 자물쇠가 닳았다면 [열쇠 출장](key-call.html)으로 실린더만 바꾸는 방법도 있습니다.
처진 철문은 경첩을 조이고 받침 위치를 맞춰 끝까지 닫히게 해 둡니다. / 그래야 잠금이 제대로 걸립니다.
공동 출입문 쪽 손볼 일이 보이면 관리하시는 분께 전할 수 있게 상태를 사진과 함께 정리해 드립니다. / 무엇을 왜 손봐야 하는지 알면 이웃과 상의하기도 쉬워집니다.

# 관고동 말고 이천 어디든
관고동 옆 중리동, 증포동, 송정동부터 부발읍, 장호원읍, 마장면, 신둔면, 백사면까지 이천 전 지역을 다닙니다. / 읍면은 위치를 받고 도착 시간을 먼저 말씀드립니다. [이천시 출장열쇠](icheon.html)와 [출장 지역](area.html)에서 보실 수 있습니다.
