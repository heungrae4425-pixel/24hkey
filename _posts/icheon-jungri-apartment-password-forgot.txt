# 중리동 아파트, 번호가 기억나지 않거나 안 먹힐 때
이사한 지 얼마 안 됐거나 번호를 오랫동안 바꾸지 않다 보면 어느 날 갑자기 번호가 떠오르지 않을 때가 있습니다. / 분명 맞게 눌렀는데 문이 반응하지 않으면 당황스럽고 마음이 급해집니다.
중리동처럼 아파트가 모여 있는 동네는 현관 도어락이 대부분 번호 방식이라 이런 일이 자주 생깁니다. / 이 글은 [이천 출장열쇠](icheon.html)를 부르기 전에 확인할 것과 진행 순서를 정리했습니다.
지금 문 앞이라면 4번 소제목부터 보셔도 됩니다.
@ 중리동 아파트 도어락 비밀번호 출장열쇠

# 번호가 안 먹힐 때 가능한 원인
- 번호를 정확히 기억하지 못하는 경우
- 배터리가 약해 입력이 제대로 전달되지 않는 경우
- 번호판에 손때나 물기가 있어 눌림이 불안정한 경우
- 여러 번 틀려 일정 시간 입력이 막힌 경우
번호가 틀렸다고 단정하기 전에 배터리와 번호판 상태부터 살펴보세요. / 같은 번호를 여러 번 반복해서 누르면 오히려 입력이 잠기는 모델도 있습니다.

# 먼저 천천히 한 번만 다시 눌러 보세요
급할수록 번호를 빠르게 연타하게 됩니다. / 한 자리씩 천천히 누르고 끝 버튼이나 별표 버튼을 눌러야 하는 모델인지 확인해 보세요.
번호판을 마른 천으로 가볍게 닦고 다시 시도하면 되는 경우도 있습니다. / 서너 번 해 보고 안 되면 멈추는 편이 좋습니다.
잠금 상태가 되었다면 몇 분 기다린 뒤 다시 해 보세요.
술을 마시고 늦게 들어왔거나 피곤한 밤에는 번호가 평소보다 더 헷갈립니다. / 그럴 때는 잠깐 숨을 돌리고 문 앞 계단이나 복도에서 마음을 가라앉힌 뒤 다시 떠올려 보세요.
손으로 번호를 누르던 순서를 허공에 그려 보면 기억이 되살아나는 경우도 있습니다. / 그래도 떠오르지 않으면 무리하지 말고 다른 방법으로 넘어가세요.

# 가족이 번호를 알고 있는지 확인하세요
함께 사는 가족이나 번호를 알려준 분에게 먼저 연락해 보세요. / 집 안에 가족이 있다면 안쪽에서 문을 열어 줄 수 있습니다.
예전에 번호를 메모해 두었거나 휴대폰에 저장해 둔 적이 없는지도 떠올려 보세요. / 이전에 살던 분의 번호가 그대로 남아 있는 경우도 있어 입주 시 번호를 바꿨는지도 생각해 보세요.
@ 중리동 도어락 번호 입력 잠김 이천 출동

# 열쇠나 카드 방법이 있다면
많은 도어락은 번호 외에 카드나 열쇠로도 열 수 있게 되어 있습니다. / 카드키가 있다면 번호판 위에 대 보시고, 열쇠 구멍이 있다면 보조 열쇠로 열어 보세요.
카드나 열쇠 방법이 없는 모델이라면 번호를 알아야 열 수 있습니다. / 이럴 때는 억지로 건드리지 말고 연락 주세요.

# 하지 말아야 할 일
번호를 알아내려고 가능한 숫자를 계속 눌러 보는 것은 입력 잠금을 부를 수 있습니다. / 번호판을 분해하거나 드라이버로 비집는 것도 피해 주세요.
문을 발로 차거나 어깨로 미는 것은 문과 문틀을 상하게 합니다. / 아파트는 소리가 크게 울려 이웃에게도 놀라움을 줄 수 있습니다.
도어락에 물이나 세척제를 뿌리면 회로가 상할 수 있으니 하지 마세요.

# 전화하실 때 알려주실 것
- 중리동 안에서 어느 쪽 아파트인지, 동과 호수
- 번호판이 켜지는지, 소리가 나는지
- 번호판 위에 제조사 이름이 보이는지
- 열쇠 구멍이나 카드를 대는 곳이 있는지
- 집 안에 사람이나 반려동물이 있는지
사진을 보내주시면 모델을 가려 준비할 수 있어 더 빠릅니다. / 위치를 받으면 예상 도착 시간을 먼저 말씀드립니다.

# 도착하면 사시는 분인지 확인합니다
아파트는 이웃 집과 가까워 더욱 확인을 꼼꼼히 합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다. / 관리사무소가 문을 닫은 시간이라면 우편물이나 고지서를 준비해 주세요.
이사 온 지 얼마 되지 않았다면 계약서나 입주 안내문도 도움이 됩니다. / 휴대폰에 저장된 공과금 고지서 화면을 보여주셔도 확인에 쓸 수 있습니다.
세입자라면 집주인과 통화로 확인하는 방법도 함께 안내해 드립니다. / 서류가 하나도 없다면 어떤 방법이 가능한지 전화로 먼저 상의해 주세요. 방법을 같이 찾아 드립니다.

# 비용은 손대기 전에 말씀드립니다
도어락 상태와 필요한 작업을 본 뒤 얼마가 드는지 먼저 알려드립니다. / 괜찮다고 하시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 설명 없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 문을 연 뒤에는 번호를 새로 정합니다
문이 열리면 번호를 새로 등록해 다시 쓸 수 있게 해 드립니다. / 쉽게 짐작되는 번호는 피하고 기억하기 쉬운 새 번호를 정해 보세요.
번호를 가족과 어떻게 공유할지도 같이 이야기하시면 같은 일이 반복되지 않습니다. / 배터리도 이때 한꺼번에 새것으로 바꾸는 것을 권합니다.
새 번호를 정한 뒤에는 문을 연 채로 안쪽에서 한 번, 바깥에서 한 번 직접 눌러 확인해 보시면 안심이 됩니다. / 문이 닫힌 뒤에 번호가 맞는지 모르는 상황을 만들지 않기 위해서입니다.
가족이 여러 명이라면 모두가 같은 번호를 쓰는지, 각자 다른 방법으로 열 수 있는지도 같이 정리해 두세요.
문 열림 방식은 [현관문 개문](door-open.html)에서 확인하실 수 있습니다.
@ 중리동 도어락 번호 재설정 이천 출장열쇠

# 도어락 자체가 문제라면
번호가 맞는데도 안 열린다면 도어락 본체나 모터 쪽 문제일 수 있습니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)로 먼저 고쳐 보고 어려우면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
고쳐서 쓸 수 있는데 바꾸라고 권하지 않습니다. / 새로 다는 일은 [도어락 설치](doorlock-install.html) 페이지를 참고하세요.

# 번호를 오래 기억하는 방법
- 번호를 가족 둘 이상이 알고 있게 하기
- 휴대폰에 번호를 직접 저장하지 말고 믿을 수 있는 방식으로 따로 기록하기
- 번호를 바꿨다면 그날 가족에게 알리기
- 열쇠나 카드 방법을 항상 하나 더 살려 두기
번호 하나에만 의지하지 않는 것이 문 앞에서 막히지 않는 길입니다. / 배터리 경고음이 나면 그날 바로 교체하는 습관도 같이 들이시면 좋습니다.

# 중리동 말고 이천 어디든 갑니다
중리동 가까운 증포동, 관고동, 송정동은 물론 부발읍까지 출동합니다. / 이천시 안이면 24시간 연락을 받습니다.
다니는 동네는 [이천시 출장열쇠](icheon.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
