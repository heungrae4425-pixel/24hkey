# 중리동, 어제까지 되던 번호가 안 먹힐 때
퇴근해서 늘 누르던 번호를 눌렀는데 짧은 경고음만 울리고 문이 열리지 않습니다. / 몇 번을 다시 눌러도 마찬가지라면 누군가 번호를 바꿨을 가능성을 먼저 떠올려 보세요.
중리동은 이천역과 가까운 시내 쪽으로 아파트가 많이 모여 있는 동네입니다. / 가족 여럿이 함께 사는 집이 많다 보니 누가 언제 번호를 바꿨는지 서로 엇갈리는 일이 생깁니다.
이 글은 이천 중리동에서 가족이 바꾼 번호를 몰라 못 들어가거나, 직접 바꾼 번호가 기억나지 않을 때 차례로 해볼 일을 정리했습니다. / 끝까지 안 되면 [이천 출장열쇠](icheon.html)로 연락 주세요.
@ 중리동 아파트 도어락 비밀번호 변경 모름

# 누가 바꿨을지 먼저 떠올려 보세요
번호는 갑자기 바뀌지 않습니다. / 최근 며칠 사이에 누가 번호를 바꿀 만한 일이 있었는지 생각해 보세요.
- 택배나 손님 때문에 번호가 노출됐다고 걱정한 가족
- 사춘기 자녀가 친구에게 번호를 알려 준 뒤 몰래 바꾼 경우
- 부모님이 보안 때문에 바꾸고 깜빡한 경우
- 배우자가 바꾸고 단체 대화방에 올렸는데 못 본 경우
가족 단체 대화방이나 문자 기록을 먼저 확인해 보세요. / 의외로 이미 알려 줬는데 못 보고 지나친 경우가 많습니다. / 대화방 검색창에 번호나 비밀번호라는 단어를 넣어 찾아보면 지나간 메시지도 금방 나옵니다.
관리사무소에서 세대 점검이나 공사가 있었는지도 한 번 떠올려 보세요. / 집 안 작업 때문에 가족이 임시로 번호를 바꿔 두었다가 원래대로 돌려놓지 않은 경우도 있습니다.

# 가족에게 연락하는 순서
집에 있을 가능성이 높은 가족부터 전화를 걸어 보세요. / 안에 누가 있다면 번호를 몰라도 문을 열어 줄 수 있습니다.
번호를 바꾼 사람이 누군지 모르겠다면 가족 모두에게 같은 내용을 한 번에 보내는 것이 빠릅니다. / 누가 바꿨는지 따지기보다 지금 번호가 뭔지만 묻는 게 대답이 빨리 옵니다.
가족이 출근 중이거나 연락이 안 된다면 언제쯤 통화가 될지 가늠해 보세요. / 한두 시간 안에 연락이 닿을 것 같으면 근처에서 기다리는 것도 방법입니다. / 다만 아이를 데리러 가야 하거나 날씨가 궂어 밖에서 오래 기다리기 어렵다면 무리하지 말고 바로 연락 주세요.

# 내가 바꾼 번호가 기억나지 않을 때
본인이 바꿨는데 기억나지 않는 경우도 생각보다 많습니다. / 바꾸고 나서 며칠 안 썼거나, 바꾼 직후 다른 일에 정신이 팔렸을 때 특히 그렇습니다.
바꿀 때 무엇을 기준으로 정했는지 떠올려 보세요. / 가족 생일, 예전 집 호수, 휴대폰 번호 일부처럼 평소에 쓰던 숫자 조합에서 나온 경우가 많습니다.
다만 이것저것 계속 눌러 보는 건 좋지 않습니다. / 여러 번 틀리면 도어락이 일정 시간 입력을 막아 버립니다.

# 입력이 잠겼다면 기다려야 합니다
번호를 여러 번 틀리면 도어락이 경고음을 내며 잠시 입력을 받지 않습니다. / 이때 계속 누르면 잠금 시간이 늘어나는 제품도 있습니다.
잠금이 걸렸다면 번호판에서 손을 떼고 몇 분 기다려 주세요. / 그 사이에 가족에게 연락을 이어 가는 편이 낫습니다.
잠금이 풀린 뒤 시도할 번호는 많아야 한두 개로 정해 두세요. / 그래도 안 되면 그때 바로 연락 주시면 됩니다. / 경고음이 몇 번 울렸는지, 잠금이 얼마나 지속됐는지 기억해 두시면 제품을 짐작하는 데 도움이 됩니다.
@ 이천 중리동 도어락 번호 오류 입력 잠금

# 번호 말고 다른 열림 방법 찾기
번호 외에 카드나 태그, 지문으로도 열리는 도어락이라면 그 방법을 먼저 써 보세요. / 지갑이나 열쇠고리에 카드가 붙어 있는지 확인해 보시면 좋습니다.
비상용 기계식 열쇠가 있는 제품이라면 열쇠가 어디 있는지 떠올려 보세요. / 집 안에 있다면 소용이 없지만 차 안이나 가족에게 맡겨 둔 경우도 있습니다.
휴대폰 앱과 연동된 제품이라면 앱으로 원격 열림이 되는지 확인합니다. / 연동이 안 되어 있다면 이 방법은 쓸 수 없습니다. / 가족 중 한 명만 앱에 등록돼 있다면 그분께 원격으로 열어 달라고 부탁해 보세요.

# 이런 시도는 하지 마세요
- 번호를 생각나는 대로 계속 눌러 보기
- 번호판을 뜯어 초기화 버튼을 찾으려 하기
- 손잡이를 세게 흔들거나 문틈을 벌리기
- 인터넷에서 본 방법으로 몸체를 열어 보기
바깥 번호판을 뜯어도 초기화는 안쪽 몸체에서만 되는 제품이 대부분입니다. / 괜히 번호판만 상하고 들어가지는 못하게 됩니다. / 번호판 아래 비상 단자에 9V를 대는 것은 전원이 꺼졌을 때만 쓰는 방법이라 번호를 모를 때는 도움이 되지 않습니다.

# 가족 갈등으로 번지지 않게
번호를 바꾸고 말을 안 해 준 가족에게 화가 나는 건 당연합니다. / 그래도 지금은 문을 여는 게 먼저이니 이야기는 들어간 뒤에 천천히 나누세요.
이번 일을 계기로 번호를 바꿀 때 어떻게 공유할지 가족끼리 정해 두면 좋습니다. / 바꾼 사람이 그날 단체 대화방에 올리고, 모두 읽었다고 답하는 식으로 정하면 엇갈리는 일이 줄어듭니다.

# 연락 주실 때 알려 주실 것
- 중리동 아파트 동, 호수
- 번호가 바뀐 것 같은지, 내가 잊은 것인지
- 입력 잠금 경고음이 났는지
- 카드나 지문 같은 다른 방법이 있는지
- 집 안에 아이나 반려동물이 있는지
도어락 정면 사진을 보내 주시면 제품을 보고 맞는 방법을 미리 준비합니다. / 언제부터 번호가 안 먹혔는지, 오늘 아침 나갈 때는 됐는지도 함께 말씀해 주세요.

# 문 열기 전 거주 확인
번호를 모르는 상황이라 사시는 분인지 확인하는 일이 꼭 필요합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 세대 확인 중 하나를 준비해 주세요.
가족이 번호를 바꾼 경우라도 확인 절차는 같습니다. / 자세한 내용은 [이용안내](guide.html)에 있습니다.

# 비용은 손대기 전에, 못 열면 없음
도어락 종류와 상태를 보고 비용을 먼저 말씀드립니다. / 동의하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 상하지 않게 여는 방법부터 시도하고, 끝내 못 열면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 중리동 현관문 개문 비밀번호 재등록

# 문을 연 뒤 번호 다시 정하기
문이 열리면 안쪽 몸체에서 새 번호를 등록하고 예전 번호는 지웁니다. / 새 번호는 그 자리에서 가족 모두에게 알리고 한 번씩 눌러 보게 하세요.
번호를 자주 잊는 가족이 있다면 카드나 지문을 함께 쓰는 설정도 도와드립니다. / 도어락이 오래돼 설정이 잘 안 된다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 상황에 맞게 말씀드립니다.

# 중리동 말고 이천 어디든
중리동은 물론 증포동, 관고동, 송정동 아파트와 부발읍, 장호원읍, 마장면, 신둔면, 백사면 주택까지 이천 전 지역을 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 문을 연 뒤 카드도 등록해 주시나요? | 네, 제품이 지원하면 카드나 지문 등록도 같이 해드립니다.
