# 마장면에서는 열쇠집 고르는 기준이 조금 다릅니다
마장면은 마을과 논밭 사이로 주택과 물류 창고, 작은 공장 사무실이 넓게 흩어져 있는 면 지역입니다. / 시내처럼 걸어갈 만한 열쇠 가게가 가까이 있지 않아 문이 잠기면 대부분 출장을 부르게 됩니다.
출장을 부를 때는 도심과 달리 거리와 도착 시간이 가장 큰 변수가 됩니다. / 여기에 창고 철문, 오래된 주택 대문처럼 문 종류도 다양해서 아무 곳에나 맡기기보다 몇 가지는 확인하고 부르는 것이 좋습니다.
이 글은 마장면처럼 시내에서 떨어진 곳에서 출장 열쇠집을 고를 때 따져볼 기준을 정리했습니다. / 저희 출동 안내는 [이천 출장열쇠](icheon.html)에 있습니다.
@ 이천 마장면 주택 창고 출장 열쇠집 선택

# 기준 하나, 도착 시간을 솔직하게 말하는가
면 지역은 기사가 어디서 출발하느냐에 따라 도착 시간이 크게 달라집니다. / 위치를 듣지도 않고 금방 간다고 하는 곳보다, 주소를 확인한 뒤 예상 시간을 말해 주는 곳이 믿을 만합니다.
도착이 늦어질 것 같으면 미리 연락해 주는지도 물어보세요. / 마냥 기다리게 하는 것보다 중간에 상황을 알려 주는 곳이 덜 답답합니다.
급한 사정이 있다면 처음 통화에서 말씀하세요. / 몇 시까지 문을 열어야 하는지 알면 그 시간에 맞출 수 있는지 솔직하게 답할 수 있습니다.

# 기준 둘, 우리 집 문을 다뤄 본 곳인가
마장면에는 아파트 현관보다 단독주택 대문, 창고 철문, 샷시 출입문 같은 문이 많습니다. / 도어락만 주로 다루는 곳이라면 열쇠식 자물쇠나 철문 빗장 앞에서 준비가 부족할 수 있습니다.
전화할 때 문 종류를 말하고, 그런 문도 작업하는지 물어보세요. / 사진을 보내 달라고 먼저 요청하는 곳이라면 준비를 꼼꼼히 하는 편이라고 볼 수 있습니다.
창고나 사무실이라면 사업장 문도 출동하는지, 사용자 확인은 어떻게 하는지도 같이 물어보시면 됩니다. / 대문과 현관이 함께 잠긴 주택이라면 두 문을 한 번에 볼 수 있는지도 확인해 두세요.

# 기준 셋, 비용을 언제 알려 주는가
멀리서 오는 출장일수록 비용이 어떻게 정해지는지 미리 알고 싶은 것이 당연합니다. / 비용을 문을 본 뒤 작업 전에 알려 주는지, 아니면 작업이 끝난 뒤에 말하는지 꼭 물어보세요.
작업 전에 듣고 동의할 수 있어야 마음 편히 맡길 수 있습니다. / 듣고 나서 생각해 보겠다고 했을 때 어떻게 되는지도 물어볼 만합니다.
@ 마장면 창고 철문 자물쇠 상태 확인

# 기준 넷, 못 열었을 때 어떻게 되는가
먼 거리를 왔는데 문을 못 열었다면 비용이 어떻게 되는지는 중요한 질문입니다. / 이 질문에 분명하게 답하지 않는 곳은 한 번 더 생각해 보세요.
저희는 문을 열지 못하면 비용을 받지 않습니다. / 거리가 멀었다는 이유로 원칙이 달라지지 않습니다.
다른 곳에 물어볼 때도 출장 비용만 따로 받는지, 아예 받지 않는지를 분명히 들어 두세요. / 나중에 말이 달라지지 않도록 통화 내용을 문자로 한 번 확인받아 두는 것도 방법입니다.

# 기준 다섯, 확인 절차가 있는가
면 지역은 이웃끼리 서로 아는 경우가 많아 확인 절차를 번거롭게 느끼실 수 있습니다. / 하지만 사는 사람인지, 사업장 사용자인지 확인하는 곳이어야 남의 문도 쉽게 열지 않는다는 뜻입니다.
주택이라면 신분증 주소나 우편물, 이웃이나 이장님 확인으로 진행합니다. / 창고나 사무실이라면 사업자 서류, 임대차 계약서, 관리인 확인처럼 사용자임을 보여 주는 것이 필요합니다.

# 기준 여섯, 상하지 않게 여는 것을 먼저 이야기하는가
처음부터 뚫거나 부수자고 하는 곳보다, 문 상태를 보고 덜 상하는 방법부터 설명하는 곳이 낫습니다. / 창고 철문이나 오래된 대문은 한 번 상하면 다시 맞추기가 쉽지 않습니다.
다른 방법이 필요하다면 손대기 전에 어떤 손상이 생길 수 있는지 미리 말해 주는지도 보세요. / 개방 방식은 [현관문 개문](door-open.html)에 정리했습니다.

# 첫 통화에서 이렇게 말해 보세요
마장면 위치는 주소만으로 찾기 어려운 곳이 있어 설명이 중요합니다.
- 마을 이름이나 가까운 큰길, 눈에 띄는 창고나 건물
- 문 종류: 주택 현관 도어락, 대문, 창고 철문, 사무실 문
- 지금 상태: 번호판 꺼짐, 열쇠 분실, 자물쇠 걸림
- 꼭 열어야 하는 시간이 있는지
- 차를 세울 곳이 있는지
이 다섯 가지를 먼저 말하고 위의 기준들을 물어보시면 됩니다. / 길지 않은 통화로도 맡길지 말지 판단하기 충분합니다.
@ 마장면 출장열쇠 첫 통화 위치 설명

# 도착한 뒤 살펴볼 것
기사가 도착하면 바로 손대기보다 문을 살피고 방법과 비용을 먼저 설명하는지 보세요. / 설명이 납득되면 그때 시작하시면 됩니다.
작업 중에 부품을 바꿔야 한다는 말이 나오면 무엇이 왜 필요한지 물어보세요. / 고쳐 쓸 수 있는데 교체부터 권한다면 한 번 더 확인해 볼 만합니다.
수리 기준은 [도어락 수리](doorlock-repair.html), 교체 기준은 [도어락 교체](doorlock-replace.html)에 적어 두었습니다.

# 미리 번호를 저장해 두면 좋은 이유
면 지역에서는 문이 잠긴 뒤에 검색하면 어디가 실제로 이곳까지 오는지 알기 어렵습니다. / 낮에 여유 있을 때 위 기준으로 알아본 곳의 번호를 휴대폰에 저장해 두세요.
창고나 사무실이라면 직원들이 함께 볼 수 있는 곳에 연락처를 붙여 두는 것도 방법입니다. / 관리자가 없을 때 누구라도 바로 연락할 수 있습니다. / 부모님 댁이 마장면에 있다면 자녀분 휴대폰에도 같은 번호를 저장해 두시면 멀리서도 대신 연락해 드릴 수 있습니다.

# 문이 잠기기 전에 해 둘 것
도어락 배터리는 경고음이 나면 그날 바로 바꾸세요. / 시내와 먼 곳일수록 막혔을 때 기다리는 시간이 길어지니 미리 챙기는 것이 가장 좋은 대비입니다.
열쇠식 자물쇠라면 여벌 열쇠를 집 밖 믿을 만한 곳에 하나 맡겨 두세요. / 창고는 관리자 말고도 한 사람이 더 열쇠 위치를 알고 있게 하면 좋습니다. / 대문 자물쇠가 뻑뻑해지기 시작했다면 완전히 멈추기 전에 낮 시간에 점검을 받아 두는 것이 밤에 부르는 것보다 훨씬 수월합니다.

# 저희가 약속하는 것
24시출장열쇠는 위치를 들은 뒤 예상 도착 시간을 먼저 말씀드립니다. / 문을 본 뒤 작업 전에 비용을 알려 드리고, 동의하실 때만 시작하며, 열지 못하면 받지 않습니다.
사시는 분이나 사업장 사용자인지 확인한 뒤에 엽니다. / 진행 방식 전체는 [이용안내](guide.html)에 있습니다.

# 마장면 말고 이천 어디든
마장면과 함께 신둔면, 백사면, 부발읍, 장호원읍은 물론 중리동, 증포동, 관고동, 송정동 시내까지 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

? 창고 철문 자물쇠도 다루시나요? | 네, 사진을 보내 주시면 맞는 장비를 챙겨 갑니다.
