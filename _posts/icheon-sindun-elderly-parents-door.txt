# 신둔면 부모님 댁 현관, 안녕하신가요
신둔면에는 오래 사신 어르신들이 계신 주택과 작은 마을이 많고, 도자기 마을로 이름난 동네의 조용한 분위기가 남아 있습니다. / 멀리 사는 자녀분들이 명절에 내려와 보면 현관 도어락이 예전보다 삐걱댄다는 걸 처음 알게 되는 일이 많습니다.
부모님은 불편해도 "그냥 쓰면 된다"고 하시는 경우가 많아서, 문 앞에서 오래 씨름하신 걸 한참 뒤에야 듣게 됩니다. / 그러다 어느 날 문이 아예 안 열려서 연락이 오기도 합니다.
이 글은 신둔면 부모님 댁 도어락을 점검할 때 눈여겨볼 것과 어르신이 쓰기 편한 설정, 그리고 [이천 출장열쇠](icheon.html)를 부르는 때를 정리했습니다.
@ 이천 신둔면 부모님 댁 도어락 점검 출장열쇠

# 어르신 댁에서 자주 생기는 불편
어르신들은 번호를 외우는 일보다 손끝 감각이 달라진 것 때문에 불편해하시는 경우가 많습니다. / 버튼을 눌러도 눌렀는지 모르겠다거나, 번호판이 어두워서 안 보인다고 하십니다.
도어락이 열렸다는 소리가 작아서 문이 잠겼는지 안 잠겼는지 헷갈리는 일도 있습니다. / 그러면 문을 잠그지 않고 외출하거나 반대로 안 열린 줄 알고 계속 누르다 입력 제한이 걸리기도 합니다.
열쇠식 자물쇠를 오래 쓰신 집은 열쇠를 돌리는 힘이 약해져서 뻑뻑한 문이 큰 부담이 됩니다. / 손목이 아프신 분께는 손잡이 형태도 중요합니다.

# 방문해서 확인해 볼 다섯 가지
부모님 댁에 갔을 때 5분만 투자해서 아래를 보세요.
- 번호판이 환하게 켜지는지, 버튼 소리가 또렷한지
- 배터리 교체 시기가 언제였는지 기억하는 사람이 있는지
- 문이 부드럽게 닫히고 걸쇠가 제대로 들어가는지
- 열쇠식이라면 열쇠가 끝까지 부드럽게 들어가는지
- 안쪽 손잡이를 쉽게 돌릴 수 있는지
이 중 하나라도 어색하면 불편이 시작되었다는 신호입니다. / 한 번에 모두 고치려 하지 말고 배터리부터 점검해 보세요.

# 배터리부터 새것으로
도어락 불편의 많은 부분이 배터리 부족에서 옵니다. / 반응이 느리거나 번호판이 흐릿하면 건전지를 전부 새것으로 바꿔 보는 것만으로 좋아지는 경우가 많습니다.
어르신 혼자 사는 집은 경고음이 나도 무슨 뜻인지 모르고 지나치는 일이 있습니다. / 자녀가 한 번에 바꿔 드리고 배터리 칸에 교체한 날짜를 적어 두면 좋습니다.
9V 건전지를 현관 근처 서랍에 하나 넣어 두시는 방법도 있습니다. / 번호판이 꺼졌을 때 바로 비상 전원을 댈 수 있어서 마음이 편합니다.
@ 신둔면 현관 도어락 배터리 교체 점검

# 어르신이 쓰기 편한 방식 고르는 법
도어락은 번호식, 카드식, 지문식 등 여러 방식이 있습니다. / 어르신이 어떤 방식에 익숙하신지가 제일 중요합니다.
번호를 잘 기억하시면 번호식이 단순하고, 번호가 어려우시면 카드나 태그를 목걸이처럼 걸어 두는 방법도 있습니다. / 지문은 손이 건조하거나 거칠어지면 잘 안 읽히는 일이 있어서 따로 번호 입력을 병행하는 것이 안전합니다.
어떤 방식이든 번호판 숫자가 크고 밝은지, 열릴 때 나는 소리가 또렷한지 직접 눌러 보고 고르시는 것이 좋습니다. / 설치 전에는 [도어락 설치](doorlock-install.html)에서 문 두께와 보조키를 확인하는 순서를 보실 수 있습니다.

# 번호를 기억하기 쉽게 정리하기
번호를 바꿀 때는 복잡한 숫자보다 가족이 같이 기억하기 쉬운 규칙을 정해 두는 것이 좋습니다. / 단, 생일처럼 남이 알기 쉬운 숫자는 피하는 것이 안전합니다.
자녀 한두 명이 번호를 같이 알고 있으면 급할 때 대신 열어 드릴 수 있습니다. / 번호를 적어 두는 종이를 현관 근처에 붙여 놓는 것은 피해 주세요.
번호를 바꾼 뒤에는 부모님과 함께 몇 번 열고 잠가 보면서 익숙하게 해드리는 것이 좋습니다. / 처음엔 어색해하셔도 두세 번이면 금방 적응하십니다.

# 이런 신호가 보이면 연락 주세요
어르신 댁 문은 갑자기 안 열릴 때 곤란이 큽니다. / 아래 같은 신호가 보이면 미루지 말고 점검해 두는 것이 좋습니다.
- 번호를 눌러도 한 번에 안 열리고 여러 번 눌러야 할 때
- 문을 닫을 때 걸쇠가 힘겹게 들어갈 때
- 열쇠가 걸리거나 돌릴 때 힘이 많이 들 때
- 경고음이 나는데도 며칠째 그대로일 때
문이 안 열려서 어르신이 혼자 갇혀 계시거나 밖에서 못 들어가고 계신 상황이라면 바로 전화 주세요. / 안전이 걱정되는 상황이면 먼저 가까운 가족이나 이웃에게 알리고 필요하면 119에 연락하는 것이 우선입니다.

# 전화하실 때 알려 주세요
부모님 댁은 마을 안쪽에 있거나 길을 찾기 어려운 경우가 많습니다.
- 마을 이름이나 근처 큰길, 눈에 띄는 가게
- 현관이 대문 안쪽인지 바로 길가인지
- 지금 안에 사람이 계신지, 어르신이 혼자인지
- 도어락 모양과 번호판 상태
어르신께 통화가 어려우시면 자녀분이 대신 전화 주셔도 됩니다. / 그 경우에도 집에 사는 분이 맞는지 확인하는 절차는 같습니다.

# 사시는 분인지 먼저 확인합니다
자녀분이 대신 연락하신 경우에는 가족 관계와 거주자를 확인합니다. / 어르신 신분증, 주소가 나온 우편물, 마을 이장님이나 이웃의 확인 중 가능한 것으로 진행합니다.
번거로우실 수 있지만 어르신 댁을 지키기 위한 절차입니다. / 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.
어르신이 직접 문 앞에 계시면 문 너머로 천천히 말씀을 나누며 안심시켜 드리고 진행합니다.

# 비용은 문을 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마가 드는지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
어르신 댁이라고 해서 불필요한 교체를 권하지 않습니다. / 고쳐서 쓸 수 있으면 먼저 [도어락 수리](doorlock-repair.html)로 손보고, 정말 낡아서 위험하다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 열고 난 뒤 같이 점검합니다
문이 열리면 어르신이 쓰기 편한지 직접 눌러 보며 확인합니다. / 번호판 밝기, 버튼 소리, 손잡이 힘 등을 같이 보고 조절할 수 있는 건 조절합니다.
문을 열었던 방법과 [현관문 개문](door-open.html) 과정도 설명드려서 다음에 당황하지 않으시게 합니다.
@ 신둔면 어르신 댁 현관문 개문 후 점검

# 신둔면 말고 이천 어디든 갑니다
이천은 시내와 읍면이 떨어져 있어도 24시간 출동합니다. / 위치를 받으면 예상 도착 시간을 먼저 말씀드립니다.
이천에서 다니는 동네는 [이천시 출장열쇠](icheon.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
