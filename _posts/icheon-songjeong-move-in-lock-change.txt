# 송정동으로 이사했다면 문부터 점검하세요
새 집에 들어서면 짐 정리와 청소가 먼저 눈에 들어오지만 현관문 상태는 의외로 놓치기 쉽습니다. / 전에 살던 분이 쓰던 번호와 열쇠가 그대로 남아 있을 수 있기 때문입니다.
송정동처럼 주택과 아파트, 빌라가 함께 있는 동네에서는 이사 들어오는 집마다 문 종류가 제각각입니다. / 이 글은 [이천 출장열쇠](icheon.html)를 부르기 전에 이사 직후 확인할 것을 정리했습니다.
이미 문 앞에서 막혔다면 7번 소제목부터 보셔도 됩니다.
@ 송정동 이사 도어락 번호 변경 출장열쇠

# 전 입주자의 번호가 남아 있을 수 있습니다
이사를 나간 분이 번호를 어떻게 정리했는지 알 수 없는 경우가 많습니다. / 중개인이나 집주인이 알려준 번호가 그대로 등록되어 있는 집도 흔합니다.
그 번호를 알고 있는 사람이 여러 명일 수 있으니 이사 첫날 바로 바꾸는 것이 마음 편합니다. / 열쇠도 마찬가지로 전 입주자가 복사해 둔 것이 있을 수 있습니다.
특히 입주 전에 인테리어나 청소 업체가 드나들었다면 번호를 아는 사람이 더 늘었을 수 있습니다.

# 이사 첫날 확인할 것
- 도어락 번호를 새로 등록하고 이전 번호가 지워졌는지 확인하기
- 열쇠나 카드가 몇 개인지, 누가 갖고 있는지 정리하기
- 배터리를 전부 새것으로 바꾸고 경고음이 나는지 확인하기
- 문이 부드럽게 닫히고 잠기는지, 걸쇠가 끝까지 들어가는지 보기
- 보조키가 있다면 실제로 돌아가는지 한 번 사용해 보기
이 다섯 가지만 해 두면 이사 후 밤에 문 앞에서 당황하는 일이 크게 줄어듭니다.

# 번호를 바꾸는 방법은 모델마다 다릅니다
설명서가 없으면 어떻게 바꾸는지 몰라 헤매는 경우가 많습니다. / 제조사와 모델에 따라 등록 방식이 다르니 번호판 위 표시나 안쪽 뚜껑 안의 버튼을 살펴보세요.
관리자 번호를 모르는 상태라면 새 번호 등록이 막혀 있을 수 있습니다. / 이럴 때는 억지로 이것저것 눌러 보지 말고 연락 주세요.
설정을 잘못 건드리면 문이 안 열리는 상황이 생길 수 있어 문을 열어 둔 채 시도하는 것이 안전합니다.
@ 송정동 새집 도어락 설정 이천 출동

# 문을 열어 둔 채로 시험해 보세요
번호를 바꿀 때는 문을 열어 둔 상태에서 안쪽과 바깥쪽을 번갈아 눌러 보세요. / 문이 닫힌 뒤 번호가 맞는지 모르는 상황이 가장 위험합니다.
새 번호가 확실히 등록된 것을 확인한 뒤에 문을 닫으세요. / 가족에게도 바로 알려 같이 확인해 두면 더 안심이 됩니다.
번호를 적어 두더라도 눈에 띄는 곳에 두지 않도록 조심하세요.
이사하는 날은 사람이 많이 드나들어 문을 계속 열어 두게 됩니다. / 이삿짐이 모두 들어간 뒤에 번호를 바꾸면 중간에 문이 잠겨 곤란해지는 일을 줄일 수 있습니다.
이삿짐 업체에게는 번호를 알려주지 말고 문을 열어 두는 방식으로 작업하도록 말씀해 두세요.

# 이사 날 문이 안 열릴 때
중개인이 알려준 번호가 안 먹힌다면 먼저 중개인이나 집주인에게 다시 확인해 보세요. / 번호가 바뀌었거나 입력 방법이 다른 모델일 수도 있습니다.
배터리가 이미 약해 번호판이 흐릿한 집도 있으니 불빛이 켜지는지 먼저 보세요. / 모두 해 봐도 안 열리면 문 앞에서 억지로 힘쓰지 말고 연락 주세요.
이삿짐 업체가 기다리고 있다면 그 점도 같이 알려주세요.

# 하지 말아야 할 일
이사 날 급하다고 문을 부수거나 도어락을 분해하는 일은 피해 주세요. / 새 집의 문은 앞으로 오래 써야 하는 문이라 처음부터 상하면 곤란합니다.
번호를 여러 번 틀려 입력이 잠기면 오히려 더 시간이 걸립니다. / 인터넷에서 본 임의의 초기화 방법을 따라 하다가 설정이 엉키는 일도 흔합니다.
집주인 허락 없이 도어락을 바꾸면 나중에 문제가 될 수 있으니 임대라면 먼저 상의하세요.

# 전화하실 때 알려주실 것
- 송정동 안에서 대략 어느 쪽인지, 아파트인지 주택인지
- 번호 도어락인지 열쇠형인지, 제조사 표시가 보이는지
- 입주 날짜와 집주인이나 중개인이 알려준 번호가 있었는지
- 이삿짐 업체가 기다리고 있는지
- 문을 못 여는 상황인지, 번호만 바꾸고 싶은지
사진을 보내주시면 모델을 가려 정확히 준비할 수 있습니다. / 위치를 받으면 예상 도착 시간을 먼저 말씀드립니다.

# 도착하면 사시는 분인지 확인합니다
이사 직후라서 신분증 주소가 아직 이전 집일 수 있습니다. / 새 집 계약서나 입주 안내문, 관리사무소 확인, 집주인과의 통화로도 확인할 수 있습니다.
확인이 어려우면 작업을 할 수 없으니 계약서 사진을 미리 준비해 두면 좋습니다. / 전입신고 서류가 있다면 그것도 도움이 됩니다.
이사 날 아직 가스나 전기 신청 서류만 있다면 그 화면을 보여주셔도 참고가 됩니다. / 어떤 서류가 인정되는지 헷갈리면 출발 전 전화로 먼저 물어보세요.
집주인이 멀리 있다면 통화로 확인할 수 있도록 연락처를 미리 준비해 두시면 좋습니다.

# 비용은 손대기 전에 말씀드립니다
문 종류와 필요한 작업을 본 뒤 얼마가 드는지 먼저 알려드립니다. / 괜찮다고 하시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 설명 없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 번호 변경부터 교체까지, 상태에 맞게
번호만 바꾸면 되는 집이 대부분이지만 문이 오래되어 걸쇠가 헐거운 집도 있습니다. / 상태를 보고 먼저 [도어락 수리](doorlock-repair.html)로 해결할 수 있는지 살핍니다.
너무 낡았거나 전 입주자의 열쇠가 걱정된다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 새로 다는 일은 [도어락 설치](doorlock-install.html) 페이지에서 확인하세요.
문을 여는 작업이 필요하면 [현관문 개문](door-open.html) 순서로 먼저 진행합니다.
@ 송정동 이사 후 자물쇠 교체 점검 이천

# 이사 후 문 점검표
- 번호와 열쇠, 카드의 개수를 확인했는지
- 새 번호를 가족 모두가 알고 있는지
- 배터리 날짜를 적어 두었는지
- 문과 문틀에 눈에 띄는 흠이나 어긋남이 없는지
- 현관 앞 센서등이나 조명이 잘 켜지는지
점검표를 사진으로 찍어 두면 다음 이사 때도 그대로 쓸 수 있습니다. / 이상이 있다면 그 자리에서 바로 연락 주세요.

# 송정동 말고 이천 어디든 갑니다
송정동 가까운 중리동, 증포동, 관고동은 물론 부발읍까지 출동합니다. / 이천시 안이면 24시간 연락을 받습니다.
다니는 동네는 [이천시 출장열쇠](icheon.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
