# 별내동 문 앞에서 번호판이 꺼져 있다면
별내동은 별내역 주변으로 아파트 단지가 이어진 주거지라 도어락을 쓰는 집이 대부분입니다. / 퇴근길에 번호를 눌러도 아무 반응이 없다면 배터리 방전을 가장 먼저 의심해 볼 만합니다.
경고음이 며칠 전부터 났는데 그냥 지나친 경우가 많습니다. / 이 글은 [남양주 출장열쇠](namyangju.html)를 부르기 전에 집 앞에서 해 볼 수 있는 비상 대처를 순서대로 정리했습니다.
@ 별내동 도어락 배터리 방전 비상 대처

# 배터리가 다 되기 전에 나타나는 신호
도어락은 배터리가 약해지면 미리 신호를 줍니다.
- 번호를 누를 때 삑 소리가 평소보다 작거나 끊기는 경우
- 문을 열 때 모터 소리가 느리거나 힘이 없는 경우
- 열릴 때마다 경고음이 길게 나는 경우
- 번호판 불빛이 어둡거나 깜빡이는 경우
이런 신호가 며칠 이어졌다면 곧 방전될 때가 된 것입니다. / 신호가 나온 날 바로 교체하는 것이 가장 좋습니다.

# 번호판이 안 켜질 때 가장 먼저 할 일
번호판이 완전히 꺼져 있다면 배터리가 바닥난 것일 가능성이 큽니다. / 이때 같은 번호를 여러 번 누르는 것은 의미가 없습니다.
도어락 아래쪽이나 옆면에 비상 전원 단자가 있는지 살펴보세요. / 9V 건전지 모양의 단자나 USB 단자가 달린 제품이 많습니다.
건전지를 단자에 잠깐 대고 있으면 번호판이 켜지면서 번호를 누를 수 있는 경우가 있습니다. / 이때 건전지는 문을 열 때까지만 대고 있으면 됩니다.
@ 별내동 도어락 비상 전원 단자 9V 건전지

# 9V 건전지가 없을 때
집 근처 편의점이나 마트에서 9V 건전지를 구할 수 있는지 확인해 보세요. / 제품이 USB 단자 방식이라면 보조 배터리를 연결해도 되는 경우가 있습니다.
비상 전원 단자가 없는 제품도 있습니다. / 이때는 열쇠 구멍을 찾아 보조 열쇠로 여는 방법이 있는지 확인하세요.
열쇠 구멍이 번호판 덮개 아래에 숨겨져 있는 제품도 있어서 덮개를 살짝 밀거나 당겨 보세요. / 억지로 힘을 주면 덮개가 부러지니 가볍게만 시도하세요.

# 열렸다면 바로 해 둘 일
비상 전원으로 문이 열렸다면 그 자리에서 배터리를 새것으로 바꾸세요. / 일부만 바꾸지 말고 한 번에 모두 새것으로 교체해야 합니다.
교체한 날짜를 배터리 덮개 안쪽이나 휴대폰 메모에 적어 두세요. / 다음 교체 시기를 놓치지 않는 가장 쉬운 방법입니다.
건전지는 오래된 제품보다 새 제품이 안전합니다. / 창고에 오래 둔 건전지는 방전되어 있을 수 있습니다.

# 안 열리면 억지로 하지 마세요
비상 전원을 대도 번호판이 안 켜지거나 켜져도 문이 안 열리는 경우가 있습니다. / 배터리 외에 접점이나 모터, 회로 쪽 문제일 수 있습니다.
이럴 때는 여러 번 시도하기보다 연락을 주시는 편이 문을 덜 상하게 합니다. / 열쇠 구멍을 억지로 돌리거나 도어락을 두드리는 것은 피해 주세요.

# 겨울철에는 방전이 더 빨리 옵니다
날씨가 추워지면 건전지 힘이 평소보다 빨리 떨어집니다. / 여름까지 잘 쓰던 도어락이 갑자기 겨울 아침에 말을 안 듣는 이유가 여기에 있습니다.
출근 시간에 문이 안 열리면 더 당황스러우니 찬 바람이 불기 시작할 때 미리 배터리를 새것으로 바꿔 두는 편이 좋습니다.
현관 쪽이 외부 공기와 닿는 집은 특히 온도 영향을 더 받습니다. / 문 앞이 유난히 차갑다면 점검 시기를 조금 앞당기세요.
방전된 건전지를 그대로 두면 액이 새서 접점이 상하는 일도 있으니 교체할 때 오래된 건전지는 바로 빼내 주세요.

# 전화하실 때 알려주세요
짧게 정리해서 말씀해 주시면 도착이 빨라집니다.
- 별내동 위치와 건물 입구 정보, 몇 층 몇 호인지
- 번호판이 켜지는지, 소리가 나는지
- 비상 전원 단자나 열쇠 구멍이 있는지
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다. / 문이 열리지 않는 상황이면 [현관문 개문](door-open.html) 순서로 진행합니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인하는 절차가 있습니다. / 신분증 주소나 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있다면 휴대폰 속 공과금 고지서나 계약서로 먼저 확인할 수 있는지 말씀해 주세요. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
상황을 확인한 뒤 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
배터리만 바꾸면 되는 상황에서는 교체를 권하지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다.
@ 별내동 24시 출장열쇠 도어락 방전 비용 안내

# 문이 열린 뒤 확인하는 것
방전이 반복되는 집은 배터리 문제가 아니라 도어락 안쪽에서 전기가 계속 새고 있을 수도 있습니다. / 이런 경우에는 새 배터리를 넣어도 얼마 못 가 다시 경고음이 납니다.
교체 후 하루 이틀 뒤에도 소리가 달라지지 않는지 지켜보시고, 이상하면 바로 연락 주세요.
배터리를 새것으로 바꾼 뒤 번호판 불빛과 모터 소리가 정상인지 확인합니다. / 문을 여러 번 열고 닫으며 걸쇠가 제대로 움직이는지도 봅니다.
배터리를 바꿔도 같은 증상이 반복되면 [도어락 수리](doorlock-repair.html)를 먼저 권합니다. / 정말 오래돼서 부품이 없을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 방전을 막는 평소 습관
출장이나 여행으로 오래 집을 비우기 전에는 배터리 상태를 한 번 확인하고 나가세요. / 돌아오는 날 문 앞에서 막히면 짐도 많은데 더 힘들어집니다.
작은 습관만 들여도 문 앞에서 막힐 일이 크게 줄어듭니다.
- 경고음이 나면 그날 바로 교체하기
- 비상용 9V 건전지를 신발장 안쪽에 하나 두기
- 해가 바뀔 때쯤 한 번에 교체하는 날 정해 두기
- 비상 전원 단자 위치를 가족 모두가 알아 두기
열쇠 구멍이 있는 제품이라면 보조 열쇠를 가족이 한 개씩 가지거나 한 곳에 따로 보관해 두세요. / 열쇠를 집 안에만 두면 막혔을 때 쓸 수 없습니다.

# 별내동 말고 남양주 어디든 갑니다
다산동, 평내동, 호평동, 금곡동, 와부읍, 진접읍, 오남읍, 화도읍, 퇴계원읍, 진건읍까지 남양주 전 지역 24시간 출동합니다. / 지역이 서로 떨어져 있어서 정확한 주소를 먼저 받고 도착 시간을 말씀드립니다.
남양주에서 다니는 동네는 [남양주시 출장열쇠](namyangju.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
