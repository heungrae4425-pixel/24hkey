# 주말에 부모님 댁 현관 앞에서
별내동은 별내역 주변으로 아파트 단지가 이어진 남양주 주거지입니다. / 자녀 가까이 살려고 이사 오신 부모님이나, 오래 사신 집을 정리하고 새 아파트로 옮기신 어르신 세대도 있습니다.
부모님 댁에 들러 보면 현관 앞에서 번호를 몇 번씩 다시 누르시거나, 경고음이 울리는데도 모르고 지나치시는 모습을 보게 됩니다. / 당장 고장은 아니어도 언젠가 문 앞에서 막히실까 걱정이 됩니다.
이 글은 별내동 부모님 댁에 들른 김에 도어락을 어르신이 쓰기 편하게 맞춰 드리는 방법을 적었습니다. / 손이 많이 가는 부분은 [남양주 출장열쇠](namyangju.html)에 맡기셔도 됩니다.
@ 별내동 부모님 댁 아파트 도어락 점검

# 먼저 부모님이 어떻게 여시는지 지켜보기
점검은 부모님이 평소처럼 문을 여시는 모습을 옆에서 보는 데서 시작합니다. / 어디서 멈칫하시는지 보면 고칠 곳이 보입니다.
- 번호판 불이 켜지기 전에 누르시는지
- 숫자가 잘 안 보여 가까이 들여다보시는지
- 누른 뒤 소리를 못 들으셔서 다시 누르시는지
- 문이 무거워 손잡이를 당기며 힘들어하시는지
부모님께 “불편한 데 있으세요” 하고 여쭤보면 대개 괜찮다고 하십니다. / 말씀보다 손 움직임을 보는 편이 정확합니다.

# 번호판이 잘 안 보이신다면
번호판 숫자가 작거나 닳아서 잘 안 보이는 경우가 있습니다. / 현관 복도 조명이 어두우면 더 그렇습니다.
번호판을 마른 천으로 닦아 드리는 것만으로도 한결 나아지기도 합니다. / 숫자 표시가 많이 닳았다면 도어락 교체 때 숫자가 큰 번호판을 고르는 것도 방법입니다.
복도 센서등이 늦게 켜진다면 관리사무소에 말해 두세요. / 번호판 앞에 섰을 때 바로 불이 들어오면 어르신이 덜 헤매십니다.

# 소리가 작게 들리신다면
번호를 누를 때 나는 확인음, 문이 열릴 때 나는 소리가 작으면 어르신은 열린 줄 모르고 계속 누르십니다. / 많은 도어락은 소리 크기를 바꿀 수 있습니다.
안쪽 몸체의 설정 버튼으로 소리를 키울 수 있는 제품이 많습니다. / 방법은 제품마다 다르니 설명서를 보거나 모델명을 찾아 확인해 보세요.
배터리 부족 경고음이 울리는데도 모르시는 경우가 있습니다. / 경고음이 어떤 소리인지 부모님 앞에서 한 번 들려 드리면 다음에 알아채기 쉽습니다.
@ 별내동 도어락 소리 크기 설정 확인

# 번호는 외우기 쉽게, 그러나 너무 쉽지 않게
어르신 댁 번호는 기억하기 쉬운 숫자로 정해 드리는 게 좋습니다. / 다만 같은 숫자 반복이나 아파트 동, 호수 그대로는 피하세요.
부모님만 아시는 의미 있는 숫자를 고르시게 하면 오래 기억하십니다. / 번호를 현관 근처나 신발장 안쪽에 적어 두시는 습관이 있다면, 대신 휴대폰 메모나 지갑 속 쪽지처럼 집 밖에 드러나지 않는 곳으로 옮겨 드리세요.
번호를 바꿨다면 그날 부모님이 직접 몇 번 눌러 보시게 하세요. / 그 자리에서 손에 익혀 두셔야 다음 날 문 앞에서 헷갈리지 않으십니다.

# 번호가 어렵다면 카드나 태그
번호를 자주 잊으신다면 카드나 열쇠고리형 태그를 같이 쓰시게 하는 것도 좋습니다. / 대기만 하면 열리니 손 떨림이 있는 어르신도 편하게 쓰십니다.
태그는 집 열쇠고리나 지갑에 달아 드리고, 여분 하나는 가까이 사는 자녀가 갖고 있으면 좋습니다. / 몇 개를 등록했고 누가 가졌는지는 자녀 쪽에서 적어 두세요.
카드를 쓰더라도 번호는 꼭 함께 등록해 두세요. / 카드를 잃어버리셨을 때 들어갈 방법이 하나 더 남습니다.

# 배터리는 자녀가 챙겨 드리기
배터리 교체는 어르신께 생각보다 번거로운 일입니다. / 덮개를 열기 어렵거나 건전지 방향이 헷갈려 미루시다 방전되는 경우가 많습니다.
부모님 댁에 들를 때 배터리 교체 날짜를 확인하고, 해가 바뀔 때쯤 한꺼번에 바꿔 드리세요. / 배터리 칸에 교체한 날짜를 적어 두면 다음에 챙기기 쉽습니다.
비상 전원 단자 위치도 부모님께 한 번 보여 드리세요. / 번호판이 꺼졌을 때 어디에 건전지를 대는지 아시면 당황하지 않으십니다.

# 문이 무겁거나 너무 빨리 닫힌다면
어르신은 무거운 현관문을 당기다 손목을 다치시기도 합니다. / 문이 너무 빨리 닫히면 몸이 다 들어오기 전에 문이 부딪히기도 합니다.
문 위 도어클로저 속도가 너무 빠르다면 천천히 닫히게 맞춰 드리는 게 좋습니다. / 문이 무겁고 뻑뻑하다면 경첩이 처졌을 수 있어 점검이 필요합니다.
@ 별내동 현관 도어클로저 속도 어르신 맞춤

# 자동 잠금과 안쪽 잠금 확인
문이 닫히면 저절로 잠기는 자동 잠금이 켜져 있는지 확인해 주세요. / 어르신이 잠그는 걸 깜빡하셔도 문이 열려 있는 일이 줄어듭니다.
반대로 안쪽에서 누르면 바깥 번호로도 안 열리는 잠금 기능이 있다면, 부모님이 그 버튼을 쓰시는지 여쭤보세요. / 혹시 집 안에서 쓰러지시는 일이 생기면 가족이 번호로 들어갈 수 없게 되니 평소에는 쓰지 않으시는 편이 낫습니다.

# 가족이 들어갈 방법 하나 남겨 두기
부모님 댁에 연락이 닿지 않을 때 가족이 들어갈 수 있는 방법을 미리 정해 두세요. / 가까이 사는 자녀가 번호나 카드를 갖고 있으면 됩니다.
멀리 사는 형제가 있다면 누가 무엇을 갖고 있는지 서로 알아 두면 좋습니다. / 이웃이나 관리사무소 연락처를 자녀 휴대폰에 저장해 두는 것도 도움이 됩니다.

# 자녀분이 대신 점검을 맡기실 때
단지 이름과 동, 호수, 그리고 부모님이 불편해하시는 점을 알려주세요. / 자녀분이 함께 계시는 시간으로 맞추시면 설정 내용을 같이 듣고 정할 수 있습니다.
도착하면 사시는 분인지 신분증이나 우편물, 관리사무소 확인으로 먼저 확인합니다. / 점검 내용과 비용은 손대기 전에 말씀드리고, 동의하실 때만 진행합니다.
문이 잠겨 부르신 경우라면 끝내 못 열 때 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 고쳐 쓸지, 바꿔 드릴지
설정과 배터리, 도어클로저 조절만으로 대부분 편해지십니다. / 고장이 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
도어락이 오래돼 번호판이 잘 안 보이고 기능도 부족하다면 [도어락 교체](doorlock-replace.html)를 고민해 볼 수 있습니다. / 바꿀 때는 숫자가 크고 소리가 또렷한 제품, 카드를 같이 쓸 수 있는 제품이 어르신께 편합니다.

# 부모님 댁이 별내동 밖이라면
다산동, 평내동, 호평동, 금곡동과 진접읍, 오남읍, 화도읍, 와부읍, 퇴계원읍, 진건읍까지 다닙니다. / 부모님 댁이 읍면 쪽이라면 위치를 받고 도착 시간을 먼저 말씀드립니다.
남양주 안내는 [남양주시 출장열쇠](namyangju.html), 서울과 경기 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 자녀가 대신 연락해도 되나요? | 됩니다. 다만 작업할 때는 사시는 부모님 확인이나 관리사무소 확인이 필요합니다.
? 번호를 자주 잊으셔요. 어떤 방식이 좋을까요? | 카드나 태그를 같이 쓰시게 하고, 번호는 비상용으로 남겨 두는 방식을 권합니다.
? 안쪽 잠금 버튼을 꺼 둘 수 있나요? | 제품에 따라 다릅니다. 도어락을 보고 설정이 되는지 확인해 드립니다.
? 점검 중에 문이 잠기면 어떡하죠? | 그 자리에서 바로 열어 드리고, 못 열면 비용은 받지 않습니다.
