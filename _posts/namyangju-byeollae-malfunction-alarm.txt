# 현관에서 삐삐삐 소리가 멈추지 않을 때
별내동은 별내역 주변으로 신도시 아파트 단지가 이어진 동네라 현관마다 전자 도어락이 달려 있습니다. / 조용한 단지 복도에서 도어락 경고음이 계속 울리면 우리 집도 놀라지만 이웃도 함께 신경이 쓰입니다.
도어락이 내는 소리에는 저마다 뜻이 있습니다. / 짧게 끊어지는 소리, 길게 이어지는 소리, 모터가 헛도는 소리를 구분하면 무엇이 문제인지 꽤 가까이 짐작할 수 있습니다.
이 글은 별내동에서 도어락이 이상한 소리를 내거나 모터만 돌고 문이 안 열릴 때 증상별로 해 볼 것과 [남양주 출장열쇠](namyangju.html)에 알려 주실 내용을 정리했습니다.
@ 별내동 도어락 경고음 오작동

# 소리 종류로 먼저 짐작하기
같은 삐 소리라도 언제, 얼마나 길게 나는지가 중요합니다. / 아래에서 가장 비슷한 경우를 찾아보세요.
- 문을 열 때마다 짧은 멜로디 뒤에 삐삐: 건전지 교체 시기 알림인 경우가 많습니다
- 문이 열린 채로 몇십 초 뒤 반복되는 삐삐: 문이 덜 닫혔다는 알림입니다
- 크고 길게 끊이지 않는 경보음: 강제로 열려는 충격이나 이상 감지 경보입니다
- 위잉 소리만 나고 걸쇠가 안 움직임: 모터나 기어, 걸쇠 걸림 문제입니다
- 아무것도 안 했는데 혼자 울림: 습기나 회로 이상일 수 있습니다
제품마다 소리가 조금씩 다르니 설명서가 있다면 경고음 항목을 함께 찾아보시면 좋습니다.

# 경보처럼 길게 울릴 때
크고 긴 경보음은 도어락이 무언가 비정상적인 움직임을 감지했다는 뜻입니다. / 번호를 여러 번 틀렸거나, 문을 세게 흔들었거나, 안쪽 몸체가 충격을 받았을 때 울립니다.
집 안에 계시다면 안쪽에서 열림 버튼을 한 번 누르거나 문을 열었다 닫으면 멈추는 제품이 많습니다. / 바깥에서는 맞는 번호를 정확히 입력하면 꺼지는 경우가 대부분입니다.
아무도 문을 건드리지 않았는데 경보가 울렸다면 혹시 모를 일이니 주변을 한 번 살펴보시고, 걱정되면 관리사무소나 경비실에도 알려 주세요.

# 문이 덜 닫혔다는 알림
문을 닫았다고 생각했는데 몇십 초 뒤 삐삐 소리가 반복된다면 문이 문틀에 완전히 붙지 않은 경우입니다. / 도어락은 문이 닫혀야 걸쇠를 내리는데, 덜 닫히면 잠그지 못하고 알림만 보냅니다.
현관 바닥에 신발이나 택배 상자가 끼어 있지 않은지 먼저 보세요. / 도어클로저가 약해져 마지막 한 뼘을 못 미는 경우도 있습니다.
문을 손으로 끝까지 밀어 닫았을 때 소리가 멈추면 이쪽 원인이 맞습니다. / 매번 그렇다면 클로저 속도나 문 처짐을 점검할 때입니다.
@ 별내동 현관문 덜 닫힘 경고음

# 모터만 위잉 돌 때
번호가 맞았다는 소리 뒤에 모터 소리가 길게 이어지는데 문이 안 열린다면 걸쇠가 어딘가에 물려 있는 상태입니다. / 문이 문틀 쪽으로 눌려 있으면 모터가 걸쇠를 끌어당길 힘이 모자랍니다.
이럴 땐 손잡이를 잡고 문을 안쪽으로 살짝 민 상태에서 다시 번호를 눌러 보세요. / 걸린 힘이 풀리면서 열리는 경우가 꽤 있습니다.
소리가 평소보다 느리고 힘이 없다면 건전지가 약한 경우도 생각해 볼 수 있습니다. / 반대로 소리는 힘찬데 걸쇠가 꿈쩍 않는다면 기어가 미끄러지는 상태일 수 있습니다.

# 걸쇠가 나왔다 들어갔다 반복할 때
잠그자마자 다시 풀리거나, 걸쇠가 들락날락하며 덜컥거리는 증상도 있습니다. / 문틀 홈에 걸쇠가 제대로 안 들어가 도어락이 잠금 실패로 판단하고 다시 푸는 경우가 많습니다.
문틀 쪽 금속 판에 먼지나 이물질이 끼어 있는지 보세요. / 홈 위치가 걸쇠와 어긋나 보인다면 직접 손대기보다 점검을 맡기는 편이 낫습니다.

# 안에서 먼저 해 볼 수 있는 일
집 안에 계시고 문이 열린 상태라면 아래 순서로 해 보세요.
- 건전지를 모두 빼고 잠시 기다렸다 다시 넣기
- 그래도 같다면 건전지를 같은 종류 새것으로 전부 교체
- 문을 연 상태에서 잠금과 열림을 여러 번 시험
- 문을 닫고 다시 시험해 증상이 닫힐 때만 나는지 확인
건전지를 뺐다 넣는 것만으로 일시적인 오류가 풀리는 경우가 있습니다. / 다만 문이 닫힌 상태에서 건전지를 빼면 바깥에서 못 열 수 있으니 꼭 문을 열어 두고 하세요.

# 밤중 경보, 이웃을 위해 먼저 끄기
늦은 밤 경보가 울리면 멈추는 게 먼저입니다. / 안에서라면 건전지를 빼는 것이 가장 확실하게 소리를 멈추는 방법입니다.
바깥에서 꺼지지 않는다면 맞는 번호를 천천히 다시 넣어 보세요. / 그래도 계속 울리면 바로 연락 주시고, 옆집에는 도어락 고장이라고 짧게 말씀해 두시면 서로 마음이 편합니다.

# 이런 행동은 오작동을 키웁니다
소리가 나니 답답해서 번호판을 두드리거나 손잡이를 세게 흔드는 분들이 있습니다. / 충격을 받으면 경보가 더 울리고, 안쪽 부품이 정말로 상할 수 있습니다.
- 번호판을 손바닥으로 치거나 흔들기
- 몸체 틈에 물이나 세정제 뿌리기
- 드라이버로 안쪽 몸체를 열어 보기
특히 안쪽 몸체를 직접 열면 다시 조립할 때 배선이 어긋나 더 큰 고장으로 이어지기 쉽습니다.

# 소리를 녹음해 보내 주세요
경고음이 어떤 소리인지 말로 설명하기 어렵다면 휴대폰으로 녹음하거나 짧은 영상을 찍어 보내 주세요. / 소리만 들어도 원인을 좁히는 데 큰 도움이 됩니다.
통화하실 때는 아파트 동과 호수, 지금 문이 열려 있는지 잠겨 있는지, 언제부터 그랬는지를 함께 말씀해 주시면 됩니다. / 아이나 반려동물이 안에 있다면 그것도 꼭 알려 주세요.

# 문이 잠긴 채라면 확인부터
문이 잠겨 들어가지 못하는 상황이면 열기 전에 사시는 분인지 확인합니다. / 신분증 주소나 주소가 적힌 우편물, 관리사무소 세대 확인 가운데 하나면 됩니다.
상태를 본 뒤 비용을 먼저 말씀드리고 동의하시면 시작합니다. / 열지 못하면 비용은 받지 않으며 흐름은 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 남양주 출장열쇠 별내동 도어락 오작동 점검

# 고쳐 쓸지 바꿀지
경고음 원인이 건전지나 문 닫힘이라면 간단한 조정으로 끝나는 경우가 많습니다. / 모터나 기어, 회로 문제라도 부품을 구할 수 있으면 [도어락 수리](doorlock-repair.html)로 손볼 수 있습니다.
습기로 회로가 상했거나 부품을 더 이상 구할 수 없는 제품이라면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다. / 고칠 수 있는 걸 바꾸자고 권하지는 않습니다.

# 별내동 주변 남양주 어디든
별내동과 가까운 퇴계원읍, 진접읍, 오남읍, 진건읍은 물론 다산동, 와부읍, 금곡동, 평내동, 호평동, 화도읍까지 다닙니다. / 남양주 안내는 [남양주 출장열쇠](namyangju.html), 다른 지역은 [출장 지역](area.html)에 있습니다.
