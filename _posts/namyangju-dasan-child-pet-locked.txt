# 번호를 맞게 눌렀는데 열리지 않는 이유
다산동은 도농역 생활권에 새 아파트 단지가 넓게 들어선 남양주 동네입니다. / 대부분 비교적 최근에 단 도어락이라 기능이 많고, 그만큼 아이 손에 눌리기 쉬운 버튼도 있습니다.
쓰레기를 버리고 돌아왔더니 번호가 맞는데도 경고음만 울리고 문이 안 열릴 때가 있습니다. / 집 안에 있던 아이가 안쪽 잠금 버튼을 눌렀거나, 반려견이 몸으로 버튼을 건드린 경우입니다.
이 글은 다산동 아파트에서 아이나 반려동물이 안에 있는 채 문이 잠겼을 때 문 밖에서 할 수 있는 일을 순서대로 적었습니다. / 바로 도움이 필요하다면 [남양주 출장열쇠](namyangju.html)에 먼저 전화 주세요.
@ 다산동 아파트 도어락 안쪽 잠금 버튼

# 가장 먼저, 위험한 상황인지 보세요
문을 여는 일보다 안에 있는 아이나 동물이 괜찮은지가 먼저입니다. / 아래 같은 상황이라면 열쇠집보다 119에 먼저 연락해 주세요.
- 아주 어린 아기가 혼자 안에 있을 때
- 가스레인지나 다리미처럼 불을 쓰던 중이었을 때
- 아이가 울음을 멈추지 않거나 대답이 없을 때
- 욕조에 물을 받던 중이었을 때
위험하지 않은 상황이라면 아래 순서대로 차분히 해 보세요. / 그사이 출장 연락을 같이 넣어 두셔도 됩니다.

# 안쪽 잠금이 걸리면 바깥 번호가 안 먹습니다
요즘 도어락에는 안에서 버튼을 누르면 바깥에서 번호나 카드로도 열리지 않게 막는 기능이 있는 제품이 많습니다. / 집에 사람이 있을 때 쓰라고 만든 기능인데, 아이가 장난으로 누르면 보호자도 못 들어가게 됩니다.
번호를 눌렀을 때 평소와 다른 경고음이 나거나 번호판에 잠금 표시가 뜬다면 이 기능이 걸린 것일 수 있습니다. / 이때 번호를 계속 누르면 입력 제한까지 걸리니 멈추세요.
버튼 이름과 위치는 제품마다 다릅니다. / 우리 집 도어락이 어떤지 모르겠다면 설명서 사진이나 모델명을 휴대폰에서 찾아 두세요.

# 아이가 말을 알아듣는 나이라면
문 너머로 아이 이름을 부르며 침착한 목소리로 말을 걸어 주세요. / 혼나는 줄 알고 숨어 버리는 아이도 있으니 “괜찮아, 같이 해 보자”처럼 편하게 말하는 게 좋습니다.
아이 키에 닿는 안쪽 손잡이나 버튼이 있다면 하나씩 천천히 설명해 보세요. / 밀고 당기는 형 도어락은 안쪽 손잡이를 당기기만 해도 열리는 경우가 많습니다.
아이가 버튼을 찾지 못하거나 겁을 먹는다면 더 시키지 마세요. / 문 앞에서 계속 말을 걸어 주며 출장을 기다리는 편이 낫습니다.
@ 다산동 현관문 너머 아이 안심시키기

# 반려동물이 안에 있다면
강아지가 현관 앞에서 뛰어오르다 안쪽 버튼을 누르는 일이 생각보다 있습니다. / 고양이는 신발장 위에서 도어락 몸체를 밟기도 합니다.
문 밖에서 계속 이름을 부르면 동물이 더 흥분해 현관에서 떠나지 않습니다. / 너무 큰 소리는 내지 말고, 출장 기사가 올 때까지 조용히 기다리는 편이 좋습니다.
도착해서 문이 열리는 순간 동물이 복도로 뛰쳐나갈 수 있습니다. / 문을 열기 전에 보호자가 바로 앞에 서서 받을 준비를 해 주세요. / 평소 좋아하는 간식이나 장난감이 손에 있다면 더 수월합니다.

# 이웃이나 관리사무소에 도움 청하기
같은 단지 안에 여분 카드나 번호를 아는 가족이 있다면 연락해 보세요. / 다만 안쪽 잠금이 걸린 상태라면 번호와 카드로는 열리지 않으니 그 점은 미리 알고 계셔야 합니다.
관리사무소에 상황을 알려 두면 출장 기사가 도착했을 때 단지 출입이 수월합니다. / 아이가 혼자 있다는 사실도 함께 말해 두면 경비실에서 신경 써 주기도 합니다.
휴대폰을 집 안에 두고 나왔다면 경비실이나 이웃에게 전화를 빌려 연락 주셔도 됩니다. / 통화가 끝난 뒤에는 그 번호로 다시 연락드리니, 빌린 휴대폰 주인께 잠시 양해를 구해 두세요.

# 출장 부를 때 맨 먼저 말할 것
- 안에 아이가 있는지, 몇 살쯤인지
- 반려동물이 있는지, 현관 가까이 있는지
- 번호를 눌렀을 때 어떤 소리가 나는지
- 단지 이름과 동, 호수
아이가 안에 있다는 말은 가장 먼저 해 주세요. / 그 이야기를 들으면 위치를 받은 즉시 도착 예상 시간을 말씀드리고 서둘러 갑니다.
@ 다산동 아이 갇힘 출장열쇠 긴급 요청

# 기다리는 동안 하지 말아야 할 것
급한 마음에 문을 세게 두드리거나 손잡이를 마구 당기면 안의 아이가 더 놀랍니다. / 걸쇠에도 힘이 걸려 나중에 열기가 더 어려워질 수 있습니다.
도어락 번호판을 떼어 내거나 드라이버로 문틈을 벌리는 것도 피해 주세요. / 새 도어락이 상하고 정작 여는 데 도움은 되지 않습니다.
베란다 쪽으로 아이를 부르는 것도 위험할 수 있습니다. / 아이는 현관 쪽에 머물게 하는 것이 안전합니다.

# 현관 앞에 도착하면
아이가 안에 있는 상황이라도 사시는 분인지는 확인합니다. / 신분증 주소나 주소가 나온 우편물, 관리사무소 확인 가운데 하나면 되고, 급하면 관리사무소 확인으로 빠르게 진행합니다.
문 상태를 보고 비용을 먼저 말씀드린 뒤 바로 시작합니다. / 덜 상하는 방법으로 열고, 끝내 못 열면 비용은 받지 않습니다.
여는 방식은 [현관문 개방](door-open.html), 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 열고 나서 같이 정리할 것
문이 열리면 먼저 아이와 반려동물을 안심시켜 주세요. / 그다음 도어락이 평소대로 잠기고 열리는지 함께 확인합니다.
안쪽 잠금 버튼에 아이 손이 쉽게 닿는다면 그 기능을 끄거나 쓰지 않도록 설정할 수 있는지 봅니다. / 제품에 따라 설정이 안 되는 경우도 있어, 그때는 다른 방법을 말씀드립니다.
도어락 기능이 아이 키우는 집에 맞지 않는다면 [도어락 교체](doorlock-replace.html)도 고민해 볼 수 있습니다. / 고장이 있었다면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.

# 다음에 같은 일이 없도록
- 아이에게 안쪽 버튼은 어른만 누르는 것이라고 알려 주기
- 쓰레기 버리러 나갈 때도 휴대폰은 꼭 챙기기
- 반려동물이 현관 앞에서 뛰어오르지 않게 중문 닫아 두기
- 가까운 가족에게 우리 집 도어락 모델과 설명서 위치 알려 두기
짧게 나가는 순간에 일이 생기는 경우가 많습니다. / 휴대폰 하나만 들고 나가도 대처가 훨씬 빨라집니다.

# 다산동 말고 남양주 어디든
별내동, 평내동, 호평동, 금곡동과 와부읍, 진접읍, 오남읍, 화도읍, 퇴계원읍, 진건읍까지 다닙니다. / 아이가 안에 있는 연락은 어느 동네든 먼저 챙깁니다.
남양주 안내는 [남양주시 출장열쇠](namyangju.html), 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
