# 비파손 개방, 말은 들었는데
금곡동은 금곡역 주변으로 아파트와 주택, 상가 건물이 함께 있는 남양주 동네입니다. / 집 현관이 잠기는 일도, 가게 출입문이 안 열리는 일도 모두 생기는 곳이라 문의 종류가 다양합니다.
문이 잠겨 열쇠집에 전화하면 “비파손으로 열어 드린다”는 말을 자주 듣게 됩니다. / 그런데 그게 정확히 무슨 뜻인지, 어떤 경우에도 가능한 건지 물어보면 대답이 엇갈리기도 합니다.
이 글은 비파손 개방이라는 말이 뜻하는 범위와, 금곡동에서 흔한 문 종류별로 방식이 어떻게 달라지는지 적었습니다. / 지금 문 앞이라면 [남양주 출장열쇠](namyangju.html)에 먼저 전화 주셔도 됩니다.
@ 금곡동 현관 도어락 비파손 개방

# 한 줄로 말하면 이렇습니다
비파손 개방은 문과 잠금장치를 부수거나 뜯지 않고, 열고 난 뒤에도 그대로 다시 쓸 수 있게 여는 것을 말합니다. / 도어락을 드릴로 뚫거나 문틀을 벌려 여는 방식과 반대되는 말입니다.
문이 열린 뒤 도어락이 평소처럼 잠기고 열린다면 비파손으로 연 것입니다. / 손잡이와 번호판, 걸쇠, 문틀까지 원래 기능이 그대로 남아 있어야 합니다.

# 흠집과 파손은 다른 이야기입니다
작업 중에 도구가 닿은 자리에 아주 작은 자국이 남는 경우는 있을 수 있습니다. / 이것은 기능이 망가지는 파손과는 구분해서 봐야 합니다.
다만 자국이 남을 수 있는 방식이라면 작업 전에 미리 말씀드립니다. / 새 도어락이라 작은 자국도 신경 쓰인다면 그 점도 처음에 알려주세요.
반대로 “비파손”이라고 해 놓고 도어락을 떼어 내거나 구멍을 뚫는다면 그건 비파손이 아닙니다. / 그런 작업이 꼭 필요하다면 손대기 전에 이유와 비용을 먼저 듣고 정하시면 됩니다.

# 왜 문마다 방식이 다를까
잠금장치는 바깥에서 쉽게 열리지 않도록 만들어진 물건입니다. / 그래서 여는 방법도 장치 모양과 문 구조에 따라 하나하나 다릅니다.
- 번호키 도어락: 문 안쪽 손잡이나 버튼을 움직이는 방식
- 열쇠 실린더: 열쇠 없이 실린더를 돌리는 방식
- 손잡이 일체형: 손잡이 축과 걸쇠를 움직이는 방식
- 상가 유리문: 바닥이나 문틀 쪽 잠금을 푸는 방식
어느 방식이 맞는지는 문을 직접 보고 정합니다. / 사진을 먼저 보내 주시면 맞는 장비를 챙겨 갈 수 있습니다.

# 아파트 번호키 문은 이렇게
금곡동 아파트 현관은 대부분 번호키 도어락입니다. / 번호키 문은 바깥에서 도어락 자체를 건드리기보다, 문 안쪽의 열림 장치에 닿는 방법을 주로 씁니다.
그래서 도어락 번호판이나 몸체에는 손을 거의 대지 않습니다. / 문이 열리면 번호판, 모터, 걸쇠가 그대로 남아 바로 다시 쓸 수 있습니다. / 배터리가 다 돼서 잠긴 경우라면 비상 전원으로 먼저 깨워 보는 것도 비파손 방법 가운데 하나입니다.
안쪽에서 이중 잠금 버튼이나 걸쇠를 걸어 둔 경우라면 시간이 더 걸립니다. / 이 경우도 덜 상하는 방법부터 차례로 시도합니다.
@ 금곡동 아파트 번호키 도어락 개방 장비

# 주택 보조키와 열쇠 문은 이렇게
오래된 주택이나 상가 위 집은 열쇠로 여는 보조키, 손잡이 열쇠를 아직 쓰는 곳이 있습니다. / 열쇠 실린더는 안쪽 핀을 맞춰 돌리는 방식으로 열어 실린더를 그대로 살립니다.
다만 실린더가 오래돼 녹이 슬었거나 안에 열쇠 조각이 박혀 있다면 이야기가 달라집니다. / 그때는 조각을 먼저 빼내거나 실린더를 바꿔야 할 수 있어, 미리 상태를 말씀드립니다.

# 상가 유리문과 셔터는 이렇게
금곡동 상가 건물은 유리문, 샷시문, 철제 셔터가 섞여 있습니다. / 유리문은 아래쪽 바닥 잠금이나 위쪽 문틀 잠금이 따로 있는 경우가 많습니다.
유리는 힘을 받으면 깨질 수 있어 더 조심스럽게 다룹니다. / 셔터 자물쇠는 열쇠 실린더와 비슷한 방식으로 엽니다. / 아침 장사 시간이 급하다면 전화로 몇 시까지 문을 열어야 하는지도 같이 말씀해 주세요.
가게 문은 사용하는 분인지 확인할 서류가 필요합니다. / 임대계약서나 사업자등록증 가운데 하나를 준비해 주세요.

# 비파손이 어려운 경우도 있습니다
모든 문을 늘 비파손으로 열 수 있는 것은 아닙니다. / 아래 같은 경우에는 다른 방법을 써야 할 수도 있습니다.
- 도어락 내부가 고장 나 걸쇠가 아예 움직이지 않을 때
- 실린더 안에 열쇠 조각이 깊이 박혀 있을 때
- 문이 크게 처져 걸쇠가 문틀에 꽉 물렸을 때
이때도 바로 부수지 않습니다. / 왜 다른 방법이 필요한지, 무엇을 바꾸게 되는지, 비용이 얼마인지 먼저 말씀드리고 동의하실 때만 진행합니다.

# 집에서 먼저 하지 말아 주세요
급한 마음에 드라이버로 번호판을 떼어 내거나 문틈을 벌리는 분이 있습니다. / 그러면 원래 비파손으로 열 수 있던 문도 그렇게 열기 어려워집니다.
손잡이를 세게 비틀거나 문을 발로 차는 것도 걸쇠를 더 꽉 물리게 합니다. / 서너 번 시도해 안 되면 손을 떼고 전화 주시는 편이 문을 지키는 길입니다.
@ 금곡동 현관문 억지로 열기 주의

# 금곡동에서 연락하실 때
아파트라면 단지 이름과 동, 호수를, 주택이나 상가라면 도로명 주소와 건물 이름을 알려주세요. / 금곡역 쪽에서 어느 방향인지 말씀해 주시면 더 빨리 찾습니다.
잠긴 문이 번호키인지 열쇠 문인지, 유리문인지도 함께 알려주세요. / 문 사진 한 장이면 어떤 방식으로 열지 미리 정할 수 있습니다.

# 확인부터 시작까지의 순서
먼저 사시는 분이나 사용하는 분인지 신분증, 우편물, 관리사무소 확인이나 서류로 확인합니다. / 확인이 되면 문 상태를 보고 여는 방식과 비용을 손대기 전에 말씀드립니다.
동의하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다. / 자세한 방식은 [현관문 개방](door-open.html), 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 열고 난 뒤 같이 보는 것
문이 열리면 도어락이 평소처럼 잠기고 열리는지 여러 번 확인합니다. / 비파손으로 열었다는 건 결국 이 확인이 문제없이 끝난다는 뜻입니다.
원래 고장 때문에 잠긴 것이었다면 [도어락 수리](doorlock-repair.html)로 원인을 손봅니다. / 너무 오래돼 다시 같은 일이 생길 것 같다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 금곡역 생활권 밖 남양주까지
평내동, 호평동, 다산동, 별내동과 와부읍, 진접읍, 오남읍, 화도읍, 퇴계원읍, 진건읍까지 다닙니다. / 동네 사이 거리가 있어 위치를 받으면 도착 시간을 먼저 말씀드립니다.
남양주 안내는 [남양주시 출장열쇠](namyangju.html), 서울과 경기 다른 지역은 [출장 지역](area.html)에서 확인하세요.
