# 삑 소리는 났는데 문은 그대로
금곡동은 평내동, 호평동과 이웃한 남양주 동네로 아파트와 오래된 주택, 상가 위층 집이 함께 있습니다. / 오래 살아온 집일수록 도어락보다 문과 문틀이 먼저 나이를 먹습니다.
번호를 누르니 열림 소리까지 났는데 손잡이를 당겨도 문이 꿈쩍하지 않을 때가 있습니다. / 도어락이 고장 난 줄 알고 당황하지만, 실제로는 문이 처져 걸쇠가 문틀에 물려 있는 경우가 많습니다.
이 글은 금곡동 오래된 집 현관에서 문틀과 경첩 쪽 원인을 가려 보는 방법과 맡길 때를 적었습니다. / 지금 문이 안 열린다면 [남양주 출장열쇠](namyangju.html)에 바로 연락 주셔도 됩니다.
@ 금곡동 오래된 현관문 문틀 처짐

# 도어락 탓인지 문 탓인지 가르는 법
문이 안 열릴 때 둘 중 어느 쪽인지 대략 가를 수 있는 방법이 있습니다. / 번호를 누른 뒤 들리는 소리와 문 움직임을 같이 보세요.
- 모터가 힘겹게 돌다 멈추는 소리: 걸쇠가 눌려 있을 가능성
- 열림 소리는 깔끔한데 문이 안 움직임: 문틀에 걸린 가능성
- 아무 소리도 없음: 배터리나 도어락 자체 문제
- 열쇠가 반쯤 돌다 막힘: 실린더보다 문 위치 문제일 가능성
소리가 정상인데 안 열린다면 도어락보다 문 쪽을 먼저 의심해 보는 게 맞습니다.

# 문을 살짝 들어 올리며 당겨 보기
문이 처지면 바깥쪽 끝이 아래로 내려앉습니다. / 그러면 걸쇠가 문틀 구멍 아래쪽에 비스듬히 걸려 잘 빠지지 않습니다.
번호를 누른 뒤 손잡이를 잡고 문을 위쪽으로 살짝 들어 올리는 느낌으로 당겨 보세요. / 반대로 문을 안쪽으로 살짝 밀었다가 당기는 것도 방법입니다.
이렇게 해서 열린다면 원인은 문 처짐입니다. / 열렸다고 그냥 두지 말고 다음 날이라도 점검을 받으세요.

# 경첩이 세 개라면 위쪽부터
현관문 경첩은 보통 두세 개가 달려 있습니다. / 문 무게를 가장 많이 받는 것은 맨 위 경첩이라 여기가 먼저 헐거워집니다.
문을 연 상태에서 위쪽 경첩 나사를 손가락으로 만져 보세요. / 나사 머리가 튀어나와 있거나 경첩판이 문틀에서 살짝 떠 있다면 처짐의 출발점입니다.
드라이버로 조여서 단단히 잡힌다면 그것만으로 한결 나아집니다. / 헛돌면서 조여지지 않는다면 나사 구멍이 넓어진 것이라 보강이 필요합니다.
@ 금곡동 현관문 위쪽 경첩 나사 확인

# 문틀 쪽에 남는 흔적
문이 처진 지 오래되면 문틀에도 흔적이 남습니다. / 문틀 위쪽 모서리 페인트가 갈라졌거나 문짝 끝이 문틀을 긁은 자국이 보일 수 있습니다.
도어락 걸쇠가 들어가는 받이쇠 주변을 보세요. / 받이쇠 아래쪽만 반짝이게 닳아 있다면 걸쇠가 늘 아래쪽으로 들어가고 있었다는 뜻입니다.
문지방 쪽 바닥에 반달 모양으로 긁힌 자국이 있다면 문 아래가 바닥에 끌리고 있는 것입니다.

# 오래된 집 문틀이 틀어지는 이유
오래된 주택은 집 자체가 조금씩 내려앉거나 벽이 미세하게 움직이면서 문틀도 같이 틀어집니다. / 상가 위층 집은 아래층 공사나 진동의 영향을 받기도 합니다.
나무 문틀은 습기에 부풀고 마르면서 모양이 변합니다. / 비가 많이 온 뒤에만 문이 안 맞는다면 이런 이유일 수 있습니다.
철문은 무게가 있어 경첩에 부담이 계속 쌓입니다. / 문을 자주 세게 닫는 집일수록 처짐이 빨리 옵니다.

# 문이 열렸다면 이것부터 확인
들어 올려 열었든, 밀었다 당겨 열었든 일단 문이 열렸다면 문을 열어 둔 채 살펴보세요. / 문을 닫았을 때 위, 옆, 아래 틈을 비교합니다.
경첩 반대쪽 위 모서리 틈이 좁고 아래쪽 틈이 넓다면 처짐입니다. / 경첩 쪽 틈이 벌어져 있다면 경첩이 문틀에서 떠 있는 것입니다.
틈을 사진으로 찍어 두시면 점검을 맡길 때 도움이 됩니다. / 그날 밤은 문을 너무 세게 닫지 말고, 걸쇠가 끝까지 들어갔는지 손으로 한 번 당겨 확인한 뒤 주무세요.

# 계절 따라 심해졌다 덜해졌다 한다면
여름 장마철에만 문이 뻑뻑하고 가을이 되면 괜찮아진다면 나무 문틀이나 문짝이 습기를 머금었다 마르는 것일 수 있습니다. / 이럴 때 문을 깎아 내면 건조한 계절에 틈이 너무 벌어지니 서두르지 않는 편이 좋습니다.
겨울에만 걸쇠가 덜 들어가고 덜컹거린다면 철문과 문틀이 찬 공기에 조금 줄어든 것입니다. / 계절마다 반복된다면 받이쇠 위치를 그 중간쯤으로 맞춰 두는 방법이 있습니다.

# 하지 말아야 할 것
- 안 열린다고 문을 어깨로 세게 밀거나 차기
- 문틈에 드라이버를 넣어 걸쇠 밀기
- 헛도는 경첩 나사를 계속 세게 조이기
- 도어락만 새것으로 바꾸고 문은 그대로 두기
처진 문에 새 도어락을 달아도 걸쇠가 같은 곳에 걸려 금방 같은 증상이 납니다. / 원인이 문이면 문부터 바로잡아야 합니다.
@ 금곡동 현관 받이쇠 걸쇠 위치 점검

# 전화하실 때 알려주실 것
아파트라면 단지 이름과 동, 호수를, 주택이나 상가 위층이라면 도로명 주소와 건물 이름을 알려주세요. / 상가 건물은 위층 올라가는 입구가 따로 있는지도 말씀해 주시면 좋습니다.
번호를 눌렀을 때 소리가 어땠는지, 문을 들어 올리면 조금이라도 움직이는지도 함께 알려주세요. / 문과 문틀이 같이 나온 사진을 보내 주시면 챙겨 갈 부품을 고를 수 있습니다.

# 확인과 비용 안내
도착하면 사시는 분인지 신분증, 주소가 나온 우편물, 관리사무소 확인으로 먼저 확인합니다. / 문이 잠긴 상태라면 덜 상하는 방법으로 먼저 열고, 그다음 원인을 봅니다.
여는 방법과 손볼 내용, 각각의 비용은 손대기 전에 말씀드립니다. / 끝내 못 열면 비용은 받지 않습니다.
여는 방식은 [현관문 개방](door-open.html), 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 어떻게 바로잡나요
가벼운 처짐은 경첩 나사를 다시 잡고 받이쇠 위치를 조금 옮기는 것으로 해결됩니다. / 나사 구멍이 넓어졌다면 보강한 뒤 다시 고정합니다.
경첩이 닳았다면 경첩을 바꾸고, 도어클로저가 문을 세게 끌어당기고 있었다면 속도도 함께 맞춥니다. / 문짝이나 문틀 자체가 크게 상했을 때만 더 큰 작업을 말씀드립니다.
도어락이 처진 문 때문에 무리를 받아 고장이 났다면 [도어락 수리](doorlock-repair.html)로 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.

# 금곡동 말고 남양주 어디든
바로 옆 평내동과 호평동은 물론 다산동, 별내동 아파트 단지와 진접읍, 오남읍, 화도읍, 와부읍 주택가까지 갑니다. / 퇴계원읍, 진건읍처럼 조금 떨어진 곳은 위치를 듣고 도착 시간을 먼저 알려드립니다.
남양주에서 다니는 동네는 [남양주시 출장열쇠](namyangju.html)에, 서울과 경기 다른 곳은 [출장 지역](area.html)에 정리해 두었습니다.
