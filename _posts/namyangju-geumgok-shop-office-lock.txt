# 금곡동 가게 문 앞에서 열쇠가 안 돌아갈 때
금곡동은 금곡역 주변으로 상가와 사무실, 주택이 섞여 있는 동네라 가게 문을 여닫는 분들이 많습니다. / 아침에 문을 열어야 하는데 열쇠가 안 돌아가면 하루 장사가 걸려 있어서 더 마음이 급합니다.
주택 현관문과 달리 상가 출입문은 유리문, 철제 셔터, 샷시문처럼 종류가 다양해서 점검 방식도 달라집니다. / 이 글은 [남양주 출장열쇠](namyangju.html)를 부르기 전에 확인할 것을 정리했습니다.
@ 금곡동 가게 사무실 출입문 잠금장치 출장열쇠

# 가게 문이 안 열리는 흔한 이유
상가 문은 하루에도 여러 번 열고 닫기 때문에 부품이 빨리 닳습니다. 아래 중 하나인 경우가 많습니다.
- 열쇠를 오래 써서 이가 닳아 실린더에 안 맞는 경우
- 열쇠 구멍에 먼지나 이물질이 쌓여 끝까지 안 들어가는 경우
- 문틀이 처지거나 샷시가 틀어져 걸쇠가 팽팽하게 걸린 경우
- 도어락 배터리가 방전되어 번호판이 꺼진 경우
- 열쇠가 부러져 구멍 안에 남아 있는 경우
어떤 경우든 영업 시간이 걱정되더라도 문을 억지로 비틀거나 발로 차는 것은 피하세요. / 유리가 깨지면 상황이 훨씬 커집니다.

# 먼저 가볍게 확인할 것
문 앞에서 아래 순서로 천천히 살펴보세요.
열쇠를 끝까지 넣고 아주 살짝 빼서 돌려 보세요. / 힘을 주면 열쇠가 휘거나 부러질 수 있습니다.
번호판식이라면 불이 켜지는지, 소리가 나는지 먼저 봅니다. / 아무 반응이 없으면 배터리가 문제일 가능성이 큽니다.
다른 직원이나 건물주가 보조 열쇠를 가지고 있는지 연락해 보세요. / 가까운 곳에 있다면 그쪽이 더 빠를 수 있습니다.
@ 금곡동 가게 열쇠 구멍 번호판 확인

# 셔터와 유리문은 따로 알려주세요
상가는 셔터, 유리문, 안쪽 문이 겹쳐 있는 곳이 많습니다. / 어느 문이 안 열리는지 정확히 알려주셔야 필요한 장비를 챙겨 갈 수 있습니다.
- 바깥 셔터 자물쇠가 안 열리는지
- 유리문 바닥 쪽 잠금이 안 풀리는지
- 안쪽 사무실 문 도어락이 안 열리는지
- 모든 문이 다 안 열리는지
문 사진을 한두 장 보내주시면 도착 후 작업이 빨라집니다. / 유리문은 잠금장치 위치가 문 아래나 위쪽에 있어 위치도 같이 알려주세요.

# 영업 시간이 걱정될 때
문이 안 열려 영업을 못 하게 되면 손님이 기다리는 시간이 길어집니다. / 그래서 위치와 영업 시작 시간을 먼저 알려주시면 도착 시간을 맞춰 안내해 드립니다.
작업 중에도 가능한 한 소리와 먼지를 줄이고, 문 외관을 상하지 않게 진행합니다. / 영업하는 가게는 입구가 지저분해지지 않게 마무리도 신경 씁니다.
급하게 열었다가 문을 못 닫는 상황이 되지 않도록 열고 난 뒤 잠금 상태까지 확인합니다.

# 전화하실 때 알려주세요
짧게 정리해서 말씀해 주시면 도착이 빨라집니다.
- 금곡동 위치와 건물 입구 정보, 몇 층 몇 호인지
- 가게인지 사무실인지, 어떤 문이 문제인지
- 열쇠식인지 번호판식인지, 보조 열쇠가 있는지
- 문 안쪽에 사람이나 물건이 남아 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다. / 문이 열리지 않는 상황이면 [현관문 개문](door-open.html) 순서로 진행합니다.

# 도착하면 사용하시는 분인지 확인합니다
가게나 사무실도 문을 여는 일이라 사용하시는 분이 맞는지 확인하는 절차가 있습니다. / 사업자등록증이나 임대 계약서, 건물 관리인 확인 중 하나면 충분합니다.
계약자가 아닌 직원이 요청하시는 경우에는 대표님께 통화로 확인할 수 있어야 합니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 금곡동 24시 출장열쇠 상가 개문 비용 안내

# 열고 난 뒤에 같이 점검하는 것
가게는 문이 한 번 막히면 같은 일이 또 생기기 쉬우니 열린 직후에 열쇠를 여러 번 넣고 돌려 보며 상태를 확인합니다.
문이 열리면 열쇠와 도어락이 부드럽게 움직이는지 여러 번 확인합니다. / 닳은 열쇠는 새로 복사해 두는 것이 좋습니다.
잠금장치가 오래돼서 불안하다면 [도어락 수리](doorlock-repair.html)가 가능한지 먼저 봅니다. / 정말 오래돼서 부품이 없을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
직원이 바뀌었거나 퇴사자가 열쇠를 가지고 있다면 이때 잠금장치를 새로 바꾸는 것도 방법입니다.

# 퇴근할 때와 출근할 때 확인할 것
마감하고 나설 때 문이 제대로 잠겼는지 한 번 더 당겨 보세요. / 열쇠를 돌린 소리가 평소와 다르거나 걸쇠가 덜 나온 느낌이라면 다음 날 아침 문제가 될 수 있습니다.
아침에 처음 문을 열 때 뻑뻑하다고 느껴지면 영업 시작 전에 미리 연락 주시는 편이 훨씬 여유롭습니다.
상가는 건물 전체 출입문이나 공용 현관까지 거쳐야 하는 경우도 있어서 어느 문부터 막혔는지 순서대로 알려주시면 좋습니다.

# 직원이 바뀔 때 잠금장치 정리
직원 입퇴사가 잦은 가게는 열쇠나 번호 관리가 어렵습니다. / 퇴사한 직원이 열쇠를 반납하지 않았거나 번호를 알고 있는 경우 불안이 남습니다.
번호키는 번호만 바꾸면 되고, 열쇠식은 실린더를 교체하는 방법이 있습니다. / 어느 쪽이 맞는지는 문과 사용 방식에 따라 다릅니다.
일일이 따로 만들기보다 출입 기록을 남기는 방식이 필요한지도 함께 상담해 드립니다.

# 가게 잠금장치 평소 관리
영업이 잦은 곳일수록 한 번 점검해 두면 갑자기 막힐 가능성이 줄어듭니다. / 비 오는 날 문 앞 물기가 열쇠 구멍으로 들어가지 않는지도 가끔 살펴보세요.
작은 관리만 해도 문 앞에서 막히는 일이 줄어듭니다.
- 열쇠를 복사해 두 개 이상 따로 보관하기
- 번호판식은 해가 바뀔 때쯤 배터리 한 번에 교체하기
- 열쇠 구멍에 먼지가 쌓이지 않게 가끔 털어내기
- 문이 뻑뻑해지는 느낌이 들면 일찍 점검 받기
영업이 끝난 뒤 문을 잠그고 나설 때 한 번 더 당겨 보는 습관도 도움이 됩니다.

# 금곡동 말고 남양주 어디든 갑니다
다산동, 별내동, 평내동, 호평동, 와부읍, 진접읍, 오남읍, 화도읍, 퇴계원읍, 진건읍까지 남양주 전 지역 24시간 출동합니다. / 지역이 서로 떨어져 있어서 정확한 주소를 먼저 받고 도착 시간을 말씀드립니다.
