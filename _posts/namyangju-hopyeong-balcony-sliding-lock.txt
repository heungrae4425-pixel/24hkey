# 현관 말고 집 안 문이 막혔을 때
현관문은 멀쩡한데 베란다로 나가는 미닫이문이 안 열리거나, 아이 방문이 안에서 잠겨 버리는 날이 있습니다. / 호평동은 평내호평역 생활권에 아파트 단지와 주택이 함께 있는 동네라 이런 집 안 문 연락도 종종 들어옵니다.
집 안 문은 현관보다 잠금장치가 단순한 대신 종류가 다양합니다. / 어떤 장치인지만 알면 혼자 풀 수 있는 경우도 꽤 많습니다.
이 글은 호평동 아파트에서 베란다, 미닫이, 방문 잠금이 걸렸을 때 종류별로 해 볼 일을 정리했습니다. / 혼자 어렵다면 [남양주 출장열쇠](namyangju.html)로 연락 주세요.
@ 호평동 아파트 베란다 미닫이문 잠금

# 먼저 누가 어느 쪽에 있는지
집 안 문이 막혔을 때 가장 먼저 볼 것은 사람이 어디 있느냐입니다. / 문 안쪽에 아이나 어르신이 갇혀 있는지, 아니면 그냥 문만 잠긴 것인지에 따라 서두르는 정도가 다릅니다.
안에 아이가 있다면 문 너머로 계속 말을 걸어 주세요. / 아이에게 무리하게 손잡이를 돌리게 하기보다 "괜찮아, 금방 열어 줄게"라고 안심시키는 것이 먼저입니다.
베란다 쪽에 사람이 갇혔다면 춥거나 더운 날씨인지 바로 살펴보세요. / 겨울이나 한여름이라면 기다리지 말고 곧장 연락 주시는 편이 낫습니다.

# 베란다 미닫이문이 안 열릴 때
아파트 베란다 미닫이문에는 문짝이 겹치는 자리에 반달 모양 걸쇠가 달린 경우가 많습니다. / 거실 쪽에서 걸쇠를 돌려 잠그는 방식이라 베란다에 나가 있는 동안 누군가 무심코 잠그면 밖에서는 열 수 없습니다.
거실 쪽에 가족이 있다면 걸쇠를 반대로 돌려 달라고 하면 끝납니다. / 혼자 베란다에 갇혔다면 휴대폰으로 가족이나 관리사무소에 먼저 연락해 보세요.
걸쇠는 풀었는데 문이 무겁고 안 밀린다면 아래 바퀴 쪽 문제일 수 있습니다. / 레일에 흙이나 작은 돌이 끼어 있지 않은지 살펴보고 털어 내 보세요.
베란다 화분에서 흘러나온 흙이나 마른 잎이 레일 사이에 쌓이면 바퀴가 그 위로 올라타 문이 잘 안 움직입니다. / 평소에 레일을 한 번씩 쓸어 주면 걸쇠를 풀고도 문이 안 열리는 일을 줄일 수 있습니다.
@ 호평동 베란다 미닫이 반달 걸쇠

# 베란다 문에서 하지 말 것
- 유리문을 세게 흔들거나 발로 차기
- 문짝을 레일에서 들어 올려 빼내기
- 걸쇠 쪽 틈에 칼이나 자를 넣어 비틀기
- 옆집 베란다로 건너가기
유리가 끼워진 문은 힘을 받으면 깨질 수 있고, 문짝을 빼면 다시 끼우기가 생각보다 어렵습니다. / 높은 층에서 옆집으로 건너가는 것은 절대 하지 마세요.

# 방문 손잡이가 안에서 잠겼을 때
방문 손잡이는 안쪽에서 누름 버튼을 누르거나 작은 꼭지를 돌려 잠그는 방식이 많습니다. / 바깥쪽 손잡이 가운데를 보면 작은 구멍이나 일자 홈이 있는 경우가 대부분입니다.
작은 구멍이라면 가는 막대를 곧게 밀어 넣으면 안쪽 버튼이 풀리는 구조입니다. / 일자 홈이라면 얇은 동전이나 일자 드라이버를 끼워 돌리면 풀립니다.
너무 두꺼운 도구를 억지로 넣으면 손잡이 안쪽이 상할 수 있습니다. / 맞는 크기가 없다면 무리하지 말고 연락 주세요.
풀린 뒤에는 안쪽 버튼이 쉽게 눌리는 손잡이인지 한 번 확인해 보세요. / 문을 닫을 때 몸이 스치기만 해도 잠기는 손잡이라면 같은 일이 금방 다시 생깁니다.

# 화장실 문이 혼자 잠겼다면
화장실 문도 방문과 같은 손잡이를 쓰는 집이 많습니다. / 샤워하다 습기 때문에 손잡이 안쪽이 뻑뻑해져 잠금이 안 풀리는 경우도 있습니다.
안에 사람이 있다면 손잡이를 돌리면서 문을 바깥쪽으로 살짝 당겨 보라고 해 보세요. / 걸쇠가 문틀에 눌려 있던 거라면 이렇게 풀리기도 합니다.
어르신이 화장실 안에서 못 나오시는 상황이라면 몸 상태부터 확인해 주세요. / 어지럽거나 불편해하신다면 문을 여는 것보다 119에 먼저 연락하는 것이 맞습니다.

# 거실 중문이 안 움직일 때
현관과 거실 사이에 중문을 단 집도 있습니다. / 미닫이 중문은 위쪽 레일이나 아래 바퀴가 어긋나면 갑자기 무거워지고, 잠금 손잡이가 달린 중문은 손잡이 고장으로 안 열리기도 합니다.
중문은 크고 무거워서 혼자 들어 올려 바로잡으려 하면 다칠 수 있습니다. / 레일 먼지를 털어 보고 그래도 안 되면 손대지 말고 점검을 받으세요. / 유리가 넓은 중문이라면 더더욱 무리하지 않는 편이 안전합니다.

# 아이가 있는 집이라면 미리
아이가 방문이나 화장실 문을 잠그는 일은 한 번 생기면 또 생깁니다. / 바깥에서 풀 수 있는 도구를 문틀 위나 정해진 서랍에 하나 놓아 두세요.
베란다 미닫이 걸쇠는 아이 손이 닿는 높이에 있는 경우가 많습니다. / 아이가 장난으로 잠그지 않도록 미리 이야기해 두거나 걸쇠 쪽에 보조 장치를 다는 것도 방법입니다.

# 혼자 풀기 어려운 경우
- 바깥에서 풀 구멍이나 홈이 없는 손잡이일 때
- 도구를 넣었는데 안쪽이 헛돌기만 할 때
- 베란다 걸쇠가 안쪽에서만 풀리는데 집 안에 아무도 없을 때
- 중문이나 미닫이문이 레일에서 빠진 것 같을 때
집 안 문이라도 억지로 열다 문짝이 상하면 바꾸는 데 시간과 비용이 더 듭니다. / 막히는 순간 멈추고 연락 주시는 편이 결국 빠릅니다.

# 호평동에서 연락 주실 때
단지 이름과 동, 호수와 함께 어떤 문이 막혔는지 알려 주세요. / 손잡이나 걸쇠 사진을 보내 주시면 맞는 도구를 챙겨 갈 수 있습니다.
안에 사람이 갇혀 있다면 그 사실을 첫마디로 말씀해 주세요. / 특히 아이나 어르신, 베란다에 갇힌 경우라면 순서를 당겨 서두릅니다.

# 집 안 문도 확인을 거칩니다
집 안 문을 여는 경우라도 그 집에 사시는 분인지는 확인합니다. / 신분증, 주소가 적힌 우편물, 관리사무소 확인 가운데 하나면 됩니다.
상태를 본 뒤 손대기 전에 비용을 먼저 말씀드립니다. / 끝내 못 열면 비용은 받지 않습니다. 진행 순서는 [이용안내](guide.html)에 있습니다.
@ 호평동 방문 화장실 잠금 출장

# 열고 나서 손볼 것
방문 손잡이가 낡아 헛돌았다면 손잡이만 바꾸면 됩니다. / 베란다 걸쇠가 헐거워 저절로 걸렸다면 나사를 조이거나 걸쇠를 바꿉니다.
현관 도어락도 함께 봐 달라고 하시면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 같이 안내해 드립니다. / 현관이 잠겨 안 열리는 경우는 [현관문 개문](door-open.html)에서 따로 정리해 두었습니다.

# 호평동 말고 남양주 어디든
호평동과 함께 평내동, 금곡동, 다산동, 별내동, 와부읍, 진접읍, 오남읍, 화도읍, 진건읍, 퇴계원읍까지 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
