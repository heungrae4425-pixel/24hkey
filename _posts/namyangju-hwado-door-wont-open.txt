# 화도읍 집 앞에서 문이 꿈쩍하지 않을 때
화도읍은 남양주 동쪽의 읍 지역으로 빌라와 단독주택, 마당 있는 전원주택이 넓게 흩어져 있습니다. / 시내 중심과 거리가 있는 집도 많아 문이 안 열리면 가까운 열쇠집을 찾기가 쉽지 않습니다.
현관문이 안 열리는 이유는 생각보다 여러 가지입니다. / 그런데 원인에 따라 해볼 수 있는 일이 다르기 때문에 무작정 번호를 누르거나 손잡이를 당기기보다 증상부터 살피는 것이 빠릅니다.
이 글은 화도읍 집에서 현관문이 안 열릴 때 증상별로 원인을 좁히는 방법을 적었습니다. / 확인해 봐도 안 되면 [남양주 출장열쇠](namyangju.html)로 연락 주세요.
@ 화도읍 주택 현관문 안 열림 점검

# 증상을 네 갈래로 나눠 보기
문 앞에서 아래 네 가지 중 어디에 해당하는지 먼저 보세요. / 이것만 정해도 전화로 설명하기가 훨씬 쉬워집니다.
어두운 밤이라면 휴대폰 손전등으로 번호판과 문틈을 비춰 보세요. / 불빛 아래에서 보면 번호판이 정말 꺼진 것인지, 밝기가 약해 안 보인 것인지도 구분할 수 있습니다.
- 번호판이 아예 안 켜진다
- 번호판은 켜지는데 누르면 경고음이 난다
- 열림 소리는 나는데 문이 안 밀린다
- 열쇠를 넣었는데 안 돌아간다
같은 안 열림이라도 갈래마다 원인이 전혀 다릅니다. / 아래에서 갈래별로 하나씩 살펴보겠습니다.

# 번호판이 안 켜진다면 전원부터
번호판을 손바닥으로 덮거나 눌러도 불이 안 들어오면 건전지가 다 됐을 가능성이 가장 큽니다. / 경고음을 듣고도 미뤄 두었던 집에서 흔히 생깁니다.
바깥 번호판 아래쪽에 9V 건전지를 대는 비상 단자가 있는지 찾아보세요. / 건전지를 대고 있는 동안 전원이 들어와 번호를 누를 수 있는 제품이 많습니다.
화도읍처럼 편의점이 멀 수 있는 곳이라면 차 안에 9V 건전지가 있는지도 떠올려 보세요. / 비상 단자가 없거나 대도 반응이 없으면 그때 연락 주시면 됩니다.

# 경고음이 난다면 번호나 입력 제한
번호를 눌렀을 때 짧은 삑 대신 길고 다른 소리가 나면 번호가 틀렸다는 신호입니다. / 가족이 번호를 바꿔 두었을 수도 있으니 먼저 전화로 물어보세요.
여러 번 틀리면 일정 시간 입력이 막히는 기능이 있습니다. / 이때는 계속 누르지 말고 몇 분 기다렸다가 천천히 다시 눌러 보세요.
안쪽에서 이중 잠금 버튼을 눌러 두면 맞는 번호를 눌러도 경고음이 나며 안 열리는 제품도 있습니다. / 집 안에 가족이 있다면 그 버튼을 다시 눌러 달라고 해 보세요.

# 열림 소리는 나는데 문이 안 밀린다면
도어락은 열렸는데 문이 안 움직인다면 다른 잠금이 걸린 것입니다. / 보조키, 안쪽 걸쇠나 체인, 그리고 문틀에 걸린 걸쇠가 대표적인 원인입니다.
문이 아예 안 움직이면 보조키, 한 뼘쯤 열리다 멈추면 안쪽 걸쇠일 가능성이 큽니다. / 걸쇠는 안에서만 걸 수 있어 집 안에 가족이 있는지부터 확인하세요.
화도읍 오래된 주택은 문틀이 처져 걸쇠가 문틀에 눌리는 일도 있습니다. / 문을 안쪽으로 살짝 밀면서 손잡이를 돌리면 풀리기도 합니다.
@ 화도읍 현관문 걸쇠 문틀 걸림 확인

# 열쇠가 안 돌아간다면 억지로 비틀지 않기
열쇠식 보조키나 오래된 현관 자물쇠는 안쪽에 먼지가 끼거나 닳아 열쇠가 잘 안 돌기도 합니다. / 열쇠를 끝까지 넣고 문을 살짝 당기거나 밀면서 천천히 돌려 보세요.
힘을 주어 비틀면 열쇠가 휘거나 안에서 부러질 수 있습니다. / 부러지면 꺼내는 일부터 해야 해 시간이 더 걸립니다.
겨울 아침에 유독 안 돌아간다면 습기가 얼었을 수 있습니다. / 뜨거운 물을 붓는 것은 다시 얼어 더 나빠질 수 있으니 피해 주세요.

# 화도읍 주택은 대문부터 볼 때도 있습니다
마당 있는 집은 현관에 닿기 전에 대문이 먼저 막히기도 합니다. / 대문이 안 열리는지, 현관이 안 열리는지에 따라 준비하는 장비가 달라집니다.
대문과 현관이 둘 다 안 열린다면 그것도 함께 말씀해 주세요. / 순서를 정해 한 번에 처리하겠습니다.
대문 안쪽에 개가 있거나 마당 문이 따로 잠겨 있다면 그것도 미리 알려 주세요. / 도착해서 들어갈 길을 찾느라 시간을 쓰지 않아도 됩니다.

# 이런 시도는 일을 키웁니다
- 드라이버나 카드로 문틈 벌리기
- 손잡이를 세게 당기거나 문을 발로 차기
- 번호를 수십 번 눌러 보기
- 창문이나 베란다로 넘어 들어가기
문틀과 도어락이 상하면 문을 연 뒤에 고칠 곳이 더 생깁니다. / 주택 창문으로 들어가려다 다치는 일도 있으니 그대로 두고 연락 주세요.
특히 낮은 단독주택 창문은 쉽게 넘을 수 있을 것 같아 보이지만, 방범창이나 화분에 걸려 넘어지는 경우가 많습니다.

# 전화하실 때 알려 주실 것
화도읍은 마을마다 거리가 있어 정확한 주소를 먼저 받습니다. / 아래를 함께 알려 주시면 도착 시간을 정확히 말씀드릴 수 있습니다.
- 도로명 주소나 지번, 근처 큰길
- 단독주택, 전원주택, 빌라 중 어느 쪽인지
- 위 네 갈래 중 어떤 증상인지
- 대문과 현관 중 어디가 막혔는지
- 집 안에 사람이나 반려동물이 있는지
도어락이나 자물쇠 사진을 보내 주시면 맞는 장비를 챙기기 좋습니다.

# 도착하면 사시는 분인지 먼저 확인
문을 여는 일이라 그 집에 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 임대차 계약서 중 하나를 준비해 주세요.
신분증이 집 안에 있다면 집주인이나 이웃 확인으로 대신할 수 있는지 함께 찾아봅니다. / 확인이 안 되면 작업할 수 없는 점 양해 부탁드립니다.
@ 화도읍 출장열쇠 거주 확인 후 작업

# 비용은 손대기 전에 알려 드립니다
증상과 문 상태를 보고 어떻게 열지, 비용이 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 원치 않으시면 그냥 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html), 여는 방식은 [현관문 개방](door-open.html)에 적어 두었습니다.

# 열고 나서 원인별로 정리하기
건전지가 원인이었다면 전부 새것으로 바꾸고, 번호 문제였다면 새 번호를 등록합니다. / 걸쇠나 문틀이 원인이었다면 문 닫힘과 받침 위치를 맞춰 다시 안 걸리게 합니다.
도어락 자체가 약해졌다면 [도어락 수리](doorlock-repair.html)로 손보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 함께 상의합니다. / 멀쩡한 제품을 무리하게 바꾸자고 하지 않습니다.

# 화도읍 말고 남양주 어디든
화도읍과 가까운 호평동, 평내동부터 다산동, 별내동, 금곡동, 와부읍, 진접읍, 오남읍, 퇴계원읍, 진건읍까지 남양주 전 지역을 다닙니다. / 남양주 안내는 [남양주시 출장열쇠](namyangju.html), 다른 지역은 [출장 지역](area.html)에서 보세요.

? 경고음이 계속 나는데 고장인가요? | 번호 오류나 입력 제한, 안쪽 이중 잠금일 수 있어 고장이라고 단정하기 어렵습니다.
? 화도읍 외곽 전원주택도 오시나요? | 네, 주소를 받아 도착 시간을 먼저 말씀드리고 출동합니다.
? 대문과 현관이 다 안 열리면 따로 불러야 하나요? | 한 번에 같이 보며 순서를 정해 처리합니다.
? 못 열면 비용을 내나요? | 끝내 열지 못하면 비용은 받지 않습니다.
