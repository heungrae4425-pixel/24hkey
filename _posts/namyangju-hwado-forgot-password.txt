# 화도읍 현관 앞, 손가락이 멈췄을 때
화도읍은 빌라와 단독주택, 전원주택이 마을마다 흩어진 남양주 동쪽의 읍 지역입니다. / 오래 살아 손에 익은 번호일수록 어느 날 갑자기 머릿속이 하얘지는 일이 생깁니다.
매일 누르던 번호가 생각나지 않으면 누구나 당황합니다. / 가족이 번호를 바꿨는데 나만 모르고 있었던 경우도 흔합니다.
이 글은 화도읍에서 도어락 번호를 잊었을 때 집 앞에서 해볼 수 있는 일과 피해야 할 일을 나눠 적었습니다. / 끝내 안 되면 [남양주 출장열쇠](namyangju.html)로 연락 주세요.
@ 화도읍 도어락 비밀번호 분실

# 우선 번호판에서 손을 떼고 숨 고르기
번호가 기억나지 않을 때 가장 먼저 할 일은 누르기를 멈추는 것입니다. / 생각나는 대로 이것저것 누르다 보면 금방 입력 제한이 걸립니다.
대부분의 도어락은 몇 번 틀리면 일정 시간 입력을 받지 않습니다. / 그사이 진짜 번호가 떠올라도 기다려야 하니, 처음 서너 번 안에 신중하게 누르는 것이 좋습니다.
잠시 눈을 감고 평소 문 앞에서 손가락이 움직이던 모양을 떠올려 보세요. / 숫자보다 손의 움직임이 먼저 기억나는 분이 많습니다.
번호판 위 버튼 배열을 보면서 손가락이 자주 가던 자리를 짚어 보는 것도 방법입니다. / 위에서 아래로, 왼쪽에서 오른쪽으로 하는 식의 모양이 떠오르면 숫자도 따라 기억나곤 합니다.

# 떠올리는 데 도움이 되는 실마리
번호는 대개 집안의 다른 숫자와 이어져 있습니다. / 아래 같은 것들을 하나씩 떠올려 보세요.
- 예전 집 도어락 번호나 휴대폰 잠금 번호
- 가족 생일이나 결혼기념일, 이사 온 날
- 대문 자물쇠나 창고 번호 자물쇠 숫자
- 휴대폰 메모, 사진첩에 찍어 둔 쪽지
휴대폰 메모를 찾아볼 때는 숫자만 적힌 메모나 '문', '현관' 같은 단어로 검색해 보세요. / 이사 때 받은 번호를 사진으로 찍어 둔 경우도 있습니다.

# 가족이 바꿨을 가능성
번호를 정확히 눌렀는데 안 열리면 누군가 바꿨을 수 있습니다. / 최근에 가족 중 누가 도어락을 만졌는지, 건전지를 갈았는지 떠올려 보세요.
건전지를 갈면서 설정이 바뀌는 제품도 가끔 있습니다. / 집에 있는 가족이나 마지막으로 나간 가족에게 먼저 전화해 확인해 보세요.
세 들어 사는 집이라면 집주인이 관리 차원에서 번호를 바꿨을 수도 있습니다. / 집주인이 같은 건물이나 근처에 산다면 직접 물어보는 것이 가장 빠릅니다.
문자나 공지로 알렸는데 미처 못 본 경우도 있으니 최근 받은 문자함을 한 번 훑어보세요.

# 어르신이 혼자 계신 집에서 번호를 잊었다면
화도읍에는 부모님 혼자 사시는 집도 많습니다. / 어르신이 번호를 잊었다는 전화를 받으면 자녀분이 먼저 번호를 알고 있는지 확인해 주세요.
자녀분도 모른다면 출장을 부르시면 됩니다. / 대신 전화하실 때 어르신 성함과 주소, 연락이 닿는 번호를 함께 알려 주시면 도착해서 바로 진행할 수 있습니다.
기다리시는 동안 어르신이 밖에 오래 서 계시지 않도록 이웃집이나 따뜻한 곳에 계시게 해 주세요.
@ 화도읍 부모님 댁 도어락 번호 분실 출장

# 집 앞에서 피했으면 하는 일
- 생각나는 번호를 십여 번 연달아 누르기
- 번호판을 손톱이나 도구로 뜯어 초기화 버튼 찾기
- 안쪽 몸체를 바깥에서 풀려고 문틈 벌리기
- 건전지를 대는 비상 단자에 다른 전원을 연결하기
초기화 버튼은 대부분 집 안쪽 몸체에 있어 바깥에서는 누를 수 없습니다. / 바깥 번호판을 뜯으면 배선이 끊겨 문을 연 뒤에도 쓸 수 없게 될 수 있습니다.

# 번호는 맞는데 안 열리는 다른 이유
번호를 확실히 기억하는데도 안 열린다면 번호 문제가 아닐 수 있습니다. / 번호판 일부 숫자가 눌리지 않거나, 건전지가 약해 입력이 끊기는 경우가 있습니다.
특정 숫자를 누를 때만 소리가 안 나면 그 버튼이 고장 난 것입니다. / 이럴 때는 번호를 다시 떠올리기보다 출장으로 열고 번호판을 점검하는 편이 낫습니다.

# 전화 주실 때 이렇게 말씀해 주세요
화도읍은 마을 사이 거리가 있어 주소를 먼저 여쭤봅니다. / 아래를 함께 주시면 준비가 빨라집니다.
- 도로명 주소나 지번, 들어오는 큰길
- 빌라인지 단독주택인지 전원주택인지
- 번호를 누르면 어떤 소리가 나는지
- 가족이나 집주인에게 확인해 봤는지
- 대문도 번호식인지
도어락 앞면 사진을 보내 주시면 제품에 맞는 방법을 미리 고를 수 있습니다.

# 사시는 분 확인은 빠지지 않습니다
번호를 잊은 경우에도 문을 여는 일이라 거주 확인을 먼저 합니다. / 신분증 주소, 주소가 찍힌 우편물, 임대차 계약서 중 하나를 준비해 주세요.
신분증이 집 안에 있다면 문을 연 뒤 바로 보여 주시는 방법도 있습니다. / 어떤 방법으로 할지 도착해서 함께 정합니다. / 집주인이나 이웃이 확인해 줄 수 있다면 그 방법도 괜찮습니다.

# 비용은 시작 전에 먼저 알려 드립니다
도어락 종류를 보고 여는 방법과 비용을 손대기 전에 말씀드립니다. / 동의하시면 시작하고, 아니면 그대로 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html), 여는 방식은 [현관문 개방](door-open.html)에 정리해 두었습니다.
@ 화도읍 출장열쇠 비용 먼저 안내

# 열린 뒤 새 번호를 정하는 요령
문이 열리면 안쪽에서 새 번호를 등록하고 예전 번호는 지웁니다. / 등록 방법이 어려우면 그 자리에서 함께 해 드립니다.
새 번호는 가족 모두가 기억할 수 있으면서 남이 짐작하기 어려운 것이 좋습니다. / 생일이나 전화번호 끝자리처럼 바로 떠오르는 숫자는 피하고, 여섯 자리 이상으로 정해 보세요.
가족에게 알릴 때는 정해진 사람에게 직접 말로 전하는 것이 깔끔합니다. / 어르신 댁이라면 크게 적은 쪽지를 집 안 정해진 곳에 두고, 현관 바깥에는 붙이지 마세요.

# 번호를 다시 잊지 않으려면
번호만 쓰는 집이라면 카드나 지문 같은 다른 방법을 하나 더 등록해 두면 좋습니다. / 지원하지 않는 오래된 제품이라면 [도어락 교체](doorlock-replace.html) 때 함께 고려해 볼 수 있습니다.
번호판이 고장 나 버튼이 잘 안 눌린다면 [도어락 수리](doorlock-repair.html)로 손볼 수 있습니다. / 새로 달 계획이라면 [도어락 설치](doorlock-install.html) 안내도 참고해 주세요.

# 화도읍 말고 남양주 어디든
화도읍에서 가까운 호평동, 평내동, 금곡동부터 다산동, 별내동, 와부읍, 진접읍, 오남읍, 퇴계원읍, 진건읍까지 남양주 전 지역에 갑니다. / 남양주 안내는 [남양주시 출장열쇠](namyangju.html), 다른 지역은 [출장 지역](area.html)을 보세요.

? 부모님 댁인데 자녀가 대신 불러도 되나요? | 네, 어르신 성함과 주소, 연락처를 알려 주시면 됩니다.
? 집주인이 번호를 바꾼 것 같아요 | 먼저 집주인께 확인해 보시고, 연락이 안 되면 거주 확인 후 열어 드립니다.
