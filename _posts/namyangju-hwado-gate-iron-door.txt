# 화도읍 대문 열쇠가 안 돌아갈 때 먼저 할 일
화도읍은 아파트보다 단독주택과 전원주택이 많은 동네입니다. / 대문과 현관문이 따로 있어서 열쇠 문제도 두 군데에서 생깁니다.
오늘 아침까지 잘 열리던 대문이 저녁에 갑자기 안 돌아가면 당황스럽습니다. / 먼저 열쇠를 뽑았다가 다시 천천히 넣어 보는 것부터 시작하세요.
이 글은 화도읍에서 대문이나 철문 열쇠가 말을 안 들을 때 전화하기 전에 확인할 것을 적었습니다. / 그다음 [남양주 출장열쇠](namyangju.html)가 어떤 순서로 일하는지도 함께 적었습니다.
@ 화도읍 출장열쇠 대문 철문 자물쇠

# 단독주택은 열쇠 문제가 두 번 생깁니다
아파트는 현관문 하나만 열면 되지만 단독주택은 대문을 지나야 현관에 닿습니다. / 대문 자물쇠가 막히면 현관 도어락이 멀쩡해도 집에 들어갈 수 없습니다.
대문은 바깥 비바람을 그대로 맞기 때문에 현관문보다 먼저 상합니다. / 녹, 먼지, 물기가 열쇠구멍 안에 쌓이는 것이 가장 흔한 시작입니다.
현관은 도어락으로 바꿨는데 대문은 오래된 열쇠 자물쇠 그대로인 집도 많습니다. / 이런 집은 대문 열쇠를 잃어버렸을 때 대안이 마땅치 않아 연락이 옵니다.

# 철문 자물쇠가 뻑뻑해지는 흔한 이유
열쇠구멍 안쪽의 작은 핀이 녹슬거나 먼지에 엉기면 열쇠가 끝까지 들어가지 않습니다. / 비가 많이 온 뒤나 겨울 아침에 특히 심해집니다.
철문 자체가 처져서 빗장이 받침에 정확히 맞지 않는 경우도 있습니다. / 이때는 열쇠가 아니라 문이 문제라서 열쇠만 새로 만들어서는 해결되지 않습니다.
자물쇠 안에 기름을 아무거나 넣어 두면 오히려 먼지가 달라붙어 더 나빠집니다. / 그래서 집에 있는 식용유나 오래된 윤활제를 넣는 것은 권하지 않습니다.

# 열쇠가 반쯤 들어가다 걸릴 때
열쇠가 끝까지 들어가지 않고 중간에서 멈추면 억지로 밀지 마세요. / 핀이 걸린 상태에서 밀면 열쇠가 휘거나 안에서 부러질 수 있습니다.
열쇠를 살짝 빼 보고 위아래로 조금씩 흔들면서 다시 넣어 보는 정도까지만 하시면 됩니다. / 그래도 안 들어가면 거기서 멈추는 것이 안전합니다.
열쇠 모양이 닳아서 안 맞는 경우도 있습니다. / 복사본으로 복사한 열쇠를 또 복사한 열쇠가 대표적입니다.
@ 화도읍 철문 자물쇠 열쇠 안 들어갈 때

# 힘으로 돌리면 일이 커집니다
열쇠가 뻑뻑할 때 펜치나 몽키스패너로 열쇠 머리를 잡고 돌리는 분들이 있습니다. / 열쇠가 부러지면 열쇠구멍 안에 조각이 남아 작업 시간이 훨씬 길어집니다.
대문을 발로 차거나 어깨로 밀어 열려는 것도 피해 주세요. / 문틀이 휘면 자물쇠와 빗장이 어긋나서 문을 바꿔야 할 수도 있습니다.
열쇠가 부러졌다면 부러진 조각은 버리지 말고 가지고 계시면 좋습니다. / 열쇠 종류를 알아보는 데 도움이 됩니다. / 조각이 작아 보여도 모양과 홈 개수를 보면 자물쇠 종류를 가늠할 수 있습니다.

# 대문 빗장이 안쪽에서 걸려 있을 때
가족 중 누가 안쪽 빗장을 걸어 둔 채 문을 닫고 나가면 밖에서는 열쇠가 맞아도 열리지 않습니다. / 집 안에 가족이 있다면 먼저 전화로 안쪽 빗장을 풀어 달라고 부탁해 보세요.
집에 아무도 없다면 빗장 위치와 형태를 알려 주셔야 방법을 고를 수 있습니다. / 대문 안쪽을 볼 수 없다면 이웃에게 담장 너머로 살펴봐 달라고 부탁하는 방법도 있습니다.

# 현관 도어락과 대문 열쇠를 같이 쓰는 집
대문 열쇠와 현관 열쇠를 하나로 묶어 다니는 집이 많습니다. / 열쇠 꾸러미를 잃어버리면 대문, 현관, 창고까지 한꺼번에 막히는 경우가 있습니다.
이런 상황에서는 어디가 먼저 열려야 집에 들어가는지 순서를 정해서 진행합니다. / 대문을 먼저 열고 현관을 확인하는 순서가 일반적입니다.
현관이 도어락이라면 비밀번호를 아시는지 먼저 확인합니다. / [도어락 수리](doorlock-repair.html)가 필요한 상태인지는 문을 열고 나서 말씀드립니다.

# 전화하실 때 알려 주실 것
화도읍은 주택 위치가 골목마다 달라서 주소 설명이 정확해야 합니다. / 지도 앱의 주소를 문자로 보내 주시면 찾아가기 훨씬 쉽습니다.
- 대문 모양(철제 여닫이, 미닫이, 전동 등)
- 자물쇠가 열쇠식인지 번호식인지
- 열쇠가 안 들어가는지, 들어가지만 안 돌아가는지
- 집 안에 사람이나 반려동물이 있는지
- 대문 앞 주차 가능 여부
사진을 한 장 보내 주시면 필요한 장비를 챙겨 가기 좋습니다. / 밤이라 어두우면 휴대폰 손전등을 켜서 열쇠구멍을 찍어 주세요.

# 도착하면 이렇게 진행합니다
도착하면 먼저 자물쇠 상태와 문 처짐을 살핍니다. / 열쇠를 새로 만들어야 하는지, 자물쇠만 손보면 되는지를 이때 판단합니다.
덜 상하는 방법부터 차례로 해 보고, 필요한 부품이 있으면 바꾸기 전에 말씀드립니다. / 문이나 자물쇠를 망가뜨리지 않는 것을 가장 먼저 생각합니다.
자세한 개방 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 대문과 철문도 같은 원칙으로 진행합니다.
@ 남양주 화도읍 출장 개문 작업

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 집인지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 적힌 우편물, 가족이 확인해 주는 방법 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집주인 모두를 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 열기 전에 말씀드립니다
문과 자물쇠 상태를 보고 얼마인지 먼저 말씀드리고, 괜찮다고 하실 때 시작합니다. / 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하는 상황이면 따로 여쭤보고 진행합니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 대문 자물쇠 오래 쓰는 관리법
- 일 년에 한두 번 열쇠구멍 먼지를 에어로 불어 내기
- 비 온 뒤에는 물기를 마른 수건으로 닦기
- 열쇠는 복사본이 아니라 원본에서 복사하기
- 예비 열쇠는 집 밖이 아니라 믿을 수 있는 가족에게 맡기기
- 대문이 처지면 경첩과 빗장 받침을 같이 점검하기
작은 관리로 막혀서 부르는 일을 많이 줄일 수 있습니다. / 열쇠가 평소보다 뻑뻑하다 싶을 때 미루지 않는 것이 가장 효과적입니다.
열쇠를 새로 맞추거나 [출장 열쇠](key-call.html) 서비스가 필요하면 말씀해 주세요.

# 화도읍 말고 남양주 어디든 갑니다
화도읍 옆 와부읍, 오남읍, 진접읍, 퇴계원읍, 진건읍과 다산동, 별내동까지 다닙니다. / 남양주는 동네 사이 거리가 멀어서 위치를 먼저 받고 도착 시간을 말씀드립니다.
동네는 [남양주시 출장열쇠](namyangju.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
