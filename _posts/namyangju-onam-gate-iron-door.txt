# 오남읍 전원주택 대문 앞에서
오남읍은 아파트 단지와 함께 단독주택, 전원주택, 농가 주택이 섞여 있는 지역입니다. / 아파트와 달리 대문과 현관문이 따로 있어 두 군데를 모두 열어야 집에 들어갈 수 있는 곳이 많습니다.
대문 철문은 바깥 날씨를 그대로 맞기 때문에 자물쇠가 쉽게 뻑뻑해지고 녹이 생깁니다. / 이 글은 [남양주 출장열쇠](namyangju.html)를 부르기 전에 확인해 볼 것과 진행 순서를 정리했습니다.
@ 오남읍 전원주택 대문 철문 자물쇠 출장열쇠

# 철문 자물쇠가 안 열리는 흔한 이유
대문은 야외에 노출되어 있어서 도어락보다 상태가 빨리 나빠집니다. 아래 중 하나인 경우가 많습니다.
- 열쇠 구멍에 먼지와 흙, 녹이 쌓여 열쇠가 끝까지 안 들어가는 경우
- 열쇠 이가 닳아 실린더 핀과 맞지 않는 경우
- 대문이 처지거나 기둥이 기울어 빗장이 팽팽하게 걸린 경우
- 겨울에 물기가 얼어붙어 열쇠가 안 돌아가는 경우
- 열쇠가 구멍 안에서 부러진 경우
어느 경우든 억지로 비틀면 상황이 악화됩니다. / 열쇠가 돌아가지 않을 때 힘을 주는 것이 가장 위험합니다.

# 먼저 눈으로 확인해 보세요
열쇠를 세게 돌리기 전에 아래 몇 가지를 살펴보세요.
열쇠가 휘었거나 닳은 곳이 없는지 봅니다. / 휘어진 열쇠를 계속 쓰면 열쇠 구멍 안쪽이 상할 수 있습니다.
열쇠 구멍 안에 이물질이 보이면 입으로 불거나 마른 솔로 털어내는 정도만 해 주세요. / 날카로운 도구로 쑤시는 것은 피하세요.
열쇠를 끝까지 넣고 살짝 뒤로 뺐다가 가볍게 돌려 보세요. / 이때도 힘을 주지 않는 것이 중요합니다.
@ 오남읍 열쇠 구멍 이물질 대문 확인

# 겨울에 얼어서 안 돌아갈 때
기온이 내려가는 계절에는 열쇠 구멍 안의 물기가 얼어 열쇠가 안 돌아가는 일이 생깁니다. / 이때 뜨거운 물을 붓는 것은 금속과 주변을 상하게 하고 다시 얼어붙을 수 있어서 좋지 않습니다.
서서히 녹을 때까지 기다리거나 따뜻한 바람을 조심스럽게 쓰는 편이 안전합니다. / 열쇠를 억지로 돌리면 부러질 수 있어요.
자주 얼어붙는 자물쇠라면 평소 물기가 들어가지 않게 덮개를 달아 두는 방법이 있습니다.

# 열쇠가 부러졌을 때
열쇠가 구멍 안에서 부러졌다면 더 이상 만지지 말고 그대로 두세요. / 핀셋이나 바늘로 빼내려다 파편이 더 깊이 들어가는 일이 있습니다.
부러진 반쪽은 버리지 말고 보관해 주세요. / 같은 모양으로 다시 만들거나 교체할 때 도움이 됩니다.
먼저 사진을 문자로 보내주시면 필요한 장비를 챙겨 갑니다.

# 대문과 현관문을 구분해서 알려주세요
어느 문이 잠겼는지 알려주셔야 필요한 장비를 챙겨 갈 수 있습니다.
- 대문(철문)만 안 열리는지
- 현관문 도어락까지 안 열리는지
- 대문에 도어락이 붙어 있는지, 열쇠만 쓰는지
- 담장 안쪽에 사람이 있는지
대문 사진과 자물쇠 사진을 같이 보내주시면 도착 후 작업이 빨라집니다. / 자물쇠가 특이한 모양이면 가까이서 한 장 더 찍어 주세요.

# 주소를 정확히 먼저 받는 이유
같은 읍 안에서도 마을과 도로가 서로 떨어져 있는 곳이 많아 대략의 위치만으로는 도착 시간을 정확히 말씀드리기 어렵습니다.
오남읍처럼 마을과 주택이 넓게 퍼진 지역은 번지수와 도로 이름만으로 찾기 어려운 곳도 있습니다. / 그래서 전화를 받으면 주소와 가까운 눈에 띄는 건물이나 표지를 먼저 여쭙니다.
지도 앱의 현재 위치를 문자로 보내주시면 가장 정확합니다. / 도착 시간도 위치를 보고 먼저 말씀드립니다.
길을 찾기 어려운 곳은 대문 앞이나 입구 표지판 사진을 같이 보내주시면 도움이 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인하는 절차가 있습니다. / 신분증 주소나 주소가 나온 우편물, 관리하시는 분 확인 중 하나면 충분합니다.
세컨드하우스나 별장은 소유자나 관리자임을 확인할 수 있어야 합니다. / 대신 요청하실 때는 주인과 통화로 확인할 수 있어야 하며, 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
자물쇠 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 오남읍 24시 출장열쇠 철문 개문 비용 안내

# 문을 여는 방법
철문과 대문 자물쇠는 상하지 않게 여는 방법부터 차례로 시도합니다. / 자물쇠 종류에 따라 걸리는 시간이 다릅니다.
열쇠가 안 돌아가는 경우에는 구멍 속 이물질이나 핀 상태를 먼저 확인합니다. / 필요하면 자물쇠를 상하지 않게 분해해서 여는 방법을 씁니다.
작업 중 교체가 필요해 보이면 손대기 전에 말씀드립니다. / 자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 열고 난 뒤 같이 점검하는 것
대문과 현관문이 둘 다 열려야 집에 들어가는 구조라면 열린 뒤에 두 문의 자물쇠 상태를 각각 확인합니다. / 하나만 고치고 가면 다음 날 다른 문에서 막히는 일이 생길 수 있기 때문입니다.
문이 열리면 자물쇠가 부드럽게 돌아가는지 여러 번 확인합니다. / 닳은 열쇠는 [출장 열쇠](key-call.html)에서 새로 복사해 드립니다.
대문이 처졌다면 경첩과 빗장 위치도 같이 살펴봅니다. / 현관 쪽 도어락에 이상이 있다면 [도어락 수리](doorlock-repair.html) 여부도 함께 봅니다.
오래된 자물쇠는 한 번 열렸을 때 새것으로 바꾸는 편이 마음이 놓이는 경우도 있습니다.

# 전원주택 자물쇠 평소 관리
대문 열쇠와 현관 열쇠를 같은 꾸러미에 두면 한 번 잃어버렸을 때 두 군데가 한꺼번에 막힙니다. / 따로 나눠 보관하는 것도 도움이 됩니다.
비바람과 먼지를 그대로 맞는 문이라 평소 관리가 중요합니다.
- 열쇠 구멍에 덮개를 달아 먼지와 빗물이 들어가지 않게 하기
- 비가 지나간 뒤 자물쇠 주변 물기 닦기
- 반년에 한 번쯤 열쇠를 돌려 보며 뻑뻑한 정도 확인하기
- 열쇠는 한두 개 더 만들어 따로 보관하기
미리 한 번 점검해 두면 문 앞에서 낭패 볼 일을 많이 줄일 수 있습니다.
