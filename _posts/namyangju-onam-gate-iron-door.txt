# 마당 있는 집의 대문이 닫혀 있을 때
오남읍에는 아파트 단지 못지않게 마당이 딸린 전원주택과 연립, 다가구주택이 많이 있습니다. / 이런 집은 현관문에 닿기 전에 대문이나 철문부터 열어야 해서 문이 두 번 막히는 구조입니다.
퇴근길에 열쇠를 꽂았는데 철문 자물쇠가 꿈쩍도 안 하면 집 앞에서 한참을 서 있게 됩니다. / 이 글은 [남양주 출장열쇠](namyangju.html)를 부르기 전에 확인해 볼 것과 요청하실 때 알려 주시면 좋은 것을 순서대로 적었습니다.
진접역이나 별내 쪽에서 오남읍으로 들어오는 길목이라면 주소를 말씀하시는 방식도 함께 참고해 주세요.

# 철문 자물쇠가 말썽을 부리는 흔한 경우
대문은 비와 눈, 먼지를 그대로 맞기 때문에 실내 도어락보다 훨씬 빨리 낡습니다.
- 열쇠구멍에 흙먼지가 쌓여 열쇠가 끝까지 들어가지 않는 경우
- 오래 써서 열쇠 이가 닳아 핀이 맞지 않는 경우
- 철문이 처지고 문기둥이 기울어 빗장이 팽팽하게 눌려 있는 경우
- 장마 뒤 습기로 자물쇠 속이 굳어 버린 경우
- 겨울 추위에 구멍 안에 물기가 얼어붙은 경우
이 가운데 어느 쪽인지 모르는 채 힘만 주면 열쇠가 부러지는 사고로 이어지니 조심하세요.
@ 오남읍 전원주택 대문 철문 자물쇠 출장열쇠

# 열쇠를 돌리기 전에 손으로 확인할 것
세게 돌리기 전에 열쇠 모양부터 살펴보세요. / 휘어 있거나 끝이 둥글게 닳아 있다면 여분 열쇠로 바꿔서 시도하는 편이 낫습니다.
대문 자체가 한쪽으로 처졌는지 가볍게 들어 올리듯 받쳐 보세요. / 문을 살짝 들어 올린 상태에서 열쇠를 돌리면 빗장이 편해져서 열리는 경우가 있습니다.
빗장이 걸린 기둥 쪽 받침이 눈에 띄게 어긋나 있다면 문 쪽 문제라서 열쇠와는 상관이 없습니다. / 이럴 때는 억지로 열쇠를 비틀지 마세요.

# 겨울에 구멍이 얼었을 때의 대처
오남읍은 겨울 아침 기온이 많이 내려가는 날이 있어서 철문 자물쇠가 얼어붙는 일이 있습니다. / 눈이 녹았다 다시 얼면서 구멍 안에 얼음이 생기는 경우가 대부분입니다.
이럴 때 끓는 물을 붓는 분이 계신데 금속이 갑자기 변하고 다시 얼기까지 하니 피하셔야 합니다. / 손난로나 따뜻한 바람으로 천천히 녹이거나 낮 기온이 오를 때까지 기다리는 편이 안전합니다.
녹은 뒤에도 물기가 남아 있으면 마른 천으로 닦아 주세요.
@ 오남읍 겨울 철문 자물쇠 결빙 점검

# 기름을 넣고 싶을 때의 기준
뻑뻑하다고 식용유나 아무 스프레이를 쓰면 먼지가 엉겨 나중에 더 심해집니다. / 자물쇠 전용 윤활제를 구멍에 아주 조금만 넣는 정도가 적당합니다.
한 번 넣고도 달라지지 않으면 반복하지 마시고 점검을 요청하세요. / 같은 시도를 거듭할수록 안쪽 부품이 더 젖어서 열기가 어려워집니다.

# 열쇠가 부러졌을 때
전원주택은 대문 열쇠를 가족 수대로 복사해 두고 오래 쓰는 집이 많아서 열쇠가 닳은 채로 부러지는 일이 드물지 않습니다. / 한 번 부러진 열쇠로 같은 자물쇠를 계속 쓰면 같은 일이 반복되기 쉽습니다.
구멍 안에서 열쇠가 부러졌다면 그 자리에서 손을 떼세요. / 핀셋으로 당기다 조각이 더 안쪽으로 들어가면 빼내는 일이 훨씬 어려워집니다.
부러진 반쪽은 버리지 말고 보관해 주세요. / 같은 규격으로 열쇠를 다시 만들 때 도움이 됩니다.
사진을 한 장 보내 주시면 장비를 정확히 챙겨 갈 수 있습니다. / 열쇠를 다시 만들 때는 닳은 열쇠가 아니라 처음 받은 원본으로 복사하는 편이 정확합니다.

# 전화할 때는 주소를 먼저 말씀해 주세요
오남읍은 읍 지역이라 건물 번호와 길 이름이 도시 아파트처럼 한눈에 안 들어오는 곳이 있습니다. / 그래서 전화를 받으면 가장 먼저 정확한 주소를 여쭙니다.
- 도로 이름과 번호, 또는 근처에서 눈에 띄는 큰 건물이나 마을 입구
- 진접역이나 별내 방향 중 어느 쪽에서 들어오는지
- 대문 하나만 안 열리는지, 현관까지 안 열리는지
- 자물쇠가 열쇠 방식인지 번호키가 달려 있는지
주소를 정확히 받아야 길을 헤매지 않고 빨리 도착할 수 있습니다. / 지도 앱의 현재 위치를 문자로 보내 주시면 가장 정확합니다.
@ 오남읍 24시 출장열쇠 주소 안내

# 문 사진은 이렇게 찍어 주세요
말로 설명하기 어려운 것은 사진 한 장이 훨씬 빠릅니다.
자물쇠가 달린 철문 전체와 자물쇠를 가까이서 찍은 사진, 이렇게 두 장이면 충분합니다. / 어두운 시간이라면 휴대폰 손전등을 켜고 찍어 주세요.
빗장 방식인지 걸쇠 방식인지 확인되면 어떤 장비를 가져갈지 정하기 쉽습니다. / 부품이 특이한 오래된 자물쇠라면 상표나 글자가 보이게 찍어 주시면 더 좋습니다.

# 거주하시는 분 확인은 이렇게 합니다
대문을 여는 일이라 이 집에 사시는 분이 맞는지 먼저 확인합니다. / 주소가 적힌 신분증이나 우편물, 공과금 고지서면 충분합니다.
신분증이 집 안에 있다면 휴대폰으로 받은 고지서나 계약서 사진을 보여 주셔도 됩니다. / 세입자가 집주인에게 확인을 받아야 하는 경우라면 통화로 확인하겠습니다.
확인할 방법이 전혀 없으면 작업을 진행할 수 없습니다. / 이런 절차는 다른 사람이 같은 방법으로 내 집에 들어오지 못하게 막는 장치입니다.

# 값은 시작하기 전에 정합니다
철문 상태와 자물쇠 종류를 직접 보고 해야 할 일과 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때부터 시작하고, 마음에 들지 않으시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 작업 도중에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 열고 난 뒤 같이 보는 것
철문이 열리면 열쇠가 부드럽게 돌아가는지 몇 번 더 확인합니다. / 한 번 돌아가고 다음에 다시 걸린다면 안쪽이 이미 많이 상했다는 신호입니다.
오래된 자물쇠는 한 번 열렸을 때 바꿔 두는 편이 안심되는 경우도 있습니다. / [출장 열쇠](key-call.html)에서 새 열쇠 복사와 교체를 같이 도와드립니다.
현관 쪽에 도어락이 달려 있다면 [도어락 교체](doorlock-replace.html)나 수리가 필요한지도 함께 봅니다. / [현관문 개문](door-open.html)이 필요한 경우도 한 번에 정리됩니다.
@ 오남읍 철문 자물쇠 교체 후 점검

# 오남읍 말고 남양주 어디든 갑니다
도농동, 별내동, 평내동, 호평동, 진접읍, 와부읍, 화도읍까지 남양주 전 지역에 24시간 출동합니다. / 읍 지역은 주소를 정확히 받은 뒤 도착 시간을 말씀드립니다.
남양주에서 다니는 동네는 [남양주시 출장열쇠](namyangju.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.

# 마무리

24시출장열쇠는 한밤이나 새벽에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
