# 자정 넘은 오남읍, 불 꺼진 골목에서
오남읍은 진접읍과 맞닿은 남양주의 읍으로 아파트와 연립, 마당 있는 주택이 함께 있는 동네입니다. / 시내보다 밤이 일찍 조용해지고, 주택가 골목은 가로등이 띄엄띄엄 서 있는 곳도 있습니다.
늦게 귀가해 현관이나 대문 앞에서 문이 안 열리면 주변에 도움을 청할 곳이 마땅치 않습니다. / 이럴 때는 전화 한 통으로 위치와 상황을 얼마나 정확히 전하느냐가 기다리는 시간을 좌우합니다.
이 글은 오남읍에서 밤늦게 문이 막혔을 때 통화 전에 챙길 것과 말하는 순서, 기다리는 동안 할 일을 적었습니다. / 바로 연락하실 분은 [남양주 출장열쇠](namyangju.html)로 전화 주세요.
@ 오남읍 한밤 주택 대문 앞 출장열쇠 요청

# 전화 걸기 전 30초
급한 마음에 바로 전화를 걸기 전에 아래 세 가지만 확인해 보세요. / 통화가 훨씬 짧고 정확해집니다.
- 휴대폰 배터리가 얼마나 남았는지
- 막힌 문이 대문인지, 현관인지, 둘 다인지
- 번호판이 켜지는지, 열쇠가 들어가는지
배터리가 얼마 없다면 화면 밝기를 낮추고 다른 앱은 꺼 두세요. / 도착할 때까지 통화와 위치 확인을 몇 번 더 해야 합니다.

# 오남읍은 위치 설명이 절반입니다
아파트라면 단지 이름과 동, 호수만으로 충분합니다. / 그런데 마당 있는 주택이나 연립은 내비게이션이 큰길에서 멈추거나 비슷한 길로 안내하는 경우가 있습니다.
도로명 주소를 먼저 말씀해 주시고, 들어오는 길에 보이는 표시를 하나 더 알려주세요. / 큰길에서 어느 방향으로 꺾는지, 근처에 무엇이 있는지 정도면 됩니다.
휴대폰 지도 앱의 위치 공유 기능을 쓰실 수 있다면 문자로 보내 주셔도 좋습니다. / 어두운 길에서도 정확한 지점을 찾을 수 있습니다.
@ 오남읍 주택가 밤길 위치 공유

# 통화는 이 순서로 말해 주세요
첫마디에 모든 걸 말하려 하면 오히려 빠지는 게 생깁니다. / 아래 순서대로 하나씩 말씀해 주시면 됩니다.
위치를 먼저, 그다음 막힌 문의 종류를 말씀해 주세요. / 이어서 번호판 상태나 열쇠 상태를 알려주시고, 집 안에 사람이나 반려동물이 있는지 말씀해 주시면 끝입니다.
통화가 끝나면 위치를 듣고 도착 예상 시간을 바로 말씀드립니다. / 오남읍은 동네 사이 거리가 있어 이 시간을 먼저 듣고 기다리시는 게 마음이 편합니다.

# 대문과 현관, 둘 다 막혔다면
마당 있는 주택은 대문을 지나야 현관에 닿습니다. / 대문 열쇠와 현관 열쇠를 한 꾸러미에 달고 다니다 같이 잃어버리면 두 문이 모두 막힙니다.
이럴 때는 대문부터 열고 현관을 여는 순서로 진행합니다. / 전화하실 때 두 문이 모두 막혔다고 말씀해 주시면 맞는 장비를 함께 챙겨 갑니다.
대문 너머로 마당에 개가 있다면 그것도 꼭 알려주세요. / 밤에 낯선 사람이 들어오면 놀라서 짖거나 달려들 수 있습니다.

# 기다리는 동안 어디에 있을까
한겨울 밤이라면 문 앞에서 오래 서 있지 마세요. / 차가 있다면 차 안에서, 없다면 가까운 편의점처럼 불이 켜진 곳에서 기다리셔도 됩니다.
도착하기 몇 분 전에 다시 전화를 드립니다. / 그때 집 앞으로 나와 계시면 됩니다.
아파트라면 경비실에 사정을 알리고 1층에서 기다리셔도 좋습니다. / 단지 출입이 막혀 있는 시간이라면 경비실에 미리 말해 두면 출장 차량이 들어가기 수월합니다.
@ 오남읍 아파트 경비실 앞 대기

# 한겨울 밤 번호판이 꺼졌다면
추운 밤에는 도어락 배터리 힘이 떨어져 번호판 반응이 느려지거나 아예 꺼지기도 합니다. / 며칠 전부터 경고음이 났는데 지나쳤다면 배터리 쪽일 가능성이 큽니다.
바깥쪽 번호판 아래에 비상 전원 단자가 있는 제품이라면 9V 건전지를 대 보세요. / 가까운 편의점에서 건전지를 구할 수 있다면 출장을 부르기 전에 한 번 시도해 볼 만합니다.
건전지를 대도 반응이 없거나 단자를 못 찾겠다면 그때 연락 주시면 됩니다. / 이미 출장을 불러 둔 뒤 열렸다면 전화로 알려 주세요.

# 밤이라 더 조심할 것
- 어두운 곳에서 번호를 계속 누르다 입력 제한 걸리기
- 창문이나 담을 넘어 들어가려는 시도
- 술을 마신 상태로 열쇠를 세게 비틀기
- 휴대폰 손전등을 켜 둔 채 배터리 다 쓰기
특히 담을 넘거나 창문으로 들어가는 것은 다칠 위험이 큽니다. / 이웃이 보고 놀라 신고하는 일도 생길 수 있습니다.
번호가 헷갈린다면 서너 번까지만 눌러 보고 멈추세요. / 입력 제한이 걸리면 한동안 맞는 번호를 넣어도 반응하지 않아 오히려 시간이 더 걸립니다.

# 이웃에게 도움을 청한다면
밤늦게 이웃 문을 두드리기는 조심스럽습니다. / 그래도 휴대폰이 꺼졌거나 집 안에 있다면 불이 켜진 집에 짧게 사정을 말하고 전화를 빌려 보세요.
빌린 전화로 연락 주시면 그 번호로 다시 연락드립니다. / 이웃께 잠시 양해를 구해 두시면 좋습니다.
연립이나 다세대라면 같은 건물 이웃이 집주인 연락처를 알고 있을 수도 있습니다. / 집주인이 여분 열쇠를 갖고 있다면 그쪽이 더 빠를 수 있으니 함께 알아보세요.

# 도착하면 먼저 하는 일
밤이라도 사시는 분인지 확인은 꼭 거칩니다. / 신분증 주소, 주소가 나온 우편물, 아파트라면 관리사무소나 경비실 확인 가운데 하나면 됩니다.
신분증이 집 안에 있다면 휴대폰 속 계약서나 택배 주소 화면도 도움이 됩니다. / 확인이 되면 문 상태를 보고 비용을 먼저 말씀드립니다.

# 비용과 시간 이야기
밤이나 새벽이라고 말없이 붙는 비용은 없습니다. / 문 상태와 잠금장치 종류를 보고 손대기 전에 얼마인지 먼저 말씀드리고, 괜찮다고 하실 때만 시작합니다.
끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html), 여는 방법은 [현관문 개방](door-open.html)에 적어 두었습니다.

# 문이 열린 뒤 그 밤에 할 일
배터리 방전이었다면 그 자리에서 새 배터리로 바꿔 드립니다. / 번호를 잊었다면 안쪽에서 새 번호를 등록하고 예전 번호는 지웁니다.
열쇠를 잃어버린 것이라면 그날 밤은 일단 들어가시고, 대문과 현관 실린더를 바꿀지는 다음 날 정하셔도 됩니다. / 도어락 고장이 원인이었다면 [도어락 수리](doorlock-repair.html)로 손보고, 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.

# 오남읍 말고 남양주 어디든
바로 옆 진접읍부터 별내동, 다산동, 평내동, 호평동, 금곡동과 화도읍, 와부읍, 퇴계원읍, 진건읍까지 다닙니다. / 늦은 밤에도 위치를 받으면 도착 시간을 먼저 말씀드리고 출발합니다.
남양주 안내는 [남양주시 출장열쇠](namyangju.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
