# 오래된 현관문이 계절마다 다르게 굴 때
오남읍은 진접읍과 맞닿은 읍으로 아파트와 연립, 마당 있는 주택이 함께 있는 동네입니다. / 오래 살아온 집이 많아 현관문과 문틀도 집과 함께 나이를 먹었습니다.
여름에는 문이 뻑뻑하다가 겨울이면 조금 헐거워지고, 어느 날은 걸쇠가 문틀에 걸려 번호를 맞게 눌러도 안 열립니다. / 도어락이 고장 난 줄 알았는데 알고 보면 문이 처져서 생긴 일인 경우가 꽤 많습니다.
이 글은 오남읍에서 오래된 문이 처지거나 경첩이 헐거워져 안 열릴 때 집에서 살펴볼 곳과 [남양주 출장열쇠](namyangju.html)가 손보는 순서를 정리했습니다.
@ 오남읍 오래된 현관문 처짐 경첩

# 처진 문이 보내는 신호
문은 하루아침에 처지지 않습니다. / 아래 같은 일이 조금씩 늘었다면 문이 내려앉고 있다는 신호입니다.
- 문을 닫을 때 끝에서 툭 걸리는 느낌이 든다
- 잠그려면 문을 몸으로 한 번 밀어야 한다
- 걸쇠가 문틀 금속판 아래쪽을 긁은 자국이 있다
- 문 아래가 현관 바닥에 스치는 소리가 난다
- 손잡이를 아래로 누른 채 당겨야 열린다
이런 증상을 그냥 두면 도어락 모터와 걸쇠가 매번 무리하게 일해 결국 고장으로 이어집니다.

# 경첩 나사부터 손으로 확인
문이 처지는 가장 흔한 원인은 경첩 나사가 풀리는 것입니다. / 문을 연 채로 경첩 쪽 문틀에 박힌 나사를 손가락으로 만져 보세요.
나사 머리가 튀어나와 있거나 손으로 돌려지는 게 있다면 헐거워진 상태입니다. / 드라이버로 살짝 조여 주는 것만으로 문이 제자리로 올라오는 경우도 있습니다.
다만 나사를 조여도 헛돌기만 한다면 나사 구멍이 넓어진 것입니다. / 이때는 억지로 더 조이지 마시고 그대로 두세요. 구멍을 보강해야 합니다.
@ 오남읍 현관문 경첩 나사 헐거움 확인

# 문 위아래 틈 비교하기
문을 닫은 상태에서 문과 문틀 사이 틈을 위쪽과 아래쪽에서 비교해 보세요. / 손잡이 쪽 위 틈이 넓고 아래 틈이 좁다면 문이 경첩 반대쪽으로 처진 것입니다.
틈 사이로 동전이나 카드를 넣어 보면 차이를 쉽게 알 수 있습니다. / 위쪽은 쑥 들어가는데 아래쪽은 안 들어간다면 처짐이 꽤 진행된 상태입니다.
이 차이를 사진으로 찍어 두시면 점검을 맡길 때 큰 도움이 됩니다.
문을 닫을 때 손잡이 쪽 모서리가 문틀 윗부분을 먼저 건드리는지, 아랫부분을 먼저 건드리는지도 지켜보세요. / 먼저 닿는 쪽이 처진 방향을 알려 주는 단서가 됩니다.

# 바닥에 끌린 자국 보기
현관 바닥이나 문턱에 문 모서리가 지나간 반달 모양 자국이 있다면 문이 내려앉아 바닥을 스치고 있는 것입니다. / 오래된 주택은 현관 타일이 들떠 바닥이 조금 올라온 경우도 있습니다.
바닥 쪽 원인이라면 문보다 바닥 상태를 함께 봐야 합니다. / 어느 쪽인지 헷갈리시면 자국 사진을 함께 보내 주세요.

# 안 열릴 때 들어 올리며 열어 보기
번호는 맞았는데 걸쇠가 문틀에 걸려 안 열린다면 문의 무게를 잠깐 덜어 주는 방법을 써 볼 수 있습니다. / 손잡이를 잡고 문을 위로 살짝 들어 올리는 느낌으로 당기면서 다시 열림을 시도해 보세요.
안쪽으로 미는 문이라면 손잡이 쪽 문 위를 손바닥으로 지그시 누르며 열어 봅니다. / 걸쇠가 문틀 금속판에 눌린 힘이 풀리면서 열리는 경우가 있습니다.
힘은 손으로 드는 정도면 충분합니다. / 어깨로 밀거나 발로 차는 건 문틀을 더 틀어지게 할 뿐입니다.

# 주택 나무문과 아파트 철문은 다르게 봅니다
마당 있는 주택의 나무 현관문은 습기를 먹으면 부풀고 마르면 줄어듭니다. / 장마철에만 뻑뻑하다면 문이 처졌다기보다 나무가 부푼 경우일 수 있습니다.
아파트나 연립의 철문은 무게가 많이 나가 경첩에 걸리는 힘이 큽니다. / 철문은 계절보다는 시간이 지나며 경첩이 서서히 늘어나 처지는 경우가 대부분입니다.
문의 재질에 따라 손보는 방법도 달라지니 통화할 때 어떤 문인지 함께 알려 주세요.

# 무리하면 생기는 일
처진 문을 매일 몸으로 밀어 잠그다 보면 걸쇠가 휘고 문틀 금속판이 뒤로 밀려납니다. / 그러면 문을 바로잡아도 걸쇠가 맞지 않아 부품까지 바꿔야 하는 일이 생깁니다.
문틀 틈에 종이나 고무를 끼워 맞추는 임시방편도 오래 쓰면 오히려 문을 더 비틀어 놓습니다. / 증상이 느껴지기 시작했을 때 점검을 받는 게 길게 보면 가장 덜 번거롭습니다.

# 연락하실 때 보내 주시면 좋은 것
아래 내용을 정리해 주시면 맞는 부품과 공구를 챙겨 가기 좋습니다.
- 도로명 주소와 집 형태: 아파트, 연립, 단독주택
- 문 재질: 철문인지 나무문인지
- 지금 상태: 아예 안 열리는지, 잠그기만 어려운지
- 사진: 경첩 쪽, 위아래 틈, 바닥 자국
오남읍은 남양주 안에서도 들어오는 길이 여러 갈래라 큰길에서 어느 쪽으로 들어오는지 함께 알려 주시면 도착이 빨라집니다.

# 확인과 비용 안내
문이 잠겨 들어가지 못하는 상황이라면 열기 전에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소나 이웃 확인 가운데 하나면 됩니다.
문 상태를 본 뒤 비용을 먼저 말씀드리고 동의하시면 시작합니다. / 열지 못하면 비용은 받지 않으며, 진행 흐름은 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 남양주 출장열쇠 오남읍 처진 문 점검

# 손보는 순서는 경첩부터
처진 문은 보통 경첩, 걸쇠가 들어가는 금속판, 도어락 순서로 봅니다. / 경첩 나사 구멍을 보강해 문을 제자리로 올리면 그것만으로 해결되는 경우가 많습니다.
문을 올려도 걸쇠가 맞지 않으면 문틀 금속판 위치를 조정합니다. / 그래도 도어락이 무리하게 움직인다면 그때 도어락 부품 상태를 확인합니다.
도어락이 처짐 때문에 이미 상했다면 [도어락 수리](doorlock-repair.html)로 손보고, 부품을 구하기 어려우면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 문 자체가 많이 상했다면
문틀이 썩거나 갈라졌거나, 문 몸체가 휘었다면 경첩과 도어락만으로는 한계가 있습니다. / 이 경우 문과 문틀 공사가 필요할 수 있어 상태를 보고 솔직하게 말씀드립니다.
급하게 문을 여는 것과 당장 쓸 수 있게 맞춰 두는 것까지는 해 드리고, 큰 공사는 따로 알아보시도록 안내합니다.

# 오남읍 주변 남양주 어디든
오남읍과 가까운 진접읍, 별내동, 진건읍, 퇴계원읍은 물론 화도읍, 호평동, 평내동, 금곡동, 다산동, 와부읍까지 다닙니다. / 남양주 안내는 [남양주 출장열쇠](namyangju.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
