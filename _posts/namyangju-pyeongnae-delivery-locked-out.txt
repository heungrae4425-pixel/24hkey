# 평내동에서 잠깐 나갔다가 문이 닫혔다면
택배를 받으러, 분리수거를 하러, 이웃에게 뭘 전해 주러 잠깐 나갔다가 뒤에서 문이 철컥 닫히는 일은 생각보다 흔합니다. / 휴대폰도 열쇠도 집 안에 두고 나온 채로 서 계시면 마음이 급해집니다.
평내동은 평내호평역 주변으로 아파트와 빌라가 이어진 주거지라 이런 문의가 적지 않습니다. / 이 글은 [남양주 출장열쇠](namyangju.html)를 부르기 전에 확인할 것과 연락하는 순서를 정리했습니다.
@ 평내동 문 잠겨 못 들어갈 때 출장열쇠

# 문이 저절로 잠기는 구조를 알아 두세요
많은 도어락은 문이 닫히면 자동으로 걸쇠가 잠기는 방식입니다. / 손잡이를 돌려 열어 둔 채 나가도 문이 닫히는 순간 잠깁니다.
손잡이만 있는 문과 달리 안쪽에서 열 수는 있지만 바깥에서는 번호나 카드, 열쇠가 있어야 합니다. / 그래서 맨몸으로 나왔다면 바로 막힙니다.
오토락 기능이 켜져 있는 집은 특히 조심해야 합니다. / 설정 방법은 제품마다 다르니 한 번쯤 설명서를 확인해 두면 좋습니다.

# 먼저 침착하게 확인할 것
문 앞에서 아래 순서로 천천히 살펴보세요.
- 집 안에 가족이 있는지, 인터폰이나 전화로 연락이 닿는지
- 주머니나 신발에 카드키나 열쇠가 있지 않은지
- 이웃이나 부모님 댁에 맡겨 둔 보조 열쇠가 있는지
- 휴대폰이 없으면 이웃에게 잠깐 빌려 연락할 수 있는지
번호를 아는 도어락이라면 번호를 눌러서 열면 됩니다. / 번호를 모르고 나왔다면 가족에게 물어보는 것이 가장 빠릅니다.
@ 평내동 가족 연락 보조 열쇠 확인

# 집 안에 가족이 있을 때
안에 사람이 있다면 안쪽에서 문을 열어 달라고 하면 됩니다. / 안쪽 손잡이나 레버는 번호가 필요 없는 경우가 대부분입니다.
인터폰이 닿지 않아도 문을 두드리면 들릴 수 있습니다. / 어린아이만 있는 경우에는 놀라지 않도록 문 너머로 계속 이야기해 주세요.
어르신이 혼자 계신 경우에는 문 열기가 어려울 수 있습니다. / 이때는 이웃이나 관리하시는 분의 도움을 먼저 받아 보세요.

# 아무도 없다면 이렇게 하세요
집 안에 아무도 없다면 이제 열쇠집을 부르는 방법이 남습니다. / 휴대폰이 없으면 가까운 가게나 이웃의 도움을 받아 연락하셔도 됩니다.
위치와 상황을 알려주시면 바로 출동 여부를 말씀드립니다. / 추운 날씨나 비가 오는 날이라면 바람을 피할 곳에서 기다리시도록 안내합니다.
가스 불을 켜 두고 나왔거나 아이가 혼자 있다면 먼저 말씀해 주세요. / 급한 상황이면 119에 먼저 도움을 청하셔야 할 수도 있습니다.

# 이런 때 특히 자주 생깁니다
평내동처럼 아파트 복도식 구조가 많은 곳에서는 이웃에게 짐을 건네러 잠깐 나가는 일이 흔합니다. / 새벽에 배달 음식을 받으러 나갔다가 문이 닫히는 경우도 적지 않습니다.
쓰레기를 버리러 나가거나 아이 등하원을 도우러 나간 사이에 닫히는 일도 있습니다. / 이럴 때 당황해서 도어락을 세게 두드리거나 손잡이를 흔들면 오히려 고장이 날 수 있습니다.
가능하면 문에서 한 걸음 물러나 상황을 정리한 뒤 하나씩 해결해 보세요.

# 전화하실 때 알려주세요
짧게 정리해서 말씀해 주시면 도착이 빨라집니다.
- 평내동 위치와 건물 입구 정보, 몇 층 몇 호인지
- 도어락 모양과 번호판이 있는지
- 문이 닫힌 지 얼마나 됐는지, 집 안에 사람이 있는지
- 지금 계신 곳이 안전한지
현재 위치를 지도 앱으로 보내주시면 찾아가기 편합니다. / 도어락 사진이 있으면 문자로 같이 보내주세요.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인하는 절차가 있습니다. / 신분증 주소나 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증을 집 안에 두고 나오셨다면 가족이나 이웃, 관리사무소를 통해 확인할 수 있는 방법을 먼저 말씀해 주세요. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 평내동 24시 출장열쇠 잠긴 문 개문 비용 안내

# 문은 어떻게 여나요
택배나 짧은 외출 때문에 닫힌 문은 도어락이 고장 난 것이 아니라 잠금이 정상 작동한 것입니다. / 그래서 부품을 건드리지 않고 여는 방식을 우선 시도합니다.
도어락과 문이 상하지 않는 방법부터 차례로 시도합니다. / 어떤 방식으로 열지는 도어락 종류와 문 상태에 따라 달라집니다.
자세한 순서는 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 작업 중에 부품 손상이 걱정되면 손대기 전에 설명해 드립니다.

# 열린 뒤에 같이 해 두면 좋은 것
문이 열린 직후에는 안으로 들어가 열쇠와 휴대폰이 어디 있는지부터 챙기세요. / 다음에 같은 일이 생기지 않도록 현관 옆 한 자리에 두는 습관이 도움이 됩니다.
문이 열리면 도어락이 정상인지 먼저 확인합니다. / 이런 일이 반복되는 집이라면 [도어락 수리](doorlock-repair.html)나 설정 변경이 필요한지 살펴봅니다.
열쇠나 카드를 한 개 따로 만들어 이웃이나 부모님께 맡겨 두는 방법도 권해 드립니다. / 문이 닫혀도 다시 들어갈 수 있는 통로 하나를 만들어 두는 셈입니다.
오토락을 쓰는 집이라면 문을 열어 둔 채로 나갈 때 잠시 걸쇠를 고정하는 방법도 알려 드립니다.

# 다음에 똑같은 일이 없도록
오토락 설정을 쓰는 집이라면 문이 닫히는 순간 잠긴다는 점을 가족 모두가 알고 있어야 합니다. / 어린 자녀가 혼자 나갔다 들어올 때도 같은 규칙을 알려 두면 좋습니다.
작은 습관 몇 가지로 막힐 일을 많이 줄일 수 있습니다.
- 현관을 나설 때 휴대폰과 열쇠를 손에 쥐었는지 확인하기
- 택배 받으러 나갈 때도 문을 완전히 닫지 않고 신발 하나로 걸쳐 두기
- 카드나 열쇠를 집 밖에 믿을 만한 곳에 하나 맡겨 두기
- 번호는 가족이 모두 기억하는 규칙으로 정하기
문 앞에 열쇠를 숨겨 두는 것은 오히려 위험합니다. / 믿을 수 있는 사람에게 맡기는 편이 안전합니다.

# 평내동 말고 남양주 어디든 갑니다
다산동, 별내동, 호평동, 금곡동, 와부읍, 진접읍, 오남읍, 화도읍, 퇴계원읍, 진건읍까지 남양주 전 지역 24시간 출동합니다. / 지역이 서로 떨어져 있어서 정확한 주소를 먼저 받고 도착 시간을 말씀드립니다.
남양주에서 다니는 동네는 [남양주시 출장열쇠](namyangju.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
