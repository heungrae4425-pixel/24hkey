# 와부읍 오래된 집 문이 뻑뻑해졌다면
와부읍은 오래 사신 분들이 많은 주택과 아파트, 한강 가까운 주거지가 이어진 지역입니다. / 오래된 집은 문과 문틀이 세월에 따라 조금씩 틀어져 열쇠가 안 맞거나 도어락이 뻑뻑해지는 일이 생깁니다.
열쇠는 멀쩡한데도 문이 안 열려서 도어락을 바꿔야 하나 고민하시는 분이 많습니다. / 이 글은 [남양주 출장열쇠](namyangju.html)를 부르기 전에 문틀 문제인지 도어락 문제인지 가늠하는 방법을 정리했습니다.
@ 와부읍 오래된 문틀 틀어짐 열쇠 안 맞음 출장열쇠

# 문틀이 틀어지는 이유
오래된 집의 문틀은 아래 이유로 조금씩 달라집니다.
- 장마철 습기를 먹고 문이 부풀었다가 마르면서 뒤틀린 경우
- 오랜 시간 문을 여닫으며 경첩이 헐거워져 문이 처진 경우
- 건물이 미세하게 내려앉아 문틀이 기운 경우
- 문틀 나무가 썩거나 갈라진 경우
이런 변화는 한 번에 오지 않고 서서히 쌓입니다. / 그래서 어느 날 갑자기 안 되는 것처럼 느껴져도 사실은 오래전부터 진행된 경우가 많습니다.

# 문이 틀어졌는지 확인하는 법
방법이 어렵지 않아서 집에서 바로 해 보실 수 있습니다.
문을 열었다 닫으며 눈으로 살펴보세요.
문 모서리가 문틀에 스치는 흔적이 있는지 봅니다. / 한쪽이 벌어지고 한쪽이 붙어 있으면 문이 틀어진 것입니다.
걸쇠가 문틀 홈에 정확히 들어가는지 확인합니다. / 살짝 눌러야만 들어가면 위치가 어긋난 것입니다.
열쇠를 돌릴 때 문을 살짝 밀거나 당기면 돌아가는지 봅니다. / 그렇다면 열쇠 구멍 문제가 아니라 문틀과 걸쇠 위치 문제일 가능성이 큽니다.
@ 와부읍 문틀 틈새 걸쇠 위치 확인

# 도어락만 바꾸면 해결될까요
문이 처져서 생긴 문제는 도어락을 바꿔도 해결되지 않는 경우가 많습니다. / 새 도어락을 달았는데 똑같이 안 맞아서 다시 연락 주시는 분도 있습니다.
먼저 문 상태를 보고 경첩, 문틀, 받음쇠(걸쇠가 들어가는 쪽 금속판) 중 어디를 손봐야 하는지 가려야 합니다. / 저희는 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
문틀이 심하게 상했다면 도어락보다 문 자체를 손봐야 할 수도 있습니다. / 이 경우는 먼저 상태를 보고 말씀드립니다.

# 열쇠가 안 맞을 때 하지 말아야 할 것
오래된 집은 이전에 문을 한 번 손본 흔적이 있는 경우도 많습니다. / 예전에 구멍을 넓히거나 부품을 덧댄 자리라면 일반 규격과 달라서 상태를 보고 판단해야 합니다.
열쇠가 안 돌아갈 때 힘으로 비트는 것이 가장 위험합니다. / 열쇠가 휘거나 구멍 안에서 부러질 수 있습니다.
기름을 아무거나 뿌리는 것도 피하세요. / 끈적이는 기름은 먼지를 붙여서 나중에 더 심하게 막힙니다.
문을 발로 차거나 어깨로 밀어 억지로 열려는 것도 문틀을 더 망가뜨립니다. / 열쇠가 안 맞는다면 멈추고 상태를 확인해 보세요.

# 전화하실 때 알려주세요
짧게 정리해서 말씀해 주시면 도착이 빨라집니다.
- 와부읍 위치와 건물 입구 정보, 몇 층 몇 호인지
- 열쇠가 안 돌아가는지, 문이 안 닫히는지, 도어락이 안 열리는지
- 문이 처졌는지, 문틀에 틈이 보이는지
- 집이 몇 년쯤 된 곳인지, 도어락을 바꾼 적이 있는지
문 전체와 열쇠 구멍 쪽 사진을 같이 보내주시면 필요한 장비를 챙겨 가기 좋습니다. / 문이 아예 안 열리면 [현관문 개문](door-open.html) 순서로 진행합니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인하는 절차가 있습니다. / 신분증 주소나 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
세입자가 요청하시는 경우에는 집주인께 통화로 확인할 수 있어야 합니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문과 도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 문틀 문제인지 도어락 문제인지 설명드린 뒤 진행합니다.
@ 와부읍 24시 출장열쇠 오래된 문 점검 비용 안내

# 문틀과 걸쇠를 어떻게 맞추나요
문과 문틀이 어긋난 정도는 눈으로 보이지 않을 만큼 작아도 걸쇠에는 크게 작용합니다. / 그래서 현장에서 문을 몇 번 여닫으며 걸리는 지점을 직접 확인합니다.
걸쇠가 들어가는 받음쇠 위치를 조금 옮기거나 구멍을 정리해서 맞추는 방법이 가장 흔합니다. / 문틀 전체를 건드리지 않고 필요한 부분만 손보는 방식입니다.
경첩 나사를 조이거나 위치를 보정해서 처진 문을 바로잡기도 합니다. / 나사 구멍이 닳았다면 따로 보강해서 고정합니다.
작업 전에 어떤 부분을 어떻게 손볼지 설명드립니다. / 문틀 나무가 많이 상한 경우에는 무리하게 손대지 않고 상태를 먼저 말씀드립니다.

# 도어락 수리와 교체는 이렇게 가립니다
문 쪽이 정리된 뒤에도 같은 증상이 남는지 먼저 확인한 다음 도어락 판단으로 넘어갑니다. / 순서를 바꾸면 불필요한 교체로 이어질 수 있습니다.
문이 정리된 뒤에도 도어락이 말을 안 들으면 그때 도어락 쪽을 봅니다. / 배터리나 접점, 손잡이 쪽 문제는 [도어락 수리](doorlock-repair.html)로 해결되는 경우가 많습니다.
정말 오래돼서 부품이 없거나 보안이 불안할 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
오래된 집이라도 문과 도어락 상태가 괜찮으면 굳이 바꾸시지 않아도 됩니다.

# 오래된 집 문을 오래 쓰는 요령
집 안에서 문을 닫을 때 소리가 둔해지거나 틈새로 바람이 들어오는 느낌이 있다면 문틀이 움직였다는 신호일 수 있습니다.
문 상태는 계절에 따라 달라지기도 합니다. / 여름에는 뻑뻑하고 겨울에는 헐거운 느낌이 든다면 습기와 온도 영향이 크다는 뜻이니 계절마다 한 번씩 확인하세요.
작은 관리만 해도 문 상태가 크게 달라집니다.
- 장마철 뒤에 문틀 틈과 경첩 나사 상태 보기
- 문에 무거운 짐이나 가방을 걸어 두지 않기
- 문을 세게 닫지 않고 손으로 받쳐 닫기
- 열쇠가 뻑뻑해지는 느낌이 들면 일찍 점검 받기
문이 평소와 다르다는 느낌이 곧 신호입니다. / 문제가 커지기 전에 손보면 비용도 시간도 훨씬 덜 듭니다.

# 와부읍 말고 남양주 어디든 갑니다
다산동, 별내동, 평내동, 호평동, 금곡동, 진접읍, 오남읍, 화도읍, 퇴계원읍, 진건읍까지 남양주 전 지역 24시간 출동합니다. / 지역이 서로 떨어져 있어서 정확한 주소를 먼저 받고 도착 시간을 말씀드립니다.
남양주에서 다니는 동네는 [남양주시 출장열쇠](namyangju.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
