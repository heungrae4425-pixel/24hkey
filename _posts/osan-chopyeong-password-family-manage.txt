# 비밀번호는 바꾸는 것보다 관리가 어렵습니다
초평동에서 가족이 함께 사는 집은 도어락 비밀번호를 여러 사람이 알고 있는 경우가 많습니다. / 한 번 정해 놓고 몇 년씩 그대로 쓰는 집이 대부분입니다.
이 글은 비밀번호를 가족과 어떻게 나누고 언제 바꾸면 좋은지, 잊어버리지 않게 관리하는 방법을 정리했습니다. / 도어락 설정이 어려우면 [오산 출장열쇠](osan.html)가 도와드립니다.
@ 초평동 도어락 비밀번호 관리 출장열쇠

# 비밀번호는 누가 알고 있나요
먼저 지금 번호를 아는 사람을 한번 꼽아 보세요. / 가족뿐 아니라 이전 세입자, 청소나 돌봄을 맡았던 분, 택배 때문에 알려준 사람까지 포함됩니다.
번호를 아는 사람이 많을수록 바꿔야 할 이유가 늘어납니다. / 누가 아는지 모르겠다면 지금 바꿀 때입니다.

# 이럴 때는 바로 바꾸세요
이사를 왔거나 가족 구성이 바뀌었을 때, 번호를 아는 사람이 이사를 가거나 관계가 달라졌을 때입니다. / 열쇠나 카드를 잃어버렸을 때도 번호를 같이 바꾸는 것이 안전합니다.
누군가 번호를 훔쳐보았다는 느낌이 들 때도 마찬가지입니다. / 찜찜하면 바꾸는 게 맞습니다.

# 얼마나 자주 바꾸는 게 좋을까
정해진 정답은 없지만 해가 바뀔 때처럼 기준 시점을 정해 두면 잊지 않습니다. / 건전지를 바꾸는 날 번호도 같이 점검하는 방법도 좋습니다.
너무 자주 바꾸면 가족이 헷갈려서 오히려 문 앞에서 막힙니다. / 가족이 모두 기억할 수 있는 주기로 정하세요.
@ 초평동 가정 현관 도어락 번호 변경

# 기억하기 쉽지만 남이 못 맞추는 번호
생일이나 전화번호 뒷자리처럼 쉽게 짐작되는 번호는 피하세요. / 같은 숫자 반복이나 1234 같은 연속된 숫자도 마찬가지입니다.
가족만 아는 날짜를 조합하거나 의미 있는 숫자를 섞어 보세요. / 너무 어려우면 잊어서 문 앞에서 막히니 적당한 선을 찾으세요.

# 가족과 번호를 나누는 방법
번호를 문자나 메신저로 보내면 남아서 위험해질 수 있습니다. / 말로 알려주거나 직접 만나서 확인시키는 방법이 안전합니다.
어린 아이가 있다면 숫자를 외우기 쉽게 노래처럼 알려주는 집도 있습니다. / 번호를 적은 쪽지를 현관 주변에 두는 것은 피하세요.

# 번호를 잊었을 때 대비책
가족 중 한 명은 번호를 따로 안전한 곳에 적어 두면 좋습니다. / 휴대폰 메모에 적을 때는 이름을 바로 알아볼 수 없게 적어야 안전합니다.
보조 열쇠나 카드를 하나 정해진 곳에 보관해 두면 도움이 됩니다. / 그래도 열리지 않으면 [출장열쇠](key-call.html)를 불러 주세요.

# 번호를 잊어서 연 경우는 이렇게 합니다
번호를 몰라 문을 연 뒤에는 새 번호를 바로 등록하는 것이 좋습니다. / 이전 번호는 지우고 새 번호만 남겨 둡니다.
24시출장열쇠는 문을 열고 난 뒤 새 번호 등록까지 같이 도와드립니다. / 가족에게 새 번호를 알려주는 방법도 같이 안내드립니다.
@ 초평동 도어락 새 번호 등록 작업

# 택배·청소·돌봄을 맡길 때
집에 사람을 들일 때마다 번호를 알려줘야 하는 상황이 생깁니다. / 일회용 번호를 지원하는 제품이라면 그 기능을 쓰는 게 가장 좋습니다.
그런 기능이 없다면 일이 끝난 뒤 바로 번호를 바꾸는 습관을 들이세요. / 번호를 바꾸는 방법은 제품마다 다르니 설명서나 전화로 확인해 보세요.

# 카드키와 번호를 같이 쓰는 방법
번호만 쓰면 누가 훔쳐볼 위험이 있고 카드만 쓰면 잃어버릴 위험이 있습니다. / 둘을 같이 쓰면 서로 단점을 보완할 수 있습니다.
카드를 잃어버렸을 때는 그 카드만 삭제하면 되는 제품도 있습니다. / 어떻게 하는지는 제품마다 다르니 도어락 모델을 알려주세요.

# 번호판에 지문이 남는 문제
번호판에 지문이나 손때가 남으면 자주 누르는 숫자가 드러납니다. / 마른 천으로 가끔 닦아 주거나 보호 필름을 붙이는 방법이 있습니다.
번호판 위에 다른 숫자를 한두 번 눌러 흔적을 섞어 주는 제품도 있습니다. / 어떤 기능이 있는지는 제품 설명서를 확인해 보세요.

# 비용은 작업 전에 말씀드립니다
번호 변경이나 설정은 간단한 일이라도 도어락 종류에 따라 시간이 다릅니다. / 작업 전에 얼마가 드는지 먼저 말씀드립니다.
마음에 안 드시면 그냥 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 초평동에서 오산 어디든 갑니다
초평동 바로 옆 오산동, 원동, 궐동, 세교동, 신장동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
오산에서 다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

# 번호를 바꾼 날 해두면 좋은 확인
번호를 바꾼 뒤에는 문을 닫은 상태에서 바깥에서 새 번호로 열어 보세요. / 안에서만 확인하고 나가면 문 앞에서 막히는 일이 생깁니다.
가족이 모두 새 번호를 알고 있는지, 문 앞에서 한 번씩 직접 눌러 보았는지 확인하세요. / 외출하기 전에 이전 번호가 아직 남아 있지는 않은지도 점검합니다.
바꾼 번호를 잊을 것 같다면 나만 알아볼 수 있는 방식으로 적어 두는 것이 좋습니다. / 문 앞에 두는 쪽지에는 적지 마세요.
