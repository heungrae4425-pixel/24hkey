# 초평동에서 원격 열림을 쓰기 전에
오산 초평동에서 오산역이나 세마역 방향으로 출퇴근하는 분들도 휴대폰으로 도어락을 열 수 있는 원격 열림 기능에 관심을 갖습니다. / 택배나 가족 방문 때 편하지만 설정을 잘못하면 불안한 구석도 생깁니다.
이 글은 겁을 주려는 글이 아니라 안전하게 쓰기 위한 체크리스트입니다. / 계정, 연결, 권한, 알림, 문제 생겼을 때 대처를 순서대로 적었습니다.
문이 안 열리거나 도어락이 이상하면 [오산시 출장열쇠](osan.html)에 연락 주세요. / 문을 못 열면 비용은 받지 않습니다.
@ 초평동 원격 열림 앱과 도어락 화면

# 원격 열림이 가능한 구조부터
원격 열림은 도어락이 집 공유기나 연결 장치를 통해 인터넷에 연결돼 있을 때 작동합니다. / 휴대폰 앱이 서버를 거쳐 도어락에 열림 신호를 보내는 방식이 흔합니다.
그래서 인터넷이 끊기거나 연결 장치가 꺼지면 원격 열림도 안 됩니다. / 원격 기능은 편리한 보조 수단이지 유일한 출입 수단이 되면 곤란합니다.
번호, 카드, 열쇠 같은 기본 수단을 항상 남겨 두는 것이 안전합니다.

# 계정 비밀번호가 곧 현관 열쇠입니다
앱 계정이 뚫리면 원격 열림이 남에게 넘어갈 수 있습니다. / 그래서 앱 계정 비밀번호를 쉽게 정하지 않는 것이 중요합니다.
- 다른 사이트와 같은 비밀번호 쓰지 않기
- 생일이나 전화번호 뒷자리 피하기
- 휴대폰 잠금을 반드시 설정하기
- 가족에게 계정 정보를 무작정 공유하지 않기
앱이 제공한다면 2단계 인증 같은 추가 보안 기능을 켜 두는 것이 좋습니다.

# 휴대폰을 잃어버렸을 때 먼저 할 일
원격 열림이 깔린 휴대폰을 잃어버렸다면 문부터 걱정해야 합니다. / 앱 계정에서 로그아웃시키거나 휴대폰을 분실 처리해 접근을 막는 것이 먼저입니다.
도어락 번호를 바꾸고 등록된 기기를 정리해 두면 더 안전합니다. / 앱 안에 등록 기기 목록이 있다면 모르는 기기가 없는지 확인하세요.
이 모든 일이 급하게 일어나면 당황스러우니 평소에 순서를 정해 두는 것이 좋습니다.

# 가족과 손님에게 권한을 줄 때
원격 열림은 누구에게 어떤 권한을 주는지가 중요합니다. / 가족에게는 상시 권한, 손님이나 일시 방문자에게는 기간을 정한 권한이 어울립니다.
- 상시 사용자와 임시 사용자를 구분하기
- 사용 기간이 끝나면 권한을 바로 회수하기
- 사용하지 않는 사용자는 삭제하기
- 누가 어떤 방식으로 열 수 있는지 가끔 점검하기
권한 정리를 미루면 이전 세입자나 오래전 손님의 접근이 남아 있을 수 있습니다.
@ 초평동 도어락 사용자 권한 목록 확인

# 연결이 끊겼을 때 문이 안 열리는 경우
공유기를 바꾸거나 전원을 뽑았다가 다시 꽂은 뒤 원격 열림이 안 되는 일이 많습니다. / 도어락이 새 네트워크에 다시 연결되지 않았기 때문입니다.
이럴 때는 연결 장치 전원과 공유기 상태, 앱 로그인 상태를 먼저 확인합니다. / 그래도 안 되면 앱에서 연결을 다시 등록해야 할 수 있습니다.
연결이 끊긴 동안에도 번호, 카드, 열쇠로는 열려야 정상입니다. / 이 기본 수단이 막혔다면 도어락 자체 문제입니다.

# 배터리가 약하면 원격 신호도 놓칩니다
원격 열림 기능은 도어락이 연결을 유지하느라 평소보다 전기를 더 쓰는 제품이 많습니다. / 그래서 일반 도어락보다 배터리가 빨리 줄 수 있습니다.
경고음이 나면 그날 바로 새 배터리로 바꾸는 것이 좋습니다. / 배터리가 약하면 원격 신호를 받아도 모터가 힘이 부족해 열리지 않는 경우도 있습니다.
배터리 교체는 한 번에 모두 새것으로 해야 효과가 오래 갑니다.

앱이 제공하는 열림 알림은 누가 언제 열었는지 바로 알려줍니다. / 낯선 시각의 열림 알림은 계정이나 권한을 점검하라는 신호입니다.
알림이 꺼져 있으면 문제가 생겨도 한참 뒤에 알게 됩니다. / 휴대폰 알림 권한이 꺼져 있지 않은지도 확인하세요.
알림만으로 모든 걸 단정할 수는 없지만 확인의 출발점이 됩니다.

# 원격 열림이 오작동할 때 하지 말아야 할 것
문이 열렸다 잠겼다 이상하게 반응한다고 앱을 마구 눌러 보지 마세요. / 신호가 겹쳐 더 헷갈리고 배터리도 빨리 닳습니다.
도어락 본체를 분해해 연결 장치를 만지는 것도 피해 주세요. / 방수나 전기 부분이 상할 수 있습니다.
초기화 버튼을 설명서 없이 누르면 등록 정보가 모두 지워질 수 있습니다. / 먼저 현재 번호를 메모하고 상태를 정리해 두는 것이 좋습니다.

# 신분 확인 후에 진행합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
앱이 열리지 않아 문 앞에서 막힌 경우에도 절차는 같습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.
진행 순서는 [이용안내](guide.html)에서 보실 수 있습니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 손대기 전에 따로 여쭙습니다.
[현관문 개문](door-open.html)과 [출장열쇠 부르는 법](key-call.html)에서 방식과 요청 요령을 확인하실 수 있습니다.
@ 초평동 출장열쇠 스마트 도어락 점검

# 원격 기능을 새로 쓰거나 바꾸고 싶을 때
원격 기능이 없는 도어락에 기능을 추가하고 싶다면 대개 제품 교체가 필요합니다. / 문 두께와 보조키 위치를 먼저 확인하고 맞는 제품을 정합니다.
[도어락 설치](doorlock-install.html)와 [도어락 교체](doorlock-replace.html)에서 확인 항목을 정리해 두었습니다. / 고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)부터 안내하고 교체는 마지막 선택으로 둡니다.
원격 기능이 정말 필요한지, 번호와 카드만으로 충분한지도 함께 따져 보시기 바랍니다.

# 원격 열림을 안전하게 오래 쓰는 습관
세마역이나 오산대역 근처에서 늦게 귀가하는 가족이 있어도 기본 수단은 반드시 남겨 두세요. / 앱이 먹통이 되는 날에 대비하는 것입니다.
- 앱과 도어락 펌웨어 업데이트 확인
- 사용하지 않는 기기와 사용자 정리
- 정기적인 비밀번호 변경
- 배터리는 경고음이 나는 즉시 교체
작은 습관이 쌓이면 원격 기능이 편리함과 안전함 둘 다 지켜 줍니다.

# 초평동 말고 오산 어디든 갑니다
초평동 옆 오산동, 원동, 궐동, 세교동, 신장동, 대원동, 남촌동, 수청동, 갈곶동도 다닙니다. / 오산 안이면 24시간 연락받습니다.
다니는 곳은 [출장 지역](area.html)에서 확인하실 수 있습니다.
