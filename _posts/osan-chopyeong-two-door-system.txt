# 문이 두 겹일 때 더 헷갈리는 이유
초평동은 오산역과 세마역 사이에서 생활하는 분들이 많은 동네입니다. / 현관이 이중문 구조인 집에서는 문이 안 열릴 때 어느 문 때문인지 찾는 일이 먼저입니다.
이중문은 바깥쪽 방화문과 안쪽 방풍문이 따로 달려 있는 형태를 말합니다. / 문이 두 개라 도어락도 두 군데에 있거나 한쪽은 단순한 잠금장치인 경우가 많습니다.
이 글은 이중문 구조에서 잠김이 생겼을 때 어느 쪽이 문제인지 가려내는 방법을 정리했습니다. / 직접 해볼 것과 [오산 출장열쇠](osan.html)를 부를 때의 순서도 담았습니다.
@ 초평동 현관 이중문 방화문 방풍문

# 방화문과 방풍문, 역할이 다릅니다
방화문은 건물 복도 쪽에 면한 두꺼운 문입니다. / 보통 번호키나 열쇠가 달린 주된 출입문이 이쪽입니다.
방풍문은 현관 안쪽에서 바람이나 외풍을 막는 얇은 문입니다. / 걸쇠 정도만 달려 있거나 작은 잠금장치가 붙은 경우가 많습니다.
- 방화문: 도어락, 보조키, 문 닫힘 장치가 달린 주 출입문
- 방풍문: 외풍 차단용, 단순 걸쇠나 작은 잠금
- 둘 다 잠겨 있으면 안쪽부터 풀어야 하는지 바깥쪽부터 풀어야 하는지 헷갈림
어느 문이 안 열리는지 구별하는 게 첫 단계입니다.
이중문은 겨울에 바깥 찬 공기를 막으려고 방풍문을 따로 다는 집이 많습니다. / 두 문이 모두 열려야 집에 들어갈 수 있으니 하나만 막혀도 출입 전체가 막힌 것처럼 느껴집니다.
설치한 시기가 서로 달라 두 문의 열쇠와 잠금 방식이 다른 집도 흔합니다. / 방화문은 번호키, 방풍문은 열쇠 잠금처럼 따로 쓰는 경우도 있으니 어떤 열쇠가 어느 문 것인지 먼저 떠올려 보세요.
택배 기사나 이웃이 방풍문만 열어 두고 가는 때도 있어 문을 닫을 때 확인하는 습관이 필요합니다.

# 어느 쪽 문이 막혔는지 가려내기
먼저 바깥쪽 방화문부터 번호를 눌러 봅니다. / 문이 열리면 방풍문에서 막힌 것입니다.
방화문이 안 열린다면 번호판 상태를 확인합니다. / 불이 켜지는지, 눌렀을 때 소리가 나는지, 모터 소리만 나는지 구분해 보세요.
방화문은 열렸는데 안쪽 문이 안 열린다면 방풍문 걸쇠를 의심합니다. / 문틈으로 손잡이 쪽을 확인하면 걸쇠가 걸려 있는지 보이기도 합니다.

# 방풍문 걸쇠가 걸려 있는 경우
방풍문은 문이 닫히는 힘으로 걸쇠가 그냥 걸리는 구조가 많습니다. / 바람이 세게 불거나 문을 세게 닫으면 걸쇠가 비스듬히 끼어 안 풀리는 때가 있습니다.
문을 살짝 안쪽으로 밀면서 손잡이를 돌려 보세요. / 문의 압력이 풀리면 걸쇠가 빠지는 경우가 있습니다.
문틈에 얇은 카드를 넣어 억지로 밀면 걸쇠 주변 마감이 상합니다. / 방풍문은 얇아서 한번 휘면 잘 닫히지 않게 되니 조심해야 합니다.
@ 초평동 방풍문 걸쇠 확인 모습

# 방화문 도어락이 말을 안 들을 때
방화문 쪽 도어락이 원인이라면 일반 현관문과 같은 순서로 확인합니다. / 번호판이 꺼졌다면 9V 건전지를 바깥쪽 비상 단자에 대 보세요.
소리는 나는데 안 열리면 모터나 걸쇠 쪽 문제일 수 있습니다. / 보조키를 안쪽에서 잠근 채 나왔다면 번호가 맞아도 문은 열리지 않습니다.
방화문은 두껍고 무거워서 문틀 처짐의 영향도 받습니다. / 문을 안쪽으로 살짝 들듯이 밀면서 열면 열리기도 합니다.

# 두 문 사이 공간에 갇힌 경우
이중문 구조에서는 두 문 사이 좁은 공간에 서서 문을 열려는 상황이 생깁니다. / 한쪽 문이 닫히면서 반대쪽 문도 잠겨 버리면 그 사이에 선 채로 막히기도 합니다.
이런 경우 방풍문 안쪽에는 보통 손잡이나 돌리는 장치가 있습니다. / 안쪽에서 열 수 있는 쪽이라면 열쇠집을 부르기 전에 한번 확인하세요.
쓰레기를 버리러 나왔다가 문이 닫히는 일도 흔합니다. / 휴대폰이 없다면 이웃에게 전화를 빌려 연락 주셔도 됩니다.

# 하지 말아야 할 것
급하다고 문을 발로 차거나 어깨로 밀면 문틀이 틀어집니다. / 방화문은 문틀이 바뀌면 다시 닫힘이 맞지 않아 수리 범위가 커집니다.
- 두 문을 동시에 열려고 당기기
- 드라이버로 걸쇠 주변을 쑤시기
- 도어락 덮개를 억지로 열기
- 번호를 계속 눌러 입력 제한 걸기
한쪽만 확인하고 침착하게 하나씩 풀어 가는 게 중요합니다.

# 전화로 상황을 알려주실 때
이중문 집은 어느 문이 문제인지를 말씀해 주시면 판단이 빨라집니다. / 오산역 쪽인지 세마역 쪽인지 대략 방향도 알려주세요.
- 방화문과 방풍문 중 열리지 않는 문
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 보조키나 걸쇠를 잠그고 나왔는지
- 집 안에 사람이나 반려동물이 있는지
- 문 모양이나 도어락 사진
사진은 문자로 보내주시면 도움이 됩니다. / 두 문 모두 찍어 주시면 챙겨 갈 장비를 고르기 좋습니다.

# 도착하면 신분 확인부터 합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 동의하시면 그때 시작하고 아니면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 더해지는 비용도 없습니다.
부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 최대한 안 상하게 엽니다
이중문은 두 문이 서로 맞물려 움직이는 구조라 한쪽 손상이 다른 쪽에도 영향을 줍니다. / 그래서 덜 상하는 방법부터 차례로 시도합니다.
도어락 종류와 문 상태에 따라 걸리는 시간이 다릅니다. / 작업 중 손대기 전에 바꿔야 할 부분이 보이면 먼저 말씀드립니다.
현관문 개방 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적었습니다.
@ 초평동 출장열쇠 현관문 개방 작업

# 열고 난 뒤 이중문 점검
문이 열리면 방화문과 방풍문 모두 잠기고 열리는지 확인합니다. / 방풍문 걸쇠가 헐거워졌다면 간단히 조절하는 것으로 정리되는 경우가 많습니다.
도어락이 원인이라면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문이 덜 닫히거나 닫힐 때 쿵 소리가 난다면 도어클로저와 경첩을 같이 보아야 합니다. / 이중문은 두 문의 닫히는 속도가 맞아야 편합니다.

# 초평동 말고 오산 어디든 갑니다
초평동 옆 오산동, 원동, 궐동, 세교동, 신장동, 대원동, 남촌동, 수청동, 갈곶동도 다닙니다. / 오산 안이면 24시간 출동합니다.
지역 안내는 [오산시 출장열쇠](osan.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
