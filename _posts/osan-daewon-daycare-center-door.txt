# 대원동 어린이집·돌봄 시설 출입문, 먼저 눈여겨볼 곳
대원동은 오산역과 오산대역을 오가는 분들이 지나는 생활권이라 아이를 맡기는 시설이 가까이 있습니다. / 아이들이 하루에도 수십 번 드나드는 출입문은 일반 가정보다 훨씬 많이 쓰입니다.
많이 쓰이는 만큼 닳는 속도도 빠르고, 아이가 있는 곳이라 문 하나에도 신경 쓸 부분이 다릅니다.
이 글은 [오산 출장열쇠](osan.html)가 시설 출입문을 점검할 때 보는 순서를 정리한 것입니다. / 시설 관리 책임이 있는 분이라면 일상 점검표로 쓰셔도 좋습니다.
@ 대원동 돌봄 시설 출입문 도어락과 손잡이 점검

# 출입문은 열기 쉬움과 잠금 사이의 균형입니다
아이를 지키려면 아무나 못 들어와야 하고, 비상시엔 빨리 나갈 수 있어야 합니다. / 두 가지는 서로 당기는 힘이 달라서 문 구조를 정할 때 균형을 잡아야 합니다.
안에서는 손잡이 하나로 쉽게 열리고, 밖에서는 번호나 카드가 있어야 열리는 구조가 일반적입니다. / 안에서 열 때 별도의 열쇠가 필요한 방식은 점검 때 꼭 다시 살펴야 합니다.

# 아이 손이 닿는 높이를 확인하세요
도어락이나 보조키가 아이 눈높이에 있으면 호기심으로 만지게 됩니다. / 안쪽 잠금 버튼을 아이가 눌러 문이 잠기는 일도 생깁니다.
- 안쪽 잠금 장치가 아이 손에 닿는지
- 문 틈새와 경첩 쪽에 손가락이 끼일 틈이 있는지
- 문이 닫힐 때 속도가 너무 빠르지 않은지
- 문 가장자리 고무나 보호 부품이 헐거워지지 않았는지
- 손잡이가 아이도 쉽게 돌릴 수 있는 모양인지
점검할 때 아이 키 높이로 몸을 낮춰서 보면 놓치던 곳이 보입니다.

# 문 닫힘 장치가 너무 빠르거나 너무 약하면
도어클로저는 문이 닫히는 속도를 조절하는 부품입니다. / 너무 빨리 닫히면 손끼임이 걱정되고, 너무 느리면 문이 덜 닫혀 잠금이 걸리지 않습니다.
닫히는 마지막 구간에서 한 번 더 부드럽게 속도가 줄어드는지 보세요. / 이 부분은 [도어락 수리](doorlock-repair.html)와 함께 점검하는 경우가 많습니다.
조절은 나사 하나로 되는 경우가 많지만, 오일이 새거나 팔이 휘었다면 부품 교체를 생각해야 합니다.

# 아이들 출입 시간에 맞춘 도어락 설정
등원과 하원 시간에 학부모가 몰리면 문이 계속 열린 채로 두게 됩니다. / 이때 도어락을 열림 상태로 고정해 두는 기능을 쓰는 곳도 있습니다.
다만 열림 고정을 쓰면 다시 잠그는 걸 잊어버리기 쉽습니다. / 마감할 때 문이 잠겼는지 확인하는 사람을 정해 두면 좋습니다. / 마감 점검표에 출입문 잠금 확인 칸을 하나 넣어 두는 것만으로도 빠뜨리는 일이 크게 줄어듭니다.
하원 차량이 오가는 시간에는 문 앞에 보호자와 아이가 한꺼번에 서게 됩니다. / 이 시간대에는 문을 여닫는 교사가 한 명으로 정해져 있어야 손끼임과 혼선이 줄어듭니다.
외부인이 따라 들어오지 못하게 문이 열려 있는 동안 입구를 지키는 사람이 있는지도 함께 정해 두세요.
@ 대원동 시설 입구에서 마감 전 도어락 잠금을 확인하는 모습

# 비밀번호와 카드는 누가 갖고 있나
시설은 교사, 조리 담당, 차량 운행 인력 등 여러 사람이 드나듭니다. / 그만큼 번호와 카드를 누가 갖고 있는지 관리 기록이 필요합니다.
퇴직하거나 담당이 바뀐 사람의 번호는 그날 바로 지우는 것이 맞습니다. / 카드는 돌려받았는지 확인하고, 못 받았다면 해당 카드를 막아 두세요.
한 번호를 여럿이 함께 쓰는 방식보다는 사람마다 번호를 다르게 두는 모델이 관리하기 편합니다.

# 비상 상황에서 빨리 열려야 합니다
화재나 대피 상황에서 안쪽에서 손잡이 한 번으로 열려야 합니다. / 이 부분이 제대로 되는지 정기 점검에서 직접 문을 열어 확인하세요.
보조키나 걸쇠가 안쪽에서 열쇠를 필요로 한다면 위험합니다. / 구조를 바꾸는 것은 시설 관리 책임자와 관련 규정에 따라야 하니, 문을 바꾸기 전에 확인하는 게 우선입니다.
이 글은 법적 기준을 단정하지 않습니다. / 소방 점검과 시설 안전 기준은 담당 기관 안내를 따라 주세요.

# 점검 주기와 기록 남기기
@ 대원동 시설 출입문 경첩과 도어클로저 점검 기록
문을 매일 아침 열면서 가볍게 확인하고, 일정 주기마다 꼼꼼히 보는 방식이 좋습니다.
- 매일: 문이 잘 닫히고 잠기는지, 이상한 소리가 없는지
- 주 단위: 번호판 반응, 카드 인식, 배터리 경고음
- 달 단위: 경첩 나사, 도어클로저 속도, 문틈 이물질
점검 결과를 간단히 적어 두면 문제가 반복되는 곳을 찾기 쉽습니다. / 언제 어떤 소리가 났는지 한 줄만 적어도 나중에 수리 상담을 할 때 큰 도움이 됩니다.
새 학기나 방학 전후처럼 출입이 달라지는 때에는 번호와 카드 목록도 같이 훑어보세요. / 어떤 도어락이 쓰이는지는 [도어락 교체](doorlock-replace.html) 판단에도 도움이 됩니다.

# 문이 갑자기 안 열릴 때
등원 시간 직전에 문이 안 열리면 현장이 순식간에 복잡해집니다. / 아이들이 밖에서 기다리고 있다면 우선 아이들 안전부터 챙기고, 그다음 연락해 주세요.
도어락 배터리, 보조키 잠금, 문틀 처짐 순서로 확인해 보고, 안 되면 [현관문 개문](door-open.html)을 요청하시면 됩니다.
아이가 안에 있는 상황이라면 꼭 먼저 말씀해 주세요. / 아이가 놀라지 않게 문 너머로 계속 말을 걸어 주시는 것이 도움이 됩니다.

# 연락할 때 알려 주실 내용
대원동 안에서 어느 방향인지, 건물 몇 층 어느 출입문인지 말씀해 주세요.
- 문에 붙은 도어락 모양
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 안에 아이가 있는지
- 시설 운영자나 관리 책임자가 현장에 있는지
시설은 운영자 확인이 중요해서, 운영 관련 서류나 관리 책임자의 확인을 부탁드립니다.
건물 전체 출입문과 시설 안쪽 문은 관리 주체가 다를 수 있습니다. / 어느 문이 어느 쪽 소관인지 미리 알아 두면 연락이 한 번에 끝납니다.

# 문 열기 전에 신분을 확인합니다
문을 여는 일이라 사시는 분이나 운영하시는 분이 맞는지 먼저 확인합니다. / 신분증, 주소나 운영 사실이 나온 우편물, 건물 관리사무소 확인 중 하나면 됩니다.

# 비용은 문을 열기 전에 먼저 말씀드립니다
문 상태를 보고 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 못 열면 비용은 받지 않습니다.
운영 시간 중이라면 아이들이 없는 쪽 출입문부터 작업해 소음과 먼지가 닿지 않게 하겠습니다.
부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 대원동 말고 오산 어디든 갑니다
오산동, 원동, 궐동, 세교동, 신장동, 남촌동, 초평동, 수청동, 갈곶동까지 24시간 출동합니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.
