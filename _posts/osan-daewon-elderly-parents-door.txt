# 대원동 부모님 집, 도어락은 괜찮을까요
자녀가 멀리 살거나 바쁘면 부모님 집 도어락을 한 번도 점검하지 못한 채 시간이 지나곤 합니다. / 어느 날 부모님이 문이 안 열린다며 전화를 하시면 그제서야 신경 쓰게 됩니다.
대원동에서도 이런 연락은 부모님 댁이 걱정된 자녀분들이 주로 하십니다. / 이 글은 방문하는 길에 직접 확인해 볼 수 있는 것과 어르신이 편하게 쓰시도록 바꿔 볼 것을 정리했습니다.
지금 부모님이 문 앞에서 기다리고 계시다면 4번부터 보셔도 됩니다. / 그 전에 먼저 전화로 차분히 설명해 드리는 것이 중요합니다.
@ 대원동 부모님 집 도어락 출장열쇠 24시

# 가장 먼저 배터리부터 확인하세요
어르신 댁에서는 경고음이 나도 그냥 지나치는 경우가 많습니다. / 소리가 작아 들리지 않거나 무슨 소리인지 몰라서 넘기기도 합니다.
방문하셨을 때 배터리를 전부 새것으로 바꿔 드리면 가장 확실하게 안심할 수 있습니다. / 교체한 날짜를 도어락 가까이에 크게 적어 두면 좋습니다.
배터리를 바꾸는 방법을 부모님께 알려드릴 때는 사진이나 글씨 크기를 크게 해 드리면 도움이 됩니다. / 작은 설명서는 보기 어려운 경우가 많습니다.

# 비밀번호는 쉽지만 안전하게
어르신이 외우기 쉬운 번호로 정하고 싶은 마음은 이해됩니다. / 하지만 생일이나 전화번호 같은 번호는 피하는 것이 안전합니다.
숫자를 외우기 어려워하시면 번호 대신 카드키나 지문이 가능한 제품도 있습니다. / 손가락 상태에 따라 지문이 잘 안 될 수도 있으니 방법을 두 가지 이상 두는 것이 좋습니다.
어떤 방식이 편하신지 부모님과 함께 직접 눌러 보며 정하세요. / 일방적으로 정하지 않고 같이 정하면 오래 씁니다.

# 소리와 불빛을 어르신에게 맞추세요
경고음이나 작동음이 너무 작거나 너무 크면 불편하실 수 있습니다. / 제품마다 소리를 조절하거나 켜고 끌 수 있는 기능이 있는 경우가 많습니다.
번호판 불빛이 어두운 곳에서도 잘 보이는지 확인해 보세요. / 시력이 좋지 않으시면 버튼 글자가 크고 밝은 제품이 편합니다.
설정을 바꾼 뒤에는 부모님이 직접 몇 번 눌러 보시게 하세요. / 어려움이 없는지 같이 확인하면 마음이 놓입니다.
@ 대원동 어르신 도어락 설정 열쇠집

# 문이 안 열린다고 전화가 왔을 때
먼저 차분하게 번호판에 불이 들어오는지 여쭤보세요. / 어르신들은 상황 설명을 어려워하실 수 있으니 천천히 물어보는 것이 좋습니다.
소리가 나는지, 문을 밀거나 당기면 움직이는지도 확인합니다. / 전화로만 해결이 안 되면 출장열쇠를 부르는 것이 낫습니다.
무리하게 문을 당기거나 손잡이를 세게 돌리시지 않게 먼저 말씀드려 주세요. / 걸쇠가 더 꽉 물려 일이 커질 수 있습니다.

# 어르신 혼자 계신 집에 출장열쇠가 갈 때
어르신이 혼자 집 안이나 문 앞에 계신 상황이라면 출동 전에 먼저 말씀해 주세요. / 낯선 사람이 오는 것이 걱정되실 수 있어서 자녀분이 통화로 확인해 주시면 안심하십니다.
자녀분이 멀리 있다면 전화로 위치와 상황을 알려주시고 어르신께는 곧 사람이 간다고 미리 알려드리세요. / 도착 후에는 사시는 분인지 신분 확인을 먼저 합니다.
어르신이 확인 서류를 찾기 어려울 때는 관리사무소나 이웃, 자녀 통화 확인을 활용할 수 있습니다. / 무리하게 진행하지 않고 안전을 먼저 봅니다.

# 이럴 때는 출장열쇠를 부르세요
번호판이 꺼져 있고 9V 건전지를 대도 반응이 없을 때, 번호는 맞는데 안 열릴 때 연락 주세요. / 대원동 전 지역과 오산 어디든 24시간 출동합니다.
[오산 출장열쇠](osan.html) 페이지에서 다니는 동네를 확인하실 수 있습니다. / 어르신이 혼자 계시다면 꼭 먼저 말씀해 주세요.
추운 날이나 더운 날 문 앞에 오래 서 계신 경우도 서둘러 출동합니다. / 상황을 알려주시면 출동 순서를 정해 드립니다.

# 전화로 이렇게 말씀해 주세요
대원동 어느 쪽인지, 근처 큰길이나 건물 방향을 알려주세요. / 어르신이 직접 말씀하시기 어렵다면 자녀분이 대신 알려주셔도 됩니다.
번호판 상태, 문이 닫혀 있는지, 안에 사람이 있는지도 알려주세요. / 어르신 건강이나 이동에 불편이 있다면 그것도 함께 말씀해 주세요.
도어락 사진을 문자로 보내주시면 장비를 챙기기가 쉽습니다. / 자녀분이 대신 문자로 보내 주셔도 됩니다.

@ 오산 대원동 어르신 도어락 점검 출장

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이므로 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
어르신 댁은 서류가 어디 있는지 모르시는 경우가 많으니 자녀분이 미리 알아봐 두면 좋습니다. / 사진이나 통화로 확인되는 방법도 상황에 따라 함께 봅니다.
확인이 어려우면 작업을 진행하지 못하니 미리 준비해 주세요. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 비용은 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 자녀분께도 먼저 여쭤봅니다. / 열기 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 오래된 도어락이라면 교체도 생각해 보세요
부모님 댁 도어락이 오래되어 자주 오작동한다면 고쳐서 쓸 수 있는지 먼저 봅니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
정말 오래된 제품이라 부품이 없거나 위험하다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 어르신이 쓰기 쉬운 제품으로 같이 고르는 것이 좋습니다.
고장이 잦은 경우에는 [도어락 수리](doorlock-repair.html)로 먼저 점검합니다. / 부모님 집이라 자주 가보기 어렵다면 한 번에 정리해 두는 것이 편합니다.
@ 대원동 24시 출장열쇠 부모님 집 010-3664-5455

# 정기적으로 확인해 두면 좋은 것
명절이나 부모님 댁에 갈 때마다 도어락 배터리와 소리를 한 번씩 확인해 보세요. / 문이 뻑뻑하지는 않은지, 번호판이 잘 눌리는지도 함께 보세요.
부모님 댁 열쇠나 카드키를 자녀가 따로 가지고 있는 것도 좋습니다. / 비상시에 도움이 됩니다.
이웃이나 가까운 친척에게 비상 연락처를 알려 두는 것도 방법입니다. / 문 앞에서 막혔을 때 도움을 받을 수 있습니다.
부모님께 출장열쇠 전화번호를 큰 글씨로 적어 현관 안쪽이나 냉장고에 붙여 드리는 것도 도움이 됩니다. / 당황하신 상황에서도 번호를 찾느라 시간을 쓰지 않으시도록 자녀분 번호와 같이 적어 두세요.

# 마무리

24시출장열쇠는 오산 열쇠집을 찾기 어려운 한밤에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요. 다른 지역은 [출장 지역](area.html)에서 지도로 확인하실 수 있습니다.
