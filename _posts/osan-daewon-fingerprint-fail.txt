# 지문은 되던 문인데 갑자기 안 열릴 때
오산 대원동에서 지문 도어락을 쓰는 집이 늘면서 "어제까지 잘 되던 지문이 오늘은 안 된다"는 연락이 오곤 합니다. / 원인은 고장이 아니라 손이나 센서 상태인 경우가 의외로 많습니다.
이 글은 대원동에서 지문 인식이 실패할 때 전화하기 전에 확인할 것을 순서대로 적었습니다. / 해봐도 안 되면 [오산 출장열쇠](osan.html)로 연락 주시면 됩니다.
출퇴근길에 세마역이나 오산대역 쪽에서 돌아와 문 앞에 섰는데 지문이 안 먹으면 마음이 급해집니다. / 그래서 1분 안에 확인할 수 있는 것부터 먼저 적었습니다.
@ 대원동 지문 도어락 인식 실패 출장열쇠

# 지문 인식이 흔들리는 가장 흔한 이유
지문 센서는 손가락 표면의 아주 작은 무늬를 읽습니다. / 그래서 손 상태가 조금만 달라져도 결과가 달라질 수 있습니다.
- 손이 젖었거나 땀이 많이 난 경우
- 겨울철처럼 손이 건조하고 갈라진 경우
- 설거지나 청소 뒤 손끝이 불어 있는 경우
- 손가락을 다쳐 밴드를 붙였거나 굳은살이 생긴 경우
- 센서 표면에 먼지, 기름, 지문 자국이 쌓인 경우
이 중 하나만 해당돼도 평소에 되던 지문이 실패할 수 있습니다. / 문이나 도어락이 고장 난 게 아닌 경우가 많으니 너무 놀라지 않으셔도 됩니다.

# 전화하기 전에 해볼 세 가지
먼저 손과 센서를 정리해 보세요. / 마른 천으로 손가락을 닦고, 센서 표면도 가볍게 닦은 뒤 다시 대 봅니다.
- 손가락을 마른 수건으로 닦고 다시 대기
- 센서 표면을 부드러운 마른 천으로 닦기
- 등록한 다른 손가락으로 시도하기
센서를 닦을 때는 물을 직접 뿌리지 마세요. / 물기가 도어락 안으로 들어가면 오히려 오작동의 원인이 될 수 있습니다.

# 손가락을 대는 방법도 결과를 바꿉니다
지문은 등록할 때의 자세와 비슷하게 대야 잘 읽힙니다. / 너무 세게 누르거나 손끝만 살짝 대면 인식이 흔들립니다.
센서 한가운데에 손가락 마디 가까운 부분까지 평평하게 올려 보세요. / 한 번에 안 되면 손가락을 떼고 숨을 고른 뒤 다시 대는 편이 낫습니다.
급하다고 여러 번 연달아 누르면 도어락이 잠깐 입력을 막기도 합니다. / 두세 번 해 보고 안 되면 멈추고 다른 방법으로 넘어가는 게 좋습니다.
@ 오산 대원동 도어락 지문 센서 점검

# 번호키나 카드키가 같이 있는지 먼저 보세요
지문 도어락은 대부분 번호나 카드, 보조 열쇠로 여는 방법을 함께 가지고 있습니다. / 지문이 안 될 때는 이쪽으로 먼저 열어 보세요.
번호를 쓰는 도어락이라면 비밀번호로 열고 들어가서 상황을 정리하면 됩니다. / 비밀번호도 잊었다면 [도어락 수리](doorlock-repair.html)와 비밀번호 안내 글을 같이 보셔도 됩니다.
카드키를 쓰는 집은 카드를 가까이 대 보세요. / 카드 인식까지 안 되면 지문 센서 문제가 아니라 전원이나 본체 쪽 문제일 수 있습니다.

# 배터리가 약해도 지문부터 먼저 말을 안 듣습니다
배터리가 줄어들면 번호판은 켜지는데 지문 센서만 반응이 느려지는 경우가 있습니다. / 센서가 전기를 더 쓰기 때문에 먼저 신호가 약해질 수 있습니다.
경고음이 한두 번 났던 기억이 있다면 배터리를 먼저 의심해 보세요. / 바깥쪽 아래 비상 단자에 9V 건전지를 대면 잠깐 전원이 들어오는 도어락도 많습니다.
건전지를 대고 지문이 되면 배터리 문제였던 겁니다. / 안으로 들어간 뒤에는 배터리를 전부 새것으로 바꿔 주세요.

# 센서가 오염되거나 긁힌 경우
센서 표면에 눌린 자국, 긁힘, 오래 쌓인 기름때가 있으면 인식률이 떨어집니다. / 오래된 문일수록 이런 흔적이 쌓여 있기 쉽습니다.
깨끗이 닦아도 같은 자리에서 계속 실패한다면 센서 자체가 닳았을 수 있습니다. / 이때는 직접 분해하지 마시고 점검을 받아 보시는 편이 안전합니다.
- 센서에 깊은 흠집이 보이는 경우
- 닦아도 반응이 없는 경우
- 특정 손가락만 계속 실패하는 경우
위 세 가지는 부품 상태를 직접 봐야 판단할 수 있습니다. / 부품을 바꿔야 하는 상황이면 바꾸기 전에 먼저 말씀드립니다.

# 지문을 다시 등록하는 요령
손가락 상태가 달라졌다면 지문을 다시 등록하는 것이 가장 확실합니다. / 같은 손가락을 각도를 바꿔 여러 번 등록해 두면 인식률이 올라갑니다.
- 손이 깨끗하고 마른 상태에서 등록하기
- 같은 손가락을 정면, 약간 왼쪽, 약간 오른쪽으로 나눠 등록하기
- 주로 쓰는 손가락 두세 개를 등록하기
- 겨울과 여름에 한 번씩 상태를 확인하고 다시 등록하기
가족 모두의 지문을 이미 등록했다면 어린 자녀는 손이 자라면서 지문 크기가 달라집니다. / 일 년에 한 번쯤은 아이 지문을 다시 등록해 주는 게 좋습니다.
@ 대원동 지문 도어락 재등록 출장열쇠

# 어르신과 아이는 지문이 더 잘 안 맞습니다
고령이거나 어린 경우에는 지문이 옅어서 인식이 어려울 수 있습니다. / 이럴 때는 지문만 믿지 말고 번호나 카드를 같이 쓰도록 설정해 두면 안심이 됩니다.
어르신이 혼자 사는 집이라면 열쇠 모양의 보조키도 따로 잘 보관해 두세요. / 도어락이 한 가지 방식만 쓰면 문제가 생겼을 때 대안이 없어집니다.
가족 중 누군가가 항상 비상용 번호를 알고 있도록 정해 두는 것도 방법입니다. / 번호 관리는 [도어락 설치](doorlock-install.html) 안내에도 설명해 두었습니다.

# 이런 경우에는 출장열쇠를 부르세요
아래 상황이라면 혼자 오래 붙잡지 않으시는 게 좋습니다. / 억지로 열려다 문이나 도어락이 상하면 일이 더 커집니다.
- 지문, 번호, 카드 어느 것으로도 문이 열리지 않을 때
- 모터 소리가 나지만 걸쇠가 안 빠질 때
- 도어락 화면에 알 수 없는 경고가 계속 뜰 때
- 배터리를 새로 넣어도 반응이 없을 때
이럴 때는 [현관문 개문](door-open.html) 안내를 먼저 보시고 전화 주세요. / 위치와 도어락 모양, 지금 상태만 알려주시면 도착 시간을 말씀드립니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다. / 지문 센서를 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다.

# 지문 도어락을 오래 쓰는 관리법
지문 도어락은 센서가 깨끗해야 오래 갑니다. / 한 달에 한 번쯤 마른 천으로 센서를 닦아 주는 것만으로도 인식 실패가 줄어듭니다.
- 센서 표면은 마른 천으로 가볍게 닦기
- 배터리는 해가 바뀔 때 한 번에 전부 교체하기
- 경고음이 나면 그날 바로 배터리 교체하기
- 비밀번호나 카드 같은 보조 수단 한 가지는 꼭 남겨 두기

# 자주 묻는 질문
? 지문이 안 되면 문을 꼭 새로 달아야 하나요? | 아닙니다. 손이나 센서 상태, 배터리 문제인 경우가 많아서 먼저 확인하고 필요한 부분만 손봅니다.
? 대원동 어디든 오시나요? | 네, 대원동은 물론 오산 안이면 동네 상관없이 24시간 출동합니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에 전화해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 지문 말고 번호만 쓰도록 바꿀 수도 있나요? | 도어락 종류에 따라 가능한 경우가 많습니다. 현장에서 확인하고 말씀드립니다.
