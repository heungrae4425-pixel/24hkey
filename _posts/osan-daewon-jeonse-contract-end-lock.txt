# 전세가 끝나는 날, 문 앞에서 생기는 일
대원동은 오산역과 오산대역 사이 생활권에서 전월세 이사가 꾸준히 이어지는 동네입니다. / 계약 만료일이 다가오면 짐 싸는 것만큼 신경 쓰이는 게 현관 도어락입니다.
이사 나가는 날 새 세입자나 집주인이 오는데 번호를 어떻게 넘겨야 할지 몰라 당황하는 분이 많습니다. / 반대로 들어오는 쪽은 전 세입자가 알려준 번호가 안 먹혀서 문 앞에 서 있기도 합니다.
이 글은 전세 계약이 끝날 때 도어락 비밀번호를 정리하는 순서를 적었습니다. / 문이 끝내 안 열릴 때 [오산 출장열쇠](osan.html)를 부르는 방법도 함께 담았습니다.
@ 대원동 전세 만료 이사 날 현관 도어락

# 비밀번호 인계가 말썽이 되는 이유
세입자가 쓰던 번호는 가족끼리만 아는 번호입니다. / 계약이 끝나도 그 번호가 그대로 남아 있으면 서로 마음이 편하지 않습니다.
- 나가는 쪽은 번호를 알려줬는데 혹시 누가 또 드나들까 불안한 경우
- 들어오는 쪽은 전 세입자 번호를 그대로 쓰기 찜찜한 경우
- 집주인이 마스터 번호나 보조 번호를 따로 등록해 둔 경우
- 이사 업체 직원에게 임시 번호를 알려주고 지우지 않은 경우
번호를 넘기는 일은 단순하지만 지우는 일을 빼먹으면 뒤탈이 생깁니다. / 그래서 인계는 알려주기와 지우기를 한 세트로 생각하시는 게 좋습니다.

# 이사 나가기 일주일 전에 할 일
나가기 전 주에 도어락 상태부터 한 번 살펴 두세요. / 이사 당일에는 정신이 없어 배터리 경고음 같은 걸 놓치기 쉽습니다.
- 안쪽 배터리 칸을 열어 건전지 상태 확인
- 등록된 카드키와 지문이 몇 개인지 세어 보기
- 보조키 열쇠가 몇 개 남았는지 모아 두기
- 임시로 등록해 둔 번호가 있는지 설정 메뉴에서 확인
열쇠가 하나 모자란다면 지금 찾아 두셔야 합니다. / 이사 날 열쇠가 안 나오면 집주인과 서로 얼굴을 붉히기 쉽습니다.

# 나가는 날 순서대로 정리하기
짐이 다 빠지고 마지막으로 집을 확인한 뒤 도어락을 정리하는 게 가장 깔끔합니다. / 집주인이나 새 세입자와 만나는 자리에서 같이 하면 오해도 줄어듭니다.
먼저 등록된 번호 중 쓰던 번호를 지웁니다. / 그다음 카드키와 열쇠를 모두 건넵니다.
새 번호를 정해 주는 쪽은 보통 집주인이나 들어오는 세입자입니다. / 나가는 사람이 마음대로 새 번호를 설정해 두고 가는 건 피하세요.
번호를 말로만 주고받으면 나중에 말이 달라질 수 있습니다. / 건넨 날짜와 시간을 문자로 남겨 두면 서로 확인하기 편합니다.

# 들어오는 쪽이 꼭 해야 할 일
새 집에 들어가면 가장 먼저 비밀번호를 바꾸시기 바랍니다. / 전 세입자가 알려준 번호가 통해서 문이 열렸다 해도 그대로 두지 마세요.
설정 방식은 제품마다 다르지만 대부분 안쪽 덮개를 열고 등록 버튼을 누르는 순서입니다. / 설명서가 없으면 제조사 이름과 모델명을 사진으로 찍어 두면 찾기 쉽습니다.
@ 대원동 도어락 비밀번호 재설정 안쪽 버튼

# 번호가 안 먹힐 때 먼저 의심할 것
이사 날 문 앞에서 번호가 안 열리는 경우를 정리해 보겠습니다. / 모두 도어락이 고장 난 게 아닌 경우가 대부분입니다.
- 전 세입자가 이미 번호를 바꾸고 이사 나간 경우
- 건전지가 다 돼서 번호판이 꺼진 경우
- 방범 모드나 외출 모드가 켜져 있는 경우
- 번호 뒤에 눌러야 하는 확인 키를 빼먹은 경우
번호를 서너 번 틀리면 도어락이 잠시 입력을 막습니다. / 계속 누르지 말고 전 세입자에게 먼저 연락해 현재 번호를 물어보세요.

# 연락이 안 되는 전 세입자, 이럴 땐 이렇게
전 세입자와 연락이 닿지 않으면 집주인에게 먼저 상황을 알립니다. / 집주인이 등록해 둔 다른 번호가 있을 수도 있습니다.
그래도 안 열린다면 열쇠집을 부르는 게 맞습니다. / 이때는 문을 여는 사람이 이 집에 들어올 권한이 있는 분인지 확인하는 절차가 꼭 필요합니다.
신분증, 임대차 계약서, 주소가 찍힌 우편물 중에서 준비 가능한 것을 챙겨 두세요. / 관리사무소에서 세대 확인을 받을 수 있는 곳이면 더 수월합니다.

# 문 열기 전에 비용을 먼저 말씀드립니다
전화를 주시면 도어락 종류와 문 상태를 듣고 어떻게 열지 설명드립니다. / 현장에서 문을 열기 전에 비용을 먼저 말씀드리고 동의하시면 시작합니다.
끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용도 없습니다.
도어락을 바꿔야 하는 경우에도 임의로 진행하지 않고 먼저 여쭙니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 열고 난 뒤에 같이 하는 정리
문이 열리면 현재 등록된 번호와 카드키를 모두 확인합니다. / 필요 없는 번호는 그 자리에서 지우고 새 번호를 등록합니다.
전세 만료 시점에 도어락을 아예 교체하는 집도 있습니다. / 이 경우 누가 비용을 부담할지는 집주인과 세입자가 계약 내용을 보고 정할 일이라 저희가 정해 드리지 않습니다.
고장이 아니라 번호 정리만 필요하면 [도어락 수리](doorlock-repair.html)로 충분한 경우가 많습니다. / 너무 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 설명드립니다.
@ 오산 열쇠집 도어락 번호 등록 확인

# 이사 업체와 인테리어 업체에 번호 알려줄 때
이사 날에는 업체 직원이 여러 번 드나듭니다. / 현관을 열어 둔 채로 작업하는 때가 많아 번호를 길게 알려줄 일은 많지 않습니다.
꼭 알려줘야 한다면 임시 번호를 따로 등록해 쓰고 작업이 끝나면 바로 지우세요. / 가족이 쓰는 번호를 그대로 알려주는 것은 피하는 게 좋습니다.
입주 청소나 도배 전에 번호를 넘겨야 하는 때도 마찬가지입니다. / 일이 끝난 날 바로 지우는 습관을 들이면 걱정이 줄어듭니다.

# 대원동에서 문 앞에 서 계실 때 알려주실 것
출장 요청을 하실 때는 아래 내용을 알려주시면 빠르게 판단할 수 있습니다. / 오산역 쪽인지 오산대역 쪽인지 대략 방향만 말씀해 주셔도 도움이 됩니다.
- 건물 이름은 말씀하지 않아도 되고 동과 호수, 가까운 길 이름
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 전 세입자와 연락이 되는지 여부
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 챙겨 갈 장비를 고르는 데 큰 도움이 됩니다.

# 대원동 말고 오산 어디든 갑니다
대원동 옆 오산동, 원동, 궐동, 세교동, 신장동, 남촌동, 초평동, 수청동, 갈곶동도 다닙니다. / 오산 안이면 동네와 상관없이 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 정리해 두었고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다. / 현관문 개방에 대한 설명은 [현관문 개문](door-open.html)에 있습니다.
