# 도어락을 바꿔야 할지 고민될 때
대원동에서 오래 쓴 도어락이 말썽을 부리면 고쳐 쓸지 새로 바꿀지 고민이 됩니다. / 가격부터 검색해 보는 분이 많지만, 바꾸기 전에 확인할 것을 먼저 알면 선택이 훨씬 쉬워집니다.
이 글은 오산 대원동에서 도어락 교체를 알아보는 분을 위해, 교체 전에 점검할 것과 비용 안내가 어떤 순서로 이뤄지는지를 정리했습니다. / 숫자로 된 가격표는 적지 않았고, 대신 어떻게 비용이 정해지는지를 적었습니다.
@ 대원동 도어락 교체 비용 안내 출장열쇠

# 정말 교체가 필요한 경우
고장이 났다고 모두 교체가 필요한 것은 아닙니다. / 배터리나 접점 문제는 수리로 해결되는 일이 많습니다.
- 수리해도 같은 고장이 반복되는 경우
- 부품이 단종돼 구할 수 없는 경우
- 번호판이나 몸체가 깨지거나 크게 파손된 경우
- 지금 도어락 방식이 불편해서 바꾸고 싶은 경우
이 중 하나에 해당하면 교체를 고민해 볼 만합니다.

# 먼저 수리로 해결되는지 봅니다
출장열쇠가 도착하면 도어락 상태를 먼저 확인합니다. / 간단한 접점 청소나 부품 교체로 살릴 수 있으면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드립니다.
새것이 항상 좋은 것은 아니니 쓸 수 있는 것을 굳이 바꾸라고 하지 않습니다. / 수리가 어렵다고 판단되면 그때 교체를 말씀드립니다.

# 교체하기 전에 알아둘 것
도어락은 문 두께, 보조키 위치, 문 안쪽 구멍 규격에 맞는 제품이어야 달 수 있습니다. / 같은 제품을 새로 사도 문 규격이 다르면 추가 작업이 필요할 수 있습니다.
기존 도어락을 떼면 문에 남는 구멍과 흔적이 새 제품에 맞는지 먼저 봅니다. / 자세한 설치 과정은 [도어락 설치](doorlock-install.html) 페이지에 적어 두었습니다.
@ 대원동 도어락 교체 설치 현장

# 도어락 종류를 정하는 기준
- 번호만 쓰는 기본형
- 번호와 카드키를 함께 쓰는 형
- 지문을 인식하는 형
- 문 열림 알림이 오는 스마트형
가족 구성, 아이 유무, 열쇠를 자주 잃는지에 따라 맞는 종류가 달라집니다. / 사용 습관을 말씀해 주시면 맞는 종류를 같이 골라 드립니다.

# 제품은 직접 사도 되고 맡겨도 됩니다
이미 사둔 제품이 있으면 가져가서 설치해 드릴 수 있습니다. / 어떤 제품을 사야 할지 모르면 쓰는 습관에 맞춰 추천해 드립니다.
제품 값은 제품마다 다르고, 설치 비용은 문 상태에 따라 달라집니다. / 두 가지를 나눠서 설명드려서 무엇에 얼마가 드는지 알 수 있게 합니다.

# 비용은 이런 순서로 안내합니다
비용을 정하는 순서는 이렇습니다. / 먼저 문 상태와 기존 도어락을 눈으로 확인합니다.
- 1단계: 기존 도어락 상태와 문 규격 확인
- 2단계: 수리인지 교체인지 방향 말씀
- 3단계: 제품 값과 설치 비용을 나눠 안내
- 4단계: 사시는 분이 괜찮다고 하면 시작
마음에 안 드시면 그냥 돌아가고, 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용은 없습니다.

# 전화로 이 정도만 알려주세요
대원동 어느 건물인지, 지금 쓰는 도어락이 무엇인지, 어떤 점이 불편한지 알려주세요. / 문 사진이나 도어락 사진을 문자로 보내 주시면 더 정확하게 안내할 수 있습니다.
사고 싶은 제품이 있으면 이름을 같이 알려 주세요. / 교체와 함께 비밀번호 등록까지 한 번에 하길 원하시는지도 말씀해 주세요.

# 신원 확인은 교체에도 합니다
교체 작업도 집 안 문을 다루는 일이라 사시는 분인지 확인합니다. / 신분증 주소나 우편물 같은 것을 준비해 두시면 빠릅니다.
이웃과 가족을 위한 절차라 꼭 필요합니다.

# 교체 작업은 이렇게 진행됩니다
기존 도어락을 조심스럽게 떼어 문에 손상이 없는지 봅니다. / 새 도어락을 달고 열림과 잠김을 몇 번씩 확인합니다.
비밀번호를 등록하고 보조키까지 함께 점검합니다. / 설치가 끝나면 사용법을 간단히 알려 드립니다.
@ 대원동 새 도어락 비밀번호 등록

# 설치 후 꼭 확인할 것
- 문이 완전히 닫힌 상태에서 번호로 잘 열리는지
- 안쪽에서 문을 잠그고 열 때 부드러운지
- 경고음이나 이상한 소리가 없는지
- 가족 모두 번호를 알고 있는지
하나라도 이상하면 바로 말씀해 주세요. / 설치 뒤 문제가 있으면 다시 확인해 드립니다.

# 기존 도어락은 어떻게 하나요
떼어낸 기존 도어락은 가져가 정리해 드립니다. / 필요하시면 두고 가라고 말씀하셔도 됩니다.
쓸 만한 부품은 따로 보관을 원하시면 알려 주세요.

# 대원동 말고 오산 어디든 갑니다
대원동 바로 옆 오산동, 원동, 궐동, 신장동, 세교동, 남촌동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 있고, 서울·경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
