# 전화하기 전 2분이 도착 시간을 줄입니다
문이 안 열리는 순간에는 머릿속이 하얘져서 무슨 말부터 해야 할지 모르게 됩니다. / 그런데 전화할 때 몇 가지만 알려주셔도 출동이 훨씬 빨라집니다.
이 글은 오산 갈곶동에서 출장열쇠를 부를 때 미리 준비하면 좋은 것을 순서대로 적었습니다. / 길지 않으니 문 앞에 서 계신 상태에서 훑어보셔도 됩니다.
어려운 준비는 없습니다. / 휴대폰 사진 한두 장과 위치, 지금 상태만 말씀해 주시면 충분합니다.
@ 갈곶동 출장열쇠 전화 전 준비 위치 사진

# 가장 먼저 알려주실 것은 위치입니다
갈곶동은 주택과 상가, 작은 단지가 섞여 있어서 번지만 말씀하시면 찾기 어려울 때가 있습니다. / 그래서 위치는 가능한 한 자세히 알려주실수록 좋습니다.
- 건물 이름이나 상호, 도로 이름
- 동과 호수, 몇 층인지
- 오산역이나 오산대역 중 어느 쪽에 가까운지
- 건물 입구 비밀번호나 경비실 유무
- 주차할 만한 곳이 있는지
지도 앱에서 현재 위치를 문자로 보내주시는 방법도 편합니다. / 건물 입구에서 문까지 가는 길이 복잡하면 그것도 한 줄 적어 주세요.

# 도어락은 사진 한 장이면 충분합니다
도어락 모양에 따라 챙겨 가는 장비가 달라집니다. / 그래서 말로 설명하기 어려우면 사진을 문자로 보내 주세요.
- 문 바깥쪽에서 도어락 전체가 보이는 사진
- 번호판이나 손잡이 쪽을 가까이 찍은 사진
- 제품 이름이 보이면 그 부분
사진이 있으면 도착해서 확인하는 시간이 줄어듭니다. / 사진을 못 찍는 상황이면 말씀으로 모양만 알려주셔도 됩니다.
@ 오산 갈곶동 도어락 사진 문자 안내

# 지금 문이 어떤 상태인지 알려주세요
번호판이 꺼졌는지, 소리는 나는지, 문을 밀면 조금 움직이는지 같은 것이 단서가 됩니다. / 전화로 이 정도만 알려주셔도 원인을 좁힐 수 있습니다.
- 번호판 불이 켜지는지 꺼져 있는지
- 번호를 누르면 소리가 나는지, 경고음이 나는지
- 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 봤는지
- 열쇠를 안에 두고 나왔는지, 비밀번호를 잊었는지
이런 단서가 있으면 [현관문 개문](door-open.html) 쪽으로 갈지, 부품 점검 쪽으로 갈지 미리 정리됩니다. / 모르는 건 모른다고 말씀하셔도 괜찮습니다.

# 이런 건 꼭 먼저 말씀해 주세요
작업 전에 알아야 안전하게 진행할 수 있는 정보가 있습니다. / 특히 집 안에 사람이 있는지 여부는 가장 중요합니다.
- 집 안에 어린 아이나 어르신이 혼자 있는지
- 집 안에 반려동물이 있는지
- 불이나 가스를 켜 둔 상태인지
- 몸이 아프거나 급히 들어가야 하는 사정이 있는지
이런 경우에는 순서를 바꿔 가장 급한 것부터 처리합니다. / 안전이 우려되는 상황이면 119에 먼저 연락하는 것도 같이 생각해 주세요.

# 누가 와도 비슷한 말을 들어야 합니다
전화에서 비용과 순서를 분명히 말해 주는지는 업체를 고르는 기준이 되기도 합니다. / 저희는 문 열기 전에 먼저 안내를 드립니다.
도착하면 문 상태와 도어락을 보고 어떻게 진행할지, 얼마나 드는지 먼저 말씀드립니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
@ 갈곶동 24시 출장열쇠 출동 안내

# 사시는 분인지 확인할 서류를 챙겨 두세요
문을 여는 일이라 사시는 분이 맞는지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
문 앞에서 막힌 상황에서는 신분증도 집 안에 있는 경우가 많습니다. / 그럴 때는 휴대폰에 저장된 우편물 사진이나 관리사무소 확인으로 대신할 수 있는지 상의해 주세요.
세입자라면 계약 서류보다 사시는 곳의 주소가 확인되는 자료가 중요합니다. / 확인이 어려우면 작업을 할 수 없으니 미리 방법을 같이 찾아보면 좋습니다.

# 이웃과 관리사무소를 활용하세요
공동주택이나 상가 건물이라면 관리사무소나 경비실이 큰 도움이 됩니다. / 세대 확인과 건물 입구 출입을 미리 말해 두면 도착이 빨라집니다.
- 건물 입구에서 막히지 않도록 미리 알리기
- 신분 확인이 어려울 때 관리사무소 확인 부탁하기
- 주차 위치를 정해 두기
이웃에게 전화를 빌려야 하는 상황이라면 이웃분 번호로 연락이 올 수 있다고 말씀해 두세요. / 문 앞에서 기다리는 동안 안전하게 있을 곳을 정해 두는 것도 좋습니다.

# 밤이나 새벽이라면 더 간단히
한밤에는 먼저 위치와 급한 정도만 알려주셔도 됩니다. / 나머지는 가는 동안 전화로 이어서 여쭤보겠습니다.
24시간 받는 전화라 시간에 신경 쓰지 말고 연락 주셔도 됩니다. / 밤늦게 이웃에게 소리가 가지 않도록 문 앞에서 두드리거나 큰소리 내는 일은 피해 주세요.
추운 계절이라면 문 앞에서 기다릴 때 몸을 따뜻하게 하고 계세요. / 어르신이나 아이와 함께라면 안전한 곳에서 기다리는 것이 우선입니다.

# 혼자 해보다가 상하는 경우를 막으려면
급하다고 드라이버나 카드를 문틈에 넣거나 손잡이를 세게 당기지 마세요. / 문틀과 도어락 외관이 상하면 나중에 비용이 더 들 수 있습니다.
비밀번호를 여러 번 틀리면 도어락이 한동안 입력을 막기도 합니다. / 서너 번 해 보고 안 되면 멈추는 게 좋습니다.
혼자 시도한 것이 있다면 그것도 전화로 말씀해 주세요. / 무엇을 해 보셨는지 알면 원인을 더 빨리 좁힐 수 있습니다.

# 문자로 남길 때는 이렇게 적어 주세요
통화가 어려운 상황이라면 문자로 먼저 남기셔도 됩니다. / 길게 쓰지 않아도 아래 네 줄이면 충분합니다.
- 위치: 갈곶동 건물 이름, 동·호수
- 상태: 번호판이 꺼짐, 경고음 있음처럼 한 줄로
- 집 안 상황: 아이나 반려동물이 있는지
- 연락 가능한 번호와 통화 가능 시간
문자를 보내신 뒤에는 휴대폰 배터리를 아껴 주세요. / 연락이 닿지 않으면 도착이 늦어질 수 있어서 통화 가능한 상태를 유지해 주시는 게 좋습니다.
사진이나 위치를 같이 보내 주시면 확인 시간이 더 줄어듭니다. / 답장이 늦으면 전화로 다시 한 번 연락 주세요.

# 이런 상황이면 바로 전화 주세요
아래 중 하나라도 해당되면 오래 붙잡지 않으셔도 됩니다. / [출장 열쇠](key-call.html) 안내를 보시고 바로 연락 주세요.
- 번호, 카드, 열쇠 모두 안 되는 경우
- 모터 소리만 나고 걸쇠가 안 빠지는 경우
- 집 안에 아이나 반려동물이 갇힌 경우
- 도어락이 소리와 불빛으로 오류를 계속 알리는 경우
교체까지 필요한지 궁금하시면 [도어락 교체](doorlock-replace.html) 안내도 참고해 주세요. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 끝난 뒤에 할 일도 미리 알아 두세요
문이 열린 뒤에는 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새 배터리로 바꾸는지도 함께 봅니다.
비밀번호를 바꿔야 하면 안쪽에서 새 번호를 등록하는 것까지 도와드립니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.
@ 오산 갈곶동 24시 출장열쇠 010-3664-5455

24시출장열쇠는 오산 전 지역을 24시간 받습니다. / 전화 010-3664-5455로 연락 주세요.
