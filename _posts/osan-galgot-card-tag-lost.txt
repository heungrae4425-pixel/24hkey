# 카드 하나 잃어버렸을 뿐인데 불안한 이유
갈곶동에서도 카드키나 태그로 여는 도어락을 쓰는 집이 늘었습니다. / 번호를 외울 필요가 없어 편하지만 잃어버리면 누가 주워도 열 수 있다는 점이 걱정됩니다.
이 글은 카드키, 태그, 리모컨을 잃어버렸을 때 어떻게 대처하고 새로 등록하는지를 정리했습니다. / 도움이 필요하면 [오산 출장열쇠](osan.html)에 연락 주세요.
@ 갈곶동 도어락 카드키 태그 분실 출장열쇠

# 가장 먼저 할 일은 분실 카드를 막는 것
카드를 잃어버린 뒤 가장 위험한 것은 누군가 그 카드로 문을 여는 일입니다. / 카드가 남아 있는 한 문이 열릴 수 있으니 빨리 막아야 합니다.
제품에 따라 분실한 카드만 삭제하는 방법도 있고 전체 카드를 지우고 새로 등록해야 하는 경우도 있습니다. / 어떤 제품인지에 따라 방법이 달라집니다.

# 도어락 종류별로 대처가 다릅니다
카드를 하나씩 따로 삭제할 수 있는 제품은 분실한 카드만 지우면 됩니다. / 그런 기능이 없다면 모든 카드를 지우고 다시 등록해야 합니다.
리모컨형은 도어락과 짝을 이루는 방식이라 분실한 리모컨의 연결을 끊고 새로 연결해야 합니다. / 어떤 방식인지 모델명을 알려주시면 방법을 말씀드립니다.

# 카드를 잃어버렸는데 문은 번호로 열 수 있다면
카드와 번호를 같이 쓰는 도어락이라면 번호로는 문이 열립니다. / 이때 서둘러 번호를 바꾸고 분실 카드를 막는 순서로 진행하세요.
카드를 잃어버렸다는 이유만으로 문을 바꿀 필요는 없습니다. / 분실 카드만 막아도 안전하게 쓸 수 있는 경우가 많습니다.
@ 갈곶동 도어락 분실 카드 삭제 작업

# 카드가 없고 번호도 모르는 경우
카드만 쓰는 도어락에서 카드를 잃어버리면 문을 열 방법이 없어집니다. / 이때는 문을 안 상하게 여는 방법부터 찾아야 합니다.
사는 분인지 확인한 뒤 덜 상하는 방법부터 차례로 시도합니다. / 문을 연 뒤에는 새 카드를 등록하는 것까지 도와드립니다.

# 카드를 잃어버린 장소를 생각해 보세요
마지막으로 카드를 쓴 곳이 어디인지 떠올려 보세요. / 가방이나 옷 주머니, 차 안, 식당 같은 곳에서 나오는 경우가 많습니다.
그곳에 연락해 보고 찾는 동안에도 분실 카드를 막아 두는 것이 안전합니다. / 찾았다면 그 카드를 다시 쓸지 새로 만들지 선택하시면 됩니다.

# 새 카드를 등록하는 순서
도어락의 등록 모드에 들어가서 새 카드를 대면 등록되는 방식이 일반적입니다. / 등록 모드는 보통 안쪽 설정 버튼이나 관리자 번호로 들어갑니다.
제품마다 순서가 달라서 설명서나 전화 안내가 필요할 수 있습니다. / 어려우시면 말씀해 주세요.

# 카드는 여러 장 만들어 두세요
가족 수만큼 카드를 만들고 하나는 따로 보관해 두는 것이 좋습니다. / 한 장뿐이면 잃어버렸을 때 문 앞에서 막히기 쉽습니다.
카드마다 누가 가지고 있는지 기억해 두면 분실했을 때 빨리 대처할 수 있습니다. / 카드에 이름이나 주소를 적어 두는 것은 피하세요.

# 카드를 아이에게 줄 때 조심할 점
아이가 학교나 학원에 갈 때 카드를 가지고 다니면 잃어버리기 쉽습니다. / 목걸이나 가방 안쪽 주머니에 달아 두는 방법이 있습니다.
아이 카드를 잃어버리면 바로 알려주도록 평소에 말해 두세요. / 야단치기보다 빨리 말하는 것이 중요하다고 알려주세요.
@ 갈곶동 가정 현관 도어락 새 카드 등록

# 사는 분인지 확인한 뒤 작업합니다
문을 여는 일이니 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리실이나 집주인 확인 중 하나면 됩니다.
작업 전에 무엇을 어떻게 할지 설명드리고 동의를 받습니다. / 그다음에 시작합니다.

# 비용은 작업 전에 말씀드립니다
문을 여는 작업인지, 카드만 새로 등록하는 작업인지에 따라 달라집니다. / 상황을 보고 얼마가 드는지 먼저 말씀드립니다.
마음에 안 드시면 그냥 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 수리나 교체가 필요한 경우
카드 인식이 잘 안 되는 문제라면 센서나 부품이 낡은 경우가 있습니다. / 이 경우에는 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 문 여는 방법은 [현관문 개문](door-open.html) 페이지에서도 볼 수 있습니다.

# 갈곶동에서 오산 어디든 갑니다
갈곶동 바로 옆 오산동, 원동, 궐동, 세교동, 신장동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
오산에서 다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
