# 문 앞에 서서 먼저 귀를 기울여 보세요
갈곶동에서 현관문이 안 열리면 대부분 마음이 먼저 급해집니다. / 세마역에서 내려 집까지 걸어왔는데 문이 꼼짝 않는다면 더 그렇습니다.
하지만 문이 보내는 신호를 읽으면 원인을 꽤 좁힐 수 있습니다. / 불빛이 어떤지, 어떤 소리가 나는지, 손잡이가 어떻게 움직이는지가 단서가 됩니다.
이 글은 그 단서를 순서대로 따라가며 원인을 찾는 방법을 담았습니다. / 상황이 급하면 해당하는 부분만 골라 읽어도 됩니다.
단서를 모을 때는 한 번에 하나씩만 해보세요. / 여러 가지를 동시에 시도하면 어느 쪽이 원인이었는지 알 수 없게 됩니다.
@ 갈곶동 현관문 안 열림 원인 확인

# 첫째 단서, 번호판에 불이 들어오나
번호판을 손바닥으로 한 번 덮듯이 눌러 보세요. / 아무 반응이 없다면 전원이 끊긴 것입니다.
대부분 배터리가 다 된 경우입니다. / 건전지 비상 단자에 9V 건전지를 대 보는 것이 가장 먼저 해볼 일입니다.
불은 들어오는데 번호를 눌러도 반응이 없다면 번호판 쪽 고장이나 습기를 의심합니다. / 마른 수건으로 닦고 잠시 뒤 다시 눌러 보세요.

# 둘째 단서, 삑 소리의 종류
번호를 누르면 나는 소리가 단서가 됩니다. / 짧게 한 번이면 입력이 들어간 것이고, 길거나 연속이면 경고입니다.
- 짧은 삑 소리만 나고 아무 일도 없음: 번호가 틀렸거나 아직 입력 중
- 경고음이 길게 이어짐: 입력 오류 누적이나 잠금 상태
- 낮은 소리로 띠띠띠: 배터리 부족 경고
- 아무 소리도 안 남: 전원 문제 가능성
모델마다 소리가 조금씩 달라 이 설명이 모든 제품에 맞지는 않습니다. / 그래도 소리가 평소와 다르다는 것만 알아도 전화로 설명하기 쉽습니다.
비밀번호를 여러 번 잘못 누르면 도어락이 일정 시간 입력을 막는 제품이 많습니다. / 그럴 때는 몇 분 쉬었다가 천천히 다시 눌러 보세요.

# 셋째 단서, 모터 소리는 나는데 안 열릴 때
번호가 맞는데 윙 하는 소리만 나고 문이 안 열리기도 합니다. / 모터는 도는데 걸쇠가 빠지지 않는 상태입니다.
이럴 때는 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 문이 틀에 눌려 걸쇠가 빠지지 않는 경우가 있어서 힘을 풀어 주면 열리기도 합니다.
그래도 안 되면 억지로 당기지 마세요. / 안쪽 부품이 맞물린 채 굳은 경우라 힘을 쓰면 오히려 단단해집니다.
특히 겨울이나 장마철에는 안쪽이 굳거나 습기가 차 동작이 둔해지기도 합니다. / 이런 날은 잠시 두었다 다시 시도하면 돌아오는 경우도 있습니다.
@ 갈곶동 도어락 모터 소리 확인

# 넷째 단서, 손잡이가 가볍게 돌아가는가
손잡이를 돌릴 때 느낌도 중요합니다. / 헛돌면 손잡이 안쪽 연결부가 풀렸거나 부러진 경우입니다.
무겁게 걸리면 걸쇠가 잠긴 채 물려 있을 수 있습니다. / 절반쯤 돌다 멈춘다면 문틀 쪽 걸림을 먼저 의심합니다.
헛도는 손잡이는 그대로 여러 번 돌리지 마세요. / 안쪽 부품이 완전히 빠져 버리면 해결이 더 어려워집니다.

# 다섯째 단서, 안쪽 보조키는 확인했나
번호가 맞고 모터 소리까지 나는데 안 열린다면 보조키를 의심해 보세요. / 밖에서는 보이지 않지만 안쪽 보조키가 잠긴 채 나온 경우가 있습니다.
어린 가족이 안에서 돌렸거나, 나가면서 습관처럼 눌렀을 수 있습니다. / 집 안에 사람이 있으면 대신 풀어 달라고 부탁하면 됩니다. / 가족이 퇴근 전이라면 연락해서 돌아오는 시간을 맞춰 보는 방법도 있습니다.
아무도 없으면 전화 주세요. / 보조키만 걸린 문은 번호가 맞아도 바깥에서는 열리지 않습니다.

# 여섯째 단서, 문이 틀어졌는가
문이 평소보다 뻑뻑하게 닫히거나 틀에 쓸리는 소리가 났다면 문틀이 틀어진 것일 수 있습니다. / 경첩 나사가 풀렸거나 문이 처진 경우입니다.
이 경우 걸쇠가 문틀 구멍과 맞지 않아 열고 닫을 때 걸립니다. / 문을 위로 살짝 들어 올리며 손잡이를 돌리면 열리기도 합니다.
이런 일이 반복되면 [도어락 수리](doorlock-repair.html) 전에 경첩 점검부터 받아 보세요. / 도어락은 멀쩡한데 문이 문제인 경우가 생각보다 많습니다.

# 확인했는데도 안 열린다면
위 단서들을 다 짚어도 문이 열리지 않으면 혼자 더 시도할수록 상태가 나빠집니다. / 이때가 전화하시기 좋은 때입니다.
단서를 알려 주시면 도착 전부터 무엇을 챙길지 준비할 수 있습니다. / 번호판 상태, 소리, 손잡이 느낌 정도면 충분합니다.
도어락 사진을 문자로 보내 주시면 더 정확합니다. / 갈곶동 어디쯤인지는 가까운 역이나 큰길 기준으로만 알려 주셔도 됩니다. / 정확한 동과 호수는 통화하면서 다시 확인해 드립니다.

# 전화로 이렇게 말씀해 주세요
- 사는 곳 위치와 동, 호수
- 번호판 불빛과 소리 상태
- 손잡이가 돌아가는지, 헛도는지
- 보조키를 잠갔을 가능성이 있는지
- 집 안에 아이나 반려동물이 있는지
이 정도만 들어도 어떤 상황인지 감을 잡을 수 있습니다. / 집 안에 사람이나 동물이 있으면 가장 먼저 알려 주세요.

# 도착하면 신분부터 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거롭더라도 이웃과 집을 지키기 위한 절차입니다. / 신분증이 집 안에 있으면 경비실이나 관리사무소 확인을 활용해 보세요.
확인이 안 되면 작업을 시작할 수 없습니다. / 미리 준비해 두시면 도착하자마자 바로 작업에 들어갈 수 있습니다.

# 비용은 문을 열기 전에 먼저 말씀드립니다
원인을 확인한 뒤 작업 내용과 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때부터 시작합니다.
문을 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. / 진행 순서는 [이용안내](guide.html)에도 있습니다.
@ 갈곶동 24시 출장열쇠 문 열기 점검

# 열린 뒤에는 원인을 같이 잡습니다
문이 열리면 다시 닫고 열어 보며 정상 작동을 확인합니다. / 배터리 문제였다면 전부 새 것으로 바꿨는지 봅니다.
헛도는 손잡이나 모터 이상이 있었다면 부품 상태를 보여 드리고 설명드립니다. / 고쳐서 쓸 수 있으면 교체를 권하지 않고, 낡았을 때만 [도어락 교체](doorlock-replace.html) 이야기를 꺼냅니다.
현관문을 여는 방식은 [현관문 개문](door-open.html) 페이지에 있습니다.

# 갈곶동 말고 오산 어디든 갑니다
갈곶동 인근 오산동, 원동, 궐동, 세교동, 신장동, 수청동도 다닙니다. / 오산 안이면 동네와 관계없이 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html)에서 보실 수 있습니다. / 다른 지역은 [출장 지역](area.html)을 참고하세요.
