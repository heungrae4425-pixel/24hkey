# 문 밖이 안 보이면 불안해집니다
갈곶동은 오산역과 세마역 사이를 오가는 분들이 많은 동네입니다. / 퇴근이 늦어지는 날 현관 앞이 잘 안 보이면 괜히 신경이 쓰입니다.
도어 아이는 문에 달린 작은 렌즈입니다. / 초인종 카메라는 현관 밖 영상을 집 안 화면이나 휴대폰으로 보여주는 장치입니다.
이 글은 갈곶동에서 도어 아이가 뿌옇거나 초인종 카메라가 안 켜질 때 확인하는 순서를 적었습니다. / 도어락과 같이 점검하면 좋은 부분과 [오산 출장열쇠](osan.html)가 도울 수 있는 범위도 나눠 두었습니다.
@ 갈곶동 현관문 도어 아이 렌즈

# 도어 아이가 뿌옇거나 어두울 때
도어 아이는 렌즈 두 장이 문을 관통해 박혀 있는 단순한 구조입니다. / 흐려지는 이유는 대부분 겉면의 먼지나 습기입니다.
- 바깥쪽 렌즈에 먼지나 물때가 낀 경우
- 안쪽 렌즈에 김이 서려 뿌옇게 보이는 경우
- 렌즈를 감싼 덮개가 돌아가 시야가 가려진 경우
- 렌즈 자체에 금이 간 경우
현관 앞 복도에 불이 어두우면 렌즈가 멀쩡해도 밖이 잘 안 보입니다. / 복도 센서등이 켜지는지도 함께 살펴보시면 원인을 빨리 가릴 수 있습니다.
부드러운 천으로 가볍게 닦아도 선명해지는 경우가 많습니다. / 세정제를 쓰면 렌즈 코팅이 상할 수 있으니 마른 천이나 물수건을 권합니다.

# 안쪽 덮개를 돌려 보세요
도어 아이 안쪽에는 작은 덮개가 달린 제품이 있습니다. / 덮개가 돌아가서 시야를 가리고 있을 수 있으니 손으로 돌려 열어 보세요.
덮개를 열었는데도 안 보이면 렌즈가 문 안에서 헐거워졌을 가능성이 있습니다. / 헐거운 렌즈는 직접 조이려다 무리하면 문 표면이 상하기 쉽습니다.
렌즈가 빠질 것 같으면 억지로 돌리지 말고 그대로 두세요. / 문 두께에 맞는 부품이 따로 있어 맞는 걸 골라 교체해야 합니다.

# 초인종 카메라가 켜지지 않을 때
초인종 카메라는 건전지를 쓰는 형태와 전선을 연결해 쓰는 형태로 나뉩니다. / 어느 쪽인지 알아야 원인을 좁힐 수 있습니다.
- 건전지식은 전원이 다 돼서 불이 안 들어옴
- 유선식은 전원 어댑터나 전선 접속이 헐거워짐
- 와이파이 연결이 끊겨 화면만 안 나옴
- 비나 습기가 들어가 회로가 일시적으로 멈춤
먼저 건전지나 어댑터 상태를 보세요. / 그다음 와이파이 공유기가 정상인지 확인하는 순서가 좋습니다.

# 도어락과 초인종이 연동된 집이라면
최근에는 도어락과 초인종 카메라가 한 앱으로 연결된 제품도 있습니다. / 이 경우 한쪽 건전지가 떨어지면 다른 쪽 알림도 먹통이 될 수 있습니다.
도어락 배터리 경고음이 이미 울리고 있었는지 떠올려 보세요. / 경고음을 놓치고 지나친 날이 며칠 있었을지도 모릅니다.
앱 연동이 안 되는 문제는 제품마다 설정이 달라 제조사 안내를 먼저 보시는 게 빠릅니다. / 저희는 문과 도어락의 물리적인 부분을 중심으로 도와드립니다.
@ 갈곶동 초인종 카메라 도어락 연동

# 문에 구멍이 뚫려 있다는 점을 알아 두세요
도어 아이는 현관문을 통째로 뚫고 지나가는 구조입니다. / 방화문처럼 두꺼운 문일수록 구멍 크기와 위치가 정해져 있습니다.
교체할 때는 문 두께, 구멍 지름, 렌즈 길이가 맞아야 합니다. / 맞지 않는 제품을 억지로 끼우면 시야가 좁아지거나 헐거워집니다.
방화문의 경우 임의로 구멍을 넓히는 것은 피하세요. / 문의 기능에 영향을 줄 수 있어 상태를 보고 안내드립니다.

# 해서는 안 되는 것
렌즈를 날카로운 도구로 긁어 때를 벗기는 분이 있습니다. / 코팅이 벗겨지면 영영 선명해지지 않습니다.
- 칼이나 드라이버로 렌즈 틈을 파내기
- 접착제로 렌즈를 붙이기
- 도어락 덮개와 같이 분해하기
- 문 안에서 렌즈를 세게 돌려 빼기
작은 부품이지만 문 안쪽 구조와 이어져 있어 손대면 일이 커집니다.

# 현관 앞이 안 보이는 날 방범에도 신경이 쓰인다면
렌즈가 흐리면 방문자 확인이 어려워 불안해지기 쉽습니다. / 모르는 사람이 왔을 때는 문을 열지 말고 인터폰이나 문 너머로 용건을 묻는 게 안전합니다.
현관 방범 점검 요령은 도어락 상태, 보조키 사용, 걸쇠 확인으로 간단히 정리됩니다. / 과하게 걱정하기보다 평소 습관으로 챙기는 정도면 충분합니다.

# 출장열쇠에 맡기는 게 나은 경우
도어 아이 렌즈 교체나 문 구멍 마감이 필요한 경우입니다. / 도어락과 한꺼번에 점검받고 싶은 때도 맡기시는 게 편합니다.
- 렌즈가 문 안에서 빠졌거나 헐거운 경우
- 문 두께에 맞는 렌즈를 찾기 어려운 경우
- 도어락과 같이 점검받고 싶은 경우
- 문 마감이 거칠어진 경우
무엇을 가져가야 하는지 판단하려면 문 사진이 도움이 됩니다.

# 전화하실 때 알려주실 것
갈곶동은 오산역 쪽과 세마역 쪽으로 방향이 나뉘므로 대략 방향을 알려주세요. / 위치를 알려주시면 이동 시간도 말씀드립니다.
- 동과 호수
- 도어 아이 또는 초인종 카메라 중 어느 쪽 문제인지
- 문 안쪽과 바깥쪽 사진
- 도어락 배터리 경고음 여부
사진을 문자로 보내주시면 챙겨 갈 부품을 고르기 쉽습니다.

방문하면 문 쪽 작업이라 집 주인이거나 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 서로를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 시작하기 전에 말씀드립니다
문 상태를 보고 어떻게 점검할지 설명한 뒤 비용을 먼저 말씀드립니다. / 괜찮으시면 시작하고 아니면 돌아갑니다.
문을 끝내 못 열거나 작업을 못 하는 경우 비용은 받지 않습니다. / 말 없이 붙는 비용도 없습니다.
부품을 바꾸기 전에는 반드시 먼저 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
@ 갈곶동 출장열쇠 현관문 렌즈 점검

# 점검하면서 도어락도 같이 봅니다
현관문 점검 때 도어락 배터리, 걸쇠, 보조키까지 한번 같이 봅니다. / 이상이 있으면 [도어락 수리](doorlock-repair.html)로 정리합니다.
너무 낡은 도어락이라면 [도어락 교체](doorlock-replace.html)를 말씀드리고, 새 제품이 궁금하다면 [도어락 설치](doorlock-install.html) 페이지를 참고하시면 됩니다.
현관문이 안 열리는 상황이라면 [현관문 개문](door-open.html) 안내를 먼저 보셔도 좋습니다.

# 갈곶동 말고 오산 어디든 갑니다
갈곶동 옆 오산동, 원동, 궐동, 세교동, 신장동, 대원동, 남촌동, 초평동, 수청동도 다닙니다. / 오산 안이면 24시간 출동합니다.
지역 안내는 [오산시 출장열쇠](osan.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
