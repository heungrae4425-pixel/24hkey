# 쉬는 날일수록 문 문제는 더 막막합니다
갈곶동은 세마역과 가까운 생활권이라 주말 외출 뒤 귀가하는 분이 많습니다. / 나들이를 다녀와 문 앞에 섰는데 도어락이 반응하지 않으면 하루가 한순간에 무거워집니다.
평일이면 관리사무소나 가까운 가게에 물어볼 수 있지만 쉬는 날은 연락할 곳이 마땅치 않습니다. / 그래서 휴일에는 미리 정해 둔 순서가 있으면 훨씬 침착해집니다.
이 글은 주말과 공휴일에 문이 안 열릴 때 단계별로 무엇을 하면 좋은지 정리했습니다. / [오산 출장열쇠](osan.html)를 부르는 때와 그 전에 해볼 수 있는 것을 나눴습니다.
@ 갈곶동 주말 공휴일 문 앞에서 막힌 상황

# 휴일에는 먼저 연락 가능한 곳을 정리하세요
쉬는 날은 관리사무소가 문을 닫거나 당직만 있는 곳이 많습니다. / 경비실이 있다면 세대 확인이 가능한지 먼저 물어보세요.
가족 중에 집 안에 있는 사람이 있는지부터 확인하는 것이 가장 빠릅니다. / 안에서 열어 줄 수 있다면 출장이 필요 없을 수도 있습니다.
- 집 안에 있는 가족에게 전화해 보기
- 근처 사는 가족이 여분 열쇠를 갖고 있는지 묻기
- 경비실이나 관리사무소에 당직이 있는지 확인
- 그래도 안 되면 출장열쇠에 연락
순서를 정해 두면 불필요하게 오래 문 앞에 서 있지 않아도 됩니다.

# 연휴 직후에는 배터리가 먼저 의심됩니다
며칠 집을 비웠다 돌아오면 도어락 배터리가 다 된 경우가 흔합니다. / 비어 있는 동안에도 도어락은 조금씩 전기를 쓰기 때문입니다.
번호판이 아예 꺼져 있다면 바깥쪽에 있는 비상 단자에 9V 건전지를 대어 보세요. / 건전지를 대고 있는 동안은 전원이 들어와 번호를 누를 수 있습니다.
쉬는 날에는 건전지를 구할 가게가 닫혀 있을 수 있어 편의점이나 가까운 역 근처를 찾아야 합니다. / 건전지를 대도 안 되면 그때 연락 주시면 됩니다.

# 휴일이라고 해서 서두를 이유는 없습니다
쉬는 날 문이 안 열리면 마음이 급해져서 이것저것 만지게 됩니다. / 하지만 손잡이를 세게 당기거나 문을 두드리는 건 상황을 나쁘게 만들 뿐입니다.
비밀번호를 여러 번 틀리면 도어락이 잠시 입력을 막습니다. / 서너 번 해보고 안 되면 멈추고 시간을 두는 편이 낫습니다.
어차피 연락할 거라면 천천히 상황을 정리하는 편이 도착도 더 정확해집니다. / 숨을 한 번 고르고 번호판 상태부터 확인해 보세요.

# 쉬는 날 열쇠집은 왜 찾기 어려울까
동네 열쇠집은 주말이나 공휴일에 문을 닫는 곳이 많습니다. / 늦은 밤에 문 연 곳을 찾는 일은 더 어렵습니다.
검색으로 찾아도 어디가 믿을 만한지 판단하기 어려운 경우가 많습니다. / 그래서 연락하기 전에 몇 가지만 확인하면 마음이 놓입니다.
- 위치를 말하면 대략 도착 시간을 알려주는지
- 문을 열기 전에 비용을 먼저 말하는지
- 신분 확인 절차를 안내하는지
- 못 열었을 때 비용 처리가 분명한지
24시출장열쇠는 이 네 가지를 모두 앞서 말씀드립니다. / 더 자세한 기준은 [출장 요청 방법](key-call.html)에도 적어 두었습니다.
@ 갈곶동 휴일 24시간 출장열쇠 연락

# 전화로 말씀해 주실 내용은 이 정도면 됩니다
위치, 도어락 모양, 번호판 상태, 집 안에 사람이나 반려동물이 있는지 네 가지를 알려주세요. / 길게 설명하지 않으셔도 충분히 알아듣습니다.
세마역 쪽인지 오산역 쪽인지처럼 대략적인 방향만 알려주셔도 이동 계획을 세울 수 있습니다. / 건물 이름이나 번지는 도착 전에 다시 확인합니다.
사진을 보내주실 수 있으면 도어락 모양을 미리 알 수 있어 준비가 정확해집니다. / 사진이 어려우면 말로만 해주셔도 괜찮습니다.

# 휴일에도 신분 확인은 똑같이 합니다
쉬는 날이라고 절차를 줄이지는 않습니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나는 필요합니다.
신분증이 집 안에 있는데 관리사무소가 쉬는 경우라면 미리 알려주세요. / 사는 곳을 확인할 다른 방법을 함께 찾아봅니다.
휴대폰에 저장된 고지서나 우편 사진이 도움이 될 때도 있습니다. / 확인이 끝내 어려우면 작업을 할 수 없는 점은 양해 부탁드립니다.

# 비용은 휴일이어도 열기 전에 말씀드립니다
도착해서 문과 도어락을 본 뒤 얼마나 드는지 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 최대한 안 상하게 여는 이유
문을 여는 방법은 여러 가지이고 덜 상하는 방법부터 차례로 해봅니다. / 쉬는 날에는 수리 가게도 닫혀 있어 문이 상하면 더 불편해집니다.
그래서 도어락과 문틀을 그대로 두고 여는 것을 가장 먼저 시도합니다. / 열린 뒤에 문이 처음처럼 여닫히도록 하는 것이 목표입니다.
방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 알려드립니다.

# 열린 뒤 휴일을 마저 보내기 위한 점검
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 전부 새것으로 바꾸는 게 좋습니다.
쉬는 날에는 부품을 구하기 어려우니 필요한 건 그 자리에서 정리하는 것이 편합니다. / 비밀번호를 잊어서 열었다면 안쪽에서 새 번호까지 등록합니다.
자주 고장 나는 도어락은 [도어락 수리](doorlock-repair.html)로 먼저 점검해 볼 수 있습니다. / 너무 오래돼 부품이 없을 때만 교체를 말씀드립니다.
@ 갈곶동 문 열린 뒤 도어락 점검

# 연휴 전에 해두면 마음이 편한 것
긴 연휴나 여행을 앞두고 있다면 도어락부터 한 번 살펴보세요. / 출발 전에 해두는 몇 가지가 돌아와서 겪을 불편을 줄여 줍니다.
- 배터리를 새것으로 바꾸거나 최근 교체 날짜 확인
- 경고음이 있었다면 미루지 말고 해결
- 가족에게 여분 열쇠나 카드 위치 공유
- 비상용 9V 건전지를 가방이나 차에 하나 넣기
이 정도만 해둬도 쉬는 날 문 앞에서 당황할 일이 많이 줄어듭니다. / 한 번 챙겨 두면 다음 연휴에도 그대로 쓸 수 있습니다.

# 갈곶동 말고 오산 어디든 갑니다
갈곶동 옆으로 오산동, 원동, 궐동, 세교동, 신장동, 대원동, 남촌동, 초평동, 수청동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
