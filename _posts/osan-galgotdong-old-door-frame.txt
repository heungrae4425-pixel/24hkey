# 문이 예전 같지 않다고 느껴질 때
오래 산 집일수록 현관문이 조금씩 달라집니다. / 갈곶동에서 문이 뻑뻑하게 닫히거나 열 때 소리가 나기 시작했다면 문틀이나 경첩이 변한 신호일 수 있습니다.
이 글은 오산 갈곶동에서 오래된 현관문이 문틀 처짐이나 경첩 문제로 안 열릴 때 확인할 것과 출장열쇠 진행을 적었습니다. / 도어락은 멀쩡한데 문이 말썽인 분들께 도움이 되도록 정리했습니다.
@ 갈곶동 오래된 현관문 문틀 처짐 개문

# 문틀이 처지면 생기는 일
문은 매일 열고 닫으며 경첩에 무게가 실립니다. / 오랜 시간이 지나면 경첩이 헐거워져 문이 조금씩 아래로 처집니다.
문이 처지면 문과 문틀 사이 간격이 달라져 걸쇠가 제 자리에 맞지 않게 됩니다. / 그러면 도어락은 정상인데도 열리지 않거나 잠기지 않는 일이 생깁니다.

# 이런 증상이 있으면 의심하세요
- 문을 닫을 때 바닥이나 문틀에 스치는 소리가 난다
- 문이 끝까지 안 닫히고 살짝 걸린다
- 문을 닫아야 겨우 잠기고, 열 때 힘이 든다
- 문과 문틀 사이 간격이 위아래가 다르다
하나라도 해당하면 도어락보다 문 자체를 먼저 봐야 합니다. / 억지로 열고 닫으면 문이 더 상하니 주의하세요.

# 안 열릴 때 문을 살짝 들어 보세요
문이 처져 걸쇠가 눌려 있는 경우, 문을 위로 살짝 들어올리듯 하면서 손잡이를 돌리면 열리기도 합니다. / 무리하게 힘을 쓰지 말고 가볍게 시도하세요.
한 번 열렸다면 그 위치를 기억해 두고 문과 문틀 간격을 점검하세요. / 열리고 나서도 같은 일이 반복될 수 있습니다.
@ 갈곶동 경첩 문틀 점검 출장열쇠

# 경첩은 사시는 분이 만지지 않는 편이 좋습니다
경첩 나사를 직접 조이려다 문이 더 틀어지는 경우가 있습니다. / 무거운 현관문은 혼자 다루다 다칠 수도 있습니다.
문이 처졌는지 정확히 확인하려면 간격을 재고 문을 살짝 열어 보는 순서가 필요합니다. / 이 점검은 현장에서 하는 것이 안전합니다.

# 도어락이 아닌 문 문제인지 가리는 법
번호는 맞게 눌렀고 소리도 정상인데 문이 안 열리면 문 쪽 문제일 가능성이 큽니다. / 열쇠로도 안 열리면 문틀과 걸쇠가 눌려 있는 경우가 많습니다.
도어락이 고장 난 것과 헷갈리지 않게 현장에서 원인을 가려 드립니다. / 원인에 따라 [도어락 수리](doorlock-repair.html)가 아니라 문 조정이 필요할 수 있습니다.

# 하지 말아야 할 것
문을 발로 차거나 어깨로 밀면 문틀과 경첩이 더 상합니다. / 경첩에 기름을 마구 뿌리면 오히려 먼지가 달라붙을 수 있습니다.
걸쇠 쪽을 드라이버로 억지로 눌러 열려고 하면 도어락 외관이 상합니다. / 안 되면 멈추고 전화 주시는 것이 가장 덜 상하는 길입니다.

# 전화로 이렇게 알려주세요
갈곶동 어느 건물, 몇 층인지, 문이 어떻게 안 열리는지 알려주세요. / 문이 스치는 소리가 나는지, 닫기 힘든지도 말씀해 주세요.
문 전체와 문틀 사이 간격이 보이는 사진을 보내 주시면 원인을 미리 가늠할 수 있습니다. / 집 안에 사람이 있는지도 알려주세요.

# 신원 확인은 이런 때도 합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 우편물, 관리사무소 확인 중 한 가지면 됩니다.
번거로우셔도 이웃과 가족을 위한 절차입니다.

# 비용은 확인한 뒤 말씀드립니다
문 상태를 보고 문 여는 비용과 조정 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문과 문틀을 덜 상하게 엽니다
오래된 문일수록 힘을 쓰지 않는 방법으로 엽니다. / 방법은 문 상태에 따라 현장에서 정합니다.
자세한 진행은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다. / 작업 중에 손볼 부분이 보이면 손대기 전에 말씀드립니다.
@ 갈곶동 현관문 열고 문틀 조정

# 열고 난 뒤 문과 걸쇠 조정
문이 열리면 걸쇠가 맞는 자리에 들어가는지 확인합니다. / 필요하면 걸쇠 받침 위치를 조정해 문이 부드럽게 닫히게 합니다.
경첩 상태가 심하면 교체나 보강이 필요한지 말씀드립니다. / 도어락이 너무 오래됐다면 [도어락 교체](doorlock-replace.html)도 같이 상의합니다.

# 오래된 문 오래 쓰는 방법
- 문을 세게 닫지 않고 손으로 받쳐 닫기
- 문에 무거운 물건을 걸어 두지 않기
- 문이 뻑뻑해지면 미루지 말고 점검
- 계절이 바뀔 때 문과 문틀 간격 확인
- 경첩 소리가 나면 그때 상태 확인
작은 관리로 문이 갑자기 안 열리는 일을 줄일 수 있습니다. / 이미 증상이 있다면 빨리 보는 것이 좋습니다.

# 갈곶동 말고 오산 어디든 갑니다
갈곶동 바로 옆 오산동, 원동, 궐동, 신장동, 대원동, 세교동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 있고, 서울·경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
