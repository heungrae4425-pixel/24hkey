# 겁먹을 필요 없는 현관 점검
오산 궐동은 주택과 빌라, 아파트가 골고루 섞여 있고 출퇴근하는 분이 많아 집을 비우는 시간이 긴 집이 많습니다. / 그러다 보니 현관문과 도어락 상태를 한 번쯤 점검해 두고 싶다는 문의를 가끔 받습니다.
이 글은 불안을 부추기려는 글이 아닙니다. / 평소에 몇 분만 투자해서 확인해 두면 좋은 부분을 차분하게 정리했습니다.
직접 해 볼 수 있는 점검과, 상태가 의심스러울 때 [오산 출장열쇠](osan.html)에 맡기면 좋은 부분을 나누어 적었습니다.
@ 궐동 현관문 도어락 방범 점검 오산 출장열쇠

# 문이 제대로 닫히는지 먼저 봅니다
문을 닫았을 때 문틀과 문 사이에 틈이 고르게 있는지 보세요. / 한쪽만 벌어져 있거나 문이 걸리면 경첩이나 문틀이 틀어졌을 수 있습니다.
도어락 걸쇠가 문틀 받침에 정확히 들어가는지도 확인합니다. / 걸쇠가 받침 끝에 겨우 걸린다면 문이 처졌다는 신호입니다.
문을 닫고 바깥에서 손잡이를 살짝 당겨 봐서 단단히 잠겨 있는지 보세요. / 헐겁게 느껴진다면 손잡이 나사나 내부 부품이 풀린 것일 수 있습니다.

# 도어락 번호판과 배터리 상태
번호판 불이 흐리거나 눌러도 반응이 늦다면 배터리가 약해진 것입니다. / 경고음이 나기 전에 바꾸는 것이 가장 안전합니다.
배터리는 전부 한 번에 새것으로 교체하고 교체한 날짜를 적어 두세요. / 일부만 바꾸면 얼마 안 가 다시 같은 일이 생깁니다.
번호판에 손자국이 잔뜩 남아 있으면 자주 누르는 숫자가 드러납니다. / 가끔 마른 천으로 닦아 주고 비밀번호도 주기적으로 바꾸는 습관을 들여 보세요.
@ 궐동 도어락 번호판 배터리 점검

# 비밀번호는 이렇게 관리하세요
생일이나 전화번호 뒷자리처럼 알려진 숫자는 피하는 것이 좋습니다. / 같은 숫자가 반복되거나 순서대로 나열된 번호도 추측하기 쉽습니다.
가족이 아닌 사람에게 알려 준 번호가 있다면 일이 끝난 뒤 바꿔 주세요. / 임시로 쓴 번호를 오래 두면 누가 알고 있는지 헷갈리게 됩니다.
번호를 바꿀 때는 새 번호가 제대로 등록됐는지 문을 열어 둔 상태에서 한 번 더 확인해 보세요. / 문 밖에서 시험하다가 실수로 잠기는 일을 줄일 수 있습니다.

# 열쇠 구멍과 보조키도 확인해 보세요
도어락에 달린 비상 열쇠 구멍이 막히거나 이물질이 끼어 있지 않은지 보세요. / 비상 열쇠가 필요한 순간에 안 들어가는 일을 막을 수 있습니다.
보조키가 따로 있는 문이라면 열쇠가 부드럽게 돌아가는지도 한 번 확인합니다. / 뻑뻑하면 자물쇠 안에 먼지가 쌓였다는 신호입니다.
여분 열쇠가 몇 개인지, 어디에 있는지 한 번 정리해 두면 좋습니다. / 누가 가지고 있는지 모르는 열쇠가 있다면 자물쇠를 바꾸는 것도 고려해 볼 만합니다.

# 문틈과 경첩 점검
경첩 나사가 헐거워지면 문이 조금씩 처져 걸쇠가 안 맞게 됩니다. / 문을 열고 닫을 때 삐걱거리는 소리가 나면 경첩 상태를 봐 주세요.
경첩 나사를 드라이버로 살짝 조여 주는 것만으로 나아지는 경우도 많습니다. / 다만 나사 구멍이 헐거워졌다면 더 조이지 말고 전문가에게 맡기는 것이 안전합니다.
문틈에서 바람이 들어오거나 빛이 보인다면 문틀이 틀어진 상태일 수 있습니다. / 이럴 때는 방범뿐 아니라 단열 때문에도 손봐 두면 좋습니다.

# 이런 신호가 있으면 점검을 받아 보세요
집에 없을 때 도어락이 혼자 울리거나 번호판이 이상하게 반응한 적이 있다면 점검해 볼 만합니다. / 이유 없이 경고음이 반복될 때도 마찬가지입니다.
문을 열었는데 안 닫히거나 걸쇠가 덜 들어가는 증상이 반복되면 작은 문제가 커지기 전에 보는 것이 좋습니다. / [도어락 수리](doorlock-repair.html) 페이지에서 증상별 대처를 확인하실 수 있습니다.
도어락이 아주 오래되었다면 교체 시기를 한번 생각해 볼 때입니다. / [도어락 교체](doorlock-replace.html)에서 어떤 경우에 바꾸는지 설명해 두었습니다.
@ 궐동 도어락 점검 걸쇠 경첩 확인

# 집을 오래 비울 때 확인할 것
여행이나 출장으로 며칠 집을 비우기 전에는 배터리 잔량을 확인하세요. / 비어 있는 동안에도 도어락은 조금씩 전기를 쓰기 때문에 오래 비울수록 배터리가 빨리 닳습니다.
우편함이나 현관 앞에 택배가 쌓이면 집이 비어 있다는 것이 보입니다. / 이웃이나 가족에게 가끔 확인해 달라고 부탁하는 것도 방법입니다.
돌아와서 문이 안 열릴 때를 대비해 비상용 9V 건전지를 하나 챙겨 두면 마음이 편합니다. / 비상 단자가 있는 도어락이라면 큰 도움이 됩니다.

# 출장을 부를 때 알려 주실 내용
점검이나 수리를 요청하실 때는 어떤 증상이 있는지 구체적으로 말씀해 주세요. / 도어락 사진과 문 전체 사진을 보내 주시면 필요한 부품을 준비해 갑니다.
급한 문제가 아니라면 방문 시간을 미리 정해 두면 서로 편합니다. / 급하게 열어야 하는 상황이라면 바로 전화 주세요.
도어락 종류와 설치 시기를 알고 계신다면 함께 알려 주세요. / 기억이 안 나더라도 사진으로 대부분 알 수 있습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
점검이든 개문이든 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
번거롭게 느끼실 수 있지만 이웃과 집을 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 주세요.
세입자라면 집주인과 이야기해 둔 부분이 있는지도 함께 말씀해 주세요. / 도어락을 바꾸는 일은 상의가 먼저인 경우가 많습니다.

# 비용은 점검 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 안내해 드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
점검만 받고 별다른 문제가 없다면 불필요한 교체를 권하지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
문을 못 열거나 고치지 못하면 비용은 받지 않습니다. / 부품을 바꿀 때는 바꾸기 전에 따로 여쭙고, 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 점검한 뒤에 같이 정리하는 것
문과 도어락 상태를 확인한 뒤 어떤 부분을 고치고 어떤 부분은 지켜봐도 되는지 정리해 말씀드립니다. / 당장 바꿔야 하는 것과 나중에 해도 되는 것을 나누어 안내합니다.
비밀번호를 새로 정하거나 카드키를 정리하는 것도 함께 도와드립니다. / 사용하지 않는 카드키나 리모컨 등록을 지우는 것도 좋은 습관입니다.
점검 결과를 문자나 메모로 남겨 두면 다음 점검 때 참고하기 좋습니다. / 도어락을 새로 달고 싶다면 [도어락 설치](doorlock-install.html) 페이지를 참고해 주세요.

# 오산 전 지역 어디든 갑니다
궐동뿐 아니라 오산동, 원동, 세교동, 신장동 등 오산 전 지역과 오산역, 오산대역, 세마역 쪽도 24시간 출동합니다. / 위치를 알려 주시면 도착 시간을 먼저 말씀드립니다.
다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있고, 문 열기는 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다. / 열쇠를 새로 만들고 싶다면 [출장 열쇠](key-call.html)도 참고해 주세요.

# 자주 묻는 질문
? 점검만 받아도 되나요? | 네, 점검만 받으셔도 됩니다. 문제가 없으면 교체를 권하지 않습니다.
? 도어락이 해킹될 수 있나요? | 걱정만 앞세우기보다 비밀번호를 주기적으로 바꾸고 배터리와 문 상태를 점검하는 기본을 지키는 것이 중요합니다.
? 비밀번호는 얼마나 자주 바꾸나요? | 정해진 주기는 없지만 가족 외에 번호를 알려 준 일이 있거나 이사한 뒤에는 바꾸는 것을 권합니다.
? 비용은 얼마나 드나요? | 문과 도어락 상태를 보고 시작하기 전에 먼저 말씀드립니다. 못 열면 비용은 받지 않습니다.
? 한밤에도 가능한가요? | 24시간 전화를 받습니다. 시간 신경 쓰지 말고 연락 주세요.
