# 새 도어락을 사기 전에 문부터 보셔야 합니다
궐동에서 오산역이나 오산대역 쪽으로 오가다 보면 도어락을 새로 달았다는 이야기를 자주 듣습니다. / 그런데 제품을 먼저 사 놓고 문에 안 맞아 곤란해지는 경우도 적지 않습니다.
도어락은 디자인이나 기능보다 내 문에 들어가느냐가 먼저입니다. / 문 두께와 구멍 위치가 맞지 않으면 아무리 좋은 제품이라도 달 수 없습니다.
이 글은 설치 전에 집에서 직접 확인할 수 있는 것들을 순서대로 정리했습니다. / 줄자 하나와 휴대폰 카메라만 있으면 충분합니다.
@ 궐동 도어락 설치 전 문 두께 측정

# 줄자로 문 두께를 먼저 재 봅니다
문을 열어 두고 문이 닫히는 쪽 옆면, 그러니까 걸쇠가 튀어나오는 면 위에서 두께를 잽니다. / 문 앞뒤 면 사이의 거리가 기준입니다.
측정값은 정확한 숫자까지 적어 두세요. / 제품마다 대응하는 문 두께 범위가 정해져 있어서 약간 차이로도 맞지 않을 수 있습니다.
문이 얇거나 두꺼운 경우에는 연결 부품을 따로 맞추기도 합니다. / 그래서 숫자를 알고 있으면 상담이 훨씬 빨라집니다.

# 지금 달린 도어락이 어떤 방식인지 확인하세요
손잡이와 번호판이 한 몸인 일체형인지, 문 위쪽에 따로 붙은 보조 장치가 있는지 봅니다. / 안쪽 몸통의 모양도 사진으로 남겨 두면 좋습니다.
- 손잡이를 아래로 누르는 레버형인지, 돌리는 원형인지
- 번호판과 손잡이가 같은 판에 있는지
- 문 옆면에 걸쇠 외에 사각 기둥이 하나 더 나오는지
- 안쪽에 뒤집는 잠금 손잡이가 있는지
이 정보가 있으면 같은 구멍을 그대로 쓸 수 있는지 판단하기 쉽습니다. / 구멍을 그대로 쓰면 문에 손을 대는 부분이 적어 깔끔하게 끝납니다.

# 보조키는 달린 채로 쓸지 먼저 정하세요
현관문에는 윗부분이나 아랫부분에 보조키가 따로 달린 경우가 많습니다. / 새 도어락을 달면서 이 보조키를 그대로 둘지, 같이 바꿀지 정해야 합니다.
보조키가 번호판 도어락과 따로 움직이면 외출할 때 하나만 잠그고 나가는 실수가 생기기 쉽습니다. / 이 부분은 생활 습관과도 연결되니 한 번 생각해 보세요.
오래된 보조키가 뻑뻑하면 새 도어락과 같이 손보는 편이 낫습니다. / 따로 하면 출장을 두 번 불러야 해서 번거롭습니다.

# 구멍 크기와 위치도 사진으로 남겨 둡니다
도어락을 떼어 내면 문에 뚫린 구멍이 보입니다. / 이 구멍이 새 제품 규격과 맞는지가 설치의 핵심입니다.
직접 떼어 내기 어렵다면 안쪽 커버를 열기 전 상태 사진만 찍어 두셔도 됩니다. / 문 옆면의 걸쇠 위치와 높이가 보이도록 찍어 주세요.
구멍이 너무 크면 가림판으로 덮을 수 있고, 너무 작으면 넓혀야 합니다. / 넓혀야 하는 경우는 문 재질에 따라 방법이 달라 현장에서 판단합니다.
@ 오산 궐동 도어락 구멍과 보조키 위치 확인

# 문 재질과 문틀 상태도 보세요
같은 철문이라도 속이 비어 있는지, 단단한지에 따라 작업이 달라집니다. / 문틀이 한쪽으로 처져 있으면 새 도어락을 달아도 잘 안 잠길 수 있습니다.
문을 닫았을 때 걸쇠가 받침 구멍에 정확히 들어가는지 확인해 보세요. / 걸쇠가 높거나 낮게 닿으면 도어락이 아닌 문틀을 먼저 손봐야 합니다.
이런 부분은 설치 전에 알고 있으면 일을 두 번 하지 않아도 됩니다. / [도어락 설치](doorlock-install.html) 페이지에 설치 과정을 따로 정리해 두었습니다.

# 건전지 방식과 전원 위치도 같이 생각하세요
도어락 안쪽에 건전지가 들어가는 칸이 있습니다. / 이 칸이 손잡이 아래인지 몸통 옆인지에 따라 교체가 편하기도, 불편하기도 합니다.
비상 전원 단자가 바깥쪽에 있는 제품이면 번호판이 꺼졌을 때 대처하기 쉽습니다. / 새로 고를 때 이 점도 같이 확인해 보세요.
문 앞에서 고생해 본 분들은 비상 단자가 있는지 먼저 보게 됩니다. / 필요한 기능이 무엇인지 미리 정리해 두면 선택이 쉬워집니다.

# 상담 전화에서 이 순서로 말씀하시면 좋습니다
먼저 문 두께와 도어락 모양을 말씀해 주세요. / 그다음 보조키를 같이 바꿀지, 어떤 방식으로 열고 싶은지 알려주시면 됩니다.
- 현재 도어락 사진과 문 두께 숫자
- 새로 원하는 방식 (번호, 카드, 지문 등)
- 보조키를 유지할지 여부
- 설치하는 곳이 집인지 사무실인지
이 정보로 필요한 부품과 시간을 미리 말씀드립니다. / 현장에서 새로 정해야 하는 부분이 줄어듭니다.
모르는 항목이 있어도 괜찮습니다. / 아는 것만 말씀해 주시면 나머지는 사진을 보고 함께 확인해 드립니다.
설치 장소가 상가나 사무실이라면 출입이 잦은 문인지도 알려주세요. / 사용 횟수에 따라 어울리는 방식이 달라질 수 있습니다.

# 비용은 시작하기 전에 정해서 말씀드립니다
현장에서 문과 구멍 상태를 본 뒤 어느 정도 드는지 먼저 말씀드립니다. / 괜찮다고 하셔야 설치를 시작하고, 아니면 그대로 돌아갑니다.
제품을 직접 사 오신 경우에도 문에 맞는지 먼저 봐 드립니다. / 맞지 않으면 억지로 달지 않고 이유를 설명해 드립니다.
설치 중에 추가 부품이 필요해지면 하기 전에 다시 여쭤봅니다. / 자세한 진행은 [이용안내](guide.html)에서 확인하세요.

# 설치 당일 확인할 것
작업이 끝나면 문을 열고 닫으며 걸쇠가 정확히 들어가는지 같이 봅니다. / 번호 등록과 비상 열쇠 위치도 함께 알려드립니다.
기존 비밀번호나 카드를 쓰던 분들은 새 등록 방식을 한 번 따라 해 보세요. / 가족 모두가 직접 한 번씩 열어 보는 게 가장 확실합니다.
사시는 분인지 확인하는 절차는 설치 때도 똑같이 있습니다. / 신분증, 주소가 적힌 우편물, 관리사무소 확인 중 하나를 준비해 주세요.
@ 궐동 도어락 설치 후 작동 확인

# 설치 뒤 관리가 더 오래갑니다
새로 단 도어락은 처음 몇 주 동안 문을 여닫을 때 느낌을 눈여겨보세요. / 이상한 소리나 걸림이 있으면 바로 연락 주시면 조정해 드립니다.
- 설명서와 비상 열쇠는 문 앞이 아닌 다른 곳에 보관
- 건전지 교체 날짜를 안쪽에 적어 두기
- 경고음이 나면 그날 바로 교체
- 문이 덜 닫히면 경첩과 문틀 점검
사용 중 불편이 생기면 [도어락 수리](doorlock-repair.html)로 먼저 확인해 보고, 방식 자체가 맞지 않으면 [도어락 교체](doorlock-replace.html)를 상의하시면 됩니다. / 처음부터 문에 맞게 고르는 것이 결국 가장 오래 쓰는 방법입니다.

# 궐동 말고 오산 어디든 갑니다
궐동 옆으로 오산동, 원동, 세교동, 신장동, 대원동, 남촌동, 초평동, 수청동, 갈곶동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
