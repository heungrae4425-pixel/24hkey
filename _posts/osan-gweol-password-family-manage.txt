# 비밀번호는 한 번 정하면 잊히기 쉽습니다
도어락 번호를 처음 정한 뒤로 한 번도 바꾸지 않은 집이 많습니다. / 궐동에서 오산역이나 세마역으로 출퇴근하는 가족이 늘어날수록 번호를 아는 사람도 슬그머니 늘어납니다.
번호를 아는 사람이 누구인지 정확히 말할 수 있는 집은 생각보다 드뭅니다. / 그래서 한 번쯤 점검해 보시길 권합니다.
이 글은 번호를 바꿀 시기와 가족끼리 공유하는 요령, 바꾼 뒤 기록하는 법을 정리했습니다. / 어렵지 않은 일이지만 순서를 놓치면 가족이 문 앞에서 막힙니다.
@ 궐동 도어락 비밀번호 가족 공유 관리

# 이럴 때는 바꾸는 편이 좋습니다
번호를 꼭 정해진 주기로 바꿔야 하는 것은 아닙니다. / 대신 아래 같은 계기가 있을 때는 바꾸는 편이 마음 편합니다. / 불안해서 자주 바꾸기보다 이유가 있을 때 확실히 바꾸는 편이 오래갑니다.
- 이사 직후 입주해서 전 주인이 쓰던 번호가 남아 있을 때
- 세입자나 공사 인력, 돌봄 인력에게 번호를 알려 준 적이 있을 때
- 가족 구성이 바뀌었거나 아이가 처음 열쇠를 받을 때
- 휴대폰이나 열쇠, 카드키를 잃어버렸을 때
- 번호가 쉬운 숫자로 되어 있다는 걸 알게 됐을 때
계기가 없다면 해를 넘기는 시점이나 배터리를 갈 때 같이 바꿔도 좋습니다.

# 어떤 번호가 좋은가
번호를 만들 때 피하면 좋은 패턴이 있습니다. / 생일이나 전화번호 끝자리, 같은 숫자 반복, 1234 같은 연속 숫자는 쉽게 짐작됩니다.
가족이 외우기는 쉽고 남이 짐작하기는 어려운 조합이 좋습니다. / 집 주소와 무관한 숫자를 고르는 것도 방법입니다.
번호를 길게 쓸 수 있는 제품이라면 자릿수를 늘려 보세요. / 대신 가족이 너무 어려워하면 외출할 때마다 불편해집니다. / 외우기 쉬운 규칙을 가족끼리 정해도 좋지만 남이 알기 쉬운 규칙은 피하세요.

# 가족에게 알리는 순서
번호를 바꾸는 날에는 가족에게 알리는 순서가 중요합니다. / 바꾸고 나서 알리면 그사이에 들어오지 못하는 사람이 생깁니다.
가장 안전한 순서는 이렇습니다.
- 가족이 집에 있을 때 번호를 먼저 바꾸기
- 바뀐 번호를 한 사람씩 직접 알려 주기
- 문 앞에서 한 번씩 실제로 눌러 보게 하기
- 못 눌러 본 가족은 따로 확인 연락 받기
특히 나이 드신 부모님이나 학교에 있는 아이는 따로 신경 써 주세요. / 번호가 바뀐 줄 모르고 돌아와 문 앞에 서 계시는 일이 의외로 흔합니다.

# 번호를 적어 둘 때 조심할 것
번호를 잊을까 봐 메모해 두는 분이 많습니다. / 하지만 현관 근처나 우편함 근처에 적어 두면 의미가 없어집니다.
휴대폰 메모에 적어 두려면 잠금을 걸어 두는 편이 좋습니다. / 가족 단톡방에 번호를 남기는 것도 추천하지는 않습니다.
꼭 필요하다면 의미를 알아보기 어려운 형태로 적어 두세요. / 가장 좋은 건 가족 모두가 외우는 것입니다. / 외우기 어렵다면 번호 대신 카드키를 보조로 쓰는 방법도 있습니다.
@ 궐동 도어락 번호 변경 가족 안내

# 손님과 돌봄 인력에게는 임시 번호를
가족이 아닌 사람에게는 가능하면 임시 번호를 따로 주세요. / 도어락에 번호를 여러 개 등록할 수 있는 제품이 많습니다.
방문이 끝나면 임시 번호를 지우면 되고, 가족 번호는 그대로 둘 수 있습니다. / 시간 제한을 둘 수 있는 제품도 있습니다.
제품마다 지원하는 기능이 다르니 사용설명서를 먼저 보세요. / 모르겠으면 전화로 모델을 알려 주시면 확인해 드릴 수 있습니다.

# 이미 가족이 번호를 바꿔 버렸다면
가족 중 한 사람이 번호를 바꾸고 말해 주지 않은 경우도 있습니다. / 문 앞에서 갑자기 기존 번호가 안 먹으면 당황스럽습니다.
먼저 가족에게 연락해서 바뀐 번호를 물어보는 것이 가장 빠릅니다. / 연락이 닿지 않으면 그때 출장열쇠를 부르세요.
여러 번 틀리면 도어락이 입력을 한동안 막기도 합니다. / 서너 번 해보고 안 되면 멈추는 게 좋습니다.

# 번호를 모를 때 전화 주세요
번호를 아예 잊었거나 바뀐 번호를 아는 사람이 없을 때는 문을 열고 다시 등록하는 방법이 있습니다. / 문을 상하지 않게 열고 나서 새 번호를 정하는 데까지 같이 도와드립니다.
도어락을 부수거나 뜯어낼 필요가 없는 경우가 대부분입니다. / 제품 상태에 따라 가능한 방법을 먼저 설명드립니다.
문 앞에서 막혔을 때 진행 방식은 [현관문 개문](door-open.html)에서 읽어 보실 수 있습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번호를 모르는 사람이 문을 열게 되는 일이라 특히 신중해야 합니다. / 확인이 어려우면 작업을 시작할 수 없습니다.

# 비용은 문을 열기 전에 먼저 말씀드립니다
현관문 상태와 도어락 종류를 본 뒤 작업 내용과 비용을 먼저 설명드립니다. / 괜찮다고 하시면 그때 시작합니다.
문을 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 번호 등록을 마친 뒤 확인할 것
새 번호를 등록한 직후에는 꼭 문을 열어 둔 채로 시험해 보세요. / 문을 닫고 나서 번호가 안 먹으면 다시 갇힐 수 있습니다.
- 새 번호로 열리는지
- 이전 번호는 지워졌는지
- 카드키나 지문 등 다른 방식도 정상인지
- 배터리 잔량 표시는 정상인지
이전 번호가 남아 있다면 지워 달라고 요청하세요. / 이 확인이 번호 관리의 마지막 단계입니다. / 번호를 바꾼 날짜도 가족이 보는 달력에 표시해 두면 다음에 바꿀 때 기준이 됩니다.
@ 궐동 24시 출장열쇠 비밀번호 재등록

# 카드키와 열쇠도 같이 정리하세요
번호만 바꾸고 예전 카드키나 열쇠가 여러 사람에게 남아 있으면 의미가 줄어듭니다. / 누가 어떤 카드키를 가졌는지 한 번 정리해 보세요.
잃어버린 카드키가 있다면 도어락에서 해당 카드를 삭제할 수 있는 제품도 있습니다. / 제품별 방법은 [도어락 수리](doorlock-repair.html) 안내나 전화로 확인해 드립니다.
배터리를 새로 가는 날에 번호도 한 번 점검하고, 가족 모두가 번호를 정확히 기억하는지 이야기해 보세요. / 오래된 도어락은 이때 상태도 같이 보시면 좋습니다.

배터리를 새로 가는 날에 번호도 한 번 점검해 보는 습관을 들여 보세요. / 가족 모두가 번호를 정확히 기억하는지, 열쇠가 어디 있는지 이야기해 보면 됩니다.
오래된 도어락은 이때 상태도 같이 보세요. / 교체가 필요한 시기라면 [도어락 교체](doorlock-replace.html)를 참고하시면 됩니다.

# 궐동 말고 오산 어디든 갑니다
궐동 가까이 오산동, 원동, 세교동, 신장동, 수청동도 다닙니다. / 오산 안이면 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
