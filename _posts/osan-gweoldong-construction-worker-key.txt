# 궐동 집수리 시작 전에 현관부터 정리하세요
궐동은 오산역과 오산대역 사이 생활권에서 오가는 분들이 많은 동네입니다. / 도배, 장판, 욕실 공사처럼 집을 손보는 일이 생기면 가장 먼저 부딪히는 것이 현관문 열쇠 문제입니다.
공사하는 분들은 집주인이 없는 시간에도 드나들어야 할 때가 많습니다. / 그래서 열쇠나 비밀번호를 누구에게 어떻게 맡기느냐가 공사 내내 신경 쓰이는 부분이 됩니다.
이 글은 오산 궐동에서 인테리어 공사 인력에게 출입 수단을 맡길 때 미리 정해 두면 좋은 것들을 정리했습니다. / 공사가 끝난 뒤 되돌리는 방법까지 이어서 적었습니다.
@ 궐동 공사 전 현관 도어락 점검 모습

# 원래 번호를 그대로 알려주는 것이 가장 흔한 실수
공사 일정이 급하면 평소 쓰던 비밀번호를 그대로 문자로 보내는 경우가 많습니다. / 편하긴 하지만 공사가 끝난 뒤에도 그 번호가 여러 사람 휴대폰에 남게 됩니다.
작업자가 바뀌거나 하청을 거치면 번호를 아는 사람이 눈덩이처럼 늘어납니다. / 누가 알고 있는지 집주인이 파악하기 어려워지는 것이 문제입니다.
가족이 쓰는 번호와 공사용 번호는 반드시 따로 두는 것이 안전합니다. / 대부분의 도어락은 번호를 여러 개 등록할 수 있어서 어렵지 않습니다.

# 공사용 임시 번호를 따로 만드는 순서
도어락 종류마다 메뉴는 다르지만 큰 흐름은 비슷합니다. / 관리자 모드로 들어가서 새 번호를 하나 추가하고, 그 번호만 공사 담당자에게 알려주면 됩니다.
- 안쪽 덮개를 열고 등록 버튼 누르기
- 기존 관리자 번호 입력하기
- 새 사용자 번호 추가하기
- 추가한 번호로 문이 실제로 열리는지 문 밖에서 확인하기
기능이 없는 구형 모델이라면 번호 추가가 안 될 수 있습니다. / 이럴 때는 전화로 모델을 말씀해 주시면 가능한 방법을 먼저 안내해 드립니다.

# 공사 책임자 한 명에게만 맡기세요
여러 명이 각자 번호를 받으면 나중에 정리하기가 어렵습니다. / 현장 책임자 한 사람에게만 번호를 알리고, 나머지 인력은 그분이 관리하게 하는 쪽이 깔끔합니다.
번호를 알려줄 때는 공사 기간과 출입 가능한 시간대를 같이 말해 두세요. / 서로 기대하는 바가 맞으면 나중에 오해도 줄어듭니다.
카드키나 열쇠를 복사해서 나눠 주는 방식은 되도록 피하는 것이 좋습니다. / 복사본은 돌려받았는지 확인하기가 번호보다 훨씬 어렵습니다.

# 열쇠를 맡겨야 한다면 이렇게
구형 열쇠식 문이라 번호 방식이 안 되는 집도 있습니다. / 이럴 때는 열쇠를 한 개만 건네고, 건넨 날짜와 돌려받을 날짜를 메모해 두세요.
열쇠를 준 사람 이름과 연락처를 휴대폰 메모에 남겨 두면 나중에 확인이 쉽습니다. / 공사가 끝나면 그 열쇠를 돌려받는 것까지 한 세트로 생각하셔야 합니다.
돌려받은 열쇠가 원본인지 복사본인지 알 수 없다면 실린더 교체를 고민해 볼 만합니다. / 이때는 [도어락 교체](doorlock-replace.html) 안내를 참고하세요.
@ 공사 중 임시 번호를 등록하는 도어락 안쪽

# 공사 먼지와 보양 작업이 도어락에 미치는 영향
인테리어 현장에서는 현관 앞에 비닐과 테이프로 보양 작업을 합니다. / 이때 번호판이나 손잡이 틈에 테이프가 눌어붙는 일이 가끔 있습니다.
톱밥이나 시멘트 가루가 번호판 틈으로 들어가면 버튼이 뻑뻑해질 수 있습니다. / 공사 전에 번호판 주변을 가볍게 가려 두면 도움이 됩니다.
공사 중에 번호판이 반응하지 않으면 먼저 먼지를 마른 솔로 털어 보세요. / 그래도 안 되면 억지로 누르지 말고 연락 주세요.

# 공사 중 배터리가 먼저 떨어지는 이유
작업자가 하루에도 몇 번씩 문을 여닫으면 배터리가 평소보다 빨리 닳습니다. / 공사 시작 전에 새 배터리로 한 번 갈아 두는 것이 가장 쉬운 예방입니다.
공사 팀이 문 앞에서 번호판이 꺼졌다고 연락하면 집주인도 난감해집니다. / 사전에 9V 비상 단자 위치를 알려두면 작업자가 스스로 해결하는 경우도 있습니다.
경고음이 울린다는 연락을 받으면 바로 배터리 교체를 안내하세요. / 미루다 보면 공사 중간에 문이 잠긴 채로 멈추는 일이 생길 수 있습니다.

# 공사 중 문이 잠겨 버렸을 때
작업자가 안에서 문을 닫고 나갔는데 열쇠를 안에 두고 나오는 일도 있습니다. / 이럴 때 집주인이 멀리 있으면 상황이 복잡해집니다.
집주인 본인이 직접 연락해 주셔야 하며, 현장 분이 대신 요청하는 경우에는 집주인과 먼저 통화가 필요합니다. / 문을 여는 일이라 사시는 분의 동의가 먼저입니다.
[출장열쇠 부르기](key-call.html) 안내에 전화 전에 준비할 것을 적어 두었습니다. / 사진 한 장만 있어도 상황 설명이 훨씬 빨라집니다.

# 신분 확인은 공사 현장에서도 똑같습니다
현장에 집주인이 없더라도 문을 여는 절차는 다르지 않습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나는 있어야 합니다.
공사 팀이 대신 연락했는데 집주인이 연락되지 않으면 작업을 진행할 수 없습니다. / 번거롭게 느껴질 수 있지만 이웃과 집을 지키기 위한 절차입니다.
집주인이 해외나 다른 지역에 있다면 관리사무소를 통해 세대 확인이 되는지 미리 알아보세요. / 확인 방법은 전화로 상황을 말씀해 주시면 같이 찾아봅니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 확인한 뒤 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭙니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
@ 궐동 도어락 번호 초기화 작업 장면

# 공사가 끝난 날 바로 해야 할 일
공사가 끝나면 그날 안에 공사용 번호를 삭제하세요. / 다음 날로 미루면 잊어버리기 쉽고, 그 사이에도 출입이 가능한 상태가 됩니다.
- 공사용 임시 번호 삭제하기
- 맡겼던 열쇠나 카드 전부 돌려받기
- 현관 도어락 작동 상태 확인하기
- 공사 중 긁힌 곳이나 틈이 없는지 살펴보기
번호를 지웠는지 확인하려면 문 밖에서 지운 번호를 한 번 눌러 보면 됩니다. / 열리지 않으면 정상적으로 삭제된 것입니다.

# 공사 뒤 도어락이 이상할 때
공사 이후 문이 잘 안 닫히거나 걸쇠가 뻑뻑해졌다면 문틀에 손상이 생겼을 수 있습니다. / 현관 보양재를 뜯는 과정에서 경첩이나 문틀이 미세하게 틀어지는 경우도 있습니다.
도어락 자체가 이상하면 [도어락 수리](doorlock-repair.html)를 먼저 고려해 보세요. / 고쳐서 쓸 수 있으면 교체까지는 권하지 않습니다.
공사가 끝난 김에 도어락을 새로 달고 싶다면 [도어락 설치](doorlock-install.html) 페이지를 참고해도 좋습니다. / 문 두께와 보조키 위치를 먼저 확인하고 알려주시면 맞는 제품을 말씀드립니다.

# 궐동 말고 오산 어디든 갑니다
궐동 바로 옆 오산동, 원동, 세교동, 신장동까지 같은 날 이동할 수 있습니다. / 오산시 안이면 동네 상관없이 24시간 받습니다.
오산에서 다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 모아 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

# 마무리
궐동에서 인테리어 공사를 앞두고 있다면 먼저 임시 번호 하나를 만들고 책임자 한 사람에게만 알려주세요. / 공사가 끝나는 날 그 번호를 지우는 일까지 일정에 적어 두시면 안심하고 맡기실 수 있습니다.
혹시 공사 중에 문이 잠기거나 도어락이 말을 듣지 않으면 상황만 알려주세요. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주시면 출동 여부를 바로 말씀드립니다.
