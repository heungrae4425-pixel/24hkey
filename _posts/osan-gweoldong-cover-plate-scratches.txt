# 작동은 되는데 겉모습이 신경 쓰이는 도어락
궐동은 오산역과 세마역 방면으로 생활하는 가구들이 모여 있는 동네입니다. / 오래 쓴 도어락은 잘 열려도 겉면 흠집과 벗겨진 도장이 눈에 들어옵니다.
현관은 집의 얼굴이라 작은 흠집이 자꾸 신경 쓰이는 분들이 계십니다. / 이 글은 도어락 외관 흠집이 생기는 이유와 교체할 때 문에 남는 구멍 자국을 어떻게 정리하는지 적었습니다.
@ 궐동 현관문 도어락 겉면 흠집

# 외관에 흠집이 나는 흔한 이유
- 열쇠고리나 카드가 번호판에 닿으며 긁히는 경우
- 짐을 들고 들어오다 가방이 부딪힌 경우
- 이사 때 가구가 손잡이를 스친 경우
- 문을 억지로 열려다 공구에 긁힌 경우
- 세월이 지나 도장이 벗겨지고 색이 바랜 경우
문제는 흠집이 기능에 영향을 주는지 여부입니다. / 대부분은 겉면만 상한 것이라 작동에는 문제가 없습니다.

# 흠집이 보이면 먼저 이것부터
먼저 마른 천으로 먼지와 기름때를 닦아 보세요. / 흠집처럼 보이던 것이 때일 때도 있습니다.
번호판 투명 덮개가 긁힌 정도라면 눌림 반응에는 영향이 적습니다. / 버튼 글씨가 지워졌다면 숫자를 헷갈릴 수 있으니 점검이 필요합니다.
날카로운 도구로 긁어 내거나 연마제를 쓰는 건 피해 주세요. / 코팅이 벗겨져 더 빨리 상하는 원인이 됩니다.

# 기능에 영향을 주는 흠집과 아닌 흠집
겉에서 보이는 흠집과 안쪽 부품 상태는 서로 별개인 경우가 많습니다. / 하지만 흠집 근처에 이상 신호가 같이 있다면 눈여겨봐야 합니다.
손잡이 아래나 번호판 가장자리에 틈이 벌어졌다면 물이 스며들 수 있습니다. / 그럴 땐 전기 부품이 젖어 오작동하기 전에 점검하는 것이 좋습니다.
반대로 표면에 얕게 긁힌 선은 그대로 써도 큰 문제가 없습니다.
- 틈이 벌어지거나 덮개가 들뜬 경우: 점검 필요
- 버튼이 눌린 채 돌아오지 않는 경우: 점검 필요
- 표면에 얕은 선만 있는 경우: 그대로 사용 가능
판단이 어려우면 사진을 보내 주세요. / 보고 점검이 필요한지 말씀드립니다.

# 외관이 상했을 때 교체까지 가야 할까
새 제품을 달면 마음은 깔끔해지지만 문에 구멍을 새로 맞춰야 하는 불편이 따릅니다. / 그래서 외관 때문에만 바꾸는 것은 천천히 생각해 보시라고 권합니다.
겉모습만 거슬린다는 이유로 바로 바꾸는 것은 권하지 않습니다. / 작동이 괜찮다면 [도어락 수리](doorlock-repair.html)나 부분 점검으로 충분한 경우가 많습니다.
다만 오래되어 배터리 칸이 헐겁고 버튼이 흐릿하다면 교체를 생각해 볼 시기입니다. / 교체가 필요한지는 사진을 보고 솔직하게 말씀드립니다.
[도어락 교체](doorlock-replace.html)가 필요하다 해도 비용은 작업 전에 먼저 안내합니다.

# 교체하면 문에 남는 구멍 자국
이사할 때나 문을 바꿀 때만이 아니라 도어락을 교체할 때도 같은 걱정이 생깁니다. / 미리 알아 두면 놀라지 않고 선택할 수 있습니다.
도어락을 새것으로 바꿀 때 문에 뚫린 구멍이 맞지 않으면 자국이 남을 수 있습니다. / 기존 제품과 새 제품의 크기, 구멍 간격, 나사 위치가 다르기 때문입니다.
문 두께와 보조키 위치를 먼저 확인하면 맞는 제품을 고르기 쉽습니다. / 기존 구멍을 그대로 쓰는 제품이면 자국이 거의 보이지 않습니다.
새 제품이 기존보다 작으면 가장자리에 예전 흔적이 드러나기도 합니다.
@ 도어락 교체 후 문에 남은 타공 자국

# 타공 자국을 줄이는 방법
자국을 완전히 없앨 수는 없어도 눈에 덜 띄게 하는 방법은 여러 가지가 있습니다. / 제품을 고르는 단계에서 이미 절반은 결정됩니다.
- 기존 구멍 크기와 비슷한 제품 고르기
- 새 도어락의 몸체가 이전 자국을 가릴 만큼 큰 제품 고르기
- 문 두께와 보조키 위치를 미리 사진으로 보내기
- 필요하면 가림판(커버 플레이트)으로 흔적 가리기
커버 플레이트는 이전 구멍 자국을 덮어 주는 작은 판입니다. / 사용 여부는 문 모양과 자국 크기에 따라 달라지니 현장에서 보고 말씀드립니다.
미리 문 사진을 보내 주시면 [도어락 설치](doorlock-install.html) 상담이 한결 빠릅니다.

# 문 재질에 따라 달라지는 자국 처리
문 안쪽 소재가 무엇인지는 겉만 봐서 알기 어려울 때가 있습니다. / 이럴 땐 구멍 주변을 만져 보고 단단한지 확인한 뒤 말씀드립니다.
나무 문, 철문, 방화문은 구멍 주변의 상태가 서로 다릅니다. / 철문은 표면이 단단해 자국 정리가 쉽고, 나무 문은 가장자리가 갈라진 경우도 있습니다.
오래된 구멍 주변이 많이 닳았다면 새 제품이 헐겁게 앉을 수 있습니다. / 이럴 땐 고정에 문제가 없도록 보강하는 방법을 먼저 상의합니다.
문을 새로 칠하거나 필름을 붙이는 일은 따로 업체에 맡기시는 편이 좋습니다.

# 문 앞에서 사진 보낼 때 이렇게 찍으세요
도어락 전체를 정면에서 한 장, 옆면을 한 장, 안쪽 몸체를 한 장 찍어 주세요. / 문 두께는 문을 열고 옆면에서 찍으면 보입니다.
- 번호판과 손잡이를 같이 찍은 정면 사진
- 문 옆면과 걸쇠 위치
- 안쪽 몸체와 배터리 칸
- 흠집이나 타공 자국이 보이는 부분 가까이
궐동 위치와 호수를 같이 알려 주시면 일정을 잡기 편합니다. / 오산역이나 세마역 중 가까운 쪽을 말씀해 주셔도 좋습니다.

# 작업 전에 사시는 분인지 확인합니다
교체나 점검이 목적일 때도 확인은 똑같이 합니다. / 세입자라면 집주인에게 작업 동의를 받았는지도 같이 챙겨 두면 좋습니다.
도어락을 만지는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로워도 이웃과 본인을 위한 절차입니다.
@ 도어락 외관을 보며 점검하는 출장열쇠

# 비용은 시작 전에 먼저 말씀드립니다
점검인지 교체인지에 따라 안내가 달라집니다. / 필요한 작업과 비용을 먼저 말씀드리고 동의하신 뒤에 시작합니다.
작업 중 추가가 필요해 보이면 손대기 전에 다시 물어봅니다. / 자세한 진행 방식은 [이용안내](guide.html)에 있습니다.
열어야 하는 상황이었는데 끝내 못 열면 비용은 받지 않습니다.

# 흠집을 덜 만드는 평소 습관
흠집은 한 번 생기면 되돌리기 어렵습니다. / 대부분은 일상에서 조금씩 조심하는 것으로 줄일 수 있습니다.
- 열쇠고리와 카드를 번호판에 대고 문지르지 않기
- 짐을 들 때 손잡이에 부딪치지 않게 한 번 더 확인
- 번호판은 부드러운 마른 천으로만 닦기
- 알코올이나 거친 세제 쓰지 않기
- 이사나 공사 땐 손잡이에 보호 테이프 붙이기
작은 습관이 외관을 오래 지켜 줍니다.

# 궐동 밖에서도 오산 어디든 갑니다
궐동 가까운 세교동, 신장동, 원동, 오산동도 다닙니다. / 지역 안내는 [오산 출장열쇠](osan.html)와 [출장 지역](area.html)에서 볼 수 있습니다.
