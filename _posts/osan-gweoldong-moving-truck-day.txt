# 이삿짐 나르는 날 궐동 현관은 늘 열려 있습니다
오산역이나 세마역에서 멀지 않은 궐동에서도 이사철이면 현관문이 하루 종일 반쯤 열려 있는 집을 봅니다. / 짐을 나르는 사람들이 오가다 보니 문을 닫지 못하고 고정해 두는 것입니다.
이런 날 의외로 많은 일이 생깁니다. / 문이 갑자기 닫히며 잠기거나, 반대로 안 닫혀서 이사가 끝난 뒤에도 문이 이상한 경우입니다.
이 글은 오산 궐동에서 이삿짐 나르는 날 문이 반쯤 열린 상태로 생기는 문제를 정리했습니다. / 이사 후 정리는 [도어락 교체](doorlock-replace.html) 자료와 함께 보시면 좋습니다.
@ 궐동 이삿짐 나르는 날 문을 열어 둔 현관

# 문이 열려 있는 동안 생기는 일
문을 오래 열어 두면 경첩과 도어클로저에 힘이 계속 걸립니다. / 무엇을 괴어 두었는지에 따라 문이 서서히 틀어지기도 합니다.
문 안쪽 벽에 닿는 부분에는 도어 스토퍼를 달아 두면 손잡이가 벽을 치는 일도 막을 수 있습니다. / 짐을 든 사람이 몸으로 문을 밀고 지나가면 문이 세게 부딪혀 문틀이 상할 수 있습니다. / 이런 충격이 쌓이면 이사 끝나고 나서야 문이 잘 안 닫힌다는 걸 알게 됩니다.

# 문을 고정할 때 쓰면 좋은 것
문이 닫히지 않게 눕혀 놓는 도구는 문 아래에 쐐기처럼 끼우는 방식이 무난합니다. / 단단한 물건이나 무거운 상자를 문에 기대 두는 것은 위험합니다.
- 문 아래에 끼우는 고무 쐐기
- 문틀과 벽 사이 완충재 대기
- 도어클로저가 있다면 고정 장치 활용
- 바람이 센 날은 두 곳 이상 고정
고정하지 않고 사람이 문을 붙잡고 있으면 손이 끼는 사고가 날 수 있으니 그것도 피해 주세요.

# 바람에 문이 쾅 닫히며 잠긴 경우
이사 중 열쇠와 휴대폰은 보통 짐 속이나 안쪽 서랍에 들어가 있습니다. / 그 상태에서 바람에 문이 닫혀 도어락이 자동으로 잠기면 사람은 밖에, 열쇠는 안에 남게 됩니다.
자동 잠금 기능이 있는 도어락은 문이 닫히는 순간 잠깁니다. / 이삿날에는 자동 잠금을 잠시 꺼 두는 방법도 있습니다.
이미 잠겼다면 번호가 기억나는지 먼저 눌러 보세요. / 새 번호를 설정한 직후라면 번호를 헷갈리는 일이 흔합니다.

# 이삿짐 업체에게 문을 맡길 때
작업하시는 분들이 마음대로 문을 고정하다 문틀을 긁는 경우가 있습니다. / 시작 전에 어느 문을 쓸지, 어떻게 고정할지 한마디 해 두면 좋습니다.
궐동처럼 빌라와 다세대가 있는 곳은 계단이 좁아 문이 복도 쪽으로 열릴 때 더 자주 부딪힙니다. / 문이 열리는 방향과 복도 폭을 이사 전에 한 번 살펴 두면 좋습니다.
열쇠나 번호를 이삿짐 작업자에게 알려줘야 한다면 일회성으로 쓰는 임시 번호가 안전합니다. / 이사가 끝나면 바로 삭제하거나 변경하세요.
@ 이삿짐 작업 중 문틀을 보호재로 감싼 모습

# 문이 안 닫히고 반쯤 걸려 있는 상태
이사가 끝났는데 문이 끝까지 안 닫히고 중간에 걸린다면 두 가지를 의심합니다. / 하나는 경첩이 처지거나 틀어진 경우, 다른 하나는 문틀이나 바닥에 이물질이 낀 경우입니다.
문 아래 틈과 문틀 위쪽 틈을 비교해 보세요. / 위쪽이 더 좁다면 문이 처진 것입니다.
경첩 나사가 헐거운지도 가볍게 확인해 보세요. / 자세한 점검 요령은 [도어락 수리](doorlock-repair.html) 안내와 함께 보셔도 됩니다.

# 억지로 닫으려는 마음을 눌러 주세요
이사가 늦어져 급하다고 문을 세게 밀어 닫으면 걸쇠가 문틀에 박혀 빠지지 않는 경우가 있습니다. / 이때는 문이 닫혔지만 안 열리는 더 어려운 상황이 됩니다.
그럴 땐 문을 살짝 안쪽으로 밀어 압력을 풀어 준 뒤 손잡이를 돌려 보세요. / 그래도 안 되면 힘을 더 쓰지 말고 연락 주세요.
[현관문 개문](door-open.html) 방법은 문과 잠금장치를 상하지 않게 여는 것이 우선입니다.

# 이삿날 아이와 반려동물은 어디에
문이 열려 있으면 아이나 반려동물이 밖으로 나가 버릴 수 있습니다. / 이삿날에는 안쪽 방에 따로 두거나 다른 가족이 돌보게 하는 편이 안전합니다.
반대로 문이 닫혀 잠긴 상태에서 아이나 동물이 안에만 남았다면 바로 연락 주세요. / 이 경우는 먼저 말씀해 주시면 순서를 앞당겨 진행합니다.
문 근처에 짐이 쌓여 있으면 급할 때 문을 열기도 어렵습니다. / 현관 앞 한 사람이 지나갈 길만큼은 비워 두세요.
이삿짐을 다 내린 뒤에도 문 앞에 박스가 남아 있으면 작업 공간이 좁아집니다. / 연락하기 전에 한 걸음 정도는 치워 두시면 도착해서 바로 시작할 수 있습니다.

# 이사 당일 급하게 오는 연락
이사 당일에는 시간이 곧 비용이라 마음이 급하십니다. / 가능한 한 문 상태와 위치를 짧게 알려주시면 빨리 판단할 수 있습니다.
- 새 집인지 이전 집인지
- 문이 지금 닫혔는지 열려 있는지
- 번호판 상태
- 이삿짐 작업이 지금 진행 중인지
이삿짐 차량이 길을 막고 있다면 출입구 위치도 말씀해 주세요.
이사 당일 문 문제는 대개 열쇠 하나, 번호 하나를 누가 갖고 있느냐에서 시작됩니다. / 그래서 연락하실 때 지금 열쇠나 카드를 누가 들고 있는지도 같이 알려주시면 도움이 됩니다.
이삿짐센터 직원과 가족이 서로 상대가 갖고 있다고 생각하다 문 앞에서 확인하는 일도 의외로 흔합니다.

# 사시는 분 확인은 이사 때 더 중요합니다
이사 중에는 낯선 사람들이 오가므로 문을 열기 전에 반드시 사시는 분인지 확인합니다. / 신분증 주소, 주소가 있는 우편물, 관리사무소 확인 중 하나면 됩니다.
막 이사 와서 주소가 아직 서류에 반영되지 않았다면 임대차 계약서나 관리인 확인으로 대신할 수 있습니다. / 미리 사진으로 담아 두시면 좋습니다.

# 비용은 문 열기 전에 먼저
문 상태를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 이사가 끝난 뒤에 해야 할 점검
짐 정리가 끝났다면 현관문을 한 번 천천히 열고 닫아 보세요. / 걸쇠가 부드럽게 들어가는지, 문이 끝까지 닫히는지 살펴봅니다.
새 집이라면 이전 거주자가 쓰던 번호를 지우고 새 번호를 등록하는 것이 안전합니다. / 필요하면 도어락 교체까지 검토해 볼 수 있습니다.
- 임시로 알려준 번호 삭제
- 새 비밀번호 가족과 공유
- 카드키나 열쇠 여분 확인
- 경첩과 문틀 상태 눈으로 확인
@ 이사 후 새 비밀번호를 등록하는 도어락

# 궐동 말고 오산 어디든 갑니다
궐동 가까운 수청동, 갈곶동, 초평동, 오산동도 다닙니다. / 오산 안이면 어디든 24시간 출동합니다.
오산 전체 안내는 [오산시 출장열쇠](osan.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
