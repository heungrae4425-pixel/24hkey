# 앱에서 갑자기 오프라인이라고 뜰 때
궐동은 오산역과 세마역 사이 생활권에서 출퇴근하는 분들이 많은 동네입니다. / 요즘은 이 동네 빌라와 아파트에도 스마트폰과 연동되는 도어락을 쓰는 집이 늘었습니다.
그런데 어느 날 앱을 열었더니 도어락이 오프라인이라고 뜨면 문이 열리지 않는 건 아닌지 걱정이 앞섭니다. / 먼저 안심하셔도 되는 부분은, 오프라인이어도 번호나 카드로는 문이 열리는 제품이 대부분이라는 점입니다.
이 글은 오프라인 표시의 원인을 나눠 보고, 집에서 해볼 점검 순서를 정리했습니다. / 문이 안 열리는 상황이라면 마지막 '문이 아예 안 열릴 때' 부분을 먼저 보세요.
@ 궐동 현관 도어락 앱에 오프라인 표시가 뜬 스마트폰 화면

# 오프라인이어도 문은 열립니다
앱 연결은 알림이나 원격 열기를 위한 부가 기능입니다. / 번호 입력이나 카드키 같은 기본 열림은 연결과 별개로 작동하는 것이 일반적입니다.
먼저 문 앞에서 번호나 카드로 열리는지 확인하세요. / 열린다면 급한 일은 아니고 연결만 다시 잡으면 됩니다.
반대로 번호도 반응이 없다면 연결 문제가 아니라 건전지나 기기 자체의 문제일 수 있습니다. / 이 경우는 연결 점검보다 문 여는 일이 먼저입니다.

# 첫 번째, 공유기부터 확인하기
도어락이 직접 와이파이에 연결되는 제품이든 별도 허브를 쓰는 제품이든, 결국 집 인터넷이 바탕입니다. / 휴대폰으로 같은 와이파이에 접속해 인터넷이 되는지 먼저 보세요.
인터넷이 안 되면 공유기 전원을 뽑고 잠시 뒤 다시 꽂아 재시작합니다. / 이것만으로 도어락이 다시 온라인이 되는 경우가 꽤 많습니다.
통신사에서 장애 공지가 있거나 공사 중이면 도어락 문제가 아니라 인터넷 문제입니다. / 이 경우는 복구되면 자동으로 연결이 돌아오는 제품이 많습니다.
@ 공유기 전원을 껐다 켜기 전 와이파이 표시등을 확인하는 모습

# 두 번째, 와이파이 이름이나 비밀번호가 바뀌었는지
공유기를 교체했거나 와이파이 비밀번호를 바꾸면 도어락은 새 정보를 모릅니다. / 그러면 인터넷이 잘 되어도 도어락만 오프라인으로 남습니다.
이사하거나 통신사를 바꾼 뒤에 많이 생기는 일입니다. / 앱에서 기기를 삭제하고 다시 등록하거나, 도어락 설정에서 새 와이파이 정보를 입력해야 합니다.
공유기가 2.4GHz와 5GHz를 나눠 쓰는 경우, 많은 도어락은 2.4GHz만 지원합니다. / 5GHz에 연결하려 하면 계속 실패할 수 있습니다.

# 세 번째, 거리와 벽이 문제일 수 있습니다
현관은 공유기에서 가장 먼 곳에 있는 경우가 많습니다. / 현관문은 금속이라 신호가 약해지기 쉽고, 벽과 방문을 거치면 더 약해집니다.
휴대폰으로 현관 앞에서 와이파이 신호 세기를 보면 대략 알 수 있습니다. / 신호가 한두 칸이면 도어락도 불안정하게 연결됩니다.
공유기를 현관 쪽으로 옮기거나 중계기를 달면 개선되는 사례가 있습니다. / 별도 허브를 쓰는 제품이라면 허브를 현관 가까이에 두는 쪽이 낫습니다.
@ 현관 근처에서 공유기와 허브 위치를 확인하는 모습

# 네 번째, 건전지가 약하면 연결부터 끊깁니다
건전지가 약해지면 도어락은 전기를 아끼려고 통신 기능부터 줄이는 제품이 있습니다. / 번호는 아직 열리는데 앱만 오프라인이 되는 경우가 이 때문일 수 있습니다.
건전지를 전부 새것으로 바꾼 뒤 몇 분 지나서 다시 앱을 확인해 보세요. / 연결이 돌아오면 원인이 건전지였던 것입니다.
교체할 때는 같은 종류로 한 번에 모두 바꾸고, 새 것과 쓰던 것을 섞지 마세요. / 방향을 거꾸로 넣으면 작동하지 않으니 표시를 다시 확인하세요.

# 다섯 번째, 앱과 펌웨어 점검
앱이 오래돼서 기기와 맞지 않는 경우도 있습니다. / 앱 스토어에서 업데이트가 있는지 확인하고 최신으로 바꿔 보세요.
도어락 자체 소프트웨어는 제조사 앱에서 안내가 나올 때 업데이트합니다. / 업데이트 도중 건전지가 모자라면 기기가 멈출 수 있으니 건전지를 바꾼 뒤에 하세요.
앱에서 로그아웃했다가 다시 로그인하는 것도 간단한 해결책이 됩니다. / 계정이 여러 개라면 기기를 등록한 계정이 맞는지 확인하세요.

# 자주 하는 실수
- 도어락과 휴대폰이 다른 와이파이에 연결돼 있는 경우
- 공유기를 껐다 켠 뒤 도어락을 재연결하지 않은 경우
- 건전지 일부만 바꾸고 나머지는 두는 경우
- 앱에서 기기를 삭제하고 초기화 방법을 몰라 헤매는 경우
초기화는 비밀번호와 등록 정보를 모두 지우는 작업이라 신중해야 합니다. / 설명서를 확인하고, 모르겠으면 하기 전에 먼저 문의 주세요.

# 도어락이 점점 자주 끊긴다면
몇 번 점검해도 오프라인이 반복된다면 통신 모듈이 약해졌을 수 있습니다. / 기기 안 통신 부품이 오래돼 신호를 못 잡는 경우입니다.
이럴 땐 [도어락 수리](doorlock-repair.html)로 점검해서 고칠 수 있는지 먼저 봅니다. / 부품 수급이 어렵거나 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 설명드립니다.
스마트 기능이 중요한 집이라면 새 제품은 설치 전에 와이파이 환경부터 같이 확인하는 것이 좋습니다. / 이 부분은 [도어락 설치](doorlock-install.html) 안내에 정리해 두었습니다.

# 문이 아예 안 열릴 때
오프라인이 아니라 문 자체가 안 열린다면 순서를 바꾸세요.
- 번호판이 켜지는지, 소리가 나는지
- 9V 건전지를 비상 단자에 대 보기
- 모터 소리만 나는지, 아무 소리도 없는지
앱으로 열어 보려고 계속 시도하지 마시고, 안 되면 전화 주세요. / 앱 연결 때문에 도어락이 잠금 상태로 대기하고 있는 경우도 있습니다.
억지로 손잡이를 당기거나 도어락을 분해하면 상태가 나빠집니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
스마트 도어락이라도 절차는 같습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 증상을 보고 작업 전에 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
@ 스마트 도어락 연결 상태를 점검하며 설정을 확인하는 작업 모습

# 궐동 말고 오산 어디든 갑니다
궐동 옆 원동, 수청동, 갈곶동 쪽도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
[오산시 출장열쇠](osan.html)에 다니는 동네를 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 공유기를 바꿨더니 연결이 끊겼어요. | 도어락이 새 와이파이 정보를 모르는 경우입니다. 앱에서 다시 등록하거나 설정에서 새 정보를 입력해야 합니다.
? 5GHz 와이파이에도 연결되나요? | 제품마다 다르지만 2.4GHz만 지원하는 제품이 많습니다. 설명서를 확인하세요.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에도 오시나요? | 24시간 전화를 받습니다. 시간 신경 쓰지 말고 연락 주세요.

# 마무리
오프라인 표시는 대부분 공유기, 와이파이 정보, 건전지, 거리 중 하나가 원인입니다. / 순서대로 하나씩 확인하면 직접 해결되는 경우가 많습니다.
그래도 안 되거나 문이 안 열리면 24시출장열쇠가 24시간 받습니다. / 서울, 경기 전 지역 전화 010-3664-5455로 연락 주세요.
