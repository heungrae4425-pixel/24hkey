# 가을이 되면 이삿짐이 늘어납니다
날씨가 선선해지는 가을은 이사를 많이 하는 계절입니다. / 남촌동에서 세마역이나 오산역 쪽으로 이동하는 분들도 이 시기에 새 집으로 옮기는 경우가 많습니다.
이삿날은 해야 할 일이 한꺼번에 몰려서 도어락은 맨 뒤로 밀리기 쉽습니다. / 그러다 이삿짐을 다 들인 뒤에야 번호를 모르는 문 앞에서 막히는 일이 생깁니다.
이 글은 이사 날짜에 도어락 일정을 어떻게 맞추면 좋은지 순서대로 정리했습니다. / 필요할 때 [오산 출장열쇠](osan.html)를 부르시면 됩니다.
@ 남촌동 가을 이사철 도어락 일정

# 이사 날짜가 정해지면 바로 해야 할 일
날짜가 확정되면 가장 먼저 새 집과 이전 집의 도어락 종류를 확인합니다. / 비밀번호식인지, 열쇠식인지, 카드키가 필요한지에 따라 준비할 것이 달라집니다.
새 집 도어락 모델과 비밀번호 방식은 이전 거주자나 집주인에게 물어보면 알 수 있습니다. / 사진을 받아 두면 나중에 설명할 때 편합니다.

이사철에는 업체와 작업 일정이 몰려 원하는 날짜가 이미 차 있을 수 있습니다. / 도어락 작업은 이삿날 전후로 여유를 두고 잡아 두는 편이 마음이 편합니다.

# 이삿날 일정에 끼워 넣는 순서
이삿짐이 들어오기 전에 도어락을 먼저 손보는 편이 좋습니다. / 짐이 가득 들어찬 뒤에는 작업 공간도 좁고 문을 여닫기도 불편합니다.
- 이사 며칠 전: 새 집 도어락과 문 상태 확인, 필요 여부 결정
- 이삿날 아침: 이전 번호 삭제와 새 번호 등록
- 이삿짐 입주 직전: 문이 잘 열리고 닫히는지 마지막 확인
- 이사 후 며칠 안: 가족 모두 새 번호에 익숙해지는지 확인
이 흐름만 지켜도 이삿날 당황할 일이 많이 줄어듭니다.

# 이전 거주자 번호 정리가 우선입니다
새 집을 얻으면 이전에 살던 분의 번호가 남아 있을 수 있습니다. / 일부러 그런 것은 아니지만 내가 모르는 번호로 문이 열릴 수 있다는 점이 마음에 걸립니다.
입주하자마자 번호를 새로 등록하고 이전 번호를 지우는 것이 첫 번째 할 일입니다. / 열쇠를 쓰는 문이라면 열쇠를 새로 맞추거나 잠금 장치 교체를 고려합니다.
@ 오산 열쇠집 남촌동 이사 도어락 재설정

# 이사 당일 문이 안 열릴 때
이사 당일 새 집 문이 안 열리면 당황스럽지만 침착하게 순서대로 보세요. / 가장 흔한 이유는 번호를 잘못 알았거나 배터리가 떨어진 경우입니다.
- 받은 번호를 다시 확인하고 번호판을 마른 천으로 닦은 뒤 천천히 누르기
- 번호판이 꺼져 있다면 9V 건전지를 비상 단자에 대 보기
- 집주인이나 이전 거주자에게 연락해 번호 변경 여부 확인하기
- 그래도 안 되면 억지로 힘을 주지 말고 연락하기
이삿짐 업체 분들이 기다리고 있는 상황이라 마음이 급해지지만 문을 상하게 하면 보상 문제가 생길 수 있습니다.

번호를 새로 정할 때는 이사 날짜나 전화번호 같은 쉬운 숫자를 피하세요. / 가족이 기억하기 쉬우면서도 남이 짐작하기 어려운 번호가 좋습니다.

# 이삿짐 업체와 도어락 접촉
이삿날에는 짐을 나르며 문을 많이 여닫습니다. / 이때 도어락에 짐이 부딪히면 부품이 상하거나 설정이 풀릴 수 있습니다.
문을 열어 둔 채 짐을 옮길 때는 걸쇠나 문 받침으로 고정해 두세요. / 도어락 번호판이 눌려 오작동하는 일을 막아 줍니다.

이삿짐 박스를 푸는 동안에도 문 상태는 눈여겨보세요. / 처음 며칠은 소리나 손맛이 낯설어 이상한지 아닌지 구분하기 어렵기 때문에 의심스러우면 메모해 두세요.

# 새 도어락을 달아야 할지 판단하기
집주인이 설치한 제품이 있다면 일단 그대로 쓰는 것을 권합니다. / 고장 없이 잘 열리고 번호 관리가 가능하다면 바꿀 필요가 없습니다.
다만 너무 낡았거나 이전 사용자의 정보가 남아 정리가 안 되는 제품이라면 교체를 고려할 수 있습니다. / 고민된다면 문을 보여주고 상담받으세요.
새로 달고 싶다면 [도어락 설치](doorlock-install.html) 안내를 참고하시고, 오래된 제품을 바꿀 때는 [도어락 교체](doorlock-replace.html) 페이지를 확인해 보세요.

새 집 문이 반듯하게 닫히는지도 입주 전에 확인해 보세요. / 걸쇠가 문틀에 잘 들어가지 않거나 문이 처졌다면 입주 전에 말씀드려 두는 것이 좋습니다.

# 집주인과 미리 정해 둘 것
세입자라면 도어락 교체나 변경이 가능한지 집주인과 미리 이야기해 두세요. / 허락 없이 바꾸면 나중에 곤란해질 수 있으니 서로 확인한 뒤 진행하는 것이 안전합니다.
번호를 바꾸는 것만으로 충분한 경우가 많아 대개는 큰 부담 없이 합의됩니다. / 퇴거할 때 원래대로 돌려놓아야 하는지도 함께 얘기해 두면 좋습니다.

# 이사 가는 쪽에서 챙길 것
떠나는 집에서도 해야 할 일이 있습니다. / 내가 등록한 번호와 카드키를 정리하고 열쇠를 모두 돌려주는 것이 기본입니다.
다음 사람이 불편하지 않도록 번호를 초기화하거나 안내 메모를 남겨 두는 방법도 있습니다. / 이 부분은 집주인과 협의해서 정하시면 됩니다.
@ 남촌동 이사 전후 도어락 점검

이사 중에 열쇠를 이전 집에 두고 와서 새 집에서 곤란해지는 일도 있습니다. / 열쇠 인수인계는 이삿날 전에 끝내 두는 것이 안전합니다.

# 출장 요청 전에 알려주면 좋은 내용
이삿날처럼 시간이 정해진 일정이면 미리 방문 시간을 조율하는 것이 좋습니다. / 도어락 모양, 문 사진, 건물 위치와 층수를 문자로 남겨 주시면 준비가 빨라집니다.
세마역 쪽에서 오시는지 오산역 쪽에서 오시는지 알려주셔도 이동 계획에 도움이 됩니다. / 이삿짐 도착 시간이 있다면 함께 말씀해 주세요.

# 작업 전 신분 확인과 비용 안내
이사 직후라 신분증 주소가 아직 이전 주소인 경우가 많습니다. / 이럴 때는 임대차 서류나 우편물, 관리사무소 확인 같은 다른 방법으로 사시는 분임을 확인합니다.
비용은 문과 도어락을 보고 작업 전에 먼저 말씀드립니다. / 괜찮다고 하실 때만 진행하고 문을 끝내 못 열면 비용은 받지 않습니다.

# 이사가 끝난 뒤의 마무리 점검
짐을 다 들인 뒤에는 가족 모두 새 번호를 쓸 수 있는지 확인합니다. / 아이와 어르신이 있다면 번호를 누르는 연습을 한 번 같이 해보세요.
배터리는 이사 시점에 전부 새것으로 바꿔 두면 좋습니다. / 이전 집에서 쓰던 건전지를 그대로 가져오는 것은 권하지 않습니다.
[도어락 수리](doorlock-repair.html)가 필요한 증상이 있다면 이삿짐 정리가 끝나기 전에 같이 손보는 편이 수월합니다. / [이용안내](guide.html)에서 진행 방식을 미리 보실 수 있습니다.

마지막으로 이사 후 우편물 주소 이전도 잊지 마세요. / 신분 확인에 우편물이 필요한 상황이 생기면 새 주소로 온 우편물이 도움이 됩니다.

# 남촌동 말고 오산 어디든 갑니다
남촌동 가까이 오산동, 원동, 대원동, 갈곶동, 세교동도 출동합니다. / 오산 안이면 이사 일정에 맞춰 가능한 시간을 조율해 드립니다.
다니는 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문

? 이전 거주자 번호는 어떻게 지우나요? | 제품 설정에서 삭제하거나 새로 초기화합니다. 방법은 제품마다 달라 현장에서 안내해 드립니다.
? 세입자인데 도어락을 바꿔도 되나요? | 집주인과 먼저 협의해 주세요. 번호 변경만으로 충분한 경우가 많습니다.
? 신분증 주소가 이전 집인데 괜찮나요? | 임대차 서류나 우편물 등 다른 확인 방법을 같이 찾습니다.
