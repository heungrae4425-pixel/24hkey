# 잠금 소리는 나는데 문이 안 잠긴다면
남촌동 현관문에서 번호를 누르면 모터 소리는 분명히 나는데, 문을 당겨 보면 잠기지 않았거나 반대로 열리지 않는 일이 있습니다. / 이럴 때 많은 분들이 도어락 고장이라고 생각하지만 실제로는 데드볼트가 문제인 경우가 적지 않습니다.
데드볼트는 문틀 안으로 들어가서 문을 단단히 잡아 주는 굵은 금속 막대입니다. / 도어락이 아무리 정상이어도 이 막대가 제 위치로 들어가고 나오지 못하면 문은 잠기지도 열리지도 않습니다.
이 글은 데드볼트가 걸리는 이유와 직접 확인할 수 있는 것, [오산 출장열쇠](osan.html)를 불러야 하는 때를 정리했습니다. / 문 앞에서 지금 겪고 계신 상황과 비교하면서 읽어 보세요.
@ 남촌동 데드볼트 잠금쇠 점검 출장열쇠

# 데드볼트가 하는 일
현관문에는 보통 두 가지 쇠가 있습니다. / 하나는 문을 닫을 때 튕겨 들어가는 걸쇠이고, 다른 하나는 잠글 때 굵게 튀어나오는 데드볼트입니다.
걸쇠는 문이 닫힌 상태를 유지하고, 데드볼트는 밖에서 문이 밀리지 않도록 단단히 잡습니다. / 번호나 열쇠로 잠금을 풀면 데드볼트가 들어가고, 잠그면 문틀 구멍으로 나옵니다.
이 쇠가 문틀 구멍에 정확히 맞아야 정상적으로 움직입니다. / 구멍이 조금만 어긋나도 쇠가 걸려서 모터가 헛돌거나 멈춥니다.

# 안 들어가는 경우와 안 나오는 경우
증상은 크게 두 가지로 나뉩니다. / 어느 쪽인지 확인하면 원인을 좁힐 수 있습니다.
- 잠그려는데 데드볼트가 끝까지 나오지 않고 중간에서 멈추는 경우
- 열려고 하는데 데드볼트가 들어가지 않아 문이 안 열리는 경우
앞의 경우는 문틀 구멍과 위치가 어긋났거나 구멍 안에 이물질이 있을 때가 많습니다. / 뒤의 경우는 문이 눌려서 쇠가 문틀에 끼었거나 모터가 약해졌을 때가 많습니다.

# 문이 눌려 있을 때 생기는 일
데드볼트가 안 빠지는 가장 흔한 이유는 문이 처져서 쇠가 문틀 구멍에 비스듬히 걸리는 것입니다. / 이때 쇠에 힘이 가해져서 모터가 아무리 돌려도 빠지지 않습니다.
이럴 때는 문을 안쪽으로 살짝 밀면서 손잡이를 위로 들어 올리듯 당기고 동시에 번호를 눌러 보세요. / 문이 눌린 상태가 풀리면서 쇠가 빠지는 경우가 있습니다.
이렇게 해서 열렸다면 도어락 문제가 아니라 문 처짐 문제이므로 경첩과 문틀을 점검해야 합니다. / 같은 일이 반복되면 처짐이 더 진행되기 전에 손봐야 합니다.
@ 남촌동 현관문 처짐 데드볼트 걸림

# 문틀 구멍을 확인해 보세요
문이 열려 있다면 문틀 쪽 데드볼트 구멍을 눈으로 확인해 보세요. / 구멍 안에 먼지, 이물질, 도장 찌꺼기가 쌓여 있는지 살펴보시면 됩니다.
구멍 주변이 긁혀 있다면 쇠가 정확히 들어가지 못하고 비스듬히 걸리고 있다는 증거입니다. / 긁힌 위치가 구멍 위쪽인지 아래쪽인지에 따라 문이 어느 방향으로 처졌는지도 알 수 있습니다.
먼지가 쌓여 있다면 마른 천이나 부드러운 솔로 가볍게 털어 주세요. / 날카로운 도구로 후비면 구멍이 넓어져서 문이 헐렁해지니 피해 주세요.

# 도어락 모터가 약해졌을 때
모터 소리가 평소보다 느리거나 중간에 멈칫한다면 배터리나 모터 문제일 수 있습니다. / 특히 배터리가 약해지면 데드볼트를 끝까지 밀어내거나 당길 힘이 부족해집니다.
먼저 배터리를 새것으로 모두 교체해 보세요. / 배터리를 바꾸고 나서 증상이 사라진다면 모터 문제가 아니라 전력 부족이 원인이었던 것입니다.
배터리를 바꿔도 같은 증상이 계속된다면 모터나 내부 기어가 닳은 경우입니다. / 이 경우는 점검과 수리가 필요합니다.

# 하지 말아야 할 행동
데드볼트가 안 움직인다고 문을 세게 당기거나 발로 차는 분들이 있습니다. / 그러면 문틀이 틀어지고 걸쇠와 데드볼트가 더 꽉 물립니다.
- 손잡이를 힘으로 돌려 억지로 열려고 하기
- 문을 세게 흔들거나 발로 차기
- 번호를 연속으로 계속 누르며 모터를 혹사하기
- 데드볼트에 윤활제를 잔뜩 뿌리기
특히 모터가 헛도는 상태에서 계속 시도하면 내부 기어가 닳아서 수리 범위가 커집니다. / 서너 번 시도해서 안 되면 멈추시는 편이 낫습니다.

# 안에서는 열리는데 밖에서 안 될 때
안쪽에서는 잘 열리는데 밖에서만 안 되는 경우도 있습니다. / 이럴 때는 바깥쪽 번호판이나 열쇠 구멍과 내부 연결 부분을 의심해 볼 수 있습니다.
문 안쪽에서 열리는 것이 확인된다면 데드볼트 자체는 움직인다는 뜻입니다. / 그렇다면 바깥쪽 입력 부분이나 연결 부분 문제일 가능성이 높습니다.
이 경우에는 [도어락 수리](doorlock-repair.html)로 점검하는 것이 맞습니다. / 외관만 보고 판단하기 어려운 경우가 많아서 직접 보고 말씀드립니다.

# 출장 점검에서 확인하는 순서
도착하면 먼저 문 상태와 데드볼트 움직임을 확인합니다. / 문이 눌려 있는지, 쇠가 문틀 구멍과 맞는지, 모터가 정상으로 도는지를 차례로 봅니다.
문이 안 열리는 상태라면 [현관문 개문](door-open.html) 방식으로 문과 도어락이 상하지 않게 열어 드립니다. / 열고 난 뒤에는 원인을 찾아서 다시 같은 일이 생기지 않게 점검합니다.
문 처짐이 원인이라면 경첩과 문틀 구멍 위치를 조정하는 방법을 안내합니다. / 도어락 내부가 원인이라면 수리 가능한지 먼저 판단합니다.
@ 남촌동 출장열쇠 데드볼트 문틀 점검

# 신분 확인과 비용
문을 만지는 일이라 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 한 가지면 됩니다.
상태를 본 뒤에 작업 방식과 비용을 먼저 말씀드리고, 괜찮다고 하실 때만 시작합니다. / 문을 끝내 못 열면 비용은 받지 않고, 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다. / 처음 부르시는 분은 한 번 읽어 보시면 마음이 편합니다.

# 데드볼트 문제를 줄이는 평소 관리
데드볼트는 문과 문틀이 잘 맞아야 오래 갑니다. / 한 번씩 확인해 주시면 잠금 문제를 많이 예방할 수 있습니다.
- 문을 닫을 때 문틀에 부딪히지 않게 천천히 닫기
- 문틀 구멍 주변에 먼지와 이물질이 쌓이지 않게 가끔 털기
- 잠금음이 평소와 다르면 미루지 말고 배터리 확인하기
- 계절이 바뀔 때 문이 뻑뻑해지는지 살펴보기
데드볼트 소리가 평소와 달라졌다면 대부분 문 틈 어딘가가 어긋난 것입니다. / 소리가 달라진 때를 기억해 두셨다가 알려주시면 원인을 찾는 데 도움이 됩니다.

# 남촌동 말고 오산 어디든
남촌동 바로 옆 오산동, 궐동, 초평동까지 오산 전 지역을 24시간 다닙니다. / 오산역이나 세마역 근처라면 위치만 알려주세요.
오산에서 다니는 동네는 [오산시 출장열쇠](osan.html)에 정리해 두었고, 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 도어락 교체가 필요하다면 [도어락 교체](doorlock-replace.html) 안내도 확인해 보세요.
