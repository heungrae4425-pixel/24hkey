# 도어락은 사기 전에 문부터 봐야 합니다
남촌동에서 도어락을 새로 달거나 바꾸려는 분들이 가장 많이 놓치는 부분이 문의 규격입니다. / 제품을 먼저 사 놓고 나서 문에 안 맞아 곤란한 경우가 생깁니다.
이 글은 도어락을 달기 전에 확인할 것들을 순서대로 정리했습니다. / 어려우시면 [오산 출장열쇠](osan.html)에 사진을 보내 주셔도 됩니다.
@ 남촌동 도어락 설치 전 문 두께 확인

# 확인할 것 하나, 문이 어떤 종류인지
현관문은 나무문, 철문, 방화문, 유리문 등 재질이 다양합니다. / 재질에 따라 구멍을 뚫는 방법과 붙이는 방식이 달라집니다.
유리문은 일반 도어락을 달기 어려운 경우가 많습니다. / 문 재질을 정확히 알려주시면 맞는 제품을 추천하기 쉽습니다.

# 확인할 것 둘, 문 두께
도어락마다 설치할 수 있는 문 두께 범위가 정해져 있습니다. / 문이 너무 두껍거나 얇으면 규격에 맞는 부속이 필요합니다.
줄자로 문 옆면의 두께를 재서 알려주시면 가장 쉽습니다. / 정확히 재기 어려우면 사진에 줄자를 대서 찍어 주세요.

# 확인할 것 셋, 기존 구멍의 위치와 크기
이미 도어락이 달려 있다면 문에 뚫린 구멍이 기준이 됩니다. / 새 제품과 구멍 위치나 크기가 안 맞으면 메꾸거나 넓히는 작업이 필요합니다.
이 작업은 문을 상하지 않게 하는 요령이 필요합니다. / 임의로 뚫으면 문이 돌이킬 수 없이 상할 수 있어 맡기시는 편이 안전합니다.
@ 오산 남촌동 현관문 구멍 규격 점검

# 확인할 것 넷, 보조키를 어떻게 할지
보조키는 문 위쪽이나 아래쪽에 달린 두 번째 잠금 장치입니다. / 도어락을 새로 달 때 보조키를 그대로 둘지, 같이 바꿀지 정해야 합니다.
보조키 모양과 열쇠 방식이 새 도어락과 맞는지도 확인해야 합니다. / 열쇠가 필요 없는 제품이라면 보조키 위치를 정리하는 방법도 있습니다.

# 확인할 것 다섯, 문틀 받침판
문틀에 걸쇠가 들어가는 받침판의 위치와 높이도 함께 봅니다. / 위치가 어긋나면 새 도어락을 달아도 문이 잘 잠기지 않습니다.
받침판 위치를 맞추는 작업이 같이 필요한 경우도 있습니다. / 이런 부분은 문을 직접 봐야 정확히 알 수 있습니다.

# 어떤 방식의 도어락이 맞을까
비밀번호만 쓰는 제품, 카드나 태그를 쓰는 제품, 지문을 쓰는 제품이 있습니다. / 가족 구성과 생활 방식에 맞춰 고르시는 게 좋습니다.
아이가 있다면 사용이 쉬운 방식을, 혼자 산다면 보안이 단단한 방식을 우선하세요. / 제품이 많다고 해서 비싼 것이 꼭 맞는 건 아닙니다.
@ 남촌동 번호키 지문 도어락 설치 모습

# 설치 전에 사진 몇 장만 보내 주세요
문 전체, 도어락이 있는 부분의 앞뒤, 문 옆면 이렇게 네 장이면 충분합니다. / 줄자를 대고 문 두께를 찍은 사진이 있으면 더 정확합니다.
사진을 보면 어떤 제품이 맞는지, 어떤 작업이 필요한지 미리 말씀드릴 수 있습니다. / 그러면 현장에서 시간이 덜 걸립니다.

# 설치 과정은 이렇게 진행됩니다
먼저 기존 도어락을 떼고 문과 구멍 상태를 봅니다. / 새 제품을 달고 번호와 카드를 등록한 다음 여러 번 열고 닫으며 확인합니다.
문틀 받침판과 보조키까지 맞춰야 작업이 끝납니다. / 마지막에 사용법을 설명해 드리고 건전지 교체 시기도 알려드립니다.
설치 과정은 [도어락 설치](doorlock-install.html) 페이지에도 자세히 적어 두었습니다.

# 비용은 작업 전에 말씀드립니다
문 상태와 제품 종류, 추가 작업 여부를 보고 얼마가 드는지 먼저 말씀드립니다. / 동의하시면 그때 시작하고, 아니면 그냥 돌아갑니다.
작업 중에 추가로 필요한 부분이 생기면 손대기 전에 먼저 여쭙니다. / 말없이 붙는 비용은 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 이미 산 제품이 있으면 어떻게 하나요
직접 구입한 제품도 설치할 수 있는지 문과 맞는지 먼저 확인해 보겠습니다. / 문에 맞지 않으면 어떤 점이 안 맞는지 설명해 드립니다.
설치 전에 제품 모델명을 알려주시면 규격을 미리 확인할 수 있습니다. / 도어락 교체는 [도어락 교체](doorlock-replace.html) 페이지를 참고하세요.

# 설치 후 관리 요령
새 도어락은 처음 등록한 비밀번호를 가족과 같이 정해 두세요. / 건전지는 해가 바뀔 때쯤 한 번에 바꾸는 습관이 좋습니다.
카드나 태그는 하나쯤 다른 곳에 보관해 두면 만일에 대비할 수 있습니다. / 이상한 소리나 반응이 느껴지면 미루지 말고 연락 주세요.

# 남촌동에서 오산 어디든 갑니다
남촌동 바로 옆 오산동, 원동, 궐동, 세교동, 신장동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
오산에서 다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

# 자주 묻는 질문
? 문 두께를 모르겠어요. | 문 옆면을 사진으로 보내 주시면 확인해 드립니다.
? 구멍 위치가 다르면 못 다나요? | 구멍을 맞추는 작업을 할 수 있는지 문을 보고 말씀드립니다.
? 보조키도 같이 바꿔야 하나요? | 상황에 따라 다릅니다. 문 상태를 보고 필요한지 말씀드립니다.
? 직접 산 제품도 달아 주나요? | 문에 맞는지 먼저 확인하고 가능한지 말씀드립니다.
? 설치 후에도 문제가 생기면요? | 연락 주시면 점검해 드립니다.
