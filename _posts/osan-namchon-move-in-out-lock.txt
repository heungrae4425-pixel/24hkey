# 남촌동 이사, 도어락은 이사 날 가장 먼저 확인하세요
이사 날은 짐과 사람으로 정신이 없어서 도어락은 마지막에야 떠올리게 됩니다. / 그런데 문 앞에서 막히면 짐 옮기기가 통째로 멈춥니다.
남촌동에서도 입주나 퇴거 날 번호가 안 맞는다는 연락이 가끔 들어옵니다. / 이 글은 이사 전후에 도어락과 현관문에서 확인할 것을 순서대로 적은 것입니다.
입주하는 쪽이든 퇴거하는 쪽이든 순서는 비슷합니다. / 이미 이사 중이라면 3번부터 보셔도 됩니다.
@ 남촌동 이사 도어락 점검 출장열쇠 24시

# 입주 전에 확인할 것
이전에 살던 사람이 쓰던 번호나 열쇠가 그대로 남아 있을 수 있습니다. / 입주하는 날 가장 먼저 새 번호로 바꾸는 것을 권합니다.
도어락 배터리가 남아 있는지도 같이 확인해 보세요. / 교체 시기를 모르는 상태라면 새 배터리로 바꿔 두는 것이 마음 편합니다.
열쇠와 카드키가 몇 개 있는지, 모두 받았는지도 확인하세요. / 집주인이나 공인중개사에게 받은 개수를 기록해 두면 퇴거 때 편합니다.

# 번호를 바꾸는 순서
번호를 바꿀 때는 먼저 도어락 안쪽의 설정 버튼 위치를 찾아야 합니다. / 제품마다 위치와 누르는 순서가 다릅니다.
설명서가 없다면 제품 이름이나 사진을 알려주시면 방법을 안내해 드립니다. / 번호를 바꾼 뒤에는 문을 연 채로 새 번호가 되는지 두세 번 확인하세요.
문이 열린 상태에서 먼저 확인해 보는 것이 중요합니다. / 문이 닫힌 상태에서 번호를 바꾸다 잘못되면 들어가지 못할 수 있습니다.
@ 남촌동 도어락 비밀번호 변경 열쇠집

# 퇴거 전에 정리할 것
퇴거할 때는 사용하던 번호를 지우고 초기 상태로 돌려놓는 것이 일반적입니다. / 계약서나 임대인 안내에 정리 방법이 있다면 그대로 따르세요.
열쇠나 카드키는 개수를 확인한 뒤 임대인에게 전달하세요. / 하나라도 빠지면 분쟁이 생길 수 있습니다.
도어락 상태에 이상이 있다면 퇴거 전에 사진을 찍어 두세요. / 누구의 책임인지는 계약 내용과 임대인과의 협의에 따라 정해집니다.

# 이삿짐 업체가 오기 전에 해두면 좋은 것
도어락 배터리가 약하면 이삿짐을 옮기는 동안 문이 자주 열리고 닫히다 꺼질 수 있습니다. / 이사 전날 배터리를 새것으로 바꿔 두면 안전합니다.
이삿짐 업체 직원이 문을 열어 둘 수 있게 번호를 임시로 알려줘야 한다면 끝난 뒤 바로 바꾸세요. / 번호를 알려주는 것이 불안하다면 이사 중에는 문을 열어 두는 방법도 있습니다.
도어락 근처 벽이나 문틀이 이삿짐에 부딪히지 않게 보호해 달라고 요청해 두세요. / 문과 도어락이 상하면 나중에 확인하기 어렵습니다.

# 이사 날 문이 안 열릴 때
번호가 맞지 않는다면 이전 입주자가 바꿨거나 인수인계가 안 된 경우입니다. / 집주인이나 공인중개사에게 먼저 확인해 보세요.
번호는 맞는데 안 열린다면 배터리나 모터 문제일 수 있습니다. / 번호판에 불이 들어오는지 확인하세요.
열쇠가 맞지 않는다면 열쇠 구멍에 이물질이 끼었거나 열쇠가 아닌 경우도 있습니다. / 억지로 돌리지 마세요.

# 이럴 때는 출장열쇠를 부르세요
이삿짐이 문 앞에서 멈췄거나 입주 첫날부터 문이 안 열릴 때 연락 주세요. / 남촌동 전 지역과 오산 어디든 24시간 출동합니다.
[오산 출장열쇠](osan.html) 페이지에서 다니는 동네를 확인하실 수 있습니다. / 이삿짐 업체가 기다리고 있다면 먼저 말씀해 주세요.
도착 시간과 상황에 따라 서둘러 출동합니다. / 위치와 도어락 모양만 알려주세요.

# 전화로 이렇게 말씀해 주세요
남촌동 어느 쪽인지, 건물 이름 대신 근처 길이나 가게를 알려주세요. / 새로 이사 가는 집이라 주소가 낯설다면 계약서에 적힌 주소를 그대로 읽어 주세요.
입주인지 퇴거인지, 문이 닫혀 있는지, 번호판 상태가 어떤지 알려주세요. / 도어락 사진이 있다면 문자로 보내 주세요.
이삿짐 차가 오는 시간이나 기다리는 사람이 있는지도 알려주세요. / 출동 순서를 정하는 데 참고합니다.

@ 남촌동 입주 퇴거 도어락 열쇠 확인

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이므로 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 계약서, 관리사무소 확인 중 하나면 됩니다.
이사 날에는 주소 이전이 안 된 경우가 많아서 계약서 사진이 가장 도움이 됩니다. / 집주인이나 공인중개사 확인도 참고가 됩니다.
확인이 어려우면 작업을 진행하지 못하니 미리 준비해 두세요. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 열기 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 도어락을 바꿀지 그대로 쓸지 고민될 때
이사하면서 도어락을 새로 바꾸는 분도 있고 그대로 쓰는 분도 있습니다. / 작동이 잘 되고 배터리만 바꾸면 되는 상태라면 그대로 쓰시는 것을 권합니다.
이전 입주자가 번호를 알고 있다는 점이 걱정이라면 번호만 바꿔도 충분한 경우가 많습니다. / 제품이 너무 오래되었거나 고장이 잦다면 [도어락 교체](doorlock-replace.html)를 상담해 보세요.
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)를 먼저 권합니다. / 임대 주택이라면 교체 전에 임대인에게 먼저 알리세요.
@ 남촌동 24시 출장열쇠 이사 010-3664-5455

# 이사 후 일주일 안에 해두면 좋은 것
번호를 가족과 공유하고 여분 열쇠나 카드키를 한 곳에 정리해 두세요. / 이사 직후에는 모든 것이 낯설어서 번호를 잊기 쉽습니다.
도어락 배터리 교체 날짜를 적어 두면 다음에 잊지 않습니다. / 문이 부드럽게 닫히는지도 며칠 써 보며 확인하세요.
이상한 소리나 걸리는 느낌이 있다면 미루지 말고 연락 주세요. / 완전히 멈추기 전에 손보면 비용도 덜 듭니다.

# 인수인계 때 사진으로 남겨 두세요
입주 첫날 도어락과 현관문 상태를 사진으로 찍어 두면 나중에 퇴거할 때 큰 도움이 됩니다. / 번호판 모양, 손잡이 상태, 문 안쪽의 흠집 같은 것을 함께 담아 두세요.
열쇠나 카드키를 받은 날짜와 개수도 메모해 두면 서로 확인하기가 쉽습니다. / 임대인과 주고받는 메시지로 남겨 두는 방법도 있습니다.
도어락이 이미 불안정하다면 입주 전에 임대인에게 알리고 어떻게 정리할지 정해 두세요. / 누가 비용을 부담할지는 계약 내용과 협의에 따라 정해지므로 당사자끼리 확인하셔야 합니다.
