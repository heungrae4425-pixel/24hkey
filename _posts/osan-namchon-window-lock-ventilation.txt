# 남촌동 창문, 환기하려다 잠금이 헐거워졌다면
남촌동은 오산역과 오산대역 쪽으로 오가는 분들이 많은 생활권입니다. / 집을 비우는 시간이 긴 가정일수록 창문 잠금이 제대로 되어 있는지가 은근히 마음에 걸립니다.
날씨가 좋은 날 환기를 하려고 창문을 열었다가, 닫고 보니 잠금 레버가 덜렁거리는 경우가 있습니다. / 헐거운 잠금장치는 바로 문제가 되지 않아도 방치하면 점점 커집니다.
이 글은 창문 잠금장치가 헐거울 때 어떤 순서로 점검하면 좋은지 정리한 것입니다. / 현관문 이야기는 아니지만 열쇠와 잠금장치를 다루는 일이라 자주 받는 문의이기도 합니다.
@ 남촌동 창문 크레센트 잠금장치 점검

# 헐겁다는 말이 가리키는 증상부터 나눠 보세요
창문 잠금이 헐겁다고 해도 실제 증상은 세 가지 정도로 나뉩니다. / 어느 쪽인지에 따라 해볼 일이 달라집니다.
- 레버를 돌려도 걸리는 느낌이 없이 헛도는 경우
- 레버는 돌아가는데 반대쪽 고리에 딱 맞지 않는 경우
- 창을 닫으면 덜컹거리며 틈이 생기는 경우
첫 번째는 레버 안쪽 부품이 문제인 경우가 많고, 두 번째는 창틀과 창문의 위치가 어긋난 경우가 많습니다. / 세 번째는 잠금장치 자체보다 창문 롤러나 틈막이 고무 쪽 문제일 수 있습니다.

# 나사 하나가 풀린 것만으로도 생기는 일
잠금장치를 고정한 나사가 오래 쓰며 풀리면 레버가 흔들리면서 헐거운 느낌이 납니다. / 이럴 때는 맞는 크기의 드라이버로 살짝 조여 주기만 해도 좋아집니다.
다만 너무 세게 조이면 샤시 틀이 상하거나 나사 구멍이 헛돌 수 있습니다. / 손으로 느끼기에 레버가 흔들리지 않을 정도에서 멈추는 게 좋습니다.
나사 구멍이 이미 닳아서 돌려도 계속 헛돌면 억지로 힘을 주지 마세요. / 그때는 부품을 바꿔야 할 수도 있으니 사진을 찍어 두고 상담하세요.

# 고리 쪽을 먼저 들여다보기
레버와 만나는 반대쪽 고리 부품이 틀어지면 잠금이 헐거워 보입니다. / 이 부품은 창문이 닫힐 때 레버가 걸리는 자리입니다.
창문을 닫은 상태에서 고리와 레버의 높이가 맞는지 눈으로 먼저 보세요. / 몇 밀리만 어긋나도 걸리는 느낌이 약해집니다.
- 고리 나사가 풀려 아래로 처졌는지
- 창문이 레일에서 한쪽으로 쏠려 있는지
- 틈막이 고무가 눌려 닳았는지
이 세 가지만 봐도 잠금장치가 원인인지 창문 자체가 원인인지 어느 정도 구분이 됩니다.
@ 창틀 고리와 레버 높이가 맞는지 확인

# 창문 롤러와 틈막이 고무도 같이 봐야 합니다
창문이 덜컹거리는 원인이 잠금이 아니라 하단 롤러일 때도 있습니다. / 롤러가 닳으면 창문이 아래로 처져 잠금이 애매하게 걸립니다.
틈막이 고무는 오래되면 딱딱해지고 줄어듭니다. / 그러면 환기할 때 바람 소리가 나고, 닫아도 틈이 남아 잠금이 헐거운 것처럼 느껴집니다.
이런 경우는 잠금장치만 바꿔서는 해결되지 않습니다. / 롤러와 고무 상태까지 같이 확인해야 오래 갑니다.

# 하지 말아야 할 것
창문이 헐겁다고 해서 바로 큰일이 나는 것은 아니니, 서두르지 말고 차례대로 확인하세요. / 한 번에 여러 부품을 건드리면 처음에 무엇이 문제였는지 알기 어려워집니다.
급하다고 잠금 레버를 세게 돌려 억지로 맞추지 마세요. / 부러지면 창문이 닫혀 있어도 잠그지 못하는 상태가 됩니다.
접착제나 테이프로 임시로 고정하는 것도 피하는 편이 좋습니다. / 나중에 부품을 바꿀 때 오히려 떼어 내기 어려워집니다.
창문 틀을 분해하기 어려운 구조인데 혼자 뜯어 보는 것도 권하지 않습니다. / 유리가 있는 창문이라 손을 다칠 수도 있습니다.

# 환기하는 동안 잠금은 어떻게 둘까
환기를 오래 하는 날에는 잠금장치를 반쯤 걸어 두는 창이 많습니다. / 이때 레버가 헐거우면 바람에 창이 밀려 소리가 날 수 있습니다.
외출할 때는 창문을 닫고 잠금까지 걸어 두는 습관이 가장 기본입니다. / 특히 낮은 층이나 베란다 쪽 창은 한 번 더 확인하는 게 좋습니다.
과장해서 불안해할 일은 아니지만, 잠금이 제 기능을 하는 창과 그렇지 않은 창은 차이가 있습니다. / 헐거운 곳은 가까운 때에 손봐 두면 마음이 편합니다.
@ 환기할 때 창문 잠금 반쯤 걸기

# 고쳐서 쓸지 바꿀지 정하는 기준
잠금장치는 대부분 고쳐서 쓸 수 있습니다. / 나사를 조이거나 고리 위치를 맞추는 정도로 해결되는 경우가 많습니다.
다음에 해당하면 부품 교체를 생각해 볼 만합니다.
- 레버 자체가 휘었거나 금이 간 경우
- 돌려도 안쪽 부품이 움직이는 느낌이 없는 경우
- 나사 구멍이 닳아 고정이 안 되는 경우
교체가 필요할 때도 창 규격과 맞는 부품을 고르는 것이 중요합니다. / 현장을 보고 문을 열기 전에 먼저 말씀드리는 것처럼, 부품도 바꾸기 전에 먼저 여쭙니다.

# 창문 잠금과 현관 잠금을 같이 점검하면 좋은 이유
잠금장치가 헐거워졌다면 현관 도어락도 같은 시기에 점검하는 편이 좋습니다. / 오래 쓴 집이라면 같은 시기에 낡은 부품이 여럿 있을 수 있기 때문입니다.
도어락 배터리는 해가 바뀔 때쯤 한 번에 교체하는 것이 좋습니다. / 문이 덜 닫히거나 걸쇠가 걸리는 느낌이 있다면 [도어락 수리](doorlock-repair.html)로 먼저 확인해 보세요.
새 제품이 필요한지는 [도어락 교체](doorlock-replace.html) 안내 페이지에서 확인하실 수 있습니다. / 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.

# 출장 요청 전에 준비하면 좋은 것
창문 잠금 점검을 부탁하실 때는 사진이 큰 도움이 됩니다. / 잠금 레버 전체, 반대쪽 고리, 창문이 닫힌 모습을 한 장씩 찍어 두세요.
- 어느 방, 어느 창인지
- 층수와 창 모양(미닫이, 여닫이)
- 증상이 언제부터인지
- 환기 때 바람 소리가 나는지
이 정도만 알려 주셔도 현장에서 맞는 부품을 챙겨 가기 쉽습니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 신분 확인과 비용 안내는 창문 작업도 같습니다
작업 전에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
비용은 작업 전에 먼저 말씀드리고, 괜찮다고 하실 때만 시작합니다. / 점검만으로 끝나는 경우도 시작 전에 설명드립니다.
현관문이 잠겨 못 들어가는 상황이라면 [현관문 개문](door-open.html) 안내를 먼저 보세요. / 못 열면 비용은 받지 않는다는 기준은 그대로입니다.

# 남촌동 말고 오산 어디든 갑니다
남촌동 바로 옆 오산동, 대원동, 원동, 초평동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
오산 출장 동네는 [오산시 출장열쇠](osan.html) 페이지에, 다른 지역은 [출장 지역](area.html) 지도에 정리해 두었습니다.
