# 오산동 단지 전체가 정전됐을 때 벌어지는 일
오산동은 오산역 가까이 있어 많은 분이 걸어서 오가는 동네입니다. / 가끔 단지 전체가 한꺼번에 정전되면 같은 시간에 수십 세대가 같은 문제를 겪게 됩니다.
엘리베이터가 멈추고, 공동현관이 안 열리고, 집 안 도어락도 반응이 이상해집니다. / 한 집만의 문제가 아니라 같이 겪는 일이라 대처 방법도 조금 다릅니다.
이 글은 단지 정전 때 도어락과 출입문에 생기는 문제를 정리했습니다. / 문이 안 열리면 [오산 출장열쇠](osan.html)에 연락하시면 됩니다.
@ 오산동 단지 정전 때 어두운 복도와 현관

# 정전이 되면 가장 먼저 확인할 것
정전이 우리 집만의 일인지 단지 전체의 일인지 먼저 구분해야 합니다. / 복도와 옆집 불이 다 꺼졌다면 단지 전체 문제일 가능성이 큽니다.
이때 도어락 문제로 착각하고 문을 두드리거나 번호를 반복해 누르는 분들이 계십니다. / 건전지로 쓰는 도어락은 정전과 무관하게 작동하는 경우가 대부분이라 먼저 상태를 구분해야 합니다.
관리사무소나 경비실에 정전 원인과 복구 예상 시간을 먼저 물어보세요. / 단지 전체 문제라면 곧 복구되는 경우도 많아 급히 서두르지 않아도 됩니다.

# 건전지식과 전기 공급식은 다릅니다
대부분의 가정용 도어락은 건전지로 움직여서 정전의 영향을 크게 받지 않습니다. / 다만 일부 제품이나 연동 장치는 외부 전원을 함께 쓰는 경우가 있습니다.
공동현관과 주차장 차단기, 엘리베이터는 건물 전기를 쓰기 때문에 정전 때 가장 먼저 영향을 받습니다. / 이 부분이 막히면 현관에 도착해도 못 들어가는 일이 생깁니다.
집 안 와이파이와 연동된 스마트 도어락은 통신이 끊기면 앱 열림이 안 될 수 있습니다. / 그래도 번호와 열쇠로는 열리도록 만들어진 제품이 대부분입니다.

# 정전 중 도어락이 보이는 증상
- 번호판은 켜지는데 앱이나 연동 기능만 안 되는 경우
- 복도 센서등이 꺼져 번호판을 보기 어려운 경우
- 복구 순간 전압이 흔들려 도어락이 이상한 소리를 내는 경우
- 오래된 제품이 복구 뒤에 설정이 초기화되는 경우
- 공동현관이 안 열려 집 앞까지 갈 수 없는 경우
이런 증상은 대부분 복구 뒤에 정리되지만, 번호가 초기화됐다면 다시 등록해야 할 수 있습니다.

# 어두운 복도에서 하면 안 되는 것
촛불이나 라이터로 불을 밝히는 것은 위험합니다. / 휴대폰 손전등을 쓰는 것이 가장 안전하고 간편합니다.
성냥을 쓰거나 연기가 나는 불을 켜 두고 문을 닫고 나가는 일은 하지 마세요.
어둡다고 번호를 급하게 눌러 여러 번 틀리면 입력이 잠깐 막힐 수 있습니다. / 한 번 숨을 고르고 번호판 위치를 손으로 확인한 뒤 천천히 누르세요.
계단으로 이동할 때는 난간을 잡고 발밑을 비추며 천천히 걸으세요. / 짐이 많으면 한 번에 들지 말고 나눠서 옮기는 편이 안전합니다.
특히 정전 중에는 서두르다 넘어지는 사고가 도어락 고장보다 훨씬 위험합니다. / 문이 안 열려도 몸이 다치지 않는 것이 먼저라는 점을 기억해 주세요.
@ 휴대폰 손전등으로 도어락 번호판 확인하기

# 집 안에 있는데 문이 이상할 때
정전 중에 집 안에 계신다면 문에 이상이 있어도 서두르지 않아도 됩니다. / 안쪽 손잡이를 돌려 열 수 있는지 먼저 확인해 보세요.
안쪽 잠금 장치는 대부분 전기 없이 손으로 열립니다. / 다만 가족이 동시에 나가려다 보조키를 돌려 놓고 놓친 경우가 있어 주의가 필요합니다.
아이나 어르신이 혼자 있다면 문 쪽으로 가는 길을 밝히고 천천히 이동하게 안내해 주세요.

# 집 밖에 있는데 못 들어갈 때
퇴근해 보니 공동현관이 안 열리고 집까지 가지 못하는 상황이 가장 흔합니다. / 관리사무소나 경비실에 도움을 요청하는 것이 가장 빠릅니다.
이웃이 들어갈 때 같이 들어가도 되는지는 단지마다 방침이 다르니 경비실 안내를 따르세요. / 확실하지 않은 상황에서 남의 출입을 따라가는 일은 서로 불편해질 수 있습니다.
집 앞에 도착했는데 도어락이 이상하다면 복구될 때까지 잠시 기다려 보는 것도 방법입니다.

# 오산동에서 출장을 요청할 때 알려주실 것
오산역 쪽에서 오시는지, 동 번호와 호수가 어떻게 되는지 알려 주세요. / 정전 중이라 길이 어두울 수 있으니 입구 위치를 알려 주시면 찾기 쉽습니다.
- 지금 정전이 단지 전체인지 우리 집만인지
- 번호판이 켜지는지, 소리가 나는지
- 평소 어떤 방식으로 열던 도어락인지
- 공동현관을 통과할 수 있는지
- 집 안에 아이나 반려동물이 있는지

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
정전 중에는 관리사무소가 연락이 어려울 수 있어 우편물이나 신분증을 미리 찾아 두시는 편이 좋습니다. / 확인이 어려우면 작업을 할 수 없으니 양해 부탁드립니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 복구된 뒤에 확인할 것
전기가 돌아오면 도어락이 정상으로 잠기고 열리는지 몇 번 확인해 보세요. / 번호가 그대로 남아 있는지, 시간이나 설정이 초기화됐는지도 봅니다.
이상이 있으면 [도어락 수리](doorlock-repair.html)로 점검을 받아 보세요. / 정전과 복구를 여러 번 겪은 오래된 제품이라면 [도어락 교체](doorlock-replace.html)도 천천히 생각해 볼 수 있습니다.
복구 뒤에는 공동현관 비밀번호가 바뀌었는지도 확인하세요.
복구 직후에는 전기가 불안정하게 들어왔다 나갔다 할 수 있어 바로 문을 닫고 나가기보다 잠시 지켜보는 편이 안전합니다. / 도어락에서 평소와 다른 소리가 나면 그날 안에 점검을 받아 두세요.
@ 복구된 뒤 도어락 작동 확인

# 단지 정전에 대비해 집에서 해둘 것
- 건전지식 도어락이면 새 배터리로 바꿔 두고 비상용 9V 건전지를 하나 보관하기
- 열쇠로도 열 수 있는 도어락이면 보조 열쇠를 집 밖에도 한 개 안전하게 두기
- 손전등과 보조 배터리를 현관 가까이에 두기
- 앱으로만 열던 습관이면 번호로 여는 방법을 가족과 함께 확인하기
- 관리사무소 비상 연락처를 휴대폰에 저장해 두기
정전은 갑자기 오기 때문에 평소에 한 번만 정리해 두면 큰 도움이 됩니다.

# 오산동 말고 오산 어디든 갑니다
오산동 가까운 원동, 궐동, 수청동 등 오산 안이면 24시간 출동합니다. / 오산에서 다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 정리해 두었습니다.
다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
