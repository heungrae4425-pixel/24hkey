# 오산동 현관문, 래치가 튀어나온 채 문이 안 닫힌다면
오산동은 오산역 가까이에서 출퇴근과 장보기를 하는 분들이 많은 생활권입니다. / 집에 들어오며 문을 닫는데 딸깍 소리가 나지 않고 문이 뻗대는 느낌이 들면 래치 문제일 수 있습니다.
래치는 문을 닫을 때 튀어나왔다가 문틀 구멍에 들어가 문을 잡아 주는 비스듬한 혀 모양 부품입니다. / 이 부품이 안으로 들어가지 않으면 문이 닫히지도, 열리지도 않는 불편한 상태가 됩니다.
이 글은 래치가 들어가지 않는 증상의 원인과 확인 순서를 정리한 것입니다. / 오산 열쇠집을 부르기 전에 해볼 수 있는 일을 먼저 적었습니다.
@ 오산동 현관문 래치와 문틀 구멍

# 래치가 들어가지 않는다는 것이 어떤 모습인가
문을 닫으려 할 때 래치가 문틀에 걸려 끝까지 안 닫히거나, 닫혔는데 손잡이를 돌려도 래치가 안 들어가 문이 안 열리는 모습입니다. / 두 가지 증상은 원인이 비슷하지만 대처법이 조금 다릅니다.
- 문이 덜 닫히고 래치가 문틀에 걸려 있는 경우
- 문은 닫혔는데 래치가 빠지지 않아 안 열리는 경우
- 래치가 손잡이를 돌려도 반쯤 들어가다 마는 경우
어느 쪽인지에 따라 확인할 곳도 달라집니다.

# 가장 먼저 문틀과 래치의 높이를 보세요
문이 처지면 래치가 문틀 구멍보다 낮은 위치로 가서 걸립니다. / 이렇게 되면 래치가 구멍 안으로 못 들어가고 문틀 가장자리에 부딪혀 문이 안 닫힙니다.
문을 닫아 보고 래치 끝에 긁힌 자국이 있는지 눈으로 확인해 보세요. / 문틀 쪽 구멍 주변에 반짝이는 긁힌 흔적이 있다면 위치가 어긋났다는 신호입니다.
경첩 나사를 살짝 조여 문 처짐을 바로잡으면 해결되는 경우도 많습니다. / 너무 세게 조이면 나사 구멍이 닳을 수 있으니 주의하세요.

# 래치가 걸려 있을 때 손잡이를 쓰는 요령
래치가 문틀에 걸려 안 열릴 때는 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 문이 밀리면서 래치에 걸리던 힘이 풀려 들어가기도 합니다.
반대로 문을 당기면서 손잡이를 돌리면 래치가 더 꽉 물립니다. / 힘의 방향이 중요합니다.
손잡이를 위로 들어 올리듯 돌려 보는 방법도 있습니다. / 처진 문일 때 이 요령이 통하는 경우가 있습니다.
@ 문을 안쪽으로 살짝 밀면서 손잡이 돌리기

# 래치 안쪽이 끈적이거나 이물질이 낀 경우
래치는 안쪽에 스프링이 있어 눌렸다가 튀어나오는 구조입니다. / 먼지, 기름때, 페인트가 끼면 스프링이 제대로 움직이지 못합니다.
이사하거나 도배, 페인트를 한 뒤에 갑자기 증상이 나타났다면 이런 이유일 수 있습니다. / 이때는 래치 끝이 굳은 이물질에 막혔는지 살펴보세요.
- 래치 끝이 끈적하거나 뻑뻑한지
- 손가락으로 눌렀을 때 부드럽게 들어가는지
- 눌렀다 놓았을 때 원래 자리로 튀어나오는지
부드럽게 안 움직이면 소량의 윤활제로 닦아 주면 좋아지기도 합니다. / 윤활제를 너무 많이 쓰면 오히려 먼지가 붙으니 아주 조금만 쓰세요.

# 도어락 안쪽 연결 부품이 문제일 수 있습니다
손잡이를 돌려도 래치가 안 움직인다면 손잡이와 래치를 잇는 내부 부품이 문제일 수 있습니다. / 이 부품이 헐거워지거나 부러지면 손잡이는 돌아가지만 래치는 그대로입니다.
이런 증상은 손잡이가 헐겁거나 헛도는 느낌과 함께 나타나는 경우가 많습니다. / 손잡이가 평소보다 가볍게 돌아가는지 느껴 보세요.
이 단계는 분해가 필요한 경우가 많아 혼자 해결하려 하지 않는 편이 안전합니다. / 억지로 분해하다가 부품이 더 상할 수 있습니다.

# 하지 말아야 할 것
- 문을 발로 차거나 어깨로 밀어 열려는 것
- 카드나 얇은 도구로 문틈의 래치를 밀어 보는 것
- 손잡이를 세게 돌리거나 당기는 것
- 윤활제를 래치 안쪽에 과하게 뿌리는 것
급한 마음에 이런 행동을 하면 래치가 휘거나 문틀이 상할 수 있습니다. / 문이 열려 있는 상태에서 닫히지 않는 경우에는 문을 억지로 쾅 닫는 것도 피하세요.

# 문이 안 닫힌 채 외출해야 한다면
래치가 안 들어가 문이 닫히지 않는 상황에서 외출해야 한다면 마음이 불안합니다. / 이럴 때는 문을 최대한 닫고, 임시로 잠글 방법이 있는지 확인하세요.
보조키나 데드볼트가 따로 있는 문이라면 그쪽으로 잠글 수 있는지 시험해 보세요. / 이때도 열쇠가 안에 있는지, 나갔다 들어올 수 있는지 먼저 확인하세요.
정말 불안하다면 이 상태로 두지 말고 전화 상담을 받는 편이 낫습니다. / 사진이나 증상 설명만으로도 임시 대처법을 안내해 드릴 수 있습니다.

# 전화하기 전 준비할 것
전화할 때 아래 정보를 알려 주시면 도착한 뒤 작업이 빨라집니다.
- 문이 덜 닫히는지, 닫혔는데 안 열리는지
- 래치가 보이는 모습(튀어나온 채인지, 반쯤 들어갔는지)
- 문 안쪽에 아이나 반려동물이 있는지
- 도어락 모양(손잡이형, 버튼형 등)
래치와 문틀이 보이게 사진 한 장을 보내 주시면 좋습니다. / 안쪽에 사람이 있으면 꼭 먼저 말씀해 주세요.
@ 래치와 문틀 구멍이 보이게 찍은 사진

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다. / 문을 여는 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 열린 뒤에 점검하고 고칠 것
문이 열린 뒤에는 래치가 문틀 구멍에 부드럽게 들어가는지 같이 확인합니다. / 필요하면 문틀 쪽 받침판 위치를 살짝 조정하기도 합니다.
부품이 닳았으면 래치나 안쪽 연결 부품만 바꾸는 방법도 있습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
자세한 내용은 [도어락 수리](doorlock-repair.html), 오래된 제품은 [도어락 교체](doorlock-replace.html) 페이지를 참고하세요.

재발을 줄이려면 생활 속 점검이 도움이 됩니다.
- 문을 닫을 때 래치가 걸리는 소리를 들어 보기
- 경첩 나사가 풀리지 않았는지 가끔 확인하기
- 문틀 구멍 주변 먼지와 페인트를 닦아 두기
- 래치 끝이 뻑뻑해지면 미루지 말고 점검받기
작은 소리 차이도 미리 알아차리면 큰 고장이 되기 전에 손볼 수 있습니다.

# 오산동 말고 오산 어디든 갑니다
오산동 바로 옆 원동, 궐동, 대원동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
오산 출장 동네는 [오산시 출장열쇠](osan.html) 페이지에, 다른 지역은 [출장 지역](area.html) 지도에 정리해 두었습니다.
