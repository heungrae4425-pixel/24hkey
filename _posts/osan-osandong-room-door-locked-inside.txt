# 안에서 잠긴 문 앞에서 제일 먼저 할 일
오산동 주택과 빌라에서 의외로 자주 받는 연락이 방문이나 화장실 문이 안에서 잠겨 안 열린다는 내용입니다. / 현관문이 아니라 집 안의 문이라 별일 아니라고 생각하기 쉽지만, 안에 누가 있는지에 따라 급한 정도가 크게 달라집니다.
가장 먼저 할 일은 문을 두드리고 안에 있는 사람에게 말을 거는 것입니다. / 대답이 있는지, 목소리가 괜찮은지부터 확인해 주세요.
이 글은 방문과 화장실 문이 안에서 잠겼을 때 순서대로 해 볼 일을 정리했습니다. / 대답이 없거나 몸이 불편한 분이 안에 있다면 바로 119에 연락하시고, 문 여는 일은 그다음입니다.
@ 오산동 방문 화장실 문 안에서 잠김 개문 출장열쇠

# 안에 있는 사람이 괜찮은지부터 확인하세요
문 너머로 이름을 부르고 괜찮은지 물어보세요. / 대답이 있다면 안에서 직접 풀 수 있는지 방법을 알려 줄 수 있습니다.
대답이 없거나 쓰러지는 소리가 났다면 지체하지 마세요. / 이 경우는 문 여는 시간보다 응급 연락이 먼저입니다.
어린 아이가 안에 있다면 놀라서 울 수 있으니 목소리를 낮추고 천천히 말해 주세요. / 아이가 손잡이를 어떻게 하고 있는지 물어봐 주시면 전화로 안내하기 쉽습니다.
어르신이 안에 계시다면 서두르지 말라고 먼저 안심시켜 드리세요. / 문이 안 열려 당황하는 순간에 괜히 힘을 쓰다가 다치시는 일을 막아야 합니다.

# 방문 손잡이 잠금은 이렇게 생겼습니다
방문 잠금은 손잡이 가운데 버튼을 누르거나 돌려서 잠그는 형이 가장 흔합니다. / 화장실 문은 같은 원리에 바깥쪽이 간단하게 풀리게 만들어진 경우도 있습니다.
바깥쪽 손잡이 가운데에 작은 구멍이나 홈이 보이면 그 문은 비상 개방이 되는 문일 수 있습니다. / 가는 막대나 전용 도구로 열 수 있는 종류가 있어서 먼저 확인해 볼 만합니다.
다만 어떤 도구든 구멍에 억지로 넣으면 안쪽 부품이 상할 수 있습니다. / 한두 번 해 보고 안 되면 더 시도하지 말고 전화 주시는 것이 낫습니다.
@ 오산동 방문 손잡이 비상 개방 구멍 확인

# 문을 밀거나 발로 차지 마세요
급한 마음에 문을 몸으로 밀거나 발로 차는 분이 있습니다. / 문틀이 부서지고 문짝이 휘어 수리할 일이 훨씬 커집니다.
특히 안에 사람이 있다면 문이 갑자기 열리면서 다칠 수도 있습니다. / 안에 있는 사람도 문 가까이에서 떨어져 있도록 말해 주세요.
카드나 칼날 같은 도구를 문틈에 넣어 밀어 보는 방법은 잠금 부위만 상하게 하는 경우가 많습니다. / 방문 틈이 좁으면 도구가 부러져 틈에 박히기도 합니다.

# 안에서 직접 풀 수 있는 경우도 많습니다
안에 있는 사람이 손잡이 버튼을 다시 돌리거나 눌러 보도록 안내해 보세요. / 잠금 버튼이 눌린 채 걸려 있는 문은 반대 방향으로 살짝 돌리면 풀리기도 합니다.
손잡이를 당기면서 돌리거나 문을 안쪽으로 살짝 밀면서 돌려 보라고 해 보세요. / 문이 틀에 걸려 있으면 그렇게 하면 잠금이 풀리는 경우가 있습니다.
이렇게 해도 안 되면 안에서 손잡이가 헛돌고 있는지, 아예 움직이지 않는지만 알려 주세요. / 이 정보만으로도 어떤 부품이 문제인지 어느 정도 가늠할 수 있습니다.

# 화장실 문은 이런 점이 다릅니다
화장실 문은 습기 때문에 잠금 부위가 녹슬거나 뻑뻑해져서 안 풀리는 경우가 많습니다. / 오래 쓴 문일수록 안쪽 잠금 버튼이 걸려 돌아오지 않는 일이 생깁니다.
바깥쪽에 비상 개방 홈이 있는 문이 많지만, 홈이 막혀 있거나 도구가 없어서 못 여는 경우도 흔합니다. / 이럴 때는 억지로 열기보다 전화를 주세요.
문이 완전히 닫혀 있고 습기가 많다면 문짝이 부풀어 틀에 끼었을 수도 있습니다. / 이 경우는 잠금과 상관없이 문 상태를 같이 봐야 합니다.

# 전화하기 전에 알려 주실 내용
몇 층 몇 호인지와 어느 방 문인지, 안에 누가 있는지를 먼저 알려 주세요. / 안에 아이나 어르신, 반려동물이 있다면 꼭 먼저 말씀해 주세요.
문 손잡이 모양과 바깥쪽에 구멍이나 홈이 있는지 사진을 보내 주시면 준비하기 쉽습니다. / 안에서 어떻게 잠갔는지 아는 만큼 알려 주시면 도움이 됩니다.
급한 상황인지 아닌지도 함께 알려 주세요. / 응급이라면 119가 먼저라는 점을 다시 한번 말씀드립니다.
@ 오산동 출장열쇠 문 상태 사진 안내

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
집 안의 문이라도 같은 절차를 거치는 이유는 어느 집 문이든 사시는 분 요청이 있어야 하기 때문입니다. / 번거로우시겠지만 이웃과 집을 지키는 절차입니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요. / 신분증이 방 안에 있다면 다른 방법을 전화로 안내해 드립니다.

# 최대한 문이 상하지 않게 엽니다
방문이나 화장실 문은 현관문보다 얇고 약해서 더 조심해서 엽니다. / 덜 상하는 방법부터 차례로 해 보고, 마지막에야 부품을 건드립니다.
문틀이나 문 표면에 흠이 생기지 않도록 보호하면서 작업합니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.
여는 방법과 순서는 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다. / 방문도 원리는 비슷하지만 도구와 방식은 문 종류에 맞춰 달라집니다.

# 비용은 문을 열기 전에 말씀드립니다
문 종류와 잠금 상태를 보고 비용을 먼저 안내해 드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 연 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭙니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 열고 난 뒤에 같이 해 두는 점검
문이 열리면 잠금 버튼이 제대로 눌리고 풀리는지 같이 확인합니다. / 다시 안에서 갇히는 일이 없도록 바깥에서도 열리는지 봅니다.
고장 난 잠금 부품은 [도어락 수리](doorlock-repair.html)로 손볼지, 통째로 바꿀지 상태를 보고 말씀드립니다. / 오래된 문은 바꾸는 편이 마음 편한 경우도 있습니다.
아이가 있는 집이라면 안쪽 잠금을 아이 손이 닿지 않는 높이로 바꾸는 방법도 이야기해 드립니다. / 작은 변화로도 같은 일이 다시 생길 가능성을 줄일 수 있습니다.

# 오산 안에서는 동네 가리지 않고 갑니다
오산동뿐 아니라 원동, 궐동, 세교동, 신장동까지 오산 전 지역과 오산역, 오산대역, 세마역 쪽도 24시간 출동합니다. / 위치를 알려 주시면 예상 도착 시간을 먼저 말씀드립니다.
오산 지역 정보는 [오산시 출장열쇠](osan.html)에 있고, 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 새 문고리나 잠금을 달고 싶다면 [도어락 설치](doorlock-install.html)도 참고해 주세요.
