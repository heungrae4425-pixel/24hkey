# 오산동 도어락이 혼자 삑삑거린다면
오산역 가까운 오산동에서 밤에 문 쪽에서 삑삑 소리가 나서 놀랐다는 이야기를 종종 듣습니다. / 아무도 누르지 않았는데 번호판이 켜지거나 소리가 나는 증상입니다.
처음에는 고장인지 장난인지 헷갈리지만 대부분 원인이 있습니다. / 이 글은 오산동에서 터치 패널이 혼자 눌리는 것처럼 보일 때 확인할 것을 순서대로 정리했습니다.
여러 증상이 섞인 경우에는 [도어락 수리](doorlock-repair.html) 페이지에서 비슷한 사례도 보실 수 있습니다.
@ 오산동 현관 도어락 터치 번호판

# 터치 패널은 어떻게 눌림을 알아채나
터치식 번호판은 버튼을 누르는 힘이 아니라 손가락이 닿을 때 생기는 전기 변화를 읽습니다. / 그래서 습기, 먼지, 물방울처럼 전기가 통하는 것이 닿아도 눌림으로 오해할 수 있습니다.
센서는 매우 민감하게 만들어져 있어 환경 변화에 쉽게 반응합니다.
특히 겨울에 바깥과 실내 온도 차가 크면 번호판 안쪽에 이슬이 맺히기도 합니다. / 눈에는 보이지 않아도 센서는 그 물기를 손가락처럼 읽을 수 있습니다.
같은 현상이 아침 시간에만 반복된다면 이슬이나 습기 때문일 가능성이 높습니다. / 낮에는 멀쩡하다가 새벽에 울린다면 더욱 그렇습니다. / 도어락이 불량인 것이 아니라 주변 조건이 영향을 주는 경우가 많습니다.

# 혼자 눌리는 증상의 대표 모습
아래 중 해당하는 것이 있는지 보세요. / 해당 항목에 따라 원인이 달라집니다.
- 밤이나 새벽에 갑자기 번호판이 켜지는 경우
- 아무도 없을 때 삑 소리가 한두 번 나는 경우
- 비 오는 날이나 아침에 더 자주 생기는 경우
- 특정 숫자만 반복해서 눌린 듯 소리가 나는 경우
- 번호를 누르다 보면 입력 오류 경고가 자주 나는 경우
어느 때 더 심한지 메모해 두면 원인을 좁히는 데 도움이 됩니다.

# 가장 먼저 의심할 것은 물기와 먼지
번호판 표면이나 틈에 물기가 남아 있으면 센서가 눌렸다고 느낍니다. / 비 오는 날 현관 밖에 습기가 차는 집일수록 자주 나타납니다.
먼지가 습기를 머금어 막처럼 붙어 있는 경우도 있습니다. / 마른 부드러운 천으로 번호판을 닦은 뒤 잠시 지켜보세요.
물걸레나 세정제를 뿌려 닦는 것은 피해 주세요. / 액체가 틈으로 들어가면 오히려 증상이 나빠집니다.

# 배터리가 약해도 비슷한 증상이 납니다
배터리 전압이 떨어지면 센서가 불안정해져 엉뚱한 신호를 읽기도 합니다. / 이 경우 오작동과 함께 경고음이 나거나 잠금이 느려지는 증상이 같이 옵니다.
교체를 한 지 오래됐다면 건전지를 전부 새것으로 바꿔 보는 것이 좋습니다. / 일부만 바꾸면 전압이 맞지 않아 증상이 이어질 수 있습니다.
경고음의 의미는 [도어락 오작동](doorlock-repair.html) 자료를 참고하셔도 됩니다.

# 문과 가까운 곳의 전기 환경
번호판 가까이에 전자기기나 충전기가 있어 영향을 주는 경우도 드뭅니다. / 현관 센서등이나 인터폰 배선과 가까운 집에서 가끔 나타납니다.
최근에 현관 쪽에 새로 단 전기 기기가 있는지 떠올려 보세요. / 시기가 겹치면 원인을 찾는 데 큰 단서가 됩니다.
@ 번호판 주변 습기와 먼지를 마른 천으로 닦아내는 점검

# 해보면 안 되는 일
번호판을 뜯어 속을 확인하려는 분들이 계십니다. / 내부 배선이 끊기거나 방수 처리가 망가질 수 있어 전화 먼저 주시기를 권합니다.
스프레이나 접점부활제를 임의로 뿌리는 것도 피하세요. / 잘못 쓰면 오히려 부식이 생깁니다.
오작동이 계속된다고 배터리를 빼 두고 지내는 것은 더 위험합니다. / 문이 안 잠기거나 비상시 열리지 않을 수 있습니다.

# 오작동이 심해 문이 안 열릴 때
혼자 눌리다가 입력 횟수가 넘어가면 도어락이 한동안 입력을 막는 경우가 있습니다. / 이때는 번호가 맞아도 열리지 않아 당황하게 됩니다.
잠시 기다렸다가 다시 눌러 보고, 그래도 안 되면 전화 주세요. / 이런 상황은 [현관문 개문](door-open.html)이 필요할 수도 있습니다.
가족 중 아이가 번호판을 장난으로 만져 생기는 일도 있어, 그런 가능성도 한 번 물어보세요. / 그런 경우는 설정에서 소리나 터치 감도를 조정하는 것으로 정리되기도 합니다.
가능하면 상황을 사진이나 영상으로 남겨 두세요. / 무엇이 반복되는지 보면 원인 파악이 빨라집니다.

문 앞에서 열어야 하는 상황이면 사시는 분인지 확인합니다. / 신분증 주소, 주소가 있는 우편물, 관리사무소 확인 중 하나면 됩니다.
점검만 하는 경우에도 도어락 설정을 만지므로 소유자 확인은 필요합니다. / 세입자라면 임대인에게 알리는 것이 좋을 때도 있습니다.

# 비용은 먼저 말씀드립니다
점검한 뒤 어떤 작업이 필요한지 말씀드리고, 비용은 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작합니다.
문을 못 열면 비용은 받지 않습니다. / 부품 교체가 필요한 경우에도 교체 전에 따로 여쭙습니다.
이용 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 수리와 교체, 어떻게 가르나
센서가 한두 번 오작동했다고 바로 교체하지는 않습니다. / 청소와 배터리 교체, 설정 확인만으로 가라앉는 경우가 많습니다.
같은 증상이 반복되고 번호판 일부 구역이 눌리지 않는다면 부품 수명을 의심합니다. / 이 경우 수리가 가능한지 먼저 보고, 어려우면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 밤에 울릴 때 가족이 놀라지 않으려면
새벽에 갑자기 소리가 나면 누가 문을 건드린다고 오해하기 쉽습니다. / 먼저 문구멍이나 인터폰으로 밖을 확인하고, 아무도 없다면 도어락 쪽 문제로 보시면 됩니다.
불안하시면 안쪽 보조키를 걸어 두고 아침에 확인하세요. / 소리가 나는 시간을 적어 두면 습기나 온도 때문인지 가늠하기 쉽습니다.
과장해서 걱정하실 일은 아니지만 같은 현상이 계속되면 방치하지 않는 것이 좋습니다. / 원인이 단순할 때 손보는 것이 가장 수월합니다.

# 오작동을 줄이는 관리 습관
번호판은 일주일에 한 번 마른 천으로 가볍게 닦아 주세요. / 겨울과 장마철에는 물기가 남지 않았는지 더 자주 봅니다.
- 현관 바닥 물걸레질 때 번호판에 물 튀기지 않기
- 배터리는 해가 바뀔 때 한 번에 교체
- 경고음이 나면 그날 확인하기
- 이상 증상이 생긴 날과 상황 메모하기
@ 번호판 표면을 가볍게 닦는 평소 관리

# 오산동 말고 오산 어디든 갑니다
오산동 가까운 원동, 궐동, 신장동, 대원동도 다닙니다. / 오산 안이면 어디든 24시간 출동합니다.
오산 전체 안내는 [오산시 출장열쇠](osan.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
