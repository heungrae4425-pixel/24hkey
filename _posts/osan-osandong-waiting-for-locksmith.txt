# 전화를 끊고 나면 오히려 길게 느껴집니다
기다리는 시간을 그냥 흘려보내지 않고 쓰면 도착 후 작업이 훨씬 매끄럽습니다. / 아래 순서대로 하나씩 해 보세요.
오산동에서 문이 안 열려 출장열쇠에 전화하고 나면 기다리는 시간이 의외로 깁니다. / 오산역 근처 길에서 서성이거나 현관 앞 계단에 앉아 있으면 불안해지기 쉽습니다.
이 글은 [오산 출장열쇠](osan.html)가 도착하기까지 문 앞에서 해두면 좋은 일을 순서대로 적었습니다. / 해두시면 도착 후 진행이 훨씬 빨라집니다.
@ 오산동 출장열쇠 도착 대기 문 앞 준비

# 먼저 안전한 자리부터 잡으세요
계단이 있는 건물이라면 난간 근처 말고 벽 쪽에 서 계시면 오가는 사람과 부딪히지 않습니다.
문 앞이 복도라면 이웃 통행에 방해가 되지 않는 쪽으로 서 계세요. / 늦은 시간이라면 계단참보다 밝은 곳이 낫습니다.
짐이 많다면 바닥에 내려놓고 쉬셔도 됩니다. / 급하게 서둘러야 할 일은 이미 전화로 끝났습니다.
오산동 길에서 비가 오거나 추우면 건물 입구 안쪽에서 기다리세요. / 공동 현관이 잠겨 있다면 경비실이나 관리사무소에 사정을 말해 두는 것도 방법입니다.

# 문을 더 건드리지 않는 것이 첫째
전화로 증상을 설명한 이후에 문 상태가 바뀌면 출장 기사가 처음 상태를 알기 어렵습니다. / 처음 그대로의 상태가 가장 좋은 단서입니다.
기다리는 동안 손잡이를 이리저리 돌려 보고 싶어집니다. / 하지만 반복해서 힘을 주면 걸쇠가 더 물리거나 도어락이 입력을 한동안 막을 수 있습니다.
비밀번호를 계속 눌러 보는 것도 마찬가지입니다. / 서너 번 해봤다면 거기서 멈추고 기다려 주세요.
문틈에 카드나 드라이버를 넣는 분도 있는데 문틀과 외관이 상할 수 있습니다. / 그냥 두는 것이 가장 안전합니다.

# 신분 확인 서류를 챙겨 두세요
서류를 휴대폰 사진으로 보관해 두는 분도 있는데, 현장에서는 주소가 확인되는 실물이 가장 확실합니다. / 가능하면 실물로 준비해 주세요.
도착하면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 휴대폰으로 받은 고지서나 택배 송장 주소도 도움이 됩니다. / 안 되면 관리사무소에서 세대 확인을 받아 두면 수월합니다.
번거로우셔도 이웃과 집 안의 소중한 물건을 지키는 절차입니다. / 확인이 안 되면 작업할 수 없으니 이 부분은 미리 챙겨 주세요.
@ 오산동 신분 확인 우편물 관리사무소

# 알려드릴 위치 정보 정리
길 안내를 받을 때는 지도 앱의 도착지 이름이 건물 정문과 다를 때가 있습니다. / 그럴 때는 눈에 보이는 큰 표지나 가게 이름을 같이 말씀해 주세요.
도착이 빨라지려면 위치가 정확해야 합니다. / 아래 항목을 휴대폰 메모에 적어 두면 전화나 문자로 답하기 편합니다.
- 건물 이름과 동·호수, 출입구 위치
- 오산역, 오산대역 등 가까운 역 방향
- 공동 현관 비밀번호가 필요한지 여부
- 주차나 출입 시간 제한이 있는지
- 문 앞 사진 한 장
도착해서 건물을 못 찾는 일이 생기면 시간이 허비됩니다. / 입구에 서서 손을 흔들어 주셔도 좋습니다.

# 기다리며 휴대폰으로 해볼 수 있는 일
휴대폰 배터리가 부족하다면 절전 모드로 바꿔 통화 가능 시간을 아껴 두세요. / 연락이 끊기면 서로 길게 헤맬 수 있습니다.
도어락 번호판과 열쇠 구멍을 사진으로 찍어 두세요. / 도착 전에 보내 주시면 장비를 맞춰 가져갈 수 있습니다.
번호판에 불이 들어오는지, 소리가 나는지 한 번만 더 확인해 메모해 두세요. / 변화가 있으면 알려 주시면 됩니다.
가족이 비밀번호를 바꾸었을 수 있으니 한 번 연락해 보는 것도 방법입니다. / 번호를 알아내면 출장 없이 해결될 수도 있습니다.

# 집 안에 사람이나 반려동물이 있다면
반려동물이 문 앞에서 짖거나 긁는 소리가 나면 놀라지 않도록 조용히 말을 걸어 주세요. / 문이 열릴 때 튀어나오지 않도록 미리 안아 줄 준비도 해 두시면 좋습니다.
아이나 반려동물이 안에 있을 때는 꼭 먼저 말씀해 주세요. / 우선순위가 달라져 빨리 오실 수 있도록 조정합니다.
아이가 놀라지 않게 문 너머로 계속 말을 걸어 주세요. / "곧 열어 줄 거야, 문 근처에서 떨어져 있어" 정도면 충분합니다.
가스 불이나 전열기구를 켜 둔 경우도 반드시 알려 주세요. / 이 경우는 일정을 최대한 앞당깁니다.

# 이웃에게 도움을 청하는 법
관리하는 분이 상주한다면 상황을 알려 두면 공동 현관을 열어 주는 등 도움을 받을 수 있습니다.
전화기가 집 안에 있다면 이웃에게 잠깐 빌려 연락해도 됩니다. / 이웃이 불편해하지 않도록 짧게 용건만 말씀드리세요.
옆집에 사정을 알려 두면 인기척에 놀라지 않습니다. / 작업 중 소리가 날 수 있다는 점도 함께 이야기해 두면 좋습니다.

# 도착한 뒤에는 이렇게 진행됩니다
궁금한 점은 그때그때 물어보셔도 됩니다.
도착 시간은 거리와 교통에 따라 달라서 전화 중에 예상 시간을 먼저 말씀드립니다. / 늦어질 것 같으면 중간에 다시 연락드려 상황을 알립니다.
기사가 도착하면 먼저 신분을 확인하고 문 상태를 봅니다. / 비용은 문 열기 전에 먼저 말씀드립니다.
괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하면 바꾸기 전에 여쭙습니다. 자세한 순서는 [이용안내](guide.html)에 있습니다.
@ 오산동 현관문 개방 진행 과정

# 작업 중에는 지켜보셔도 됩니다
작업하는 동안 궁금한 점은 언제든 물어보세요. / 무엇을 하는지 설명드리는 것이 원칙입니다.
문을 열기 위한 작업은 덜 상하는 방법부터 차례로 합니다. / 어떤 방식으로 하는지 궁금하시면 물어보셔도 됩니다.
[현관문 개문](door-open.html) 페이지에 방법을 설명해 두었습니다. / 열쇠 자체가 문제라면 [열쇠 출장](key-call.html) 안내도 참고하세요.

# 문이 열린 직후에 할 일
열린 직후에는 집 안에 들어가기 전에 가스나 전열기구 상태부터 눈으로 확인하세요. / 오래 기다렸다면 피곤해서 놓치기 쉬운 부분입니다.
문이 열리면 바로 들어가지 말고 도어락이 다시 잠기고 열리는지 확인합니다. / 배터리 문제였다면 새것으로 교체하고, 비밀번호 문제였다면 새 번호를 등록합니다.
고장이 반복되면 [도어락 수리](doorlock-repair.html)를 먼저 권하고, 너무 낡았을 때만 교체를 말씀드립니다. / 원인을 알아야 다음에 같은 일이 안 생깁니다.

# 오산동 말고 오산 어디든 갑니다
원동, 궐동, 세교동, 신장동, 대원동, 남촌동, 초평동, 수청동, 갈곶동도 다닙니다. / 세마역 쪽도 24시간 전화를 받습니다.
다니는 동네는 [오산시 출장열쇠](osan.html)에 있고, 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 마무리
오산역 방면이든 다른 골목이든 기다림은 누구에게나 길게 느껴집니다. / 그래서 연락을 끊지 않고 중간에 소식을 전하겠습니다.
기다리는 동안에는 문을 더 건드리지 않고, 위치와 신분 확인만 챙겨 주시면 됩니다. / 그 이상은 저희가 해결하겠습니다.
