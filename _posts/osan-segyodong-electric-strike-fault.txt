# 세교동에서 전기 걸쇠 문이 갑자기 안 풀릴 때
오산 세교동에서 세마역이나 오산대역 쪽으로 오가는 분들 중에는 상가나 사무실, 공동 출입구의 전기 걸쇠 문을 쓰는 경우가 있습니다. / 평소엔 버튼이나 카드로 잘 열리던 문이 어느 날 딸깍 소리만 내고 안 풀리면 업무도 막힙니다.
전기 걸쇠, 흔히 전기정이라 부르는 장치는 전기가 들어올 때 걸쇠를 풀어주는 구조입니다. / 그래서 전기, 문 눌림, 걸쇠 부품 세 가지가 주요 원인입니다.
이 글은 안 풀릴 때 확인 순서와 하지 말아야 할 것을 정리했습니다. / 끝내 안 열리면 [오산시 출장열쇠](osan.html)로 연락 주세요.
@ 세교동 전기 걸쇠 출입문 외관

# 전기 걸쇠가 어떻게 문을 잡고 푸는지
문틀 쪽에 달린 전기 걸쇠는 평소 문의 래치를 잡고 있다가 신호가 오면 걸림 부분을 열어줍니다. / 신호는 출입 버튼, 카드 리더, 인터폰 등에서 옵니다.
전기를 주는 방식에 따라 전원이 들어올 때 열리는 것과 전원이 끊길 때 열리는 것이 있습니다. / 어느 방식인지에 따라 정전 때 문이 열릴지 잠길지가 달라집니다.
우리 문이 어느 쪽인지 모르면 설치한 곳이나 관리처에 한 번 확인해 두는 것이 좋습니다. / 정전 상황 대비에도 필요한 정보입니다.

# 소리가 나는지로 원인 가르기
버튼을 눌렀을 때 문틀에서 딸깍 하는 소리가 나는지가 첫 단서입니다. / 소리가 나면 전기는 오고 있다는 뜻이고, 소리가 없으면 전기가 오지 않는다는 뜻입니다.
- 딸깍 소리가 나는데 문이 안 풀리면 문 눌림이나 걸쇠 부품 문제
- 소리 자체가 없으면 전원, 버튼, 배선, 전원장치 문제
- 가끔만 되고 가끔 안 되면 접촉 불량이나 노후 부품
이 구분만 해도 전화로 상황을 설명하기가 훨씬 쉬워집니다.

# 문이 눌려서 걸쇠가 못 빠지는 경우
딸깍 소리가 나는데도 문이 안 열리면 문이 문틀 쪽으로 눌려 있는지 의심해 보세요. / 래치가 걸쇠에 압력을 받고 있으면 걸림이 풀려도 빠지지 않습니다.
버튼을 누르는 동시에 문을 안쪽으로 살짝 밀었다가 당겨 보면 풀리는 경우가 있습니다. / 힘을 줘서 흔드는 것이 아니라 압력을 잠깐 빼 주는 개념입니다.
문이 처졌거나 문틀이 어긋난 곳은 이 증상이 반복됩니다. / 그럴 땐 걸쇠보다 경첩과 문틀을 먼저 봐야 합니다.

# 소리가 안 날 때 전기 쪽 확인
소리가 전혀 없다면 우선 건물 전체 정전이나 차단기 문제가 아닌지 봅니다. / 같은 층의 다른 전기 기기가 정상이면 해당 문 회로만 문제라는 뜻입니다.
출입 버튼을 여러 번 눌러도 반응이 없을 때는 버튼 자체의 고장도 의심합니다. / 안쪽 버튼과 카드 리더가 따로 있다면 둘 다 안 되는지 비교해 보세요.
전원장치를 열어 보는 것은 감전 위험이 있어 권하지 않습니다. / 확인이 어려우면 손대지 말고 연락 주세요.
@ 세교동 출입문 전원장치와 배선 점검

# 걸쇠 안에 이물질이 낀 경우
오래 쓰다 보면 먼지, 이물질, 도장 찌꺼기가 걸쇠 안쪽에 쌓여 움직임이 둔해집니다. / 겨울철에는 그리스가 굳어 반응이 느려지기도 합니다.
문틀 걸쇠 구멍에 종이나 클립 같은 이물질이 들어간 경우도 가끔 있습니다. / 눈에 보이더라도 날카로운 도구로 후비지는 마세요. 안쪽 부품이 상할 수 있습니다.
청소나 윤활 정도로 해결되는지는 상태를 직접 봐야 압니다. / 불필요한 교체는 권하지 않고 고칠 수 있으면 고치는 쪽으로 봅니다.

# 하지 말아야 할 것
세교동처럼 상가와 주거가 섞인 곳은 같은 건물 안에서 여러 업체가 문 하나를 함께 쓰는 일이 있습니다. / 이럴 때는 관리하는 쪽에 먼저 알려야 나중에 서로 오해가 생기지 않습니다.
급하다고 문을 발로 차거나 지렛대로 밀지 마세요. / 문틀과 걸쇠가 함께 변형돼 수리 범위가 훨씬 커집니다.
걸쇠 단자에 선을 임의로 연결해 전기를 직접 주는 시도도 금물입니다. / 합선이나 감전, 화재의 위험이 있습니다.
카드나 얇은 판을 문틈에 넣어 래치를 밀어내는 방법도 문 상태에 따라 효과가 없고 문이 상할 수 있습니다. / 무리한 시도는 일을 키웁니다.

# 상가·사무실에서 안에 사람이 갇힌 경우
출입문이 안 풀릴 때 안쪽에서 나올 수 있는지가 가장 중요합니다. / 안쪽 비상 열림 수단이 있다면 먼저 그것을 사용해 주세요.
사람이 안에 있고 급박하다면 지체하지 말고 상황을 먼저 말씀해 주세요. / 아이나 몸이 불편한 분이 있다면 반드시 알려주셔야 합니다.
평소 영업 시간 전에 한 번 출입문을 시험해 보는 습관이 도움이 됩니다. / 작은 이상 신호를 미리 잡을 수 있습니다.

# 신분과 권한 확인 후에 진행합니다
문을 여는 일이라 사용하시는 분이 맞는지 먼저 확인합니다. / 거주지라면 신분증 주소, 우편물, 관리사무소 확인으로 충분합니다.
상가나 사무실이면 임대 계약서나 사업장 서류, 관리처 확인 등으로 확인합니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.
번거롭더라도 이웃과 건물 모두를 위한 절차입니다. / 자세한 진행은 [이용안내](guide.html)에 있습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 손대기 전에 따로 여쭙습니다.
출장 요청 방법은 [출장열쇠 부르는 법](key-call.html)에서 미리 보실 수 있습니다. / 전화로 증상만 말씀해 주셔도 됩니다.
@ 세교동 출장열쇠 개문 작업 모습

# 열고 난 뒤 부품과 문 상태 같이 점검
문이 열리면 걸쇠가 정상 작동하는지 시험해 봅니다. / 소리, 풀리는 타이밍, 문 닫힘까지 함께 확인합니다.
원인이 문 처짐이라면 걸쇠만 고쳐도 같은 일이 반복됩니다. / 이 경우 경첩과 문틀 상태를 같이 말씀드립니다.
도어락이 함께 달려 있는 문이라면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html) 여부도 상태에 따라 안내합니다.

# 세교동 전기 걸쇠 문 오래 쓰는 법
전기 장치는 자주 쓰는 만큼 소모가 빠릅니다. / 평소 관리가 수명을 크게 좌우합니다.
- 문을 세게 닫지 않기
- 걸쇠 구멍 주변 먼지 가끔 닦기
- 버튼이나 리더 반응이 느려지면 미루지 않고 점검하기
- 정전 시 문이 열릴지 잠길지 미리 알아두기
세마역이나 오산대역 근처 상가처럼 출입이 잦은 곳일수록 점검 주기를 짧게 가져가는 것이 좋습니다.

# 세교동 말고 오산 어디든 갑니다
세교동 옆 오산동, 원동, 궐동, 신장동, 대원동, 남촌동, 초평동, 수청동, 갈곶동도 다닙니다. / 오산 안이면 24시간 연락받습니다.
다니는 곳은 [출장 지역](area.html)에서 확인하실 수 있습니다.
