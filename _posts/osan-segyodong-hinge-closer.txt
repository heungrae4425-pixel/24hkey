# 문이 덜 닫히면 도어락은 멀쩡해도 잠기지 않습니다
세교동은 오산역과 가까운 신도시 생활권이라 출퇴근으로 문을 자주 여닫는 집이 많습니다. / 문을 닫았는데 걸쇠가 물리지 않아 잠기지 않는다면 도어락이 아니라 문의 문제일 수 있습니다.
번호판은 멀쩡하게 켜지는데 문이 살짝 열려 있거나 철컥 소리 없이 닫힌다면 경첩과 도어클로저를 의심해 보세요. / 이 두 부품이 문의 위치와 닫히는 속도를 잡아 줍니다.
이 글은 집에서 직접 살펴볼 수 있는 것과 점검을 요청해야 하는 때를 나눠 적었습니다. / [오산 출장열쇠](osan.html)를 부르기 전 참고용으로 읽어 주세요.
@ 세교동 현관문 덜 닫힘 점검

# 문이 닫히는 모습부터 눈으로 확인하세요
문을 열어 둔 채 놓았다가 닫히는 모습을 천천히 지켜보세요. / 중간에 걸리는지, 끝에서 멈추는지, 쾅 닫히는지에 따라 원인이 달라집니다.
- 끝에서 살짝 멈추면 도어클로저 힘이 약하거나 걸쇠 위치가 어긋난 경우
- 중간에 끼는 느낌이면 경첩이 처졌거나 문틀과 닿는 경우
- 쾅 하고 닫히면 도어클로저 속도 조절이 필요한 경우
- 닫혀도 흔들리면 문틀 쪽 고정이 헐거운 경우
어느 쪽인지 알면 점검을 요청할 때 설명이 쉬워집니다. / 영상으로 짧게 찍어 두시면 더 정확하게 전달됩니다.

# 경첩이 처지면 문 모서리가 문틀에 닿습니다
경첩은 문을 문틀에 붙들어 매는 부품입니다. / 오래 쓰거나 문이 무거우면 나사가 헐거워져 문이 아래로 처질 수 있습니다.
문 아래쪽 모서리가 바닥이나 문턱에 스치는 흔적이 있는지 보세요. / 문틀과 문 사이 틈이 위쪽은 넓고 아래쪽은 좁다면 처짐이 의심됩니다.
이럴 때 나사만 조이면 해결되는 경우도 있지만, 구멍이 헐렁해졌다면 보강이 필요합니다. / 억지로 조이다가 나사 머리가 뭉개지면 더 어려워지니 조심하세요.

# 도어클로저는 속도와 마지막 힘이 핵심입니다
도어클로저는 문 위쪽에 붙은 팔 모양 장치로, 문이 닫히는 속도를 잡아 줍니다. / 속도가 너무 빠르면 소음이 크고, 너무 느리면 문이 끝까지 닫히지 않습니다.
조절 나사가 장치 옆에 있어서 돌리면 속도가 바뀌지만 많이 돌리면 오일이 새거나 상태가 나빠질 수 있습니다. / 기울기가 의심되면 직접 만지기보다 점검을 요청하시는 편이 안전합니다.
기름이 문에 묻어 나오거나 팔이 헐렁하게 흔들리면 교체 시기일 수 있습니다. / 상태를 사진으로 찍어 보내주시면 먼저 판단해 드립니다.

# 걸쇠가 받침 구멍과 맞는지 확인하세요
문이 끝까지 닫혀도 걸쇠가 문틀 구멍에 정확히 들어가지 않으면 잠기지 않습니다. / 구멍과 걸쇠 높이가 어긋나면 철컥 소리가 안 나거나 걸쇠가 구멍 가장자리에 닿습니다.
문틀 받침판에 긁힌 자국이 있다면 걸쇠가 구멍 위나 아래를 치고 있다는 신호입니다. / 이 자국을 사진으로 남겨 두시면 점검이 쉬워집니다.
받침판 위치를 조정하면 되는 경우가 많아 도어락 교체까지 가지 않아도 됩니다. / 먼저 문의 닫힘 상태부터 고치는 것이 순서입니다.
@ 오산 세교동 경첩 도어클로저 상태 확인

# 직접 해볼 수 있는 가벼운 점검
공구 없이도 해볼 수 있는 점검이 있습니다. / 아래 정도만 하시고 그다음은 맡기시는 게 좋습니다.
- 경첩 나사가 눈에 띄게 풀렸는지 손으로 확인
- 문 아래쪽이 바닥에 스치는 흔적 찾기
- 문틀과 문 사이 간격을 위아래로 비교
- 도어클로저 팔이 흔들리거나 기름이 묻는지 보기
무리하게 분해하거나 큰 힘을 쓰는 건 피하세요. / 문은 무거워서 잘못 만지면 손을 다칠 수도 있습니다.

# 문이 덜 닫힌 채로 오래 두면 생기는 일
문이 제대로 안 닫히면 외출 때 잠겼다고 착각하기 쉽습니다. / 걸쇠가 물리지 않은 채 나가면 문이 열려 있는 걸 모르고 있게 됩니다.
도어락도 이상 신호를 계속 받아서 모터가 불필요하게 작동하고 배터리가 빨리 닳습니다. / 작은 틈이 점점 다른 고장으로 이어질 수 있습니다.
외출할 때 문이 정말 닫혔는지 한 번 당겨 확인하는 습관이 도움이 됩니다. / 문이 이상하면 며칠 두지 말고 일찍 점검을 받는 쪽이 낫습니다.

# 문이 아예 안 열리거나 안 잠기는 상황이라면
점검 단계를 넘어 문이 열리지 않는 상태라면 먼저 신분 확인 절차를 준비해 주세요. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁할 수 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두면 편합니다.
문이 처졌거나 틀어진 경우에는 여는 방식이 일반 상황과 달라질 수 있습니다. / 상황을 있는 그대로 알려주시면 맞는 방법을 준비합니다.

# 비용은 점검하기 전에 먼저 말씀드립니다
도착해서 경첩과 도어클로저, 도어락을 함께 보고 어떤 작업이 필요한지 설명드립니다. / 얼마나 드는지 먼저 말씀드리고 괜찮다고 하실 때만 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 작업 중에 부품을 바꿔야 하면 바꾸기 전에 다시 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다. / 모르는 부분은 통화로 물어봐 주세요.

# 점검이 끝난 뒤 확인할 것
작업이 끝나면 문을 천천히 닫아 보며 속도와 걸림을 같이 봅니다. / 걸쇠가 구멍에 정확히 들어가는지, 도어락이 부드럽게 잠기는지도 확인합니다.
도어락 자체에 이상이 있으면 [도어락 수리](doorlock-repair.html)로 이어서 점검합니다. / 열어야 하는 상황이었다면 [현관문 개문](door-open.html) 방식대로 문을 상하지 않게 엽니다.
문이 반복해서 틀어진다면 문틀 쪽 근본 원인을 말씀드립니다. / 그때 필요하면 교체나 보강을 함께 상의합니다.
@ 세교동 도어클로저 경첩 점검 후 확인

# 오래 쓰는 문 관리 습관
문은 매일 쓰는 만큼 작은 변화가 쌓입니다. / 가끔 닫히는 소리를 귀 기울여 들어 보세요.
- 경첩 부위에 먼지가 끼지 않게 마른 천으로 닦기
- 문 앞에 짐을 쌓아 문이 끝까지 열리지 않게 하지 않기
- 문을 세게 닫거나 손으로 받치지 않기
- 닫히는 소리가 달라지면 며칠 안에 점검
이 정도 관리만으로도 문 앞에서 막히는 일이 많이 줄어듭니다.
계절이 바뀔 때 문이 뻑뻑해지거나 헐거워지는 느낌이 들면 그때가 점검 시기입니다. / 금속 부품은 온도와 습기에 따라 미세하게 변하기 때문입니다.
이사나 짐 정리로 문을 자주 활짝 열어 두는 때에는 경첩에 무게가 쏠립니다. / 그런 날 뒤에는 문이 잘 닫히는지 한 번 더 살펴 주세요.

# 세교동 말고 오산 어디든 갑니다
세교동 옆으로 오산동, 원동, 궐동, 신장동, 대원동, 남촌동, 초평동, 수청동, 갈곶동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
