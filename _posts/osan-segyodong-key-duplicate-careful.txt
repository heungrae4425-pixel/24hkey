# 복사해 둔 열쇠인데 왜 안 돌아갈까
세교동은 세마역 쪽 생활권을 이용하는 가구들이 많은 동네입니다. / 현관이나 보조키, 우편함까지 열쇠를 쓰는 곳이 아직 여럿 있습니다.
여분을 만들어 두었는데 막상 쓰려고 하면 들어가긴 하는데 돌아가지 않는 경우가 있습니다. / 어떤 때는 원본은 매끄러운데 복사본만 뻑뻑합니다.
이 글은 복사한 열쇠가 안 맞을 때 원인이 무엇인지, 그리고 하지 말아야 할 행동과 확인 순서를 정리했습니다.
@ 세교동 현관 열쇠 구멍에 꽂은 복사 열쇠

# 복사본이 안 맞는 가장 흔한 이유
열쇠는 겉으로는 같아 보여도 홈의 깊이가 아주 조금만 달라도 잠금 장치 안의 핀이 맞지 않습니다. / 머리카락 굵기 정도의 차이로 돌아가고 안 돌아가고가 갈리기도 합니다.
- 원본 열쇠가 닳아 홈 깊이가 달라진 경우
- 복사하는 과정에서 홈의 깊이나 각도가 조금 어긋난 경우
- 복사 원본이 이미 한 번 복사된 열쇠인 경우
- 열쇠 몸체가 휘어 있는 경우
- 열쇠 구멍 안에 먼지나 이물이 낀 경우
복사에 복사를 거듭할수록 오차가 쌓입니다. / 그래서 가능하면 원본 또는 처음 받은 열쇠를 기준으로 복사하는 게 좋습니다.

# 억지로 돌리면 생기는 일
여분 열쇠를 처음 써 보는 날은 급할 때가 많습니다. / 그래서 힘이 들어가기 쉬운데 바로 그때가 가장 위험합니다.
뻑뻑한 열쇠를 힘으로 돌리면 열쇠가 휘거나 부러질 수 있습니다. / 부러진 조각이 구멍 안에 남으면 문제는 훨씬 커집니다.
열쇠 구멍 안쪽 핀이 눌려 상할 수도 있습니다. / 이런 경우는 열쇠 하나가 아니라 잠금 장치 전체를 손봐야 합니다.
조금 걸린다고 느껴지면 일단 멈추세요. / 몇 번 시도해 보고 안 되면 다른 방법을 찾는 것이 안전합니다.

# 원본으로 먼저 돌려 보세요
집에 열쇠가 여러 개라면 모두 꺼내 한 번씩 꽂아 보는 것도 방법입니다. / 어떤 것은 되고 어떤 것은 안 되는지 알면 원인이 훨씬 좁혀집니다.
복사본이 안 될 때는 원본이 있다면 원본을 먼저 넣어 보세요. / 원본도 뻑뻑하다면 열쇠가 아니라 열쇠 구멍 쪽 문제입니다.
원본은 매끄러운데 복사본만 안 된다면 복사 오차를 의심할 수 있습니다. / 이럴 땐 다른 열쇠 가게에서 원본을 기준으로 다시 복사하는 것이 방법입니다.
두 열쇠를 나란히 놓고 홈의 모양이 같은지 눈으로 비교해 보세요. / 육안으로 구별되는 차이가 있으면 복사를 다시 하셔야 합니다.

# 열쇠 구멍 청소와 간단한 점검
구멍 안에 먼지가 쌓이면 열쇠가 끝까지 들어가지 않습니다. / 입으로 세게 불거나 에어 스프레이로 가볍게 먼지를 날려 보세요.
기름을 막 뿌리는 방법은 권하지 않습니다. / 일시적으로 부드러워져도 먼지를 더 끌어모아 나중에 더 굳을 수 있습니다.
흑연 가루처럼 열쇠 구멍 전용 윤활제를 쓰는 경우도 있지만 방법을 모르면 하지 마세요. / 잘못 쓰면 안쪽이 막힙니다.
@ 열쇠 구멍 안쪽 먼지를 확인하는 모습

# 문 안쪽과 걸쇠 쪽도 같이 봅니다
비 온 뒤나 한여름에는 문이 부풀어 걸쇠가 빡빡해지기도 합니다. / 그럴 땐 계절이 바뀌면 저절로 나아지는 일도 있습니다.
열쇠는 돌아가는데 문이 안 열린다면 열쇠 문제가 아닐 수 있습니다. / 문이 처져 걸쇠가 문틀에 눌려 있을 때도 같은 증상이 납니다.
문을 안쪽으로 살짝 밀어 주면서 열쇠를 돌려 보세요. / 그러면 걸쇠 압력이 줄어 잘 돌아가기도 합니다.
이런 방식으로 해결되는 경우는 열쇠 복사와 무관한 문제입니다.

# 새로 복사하기 전에 알아 둘 점
복사해 둔 열쇠는 한 번 써 보고 이상이 없는지 꼭 확인하세요. / 가게에서 받은 그 자리에서 자기 집 열쇠 구멍에 맞는지 바로 확인할 수는 없으니 집에 오자마자 시험해 보는 것이 좋습니다.
같은 열쇠 모양이라도 제조사나 규격이 다르면 복사가 어렵습니다. / 열쇠에 새겨진 글씨나 모양을 사진으로 남겨 두면 도움이 됩니다.
보안이 높은 열쇠는 복사 자체가 제한되는 경우도 있습니다. / 이럴 땐 열쇠 구멍을 아예 바꾸는 방향으로 상의하게 됩니다.
열쇠를 복사하기 전에 지금 쓰는 열쇠가 얼마나 닳았는지부터 보세요. / 너무 닳은 열쇠는 새로 만든 것도 오차가 크기 쉽습니다.

# 열쇠가 끝내 안 돌아갈 때 연락 요령
열쇠를 꽂은 채 다시 빼지 못하는 상황이면 더 이상 건드리지 마세요. / 상태 그대로 두고 연락 주시는 것이 좋습니다.
열쇠가 안 돌아가는데 문이 닫혀 있으면 [출장열쇠 요청](key-call.html)을 하는 것이 낫습니다. / 구멍이 상하기 전에 연락하면 열쇠를 살리고 문도 지킬 수 있습니다.
- 어떤 열쇠인지(현관, 보조키, 우편함 등)
- 원본이 있는지 복사본뿐인지
- 열쇠가 들어가는지, 어디서 걸리는지
- 안에 사람이나 반려동물이 있는지
열쇠 구멍 사진을 보내 주시면 상태를 가늠하기 쉽습니다.

# 도착하면 사시는 분인지 확인합니다
열쇠 문제로 연락하신 경우에도 확인 절차는 같습니다. / 열쇠만 들고 있다고 해서 사는 곳이라는 증명이 되지는 않기 때문입니다.
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 가운데 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.
번거로워도 이웃과 본인을 위한 절차입니다.

# 비용은 작업 전에 말씀드립니다
열쇠 상태와 문 종류를 보고 진행 방법과 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 부품을 교체해야 하면 바꾸기 전에 다시 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에서도 볼 수 있습니다.

# 열고 난 뒤 열쇠를 어떻게 할지
열쇠가 닳았다면 지금 가진 것을 기준으로 다시 복사하기보다 새로 만드는 쪽을 권합니다. / 어느 쪽이 나은지는 현장에서 열쇠를 보고 말씀드립니다.
문이 열리면 열쇠가 왜 안 맞았는지 같이 살펴봅니다. / 열쇠가 닳았다면 새로 만들고, 구멍이 문제라면 구멍을 손봅니다.
구멍 상태가 나쁘면 [도어락 수리](doorlock-repair.html)로 먼저 점검하고, 오래되어 교체가 맞다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
번호나 카드를 함께 쓰는 방식으로 바꾸고 싶다면 [도어락 설치](doorlock-install.html) 상담도 받습니다.
@ 열쇠 구멍을 점검하는 출장열쇠

# 열쇠를 오래 쓰는 평소 습관
- 원본 열쇠는 따로 보관하고 복사본을 일상에 사용
- 열쇠고리에 무거운 장식을 달지 않기
- 열쇠를 넣고 뺄 때 힘으로 비틀지 않기
- 구멍에 이물이 들어가지 않게 입구를 가끔 확인
- 복사본이 뻑뻑하면 바로 다시 만들기
작은 습관이 열쇠와 구멍을 둘 다 오래 가게 합니다.

# 세교동 밖에서도 오산 어디든 갑니다
세교동 가까운 궐동, 신장동, 오산동, 원동도 다닙니다. / 지역 안내는 [오산 출장열쇠](osan.html)와 [출장 지역](area.html)에서 볼 수 있습니다.
