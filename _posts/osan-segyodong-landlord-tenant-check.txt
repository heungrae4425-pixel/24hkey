# 도어락이 고장 났는데 누가 해결해야 하죠
세교동에 살다 보면 도어락이 갑자기 말썽인데 이걸 누가 고쳐야 하는지 막막할 때가 있습니다. / 오산대역이나 세마역 쪽으로 오가는 분들 중에는 전월세로 사시는 분도 많습니다.
이 글은 집주인과 세입자가 서로 이야기를 풀어 갈 때 확인하면 좋은 것들을 모았습니다. / 누가 맞고 틀리다는 판단이 아니라, 대화를 시작할 때 쓸 수 있는 점검표입니다.
@ 세교동 임대 주택 도어락 문제 정리

# 먼저 말씀드리는 한계
출장열쇠는 문을 열고 도어락을 점검하는 곳이지 법적 책임을 정하는 곳이 아닙니다. / 누가 비용을 내야 하는지는 계약서 내용과 집 상황에 따라 달라집니다.
그래서 이 글에서는 어느 쪽 책임이라고 단정하지 않습니다. / 분쟁이 커질 것 같으면 계약서를 먼저 확인하시고, 필요하면 전문 상담을 받으세요.
저희가 할 수 있는 일은 문 상태를 정확히 보고 무엇이 문제인지 사실대로 알려 드리는 것까지입니다. / 그 내용을 두 분이 같이 보며 이야기하시면 됩니다.

# 계약서에서 먼저 볼 부분
이야기를 꺼내기 전에 계약서를 한 번 훑어 보세요. / 시설 수리나 기본 설비에 관한 문구가 있는지 보시면 됩니다.
- 도어락이 기본 제공 설비로 적혀 있는지
- 수리나 교체에 관해 따로 정한 문구가 있는지
- 입주 때 상태를 기록한 내용이 있는지
문구가 애매하면 서로 편하게 확인하는 게 가장 빠릅니다. / 같은 말을 서로 다르게 기억하는 일이 의외로 많습니다.

# 입주할 때 사진 몇 장이 큰 도움이 됩니다
들어갈 때 도어락과 현관문 상태를 사진으로 남겨 두면 좋습니다. / 번호판, 손잡이, 문틀, 안쪽 보조키를 각각 찍어 두세요.
나중에 고장이 났을 때 원래부터 그랬는지, 이후에 생겼는지 이야기하기 쉽습니다. / 날짜가 보이게 저장해 두시면 더 좋습니다.
이미 입주하셨다면 지금이라도 찍어 두세요. / 문제가 없는 상태의 사진도 나중에 비교 자료가 됩니다.
집주인 입장에서도 입주 전후 기록이 있으면 서로 오해가 줄어듭니다.

# 고장 원인에 따라 이야기가 달라집니다
같은 도어락 고장이라도 원인이 여러 가지입니다. / 오래 써서 닳은 것인지, 갑자기 생긴 문제인지, 쓰다가 부딪힌 것인지에 따라 대화가 달라집니다.
배터리 교체처럼 생활 소모품은 보통 쓰는 사람이 챙기는 경우가 많습니다. / 내부 모터나 회로 고장은 설비 문제로 보고 이야기하는 경우도 있습니다.
어디까지나 흔한 사례일 뿐 정답은 아닙니다. / 계약 내용과 당사자 합의가 우선입니다.
원인을 모르겠다면 점검 때 어디가 어떻게 문제인지 먼저 확인해 달라고 하세요. / 점검 결과를 알면 대화가 훨씬 구체적이 됩니다.

# 출장 점검을 부를 때 알려야 할 사람
세입자가 직접 출장을 부르기 전에 집주인에게 먼저 알려 두면 나중에 편합니다. / 문자 한 통이면 충분합니다.
고장 상황, 사진, 부를 예정이라는 내용을 짧게 보내 두세요. / 동의를 받아 두면 비용을 놓고 의견이 갈릴 때 덜 곤란합니다.
급한 경우에는 먼저 문을 열고 나중에 알리는 일도 생깁니다. / 그때도 기록은 꼭 남겨 두세요.
@ 오산 세교동 집주인 세입자 도어락 상의

# 문이 안 열려 급한 상황이라면
집주인과 연락이 닿지 않아도 문을 열어야 하는 순간이 있습니다. / 사시는 분이라는 확인이 되면 출장열쇠는 문을 열어 드립니다.
신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나를 준비해 주세요. / 임대차 계약서도 사시는 분을 보여 주는 자료가 될 수 있습니다.
집주인의 허락이 있어야만 열 수 있는 것은 아닙니다. / 다만 확인이 안 되면 작업을 시작하지 못합니다.

# 비용은 문을 열기 전에 먼저 말씀드립니다
도착해서 문과 도어락을 보고 작업 내용과 비용을 설명드립니다. / 그 자리에서 하실지 말지 정하시면 됩니다.
문을 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
견적서나 영수증이 필요하면 말씀해 주세요. / 나중에 집주인과 정산할 때 쓰실 수 있습니다. 진행 방식은 [이용안내](guide.html)에서 보실 수 있습니다.

# 영수증과 기록은 이렇게 남기세요
비용을 누가 낼지 나중에 이야기해야 한다면 기록이 가장 큰 힘이 됩니다. / 작업 전후 사진과 영수증, 대화 내용을 한곳에 모아 두세요.
- 고장 시작 시점과 증상
- 작업 내용과 교체한 부품
- 집주인에게 알린 날짜와 답변
문자나 메신저 대화는 지우지 말고 남겨 두세요. / 구두로만 이야기하면 시간이 지나 서로 기억이 달라집니다.

# 교체나 설치를 정할 때 같이 볼 것
새 도어락으로 바꾸는 이야기가 나오면 몇 가지를 같이 확인하세요. / 이사 나갈 때 두고 갈 것인지, 가지고 갈 것인지부터 정해 두면 좋습니다.
문에 구멍을 새로 내거나 기존 장치를 떼는 작업이라면 집주인 동의를 미리 받는 편이 안전합니다. / 원상 복구가 필요할 수 있기 때문입니다.
제품 선택은 [도어락 교체](doorlock-replace.html)와 [도어락 설치](doorlock-install.html) 안내를 참고하시면 됩니다.

# 비밀번호와 열쇠는 이렇게 주고받으세요
집주인이 비밀번호나 여분 열쇠를 가지고 있는 경우도 있습니다. / 세입자 입장에서는 이 부분이 늘 신경 쓰입니다.
입주 때 번호를 새로 바꾸고 누가 아는지 서로 확인해 두면 편합니다. / 여분 열쇠를 가진 사람이 있다면 그 사실도 터놓고 정해 두세요.
퇴거할 때는 번호를 지우거나 새로 정하고 열쇠를 돌려주는 순서를 미리 정하면 깔끔합니다. / 서로 확인한 내용은 메시지로 남겨 두시길 권합니다. / 번호를 말로만 주고받지 말고 바꾼 날짜도 함께 적어 두세요.
@ 세교동 도어락 비밀번호 열쇠 인수인계

# 조용히 풀리는 대화 요령
고장 이야기를 꺼낼 때 책임을 따지는 말투보다 상황을 알리는 말투가 좋습니다. / 문이 이렇게 됐는데 어떻게 하면 좋을까요 정도로 시작해 보세요.
사진과 기록을 같이 보내면 상대도 판단하기 쉽습니다. / 서로 불편한 대화가 되기 전에 빠르게 끝날 수 있습니다.
오산대역 근처 원룸처럼 집주인이 멀리 계신 경우도 많습니다. / 그럴수록 문자와 사진으로 차근차근 알려 두는 방식이 잘 맞습니다.
의견이 크게 갈리면 계약서와 기록을 가지고 필요한 곳에 상담을 받으시길 권합니다.

# 세교동 말고 오산 어디든 갑니다
세교동 가까이 오산동, 원동, 궐동, 신장동, 수청동까지 다닙니다. / 오산 안이면 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 자주 묻는 질문
? 세입자가 도어락을 고쳐도 되나요? | 배터리 교체처럼 간단한 관리는 가능하지만, 부품 교체나 설치는 집주인과 먼저 이야기하시길 권합니다.
? 비용은 누가 내야 하나요? | 계약 내용과 당사자 합의에 따라 달라서 단정해 드릴 수 없습니다. 영수증과 작업 내용은 자세히 남겨 드립니다.
? 집주인 허락 없이 문을 열어도 되나요? | 사시는 분이라는 확인만 되면 열어 드립니다. 신분증이나 우편물을 준비해 주세요.
? 문을 못 열면 비용이 드나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 이사 나갈 때 도어락은 어떻게 하나요? | 번호를 지우고 상태를 사진으로 남기는 것을 권합니다. 두고 갈지 가져갈지는 미리 정해 두세요.
