# 세교동 오래된 빌라, 나무 현관문의 사정
세교동에는 새로 지은 건물도 많지만 지은 지 오래된 빌라와 다세대 주택도 함께 있습니다. / 오산대역이나 세마역 쪽을 오가며 지내는 분들 중에도 오래된 건물에 사는 분들이 있고, 이런 집에는 목재 현관문이 그대로 달린 경우가 있습니다.
나무 문은 철문과 달리 계절과 습도에 따라 부풀었다 줄었다를 반복합니다. / 그래서 어제까지 잘 열리던 문이 갑자기 뻑뻑해지거나 안 열리는 일이 생깁니다.
이 글은 세교동 오래된 빌라의 목재 현관문이 말을 안 들을 때 먼저 볼 것과 [오산 출장열쇠](osan.html)를 부르면 어떻게 진행되는지를 적었습니다.
@ 세교동 오래된 빌라 목재 현관문

# 나무 문이 안 열리는 대표적인 이유
목재 문은 문 자체가 변하기 때문에 도어락이 멀쩡해도 문제가 생깁니다. / 원인을 구분하면 대처도 달라집니다.
- 장마나 겨울 결로로 문이 습기를 먹어 부풀어 문틀에 끼는 경우
- 오래 쓰며 경첩 나사가 헐거워져 문이 아래로 처진 경우
- 손잡이나 자물쇠가 박힌 부분의 나무가 갈라지거나 헐거워진 경우
- 문틀과 문 사이 틈이 좁아져 걸쇠가 겨우 걸리거나 안 빠지는 경우
도어락이 번호는 인식하는데 문이 안 열린다면 문 자체의 문제일 가능성이 있습니다. / 반대로 문은 움직이는데 잠금이 안 풀리면 도어락 쪽을 의심합니다.

# 문을 밀고 당기며 열쇠를 돌려 보세요
처진 문은 걸쇠가 문틀 구멍과 어긋나 있어서 그냥 돌려서는 풀리지 않는 경우가 많습니다. / 문을 안쪽으로 살짝 들어 올리듯 밀면서 열쇠나 손잡이를 돌려 보세요.
이때 힘을 세게 주면 안 됩니다. / 가볍게 들어 올리듯 하는 것이 포인트이고, 몇 번 해도 안 되면 그만두세요.
이 방법은 나무 문에서 효과를 보는 일이 많지만 철문에서는 소용이 없는 경우가 많습니다.

# 하지 말아야 할 일
오래된 목재 문은 한 번 상하면 원래대로 되돌리기 어렵습니다. / 급해도 아래 행동은 피해 주세요.
- 어깨로 문을 밀거나 발로 차기(문틀 갈라짐, 경첩 뜯김)
- 칼이나 드라이버를 문틈에 넣어 걸쇠를 밀기(문 표면 긁힘)
- 습기 찬 문을 헤어드라이어나 열기로 말리기(나무가 뒤틀림)
- 문을 대패나 칼로 깎아서 맞추기(나중에 틈이 벌어짐)
목재는 한 번 깎으면 돌려놓을 수 없습니다. / 먼저 원인을 확인하고 필요한 부분만 손봐야 문이 오래갑니다.
@ 세교동 목재 현관문 경첩 처짐 확인

# 경첩이 처졌는지 눈으로 확인하는 법
문을 닫은 상태에서 문 위쪽 틈과 아래쪽 틈의 간격을 비교해 보세요. / 한쪽만 유난히 좁거나 문 모서리가 문틀에 닿는 자국이 보이면 경첩이 처진 것입니다.
경첩 나사가 헐거워서 나무 구멍이 넓어진 경우에는 단순히 나사를 조이는 것만으로는 다시 풀리기 쉽습니다. / 이런 경우 나무 조각이나 더 긴 나사로 보강하는 방법이 있습니다.
경첩 문제는 도어락을 새로 바꾼다고 해결되지 않습니다. / 그래서 문을 열고 나서 상태를 먼저 확인하는 것이 중요합니다.

# 오래된 열쇠 구멍과 자물쇠도 같이 봅니다
오래된 목재 문에는 오래된 열쇠식 자물쇠가 달려 있는 경우가 많습니다. / 열쇠 모양이 닳아서 걸리거나 안쪽 부품이 굳으면 열쇠가 잘 돌지 않습니다.
열쇠가 닳았다면 복사본은 더 안 맞을 수 있습니다. / 이럴 때는 원본 열쇠를 아껴 쓰고, 새로 자물쇠를 바꾸는 방법을 검토하는 것이 낫습니다.
나무 문에 자물쇠가 박힌 자리가 헐겁다면 자물쇠를 바꿀 때 구멍 크기와 문 두께를 먼저 재야 합니다. / 이 부분은 [도어락 설치](doorlock-install.html) 안내에서 확인하실 수 있습니다.

# 전화할 때 알려주시면 좋은 것
오래된 건물일수록 전화로 상황을 정확히 알려주시면 챙길 장비가 달라집니다. / 아래 정도를 말씀해 주세요.
- 문 재질(나무인지, 나무에 철판을 덧댄 것인지)
- 열쇠식인지 번호식인지, 둘 다 있는지
- 최근 비가 많이 왔거나 문이 부풀었다고 느끼는지
- 문틈이 넓은지 좁은지, 처짐이 보이는지
- 안에 아이나 반려동물이 있는지
가능하면 문 전체와 자물쇠 부분 사진을 문자로 보내 주세요. / 장비를 맞게 챙겨 가기 좋습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 확인 절차는 생략하지 않습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
다세대 빌라는 관리사무소가 없는 경우도 많습니다. / 이럴 때는 집주인 확인이나 계약서, 공과금 고지서 같은 자료를 함께 살펴봅니다.
세입자라서 집주인 연락이 어려운 경우에도 사시는 분인지 확인되면 진행할 수 있습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 자물쇠 종류를 보고 먼저 얼마인지 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 작업 중 부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다.
[이용안내](guide.html)에 진행 순서를 적어 두었습니다.

# 목재 문은 더 조심해서 엽니다
나무 문은 철문보다 흠집이 쉽게 남습니다. / 그래서 문 표면과 문틀을 덜 건드리는 방법부터 차례로 해봅니다.
처짐이나 부풀음이 원인이면 문 자체를 살짝 받쳐 걸쇠가 풀리게 한 뒤 엽니다. / 자물쇠 구멍이 헐겁다면 열면서 상태를 같이 확인합니다.
[현관문 개문](door-open.html) 페이지에 방식이 자세히 적혀 있습니다.
@ 세교동 목재 문 비파손 개방 작업

# 열고 난 뒤 고쳐 쓸지 바꿀지 판단하는 기준
문이 열렸다면 같은 일이 반복되지 않게 상태를 봅니다. / 경첩만 손보면 되는 경우도 있고 자물쇠를 바꿔야 하는 경우도 있습니다.
고쳐서 쓸 수 있으면 교체는 권하지 않고 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 너무 낡아 계속 말썽이라면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문을 아예 새로 달아야 하는지는 건물 관리 주체와 상의할 일이라 제가 단정하지 않습니다.

# 오래된 목재 문을 오래 쓰는 관리법
나무 문은 작은 관리가 큰 차이를 냅니다. / 아래만 지켜도 안 열리는 일이 줄어듭니다.
- 장마철과 겨울에 문 가장자리 틈을 가끔 확인
- 경첩 나사가 헐거워지면 그때그때 조이기
- 문 아래쪽에 물이 닿지 않게 현관 바닥 물기 닦기
- 환기를 자주 해 습기가 고이지 않게 하기
- 열쇠 구멍에 먼지가 쌓이면 에어로 가볍게 불어내기
문 틈에 신문지나 천을 끼워 두는 습관은 문틀 변형을 숨길 뿐 원인을 해결하지는 못합니다. / 틈이 변하면 점검을 받는 편이 낫습니다.

# 세교동 말고 오산 어디든 갑니다
세교동 가까이 있는 수청동, 갈곶동, 오산동, 궐동은 물론 원동, 신장동, 대원동, 남촌동, 초평동까지 오산 안이면 24시간 출동합니다. / 오산대역, 세마역, 오산역 어느 쪽 생활권에서도 위치만 알려주세요.
동네 목록은 [오산시 출장열쇠](osan.html), 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
