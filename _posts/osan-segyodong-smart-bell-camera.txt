# 세교동 스마트 초인종, 도어락부터 같이 보세요
세교동은 오산역과 세마역을 오가는 분들이 많이 사는 생활권입니다. / 새 집에 들어오면서 영상 초인종을 같이 다는 댁이 늘어난 동네이기도 합니다.
초인종만 새로 달았는데 문 앞이 더 불편해졌다는 말씀을 가끔 듣습니다. / 초인종과 도어락이 한 문에서 같이 움직이다 보니 서로 영향을 주기 때문입니다.
이 글은 [오산 출장열쇠](osan.html)가 문 앞에서 본 경험을 바탕으로, 스마트 초인종을 달기 전에 도어락과 함께 살펴볼 것을 정리했습니다.
@ 세교동 현관문 옆 스마트 초인종과 도어락 설치 위치

# 초인종과 도어락은 같은 문을 나눠 씁니다
현관문은 생각보다 자리가 넓지 않습니다. / 도어락 본체, 보조키, 문 닫힘 장치, 초인종이 모두 한 면에 모입니다.
초인종 카메라가 시야에 문 손잡이와 번호판을 담을 수 있어서, 설치 각도를 잡을 때 도어락 높이를 같이 보면 좋습니다.
번호판이 영상에 크게 잡히면 비밀번호를 누르는 손이 그대로 찍힐 수 있습니다. / 카메라 각도는 얼굴 쪽을 향하게 하고 번호판은 가장자리로 밀어 두는 편이 안전합니다.

# 설치 전에 도어락 모델과 배터리부터 확인
초인종 작업을 하다가 도어락 배터리가 약한 걸 뒤늦게 아는 경우가 있습니다. / 이왕 문 앞에 서 있다면 도어락 덮개를 열고 배터리 상태도 함께 보세요.
- 번호 누를 때 소리가 작아졌거나 반응이 느린지
- 최근 저전압 경고음이 한 번이라도 났는지
- 손잡이를 돌릴 때 걸쇠가 매끄럽게 들어가는지
- 보조키가 있다면 잠글 때 뻑뻑하지 않은지
하나라도 걸리면 초인종을 달기 전에 먼저 정리하는 게 순서입니다.

# 배선형과 건전지형, 어떤 초인종인지
스마트 초인종은 크게 건전지로 도는 것과 전원을 연결해 쓰는 것으로 나뉩니다. / 건전지형은 문 옆에 붙이기만 하면 되어서 도어락과 부딪힐 일이 적습니다.
전원 연결형은 벽 안쪽 배선이나 기존 벨 선을 쓰기도 합니다. / 이 경우 전선 작업은 초인종 설치 기사나 전기 쪽에 맡기고, 도어락 쪽은 건드리지 않는 것이 좋습니다.
어느 쪽이든 현관문 철판에 구멍을 뚫는 작업은 신중해야 합니다. / 안쪽에 도어락 몸통이 지나가는 자리라서 잘못 뚫으면 걸쇠가 상할 수 있습니다.

# 문에 붙일지 벽에 붙일지 정하기
문에 직접 붙이는 방식은 문을 여닫을 때마다 진동이 전해집니다. / 접착식이라면 시간이 지나 떨어지거나 각도가 틀어질 수 있습니다.
벽에 붙이면 흔들림이 적은 대신 카메라가 문 앞 복도 쪽을 넓게 비춥니다. / 공동 복도라면 이웃의 문까지 영상에 들어가지 않는지 확인하세요.
세교동처럼 복도가 좁은 집에서는 벽 위치가 충분히 나오지 않는 일도 있습니다. / 이럴 땐 문 높이 위쪽 가장자리에 붙이되 문이 열리는 방향과 겹치지 않게 정합니다.

# 문이 열리는 방향과 걸쇠 위치 잊지 마세요
문을 활짝 열었을 때 초인종 본체나 손잡이가 벽이나 신발장에 닿으면 안 됩니다. / 부딪히는 소리가 반복되면 도어락 연결부가 먼저 헐거워집니다.
@ 현관문을 열었을 때 초인종과 손잡이가 닿지 않는지 확인하는 모습

# 알림 소리가 도어락 경고음과 헷갈릴 때
스마트 초인종은 휴대폰으로 알림이 오고 자체 소리도 냅니다. / 도어락도 배터리 부족이나 오류를 소리로 알려 주니 두 소리를 구분해 둬야 합니다.
처음 설치한 날 도어락 경고음과 초인종 소리를 각각 직접 들어 보시길 권합니다. / 어느 소리가 나는지 모르고 지나치면 배터리 경고를 놓치기 쉽습니다.
연동 앱을 쓰는 도어락이라면 초인종 앱과 별도로 알림을 받는 점도 알아 두세요. / 두 앱을 한곳에서 보려면 호환 여부를 먼저 확인해야 합니다. 설치 방법은 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.

# 가족과 방문자 설정은 나눠서 관리
초인종 앱은 가족이 같이 쓰는 경우가 많습니다. / 도어락 비밀번호는 새로 정해 두고, 앱 계정은 가족 구성원별로 따로 관리하는 쪽이 낫습니다.
세입자나 이사 온 분이라면 이전 사용자가 앱에 남겨 둔 계정이 없는지 확인하세요. / 초인종을 중고로 쓰거나 기존 설치분을 이어받았다면 초기화부터 하는 게 맞습니다.

# 이런 일이 생기면 먼저 전화 주세요
초인종을 달다가 문이 안 열리는 일은 생각보다 흔합니다.
- 설치하다 도어락 덮개를 열었다가 번호판이 꺼진 경우
- 문 안쪽에서 나사를 풀다 보조키가 잠긴 경우
- 문을 닫은 채로 작업하다 열쇠를 안에 두고 나온 경우
이럴 땐 억지로 열려고 하지 말고 [현관문 개문](door-open.html) 안내를 참고해 전화 주세요. / 도어락과 초인종이 함께 붙어 있어서 힘으로 열면 둘 다 상할 수 있습니다.

문이 안 열려 연락하실 때는 현재 문 앞 사진과 도어락 모양을 문자로 보내 주시면 도움이 됩니다. / 어떤 장비를 챙겨 가야 하는지 미리 가늠할 수 있기 때문입니다.
세교동 어느 단지인지는 말씀해 주시되, 단지 이름 말고 동, 호수와 가까운 방향 정도면 충분합니다. / 오산역 쪽인지 세마역 쪽인지 말씀해 주시면 더 빠릅니다.
집 안에 아이나 반려동물이 있는지, 초인종 작업 중 어떤 부분까지 손댔는지도 알려 주세요. / 어디서부터 어긋났는지 알면 확인 순서가 짧아집니다.

# 도착하면 사는 분인지 먼저 확인합니다
문을 여는 일이라 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나는 꼭 필요합니다. / 이웃과 가족 모두를 위한 절차라 번거로워도 양해 부탁드립니다.
신분증이 집 안에 있으면 관리사무소를 통해 세대 확인을 부탁하는 방법도 있습니다.

# 비용은 문을 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.
@ 세교동 도어락 점검과 초인종 설치 후 작동 확인

# 설치 뒤에 한 번 해 볼 확인
초인종을 달고 나면 잠시 문 앞에서 아래를 확인해 보세요.
- 도어락 번호를 눌러 열리고 잠기는지
- 문을 닫았을 때 자동 잠금이 정상인지
- 초인종 앱에서 현관 영상이 정상으로 나오는지
- 번호판이 영상에 크게 들어오지 않는지
도어락에 문제가 보이면 [도어락 수리](doorlock-repair.html)를, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 살펴보시면 됩니다.

# 세교동 말고 오산 어디든 갑니다
오산동, 원동, 궐동, 신장동, 대원동, 남촌동, 초평동, 수청동, 갈곶동까지 오산 안이면 24시간 출동합니다. / 지역은 [출장 지역](area.html)에서 보실 수 있고, 이용 순서는 [이용안내](guide.html)에 적어 두었습니다.
