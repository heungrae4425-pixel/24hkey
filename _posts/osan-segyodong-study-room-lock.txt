# 세교동 독서실 출입문이 안 열린다면
세교동은 세마역과 오산대역 쪽을 오가는 학생과 직장인이 많아 늦은 시간까지 불이 켜진 공부 공간이 눈에 띕니다. / 독서실이나 스터디카페는 이용자가 시간대별로 드나들어서 출입문 문제가 생기면 여러 사람이 동시에 불편해집니다.
오픈하려고 왔는데 문이 안 열리거나, 마감하고 나가다 문이 잠겨 버리는 일이 대표적입니다. / 이 글은 세교동의 이런 공간에서 출입문이 잠겼을 때 확인할 순서를 정리했습니다.
저녁 늦게 혼자 남아 마감하는 운영자라면 이런 일이 더 부담스럽습니다. / 외부에서 열 수 없는 구조라면 안에서 꼼짝 못 하기도 합니다.
@ 세교동 스터디카페 출입문 도어락

# 일반 현관문과 다른 점
집 현관은 가족 몇 명만 쓰지만 독서실은 많은 사람이 하루에도 수십 번 문을 엽니다. / 그래서 같은 도어락이라도 배터리 소모와 부품 마모가 훨씬 빠릅니다.
출입 방식도 다양합니다. / 번호키, 카드 태그, 지문, 원격 개방 장치를 함께 쓰는 곳이 많아 원인을 가려내려면 순서가 필요합니다.
한 곳에서 문이 안 열리면 안쪽의 이용자, 바깥의 대기자, 운영자가 모두 같은 질문을 하게 됩니다. / 그래서 누가 어디서 무엇을 확인할지 역할을 나누면 시간이 줄어듭니다.
또 출입문이 유리문이거나 얇은 프레임이라 힘을 주면 쉽게 상합니다. / 손잡이를 흔들기 전에 먼저 상태를 살펴 주세요.

# 운영자가 문 앞에서 먼저 볼 것
문이 안 열릴 때는 아래 순서로 살펴보세요.
- 도어락 불빛이 켜지는지, 안내 음성이 나오는지
- 카드나 번호 중 어느 한쪽만 안 되는지
- 문이 문틀에 눌려 걸쇠가 빠지지 않는 상태인지
- 전원 어댑터를 쓰는 제품이라면 코드가 빠지거나 정전은 아닌지
한 가지만 안 되면 입력 장치 문제일 가능성이 있고, 전부 안 되면 전원이나 모터 쪽을 먼저 의심합니다. / 이 구분만 해도 출동 전에 원인을 좁힐 수 있습니다.
불빛이 들어오는데도 카드만 안 된다면 리더기 연결선이 헐거워진 경우도 있습니다. / 이럴 때 선을 직접 만지기보다 상태를 사진으로 찍어 두시면 설명이 쉽습니다.

# 이용자가 안에 갇힌 경우
마감 후에 안쪽 잠금 장치가 풀리지 않는 경우도 있습니다. / 안쪽에서 돌리는 손잡이나 열림 버튼이 반응이 없으면 억지로 열지 마세요.
안에 있는 분은 비상 열림 버튼이 있는지, 옆에 수동 열림 레버가 있는지 먼저 확인하면 됩니다. / 이것으로 안 되면 밖에서 여는 방법을 안내해 드립니다.
이용자가 혼자 남은 늦은 시간이라면 놀라지 않게 계속 통화를 이어 가시는 것이 좋습니다.

# 카드 태그가 안 먹히는 이유
카드 출입 장치는 카드가 닳거나 등록이 풀리면 인식이 안 됩니다. / 지갑 안에서 다른 카드와 겹치면 신호가 섞여 읽히지 않기도 합니다.
카드를 한 장만 꺼내 천천히 갖다 대 보세요. / 그래도 반응이 없고 다른 사람 카드는 된다면 카드 쪽 문제입니다.
카드가 전부 안 된다면 리더기 전원이나 제어기를 확인해야 합니다. / 이때는 문을 먼저 열고, 장치를 따로 점검하는 순서가 안전합니다.

# 시험 기간에 특히 조심할 것
시험이 가까워지면 늦은 시간까지 이용자가 몰리고 문 여닫는 횟수가 늘어납니다. / 이때 갑자기 출입문이 멈추면 한꺼번에 여러 명이 밖에 서게 됩니다.
평소에 경고음이 났거나 반응이 느려진 적이 있다면 그 시점에 미리 점검해 두는 것이 낫습니다. / 사용 인원이 많은 곳은 배터리를 일정 시점에 모두 교체하는 습관도 도움이 됩니다.
@ 세교동 독서실 카드 리더 출입 장치 점검

# 해보시면 안 되는 것
급한 마음에 문을 발로 차거나 어깨로 밀면 다칠 수 있고 문틀이 틀어집니다. / 유리문은 깨지면 더 큰 사고로 이어집니다.
도어락 덮개를 뜯어 배선을 만지는 것도 피해 주세요. / 잘못 만지면 전체 출입 시스템이 멈춥니다.
임시로 문을 열어 둔 채 자리를 비우는 일도 위험합니다. / 장비와 이용자 물품이 있는 공간이라 잠깐이라도 비워 두지 않는 게 좋습니다.

# 전화로 알려주실 내용
정확히 알려주실수록 출동이 빨라집니다.
- 어느 동네이고 건물 몇 층인지
- 출입문 모양(유리문, 철문, 목문)과 도어락 종류
- 번호, 카드, 지문 중 무엇이 안 되는지
- 안에 사람이 있는지, 몇 명인지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙겨 갈 수 있습니다. / 건물 안내가 필요하면 관리사무소 연락처도 같이 알려 주세요.
주차장이나 공용 복도를 거쳐야 하는 건물이라면 출입 방법도 미리 알려 주세요. / 도착하자마자 바로 작업에 들어갈 수 있습니다.

# 신분 확인은 운영자 기준으로
사업장은 집과 확인 방법이 조금 다릅니다. / 사업자 관련 서류, 사업장 주소가 적힌 우편물, 건물 관리사무소 확인 중 하나면 됩니다.
임차인이라면 계약서를 보여 주셔도 됩니다. / 확인이 어려우면 작업이 어렵다는 점은 집과 같습니다.
직원이나 아르바이트 분이 대신 연락하셨다면 운영자와 통화로 확인하는 과정이 필요할 수 있습니다.

# 비용은 문 열기 전에
출입문 종류와 도어락 상태를 확인한 뒤 비용을 먼저 말씀드립니다. / 동의하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
상가 출입문 작업 일반은 [상가 사무실 도어락](doorlock-repair.html) 쪽 설명과 [이용안내](guide.html)를 참고하시면 됩니다.

# 열고 난 뒤 같이 점검합니다
문이 열리면 닫고 잠그는 동작을 몇 번 반복하며 확인합니다. / 카드와 번호가 모두 되는지, 안쪽 열림이 부드러운지도 봅니다.
원인이 배터리였다면 전체를 새것으로 바꾸고 교체 날짜를 적어 두기를 권합니다. / 오래되어 반복되는 고장이라면 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html)를 설명해 드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 운영자가 미리 해두면 좋은 준비
문제가 터지기 전에 몇 가지만 준비해 두면 대처가 쉽습니다.
- 비상용 열쇠를 건물 밖이 아닌 믿을 만한 곳에 보관
- 카드와 번호 등록 목록을 따로 정리
- 도어락 모델명과 설치 위치 사진을 휴대폰에 저장
- 전원과 배터리 교체 일정을 달력에 표시
@ 세교동 공부 공간 출입문 사전 점검 목록
이 정도만 해두어도 급할 때 전화 한 통으로 정리가 됩니다.

# 세교동 말고 오산 어디든 갑니다
세교동 가까운 오산동, 원동, 궐동, 신장동은 물론 오산 안이면 동네 상관없이 24시간 출동합니다. / 오산역, 오산대역, 세마역 근처 어디든 문의 주세요.
다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 정리해 두었습니다.
