# 뚝 소리와 함께 열쇠가 반쪽이 됐다면
열쇠를 돌리는 순간 뚝 하는 느낌이 들고 손에는 머리 부분만 남아 있다면 열쇠가 구멍 안에서 부러진 것입니다. / 오산역에서 신장동으로 돌아온 퇴근길에 이런 일을 겪으면 정말 난감합니다.
이 글은 부러진 열쇠가 안에 박혔을 때 직접 해도 되는 일과 하지 말아야 할 일, 그리고 출장열쇠가 어떻게 빼내는지 정리한 것입니다.
@ 신장동 열쇠 부러짐 구멍 안 박힘

# 가장 먼저 멈춰야 할 행동
부러진 조각이 살짝 보인다고 손톱이나 칼끝으로 끄집어내려는 분이 많습니다. / 그러면 조각이 더 안쪽으로 밀려 들어가 빼기 어려워집니다.
남은 열쇠 머리로 다시 구멍을 돌려 보는 것도 피해 주세요. / 부러진 조각이 구멍 안에서 다른 방향으로 꺾이기도 합니다.
일단 손을 떼고 상태를 사진으로 남겨 두는 것이 가장 안전합니다.
부러진 열쇠 머리 부분은 버리지 말고 챙겨 두세요. / 머리에 남은 홈 모양을 보면 구멍 종류를 짐작하고 새 열쇠를 만들기 쉽습니다.
이웃이 비슷한 도구를 빌려주겠다고 해도 일단 사양하고 전문가에게 맡기는 편이 결과적으로 시간이 덜 듭니다.

# 조각이 보이는지부터 살펴보기
휴대폰 손전등을 구멍에 비춰 보세요. / 부러진 조각 끝이 구멍 바깥으로 조금이라도 나와 있는지 확인합니다.
끝이 밖으로 나와 있으면 빼내기 쉬운 편이고, 완전히 안으로 들어가 있으면 전용 도구가 필요합니다. / 이 차이를 알려주면 어떤 장비를 챙겨 갈지 정할 수 있습니다.
조각이 나왔어도 맨손이나 집에 있는 집게로 잡아당기는 것은 권하지 않습니다. / 순간적으로 힘이 쏠려 조각이 더 부러지기 때문입니다.

# 왜 열쇠가 부러지는지
열쇠가 부러지는 원인은 대개 오래 써서 약해졌거나, 구멍 안쪽이 뻑뻑해졌기 때문입니다. / 평소 열쇠가 잘 안 돌아간다고 느꼈다면 이미 위험 신호였을 수 있습니다.
돌리는 방향이 아닌 쪽으로 억지로 힘을 줘도 열쇠가 휘다 끝내 부러집니다. / 특히 추운 날에는 금속이 더 딱딱해져 부러지기 쉽습니다.
복사한 열쇠를 여러 번 다시 복사해 쓴 경우 홈이 어긋나 구멍에 걸리기도 합니다.
열쇠고리에 달린 장식이 무거워 구멍에 늘 하중이 걸리는 경우도 있습니다. / 이런 습관이 쌓이면 어느 날 갑자기 부러지는 것처럼 느껴집니다.
부러진 순간 문이 어느 방향으로 돌아가 있었는지도 기억해 두면 작업에 도움이 됩니다.

# 문이 잠긴 채인지 열린 채인지 확인
부러진 열쇠가 박혀 있어도 문이 열린 상태라면 급할 일은 적습니다. / 문이 아직 잠겨 있고 집 안으로 들어가야 한다면 그때부터가 본격적인 문제입니다.
안쪽 보조키나 도어락이 따로 있는 집이라면 문이 다른 방식으로 열릴 수 있습니다. / 비밀번호 도어락이 같이 달린 문이라면 번호로 열고 나서 천천히 수리를 맡기시면 됩니다.
번호판 없이 열쇠 구멍 하나뿐인 문이라면 바로 연락 주시는 편이 낫습니다.
@ 신장동 현관 열쇠 구멍 조각 제거

# 부러진 열쇠를 빼내는 방법
출장열쇠는 전용 가는 갈고리형 도구로 조각 끝을 걸어 천천히 뽑아냅니다. / 조각이 깊이 들어갔을 때는 구멍을 일부 분해해서 빼기도 합니다.
힘으로 당기지 않고 구멍 속 핀이 상하지 않게 하는 것이 핵심입니다. / 핀이 상하면 열쇠를 뺀 뒤에도 새 열쇠가 안 맞을 수 있기 때문입니다.
빼는 도중에 구멍을 바꿔야 할 상황이 보이면 먼저 말씀드리고 허락을 구합니다.
조각이 빠지면 구멍 안에 남은 쇳가루를 털어내고 새 열쇠를 꽂아 돌아가는 느낌을 같이 확인합니다. / 이 확인을 건너뛰면 며칠 뒤에 다시 막히는 일이 생길 수 있습니다.
문이 잠긴 상태에서 조각을 뺀 경우에는 문을 여는 작업이 이어서 진행됩니다. / 두 작업을 따로 부르지 않고 한 번에 끝낼 수 있습니다.

# 빼낸 다음에 꼭 봐야 할 것
조각을 빼냈다고 바로 쓰면 같은 일이 되풀이될 수 있습니다. / 구멍 안쪽이 닳았다면 새 열쇠를 넣어도 뻑뻑하게 돌아갑니다.
열쇠 구멍 부분만 새것으로 바꾸는 방법이 있습니다. / 문 전체를 바꾸는 것이 아니라 구멍 부분만 교체하는 정도로 끝나는 경우가 많습니다.
이때 열쇠도 새로 만들어 드리니 여분을 두세 개 만들어 두면 좋습니다. / 자세한 교체 방식은 [도어락 교체](doorlock-replace.html) 페이지에서 볼 수 있습니다.

# 직접 해보는 사람들이 자주 하는 실수
- 순간접착제로 조각을 붙여 빼려는 시도
- 이쑤시개나 바늘을 구멍에 밀어 넣는 것
- 구멍에 기름을 잔뜩 뿌리는 것
- 망치로 문 주변을 두드려 보는 것
순간접착제는 구멍 속 핀이 굳어 버려 수리가 훨씬 어려워집니다. / 기름도 한꺼번에 많이 넣으면 먼지가 엉겨 더 뻑뻑해집니다.
이런 시도는 하지 마시고 상태 그대로 두는 게 가장 도움이 됩니다.

# 연락할 때 말씀해 주실 것
전화로 몇 가지만 알려주시면 출발 준비가 빨라집니다.
- 신장동 아파트나 빌라 이름과 몇 층 몇 호인지
- 열쇠 조각이 밖으로 보이는지 안으로 들어갔는지
- 문 바깥에 번호판 도어락이 같이 있는지
- 열쇠가 부러지기 전에 뻑뻑했는지
- 집 안에 아이나 반려동물이 있는지
구멍 사진을 문자로 보내주시면 필요한 도구를 정확히 챙겨 갈 수 있습니다.

# 도착하면 사시는 분인지 확인합니다
먼저 거주자가 맞는지 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁해 보세요. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
세입자라도 사시는 분이면 문제없이 진행됩니다.

# 비용은 시작 전에 먼저 말씀드립니다
조각 상태와 문 종류를 보고 작업 전에 비용을 알려드립니다. / 동의하시면 시작하고, 아니라면 그대로 돌아갑니다.
조각을 못 빼고 문도 못 열면 비용은 받지 않습니다. / 구멍 부분 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에 적어 두었고, 문 여는 방법은 [현관문 개문](door-open.html)에서 볼 수 있습니다.
@ 신장동 24시 출장열쇠 부러진 열쇠 제거

# 부러지기 전에 막는 습관
열쇠가 평소 뻑뻑하다면 부러지기 전에 구멍을 점검받는 게 좋습니다. / 열쇠를 돌릴 때 힘이 많이 든다면 이미 한계에 가까운 상태입니다.
오래 쓴 열쇠는 새로 복사해 두고 헌 열쇠는 쓰지 않는 편이 안전합니다. / 열쇠고리가 무거우면 구멍이 한쪽으로 처져 닳기도 하니 열쇠꾸러미를 가볍게 하세요.
번호판 도어락을 함께 쓰면 열쇠에 의존하는 일이 줄어듭니다. / 설치를 고민한다면 [도어락 설치](doorlock-install.html)에서 확인해 보세요.

# 신장동 말고 오산 어디든 갑니다
신장동 옆 오산동, 원동, 궐동, 오산대역과 세마역 쪽 동네도 다닙니다. / [오산시 출장열쇠](osan.html)에 다니는 동네를 정리해 두었고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
