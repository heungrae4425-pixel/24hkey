# 신장동 부모님 댁, 요양보호사 방문이 시작되면
신장동은 오산역 일대와 가까운 생활권이라 부모님 댁을 가까이 모신 가족이 많습니다. / 거동이 불편해지면 요양보호사가 정해진 시간에 집을 찾아오게 되는데, 그때 가장 먼저 부딪히는 일이 문 앞입니다.
어르신이 문을 열어 드리기 어렵다면 비밀번호를 알려야 하고, 그러면 열쇠 관리 문제도 같이 생깁니다.
이 글은 [오산 출장열쇠](osan.html)가 정리한, 돌봄 인력이 오는 집의 도어락 관리 요령입니다.
@ 신장동 어르신 댁 현관 도어락과 방문 돌봄 안내 메모

# 어르신이 직접 열어 주기 어려운 시간이 생깁니다
요양보호사는 보통 정해진 요일과 시간에 옵니다. / 그 시간에 어르신이 낮잠을 주무시거나 화장실에 계시면 벨을 눌러도 응답이 늦어집니다.
처음엔 벨을 눌러 열어 주다가 점점 번호를 알려 주는 쪽으로 넘어가는 집이 많습니다. / 그때 번호를 어떻게 알려 주고 어떻게 정리할지 미리 정해 두는 편이 낫습니다.

# 가족 번호를 그대로 알려 주지 마세요
가장 흔한 실수는 가족이 쓰는 번호를 그대로 알려 주는 일입니다. / 번호 하나로 여러 사람이 드나들면 누가 언제 들어왔는지 구분이 되지 않습니다.
- 가족용 번호와 방문 인력용 번호를 따로 두기
- 방문 인력이 바뀔 때마다 번호도 새로 정하기
- 번호를 문자나 메신저에 오래 남기지 않기
이 세 가지만 지켜도 불필요한 걱정이 많이 줄어듭니다.

# 임시 번호를 지원하는 도어락이라면
도어락에 따라 임시 번호나 일회성 번호를 만들 수 있는 모델이 있습니다. / 기간이나 횟수를 정해 두면 그 시간이 지난 뒤 자동으로 막히는 방식입니다.
@ 도어락에 방문 인력용 임시 번호를 등록하는 모습
내 도어락이 이 기능을 쓸 수 있는지는 설명서나 제품 이름으로 확인하세요. / 모르겠으면 도어락 사진을 보내 주시면 기능 여부를 같이 봐 드립니다. 관리 방법은 [도어락 설치](doorlock-install.html) 쪽에도 적어 두었습니다.
임시 번호 기능이 없는 도어락이라면 번호를 하나 더 등록할 수 있는지 보세요. / 그것도 어렵다면 방문 인력이 바뀔 때마다 번호를 바꾸는 방법이 있습니다.

# 번호 전달은 말로, 가능하면 직접
메시지로 번호를 보내면 휴대폰 화면에 남고 다른 사람 눈에도 띕니다. / 처음 인사를 나누는 자리에서 직접 알려 주거나, 전화로 불러 주는 방식이 낫습니다.
번호를 알려 준 뒤에는 한 번 같이 눌러 열어 보게 하세요. / 열리지 않으면 방문 시간에 문 앞에서 한참 서 있게 됩니다.
시간대와 방문 요일도 함께 정해 두면 이상한 시간에 번호가 쓰였을 때 알아차리기 쉽습니다.

# 보조키와 걸쇠는 풀어 두세요
어르신이 밤에 걸어 둔 보조키를 아침에 풀지 않으면 번호를 눌러도 문이 열리지 않습니다. / 요양보호사가 문 앞에서 기다리게 되는 가장 흔한 이유입니다.
방문 시간 전에 보조키를 푸는 습관을 가족이 함께 챙겨 주세요. / 어려우시면 방문 시간대만이라도 안쪽 걸쇠를 걸지 않기로 정해 두는 것도 방법입니다.

# 어르신이 번호를 헷갈리실 때
번호를 자주 바꾸면 어르신이 잊어버려 직접 문 앞에서 막히는 일이 생깁니다. / 바꾸는 주기는 어르신이 기억하기 어렵지 않은 범위로 하는 게 좋습니다.
번호판 옆에 번호를 적어 두는 일은 하지 마세요. / 대신 가족 한 명이 어르신의 번호를 따로 기록해 두면 좋습니다.
지문이나 카드를 쓰는 도어락이라면 어르신께는 카드 하나를 목에 걸 수 있게 해 드리는 것도 방법입니다. / 번호 기억이 어려운 분께 부담이 덜합니다.
외출 후 돌아오실 때 번호가 기억나지 않아 문 앞에서 오래 서 계시는 경우가 의외로 많습니다. / 그런 일이 한 번이라도 있었다면 가족이 도어락 방식을 쉬운 쪽으로 바꾸는 상의를 해 보세요. 고르는 요령은 [도어락 교체](doorlock-replace.html) 안내에 있습니다.

# 돌봄 인력이 바뀔 때의 정리
기관에서 담당 요양보호사를 바꾸면 이전 담당자 번호는 지워야 합니다. / 번호를 지우지 않고 두면 나중에 관리하기 힘들어집니다.
- 담당이 바뀐 날 이전 번호 삭제
- 새 담당자용 번호 새로 등록
- 가족에게 바뀐 일정을 공유
등록과 삭제 방법을 모르면 전화 주세요. / [도어락 수리](doorlock-repair.html) 때 함께 알려 드립니다.

# 문 앞에서 문제가 생겼을 때
방문 시간에 요양보호사가 번호를 눌러도 열리지 않는 일이 있습니다. / 배터리가 약하거나 안쪽 보조키가 잠겼거나, 어르신이 안에서 응답이 없을 수도 있습니다.
요양보호사가 이런 일을 겪었을 때 누구에게 먼저 연락할지 가족이 미리 정해 두면 대응이 빨라집니다. / 가족 연락처, 가까운 이웃, 관리사무소 번호를 방문 인력에게 알려 두세요.
특히 어르신이 안에서 응답이 없다면 상황이 급할 수 있으니 먼저 가족에게 연락을 하게 하세요. / 응급 상황이 걱정되면 119에 먼저 연락하는 것이 우선입니다.
@ 신장동 현관문 앞에서 도어락 번호판 상태를 확인하는 모습

# 응급이 아닌데 문만 안 열릴 때
집 안이 안전한 걸 확인한 상태에서 문만 안 열린다면 [현관문 개문](door-open.html)을 요청하시면 됩니다. / 가족이 멀리 있어도 전화로 상황을 설명하고, 현장에서 사는 분이 맞는지 확인되면 진행합니다.
가족 대신 요양보호사가 전화를 주셔도 되지만, 신분 확인은 집 주인이나 가족이 해 주셔야 합니다.
어르신이 혼자 계신 집이라면 놀라지 않으시도록 가족이 미리 전화로 방문 사실을 알려 드리는 것이 좋습니다. / 낯선 사람이 문 앞에 서 있으면 어르신이 불안해하실 수 있기 때문입니다.
방문 인력이 여럿 번갈아 오는 집은 방문 일정표를 현관 안쪽 잘 보이는 곳에 붙여 두면 가족도 확인하기 편합니다. / 일정표에 번호는 적지 마세요.

# 문 열기 전에 신분을 확인합니다
어르신 댁이라고 확인 절차를 건너뛰지는 않습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나가 필요합니다.
가족이 멀리 있다면 관리사무소에 세대 확인을 요청하는 방법도 있습니다. / 이 절차는 어르신 댁을 지키기 위한 것입니다.

# 비용은 문을 열기 전에 먼저 말씀드립니다
상황을 보고 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 못 열면 비용은 받지 않습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다. / 이용 순서는 [이용안내](guide.html)에 정리했습니다.

# 신장동 말고 오산 어디든 갑니다
오산동, 원동, 궐동, 세교동, 대원동, 남촌동, 초평동, 수청동, 갈곶동까지 24시간 출동합니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.
