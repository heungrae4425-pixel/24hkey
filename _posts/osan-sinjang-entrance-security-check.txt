# 방범 점검, 겁먹을 일이 아니라 습관입니다
신장동은 오산역에서 가까워 출퇴근 동선이 길게 이어지는 생활권입니다. / 아침마다 서둘러 나가다 보면 문이 제대로 잠겼는지 한 번 더 확인하지 못하고 나올 때가 있습니다.
방범 점검이라고 하면 거창하게 들리지만 실제로는 몇 분이면 끝나는 확인입니다. / 이 글은 불안을 키우려는 글이 아니라, 집 문을 평소에 어떻게 살펴보면 좋은지 차분히 적은 것입니다.
문제가 생기기 전에 한 번씩 보는 것만으로도 도어락 고장 대부분은 미리 알아챌 수 있습니다. / 필요할 때만 [오산 출장열쇠](osan.html)를 부르시면 됩니다.
@ 신장동 현관 방범 점검 출장열쇠

# 점검은 문 안쪽에서 시작합니다
먼저 현관 안쪽에 서서 문 전체를 눈으로 훑어봅니다. / 도어락, 보조키, 걸쇠, 문틀 순서로 보면 빠뜨리는 곳이 없습니다.
손으로 문을 가볍게 밀어 보았을 때 덜컹거리거나 틈이 벌어지는 곳이 있는지 봅니다. / 평소와 다른 느낌이 있으면 메모해 두었다가 나중에 설명하시면 됩니다.

# 도어락이 보내는 신호를 읽어 보세요
도어락은 문제가 생기기 전에 작은 신호를 먼저 보냅니다. / 아래 같은 신호가 보이면 점검 시기라고 생각하시면 됩니다.
- 번호를 누를 때 반응이 늦거나 한두 번 씹히는 경우
- 잠글 때 모터 소리가 평소보다 길게 나는 경우
- 배터리 부족 안내음이 가끔 나오는 경우
- 손잡이를 돌릴 때 뻑뻑하거나 헛도는 느낌이 드는 경우
이런 신호를 몇 번 넘기다 보면 어느 날 갑자기 안 열리는 일로 이어집니다. / 신호가 보일 때 손보는 편이 시간도 덜 듭니다.

# 문틀과 걸쇠가 잘 맞물리는지 확인
문을 닫았을 때 걸쇠가 문틀 구멍에 깨끗하게 들어가는지 봅니다. / 걸쇠가 구멍 가장자리에 긁히는 소리가 난다면 문이 조금 처졌다는 뜻일 수 있습니다.
문과 문틀 사이 틈이 위아래에서 다르게 보이면 경첩 쪽을 의심해 볼 수 있습니다. / 이 경우는 도어락만 만져서는 해결되지 않아 문 전체를 같이 봐야 합니다.
@ 오산 열쇠집 신장동 문틀 걸쇠 점검

# 보조키는 쓰는 습관이 중요합니다
보조키가 달려 있어도 평소에 안 쓰면 소용이 없습니다. / 반대로 매번 잠그고 나가다 보면 열쇠를 어디 뒀는지 몰라 난처해지기도 합니다.
집에 있을 때 쓰는 잠금과 외출할 때 쓰는 잠금을 가족이 같이 정해 두면 헷갈리지 않습니다. / 특히 아이가 안에서 보조키를 돌려 잠그는 일이 잦다면 한 번 이야기해 두세요.

# 비밀번호는 눈에 띄는 곳에 적지 않기
번호를 현관 근처 메모지나 달력에 적어 두는 분들이 의외로 많습니다. / 편하긴 해도 누가 지나가며 볼 수 있으니 휴대폰 메모 잠금처럼 한 번 걸러서 보관하는 편이 낫습니다.
생년월일이나 전화번호 뒷자리처럼 남이 짐작하기 쉬운 번호는 바꿔 두면 좋습니다. / 바꾸는 방법은 제품 설명서에 있고, 어렵다면 [도어락 수리](doorlock-repair.html) 때 함께 안내받으실 수 있습니다.

# 외출 전 10초 체크 목록
거창하지 않은 확인 순서를 정해 두면 외출이 편해집니다. / 현관을 나서며 아래 순서만 떠올려 보세요.
- 문이 완전히 닫혔고 잠금 소리가 났는지
- 보조키나 걸쇠 상태가 내가 의도한 대로인지
- 열쇠, 카드키, 휴대폰을 챙겼는지
- 택배나 전단지가 문 앞에 쌓여 있지는 않은지
오래 집을 비울 때는 우편물과 택배가 쌓이지 않게 이웃이나 가족에게 부탁해 두는 것도 방법입니다. / 문 앞이 비어 있지 않다는 인상 자체가 불필요한 관심을 부르기 때문입니다.

도어락이 잘 작동하고 문이 반듯하게 닫힌다면 따로 손댈 필요가 없습니다. / 멀쩡한 제품을 불안한 마음에 바꾸는 것은 권하지 않습니다.
다만 오래 써서 동작이 불안정하거나 부품이 낡아 보이면 상담받아 보세요. / 고쳐 쓸 수 있는지 먼저 보고, 어려울 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

점검 기록을 남기는 것도 도움이 됩니다. / 휴대폰 메모에 배터리를 간 날짜, 비밀번호를 바꾼 날짜, 불편했던 증상을 짧게 적어 두면 나중에 설명하기 쉽습니다.
집 안 사람 모두가 같은 기준으로 문을 쓰는지도 확인해 보세요. / 한 사람만 문을 세게 닫거나 잠금을 어색하게 다루면 부품이 먼저 닳습니다.

# 열쇠를 복사해 둔 곳은 알아 두기
예전에 열쇠를 여러 개 만들어 이웃이나 친척에게 맡긴 경우가 있습니다. / 누구에게 맡겼는지 기억나지 않는다면 한 번 정리해 보는 것도 좋습니다.
이사 직후이거나 세입자가 바뀐 직후라면 이전 사용자의 번호와 열쇠가 남아 있을 수 있습니다. / 이럴 때는 번호를 지우고 새로 등록하는 것만으로도 마음이 훨씬 놓입니다.
@ 신장동 현관 도어락 비밀번호 정리

점검을 부탁하실 때는 불편했던 점을 짧게 알려주시면 충분합니다. / 문 사진이나 도어락 모양을 문자로 보내주시면 챙겨 갈 장비를 고르는 데 도움이 됩니다.
오산역 쪽인지, 세마역 쪽인지 정도만 알려주셔도 이동 계획을 세우기 쉽습니다. / 급하지 않은 점검이라면 방문 가능한 시간대를 같이 말씀해 주세요.

같은 방범 점검이라도 집마다 신경 쓸 곳이 다릅니다. / 1층이나 저층이라면 베란다 쪽 잠금도 같이 봐 두면 좋고, 고층이라면 현관 쪽만 챙겨도 충분한 경우가 많습니다.

# 방문하면 신분 확인부터 합니다
문을 여는 일이든 점검이든 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
이웃과 집주인 모두를 지키는 절차라 생략하지 않습니다. / 서류가 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

# 비용은 시작 전에 먼저 말씀드립니다
점검에서 손볼 곳이 나오면 어디를 어떻게 고치는지 설명드린 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하실 때만 작업하고, 아니면 그대로 돌아갑니다.
문이 잠겨 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에서도 보실 수 있습니다.

# 문이 이미 안 열릴 때는 현관문 개문으로
점검 중에 문이 갑자기 안 열리는 일이 생기면 억지로 힘을 주지 마세요. / 손잡이를 세게 당기거나 도구로 문틈을 벌리면 문과 도어락이 상할 수 있습니다.
최대한 흔적이 남지 않게 여는 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다. / 오산 어디든 24시간 연락 가능합니다.

# 신장동 밖 오산 다른 동네도 다닙니다
신장동 가까이 오산동, 원동, 대원동, 갈곶동, 세교동까지 모두 출동 범위입니다. / 오산 안이면 동네와 상관없이 전화 주시면 됩니다.
다니는 지역은 [출장 지역](area.html) 페이지에 지도로 정리되어 있습니다.

? 점검했는데 이상이 없으면 비용이 드나요? | 시작 전에 안내드린 내용대로만 진행합니다. 열쇠 개방을 못 한 경우에는 비용을 받지 않습니다.

? 임차인인데 점검을 맡겨도 되나요? | 사시는 분이라는 확인만 되면 가능합니다. 신분증이나 우편물을 준비해 주세요.
? 늦은 밤에도 전화해도 되나요? | 24시간 받습니다. 시간 걱정하지 말고 연락 주세요.
