# 새벽 문 앞에서 가장 힘든 건 시간이 아니라 조용함입니다
신장동은 오산역에서 걸어서 집으로 향하는 분들이 많은 동네입니다. / 막차를 타고 돌아와 문 앞에 섰는데 번호판이 꺼져 있으면 사방이 조용해 더 막막해집니다.
이웃이 잠든 시간이라 문을 두드리거나 소리를 낼 수도 없습니다. / 그렇다고 밖에서 밤을 지새울 수도 없어 마음이 급해집니다.
이 글은 한밤이나 새벽에 문이 안 열릴 때 안전하게 연락하고 기다리는 요령을 적었습니다. / 가능한 한 이웃에게 폐를 끼치지 않고 해결하는 방법에 맞췄습니다.
@ 신장동 한밤 귀가길 현관문 앞

# 우선 내 안전부터 확인하세요
늦은 시간에 낯선 복도에서 오래 서 있는 건 마음이 불편하고 위험할 수도 있습니다. / 조명이 어두우면 휴대폰 손전등을 켜 두세요.
혼자라면 가족이나 친구에게 지금 어디에 있는지 문자로 알려 두는 게 좋습니다. / 필요하면 통화를 이어 가면서 기다리는 방법도 있습니다.
건물 안이 춥다면 계단참처럼 바람을 피할 곳으로 옮기셔도 됩니다. / 다만 위치를 알려드린 곳에서 크게 벗어나지는 말아 주세요.

# 소리를 크게 내지 말고 번호판부터 눌러 보세요
한밤에 가장 흔한 원인은 배터리 방전과 번호 오입력입니다. / 번호판에 손바닥을 대어 불이 들어오는지부터 확인합니다.
불이 켜진다면 숫자를 천천히 한 번 더 눌러 보세요. / 급할수록 손이 틀려서 같은 실수를 반복하기 쉽습니다.
반응이 아예 없으면 바깥쪽 비상 단자에 9V 건전지를 대는 방법이 있습니다. / 한밤에 건전지를 구하기 어렵다면 무리하지 말고 연락 주세요.

# 해서는 안 되는 행동, 늦은 시간일수록 더 조심
급한 마음에 문을 발로 차거나 손잡이를 세게 당기는 분들이 있습니다. / 그러면 도어락이 상하고 이웃도 놀라게 됩니다.
카드나 드라이버로 문틈을 벌리는 것도 위험합니다. / 문틀과 도어락 외관이 상해 교체 비용이 더 커질 수 있습니다.
비밀번호를 여러 번 틀리면 입력이 잠시 막힐 수 있으니 서너 번 해보고 멈추세요. / 쉬는 것도 방법입니다.
- 문을 두드리며 소리 지르기
- 도구로 문틈을 억지로 벌리기
- 번호를 계속 반복해서 누르기
- 다른 집 문을 두드려 도움 구하기

# 한밤 통화는 이렇게 짧게 하셔도 됩니다
조용한 시간이라 통화가 길어지면 이웃에게 소리가 들릴 수 있습니다. / 말해야 할 건 위치와 번호판 상태, 집 안에 사람이나 동물이 있는지 세 가지뿐입니다.
통화가 어려우면 문자로 건물 위치와 도어락 사진을 먼저 보내셔도 됩니다. / 문자를 확인하고 전화드립니다.
상황을 짧게 정리하면 도착 시간도 정확히 알려드릴 수 있습니다. / 어디서 기다릴지도 함께 정하면 편합니다.
@ 신장동 새벽 출장열쇠 전화 상담

# 위치는 오산역과 같은 기준점으로 말씀해 주세요
밤에는 건물 표시가 잘 안 보여 설명이 어려운 경우가 많습니다. / 오산역에서 어느 방향인지, 눈에 띄는 큰길이 어느 쪽인지 알려주시면 찾기 쉽습니다.
- 가까운 역이나 큰길 기준 방향
- 건물 입구 모양과 층수
- 공동현관 비밀번호나 출입 방법
- 도착했을 때 문 앞에서 기다릴 수 있는지
공동현관이 잠겨 있으면 도착해도 들어갈 수 없으니 미리 알려주세요. / 도착 전에 연락을 드려 문 앞에서 만날 수 있게 맞춥니다.

# 집 안에 아이나 반려동물이 있다면 먼저 말씀해 주세요
한밤에 아이가 혼자 있거나 불을 켜 둔 상황이라면 순서가 달라집니다. / 이 한 가지는 어떤 사정보다 먼저 전달해 주세요.
문 너머로 조용히 말을 걸어 아이가 놀라지 않게 해주시면 도움이 됩니다. / 아이가 안쪽 잠금장치를 건드리지 않게 이야기해 주세요.
가스 불이나 전열기를 켜 두고 나왔다면 그것도 바로 말씀해 주세요. / 문을 여는 순서를 앞당겨 움직입니다.

# 한밤에도 신분 확인은 꼭 합니다
문을 여는 일이라 늦은 시간에도 사시는 분인지 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있는 경우에는 경비실에 세대 확인을 부탁해 보세요. / 한밤이면 관리사무소가 닫혀 있는 경우가 많아 대체 방법을 함께 찾아봅니다.
휴대폰에 저장된 고지서나 우편 사진이 확인 수단이 될 때도 있습니다. / 확인이 끝내 어렵다면 작업은 할 수 없는 점 양해 부탁드립니다.

# 비용은 한밤에도 열기 전에 말씀드립니다
늦은 시간이라고 해서 비용을 따로 숨기지 않습니다. / 도착해 문과 도어락을 본 뒤 얼마나 드는지 먼저 말씀드립니다.
괜찮다고 하실 때만 시작하고, 마음에 안 드시면 그대로 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하면 바꾸기 전에 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 작업은 이웃을 생각해 조용히 합니다
한밤에는 작은 소리도 복도에 크게 울립니다. / 도구를 내려놓을 때나 문을 다룰 때 소리가 나지 않게 신경 써서 작업합니다.
문을 상하지 않게 여는 방법부터 차례로 해보기 때문에 소음이 큰 작업은 거의 하지 않습니다. / 자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.
작업 시간이 길어질 때는 중간에 상황을 말씀드립니다. / 서두르지 않고 안전하게 진행합니다.

# 열고 난 뒤 오늘 밤 안에 해둘 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새것으로 바꿔 두어야 같은 일이 반복되지 않습니다.
비밀번호를 잊었다면 안쪽에서 새 번호를 등록하고 기존 번호는 지웁니다. / 지문이나 카드도 한 번씩 열어 보고 마무리합니다.
고장이 반복되는 도어락은 [도어락 수리](doorlock-repair.html)로 점검해 볼 수 있습니다. / 방식 자체를 바꾸고 싶다면 날이 밝은 뒤에 [도어락 교체](doorlock-replace.html)를 천천히 상의하세요.
@ 신장동 한밤 도어락 점검 후 마무리

# 새벽 귀가 전에 해두면 좋은 준비
늦게 들어오는 날이 많다면 몇 가지만 챙겨 두세요. / 작은 준비가 문 앞에서의 당황을 많이 줄여 줍니다.
- 비상용 9V 건전지를 가방에 하나 넣기
- 가족에게 귀가 시간 미리 알리기
- 휴대폰 충전 확인하고 나가기
- 도어락 배터리 교체 날짜를 적어 두기
특히 휴대폰이 꺼지면 연락 자체가 어려워집니다. / 외출 전에 충전 상태를 확인하는 습관이 가장 효과적입니다.

# 신장동 말고 오산 어디든 갑니다
신장동 옆으로 오산동, 원동, 궐동, 세교동, 대원동, 남촌동, 초평동, 수청동, 갈곶동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

24시출장열쇠는 가장 늦은 시간에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
