# 신장동에서 도어락을 바꾸려는데 부품이 안 맞는다면
오산역 쪽 생활권에 있는 신장동에서도 오래 쓴 도어락을 바꾸려는 분들이 꾸준히 계십니다. / 그런데 새 제품을 사 왔는데 문에 맞지 않아 헛걸음하는 경우가 생각보다 많습니다.
이유는 도어락 겉모양만 보고 고르기 때문입니다. / 정작 중요한 것은 문 안쪽에 박혀 있는 매립형 부품, 흔히 말하는 문 속 자물쇠 몸통의 규격입니다.
이 글은 신장동에서 도어락을 교체할 때 문 안쪽 부품 규격을 어떻게 확인하고 맞추는지, [오산 출장열쇠](osan.html)가 현장에서 어떻게 점검하는지를 정리했습니다.
@ 신장동 도어락 교체 전 문 안쪽 부품 확인

# 매립형 부품이 무엇인지부터
현관문 속에는 잠금장치의 몸통이 들어 있습니다. / 바깥에서 보이는 번호판이나 손잡이는 이 몸통에 연결된 부분일 뿐입니다.
몸통이 문 안에 파묻혀 있다고 해서 매립형이라고 부르며, 문을 새로 깎아 다시 맞추는 것은 가능한 한 피해야 합니다. / 그래서 기존 구멍 크기에 맞는 제품을 고르는 일이 중요합니다.
- 문 안에 들어간 몸통의 크기와 모양
- 문 두께
- 몸통과 손잡이를 잇는 축의 위치
- 데드볼트가 나오는 구멍과 문틀의 걸림판 위치

# 규격을 재는 기준 몇 가지
정확한 치수는 현장에서 재야 하지만 대략의 확인은 미리 하실 수 있습니다. / 줄자 하나와 휴대폰 카메라면 충분합니다.
문 옆면을 보면 몸통 앞판이 보이고 그 크기와 모양이 사각형인지 둥근 모서리인지 확인됩니다. / 문 두께는 문을 열고 문 옆면 가장자리를 재면 됩니다.
도어락 앞면에서 걸쇠 중심까지의 거리도 도움이 됩니다. / 이 값은 제품마다 달라서 사진과 함께 전해주시면 판단이 빨라집니다.

# 문 두께가 달라지면 생기는 일
문이 너무 얇은데 두꺼운 문용 제품을 달면 나사가 문 반대쪽으로 튀어나오거나 고정이 헐겁습니다. / 반대로 문이 두꺼운데 얇은 문용 제품을 달면 연결 축이 닿지 않아 손잡이가 헛돕니다.
사용 중인 도어락이 문 두께에 맞게 나온 제품인지 모른다면 상자나 안쪽 라벨을 확인해 보세요. / 라벨이 지워졌다면 문 두께를 재서 알려주시는 게 가장 확실합니다.
@ 신장동 현관문 두께와 구멍 간격 측정

# 같은 모양인데 안 맞는 경우
겉으로 보기엔 같은 모양인데 안쪽 몸통 규격이 다른 제품이 있습니다. / 이런 경우 구멍 위치가 달라 새로 뚫어야 하는 상황이 생기기도 합니다.
기존 구멍을 크게 넓히거나 새로 뚫으면 문이 약해지고 나중에 되돌리기 어렵습니다. / 가능하면 기존 구멍에 맞는 제품을 우선 찾습니다.
어쩔 수 없이 가공이 필요하다면 하기 전에 먼저 어디를 어떻게 건드리는지 설명드립니다. / 문의 안전과 외관에 영향이 있으니 사시는 분의 동의를 구하고 진행합니다.

# 번호키만 바꾸는지, 몸통까지 바꾸는지
번호판이나 손잡이만 새것으로 바꾸고 문 안쪽 몸통은 그대로 쓸 수 있는 경우가 있습니다. / 이때는 비용도 시간도 줄고 문이 덜 상합니다.
다만 몸통이 오래돼 걸쇠 힘이 약해졌거나 열쇠 구멍이 닳았다면 같이 바꾸는 편이 안전합니다. / 이 판단은 문을 열고 안쪽을 직접 봐야 정확합니다.
무조건 전부 바꾸라고 권하지 않습니다. / 쓸 수 있는 부분은 그대로 쓰는 방향으로 먼저 안내합니다.

# 보조키와 걸림판도 같이 봅니다
문 위나 아래에 보조키가 따로 있다면 그 위치와 간격도 확인해야 합니다. / 새 도어락의 크기가 보조키와 겹치거나 닿으면 문이 닫히지 않을 수 있습니다.
문틀 쪽에 붙은 걸림판 구멍이 어긋나 있으면 새 제품을 달아도 잠금이 거칠게 걸립니다. / 이때는 걸림판 위치를 살짝 조정하는 것으로 해결되는 경우가 많습니다.

# 교체 상담 전화에서 알려주시면 좋은 것
정확한 상담을 위해 몇 가지만 알려주세요. / 아는 만큼만 말씀하셔도 충분합니다.
- 지금 쓰는 도어락의 모양(손잡이형, 푸시풀형, 번호판 단독형)
- 제품 브랜드와 모델명(기기 안쪽이나 상자에 적힌 경우)
- 문 재질(철, 목재)과 대략의 두께
- 보조키가 있는지, 위치가 어디인지
- 새로 달고 싶은 방식(번호, 지문, 카드)
도어락 앞면과 옆면, 문 가장자리 사진이 있으면 상담이 훨씬 빨라집니다.

# 도착하면 사시는 분인지 확인합니다
교체를 하려면 먼저 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
세입자는 집주인 동의가 필요한 공사인지 미리 확인해 두시는 것이 좋습니다. / 법적 판단은 하지 않지만 문제가 생기지 않도록 계약서 내용을 한 번 살펴보시길 권합니다.

# 비용은 작업 전에 먼저 말씀드립니다
문 안쪽 부품을 확인한 뒤 어떤 작업이 필요한지 설명드립니다. / 비용도 그 자리에서 작업 전에 먼저 말씀드리고, 괜찮다고 하시면 시작합니다.
마음에 안 드시면 그냥 돌아갑니다. / 작업 중에 바꿀 부품이 새로 보이면 손대기 전에 다시 여쭤봅니다.
잠긴 문을 열어야 하는 상황이라면 못 열면 비용을 받지 않는 원칙은 그대로입니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 문 안쪽 부품 확인 작업이 이어지는 순서
현장에서는 문과 문틀 상태를 먼저 보고, 기존 도어락을 풀어 몸통을 꺼내 규격을 확인합니다. / 그다음 새 제품이 맞는지 대어 보고 고정합니다.
몸통과 손잡이를 잇는 축 길이가 맞는지, 데드볼트가 문틀에 정확히 들어가는지 확인합니다. / 이 순서를 지키면 설치 후 문이 덜 닫히는 일을 줄일 수 있습니다.
[도어락 설치](doorlock-install.html)와 [도어락 교체](doorlock-replace.html) 페이지에도 정리해 두었습니다.
@ 신장동 도어락 몸통 규격 비교 설치

# 설치 뒤 반드시 해 볼 것
설치가 끝나면 바로 문을 닫지 말고 아래를 확인합니다.
- 문을 열어 둔 채 열쇠나 번호로 걸쇠가 들락거리는지
- 문을 닫고 잠금이 한 번에 걸리는지
- 안쪽 손잡이와 보조키를 조작했을 때 부드러운지
- 번호 등록, 카드 등록, 경고음 설정이 제대로 됐는지
- 여분 열쇠나 비상 열쇠를 어디에 둘지 정했는지
도어락이 고장 나서 연락 주신 경우가 아니라면 [도어락 수리](doorlock-repair.html)로 해결되는지 먼저 살펴봅니다. / 고쳐 쓸 수 있으면 교체는 권하지 않습니다.

# 신장동 말고 오산 어디든 갑니다
신장동 가까이 있는 원동, 오산동, 궐동은 물론 세교동, 대원동, 남촌동, 초평동, 수청동, 갈곶동까지 오산 안이면 24시간 출동합니다. / 오산역, 오산대역, 세마역 쪽 어디서든 위치만 알려주세요.
다니는 동네는 [오산시 출장열쇠](osan.html), 다른 지역은 [출장 지역](area.html)에 있습니다.
