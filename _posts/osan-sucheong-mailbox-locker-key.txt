# 수청동에서 우편함이 안 열릴 때
오산 수청동은 아파트와 빌라, 오피스텔이 가까이 있어서 우편함이나 사물함 열쇠 문제로 연락 주시는 분도 가끔 있습니다. / 현관문처럼 급한 일은 아니지만 우편물이나 중요한 서류가 안에 있으면 마음이 급해집니다.
이 글은 우편함, 사물함, 작은 자물쇠 열쇠를 잃어버렸거나 안 열릴 때 먼저 확인할 것을 정리했습니다. / 그다음 [오산 출장열쇠](osan.html)가 어떤 순서로 도와드리는지 적었습니다.
공동 시설이라면 열기 전에 관리하는 분과 먼저 이야기해야 할 부분도 있으니 5번 항목을 꼭 읽어 주세요.
@ 수청동 우편함 사물함 열쇠 분실 출장열쇠

# 먼저 열쇠가 어디 있는지부터 찾아보세요
우편함 열쇠는 현관 열쇠와 따로 달려 있어 어디에 뒀는지 기억이 안 나는 경우가 많습니다. / 현관 근처 서랍, 가방 안쪽 주머니, 이사할 때 받은 열쇠 꾸러미를 먼저 찾아보세요.
이사 올 때 건네받은 열쇠 꾸러미에 우편함 열쇠가 따로 들어 있을 수 있습니다. / 집주인이나 전 입주자가 가지고 있을 수도 있으니 연락해 볼 만합니다.
열쇠에 번호나 호수가 적혀 있다면 어느 우편함 열쇠인지 확인하기 쉽습니다. / 번호가 지워졌다면 사진을 찍어 두시고 전화 주세요.

# 우편함 자물쇠 종류를 알아 두세요
우편함은 작은 원통형 자물쇠, 번호를 맞추는 자물쇠, 판을 밀어 여는 방식 등 여러 가지입니다. / 열쇠가 필요한 우편함은 대부분 작은 원통형 자물쇠를 씁니다.
번호를 맞추는 우편함은 번호를 잊어버린 경우가 문제입니다. / 이 경우 번호를 하나씩 돌려 맞춰 보는 방식으로도 열 수 있지만 시간이 걸립니다.
어떤 종류인지는 사진으로 보면 대부분 알 수 있습니다. / 우편함 전체와 자물쇠 부분을 두 장 찍어 보내 주세요.
@ 수청동 우편함 자물쇠 종류 확인

# 열쇠가 안 돌아가거나 걸릴 때
우편함은 밖에 노출돼 있어 먼지와 녹이 생기기 쉽습니다. / 열쇠가 들어가는데 돌아가지 않으면 안쪽 핀이 굳었을 가능성이 있습니다.
열쇠 구멍 전용 윤활제를 소량 쓰고 천천히 돌려 보세요. / 힘을 줘서 돌리면 열쇠가 부러져 박히는 일이 생깁니다.
한두 번 해 봐도 안 되면 더 시도하지 말고 전화 주세요. / 열쇠가 부러지면 열기가 훨씬 어려워집니다.

# 억지로 열려고 하지 마세요
우편함 문을 도구로 비틀어 열면 문이 휘어 닫히지 않거나 자물쇠가 망가집니다. / 공동으로 쓰는 우편함이라면 다른 세대 우편함까지 상할 수 있어 주의해야 합니다.
우편함이 부서지면 남의 우편물이 보이게 되거나 분실될 위험도 생깁니다. / 급하더라도 억지로 힘을 쓰기보다 방법을 먼저 정하는 것이 좋습니다.
우편함 안에 꼭 필요한 서류가 있다면 우체국이나 관리 주체와 연락하는 방법도 있습니다. / 상황에 따라 다른 길이 더 빠를 수 있습니다.

# 공동 시설이라면 관리하는 분과 먼저 이야기하세요
다가구 건물이나 오피스텔 우편함은 건물 관리하는 분이 따로 있는 경우가 많습니다. / 관리하는 분이 여분 열쇠를 갖고 있을 수도 있어서 먼저 물어보면 빨리 해결되기도 합니다.
관리하는 분이 우편함을 열어도 된다고 확인해 주셔야 하는 경우도 있습니다. / 그럴 때는 연락처를 알려 주시면 확인 후 진행합니다.
내 우편함인지 확인되지 않는 상태에서는 열 수 없습니다. / 이건 남의 우편물을 지키는 기본 절차입니다.

# 사물함이나 작은 자물쇠도 가능합니다
헬스장, 학원, 공용 보관함 같은 사물함 열쇠도 비슷하게 다룰 수 있습니다. / 다만 공용 시설은 운영하는 곳의 허락이 먼저 필요합니다.
개인이 산 자물쇠라면 본인 확인만 되면 진행하는 경우가 많습니다. / 자물쇠가 어디서 산 어떤 모양인지 사진을 보내 주세요.
작은 자물쇠는 열고 나서 새 자물쇠로 바꾸는 것이 간단한 경우가 많습니다. / 열쇠를 새로 만드는 것도 [출장 열쇠](key-call.html)에서 도와드립니다.

# 전화하기 전에 알려 주실 내용
우편함이나 사물함이 어디에 있는지, 어떤 모양의 자물쇠인지 알려 주세요. / 열쇠를 잃어버렸는지, 열쇠는 있는데 안 돌아가는지도 말씀해 주세요.
안에 들어 있는 물건이 급한지도 알려 주시면 일정을 정하기 쉽습니다. / 우편함 번호나 호수가 적혀 있으면 함께 알려 주세요.
공동 시설이라면 관리하는 분 연락처도 같이 알려 주세요. / 허락이 필요한 부분을 같이 확인하기 편해집니다.
@ 수청동 우편함 사물함 출장열쇠 상담

# 도착하면 먼저 사시는 분인지 확인합니다
우편함은 사시는 분 것이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소나 관리하는 분 확인 중 하나면 충분합니다.
번거롭게 느끼실 수 있지만 남의 우편물을 지키는 절차라고 생각해 주세요. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.
신분증이 집 안에 있다면 관리하는 분에게 확인을 부탁하는 방법도 있습니다. / 전화로 미리 안내해 드립니다.

# 비용은 시작하기 전에 말씀드립니다
자물쇠 종류와 상태를 보고 비용을 먼저 안내해 드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 작업 후에 말없이 붙는 비용도 없습니다.
자물쇠를 바꿔야 하면 바꾸기 전에 따로 여쭙니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 열고 난 뒤 새 열쇠와 자물쇠 정하기
우편함이 열리면 안에 있던 물건을 먼저 확인하시고, 자물쇠 상태를 함께 봅니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
열쇠를 잃어버렸다면 남이 가진 열쇠가 있을 수 있어 자물쇠를 새로 바꾸는 편이 안전합니다. / 열쇠를 복사해 두면 다음에 잃어버려도 대비할 수 있습니다.
번호식 자물쇠로 바꾸면 열쇠를 안 챙겨도 되지만 번호를 잊지 않아야 합니다. / 어떤 방식이 맞는지 상황을 보고 말씀드립니다.

# 우편함 열쇠 잃어버리지 않는 습관
현관 열쇠 꾸러미에 우편함 열쇠를 같이 달아 두면 따로 잃어버릴 일이 줄어듭니다. / 열쇠에 작은 이름표를 달아 두면 어느 열쇠인지 헷갈리지 않습니다.
여분 열쇠는 한 개 더 복사해 믿을 수 있는 곳에 보관해 두세요. / 여분을 집 밖 눈에 띄는 곳에 두는 것은 권하지 않습니다.
이사 나가기 전에 우편함 열쇠를 인계하는 것도 잊지 마세요. / 열쇠가 어디 있는지 모르는 일을 줄여 줍니다.

# 오산 안에서는 동네 가리지 않고 갑니다
수청동뿐 아니라 오산동, 원동, 궐동, 세교동, 신장동 등 오산 전 지역과 오산역, 오산대역, 세마역 쪽도 24시간 출동합니다. / 위치를 알려 주시면 도착 시간을 먼저 말씀드립니다.
오산 지역 정보는 [오산시 출장열쇠](osan.html), 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다. / 문 열기는 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
