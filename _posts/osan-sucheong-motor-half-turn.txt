# 수청동 도어락, 윙 소리만 나다 중간에 멈춘다면
수청동은 오산역과 오산대역을 이용하는 분들이 오가는 생활권에 있는 동네입니다. / 퇴근하고 번호를 눌렀는데 모터가 윙 하고 돌다가 중간에 멈추고 문이 안 열리면 당황스럽습니다.
번호판은 켜졌고 번호도 맞았는데 걸쇠가 반쯤 움직이다 말아 버리는 증상입니다. / 아예 아무 소리도 안 나는 고장과는 원인이 조금 다릅니다.
이 글은 모터가 반쯤 돌다 멈추는 증상의 원인을 순서대로 짚고, 전화 전에 해볼 것과 하지 말아야 할 것을 정리했습니다. / 오산 열쇠집을 부르기 전에 읽어 두시면 통화가 훨씬 쉬워집니다.
@ 수청동 도어락 모터 소리만 나고 멈추는 증상

# 반쯤 돌다 멈춘다는 것이 뜻하는 것
도어락 모터는 걸쇠를 끝까지 당겨야 문이 열립니다. / 중간에 멈춘다는 건 힘이 모자라거나 어딘가에 걸려 더 못 움직이는 상태라는 뜻입니다.
소리가 길게 나면서 천천히 느려지다 멈추는지, 짧게 윙 하고 바로 끊기는지 구분해 보세요. / 이 차이만으로도 원인을 어느 정도 좁힐 수 있습니다.
- 소리가 점점 느려지며 멈추는 경우: 배터리 힘이 모자란 쪽
- 짧게 윙 하고 끊기는 경우: 걸쇠가 문틀에 물려 있는 쪽
- 소리는 정상인데 걸쇠만 안 움직이는 경우: 내부 연결 부품 쪽

# 가장 흔한 원인은 약해진 배터리
번호판이 켜진다고 해서 배터리가 충분한 것은 아닙니다. / 불을 켜는 데 필요한 전력과 모터를 돌리는 데 필요한 전력은 다릅니다.
배터리가 거의 다 되면 번호판은 켜지는데 모터는 힘이 모자라 반쯤 돌다 멈춥니다. / 특히 추운 날에는 이런 증상이 더 자주 나옵니다.
이럴 때는 안쪽 배터리를 전부 새것으로 바꾸면 해결되는 경우가 많습니다. / 일부만 바꾸면 같은 증상이 며칠 안에 다시 나올 수 있습니다.

# 문을 살짝 밀면서 다시 눌러 보세요
걸쇠가 문틀 구멍에 꽉 물려 있으면 모터가 힘이 있어도 못 당길 수 있습니다. / 문이 약간 처졌거나 문틀이 틀어진 집에서 자주 생기는 일입니다.
문을 안쪽으로 살짝 밀거나 손잡이를 위로 들어 올리듯 하면서 번호를 다시 눌러 보세요. / 이때 걸쇠가 풀리며 열리는 경우가 있습니다.
힘을 세게 주면 오히려 걸쇠가 더 꽉 물립니다. / 살짝 압력을 주는 정도면 충분합니다.
@ 문을 살짝 밀면서 번호를 다시 누르기

# 비상 전원으로 힘을 보태 보기
바깥쪽 아래에 9V 건전지를 대는 단자가 있는 도어락이라면 건전지를 대고 번호를 눌러 보세요. / 안쪽 배터리가 약해 모터가 힘이 모자란 경우라면 이 방법으로 열리기도 합니다.
건전지는 편의점에서 구할 수 있습니다. / 건전지를 댄 채로 안 열리면 배터리 문제가 아닐 가능성이 큽니다.
문이 열리면 바로 안쪽 배터리를 모두 새것으로 바꿔 주세요. / 열린 김에 번호판과 걸쇠 소리도 한 번씩 확인해 두면 좋습니다.

# 같은 증상이 계속 반복될 때
배터리를 바꿨는데도 반쯤 돌다 멈추는 일이 반복된다면 내부 모터나 기어 쪽을 의심해야 합니다. / 오래 쓰면 모터 안의 작은 기어가 닳아 걸쇠를 끝까지 못 당기게 됩니다.
문틀과 걸쇠 위치가 맞지 않는 경우도 계속 반복됩니다. / 이때는 도어락만 손봐서는 해결되지 않고 문틀 쪽 보정이 필요할 수 있습니다.
- 배터리를 바꿔도 비슷한 증상이 반복
- 겨울이나 습한 날에만 심해짐
- 문을 닫는 방법에 따라 열릴 때와 안 열릴 때가 다름
이 셋 중 하나라도 해당하면 점검을 받아 보는 편이 안전합니다.

# 하지 말아야 할 것
소리가 난다고 계속 번호를 반복해서 누르면 모터에 무리가 갑니다. / 서너 번 시도해서 안 되면 멈추고 기다리세요.
손잡이를 세게 당기거나 문을 발로 차는 것은 절대 피해야 합니다. / 걸쇠가 더 꽉 물리거나 내부 부품이 부러져 상황이 커집니다.
드라이버로 도어락 외관을 열어 보는 것도 권하지 않습니다. / 나중에 보증이나 수리 때 오히려 곤란해질 수 있습니다.

# 전화하기 전에 알려 주실 것
증상이 반쯤 돌다 멈추는 경우라면 상황을 구체적으로 설명할수록 좋습니다.
- 모터 소리가 얼마나 났는지(길게, 짧게)
- 번호판 불이 어떻게 켜지는지
- 안쪽 배터리를 마지막으로 바꾼 시기
- 문 안쪽에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 맞는 부품을 챙겨 가기 좋습니다. / 안쪽에 아이가 있거나 불을 켜 둔 상황이면 꼭 먼저 말씀해 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

모터가 중간에 멈춘 문은 억지로 열면 오히려 걸쇠가 상할 수 있습니다. / 덜 상하는 방법부터 차례로 시도합니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다. / 문을 어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
@ 비파손으로 도어락 모터 점검하는 작업

# 비용은 문 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭙니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 고칠지 바꿀지는 상태를 보고 정합니다
모터나 기어가 문제라면 부품을 고쳐서 쓸 수 있는 경우가 많습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
같은 부품이 자꾸 닳거나 제품이 너무 오래됐다면 그때 교체를 말씀드립니다. / 자세한 내용은 [도어락 수리](doorlock-repair.html)와 [도어락 교체](doorlock-replace.html) 페이지에서 보실 수 있습니다.

# 재발을 줄이는 습관
배터리는 해가 바뀔 때 한 번에 새것으로 바꾸고, 경고음이 나면 미루지 마세요. / 문을 닫을 때 걸쇠가 문틀에 부드럽게 들어가는지도 가끔 보세요.
문이 뻑뻑하게 닫힌다면 경첩과 문틀 상태를 점검하는 것이 먼저입니다. / 비상용 9V 건전지 하나를 가방에 넣어 두는 것도 방법입니다.

# 수청동 말고 오산 어디든 갑니다
수청동 바로 옆 초평동, 갈곶동, 대원동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
오산에서 다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에, 다른 지역은 [출장 지역](area.html) 지도에 정리해 두었습니다.

? 배터리만 바꾸면 해결되나요? | 약한 배터리가 원인이라면 해결되는 경우가 많습니다. 반복되면 점검이 필요합니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.

? 문 열고 나서 도어락도 점검해 주시나요? | 네, 다시 잘 잠기고 열리는지까지 같이 확인합니다.
