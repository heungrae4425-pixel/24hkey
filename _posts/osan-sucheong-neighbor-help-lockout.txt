# 문이 잠기면 가장 가까운 사람은 이웃입니다
수청동에서 문이 잠겨 버렸는데 휴대폰도 집 안에 있다면 도움받을 곳은 가까운 사람뿐입니다. / 오산역에서 내려 집에 도착한 늦은 시간이라면 더 그렇습니다.
이웃에게 부탁하는 일은 멋쩍지만 가장 빠른 길이기도 합니다. / 문제는 어떻게 부탁해야 서로 불편하지 않느냐입니다.
이 글은 이웃이나 경비실에 도움을 구할 때의 순서와 예의를 정리했습니다. / 마지막에는 출장열쇠로 이어지는 흐름까지 적었습니다. / 열쇠를 잃어버린 경우의 안내는 [열쇠 출장](key-call.html)에도 있습니다.
@ 수청동 문 잠김 이웃 경비실 도움 요청

# 부탁하기 전에 스스로 확인할 것
이웃 문을 두드리기 전에 먼저 할 수 있는 일이 있습니다. / 문이 정말 잠긴 것인지, 번호판이 꺼진 것인지부터 보세요.
- 번호판이 꺼졌다면 건전지 비상 단자를 먼저 시도
- 안쪽에서 보조키가 잠겼을 가능성
- 가족 중 안에 있는 사람이 있는지
- 다른 출입구나 베란다로 들어갈 수 있는지는 무리하게 시도하지 않기
간단히 풀릴 일에 이웃을 깨우면 서로 미안해집니다. / 그래도 막혔다면 그때 부탁하시면 됩니다. / 부탁은 마지막 수단이 아니라 적절한 순서에서 하는 것입니다.

# 밤늦은 시간에는 경비실이 먼저입니다
아파트라면 경비실이 항상 열려 있는 경우가 많습니다. / 이웃 집 초인종을 누르기 전에 경비실부터 들러 보는 편이 예의에도 맞습니다.
경비 아저씨께는 동과 호수, 이름을 말씀드리고 상황을 짧게 알려 주세요. / 이웃 연락처나 관리사무소 연락 방법을 알려 주기도 합니다.
경비실이 없는 건물이면 이웃보다 건물 관리인이나 집주인이 연락될지 먼저 떠올려 보세요. / 빌라나 원룸은 관리 연락처가 현관에 붙어 있기도 합니다. / 공동현관 안쪽 게시판이나 우편함 근처를 한번 살펴보세요.

# 이웃에게는 이렇게 말을 꺼내세요
문을 두드린다면 몇 가지만 지켜도 훨씬 부드럽습니다. / 먼저 얼굴을 보이고 간단히 이름을 밝히세요.
이웃 몇 호에 사는 누구인지, 문이 잠겨 곤란하다는 이야기를 짧게 하는 것이 좋습니다. / 길게 설명하지 않아도 사정은 충분히 전해집니다. / 인터폰으로 먼저 말씀드리고 문을 열어 주실 때까지 기다리는 편이 놀라시지 않게 합니다.
- 어느 집에 사는 사람인지 먼저 알리기
- 전화 한 통만 빌릴 수 있는지 정중히 묻기
- 오래 신세 지지 않을 것이라고 말하기
- 끝나면 인사와 감사 한마디 남기기
@ 수청동 이웃에게 전화 빌리는 모습

# 집에 들이는 부탁은 하지 마세요
도움을 청할 때 경계해야 할 선이 있습니다. / 이웃 집에 오래 머물거나 물건을 맡기는 부탁은 되도록 피하세요.
전화 한 통을 빌리거나 잠깐 현관에서 기다리게 해달라는 정도가 적당합니다. / 한밤중이라면 현관 안으로 들어가는 것도 서로 조심스럽습니다.
계단이나 복도에서 기다리는 편이 서로 편한 경우가 많습니다. / 아이가 있는 집이나 어르신 혼자 사는 집은 더욱 조심스럽습니다.

# 휴대폰 없이 연락하는 법
전화번호는 외우고 있는 것이 거의 없어 막막합니다. / 가족 번호 하나는 외워 두시길 권합니다.
이웃 전화를 빌리면 24시출장열쇠 번호 010-3664-5455를 눌러 상황을 말씀해 주세요. / 이름과 호수, 어떤 상태인지만 알려 주시면 됩니다.
통화가 끝나면 이웃에게 곧 사람이 올 거라고 알려 두는 게 예의입니다. / 낯선 사람이 건물에 들어오는 것이 놀라울 수 있기 때문입니다.

# 출장 열쇠가 오기까지 기다리는 동안
도착까지 시간이 걸릴 수 있으니 안전한 곳에서 기다리세요. / 이웃 문 앞이나 계단에서 오래 서 있으면 서로 불편합니다.
공동현관 근처나 1층 편한 곳에서 기다리고 있다가 오시면 만나는 방식이 좋습니다. / 오시는 길을 문자로 알려 달라고 하면 맞춰 나갈 수 있습니다. / 이웃 전화로 연락한 경우에는 그 번호로 도착 소식을 드릴 수 있습니다.
기다리는 동안 문을 억지로 건드리지 않는 것이 중요합니다. / 손잡이를 흔들거나 번호를 계속 눌러 대면 오히려 잠금이 길어질 수 있습니다.

# 도착하면 신분부터 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
휴대폰도 신분증도 집 안에 있다면 경비실이나 관리사무소에서 세대 확인을 받아 주세요. / 이웃이 사는 사람임을 알려 주는 경우도 도움이 될 수 있습니다.
번거롭더라도 이웃 모두를 위한 절차입니다. / 확인이 안 되면 작업을 시작할 수 없으니 방법을 미리 생각해 두세요.

# 비용은 문을 열기 전에 먼저 말씀드립니다
문 상태를 보고 작업 내용과 비용을 먼저 말씀드립니다. / 하실지 말지는 사시는 분이 정하십니다.
문을 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 이유 없이 붙는 비용도 없습니다.
부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 이웃이 문을 열어 보겠다고 할 때
도와주려는 마음에 이웃이 공구로 문을 열어 보겠다고 하는 일도 있습니다. / 고마운 마음은 받되 문과 도어락을 상하게 하지 않도록 정중히 사양하는 편이 낫습니다.
잘못 건드리면 부품이 휘거나 걸쇠가 더 꽉 물립니다. / 나중에 이웃 사이에 문 고쳐 준 비용 문제로 서먹해질 수도 있습니다. / 마음만 받고 전문가를 부르는 쪽이 서로 깔끔합니다.
@ 수청동 현관문 24시 출장열쇠 개방

# 열린 뒤 이웃에게 남기는 인사
문이 열리면 도와준 이웃과 경비실에 한마디 인사를 남기세요. / 작은 음료나 짧은 메모만으로도 충분합니다. / 말 한마디가 가장 큰 보답입니다.
한밤중이었다면 다음 날 마주쳤을 때 다시 한번 감사를 전하면 좋습니다. / 이런 마음이 오가면 다음에 필요할 때도 서로 편해집니다. / 이웃끼리 비상 연락처를 주고받아 두는 것도 좋은 방법입니다.

# 같은 일이 반복되지 않게
문이 잠긴 일을 계기로 몇 가지는 정리해 두면 좋습니다. / 이웃에게 부탁하는 일이 잦아지면 서로 지칩니다.
- 현관 근처에 가족이 아는 비상 연락 방법 정하기
- 외출 때 열쇠와 휴대폰을 확인하는 습관 만들기
- 번호키라면 카드키 하나를 다른 곳에 보관
- 배터리 교체일을 메모해 두기
문 열기와 점검에 관한 내용은 [현관문 개문](door-open.html)에서 더 보실 수 있습니다.

# 수청동 말고 오산 어디든 갑니다
수청동 가까이 오산동, 원동, 궐동, 세교동, 신장동까지 다닙니다. / 오산 안이면 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 이웃이 대신 연락해도 되나요? | 네, 상황을 전해 주시면 됩니다. 다만 문을 열 때는 사시는 분 확인이 필요합니다.
