# 수청동에서 폰으로 열던 문이 어느 날 조용해졌다면
수청동은 오산대역과 오산역을 오가며 지내는 분이 많은 동네입니다. / 출퇴근길에 휴대폰만 대면 문이 열리는 도어락을 쓰던 분들이 어느 날 아무 반응이 없어 당황하곤 합니다.
어제까지 잘 되던 것이 오늘 갑자기 안 된다면 대개 이유가 있고, 하나씩 짚어 보면 꽤 많은 경우 문 앞에서 풀립니다. / 이 글은 스마트폰 NFC와 블루투스 열림이 안 될 때의 확인 순서를 정리한 것입니다.
그래도 안 열릴 때를 위해 [오산 출장열쇠](osan.html)를 부르는 방법도 뒤에 적었습니다.
@ 수청동 스마트폰 NFC 도어락 열림 안 될 때

# NFC와 블루투스는 방식이 다릅니다
NFC는 휴대폰을 도어락 가까이 대면 짧은 거리에서 인식하는 방식입니다. / 블루투스는 조금 떨어진 거리에서 앱과 연결해 열거나 알림을 주고받는 방식입니다.
두 방식은 고장 나는 이유도 다릅니다. / NFC는 대는 위치와 휴대폰 상태, 블루투스는 연결과 앱 권한에 영향을 많이 받습니다.
어느 쪽으로 쓰고 계신지 먼저 아는 것이 순서의 시작입니다. / 모르겠다면 평소 휴대폰을 어떻게 갖다 대는지 떠올려 보세요.

# 갑자기 반응이 없어지는 흔한 이유
- 휴대폰 운영체제를 업데이트한 뒤 앱 권한이 초기화된 경우
- 휴대폰 케이스에 카드나 금속 판을 같이 넣어 신호가 막힌 경우
- 휴대폰 NFC 기능이나 블루투스가 꺼진 경우
- 절전 모드가 앱을 백그라운드에서 멈춰 둔 경우
- 도어락 배터리가 약해져 통신 부분만 먼저 힘이 빠진 경우
이 중 앞의 네 가지는 휴대폰 쪽 문제이고, 마지막이 도어락 쪽 문제입니다. / 한쪽만 의심하지 말고 양쪽을 번갈아 확인하는 것이 좋습니다.

# 휴대폰 쪽부터 확인하는 순서
먼저 NFC와 블루투스 설정이 켜져 있는지 봅니다. / 그다음 도어락 앱을 열어 로그인 상태가 풀리지 않았는지 확인합니다.
앱 권한에서 근처 기기, 위치, NFC 허용이 꺼져 있지 않은지도 살펴보세요. / 업데이트 뒤에 조용히 꺼지는 일이 종종 있습니다.
절전 모드를 끄고 앱을 완전히 종료했다가 다시 켜 보는 것도 방법입니다. / 케이스에 카드가 들어 있다면 빼고 휴대폰 뒷면만 대어 보세요.
도어락 쪽 NFC 위치는 제품마다 달라서 번호판 한가운데일 수도 있고 가장자리일 수도 있습니다. / 천천히 위치를 바꿔 가며 대어 보면 반응하는 지점이 있습니다.

# 도어락 쪽에서 볼 것
번호판이 켜지는지, 버튼을 누를 때 소리가 나는지 먼저 봅니다. / 번호판이 어둡거나 반응이 느리면 배터리가 약해졌을 가능성이 있습니다.
배터리가 약하면 번호 입력은 되는데 통신만 불안정한 때가 있어서, 폰 문제로 오해하기 쉽습니다. / 안쪽 배터리를 새것으로 한 번에 바꾸면 해결되는 경우가 적지 않습니다.
휴대폰 인증이 실패하는 상황에서도 번호나 열쇠로 열 수 있는 도어락이 대부분입니다. / 평소 쓰지 않아도 비밀번호와 보조 열쇠는 따로 챙겨 두면 든든합니다.

# 하지 않는 편이 좋은 것
앱을 지우고 다시 깔았다가 도어락 등록 정보를 잃어 버리는 경우가 있습니다. / 등록을 다시 하려면 안쪽에서 해야 하는 제품이 많아 문밖에서는 곤란해집니다.
도어락을 초기화하는 버튼을 눌러 보는 것도 조심하셔야 합니다. / 등록된 번호와 카드까지 지워져 문을 열 방법이 더 줄어듭니다.
번호판을 두드리거나 강하게 누르는 것도 도움이 되지 않습니다.
@ 도어락 번호판과 휴대폰 인식 위치 확인

# 문 앞에서 막혔을 때 시간대별로 생각하기
퇴근 후 늦은 밤이라면 먼저 가족이나 같이 사는 분에게 안에서 열어 달라고 부탁할 수 있는지 봅니다. / 안에서 열 수 없는 상황이면 무리하지 말고 전화 주시는 편이 낫습니다.
낮 시간이라면 관리사무소에 보조 열쇠가 있는지 확인해 볼 수도 있습니다.
휴대폰 배터리가 얼마 남지 않았다면 먼저 충전을 하거나 연락처를 정리해 두세요. / 통화 도중에 꺼지면 위치 전달이 어려워집니다.

# 수청동에서 출장을 부를 때 알려주실 것
오산대역 쪽인지 오산역 쪽인지, 건물 입구에서 어느 방향인지 말씀해 주시면 도착이 빨라집니다.
- 어떤 방식으로 열던 도어락인지 (NFC, 블루투스, 앱)
- 번호판이 켜지는지, 소리가 나는지
- 번호를 눌렀을 때 반응이 어떤지
- 안쪽에서 문을 열어 줄 사람이 있는지
- 최근 휴대폰을 바꾸거나 업데이트했는지
도어락 사진을 보내 주시면 제품 종류를 알기 쉬워 장비를 맞춰 갑니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
휴대폰이 열쇠 역할을 하는 집이라면 휴대폰 속 앱 화면만으로는 확인이 어렵습니다. / 신분증을 따로 챙기는 습관을 들이면 이런 때 큰 도움이 됩니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
[이용안내](guide.html)에 진행 방식을 적어 두었습니다.

# 열고 난 뒤 연동 상태까지 맞춥니다
문이 열리면 배터리부터 확인하고, 필요하면 새 배터리로 바꿉니다. / 이후 NFC나 블루투스가 다시 인식되는지 같이 시험합니다.
앱 연결이 풀린 경우라면 안쪽에서 다시 등록하는 것을 도와드립니다. / 오래된 등록 정보는 정리하고 쓰는 것만 남기는 쪽이 안전합니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 통신 부분이 계속 불안정하면 [도어락 수리](doorlock-repair.html)를 먼저 보고, 그래도 어려우면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 도어락 앱 등록 상태 다시 확인하는 모습

# 폰으로 여는 집이 평소 해두면 좋은 것
- 비밀번호나 열쇠로 열 수 있는 수단을 하나 이상 남겨 두기
- 휴대폰을 바꾸기 전에 도어락 등록을 먼저 옮겨 두기
- 운영체제 업데이트 뒤에는 문 앞에서 한 번 시험해 보기
- 해가 바뀔 때쯤 배터리를 전부 새것으로 교체하기
- 가족 휴대폰도 같은 방식으로 등록해 두기
외출 전에 휴대폰만 들고 나가지 말고 보조 수단이 어디 있는지 한 번 떠올려 보세요. / 이런 습관 하나가 밤늦은 호출을 크게 줄여 줍니다.

# 수청동 말고 오산 어디든 갑니다
수청동 주변 초평동, 오산동, 원동, 갈곶동 등 오산 안이면 24시간 출동합니다. / 오산에서 다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에 있습니다.
다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
