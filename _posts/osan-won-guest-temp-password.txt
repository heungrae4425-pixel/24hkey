# 원동 집에 다른 사람이 들어와야 할 때
집을 비운 사이 가사도우미가 오거나, 돌봄 인력이 아이를 맞이하거나, 친구가 며칠 머물러야 하는 일이 있습니다. / 원동에서도 이럴 때마다 열쇠를 복사해 주는 것이 마땅치 않아 도어락 번호를 알려줘야 할지 고민하는 분이 많습니다.
번호를 그대로 알려주면 편하지만 그 뒤가 문제입니다. / 한 번 알려준 번호가 언제까지 쓰일지 정하지 않으면 불안이 오래 남습니다.
이 글은 임시로 번호를 주는 방법과 끝난 뒤 정리하는 순서를 적은 것입니다. / 이미 번호를 준 상태라면 7번부터 보셔도 됩니다.
@ 원동 도어락 임시 비밀번호 출장열쇠 24시

# 번호를 그대로 알려주기 전에 생각할 것
내가 쓰는 번호를 그대로 알려주면 나중에 그 번호를 바꾸기 전까지는 누구나 들어올 수 있습니다. / 아무리 믿는 사람이라도 번호가 다른 사람에게 다시 전달될 수 있습니다.
가능하다면 나만 쓰는 번호와 손님에게 주는 번호를 따로 두는 것이 가장 안전합니다. / 이를 지원하는 제품이면 별도 번호를 만들어 쓰시면 됩니다.
제품이 번호를 하나만 저장한다면 알려준 번호를 끝나는 날 바로 바꾸는 방식으로 관리하셔야 합니다. / 이 경우에는 약속을 정해 두는 것이 중요합니다.

# 도어락마다 번호를 따로 만들 수 있는지 확인하세요
요즘 도어락은 번호를 여러 개 저장하는 제품이 많습니다. / 사용설명서나 제품 이름을 알면 몇 개까지 저장되는지 찾아볼 수 있습니다.
지문, 카드, 번호가 함께 되는 제품이라면 손님에게는 카드나 번호만 주고 지문은 가족만 쓰게 나눌 수 있습니다. / 이렇게 나누면 정리하기가 훨씬 편합니다.
어떤 제품인지 모르겠다면 도어락 사진을 보내주세요. / 어떤 설정이 가능한지 같이 확인해 드립니다.

# 기간이 정해져 있다면 이렇게 하세요
며칠만 머무는 손님이라면 도착하는 날 새 번호를 만들어 알려주고, 떠나는 날 바로 지우세요. / 날짜를 달력에 적어 두면 잊지 않습니다.
가사도우미나 돌봄 인력처럼 정기적으로 오는 경우에는 방문 요일과 시간을 정해 두세요. / 그 시간 외에 번호가 쓰였다면 이상한 일이니 바로 알 수 있습니다.
번호를 알려준 사람에게는 다른 사람에게 알려주지 않기로 먼저 약속을 받아 두세요. / 서로 확인하는 과정이 오해를 막아 줍니다.
@ 원동 도어락 번호 관리 임시 비밀번호

# 쉬운 번호는 피하세요
생일, 전화번호 뒷자리, 1111처럼 단순한 번호는 피하는 것이 좋습니다. / 손님에게 주는 번호일수록 오히려 기억하기 쉬운 번호를 정하려는 경향이 있어서 더 조심해야 합니다.
이미 쓰고 있는 번호와 비슷한 숫자도 권하지 않습니다. / 앞뒤만 바꾼 번호는 쉽게 추측됩니다.
번호를 알려줄 때는 문자나 메신저 대신 말로 전달하는 것이 좋습니다. / 문자는 기록이 남아 다른 사람이 볼 수 있기 때문입니다.

# 번호가 안 맞을 때 당황하지 마세요
손님이 도착했는데 번호를 눌러도 안 열린다는 연락이 오는 경우가 있습니다. / 숫자 하나를 잘못 알려준 경우가 가장 흔합니다.
번호를 여러 번 틀리면 도어락이 일정 시간 입력을 막기도 합니다. / 이때는 잠시 기다렸다가 다시 눌러 보게 해주세요.
번호가 맞는데도 안 열린다면 도어락 배터리나 모터 문제일 수 있습니다. / 억지로 열려고 하지 말고 연락 주세요.

# 끝난 뒤에는 꼭 번호를 지우거나 바꾸세요
방문이 끝나면 임시로 준 번호를 바로 삭제하거나 새 번호로 바꿔 주세요. / 이 과정을 미루면 정리하기 어려워지고 잊게 됩니다.
도어락마다 번호를 삭제하는 방법이 다르니 처음 번호를 만들 때 삭제 방법도 함께 확인해 두세요. / 설명서가 없다면 제품 이름을 알려주세요.
번호를 바꾼 뒤에는 가족에게도 알리는 것을 잊지 마세요. / 가족이 모르는 사이 번호가 바뀌면 문 앞에서 막히는 일이 생깁니다.
@ 원동 도어락 비밀번호 변경 열쇠집

# 이미 번호를 준 상태에서 불안할 때
번호를 알려준 뒤 불안해졌다면 지금이라도 바꾸시면 됩니다. / 이유를 설명하기 곤란하더라도 번호를 바꾸는 것은 집주인의 권리입니다.
문 앞에 처음 보는 사람이 오래 서 있거나 낯선 사람이 번호를 눌러 보려는 느낌이 들었다면 더 빨리 바꾸세요. / 의심이 들면 바로 바꾸는 편이 마음이 편합니다.
번호를 바꾸는 방법을 모르겠다면 전화로 안내를 받으실 수 있습니다. / 현장에서 설정까지 도와드릴 수도 있습니다.

# 번호가 바뀌었는데 나도 모를 때
가족 중 누군가 번호를 바꿔 놓고 알려주지 않은 경우에도 문 앞에서 열리지 않을 수 있습니다. / 먼저 가족에게 연락해 보세요.
아무도 바꾼 적이 없다고 한다면 도어락 설정이 초기화되었거나 배터리 문제일 수 있습니다. / 이때는 현장 확인이 필요합니다.
[현관문 개문](door-open.html) 페이지에 열기 방식과 진행 순서를 적어 두었습니다. / 비파손 개방을 먼저 시도합니다.

# 이럴 때는 출장열쇠를 부르세요
번호는 맞는데 안 열리거나 번호를 바꾸는 방법을 몰라서 문 앞에서 막혔을 때 연락 주세요. / 원동 전 지역과 오산 어디든 24시간 출동합니다.
[오산 출장열쇠](osan.html) 페이지에서 다니는 동네를 확인하실 수 있습니다. / 위치와 도어락 모양만 알려주세요.
손님이 문 앞에서 기다리는 상황이라면 더 서둘러 출동합니다. / 상황을 먼저 말씀해 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
손님이나 도우미가 문 앞에서 연락한 경우에도 사시는 분이 맞는지 확인합니다. / 집주인이나 거주자가 직접 확인해 주셔야 합니다.
신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다. / 이런 절차는 이웃과 의뢰하신 분 모두를 위한 것입니다.
확인이 어려우면 작업을 진행하지 못합니다. / 자세한 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 번호 변경이나 설정만 도와드리는 경우에도 먼저 안내해 드립니다.

# 번호를 오래 안전하게 쓰는 습관
정기적으로 번호를 바꾸는 습관을 들이면 걱정이 줄어듭니다. / 달력에 변경할 날을 적어 두면 잊지 않습니다.
가족이 쓰는 번호와 손님이 쓰는 번호를 분리하면 관리가 쉽습니다. / 제품이 지원하지 않는다면 [도어락 교체](doorlock-replace.html)를 고민해 볼 수 있습니다.
고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 손보는 것을 권합니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 원동 24시 출장열쇠 도어락 번호 010-3664-5455
