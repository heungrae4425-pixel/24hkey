# 원동에서 도어락 출입 기록을 찾아보게 되는 때
오산 원동에서 오산역 쪽으로 오가며 사는 가족이라면 아이가 학원에서 돌아왔는지, 부모님이 외출에서 들어오셨는지 궁금한 날이 있습니다. / 전화를 안 받을 때 도어락에 남은 출입 기록이 단서가 되기도 합니다.
요즘 도어락은 문이 열린 시각을 저장해 두는 제품이 많습니다. / 다만 제품마다 보는 방법이 달라서 막상 필요할 때 어디를 눌러야 하는지 몰라 헤매는 분이 많습니다.
이 글은 원동 가정에서 출입 기록 기능을 어떻게 확인하고 쓰는지, 기록이 이상할 때는 무엇을 점검하는지 순서대로 적었습니다. / 문이 안 열리거나 기록 때문에 도어락이 오작동하는 느낌이면 [오산시 출장열쇠](osan.html)로 연락 주셔도 됩니다.
@ 원동 도어락 출입 기록 확인 화면

# 출입 기록 기능은 어떤 도어락에 있나
모든 도어락에 기록 기능이 있는 것은 아닙니다. / 번호만 누르는 기본형은 기록이 없고, 앱 연동형이나 일부 지문·카드 겸용 제품에 들어 있습니다.
- 앱에 연결해 휴대폰으로 기록을 보는 제품
- 도어락 본체 버튼으로 최근 기록을 소리나 화면으로 알려주는 제품
- 사용자별로 번호나 카드를 구분해 누가 열었는지 남기는 제품
- 기록 기능이 아예 없는 기본형 제품
가지고 계신 제품이 어느 쪽인지는 설명서나 제품 뒷면 모델명으로 확인할 수 있습니다. / 모델명을 모르겠으면 사진을 찍어 보내 주셔도 대략 알려드립니다.

# 기록으로 알 수 있는 것과 알 수 없는 것
기록은 문이 언제 어떤 방식으로 열렸는지 정도를 보여줍니다. / 번호로 열렸는지, 카드로 열렸는지, 안쪽 손잡이로 열렸는지가 구분되는 제품도 있습니다.
반대로 기록만으로 누가 들어왔는지 단정할 수는 없습니다. / 가족이 같은 번호를 함께 쓰면 누구의 출입인지는 따로 알 수 없기 때문입니다.
그래서 귀가 확인이 목적이라면 가족마다 다른 카드나 사용자 번호를 등록해 두는 편이 훨씬 정확합니다. / 한 번호를 돌려 쓰는 집은 기록이 있어도 활용도가 떨어집니다.

# 앱으로 확인할 때 먼저 볼 것
앱 연동형은 도어락과 휴대폰이 같은 공유기 또는 연결 장치에 묶여 있어야 기록이 올라옵니다. / 기록이 비어 있다면 앱이 고장났다고 생각하기 전에 연결 상태부터 보세요.
- 도어락 연결 장치의 전원 램프가 켜져 있는지
- 집 공유기가 최근에 바뀌거나 비밀번호가 바뀌지 않았는지
- 앱이 로그아웃되어 있지 않은지
- 휴대폰 알림 권한이 꺼져 있지 않은지
이 네 가지 중 하나만 틀어져도 기록이 늦게 오거나 아예 안 옵니다. / 연결이 끊긴 동안 열린 기록은 나중에 한꺼번에 들어오는 제품도 있어 시간이 뒤섞여 보일 수 있습니다.

# 본체에서 직접 기록 확인하는 순서
앱이 없는 제품은 본체 설정 모드에서 기록을 듣거나 볼 수 있는 경우가 있습니다. / 보통 관리자 번호나 설정 버튼을 먼저 누르는 방식입니다.
설정 모드에 들어가는 방법은 제품마다 다릅니다. / 잘못 누르면 기존 번호가 초기화되는 제품도 있으니 설명서 없이 이것저것 눌러 보는 것은 피해 주세요.
어떤 버튼이 기록 확인인지 모르겠으면 전화로 모델명을 알려주시면 순서를 말씀드립니다. / 번호 초기화가 걱정되는 분은 먼저 현재 번호를 메모해 두면 안전합니다.
@ 원동 도어락 본체 설정 버튼 확인

# 기록 시각이 실제와 다를 때
기록에 찍힌 시각이 어긋나 있으면 도어락 내부 시계가 맞지 않는 것입니다. / 배터리를 오래 비워 두었다가 갈면 시계가 초기 상태로 돌아가는 제품이 있습니다.
시계를 다시 맞추는 메뉴가 있는 제품도 있고 앱으로 자동 동기화되는 제품도 있습니다. / 둘 다 안 되는 기본형이라면 기록 시각은 참고용으로만 보셔야 합니다.
배터리를 교체한 직후에는 기록 시각부터 한 번 확인해 두면 나중에 헷갈리지 않습니다. / 이 작은 확인이 귀가 파악의 신뢰도를 좌우합니다.

# 아이와 부모님 귀가 확인에 쓸 때 정할 약속
출입 기록은 편하지만 가족끼리 서로 감시하는 느낌이 들면 오래 못 갑니다. / 처음부터 무엇을 보고 언제 확인하는지 가족이 함께 정해 두는 것이 좋습니다.
아이에게는 도착하면 기록이 남는다는 정도만 알려 주면 충분합니다. / 부모님께는 걱정을 덜기 위한 용도라고 설명드리면 거부감이 줄어듭니다.
기록을 본 뒤에 바로 연락해야 하는 기준도 미리 정해 두면 불안이 줄어듭니다. / 예를 들어 약속한 시간이 한참 지나도 기록이 없을 때만 전화한다는 식입니다.

# 번호 하나를 같이 쓰면 기록이 의미 없어집니다
가장 흔한 실수가 모두가 같은 번호를 쓰는 것입니다. / 이 경우 기록에는 번호로 열었다는 사실만 남아 누가 들어왔는지 알 수 없습니다.
가족 구성원마다 번호를 따로 등록하거나 아이에게는 카드를 따로 주는 방법이 있습니다. / 어떤 제품은 사용자 번호를 여러 개 등록할 수 있어 이 방법이 가장 간단합니다.
등록할 수 있는 개수는 제품마다 다르니 먼저 확인이 필요합니다. / 등록과 변경은 [도어락 설치](doorlock-install.html) 때 같이 정리해 두는 분도 많습니다.

# 기록 확인 중 도어락이 안 열릴 때
기록을 보려고 설정을 만지다가 그 뒤로 번호가 안 먹는 경우가 있습니다. / 설정 모드가 그대로 남아 있거나 번호가 초기화되었을 가능성이 있습니다.
이럴 때는 번호를 여러 번 반복해서 누르지 마세요. / 오입력이 쌓이면 도어락이 잠시 입력을 막아 더 오래 기다려야 합니다.
번호판이 꺼져 있으면 배터리, 소리만 나면 모터나 걸쇠 쪽을 의심해 볼 수 있습니다. / 상황이 정리되지 않으면 [현관문 개문](door-open.html) 안내를 보시고 전화 주세요.

# 신분 확인 후에 진행합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
가족이 출입 기록 때문에 다투다 문을 못 열게 된 경우처럼 사정이 복잡해도 절차는 같습니다. / 사시는 분임이 확인되면 진행합니다.
비용은 문을 열기 전에 먼저 말씀드리고 동의하시면 시작합니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
@ 원동 출장열쇠 신분 확인과 개문 작업

# 기록 기능이 필요하면 교체를 생각해 볼 때
지금 도어락에 기록 기능이 없는데 필요해졌다면 교체를 고민하게 됩니다. / 다만 필요한 기능이 정말 기록뿐인지 먼저 따져 보는 것이 좋습니다.
사용 인원, 문 두께, 보조키 유무에 따라 맞는 제품이 달라집니다. / 비교 포인트는 [도어락 교체](doorlock-replace.html) 안내에 정리해 두었습니다.
고쳐 쓸 수 있는 고장이라면 교체를 권하지 않고 [도어락 수리](doorlock-repair.html)부터 말씀드립니다. / 교체는 마지막 선택지로 두고 있습니다.

# 기록을 오래 믿고 쓰기 위한 관리
기록 기능은 배터리가 약하면 저장이 누락될 수 있습니다. / 경고음이 나면 그날 바로 새 배터리로 바꿔 주세요.
- 배터리는 한 번에 모두 새것으로 교체
- 교체 후 시각 맞는지 확인
- 앱 연결 장치 전원 상시 유지
- 가족 번호와 카드는 정기적으로 정리
오산역, 오산대역, 세마역 생활권을 오가는 가족일수록 귀가 시간이 제각각이라 기록이 정확해야 도움이 됩니다. / 작은 점검 몇 가지로 기록의 쓸모가 크게 달라집니다.

# 원동 말고 오산 어디든 갑니다
원동 옆 오산동, 궐동, 세교동, 신장동, 대원동, 남촌동, 초평동, 수청동, 갈곶동도 다닙니다. / 오산 안이면 동네와 상관없이 24시간 연락받습니다.
다니는 동네는 [오산시 출장열쇠](osan.html) 페이지에, 그 밖의 지역은 [출장 지역](area.html) 지도에 정리해 두었습니다. / 전화 주실 때 위치와 도어락 모양을 같이 알려주시면 빠릅니다.

? 기록으로 누가 들어왔는지 알 수 있나요? | 가족마다 번호나 카드를 따로 등록했을 때만 구분됩니다. 한 번호를 같이 쓰면 알 수 없습니다.
? 기록이 앱에 안 올라오는데 고장인가요? | 먼저 연결 장치 전원, 공유기, 앱 로그인 상태를 확인해 보세요. 그래도 안 되면 문의 주세요.
? 기록 보려고 만지다가 번호가 안 먹어요. | 번호를 반복 입력하지 마시고 전화 주세요. 문을 못 열면 비용은 받지 않습니다.
? 출장 오면 신분 확인은 어떻게 하나요? | 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
