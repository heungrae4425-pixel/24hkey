# 번호가 갑자기 생각나지 않을 때
평소엔 손이 알아서 누르던 번호가 오늘따라 떠오르지 않는 날이 있습니다. / 원동 집 앞에서 몇 번을 눌러도 삑 소리만 난다면 먼저 마음부터 가라앉히세요.
이 글은 오산 원동에서 도어락 비밀번호를 잊었거나, 가족이 몰래 바꾼 줄도 모르고 있을 때 어떻게 하면 좋은지 정리한 글입니다. / 문을 여는 순서와 열고 난 뒤 새 번호를 정하는 방법까지 함께 적었습니다.
@ 원동 도어락 비밀번호 분실 출장열쇠

# 틀리기 전에 먼저 멈추세요
번호를 계속 틀리면 도어락이 몇 분 동안 입력을 막아 버립니다. / 어떤 모델은 여러 번 틀리면 경보음이 울리기도 해서 이웃에게 민망해질 수 있습니다.
서너 번 눌러 보고 아니라면 한 번 숨을 고르고 생각해 보세요. / 이때 오른손잡이는 오른손 약지로, 왼손잡이는 반대로 눌러 보는 등 평소 누르던 손 모양을 떠올리면 기억나기도 합니다.

# 번호가 생각나지 않는 흔한 이유
- 새 도어락으로 바꾼 지 얼마 안 돼 손에 익지 않았다
- 가족 중 누군가 번호를 바꾸고 알려주지 않았다
- 임시 비밀번호를 만들어 두고 원래 번호로 착각했다
- 오랜만에 집에 오거나 장기간 출장 후 돌아왔다
가족이 바꾼 경우라면 전화 한 통으로 해결되는 일도 많습니다. / 연락이 닿지 않거나 알려줄 사람이 없을 때 출장열쇠를 부르시면 됩니다.

# 가족에게 먼저 물어보세요
같이 사는 가족이나 룸메이트에게 먼저 번호를 물어보세요. / 문자나 메신저에 예전에 보낸 번호가 남아 있을 수도 있습니다.
카드키나 지문으로도 열리는 모델이라면 그쪽으로 시도해 보세요. / 보조 열쇠가 어디 있는지도 가족과 함께 떠올려 보시면 좋습니다.
@ 오산 원동 비밀번호 도어락 문 열기

# 번호 힌트를 메모하는 방법
열고 나서 새 번호를 정할 때는 남이 알아도 모르는 방식으로 힌트를 남기세요. / 번호를 그대로 쓰지 말고 '엄마 생일 앞자리' 같은 단서만 따로 적어 두는 식입니다.
휴대폰 메모장 잠금 폴더에 보관하는 방법도 있습니다. / 종이에 적어 현관 근처에 붙여 두는 것은 가장 위험하니 피해 주세요.

# 출장열쇠를 부르는 순서
전화 주시면 원동 위치, 층수, 도어락 모양을 먼저 여쭙니다. / 도어락 사진을 문자로 보내 주시면 맞는 장비를 챙겨 가기 좋습니다.
도착 전에 대략 걸리는 시간과 진행 방식을 먼저 말씀드립니다. / 집에 아이나 반려동물이 있다면 꼭 먼저 말씀해 주세요.
급하면 [오산 출장열쇠](osan.html) 페이지에서 지역을 확인하시고 바로 전화 주셔도 됩니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 한 가지면 됩니다.
비밀번호를 잊어서 연 경우에는 특히 꼼꼼히 확인합니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 최대한 안 상하게 엽니다
비밀번호만 잊은 경우에는 도어락을 망가뜨리지 않고 여는 방법을 우선 씁니다. / 문틀과 도어락 외관이 상하지 않는 것이 먼저입니다.
방법은 도어락 종류에 따라 달라서 현장에서 보고 정합니다. / 자세한 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.
@ 원동 도어락 열고 새 번호 등록

# 열고 난 뒤 새 번호 등록
문이 열리면 안쪽에서 기존 번호를 지우고 새 번호를 등록합니다. / 옛 번호가 남아 있으면 같은 일이 반복되고 보안에도 좋지 않습니다.
새 번호는 생일이나 전화번호 뒷자리처럼 남이 짐작하기 쉬운 것은 피하세요. / 가족과 함께 정하고 오래 쓸 번호로 정리해 두는 것이 좋습니다.

# 번호가 자주 헷갈린다면 방식을 바꾸세요
번호를 자꾸 잊는다면 지문이나 카드키가 함께 되는 도어락도 한 방법입니다. / 번호를 기억하지 않아도 되니 편해지는 분이 많습니다.
고장이 잦은 도어락이면 먼저 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 봅니다. / 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 원동 말고 오산 어디든 갑니다
원동 바로 옆 오산동, 궐동, 신장동, 대원동, 세교동, 남촌동도 다닙니다. / 오산 안이면 동네 상관없이 24시간 출동합니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

# 자주 묻는 질문
? 비밀번호를 완전히 잊었는데 문을 열 수 있나요? | 네, 사시는 분인지 확인되면 도어락을 최대한 상하지 않게 열어 드립니다.
? 열고 나서 번호도 바꿔 주시나요? | 네, 기존 번호를 지우고 새 번호를 등록하는 것까지 같이 합니다.
? 가족이 바꾼 번호를 모를 때도 부르면 되나요? | 가족과 연락이 안 될 때 부르시면 됩니다. 사시는 분인지는 확인합니다.
? 못 열면 비용이 드나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤에도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
