# 공사 소리가 시작되기 전에 현관부터
원동에서 집 안을 고치기로 하셨다면 철거 날짜가 잡히기 전에 현관문을 한 번 보시길 권합니다. / 오산역에서 가까운 생활권이라 오래된 집을 손보는 분들이 많은 동네입니다.
공사가 시작되면 사람이 계속 드나들고 먼지와 자재가 현관 앞에 쌓입니다. / 이때 도어락이 가장 쉽게 상합니다.
이 글은 인테리어나 리모델링을 하는 동안 현관 도어락을 지키는 법과 임시로 쓰는 요령을 정리한 것입니다. / 공사 업체와 이야기할 때 참고하셔도 좋습니다.
업체에 현관은 건드리지 말아 달라고 미리 말해 두는 것만으로도 사고가 줄어듭니다. / 말하지 않으면 작업자는 현관을 그냥 통로로만 생각하기 쉽습니다.
@ 원동 인테리어 공사 현관 도어락 보호

# 공사 중 도어락이 망가지는 흔한 장면
도어락은 정밀한 부품이라 먼지와 충격에 약합니다. / 공사 현장에서는 아래 같은 일이 자주 벌어집니다.
- 번호판 틈에 석고 가루와 페인트 입자가 들어가 버튼이 뻑뻑해짐
- 자재를 옮기다 손잡이나 문틀에 부딪혀 어긋남
- 도배나 페인트 작업 중 번호판에 액체가 묻어 오작동
- 수십 번 여닫으면서 배터리가 빨리 닳음
한 번 망가지면 공사가 끝난 뒤에야 알게 되는 경우가 많습니다. / 그래서 시작 전에 미리 막아 두는 쪽이 낫습니다.

# 번호판과 손잡이는 이렇게 가려 두세요
가장 좋은 방법은 분리해서 보관하는 것이지만, 어려우면 가리기만 해도 도움이 됩니다. / 마스킹 테이프와 비닐로 번호판과 손잡이 전체를 감쌉니다.
테이프는 도어락 표면에 오래 붙여 두면 접착제가 남을 수 있습니다. / 공사가 길어지면 중간에 한 번 갈아 주는 편이 안전합니다.
키패드 구멍을 완전히 막으면 나중에 배터리 교체나 비상 단자 접근이 어렵습니다. / 비상 단자 위치만큼은 열어 두거나 표시해 두세요.

# 아예 떼어 두는 것도 방법입니다
공사가 길고 먼지가 많다면 도어락을 떼어서 잘 보관하는 방법도 있습니다. / 그동안은 문에 임시 잠금을 쓰면 됩니다.
떼어 낼 때는 안쪽과 바깥쪽, 나사 위치를 사진으로 남겨 두세요. / 다시 달 때 문 두께와 구멍에 맞는지 쉽게 확인할 수 있습니다.
직접 분리하다 케이블을 당기면 내부가 끊어질 수 있습니다. / 자신이 없으면 [도어락 설치](doorlock-install.html) 문의로 도움을 받으셔도 됩니다.

# 공사 기간 동안 쓸 임시 잠금
문을 비워 둘 수 없으니 임시로 잠글 방법이 필요합니다. / 열쇠로 잠그는 임시 방식, 간단한 손잡이형 잠금, 안쪽 보조키 정도가 일반적입니다.
공사 인력이 드나드는 시간에는 문을 열어 두고, 퇴근 시간에 사시는 분이 직접 잠그는 방식도 많이 씁니다. / 열쇠를 여러 사람이 가지게 되므로 누가 가졌는지 적어 두세요.
@ 오산 원동 공사 중 임시 현관 잠금

# 열쇠와 번호는 한 사람이 관리하세요
공사 팀장, 목수, 전기 기사가 각자 열쇠를 가지면 나중에 누가 가졌는지 모르게 됩니다. / 열쇠 복제는 한 번만 하고, 받아 간 사람 이름을 메모해 두세요.
공사가 끝나면 모든 열쇠를 회수하고 도어락 번호도 새로 정하는 것이 마음 편합니다. / 임시 번호는 공사 마지막 날 반드시 지웁니다. / 작업자에게 알려 준 번호가 그대로 남아 있으면 나중에 누가 들어올 수 있는지 알기 어렵습니다.
공사 중에는 관리사무소에 작업 기간을 알려 두면 출입 관련 문의가 있을 때 도움이 됩니다.

# 먼지가 들어갔다면 공사 직후 이렇게
마무리가 끝났는데 번호판이 뻑뻑하거나 소리가 이상하다면 먼지 가능성이 큽니다. / 마른 붓이나 부드러운 솔로 번호판 주변을 쓸어 주세요.
물이나 알코올을 뿌리는 것은 피해야 합니다. / 안쪽 회로에 스며들면 고장으로 이어질 수 있습니다.
증상이 가시지 않으면 [도어락 수리](doorlock-repair.html) 쪽으로 점검을 받아 보세요. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 공사 중에 문이 잠겨 버렸다면
임시 잠금 상태에서 열쇠를 안에 두고 나오는 일도 생깁니다. / 도어락을 떼어 둔 상태라 평소와 다른 곳이 잠겨 있을 수 있습니다.
이럴 때는 상황을 그대로 말씀해 주세요. / 어떤 장치가 걸려 있는지에 따라 접근이 달라집니다.
억지로 문을 밀거나 틈을 벌리지 마시고, 현관 상태 사진을 문자로 보내 주시면 도움이 됩니다.
임시 잠금 장치 모양이 보이게 찍어 주시면 챙길 도구를 맞추기 쉽습니다. / 가까운 오산대역이나 세마역 방향에서 오시는 길에도 사진을 보고 준비합니다.

# 열기 전에 사시는 분인지 확인합니다
공사 중인 집은 사람이 많이 드나들어 더 조심해야 합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나는 꼭 보여 주셔야 합니다.
공사 업체 직원이 대신 요청하는 경우에도 사시는 분 본인 확인이 먼저입니다. / 집주인이 연락이 안 되면 작업이 어렵습니다.

# 비용은 문을 열기 전에 먼저 말씀드립니다
현장을 보고 작업 내용과 비용을 먼저 설명드립니다. / 하겠다고 하시면 그때 시작합니다.
끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다.
진행 순서는 [이용안내](guide.html)에 적어 두었습니다. / 공사 중 사정이 복잡해도 먼저 상담 받으셔도 됩니다.

# 공사가 끝난 뒤 도어락 점검표
정리가 다 끝나면 아래 순서로 한 번 확인해 보세요.
- 번호를 눌렀을 때 소리와 불빛이 정상인지
- 문을 닫았을 때 걸쇠가 소리 나게 걸리는지
- 손잡이를 돌릴 때 걸림이나 헛돎이 없는지
- 배터리 잔량 표시가 정상인지
- 비상 단자와 열쇠 구멍이 막히지 않았는지
이 중 하나라도 이상하면 그날 바로 확인하세요. / 공사 후 점검은 늦을수록 원인을 찾기 어렵습니다.
공사 업체가 하자 여부를 따질 때도 날짜가 남은 사진이 도움이 됩니다. / 점검한 날 번호판과 문틀 사진을 한 장씩 찍어 두세요.
@ 원동 공사 후 도어락 점검

# 교체가 필요한 경우는 따로 정리하세요
공사 때문에 문까지 바꾸게 되면 도어락 규격도 달라집니다. / 새 문 두께와 보조키 위치를 확인한 뒤 맞는 제품을 고르는 게 순서입니다.
기존 도어락을 그대로 옮겨 달 수 있는지도 같이 확인해 보세요. / 교체와 재설치 중 어느 쪽이 나은지는 [도어락 교체](doorlock-replace.html)에서 설명드립니다.

# 원동 말고 오산 어디든 갑니다
원동 바로 옆 오산동, 궐동, 세교동, 신장동, 수청동도 다닙니다. / 오산 안이면 24시간 출동합니다.
다니는 동네는 [오산시 출장열쇠](osan.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

# 자주 묻는 질문
? 공사 중에는 도어락을 꼭 떼어 둬야 하나요? | 꼭은 아닙니다. 번호판과 손잡이를 잘 가리면 쓸 수 있고, 먼지가 많은 공사라면 떼어 두는 쪽이 안전합니다.
? 마스킹 테이프는 아무거나 써도 되나요? | 가급적 떼어낼 때 자국이 남지 않는 종류를 쓰고, 오래 붙여 두지 않는 게 좋습니다.
? 공사 중에 문이 잠겨도 오시나요? | 네, 상황을 말씀해 주시면 24시간 출동합니다. 못 열면 비용은 받지 않습니다.
? 열쇠를 여러 개 복제해도 되나요? | 가능하면 최소한만 복제하고 누가 가졌는지 기록해 두세요.
? 공사가 끝나면 번호도 바꿔야 하나요? | 임시 번호를 썼다면 지우고 새로 정하시길 권합니다.
