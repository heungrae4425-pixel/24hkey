# 앞문보다 먼저 고장 나는 뒷문
뒷문은 현관처럼 관리하는 시선이 적어 문제가 생겨도 한참 뒤에야 알게 되는 경우가 많습니다.
현관은 매일 열어 보지만 뒷문이나 쪽문은 가끔만 씁니다. / 그래서 막상 쓰려는 날 안 열리는 일이 자주 생깁니다.
원동에서 건물 뒤편 후문으로 돌아가려는데 잠금이 안 풀리는 경우를 생각해 보세요. / 오산역 쪽 큰길을 피해 들어온 날 막히면 더 곤란합니다.
이 글은 뒷문, 쪽문, 후문 잠금장치가 말을 안 들을 때 원인과 확인할 것, [오산 출장열쇠](osan.html) 요청 방법을 정리했습니다.
@ 원동 뒷문 쪽문 후문 잠금장치

# 뒷문의 잠금은 이런 모양이 많습니다
쪽문은 사람 한 명이 겨우 지나갈 정도의 좁은 문이라 작업 공간도 좁은 편입니다. / 문 앞에 물건이 쌓여 있다면 미리 치워 주시면 작업이 빨라집니다.
같은 자물쇠라도 안쪽과 바깥쪽 모양이 다르게 달린 문이 있습니다. / 두 면을 모두 확인해서 말씀해 주세요.
뒷문과 쪽문은 현관 도어락과 다른 단순한 장치가 달린 경우가 많습니다. / 크게 세 가지입니다.
- 열쇠로 돌리는 원통형 잠금
- 안쪽에서 돌려 잠그는 걸쇠나 빗장
- 철문에 붙은 큰 자물쇠
각각 고장 증상과 해결 방법이 다릅니다. / 어느 쪽인지 먼저 보고 말씀해 주세요.

# 오래 안 쓴 문이 안 열리는 이유
오래 쓰지 않은 철제 자물쇠는 속에 녹이 굳어 열쇠가 부러지는 일이 흔합니다. / 힘으로 돌리는 것이 가장 위험합니다.
비를 맞는 쪽 문은 철제 경첩의 녹이 가장 먼저 문제를 일으킵니다. / 경첩 쪽에서 삐걱 소리가 나면 이미 신호가 온 것입니다.
가장 흔한 원인은 녹과 먼지입니다. / 오래 안 쓴 열쇠 구멍은 속에 먼지가 쌓이고 금속이 녹슬어 열쇠가 잘 안 돌아갑니다.
문틀이나 경첩에 녹이 슬면 문이 뻑뻑해져 열쇠가 맞아도 열리지 않습니다. / 비바람을 직접 맞는 뒷문은 특히 그렇습니다.
자주 안 여는 문일수록 한 달에 한 번이라도 열어 보면 상태를 미리 알 수 있습니다.

# 열쇠가 안 돌아갈 때
문과 열쇠를 사진으로 찍어 보내 주시면 복사 열쇠를 새로 만들어야 하는지 판단하기 쉽습니다.
열쇠가 부러져 속에 남을까 걱정된다면 일단 멈추고 전화로 상태를 알려 주세요. / 부러진 조각은 방법이 따로 있습니다.
열쇠를 꽂았는데 중간에 걸리면 억지로 돌리지 마세요. / 열쇠가 부러지면 일이 커집니다.
문을 살짝 안으로 밀면서 가볍게 돌려 보세요. / 걸림판에 눌려 무거운 경우 이렇게 풀리는 일이 있습니다.
식용유 같은 기름은 먼지를 끌어당겨 나중에 더 막히니 피해 주세요.
@ 원동 뒷문 열쇠 구멍 녹 먼지 점검

# 철문이나 쪽문 빗장이 걸렸다면
빗장이 안쪽에서 걸린 문은 틈이 좁다면 바깥에서 건드리지 않는 편이 안전합니다. / 억지로 틈을 벌리면 철문이 휘어 더 안 열립니다.
안쪽에서 빗장이나 걸쇠를 걸고 나온 문은 바깥에서 열 수 없습니다. / 이 경우는 고장이 아니라 안에서 잠겨 있는 것입니다.
다른 출입구가 있는지, 이웃이나 관리하는 사람이 안으로 들어갈 수 있는지 먼저 확인하세요. / 안에서 풀 수 있는 사람이 있으면 가장 빠릅니다.
없다면 빗장 종류와 문틀 사이 간격을 사진으로 찍어 두세요. / 방법을 미리 짐작할 수 있습니다.

# 여러 사람이 함께 쓰는 문이라면
열쇠를 맡긴 사람이 누구인지 정리해 두면 비슷한 일이 다시 생겨도 쉽게 대응할 수 있습니다.
공용 문은 여러 사람이 쓰기 때문에 열쇠를 가진 분이 따로 있는 경우가 많습니다. / 먼저 그분께 연락해 보시는 게 가장 빠릅니다.
뒷문이 건물 전체가 쓰는 공용 출입구라면 관리 주체에게 먼저 알리는 것이 좋습니다. / 관리사무소나 건물 관리하는 분이 열쇠를 갖고 있을 수 있습니다.
개인 공간이 아닌 곳은 문을 열기 전에 권한 확인이 더 엄격해집니다. / 이 점을 미리 이해해 주세요.
공용 출입구를 임의로 고치면 문제가 생길 수 있으니 허락을 받아 두세요.

# 출장 요청 시 알려주실 것
후문은 대문과 방향이 반대인 경우가 많아 길 안내가 헷갈립니다. / 후문이 어느 길에 면해 있는지 말씀해 주세요.
- 원동 안에서 가까운 방향 (오산역 쪽인지 등)과 건물 이름
- 뒷문인지 쪽문인지 후문인지, 철문인지 목문인지
- 잠금 모양 (열쇠, 빗장, 자물쇠)
- 안쪽에 사람이나 반려동물이 있는지
- 문 전체와 잠금 부분 사진
뒷길은 안내가 어려우니 지나기 쉬운 표지를 알려 주세요. / 도착이 한결 빨라집니다.

# 신분 확인은 여기서도 합니다
상가나 사무실이라면 사업자 관련 서류나 임대 관련 서류가 확인에 도움이 됩니다.
도착하면 사시는 분이나 관리하시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
상가나 공용 건물이라면 관리 주체의 확인이 필요할 수 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 주세요.

# 비용은 열기 전에 말씀드립니다
녹을 풀거나 부품을 손보는 과정이 길어질 수 있어 예상되는 범위를 먼저 알려 드립니다.
문과 잠금 상태를 본 뒤 시작하기 전에 먼저 말씀드립니다. / 동의하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 여쭙습니다. 진행 순서는 [이용안내](guide.html)에서 확인하세요.
@ 원동 뒷문 개방 출장열쇠 비용 안내

# 문을 상하지 않게 엽니다
녹슨 문은 힘으로 열면 부러지기 쉽습니다. / 먼저 녹을 풀고 덜 상하는 방법으로 접근합니다.
방법은 [현관문 개문](door-open.html)에 정리한 원칙과 같습니다. / 열쇠가 필요하면 [열쇠 출장](key-call.html)에서 열쇠 제작도 같이 안내합니다.

# 열고 난 뒤 바꿔 두면 좋은 것
경첩에는 마른 윤활제를 소량만 쓰고, 넘치게 바르면 먼지가 끼니 주의하세요.
문이 열리면 열쇠 구멍을 청소하고 마른 윤활제를 소량 넣습니다. / 경첩 나사도 한 번 조여 둡니다.
녹이 심한 자물쇠는 교체를 권하는 경우가 있습니다. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 마치고, 새로 달고 싶을 때는 [도어락 설치](doorlock-install.html)를 상담합니다.
자주 안 쓰는 문이라도 비상 탈출구로 쓸 수 있으니 항상 열릴 상태로 두세요.

# 평소에 해두면 좋은 점검
- 한 달에 한 번 열고 닫아 보기
- 경첩과 빗장에 녹이 슬지 않았는지 보기
- 열쇠를 어디에 두었는지 가족이 알고 있기
- 비 온 뒤 문틀 물기를 닦아 두기
이 정도만 해도 막상 쓰려는 날 당황하는 일이 줄어듭니다.

# 원동 말고 오산 어디든 갑니다
뒷문이나 쪽문 하나만 문의하셔도 괜찮습니다. / 규모가 작은 일도 정성껏 봐 드립니다.
원동 옆 오산동, 궐동, 세교동, 신장동, 대원동, 남촌동, 초평동, 수청동, 갈곶동도 다닙니다. / 오산대역, 세마역 쪽도 24시간 받습니다.
[오산시 출장열쇠](osan.html)에서 다니는 동네를 보시고, 다른 지역은 [출장 지역](area.html)에서 확인하세요.
