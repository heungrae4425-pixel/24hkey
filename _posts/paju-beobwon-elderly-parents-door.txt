# 법원읍 부모님 댁 도어락, 언제 한번 점검해 보셨나요
법원읍에는 오래 사신 어르신들이 계신 집이 많습니다. / 멀리 사는 자녀분이 부모님 집 문이 안 열린다는 전화를 받고 연락을 주시는 경우가 많습니다.
도어락은 있는 줄도 모르게 쓰다가 어느 날 갑자기 멈춥니다. / 특히 배터리와 비밀번호는 어르신 혼자서 챙기기 어려운 부분입니다.
이 글은 부모님 댁 도어락을 미리 살펴 두는 방법과 어르신이 쓰기 편하게 맞추는 요령, 문이 안 열렸을 때 가족이 해야 할 일을 정리했습니다. / 바쁘더라도 한 번만 읽어 두시면 마음이 훨씬 놓입니다.
@ 법원읍 24시 출장열쇠 부모님 댁 도어락 점검

# 방문하실 때 5분이면 되는 점검
부모님 집에 들를 때 아래 다섯 가지만 보셔도 큰 고장을 많이 막을 수 있습니다. / 복잡한 도구는 필요 없습니다.
- 번호판이 환하게 켜지는지, 눌렀을 때 소리가 나는지
- 문을 닫았을 때 끝까지 닫혀 잠금 소리가 나는지
- 배터리 경고음이 최근에 난 적이 있는지 어르신께 여쭙기
- 열쇠구멍이 있는 제품이라면 비상 열쇠가 어디 있는지
- 문틀과 경첩 쪽에 틈이나 삐걱임이 있는지
이상이 하나라도 보이면 메모해 두고 미루지 마세요. / 큰 고장은 작은 이상에서 시작됩니다.

# 배터리는 자녀분이 달력에 적어 주세요
어르신은 배터리 경고음이 나도 그냥 두시는 경우가 있습니다. / 소리가 나도 며칠은 쓸 수 있어서 괜찮다고 생각하시기 쉽습니다.
교체 날짜를 달력이나 문 안쪽에 적어 두고, 자녀분이 직접 가서 바꿔 드리는 방법이 좋습니다. / 일부만 바꾸지 말고 전부 새 것으로 교체해 주세요.
방문이 어렵다면 비상용 9V 건전지를 현관 가까운 곳에 두시게 하고 쓰는 법을 한 번 알려 드리세요. / 단자가 있는 제품인지 먼저 확인해 두면 좋습니다.

# 비밀번호는 외우기 쉽고 남이 알기 어렵게
어르신은 복잡한 번호를 외우기 어려워하십니다. / 그렇다고 생일이나 전화번호처럼 누구나 짐작하는 번호는 피하는 게 좋습니다.
가족만 아는 날짜나 숫자 조합을 정하고, 번호는 자녀 두세 명이 같이 알아 두세요. / 어르신이 잊으셨을 때 바로 연락해서 알려 드릴 수 있습니다.
종이에 적어 현관 근처에 붙이는 것은 피해 주세요. / 대신 가까운 가족 휴대폰에 안전하게 저장해 두는 편이 낫습니다.

# 소리와 불빛은 크고 또렷하게
번호판 소리가 너무 작으면 어르신이 눌렸는지 아닌지 헷갈려 같은 번호를 여러 번 누르십니다. / 오류가 쌓이면 도어락이 입력을 막아 버립니다.
제품에 따라 작동음 크기를 조절할 수 있으니 설명서나 안쪽 버튼을 확인해 보세요. / 소리가 불편하다고 완전히 끄면 오히려 상태를 모를 수 있어 권하지 않습니다.
번호판이 어두워 잘 안 보인다면 불빛이 밝은 제품이나 밝기 설정을 살펴보세요. / 현관 조명이 어두우면 센서 등을 달아 드리는 것도 한 방법입니다.
@ 파주 법원읍 어르신 도어락 설정 점검 출장

# 열쇠 방식과 번호 방식, 어느 쪽이 편할까
익숙한 열쇠가 더 편하다고 하시는 어르신이 많습니다. / 번호가 익숙해지기까지는 시간이 걸리니 한동안은 두 가지를 같이 쓰게 해 드려도 좋습니다.
열쇠구멍이 있는 도어락이라면 비상 열쇠를 부모님과 자녀가 하나씩 나눠 가지세요. / 번호를 잊었을 때 문을 열 수 있는 가장 간단한 방법입니다.
카드키나 태그를 함께 쓰는 제품은 잃어버리기 쉬우니 목걸이나 열쇠고리에 묶어 두는 게 좋습니다. / 자세한 상담은 문을 보고 말씀드립니다.

# 문이 안 열린다는 전화를 받았을 때
어르신이 당황한 목소리로 전화를 하시면 먼저 진정시켜 주세요. / 문 앞에 서 계신 곳이 안전한지, 날씨가 어떤지도 물어봐 주세요.
번호판에 불이 들어오는지, 소리가 나는지를 차분히 물어보면 원인을 어느 정도 가늠할 수 있습니다. / 멀리 계시면 어르신께 사진을 찍어 보내 달라고 하기 어려우니 이웃의 도움을 받는 것도 방법입니다.
가까운 이웃에게 부탁할 수 있도록 평소에 연락처를 알아 두면 좋습니다. / 급할 때는 바로 24시출장열쇠에 전화 주세요.

# 어르신이 혼자 계실 때 우선 해야 할 일
추운 날이나 더운 날에 오래 문 앞에 서 계시면 건강에 무리가 갑니다. / 가까운 이웃집이나 마을회관, 읍내 가게 같은 안전한 곳으로 일단 옮겨 계시게 하세요.
복용 중인 약이 있거나 몸이 불편하신 분이라면 상황이 급하다는 점을 꼭 말씀해 주세요. / 몸에 이상이 느껴지면 열쇠집보다 119가 먼저입니다.
상황이 괜찮다면 자녀분이 위치를 정확히 알려 주시면 됩니다. / 어르신 대신 전화해 주셔도 괜찮습니다.

# 대신 전화하실 때 알려 주세요
가족이 대신 연락하실 때는 이런 정보가 도움이 됩니다. / 부모님 대신 설명하기 어려운 부분은 있는 그대로 말씀해 주세요.
- 부모님 집 주소와 가까운 눈에 띄는 곳
- 어르신이 지금 어디에 계신지
- 문 상태 (번호판이 꺼졌는지, 소리만 나는지)
- 집 안에 다른 가족이나 반려동물이 있는지
- 문 앞까지 도와줄 이웃이 있는지
사진을 받을 수 있으면 도어락 모양을 먼저 확인합니다. / 맞는 장비를 챙겨 가기 위한 준비입니다.

# 신분 확인은 어르신 댁에서도 합니다
문을 여는 일이라서 사시는 분이 맞는지 먼저 확인합니다. / 어르신 댁이면 부모님 신분증이나 주소가 나온 우편물을 같이 봅니다.
자녀분이 대신 요청하셨다면 부모님 본인과 통화로 확인하거나 현장에서 직접 확인합니다. / 이웃의 확인이나 관리사무소 확인도 참고합니다.
번거로우실 수 있지만 집을 지키기 위한 절차입니다. / 확인이 안 되면 작업을 할 수 없는 점은 미리 말씀드립니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 어르신께도 같은 방식으로 충분히 설명드립니다.
괜찮다고 하시면 시작하고, 아니라고 하시면 그냥 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 자녀분께도 여쭙고 진행하고 싶으시면 그렇게 합니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문은 이렇게 엽니다
어르신 댁 문은 오래된 경우가 많아 더 조심스럽게 엽니다. / 문과 도어락이 상하지 않는 방법부터 차례로 시도합니다.
작업 중에 보이는 문제가 있으면 손대기 전에 먼저 말씀드립니다. / 갑자기 부품을 뜯거나 바꾸는 일은 없습니다.
자세한 개방 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 비파손 개방을 기본으로 합니다.
@ 법원읍 부모님 댁 현관문 개문 후 점검

# 열고 난 뒤에는 쓰기 편하게 다시 맞춥니다
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 어르신이 직접 눌러 보시게 하고 불편한 부분을 들어 봅니다.
배터리가 원인이었다면 새 것으로 바꾸고, 다음에 바꿀 시기를 메모해 드립니다. / 번호를 잊어서 연 경우에는 새 번호를 등록하는 것까지 도와드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 자주 고장이 나면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 법원읍 말고 파주 어디든 갑니다
법원읍 말고도 금촌, 운정, 교하, 문산읍, 파주읍, 조리읍까지 파주 전 지역으로 다닙니다. / 24시간 받으니 급할 때는 바로 전화 주세요.
파주에서 다니는 동네는 [파주시 출장열쇠](paju.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
