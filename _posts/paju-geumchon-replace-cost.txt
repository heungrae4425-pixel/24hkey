# 금촌동에서 도어락을 바꿀까 고민된다면
금촌동은 금촌역을 중심으로 오래된 주택가와 아파트, 상가가 어우러진 생활권입니다. / 도어락을 단 지 오래된 집이 많아 "이제 바꿀 때가 됐나" 하는 문의가 자주 들어옵니다.
그런데 막상 바꾸려면 어떤 제품이 우리 문에 맞는지, 비용은 어떻게 정해지는지 알기 어렵습니다. / 전화로 "얼마예요?"라고 물어도 문을 보지 않고는 정확한 답을 듣기 힘든 이유도 있습니다.
이 글은 교체하기 전에 확인할 것, 비용을 바꾸는 요소, 저희가 비용을 안내하는 방식을 적었습니다. / 상담이 필요하시면 [파주 출장열쇠](paju.html)로 연락 주세요.
@ 금촌동 도어락 교체 상담

# 바꾸기 전에, 정말 바꿔야 하나요
도어락이 말썽이라고 모두 교체가 답은 아닙니다. / 아래 경우는 손보는 것으로 해결되는 일이 많습니다.
- 건전지를 바꾸면 좋아지는 번호판 꺼짐이나 경고음
- 문 처짐 때문에 걸쇠가 눌려 생기는 열림 불량
- 번호판 한두 칸이 잘 안 눌리는 정도의 고장
- 카드나 지문 등록이 꼬인 경우
반대로 모터와 기어가 닳았는데 같은 부품이 없거나, 회로에 물이 들어가 여러 기능이 동시에 망가졌다면 교체가 맞습니다. / 어느 쪽인지는 점검해 보고 솔직하게 말씀드리며, 손보는 쪽은 [도어락 수리](doorlock-repair.html)에 정리해 두었습니다.

# 문 쪽에서 확인할 것
같은 도어락이라도 문에 따라 달 수 있는지가 달라집니다. / 교체 전에 아래를 먼저 봐야 합니다.
문 두께가 얼마나 되는지, 철문인지 나무 문인지에 따라 맞는 제품이 정해집니다. / 금촌동 오래된 주택은 문이 얇거나 나무 문인 경우도 있어 꼭 확인해야 합니다.
지금 도어락을 떼어 낸 자리의 구멍 크기와 위치도 중요합니다. / 새 제품이 기존 구멍을 덮지 못하면 문에 손을 더 대야 해서 작업이 늘어납니다.
보조키가 따로 달려 있다면 그것을 남길지, 없애고 하나로 합칠지도 정해야 합니다. / 문 두께와 구멍 확인 방법은 [도어락 설치](doorlock-install.html)에 자세히 적어 두었습니다.
@ 금촌동 오래된 주택 문 두께 기존 구멍

# 쓰는 사람 쪽에서 확인할 것
누가 어떻게 쓸지에 따라 고를 제품이 달라집니다. / 기능이 많다고 다 좋은 것은 아닙니다.
어르신이 쓰신다면 글자가 크고 소리가 또렷한 번호식이나 카드식이 편합니다. / 아이가 있다면 안에서 쉽게 열리지 않는 기능을, 손님이 자주 오는 집이라면 임시 번호 기능을 보세요.
지문이나 앱 연동은 편리하지만 꼭 필요한지 한 번 더 생각해 보세요. / 쓰지 않는 기능이 많을수록 고장 날 곳도 늘어납니다.

# 비용을 바꾸는 요소들
도어락 교체 비용은 몇 가지 요소에 따라 달라집니다. / 그래서 문을 보기 전에 한 가지 금액을 말씀드리기 어렵습니다.
- 고르신 제품의 종류와 기능
- 문 재질과 두께, 기존 구멍을 그대로 쓸 수 있는지
- 보조키를 함께 바꾸거나 떼어 내는지
- 문틀 받침쇠나 경첩을 같이 손봐야 하는지
- 기존 도어락이 잠긴 상태라 먼저 문을 열어야 하는지
전화로 사진을 보내 주시면 대략 어느 쪽인지 미리 말씀드릴 수 있습니다. / 정확한 비용은 문을 직접 본 뒤에 확정합니다.

# 저희가 비용을 안내하는 방식
문과 기존 도어락을 본 뒤, 어떤 제품을 어떻게 달지와 그 비용을 작업 전에 먼저 말씀드립니다. / 들어 보시고 괜찮다고 하실 때만 시작합니다.
마음에 들지 않으시면 그냥 돌아갑니다. / 작업 중에 따로 손봐야 할 곳이 보이면 손대기 전에 다시 여쭤봅니다.
작업이 끝난 뒤 말없이 붙는 비용은 없습니다. / 이 방식은 [이용안내](guide.html)에도 적어 두었습니다.
여러 제품을 놓고 고민하신다면 제품마다 무엇이 다르고 비용이 어떻게 달라지는지 나란히 말씀드립니다. / 비싼 제품을 권하기보다 우리 집에 필요한 기능에 맞춰 고르실 수 있게 돕는 것이 먼저입니다.
가족과 상의할 시간이 필요하시면 그날 바로 정하지 않으셔도 됩니다. / 들으신 내용을 바탕으로 천천히 정하고 다시 연락 주시면 됩니다.

# 직접 사 온 제품을 달고 싶을 때
인터넷이나 매장에서 직접 산 도어락을 달아 달라는 분도 계십니다. / 문에 맞는 제품이라면 설치해 드립니다.
다만 사기 전에 문 두께와 기존 구멍 크기를 먼저 확인하세요. / 맞지 않는 제품을 사면 반품하거나 문에 손을 더 대야 할 수 있습니다.
모델명을 미리 알려주시면 맞는지 함께 봐 드립니다.
상자를 뜯기 전에 문 사진과 제품 설명서 속 치수를 함께 보내 주시면 더 정확합니다. / 맞지 않는다는 걸 미리 알면 반품도 훨씬 수월합니다.
떼어 낸 기존 도어락은 원하시면 그대로 돌려 드리고, 필요 없으시면 정리해 드립니다.

# 교체 날 진행 순서
도착하면 먼저 문과 기존 도어락 상태를 다시 봅니다. / 전화로 들은 내용과 다른 점이 있으면 작업 전에 말씀드립니다.
기존 도어락을 떼어 내고 새 도어락을 단 뒤, 걸쇠가 문틀 받침쇠에 정확히 들어가는지 맞춥니다. / 그다음 비밀번호, 카드, 지문을 사시는 분과 함께 등록합니다.
마지막으로 문을 여러 번 열고 닫으며 잠금과 열림이 매끄러운지 확인합니다. / 교체 과정 전체는 [도어락 교체](doorlock-replace.html)에도 정리해 두었습니다.
@ 금촌동 새 도어락 설치 후 등록 확인

# 잠긴 상태에서 교체가 필요하다면
도어락이 고장 나 문이 잠긴 채 바꿔야 하는 경우도 있습니다. / 이때는 먼저 사시는 분인지 신분증, 주소가 찍힌 우편물, 관리사무소 확인 중 하나로 확인합니다.
그다음 문을 덜 상하는 방법으로 연 뒤 교체를 진행합니다. / 여는 방식은 [현관문 개문](door-open.html)에 있고, 끝내 못 열면 비용은 받지 않습니다.

# 교체 뒤 오래 쓰는 요령
새 도어락도 건전지를 제때 바꾸지 않으면 금방 말썽입니다. / 경고음이 나면 그날 바로 전부 새것으로 바꿔 주세요.
문이 처지기 시작하면 도어락에 무리가 갑니다. / 문 아래가 바닥에 끌리거나 닫힐 때 덜컥 걸리면 일찍 점검을 받으세요.
설명서와 비상 열쇠는 한곳에 모아 두세요. / 나중에 설정을 바꿀 때 바로 찾을 수 있습니다.
바꾼 첫 달에는 가족 모두 새 방식으로 몇 번씩 열어 보며 익숙해지는 시간을 가지세요.

# 전화로 알려주시면 좋은 것
- 금촌역 기준 대략 위치, 아파트 동, 호수 또는 주택 주소
- 지금 도어락 앞뒤 사진과 문 옆면 사진
- 원하는 여는 방식 (번호, 카드, 지문 등)
- 보조키를 남길지 없앨지
사진만 있어도 맞는 제품을 추려서 말씀드릴 수 있습니다. / 급하지 않다면 편한 시간을 정해 방문합니다.

# 금촌동 밖 파주 지역도
금촌동 옆 교하동, 운정동부터 조리읍, 문산읍, 파주읍, 법원읍, 탄현면, 월롱면까지 파주 전 지역을 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 교체 비용에 대해 자주 묻는 것
? 전화로 비용을 정확히 알 수 있나요? | 사진으로 대략은 말씀드리고, 정확한 비용은 문을 본 뒤 작업 전에 확정합니다.
? 와서 보고 마음에 안 들면요? | 그냥 돌아갑니다. 동의하실 때만 작업합니다.
? 고칠 수 있는데 교체를 권하시나요? | 아닙니다. 고쳐 쓸 수 있으면 그쪽을 먼저 말씀드립니다.
? 직접 산 제품도 달아 주시나요? | 문에 맞으면 설치해 드립니다.
? 작업 뒤에 추가 비용이 붙나요? | 말없이 붙는 비용은 없습니다. 더 필요한 작업은 미리 여쭤봅니다.
