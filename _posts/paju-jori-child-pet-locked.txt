# 조리읍에서 집 안에 아이가 있는데 문이 잠겼다면
조리읍은 가족 단위로 사는 집이 많아 아이와 함께 지내는 분들의 연락이 잦은 동네입니다. / 택배를 받으러 나왔다가, 쓰레기를 버리러 잠깐 나왔다가 문이 닫혀 버리는 일이 흔합니다.
집 안에 아이나 반려동물이 있으면 마음이 급해져 평소처럼 생각하기 어렵습니다. / 이 글은 그런 상황에서 어떤 순서로 움직이면 좋은지 차분히 적었습니다.
핵심은 두 가지입니다. / 안에 있는 아이나 동물이 놀라지 않게 하는 것, 그리고 문을 상하지 않게 여는 것입니다.
@ 조리읍 24시 출장열쇠 집 안 아이 문 잠김 개문

# 가장 먼저 할 일은 목소리를 들려주는 것
문 너머로 계속 말을 걸어 주세요. / 아이는 부모 목소리가 들리면 훨씬 안정됩니다.
큰 소리로 다그치거나 문을 두드리면 안에서 더 놀랄 수 있습니다. / 낮고 천천히, 곧 들어간다고 반복해서 말해 주세요.
문 쪽으로 오지 못하는 어린 아이라면 안쪽에서 무엇을 하고 있는지 소리로 짐작해 보세요. / 울음이 심하거나 위험한 소리가 나면 바로 119에 먼저 연락하는 것이 맞습니다.

# 119를 먼저 부르는 경우
집 안에서 연기나 타는 냄새가 나거나 아이가 다친 것 같다면 열쇠집보다 119가 먼저입니다. / 이럴 때는 망설이지 말고 119에 전화해 주세요.
그다음 같은 상황을 열쇠집에도 알려 주시면 이어서 출동 준비를 합니다. / 두 곳에 모두 연락해도 괜찮습니다.
급박한 위험이 없고 아이가 괜찮은 것 같다면 열쇠집을 바로 부르시면 됩니다. / 전화하면서 상황을 먼저 말씀해 주세요.

# 전화할 때 꼭 말해 주세요
아이나 반려동물이 안에 있다는 사실을 가장 먼저 말씀해 주세요. / 그래야 우선순위를 두고 빠르게 움직일 수 있습니다.
- 안에 있는 사람이나 동물이 몇 명인지, 나이는 어느 정도인지
- 안에서 문을 열 수 있는 나이인지 (손잡이를 돌릴 수 있는지)
- 불이나 가스, 전기 제품이 켜져 있는지
- 지금 서 있는 곳과 도어락 상태
도어락 사진을 보내 주시면 맞는 장비를 챙기기 쉽습니다. / 열쇠구멍이 있는 문인지도 같이 알려 주세요.

# 안에서 열 수 있는 나이라면
조금 큰 아이는 안쪽 손잡이나 잠금 버튼을 돌려서 열 수도 있습니다. / 문 너머로 어떻게 하라고 천천히 알려 주면 도움이 됩니다.
다만 안쪽 보조키가 잠긴 경우에는 안에서만 풀 수 있는 모양이 많습니다. / 손잡이 위쪽의 작은 돌림쇠를 돌리면 풀린다고 알려 주세요.
아이가 무서워하면 억지로 시키지 말고 그대로 기다리세요. / 저희가 도착해서 열면 됩니다.

# 반려동물이 안에 있을 때
강아지나 고양이는 문 앞에서 소리를 듣고 흥분하는 경우가 많습니다. / 큰 소리를 내지 말고 평소처럼 낮은 목소리로 불러 주세요.
문을 열 때 동물이 튀어나갈 수 있으니 출입문 앞을 미리 정리해 두세요. / 복도에서 줄이 있다면 짧게 잡고 계시면 안전합니다.
더운 날이나 추운 날에는 오래 기다리는 것이 동물에게 부담이 됩니다. / 이럴 땐 시간이 중요하니 상황을 꼭 먼저 말씀해 주세요.
@ 조리읍 반려동물 집 안 문 잠김 출장 개문

# 하면 안 되는 일
창문이나 베란다로 넘어 들어가려는 시도는 매우 위험합니다. / 특히 높은 층이라면 절대 하지 마세요.
문을 발로 차거나 몸으로 밀면 문과 문틀이 상하고, 안에 있는 아이가 놀랍니다. / 이웃에게도 큰 불편이 됩니다.
카드나 드라이버로 문틈을 벌리는 것도 문틀과 도어락을 상하게 합니다. / 기다리는 동안은 그대로 두고 연락만 해 주세요.
급해서 이웃의 사다리나 도구를 빌려 시도하는 분도 있는데, 안전을 해치기 쉬우니 피해 주세요. / 열쇠집은 이런 일을 늘 하는 사람이니 맡기는 편이 가장 빠르고 안전합니다.
안에 있는 아이가 말을 할 수 있다면 문 가까이에 앉아 기다리라고 알려 주세요. / 문이 열릴 때 부딪히지 않도록 문에서 한 걸음 떨어져 있게 하는 것도 도움이 됩니다.

@ 파주 조리읍 출장열쇠 아이 안심 개문

# 신분 확인은 꼭 합니다
문을 여는 일이라서 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
아이가 안에 있는 급한 상황이라도 이 절차는 건너뛰지 않습니다. / 대신 빠르게 확인하고 바로 작업합니다.
신분증이 집 안에 있다면 휴대폰에 있는 주소 증명 자료를 보여 주셔도 됩니다. / 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 바로 시작하고, 아니라고 하시면 돌아갑니다.
급한 상황이라고 설명 없이 값이 붙지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 다시 여쭙습니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 문은 이렇게 엽니다
문이나 도어락이 상하지 않는 방법부터 차례로 시도합니다. / 안에 있는 아이가 놀라지 않도록 소리가 크지 않은 방법을 먼저 씁니다.
도어락 종류와 문 상태에 따라 걸리는 시간은 다릅니다. / 작업 중에 무엇을 하는지 옆에서 짧게 설명드립니다.
자세한 개방 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 비파손 개방을 기본으로 합니다.

# 열린 뒤에는 아이부터 안아 주세요
문이 열리면 먼저 아이나 반려동물 상태를 살피세요. / 놀랐을 수 있으니 차분히 안아 주고 달래 주세요.
그다음 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새 것으로 바꿨는지도 봅니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 자주 고장이 나면 [도어락 수리](doorlock-repair.html)를, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 다음엔 이렇게 미리 대비하세요
잠깐이라도 나갈 때는 휴대폰과 열쇠를 꼭 챙기는 습관을 들이세요. / 현관 앞에 걸어 두는 작은 체크 메모가 도움이 됩니다.
문이 저절로 닫히지 않게 문틈에 작은 받침을 두는 방법도 있습니다. / 다만 방범에는 불리하니 짧은 시간만 쓰세요.
아이가 안에서 문을 잠그지 못하도록 안쪽 보조키는 높은 위치에 두거나 아이 키가 닿지 않는 제품으로 점검해 보세요. / 가족이 같이 사용법을 정해 두면 좋습니다.
집을 나서기 전 아이가 안에서 문을 만지지 않도록 눈높이에서 미리 확인해 두세요. / 놀이를 하다가 잠금 버튼을 눌러 버리는 일이 의외로 많습니다.

# 조리읍 말고 파주 어디든 갑니다
조리읍 말고도 금촌, 운정, 교하, 문산읍, 파주읍, 법원읍까지 파주 전 지역으로 다닙니다. / 24시간 받으니 급할 때는 바로 전화 주세요.
파주에서 다니는 동네는 [파주시 출장열쇠](paju.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
