# 조리읍 오래된 주택, 문이 예전 같지 않을 때
조리읍은 파주 읍 지역답게 단독주택과 연립이 많고, 마당을 지나 현관에 닿는 집도 흔합니다. / 집을 지을 때 단 현관문을 그대로 쓰면서 도어락만 몇 번 바꾼 집이 많습니다.
이런 문은 어느 날부터 아침에는 잘 열리다가 저녁에는 안 열리거나, 비 온 뒤에만 꽉 끼는 식으로 조금씩 말썽을 부립니다. / 도어락을 바꿔도 나아지지 않는다면 원인은 문 쪽에 있을 가능성이 큽니다.
이 글은 오래된 현관문을 문짝, 경첩, 문틀 세 군데로 나눠 점검하는 법과 지금 문 앞에서 해볼 요령을 적었습니다. / 손보기 어려운 부분은 [파주 출장열쇠](paju.html)에 맡겨 주세요.
@ 조리읍 단독주택 오래된 현관문 점검

# 우리 집 문은 어떤 종류인가요
점검하기 전에 문 재질부터 보세요. / 재질에 따라 처지는 방식과 손보는 방법이 다릅니다.
- 철문: 무게가 무거워 경첩 나사가 먼저 풀리고 손잡이 쪽이 내려앉습니다.
- 나무 문: 습기를 먹으면 부풀고 마르면 줄어들어 계절마다 틈이 달라집니다.
- 유리가 섞인 샷시형 현관문: 틀이 가벼운 대신 바퀴나 경첩이 닳으면 덜컹거립니다.
조리읍 오래된 주택에는 세 가지가 모두 있습니다. / 어떤 문인지 알려주시면 원인을 짚기가 훨씬 쉬워집니다.
문을 두드려 봤을 때 속이 꽉 찬 소리가 나면 철문이나 두꺼운 나무 문, 가볍게 울리면 속이 빈 문일 가능성이 큽니다. / 속이 빈 문은 도어락을 단 자리 주변이 약해져 있을 수 있어 손볼 때 더 조심해야 합니다.
언제부터 증상이 시작됐는지도 떠올려 보세요. / 도어락을 바꾼 직후부터라면 새 도어락 무게나 걸쇠 위치 문제, 몇 해에 걸쳐 서서히라면 문과 경첩 노후 쪽입니다.

# 문짝 점검, 틈과 바닥 자국
문을 닫고 문틀과 문 사이 틈을 위에서 아래로 훑어보세요. / 손잡이 쪽 위 모서리 틈은 넓고 아래 모서리 틈은 거의 없다면 문짝이 경첩 반대쪽으로 내려앉은 것입니다.
현관 바닥이나 문턱에 부채꼴 모양으로 긁힌 자국이 있는지도 보세요. / 문이 열릴 때마다 바닥을 스친 흔적이라 처짐이 꽤 진행됐다는 뜻입니다.
나무 문이라면 문짝 아래쪽 모서리가 거뭇하게 변했거나 부풀어 있는지 보세요. / 바닥 물기를 오래 먹은 문은 그 부분부터 상합니다.

# 경첩 점검, 나사와 축
문을 반쯤 열고 손잡이 쪽을 위아래로 살짝 흔들어 보세요. / 덜렁거린다면 경첩이 헐거워진 것입니다.
경첩 판이 문틀에서 떠 있거나 나사 머리가 튀어나와 있으면 나사가 빠지고 있는 중입니다. / 드라이버로 조여 봤는데 헛돈다면 나사 구멍이 닳은 것이라 보강이 필요합니다.
열고 닫을 때 끼익 소리가 크다면 경첩 축이 마르거나 닳은 것입니다. / 축이 닳으면 문 전체가 조금씩 기울어 걸쇠 위치도 같이 어긋납니다.
@ 조리읍 현관 경첩 나사 헐거움 확인

# 문틀 점검, 집이 움직였는지
경첩이 단단하고 문짝도 멀쩡한데 틈이 고르지 않다면 문틀이 기운 것일 수 있습니다. / 문틀 모서리 벽에 금이 갔거나 문틀과 벽 사이가 벌어져 있으면 그럴 가능성이 높습니다.
오래된 주택은 현관 앞 계단이나 바닥이 조금씩 내려앉으면서 문틀에도 영향을 줍니다. / 이런 경우는 문짝을 손봐도 다시 어긋나기 쉬워 문틀 쪽 보강을 함께 생각해야 합니다.
문틀이 크게 틀어졌다면 문을 새로 달아야 하는지도 함께 보고 그대로 말씀드립니다.

# 지금 문이 안 열린다면 이렇게
문 앞에서 당장 열어야 한다면 아래를 한 번씩만 해 보세요.
- 손잡이를 잡고 문을 위로 살짝 들어 올리는 느낌으로 힘을 준 채 열기
- 문을 안쪽으로 밀면서 번호를 누르거나 열쇠를 돌리기
- 반대로 내 쪽으로 당기면서 다시 해보기
처진 문은 걸쇠가 문틀 구멍 아래쪽에 눌려 있어서 눌림만 풀면 열리는 경우가 많습니다. / 세 가지 모두 안 되면 더 세게 하지 말고 멈춰 주세요.

# 오래된 문에 하면 안 되는 것
- 어깨나 발로 문을 밀어붙이기
- 문틈에 드라이버나 쇠막대를 넣어 들어 올리기
- 나무 문이 끼었다고 문 가장자리를 대패나 칼로 깎기
- 경첩 나사 구멍에 이쑤시개를 잔뜩 넣고 억지로 조이기
나무 문을 여름에 깎으면 겨울에 틈이 벌어져 찬바람이 들고 잠금이 헐거워집니다. / 이쑤시개 보강은 잠깐은 버티지만 문 무게를 오래 견디지 못합니다.

# 마당과 대문이 있는 집이라면
조리읍 주택은 대문을 지나 마당을 건너 현관에 닿는 집이 많습니다. / 대문도 오래됐다면 같은 원인으로 처지거나 걸리는 일이 생깁니다.
대문까지 잠긴 상황이라면 어느 문부터 열어야 하는지 먼저 알려 주세요. / 대문 열쇠나 번호를 가진 가족이 가까이 있는지도 확인해 보세요.
마당에 차를 세울 수 있는지, 골목이 좁은지도 함께 말씀해 주시면 도착이 빨라집니다.

# 전화하실 때 알려주실 것
조리읍은 파주 안에서도 길이 넓게 퍼져 있어 위치를 받고 도착 시간을 먼저 말씀드립니다.
- 주소나 근처에 보이는 큰 건물, 길 이름
- 문 재질 (철문, 나무 문, 샷시형)과 도어락 모양
- 문이 아예 안 열리는지, 힘을 주면 열리는지
- 바닥 긁힘이나 경첩 벌어짐이 보이는지
문 전체, 경첩, 바닥 자국을 찍은 사진을 보내 주시면 필요한 공구와 부품을 챙겨 갑니다. / 늦은 시간에도 출동합니다.

# 신분 확인과 비용 안내
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 이웃이나 집주인 확인 중 하나면 됩니다.
여는 데 드는 비용과 경첩, 문틀을 손보는 비용을 나눠서 작업 전에 먼저 말씀드립니다. / 오늘은 문만 열고 손보는 건 나중에 하셔도 됩니다.
끝내 못 열면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 있습니다.
@ 조리읍 처진 현관문 경첩 보강 작업

# 열린 다음 손보는 순서
먼저 경첩 나사를 다시 잡고, 닳은 구멍은 보강해서 문 무게를 버티게 합니다. / 그다음 문을 여러 번 닫아 보며 걸쇠가 문틀 구멍 가운데로 들어가는지 받침쇠 위치를 맞춥니다.
처짐 때문에 도어락 모터가 무리했다면 [도어락 수리](doorlock-repair.html)로 함께 손봅니다. / 너무 오래돼 부품을 구할 수 없을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
나무 문은 습기를 덜 먹도록 문 아래 바닥 물기 관리를 함께 안내해 드립니다.
손본 뒤에는 사시는 분이 직접 문을 열고 닫으며 바닥에 끌리지 않는지, 잠금이 한 번에 걸리는지 확인하시게 합니다. / 계절이 바뀌고 다시 틈이 달라지면 사진 한 장 보내 주셔도 상태를 말씀드릴 수 있습니다.

# 조리읍 말고 파주 다른 동네
조리읍 옆 금촌동, 교하동, 운정동부터 문산읍, 파주읍, 법원읍, 탄현면, 월롱면까지 파주 전 지역 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 오래된 문 점검 때 묻는 것
? 나무 문이 여름에만 끼는데 괜찮나요? | 습기 때문일 가능성이 큽니다. 깎지 마시고 경첩과 틈부터 점검해 보세요.
? 경첩 나사만 조이면 되나요? | 구멍이 덜 닳았다면 됩니다. 헛돌면 보강이 필요합니다.
? 문을 새로 달아야 하나요? | 대부분 손봐서 씁니다. 문틀이 크게 틀어졌을 때만 교체를 말씀드립니다.
? 대문도 같이 봐 주시나요? | 네, 대문 잠금장치와 처짐도 함께 봅니다.
? 못 열면 비용이 나오나요? | 못 열면 받지 않습니다.
