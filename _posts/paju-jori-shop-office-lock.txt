# 조리읍 가게 문 앞, 오픈 시간은 다가오는데
조리읍은 단독주택과 연립이 많은 파주의 읍 지역으로, 읍내 길가에 가게와 작은 사무실이 이어져 있습니다. / 아침 일찍 셔터를 올리고 출입문을 여는 순간 도어락이 반응하지 않으면 하루 시작부터 막힙니다.
가게 문은 집 현관과 사정이 조금 다릅니다. / 열쇠나 번호를 여러 사람이 나눠 쓰고, 문 모양도 유리문, 철문, 셔터 안쪽 문처럼 다양합니다.
이 글은 조리읍 가게와 사무실에서 출입문이 말썽일 때 영업 전에 확인할 것, 출장을 부를 때 준비할 서류, 문을 연 뒤 정리할 것을 적었습니다. / 급하면 [파주 출장열쇠](paju.html)로 바로 연락 주세요.
@ 조리읍 가게 출입문 도어락 잠김

# 우리 가게 문이 어떤 모양인지부터
가게 출입문은 집보다 종류가 많습니다. / 어떤 문인지에 따라 해볼 수 있는 일과 챙길 장비가 다릅니다.
- 유리문 아래나 위에 다는 바닥형 자물쇠
- 유리문 손잡이에 붙이는 도어락
- 철문이나 나무 문에 단 일반 도어락
- 셔터 안쪽에 따로 있는 출입문 자물쇠
문 사진 한 장만 있으면 어떤 문인지 바로 알 수 있습니다. / 전화하기 전에 정면과 자물쇠 쪽을 한 장씩 찍어 두세요.

# 마지막에 문을 잠근 사람에게 먼저
가게 문이 안 열리면 전날 마지막으로 잠근 사람에게 먼저 연락해 보세요. / 다른 열쇠로 잠갔거나 보조 자물쇠까지 잠근 경우가 의외로 많습니다.
번호식 도어락이라면 누군가 번호를 바꾸지 않았는지도 물어보세요. / 직원이 바뀌었거나 사장님이 관리 차원에서 번호를 바꿨는데 공유가 늦은 일이 생깁니다.
여러 사람이 열쇠를 갖고 있다면 다른 사람 열쇠로도 한 번 시도해 보세요. / 한 열쇠만 닳아 안 맞는 경우라면 그걸로 해결됩니다.
뒷문이나 창고 쪽 출입문이 따로 있는 가게라면 그쪽으로 들어갈 수 있는지도 확인해 보세요. / 안에서 열 수 있으면 앞문 점검은 영업 중에 천천히 해도 됩니다.

# 번호판이 꺼졌다면 건전지부터
가게는 주말이나 휴무일에 며칠씩 문을 쓰지 않아 건전지가 다 된 줄 모르기 쉽습니다. / 번호판에 불이 안 들어오면 바깥쪽 비상 단자에 9V 건전지를 대 보세요.
비상 단자가 없는 제품이나 건전지를 대도 반응이 없다면 그때 연락 주시면 됩니다. / 문이 열리면 안쪽 건전지를 모두 새것으로 바꾸고, 바꾼 날짜를 몸체에 적어 두세요.

# 유리문 바닥 자물쇠가 안 돌아갈 때
유리문 아래 바닥에 꽂는 자물쇠는 먼지와 모래가 잘 들어갑니다. / 길가에 바로 붙은 가게라면 바람에 날린 흙먼지가 홈에 쌓이기 쉽습니다. / 평소 문 닫을 때 바닥 홈을 빗자루로 한 번 쓸어 주면 이런 일이 줄어듭니다.
열쇠가 반쯤 들어가다 걸리면 억지로 밀어 넣지 마세요. / 바닥 홈에 낀 이물질 때문에 걸쇠가 안 빠지는 경우라면 무리하게 돌리다 열쇠가 부러질 수 있습니다.
유리문은 힘을 주어 당기거나 밀면 유리와 문틀 연결부가 상할 수 있습니다. / 비싼 수리로 이어지기 쉬우니 손잡이를 세게 흔드는 것도 피해 주세요.
@ 조리읍 유리문 바닥 자물쇠 점검

# 하지 말아야 할 응급처치
- 유리문 틈에 드라이버를 넣어 젖히기
- 셔터를 반쯤 올린 채 몸을 넣어 안쪽 문 열기
- 열쇠 구멍에 기름을 잔뜩 뿌리기
- 번호를 여러 번 바꿔 눌러 입력 제한 걸리게 하기
가게 문은 유리와 큰 철판이 많아 한 번 상하면 고치는 데 오래 걸립니다. / 영업이 급할수록 억지로 하지 말고 연락 주시는 편이 결국 빠릅니다.

# 사업장 확인에 필요한 서류
가게와 사무실 문을 열 때는 그곳을 쓰는 분인지 먼저 확인합니다. / 아래 중 하나를 준비해 주세요.
- 사업자등록증(사진도 괜찮습니다)
- 그 점포의 임대차 계약서
- 건물주나 관리인의 확인
직원이 대신 부르는 경우에는 대표나 관리 책임자와 통화가 되면 진행할 수 있습니다. / 사업자등록증 사진을 휴대폰에 하나 저장해 두시면 이럴 때 바로 쓸 수 있습니다.

# 전화로 알려 주실 것
- 조리읍 가게 주소와 가까운 큰길
- 문 종류(유리문, 철문, 셔터 안쪽 문)
- 번호식인지 열쇠식인지, 번호판 상태
- 영업 시작 시간과 급한 정도
- 확인 서류를 지금 갖고 있는지
영업 시작 시간을 알려 주시면 그에 맞춰 도착 시간을 말씀드립니다. / 조리읍은 읍내와 마을 사이 거리가 있어 위치를 받은 뒤 시간을 안내합니다.

# 비용은 작업 전에 먼저 말씀드립니다
문 종류와 자물쇠 상태를 보고 어떻게 열지, 비용이 얼마인지 손대기 전에 말씀드립니다. / 사업장이라 영수증이 필요하시면 미리 말씀해 주세요.
끝내 열지 못하면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에, 여는 방식은 [현관문 개방](door-open.html)에 정리해 두었습니다.
@ 조리읍 사무실 출입문 출장열쇠 작업

# 문을 연 뒤 영업 시작 전에 할 일
문이 열리면 바로 영업에 들어가기 전에 잠김이 정상인지 꼭 확인하세요. / 퇴근 때 문이 안 잠겨 밤새 열려 있는 일이 생기면 더 큰 일입니다.
안에서 잠그고 밖에서 여는 것을 두세 번 해 보고, 유리문이라면 바닥 자물쇠가 끝까지 들어가는지 봅니다. / 이상이 있으면 그 자리에서 손보는 편이 다시 부르는 것보다 낫습니다. / 오늘 문을 연 사람과 원인도 직원들과 함께 공유해 두면 같은 일이 덜 생깁니다.

# 직원이 바뀔 때 번호와 열쇠 정리
가게 문은 드나드는 사람이 자주 바뀝니다. / 직원이 그만두면 그날 번호를 바꾸고, 열쇠를 돌려받았는지 확인하세요.
열쇠를 돌려받지 못했다면 실린더를 바꾸는 것도 생각해 볼 만합니다. / 번호식이라면 직원마다 다른 카드를 주고, 그만둘 때 그 카드만 지우는 방식이 관리하기 편합니다.
누가 어떤 열쇠나 카드를 갖고 있는지 간단히 장부로 적어 두세요. / 문제가 생겼을 때 누구에게 먼저 물어볼지 바로 알 수 있습니다.

# 오래된 가게 자물쇠, 바꿀 때가 됐다면
열쇠가 자주 걸리거나 유리문 자물쇠가 헐거워졌다면 [도어락 수리](doorlock-repair.html)로 먼저 손볼 수 있습니다. / 번호식으로 바꾸고 싶다면 [도어락 설치](doorlock-install.html) 전에 문 종류에 맞는 제품을 함께 고릅니다.
지금 쓰는 도어락이 오래됐다면 [도어락 교체](doorlock-replace.html)도 상의해 드립니다. / 임대 점포라면 건물주와 미리 이야기해 두시는 것이 좋습니다. / 휴무일에 맞춰 작업 날을 잡으면 영업에 지장이 없습니다.

# 조리읍 밖 파주 출장
조리읍과 가까운 금촌동, 운정동, 교하동부터 문산읍, 파주읍, 법원읍, 탄현면, 월롱면까지 파주 전 지역을 다닙니다. / 파주 안내는 [파주시 출장열쇠](paju.html), 다른 지역은 [출장 지역](area.html)에서 보세요.

# 자주 묻는 질문

? 유리문 바닥 자물쇠도 열 수 있나요? | 네, 자물쇠 상태를 보고 유리문이 상하지 않는 방법으로 엽니다.
? 이른 아침 영업 전에도 오시나요? | 24시간 받으며, 영업 시작 시간을 알려 주시면 맞춰 보겠습니다.
? 영수증을 받을 수 있나요? | 사업장 작업이라 필요하시면 미리 말씀해 주세요.
? 그만둔 직원 카드만 지울 수 있나요? | 제품에 따라 다르며, 어려우면 전체 정리 뒤 남은 카드를 다시 등록합니다.

# 마무리

24시출장열쇠는 이른 아침 영업 전에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
