# 문산읍, 열쇠가 반쯤 돌다 멈췄을 때
문산읍은 문산역 둘레 읍내에 주택가와 상가가 모여 있고, 조금 들어가면 오래된 마을이 이어지는 동네입니다. / 도어락이 흔해졌어도 대문, 보조키, 가게 셔터 안쪽 문처럼 아직 열쇠를 쓰는 곳이 많습니다.
열쇠는 매일 쓰다 보면 어느 날 갑자기 말을 듣지 않습니다. / 끝까지 들어가지 않거나, 들어가도 돌아가지 않거나, 돌린 뒤 빠지지 않는 식입니다.
이 글은 문산읍에서 열쇠가 말썽일 때 증상별 원인과 집에서 해볼 수 있는 일, 하지 말아야 할 일을 적었습니다. / 손을 쓸 수 없을 때는 [파주 출장열쇠](paju.html)로 연락 주세요.
@ 문산읍 열쇠 실린더 안 돌아감

# 열쇠 문제는 세 가지 모양으로 옵니다
증상에 따라 원인이 다르니 먼저 지금 상태를 나눠 보세요.
- 열쇠가 구멍에 끝까지 안 들어간다
- 끝까지 들어가는데 돌아가지 않는다
- 돌아는 갔는데 빠지지 않는다
세 가지가 한꺼번에 오기도 하지만 대개 하나에서 시작합니다. / 어디서 막혔는지 알면 힘을 줄지 말지도 정할 수 있습니다.
최근에 열쇠를 새로 복사했다면 그것도 떠올려 보세요. / 복사한 열쇠는 홈이 미세하게 달라 처음 몇 번은 되다가 점점 안 맞는 경우가 있습니다.

# 끝까지 안 들어갈 때
열쇠가 중간에서 걸리면 구멍 안에 먼지나 이물질이 있을 가능성이 큽니다. / 장난으로 누군가 무언가를 넣었거나, 오래 안 쓴 자물쇠에 흙먼지가 쌓인 경우입니다.
열쇠 자체가 휘었거나 끝이 닳은 것은 아닌지도 보세요. / 다른 여분 열쇠가 있다면 그것으로 한 번 넣어 보면 어느 쪽 문제인지 금방 압니다.
여분 열쇠는 잘 들어가는데 쓰던 열쇠만 걸린다면 열쇠를 새로 맞추면 되는 경우가 많습니다.
구멍을 들여다봤을 때 이물질이 보여도 핀이나 이쑤시개로 파내지는 마세요. / 더 깊이 밀려 들어가 꺼내기 어려워질 수 있습니다.

# 들어가는데 돌아가지 않을 때
가장 흔한 경우입니다. / 실린더 안쪽 작은 핀들이 열쇠 홈과 맞아야 돌아가는데, 닳거나 먼지가 끼면 핀이 제자리에 서지 않습니다.
열쇠를 끝까지 넣은 뒤 아주 살짝 빼서 다시 돌려 보세요. / 반 밀리 정도 차이로 핀이 맞아 돌아가는 일이 있습니다.
문이나 대문을 몸 쪽으로 당기거나 밀면서 돌려 보는 것도 방법입니다. / 문이 처져 걸쇠가 눌려 있을 때 이렇게 하면 풀리기도 합니다.
@ 문산읍 대문 열쇠 꽂고 문 밀면서 돌리기

# 돌린 뒤 빠지지 않을 때
열쇠가 꽂힌 채 안 빠지면 대개 열쇠가 처음 위치까지 돌아오지 않은 것입니다. / 열쇠를 넣었던 각도로 정확히 되돌린 뒤 천천히 빼 보세요.
열쇠가 휘었거나 금이 가 있다면 무리하게 빼다가 부러질 수 있습니다. / 부러진 조각이 안에 남으면 꺼내는 작업부터 해야 해서 일이 커집니다.
이럴 때 펜치로 잡아 비틀지 마세요. / 열쇠가 그대로 꽂혀 있으면 오히려 꺼내기 쉬운 상태라 그대로 두고 연락 주시는 편이 낫습니다.

# 겨울 아침에만 안 돌아간다면
날이 추우면 자물쇠 안쪽에 있던 습기가 얼어 핀이 움직이지 않습니다. / 바깥에 바로 닿는 대문 자물쇠는 겨울 새벽에 이런 일이 종종 생깁니다.
해가 들고 기온이 오르면 저절로 풀리기도 하니, 급하지 않다면 조금 기다려 보는 것도 방법입니다.
손으로 열쇠를 잠시 쥐어 따뜻하게 한 뒤 넣어 보세요. / 라이터로 열쇠를 달구거나 뜨거운 물을 붓는 것은 피해 주세요. 녹은 물이 다시 얼어 더 나빠집니다.

# 윤활제를 쓴다면 이렇게
열쇠 구멍에 식용유나 일반 기름을 넣으면 먼지와 엉겨 오히려 뻑뻑해집니다. / 쓸 거라면 자물쇠용 건식 윤활제를 아주 조금만 쓰세요.
윤활제를 넣은 뒤에는 열쇠를 여러 번 넣었다 빼며 안쪽에 고루 퍼지게 합니다. / 그래도 돌아가지 않으면 실린더 안쪽이 닳은 것이라 교체를 생각해야 합니다.

# 이렇게 하면 실린더가 망가집니다
- 펜치나 렌치로 열쇠를 잡고 세게 돌리기
- 다른 열쇠나 드라이버를 넣어 억지로 돌리기
- 망치로 열쇠 머리를 두드리기
- 순간접착제가 묻은 손으로 열쇠 만지기
이런 시도는 대부분 열쇠를 부러뜨리거나 실린더를 망가뜨립니다. / 열쇠 하나 바꾸면 될 일이 자물쇠 교체로 커지니 멈춰 주세요. / 이미 해 본 것이 있다면 숨기지 말고 말씀해 주시면 됩니다.

# 가게 문이라면 영업 시간 전에
문산역 근처 가게에서 아침에 셔터 안쪽 문 열쇠가 안 돌아가는 일도 있습니다. / 영업 시작 전이라 급하시겠지만 억지로 돌리면 더 오래 걸립니다.
가게는 그곳을 쓰는 분인지 사업자등록증이나 임대차 계약서로 확인합니다. / 미리 사진으로라도 준비해 두시면 시작이 빨라집니다.
열쇠를 여러 직원이 나눠 쓰는 가게라면 누가 마지막으로 잠갔는지도 확인해 보세요. / 다른 열쇠로 잠갔거나 잠금 방향을 반대로 돌린 경우도 있습니다.

# 전화 주실 때 알려 주실 것
문산읍은 읍내와 마을 사이 거리가 있어 위치를 먼저 여쭙습니다.
- 주소와 문산역에서 어느 방향인지
- 현관, 대문, 보조키, 가게 문 중 어느 것인지
- 세 가지 증상 중 어디에 해당하는지
- 열쇠가 지금 꽂혀 있는지, 휘거나 금이 갔는지
열쇠와 자물쇠 사진을 함께 보내 주시면 맞는 실린더와 공구를 챙겨 가기 좋습니다. / 열쇠 머리에 새겨진 글자나 숫자가 보이면 그것도 찍어 주세요.

# 도착하면 확인과 비용 안내부터
문을 열어야 하는 상황이라면 사시는 분이나 쓰시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 찍힌 우편물, 계약서 중 하나를 준비해 주세요.
그다음 상태를 보고 어떻게 할지, 비용이 얼마인지 손대기 전에 말씀드립니다. / 끝내 열지 못하면 비용은 받지 않습니다. 진행 방식은 [이용안내](guide.html)에 있습니다.
@ 문산읍 출장열쇠 실린더 점검 비용 안내

# 고칠까, 실린더를 바꿀까
열쇠만 닳았다면 새 열쇠를 맞추는 것으로 끝나기도 합니다. / 이때는 닳은 열쇠 말고 덜 쓴 여분 열쇠를 기준으로 맞추는 것이 좋습니다. / 실린더 안쪽이 닳았다면 실린더만 바꾸면 되고, 문 전체를 바꿀 일은 드뭅니다.
열쇠 관리가 번거롭다면 현관을 도어락으로 바꾸는 것도 방법입니다. / 그럴 때는 [도어락 설치](doorlock-install.html) 전에 문 두께와 구멍을 먼저 봅니다. 이미 단 도어락이 말썽이면 [도어락 수리](doorlock-repair.html)를 보세요.
문이 잠긴 채 열쇠가 안 돌아 못 들어가는 상황이라면 [현관문 개방](door-open.html)부터 진행합니다.

# 문산읍 말고 파주 어디든
문산읍과 가까운 파주읍, 월롱면, 법원읍부터 금촌동, 운정동, 교하동, 조리읍, 탄현면까지 파주 전 지역을 다닙니다. / 파주 안내는 [파주시 출장열쇠](paju.html), 다른 지역은 [출장 지역](area.html)에서 보세요.

? 열쇠가 꽂힌 채 안 빠지는데 그냥 둬도 되나요? | 무리하게 빼다 부러지는 것보다 그대로 두고 연락 주시는 편이 낫습니다.

? 실린더만 바꿀 수 있나요? | 대부분 실린더만 바꾸면 되고 문을 바꿀 필요는 드뭅니다.
? 가게 셔터 안쪽 문도 오시나요? | 네, 사업자등록증이나 계약서로 확인한 뒤 진행합니다.
