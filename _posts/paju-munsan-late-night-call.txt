# 문산읍에서 밤늦게 문이 안 열릴 때
문산읍은 문산역 둘레 상가와 주택가, 조금 안쪽 마을까지 분위기가 다른 동네가 이어져 있습니다. / 밤이 깊을수록 불이 꺼진 길이 많아 문 앞에서 막히면 더 막막합니다.
퇴근이 늦었거나 모임을 마치고 돌아왔는데 번호판이 반응이 없는 상황을 가장 많이 듣습니다. / 이 글은 문산읍에서 한밤에 문이 안 열릴 때 어떤 순서로 움직이면 되는지 적었습니다.
급할수록 문을 세게 흔들게 되는데, 그러면 일이 더 커집니다. / 먼저 숨을 한 번 고르고 아래 순서대로 보시면 됩니다.
@ 문산읍 24시 출장열쇠 한밤 현관문 개문

# 먼저 안전한 곳에 계세요
새벽이나 한밤에는 문 앞 복도에 오래 서 있지 않는 게 좋습니다. / 복도가 어둡거나 인적이 드물면 밝은 곳이나 공동현관 안쪽으로 자리를 옮겨 주세요.
추위가 심한 계절이면 겉옷을 챙기고, 휴대폰 배터리가 얼마나 남았는지도 확인해 주세요. / 전화가 끊기면 위치를 다시 설명해야 해서 시간이 더 걸립니다.
혼자 계신 것이 걱정되면 가족이나 지인에게 지금 어디에 있는지 문자 한 통 남겨 두세요. / 열쇠집을 부르는 동안 연락이 닿는 사람이 있으면 마음이 한결 놓입니다.

# 전화 한 통으로 전할 것 네 가지
통화에서 꼭 필요한 정보는 네 가지입니다. / 이것만 말씀해 주시면 도착 준비가 훨씬 빨라집니다.
- 지금 서 있는 곳 (건물 이름이나 도로 쪽 방향, 가까운 눈에 띄는 곳)
- 문 상태 (번호판이 꺼졌는지, 소리가 나는지, 걸쇠가 걸렸는지)
- 도어락 모양 (손잡이 일체형인지, 버튼형인지, 열쇠구멍이 있는지)
- 집 안에 사람이나 반려동물, 켜 둔 불이 있는지
설명이 어려우면 도어락 사진을 문자로 보내 주셔도 됩니다. / 사진 한 장이 긴 설명보다 정확할 때가 많습니다.

# 문산역 쪽인지 읍내 안쪽인지 알려주세요
문산읍은 역 근처와 안쪽 동네의 도로 모양이 다릅니다. / 같은 읍 안이라도 어느 방향에서 들어가야 하는지에 따라 도착 시간이 달라질 수 있습니다.
문산역을 기준으로 어느 쪽인지, 큰길에서 몇 번째 골목쯤인지 대략만 말씀해 주세요. / 정확한 번지를 모르셔도 괜찮습니다.
위치를 받으면 예상 도착 시간을 먼저 말씀드립니다. / 길이 막히거나 외진 곳이면 그 사정도 솔직하게 알려드립니다.

# 번호판 상태를 말로 설명하는 법
번호판이 보여 주는 모습이 원인을 가리킬 때가 많습니다. / 말씀해 주시면 전화로도 어느 정도 짐작이 됩니다.
- 아무것도 안 켜진다: 배터리가 다 됐을 가능성이 큽니다
- 켜지지만 누르면 짧게 경고음만 난다: 배터리 부족 경고일 수 있습니다
- 소리는 나는데 문이 안 풀린다: 모터나 걸쇠 쪽을 의심합니다
- 비밀번호를 여러 번 틀려 잠깐 막힌 상태: 시간이 지나면 풀리기도 합니다
어느 쪽에 가까운지만 알려주셔도 충분합니다. / 정확히 모르겠으면 보이는 그대로 말씀해 주세요.

# 한밤에 하면 안 되는 일
급한 마음에 칼이나 드라이버로 문틈을 벌리는 분이 있습니다. / 문틀과 도어락 외관이 상하고 다치기도 쉬워서 절대 권하지 않습니다.
문을 발로 차거나 어깨로 밀면 걸쇠가 더 깊이 물릴 수 있습니다. / 이웃도 놀라시니 조용히 기다리는 편이 낫습니다.
비밀번호를 계속 눌러 보는 것도 서너 번에서 멈춰 주세요. / 오류가 쌓이면 도어락이 한동안 입력을 막아 버립니다.
@ 문산 열쇠집 도어락 한밤 출장 대기

# 이웃에게 양해를 구할 때
밤에 복도에서 소리가 나면 이웃이 놀랄 수 있습니다. / 필요하면 가까운 이웃에게 사정을 짧게 말씀드려 두세요.
공동현관이 잠겨 있으면 열쇠집이 들어가지 못하기도 합니다. / 이때는 경비실이나 관리사무소, 안에 계신 가족에게 연락해 문을 열어 달라고 부탁해 주세요.
관리사무소가 닫힌 시간이면 도착해서 전화 주시면 그때 방법을 같이 찾습니다. / 미리 걱정하지 않으셔도 됩니다.

# 도착 시간은 위치를 받고 말씀드립니다
문산읍은 넓어서 어디서 출발하는지에 따라 걸리는 시간이 다릅니다. / 그래서 위치를 받은 뒤에 예상 시간을 알려드립니다.
도착 전까지 문 앞 상태를 그대로 두고 기다려 주세요. / 이것저것 만져 보시면 원인을 가리기가 더 어려워집니다.
오는 동안 연락이 필요하면 같은 번호로 다시 전화 주세요. / 길을 못 찾으시겠다 싶으면 사진이나 위치를 한 번 더 보내 주셔도 됩니다.

# 신분 확인은 밤에도 합니다
문을 여는 일이라서 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
시간이 늦었다고 이 절차를 건너뛰지 않습니다. / 이웃과 손님 모두를 위한 약속입니다.
신분증이 집 안에 있다면 휴대폰에 저장된 주소 증명이나 택배 내역 같은 것도 같이 살펴봅니다. / 그래도 확인이 안 되면 작업을 할 수 없는 점은 미리 말씀드립니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 그때 시작하고, 아니라고 하시면 그냥 돌아갑니다.
한밤이라고 해서 설명 없이 값이 붙지 않습니다. / 부품을 바꿔야 하는 경우에는 바꾸기 전에 한 번 더 여쭙습니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 작업은 조용하게 합니다
밤에는 소리가 멀리 퍼집니다. / 이웃 잠을 방해하지 않도록 최대한 조용히 작업합니다.
문이나 도어락이 상하지 않는 방법부터 차례로 해 봅니다. / 자세한 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.
작업 중에 보이는 문제가 있으면 손대기 전에 먼저 말씀드립니다. / 갑자기 부품을 뜯거나 바꾸는 일은 없습니다.

# 문이 열린 뒤에 확인할 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새 것으로 바꿨는지도 봅니다.
번호를 잊어서 열었다면 안쪽에서 새 번호를 등록하는 것까지 돕습니다. / 예전 번호는 지워 두는 편이 안전합니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 자주 고장이 나면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 파주 문산읍 도어락 점검 후 마무리

# 다음에 같은 일이 없도록
배터리는 경고음이 나는 날 바로 새 것으로 바꿔 주세요. / 한밤에 꺼지는 일은 대부분 며칠 전 경고음을 놓쳐서 생깁니다.
비상용 9V 건전지를 가방이나 현관 서랍에 하나 두면 번호판이 꺼졌을 때 바로 시도해 볼 수 있습니다. / 단자가 있는 제품인지 한 번 확인해 두세요.
가족과 비밀번호를 같이 정하고, 열쇠나 카드키를 하나는 따로 보관해 두면 좋습니다. / 작은 습관이 한밤의 곤란을 많이 줄여 줍니다.

# 문산읍 말고 파주 어디든 갑니다
문산읍 말고도 금촌, 운정, 교하, 파주읍, 법원읍까지 파주 전 지역으로 다닙니다. / 24시간 받으니 시간 신경 쓰지 말고 전화 주세요.
파주에서 다니는 동네는 [파주시 출장열쇠](paju.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 못 열면 돈을 내야 하나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.
