# 문산역 근처 원룸, 열쇠도 번호도 막혔을 때
문산읍은 문산역 주변 읍내에 주택가와 상가가 모여 있고, 그 사이사이 원룸 건물과 상가 위층 원룸이 섞여 있는 동네입니다. / 혼자 지내는 분이 원룸에 사시는 경우가 많아 문 잠김 연락도 원룸 건물에서 종종 옵니다.
원룸은 아파트처럼 관리사무소가 늘 있는 곳이 드뭅니다. / 그래서 문이 잠겼을 때 "누구에게 먼저 연락하지?"부터 막막해집니다.
이 글은 문산읍 원룸에서 현관이 잠겼을 때 집주인 연락부터 출장 요청까지 흐름을 순서대로 적었습니다. / 바로 도움이 필요하면 [파주 출장열쇠](paju.html)로 전화 주세요.
@ 문산역 원룸 건물 현관 잠김

# 흐름 1, 지금 어디가 잠겼는지 정하기
원룸 건물은 출입문이 두 곳인 경우가 많습니다. / 건물 1층 출입문과 내 방 문 중 어디에서 막혔는지 먼저 정해 보세요.
1층 출입문이 번호식인데 번호를 모른다면 같은 건물 이웃이나 집주인에게 물어보는 게 빠릅니다. / 출입문 근처에 관리 연락처 스티커가 붙어 있는지도 보세요.
방 문이 잠겼다면 번호판이 켜지는지, 열쇠식인지, 안쪽 걸쇠가 걸렸는지에 따라 다음 흐름이 달라집니다.

# 흐름 2, 집주인에게 먼저 묻기
문산읍 원룸은 집주인이 같은 건물이나 가까운 곳에 사는 경우가 있습니다. / 비상 열쇠나 초기 번호를 갖고 있을 수 있으니 먼저 연락해 보세요.
늦은 시간이라 연락이 망설여진다면 문자로 상황을 남겨 두시고 저희에게도 함께 연락 주셔도 됩니다. / 집주인과 연락이 안 돼도 사시는 분이 확인되면 문을 열 수 있습니다.
집주인이 번호를 알려 줬는데 안 열린다면 입주 뒤 번호를 바꾼 적이 없는지 떠올려 보세요. / 바꾼 번호를 잊었다면 집주인 번호도 소용이 없습니다.

# 흐름 3, 번호판 상태 보기
번호판이 아예 안 켜지면 건전지 방전일 가능성이 큽니다. / 원룸 도어락은 입주할 때 건전지를 새로 갈지 않은 경우가 많아 생각보다 빨리 꺼집니다.
번호판 아래 비상 단자가 있으면 9V 건전지를 대고 번호를 눌러 보세요. / 문산역 주변 편의점에서 구하실 수 있습니다.
번호판은 켜지는데 번호가 틀렸다고 나오면 서너 번 안에 멈추세요. / 여러 번 틀리면 입력이 막혀 기다리는 시간만 길어집니다.
@ 문산읍 원룸 도어락 번호판 비상 전원

# 흐름 4, 열쇠식 자물쇠라면
오래된 원룸 건물은 아직 열쇠로 여는 문도 있습니다. / 열쇠를 방 안에 두고 문을 닫았다면 집주인 여분 열쇠가 가장 빠른 길입니다.
열쇠가 있는데 안 돌아간다면 억지로 비틀지 마세요. / 원룸 열쇠는 여러 번 복사한 것이 많아 이가 닳아 있고, 힘을 주면 쉽게 부러집니다.
열쇠가 부러져 안에 남았다면 더는 건드리지 말고 연락 주세요.
열쇠식 문을 열고 들어간 뒤에는 실린더를 새것으로 바꿀지 집주인과 상의해 보세요. / 몇 사람을 거친 원룸 열쇠는 누가 복사본을 갖고 있는지 알기 어렵기 때문입니다.
번호식 도어락으로 바꾸는 것을 원하시면 문 두께와 구멍을 보고 맞는 제품을 말씀드립니다.

# 흐름 5, 안쪽 걸쇠가 걸렸다면
도어락은 풀렸는데 문이 조금만 열리고 멈춘다면 안쪽 걸쇠가 걸린 것입니다. / 함께 사는 사람이 안에 있다면 전화해서 풀어 달라고 하시면 됩니다.
아무도 없는데 걸렸다면 밖에서 해볼 것은 거의 없습니다. / 문틈에 손이나 도구를 넣지 말고 그대로 두고 연락 주세요.
나올 때 걸쇠가 저절로 넘어가 걸리는 구조라면 들어간 뒤 걸쇠 방향이나 위치를 손봐 드릴 수 있습니다.

# 상가 위층 원룸과 오피스텔은 조금 달라요
상가 건물 위층 원룸은 1층 가게 옆 계단으로 올라가는 구조가 많습니다. / 밤에는 계단 입구 셔터나 출입문이 닫혀 있기도 하니, 건물 출입이 되는지 먼저 확인해 주세요.
가게가 문을 닫은 시간이라 계단 출입문 열쇠를 가진 사람이 집주인뿐이라면 그 사정도 함께 알려 주세요. / 출입 방법을 같이 찾은 뒤 방 문을 엽니다.
오피스텔은 건물 관리실이 낮에만 운영되는 곳이 있습니다. / 관리실 연락처가 엘리베이터 안이나 1층 게시판에 붙어 있는 경우가 많으니 사진을 찍어 두시면 좋습니다.
어느 쪽이든 건물 출입과 방 문 열기를 나눠 생각하면 해결 순서가 분명해집니다.

# 거주 확인, 이렇게 준비하세요
원룸은 전입 신고를 아직 안 했거나 신분증 주소가 예전 집인 분이 많습니다. / 그래도 아래 중 하나가 있으면 됩니다.
- 신분증 주소가 이 건물로 되어 있는 경우
- 임대차 계약서나 계약서 사진
- 이 주소로 온 우편물이나 택배 송장
- 집주인이나 관리인의 전화 확인
문을 연 직후 방 안에 있는 서류로 확인하는 방법도 있습니다. / 이 경우 옆에서 확인해 줄 이웃이나 집주인이 있으면 더 수월합니다.

# 기다리는 동안 하지 않을 것
- 창문이나 베란다를 통해 들어가 보기
- 문을 발로 차거나 어깨로 밀기
- 카드나 자를 문틈에 넣어 걸쇠 밀기
- 번호판을 손으로 두드리기
원룸 도어락은 집주인 소유인 경우가 많습니다. / 상하게 하면 나중에 다시 맞춰 드려야 할 수 있으니 무리하지 않는 게 좋습니다.

# 문산읍 위치는 이렇게 알려주세요
문산읍은 파주 북쪽이라 위치를 받고 도착 시간을 먼저 말씀드립니다. / 아래를 알려 주시면 길을 헤매지 않습니다.
- 건물 이름과 호수, 문산역에서 어느 쪽인지
- 근처에 보이는 큰 건물이나 길 이름
- 1층 출입문이 잠겨 있는지
- 도어락 모양, 열쇠식인지 번호식인지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙겨 갑니다. / 반려동물이 방 안에 있다면 꼭 먼저 말씀해 주세요.

# 도착 후 진행과 비용
도착하면 거주 확인을 먼저 하고, 도어락 상태를 본 뒤 어떻게 열지 말씀드립니다. / 비용도 작업 전에 먼저 말씀드리고 괜찮다고 하실 때 시작합니다.
끝내 못 열면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 전체 진행은 [이용안내](guide.html)에 정리해 두었습니다.
@ 문산읍 원룸 거주 확인 후 출장 개문

# 들어간 뒤 같이 정리할 것
건전지 문제였다면 건전지를 모두 새것으로 바꿉니다. / 번호를 잊었다면 새 번호를 등록하고 예전 번호는 지웁니다.
도어락이 낡아 자주 말썽이었다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 바꿔야 할 때는 집주인과 상의하신 뒤 [도어락 교체](doorlock-replace.html)를 정하시면 됩니다. / 원룸은 계약 내용에 따라 누가 바꿀지가 달라지니 미리 확인해 보세요.
새 번호와 1층 출입문 번호는 휴대폰 메모에 함께 적어 두세요. / 휴대폰을 방에 두고 나오는 일도 있으니 가까운 가족에게도 한 번 알려 두시면 좋습니다.

# 문산읍 말고 파주 다른 곳
문산읍 옆 파주읍, 월롱면, 법원읍부터 금촌동, 조리읍, 교하동, 운정동, 탄현면까지 파주 전 지역 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
