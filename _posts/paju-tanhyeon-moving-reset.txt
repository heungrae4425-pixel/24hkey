# 탄현면 새 집, 도어락은 아직 전 주인 것입니다
탄현면은 운정 신도시와 맞닿은 면 지역으로, 빌라와 단독주택, 전원주택이 마을마다 모여 있습니다. / 운정 쪽 아파트에서 넓은 주택으로 옮겨 오는 분도 있고, 시내에서 아예 이사 오는 분도 있습니다.
이사를 마치고 짐을 풀다 보면 현관 도어락은 받은 번호로 열리니 그냥 쓰게 됩니다. / 하지만 그 도어락에는 이전에 살던 분의 번호와 카드, 휴대폰 연동이 그대로 남아 있을 수 있습니다.
이 글은 탄현면으로 이사한 뒤 도어락을 초기화하고 새 비밀번호를 거는 순서를 정리했습니다. / 막히는 부분이 있으면 [파주 출장열쇠](paju.html)로 연락 주세요.
@ 탄현면 이사 후 도어락 초기화

# 초기화가 필요한 이유
집 열쇠를 넘겨받으면 문이 열리는 방법이 모두 내 손에 들어온 것처럼 느껴집니다. / 그런데 도어락은 번호 여러 개, 카드 여러 장을 기억할 수 있어서 내가 모르는 열림 방법이 남아 있을 수 있습니다.
이전 사람이 가족에게 따로 알려 준 번호나 돌려주지 않은 카드가 그런 경우입니다. / 초기화는 이런 것들을 한 번에 지우고 새로 시작하는 과정입니다.
새로 지은 집에 처음 들어가는 경우라도 공사하는 동안 쓰던 임시 번호가 남아 있을 수 있습니다. / 첫 입주라도 한 번은 정리하고 쓰시는 편이 좋습니다.

# 시작 전에 준비할 것
초기화를 시작하기 전에 몇 가지를 챙겨 두면 중간에 멈추지 않고 끝낼 수 있습니다. / 특히 문을 열어 둔 상태에서 해야 한다는 점을 꼭 기억해 주세요.
- 새 건전지 한 세트
- 도어락 제품 이름이나 설명서
- 새로 쓸 비밀번호 메모
- 등록할 카드나 태그
- 문을 열어 고정해 둘 받침
배터리가 약한 상태에서 초기화를 하면 중간에 전원이 끊겨 설정이 꼬일 수 있습니다. / 먼저 건전지를 전부 새것으로 바꾸고 시작하세요.

# 초기화 버튼은 어디 있을까
초기화 버튼은 대부분 안쪽 몸체 배터리 덮개 안에 있습니다. / 작은 구멍 안에 있거나 등록 버튼을 길게 누르는 방식인 제품이 많습니다.
제품마다 누르는 시간과 순서가 다르니 설명서를 꼭 확인해 주세요. / 설명서가 없다면 제품 앞면이나 배터리 칸 안쪽에 적힌 모델 이름으로 제조사 안내를 찾아볼 수 있습니다.
@ 파주 탄현면 도어락 배터리 덮개 초기화 버튼

# 순서대로 따라 해 보기
제품마다 조금씩 다르지만 큰 흐름은 비슷합니다. / 아래 순서를 기준으로 설명서와 맞춰 보세요.
- 문을 활짝 열고 받침으로 고정하기
- 건전지를 모두 새것으로 바꾸기
- 초기화 버튼이나 등록 버튼으로 전체 삭제하기
- 새 비밀번호 등록하기
- 카드나 태그 다시 등록하기
- 문을 연 채로 바깥에서 새 번호로 열림 확인하기
- 마지막으로 문을 닫고 다시 한 번 확인하기
전체 삭제 뒤에는 기존 번호가 하나도 안 먹히는지도 확인해 보세요. / 이전 번호로 열리면 삭제가 제대로 안 된 겁니다.

# 휴대폰 앱과 이어진 도어락이라면
요즘 도어락 가운데는 휴대폰 앱과 연결해 문을 열거나 알림을 받는 제품이 있습니다. / 이런 제품은 이전 사람의 계정에 묶여 있을 수 있습니다.
도어락 초기화만으로 연결이 끊기지 않는 제품도 있으니 앱 안의 기기 삭제 방법을 확인해 주세요. / 이전 사람과 연락이 닿는다면 그쪽 앱에서 기기를 지워 달라고 부탁하는 것이 가장 깔끔합니다.

# 보조키와 열쇠는 따로 생각해야 합니다
도어락 초기화는 번호와 카드만 지웁니다. / 비상용 열쇠구멍이나 보조키 열쇠는 그대로 남아서 복사본이 있다면 여전히 문을 열 수 있습니다.
주택은 대문과 보조키를 열쇠로 쓰는 집이 많아 이 부분이 더 중요합니다. / 열쇠가 몇 개 나갔는지 모른다면 실린더를 바꾸는 것도 생각해 보세요. / 열쇠 관련 내용은 [열쇠 출장](key-call.html)에 정리해 두었습니다.

# 전원주택은 대문 쪽 장치도 함께
탄현면 전원주택 가운데는 현관뿐 아니라 대문이나 차고 문에도 번호식 잠금이나 리모컨을 쓰는 집이 있습니다. / 현관 도어락만 초기화하고 대문 쪽은 그대로 두면 정리가 반쪽짜리가 됩니다.
대문 잠금이 번호식이라면 현관과 같은 방법으로 전체 삭제 후 다시 등록합니다. / 리모컨을 쓰는 문이라면 몇 개가 등록돼 있는지 확인하고, 받은 것 말고 다른 리모컨이 있었는지 이전 사람에게 물어보세요.
창고나 보일러실처럼 열쇠로 여는 작은 문도 열쇠 개수를 함께 확인해 두면 좋습니다. / 이사 첫 주에 한꺼번에 정리해 두면 나중에 따로 신경 쓸 일이 없습니다.

# 초기화하다 막혔을 때
초기화 버튼을 잘못 눌러 문을 닫았더니 아무 번호도 안 먹히는 일이 생길 수 있습니다. / 이럴 때는 번호를 계속 누르지 말고 멈춰 주세요.
- 문이 열려 있다면 그대로 두고 설명서를 다시 확인
- 경고음이 계속 나면 건전지가 제대로 들어갔는지 확인
- 문이 닫혀 버렸다면 바깥 비상 열쇠구멍이 있는지 살피기
그래도 안 되면 연락 주세요. / 문이 닫힌 상태라면 사시는 분 확인을 거쳐 문을 연 뒤 초기화까지 다시 맞춰 드립니다.

# 새 비밀번호 고르는 법
새 번호는 가족이 외우기 쉽고 남이 짐작하기 어려운 것으로 정하세요. / 집 주소, 생일, 전화번호 끝자리는 피하는 게 좋습니다.
번호를 누르기 전후에 아무 숫자나 더 섞어 누를 수 있는 기능이 있다면 함께 써 보세요. / 번호판에 손자국이 남아 번호가 드러나는 일도 줄어듭니다.
@ 탄현면 새 비밀번호 등록 확인

# 출장으로 초기화를 맡기실 때
직접 하기 어렵거나 설명서가 없다면 맡기셔도 됩니다. / 도착하면 사시는 분이 맞는지 신분증이나 임대차 계약서, 매매 계약서로 먼저 확인합니다.
도어락 상태를 보고 비용을 먼저 말씀드리고, 괜찮으시면 시작합니다. / 문이 잠겨 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.
탄현면은 마을마다 들어가는 길이 달라서 위치를 받으면 예상 도착 시간을 먼저 말씀드립니다.

# 이참에 도어락을 바꾸고 싶다면
이전 사람이 오래 쓴 도어락이라 등록이 잘 안 되거나 버튼이 닳아 있다면 바꾸는 것도 방법입니다. / 쓸 만하다면 굳이 바꾸지 않아도 됩니다.
고장 부분만 손볼 수 있으면 [도어락 수리](doorlock-repair.html), 새로 바꾸신다면 [도어락 교체](doorlock-replace.html) 안내를 참고해 주세요.

# 탄현면 말고 파주 어디든
탄현면 가까운 교하동, 운정동은 물론 금촌동, 문산읍, 조리읍, 파주읍, 법원읍, 월롱면까지 파주 전 지역으로 갑니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

# 자주 묻는 질문
? 초기화하면 기존 번호와 카드가 다 지워지나요? | 대부분 그렇습니다. 끝난 뒤 이전 번호로 열리지 않는지 꼭 확인해 보세요.
? 설명서가 없는데 어떻게 하나요? | 제품 이름을 알려 주시면 방법을 안내해 드립니다. 직접 하기 어려우면 출장으로 맡기셔도 됩니다.
? 앱 연결은 초기화로 끊기나요? | 제품마다 다릅니다. 앱에서 기기 삭제를 따로 해야 하는 경우가 있으니 확인이 필요합니다.
? 초기화하다 문이 닫혀 버렸어요. | 번호를 계속 누르지 말고 연락 주세요. 사시는 분 확인 뒤 문을 열고 설정까지 다시 맞춰 드립니다.
? 보조키 열쇠도 바꿔야 하나요? | 열쇠가 몇 개 나갔는지 모르면 실린더 교체를 권합니다. 상태를 보고 말씀드립니다.
