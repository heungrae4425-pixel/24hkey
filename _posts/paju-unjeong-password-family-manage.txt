# 운정동 우리 집 번호, 누가 알고 있나요
운정동은 운정역과 야당역 둘레로 새 아파트가 많이 들어선 운정 신도시 동네입니다. / 입주하던 날 정한 비밀번호를 지금까지 그대로 쓰는 집도 많습니다.
처음엔 가족만 알던 번호도 시간이 지나면 아는 사람이 늘어납니다. / 이삿짐 업체, 인테리어 작업자, 잠깐 아이를 봐 준 친척, 택배를 대신 받아 준 이웃까지 떠올려 보면 생각보다 많습니다.
이 글은 운정동 가족이 함께 쓰는 도어락 번호를 언제 바꾸면 좋은지, 바꾼 번호를 어떻게 나누고 기억할지 집안 규칙으로 정리하는 방법을 적었습니다. / 바꾸다 막히면 [파주 출장열쇠](paju.html)로 연락 주세요.
@ 운정동 아파트 도어락 비밀번호 가족 관리

# 번호를 아는 사람 목록부터 적어 보기
번호를 바꾸기 전에 지금 번호를 아는 사람을 종이에 적어 보세요. / 적다 보면 바꿔야 할지 말아야 할지 저절로 판단이 섭니다.
- 함께 사는 가족
- 따로 사는 부모님이나 형제
- 집에 드나든 작업자나 도우미
- 번호를 쪽지나 메모로 받은 적 있는 사람
목록에 지금은 연락하지 않는 사람이나 일이 끝난 사람이 있다면 바꿀 때가 된 것입니다. / 카드와 지문을 함께 쓰는 집이라면 등록된 사람 목록도 같이 적어 보세요.

# 이럴 때는 미루지 말고 바꾸기
정해진 주기와 별개로 아래 같은 일이 있었다면 그때 바로 바꾸는 편이 좋습니다.
- 인테리어나 수리 공사가 끝났을 때
- 아이를 돌봐 주던 분이 일을 그만두었을 때
- 번호를 적은 쪽지나 휴대폰을 잃어버렸을 때
- 번호판에 자주 누르는 숫자만 닳아 보일 때
특히 번호판 닳은 자국은 낮에 비스듬히 보면 잘 보입니다. / 반들반들한 숫자 네다섯 개가 보이면 번호를 바꾸거나 허수 입력을 함께 쓰세요.

# 바꾸는 주기는 집집마다 정하면 됩니다
몇 달에 한 번이 정답이라고 말하기는 어렵습니다. / 드나드는 사람이 많은 집은 자주, 가족만 쓰는 집은 덜 자주 바꿔도 됩니다.
가장 잊지 않는 방법은 바꾸는 때를 다른 일과 묶는 것입니다. / 예를 들어 도어락 건전지를 갈 때, 새 학기가 시작할 때, 명절을 지내고 난 뒤처럼 해마다 돌아오는 날에 맞추면 좋습니다.
@ 운정동 도어락 비밀번호 변경 주기

# 새 번호를 정할 때 지킬 것
새 번호는 가족 모두가 외울 수 있으면서 남이 짐작하기 어려워야 합니다. / 생일, 동 호수, 전화번호 끝자리처럼 쉽게 떠오르는 숫자는 피해 주세요.
자리수는 가능한 한 길게 하는 것이 좋습니다. / 여섯 자리 이상이면 아이도 노래처럼 리듬을 붙여 외울 수 있습니다.
같은 숫자를 반복하거나 1234처럼 이어지는 숫자는 쓰지 않습니다. / 예전 번호에서 한 자리만 바꾸는 것도 의미가 적으니 아예 새로 정하세요.

# 가족에게 알리는 방법 정하기
새 번호를 정했다면 어떻게 알릴지도 정해 두세요. / 가장 좋은 건 얼굴을 보고 직접 말로 전하는 것입니다.
떨어져 사는 가족에게 문자로 보내야 한다면 번호만 덩그러니 보내지 말고, 받은 뒤 지워 달라고 부탁하세요. / 단체 대화방은 나중에 들어온 사람도 예전 기록을 볼 수 있어 피하는 편이 좋습니다.
가족 중 한 사람을 번호 담당으로 정해 두는 것도 방법입니다. / 누가 바꿨는지 몰라 헷갈리는 일이 줄어듭니다.

# 번호를 적어 둔다면 어디에 둘까
외우는 것이 가장 좋지만 가족 중에는 적어 두어야 마음이 놓이는 분도 있습니다. / 적어 둔다면 장소를 가족끼리 정해 두세요.
현관 근처, 신발장, 번호판 옆 벽처럼 문 가까운 곳은 피하는 것이 좋습니다. / 지갑이나 휴대폰 메모에 남길 때는 '현관' 같은 단어 없이 숫자만 다른 정보처럼 적어 두는 분도 있습니다.
번호를 바꾸면 예전 번호가 적힌 쪽지와 메모도 함께 지우세요. / 옛 번호와 새 번호가 섞여 있으면 급할 때 오히려 헷갈립니다.

# 아이가 쓰는 번호는 따로 생각하기
초등학생 아이가 혼자 하교하는 집은 아이가 번호를 정확히 외우는지가 중요합니다. / 바꾼 날 저녁에 아이와 함께 문 앞에서 두세 번 눌러 보며 연습하세요.
아이가 번호를 친구에게 말하지 않도록 이유를 쉽게 설명해 주세요. / 아이 가방에 번호를 적어 두는 것은 피하는 것이 좋습니다.
번호를 자주 잊는 아이라면 카드나 지문을 함께 등록해 두면 마음이 편합니다. / 다만 카드는 잃어버릴 수 있으니 번호도 함께 쓰게 하세요.

# 어르신 가족이 함께 산다면
어르신은 갑자기 바뀐 번호를 기억하기 어려워하실 수 있습니다. / 바꾸기 전에 미리 말씀드리고, 새 번호를 몇 번 함께 눌러 보세요.
번호판 숫자가 작거나 어두워 잘 안 보이시면 다른 방식을 함께 쓰는 것도 고려해 보세요. / 지문 등록이 잘 안 되는 분도 있어 등록 후 여러 번 시험해 보는 것이 좋습니다. / 바꾼 뒤 며칠은 어르신이 혼자 들어오실 때 잘 열렸는지 전화로 여쭤봐 주세요.

# 임시 번호가 되는 제품이라면
일부 도어락은 손님용 임시 번호나 한 번만 쓰는 번호를 지원합니다. / 작업자나 도우미에게는 가족 번호 대신 이런 기능을 쓰면 나중에 따로 바꿀 일이 줄어듭니다.
우리 집 제품에 이런 기능이 있는지는 설명서나 제조사 안내에서 확인할 수 있습니다. / 기능이 없다면 일이 끝난 뒤 바로 번호를 바꾸는 습관으로 대신하세요.

# 번호를 바꾸다 문이 막혔을 때
번호를 바꾸다 잘못 저장해 아무도 새 번호를 모르게 되는 경우가 있습니다. / 바꿀 때는 꼭 문을 열어 둔 상태에서 새 번호로 몇 번 시험한 뒤에 닫으세요.
이미 문이 닫혀 버렸다면 번호를 이것저것 눌러 보지 말고 연락 주세요. / 도착하면 사시는 분인지 신분증, 우편물, 관리사무소 확인으로 먼저 확인하고, 비용은 손대기 전에 말씀드립니다.
끝내 열지 못하면 비용은 받지 않습니다. / 여는 방식은 [현관문 개방](door-open.html), 진행 순서는 [이용안내](guide.html)에 있습니다.
@ 운정동 출장열쇠 번호 재설정 도움

# 등록이 어렵거나 제품이 오래됐다면
버튼 순서가 복잡해 혼자 등록하기 어렵다면 방문해서 함께 정리해 드립니다. / 카드와 지문 목록도 지금 쓰는 사람만 남기고 정리합니다.
번호판이 잘 안 눌리거나 저장이 자꾸 풀린다면 [도어락 수리](doorlock-repair.html)가 필요할 수 있습니다. / 기능이 부족한 오래된 제품은 [도어락 교체](doorlock-replace.html) 때 가족 생활에 맞는 방식을 함께 고릅니다.

# 운정동 말고 파주 어디든
운정동과 가까운 교하동, 탄현면부터 금촌동, 문산읍, 조리읍, 파주읍, 법원읍, 월롱면까지 파주 전 지역을 다닙니다. / 파주 안내는 [파주시 출장열쇠](paju.html), 다른 지역은 [출장 지역](area.html)에서 보세요.
