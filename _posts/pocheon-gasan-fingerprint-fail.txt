# 가산면 주택 현관, 손가락을 대도 반응이 없다면
가산면은 마을과 마을 사이가 떨어져 있고 단독주택, 농가주택, 창고가 섞여 있는 곳입니다. / 열쇠 대신 지문 도어락을 단 집도 늘었는데, 바깥일을 마치고 들어오는 길에 지문이 안 먹는다는 연락을 종종 받습니다.
손가락을 몇 번 대도 짧은 경고음만 나고 문이 꿈쩍하지 않으면 피곤한 몸이 더 지칩니다. / 그런데 이 경우 도어락 고장보다 그날 손 상태가 원인인 경우가 꽤 많습니다.
이 글은 가산면 주택에서 지문 인식이 잘 안 될 때 손, 센서, 건전지 순서로 살펴볼 것과 [포천 출장열쇠](pocheon.html)를 부를 때를 정리했습니다.
@ 가산면 주택 지문 도어락 인식 실패 점검

# 오늘 손이 어땠는지 먼저 떠올려 보세요
지문 센서는 손가락 표면의 굴곡을 읽습니다. / 그 굴곡이 흙이나 물기, 굳은살로 덮이면 등록할 때와 다른 손가락으로 읽힙니다.
- 장갑 없이 흙이나 비료를 만졌는지
- 물일이나 세척을 막 끝냈는지
- 찬 바람 속에서 오래 일했는지
- 손끝에 작은 상처나 반창고가 있는지
이 중 하나라도 해당된다면 기계보다 손을 먼저 의심해 보세요. / 같은 손가락으로 아침에는 잘 열렸는데 저녁에만 안 된다면 더욱 그렇습니다.

# 흙과 물기는 센서보다 손에서 먼저
흙 묻은 손가락을 센서에 대면 센서 유리에도 흙이 옮겨 붙습니다. / 그다음부터는 깨끗한 손가락을 대도 실패가 이어집니다.
가까운 수돗가에서 손을 씻고 수건으로 물기를 완전히 닦은 뒤 다시 대 보세요. / 물기가 남아 있으면 그것도 실패의 원인이 됩니다.
손을 씻을 수 없다면 옷소매 안쪽처럼 깨끗한 천으로 손끝을 여러 번 문질러 닦는 것만으로도 달라질 때가 있습니다.

# 굳은살과 작은 상처
농사일을 오래 하신 분들은 손끝에 굳은살이 두껍게 박여 지문이 옅어지기도 합니다. / 계절에 따라 굳은살이 늘었다 줄었다 하면서 인식률이 오락가락합니다.
손끝에 베인 자국이나 갈라진 틈이 있으면 그 손가락은 상처가 나을 때까지 잘 안 될 수 있습니다. / 다른 손가락을 하나 더 등록해 두시면 이런 날에도 문을 열 수 있습니다.
일을 많이 하는 손이라면 집게손가락보다 덜 쓰는 약지나 새끼손가락이 오히려 잘 읽히기도 합니다. / 등록할 때 여러 손가락을 시험해 보고 가장 잘 되는 것을 골라 두세요.

# 찬 손은 잠깐 녹이고 다시
포천은 겨울이 추운 편이라 이맘때부터 바깥일 하는 손이 금방 차가워집니다. / 손이 얼면 피부가 수축하고 건조해져 센서가 지문을 잘 못 읽습니다.
주머니에 손을 넣거나 입김으로 잠깐 녹인 뒤 다시 대 보세요. / 손가락을 너무 세게 누르기보다 평평하게 살짝 올려놓는 것이 더 잘 됩니다.
반대로 센서 쪽에 성에나 이슬이 맺혀 있을 때도 있습니다. / 이른 아침이나 해가 진 뒤라면 센서 유리를 손바닥으로 잠깐 덮었다가 닦고 대 보세요.
@ 가산면 겨울 찬 손 지문 인식 요령

# 센서 유리 상태 보기
센서 표면에 먼지, 흙, 손때가 얇게 앉아 있지 않은지 보세요. / 부드러운 마른 천으로 가볍게 닦아 주면 됩니다.
세정제나 알코올을 바로 뿌리는 것은 피하세요. / 센서 주변 틈으로 스며들어 고장이 날 수 있습니다.
센서 유리에 긁힌 자국이 깊게 났다면 닦아도 나아지지 않습니다. / 이럴 때는 센서 부품 점검이 필요합니다.

# 지문 말고 남은 수단 꺼내기
지문이 계속 실패하면 번호로 여는 것이 가장 빠릅니다. / 지문만 쓰다 보면 번호를 잊는 분이 많으니 평소에 가끔 번호로도 열어 보세요.
카드나 태그를 함께 등록해 둔 집이라면 열쇠고리나 차 안에 하나 넣어 두세요. / 작업복 주머니에 늘 넣어 두는 것도 좋습니다. / 비상 열쇠 구멍이 있는 제품이라면 그 열쇠를 어디에 두었는지도 가족과 정해 두면 좋습니다.

# 지문 등록을 다시 할 때 요령
문이 열린 뒤에는 지문을 다시 등록해 두는 것을 권합니다. / 오래전에 등록한 지문은 손이 변하면서 맞지 않게 되기도 합니다.
- 손을 씻고 완전히 말린 상태에서 등록하기
- 손가락 끝만이 아니라 가운데 부분까지 센서에 닿게 하기
- 등록할 때 각도를 조금씩 바꿔 가며 여러 번 대기
- 양손에서 하나씩, 두세 개 손가락을 등록하기
겨울이 오기 전에 한 번 다시 등록해 두면 추운 날 실패가 줄어듭니다. / 예전에 등록한 지문 가운데 안 쓰는 것은 지워 두시면 등록 칸이 모자라 새로 못 넣는 일도 막을 수 있습니다.

# 가족 모두 실패한다면 기계 쪽
나만 안 되는 게 아니라 가족 모두 실패한다면 손이 아니라 도어락 쪽 문제일 가능성이 높습니다. / 센서가 상했거나 등록 정보가 지워졌을 수 있습니다.
도어락을 떨어뜨리거나 문에 세게 부딪힌 적이 있다면 그것도 떠올려 보세요. / 이런 경우는 [도어락 수리](doorlock-repair.html)로 점검을 받는 편이 좋습니다.
번호도 맞게 눌렀는데 안 열린다면 지문보다 모터나 걸쇠 쪽까지 같이 봐야 할 수 있습니다. / 그때 나는 소리를 기억해 두셨다가 전화로 알려주세요.

# 번호판은 켜지는데 지문만 안 될 때 건전지
건전지 힘이 떨어지면 번호판은 켜져도 지문 센서가 먼저 불안해지는 제품이 있습니다. / 최근 경고음을 들은 적이 있다면 문이 열린 뒤 건전지를 전부 새것으로 바꿔 보세요.
추운 날에는 건전지 힘이 더 빨리 떨어지니 겨울 들기 전에 바꿔 두는 것도 방법입니다.
@ 가산면 지문 도어락 건전지 교체 확인

# 연락 주실 때
가산면은 마을이 떨어져 있어 위치를 정확히 알려주시는 것이 중요합니다. / 마을 이름, 가까운 큰길이나 눈에 띄는 건물, 대문 색깔 정도를 말씀해 주세요.
- 지문이 안 될 때 나는 소리나 표시
- 번호, 카드로도 안 되는지
- 도어락 앞면 사진
거리가 있는 곳이라 위치를 받고 도착 시간을 먼저 말씀드립니다. / 기다리시는 동안 마당이나 창고처럼 바람을 피할 곳이 있다면 그쪽에 계셔도 되고, 도착하기 전에 전화로 한 번 더 길을 여쭙겠습니다.

# 확인과 비용
문을 열어야 하는 상황이면 사시는 분인지 신분증, 주소가 나온 우편물, 이웃이나 가족 확인으로 살펴봅니다. / 상태를 보고 비용을 먼저 말씀드린 뒤 동의하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다.
문 여는 과정은 [현관문 개문](door-open.html), 전체 진행은 [이용안내](guide.html)에 있습니다. / 센서가 상해 바꿔야 한다면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.

# 가산면 말고 포천 어디든
소흘읍, 선단동, 포천동, 군내면, 신북면, 일동면, 영중면까지 포천 전 지역을 다닙니다. / 포천에서 다니는 곳은 [포천시 출장열쇠](pocheon.html)에, 다른 지역은 [출장 지역](area.html)에 정리했습니다.
