# 포천동 현관에서 들린 낯선 멜로디
포천동은 포천시청이 있는 시내 쪽 동네로, 아파트와 주택, 상가가 함께 있는 곳입니다. / 퇴근하고 문을 여는데 평소와 다른 짧은 멜로디가 따라붙는다면 도어락이 건전지가 얼마 남지 않았다고 알리는 것입니다.
이 소리를 듣고 바로 갈면 아무 일도 생기지 않습니다. / 며칠 미루다 보면 어느 날 번호판이 깜깜한 채로 문 앞에 서게 됩니다.
이 글은 포천동에서 건전지 경고음을 들은 날부터 번호판이 완전히 꺼진 날까지, 시점마다 할 일을 정리했습니다. / 혼자 해결이 안 되면 [포천 출장열쇠](pocheon.html)에 연락 주시면 됩니다.
@ 포천동 도어락 건전지 경고음 교체

# 경고음을 들은 그날 할 일
경고음은 내일 갈아도 되겠지 싶은 소리지만, 그날 바로 가는 것이 가장 좋습니다. / 포천은 이맘때부터 밤 기온이 많이 내려가서 남은 힘이 예상보다 빨리 빠집니다.
안쪽 몸체의 건전지 덮개를 열어 들어 있는 건전지 종류와 개수를 확인하세요. / 휴대폰으로 사진을 찍어 두면 사러 갈 때 헷갈리지 않습니다.
시내 쪽이라 가까운 편의점이나 마트에서 구하기 어렵지 않습니다. / 사러 나가는 김에 비상용 9V 건전지도 하나 같이 사 두세요.

# 어떤 건전지를 사야 할까
대부분의 도어락은 AA 크기 건전지를 씁니다. / 같은 크기라도 오래가는 알카라인 건전지를 쓰는 것이 좋습니다.
값이 싼 건전지는 처음엔 잘 되다가 추운 날 힘이 확 떨어지기도 합니다. / 도어락은 모터를 돌릴 때 순간적으로 힘을 많이 쓰기 때문에 건전지 품질 차이가 잘 드러납니다.
건전지 덮개 안쪽에 권장 건전지가 적혀 있다면 그것을 따르세요. / 사 온 건전지의 유통기한도 한 번 보세요. 진열대에 오래 있던 건전지는 새것이라도 힘이 덜할 수 있습니다.

# 충전지를 넣어도 될까
충전해서 쓰는 건전지는 전압이 일반 건전지와 조금 달라서 일부 도어락에서는 잔량 표시가 정확하지 않습니다. / 아직 힘이 남은 것처럼 보이다가 갑자기 꺼지는 일이 생길 수 있습니다.
특별히 충전지를 써도 된다고 안내된 제품이 아니라면 일반 알카라인 건전지를 권합니다. / 리모컨이나 장난감에서 쓰던 건전지를 빼서 넣는 것도 피해 주세요. 남은 양을 알 수 없어 금방 다시 경고음이 납니다.

# 갈아 끼울 때 순서
- 문을 활짝 열어 둔 상태에서 작업하기
- 들어 있는 건전지를 전부 빼기
- 같은 종류 새 건전지로 전부 바꿔 넣기
- 덮개 안쪽 그림에 맞춰 극 방향 확인하기
- 문을 연 채로 번호, 카드, 지문이 되는지 시험하기
- 문을 닫고 바깥에서 한 번 더 열어 보기
문을 닫아 둔 채 건전지를 갈다가 설정이 바뀌면 바깥에서 문이 안 열릴 수 있습니다. / 꼭 열어 둔 상태에서 하세요.
덮개가 잘 안 열리면 손톱 대신 동전 끝으로 홈을 살짝 눌러 보세요. / 힘으로 잡아당기면 걸림쇠가 부러집니다.
@ 포천동 도어락 건전지 교체 극 방향 확인

# 경고음을 며칠 미뤘다면
경고음이 난 지 며칠 됐다면 모터 소리가 느려지거나 지문 인식이 한 번에 안 되는 등 다른 신호가 붙기 시작합니다. / 이 단계에서는 문이 열리긴 하지만 언제 멈춰도 이상하지 않습니다.
외출하기 전에 갈 시간이 없다면 9V 건전지를 가방에 넣고 나가세요. / 돌아왔을 때 번호판이 꺼져 있어도 바로 대처할 수 있습니다.
가족에게도 경고음이 났다는 사실을 알려 두세요. / 먼저 집에 오는 사람이 갈아 끼우면 되고, 누군가 문 앞에서 혼자 막히는 일도 막을 수 있습니다.

# 번호판이 꺼진 날, 문 앞에서
번호판을 손바닥으로 덮어도 불이 안 들어온다면 전원이 끊긴 상태입니다. / 도어락 바깥쪽 아래에서 9V 건전지를 대는 두 개의 금속 단자를 찾아보세요.
단자에 9V 건전지를 댄 채로 번호를 누르면 문이 열리는 경우가 많습니다. / 들어가자마자 안쪽 건전지를 모두 새것으로 바꿔 주세요.
번호를 여러 번 틀리면 입력이 잠시 막히니 비상 전원을 대고 나서는 천천히 정확하게 누르세요.

# 비상 단자에 대도 안 될 때
9V 건전지를 대도 반응이 없다면 단자 접촉 불량, 건전지 자체가 오래된 것, 또는 몸체 쪽 고장일 수 있습니다. / 새 9V 건전지인지 먼저 확인해 보세요.
단자가 없는 제품이거나, 불은 켜지는데 모터가 안 도는 경우도 있습니다. / 이럴 때는 더 시도하지 마시고 연락 주세요. 억지로 하면 단자나 모터가 더 상합니다.

# 상가 위층 집이나 계단 현관이라면
포천동에는 상가 건물 위층에 사는 집도 있습니다. / 계단 현관은 바깥바람이 그대로 들어와 아파트 복도보다 도어락이 추위를 더 탑니다.
이런 집은 경고음이 나기 전이라도 겨울 들기 전에 미리 건전지를 바꿔 두세요. / 아래층 가게가 문을 닫은 밤에는 건물 안이 더 조용하고 어두우니 손전등도 하나 챙겨 두면 단자를 찾기 쉽습니다. / 건물 출입문이 따로 있다면 그 문 상태도 함께 알려주시면 출동할 때 도움이 됩니다.

# 연락하실 때와 도착 후 순서
- 번호판이 완전히 꺼졌는지, 흐릿하게라도 켜지는지
- 9V 비상 전원을 시도했는지
- 도어락 앞면과 아래쪽 사진
- 아파트 동·호수 또는 상가 건물 이름과 층
도착하면 사시는 분인지 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나로 확인합니다. / 상태를 보고 비용을 먼저 말씀드린 뒤 동의하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html), 문 여는 방식은 [현관문 개문](door-open.html)에 있습니다.

# 건전지가 너무 빨리 닳는다면
새 건전지를 넣었는데 한두 달 만에 또 경고음이 난다면 건전지 문제가 아닐 수 있습니다. / 문이 처져 모터가 매번 무리하게 돌거나, 안쪽 회로에서 전기가 새는 경우입니다.
문을 닫을 때 한 번에 잠기지 않고 모터가 여러 번 도는 소리가 난다면 문 처짐을 의심해 보세요. / 이런 경우는 [도어락 수리](doorlock-repair.html)로 점검하고, 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 함께 상담합니다.

# 겨울 들기 전 한 번 더
포천의 겨울은 길고 추운 편입니다. / 경고음이 아직 안 났어도 겨울 초입에 건전지를 한 번 바꿔 두면 한겨울 아침에 문 앞에서 막힐 일이 크게 줄어듭니다.
바꾼 날짜를 덮개 안쪽에 적어 두세요. / 다음에 언제 바꿨는지 떠올리느라 고민하지 않아도 됩니다.
@ 포천동 겨울 전 도어락 배터리 미리 교체

# 포천동 말고 포천 어디든
선단동, 소흘읍, 군내면, 신북면, 가산면, 일동면, 영중면까지 포천 전 지역을 다닙니다. / 포천에서 다니는 곳은 [포천시 출장열쇠](pocheon.html), 다른 지역은 [출장 지역](area.html)에 정리했습니다.
