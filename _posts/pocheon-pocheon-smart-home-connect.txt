# 포천동 집 도어락, 알림이 어느 날부터 조용하다면
포천동은 포천시청이 있는 시내 쪽 동네로, 아파트와 주택, 상가가 함께 있는 곳입니다. / 문이 열리면 휴대폰으로 알림이 오는 도어락은 아파트든 주택이든 쓰임새가 꽤 있습니다.
아이가 학교에서 돌아왔는지, 부모님이 외출하셨다 들어오셨는지 알림으로 확인하던 집이라면 갑자기 알림이 끊기면 불안해집니다. / 앱을 열어 보면 기기가 연결되지 않았다는 문구만 떠 있기도 합니다.
이 글은 포천동에서 도어락 알림과 앱 연동이 안 될 때 집에서 차례로 점검할 것을 적었습니다. / 문 자체가 안 열리는 상황이라면 [포천 출장열쇠](pocheon.html)로 먼저 연락 주세요.
@ 포천동 도어락 앱 알림 연동 끊김

# 문 여닫기와 알림은 따로 움직입니다
먼저 안심하셔도 되는 점이 있습니다. / 대부분의 도어락은 앱 연동이 끊겨도 번호, 지문, 카드로 문을 여닫는 기능은 그대로 됩니다.
알림과 원격 확인은 도어락에 붙은 통신 장치나 집 공유기를 거쳐 휴대폰까지 전달됩니다. / 이 길 중 어딘가가 끊기면 문은 잘 되는데 알림만 안 오는 상태가 됩니다.
그래서 점검도 문이 아니라 전달하는 길을 따라가며 하나씩 보는 것이 순서입니다. / 아래 순서대로 확인해 보세요.

# 첫째, 집 인터넷과 공유기
가장 흔한 원인은 집 인터넷입니다. / 공유기가 꺼졌거나, 비밀번호를 바꿨거나, 새 공유기로 교체한 뒤에 연동이 끊기는 경우가 많습니다.
휴대폰으로 집 와이파이가 잘 잡히는지 먼저 확인해 보세요. / 다른 기기도 인터넷이 안 된다면 공유기 전원을 껐다가 잠시 뒤 다시 켜 보세요.
공유기를 바꿨거나 와이파이 이름, 비밀번호를 바꿨다면 도어락 쪽에도 새 정보를 다시 등록해야 합니다. / 이 과정을 빼먹어 연동이 끊기는 집이 꽤 많습니다.

# 둘째, 현관까지 신호가 닿는지
공유기가 집 안쪽 깊은 방에 있으면 현관까지 신호가 약하게 닿습니다. / 벽이 두껍거나 현관과 공유기 사이에 방이 여러 개 있으면 더 그렇습니다.
현관 앞에 서서 휴대폰 와이파이 표시가 몇 칸인지 보세요. / 한두 칸밖에 안 된다면 도어락 쪽 신호도 불안정할 가능성이 큽니다.
공유기 위치를 현관 쪽으로 옮기거나 신호를 넓혀 주는 장치를 두면 나아지는 경우가 많습니다. / 주택이라면 현관과 공유기가 다른 층에 있지 않은지도 확인해 보세요.
@ 포천 포천동 현관 와이파이 신호 확인

# 셋째, 연결 장치가 따로 있는지
도어락에 따라 공유기와 바로 이어지는 것도 있고, 콘센트에 꽂는 작은 연결 장치를 거치는 것도 있습니다. / 이 연결 장치의 전원이 빠지면 알림이 끊깁니다.
청소하다가 플러그를 뽑았거나, 멀티탭 스위치를 끈 경우가 의외로 흔합니다. / 집 안 콘센트에 처음 보는 작은 장치가 꽂혀 있다면 그것이 연결 장치일 수 있습니다.
장치에 불이 들어와 있는지 보세요. / 꺼져 있다면 다시 꽂고 잠시 기다리면 연동이 돌아오는 경우가 있습니다.

# 넷째, 도어락 배터리
배터리가 약해지면 도어락은 문을 여닫는 기능을 지키려고 통신 기능부터 줄이는 경우가 있습니다. / 그래서 문은 잘 열리는데 알림만 먼저 끊기기도 합니다.
포천은 겨울이 추운 편이라 배터리가 빨리 닳습니다. / 앱에 배터리 잔량이 표시된다면 확인해 보고, 낮다면 한꺼번에 새것으로 바꿔 주세요.
배터리를 바꾼 뒤에는 연동이 저절로 돌아오기도 하고, 다시 등록해야 하기도 합니다. / 제품마다 달라 설명서나 앱 안내를 함께 보세요.

# 다섯째, 휴대폰과 앱 설정
휴대폰 쪽에서 알림이 꺼져 있을 수도 있습니다. / 휴대폰을 바꿨거나 운영체제를 새로 올린 뒤에 알림 허용이 풀리는 경우가 있습니다.
휴대폰 설정에서 해당 앱의 알림이 켜져 있는지 확인해 보세요. / 배터리 절약 모드가 앱을 멈추게 해서 알림이 늦게 오거나 안 오기도 합니다.
앱을 최신으로 업데이트하고, 로그아웃했다가 다시 로그인해 보는 것도 방법입니다. / 가족이 같이 쓰는 경우 내 계정이 공유 목록에서 빠지지 않았는지도 보세요.

# 가족과 함께 쓰는 경우
한 사람 계정으로 등록하고 가족을 초대해 함께 쓰는 집이 많습니다. / 처음 등록한 사람이 휴대폰을 바꾸거나 계정을 지우면 다른 가족의 연동도 끊길 수 있습니다.
누가 처음 등록했는지, 관리 권한이 누구에게 있는지 알아 두세요. / 그분 휴대폰에서 다시 초대해 주면 대부분 해결됩니다.

# 이럴 땐 기기 쪽 점검이 필요합니다
위 순서대로 다 해 봤는데도 안 된다면 도어락이나 통신 부품 쪽 문제일 수 있습니다. / 아래 같은 증상이 함께 있다면 점검을 받아 보세요.
- 앱에서 등록 자체가 계속 실패한다
- 문을 열어도 앱 기록이 몇 시간 늦게 남는다
- 배터리를 새로 넣었는데 금방 닳는다
- 번호판 반응까지 느려지거나 오작동한다
통신 부품만 손보면 되는 경우도 있고, 오래된 제품이라 바꾸는 편이 나은 경우도 있습니다. / 현장에서 보고 [도어락 수리](doorlock-repair.html)와 [도어락 교체](doorlock-replace.html) 중 맞는 쪽을 말씀드립니다.

# 문까지 안 열린다면 먼저 문부터
알림 문제와 함께 번호판이 꺼지거나 문이 안 열린다면 그것부터 해결해야 합니다. / 번호판 아래 9V 건전지 비상 단자에 건전지를 대고 번호를 눌러 보세요.
그래도 안 되면 위치와 상황을 알려주세요. / 도착하면 사시는 분인지 신분증이나 우편물, 관리사무소 확인으로 본 뒤 문을 엽니다.
여는 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 비용은 원인을 보고 먼저 안내합니다
공유기 재등록이나 설정만으로 끝나는지, 부품을 손봐야 하는지에 따라 다릅니다. / 현장에서 원인을 보여 드리고 비용을 먼저 말씀드린 뒤 동의하실 때 시작합니다.
끝내 문을 열지 못하는 경우라면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에서 보실 수 있습니다.
@ 포천동 스마트 도어락 연동 점검 출장

# 연동을 오래 유지하는 습관
- 공유기를 바꾸거나 비밀번호를 바꾸면 바로 도어락도 다시 등록하기
- 연결 장치 플러그에 표시를 붙여 실수로 뽑지 않게 하기
- 겨울 전에 도어락 배터리를 미리 새것으로 바꾸기
- 관리 권한을 가진 가족이 휴대폰을 바꿀 때 공유 설정 다시 확인하기
알림은 편리한 기능이지만 문을 지키는 기본은 여전히 도어락 자체입니다. / 알림이 끊긴 날에도 번호와 카드로 문을 여닫을 수 있도록 기본 방법은 꼭 기억해 두세요.

# 포천동 말고 포천 어디든 갑니다
선단동, 소흘읍 아파트와 군내면, 신북면, 가산면, 일동면, 영중면 주택까지 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 보세요.
