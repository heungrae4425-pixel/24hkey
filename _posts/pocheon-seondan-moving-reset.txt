# 선단동 새집에 들어가자마자 할 일
선단동으로 이사해서 짐을 풀기 전에 가장 먼저 할 일은 현관 도어락 번호를 바꾸는 것입니다. / 이전에 살던 사람이나 부동산, 공사하신 분들이 알던 번호가 그대로 남아 있을 수 있기 때문입니다.
이 글은 [포천 출장열쇠](pocheon.html)를 부르기 전에 직접 해볼 수 있는 초기화 순서와, 막혔을 때 도움을 받는 방법을 정리했습니다.
새집에서 처음으로 안전하게 문을 쓰는 첫걸음이라 천천히 따라 해 보셔도 좋습니다.
@ 선단동 이사 도어락 비밀번호 초기화 출장

# 이사 후 번호를 꼭 바꿔야 하는 이유
이전 입주자나 공사하신 분, 중개인이 번호를 알고 있을 가능성을 지울 수 없습니다. / 번호를 바꾸지 않으면 누가 알고 있는지 확인할 방법이 없습니다.
- 이전 입주자가 알던 번호가 그대로 남은 경우
- 입주 청소나 공사 때 임시로 쓰던 번호가 남은 경우
- 카드키나 태그가 이전 것까지 등록된 상태인 경우
- 관리용 마스터 번호가 초기값 그대로인 경우
번호를 새로 정하는 일은 몇 분이면 끝나지만 안전에는 큰 차이가 납니다.

# 먼저 도어락 종류부터 살펴보기
도어락은 제품마다 초기화 방법이 다릅니다. / 안쪽 문 뒷면에 있는 작은 버튼이나 배터리 덮개 안쪽에 있는 버튼을 쓰는 경우가 많습니다.
제품 이름이 문 안쪽이나 번호판 옆에 적혀 있으면 사진으로 찍어 두세요. / 이름만 알아도 초기화 방법을 훨씬 쉽게 찾을 수 있습니다.
설명서가 없어도 걱정하지 마시고, 제품 모양과 이름 사진을 보내주시면 알려드릴 수 있는 경우도 있습니다.

# 일반적인 초기화 순서
대부분의 도어락은 비슷한 흐름으로 번호를 다시 등록합니다. / 제품마다 다르니 아래는 큰 흐름만 참고하세요.
- 문을 연 상태에서 안쪽 배터리 덮개를 열고 등록 버튼을 찾는다
- 등록 버튼을 눌러 설정 모드로 들어간다
- 기존 번호를 지우고 새 번호를 두 번 입력한다
- 문을 닫고 새 번호로 실제 열리는지 확인한다
확인하지 않고 문을 닫았다가 번호가 안 맞아 못 들어오는 일이 생길 수 있으니, 반드시 문이 열린 상태에서 시험해 보세요.
@ 포천 선단동 도어락 비밀번호 새로 등록

# 초기화가 안 될 때
등록 버튼이 안 눌리거나 소리가 안 나면 배터리가 약한 경우가 많습니다. / 새 건전지로 바꾼 뒤 다시 해 보세요.
버튼을 눌러도 제품이 반응하지 않거나, 이전 입주자가 관리자 번호를 설정해 두어서 막힌 경우도 있습니다. / 이럴 때는 억지로 이것저것 눌러 보기보다 연락 주시는 편이 빠릅니다.
여러 번 잘못 누르면 도어락이 한동안 입력을 막으니 서너 번 해보고 안 되면 멈추세요.

# 카드키와 태그는 이렇게 정리합니다
이전 입주자가 쓰던 카드키나 태그가 남아 있으면 그 카드도 문을 열 수 있습니다. / 전달받은 카드키는 등록을 한 번 지운 뒤 새로 등록하는 것이 좋습니다.
카드키를 몇 장 받았는지 확인하고, 분실된 카드가 있다면 등록에서 삭제해 두세요. / 새 카드는 가족 수에 맞춰 등록하고, 한 장은 따로 보관해 두면 좋습니다.

# 이사 날 번호 공유는 이렇게
이삿짐 업체나 청소 업체에는 임시 번호를 따로 만들어 쓰는 방법이 있습니다. / 작업이 끝나면 임시 번호를 지우고 가족용 번호만 남겨 두세요.
- 이사 날에만 쓰는 임시 번호를 먼저 등록한다
- 이사가 끝나면 임시 번호를 삭제한다
- 가족에게는 새 번호를 직접 전달한다
- 번호를 문자나 메신저에 남겨 두지 않는다
문자로 보낸 번호는 휴대폰에 그대로 남으니 전달한 뒤 지우는 것이 좋습니다.

# 선단동에서 이사 후 연락하실 때 알려주세요
초기화가 어려우시면 상황을 알려주세요. / 사진 한 장이 있으면 통화가 훨씬 빨라집니다.
- 도어락 제품 이름이나 모양(문 안쪽 사진)
- 번호판이 켜지는지, 소리가 나는지
- 이전 입주자가 설정한 관리자 번호가 있는지
- 새로 설치를 원하시는지, 기존 것을 쓰실지
위치를 알려주시면 예상 도착 시간을 먼저 말씀드립니다. / 이사 날이라 바쁘시면 편한 시간을 말씀해 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이 아니더라도 도어락을 만지는 일이라 사시는 분이 맞는지 확인합니다. / 신분증 주소, 계약서, 주소가 나온 우편물 중 가능한 것을 준비해 주세요.
이사 직후라 주소 이전이 안 된 경우에는 임대차 계약서나 관리사무소 확인으로 대신할 수 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
번거로우셔도 이웃과 집을 지키기 위한 절차입니다.
@ 선단동 이사 후 도어락 설정 출장열쇠

# 비용은 시작하기 전에 말씀드립니다
초기화만 하면 되는지, 점검이나 교체가 필요한지 보고 시작하기 전에 먼저 안내합니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
말씀드리지 않은 비용은 붙이지 않습니다. / 부품을 바꿔야 하는 경우도 바꾸기 전에 꼭 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 도어락 상태도 같이 봐 드립니다
번호를 새로 정하는 김에 문 전체 상태를 한 번 살펴보는 것이 좋습니다. / 이전에 쓰던 흔적에서 고장 신호가 보일 때가 있습니다.
- 번호판 버튼 중 반응이 느린 곳이 있는지
- 걸쇠가 문틀에 정확히 들어가는지
- 안쪽 손잡이를 돌릴 때 걸리는 느낌이 없는지
- 배터리 잔량이 충분한지
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 새 도어락을 달고 싶을 때
이사하는 김에 도어락을 새로 바꾸는 분도 많습니다. / 지문이나 카드키 방식으로 바꾸고 싶다면 문 두께와 기존 구멍 위치를 먼저 확인해야 합니다.
[도어락 설치](doorlock-install.html) 페이지에서 종류별 특징을 볼 수 있고, 사진을 보내주시면 맞는 제품을 추천해 드립니다. / 설치 전에 가격을 먼저 안내하고 결정하시게 합니다.

# 새집에서 번호를 오래 안전하게 쓰는 법
- 생일이나 전화번호 끝자리처럼 쉬운 번호는 피하기
- 번호를 가족 모두가 기억하고 문자에 남기지 않기
- 해마다 한 번씩 번호 바꾸기
- 카드키나 열쇠 한 개는 믿을 만한 곳에 따로 보관하기
- 배터리는 해마다 한 번에 전부 교체하기
번호를 바꿀 때마다 가족에게 알리는 습관을 들이면 문 앞에서 막히는 일이 줄어듭니다.

# 선단동 말고 포천 어디든 갑니다
선단동 가까이 있는 소흘읍, 포천동은 물론 일동면, 신북면, 가산면, 영중면, 군내면까지 다닙니다. / 포천 안이면 동네 상관없이 24시간 출동합니다.
포천에서 다니는 곳은 [포천시 출장열쇠](pocheon.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
