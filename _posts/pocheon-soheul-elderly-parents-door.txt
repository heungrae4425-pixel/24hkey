# 소흘읍 부모님 댁, 겨울 들기 전에 한 번
소흘읍은 송우리 쪽을 중심으로 아파트가 모여 있는 동네입니다. / 은퇴 후 이곳 아파트에서 두 분이, 혹은 한 분이 지내시는 부모님도 많습니다.
포천은 겨울이 추운 편이라 도어락 배터리가 빨리 닳고 반응이 느려집니다. / 부모님은 그런 변화를 그러려니 하고 넘기시다가 어느 저녁 문 앞에서 막히곤 하십니다.
이 글은 자녀가 소흘읍 부모님 댁에 들렀을 때 현관 도어락에서 짚어 볼 목록을 정리했습니다. / 직접 하기 어려운 부분은 [포천 출장열쇠](pocheon.html)에 맡기셔도 됩니다.
@ 소흘읍 아파트 부모님 댁 도어락 겨울 점검

# 점검 목록 한눈에 보기
들르신 김에 아래 순서대로 하나씩 보시면 10분이면 끝납니다. / 부모님과 같이 보시면 설명도 함께 드릴 수 있어 더 좋습니다.
- 배터리 교체 시기와 경고음이 들리는지
- 번호판 불빛과 숫자가 잘 보이는지
- 번호를 부모님이 정확히 기억하시는지
- 안쪽 걸쇠를 어떻게 쓰고 계신지
- 자동 잠금이 켜져 있는지
- 문이 너무 무겁거나 세게 닫히지 않는지
하나라도 걸리는 게 있으면 아래 내용을 참고해 손봐 드리세요.

# 배터리는 겨울 전에 미리
추운 날에는 같은 배터리라도 힘이 떨어집니다. / 가을에 남아 있던 배터리가 한겨울에 갑자기 바닥나는 일이 흔합니다.
배터리 칸을 열어 교체 날짜가 적혀 있는지 보세요. / 날짜가 없거나 오래됐다면 들른 김에 한꺼번에 새것으로 바꿔 드리고 날짜를 적어 두세요.
같은 종류의 새 배터리로 전부 바꾸는 것이 중요합니다. / 헌것과 새것을 섞으면 금방 다시 경고가 울립니다.

# 경고음을 부모님이 알아들으시는지
배터리가 약해지면 도어락이 소리나 음성으로 알려 줍니다. / 그런데 어르신은 이 소리를 듣지 못하시거나, 들어도 무슨 뜻인지 모르시는 경우가 있습니다.
경고음이 어떤 소리인지 부모님 앞에서 한 번 들려 드리세요. / 이 소리가 나면 자녀에게 전화하시라고 약속해 두면 좋습니다.
소리가 너무 작게 설정돼 있다면 크게 바꿔 드리세요. / 방법은 제품마다 달라 모델명을 알려주시면 안내해 드립니다.

# 안쪽 걸쇠 습관을 꼭 여쭤보세요
어르신 중에는 밤마다 안쪽 걸쇠나 보조 잠금을 걸고 주무시는 분이 많습니다. / 방범에는 좋지만, 갑자기 몸이 불편해지셨을 때 가족이나 구급대원이 밖에서 들어오기 어려워집니다.
걸쇠가 걸려 있으면 바깥에서 번호를 눌러도 문이 조금만 열리고 멈춥니다. / 이 경우 걸쇠를 풀기 위해 시간이 더 걸립니다.
걸쇠를 꼭 쓰셔야 마음이 놓이신다면, 자녀가 열쇠나 카드를 하나 갖고 있는 것만으로는 부족하다는 점을 알려 드리세요. / 건강이 걱정되시는 분이라면 걸쇠 대신 도어락 잠금만으로 지내시는 것도 생각해 볼 만합니다.

# 자동 잠금이 켜져 있는지
요즘 도어락은 문이 닫히면 저절로 잠기는 기능이 있습니다. / 이 기능이 꺼져 있으면 부모님이 문을 닫기만 하고 잠그지 않은 채 지내실 수 있습니다.
반대로 자동 잠금이 켜져 있으면 쓰레기를 버리러 잠깐 나가셨다가 문이 잠겨 버리기도 합니다. / 그래서 자동 잠금을 쓰신다면 휴대폰을 꼭 들고 나가시라고 말씀드리세요.
어느 쪽이 맞는지는 부모님 생활에 따라 다릅니다. / 자주 깜빡하시는 편이면 자동 잠금, 자주 나갔다 들어오시면 카드나 지문을 함께 쓰는 쪽이 낫습니다.
@ 포천 소흘읍 어르신 도어락 자동 잠금 설정

# 번호판이 잘 보이고 잘 눌리는지
아파트 복도가 어두우면 번호판 숫자가 잘 안 보이십니다. / 번호판에 불빛이 밝게 들어오는지, 숫자가 큼직한지 보세요.
번호를 누를 때 한 번에 안 눌려 두세 번씩 누르신다면 버튼이 닳았을 수 있습니다. / 이런 경우는 [도어락 수리](doorlock-repair.html)로 점검하거나 버튼이 큰 제품으로 바꾸는 것을 생각해 보세요.
손 떨림이 있으시면 카드 방식이 편합니다. / 갖다 대기만 하면 열리니 번호를 누르실 필요가 없습니다.

# 문 무게와 닫히는 속도
문이 너무 무거우면 짐을 든 채 여시기 힘듭니다. / 반대로 너무 세게 닫히면 손이나 발이 끼일 수 있습니다.
문 위 도어클로저 속도를 조절하면 대부분 나아집니다. / 몸통에 기름 자국이 있다면 교체가 필요할 수 있습니다.
지팡이나 보행 보조기를 쓰시는 분이라면 문이 닫히는 속도를 조금 더 느리게 맞춰 드리는 게 좋습니다. / 문을 지나가시는 동안 여유가 생겨 훨씬 안전합니다.

# 번호는 부모님 기억에 맞게
번호를 바꿔 드릴 때는 부모님이 오래 기억하시는 숫자로 정하세요. / 너무 길게 하면 자꾸 틀리시고, 그러다 입력이 잠기면 더 당황하십니다.
바꾼 번호는 형제자매 모두에게 바로 알리세요. / 가까이 사는 자녀 한 명은 꼭 알고 있어야 합니다.

# 부모님 휴대폰에 저장해 드릴 것
- 가까이 사는 자녀 번호를 단축번호로
- 관리사무소 번호
- 출장열쇠 번호 010-3664-5455
문 앞에서 막히셨을 때 누구에게 먼저 전화하실지 순서를 정해 두면 당황하지 않으십니다. / 출장열쇠는 부모님이 직접 부르셔도 되고 자녀가 대신 연락하셔도 됩니다.

# 멀리 사는 자녀가 미리 해 둘 일
자주 들르기 어려운 자녀라면 한 번 왔을 때 몇 가지를 기록해 두세요. / 나중에 전화로 부모님을 도와드릴 때 큰 힘이 됩니다.
도어락 앞면과 안쪽 몸체를 사진으로 찍어 두고, 배터리 칸 안쪽에 적힌 모델명도 찍어 두세요. / 부모님이 문 앞에서 막히셨을 때 그 사진을 보내 주시면 어떤 제품인지 바로 알 수 있습니다.
관리사무소 위치와 전화번호, 부모님 동과 호수도 휴대폰에 따로 저장해 두세요. / 대신 연락하실 때 위치를 정확히 알려주시면 단지 안에서 헤매지 않고 바로 찾아갑니다.
명절이나 생신처럼 정해진 날마다 배터리를 바꿔 드리는 것도 방법입니다. / 날짜를 정해 두면 잊어버릴 일이 없습니다.

# 문이 잠겼을 때는 이렇게 진행합니다
도착하면 먼저 사시는 분인지 신분증이나 주소가 적힌 우편물, 관리사무소 확인 중 하나로 확인합니다. / 자녀가 대신 연락했더라도 부모님이 현장에 계셔야 합니다.
확인 뒤 문과 도어락 상태를 보고 비용을 먼저 말씀드리고, 동의하실 때 시작합니다. / 끝내 열지 못하면 비용은 받지 않습니다. 진행 순서는 [이용안내](guide.html)에 있습니다.
도어락이 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 부모님과 함께 상의해 보세요.
@ 소흘읍 부모님 아파트 현관 도어락 점검 출장

# 소흘읍 말고 포천 어디든 갑니다
선단동, 포천동 시내와 군내면, 신북면, 가산면, 일동면, 영중면 주택까지 다닙니다. / 거리가 있는 곳은 도착 시간을 먼저 말씀드립니다.
다른 지역 부모님 댁은 [출장 지역](area.html)에서 확인해 보세요.
