# 카드키가 하나뿐이라면 마음이 불안합니다
안중읍에서 도어락을 쓰는 가정은 가족마다 출입 시간이 달라 카드키 한 장으로 돌려 쓰는 경우가 많습니다. / 평택역까지 나가는 분이 있고 읍내에서 일하는 분이 있으니 열쇠 대신 카드를 선호하는 집도 많습니다.
그런데 카드키가 한 장뿐이거나 다른 가족이 가져가 버린 날에는 문 앞에서 막막해집니다. / 이 글은 카드키와 태그를 추가로 등록하는 방법과 초기화를 하기 전에 확인할 것을 순서대로 정리했습니다.
문이 이미 안 열린다면 [평택 출장열쇠](pyeongtaek.html) 안내를 먼저 보셔도 좋습니다.
@ 안중읍 도어락 카드키 태그 추가 등록

# 카드키와 태그, 무엇이 다른가요
카드키는 지갑에 들어가는 얇은 모양이고, 태그는 열쇠고리에 달기 좋은 작은 모양입니다. / 둘 다 도어락 번호판 근처에 대면 읽히는 방식은 같습니다.
다만 기종마다 등록 가능한 개수와 방식이 달라서, 쓰시는 도어락이 어떤 카드를 받는지 먼저 확인해야 합니다. / 같은 모양이라도 다른 회사 카드가 호환되지 않는 경우가 있습니다.
- 카드키: 지갑이나 카드 케이스에 넣어 다니기 편함
- 태그: 열쇠고리나 가방 고리에 달기 편함
- 스티커형: 휴대폰 케이스에 붙여 쓰는 형태
아이에게 처음 줄 때는 목걸이형 태그나 가방에 달 수 있는 형태가 잃어버릴 위험이 적습니다. / 어르신께는 크기가 있어 손에 잡기 쉬운 것이 편합니다.

# 등록하기 전에 필요한 것
- 기존에 쓰던 번호나 관리자 모드로 들어갈 수 있는 상태
- 새로 등록할 카드나 태그 (도어락이 지원하는 것)
- 안쪽에서 조작할 수 있게 문이 열려 있는 상황
- 새 건전지 (등록 중 전원이 꺼지면 처음부터 다시 해야 함)
특히 건전지는 등록 시작 전에 확인하세요. / 도중에 꺼지면 어디까지 저장됐는지 알기 어려워 혼란이 생깁니다.

# 추가 등록의 큰 흐름
기종마다 버튼 위치와 안내음은 다르지만 큰 흐름은 대체로 이렇습니다.
- 문을 열고 안쪽 설정 버튼으로 관리 모드에 들어갑니다
- 카드 등록 메뉴를 선택하고 등록 안내음을 기다립니다
- 새 카드를 번호판 부근에 대어 인식시킵니다
- 완료 안내음이 나면 문을 닫고 바깥에서 새 카드로 열려 보는 시험을 합니다
설명서가 없다면 제품 모델명을 기준으로 검색하거나 문의하는 방법도 있습니다. / 그래도 막히면 전화로 상황을 알려 주시면 맞는 방식을 안내드립니다.
안내음이 몇 번 울리는지, 불빛 색이 어떻게 바뀌는지를 메모해 두면 설명하기 쉽습니다. / 문이 열려 있는 상태에서 천천히 한 단계씩 진행하는 것이 가장 안전합니다.
@ 안중읍 카드 태그 등록 절차

# 등록이 안 될 때 확인할 것
카드를 대도 반응이 없을 때는 생각보다 원인이 단순한 경우가 많습니다.
- 도어락이 지원하는 방식이 아닌 카드일 수 있음
- 카드와 번호판 사이 거리가 너무 멀거나 비스듬함
- 저장 가능한 개수가 이미 가득 찬 상태
- 배터리가 약해 인식 전력이 부족함
이 중 배터리 문제가 가장 흔합니다. / 새 건전지로 바꾸고 다시 해보면 해결되는 경우가 많습니다.
카드를 대는 위치도 의외로 중요해서, 번호판 정중앙보다 안내 표시가 있는 자리에 평평하게 대야 인식이 잘 됩니다. / 두꺼운 카드 케이스나 금속이 겹치면 읽히지 않을 수 있습니다.

# 카드 개수가 가득 찼다면
도어락마다 등록할 수 있는 카드 수가 정해져 있습니다. / 오래 쓰던 집은 이미 잃어버린 카드가 여러 장 남아 있어 새 카드를 넣을 자리가 없는 경우가 있습니다.
이럴 때는 사용하지 않는 카드를 지우고 필요한 카드만 남기는 정리를 먼저 해야 합니다. / 잃어버린 카드가 있다면 이 정리가 보안 면에서도 도움이 됩니다.

# 초기화는 마지막 수단으로 생각하세요
초기화를 하면 등록된 번호와 카드, 지문이 모두 지워지는 기종이 많습니다. / 한 번 지우면 되돌릴 수 없으니 정말 필요한지 먼저 생각해 보세요.
초기화가 필요한 경우는 대개 관리자 번호를 잊었거나, 잃어버린 카드가 많아 전부 정리하고 싶을 때입니다. / 그 외에는 등록과 삭제만으로 충분한 경우가 많습니다.
초기화 전에 가족 모두에게 알려 두고, 직후에 새 번호와 카드를 바로 등록할 시간을 확보하세요.
바쁜 출근 직전에 초기화부터 하는 것은 피하는 편이 좋습니다. / 문을 연 채로 여유 있게 진행해야 중간에 문제가 생겨도 당황하지 않습니다.

# 초기화 후 바로 해야 할 일
- 새 비밀번호를 정해 등록하기
- 사용할 카드와 태그를 모두 다시 등록하기
- 가족 모두에게 새 번호를 알리기
- 문을 닫고 바깥에서 번호와 카드로 모두 시험하기
등록을 한꺼번에 하다 빠뜨리는 카드가 생기기 쉬우니 카드 목록을 종이에 적어 가며 하세요. / 목록에는 번호 대신 누구의 카드인지만 적어 두는 정도면 충분합니다.
@ 안중읍 도어락 초기화 후 재등록

# 카드를 잃어버렸을 때의 순서
카드를 잃어버렸다고 해서 바로 도어락 전체를 바꿀 필요는 없습니다. / 먼저 잃어버린 카드를 도어락에서 삭제하거나 모르는 카드를 정리할 수 있는지 확인하세요.
삭제 기능이 없는 기종은 초기화 후 전체 재등록이 필요할 수 있습니다. / 이 판단은 기종을 보고 안내드리니 사진이나 모델명을 알려 주세요.
카드를 어디서 잃어버렸는지 짐작이 간다면 그 장소부터 다시 찾아보는 것도 방법입니다. / 찾지 못했다면 그날 안에 삭제나 재설정을 하는 편이 마음이 놓입니다.

# 문이 안 열려서 등록을 못 하는 경우
카드를 등록하려고 해도 이미 문이 안 열려 있으면 안쪽 설정에 접근할 수 없습니다. / 이때는 먼저 도어락과 문을 상하지 않게 여는 일이 순서입니다.
방법은 [현관문 개문](door-open.html) 페이지에 설명해 두었습니다. / 방문하면 사시는 분인지 먼저 확인하며 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
비용은 작업 전에 먼저 말씀드리고 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에서도 볼 수 있습니다.

# 등록을 도와드릴 수 있는 범위
문을 연 김에 새 카드와 태그 등록, 번호 변경, 배터리 교체를 한 번에 정리해 드립니다. / 등록이 반복해서 실패하면 리더기나 기판 문제일 수 있어 [도어락 수리](doorlock-repair.html)로 먼저 확인합니다.
너무 오래되어 카드 방식이 맞지 않는 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 안중읍 말고 평택 어디든 갑니다
안중읍은 물론 포승읍, 청북읍, 팽성읍과 서정동, 비전동, 세교동까지 평택 전역을 다닙니다. / 다니는 지역은 [출장 지역](area.html)에서 확인하세요.

# 자주 묻는 질문
? 아무 카드나 등록할 수 있나요? | 도어락이 지원하는 방식의 카드만 등록됩니다. 모델을 알려 주시면 확인해 드립니다.
? 카드 등록은 몇 장까지 가능한가요? | 기종마다 다르니 쓰시는 제품 설명서나 모델명을 기준으로 확인해야 합니다.
? 초기화하면 지문도 지워지나요? | 기종에 따라 다르니 초기화 전에 지워지는 항목을 먼저 확인하세요.
? 문을 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않으며 작업 전에 먼저 말씀드립니다.
? 세입자가 카드를 추가해도 되나요? | 사시는 분이면 가능하며, 확인을 위해 신분증이나 우편물을 준비해 주세요.
