# 공사 소리보다 먼저 챙길 것은 현관문
안중읍에서 집 안을 고치는 분들이 늘어나면 현관문 이야기도 따라서 나옵니다. / 도배, 장판, 주방, 욕실 공사에 집중하다 보면 정작 도어락은 공사 기간 내내 방치되기 쉽습니다.
작업자가 하루에도 몇 번씩 자재를 들고 드나드는 문이 바로 현관문입니다. / 도어락은 먼지, 페인트, 충격에 가장 먼저 노출되는 부품입니다.
이 글은 공사를 시작하기 전, 공사 중, 끝난 뒤로 나누어 도어락을 지키고 임시로 쓰는 방법을 정리한 안내입니다.
@ 안중읍 리모델링 공사 중 도어락 보호

# 공사 전에 도어락 상태 사진으로 남기기
공사가 시작되기 전에 현재 도어락과 문 상태를 사진으로 찍어 두세요. / 번호판, 손잡이, 문 안쪽, 문틀 걸쇠 부분까지 한 장씩이면 충분합니다.
공사가 끝난 뒤 흠집이나 고장이 생겼을 때 원래 상태와 비교할 수 있는 기준이 됩니다. / 업체와 이야기할 때도 사진이 있으면 오해가 줄어듭니다.
배터리 잔량도 이 시점에 점검하고 필요하면 미리 새것으로 바꿔 두세요. / 공사 중에 방전되면 작업자도 집주인도 곤란해집니다.
공사 업체와 현관문을 어떻게 다룰지 미리 이야기해 두는 것도 중요합니다. / 문을 활짝 열어 고정해 둘 때 손잡이나 걸쇠에 무리가 가지 않는 방법을 부탁해 보세요.

# 번호판과 손잡이는 가려 두는 것이 기본
도배 풀이나 페인트가 번호판에 묻으면 닦아도 센서가 둔해질 수 있습니다. / 마스킹 테이프나 비닐로 번호판 전체를 덮어 두는 방법이 가장 간단합니다.
손잡이와 문 표면도 같은 방식으로 가려 두면 긁힘과 오염을 줄일 수 있습니다. / 테이프를 오래 붙여 두면 접착제가 남을 수 있으니 공사 막바지에 바로 떼어 주세요.
도어락 틈새로 먼지가 들어가면 안쪽 부품이 뻑뻑해질 수 있습니다. / 연마나 철거 소음이 큰 작업이라면 더욱 덮어 두는 편이 안전합니다.
@ 번호판 마스킹과 문 표면 보호

# 공사 기간에는 도어락을 잠시 떼어 두는 방법
공사가 길거나 먼지가 심하다면 도어락을 아예 분리해 보관하는 방법도 있습니다. / 이 경우 문에는 임시로 쓸 수 있는 간단한 잠금장치를 달아 두게 됩니다.
도어락을 뗄 때는 나사와 부품을 잃어버리지 않게 한 봉투에 모아 두세요. / 분리 순서를 사진으로 찍어 두면 다시 달 때 도움이 됩니다.
직접 분해하기 불안하다면 [도어락 설치](doorlock-install.html) 안내를 참고하시거나 상담을 받아 보세요. / 잘못 분해하면 외관이나 선이 상할 수 있어서 모르겠으면 맡기는 편이 낫습니다.

# 작업자에게 출입 방법은 어떻게 알릴까
작업자가 드나들어야 하는 동안은 번호를 알려 줘야 하는 상황이 생깁니다. / 이때 내 번호를 그대로 알려 주면 공사 후에도 그 번호가 남게 됩니다.
임시 번호를 따로 등록할 수 있는 제품이라면 공사 기간 동안만 쓰도록 하고 끝나면 삭제하세요. / 임시 번호가 없는 제품이라면 공사가 끝난 뒤에 번호를 바꾸는 것을 전제로 알려 주시면 됩니다.
열쇠를 맡기는 경우에는 몇 개를 누구에게 줬는지 기록해 두세요. / 반납받을 때 개수를 확인하면 분실을 막을 수 있습니다.

# 공사 중에 문이 잠겨 버렸을 때
공사 중에는 문이 계속 열려 있다가 갑자기 닫히며 잠기는 일이 생깁니다. / 자재를 들고 오가다 문이 닫히면서 열쇠를 안에 둔 채 잠긴 경우가 대표적입니다.
이럴 때 문틀 사이로 도구를 넣거나 문을 세게 밀어 보면 문과 도어락이 더 상합니다. / 먼저 [현관문 개문](door-open.html) 안내를 확인하시고 연락 주세요.
공사 중인 집은 거주자가 없는 경우도 많아 신분 확인 방법을 미리 생각해 두면 좋습니다. / 아래 신분 확인 항목을 참고해 주세요.
자재를 나르는 동안 문을 고정하려고 걸쇠에 물건을 끼워 두는 일도 흔한데, 이 방식은 걸쇠 스프링을 약하게 만듭니다. / 문 고정용 도구를 따로 쓰도록 부탁하시는 편이 좋습니다.

# 먼지와 습기가 도어락에 미치는 영향
도배나 타일 공사 후에는 집 안의 습도가 평소보다 높아지는 경우가 많습니다. / 이 습기가 도어락 안쪽에 영향을 주어 한동안 오작동을 일으킬 수도 있습니다.
공사가 끝난 뒤 창문을 열어 충분히 환기하고 도어락도 마른 천으로 닦아 주세요. / 반응이 둔하거나 소리가 이상하다면 며칠 지켜본 후 점검을 받는 것이 좋습니다.
@ 공사 후 도어락 청소와 환기

# 공사 끝나고 꼭 해야 할 점검
공사가 끝난 날에는 도어락을 천천히 점검해 보세요. / 처음부터 끝까지 확인하면 문제를 일찍 발견할 수 있습니다.
- 모든 번호와 카드, 지문이 정상적으로 열리는지
- 문이 부드럽게 닫히고 걸쇠가 제대로 들어가는지
- 번호판의 불빛과 안내음이 평소와 같은지
- 작업자에게 알려 준 임시 번호를 지웠는지
- 배터리를 새것으로 교체했는지
이 중 하나라도 이상하면 공사 업체가 아직 있을 때 확인해 두는 편이 낫습니다. / 시간이 지나면 원인이 불분명해지는 경우가 많습니다.

# 공사 중 교체나 새로 설치를 하는 경우
인테리어를 하면서 도어락도 새것으로 바꾸고 싶은 분이 많습니다. / 이런 경우에는 도어락을 마지막 단계에 설치하는 것이 가장 좋습니다.
공사 중에 새 제품을 달면 먼지와 충격을 그대로 받기 때문입니다. / 문 색을 바꾸는 공사라면 문 도장이 끝나고 완전히 마른 뒤에 달아야 합니다.
제품 선택과 교체 순서는 [도어락 교체](doorlock-replace.html) 안내에서 확인하실 수 있습니다. / 공사 일정에 맞춰 날짜를 상의하셔도 좋습니다.

# 전화하실 때 알려 주시면 좋은 것
- 안중읍 어디쯤인지
- 공사 중인지, 공사가 끝났는지
- 도어락을 떼어야 하는지, 보호만 하면 되는지
- 문이 지금 열리는 상태인지
- 작업 일정과 함께 계시는 분의 연락처
도어락과 문 사진을 보내 주시면 필요한 준비를 미리 할 수 있습니다. / 집에 계신 분이 없을 때는 연락이 가능한 분의 정보를 함께 알려 주세요.

# 문을 열거나 손보기 전에 사시는 분인지 확인합니다
공사 중이라도 현관문을 다루는 일이라 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리하는 분의 확인 중 하나를 준비해 주세요.
이사 전에 공사를 하는 경우라면 계약서처럼 거주 예정을 보여 주는 서류도 도움이 됩니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 주세요.

# 비용은 시작하기 전에 안내합니다
필요한 작업을 확인한 뒤 비용을 먼저 말씀드립니다. / 동의하시면 시작하고 아니면 그대로 돌아갑니다.
문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없으며, 진행 방식은 [이용안내](guide.html)에 있습니다.

# 안중읍 말고 평택 곳곳으로 갑니다
안중읍은 물론 포승읍, 청북읍, 팽성읍, 서정동, 송탄동, 지산동도 다닙니다. / 평택 안이면 24시간 연락이 닿습니다.
[평택 출장열쇠](pyeongtaek.html) 페이지에서 지역을 확인하시고, 다른 지역은 [출장 지역](area.html)을 참고하세요.
