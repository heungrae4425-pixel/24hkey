# 문 밑이 드르륵 끌리기 시작했다면
비전동에서 평택역이나 지제역 쪽으로 출퇴근하다 보면 하루에도 여러 번 현관문을 여닫게 됩니다. / 그러다 어느 날부터 문 아래가 바닥에 닿아 드르륵 소리가 나기 시작합니다.
처음에는 조금 뻑뻑한 정도라 그냥 쓰다가, 어느 날 문이 아예 끝까지 열리거나 닫히지 않는 일이 생깁니다.
이 글은 문 아래가 바닥에 쓸리는 증상이 왜 생기는지, 직접 확인해 볼 순서와 건드리지 말아야 할 것을 정리했습니다.
@ 비전동 현관문 아래가 바닥에 쓸리는 모습

# 문이 처지는 이유는 대개 세 가지입니다
문은 경첩 두세 개에 매달려 있어서, 무게가 쏠리면 반대쪽 모서리가 아래로 내려갑니다.
- 경첩 나사가 헐거워지면서 문이 아래로 내려앉은 경우
- 경첩 자체가 닳아 문이 기울어진 경우
- 문틀이나 벽 쪽이 조금씩 틀어져 문과의 간격이 달라진 경우
여기에 문 안쪽에 무거운 도어락이나 방충문을 달아 무게가 늘면 처짐이 더 빨라집니다.

# 쓸리는 위치로 원인을 짐작해 보세요
문이 바닥에 쓸리는 자리를 보면 어디가 문제인지 어느 정도 알 수 있습니다.
손잡이 반대쪽, 즉 경첩에서 먼 아래 모서리가 쓸린다면 경첩 쪽 처짐을 먼저 의심합니다. / 문 아래 전체가 고르게 쓸린다면 바닥재나 문턱 높이가 달라졌을 수도 있습니다.
쓸린 자국이 문 아래에 하얗게 남아 있다면 어느 쪽이 닿았는지 한눈에 보입니다.

# 직접 해볼 수 있는 확인 순서
공구 없이도 해볼 수 있는 확인이 몇 가지 있습니다.
- 문을 열었다 닫으며 어느 지점에서 끌리는지 보기
- 경첩 나사를 손으로 만져 흔들리는지 확인
- 문과 문틀 사이 틈이 위쪽과 아래쪽 중 어느 쪽이 좁은지 보기
- 문을 열고 손잡이 쪽을 살짝 들어 올렸을 때 경첩이 움직이는지 확인
경첩 나사가 눈에 띄게 헐거우면 일단 거기서 원인이 보입니다. / 단, 나사를 마구 조이다 헛돌게 만들 수 있으니 힘을 조절하세요.

# 나사만 조이면 될까요
나사가 약간 풀렸을 뿐이라면 조이는 것으로 좋아지는 경우가 있습니다. / 하지만 나사 구멍이 이미 넓어져 헛돌면 아무리 조여도 곧 다시 풀립니다.
이럴 때는 구멍을 메우거나 더 긴 나사를 쓰는 등 다른 방법이 필요합니다. / 억지로 조이다 나사 머리가 뭉개지면 풀 수도 없게 되어 일이 더 커집니다.
조여 보고 하루 이틀 뒤 다시 끌리기 시작하면 임시 처방에 불과했다고 보시면 됩니다.
@ 경첩 나사 상태를 확인하는 점검

# 문이 쓸리면 도어락과 걸쇠에 어떤 영향이 있나
문이 처지면 걸쇠가 문틀 홈과 어긋나 잠금이 잘 안 되거나, 반대로 잠그고 나서 열리지 않을 수 있습니다. / 도어락은 정상인데 문이 안 열리는 경우가 사실은 처짐 때문인 일이 흔합니다.
번호는 맞고 모터 소리도 나는데 걸쇠가 안 빠진다면 문틀과의 위치 어긋남을 의심해 볼 만합니다.
문을 안쪽으로 살짝 들어 올리듯 밀면서 손잡이를 돌리면 열리기도 합니다.

문 아래를 칼이나 사포로 깎아 맞추는 분들이 있습니다. / 이런 것은 하지 않는 편이 좋습니다. / 원인을 해결하지 않고 깎으면 틈만 생겨 바람과 소음이 늘고, 되돌릴 수 없습니다.
경첩 아래에 종이나 나무 조각을 끼워 임시로 높이는 방법도 오래 못 갑니다.
문을 발로 차거나 세게 당겨 열면 경첩과 문틀이 더 틀어집니다. / 문이 끝까지 안 열린다면 억지로 열기보다 원인을 먼저 보는 게 낫습니다.

# 문이 쓸려서 아예 안 열리거나 안 닫힐 때
문 아래가 걸려 문이 열리지 않을 정도가 되면 혼자 해결하기 어렵습니다. / 안쪽에서는 열리는데 밖에서는 안 열리거나, 닫히긴 했는데 잠기지 않는 경우도 있습니다.
이럴 때는 도어락 고장과 처짐을 구별하는 것이 우선입니다. / 상황을 전화로 말씀해 주시면 어떤 경우인지 먼저 같이 정리해 드립니다.
출장 요청이 처음이라면 [출장열쇠](key-call.html) 페이지에서 흐름을 먼저 보셔도 좋습니다.

문이 안 열려 불러 주셨다면, 도착해서 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로울 수 있지만 문 여는 일은 이 절차를 건너뛰지 않습니다. / 확인이 어려울 때는 방법을 같이 찾아봅니다. / 신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁하는 방법도 있습니다.
빌라나 다세대처럼 관리사무소가 없는 건물이라면 주소가 적힌 우편물이나 휴대폰 속 계약 정보 등으로 확인할 수 있는지 전화로 먼저 상의해 주세요.

# 비용은 문을 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 확인한 뒤 먼저 안내드립니다. / 괜찮다고 하셔야 작업을 시작하고, 끝내 못 열면 비용은 받지 않습니다.
경첩을 손봐야 하는 경우에는 어디를 어떻게 하는지 설명드린 뒤 진행합니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
문 열기와 문 처짐 보정은 별개의 작업이라 따로 구분해 말씀드립니다.

# 상하지 않게 여는 것이 먼저입니다
처진 문은 이미 문틀과 걸쇠가 팽팽하게 물려 있어서 잘못 건드리면 더 상합니다. / 그래서 덜 상하는 방법부터 차례로 시도합니다.
열린 뒤에 문이 쓸리는 자리를 같이 보고, 원인이 경첩인지 문틀인지 알려 드립니다. / 작업 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
@ 처진 현관문을 상하지 않게 여는 작업

# 열고 난 뒤에 점검할 것
문이 열린 후에는 문을 천천히 여닫으며 쓸리는 자리를 다시 봅니다. / 도어락 걸쇠가 문틀 홈에 정확히 들어가는지도 함께 확인합니다.
잠금이 불안정하다면 [도어락 수리](doorlock-repair.html)로 먼저 점검받아 보세요. / 도어락이 너무 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문 높이가 달라진 이유가 바닥 공사나 새 장판에 있다면 그것도 같이 살펴봅니다.

# 문 처짐을 늦추는 평소 습관
- 문을 세게 닫지 않고 끝까지 손으로 받쳐 닫기
- 문 안쪽에 무거운 것을 걸어 두지 않기
- 계절이 바뀔 때 경첩 나사를 가볍게 확인
- 경첩이 삐걱이면 윤활제를 소량 넣기
- 아이가 문에 매달리지 않도록 알려 주기
특히 택배 상자나 이삿짐을 들이느라 문을 활짝 열어 둔 채 오래 세워 두는 날에는 문 무게가 경첩에 그대로 실립니다. / 이럴 때는 문 멈춤 장치를 쓰거나 잠깐씩 닫아 주세요.
이런 습관만으로도 처짐 속도를 꽤 늦출 수 있습니다. / 문이 쓸리기 시작했다면 일찍 손볼수록 일이 작아집니다.

# 비전동 말고 평택 어디든 갑니다
비전동은 물론 세교동, 동삭동, 고덕동, 지산동, 서정동과 읍 지역까지 다닙니다. / 평택 안이면 동네 상관없이 24시간 전화를 받습니다.
다니는 곳은 [평택 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다.
