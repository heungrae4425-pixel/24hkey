# 비전동 집주인 마스터 번호, 왜 따로 이야기할까
비전동은 평택역 방향으로 주택과 상가, 아파트가 이어진 동네라 월세와 전세로 사는 집이 꽤 섞여 있습니다. / 이런 곳에서는 도어락에 세입자 번호와 별도로 집주인 몫의 마스터 번호가 들어 있는 경우를 가끔 봅니다.
마스터 번호는 관리용으로 편리하지만, 쓰는 방식에 따라 서로 불편한 일이 생길 수 있습니다. / 이 글은 집주인과 세입자 모두 알아 두면 좋은 주의점을 정리했습니다.
문이 안 열려 [평택 출장열쇠](pyeongtaek.html)를 부르게 되는 상황과도 이어지는 이야기라 순서대로 적었습니다.
@ 비전동 임대 주택 도어락 마스터 번호

# 마스터 번호가 무엇인지부터 정리
마스터 번호는 일반 사용자 번호와 별도로 등록해 두는 관리용 번호입니다. / 제품에 따라 이름과 기능이 다릅니다. 일반 번호와 같은 열림 기능만 하는 것도 있고 설정 메뉴에 들어갈 수 있는 것도 있습니다.
어떤 제품은 처음 설정할 때 입력한 번호가 곧 관리자 번호가 됩니다. / 이 번호를 바꾸지 않으면 사용자 번호를 바꿔도 관리자 번호는 그대로 남아 있습니다.
내 도어락이 어느 쪽인지는 설명서나 제품 모델로 확인해야 정확합니다. / 확실하지 않으면 모른다고 하고 사진을 보내 주세요.

# 세입자 입장에서 먼저 알아 둘 것
내가 사는 집의 도어락에 집주인 번호가 남아 있는지는 보이지 않아 알기 어렵습니다. / 이사 들어올 때 번호를 새로 등록했다면 이전 번호는 지웠는지 함께 물어보는 편이 좋습니다.
서로 오해 없이 하려면 마스터 번호 유무와 사용 조건을 말로 한 번 정해 두는 것이 안전합니다. / 계약서에 적을지 문자로 남길지는 두 분이 정할 일이고, 저희가 법적으로 판단할 부분은 아닙니다.
불안하시다면 사용자 번호를 새로 등록하고 관리자 번호도 직접 바꾸는 방법이 있습니다. / 이때는 집주인께 먼저 알리는 것이 매끄럽습니다.

# 집주인 입장에서 지켜야 할 마음가짐
사는 사람에게 집은 일상 공간입니다. / 사전 연락 없이 번호로 들어가면 안에 계신 분이 크게 놀랄 수 있습니다.
수도나 보일러 점검처럼 들어갈 일이 있다면 먼저 연락하고 시간을 맞추세요. / 번호를 가지고 있다는 사실과 쓸 수 있다는 판단은 별개입니다.
이렇게 하면 나중에 번호를 지워 달라는 요청이 나와도 서로 얼굴을 붉히지 않습니다.
@ 비전동 세입자 집주인 번호 확인 상담

# 마스터 번호로도 문이 안 열리는 경우
가끔 "마스터 번호면 다 열리는 줄 알았는데요" 하고 연락이 옵니다. / 제품에 따라 안쪽 보조키가 잠겨 있으면 어떤 번호로도 열리지 않습니다.
배터리가 나갔거나 모터가 헛도는 경우에도 번호와 상관없이 문이 움직이지 않습니다. / 번호가 문제가 아니라 장치가 문제인 상황입니다.
이럴 때 번호를 계속 바꿔 누르면 입력 제한이 걸려 한동안 아무 반응이 없게 됩니다. / 두세 번 해보고 안 되면 멈춰 주세요.

# 번호를 바꿨는데 서로 모르는 경우
세입자가 보안 때문에 번호를 바꾸고 집주인에게 알리지 않으면, 집주인의 마스터 번호가 막혔다고 오해합니다. / 반대로 집주인 번호가 남아 있는 줄 모르고 세입자가 사용자 번호만 바꾸는 일도 있습니다.
두 번호가 따로 움직이는 제품도 있고 함께 움직이는 제품도 있습니다. / 어떤 구조인지 보려면 제품 설정 메뉴나 모델명이 필요합니다.
이런 혼선은 한 번만 연락해서 정리해도 크게 줄어듭니다. / 이 단계에서 문을 억지로 열 필요는 대개 없습니다.

# 집주인이 대신 문을 열어 달라고 부를 때
세입자가 연락이 안 되는데 문을 열어야 한다는 요청도 가끔 있습니다. / 이런 경우에는 안에 계신 분의 안전이 걸려 있을 수 있어 민감합니다.
저희는 사는 분 본인 확인이 먼저입니다. / 집주인 요청만으로 임차인의 집을 열어 드리는 것은 어렵고, 필요하면 관계 확인과 현장 상황을 같이 보고 안내드립니다.
법적으로 가능한지 판단이 필요한 상황이라면 먼저 관할 기관이나 전문가 상담을 권해 드릴 수 있습니다. / 어떤 경우든 문을 부수는 일은 마지막까지 피합니다.

# 이사 나갈 때 정리하는 순서
세입자가 이사 나갈 때는 등록한 번호와 카드를 지우는 것이 기본입니다. / 집주인은 새 입주자를 위해 번호를 초기화하거나 새로 등록해야 합니다.
- 퇴거 날짜에 맞춰 도어락 설정 메뉴 확인
- 이전 사용자 번호와 카드 삭제
- 마스터 번호를 쓰는 제품이면 관리자 번호도 변경
- 배터리 상태 확인 후 새것으로 교체
- 다음 입주자에게 새 번호 전달
이 순서를 지키면 이전 사람이 번호를 알고 있다는 걱정이 줄어듭니다. / 더 자세한 방법은 [도어락 교체](doorlock-replace.html) 쪽에서도 안내드립니다.

# 비전동에서 출장열쇠를 부르면
전화로 도어락 모양과 번호판 상태를 먼저 여쭙니다. / 마스터 번호가 있는지 모르면 모른다고 말씀해 주시면 됩니다.
도착하면 사시는 분인지 신분증, 주소가 나온 우편물, 관리사무소 확인으로 먼저 확인합니다. / 이 과정은 이웃과 집 모두를 보호하기 위한 것이라 빠뜨리지 않습니다.
상태를 보고 비용을 문 열기 전에 먼저 말씀드리며, 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에서 확인하실 수 있습니다.
@ 비전동 출장열쇠 신분 확인 후 개문

# 마스터 번호를 아예 쓰지 않는 선택
관리 번호를 남겨 두는 것이 부담스럽다면 쓰지 않는 방법도 있습니다. / 필요할 때만 세입자가 임시 번호를 만들어 주는 방식입니다.
제품에 따라 한 번 쓰고 지워지는 번호나 기간 번호를 지원하는 모델도 있습니다. / 이런 기능이 있는 모델인지는 설명서나 사진으로 확인합니다.
필요하다면 [도어락 설치](doorlock-install.html)를 새로 하면서 사용 방식을 같이 정하는 방법도 있습니다. / 집주인 몫의 관리 방식은 마음에 맞게 정하시면 됩니다.

# 하지 말아야 할 일 세 가지
- 세입자 몰래 번호를 쓰거나 몰래 등록하는 일
- 문이 안 열린다고 도어락을 억지로 분해하는 일
- 번호를 문자나 메신저에 그대로 오래 남겨 두는 일
번호는 메모처럼 남겨 두면 계속 돌아다닙니다. / 필요한 사람에게만 전달하고 쓴 뒤에는 바꾸는 것이 좋습니다.
분해하다 배선이 끊기면 열쇠로도 못 여는 상태가 될 수 있습니다. / 그때는 단순한 번호 문제가 아니라 [도어락 수리](doorlock-repair.html)가 필요해집니다.

# 비전동 말고 평택 어디든 갑니다
비전동 옆 세교동, 동삭동, 서정동은 물론 고덕동, 지산동, 송탄동과 안중읍, 포승읍, 팽성읍, 청북읍까지 다닙니다. / 평택 안이면 24시간 연락받습니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
