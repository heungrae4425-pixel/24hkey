# 비전동에서 우편함이나 사물함이 안 열릴 때
비전동은 아파트와 오피스텔이 많고 1층 우편함, 지하 사물함, 헬스장 개인 사물함까지 열쇠 쓸 일이 생각보다 많은 동네입니다. / 현관문은 문제가 없는데 우편함이나 사물함이 안 열려서 연락 주시는 일이 종종 있습니다.
급한 우편물이 안에 있거나 사물함에 중요한 물건이 있으면 마음이 급해집니다. / 이 글은 평택 비전동에서 우편함과 사물함 열쇠 문제가 생겼을 때 확인할 것을 정리했습니다.
[평택 출장열쇠](pyeongtaek.html)에 연락하기 전에 아래 순서로 먼저 살펴보세요. / 의외로 간단히 해결되는 경우도 있습니다.
@ 비전동 우편함 사물함 열쇠 출장열쇠

# 열쇠를 잃어버렸다면 먼저 찾아볼 곳
우편함 열쇠는 현관 열쇠 꾸러미나 신발장 위, 옷 주머니에 있는 일이 많습니다. / 최근에 입었던 옷 주머니를 한 번 더 확인해 보세요.
이사 올 때 받은 열쇠 중 따로 보관해 둔 것이 없는지도 떠올려 보세요. / 계약서 서류 봉투에 같이 들어 있는 일이 있습니다.
가족 중 다른 분이 가지고 있을 가능성도 있습니다. / 연락해서 확인하면 시간이 훨씬 줄어듭니다.

# 열쇠가 안 돌아갈 때 확인할 것
우편함 열쇠는 작고 얇아서 쉽게 휘거나 닳습니다. / 닳은 열쇠는 돌아가다 걸리면 바로 부러질 수 있습니다.
열쇠 구멍에 먼지, 녹, 종이 조각이 낀 경우도 있습니다. / 이쑤시개로 살살 빼내 보시고 억지로 돌리지는 마세요.
열쇠를 끝까지 넣었다 살짝 빼서 돌려 보면 되는 경우도 있습니다. / 그래도 안 되면 그대로 두세요.

# 관리사무소나 관리하는 분께 먼저 물어보세요
공용으로 설치된 우편함은 관리사무소에 예비 열쇠가 있는 곳이 있습니다. / 먼저 전화로 문의해 보시면 시간이 절약됩니다.
건물을 관리하는 분이 설치한 우편함이라면 임의로 건드리지 않는 것이 좋습니다. / 허락을 받고 진행하는 쪽이 서로 편합니다.
관리사무소가 닫은 시간이라면 다음 날 확인해도 되는지 먼저 따져 보세요. / 급한 물건이 아니라면 낮에 다시 알아보는 편이 낫습니다.
@ 평택 비전동 우편함 열쇠 개방 출장

# 사물함이나 캐비닛은 종류가 다양합니다
헬스장, 학원, 사무실 사물함은 대개 작은 열쇠 구멍이 달려 있습니다. / 어떤 곳은 번호 자물쇠를 쓰기도 합니다.
열쇠형은 복사가 가능한 경우가 많고, 번호형은 비밀번호 확인이 먼저입니다. / 번호가 기억나지 않으면 설치한 곳에 먼저 문의하세요.
직접 산 개인 자물쇠라면 본인 것이라는 것이 확인되어야 합니다. / 이 부분은 뒤에 적은 확인 절차를 따릅니다.

# 남의 물건이 아니라는 것을 먼저 확인합니다
열쇠를 여는 일은 내 것인지 먼저 확인하는 것이 중요합니다. / 우편함이라면 사시는 집 호수와 이름이 일치하는지 살펴봅니다.
사물함이라면 이용 신청서나 회원권, 계약서 같은 서류를 보여 주시면 됩니다. / 서류가 없으면 설치한 곳의 확인을 받으면 됩니다.
확인이 어려우면 작업을 할 수 없습니다. / 이웃과 다른 이용자 모두를 위한 절차이니 양해 부탁드립니다.

# 열쇠를 복사하거나 새로 만들 수 있습니다
기존 열쇠가 하나라도 남아 있다면 복사가 가장 간단합니다. / 열쇠가 전부 없다면 자물쇠를 열고 난 뒤 새 열쇠를 만드는 방법이 있습니다.
[출장 열쇠](key-call.html) 페이지에 적어 둔 대로 열쇠 복사와 제작도 같이 해 드립니다. / 열쇠 종류에 따라 시간이 조금 다릅니다.
복사한 열쇠가 잘 맞는지 현장에서 한 번 더 돌려 보고 확인합니다. / 안 맞으면 그 자리에서 다시 손봅니다.

# 자물쇠를 새로 바꿔야 하는 경우
열쇠 구멍이 심하게 상했거나 안쪽 부품이 부러졌다면 자물쇠를 바꾸는 것이 나을 수 있습니다. / 그래도 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.
교체가 필요하면 우편함 규격에 맞는 제품을 먼저 보여 드립니다. / 마음에 안 드시면 하지 않으셔도 됩니다.
건물 공용 우편함은 임의로 바꾸지 말고 관리하는 분과 먼저 상의하세요. / 같은 모양으로 맞추는 것이 보통 더 좋습니다.

# 비용은 열기 전에 말씀드립니다
자물쇠 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 우편함 열쇠를 잃어버리지 않는 방법
현관 열쇠와 같은 꾸러미에 달아 두는 것이 가장 확실합니다. / 우편함 열쇠만 따로 두면 오히려 잃어버리기 쉽습니다.
복사본을 하나 만들어 믿을 수 있는 가족에게 맡겨 두세요. / 휴대폰으로 열쇠 사진을 찍어 두면 나중에 복사할 때 도움이 됩니다.
열쇠에 작은 고리나 색깔 표시를 해 두면 찾기 쉽습니다. / 이사 때 새로 받은 열쇠는 개수를 확인해 두세요.

# 우편물이 급할 때 미리 알아 둘 것
우편함이 안 열려도 우편물은 우체국에서 다시 받을 방법이 있는 경우가 있습니다. / 급한 문서라면 발송처에 연락해 보세요.
직접 열쇠집을 부르려면 우편함 앞에서 사진을 찍어 먼저 보내 주세요. / 열쇠 구멍 모양을 보면 필요한 준비가 달라집니다.
저희는 우편물 내용은 보지 않고 자물쇠만 엽니다. / 물건은 부르신 분이 직접 꺼내시면 됩니다.

비전동 옆 지산동, 세교동, 동삭동도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
평택에서 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
현관문이 아니라도 열쇠 때문에 곤란하시면 전화 주세요. / 작은 일이라고 망설이지 않으셔도 됩니다.
