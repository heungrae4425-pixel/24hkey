# 비전동에서 자주 듣는 말, 비파손 개방
평택역 가까운 비전동은 새 아파트와 상가, 오피스텔이 섞여 있어 문이 잠겼다는 연락이 꾸준한 동네입니다. / 전화를 하면서 문을 부수지 않고 열 수 있느냐고 먼저 물어보시는 분이 많습니다.
도어락은 한 번 상하면 고치는 데 시간과 돈이 더 들기 때문에 걱정되는 것이 당연합니다. / 이 글은 비파손 개방이 무슨 뜻인지, 어떤 순서로 하는지, 한계는 무엇인지 솔직하게 적었습니다.
[평택 출장열쇠](pyeongtaek.html)를 부르기 전에 알아 두시면 통화가 훨씬 편해집니다. / 지금 문 앞에서 급하신 분은 2번과 6번만 먼저 보셔도 됩니다.
@ 비전동 출장열쇠 24시간 비파손 개방 전문

# 비파손 개방은 이런 뜻입니다
비파손 개방은 문, 문틀, 도어락에 흠을 내거나 부수지 않고 여는 것을 뜻합니다. / 열고 난 뒤에도 도어락을 그대로 쓸 수 있는 상태로 남기는 것이 목표입니다.
반대로 파손 개방은 도어락을 뜯어내거나 문틀을 벌려서 여는 방식입니다. / 빨리 열릴 수는 있지만 부품을 새로 달아야 하는 경우가 많습니다.
어느 쪽이 더 좋은지는 문 상태와 도어락 종류, 상황의 급한 정도에 따라 달라집니다. / 그래서 방법을 정하기 전에 먼저 설명드리고 동의를 받습니다. / 급하다는 이유로 설명 없이 바로 시작하는 일은 없습니다. / 같은 잠금 상태라도 도어락 종류에 따라 가능한 방법이 다르기 때문에 눈으로 본 뒤에 정합니다.

# 왜 부수지 않는 쪽부터 해볼까요
부수고 열면 문은 열리지만 문을 다시 잠그려면 도어락을 새로 달아야 하는 경우가 많습니다. / 한밤에 문이 안 닫히는 채로 지내시는 것은 안전 면에서도 부담이 됩니다.
문 표면이나 문틀에 난 흠집은 나중에 보기에도 신경 쓰이고 고치기도 번거롭습니다. / 그래서 덜 상하는 방법부터 차례로 시도합니다.
비파손으로 열리면 도어락 교체 비용이 따로 들지 않는 경우도 있습니다. / 교체가 필요한 상황이라면 그 이유를 설명드린 뒤에 여쭙습니다. / 열기 전에 교체를 먼저 권하는 일은 하지 않습니다.

# 비파손으로 열기 좋은 상황
아래 같은 경우는 비파손으로 열 수 있는 가능성이 높습니다.
- 열쇠나 카드를 안에 두고 나와 문이 닫힌 경우
- 비밀번호를 잊었거나 배터리가 다 되어 번호판이 꺼진 경우
- 보조키를 잠근 채 문을 닫고 나온 경우
- 도어락은 멀쩡한데 손잡이나 걸쇠가 걸린 경우
모두 도어락 부품이 크게 고장 난 것이 아니라 열리지 않는 상태가 된 경우입니다. / 이런 경우에는 도어락을 살리면서 열 수 있는지 먼저 봅니다. / 도어락 종류와 문 두께에 따라 걸리는 시간은 다르지만, 서두르지 않고 덜 상하는 순서로 진행합니다. / 문이 열린 뒤에도 문과 도어락에 흠이 없는지 같이 확인해 보여드립니다.

# 비파손으로 열기 어려운 상황
모든 경우를 비파손으로 열 수 있는 것은 아닙니다. / 솔직하게 말씀드리면 아래 같은 경우는 어려울 수 있습니다.
- 도어락 내부가 이미 부러지거나 고장 나 있는 경우
- 문이나 문틀이 틀어져 문이 걸려 있는 경우
- 열쇠가 안에서 부러져 막혀 있는 경우
- 잠금장치가 여러 개 겹쳐 있고 일부가 고장 난 경우
이런 경우는 현장에서 보고 방법을 말씀드립니다. / 부수는 방법이 필요하다면 이유와 비용을 먼저 설명드리고 동의를 받은 뒤에 진행합니다. / 그 과정에서 어디까지 상할 수 있는지, 교체가 필요한 부품이 무엇인지도 함께 말씀드립니다. / 동의하지 않으시면 거기서 멈추고 돌아갑니다.
@ 비전동 열쇠집 도어락 비파손 개방 출장

# 시작하기 전에 설명하고 동의를 받습니다
도착하면 먼저 사시는 분인지 확인하고, 문과 도어락 상태를 눈으로 봅니다. / 그다음 어떤 방법으로 열지, 문에 영향이 있을 수 있는지 설명드립니다.
비용도 이때 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.

# 신분 확인은 꼭 필요합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로울 수 있지만 이웃과 집주인 모두를 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요. / 신분증이 집 안에 있다면 휴대폰 속 주소 문자나 관리사무소 확인으로 대신할 수 있는지 함께 찾아봅니다.
자세한 절차는 [이용안내](guide.html)에도 적어 두었습니다.

# 이런 행동은 비파손 가능성을 낮춥니다
전화하기 전에 급한 마음에 혼자 시도하다가 문이 더 상하는 경우가 있습니다.
- 손잡이를 세게 당기거나 문을 발로 차는 것
- 드라이버나 카드로 문틈을 벌리는 것
- 번호판을 두드리거나 눌러 보는 것
- 비밀번호를 수없이 틀려서 도어락이 잠기게 하는 것
이런 시도는 걸쇠를 더 꽉 물게 하거나 문틀을 처지게 만들 수 있습니다. / 비파손으로 열 수 있었던 문이 못 열게 되는 경우도 있으니 그대로 두고 전화 주세요.

# 열고 난 뒤에는 이렇게 확인합니다
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새 건전지로 바꿨는지도 함께 봅니다.
번호를 잊어서 연 경우에는 새 번호를 등록하는 것까지 도와드립니다. / 기존 번호는 지우고 새 번호만 남겨 둡니다. / 열쇠를 안에 두고 나온 경우라면 앞으로는 번호나 카드로도 열 수 있도록 설정을 같이 정리합니다. / 같은 일이 다시 생기지 않도록 확인할 것을 간단히 알려드립니다.
[현관문 개문](door-open.html) 뒤에 도어락이 이상하면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드립니다. / 너무 오래되었으면 [도어락 교체](doorlock-replace.html)를 설명드립니다.
@ 비전동 24시 출장열쇠 도어락 현관문

# 비전동 위치는 이렇게 알려주세요
비전동은 단지와 건물이 많아 정확한 동과 호수가 있으면 도착이 빨라집니다. / 평택역 쪽에서 어느 방향인지 알려주셔도 도움이 됩니다.
- 건물이나 단지 이름과 동, 호수
- 평택역 쪽 어느 방향인지
- 도어락 모양과 번호판 상태
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다.

# 평택 어디든, 비전동 밖도 갑니다
비전동뿐 아니라 평택 안이면 동네 상관없이 24시간 출동합니다. / 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
