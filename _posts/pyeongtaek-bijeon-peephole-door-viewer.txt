# 비전동 현관 앞 도어 아이와 초인종 카메라
평택 비전동은 평택역과 지제역 두 방향으로 출퇴근하는 분들이 많이 사는 생활권입니다. / 저녁에 귀가해서 현관 앞에 서면 밖을 내다보는 도어 아이나 초인종 카메라가 제대로 보이는지가 생각보다 중요합니다.
문 열림 문제는 도어락에서만 생기지 않습니다. / 렌즈가 흐려지거나 카메라가 먹통이 되면 문 앞 상황을 몰라 불안해지고, 그 불안이 도어락 점검으로 이어지는 경우가 많습니다.
이 글은 비전동에서 도어 아이와 초인종 카메라를 점검하는 순서를 적었습니다. / 도어락까지 같이 이상할 때 [평택 출장열쇠](pyeongtaek.html)를 어떻게 부르면 되는지도 이어서 정리했습니다.
@ 비전동 현관문 도어 아이 렌즈 점검

# 렌즈가 뿌옇거나 어두울 때 먼저 볼 것
도어 아이는 작은 유리 렌즈 여러 장이 겹친 구조라 습기와 먼지에 약합니다. / 안쪽에서 들여다봤을 때 뿌옇다면 렌즈 겉면에 낀 막인지, 렌즈 사이로 들어간 습기인지부터 구분해야 합니다.
- 바깥쪽 렌즈 표면에 먼지나 지문, 페인트 얼룩이 묻었는지
- 안쪽 덮개를 열었을 때 렌즈가 물기로 맺혀 있는지
- 복도 센서등이 꺼져 있어 어두운 것은 아닌지
겉면 얼룩이라면 마른 안경닦이로 살살 닦는 것으로 충분한 경우가 많습니다. / 물을 직접 뿌리면 문틈으로 스며들 수 있으니 천에 약간만 묻혀 쓰는 편이 안전합니다.

# 도어 아이 덮개가 헐겁거나 돌아갈 때
안쪽 덮개가 손가락에 걸려 헐겁게 돌아가면 렌즈 본체가 풀리고 있다는 신호입니다. / 그대로 두면 렌즈가 문 바깥으로 밀려 빠지거나, 안쪽으로 떨어져 구멍이 뚫린 채로 남을 수 있습니다.
조일 때는 손으로 살짝만 돌려 보시고, 강하게 돌려 억지로 조이지는 마세요. / 나사산이 마모된 경우에는 더 헛돌아 오히려 일이 커집니다.
문 두께에 맞지 않는 도어 아이는 처음부터 헐겁게 끼워져 있을 수 있어서, 문 두께를 재서 맞는 제품으로 바꾸는 쪽이 낫습니다. / 문 두께와 관련된 확인은 [도어락 설치](doorlock-install.html) 페이지의 설명과 같은 방식입니다.

# 초인종 카메라가 안 켜질 때 확인 순서
초인종 카메라는 전원, 통신, 앱 세 가지 중 하나가 막히면 먹통이 됩니다. / 하나씩 순서대로 확인하면 원인이 금방 좁혀집니다.
- 본체 표시등이 켜지는지, 깜빡이는지
- 건전지형이면 건전지 방향과 잔량
- 전원선형이면 어댑터 연결과 멀티탭 스위치
- 앱에서 기기가 오프라인으로 뜨는지
표시등이 아예 안 들어오면 전원 문제이고, 켜지는데 앱에서 안 보이면 통신 문제입니다. / 이 구분만 해도 전화로 상황을 설명하기가 훨씬 쉬워집니다.

# 와이파이 끊김과 배터리, 어느 쪽 문제일까
최근에 공유기를 바꾸거나 비밀번호를 바꿨다면 카메라가 새 와이파이를 못 찾는 것일 수 있습니다. / 이 경우 카메라 쪽 설정에서 와이파이만 다시 잡아 주면 돌아옵니다.
반대로 와이파이는 멀쩡한데 영상이 뚝뚝 끊긴다면 배터리가 약해졌을 가능성이 큽니다. / 겨울 아침에는 저온 때문에 건전지 힘이 급격히 떨어지는 일도 흔합니다.
건전지는 반쯤 남은 것과 새것을 섞지 말고 한꺼번에 바꿔 주세요. / 그래야 같은 문제가 며칠 만에 다시 오지 않습니다.

# 비 오는 날과 겨울 아침에 생기는 일
카메라 앞면에 빗물이나 결로가 맺히면 화면이 흐리게 나오고, 간혹 오작동 알림이 계속 울립니다. / 마른 수건으로 닦고 잠시 두면 대부분 가라앉습니다.
겨울에는 문 안팎 온도 차가 커서 도어 아이 안쪽에도 김이 서리기 쉽습니다. / 실내 환기를 하거나 현관 앞 습기를 줄여 주면 덜합니다.
@ 비전동 초인종 카메라 와이파이 연결 확인

# 방문자 확인이 안 될 때 하지 말아야 할 것
렌즈나 카메라가 안 보인다고 해서 문을 열고 밖을 확인하려고 허둥대지는 마세요. / 모르는 사람이 서 있는 상황이라면 문을 열지 않고 인터폰이나 전화로 먼저 물어보는 것이 낫습니다.
도어 아이를 직접 뜯어서 구멍을 확인하는 것도 피해 주세요. / 문에 난 구멍이 커지면 방음과 단열이 나빠지고 외관도 상합니다.
카메라 본체를 문에서 억지로 떼다가 문 표면이 긁히거나 접착제가 남는 일도 많습니다. / 먼저 고정 방식을 확인하고 떼어야 합니다.

# 도어락과 초인종 카메라가 같이 이상할 때
도어락이 안 열리면서 초인종 카메라도 먹통이라면 같은 전원이나 통신에 문제가 있을 수 있습니다. / 현관 앞 전원 차단이나 정전이 겹친 때가 대표적입니다.
번호판이 꺼져 있고 카메라 표시등도 꺼져 있다면 먼저 집 안 차단기가 내려갔는지 보세요. / 문 밖에 서 있는 상황이라면 이웃 세대 복도 불이 켜져 있는지부터 봐도 단서가 됩니다.
도어락은 대개 9V 건전지를 바깥 단자에 대면 임시로 켜집니다. / 그래도 반응이 없을 때 [현관문 개문](door-open.html)을 부탁해 주세요.
@ 평택 비전동 도어락 9V 건전지 비상 전원

# 출장열쇠에 전화할 때 알려주실 것
문이 안 열리는 상황이 겹쳤다면 전화로 아래 내용을 알려주세요. / 상황을 잘 알아야 맞는 장비를 챙겨 갈 수 있습니다.
- 비전동 안에서 단지 방향과 동, 호수
- 번호판이 꺼졌는지, 소리만 나는지
- 초인종 카메라가 켜지는지
- 집 안에 아이나 반려동물이 있는지
도어락과 초인종 카메라 모양을 사진으로 보내주시면 더 정확합니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 손님을 모두 지키는 절차입니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 주세요.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 할 때도 바꾸기 전에 따로 여쭙니다. 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 점검을 마친 뒤 한 달에 한 번 보는 습관
도어 아이와 초인종 카메라는 한 번 손봐 두면 한동안 잊고 지냅니다. / 그래서 가끔씩 상태만 눈으로 보는 습관이 오래 쓰게 해 줍니다.
- 한 달에 한 번 렌즈를 마른 천으로 닦기
- 건전지형 초인종은 계절이 바뀔 때 교체
- 공유기를 바꿨다면 카메라 와이파이 다시 연결
- 도어락 소리가 달라지면 [도어락 수리](doorlock-repair.html)를 미리 알아보기
문이 열리고 나서도 도어락 건전지를 같이 갈아 두면 한 번에 정리됩니다. / 낡아서 계속 문제가 이어지면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 비전동 말고 평택 어디든 갑니다
비전동 옆 세교동, 동삭동, 고덕동, 서정동은 물론 안중읍, 포승읍, 팽성읍, 청북읍도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
다른 지역 출동 범위는 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.

# 자주 묻는 질문

? 초인종 카메라 설정까지 봐주나요? | 현장에서 가능한 범위를 먼저 말씀드립니다. 안 되는 부분은 미리 알려드립니다.

? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.
