# 비 오는 밤 비전동 문 앞에서
비전동은 평택역과 가까워 늦은 시간에 역에서 걸어 귀가하는 분이 많은 동네입니다. / 우산을 들고 짐까지 든 채로 문 앞에 섰는데 번호판이 반응하지 않으면 누구라도 마음이 급해집니다.
비가 오는 날은 평소와 달리 신경 쓸 것이 몇 가지 더 늘어납니다. / 이 글은 그런 밤에 출장을 요청할 때 미리 알려 주시면 도착이 빨라지는 내용을 모았습니다.
먼저 [평택 출장열쇠](pyeongtaek.html) 안내를 한 번 읽어 두시면 통화가 훨씬 수월합니다.
@ 비전동 비 오는 밤 출장열쇠 요청

# 우선 몸부터 비를 피하세요
문이 안 열린다고 비를 맞으며 계속 시도할 필요는 없습니다. / 공동 현관 안쪽이나 건물 처마 밑 같은 마른 자리로 먼저 옮기세요.
젖은 손으로 번호판을 계속 누르면 물기가 번호판 틈으로 들어가 오작동이 더 심해질 수 있습니다. / 손과 번호판을 마른 천이나 손수건으로 한 번 닦아 주고 잠시 기다려 보는 것이 좋습니다.
급한 마음에 무리해서 문을 당기다 우산 살이나 짐으로 도어락을 치는 일도 조심하세요.
짐이 무겁다면 일단 바닥에 내려놓고 양손을 비워야 번호를 정확히 누를 수 있습니다. / 한숨 돌리고 숨을 고르는 것만으로 번호를 잘못 누른 실수가 풀리는 경우도 의외로 많습니다.

# 비 때문에 번호판이 안 눌릴 때
장마나 비 오는 날에는 번호판에 습기가 맺혀 입력이 흐트러질 수 있습니다. / 몇 분 기다리며 물기가 마르면 다시 되살아나는 경우도 있습니다.
- 번호판 표면의 물기를 마른 천으로 가볍게 닦기
- 한두 번만 천천히 다시 눌러 보기
- 반응이 없거나 경고음이 계속 나면 멈추기
헤어드라이어로 뜨거운 바람을 가까이 대는 것은 부품이 상할 수 있어 권하지 않습니다.
비가 그친 뒤에도 번호판 안쪽에 물이 남아 있으면 증상이 이어질 수 있습니다. / 다음 날 아침에도 반응이 둔하면 그냥 넘기지 말고 점검을 받아 보세요.

# 전화하기 전에 정리해 둘 정보
통화 시간이 길어지면 비 맞는 시간도 길어집니다. / 아래 네 가지를 머릿속에 정리해 두면 한 번에 끝납니다.
- 현재 위치: 비전동 안에서도 평택역 쪽인지 아닌지, 건물 동과 호수
- 도어락 상태: 완전히 꺼짐, 켜져 있지만 열리지 않음, 경고음
- 열쇠 구멍 유무와 열쇠를 어디에 두고 나왔는지
- 연락 가능한 번호와 지금 기다릴 수 있는 장소
통화 중에는 휴대폰 배터리가 얼마 남았는지도 함께 살펴 주세요. / 중간에 꺼지면 다시 연락하기 어려우니 필요하면 가까운 곳에서 충전할 방법을 찾아 두세요.

# 사진 한 장이 큰 도움이 됩니다
도어락 앞면을 사진으로 찍어 문자로 보내주시면 기종을 미리 알고 출발할 수 있습니다. / 비 오는 날 젖은 휴대폰이 어렵다면 입으로 모양을 설명하셔도 괜찮습니다.
손잡이 일체형인지, 버튼만 있는 형태인지, 위쪽에 보조키가 따로 있는지 정도만 알려 주세요. / 같은 상황이라도 맞는 장비를 챙겨 가는 시간이 크게 줄어듭니다.
사진을 찍을 때는 번호판 전체와 손잡이, 문틀이 함께 보이면 가장 좋습니다. / 문 옆 호수 표시가 같이 나오면 위치 확인도 빨라집니다.
@ 비전동 도어락 사진 문자 전송 기종 확인

# 비 오는 밤에는 도착이 평소보다 늦을 수 있습니다
비가 많이 오면 도로 사정과 시야 때문에 이동에 시간이 더 걸립니다. / 도착 예정 시간은 통화할 때 솔직하게 말씀드리고, 늦어질 때는 중간에 다시 연락드립니다.
그 사이에는 안전한 곳에서 대기하시고 낯선 사람에게 도움을 청해 문을 열려는 시도는 피해 주세요. / 이웃이라도 신원이 확실하지 않은 사람에게 번호를 알려 주지 않는 것이 좋습니다.

# 집 안에 사람이나 동물이 있다면 먼저 말씀해 주세요
아이나 반려동물이 집 안에 혼자 있는 상황이라면 작업의 순서가 달라집니다. / 불이나 가스 레인지를 켜 둔 채 나왔다면 그 사실도 꼭 먼저 알려 주세요.
이 경우에는 다른 일정보다 먼저 움직입니다.
창문이나 베란다 쪽이 열려 있는지, 집 안에 가족이 더 있는지도 알려 주세요. / 작은 정보 하나가 문 여는 방법을 정하는 데 큰 도움이 됩니다. / 문 너머로 계속 말을 걸어 안심시켜 주시면 도움이 됩니다.

# 도착하면 신분 확인부터 합니다
비를 맞고 계시더라도 사시는 분인지 먼저 확인하는 절차는 생략할 수 없습니다. / 이웃과 집주인 모두를 지키기 위한 최소한의 절차입니다.
신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다. / 신분증이 집 안에 있다면 경비실이나 관리사무소에 세대 확인을 부탁해 보세요.
확인이 어려우면 문을 열 수 없으니 이 점만 미리 알아 두시면 좋습니다.
우편물은 고지서 한 장이든 택배 상자든 주소가 보이면 됩니다. / 휴대폰에 저장된 주소지 화면도 참고가 되니 비 맞기 전에 미리 찾아 두세요.

# 비용은 열기 전에 먼저, 못 열면 없음
도어락 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니라면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙습니다. / 전체 흐름은 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 우천 중에도 최대한 안 상하게 엽니다
비가 오는 날일수록 작업 중 물이 도어락 내부로 들어가지 않게 주의합니다. / 우산이나 덮개로 막고 덜 상하는 방법부터 차례로 해봅니다.
도어락과 문틀이 그대로 남도록 하는 것이 먼저이고, 방법은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.
@ 비전동 우천 출장열쇠 문 열기 작업

# 문이 열린 뒤 마른 수건으로 마무리
문이 열리면 먼저 번호판과 손잡이 주변의 물기를 닦아 주고 잠금이 정상인지 확인합니다. / 비 때문에 입력이 흐트러진 경우라면 건조 후 작동을 한 번 더 시험합니다.
배터리나 번호 문제가 함께 있었다면 그것도 같이 정리합니다. / 반복되는 오작동은 [도어락 수리](doorlock-repair.html)로 먼저 점검하고, 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 비 오는 날 대비해 두면 좋은 것
- 출입 시 우산을 접고 번호판에 물이 튀지 않게 한 손으로 가리기
- 현관 앞에 작은 수건 하나 걸어 두기
- 배터리를 계절 바뀔 때마다 점검하기
- 비상용 9V 건전지를 가방에 넣어 두기
이런 습관은 비 오는 밤에 가장 큰 도움이 됩니다.
특히 비 오는 날 번호판에 물이 닿는 시간을 줄이는 것만으로도 오작동 확률이 줄어듭니다. / 도어락에 작은 차양이나 덮개가 있는 기종이라면 평소 잘 닫혀 있는지도 봐 두세요.

# 비전동 말고 평택 어디든 갑니다
비전동 옆 세교동, 동삭동, 서정동, 지산동은 물론 송탄동과 팽성읍, 청북읍까지 평택 전역을 다닙니다. / 다니는 지역은 [출장 지역](area.html)에서 확인하세요.
