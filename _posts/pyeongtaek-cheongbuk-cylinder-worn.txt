# 청북읍 오래된 집 열쇠가 헛돌기 시작했다면
청북읍은 오래 사시는 분이 많은 읍 생활권으로, 평택역까지 나가는 데 시간이 걸려 동네에서 해결하려는 분이 많습니다. / 현관문이나 대문에 십 년 넘게 쓴 열쇠 방식 자물쇠가 아직 많이 남아 있습니다.
어느 날부터 열쇠가 매끄럽게 돌지 않고 헛돌거나 중간에 걸리면 실린더가 닳았다는 신호입니다. / 이 글은 닳은 실린더의 증상과 대처법을 순서대로 적었습니다.
확인해도 안 풀리면 [평택 출장열쇠](pyeongtaek.html)로 연락 주세요.
@ 청북읍 오래 쓴 실린더 열쇠 점검

# 실린더가 뭔가요
열쇠를 꽂는 원통 부분이 실린더입니다. / 안에는 열쇠 홈 높이에 맞춰 움직이는 작은 핀들이 줄지어 있습니다.
열쇠를 꽂으면 핀들이 정확한 높이로 맞춰지면서 원통이 돌아갑니다. / 오래 쓰면 이 핀과 열쇠 모두 조금씩 닳아 맞는 높이가 어긋납니다.
닳는 건 자연스러운 일이라 고장보다는 수명이 다했다고 보는 편이 맞습니다.

# 닳았을 때 나타나는 증상
- 열쇠를 꽂아도 헛돌고 문이 안 열림
- 열쇠를 요리조리 흔들어야 겨우 돌아감
- 열쇠가 잘 안 들어가거나 잘 안 빠짐
- 잠글 때와 열 때 느낌이 다름
- 열쇠 끝이 반짝이게 닳아 있음
이런 증상이 두 가지 이상 겹치면 실린더 상태가 많이 나빠진 것입니다.

# 헛돌 때 먼저 해볼 것
힘을 주기 전에 열쇠를 천천히 뺐다가 다시 꽂아 보세요. / 끝까지 들어갔는지 확인하고 아주 살짝 당긴 상태로 돌리면 걸리는 경우도 있습니다.
여분 열쇠가 있다면 모두 써 보세요. / 원본이 오래 쓴 열쇠보다 덜 닳아 있어서 의외로 잘 돌아가는 일이 있습니다.
문을 살짝 밀거나 당기면서 돌려 보면 걸림쇠 압력이 줄어 풀리기도 합니다.

# 이런 행동은 상태를 더 나쁘게 합니다
- 열쇠를 억지로 돌려서 부러뜨리기
- 구멍에 기름이나 접착제 붓기
- 망치로 두드리거나 도구로 쑤시기
- 닳은 열쇠를 계속 계속 복사해 쓰기
복사본을 또 복사하면 오차가 쌓여 점점 더 안 맞게 됩니다. / 원본이 있다면 그것으로 새로 복사하는 것이 좋습니다.
@ 청북읍 닳은 열쇠 헛돎 증상

# 기름을 넣으면 안 되는 이유
뻑뻑하다고 일반 기름을 넣는 분이 많은데, 당장은 부드러워져도 먼지가 달라붙어 더 심해집니다. / 핀 사이에 끈적한 이물질이 쌓이면 청소하기도 어려워집니다.
굳이 쓴다면 열쇠 구멍용 전용 제품을 아주 소량만 쓰는 것이 낫습니다. / 그것도 상태가 심하면 오히려 고장을 앞당길 수 있습니다.

# 대문과 현관문은 증상이 조금 다릅니다
대문은 비바람을 맞아 녹과 먼지로 뻑뻑해지기 쉽습니다. / 현관문은 하루 몇 번씩 열고 닫아 마모가 빨리 옵니다.
같은 실린더라도 환경에 따라 닳는 속도가 달라서 오래됐다고 한 번에 판단하기는 어렵습니다. / 직접 보고 상태를 확인한 뒤 말씀드립니다.

# 열쇠가 부러졌다면 멈추세요
돌리다 열쇠가 부러져 안쪽에 박히는 경우도 있습니다. / 이때는 더 쑤시지 말고 그대로 두고 연락 주세요.
부러진 조각을 빼내는 일은 구멍 안쪽을 상하지 않게 하는 것이 중요합니다. / 서툴게 빼려다 더 깊이 들어가면 해결이 어려워집니다.

# 전화하실 때 알려주실 내용
청북읍 위치와 상황을 짧게 알려 주시면 도착이 빨라집니다.
- 청북읍 어느 쪽인지, 대문인지 현관문인지
- 열쇠를 돌렸을 때 증상
- 열쇠가 부러졌는지 여부
- 문과 열쇠 구멍 사진
- 집 안에 사람이나 반려동물이 있는지
열쇠 사진을 함께 보내 주시면 도움이 됩니다.

문을 여는 일이라 사시는 분이 맞는지 확인합니다. / 신분증, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 진행할 수 없으니 미리 챙겨 주세요.

# 비용은 열기 전에 말씀드립니다
문 상태와 실린더 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙니다.
진행 방식은 [이용안내](guide.html)에서 확인하실 수 있습니다.
@ 청북읍 출장열쇠 실린더 교체 상담

# 열고 난 뒤 수리할지 바꿀지
문이 열리면 실린더 안쪽 상태를 보고 청소나 조정으로 충분한지 먼저 봅니다. / 가능하면 교체는 미루는 쪽으로 안내합니다.
핀이 많이 닳았다면 실린더만 교환하는 방법이 있어 [도어락 교체](doorlock-replace.html)에서 안내합니다. / 고장 부위를 손보는 일은 [도어락 수리](doorlock-repair.html)에서 설명합니다.
열쇠 대신 번호키로 바꾸고 싶은 분은 [도어락 설치](doorlock-install.html)도 확인해 보세요.
문 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 실린더를 오래 쓰는 관리법
- 열쇠를 꽂을 때 억지로 밀어 넣지 않기
- 열쇠 구멍에 먼지가 보이면 털어 내기
- 열쇠 고리에 무거운 열쇠를 달고 꽂은 채 두지 않기
- 복사는 원본으로만 하기
- 증상이 보이면 미루지 말고 점검
열쇠에 무게가 실려 매달린 채 쓰면 실린더가 한쪽으로 닳습니다.

열쇠를 오래 쓰다 보면 어느 순간 평소와 다른 느낌이 오기 시작합니다. / 이때 알아채고 점검하면 문 앞에서 막히는 일을 피할 수 있습니다.
열쇠를 꽂을 때 걸리는 느낌이 있거나 돌릴 때 소리가 달라졌다면 닳기 시작한 신호입니다. / 하루 이틀 두고 보면 점점 심해지는 경우가 대부분입니다.
실린더만 바꾸면 문 전체를 바꾸지 않아도 되는 경우가 많습니다. / 문과 도어락을 상하지 않게 하면서 필요한 부분만 손보는 방식을 먼저 생각합니다.
새 실린더로 바꾸면 열쇠도 새로 받게 되어 예전 열쇠 복사본이 돌고 있는 걱정도 덜 수 있습니다. / 이사 오기 전부터 쓰던 열쇠가 걱정되는 분께도 도움이 됩니다.

집을 비우는 일이 많은 분이라면 장기간 집을 비우기 전 열쇠가 부드럽게 도는지 확인해 두세요. / 돌아왔을 때 문이 안 열리는 일을 막을 수 있습니다.
열쇠를 새로 복사할 때는 문을 잠그고 여는 느낌까지 같이 확인하세요. / 복사본이 처음부터 뻑뻑하다면 그대로 쓰지 말고 다시 맞추는 편이 좋습니다.
작은 불편을 참고 쓰다가 큰 문제가 되는 경우가 많아, 미리 말씀 주시면 상태를 보고 필요한 만큼만 안내드립니다.

열쇠가 새것처럼 매끈하지 않고 모서리가 둥글어졌다면 교체 시기가 가까워졌다는 신호입니다. / 눈으로 보이는 변화도 판단에 도움이 되니 사진을 찍어 두세요.

열쇠 구멍 주변 금속이 번들거리거나 긁힌 자국이 많다면 그동안 억지로 돌린 흔적일 수 있습니다. / 그런 문은 한 번 점검을 받아 두면 마음이 편합니다.

# 청북읍 말고 평택 어디든 갑니다
청북읍 인근 포승읍, 안중읍, 팽성읍도 다닙니다. / 평택 안이면 24시간 출동합니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
