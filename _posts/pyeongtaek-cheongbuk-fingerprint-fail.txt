# 어제까지 되던 지문이 오늘은 안 읽힙니다
청북읍에서 지제역이나 평택역 쪽으로 출퇴근하시는 분들은 하루에도 몇 번씩 현관 앞에 서게 됩니다. / 손가락을 대면 늘 바로 열리던 도어락이 갑자기 삐 소리만 내면 순간 당황하기 마련입니다.
지문 인식은 편하지만 센서와 손가락, 두 가지 조건이 맞아야 열립니다. / 어느 쪽이 문제인지만 가려도 대부분은 문 앞에서 정리가 됩니다.
이 글은 청북읍 도어락 지문이 잘 안 읽힐 때 확인할 것을 순서대로 적었습니다. / 끝까지 안 열리면 [평택 출장열쇠](pyeongtaek.html)로 연락하는 방법까지 이어서 설명합니다.
@ 청북읍 지문 도어락 인식 오류 점검

# 센서 유리부터 눈으로 살펴보세요
지문 센서는 손가락 끝이 닿는 작은 유리나 금속 면입니다. / 여기에 손때, 로션, 물기가 얇게 앉아도 인식률이 눈에 띄게 떨어집니다.
- 센서 면에 기름기나 지문 자국이 번져 있는지
- 먼지나 스티커, 투명 필름이 붙어 있는지
- 긁힌 자국이나 금이 간 곳이 있는지
마른 안경 닦이용 천으로 한 방향으로 가볍게 닦아 보세요. / 알코올이나 세제를 직접 뿌리면 틈으로 스며들 수 있으니 천에 아주 조금만 묻혀 쓰는 편이 안전합니다.

# 손가락 상태가 바뀌었을 때
지문은 같아도 읽히는 모양은 그날 컨디션에 따라 달라집니다. / 손이 너무 건조하거나 반대로 땀이 났을 때, 장갑을 막 벗었을 때 특히 그렇습니다.
농사일이나 공장 작업, 설거지를 오래 한 날은 손끝이 불거나 닳아 인식이 어려워집니다. / 이럴 때는 손을 말리고 잠시 숨을 고른 뒤 다시 대 보세요.
작은 상처나 밴드가 붙은 손가락은 다른 손가락으로 바꾸는 게 빠릅니다. / 등록해 둔 손가락이 여러 개라면 그중 상태 좋은 쪽을 쓰면 됩니다.

# 대는 방법만 바꿔도 달라집니다
센서에 손끝만 살짝 올리는 분이 많은데, 지문 한가운데가 닿아야 잘 읽힙니다. / 너무 세게 누르거나 쓸어내리듯 움직이면 오히려 실패합니다.
처음 등록할 때와 같은 각도, 같은 힘으로 대는 것이 좋습니다. / 삐 소리가 난 직후 바로 다시 대기보다 한 박자 쉬고 대 보세요.
연속으로 여러 번 실패하면 도어락이 잠시 입력을 막는 제품이 있습니다. / 서너 번 해 보고 안 되면 멈추고 다른 방법으로 넘어가는 게 낫습니다.

겨울 아침 차가운 손으로 대면 지문이 평소와 다르게 읽힙니다. / 손을 주머니에 넣어 데운 뒤 다시 대면 열리는 경우가 흔합니다.
비 오는 날 우산과 짐을 든 채 젖은 손을 대는 것도 실패의 흔한 이유입니다. / 손과 센서를 마른 천으로 닦고 시도해 주세요.
@ 청북읍 도어락 센서 청소와 손가락 상태 확인

# 지문 말고 다른 방법이 있는지 떠올려 보세요
지문 도어락은 대부분 번호나 카드, 열쇠로도 열리게 만들어져 있습니다. / 지문이 안 읽혀도 번호를 기억하신다면 번호판부터 눌러 보세요.
- 비밀번호 입력
- 등록해 둔 카드키나 태그
- 도어락 아래쪽 비상 열쇠 구멍
- 외부 전원을 연결하는 비상 단자
열쇠 구멍이 있는 제품은 덮개를 열어야 보이는 경우가 많습니다. / 열쇠를 집 안에 두고 나왔다면 이 방법은 쓸 수 없으니 바로 다음 단계로 가시면 됩니다.

# 배터리가 약할 때도 지문부터 흔들립니다
배터리가 약해지면 번호판은 켜지는데 지문 센서만 느려지거나 읽지 못하는 일이 있습니다. / 센서가 번호판보다 전기를 더 쓰기 때문입니다.
경고음이 평소보다 자주 나거나 불빛이 흐리다면 배터리를 의심해 보세요. / 아래 비상 단자에 9V 건전지를 대면 일시적으로 전원이 들어옵니다.
문이 열리면 안쪽에서 배터리를 전부 새것으로 바꿔 주세요. / 일부만 바꾸면 같은 증상이 금방 다시 나옵니다.

# 이럴 땐 혼자 붙잡지 마세요
센서를 닦고 손가락을 바꾸고 번호까지 눌러 봤는데도 열리지 않는 경우가 있습니다. / 모터 소리만 나거나 번호판이 완전히 꺼졌다면 내부 문제일 가능성이 있습니다.
드라이버로 도어락 덮개를 열거나 문틈을 벌리는 것은 피해 주세요. / 센서 배선이 끊어지면 고쳐 쓸 수 있던 도어락도 바꿔야 할 수 있습니다.
이때가 평택 열쇠집에 연락하실 때입니다. / 청북읍처럼 평택 시내에서 조금 떨어진 곳이라면 위치를 정확히 알려주시는 것이 중요합니다.

# 전화로 이렇게 말씀해 주세요
전화로 상황을 짧게 설명하시면 필요한 장비를 챙겨 갈 수 있습니다. / 다음 내용만 알려주셔도 충분합니다.
- 청북읍 안의 대략적인 위치와 건물 형태
- 지문 센서 상태, 번호판이 켜지는지 여부
- 삐 소리인지 모터 소리인지 같은 반응
- 도어락 모양과 가능하면 사진
- 집 안에 아이나 반려동물이 있는지
사진은 문자로 보내주시면 됩니다. / 집 안에 사람이 있다면 꼭 먼저 말씀해 주세요.
@ 청북읍 24시 출장열쇠 도어락 문 열기

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 우편물이나 휴대폰 속 계약 관련 자료로 상황을 설명해 주세요. / 건물에 관리사무소가 있으면 세대 확인을 부탁하는 방법도 있습니다.
확인이 어려우면 작업을 시작할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 먼저 안내하고, 괜찮다고 하실 때 시작합니다. / 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 열고 난 뒤 지문 설정을 다시 잡습니다
문이 열리면 지문 센서가 정상인지 먼저 확인합니다. / 센서가 멀쩡한데 지문만 안 읽혔다면 등록을 새로 하는 것이 해결책일 때가 많습니다.
등록은 같은 손가락을 여러 각도로 나눠 여러 번 찍어 두면 훨씬 잘 읽힙니다. / 가족마다 두세 개씩 등록해 두면 한 손가락이 다쳐도 문제가 없습니다.
센서 자체가 고장이면 [도어락 수리](doorlock-repair.html)로 고칠 수 있는지 먼저 보고, 어렵다면 그때 [도어락 교체](doorlock-replace.html)를 설명드립니다.

# 지문 도어락을 오래 잘 쓰는 습관
- 센서는 일주일에 한 번 마른 천으로 닦기
- 손이 젖었거나 로션을 바른 직후엔 닦고 대기
- 배터리는 경고음이 나면 그날 바로 교체
- 지문 등록은 손가락 두세 개, 각도를 바꿔 여러 번
- 비밀번호나 카드키는 지문과 별도로 꼭 기억해 두기
지문에만 의존하면 인식이 안 되는 날 문 앞에서 막힙니다. / 다른 열기 수단을 하나는 늘 살려 두세요.
도어락 교체 시기를 알아보고 싶으시면 [도어락 설치](doorlock-install.html) 안내도 참고해 주세요.

# 청북읍 말고 평택 어디든 갑니다
청북읍 가까이로는 안중읍, 포승읍, 팽성읍, 서정동, 송탄동도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

# 자주 묻는 질문
? 지문 등록을 지우고 새로 해도 되나요? | 네, 열린 뒤에 기존 등록을 지우고 새로 등록해 드릴 수 있습니다.
? 센서가 고장이면 꼭 도어락을 바꿔야 하나요? | 먼저 고칠 수 있는지 봅니다. 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
? 문을 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에도 전화받나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.

# 마무리
지문이 안 읽힌다고 해서 바로 고장은 아닙니다. / 센서를 닦고 손을 바꾸고 번호를 눌러 보는 것만으로 열리는 경우가 많습니다.
그래도 안 열리면 억지로 열지 마시고 상황만 알려주세요. / 24시출장열쇠는 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주시면 됩니다.
