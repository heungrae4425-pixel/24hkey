# 청북읍 도어락 건전지, 마트에서 뭘 사야 할까
청북읍은 평택역이나 지제역으로 오가는 길이 있는 읍 지역이라 급하게 건전지를 구하러 나가기가 번거로운 때가 있습니다. / 그래서 미리 어떤 건전지를 쓸지 정해 두는 편이 좋습니다.
도어락 배터리는 마트에 가면 알카라인, 리튬, 충전식까지 종류가 많아 헷갈립니다. / 잘못 사면 번호판이 금방 꺼지거나 제품이 상할 수 있습니다.
이 글은 청북읍에서 도어락 건전지를 고르는 기준과 교체할 때 주의할 점을 정리했습니다. / 먼저 내 도어락이 어떤 건전지를 쓰는지 확인하는 것이 순서입니다.

# 먼저 도어락이 요구하는 규격 확인
건전지 종류보다 먼저 봐야 할 것은 규격입니다. / 도어락마다 AA, AAA, 또는 비상용 9V 같은 규격이 정해져 있습니다.
- 안쪽 배터리 덮개에 적힌 규격
- 설명서에 적힌 권장 건전지 종류
- 건전지 몇 개가 들어가는지
규격을 모르겠으면 덮개를 열어 기존 건전지를 사진으로 찍어 두세요. / 그 사진을 들고 가면 고르기가 쉽습니다.
건전지에 적힌 글자가 지워졌다면 크기를 재어 보는 방법도 있습니다. / 어느 쪽이든 문이 열린 상태에서 확인하세요.

# 알카라인 건전지의 특징
알카라인은 가장 흔하게 쓰는 일반 건전지입니다. / 어디서든 쉽게 구할 수 있다는 것이 가장 큰 장점입니다.
편의점이나 마트 어디서든 같은 모양을 찾기 쉽고, 한 번 사서 여러 개를 쟁여 두기도 쉽습니다. / 너무 싼 무명 제품보다는 이름이 알려진 제품이 안정적입니다.

대부분의 도어락은 알카라인 기준으로 설계되어 있습니다. / 평소에는 이것만으로도 충분히 잘 작동합니다.
다만 온도가 많이 내려가면 힘이 약해지는 경향이 있습니다. / 겨울에 갑자기 반응이 느려진다면 이 영향일 수 있습니다.

# 리튬 건전지의 특징
리튬은 알카라인보다 추위에 강하고 오래 쓰는 편이라고 알려져 있습니다. / 대신 쉽게 구할 수 있는 곳이 적고 값이 높은 편입니다.
모든 도어락에 리튬을 쓸 수 있는 것은 아닙니다. / 제품에 따라 전압이 달라 맞지 않는 경우가 있어서입니다.
설명서에 허용한다고 적혀 있는지 먼저 확인하세요. / 확실하지 않으면 사용하지 않는 편이 안전합니다.
설명서가 없다면 제조사 이름과 모델명으로 확인해 볼 수 있습니다. / 그래도 모르면 전화로 모델 사진을 보내 주세요.
@ 알카라인과 리튬 건전지 비교

# 충전식 건전지는 조심해서
충전식 건전지는 처음에는 경제적으로 보입니다. / 하지만 전압이 일반 건전지보다 낮은 경우가 많습니다.
도어락은 전압이 조금만 낮아도 경고음을 내거나 오작동할 수 있습니다. / 제품이 충전식 사용을 허용한다고 적혀 있을 때만 쓰세요.
충전식은 방전이 서서히 일어나 갑자기 꺼지는 경우도 있습니다. / 중요한 현관문에는 권하지 않는 편입니다.
대신 예비 건전지는 서랍에 넣어 두고, 쓰는 건전지는 한꺼번에 교체하는 편이 훨씬 안전합니다.

# 겨울철에 고려할 점
날이 추워지면 건전지 성능이 떨어집니다. / 가을 끝무렵부터 한 번 점검해 두는 것이 좋습니다.
- 번호 입력 때 평소보다 반응이 느린지
- 경고음이 평소보다 자주 나는지
- 문을 열 때 모터 소리가 약해졌는지
이런 신호가 보이면 건전지를 바꿀 때가 된 것입니다. / 한파가 오기 전에 새 것으로 교체하세요.
새 건전지라도 오래 방치해 둔 것은 이미 힘이 빠졌을 수 있습니다. / 유통 기한이 표시된 제품은 날짜를 확인하고 사세요.

# 교체할 때는 전부 한꺼번에
건전지는 일부만 바꾸면 안 됩니다. / 새것과 헌것을 섞어 쓰면 헌것이 새것을 빨리 소모시킵니다.
같은 종류, 같은 회사, 같은 시기에 산 건전지를 한꺼번에 넣는 것이 가장 좋습니다. / 종류가 다른 건전지를 섞으면 누액이 생길 수 있습니다.
헌 건전지는 일반 쓰레기가 아니라 분리수거함에 따로 버려야 합니다. / 동네 주민센터나 아파트 수거함을 이용하세요.
교체한 날짜를 배터리 칸 덮개 안쪽에 적어 두면 잊지 않습니다.

# 극성 방향 확인
건전지를 거꾸로 넣으면 작동하지 않을 뿐 아니라 제품이 상할 수 있습니다. / 플러스, 마이너스 표시를 꼭 확인하세요.
넣은 뒤 번호판을 눌러 불이 들어오고 소리가 나는지 확인합니다. / 이상이 없으면 문을 닫은 채 한 번, 연 채 한 번 번호를 눌러 보세요.
문 밖에서 확인하지 않고 문을 닫아 버렸다가 작동하지 않으면 곤란합니다. / 반드시 문이 열린 상태에서 확인하세요.
@ 도어락 건전지 극성 방향 확인

# 건전지를 갈았는데도 안 될 때
새 건전지를 넣었는데도 번호판이 켜지지 않으면 접점이 문제일 수 있습니다. / 접점 부분이 더러워지거나 부식된 경우입니다.
마른 면봉으로 가볍게 닦아 보세요. / 물이나 알코올을 많이 쓰는 것은 권하지 않습니다.
그래도 안 되면 도어락 내부 문제일 수 있으니 [도어락 수리](doorlock-repair.html) 안내를 참고해 전화 주세요.

# 비상용 9V 건전지 준비
많은 도어락에는 바깥쪽 아래에 9V 비상 단자가 있습니다. / 건전지를 대고 있는 동안 전원이 들어와 번호를 누를 수 있습니다.
차나 가방에 9V 건전지 하나를 넣어 두면 번호판이 꺼졌을 때 큰 도움이 됩니다. / 다만 오래 두면 방전될 수 있으니 가끔 확인하세요.
이 방법으로도 안 되면 억지로 하지 말고 연락 주세요.
9V 건전지를 댈 때는 단자에 접촉만 시키고 오래 누르지 마세요. / 몇 초 안에 번호를 눌러 열리는 것이 정상입니다.

# 문이 잠겼을 때 출장열쇠가 하는 일
건전지 문제로 문이 안 열리면 먼저 비상 전원으로 시도합니다. / 안 되면 문을 상하지 않게 여는 방법으로 진행합니다.
신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나를 준비해 주세요. / 열기 전에 비용을 먼저 말씀드리고, 못 열면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html)와 [현관문 개문](door-open.html) 페이지에도 정리해 두었습니다.
