# 청북읍 도어락 앱이 갑자기 안 될 때
청북읍은 읍 단위라 동네와 동네 사이가 넓고, 평택역이나 지제역 쪽으로 나가려면 차로 움직이는 집이 많습니다. / 그래서 출근길에 문을 잠갔는지 휴대폰으로 확인하는 도어락을 쓰는 분도 적지 않습니다.
그런데 어느 날 앱에 연결 실패가 뜨고, 문이 열리고 닫히는 알림도 오지 않는 일이 생깁니다. / 문이 잠겨 있는지조차 알 수 없으니 괜히 마음이 불안해집니다.
이 글은 청북읍에서 도어락 앱 연동이 안 될 때 집에서 먼저 해볼 순서를 정리했습니다. / 마지막에는 현관문 자체가 안 열릴 때 [평택 출장열쇠](pyeongtaek.html)를 부르는 기준도 적었습니다.
지금 문 앞에 서 계신데 문이 안 열리는 상황이라면 4번과 7번부터 보셔도 됩니다.
@ 청북읍 출장열쇠 24시간 도어락 앱 연동

# 앱이 안 돼도 문은 열리는 경우가 많습니다
앱 연동은 도어락에 더해진 편의 기능이고, 문을 여닫는 기본 기능은 따로 움직입니다. / 그래서 앱이 먹통이어도 번호나 카드, 열쇠로는 문이 열리는 집이 대부분입니다.
먼저 도어락 번호판을 눌러 보세요. / 평소처럼 불이 들어오고 번호로 열린다면 도어락 본체는 정상이고, 문제는 앱이나 통신 쪽에 있을 가능성이 큽니다.
이때는 서두를 필요가 없습니다. / 천천히 아래 순서대로 확인하면 직접 해결되는 경우가 많습니다.

이유는 크게 다섯 가지로 나뉩니다.
- 집 공유기가 바뀌었거나 와이파이 비밀번호를 새로 정한 경우
- 휴대폰 운영체제를 업데이트하면서 앱 권한이 초기화된 경우
- 절전 설정 때문에 앱이 뒤에서 꺼져 알림이 막힌 경우
- 도어락 배터리가 약해져 통신이 먼저 끊기는 경우
- 앱 로그인이 만료되었거나 계정을 새로 만든 경우
어느 쪽인지 모른 채 앱을 지웠다 깔면 등록 정보가 날아가 더 번거로워질 수 있습니다. / 지우기 전에 아래 순서로 먼저 확인해 보시길 권합니다.

# 1단계, 휴대폰 쪽 설정부터 봅니다
블루투스와 위치 권한이 켜져 있는지 확인하세요. / 알림 권한과 절전 제외 설정도 함께 봅니다.
휴대폰을 껐다 켜기만 해도 연결이 돌아오는 경우가 있습니다. / 가장 쉬운 방법이니 제일 먼저 해보세요.
최근에 휴대폰을 바꾸셨다면 새 기기에서 도어락을 다시 등록해야 할 수 있습니다. / 이때는 도어락 안쪽의 등록 버튼 위치를 설명서에서 찾아야 합니다.

# 2단계, 집 와이파이와 연결 장치를 봅니다
와이파이로 연결되는 도어락은 문 옆이나 현관 안쪽에 연결 장치가 따로 붙어 있는 경우가 있습니다. / 이 장치의 전원 어댑터가 빠졌거나 멀티탭이 꺼져 있어서 끊기는 일이 의외로 많습니다.
공유기를 교체했거나 재부팅했다면 연결 장치도 다시 한번 연결해야 할 수 있습니다. / 와이파이 이름과 비밀번호가 예전과 같은지 확인해 주세요.
현관문은 철문이라 신호가 약하게 잡히는 집도 있습니다. / 공유기가 현관과 먼 방에 있다면 연결 장치를 현관 가까이로 옮겨 보는 것도 방법입니다.
@ 청북읍 열쇠집 도어락 연동 점검 출장

# 3단계, 배터리를 확인합니다
배터리가 약해지면 도어락은 문을 여닫는 기능을 지키려고 통신부터 줄이는 경우가 있습니다. / 그래서 알림이 먼저 안 오고, 며칠 뒤 번호판이 꺼지는 순서로 문제가 나타나기도 합니다.
앱에서 배터리 잔량을 볼 수 있다면 확인하고, 없다면 번호판의 경고음과 불빛을 살핍니다. / 건전지는 한 개만 바꾸지 말고 전부 새것으로 함께 바꿔 주세요.
교체 후에는 연결을 다시 확인합니다. / 이 단계에서 해결되는 경우도 많습니다.

# 4단계, 번호판이 꺼졌거나 문이 안 열릴 때
앱이 안 되는 것과 문이 안 열리는 것은 다른 문제입니다. / 번호판이 아예 꺼져 있다면 배터리가 다 된 것일 수 있어 비상 전원을 대 봐야 합니다.
많은 도어락은 바깥쪽 아래에 9V 건전지를 대는 단자가 있습니다. / 건전지를 대고 있는 동안 번호를 누르면 열리는 경우가 있습니다.
그래도 반응이 없거나 모터 소리만 나고 열리지 않는다면 혼자 붙잡지 마세요. / 억지로 당기거나 문틈을 벌리면 도어락과 문틀이 상합니다.

# 앱 재설치와 초기화는 마지막에
앱을 지웠다 다시 깔면 등록 정보가 사라질 수 있습니다. / 초기화는 기존 비밀번호와 등록한 카드가 모두 지워질 수 있어 더 신중해야 합니다.
초기화 전에 가족 비밀번호와 카드를 어떻게 다시 등록할지 먼저 정해 두세요. / 설명서가 없다면 도어락 안쪽의 제조사와 모델명을 사진으로 남겨 두면 도움이 됩니다.
혼자 하기 부담되면 전화로 상황을 먼저 말씀해 주세요. / 방문해서 같이 보면 훨씬 빠르게 정리됩니다.

# 이런 상황에서는 바로 전화 주세요
아래에 해당하면 집에서 더 시도하지 않는 편이 안전합니다.
- 번호도 열쇠도 안 먹히고 문이 열리지 않을 때
- 번호판이 꺼진 채 비상 전원을 대도 반응이 없을 때
- 알림이 이상하게 오거나 문이 혼자 잠기고 열리는 것처럼 보일 때
- 초기화를 했는데 번호가 등록되지 않을 때
@ 청북읍 24시 출장열쇠 도어락 현관문

# 청북읍 위치는 이렇게 알려주세요
읍 단위라 지번이 넓게 퍼져 있어 위치를 정확히 알려주셔야 도착 시간을 말씀드리기 쉽습니다. / 건물 이름이나 마을 이름, 그리고 근처에서 눈에 띄는 가게를 함께 알려주세요.
- 건물 또는 마을 이름과 호수
- 평택역, 지제역 쪽 중 어느 방향인지
- 도어락 모양과 번호판 상태
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다. / 연동 장치가 있다면 그 모양도 함께 찍어 주세요.

# 도착하면 신분 확인과 비용 안내부터 합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로울 수 있지만 이웃과 손님 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

도어락 종류와 문 상태를 보고 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문은 최대한 안 상하게 엽니다
[현관문 개문](door-open.html)은 도어락과 문틀이 덜 상하는 방법부터 차례로 해봅니다. / 연동 장치나 센서가 붙어 있다면 손대기 전에 위치를 먼저 확인합니다.
문을 연 뒤에는 도어락이 다시 잘 잠기고 열리는지 같이 봅니다. / 앱 연동은 그 자리에서 다시 맞춰 드릴 수 있는지 먼저 말씀드립니다.
상태에 따라 [도어락 수리](doorlock-repair.html)로 해결되는지, [도어락 교체](doorlock-replace.html)가 필요한지 설명드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 연동 도어락을 오래 쓰는 관리법
- 배터리는 해마다 한 번에 전부 교체
- 공유기를 바꾸면 연동 장치도 같은 날 다시 연결
- 휴대폰을 바꾸면 도어락 등록부터 정리
- 가족 번호는 휴대폰 말고 따로 적어 안전한 곳에 보관
- 휴대폰이 꺼져도 열 수 있도록 번호나 카드 방식을 꼭 남겨 두기
앱에 의존하다가 휴대폰이 방전되면 문 앞에서 막히는 일이 생깁니다. / 번호나 카드 방식은 항상 열려 있게 두는 것이 안전합니다.
새로 도어락을 고르실 때는 [도어락 설치](doorlock-install.html) 페이지의 확인 항목도 참고해 보세요.

# 평택 어디든, 청북읍 밖도 갑니다
청북읍뿐 아니라 평택 안이면 동네 상관없이 24시간 출동합니다. / 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.
