# 청북읍 한여름 낮에 문 앞에서 막혔을 때
청북읍은 평택역이나 송탄역, 지제역과는 거리가 있는 생활권이라 집 앞에서 막히면 바로 쉴 곳을 찾기 어려울 때가 있습니다. / 한여름 낮에 문이 안 열리면 문제는 문만이 아니라 더위입니다.
이 글은 열쇠를 부르고 기다리는 동안 몸을 지키는 방법을 중심으로 적었습니다. / 문 여는 순서는 [평택 출장열쇠](pyeongtaek.html)가 오면 어떻게 진행되는지로 이어집니다.
문 앞에서 기다리는 시간이 길어질수록 위험해지니, 아래 순서를 먼저 보세요.
@ 청북읍 한여름 낮 현관문 앞 그늘에서 대기

# 가장 먼저 할 일은 그늘과 물
문이 안 열린다는 걸 알았다면 일단 몸부터 식히세요. / 햇볕이 드는 복도라면 계단참이나 건물 입구 그늘로 자리를 옮기는 편이 낫습니다.
물이나 음료를 챙겨 두지 않았다면 가까운 편의점이나 가게에서 먼저 사 오세요. / 문 앞에 서서 기다리다 어지러워지고 나서 움직이는 건 늦습니다.
모자나 양산이 있다면 쓰고, 목 뒤와 이마를 젖은 수건으로 식혀 주면 좋습니다.

# 이런 증상이면 기다리지 말고 쉽니다
더운 날 밖에서 오래 있으면 몸이 먼저 신호를 보냅니다. / 아래 증상이 나타나면 문을 열려는 일보다 쉬는 것이 먼저입니다.
- 머리가 아프고 어지러운 느낌
- 땀이 갑자기 멎고 피부가 뜨겁고 붉어짐
- 구역질이 나거나 몸에 힘이 빠짐
- 말이 어눌해지거나 정신이 흐려짐
증상이 심하거나 의식이 흐려지면 열쇠를 부르기 전에 119에 먼저 연락하세요. / 문은 나중에 열 수 있지만 몸은 늦으면 되돌리기 어렵습니다.

# 아이와 반려동물이 같이 있다면
아이는 어른보다 열을 빨리 받고 표현도 서툴러서 먼저 챙겨야 합니다. / 아스팔트나 철문에 직접 앉히지 말고 그늘진 곳에서 물을 먹이세요.
반려동물도 더위에 약합니다. / 차 안에 두고 기다리는 건 짧아도 위험하니 피해 주세요.
집 안에 아이나 반려동물이 갇혀 있는 상황이라면 전화할 때 꼭 먼저 말씀해 주세요. / 순서를 앞당겨 안내해 드립니다.

# 집 안에 사람이 있는데 문이 잠겼다면
어르신이나 아이가 안에 있고 문이 열리지 않는다면 에어컨이 꺼졌는지부터 떠올려 보세요. / 한여름 닫힌 집은 한 시간만 지나도 숨쉬기 힘들 만큼 더워질 수 있습니다.
문 너머로 계속 말을 걸어 안쪽 상태를 확인하고, 창문을 열 수 있는지 물어보세요. / 답이 없거나 반응이 이상하면 전화로 바로 알려주셔야 합니다.
이 경우에는 문 상태보다 사람 안전이 우선입니다.

# 기다리는 동안 혼자 하지 말아야 할 것
급한 마음에 문을 발로 차거나 어깨로 밀면 몸을 다치고 문틀도 상합니다. / 손잡이를 세게 당기면 걸쇠가 더 꽉 물립니다.
드라이버나 신용카드로 문틈을 벌리는 것도 피해 주세요. / 도어락 외관이 상하고 나중에 비용이 더 드는 경우가 많습니다.
비밀번호를 여러 번 틀리면 도어락이 입력을 한동안 막습니다. / 서너 번 해보고 안 되면 멈추세요.
@ 청북읍 문 앞에서 전화로 상황을 설명하는 모습

# 더위가 문을 더 잘 안 열리게 만들기도 합니다
한여름 열기에 철문과 문틀이 조금씩 팽창해 평소보다 빡빡해지기도 합니다. / 그래서 잘 열리던 문이 낮에만 걸리는 일이 생깁니다.
번호판이 뜨거워진 문 표면 때문에 반응이 늦는 경우도 있습니다. / 그늘에서 잠깐 식힌 뒤 다시 눌러 보면 돌아오기도 합니다.
원인이 열인지 배터리인지는 [현관문 안 열림 상황별 확인](door-open.html)을 보시면 구별하기 쉽습니다.

# 청북읍에서 위치를 알릴 때 도움이 되는 것
청북읍은 공단과 주거지, 큰길이 섞여 있어 건물 이름만으로는 찾기 어려울 수 있습니다. / 가까운 큰길이나 눈에 띄는 가게 방향을 함께 말씀해 주세요.
- 현재 서 계신 위치와 층, 호수
- 문 앞 그늘이 있는지, 사람이 몇 명인지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙겨 가기 좋습니다.

# 신분 확인과 비용, 문 열기 전에 먼저
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
더운 날에 번거롭겠지만 이웃과 집주인 모두를 지키는 절차입니다. / 신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁해 두세요.

문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 아니라면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열린 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 먼저 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 빨리 열되 문은 상하지 않게
기다리는 시간이 길수록 힘든 날씨라 빠르게 여는 것이 중요합니다. / 하지만 서두르다 문이나 도어락이 상하면 나중에 더 번거로워집니다.
덜 상하는 방법부터 차례로 시도하고, 작업 중 교체할 부품이 보이면 먼저 말씀드립니다.
방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.
@ 청북읍 출장열쇠 현관문 개문 작업

# 문이 열린 뒤 더위 속에서 해둘 점검
열린 집은 먼저 환기를 시키고 에어컨부터 켜서 실내 온도를 낮추세요. / 안에서 오래 갇혀 있던 사람이라면 물을 마시게 하고 잠깐 쉬게 해 주세요.
도어락은 배터리와 동작을 다시 확인합니다. / 열 때문에 반응이 늦었던 거라면 직사광선이 닿는 위치인지도 같이 봅니다.
고쳐서 쓸 수 있으면 교체를 권하지 않고, 고장이 잦을 때만 [도어락 수리](doorlock-repair.html)를 먼저 안내합니다.

# 한여름에 대비해 둘 것들
- 외출할 때 가방에 작은 물병과 얇은 수건 챙기기
- 비상용 9V 건전지와 보조키 챙기기
- 현관 가까이에 앉을 수 있는 그늘 위치 알아 두기
- 아이에게 번호나 연락처 한 곳 외워 두게 하기
- 배터리는 더위가 오기 전에 한꺼번에 교체하기
미리 챙겨 두면 낮에 문이 안 열려도 훨씬 여유 있게 기다릴 수 있습니다.
가까운 이웃이나 가족에게 상황을 알려 두면 시원한 곳에서 기다릴 수도 있습니다. / 혼자 오래 버티지 말고 잠깐이라도 실내로 들어가 쉬는 것이 좋습니다.
긴 시간 서 있기보다 앉을 수 있는 그늘이 있다면 그곳에서 전화를 이어 가세요.

# 청북읍 말고 평택 어디든 갑니다
청북읍 옆 포승읍, 안중읍, 팽성읍과 고덕동, 비전동, 송탄동도 다닙니다. / 평택 안이면 24시간 출동합니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에서, 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
