# 청북읍 학생이 혼자 집에 들어올 때
청북읍은 평택 북서쪽에 있는 읍 지역으로 주택과 아파트, 빌라가 섞여 있습니다. / 평택역이나 지제역으로 나가는 부모님과 달리 아이들은 학교에서 곧바로 집으로 오는 경우가 많습니다.
부모님이 퇴근하기 전에 학생이 먼저 귀가하는 집이라면 도어락 번호가 사실상 열쇠 역할을 합니다. / 열쇠를 들고 다니다 잃어버리는 걱정은 줄지만, 번호 관리라는 새 숙제가 생깁니다.
이 글은 청북읍에서 열쇠 없이 하교하는 학생의 도어락 번호를 어떻게 정하고 관리하면 좋은지 [평택 출장열쇠](pyeongtaek.html) 입장에서 정리했습니다.
@ 청북읍 학생 하교 후 현관 도어락 번호 입력

# 번호는 아이가 외우기 쉽되 남이 짐작하기 어렵게
생일이나 전화번호 끝자리는 외우기 쉽지만 남도 짐작하기 쉽습니다. / 아이가 기억하기 좋은 규칙을 가족이 같이 만들어 보세요.
- 연속된 숫자나 같은 숫자 반복은 피하기
- 집 호수나 생일 그대로 쓰지 않기
- 아이가 자기만의 방식으로 풀어서 기억할 수 있는 번호
- 너무 길어 틀리기 쉬운 번호는 피하기
번호는 아이와 함께 정하면 스스로 책임감을 갖고 기억하게 됩니다.
번호를 정한 뒤에는 현관 앞에서 아이가 직접 두세 번 눌러 보게 해 주세요. / 손가락이 번호판에 닿는 위치를 몸으로 익히면 훨씬 덜 헷갈립니다.
가방에서 열쇠를 꺼내는 일이 없으니 양손에 짐이 있어도 문을 열 수 있다는 장점이 있습니다. / 다만 번호를 큰 소리로 말하거나 누르는 모습이 보이지 않게 손으로 가리는 습관은 알려 주세요.

# 친구에게 번호를 알려주지 않도록 이야기하기
학생들은 친한 친구를 집에 데려오면서 번호를 쉽게 알려 줄 수 있습니다. / 잘못이라기보다 아직 번호가 중요한 정보라는 감각이 덜 생긴 것입니다.
가족 번호는 친구에게 알려 주지 않는 것이 규칙이라고 부드럽게 이야기해 주세요. / 친구가 오는 날은 아이가 직접 문을 열어 주는 방식으로 정하면 됩니다.
혹시 번호가 알려진 것 같다면 비난하지 말고 번호를 새로 바꾸면 됩니다.
@ 청북읍 하교 시간 현관 도어락 사용
하교 시간대에는 엘리베이터나 복도에 다른 사람이 있을 수 있습니다. / 번호를 누르기 전에 주변을 한 번 살피고, 낯선 사람이 따라 들어오지 않도록 문이 닫히는 것을 확인하라고 알려 주세요.
@ 청북읍 도어락 번호 가족 공유 약속

# 번호를 잊었을 때 아이가 할 일 정해 두기
아이가 번호가 기억나지 않아 문 앞에서 기다리게 되는 날이 생깁니다. / 미리 순서를 정해 두면 아이도 당황하지 않습니다.
- 먼저 천천히 한 번 더 눌러 보기 (여러 번 틀리면 잠깐 막힐 수 있음)
- 안 되면 부모님이나 보호자에게 전화하기
- 보호자가 안 받으면 믿을 수 있는 이웃이나 학교 안내에 도움 요청하기
- 낯선 사람이 문을 열어 준다고 해도 따라가지 않기
이 순서를 종이에 적어 가방에 넣어 두는 것도 좋은 방법입니다.
순서를 정한 날 아이와 한 번 소리 내어 읽어 보면 더 잘 기억합니다.

# 번호 오류가 반복될 때 알아둘 것
도어락은 번호를 여러 번 틀리면 한동안 입력을 막는 기능이 있는 제품이 많습니다. / 아이가 계속 눌러서 막혀 버리는 경우가 있어 몇 번 틀리면 멈추라고 알려 주세요.
막혔다면 시간이 지난 뒤 다시 눌러 보면 풀리는 경우가 많습니다. / 그래도 안 되면 배터리나 번호판 상태를 확인해야 합니다.
번호판이 어둡거나 일부 숫자가 눌리지 않는다면 번호가 맞아도 열리지 않습니다.
밤이 이른 계절에는 하교 후 집 앞이 어두워 번호판이 잘 안 보이기도 합니다. / 현관 앞 조명이 켜지는지도 함께 점검해 보세요.
아이가 배터리 경고음을 못 알아듣는 경우도 있습니다. / 부모님이 주기적으로 배터리를 교체하는 날을 정해 두면 가장 확실합니다.

# 보호자가 먼 곳에 있을 때
부모님이 출장 중이거나 일 때문에 바로 오지 못하면 아이가 오래 밖에서 기다리게 됩니다. / 이럴 때는 아이의 안전이 우선입니다.
가능하면 아이를 편한 곳에서 기다리게 하고, 보호자가 전화로 상황을 알려 주세요. / 문을 열어야 하는 경우는 사시는 분 확인이 필요해서 보호자가 직접 연락해 주셔야 합니다.
학생 혼자 요청하면 신분 확인이 어려워 열지 못할 수 있습니다.
아이가 이런 상황에서 가장 먼저 해야 할 일은 밖에서 안전하게 기다리는 것입니다. / 번호를 알아내겠다고 낯선 도움을 받는 것은 하지 않도록 평소에 이야기해 주세요.
한 번 겪고 나면 아이도 다음에는 침착하게 대응합니다. / 야단치기보다 잘 기다렸다고 칭찬해 주는 것이 효과적입니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사는 분인지 확인하는 절차를 꼭 거칩니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
보호자가 직접 연락하셔야 하고 현장에는 아이만 있을 수 있어 사전에 전화로 먼저 확인하는 경우도 있습니다. / 아이가 놀라지 않게 차분히 진행합니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
상태를 본 뒤 작업 전에 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
금액이 궁금하시면 전화로 상황을 설명해 주실 때 함께 물어보셔도 됩니다. / 현장에 도착해서 상태를 확인한 뒤 다시 한 번 정확히 말씀드리고, 그때 결정하셔도 늦지 않습니다. / 급하다는 이유로 설명 없이 작업을 시작하는 일은 없습니다.

# 학생 눈높이에서 도어락 점검하기
아이 키에서 번호판이 잘 보이고 누르기 편한지 한 번 확인해 보세요. / 햇빛이 번호판에 반사되면 숫자를 잘못 누를 수 있습니다.
배터리 부족 경고음이 나면 아이가 무엇을 해야 하는지 알려 주세요. / 소리가 나면 부모님께 바로 알리라고만 정해 둬도 충분합니다.
번호판이 느려지거나 꺼지는 증상은 [도어락 수리](doorlock-repair.html) 쪽에서 점검할 수 있습니다.

# 번호를 바꿔야 하는 때
분명히 번호가 알려졌거나 아이가 번호를 헷갈려 하면 바꾸는 것이 좋습니다. / 학기가 바뀔 때처럼 정해진 시점에 같이 바꾸면 습관이 됩니다.
번호를 바꾸는 방법은 제품마다 달라서 어렵다면 전화로 안내를 받을 수 있습니다. / 새 제품을 고민 중이라면 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html)를 참고하세요.

# 청북읍 말고 평택 어디든 갑니다
청북읍 가까운 포승읍, 안중읍을 포함해 평택 안 다른 동네와 읍면까지 다닙니다. / 지제역, 평택역 쪽에서 부르셔도 됩니다.
다니는 지역은 [평택시 출장열쇠](pyeongtaek.html)에 정리했고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
