# 동삭동에서 인터폰으로 문을 열었는데 반응이 없을 때
동삭동은 평택역이나 지제역으로 오가는 생활권에 아파트와 빌라가 모여 있어, 인터폰이나 월패드로 문을 열어주는 집이 많습니다. / 손님이나 택배를 맞으려고 열림 버튼을 눌렀는데 문이 꿈쩍 않으면 당황스럽습니다.
이 글은 인터폰 열림 버튼으로 문이 안 열릴 때 원인을 구분하는 순서를 적었습니다. / 공동현관이 안 열리는 경우와 우리 집 현관문이 안 열리는 경우를 나눠서 설명합니다.
@ 동삭동 인터폰 열림 버튼과 현관문 도어락

# 어느 문이 안 열리는지부터 구분합니다
인터폰 열림은 공동현관, 세대 현관문, 주차장 출입문처럼 여러 문에 연결될 수 있습니다. / 먼저 어느 문이 안 열리는지 정확히 파악해야 합니다.
공동현관만 안 열린다면 우리 집 문제가 아니라 건물 공용 설비 문제일 가능성이 큽니다. / 그 경우 관리사무소에 문의하는 것이 맞습니다.
세대 현관문만 안 열린다면 인터폰 연결이나 도어락 쪽을 확인해야 합니다.

# 인터폰 쪽에서 확인할 것
인터폰은 사용하는 사이에 서서히 소리가 작아지거나 화면이 흐려지기도 합니다. / 평소와 달라졌다면 열림 기능도 같이 점검받아야 하는 신호일 수 있습니다.
- 인터폰 화면이 켜지고 통화음이 들리는지
- 열림 버튼을 누를 때 안내음이나 확인음이 나는지
- 전원이 꺼져 화면이 어둡지는 않은지
- 다른 세대나 이웃도 같은 증상인지
화면은 켜지는데 열림만 안 된다면 연결선이나 문 쪽 장치 문제일 수 있습니다. / 화면 자체가 꺼져 있다면 인터폰 전원부터 의심해 볼 수 있습니다.
어떤 증상인지 메모해 두면 관리사무소나 저희에게 설명하기 쉽습니다.

# 도어락과 인터폰 열림은 별개로 움직입니다
인터폰 열림 버튼은 전기 신호로 잠금을 푸는 방식이라 도어락 번호판과는 별도로 작동하는 경우가 많습니다. / 그래서 번호판은 멀쩡해도 인터폰 열림만 안 되는 일이 생깁니다.
반대로 인터폰은 되는데 도어락 배터리가 약해 모터가 못 움직이는 경우도 있습니다. / 이럴 때는 번호판 반응이 느리거나 경고음이 들립니다.
번호를 직접 눌러 열리는지 확인하면 원인을 구분하기 쉽습니다.

# 문을 열어줘야 하는 사람이 밖에 있을 때
택배 기사나 방문객이 바깥에 있다면 우선 전화로 사정을 알려 주세요. / 인터폰으로 열어주려 했는데 안 열린다면 직접 나가서 문을 열어 주는 방법이 가장 빠릅니다.
집 안에 있는 사람이 현관문까지 갈 수 있다면 안쪽 손잡이로 직접 열면 됩니다. / 공동현관이라면 관리사무소나 경비실에 문을 열어달라고 부탁할 수도 있습니다.
무리하게 인터폰 버튼을 계속 누르면 장치에 부담만 줍니다.

# 안에 있는 사람이 나올 수 없을 때
어르신이나 아이만 집에 있고 현관문이 안 열린다면 안에서도 열 수 있는지 확인해야 합니다. / 안쪽 손잡이나 잠금 레버를 돌려 걸쇠가 풀리는지 알려 주세요.
보조키나 걸쇠가 걸려 있으면 안쪽에서 먼저 풀어야 합니다. / 문 너머로 계속 말을 걸어 아이가 놀라지 않게 해 주세요.
집 안에 사람이 갇힌 상황이라면 전화할 때 꼭 먼저 말씀해 주세요.
@ 동삭동 현관 안쪽 잠금 레버와 인터폰

# 해서는 안 되는 것들
급할수록 장치를 직접 고쳐 보고 싶어지지만, 공동주택 인터폰은 건물 전체와 연결된 경우가 많습니다. / 한 세대에서 선을 건드리면 다른 세대까지 영향을 줄 수 있어 신중해야 합니다.
- 인터폰 본체를 분해하거나 선을 직접 만지기
- 열림 버튼을 오래 눌러 두고 문을 세게 당기기
- 문틈에 카드나 도구를 밀어 넣기
- 도어락 비밀번호를 연달아 틀리게 입력하기
선을 건드리면 인터폰뿐 아니라 이웃 세대 연결에도 문제가 생길 수 있습니다. / 일이 커지기 전에 멈추고 연락하는 편이 빠릅니다.

# 동삭동에서 전화하실 때 알려주면 좋은 것
아파트와 빌라, 상가가 섞여 있어 건물과 호수를 정확히 알려주셔야 합니다. / 가까운 큰길이나 눈에 띄는 가게도 함께 말씀해 주세요.
- 위치와 호수
- 어느 문이 안 열리는지 (공동현관인지 세대 문인지)
- 번호판이 켜지는지
- 인터폰 화면과 통화음이 정상인지
- 집 안에 사람이나 반려동물이 있는지
도어락과 인터폰 사진을 보내 주시면 챙길 장비를 고르기 쉽습니다.

# 신분 확인, 비용, 그리고 개문 방식
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
공동주택이라 이웃 안전과 직결되는 절차입니다. / 신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁해 두세요.

문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 아니라면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열린 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 먼저 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

인터폰과 연결된 문은 전기 부품이 많아 무리한 방식은 피합니다. / 도어락과 문틀이 상하지 않는 방법부터 시도합니다.
작업 중 교체가 필요해 보이면 손대기 전에 먼저 말씀드립니다.
방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 문이 열린 뒤 점검
문이 열렸다고 바로 끝내지 않고 인터폰 열림을 한 번 더 눌러 정상인지 같이 확인합니다. / 이때 이상이 남아 있으면 이유를 설명드리고 어느 쪽에서 손봐야 하는지 알려드립니다.
문이 열리면 도어락 배터리와 모터 동작을 확인합니다. / 인터폰 쪽 이상이라면 저희가 고칠 수 있는 범위와 관리사무소나 설비 업체에 맡길 범위를 구분해 알려드립니다.
도어락이 원인이면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
고쳐서 쓸 수 있으면 교체를 권하지 않습니다.
@ 동삭동 출장열쇠 도어락 점검 작업

# 인터폰 열림 문제를 줄이는 평소 습관
- 인터폰 화면이 꺼지거나 소리가 작아지면 미루지 말고 관리사무소에 알리기
- 도어락 배터리는 해가 바뀔 때쯤 전부 교체하기
- 번호나 열쇠 같은 따로 열 방법을 항상 준비하기
- 손님이 올 때는 미리 연락해 문 앞에서 맞이하기
인터폰 하나에만 기대지 말고 직접 열 방법을 하나 더 두는 게 안전합니다.

# 동삭동 말고 평택 어디든 갑니다
동삭동 가까이 비전동, 세교동, 서정동과 고덕동, 송탄동도 다닙니다. / 평택 안이면 24시간 출동합니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에, 다른 지역은 [출장 지역](area.html) 지도에 정리해 두었습니다.
