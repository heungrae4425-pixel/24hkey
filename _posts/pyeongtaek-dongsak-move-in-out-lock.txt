# 동삭동 입주 첫날 도어락부터 확인하세요
이사 첫날은 짐 정리에 바빠 도어락을 확인할 겨를이 없습니다. / 하지만 새 집에 들어온 날 도어락을 먼저 점검해 두는 것이 가장 좋습니다.
평택 동삭동처럼 이사가 잦은 동네에서는 이전 사는 분이 쓰던 번호와 카드가 그대로 남아 있는 일이 흔합니다. / 이 글은 [평택 출장열쇠](pyeongtaek.html)가 입주와 퇴거 때 자주 받는 질문을 정리한 것입니다.
@ 동삭동 입주 퇴거 도어락 확인

# 입주할 때 가장 먼저 할 것
이전에 살던 분이 쓰던 번호가 그대로 남아 있을 수 있습니다. / 번호를 아는 사람이 누구인지 알 수 없으니 새 번호로 바꾸는 것이 가장 안전합니다.
- 기존 번호를 전부 지우고 새 번호 등록하기
- 이전 사는 분이 쓰던 카드키나 태그가 남아 있는지 확인하기
- 열쇠를 쓰는 문이라면 받은 열쇠 개수를 세어 보기
- 배터리를 새것으로 바꾸기
이 네 가지만 해도 입주 첫날 마음이 훨씬 놓입니다.
이사 업체 분들이 짐을 옮기는 동안 문을 열어 둔 채로 두다 보면 도어락 설정을 잊기 쉽습니다. / 짐 정리가 끝난 뒤 저녁에라도 문을 닫고 번호를 새로 눌러 열어 보는 시간을 꼭 가지세요.

# 열쇠로 여는 문이라면 열쇠 개수를 확인합니다
계약 때 받은 열쇠가 몇 개인지 확인해 두세요. / 이전 사는 분이 복사해 둔 열쇠가 있을 가능성도 있습니다.
불안하다면 열쇠구멍 부분을 교체하는 방법이 있습니다. / 문 전체를 바꾸지 않고도 이전 열쇠를 쓸 수 없게 할 수 있어 비용 부담이 덜한 편입니다.
교체가 필요한지는 현장에서 문 상태를 보고 말씀드립니다.

# 도어락 번호를 바꾸는 방법
번호 변경 방법은 모델마다 조금씩 다릅니다. / 설명서가 있으면 먼저 읽어 보시고, 없으면 모델명을 알려주세요.
번호를 바꿀 때는 가족이 기억하기 쉬우면서 남이 짐작하기 어려운 번호를 고르세요. / 생일, 전화번호 뒷자리, 연속된 숫자는 피하는 것을 권합니다.
새 번호를 등록한 뒤에는 문을 열고 닫은 상태에서 바깥에서 새 번호로 한 번 열어 보세요. / 안에서만 확인하고 나갔다가 안 열리는 일이 가끔 있습니다.

# 임대인이나 이전 사는 분과 정리할 것
세입자라면 도어락이 임대인 소유인지, 내 비용으로 바꿔도 되는지 확인이 필요합니다. / 계약 내용에 따라 다를 수 있어 임대인과 먼저 이야기하시는 것을 권합니다.
- 번호를 바꿔도 되는지 임대인에게 알리기
- 번호를 바꾼 사실과 필요한 경우 알려 줄 사람 정하기
- 퇴거할 때 원래 상태로 돌려야 하는지 확인하기
법적인 판단이 필요한 부분은 저희가 단정해 드릴 수 없습니다. / 임대인과 직접 확인하시는 것이 정확합니다. / 대화 내용은 나중에 확인할 수 있게 메시지로 남겨 두는 편이 좋습니다.
@ 동삭동 도어락 번호 변경 출장열쇠

# 퇴거할 때 도어락에서 정리할 것
나가는 날에는 열쇠를 돌려주는 것만 생각하기 쉽습니다. / 하지만 내 번호와 카드를 정리하지 않고 나가면 번호가 남아 있게 됩니다.
- 내가 등록했던 번호가 남아 있으면 지우기
- 가족이나 지인에게 만들어 준 카드, 태그 회수하기
- 열쇠를 전부 돌려주고 몇 개를 돌려줬는지 기록해 두기
- 도어락을 내가 바꿨다면 원래대로 돌려야 하는지 확인하기
새로 들어오는 분이 안전하게 쓸 수 있도록 하는 것이 도리입니다.
퇴거 청소를 맡기는 경우에는 청소하는 분께 알려 준 임시 번호가 남아 있지 않은지도 확인하세요. / 이사 당일 이삿짐 업체에 알려 준 번호도 마찬가지로 정리 대상입니다.

# 이사 당일 문이 안 열릴 때
이사하는 날 문이 안 열리면 일정이 크게 틀어집니다. / 짐이 가득한 상태에서는 더 곤란합니다.
번호를 모르거나 이전 사는 분이 번호를 안 알려줬다면 도어락을 초기화하거나 열어야 할 수 있습니다. / 이때는 [현관문 개문](door-open.html)으로 진행하며, 새 번호 등록까지 함께 해 드립니다.
문 앞에 계신 분이 이사하는 세입자나 새 주인이 맞는지 확인하는 절차가 필요합니다. / 계약서나 주소가 나온 서류를 준비해 주세요.
이삿짐 속에 서류가 들어가 있다면 휴대폰에 찍어 둔 계약서 사진도 도움이 됩니다. / 임대인이나 중개하는 분의 확인이 가능하면 그쪽도 함께 알려 주세요.
이사 당일에는 일정이 촉박하니 빨리 연락하실수록 좋습니다. / 도어락을 새로 달거나 초기화해야 하는 상황이면 비용을 먼저 말씀드리고 시작합니다.

# 동삭동 위치를 알릴 때
이사 때는 건물이 새로 지어진 곳도 있고 주소가 낯선 경우가 있습니다. / 눈에 띄는 가게, 큰길과의 위치를 같이 알려주세요.
- 건물 종류와 층, 호수
- 큰길에서 어느 쪽으로 들어오는지
- 도어락 상태(꺼짐, 켜짐, 경고음)
위치를 정확히 받으면 도착 시간을 먼저 말씀드립니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 열거나 번호를 바꾸는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 계약서, 주소가 적힌 우편물, 관리하는 분의 확인 중 하나면 됩니다.
이사 직후라 주소가 아직 바뀌지 않은 경우에는 계약서가 가장 빠른 확인 방법이 됩니다. / 확인이 어려우면 작업을 할 수 없으니 이 점은 양해 부탁드립니다.
@ 동삭동 이사 당일 도어락 개방 출장

# 비용은 작업 전에 말씀드립니다
번호 변경이나 열쇠구멍 교체처럼 간단한 작업도 비용을 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 동삭동 24시 출장열쇠 입주 도어락 점검

# 도어락을 새로 달지 고쳐 쓸지
이사 온 집의 도어락이 오래되었거나 자꾸 오류가 난다면 교체를 고민하게 됩니다. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드립니다.
너무 오래된 제품이거나 부품이 없는 경우에는 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 새로 달 때는 문 두께와 기존 구멍 규격이 맞는지 [도어락 설치](doorlock-install.html) 기준으로 확인합니다.
세입자라면 임대인과 상의한 뒤 진행하시는 것을 권합니다.

# 동삭동 말고 평택 어디든 갑니다
동삭동 바로 옆 비전동, 세교동, 지산동도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에, 서울·경기 다른 지역은 [출장 지역](area.html) 지도에 있습니다.
