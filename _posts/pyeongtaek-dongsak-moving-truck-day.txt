# 이삿짐이 오가는 날, 문이 반쯤 열려 있다면
동삭동에서 지제역 쪽으로 이사 오거나 나가는 날은 현관문이 하루 종일 열렸다 닫혔다 합니다. / 짐을 든 사람들이 드나들다 보면 문이 제대로 닫히지도, 완전히 열려 있지도 않은 어정쩡한 상태가 되기 쉽습니다.
이 글은 이삿짐 나르는 날 현관문이 반쯤 열린 채 움직이지 않거나, 문을 고정해 둔 채 잠겨 버린 상황을 다룹니다. / 도어락이 원인인지 문 자체가 원인인지 구분하는 방법과 [평택 출장열쇠](pyeongtaek.html) 부르는 순서를 정리했습니다.
@ 동삭동 이사 당일 현관문 반쯤 열림

# 문이 반쯤만 열려 움직이지 않는 이유
이삿짐을 나르는 동안 문을 고정하려고 끼워 둔 물건이 문턱이나 경첩 쪽에 낀 경우가 있습니다. / 문 아래에 쐐기, 박스, 벽돌 같은 것을 대 두었다가 짐을 옮기며 위치가 틀어지면 빠지지 않을 수 있습니다.
도어클로저가 문이 닫히는 속도를 잡아 주는 집이라면 중간에 걸린 상태로 멈추기도 합니다. / 문틀이 처졌거나 경첩이 헐거운 집은 더 자주 그렇습니다.
짐이 문에 닿아 문이 휘어지거나 바닥에 끌려서 박히는 일도 있습니다.

# 먼저 문을 가로막는 것이 있는지 살피세요
- 문 아래나 뒤쪽에 낀 쐐기, 박스, 신발, 카펫 끝
- 경첩 쪽에 걸친 이삿짐 끈이나 포장재
- 문과 벽 사이에 낀 가구나 포장 박스
- 바닥 레일이나 몰딩 모서리에 걸린 문 하단
- 도어클로저 팔이 꺾이거나 빠진 흔적
이 중 하나만 걸려도 문은 반쯤 열린 채 멈춥니다. / 힘으로 잡아당기기 전에 조심스럽게 물건부터 치워 주세요.

# 문을 억지로 밀고 당기지 마세요
급한 마음에 문을 발로 차거나 어깨로 밀면 경첩이 휘거나 문틀이 어긋납니다. / 이삿날에는 사람이 많아 한꺼번에 힘을 주는 일이 생깁니다.
한 사람이 문을 잡고, 한 사람이 걸린 곳을 보며 천천히 움직여야 합니다. / 문이 움직이는 방향으로만 조금씩 힘을 줍니다.
문이 어느 방향으로도 움직이지 않으면 거기서 멈추세요. / 억지로 하면 이사 후에 고쳐야 할 곳이 늘어납니다.

# 반쯤 열린 상태로 도어락이 잠겨 버렸다면
문이 완전히 닫히지 않았는데 도어락이 잠금 동작을 하면 걸쇠가 문틀에 걸려 버립니다. / 이때 손잡이가 눌리지도, 돌아가지도 않는 경우가 있습니다.
번호를 눌러도 모터 소리만 나고 열리지 않으면 걸쇠가 문틀 구멍에 맞지 않는 상태일 수 있습니다. / 문을 살짝 안쪽으로 당겼다가 놓은 뒤 다시 눌러 보면 열리기도 합니다.
그래도 안 되면 힘을 주지 말고 연락 주세요.
@ 동삭동 이삿날 도어락 걸쇠 걸림 확인

# 집을 비우는 쪽이면 먼저 확인할 것
이사 나가는 날에는 마지막까지 문을 닫지 않고 드나드는 일이 많습니다. / 다 나온 뒤 문을 닫았더니 잠겨 있고 열쇠가 이미 짐 속에 들어간 경우가 생깁니다.
열쇠와 카드, 비밀번호를 메모해 둔 종이를 이삿짐과 별도로 챙겨 두세요. / 마지막 점검 때 쓸 열쇠를 이삿짐 트럭에 실어 보내지 않는 것이 중요합니다.
집주인이나 다음 입주자에게 넘길 열쇠도 따로 모아 두면 편합니다.

새로 들어오는 쪽이라면 아래도 보세요. / 새 집에 입주하는 날은 이전 사용자의 번호가 남아 있을 수 있습니다. / 짐을 들이기 전에 문 앞에서 새 번호를 등록하는 방법을 먼저 확인하세요.
열쇠를 받았다면 기계식 열쇠로 열리는지, 번호가 맞는지 둘 다 시험해 보세요. / 짐을 다 옮긴 뒤 문제를 발견하면 이삿짐 일꾼이 돌아간 뒤라 곤란합니다.
문을 고정해 둘 때는 쐐기 대신 짐으로 막기보다 정해진 한 사람이 문을 잡는 방식이 안전합니다.

# 이럴 때 출장열쇠를 부르세요
- 문이 반쯤 열린 채 걸려 어느 쪽으로도 움직이지 않을 때
- 도어락이 잠긴 소리가 났는데 문이 다 닫히지 않았을 때
- 열쇠가 짐 속에 들어가 못 찾을 때
- 새 번호가 등록되지 않거나 이전 번호가 남아 있을 때
- 이삿짐 일꾼이 문을 눌러 도어락이 오작동할 때
이사 당일은 시간이 빠듯하니 오래 붙잡고 있지 말고 상황을 알려 주세요.

# 전화할 때 알려 주실 내용
동삭동은 단지와 주택이 섞여 있어 건물 정보를 구체적으로 알려 주시면 도착이 빨라집니다.
- 아파트 이름이 아닌 동 번호와 호수, 근처 큰길
- 이사 나가는 집인지 들어오는 집인지
- 문이 어느 정도 열려 있는지, 무엇이 걸려 있는지
- 도어락 소리와 번호판 상태
- 이삿짐 업체가 대기 중인 시간
문과 도어락 사진을 보내 주시면 가져갈 장비를 정하기 쉽습니다.

# 도착하면 사시는 분인지 확인합니다
이사 당일이라도 문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
막 이사 와서 주소가 정리되지 않았다면 계약 관련 서류를 보여 주세요. / 신분증이 짐 속에 있으면 관리사무소의 세대 확인을 부탁하는 방법도 있습니다.
이삿짐 일꾼의 말만으로는 열 수 없으니 본인이나 가족이 함께 있어 주세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 확인한 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
이삿날 시간이 급해도 비용 이야기를 건너뛰지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 동삭동 이삿짐 일꾼 대기 중 문 개방 작업

# 문과 도어락이 덜 상하게 엽니다
이삿짐으로 이미 문 주변이 긁혔을 수 있어 추가로 상하지 않게 하는 것이 우선입니다. / 먼저 문과 도어락에 손상이 덜 가는 방법부터 차례로 시도합니다.
문이 휘어 걸린 경우에는 도어락만이 아니라 경첩과 문틀 상태도 같이 봅니다. / 자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 이사 마치기 전에 확인하는 마무리
문이 열리면 닫고 잠그는 동작을 몇 번 반복해 걸쇠가 문틀에 정확히 들어가는지 봅니다. / 경첩이 헐거워졌다면 나사를 조이거나 점검이 필요한지 말씀드립니다.
새 입주라면 번호를 새로 등록하고 배터리 상태까지 확인합니다. / 도어락이 이사 중 눌려 고장 났다면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 안 되면 [도어락 교체](doorlock-replace.html)를 안내합니다.
새로 달 계획이라면 [도어락 설치](doorlock-install.html)도 참고하세요.

# 동삭동 이삿날 이렇게 준비하면 덜 곤란합니다
- 열쇠, 카드, 번호 메모를 가방에 따로 챙기기
- 문을 고정할 때 한 사람이 문을 잡거나 도어스토퍼 쓰기
- 이삿짐 옮기기 전에 도어락 배터리 확인
- 마지막에 문을 닫고 잠그는 사람 정해 두기
- 문이 이상하면 일꾼이 힘으로 밀지 않게 알려 두기
이사 당일은 정신이 없으니 사전 확인이 가장 큰 도움이 됩니다.

? 이삿짐 업체 직원이 대신 요청해도 되나요? | 사시는 분이 직접 확인을 받아야 합니다. 본인이나 가족이 함께 계셔 주세요.
? 문을 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.

? 새 집 번호도 바로 바꿔 주시나요? | 네, 새 번호 등록과 배터리 확인까지 해드립니다.
