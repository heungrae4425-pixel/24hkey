# 문이 잠기면 제일 먼저 옆집 얼굴이 떠오릅니다
동삭동에서 평택역이나 지제역 쪽으로 오가다 보면 집에 돌아와 문 앞에서 막히는 날이 있습니다. / 이럴 때 많은 분이 가장 먼저 이웃이나 경비실을 떠올립니다.
이웃에게 도움을 구하는 것은 자연스러운 일이지만 순서와 예의가 있습니다. / 그것을 지키면 서로 불편하지 않고 일도 빨리 풀립니다.
이 글은 동삭동에서 문이 잠겼을 때 누구에게 무엇을 부탁할 수 있는지 정리했습니다. / 이웃의 도움으로 해결되지 않으면 [평택 출장열쇠](pyeongtaek.html)로 이어가는 방법도 적었습니다.
@ 동삭동 문 잠김 이웃 도움 요청

# 도움을 구하기 전에 내 상황부터 정리하기
부탁하기 전에 무엇이 필요한지 스스로 정리해 두면 말이 짧아집니다. / 휴대폰을 쓸 수 있는지, 열쇠가 어디에 있는지, 집 안에 사람이 있는지를 생각해 보세요.
필요한 것이 전화인지, 잠깐 쉴 자리인지, 관리실 연결인지에 따라 부탁이 달라집니다. / 막연히 도와달라는 말보다 구체적으로 말하면 상대도 수월합니다.

# 경비실이나 관리사무소가 있다면 먼저 찾기
단독이나 다가구 주택이라면 관리하는 분이나 집주인에게 먼저 연락해 볼 수 있습니다. / 연락처를 모를 때는 계약서나 문자 기록을 찾아보세요.
공동주택이라면 경비실이나 관리사무소가 가장 먼저 부를 곳입니다. / 입주 확인을 해주고, 필요하면 비상 연락처를 알려주기도 합니다.
- 어느 동, 몇 호인지 정확히 말하기
- 지금 휴대폰이 있는지 없는지 알리기
- 세대 확인을 부탁할 수 있는지 문의하기
- 가까운 열쇠집이나 연락 방법을 아는지 묻기
관리실이 문을 닫은 시간이면 경비실에 요청하는 편이 낫습니다. / 담당자가 바쁘면 잠시 기다리라는 말을 들을 수도 있으니 침착하게 응해 주세요.

# 이웃에게 부탁할 때 쓰는 말
옆집이나 아랫집에 초인종을 누를 때는 시간대를 먼저 살핍니다. / 늦은 밤이나 이른 새벽이면 놀랄 수 있으니 문자나 관리실 경유가 더 좋습니다.
처음 한마디는 사과와 인사로 시작하세요. / "죄송한데 문이 잠겨서요"라는 말이면 충분합니다.
빌리고 싶은 것을 분명히 하세요. / 전화 한 통, 잠시 기다릴 자리, 물 한 잔처럼 작은 부탁이어도 괜찮습니다.
도움을 받았다면 고맙다는 말을 꼭 남기세요. / 다음에 서로 마주쳐도 불편하지 않습니다.

# 부탁하지 말아야 하는 것들
급하다는 이유로 선을 넘는 부탁을 하게 되는 경우가 있습니다. / 상대가 거절하더라도 서운해하지 말고 다른 방법으로 넘어가세요.
이웃에게 열쇠를 대신 열어달라고 하거나 남의 집 베란다로 넘어가 달라는 부탁은 위험합니다. / 추락이나 다툼으로 이어질 수 있으니 하지 마세요.
이웃의 연장을 빌려 문을 열려는 것도 피해야 합니다. / 도어락과 문틀이 상하면 오히려 일이 커집니다.
- 옆집 발코니를 넘나드는 방법
- 남의 사다리나 공구로 문 열기
- 문을 세게 차거나 밀어 부수기
- 모르는 사람에게 열쇠 복사를 부탁하기
안전하게 해결할 길이 따로 있으니 위험한 방법은 접어 두세요. / 몸을 다치거나 이웃과 사이가 틀어지면 문 하나 여는 일보다 훨씬 큰 손해가 됩니다.

# 이웃이 비밀번호를 알고 있다면
가족이 맡겨 둔 번호나 보관 열쇠를 가진 이웃이 있다면 가장 빠릅니다. / 평소에 믿을 만한 이웃에게 비상용으로 맡겨 두신 분들이 있습니다.
이때도 문을 여는 사람은 사시는 분이 직접 확인하고 열도록 합니다. / 이웃은 열어 주고, 집주인은 바로 번호나 열쇠를 정리하는 것이 안전합니다.
@ 동삭동 경비실 관리사무소 세대 확인

# 도움이 안 되면 전문가를 부르는 시점
경비실에서도 방법이 없고 이웃도 열쇠가 없다면 더 끌지 않는 것이 좋습니다. / 시간이 갈수록 몸도 마음도 지칩니다.
전화로 위치와 도어락 상태를 알려주시면 출동 여부를 바로 안내합니다. / 위치를 정확히 말씀해 주시면 도착까지 걸리는 시간을 안내합니다.
전화할 때 알려줄 것은 아래와 같습니다.
- 동과 호수, 건물 입구
- 번호판이 켜지는지, 소리가 나는지
- 도어락 모양
- 안에 아이나 반려동물이 있는지

# 이웃과 같이 기다릴 때 지킬 것
혼자 해결이 안 될 때 이웃의 집에서 잠시 쉬어야 하는 상황도 생깁니다. / 그럴수록 서로 부담이 안 되게 선을 지키는 것이 중요합니다.
이웃이 잠시 자리를 내주었다면 오래 머무르지 않는 것이 예의입니다. / 대략 언제쯤 기사가 오는지 알려드리고 도착하면 바로 나가겠다고 말씀드리세요.
현관 앞에서 기다린다면 복도에서 소리를 크게 내지 않도록 합니다. / 통화도 목소리를 낮춰서 하세요.
짐이 많으면 공용 공간에 오래 두지 않도록 합니다. / 계단이나 엘리베이터 앞을 막지 않게 한쪽으로 모아 두세요.
어린 자녀가 함께 있다면 아이가 이웃집 현관을 두드리거나 뛰지 않도록 곁에서 챙겨 주세요. / 작은 배려가 모여 서로 오래 편한 이웃이 됩니다.

# 출장열쇠 도착 후 이웃에게 알리기
기사가 오면 복도에서 작업이 있을 수 있음을 이웃에게 한마디 알려 두세요. / 큰 소음이 나는 작업은 아니어도 인기척이 있으면 놀랄 수 있습니다.
경비 담당자에게도 방문 사실을 알려 주면 신분 확인이 수월해집니다. / 기사는 사시는 분인지 먼저 확인합니다. 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.

# 비용은 열기 전에 설명드립니다
문 상태와 도어락을 본 뒤 먼저 안내하고, 동의하실 때 시작합니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
열고 난 뒤 말없이 붙는 비용도 없고, 부품을 바꿔야 하면 따로 먼저 여쭙습니다. / 상세한 흐름은 [이용안내](guide.html)에 있습니다.

# 문이 열린 뒤 이웃과 함께 정리하기
문이 열리면 원인을 정리하고 같은 일을 막을 방법을 생각해 둡니다. / 고마운 이웃에게 간단한 인사를 전하면 다음에도 서로 편합니다.
도어락 점검은 [도어락 수리](doorlock-repair.html)로 먼저 보고, 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 설명드립니다. / 현관문 개문 방식은 [현관문 개문](door-open.html)에서 볼 수 있습니다.
@ 동삭동 24시 출장열쇠 도어락 점검

# 평소에 이웃과 해두면 좋은 일
- 비상시 연락할 이웃 한 분과 서로 번호 교환
- 관리사무소 전화번호를 휴대폰에 저장
- 가족 비밀번호를 한 사람 더 알고 있게 하기
- 문이 잠기면 누구에게 연락할지 가족과 약속하기
이런 준비는 큰일이 아니지만, 문 앞에서 큰 힘이 됩니다. / 특히 혼자 사는 분이라면 믿을 만한 연락처 한두 곳은 꼭 정해 두세요.
연락처는 종이에 적어 지갑에 넣어 두면 휴대폰이 꺼진 날에도 쓸 수 있습니다. / 이웃끼리 인사를 나누는 것도 가장 좋은 대비입니다.

# 동삭동 말고 평택 어디든 갑니다
동삭동 인근 비전동, 세교동, 고덕동은 물론 송탄동, 안중읍, 팽성읍, 청북읍까지 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 이웃에게 도움을 청해도 되나요? | 네, 다만 시간대와 말투를 조심하고 위험한 부탁은 피해 주세요.
? 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
