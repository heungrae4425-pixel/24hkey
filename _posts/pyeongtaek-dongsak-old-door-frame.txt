# 번호는 맞는데 문이 꿈쩍도 하지 않을 때
동삭동은 지제역과 평택 시내를 오가기 좋은 곳에 아파트와 주택이 함께 있는 생활권입니다. / 오래 살아온 집일수록 현관문이 오랜 세월의 개폐를 견뎌 온 경우가 많습니다.
번호를 정확히 눌렀고 모터 소리도 나는데 문이 그대로라면 도어락이 아니라 문 자체에 이유가 있을 수 있습니다. / 문이 서서히 처지면서 걸쇠가 문틀 구멍과 어긋나기 때문입니다.
이 글은 오래된 문이 처지거나 문틀과 맞지 않아 안 열릴 때 살펴볼 점과 대처 순서를 정리했습니다. / 도어락 문제로만 생각하고 건전지만 계속 바꾸는 분들께 도움이 되길 바랍니다.
@ 동삭동 오래된 현관문 문틀 처짐 점검

# 문이 처졌는지 확인하는 방법
눈으로 보면 문이 기울어 있다는 느낌이 들지 않을 수도 있습니다. / 아래 세 가지를 확인하면 처짐 여부를 대략 알 수 있습니다.
- 문을 닫았을 때 문 위쪽 틈이 좌우로 다르게 보이는가
- 문 아래쪽이 바닥이나 문턱에 스치는 소리가 나는가
- 걸쇠와 데드볼트가 문틀 구멍 중앙에 닿는가
데드볼트가 문틀 구멍의 위쪽이나 아래쪽 가장자리에 걸려 있는 모양이면 처진 것입니다. / 이런 문은 열 때 힘을 줘야 하거나 아예 안 열리기도 합니다.

# 경첩이 헐거워지는 원인
현관문은 하루에도 여러 번 열리고 닫혀서 부품 하나하나가 같은 방향으로 힘을 받습니다. / 한쪽으로 쏠리기 시작하면 속도가 점점 빨라지는 것이 특징입니다.
경첩은 문 무게를 지탱하는 부품이라 오래 쓰면 나사가 풀리거나 구멍이 넓어집니다. / 문을 세게 닫는 습관이 있으면 더 빨리 헐거워집니다.
위쪽 경첩이 먼저 느슨해지면 문이 아래로 쏠리면서 아래쪽 모서리가 닿습니다. / 아래쪽 경첩이 문제라면 문 위쪽이 문틀에서 벌어집니다.
나사를 다시 조이는 것만으로 좋아지는 경우도 있지만 나사 구멍이 이미 넓어져 있으면 헛돕니다. / 이럴 때는 긴 나사로 바꾸거나 구멍을 메우는 작업이 필요합니다.

# 계절에 따라 문이 달라집니다
문과 문틀은 습기와 온도에 따라 미세하게 부풀거나 줄어듭니다. / 여름 장마철에 문이 뻑뻑해졌다가 건조한 계절에 괜찮아지는 집이 있다면 이런 영향일 수 있습니다.
반대로 겨울에는 문틀 쪽 금속이 수축해 걸쇠 위치가 미세하게 달라지기도 합니다. / 매번 같은 시기에 같은 증상이 나타난다면 계절 변화 때문일 가능성이 높습니다.
이 경우는 문을 억지로 당기기보다 위치를 맞추는 조정으로 풀어야 합니다. / 문틈에 두꺼운 종이를 끼워 보아 여닫을 때 걸리는 곳을 확인해 보세요.

# 집에서 해볼 수 있는 안전한 확인
안쪽에서 문을 살짝 위로 들어 올리는 느낌으로 밀면서 손잡이를 돌려 보세요. / 처진 문은 이 방법으로 걸쇠가 풀리는 일이 있습니다.
경첩 나사가 눈에 보이면 드라이버로 가볍게 조여 봅니다. / 너무 세게 조이면 나사산이 망가질 수 있으니 힘을 아껴 주세요.
- 경첩 나사가 헐거운지 손으로 만져 본다
- 문을 열고 닫아 소리가 나는지 듣는다
- 걸쇠 쪽 문틀 구멍 주변이 긁혔는지 본다
아래 같은 행동은 피해 주세요. / 문을 발로 차거나 어깨로 미는 방법은 처진 문을 더 틀어지게 합니다.
@ 동삭동 경첩 나사 점검 문 처짐

# 문이 이미 안 열릴 때의 대처
이때 가장 하지 말아야 할 일은 번호를 계속 눌러 보는 것입니다. / 입력만 잠기고 원인은 그대로이기 때문입니다.
안에서 잠긴 것이 아니라 걸쇠가 문틀에 물려 있는 상태라면 문틈을 무리하게 벌리지 말아야 합니다. / 도어락을 억지로 분리하려다 문 마감이 찢어지는 경우도 있습니다.
출장을 요청하면 문의 처진 정도와 걸쇠의 위치부터 확인합니다. / 도어락이 이상한 것인지 문이 이상한 것인지 구분해야 열 방법이 정해집니다.
문을 먼저 비파손 방식으로 열 수 있는지 살핍니다. / 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 전화할 때 알려 주면 좋은 것
오래된 문일수록 상황 설명이 구체적일수록 좋습니다. / 아래만 말씀해 주시면 장비를 맞춰 갈 수 있습니다.
- 동삭동 안의 건물 이름과 동, 호수
- 문이 언제부터 뻑뻑했는지, 어느 쪽이 걸리는지
- 번호판 불빛과 모터 소리 여부
- 문 전체 사진과 걸쇠 쪽 문틈 사진
이전에 문을 고친 적이 있는지도 알려 주세요. / 경첩을 교체했거나 문을 다시 달았다면 원인을 짐작하기 쉬워집니다.

# 도착하면 거주자 확인부터
문을 여는 일이므로 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 있는 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁할 수 있습니다. / 확인이 안 되면 작업이 어려운 점 양해 부탁드립니다.
세입자든 소유자든 지금 사는 분이면 가능합니다. / [이용안내](guide.html)에 절차를 정리해 두었습니다.

# 비용은 열기 전에, 못 열면 받지 않습니다
문의 상태를 보고 필요한 작업을 정한 뒤 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고 아니라면 돌아갑니다.
끝내 문을 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용도 없습니다.
경첩 교체나 문틀 보강이 필요한 경우 손대기 전에 꼭 먼저 여쭙니다. / 문 한 짝을 새로 갈아야 하는 경우는 드물고 대부분 조정으로 해결됩니다.

# 열린 뒤에는 처짐을 바로잡습니다
문틀 구멍이 많이 닳았다면 판을 덧대어 걸쇠가 닿는 자리를 보강하는 방법도 있습니다. / 어떤 방식이 맞는지는 문을 보고 말씀드립니다.
문이 열렸다고 끝내지 않고 걸쇠가 문틀 중앙에 닿도록 조정합니다. / 경첩 나사를 다시 조이거나 높낮이를 맞추는 정도로 정리되는 경우가 많습니다.
도어락 쪽에 무리가 갔는지도 확인합니다. / 모터가 헛돌거나 소리가 불안정하면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 낡은 경우에만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
조정 뒤에 문을 여러 번 열고 닫아 보며 걸림이 없는지 같이 확인합니다.
@ 동삭동 출장열쇠 문 조정 후 도어락 확인

# 오래된 문을 오래 쓰는 습관
오래된 집은 문이 낡았다는 이유만으로 바꿀 필요는 없습니다. / 처음 상태에 가깝게 조정해 주면 몇 해 더 편하게 쓰는 경우가 많습니다.
문을 닫을 때 손으로 잡아 천천히 닫는 습관만으로도 경첩 부담이 크게 줄어듭니다. / 아이가 문에 매달리는 일이 있다면 막아 주세요.
문 위쪽에 무거운 물건을 걸어 두지 않는 것이 좋습니다. / 계절이 바뀔 때쯤 문틈 상태를 한 번 눈여겨보세요.
- 계절이 바뀔 때 경첩 나사를 한 번 점검
- 문을 세게 닫지 않기
- 문틈이 한쪽만 좁아지면 미리 상담
작은 변화를 일찍 알아채면 큰 수리 없이 지나갈 수 있습니다.

# 동삭동 말고 평택 전역으로
동삭동 가까운 비전동, 세교동, 지산동, 고덕동, 서정동도 다닙니다. / 평택에서 다니는 동네는 [평택 출장열쇠](pyeongtaek.html)에 있고 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
