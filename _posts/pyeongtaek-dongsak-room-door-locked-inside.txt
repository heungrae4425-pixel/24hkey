# 동삭동에서 방문이 안에서 잠겼을 때
동삭동은 새로 지은 아파트와 빌라가 함께 있는 동네라서 집 구조가 다양합니다. / 현관문이 아니라 방문이나 화장실 문이 잠겨서 연락 주시는 일도 꾸준히 있습니다.
문이 안에서 잠기면 현관처럼 열쇠를 꽂을 곳이 없어서 더 막막합니다. / 이 글은 평택 동삭동에서 방문, 화장실 문이 안 열릴 때 확인할 것을 순서대로 적었습니다.
[평택 출장열쇠](pyeongtaek.html)에 연락하기 전에 안에 누가 있는지부터 확인하세요. / 사람이 있느냐 없느냐에 따라 급한 정도가 달라집니다.
@ 동삭동 방문 화장실 문 잠김 출장열쇠

# 안에 사람이 있다면 먼저 말부터 걸어 주세요
아이나 어르신이 안에서 잠그고 나오지 못하는 경우가 가장 급합니다. / 문 너머로 계속 말을 걸어 안심시키고 잠금 버튼을 다시 돌려 보게 해 주세요.
안에 있는 분이 말을 못 하거나 쓰러진 것 같은 느낌이 든다면 바로 119에 연락하세요. / 저희를 기다리는 것보다 그것이 우선입니다.
전화를 주실 때 안에 누가 있는지, 몇 살쯤인지, 소리는 어떤지 알려 주세요. / 급한 순서대로 출동 계획을 세울 수 있습니다.

# 방문 손잡이 가운데 작은 구멍을 찾아보세요
많은 방문 손잡이는 바깥쪽에 비상 해제용 작은 구멍이나 홈이 있습니다. / 화장실 문은 거의 대부분 이런 구조로 되어 있습니다.
가는 일자 드라이버나 펼친 클립을 구멍에 넣고 살짝 돌리면 잠금이 풀리는 제품이 많습니다. / 힘으로 밀지 말고 걸림이 느껴지는 곳에서 가볍게 돌려 보세요.
이 방법으로 안 되면 손잡이 모양이나 제품이 달라서일 수 있습니다. / 그때는 사진을 찍어 보내 주세요.

# 힘으로 밀거나 부수지 마세요
급한 마음에 문을 어깨로 밀거나 발로 차는 분들이 있습니다. / 그러면 문틀이 갈라지고 경첩이 빠져 수리할 곳이 늘어납니다.
특히 화장실 문은 얇아서 한 번 부서지면 문짝 전체를 바꿔야 할 수 있습니다. / 안전에 문제가 없는 상황이라면 기다리는 편이 낫습니다.
안에 사람이 위험한 상황이라면 이야기가 달라집니다. / 그럴 때는 119를 먼저 부르세요.
@ 평택 동삭동 화장실 문 열기 출장

# 전화로 이렇게 설명해 주세요
문이 어느 방인지, 손잡이 모양이 둥근지 레버식인지 알려 주세요. / 바깥쪽에 비상 구멍이 있는지도 말씀해 주시면 장비를 맞춰 챙깁니다.
사진을 문자로 보내 주시면 훨씬 정확합니다. / 손잡이 정면 한 장, 옆면 한 장이면 충분합니다.
위치는 건물 이름이 아니라 동 이름과 가까운 역으로 알려 주셔도 됩니다. / 동삭동은 지제역 쪽인지 평택역 쪽인지만 말씀해 주세요.

# 방문 개문은 현관보다 단순한 경우가 많습니다
방문 손잡이는 현관 도어락보다 구조가 단순해서 흠집 없이 여는 경우가 많습니다. / 문을 부수는 일은 거의 없습니다.
다만 오래된 손잡이는 내부 부품이 굳어 있어서 시간이 조금 더 걸릴 수 있습니다. / 작업 중에 어떤 상황인지 중간중간 설명드립니다.
[현관문 개문](door-open.html)과 같은 원칙으로 덜 상하는 방법부터 시도합니다. / 안 되면 다른 방법을 말씀드리고 허락을 받습니다.

# 사시는 분인지 먼저 확인합니다
방문이나 화장실 문이어도 사시는 집이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
집 안에서 부르시는 경우도 마찬가지입니다. / 문 안쪽이 아니라 집 안에 들어오는 일이므로 확인이 필요합니다.
번거로우셔도 이웃과 가족 모두를 위한 절차입니다. / 확인이 어려우면 작업을 하지 못합니다.

# 비용은 문 열기 전에 말씀드립니다
문 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
손잡이를 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 난 뒤에는 손잡이부터 점검합니다
문이 열리면 잠금장치가 다시 잘 걸리고 풀리는지 같이 확인합니다. / 같은 일이 반복되지 않게 어디가 원인이었는지 말씀드립니다.
잠금 버튼이 너무 쉽게 눌리거나 안쪽 구조가 헐거우면 부품을 점검해야 합니다. / 필요하면 [도어락 수리](doorlock-repair.html)처럼 손봐 드립니다.
교체가 나은 경우에는 이유를 먼저 설명드립니다. / 필요 없으면 하지 않으셔도 됩니다.

# 아이가 있는 집이라면 미리 해 두면 좋은 것
아이 방이나 화장실 문은 안에서 잠그지 못하는 제품을 고르는 것도 방법입니다. / 이미 달려 있다면 비상 해제 도구를 한곳에 모아 두세요.
도구가 어디 있는지 가족 모두가 알고 있으면 급할 때 큰 도움이 됩니다. / 높은 곳에 두되 아이 손이 닿지 않게 하세요.
아이에게 "문을 잠그면 엄마가 열 수 있다"는 것을 미리 알려 두면 겁먹는 일이 줄어듭니다. / 놀이처럼 연습해 보는 집도 있습니다.
@ 동삭동 24시 방문 개문 출장열쇠

# 화장실 문이 잠기는 흔한 상황
샤워 중 손잡이 잠금 버튼을 누르고 나왔다가 문이 닫혀 버리는 경우가 있습니다. / 안에는 가족이 없고 물건만 있어도 열어야 할 때가 많습니다.
습기가 많은 곳이라 잠금장치가 뻑뻑해지기도 합니다. / 가끔 마른 천으로 닦아 주면 오래 갑니다.
화장실 문은 안쪽에서만 잠기는 구조가 많아 비상 해제 구멍을 확인해 두면 편합니다. / 이사 오신 날 한번 살펴 두세요.

# 동삭동 말고 평택 어디든 갑니다
동삭동 옆 세교동, 지산동, 고덕동도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
평택에서 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
방문이나 화장실 문처럼 작은 일도 마다하지 않습니다. / 혼자 해결하려고 오래 붙잡고 있지 마시고 전화 주세요.
