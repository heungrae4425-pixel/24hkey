# 고덕동 집 거래, 열쇠부터 정리하고 시작하세요
고덕동에서 집을 내놓거나 새로 구하는 분들은 지제역이나 평택역 쪽 생활권을 오가며 집을 보러 다니는 경우가 많습니다. / 그러다 보면 중개인이 집을 보여 주려고 현관 열쇠나 비밀번호를 받아 가는 일이 생깁니다.
편하긴 하지만 열쇠를 누구 손에 맡겼는지 잊어버리면 나중에 곤란해질 수 있습니다. / 이 글은 중개인에게 열쇠를 맡길 때 미리 확인할 것과, 문이 안 열릴 때 [평택 출장열쇠](pyeongtaek.html)를 부르는 순서를 적었습니다.
@ 고덕동 집 거래 전 현관 열쇠 맡기기 확인

# 맡기기 전에 열쇠가 몇 개인지부터 세어 보세요
현관문 열쇠는 보통 도어락 카드나 보조키 열쇠까지 합쳐 여러 개입니다. / 집 주인도 정확히 몇 개가 있는지 모르는 경우가 의외로 많습니다.
거래가 끝나고 나서 "그때 하나가 어디 갔지" 하고 찾게 되면 곤란합니다. / 맡기기 전에 가진 열쇠를 전부 꺼내 놓고 종류별로 개수를 적어 두세요.
- 보조키 열쇠 몇 개인지
- 도어락 카드나 태그가 있는지
- 우편함, 공동 현관, 창고 열쇠가 따로 있는지

열쇠 구멍에 꽂는 열쇠뿐 아니라 도어락 카드도 같이 세어야 합니다. / 카드는 작아서 서랍 어딘가에 들어가 있는 경우가 많으니, 맡기기 전에 한 번 꺼내 놓고 확인하세요.
복사한 열쇠를 중개사무소에 두고 오래 잊는 일도 흔합니다. / 맡긴 날짜를 휴대폰 일정에 적어 두면 돌려받을 때가 되었을 때 알림이 옵니다.
# 맡기는 사람과 받는 사람 이름을 적어 두기
말로만 "맡겼다"고 하면 시간이 지나 기억이 서로 달라집니다. / 문자 한 통이라도 날짜와 받는 분 이름, 맡긴 물건을 남겨 두면 나중에 확인하기 쉽습니다.
중개사무소 직원이 바뀌었거나 다른 분이 가져가는 일도 있으니, 누가 들고 있는지 알아 두는 것이 중요합니다. / 돌려받을 날짜도 같이 정해 두면 흐지부지되지 않습니다.

# 가능하면 열쇠보다 임시 비밀번호를 쓰세요
열쇠는 복사해 가도 알 수 없지만, 도어락 비밀번호는 바꾸면 그만입니다. / 도어락이 있는 집이라면 집을 보여 주는 동안만 쓸 임시 번호를 따로 만들어 두는 방법이 있습니다.
기종에 따라 임시 번호나 손님용 번호를 등록하는 기능이 있습니다. / 설명서를 보거나 모르겠으면 [도어락 수리](doorlock-repair.html) 쪽으로 문의하면 설정을 같이 봐 드립니다.
거래가 끝난 뒤에는 임시 번호를 지우는 것까지 해야 한 번에 정리가 됩니다.

# 집 안에 두고 가는 것은 따로 정리해 두세요
집을 보여 주는 동안 중개인이 혼자 드나드는 일이 생길 수 있습니다. / 귀중품, 통장, 현금처럼 꼭 챙겨야 할 물건은 미리 치워 두는 편이 마음이 편합니다.
중개인을 의심하라는 이야기가 아니라, 누구나 실수할 수 있으니 처음부터 정리해 두자는 뜻입니다. / 집이 비어 있는 시간대에는 창문과 베란다 잠금도 같이 확인해 두세요.
@ 중개인 방문 전 집 안 정리와 도어락 번호 확인

집을 보러 오는 사람이 많아지는 시기에는 하루에 몇 번씩 문이 열리고 닫힙니다. / 그만큼 도어락 배터리도 빨리 닳으니, 거래 기간에는 배터리를 미리 새것으로 바꿔 두는 것이 안전합니다.
집을 보여 주는 도중에 번호판이 꺼지면 보러 온 분 앞에서 난처해질 수 있습니다. / 비상용 9V 건전지를 현관 밖에서 쓸 수 있게 챙겨 두세요.
# 거래가 끝나면 번호와 열쇠를 어떻게 하나
거래가 끝나고 집을 넘기는 경우에는 도어락 번호와 열쇠를 새로 정리하는 것이 기본입니다. / 이전 사용자가 쓰던 번호가 남아 있으면 새로 들어오는 분이 불안해할 수 있습니다.
집을 사거나 임차한 분 입장에서도 이전에 중개인과 이전 거주자가 열쇠를 가졌을 수 있다는 점은 생각해 둘 만합니다. / 입주 전에 번호를 새로 등록하고 카드를 다시 맞추는 것을 권합니다.

# 입주하는 분이라면 이렇게 확인하세요
- 도어락 초기화 후 새 비밀번호 등록
- 보조키 열쇠 개수와 작동 확인
- 카드나 태그를 쓰는 기종은 새로 등록
- 우편함과 공동 현관 열쇠 인수 확인
집 안에 이전에 쓰던 보조키 열쇠가 남아 있다면 다른 곳에 사용되던 것인지도 확인해 보세요. / 모양이 비슷한데 맞지 않는 열쇠는 따로 챙겨 두면 헷갈리지 않습니다.

# 열쇠를 맡겼는데 문이 안 열릴 때
중개인이 집을 보러 갔다가 문이 안 열린다고 연락이 오는 일도 있습니다. / 이럴 때는 주인이 직접 문 앞에 가기 어려운 경우가 많습니다.
번호판이 꺼졌는지, 소리는 나는지, 보조키가 잠겨 있는지부터 전화로 확인해 보세요. / 배터리 문제라면 바깥 아래쪽 비상 단자에 9V 건전지를 대는 방법이 있습니다.
그래도 안 되면 억지로 힘을 쓰지 말고 연락 주세요. / 열쇠를 돌리다 부러지면 일이 더 커지니 무리하지 않는 것이 좋습니다.

# 고덕동 위치를 알려줄 때 필요한 정보
고덕동은 새로 생긴 주거지가 여럿 이어져 있어 위치를 정확히 알려 주는 것이 도움이 됩니다. / 아파트나 건물 이름 대신 동, 호수와 지금 상황을 말씀해 주시면 됩니다.
- 대략 어느 방향인지 (지제역 쪽인지, 평택역 쪽인지)
- 도어락 모양과 번호판 상태
- 집 안에 사람이나 반려동물이 있는지
- 지금 현장에 계신 분이 집 주인인지 중개인인지
@ 고덕동 출장 전 위치와 도어락 상태 전달

# 집 주인이 없을 때는 누가 신분을 확인하나
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
중개인이 대신 부른 경우라도 집 주인이 누군지 확인이 필요합니다. / 주인에게 전화로 허락을 받거나, 확인할 수 있는 서류를 준비해 주시면 진행이 빠릅니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 난 뒤 번호부터 바꿔 두세요
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 비밀번호를 새로 정하는 것까지 도와드리고, 기존 번호는 지웁니다.
중개인에게 맡겼던 번호가 남아 있다면 이참에 정리해 두면 마음이 편합니다. / 고장이 잦거나 너무 오래된 도어락이라면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

- 열쇠 개수를 한 번 적어 두고 가끔 확인
- 맡길 때는 날짜와 받는 사람 기록
- 임시 번호는 용도가 끝나면 바로 삭제
- 배터리는 해가 바뀔 때쯤 한 번에 교체
작은 기록 하나가 나중에 큰 불편을 막아 줍니다. / 거래가 있는 시기에는 특히 한 번 더 확인하는 습관이 도움이 됩니다.

# 고덕동 말고 평택 어디든 갑니다
고덕동 옆 서정동, 지산동, 송탄동을 비롯해 평택 안이면 동네 상관없이 다닙니다. / 읍 지역인 안중, 포승, 팽성, 청북도 갑니다.
평택에서 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 중개인에게 열쇠를 맡겨도 되나요? | 맡기는 것 자체는 흔한 일입니다. 개수와 받는 사람, 돌려받을 날짜만 적어 두세요.
? 열쇠 말고 임시 비밀번호로 해도 되나요? | 도어락 기종에 따라 가능합니다. 끝나면 번호를 지우는 것까지 하세요.
? 중개인이 부른 경우도 신분 확인을 하나요? | 네, 집 주인이 맞는지 확인 후 진행합니다. 신분증이나 우편물을 준비해 주세요.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
