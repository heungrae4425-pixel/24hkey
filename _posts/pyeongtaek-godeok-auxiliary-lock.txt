# 고덕동에서 번호는 맞는데 문이 안 열릴 때
고덕동은 새로 개발된 신도시 아파트가 모여 있는 동네입니다. / 번호는 분명히 맞는데 문이 꿈쩍도 안 하는 경우가 있는데, 보조키가 잠겨 있을 때 자주 생기는 일입니다.
보조키는 도어락 위쪽에 따로 달린 안전 잠금장치입니다. / 한 번 돌려 두면 도어락 번호가 맞아도 문이 열리지 않습니다.
이 글은 고덕동에서 보조키 때문에 막혔을 때 확인할 것과 [평택 출장열쇠](pyeongtaek.html)를 부르는 순서를 정리했습니다.
@ 고덕동 보조키 잠김 출장열쇠

# 보조키가 하는 일
보조키는 도어락과 별개로 문을 한 번 더 잠그는 장치입니다. / 밖에서는 열쇠로, 안에서는 손잡이를 돌려 잠글 수 있습니다.
외출하며 보조키를 잠그고 나온 걸 잊었거나, 안에서 아이가 돌려 둔 경우에 문제가 생깁니다.
- 열쇠로 밖에서 잠그고 나온 경우
- 안쪽에서 손으로 돌려 잠긴 경우
- 걸쇠가 문틀에 걸려 안 빠지는 경우

# 먼저 확인해 볼 것
도어락 위쪽에 열쇠 구멍이 하나 더 있는지 보세요. / 이게 보조키 열쇠 구멍입니다.
열쇠가 있다면 돌려서 풀어 보세요. / 열쇠를 안 가지고 나왔다면 다른 방법이 필요합니다.
도어락 번호를 눌렀을 때 모터 소리가 나는데 안 열린다면 보조키나 걸쇠 쪽을 의심해 볼 수 있습니다.

# 걸쇠가 문틀에 걸린 경우
문이 오래 쓰이다 보면 미세하게 틀어져 걸쇠가 문틀에 걸립니다. / 고덕동처럼 비교적 새 건물이라도 겨울과 여름에 문이 조금씩 틀어지기도 합니다.
이럴 때는 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 걸쇠가 풀리며 열릴 때가 있습니다.
세게 당기면 오히려 더 꽉 물리니 힘을 빼고 해 보세요.
@ 평택 현관문 걸쇠 걸림 문 열기

# 안에서 아이가 잠근 경우
집 안에서 아이가 보조키를 돌려 잠그는 일이 있습니다. / 바깥에서 번호를 눌러도 열리지 않아 당황스럽습니다.
이때 아이가 놀라지 않게 문 너머로 계속 말을 걸어 주세요. / 아이가 직접 풀 수 있다면 방법을 천천히 알려 주셔도 됩니다.
어려우면 바로 전화해서 상황을 먼저 말씀해 주세요.

# 하지 말아야 할 행동
급하다고 문을 세게 당기거나 발로 차지 마세요. / 걸쇠와 문틀이 상하면 원인이 하나 더 늘어납니다.
카드나 드라이버로 문틈을 벌리는 것도 피하세요. / 도어락 외관과 문틀이 상해 교체 비용이 더 들 수 있습니다.
비밀번호를 계속 반복해서 누르는 것도 좋지 않습니다. / 일정 횟수가 지나면 도어락이 잠시 입력을 막기도 합니다.

# 전화 주실 때 알려주실 것
상황이 간단히 전달되면 출동 준비가 빨라집니다. / 아래 정도면 충분합니다.
- 동 이름과 호수, 대략적인 위치
- 번호는 맞는데 소리는 나는지 여부
- 보조키 열쇠를 가지고 있는지
- 집 안에 아이나 반려동물이 있는지
도어락과 보조키 사진을 문자로 보내 주시면 더 좋습니다.

# 도착하면 신분을 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 이웃과 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 문을 상하지 않게 엽니다
보조키가 잠겨 있어도 문을 상하지 않게 여는 방법부터 시도합니다. / 상황에 따라 걸리는 시간은 다릅니다.
어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.
@ 고덕동 출장열쇠 보조키 개문

# 비용은 열기 전에 말씀드립니다
도착해서 문과 보조키 상태를 보고 어떻게 얼마가 드는지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니라면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 열린 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 열고 나서 점검할 것
문이 열리면 보조키와 걸쇠가 부드럽게 움직이는지 같이 봅니다. / 뻑뻑하다면 문틀과 걸쇠 위치도 확인합니다.
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 말씀드립니다. / 너무 오래돼 손보기 어려우면 [도어락 교체](doorlock-replace.html)를 권해 드립니다.

# 보조키 때문에 다시 막히지 않으려면
습관 하나만 바꿔도 같은 일이 줄어듭니다. / 아래 방법을 참고해 보세요.
- 외출할 때 보조키 열쇠를 꼭 챙기기
- 아이가 있는 집은 안쪽 보조키 잠금을 가르치거나 위치 높이기
- 문이 덜 닫히면 미루지 말고 점검하기
- 여분 열쇠를 믿을 만한 곳에 맡기기

# 평택 어디든 갑니다
고덕동 가까운 비전동, 세교동, 동삭동, 서정동, 송탄동까지 평택 전역을 다닙니다. / 안중읍, 포승읍, 팽성읍, 청북읍도 출동합니다.
다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.

# 보조키 열쇠를 복사해 두면 좋은 이유
보조키 열쇠는 하나만 갖고 다니다 잃어버리면 곤란합니다. / 믿을 만한 가족이나 이웃에게 하나 더 맡겨 두면 큰 도움이 됩니다.
복사할 때는 열쇠 모양이 닳지 않은 원본으로 하세요. / 닳은 열쇠로 복사하면 잘 돌아가지 않을 수 있습니다.
열쇠가 하나도 없는 상황이라면 잠금장치 자체를 새로 맞추는 방법도 있어 상담해 드립니다.

? 걸쇠가 걸렸을 땐 어떻게 하나요? | 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. 안 되면 전화 주세요.

? 신분증이 집 안에 있어요. | 관리사무소 확인이나 주소가 적힌 우편물로 대신할 수 있습니다.
