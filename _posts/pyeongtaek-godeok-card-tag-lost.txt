# 지갑에 있던 카드키가 사라진 날
고덕동은 평택에서도 비교적 새로 조성된 주거 지역이라 카드키나 태그로 여는 도어락을 쓰는 집이 많습니다. / 열쇠를 들고 다니지 않고 카드 한 장으로 출입하는 생활에 익숙해진 분들이 많습니다.
그러다 카드를 어디에 두었는지 모르게 되면 문 앞에서 한참 가방을 뒤지게 됩니다. / 번호판이 있는 제품이라면 번호로 열면 되지만, 번호 없이 카드만 쓰는 제품이면 문 앞에서 막힙니다.
이 글은 카드키와 태그, 리모컨 같은 출입 수단을 잃어버렸을 때의 순서를 정리했습니다. / 지금 문 앞에서 찾고 계시다면 두 번째 소제목부터 보세요.

# 카드는 몇 번 더 찾아 보세요
분실이라고 생각했지만 의외의 곳에서 나오는 경우가 많습니다. / 외투 안주머니, 가방 바깥 주머니, 차량 수납함, 어제 입은 옷 주머니를 먼저 보세요.
- 마지막으로 카드를 쓴 장소와 시간
- 어제 입은 옷과 어제 가져간 가방
- 차 안 컵홀더와 문 수납함
- 카페나 식당 등 결제하며 꺼냈을 만한 곳
카드가 밖에서 분실됐다면 누군가 주울 수 있다는 점도 생각해야 합니다. / 이 집에 맞는 카드인지는 주운 사람이 알기 어렵지만 안심하긴 이릅니다.
@ 고덕동 카드키 태그 분실 도어락 확인

# 번호나 지문으로 열 수 있는지 먼저
카드를 못 찾았다고 바로 전화하기보다 열 수 있는 다른 방법이 남아 있는지 보는 것이 순서입니다. / 의외로 번호를 잊고 있었던 것이 아니라 카드 습관에 익숙해져 번호 입력을 안 했을 뿐인 경우가 있습니다.
카드키만 쓰는 도어락도 있지만 대부분 번호 키패드나 지문이 함께 있습니다. / 카드가 없을 때를 대비해 번호를 따로 정해 두는 제품이 많습니다.
번호가 기억나지 않으면 가족에게 물어보세요. / 가족이 번호를 바꿨는지 모르고 이전 번호를 누르면 입력이 잠기기도 합니다.
번호를 모르는데 카드도 없으면 이때가 출장열쇠를 부르는 시점입니다. / 문을 연 뒤 새 카드와 번호를 등록하면 됩니다.

# 분실 카드는 반드시 무효화해야 하는 이유
문을 연 다음 가장 먼저 할 일은 잃어버린 카드를 쓸 수 없게 하는 것입니다. / 도어락은 등록 방식이 제품마다 달라서 한 번 초기화하거나 등록된 카드를 지우는 과정을 거칩니다.
카드를 지우지 않은 채 새 카드만 더하면 잃어버린 카드도 계속 열릴 수 있습니다. / 이것이 카드 분실에서 가장 흔한 놓침입니다.
등록 카드 목록을 지우고 남아 있는 카드를 다시 등록하는 방식이 일반적입니다. / 그러면 가족 카드도 다시 등록해야 하니 한자리에 모아 두세요.

# 카드 종류별로 다르게 대처합니다
카드, 스티커 태그, 팔찌, 리모컨은 모양은 달라도 도어락과 약속된 신호를 주고받는다는 점은 같습니다. / 다만 재등록 방법과 다시 사야 하는지는 제품마다 다릅니다.
- 카드형: 가장 흔하고 새 카드를 등록해 쓸 수 있음
- 스티커 태그: 휴대폰 뒷면이나 열쇠고리에 붙여 쓰는 것
- 리모컨형: 건전지가 들어가 있어 배터리 문제와 분실 문제가 섞임
- 팔찌 키: 물에 강한 대신 분실 시 확인이 필요함
같은 규격의 카드가 시중에 있는지는 도어락 모델에 따라 다릅니다. / 모델명이 보이면 사진으로 보내 주세요.

# 카드가 없어서 문 앞에 서 있을 때 하면 안 되는 것
급한 마음에 문손잡이를 세게 흔들거나 문틈에 도구를 넣는 일은 피해 주세요. / 신도시 아파트의 문은 문틀이 정교해서 작은 틈에도 흠이 남기 쉽습니다.
창문을 통해 들어가려는 시도는 위험합니다. / 특히 고층에서는 절대 하지 마세요.
이웃에게 열쇠를 빌리는 것은 가능하지만 도어락 구조가 다르면 소용이 없을 수 있습니다.
@ 평택 고덕동 출장열쇠 카드키 재등록

# 전화할 때 알려 주실 내용
카드를 잃어버렸다는 것 외에도 알려 주면 좋은 정보가 있습니다. / 아래만 말씀해 주시면 장비를 맞춰 출발할 수 있습니다.
- 도어락 제품 모양과 번호판 유무
- 카드, 태그, 리모컨 중 어떤 것을 잃었는지
- 가족이 가진 카드가 남아 있는지
- 번호를 아는지, 지문 등록이 있는지
도어락 사진은 문자로 보내 주세요. / 고덕동 안의 건물 이름과 호수, 가까운 기준점을 같이 알려 주세요.

# 도착 후 거주자 확인
카드 분실은 누가 주운 카드로 들어가려는 것이 아닌지와 구분하기 어렵습니다. / 그래서 현장 확인은 선택이 아니라 기본입니다.
작업 전에 사시는 분임을 확인합니다. / 신분증 주소, 주소가 보이는 우편물, 관리사무소 확인 중 하나면 됩니다.
지금 사는 분이면 세입자든 소유자든 상관없습니다. / 신분증이 집 안에 있다면 관리사무소에서 세대 확인을 받을 수 있습니다.
확인이 어려울 땐 작업을 못 하는 점 양해 부탁드립니다. / 자세한 내용은 [이용안내](guide.html)에서 보실 수 있습니다.

# 비용은 열기 전에, 못 열면 없습니다
카드키형 도어락은 종류가 다양해서 현장에서 보고 먼저 비용을 말씀드립니다. / 괜찮으시면 시작하고, 아니라면 그냥 돌아갑니다.
문을 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 늘어나는 비용도 없습니다.
카드를 새로 구해야 한다면 필요한 규격을 알려드리고 따로 여쭙니다. / [도어락 설치](doorlock-install.html) 때 확인했던 카드 규격을 그대로 쓸 수 있는지도 같이 봅니다.

# 재등록이 끝나면 확인할 것
문이 열렸다고 곧바로 끝내지 말고 5분만 같이 확인해 드립니다. / 안쪽 손잡이로 열리는지, 자동으로 잠기는지, 배터리 상태가 어떤지를 하나씩 봅니다.
새 카드를 등록한 뒤 열림과 잠김을 번갈아 몇 번 해보세요. / 카드가 닿는 위치가 제품마다 다르니 한 번 익혀 두면 좋습니다.
남은 카드를 모두 등록했는지, 번호도 같이 바꿨는지 확인합니다. / 번호를 새로 정했다면 가족에게 알려 주세요.
카드를 분실한 일이 반복된다면 [도어락 교체](doorlock-replace.html)로 번호와 지문이 있는 제품을 고르는 방법도 있습니다.
@ 고덕동 도어락 카드 재등록 가족 카드 정리

# 카드를 덜 잃어버리게 하는 습관
카드는 작아서 잃어버리기 쉽습니다. / 눈에 띄는 색의 고리나 케이스를 쓰면 가방 속에서도 금방 찾을 수 있습니다.
카드를 열쇠고리에 달아 가방 안쪽 고리에 걸어 두면 분실이 크게 줄어듭니다. / 휴대폰 케이스에 카드를 넣고 다니는 분은 휴대폰 분실과 함께 잃지 않게 주의하세요.
여분 카드 하나는 집 밖의 믿을 수 있는 곳에 맡겨 두세요. / 가족 중 한 명이 보관하는 방식도 괜찮습니다.
카드가 몇 장 있는지 달력에 적어 두면 한 장이 없어졌을 때 알아채기 쉽습니다.

# 고덕동 밖 평택 전역
고덕동 옆 서정동, 지제역 주변, 안중읍, 팽성읍, 청북읍, 포승읍도 다닙니다. / 평택 안이면 동네와 상관없이 24시간 출동합니다.
다니는 동네는 [평택 출장열쇠](pyeongtaek.html)에서 확인하실 수 있고 다른 지역은 [출장 지역](area.html)에 있습니다.

카드를 잃어버렸다는 사실만으로 큰 문제가 되는 것은 아닙니다. / 등록을 정리하면 이전 카드는 쓸 수 없고 새 카드로 다시 시작하면 됩니다.
고덕동에서 카드키나 태그를 잃어버렸다면 문을 연 뒤 등록을 정리하는 것까지 한 번에 생각해 주세요. / 상황만 알려 주시면 순서를 안내해 드립니다.
