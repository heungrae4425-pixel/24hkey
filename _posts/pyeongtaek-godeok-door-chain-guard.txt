# 고덕동 현관에 도어체인을 다는 이유
평택 고덕동은 비교적 새로 조성된 주거지가 많아 지제역이나 평택역 방향으로 오가는 가족 단위 세대가 많습니다. / 아이가 있는 집에서는 도어락과 별개로 도어체인이나 도어가드를 하나 더 거는 일이 흔합니다.
도어체인은 문이 일정 폭까지만 열리게 잡아 주는 보조 장치입니다. / 택배나 방문자를 확인할 때, 혹은 밤에 문을 살짝 열어 볼 때 쓰입니다.
다만 체인이 풀리지 않거나 걸린 채 닫히는 일이 의외로 자주 생깁니다. / 이 글은 고덕동에서 도어체인과 도어가드를 달 때 볼 것과, 풀리지 않을 때의 대처법을 정리했습니다. 도어락 문제가 함께 있으면 [평택 출장열쇠](pyeongtaek.html)에 연락해 주세요.
@ 고덕동 현관문 도어체인 도어가드 설치

# 도어체인과 도어가드는 어떻게 다를까
이름은 비슷하지만 구조가 다릅니다. / 어떤 것이 달려 있는지 알아야 풀 때도 헷갈리지 않습니다.
- 도어체인은 가는 쇠사슬을 홈에 끼워 거는 방식
- 도어가드는 짧은 막대가 문틀 쪽 걸이에 걸리는 방식
- 둘 다 문을 약간만 열었을 때 더 이상 열리지 않도록 잡아 줍니다
체인은 길이가 짧고 홈이 작아 힘을 주면 쉽게 걸립니다. / 가드는 튼튼하지만 각도가 안 맞으면 걸림쇠가 풀리지 않을 수 있습니다.

# 설치 전에 문과 문틀부터 확인하세요
문이 안쪽으로 열리는지 바깥으로 열리는지에 따라 체인이 달리는 쪽이 다릅니다. / 방화문처럼 금속 문틀이 두꺼운 문은 나사가 잘 안 박히는 경우도 있습니다.
- 문 두께와 문틀 폭 측정
- 문틀에 나사 박을 자리가 충분한지
- 도어락 손잡이와 체인이 서로 부딪치지 않는지
- 문 열림 각도를 얼마나 허용할지
나사 길이와 위치를 잘못 잡으면 몇 번 쓰지 못하고 헐거워집니다. / 설치 전 확인 방법은 [도어락 설치](doorlock-install.html) 페이지의 확인 항목과 비슷합니다.

# 직접 달 때 자주 하는 실수
셀프로 다는 분들이 가장 많이 놓치는 것은 위치 높이입니다. / 너무 낮게 달면 아이가 쉽게 풀 수 있고, 너무 높으면 어른도 손이 닿기 불편합니다.
- 문틀 쪽 걸이와 문 쪽 레일을 일직선으로 맞추지 않음
- 나사를 너무 세게 조여 문틀이 갈라짐
- 도어클로저가 달려 있는데 체인 길이를 안 맞춤
- 문틈 폭을 고려하지 않아 체인이 닫을 때 끼임
레일 위치가 비껴가면 체인이 매끄럽게 미끄러지지 않고 중간에서 걸립니다. / 처음 달 때 몇 번 걸었다 풀었다 해 보며 부드러운지 확인하세요.

# 체인이 안 풀리는 가장 흔한 이유
체인이 걸린 상태에서 문을 닫았다 열면 체인이 꼬이거나 홈 안에서 한쪽으로 쏠립니다. / 이럴 때 억지로 당기면 체인이 더 단단히 조여집니다.
먼저 문을 살짝 닫아 체인에 여유를 만들어 보세요. / 그다음 체인 끝 구슬을 홈의 넓은 쪽으로 밀어 빼면 풀리는 경우가 많습니다.
문틈이 좁아 손이 안 들어가면 얇은 젓가락 같은 막대로 체인 구슬을 밀어 올려 볼 수 있습니다. / 칼날이나 철사처럼 날카로운 것은 문과 체인이 상하니 피해 주세요.
@ 고덕동 도어체인 걸림 풀기 문틈

# 도어가드가 걸려서 안 열릴 때
막대형 가드는 걸림쇠가 비스듬히 박혀 있을 때 풀리지 않습니다. / 문을 안쪽으로 한 번 꾹 닫았다가 천천히 열면서 막대를 위로 들어 올려 보세요.
세게 흔들면 가드의 고정 나사가 헐거워져 문틀에서 빠집니다. / 한 번에 풀리지 않으면 힘을 빼고 각도를 조금씩 바꿔 가며 시도해 보세요.
문을 열어 두고 나사를 점검하는 중이라면 완전히 닫지 말고 작업하는 것이 안전합니다. / 도어락이 한쪽에서 잠기면 문 밖에서 열기 어렵습니다.

# 밖에서 체인이 걸려 못 들어올 때
가장 곤란한 경우는 집 안에서 누군가 체인을 걸어 둔 채로 잠이 들었거나 외출한 경우입니다. / 도어락 번호가 맞아서 걸쇠가 풀려도 체인이 걸려 문이 조금만 열립니다.
안에 가족이 있다면 먼저 전화로 깨우거나 문을 두드려 체인을 풀어 달라고 요청하세요. / 전화가 안 되면 이웃과 관리사무소에 상황을 알려 두는 것이 좋습니다.
혼자 사는 어르신이나 아이가 안에 있는 상황이라면 지체하지 말고 연락하세요. / [현관문 개문](door-open.html)은 이런 때 문과 체인이 상하지 않는 방식으로 진행합니다.

# 하지 말아야 할 것
문을 어깨로 밀거나 발로 차서 체인을 끊으려는 분들이 있습니다. / 체인 고정 나사가 문틀과 함께 뜯겨 나가면 수리 범위가 훨씬 커집니다.
- 문틈에 공구를 넣어 체인을 억지로 비틀기
- 체인이 걸린 상태에서 도어락 번호를 계속 누르기
- 문을 열고 체인을 반복해서 거는 연습을 지나치게 하기
- 비 오는 날 젖은 손으로 체인을 만지다 전기 도어락에 물이 들어가게 하기
체인은 작은 부품이지만 문틀에 직접 박혀 있어서 손상되면 문틀 보수가 필요할 수 있습니다.

# 전화하기 전에 알려주실 것
체인과 도어락이 함께 얽힌 상황이면 아래 내용을 알려주시면 좋습니다.
- 고덕동 안에서 건물 위치와 동, 호수
- 체인이 걸린 쪽이 안인지 밖인지
- 도어락 번호판이 켜지는지 소리가 나는지
- 문이 얼마나 열리는지
체인 모양과 문틈 사진을 문자로 보내시면 맞는 도구를 챙겨 갈 수 있습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있으면 관리사무소에 세대 확인을 부탁해 주세요. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 체인 위치를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 체인이나 가드를 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. 진행 방식은 [이용안내](guide.html)에도 있습니다.
@ 고덕동 출장열쇠 도어체인 문틀 점검

# 풀고 난 뒤 체인을 오래 쓰는 법
체인이 걸렸다 풀린 뒤에는 홈과 구슬 상태를 한 번 살펴보세요. / 휜 곳이 있거나 홈이 닳았으면 같은 문제가 반복됩니다.
- 체인 구슬을 풀 때 천천히 밀어 빼기
- 월 1회 문틀 쪽 나사를 손으로 돌려 헐거운지 확인
- 가족이 체인 거는 위치와 푸는 순서를 함께 익히기
- 도어락이 이상하면 [도어락 수리](doorlock-repair.html)를 먼저 알아보기
너무 낡은 체인은 교체가 낫지만, 문틀이 상한 경우에는 문틀 보수가 먼저입니다.

# 고덕동 말고 평택 어디든 갑니다
고덕동 옆 서정동, 동삭동, 세교동은 물론 안중읍, 포승읍, 팽성읍, 청북읍도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
출동 지역은 [출장 지역](area.html) 지도에서 확인하세요.
