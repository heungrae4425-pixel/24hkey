# 닫았는데 안 닫혔다고 우는 도어락
고덕동에서 지제역 방면으로 출근하다가 문을 닫았는데 도어락이 삐 소리를 내며 열려 있다고 알리는 경우가 있습니다. / 분명 닫았는데 자동으로 잠기지도 않으니 괜히 불안해집니다.
이런 일은 도어락이 문의 닫힘을 감지하는 부분이 제대로 작동하지 않을 때 생깁니다. / 도어락이 틀렸다기보다 문과 도어락이 서로 맞지 않게 된 상황인 경우가 많습니다.
이 글은 닫힘 센서와 걸쇠, 문틀 사이에서 무슨 일이 벌어지는지 풀어서 정리한 안내입니다.
@ 고덕동 도어락 닫힘 감지 센서 점검

# 도어락은 문이 닫혔다는 걸 어떻게 알까
도어락에는 문이 닫혔는지 알아보는 작은 장치가 들어 있습니다. / 걸쇠가 문틀 구멍에 들어가거나 문 옆면이 문틀에 닿는 것을 감지하는 방식이 많습니다.
이 장치가 눌리지 않거나 항상 눌린 상태로 있으면 도어락은 문 상태를 잘못 판단합니다. / 그래서 닫았는데도 열린 것처럼 경고음이 나거나 잠김이 완료되지 않는 증상이 생깁니다.
제품마다 방식이 달라서 어떤 방식인지 정확히 말씀드리려면 직접 봐야 합니다. / 여기서는 가장 흔한 경우를 중심으로 적었습니다.

# 증상별로 구분해 보기
먼저 어떤 증상인지 가려 보세요. / 같은 닫힘 문제라도 원인이 다를 수 있습니다.
- 문을 닫아도 계속 경고음이 나는 경우
- 문을 닫았는데 자동으로 잠기지 않는 경우
- 문을 열었는데 닫혀 있다고 인식하는 경우
- 문을 살짝 밀어야 잠기는 경우
첫째와 둘째는 센서가 눌리지 않는 쪽, 셋째는 센서가 눌린 채 걸린 쪽을 의심할 수 있습니다. / 넷째는 문틀과 걸쇠의 위치가 어긋난 경우가 많습니다.

# 문틀 구멍과 걸쇠 위치부터 눈으로 확인
문을 열어 놓고 문 옆면의 걸쇠와 문틀의 구멍을 나란히 보세요. / 문을 닫았을 때 걸쇠가 구멍 한가운데로 들어가는지가 핵심입니다.
구멍 가장자리에 긁힌 자국이 있다면 걸쇠가 구멍에 정확히 맞지 않고 닿고 있다는 증거입니다. / 이 경우 도어락이 닫힘을 감지하기 전에 이미 걸쇠가 막히고 있을 수 있습니다.
문이 조금 처졌거나 문틀이 미세하게 변형되면 위치가 어긋납니다. / 오래된 문이라면 [도어락 수리](doorlock-repair.html)에서 문 상태와 경첩 점검 방식을 함께 확인해 보세요.
@ 걸쇠와 문틀 구멍 위치 확인

# 걸쇠가 끝까지 나오지 않을 때
걸쇠 끝이 들어가지 않거나 중간에 멈추는 경우가 있습니다. / 스프링이 약해졌거나 안에 먼지가 쌓이면 이런 증상이 생깁니다.
문을 열고 걸쇠를 손가락으로 눌러 보면 부드럽게 들어갔다 나오는지 확인할 수 있습니다. / 뻑뻑하거나 도중에 걸리는 느낌이 있다면 내부 부품이 원인일 수 있습니다.
이때 기름을 많이 뿌리면 먼지가 더 달라붙어 오히려 나빠지는 일이 있습니다. / 모르겠으면 더 만지지 마시고 점검을 받으세요.

# 문이 닫히는 속도와 방향도 영향을 줍니다
문이 너무 세게 닫히면 걸쇠가 구멍을 넘어 튕겨 나오기도 합니다. / 반대로 너무 약하게 닫히면 걸쇠가 끝까지 들어가지 못하고 멈춥니다.
도어클로저가 달린 문이라면 닫히는 힘과 마지막 속도가 걸쇠 맞물림에 큰 영향을 줍니다. / 마지막에 한 번 더 잡아당기듯 닫아야 잠긴다면 이 부분을 의심해 볼 만합니다.
문을 닫을 때 쿵 소리나 삐걱임이 같이 난다면 경첩과 도어클로저도 함께 봐야 합니다. / 소리와 닫힘 증상은 원인이 겹치는 부분이 많습니다.

# 배터리가 약해도 닫힘 인식이 흔들립니다
의외로 배터리가 약해져 센서 신호를 제대로 읽지 못하는 경우가 있습니다. / 이때 번호판 불빛이 평소보다 어둡고 반응이 느린 증상이 같이 나타나기도 합니다.
배터리를 전부 새것으로 바꾸면 거짓 경고음이 사라지는 경우도 적지 않습니다. / 먼저 이 방법을 시도해 보고 안 되면 다음 단계로 넘어가세요.
일부만 바꾸면 전압이 맞지 않아 같은 증상이 남을 수 있으니 모두 교체하는 것이 좋습니다.
@ 배터리 교체 후 닫힘 인식 확인

# 안에서 보조키나 잠금 버튼을 건드리지는 않았는지
문 안쪽의 잠금 버튼이나 보조키가 반쯤 눌려 있어도 도어락이 상태를 헷갈립니다. / 손잡이를 돌리다가 레버가 중간 위치에 걸리는 경우입니다.
레버를 한 번 완전히 풀어 원위치에 놓고 문을 다시 닫아 보세요. / 이것만으로 해결되는 경우가 생각보다 많습니다.
어린 가족이 장난으로 만졌을 수도 있으니 가족에게도 물어보시길 권합니다.

# 억지로 눌러서 잠그려 하지 마세요
닫힘 문제가 있을 때 문을 세게 밀어 잠그는 방법에 익숙해지는 분이 있습니다. / 하지만 그렇게 쓰면 걸쇠와 문틀이 더 빨리 상합니다.
문틈에 테이프나 종이를 끼워 닫힘을 속이는 방법도 권하지 않습니다. / 잠겼다고 믿었는데 실제로는 열려 있는 상태가 되어 안전하지 않습니다.
증상이 반복된다면 [도어락 수리](doorlock-repair.html)로 센서와 걸쇠를 먼저 점검하는 것이 좋습니다. / 고쳐 쓸 수 있으면 교체는 권하지 않습니다.

# 전화로 알려 주시면 좋은 것
- 문을 닫았을 때 어떤 소리가 나는지
- 닫힘 문제가 언제부터인지
- 배터리를 최근 교체했는지
- 문을 닫을 때 걸쇠가 구멍에 들어가는 소리가 나는지
- 도어락과 문틀 사진
짧은 영상으로 문을 닫는 모습을 보내 주시면 원인을 가려내는 데 큰 도움이 됩니다. / 고덕동 어느 쪽인지도 알려 주세요.
닫힘 문제로 도어락이 계속 잠금 상태를 유지해 문이 아예 안 열리는 경우도 있습니다. / 이럴 때는 억지로 열려 하지 마시고 [현관문 개문](door-open.html) 안내를 먼저 보세요.
문을 상하지 않게 여는 것을 우선으로 하고, 열린 뒤에 원인이 된 부분을 함께 점검해 드립니다. / 이미 문을 연 뒤라면 증상이 언제 시작됐는지 기억나는 대로 알려 주시면 도움이 됩니다.
집 안에 아이나 반려동물이 있는 상황이라면 꼭 먼저 말씀해 주세요. / 오래 기다리지 않도록 우선순위를 정해 안내합니다.

닫힘 문제로 도어락이 계속 잠금 상태를 유지해 문이 안 열리는 경우도 있습니다. / 이럴 때는 억지로 열려 하지 마시고 [현관문 개문](door-open.html) 안내를 먼저 보세요.
문을 상하지 않게 여는 것을 우선으로 하고, 열린 뒤에 원인이 된 부분을 함께 점검합니다.

# 방문하면 사시는 분인지 확인합니다
문과 도어락을 만지는 일이라 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나를 준비해 주세요.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 주시면 좋습니다.

# 비용은 시작하기 전에 안내합니다
증상을 확인한 뒤 필요한 작업과 비용을 먼저 설명드립니다. / 동의하시면 시작하고 아니면 그대로 돌아갑니다.
문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없으며, 진행 방식은 [이용안내](guide.html)에 있습니다.

# 고덕동 말고 평택 곳곳으로 갑니다
고덕동 가까이 서정동, 지제역 쪽 동네, 동삭동, 비전동, 세교동, 송탄동도 다닙니다. / 평택 안이면 24시간 연락이 닿습니다.
[평택 출장열쇠](pyeongtaek.html) 페이지에서 지역을 확인하시고, 다른 지역은 [출장 지역](area.html)을 참고하세요.
