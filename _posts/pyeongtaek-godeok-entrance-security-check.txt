# 고덕동 현관, 불안해하기보다 한 번 점검해 두세요
고덕동은 새 단지가 계속 들어서고 있어서 처음 도어락을 쓰는 분도 많은 동네입니다. / 이사를 마치고 나면 문 앞이 허전해 보여도 정작 점검은 뒤로 미루게 됩니다.
방범이라고 하면 크게 무서운 이야기를 떠올리기 쉬운데 실제로는 아주 작은 습관에서 차이가 납니다. / 이 글은 평택 고덕동에서 현관 방범을 차분히 점검하는 방법을 정리했습니다.
겁을 주려는 것이 아니라 한 번 확인해 두면 마음이 편해진다는 정도로 읽어 주세요. / [평택 출장열쇠](pyeongtaek.html)가 점검을 도와드릴 수도 있습니다.
@ 고덕동 현관 방범 점검 도어락 출장열쇠

# 외출하기 전 문 앞에서 확인할 다섯 가지
문이 끝까지 닫혔는지 손잡이를 한 번 당겨 확인하세요. / 도어락이 잠금 소리를 냈는지도 귀로 확인하면 좋습니다.
보조키까지 쓰는 집이라면 보조키도 같이 잠갔는지 봅니다. / 습관이 되면 외출 후에 문을 걱정하는 일이 줄어듭니다.
택배나 전단지가 문 앞에 오래 쌓여 있으면 비어 있다는 신호가 됩니다. / 장기간 집을 비울 때는 이웃에게 부탁해 두세요.

# 도어락 상태를 눈으로 살펴보세요
번호판에 손자국이 한쪽만 심하게 남아 있으면 비밀번호가 짐작되기 쉽습니다. / 가끔 닦아 주시거나 번호를 바꿔 주세요.
배터리 경고음이 나는데 미루고 있지는 않은지 확인하세요. / 경고음은 곧 방전된다는 알림입니다.
문이 열릴 때와 닫힐 때 소리가 예전과 다르지 않은지도 들어 보세요. / 평소와 다른 소리는 부품이 닳았다는 신호일 수 있습니다.

# 문틀과 걸쇠 상태 보기
걸쇠가 문틀 홈에 제대로 들어가는지 확인하세요. / 문이 처졌다면 걸리는 깊이가 얕아집니다.
문틀과 문 사이 틈이 한쪽만 벌어져 있다면 경첩 점검이 필요합니다. / 이런 틈은 방범에도 좋지 않고 바람 소리도 만듭니다.
문틀 주변에 오래된 흠집이나 파손이 있는지도 눈으로 훑어보세요. / 이사 전부터 있던 것이라면 사진으로 기록해 두세요.
@ 평택 고덕동 문틀 걸쇠 점검 출장

# 보조키를 쓰는 습관
현관 도어락만 쓰는 집이 많지만 보조키가 있다면 외출 때 같이 잠그는 것이 좋습니다. / 도어락이 방전되어도 보조키는 영향을 받지 않습니다.
보조키 열쇠는 도어락 열쇠와 따로 보관하세요. / 한곳에 모아 두면 한 번에 잃어버릴 위험이 커집니다.
열쇠가 뻑뻑해졌다면 미루지 말고 점검받으세요. / 열쇠가 안 돌아가는 때는 대개 안쪽이 닳았거나 먼지가 낀 경우입니다.

# 비밀번호 관리는 가장 쉬운 방범입니다
이사 올 때 정해 둔 초기 번호를 그대로 쓰고 있지는 않나요. / 생일이나 전화번호 뒷자리 같은 쉬운 번호는 피하는 편이 좋습니다.
가족에게만 공유하고 메모나 사진으로 남겨 두지 마세요. / 공유한 사람이 바뀌면 번호도 바꿔 주세요.
정기적으로 바꾸는 습관이 있으면 마음이 편합니다. / 방법은 제품마다 달라서 설명서를 먼저 확인하세요.

# 낯선 방문이나 전단지에 대하는 법
모르는 사람이 벨을 누르고 도어락이나 열쇠를 점검해 준다고 하면 신중히 대응하세요. / 문을 열기 전에 인터폰으로 먼저 확인하세요.
저희는 부르신 분이 있을 때만 출동합니다. / 먼저 찾아가 문을 열어 주겠다고 권하는 일은 하지 않습니다.
의심스러운 경우 관리사무소나 이웃에게 알려 두세요. / 경찰에 상담하는 것도 방법입니다.

# 비상 상황을 대비한 정보 정리
집 열쇠를 잃어버렸을 때 어디에 연락할지 한 줄로 적어 두세요. / 휴대폰 메모에 열쇠집 번호를 저장해 두는 것만으로도 충분합니다.
비밀번호를 잊었을 때를 대비해 믿을 수 있는 가족에게 알려 두세요. / 번호를 한곳에 적어 두는 것은 권하지 않습니다.
열쇠 복사본은 가까이 두기보다 믿을 수 있는 분에게 맡기는 편이 낫습니다. / 한 곳에 모아 두면 한꺼번에 문제가 생깁니다.

# 점검을 부탁하실 때의 진행 방식
전화로 연락 주시면 문 종류와 불편한 점을 먼저 여쭙니다. / 도어락 사진을 보내 주시면 준비할 것이 줄어듭니다.
방문해서 도어락, 보조키, 걸쇠, 문틀 상태를 같이 확인합니다. / 그 자리에서 고칠 수 있는 것은 고치고 어렵다면 설명드립니다.
고쳐서 쓸 수 있으면 교체를 권하지 않습니다. / 필요할 때는 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 사시는 분인지 먼저 확인합니다
점검이라도 집 안에 들어가는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우시더라도 이웃과 가족 모두를 위한 절차입니다. / 확인이 어려우면 작업을 하지 못합니다.
점검만 받고 아무것도 바꾸지 않으셔도 괜찮습니다. / 필요하지 않은 작업은 권하지 않습니다.

# 비용은 시작하기 전에 말씀드립니다
점검한 결과를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 열어야 하는 상황에서는 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 고덕동 24시 열쇠집 방범 점검 출장

# 고덕동 말고 평택 어디든 갑니다
고덕동 옆 서정동, 지산동, 팽성읍도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
평택에서 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
새 단지는 입주 시기가 몰려 있어 점검 요청이 갑자기 늘기도 합니다. / 급하지 않다면 낮 시간에 미리 말씀해 주시면 일정을 맞추기 쉽습니다.
