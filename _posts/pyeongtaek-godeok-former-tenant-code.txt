# 고덕동 새집 도어락, 앞사람 번호는 지워졌을까
고덕동은 지제역과 서정리역 쪽 생활권으로 새로 이사 오는 분이 많은 동네입니다. / 이사 날 짐 정리에 정신이 없다 보면 도어락 설정은 뒷전이 되기 쉽습니다.
그런데 이전 세입자나 집주인이 쓰던 번호와 카드가 그대로 남아 있을 수 있습니다. / 알지 못하는 사람이 들어올 수 있다는 가능성은 작아도 마음에 걸리는 일입니다.
이 글은 고덕동에서 이사 후 이전 번호가 남아 있는지 확인하고 정리하는 순서를 적었습니다. / 직접 하기 어렵거나 문이 안 열릴 때는 [평택 출장열쇠](pyeongtaek.html)로 연락 주시면 됩니다.
@ 고덕동 이사 후 도어락 번호 확인

# 번호가 남는 이유부터 알아 두기
도어락은 전원을 껐다 켠다고 번호가 지워지지 않습니다. / 한 번 등록한 번호와 카드는 직접 삭제하거나 초기화하기 전까지 저장돼 있는 제품이 많습니다.
이전 사용자가 이사 나가면서 번호를 지우고 가면 좋겠지만 모두가 그렇게 하지는 않습니다. / 새 입주자가 들어오기 전에 집주인이 정리했는지도 알 수 없는 경우가 대부분입니다.
번호가 남아 있다고 해서 누가 악용한다는 뜻은 아닙니다. / 다만 정리하지 않고 쓰는 것보다 정리하고 쓰는 편이 마음이 편합니다.

# 이삿날 도어락 점검 순서
- 번호판에 불이 잘 들어오는지, 소리가 정상인지
- 설정 메뉴에 들어가 등록된 번호와 카드 개수를 볼 수 있는지
- 안쪽에 설명서 스티커나 모델명이 있는지
- 배터리 교체 시기가 오래돼 보이지 않는지
제품에 따라 등록 개수를 음성으로 알려주기도 하고, 번호만 보여주기도 합니다. / 개수를 확인할 수 없는 제품은 번호를 새로 등록하는 쪽이 현실적입니다.
확인이 어려우면 모델명을 사진으로 찍어 보내 주세요. / 모델에 맞는 확인 방법을 안내드립니다.

# 가장 확실한 방법은 새로 등록하고 이전 것은 삭제
이전 번호가 남아 있는지 몰라도, 새 번호를 등록하고 이전 번호를 지우는 방법이면 문제가 없습니다. / 이때 "전체 삭제" 기능이 있는지 먼저 확인합니다.
전체 삭제 기능이 없는 제품은 하나씩 지워야 하는데, 자리를 몰라 헤매는 분이 많습니다. / 이럴 때는 초기화를 하고 새로 등록하는 방법을 고려합니다.
초기화하면 모든 설정이 공장 상태로 돌아가므로 새 입주자가 처음부터 다시 정리합니다. / 이후 가족들에게 새 번호를 알려 주면 끝입니다.
@ 고덕동 도어락 번호 삭제 및 초기화

# 카드키나 열쇠도 함께 확인하세요
번호만 신경 쓰다가 카드키나 열쇠를 놓치는 경우가 많습니다. / 이전 입주자가 카드를 몇 장 가지고 나갔는지 알기 어렵습니다.
카드가 여러 장 등록돼 있다면 일단 모두 삭제하고 지금 가진 카드만 새로 등록하세요. / 이 과정이 번거로워도 한 번 해두면 오래 편합니다.
열쇠로 여는 방식의 보조 열쇠도 이전 사람이 가지고 있을 가능성이 있습니다. / 이런 경우에는 [도어락 교체](doorlock-replace.html)나 실린더 교환을 같이 알아보는 분도 있습니다.

# 집주인이나 중개사에게 먼저 물어볼 것
이사 전에 가능하다면 두 가지를 물어보세요. / 이전 입주자 번호는 지웠는지, 집주인 관리용 번호가 따로 있는지입니다.
답을 듣고도 마음이 놓이지 않으면 직접 새로 설정하는 방법이 확실합니다. / 이 일은 문자로 남겨 두면 나중에 서로 오해가 없습니다.
다만 집주인의 허락 없이 도어락을 통째로 바꾸는 일은 계약 내용에 따라 문제가 생길 수 있어서 먼저 이야기를 나누시길 권합니다. / 법적인 판단은 저희가 대신할 수 없는 부분입니다.

# 번호가 안 맞아서 문이 안 열릴 때
이삿날 받은 번호로 눌러도 안 열리는 경우가 있습니다. / 앞 사람이 번호를 바꾸고 가거나, 전달받은 번호가 틀렸을 수 있습니다.
먼저 번호를 정확히 눌렀는지, 전달받은 번호 끝에 "샵" 버튼이 필요한 제품인지 확인하세요. / 입력 방식이 제품마다 다른 경우가 있습니다.
여러 번 시도하면 입력 제한이 걸립니다. / 서너 번 해보고 안 되면 멈추고 전달해 준 사람에게 다시 확인하세요.

# 이사 당일 문을 못 열 때의 대처
이삿짐이 도착했는데 현관문이 안 열리면 하루 일정이 모두 꼬입니다. / 집주인이나 중개사에게 연락이 닿지 않으면 불안이 커집니다.
이럴 때는 먼저 번호판이 켜지는지, 배터리가 남았는지 확인합니다. / 9V 건전지를 비상 전원 단자에 대어 보는 방법이 첫 번째입니다.
그래도 안 되면 사용하는 분 확인 서류, 즉 계약서나 입주 관련 서류와 신분증을 준비하고 전화 주세요. / 서류가 있으면 확인이 훨씬 수월합니다.

# 출장열쇠를 부르면 이렇게 진행됩니다
전화로 도어락 모양과 번호판 상태, 이사 중인지 여부를 여쭙니다. / 이삿짐 업체가 대기 중이면 시간이 급하다는 말씀도 해 주세요.
도착하면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 되고, 막 이사한 경우에는 계약서나 입주 관련 서류도 도움이 됩니다.
상태를 보고 비용을 문 열기 전에 먼저 말씀드립니다. / 못 열면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html)에서 확인하실 수 있습니다.
@ 고덕동 이사 당일 출장열쇠 출동

# 새로 설정할 때 같이 정하면 좋은 것
번호를 새로 정할 때는 생일이나 전화번호 끝자리 같은 쉬운 숫자를 피하세요. / 가족이 외우기 쉬우면서도 남이 짐작하기 어려운 번호가 좋습니다.
관리자 번호가 따로 있는 제품은 관리자 번호도 반드시 바꿔 주세요. / 이 번호를 그대로 두면 앞사람이 설정했던 상태가 남아 있을 수 있습니다.
카드키는 가족 수에 맞춰 등록하고 하나는 따로 보관해 두세요. / 배터리를 새것으로 바꾸고 교체 날짜를 적어 두면 더 좋습니다.

# 오래된 도어락이라면 수리나 교체도 고려
이사 들어간 집의 도어락이 너무 오래됐다면 번호만 정리하고 쓰기엔 불안할 수 있습니다. / 소리가 불규칙하거나 반응이 느린 제품은 곧 고장 날 수 있습니다.
먼저 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 보고, 그래도 어렵다면 교체를 말씀드립니다. / 새로 달 때는 [도어락 설치](doorlock-install.html)에서 문 두께와 규격을 같이 확인합니다.
교체는 꼭 필요한 경우에만 권하고, 비용은 작업 전에 먼저 말씀드립니다.

# 고덕동 말고 평택 어디든 갑니다
고덕동 옆 서정동, 동삭동, 세교동, 비전동은 물론 지산동, 송탄동과 안중읍, 포승읍, 팽성읍, 청북읍까지 다닙니다. / 평택 안이면 24시간 연락받습니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
