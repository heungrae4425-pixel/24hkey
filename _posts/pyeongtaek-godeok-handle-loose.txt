# 고덕동 현관 손잡이가 헐겁게 흔들린다면
고덕동은 새로 입주한 주거 지역이 넓게 퍼진 동네입니다. / 도어락이 비교적 새것이어도 손잡이 쪽 이상은 생각보다 자주 생깁니다.
어느 날부터 손잡이가 헐겁게 흔들리거나, 돌려도 걸쇠가 움직이지 않는 느낌이 들면 사용을 멈추고 상태를 보는 게 좋습니다. / 계속 쓰면 문 안쪽 부품까지 상할 수 있습니다.
이 글은 고덕동에서 손잡이가 헐겁거나 헛돌 때 먼저 확인할 것을 정리했습니다. / 직접 고치기 어려운 경우 [평택 출장열쇠](pyeongtaek.html)가 점검하는 순서도 적었습니다.
@ 고덕동 출장열쇠 현관 손잡이 점검

# 손잡이가 헛도는 흔한 원인
손잡이를 돌렸는데 걸쇠가 안 움직이면 손잡이와 걸쇠를 잇는 부분에 문제가 생긴 겁니다. / 증상별로 원인이 다릅니다.
- 손잡이 고정 나사가 풀려 손잡이가 흔들리는 경우
- 안쪽 손잡이와 바깥 손잡이를 잇는 축이 헐거워진 경우
- 걸쇠 내부 부품이 마모되어 힘이 전달되지 않는 경우
첫 번째는 비교적 가볍게 해결되지만 두 번째와 세 번째는 부품 점검이 필요합니다. / 그래서 어떤 증상인지 먼저 구분해 보는 것이 중요합니다.

# 먼저 손잡이를 가볍게 흔들어 보세요
문을 연 상태에서 손잡이를 위아래로 가볍게 흔들어 봅니다. / 많이 덜렁거리면 고정이 풀린 겁니다.
손잡이 뒤쪽 덮개를 살짝 돌려 보면 나사가 보이는 모델도 있습니다. / 맞는 드라이버로 살짝 조이면 증상이 없어지는 경우도 있습니다.
하지만 나사를 세게 조이다가 나사산이 뭉개지는 일이 있으니 조심하세요. / 힘을 주었는데도 계속 헛돌면 멈추고 전화 주시는 게 낫습니다.

# 문이 닫힌 채 손잡이가 헛돌 때가 가장 급합니다
문이 열려 있을 때는 시간 여유가 있지만 닫혀 있을 때는 이야기가 달라집니다. / 손잡이가 헛돌아 문이 안 열리면 그대로 갇히거나 집 밖에서 못 들어갈 수 있습니다.
이때는 손잡이를 억지로 세게 돌리거나 문을 발로 차는 일은 하지 마세요. / 안쪽 부품이 완전히 부러지면 비파손으로 여는 일이 어려워집니다.
안쪽에 있다면 번호나 카드로 열 수 있는지, 보조키가 잠겨 있는지만 확인하고 전화 주세요. / 상황만 알려주셔도 어떻게 접근할지 바로 말씀드립니다.
@ 고덕동 도어락 손잡이 헛돔 개방

# 전화하실 때 알려주시면 좋은 것
증상을 구체적으로 말씀해 주시면 도착 후 작업이 빨라집니다. / 아래 내용을 간단히 정리해 두세요.
- 손잡이가 흔들리는지, 돌아가기만 하고 걸쇠가 안 움직이는지
- 문이 열려 있는지 닫혀 있는지
- 도어락 종류(손잡이 일체형, 푸시풀형 등)
- 얼마 전에 도어락을 설치하거나 교체한 적이 있는지
- 집 안에 사람이나 반려동물이 있는지
손잡이 부분 사진을 보내주시면 맞는 부품을 챙겨 갈 수 있습니다. / 집 안에 아이가 혼자 있다면 꼭 먼저 말씀해 주세요.

# 고덕동 위치는 이렇게 알려주세요
고덕동은 새 건물이 많고 길이 넓지만 주소가 비슷한 건물이 이어져 있습니다. / 건물 이름이 아니라 동과 호수, 가까운 큰 도로를 같이 알려주시면 좋습니다.
공동 현관에 비밀번호가 있으면 미리 알려주세요. / 도착해서 기다리는 시간을 줄일 수 있습니다.
늦은 시간에는 주변이 어두워 건물을 찾기 어렵습니다. / 전화로 위치를 한 번 더 확인해 드립니다.

# 출장열쇠가 와서 하는 점검
손잡이를 돌려 보며 어디서 힘이 끊기는지 확인합니다. / 고정 나사 상태부터 보고, 문제가 더 깊으면 도어락 본체를 열어 걸쇠와 연결부를 봅니다.
부품만 바꾸면 되는 경우에는 도어락 전체를 바꾸지 않아도 됩니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않는 것이 원칙입니다.
작업 중 부품을 바꿔야 하면 손대기 전에 먼저 말씀드리고 진행합니다. / 문이 닫혀 있다면 [현관문 개문](door-open.html) 방식으로 문을 먼저 엽니다.
점검과 수리는 [도어락 수리](doorlock-repair.html) 페이지에 정리해 두었습니다.

# 수리와 교체를 나누는 기준
손잡이 쪽 부품만 상했고 본체는 멀쩡하다면 부분 수리로 충분합니다. / 반대로 본체 내부가 오래되어 여러 곳이 동시에 낡았다면 교체가 맞을 수 있습니다.
이럴 때는 상태를 보여드리고 이유를 설명드립니다. / 교체가 필요하다면 [도어락 교체](doorlock-replace.html)를 안내합니다.
무리한 교체를 권하지 않고 선택은 맡깁니다. / 설명을 들으신 뒤 정하셔도 늦지 않습니다.

# 비용은 작업 전에 먼저 말씀드립니다
도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 사시는 분인지 확인하는 절차
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 입주민 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
@ 고덕동 도어락 수리 출장열쇠 평택

# 손잡이를 오래 쓰는 평소 요령
문을 열 때 손잡이를 위아래로 세게 누르거나 매달리지 마세요. / 하루에 수십 번 쓰는 부품이라 작은 힘이 쌓이면 헐거워집니다.
아이들이 손잡이에 매달려 놀다 헐거워지는 일도 많습니다. / 손잡이가 아래로 처져 있다면 한 번 점검받으시기를 권합니다.
- 손잡이가 흔들리면 바로 사용 줄이기
- 나사를 세게 조이지 않고 살짝 확인만 하기
- 경고음이 나면 배터리도 함께 확인하기
일찍 발견하면 부분 수리로 끝납니다.

# 새 도어락도 손잡이가 헐거워질 수 있는 이유
설치한 지 얼마 안 된 도어락도 손잡이가 흔들리는 일이 있습니다. / 설치할 때 고정 나사가 충분히 조여지지 않았거나 문 두께에 맞지 않는 부품이 쓰였을 수 있습니다.
문이 얇은 경우 손잡이 축이 깊게 박히지 않아 시간이 지나면서 헐거워지기도 합니다. / 이런 때는 단순히 조이는 것으로 끝나지 않고 설치 상태를 다시 맞춰야 합니다.
새 도어락이니 괜찮겠지 하고 그냥 쓰다 보면 어느 날 갑자기 손잡이가 돌아가 버리는 일이 생깁니다. / 흔들림이 느껴지는 초기에 알려주시면 가볍게 끝낼 수 있습니다.

# 고덕동 말고 평택 어디든 갑니다
고덕동에서 가까운 지제역 쪽과 서정동, 동삭동까지 자주 다닙니다. / 평택 안이면 동네를 가리지 않고 24시간 출동합니다.
송탄동, 안중읍, 팽성읍처럼 거리가 있는 곳도 위치를 받으면 도착 시간을 먼저 말씀드립니다. / 평택에서 다니는 지역은 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
