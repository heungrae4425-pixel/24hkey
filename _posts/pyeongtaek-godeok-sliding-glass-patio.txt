# 고덕동 테라스 샷시, 잠겼는데 잠긴 게 아닐 때
고덕동은 지제역과 평택역 쪽을 오가는 분들이 많이 사는 새 생활권입니다. / 이런 동네는 현관문만큼 테라스나 발코니 샷시 잠금에 대한 문의도 조용히 늘어납니다.
유리문을 밀어서 닫았는데 손잡이를 올려도 철컥 소리가 없거나, 닫힌 것 같은데 살짝 밀면 열리는 경우가 있습니다. / 한 번 그런 경험을 하면 외출할 때마다 마음이 쓰입니다.
이 글은 고덕동 테라스·발코니 샷시 잠금을 직접 확인하는 순서와, 손대지 말아야 할 때를 정리한 안내입니다. / 현관문이 아니어도 [평택 출장열쇠](pyeongtaek.html)가 방문해서 점검해 드립니다.
@ 고덕동 테라스 샷시 잠금장치 점검

# 샷시 잠금은 어떻게 생겼나
미닫이 샷시의 잠금은 대개 손잡이 옆에 달린 갈고리 모양 부품이 반대쪽 틀의 고리에 걸리는 방식입니다. / 이 갈고리를 흔히 크레센트라고 부릅니다.
손잡이를 올리면 갈고리가 돌아 걸리고, 내리면 풀립니다. / 구조가 단순해서 어긋남이 생기는 곳도 정해져 있습니다.
테라스 문은 현관문보다 바깥 공기를 직접 받습니다. / 햇빛, 비, 먼지가 번갈아 닿아서 고무 패킹과 바퀴가 먼저 낡습니다.
그래서 잠금이 안 걸린다고 해서 곧바로 잠금 부품만 탓하기보다 문 전체 상태를 같이 보는 편이 정확합니다. / 이 글의 순서도 겉에서 안으로 들어가도록 짰습니다.

# 먼저 문이 끝까지 닫혔는지 봅니다
잠금이 안 걸리는 이유의 상당수는 문이 레일 끝까지 가지 못해서입니다. / 손잡이를 잡고 한 번 더 천천히 밀어 맞닿는지 확인해 보세요.
이때 억지로 쾅 하고 밀면 유리 틀에 충격이 갑니다. / 부드럽게 밀어 끝에서 멈추는 위치를 손끝으로 느껴 보면 됩니다.
끝까지 갔는데도 갈고리가 반대편 고리에서 한참 떨어져 있다면 문짝이 처진 쪽을 의심합니다.
처진 정도가 눈으로 보일 만큼 크다면 바퀴가 닳았거나 부러진 것일 수 있습니다. / 문을 들어 올려 보았을 때 가볍게 올라가면서 소리가 난다면 바퀴 쪽 문제입니다.
이 경우 억지로 잠금만 만지면 아무 소용이 없고, 오히려 틀이 휘기도 합니다.

# 레일과 바퀴, 눈으로 먼저 확인
문 아래 레일에 먼지, 머리카락, 작은 돌이 끼어 있으면 문이 비스듬히 선 채 움직입니다. / 그러면 윗부분의 잠금 높이가 맞지 않게 됩니다.
마른 걸레와 칫솔로 레일 홈을 쓸어 내면 의외로 해결되는 경우가 많습니다. / 청소 후 문을 몇 번 열고 닫으며 부드럽게 굴러가는지 보세요.
물을 부어 닦는 것은 권하지 않습니다. / 물기가 남으면 겨울에 얼거나 바퀴 축이 녹슬 수 있습니다.
@ 샷시 레일 청소와 바퀴 점검

# 갈고리가 헛돌 때는 나사부터 봅니다
손잡이를 올렸는데 힘이 없이 돌기만 한다면 안쪽 나사가 풀렸을 수 있습니다. / 손잡이 몸통 옆면의 작은 나사를 드라이버로 살짝 조여 보는 정도는 괜찮습니다.
다만 힘을 세게 주지는 마세요. / 샷시 틀은 알루미늄이라 나사 구멍이 쉽게 뭉개집니다.
조여도 계속 헛돌거나 부품이 갈라져 보이면 교체해야 하는 부품입니다. / 이때는 무리하지 말고 사진을 찍어 두세요.

# 보조 잠금과 높이 맞추기
샷시에는 윗부분에 방범용 보조 잠금이 달린 경우가 많습니다. / 작은 꼭지를 돌리거나 눌러서 잠그는 형태입니다.
보조 잠금은 문이 처진 만큼 어긋나서 안 맞는 일이 흔합니다. / 문짝 아래 바퀴 조절 나사로 높이를 맞추면 두 잠금이 다시 만납니다.
높이 조절은 반 바퀴씩만 돌리며 문을 흔들어 확인하는 것이 안전합니다. / 한꺼번에 많이 돌리면 반대로 문이 틀에 닿아 긁힙니다.
조절 나사는 문 아래쪽 옆면에 작은 구멍으로 숨어 있는 경우가 많습니다. / 구멍을 못 찾겠으면 무리해서 찾지 말고 사진을 찍어 두세요.
양쪽 바퀴를 같은 만큼 조절해야 문이 한쪽으로 기울지 않습니다. / 한쪽만 돌려 놓으면 닫을 때 반대쪽이 걸립니다.

# 테라스 문이 밖에서 잠겨 버렸다면
빨래를 널러 나갔다가 문이 닫히면서 안쪽 잠금이 걸리는 경우가 있습니다. / 집은 안에 있고 나는 테라스에 서 있는 난감한 상황입니다.
1층이나 낮은 층이라고 해서 담이나 난간을 넘어가려 하지 마세요. / 다치는 것도 문제지만 유리를 건드려 깨질 수 있습니다.
추운 날 얇은 옷으로 오래 서 있으면 몸이 먼저 상합니다. / 이웃에게 전화를 빌리거나 가까운 이웃집 문을 두드려 도움을 청하는 것이 낫습니다.

# 고덕동에서 이런 연락이 많은 때
환기 때문에 샷시를 열어 두었다가 바람에 문이 흔들려 잠금이 어긋나는 경우가 있습니다. / 바람이 센 날 잠금을 걸어 두지 않았다가 생기는 일입니다.
여름 끝자락과 겨울 초입에는 온도 차로 문틀이 미세하게 수축하고 늘어납니다. / 그래서 한 계절 내내 멀쩡하다가 날씨가 바뀌면 갑자기 안 맞기도 합니다.
이사 직후에도 잘 생깁니다. / 짐을 옮기다 문짝을 한 번 들썩이면 바퀴 높이가 바뀌기 때문입니다.

# 하지 말아야 할 것
- 윤활유를 잠금 부품 안쪽에 많이 뿌리기
- 드라이버로 갈고리를 비틀어 열기
- 유리 틀을 발로 밀거나 어깨로 밀기
- 접착테이프로 잠금 위치를 고정해 두기
기름을 많이 뿌리면 먼지가 엉겨 붙어 다음에 더 뻑뻑해집니다. / 테이프로 붙여 두면 잠겼다고 착각해서 오히려 방범에 구멍이 납니다.

# 출장열쇠가 와서 보는 순서
먼저 문이 끝까지 닫히는지, 레일에 이물질이 있는지 봅니다. / 그다음 갈고리와 받이의 높이, 나사 상태를 차례로 확인합니다.
고칠 수 있는 곳이면 현장에서 조정하고, 부품이 닳았다면 바꾸기 전에 먼저 말씀드립니다. / 현관 도어락도 같이 봐 달라고 하시면 [도어락 수리](doorlock-repair.html) 항목에서 설명하는 점검을 함께 합니다.
신분 확인은 샷시 작업에도 똑같이 합니다. / 신분증, 주소가 적힌 우편물, 관리사무소 확인 중 하나를 준비해 주세요.

# 비용은 시작 전에 먼저 말씀드립니다
점검을 시작하기 전에 상황을 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하셔야 작업을 시작합니다.
열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 작업 중에 말없이 늘어나는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다. / 현관문을 열어야 하는 경우라면 [현관문 개문](door-open.html) 페이지도 같이 보시면 이해가 쉽습니다.
