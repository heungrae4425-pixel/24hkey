# 고덕동 새집 첫날, 현관문부터 챙기세요
고덕동은 지제역과 평택역 쪽으로 오가는 새 보금자리를 꾸리는 분들이 눈에 띄는 동네입니다. / 신혼집 열쇠를 받고 설레는 마음으로 현관 앞에 섰는데, 번호가 안 맞거나 이전 사람 번호가 남아 있으면 첫날부터 당황하게 됩니다.
이사와 혼수에 신경 쓰다 보면 도어락은 맨 마지막 순서로 밀리기 쉽습니다. / 하지만 집의 문을 누가 열 수 있는지는 입주 첫날 가장 먼저 정리해 둘 일입니다.
이 글은 신혼집에 입주할 때 도어락에서 확인할 순서를 차근차근 적었습니다.
@ 고덕동 신혼집 현관 도어락

# 입주 전에 열쇠를 누가 가지고 있는지 파악하세요
새집이든 중고 매물이든 이전 거주자, 시공 업체, 중개하신 분, 청소 업체에 열쇠나 번호가 남아 있을 수 있습니다. / 모두를 의심하자는 뜻이 아니라, 누가 알고 있는지를 정리하자는 것입니다.
받은 열쇠 개수를 세어 보고, 계약 과정에서 문을 열어 본 사람이 있는지 물어보세요. / 확인이 어렵다면 입주 첫날 도어락 설정을 새로 하는 것이 가장 깔끔합니다.

# 초기화를 먼저 해야 하는 이유
도어락에는 이전에 등록된 번호, 카드, 지문이 남아 있을 수 있습니다. / 이를 지우지 않고 새 번호만 추가하면 이전 정보로도 문이 열립니다.
초기화를 하면 모든 등록 정보가 사라지고 처음 상태로 돌아갑니다. / 이후에 새 번호를 등록하면 지금 사시는 분들만 열 수 있게 됩니다.
제품마다 초기화 방법이 다르니 설명서나 모델명 확인이 먼저입니다. / 방법을 몰라 순서를 잘못 누르면 오히려 잠기는 일도 있어 조심해야 합니다.

# 비밀번호를 정하는 요령
부부가 함께 쓸 번호는 두 사람 모두 기억하기 쉬우면서도 남이 추측하기 어려운 조합이 좋습니다.
- 생일, 결혼기념일처럼 쉽게 알려진 숫자는 피하기
- 같은 숫자를 반복하거나 연속되는 번호 피하기
- 부모님이나 지인에게 알려 줄 때는 임시 번호를 따로 만들기
- 번호를 바꾼 뒤 서로에게 확실히 공유하기
번호를 바꿔 놓고 한 사람에게만 알려서 다른 사람이 문 앞에서 막히는 일이 의외로 흔합니다.

# 카드키와 지문 등록은 둘 다 해 두세요
번호가 가장 기본이지만, 카드키나 지문을 같이 등록해 두면 번호를 깜빡해도 문을 열 수 있습니다. / 두 사람이 각자 카드와 지문을 등록해 두면 편리합니다.
카드키는 분실하기 쉬우니 여분을 한 장 따로 보관하세요. / 잃어버린 카드는 등록을 지워 두는 것이 안전합니다.
@ 카드키와 지문 등록 점검

# 보조키와 걸쇠 상태 확인
도어락 외에 현관문 안쪽에 돌려 잠그는 보조키가 있는 집이 많습니다. / 입주 첫날 보조키가 잘 돌아가는지, 열쇠 구멍이 막혀 있지 않은지 확인해 보세요.
밖에서 보조키를 잠가 버리면 도어락 번호가 맞아도 문이 안 열립니다. / 이 점을 가족이 모두 알고 있어야 합니다.
신혼집에 오시는 양가 부모님께도 간단히 설명해 두면 오해가 줄어듭니다.

문 닫힘과 걸쇠 위치도 봐 두세요. / 이사 짐을 들이면서 문이 많이 여닫히면 경첩이나 문틀이 미세하게 달라지기도 합니다. / 짐 정리가 끝나고 나서 한 번 문이 완전히 닫히는지, 잠금이 한 번에 되는지 확인하세요.
문을 닫았는데 잠금음이 늦게 나거나 걸쇠가 문틀에 걸려 보인다면 위치가 어긋난 것입니다.
새집이라도 시공 직후에는 미세한 조정이 필요한 경우가 있습니다. / 이삿짐 업체가 문을 오래 열어 둔 날에는 경첩 나사가 풀리지 않았는지도 한 번 만져 보세요.
증상이 사소해 보여도 신혼 초에 바로 잡아 두면 몇 해 뒤 큰 고장으로 번지는 일을 막을 수 있습니다.

# 배터리 교체 날짜를 적어 두세요
입주 때 들어 있던 배터리가 얼마나 쓴 것인지는 알기 어렵습니다. / 처음에 새 건전지로 바꾸고 날짜를 안쪽 덮개에 적어 두면 이후 관리가 쉬워집니다.
경고음이 나기 시작하면 그날 바로 바꾸는 습관이 중요합니다. / 부부가 번갈아 확인하는 방법도 좋습니다.
비상용 9V 건전지나 보조 배터리를 현관 근처에 하나 두는 것도 방법입니다.

# 입주 첫날 문이 안 열릴 때 확인 순서
받은 번호가 맞는데 안 열린다면 순서를 지켜 확인해 보세요.
- 번호판이 켜지는지, 배터리가 방전되지 않았는지
- 받은 번호가 기본 번호인지, 이전 번호인지
- 보조키가 잠겨 있지 않은지
- 모터 소리만 나고 걸쇠가 안 빠지는지
이전 사람 번호가 남아 있다면 초기화가 필요할 수 있습니다. / 도저히 안 열리면 [현관문 개문](door-open.html) 안내를 먼저 보시고 전화 주세요.

# 신분 확인은 새집에서도 필요합니다
입주 직후에는 계약서나 우편물 등이 아직 정리되지 않은 경우가 많습니다. / 문을 열 때는 사시는 분인지 확인하는 절차를 건너뛰지 않습니다.
신분증, 주소가 나온 서류나 우편물, 관리사무소 확인 중 하나면 됩니다. / 신분증 주소가 아직 이전 주소라면 계약서나 입주 안내서를 함께 준비해 주세요.
확인이 어렵다면 방법을 전화로 먼저 같이 상의합니다.

# 비용은 작업 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 확인한 뒤 먼저 안내드립니다. / 동의하신 후에 시작하고, 끝내 못 열면 비용은 받지 않습니다.
초기화나 번호 등록처럼 간단한 작업인지, 부품이 필요한 일인지는 현장에서 보고 말씀드립니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
@ 입주 도어락 설정 도움

# 새로 도어락을 달고 싶다면
기존 도어락이 마음에 들지 않거나 오래된 제품이라면 입주를 계기로 바꿔 보는 것도 방법입니다. / 지문이나 카드 방식을 원하는지, 문 두께와 보조키 위치가 맞는지 먼저 확인해야 합니다.
[도어락 설치](doorlock-install.html) 안내에서 설치 전에 확인할 것들을 보실 수 있습니다. / 이미 있는 제품을 바꾸는 상황이라면 [도어락 교체](doorlock-replace.html)도 참고하세요.
고쳐서 쓸 수 있다면 교체는 권하지 않습니다. / 증상이 있으면 [도어락 수리](doorlock-repair.html)로 먼저 점검받을 수 있습니다.

# 입주 후 한 달 안에 해 두면 좋은 것
- 가족 모두 번호와 카드키로 한 번씩 열어 보기
- 여분 열쇠 위치를 정해 두기
- 도어락 모델명과 설명서 사진 보관
- 택배나 가사 도움을 받는다면 임시 번호 쓰는 법 익히기
작은 일 같아도 이런 정리가 되어 있으면 갑자기 문이 안 열리는 날에도 침착하게 움직일 수 있습니다. / 처음 한 달이 지나면 도어락이 몸에 익어 신경이 덜 쓰입니다.

# 고덕동 말고 평택 어디든 갑니다
고덕동은 물론 비전동, 세교동, 동삭동, 지산동과 읍 지역까지 다닙니다. / 평택 안이면 동네 상관없이 24시간 전화를 받습니다.
다니는 곳은 [평택 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다.
