# 지산동 현관문, 잠금 장치가 두 개인 집
지산동은 평택역과 송탄역 쪽으로 오가는 분들이 사는 주택가와 빌라가 이어진 동네입니다. / 현관문에 도어락과 보조키 열쇠가 따로 달린 집도 많아 문제가 생겼을 때 어느 쪽 탓인지 헷갈립니다.
이 글은 도어락과 보조키를 함께 쓰는 집에서 순서대로 점검하는 방법을 정리했습니다. / 직접 해 볼 수 있는 것과 [평택 출장열쇠](pyeongtaek.html)에 맡길 때를 나눠 적었습니다.
@ 지산동 현관문 도어락과 보조키 두 개 잠금

# 두 잠금 장치는 서로 다른 일을 합니다
도어락은 번호나 카드로 여는 장치이고, 보조키는 열쇠로 돌려 잠그는 별도 장치입니다. / 문을 닫을 때 도어락만 자동으로 잠기고 보조키는 손으로 돌려야 잠기는 구조가 많습니다.
그래서 문이 안 열릴 때는 어느 쪽이 잠겨 있는지부터 구분해야 합니다. / 이 구분만 해도 전화로 상황을 설명하기가 훨씬 쉬워집니다.

# 1단계 번호판 상태를 먼저 봅니다
번호판이 켜지는지, 눌렀을 때 소리가 나는지부터 확인하세요. / 아무 반응이 없으면 배터리, 소리는 나는데 안 열리면 다른 쪽 문제일 가능성이 있습니다.
- 손으로 덮었을 때 불이 들어오는지
- 번호를 누르면 삑 소리가 나는지
- 열림 소리 뒤에도 손잡이가 안 돌아가는지

가족 중 한 명이 보조키를 잠그고 먼저 나간 경우에도 같은 일이 생깁니다. / 나중에 온 사람은 번호가 맞아도 문이 안 열려 도어락만 의심하게 됩니다.
그래서 가족끼리 보조키를 쓰는 습관을 한 번 정해 두면 좋습니다. / 마지막에 나가는 사람이 잠그고 열쇠를 어디에 두는지 정해 두세요.
# 2단계 보조키가 잠겨 있지 않은지 확인
도어락이 열리는 소리가 났는데 문이 안 열리면 보조키가 잠긴 경우가 많습니다. / 외출할 때 습관처럼 보조키를 돌려 놓고 잊은 채 번호만 누르는 일이 잦습니다.
보조키 열쇠를 가지고 있다면 먼저 돌려 보세요. / 열쇠가 집 안에 있으면 도어락만으로는 열리지 않으니 그때는 연락 주세요.
@ 보조키 열쇠 구멍과 도어락 번호판 확인

문이 닫혀 있어도 걸쇠가 구멍에 반쯤만 들어간 경우가 있습니다. / 이때는 손잡이를 위로 들어 올리듯 돌리면 풀리기도 합니다.
경첩이 헐거워 문이 아래로 처졌다면 보조키 자리가 문틀과 어긋나기도 합니다. / 열쇠가 잘 안 돌아가는 이유가 여기에 있는 경우도 많습니다.
# 3단계 문을 살짝 밀면서 열어 보기
두 잠금 장치가 모두 풀렸는데도 문이 뻑뻑하면 문틀과 문이 서로 눌린 경우가 있습니다. / 손잡이를 돌리면서 문을 문틀 쪽으로 살짝 밀면 걸쇠가 풀리는 일도 있습니다.
이렇게 해서 열리면 문틀 처짐이나 경첩 헐거움을 의심해 볼 수 있습니다. / 이런 경우는 도어락이 아니라 [문 열기](door-open.html) 점검 항목에 가깝습니다.

# 4단계 열쇠가 안 돌아갈 때
보조키 열쇠를 넣었는데 안 돌아가면 열쇠 구멍 안쪽 문제일 수 있습니다. / 이때 억지로 돌리면 열쇠가 부러져 안에 남을 수 있으니 힘을 주지 마세요.
- 열쇠가 정확히 끝까지 들어가는지 확인
- 열쇠가 휘었거나 닳아서 헛도는 건 아닌지 확인
- 구멍에 이물질이 있는지 확인
이 단계에서 안 되면 멈추고 연락 주시는 편이 안전합니다.

# 하지 말아야 할 행동
급한 마음에 드라이버로 문틈을 벌리거나 잠금 장치에 기름을 뿌리는 분들이 있습니다. / 잘못 쓰면 먼지가 붙어 오히려 뻑뻑해지고 도어락 내부가 상할 수 있습니다.
문을 발로 차거나 세게 당기면 문틀이 틀어져 나중에 더 큰 수리가 필요해집니다. / 비밀번호를 여러 번 틀리면 입력이 잠시 막히니 서너 번 하고 멈추세요.

# 지산동에서 출장을 요청할 때 알려줄 것
지산동은 주택과 빌라가 많아 건물 이름보다 길 방향과 호수를 알려 주시는 것이 빠릅니다. / 평택역이나 송탄역 쪽으로 어느 방향인지도 같이 말씀해 주세요.
- 도어락과 보조키 중 어느 쪽이 안 열리는지
- 번호판 상태와 들리는 소리
- 집 안에 아이나 반려동물이 있는지
- 보조키 열쇠가 집 안에 있는지
도어락과 보조키 모양을 사진으로 보내 주시면 맞는 장비를 챙겨 갑니다.
@ 지산동 도어락 보조키 상태 사진 전달

신분 확인은 도어락과 보조키가 모두 달린 집에서 특히 중요합니다. / 잠금이 두 겹이라는 것은 그만큼 보안을 신경 쓰는 집이라는 뜻이기 때문입니다.
# 문 열기 전에 신분 확인을 합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
빌라처럼 관리사무소가 없는 곳이라면 우편물이나 계약서가 도움이 됩니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.

도어락만 바꿀지, 보조키까지 같이 손볼지는 문 상태를 본 뒤에 의견을 드립니다. / 둘 중 하나만 문제라면 그 부분만 손보는 쪽으로 안내합니다.
두 장치가 같은 문에 달려 있으면 서로 영향을 줄 때가 있어, 한쪽을 만지면 다른 쪽 작동도 같이 확인합니다. / 이 과정에서 달라지는 점은 작업 전에 먼저 말씀드립니다.
# 비용은 문 열기 전에 말씀드립니다
잠금 장치가 몇 개인지, 어떤 종류인지를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 두 장치를 모두 살리는 방향으로 고칩니다
도어락과 보조키 중 하나만 고장 났다면 그 부분만 손보는 것이 기본입니다. / 멀쩡한 장치까지 바꾸자고 하지 않습니다.
도어락만 문제라면 [도어락 수리](doorlock-repair.html)로 해결하는 경우가 많습니다. / 너무 오래돼서 고쳐 쓰기 어려우면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 열고 난 뒤 순서대로 다시 점검
문이 열리면 도어락과 보조키를 각각 잠그고 열어 보며 확인합니다. / 어느 쪽이 먼저 걸리는지, 문이 닫힐 때 걸쇠가 잘 들어가는지도 같이 봅니다.
비밀번호를 잊어서 연 경우라면 새 번호를 등록하고 기존 번호는 지웁니다. / 보조키 열쇠는 가진 개수를 한 번 세어 두세요.

- 외출할 때 보조키까지 잠갔는지 한 번씩 확인
- 보조키 열쇠를 도어락 카드와 따로 보관
- 도어락 배터리는 해가 바뀔 때쯤 교체
- 문이 덜 닫히면 경첩과 문틀 점검
도어락 번호는 알고 있어도 열쇠를 집에 두고 나오는 일이 잦습니다. / 열쇠 하나는 가방이나 믿을 수 있는 가족에게 따로 맡겨 두는 방법도 있습니다.

지산동 옆 송탄동, 서정동을 비롯해 평택 안이면 동네 상관없이 다닙니다. / 안중읍, 포승읍, 팽성읍, 청북읍도 갑니다.
평택 지역은 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문

? 열쇠를 집 안에 두고 나왔는데 열 수 있나요? | 상황에 따라 가능합니다. 신분 확인 후 진행합니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 보조키만 새로 맞추는 것도 되나요? | 네, 상태를 보고 열쇠나 장치 교체를 안내해 드립니다.
