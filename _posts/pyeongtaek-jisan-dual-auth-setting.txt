# 지산동 도어락, 번호와 카드를 같이 쓴다는 것
지산동은 평택역 쪽으로 오가는 분들이 많은 생활권입니다. / 요즘은 집 도어락도 번호와 카드를 함께 쓰는 방식이 늘어서 설정 문의가 많습니다.
이중 인증이라고 하면 어렵게 들리지만, 번호만으로 열리지 않고 카드나 태그를 한 번 더 대야 열리게 하는 방식입니다. / 한 가지를 잃어버려도 문이 그냥 열리지는 않게 하려는 목적입니다.
이 글은 지산동에서 번호와 카드를 함께 설정할 때 알아 둘 것과 잠겼을 때의 대처를 정리한 안내입니다. / 모든 도어락이 같은 방식은 아닙니다.

# 이중 인증이 필요한 집은 따로 있습니다
모든 집에 필요한 기능은 아닙니다. / 편리함이 줄어드는 대신 안전을 높이는 방식이기 때문입니다.
- 번호가 외부에 자주 노출되는 출입문
- 여러 사람이 드나드는 공간의 문
- 번호를 가족 밖으로 공유한 적이 있는 집
- 집을 오래 비우는 일이 잦은 집
이런 경우가 아니라면 번호 하나나 카드 하나만 쓰는 편이 오히려 낫습니다. / 필요한 만큼만 쓰는 것이 가장 좋습니다.
보안을 높이려다 오히려 가족이 매일 불편해지면 결국 기능을 끄고 쓰게 됩니다. / 끄고 쓰는 것은 처음부터 안 쓰는 것보다 못한 경우도 있습니다.
그래서 생활 방식에 맞는지를 먼저 따져 보는 것이 좋습니다. / 아이가 혼자 귀가하는 집이라면 특히 더 신중해야 합니다.

# 도어락마다 지원이 다릅니다
먼저 내 도어락이 이중 인증을 지원하는지 확인해야 합니다. / 설명서나 안쪽 덮개 안의 모델 표기를 보면 알 수 있습니다.
어떤 제품은 번호 입력 뒤 카드를 대는 순서가 정해져 있습니다. / 어떤 제품은 둘 중 아무 순서나 가능하거나, 아예 기능이 없기도 합니다.
기능이 없는 제품에 억지로 설정을 시도하면 오히려 오류가 날 수 있습니다. / 이럴 때는 모델 정보를 알려 주시면 가능 여부를 먼저 말씀드립니다.
설정 메뉴가 보이지 않으면 아예 지원하지 않는 것입니다. / 이럴 때 무리하게 버튼을 계속 누르면 설정이 초기화되기도 합니다.

# 설정 전에 준비할 것
설정 중에 도어락이 잠겨 버리는 일을 막으려면 준비가 필요합니다. / 아래 네 가지를 갖춰 두세요.
- 문이 열린 상태에서 시작하기
- 새 건전지 넣어 두기
- 등록할 카드 모두 손에 들기
- 마스터 번호 또는 관리자 번호 확인하기
문을 닫고 밖에서 하다가 설정이 꼬이면 못 들어가는 경우가 생깁니다. / 반드시 안쪽에서, 문을 열어 둔 채 하세요.

대부분 설정 모드에 들어가 카드를 하나씩 대는 방식입니다. / 등록이 끝나면 확인음이 납니다.
처음부터 카드를 여러 장 받았다면 전부 한 번에 등록하세요. / 나중에 하나만 따로 추가하기는 제품마다 방법이 달라 번거롭습니다.

# 번호와 카드의 순서를 정하기
이중 인증은 순서가 정해져 있는 제품이 많습니다. / 처음에는 가족 모두 순서를 헷갈립니다.
- 먼저 카드를 대고 번호를 누르는 방식
- 먼저 번호를 누르고 카드를 대는 방식
- 지정한 시간 안에 두 가지를 모두 해야 하는 방식
시간 제한이 있는 방식은 어르신이나 아이가 쓰기 어려울 수 있습니다. / 가족 구성에 맞춰 선택하는 것이 좋습니다.

# 가족이 있는 집에서 생기는 문제
이중 인증을 켜 두고 가족에게 알리지 않으면 반드시 문제가 생깁니다. / 번호는 아는데 카드가 없어서 못 들어가는 일입니다.
가족 한 사람마다 카드가 한 장씩은 있어야 합니다. / 아이는 가방에 달아 두는 형태를 많이 씁니다.
손님이나 돌봄 인력에게 임시로 열어 줄 일이 있다면 이중 인증은 불편할 수 있습니다. / 이런 집은 임시 번호를 쓰는 방법을 따로 상의하시면 좋습니다.

카드를 잃어버렸을 때를 대비해 예비 카드를 따로 보관해 두세요. / 그 한 장이 밤에 큰 힘이 됩니다.

# 카드를 잃어버렸다면
이중 인증 상태에서 카드를 잃어버렸다면 번호만으로는 열리지 않을 수 있습니다. / 가장 먼저 해야 할 일은 분실한 카드를 도어락에서 삭제하는 것입니다.
삭제는 안쪽에서 설정 모드로 들어가 하는 경우가 많습니다. / 문이 닫힌 채라면 먼저 문을 열어야 하는 상황입니다.
이때는 도어락을 임의로 분해하지 마세요. / 안쪽 설정 모드까지 가려면 먼저 문을 상하지 않게 열어야 합니다.
문이 열린 뒤에는 분실 카드를 삭제하고 새 카드를 등록해 두면 안심하고 쓸 수 있습니다.
카드 분실에 대한 더 자세한 안내는 다른 글에도 적어 두었으니 [출장 안내](key-call.html)에서 전화 요령을 먼저 보셔도 됩니다.

# 설정했는데 문이 안 열릴 때
설정이 끝난 직후에 문이 안 열리면 조급해지기 쉽습니다. / 먼저 순서와 시간 제한을 다시 떠올려 보세요.
설정 중에는 문을 열어 둔 채 가족이 바깥에서 한 번씩 시험해 보면 가장 정확합니다. / 문이 닫힌 뒤 처음 시험하는 일은 피하세요.
카드를 대는 위치가 맞는지도 봅니다. / 손잡이 쪽이 아니라 번호판 근처 특정 구역에 대야 인식되는 제품이 있습니다.
여러 번 틀리면 도어락이 잠시 입력을 막을 수 있습니다. / 몇 번 해도 안 되면 멈추고 전화 주세요.
입력이 막혔을 때는 보통 몇 분 기다리면 풀립니다. / 그 사이 번호를 계속 누르면 막힌 시간이 늘어나기도 하니 손을 떼고 기다리세요.
@ 도어락이 인증을 못 받아 닫혀 있는 모습

# 출장열쇠가 하는 일
이미 문이 잠긴 상태에서는 우선 비파손 방식으로 문을 엽니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나를 준비해 주세요.
문이 열린 뒤에는 설정을 함께 정리합니다. / 이중 인증을 계속 쓸지, 단순하게 바꿀지는 사시는 분이 정하시면 됩니다.
[도어락 설치](doorlock-install.html)와 [도어락 수리](doorlock-repair.html) 안내에서 제품별 차이를 확인할 수 있습니다.

# 비용 안내 방식
작업 전에 상황을 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.
