# 열쇠가 없다는 걸 문 앞에서 알았을 때
송탄역 쪽에서 퇴근해 지산동 집 앞에 도착했는데 주머니에 열쇠가 없다면 순간 머릿속이 하얘집니다. / 가방을 뒤지고 주머니를 몇 번이나 만져 봐도 보이지 않으면 시간은 더디게 갑니다.
열쇠를 잃어버린 경우와 집 안에 두고 나온 경우는 비슷해 보여도 대처가 조금 다릅니다. / 어느 쪽인지에 따라 바로 해야 할 일이 달라지기 때문입니다.
이 글은 지산동에서 열쇠 문제로 문이 잠겼을 때 차분히 확인할 순서와 [평택 출장열쇠](pyeongtaek.html)를 부르는 방법을 정리한 것입니다.
@ 지산동 열쇠 분실 후 현관 앞

# 먼저 숨을 고르고 마지막 기억을 되짚어 보세요
열쇠가 어디 있는지 정리가 되지 않을 때는 마지막으로 열쇠를 쓴 곳을 떠올려 보세요. / 오늘 아침 문을 잠글 때 가방에 넣었는지 주머니에 넣었는지 기억나는 경우도 있습니다.
- 오늘 입은 겉옷과 바지 주머니를 모두 확인
- 가방 안쪽 작은 주머니와 지갑 사이
- 차 안이나 회사 책상 서랍
- 집 안에 두고 나온 게 확실한지 가족에게 확인
가족이 집 안에 있다면 전화로 문을 열어 달라고 하면 가장 간단합니다.

# 집 안에 있는지 밖에서 잃어버렸는지 구분하기
둘은 불안의 종류가 다릅니다. / 집 안에 두고 나온 열쇠는 문만 열리면 찾지만, 밖에서 잃어버린 열쇠는 누군가 주웠을 수 있다는 걱정이 남습니다.
밖에서 잃어버린 경우라면 문을 연 뒤 열쇠 구멍 자체를 바꾸는 것도 한 번 생각해 볼 만합니다. / 번호 방식 도어락이라면 비밀번호를 새로 정하는 것으로 충분합니다.
집 안에 두고 나온 게 확실하다면 문만 열고 그대로 쓰시면 됩니다.

# 열쇠가 없어도 번호로 열리는 도어락이라면
번호판이 달린 도어락이라면 열쇠 없이 번호로 열 수 있습니다. / 평소 열쇠를 쓰지 않아 비상용으로만 갖고 계신 분이 많습니다.
번호가 기억나지 않거나 건전지가 방전됐다면 이 경우는 따로 정리했습니다. / 번호판이 꺼졌을 때는 바깥쪽 비상 단자에 9V 건전지를 대 보는 방법도 있습니다.
번호도 안 되고 건전지도 소용없다면 그때 전화 주시면 됩니다.
@ 번호판 도어락 비상 전원 확인

# 열쇠로만 여는 잠금장치라면
열쇠 구멍만 있는 옛날 방식 문이라면 열쇠가 없을 때 다른 선택지가 많지 않습니다. / 이럴 때는 억지로 문을 당기거나 구멍에 이물질을 넣지 말고 그대로 전화 주세요.
열쇠 구멍에 도구를 넣어 이리저리 돌리다 부러지면 상황이 복잡해집니다. / 구멍 안에 뭔가 박히면 열기 어려워지고 시간도 더 걸립니다.
열고 난 뒤에는 새로 열쇠를 만들거나 잠금장치를 바꾸는 방법이 있습니다. / 상황에 맞는 선택지를 현장에서 설명드립니다. / 열쇠를 새로 맞추는 일은 문을 열고 난 뒤에 차분히 정하셔도 늦지 않습니다.

열쇠를 잃어버린 시각이 밤이라면 더 서두르고 싶어집니다. / 그래도 날이 밝기를 기다릴 필요는 없습니다. 한밤이든 새벽이든 전화를 받습니다.
기다리는 동안은 따뜻하고 안전한 곳에서 대기하시고, 도착 예상 시간을 말씀드리면 그때에 맞춰 집 앞에서 만나시면 됩니다.

# 급해도 이런 건 하지 마세요
- 창문이나 베란다로 넘어 들어가려는 것
- 이웃집 난간을 타고 이동하는 것
- 문을 발로 차거나 몸으로 밀어붙이는 것
- 인터넷에 도는 방법을 따라 하다 문을 상하게 하는 것
특히 높은 층에서 난간을 타는 일은 열쇠 분실과 비교할 수 없는 큰 사고로 이어질 수 있습니다. / 천천히 기다리는 편이 훨씬 안전합니다.

# 전화하실 때 알려주시면 좋은 내용
- 지산동 위치와 가까운 곳(송탄역 방향 등)
- 도어락 모양과 번호판 유무 사진
- 열쇠를 어디서 어떻게 잃었는지
- 집 안에 사람이나 반려동물이 있는지
- 열쇠 말고 번호로도 열리는지
정보가 많을수록 필요한 장비를 챙겨 가기 좋습니다. / 열쇠를 잃어버린 장소가 집 근처라면 그 근처를 먼저 한 바퀴 둘러보시는 것도 방법입니다. / 정확한 정보가 없어도 괜찮으니 일단 전화 주세요.

# 도착하면 사시는 분인지 먼저 확인합니다
열쇠 없이 문을 여는 일이라 사시는 분이 맞는지 꼼꼼히 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
열쇠도 신분증도 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁해 두세요. / 확인이 어려우면 작업을 할 수 없습니다.
@ 지산동 출장열쇠 신분 확인 절차

# 비용은 열기 전에 먼저 말씀드립니다
문 상태와 잠금장치를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용은 없고, 부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문을 상하지 않게 여는 방법부터 시작합니다
열쇠가 없을 때도 문과 잠금장치를 상하지 않는 쪽을 먼저 택합니다. / 열린 뒤에도 문이 이전처럼 쓰이는 것이 목표입니다.
방법은 잠금장치 종류와 문 상태에 따라 달라집니다. / 자세한 설명은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 열고 난 뒤 열쇠 문제를 정리하는 방법
- 잃어버린 열쇠를 다른 사람이 주웠을 수 있다면 잠금장치 교체나 번호 변경
- 단순히 집 안에 둔 것이라면 그대로 사용
- 예비 열쇠를 하나 더 만들어 가족이 나눠 가지기
- 번호 방식이라면 새 번호를 등록해 열쇠 의존도 줄이기
잠금장치를 아예 바꿔야 하는지는 상황에 따라 다릅니다. / 고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로, 바꾸는 편이 낫다면 [도어락 교체](doorlock-replace.html)로 설명드립니다.

# 열쇠를 다시 잃어버리지 않는 습관
열쇠를 잃어버리는 일은 대개 정해진 순간에 생깁니다. / 현관 문을 열고 들어오면서 잠깐 어딘가에 두는 순간입니다.
- 현관 안쪽 같은 자리에 열쇠를 거는 습관 들이기
- 열쇠고리를 눈에 띄는 색이나 큰 모양으로 바꾸기
- 예비 열쇠를 믿을 만한 가족에게 보관
- 번호 방식 도어락이라면 열쇠 없이 다니는 연습
열쇠가 없어도 집에 들어올 수 있게 해 두면 마음이 훨씬 편합니다.
열쇠를 문 밖 화분이나 우편함 속에 숨겨 두는 방법은 편해 보여도 권하지 않습니다. / 누구나 먼저 찾아보는 곳이라 오히려 안전에 허점이 됩니다.
믿을 만한 가족이나 이웃에게 맡겨 두는 것이 가장 낫습니다.

# 지산동 밖 평택 어디든 갑니다
지산동과 가까운 송탄동, 서정동, 평택역, 지제역 주변까지 평택 전역을 다닙니다. / 평택 안이라면 24시간 출동합니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 상관없이 전화 주세요.
