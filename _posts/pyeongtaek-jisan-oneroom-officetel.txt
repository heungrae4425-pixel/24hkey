# 혼자 사는 집일수록 문 앞에서 더 막막합니다
지산동은 송탄역과 가까운 곳에 원룸과 다세대, 오피스텔이 함께 모여 있는 생활권입니다. / 직장이나 학교 때문에 혼자 사는 분들이 많고 가족이 가까이 없는 경우도 흔합니다.
퇴근길에 번호판이 꺼졌거나 열쇠를 안에 두고 나왔는데 곁에 도와줄 사람이 없으면 시간이 더 길게 느껴집니다. / 연락할 곳도, 열쇠를 갖다 줄 사람도 마땅치 않기 때문입니다.
이 글은 원룸과 오피스텔처럼 건물에 여러 세대가 사는 곳에서 출입문이 잠겼을 때의 대처를 정리했습니다. / 건물 관리인이 있는지, 공동 현관이 있는지 같은 원룸 특유의 사정을 중심으로 적었습니다.
@ 지산동 원룸 오피스텔 출입문 잠김

# 먼저 어느 문이 막혔는지 구분하세요
원룸과 오피스텔은 문이 두 겹인 경우가 많습니다. / 건물 입구의 공동 현관과 내 방 앞의 개인 현관이 따로 있는 구조입니다.
- 건물 공동 현관이 안 열리는 경우
- 내 방 현관문이 안 열리는 경우
- 둘 다 안 열리는 경우
공동 현관은 건물주나 관리인이 관리하는 경우가 많아 출장열쇠보다 먼저 그쪽에 연락하는 편이 빠를 수 있습니다. / 내 방 현관문이라면 아래 순서로 진행하면 됩니다.

# 집주인과 관리인에게 먼저 연락할 일
원룸은 건물주가 마스터키나 여분 열쇠를 가지고 있는 경우가 있습니다. / 계약서에 적힌 연락처나 건물 안내문에서 관리 담당자를 찾아보세요.
오피스텔은 관리사무소나 안내 데스크가 있는 곳이 많습니다. / 안내 데스크에 상황을 말하면 세대 확인을 해 주거나 보관 열쇠를 안내해 주는 경우도 있습니다.
다만 늦은 시간이라 연락이 닿지 않거나 여분이 없다면 그때 전화 주시면 됩니다. / 건물주 연락을 기다리다 몇 시간씩 밖에 서 계시는 것보다 낫습니다.
계약서 사진을 휴대폰에 저장해 두면 이런 때 큰 도움이 됩니다.

# 원룸 도어락에서 자주 일어나는 일
원룸의 도어락은 여러 입주자가 거쳐 가며 번호가 바뀌고 설정이 섞이는 일이 있습니다. / 배터리를 오래 안 갈았거나 입주자가 바뀐 뒤 초기 설정이 그대로인 경우도 있습니다.
- 입주 때 받은 번호와 현재 번호가 다른 경우
- 배터리가 오래 되어 번호판이 꺼진 경우
- 열쇠를 안에 두고 나와 자동으로 잠긴 경우
- 센서가 낡아 지문이나 카드가 안 읽히는 경우
자동으로 잠기는 도어락은 문이 닫히는 순간 걸쇠가 걸립니다. / 쓰레기를 버리러 나오거나 택배를 받으러 나갈 때 열쇠나 휴대폰을 꼭 챙겨 나가세요.
@ 평택 지산동 원룸 도어락 배터리 번호 확인

# 오피스텔은 방범 기능이 조금 더 있습니다
오피스텔은 공동 현관과 각 호실 사이에 카드키나 비밀번호 구조가 이중으로 있는 경우가 많습니다. / 호실 문이 잠겨도 건물 출입이 되는 사람이 따로 있는지 먼저 확인하세요.
관리 업체가 설정한 도어락이라면 임의로 만지면 규정에 어긋날 수 있습니다. / 이럴 땐 관리 측에 먼저 알리고 작업 허용 여부를 확인해야 합니다.
세입자가 도어락을 바꾸거나 설정을 건드릴 수 있는지는 계약 조건에 따라 다릅니다. / 계약 내용이 애매하면 건물주에게 먼저 문의하시는 것이 안전합니다.

# 신분 확인은 더 꼼꼼하게 합니다
혼자 사는 집일수록 문을 여는 일에 신중해야 합니다. / 신분증 주소, 주소가 보이는 우편물, 관리사무소 확인 중 하나로 사시는 분임을 확인합니다.
원룸은 주소가 호수까지 나오는 우편물이 없는 경우도 있습니다. / 이럴 땐 임대차계약서 사진이나 공과금 고지서, 건물 관리인 확인이 도움이 됩니다.
신분증이 방 안에 있다면 건물주나 관리인에게 연락해 세대를 확인받는 방법이 있습니다. / 확인이 어려우면 작업을 할 수 없는 점 양해 부탁드립니다.

# 전화하실 때 알려 주면 빠른 것
원룸 건물은 외관이 비슷해서 위치를 정확히 말씀해 주셔야 합니다. / 지산동 안의 건물 이름이나 번지, 층과 호수를 알려 주세요.
- 송탄역에서 어느 방향인지, 눈에 띄는 가게나 건물
- 공동 현관 비밀번호가 있는지, 건물주 연락이 닿는지
- 도어락 모양과 번호판 상태
- 열쇠가 안에 있는지, 번호를 모르는 건지
사진을 문자로 보내 주시면 장비를 맞추기 쉽습니다. / 방 안에 반려동물이나 켜 둔 전기 제품이 있으면 꼭 말씀해 주세요.

# 기다리는 동안 안전하게 있는 법
밤늦게 혼자 건물 복도에서 기다리는 것이 불안하다면 밝은 곳이나 편의점에서 기다려도 됩니다. / 도착 전에 전화로 위치를 확인할 테니 편한 곳에서 만나면 됩니다.
번호판이 꺼진 경우라면 근처 편의점에서 9V 건전지를 구해 비상 단자에 대 보는 방법이 있습니다. / 열리면 방에 들어가 안쪽 배터리를 새것으로 바꿔 주세요.
문손잡이를 세게 당기거나 문틈에 도구를 넣는 시도는 피하세요. / 벽이 얇은 원룸에서는 이웃에게도 소리가 크게 들립니다.
@ 지산동 출장열쇠 원룸 혼자 사는 집 도어락

# 비용은 열기 전에, 못 열면 받지 않습니다
문과 도어락 상태를 확인한 뒤 열기 전에 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고 아니면 돌아갑니다.
끝내 문을 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우 임대 주택이라면 누가 부담하는지는 계약에 따라 다르니 먼저 건물주와 이야기해 보시는 것을 권합니다. / 자세한 진행 방식은 [이용안내](guide.html)에서 보실 수 있습니다.

# 열고 난 뒤 챙길 것
문이 열리면 도어락이 다시 열리고 잠기는지 확인합니다. / 배터리가 원인이면 새것으로 모두 바꿉니다.
번호를 모르는 문제였다면 새 번호를 등록하는 것까지 도와드립니다. / 전 입주자 번호가 남아 있을 수 있어 새로 등록하는 것이 안전합니다.
고장이 반복되면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 임대인 동의가 필요한 교체는 그다음에 [도어락 교체](doorlock-replace.html)를 상의하면 됩니다.
문을 여는 방식은 [현관문 개문](door-open.html) 페이지에 있습니다.

# 문 앞에서 막히지 않으려면
혼자 사는 집은 작은 습관이 큰 도움이 됩니다. / 아래 정도만 지켜도 한밤중에 밖에 서 있는 일이 크게 줄어듭니다.
- 휴대폰과 열쇠를 꼭 챙기고 나가기
- 집 밖에 여분 열쇠를 숨기지 말고 믿을 사람에게 맡기기
- 배터리는 반년마다 점검하고 경고음이 나면 바로 교체
- 건물주와 관리인 연락처를 휴대폰에 저장
- 계약서와 신분증 사진을 따로 저장
특히 여분 열쇠는 [열쇠 출장](key-call.html)으로 미리 만들어 가까운 지인에게 맡겨 두면 든든합니다.

# 지산동에서 평택 전역으로
지산동 가까운 송탄동, 서정동, 비전동, 세교동도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [평택 출장열쇠](pyeongtaek.html)에서 확인하실 수 있습니다.

? 공동 현관도 열어 주나요? | 건물 관리 주체의 동의가 필요하니 관리인 확인 후 안내해 드립니다.
