# 지산동 창문 잠금, 헐거워진 걸 방치하면 생기는 일
지산동은 송탄역 방향 생활권에 주택과 빌라가 모여 있는 동네입니다. / 환기를 자주 하는 집이 많아 창문을 열고 닫는 횟수도 그만큼 많습니다.
창문 잠금장치는 현관 도어락처럼 눈에 띄지 않아서 헐거워져도 오래 방치되기 쉽습니다. / 어느 날 잠금 손잡이가 헛돌거나 창이 끝까지 닫히지 않아서야 알게 됩니다.
이 글은 지산동에서 창문 잠금장치가 헐거울 때 어디를 어떤 순서로 보면 좋은지 정리했습니다. / 열쇠집이 도와드릴 수 있는 범위도 함께 적었습니다.
@ 지산동 창문 잠금장치 크레센트 점검

# 창문 잠금장치는 이렇게 생겼습니다
창문마다 잠금 방식이 조금씩 다릅니다. / 어떤 종류인지 알면 어디가 헐거워졌는지 짐작할 수 있습니다.
- 초승달 모양 갈고리를 돌려 거는 크레센트 방식
- 창틀에 달린 고리에 걸쇠를 올려 잠그는 방식
- 창 가장자리에 달린 보조 잠금이나 안전핀 방식
- 방충망에 달린 작은 걸쇠
크레센트는 창틀 한쪽에 달린 받이에 갈고리가 걸리면서 창을 눌러 줍니다. / 이 두 부품이 맞지 않으면 닫아도 창이 덜렁거립니다.

# 헐거워졌다는 신호
잠금이 헐거워지면 몇 가지 징후가 먼저 나타납니다. / 아래에 해당하는 것이 있는지 확인해 보세요.
- 손잡이를 돌릴 때 걸리는 느낌 없이 헛도는 것
- 잠근 뒤에도 창이 앞뒤로 덜컹거리는 것
- 바람 부는 날 창에서 소리가 나는 것
- 잠금 손잡이가 위아래로 흔들리는 것
- 갈고리가 받이에 닿지 않고 비껴가는 것
이런 증상이 하나라도 있다면 잠금이 제 역할을 못하고 있을 가능성이 큽니다. / 방치할수록 창틀과 잠금 부품이 더 어긋납니다.

# 가장 흔한 원인, 나사 풀림
창문은 열고 닫을 때마다 작은 진동을 받습니다. / 이 진동에 크레센트를 고정하는 나사가 조금씩 풀립니다.
나사가 풀리면 부품이 기울어서 갈고리가 받이에 정확히 걸리지 않습니다. / 먼저 맞는 크기의 드라이버로 나사를 조여 보세요.
너무 세게 조이면 나사 구멍이 닳아 오히려 헛돌게 됩니다. / 멈추는 느낌이 오면 거기서 그치는 것이 좋습니다.
@ 지산동 창문 크레센트 나사 조이기

# 걸림 위치가 맞지 않을 때
나사를 조여도 창이 흔들린다면 갈고리와 받이의 높이가 어긋난 것일 수 있습니다. / 창틀 하단 바퀴가 닳아서 창이 처졌을 때 자주 생깁니다.
창을 닫은 상태에서 갈고리가 받이의 어느 쪽에 닿는지 보세요. / 위로 치우치면 창이 처진 것이고, 아래로 치우치면 창이 들린 것입니다.
바퀴 높이를 맞추는 조절 나사가 창 아래 모서리에 있는 모델도 있습니다. / 있다면 아주 조금씩 돌려서 높이를 맞추고, 돌릴 때마다 다시 잠가 봅니다.

# 직접 하지 않는 편이 좋은 것
창문 부품은 얇고 깨지기 쉽습니다. / 아래는 피해 주세요.
- 크레센트를 통째로 억지로 빼기
- 유리와 가까운 곳에 센 힘으로 망치질하기
- 접착제를 부품에 바르기
- 방충망 프레임을 힘으로 꺾어 열기
- 높은 층 창문을 몸을 내밀고 작업하기
특히 높은 층에서는 안전이 가장 먼저입니다. / 위험하다고 느껴지면 직접 하지 말고 도움을 청하세요.

# 환기와 방범을 같이 챙기려면
여름과 가을에는 창을 열어 두는 시간이 길어집니다. / 잠금이 헐거우면 열어 둔 채 고정하는 보조 장치가 제 역할을 못 합니다.
창을 조금만 열고 고정하는 보조 걸쇠가 있다면 같이 점검해 보세요. / 한 칸씩 걸리는지, 흔들리면 빠지지 않는지 확인합니다.
외출할 때는 창을 닫고 잠그는 습관이 가장 기본입니다. / 지나친 걱정은 필요 없지만 잠금이 제대로 작동하는지는 한 번씩 보시길 권합니다.
비 오는 날에는 창틀에 물이 고이지 않는지도 같이 봐 주세요. / 물기가 잠금 부품에 오래 닿으면 녹이 슬어 뻑뻑해지기 쉽습니다.
환기를 마친 뒤에는 잠금 손잡이를 끝까지 돌려 갈고리가 받이에 완전히 들어갔는지 확인하는 것이 좋습니다. / 반쯤 걸린 상태로 두면 바람에 창이 흔들려 부품이 더 빨리 닳습니다.

# 열쇠집이 창문 잠금을 도와드리는 경우
열쇠집이라고 현관만 다루지는 않습니다. / 창문과 방충망 잠금, 작은 문 잠금도 상태를 보고 말씀드립니다.
- 크레센트가 부러졌거나 갈고리가 닳은 경우
- 받이가 창틀에서 떨어져 나간 경우
- 열쇠가 있는 창문 잠금의 열쇠를 잃어버린 경우
- 잠금이 걸린 채 풀리지 않는 경우
부품 규격이 다양해서 사진을 먼저 보내 주시면 맞는 것을 준비하기 쉽습니다. / 유리나 창틀 자체가 상한 경우는 창호 업체가 맞는 쪽이니 솔직히 안내드립니다.

# 전화하실 때 알려 주실 것
창문은 모양이 제각각이라 설명이 중요합니다. / 아래만 알려 주셔도 충분합니다.
- 지산동 내 대략적인 위치
- 어느 창인지(거실 큰 창, 방 창, 베란다 창 등)
- 잠금 손잡이 모양과 증상
- 열쇠 구멍 유무
- 지금 창이 열려 있는지 닫혀 있는지
사진을 가까이서 찍어 보내 주세요. / 부품 이름과 규격을 알아보기 쉽습니다.

# 사시는 분인지 확인하는 절차
집에 방문하는 일이라 먼저 신분 확인을 합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
세입자는 부품을 바꾸기 전에 집주인에게 알리는 것이 좋습니다. / 법적인 판단은 하지 않고 확인만 도와드립니다.
확인이 어려우면 작업이 어려운 점 양해 부탁드립니다. / 이웃과 집을 위한 절차입니다.

# 비용은 작업 전에 먼저 말씀드립니다
상태를 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
창문 잠금이 아니라 문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
@ 지산동 창문 잠금 부품 교체 작업

# 현관과 창문을 같이 점검하면
출장 온 김에 현관 도어락 상태도 함께 보고 싶다고 하시는 분이 많습니다. / 배터리와 걸쇠, 문틀 상태 정도는 같이 봐 드립니다.
도어락이 이상하면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 새로 달 계획이 있다면 [도어락 설치](doorlock-install.html)도 참고해 주세요.
문이 안 열려서 부르시는 경우는 [현관문 개문](door-open.html) 순서대로 진행합니다. / 필요한 것만 하는 것이 원칙입니다.

# 지산동 말고 평택 어디든 갑니다
지산동 주변 송탄동, 서정동, 비전동, 세교동은 물론 안중읍, 포승읍, 팽성읍, 청북읍도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
평택에서 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
@ 지산동 24시 출장열쇠 창문 잠금
