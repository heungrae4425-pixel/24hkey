# 팽성읍 도어락, 건전지를 갈았는데도 안 켜진다면
팽성읍은 평택역이나 송탄역 쪽 도심에서 조금 떨어진 생활권이라, 도어락이 말썽이면 가까운 가게에서 해결하기 어렵다는 이야기를 자주 듣습니다. / 새 건전지를 넣었는데도 번호판이 켜지지 않으면 접점 부식을 의심해 볼 만합니다.
이 글은 오래 쓴 건전지에서 액이 새어 배터리 칸 접점이 하얗게 또는 푸르게 변했을 때의 확인 순서입니다. / 닦아서 살릴 수 있는 경우와 [평택 출장열쇠](pyeongtaek.html)를 부르는 편이 나은 경우를 나누어 적었습니다.
@ 팽성읍 도어락 배터리 칸 접점 부식 모습

# 누액이 생기는 이유
건전지는 오래 쓰거나 다 닳은 채 방치되면 안의 액이 새어 나옵니다. / 특히 서로 다른 종류나 새것과 헌것을 섞어 쓰면 더 쉽게 샙니다.
도어락은 열고 닫을 때마다 전류가 흐르다 멈추기를 반복해서 건전지에 부담이 큽니다. / 배터리 칸이 오래 닫혀 있으면 누액을 알아채기도 어렵습니다.
한여름 열기나 장마철 습기가 더해지면 접점이 더 빨리 부식됩니다.

# 접점이 부식됐는지 보는 방법
배터리 덮개를 열었을 때 건전지 끝이나 금속 판에 가루가 붙어 있다면 의심해야 합니다. / 흰색이나 청록색 가루, 끈적한 막이 대표적인 모습입니다.
- 건전지 끝에 하얀 가루가 붙어 있는지
- 금속 판 접점이 검게 변했는지
- 건전지를 빼기 힘들 정도로 붙어 있는지
- 냄새가 시큼한지
이 중 하나라도 해당하면 전류가 제대로 흐르지 못하는 상태입니다. / 이때는 새 건전지를 넣어도 번호판이 켜지지 않습니다.

# 만지기 전에 꼭 지킬 것
누액은 피부에 닿으면 따가울 수 있고 오래 두면 배터리 칸 플라스틱까지 상하게 하니 맨손으로 만지지 마세요. / 장갑을 끼거나 휴지로 감싸서 건전지를 꺼내는 편이 안전합니다.
눈이나 입에 닿지 않게 하고, 닿았다면 깨끗한 물로 충분히 씻어 주세요. / 어린 아이와 반려동물이 근처에 오지 않게 해 두는 것도 좋습니다.
꺼낸 건전지는 일반 쓰레기로 아무렇게나 버리지 말고 폐건전지 수거함에 모아 두세요.

# 직접 닦아볼 때의 순서
가벼운 정도라면 마른 천이나 면봉으로 가루를 걷어낼 수 있습니다. / 물을 직접 붓거나 금속 도구로 긁는 것은 피해 주세요.
- 건전지를 모두 빼고 전원이 완전히 꺼진 상태에서 시작하기
- 마른 면봉으로 가루를 조심스럽게 털어내기
- 식초를 아주 소량 묻힌 면봉으로 닦은 뒤 마른 면봉으로 다시 닦기
- 완전히 마를 때까지 기다린 뒤 새 건전지 넣기
식초가 안쪽 회로로 흘러들면 오히려 상태가 나빠지니 양을 최소로 줄이세요. / 이 방법이 어렵게 느껴지면 무리하지 마세요.
@ 팽성읍 면봉으로 접점 가루 닦아내는 작업

# 닦아도 안 켜지는 경우
접점이 깊게 부식돼 금속이 얇아지거나 떨어져 나갔다면 닦아서는 돌아오지 않습니다. / 누액이 회로 기판까지 흘러들었을 가능성도 있습니다.
이 경우는 번호판이 켜지지 않거나, 켜졌다가 곧바로 꺼지기도 합니다. / 억지로 건전지를 눌러 끼우는 건 피해 주세요.
이 단계에서 문까지 잠겨 있다면 [도어락 수리](doorlock-repair.html)가 필요한지 직접 보고 판단해야 합니다.

# 문이 잠긴 채 부식이 발견됐다면
배터리 칸이 문 안쪽에 있어 문이 잠겨 있으면 건전지 상태를 볼 수 없습니다. / 바깥에서는 비상 단자에 9V 건전지를 대는 방법을 시도해 보세요.
접점이 부식된 도어락이라도 비상 단자는 따로 연결돼 있어서 반응이 오는 경우가 있습니다. / 반응이 없다면 그때는 전화를 주시는 게 낫습니다.
손잡이를 세게 흔들거나 문틈을 벌리는 건 도어락을 더 상하게 합니다.

# 팽성읍에서 전화하실 때 알려주면 좋은 것
읍내와 외곽이 넓게 이어져 있어 도착 위치를 정확히 알려주셔야 합니다. / 가까운 큰길이나 건물 방향을 먼저 말씀해 주세요.
- 현재 위치와 호수
- 번호판이 아예 안 켜지는지
- 비상 단자에 건전지를 대 봤는지
- 배터리 칸에서 가루나 냄새를 봤는지
도어락과 배터리 칸 사진을 보내 주시면 챙길 장비를 고르기 쉽습니다.

# 신분 확인과 비용, 문 열기 전에 먼저
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로울 수 있지만 모두를 위한 절차입니다. / 신분증이 집 안에 있으면 관리사무소에 세대 확인을 부탁해 주세요.

도어락 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열린 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 한다면 바꾸기 전에 먼저 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 문은 이렇게 상하지 않게 엽니다
배터리 접점이 망가진 도어락도 외관이 상하지 않게 여는 방법부터 시도합니다. / 문과 도어락 모두 가능하면 그대로 두는 것이 우선입니다.
작업 중 교체가 필요해 보이면 손대기 전에 먼저 말씀드립니다.
방식은 [현관문 개문](door-open.html) 페이지에도 정리해 두었습니다.
@ 팽성읍 출장열쇠 도어락 비파손 개문

# 열고 난 뒤 접점과 도어락 점검
문이 열리면 접점 상태를 보고 닦아서 쓸 수 있는지 판단합니다. / 닦아서 쓸 수 있으면 교체를 권하지 않습니다.
배터리 칸 덮개 안쪽에 물기가 맺혀 있었다면 그 원인도 함께 봅니다. / 같은 자리에서 다시 부식되지 않게 습기가 들어오는 틈이 없는지 확인합니다.
접점 부품이 떨어졌거나 기판이 상했다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 그 경우에도 먼저 보여드리고 동의를 받은 뒤 진행합니다.
새 건전지를 넣은 뒤에는 번호 입력과 잠금, 해제를 여러 번 확인합니다.

# 누액을 막는 관리 습관
- 다 닳은 건전지를 오래 그대로 두지 않기
- 새것과 헌것, 다른 종류를 섞지 않기
- 해가 바뀔 때쯤 한꺼번에 전부 교체하기
- 습기가 많은 철에는 배터리 칸 덮개가 잘 닫혔는지 보기
- 오래 비울 때는 교체 날짜를 적어 두기
경고음이 나면 그날 바로 바꾸는 습관이 가장 효과가 큽니다. / 평소에 덮개를 한 번씩 열어 상태를 보는 것도 방법입니다.

# 팽성읍 말고 평택 어디든 갑니다
읍 지역은 거리가 있어 출발 전에 위치와 상태를 먼저 들어야 도착이 빠릅니다. / 사진이 있으면 현장에서 부품을 찾는 시간도 줄어듭니다.
팽성읍 옆 안중읍, 포승읍, 청북읍과 고덕동, 비전동, 송탄동도 다닙니다. / 평택 안이면 24시간 출동합니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에서 볼 수 있고, 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
