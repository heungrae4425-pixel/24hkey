# 잠금 손잡이가 말을 안 듣는 날
팽성읍은 읍내 주택가와 단독, 연립이 섞여 있어 집마다 문의 나이와 모양이 제각각입니다. / 평택역까지 나가는 길이 먼 분들은 집에서 문 때문에 막히면 더 난감해집니다.
현관 안쪽에서 돌려 잠그는 손잡이가 뻑뻑하거나 아예 헛돌면 문을 잠글 수도 열 수도 없게 됩니다. / 이 글은 그 손잡이가 말을 안 들을 때 원인을 구분하고 무리하지 않고 푸는 순서를 정리했습니다.
도움이 필요하면 [평택 출장열쇠](pyeongtaek.html) 안내를 참고해 연락 주세요.
@ 팽성읍 현관 안쪽 잠금 손잡이

# 안쪽 잠금 손잡이란 무엇인가
문 안쪽에 달려 손가락으로 돌려 잠그고 푸는 작은 손잡이를 말합니다. / 도어락 안쪽 몸체에 붙은 것도 있고 문에 따로 달린 보조키 형태도 있습니다.
돌리면 안쪽의 막대가 움직여 문을 고정하는 구조라, 이 부분이 고장 나면 잠금 상태와 손잡이 위치가 어긋납니다. / 겉보기에는 멀쩡한데 안쪽이 닳았거나 풀렸다면 증상이 갑자기 나타나기도 합니다.
오래된 집일수록 매일 쓰던 부품이 닳아 어느 날 한꺼번에 드러나곤 합니다. / 손잡이가 평소보다 유난히 가볍거나 무겁다고 느껴졌다면 그것이 신호였을 수 있습니다.

# 헛돌 때와 뻑뻑할 때는 원인이 다릅니다
증상을 둘로 나누어 보면 원인을 좁히기 쉽습니다.
- 헛돌 때: 손잡이와 막대를 연결하는 부분이 헐겁거나 마모된 경우
- 뻑뻑할 때: 걸쇠가 문틀에 눌리거나 안쪽 부품에 이물이 낀 경우
- 돌아가다 중간에 멈출 때: 문이 처져 걸쇠 위치가 어긋난 경우
- 아예 안 움직일 때: 내부 부품이 걸렸거나 파손된 경우
어떤 경우인지에 따라 직접 해볼 수 있는 일과 부르는 일이 갈립니다.
증상이 언제부터인지, 계절이나 날씨와 관련이 있는지도 기억해 두면 원인을 짚는 데 도움이 됩니다. / 추운 날에만 뻑뻑해지는 경우는 문과 부품이 수축해서인 때가 많습니다.

# 가장 먼저 해볼 한 가지
문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 문틀에 걸쇠가 눌려 있을 때는 이 방법만으로 움직이는 경우가 있습니다.
문 중간을 손으로 받쳐 위로 약간 들어올리듯 하면 처진 문이 제자리를 찾아 잠금이 돌아갈 수도 있습니다. / 그래도 안 되면 힘을 더 주지 말고 멈추세요.
세게 돌리면 안쪽 막대가 휘거나 손잡이 축이 부러져 훨씬 큰 고장이 됩니다.
손잡이가 중간에서 걸리는 느낌이 들면 그 지점을 기억해 두었다가 설명해 주세요. / 어느 각도에서 걸리는지가 원인을 구분하는 단서가 됩니다.

# 헐거워진 손잡이 나사 살펴보기
손잡이를 고정하는 작은 나사가 풀리면 헛도는 증상이 나타납니다. / 손잡이 밑이나 옆에 작은 구멍이 있다면 육각 렌치나 작은 드라이버로 조여지는 구조일 수 있습니다.
기종마다 구조가 달라서 모양을 모르면 무리하게 분해하지 않는 것이 좋습니다. / 나사를 돌려도 계속 헐겁다면 구멍이 닳아 있다는 뜻이라 부품 점검이 필요합니다.
손잡이를 돌리다 보니 윤활제를 뿌려 볼까 싶을 수도 있습니다. / 이때 아무 기름이나 쓰면 먼지가 엉겨 더 굳을 수 있습니다.
@ 팽성읍 헛도는 잠금 손잡이 나사 점검

뻑뻑할 때 아무 기름이나 뿌리면 먼지가 엉겨 더 굳을 수 있습니다. / 쓰신다면 도어락 전용이나 건식 윤활제를 소량만 써야 하고 번호판 쪽에는 닿지 않게 해야 합니다.
기름기가 전자부품에 들어가면 오작동의 원인이 될 수 있습니다. / 확신이 없다면 뿌리기보다 증상을 말씀해 주시는 편이 안전합니다.
한 번 기름이 스며든 부품은 닦아 내기도 어려워 점검할 때 시간이 더 걸립니다.

# 문이 잠긴 채 안 열릴 때
안쪽 손잡이가 돌아가지 않아 문이 안 열리는 상황이라면 바깥에서는 번호나 열쇠로 풀 수 있는지 먼저 확인합니다. / 안쪽에 있다면 비상 해제 방법이 있는지 살펴보세요.
- 문 안쪽에 있고 열쇠나 번호로 바깥을 풀 수 있는지
- 가족이 바깥에 있다면 번호나 열쇠로 열 수 있는지
- 창문이나 다른 출입구로 나갈 필요가 있는지
안에 있는 사람이 갇혔다고 느끼면 먼저 진정하고 연락해 주세요. / 급한 상황이면 119에 먼저 연락하는 것이 우선입니다.

# 아이나 어르신이 안에서 못 나올 때
아이나 어르신이 안에서 못 나오는 상황이라면 놀라지 않도록 목소리로 계속 안심시켜 주세요. / 문 너머로 손잡이를 어떻게 돌리고 있는지 차분히 물어보는 것도 도움이 됩니다.
이 경우에는 다른 일정보다 먼저 살펴 드리니 전화로 먼저 알려 주세요. / 안쪽에서 무리하게 힘주지 않도록 말씀해 주시는 것이 중요합니다.

# 연락하실 때 알려 주세요
팽성읍 안에서 대략 어느 쪽인지와 주소를 알려 주시고 증상을 짧게 말씀해 주세요.
- 헛도는지 뻑뻑한지 아예 안 움직이는지
- 열쇠나 번호로 바깥에서 열 수 있는지
- 안쪽 손잡이 사진 한 장
- 집 안에 사람이나 반려동물이 있는지
기종 정보가 있으면 부품 준비에 도움이 됩니다.
제품 뒷면이나 옆면에 적힌 이름이 보이면 함께 찍어 주세요. / 없다면 모양만 설명해 주셔도 괜찮습니다.

# 도착하면 신분 확인부터
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
단독이나 연립이라 관리사무소가 없다면 우편물이나 신분증이 가장 간단합니다. / 확인이 어려우면 작업이 어려우니 미리 준비해 주세요.
비용은 작업 전에 먼저 말씀드리고 못 열면 비용은 받지 않습니다. / 진행은 [이용안내](guide.html)에도 있습니다.

# 상하지 않게 푸는 순서
안쪽 손잡이 고장은 문 자체를 상하지 않게 푸는 방법부터 차례로 해봅니다. / 문과 도어락 모양을 그대로 두는 것이 우선입니다.
자세한 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙습니다.
@ 팽성읍 출장열쇠 안쪽 잠금장치 점검

# 고쳐 쓸지 바꿔 쓸지 판단하기
손잡이 한 부분만 닳았다면 해당 부품만 손보는 것이 합리적입니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)로 먼저 확인합니다.
전체가 너무 오래되어 다른 부분도 연달아 고장 나는 상태라면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐 쓸 수 있는데 교체를 권하지 않습니다.

# 평소에 이렇게 쓰면 덜 고장 납니다
- 손잡이를 돌릴 때 끝까지 억지로 밀지 않기
- 문을 세게 닫아 걸쇠가 문틀에 부딪히지 않게 하기
- 한 달에 한 번 잠금과 해제를 천천히 시험해 보기
- 뻑뻑함이 느껴지면 미루지 않고 바로 점검 받기

# 팽성읍 말고 평택 어디든 갑니다
팽성읍 가까이 안중읍, 서정동, 송탄동은 물론 비전동, 세교동, 청북읍까지 평택 전역을 다닙니다. / 다니는 지역은 [출장 지역](area.html)에서 확인하세요.
