# 팽성읍의 김장철, 베란다에 서 있는데 문이 닫혔다
팽성읍은 평택역이나 송탄역으로 나가려면 이동 거리가 있는 동네라 집에서 해결하는 일이 많습니다. / 11월이 되면 김장을 베란다나 마당에서 하는 집이 많아집니다.
배추를 씻고 절이다가 잠깐 베란다에 나갔는데 바람에 문이 닫히며 잠겨 버리는 일이 있습니다. / 손에 장갑을 낀 채 휴대폰도 안에 있다면 정말 난감합니다.
이 글은 팽성읍에서 김장이나 베란다 작업 중 문이 잠겼을 때 침착하게 해야 할 일을 정리했습니다. / 날이 추워지는 시기라 서두를 필요도 있습니다.
@ 팽성읍 김장 중 베란다 문 잠김

# 이런 일이 왜 잘 생기나
김장은 하루 종일 집 안과 밖을 오가는 작업입니다. / 문을 열어 둔 채로 오가다가 바람이 불면 문이 쾅 하고 닫힙니다.
- 현관문이 닫히면서 자동으로 잠기는 도어락
- 베란다 샷시가 안쪽에서 잠겨 있는 경우
- 마당 쪽 문이 안에서 걸쇠로 잠기는 경우
- 문 틈에 끼워 둔 벽돌이나 물건이 빠진 경우
김장철에 가장 많은 것은 현관 자동 잠금과 샷시 안쪽 잠금입니다. / 어느 쪽에 서 계신지에 따라 방법이 달라집니다.

# 먼저 해야 할 일, 몸 보온
추운 날씨에 물일을 하다 나왔다면 몸이 젖어 있을 수 있습니다. / 열쇠 문제보다 몸이 식는 것이 더 위험합니다.
가능하면 입을 수 있는 앞치마나 장갑을 걸치고 바람을 피할 곳을 찾으세요. / 이웃이 있다면 잠깐 몸을 녹이게 도움을 청해도 좋습니다.
급하다고 외벽을 타거나 난간을 넘으려 하지 마세요. / 물에 젖은 손발로는 미끄러지기 쉽습니다.
젖은 신발은 평소보다 훨씬 미끄럽습니다. / 베란다 바닥의 물기와 배추 부스러기도 낙상의 원인이 됩니다.

# 휴대폰이 안에 있다면
연락 수단이 없는 것이 가장 큰 문제입니다. / 이웃집이나 지나가는 분께 전화를 한 통만 부탁해 보세요.

- 가까운 가게나 경비실에서 도움 청하기
- 가족에게 번호를 불러 대신 연락하게 하기
전화를 받을 때는 위치와 지금 서 계신 곳(베란다, 마당, 현관 앞)을 말씀해 주세요. / 그것만 알아도 준비물이 달라집니다.
양손이 젖어 있어 전화를 걸기 어렵다면 이웃에게 대신 눌러 달라고 하셔도 됩니다. / 불러 주시는 번호만 정확하면 됩니다.

# 베란다에 갇힌 경우
베란다에 있다면 안쪽 샷시와 현관문을 모두 확인해야 합니다. / 샷시는 안에서 잠긴 경우가 많아 밖에서는 열기가 어렵습니다.
이럴 때 유리를 깨려는 분들이 가끔 있습니다. / 깨지면 다치는 것도 문제지만 수리비가 훨씬 커지니 하지 마세요.
샷시는 유리와 틀을 상하지 않게 여는 방법이 따로 있습니다. / 현장에서 구조를 보고 방법을 정합니다.

# 마당이나 현관 앞에 있는 경우
마당에서 작업하다 현관문이 잠겼다면 도어락 종류를 먼저 봅니다. / 번호 입력식이라면 번호를 아는 가족에게 연락할 수 있는지 확인하세요.
자동 잠금 도어락은 문이 닫히면 바로 잠기는데, 번호는 알아도 손이 젖어 인식이 안 되는 경우가 있습니다. / 마른 수건으로 손과 번호판을 닦고 다시 해 보세요.
몇 번 해도 안 되면 그만두는 게 좋습니다. / 여러 번 틀리면 도어락이 잠시 입력을 막기도 합니다.
번호를 알고 있는데도 안 열리는 경우는 배터리나 센서 문제일 수 있습니다. / 그럴 때는 번호를 계속 누르기보다 상태를 말씀해 주세요.

# 젖은 손으로 생기는 오작동
지문이나 터치식 도어락은 젖은 손에 반응하지 않습니다. / 김장 양념이 묻은 손이라면 번호판이 더러워졌을 수도 있습니다.
- 마른 수건으로 손 완전히 닦기
- 번호판 표면을 가볍게 닦기
- 잠시 기다린 뒤 다시 눌러 보기
고춧가루가 번호판 틈에 들어가면 오작동의 원인이 됩니다. / 작업이 끝난 뒤 한 번 닦아 주세요.
번호판 틈새는 면봉에 마른 천을 감아 가볍게 닦는 정도면 충분합니다. / 물을 직접 뿌리지는 마세요.

# 출장열쇠가 와서 하는 일
도착하면 먼저 사시는 분인지 확인합니다. / 신분증, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 이웃이나 가족의 확인으로 대신할 수 있는지 안내해 드립니다. / 확인이 안 되면 작업을 할 수 없는 점은 양해해 주세요.
[현관문 개문](door-open.html)은 문을 상하지 않게 여는 방식입니다. / 못 열면 비용은 받지 않습니다.
@ 팽성읍 현관문 비파손 개문

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 열기 전에 먼저 비용을 말씀드립니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
작업 후 말없이 붙는 비용은 없습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에서 볼 수 있습니다.
작업 전에 먼저 현장 상태를 설명드립니다.

# 문이 열린 뒤에 같이 보는 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 확인합니다. / 자동 잠금이 불편하다면 설정을 바꿀 수 있는지도 같이 봅니다.
번호판이 더러워졌다면 닦는 법을 알려 드립니다. / 자주 오작동하면 [도어락 수리](doorlock-repair.html) 상담도 가능합니다.
김장 철 이후에도 바람 센 날에는 문 닫힘 속도를 조절하는 방법을 알려 드립니다.

# 김장 작업 중 미리 챙기면 좋은 것
- 열쇠나 카드를 앞치마 주머니에 넣어 두기
- 휴대폰을 방수 팩에 넣어 몸에 지니기
- 문틈에 끼울 문 고정 장치 준비하기
- 가족에게 작업 시간을 알려 두기
특히 문 고정 장치는 바람 센 날 효과가 큽니다. / 값비싼 것이 필요하지 않고 문이 닫히지 않게만 해도 충분합니다.
