# 포승읍 오래된 건물, 문을 새로 달아야 할까
포승읍에는 지어진 지 오래된 주택과 공동주택이 섞여 있고, 평택역이나 지제역으로 나가는 길이 먼 만큼 주변 도움을 받기가 쉽지 않을 때가 있습니다. / 건물이 재건축이나 재개발 이야기를 앞두고 있으면 문 고장에 마음이 더 복잡해집니다.
곧 헐릴지도 모르는 건물에 도어락 값을 들이는 것이 아깝다는 생각 때문입니다. / 그렇다고 문이 고장난 채로 지낼 수도 없습니다.
건물이 낡았다고 해서 문의 안전까지 포기할 필요는 없습니다. / 오래 쓰던 문일수록 작은 손질만으로 한동안 문제없이 쓰는 경우가 많습니다.

이 글은 포승읍에서 재건축·재개발을 앞둔 오래된 건물의 현관문과 도어락을 어디까지 고쳐 쓰고 언제 바꾸는지 판단하는 기준을 정리했습니다. / 확정되지 않은 일정에 맞춰 무리하게 쓰지 않도록 돕는 안내입니다.

# 일정이 확정되지 않았다면
재건축이나 재개발은 일정이 몇 번씩 바뀌는 일이 흔합니다. / 곧 철거된다고 믿고 방치했다가 오래 더 살게 되는 경우도 있습니다.
그래서 일정을 알 수 없으면 당장 안전하게 쓸 수 있게 하는 것이 먼저입니다. / 문이 안 잠기거나 안 열리는 상태로 두는 것은 가장 위험합니다.
- 지금 문이 잘 잠기고 잘 열리는지
- 열쇠가 하나만 남아 있는지
- 문틀과 경첩이 처지지 않았는지
이 세 가지를 보고 최소한으로 손보는 방법을 고릅니다.
열쇠가 하나만 남은 집은 복사 가능한지 먼저 보셔야 합니다. / 열쇠 하나로 버티다 분실하면 그때는 문을 열어야 하는 일이 됩니다.

# 오래된 문이 말썽을 부리는 이유
오래된 건물의 문은 도어락보다 문틀과 경첩이 더 큰 영향을 줍니다. / 문이 처지면 걸쇠가 문틀에 제대로 들어가지 않습니다.
도어락만 새 것으로 바꿔도 문이 처져 있으면 같은 문제가 반복됩니다. / 그래서 새 제품부터 사기 전에 문 상태를 먼저 봐야 합니다.
오래된 열쇠 방식 잠금은 실린더가 닳아서 열쇠가 헛돌기도 합니다. / 이런 경우 실린더만 교체해도 해결됩니다.

# 고쳐 쓰기와 바꾸기, 판단 기준
상황별로 간단히 나눠 보면 선택이 쉬워집니다.
- 경첩 나사가 풀려 문이 처짐: 조정으로 해결
- 열쇠가 뻑뻑하고 헛돎: 실린더 점검, 필요하면 부분 교체
- 도어락이 가끔 오작동: 배터리와 접점 먼저 점검
- 도어락 자체가 오래돼 부품이 안 나옴: 교체 고려
대부분은 앞의 세 가지에서 끝납니다. / 마지막 경우도 곧바로 비싼 제품을 고를 필요는 없습니다.
@ 오래된 문 경첩과 문틀 점검

# 철거가 가까울 때 최소한의 선택
철거가 몇 달 안으로 예상된다면 가장 간단하고 단단한 방법을 고르면 됩니다. / 복잡한 스마트 기능보다 기본 기능이 확실한 제품이 나을 수 있습니다.
이사할 때 가져갈 수 있는 형태인지도 생각해 보세요. / 도어락은 문 두께와 규격이 맞아야 새 집에서도 쓸 수 있습니다.
어차피 쓸 기간이 짧다면 임시로 쓸 부품만 고치는 선택도 좋습니다. / 이럴 때는 무리하게 교체를 권하지 않습니다.
반대로 이미 철거 일정이 가까워졌다면 새 제품을 달기보다 지금 것을 안전하게 유지하는 쪽을 먼저 권합니다. / 쓸 기간에 비해 투자가 과한지를 함께 따져 드립니다.

# 세입자와 소유자가 같이 정리할 것
재건축을 앞둔 건물은 세입자와 소유자가 함께 문 문제를 정리해야 할 때가 있습니다. / 누가 비용을 낼지는 서로 합의할 문제입니다.
출장열쇠는 법적인 판단은 하지 않습니다. / 다만 사진, 작업 내용, 부품 교체 여부를 기록해서 말씀드립니다.
이렇게 남겨 두면 나중에 서로 설명하기가 쉬워집니다.
교체한 부품은 버리지 말고 한동안 보관하시길 권합니다. / 나중에 정산이나 인수 과정에서 확인할 일이 생길 수 있습니다.

# 문이 안 열릴 때 우선 확인
급하게 문이 안 열리는 상황이라면 아래 순서로 봅니다.
- 번호판이나 열쇠 구멍이 평소와 다른지
- 문을 안쪽으로 살짝 밀면서 손잡이를 돌려도 안 되는지
- 소리가 나는지, 아무 반응이 없는지
오래된 문은 손잡이를 세게 당기면 축이 휘는 일이 많습니다. / 힘으로 열려고 하지 마시고 전화 주세요.
경첩이 있는 쪽 문틈이 한쪽만 넓게 벌어져 있다면 처짐 신호입니다. / 문을 닫을 때 위쪽 모서리가 문틀에 닿는 소리가 나는지도 들어 보세요.

# 신분 확인은 이렇게 합니다
문을 열기 전에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 건물 관리인 확인 중 하나면 됩니다.
재건축 대상 건물은 관리인이 바뀌었거나 없는 경우가 있습니다. / 그럴 땐 우편물이나 공과금 고지서가 유용합니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.
@ 포승읍 주택 현관문 신분 확인

# 열기 전에 비용부터 말씀드립니다
문 상태와 도어락 종류를 보고 열기 전에 비용을 먼저 말씀드립니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체는 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 나서 확인하는 것
문이 열린 뒤에는 잠금이 다시 부드럽게 걸리는지, 문틀과 안 부딪히는지 같이 봅니다. / 원인이 배터리라면 새 것으로 바꾼 뒤 확인합니다.
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 정말 바꿔야 할 때만 [도어락 교체](doorlock-replace.html)를 설명드립니다.
새로 설치할 일이라면 [도어락 설치](doorlock-install.html) 안내에서 문 두께와 보조키 확인법을 볼 수 있습니다.

# 이사 준비와 문 정리
이주가 가까워지면 열쇠와 카드, 비밀번호를 정리해야 합니다. / 가족이 여럿이라면 누가 어떤 열쇠를 가졌는지 한 번 확인하세요.
이사 직전에 도어락을 떼어 가져가는 경우도 있습니다. / 이때는 떼어낸 뒤 문에 남는 구멍을 어떻게 할지도 미리 생각해 두세요.
사시던 집을 비우고 나갈 때도 문이 안전하게 잠기도록 마지막 점검을 하는 것이 좋습니다.
공용 출입문이 있는 건물이라면 공용부 잠금은 개인이 바꾸지 말고 관리 주체와 먼저 상의하세요. / 개인 현관문과 공용부는 책임이 다릅니다.
