# 포승읍 집 공사, 열쇠는 어떻게 맡길까
포승읍은 평택 서쪽 바다 쪽에 있는 읍 지역으로 주택, 빌라, 상가가 섞여 있고 생활 이동은 대체로 차량 중심입니다. / 평택역이나 서정리역까지 나가 일을 보는 분도 많습니다.
집을 고치는 인테리어 공사를 하게 되면 작업하시는 분들이 낮 동안 집을 드나들어야 합니다. / 이때 열쇠나 비밀번호를 어떻게 맡길지가 의외로 고민이 됩니다.
이 글은 포승읍에서 공사 인력에게 집 열쇠를 맡길 때 어떻게 정하면 편하고, 공사가 끝난 뒤 무엇을 정리하면 좋은지 [평택 출장열쇠](pyeongtaek.html) 입장에서 적었습니다.
@ 포승읍 인테리어 공사 현장 현관 도어락

# 공사 전에 먼저 정할 것
누가 들어오고 언제까지 쓰는지를 먼저 정해 두면 모든 것이 쉬워집니다.
- 출입하는 사람이 몇 명인지, 매일 같은 사람인지
- 공사 기간이 대략 언제부터 언제까지인지
- 집주인이 현장에 있는 시간과 비어 있는 시간
- 열쇠를 줄지, 임시 번호를 줄지, 직접 열어 줄지
이 네 가지만 정해도 나중에 혼선이 크게 줄어듭니다.
정한 내용은 공사 팀장과 문자로 한 번 주고받아 두면 서로 기억이 같아집니다.

# 실물 열쇠를 주는 것보다 임시 번호가 편한 이유
열쇠는 복사하면 누가 가지고 있는지 알기 어렵습니다. / 공사가 끝난 뒤에도 돌려받았는지 확신하기 어려운 점이 있습니다.
번호식 도어락이라면 공사 기간만 쓰는 번호를 따로 등록해 두고, 끝나면 지우면 됩니다. / 가족이 쓰는 번호와 작업자 번호를 나눠 두는 것입니다.
등록 방법은 제품마다 다르니 사용설명서를 먼저 확인하시고, 어려우면 전화 주세요.

# 가족 번호를 그대로 알려주지 마세요
편하다고 평소 쓰는 번호를 그대로 알려 주면 공사가 끝난 뒤에도 그 번호를 아는 사람이 남습니다. / 그때 번호를 바꾸면 되지만 바꾸는 일을 깜빡하는 경우가 많습니다.
처음부터 임시 번호를 만들어 두면 끝나는 날 지우기만 하면 됩니다.
번호는 문자로 여기저기 보내기보다 꼭 필요한 사람에게만 알려 주세요. / 작업 팀이 바뀌면 번호도 같이 정리하는 것이 좋습니다.
@ 포승읍 공사 중 현관 보호 및 출입 관리
공사 시작 전 작업 팀장과 출입 시간을 서로 확인해 두면 오해가 줄어듭니다. / 몇 시에 들어와서 몇 시에 나가는지만 정해도 번호를 켜 두는 시간을 줄일 수 있습니다.
@ 포승읍 공사 중 임시 비밀번호 설정 화면

# 열쇠를 맡길 때 기록해 두면 좋은 것
누구에게, 언제, 몇 개를 주었는지 간단히 메모해 두세요.
- 받은 사람 이름과 연락처
- 건네준 날짜와 돌려받기로 한 날짜
- 열쇠 개수나 등록한 카드·번호 종류
- 공사 중 집 안에 두는 귀중품은 따로 보관
거창한 서류가 필요한 것은 아니고 휴대폰 메모 한 줄이면 충분합니다.
공사 중에는 자재 반입으로 현관문을 활짝 열어 두는 시간이 길어집니다. / 그때 바람에 문이 닫히며 열쇠가 안에 들어간 채 잠기는 일도 생기니 문 고정 장치를 쓰는 것이 좋습니다.
공사가 길어지면 중간에 작업자가 바뀌는 일이 흔합니다. / 새로 오는 분에게도 같은 방식으로 임시 번호를 따로 주고, 나가신 분의 번호는 그때그때 지워 두세요.
집을 비운 사이 공사가 진행된다면 현관 쪽에 귀중품이나 서류를 두지 않는 것이 좋습니다. / 통장이나 중요한 우편물은 공사 전에 한곳에 모아 잠글 수 있는 곳에 보관해 두세요.

# 공사 중에 도어락이 상하는 경우
자재를 나르다 보면 문틀이나 도어락 번호판이 부딪혀 상하는 일이 생길 수 있습니다. / 비닐이나 보호 필름으로 문 주변을 감싸 두면 흠집을 줄일 수 있습니다.
먼지가 도어락 틈에 들어가 열쇠가 뻑뻑해지는 경우도 있습니다. / 공사 중에는 열쇠 구멍이나 번호판을 덮어 두는 것이 좋습니다.
공사 끝나고 번호판이 반응하지 않으면 배터리와 먼지부터 확인해 보세요.
공사 먼지는 생각보다 고운 입자라 열쇠 구멍 안쪽까지 들어갑니다. / 끝난 뒤에도 열쇠가 뻑뻑하면 억지로 돌리지 말고 알려 주세요.

# 공사 현장에서 문이 잠겨 못 들어갈 때
작업자가 열쇠를 못 받았거나 번호를 잘못 눌러 문이 안 열리는 일이 생깁니다. / 집주인이 멀리 있으면 현장이 멈춰 버리기도 합니다.
이런 경우에도 사시는 분 확인이 먼저입니다. / 집주인과 연락이 닿아 확인이 되면 열어 드리고, 확인이 어려우면 열지 못합니다.
작업자 혼자 요청하는 경우에는 집주인이 직접 전화나 확인을 해 주셔야 합니다.
현장 담당자가 대신 전화하는 일도 있는데, 이때도 집주인과 직접 통화가 된 뒤에 진행합니다. / 문자나 메신저로 대신 허락했다는 말만으로는 열지 않습니다.
공사 일정이 하루 이틀 밀리는 일은 흔합니다. / 그때마다 번호 사용 기간을 늘릴지 정해서 알려 주면 오해가 없습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사는 분인지 확인하는 절차를 꼭 거칩니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
공사 중인 집은 빈집처럼 보여 더 신중하게 확인합니다. / 번거로우셔도 이해 부탁드립니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
상태를 본 뒤 작업 전에 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
금액이 궁금하시면 전화로 상황을 설명해 주실 때 함께 물어보셔도 됩니다. / 현장에 도착해서 상태를 확인한 뒤 다시 한 번 정확히 말씀드리고, 그때 결정하셔도 늦지 않습니다. / 급하다는 이유로 설명 없이 작업을 시작하는 일은 없습니다.

# 공사가 끝난 날 해야 할 정리
공사가 끝나면 그날 바로 정리하는 것이 가장 안전합니다.
- 작업자용 임시 번호와 카드 삭제
- 복사한 열쇠를 돌려받았는지 확인
- 가족이 쓰는 번호도 이 기회에 바꾸기
- 도어락 배터리 상태 확인
번호를 바꾸는 방법이 어렵다면 [도어락 비밀번호 재설정 및 점검](doorlock-repair.html)을 문의하셔도 됩니다.

# 공사 때 도어락을 새로 달 계획이라면
집을 고치는 김에 도어락도 바꾸시려는 분이 많습니다. / 도어락 교체는 공사 마지막 단계에서 하는 편이 먼지와 충격으로부터 새 제품을 지킬 수 있습니다.
문 두께와 보조키 위치는 미리 확인해 두면 좋습니다. / 설치를 알아보신다면 [도어락 설치](doorlock-install.html) 페이지를 참고하세요.

# 포승읍 말고 평택 어디든 갑니다
포승읍 가까운 안중읍, 청북읍을 포함해 평택 안 다른 동네와 읍면까지 다닙니다. / 평택역, 지제역 쪽에서 부르셔도 됩니다.
다니는 지역은 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다.
