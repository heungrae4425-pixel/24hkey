# 포승읍 연휴 뒤 현관문이 안 열릴 때
며칠 집을 비웠다가 돌아와 보니 번호판에 아무 반응이 없는 경우가 있습니다. / 평택 포승읍처럼 평택항과 가까운 읍 지역에서도 연휴가 끝나는 저녁이면 이런 연락이 몰립니다.
짐을 양손에 든 채 문 앞에 서 있으면 마음이 더 급해집니다. / 이 글은 그럴 때 바로 해볼 수 있는 확인 순서와 [평택 출장열쇠](pyeongtaek.html)를 부르면 어떻게 진행되는지를 적었습니다.
@ 포승읍 명절 여행 뒤 현관문 안 열림 출장열쇠

# 며칠 비운 집에서 도어락에 생기는 일
도어락은 사람이 없어도 조금씩 전기를 씁니다. / 닷새, 열흘을 비우는 동안 배터리가 바닥나는 일이 생각보다 자주 있습니다.
- 배터리가 다 되어 번호판이 아예 꺼진 경우
- 비운 사이 경고음이 났는데 못 들은 경우
- 출발할 때 보조키를 잠그고 나간 경우
- 문이 덜 닫힌 채 잠겨 걸쇠가 문틀에 걸린 경우
원인을 알면 대처가 쉬워집니다. / 아래에서 하나씩 보겠습니다.

# 문 앞에서 먼저 1분 확인할 것
짐을 내려놓고 아래 세 가지만 보셔도 원인이 좁혀집니다.
- 번호판을 손으로 쓸었을 때 불이 들어오는지
- 번호를 눌렀을 때 삑 소리가 나는지
- 안쪽에서 문이 움직이는 소리가 나는지
전화로 말씀하실 때 이 세 가지를 같이 알려주시면 출동 준비가 훨씬 빨라집니다.

# 번호판이 꺼져 있다면 9V 건전지로 비상 전원
많은 도어락 아래쪽에는 9V 건전지를 대는 비상 단자가 있습니다. / 건전지를 댄 상태에서 번호를 누르면 열리는 경우가 많습니다.
읍내 편의점이나 마트에서 9V 건전지를 구할 수 있는지 먼저 떠올려 보세요. / 단자가 없는 모델이거나 건전지를 대도 반응이 없으면 그때 연락 주시면 됩니다.
@ 포승읍 도어락 배터리 비상 전원 출장열쇠

# 번호는 맞는데 안 열릴 때
번호판은 켜지는데 모터 소리만 나고 걸쇠가 안 빠지는 경우가 있습니다. / 이럴 때 손잡이를 세게 당기면 걸쇠가 더 꽉 물립니다.
문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 그래도 안 되면 억지로 힘을 주지 마시고 상태만 알려주세요.
여행 전에 보조키를 잠갔다면 바깥에서는 번호로 열리지 않는 모델이 있습니다. / 이 경우 열쇠가 필요한데, 열쇠도 없다면 개문 작업으로 진행합니다.

먼 길을 다녀온 뒤에는 피곤해서 비밀번호를 여러 번 틀리기 쉽습니다. / 도어락은 여러 번 틀리면 한동안 입력을 막으니 서너 번 해보고 멈추는 게 좋습니다.
아이나 어르신이 함께 계시면 잠시 따뜻한 곳에서 기다려 주세요. / 문 앞에서 오래 서 있지 않도록 위치만 먼저 알려주셔도 됩니다.

# 열쇠로 여는 문이라면
도어락 없이 열쇠만 쓰는 현관문도 연휴 뒤에 열쇠가 안 돌아가는 일이 있습니다. / 열쇠를 꽂아도 뻑뻑하면 억지로 돌리다 열쇠가 부러질 수 있으니 멈추는 게 안전합니다.
열쇠구멍에 윤활제를 급하게 뿌리는 분들이 계십니다. / 나중에 먼지가 엉겨 더 안 돌아갈 수 있으니 그대로 두시고 전화 주세요.
열쇠 모양이 닳았거나 여분 열쇠가 하나뿐이라면 이번 기회에 상태를 같이 봐 드립니다. / 열쇠가 안 돌아가는 원인이 열쇠인지 문 쪽인지부터 가려야 헛걸음이 없습니다.

# 평택항 쪽 포승읍에서 위치를 알릴 때
포승읍은 읍 단위라 건물과 길이 넓게 퍼져 있습니다. / 건물 이름이나 눈에 띄는 가게, 큰길과의 위치를 같이 알려주세요.
- 건물 종류(주택, 빌라, 원룸 등)와 층
- 큰길에서 어느 쪽으로 들어오는지
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집 안에 사람이나 반려동물이 있는지
위치를 정확히 받으면 도착 시간을 먼저 말씀드립니다.

# 연휴 중 늦은 시간에 연락할 때
연휴가 끝나는 밤이나 새벽에도 전화를 받습니다. / 시간이 늦었다고 망설이지 말고 연락 주세요.
다만 공휴일 저녁에는 연락이 몰릴 수 있어 도착 시간이 달라질 수 있습니다. / 이때는 예상 시간을 솔직하게 말씀드립니다.
기다리는 동안에는 번호를 계속 누르지 마시고, 짐을 한쪽에 모아 두고 계시면 됩니다. / 출동 중에 상태가 바뀌면, 예를 들어 이웃이 문을 열어 주었거나 번호가 기억났다면 바로 전화로 알려 주세요.
@ 평택 포승읍 24시 출장열쇠 연휴 개문

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리하는 분의 확인 중 하나면 됩니다.
여행 가방 안에 신분증이 있다면 미리 꺼내 두시면 빠릅니다. / 확인이 어려우면 작업을 할 수 없으니 이 점은 양해 부탁드립니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

문과 도어락이 상하지 않는 방법부터 차례로 해봅니다. / 상태에 따라 걸리는 시간은 다르지만, 손대기 전에 어떻게 진행할지 먼저 설명드립니다.
자세한 내용은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 문이 열린 뒤 바로 하면 좋은 점검
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 봅니다. / 배터리가 원인이었다면 전부 새것으로 바꾸는 것까지 안내합니다.
새 번호를 등록할 때는 가족이 기억하기 쉬우면서 남이 짐작하기 어려운 번호를 권해 드립니다. / 연휴 때 맡겼던 임시 번호나 지워야 할 번호가 있으면 이때 함께 정리합니다.
고쳐 쓸 수 있으면 교체는 권하지 않습니다. / 고장이 반복되면 [도어락 수리](doorlock-repair.html)를 먼저 살펴보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 다음 연휴 전에 해두면 좋은 준비
오래 비우기 전에 배터리를 새것으로 바꿔 두면 걱정이 줄어듭니다. / 출발 전 문이 잘 닫혔는지, 번호판이 정상인지 한 번 눌러 보고 나가세요.
- 출발 전에 배터리 경고음이 없는지 확인
- 가족에게 비상 연락처로 이 번호를 공유
- 비상용 9V 건전지를 가방에 하나 넣기
- 열쇠가 있는 문이라면 여분 열쇠를 믿을 수 있는 곳에 보관
@ 포승읍 연휴 전 도어락 점검 010-3664-5455

# 포승읍 말고 평택 어디든 갑니다
포승읍 바로 옆 안중읍, 청북읍, 팽성읍도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에, 서울·경기 다른 지역은 [출장 지역](area.html) 지도에 있습니다.

? 여행 중에 집에 있는 가족이 못 들어온다는데 대신 부탁해도 되나요? | 지금 문 앞에 계신 분의 거주 확인이 가능해야 합니다. 신분증이나 주소 우편물을 준비해 주세요.
? 문이 열린 뒤 비밀번호도 바꿔 주시나요? | 네, 새 번호 등록과 배터리 교체까지 같이 해드립니다.

# 마무리
연휴 뒤 문이 안 열리면 억지로 열려 하지 마시고 번호판 상태부터 확인해 주세요. / 9V 건전지로도 안 되면 위치와 상황만 알려주시면 바로 출동 여부를 말씀드립니다.
24시출장열쇠는 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
