# 포승읍 겨울 아침, 문이 바닥에 붙어 버렸다면
포승읍은 평택 서쪽 바닷가 쪽에 자리해서 겨울에 바람이 차고 기온 차가 큰 편이라는 이야기를 듣는 동네입니다. / 평택역이나 송탄역 방향으로 차로 오가는 분이 많아 아침 일찍 나서는 집이 많습니다.
낮에 눈이 녹아 현관 앞에 물이 고였다가 밤에 다시 얼면 문 아래와 바닥이 한 덩어리로 붙어 버리는 일이 있습니다. / 도어락은 멀쩡한데 문이 꿈쩍도 하지 않으면 이 경우를 의심해 볼 수 있습니다.
이 글은 포승읍에서 눈이 녹았다가 얼어 문 아래가 막혔을 때 안전하게 푸는 순서를 정리했습니다. / 풀리지 않으면 [평택 출장열쇠](pyeongtaek.html)를 부르는 기준도 같이 적었습니다.
@ 포승읍 현관문 아래 결빙 눈 얼음

# 왜 문 아래가 얼어붙는지
문 아래에는 바닥과 맞닿는 문턱과 고무 패킹이 있습니다. / 눈이 녹은 물이 이 틈으로 스며들었다가 기온이 내려가면 얼음이 되어 문과 바닥을 접착제처럼 붙입니다.
밖으로 열리는 문은 문 아래에 눈이 쌓이거나 얼음이 생기면 더 쉽게 막힙니다. / 안으로 열리는 문은 얼음이 문턱 쪽에서 걸려 문이 반쯤만 열리기도 합니다.
도어락과는 상관없이 문 자체가 물리적으로 막힌 경우입니다. / 번호가 맞아도 걸쇠가 풀려도 문이 움직이지 않으니 따로 구분해야 합니다.

# 도어락 문제인지 얼음 문제인지 구분하기
먼저 증상을 보면서 원인을 가려 봅니다. / 아래 중 어느 쪽에 가까운지 확인해 보세요.
- 번호를 누르면 정상 소리가 나고 걸쇠 소리도 들리는 경우
- 손잡이는 돌아가는데 문이 아주 약간만 움직이는 경우
- 문 아래 틈에 얼음이나 서리가 보이는 경우
- 문을 밀면 위쪽은 벌어지는데 아래쪽이 안 열리는 경우
이런 증상이면 도어락이 아니라 결빙일 가능성이 큽니다. / 반대로 번호판이 아예 꺼졌거나 소리가 이상하면 배터리 문제를 같이 봐야 합니다.
@ 포승읍 문 아래 틈 얼음 확인

# 절대 하지 말아야 할 것
급하다고 뜨거운 물을 붓는 분이 많지만 이는 가장 위험한 방법입니다. / 아래는 꼭 피해 주세요.
- 끓는 물이나 아주 뜨거운 물을 문 아래에 붓기
- 쇠 주걱이나 칼로 얼음을 깊게 찍어 내기
- 문을 세게 당기거나 발로 차서 얼음을 깨기
- 도어락 번호판에 열풍기를 바로 대기
뜨거운 물은 순간적으로 녹았다가 다시 얼어 더 단단해질 수 있고 바닥 미끄럼 사고로 이어집니다. / 문틀과 도어락도 급격한 온도 차로 상할 수 있습니다.

# 안전하게 푸는 순서
천천히 하는 것이 가장 빠릅니다. / 아래 순서대로 해보세요.
먼저 문을 안쪽에서 아주 약하게 반복해서 밀고 당기며 틈이 생기는지 봅니다. / 얼음 접착이 약하면 이 진동만으로 떨어지기도 합니다.
틈이 보이면 미지근한 물을 천천히 조금씩 부어 녹입니다. / 물이 바로 다시 얼지 않도록 바로 닦아 냅니다.
플라스틱 헤라나 카드 같은 부드러운 도구로 얼음을 살살 긁어냅니다. / 단단한 도구는 문과 패킹에 흠을 냅니다.

# 얼음이 녹은 뒤에 해야 할 일
문이 열리면 바닥과 문턱의 물을 마른 걸레로 말끔히 닦아 주세요. / 남은 물기가 밤에 다시 얼면 같은 일이 반복됩니다.
문 아래 고무 패킹이 찢어지거나 말려 있다면 물이 더 스며듭니다. / 상태를 확인해 두고 필요하면 보수를 생각해 보세요.
문턱에 소금이나 제설제를 뿌리는 경우는 도어락과 철제 부품에 영향을 줄 수 있습니다. / 사용한다면 문에 닿지 않게 문틀 바깥쪽에만 두세요.

# 문이 얼어서 열쇠집을 부르는 경우
혼자 해결하기 어려운 상황도 분명 있습니다. / 이럴 때는 무리하지 말고 연락해 주세요.
- 얼음이 두껍게 쌓여 미지근한 물로도 풀리지 않는 경우
- 문이 얼어서 도어락과 문틀이 같이 눌려 있는 경우
- 얼음 때문에 걸쇠가 문틀 안쪽에 낀 경우
- 문이 열리긴 하는데 손잡이가 돌아가지 않는 경우
- 안에 아이나 노인이 있어서 서둘러야 하는 경우
출장 전에는 어디가 얼었는지, 문 안쪽에 사람이 있는지 알려 주세요. / 상황에 따라 챙겨 가는 도구가 달라집니다.
@ 포승읍 겨울 현관문 얼음 제거 작업

# 전화할 때 알려 주면 빠른 정보
추운 날에는 길이 미끄러워 도착 시간이 길어질 수 있습니다. / 정보를 미리 주시면 출발 준비가 빨라집니다.
- 포승읍 내 대략적인 위치(차로 오는 길과 가까운 건물)
- 문이 어느 쪽으로 열리는지(안쪽, 바깥쪽)
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 문 아래 얼음이 보이는지 여부
- 집 안 사람 유무와 난방 상태
눈이 쌓인 길이라면 진입이 어려운 곳이 있는지도 알려 주세요. / 도착 경로를 미리 확인할 수 있습니다.

# 사시는 분인지 확인하는 절차
겨울이어도 문을 여는 일이라 먼저 신분 확인을 합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있다면 이웃이나 관리인에게 세대 확인을 부탁해 보세요. / 추운 날 문 앞에서 오래 기다리지 않도록 따뜻한 곳에서 기다리시길 권합니다.
확인이 어려우면 작업이 어려운 점 양해 부탁드립니다. / 집과 이웃을 위한 절차입니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
상태를 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 문을 상하지 않게 여는 방식
얼음 때문에 막힌 문은 억지로 열면 문 아래 패킹과 문틀이 같이 상합니다. / 얼음을 서서히 녹이고 틈을 확보한 뒤 열어서 문이 상하지 않게 합니다.
걸쇠가 눌린 경우에는 문의 위치를 조금 조정해서 풉니다. / 방식은 [현관문 개문](door-open.html)에 설명한 원칙과 같습니다.

문이 열리면 도어락 번호판과 걸쇠가 얼어서 영향을 받지 않았는지 확인합니다. / 한파에는 배터리 반응이 느려지는 경우도 있습니다.
배터리가 약하다면 새것으로 바꾸는 것이 좋습니다. / 상태가 이상하면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
문 아래 패킹과 문턱 상태가 심하게 상했다면 점검 방법을 안내드립니다. / 너무 오래된 도어락일 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 겨울철 문 앞 미리 대비하기
눈이 오기 전에 몇 가지만 해 두면 결빙을 많이 줄일 수 있습니다. / 아래를 참고해 보세요.
- 눈이 오면 문 앞 눈을 바로 치워 쌓이지 않게 하기
- 문 아래 고인 물을 마른 걸레로 닦아 두기
- 낮에 녹은 물이 문 앞으로 흐르지 않게 경사 확인하기
- 해가 지기 전에 문 앞을 한 번 정리하기
- 비상용 9V 건전지를 가까운 곳에 두기
한파에 배터리가 약한 상태라면 더 불안하니 겨울 전에 바꿔 두면 좋습니다. / 이런 작은 준비가 아침의 곤란함을 줄여 줍니다.

# 포승읍 말고 평택 어디든 갑니다
포승읍 주변 안중읍, 청북읍, 팽성읍은 물론 고덕동, 동삭동, 비전동, 세교동, 서정동, 지산동, 송탄동도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
평택에서 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 뜨거운 물을 부어도 되나요? | 권하지 않습니다. 다시 얼거나 문과 도어락이 상할 수 있어 미지근한 물을 조금씩 쓰시길 바랍니다.
? 문 아래 얼음만 녹이러 와 주시나요? | 상황을 보고 가능한 범위를 말씀드립니다. 문이 열리지 않는 상태라면 연락 주세요.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.
? 눈이 오는 새벽에도 오시나요? | 24시간 받습니다. 길 상황을 보고 도착 시간을 안내드립니다.
? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.

# 마무리
포승읍에서 눈이 녹았다가 얼어 문이 안 열린다면 뜨거운 물보다 미지근한 물과 부드러운 도구로 천천히 풀어 보세요. / 그래도 안 되면 위치와 문 상태만 알려 주시면 출동 여부를 바로 말씀드립니다.
24시출장열쇠는 추운 새벽에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
