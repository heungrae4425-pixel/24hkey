# 세교동 베란다 문과 방문 잠금장치 이야기
세교동은 입주한 지 오래되지 않은 단지와 상가가 섞여 있어서 현관문보다 안쪽 문 문제로 연락 주시는 분도 많습니다. / 베란다 문이 안 잠기거나 미닫이 방문이 빡빡하게 걸리는 일입니다.
현관문만 도어락이 있고 안쪽 문은 크게 신경 쓰지 않다가 막상 문제가 생기면 당황하게 됩니다. / 이 글은 평택 세교동에서 안쪽 잠금장치가 말썽일 때 확인할 것을 정리했습니다.
[평택 출장열쇠](pyeongtaek.html)를 부르기 전에 아래 순서로 먼저 살펴보세요. / 현관문과는 구조가 달라서 확인할 부분도 다릅니다.
@ 세교동 베란다 문 방문 잠금장치 출장열쇠

# 베란다 문은 구조가 현관문과 다릅니다
베란다 문은 크게 여닫이와 미닫이로 나뉩니다. / 미닫이는 문이 레일 위를 지나가는 방식이라 레일 쪽 문제가 많습니다.
잠금은 대부분 문틀 쪽 갈고리형 장치나 반달형 잠금쇠로 되어 있습니다. / 문이 조금만 처져도 갈고리가 맞지 않아 잠기지 않습니다.
현관문처럼 열쇠를 쓰지 않는 경우가 많아서 열쇠집에 연락하는 것이 어색하게 느껴질 수 있습니다. / 하지만 상황에 따라 저희가 손봐 드릴 수 있는 일이 있습니다.

# 잠금이 안 맞을 때 가장 먼저 볼 곳
문을 닫은 상태에서 잠금 갈고리와 문틀 홈 위치가 맞는지 눈으로 보세요. / 위아래로 한 칸 정도 어긋나 있다면 문이 처진 것입니다.
레일에 먼지나 이물질이 많이 쌓여도 문이 제자리에 오지 않습니다. / 마른 솔이나 청소기로 먼저 치워 보시면 의외로 해결됩니다.
바퀴가 닳았거나 높이 조절 나사가 풀린 경우도 있습니다. / 이런 일은 문 아래쪽 옆면의 나사 부분을 살펴보시면 됩니다.

# 미닫이 방문이 빡빡하거나 안 열릴 때
안방이나 작은 방 문이 미닫이인 집이 있습니다. / 잠금 버튼을 눌러 놓고 열리지 않을 때가 가장 당황스럽습니다.
손잡이 부분 가운데에 작은 구멍이 있다면 비상 해제용입니다. / 가는 막대나 펼친 클립을 넣고 살짝 돌려 보세요.
무리하게 힘을 주면 문틀이나 문짝이 휠 수 있습니다. / 안 열리면 그대로 두고 연락 주시는 것이 낫습니다.

# 아이나 노인이 안에 있다면 먼저 말씀하세요
방문이 안에서 잠긴 채 아이나 어르신이 나오지 못하는 일이 가끔 있습니다. / 이 경우에는 문 너머로 계속 말을 걸어 안심시켜 주세요.
전화로 상황을 설명할 때 안에 누가 있는지, 말은 주고받을 수 있는지 먼저 알려 주세요. / 급한 정도에 따라 순서를 정해 출동합니다.
너무 놀라 소리가 없다면 119에도 도움을 요청하세요. / 저희도 최대한 빨리 가는 길을 확인해 드립니다.
@ 평택 세교동 방문 잠금 열기 출장

# 잠금장치가 헐거울 때 보이는 신호
손잡이를 눌러도 걸림이 약하거나 잠금 버튼이 덜렁거리면 내부 부품이 닳은 것입니다. / 이럴 때는 교체가 필요한지 점검이 필요한지 눈으로 확인해야 합니다.
나사 몇 개만 조이면 되는 경우도 있습니다. / 드라이버로 나사만 조였는데 좋아지기도 합니다.
그래도 덜렁거린다면 부품 자체를 바꿔야 합니다. / 이때는 어떤 부품이 필요한지 알려 드리고 진행 전에 먼저 여쭤봅니다.

# 문을 상하지 않게 여는 방법
문틈이 좁은 미닫이는 억지로 벌리면 문틀이 상합니다. / 덜 상하는 방법부터 차례로 해 보고, 어려우면 다른 방법을 말씀드립니다.
방문은 도어락과 달리 구조가 단순해서 흠집 없이 여는 경우가 많습니다. / 작업 전에 어떤 방법으로 열지 먼저 설명드립니다.
[현관문 개문](door-open.html)과 같은 원칙입니다. / 문과 문틀을 최대한 그대로 두는 것이 먼저입니다.

# 사시는 분인지 먼저 확인합니다
방문이나 베란다 문도 사시는 집이 맞는지 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
집 안에 이미 들어와 있는 분이 부르시는 경우도 같은 방식입니다. / 이웃이나 지인이 대신 연락해 주셔도 현장에서 확인합니다.
번거로우셔도 모두를 위한 절차입니다. / 확인이 어려우면 작업을 하지 못합니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 부품을 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 작업 후에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 베란다 문을 안전하게 쓰는 요령
잠금장치가 약해진 베란다 문은 외출할 때 한 번 더 확인하세요. / 특히 낮은 층은 잠금을 소홀히 하지 않는 것이 좋습니다.
레일은 계절이 바뀔 때마다 한 번씩 청소해 주세요. / 모래와 먼지가 쌓이면 문이 처지는 속도가 빨라집니다.
문이 한쪽으로 쏠려 닫힌다면 높이 조절 나사를 살짝 돌려 맞추는 방법도 있습니다. / 어려우면 무리하지 마시고 연락 주세요.

# 도어락과 안쪽 문을 같이 점검하면 좋습니다
현관 도어락 점검을 받으시는 김에 안쪽 문 잠금장치도 같이 보시면 효율적입니다. / 한 번 출동에 여러 가지를 확인할 수 있어서 편합니다.
고쳐서 쓸 수 있으면 교체를 권하지 않습니다. / 고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
너무 오래된 장치는 [도어락 교체](doorlock-replace.html)나 설치도 같이 말씀드립니다. / 필요 없으면 하지 않으셔도 됩니다.
@ 세교동 24시 출장열쇠 현관 점검

# 세교동 말고 평택 어디든 갑니다
세교동 옆 지산동, 비전동, 동삭동도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
평택에서 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
위치를 알려 주실 때는 건물 이름, 층, 호수와 가까운 역을 말씀해 주세요. / 지제역, 평택역 쪽이라고 말씀하셔도 도착 시간을 알려 드립니다.
