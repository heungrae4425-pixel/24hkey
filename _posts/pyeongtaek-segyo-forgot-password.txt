# 세교동에서 비밀번호가 갑자기 생각나지 않을 때
세교동은 지제역 쪽 생활권으로 새 아파트와 상가가 모여 있는 동네입니다. / 번호를 늘 눌러 오던 손이 어느 날 갑자기 틀리는 일은 생각보다 자주 일어납니다.
이사한 지 얼마 안 됐거나 가족이 번호를 바꾼 걸 모르고 있었다면 더 그렇습니다.
이 글은 세교동에서 비밀번호를 모를 때 문 앞에서 해볼 것과, 안 될 때 [평택 출장열쇠](pyeongtaek.html)를 부르는 순서를 정리했습니다.
@ 세교동 도어락 비밀번호 분실 출장열쇠

# 먼저 비밀번호를 틀리게 되는 흔한 이유
번호를 완전히 잊어버린 경우보다 헷갈린 경우가 훨씬 많습니다. / 아래 같은 사정이 겹치면 누구나 틀립니다.
- 이전 집이나 사무실 번호와 섞인 경우
- 가족이 모르게 번호를 바꾼 경우
- 최근에 초기화하거나 새로 등록한 경우
- 번호판이 닳아 눌러도 입력이 덜 되는 경우
기억이 안 나는 번호를 억지로 짜내기보다 상황을 먼저 정리하는 편이 빠릅니다.

# 전화 한 통으로 해결되는 경우부터 확인하세요
같이 사는 가족에게 먼저 전화해 보세요. / 번호를 바꾼 사람이 있다면 가장 빠른 해결책입니다.
집 안에 사람이 있으면 안쪽에서 열어 줄 수 있습니다. / 이웃이나 관리사무소에 맡겨 둔 열쇠가 있는지도 떠올려 보세요.
이 방법들이 모두 안 될 때 전문가를 부르는 게 맞습니다.

# 같은 번호를 계속 누르면 생기는 일
비밀번호를 여러 번 틀리면 많은 도어락이 일정 시간 입력을 막습니다. / 그 사이에 맞는 번호를 눌러도 반응하지 않아 더 당황하게 됩니다.
서너 번 해보고 안 되면 잠시 멈추고 다른 방법을 찾는 게 좋습니다. / 막혀 있는 시간이 풀린 뒤 생각난 번호를 다시 눌러 보는 것도 방법입니다.
@ 평택 도어락 비밀번호 오류 문 열기

# 번호를 모를 때 열쇠 구멍이 있는지 보세요
일부 도어락은 번호판 옆이나 아래에 비상 열쇠 구멍이 숨어 있습니다. / 덮개를 밀거나 눌러 열면 나타나는 모델이 있습니다.
비상 열쇠가 따로 있다면 그걸로 열고 번호를 새로 정하면 됩니다. / 열쇠가 집 안에 있는 경우라면 전화로 상황을 알려주세요.

# 출장열쇠를 부르기 전에 준비해 두면 좋은 것
도착 후 확인을 빨리 마치려면 아래를 챙겨 두세요. / 문 앞에서 시간을 줄여 줍니다.
- 신분증 또는 주소가 적힌 우편물
- 도어락 앞면 사진 (제조사 이름이 보이게)
- 아파트나 건물 이름 대신 대략적인 위치와 호수
- 집 안에 사람이나 반려동물이 있는지 여부
지제역 쪽이면 방향만 말씀해 주셔도 위치를 가늠하는 데 도움이 됩니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인부터 합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 이웃과 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다.

# 비밀번호를 모른 채 여는 방법
번호를 모를 때도 문과 도어락을 상하지 않게 여는 방법이 있습니다. / 덜 상하는 방법부터 순서대로 해봅니다.
어떤 방식으로 여는지는 [현관문 개문](door-open.html) 페이지에 설명해 두었습니다. / 도어락 종류와 문 상태에 따라 걸리는 시간은 달라집니다.
부품을 바꿔야 한다면 손대기 전에 먼저 말씀드립니다.
@ 세교동 출장열쇠 비파손 문 열기

# 열고 난 뒤 새 번호를 정합니다
문이 열리면 기존 번호는 지우고 새 번호를 다시 등록합니다. / 이때 가족이 다 같이 아는 번호로 정하는 것이 중요합니다.
너무 쉬운 번호는 피하고, 생일이나 전화번호 끝자리 같은 건 쓰지 않는 게 안전합니다. / 번호를 새로 정했으면 가족 모두에게 바로 알려 주세요.

# 비용은 문 열기 전에 말씀드립니다
도착해서 문과 도어락을 확인하고 어떻게 얼마가 드는지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니라면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 번호 잊지 않는 관리법
번호를 외우는 데만 의존하면 언젠가 또 막힙니다. / 아래 방법을 한두 가지만 같이 써도 훨씬 안전합니다.
- 카드키나 지문 같은 다른 열기 수단을 하나 더 등록
- 비밀번호는 가족 단체방 말고 직접 말로 공유
- 번호를 바꿀 때는 바꾼 사람이 꼭 가족에게 알리기
- 비상 열쇠는 집 밖 믿을 만한 곳에 하나 두기
@ 평택 도어락 비밀번호 새로 등록

# 이럴 땐 도어락 교체도 생각해 보세요
번호판이 닳아 숫자가 눌리지 않거나 자꾸 오입력이 난다면 도어락 자체가 오래된 것일 수 있습니다. / 그럴 때는 [도어락 교체](doorlock-replace.html)가 오히려 마음이 편합니다.
고쳐서 쓸 수 있는 상태라면 교체는 권하지 않고 [도어락 수리](doorlock-repair.html)부터 말씀드립니다.

# 세교동 말고 평택 어디든 갑니다
세교동 옆 동삭동, 비전동, 고덕동, 서정동, 송탄동까지 평택 전역을 다닙니다. / 안중읍, 포승읍, 팽성읍, 청북읍도 출동합니다.
다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
