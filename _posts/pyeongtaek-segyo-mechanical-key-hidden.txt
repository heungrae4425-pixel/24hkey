# 번호판만 있는 줄 알았던 도어락에 열쇠 구멍이 있다고요
세교동에서 지제역 방향으로 오가다 보면 생활권 안에 다양한 집이 있어 도어락 종류도 제각각입니다. / 번호판만 보이는 도어락도 대부분 비상용 기계식 열쇠 구멍을 숨겨 두고 있습니다.
배터리가 완전히 나갔을 때 이 구멍을 알면 비상 건전지 없이도 문을 열 수 있습니다. / 문제는 구멍이 어디 있는지 모르는 분이 많다는 것입니다.
이 글은 숨은 열쇠 구멍을 찾는 방법과, 찾았는데도 안 될 때 [평택 출장열쇠](pyeongtaek.html)를 부르는 순서를 정리한 글입니다.
@ 세교동 도어락 숨은 기계식 열쇠 구멍 위치

# 기계식 열쇠 구멍은 왜 숨겨 두었을까
번호판과 지문 인식부가 있는 도어락은 겉으로 보이는 구멍이 지저분하다고 느껴져 덮개를 씌워 둡니다. / 외관을 깔끔하게 하려는 이유도 있고, 먼지와 물이 들어가는 것을 막으려는 이유도 있습니다.
그래서 평소에는 열쇠를 쓸 일이 거의 없고, 사용자도 열쇠가 있는 줄 모르고 지냅니다. / 입주할 때 열쇠 몇 개를 받았다면 어딘가 쓰이는 구멍이 있다는 뜻입니다.

# 가장 흔한 위치는 손잡이 옆 덮개입니다
도어락 바깥쪽 몸체 아래나 옆을 손으로 천천히 훑어 보세요. / 작은 원형이나 사각형 덮개가 살짝 다른 색이나 재질로 붙어 있는 경우가 많습니다.
손톱으로 덮개 가장자리를 눌러 보면 옆으로 밀리거나 위로 뚜껑처럼 열립니다. / 안쪽에 열쇠 구멍이 보이면 열쇠를 꽂아 돌려 보세요.
덮개는 힘을 세게 주면 부러집니다. / 반드시 손으로 부드럽게 눌러 밀어 주세요.

# 덮개가 안 열릴 때 확인해 볼 것
- 덮개 옆의 작은 홈이나 걸림 부분을 손톱으로 눌러 보기
- 몸체 아래쪽을 만져 얇은 틈이 있는지 보기
- 번호판 전체가 위로 들리는 구조인지 보기
- 손잡이 밑에 별도의 돌림 장치가 있는지 보기
- 설명서나 제품 이름이 적힌 스티커 찾기
제품 이름을 휴대폰으로 검색하면 열쇠 구멍 위치를 알려주는 자료를 찾을 수 있습니다. / 문 앞에서 찾기 어려우면 사진을 찍어 두었다가 전화로 보여 주셔도 됩니다. / 밝은 곳에서 손전등을 비추면 덮개의 경계선이 훨씬 잘 보입니다.

# 열쇠를 꽂을 때 부드럽게 돌아가는지 봅니다
구멍이 보여도 열쇠가 바로 맞지 않는 경우가 있습니다. / 열쇠가 헐거운 듯 들어가거나 중간에 걸리면 억지로 돌리지 마세요.
열쇠를 살짝 뺐다 넣으며 위치를 조절하고, 손잡이를 약간 눌러 주면 돌아가기도 합니다. / 그래도 안 되면 열쇠가 닳았거나 구멍 안에 먼지가 쌓였을 수 있습니다.
무리하게 힘을 주면 열쇠가 부러져 안에 박히는 일이 생깁니다. / 그때는 일이 훨씬 커집니다.
@ 세교동 도어락 비상 열쇠 구멍 덮개 열기

열쇠가 어디 있는지도 떠올려 보세요. / 입주할 때 받은 열쇠 꾸러미가 서랍이나 가방 속에 있을 수 있습니다. / 가족이 가지고 있는 열쇠를 가져다 달라고 부탁하는 방법도 있습니다.
열쇠가 아예 없다면 기계식 구멍이 있어도 쓸 수 없습니다. / 이 경우에는 열쇠 구멍을 직접 여는 방법을 방문해서 판단합니다.

# 열쇠 구멍이 없는 도어락도 있습니다
모든 도어락에 기계식 열쇠 구멍이 있는 것은 아닙니다. / 열쇠 없이 번호와 카드만 쓰는 제품은 아예 구멍이 없을 수 있습니다.
이런 제품은 배터리가 방전되면 바깥 비상 단자에 9V 건전지를 대는 방식으로 전원을 넣어야 합니다. / 단자가 없는 제품이면 다른 방법으로 접근해야 합니다.
어느 쪽인지 모르겠으면 억지로 뜯어 보지 말고 사진을 보내 주세요. / 제품 뒷면이나 안쪽 덮개 안에 모델 이름이 적혀 있는 경우가 많습니다. / 그 이름만 알려 주셔도 구멍이 있는 제품인지 바로 알 수 있습니다.

# 이럴 때는 억지로 하지 마세요
열쇠 구멍을 찾는 데 몇 분 이상 쓰고 있다면 한 번 멈추고 상황을 정리해 보세요. / 급할수록 덮개를 부수거나 구멍에 이물질을 넣기 쉽습니다.
작은 드라이버로 덮개를 뜯어내거나 번호판을 젖히는 분들이 있습니다. / 내부 전선이 끊어지면 배터리 문제에서 부품 고장으로 번질 수 있습니다.
열쇠가 맞지 않는다고 윤활제를 구멍 안에 뿌리는 것도 피하세요. / 내부에 먼지가 들러붙어 더 굳는 경우가 있습니다.
어느 정도 해보고 안 되면 멈추는 편이 문을 지키는 길입니다. / 멈추고 전화 주시면 상황에 맞는 방법을 함께 찾아 드리니 오래 붙잡고 있지 않으셔도 됩니다.

# 전화하실 때 이 정도만 알려 주세요
도어락 모양이 다양하니 아래 내용을 알려 주시면 좋습니다.
- 번호판 위치와 모양(손잡이 위, 손잡이 아래, 일체형)
- 덮개 같은 부분이 보이는지 여부
- 열쇠를 갖고 있는지
- 번호판 불빛과 소리 상태
- 근처 큰 건물이나 지제역 쪽 방향 등 대략 위치
도어락 사진을 문자로 보내 주시면 구멍 위치와 열기 방식을 미리 판단하기 좋습니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁하는 방법을 안내합니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 아니면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 할 경우 바꾸기 전에 먼저 여쭙니다. / 자세한 순서는 [이용안내](guide.html)를 보세요.
@ 세교동 현관문 도어락 비파손 개방

# 방문했을 때는 이렇게 엽니다
출장 시에도 기계식 구멍이 있는 도어락은 열쇠 구멍 쪽을 먼저 살펴봅니다. / 구멍이 막혔거나 열쇠를 잃어버렸다면 도어락과 문이 덜 상하는 다른 방법을 순서대로 시도합니다.
문을 여는 구체적인 방식은 [현관문 개문](door-open.html) 페이지에 설명해 두었습니다.

# 열린 뒤에 해둘 일
문이 열리면 배터리를 전부 새것으로 바꾸고 잠금이 정상인지 봅니다. / 이때 기계식 열쇠 구멍의 위치와 덮개 여는 방법을 함께 보여 드립니다.
열쇠가 닳았거나 하나뿐이라면 여분을 만들어 두는 것을 권합니다. / 고장이 잦으면 [도어락 수리](doorlock-repair.html)를 먼저 보고, 어렵다면 [도어락 교체](doorlock-replace.html)를 안내합니다.

# 숨은 열쇠 구멍을 대비하는 방법
- 열쇠를 집 안과 가방, 가족 중 한 사람에게 나눠 보관
- 구멍 덮개 여는 방법을 한 번 직접 해보고 익히기
- 배터리는 해마다 정해진 시기에 한꺼번에 교체
- 열쇠 구멍 안에 먼지가 쌓이지 않도록 평소에 덮개 닫아 두기
- 이사 온 날 열쇠 개수와 위치를 확인해 두기
