# 문이 멀쩡할 때 찍어 두는 사진 한 장의 값어치
세교동은 평택역과 지제역 두 곳을 오가며 생활하는 분들이 많은 동네입니다. / 출퇴근길에 문 앞에서 막히는 일은 대개 예고 없이 오고, 그때는 휴대폰 배터리마저 얼마 안 남아 있는 경우가 흔합니다.
그래서 문이 멀쩡할 때 도어락 사진을 몇 장 찍어 두자는 얘기를 드리려고 합니다. / 사진이 있으면 [평택 출장열쇠](pyeongtaek.html)에 연락할 때 설명이 짧아지고, 맞는 도구를 챙겨 가기도 쉽습니다.
@ 세교동 도어락 사진 미리 찍어 두기

# 왜 사진이 있으면 연락이 빨라지는지
도어락은 겉모양이 비슷해 보여도 안쪽 구조가 제각각입니다. / 전화로 "번호판 달린 거요"라고만 해서는 어떤 제품인지 알기 어렵습니다.
사진 한 장이면 번호판 모양, 손잡이 방향, 보조키 유무까지 한눈에 들어옵니다. / 그만큼 도착해서 작업을 시작하기까지 시간이 줄어듭니다.
특히 한밤에 당황한 상태에서는 설명이 자꾸 엇갈립니다. / 미리 찍어 둔 사진은 그럴 때 말 대신 상황을 정확히 전해 줍니다.

# 꼭 찍어 둘 사진 네 장
대단한 촬영 기술은 필요 없습니다. / 문 앞에서 아래 네 곳만 찍어 두면 됩니다.
- 현관문 바깥쪽 도어락 전체가 나오게 한 장
- 도어락 번호판을 가까이서 한 장
- 문을 안에서 봤을 때 안쪽 몸체와 배터리 덮개가 보이게 한 장
- 문 윗부분이나 옆의 보조키, 걸쇠가 보이게 한 장
번호판은 가까이서 찍되 비밀번호가 지워진 상태에서 찍는 게 안전합니다. / 번호가 닳아 보이는 자국이 드러나지 않게 각도를 조금 바꿔 주세요.

# 사진에서 보이는 정보는 이런 것들입니다
번호판이 버튼형인지 터치형인지가 먼저 보입니다. / 손잡이가 레버형인지 일체형인지에 따라 작업 방법이 달라집니다.
안쪽 덮개를 열 수 있는지, 배터리가 몇 개나 들어가는지도 사진으로 어느 정도 짐작됩니다. / 보조키가 따로 달려 있으면 열쇠가 없을 때 어디를 먼저 보아야 하는지가 정리됩니다.
이런 정보는 전화로 길게 설명하지 않아도 되는 부분입니다. / 대신 현장에서 확인할 것에 시간을 쓸 수 있습니다.

# 사진을 찍을 때 피해야 할 것
번호판에 직접 손가락을 대거나 불필요하게 눌러 보는 건 피해 주세요. / 오작동을 일으킬 수 있고 지문 자국으로 번호가 드러날 수도 있습니다.
현관문 호수 표지판이 크게 나온 사진은 SNS에 올리지 않는 게 좋습니다. / 연락용으로만 쓰시고, 공개된 곳에는 올리지 마세요.
어두운 복도에서 플래시를 켜면 번호판이 반사되어 하나도 안 보이는 경우가 있습니다. / 각도를 조금만 비스듬히 하면 훨씬 잘 보입니다.
@ 세교동 현관 도어락 번호판 촬영 각도

# 사진은 어디에 저장해 두면 좋을까
휴대폰 갤러리 안에 "현관"이라는 앨범을 따로 만들어 두면 급할 때 바로 찾습니다. / 사진이 수백 장 쌓인 갤러리에서 한 장을 찾다가 시간을 쓰기 쉽기 때문입니다.
가족 단체 대화방에 한 번 올려 두는 방법도 있습니다. / 가족 누군가의 휴대폰에는 남아 있게 되니 내 휴대폰이 꺼졌을 때도 도움이 됩니다.
클라우드 사진 보관함을 쓰신다면 동기화가 되는지 한 번 확인해 두세요. / 휴대폰이 바뀌어도 사진을 이어 쓸 수 있습니다.

# 사진과 함께 알려 주시면 좋은 말
사진에는 담기지 않는 정보를 몇 줄 덧붙이면 충분합니다. / 짧게 적어도 출동 준비에는 큰 차이가 납니다.
- 세교동 어느 쪽인지(평택역 방향, 지제역 방향 등 대략적인 위치)
- 문이 어떻게 막혔는지(번호판 꺼짐, 경고음, 모터 소리만 남 등)
- 보조키를 안쪽에서 잠갔는지 기억하는지
- 집 안에 아이나 반려동물이 있는지
이 네 줄에 사진 두세 장이면 거의 모든 정보가 전달됩니다.

# 사진이 없을 때는 이렇게 설명해도 됩니다
이미 문이 막힌 상태라서 사진을 못 찍는 경우도 있습니다. / 바깥쪽 도어락은 문 앞에서 찍을 수 있으니 우선 그것만 보내 주세요.
안쪽 사진은 가족이 안에 있다면 부탁해 보시고, 없다면 말로 설명하셔도 됩니다. / "손잡이는 위로 올려서 여는 형이고, 번호판은 둥근 버튼입니다"처럼 모양을 말해 주세요.
사진 없이도 출동은 가능하니 부담 갖지 말고 먼저 전화 주세요. / 사진은 속도를 높여 주는 보조 수단입니다.
이웃집 도어락과 모양이 비슷하다면 이웃에게 양해를 구하고 그 문을 찍어 보내는 방법도 있습니다. / 같은 층 같은 제품이라면 어떤 형태인지 가늠하는 데 도움이 됩니다.
다만 이웃에게 무리하게 부탁하거나 늦은 시간에 초인종을 누르는 일은 피하시고, 어려우면 말로 설명하는 쪽을 택해 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
이 절차는 사진이 있든 없든 똑같이 거칩니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
사진으로 대략 상황을 본 뒤, 현장에서 문 상태를 확인하고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없고, 부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭙니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 사진을 찍는 김에 같이 점검해 보세요
사진을 찍으려고 문 앞에 서면 도어락 상태도 자연스럽게 눈에 들어옵니다. / 번호판 글자가 닳았거나 버튼이 눌리는 느낌이 둔하면 [도어락 수리](doorlock-repair.html)를 고려할 신호일 수 있습니다.
너무 오래되어 부품 구하기가 어려운 제품이라면 [도어락 교체](doorlock-replace.html)로 넘어가는 게 나을 때도 있습니다. / 어느 쪽이든 문이 막히기 전에 알아 두는 게 좋습니다.
@ 세교동 도어락 점검 안쪽 배터리 덮개

# 한 번 찍어 둔 사진은 이런 때 다시 씁니다
도어락을 교체하거나 새로 설치할 때도 기존 사진이 참고가 됩니다. / [도어락 설치](doorlock-install.html)를 알아볼 때 문 두께와 구멍 모양을 설명하기 쉽습니다.
이사하는 날 새 집 문을 찍어 두면 입주 후 점검에도 편합니다. / 한 번 습관이 되면 집을 옮겨도 똑같이 쓸 수 있는 요령입니다.

# 세교동 말고 평택 어디든 갑니다
세교동 옆 비전동, 동삭동, 고덕동은 물론 송탄동, 서정동, 지산동과 안중읍, 포승읍, 팽성읍, 청북읍도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리했고, 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
