# 전화를 끊고 나면 오히려 더 막막합니다
세교동에서 문이 안 열려 전화를 걸고 나면, 기사가 도착하기까지 시간이 비어 버립니다. / 지제역이나 평택역 쪽에서 퇴근해 돌아온 날이라면 몸도 지치고 마음도 급합니다.
이 시간을 그냥 서 있으면 길게 느껴지지만, 해둘 일이 몇 가지 있습니다. / 미리 준비해 두면 도착한 뒤 진행이 훨씬 빨라집니다.
이 글은 [평택 출장열쇠](pyeongtaek.html)를 부른 뒤 세교동 문 앞에서 기다리는 동안 할 일을 시간 순서대로 적었습니다.
@ 세교동 출장열쇠 도착 전 문 앞 준비

# 먼저 안전한 자리를 잡으세요
복도나 계단 앞에서 오래 서 있어야 한다면 이웃의 통행을 막지 않는 자리를 찾습니다. / 짐이 많으면 바닥에 내려놓고 현관 앞을 비워 두세요.
밤이라면 불이 켜진 곳, 사람이 지나다니는 곳에서 기다리는 편이 마음이 놓입니다. / 날씨가 춥거나 비가 오면 건물 입구 안쪽처럼 바람을 피할 곳이 좋습니다.
혼자 있다는 생각에 불안하다면 가족이나 친구에게 지금 상황을 문자로 알려 두세요. / 기다리는 동안 누군가와 연결되어 있다는 것만으로도 마음이 한결 가라앉습니다.
집 앞이 어둡다면 휴대폰 손전등을 켜서 도어락 쪽을 비춰 두면 사진도 잘 찍히고 기사가 도착했을 때 문 위치를 알아보기 좋습니다.

# 도어락과 문을 사진으로 남겨 두세요
기다리는 동안 휴대폰으로 현관 사진을 몇 장 찍어 두면 도움이 됩니다. / 이미 연락한 곳에 사진을 보내면 필요한 장비를 챙기는 데 쓰입니다.
- 도어락 앞면 전체와 번호판 모양
- 손잡이 주변과 문틈
- 불빛이나 화면에 나오는 표시
- 문 위쪽에 붙은 보조키나 걸쇠가 보이는지
사진은 지금 상태를 기록하는 용도도 됩니다. / 작업 전후 비교가 필요할 때 기준이 되어 줍니다.

# 신분 확인 서류를 미리 꺼내 두세요
기사가 오면 사시는 분이 맞는지 먼저 확인합니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 휴대폰에 남아 있는 우편 고지서나 택배 주소 같은 자료를 찾아보세요. / 관리사무소가 열려 있는 시간이면 세대 확인을 미리 부탁해 두는 것도 방법입니다.
확인이 안 되면 문을 열 수 없으니 이 준비가 가장 중요합니다.

# 문을 만지는 일은 잠시 멈춥니다
기사가 오기 전에 가능하면 현관 주변에 있는 물건을 한쪽으로 치워 두세요. / 작업할 공간이 있어야 빨리 끝납니다.
기다림이 길어지면 손잡이를 다시 돌려보고 싶어집니다. / 그러나 세게 당기거나 밀면 걸쇠가 더 물리는 일이 있습니다.
특히 도어락이 경고음을 내는 중이라면 계속 누르지 않는 편이 좋습니다. / 입력이 쌓이면 도어락이 한동안 잠기기도 합니다.
드라이버나 카드, 철사 같은 도구는 꺼내지 마세요. / 문틀이 긁히거나 내부 부품이 상하면 간단하던 일이 커집니다.

# 집 안 상황을 다시 한번 생각해 봅니다
문 안쪽에 켜 둔 것이 있는지 떠올려 보세요. / 가스레인지, 전기 장판, 다리미처럼 불이나 열을 쓰는 물건이 있다면 기사에게 꼭 먼저 알려주세요.
집 안에 아이나 반려동물이 있다면 소리를 내서 안심시켜 주시고, 이 경우는 가장 먼저 말씀해 주세요. / 이럴 때는 순서가 바뀌고 서둘러 움직입니다.
가족 중 누가 안에 있을 수 있는지도 확인해 보세요. / 연락이 닿으면 안쪽에서 문을 열어줄 수 있습니다.
@ 세교동 도어락 사진과 신분 확인 준비

# 가족과 이웃에게 연락해 볼 수 있습니다
기다리는 시간은 누구에게 연락할지 정리하기 좋은 때이기도 합니다. / 급할 때 전화번호를 못 외워서 곤란한 분이 의외로 많습니다.
가까운 가족이 비밀번호나 여분 열쇠를 갖고 있을 수 있습니다. / 집 안에서 문을 열어줄 사람이 있으면 가장 빨리 해결됩니다.
이웃에게 도움을 청할 때는 인사부터 건네고 짧게 상황을 설명하세요. / 초인종을 늦은 밤에 누르는 것이 부담스럽다면 문자나 관리사무소를 먼저 이용하세요.
여분 열쇠를 맡긴 곳이 가까이 있다면 확인하는 시간과 출장 시간을 비교해 보시고 선택하면 됩니다.

# 체온과 짐을 챙기며 기다리기
겨울이면 외투를 여미고 장갑을 끼는 것만으로도 기다리는 시간이 편해집니다. / 여름에는 그늘진 곳을 찾고 물을 마시세요.
무거운 장바구니에 냉동식품이나 상하기 쉬운 음식이 있다면 서늘한 곳으로 옮기세요. / 가까운 이웃에게 잠시 맡기는 방법도 있습니다.
휴대폰 배터리가 부족하면 절전 모드로 바꿔 두세요. / 기사와 통화가 끊어지면 곤란합니다.

# 기사와 계속 연락이 닿게 해두세요
도착 시간이 가까워지면 전화를 받을 수 있는 상태인지 확인합니다. / 건물이 찾기 어렵다면 입구에서 기다리거나 눈에 띄는 위치를 알려주세요.
세교동은 골목과 건물 입구가 여러 곳이라 호수와 입구를 헷갈리기 쉽습니다. / 층수와 호수, 엘리베이터 위치를 짧게 문자로 보내 두면 헤매지 않습니다.
도착 전에 예상보다 늦어지는 느낌이 들면 한 번 더 통화해 보세요.

# 도착 후엔 이런 순서로 진행합니다
기사가 도착하면 신분 확인이 먼저입니다. / 그다음 도어락 상태를 보고 방법을 정합니다.
- 상태 확인과 원인 파악
- 문 열기 방법과 걸리는 시간 설명
- 비용을 먼저 말씀드리고 동의를 받은 뒤 시작
- 열린 후 도어락 작동 점검
비용은 문 열기 전에 먼저 안내합니다. / 문을 끝내 못 열면 비용은 받지 않으며 열고 난 뒤 말없이 붙는 비용도 없습니다.
자세한 흐름은 [이용안내](guide.html)에 적어 두었습니다.
@ 세교동 24시 출장열쇠 도어락 점검

# 문이 열린 뒤에 바로 할 일
문이 열렸다고 바로 들어가 쉬지 말고 원인을 확인합니다. / 배터리 때문이었다면 새것으로 바꾸고, 번호를 잊었다면 새로 정하세요.
수리가 필요한지 교체가 필요한지는 [도어락 수리](doorlock-repair.html)와 [도어락 교체](doorlock-replace.html) 안내를 참고하실 수 있습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
현관문 개문 방식은 [현관문 개문](door-open.html) 페이지에도 정리해 두었습니다.

# 같은 일이 다시 생기지 않게 준비해 두기
- 휴대폰 메모에 신분 확인용 사진 한 장 저장해 두기
- 도어락 아래 비상 단자용 9V 건전지 하나 보관
- 가족끼리 비밀번호를 공유해 두기
- 믿을 수 있는 이웃이나 지인에게 연락처 알려 두기
- 배터리 교체일 메모해 두기
- 현관 주소와 호수를 가족 모두 말할 수 있게 해두기
준비라는 말이 거창하지만 사실 몇 분이면 끝납니다. / 한 번 정해 두면 가족 모두가 같은 순서로 움직일 수 있습니다. / 문 앞에서 기다리던 시간을 떠올리면 해둘 만한 일입니다.

# 세교동 말고 평택 어디든 갑니다
세교동 인근 비전동, 동삭동, 고덕동, 지산동은 물론 송탄동, 안중읍, 팽성읍까지 다닙니다. / 지역 정리는 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 기다리는 동안 문을 더 만져봐도 되나요? | 가볍게 한두 번은 괜찮지만 세게 당기거나 도구를 쓰는 것은 피해 주세요.
? 사진은 꼭 보내야 하나요? | 필수는 아니지만 보내주시면 맞는 장비를 챙기기 쉽습니다.
? 문을 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 도착 시간은 정확히 알 수 있나요? | 통화로 위치를 확인한 뒤 예상 시간을 말씀드립니다.
? 신분증이 집 안에 있으면 어떻게 하나요? | 주소가 나온 우편물이나 관리사무소 확인으로도 됩니다.
