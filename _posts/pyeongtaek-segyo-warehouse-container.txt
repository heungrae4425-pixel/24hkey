# 세교동 창고 문 앞에서 열쇠가 말을 안 들을 때
세교동은 송탄역이나 서정리역 쪽 생활권과 이어져 있어 주거지 말고도 창고와 작은 사업장을 쓰는 분들이 계십니다. / 이른 아침 물건을 내가려고 창고 앞에 섰는데 자물쇠가 안 열리면 그날 일정이 통째로 흔들립니다.
창고나 컨테이너 사무실 문은 집 현관문과 구조가 달라서, 같은 열쇠 문제라도 확인할 순서가 다릅니다.
이 글은 창고·컨테이너 사무실 출입문이 안 열릴 때 생각해 볼 원인과 대처 순서를 정리한 것입니다.
@ 세교동 창고 출입문 자물쇠

# 창고와 컨테이너 문은 무엇이 다른가
창고 문은 철제 셔터나 미닫이 철문, 컨테이너는 양쪽으로 여는 철문에 막대형 걸쇠를 쓰는 구조가 흔합니다. / 이런 문은 바람과 비, 먼지에 그대로 노출되어 있어 자물쇠가 쉽게 녹슬고 굳습니다.
집 현관문은 도어락이 몸체 안에 들어 있지만, 창고 문은 외부에 걸린 자물쇠와 걸이쇠를 쓰는 경우가 많습니다. / 그래서 열쇠 구멍보다 걸이쇠 부분이 문제인 일도 있습니다.
사무실로 쓰는 컨테이너에는 일반 도어락을 달아 둔 경우도 있어 문 구조를 먼저 파악하는 것이 시작입니다.

# 열리지 않는 흔한 원인
- 자물쇠 내부가 녹슬거나 먼지가 굳어 열쇠가 안 돌아가는 경우
- 겨울에 물기가 얼어 열쇠 구멍이 막힌 경우
- 문짝이 처지면서 걸이쇠가 한쪽으로 당겨진 경우
- 열쇠를 분실했거나 복사본이 닳아 맞지 않는 경우
- 안쪽에서 빗장이 걸린 채 밖에서 닫은 경우
어느 쪽인지에 따라 해볼 수 있는 방법이 다릅니다. / 자물쇠를 한참 두드리기 전에 먼저 어떤 유형인지 가려 보세요.

# 열쇠가 안 돌아갈 때 먼저 해볼 것
열쇠가 뻑뻑하면 문을 살짝 당기거나 밀어 걸이쇠 압력을 풀어 보세요. / 문짝이 처져 눌리고 있으면 압력이 풀리는 순간 열쇠가 돌아가는 일이 있습니다.
- 열쇠를 끝까지 넣었다가 반 칸 빼서 돌려 보기
- 다른 복사본이 있다면 바꿔서 시도하기
- 열쇠를 망치로 두드리거나 억지로 비틀지 않기
- 기름을 과하게 붓지 않기
기름을 많이 넣으면 당장은 돌아가는 듯해도 먼지가 엉겨 더 굳을 수 있습니다.

얼어붙은 자물쇠는 급하게 다루지 마세요. / 추운 날 자물쇠가 얼었다면 따뜻한 손이나 미지근한 기운으로 천천히 녹이는 편이 안전합니다. / 뜨거운 물을 부으면 순간 녹지만 다시 얼면 더 단단히 굳습니다.
라이터 불로 달구는 분들이 있는데, 자물쇠 내부 부품이 변형될 수 있어 권하지 않습니다.
@ 창고 자물쇠 내부 점검

# 열쇠를 잃어버렸다면
창고 열쇠를 잃으셨다면 마지막으로 쓴 사람과 시각, 복사본 위치를 먼저 정리해 보세요. / 복사본이 하나라도 남아 있으면 그것으로 열고 나서 자물쇠를 바꾸는 순서가 훨씬 간단합니다.
복사본이 없다면 문을 열어야 하는데, 이때는 자물쇠만 상하게 하고 문은 지키는 방식을 우선합니다.
잃어버린 열쇠가 누군가에게 넘어갔을지 걱정되면 열고 난 뒤에 자물쇠를 바꾸는 방법도 같이 상의합니다. / 이 판단은 열기 전이 아니라 연 뒤에 함께 정합니다.

# 신분 확인은 창고에서도 필요합니다
창고나 사무실은 물건이 들어 있는 곳이라 더 조심해야 합니다. / 그래서 요청하신 분이 이 공간을 쓰는 분이 맞는지 먼저 확인합니다.
임대 계약서, 사업자 관련 서류에 적힌 주소, 건물 관리자의 확인 중 하나면 됩니다. / 신분증도 함께 확인합니다.
임차인이라면 건물주나 관리하는 분께 먼저 연락을 해 두시면 확인이 빨라집니다.

# 전화할 때 알려 주시면 좋은 것
- 세교동 안에서 대략 어디쯤인지, 큰길에서 들어오는 길
- 문의 형태(미닫이, 여닫이, 컨테이너 양문, 셔터)
- 자물쇠 종류(외부 걸이 자물쇠, 문에 달린 도어락)
- 열쇠를 잃었는지, 안 돌아가는지, 언제부터 그랬는지
- 문 주변에 차가 들어올 공간이 있는지
자물쇠 사진을 보내주시면 장비를 맞게 챙길 수 있어 현장에서 달라지는 일이 줄어듭니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 형태와 자물쇠 상태를 본 뒤 비용을 먼저 안내드립니다. / 동의하신 뒤에 시작하고, 끝내 못 열면 비용은 받지 않습니다.
자물쇠를 바꿔야 하는 경우에는 바꾸기 전에 어떤 제품을 왜 바꾸는지 먼저 설명드립니다.
사업장이라 영수증이나 작업 내용 정리가 필요하시다면 미리 말씀해 주세요. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 문을 상하지 않게 여는 것이 먼저입니다
철문이나 컨테이너 문은 한번 휘면 모양이 쉽게 돌아오지 않습니다. / 그래서 힘으로 부수는 방법은 마지막으로 미뤄 두고, 덜 상하는 방법부터 차례로 해봅니다.
작업 중 부품을 바꿔야 할 것 같으면 손대기 전에 미리 말씀드립니다.
문을 여는 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 창고 문은 구조가 달라 현장에서 보고 방법을 정합니다.
@ 철문 자물쇠를 상하지 않게 여는 작업

# 컨테이너 사무실에 도어락을 쓰고 있다면
컨테이너 사무실에 현관 도어락을 단 경우에는 문 두께와 틀 모양이 일반 아파트와 달라 설치 상태가 불안정할 수 있습니다. / 철문이 얇으면 도어락이 헐거워지거나 문이 닫혀도 걸쇠가 덜 물리는 일이 있습니다.
배터리가 방전되면 가정집과 마찬가지로 번호판이 꺼집니다. / 비상 전원 단자가 있는지 먼저 확인해 보세요.
오래 쓴 제품이라면 [도어락 수리](doorlock-repair.html)로 점검받는 것도 방법입니다.

# 열고 난 뒤 점검할 것
작업이 끝나면 무엇을 했는지 한 번 더 설명드리고, 앞으로 같은 일이 생기지 않도록 관리 요령도 알려 드립니다. / 문이 열리면 자물쇠와 걸이쇠가 제대로 잠기고 열리는지 다시 확인합니다. / 문짝이 처졌다면 경첩과 레일도 함께 봅니다.
창고라면 안에 든 물건 정리 후 문을 닫기 전에 열쇠를 안에 두고 나오지 않도록 습관을 들이세요.
교체가 필요한 상황이면 [도어락 설치](doorlock-install.html) 안내에서 확인할 것들을 먼저 읽어 보셔도 좋습니다.

# 창고 문을 오래 쓰는 관리법
- 일 년에 한두 번 자물쇠에 전용 윤활제를 소량 넣기
- 문 아래 레일이나 경첩의 먼지와 녹 닦기
- 열쇠 복사본 위치를 적어 두기
- 비 오는 날 자물쇠 틈에 물이 고이지 않게 덮개 쓰기
이런 관리를 해 두면 열쇠가 굳는 일이 크게 줄어듭니다. / 철문 아래쪽에 물이 고이는 자리가 있다면 배수도 같이 살펴보세요.

# 세교동 말고 평택 어디든 갑니다
세교동은 물론 비전동, 동삭동, 고덕동, 지산동과 읍 지역까지 다닙니다. / 평택 안이면 동네 상관없이 24시간 전화를 받습니다.
다니는 곳은 [평택 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
