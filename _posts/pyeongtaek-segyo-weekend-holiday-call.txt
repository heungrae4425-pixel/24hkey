# 쉬는 날에 하필 문이 안 열립니다
주말에 가족과 나들이를 다녀오거나 공휴일에 장을 보고 들어오다 보면 현관 앞에서 막히는 일이 생깁니다. / 세교동에서 지제역이나 평택역을 오가는 평일과 달리 쉬는 날에는 주변이 한산해 도움받기가 더 어렵습니다.
관리사무소가 쉬고, 가까운 가게도 문을 닫은 시간이라면 더 그렇습니다. / 이럴 때를 대비해 연락하는 요령을 미리 알아 두면 마음이 편합니다.
이 글은 세교동에서 주말과 공휴일에 문이 안 열릴 때 필요한 것을 순서대로 정리했습니다. / 도움이 필요하면 [평택 출장열쇠](pyeongtaek.html)로 바로 연락하시면 됩니다.
@ 세교동 주말 공휴일 현관문 잠김

# 쉬는 날은 이런 점이 평소와 다릅니다
평일에는 관리사무소나 경비실에 도움을 청하기 쉽지만 쉬는 날에는 그렇지 않은 곳이 많습니다. / 담당자가 없으면 세대 확인도 늦어집니다.
편의점이나 마트가 닫는 시간이 이르면 9V 건전지를 구하기도 어렵습니다. / 이웃도 외출했을 가능성이 높아 도움받기 쉽지 않습니다.
그래서 쉬는 날에는 처음부터 해결 순서를 짧게 가져가는 것이 낫습니다. / 혼자 오래 붙잡고 있어도 도움받을 곳이 늘어나지 않기 때문입니다.
특히 비나 눈이 오는 날이나 해가 진 뒤라면 더 서두르지 않고 안전한 자리를 먼저 확보하세요. / 짐을 든 채 서 있는 것만으로도 지치기 쉽습니다.

# 1단계는 번호판과 소리를 살펴보기
먼저 번호판이 켜지는지, 눌렀을 때 소리가 나는지 확인하세요. / 이것만으로도 배터리 문제인지 다른 문제인지 구분이 됩니다.
- 번호판이 완전히 꺼져 있다면 배터리 방전 가능성
- 소리는 나는데 안 열리면 모터나 걸쇠 쪽
- 평소와 다른 경고음이 나면 오작동 가능성
- 아무 반응이 없고 불도 안 들어오면 전원 문제
상태를 알면 전화로 설명하기도, 기사가 준비하기도 쉬워집니다.

# 2단계는 가족이 집에 있는지 확인하기
세교동처럼 맞벌이 가정이 많은 동네라면 가족 단체방에 현재 상황을 한 줄로 올려 보세요. / 누가 가장 가까운지 바로 알 수 있습니다.
가족 중 누군가가 안에 있거나 번호를 알고 있다면 가장 빠른 해결책입니다. / 쉬는 날에는 모두 외출했다 돌아오는 경우가 많으니 연락이 닿는 사람부터 찾아보세요.
번호를 아는 가족이 근처에 있다면 도착까지 걸리는 시간을 비교해서 정하세요. / 출장열쇠를 부르는 시간과 큰 차이가 없다면 함께 부르는 것도 방법입니다.
여분 열쇠를 맡긴 곳이 가까운지도 떠올려 보세요.

# 3단계 연락할 때 알려 둘 것
전화로 정확히 알려 주시면 쉬는 날에도 빠르게 움직일 수 있습니다. / 아래 내용만 알려 주세요.
- 세교동 안의 위치, 건물 입구, 호수
- 번호판 상태와 소리
- 도어락 모양과 열쇠 구멍 유무
- 집 안에 아이나 반려동물이 있는지
- 연락 가능한 번호
사진 한 장을 문자로 보내주시면 훨씬 정확합니다. / 쉬는 날에는 나들이 짐이 많을 수 있으니 짐을 둘 곳도 정리해 두세요.
@ 세교동 휴일 출장열쇠 연락 요령

# 쉬는 날이라도 24시간 전화받습니다
공휴일과 주말, 밤과 새벽을 가리지 않고 전화를 받습니다. / 시간 걱정 없이 먼저 상황부터 알려주세요.
연휴에는 외출과 귀가가 몰리는 시간대가 있어 도착까지 걸리는 시간은 그때그때 말씀드립니다. / 확실하지 않은 시간을 약속하지 않고 가능한 시간을 정직하게 안내합니다.
오래 기다려야 하는 상황이면 그동안 신분 확인 자료와 도어락 사진을 준비해 두세요. / 도착한 뒤 진행이 훨씬 빨라집니다.

# 연휴에 특히 조심할 일
긴 연휴를 앞두고 있다면 떠나기 전 문 앞에서 한 번만 점검해도 많은 일이 줄어듭니다. / 배터리 경고음이 있었는지, 문이 끝까지 닫히는지 확인하세요.
집을 비웠다 돌아온 날은 도어락 배터리가 다 닳은 경우가 있습니다. / 쉬는 동안에도 도어락은 조금씩 전기를 쓰기 때문입니다.
연휴 끝날 늦은 저녁에는 도로나 일정이 겹쳐 서두르다가 문을 잠근 채 나오기도 합니다. / 나갈 때 휴대폰, 열쇠, 카드를 확인하는 습관이 필요합니다.
친척이 오가는 명절에는 번호가 여러 사람에게 퍼지기 쉽습니다. / 연휴가 끝나면 번호를 정리하는 것이 좋습니다. / 손님용으로 따로 알려준 번호는 가는 날 바로 지우면 됩니다.

# 문 앞에서 하지 말아야 할 행동
쉬는 날은 시간 여유가 있다는 생각에 이것저것 시도해 보게 됩니다. / 그러나 시도가 길어질수록 도어락 상태는 오히려 나빠질 수 있습니다.
기다리기 답답하다고 문을 세게 당기거나 발로 차는 것은 피해 주세요. / 걸쇠가 더 꽉 물리고 문틀이 상할 수 있습니다.
드라이버나 카드로 문틈을 벌리는 것도 문과 도어락을 상하게 합니다. / 비밀번호를 여러 번 틀리면 도어락이 잠시 입력을 막기도 합니다.
쉬는 날이라 도움을 받기 어렵다고 해서 이웃집 발코니를 넘는 것도 위험합니다. / 안전하게 해결할 방법이 있으니 무리하지 마세요.

# 도착 후 신분 확인이 먼저입니다
기사가 도착하면 사시는 분이 맞는지 확인합니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
쉬는 날에는 관리사무소가 닫혀 있을 수 있으니 신분증이나 우편물을 준비해 두세요. / 신분증이 집 안에 있다면 휴대폰 속 고지서나 택배 주소 같은 자료를 찾아 보여 주셔도 됩니다.
확인이 어려우면 작업을 시작할 수 없습니다.

# 비용은 문 열기 전에 설명드립니다
도어락과 문 상태를 보고 먼저 안내하며 동의하시면 시작합니다. / 쉬는 날이라고 해서 설명 없이 달라지는 비용은 없습니다.
문을 끝내 못 열면 비용은 받지 않고, 열고 난 뒤 말없이 붙는 비용도 없습니다. / 부품을 바꿔야 하면 하기 전에 먼저 여쭙습니다.
진행 방식은 [이용안내](guide.html)에서 볼 수 있습니다.
@ 세교동 24시 출장열쇠 도어락 점검

# 문이 열린 뒤 마무리 점검
문이 열리면 원인을 확인하고 같은 일이 안 생기도록 정리합니다. / 배터리 때문이었다면 전부 새것으로 바꾸고, 번호가 문제였다면 새로 정합니다.
도어락 점검은 [도어락 수리](doorlock-repair.html)로 먼저 보고, 낡았으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
현관문 개문 방식은 [현관문 개문](door-open.html)에서 볼 수 있습니다.

# 쉬는 날 대비 준비물
- 비상용 9V 건전지 한 개를 현관 근처에 보관
- 관리사무소와 경비실 번호를 휴대폰에 저장
- 신분 확인용 자료(우편물 사진 등)를 휴대폰에 보관
- 가족에게 번호와 여분 열쇠 위치 공유
- 연휴 전 배터리 상태 미리 확인
연휴 전날 5분만 투자하면 쉬는 날 문 앞 소동을 크게 줄일 수 있습니다.

# 세교동 말고 평택 어디든 갑니다
세교동 가까이 비전동, 동삭동, 고덕동, 지산동은 물론 송탄동, 서정동, 안중읍까지 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 번호를 몰라도 열어 주나요? | 사시는 분인지 확인되면 열어 드립니다.
