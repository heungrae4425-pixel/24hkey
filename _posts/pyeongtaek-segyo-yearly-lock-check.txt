# 세교동 도어락, 1년에 한 번은 꼭 보세요
평택 세교동에서 평택역이나 서정리역 쪽으로 오가다 보면 집 현관문을 하루에 몇 번씩 여닫게 됩니다. / 그렇게 자주 쓰는 도어락인데도 점검은 고장이 난 뒤에야 하게 되는 경우가 대부분입니다.
11월은 한 해를 정리하기에 좋은 달입니다. / 이 글은 세교동 집에서 직접 해볼 수 있는 연 1회 도어락 점검표를 순서대로 적었습니다.
전문 장비 없이 눈과 손으로 하는 점검이라 20분 정도면 끝납니다. / 이상이 있으면 어떤 때에 [평택 출장열쇠](pyeongtaek.html)를 부르면 되는지도 마지막에 정리했습니다.
@ 세교동 도어락 연 1회 점검 현관문

# 점검은 왜 연말에 하면 좋을까
겨울에는 기온이 떨어져 건전지 힘이 약해지고, 문틀도 수축하면서 걸쇠가 뻑뻑해집니다. / 그래서 한파가 오기 전에 점검해 두면 한겨울 새벽에 문 앞에서 막히는 일이 크게 줄어듭니다.
연말에는 가족 모임이나 손님이 오는 일도 많아서 비밀번호를 정리하기에도 좋습니다. / 한 해 동안 쌓인 임시 번호를 이때 한꺼번에 지울 수 있습니다.

# 1단계 건전지부터 한꺼번에 바꾸기
점검표의 첫 줄은 건전지입니다. / 아직 켜진다고 해서 두고 가면 한겨울에 먼저 꺼집니다.
- 번호판 위에 저전압 표시나 경고음이 있었는지 기억해 보기
- 건전지 네 개를 모두 새것으로 교체
- 새것과 쓰던 것을 섞지 않기
- 바꾼 날짜를 건전지 덮개 안쪽에 적어 두기
건전지를 갈 때는 극 방향을 한 번 더 확인하세요. / 반대로 끼우면 번호판이 켜지지 않아 고장으로 오해하기 쉽습니다.
빼낸 건전지는 따로 모아 두면 리모컨이나 시계에 한 번 더 쓰기도 합니다. / 다만 도어락에는 다시 넣지 마세요.

# 2단계 문을 닫을 때 걸쇠 소리를 들어 보기
건전지를 바꾼 뒤 문을 열고 닫으며 걸쇠가 들어가는 소리를 들어 봅니다. / 소리가 한 번에 '딸깍' 하고 맑게 나면 정상입니다.
소리가 두 번 끊겨서 나거나 문을 세게 밀어야 잠긴다면 문틀과 걸쇠가 어긋난 것입니다. / 이 신호는 몇 달 지나면 도어락 모터 고장으로 번지기 쉽습니다.
- 문을 천천히 닫았을 때 걸쇠가 문틀 구멍에 맞는지
- 닫힌 뒤 손잡이를 돌려도 문이 움직이지 않는지
- 안쪽 잠금 레버가 부드럽게 도는지

# 3단계 비밀번호와 등록된 카드 정리
가족이 쓰는 번호는 시간이 지나면 그 사이 몇 명이 알게 되었는지 알 수 없게 됩니다. / 점검할 때 번호를 바꾸는 것이 가장 깔끔합니다.
- 오래된 임시 번호와 손님용 번호 삭제
- 쓰지 않는 카드키와 태그 삭제
- 가족 모두가 새 번호를 알고 있는지 확인
- 번호 변경 방법을 메모해 두는 곳을 정하기
새 번호는 생일이나 전화번호 뒷자리처럼 남들이 짐작하기 쉬운 숫자는 피해 주세요. / 번호 관리 방식은 가족마다 다르니 편한 방식을 정하시면 됩니다.
@ 세교동 도어락 비밀번호 등록 카드 정리

# 4단계 번호판과 손잡이 겉면 닦기
번호판에 낀 기름때와 먼지는 센서를 둔하게 만듭니다. / 마른 천에 물을 약간 묻혀 닦고, 알코올이나 세정제는 직접 뿌리지 않습니다.
손잡이의 흔들림도 같이 봅니다. / 손잡이가 아래로 처지거나 돌릴 때 헛돈다면 안쪽 고정 나사가 풀렸을 가능성이 있습니다.
나사를 조이다가 도어락 안쪽 부품이 같이 움직이면 그만두고 전문가에게 맡기는 것이 좋습니다. / 조이기만 하다가 축이 어긋나는 일이 가끔 있습니다.

# 5단계 보조키와 비상 열쇠 위치 확인
디지털 도어락만 믿고 열쇠를 어디에 뒀는지 잊어버린 분이 많습니다. / 점검할 때 비상 열쇠가 어디 있는지, 아직 열쇠가 맞게 돌아가는지도 함께 확인하세요.
- 비상 열쇠를 한 번 꽂아 돌려서 부드럽게 도는지 확인
- 열쇠를 집 밖의 믿을 만한 곳에도 하나 두었는지
- 열쇠 구멍에 먼지가 쌓이면 마른 솔로 털어내기
열쇠가 뻑뻑하면 기름을 뿌리고 싶겠지만, 먼지가 엉겨 더 막힐 수 있습니다. / 이럴 때는 [열쇠 출장](key-call.html) 상담을 받아 보세요.

@ 세교동 도어락 건전지 교체 걸쇠 확인

# 6단계 경첩과 문틀 눈으로 보기
도어락이 멀쩡해도 경첩이 처지면 문이 안 열릴 수 있습니다. / 문을 닫았을 때 윗부분 틈이 아래보다 넓지 않은지 눈여겨보세요.
경첩 나사가 헐거우면 문이 처지고, 처진 문은 걸쇠를 문틀에서 비껴가게 만듭니다. / 나사를 손으로 돌려 보아 헛도는지만 확인해도 충분합니다.
문을 반쯤 열어 두었을 때 스스로 움직이는지도 보세요. / 저절로 닫히거나 열리면 경첩 축이 한쪽으로 기운 것이니, 그대로 쓰다 보면 문틀과 걸쇠가 같이 상합니다.
도어클로저가 달려 있다면 닫히는 속도가 너무 빠르거나 느리지 않은지도 같이 적어 두세요. / 속도 문제는 따로 조절하면 되는 경우가 많습니다.

# 점검표는 이렇게 기록해 두세요
점검 결과는 휴대폰 메모에 날짜와 함께 한 줄씩 적어 두면 좋습니다. / 다음 해에 같은 항목을 볼 때 어디가 달라졌는지 비교할 수 있습니다.
- 건전지 교체한 날
- 번호를 바꾼 날과 삭제한 카드 수
- 걸쇠 소리나 손잡이 느낌이 평소와 다른 곳
- 다음 점검 예정 달
가족이 함께 보는 메모장이나 단체 대화방에 올려 두면 누가 언제 했는지 헷갈리지 않습니다.

# 점검표에서 이상이 나왔다면
점검하다가 아래 증상이 보이면 해를 넘기지 말고 손보는 것이 좋습니다.
- 번호를 눌렀는데 모터 소리만 나고 걸쇠가 안 움직임
- 건전지를 새로 넣어도 번호판이 자주 꺼짐
- 문을 닫을 때 한 번에 안 잠기고 손으로 눌러야 잠김
이런 때는 [도어락 수리](doorlock-repair.html)로 먼저 확인합니다. / 너무 오래돼서 부품을 구하기 어려울 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 점검 중 문이 잠겨 버렸다면
점검은 문을 열어 둔 채로 하는 것이 안전합니다. / 현관문을 완전히 닫기 전에 열쇠나 휴대폰이 주머니에 있는지 먼저 확인하세요.
점검하다가 문을 닫고 나왔는데 열리지 않는 일도 있습니다. / 번호를 바꾸는 중이었다면 새 번호를 잘못 등록한 경우일 수 있습니다.
바꾼 번호를 여러 번 눌러도 안 되면 억지로 시도하지 마세요. / 입력이 한동안 막힐 수 있습니다. 이때 [현관문 개문](door-open.html)을 요청해 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
비용은 문 열기 전에 먼저 말씀드리고, 문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에서 보실 수 있습니다.

# 세교동 말고 평택 어디든 갑니다
세교동 옆 비전동, 동삭동, 서정동, 지산동은 물론 송탄동, 고덕동도 다닙니다. / 안중읍, 포승읍, 팽성읍, 청북읍까지 평택 안이면 24시간 출동합니다.
출동 지역은 [출장 지역](area.html) 지도에서 확인하세요.
