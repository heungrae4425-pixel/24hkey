# 서정동 교회 문 앞에서 열쇠가 없을 때
서정동은 서정리역 가까이에 상가와 주택이 섞여 있어 건물 한쪽에 교회나 종교시설이 들어서 있는 모습을 볼 수 있습니다. / 이른 새벽 기도나 주일 아침에 문을 열어야 하는데 열쇠를 가진 분이 연락이 안 되면 곤란해집니다.
이 글은 교회와 종교시설 출입문 열쇠를 어떻게 관리하면 좋은지, 문이 안 열릴 때 [평택 출장열쇠](pyeongtaek.html)를 부르는 순서를 정리했습니다. / 집 현관과 달리 여러 사람이 드나드는 문이라 관리 방법이 조금 다릅니다.
@ 서정동 교회 출입문 열쇠 확인

# 여러 사람이 쓰는 문은 열쇠가 퍼지기 쉽습니다
교회 문은 목회자, 관리하는 분, 청소하는 분, 찬양팀 등 여러 사람이 열어야 하는 경우가 많습니다. / 열쇠를 복사하다 보면 누가 몇 개를 갖고 있는지 아무도 모르게 되는 일이 생깁니다.
오래 쓴 열쇠일수록 이미 주인이 바뀌었거나 다른 곳으로 옮겨 간 경우도 있습니다. / 지금 쓰는 열쇠가 몇 개인지 한 번은 정리해 보는 것이 좋습니다.

# 열쇠 대장을 만들어 두세요
거창한 장부가 필요하지는 않습니다. / 종이 한 장에 열쇠 번호, 가진 분 이름, 받은 날짜만 적어도 충분합니다.
- 정문과 후문, 예배당, 사무실 문 구분
- 열쇠 가진 분의 이름과 받은 날짜
- 반납했는지 여부
- 예비 열쇠를 보관하는 장소
사람이 바뀔 때마다 이 장부를 같이 고치면 누구에게 연락해야 하는지 바로 알 수 있습니다.

# 열쇠를 도어락으로 바꿀 때 생각할 것
번호나 카드를 쓰는 도어락으로 바꾸면 열쇠를 돌려받지 못해도 번호만 바꾸면 됩니다. / 다만 번호를 아는 사람이 많아질수록 번호가 퍼질 수 있으니 주기적으로 바꾸는 습관이 필요합니다.
출입문이 철문이거나 유리문이면 설치 가능한 기종이 달라질 수 있습니다. / 먼저 [도어락 설치](doorlock-install.html) 문의로 문 종류를 알려 주시면 맞는 방식을 말씀드립니다.

# 문이 안 열릴 때 먼저 해 볼 것
갑자기 문이 안 열릴 때는 원인부터 나눠 보세요. / 번호판이 꺼졌는지, 소리는 나는데 안 열리는지, 열쇠가 돌아가지 않는지에 따라 다릅니다.
- 번호판이 꺼졌으면 배터리를 먼저 의심
- 열쇠가 돌아가다 멈추면 억지로 돌리지 않기
- 문이 덜 닫혀 있는지, 안쪽 걸쇠가 걸렸는지 확인
- 다른 출입문으로 들어갈 수 있는지 확인
@ 교회 문 번호판과 열쇠 구멍 상태 확인

# 예배 시간이 임박했을 때 하지 말 것
시간이 급하면 문을 세게 밀거나 열쇠 구멍에 이것저것 넣어 보고 싶어집니다. / 하지만 그러면 열쇠 구멍이 막히거나 문이 상해 고치는 시간이 더 길어집니다.
열쇠가 안 돌아가는데 힘으로 돌리면 열쇠가 부러져 안에 남을 수 있습니다. / 한두 번 시도하고 안 되면 멈추고 전화 주시는 편이 빠릅니다.

출입문이 하나가 아니라 정문, 후문, 사무실, 주방 문까지 여러 개인 곳도 있습니다. / 문마다 열쇠가 따로인 경우가 많으니, 어느 문이 안 열리는지 정확히 알려 주세요.
본당 문이 막혔을 때는 다른 문으로 우선 들어갈 수 있는지도 같이 알려 주시면 작업 순서를 정하기 쉽습니다.
# 유리문, 철문, 목재문에 따라 다른 점
교회 출입문은 건물마다 재질이 달라서 열쇠 구조도 다릅니다. / 철문은 잠금 장치가 두껍고 유리문은 하단 바닥 쪽에 잠금이 달린 경우도 있습니다.
문 재질과 잠금 모양을 사진으로 보내 주시면 맞는 장비를 챙겨 갑니다. / 어떤 문인지 모르면 바깥과 안쪽 모양을 모두 찍어 보내 주세요.

# 비어 있는 시간대의 점검 요령
교회는 평일에 비어 있는 시간이 길어서 도어락 배터리가 모르는 사이 닳는 경우가 있습니다. / 주일 아침에야 문이 안 열려 알게 되면 낭패이니, 평일에 한 번 확인해 두세요.
- 배터리 교체 시기를 달력에 적기
- 안쪽에서 비상 개폐가 되는지 확인
- 예비 열쇠를 건물 밖이 아닌 안전한 곳에 보관
특히 열쇠를 문 근처 화분 밑이나 우편함에 숨겨 두는 습관은 피하는 것이 좋습니다.

행사나 예배 시간이 정해져 있다면 몇 시까지 열려야 하는지도 말씀해 주세요. / 시간이 촉박한 경우 도착 예상 시간을 먼저 말씀드리고, 그 안에 가능한지 솔직하게 안내합니다.
문을 열 때 안에 어린이나 어르신이 있는 경우도 꼭 먼저 알려 주세요. / 안쪽에서 문이 잠긴 상황이라면 순서가 달라집니다.
# 출장 요청 시 알려주실 정보
서정동은 건물이 이어져 있어 정확한 위치를 알려 주시는 것이 도움이 됩니다. / 건물 층과 호수, 어느 문인지를 구체적으로 말씀해 주세요.
- 서정리역에서 어느 방향인지
- 열어야 하는 문이 정문인지 후문인지
- 도어락인지 열쇠 방식인지
- 안에 사람이 갇혀 있는지 여부
@ 서정동 종교시설 출입문 도어락 사진 전달

종교시설은 대표자 한 분이 모든 열쇠를 관리하지 않는 경우가 많습니다. / 현장에 계신 분이 관계자라는 것을 확인할 수 있는 분께 연락해 주시면 진행이 빠릅니다.
# 문을 여는 분이 누구인지 확인합니다
교회 문도 마찬가지로 문을 여는 분이 관계자가 맞는지 먼저 확인합니다. / 건물 관리인이나 임대 계약서, 건물주 확인 등 확인할 수 있는 방법을 말씀해 주세요.
신분증과 함께 건물을 관리하는 사실이 확인되는 서류나 관리사무소 확인이 있으면 좋습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.

교회 문은 모두가 쓰는 공간이라 한 번 고장 나면 불편이 큽니다. / 그래서 문을 연 뒤 같은 일이 반복되지 않게 원인까지 같이 설명해 드립니다.
작업 전에 문을 어떻게 열지, 부품을 바꿔야 할 가능성이 있는지도 미리 말씀드립니다. / 예산을 정해야 하는 단체라면 이 설명을 듣고 회의를 거쳐 결정하셔도 됩니다.
# 비용은 문 열기 전에 말씀드립니다
문 종류와 잠금 방식을 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

문 여는 방법은 여러 가지가 있고, 덜 상하는 방법부터 차례로 해봅니다. / 건물 외관과 문틀이 상하지 않게 하는 것이 먼저입니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다. / 문 여는 방법은 [문 열기](door-open.html) 페이지에 자세히 적어 두었습니다.

# 열고 난 뒤 열쇠와 번호를 정리하세요
문이 열리면 다시 잘 잠기고 열리는지 같이 확인합니다. / 열쇠를 잃어버려서 문제가 생긴 경우라면 열쇠 정리를 이 기회에 하는 것이 좋습니다.
열쇠를 새로 맞추거나 도어락 번호를 바꾸는 것까지 [열쇠 출장](key-call.html)에서 같이 안내합니다. / 가진 사람이 많으면 번호를 바꾸고 아는 사람만 다시 알려 주세요.

서정동 옆 지산동, 송탄동, 고덕동을 비롯해 평택 안이면 동네 상관없이 다닙니다. / 안중읍, 포승읍, 팽성읍, 청북읍도 갑니다.
다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
