# 서정동에서 지문 도어락이 말을 안 들을 때
서정동은 서정리역과 가까워 아침저녁으로 출퇴근하는 분이 많은 동네입니다. / 바쁜 시간에 지문이 인식되지 않으면 몇 분만 늦어도 곤란해집니다.
어제까지 잘 되던 지문이 오늘 갑자기 안 읽히는 일은 생각보다 흔합니다. / 이 글은 평택 서정동에서 지문 도어락이 말썽일 때 확인할 것을 정리했습니다.
[평택 출장열쇠](pyeongtaek.html)를 부르기 전에 아래 순서를 한 번만 따라 해 보세요. / 대부분은 손과 센서만 깨끗이 해도 돌아옵니다.
@ 서정동 지문 인식 도어락 출장열쇠

# 손 상태부터 확인해 보세요
손가락이 젖었거나 지나치게 건조하면 센서가 선을 잘 읽지 못합니다. / 겨울에는 건조해서, 여름에는 땀 때문에 실패하는 일이 많습니다.
손을 닦고 잠시 후에 다시 대 보세요. / 너무 세게 누르지 말고 평소처럼 자연스럽게 올려 주세요.
손가락에 상처가 났거나 굳은살이 생긴 경우도 인식이 흔들립니다. / 이럴 때는 다른 손가락으로 시도해 보세요.

# 센서 표면을 닦아 주세요
센서에 지문 기름과 먼지가 쌓이면 읽는 힘이 약해집니다. / 부드러운 마른 천으로 한두 번 닦아 주면 좋아지는 경우가 많습니다.
물이나 알코올을 직접 뿌리면 안쪽으로 스며들 수 있으니 피하세요. / 천에 아주 약간만 묻혀 닦는 정도면 충분합니다.
번호판 쪽이 아니라 센서 부분을 중심으로 닦아 주세요. / 센서에 긁힘이 있다면 제품 점검이 필요할 수 있습니다.
@ 평택 서정동 지문 센서 점검 출장

# 다른 손가락과 다른 각도로 해 보세요
등록했던 손가락과 대는 위치가 조금만 달라도 인식이 안 될 수 있습니다. / 처음 등록할 때처럼 같은 위치, 같은 각도로 올려 보세요.
손가락 전체가 센서에 닿도록 하되 너무 오래 대고 있지는 마세요. / 한 번에 되지 않아도 두세 번 시도해 보면 됩니다.
여러 손가락을 등록해 두면 이런 때 큰 도움이 됩니다. / 등록 방법은 제품마다 다르니 설명서를 참고하세요.

# 지문이 안 되면 번호나 카드로
지문이 되지 않아도 번호나 카드로 열 수 있는 제품이 대부분입니다. / 번호를 기억하고 있다면 당황하지 않아도 됩니다.
번호까지 기억나지 않는다면 [현관문 개문](door-open.html) 쪽으로 연락 주세요. / 지문 센서만 문제인지 도어락 전체 문제인지 먼저 확인합니다.
배터리가 약해져도 지문 센서가 가장 먼저 반응이 나빠집니다. / 경고음이 있었는지 떠올려 보세요.

# 배터리가 약해서 생기는 증상
지문 센서는 전기를 많이 쓰는 부품이라 배터리가 약해지면 가장 먼저 느려집니다. / 번호는 눌리는데 지문은 반응이 느리다면 배터리를 의심해 보세요.
배터리를 전부 새것으로 바꾸면 해결되는 경우가 꽤 많습니다. / 일부만 바꾸면 며칠 못 가서 같은 증상이 나옵니다.
바꾸고도 안 되면 센서나 기판 쪽 문제일 수 있습니다. / 이때는 점검이 필요합니다.

# 지문 재등록은 이렇게 합니다
기존 지문을 지우고 새로 등록하면 인식이 좋아지는 경우가 있습니다. / 다만 방법이 제품마다 다르고 관리자 번호가 필요할 수 있습니다.
설명서가 없으면 제조사 이름과 모델명을 사진으로 찍어 두세요. / 모델을 알면 등록 방법을 안내하기 쉽습니다.
재등록 중에는 손가락을 여러 각도로 여러 번 올려 두는 것이 좋습니다. / 한 번에 끝내려 하지 말고 천천히 진행하세요.

# 이런 증상이면 점검이 필요합니다
센서에 불이 안 들어오거나 계속 깜빡이는 경우입니다. / 지문을 대도 아무 반응이 없는 경우도 마찬가지입니다.
센서 표면이 깨졌거나 금이 갔다면 습기가 들어가 고장이 커질 수 있습니다. / 그대로 쓰지 말고 점검받으세요.
번호도 카드도 안 되고 문이 안 열린다면 바로 연락 주세요. / 먼저 사진을 보내 주시면 더 빠릅니다.

# 문 앞에서 막혔을 때 개문은 이렇게 합니다
번호, 카드, 지문이 모두 안 되면 도어락 전체 점검이 필요합니다. / 문을 상하지 않게 여는 것이 먼저입니다.
덜 상하는 방법부터 차례로 해 보고 작업 전에 어떤 방법인지 설명드립니다. / 안 열리는 방법은 쓰지 않고 다른 방법을 말씀드립니다.
문이 열린 뒤에 센서와 배터리, 기판을 살펴봅니다. / 고쳐서 쓸 수 있는지 먼저 확인합니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
지문이 안 열린다고 해서 확인 절차를 건너뛰지는 않습니다. / 이웃과 가족 모두를 위한 절차입니다.
확인이 어려우면 작업을 하지 못합니다. / 미리 챙겨 두시면 시간이 줄어듭니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 수리로 될지 교체가 나을지
센서만 문제라면 센서를 바꿔 쓸 수 있는지 먼저 확인합니다. / 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.
[도어락 수리](doorlock-repair.html)로 해결이 안 되고 제품이 너무 오래되었다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 이유를 먼저 설명드리고 선택은 부르신 분이 합니다.
지문 방식이 불편했다면 번호와 카드 중심의 제품으로 바꾸는 방법도 있습니다. / 사용하시는 가족 모습에 맞춰 같이 고민해 드립니다.
@ 서정동 24시 지문 도어락 수리 교체

# 서정동 말고 평택 어디든 갑니다
서정동 옆 송탄동, 지산동, 고덕동도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
평택에서 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
서정리역 쪽인지 평택역 쪽인지만 알려 주셔도 도착 시간을 알려 드립니다. / 위치는 건물 이름과 층, 호수까지 말씀해 주시면 더 정확합니다.

# 자주 묻는 질문
? 지문이 자꾸 인식 실패하는 이유가 뭔가요? | 손 상태, 센서 오염, 배터리 약화가 가장 흔한 원인입니다. 닦고 배터리를 바꿔 보시고 안 되면 연락 주세요.
? 지문 센서만 따로 바꿀 수 있나요? | 제품에 따라 가능합니다. 모델을 확인한 뒤 가능한 범위를 말씀드립니다.
? 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 지문이 안 되는데 번호도 기억이 안 나요. | 바로 전화 주세요. 사시는 분 확인 후 덜 상하는 방법으로 열어 드립니다.
? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
