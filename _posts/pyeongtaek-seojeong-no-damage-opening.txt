# 문을 부수지 않고 연다는 말, 정확히 무슨 뜻일까
서정동에서 서정리역을 오가다 문이 잠겨 곤란을 겪는 분들이 가장 먼저 걱정하는 것은 문이 망가지지 않을까 하는 점입니다. / 전화로 비파손 개방이라는 말을 들으면 설명이 부족해 막연하게 느껴지기도 합니다.
이 글은 비파손 개방이 어떤 뜻인지, 어떤 문에서 가능하고 어떤 때는 어려운지, [평택 출장열쇠](pyeongtaek.html)가 어떤 순서로 진행하는지를 쉬운 말로 풀어 정리했습니다.
@ 서정동 현관문 비파손 개방 설명

# 비파손 개방은 문을 그대로 두고 잠금만 푸는 일입니다
말 그대로 문이나 도어락을 깨뜨리거나 뜯어내지 않고 잠금 상태만 해제하는 방식입니다. / 열고 난 뒤에도 문이 이전처럼 쓰이는 것을 목표로 합니다.
문을 부수거나 도어락을 통째로 뜯어내는 방식은 확실하게 열 수는 있어도 열고 나면 새로 설치해야 하는 부담이 따릅니다. / 그래서 먼저 상하지 않는 방법을 시도하고, 정말 어려울 때만 다른 방법을 말씀드립니다.
어떤 방법이든 하기 전에 먼저 설명하고 동의를 받은 뒤에 진행합니다.

# 잠금장치마다 여는 방법이 다릅니다
같은 현관문이라도 안쪽 구조에 따라 접근 방법이 달라집니다.
- 번호나 지문 방식의 디지털 도어락
- 열쇠를 꽂아 돌리는 원통형 잠금장치
- 문 옆면의 데드볼트와 걸쇠가 함께 있는 구조
- 안쪽 보조키가 따로 달린 현관문
어느 쪽이든 잠금을 풀기 위한 가장 약한 경로부터 차례로 시도합니다. / 이 과정에서 문이나 장치에 흔적이 남지 않도록 조심합니다.

# 비파손으로 열 수 있는 경우
다음과 같은 상황은 비파손 개방이 가능한 경우가 많습니다.
- 건전지가 다 되어 번호판이 꺼진 경우
- 비밀번호를 잊어버린 경우
- 열쇠를 집 안에 두고 문이 닫힌 경우
- 걸쇠나 빗장만 걸려 문이 안 열리는 경우
다만 같은 상황이라도 문의 상태와 도어락 종류에 따라 결과가 달라질 수 있어 현장에서 보고 판단합니다.
@ 도어락 상태를 눈으로 확인하는 모습

# 비파손이 어려울 수 있는 경우
솔직하게 말씀드리면 모든 문을 상하지 않고 열 수 있는 것은 아닙니다. / 안쪽에서 보조 잠금이 이중 삼중으로 걸려 있거나 부품이 부러져 있으면 어려울 수 있습니다.
오래되어 문이 휘었거나 잠금장치 내부가 이미 고장 난 경우도 마찬가지입니다. / 이럴 때는 먼저 상태를 설명드리고 어떤 선택지가 있는지 말씀드립니다.
끝내 열지 못하면 비용은 받지 않으니 그 점은 마음 놓으셔도 됩니다.

# 열기 전에 현장에서 가장 먼저 보는 것
도착하면 바로 작업을 시작하지 않고 문과 도어락 상태를 먼저 살핍니다. / 서둘러 시작하면 오히려 문제를 키우기 때문입니다.
- 도어락 브랜드와 모양
- 번호판이 켜지는지, 경고음이 나는지
- 문틈과 문틀의 처짐 정도
- 안쪽에 잠금이 몇 개 걸려 있을 가능성이 있는지
이 확인에 걸리는 시간이 짧아 보여도 이후 작업의 성패를 좌우합니다.

# 비파손과 일반 개방, 무엇이 다른가요
이 둘은 결과보다 과정이 다릅니다. / 비파손 개방은 부품을 부수지 않고 잠금 구조를 이해해 푸는 방식이라 시간이 조금 더 걸릴 수 있습니다.
급하다고 해서 더 빠른 방법이 항상 더 좋은 것은 아닙니다. / 문이 상하면 열린 뒤에 다시 잠그지 못해 밤새 문을 열어 둔 채 지내야 하는 일이 생기기도 합니다.
그래서 시간이 조금 더 걸려도 문을 지키는 방법을 먼저 권해 드립니다. / 안에 사람이 갇혀 있는 등 급박한 상황이라면 그 사정에 맞게 방법을 바꿀 수 있으니 처음 통화에서 꼭 알려 주세요.

# 직접 해보려다 문을 상하게 하는 흔한 방법
- 카드나 도구로 문틈을 벌려 걸쇠를 밀어내려는 것
- 손잡이를 세게 비틀거나 당기는 것
- 번호판을 뜯어내려는 것
- 문을 발로 차거나 어깨로 밀어붙이는 것
이런 방법은 걸쇠를 더 단단하게 물리게 하거나 문틀을 휘게 해서 비파손 개방을 오히려 어렵게 만듭니다. / 급해도 손대지 말고 그 자리에서 전화 주시는 편이 훨씬 낫습니다.

# 전화하실 때 알려주시면 좋은 내용
서정동은 서정리역과 가까운 주택과 원룸, 상가가 섞여 있어 위치 설명이 있으면 빠르게 찾아갈 수 있습니다.
- 주소와 건물 종류, 몇 층인지
- 서정리역에서 어느 방향인지
- 도어락 사진
- 번호판이 켜지는지 여부
- 집 안에 사람이나 반려동물이 있는지
도어락 사진은 정면과 측면 모두 보내 주시면 좋습니다.

# 도착하면 신분을 확인하고 비용을 먼저 말씀드립니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인하는 절차를 둡니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁해 두세요. / 확인이 어려우면 작업을 진행할 수 없습니다.
@ 서정동 출장열쇠 신분 확인 후 개방

현장에서 문과 도어락을 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용은 없고, 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 문이 열린 뒤 확인하는 것들
문이 열리면 흔적이나 손상이 없는지 같이 봅니다. / 도어락이 이전처럼 잠기고 열리는지도 확인합니다.
원인이 건전지였다면 새것으로 전부 교체하고, 비밀번호를 잊어서 연 경우라면 새 번호를 등록해 드립니다. / 고장이 있다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 설명드립니다.
개방 과정이 더 궁금하시면 [현관문 개문](door-open.html) 페이지를 참고해 주세요.

상하지 않고 잘 열렸던 집들은 평소 관리가 조금 더 되어 있습니다. / 건전지를 제때 바꾸고, 문이 정상적으로 닫히고, 경고음을 무시하지 않은 집입니다.
반대로 경첩이 처져 문이 틀에 눌려 있거나 열쇠 구멍에 먼지가 가득한 집은 작업이 한층 까다롭습니다. / 평소 관리가 급할 때의 선택지를 넓혀 줍니다.

# 다음에 같은 일이 없도록 해두면 좋은 것
- 건전지는 해가 바뀔 때 한 번에 교체하기
- 열쇠나 카드키 한 개를 집 밖 안전한 곳에 보관
- 문이 덜 닫히는 증상은 일찍 점검하기
- 가족이 모두 비밀번호를 알고 있는지 확인하기
문이 잠기는 일은 누구에게나 생깁니다. / 중요한 것은 당황하지 않고 상하지 않는 방법을 먼저 찾는 것입니다.

# 서정동 밖 평택 어디든 갑니다
서정동 바로 옆 지제역, 평택역, 송탄역 주변까지 평택 전역을 다닙니다. / 평택 안이라면 24시간 출동합니다.
다니는 동네는 [평택시 출장열쇠](pyeongtaek.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
