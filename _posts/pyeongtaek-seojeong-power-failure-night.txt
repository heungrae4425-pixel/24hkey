# 서정동 정전, 문 앞에서 가장 먼저 드는 걱정
평택 서정동은 서정리역을 중심으로 상가와 주택이 섞인 생활권이라 늦은 시간에도 오가는 분이 많습니다. / 갑자기 정전이 된 밤에 문 앞에 서면 전자식 도어락이 열릴지부터 걱정됩니다.
정전이라고 해서 모든 도어락이 먹통이 되는 것은 아닙니다. / 어떤 방식의 도어락인지, 어떤 전원을 쓰는지에 따라 달라집니다.
이 글은 서정동에서 정전된 밤 도어락이 어떻게 되는지, 문 앞에서 무엇을 확인하면 되는지를 순서대로 적었습니다. / 해결이 안 되면 [평택 출장열쇠](pyeongtaek.html)에 연락하는 방법도 이어서 정리했습니다.
@ 서정동 정전 밤 현관문 도어락

# 대부분의 도어락은 정전과 상관없이 작동합니다
가정용 디지털 도어락은 대개 도어락 안의 건전지로 움직입니다. / 그래서 집 전기가 나가도 번호 입력과 문 열림에는 영향이 없는 경우가 많습니다.
- 건전지로 움직이는 방식은 정전에 거의 영향받지 않음
- 집 전원에 직접 연결된 방식은 정전 시 작동이 달라질 수 있음
- 공동현관이나 자동문은 건물 전기에 따라 먹통이 될 수 있음
내 집 도어락이 어느 방식인지는 안쪽 몸체에 건전지 덮개가 있는지로 대충 알 수 있습니다. / 덮개가 있고 건전지를 넣는 구조라면 대부분 첫 번째입니다.

# 번호판이 어두워서 안 보일 때
정전이 되면 복도 불이 꺼져 번호판 숫자가 잘 안 보입니다. / 번호판은 손이 닿으면 불이 들어오는 방식이 많으니 손바닥을 가볍게 대 보세요.
휴대폰 손전등을 켜서 비추면 숫자 위치가 보입니다. / 번호판에 불이 안 들어와도 숫자 위치를 기억한다면 눌러 볼 수 있습니다.
습관처럼 같은 번호를 빠르게 누르면 입력이 막힐 수 있으니 한 자리씩 천천히 누르세요. / 정전으로 마음이 급해지면 입력이 틀리는 일이 흔합니다.

# 번호판이 안 켜지면 9V 건전지를 대 보세요
번호판이 켜지지 않으면 건전지가 약한 상태에서 정전이 겹친 것일 수 있습니다. / 바깥쪽 아래에 있는 비상 단자에 9V 건전지를 대면 임시로 전원이 들어옵니다.
- 건전지의 단자 방향을 맞춰 단자에 밀착
- 건전지를 대는 동안 번호를 입력
- 문이 열리면 즉시 안쪽 건전지를 새것으로 교체
정전 중에 편의점 같은 곳이 닫혀 있으면 구하기 어려울 수 있습니다. / 평소에 집이나 차에 비상용으로 한 개씩 두는 습관이 도움이 됩니다.

# 전원 연결식 도어락일 때는 어떨까
문 안쪽 몸체에서 전원선이 나와 있거나, 집 안 월패드와 연결된 제품이라면 이쪽일 가능성이 있습니다. / 정전이 길어지면 보조 전원이 먼저 소진됩니다.
일부 제품은 문 위쪽 전원선이나 인터폰과 연결되어 있고 보조 건전지를 쓰는 방식입니다. / 이 경우 정전이 되면 번호판이 꺼지고 보조 건전지로만 버티는 경우가 많습니다.
보조 건전지가 남아 있으면 열리고, 방전됐다면 번호판이 꺼진 채 반응이 없습니다. / 오래 쓴 제품일수록 후자가 많아 정전된 밤 문제가 되기 쉽습니다.
제품 종류는 도어락 모양만으로 알기 어려우니, 사진을 찍어 두면 상담할 때 도움이 됩니다.

# 정전일 때 하지 말아야 할 것
급한 마음에 도어락 앞면 패널을 억지로 열거나 단자를 만지지는 마세요. / 습기가 있는 날에는 합선 위험도 있습니다.
- 라이터나 성냥으로 불을 밝히며 도어락을 만지기
- 번호판을 젖은 손으로 반복해서 누르기
- 도어락을 발로 차거나 문을 세게 밀기
- 건전지를 아무 방향으로나 대 보기
정전 중에는 방범 상태도 평소와 다르니 서두르지 말고 주변을 한 번 둘러보세요. / 혼자 계신 것이 불안하면 건물 1층이나 밝은 상가 앞으로 이동해 기다리세요.
@ 서정동 도어락 9V 건전지 비상 단자

# 정전이 풀린 뒤 도어락이 이상할 때
전기가 들어왔다고 곧바로 안심하기는 이릅니다. / 갑자기 전압이 오르내리면 도어락 기판이 영향을 받아 평소 하지 않던 경고음을 낼 수 있습니다.
전기가 다시 들어온 뒤 도어락이 이상 동작을 하는 경우가 있습니다. / 번호판이 깜빡이거나, 모터 소리만 나거나, 시간이 틀어지는 증상이 대표적입니다.
- 정전 전후로 건전지를 새것으로 한꺼번에 교체
- 번호판이 켜져도 모터가 안 도는지 확인
- 문을 열고 닫으며 걸쇠 소리가 평소와 같은지 확인
증상이 계속되면 [도어락 수리](doorlock-repair.html)를 먼저 알아보세요. / 부품이 낡아서 반복된다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 정전과 상관없이 문이 안 열릴 때
정전과 도어락 고장이 우연히 겹친 경우도 있습니다. / 번호는 맞는데 모터 소리만 나거나 문이 꿈쩍 않는다면 정전이 아닌 걸쇠 쪽을 의심해야 합니다.
이웃 세대 복도 불이 들어와 있다면 우리 집만 전원이 문제인 것이니, 집 차단기를 확인해 보세요. / 문밖에서는 확인하기 어려우니 이웃이나 경비실을 통해 알아보는 것도 방법입니다.

# 전화할 때 알려주실 것
밤에 길게 통화하기 어렵다면 문자로 먼저 상황을 남겨 두셔도 됩니다. / 위치, 번호판 상태, 아이나 반려동물 유무 세 가지만 있어도 출동 준비가 훨씬 빨라집니다.
정전된 밤에는 통화가 길어지면 휴대폰 배터리가 걱정되니 짧고 정확하게 말씀해 주세요.
- 서정동 안에서 건물 위치와 동, 호수
- 번호판이 켜지는지, 소리가 나는지
- 9V 건전지를 대 봤는지
- 집 안에 아이나 반려동물이 있는지
도어락 사진과 현재 위치를 문자로 보내 두면 통화가 끊겨도 안심됩니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
정전 중이라 관리사무소가 닫혀 있다면 경비실이나 이웃을 통한 확인 방법을 같이 찾아봅니다. / 확인이 어려우면 작업을 할 수 없으니 신분증은 미리 챙겨 다니시길 권합니다.

# 비용은 문 열기 전에 말씀드립니다
어두운 곳에서 서두르지 않고 도어락 상태를 확인한 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 문 여는 방식은 [현관문 개문](door-open.html)에, 전체 진행은 [이용안내](guide.html)에 적어 두었습니다.
@ 서정동 출장열쇠 정전 밤 현관문 개문

# 서정동 말고 평택 어디든 갑니다
서정동 옆 지산동, 송탄동, 고덕동은 물론 안중읍, 포승읍, 팽성읍, 청북읍도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
출동 지역은 [출장 지역](area.html) 지도에서 확인하세요.

# 자주 묻는 질문
? 정전이면 도어락도 무조건 안 열리나요? | 아닙니다. 건전지로 움직이는 방식은 정전과 상관없이 열리는 경우가 많습니다.
? 9V 건전지는 어디에 대나요? | 도어락 바깥쪽 아래에 비상 단자가 있는 제품이 많습니다. 단자 방향을 맞춰 밀착하세요.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.

서정동에서 정전된 밤에 도어락이 안 열려도 당황하지 마세요. / 번호판 상태를 보고 9V 건전지를 대 본 뒤 안 되면 연락 주세요.
