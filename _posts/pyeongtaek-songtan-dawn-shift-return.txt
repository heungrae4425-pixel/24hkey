# 송탄동 새벽 귀가길, 번호판이 먹통이면
송탄동은 송탄역 가까이에 주택과 상가가 이어져 있어 교대 근무를 하는 분들의 귀가가 이른 새벽이나 한밤에 몰리는 동네입니다. / 밤새 일하고 돌아와 집 앞에서 번호판이 반응하지 않으면 피로까지 겹쳐 더 막막해집니다.
이 글은 송탄동에서 새벽 근무를 마치고 돌아왔는데 번호판이 꺼져 있거나 눌러도 반응이 없을 때 확인할 것을 정리했습니다. / 가능한 것부터 해보고 안 되면 [평택 출장열쇠](pyeongtaek.html)를 부르는 순서입니다.
새벽에는 이웃이 자고 있으니 소리를 내는 방법도 조심해야 합니다. / 그 점도 같이 적었습니다.
@ 송탄동 새벽 귀가 도어락 번호판 먹통

# 새벽에 번호판이 반응하지 않는 흔한 이유
같은 증상이라도 원인은 여러 가지입니다. / 상태를 눈으로 먼저 구분하면 해결이 빨라집니다.
- 배터리가 거의 다 돼서 번호판 불이 아예 안 들어오는 경우
- 불은 들어오는데 눌러도 소리가 안 나는 경우
- 소리는 나는데 모터가 돌다 마는 경우
- 출근할 때 문을 덜 닫아 걸쇠가 반쯤 걸려 있는 경우
- 낮 동안 가족이 비밀번호를 바꿔 놓은 경우
밤샘 근무를 하는 분은 낮에 집에서 쉬는 가족과 번호가 달라진 줄 모르고 오는 일도 있습니다. / 가족에게 연락이 닿는다면 가장 먼저 물어보세요.

# 번호판을 건드리기 전에 손으로 확인
문 앞에 서서 번호판을 손으로 덮거나 가볍게 두드려 보세요. / 센서형이라면 덮었을 때 불이 켜지는 경우가 있습니다.
바깥 쪽 아래에 9V 건전지를 대는 비상 단자가 있는지도 봅니다. / 많은 도어락이 이 단자를 통해 잠시 전원을 받아 문을 엽니다.
근무 중에 건전지를 구하기 어렵다면 편의점이나 24시간 마트에서 구할 수 있는지 떠올려 보세요. / 송탄역 근처 생활권에는 새벽에도 문을 여는 곳이 있을 수 있습니다.
@ 송탄동 도어락 비상 전원 9V 건전지

# 비밀번호를 여러 번 누르지 마세요
졸린 상태에서 번호를 자꾸 누르게 되지만 서너 번 틀리면 도어락이 입력을 막습니다. / 일정 시간 동안 아무 반응이 없게 되고, 그동안 번호를 눌러도 더 오래 막힐 수 있습니다.
번호를 기억 못 하는 것인지 번호판이 반응 못 하는 것인지 구분하는 것이 중요합니다. / 숫자를 눌렀을 때 소리와 불빛이 있으면 번호판은 살아 있는 것입니다.
기억이 안 날 때는 한참 쉬었다가 다시 천천히 눌러 보세요. / 피곤할 때 습관처럼 누르던 번호가 갑자기 생각나지 않는 일은 흔합니다.

# 문을 세게 당기거나 흔들지 마세요
빨리 들어가고 싶어서 손잡이를 세게 당기거나 문을 발로 차는 분이 있습니다. / 걸쇠가 문틀을 더 세게 물거나 손잡이 축이 휘어 일이 커집니다.
카드나 드라이버로 문틈을 벌리려는 시도도 문틀과 도어락 외관을 상하게 합니다. / 새벽에 큰 소리가 나면 이웃에게 불안을 줄 수도 있습니다.
조용히 상태를 확인하고 필요하면 전화를 해 주세요. / 문이 닫혀 있는 한 급할 것은 없습니다.

# 날이 추우면 건전지 반응도 느려집니다
새벽 기온이 내려가면 도어락 배터리는 전압이 떨어져 평소보다 반응이 느려집니다. / 집을 나설 때는 멀쩡했는데 돌아와서 안 되는 이유 중 하나입니다.
건전지를 손으로 잠깐 감싸서 따뜻하게 한 뒤 비상 단자에 대면 반응할 때도 있습니다. / 방법이 맞는 모델인지 확인되지 않았다면 억지로 하지 말고 전화 주세요.
가을과 겨울이 되면 문 앞에서 이런 일이 부쩍 늘어납니다. / 배터리를 미리 갈아 두는 습관이 도움이 됩니다.

# 전화할 때 알려 주면 빠른 정보
새벽에는 전화로 짧게 설명하는 편이 좋습니다. / 아래만 말씀해 주시면 출발을 준비합니다.
- 송탄역 쪽인지 시장 쪽인지 등 대략적인 위치
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 소리가 나는지, 모터가 돌아가는지
- 비상 단자 유무와 건전지를 대 봤는지 여부
- 집 안에 가족이나 반려동물이 있는지
가족이 안에서 자고 있다면 초인종이나 노크로 깨울 수 있는지도 알려 주세요. / 그것이 가장 빠른 해결일 때가 있습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 새벽이라도 신분 확인을 합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁해 보세요. / 새벽에는 직원이 없을 수 있으니 미리 방법을 생각해 두면 좋습니다.
가족이 안에 있다면 가족이 문 안쪽에서 확인해 줄 수도 있습니다. / 확인이 어려우면 작업이 어려운 점 양해 부탁드립니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
시간대와 상관없이 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 문을 최대한 상하지 않게 엽니다
새벽에는 소음도 신경 써야 합니다. / 이웃이 자는 시간이니 가능한 한 조용한 방식부터 차례로 해봅니다.
도어락과 문틀이 상하지 않는 쪽이 먼저입니다. / 방식은 [현관문 개문](door-open.html)에 설명한 원칙과 같습니다.
도어락 종류에 따라 걸리는 시간이 다르니 시작 전에 대략 말씀드립니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 여쭙습니다.

# 열고 난 뒤 배터리와 번호 점검
문이 열리면 도어락이 다시 잘 잠기고 열리는지 확인합니다. / 배터리가 원인이라면 안쪽 배터리를 모두 새것으로 바꾸시길 권합니다.
번호가 바뀐 것이 원인이었다면 가족과 새 번호를 함께 정하시면 좋습니다. / 기존 번호는 지우고 새 번호만 남깁니다.
반응이 자주 느리다면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 먼저 봅니다. / 너무 오래된 제품일 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 송탄동 도어락 배터리 교체 후 확인

# 교대 근무자를 위한 도어락 사용 요령
퇴근 시간이 일정하지 않은 분은 도어락 관리가 더 중요합니다. / 아래 습관을 추천드립니다.
- 근무 가는 날 배터리 경고음이 났다면 그날 바로 교체하기
- 비상용 9V 건전지를 가방에 하나 넣어 두기
- 카드키나 열쇠 하나는 직장 사물함이나 믿을 만한 곳에 두기
- 가족과 비밀번호 변경은 반드시 같이 공유하기
- 퇴근 전 가족에게 도착 시간을 알려 두기
작은 준비가 새벽 문 앞의 막막함을 크게 줄여 줍니다. / 특히 비상 건전지 하나는 효과가 큽니다.

# 송탄동 말고 평택 어디든 갑니다
송탄동 주변 지산동, 서정동, 비전동, 세교동은 물론 안중읍, 포승읍, 팽성읍, 청북읍도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
평택에서 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.
