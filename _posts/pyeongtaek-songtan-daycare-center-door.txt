# 송탄동 돌봄 시설의 출입문은 하루에도 수십 번 열립니다
평택 송탄동은 송탄역 생활권으로 오가는 가정이 많아 어린이집이나 돌봄 공간을 찾는 부모님도 많습니다. / 이런 시설의 출입문은 아이들이 오가고 보호자가 드나들고 교사가 수시로 확인하는 문입니다.
일반 가정집 현관문보다 사용 횟수가 훨씬 많고, 쓰는 사람도 다양합니다. / 그만큼 도어락이나 잠금장치가 빨리 닳고, 문제가 생기면 아이들 안전과 바로 연결됩니다.
이 글은 송탄동에서 어린이집이나 돌봄 시설을 운영하시는 분들이 출입문을 점검할 때 보는 항목을 정리했습니다. / 문이 안 열릴 때 [평택 출장열쇠](pyeongtaek.html)를 부르는 순서도 함께 적었습니다.
@ 송탄동 어린이집 돌봄 시설 출입문

# 아이 안전이 우선입니다, 점검 전에 알아둘 것
출입문 점검은 아이들이 시설 안에 없는 시간에 하는 것이 좋습니다. / 점검 중에는 문이 열려 있거나 잠금이 풀린 상태가 있을 수 있기 때문입니다.
- 점검 시간은 원생이 없는 때로 잡기
- 점검 중에는 출입구에 안내문 붙이기
- 교사와 관리자가 점검 일정을 같이 알기
- 비상 시 대피 경로를 막지 않기
출입문의 잠금 방식은 시설마다 정해진 안전 기준이 있을 수 있으니, 운영 방식이 바뀌는 점검은 담당 기관 안내를 따라야 합니다. / 이 글은 일반적인 점검 요령이며 규정을 단정하지 않습니다.

# 출입문 잠금장치 점검 항목
매일 열고 닫는 문이라 눈으로 보는 점검이 중요합니다.
- 번호나 카드를 대면 바로 열리는지, 반응이 느린지
- 문이 닫힐 때 천천히 닫히는지, 갑자기 쾅 닫히지는 않는지
- 안쪽에서 손잡이를 돌려 쉽게 나갈 수 있는지
- 문틈에 손가락이 끼일 위험이 없는지
도어클로저가 너무 빠르게 닫히면 아이 손이 끼일 수 있어 속도를 조절해야 합니다. / 닫힘 속도 조절은 [도어락 수리](doorlock-repair.html) 점검 때 같이 볼 수 있습니다.

# 카드키와 비밀번호 관리
보호자나 방문자가 올 때마다 문을 열어 줄 사람을 정해 두면 번호를 공유하지 않고도 출입을 관리할 수 있습니다. / 시설 운영 방식에 맞게 정하시면 됩니다.
돌봄 시설은 교사가 바뀌거나 보조 인력이 오가는 일이 잦습니다. / 그때마다 카드나 번호가 쌓이면 누가 갖고 있는지 알기 어려워집니다.
- 퇴사나 근무 종료 시 카드와 번호 즉시 정리
- 학부모용 임시 번호를 따로 쓰지 않기
- 카드를 분실하면 같은 날 삭제 등록
- 번호를 정기적으로 바꾸는 날 정하기
번호는 칠판이나 메모판에 적어 두면 외부인이 볼 수 있으니 피해 주세요. / 관리 담당자 한 명을 정해 두는 편이 좋습니다.
@ 송탄동 돌봄 시설 카드키 번호 관리

# 건전지와 경고음은 미루지 마세요
하루에도 여러 번 열리는 문이라 건전지 소모 속도가 가정집과 다릅니다. / 같은 제품이라도 설치 장소에 따라 교체 주기가 달라지니 시설에 맞는 주기를 정해 두세요.
출입 횟수가 많은 도어락은 건전지가 빨리 닳습니다. / 저전압 경고음이 한 번이라도 나면 그날 바로 교체하는 것이 원칙입니다.
등원 시간에 문이 안 열리면 아이들과 보호자가 문 앞에서 기다리게 됩니다. / 건전지는 교체 주기를 정해 두고, 한꺼번에 새것으로 갈아 두세요.
교체한 날짜를 건전지 덮개 안쪽에 적어 두면 다음 교체 시기를 놓치지 않습니다. / 여분 건전지를 항상 시설 안에 보관해 두는 것도 좋습니다.

# 문이 안 열리는 아침에 먼저 할 일
아이들이 도착하기 전에 문이 안 열린다면 우선 상황을 차분히 정리하세요. / 급한 마음에 문을 흔들면 걸쇠가 더 꽉 물릴 수 있습니다.
- 번호판이 켜지는지, 건전지 비상 전원을 대 볼 수 있는지
- 안쪽에 아직 누군가 남아 있는지
- 다른 출입구로 안전하게 들어갈 수 있는지
- 보호자에게 늦어질 수 있음을 알릴 방법이 있는지
아이들이 먼저 도착한 상황이라면 안전한 곳에서 기다리게 하고, 교사가 함께 있도록 해 주세요. / 문 앞에서 장비를 만지는 동안 아이들이 가까이 오지 않게 해야 합니다.

# 아이가 안에 있는데 문이 안 열릴 때
가장 급한 상황은 아이가 안에서 잠긴 경우입니다. / 이럴 때는 전화로 출동 요청을 하면서 아이 상태를 먼저 알려주세요.
아이에게는 문 너머로 계속 말을 걸어 안심시키고, 문 가까이에서 떨어져 있게 하세요. / 안쪽 잠금을 돌릴 수 있는 나이라면 방법을 천천히 알려주는 것도 도움이 됩니다.
이 경우는 [현관문 개문](door-open.html)에서 안전하게 열 수 있도록 우선으로 처리합니다.

# 하지 말아야 할 것
급할 때일수록 눈앞의 방법을 쓰고 싶지만, 아이들이 드나드는 문은 임시방편이 가장 위험합니다. / 한번 고쳐서 제대로 닫히고 잠기는 상태를 만들어 두는 것이 기본입니다.
시설 문은 공용이라 여러 사람이 만지면서 임시방편이 쌓이기 쉽습니다.
- 문틈에 종이를 끼워 열어 두는 습관
- 잠금장치를 테이프로 고정해 두기
- 고장 난 도어락을 그대로 두고 열쇠로만 쓰기
- 아이 눈높이에 위험한 부품이 드러나게 두기
임시방편이 오래가면 고장이 커지고, 비상시에 문이 안 열리는 일로 이어질 수 있습니다.

# 전화할 때 알려주실 것
시설 상황에 맞춰 아래 내용을 알려주시면 출동이 빨라집니다.
- 송탄동 안에서 건물 위치와 층
- 시설 운영자나 관리자의 이름과 연락처
- 안에 아이나 사람이 있는지
- 번호판 상태와 소리 여부
도어락 사진을 보내주시면 장비를 맞게 준비할 수 있습니다.

# 도착하면 먼저 권한과 신분을 확인합니다
시설 문을 여는 일이라 요청하신 분이 해당 시설의 운영자나 관리자인지 먼저 확인합니다. / 신분증, 시설 운영 관련 서류, 관리사무소나 건물주 확인 중 가능한 방법으로 진행합니다.
확인이 어려우면 작업을 할 수 없으니 번거롭더라도 미리 챙겨 두세요.

# 비용은 문 열기 전에 말씀드립니다
문과 도어락 상태를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하셔야 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. 진행 방식은 [이용안내](guide.html)에도 있습니다.
@ 송탄동 출장열쇠 시설 출입문 도어락 점검

# 열고 난 뒤 재발 방지와 교체 상담
문이 열린 뒤에는 닫힘과 잠금이 정상인지, 안쪽에서 아이가 쉽게 나갈 수 있는 높이와 형태인지도 함께 봅니다. / 점검 결과는 운영자에게 말씀드리고 필요한 조치를 같이 정합니다.
문이 열리면 원인을 찾아 같은 일이 반복되지 않게 정리합니다. / 건전지가 원인이라면 새것으로 교체하고, 부품이 낡았다면 상담을 드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 너무 낡아 부품 구하기가 어려울 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 송탄동 말고 평택 어디든 갑니다
송탄동 옆 지산동, 서정동은 물론 비전동, 세교동, 동삭동, 고덕동과 안중읍, 포승읍, 팽성읍, 청북읍도 다닙니다. / 평택 안이면 24시간 출동합니다.
출동 지역은 [출장 지역](area.html) 지도에서 확인하세요.
