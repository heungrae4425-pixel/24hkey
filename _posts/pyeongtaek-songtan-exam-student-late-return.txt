# 학원 끝나고 돌아온 아이가 문 앞에서 멈췄다면
송탄동은 송탄역을 중심으로 학원가와 주택, 아파트가 가까이 섞여 있는 생활권입니다. / 시험을 앞둔 자녀가 있는 집이라면 밤 열 시가 넘어 귀가하는 날이 드물지 않습니다.
그런 날 번호판이 꺼져 있거나 열쇠를 두고 나갔다면 아이는 계단참에서 혼자 당황하게 됩니다. / 부모가 직장에 있거나 멀리 있을 때는 더 그렇습니다.
이 글은 수험생이나 학원에 다니는 자녀가 늦게 귀가하는 집에서 문 때문에 생기는 일을 미리 정리한 것입니다. / 아이에게 전해 둘 말과 부모가 준비해 둘 것을 순서대로 적었습니다.
@ 송탄동 늦은 귀가 현관문 출장열쇠

# 늦은 시간에 문이 말썽을 부리는 이유
밤늦게 들어오는 날은 하루 중 도어락이 가장 지쳐 있는 때이기도 합니다. / 아침부터 가족이 번갈아 여닫으면서 버튼과 걸쇠가 가장 많이 쓰인 뒤이기 때문입니다.
배터리가 약해진 도어락은 낮에는 겨우 버티다가 밤에 한 번 더 누르는 순간 꺼지기도 합니다. / 아이가 번호를 누르는데 반응이 느려지면 이미 신호가 온 것입니다.
- 번호판이 희미하게 켜졌다가 바로 꺼진다
- 누를 때 삑 소리가 평소보다 작다
- 문을 열 때 모터 소리가 느리고 힘이 없다
이런 증상을 아이가 말해 주면 바로 배터리를 바꿔 주시면 됩니다. / 아이는 대수롭지 않게 넘기는 경우가 많아서 한 번 물어봐 두는 것이 좋습니다.

# 열쇠 없이 나간 날을 대비하는 방법
공부하는 아이는 가방이 무거워서 열쇠를 빼놓고 나가는 일이 생깁니다. / 도어락만 믿고 나갔다가 번호판 고장이 나면 방법이 없어집니다.
집 밖 어디에도 열쇠를 숨겨 두는 것은 권하지 않습니다. / 화분 밑이나 소화전 위는 오히려 낯선 사람에게 먼저 눈에 띕니다.
대신 아이 가방 속 지갑이나 필통에 카드키 하나를 따로 넣어 두면 좋습니다. / 지문이 되는 도어락이면 아이 손가락을 미리 등록해 두는 것도 방법입니다.
카드키를 잃어버릴 때를 생각해 [도어락 교체](doorlock-replace.html) 대신 카드만 다시 등록할 수 있는지 먼저 확인해 보세요.

# 비밀번호를 아이에게 알려줄 때 정할 것
번호를 알려줄 때는 숫자만 건네지 말고 사용 규칙도 같이 말해 주세요. / 친구와 같이 올 때 번호를 누르는 모습이 보이지 않게 손으로 가리라는 한마디면 충분합니다.
생일이나 호수처럼 쉽게 짐작되는 숫자는 피하는 것이 좋습니다. / 시험이 끝난 뒤에는 번호를 한 번 바꿔 주면 새로 시작하는 기분도 듭니다.
번호를 바꿨는데 아이에게 말하지 않아 문 앞에서 막히는 일이 의외로 많습니다. / 바꾼 날은 문자로 꼭 남겨 주세요.
@ 평택 송탄동 도어락 비밀번호 학생 자녀

# 아이가 문 앞에서 전화했을 때 부모가 할 말
아이가 울먹이며 전화하면 부모도 마음이 급해집니다. / 이때는 순서대로 묻는 것이 가장 빠릅니다.
- 번호판에 불이 들어오는지
- 누르면 어떤 소리가 나는지
- 문손잡이가 헛도는지, 뻣뻣한지
- 지금 아이 곁에 안전한 어른이나 이웃이 있는지
불이 아예 안 들어오면 아이에게 편의점에서 9V 건전지를 사서 비상 단자에 대 보게 하는 방법이 있습니다. / 송탄역 근처 편의점은 늦게까지 여는 곳이 많아 구하기 어렵지 않습니다.
건전지를 대도 소용없으면 아이 혼자 문을 두드리고 당기지 말고 계단 아래나 편의점처럼 밝은 곳으로 내려가 있게 해 주세요.

# 부모가 멀리 있을 때 문을 열어도 되는지
부모가 출장 중이어서 집에 갈 수 없는 경우가 있습니다. / 이럴 때 아이만 문 앞에서 기다리는 상황을 어떻게 풀지가 제일 걱정됩니다.
문을 여는 일은 거주자를 확인한 뒤에 하는 것이 원칙입니다. / 아이가 학생증이나 집 주소가 적힌 우편물을 갖고 있으면 확인에 도움이 됩니다.
신분증이 집 안에 있다면 관리사무소나 경비실에서 세대 확인을 받을 수도 있습니다. / 부모가 전화로 주소와 사정을 말씀해 주시면 도착 전에 필요한 것을 안내해 드립니다.
미성년자 혼자라면 이웃이나 경비 어른이 곁에 계신 상태에서 작업하는 편이 모두에게 안전합니다.

# 시험 기간 배터리 점검은 이렇게
시험 한 달 전쯤 집 안 도어락 배터리를 한꺼번에 새것으로 바꿔 두세요. / 일부만 바꾸면 남은 낡은 건전지가 먼저 닳아 며칠 안에 같은 일이 생깁니다.
교체한 날짜를 배터리 덮개 안쪽에 적어 두면 다음 시기를 놓치지 않습니다. / 알카라인 건전지를 쓰는 것이 일반적으로 더 안정적입니다.
경고음이 한 번이라도 들리면 그날 밤에 바로 갈아 주세요. / 아이가 시험 전날 문 때문에 마음이 흔들리지 않게 하는 가장 쉬운 방법입니다.

# 독서실 다니는 아이와 현관 방범
새벽까지 독서실에 있다 오는 날은 복도가 어둡고 사람이 적습니다. / 아이에게 현관 앞에서 두리번거리지 말고 번호를 빠르게 누르고 들어가 문이 닫힌 것을 확인하라고 가르쳐 주세요.
문이 완전히 닫히지 않아 걸쇠가 덜 걸린 채 방치되는 일도 흔합니다. / 문이 닫힐 때 철컥 소리가 나는지 한 번 귀 기울이게 하는 것만으로 충분합니다.
현관 방범은 [출장열쇠 이용안내](guide.html)에서 설명하는 기본 점검과 함께 보시면 좋습니다.
@ 송탄역 근처 수험생 집 도어락 점검

# 출장열쇠를 부를 때 알려 주실 것
아이가 대신 전화를 걸 수도 있으니 알려 줄 것을 적어 두면 편합니다. / 냉장고에 메모로 붙여 두는 집도 있습니다.
- 동 이름과 건물 이름, 호수
- 송탄역, 서정리역 쪽 등 대략의 위치
- 도어락 모양과 번호판 상태
- 지금 아이가 혼자인지, 곁에 어른이 있는지
사진을 문자로 보내 주시면 챙길 장비를 맞추기 좋습니다. / 현관문 개문 방식은 [현관문 개문](door-open.html) 페이지에서 미리 보실 수 있습니다.

# 비용은 열기 전에, 못 열면 받지 않습니다
도착해서 문과 도어락을 본 뒤 먼저 비용을 말씀드립니다. / 마음에 드시면 시작하고, 아니면 그냥 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품 교체가 필요해 보여도 손대기 전에 먼저 여쭤봅니다. / 아이가 놀란 밤이라도 서두르지 않고 설명해 드립니다.

# 문이 열린 뒤 챙길 점검
문이 열리면 도어락이 다시 잘 열리고 잠기는지 같이 확인합니다. / 배터리가 원인이면 그 자리에서 새것으로 바꿀 수 있게 합니다.
아이가 번호를 잊었다면 새 번호를 정하고 이전 번호는 지웁니다. / 이후 열쇠를 자주 잊는 아이라면 [열쇠 출장](key-call.html)으로 여분 열쇠를 만드는 방법도 있습니다.
고장이 반복되면 [도어락 수리](doorlock-repair.html)로 먼저 점검하고, 정말 낡았을 때만 교체를 말씀드립니다.

# 송탄동 밖에서도 평택 전역 출동
송탄동뿐 아니라 평택역, 지제역 주변과 안중읍, 팽성읍, 포승읍까지 다닙니다. / 평택에서 다니는 동네는 [평택 출장열쇠](pyeongtaek.html)에 정리해 두었습니다.
다른 지역이 궁금하시면 [출장 지역](area.html) 안내에서 확인하실 수 있습니다.
