# 송탄동 대문과 철문, 오래된 만큼 손이 갑니다
송탄동은 오래된 주택과 빌라가 많아서 현관문보다 대문이나 철문으로 연락 주시는 일이 잦습니다. / 대문은 비바람을 그대로 맞기 때문에 아파트 현관문보다 먼저 낡습니다.
녹이 슬거나 경첩이 처지면 열쇠를 돌려도 걸림이 생깁니다. / 이 글은 평택 송탄동에서 대문, 철문, 공동 출입문이 말썽일 때 확인할 것을 정리했습니다.
[평택 출장열쇠](pyeongtaek.html)에 연락하시기 전에 아래 내용을 한 번 살펴보세요. / 문 종류에 따라 확인할 부분이 달라서 먼저 구분해 두면 도움이 됩니다.
@ 송탄동 대문 철문 열쇠 출장열쇠

# 대문 종류부터 구분해 보세요
단독주택 대문은 대개 철제 문에 실린더 자물쇠가 달려 있습니다. / 요즘은 대문에도 번호 도어락을 쓰는 집이 늘었습니다.
빌라와 다세대 공동 출입문은 번호키나 카드키, 열쇠 방식이 섞여 있습니다. / 어떤 방식인지에 따라 해결 방법이 달라집니다.
상가 건물 철문이나 셔터 옆 출입문도 비슷한 구조입니다. / 전화로 알려 주실 때 문 종류만 말씀해 주셔도 준비가 빨라집니다.

# 열쇠가 안 돌아갈 때 먼저 해 볼 것
열쇠를 끝까지 넣었다가 살짝 뒤로 빼서 돌려 보세요. / 열쇠가 끝까지 들어가 있으면 오히려 걸리는 경우가 있습니다.
열쇠가 휘었거나 닳았다면 복사본을 써 보는 것도 방법입니다. / 새로 복사한 열쇠가 더 잘 맞는 일이 많습니다.
열쇠 구멍에 먼지와 녹이 많으면 억지로 돌리지 마세요. / 부러지면 안쪽에 박혀서 일이 훨씬 커집니다.

# 녹과 습기가 원인일 때
송탄동 오래된 대문은 비가 오는 철에 열쇠 구멍이 뻑뻑해집니다. / 겨울에는 얼어서 안 열리는 경우도 있습니다.
기름을 아무 데나 뿌리는 분들이 계시는데 먼지가 달라붙어 나중에 더 굳을 수 있습니다. / 열쇠 구멍 전용 윤활제가 아니면 쓰지 않는 편이 낫습니다.
녹이 심하면 자물쇠 전체를 점검해야 합니다. / 그때는 점검 결과를 말씀드리고 어떻게 할지 함께 정합니다.
@ 평택 송탄동 철문 자물쇠 점검 출장

# 경첩이 처졌을 때 보이는 모습
대문을 닫을 때 땅에 끌리거나 걸쇠가 문틀에 맞지 않으면 경첩 문제입니다. / 문이 한쪽으로 기울어 있으면 잠금이 안 걸리거나 겨우 걸립니다.
이런 상태에서 열쇠를 돌리면 자물쇠에 무리가 갑니다. / 문을 살짝 들어 올리며 열어 보면 열리는 일이 있습니다.
경첩 나사가 풀렸거나 구멍이 헐거워졌다면 보강이 필요합니다. / 이 부분은 보기만 해도 판단이 서기 때문에 사진으로도 대략 알 수 있습니다.

# 빌라 공동 출입문이 안 열릴 때
공동 출입문은 여러 세대가 같이 쓰기 때문에 한 집만 문제가 아닐 수 있습니다. / 이웃도 못 들어가고 있는지 먼저 확인해 보세요.
번호키가 먹통이면 건물 전체의 문제일 가능성이 큽니다. / 관리하는 분이나 집주인에게 먼저 알려 주세요.
카드키가 안 먹히는 것이 나 혼자라면 카드 쪽 문제입니다. / 이럴 때는 카드 재등록이나 교체를 안내해 드립니다.

# 건물 관리하는 분이 부르는 경우
공동 출입문 수리는 건물을 관리하는 분이 부르시는 일이 많습니다. / 현장에 계시지 않아도 전화로 먼저 상황을 알려 주시면 됩니다.
현장에는 거주하시는 분이 계셔서 사진을 찍어 보내 주시는 식으로 진행합니다. / 작업은 신분 확인 후 진행합니다.
수리 범위가 넓으면 먼저 설명드리고 허락을 받은 뒤에 시작합니다. / 건물 전체에 영향을 주는 일은 더욱 신중히 합니다.

# 문을 상하지 않게 여는 것이 먼저입니다
대문이나 철문은 단단해 보여도 억지로 열면 문틀과 자물쇠가 같이 상합니다. / 그래서 덜 상하는 방법부터 차례로 해 봅니다.
[현관문 개문](door-open.html)에 적어 둔 원칙과 같습니다. / 작업 전에 어떤 방법으로 열지 먼저 설명드립니다.
정말 안 열리는 경우에는 어떻게 할지 먼저 말씀드리고 허락을 받습니다. / 허락 없이 부수는 일은 없습니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
단독주택은 우편물이나 세금 고지서로 확인하는 경우가 많습니다. / 신분증 주소가 달라도 다른 방법으로 확인하면 됩니다.
번거로우셔도 이웃과 가족 모두를 위한 절차입니다. / 확인이 어려우면 작업을 하지 못합니다.

# 비용은 문 열기 전에 말씀드립니다
문 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
자물쇠를 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 대문 자물쇠를 새로 달 때 생각해 볼 것
단독주택이라면 열쇠 자물쇠와 번호 도어락을 같이 쓰는 방법도 있습니다. / 평소에는 번호로 열고 비상용으로 열쇠를 남겨 두는 식입니다.
철문은 두께와 구조를 먼저 확인해야 합니다. / 설치 전에 맞는 제품인지 현장에서 보고 말씀드립니다.
[도어락 설치](doorlock-install.html)가 필요한 경우에는 선택지를 먼저 보여 드립니다. / 필요 없으면 하지 않으셔도 됩니다.
@ 송탄동 24시 대문 도어락 설치 출장

# 겨울을 나기 전에 해 두면 좋은 점검
송탄동은 겨울에 바람이 센 날이 많아 대문 자물쇠가 얼기 쉽습니다. / 겨울이 오기 전에 열쇠 구멍에 윤활제를 소량 넣어 두세요.
번호 도어락은 추위에 배터리가 빨리 줄어듭니다. / 배터리 경고음이 나면 그날 바로 교체하세요.
경첩에도 소량 기름칠을 하면 문이 부드러워집니다. / 너무 많이 바르면 먼지가 붙어 오히려 해롭습니다.

# 송탄동 말고 평택 어디든 갑니다
송탄동 옆 지산동, 서정동, 비전동도 다닙니다. / 평택 안이면 동네 상관없이 24시간 출동합니다.
평택에서 다니는 동네는 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
위치를 알려 주실 때는 건물 이름보다 골목 이름이나 가까운 역을 말씀해 주세요. / 송탄역 쪽이라고만 하셔도 대략 도착 시간을 알려 드립니다.
