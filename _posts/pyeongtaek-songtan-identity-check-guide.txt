# 문을 열어 주는 일은 확인부터 시작합니다
송탄역 근처 송탄동에서 퇴근하고 돌아온 길에 문이 안 열리면 하루 빨리 들어가 쉬고 싶은 마음뿐입니다. / 그런데 전화로 출장열쇠를 부르면 도착 후 가장 먼저 신분 확인을 요청받습니다.
처음 겪는 분은 번거롭다고 느끼거나 의심받는 것 같아 불쾌해하기도 합니다. / 하지만 이 절차는 이웃과 사시는 분 모두를 지키기 위한 것입니다.
이 글은 신분 확인을 왜 하는지, 무엇으로 하는지, 서류가 없을 때는 어떻게 하는지 정리했습니다. / [평택 출장열쇠](pyeongtaek.html)를 부르기 전에 읽어 두시면 도움이 됩니다.
@ 송탄동 출장열쇠 신분 확인 절차

# 왜 굳이 신분을 확인할까요
집 문은 가장 사적인 공간의 입구입니다. / 열쇠 업무는 편리한 만큼 신뢰가 바탕이어야 합니다.
남의 집 문을 여는 일은 그 자체로 위험이 큰 일입니다. / 사시는 분이 아닌 사람이 문을 열어 달라고 요청하면 범죄에 쓰일 수도 있습니다.
확인 절차가 없다면 누구나 남의 집 문을 열게 할 수 있다는 뜻이 됩니다. / 이는 내 집을 지키는 일이기도 하고 옆집을 지키는 일이기도 합니다.
그래서 확인이 되지 않으면 아무리 급한 사정이어도 작업을 시작하지 못합니다. / 이 원칙은 밤이든 낮이든 같습니다.

# 인정되는 확인 방법 세 가지
다음 중 하나만 있으면 됩니다. / 모든 것을 갖추실 필요는 없습니다.
- 신분증: 주소가 현재 사는 곳과 일치하는지 확인
- 주소가 나온 우편물: 고지서, 택배 송장 등 집 주소가 적힌 자료
- 관리사무소 확인: 세대 거주자임을 관리 측에서 확인
신분증 주소가 이전 주소로 되어 있다면 현재 주소가 나온 우편물을 함께 보여 주세요. / 이사한 지 얼마 안 된 경우에 흔한 상황입니다.

# 신분증이 집 안에 있을 때
열쇠와 함께 신분증도 안에 두고 나온 경우가 많습니다. / 이때는 휴대폰에 있는 자료를 먼저 찾아보세요.
- 휴대폰으로 받은 주소가 적힌 고지서나 문자 내용
- 택배 앱에 저장된 배송지 주소 화면
- 은행이나 보험 앱에서 확인되는 주소
- 임대차 계약 관련 자료 사진
위 자료는 사시는 곳을 설명하는 보조 자료로 쓰입니다. / 자료가 충분한지는 현장에서 기사가 안내해 드립니다.
@ 송탄동 주소 확인 우편물 신분증

# 관리사무소가 있을 때 활용하기
공동주택에 관리사무소가 있다면 세대 거주를 확인받는 방법이 있습니다. / 평일 낮이면 직접 방문하거나 전화로 요청하면 됩니다.
쉬는 시간이라면 경비실에 먼저 상황을 말해 두세요. / 경비 담당이 세대를 확인해 주는 곳도 있습니다.
단지마다 확인 방식이 달라 안 되는 곳도 있으니 미리 확인해 두면 좋습니다. / 평소에 관리사무소 연락처를 휴대폰에 저장해 두세요.

# 세입자나 방을 얻어 쓰는 경우
집주인이 아니어도 실제로 사는 분이면 확인이 됩니다. / 세입자가 집주인 허락을 받으러 갈 필요는 없습니다.
다만 신분증과 우편물, 계약 관련 자료 등으로 거주 사실을 보여 주셔야 합니다. / 법적인 권리 관계 판단은 저희가 하지 않고 거주 확인만 합니다.
전입한 지 얼마 되지 않았다면 우편물이 아직 안 왔을 수도 있습니다. / 그럴 때는 계약서나 관리인의 확인이 도움이 됩니다.

# 가족이 대신 요청할 때
멀리 있는 자녀분이 부모님 댁 문을 대신 요청하는 경우가 있습니다. / 이때는 현장에 계시는 분이 사시는 분인지 확인하는 것이 먼저입니다.
요청한 분이 직접 오지 못하면 전화로 관계를 설명해 주시고 현장 확인 자료를 준비하게 하세요. / 어르신 혼자 계시다면 우편물이나 이웃의 확인을 보조로 쓸 수 있습니다.
집 안에 사람이 갇힌 급한 상황이면 전화로 먼저 알려 주세요. / 상황에 맞춰 순서를 조정하되 확인은 반드시 합니다.

# 서류가 아예 없다면
송탄동처럼 오래 사신 분이 많은 동네에서는 이사 후 주소를 정리하지 못한 분도 있습니다. / 그런 경우에도 방법을 같이 찾아봅니다.
신분증도 우편물도 관리실 확인도 불가능한 경우가 있을 수 있습니다. / 이때는 억지로 작업하지 않고 다른 방법을 먼저 찾아드립니다.
- 가족이나 이웃이 현장으로 와서 확인해 주는 방법
- 집주인이나 관리인이 연락되는 경우 연락해 확인
- 날이 밝은 뒤 관리사무소가 열렸을 때 다시 연락
작업이 안 되는 경우에도 비용은 받지 않습니다. / 안전과 확인이 가장 먼저입니다. / 서류를 갖추는 데 시간이 걸린다면 안전한 곳에서 기다리며 필요한 자료를 하나씩 모아 주세요.
확인 과정에서 개인 정보를 따로 적어 두거나 사진으로 저장하지 않습니다. / 보여 주시는 서류는 확인 용도로만 봅니다.

# 신분 확인이 끝나면 바로 설명드립니다
확인이 끝나면 도어락 상태와 문 형태를 보고 방법을 설명드립니다. / 걸리는 시간과 주의할 점도 같이 말씀드립니다.
비용은 문을 열기 전에 먼저 안내하고 동의하시면 시작합니다. / 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않고, 열고 난 뒤 말없이 붙는 비용도 없습니다. / 부품 교체는 하기 전에 먼저 여쭙습니다.

궁금하신 점은 작업 중에도 편하게 물어보셔도 됩니다. / 하는 일을 설명받는 것은 의뢰하신 분의 권리입니다.
작업을 지켜보고 싶으시면 문 앞에서 함께 계셔도 좋습니다. / 문이나 도어락에 닿는 부분이 달라 보이면 바로 말씀해 주세요.
진행 흐름은 [이용안내](guide.html)에도 적어 두었습니다.
@ 송탄동 24시 출장열쇠 도어락 개방 작업

# 비파손으로 열 수 있는지 먼저 봅니다
문이나 도어락을 상하지 않게 여는 방법부터 차례로 시도합니다. / 어쩔 수 없이 부품을 바꿔야 하는 경우는 사전에 설명드립니다.
현관문 개문 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다. / 고장이 원인이라면 [도어락 수리](doorlock-repair.html)로 먼저 점검합니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 필요할 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 전화로 이렇게 말씀해 주세요
신분 확인 준비를 위해 처음 통화에서 아래를 알려 주세요.
- 송탄동 안의 위치와 건물 입구, 호수
- 번호판 상태, 열쇠 구멍 유무
- 지금 가지고 있는 확인 자료(신분증, 우편물 등)
- 관리사무소나 경비실에 연락 가능한지
- 집 안에 아이나 반려동물이 있는지
미리 알려 주시면 도착 후 더 빨리 진행할 수 있습니다.

# 평소에 해두면 좋은 준비
신분 확인 자료는 평소에 휴대폰에 저장해 두면 큰 도움이 됩니다. / 주소가 나온 우편물을 사진으로 찍어 두는 정도면 충분합니다.
- 주소가 보이는 우편물 한 장 사진으로 저장
- 신분증 앞면을 개인 보관함에 저장
- 관리사무소 연락처 휴대폰에 저장
- 가족과 문이 잠겼을 때 연락 순서 정해 두기
사진이나 자료는 본인만 볼 수 있게 잘 보관해야 합니다. / 휴대폰 잠금을 설정해 두면 분실했을 때도 안심할 수 있습니다.
신분증 사진을 메신저에 그대로 올려 두는 습관은 피하세요. / 필요할 때 꺼내 쓸 수 있는 개인 보관함이 더 안전합니다.

# 송탄동 말고 평택 어디든 갑니다
송탄동 가까이 지산동, 서정동, 비전동, 세교동은 물론 안중읍, 팽성읍, 포승읍, 청북읍까지 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
