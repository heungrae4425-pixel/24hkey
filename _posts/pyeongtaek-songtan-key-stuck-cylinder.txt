# 송탄동에서 열쇠가 돌아가지 않을 때
송탄동에는 오래 살아온 주택과 상가 건물이 많이 섞여 있습니다. / 열쇠로 여는 문을 오래 써 온 집이 아직 적지 않습니다.
평소처럼 열쇠를 꽂았는데 뻑뻑하게 걸리거나, 돌아가지 않고 빠지지도 않으면 당황하게 됩니다. / 이럴 때 가장 하지 말아야 할 일이 힘으로 돌리는 것입니다.
이 글은 송탄동에서 열쇠가 말을 듣지 않을 때 먼저 확인할 것을 순서대로 적었습니다. / 그래도 안 되면 [평택 출장열쇠](pyeongtaek.html)를 부르는 시점도 함께 정리했습니다.
@ 송탄동 출장열쇠 열쇠 안 돌아감

# 열쇠가 걸리는 이유는 대부분 세 가지입니다
열쇠가 안 돌아가는 데는 이유가 있습니다. / 실린더 안쪽 상태와 열쇠 상태, 그리고 문 자체의 틀어짐 가운데 하나인 경우가 많습니다.
- 열쇠 날이 닳거나 휘어서 실린더 핀과 맞지 않는 경우
- 실린더 안에 먼지와 이물질이 쌓여 핀이 제대로 움직이지 않는 경우
- 문이 처져 걸쇠가 문틀에 눌린 채 잠겨 있는 경우
원인이 다르면 대처도 달라집니다. / 그래서 먼저 어느 쪽인지 가늠해 보는 것이 중요합니다.

# 열쇠를 꽂을 때 느낌을 살펴보세요
열쇠가 끝까지 들어가는지부터 확인합니다. / 중간에 걸리면 이물질이나 열쇠 변형을, 끝까지 들어가는데 안 돌아가면 핀이나 문 눌림을 의심해 볼 수 있습니다.
열쇠를 살짝 빼고 다시 꽂으며 미세하게 위치를 바꿔 보면 돌아가는 경우가 있습니다. / 이때 힘을 주지 말고 손끝 감각으로만 시도하세요.
문을 안쪽으로 살짝 밀거나 당기면서 돌려 보는 것도 방법입니다. / 걸쇠가 문틀에 눌려 있으면 위치가 풀리며 돌아가기도 합니다.

# 힘주어 돌리면 열쇠가 부러집니다
급한 마음에 열쇠를 세게 비틀면 열쇠가 실린더 안에서 부러지는 일이 생깁니다. / 그러면 열쇠를 빼는 작업부터 새로 시작해야 해서 일이 두 배가 됩니다.
열쇠에 윤활제를 잔뜩 뿌리는 것도 권하지 않습니다. / 기름이 먼지를 끌어 모아 안쪽이 더 굳을 수 있습니다.
돌아가지 않는 상태에서 열쇠를 꽂은 채 두면 열쇠와 실린더 모두 상할 수 있습니다. / 한두 번 시도해 안 되면 멈추는 게 좋습니다.
@ 송탄동 열쇠 실린더 점검 출장

# 집에서 해볼 수 있는 가벼운 점검
열쇠 날 부분을 마른 천으로 닦아 먼지와 기름때를 없애 봅니다. / 열쇠가 깨끗해지는 것만으로 돌아가는 경우도 있습니다.
복사한 열쇠만 안 돌아가고 원본은 잘 돌아간다면 복사 과정의 오차일 가능성이 큽니다. / 이때는 원본을 기준으로 다시 맞추는 것이 좋습니다.
실린더 구멍에 마른 가루 윤활제를 아주 조금 넣는 방법도 있지만 반드시 소량만 쓰세요. / 확신이 없으면 그대로 두고 전화 주시는 편이 안전합니다.

# 열쇠가 안 빠질 때는 특히 조심하세요
돌아가지도 않고 빠지지도 않는 상태는 실린더 안에서 핀이 낀 경우가 많습니다. / 열쇠를 위아래로 흔들거나 비틀어 빼려다 열쇠가 휘기도 합니다.
이럴 때는 그 자리에서 손을 떼고 문 상태를 알려주시는 것이 가장 안전합니다. / 실린더 구조를 알고 풀어야 열쇠와 문을 모두 살릴 수 있습니다.
송탄동처럼 오래된 문은 실린더가 낡아 이런 증상이 더 자주 생깁니다. / 한번 이런 일을 겪었다면 실린더 교체를 한 번 상의해 보셔도 좋습니다.

# 송탄동 위치는 이렇게 알려주세요
송탄동은 골목과 건물이 많아 위치를 정확히 알려주시면 도착이 빨라집니다. / 건물 이름이나 눈에 띄는 가게, 송탄역 방향 등을 함께 말씀해 주세요.
- 건물 종류(주택, 상가, 빌라)와 층수
- 열쇠를 꽂았을 때의 상태(걸림, 돌아가지 않음, 안 빠짐)
- 문이 열쇠식인지 도어락 병행인지
- 열쇠가 부러졌는지, 일부가 안에 남았는지
- 집 안에 사람이나 반려동물이 있는지
열쇠 구멍 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다. / 집 안에 아이가 혼자 있다면 꼭 먼저 말씀해 주세요.

# 출장열쇠가 와서 하는 일
먼저 문 상태와 열쇠 상태를 같이 봅니다. / 실린더를 상하게 하지 않는 방법부터 차례로 시도합니다.
열쇠가 빠지지 않는 경우에는 실린더 안쪽 핀을 살려 가며 열쇠를 빼냅니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.
문을 여는 방식이 궁금하시면 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다. / 열쇠 복사나 교체가 필요하면 [출장 열쇠](key-call.html) 쪽에서 함께 처리합니다.
@ 송탄동 열쇠 문 열기 평택 출장열쇠

# 실린더를 바꿔야 하는 경우
열쇠가 자주 걸리고 몇 번 겪었다면 실린더가 낡았을 가능성이 큽니다. / 계속 쓰다가 어느 날 완전히 안 열리는 일이 생길 수 있습니다.
열쇠 날이 심하게 닳았거나 복사 열쇠가 여러 개 돌아다니는 집이라면 교체가 도움이 됩니다. / 교체 전에는 먼저 상태를 보고 이유를 설명드립니다.
교체를 하실지는 설명을 들으신 뒤 정하시면 됩니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 비용은 작업 전에 말씀드립니다
문 상태와 작업 내용을 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 사시는 분인지 확인하는 절차
열쇠가 안 돌아가는 문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 건물 관리인이나 이웃의 확인을 부탁드릴 수도 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 열쇠를 오래 쓰는 평소 관리법
열쇠를 바닥이나 주머니에 마구 넣어 두면 날이 휘기 쉽습니다. / 열쇠고리에 무거운 물건을 많이 달아 두는 것도 실린더에 부담을 줍니다.
복사 열쇠를 만들 때는 원본 상태가 좋은지 먼저 확인하세요. / 닳은 열쇠를 복사하면 복사본도 처음부터 헐렁하게 만들어집니다.
- 열쇠 날을 가끔 마른 천으로 닦기
- 열쇠를 꽂을 때 세게 밀어 넣지 않기
- 돌릴 때 걸리는 느낌이 있으면 바로 상태 확인하기
작은 습관이 어느 날 문 앞에서 막히는 일을 줄여 줍니다.

# 송탄동 말고 평택 어디든 갑니다
송탄동에서 가까운 서정동과 지산동, 평택역 근처, 세교동까지 자주 다닙니다. / 평택 안이면 동네를 가리지 않고 24시간 출동합니다.
안중읍, 포승읍, 팽성읍, 청북읍처럼 거리가 있는 곳도 위치를 받으면 도착 시간을 먼저 말씀드립니다. / 평택에서 다니는 지역은 [평택시 출장열쇠](pyeongtaek.html) 페이지에 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
