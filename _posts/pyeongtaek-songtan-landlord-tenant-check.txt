# 도어락이 고장 나면 누가 해결하나 하는 고민
송탄동은 송탄역 주변으로 전세와 월세로 사는 분이 적지 않은 생활권입니다. / 그러다 보니 도어락이 고장 났을 때 집주인에게 말해야 할지 내가 처리해야 할지 헷갈리는 일이 생깁니다.
이 글은 누구 잘못이라고 가르는 글이 아닙니다. / 서로 이야기를 시작하기 전에 확인해 두면 좋은 사실들을 정리한 안내입니다.
계약 내용과 상황마다 다르기 때문에 법적인 판단은 할 수 없고, 현장에서 필요한 확인 순서만 적었습니다. / 판단이 필요한 부분은 계약서와 당사자 대화를 기준으로 하시기 바랍니다.
@ 송탄동 임대인 임차인 도어락 확인

# 고장의 정도부터 사진으로 남기기
이야기를 시작하기 전에 지금 상태를 객관적으로 남겨 두는 것이 우선입니다. / 말로만 설명하면 서로 기억이 달라질 수 있습니다.
- 도어락 전체 사진과 번호판 사진
- 증상이 보이는 영상 (소리, 반응 없음 등)
- 증상이 처음 나타난 시점
- 최근 배터리를 바꾼 시점
사진과 짧은 영상이면 충분합니다. / 문자로 주고받으면 날짜도 함께 남아서 나중에 확인하기 좋습니다.
문 안쪽과 바깥쪽을 모두 찍어 두면 어디에서 문제가 생겼는지 가늠하기 쉽습니다. / 번호판이 꺼져 있는지, 켜져 있는데 반응이 없는지도 구분되게 남겨 주세요.

# 소모품과 고장은 구분해서 보기
도어락에서 가장 흔한 문제는 배터리 방전입니다. / 이것은 고장이라기보다 소모품 교체에 가까워 직접 처리하는 경우가 많습니다.
반면 배터리를 바꿔도 반응이 없거나 모터 소리만 나는 경우는 부품 문제일 가능성이 있습니다. / 이 둘을 구분해서 이야기하면 대화가 한결 부드러워집니다.
누가 비용을 부담해야 하는지는 계약과 합의로 정해지는 부분이라 단정해 드릴 수 없습니다. / 원인과 필요한 작업을 정리해서 알려 드리는 것까지가 저희가 도울 수 있는 부분입니다.
다만 사용하다 보면 자연스럽게 낡아서 생기는 고장과 사용 중 부주의로 생긴 고장은 모습이 다릅니다. / 점검할 때 어떤 쪽에 가까운지 보이는 대로 솔직하게 말씀드립니다.

# 집주인에게 알릴 때 이렇게 말씀해 보세요
길게 설명하기보다 사실만 짧게 전달하는 것이 좋습니다. / 감정이 섞이지 않은 문자 한 통이 이후 대화를 훨씬 쉽게 만듭니다.
예를 들어 현관 도어락이 어제부터 반응이 없고 배터리를 바꿔도 같다는 정도면 충분합니다. / 사진을 같이 보내고 수리 전에 어떻게 하면 좋을지 의견을 묻는 식입니다.
급하게 문이 안 열리는 상황이라면 먼저 문을 열고 나서 이야기하는 편이 현실적입니다. / 이럴 때는 [현관문 개문](door-open.html)부터 진행하는 방법을 확인해 보세요.
@ 도어락 상태 사진과 증상 기록

# 교체와 수리, 어느 쪽이 맞을지 물어보기
같은 증상이라도 수리로 해결될 수 있는지 교체가 나은지는 제품 상태에 따라 다릅니다. / 직접 보고 판단하기 전에는 확정해서 말씀드리기 어렵습니다.
고쳐 쓸 수 있으면 수리를 먼저 권해 드립니다. / 수리로 어렵거나 너무 오래된 제품일 때만 교체를 말씀드립니다.
[도어락 수리](doorlock-repair.html)와 [도어락 교체](doorlock-replace.html) 안내에서 각각의 진행 방식을 확인하실 수 있습니다. / 두 분이 같은 내용을 보고 이야기하면 오해가 줄어듭니다.

# 원래 있던 도어락인지, 설치한 것인지 확인
세입자가 직접 설치한 도어락이라면 이사할 때 어떻게 할지도 이야기해 두어야 합니다. / 반대로 원래 달려 있던 도어락이라면 임의로 바꾸기 전에 의논하는 편이 안전합니다.
계약서에 시설물 관련 내용이 있는지 읽어 보시고, 없다면 대화로 정리해 두세요. / 문자나 메신저로 합의 내용을 남겨 두면 나중에 서로 도움이 됩니다.
합의가 어렵다면 일단 임시로 쓸 수 있게만 조치하고 나머지는 천천히 정리하는 방법도 있습니다. / 급한 불부터 끄고 비용 이야기는 차분히 나누는 편이 관계에도 좋습니다.
어떤 경우든 철거하거나 교체하기 전에 기존 제품의 사진을 남겨 두세요. / 처음 상태를 확인할 수 있는 기록이 됩니다.

# 열쇠와 번호, 몇 사람이 알고 있는지
임대 중인 집은 열쇠나 번호를 아는 사람이 생각보다 많을 수 있습니다. / 이전 세입자, 관리를 맡은 사람, 청소나 수리 인력 등이 있었을 수 있습니다.
세입자 입장에서는 내 집의 출입 정보를 정리하고 싶은 것이 자연스럽습니다. / 이를 위해 초기화나 번호 재설정을 하는 경우가 많습니다.
이때도 집주인에게 먼저 알려 두면 서로 오해할 일이 줄어듭니다. / 번호를 바꾸면 비상시 확인 방법을 어떻게 할지도 함께 정해 두세요.

# 현장에서는 누가 요청해도 신분을 확인합니다
저희는 집주인이든 세입자든 문을 열거나 도어락을 만지기 전에 확인 절차를 거칩니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나가 필요합니다.
집주인이 요청하는 경우에도 지금 그 집에 사는 분의 상황과 동의가 중요합니다. / 거주자가 있는 집이라면 거주자와 연락이 되는지 확인합니다.
이 절차는 번거롭더라도 모든 분을 위한 최소한의 안전장치입니다. / 확인이 되지 않으면 작업을 할 수 없는 점 이해 부탁드립니다.
세입자가 해외나 타지에 있고 집주인이 대신 연락하는 상황처럼 예외적인 경우도 있습니다. / 이럴 때는 관리사무소 확인이나 가능한 서류를 함께 보면서 진행 가능 여부를 안내해 드립니다.
@ 현장 신분 확인 신분증 우편물

# 비용은 누구에게 청구할지도 먼저 정리
작업을 하게 되면 비용을 먼저 설명드립니다. / 두 분이 함께 계신 자리가 아니라면 요청하신 분께 안내됩니다.
누가 부담할지는 미리 정해 두시면 현장에서 곤란해지지 않습니다. / 정해지지 않았다면 우선 필요한 작업과 비용을 확인한 뒤 의논하셔도 됩니다.
문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없으며, 진행 방식은 [이용안내](guide.html)에 있습니다.

# 작업이 끝난 뒤 남겨 두면 좋은 기록
수리나 교체를 했다면 어떤 작업을 했는지 간단히 기록해 두세요. / 날짜, 작업 내용, 바꾼 부품이 있다면 무엇인지 정도면 충분합니다.
이 기록은 이사를 나갈 때나 다음 문제가 생겼을 때 기준이 됩니다. / 사진도 함께 남기면 더 분명해집니다.
새로 설정한 번호는 누구에게 공유할지도 정리해 두세요. / 가능한 한 필요한 사람에게만 알리는 것이 원칙입니다.

# 송탄동 말고 평택 곳곳으로 갑니다
송탄동은 물론 지산동, 서정동, 비전동, 세교동, 고덕동, 안중읍, 팽성읍도 다닙니다. / 평택 안이면 24시간 연락이 가능합니다.
[평택 출장열쇠](pyeongtaek.html) 페이지에서 지역을 확인하시고, 다른 지역은 [출장 지역](area.html)을 참고하세요.
