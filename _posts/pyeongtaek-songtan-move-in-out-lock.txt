# 이삿짐보다 먼저 현관문을 보세요
송탄동은 송탄역을 중심으로 오가는 분이 많아 이사 들고 나는 일이 자주 있는 생활권입니다. / 짐 옮기는 일에 정신이 팔리다 보면 정작 현관문 점검은 맨 마지막으로 밀리기 쉽습니다.
그런데 문을 제대로 확인하지 않으면 첫날 밤이나 마지막 날 아침에 곤란해질 수 있습니다. / 이 글은 입주할 때와 퇴거할 때 도어락과 열쇠에서 무엇을 살펴야 하는지 순서대로 적었습니다.
@ 송탄동 이사 입주 도어락 확인

# 입주 전날 해볼 수 있는 확인
계약이 끝나고 열쇠를 받았다면 이삿날 전에 한 번 방문해서 문부터 열어 보세요. / 그날 문이 잘 열리고 잘 잠기는지 확인하는 것만으로 이삿날 변수가 줄어듭니다.
- 받은 열쇠가 몇 개인지, 모두 문에 들어가고 돌아가는지
- 도어락 번호가 어떻게 되어 있는지, 전 거주자가 쓰던 번호가 남아 있는지
- 번호판 불이 들어오는지, 경고음이 나는지
- 보조키와 걸쇠가 부드럽게 움직이는지
이삿날 한꺼번에 하려고 하면 짐이 쌓여 있어서 제대로 확인하기 어렵습니다. / 비어 있는 집에서 차분히 하는 것이 훨씬 낫습니다.
입주 청소나 도배, 에어컨 설치처럼 다른 업체가 먼저 드나드는 일정이 있다면 그 전에 문을 확인하세요. / 여러 사람이 드나든 뒤에 생긴 문제는 원인을 찾기가 더 어렵기 때문입니다.
처음 며칠은 가족 모두가 새 번호와 열쇠 위치에 익숙해지는 기간이라 생각하시면 편합니다. / 아이나 어르신이 있는 집이라면 번호를 쉬운 순서로 정하되 너무 단순하지 않게 고르는 것이 좋습니다.

# 전 거주자 번호와 등록 정보는 반드시 지우기
입주한 집의 도어락에 이전 사람이 등록한 번호나 카드가 남아 있을 수 있습니다. / 그 사람이 나쁜 마음을 먹는다는 뜻이 아니라, 누가 열 수 있는지 모르는 상태 자체가 불안하기 때문입니다.
제품마다 초기화 방법이 다르니 설명서를 확인하시고 모르겠으면 상담을 받으세요. / 초기화하고 나면 내 번호를 새로 등록하고, 가족 카드나 지문도 새로 넣으면 됩니다.
임대차 집이라면 도어락을 바꾸거나 초기화해도 되는지 집주인에게 먼저 말해 두면 서로 편합니다. / 이 부분은 [도어락 교체](doorlock-replace.html) 안내에서 순서를 정리해 두었습니다.

# 이삿날 도어락이 말썽이면 이렇게
짐을 들고 오가다 보면 문을 열어 두기 위해 걸쇠를 고정하는 일이 생깁니다. / 이때 문이 반쯤 닫히거나 보조키가 걸리는 일도 흔합니다.
이사 업체 직원이 들락거리는 동안 문이 닫히면 잠금 상태로 돌아가는 도어락이 많습니다. / 안에 열쇠를 두고 나갔다가 문이 닫혀 버렸다면 억지로 열려 하지 마시고 연락 주세요.
번호가 안 맞거나 키가 안 돌아가는 낯선 집이라 더 헷갈리는 경우도 있습니다. / 이때는 [현관문 개문](door-open.html) 안내를 먼저 보시고 사시는 분 확인 절차를 챙겨 두면 도움이 됩니다.
@ 이삿날 현관문 열쇠 번호 점검

# 열쇠 개수와 종류, 인수인계 때 적어 두기
계약서만큼 중요한 것이 열쇠를 몇 개 받았고 몇 개를 돌려주었는지의 기록입니다. / 문자나 사진으로 남겨 두면 나중에 서로 말이 달라질 일이 없습니다.
현관 열쇠 외에 우편함 열쇠, 공동 현관 카드, 주차 리모컨도 함께 챙겨야 합니다. / 이 중 하나라도 빠지면 이사 후에 갑자기 불편해집니다.
카드키가 여러 장이라면 모두 작동하는지 한 번씩 대 보세요. / 한 장이라도 반응이 없으면 분실이나 고장 가능성을 따져 봐야 합니다.

# 퇴거 전에 도어락 상태 사진 남기기
퇴거 날에는 열쇠를 반납하기 전에 도어락의 현재 상태를 사진으로 남겨 두세요. / 번호판, 손잡이, 문틀 쪽 걸쇠 부분까지 한 장씩이면 충분합니다.
원래 있던 흠집인지 살면서 생긴 것인지로 이야기가 길어지는 일을 줄여 줍니다. / 불필요한 오해를 예방하는 가장 쉬운 방법입니다.
비밀번호는 퇴거 직전에 알려 주기로 했다면 약속을 정확히 해 두세요. / 서로 언제 바꾸는지 모르는 상태가 가장 곤란합니다.

# 이사 나가면서 내 등록 정보도 정리하기
내 번호, 카드, 지문이 도어락에 남아 있으면 나간 뒤에도 정보가 그대로 남습니다. / 가능하면 내 정보를 지우고 초기 상태로 되돌려 놓는 것이 서로에게 편합니다.
다만 제품을 바꾸거나 초기화할지는 집주인과 먼저 이야기해야 하는 부분입니다. / 임대인과 임차인이 확인해야 할 점은 따로 정리해 두었으니 필요하면 문의해 주세요.
배터리를 새것으로 바꿔 두고 나가는 것도 작은 배려입니다. / 다음 사람이 들어와서 번호판이 꺼져 있는 일은 없도록 말입니다.
@ 퇴거 전 도어락 초기화와 배터리 교체

# 문틀과 보조키까지 같이 보면 놓치는 게 없습니다
도어락만 보고 지나치는 곳이 문틀과 보조키입니다. / 보조키가 헐겁거나 문틀 구멍에 걸리는 소리가 나면 사는 동안 말썽이 될 수 있습니다.
오래된 집이라면 경첩이 처지거나 문이 뻑뻑한 경우도 있습니다. / 입주 전에 고쳐 두면 살면서 불편이 한결 덜합니다.
설치된 도어락이 오래되어 보이면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 먼저 확인합니다. / 바꿔야 할 정도인지는 문을 직접 보고 말씀드립니다.

# 전화로 알려 주시면 좋은 것
입주나 퇴거 때 연락을 주실 때는 아래 내용을 알려 주시면 준비가 수월합니다. / 도어락 사진을 함께 보내 주시면 더 좋습니다.
- 송탄동 어디쯤인지, 송탄역 방면인지
- 입주인지 퇴거인지, 문이 지금 열리는 상태인지
- 도어락 모양과 번호판 상태
- 필요한 작업이 초기화인지 수리인지 교체인지
아직 정하지 못하셨다면 상황만 말씀하셔도 괜찮습니다. / 필요한 작업은 전화로 같이 정리해 드립니다.

# 문을 열거나 손보기 전에 사시는 분인지 확인합니다
출입문을 다루는 일이라 현장에서 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나를 준비해 주세요.
이사 당일이라 아직 주소가 옮겨지지 않았다면 계약서나 입주 확인이 가능한 서류도 도움이 됩니다. / 판단이 어려우면 관리사무소에 먼저 확인을 부탁해 보세요.

# 비용은 시작하기 전에 안내합니다
필요한 작업을 정리한 뒤 비용을 먼저 말씀드립니다. / 동의하시면 시작하고, 아니면 그대로 돌아갑니다.
문이 안 열려 개방이 필요한 경우 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없으며, 진행 방식은 [이용안내](guide.html)에서 볼 수 있습니다.

# 송탄동 말고 평택 어디든 갑니다
송탄동은 물론 지산동, 서정동, 비전동, 세교동, 고덕동, 안중읍, 포승읍도 다닙니다. / 평택 안이면 24시간 연락이 가능합니다.
자세한 지역은 [평택 출장열쇠](pyeongtaek.html) 페이지를, 그 밖의 지역은 [출장 지역](area.html)을 참고하세요.
