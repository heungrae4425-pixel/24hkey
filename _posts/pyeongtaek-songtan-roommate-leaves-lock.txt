# 같이 살던 사람이 나가면 생기는 일
송탄역 근처 송탄동에서 둘이나 셋이 함께 살다가 한 사람이 이사를 나가는 일은 흔합니다. / 이삿짐은 정리되는데 정작 도어락 번호와 열쇠는 그대로 두고 지나가는 일도 흔합니다.
나간 사람이 나쁜 마음을 먹어서가 아니라, 누가 어떤 열쇠와 번호를 가지고 있는지 정리되지 않은 상태 자체가 불안의 씨앗이 됩니다.
이 글은 [평택 출장열쇠](pyeongtaek.html)에서 자주 안내드리는 룸메이트 퇴거 후 도어락 정리 순서를 담았습니다.
@ 송탄동 룸메이트 퇴거 후 도어락 정리

# 먼저 누가 무엇을 가졌는지 적어 보기
정리의 시작은 목록입니다. / 종이에 아래 항목을 적어 보세요.
- 현관 열쇠(보조키 포함) 몇 개를 누가 가졌는지
- 카드키나 태그가 몇 장이고 누구 손에 있는지
- 번호를 아는 사람이 누구인지
- 지문이 등록되어 있다면 누구 것인지
목록을 보면 해야 할 일이 의외로 간단하다는 것을 알게 됩니다.

# 나간 사람에게 돌려받을 것
퇴거 날짜가 정해지면 열쇠와 카드키를 직접 건네받는 자리를 만듭니다. / 택배나 우편으로 나중에 보낸다는 약속은 잊히기 쉽습니다.
받을 때는 몇 개를 받았는지 서로 확인합니다. / 하나가 비면 어디 있는지 이야기해 두고, 분실이면 분실로 정리해 둡니다.
대화가 어색하면 문자로 "열쇠 1개, 카드 1장 돌려받기로 했다"처럼 남겨 두면 나중에 기억이 엇갈리지 않습니다.

# 번호는 돌려받는 것이 아니라 바꾸는 것
번호는 머릿속에 있는 정보라 돌려받을 수 없습니다. / 그래서 퇴거 당일 또는 다음 날 새 번호로 바꾸는 것이 가장 확실합니다.
단순한 번호 하나만 바꾸는 것이 아니라 등록된 번호 전체를 지우고 필요한 번호만 다시 만드는 방식이 깔끔합니다. / 이전 번호가 구석 어딘가에 남아 있지 않다는 확신이 생깁니다.
바꾸는 시점도 중요합니다. / 퇴거 당일 짐이 다 빠지고 열쇠를 받은 직후에 바로 바꾸면 중간에 비는 시간이 없습니다.
나간 사람이 마지막으로 짐을 가지러 한 번 더 오는 일정이 있다면, 그 방문이 끝난 뒤에 바꾸는 것이 서로 편합니다. / 방문 전에 바꾸면 들어오지 못해 다툼이 생길 수 있고, 방문 뒤에도 안 바꾸면 불안이 남습니다.
새 번호는 숫자 네 자리로 단순하게 정하기보다 가능한 자릿수를 길게 쓰는 편이 안전합니다. / 다만 가족이 외우기 어려울 정도로 복잡하면 오히려 문 앞에서 막히니 적당한 선을 찾으세요.

# 열쇠는 어떻게 할까
도어락과 별개로 아직 열쇠로 여는 구조라면 실린더 교체를 생각해 볼 수 있습니다. / 열쇠는 복사가 쉬워 몇 개가 돌아다니는지 정확히 알기 어렵습니다.
다만 모든 경우에 교체가 필요한 것은 아니고, 돌려받은 개수가 정확히 맞고 서로 신뢰가 있는 상황이라면 그대로 쓰기도 합니다. / 판단은 본인이 편한 쪽으로 하시면 됩니다.
@ 현관 보조키와 돌려받은 열쇠들

# 카드키와 지문 등록 지우기
카드키가 한 장 빠졌다면 번호를 바꾸는 것과 별도로 카드 등록도 지워야 합니다. / 제품에 따라 전체 삭제 후 남은 카드만 다시 등록하는 방식을 씁니다.
지문이 등록된 도어락은 나간 사람의 지문 번호를 지우거나, 전체를 지우고 남는 사람 것만 다시 등록합니다. / 설명서가 없으면 제품 모델을 알려 주세요.

# 임대차 관계가 있을 때 조심할 점
집주인이 따로 있거나 계약자가 한 사람인 경우에는 도어락 변경을 누구와 상의해야 하는지 헷갈릴 수 있습니다. / 이 부분은 법적으로 단정할 수 없으니 계약서 내용과 집주인에게 먼저 알리는 것을 권합니다.
나간 사람이 계약상 아직 거주자로 되어 있다면 번호를 바꾸는 일이 갈등으로 번질 수도 있습니다. / 문자 등으로 기록을 남기고 차분히 진행하세요.
월세나 보증금 문제가 얽혀 있다면 도어락 일은 따로 떼어 생각하세요. / 정산은 정산대로, 번호 정리는 번호 정리대로 순서를 나누면 다툼이 줄어듭니다.

# 감정이 상한 상태라면 더 신중하게
사이가 틀어져 나간 경우에는 "다시 올까 봐 불안하다"는 마음이 클 수 있습니다. / 그럴수록 감정적인 대응보다 번호 변경과 열쇠 정리라는 실무로 마음을 가라앉히는 것이 좋습니다.
상대의 짐이 아직 집에 있다면 그것을 전달하는 방법은 따로 약속하고, 번호는 알려 주지 않습니다. / 짐은 집 밖에서 건네는 것이 안전합니다.
사이가 어긋난 상태라면 말을 길게 주고받기보다 문자로 날짜와 시간, 돌려받을 물건만 간단히 정리하세요. / 감정이 오가는 대화는 기록이 남아도 서로 오해하기 쉽습니다.
도어락 번호를 알려 달라는 요구가 오면 "새 번호로 바꿨다"고만 답하고 번호는 말하지 않아도 됩니다. / 집은 지금 사는 사람이 안전해야 하는 공간이라는 점을 기억하세요.

# 번호를 바꾼 뒤 남은 사람에게 알리기
남아 있는 사람이 둘 이상이라면 새 번호를 모두가 알아야 합니다. / 메신저에 번호를 그대로 적어 보내기보다 말이나 따로 보관한 메모로 알리는 편이 좋습니다.
새 번호를 처음 쓰는 날은 문을 열어 둔 상태에서 한 번씩 눌러 보게 합니다. / 문이 닫힌 뒤에 번호가 틀리면 모두 문 앞에서 난감해집니다.

# 번호를 바꾸다 문이 안 열릴 때
설정 중에 문을 닫고 확인했는데 안 열리는 경우도 있습니다. / 이때는 당황해서 계속 누르지 말고 멈추세요. 입력을 여러 번 틀리면 도어락이 잠시 입력을 막기도 합니다.
[현관문 개문](door-open.html)이 필요하면 전화 주세요. / 도착하면 신분증, 주소가 적힌 우편물, 관리사무소 확인 중 하나로 사시는 분이 맞는지 먼저 확인합니다.

# 비용은 문 열기 전에 말씀드립니다
번호 재설정이든 문 열기든 상태를 듣고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 끝내 문을 못 열면 비용은 받지 않습니다.
부품을 바꿔야 한다면 바꾸기 전에 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
@ 도어락 비밀번호 재등록 중인 번호판

# 이사 나가는 쪽에서 해둘 일
반대로 내가 나가는 사람이라면 돌려줄 것을 챙기고 번호를 알려 줄 필요가 없다는 점을 기억하세요. / 남는 사람이 새 번호로 바꾼다고 하면 기분 나빠하지 말고 협조하는 것이 서로에게 좋습니다.
퇴거 때 도어락 관련 점검은 열쇠 수리나 교체를 알아보기 전에 서로 목록으로 확인하는 것이 먼저입니다. / 문이 뻑뻑하거나 번호판이 이상하면 그때 [도어락 수리](doorlock-repair.html)를 보시면 됩니다.

# 송탄동 말고 평택 어디든 갑니다
송탄동 옆 지산동, 서정동은 물론 비전동, 세교동, 동삭동, 고덕동까지 다닙니다. / 안중읍, 포승읍, 팽성읍, 청북읍도 연락 주시면 갑니다. 다른 지역은 [출장 지역](area.html)에서 확인하세요.
