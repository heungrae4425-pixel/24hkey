# 송탄동에서 스마트 도어락을 알아보신다면
송탄동은 송탄역 주변으로 오랜 시가지와 주택, 상가가 어우러진 동네입니다. / 열쇠를 들고 다니기 번거로워 스마트 도어락으로 바꾸려는 분이 늘고 있습니다.
그런데 종류가 많아 어떤 걸 골라야 할지 막막하기 마련입니다.
이 글은 송탄동에서 지문, 카드, 번호 방식을 비교하고 [평택 출장열쇠](pyeongtaek.html)로 설치하는 순서를 정리했습니다.
@ 송탄동 스마트 도어락 설치 출장열쇠

# 도어락 방식은 크게 네 가지
요즘 많이 쓰는 방식은 번호, 카드, 지문, 그리고 이를 함께 쓰는 복합형입니다. / 각각 장단점이 뚜렷합니다.
- 번호 방식: 열쇠 없이 번호만 누르면 됨
- 카드·태그 방식: 번호를 외울 필요가 없음
- 지문 방식: 손만 대면 열려 편함
- 복합 방식: 여러 방법을 함께 등록해 두고 씀
복합형은 한 가지가 막혀도 다른 방법이 있어 안심이 됩니다.

# 번호 방식이 맞는 분
가장 널리 쓰이고 구조가 단순해 고장이 적은 편입니다. / 열쇠를 아예 들고 다니기 싫은 분께 잘 맞습니다.
다만 번호를 잊거나 어깨너머로 보일 수 있다는 점은 유의해야 합니다. / 번호판에 지문 자국이 남아 번호가 짐작되는 경우도 있어 가끔 닦아 주면 좋습니다.

# 카드·태그 방식이 맞는 분
번호를 자주 잊는 분이나 어르신께 편합니다. / 카드를 잃어버리지 않게 따로 보관하는 습관이 필요합니다.
카드를 잃어버렸을 때는 바로 삭제하고 새로 등록할 수 있어 보안도 챙길 수 있습니다. / 카드 분실은 [출장 열쇠](key-call.html)로 상담하셔도 됩니다.
@ 평택 스마트 도어락 카드 번호 지문

# 지문 방식이 맞는 분
아이가 있거나 손에 짐이 많은 분께 편합니다. / 손가락만 대면 열려 번호를 누를 필요가 없습니다.
손이 젖었거나 지문이 닳은 경우에는 인식이 잘 안 될 수 있습니다. / 비상용으로 번호나 카드도 함께 등록해 두는 게 좋습니다.

# 배터리와 비상 수단도 같이 보세요
스마트 도어락은 전기를 쓰기 때문에 배터리가 닳으면 멈춥니다. / 비상 전원 단자가 있는지, 비상 열쇠가 따로 있는지도 확인해 두세요.
쓰는 동안 배터리 경고음이 나면 그날 바로 교체하는 습관이 필요합니다. / 이 점만 지켜도 문 앞에서 막히는 일이 크게 줄어듭니다.

# 고를 때 확인할 것
제품을 정하기 전에 아래를 살펴보면 후회가 줄어듭니다. / 사진과 함께 상담받으면 더 정확합니다.
- 문 두께와 기존 구멍 규격
- 보조키를 같이 쓸지 여부
- 가족이 쓰기 편한 방식
- 비상 시 열 수 있는 방법
송탄동처럼 오래된 문이 많은 곳은 문 상태에 따라 설치 가능한 제품이 달라질 수 있습니다.
@ 송탄동 도어락 문 규격 확인

# 전화 주실 때 알려주실 것
상담이 빨라지도록 아래 내용을 알려주세요. / 사진이 있으면 더 좋습니다.
- 동 이름과 대략적인 위치
- 지금 쓰는 도어락과 문 사진
- 원하는 방식 (번호, 카드, 지문)
- 이사나 보안 같은 교체 이유

# 비용은 열기 전에 말씀드립니다
비용은 제품과 문 상태에 따라 달라 숫자를 미리 정해 두지 않습니다. / 도착해서 문을 확인하고 어떻게 얼마가 드는지 먼저 말씀드립니다.
괜찮다고 하시면 시작하고, 아니라면 그냥 돌아갑니다. / 작업 뒤에 말없이 붙는 비용은 없습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 설치는 이런 순서로 합니다
기존 도어락이 있으면 떼어 내고 문 상태를 확인합니다. / 새 도어락을 맞춰 끼운 뒤 열림과 잠김을 반복해서 확인합니다.
번호나 카드, 지문을 등록하고 사용법과 배터리 교체 방법을 알려 드립니다. / 자세한 내용은 [도어락 설치](doorlock-install.html)와 [도어락 교체](doorlock-replace.html) 페이지에 있습니다.

# 설치하고 나서 꼭 해볼 것
문을 열어 둔 상태로 번호나 카드를 여러 번 시험해 보세요. / 문이 열린 상태에서 시험해야 갇힐 걱정이 없습니다.
가족 모두의 지문과 카드를 한 번에 등록해 두면 편합니다. / 비상 열쇠 위치와 배터리 교체 방법도 같이 알아 두세요.

# 이럴 땐 수리가 먼저입니다
지금 도어락이 고장 난 정도라면 교체보다 [도어락 수리](doorlock-repair.html)로 해결되기도 합니다. / 배터리나 접점 문제는 수리로 끝나는 경우가 많습니다.
수리로 해결되면 굳이 교체를 권하지 않습니다. / 정말 바꿔야 할 때만 이유를 설명드립니다.

# 스마트 도어락 보안 관리
편한 만큼 관리도 필요합니다. / 아래 정도만 챙겨도 훨씬 안전합니다.
- 번호는 주기적으로 바꾸기
- 이사하거나 사람이 바뀌면 등록 정보 정리
- 카드를 잃어버리면 바로 삭제
- 번호판 지문 자국을 가끔 닦기

# 평택 어디든 갑니다
송탄동 가까운 지산동, 서정동, 비전동, 세교동, 동삭동까지 평택 전역을 다닙니다. / 안중읍, 포승읍, 팽성읍, 청북읍도 출동합니다.
다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.

# 이런 분께는 복합 방식을 권합니다
한 가지 방식만 쓰다가 막히는 경우가 많습니다. / 그래서 번호와 카드, 지문을 함께 등록해 두는 복합형이 안심이 됩니다.
예를 들어 평소엔 지문으로 열고, 손이 젖었을 때는 번호로, 번호를 잊었을 때는 카드로 열 수 있습니다. / 가족 구성에 맞게 등록 방식을 정하시면 됩니다.
어떤 조합이 맞는지는 상담하며 같이 정해 드립니다.
