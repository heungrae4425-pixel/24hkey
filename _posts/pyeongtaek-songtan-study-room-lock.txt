# 송탄동 독서실 앞에서 문이 안 열릴 때
송탄동은 송탄역 주변으로 학원과 독서실, 스터디카페를 찾는 학생과 직장인이 많은 생활권입니다. / 이런 공간은 출입문 하나가 잠기면 안에 있는 이용자와 밖에 있는 운영자 모두 곤란해집니다.
카드나 번호로 드나드는 무인 방식이 늘면서 출입 장치 문제도 함께 늘었습니다. / 시험 기간이면 더 급한 문제가 됩니다.
이 글은 송탄동 독서실·스터디카페 출입문이 잠기거나 안 열릴 때 누가 무엇을 확인해야 하는지 정리한 안내입니다. / 매장 출입문이라도 비파손으로 여는 것이 기본입니다.

# 독서실 출입문은 보통 이런 구조입니다
출입문은 유리문이나 방화문에 전자 잠금을 단 형태가 많습니다. / 카드 리더, 번호판, 전기 걸쇠가 함께 쓰이기도 합니다.
- 전기를 받아 잠금을 푸는 방식
- 정전이나 연결이 끊기면 잠기는 방식
- 정전 시에는 풀리는 방식
- 건전지로 움직이는 독립형 도어락
어떤 방식인지에 따라 정전이나 배터리가 다했을 때 반응이 반대가 됩니다. / 그래서 먼저 우리 가게 문이 어떤 구조인지 아는 것이 중요합니다.
같은 건물 안에서도 층마다 다른 방식이 쓰인 경우가 있습니다. / 새 가게를 인수한 분이라면 이전 운영자에게 방식을 물어보시는 것이 좋습니다.
설치한 업체의 연락처나 모델명을 적어 두면 문제가 생겼을 때 훨씬 수월합니다. / 문 안쪽 덮개에 붙은 스티커를 사진으로 찍어 두는 것만으로도 충분합니다.
구조를 모른 채 부딪히면 정전 상태에서 문이 잠기는지 풀리는지조차 알 수 없습니다.

# 이용자가 안에 있을 때의 우선순위
문이 잠겨서 안에 사람이 있는 상황이라면 안전이 먼저입니다. / 안에서 나갈 수 있는 비상 개방 장치가 있는지 확인하세요.
- 문 옆 버튼이나 레버가 있는지
- 비상 손잡이가 안쪽에 있는지
- 문 위 비상구 표시와 연결된 장치가 있는지
정상적으로 안에서는 열려야 합니다. / 안에서도 열리지 않는다면 바로 전화를 주세요.
방화 관련 문이라면 안쪽에서는 언제든 열려야 하는 것이 원칙입니다. / 그렇지 않은 상태라면 이용자 안전 측면에서 빨리 점검이 필요합니다.

# 운영자가 밖에서 확인할 것
운영자라면 번호판에 불이 들어오는지, 카드를 댔을 때 소리가 나는지부터 봅니다. / 소리는 나는데 안 열리는 경우와 아무 반응이 없는 경우는 원인이 다릅니다.
소리가 나는데 열리지 않는다면 모터나 전기 걸쇠가 끼였을 수 있습니다. / 아무 반응이 없다면 전원 공급이 끊겼을 가능성이 큽니다.
최근에 설정을 바꾼 일이 없는지도 떠올려 보세요. / 카드 추가나 번호 변경 뒤에 생기는 문제가 의외로 많습니다.
전원 어댑터가 빠져 있거나 멀티탭이 꺼진 경우도 종종 있습니다. / 청소 후에 플러그를 뽑아 두고 잊는 경우입니다.
공유기나 다른 기기와 같은 멀티탭을 쓰다 전원이 나간 경우도 있습니다. / 멀티탭의 스위치 불빛이 들어와 있는지 먼저 눈으로만 확인하세요.

# 야간 운영 시간에 막힐 때
24시간 운영하는 곳은 새벽에 문제가 생기면 마땅히 부를 곳이 없어 더 곤란합니다. / 운영자가 현장에 없는 무인 매장이라면 더 그렇습니다.
이용자가 먼저 전화로 알려 오면 운영자는 위치만 확인해 주세요. / 신분 확인은 운영자 쪽에서 해 주셔야 합니다.
이용자가 문 앞에 있다면 전화로 운영자 확인을 받은 뒤 진행합니다. / 이 확인이 없으면 작업을 시작할 수 없습니다.

# 사업장 문이라서 더 중요한 신분 확인
집과 달리 사업장은 누구 소유인지 확인하는 절차가 더 중요합니다. / 사업자등록증 사본, 임대차계약서, 건물 관리인의 확인 중 하나면 됩니다.
출장열쇠가 가서 먼저 하는 일이 이 확인입니다. / 번거로워도 이웃 점포와 건물 전체를 위한 절차입니다.
운영자가 멀리 있다면 사진이나 서류를 휴대폰으로 보내 주셔도 됩니다.
건물 관리인이 있다면 관리인이 대신 확인해 주는 경우도 많습니다. / 미리 연락처를 알려 주시면 도착 전에 확인을 마칠 수 있습니다.
건물 관리인이 있다면 관리인이 대신 확인해 주는 경우도 많습니다. / 미리 연락처를 알려 주시면 도착 전에 확인을 마칠 수 있습니다.

# 하지 말아야 할 것
- 유리문을 두드리거나 발로 차기
- 카드 리더를 임의로 뜯어 보기
- 전선이나 어댑터를 마음대로 뽑았다 꽂기
- 이용자 몰래 문을 억지로 열어 두기
전자 잠금장치는 충격에 약합니다. / 유리문에 금이 가면 수리가 더 커집니다.
카드 리더 덮개를 뜯으면 다시 맞추기가 어렵습니다. / 그대로 두고 연락 주시는 게 낫습니다.
@ 독서실 출입문 전자 잠금 점검

# 출장열쇠가 가서 보는 순서
먼저 전원과 연결 상태를 확인하고, 잠금 방식이 무엇인지 봅니다. / 그다음 정상 개방 방법이 있는지 먼저 찾아봅니다.
문이나 유리를 상하지 않게 여는 것이 기본입니다. / 부품을 바꿔야 한다면 바꾸기 전에 먼저 말씀드립니다.
[현관문 개문](door-open.html) 페이지에서 비파손 개문의 기본 원칙을 볼 수 있습니다. / 사업장 문도 같은 원칙으로 진행합니다.

# 비용은 열기 전에 말씀드립니다
상황을 보고 문을 열기 전에 먼저 비용을 말씀드립니다. / 괜찮다고 하셔야 작업을 시작합니다.
끝내 못 열면 비용은 받지 않습니다. / 작업 후 말없이 늘어나는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 열고 난 뒤 정리할 것
문이 열린 뒤에는 같은 일이 다시 생기지 않도록 원인을 짚어 봅니다. / 전원 문제, 카드 설정, 번호 변경 중 무엇이었는지 같이 확인합니다.
수리로 해결되면 수리만 하고, 낡아서 자주 말썽이면 [도어락 교체](doorlock-replace.html)를 설명드립니다. / 교체는 필요할 때만 권합니다.
운영 시간이 긴 곳이라면 예비 열쇠나 비상 번호를 따로 정해 두는 편이 좋습니다.
비상 번호는 운영자 한두 명만 알도록 관리하세요. / 이용자 카드와 관리자 카드를 구분해 두면 분실 시 정리도 쉽습니다.
비상 번호는 운영자 한두 명만 알도록 관리하세요. / 이용자 카드와 관리자 카드를 구분해 두면 분실 시 정리도 쉽습니다.

# 시험 기간 전에 점검해 두면
시험 기간이나 방학 특강 시즌에는 이용자가 몰려 문을 평소보다 많이 여닫습니다. / 그전에 한 번 점검해 두면 마음이 편합니다.
- 카드 리더 반응 속도 확인
- 번호판 버튼 눌림 확인
- 정전 시 문이 어떻게 되는지 확인
- 건전지식이면 교체 시기 점검
이 항목을 한 번 훑는 데 오래 걸리지 않습니다. / 필요하면 [도어락 수리](doorlock-repair.html) 안내에서 점검 범위를 확인하세요.
