# 백현동 새벽 귀가길, 번호판이 깜깜할 때
백현동은 판교역 쪽 일터로 오가거나 교대 근무를 하는 분이 많이 사는 동네입니다. / 밤샘이나 이른 새벽 근무를 마치고 돌아온 현관 앞에서 번호판이 반응하지 않으면 피로가 한꺼번에 몰려옵니다.
이 글은 그런 새벽에 침착하게 확인할 순서를 적었습니다. / 이웃이 잠든 시간이라 소리를 내기도 조심스러운 상황을 기준으로 썼습니다.
@ 백현동 새벽 귀가 도어락 번호판 무반응

# 우선 숨 한 번, 그리고 손으로 번호판 덮기
긴 근무 뒤에는 판단이 느려져 같은 번호를 계속 반복하기 쉽습니다. / 한 번 물러서서 문 상태를 눈으로 보는 것이 의외로 가장 빠른 길입니다.
급한 마음에 번호를 연달아 누르면 입력 제한이 걸릴 수 있습니다. / 먼저 한 번 멈추고 손바닥으로 번호판을 덮어 불이 들어오는지 보세요.
불이 들어오면 전원은 있다는 뜻이고, 전혀 안 들어오면 배터리 쪽 문제일 가능성이 큽니다.

# 근무 직후 손이 얼어서 생기는 착각
겨울 새벽에는 손이 곱아 번호를 평소와 다르게 누르게 됩니다. / 장갑을 낀 채라면 반응이 약해 눌렀는데도 입력이 안 되기도 합니다.
장갑을 벗고 번호를 천천히 한 자리씩 눌러 보세요. / 한 번에 틀리면 같은 번호를 서두르지 말고 몇 초 쉬었다가 다시 입력하세요.

# 반응이 없는 모양을 세 가지로 나눠 보기
전화로 설명할 때 문 앞에서 직접 소리를 들려주시는 것도 도움이 됩니다. / 눌렀을 때 나는 삑 소리의 길이와 횟수가 원인을 짐작하는 단서가 되기 때문입니다.
번호판이 반응하지 않는다는 말에도 모양이 여러 가지입니다. / 어느 쪽인지 알면 전화 한 통으로 원인을 훨씬 좁힐 수 있습니다.
- 불도 소리도 전혀 없는 경우
- 불은 켜지는데 눌러도 소리가 없는 경우
- 소리는 나는데 모터가 움직이지 않는 경우
첫 번째는 배터리, 두 번째는 번호판 접촉이나 습기, 세 번째는 모터나 걸쇠를 먼저 의심합니다.

# 새벽에 건전지를 구하는 방법
건전지를 대고 열었다면 안으로 들어가 바로 모든 건전지를 새것으로 바꾸세요. / 내일 아침 출근길에 같은 일이 반복되지 않게 하는 가장 확실한 방법입니다.
비상 단자 접촉이 약하면 건전지를 조금 더 눌러서 대야 합니다. / 손이 떨려 접촉이 흔들리지 않게 벽에 팔을 기대고 하면 쉽습니다.
밤새 열려 있는 편의점이나 근처 판매점에서 9V 건전지를 구할 수 있는지 먼저 떠올려 보세요. / 바깥쪽 아래 비상 단자에 건전지를 대고 있는 동안은 번호를 눌러 열 수 있는 제품이 많습니다.
단자 위치를 모르겠다면 무리하게 만지지 말고 도어락 아랫면을 손으로 훑어 보세요. / 그래도 못 찾겠으면 상황을 설명해 주시면 됩니다.
@ 백현동 도어락 비상 단자 9V 건전지 대기

# 경비실과 관리사무소에 확인할 것
경비실에서는 최근 정전이나 공용부 점검이 있었는지도 알려 줄 수 있습니다. / 전기가 잠깐 끊긴 뒤 도어락이 먹통이 되는 경우도 있기 때문입니다.
새벽이라 관리사무소는 닫혀 있어도 경비실이 있는 곳이 많습니다. / 공동 현관이 막혔다면 경비실에 먼저 알려 도움을 청하세요.
세대 확인이 필요한 경우를 대비해 신분증과 우편물 사진을 휴대폰에 저장해 두면 편합니다.

# 소리 내서 두드리지 마세요
새벽의 아파트 복도는 작은 소리도 크게 울립니다. / 문 앞에서 한참 번호를 누르고 한숨을 쉬는 소리가 이웃에게는 낯선 인기척으로 들릴 수 있습니다.
문을 크게 두드리거나 손잡이를 흔들면 이웃이 놀랍니다. / 새벽 시간에는 소음 민원이 생길 수 있어 조용한 해결이 더 낫습니다.
도어락을 세게 건드리는 일은 고장을 키우기도 합니다. / 안 열리는 문 앞에서 오래 버티지 않고 연락하는 편이 낫습니다.

# 안에 가족이 있다면
자는 가족을 깨우기 미안해 혼자 해결하려다 시간만 흘리는 경우가 많습니다. / 가장 빠른 방법은 가족이 안쪽에서 문을 열어 주는 것이니 먼저 시도해 보세요.
같이 사는 가족이 자고 있다면 휴대폰으로 먼저 깨워 보세요. / 안쪽에서 문을 열어 주면 가장 간단하게 끝납니다.
가족이 아이나 어르신이라면 놀라지 않게 천천히 말을 걸어 달라고 부탁하세요. / 문 안에 아이가 혼자 있는 상황이면 꼭 먼저 알려 주세요.

# 전화하실 때 알려주면 좋은 정보
통화 중에도 번호판을 한 번 더 눌러 보며 소리를 들려주시면 원인을 좁히는 데 큰 도움이 됩니다.
전화로 아래 내용을 알려주시면 출동 준비가 빠릅니다.
- 판교역 쪽인지 다른 방향인지 대략적인 위치와 동, 호수
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 건전지를 대 봤는지 여부
- 집 안에 사람이나 반려동물이 있는지
도어락 사진이 있으면 문자로 보내주세요.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 신분 확인이 필요합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 경비실이나 관리사무소를 통해 세대 확인을 부탁하는 방법도 있습니다. / 새벽이라면 경비실에 먼저 상황을 말해 두시면 수월합니다.

# 비용은 문 열기 전에 말씀드립니다
새벽이라고 비용이 몰래 올라가는 일은 없습니다. / 도착해서 상태를 본 뒤 작업 전에 먼저 말씀드리고 동의하실 때만 시작합니다.
상태를 보고 문 열기 전에 먼저 비용을 안내합니다. / 괜찮다고 하실 때만 시작하고, 문을 못 열면 비용은 받지 않습니다.
@ 백현동 24시출장열쇠 새벽 출동

# 열린 뒤에 바로 점검할 것
새벽에 겨우 들어와 잠들기 전에 마지막으로 번호를 한 번 시험해 두세요. / 안쪽에서 잠금과 해제를 반복해 보면 아침에 다시 곤란해지는 일을 막을 수 있습니다.
비밀번호가 노출됐다고 느낀다면 이 기회에 새로 등록하는 것도 방법입니다.
문이 열리면 도어락이 정상으로 돌아왔는지 같이 확인합니다. / 배터리가 원인이었다면 새것으로 바꾸고 번호도 다시 시험합니다.
다음 새벽에도 같은 일이 생기지 않도록 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)가 필요한지 설명해 드립니다. / 꼭 필요한 경우가 아니면 권하지 않습니다.

# 야간 교대 근무자를 위한 평소 습관
근무 시간이 불규칙한 분은 같이 사는 가족과 귀가 시간을 공유해 두면 좋습니다. / 문제가 생겼을 때 안쪽에서 바로 도와줄 수 있기 때문입니다.
출근 전에 배터리 경고음이 났는지 떠올려 보는 습관이 도움이 됩니다. / 경고음이 한 번이라도 났다면 그날 바로 건전지를 바꾸세요.
- 건전지 교체일을 도어락 안쪽에 적어 두기
- 비상용 9V 건전지를 가방이나 차에 두기
- 열쇠 구멍이 있다면 열쇠를 가족에게 맡기기
- 번호판에 물기가 남지 않게 닦기
[이용안내](guide.html)와 [현관문 개문](door-open.html) 페이지에서 진행 방식을 확인하세요. / 성남 안 다른 동네도 24시간 출동하며 [성남 출장열쇠](seongnam.html)에서 다니는 동네를 볼 수 있습니다.
