# 전화를 끊고 나면 기다림이 시작됩니다
백현동은 판교역과 가까워 출퇴근 때 이동이 많은 생활권입니다. / 문이 안 열려 전화를 걸고 나면 이제 기다리는 일만 남은 것 같지만 사실 할 일이 몇 가지 있습니다.
기다리는 동안 준비를 해 두면 도착 후 작업이 훨씬 빨리 끝납니다. / 이 글은 [성남 출장열쇠](seongnam.html)를 부른 뒤 도착하기 전까지 문 앞에서 할 일을 순서대로 정리했습니다.
막연히 서 있기보다 몇 가지만 챙겨 두면 시간이 덜 길게 느껴집니다. / 전화 통화로 출발 예정 시간을 들었다면 그 시간에 맞춰 준비를 끝내 두는 것을 목표로 하세요.
@ 백현동 출장열쇠 도착 전 준비

# 가장 먼저 안전한 자리를 정합니다
복도식이든 계단식이든 오가는 사람이 많은 곳은 피하세요. / 문 앞이 좁다면 계단 아래나 엘리베이터 근처 같은 눈에 띄는 곳이 낫습니다.
짐이 많다면 한쪽에 모아 두고 사람이 지나다니는 길을 막지 않도록 합니다. / 아이를 데리고 있다면 한시도 눈을 떼지 마세요.
밤이라면 밝은 곳, 사람이 있는 곳에서 기다리는 것이 좋습니다. / 불안하면 가족이나 지인에게 통화로 상황을 알려 두세요.

# 확인 서류를 미리 꺼내 둡니다
도착하면 가장 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
가방에서 서류를 꺼내 두거나 휴대폰에서 모바일 신분증과 고지서를 찾아 두세요. / 막상 도착했을 때 찾느라 시간이 걸리면 문 앞 대기가 길어집니다.
신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁해 두는 것도 지금 할 수 있는 일입니다. / 관리사무소 전화번호를 휴대폰에 찾아 두면 도움이 됩니다.

# 도어락 사진을 찍어 둡니다
문 전체와 도어락 가까이에서 두 장 정도 찍어 두세요. / 필요하면 문자로 보내 주시면 맞는 장비를 챙기는 데 도움이 됩니다.
번호판 모양, 손잡이 형태, 열쇠 구멍 유무가 보이면 좋습니다. / 제조사 이름이나 모델명이 적혀 있으면 함께 찍어 주세요.
사진은 설명을 대신해 줍니다. / 전화로 말씀하시기 어려운 부분을 눈으로 보여 줄 수 있습니다.
문틈이나 손잡이 주변에 이물질이 끼어 있는지도 보이게 찍어 두면 원인을 짐작하기 쉽습니다. / 어두운 곳에서는 플래시를 켜고 찍어 주세요.
문자로 사진을 보내기 어려우면 도착한 뒤 보여 주셔도 괜찮습니다.

# 번호판 상태를 다시 확인하되 무리하지 않습니다
기다리는 동안 번호판에 불이 들어오는지 한 번 더 보세요. / 상태가 바뀌었다면 도착 시간을 정하는 데 도움이 되니 알려 주세요.
다만 번호를 계속 눌러 보는 것은 피하세요. / 여러 번 틀리면 도어락이 한동안 입력을 막아 버립니다.
손잡이를 세게 당기거나 문을 두드리는 일도 하지 않는 편이 좋습니다. / 문과 도어락이 상할 수 있고 이웃에게 소음이 됩니다.
@ 성남 백현동 도어락 번호판 상태 확인

# 집 안에 사람이 있다면 먼저 알려 주세요
가족이나 동거인이 집 안에 있다면 연락해 보세요. / 안에서 열어 줄 수 있으면 출장이 필요 없을 수도 있습니다.
집 안에 아이나 노약자, 반려동물이 혼자 있다면 꼭 먼저 말씀해 주세요. / 우선순위가 달라지므로 도착 시간과 방법을 다시 조율합니다.
가스 불을 켜 두었거나 물을 틀어 놓았다면 그 사실도 알려 주세요. / 안전과 관련된 일은 다른 어떤 것보다 먼저입니다.

# 기사 도착 알림을 받는 방법
기사가 가까이 오면 전화나 문자로 연락드립니다. / 모르는 번호가 와도 받아 주시면 좋습니다.
건물 입구에서 길을 찾기 어려운 경우가 많으니 출입구 위치를 미리 알려 주세요. / 공동 현관이 잠겨 있다면 호출 방법이나 번호를 알려 주셔야 들어올 수 있습니다.
입구까지 나와 주실 수 있으면 훨씬 빠릅니다. / 동과 호수가 적힌 안내판 앞에서 만나기로 하면 길을 헤매는 일이 줄어듭니다.
지하주차장으로 들어오는 경우라면 주차 가능한 위치도 알려 주세요. / 방문 차량 등록이 필요한 단지라면 경비실에 미리 말해 두면 편합니다. / 다만 아이나 노약자와 함께 계시다면 무리해서 나오실 필요는 없습니다.

# 아파트 안에서는 이웃을 배려해 주세요
문 앞에서 오래 기다리면 이웃의 눈에 띕니다. / 큰 소리로 통화하거나 문을 두드리는 일은 가급적 자제해 주세요.
이웃이 놀라서 연락하는 일이 없도록 작은 소리로 상황을 설명하면 이해해 줍니다. / 밤이라면 더욱 조심해 주세요.
엘리베이터나 복도를 막고 있지 않은지도 한 번 살펴보세요. / 소방 통로나 비상계단 앞에 짐을 두는 일은 특히 피해야 합니다.
경비실이 있다면 문이 잠겼다는 사실을 미리 알려 두는 것이 좋습니다. / 낯선 사람이 문 앞에 서 있다고 신고가 들어가는 일을 막을 수 있습니다.

# 날씨가 춥거나 더울 때
겨울에는 문 앞 복도가 바깥만큼 춥기도 합니다. / 외투를 입고 몸을 따뜻하게 하는 것이 우선입니다.
여름에는 복도가 후덥지근해 물을 챙겨 마시는 것이 좋습니다. / 아이나 어르신과 있다면 더 신경 써 주세요.
너무 오래 걸릴 것 같으면 가까운 건물 로비나 편의점에서 기다리고 도착이 가까워지면 다시 문 앞으로 오셔도 됩니다.

# 기다리는 동안 하면 안 되는 일
- 드라이버나 카드로 문틈을 벌리는 일
- 베란다나 옆집으로 넘어가려는 일
- 도어락을 분해하거나 건전지를 마구 빼는 일
- 인터넷에서 본 방법을 따라 해 보는 일
이런 행동은 문과 도어락을 상하게 해 비용을 키울 수 있습니다. / 특히 높은 곳을 오가는 행동은 위험하니 절대 하지 마세요.
기다리는 시간이 길어도 서두르지 말고 그대로 두는 것이 가장 안전합니다. / 현관문 개문 방법은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 도착하면 이렇게 진행합니다
기사가 도착하면 먼저 신분을 확인하고 문과 도어락 상태를 봅니다. / 방법과 비용을 먼저 말씀드리고 동의하시면 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 다시 여쭤봅니다.
최대한 문이 상하지 않는 방법부터 순서대로 해 봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 백현동 24시 출장열쇠 도착 진행

# 열린 뒤에는 원인을 같이 정리합니다
문이 열리면 왜 안 열렸는지 설명해 드립니다. / 배터리가 문제였다면 새것으로 교체하고, 번호를 잊었다면 새로 등록합니다.
같은 일이 반복되지 않도록 점검할 부분도 알려 드립니다. / 수리가 필요하면 [도어락 수리](doorlock-repair.html)로, 너무 낡았다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
다음에는 배터리를 한꺼번에 교체하고 9V 건전지를 하나 준비해 두세요.

# 백현동 말고 성남 어디든 연결됩니다
판교, 삼평동, 운중동, 정자동까지 성남 안이면 24시간 출동합니다. / 성남 밖은 [출장 지역](area.html)에서 확인해 주세요.

# 자주 묻는 질문
? 기다리는 동안 꼭 문 앞에 있어야 하나요? | 아닙니다. 안전하고 따뜻한 곳에서 기다리다 도착 즈음 문 앞에 오셔도 됩니다.
? 신분증이 집 안에 있어요. | 주소가 나온 우편물이나 관리사무소 확인으로 가능합니다.
? 기다리는 동안 번호를 계속 눌러 봐도 되나요? | 권하지 않습니다. 여러 번 틀리면 도어락이 입력을 막습니다.
? 문을 못 열면 비용이 드나요? | 못 열면 비용은 받지 않습니다.
? 한밤에도 연락해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.

백현동에서 문이 안 열리면 우선 전화로 상황을 알려 주세요. / 24시출장열쇠는 서울, 경기 전 지역 24시간, 전화 010-3664-5455입니다.
