# 현관문 말고 다른 문도 잠깁니다
단대동은 단대오거리역 주변으로 빌라와 아파트가 이어진 주거 동네입니다. / 현관문 얘기만 많이 하지만 실제로는 베란다 문, 미닫이문, 방문 잠금장치 때문에 연락 주시는 경우도 적지 않습니다.
이런 문은 현관문보다 구조가 단순해 보이지만 부품이 작고 약해서 힘을 주면 쉽게 망가집니다.
이 글은 단대동에서 집 안쪽 문이 잠기거나 안 열릴 때 문 종류별로 무엇을 확인하면 좋은지, 어느 때 연락하면 되는지 정리했습니다.
@ 단대동 베란다 방문 잠금장치 점검

# 어떤 문이 문제인지부터 구분하기
같은 잠금 문제라도 문 종류에 따라 방법이 다릅니다.
- 베란다 샷시 창, 미닫이 유리문
- 방문의 동그란 잠금 손잡이
- 화장실 문 잠금
- 붙박이장이나 서랍 같은 작은 잠금
문 종류를 알면 전화로 설명하기 쉽고, 챙겨 갈 장비도 정확해집니다.

# 베란다 문이 안 열릴 때
베란다 문은 바닥 레일에 먼지가 쌓이거나 잠금 걸쇠가 헐거워지면 안 열립니다. / 특히 겨울에 환기를 오래 안 시키다가 열려고 하면 뻑뻑해지는 일이 많습니다.
문을 위로 살짝 들어 올리듯 밀면서 열어 보세요. / 바퀴가 레일에서 벗어나 있으면 이렇게 하면 제자리에 걸리기도 합니다.
걸쇠 잠금 방향이 맞는지도 한 번 확인해 보세요. / 잠금 손잡이를 반대로 돌려 두고 열려고 하는 경우도 의외로 많습니다.

# 베란다에 갇혔다면
베란다에 나갔다가 문이 닫히며 안쪽 잠금이 걸린 경우, 집 안으로 못 들어오는 일이 있습니다. / 이때는 먼저 휴대폰이 있는지, 가족이 집 안에 있는지 확인하세요.
- 가족에게 전화해 안에서 열어 달라고 부탁하기
- 베란다 바닥이나 난간에 위험한 물건이 없는지 살피기
- 추운 날씨라면 몸을 따뜻하게 하고 오래 서 있지 않기
가족이 안에 없으면 연락 주세요. / 높은 층은 특히 안전이 먼저라서 무리하게 창틀을 넘으려 하지 마세요.
@ 단대동 베란다 문 잠김 출장열쇠

# 미닫이 잠금장치가 걸렸을 때
미닫이문의 작은 걸쇠는 안쪽에서 내려 두면 바깥에서 열리지 않습니다. / 아이가 만지다가 내려놓았는데 부모가 모르고 문을 닫아 잠기는 일이 종종 있습니다.
얇은 도구로 틈새를 벌려 걸쇠를 올리는 방법이 널리 알려져 있지만 문틀과 유리에 손상이 갈 수 있습니다. / 잘 모르고 하면 오히려 걸쇠가 휘어 못 쓰게 됩니다.
걸쇠 모양과 문 사이 틈 정도를 알려주시면 방법을 정할 수 있습니다.
유리가 있는 문은 힘을 주면 깨질 수 있어 특히 조심스럽습니다. / 그래서 누르거나 흔들지 않고 상태를 보는 것부터 시작합니다.

# 방문 동그란 잠금 손잡이
방문에는 가운데 작은 구멍이 있는 동그란 손잡이를 쓰는 경우가 많습니다. / 안에서 잠그면 밖에서 비상용 도구로 풀 수 있게 만든 구조입니다.
방 안에 아이가 들어가 잠갔는데 못 푸는 경우가 가장 많습니다. / 이럴 때는 문 너머로 침착하게 대화하면서 손잡이를 돌려 보라고 알려 주세요.
아이가 울거나 겁을 먹은 상태라면 힘으로 문을 두드리거나 열려고 하지 마세요. / 전화로 상황을 알려주시면 순서를 안내해 드립니다.

화장실 문은 습기 때문에 부품이 쉽게 녹슬고 굳습니다. / 오래된 집일수록 잠금 걸쇠가 안에서 걸려 밖에서 열리지 않는 경우가 많습니다.
안에 사람이 있는지부터 확인하세요. / 안에 갇힌 분이 어르신이거나 몸이 불편하다면 지체하지 말고 바로 연락 주셔야 합니다.
화장실은 좁아서 문을 억지로 열다 안에 있는 분이 다칠 수 있습니다.
샤워 중이거나 미끄러운 바닥에서 넘어진 경우도 있으니 문 너머로 계속 말을 걸어 반응을 확인하세요. / 대답이 없다면 시간을 끌지 말고 바로 전화해 주세요.

# 직접 열 때 하지 말아야 할 일
- 칼이나 드라이버로 문틀 틈을 억지로 벌리기
- 유리 부분을 누르거나 두드려 보기
- 문을 세게 밀거나 발로 차기
- 손잡이를 힘껏 비틀기
이런 방법은 문, 틀, 유리 모두를 상하게 합니다. / 안에 사람이 있다면 더 위험합니다.
직접 해볼 수 있는 확인만 하시고 나머지는 연락 주세요.

# 전화하실 때 알려주면 좋은 것
- 어떤 문인지 (베란다, 미닫이, 방문, 화장실)
- 안쪽에 사람이나 반려동물이 있는지
- 문이 잠긴 상태인지, 레일에서 벗어난 상태인지
- 층수와 대략적인 위치, 단대오거리역 방향인지 모란역 방향인지
- 문 사진
문 사진이 있으면 장비를 맞춰 챙겨 갈 수 있습니다. / 사진을 보내기 어렵다면 말로 모양을 설명해 주세요.

# 도착하면 사시는 분인지 확인합니다
집 안쪽 문이라도 남의 집에 들어가는 일이라 신분 확인부터 합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
집 안에 가족만 있고 본인이 밖에 계신 경우에는 관리사무소에 세대 확인을 부탁해 보세요. / 확인이 되지 않으면 작업을 할 수 없습니다.

# 문을 상하지 않게 여는 방법
작은 문일수록 부품이 약해서 가장 덜 상하는 방법부터 시도합니다. / 걸쇠가 걸렸는지 레일이 문제인지 보고 나서 맞는 방법을 고릅니다.
작업 중에 부품을 바꿔야 하면 손대기 전에 먼저 말씀드립니다. / 현관문과 도어락 개방은 [현관문 개문](door-open.html) 페이지에 따로 정리해 두었습니다.
@ 성남 단대동 출장열쇠 미닫이 방문 개방

# 비용은 시작 전에 말씀드립니다
문 종류와 상태를 보고 열기 전에 먼저 알려드립니다. / 괜찮다고 하시면 시작하고 아니면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에서 볼 수 있습니다.

# 열고 난 뒤 고쳐야 할 것
문이 열렸다면 걸쇠와 레일, 손잡이를 같이 점검합니다. / 부품이 닳았다면 그 부분만 바꾸면 되는 경우가 많습니다.
방문이나 현관 쪽 도어락까지 문제가 있다면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 많이 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
잠금장치를 새로 달고 싶은 경우에는 [도어락 설치](doorlock-install.html)를 참고하세요.

- 베란다 레일을 가끔 청소해 먼지와 이물질 빼기
- 잠금 걸쇠가 헐거워지면 그날 점검
- 아이가 방문을 잠글 수 있는 나이라면 열 수 있는 방법을 같이 알려 주기
- 화장실 문은 환기를 자주 해서 습기 줄이기
- 문 틈에 낀 이물질은 마른 솔로 쓸어내기
작은 문은 존재감이 적어서 고장을 방치하기 쉽습니다. / 그래서 막상 못 열 때가 되어서야 놀라는 일이 많습니다.
계절이 바뀔 때 한 번씩 모든 문을 열고 닫아 보는 습관이 좋습니다. / 이런 점검은 몇 분이면 되고 비용도 들지 않습니다.

# 단대동 말고 성남 어디든 갑니다
단대동 옆 신흥동, 수진동, 태평동, 금광동도 다닙니다. / 성남 안이면 어디든 24시간 출동합니다.
성남 동네는 [성남시 출장열쇠](seongnam.html)에서 볼 수 있습니다. / 다른 지역은 [출장 지역](area.html)을 확인해 주세요.
