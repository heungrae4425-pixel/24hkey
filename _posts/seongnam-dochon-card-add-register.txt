# 카드 한 장으로 버티던 집이 늘어난 가족을 만났을 때
도촌동은 아이를 키우는 가정과 출퇴근하는 직장인이 섞여 사는 동네입니다. / 처음 도어락을 달 때 받은 카드가 두 장뿐이라, 가족이 늘거나 자녀가 커서 혼자 다니기 시작하면 카드 한 장이 아쉬워집니다.
카드를 더 만들려고 설명서를 찾다가 어디서부터 해야 할지 막막한 분이 적지 않습니다. / 이 글은 도촌동에서 카드키나 태그를 추가로 등록하거나 초기화하려는 분을 위해 순서대로 정리했습니다.
등록하다가 문이 안 열리는 상황까지 생기면 [성남 출장열쇠](seongnam.html)로 연락 주셔도 됩니다.
@ 도촌동 도어락 카드키 추가 등록

# 카드키와 태그는 같은 원리로 움직입니다
카드, 열쇠고리형 태그, 팔찌형 태그 모두 도어락에 정해 둔 신호를 등록해 두는 방식입니다. / 겉모양은 달라도 등록하는 흐름은 거의 같습니다.
- 도어락 안쪽에서 등록 모드로 들어간다
- 새 카드를 인식부에 가져다 댄다
- 등록음이 울리면 완료한다
제품마다 등록 모드로 들어가는 버튼 조합이 다릅니다. / 설명서가 없다면 모델명을 사진으로 보내주시면 확인해 드립니다.

# 추가 등록 전에 챙길 것
시작 전에 준비물만 갖추면 5분 안에 끝나는 경우가 많습니다.
- 현재 사용 중인 비밀번호나 관리자 번호
- 등록할 새 카드나 태그
- 안쪽 덮개를 열 수 있는 작은 도구
- 배터리 상태가 충분한지 확인
배터리가 약한 상태에서 등록하면 중간에 꺼져 처음부터 다시 해야 합니다. / 등록 전에 새 배터리로 바꿔 두는 편이 안전합니다.
등록을 끝낸 뒤에는 새 카드로 문 밖에서 실제로 열어 보세요. / 안쪽에서 등록음이 났다고 해서 바깥 인식부에서도 반응한다는 보장은 없습니다.
문을 닫기 전에 한 번, 닫은 뒤에 한 번 시험하면 안심할 수 있습니다. 특히 아이가 쓸 카드라면 아이 손으로 직접 대 보게 하세요. 어른이 대는 속도와 아이가 대는 속도가 달라 인식이 다를 때가 있습니다.

# 등록 모드에 들어가는 두 가지 방식
제품에 따라 안쪽 버튼을 누르는 방식과, 관리자 번호를 입력하는 방식으로 나뉩니다. / 안쪽 버튼 방식은 문을 연 상태에서 안쪽 덮개를 열고 등록 버튼을 누르면 됩니다.
관리자 번호 방식은 번호판에서 특정 순서로 눌러 모드에 들어갑니다. / 번호를 잊었다면 등록이 막히므로 초기화를 생각해야 합니다.
어느 쪽인지 헷갈리면 억지로 눌러 보지 마세요. / 여러 번 틀리면 잠시 입력이 막힐 수 있습니다.
@ 안쪽 덮개와 등록 버튼 위치

# 카드를 새로 만들 때 흔한 실수
처음 하는 분들이 자주 겪는 일을 모아 봤습니다.
- 카드를 너무 빨리 떼서 인식이 안 된 경우
- 호환되지 않는 카드를 사 온 경우
- 기존 카드를 같이 지워 버린 경우
- 등록은 됐는데 문 쪽 인식부가 아닌 안쪽에서만 반응하는 경우
카드는 도어락 종류에 맞는 규격이어야 합니다. / 구입 전에 모델명이나 현재 쓰는 카드 모양을 비교해 보세요.

# 가족 수대로 늘릴 때 정리하는 기준
카드를 늘릴 때는 누가 어떤 카드를 쓰는지 정해 두면 관리가 쉽습니다. / 아이에게는 열쇠고리형 태그를 목걸이처럼 달아 주기도 합니다.
- 부모용 카드는 지갑에 한 장
- 아이용 태그는 가방 고리에 달기
- 비상용 카드는 믿을 수 있는 곳에 따로 보관
너무 많이 만들어 누가 가졌는지 모르는 상태가 되면 오히려 불안합니다. / 필요한 수만큼 등록하고 목록을 메모해 두세요.
도촌동처럼 아이들이 학원이나 학교를 오가는 동네에서는 카드를 가방 바깥에 달아 두었다가 잃어버리는 일이 흔합니다. / 안쪽 주머니에 넣는 습관을 같이 알려 주면 분실이 줄어듭니다.
등하교 시간에 맞춰 부모가 집에 없는 날에는 카드 하나가 곧 아이의 안전과 연결됩니다. 그만큼 카드의 보관 방식도 가족이 함께 정해 두는 편이 좋습니다.

# 카드를 잃어버렸을 때 먼저 할 일
카드가 없어졌다면 등록해 둔 카드를 지우고 새로 등록하는 편이 안전합니다. / 누군가 주워서 쓸 수 있는지는 알 수 없으니 먼저 신호를 무효화하세요.
일부 제품은 개별 삭제가 되지만, 어떤 제품은 전체를 지운 뒤 다시 등록해야 합니다. / 이 경우 남은 카드도 모두 다시 등록해야 하니 가족 것을 한자리에 모아서 하세요.
분실이 반복되는 집이라면 [카드키 분실](key-call.html) 대처 요령도 읽어 보세요.

# 초기화는 마지막 수단입니다
초기화하면 등록해 둔 비밀번호와 카드가 모두 사라집니다. / 방법을 모를 때 눌러 보다가 이미 초기화되는 경우도 있습니다.
초기화가 필요한 대표적인 때는 관리자 번호를 잊었을 때, 중고로 받은 집의 이전 설정을 지우고 싶을 때입니다. / 초기화 뒤에는 번호와 카드를 새로 등록하는 데 시간이 걸립니다.
- 초기화 전에 지금 문이 열려 있는지 확인
- 문을 연 채로 작업해야 중간에 잠기지 않음
- 끝난 뒤 가족 모두 한 번씩 열어 보기
문을 닫은 채 초기화하다 잠기는 일이 의외로 흔합니다. / 반드시 문을 열어 둔 채 진행하세요.

# 등록이 안 될 때 확인하는 순서
설명대로 했는데 등록음이 안 난다면 아래를 점검해 보세요.
배터리 잔량이 부족한 건 아닌지, 카드 규격이 맞는지, 인식부에 먼지나 물기가 있는지 봅니다. / 안쪽 덮개를 열었을 때 기판에 이물질이 있어도 반응이 둔해집니다.
다 해봐도 안 되면 제품 불량이나 내부 고장일 수 있습니다. / 이 경우 [도어락 수리](doorlock-repair.html)로 점검이 필요합니다.
@ 카드 인식부 배터리 상태 확인

# 문이 잠겨 등록은커녕 열리지도 않을 때
등록하려고 만지다가 문이 닫히면서 잠기는 경우가 있습니다. / 카드도 번호도 먹지 않는다면 억지로 열려고 하지 마세요.
이럴 땐 번호판 상태와 소리를 살펴보고 연락 주시면 됩니다. / 도어락 사진을 보내주시면 맞는 장비를 챙겨 가기 좋습니다.
어떤 방법으로 열지는 도착해서 보고 정합니다. / 현관문 개문 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 도착하면 신분 확인부터 합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 이웃과 집 모두를 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 시작하기 전에 말씀드립니다
등록만 도와드리는 일인지, 문을 열어야 하는지, 부품을 바꿔야 하는지에 따라 달라집니다. / 얼마인지는 작업 전에 먼저 알려드리고 동의하신 뒤에 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다. 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 도촌동 말고 성남 어디든 갑니다
도촌동 주변은 물론 모란역, 야탑역, 판교역 생활권까지 성남 전역을 다닙니다. / 다니는 동네는 [성남시 출장열쇠](seongnam.html)에서 확인하세요.
서울, 경기 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
