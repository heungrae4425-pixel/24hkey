# 도촌동 새 집, 도어락부터 확인해야 하는 이유
도촌동은 모란역 쪽으로 오가는 분들이 많은 동네로 알고 있고, 이사 오고 나가는 일도 자주 있습니다. / 이사 첫날 짐 정리에 정신이 없다 보면 현관 도어락은 그대로 두고 지나치기 쉽습니다.
그런데 앞서 살던 사람이 쓰던 번호나 카드가 도어락에 그대로 남아 있을 수 있습니다. / 이 글은 그걸 어떻게 확인하고 정리하는지 순서대로 적었습니다.
@ 도촌동 이사 온 집 현관 도어락 번호판

# 이전 세입자 번호가 남을 수 있는 구조
도어락은 비밀번호를 여러 개 저장하는 제품이 많습니다. / 새로 번호를 하나 더 등록해도 기존 번호가 지워지는 게 아니라 같이 남는 경우가 있습니다.
카드키나 지문도 마찬가지입니다. / 이사 나가는 쪽이 카드를 가져갔다면 그 카드는 여전히 그 도어락을 열 수 있는 상태일 수 있습니다.
악의가 있다는 뜻이 아니라, 그냥 정리가 안 된 상태라는 점이 문제입니다.
특히 임대 기간이 짧게 바뀌는 집은 이전 사용자가 한 명이 아닌 경우도 있습니다. / 몇 사람이 거쳐 간 도어락이라면 저장된 정보가 쌓여 있을 수 있습니다.
번호 등록 개수가 정해진 제품도 있어, 꽉 차 있으면 새 번호가 등록되지 않기도 합니다.

# 입주 전에 가장 먼저 해 볼 것
- 안쪽 덮개를 열어 초기화 버튼이 있는지 확인
- 사용 설명서나 제품 이름을 찾아 등록 번호 삭제 방법 확인
- 임대인이나 중개인에게 도어락을 교체했는지 물어보기
- 등록된 카드나 열쇠가 몇 개인지 정리
먼저 물어볼 사람이 있으면 짐을 풀기 전에 연락해 두세요. / 이전 사용자가 쓰던 번호를 아는 사람이 아직 있을 수 있습니다.
가능하면 계약서를 쓰는 단계에서 도어락을 새로 정리해 달라고 요청해 두세요. / 그게 어려웠다면 입주 당일에라도 직접 확인하면 됩니다.
확인한 날짜와 한 일을 휴대폰 메모에 짧게 적어 두면 나중에 문제가 생겼을 때 도움이 됩니다.

# 초기화와 번호 삭제는 뭐가 다른가
초기화는 저장된 번호와 카드를 한꺼번에 지우고 공장 상태로 돌리는 것입니다. / 번호 삭제는 특정 번호 하나만 지우는 방식이라 나머지가 남을 수 있습니다.
안전하게 하려면 초기화 후 내 번호만 새로 등록하는 편이 확실합니다. / 제품마다 초기화 방법이 달라서, 설명서에 없다면 모델명을 확인한 뒤 연락 주세요.
@ 도어락 안쪽 덮개를 열고 초기화 버튼을 찾는 모습
일부 제품은 초기화해도 관리자 번호만 남는 설정이 있습니다. / 초기화 후에는 안쪽에서 새 번호를 등록하고, 바깥에서 기존 번호가 여전히 먹히는지 꼭 시험해 보세요.
초기화 뒤에 소리나 불빛 변화가 있는지 지켜보세요. / 제품마다 완료를 알리는 방식이 달라 처음 하시는 분은 헷갈리기 쉽습니다.

# 직접 초기화할 때 주의할 점
초기화 버튼을 누르고 전원을 연결하는 순서가 중요한 제품이 있습니다. / 순서를 잘못하면 경고음만 나고 아무것도 안 바뀌어 불안해질 수 있습니다.
관리자 번호가 따로 있는 제품은 초기화하면 관리자 번호도 같이 사라지는 경우가 있습니다. / 새 번호를 정해 놓고 초기화하기 전에 문을 열어 둔 채로 작업하세요. 밖에 나와서 문이 닫히면 낭패입니다.

# 카드키와 열쇠는 어떻게 하나
받은 카드키가 몇 장인지 먼저 세어 보세요. / 이전 사용자에게 몇 장 만들어 줬는지는 알 수 없으니, 카드를 전부 지우고 새로 등록하는 게 낫습니다.
비상 열쇠도 같은 생각으로 접근합니다. / 예전 열쇠를 가진 사람이 있을 수 있으므로 열쇠를 교체하거나 실린더를 바꾸는 것도 방법입니다.
[도어락 교체](doorlock-replace.html)를 하지 않더라도 카드와 번호 정리는 꼭 해 두세요.
카드키는 분실 위험이 크니 이사 직후 몇 장을 쓸지 정하고 나머지는 등록 해제하세요. / 열쇠를 복사해 둔 사람이 있는지 집주인에게 물어보는 것도 방법입니다.

# 어디까지 정리하면 안심할 수 있나
번호, 카드, 지문, 비상 열쇠를 전부 새 상태로 맞추면 됩니다. / 하나라도 빠지면 그 틈으로 이전 정보가 남습니다.
정리를 끝낸 뒤에는 새 번호로 열고 닫기를 몇 번 해 보며 정상 작동을 확인합니다. / 안쪽에서 보조키를 돌려 보는 것까지 해 두면 좋습니다.
확인할 때는 문이 열려 있는 상태에서 안과 밖을 오가며 반복하세요. / 한 번에 끝내지 않고 간격을 두고 다시 확인하면 놓친 부분을 잡을 수 있습니다.
마지막으로 비상 열쇠가 실제로 들어가고 돌아가는지도 시험해 보시면 확실합니다.

# 이사 첫날 문 앞에서 막혔다면
번호를 들었는데 안 열리거나, 알려준 번호가 이미 바뀌어 있는 경우도 있습니다. / 이럴 때 억지로 여러 번 누르면 도어락이 입력을 잠깐 막기도 합니다.
세 번 정도 시도해 보고 안 되면 멈추고 임대인이나 중개인에게 먼저 확인하세요. / 연락이 닿지 않으면 [출장열쇠](key-call.html)로 연락 주시면 됩니다.
이삿짐센터가 이미 다녀간 뒤라면 번호를 임시로 공유한 사람이 있는지도 떠올려 보세요. / 그 번호는 이사가 끝나면 바로 지우는 것이 좋습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
이사 온 집이라도 문을 여는 일이라 신분 확인을 먼저 합니다. / 임대차 계약서, 신분증, 주소가 나온 우편물, 관리사무소 확인 중 가능한 것을 준비해 주세요.
번거로워도 이웃과 집 주인 모두를 지키는 절차입니다. / 새 집이라 아직 우편물이 없다면 관리사무소에 입주 확인을 부탁하는 방법이 있습니다.

# 비용은 문 열기 전에 말씀드립니다
번호 정리, 카드 등록, 초기화 작업은 도어락 종류에 따라 시간이 다릅니다. / 작업 전에 먼저 비용을 말씀드리고, 괜찮다고 하셔야 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙니다.
@ 새 비밀번호를 등록하는 도어락 번호판

# 새 번호를 정할 때 요령
생일, 전화번호 뒷자리, 주소 숫자처럼 남이 짐작하기 쉬운 번호는 피하세요. / 가족과 함께 외울 수 있으면서 규칙이 눈에 띄지 않는 번호가 좋습니다.
번호를 정했으면 가족에게 문자로 보내기보다 말로 전하는 게 낫습니다. / 필요한 정리는 [도어락 설치](doorlock-install.html)나 교체 상담 때 함께 이야기하면 됩니다.
번호를 정한 뒤에는 안쪽에서 열고 닫기를 두세 번 시험해 보세요. / 문이 열린 상태에서 등록이 제대로 됐는지 확인하는 것이 안전합니다.
룸메이트나 가족이 있다면 새 번호를 정했다고 같이 알려야 문 앞에서 서로 헷갈리지 않습니다.

# 도촌동 말고 성남 어디든 갑니다
도촌동 옆 동네는 물론 성남 전 지역을 다닙니다. / 24시간 출동하므로 이사 당일 저녁이라도 연락 주셔도 됩니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html)에서 보시고, 이용 순서는 [이용안내](guide.html)에 있습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)을 참고하세요.
