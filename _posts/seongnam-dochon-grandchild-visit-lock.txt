# 도촌동 할머니 할아버지 댁, 손주 번호는 어떻게 할까
도촌동에는 야탑역 방면 생활권과 가까운 곳에서 오래 사시는 어르신들이 많습니다. / 주말이면 손주가 오는데 매번 문을 열어 주러 나가기가 번거롭다는 말씀을 자주 들습니다.
그렇다고 가족 번호를 그대로 알려주자니 아이가 아무한테나 말할까 걱정되기도 합니다. / 아이가 외우기 쉽고, 어른이 관리하기 편한 번호를 정하는 요령을 정리했습니다.
@ 도촌동 손주 방문용 도어락 번호 설정

# 손주용 번호를 따로 두면 좋은 이유
손주가 여럿이면 아이마다 다른 번호를 주는 방법도 있습니다. / 누가 언제 왔는지 알기 쉽고, 한 명 번호만 지울 수도 있습니다.
집 전체 번호를 아이에게 알려주면 바꿀 때마다 모두에게 다시 알려야 합니다. / 손주용 번호를 따로 만들면 필요할 때 그것만 지우면 됩니다.
많은 도어락이 번호를 여러 개 등록할 수 있습니다. / 제품 설명서에서 '사용자 추가'나 '임시 번호' 같은 항목을 찾아보세요.
한 개만 저장되는 제품도 있으니 먼저 확인이 필요합니다.

# 아이가 외우기 쉬운 번호의 조건
너무 짧으면 쉽게 맞춰지고, 너무 길면 아이가 헷갈립니다. / 제품이 허용하는 길이 안에서 무리 없는 자리 수로 정하세요.
- 같은 숫자를 반복하는 번호는 피하기
- 123456처럼 순서대로 나열한 번호는 피하기
- 집 주소나 출생연도처럼 남이 알 만한 번호는 피하기
- 아이가 노래처럼 따라 부를 수 있는 규칙을 만들기
예를 들어 손주 이름 글자 수와 방문하는 요일처럼 둘만 아는 규칙을 쓰면 외우기 쉽습니다. / 다만 너무 뻔하면 남도 알 수 있으니 한 가지는 섞어 주세요.

# 아이에게 번호를 알려줄 때
도촌동 댁에서 아이가 처음 혼자 문을 열어 보는 날은 어른이 문 안쪽에서 지켜봐 주세요. / 처음 성공하는 경험이 있으면 다음부터 훨씬 자신 있게 누릅니다.
번호를 말로만 알려주면 금방 잊습니다. / 종이에 적어 가방에 넣어 주기보다 부모와 함께 한 번 눌러 보게 하는 편이 낫습니다.
번호는 소리 내어 읽지 않도록 가르쳐 주세요. / 엘리베이터나 복도에서 다른 사람이 들을 수 있습니다.
문 앞에서 번호를 누를 때 손으로 살짝 가리는 습관도 알려 주면 좋습니다.
@ 도촌동 아이와 함께 번호 눌러 보기

# 번호를 눌러도 안 열릴 때 아이는 어떻게
아이가 혼자 문 앞에서 막히면 당황해 울기도 합니다. / 미리 이럴 때 어떻게 하라고 정해 두세요.
- 두세 번 눌러 보고 안 되면 멈추고 어른에게 전화하기
- 문을 세게 흔들거나 발로 차지 않기
- 번호판이 꺼져 있으면 건드리지 말고 기다리기
여러 번 틀리면 도어락이 잠시 입력을 막습니다. / 그러면 기다려도 한동안 못 누르니, 무리하게 반복하지 않도록 알려 주세요.

# 손주가 안에서 문을 잠갔을 때
도촌동 댁에서 손주가 혼자 화장실이나 방에 들어가 문을 잠그는 일도 있습니다. / 이 경우 방문 잠금은 보통 동전이나 가는 막대로 풀 수 있는 구조라 침착하게 안내해 주세요.
아이가 장난으로 안쪽 보조키를 돌려 잠그는 일이 있습니다. / 이때 어른이 밖에서 놀라 큰 소리를 내면 아이가 더 당황합니다.
문 너머로 천천히 말을 걸어 안쪽 잠금 방향을 돌려 보게 이끌어 주세요. / 그래도 안 되면 [열쇠 출장](key-call.html) 안내를 보시고 전화 주세요.
아이가 안에 있다는 것은 꼭 먼저 알려주셔야 합니다.

# 방문이 끝난 뒤에는 번호를 지웁니다
명절이나 방학처럼 손주가 며칠 머무는 때는 기간을 정해 두면 편합니다. / 떠나는 날 아침에 함께 지우는 습관을 들이면 잊지 않습니다.
손주가 다녀간 뒤에도 번호가 남아 있으면 다음에 누가 알게 될지 모릅니다. / 방문 기간이 지나면 바로 지우거나 바꿔 두세요.
잊기 쉬우니 달력에 '번호 바꾸는 날'을 적어 두는 방법이 있습니다. / 어르신이 직접 하기 어려우면 가족이 방문할 때 같이 바꾸세요.
임시 번호를 쓰는 요령은 설명서를 먼저 보시고, 모르면 편하게 문의해 주세요. / 도어락이 오래돼 번호 등록이 잘 안 되면 [도어락 수리](doorlock-repair.html)로 점검해 드립니다.

# 어르신이 쓰기 편한 설정
번호 하나를 길게 외우기 힘드시면 숫자를 소리 내어 한 자리씩 눌러 보는 연습이 도움이 됩니다. / 손주가 오는 날 아침에 한 번 같이 해 보시면 자신이 생깁니다.
오래 쓰던 도어락은 버튼이 닳아 잘 안 눌리기도 합니다. / 손가락 힘이 약한 어르신에게는 이 점이 불편할 수 있어 같이 확인합니다.
번호판 밝기를 높이고 눌렀을 때 소리가 또렷하게 나게 설정하면 확인하기 쉽습니다. / 안쪽 손잡이를 돌려서만 잠기는 방식이 편한지도 점검해 보세요.
번호를 자주 틀리신다면 단순한 번호를 따로 정해 가족 모두 같은 규칙으로 쓰는 방법이 있습니다. / 어르신 번호와 손주 번호를 다르게 두면 문제가 생겼을 때 구분하기 쉽습니다.
설정이 어렵다면 한 번만 방문해서 같이 맞춰 두면 오래 편합니다.

# 번호 대신 카드나 열쇠를 줄 수도 있습니다
도촌동 댁처럼 어르신이 계신 집은 카드를 늘리는 것이 오히려 관리가 어려울 수도 있습니다. / 몇 장을 누가 가졌는지 적어 두면 좋습니다.
아주 어린 아이는 번호를 외우는 것이 부담스럽습니다. / 카드키를 목걸이나 가방에 달아 주면 대고 열기만 하면 되어 쉽습니다.
다만 분실 위험이 있어, 잃어버리면 바로 그 카드를 지워야 합니다. / 지문 방식은 아이 손이 작아 인식이 잘 안 되는 경우도 있습니다.
어떤 방식이 맞는지는 [도어락 교체](doorlock-replace.html)를 고민하실 때 같이 따져 보세요.

# 신분 확인과 비용 안내
도촌동에서 출장 요청을 하시면 문을 열거나 도어락을 만지기 전에 사시는 분이 맞는지 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나로 먼저 확인합니다. / 세대 확인이 번거로우셔도 이웃을 위한 절차입니다.
비용은 시작 전에 먼저 말씀드리고 동의하시면 진행합니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 도촌동에서 번호 설정이 어려울 때
번호를 새로 등록하려면 먼저 관리자 번호나 등록 모드로 들어가야 하는 제품이 많습니다. / 이 단계에서 막히는 분이 가장 많습니다.
설명서를 잃어버렸거나 버튼 조합이 복잡하면 혼자 하기 어렵습니다. / 제품 이름이나 모양을 사진으로 알려주시면 방법을 안내해 드립니다.
직접 방문이 필요하면 가서 어르신 앞에서 번호를 등록하고 쓰는 법까지 함께 해 드립니다. / 방문해서 천천히 알려드리니 부담 갖지 않으셔도 됩니다.

# 도촌동 말고 성남 어디든 갑니다
도촌동 옆 상대원동, 금광동, 은행동, 야탑동과 서현·정자·판교 쪽도 다닙니다. / 성남 안이면 24시간 출동합니다.
동네는 [성남시 출장열쇠](seongnam.html)에, 다른 지역은 [출장 지역](area.html)에 있습니다.
