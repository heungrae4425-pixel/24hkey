# 도촌동으로 이사 오셨다면
이사 날은 짐을 옮기느라 정신이 없어 현관문 점검이 가장 뒤로 밀립니다. / 그래도 이사 당일이나 며칠 안에 한 번 정리해 두면 이후 몇 년이 편합니다. / 특히 이전 거주자의 흔적이 남을 수 있는 도어락과 열쇠는 가장 먼저 챙길 부분입니다.
도촌동은 수정구에서도 남쪽, 서울 쪽과 가까운 외곽 단지와 주택이 함께 있는 동네입니다. / 이사 후 정리할 것이 많아 현관문은 뒷전으로 밀리기 쉽습니다.
하지만 이사 직후가 도어락을 정리하기에 가장 좋은 때입니다. / 이전 입주자가 쓰던 번호와 열쇠가 남아 있을 수 있기 때문입니다.
@ 도촌동 이사 도어락 초기화 재설정

# 이사하면 꼭 확인할 세 가지
- 이전 입주자가 등록한 번호가 남아 있는지
- 카드키나 열쇠가 몇 개 나갔는지 모르는지
- 도어락 상태와 배터리가 괜찮은지
셋 중 하나라도 확신이 없으면 정리하는 것이 마음 편합니다. / 특히 열쇠는 몇 개가 어디 있는지 알기 어렵습니다.

# 초기화는 이렇게 합니다
많은 도어락은 안쪽 배터리 칸 근처에 초기화 버튼이 있습니다. / 이 버튼을 일정 시간 눌러 기존 번호를 지우고 새로 시작합니다.
제품마다 방식이 다르니 모양을 알려주시면 확인해 드립니다. / 무리하게 버튼을 누르거나 분해하지는 마세요.
초기화하면 이전 번호가 모두 지워지고 처음 설정 상태로 돌아갑니다.

# 새 번호를 정할 때
새 번호를 정하고 나면 가족 각자가 직접 한 번씩 열어 보세요. / 말로만 알려 주면 틀린 번호를 기억하는 일이 생깁니다. / 새 번호가 손에 익을 때까지 며칠은 시간이 걸린다는 점도 기억해 두세요.
이전 번호가 지워졌다면 바로 새 번호를 정해 두세요. / 생일이나 전화번호 뒷자리, 연속 숫자는 피하는 것이 좋습니다.
- 가족만 아는 조합으로 정하기
- 가능하면 길게 설정하기
- 바꾼 번호는 가족에게 안전하게 전달하기
- 몇 달에 한 번씩 변경하기
처음 정한 번호를 오래 쓰면 노출되기 쉽습니다.
@ 도촌동 도어락 새 번호 등록

# 열쇠가 남아 있다면
도어락은 바꿨는데 열쇠 구멍은 그대로인 경우가 있습니다. / 이전 입주자가 가진 열쇠로 열릴 수 있다는 뜻입니다.
불안하다면 열쇠 구멍 부분만 교체하거나, 도어락을 새로 설치하는 방법도 있습니다. / 상황에 맞게 상담해 드립니다.
열쇠 제작이 필요하면 [출장 열쇠](key-call.html)를 참고하세요.

# 카드키나 태그도 확인
이사하면서 카드키가 몇 개 있었는지 모르는 경우가 많습니다. / 이전 카드가 그대로 등록되어 있으면 정리가 필요합니다.
카드 등록 삭제와 신규 등록은 초기화와 함께 하면 한 번에 끝납니다. / 가족 카드는 다시 등록해 두세요.

# 도어락이 이상하다면
이사 직후 번호판이 안 켜지거나 소리가 이상하면 배터리부터 확인해 보세요. / 비어 있던 집에서는 배터리가 약해져 있는 일이 흔합니다.
배터리를 새것으로 바꿔도 같은 증상이면 점검이 필요합니다. / 자세한 것은 [도어락 수리](doorlock-repair.html)를 보세요.

# 교체가 나을 때
오래된 도어락이고 고장이 잦거나, 쓰고 싶은 기능이 있다면 이사를 계기로 바꾸는 것도 방법입니다. / 새로 설치하면 이전 흔적이 완전히 사라집니다.
문 규격은 사진으로 먼저 확인하면 좋습니다. / 선택 기준은 [도어락 교체](doorlock-replace.html)와 [도어락 설치](doorlock-install.html)를 참고하세요.

# 비용은 작업 전에 말씀드립니다
초기화나 번호 재설정만이면 간단하게 끝나는 경우가 많습니다. / 교체나 열쇠 구멍 작업이 필요하면 문을 보고 먼저 안내합니다.
동의하신 뒤에 시작하고, 추가 부품은 바꾸기 전에 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 사시는 분인지 확인합니다
이사 직후라 신분 확인이 번거로울 수 있습니다. / 임대차 계약서나 이사 확인 서류, 우편물 중 하나면 확인이 됩니다.
이웃과 집 주인을 지키기 위한 절차입니다. / 관리사무소 확인도 가능합니다.

# 작업 순서
도어락 상태를 확인하고 초기화 방법을 정합니다. / 새 번호와 카드를 등록하고 열고 닫기를 시험합니다.
열쇠 구멍은 별도로 점검하고 필요하면 조치합니다. / 마지막으로 가족과 같이 한 번씩 열어 보면 마무리됩니다.
@ 성남 출장열쇠 도촌동 이사 도어락 점검

# 이사 날 비어 있던 집 확인
오래 비어 있던 집은 습기와 먼지로 도어락이 약해져 있을 수 있습니다. / 번호판 기능, 모터 소리, 걸쇠 움직임을 확인하세요.
이상이 있으면 입주 전에 점검받으면 이사한 날 문 앞에서 고생하는 일이 줄어듭니다.

# 이사 후 정리 체크리스트
체크리스트를 현관 안쪽 메모로 붙여 두고 하나씩 지워 가면 빠뜨리는 일이 없습니다. / 정리가 끝난 날짜를 적어 두면 다음 점검 시기도 잊지 않습니다.
- 이전 번호 삭제와 새 번호 등록
- 카드와 열쇠 개수 확인
- 배터리 새것으로 교체
- 보조키 작동 확인
- 비상 전원 단자 위치 확인
이 다섯 가지만 해 두면 한동안 걱정이 없습니다.

# 자주 묻는 질문
? 이사 당일에도 부를 수 있나요? | 네, 24시간 전화를 받습니다.
? 이전 번호가 남아 있는지 어떻게 아나요? | 초기화하면 모두 지워집니다. 방법은 제품에 맞게 안내해 드립니다.
? 열쇠 구멍만 바꿀 수도 있나요? | 가능한 경우가 있습니다. 문을 보고 말씀드립니다.
? 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 사시는 분 확인은 어떻게 하나요? | 계약서, 우편물, 관리사무소 확인 중 하나면 됩니다.

# 도촌동 말고 성남 어디든
도촌동 옆 상대원동, 금광동, 은행동은 물론 분당, 판교, 위례까지 갑니다. / 성남 안이면 24시간 출동합니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 있고, 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
