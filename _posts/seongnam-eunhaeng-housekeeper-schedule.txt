# 은행동 맞벌이 가정, 도우미 번호는 어떻게 하시나요
은행동은 모란역 쪽으로 출퇴근하는 맞벌이 가정이 많은 생활권입니다. / 집을 비운 사이 가사도우미가 오는 요일이 정해져 있는 경우가 많습니다.
열쇠를 맡기던 시절과 달리 지금은 도어락 번호를 알려주는 방식이 일반적입니다. / 그런데 번호를 한 번 알려주고 그대로 두면 관리가 흐트러지기 쉽습니다.
이 글은 [성남 출장열쇠](seongnam.html)에 문의하시는 분들께 안내드리는 요일별 임시 번호 관리법입니다.
처음에는 믿고 맡긴다는 마음으로 번호를 알려주지만 시간이 지나면 걱정이 생기기 마련입니다. / 번호를 쓰는 방식을 미리 정해 두면 서로 마음이 편해집니다.
도우미 입장에서도 정해진 요일에만 들어가는 것이 오해를 막는 길입니다. / 관리 체계는 양쪽 모두에게 도움이 되는 약속입니다.
@ 은행동 가사도우미 방문 도어락 번호 입력

# 번호를 한 번 알려주고 그대로 두면 생기는 문제
번호가 오래 유지되면 누가 알고 있는지 잊게 됩니다. / 도우미가 바뀌어도 옛 번호가 남아 있습니다.
같은 번호를 가족과 도우미가 함께 쓰면 누가 언제 출입했는지 구분되지 않습니다. / 문제가 생겨도 확인할 방법이 없습니다.
번호를 종이에 적어 건네면 분실이나 노출 위험도 있습니다. / 되도록 말로 전달하고 기록은 남기지 않는 편이 낫습니다.

# 요일별로 번호를 나누는 기본 방식
도우미가 오는 요일에 맞춰 임시 번호를 등록하고 끝나면 지웁니다. / 이렇게 하면 방문하지 않는 날에는 번호가 열리지 않습니다.
- 방문 전날 저녁에 임시 번호 등록
- 방문 당일 일이 끝나면 번호 삭제
- 다음 방문 때 새로운 번호를 등록
- 카드나 태그를 쓰는 제품이면 카드만 따로 발급
매번 바꾸는 게 번거로우면 요일별로 번호를 두는 방법도 있습니다. / 월요일 번호, 목요일 번호처럼 나누는 식입니다.
도우미가 두 명 이상 번갈아 오는 집이라면 각자 번호를 따로 두는 것이 좋습니다. / 누가 언제 들어왔는지 알림으로 확인되는 제품이면 더욱 편합니다.
방문 시간이 정해져 있다면 시작 전과 끝난 뒤 가족에게 한 줄 연락을 받는 습관도 도움이 됩니다.

# 내 도어락에 임시 번호 기능이 있는지 확인
모든 도어락이 임시 번호를 지원하는 것은 아닙니다. / 제품 설명서에서 사용자 번호 등록, 일회용 번호, 기간 설정 메뉴가 있는지 보세요.
기간 설정이 되는 제품은 정해진 요일과 시간에만 열리게 할 수 있습니다. / 이런 제품은 관리가 훨씬 편합니다.
모델을 모르면 번호판 모양과 제조사 표시를 사진으로 찍어 두세요. / 전화로 말씀해 주시면 가능한 기능을 안내합니다.
@ 은행동 도어락 사용자 번호 등록 메뉴

# 도우미에게 번호를 알려줄 때 주의할 점
번호를 문자로 보내면 휴대폰에 그대로 남습니다. / 잠금 화면에 보이지 않게 하거나 말로 전달하는 것을 권합니다.
같이 사는 가족과 번호를 공유할 때는 변경 사실을 모두에게 알려야 합니다. / 가족이 모르고 옛 번호를 누르면 입력 잠금이 걸릴 수 있습니다.
도우미에게 건물 공동현관 번호도 함께 알려야 하는 경우가 있습니다. / 이 번호는 관리사무소 소관이라 별도로 확인하세요.
반려동물이 있는 집이라면 도우미가 들어올 때 문 앞으로 튀어나가지 않게 미리 안내해 두세요. / 문이 열리는 순간이 가장 위험합니다.
집 안 중요 물건은 도우미가 오기 전에 정리해 두는 것이 서로에게 편합니다.

# 도우미가 번호를 눌러도 문이 안 열릴 때
도우미 연락이 오면 먼저 번호를 정확히 눌렀는지 확인해 달라고 하세요. / 번호 끝에 별표나 샵을 눌러야 하는 제품도 있습니다.
번호판이 안 켜지면 배터리 문제일 수 있습니다. / 비상 전원 단자에 9V 건전지를 대는 방법을 알려 주면 도움이 됩니다.
이도 안 되면 억지로 시도하지 말고 전화 주세요. / 입력을 여러 번 틀리면 잠깐 막힙니다.

# 집에 아무도 없을 때 문이 안 열리는 경우
도우미만 집 앞에 있고 가족이 모두 외출 중일 수 있습니다. / 이런 경우는 사시는 분 확인이 어렵습니다.
출장을 요청하려면 집 주인이 전화로 상황을 알려 주고 신분 확인에 응해야 합니다. / 도우미 혼자서 요청하면 진행이 어려울 수 있습니다.
미리 연락 가능한 시간대를 도우미와 정해 두세요. / 급할 때 바로 닿을 수 있어야 합니다.

# 신분 확인은 집주인 기준으로 합니다
문을 열 때는 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
가사도우미가 요청하는 경우에는 집주인과 직접 통화로 확인하는 절차를 거칠 수 있습니다. / 번거롭지만 집과 가족을 지키기 위한 절차입니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 붙는 말 없는 비용도 없습니다.
부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
@ 은행동 도어락 임시 번호 삭제 작업

# 도우미 계약이 끝났을 때 하실 일
도우미가 바뀌거나 계약이 끝나면 그 사람이 알던 번호를 반드시 지우세요. / 카드나 태그를 줬다면 회수합니다.
번호를 알던 사람이 여러 명이었다면 전체 초기화도 고려해 볼 만합니다. / 이때는 [도어락 교체](doorlock-replace.html)까지 가지 않고 설정만으로 해결되는 경우가 많습니다.
오래된 제품이라 지우기가 어렵다면 [도어락 수리](doorlock-repair.html)로 먼저 점검합니다.

# 번호 관리를 편하게 하는 습관
- 방문 요일을 달력에 적고 번호 등록과 삭제를 함께 기록
- 한 달에 한 번 등록된 번호 목록 점검
- 배터리가 약해지면 경고음 전에 미리 교체
- 가족에게 번호 변경 사실을 바로 공유
작은 습관이 쌓이면 번호 걱정이 크게 줄어듭니다.

# 문을 열어야 할 때는 이렇게 진행합니다
번호를 잊었거나 오류가 났을 때 문 여는 방식은 도어락 상태에 따라 다릅니다. / 덜 상하는 방법부터 차례로 해 봅니다.
방식이 궁금하면 [현관문 개문](door-open.html) 페이지를 참고해 주세요.

# 은행동 말고 성남 어디든 갑니다
은행동 옆 금광동, 상대원동, 신흥동 쪽도 다닙니다. / 성남 안이면 24시간 출동하고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 임시 번호는 어떻게 만드나요? | 제품 설정 메뉴에서 등록합니다. 모델을 알려주시면 방법을 안내합니다.
? 도우미가 밖에서 못 들어올 때 열어 주나요? | 집주인과 통화 확인 후 진행합니다. 못 열면 비용은 받지 않습니다.
? 밤에도 전화해도 되나요? | 24시간 받습니다.
? 번호를 바꾸면 가족도 새로 외워야 하나요? | 임시 번호만 따로 쓰면 가족 번호는 그대로 둘 수 있습니다.

# 마무리
방문 요일이 바뀌거나 한동안 쉬게 될 때는 그 기간의 번호를 미리 지워 두세요. / 달력에 표시해 두면 잊지 않습니다. 작은 정리가 걱정을 크게 덜어 줍니다.
믿고 맡기는 일에도 정해 둔 약속과 기록이 있으면 서로 편합니다. / 임시 번호를 쓰는 습관은 한 번 익히면 어렵지 않습니다.
제품에 따라 등록 방법이 달라 헷갈린다면 번호판 사진을 보내 주세요. / 어떤 기능이 있는지부터 같이 확인해 드립니다.
도우미 번호 관리는 방문 전 등록, 방문 후 삭제만 기억하면 됩니다. / 막히면 번호판 상태부터 확인해 주세요.
