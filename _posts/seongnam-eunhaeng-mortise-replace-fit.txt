# 은행동 도어락 교체, 문 안쪽 부품부터 봐야 합니다
은행동은 모란역 생활권과 가까워 빌라와 주택, 상가가 섞여 있는 동네입니다. / 오래된 문이 많다 보니 도어락만 새것으로 바꾸려다 문 안쪽 부품이 맞지 않아 멈추는 일이 생깁니다.
새 도어락을 사 두었는데 설치가 안 된다는 연락이 의외로 자주 옵니다. / 대부분 문 안에 박혀 있는 매립형 부품, 즉 문 옆면 안쪽 몸통의 규격이 달라서입니다.
이 글은 은행동에서 도어락을 교체하기 전에 이 부품을 어떻게 확인하는지 풀어 쓴 글입니다.
@ 은행동 문 옆면 매립형 부품 규격 확인

# 매립형 부품이란 무엇인가
문 옆면을 보면 걸쇠가 나오는 금속판이 있습니다. / 이 판 뒤쪽 문 속에 박혀 있는 몸통이 매립형 부품이고, 도어락 안팎 손잡이가 이 몸통과 연결됩니다.
겉에서는 판만 보이기 때문에 속 규격을 알기 어렵습니다. / 그래서 같은 모양처럼 보여도 맞지 않는 제품이 생깁니다.
도어락을 떼면 이 부품은 문에 그대로 남아 새 제품과 만납니다. / 새 제품이 이 부품에 맞아야 설치가 끝납니다.

# 규격이 달라지는 대표적인 부분
- 몸통이 문 가장자리에서 손잡이 중심까지 떨어진 거리
- 문 옆면 판의 가로 폭과 모양
- 몸통의 두께와 안에 들어가는 깊이
- 손잡이 축이 지나가는 구멍의 모양
- 열쇠 실린더가 들어가는 자리
이 중 하나만 달라도 새 제품이 헛돌거나 문에 닿지 않습니다. / 특히 손잡이 중심까지의 거리는 눈으로 어림잡기 어려워 꼭 재야 합니다.

# 집에서 할 수 있는 간단한 확인
문 안쪽 부품은 겉에서 안 보이니, 보이는 단서를 모아 두는 것이 핵심입니다. / 단서가 많을수록 전화로도 어느 정도 가늠할 수 있습니다.
줄자로 문 두께를 먼저 재 보세요. / 그다음 문 옆면 판의 폭과 세로 길이를 재고, 사진을 정면과 옆면으로 찍어 두세요.
도어락 안쪽 커버를 열 수 있다면 몸통이 보이는 부분도 사진으로 남기면 좋습니다. / 손잡이가 한 방향으로만 달린 구조인지, 위아래로 따로 있는지도 같이 담아 주세요.
무리해서 분해하지는 마시고, 보이는 만큼만 찍으시면 충분합니다.
기존 도어락 뒷면에 제조사나 모델 이름이 적힌 스티커가 있다면 그것도 꼭 찍어 주세요. / 같은 모델이 나왔던 규격을 알면 비교가 훨씬 빨라집니다.

# 오래된 문일수록 변형이 있습니다
은행동에는 몇십 년 된 건물의 철문과 나무문이 함께 있습니다. / 문마다 안쪽 사정이 달라 같은 동네라도 맞는 제품이 제각각입니다.
은행동처럼 오래된 건물은 예전 방식의 몸통이 박혀 있을 수 있습니다. / 요즘 제품과 구멍 위치가 달라 가공이나 보강이 필요한 경우가 있습니다.
오래 쓴 문은 몸통 주변 목재나 철판이 닳아 구멍이 헐렁해지기도 합니다. / 그러면 새 도어락을 달아도 흔들려서 얼마 못 갑니다.
이런 상태는 열어 보기 전에는 알 수 없어서, 방문해서 직접 보고 말씀드립니다.

# 구입 전에 먼저 물어보세요
인터넷에서 싸게 보여도 규격이 맞지 않으면 쓸 수 없습니다. / 반품 배송과 재구매로 오히려 시간이 더 걸리는 경우를 자주 봅니다.
제품부터 사 오시기보다 사진과 치수를 먼저 보내 주세요. / 어떤 제품이 맞을지 같이 따져 보고 고르면 반품 걱정이 줄어듭니다.
이미 사 두셨다면 상자 옆면의 규격 표기를 사진으로 보내 주셔도 됩니다. / 맞지 않으면 어디가 다른지 정확히 알려드립니다.
고르는 법은 [도어락 교체](doorlock-replace.html) 안내에도 적어 두었습니다.

# 몸통을 바꿔야 하는 경우와 그대로 쓰는 경우
기존 몸통이 멀쩡하고 새 제품이 같은 규격이면 그대로 두고 도어락만 바꿉니다. / 이 편이 문에 손을 덜 대서 흔적이 적게 남습니다.
몸통 규격이 다르면 몸통까지 함께 바꾸는 방법이 있습니다. / 이때는 문 옆면 판 위치가 조금 달라질 수 있어 먼저 설명드립니다.
몸통이 녹슬거나 걸쇠가 뻑뻑하다면 이 기회에 같이 바꾸는 편이 낫습니다.
@ 은행동 기존 몸통 분리 후 새 제품 시험 장착

# 문에 구멍을 더 내야 하는 경우
구멍 가공은 한 번 하면 되돌릴 수 없는 작업입니다. / 그래서 치수를 두 번 확인하고 시작합니다.
새 제품이 기존 구멍보다 크면 문을 넓혀야 합니다. / 문 재질에 따라 가능한 경우와 어려운 경우가 갈립니다.
얇은 철문은 무리하게 넓히면 모양이 상할 수 있어 신중히 봅니다. / 가능하다고 판단되면 어떻게 할지 먼저 설명하고 동의를 받은 다음에 합니다.
어렵다면 규격이 맞는 다른 제품을 권해 드립니다.

# 작업 순서는 이렇게 진행됩니다
기존 도어락을 떼기 전에 작동 상태를 한 번 확인합니다. / 그다음 안팎 손잡이를 분리하고 몸통 상태와 구멍 치수를 확인합니다.
새 제품을 가볍게 대 보고 맞으면 고정한 뒤 배선과 동작을 시험합니다. / 마지막으로 번호 등록과 열쇠 동작까지 확인합니다.
설치 전 점검은 [도어락 설치](doorlock-install.html) 페이지에도 정리해 두었습니다.

# 작업 시작 전에 신분 확인을 합니다
교체 작업도 문의 주인이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
세입자라면 집주인에게 교체 가능 여부를 미리 물어 두시면 좋습니다. / 은행동 빌라는 공용 문과 세대 문이 섞인 곳도 있어 어느 문인지도 알려주세요.

# 비용은 시작 전에 먼저 말씀드립니다
치수를 확인한 뒤 어디까지 하면 되는지, 비용이 어떻게 되는지 문을 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문이 안 열려 부르신 경우 끝내 못 열면 비용은 받지 않습니다. / 작업 중에 부품이 더 필요하면 하기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 있습니다.

# 교체 뒤 꼭 해 보는 확인
설치가 끝났다고 바로 돌아가지 않고 문을 열고 닫기를 여러 번 반복해 봅니다. / 처음에는 잘 되다가 몇 번 지나 걸리는 경우를 미리 찾기 위해서입니다.
설치 후 문을 닫고 걸쇠가 문틀에 부드럽게 들어가는지 봅니다. / 안쪽에서 손잡이를 돌려 열어 보고, 바깥에서 번호로도 열어 봅니다.
열쇠가 있는 제품이면 열쇠로도 한 번 돌려 봅니다. / 비상 전원 단자가 있는지, 배터리는 새것인지도 같이 봅니다.
고장이 아니라 규격 문제로 오래 쓰던 제품에 손만 대는 경우라면 [도어락 수리](doorlock-repair.html)로 해결되는지도 따져 봅니다.
@ 은행동 교체 후 걸쇠 동작과 번호 등록 확인

# 은행동 말고 성남 어디든 갑니다
은행동 옆 금광동, 상대원동, 단대동, 신흥동과 서현·정자·야탑·판교 쪽도 다닙니다. / 성남 안이면 24시간 출동합니다.
동네는 [성남시 출장열쇠](seongnam.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
