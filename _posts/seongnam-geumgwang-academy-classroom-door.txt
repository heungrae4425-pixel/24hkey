# 금광동 학원가, 수업 전에 문이 안 열리면
금광동은 모란역 쪽 생활권에서 가깝고, 상가 건물에 학원과 교습소가 들어선 곳이 많습니다. / 수업 시작 전에 출입문이 안 열리면 학생들은 복도에 서 있고 원장님은 마음이 급해집니다.
학원 문은 가정집 현관과 달리 출입문, 강의실 문, 원장실 문이 따로 있고 쓰는 사람도 많습니다. / 그래서 문제가 생기는 지점도 다릅니다.
이 글은 [성남 출장열쇠](seongnam.html)에 연락 주시는 학원 관계자분들께 자주 안내드리는 순서를 정리한 것입니다.
학원은 정해진 시각에 정확히 문이 열려야 하는 곳이라 작은 고장도 하루 일정을 흔듭니다. / 그래서 평소 점검과 비상 대처를 미리 정해 두는 일이 중요합니다.
교습소처럼 규모가 작은 곳은 원장님이 혼자 모든 것을 맡는 경우가 많습니다. / 혼자 해결하기 어려울 때를 대비한 순서를 같이 적었습니다.
@ 금광동 학원 건물 출입문

# 학원 문은 가정집 문과 무엇이 다른가
출입이 하루에도 여러 번 이루어져 도어락이 빨리 닳습니다. / 번호 버튼 앞쪽이 먼저 마모돼 눌림이 둔해지는 경우가 많습니다.
번호를 아는 사람이 많아 변경 주기가 길어지는 점도 문제입니다. / 퇴사한 강사의 번호가 남아 있기도 합니다.
방음을 위해 문이 두껍고 무거운 경우도 많습니다. / 도어클로저 힘이 강해 닫힐 때 충격이 커 문틀 쪽 고장으로 이어집니다.

# 출입문이 안 열릴 때 먼저 볼 것
- 번호판 불이 들어오는지
- 번호를 누를 때 소리가 나는지
- 카드나 태그를 쓰는 곳이면 리더기 불이 켜지는지
- 손잡이를 돌릴 때 걸리는 느낌이 있는지
번호판이 꺼져 있으면 배터리부터 의심합니다. / 아래 비상 전원 단자에 9V 건전지를 대 보세요.
소리는 나는데 안 열린다면 모터나 걸쇠 쪽을 봐야 합니다. / 이때는 억지로 당기지 말고 상태를 알려 주세요.

# 강의실 문은 안에서 잠기는 경우가 많습니다
강의실 문은 안쪽 잠금 장치가 달린 경우가 있습니다. / 아이가 장난으로 잠그거나 문이 닫히며 걸쇠가 눌려 잠기는 일이 생깁니다.
안에 학생이 있는 상태에서 문이 안 열리면 안전이 먼저입니다. / 문 너머로 계속 말을 걸어 학생을 안심시키세요.
강의실 문이 안에서 잠겼을 때의 일반적인 원리는 [현관문 개문](door-open.html)과 비슷하지만 구조는 다를 수 있습니다. / 문 종류를 알려 주시면 맞는 방법을 정합니다.
방음문은 두껍고 문틈이 촘촘해서 안에서 소리가 잘 안 들립니다. / 학생이 문을 두드려도 밖에서는 못 들을 수 있으니 수시로 확인하세요.
강의실 안에 잠금장치가 있다면 수업 시작 전에 작동 방법을 강사에게 알려 두는 것이 좋습니다.
@ 금광동 강의실 문과 도어락

# 아이들이 있을 때 먼저 하실 일
학생이 안에 갇혔다면 먼저 괜찮은지 확인하세요. / 다친 곳이 없는지, 불안해하지 않는지 말로 확인합니다.
학부모 연락은 상황이 정리된 뒤에 하는 편이 낫습니다. / 일찍 알리면 걱정이 커질 수 있습니다.
문에 손잡이를 흔들거나 발로 차는 행동은 막아 주세요. / 아이들이 다칠 수 있고 문도 더 상합니다.

# 원장님이 번호를 관리하는 요령
학원은 번호를 아는 사람이 많으니 관리 체계가 필요합니다.
- 강사별로 번호를 따로 등록할 수 있는 제품인지 확인
- 퇴사 때 해당 번호를 바로 삭제
- 방학이나 학기 시작 때 전체 번호 점검
- 학부모에게는 번호를 알려주지 않기
번호를 한 가지로 계속 돌려 쓰면 누가 들어왔는지 알 수 없습니다. / 개인 번호나 카드키를 나눠 두면 관리가 훨씬 쉽습니다.
청소나 시설 관리 인력이 따로 들어오는 학원도 있습니다. / 이분들께도 정해진 요일과 시간에만 쓰는 번호를 따로 주는 편이 좋습니다.
번호를 바꿀 때는 강사 단체 대화방에 한 번 알리고, 이전 번호는 완전히 지웠는지 직접 눌러 확인하세요.

# 상가 건물 공용 출입문과 우리 학원 문의 구분
상가 건물은 공용 출입문과 호실 문이 따로 있습니다. / 공용 쪽은 건물 관리 주체의 동의가 있어야 작업할 수 있는 경우가 많습니다.
요청 때 어느 문인지 정확히 말씀해 주세요. / 호실 문이면 임차인이 요청할 수 있는 범위를 먼저 확인합니다.
임대인과 임차인 사이에서 도어락 교체나 번호 변경이 필요하면 서로 알리고 하는 것이 좋습니다. / 법적인 판단은 이 글에서 하지 않습니다.
@ 금광동 상가 건물 호실 출입문

# 신분 확인은 영업장에서도 합니다
영업장 문을 열 때는 사업장 관계자가 맞는지 확인합니다. / 사업자등록증 주소, 우편물, 건물 관리사무소 확인 중 하나면 됩니다.
신분증으로 본인 확인을 하고, 사업장이 맞는지는 서류나 관리인 확인으로 대신합니다. / 번거로울 수 있지만 영업장 보안을 위한 절차입니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 주세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 작업 후 말없이 붙는 비용도 없습니다.
부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 수업 시간대를 피해 점검하는 방법
출입이 많은 학원은 수업 중 점검이 어렵습니다. / 수업 시작 전이나 종료 후에 시간을 잡으면 방해가 적습니다.
오래 쓴 도어락은 [도어락 수리](doorlock-repair.html)로 먼저 점검하고, 너무 낡았으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 교체 일정은 학원 운영에 맞춰 조정할 수 있습니다.

# 개학, 방학 때 미리 점검할 것
방학이 끝나고 학기가 시작되기 전에 출입문과 강의실 문을 한 번 점검해 보세요. / 배터리 상태와 도어클로저 속도를 같이 보면 좋습니다.
문이 너무 세게 닫히면 아이들 손이 낄 수 있습니다. / 속도를 조절해 두는 것이 안전합니다.
복도 쪽으로 열리는 문이라면 지나가던 학생과 부딪치지 않는지도 살펴보세요. / 문 위치와 열리는 방향은 설치 때 놓치기 쉬운 부분입니다.

# 금광동 말고 성남 어디든 갑니다
금광동 옆 은행동, 상대원동, 단대동 쪽도 다닙니다. / 성남 안이면 24시간 출동하고, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.

문 하나가 막히면 수업 전체가 늦어지니 평소 비상 연락처와 대처 순서를 강사들과 공유해 두세요. / 출입문 번호판 상태, 배터리 교체 날짜, 강의실 문 잠금 방식을 한 장에 적어 두면 누구든 당황하지 않습니다.
