# 문이 열렸다고 끝이 아닙니다
금광동은 중원구에 있고 주택가와 빌라, 상가가 이어진 동네입니다. / 오래 사신 집이 많아 도어락과 문틀도 세월이 쌓인 경우가 많습니다.
문이 열리면 안도감에 바로 들어가 쉬고 싶으시겠지만, 그날 몇 가지만 확인해 두면 같은 일이 다시 생기는 것을 많이 막을 수 있습니다. / 이 글은 문을 연 직후에 점검할 것을 순서대로 정리했습니다.
지금 문이 막 열린 상태라면 1번부터 따라와 주세요. / 아직 문 앞이라면 [성남 출장열쇠](seongnam.html)로 먼저 연락 주세요.
@ 금광동 출장열쇠 24시간 개문 후 점검

# 먼저 문이 왜 안 열렸는지 확인
같은 일이 반복되지 않으려면 원인을 알아야 합니다. / 문이 안 열린 이유는 대개 몇 가지로 나뉩니다.
- 도어락 배터리가 다 되어 번호판이 꺼진 경우
- 비밀번호를 잊었거나 바뀐 걸 모르는 경우
- 걸쇠나 보조키가 걸려 있었던 경우
- 도어락 안쪽 부품이 고장 난 경우
- 문틀이 처져서 걸쇠가 걸린 경우
원인에 따라 해야 할 점검이 다릅니다. / 열어준 사람에게 원인이 무엇이었는지 꼭 물어보세요.

# 배터리부터 전부 새것으로
배터리가 원인이었다면 하나만 바꾸지 말고 전부 한꺼번에 바꿔 주세요. / 섞어서 쓰면 며칠 안에 같은 일이 다시 생깁니다.
배터리가 원인이 아니었더라도 이번 기회에 바꿔 두면 마음이 편합니다. / 바꾼 날짜를 배터리 칸 안쪽에 적어 두세요.
경고음이 나기 시작하면 미루지 말고 그날 바로 바꾸는 것이 좋습니다. / 비상용 9V 건전지 하나를 따로 보관해 두는 것도 방법입니다.
금광동처럼 골목 안쪽 집이 많은 곳은 밤에 편의점까지 가는 길이 멀 수 있어서 집 안에 여분 건전지를 두는 것이 특히 도움이 됩니다. / 건전지는 새것을 습기가 없는 서랍에 넣어 두고 해마다 한 번 확인해 주세요.
@ 금광동 도어락 배터리 교체 점검

# 열리고 잠기는지 몇 번 시험
문이 열렸다면 바로 닫고 번호를 눌러 열리는지 확인해 보세요. / 안쪽에서 잠그고 바깥에서 여는 동작을 두세 번 반복합니다.
한 번에 잘 열리고 잠기는지, 걸리거나 늦게 반응하지 않는지 봅니다. / 열쇠구멍이 있는 제품은 열쇠로도 한 번 열어 봅니다.
출장 온 분이 보는 앞에서 같이 확인해 두면 이상이 있을 때 바로 말씀드릴 수 있습니다. / 확인이 끝나기 전에 보내지 마시고 같이 보세요.

# 비밀번호는 이번에 정리
비밀번호를 잊어서 연 경우에는 새 번호를 등록하는 것까지 같이 합니다. / 기존 번호는 지우고 새 번호만 남겨 두는 것이 좋습니다.
평소에 쓰는 번호가 너무 단순하거나 가족 생일이면 이번 기회에 바꾸는 것을 권합니다. / 가족과 번호를 같이 정하고, 바뀐 걸 모두에게 알려 주세요.
번호를 적어 둘 때는 도어락 근처나 현관에 두지 마세요. / 휴대폰 메모에 이름을 숨겨서 저장하는 방법이 있습니다.

# 카드키와 여분 열쇠 챙기기
카드키나 태그를 쓰는 제품은 몇 개가 등록되어 있는지 확인합니다. / 잃어버린 카드가 있다면 이번에 지우고 새로 등록해 두세요.
여분 열쇠는 집 안이 아닌 믿을 수 있는 곳에 따로 두면 문이 잠겼을 때 도움이 됩니다. / 문 앞 화분이나 우편함 속은 위험하니 피해 주세요.
- 등록된 카드와 태그 개수 확인
- 잃어버린 카드 삭제
- 여분 열쇠 보관 장소 정하기
- 가족에게 보관 장소 알리기
여분 열쇠를 두는 곳은 가족이 아닌 사람이 쉽게 짐작할 수 없는 곳이어야 합니다. / 가까운 친척이나 믿을 수 있는 이웃에게 맡겨 두는 방법이 가장 안전합니다.
카드키는 지갑 속에 같이 넣어 두면 지갑을 잃어버릴 때 함께 사라집니다. / 집 열쇠와 카드가 한 곳에 있다는 것을 다른 사람이 알 수 없게 분리해서 보관해 주세요.

# 문틀과 경첩도 한번 보기
도어락은 멀쩡한데 문틀이 처져서 안 열리는 경우도 있습니다. / 오래된 집이 많은 금광동 같은 곳에서는 특히 문틀과 경첩 상태가 중요합니다.
문을 천천히 닫아 보면서 끝까지 닫히는지, 걸리는 소리가 나는지 보세요. / 문이 툭 걸리거나 덜 닫히면 경첩부터 점검해야 합니다.
경첩 나사가 풀려 있으면 조이는 것만으로 좋아지기도 합니다. / 심하게 처졌다면 [도어락 수리](doorlock-repair.html) 상담을 받아 보세요.
@ 금광동 문틀 경첩 점검

# 고칠지 바꿀지는 서두르지 마세요
문을 열고 난 뒤 교체를 권하는 곳이 있어 부담스러워하시는 분이 많습니다. / 저희는 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.
같은 증상이 반복되거나 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 그 자리에서 결정하지 않으셔도 되고, 생각해 보고 연락 주셔도 됩니다.
교체를 하게 되면 비용은 작업 전에 먼저 안내합니다. / 마음에 안 드시면 그냥 두셔도 됩니다.

# 가족과 이웃에게도 알려두기
이번 일을 가족에게 알려서 같은 상황에서 어떻게 할지 함께 정해 두세요. / 누가 먼저 확인하고 누구에게 연락할지 정해 두면 다음에는 훨씬 빨리 해결됩니다.
고령의 부모님이나 아이가 혼자 있는 집이라면 더 중요합니다. / 비상 연락처를 현관 안쪽에 붙여 두는 것도 좋은 방법입니다.
관리사무소 번호도 휴대폰에 저장해 두면 늦은 시간에 도움이 됩니다. / 열쇠집 번호도 같이 저장해 두세요.

# 다음 점검 날짜 정하기
점검은 한 번 하고 끝이 아니라 주기를 정해 두는 것이 좋습니다. / 배터리는 해가 바뀔 때쯤 한 번에 전부 교체하는 습관을 들이면 편합니다.
- 해가 바뀔 때 배터리 전부 교체
- 장마철과 겨울 전에 번호판 닦고 점검
- 반년에 한 번 열리고 잠기는 시험
- 경고음이 나면 그날 바로 조치
휴대폰 달력에 점검 날을 적어 두면 잊지 않습니다. / 작은 습관이 다음 번 비상 상황을 줄여 줍니다.

# 이럴 때는 다시 연락 주세요
열고 난 뒤에도 이상한 소리가 나거나 잠금이 한 번에 안 되면 미루지 마세요. / 완전히 멈추기 전에 손보면 비용도 덜 듭니다.
같은 증상이 며칠 안에 다시 생기면 원인이 다른 곳에 있을 수 있습니다. / 그때는 사진과 함께 증상을 알려주세요.
열어 드린 작업에 대해 궁금한 점이 있으면 언제든 물어보셔도 됩니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 금광동 말고 성남 어디든 갑니다
금광동 옆 은행동, 상대원동, 도촌동, 신흥동도 다닙니다. / 성남 안이면 동네 상관없이 24시간 출동합니다.
성남에서 다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
문을 여는 방법이 궁금하시면 [현관문 개문](door-open.html) 페이지를 보세요. / 개문 전에 비용부터 말씀드리고, 못 열면 비용은 받지 않습니다.
