# 현관문만 문이 아닙니다
금광동 오래된 집에서는 현관문보다 베란다 문이나 방문 잠금이 먼저 말썽을 부리는 일이 있습니다. / 평소에 잘 안 쓰던 문이 급할 때 갑자기 안 열리면 더 당황스럽습니다.
이 글은 베란다 문, 미닫이 문, 방문에 달린 잠금장치가 안 잠기거나 안 열릴 때 확인할 것을 적었습니다. / 현관문과는 구조가 달라서 원인도 다르게 봐야 합니다.
혼자 해볼 수 있는 것과 [성남 출장열쇠](seongnam.html)를 부르는 편이 나은 경우를 나눠 두었습니다. / 문을 억지로 당기기 전에 먼저 읽어 보세요.
@ 금광동 출장열쇠 베란다 미닫이 잠금장치

# 베란다 문 잠금은 어떻게 생겼나
베란다 문은 보통 안쪽 손잡이를 돌려 잠그거나 위아래에 걸림 장치가 달린 구조입니다. / 현관문 도어락처럼 전기를 쓰는 경우는 드물어서 배터리 문제는 거의 없습니다.
대신 오래 쓰면 걸림 장치 안쪽 부품이 마모되거나 먼지가 껴서 움직임이 뻑뻑해집니다. / 이때 힘을 세게 주면 손잡이 축이 휘거나 부러질 수 있습니다.
창틀이 처져서 걸림 장치가 맞물리는 위치가 어긋나는 경우도 있습니다. / 문을 살짝 들어 올리면서 돌리면 열리는 집이 있는 이유입니다.

# 안 잠기는 경우 먼저 볼 것
잠금 걸림쇠가 홈에 들어가지 않으면 문이 완전히 닫혔는지 먼저 확인합니다. / 문이 반쯤 걸려 있으면 걸림쇠가 홈과 어긋나 잠기지 않습니다.
창틀 아래 레일에 이물질이 끼어 문이 끝까지 밀리지 않는 경우도 많습니다. / 레일을 닦고 마른 천으로 훔친 뒤 다시 닫아 보세요.
그래도 안 잠기면 손잡이를 돌릴 때 느낌이 헐겁지는 않은지 봅니다. / 손잡이가 헛돌면 안쪽 부품이 빠졌을 가능성이 있습니다.

# 안 열리는 경우 먼저 볼 것
안에서 잠근 채로 문이 안 열릴 때는 손잡이를 끝까지 돌렸는지 확인합니다. / 반만 돌린 상태에서는 걸림쇠가 빠지지 않습니다.
문을 안쪽으로 살짝 밀면서 손잡이를 돌리면 걸림이 풀리는 경우가 있습니다. / 이 방법이 안 되면 세게 당기지 말고 멈추세요.
창틀 고무 패킹이 눌려 붙어 있는 경우도 있습니다. / 장마철에는 특히 문이 틀에 달라붙어 열리지 않는 일이 생깁니다.
@ 성남 금광동 미닫이문 방문 잠금 열쇠집

# 미닫이문은 어디가 문제일까
미닫이문은 문틀 위아래 레일과 바퀴로 움직이는 구조입니다. / 바퀴가 마모되거나 레일이 휘면 문이 끝까지 안 가고 중간에 걸립니다.
잠금장치는 보통 문 옆면 갈고리가 반대편 문틀 홈에 걸리는 방식입니다. / 문이 조금만 어긋나도 갈고리가 홈에 안 들어갑니다.
잠금이 안 풀리는 경우는 갈고리 안쪽 스프링이 굳었을 때가 많습니다. / 이 부분은 억지로 흔들면 오히려 부러질 수 있으니 조심하세요.

# 방문 잠금이 안에서 잠긴 경우
방문은 손잡이 가운데 작은 버튼을 눌러 잠그는 구조가 흔합니다. / 밖에서는 가는 막대나 작은 홈으로 열 수 있게 만든 것도 있습니다.
아이가 안에서 잠그고 나오지 못하는 일이 가장 걱정스럽습니다. / 문 너머로 계속 말을 걸어 아이를 안심시키고, 바로 연락 주세요.
방문 잠금은 현관문보다 구조가 단순해서 상하지 않게 여는 방법이 있는 경우가 많습니다. / 도착해서 문 종류를 보고 가장 덜 상하는 방법부터 시도합니다.

# 혼자 해보지 않는 것이 좋은 경우
손잡이를 세게 비틀거나 망치로 두드리는 것은 피해 주세요. / 문과 잠금장치가 상하면 열쇠집을 부르는 것보다 일이 커집니다.
드라이버로 잠금 부분을 억지로 뜯는 것도 권하지 않습니다. / 나사를 풀다 부품이 흩어져 다시 조립하기 어려워집니다.
유리가 들어 있는 베란다 문은 특히 조심해야 합니다. / 힘을 주다 유리가 깨지면 안전 문제로 이어질 수 있습니다.

# 전화하실 때 알려주면 좋은 것
어느 문인지(베란다, 미닫이, 방문 중 무엇인지)와 안에 사람이나 반려동물이 있는지를 먼저 알려주세요. / 손잡이 모양이나 잠금 버튼 위치를 사진으로 보내주시면 챙겨 갈 장비를 고르기 좋습니다.
동 이름과 건물 형태(주택, 빌라, 아파트)를 알려주시면 도착 시간을 더 정확히 말씀드릴 수 있습니다. / 주차할 곳이 마땅치 않으면 그것도 같이 알려주세요.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 신분증이나 주소가 적힌 우편물로 먼저 확인합니다. / 어렵다면 관리사무소나 경비실 확인으로도 가능합니다.
방문 잠금처럼 집 안쪽 문일 때도 같은 절차를 지킵니다. / 이웃과 거주자를 모두 지키기 위한 절차이니 미리 챙겨 두시면 좋습니다.
확인이 끝나면 문 상태를 보고 얼마가 드는지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 못 열면 비용은 받지 않습니다.

# 열고 난 뒤 같이 점검합니다
문이 열리면 잠금과 열림이 한 번에 잘 되는지 몇 번 시험합니다. / 부품이 닳아 자꾸 걸리는 것 같으면 그 이유를 설명드립니다.
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)처럼 부품만 손보는 쪽으로 권해드립니다. / 새로 바꿔야 할 정도로 오래되었으면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
작업 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 현관문이 아닌 문도 같은 원칙으로 최대한 안 상하게 엽니다.

# 문 잠금장치 오래 쓰는 관리법
레일과 걸림 부분은 마른 천으로 가끔 닦아 먼지가 쌓이지 않게 합니다. / 기름을 너무 많이 바르면 먼지가 더 붙으니 조금만 쓰세요.
문을 닫을 때 세게 닫지 않는 습관만으로도 부품 수명이 길어집니다. / 장마철에는 문이 틀에 달라붙지 않는지 한 번씩 열어 보세요.
잠금 소리가 평소와 다르거나 손잡이가 헐거워지면 그날 바로 손보는 것이 좋습니다. / 완전히 고장 나기 전에 손보면 일이 훨씬 작아집니다.
@ 금광동 24시 출장열쇠 문 잠금 점검

# 금광동 말고 성남 어디든 갑니다
금광동과 가까운 은행동, 상대원동, 단대동, 신흥동도 다닙니다. / 성남 안이면 동네와 상관없이 24시간 출동합니다.
성남에서 다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다. / 서울과 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
