# 이 소리가 무슨 뜻인지 모르겠을 때
밤에 갑자기 도어락이 삐삐 하고 울리면 가족이 모두 놀라 일어납니다. / 모란역 쪽 생활권인 금광동에서도 도어락 소리 때문에 문의하는 분들이 계십니다.
소리가 길게 한 번인지, 짧게 여러 번인지, 멈췄다 반복되는지에 따라 의미가 달라지기도 합니다. / 이 글은 소리 패턴으로 원인을 가늠하는 요령과 연락하실 때의 순서를 정리했습니다.
먼저 알려 드릴 점은, 소리의 뜻이 제품마다 다르다는 것입니다. / 정확한 뜻은 사용 설명서가 기준이고, 아래는 일반적으로 많이 있는 경향입니다.
@ 금광동 도어락 경고음 소리 구분

# 제품마다 소리 규칙이 다릅니다
같은 짧은 삐 소리가 어떤 제품에서는 입력 확인음이고 다른 제품에서는 배터리 부족 안내입니다. / 그래서 한 가지 소리로 원인을 단정하기보다 여러 상황을 함께 보셔야 합니다.
제품 뒷면이나 안쪽 덮개에 모델명이 적힌 경우가 많습니다. / 모델명을 알면 설명서 내용을 찾아보기가 한결 쉬워집니다.
모델명을 알려 주시면 전화로 먼저 일반적인 경우를 안내해 드릴 수 있습니다. / 모르시면 사진으로 보내 주셔도 됩니다.

# 짧은 소리가 여러 번 반복될 때
버튼을 눌렀을 때 나는 짧은 소리는 대개 입력이 들어갔다는 확인음입니다. / 문제는 누르지 않았는데도 짧은 소리가 반복되는 경우입니다.
이때는 배터리 부족 경고일 수 있어서 먼저 안쪽 배터리 상태를 확인하세요. / 새것으로 전부 교체한 뒤에도 같은 소리가 나면 다른 원인을 찾아봐야 합니다.
습기가 번호판에 맺혀 스스로 버튼이 눌린 것처럼 인식되기도 합니다. / 마른 수건으로 번호판을 닦고 잠시 지켜본 뒤에 다시 확인해 보세요.

# 길게 한 번 또는 길게 이어지는 소리
길게 울리는 소리는 보통 오류나 잠금 상태를 알리는 경우가 많습니다. / 비밀번호를 연속으로 여러 번 틀렸을 때 도어락이 한동안 입력을 막으면서 길게 소리를 내기도 합니다.
이 경우는 잠시 기다린 뒤 다시 입력하면 풀리는 경우가 많습니다. / 급하다고 계속 누르면 막힌 시간이 더 늘어날 수 있으니 멈추세요.
문을 닫았는데 길게 소리가 난다면 걸쇠나 닫힘 감지 쪽 문제일 수 있습니다. / 이 경우는 문이 제대로 닫혔는지 먼저 확인해 보세요.

# 소리가 나면서 모터 소리만 들릴 때
번호를 누르면 윙 하고 모터 소리는 나는데 문이 안 열리는 경우가 있습니다. / 내부 부품이 마모되었거나 걸쇠가 문틀에 눌려 빠지지 않는 상황일 수 있습니다.
이럴 때 손잡이를 세게 돌리면 부품이 더 상하니 힘을 주지 마세요. / 문을 살짝 안쪽으로 밀면서 열어 보는 정도만 해보시길 권합니다.
안쪽에서 열어도 같은 증상이라면 도어락 내부 점검이 필요한 상태입니다. / 오래 두면 어느 날 완전히 안 열리는 일이 생길 수 있습니다.

# 배터리 때문에 나는 소리 해결하기
배터리 부족 경고는 가장 흔한 원인이라 먼저 점검해 볼 만합니다. / 건전지는 칸에 든 것을 전부 새것으로 바꿔 주세요.
- 일부만 바꾸면 전압이 고르지 않아 경고가 계속될 수 있음
- 오래된 건전지와 새 건전지를 섞지 않기
- 건전지 접점에 먼지나 부식이 없는지 확인
- 교체한 날짜를 배터리 칸에 적어 두기
교체 후 소리가 사라지면 그대로 쓰시면 됩니다. / 사라지지 않으면 다른 원인으로 넘어가 확인합니다.
@ 도어락 배터리 교체 후 경고음 확인

# 소리가 계속될 때 일단 끄는 방법
밤에 경고음이 멈추지 않으면 건전지를 빼서 소리를 멈추는 것도 일시적인 방법입니다. / 다만 건전지를 뺀 상태에서는 문이 잠긴 채로 번호 입력이 안 될 수 있어서 반드시 문 안에 계실 때만 하세요.
집 밖에 있는 상황에서는 건전지를 빼지 마세요. / 문 앞에서 열리지 않는 사태로 이어질 수 있습니다.
소리가 멈추면 날이 밝은 뒤 점검받으시면 됩니다. / 그날 바로 해결이 필요하면 24시간 연락 주세요.

밤에 아무 때나 울리고 사람이 누르지 않았는데도 소리가 나면 오작동을 의심합니다. / 습기, 정전기, 센서 오인식 등이 이유일 수 있습니다.
오작동은 환경을 개선하면 사라지기도 하지만 부품 노후로 생긴 경우는 점검이 필요합니다. / 증상이 계속 반복되면 고장 쪽에 가깝습니다.
고장이 의심되면 일단 문이 열리는지부터 확인하고 연락 주세요. / 열리지 않는 상황이면 시간이 곧 중요한 문제입니다.

# 금광동에서 연락하실 때 알려 주실 내용
금광동은 주택과 상가가 이어진 곳이 많아 건물과 호수를 정확히 알려 주셔야 합니다. / 가까운 모란역 쪽에서 어느 방향인지도 알려 주시면 도움이 됩니다.
- 건물 종류와 호수
- 소리의 모양(짧게 반복, 길게 한 번 등)
- 소리가 나는 순간(문 열 때, 닫을 때, 아무 때나)
- 배터리를 최근 교체했는지
- 문이 지금 열리는 상태인지 아닌지
짧게라도 소리를 녹음해서 보내 주시면 제품 상태를 이해하는 데 큰 도움이 됩니다. / 가능하면 도어락 사진도 같이 부탁드립니다.

# 도착하면 거주자 확인을 먼저 합니다
점검이라도 집에 들어가는 일이라 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
이 절차는 모든 분께 똑같이 하는 것입니다. / 확인이 어려우면 작업을 진행하지 못하니 미리 준비해 주세요.

# 점검과 비용 안내 방식
소리 원인을 확인하고, 어떤 작업이 필요한지 설명드립니다. / 작업에 들어가기 전에 비용을 먼저 말씀드리고 동의하시면 시작합니다.
문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙니다.
진행 방식은 [이용안내](guide.html)에 자세히 적어 두었습니다. / 문이 안 열린 상태라면 [현관문 개문](door-open.html)도 참고하세요.
@ 금광동 출장열쇠 도어락 소리 점검

# 고쳐서 쓸 수 있으면 교체하지 않습니다
소리 문제의 상당수는 배터리나 습기, 센서 위치 조정으로 정리됩니다. / 이런 경우 새 제품이 필요한 것이 아닙니다.
부품 마모가 원인이면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 정말 오래되어 고장이 잦을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
교체가 필요한 상황이라도 작업 전에 이유와 방법을 먼저 설명합니다. / 동의하지 않으시면 하지 않습니다.

# 도어락 소리를 편안하게 쓰는 관리법
- 해가 바뀔 때쯤 배터리 전부 교체
- 비 오는 날 번호판 물기 닦기
- 소리가 평소와 다르면 미루지 말고 점검
- 설명서나 모델명 사진을 휴대폰에 저장
- 소리 크기를 줄이는 설정이 있다면 가족과 같이 확인
소리가 너무 크게 느껴지면 음량 설정을 바꾸는 방법이 제품에 있을 수 있습니다. / 다만 경고음까지 끄면 중요한 알림을 놓칠 수 있으니 주의하세요.

# 금광동 말고 성남 어디든 갑니다
금광동 바로 옆 은행동, 상대원동, 신흥동, 태평동, 단대동은 물론 성남 전 지역에 24시간 출동합니다. / 다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다.
다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 동네 상관없이 편하게 연락 주세요.
