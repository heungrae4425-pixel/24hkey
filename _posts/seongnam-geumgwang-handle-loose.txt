# 금광동 현관 손잡이가 헐겁게 돌아간다면
금광동 주택가와 빌라, 오래된 아파트는 현관문 손잡이를 오래 쓰는 집이 많습니다. / 어느 날 손잡이가 덜렁거리거나, 돌려도 힘없이 헛돌기 시작합니다.
손잡이가 헛돈다는 것은 손잡이와 안쪽 걸쇠를 이어 주는 부분이 느슨해졌다는 뜻입니다. / 방치하면 어느 날 갑자기 문이 안 열리는 상황으로 이어질 수 있습니다.
이 글은 금광동에서 손잡이가 헐겁거나 헛돌 때 확인할 순서와 직접 해볼 수 있는 점검, 불러야 하는 경우를 정리했습니다. / 금광동 [성남 출장열쇠](seongnam.html)를 찾는 분들이 가장 자주 묻는 증상 중 하나입니다.
@ 금광동 출장열쇠 손잡이 헛돔 점검

# 증상을 세 가지로 나눠 보세요
같은 헐거움이라도 모양에 따라 원인이 다릅니다. / 어떤 쪽인지 먼저 구분해 보세요.
- 손잡이가 위아래로 덜렁거리는 경우: 고정 나사가 풀림
- 돌려도 힘없이 헛돌기만 하는 경우: 손잡이 축이나 걸쇠 연결부 파손
- 돌아가긴 하는데 걸쇠가 덜 빠지는 경우: 내부 스프링이나 걸쇠 마모
위아래로 덜렁거린다면 가장 간단한 경우이고, 헛돌기만 한다면 안쪽이 이미 상한 상태일 수 있습니다. / 이 구분이 전화 통화에서 큰 도움이 됩니다.

# 고정 나사가 풀린 경우
손잡이가 덜렁거리면 안쪽 나사가 풀렸을 확률이 높습니다. / 손잡이 아래나 옆에 작은 나사 구멍이 보이거나, 손잡이 받침이 돌아가는 형태라면 조여 볼 수 있습니다.
조일 때는 너무 세게 돌리지 말고 가볍게 조이는 정도로만 하세요. / 나사를 끝까지 세게 조이면 안쪽 부품이 눌려 손잡이가 안 돌아가기도 합니다.
조인 뒤에도 곧 다시 헐거워진다면 나사 구멍이 닳아서 나사가 못 버티는 것입니다. / 이 경우는 나사만으로 해결되지 않아 부품을 손봐야 합니다.

# 헛돌기만 하는 경우는 멈추세요
손잡이를 돌려도 걸쇠가 안 움직이고 힘없이 돌기만 한다면 안쪽 연결이 끊어진 것입니다. / 이때 계속 돌려 보시는 것은 도움이 안 되고 부품 상태를 더 나쁘게 합니다.
손잡이를 눌러도 반응이 없다면 도어락이 열림 신호를 줘도 문이 안 열릴 수 있습니다. / 이 상태에서는 문 안으로 못 들어가거나, 안에 있다가 못 나가는 일이 생길 수 있습니다.
문 안쪽에 있을 때 손잡이가 헛돌면 문을 못 열고 갇히는 경우도 있습니다. / 그런 상황이라면 바로 전화해 주세요.
@ 금광동 현관문 손잡이 걸쇠 연결부 수리

# 오래된 주택에서 자주 생기는 이유
금광동 주택가 현관문은 20~30년 넘게 한 번도 안 바꾼 곳이 많습니다. / 그만큼 손잡이를 돌린 횟수도 엄청나서 안쪽이 닳습니다.
손잡이를 세게 당기며 여는 습관이 있으면 연결부가 더 빨리 상합니다. / 문을 열 때 힘으로 돌리기보다 가볍게 돌려 쓰는 것이 오래갑니다.
무거운 가방이나 봉투를 손잡이에 걸어 두는 습관도 영향을 줍니다. / 손잡이 축에 계속 하중이 걸리면 연결부가 휘어집니다.

# 직접 해보기 전에 알아 둘 것
손잡이를 분해해 보려는 분들이 있습니다. / 모양이 비슷해 보여도 도어락마다 구조가 달라 분해했다가 다시 못 맞추는 경우가 많습니다.
나사만 풀어 보려다가 손잡이 안쪽 스프링이 튀어나오는 사고도 있습니다. / 작은 부품은 잃어버리면 구하기도 어렵습니다.
어디까지 직접 하셔도 괜찮은지 기준을 정해 두시면 좋습니다. / 눈에 보이는 나사를 가볍게 조이는 것까지만 하시고, 그 이상은 맡기시는 편이 낫습니다.

# 전화하실 때 알려주세요
손잡이 상태를 정확히 말씀해 주시면 맞는 부품을 챙겨 갈 수 있습니다. / 사진을 같이 보내주시면 훨씬 정확합니다.
- 손잡이 모양(막대형, 둥근 손잡이형 등)
- 어떤 증상(덜렁거림, 헛돎, 걸쇠가 덜 빠짐)
- 문 안쪽에서 열 때와 바깥에서 열 때가 같은지
- 도어락이 같이 달려 있는지
- 건물 종류와 금광동 위치
손잡이 앞뒤를 가까이서 찍은 사진 두 장이면 충분합니다. / 부품을 구하기 어려운 모양이면 미리 말씀드립니다.

# 도착하면 이렇게 진행합니다
먼저 손잡이를 돌려 보며 어디서 힘이 빠지는지 확인합니다. / 안쪽 연결부를 열어 상태를 보고 나서 수리할지 교체할지 말씀드립니다.
고쳐서 쓸 수 있으면 부품만 바꾸는 쪽을 먼저 권합니다. / 손잡이 전체를 새로 바꾸는 것은 꼭 필요할 때만 말씀드립니다.
작업 방법과 비용은 시작 전에 말씀드리고, 괜찮다고 하시면 진행합니다. / 마음에 안 드시면 그대로 돌아갑니다.
[도어락 수리](doorlock-repair.html) 페이지에 수리가 가능한 경우를 적어 두었습니다. / 교체가 필요한 경우는 [도어락 교체](doorlock-replace.html)에서 보실 수 있습니다.

# 이미 문이 안 열리는 상태라면
손잡이가 완전히 헛돌아서 문이 안 열리는 상황이라면 먼저 문부터 열어야 합니다. / 이럴 때는 [현관문 개문](door-open.html)과 수리를 이어서 진행합니다.
문을 열 때는 최대한 도어락과 문이 상하지 않는 방법부터 씁니다. / 부품이 손상된 상태라 방법을 고르는 것이 조심스럽습니다.
안에 사람이 갇혀 있다면 가장 먼저 말씀해 주세요. / 침착하게 문 너머로 계속 말을 걸어 주시면 안심이 됩니다.

# 신분 확인은 꼭 합니다
문을 열거나 도어락을 만지는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
세입자이거나 부모님 댁에 대신 오신 경우라면 미리 말씀해 주세요. / 상황에 맞게 확인 방법을 안내해 드립니다.
전체 진행 순서는 [이용안내](guide.html)에 적어 두었습니다. / 처음 부르시는 분들이 한 번 읽어 보시면 좋습니다.

# 헐거워지지 않게 오래 쓰는 방법
손잡이는 매일 쓰는 부분이라 작은 습관이 수명을 좌우합니다. / 아래만 지켜도 훨씬 오래 씁니다.
- 손잡이에 무거운 물건 걸어 두지 않기
- 문을 닫을 때 손잡이를 잡고 세게 당기지 않기
- 1년에 한 번쯤 고정 나사가 풀리지 않았는지 보기
- 손잡이가 덜렁거리기 시작하면 바로 조이거나 점검받기
작은 헐거움을 며칠 방치하면 안쪽 부품이 같이 닳아서 수리 범위가 커집니다. / 처음 느꼈을 때 손보는 것이 가장 덜 번거롭습니다.
@ 금광동 24시 출장열쇠 현관문 손잡이

# 금광동 말고 성남 어디든 갑니다
금광동 바로 옆 은행동, 상대원동, 단대동, 신흥동과 모란역 일대, 성남 전 지역에 출동합니다. / 위치를 알려주시면 도착 시간을 먼저 말씀드립니다.
성남 안내는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.

혼자 해결하기 어려우면 사진과 위치를 문자로 보내주시고 전화해 주시면 됩니다. / 24시간 받고, 서울·경기 전 지역에 출동합니다.
