# 번호는 맞는데 문이 안 열리는 이유가 설정일 수 있습니다
금광동은 모란역 생활권을 끼고 빌라와 주택, 상가가 어우러진 동네입니다. / 퇴근길에 번호를 눌렀는데 삑 소리만 나고 열리지 않는다는 연락이 가끔 들어옵니다.
도어락이 고장 난 것이 아니라 수동 잠금 모드가 켜져 있어서인 경우가 있습니다. / 이 글은 [성남 출장열쇠](seongnam.html)가 그런 상황에서 안내하는 확인 순서를 정리했습니다.
제품마다 이름과 방법이 조금씩 다르니 일반적인 흐름 위주로 적었습니다.
@ 금광동 도어락 수동 잠금 모드 확인

# 수동 잠금 모드란 무엇인가
수동 잠금 모드는 바깥에서 번호나 카드로 열 수 없게 잠가 두는 기능입니다. / 제품에 따라 외출 모드, 이중 잠금, 휴가 모드, 잠금 고정 같은 이름으로 부릅니다.
집 안에서 이 기능을 켜 두면 밖에서 아무리 맞는 번호를 눌러도 문이 열리지 않습니다. / 안전을 위한 기능이지만 켜 둔 사실을 잊으면 막막해집니다.
도어락 고장과 증상이 비슷해서 혼동하기 쉽습니다.
밤에 잠들기 전 가족 누군가가 습관처럼 켜 두는 집도 있어서, 아침에 출근하려는 사람이 먼저 막히는 경우가 있습니다. / 모드를 쓰는 사람과 모르는 사람이 한 집에 있을 때 특히 자주 생깁니다.

# 이런 증상이면 모드를 의심해 보세요
고장과 구분되는 단서가 있습니다.
- 번호를 누르면 평소처럼 삑 소리는 나는데 모터가 돌지 않는다
- 번호판에 평소 못 보던 표시등이 켜져 있다
- 안쪽에서 손잡이나 버튼으로 잠금 상태를 바꾼 기억이 있다
- 배터리 경고음은 없고 번호판 반응은 정상이다
반대로 번호판이 아예 안 켜지면 배터리 문제입니다. / 모터 소리만 크게 나는 경우는 걸쇠 쪽 문제일 수 있어 구분이 필요합니다.

# 누가 켰는지 가족에게 먼저 물어보세요
집 안에 가족이 있다면 가장 빠른 해결책은 안에서 모드를 풀어 주는 것입니다. / 안쪽 손잡이 위에 있는 작은 버튼이나 돌리는 꼭지가 잠금 고정과 관련돼 있습니다.
아이가 장난으로 눌러 두었거나 어르신이 외출 모드로 돌려 놓은 일도 많습니다. / 전화로 안쪽 상태를 말로 설명하며 풀어 보세요.
가족이 없다면 밖에서 풀 방법이 제품마다 다릅니다.
전화로 안내할 때는 손잡이 위아래 어느 쪽에 버튼이 있는지, 눌렀을 때 소리가 나는지를 차례로 여쭤봅니다. / 한 번에 한 가지씩만 눌러 보시면 원인을 가리기 쉽습니다.
@ 금광동 도어락 안쪽 잠금 버튼 상태

# 밖에서 풀 수 있는 방법이 있는지 확인
일부 제품은 등록된 카드나 관리자 번호로 모드를 풀 수 있게 만들어져 있습니다. / 제품 설명서에 이중 잠금 해제 방법이 있다면 그대로 따라 해 보세요.
- 관리자 번호나 마스터 코드가 따로 있는지 확인
- 카드나 열쇠로 우선 열 수 있는 제품인지 확인
- 비상 열쇠 구멍이 있다면 열쇠를 사용해 보기
열쇠 구멍이 번호판 아래 덮개 속에 숨겨진 제품도 있습니다. / 덮개를 살살 당겨 열면 나오는 경우가 많습니다.

# 해제하려고 무작정 누르지 마세요
급한 마음에 번호를 여러 번 틀리게 누르면 도어락이 입력을 한동안 막습니다. / 그러면 원래 풀 수 있었던 것도 기다려야 합니다.
버튼을 길게 누르거나 여러 개를 동시에 누르다 보면 설정이 의도치 않게 바뀌기도 합니다. / 되돌리기 어려워지면 설정을 처음부터 다시 해야 합니다.
서너 번 해 보고 반응이 없으면 멈추고 상황을 정리해 주세요.
금광동처럼 건물이 오래된 곳은 도어락도 오래된 제품이 많아 표시등 의미를 모르는 경우가 흔합니다. / 모르는 표시등은 그대로 두고 사진으로 남겨 두시면 됩니다.

# 전화하실 때 알려주세요
설정 문제인지 고장인지 구분하기 위해 아래를 알려 주시면 빠릅니다.
- 도어락 상표나 모양(손잡이 일체형, 푸시풀, 번호판 분리형)
- 번호판에 켜져 있는 표시등과 소리
- 최근 안쪽에서 무엇을 건드렸는지
- 집 안에 사람이 있는지
- 집이 금광동 어느 방향인지
번호판 사진을 문자로 보내 주시면 모델을 알아보기 쉽습니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분 집이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 이웃과 집을 지키는 절차입니다. / 집 안에 아이가 있다면 먼저 말씀해 주세요.
안에서 가족이 풀 수 있는 상황이라면 우리가 도착하기 전에 시도해 보시도록 전화로 안내드릴 수도 있습니다.

# 어떻게 여는지 순서대로
먼저 모드 해제를 시도해 설정만 풀면 되는 문제인지 확인합니다. / 설정만으로 풀리면 도어락이나 문에 손댈 일이 없습니다.
풀리지 않으면 비상 열쇠 구멍이나 외부 장치로 걸쇠를 움직이는 방법으로 넘어갑니다. / 도어락과 문이 상하지 않는 방법부터 차례로 시도합니다.
방법별 설명은 [현관문 개문](door-open.html) 안내에 정리해 두었습니다. / 부품을 바꿔야 하는 상황이라면 손대기 전에 먼저 여쭤봅니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 상황을 보고 얼마인지 먼저 알려 드립니다. / 괜찮다고 하시면 시작하고 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 열고 난 뒤 모드 설정을 같이 정리합니다
문이 열리면 어떤 모드가 켜져 있었는지 같이 확인합니다. / 가족이 헷갈리지 않게 모드를 쓰는 방법도 알려 드립니다.
쓰지 않을 기능이라면 잘 안 켜지게 정리해 두는 것이 안전합니다. / 필요하면 비밀번호도 새로 등록합니다.
모드 때문에 막혔던 일은 한 번 겪으면 가족 모두가 기억하게 됩니다. / 그래도 사용법을 종이에 적어 현관 안쪽에 붙여 두면 훨씬 안심입니다.
설정만의 문제가 아니라 고장이 의심되면 [도어락 수리](doorlock-repair.html)로 먼저 점검합니다. / 제품이 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 금광동 도어락 설정 정리 및 점검

# 모드 때문에 막히지 않는 집안 규칙
- 외출 모드나 이중 잠금을 쓰는 가족에게 사용법 알려 주기
- 도어락 설명서를 한 곳에 보관하기
- 번호판에 표시등이 켜진 채로 외출하지 않기
- 관리자 번호는 가족 한 사람이 메모해 두기
- 아이가 만지지 않도록 설정 버튼 위치 알려 주기
새로 도어락을 들일 때 모드 기능이 필요한지도 생각해 보세요. / 안 쓸 기능이 많은 제품보다 필요한 기능만 있는 제품이 오히려 편합니다.

# 금광동 말고 성남 어디든 갑니다
금광동 옆 은행동, 상대원동, 신흥동, 태평동, 단대동까지 성남 전역을 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
