# 금광동 집수리 끝나고 도어락이 이상해졌다면
금광동은 모란역 생활권과 이어져 있어 오래된 집을 고쳐 쓰는 분들이 많은 동네입니다. / 도배를 새로 하거나 현관문과 문틀에 페인트를 칠한 뒤부터 도어락이 뻑뻑하다는 연락이 가끔 옵니다.
공사 전에는 멀쩡하던 번호판이 눌리다 말거나 손잡이가 끝까지 안 돌아가면 불안해집니다. / 대부분 고장이 아니라 틈에 들어간 이물질이 원인인 경우가 많습니다.
이 글에서는 금광동 집에서 작업 뒤 도어락이 말썽일 때 직접 확인할 것과 [성남 출장열쇠](seongnam.html)를 부르는 때를 순서대로 적었습니다.
@ 금광동 도배 페인트 작업 뒤 도어락 틈 점검

# 작업 직후에 생기는 증상부터 구분하기
먼저 어떤 증상인지 가려 보세요. / 증상에 따라 원인이 다릅니다.
- 번호 버튼이 눌린 채 올라오지 않는 경우
- 손잡이가 중간에서 걸리듯 돌아가는 경우
- 걸쇠가 문틀 구멍에 들어가다 마는 경우
- 열쇠 구멍에 열쇠가 끝까지 들어가지 않는 경우
버튼이 끈적하게 눌리면 도료가 번졌을 가능성이 있습니다. / 걸쇠가 안 들어가면 문틀 쪽 홈에 페인트가 두껍게 앉았을 수 있습니다.

# 틈으로 들어가는 물질은 생각보다 다양합니다
도배 풀, 페인트, 퍼티 가루, 실리콘 부스러기가 모두 틈으로 들어갈 수 있습니다. / 한 번 말라 굳으면 접착제처럼 부품을 붙잡습니다.
특히 롤러로 문틀 가까이까지 칠하다 보면 도어락 몸통과 문 사이 이음새에 도료가 스며듭니다. / 겉으로는 깨끗해 보여도 안쪽 스프링 주변에 묻어 있는 일이 있습니다.
먼지 가루는 번호판 틈으로 들어가 버튼 아래 접점에 쌓이기도 합니다. / 이 경우 번호를 눌러도 반응이 한 박자 늦거나 건너뜁니다.

# 가장 먼저 해 볼 것은 닦아내기
마른 천에 물을 아주 약간만 묻혀 번호판과 손잡이 둘레를 조심스럽게 닦아 보세요. / 표면에 묻은 얼룩이 걷히면 버튼이 부드러워지는 경우도 있습니다.
굳은 도료는 손톱으로 긁지 말고 그대로 두는 편이 낫습니다. / 긁다가 코팅이 벗겨지면 번호판에 자국이 남습니다.
물을 흠뻑 뿌리거나 번호판 안쪽으로 흘려 넣는 것은 피해 주세요. / 전자 부품이 젖으면 작은 일이 큰 고장이 됩니다.

# 기름칠 스프레이는 쓰기 전에 한 번 더 생각하세요
뻑뻑하다고 윤활 스프레이를 듬뿍 뿌리는 분이 많습니다. / 하지만 굳은 도료와 기름이 섞이면 더 끈적해지고 먼지가 달라붙습니다.
번호판 가까이에 뿌리면 접점에 기름막이 생겨 오작동할 수도 있습니다. / 쓰시더라도 열쇠 구멍 같은 기계 부분에 아주 소량만 쓰시길 권합니다.
상태가 애매하면 아무것도 뿌리지 않고 전화로 물어보시는 편이 안전합니다.

# 문틀 쪽 걸쇠 구멍도 같이 보세요
도어락 자체가 아니라 문틀의 걸쇠 받침이 문제인 경우가 있습니다. / 칠이 두껍게 올라가 구멍이 좁아지면 걸쇠가 끝까지 들어가지 못합니다.
문을 닫았을 때 걸쇠가 닿는 위치에 얇은 종이를 대고 닫아 흔적을 보면 어디가 걸리는지 알 수 있습니다. / 흔적이 구멍 가장자리에 찍힌다면 구멍 안쪽을 정리해야 합니다.
이 작업은 문틀 도장을 상하게 하기 쉬워 직접 하기보다 맡기시는 분이 많습니다.
@ 금광동 문틀 걸쇠 구멍 도료 확인 장면

# 이미 안에 갇히거나 밖에 못 들어갈 때
버튼이 눌린 채로 안 올라와 번호를 못 넣는 상황이면 문 앞에서 막힙니다. / 이때 버튼을 세게 반복해서 누르면 접점이 더 눌려 상태가 나빠질 수 있습니다.
공사 기간에 집을 비우고 돌아왔는데 열리지 않는 일도 있습니다. / 현장 정리가 덜 된 채 마스킹 테이프 조각이 열쇠 구멍에 남은 경우가 실제로 있습니다.
안쪽에서 열쇠로 잠그고 나왔다면 [열쇠 출장](key-call.html) 안내를 보시고 상황을 알려주세요.

# 마스킹은 공사 전에 이렇게 하면 좋았습니다
다음에 작업을 하신다면 도어락은 가능하면 떼어 두거나 비닐로 감싸 두세요. / 종이 테이프만 붙이면 틈새로 도료가 스며드는 일이 많습니다.
- 번호판은 전체를 비닐과 테이프로 감싸기
- 열쇠 구멍은 테이프로 막되 작업 뒤 바로 떼기
- 걸쇠 구멍은 종이를 구겨 넣어 막기
- 공사 중에는 문을 닫아 두지 않고 고정해 두기
작업자에게 도어락은 건드리지 말고 가려만 달라고 미리 부탁하면 좋습니다. / 도어락을 떼어 보관하면 가장 안전하지만 다시 달 때 맞춤을 확인해야 합니다.

# 출장열쇠가 와서 하는 점검 순서
방문하면 먼저 어떤 증상인지 듣고, 도어락 겉모양과 문틀 상태를 눈으로 살핍니다. / 그다음 번호판, 손잡이, 걸쇠가 각각 제대로 움직이는지 하나씩 확인합니다.
틈에 낀 이물질이 보이면 부품이 상하지 않는 방법으로 정리합니다. / 안쪽까지 들어갔다면 분해가 필요한지 먼저 말씀드리고 시작합니다.
부품을 바꿔야 하는 상태라면 [도어락 수리](doorlock-repair.html)로 갈지, 교체가 나은지 비교해서 말씀드립니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 열거나 도어락을 만지는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
공사 중인 집은 거주자가 아닌 작업자만 있는 경우가 있습니다. / 이럴 땐 집주인이나 세입자 본인과 통화로 확인해야 하니 미리 연락해 두세요.

# 비용은 시작 전에 먼저 말씀드립니다
점검한 뒤 어디까지 하면 되는지, 비용은 어떻게 되는지 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꾸는 경우는 바꾸기 전에 꼭 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 금광동 도어락 이물질 제거 후 작동 확인

# 작업 후 금광동 집에서 하면 좋은 습관
공사가 끝나고 일주일쯤 지나 도료가 완전히 마른 뒤에 도어락을 한 번 더 점검해 보세요. / 마르는 동안 변하는 증상이 있어서입니다.
버튼을 하나씩 눌러 보고 걸쇠가 문틀에 부드럽게 들어가는지 확인하세요. / 열쇠도 한 번씩 꽂아 돌려 봅니다.
이상이 있으면 미루지 말고 연락하시는 게 좋습니다. / 굳기 전에 손보면 간단히 끝나는 경우가 많습니다.

# 금광동 말고 성남 어디든 갑니다
금광동 옆 은행동, 상대원동, 단대동, 신흥동과 서현·정자·야탑 쪽도 다닙니다. / 성남 안이면 동네와 상관없이 24시간 출동합니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

# 마무리

도어락 새로 다는 일이나 [도어락 교체](doorlock-replace.html)가 궁금하시면 함께 물어보셔도 됩니다.
