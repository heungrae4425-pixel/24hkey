# 구미동 집 공사를 맡기기 전에
구미동은 정자역 쪽 생활권과 이어진 주거지라 집 안을 고치는 인테리어 공사가 틈틈이 이어지는 동네입니다. / 공사 기간에는 집주인이 매번 문을 열어 줄 수 없어서 열쇠나 비밀번호를 작업하는 분께 맡기게 됩니다.
문제는 공사가 끝난 뒤입니다. / 맡긴 열쇠가 어디 있는지, 알려 준 번호가 아직 살아 있는지 모른 채 지내는 집이 의외로 많습니다.
이 글은 성남 구미동에서 공사 인력에게 출입 수단을 맡길 때 미리 정할 것과 끝난 뒤 정리법을 적었습니다. / [성남 출장열쇠](seongnam.html)에 맡기기 전에 한번 훑어 보세요.
@ 구미동 인테리어 공사 중 현관 도어락

# 열쇠를 줄지 번호를 줄지 먼저 정합니다
방법은 크게 세 가지입니다. / 실물 열쇠를 주거나, 도어락 번호를 알려 주거나, 매번 집주인이 직접 열어 주는 방식입니다.
- 열쇠를 주면 복사본이 만들어졌는지 확인하기 어렵습니다
- 번호를 주면 공사 후 바꾸기만 하면 정리가 끝납니다
- 직접 열어 주면 안전하지만 시간을 맞추기 번거롭습니다
공사가 며칠 걸리는 규모면 번호를 따로 정해 주고 끝나면 바꾸는 방식이 가장 정리하기 쉽습니다.

# 공사용 임시 번호를 따로 만듭니다
평소 가족이 쓰는 번호를 그대로 알려 주면 공사 후에도 그 번호가 남습니다. / 가능하면 임시 번호를 따로 만들어 공사 기간에만 쓰게 하세요.
도어락마다 방문자용이나 임시 번호를 따로 두는 기능이 있습니다. / 기능이 있다면 사용 기간을 정해 두면 정리가 쉽습니다.
없는 모델이라면 공사 기간용으로 번호를 한 번 바꾸고, 끝나면 다시 바꾸는 방식도 있습니다. / 번호를 바꾼 날짜는 메모해 두세요.

# 몇 명이 드나드는지 확인합니다
인테리어는 한 사람이 하는 일이 아닙니다. / 도배, 전기, 목공, 철거 등 공정마다 다른 분이 오고, 누구에게 번호가 넘어갔는지 잊기 쉽습니다.
공사 책임자 한 분에게만 출입 수단을 맡기고 나머지는 그분이 챙기도록 정해 두면 관리가 쉽습니다.
누구에게 언제 알려 줬는지 간단히 메모해 두면 끝난 뒤 정리가 빠릅니다.
공사 마지막 날에 책임자와 함께 집을 둘러보며 열쇠와 번호를 정리하겠다고 처음부터 말해 두면 서로 편합니다. / 사람을 믿지 못해서가 아니라 순서를 정하는 일이라고 설명하면 어색하지 않습니다.
@ 구미동 공사 작업자 출입 번호 메모

# 열쇠를 복사해 간 것 같을 때
작업자에게 실물 열쇠를 줬다면 돌려받을 때 몇 개를 줬는지 꼭 확인하세요. / 몇 개를 줬는지 기억이 안 난다면 복사본이 있을 수도 있다고 생각하는 편이 안전합니다.
의심이 가거나 불안하면 열쇠를 바꾸거나 도어락 번호를 바꾸는 방법이 있습니다. / 사람을 의심하자는 게 아니라 정리의 한 단계로 보시면 됩니다.
기계식 열쇠만 쓰는 문이라면 실린더 교체도 방법입니다. / 어떤 방법이 맞는지는 문 상태를 보고 말씀드립니다.

# 공사 중 도어락이 말썽일 때
공사 현장은 먼지가 많이 날립니다. / 번호판 틈으로 가루가 들어가면 반응이 느려지거나 키패드가 눌려도 안 되는 경우가 있습니다.
문을 열고 닫는 횟수도 평소보다 훨씬 많아서 배터리가 빨리 닳습니다. / 공사 중에 번호판이 꺼졌다면 9V 건전지를 바깥 단자에 대 보세요.
작업하시는 분들이 문을 활짝 열어 둔 채 자재를 나르다 도어락을 부딪치기도 합니다. / 문이 닫힐 때 걸쇠가 문틀에 닿는지도 봐 주세요.

# 현관문을 보양해 달라고 요청하세요
공사 때 현관문과 도어락을 비닐이나 테이프로 감싸는 보양을 해 달라고 미리 말씀하세요. / 페인트나 접착제가 번호판에 묻으면 닦기 어렵습니다.
테이프를 떼다가 번호판 코팅이 같이 벗겨지는 일도 있어서 약한 종이테이프를 쓰는 편이 낫습니다.
도어락 자체에 시너 같은 용제를 쓰지 않도록 부탁하세요. / 표면 마감이 하얗게 변하거나 번호가 지워질 수 있습니다.

# 작업자가 잠그고 간 날
작업자가 마지막에 퇴근하며 문을 잠갔는데 보조키까지 잠가 버려 집주인이 못 들어오는 일이 있습니다. / 반대로 집주인이 안에서 보조키를 돌려 놓고 나와서 작업자가 못 들어오기도 합니다.
이럴 땐 억지로 열려 하지 말고 전화로 상황을 알려 주세요. / 문이나 도어락이 상하지 않도록 순서대로 해봅니다.
현장에서 작업이 멈추면 일정에도 영향이 있어 서둘러 연락 주시는 게 좋습니다.

# 전화하실 때 알려주실 것
구미동은 단지와 빌라, 주택이 섞여 있어 위치를 정확히 알려 주시면 도착이 빨라집니다.
- 대략 위치(정자역 방향 등)와 건물 형태
- 문을 잠근 사람이 집주인인지 작업자인지
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집 안에 아이나 반려동물이 있는지
공사 중이라 집 안에 자재가 쌓여 있다면 그것도 말씀해 주세요. / 문을 열 때 걸리는 물건이 없는지 미리 알아야 안전하게 작업할 수 있습니다.

# 도착하면 사시는 분인지 먼저 확인합니다
공사 중인 집이라도 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
작업자가 먼저 연락 주셨더라도 집주인이 확인되어야 진행합니다. / 집주인이 멀리 계시면 통화로 허락을 받는 방법을 안내해 드립니다.
이웃과 집 모두를 위한 절차입니다.
@ 구미동 출장열쇠 신분 확인 절차

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 공사가 끝나면 이 순서로 정리하세요
공사 끝난 날 바로 하는 것이 가장 확실합니다.
- 맡겼던 열쇠를 모두 돌려받았는지 개수 확인
- 임시 번호를 지우거나 도어락 번호 새로 설정
- 공사 중 쌓인 먼지를 번호판과 틈에서 닦아내기
- 배터리 상태 확인하고 필요하면 전부 교체
- 문이 부드럽게 닫히는지, 걸쇠가 잘 나오는지 확인
번호 변경이 어렵거나 도어락이 불안하면 [도어락 수리](doorlock-repair.html)를 먼저 알아보시고, 너무 낡았다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / [현관문 개문](door-open.html) 안내도 참고하세요.

# 구미동 말고 성남 어디든 갑니다
구미동 바로 옆 정자동, 수내동, 서현동, 야탑동도 다닙니다. / 성남 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에서, 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
