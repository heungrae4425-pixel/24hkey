# 구미동에서 열쇠가 없을 때
열쇠가 없어졌다는 사실을 깨닫는 순간은 보통 현관문 앞입니다. / 주머니를 몇 번씩 뒤져도 없으면 마음이 급해지는데, 이럴 때일수록 한 가지씩 확인하는 것이 빠릅니다. / 구미동처럼 단지 사이 길이 이어진 동네는 걸어서 오가는 경로가 많아 분실 위치를 좁히기 쉽지 않습니다.
구미동은 분당 북쪽 끝에서 구미 쪽 단지들이 모여 있고, 산책길과 가까운 동네입니다. / 아침에 쓰레기 버리러 잠깐 나왔다가 문이 닫혀 버렸다는 전화가 의외로 많습니다.
열쇠를 잃어버린 것과 안에 두고 나온 것은 해결 방식이 다릅니다. / 이 글에서는 두 경우를 나눠서 적었습니다.
@ 구미동 열쇠 분실 출장열쇠 문 열기

# 열쇠를 잃어버렸을 때 먼저 할 일
마지막으로 열쇠를 본 곳부터 천천히 떠올려 보세요. / 가방, 외투 주머니, 차량, 근처 상가 분실물 보관함까지 한 번씩 확인합니다.
- 최근 입었던 옷의 주머니
- 차 안, 특히 좌석 아래와 컵홀더
- 자주 가는 가게나 헬스장 분실물
- 열쇠를 건네준 적 있는 가족, 지인
그래도 없으면 누군가 주웠을 가능성까지 생각해야 합니다. / 이때는 문을 여는 것과 별개로 도어락이나 열쇠 교체를 따져 보는 게 안전합니다.

# 집 안에 두고 문이 닫힌 경우
집 안에 열쇠가 있고 문만 닫혔다면 사실 큰 문제는 아닙니다. / 문을 상하지 않게 열면 열쇠는 그대로 쓸 수 있습니다.
스스로 열어 보려고 카드나 철사를 쓰면 문틈과 도어락이 상할 수 있어 권하지 않습니다. / 그대로 두고 전화 주시는 게 낫습니다.
이웃에게 휴대폰을 빌려 연락하셔도 됩니다.

# 열쇠를 잃어버렸다면 꼭 따져볼 것
열쇠를 주운 사람이 우리 집 위치를 알 수 있는 경우라면 더 신경 써야 합니다. / 열쇠고리에 주소나 호수가 붙어 있었는지 떠올려 보세요. / 그렇지 않더라도 불안하다면 열쇠 구멍을 새것으로 바꾸는 것이 가장 마음 편한 방법입니다. / 부담스럽다면 상황을 설명드릴 테니 천천히 정하셔도 됩니다.
열쇠를 잃어버린 경우는 문을 여는 것 외에 한 가지가 더 필요합니다. / 누가 그 열쇠를 가지고 있을 수 있으니 같은 키로 열리지 않게 하는 일입니다.
방법은 몇 가지가 있습니다. 상황에 맞게 상담해 드립니다.
- 열쇠 구멍(실린더)만 교체
- 도어락을 새로 설치
- 번호와 카드키로 바꾸고 열쇠는 보조로만 사용
무조건 교체를 권하지는 않고 상황에 따라 말씀드립니다.
@ 구미동 열쇠 분실 후 잠금장치 점검

# 전화하실 때 알려주세요
- 구미동 안에서 대략 어디인지, 가까운 역이나 길
- 열쇠를 잃어버렸는지, 안에 있는지
- 도어락 형태(열쇠만 쓰는지, 번호도 같이 쓰는지)
- 집 안에 아이나 반려동물이 있는지
위치와 상황이 정확할수록 도착 시간도 빨라집니다.

# 도착하면 사시는 분인지부터 확인
열쇠가 없다는 상황에서는 이 확인이 더 중요합니다. / 가족이나 이웃이 우리 집 사람임을 확인해 줄 수 있다면 같이 있어 주셔도 됩니다. / 신분증 사진이 휴대폰에 있다면 먼저 보여주셔도 확인에 도움이 됩니다. / 작업은 확인이 끝난 뒤에 시작합니다. / 미리 준비해 두시면 도착 후 시간이 줄어듭니다.
열쇠가 없다고 말하는 분이 사시는 분인지 확인하는 일은 꼭 필요합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우시겠지만 이웃과 집 주인을 지키기 위한 절차입니다. / 신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁하는 방법이 있습니다.

# 비용은 열기 전에 먼저 말씀드립니다
문 상태와 열쇠 종류를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 교체가 필요한 부품도 바꾸기 전에 따로 여쭙니다.
진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 문은 이렇게 엽니다
덜 상하는 방법부터 차례로 해봅니다. / 열쇠 구멍이 있는 문과 번호 도어락이 달린 문은 접근 방식이 다릅니다.
자세한 것은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 열쇠 복사나 추가 제작이 필요하면 [출장 열쇠](key-call.html) 안내도 함께 보세요.
@ 성남 출장열쇠 구미동 현관문 개문

# 열고 난 뒤 같이 점검하는 것
문이 열리면 열쇠 구멍과 도어락이 잘 돌아가는지 확인합니다. / 잃어버린 열쇠가 있다면 이전 키로 열리지 않게 조치할지도 상의합니다.
- 남은 열쇠 수와 가족 몫 확인
- 번호 도어락이면 번호 재설정
- 오래된 열쇠 구멍이면 부드러움 점검
작업이 길어지지 않게 필요한 것만 말씀드립니다.

# 같은 일이 안 생기게 하는 방법
현관 근처에 열쇠 거치대를 두면 습관이 되어 큰 도움이 됩니다. / 열쇠를 가방 속에 던져 넣기보다 항상 같은 주머니에 넣는 습관만으로도 분실이 크게 줄어듭니다.
현관 앞 작은 습관만으로도 이런 일을 크게 줄일 수 있습니다.
- 현관 안쪽에 열쇠 거는 자리 정하기
- 나가기 전 문 앞에서 열쇠·휴대폰 확인하기
- 가족이나 믿을 만한 곳에 여분 열쇠 보관하기
- 열쇠고리에 집 주소를 적지 않기
열쇠를 숨겨 두는 곳은 화분 밑처럼 흔한 곳이 아닌 한 곳을 정해 가족만 알게 하세요. / 모르는 사람이 찾아내기 어려운 곳이 좋습니다.
도어락 설치가 고민되면 [도어락 설치](doorlock-install.html) 페이지를 참고하세요.

? 한밤이나 새벽에도 오나요? | 24시간 전화를 받습니다.
? 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 열쇠를 새로 만들어 주나요? | 문 상태에 맞게 새 열쇠 제작이 가능한지 확인해 말씀드립니다.
