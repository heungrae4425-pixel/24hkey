# 이사 첫날 현관문부터 챙기세요
짐을 옮기고 나면 정신없이 가구 배치에 매달리지만, 현관 도어락은 먼저 살펴볼 일입니다. / 구미동으로 새로 오신 분들이라면 이전 사람이 쓰던 번호와 카드가 아직 남아 있을 수 있습니다.
이 글은 이사 후에 도어락을 어떻게 초기화하고 새 비밀번호를 정하면 좋은지 순서대로 적은 것입니다. / 정자역이나 미금역 쪽 생활권으로 이사 오신 분들이 흔히 궁금해하는 부분이기도 합니다.
@ 구미동 이사 후 도어락 초기화

# 왜 이사하자마자 번호를 바꿔야 하나
이전 거주자가 쓰던 번호와 등록된 카드, 지문이 그대로 남아 있을 가능성이 있습니다. / 의심하자는 것이 아니라 누가 번호를 알고 있는지 모르는 상태 자체가 불편하기 때문입니다.
새 집에서 안심하고 지내려면 내 가족이 정한 번호만 남기는 것이 가장 깔끔합니다. / 이사 당일이나 다음 날 안에 하시면 가장 좋습니다.
입주 청소나 인테리어 업체가 드나든 경우라면 더욱 정리해 두는 것이 좋습니다. / 작업자에게 임시로 알려 준 번호가 남아 있을 수 있기 때문입니다.

# 초기화를 시작하기 전에 확인할 것
도어락은 제품마다 초기화 방법이 다르고, 일부는 버튼이 안쪽 덮개 안에 숨어 있습니다. / 먼저 문 안쪽의 배터리 덮개를 열어 보세요.
- 제품 모델명이나 제조사 표시
- 초기화 버튼의 위치(배터리 칸 근처 작은 버튼 등)
- 등록된 카드나 지문 기능이 있는지
- 배터리가 충분한지
초기화 도중에 배터리가 약해 꺼지면 설정이 꼬일 수 있습니다. / 시작 전에 새 배터리로 바꿔 두는 편이 안전합니다.

# 초기화와 비밀번호 변경은 다른 일입니다
초기화는 등록된 정보를 전부 지우고 공장 상태로 돌리는 것입니다. / 비밀번호 변경은 기존 설정은 그대로 두고 번호만 바꾸는 것입니다.
이전 사용자의 카드나 지문까지 정리하려면 초기화가 필요하고, 번호만 바꾸면 되는 상황이면 변경으로 충분합니다. / 어느 쪽이 맞는지는 제품과 상황에 따라 다릅니다.
초기화 후에는 기본 번호로 돌아가거나 번호가 비는 제품도 있어서 바로 새 번호를 등록해야 합니다. / 이 순서를 모르고 중간에 멈추면 문이 번호 없이 열리는 상태가 될 수도 있어 주의하세요.
@ 도어락 초기화 버튼 위치 확인

# 새 비밀번호는 이렇게 정하세요
누구나 떠올릴 법한 생일이나 전화번호 뒷자리, 연속된 숫자는 피하는 편이 좋습니다. / 가족이 외우기 쉬우면서도 남이 짐작하기 어려운 조합이 이상적입니다.
너무 복잡하면 가족이 자꾸 잊어버려 문 앞에서 막히게 됩니다. / 외우기 쉬운 문장을 숫자로 바꾸는 식으로 정하는 분들도 있습니다.
정한 번호는 가족 모두에게 같은 시간에 알려 주세요. / 한 명만 알고 있으면 그 사람이 없을 때 곤란해집니다.

# 카드키와 지문은 어떻게 하나
카드키가 여러 장 딸려 있다면 초기화 후 필요한 카드만 다시 등록합니다. / 남는 카드는 따로 보관하거나, 쓰지 않는다면 정리해 두세요.
지문을 등록할 때는 같은 손가락을 두세 번 나누어 인식시키면 이후 인식이 잘 됩니다. / 손이 건조한 계절에는 인식이 약해질 수 있으니 여러 손가락을 등록해 두면 편합니다.
어린 자녀나 어르신 지문은 변화가 커서 인식이 약할 수 있습니다. / 카드나 번호를 함께 쓰는 방식이 더 안정적일 수 있습니다.

# 보조키와 열쇠는 따로 챙깁니다
도어락 말고 안쪽 보조키나 열쇠로 여는 구조라면 그쪽 열쇠가 몇 개인지 확인하세요. / 이전 거주자가 가지고 있는 열쇠가 남아 있을 수 있습니다.
열쇠 복사본이 다른 곳에 있을지 몰라 걱정된다면 열쇠 자체를 새로 바꾸는 방법도 있습니다. / 필요하다고 판단되면 현장에서 상태를 보고 말씀드립니다.
무조건 교체를 권하지는 않습니다. / 가족이 불안하지 않은 선에서 필요한 만큼만 하시면 됩니다.

# 직접 하다 막히면 부르셔도 됩니다
설명서를 잃어버렸거나 모델 정보를 찾기 어려우면 초기화 방법을 알아내기 어렵습니다. / 억지로 이것저것 눌러 보다 번호가 꼬여 문이 안 열리는 경우도 있습니다.
그럴 땐 위치와 상황을 알려 주세요. / 구미동에서는 보통 동 이름과 가까운 역 방면을 말씀해 주시면 됩니다.
- 건물 종류와 동, 호수
- 도어락 모양과 제조사 표시
- 지금 문이 열리는 상태인지
- 이미 시도해 본 것이 있는지

# 도착하면 거주자 확인을 먼저 합니다
이사 직후라 신분증 주소가 아직 이전 주소인 경우가 많습니다. / 이럴 때는 계약서, 입주 안내문, 주소가 적힌 우편물, 관리사무소 확인 등 여러 방법으로 거주를 확인합니다.
번거로울 수 있지만 모든 분께 같은 방식입니다. / 어떤 서류가 있는지 전화로 미리 말씀해 주시면 확인이 수월합니다.
확인이 끝내 어려우면 작업을 진행하지 못하니 미리 챙겨 두시면 좋습니다.

# 비용은 시작 전에 말씀드립니다
도어락 상태를 확인한 뒤 작업 전에 비용을 먼저 안내합니다. / 동의하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 열어야 하는 상황에서 열지 못하면 비용은 받지 않습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다. / 문이 안 열리는 상태라면 [현관문 개문](door-open.html)도 참고해 주세요.
@ 구미동 출장열쇠 비밀번호 재설정

# 초기화 뒤 동작 확인
새 번호를 등록한 뒤에는 문을 연 채로 몇 번 열고 닫아 보세요. / 문이 닫힌 상태에서 새 번호로 열리는지도 반드시 확인합니다.
한 번 확인한 뒤 문을 닫고 나서 열쇠 없이 빠져나가지 마세요. / 새 번호가 제대로 등록되었는지 확신하기 전에는 문을 열어 둔 채 시험하는 것이 안전합니다.
가족 모두가 새 번호로 열어 보는 시간도 필요합니다. / 이 확인만 해도 이사 첫날 문 앞에서 생기는 문제를 대부분 막을 수 있습니다.

# 오래된 도어락이라면 교체도 살펴보기
이사 온 집의 도어락이 많이 낡았다면 초기화만으로는 부족할 수 있습니다. / 버튼이 눌리지 않거나 손잡이가 헐거운 경우는 [도어락 수리](doorlock-repair.html)로 먼저 점검합니다.
너무 낡아서 안정적으로 쓰기 어렵다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 새 제품이 필요한 경우에도 이유를 먼저 설명하고 동의하셔야 진행합니다.
처음 이사하는 날 모든 걸 바꿀 필요는 없습니다. / 쓰면서 불편한 점이 생기면 그때 상의하셔도 늦지 않습니다.

- 이전 사용자 번호와 카드 정리
- 새 번호 가족 공유
- 배터리 새것으로 교체
- 보조키와 열쇠 개수 확인
- 모델명 사진을 휴대폰에 보관
이 다섯 가지만 해두면 새집에서 안심하고 지낼 수 있습니다. / 처음이라 헷갈린다면 한 번에 하나씩 천천히 진행하세요.

# 구미동 말고 성남 어디든 갑니다
구미동 바로 옆 정자동, 수내동, 서현동, 이매동, 야탑동은 물론 성남 전 지역에 24시간 출동합니다. / 다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다.
다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.

? 문을 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.

? 계약서가 아직 이전 주소인데 확인이 되나요? | 계약서, 입주 안내문, 우편물, 관리사무소 확인 등으로 거주를 확인합니다.
? 비밀번호만 새로 바꿔 주실 수 있나요? | 네, 새 번호 등록과 배터리 교체까지 함께 도와드립니다.
