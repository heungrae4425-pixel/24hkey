# 문제가 생기기 전에 사진 몇 장
구미동은 정자역 생활권과 가까워 퇴근길에 걸어서 집으로 오는 분이 많은 동네입니다. / 문 앞에서 도어락이 먹통이 되면 그제야 휴대폰을 꺼내 설명하려다 막히는 경우가 많습니다.
도어락 모양을 말로만 설명하면 서로 알아듣기 어렵습니다. / 평소에 사진 몇 장을 찍어 두면 급할 때 문자로 보내기만 하면 됩니다.
이 글은 구미동에서 도어락 사진을 미리 찍어 두는 방법과 어떤 사진이 가장 도움이 되는지를 적었습니다. / 지금 문제없는 집일수록 읽어 두시면 좋습니다.
@ 구미동 도어락 앞면 사진 찍기

# 왜 사진이 있으면 빨라질까
도어락은 제조사와 형태가 다양해서 이름만으로는 구분하기 어렵습니다. / 같은 번호판 모양이라도 안쪽 구조와 열 수 있는 방법은 다를 수 있습니다.
사진이 있으면 전화 통화 시간이 줄고 챙겨 갈 장비를 미리 정할 수 있습니다. / 급한 상황일수록 이 차이가 큽니다.
배터리 덮개 위치, 비상 전원 단자 유무, 열쇠 구멍 유무도 사진에서 바로 보입니다.
예를 들어 번호판 아래에 작은 단자가 보이면 9V 건전지로 임시 전원을 대 볼 수 있는지 전화로 바로 안내드릴 수 있습니다. / 단자가 없는 제품이라면 처음부터 다른 방법을 준비해 갑니다.
문 앞에서 한 번도 도어락을 자세히 본 적 없는 분이 많아서, 평소에 한 번 들여다보는 것만으로도 막상 일이 생겼을 때 훨씬 침착해집니다.
사진은 가족끼리 나눠 두면 한 사람이 자리에 없어도 다른 사람이 대신 설명할 수 있습니다.

# 찍어 둘 사진 목록
아래 다섯 가지만 찍어 두면 충분합니다. / 한 번 찍어서 휴대폰 앨범에 모아 두세요.
- 현관문 바깥쪽에서 본 도어락 전체
- 현관문 안쪽에서 본 도어락과 손잡이
- 번호판 아래쪽, 비상 전원 단자 쪽 가까운 사진
- 문 옆면의 걸쇠가 나오는 부분
- 현관문 전체와 보조키(있다면)
각 사진은 흔들리지 않게 밝은 곳에서 찍는 것이 좋습니다. / 야간에는 플래시를 켜면 반사로 글씨가 안 보일 수 있으니 거리를 조금 두고 찍어 보세요.

# 앞면 사진, 이렇게 찍으세요
정면에서 번호판이 한눈에 보이게 찍습니다. / 번호판에 불이 들어온 상태와 꺼진 상태를 둘 다 있으면 더 좋습니다.
제조사 로고가 보이도록 찍어 두면 모델 구분이 쉬워집니다. / 다만 로고가 없는 제품도 있으니 모양 전체가 보이는 것이 먼저입니다.
손잡이의 형태(레버형, 누르는 형)와 열쇠 구멍이 있는지도 함께 담으면 좋습니다.

# 안쪽 사진에서 알 수 있는 것
집 안쪽 사진에는 배터리 덮개, 보조키, 잠금 버튼이 나옵니다. / 배터리가 몇 개 들어가는지, 덮개 여는 방식이 무엇인지는 열어서 확인해야 알 수 있습니다.
안쪽 손잡이 위에 있는 돌리는 보조키와 문 측면 걸쇠 상태도 같이 찍어 두세요. / 문을 잠그고 나왔을 때 어떤 장치가 잠겨 있는지 구분하는 데 도움이 됩니다.
@ 구미동 도어락 안쪽 배터리 덮개와 보조키

# 사진과 함께 적어 둘 메모
사진만큼 짧은 메모가 도움이 됩니다. / 휴대폰 메모장에 한 줄씩 적어 두면 충분합니다.
- 동, 호수와 건물 입구를 찾는 방법
- 도어락을 설치한 시기가 대략 언제쯤인지
- 최근 배터리를 바꾼 날
- 가족 중 비밀번호를 아는 사람이 누구인지
날짜가 정확하지 않아도 괜찮습니다. / 대략 "작년 겨울쯤"처럼 적어 두시면 됩니다.

# 사진을 잘못 공유하면 곤란한 점
사진에는 비밀번호가 보이면 안 됩니다. / 번호판 지문이나 손때로 자주 쓰는 숫자가 드러나기도 하니 닦고 찍으세요.
문 앞 전체를 찍을 때 집 안 내부나 가족 사진이 비치지 않게 주의하세요. / 이웃집 현관 번호가 보이는 것도 피하는 편이 좋습니다.
사진을 SNS나 단체방에 올리지 말고 필요한 상대에게만 문자로 보내세요.

# 사진 보내실 때 이렇게 하세요
연락할 때 사진을 먼저 보내고 통화하면 한결 수월합니다. / 문자에는 위치와 상황 한 줄만 함께 적어 주세요.
- 구미동 안에서 어느 쪽인지(정자역 쪽, 안쪽 주택가 등)
- 번호판이 켜지는지, 소리가 나는지
- 안에 아이나 반려동물이 있는지
- 문이 열리지 않는 것 같은지, 잠기지 않는 것 같은지
사진은 한 장만 보내도 되고, 여러 장이면 더 좋습니다. / 흐릿하면 다시 부탁드릴 수 있으니 양해 바랍니다.
사진이 없어도 괜찮습니다. / 사진이 없는 경우도 위치와 상황을 말씀해 주시면 출동합니다.

# 신분 확인은 사진과 별개로 합니다
사진을 보냈다고 문을 바로 여는 것은 아닙니다. / 도착하면 사시는 분이 맞는지 먼저 확인합니다.
신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다. / 신분증이 집 안에 있으면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.
확인이 어려우면 작업을 할 수 없으니 신분증이나 우편물은 눈에 띄는 곳에 미리 사진으로도 찍어 두면 편합니다.
@ 구미동 출장열쇠 도어락 사진 확인 후 방문

# 비용은 열기 전에 말씀드립니다
사진과 현장 상태를 보고 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
사진이 있으면 같은 비용 설명이 더 간단해집니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 도어락을 바꾸실 계획이라면 사진이 더 중요합니다
교체나 설치를 생각하신다면 사진과 함께 문 두께와 보조키 유무를 알려주세요. / 문 사진이 있으면 맞는 제품을 추리기 쉽습니다.
[도어락 교체](doorlock-replace.html)가 필요한지, 고쳐서 쓸 수 있는지를 사진으로 먼저 가늠해 드립니다. / 새로 다는 경우는 [도어락 설치](doorlock-install.html) 페이지를 참고하세요.
고장이 계속되는 제품은 [도어락 수리](doorlock-repair.html)로 해결되는지도 같이 봅니다.

# 사진 정리 습관
찍은 사진은 한곳에 모아 두면 급할 때 바로 찾습니다. / 앨범에 "현관" 같은 이름으로 폴더를 만들어 두면 좋습니다.
- 가족 모두 같은 앨범을 볼 수 있게 공유하기
- 도어락을 바꾸거나 배터리를 갈면 사진 다시 찍기
- 연 사진은 몇 달에 한 번씩 확인하고 낡은 사진 정리하기
- 예비 열쇠 보관 위치도 메모로 같이 남기기
사진은 문제를 해결하는 열쇠가 아니라 설명을 쉽게 해 주는 도구입니다. / 부담 없이 한 번 찍어 보세요.

# 구미동 말고 성남 어디든 갑니다
구미동 옆 정자동, 수내동, 서현동, 야탑동, 이매동도 다닙니다. / 성남 안이면 24시간 출동합니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html), 개문 방식은 [현관문 개문](door-open.html)에서 보실 수 있습니다.
