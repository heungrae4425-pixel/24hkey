# 이매동에서 처음 혼자 사는 신입생에게
이매동은 서현역과 판교역 사이 생활권에 있어 두 방향으로 오가기 편한 동네입니다. / 대학에 들어가며 처음 자취를 시작하는 분이 이 근처에 방을 구하는 경우도 있습니다.
부모님 집에서는 열쇠나 번호를 신경 쓸 일이 거의 없었는데, 혼자 살면 문 앞 사고도 혼자 해결해야 합니다. / 이 글은 첫 도어락을 쓰는 신입생이 알아 둘 것을 순서대로 정리했습니다.
@ 이매동 자취방 현관의 도어락
걱정하지 않으셔도 됩니다. / 기본기만 익혀 두면 대부분의 문 앞 사고는 혼자서 막을 수 있습니다.

# 입주 첫날 도어락부터 정리하기
이삿짐을 풀기 전에 도어락 번호를 새로 정하세요. / 앞서 살던 사람이 쓰던 번호나 카드가 남아 있을 수 있기 때문입니다.
초기화 방법은 제품마다 달라서 안쪽 덮개를 열어 설명서를 확인합니다. / 방법을 모르겠으면 모델명을 사진으로 찍어 두세요.
이사 후 정리는 [도어락 설치](doorlock-install.html) 페이지에서도 확인할 수 있습니다.
혼자 사는 집은 문이 곧 안전의 시작입니다. / 겁낼 필요는 없지만 처음 한 번 꼼꼼히 정리해 두면 이후가 편해집니다.
집주인이나 관리인에게 도어락 모델과 비상 열쇠 위치도 한 번 물어봐 두세요.

# 비밀번호는 이렇게 정하세요
생일, 학번, 전화번호 뒷자리는 남이 짐작하기 쉽습니다. / 외우기 쉬우면서 규칙이 눈에 띄지 않는 번호가 좋습니다.
처음 만든 번호는 휴대폰 메모에 적어 두기보다 머리로 기억하세요. / 부모님께는 말로 전하고, 문자로 남기는 건 피하는 게 좋습니다.
친구가 놀러 오면 임시로 번호를 알려 주고 다음 날 바꾸는 습관을 들이세요.
같은 번호를 현관, 사물함, 휴대폰에 모두 쓰는 것은 피하세요. / 하나가 알려지면 전부 위험해집니다.

# 문이 닫히면 자동으로 잠기는 방식
대부분의 도어락은 문이 닫히면 저절로 잠깁니다. / 쓰레기를 버리러 잠깐 나가거나 택배를 받으러 나갈 때도 마찬가지입니다.
휴대폰 없이 문만 닫고 나오면 그 순간 집 안에 갇힌 것이 아니라 집 밖에 갇힌 셈이 됩니다. / 그래서 나갈 때 휴대폰과 번호가 기억나는지 확인하는 습관이 필요합니다.
@ 쓰레기를 들고 현관문을 나서는 모습
문 앞에서 택배를 받거나 이웃과 잠깐 이야기할 때도 문이 닫히면 잠깁니다. / 수업이 일찍 있는 날 급하게 나서는 아침에 특히 조심하세요.
외출 전에 주머니를 두드리며 휴대폰과 지갑을 확인하는 습관이 가장 좋은 예방입니다.

# 배터리 경고음을 놓치지 마세요
도어락은 건전지로 작동하고, 다 되기 전에 경고음이나 불빛으로 알려 줍니다. / 이 소리를 무시하다가 새벽에 번호판이 꺼지는 일이 가장 흔합니다.
삑 소리가 평소와 달리 길거나 반복되면 그날 바로 새 건전지로 교체하세요. / 한두 개만 바꾸지 말고 전부 같은 새것으로 바꿔야 합니다.
비상용 9V 건전지를 하나 사 두면 도어락이 꺼졌을 때 바깥 단자에 대 볼 수 있습니다.
시험 기간처럼 집에 늦게 들어오는 날이 이어지면 경고음을 흘려듣기 쉽습니다. / 방학 동안 집을 비웠다 돌아온 날 번호판이 꺼져 있는 경우도 흔합니다.
건전지는 편의점에서도 구할 수 있으니 미리 여분을 한 벌 사 두면 든든합니다.

# 문이 안 열릴 때 침착하게 확인할 것
- 번호판이 켜지는지, 소리가 나는지
- 번호를 정확히 눌렀는지 (손이 젖거나 급하면 틀리기 쉽다)
- 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보기
- 비상 건전지 단자가 있는지
이 네 가지만 해 봐도 원인이 많이 좁혀집니다. / 확인한 내용을 그대로 전화로 말씀해 주시면 훨씬 빨리 해결됩니다.
친구에게 번호를 알려 준 적이 있다면 그 친구가 번호를 바꿨는지도 생각해 보세요. / 같이 사는 룸메이트가 있다면 먼저 연락해 보는 것이 가장 빠릅니다.
그래도 안 되면 문 앞에서 오래 서성이지 말고 일단 연락해 주세요. / 늦은 밤 혼자 기다리는 것보다 빨리 정리하는 편이 안전합니다.

# 혼자 살 때 흔한 실수 사례
친구들과 밤늦게 모임을 갖고 들어오다 번호가 갑자기 기억나지 않는 경우가 있습니다. / 술을 마셨거나 피곤하면 평소 쓰던 번호도 헷갈립니다.
이럴 때는 억지로 여러 번 누르지 말고 잠시 쉬었다가 천천히 눌러 보세요. / 계속 틀리면 도어락이 입력을 막아 더 못 들어가게 됩니다.
그래도 안 되면 [출장열쇠](key-call.html)로 연락 주세요.
열쇠를 가방 안쪽 주머니에 넣어 두고 잊어 버려 가방을 뒤적이다 한참 걸리는 일도 있습니다. / 현관 근처 한곳에 고정해 두면 이런 일이 줄어듭니다.

# 부모님께 알려 두면 좋은 것
부모님이 급한 일이 있을 때를 대비해 도어락 상황은 알려 두는 편이 좋습니다. / 다만 번호를 전부 공유하기보다 연락이 닿을 방법을 먼저 정해 두세요.
집주인이나 관리인의 연락처도 휴대폰에 저장해 두면 도움이 됩니다. / 문이 안 열릴 때 가장 먼저 물어볼 수 있는 사람이기 때문입니다.
택배 기사나 수리 기사가 방문할 때는 현관문을 열기 전에 확인부터 하는 습관이 좋습니다. / 낯선 사람에게 번호를 알려 주지 마세요.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
막 이사 와서 아직 우편물이 없다면 임대차 계약서나 입주 확인을 준비해 주세요. / 이웃과 집 주인 모두를 위한 절차라 확인이 어려우면 작업을 할 수 없습니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 문을 열기 전에 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고 아니면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙니다.
@ 출장열쇠 기사가 자취방 도어락을 확인하는 모습

# 도어락이 고장 난 것 같을 때
번호판이 반응하지 않거나 경고음이 계속 나면 먼저 건전지를 확인하세요. / 건전지를 바꿔도 같으면 [도어락 수리](doorlock-repair.html)로 점검이 필요한 상태입니다.
임대로 살고 있다면 도어락 수리나 교체는 집주인과 먼저 이야기하는 편이 좋습니다. / 책임이 누구에게 있는지는 계약 내용에 따라 다르니 단정하지 말고 확인하세요.
자취방은 도어락 상태를 모르고 들어오는 경우가 많습니다. / 처음 일주일 동안 작동 소리와 반응을 눈여겨봐 두면 이상 신호를 빨리 알아챌 수 있습니다.

# 이매동 말고 성남 어디든 갑니다
이매동 옆 서현동, 야탑동, 구미동, 백현동도 다닙니다. / 성남 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html)에 있고, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.
