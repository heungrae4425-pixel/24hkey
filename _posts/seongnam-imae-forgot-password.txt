# 이매동에서 비밀번호가 갑자기 생각나지 않을 때
번호를 잊는 일은 기억력이 나빠서가 아니라 너무 익숙해서 일어나는 경우가 많습니다. / 손가락이 기억하던 순서가 깨지면 머리로는 오히려 떠오르지 않습니다. / 피곤한 퇴근길이나 오랜만에 돌아온 날에는 더 흔합니다. / 당황하지 말고 아래 순서대로 하나씩 해보세요.
이매동은 분당 한가운데에서 이매역 쪽으로 단지와 상가가 이어진 동네입니다. / 오랜만에 늦게 귀가하다 번호판 앞에서 번호가 하나도 떠오르지 않는 일은 생각보다 흔합니다.
번호를 잊은 건지, 누가 바꿨는지, 아니면 도어락이 이상한 건지 먼저 가려야 합니다. / 이 글은 그 순서를 차근차근 정리했습니다.
@ 이매동 도어락 비밀번호 분실 출장열쇠

# 번호를 잊는 흔한 경우 세 가지
이매동 같은 주거 밀집 지역에서 자주 듣는 사례를 모았습니다.
- 한 번만 바꾸고 한참 지나 새 번호가 헷갈리는 경우
- 가족이 모르게 바꾸거나 알려주지 않은 경우
- 오래 비웠다가 돌아와 예전 번호와 섞여 틀리는 경우
세 번째는 뜻밖에 많습니다. / 사람은 반복해서 누르는 손가락 순서로 번호를 기억해서, 평소 습관이 깨지면 번호가 막힙니다.

# 먼저 가족에게 연락해 보세요
이매동처럼 가족 단위로 사는 집이 많은 동네는 가족 중 누군가가 번호를 알고 있을 가능성이 높습니다. / 혼자 사는 경우라면 예전 메모, 이삿짐 서류, 휴대폰 사진첩에 번호가 남아 있는지 찾아보세요. / 도어락 설치 당시 받은 설명서나 사진에 적혀 있는 경우도 있습니다.
가장 빠른 해결은 가족 중 누군가에게 번호를 묻는 것입니다. / 휴대폰 메모나 가족 단체방에 적어 둔 번호가 없는지도 찾아보세요.
도어락에 카드키나 열쇠가 따로 등록되어 있다면 그쪽이 더 빠릅니다. / 지갑이나 가방 안쪽 주머니에 넣어 둔 카드가 의외로 많이 나옵니다.
이미 해본 뒤 안 풀릴 때 전화 주시면 됩니다.

# 틀린 번호를 계속 누르면 잠깁니다
번호를 여러 번 틀리면 일정 시간 입력을 막는 도어락이 많습니다. / 처음 몇 번은 생각날 법한 번호를 넣어보되 서너 번 안 되면 멈추세요.
막힌 상태에서 계속 누르면 대기 시간만 늘어납니다. / 침착하게 몇 분 기다렸다가 전화로 도움을 요청하는 편이 낫습니다.

# 번호를 모를 때는 이렇게 엽니다
비밀번호를 모르는 문은 번호를 알아내는 방식이 아니라 문을 상하지 않게 여는 방식으로 진행합니다. / 도어락 종류와 문 상태를 확인하고 덜 상하는 방법부터 시작합니다.
자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.
@ 성남 출장열쇠 이매동 도어락 개문

# 전화할 때 알려주시면 좋은 것
- 이매동에서 가까운 역(이매역, 야탑역 쪽 등)과 대략의 위치
- 도어락 모양과 번호판 형태
- 번호판이 켜지는지, 켜지는데 안 열리는지
- 집 안에 사람이나 반려동물이 있는지
사진을 문자로 보내주시면 도착 전에 상황을 미리 가늠할 수 있습니다.

# 사시는 분인지 확인합니다
번호를 모르는 문을 열어드리는 일이라 사시는 분 확인은 꼭 거칩니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
집 안에 신분증이 있어 난감하다면 관리사무소나 경비실에 세대 확인을 부탁해 보세요. / 늦은 시간이면 미리 말해 두는 것이 수월합니다.

# 비용은 시작 전에 먼저
상황을 보고 비용을 먼저 말씀드리고, 괜찮다고 하셔야 시작합니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
열고 난 뒤 얘기 없이 붙는 비용도 없습니다. / 진행 순서는 [이용안내](guide.html)에 정리되어 있습니다.

# 문이 열린 다음에 꼭 할 일
새 번호를 정한 뒤에는 가족에게 어떻게 전달할지도 정해 두세요. / 문자로 보내기보다 직접 말로 전하거나 보안이 되는 메모를 쓰는 편이 안전합니다.
열렸다고 끝이 아닙니다. / 같은 일이 반복되지 않게 새 번호를 정해 등록하는 것까지가 한 세트입니다.
기존 번호는 지우고 새 번호만 남겨 둡니다. / 가족 모두가 아는 번호인지도 같이 확인합니다.
등록 방법이 헷갈리면 안쪽 버튼 위치부터 같이 짚어드립니다.

# 기억하기 쉽되 맞추기 어려운 번호 만들기
생일이나 전화번호 뒷자리, 1234 같은 번호는 피하는 게 좋습니다. / 남이 맞추기 쉽고 자주 쓰다 보니 외우기도 쉬운 쪽으로 쏠리기 때문입니다.
- 가족만 아는 숫자 조합을 정하기
- 숫자를 네 자리가 아닌 더 긴 자리로 설정하기
- 바꾼 날짜는 달력이 아닌 안전한 곳에 적어 두기
번호를 메모할 때는 도어락 이름 없이 숫자만 적지 마시고, 휴대폰 보안 메모로 보관하는 편이 안전합니다.

# 카드키나 열쇠를 같이 등록해 두세요
번호만 쓰는 도어락이라면 카드키나 보조키를 하나 더 마련해 두면 좋습니다. / 번호를 잊었을 때 다른 방법이 있다는 것만으로도 큰 안심이 됩니다.
카드는 가방이 아니라 평소 자리 한 곳에 보관하세요. / 잃어버렸다면 그 카드 등록을 삭제해야 합니다.
교체나 추가가 필요한 상황은 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html) 페이지를 참고하세요.
@ 이매동 도어락 비밀번호 재설정 점검

? 가족이 바꾼 번호를 모를 때도 부르면 되나요? | 네, 사시는 분인지만 확인되면 진행합니다.
? 열고 나서 새 번호도 만들어 주나요? | 네, 새 번호 등록과 기존 번호 삭제까지 같이 해드립니다.
? 한밤에도 오나요? | 24시간 전화를 받습니다. 시간 상관없이 전화 주세요.
? 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.

# 이매동 말고도 성남 어디든
이매동 옆 야탑동, 서현동, 정자동은 물론 판교, 수정구, 중원구, 위례까지 갑니다. / 성남 안이면 24시간 출동합니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 있고, 서울·경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
