# 이매동에서 집을 오래 비우기 전에
출장이 길수록 돌아오는 날은 피곤하고 마음은 급합니다. / 그런 날 문 앞에서 시간을 허비하지 않도록 미리 준비하는 방법을 순서대로 담았습니다.
점검은 어렵지 않고 특별한 도구도 필요 없습니다. / 건전지와 열쇠, 그리고 몇 분의 시간이면 충분합니다.
이매동은 서현역과 판교역 쪽을 오가며 출퇴근하는 분이 많은 동네입니다. / 몇 주씩 이어지는 출장이나 해외 체류를 앞두고 있다면 짐 싸기 전에 현관문부터 점검하시길 권합니다.
집을 오래 비우면 도어락은 아무도 쓰지 않아도 조금씩 전기를 씁니다. / 떠날 때 멀쩡해 보여도 돌아올 때는 번호판이 꺼져 있을 수 있습니다.
@ 이매동 장기 출장 전 도어락 배터리 점검

# 떠나기 일주일 전에 하면 좋은 일
출발 직전에는 짐과 서류 챙기느라 도어락까지 볼 여유가 없습니다. / 그래서 미리 날짜를 정해 두고 하나씩 지워 가는 방식이 편합니다.
점검 목록을 휴대폰 메모에 적어 두면 다음 출장 때도 그대로 쓸 수 있습니다.
출발 당일에 몰아서 하면 놓치는 것이 생깁니다. / 일주일쯤 전에 한 번 확인해 두면 문제가 생겨도 고칠 시간이 있습니다.
- 배터리 잔량 경고음이 한 번이라도 났었는지 떠올리기
- 보조키 잠금 방향과 손에 쥔 느낌 확인
- 비상 열쇠나 카드키가 어디 있는지 정하기
- 가족이나 이웃에게 비상시 연락 방법 알려 두기

# 배터리는 새것으로 전부 교체
건전지 소모는 번호판 밝기, 문을 여닫는 횟수, 겨울 기온에 따라 달라집니다. / 그래서 몇 개월 썼으니 괜찮다는 계산보다 출발 전 교체가 훨씬 확실합니다.
비상용 9V 건전지 하나를 여행 가방이 아닌 현관 근처 가까운 곳에 두는 것도 방법입니다.
남은 용량이 있어 보여도 장기 부재 전에는 새 건전지로 바꾸는 것이 안전합니다. / 일부만 바꾸면 약한 쪽이 먼저 떨어져 전체 전압이 흔들립니다.
같은 종류, 같은 제조 시기의 건전지로 모두 바꾸세요. / 교체한 날짜를 메모해 두면 돌아와서도 상태를 가늠할 수 있습니다.

# 교체 직후에 꼭 해 볼 시험
건전지를 갈아 끼운 뒤에는 문을 연 채로 번호를 몇 번 눌러 보세요. / 문이 열린 상태에서 시험하면 잘못 잠겨도 곤란해지지 않습니다.
- 안쪽에서 잠금과 해제를 두세 번 반복
- 밖에서 번호로 열리는지 확인
- 문을 닫고 걸쇠가 소리 없이 들어가는지 확인
시험 중 경고음이 이어지거나 모터 소리가 평소와 다르면 출발 전에 [도어락 수리](doorlock-repair.html)를 먼저 알아보세요.
@ 이매동 도어락 건전지 교체 후 작동 시험

# 보조키와 안쪽 잠금장치 확인
반대로 보조키를 잠그지 않으면 마음이 불안하다는 분도 계십니다. / 이럴 때는 돌아오는 날 가족이 먼저 들어가 풀어 줄 수 있는지 계획을 세워 두세요.
혼자 돌아오는 경우라면 번호가 먹히는 상태로 두는 쪽이 편한 경우가 많습니다.
보조키를 잠가 둔 채 나가면 돌아와서 번호를 눌러도 열리지 않습니다. / 장기 부재 때는 보조키를 잠글지 말지 정해 두고 가족 모두 같은 규칙을 따르게 하세요.
걸쇠나 체인을 걸어 둔 채 나가는 일은 거의 없지만 혼자 사는 집에서는 실수가 잦습니다. / 문을 닫기 전 안쪽 손잡이 아래 장치를 눈으로 한 번 보는 습관이 도움이 됩니다.

# 비상 열쇠는 집 밖에 하나 둡니다
해외로 나가는 경우라면 열쇠를 공항에 들고 가는 것도 손해입니다. / 잃어버릴 위험이 있으니 믿을 만한 가족에게 맡기는 편이 낫습니다.
맡길 사람이 정해졌다면 그분이 집 위치와 호수를 정확히 아는지도 확인하세요.
도어락에 기계식 열쇠 구멍이 있는 제품이면 열쇠는 집 안이 아닌 믿을 만한 곳에 따로 보관하세요. / 가족이나 직장 책상 서랍이 흔한 선택입니다.
현관 근처 화분 밑이나 우편함 속은 위험하니 피하세요. / 열쇠를 어디에 맡겼는지 한 줄로 메모해 두면 급할 때 헤매지 않습니다.

# 부재 중 이웃과 가족이 할 일
택배가 문 앞에 쌓이는 상황은 미리 줄이는 것이 좋습니다. / 택배 수령 장소를 바꾸거나 배송 보류를 요청해 두면 한결 안심이 됩니다.
우편물이 쌓이면 빈집 티가 납니다. / 가능하면 가족이나 이웃에게 주기적으로 문 앞을 확인해 달라고 부탁하세요.
다만 비밀번호를 그대로 알려 주기보다 임시 번호를 따로 만들어 쓰는 편이 낫습니다. / 돌아와서 그 번호를 지우면 되기 때문입니다.

# 돌아왔는데 번호판이 꺼져 있다면
번호판이 켜지는데 번호를 눌러도 반응이 없으면 다른 원인입니다. / 모터 소리만 나는지, 아무 소리도 없는지 구분해서 알려주시면 원인을 좁히기 쉽습니다.
방금 내린 택시나 차를 보내지 말고 상황을 확인한 뒤 결정하셔도 됩니다.
긴 비행이나 열차 뒤에 지친 몸으로 문 앞에서 막히는 일이 생깁니다. / 먼저 번호판을 손으로 덮었을 때 불이 켜지는지 보세요.
불이 전혀 없으면 바깥쪽 아래 비상 단자에 9V 건전지를 대 보는 방법이 있습니다. / 단자가 없거나 반응이 없으면 억지로 힘을 쓰지 말고 연락 주세요.

# 이럴 땐 억지로 열지 마세요
손잡이를 세게 돌리거나 문틈에 도구를 넣는 일은 문과 도어락을 모두 상하게 합니다. / 비밀번호도 여러 번 틀리면 한동안 입력이 막힙니다.
짐이 많은 상태에서 서두르다가 번호를 헷갈리는 일이 흔합니다. / 짐을 내려놓고 숨을 고른 뒤 천천히 한 번 더 눌러 보세요.

# 위치와 상황은 이렇게 알려주세요
이매동 어디쯤인지, 서현역 쪽인지 판교역 쪽인지처럼 대략적인 방향도 알려주시면 좋습니다. / 아래 내용이 있으면 출동 준비가 빨라집니다.
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집을 비운 기간
- 출발 전에 건전지를 바꿨는지
- 안에 반려동물이나 가족이 있는지

# 신분 확인과 비용 안내
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
비용은 문 열기 전에 먼저 말씀드리고, 괜찮다고 하실 때만 시작합니다. / 문을 못 열면 비용은 받지 않습니다.
@ 이매동 24시출장열쇠 현장 신분 확인

# 열린 뒤에 바로 하면 좋은 정리
문을 열고 들어선 뒤에는 짐을 풀기 전에 도어락부터 한 번 점검하세요. / 이런 순서가 습관이 되면 다음 출장 때도 같은 실수를 막을 수 있습니다.
문이 열리면 건전지를 새것으로 바꾸고 번호를 다시 시험합니다. / 부재 중 쌓인 문제가 없는지 보조키와 걸쇠도 같이 확인하세요.
비밀번호를 바꾸고 싶다면 안쪽에서 새 번호를 등록합니다. / 도어락이 오래돼 자주 말썽이면 [도어락 교체](doorlock-replace.html) 상담도 가능합니다.

# 이용 안내와 출동 지역
진행 방식은 [이용안내](guide.html)에, 현관문 개문 방법은 [현관문 개문](door-open.html)에 적어 두었습니다. / 성남 안 동네는 [성남 출장열쇠](seongnam.html)에서 볼 수 있습니다.
