# 혼자 사는 집일수록 문이 잠기면 더 막막합니다
이매동은 이매역을 중심으로 원룸과 오피스텔에서 혼자 사는 분도 많은 생활권입니다. / 혼자 살면 집 안에서 열어 줄 사람이 없어 문이 잠겼을 때 더 난감합니다.
원룸과 오피스텔은 일반 가정집과 달리 공동 출입구, 호실 문, 관리실이라는 단계가 겹쳐 있습니다. / 어디에서 막혔는지 알아야 필요한 사람을 부를 수 있습니다.
이 글은 이매동 원룸과 오피스텔에서 출입문이 잠겼을 때 순서대로 확인할 점을 정리했습니다. / 마지막에는 [성남 출장열쇠](seongnam.html)를 부르는 방법도 담았습니다.
@ 이매동 원룸 오피스텔 출입문 출장열쇠

# 먼저 어느 문이 막혔는지 구분합니다
오피스텔은 문이 여러 겹입니다. / 건물 정문, 엘리베이터 카드 인식, 층 복도 출입문, 호실 문 순서로 지나옵니다.
- 건물 정문이 안 열리는 경우
- 엘리베이터가 내 층에 서지 않는 경우
- 복도 출입문이 안 열리는 경우
- 호실 문 도어락이 안 열리는 경우
앞의 세 가지는 건물 관리실에서 풀어 주는 경우가 많습니다. / 호실 문이 문제일 때 열쇠집을 부르시면 됩니다.

# 관리실에 먼저 물어볼 것
건물 관리실이 열려 있다면 먼저 연락해 보세요. / 정문이나 엘리베이터 문제는 관리실이 가장 빠릅니다.
관리실에서는 호실 거주 확인을 도와줄 수 있습니다. / 신분 확인이 필요한 열쇠집에서도 이 확인을 인정하는 경우가 있습니다.
밤에 관리실이 닫혀 있다면 야간 연락처가 적혀 있는지 건물 입구를 살펴보세요. / 연락처를 휴대폰에 저장해 두면 다음에도 쓸모가 있습니다. / 관리실이 상주하지 않는 건물이라면 관리 업체 연락처가 우편함이나 게시판에 붙어 있는 경우가 많습니다.
관리실에 문의할 때는 몇 호에 사는 누구인지, 지금 어디서 막혔는지만 짧게 말하면 됩니다.

# 호실 도어락 배터리부터
원룸 도어락은 하루에도 여러 번 열고 닫아 배터리가 빨리 닳습니다. / 번호판이 안 켜지면 배터리부터 의심하세요.
바깥 아래쪽 단자에 9V 건전지를 대 보면 열리는 경우가 많습니다. / 편의점에서 구할 수 있는 건전지로 충분합니다.
열리면 곧바로 배터리를 새것으로 바꿔 주세요. / 임대 중인 집이라면 배터리는 보통 사는 사람이 관리하는 경우가 많으니 계약 내용을 한 번 살펴보세요.
@ 이매동 원룸 호실 도어락 배터리 확인

# 열쇠 없이 나왔을 때 흔한 상황
원룸은 쓰레기를 내놓거나 택배를 찾으러 잠깐 나왔다가 문이 닫혀 버리는 일이 흔합니다. / 자동 잠금이 기본인 도어락은 문이 닫히는 순간 잠깁니다.
휴대폰과 지갑이 모두 집 안에 있으면 이웃에게 전화를 빌려야 합니다. / 관리실이나 편의점 직원에게 부탁하는 방법도 있습니다.
외출 직전 문을 닫기 전에 손으로 주머니를 한 번 확인하는 습관이 가장 확실한 예방입니다. / 도어스토퍼를 잠깐 끼워 두는 방법도 쓸모가 있습니다. / 복도 출입문이 자동으로 잠기는 건물이라면 그 문까지 닫혀 갇히지 않게 주의해야 합니다.
실내복 차림으로 나왔다가 막혔다면 이웃의 호의로 잠시 기다릴 곳을 구하는 것도 방법입니다. / 모르는 사람에게 무리하게 부탁하기보다는 관리실이나 경비 인력의 도움을 먼저 구하세요.

# 신분 확인이 원룸에서는 더 중요합니다
원룸과 오피스텔은 같은 건물에 많은 호실이 있어 누가 어느 호실에 사는지 확인이 더 엄격합니다. / 사시는 분인지 확인하지 않고는 열 수 없습니다.
신분증 주소, 주소가 나온 우편물, 관리실 확인 중 하나를 준비해 주세요. / 입주한 지 얼마 안 되어 신분증 주소가 이전 주소라면 계약서나 입주 서류 사진도 도움이 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 집주인과 관리실의 역할
원룸이나 오피스텔은 임대인이 따로 있는 경우가 많습니다. / 문을 열어 달라는 것과 도어락을 바꾸는 것은 다른 문제입니다.
사시는 분이 확인되면 개문은 가능합니다. / 하지만 도어락을 교체하거나 부품을 바꾸는 경우 임대인과 상의할 일이 있을 수 있습니다.
비용 부담이나 계약 문제는 저희가 판단할 수 있는 일이 아니라 임대인과 직접 이야기해야 합니다. / 필요하면 열고 난 뒤 상황을 정리해서 말씀드리면 됩니다.

# 전화할 때 알려주시면 좋은 것
- 이매동 어느 건물이고 가까운 역은 어디인지
- 건물 정문 비밀번호나 호출 방법
- 몇 층 몇 호인지
- 번호판 상태와 도어락 모양
- 관리실이 열려 있는지
공동 출입구가 잠겨 있으면 기사가 건물에 들어올 방법도 알려 주셔야 합니다. / 건물 앞까지 나와 주시거나 호출해 주시면 가장 빠릅니다.

# 도어락 종류를 미리 알아 두세요
원룸은 번호식, 카드식, 지문식이 섞여 있습니다. / 어떤 방식이 쓰였는지에 따라 열 때의 방법이 달라집니다.
카드로 여는 오피스텔은 카드를 잃어버렸을 때 새 카드 등록이 필요합니다. / 이 경우는 [열쇠 호출](key-call.html) 페이지에서 상황을 확인해 보세요.
사진 한 장이 전화 설명 열 마디보다 낫습니다. / 도어락이 보이게 찍어 두세요.

# 도착하면 이렇게 진행합니다
기사가 도착하면 신분을 확인하고 문과 도어락 상태를 봅니다. / 방법과 비용을 먼저 말씀드리고 동의하시면 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 최대한 문과 도어락이 상하지 않는 방식부터 해 봅니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 이매동 24시 출장열쇠 신분 확인 개문

# 열린 뒤 챙길 점검
문이 열리면 도어락이 정상으로 열리고 잠기는지 몇 번 확인합니다. / 배터리를 교체하고 번호 설정이 그대로인지 봅니다.
수리가 필요하면 [도어락 수리](doorlock-repair.html)로, 너무 낡았다면 [도어락 교체](doorlock-replace.html)를 안내합니다. / 임대 중이라면 교체 전에 임대인과 상의하시길 권합니다.
문 여는 과정은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.

# 원룸에서 미리 해 둘 준비
- 휴대폰에 관리실 연락처와 집주인 연락처 저장
- 예비 열쇠나 카드를 믿을 수 있는 사람에게 맡기기
- 배터리는 반년마다 점검하고 경고음 나면 바로 교체
- 신분증 사진이나 주소가 나온 서류를 휴대폰에 저장
- 외출 전 주머니 확인하는 습관 만들기
이렇게 해 두면 혼자 사는 집에서도 문 앞에서 오래 막힐 일이 줄어듭니다. / 여행이나 출장으로 오래 비울 때는 배터리를 미리 점검하고 가세요.
돌아와서 문이 안 열리는 일은 오랜만에 집에 오는 날 가장 자주 생깁니다.

# 이매동 말고 성남 어디든 연결됩니다
서현동, 야탑동, 정자동, 구미동까지 성남 안이면 24시간 출동합니다. / 성남 밖은 [출장 지역](area.html)에서 확인해 주세요.
