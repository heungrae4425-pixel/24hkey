# 이매동 도어락이 아무도 안 눌렀는데 삑삑거릴 때
서현역과 야탑역 쪽 생활권에 걸쳐 있는 이매동에서도 한밤중에 현관 도어락이 혼자 삑삑 소리를 내거나 불이 켜졌다 꺼지는 일을 겪는 분들이 있습니다. / 아무도 만지지 않았는데 숫자가 눌린 듯한 소리가 나면 불안해지기 마련입니다.
이 글은 터치 패널이 혼자 눌리는 듯한 오작동의 원인을 구분하는 방법과 [성남 출장열쇠](seongnam.html)가 점검하는 순서를 정리했습니다. / 대부분은 습기, 먼지, 배터리 같은 흔한 이유입니다.
@ 이매동 현관 터치 패널에 불이 들어온 모습

# 혼자 눌리는 것처럼 보이는 대표 원인
터치 방식 번호판은 손가락의 미세한 전기 신호를 감지합니다. / 그래서 손이 아닌 것이 비슷한 신호를 만들면 눌린 것처럼 반응합니다.
- 번호판 표면에 습기나 결로가 맺힌 경우
- 먼지와 기름때가 쌓여 전기가 번지는 경우
- 배터리가 약해져 센서가 불안정해진 경우
- 문 열림 때 센서가 오작동 신호를 보내는 경우
- 패널 안쪽에 물이 들어간 경우
원인이 하나가 아니라 겹쳐 있는 경우도 많습니다.

겨울 새벽처럼 바깥과 실내 온도 차가 큰 시간에는 번호판 안쪽에 얇은 물방울이 생겨 센서가 흔들리기도 합니다. / 이런 경우 낮에는 멀쩡하다가 밤에만 소리가 나서 더 이상하게 느껴집니다.
고장이라고 단정하기 전에 이런 환경 요인부터 따져 보는 것이 순서입니다. / 불필요한 교체를 피하는 데도 도움이 됩니다.

# 언제 소리가 나는지 먼저 기록해 보세요
원인을 좁히려면 소리가 나는 시간과 날씨를 며칠 적어 보면 도움이 됩니다.
- 새벽이나 아침 일찍 기온이 떨어질 때만 나는지
- 비가 오거나 습한 날에만 나는지
- 밤마다 비슷한 시간에 나는지
- 문을 여닫은 직후에만 나는지
습기와 관련 있다면 날씨와 맞물려 반복됩니다. / 배터리라면 시간과 상관없이 불안정하게 나타납니다.
@ 이매동 도어락 번호판 표면의 물기와 먼지

# 해볼 수 있는 안전한 조치
부품을 열지 않고 할 수 있는 것부터 해보세요.
- 마른 부드러운 천으로 번호판 표면을 가볍게 닦기
- 물을 직접 뿌리거나 세제를 쓰지 않기
- 배터리를 전부 새것으로 바꿔 보기
- 번호판 주변 틈새에 쌓인 먼지 살짝 털기
배터리 교체는 일부만 바꾸지 말고 전부 같은 제품으로 바꾸세요. / 새 배터리로 바꾸고도 계속된다면 다른 원인일 수 있습니다.

# 해서는 안 되는 것
궁금하다고 번호판을 뜯거나 알코올로 닦는 것은 피해 주세요. / 표면 코팅이 벗겨지거나 내부 회로가 상할 수 있습니다.
혼자 눌리는 소리가 싫다고 무음으로만 바꾸고 방치하는 것도 좋지 않습니다. / 소리가 사라져도 오작동 원인은 그대로 남아 있을 수 있습니다.
번호가 계속 눌리고 있다면 도어락이 입력 제한에 걸려 정작 필요할 때 문이 안 열릴 수도 있습니다.

# 오작동이 문이 안 열리는 문제로 번졌다면
혼자 눌리는 일이 반복되다가 어느 날 번호를 눌러도 반응이 없고 문이 안 열릴 수 있습니다. / 입력 제한이 걸렸거나 배터리가 바닥난 경우입니다.
이때는 억지로 열지 말고 바깥쪽 아래 비상 단자에 9V 건전지를 대 보는 방법을 먼저 시도해 보세요. / 그래도 안 되면 연락 주세요.
문 앞에서 막혔다면 [현관문 개문](door-open.html) 방식으로 최대한 안 상하게 열어드립니다.

가끔은 집 안 쪽에서 문을 닫을 때의 진동이나 바람, 문 틈새로 들어오는 습기가 센서를 건드리는 경우도 있습니다. / 이럴 때는 번호판 하나만이 아니라 문과 문틀 틈까지 함께 봐야 합니다.
가족 중 누가 늦게 들어오며 문 앞에서 서성이는 소리인지도 구분해 보세요. / 의외로 이웃이나 가족의 발소리를 오해하는 경우도 있습니다.

# 전화로 알려주면 점검이 빨라지는 것
상황을 설명해 주시면 점검 방향을 잡기 쉽습니다.
- 이매동 어느 쪽인지, 서현역이나 야탑역 방향 정도의 위치
- 혼자 눌리는 소리가 나는 시간대와 날씨
- 배터리를 언제 바꿨는지
- 도어락 모양과 번호판 사진
사진이 있으면 증상 판단에 도움이 됩니다.

# 방문 점검 때 사시는 분인지 확인합니다
문과 도어락을 만지는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 가족과 이웃 모두를 위한 절차입니다. / 확인이 어려우면 작업을 시작할 수 없으니 미리 챙겨 두세요.

# 비용은 점검 전에 말씀드립니다
증상을 보고 청소와 조정으로 충분한지, 부품을 바꿔야 하는지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고 아니면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 점검은 이렇게 진행합니다
먼저 번호판 표면과 틈새를 확인하고 배터리 전압을 봅니다. / 이어서 습기가 들어간 흔적과 패널 접촉 상태를 살펴봅니다.
청소와 배터리 교체로 해결되면 거기서 끝냅니다. / 부품 문제라면 어떤 부품인지 보여드리고 말씀드립니다.
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 접근하고, 너무 오래됐거나 자주 반복되면 [도어락 교체](doorlock-replace.html)를 권해 드립니다.
@ 이매동 도어락 터치 패널 점검 작업

# 고친 뒤 재발을 줄이는 습관
점검이 끝나도 같은 증상이 다시 나올 수 있어 평소 관리가 필요합니다.
- 번호판은 마른 천으로 가끔 가볍게 닦기
- 겨울 결로철에는 현관 앞 환기 신경 쓰기
- 비 들이치는 날 번호판 물기 확인하기
- 배터리는 해가 바뀔 때쯤 전부 교체하기
증상이 다시 나오면 날짜와 시간을 적어 두었다가 알려주세요. / 기록이 있으면 원인 찾기가 훨씬 쉽습니다.

# 터치 대신 다른 방식이 나을 때
터치 패널이 습기에 계속 민감한 환경이라면 버튼식이나 다른 방식이 나을 수도 있습니다. / 이 판단은 현장 환경을 보고 말씀드립니다.
무조건 교체를 권하지 않고 지금 제품이 쓸 만한지 먼저 봅니다. / 교체가 필요하면 문 두께와 보조키 위치도 함께 확인합니다.

오작동 소리를 녹음하거나 짧은 영상으로 남겨 두면 점검 때 큰 도움이 됩니다. / 소리가 나는 순간 번호판 불이 어떻게 켜지는지도 함께 담아 주세요. 증상이 간헐적이라 현장에서 재현되지 않을 수도 있어서, 기록이 있으면 원인을 훨씬 정확하게 추릴 수 있습니다. 걱정되는 마음에 번호판을 가리거나 테이프를 붙이는 것은 피해 주세요.

# 이매동 말고 성남 어디든 갑니다
이매동 옆 서현동, 야탑동, 구미동은 물론 성남 안이면 동네 상관없이 24시간 출동합니다. / 지역은 [성남시 출장열쇠](seongnam.html)에서, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
