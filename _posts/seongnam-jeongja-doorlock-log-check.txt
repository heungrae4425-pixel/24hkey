# 정자역 근처 맞벌이 가정이 궁금해하는 것
정자동은 정자역을 중심으로 출퇴근하는 가정이 많은 동네입니다. / 부모가 퇴근하기 전에 아이가 학원에서 돌아왔는지, 혼자 사시는 부모님이 오늘 문을 열고 나갔는지 궁금해지는 순간이 있습니다.
이럴 때 도어락 출입 기록 기능을 쓰면 별도 확인 전화 없이 대략의 귀가 시각을 알 수 있습니다. / 이 글은 출입 기록 확인 기능을 어떻게 쓰고 어디까지 믿을 수 있는지 적은 것입니다.
@ 정자동 현관 도어락과 출입 기록 확인 화면

# 출입 기록 기능이란 무엇인가
출입 기록은 도어락이 언제 열리고 닫혔는지, 어떤 방법으로 열렸는지를 저장해 두는 기능입니다. / 번호로 열었는지, 카드로 열었는지, 지문으로 열었는지가 구분돼 남는 제품도 있습니다.
모든 도어락에 있는 기능은 아닙니다. / 제품에 따라 기록 개수와 확인 방법이 다르므로 설명서나 모델명을 먼저 확인하세요.
기록은 누가 열었는지를 알려주는 것이 아니라 어떤 수단이 쓰였는지 알려주는 것입니다. / 가족마다 다른 번호나 카드를 쓰면 구분이 쉬워집니다.

# 확인하는 방법은 크게 세 가지
첫째, 도어락 본체에서 직접 보는 방식입니다. / 안쪽 기기에서 메뉴를 눌러 최근 기록을 확인합니다.
둘째, 스마트폰 앱에 연결해 보는 방식입니다. / 외출 중에도 확인할 수 있어 가장 널리 쓰입니다.
셋째, 알림으로 받는 방식입니다. / 아이가 문을 열면 부모 휴대폰에 알림이 오도록 설정할 수 있는 제품도 있습니다.
어느 방식이든 제품이 지원해야 가능하므로 구입 전에 확인하세요.

# 가족마다 번호나 카드를 따로 정합니다
같은 번호를 모두 쓰면 기록에는 번호로 열었다는 사실만 남습니다. / 가족별로 다른 번호나 카드를 등록하면 누가 열었는지 짐작할 수 있습니다.
아이용 번호, 부모님용 번호, 돌봄하시는 분 번호를 따로 두는 집이 많습니다. / 이름표를 붙이듯 번호마다 이름을 지정해 주는 기능이 있는 제품도 있습니다.
가족 번호를 정할 때는 [도어락 설치](doorlock-install.html) 상담에서 몇 개까지 등록되는지 먼저 확인하는 것이 좋습니다.

# 아이 귀가 확인에 쓸 때 마음가짐
아이에게 감시당한다는 느낌을 주지 않도록 미리 이야기해 두세요. / 안전을 확인하는 용도라는 점을 알려 주면 거부감이 줄어듭니다.
기록이 안 남았다고 해서 아이에게 일이 생긴 것은 아닙니다. / 문이 열리는 시각이 어긋나거나 다른 방법으로 들어왔을 수도 있습니다.
학원이 끝나는 시간대에 알림이 안 오면 먼저 아이 휴대폰으로 안부를 묻고, 그래도 연락이 안 될 때 다음 방법을 생각해 보세요. / 문 앞에서 아이가 번호를 잊어 서성이는 경우도 의외로 많습니다.
확인이 어렵다면 아이에게 직접 연락하는 것이 가장 빠릅니다. / 출입 기록은 참고용이라고 생각하는 편이 마음이 편합니다.
@ 스마트폰으로 도어락 최근 출입 시각 확인

# 부모님 안부 확인에 쓸 때
혼자 사시는 부모님 집 도어락 기록을 보면 아침에 문이 열렸는지를 알 수 있습니다. / 하루 종일 기록이 없다면 전화를 한 번 드려 보는 정도로 사용하세요.
부모님께 미리 설명드리고 동의를 받는 것이 가장 중요합니다. / 기능을 켜 두고 말씀을 안 드리면 오해가 생깁니다.
부모님이 쓰기 편한 설정은 [도어락 교체](doorlock-replace.html) 페이지의 안내와도 이어지는 부분입니다.

# 기록이 안 보이거나 시각이 틀릴 때
기록이 비어 있는 경우 먼저 도어락과 앱이 연결돼 있는지 확인합니다. / 와이파이가 바뀌었거나 앱이 업데이트된 뒤 연결이 끊기는 경우가 있습니다.
시각이 어긋나 있다면 도어락 시계 설정이 맞는지 봅니다. / 건전지를 갈아 끼운 뒤 시간이 초기화되는 제품도 있습니다.
건전지가 약해지면 기록 저장이나 전송이 안 될 수 있습니다. / 알림이 갑자기 안 온다면 건전지부터 새것으로 바꿔 보세요.

# 기록 확인 기능이 있어도 지켜야 할 것
출입 기록은 가족 사이 정보라 함부로 공유하지 않는 것이 좋습니다. / 휴대폰 잠금과 앱 비밀번호를 설정해 두세요.
기록 개수가 정해져 있어 오래된 것은 지워질 수 있습니다. / 중요한 시각이 필요하다면 그날 캡처해 두는 방법이 있습니다.
기록이 있다고 해서 보안이 저절로 강화되는 것은 아닙니다. / 번호를 주기적으로 바꾸고 관리하는 습관은 그대로 필요합니다.

# 정자동에서 출장을 부를 때 알려 주실 것
기록 기능 점검이나 설정만 도와달라는 요청도 받습니다. / 도어락 모델명, 앱 사용 여부, 어떤 증상인지 알려 주세요.
- 도어락 제조사와 모델명이 보이는 사진
- 기록이 안 보이는 시점과 증상
- 앱 연동을 했는지 여부
- 정자역 쪽 어느 방향인지, 건물 이름과 동·호수
문이 안 열려 출장을 부르는 경우는 위치와 번호판 상태를 먼저 알려 주세요. / 기록 점검은 문이 열린 뒤에 같이 봅니다.

# 문 앞이라면 신분 확인 먼저
문이 안 열려 요청하신 경우라면 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
기록 확인 설정만 도와드릴 때도 주소와 거주 확인은 같이 합니다. / 가족 출입 정보를 다루는 일이라 더 신중하게 진행합니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요.

# 비용은 시작 전에 먼저 말씀드립니다
도어락 종류와 필요한 작업을 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 기록 기능을 새로 쓰고 싶다면
지금 도어락이 기록 기능을 지원하는지부터 확인합니다. / 지원하지 않는다면 교체를 하거나 별도 장치를 쓰는 방법이 있습니다.
교체를 한다면 문 두께, 보조키 유무, 와이파이 환경을 먼저 봅니다. / 그래서 [도어락 교체](doorlock-replace.html)와 [도어락 설치](doorlock-install.html) 안내를 함께 읽어 보시길 권합니다.
꼭 필요한 기능만 고르고 쓰지 않는 기능은 빼는 것이 가격과 관리 면에서 부담이 적습니다.
@ 출입 기록 설정을 점검하는 모습

# 정자동 말고 성남 어디든 갑니다
정자동 가까운 서현동, 수내동, 백현동, 구미동 등 성남이면 동네 상관없이 24시간 받습니다. / 다니는 동네는 [성남시 출장열쇠](seongnam.html)에 정리해 두었습니다.
서울과 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다. / 현관문 개방은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

? 기록으로 누가 열었는지 정확히 알 수 있나요? | 번호나 카드를 가족별로 따로 등록해야 구분됩니다.
