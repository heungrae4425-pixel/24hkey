# 정자동 도어락이 평소와 다르게 울릴 때
정자동은 정자역 주변으로 아파트 단지와 상가, 오피스텔이 가까이 붙어 있는 동네입니다. / 출퇴근 시간이 일정한 분들이 많아서 아침에 문이 말썽이면 바로 일정이 꼬입니다.
도어락은 갑자기 멈추는 것처럼 보여도 대개 며칠 전부터 신호를 보냅니다. / 평소 안 나던 소리가 나기 시작했다면 그게 신호입니다.
이 글은 정자동에서 도어락이 이상하게 울리거나 소리만 나고 안 열릴 때 소리별로 무엇을 의심할지 정리했습니다. / 직접 해볼 수 있는 선까지만 적었고, 그다음은 [성남 출장열쇠](seongnam.html)에 맡기시면 됩니다.
@ 정자동 도어락 오작동 출장열쇠

# 소리를 먼저 구분해 보세요
도어락은 소리로 상태를 알려줍니다. / 같은 "삐" 소리라도 길이와 횟수에 따라 뜻이 다릅니다.
- 짧게 삑 한 번: 입력이 정상으로 들어갔다는 뜻
- 삑삑삑 여러 번 반복: 입력 오류 또는 건전지 부족 경고
- 길게 삐이: 잠금 상태에서 열림 동작이 안 된 경우
- 웅 하는 모터음 후 정적: 번호는 맞았지만 걸쇠가 안 움직이는 경우
제품마다 조금씩 다르니 설명서 기준이 우선입니다. / 설명서가 없으면 소리를 그대로 말씀해 주셔도 대략 짐작이 갑니다.

# 경고음이 반복되면 건전지부터
번호를 누를 때마다 경고음이 섞여 나오면 가장 흔한 원인은 건전지입니다. / 전압이 떨어지면 번호는 인식되는데 모터를 돌릴 힘이 모자라게 됩니다.
이런 상태에서 억지로 여러 번 누르면 건전지가 더 빨리 바닥납니다. / 한두 번 시도해 보고 안 되면 멈추는 쪽이 낫습니다.
정자동 근처 편의점에서도 건전지는 구할 수 있지만, 도어락마다 AA인지 9V인지 다릅니다. / 사기 전에 안쪽 건전지 덮개를 열어 규격부터 확인해 주세요.

# 번호는 맞는데 모터 소리만 날 때
삑 하고 모터가 도는 소리까지 나는데 문이 안 열리면 기계 쪽 문제일 수 있습니다. / 모터가 돌아도 걸쇠를 움직이는 부품이 헐거워졌거나 걸려 있는 경우입니다.
이때는 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보면 열리기도 합니다. / 문틀이 처져서 걸쇠가 눌려 있는 상태라면 그렇게 풀립니다.
그래도 안 열리면 더 힘주지 마세요. / 손잡이 축이 휘면 수리가 교체로 바뀝니다.

# 잠기다 마는 문, 반쯤 걸리는 문
문을 닫았는데 도어락이 끝까지 잠기지 않고 중간에서 멈추는 일도 있습니다. / 문이 제자리에 안 닿는 경우가 많아서 걸쇠 위치와 문틀 구멍이 어긋났을 가능성이 큽니다.
틈이 벌어졌는지 손으로 눌러 가며 닫아 보면 어느 쪽이 걸리는지 알 수 있습니다. / 사진으로 찍어서 문자로 보내주시면 도움이 됩니다.
이런 증상은 도어락을 바꿔도 해결되지 않을 수 있습니다. / 문 쪽을 같이 봐야 해서 현장에서 확인하고 말씀드립니다.
@ 성남 정자동 도어락 모터 소리만 날 때

# 터치가 안 먹거나 불이 깜빡일 때
번호판이 깜빡이거나 눌러도 반응이 늦으면 물기나 먼지를 먼저 의심합니다. / 마른 수건으로 닦고 잠시 두었다가 다시 눌러 보면 돌아오는 경우가 있습니다.
비 오는 날이나 겨울철 결로 때문에 일시적으로 그러는 일도 많습니다. / 며칠째 계속된다면 내부 기판 문제일 수 있으니 점검이 필요합니다.
번호판을 분해하거나 물을 직접 뿌려 닦는 것은 피해 주세요. / 기판에 닿으면 멀쩡하던 제품까지 못 쓰게 됩니다.

# 해볼 수 있는 것과 하지 말아야 할 것
먼저 할 수 있는 일은 많지 않습니다. / 건전지 교체, 번호판 닦기, 문 밀면서 열어 보기, 이 세 가지면 충분합니다.
하지 말아야 할 일은 분명합니다. / 드라이버로 외관을 뜯거나 윤활제를 열쇠 구멍에 듬뿍 뿌리는 일입니다.
윤활제는 처음엔 부드러워 보여도 먼지가 붙어 시간이 지나면 더 뻑뻑해집니다. / 필요하면 현장에서 맞는 방법으로 처리합니다.

# 건전지를 바꿀 때 주의할 점
건전지는 한두 개만 바꾸지 말고 전부 새것으로 바꿔야 합니다. / 새것과 헌것이 섞이면 전압이 불균형해져 경고음이 다시 나기 쉽습니다.
방향을 반대로 끼우면 작동하지 않으니 극을 맞춰서 넣어 주세요. / 덮개를 닫을 때 걸림 소리가 나는지도 확인하면 좋습니다.
교체한 날짜를 덮개 안쪽에 적어 두면 다음에 잊어버리지 않습니다. / 작은 습관이지만 효과가 큽니다.

# 정자동에서 연락 주실 때 알려주실 것
- 정자동 어느 쪽인지, 정자역에서 가까운지 여부 (대략이면 충분)
- 소리가 어떻게 나는지 (삑 횟수, 길이)
- 문이 지금 열려 있는지 닫혀 있는지
- 도어락 모양 사진 한 장
- 안에 사람이나 반려동물이 있는지
위치와 증상을 알면 필요한 부품을 챙겨 가서 한 번에 끝내기 좋습니다. / 문이 안 열리는 상황이라면 신분 확인 방법도 같이 안내해 드립니다.

# 현장에서는 이 순서로 봅니다
도착하면 먼저 소리와 건전지, 번호판 반응을 확인합니다. / 간단한 원인이면 현장에서 바로 끝냅니다.
부품 문제로 보이면 어느 부분이 어떻게 상했는지 보여드리고 설명합니다. / 바꿔야 하는지, 손봐서 쓸 수 있는지 두 가지를 모두 말씀드립니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다. / 문을 열어야 하는 경우의 작업 방식은 [현관문 개문](door-open.html) 페이지에서 볼 수 있습니다.
@ 성남 정자동 도어락 수리 점검

# 고쳐 쓸지, 바꿀지
같은 증상이 처음이라면 대부분 고쳐서 씁니다. / 건전지나 접점 청소, 걸쇠 조정으로 해결되는 경우가 많습니다.
반복해서 고장나거나 부품이 단종된 제품이면 바꾸는 쪽이 오래 갑니다. / 이때는 [도어락 수리](doorlock-repair.html)와 [도어락 교체](doorlock-replace.html)를 비교해서 말씀드립니다.
권하는 쪽이 아니라 상태에 맞는 쪽을 말씀드리는 게 원칙입니다. / 교체는 필요할 때만 이야기합니다.

# 비용은 시작 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 이야기합니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.

# 정자동 말고 분당 다른 동네도 갑니다
서현동, 수내동, 야탑동, 이매동, 구미동, 판교 쪽까지 성남 전역에서 출동합니다. / 위치를 알려주시면 도착 시간을 먼저 말씀드립니다.
성남에서 다니는 지역은 [성남시 출장열쇠](seongnam.html) 페이지에 정리했고, 서울과 경기 다른 곳은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 모터 소리만 나고 안 열리면 도어락을 바꿔야 하나요? | 먼저 걸쇠와 문틀 상태를 봅니다. 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

? 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 사진을 보내도 되나요? | 도어락 사진이 있으면 장비를 맞게 챙겨 갈 수 있어 도움이 됩니다.
