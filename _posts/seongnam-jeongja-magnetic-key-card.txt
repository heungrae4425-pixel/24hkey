# 정자동에서 카드키와 열쇠를 한꺼번에 잃어버렸다면
정자동은 정자역을 중심으로 출퇴근하는 분이 많은 동네입니다. / 아침저녁으로 지갑과 가방을 여닫다 보면 카드키가 어디선가 빠지는 일이 생깁니다.
특히 자석 방식 카드키와 휴대용 열쇠를 같은 열쇠고리에 달고 다니다 한꺼번에 잃어버리면 집에 들어갈 방법이 사라집니다. / 당황하기 쉬운 순간이라 순서를 먼저 정리했습니다.
이 글은 정자동에서 카드키와 열쇠를 잃었을 때 먼저 할 일과 [성남 출장열쇠](seongnam.html) 이용 순서를 적었습니다.
@ 정자동 자석 카드키와 휴대 열쇠 분실

# 먼저 정말 잃어버렸는지 찾아보기
분실했다고 단정하기 전에 오늘 입은 옷을 모두 뒤져 보세요. / 어제 입은 겉옷 주머니에 있는 경우가 의외로 많습니다.
가방 안쪽 주머니, 코트 안주머니, 차 안 컵홀더를 순서대로 살펴보세요. / 마지막으로 쓴 장소가 어디였는지 떠올려 보는 것도 도움이 됩니다.
정자역 근처 상점이나 식당에서 흘렸을 수도 있어 연락해 볼 만합니다. / 지하철이나 버스는 분실물 센터에 문의하는 방법이 있습니다.
찾는 동안에도 집에 가족이 있다면 먼저 문을 열어 달라고 부탁하세요.

# 자석 카드키란 무엇인가
겉모양은 교통카드나 작은 열쇠고리 모양으로 다양합니다. / 카드에 이름이나 주소가 인쇄돼 있지 않아 주운 사람이 곧바로 집을 알기는 어렵습니다.
자석 카드키는 카드 속 자기 정보나 작은 자석을 읽어 문을 여는 방식입니다. / 대는 순간 열리니 편하지만 카드 하나가 곧 열쇠입니다.
도어락 쪽 번호판이나 카드 인식부에 대면 반응해 열립니다. / 번호와 함께 쓰는 제품도 있고 카드만 쓰는 제품도 있습니다.
어떤 방식인지에 따라 분실 후 대처가 조금씩 달라집니다.

# 번호로도 열리는 제품이면 우선 번호로
카드와 번호를 함께 지원하는 제품이라면 번호로 열고 들어가면 됩니다. / 들어간 뒤에 분실한 카드를 지우는 것이 가장 중요한 순서입니다.
카드를 지우지 않고 두면 주운 사람이 쓸 수 있는 위험이 남습니다. / 그렇다고 지나치게 걱정하실 필요는 없고, 집에 들어가자마자 정리하시면 됩니다.
등록된 카드 목록을 한 번에 지우고 남은 카드만 다시 등록하는 제품도 있습니다.

# 카드만 쓰는 제품이면 어떻게 열까
번호가 없는 제품이면 카드가 없을 때 안에서만 열리고 밖에서는 방법이 없습니다. / 이때 비상 열쇠가 있는지 먼저 확인하세요.
열쇠도 같은 고리에 있었다면 도움을 받아야 합니다. / 억지로 문틈을 벌리거나 드라이버를 쓰면 도어락과 문이 상합니다.
[현관문 개문](door-open.html) 안내에서 최대한 덜 상하게 여는 방법을 소개하고 있습니다.

# 휴대 열쇠와 카드를 같이 잃었을 때 위험한 점
열쇠와 카드가 한 곳에 있으면 주운 사람이 집을 알아낼 방법도 있어 걱정이 됩니다. / 다만 보통 열쇠에는 주소가 적혀 있지 않아 바로 알기는 어렵습니다.
그래도 잃어버린 위치가 가깝다면 번호나 열쇠를 바꿔 두는 편이 마음이 놓입니다. / 현관 열쇠 실린더가 있다면 교체를 고민해 볼 만합니다.
불안이 크면 [도어락 교체](doorlock-replace.html) 안내를 참고하시되, 필요 이상으로 권하지 않습니다.
@ 정자동 분실 후 도어락 카드 목록 정리

# 문 앞에서 하지 말아야 할 것
시간이 늦으면 손쉬운 방법을 찾으려는 마음이 생깁니다. / 하지만 카드 대용으로 아무 카드나 대 보거나 도어락을 흔드는 일은 소용이 없습니다.
- 도어락 덮개를 억지로 열려고 하기
- 문틈에 칼이나 카드를 넣어 걸쇠를 밀기
- 인터넷 영상을 보고 도구로 직접 열어 보기
- 지인에게 임의로 열어 달라고 도구를 빌리기
이런 시도는 문틀과 도어락에 흠을 남기고 비용도 커집니다. / 그대로 두고 연락 주시는 편이 훨씬 안전합니다.

# 부를 때 알려주면 빠른 정보
정자동은 업무 시설과 주거 건물이 가까이 섞여 있어 건물 입구가 여러 곳인 경우가 있습니다. / 어느 입구에서 어느 층인지까지 말씀해 주시면 헤매지 않습니다.
정자동은 주소가 같아 보여도 건물과 호수가 많습니다. / 정확히 알려주시면 도착이 빨라집니다.
- 건물 이름 대신 길 이름과 동, 호수
- 정자역에서 어느 방향인지
- 도어락 모양과 번호판 있는지 여부
- 잃어버린 것이 카드인지 열쇠인지 둘 다인지
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 갑니다.

# 도착하면 먼저 신분 확인을 합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
열쇠와 지갑을 모두 잃은 상황이라 신분증도 없을 수 있습니다. / 그럴 땐 관리사무소에 세대 확인을 부탁하거나, 집 안에 있는 가족이 확인해 주는 방법을 같이 찾아봅니다.
확인이 어려우면 작업을 할 수 없으니 미리 방법을 생각해 두세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
상황을 보고 어떤 방법으로 얼마가 드는지 문을 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꾸는 일은 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열린 뒤에는 분실물 정리
등록된 카드 수가 몇 장인지 확인하면 몇 장이 남았는지 알 수 있습니다. / 가족 카드가 남아 있다면 새 카드는 그 카드와 구분되게 표시해 두면 좋습니다.
문이 열리면 등록된 카드와 번호를 먼저 정리합니다. / 잃어버린 카드를 지우고 새 카드를 등록하는 것까지 함께 합니다.
열쇠 실린더를 쓰는 제품이라면 새 열쇠를 만들거나 실린더를 바꾸는 방법도 설명드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
도어락이 낡아 반응이 느리면 [도어락 수리](doorlock-repair.html)로 먼저 손보는 방법도 있습니다.
@ 정자동 새 카드 등록과 작동 확인

# 다시 잃어버리지 않는 습관
휴대폰 케이스 뒷면에 카드를 꽂아 두는 분도 있지만 휴대폰을 잃으면 함께 사라집니다. / 가능하면 휴대폰과 따로 두세요.
카드와 열쇠를 같은 고리에 달지 말고 나눠 보관하세요. / 한쪽을 잃어도 다른 쪽으로 들어갈 수 있습니다.
카드 하나는 집 안 잘 보이지 않는 곳에 예비로 두세요. / 가족에게만 위치를 알려주고 번호도 서로 공유하면 든든합니다.
정자역 출퇴근 가방에 넣는 소지품은 한 곳에 모아 두는 습관이 도움이 됩니다.

# 정자동 말고 성남 어디든 갑니다
정자동 옆 서현동, 수내동, 구미동, 백현동, 판교 쪽도 다닙니다. / 성남 안이면 24시간 출동합니다.
동네는 [성남시 출장열쇠](seongnam.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

? 번호로 열 수 있으면 출장이 필요 없나요? | 네, 번호로 열리면 들어가서 분실한 카드를 지우시면 됩니다.
? 신분증도 같이 잃어버렸어요. | 관리사무소나 가족 확인 등 다른 방법을 같이 찾아봅니다. 전화로 상황을 말씀해 주세요.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
