# 삼평동 집 안쪽 작은 방 문이 안 열릴 때
판교역에서 삼평동 쪽으로 걸어 들어가면 직장인과 가족이 함께 사는 집이 이어집니다. / 현관은 도어락으로 잘 열고 들어왔는데 집 안 다락이나 창고방 문이 안 열려 곤란한 경우가 있습니다.
이런 문은 현관문과 달리 간단한 걸쇠나 작은 잠금장치가 달린 미닫이인 경우가 많습니다. / 평소에 거의 안 열어서 잠금이 굳어 있거나 열쇠가 어디 갔는지 모르는 일도 흔합니다.
이 글은 삼평동에서 다락·창고방 미닫이 문 잠금이 안 열리거나 안 잠길 때 확인할 순서를 적었습니다.
@ 삼평동 다락방 미닫이 문 잠금

# 다락과 창고방 문은 구조가 다릅니다
현관문은 두껍고 걸쇠와 데드볼트가 있는 구조지만 작은 방 미닫이는 가볍고 얇습니다. / 문틀 레일 위를 바퀴가 구르는 방식이라 잠금도 단순한 편입니다.
잠금도 종류가 다양해서 고리형 걸쇠, 작은 열쇠 걸림쇠, 문과 문틀을 맞물리는 갈고리형이 있습니다. / 어떤 형태인지부터 확인해야 대처 방법이 정해집니다.
안쪽에서만 잠기는 형태도 있어 밖에서 열쇠가 없으면 방법이 제한됩니다.
다락은 천장이 낮고 습기가 차기 쉬워서 나무 문틀이 부풀어 문이 뻑뻑해지는 일도 있습니다. / 여름 장마나 겨울 결로가 지난 뒤에 갑자기 안 열린다면 이런 경우를 의심해 볼 수 있습니다.
창고방은 물건을 문 쪽에 쌓아 두었다가 문이 물건에 눌려 안 움직이는 때도 있으니, 안쪽에 짐이 기대어 있진 않은지 생각해 보세요.

# 문이 안 열릴 때 먼저 확인할 것
힘으로 밀기 전에 아래를 차례로 보세요. / 대부분 간단한 원인입니다.
- 잠금 걸쇠가 걸려 있는지, 반쯤 걸려 있는지
- 문이 레일에서 벗어나 비스듬히 기울어 있지 않은지
- 레일 홈에 먼지나 물건 조각이 끼어 바퀴가 걸리지 않는지
- 문을 살짝 위로 들면서 옆으로 밀면 움직이는지
미닫이는 위로 아주 조금 들어 올리며 밀면 바퀴가 홈에 다시 걸려 움직이는 경우가 있습니다. / 억지로 당기면 문이 뒤틀립니다.

# 잠금이 헐거워서 문이 저절로 열릴 때
잠그고 나서도 문이 슬쩍 밀리거나 흔들린다면 잠금 부품이 헐거워진 것입니다. / 고정 나사가 풀렸거나 걸림쇠 위치가 문틀과 어긋난 경우가 많습니다.
나사를 조여도 맞지 않으면 걸림쇠를 문틀 쪽으로 조금 옮겨 달아야 합니다. / 구멍이 너무 헐거워진 경우는 부품을 바꾸는 것이 낫습니다.
@ 삼평동 창고방 미닫이 걸림쇠 위치

# 안에 사람이나 반려동물이 갇힌 경우
다락이나 창고방 안에 아이가 들어가 문이 닫혔다면 가장 먼저 침착하게 말을 걸어 주세요. / 아이가 놀라 문을 더 당기면 잠금이 더 꽉 걸릴 수 있습니다.
반려동물이 들어가 있는 경우도 마찬가지로 소리로 위치를 확인해 두세요. / 안에 있는 대상의 상태를 전화로 먼저 말씀해 주시면 우선순위를 정해 움직입니다.
통풍이 안 되는 좁은 공간에 오래 갇히면 위험할 수 있으니 시간을 끌지 마시고 연락 주세요.

# 열쇠가 어디 있는지 모를 때
평소에 안 쓰는 방 열쇠는 이사 때 서랍 속에 섞여 사라지기 쉽습니다. / 열쇠를 찾기 전에 문이 정말 잠겨 있는지도 확인해 보세요.
- 현관 열쇠 꾸러미 안에 작은 열쇠가 섞여 있는지
- 주방 서랍이나 신발장 안쪽에 보관 상자가 있는지
- 전 거주자에게 문의할 수 있는지
- 이사 때 받은 열쇠 봉투가 남아 있는지
열쇠가 있다 해도 오래돼 녹슬면 안 돌아갈 수 있습니다. / 억지로 돌리다 부러지면 훨씬 일이 커집니다.

# 이럴 때는 하지 마세요
작은 문이라고 해서 칼이나 드라이버로 틈을 벌려 열려는 경우가 있습니다. / 문틀이나 문짝에 흠이 나고 잠금 부품이 휘어 나중에 더 번거로워집니다.
문을 발로 차거나 어깨로 밀면 문 자체가 부서지고 레일이 휘어 문이 아예 움직이지 않게 됩니다. / 한 번 휜 레일은 다시 펴기 어렵습니다.
윤활유를 레일에 많이 뿌리면 먼지가 엉겨 붙어 더 안 움직입니다.

# 연락하실 때 알려주실 것
작은 문은 모양이 제각각이라 사진이 큰 도움이 됩니다. / 문자로 보내주시면 맞는 도구를 챙겨 갑니다.
- 문 전체 사진과 잠금 부분 가까운 사진
- 안에서만 잠기는지, 밖에서 열쇠가 필요한지
- 삼평동에서 대략 어느 쪽인지(판교역 방향 등)
- 안에 사람, 동물, 급히 필요한 물건이 있는지

# 도착하면 사시는 분인지 먼저 확인합니다
집 안 문이라도 확인 절차는 같습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안 잠긴 방 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.
세입자라면 집주인이 보관 중인 열쇠가 있는지 먼저 여쭤보셔도 좋습니다.

# 비용은 열기 전에, 못 열면 받지 않습니다
문 종류와 잠금 상태를 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
@ 삼평동 출장열쇠 미닫이 문 개방

# 연 뒤에 고쳐서 쓸 수 있게 정리합니다
문이 열리면 레일 청소와 바퀴 점검, 잠금 부품 조임을 함께 봅니다. / 간단한 조정으로 해결되면 부품을 바꾸지 않습니다.
잠금장치 자체가 낡았다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html) 중 필요한 것만 말씀드립니다. / 새 잠금을 달고 싶으시면 [도어락 설치](doorlock-install.html) 가능 여부도 문 상태를 보고 안내합니다.
열쇠를 아예 쓰지 않는 방이라면 잠금을 풀고 걸쇠만 남겨 두는 방법도 있습니다. / 어떻게 정리할지 편하게 말씀해 주세요.

# 작은 방 문을 오래 쓰는 방법
평소 쓰지 않는 문일수록 몇 달에 한 번 열고 닫아 줘야 레일과 잠금이 굳지 않습니다. / 이사 오시는 집이라면 처음 한 번 점검해 보시길 권합니다.
- 레일 먼지를 청소기로 빨아들이고 마른 천으로 닦기
- 바퀴가 닳았는지 눈으로 확인하기
- 잠금 걸림쇠 나사가 헐겁지 않은지 보기
- 열쇠가 있다면 두 개 이상 확인하고 한곳에 보관하기
작은 습관으로 막상 급할 때 문이 안 열리는 일을 줄일 수 있습니다.

# 삼평동 말고 성남 어디든 갑니다
삼평동 옆 백현동, 운중동, 정자동, 서현동, 야탑동도 다닙니다. / 성남 안이면 24시간 출동합니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html), 개문 방식은 [현관문 개문](door-open.html), 진행 방식은 [이용안내](guide.html)에서 보실 수 있습니다.

24시출장열쇠는 집 안 작은 문 하나도 소홀히 하지 않고 전화를 받습니다. / 성남 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
