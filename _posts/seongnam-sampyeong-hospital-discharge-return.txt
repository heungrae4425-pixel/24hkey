# 퇴원한 날, 집 앞에서 문이 안 열리면
삼평동은 판교역 생활권에 속해 있고 부모님 댁을 가까이 둔 가족도 많은 동네입니다. / 병원에서 퇴원해 힘들게 집 앞까지 왔는데 현관문이 열리지 않으면 부모님도 보호자도 지치기 쉽습니다.
입원 기간 동안 집을 비웠다가 돌아오는 날은 문 앞 사정이 평소와 다를 수 있습니다. / 이 글은 삼평동에서 그런 상황을 만났을 때 침착하게 확인할 순서를 적었습니다. [성남 출장열쇠](seongnam.html) 이용 방법도 함께 담았습니다.
@ 삼평동 퇴원 후 부모님 집 현관 앞 도어락 확인

# 먼저 부모님이 편히 계실 곳부터 정하세요
문제를 해결하기 전에 부모님을 어디에 모실지가 먼저입니다. / 퇴원 직후라면 찬 복도에 오래 서 있는 것만으로도 몸에 무리가 갑니다.
엘리베이터 앞 의자나 근처 가족 집, 차 안처럼 앉아서 쉴 곳을 먼저 마련하세요. / 문은 보호자가 대신 처리하고 부모님은 쉬시는 것이 좋습니다.
날씨가 춥거나 더운 날이면 더욱 서두르지 마세요. / 병원에서 받은 약이나 짐은 보호자가 먼저 챙겨 들고 계시면 됩니다.

# 오래 비운 집의 도어락에서 흔히 생기는 일
몇 주 동안 집이 비어 있으면 도어락 배터리가 서서히 닳습니다. / 사용하지 않아도 대기 전력은 계속 쓰이기 때문입니다.
부모님이 입원 전에 비밀번호를 바꿔 두고 잊어버렸을 수도 있습니다. / 입원 중에 다른 가족이 번호를 바꿨는데 공유가 안 된 경우도 있습니다.
오래 쓰지 않은 보조키나 걸쇠가 안쪽에서 잠긴 채인 경우도 가끔 있습니다. / 집을 나설 때 습관처럼 잠그고 나간 것이 원인이 되곤 합니다.
- 배터리 방전으로 번호판이 꺼진 경우
- 번호를 잊었거나 가족이 바꾼 번호를 모르는 경우
- 보조키가 잠겨 있는 경우
- 열쇠를 병원 짐 속에 두고 온 경우

# 번호판 상태부터 차분히 보세요
번호판이 켜지는지, 눌렀을 때 소리가 나는지 확인합니다. / 불이 안 들어오면 배터리 문제일 가능성이 높습니다.
소리는 나는데 열리지 않으면 번호가 틀렸거나 모터 쪽 문제일 수 있습니다. / 경고음이 길게 나면 배터리 부족 알림일 때가 많습니다.
번호를 여러 번 틀리면 도어락이 잠시 입력을 막습니다. / 서너 번 해보고 안 되면 쉬었다가 다시 해보세요.
@ 도어락 번호판 배터리 상태와 경고음 확인

# 9V 건전지로 비상 전원 넣어 보기
많은 도어락은 바깥쪽 아래에 9V 건전지를 대는 단자가 있습니다. / 건전지를 대면 그동안 전원이 들어와 번호를 누를 수 있습니다.
편의점이나 가까운 생활 상가에서 건전지를 구할 수 있습니다. / 건전지를 대고 번호를 눌렀을 때 열리면 안쪽 배터리를 모두 새것으로 바꾸세요.
단자가 없는 모델이거나 건전지를 대도 반응이 없으면 더 시도하지 마시고 전화 주세요.

부모님이 번호를 헷갈려 하셔도 괜찮습니다. / 퇴원 직후엔 컨디션 때문에 평소 외우던 것도 생각이 안 날 수 있습니다.
형제나 자녀에게 최근에 번호를 바꾼 적이 있는지 전화로 물어보세요. / 휴대폰 메모나 가족 단체방에 적혀 있을 수도 있습니다.
기억나는 번호를 여러 번 눌러 보는 것은 피해 주세요. / 입력 제한이 걸리면 오히려 시간이 더 걸립니다.

# 집 안에 아무도 없는데 잠긴 보조키
부모님이 입원하면서 안쪽 보조키를 잠가 두고 나갔다면 도어락 번호가 맞아도 문이 열리지 않습니다. / 이럴 때는 번호가 아니라 보조키가 원인입니다.
손잡이를 돌려도 문이 안쪽에서 걸린 느낌이면 이 경우를 의심해 보세요. / 억지로 힘을 주면 문틀이나 잠금 장치가 상합니다.
보조키가 걸린 채라면 일반 도어락 해결법으로는 열리지 않습니다. / 이때는 상황을 말씀해 주시면 해당 방식으로 준비해 갑니다.

# 하지 말아야 할 것
급한 마음에 문을 발로 차거나 어깨로 미는 일은 절대 피해 주세요. / 부모님이 놀라시고 문과 도어락도 상합니다.
드라이버로 문틈을 벌리거나 카드로 걸쇠를 밀어 보는 것도 권하지 않습니다. / 외관이 상하면 나중에 교체까지 가게 될 수 있습니다.
이웃에게 임의로 창문 같은 다른 통로를 부탁하는 일도 조심하세요. / 안전하지 않은 통로는 부모님 건강에 더 위험할 수 있습니다.

# 전화하실 때 알려주면 좋은 정보
- 삼평동 안에서 건물 위치와 호수
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 문이 안쪽에서 걸린 느낌인지
- 부모님 건강 상태나 지금 쉬고 계신 곳
- 도어락 모양(손잡이 일체형, 버튼형 등)
부모님이 급하게 쉬셔야 하는 상황이라면 꼭 먼저 말씀해 주세요. / 도착 순서와 준비를 그에 맞추어 안내합니다.
@ 출장열쇠 도착 전 문 앞 도어락 사진 준비

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 이 집에 사시는 분인지 먼저 확인합니다. / 부모님 댁이라면 부모님 신분증 주소나 주소가 적힌 우편물이 필요합니다.
신분증이 집 안이나 병원 짐 속에 있다면 관리사무소 확인으로 대신할 수 있습니다. / 보호자 신분증과 함께 가족 관계를 설명해 주시면 진행에 도움이 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다. / 번거로우셔도 이웃과 집 주인을 지키기 위한 절차입니다.

# 비용은 문을 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 들면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 문이 열린 뒤에 같이 점검할 것
문이 열리면 도어락이 다시 잘 열리고 잠기는지 같이 확인합니다. / 배터리가 원인이었다면 새 배터리로 교체했는지도 봅니다.
번호를 모르는 채 열었다면 새 번호를 등록하고 기존 번호는 지웁니다. / 부모님이 기억하기 쉬운 번호인지 함께 의논하면 좋습니다.
퇴원 직후라면 문 열고 닫는 동작이 부모님께 부담이 되는지도 살펴보세요. / 손잡이 방향이나 무게 때문에 힘드시면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)로 편한 방식을 상담하실 수 있습니다.

# 회복하시는 동안 도어락 설정 바꿔 보기
고령이거나 회복 중인 분이 쓰는 도어락은 단순할수록 좋습니다. / 번호판이 크고 소리가 또렷한 제품이 편합니다.
돌봄 인력이나 가족이 자주 드나든다면 임시 번호를 따로 쓰는 방법도 있습니다. / 일정 기간만 쓰고 지우면 관리가 훨씬 수월합니다.
보조키 사용은 필요한 만큼만 정하고 가족이 같이 알고 있도록 하세요. / 위급할 때 문 앞에서 막히지 않는 것이 가장 중요합니다.

# 삼평동 말고 성남 어디든 갑니다
삼평동 바로 옆 백현동, 운중동은 물론 정자동, 서현동, 야탑동, 태평동까지 성남 안은 24시간 출동합니다. / 판교역과 정자역, 서현역, 야탑역, 모란역 근처도 모두 갑니다.
다른 지역은 [출장 지역](area.html) 지도에서 보시고, 일반 개문은 [현관문 개문](door-open.html) 페이지를 참고하세요.

? 퇴원 직후라 급한데 밤에도 되나요? | 24시간 받습니다. 부모님 상태를 먼저 말씀해 주세요.

24시출장열쇠는 늦은 밤과 이른 새벽에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
