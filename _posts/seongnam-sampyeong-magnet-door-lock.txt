# 삼평동 출입문에서 자석 소리가 안 날 때
출입문은 한 사람이 쓰는 문이 아니라 여러 사람이 함께 쓰는 문입니다. / 그래서 원인을 찾는 순서를 정해 두면 누가 와도 같은 방식으로 확인할 수 있습니다.
삼평동은 판교역을 중심으로 사무실과 일터가 모여 있어 출입문 잠금장치 문의가 낮에도 이어지는 동네입니다. / 출근하자마자 사무실 문이 안 열리거나 퇴근 때 문이 안 잠기면 업무 전체가 멈춥니다.
이 글은 자석식 잠금장치가 풀리지 않거나 잠기지 않을 때 직접 확인할 순서를 정리했습니다. / 집 현관 도어락과는 구조가 달라 원인을 따로 보는 것이 좋습니다.
@ 삼평동 자석식 출입문 잠금장치 구조

# 자석식 잠금장치는 어떻게 작동하나
집 현관의 도어락은 걸쇠와 데드볼트가 문틀 구멍에 들어가 잠깁니다. / 자석식은 그런 금속 걸림이 없고 자석의 힘으로 문을 붙잡는 점이 가장 큰 차이입니다.
전자석이 문틀 쪽 금속판을 붙잡아 문을 잠그는 방식입니다. / 전기가 흐르는 동안만 붙고, 전기가 끊기면 풀리는 제품이 많습니다.
그래서 정전이나 전원 장치 고장이 곧 열림 문제로 이어집니다. / 반대로 전기가 계속 흐르는데 문이 풀리지 않으면 제어 쪽을 의심합니다.

# 문이 안 열릴 때 가장 먼저 볼 것
사무실이 잠긴 채 열리지 않으면 급한 업무에 쫓겨 문을 세게 당기게 됩니다. / 하지만 자석 잠금은 힘으로 당기면 오히려 문이나 문틀이 먼저 상합니다.
문에 붙은 장치를 직접 만지기 전에 전원 상태부터 확인하세요. / 건물 전체가 정전인지, 우리 사무실 구역만 그런지 구분하는 것이 첫걸음입니다.
- 전원 표시등이나 작은 램프가 켜져 있는지
- 인터폰이나 리더기 화면이 살아 있는지
- 같은 층 다른 문은 정상인지
- 최근에 두꺼비집이 내려간 일이 있었는지

# 전원 장치(어댑터)를 점검하세요
전원 장치는 시간이 지나며 내부 부품이 약해져 갑자기 꺼지는 일이 있습니다. / 표시등이 깜빡이거나 윙 하는 소리가 나면 수명이 다 돼 간다는 신호일 수 있습니다.
임의로 용량이 다른 어댑터로 바꾸면 잠금장치가 상할 수 있으니 같은 규격이 필요합니다.
자석 잠금은 보통 별도의 전원 공급 장치를 씁니다. / 천장이나 문 옆 박스 안에 있는 경우가 많아 한 번 열어 상태를 보세요.
표시등이 꺼져 있거나 플러그가 빠져 있으면 다시 꽂아 보세요. / 열이 심하게 나거나 타는 냄새가 나면 만지지 말고 연락 주세요.

# 문과 자석판이 어긋났을 때
자석이 붙는 금속판과 자석 본체가 서로 어긋나면 약하게 붙습니다. / 문이 처졌거나 오래 써서 경첩이 헐거워진 경우에 자주 생깁니다.
문을 닫았을 때 금속판이 자석 한가운데 닿는지 눈으로 확인하세요. / 이 어긋남은 [경첩 점검](door-open.html) 상담과 함께 보면 좋습니다.
@ 삼평동 자석판과 문틀 정렬 확인

# 자석에 먼지나 이물질이 붙었을 때
청소할 때는 전원이 켜져 있어도 자석 면 정도는 마른 천으로 닦아도 됩니다. / 다만 액체 세제를 뿌리면 내부로 스며들 수 있으니 피하세요.
자석 면에 먼지나 종이, 스티커 조각이 붙으면 접촉이 약해집니다. / 마른 천으로 살살 닦아 주세요.
오래 방치된 먼지는 습기와 만나 굳어서 붙는 힘을 떨어뜨립니다. / 도구로 긁지 말고 부드럽게 닦는 정도로만 하세요.

# 문이 안 풀리는 것과 안 잠기는 것은 다릅니다
퇴근할 때 문이 잠겼는지 확인하는 습관이 중요합니다. / 문을 밀었을 때 흔들리거나 쉽게 열리면 자석이 제대로 붙지 않은 것입니다.
반대로 잠기지 않는 경우는 전원이 끊겼거나 자석이 약해진 경우입니다. / 외부인이 쉽게 들어올 수 있어 빨리 점검이 필요합니다.
이 경우 임시로 열쇠나 다른 잠금으로 대신 잠가 두세요. / 근본 원인은 전원 확인과 장치 점검으로 찾습니다.

# 비상 해제 장치가 있는지 찾아보세요
건물마다 화재 등 비상 상황에서 문이 자동으로 풀리도록 설계된 곳이 있습니다. / 그런 연동이 있는 구역은 임의로 손대지 말고 관리 쪽 안내를 먼저 받으세요.
관리 구역의 출입문에는 비상 해제 버튼이나 키 스위치가 따로 있는 경우가 많습니다. / 위치는 문 옆 벽면이나 천장 쪽 박스 안입니다.
비상 상황에서 쓰는 장치라 평소에 위치를 직원들과 공유해 두는 것이 안전합니다. / 함부로 누르거나 전선을 만지지는 마세요.

# 이럴 땐 직접 하지 마세요
문이 안 열린다고 유리창이나 다른 경로로 억지로 들어가는 일도 위험합니다. / 연락을 주시면 문과 장치를 상하지 않게 여는 방법부터 차례로 시도합니다.
전선이나 단자를 만지다 감전되거나 단락이 날 수 있습니다. / 문을 억지로 당기면 자석판이 휘거나 문틀이 상합니다.
장치를 임의로 해체하면 건물 소방 설비와 연결된 경우 문제가 될 수 있습니다. / 의심되면 건물 관리 쪽과 함께 확인하세요.

# 전화하실 때 알려주면 좋은 정보
가능하면 문 위쪽과 옆쪽에 붙은 장치를 한 장씩 찍어 보내주세요. / 장치의 제조사 표시나 모델명이 보이면 더 좋습니다.
- 삼평동 어느 건물 몇 층인지(상호 말고 위치 위주로)
- 문이 안 풀리는지, 안 잠기는지
- 표시등이나 리더기 상태
- 정전 여부와 건물 관리실에 확인했는지
문 사진과 장치 사진을 보내주시면 챙길 장비를 정하기 좋습니다.

# 도착하면 먼저 확인하는 것
출입문은 여러 사람의 공간을 지키는 문이라 확인 절차를 건너뛰지 않습니다. / 번거로우시더라도 미리 서류나 연락처를 준비해 주시면 훨씬 빠릅니다.
문을 여는 일이라 사용하는 분이 맞는지 먼저 확인합니다. / 사업자 관련 서류나 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
회사 직원이라면 대표나 관리 담당자와 연결해서 확인하는 방법도 있습니다.

# 비용은 문 열기 전에 말씀드립니다
부품 교체가 필요하면 바꾸기 전에 따로 여쭙고 동의하실 때만 진행합니다. / 열고 난 뒤 말없이 붙는 비용은 없습니다.
장치 상태를 보고 작업 전에 먼저 비용을 안내합니다. / 괜찮다고 하실 때만 진행하고, 문을 못 열면 비용은 받지 않습니다.
@ 삼평동 출장열쇠 출입문 점검 현장

# 점검 뒤 재발 방지
진행 방식은 [이용안내](guide.html)에, 성남 안 다른 동네는 [성남 출장열쇠](seongnam.html)에 정리해 두었습니다. / 판교역 쪽 일터뿐 아니라 어느 동네든 24시간 출동합니다.
원인이 정리되면 전원 장치와 자석, 문 정렬을 다시 한 번 시험합니다. / 반복되는 문제라면 [도어락 수리](doorlock-repair.html)로 부품부터 손봅니다.
장치가 너무 오래됐다면 [도어락 설치](doorlock-install.html) 상담도 같이 가능합니다. / 꼭 필요하지 않은 교체는 권하지 않습니다.

자석식 출입문은 전원과 정렬만 봐도 원인이 좁혀지는 일이 많습니다. / 그래도 풀리지 않으면 전선을 만지지 마시고 연락 주세요.
