# 정전된 밤, 문 앞에서 가장 먼저 드는 걱정
삼평동은 판교역 근처로 퇴근 시간이 늦은 분이 많은 동네입니다. / 밤늦게 집에 오는데 건물 전체가 정전이면 엘리베이터도 서고 복도도 캄캄해서 현관 앞에서 마음이 급해집니다.
전자식 도어락은 전기가 필요한 물건이라 정전이 나면 안 열리는 건 아닌지 걱정하게 됩니다. / 실제로는 대부분 도어락이 건전지로 움직이기 때문에 건물 정전과는 상관없이 작동합니다.
이 글은 성남 삼평동에서 정전이 난 밤 전자식 도어락을 어떻게 써야 하는지, 그래도 안 열릴 때 어떻게 하는지 적었습니다. / [성남 출장열쇠](seongnam.html)에 전화하기 전에 확인해 보세요.
@ 삼평동 정전 밤 현관 도어락 앞

# 정전과 도어락 작동은 다른 문제입니다
가정용 전자식 도어락의 대부분은 건전지를 넣어 쓰는 방식입니다. / 그래서 건물이 정전이어도 건전지가 남아 있으면 번호를 눌러 열 수 있습니다.
다만 집 안 전기를 끌어 쓰는 방식이나 인터폰과 연결된 도어락은 정전의 영향을 받을 수 있습니다. / 모델에 따라 차이가 있으니 평소 어떤 방식인지 알아 두면 좋습니다.
정전 때문에 문이 안 열린다고 단정하기 전에 번호판에 불이 들어오는지부터 보세요.

# 번호판에 불이 들어오는지 확인
번호판을 손으로 한 번 덮었다 떼어 보세요. / 불이 들어오면 건전지는 살아 있다는 뜻입니다.
- 불이 들어오고 소리도 난다 → 정전과 무관하게 정상 작동
- 불이 안 들어온다 → 건전지 방전 가능성
- 불은 들어오는데 번호 입력 후 반응이 없다 → 모터나 걸쇠 쪽 문제
정전과 건전지 방전이 같은 날 겹치면 정전 탓으로 오해하기 쉽습니다. / 먼저 원인을 나눠 보는 것이 좋습니다.

# 복도가 캄캄할 때 번호를 정확히 누르는 법
정전 시 복도 불이 꺼져 있으면 번호판이 어디 있는지, 몇 번을 눌렀는지 알기 어렵습니다. / 휴대폰 손전등을 켜서 번호판을 비추고 한 자리씩 천천히 눌러 보세요.
너무 급하게 누르면 번호가 한두 개 빠지거나 틀려 입력이 막힐 수 있습니다. / 한두 번 틀렸다면 잠시 숨을 고르고 다시 하세요.
휴대폰 배터리가 얼마 안 남았다면 불빛을 아끼면서 번호판만 비추세요.

# 건전지가 다 됐다면 9V 비상 전원
많은 도어락은 바깥쪽 아래에 9V 건전지를 대는 비상 단자가 있습니다. / 건전지를 대고 있으면 전원이 들어와 번호를 누를 수 있습니다.
정전이라 가까운 편의점도 문을 닫았거나 불이 꺼져 있을 수 있습니다. / 평소에 비상용 9V 건전지를 가방이나 차에 하나 두면 이런 날 큰 도움이 됩니다.
단자가 없는 모델이거나 건전지를 대도 반응이 없으면 그때 전화 주세요.
@ 삼평동 도어락 9V 비상 전원 단자

# 열쇠 구멍이 숨어 있는 도어락도 있습니다
번호판 모양만 보이는 도어락도 덮개를 밀거나 눌러 열면 기계식 열쇠 구멍이 나오는 경우가 있습니다. / 열쇠를 들고 다니지 않았다면 소용없지만 차 열쇠 꾸러미나 가방 속에 오래된 열쇠가 남아 있는지 한번 찾아보세요.
덮개는 힘을 주면 부러지니 천천히 위아래나 옆으로 밀어 보세요. / 안 열리면 억지로 하지 마세요.
열쇠 구멍이 아예 없는 모델도 많으니 그럴 땐 비상 전원 쪽이 답입니다.

# 정전이 풀리면 오히려 오작동하기도 합니다
정전이 끝나고 전기가 다시 들어올 때 도어락이 한 번 리셋되며 이상 동작을 보이는 경우가 있습니다. / 번호판이 깜빡이거나 소리가 계속 나는 정도라면 건전지를 빼고 잠시 후 다시 끼워 보세요.
인터폰이나 공동 현관과 연결된 모델은 건물 전체 전원이 돌아온 뒤에도 몇 분간 반응이 느릴 수 있습니다. / 몇 분 기다린 뒤 다시 시도하는 편이 좋습니다.
번호가 지워지거나 초기화된 것 같다면 [도어락 수리](doorlock-repair.html)를 상담해 보세요.

# 정전 때 하지 말아야 할 일
- 어두운 곳에서 드라이버로 번호판 덮개를 뜯기
- 불안해서 같은 번호를 계속 눌러 입력 막힘 만들기
- 손잡이를 당기며 문을 흔들거나 발로 차기
- 열쇠 구멍에 아무 물건이나 넣어 보기
어두워서 평소보다 실수하기 쉽고, 한번 상한 도어락은 고치는 데 더 시간이 걸립니다. / 정전은 곧 끝나므로 여유를 갖는 편이 안전합니다.

집 안에 아이나 반려동물, 고령의 가족이 있다면 문 밖에서 시간을 끌지 않는 것이 좋습니다. / 겨울이라면 밖이 춥고 위험할 수 있으니 먼저 전화로 상황을 알려 주세요.
냉장고나 보일러 같은 집 안 설비가 걱정되더라도 문부터 안전하게 여는 것이 우선입니다.
엘리베이터가 서 있다면 층수가 높은 집은 계단으로 올라가야 하니 무리하지 마시고, 현관 앞에 도착한 뒤 상황을 전해 주세요.

# 전화하실 때 알려주실 것
삼평동은 판교역과 가까운 지역이라 건물 위치를 정확히 알리면 도착이 빨라집니다.
- 대략 위치(판교역 방향 등)와 건물 형태
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 건물 전체가 정전인지 우리 집만 그런지
- 집 안에 아이나 반려동물이 있는지
건물이 모두 정전이면 출입 자체가 어려울 수 있어 미리 알려 주시는 것이 좋습니다. / 도착 시간이 늘어질 수 있는 점도 솔직하게 말씀드립니다.

# 도착하면 사시는 분인지 먼저 확인합니다
정전된 밤이라도 문을 여는 일이라 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
어두운 밤일수록 확인이 더 중요하니 번거로우셔도 이해해 주세요. / 신분증이 집 안에 있다면 경비실이나 관리사무소 확인을 부탁해 보세요.
@ 삼평동 출장열쇠 신분 확인 절차

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다. / 작업 방식은 [현관문 개문](door-open.html) 안내를 참고하세요.

# 정전 대비로 평소에 해둘 것
- 배터리는 해가 바뀔 때쯤 전부 새것으로 교체
- 경고음이 나면 그날 바로 건전지 교체
- 비상용 9V 건전지를 가방이나 차에 하나 보관
- 기계식 열쇠가 있는 모델이면 예비 열쇠를 가족과 나눠 보관
도어락이 낡았거나 자주 오작동한다면 [도어락 교체](doorlock-replace.html)를 한 번 상담해 보세요. / 기계식 열쇠 구멍이 있는 모델은 이런 날 든든합니다.

# 삼평동 말고 성남 어디든 갑니다
삼평동 바로 옆 백현동, 운중동, 판교 주변도 다닙니다. / 성남 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

# 자주 묻는 질문
? 정전이면 도어락이 아예 안 열리나요? | 대부분 건전지로 작동하므로 정전과 무관하게 열립니다. 번호판이 꺼졌다면 건전지 방전을 의심해 보세요.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 건물 전체 정전인데도 오시나요? | 네, 접근이 가능하면 갑니다. 도착이 늦어질 수 있는 점은 미리 말씀드립니다.
? 밤늦게나 새벽에도 전화해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 정전 뒤 번호가 지워졌어요. | 새 번호 등록과 상태 점검까지 도와드립니다.
