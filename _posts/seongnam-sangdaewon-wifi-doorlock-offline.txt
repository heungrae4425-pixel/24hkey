# 상대원동 도어락이 앱에서 오프라인이라고 뜰 때
상대원동은 모란역 생활권과 이어져 일터와 주거가 함께 있는 동네입니다. / 출퇴근 시간이 제각각이라 도어락 앱으로 문 상태를 확인하는 분이 많습니다.
어느 날 앱을 열었더니 도어락이 오프라인이라고 뜨고 알림도 오지 않는다면 걱정이 앞섭니다. / 하지만 문이 안 열리는 것과 앱에서 안 보이는 것은 다른 문제입니다.
이 글은 상대원동에서 와이파이 연동 도어락이 오프라인으로 뜰 때 확인 순서를 적은 글입니다.
@ 상대원동 도어락 앱 오프라인 표시 화면

# 먼저 문 자체는 열리는지 확인
상대원동에서 이런 문의를 주시는 분은 대개 앱 알림이 한동안 끊긴 뒤 처음 발견하십니다. / 그래서 언제부터 안 보였는지 기억해 두면 원인 찾기가 쉬워집니다.
오프라인이어도 번호나 카드, 열쇠로는 열리는 경우가 대부분입니다. / 문이 열리면 급한 일은 아니니 차분히 원인을 찾으시면 됩니다.
반대로 번호도 안 눌리고 번호판이 꺼져 있다면 연결이 아니라 전원 문제입니다. / 그때는 배터리부터 의심하세요.
앱 문제인지 문 문제인지를 가르는 것이 첫 단계입니다.

# 오프라인이 되는 흔한 원인
- 공유기가 꺼졌거나 인터넷이 끊긴 경우
- 와이파이 이름이나 비밀번호를 바꾼 경우
- 도어락 배터리가 약해져 통신이 먼저 끊긴 경우
- 도어락 연결 장치가 공유기와 멀어진 경우
- 앱 계정이나 로그인이 풀린 경우
전기가 약해지면 통신 기능부터 멈추는 제품이 많습니다. / 문은 열리는데 오프라인만 뜬다면 배터리를 먼저 점검해 보세요.

# 공유기부터 살펴보기
정전이나 점검으로 인터넷이 잠깐 끊겼다 돌아온 뒤 도어락만 연결이 안 되는 일도 흔합니다. / 공유기가 다시 켜지면서 주소를 새로 나눠 주는데 도어락이 그걸 못 따라오는 경우입니다.
같은 와이파이를 쓰는 다른 기기, 예를 들어 휴대폰이나 TV가 인터넷이 되는지 봅니다. / 안 된다면 도어락이 아니라 공유기나 인터넷 문제입니다.
공유기 전원을 껐다 켜면 풀리는 경우가 많습니다. / 켜진 뒤 몇 분은 기다려야 도어락이 다시 연결됩니다.
공유기를 교체했거나 설정을 초기화한 적이 있다면 도어락도 다시 등록해야 합니다.

# 도어락과 공유기의 거리
현관문 바깥쪽은 벽과 철문 때문에 신호가 약합니다. / 공유기가 방 안쪽 깊은 곳에 있으면 문 앞까지 신호가 잘 닿지 않습니다.
연결 장치가 따로 있는 제품은 그 장치를 현관 가까이에 두는 편이 낫습니다. / 위치만 옮겨도 오프라인이 사라지는 경우가 있습니다.
상대원동처럼 복도가 길거나 철문이 두꺼운 집은 신호가 잘 막히기도 합니다.

# 와이파이 주파수와 이름 확인
집에 와이파이 증폭기를 새로 달았다면 이름이 같아도 신호가 다르게 잡힐 수 있습니다. / 도어락은 가까운 신호에 붙는 경우가 많아 증폭기를 거치면 불안정해지기도 합니다.
도어락 중에는 특정 주파수만 연결되는 제품이 있습니다. / 공유기가 두 주파수를 같은 이름으로 쓰면 연결이 헷갈리기도 합니다.
공유기를 바꾼 뒤 이름이나 비밀번호가 달라졌다면 도어락 쪽에 새로 입력해 줘야 합니다. / 앱의 연결 설정 메뉴에서 다시 등록하는 방식이 일반적입니다.
제품마다 방식이 달라 설명서를 같이 보시길 권합니다.
@ 상대원동 공유기와 도어락 연결 장치 위치

# 배터리와 전원 점검
통신하는 도어락은 일반 제품보다 전기를 더 씁니다. / 번호판 반응이 느려지거나 경고음이 가끔 난다면 배터리가 약해진 신호일 수 있습니다.
건전지는 일부만 바꾸지 말고 모두 새것으로 바꿔 주세요. / 섞어 쓰면 전압이 고르지 않아 통신이 불안정해집니다.
번호판이 꺼졌다면 바깥 비상 단자에 9V 건전지를 대어 열고 배터리를 교체하는 순서로 하세요.

# 앱 쪽에서 해 볼 것
앱이 문제인지 확인하려면 가족의 휴대폰으로 같은 계정에 접속해 보세요. / 가족 폰에서는 정상이라면 내 휴대폰 설정 문제입니다.
앱을 완전히 종료했다가 다시 열어 보세요. / 로그인이 풀렸다면 다시 로그인하면 됩니다.
앱이 오래된 버전이면 업데이트 후 다시 확인해 보세요. / 휴대폰이 절전 모드이거나 앱 알림이 꺼져 있어도 알림이 오지 않습니다.
계정을 가족과 함께 쓴다면 누가 마지막으로 설정을 바꿨는지도 확인해 보시면 좋습니다.

# 도어락을 앱에서 지우고 다시 등록하기
위 방법으로 안 풀리면 앱에서 도어락을 삭제하고 다시 등록하는 방법이 있습니다. / 이때 도어락에 저장된 번호나 카드가 지워지는 제품이 있습니다.
삭제하기 전에 등록된 비밀번호와 카드 목록을 메모해 두세요. / 어떤 제품이 어떻게 되는지는 설명서를 먼저 확인하시길 권합니다.
잘 모르시면 지우기 전에 전화로 물어보세요. / 잘못 지우고 다시 설정하지 못하는 일이 종종 있습니다.

# 문이 안 열리면서 오프라인일 때
번호가 안 눌리고 앱도 오프라인이라면 전원이 완전히 나간 경우입니다. / 이때는 앱으로 열 방법이 없으니 비상 전원이나 열쇠를 먼저 쓰세요.
열쇠가 집 안에 있다면 [현관문 개문](door-open.html) 안내를 보시고 전화 주세요. / 열쇠로 잠그고 나온 경우는 [열쇠 출장](key-call.html) 안내도 도움이 됩니다.
억지로 문을 당기거나 도구로 틈을 벌리는 일은 하지 마세요.

# 출장열쇠가 하는 점검
방문 전에 전화로 제품 이름과 증상을 들으면 필요한 부품을 챙겨 갈 수 있습니다. / 연결 장치 전원 어댑터나 배터리 같은 작은 부품이 원인인 경우가 많습니다.
방문하면 문이 정상 작동하는지부터 보고, 배터리와 통신 상태를 확인합니다. / 와이파이 설정은 공유기 정보가 필요해서 가능한 범위에서 같이 진행합니다.
연결 장치를 옮기거나 다시 등록하는 일, 고장 부품이 있는지 보는 일을 순서대로 합니다. / 수리로 될지 교체가 나을지는 [도어락 수리](doorlock-repair.html)와 비교해서 말씀드립니다.
공유기 자체 설정은 통신사나 공유기 제조사 안내가 필요할 수 있다는 점도 미리 알려드립니다.

# 신분 확인과 비용 안내
문을 열거나 도어락을 손보기 전에 사시는 분이 맞는지 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나로 먼저 확인합니다. / 비용은 작업 시작 전에 먼저 말씀드리고 동의하시면 진행합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.
@ 상대원동 도어락 통신 상태 점검 장면

# 상대원동 말고 성남 어디든 갑니다
상대원동 옆 금광동, 은행동, 도촌동, 단대동과 서현·정자·야탑·판교 쪽도 다닙니다. / 성남 안이면 24시간 출동합니다.
동네는 [성남시 출장열쇠](seongnam.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
