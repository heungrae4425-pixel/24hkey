# 서현동 계단실 방화문 앞에서 갇혔다면
서현동은 서현역 생활권에 높은 건물이 많은 동네입니다. / 층마다 엘리베이터 홀과 계단실을 나누는 방화문이 있고, 이 문이 닫히며 잠겨 곤란해지는 분이 있습니다.
잠깐 분리수거를 하러 나왔다가 방화문이 닫혔는데 반대편에서 손잡이가 돌아가지 않는 일이 대표적입니다. / 현관은 이미 닫혀 있어 오도 가도 못하는 상황이 됩니다.
이 글은 서현동에서 이런 일이 생겼을 때 먼저 할 일과 [성남 출장열쇠](seongnam.html)를 부르는 순서를 적었습니다.
@ 서현동 엘리베이터 홀 방화문 앞

# 방화문은 왜 저절로 닫히고 잠길까
건물이 높을수록 방화문의 문닫개 힘이 강해 문이 빠르게 닫힙니다. / 손을 놓는 순간 닫히기 때문에 생각할 틈이 없습니다.
방화문은 불이 번지지 않게 평소에도 닫혀 있도록 만든 문입니다. / 위쪽에 달린 문닫개가 문을 끝까지 끌어 닫습니다.
문이 닫히면 걸쇠가 걸려 한쪽에서는 열리고 한쪽에서는 안 열리는 구조인 경우가 많습니다. / 계단 쪽에서는 손잡이가 안 돌아가기도 합니다.
이 구조를 모르고 나갔다가 잠겨 버리는 일이 생깁니다.

# 잠기는 대표적인 상황
서현역에서 오가는 길에 장바구니를 든 채 문을 열다 보면 손이 모자라 문이 닫힙니다. / 그럴 때 가장 많이 놓고 가는 것이 휴대폰입니다.
- 쓰레기를 버리러 계단실 쪽으로 나갔다가 닫힌 경우
- 이사 짐을 옮기다 문을 열어 두었는데 닫힌 경우
- 아이가 장난으로 문을 밀어 닫은 경우
- 계단으로 내려갔다가 다른 층에서 문이 안 열리는 경우
공통점은 휴대폰이나 열쇠를 집 안에 두고 나온 경우가 많다는 것입니다. / 이웃에게 도움을 청하기도 어려운 늦은 시간이면 더 힘듭니다.

# 가장 먼저 침착하게 확인할 것
문 아래 틈이나 유리창이 있으면 안쪽 불빛이나 사람 소리가 들리는지 살펴보세요. / 안에 누가 있다면 두드려서 알릴 수 있습니다.
문 손잡이 위아래에 열림 방향을 알려주는 안내가 있는지 보세요. / 밀어서 열리는 문인지 당겨서 열리는 문인지를 헷갈린 경우도 있습니다.
손잡이를 세게 흔들지 말고 천천히 돌려 보세요. / 걸쇠가 문틀에 걸린 정도라면 문을 살짝 밀어 주며 돌리면 빠지기도 합니다.
그래도 안 열린다면 억지로 힘을 주지 마시고 다음 단계로 넘어가세요.

# 같은 층이나 아래층 이웃에게 도움 청하기
엘리베이터 홀에서 이웃집 초인종을 누르고 전화를 빌릴 수 있습니다. / 한밤이라면 놀라지 않게 한 번만 짧게 눌러 주세요.
이웃의 전화로 가족에게 연락해 집 안에서 열어 줄 사람이 있는지 확인하세요. / 가족이 안에 있다면 현관 문을 열어 방화문 쪽으로 나올 수 있습니다.
관리사무소나 경비실에 도움을 청하는 방법도 있습니다.
@ 서현동 계단실 방화문 걸쇠 상태 확인

# 현관은 이미 닫혔는데 방화문까지 잠겼을 때
이런 경우 방화문과 현관문 두 군데가 모두 잠겨 두 번 막힌 셈입니다. / 어느 문부터 열어야 하는지 정리가 필요합니다.
일반적으로 방화문이 열려야 현관 앞으로 갈 수 있으니 먼저 방화문부터 해결합니다. / 방화문을 지나 현관 앞에 가면 현관의 번호나 카드로 열 수 있는지 봅니다.
둘 다 막혔다면 한 번에 상황을 설명해 주시면 순서를 안내해 드립니다.

# 건물 공용 문이면 관리사무소 확인이 먼저
공용 문에는 소방 관련 장치가 연결돼 있는 경우도 있습니다. / 임의로 분해하면 안 되는 이유입니다.
방화문은 개인 집의 문이 아니라 건물 공용 시설입니다. / 그래서 함부로 건드리면 안 되는 부분이 있습니다.
공용 문을 열거나 손볼 때는 관리사무소 확인이 먼저 필요한 경우가 있습니다. / 이 점은 도착해서 상황을 보고 같이 정리합니다.
세대 현관문과는 접근 방식이 다르다는 점을 알아 두세요. [현관문 개문](door-open.html) 안내도 참고하실 수 있습니다.

# 전화할 때 이렇게 알려주세요
이웃 전화를 빌린 상태라면 그 번호로 다시 연락드릴 수 있게 번호를 말씀해 주세요. / 통화가 끊겨도 바로 이어가기 위해서입니다.
서현동은 건물 층과 호수가 많아서 위치가 정확해야 빠릅니다. / 다음 정보를 간단히 말씀해 주세요.
- 건물 길 이름과 동, 층
- 서현역에서 어느 방향인지
- 갇힌 곳이 방화문 안쪽인지 바깥쪽인지
- 현관문이 같이 잠겼는지
- 집 안에 아이나 반려동물이 있는지
방화문과 문닫개 사진이 있으면 문자로 보내 주시면 준비가 쉽습니다.

# 집 안에 아이나 반려동물이 있다면 먼저 말씀해 주세요
서현동 같은 고층 건물은 밖에서 소리가 잘 안 들려 안쪽 상황을 알기 어렵습니다. / 그래서 접수 때 알려주시는 정보가 더 중요합니다.
혼자 있는 아이가 불안해하면 상황이 급해집니다. / 이 경우는 접수 단계에서 먼저 알려주세요.
문 너머로 계속 말을 걸어 아이를 안정시키고 가스불이나 전기 제품이 켜져 있는지도 확인해 알려주세요. / 상황에 따라 순서를 앞당겨 안내해 드립니다.
반려동물이 있는 경우는 문을 여는 순간 뛰어나갈 수 있어 미리 알려주시는 게 좋습니다.

# 도착하면 먼저 신분 확인을 합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두시면 수월합니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
방화문과 세대 현관이 모두 잠긴 경우도 한 번에 정리해서 말씀드립니다. / 두 번에 나눠 따로 놀라지 않으시게 하는 것이 원칙입니다.
상황을 보고 어떻게 할지, 비용은 어떻게 되는지 문 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.
@ 서현동 출장열쇠 도착 후 신분 확인

# 같은 일이 다시 생기지 않게
계단실로 나가야 할 일이 있으면 가족에게 미리 말하고 나가는 것도 방법입니다. / 안에서 소리가 나면 열어 줄 수 있습니다.
쓰레기를 버리러 나갈 때는 휴대폰을 꼭 챙기세요. / 방화문 아래에 문고리를 괴는 것은 안전 규정과 이웃에게 문제가 될 수 있어 피해 주세요.
현관 열쇠를 신발이나 주머니에 하나씩 넣어 두는 습관이 도움이 됩니다. / 카드키를 가진 가족과 시간을 맞춰 나가는 것도 방법입니다.
문 닫개가 너무 세게 닫히면 관리사무소에 점검을 요청하세요. / [도어락 수리](doorlock-repair.html)가 필요한 세대 문과는 다른 부분입니다.

# 서현동 말고 성남 어디든 갑니다
서현동 옆 수내동, 야탑동, 이매동, 정자동, 판교 쪽도 다닙니다. / 성남 안이면 24시간 출동합니다.
동네는 [성남시 출장열쇠](seongnam.html)에, 다른 지역은 [출장 지역](area.html)에 있습니다.
