# 서현동에서 얼굴로 여는 도어락, 어떨까요
서현동은 서현역 주변으로 상가와 주거지가 이어져 있어 사람 오가는 일이 많은 동네입니다. / 요즘은 열쇠 없이 얼굴만 보여 주면 열리는 도어락을 문의하는 분들도 늘었습니다.
얼굴 인식 도어락은 편해 보이지만 모든 집에 같은 만족을 주지는 않습니다. / 사기 전에 짚어 볼 것이 몇 가지 있습니다.
이 글은 [성남 출장열쇠](seongnam.html)가 설치 문의를 받으며 자주 설명하는 순서를 그대로 옮겼습니다. / 어떤 제품이 좋다고 추천하는 글이 아니라, 우리 집에 맞는지 가려내는 기준을 적었습니다.

# 얼굴 인식이 어떤 방식인지부터
얼굴 인식 도어락은 문 앞에 서면 카메라나 센서가 얼굴 특징을 읽어 열어 주는 장치입니다. / 제품마다 읽는 방식과 필요한 거리가 달라서 설명서 확인이 중요합니다.
손이 비어 있지 않을 때 편하다는 점이 가장 큰 장점으로 꼽힙니다. / 장바구니나 아이를 안고 있을 때 번호를 누르지 않아도 되니까요.
다만 어떤 방식이든 번호나 열쇠 같은 보조 수단이 같이 있는 제품이 대부분입니다. / 얼굴만으로 되는 장치를 기대하지 말고 대체 수단이 무엇인지 보세요.

# 내 집 문에 달 수 있는지 먼저 재기
도어락은 문 두께와 구멍 모양이 맞아야 설치됩니다. / 얼굴 인식 제품은 본체가 크고 무거운 편이어서 문이 얇거나 오래된 경우 더 신경 써야 합니다.
기존 도어락의 모양, 문 두께, 보조키 위치를 사진으로 찍어 두세요. / 자세한 측정 요령은 [도어락 설치](doorlock-install.html) 안내에 적어 두었습니다.
문 안쪽에 철판이 덧대어진 경우나 문틀과 간격이 좁은 경우 맞는 제품이 제한될 수 있습니다. / 사진을 보내주시면 설치 가능 여부를 먼저 말씀드립니다.

# 전원은 건전지인가 전기선인가
얼굴 인식은 센서를 계속 대기시켜야 해서 일반 번호키보다 전기를 더 씁니다. / 건전지 방식이면 교체 주기가 짧아질 수 있습니다.
전기선을 연결하는 방식은 문 틈으로 선을 지나가게 해야 해서 공사가 따로 필요합니다. / 건전지와 전기선을 같이 쓰는 제품도 있으니 설명서를 확인하세요.
정전이 났을 때 어떻게 되는지 꼭 물어보세요. / 전기가 나가도 비상 전원으로 열 수 있는지가 얼굴 인식 도어락을 고를 때 가장 중요한 질문입니다.

# 인식이 안 되는 순간을 미리 상상해 보기
마스크, 모자, 안경, 어두운 밤, 역광 같은 조건에서 인식이 달라질 수 있습니다. / 제품 설명서에 적힌 조건과 실제 현관 앞 환경은 다를 수 있습니다.
현관 앞이 유난히 밝은 집, 복도 조명이 어두운 집은 인식 상태를 직접 시험해 보세요. / 눈이 오는 날이나 장마철에 렌즈에 물기가 맺히는 것도 생각해 볼 일입니다.
인식이 한두 번 실패했을 때 자연스럽게 번호로 넘어갈 수 있는지도 봅니다.
@ 현관 앞 조명과 센서 위치를 점검하는 모습

# 비상 상황에서 열 방법이 있는가
이 항목이 가장 중요합니다. / 배터리가 나갔을 때, 센서가 고장 났을 때 열 수 있는 마지막 길이 있어야 합니다.
기계식 열쇠를 같이 쓰는 제품은 마지막 보루가 분명합니다. / 열쇠 구멍이 없는 제품이라면 비상 전원 단자가 있는지 확인하세요.
이런 대비가 없으면 문이 안 열릴 때 고칠 방법도 줄어듭니다. / 그럴 때는 신분 확인 뒤 [현관문 개문](door-open.html)으로 상태를 보고 방법을 정합니다.

# 가족 얼굴 등록은 어떻게 할까
처음 설정할 때 가족 얼굴을 한 사람씩 등록합니다. / 아이는 자라면서 얼굴이 변하므로 시간이 지나면 다시 등록해야 할 수 있습니다.
어르신은 천천히 다가오는 경우가 많아 인식 거리를 직접 시험해 보면 좋습니다. / 등록하는 순간 카메라 높이가 너무 높으면 아이가 못 쓰기도 합니다.
얼굴 외에 비밀번호도 꼭 함께 등록해 두세요. / 얼굴이 안 될 때 가족이 같은 번호로 들어오는 습관이 있어야 합니다.

# 개인 정보와 기록, 어떻게 다뤄지는지
얼굴 정보가 장치 안에 저장되는지, 바깥 서버로 가는지는 제품마다 다릅니다. / 설명서에서 저장 방식과 삭제 방법을 확인해 보세요.
중고나 이사 때 정보를 지울 수 있는지도 중요합니다. / 이사를 나가거나 도어락을 교체할 때 등록 정보를 초기화하는 방법을 알아 두면 안심입니다.
법적 판단이 필요한 부분은 제조사 안내를 따르시는 것이 맞습니다. / 저희는 문과 도어락이 실제로 어떻게 작동하는지 위주로 설명드립니다.

서현동처럼 상가와 주거지가 가까운 곳은 현관 앞을 지나는 사람이 많아 센서가 의도치 않게 반응하는 경우도 있습니다. / 센서 감도를 조절할 수 있는 제품인지도 알아 두면 좋습니다.

# 지금 쓰는 도어락 그대로 두는 것도 선택
얼굴 인식이 꼭 필요한가를 한 번 더 생각해 보세요. / 번호키나 카드키로 충분히 편하고 안정적이라면 바꾸지 않아도 됩니다.
고장이 잦은 도어락이라 바꾸려는 것이라면 먼저 [도어락 수리](doorlock-repair.html)로 고칠 수 있는지 봅니다. / 교체는 꼭 필요할 때만 권해 드립니다.
비용은 설치 전에 먼저 말씀드리고, 동의하신 뒤에 시작합니다.

주변에서 좋다고 해서 바꾸기보다 우리 가족이 어떤 순간에 가장 불편한지부터 적어 보세요. / 아침 출근길, 아이 하교, 장보고 오는 길 중 어디서 불편한지에 따라 필요한 기능이 달라집니다.
