# 서현동에서 현관문이 안 열린다면
서현동은 서현역 주변으로 아파트와 상가가 이어진 분당의 중심 생활권입니다. / 늦게까지 영업하는 가게가 많아 밤늦게 귀가하는 분들도 흔합니다.
문 앞에 서서 몇 번 눌러도 반응이 없으면 마음이 급해집니다. / 이때 원인을 잘 구분하면 불러야 할지 아닐지 훨씬 빨리 판단할 수 있습니다.
이 글은 서현동에서 현관문이 안 열릴 때 원인별로 나눠 보는 방법을 적었습니다. / 직접 해결이 안 되면 [성남 출장열쇠](seongnam.html)에 전화 주시면 됩니다.
@ 서현동 현관문 안 열림 출장열쇠

# 먼저 문 앞 상황을 정리합니다
급할수록 상황을 말로 정리해 보세요. / 정리가 되면 판단이 빨라지고 전화로 설명하기도 쉬워집니다.
- 번호판에 불이 들어오는지
- 번호를 누르면 소리가 나는지
- 키나 카드를 쓰는 도어락인지
- 문이 열린 적이 오늘 한 번이라도 있었는지
이 네 가지만 알아도 원인은 대부분 두세 가지로 줄어듭니다. / 지금 문 앞이라면 하나씩 눌러 보며 확인하세요.

# 번호판이 아예 꺼져 있다면
전원 문제입니다. / 건전지가 다 됐거나 연결이 끊어진 경우입니다.
도어락 아래쪽에 비상 전원 단자가 있는 제품이라면 9V 건전지를 대고 번호를 눌러 볼 수 있습니다. / 건전지를 대고 있는 동안만 전원이 들어옵니다.
단자가 없거나 건전지를 대도 반응이 없으면 안쪽 배터리 칸이 문제일 수 있습니다. / 이때는 바깥에서 할 수 있는 일이 거의 없습니다.

# 불은 들어오는데 안 열리는 경우
번호는 맞게 눌렀는데 여전히 안 열리면 비밀번호를 잊었거나 바뀐 걸 모르는 경우도 있습니다. / 가족이 바꿨는지 전화로 확인해 보세요.
소리가 나는데 모터가 안 도는 경우는 건전지가 거의 바닥인 상태일 수 있습니다. / 비상 전원을 대면 열리는 일이 많습니다.
몇 번 연속으로 틀렸다면 도어락이 입력을 잠시 막고 있을 수 있습니다. / 몇 분 기다렸다가 다시 시도해 보세요.

# 안에서 잠그고 나온 경우
안쪽 보조 잠금이나 걸쇠를 걸어둔 채 문을 닫고 나오는 경우가 의외로 많습니다. / 보조키가 걸려 있으면 밖에서 번호를 눌러도 열리지 않습니다.
이 경우는 도어락 고장이 아니라서 부품 교체는 필요 없는 경우가 대부분입니다. / 문을 안 상하게 여는 것으로 끝납니다.
아이가 안에서 돌려 잠근 경우라면 먼저 말씀해 주세요. / 아이 안전이 우선이라 순서를 다르게 합니다.
@ 서현동 도어락 비밀번호 번호판 점검

# 문이 눌려서 안 빠지는 경우
오래된 아파트는 문이 조금씩 처져서 걸쇠가 문틀에 눌리는 일이 있습니다. / 번호는 맞게 눌러지고 모터 소리도 나는데 문이 안 열리는 경우입니다.
문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 걸쇠가 풀리며 열리기도 합니다.
이런 일이 자주 있다면 도어락보다 문틀과 경첩을 봐야 합니다. / 현장에서 상태를 보고 필요한 부분만 말씀드립니다.

# 해서는 안 되는 일
문을 발로 차거나 어깨로 밀면 문틀과 도어락이 같이 상합니다. / 열리지도 않고 수리 범위만 커집니다.
드라이버나 카드로 문틈을 벌리는 것도 외관을 크게 해칩니다. / 문틈에 칼을 넣는 시도도 위험합니다.
비밀번호를 수십 번 연달아 누르는 것도 좋지 않습니다. / 서너 번 해보고 안 되면 멈추는 게 맞습니다.

# 서현동에서 전화 주실 때
위치를 정확하게 알려주시면 도착이 빨라집니다. / 서현동은 단지가 많아서 이름보다 동, 호수가 더 중요합니다.
- 서현동 몇 단지 몇 동, 호수
- 서현역에서 어느 방향인지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 도어락 모양 사진 한 장
- 집 안에 아이나 반려동물이 있는지
이 정보가 있으면 맞는 장비를 챙겨서 한 번에 처리하기 좋습니다. / 문자로 사진을 보내주셔도 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 작업이라 거주자가 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로울 수 있지만 이웃 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.
신분증이 집 안에 있으면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두시면 수월합니다.

# 비용은 시작하기 전에 말씀드립니다
문 상태와 도어락 종류를 본 뒤 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
못 열면 비용은 받지 않습니다. / 열고 나서 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 문을 열 때는 이렇게 합니다
가장 덜 상하는 방법부터 차례로 시도합니다. / 문과 도어락이 상하지 않게 여는 것이 먼저입니다.
도어락 종류에 따라 시간이 다르고, 작업 중에 바꿔야 할 부품이 보이면 먼저 말씀드립니다. / 자세한 방식은 [현관문 개문](door-open.html) 페이지에 적었습니다.
출장열쇠 전반에 대한 내용은 [출장 열쇠](key-call.html)에서 볼 수 있습니다.
@ 성남 서현동 출장열쇠 도어락 개문

# 열고 난 뒤에는 이것까지 봅니다
문이 열리면 도어락이 다시 잘 잠기고 열리는지 함께 확인합니다. / 건전지가 원인이었다면 전부 새것으로 바꿨는지도 봅니다.
비밀번호를 잊어서 연 경우에는 새 번호 등록까지 도와드립니다. / 기존 번호는 지우고 새 번호만 남겨 둡니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 자주 고장난다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 정말 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 서현동 말고 분당 어디든
수내동, 정자동, 야탑동, 이매동, 구미동까지 분당 전역을 다닙니다. / 성남 안이면 동네 상관없이 24시간 출동합니다.
성남 전체 안내는 [성남시 출장열쇠](seongnam.html)에, 서울과 경기 다른 지역은 [출장 지역](area.html) 지도에 있습니다.
