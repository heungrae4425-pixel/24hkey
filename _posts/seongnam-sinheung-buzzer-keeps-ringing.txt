# 신흥동 현관 앞에서 경고음이 멈추지 않는다면
신흥동은 모란역 쪽 생활권과 가까운 동네라 오래된 주택과 빌라, 아파트가 섞여 있습니다. / 퇴근하고 문 앞에 서는데 도어락이 삐익 소리를 멈추지 않으면 이웃 눈치도 보이고 마음이 급해집니다.
경고음은 도어락이 보내는 신호입니다. / 소리의 모양에 따라 원인이 다르고, 맞는 대처를 하면 의외로 쉽게 멈추는 경우가 많습니다.
이 글은 성남 신흥동에서 경고음이 계속 울릴 때 소리별 원인과 끄는 순서를 적었습니다. / 해결이 안 될 때 [성남 출장열쇠](seongnam.html)를 부르는 기준도 함께 정리했습니다.
@ 신흥동 도어락 경고음 울리는 현관

# 소리가 한 번인지 계속인지 구분합니다
먼저 어떤 소리가 나는지 들어 보세요. / 한 번 짧게 나는 소리와 계속 이어지는 소리, 짧은 소리가 여러 번 나는 소리는 뜻이 다릅니다.
- 번호를 누를 때마다 삐 하고 짧게: 정상 입력음
- 문을 열 때마다 같은 경고음: 배터리 부족 신호
- 쉬지 않고 계속: 오작동, 침입 감지 또는 센서 이상
- 일정한 간격으로 반복: 문이 덜 닫힌 경고
제품마다 소리가 조금 다르니 설명서가 있다면 함께 보세요. / 소리를 녹음해 두면 전화로 설명할 때 도움이 됩니다.
밤에 울리는 경고음은 이웃에게 소음이 되기 쉽습니다. / 소리 때문에 마음이 급해도 먼저 문 상태와 번호판을 차분히 살펴보는 것이 빠른 길입니다.

# 배터리 부족이 가장 흔한 원인입니다
문을 열 때마다 경고음이 나거나 잠금 소리가 평소보다 느리다면 배터리가 거의 다 된 것입니다. / 건전지가 약해지면 도어락이 놀라 경고음을 길게 낼 수 있습니다.
안쪽 덮개를 열고 건전지를 전부 새것으로 바꿔 주세요. / 일부만 바꾸면 얼마 안 가 다시 울립니다.
새 건전지를 넣고도 소리가 멈추지 않으면 다른 원인을 의심합니다.
건전지는 새것이라도 방향이 반대로 끼워졌거나 접촉이 느슨하면 약한 전기만 들어갑니다. / 극 방향을 확인하고 한 개씩 눌러 단단히 끼워 보세요.
서로 다른 종류나 오래된 건전지를 섞으면 다시 경고음이 울릴 수 있으니 같은 제품으로 한꺼번에 바꾸세요.

# 문이 덜 닫혀 있는지 확인합니다
문이 완전히 닫히지 않으면 도어락이 계속 경고음을 낼 수 있습니다. / 걸쇠가 문틀 구멍에 끝까지 들어가지 않았을 가능성입니다.
문을 안쪽에서 살짝 밀고 손잡이를 돌려 걸쇠가 제대로 걸리게 해보세요. / 신흥동처럼 오래된 건물에서는 문틀이 조금씩 처져 걸쇠가 안 들어가는 일도 있습니다.
문을 닫을 때 문틀과 부딪히는 소리가 난다면 경첩이나 문틀 점검이 필요합니다.
@ 신흥동 도어락 걸쇠 문틀 맞춤 점검

# 센서가 오작동하는 경우
일부 도어락은 충격이나 진동을 감지하면 경고음이 울립니다. / 문을 세게 닫거나 근처 공사 진동으로 센서가 반응할 수 있습니다.
이 경우 번호를 정확히 한 번 눌러 열면 경고음이 멈추는 모델이 많습니다. / 먼저 문을 안쪽에서 확인한 뒤 열어 보세요. / 멈추지 않으면 안쪽에서 설정을 확인해야 합니다.
습기나 먼지로 센서가 잘못 읽는 경우도 있으니 번호판을 마른 천으로 닦아 주세요.

# 번호판이 눌린 채 걸렸을 때
번호판 한쪽이 눌린 채로 걸리면 도어락이 계속 입력 중이라고 인식하며 경고음을 낼 수 있습니다. / 가방이나 물건이 번호판에 기대어 있으면 이런 일이 생깁니다.
번호판 전체를 가볍게 두드려 보고 특정 번호만 반응이 이상한지 확인하세요. / 한 번호만 계속 눌린 느낌이면 번호판 접촉 불량일 수 있습니다.
이 경우는 억지로 분해하지 말고 점검을 받는 게 좋습니다.
번호판 틈에 음료나 물기가 들어간 뒤 생기는 일도 많습니다. / 물기가 의심되면 건전지를 빼 두고 마른 곳에서 잠시 말린 다음 다시 끼워 보세요.

# 비밀번호를 여러 번 틀린 뒤라면
번호를 여러 번 틀리면 도어락이 보안 모드로 들어가며 경고음을 낼 수 있습니다. / 일정 시간이 지나면 풀리는 모델이 많으니 잠시 기다려 보세요.
기다리는 동안 번호를 계속 누르면 시간이 더 늘어날 수 있습니다. / 손을 떼고 몇 분 쉬었다가 정확한 번호로 다시 입력해 보세요.
번호가 맞는데도 안 되면 번호가 바뀌었는지 가족에게 물어보세요.

# 경고음을 끄려고 해서는 안 되는 방법
- 건전지를 마구 뺐다 끼웠다 반복하기
- 덮개를 뜯어 내부 전선 만지기
- 소리가 난다고 문을 세게 두드리기
- 스피커 부분을 막아 소리만 줄이기
소리를 줄이는 것만으로는 원인이 사라지지 않습니다. / 소리가 멈췄다고 안심했다가 며칠 뒤 갑자기 문이 안 열리는 일도 있습니다.

# 전화하실 때 알려주실 것
신흥동은 모란역과 가까운 길이 좁은 곳도 있어 위치를 정확히 알려 주시면 도착이 빨라집니다.
- 대략 위치(모란역 방향 등)와 건물 형태
- 소리의 모양(계속, 반복, 한 번)과 시작된 시각
- 문이 열리는지 안 열리는지
- 집 안에 아이나 반려동물이 있는지
도어락 사진과 소리 녹음을 문자로 보내 주시면 원인을 좁히기 쉽습니다. / 문 안쪽에 사람이 있어 급하면 꼭 먼저 말씀해 주세요.

# 도착하면 사시는 분인지 먼저 확인합니다
문과 도어락을 만지는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 이웃과 집 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.
@ 신흥동 출장열쇠 신분 확인 절차

# 비용은 작업 전에 말씀드립니다
도어락 상태와 문 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 경고음의 원인을 고친 뒤 확인할 것
소리가 멈췄다면 문을 몇 번 열고 닫으며 다시 울리지 않는지 보세요. / 번호를 정확히 눌렀을 때 한 번에 열리는지도 확인합니다.
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 해결하고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문이 안 열리는 상태라면 [현관문 개문](door-open.html) 페이지의 진행 방식을 참고하세요.

# 신흥동 말고 성남 어디든 갑니다
신흥동 바로 옆 태평동, 단대동, 은행동, 모란 주변도 다닙니다. / 성남 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html)에, 다른 지역은 [출장 지역](area.html)에 정리했습니다.
