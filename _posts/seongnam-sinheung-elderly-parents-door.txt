# 부모님 댁 문이 걱정될 때
명절이나 주말에 부모님 댁에 가 보면 현관문 앞에서 한참 번호를 누르고 계신 모습을 보게 될 때가 있습니다. / 신흥동은 오래 사신 분들이 많은 동네라 도어락도 몇 년씩 된 집이 많습니다.
도어락은 한 번 달면 신경을 안 쓰게 되는데, 어르신 댁은 배터리 교체나 비밀번호 관리를 놓치기 쉽습니다. / 아무 일이 없을 때 한 번 점검해 두는 것이 가장 좋은 대비입니다.
이 글은 부모님 댁 도어락을 점검할 순서와 쓰기 편하게 바꾸는 방법, 그리고 [성남 출장열쇠](seongnam.html)가 도와드리는 범위를 적었습니다. / 급하게 문이 안 열리는 상황이라면 4번부터 보셔도 됩니다.
@ 신흥동 출장열쇠 부모님 댁 도어락 점검

# 먼저 평소 쓰시는 모습을 살펴보세요
부모님이 문을 열 때 어떻게 하시는지 옆에서 가만히 지켜보세요. / 번호를 자주 틀리시는지, 번호판이 잘 안 보여서 얼굴을 가까이 대시는지, 문이 한 번에 안 열려 여러 번 시도하시는지가 힌트가 됩니다.
- 번호를 누르는 속도와 정확도
- 번호판 불빛이 충분히 밝은지
- 안내음이 너무 작거나 너무 빠르지 않은지
- 문을 닫을 때 걸쇠가 잘 걸리는지
- 열쇠 구멍 쪽 사용 흔적이 있는지
불편해 보이는 부분이 있다면 대개 설정이나 간단한 점검으로 나아집니다.

# 배터리부터 새것으로 바꿔 주세요
어르신 댁에서 가장 흔한 일은 배터리가 약해졌는데 경고음을 못 들으시고 그대로 쓰시는 경우입니다. / 경고음이 울렸어도 소리가 작거나 귀에 안 들려서 놓치기도 합니다.
방문하셨을 때 배터리를 전부 새것으로 바꿔 드리고, 교체한 날짜를 도어락 안쪽에 적어 두세요. / 달력에 일 년 뒤 날짜를 표시해 두면 더 좋습니다.
건전지는 같은 종류로 한꺼번에 바꾸는 것이 원칙입니다. / 새것과 헌것을 섞어 쓰면 금방 같은 증상이 다시 생깁니다.

# 번호는 외우기 쉬우면서도 남이 알기 어렵게
어르신들은 자주 쓰던 숫자를 번호로 쓰시는 경우가 많습니다. / 생일이나 전화번호 끝자리처럼 남이 추측하기 쉬운 번호는 바꾸시는 것이 좋습니다.
번호를 너무 길게 하면 오히려 틀리실 수 있으니 부모님이 편하게 누를 수 있는 길이로 정하세요. / 가족 모두가 같은 번호를 알고 있는지도 같이 확인해 두세요.
번호를 종이에 적어 두실 때는 현관 근처에 두지 마시고 안쪽 서랍 같은 곳에 보관하세요. / 비밀번호는 가족 연락처와 함께 적어 두면 좋습니다.
@ 신흥동 도어락 비밀번호 점검 설정

# 소리와 불빛을 어르신께 맞춰 보세요
도어락에 따라 안내음 크기나 번호판 밝기를 조절할 수 있는 제품이 있습니다. / 소리가 너무 작아 안 들리거나 반대로 너무 커서 밤에 놀라시는 경우도 있습니다.
- 안내음이 잘 들리는지 직접 눌러 보며 확인
- 번호판 불빛이 어두우면 배터리를 먼저 점검
- 경고음이 울릴 때 어떤 뜻인지 부모님께 알려 드리기
- 설명서가 없다면 제품 앞면 모양을 사진으로 찍어 두기
조절이 안 되는 제품이라면 소리가 더 잘 들리는 제품으로 바꾸는 방법도 있습니다.

# 비상 열쇠와 연락처를 정해 두세요
번호를 잊으시거나 도어락이 고장 났을 때 부모님이 혼자 곤란해지지 않게 대비해 두세요. / 비상 열쇠를 가까운 가족이나 믿을 만한 이웃에게 맡겨 두면 가장 빠릅니다.
문 안쪽 잘 보이는 곳에 연락처를 크게 적어 두는 것도 좋습니다. / 가족 연락처와 함께 [24시출장열쇠](./) 번호 010-3664-5455를 적어 두시면 급할 때 쓸 수 있습니다.
부모님이 낯선 사람에게 번호를 알려 드리지 않도록 평소에 말씀드려 두세요. / 누군가 문 열어 준다며 찾아오면 먼저 가족에게 전화하시도록 안내해 주세요.

# 부모님 댁 문이 안 열릴 때 가족이 할 일
부모님이 안에 계신데 문이 안 열린다면 우선 안에 계신 분의 안전을 먼저 확인해야 합니다. / 인기척이 없거나 연락이 안 된다면 지체하지 말고 119에 먼저 연락하세요.
안에서 대답은 하시는데 문만 안 열리는 상황이라면 전화로 번호판 상태를 차근차근 여쭤보세요. / 배터리, 보조키, 걸쇠 순서로 하나씩 확인하면 원인이 좁혀집니다.
혼자 해결이 어렵다면 위치와 상황을 알려주세요. / 안에 어르신이 계신 상황은 우선순위를 높여 안내해 드립니다.

# 신흥동 위치는 이렇게 알려주세요
신흥동은 언덕과 골목 안 주택이 많아 차량이 들어가기 어려운 곳도 있습니다. / 주소와 함께 가까운 큰길이나 역 방향을 알려주시면 도착이 빨라집니다.
- 주소나 건물 이름
- 가까운 큰길이나 모란역 쪽인지
- 차를 세울 수 있는 곳이 있는지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 집 안에 어르신이 혼자 계신지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라서 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
자녀분이 대신 부르신 경우에는 부모님 본인이나 가족관계를 확인할 수 있는 방법을 함께 안내합니다. / 어르신이 직접 확인해 주시면 가장 빠릅니다.
확인 절차는 [이용안내](guide.html)에 적어 두었습니다. / 번거로워도 집을 지키기 위한 절차입니다.

# 비용은 문 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 개문 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
@ 성남 신흥동 24시 출장열쇠 도어락 점검

# 고쳐서 쓸지 바꿀지 판단하는 기준
오래된 도어락이라도 고쳐서 쓸 수 있으면 굳이 바꾸시라고 권하지 않습니다. / 배터리나 접촉 불량 정도라면 [도어락 수리](doorlock-repair.html)로 해결되는 경우가 많습니다.
다만 번호판이 잘 안 보이거나 자주 오작동하는 경우, 어르신이 쓰기 불편한 구조라면 바꾸는 쪽이 낫습니다. / 이럴 때는 [도어락 교체](doorlock-replace.html)로 쓰기 편한 제품을 같이 골라 드립니다.
결정은 부모님과 가족이 하시고 저희는 설명만 드립니다. / 서두르지 않으셔도 됩니다.

# 점검할 때 가져가면 좋은 것
부모님 댁에 가시는 날 아래 몇 가지를 챙기시면 점검이 훨씬 수월합니다.
- 새 건전지 한 세트와 비상용 9V 건전지
- 도어락 사진과 제품 모델명 메모
- 가족 연락처를 적을 종이와 펜
- 비상 열쇠를 맡길 사람의 연락처
- 도어락 설명서가 있다면 한 번 훑어보기
이 정도만 준비하셔도 반 시간 안에 기본 점검을 마칠 수 있습니다.

# 신흥동 말고 성남 어디든 갑니다
신흥동 바로 옆 태평동, 단대동, 수진동과 분당 서현, 정자, 야탑 쪽도 24시간 출동합니다. / 위례와 판교 쪽도 위치에 맞춰 도착 시간을 말씀드립니다.
성남에서 다니는 동네는 [성남시 출장열쇠](seongnam.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
