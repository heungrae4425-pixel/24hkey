# 이사 당일 문 앞에서 당황하지 않으려면
신흥동은 신흥역 주변으로 빌라와 다세대, 아파트가 이어져 있어 이사가 잦은 동네입니다. / 이삿짐이 들어오는 날 도어락이 말을 안 들으면 짐 차량을 세워 둔 채 시간만 흘러갑니다.
이 글은 입주하는 날과 퇴거하는 날로 나누어 도어락과 열쇠를 어떤 순서로 확인하면 좋은지 정리했습니다. / 이사 일주일 전부터 당일, 그리고 이사 후 며칠까지 시간 순서대로 따라 하시면 됩니다.
@ 신흥동 이사 입주 도어락 열쇠 확인

# 이사 일주일 전에 해 둘 일
이사 날짜가 잡혔다면 일주일 전쯤 현재 집과 새 집의 문 상태를 미리 알아 두세요. / 날짜에 쫓겨서 확인하면 문제를 발견해도 해결할 시간이 없습니다.
- 새 집 도어락 종류와 비밀번호 방식 확인
- 현재 집 열쇠 개수와 반납할 열쇠 정리
- 이사 업체에게 출입 방법을 어떻게 알릴지 정하기
- 도어락 배터리가 새것인지 확인
특히 이사 직전에 배터리를 바꾸는 습관은 의외로 효과가 큽니다.
이사 날은 짐을 들고 문을 수없이 열고 닫기 때문에 평소보다 배터리를 훨씬 많이 씁니다. / 새 배터리로 시작하면 한참 짐을 나르다 번호판이 꺼지는 일을 피할 수 있습니다.

# 입주하는 날에 가장 먼저 할 일
짐이 들어오기 전에 문을 열고 닫아 보는 것부터 시작합니다. / 전 거주자가 쓰던 번호가 남아 있을 수 있어서 반드시 새 번호로 바꿔야 합니다.
- 기존 비밀번호와 카드, 지문 등록 정보 지우기
- 새 비밀번호 등록
- 안쪽 보조키와 걸쇠가 잘 작동하는지 확인
- 받은 열쇠가 실제로 맞는지 직접 돌려 보기
열쇠가 맞지 않는 집은 입주 첫날부터 곤란해집니다. / 받은 열쇠는 그날 바로 한 번씩 꽂아 돌려 봐야 합니다.
열쇠가 여러 개라면 하나씩 번호를 매겨 두고 어느 열쇠가 어느 문에 맞는지 적어 두세요. / 나중에 우편함이나 공동 현관 열쇠와 섞여도 헷갈리지 않습니다.

# 이삿짐 날에는 번호를 길게 쓰지 마세요
이사 업체 직원이 여러 번 드나들 때는 임시 번호를 따로 쓰는 편이 안전합니다. / 이삿짐이 모두 들어온 뒤에 정식 번호로 바꿔 쓰면 번호가 퍼지는 걸 막을 수 있습니다.
임시 번호를 등록할 수 없는 제품이라면 문을 열어 둔 채 짐을 받는 방법이 있습니다. / 그때는 사람이 문 앞을 지키는 것이 중요합니다.
@ 신흥동 이사 날 현관 도어락 새 번호 등록

# 열쇠가 안 맞거나 번호가 안 지워질 때
전 거주자가 설정한 번호를 모르는 채로 들어와야 하는 경우도 있습니다. / 이때 무리해서 열려고 하지 말고 계약 관련 연락처나 중개한 분께 먼저 확인해 보세요.
도어락 기록을 지우는 초기화 방법은 제품마다 다릅니다. / 초기화 버튼이 안쪽 배터리 칸 근처에 있는 경우가 많지만 모르는 채 누르면 설정이 한꺼번에 사라지니 확인하고 하세요.
열쇠가 맞지 않거나 초기화가 안 되는 경우에는 연락 주시면 사시는 분 확인 후 열어 드립니다.

# 퇴거하는 날은 반납 순서가 중요합니다
집을 비울 때는 청소가 끝난 뒤 마지막에 문을 확인합니다. / 열쇠와 카드키, 비밀번호 정보를 모두 넘기고 나서 나와야 뒷말이 생기지 않습니다.
- 갖고 있는 열쇠를 모두 모아 개수 세기
- 도어락에 등록한 내 지문과 카드 지우기
- 비밀번호를 임의로 바꿨다면 새 집주인이나 임대인에게 알리기
- 배터리를 일부러 빼 가지 않기
배터리를 빼 가면 나중에 문이 안 열려 분쟁이 생길 수 있습니다. / 원래 있던 상태 그대로 두는 게 안전합니다.
퇴거하는 날 점검 사진을 한 장 남겨 두는 것도 좋습니다. / 열쇠를 반납하는 장면이나 도어락 화면을 찍어 두면 나중에 서로 확인하기 편합니다.

# 임대인과 임차인이 헷갈리는 부분
도어락을 누가 바꾸고 누가 비용을 내는지는 계약 내용과 상황에 따라 다릅니다. / 우리가 법적으로 정해 드릴 수 있는 부분은 아니어서 미리 서로 이야기해 두시길 권합니다.
다만 사진을 남겨 두면 도움이 됩니다. / 입주할 때 문과 도어락 상태를 찍어 두고 퇴거할 때 비교하면 서로 오해가 줄어듭니다.

# 입주 첫 일주일에 문이 먼저 알려주는 신호
이사 직후에는 문과 도어락이 새 환경에 적응하는 기간입니다. / 이때 다음과 같은 신호가 보이면 점검이 필요합니다.
- 번호는 맞는데 가끔 반응이 늦는 경우
- 문을 닫아도 걸쇠가 덜 들어가는 경우
- 잠글 때 평소보다 모터 소리가 큰 경우
이런 증상을 방치하면 이사 후 한 달 안에 문이 안 열리는 일로 이어질 수 있습니다. / 처음 증상이 보일 때 한 번 점검받는 편이 훨씬 수월합니다.

# 문 앞에서 바로 연락해야 하는 때
이사 날 문이 아예 안 열리면 짐을 올리지 못하고 시간이 지체됩니다. / 이럴 때는 번호판 상태와 문 앞 상황을 알려주시면 빠르게 출동합니다.
- 번호판이 꺼져 있는지 켜지는지
- 열쇠가 맞지 않는지, 구멍에 들어가지 않는지
- 새 집인지 현재 집인지
- 이사 시간이 정해져 있다면 몇 시까지 열어야 하는지
시간이 급하다는 점을 먼저 말씀해 주시면 순서를 맞춰 진행합니다.
이삿짐 차량이 도로에 서 있는 상황이라면 주차 위치도 알려주세요. / 도착해서 바로 작업에 들어갈 수 있도록 미리 준비합니다.

# 오면 먼저 사시는 분인지 확인합니다
새로 이사 오는 날에는 신분증 주소가 아직 이전 집일 수 있습니다. / 이 경우 계약서나 입주 확인 문서, 관리사무소 확인으로 대신할 수 있는지 함께 봅니다.
확인 수단은 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다. / 신분이 확인되지 않으면 작업을 할 수 없다는 점은 미리 알아 두세요.
@ 성남 신흥동 이사 날 출장열쇠 신분 확인

# 비용은 열기 전에 말씀드립니다
문 종류와 도어락 상태를 보고 먼저 알려드립니다. / 괜찮다고 하시면 시작하고 마음에 안 드시면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 이사 날이라 마음이 바쁘시겠지만 비용은 시작 전에 꼭 확인하세요.
작업 방식은 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 열고 난 뒤 도어락을 어떻게 할지 정하기
문을 열고 보니 도어락이 너무 낡았거나 기능이 안 맞는다면 이사 기회에 바꾸는 것도 방법입니다. / 다만 고쳐 쓸 수 있는 상태라면 [도어락 수리](doorlock-repair.html)를 먼저 권해 드립니다.
교체가 필요하면 [도어락 교체](doorlock-replace.html)에서 방식과 순서를 확인해 보세요. / 새로 달고 싶은 경우에는 [도어락 설치](doorlock-install.html) 안내도 도움이 됩니다.
문 두께와 보조키 위치를 미리 알아 두면 교체가 빨라집니다.

# 신흥동 말고 성남 어디든 갑니다
신흥동 옆 태평동, 수진동, 단대동, 은행동도 다닙니다. / 이사 일정은 시간이 중요하니 성남 안에서는 가장 가까운 순서로 출동합니다.
성남 동네 목록은 [성남시 출장열쇠](seongnam.html)에서 보실 수 있습니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.

? 열쇠가 맞지 않는데 어떻게 하나요? | 억지로 돌리지 마시고 연락 주세요. 원인을 보고 방법을 말씀드립니다.
