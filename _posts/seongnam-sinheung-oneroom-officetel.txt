# 신흥동 원룸 문이 잠겼다면 먼저 숨부터 고르세요
성남 신흥동에서 혼자 지내는 분들이 가장 많이 겪는 일이 출입문 잠김입니다. / 쓰레기를 버리러 잠깐 나왔다가 문이 닫혀 버리는 식으로 시작하는 경우가 대부분입니다.
혼자 사는 집은 문 안쪽에 열쇠와 휴대폰이 그대로 있는 일이 많아 당황이 더 큽니다. / 이 글은 [성남 출장열쇠](seongnam.html)를 부르기 전에 할 수 있는 일과 부른 뒤의 순서를 적었습니다.
모란역과 가까운 쪽에서 오시는 분도, 언덕 쪽 골목에서 오시는 분도 순서는 같습니다. / 지금 문 앞이라면 바로 아래 두 번째 소제목부터 보셔도 됩니다.
@ 신흥동 원룸 출입문 잠김 출장열쇠

# 원룸 출입문이 잠기는 흔한 경우 네 가지
원룸이나 오피스텔 문은 자동으로 잠기는 방식이 많아서 문만 닫아도 잠깁니다. / 그래서 아래 같은 일이 자주 생깁니다.
- 쓰레기, 택배, 세탁물을 들고 잠깐 나왔다가 문이 닫힌 경우
- 휴대폰은 안에 두고 번호도 잊은 경우
- 배터리가 다 돼서 번호판이 안 켜지는 경우
- 안쪽 잠금장치가 눌린 채 문이 닫힌 경우
각각 해결 방법이 다르니 먼저 어떤 경우인지 가늠해 보시면 좋습니다.

# 관리실이나 집주인에게 먼저 연락해 볼 수 있다면
건물에 관리실이 있다면 여분 열쇠나 번호를 가지고 있을 수 있습니다. / 집주인과 바로 연락이 되면 그쪽이 가장 빠른 길일 때도 있습니다.
다만 늦은 시간이라 연락이 안 되면 기다리는 시간이 길어집니다. / 그럴 때는 기다리지 말고 전화 주셔도 됩니다.
세입자 입장에서 집주인에게 알리기 부담스러운 분도 계십니다. / 문을 연 뒤에 알리고 싶으신지는 편하신 대로 하시면 됩니다.

# 전화로 이 네 가지만 말씀해 주세요
성남 신흥동 위치와 문 상태를 알려주시면 도착 시간을 바로 말씀드립니다. / 길게 설명하지 않아도 괜찮습니다.
- 건물이 보이는 위치(큰길에서 어느 쪽인지, 몇 층인지)
- 도어락 모양(번호판형, 손잡이 일체형, 카드형)
- 번호판이 켜지는지, 소리가 나는지
- 안에 사람이나 반려동물이 있는지
가능하면 도어락 사진을 문자로 보내 주세요. / 맞는 장비를 챙겨 가기 좋아서 작업이 빨라집니다.

# 문 앞에서 하지 말아야 할 것
급한 마음에 카드나 칼로 문틈을 벌리는 분들이 있습니다. / 문틀과 걸쇠가 상해서 오히려 열기 어려워지고 나중에 고칠 곳이 늘어납니다.
번호를 열 번 스무 번 반복해서 누르는 것도 좋지 않습니다. / 도어락이 한동안 입력을 막아 버릴 수 있습니다.
창문으로 들어가려다 다치는 일은 더더욱 피하셔야 합니다. / 안전이 가장 먼저입니다.
@ 신흥동 원룸 도어락 문 열기 출장

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 그 집에 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있으면 관리실이나 집주인이 확인해 주는 방법도 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 방법을 같이 찾아봅니다.
번거로우셔도 이웃과 건물 모두를 지키는 절차입니다. / 이해해 주시면 감사하겠습니다.

# 비용은 시작하기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다. / 부품을 바꿔야 할 때는 바꾸기 전에 꼭 여쭤봅니다.

# 문은 최대한 덜 상하게 엽니다
문을 여는 방법은 여러 가지이고 덜 상하는 방법부터 차례로 해봅니다. / 원룸 문은 건물 공용 설비라 손상이 없도록 더 신경 씁니다.
어떤 방법으로 열지는 문과 도어락에 따라 달라집니다. / 자세한 진행은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 열고 난 뒤에 같이 확인하는 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새것으로 바꿨는지도 함께 봅니다.
자동으로 잠기는 방식이라면 문을 닫기 전에 확인하는 습관을 알려드립니다. / 문 바깥에 손을 짚고 나가는 식의 작은 방법만으로도 많이 줄어듭니다.
고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래됐다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 혼자 사는 집 문 앞 잠김 줄이는 습관
작은 습관이 밤중 호출을 가장 많이 줄여줍니다.
- 현관 안쪽 신발장 위에 여분 열쇠를 두지 말고 가까운 사람에게 맡기기
- 쓰레기 버리러 나갈 때도 휴대폰은 꼭 주머니에
- 번호는 가족이나 믿을 만한 한 사람과만 공유
- 배터리 교체일을 문 안쪽에 적어 두기
- 경고음이 나면 그날 바로 새 배터리로 교체
혼자 사실수록 한 번 더 확인하는 습관이 큰 도움이 됩니다.

# 원룸 문이 잠겼을 때 건물 사정도 같이 알려주세요
원룸이나 오피스텔은 건물마다 관리 방식이 다릅니다. / 관리실이 있는지, 공동현관 비밀번호가 따로 있는지 알려주시면 도착해서 헤매지 않습니다.
공동현관이 잠겨 있으면 입구에서부터 막힐 수 있어 전화를 받으면서 어떻게 들어갈지 같이 정합니다. / 층수와 호수를 말씀해 주시면 계단과 엘리베이터 동선도 미리 가늠할 수 있습니다.
건물 규칙상 늦은 시간 작업이 어려운 곳이라면 미리 알려주세요. / 소음을 줄이는 방법으로 먼저 진행합니다.
