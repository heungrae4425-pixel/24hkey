# 수내동에서 열쇠가 꽉 물려 안 돌아갈 때
수내역 주변 주택과 상가 건물에는 아직 열쇠로 여는 문이 꽤 남아 있습니다. / 번호 도어락을 달았어도 보조키로 열쇠를 같이 쓰는 집이 많습니다.
평소처럼 열쇠를 꽂았는데 돌아가지 않거나, 돌린 뒤에 열쇠가 빠지지 않는 일이 생기면 당황하기 쉽습니다. / 이럴 때 가장 먼저 필요한 것은 힘을 빼는 것입니다.
이 글은 수내동에서 열쇠 문제가 생겼을 때 원인을 어떻게 나눠 보는지, 해서는 안 되는 행동은 무엇인지 적었습니다. / 급하게 [출장 열쇠](key-call.html)를 부르기 전에 읽어 두시면 도움이 됩니다.
@ 수내동 출장열쇠 열쇠 안 돌아감

# 먼저 손에서 힘부터 빼 주세요
열쇠가 안 돌아가는 순간 대부분 더 세게 돌립니다. / 그런데 그 힘이 열쇠를 부러뜨리거나 열쇠구멍 안쪽 부품을 상하게 하는 경우가 많습니다.
열쇠가 반쯤 돌아간 상태에서 멈췄다면 무리하게 계속 돌리지 말고, 다시 제자리로 돌려 놓은 뒤 살살 빼 보세요. / 빠지지 않는다면 거기서 멈추는 것이 좋습니다.
열쇠가 구멍 안에서 부러지면 일이 한 단계 더 커집니다. / 부러진 조각이 안에 박혀 있으면 빼내는 작업이 따로 필요합니다.

# 열쇠가 안 돌아가는 흔한 원인
원인은 크게 열쇠 쪽과 자물쇠 쪽으로 나뉩니다. / 어느 쪽인지 알면 해볼 만한 일과 불러야 하는 때가 구분됩니다.
- 열쇠 모양이 닳아서 안쪽 핀을 제대로 못 올리는 경우
- 열쇠를 복사한 복사본이 원본과 미세하게 다른 경우
- 열쇠구멍 안에 먼지와 이물질이 쌓인 경우
- 문이 처져서 데드볼트가 당겨 눌리는 경우
오래 쓴 열쇠일수록 모서리가 둥글어져서 어느 날 갑자기 안 돌아가기 시작합니다. / 이런 증상이 며칠 전부터 뻑뻑했다면 닳은 열쇠 쪽일 가능성이 큽니다.

# 문이 눌려서 안 돌아가는 경우
열쇠는 멀쩡한데 문이 처져서 안 돌아가는 일도 많습니다. / 문을 안쪽으로 살짝 들어 올리듯 밀면서 열쇠를 돌리면 부드럽게 돌아가기도 합니다.
이렇게 돌아간다면 자물쇠 문제가 아니라 문과 문틀 위치가 어긋난 것입니다. / 이 상태로 계속 쓰면 점점 더 힘이 들어가므로 점검이 필요합니다.
문을 누르는 방향은 안쪽으로 가볍게 하시고, 발로 차거나 어깨로 미는 방식은 피해 주세요. / 문틀과 경첩이 같이 상합니다.

# 열쇠구멍에 윤활제 뿌려도 되나요
먼지가 원인일 때 열쇠구멍 전용 윤활제를 소량 넣으면 부드러워지기도 합니다. / 일반 기름이나 오일 스프레이는 먼지를 끌어당겨서 시간이 지나면 더 뻑뻑해질 수 있습니다.
쓰신다면 꼭 열쇠구멍용으로 나온 제품을 아주 조금만 쓰세요. / 많이 뿌리면 안쪽에 고여서 오히려 문제가 커집니다.
도어락이 같이 달려 있는 문이라면 윤활제가 번호판 쪽으로 들어가지 않게 주의해 주세요. / 전자 부품이 오작동하는 원인이 됩니다.
@ 수내역 근처 열쇠구멍 점검

# 열쇠가 안 빠질 때는
열쇠가 돌아간 상태로 안 빠지거나, 꽂은 채 빠지지 않는 경우는 안쪽 핀이 걸린 것입니다. / 열쇠를 위아래로 아주 조금씩 흔들면서 살짝 당겨 보면 빠지기도 합니다.
이때 펜치나 공구로 열쇠 머리를 잡고 세게 당기면 열쇠가 부러지기 쉽습니다. / 그대로 두고 전화 주시는 편이 안전합니다.
열쇠가 꽂혀 있는 상태에서 문이 잠겨 있다면 열쇠가 문 안쪽으로 눌려 있을 수도 있습니다. / 억지로 빼지 말고 위치만 기억해 알려주세요.

# 이렇게 하시면 문제가 커집니다
급한 마음에 하지 말아야 할 행동이 몇 가지 있습니다. / 아래를 피하시면 나중에 손볼 부분이 줄어듭니다.
- 드라이버나 철사를 열쇠구멍에 넣어 돌려 보는 것
- 열쇠 머리를 망치로 두드리는 것
- 라이터로 열쇠를 달궈 넣는 것
- 문을 발로 차거나 강하게 흔드는 것
특히 철사나 드라이버로 구멍 안을 건드리면 안쪽 핀이 휘거나 부러져서 열쇠가 영영 안 들어가게 되기도 합니다. / 이 경우 자물쇠를 통째로 바꿔야 할 수 있습니다.

# 수내동 건물별로 다른 점
수내동에는 아파트와 빌라, 상가 건물이 섞여 있습니다. / 건물에 따라 열쇠 문제가 생기는 모양이 조금씩 다릅니다.
빌라와 오래된 주택은 열쇠구멍이 낡고 먼지가 많아 뻑뻑해지는 경우가 흔합니다. / 닳은 열쇠를 오래 쓰다가 갑자기 안 돌아가기도 합니다.
상가 출입문은 열쇠를 여러 사람이 돌려 쓰는 경우가 많아 열쇠가 닳기 쉽습니다. / 이때는 복사본을 새로 만들어 쓰는 편이 좋습니다.
아파트는 보조키만 열쇠로 쓰는 일이 많아서, 평소에 쓰지 않던 열쇠가 어느 날 안 돌아가면 당황하게 됩니다. / 가끔 한 번씩 돌려 보면 미리 알아챌 수 있습니다.

# 전화하실 때 알려주시면 좋은 것
증상을 짧게 정리해 말씀해 주시면 도착 후 진행이 빨라집니다. / 모르는 항목은 건너뛰셔도 됩니다.
- 열쇠가 들어가는지, 안 들어가는지
- 어디까지 돌아가고 멈추는지
- 열쇠가 부러졌는지 여부
- 도어락과 열쇠를 같이 쓰는 문인지
- 위치(동 이름, 건물 종류, 층)
열쇠를 부러뜨리지 않으셨다면 새 열쇠를 같이 만들 수 있는 경우도 있어서, 지금 가진 열쇠를 버리지 말고 보관해 주세요. / 원본이 있으면 작업이 훨씬 수월합니다.
@ 수내동 24시 출장열쇠 열쇠 문제

# 도착하면 이렇게 진행합니다
먼저 열쇠와 자물쇠 중 어디가 원인인지 확인합니다. / 필요하면 문 처짐도 같이 봅니다.
열쇠를 새로 맞춰서 해결되는 경우라면 그쪽을 먼저 권합니다. / 자물쇠 전체를 바꾸는 것은 마지막 수단입니다.
조치가 필요하면 어떤 작업이고 비용이 얼마나 드는지 시작 전에 말씀드립니다. / 마음에 안 드시면 그냥 돌아갑니다.
열쇠 관련 작업이 어떻게 진행되는지는 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다. / 도어락 교체가 필요한 경우는 [도어락 교체](doorlock-replace.html)에서 보실 수 있습니다.

# 신분 확인 절차
문을 열거나 자물쇠를 만지는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
번거로울 수 있지만 이웃과 집 주인 모두를 위한 절차입니다. / 확인이 어려운 경우에는 작업이 어려울 수 있어 미리 챙겨 두시면 좋습니다.
진행 순서 전체는 [이용안내](guide.html)에서 확인하실 수 있습니다. / 처음 부르시는 분들이 가장 많이 읽는 페이지입니다.

# 열쇠 문제를 미리 줄이는 방법
평소에 조금만 신경 쓰면 갑자기 안 돌아가는 일을 줄일 수 있습니다. / 어렵지 않은 습관들입니다.
- 열쇠를 정기적으로 한 번씩 돌려 보고 뻑뻑하면 미리 점검받기
- 오래 쓴 열쇠는 새로 복사해 두기(복사본의 복사본은 피하기)
- 열쇠구멍은 마른 천이나 전용 청소제로 가끔 닦기
- 열쇠를 열쇠고리에 너무 무거운 물건과 함께 달지 않기
열쇠 구멍에 무거운 열쇠뭉치가 매달린 채로 오래 두면 안쪽 부품이 한쪽으로 닳습니다. / 문을 열 때 열쇠뭉치를 손으로 받쳐 주는 것만으로도 수명이 달라집니다.
