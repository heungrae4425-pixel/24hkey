# 아기가 생기면 현관 풍경이 달라집니다
수내동은 수내역을 중심으로 아이 키우는 가정이 많이 사는 생활권입니다. / 아기가 태어나면 유모차, 카시트, 기저귀 가방 때문에 현관을 드나드는 모습부터 달라집니다.
두 손이 모자란 상태에서 문을 여닫다 보면 평소엔 하지 않던 실수가 생깁니다. / 그 실수가 문 앞에서 오래 서 있게 만드는 원인이 되기도 합니다.
이 글은 수내동에서 신생아나 영유아가 있는 집이 현관 잠금을 쓸 때 주의할 점을 모았습니다. / 급한 상황에는 [성남 출장열쇠](seongnam.html)를 부르는 순서도 적어 두었습니다.
@ 수내동 영유아 가정 현관 도어락 출장열쇠

# 가장 흔한 일, 아기를 안고 문이 닫혀 버린 경우
아기를 안고 쓰레기를 버리러 나왔다가 문이 닫히는 경우가 있습니다. / 자동으로 잠기는 도어락은 문이 닫히는 순간 잠깁니다.
휴대폰도 열쇠도 집 안에 있으면 막막해집니다. / 이때 가장 먼저 할 일은 아기를 안전하게 두는 것입니다. 바닥에 내려놓지 말고 안은 채로 이웃이나 경비실에 도움을 청하세요.
쓰레기를 버리러 나갈 때만이라도 문틈에 신발이나 도어스토퍼를 끼워 두는 습관이 좋습니다. / 작은 습관이 문 앞에서 아기를 안고 서 있는 일을 막아 줍니다.

# 아기가 집 안에 혼자 있는데 문이 잠겼다면
이 경우가 가장 급합니다. / 아기가 집 안에 혼자 있다면 지체하지 말고 먼저 알려 주세요.
전화로 말씀해 주실 내용은 아기가 몇 개월쯤인지, 지금 소리가 들리는지, 깨어 있는지 자는지입니다. / 아기 상태가 걱정될 만큼 급하면 119에 먼저 도움을 청하는 것이 맞습니다.
문 너머로 아기가 울면 안심시키는 말을 계속 걸어 주세요. / 가능하면 보호자 한 분은 문 앞에서 떠나지 마시고, 다른 분이 연락을 하시면 훨씬 빨라집니다.

# 아기가 보조키를 만지는 시기
아이가 걷기 시작하면 손이 닿는 모든 것을 만집니다. / 안쪽 보조키와 걸쇠는 눈높이에 있어서 돌려 보기 쉽습니다.
보조키가 안에서 잠기면 바깥에서 번호를 눌러도 열리지 않습니다. / 아이가 문을 막고 있는 줄 모르고 계속 번호를 누르다 도어락이 입력을 막는 경우도 있습니다.
보조키 위치가 낮다면 아이 손이 닿지 않는 높이로 장치를 바꾸거나, 잠금 버튼에 아이용 덮개를 쓰는 방법이 있습니다. / 어떤 방식이 가능한지는 문 종류에 따라 달라 직접 보고 안내드립니다.

# 문이 쾅 닫히는 소리와 손가락 끼임
잠든 아기가 문 소리에 깨는 경우가 많습니다. / 도어클로저가 너무 세게 닫히도록 되어 있으면 문 소리도 크고 아이 손이 끼일 위험도 큽니다.
문을 닫을 때 속도를 조절하는 나사가 도어클로저에 있는 제품이 있습니다. / 조절하면 천천히 닫혀 소리와 위험이 모두 줄어듭니다. 점검 방법은 [도어락 수리](doorlock-repair.html) 안내도 참고하세요.
문 경첩 쪽 틈에 아이 손가락이 들어가지 않도록 보호 덮개를 쓰는 집도 있습니다. / 현관뿐 아니라 방문과 화장실 문도 같이 살펴 주세요.
@ 성남 수내동 문 닫힘 소리 도어클로저 점검

# 도어락 경고음과 번호판 소리 줄이기
번호를 누를 때마다 크게 울리는 소리가 잠든 아기에게는 큰 소음입니다. / 많은 도어락이 소리를 줄이거나 끄는 설정을 갖고 있습니다.
다만 경고음까지 끄면 배터리가 약해졌을 때 알아차리기 어렵습니다. / 번호 입력음은 줄이고 배터리 경고만 남기는 설정이 가장 낫습니다.
설정 방법은 제품마다 달라서 설명서를 보거나 모델명으로 확인하는 게 정확합니다. / 잘 모르겠으면 사진을 보내 주시면 방법을 안내드립니다.

# 아이가 안쪽에서 손잡이를 돌려 열 수 있을까
돌 지난 아이가 현관을 혼자 열고 나가는 일이 걱정이라는 분이 많습니다. / 안쪽 손잡이가 낮은 눌러 여는 형태면 의외로 쉽게 열립니다.
반대로 안에서도 열기 어렵게 만들면 위급할 때 대피가 늦어집니다. / 안전과 편리 사이에서 균형이 필요한 부분입니다.
어른은 쉽게 열고 아이는 어렵게 열도록 하는 방법이 몇 가지 있습니다. / 상황에 맞는 방법은 현장에서 문을 보고 말씀드립니다.

# 유모차를 끌고 들어올 때 번호 입력 요령
두 손이 막혀 있을 때는 번호를 누르기 힘듭니다. / 이럴 때는 카드나 지문처럼 한 번에 열리는 방식이 편리합니다.
번호 방식을 계속 쓰고 싶다면 짧고 외우기 쉬운 번호를 쓰되 쉬운 숫자는 피하세요. / 번호판이 잠든 아기 쪽을 깨우지 않게 소리를 줄여 두면 더 좋습니다.
한 번에 열리는 방식으로 바꾸는 일은 급할 때 정할 문제가 아닙니다. / 필요하면 [도어락 교체](doorlock-replace.html) 안내를 보고 천천히 비교해 보세요.

# 출장 요청 때 알려주시면 좋은 것
아기가 있는 집은 우선순위가 다릅니다. / 전화하실 때 처음에 아기 이야기부터 해 주세요.
- 집 안에 아기가 있는지, 몇 개월쯤인지
- 아기가 깨어 있는지, 소리가 들리는지
- 수내동 어느 쪽이고 가까운 역은 어디인지
- 번호판 상태와 도어락 모양
- 문 앞에 어른이 계속 있을 수 있는지
이 내용이 있으면 도착해서 바로 순서를 정할 수 있습니다. / 아기 상태가 급해 보이면 준비되는 대로 바로 출발하겠다고 말씀드립니다.
@ 수내동 24시 출장열쇠 영유아 개문

# 도착해서 하는 일
먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나를 준비해 주세요.
급한 상황이라 신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁하는 방법도 있습니다. / 확인 절차는 이웃을 위한 약속이라 아기가 있어도 생략하지 않습니다.
확인이 끝나면 문과 도어락 상태를 보고 방법을 말씀드립니다. / 최대한 문이 상하지 않는 방법으로 열고, 비용은 열기 전에 먼저 알려 드립니다.

# 비용은 시작 전에, 못 열면 받지 않습니다
작업 전에 얼마인지 먼저 이야기합니다. / 괜찮다고 하실 때 시작하고, 열고 난 뒤 말없이 더해지는 비용은 없습니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
자세한 진행은 [이용안내](guide.html)에 적어 두었습니다.

# 문이 열린 뒤 집 안에서 다시 확인할 것
문이 열리면 아기부터 확인하시고, 그다음 도어락을 점검합니다. / 배터리가 문제였다면 새것으로 교체하고 경고음 설정도 같이 봅니다.
번호를 잊어서 연 경우는 새 번호를 안쪽에서 등록해 드립니다. / 기존 번호는 지우고 새 번호만 남깁니다.
아이가 만질 수 있는 낮은 곳의 보조키와 걸쇠는 어떻게 하면 좋을지도 같이 이야기합니다.

# 수내동 말고 성남 어디든 갑니다
정자동, 서현동, 야탑동, 이매동처럼 성남 안이면 24시간 출동합니다. / 성남 밖 지역은 [출장 지역](area.html)에서 확인해 주세요.
