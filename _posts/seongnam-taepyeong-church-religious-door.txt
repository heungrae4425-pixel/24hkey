# 일요일 아침 문이 안 열리면
태평동은 모란역과 가까운 구시가지 생활권으로, 주택과 상가, 작은 예배 공간이 한 골목에 섞여 있는 곳이 있습니다. / 모란역에서 걸어 올라오는 길에 건물 사이로 이런 시설을 보신 분도 많을 겁니다.
예배나 모임이 있는 날 아침, 먼저 도착한 사람이 열쇠로 문을 열려는데 안 열리면 모두가 곤란해집니다. / 여러 사람이 열쇠를 나눠 가진 곳일수록 이런 일이 더 쉽게 생깁니다.
이 글은 [성남 출장열쇠](seongnam.html)를 부르기 전에 교회나 종교시설 출입문 열쇠를 어떻게 관리하면 좋은지와, 문이 안 열릴 때 확인할 것을 정리했습니다.
@ 태평동 종교시설 출입문 열쇠 구멍 확인

# 종교시설 문은 왜 열쇠가 많이 돌아다닐까
예배당이나 모임 공간은 청소, 준비, 관리를 맡는 분이 따로 있는 경우가 많습니다. / 그래서 열쇠가 한두 개가 아니라 여러 사람 손에 나뉘어 있습니다.
사람이 바뀌어도 열쇠는 돌려받지 않는 일이 흔하고, 누가 몇 개 갖고 있는지 정확히 아는 사람이 없는 곳도 있습니다. / 이 상태에서 열쇠가 하나라도 사라지면 확인할 방법이 막막해집니다.
특히 새벽 기도나 저녁 모임처럼 이른 시간과 늦은 시간에 문을 여닫는 일이 잦으면 열쇠를 가진 사람이 더 늘어납니다. / 시설이 커지고 모임이 많아질수록 관리 기준이 더 필요해집니다.

# 열쇠 대장부터 만들어 보세요
어렵게 생각하지 말고 종이 한 장이면 됩니다. / 열쇠를 가진 사람, 받은 날짜, 돌려받은 날짜 세 가지만 적어 두세요.
- 열쇠 개수와 가진 사람 이름
- 어느 문 열쇠인지 구분 표시
- 분실이나 교체한 날짜
- 대장을 맡아 관리하는 사람
이렇게 해 두면 열쇠 하나를 잃어버렸을 때 누구에게 물어야 할지가 바로 정해집니다.
대장은 문 앞에 붙여 두지 말고 관리하는 분이 따로 보관하세요. / 누가 어느 문 열쇠를 갖고 있는지가 밖에 드러나는 것은 좋지 않습니다.

# 열쇠를 돌려받는 순간을 정해 두세요
봉사나 관리 역할이 바뀔 때 열쇠를 돌려받는 시점을 미리 정해 두면 좋습니다. / 말하기 어려운 분위기라도 규칙으로 정해 두면 서운함 없이 처리됩니다.
열쇠를 돌려받기 어려운 상황이라면 잠금장치를 바꾸는 쪽이 오히려 마음이 편합니다. / 누가 갖고 있는지 모르는 열쇠를 안고 사는 것보다 깔끔합니다.

# 번호식 도어락으로 바꾸면 달라지는 점
열쇠 대신 번호나 카드를 쓰면 사람이 바뀌어도 번호만 바꾸면 됩니다. / 열쇠를 되돌려 받는 번거로움이 없고, 분실 걱정도 줄어듭니다.
다만 번호를 아무에게나 알려주면 열쇠를 나눠 주는 것과 다를 바 없습니다. / 번호를 아는 사람의 범위를 정하고, 주기적으로 바꾸는 약속도 함께 만들어야 합니다.
@ 교회 출입문 번호식 도어락 교체 상담

# 문이 안 열릴 때 확인 순서
먼저 열쇠가 해당 문의 것이 맞는지 봅니다. / 여러 문의 열쇠가 한 꾸러미에 있으면 비슷한 모양끼리 헷갈립니다.
열쇠가 들어가는데 안 돌아가면 구멍이 마모되었거나 열쇠 자체가 닳았을 수 있습니다. / 복사한 열쇠를 다시 복사한 열쇠일수록 이런 경우가 많습니다.
번호식이라면 번호판이 켜지는지, 경고음이 나는지부터 봅니다. / 자세한 건 번호판 상태를 알려주시면 전화로 짚어 드립니다.

# 서두르다 하기 쉬운 실수
예배 시간이 다가오면 마음이 급해져 문을 발로 차거나 손잡이를 힘껏 당기는 분들이 계십니다. / 이렇게 하면 문과 잠금장치가 상하고 수리 범위가 커집니다.
열쇠가 안 돌아간다고 계속 힘을 주다가 열쇠가 부러지는 일도 있습니다. / 부러진 조각이 안에 박히면 열기 훨씬 어려워지니 멈추는 게 좋습니다.
모임 시간이 가까워도 일단 멈추고 상황부터 알려주시면 더 빨리 해결됩니다. / 사람이 많이 모이는 날일수록 문 앞에서 시간을 허비하지 않도록, 열쇠가 의심스러우면 전날 미리 한 번 돌려 보는 습관이 도움이 됩니다.

# 연락 주실 때 알려주실 것
모란역 쪽 어느 방향인지, 건물 층수와 출입문 위치를 말씀해 주세요. / 건물 이름 대신 큰길이나 근처 가게 방향으로 설명하셔도 됩니다.
- 열쇠로 여는 문인지, 번호로 여는 문인지
- 열쇠를 꽂으면 어떻게 되는지
- 문을 열어야 하는 시간
- 안에 사람이나 중요한 물건이 있는지
사진으로 문과 잠금장치를 보여주시면 맞는 장비를 챙겨 갑니다.

# 방문하면 먼저 관리하시는 분인지 확인합니다
종교시설도 공용 공간이라 문을 여는 일이라면 관리하시는 분이 맞는지 확인이 필요합니다. / 건물에 상주하시는 분, 임대 계약을 아는 분, 관리 책임자의 확인 같은 방법이 있습니다.
신분증, 주소가 보이는 우편물, 건물 관리 측의 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 책임자와 연락이 닿는 상태에서 불러주시면 수월합니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 잠금 종류를 보고 작업 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다.
공동으로 쓰는 곳이라 비용 처리를 누가 하는지 미리 정하고 부르시면 서로 편합니다. / 여러 분이 의견을 모아야 하는 곳이면 안내를 듣고 정하셔도 괜찮으니 천천히 말씀해 주세요.

# 문을 열고 난 뒤 같이 점검하는 것
문이 열리면 열쇠가 매끄럽게 돌아가는지, 잠금이 단단히 걸리는지 봅니다. / 열쇠가 닳아서 생긴 문제라면 새 열쇠를 만드는 방법을 말씀드립니다.
자세한 진행은 [현관문 개문](door-open.html) 페이지에 적어 두었고, 열쇠 문제는 [열쇠 출장](key-call.html)에서도 다룹니다.
이용 방식이 궁금하시면 [이용안내](guide.html)를 먼저 보셔도 좋습니다.

# 오래 쓰는 문, 이렇게 관리해 보세요
출입문은 하루에도 여러 번 열고 닫는 곳이라 잠금장치가 빨리 닳습니다. / 열쇠가 뻑뻑해졌을 때 미루지 말고 점검하는 것이 좋습니다.
- 열쇠 대장을 해마다 한 번 정리하기
- 오래된 복사 열쇠는 새로 정리하기
- 문이 닫힐 때 걸리면 경첩과 문틀 확인
- 번호식은 배터리를 때맞춰 한 번에 교체
고장이 나면 [도어락 수리](doorlock-repair.html), 오래되어 바꿔야 하면 [도어락 교체](doorlock-replace.html)를 상담해 드립니다.
@ 태평동 출입문 점검 후 열쇠 정리

# 태평동 말고 성남 어디든 갑니다
태평동 가까이 신흥동, 단대동, 은행동, 금광동과 모란역 생활권은 물론 서현역, 정자역, 야탑역, 판교역 쪽까지 24시간 출동합니다. / 다니는 동네는 [성남시 출장열쇠](seongnam.html)에서, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
