# 태평동 주택가 현관문이 안 열릴 때
태평동은 성남 수정구에 있는 오래된 주택가로 언덕과 계단이 많은 동네입니다. / 분당 아파트 단지와는 문과 도어락의 형태부터 다른 경우가 많습니다.
오래된 주택은 현관문이 철문이거나 나무문이고, 도어락도 여러 번 바꾼 흔적이 있기도 합니다. / 문틀이 처지고 경첩이 헐거워서 생기는 문제도 흔합니다.
이 글은 태평동에서 오래된 주택이나 빌라 현관문이 안 열릴 때 확인할 것과 진행 방식을 정리했습니다. / 직접 해결이 어려우면 [성남 출장열쇠](seongnam.html)로 연락 주시면 됩니다.
@ 태평동 주택 현관문 출장열쇠

# 오래된 문은 원인이 다릅니다
아파트 현관문은 규격이 비슷해서 원인도 비슷합니다. / 오래된 주택은 문마다 사정이 다르고, 쓰는 자물쇠도 제각각입니다.
- 철문 경첩이 처져서 문이 문틀에 눌리는 경우
- 오래된 열쇠 자물쇠가 녹슬거나 이물질이 낀 경우
- 도어락을 나중에 덧단 곳에서 걸쇠 위치가 어긋난 경우
- 대문과 현관문이 따로 있어 어느 쪽이 안 열리는지 헷갈리는 경우
어느 쪽 문이 문제인지 먼저 구분하는 것이 중요합니다. / 대문이 안 열리는 것인지, 현관문이 안 열리는 것인지 알려주세요.

# 열쇠가 돌아가다 마는 경우
열쇠를 꽂아 돌렸는데 중간에서 걸리거나 헛도는 경우가 있습니다. / 오래된 자물쇠는 내부 부품이 마모됐거나 이물질이 껴서 그럴 때가 많습니다.
열쇠를 억지로 돌리면 열쇠가 부러져 구멍 안에 남을 수 있습니다. / 부러진 열쇠를 빼내는 일은 처음보다 훨씬 번거롭습니다.
열쇠가 잘 안 들어가거나 뻑뻑하다면 그 상태에서 멈추세요. / 이미 부러졌다면 사진을 보내주시면 도움이 됩니다.

# 문이 처져서 눌려 있다면
오래된 철문은 시간이 지나면서 경첩이 처지고 문이 아래로 조금씩 내려앉습니다. / 이러면 걸쇠가 문틀 구멍에 꽉 물려 빠지지 않습니다.
문을 위로 살짝 들어 올리면서 열쇠를 돌리면 열리는 경우가 있습니다. / 몸으로 문을 받쳐서 하중을 덜어 주는 방식입니다.
그래도 안 되면 무리하게 힘을 쓰지 마세요. / 경첩과 문틀을 같이 봐야 해서 현장에서 확인하고 말씀드립니다.
@ 태평동 오래된 현관문 개문 출장

# 언덕과 계단이 많은 동네에서 알려줄 것
태평동은 차가 들어가기 어려운 골목이 많습니다. / 위치를 정확히 알려주셔야 도착이 빨라집니다.
- 대략 어느 지하철역이나 큰길에서 가까운지
- 차가 들어올 수 있는 골목 입구가 어디인지
- 대문에서 현관까지 계단이 몇 층 정도인지
- 주변에서 눈에 띄는 가게나 건물
골목 입구에서 전화 주시면 만나서 안내받는 방법도 있습니다. / 이럴 때는 한 번에 찾아가기가 훨씬 쉽습니다.

# 대문 자물쇠와 현관 도어락이 따로 있을 때
주택은 대문과 현관문 모두 잠겨 있는 경우가 많습니다. / 한쪽이 안 열리는데 다른 쪽도 같이 문제인 경우가 있어 둘 다 알려주셔야 합니다.
대문 열쇠는 오래돼서 같은 모양의 열쇠를 구하기 어려운 경우도 있습니다. / 필요하면 새 자물쇠로 바꾸는 방법도 말씀드립니다.
무엇이 필요한지는 문을 보고 판단하며, 필요 없는 교체는 권하지 않습니다. / [도어락 수리](doorlock-repair.html)로 해결되면 그걸로 끝냅니다.

# 도착하면 먼저 거주자 확인
문을 열기 전에 사시는 분인지 먼저 확인합니다. / 주소가 나온 우편물이나 신분증, 전기요금 고지서 등으로도 가능합니다.
세입자이든 집주인이든 지금 이곳에 사는 분이면 됩니다. / 사정이 있으시면 먼저 말씀해 주세요.
번거로우실 수 있지만 안전을 위한 순서입니다. / 확인이 어려우면 작업을 할 수 없습니다.

# 문을 열 때는 이렇게 합니다
오래된 문은 문이든 자물쇠든 한 번 상하면 구하기 어려운 경우도 있습니다. / 그래서 상하지 않는 방법부터 조심스럽게 시도합니다.
작업 중에 부품이 상태가 나빠서 바꿔야 하는 경우에는 손대기 전에 먼저 말씀드립니다. / 상태를 보여드리고 설명한 뒤에 진행합니다.
어떻게 문을 여는지는 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다. / 비용과 진행 방식은 [이용안내](guide.html)에서 볼 수 있습니다.
@ 성남 태평동 주택 도어락 수리 점검

# 비용은 열기 전에 말씀드립니다
문과 자물쇠 상태를 본 뒤 얼마인지 먼저 말씀드립니다. / 동의하시면 시작하고, 아니면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 갑자기 붙는 비용은 없습니다.
부품을 바꿀 일이 생기면 따로 여쭤보고 진행합니다. / 모르는 사이에 바뀌는 일은 없습니다.

# 열고 난 뒤 점검할 것
문이 열리면 열쇠와 도어락이 다시 잘 작동하는지 같이 확인합니다. / 원인이 처진 문이었다면 경첩과 문틀 상태를 같이 알려드립니다.
오래된 도어락이 자주 말썽이면 [도어락 교체](doorlock-replace.html)를, 새로 달고 싶다면 [도어락 설치](doorlock-install.html)를 안내합니다. / 필요하지 않으면 권하지 않습니다.
나중에 같은 일이 다시 생기지 않도록 평소에 볼 부분도 알려드립니다. / 문 쪽 작은 정비만으로도 오래 가는 경우가 많습니다.

# 오래된 문을 오래 쓰는 방법
- 경첩에 틈이 보이면 일찍 조정하기
- 열쇠가 뻑뻑해지면 억지로 쓰지 말고 점검받기
- 겨울철 결로와 녹을 봄에 한 번 확인하기
- 대문과 현관문 여분 열쇠를 따로 보관하기
작은 습관이 문 앞에서 막히는 일을 줄여 줍니다. / 열쇠는 한 벌씩 다른 장소에 두면 잃어버렸을 때 큰 도움이 됩니다.

# 태평동 말고 성남 어디든
신흥동, 단대동, 은행동, 금광동, 상대원동까지 수정구와 중원구 구석구석 다닙니다. / 분당과 판교, 위례까지 성남 안이면 24시간 출동합니다.
성남 전체 안내는 [성남시 출장열쇠](seongnam.html)에, 서울과 경기 다른 지역은 [출장 지역](area.html) 지도에 있습니다.
