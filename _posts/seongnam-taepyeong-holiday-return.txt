# 며칠 비웠을 뿐인데 집 문이 낯설어졌을 때
태평동은 신흥역과 태평역이 가까운 성남 수정구 생활권으로, 명절이나 휴가철에 고향이나 여행지로 떠나는 분이 많습니다. / 짐을 잔뜩 들고 늦게 돌아와 현관 앞에 섰는데 문이 안 열리면 피로가 한꺼번에 몰려옵니다.
집을 오래 비웠다가 돌아오면 평소와 다른 일이 생기는 경우가 있습니다. / 도어락도 그 사이에 조금씩 달라져 있을 수 있습니다.
이 글은 명절이나 여행을 다녀온 뒤 문이 안 열릴 때의 원인과 확인 순서를 정리한 것입니다. / 해결되지 않으면 [성남 출장열쇠](seongnam.html)를 부르는 방법도 적었습니다.

# 집을 비운 동안 일어나는 일
사람이 없어도 도어락은 계속 대기 상태로 전기를 씁니다. / 며칠이든 몇 주든 시간이 지나는 동안 배터리는 조금씩 닳습니다.
- 배터리가 서서히 약해지다 돌아올 즈음 끝나는 경우
- 비운 동안 날씨가 변해 번호판에 습기나 결로가 생긴 경우
- 떠나기 직전 급하게 보조키를 걸고 나온 경우
- 가족이 번호를 바꿨는데 전달이 안 된 경우
이 중 어느 것인지 알아야 대처가 달라집니다. / 태평역에서 내려 오래 걸어온 뒤라면 더 지치기 쉬우니 잠깐 숨을 고르고 시작하세요. / 문 앞에서 번호판 상태를 먼저 보는 것이 가장 빠른 구분 방법입니다.
@ 태평동 명절 귀가 짐 든 채 현관문 도어락

# 번호판이 꺼져 있을 때
번호판에 아무 불도 들어오지 않으면 배터리가 다 됐을 가능성이 큽니다. / 비운 시간이 길수록 이런 일이 더 잘 생깁니다.
아래쪽에 비상 단자가 있는 도어락이라면 9V 건전지를 대어 전원을 줄 수 있습니다. / 건전지를 대는 동안 번호를 누르면 열리는 경우가 많습니다.
단자가 없는 제품이거나 건전지를 대도 반응이 없으면 혼자 애쓰지 말고 연락 주세요. / 문이 열리면 안쪽 배터리를 전부 새것으로 바꿔야 며칠 뒤 같은 일이 반복되지 않습니다.

# 번호판은 켜지는데 열리지 않을 때
번호판은 켜지는데 번호를 눌러도 열리지 않는 경우는 두 가지를 의심합니다. / 번호를 잘못 기억하고 있거나, 걸쇠가 문틀에서 빠지지 않는 경우입니다.
명절에는 가족이 모여 번호를 바꾸고 알리지 않는 일도 있습니다. / 같이 사는 가족에게 최근에 번호를 바꿨는지 먼저 물어보세요.
번호가 맞는데 모터 소리만 나고 걸쇠가 안 빠진다면 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요.

# 비운 사이 보조키가 걸린 경우
떠나기 전에 보조키를 안에서 돌려 잠그고 나가는 분은 많지 않습니다. / 하지만 문을 닫을 때 안쪽 손잡이가 눌려 걸쇠가 걸렸다면 밖에서는 번호만으로 열리지 않을 수 있습니다.
이런 경우는 도어락이 멀쩡해도 문이 열리지 않아 헷갈립니다. / 열쇠 구멍이 있는 도어락이라면 열쇠로 보조키를 푸는지 시도해 보세요.
열쇠가 있어도 안 돌아간다면 억지로 힘을 주지 마세요.

# 습기와 결로가 의심될 때
명절이 겨울이라면 현관 안팎의 온도 차 때문에 번호판에 결로가 생길 수 있습니다. / 여름 연휴에는 장마철 습기가 원인이 되기도 합니다.
마른 수건으로 번호판을 가볍게 닦고 잠시 기다린 뒤 다시 눌러 보세요. / 헤어드라이어로 바로 말리면 내부 부품이 상할 수 있으니 피해 주세요.
습기 때문에 일시적으로 반응이 없는 경우는 마르면 정상으로 돌아오기도 합니다.

# 하지 말아야 할 행동
오랜 이동 후라 피곤해서 서두르게 되지만 아래 행동은 피해 주세요.
- 손잡이를 세게 당기거나 문을 발로 차는 일
- 번호를 열 번 넘게 계속 누르는 일
- 드라이버나 카드를 문틈에 넣는 일
- 이웃집을 거쳐 베란다로 넘어가려는 일
번호를 여러 번 틀리면 도어락이 잠시 입력을 막습니다. / 멈추고 연락하는 편이 훨씬 빠릅니다.
@ 태평동 도어락 배터리 방전 비상 전원 확인

# 출장열쇠를 부를 때 알려 주세요
태평동 안에서의 위치와 가까운 역 방향, 동과 호수를 말씀해 주세요. / 지금 번호판 상태가 어떤지, 얼마나 집을 비웠는지도 알려 주시면 원인 파악에 도움이 됩니다.
- 번호판이 꺼졌는지, 켜졌는지, 경고음이 나는지
- 며칠이나 집을 비웠는지
- 최근에 번호나 배터리를 바꾼 적이 있는지
- 집 안에 사람이나 반려동물, 화분 같은 걱정되는 것이 있는지
짐이 많아 사진 찍기가 어렵다면 말씀만 해주셔도 됩니다. / 아이나 어르신과 함께 돌아온 길이라면 그 점도 알려 주세요. / 기다리는 동안 앉을 곳이나 따뜻한 곳을 찾는 데 도움이 됩니다.

# 거주 확인을 먼저 합니다
문을 열기 전에 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
여행에서 돌아온 길이라면 신분증이 가방 안에 있을 가능성이 높으니 미리 꺼내 두세요. / 늦은 시간이면 경비실에 먼저 말해 두시는 것도 도움이 됩니다. / 명절 연휴에는 관리사무소가 쉬는 경우가 많으니 경비실이나 가족을 통한 확인 방법을 미리 생각해 두세요.
확인되지 않으면 작업을 시작할 수 없습니다.

# 비용은 시작 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 동의하시면 시작하고 아니라면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품이 필요하면 교체 전에 다시 여쭙습니다.
[이용안내](guide.html)에도 진행 방식이 정리되어 있습니다.
@ 태평동 출장열쇠 비용 설명 후 작업 시작

# 문이 상하지 않게 엽니다
문을 열 때는 도어락과 문틀이 덜 상하는 방법부터 시도합니다. / 자세한 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.
열린 뒤에는 도어락이 다시 잘 잠기고 열리는지 확인합니다. / 배터리가 원인이었다면 새것으로 바꾸고, 번호를 새로 정하고 싶으시면 같이 등록합니다.

# 오래 비웠다 돌아온 집의 점검
문이 열린 뒤에는 도어락 말고도 살펴볼 것이 있습니다.
- 냉장고 속 음식과 전기 상태
- 창문과 베란다 문이 제대로 잠겨 있는지
- 수도와 가스 밸브 확인
- 우편함이나 현관 앞에 쌓인 우편물
도어락 점검이 더 필요하면 [도어락 수리](doorlock-repair.html)에서 확인할 수 있습니다.

# 다음 연휴를 위한 준비
떠나기 전에 배터리 상태를 한 번 확인하고 경고음이 있었다면 미리 교체해 두세요. / 가족에게 번호를 바꿀 때는 꼭 알리는 규칙도 정해 두면 좋습니다. / 여행 중에 가족이 먼저 집에 들를 사람이 있다면 그분께 번호와 열쇠 위치를 알려 두는 것도 방법입니다. / 연휴가 길수록 중간에 한 번 집 상태를 살펴봐 줄 사람이 있으면 마음이 편합니다.
고장이 잦은 제품이라면 연휴 전에 [도어락 교체](doorlock-replace.html)를 알아보는 것도 방법입니다. / 불필요한 교체는 권하지 않고, 필요한지 판단하는 것까지 도와드립니다.
태평동과 가까운 신흥동, 단대동, 은행동 등 성남 전 지역을 다닙니다. / 지역별 안내는 [출장 지역](area.html) 페이지에서 확인하실 수 있습니다.

? 태평동 어느 건물이든 오시나요? | 네, 태평동 전 지역과 성남 어디든 24시간 갑니다.

? 열고 나서 번호도 바꿔 주시나요? | 네, 필요하시면 새 번호 등록과 배터리 교체까지 같이 도와드립니다.

# 마무리

그래도 열리지 않으면 억지로 열려고 하지 말고 연락 주세요. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 24시출장열쇠가 안내해 드립니다.
