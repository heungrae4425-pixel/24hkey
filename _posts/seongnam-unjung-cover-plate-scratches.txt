# 운중동 현관문, 도어락만 새것이면 아쉬운 이유
문은 집의 얼굴과 같아서 작은 흠도 눈에 오래 남습니다. / 다만 외관 문제와 기능 문제는 서로 다르니 먼저 둘을 나눠서 생각하는 것이 좋습니다.
운중동은 판교역 쪽과 가까우면서도 조용한 주거지가 이어지는 동네입니다. / 오래 살면서 문을 가꾸는 분이 많아 도어락 외관의 흠집에 신경 쓰는 분이 꽤 있습니다.
특히 도어락을 새로 바꾸고 나면 이전 제품이 남긴 구멍과 자국이 눈에 띄어 마음에 걸립니다. / 이 글은 흠집과 타공 자국을 줄이는 현실적인 방법을 정리했습니다.
@ 운중동 도어락 외관 흠집과 타공 자국

# 흠집은 어디에서 생기는가
가장 흔한 곳은 손잡이 주변과 번호판 가장자리입니다. / 매일 손이 닿고 가방과 짐이 스치는 자리라 어쩔 수 없이 생기는 흔적입니다.
도어락 외관의 흠집은 대개 열쇠 고리, 가방 모서리, 택배 상자 때문에 생깁니다. / 이사 때 큰 가구를 옮기다 긁히는 경우도 많습니다.
- 손잡이 주변이 가방에 자주 쓸리는 경우
- 번호판 덮개가 열쇠에 긁히는 경우
- 청소할 때 거친 수세미로 문지른 경우
- 문틈에 억지로 도구를 넣어 생긴 상처

# 흠집을 줄이는 간단한 청소 요령
청소는 한 달에 한두 번이면 충분합니다. / 번호판 틈새에 낀 먼지는 부드러운 붓이나 면봉으로 살살 털어 내세요.
번호판 표면은 마른 부드러운 천으로 닦는 것이 가장 안전합니다. / 알코올이나 강한 세제는 표면 코팅을 상하게 할 수 있어 피하세요.
얼룩이 심하면 물에 살짝 적신 천으로 닦은 뒤 바로 마른 천으로 마무리하세요. / 금속 부분은 같은 방향으로 한 번씩 닦으면 결이 살아납니다.

# 얕은 흠집과 깊은 흠집은 다릅니다
손톱으로 눌러도 걸리지 않을 만큼 얕은 흠은 닦아서 눈에 덜 띄게 할 수 있습니다. / 손톱이 걸리는 깊은 흠은 도색이나 부품 교체가 필요한 경우가 많습니다.
도어락 표면 재질은 제품마다 달라 한 가지 방법을 일괄 권하기 어렵습니다. / 제품 사진을 보내주시면 가능한 선에서 안내드립니다.

# 외관이 거슬려 교체를 고민할 때
교체를 하면 번호 등록과 카드 등록도 새로 해야 한다는 점을 기억해 두세요. / 가족 모두가 새 번호를 알고 있어야 하니 날짜를 미리 정해 두면 좋습니다.
외관만 거슬린다면 기능은 멀쩡한 제품이니 바로 교체할 이유는 없습니다. / 먼저 기능이 정상인지, 오래 써서 걸림이나 경고음이 있는지를 따져 보세요.
고쳐서 쓸 수 있으면 교체를 권하지 않습니다. / 정말 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 교체하면 남는 타공 자국의 정체
타공이란 도어락을 달기 위해 문에 뚫어 둔 구멍을 말합니다. / 구멍은 한번 뚫으면 되돌릴 수 없어서 교체할 때 크기와 위치를 같이 고려해야 합니다.
도어락은 문에 구멍을 뚫어 고정합니다. / 새 제품이 같은 위치와 크기라면 자국이 거의 가려지지만 크기나 위치가 다르면 이전 구멍이 드러납니다.
- 이전 제품이 더 컸던 경우의 가장자리 흔적
- 나사 구멍이 새 제품과 맞지 않는 경우
- 오래 쓰며 생긴 얼룩과 도장 변색
@ 운중동 도어락 교체 후 문에 남은 타공 자국

# 설치 전에 문 두께와 구멍 크기부터
문 두께가 맞지 않으면 억지로 고정하다 문 표면이 상할 수 있습니다. / 보조키가 위쪽에 따로 있는 구조인지도 함께 확인하세요.
새 도어락이 이전 제품 구멍에 맞는지 확인하는 것이 가장 중요합니다. / 문 두께와 보조키 위치, 손잡이 높이가 맞아야 자국이 최소화됩니다.
설치 전에 문 옆면과 앞뒤 사진을 보내주시면 맞는 제품을 가늠하기 쉽습니다. / 자세한 내용은 [도어락 설치](doorlock-install.html) 페이지에 정리해 두었습니다.

# 자국을 가리는 방법들
덮개판은 모양과 색을 고를 수 있어 문 분위기에 맞추기 좋습니다. / 다만 너무 크면 오히려 어색하니 현장에서 크기를 가늠하고 정하는 편이 낫습니다.
새 제품의 몸체가 이전 구멍을 완전히 덮도록 고르는 것이 가장 깔끔합니다. / 덮개판(커버 플레이트)을 쓰면 크기가 어긋난 자국을 가릴 수 있습니다.
- 크기가 큰 제품으로 바꿔 자국을 덮기
- 별도 덮개판으로 가장자리 가리기
- 문 색에 맞는 보수용 도색 쓰기
문을 직접 칠하는 것은 마감이 어렵고 오히려 눈에 띌 수 있으니 상태를 보고 판단하세요.

# 구멍이 뚫린 자리를 건드리면 안 되는 경우
공동주택 현관문은 규정과 관리 기준이 있는 경우도 있어 관리사무소에 문의해 보는 것이 좋습니다. / 개인이 임의로 문을 가공하기 전에 확인하는 것이 안전합니다.
문 내부에 철판이 들어 있거나 방화문이라면 임의로 구멍을 넓히면 안 됩니다. / 문 구조를 해치면 방범과 안전 성능에 문제가 생길 수 있습니다.
어떤 문이든 현장에서 문을 확인한 뒤 가능한 방법을 정합니다. / 확실하지 않으면 무리하게 뚫거나 넓히지 않습니다.

# 철거할 때 흠집을 줄이는 방법
철거한 뒤에 문에 남은 접착 자국은 부드러운 천으로 천천히 닦아 주세요. / 흠집이 이미 깊게 남았다면 억지로 문지르기보다 덮개판 쪽을 고려하세요.
기존 도어락을 뗄 때 문 표면을 보호하면 자국이 훨씬 덜 남습니다. / 나사를 풀고 천천히 빼면 문에 긁힌 흔적이 적습니다.
급하게 힘으로 뽑으면 손잡이 쪽 문 표면이 눌리거나 찍힙니다. / 시간이 걸리더라도 순서대로 하는 편이 낫습니다.

# 운중동에서 전화 주실 때
사진은 밝은 곳에서 정면과 옆면을 각각 찍어 주세요. / 흠집의 깊이를 가늠하려면 비스듬한 각도의 사진이 도움이 됩니다.
- 도어락 앞뒤와 문 옆면 사진
- 현재 제품의 대략적인 크기와 모양
- 판교역 쪽 방향 등 대략적인 위치
- 외관만 바꾸고 싶은지, 기능도 문제인지
사진을 보고 가능한 방향을 먼저 안내드립니다.
@ 운중동 출장열쇠 도어락 설치 상담

# 비용은 작업 전에 말씀드립니다
도어락이 고장 나 문을 열어야 한다면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
교체만 상담하는 경우는 방문 시 문 상태를 함께 보면서 이야기합니다. / 문이 안 열리는 상황이라면 [현관문 개문](door-open.html) 페이지의 진행 방식을 먼저 보셔도 됩니다.

문 상태와 제품을 보고 작업 전에 먼저 비용을 안내합니다. / 괜찮다고 하실 때만 시작하고, 문을 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 교체 뒤에 깨끗하게 쓰는 관리
새 도어락은 첫 달에 외관 관리를 잘해 두면 오래 갑니다. / 마른 천으로 닦고 날카로운 물건과 닿지 않게 하세요.
문을 열고 닫을 때 손잡이를 잡는 습관이 번호판을 덜 긁히게 합니다. / 성남 안 다른 동네는 [성남 출장열쇠](seongnam.html)에서 확인하세요.
