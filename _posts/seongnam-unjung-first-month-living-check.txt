# 운중동 이사 후 한 달, 현관문부터 천천히 보세요
운중동은 판교역 생활권과 가까워 출퇴근길에 판교를 오가는 분들이 많은 동네입니다. / 이사 직후에는 짐 정리에 정신이 없어서 현관문은 "일단 열리니까" 하고 넘어가기 쉽습니다.
그런데 새 집에서 처음 한 달은 도어락의 상태를 알아보기 가장 좋은 때입니다. / 이 글은 입주하고 한 달 동안 해볼 점검을 순서대로 적었고, 필요하면 [성남 출장열쇠](seongnam.html)에 부탁하시면 됩니다.
@ 운중동 입주 첫 달 현관 도어락 점검

# 첫날 밤에 먼저 해두면 좋은 것
이삿짐이 들어오는 날은 문이 계속 열렸다 닫혔다 합니다. / 작업이 끝나고 조용해진 뒤에 도어락이 잘 잠기는지부터 확인해 보세요.
- 문을 닫았을 때 철컥 하고 한 번에 잠기는지
- 안쪽에서 잠금 표시가 제대로 바뀌는지
- 보조키를 돌렸을 때 걸림 없이 움직이는지
이 세 가지가 정상이면 일단 하루는 안심해도 됩니다. / 이상하면 메모해 두었다가 사진과 함께 문의해 주세요.

# 이전 거주자의 번호와 카드는 정리됐나요
가장 먼저 짚을 일은 앞서 살던 분이 등록해 둔 번호와 카드입니다. / 입주 전에 초기화되었다고 들었어도 직접 확인해 보는 편이 좋습니다.
도어락마다 방식은 다르지만 보통 안쪽 메뉴에서 등록된 정보를 지우고 새로 등록할 수 있습니다. / 번호 하나만 바꾸고 끝내지 말고 카드와 지문이 남아 있지 않은지도 같이 보세요.
이전 거주자가 쓰던 카드가 남아 있다면 새 카드로 바꾸고 기존 카드는 삭제하는 것이 원칙입니다. / 설정 방법이 낯설면 [도어락 수리](doorlock-repair.html) 쪽으로 문의해도 됩니다.

# 번호는 가족만 아는 새 번호로
번호를 새로 정할 때는 가족이 외우기 쉬우면서 남에게는 의미 없는 숫자가 좋습니다. / 메모장이나 휴대폰 사진첩에 번호를 그대로 저장해 두는 것은 피해 주세요.
새 번호는 생일이나 전화번호 끝자리처럼 남이 짐작하기 쉬운 숫자를 피합니다. / 같은 숫자가 반복되거나 순서대로 늘어나는 번호도 좋지 않습니다.
이사 때 도와준 분들이 번호를 알게 되었다면 이사가 끝난 뒤 한 번 더 바꿔 주세요. / 한 달 안에 바꾸는 습관만 들여도 훨씬 마음이 편합니다.

# 배터리 상태는 첫 주에 확인
입주한 집의 도어락 배터리가 얼마나 남았는지는 알기 어렵습니다. / 이전 거주자가 언제 갈았는지 모르기 때문입니다.
저전압 안내음이 한 번이라도 나왔다면 바로 전부 새것으로 바꿉니다. / 안 나왔더라도 입주 첫 달에 한 번 교체해 두면 기준일이 생깁니다.
교체한 날짜를 배터리 칸 덮개 안쪽에 적어 두세요. / 나중에 언제 갈았는지 몰라 헷갈리는 일이 없어집니다.

# 문이 닫히는 속도와 소리
입주 직후에는 이삿짐을 옮기느라 문을 활짝 열어 두는 시간이 길었습니다. / 그동안 문을 받쳐 둔 물건에 눌려 경첩이 약간 틀어지는 일도 생깁니다.
도어클로저가 있는 집이라면 문이 닫히는 속도를 살펴보세요. / 너무 빠르면 쾅 하고 닫히고, 너무 느리면 걸쇠가 걸리지 않고 열려 있게 됩니다.
소리가 이상하게 크거나 삐걱이면 경첩 쪽을 의심해 봅니다. / 새로 칠하거나 도배한 직후에는 문틀에 페인트가 두껍게 묻어 걸림이 생기기도 합니다.
작은 문제를 한 달 안에 알아 두면 나중에 큰 고장으로 번지기 전에 손볼 수 있습니다.
@ 운중동 현관문 도어클로저와 경첩 확인

# 이삿짐 센터 직원이 번호를 알고 있다면
짐을 옮기는 동안 현관 번호를 알려 준 경우가 많습니다. / 믿을 만한 분들이어도 이사가 끝나면 번호는 새로 정하는 것이 가장 단순한 정리입니다.
임시로 쓰던 번호를 그대로 두면 나중에 누가 알고 있는지 기억하기 어렵습니다. / 이사 당일 저녁에 바꿔 두면 가장 깔끔합니다.

# 열쇠는 몇 개 받으셨나요
이사하면서 받은 열쇠 개수를 정확히 세어 두세요. / 이전 집주인이나 관리사무소에 여분이 있는지도 한 번 물어보면 좋습니다.
오래 쓰지 않을 열쇠라면 보관 장소를 가족과 같이 정해 둡니다. / 문 앞 화분이나 우편함 아래에 두는 방법은 피해 주세요.
열쇠 복사 이야기는 간단히 넘기지 말고, 필요한지 먼저 따져 본 뒤에 결정하세요. / 보조키 자체를 새것으로 바꾸면 이전 열쇠가 쓸모없어져 한결 깔끔합니다.

# 비 오는 날과 추운 날 반응 보기
첫 달 안에 날씨가 바뀌는 날이 한 번쯤은 옵니다. / 비가 온 다음 날이나 아침 기온이 떨어진 날에 번호판 반응이 느려지지 않는지 눈여겨보세요.
평소와 다르게 번호가 한 번에 안 눌리거나 백라이트가 흐리면 배터리나 습기를 의심해 볼 수 있습니다. / 마른 수건으로 닦고 다시 눌러 보면 돌아오는 경우도 많습니다.

# 가족 모두 같은 방법으로 열 수 있나요
아이와 어르신까지 모두가 번호든 카드든 직접 열어 본 적이 있어야 합니다. / 한 사람만 방법을 알고 있으면 그 사람이 없을 때 문 앞에서 기다려야 합니다.
처음 일주일 안에 가족이 한 번씩 문 밖에서 열어 보게 하세요. / 열쇠를 안 챙기는 날을 대비해 비밀번호 알려 주는 방법도 같이 정해 둡니다.

# 한 달 점검표
점검표는 냉장고나 현관 안쪽에 붙여 두면 하나씩 지워 가기 좋습니다. / 바쁜 달이라면 번호 정리와 배터리 교체, 두 가지만이라도 먼저 끝내세요. / 나머지는 주말에 나눠서 해도 늦지 않습니다.
한 달이 지나면 아래 목록을 한번 돌아보세요.
- 번호를 가족만 아는 새 번호로 바꿨는지
- 이전 카드와 지문이 남아 있지 않은지
- 배터리 교체일을 적어 두었는지
- 보조키와 열쇠 개수가 맞는지
- 문이 한 번에 닫히고 잠기는지
빠진 게 있으면 이번 주말에 하나씩 해결하세요.

# 점검하다 문제가 보이면
점검 중 모터 소리만 나거나 걸쇠가 덜 들어간다면 혼자 분해하지 마세요. / 나사를 풀다가 부품이 어긋나면 오히려 못 열게 되는 일도 있습니다.
증상을 사진이나 영상으로 남겨 두면 전화로 설명하기 쉽습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않고, 정말 오래된 제품일 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 점검 중 문이 잠겨 버렸다면
번호를 바꾸는 중에 문이 밖에서 닫히면 이전 설정과 새 설정이 섞여 열리지 않을 수 있습니다. / 억지로 여러 번 시도하면 입력이 일정 시간 잠기니 서너 번 해보고 멈추세요.
출동하면 사시는 분인지 먼저 확인합니다. / 이사 직후라 우편물이 없다면 계약서나 관리사무소 확인 같은 방법을 말씀해 주세요.
못 열면 비용은 받지 않고, 열기 전에 비용은 먼저 말씀드립니다. / 개문 방식은 [현관문 개문](door-open.html)에서 볼 수 있습니다.
@ 운중동 출장열쇠 도어락 번호 재설정
