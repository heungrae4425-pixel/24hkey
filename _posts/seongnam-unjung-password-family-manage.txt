# 비밀번호는 정하는 것보다 관리가 더 어렵습니다
성남 운중동에서 도어락 비밀번호를 한 번 정해 놓고 몇 년째 그대로 쓰는 집이 의외로 많습니다. / 편하긴 하지만 가족이 늘거나 사람이 드나들면 번호를 누가 아는지 알 수 없어집니다.
이 글은 비밀번호를 안전하고 편하게 관리하는 방법과, 번호를 잊었을 때 [성남 출장열쇠](seongnam.html)가 어떻게 도와드리는지 적었습니다.
어려운 이야기는 없고 오늘부터 해 볼 수 있는 것들입니다.
@ 운중동 도어락 비밀번호 관리 출장열쇠

# 번호를 바꿔야 하는 때
다음과 같은 일이 있었다면 번호를 바꾸는 것이 좋습니다.
- 이사 직후 이전 거주자의 번호가 남아 있을 때
- 가사도우미나 방문 업체에게 번호를 알려준 적이 있을 때
- 가족 중 연락이 끊기거나 사이가 틀어진 사람이 번호를 알 때
- 번호를 누르는 모습이 다른 사람에게 보였을 가능성이 있을 때
- 오랫동안 한 번도 바꾸지 않았을 때
한 번만 짚어 봐도 대부분 해당되는 것이 있습니다.

# 좋은 번호와 나쁜 번호
생일이나 전화번호 끝자리처럼 남이 쉽게 짐작하는 번호는 피하세요. / 1234, 0000, 같은 숫자 반복은 가장 먼저 시도되는 번호입니다.
번호판에 손자국이 남으면 어떤 숫자를 눌렀는지 보이는 경우가 있습니다. / 가끔 번호판을 닦아 주는 것만으로도 도움이 됩니다.
번호 길이가 길수록 추측이 어려워지니 가능한 길이로 설정하는 것이 좋습니다.

# 가족과 번호 나눠 쓰는 요령
가족 모두가 같은 번호를 쓰면 편하지만 누가 바꿔도 다른 사람이 모르게 되는 일이 생깁니다. / 번호를 바꿀 때는 가족에게 바로 알리는 약속을 정해 두세요.
카드나 태그를 한 장씩 나눠 가지면 번호를 잊었을 때도 대비가 됩니다. / 번호만 믿으면 방전이나 오류 때 가족이 모두 못 들어오는 일이 생깁니다.
@ 운중동 가족 도어락 번호 공유

# 가사도우미나 방문자에게 번호 알려줄 때
잠시 방문하는 분에게는 영구 번호보다 임시로 쓰는 방식이 안전합니다. / 일회용 번호를 지원하는 도어락이면 그 기능을 쓰세요.
기능이 없다면 방문이 끝난 날 바로 번호를 바꾸는 것이 낫습니다. / 번호를 바꾸는 일이 번거로워 미루다 보면 계속 쓰이게 됩니다.

# 번호를 바꾸는 법은 모델마다 다릅니다
같은 회사 제품도 모델에 따라 번호 변경 방법이 다릅니다. / 안쪽 버튼을 누르고 새 번호를 등록하는 방식이 가장 흔합니다.
설명서가 없거나 방법이 헷갈리면 억지로 눌러 보지 마세요. / 잘못 누르면 이전 번호가 삭제돼 오히려 문제가 생길 수 있습니다.
모르는 부분은 사진을 보내 주시면 방법을 알려드립니다.

# 번호를 잊었을 때는
번호를 잊었다고 해서 문을 부수거나 큰 작업을 해야 하는 것은 아닙니다. / 도어락 종류에 따라 열쇠, 카드, 비상 전원 같은 방법이 있습니다.
방법이 없다면 출장열쇠가 사시는 분 확인 후 문을 열고 새 번호를 등록해 드립니다. / 기존 번호는 지우고 새 번호만 남겨 둡니다.
열쇠가 없는 모델이라면 번호를 잊는 일이 더 곤란하니 번호는 꼭 따로 메모해 두세요.

# 번호 메모는 이렇게 보관하세요
번호를 문 가까이에 적어 두면 위험합니다. / 휴대폰 메모 앱의 비밀 메모나 잠금 기능이 있는 곳을 이용하세요.
가족 중 한 사람이 번호를 알고 있도록 약속하는 것도 방법입니다. / 번호를 변경할 때마다 새 번호를 기록하는 습관이 중요합니다.
@ 운중동 도어락 번호 메모 보관

# 문이 안 열릴 때 전화 요령
전화하실 때 운중동 위치와 번호판 상태를 알려주세요. / 번호를 잊었는지, 번호는 아는데 안 열리는지도 말씀해 주시면 좋습니다.
안에 사람이나 반려동물이 있는지도 알려주시면 작업 순서를 정하는 데 도움이 됩니다.
현관문 개문 방법은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 그 집에 사시는 분인지 먼저 확인합니다. / 신분증의 주소, 주소가 찍힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 이웃과 집을 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 할 때는 바꾸기 전에 꼭 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 오래된 번호키를 바꿔야 할 때
도어락이 너무 오래돼 번호 변경이 안 되거나 반응이 느리다면 교체를 생각해 볼 수 있습니다. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)가 먼저입니다.
교체가 필요하다면 [도어락 교체](doorlock-replace.html) 페이지를 참고하시고 사진을 보내 주세요.

# 운중동 말고 성남 어디든
성남 안이라면 분당, 수정, 중원 어디든 24시간 출동합니다. / 운중동 주변 동네도 위치만 알려주시면 됩니다.
성남 전체 안내는 [성남시 출장열쇠](seongnam.html)에, 다른 지역은 [출장 지역](area.html) 지도에 있습니다.

# 번호를 바꾼 뒤에 꼭 해보는 확인
번호를 바꾸고 나서 문을 닫기 전에 안쪽에서 새 번호로 한 번 열어 보세요. / 문 안에서 잘 되는지 확인하지 않고 닫으면 바깥에서 막힐 수 있습니다.
가족에게 새 번호를 알릴 때는 메시지에 번호만 남기지 말고 말로 전달하는 것이 안전합니다. / 알린 뒤에는 각자 직접 눌러 보게 해 보세요.
이전 번호가 남아 있지 않은지도 확인하면 마무리가 됩니다.
