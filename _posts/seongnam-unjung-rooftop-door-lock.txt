# 운중동 옥상 문, 평소엔 잊고 지내다가
운중동은 판교역 쪽 생활권과 이어지면서도 주택과 빌라가 조용히 모여 있는 동네입니다. / 옥상이 있는 건물이 많아 빨래를 널거나 화분을 돌볼 때 옥상 문을 드나드는 분들이 계십니다.
옥상 문은 현관문처럼 매일 쓰지 않아서 열쇠가 어디 있는지, 잠금이 어떻게 되어 있는지 모르고 지내기 쉽습니다. / 정작 필요한 날 열쇠가 없거나 문이 안 열리면 당황스럽습니다.
이 글은 [성남 출장열쇠](seongnam.html)를 찾기 전에 옥상 출입문 잠금과 열쇠 보관을 어떻게 정리하면 좋은지 적은 것입니다.
@ 운중동 건물 옥상 출입문 잠금장치

# 옥상 출입문은 왜 따로 챙겨야 할까요
옥상 문은 비바람과 햇빛을 그대로 받는 곳에 있어 안쪽 문보다 쉽게 낡습니다. / 열쇠 구멍에 먼지가 쌓이거나 녹이 슬어 열쇠가 뻑뻑해지는 일이 흔합니다.
또 한 건물에 사는 여러 세대가 같이 쓰는 문이라 열쇠 관리가 흐트러지기 쉽습니다. / 누가 갖고 있는지 모르는 열쇠가 여러 개 돌아다니기도 합니다.

# 우선 어떤 방식의 잠금인지부터 알아두세요
옥상 문은 보통 열쇠로 여는 실린더 방식이나 안쪽에서 돌려 잠그는 방식이 쓰입니다. / 도어락이 달린 곳도 있지만 대부분 단순한 구조입니다.
- 바깥에서 열쇠를 꽂아 여는 문인지
- 안쪽에서만 잠그는 걸이식 문인지
- 번호나 카드로 여는 도어락인지
어느 쪽인지 알아 두면 문제가 생겼을 때 전화로 설명하기 편합니다.
문 모양과 손잡이 형태도 사진으로 한 장 찍어 두세요. / 평소에 찍어 둔 사진 한 장이 급한 날 설명 시간을 크게 줄여 줍니다.

# 열쇠는 한 곳에 모아 보관하세요
옥상 열쇠는 현관 열쇠와 따로 놓으면 잃어버리기 쉽습니다. / 건물에 관리하는 분이 있다면 그분께, 없다면 세대끼리 정해 한 곳에 두는 것이 좋습니다.
열쇠에 이름표나 표시를 붙여 두면 필요할 때 헤매지 않습니다. / 다만 주소나 호수를 크게 써서 걸어 두는 것은 피해 주세요.
보관 장소를 가족이나 같은 건물 사람들과 공유해 두면 급할 때 큰 도움이 됩니다.

# 옥상 문이 안 열릴 때 확인 순서
먼저 열쇠가 맞는지 확인합니다. / 다른 열쇠를 가져와 꽂고 있는 경우가 의외로 많습니다.
열쇠가 들어가는데 돌아가지 않으면 구멍 안쪽 이물질을 의심해 볼 수 있습니다. / 억지로 돌리면 열쇠가 부러질 수 있으니 힘을 주지 마세요.
문이 열쇠로는 풀리는데 밀어도 안 열린다면 문이 틀에 끼었거나 안쪽 걸이가 걸려 있는 경우입니다. / 비가 많이 온 뒤에는 목재나 철문이 부풀어 잘 안 열리기도 합니다.
@ 옥상 문 열쇠 구멍 이물질 확인

# 하지 말아야 할 것들
열쇠 구멍에 기름을 마구 뿌리면 먼지가 엉겨 더 막힐 수 있습니다. / 윤활제는 전용 제품을 소량만 쓰는 것이 낫고, 잘 모르면 쓰지 마세요.
철사나 송곳을 넣어 직접 열어 보려는 시도도 위험합니다. / 구멍 안 부품이 망가져 열쇠로도 못 열게 될 수 있습니다.
옥상 난간 쪽으로 돌아서 들어가려는 행동은 절대 하지 마세요. / 추락 위험이 있으니 안전이 먼저입니다.

# 옥상에 갇혔다면 이렇게 하세요
옥상으로 올라갔다가 문이 닫히며 안쪽에서 열리지 않는 경우가 있습니다. / 이럴 때는 먼저 휴대폰이 있는지 확인하고 침착하게 연락해 주세요.
옥상 문 앞에 서서 휴대폰 불빛으로 문 안쪽 잠금 구조를 사진으로 찍어 보내주시면 도움이 됩니다. / 날씨가 춥거나 어두운 때는 몸을 보호하고 난간에서 떨어져 계세요.
아이나 어르신이 같이 계시면 꼭 먼저 말씀해 주세요. / 옥상 문 안쪽에 비상 개폐 장치가 있는 건물도 있으니 문 안쪽을 차분히 살펴보시고, 그것을 억지로 부수려 하지는 마세요. 건물에 관리하는 분이 있다면 같이 연락해 두면 확인이 빨라집니다.

# 비 오는 날과 겨울에 더 신경 쓸 점
비가 오는 날에는 문 아래 틈으로 물이 스며 잠금장치가 젖습니다. / 젖은 상태에서 억지로 열쇠를 돌리지 말고 마른 천으로 닦은 뒤 시도하세요.
겨울에는 얼어서 열쇠가 안 들어가는 일이 있습니다. / 뜨거운 물을 붓는 것은 오히려 얼어붙을 수 있으니 피하고 손의 온기로 천천히 녹여 주세요.
눈이 쌓인 날에는 문 앞 바닥이 미끄러워 넘어질 위험도 큽니다. / 급하지 않은 일이면 날이 풀린 뒤로 미루는 것도 방법입니다.
옥상에 널어 둔 빨래나 화분 때문에 꼭 올라가야 한다면 문이 완전히 닫히지 않게 무엇인가 받쳐 두고 다니세요. / 문이 바람에 닫히면서 잠기는 사고가 생각보다 자주 납니다.

# 운중동에서 위치를 알려주는 요령
옥상 문은 건물 이름보다 길 이름이나 가까운 큰길로 설명하는 편이 빠릅니다. / 판교역 방향에서 어느 쪽인지 함께 알려주세요.
- 건물 층수와 옥상 문이 있는 위치
- 열쇠를 꽂는 문인지, 번호로 여는 문인지
- 지금 사람이 안에 있는지, 밖에 있는지
- 사진 한두 장
사진은 문 전체와 잠금장치 가까이를 각각 찍어 주시면 됩니다.

# 방문하면 먼저 확인하는 것
옥상 문은 건물 공용 공간일 수 있어 관리하시는 분인지, 건물에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 건물주 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.

# 비용은 열기 전에 먼저 말씀드립니다
문 상태와 잠금 종류를 보고 작업 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 들면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
@ 운중동 옥상 문 열기 전 상태 확인

# 연 뒤에는 열쇠를 정리해 드립니다
문이 열리면 열쇠가 잘 돌아가는지, 잠금이 정상인지 확인합니다. / 열쇠가 하나뿐이면 여분을 만드는 방법도 상의합니다.
잠금장치가 심하게 낡았으면 [도어락 교체](doorlock-replace.html)를 말씀드리고, 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 열쇠를 여러 사람이 쓰는 건물이라면 번호식으로 바꾸는 방법도 있습니다.

문을 최대한 상하지 않게 여는 방법부터 시도합니다. / 열쇠가 부러졌거나 구멍이 막혔어도 먼저 상태를 보고 방법을 정합니다. / 자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.
열쇠를 잃어버렸다면 [열쇠 출장](key-call.html) 안내도 함께 보시고, 이용 방식은 [이용안내](guide.html)에도 있습니다.
