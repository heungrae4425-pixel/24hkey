# 부모님 집 현관은 자녀가 먼저 살펴야 합니다
위례동에 사시는 부모님 댁에 갈 때마다 도어락이 예전 같지 않다고 느끼신 적이 있을 겁니다. / 어르신들은 불편해도 참고 지내시다가 문이 아예 안 열리고 나서야 연락하시는 경우가 많습니다.
번호가 안 떠올라 애를 쓰시거나, 경고음이 계속 나는데 어떻게 하는지 몰라 그냥 두시기도 합니다. / 이 글은 위례동 부모님 집 도어락을 자녀가 미리 점검하는 요령과 어르신이 쓰기 편한 설정을 정리했습니다.
혹시 지금 부모님이 문 앞에서 막혀 계시다면 [성남 출장열쇠](seongnam.html)로 바로 연락 주세요.
@ 위례동 부모님 댁 도어락 점검

# 방문하는 날 5분이면 끝나는 점검
부모님 댁에 가실 때 도어락만 따로 살펴보는 시간을 가지세요.
- 번호판이 선명하게 켜지는지
- 번호를 누를 때 소리가 평소와 같은지
- 열고 닫을 때 걸쇠가 부드럽게 움직이는지
- 경고음이 나는 적이 있었는지 부모님께 여쭤보기
- 배터리를 마지막으로 바꾼 시기 확인하기
이 정도만 해도 갑자기 안 열리는 상황을 대부분 미리 막습니다. / 부모님께 직접 물어보면 평소 불편한 점도 알게 됩니다.
어르신들은 불편을 말씀하지 않으시는 경우가 많으니, 직접 문을 열고 닫아 보시게 하면서 지켜보세요. / 손가락 힘이 약해져 번호 버튼을 세게 못 누르시는 일도 있습니다.
위례동처럼 새로 조성된 동네라도 집 안 살림이 오래된 부모님 댁이라면 문은 이미 한참 쓴 상태일 수 있습니다. 도어락이 그만큼 낡았다는 뜻은 아니지만 정기 점검은 필요합니다.

# 배터리는 날짜를 정해서 한 번에 교체
어르신 댁에서 가장 흔한 문제는 배터리입니다. / 경고음이 울려도 무슨 소리인지 몰라 방치하다 방전됩니다.
자녀가 올 때마다 새 배터리로 한 번에 갈아 두면 안심이 됩니다. / 일부만 바꾸면 곧 다시 같은 일이 생깁니다.
배터리 칸에 교체한 날짜를 적어 두세요. / 부모님이 보셔도 알 수 있게 큰 글씨로 적으면 더 좋습니다.

# 번호는 기억하기 쉽게, 하지만 단순하지 않게
어르신이 번호를 자주 잊으신다면 외우기 쉬운 번호로 바꾸는 방법이 있습니다. / 다만 생일이나 전화번호처럼 누구나 짐작할 수 있는 숫자는 피하는 게 좋습니다.
- 부모님과 자녀 모두 기억할 수 있는 의미 있는 숫자 조합
- 눌러 본 번호가 맞는지 소리나 불빛으로 확인하기
- 자녀들이 번호를 공유해 두기
번호를 종이에 적어 현관 근처에 붙이는 건 위험하니 피해 주세요. / 대신 카드나 열쇠를 함께 쓰도록 안내하면 좋습니다.
@ 어르신 번호 버튼 크기와 불빛 확인

# 버튼이 크고 불빛이 밝은 제품이 편합니다
눈이 침침하신 분에게는 번호판의 밝기와 글자 크기가 중요합니다. / 버튼이 작고 불빛이 약한 제품은 어두운 저녁에 쓰기 어렵습니다.
- 버튼 글자가 크고 선명한 제품
- 눌렀을 때 소리나 음성 안내가 있는 제품
- 손잡이가 잡기 편한 모양인 제품
바꾸는 것까지는 아니더라도 번호판 앞에 작은 조명을 달거나 센서등을 설치하는 방법도 있습니다. / 제품 선택은 [도어락 교체](doorlock-replace.html)에서 더 자세히 볼 수 있습니다.
교체를 결정하기 전에는 부모님이 직접 손으로 눌러 보시게 하는 것이 가장 정확합니다. / 자녀 눈에 편해 보여도 어르신에게는 버튼 간격이 좁을 수 있습니다.
설명서 글씨가 작아 못 읽으시는 경우도 많으니, 자주 쓰는 기능만 큰 글씨로 정리한 안내문을 안쪽 문에 붙여 드리는 것도 좋습니다.

# 카드나 태그를 쓰면 번호가 필요 없습니다
번호를 자주 잊으시는 분께는 카드를 쓰는 방법이 편할 수 있습니다. / 목걸이나 열쇠고리에 달아 두면 따로 번호를 외울 필요가 없습니다.
다만 카드를 잃어버리지 않게 가방이나 현관 근처 정해진 자리에 두도록 안내하세요. / 두 번째 수단으로 지문이나 번호를 같이 두는 것이 안전합니다.
카드를 잃어버렸을 때는 [카드키 분실](key-call.html) 안내를 참고하세요.

# 부모님께 알려드리면 좋은 비상 대응
문 앞에서 당황하지 않도록 간단한 순서를 정해 드립니다.
- 번호판이 꺼져 있으면 무리하지 말고 자녀에게 전화하기
- 경고음이 울리면 그날 바로 가족에게 알리기
- 번호를 여러 번 틀리면 잠시 쉬었다가 천천히 다시 누르기
큰 글씨로 연락처를 적어 지갑이나 현관 안쪽에 붙여 두면 도움이 됩니다. / 휴대폰 단축번호에 자녀와 이 번호를 저장해 드리는 것도 방법입니다.
만약 부모님이 혼자 계시다가 문이 안 열려 불안해하신다면 통화를 끊지 말고 이어서 안내하세요. / 목소리를 들려 드리는 것만으로도 큰 도움이 됩니다.
자녀가 멀리 있어 바로 못 가는 경우에도 전화로 위치와 상황을 알려주시면 출동할 수 있습니다. 도착 시간과 신분 확인 방법은 통화로 부모님께도 쉽게 설명드립니다.

# 혼자 계신 부모님 집 문이 안 열릴 때
부모님이 집 안에 계시는데 안에서 문이 안 열리는 경우도 있습니다. / 안쪽 버튼이 눌러지지 않거나 손잡이가 돌아가지 않을 때입니다.
이럴 땐 부모님께 문을 억지로 흔들지 마시라고 먼저 말씀드리세요. / 침착하게 현재 상황을 전화로 전해 주시면 가장 빠르게 도울 수 있습니다.
몸이 불편하시거나 응급이 의심되면 119 연락이 먼저입니다. / 그 후 문을 열어야 할 때 저희에게 연락 주세요.

# 도착하면 신분과 관계를 확인합니다
부모님 댁 문을 자녀가 요청하는 경우에는 확인이 더 중요합니다. / 부모님이 직접 연락 가능하면 통화로 확인하고, 어려우면 신분증과 가족 관계를 확인할 수 있는 서류, 관리사무소 확인을 안내드립니다.
번거로울 수 있지만 부모님 집을 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 상의해 주세요.
@ 위례동 부모님 댁 신분 확인

# 비용은 문 열기 전에 말씀드립니다
고령 부모님 댁이라고 달라지는 것은 없습니다. / 상태를 보고 먼저 알려드리고, 동의하신 뒤에만 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부모님께도 같은 내용을 쉬운 말로 한 번 더 설명드립니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 열고 난 뒤에는 부모님 눈높이에 맞춥니다
문이 열린 뒤에는 기능을 단순하게 정리합니다. / 쓰지 않는 모드는 꺼 두고, 번호와 카드 둘 정도만 남겨 둡니다.
- 필요 없는 임시 번호 삭제
- 경고음 소리와 알림 방식 확인
- 안쪽 잠금 버튼이 쓰기 편한 위치인지 보기
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 설치 요령은 [도어락 설치](doorlock-install.html)에 있습니다.

# 위례동 말고 성남 어디든 갑니다
위례동 주변은 물론 성남 전역을 다닙니다. / 다니는 동네는 [성남시 출장열쇠](seongnam.html)에서 보시고, 다른 지역은 [출장 지역](area.html)에서 확인하세요.
