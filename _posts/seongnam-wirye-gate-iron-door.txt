# 위례동 철문 앞에서 멈췄다면
위례동은 신도시 생활권이라 아파트 외에도 단독 주택, 상가 주택처럼 대문이나 철문을 따로 쓰는 집이 섞여 있습니다. / 현관문이 아니라 집 앞 대문이나 공동 출입문이 막혀서 연락하시는 분도 적지 않습니다.
이 글은 위례동에서 철문과 공동 출입문이 안 열릴 때 무엇부터 보고 어떻게 연락하면 되는지 정리한 글입니다. / 가까운 지하철역 방향으로 퇴근해 돌아오는 밤에도 그대로 따라 하실 수 있게 적었습니다.
현관문과 달리 대문은 바깥에서 비바람을 직접 맞기 때문에 고장 원인이 조금 다릅니다. / 그래서 이 글은 대문과 철문 위주로 구성했습니다.
@ 위례동 철문 대문 출입문 열쇠 출장

# 대문과 현관문은 고장 나는 방식이 다릅니다
현관문은 집 안쪽 공기 속에 있어서 주로 배터리나 비밀번호 문제가 많습니다. / 대문은 비, 눈, 먼지를 그대로 맞아서 녹과 이물질이 먼저 문제를 일으킵니다.
- 자물쇠 구멍에 흙이나 먼지가 들어가 열쇠가 뻑뻑한 경우
- 철문이 처지면서 빗장이 받침 구멍에 맞지 않는 경우
- 빗장이나 래치가 녹슬어 움직이지 않는 경우
- 오래 안 쓴 자물통이 굳어 버린 경우
같은 대문이라도 증상에 따라 해야 할 일이 달라지므로 어느 쪽인지 먼저 구분해 보세요.

# 열쇠가 들어가는데 안 돌아간다면
열쇠가 끝까지 들어가는데 돌아가지 않으면 구멍 안쪽 부품이 굳었을 가능성이 큽니다. / 이때 힘으로 돌리면 열쇠가 부러져 박힐 수 있어 가장 조심해야 합니다.
열쇠를 살짝 뺐다가 다시 넣고, 좌우로 아주 약하게 흔들며 돌려 보는 정도까지만 해보세요. / 그래도 막히면 더 힘주지 말고 멈추는 게 좋습니다.
기름 스프레이를 급하게 뿌리는 분이 있는데, 먼지와 엉겨 오히려 더 굳는 일이 있습니다. / 어떤 제품을 썼는지 전화로 알려주시면 작업 방법을 고르는 데 도움이 됩니다.

# 문이 처져서 빗장이 안 맞을 때
철문은 무거워서 경첩이 오래되면 조금씩 아래로 처집니다. / 처진 문은 빗장이 받침에 정확히 들어가지 않아서 잠그기도 열기도 어렵습니다.
문을 두 손으로 살짝 들어 올리면서 열쇠를 돌렸을 때 돌아간다면 처짐이 원인입니다. / 이런 문은 열고 나서 경첩 쪽을 따로 손봐야 같은 일이 반복되지 않습니다.
밤에는 문 아래 틈 간격을 보기 어려우니 낮에 다시 확인하는 것도 방법입니다. / 억지로 문을 흔들면 용접 부위가 상할 수 있습니다.

# 공동 출입문은 혼자 판단하지 마세요
다세대 주택이나 상가 건물의 공동 출입문은 여러 세대가 같이 쓰기 때문에 한 사람이 마음대로 열고 바꿀 수 없는 경우가 많습니다. / 관리하는 분이 따로 있다면 먼저 그분께 연락해 보세요.
- 건물을 관리하는 분이나 대표 연락처가 있는지
- 이웃 세대 중 같은 열쇠나 비밀번호를 가진 분이 있는지
- 문이 자동 잠김인지, 열쇠로만 잠기는지
이 세 가지만 알아도 전화로 상황을 설명하기 쉽습니다. / 공동 출입문은 사시는 분이 맞는지 확인하는 절차를 더 꼼꼼히 하는 편입니다.

# 비 오는 날과 겨울에 더 자주 생깁니다
비가 많이 오면 대문 자물쇠 안으로 물이 들어가 안쪽이 녹슬기도 합니다. / 겨울에는 물기가 얼어서 열쇠가 들어가지 않거나 돌아가지 않을 때도 있습니다.
얼었을 때 뜨거운 물을 붓는 분이 있는데, 다시 얼면 상황이 더 나빠집니다. / 손으로 열쇠 몸통을 잠시 감싸 체온을 전해 주는 정도가 안전합니다.
@ 성남 위례동 대문 자물쇠 점검 출장열쇠

# 전화하실 때 알려주면 좋은 것
위례동은 길이 반듯해 보여도 건물 이름 없이 설명하면 헷갈리기 쉽습니다. / 가까운 큰길과 건물 모양을 같이 말씀해 주시면 도착이 빨라집니다.
- 대문, 철문, 공동 출입문 중 어느 문인지
- 자물쇠 모양과 열쇠 모양
- 안 열리는 문이 집 밖에 있는지, 안쪽 문까지 잠겨 있는지
- 문 앞에 휴대폰으로 찍은 사진이 있는지
사진 한 장이 있으면 어떤 장비를 챙길지 미리 정할 수 있습니다. / 사진이 없어도 괜찮으니 말로 편하게 설명해 주세요.

# 도착해서 먼저 하는 일은 신분 확인
대문이나 공동 출입문도 남의 집 문을 여는 일이라 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증을 집 안에 두고 나오셨다면 가까운 이웃이나 건물 관리하는 분께 확인을 부탁할 수 있습니다. / 확인이 되지 않으면 작업을 할 수 없으니 미리 준비해 주세요.

# 철문을 여는 방법과 순서
철문은 구조가 단순해 보여도 문과 문틀이 서로 물려 있어서 한쪽만 건드리면 어긋나기 쉽습니다. / 그래서 겉모습이 덜 상하는 방법부터 차례로 시도합니다.
자물쇠 안쪽 상태를 먼저 보고, 열쇠 구멍이 막혔는지 빗장이 걸렸는지 구분한 뒤 방법을 정합니다. / 부품을 바꿔야 하면 바꾸기 전에 꼭 말씀드립니다.
문을 여는 일반적인 방법은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다. / 대문도 기본 원칙은 같습니다.
@ 성남 철문 자물쇠 비파손 개방 작업

# 비용은 시작 전에 설명드립니다
문 종류, 자물쇠 상태, 시간대를 보고 먼저 얼마인지 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니라고 하시면 그대로 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식이 궁금하면 [이용안내](guide.html)를 먼저 보셔도 됩니다.

# 열고 난 뒤 같이 보는 것
문이 열렸다고 끝이 아니라 다시 잠그고 열 때 부드러운지 확인합니다. / 열쇠가 뻑뻑했던 문이라면 자물쇠를 새로 바꿀지, 청소만으로 충분한지 같이 판단합니다.
고쳐 쓸 수 있으면 교체를 권하지 않습니다. / 대문 자물쇠는 비바람에 약해 [도어락 교체](doorlock-replace.html)나 자물통 교체가 필요한 경우도 있어 그때 설명드립니다.
대문에도 번호식 잠금장치를 달고 싶다면 [도어락 설치](doorlock-install.html) 페이지를 참고해 주세요. / 야외용인지 먼저 확인하는 것이 중요합니다.

# 대문 자물쇠를 오래 쓰는 습관
- 열쇠 구멍 주변을 가끔 마른 천으로 닦기
- 빗장이 뻑뻑해지기 시작하면 바로 점검받기
- 여분 열쇠를 가족과 나눠 갖되 한 개는 따로 보관
- 처진 문은 더 처지기 전에 경첩부터 손보기
- 겨울 전에 열쇠가 부드럽게 들어가는지 한 번 확인
이런 점검은 5분 정도면 끝나지만 한밤중에 문 앞에서 막히는 일을 크게 줄여 줍니다. / 평소와 다른 소리가 나면 그날 바로 확인해 주세요.

# 위례동 말고 성남 어디든 갑니다
위례동 옆 창곡동, 복정동은 물론 정자동, 서현동, 수내동, 야탑동, 판교 쪽까지 성남 전 지역을 다닙니다. / 모란역이나 서현역 근처처럼 구시가지와 신도시 어디든 24시간 출동합니다.
성남에서 다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에서 볼 수 있습니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.
