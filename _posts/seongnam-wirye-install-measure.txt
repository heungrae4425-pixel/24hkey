# 새 도어락, 사기 전에 문부터 보세요
성남 위례동에서 새로 입주하거나 이사하면서 도어락을 직접 고르는 분들이 있습니다. / 마음에 드는 제품을 먼저 사 놓고 나중에 문에 안 맞아 곤란해지는 일이 가장 흔합니다.
이 글은 도어락을 설치하기 전에 문에서 확인할 것과 [성남 출장열쇠](seongnam.html)가 출장 설치할 때 어떤 순서로 보는지 적었습니다.
제품을 사기 전에 읽으시면 가장 도움이 됩니다.
@ 위례동 도어락 설치 전 문 확인

# 도어락이 안 맞는 가장 흔한 이유
도어락은 같은 모양이어도 문에 뚫린 구멍과 문 두께가 다르면 달 수 없습니다. / 제품 상자에는 맞는 문 두께와 구멍 규격이 적혀 있습니다.
인터넷에서 산 제품이 안 맞으면 반품과 재구매가 번거롭습니다. / 먼저 문 상태를 알려주시면 맞는 제품을 알려드릴 수 있습니다.

# 확인 1. 문 두께
문을 열고 옆면을 보면 문의 두께를 알 수 있습니다. / 줄자로 재거나 문 가장자리를 사진으로 찍어 두세요.
요즘 현관문은 두께가 서로 달라 도어락 규격과 맞는지 확인해야 합니다. / 두께가 규격을 벗어나면 별도 부품이 필요하거나 설치가 어려울 수 있습니다.
두께만 알아도 후보를 크게 줄일 수 있습니다.

# 확인 2. 기존 도어락 구멍 위치
이미 달린 도어락이 있다면 떼어 내기 전에 사진을 여러 장 찍어 두세요. / 손잡이 구멍, 보조키 구멍, 걸쇠 위치가 새 제품과 맞아야 합니다.
구멍 위치가 다르면 문에 새로 구멍을 뚫어야 할 수 있습니다. / 문 마감이 상할 수 있으니 이 부분은 꼭 미리 상의하세요.
@ 위례동 도어락 설치 구멍 규격 확인

# 확인 3. 보조키 유무
보조키는 문 위쪽에 달린 별도 잠금장치입니다. / 도어락과 따로 달려 있어 새 제품에서 쓸지 정하는 것도 중요합니다.
보조키를 없애고 일체형으로 바꾸는 방법도 있고, 그대로 두고 도어락만 바꾸는 방법도 있습니다. / 문 상태와 사시는 분의 편의에 따라 정하시면 됩니다.

# 확인 4. 문 재질
문이 철문인지, 나무문인지, 유리가 들어간 문인지에 따라 설치 방법이 달라집니다. / 철문은 단단해 구멍 작업이 번거롭고, 나무문은 마감이 상하기 쉽습니다.
유리문이나 얇은 문은 도어락 무게를 견디는지도 확인해야 합니다. / 재질을 모르면 문 안쪽과 바깥쪽 사진을 찍어 보내 주세요.

# 확인 5. 어떤 방식으로 열고 싶은지
번호만 쓰면 충분한지, 카드나 지문도 쓰고 싶은지 먼저 정하면 제품이 좁혀집니다. / 가족 수와 사용 방식에 따라 편한 방식이 달라집니다.
기능이 많을수록 배터리와 부품이 늘어 관리할 것도 늘어납니다. / 처음 쓰는 분이라면 꼭 필요한 기능부터 정하시길 권합니다.
어떤 제품이 맞는지는 [도어락 설치](doorlock-install.html) 페이지에 정리해 두었습니다.

# 출장 설치 요청하실 때 알려주세요
- 위례동 어느 쪽인지(건물이 보이는 위치와 층)
- 새 제품을 이미 샀는지, 제품 추천이 필요한지
- 기존 도어락 사진과 문 옆면 사진
- 보조키를 쓸지 정했는지
- 설치를 원하는 날짜와 시간
사진이 있으면 현장에서 헛걸음 없이 준비해 갈 수 있습니다.

# 출장 설치는 이 순서로 진행합니다
먼저 도착해서 문과 기존 도어락 상태를 확인합니다. / 그다음 어떤 제품을 어떻게 달지 설명드리고 동의하시면 시작합니다.
기존 도어락을 떼어 내고 구멍을 확인해 새 제품을 맞춰 설치합니다. / 설치가 끝나면 번호 등록과 열림, 잠금 시험을 같이 해봅니다.
설치 중에 부품이 더 필요하거나 문에 손을 대야 하면 꼭 먼저 여쭤봅니다.
@ 위례동 도어락 출장 설치

# 비용은 시작 전에 말씀드립니다
문 상태와 제품, 작업 범위를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
설치 도중에 말없이 붙는 비용은 없습니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 직접 산 제품도 달아 드립니다
이미 구입한 제품이 있다면 그대로 설치해 드릴 수 있습니다. / 문 두께와 구멍이 맞는지 먼저 확인합니다.
맞지 않으면 어떻게 하면 좋을지 설명드립니다. / 제품 교환이나 다른 방법을 같이 찾아봅니다.
교체 개념으로 보시려면 [도어락 교체](doorlock-replace.html) 페이지도 참고하세요.

# 설치 후 꼭 해두면 좋은 것
- 처음 쓰는 번호는 가족과 같이 정하고 기억하기
- 비상 열쇠나 카드를 집 밖 한 곳에 따로 보관
- 배터리를 새것으로 교체한 날짜를 문 안쪽에 적어 두기
- 안쪽 잠금장치 사용법을 가족 모두가 알기
- 이상한 소리가 나면 바로 점검받기
설치가 끝나면 사용법을 같이 알려드립니다. / 모르는 부분은 그 자리에서 물어보셔도 됩니다.

# 문이 안 열릴 때는 개문부터
설치하려던 문이 이미 잠겨 안 열린다면 먼저 문을 여는 것이 순서입니다. / 이 경우는 [현관문 개문](door-open.html)과 설치를 같이 진행할 수 있습니다.
문 열기와 설치를 따로 부르는 것보다 한 번에 말씀해 주시면 편합니다.

# 위례동 말고 성남 어디든
성남 안이라면 분당, 수정, 중원 어디든 24시간 출동합니다. / 위례동 주변도 위치만 알려주시면 됩니다.
성남 전체 안내는 [성남시 출장열쇠](seongnam.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
