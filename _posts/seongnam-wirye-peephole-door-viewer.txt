# 위례동 현관, 밖이 안 보이면 불안해집니다
위례동은 신도시 생활권이라 비교적 새 집이 많고, 현관에 초인종 카메라를 단 집도 흔합니다. / 모란역이나 지하철을 이용해 출퇴근하는 분들은 귀가가 늦어 현관 앞 상황을 더 신경 쓰게 됩니다.
도어 아이가 뿌옇거나 초인종 화면이 안 나오면 누가 문 앞에 있는지 알 수 없어 불안합니다. / 이 글은 직접 해 볼 수 있는 점검과 부를 때 알려줄 것을 정리했습니다.
[성남 출장열쇠](seongnam.html)에 연락 주시는 분들이 자주 물으시는 부분 위주로 적었습니다.
위례동은 새로 지은 집이 많아 설치된 지 오래되지 않은 제품이 대부분입니다. / 그래서 고장보다는 설정이나 이물질, 습기 같은 사소한 원인인 경우가 많습니다.
현관은 집의 첫인상이자 보안의 첫 단계입니다. / 작은 불편을 방치하지 않고 한 번 점검해 두면 마음이 훨씬 편해집니다.
@ 위례동 현관문 도어 아이와 초인종

# 도어 아이가 뿌옇게 보이는 이유
도어 아이는 문 두께를 지나는 작은 렌즈 구조입니다. / 안쪽이나 바깥쪽 렌즈에 먼지와 기름때가 끼면 상이 흐려집니다.
습기가 렌즈 사이로 들어가면 안개가 낀 듯 보이기도 합니다. / 겨울철 결로 때문에 생기는 경우가 많습니다.
렌즈 한쪽이 돌아가 있으면 시야가 한쪽으로 쏠려 보입니다. / 오래 쓰면 나사가 느슨해져 생기는 일입니다.

# 렌즈부터 닦아 보세요
부드러운 천에 약간의 물을 묻혀 바깥 렌즈를 가볍게 닦아 보세요. / 세제나 알코올은 코팅을 상하게 할 수 있어 피하는 게 좋습니다.
안쪽 렌즈는 보통 문 안쪽에서 돌려서 분리됩니다. / 힘주어 돌리지 말고 천천히 돌려 보세요.
닦아도 계속 뿌옇다면 렌즈 사이에 습기가 들어갔을 가능성이 큽니다. / 이때는 도어 아이를 새로 교체하는 편이 낫습니다.
@ 위례동 도어 아이 렌즈 닦는 모습

# 도어 아이 교체가 가능한지 먼저 보는 것
도어 아이는 문 두께와 구멍 지름이 맞아야 끼워집니다. / 맞지 않으면 구멍을 넓히거나 다른 규격을 써야 합니다.
문 두께를 모르면 문틈 쪽에서 대략 재 보고 사진을 보내 주세요. / 사진이 있으면 맞는 제품을 챙겨 가기 쉽습니다.
교체는 대개 짧게 끝나지만 문 재질에 따라 차이가 있습니다. / 방화문처럼 두꺼운 문은 별도로 확인합니다.

# 초인종 카메라 화면이 안 나올 때
초인종 카메라는 전원 방식이 크게 건전지형과 전원 연결형으로 나뉩니다. / 어느 쪽인지에 따라 점검 순서가 달라집니다.
- 건전지형은 배터리 잔량부터 확인
- 전원 연결형은 차단기나 어댑터 연결 확인
- 앱 연동형은 공유기와 와이파이 연결 확인
- 화면은 나오는데 소리가 안 나면 마이크 쪽 확인
이렇게 순서를 두면 어디서 막히는지 좁힐 수 있습니다.

# 와이파이가 원인인 경우가 의외로 많습니다
초인종 화면이 끊기거나 알림이 안 오는 이유가 와이파이일 때가 많습니다. / 공유기를 옮기거나 비밀번호를 바꾸면 연결이 끊깁니다.
현관 쪽은 철문 때문에 신호가 약한 편입니다. / 공유기 위치를 옮기거나 중계기를 쓰면 나아지기도 합니다.
이런 설정은 제품마다 앱 구성이 달라 전화로 단정하기 어렵습니다. / 제품명이 있으면 알려 주세요.
와이파이 공유기를 껐다 켜는 것만으로 돌아오는 경우도 있습니다. / 그래도 안 되면 앱에서 기기를 삭제하고 다시 등록해야 할 수 있습니다.
이웃 집 초인종은 되는데 우리 집만 안 된다면 제품 자체나 전원 연결을 의심해 볼 만합니다.

# 카메라 각도와 야간 시야 점검
카메라가 위를 보고 있어 사람이 아래만 잘리는 경우가 있습니다. / 각도 조절 나사를 살짝 풀어 맞추면 됩니다.
밤에 화면이 번지는 것은 조명이나 반사 때문일 수 있습니다. / 복도 조명이 렌즈에 직접 비치는지 확인해 보세요.
유리나 반사되는 벽이 근처에 있으면 빛이 번져 얼굴이 하얗게 날아가 보일 수 있습니다. / 이런 경우는 카메라 각도를 조금만 바꿔도 좋아집니다.
해가 질 무렵에 화면이 가장 흐리게 느껴지는 것도 흔한 일입니다. / 하루 중 언제 불편한지 적어 두면 원인을 짚기 쉽습니다.
렌즈 보호 필름이 붙은 채라면 떼어 주세요. / 새 제품에서 가끔 놓치는 부분입니다.

# 하지 말아야 할 것
렌즈를 칼이나 드라이버로 긁어 닦지 마세요. / 한번 긁히면 되돌릴 수 없습니다.
전선이 보인다고 임의로 잘라 연결을 바꾸지 마세요. / 합선이나 고장으로 이어질 수 있습니다.
도어 아이를 힘으로 뽑으려 하면 문 구멍이 상할 수 있습니다. / 돌려서 빠지는 구조인지 먼저 확인하세요.
@ 위례동 초인종 카메라 설치 상태

# 출장을 부를 때 알려주실 것
위례동은 단지와 상가가 구분돼 있어 위치를 정확히 알려주시면 도착이 빠릅니다.
- 몇 동 몇 호인지와 대략의 위치
- 도어 아이인지 초인종 카메라인지
- 흐린지, 안 나오는지, 소리만 문제인지
- 제품 사진 또는 제조사 표시
문이 안 열리는 상황과 겹치면 먼저 말씀해 주세요. / 이때는 [현관문 개문](door-open.html)부터 진행합니다.

# 신분 확인 절차는 그대로입니다
점검이든 문 열기든 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로울 수 있지만 이웃과 집 안을 지키기 위한 절차입니다. / 확인이 어렵다면 작업을 할 수 없으니 미리 준비해 두세요.

# 비용은 작업 전에 먼저 말씀드립니다
점검 범위와 교체 필요 여부를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다.
자세한 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 도어락과 함께 점검하면 좋은 것
도어 아이와 초인종을 볼 때 도어락 배터리와 보조키도 같이 보면 효율적입니다. / 현관 앞에서 한 번에 확인하는 것이 편합니다.
오래된 제품은 [도어락 수리](doorlock-repair.html)로 먼저 손보는 방법도 있습니다. / 너무 낡았으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 위례동 말고 성남 어디든 갑니다
위례동 주변 단대동, 신흥동, 태평동도 다닙니다. / 성남 안이면 24시간 출동하고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 마무리
택배 기사나 방문객이 많은 집이라면 화면이 잘 나오는지 한 달에 한 번쯤 직접 확인해 보세요. / 문제를 일찍 알면 고치는 것도 간단합니다. 가족 모두가 화면 보는 법을 알아 두면 더욱 좋습니다.
도어 아이와 초인종 카메라는 한 번 손봐 두면 오래 편하게 쓰는 부분입니다. / 계절이 바뀔 때 렌즈를 닦고 앱 연결과 배터리를 같이 살펴보는 것을 습관으로 삼아 보세요.
점검이 어렵거나 장비 선택이 고민될 때는 현관 사진을 보내 주시면 방향을 잡아 드립니다. / 모르는 부분은 편하게 물어보셔도 됩니다.
현관 앞이 잘 보이는 것만으로도 집에 들어서는 마음이 놓입니다. / 렌즈 닦기와 전원 확인만으로 해결되는 경우도 많으니 먼저 해 보세요.
