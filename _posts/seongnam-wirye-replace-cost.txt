# 위례동 도어락, 지금 꼭 바꿔야 할까
새 단지에 이사 온 분들이 의외로 많이 묻는 것이 기본 도어락을 그대로 써도 되느냐는 질문입니다. / 대부분은 그대로 써도 문제없습니다. / 다만 가족 구성이 바뀌었거나 쓰고 싶은 기능이 생겼다면 바꾸는 것도 충분히 의미가 있습니다.
위례동은 비교적 새로 입주한 단지가 많아 도어락도 새것이라고 생각하기 쉽습니다. / 하지만 입주 때 달려 있던 기본형 도어락이 불편해 바꾸고 싶다는 분이 꾸준히 있습니다.
교체를 먼저 정하고 전화하기보다 지금 상태가 어떤지 확인하는 것이 순서입니다. / 이 글은 위례동에서 교체 전에 보면 좋은 것들을 모았습니다.
@ 위례동 도어락 교체 전 확인 출장열쇠

# 고쳐서 쓸 수 있는 경우가 많습니다
번호판이 어둡거나 경고음이 나는 증상은 교체가 아니라 배터리 교체로 끝나는 일이 많습니다. / 모터 소리가 약하거나 걸쇠가 뻑뻑한 경우도 부품 점검으로 해결됩니다.
무조건 새 제품을 권하지 않는 이유입니다. / 고쳐서 충분히 쓸 수 있으면 수리를 먼저 말씀드립니다.
자세한 내용은 [도어락 수리](doorlock-repair.html)에 적어 두었습니다.

# 교체를 생각해 볼 만한 때
- 수리해도 같은 고장이 자주 반복될 때
- 번호판 버튼이 눌리지 않거나 오작동이 잦을 때
- 지문이나 카드 등 쓰고 싶은 기능이 생겼을 때
- 잃어버린 열쇠나 카드를 다른 사람이 가졌을까 불안할 때
- 이사해서 이전 사람이 쓰던 번호나 열쇠를 지우고 싶을 때
이런 경우는 새 제품이 마음의 부담을 줄여 줍니다. / 필요를 먼저 정하면 고르기가 쉬워집니다.

# 바꾸기 전에 문부터 확인합니다
도어락은 문 규격에 맞아야 달 수 있습니다. / 같은 모양이라도 문 두께와 구멍 위치에 따라 맞는 제품이 달라집니다.
- 문 두께
- 기존 도어락 구멍 크기와 위치
- 보조키 유무
- 문이 열리는 방향(좌, 우)
이 정보를 사진으로 보내주시면 도착 전에 어떤 제품이 맞을지 가늠할 수 있습니다. / 자세한 사항은 [도어락 설치](doorlock-install.html) 페이지를 참고하세요.

# 제품은 쓰는 사람에 맞게 고릅니다
같은 제품도 집마다 평가가 달라집니다. / 인테리어 취향과 가족의 사용 습관을 먼저 떠올려 보시면 고르기가 쉬워집니다. / 처음 상담이라면 쓰고 싶은 기능 두세 가지만 정리해 오셔도 충분합니다.
어떤 제품이 좋다기보다 어떤 사람에게 맞느냐가 중요합니다.
- 아이가 있는 집: 아이 손이 닿기 어려운 잠금, 열림 알림
- 어르신이 있는 집: 큰 버튼, 단순한 조작
- 자주 비우는 집: 배터리 알림, 카드나 지문 병행
- 자주 손님이 오는 집: 임시 번호 기능
위례동 신축 단지는 현관 인테리어와 어울리는 외관도 많이 고민하십니다. / 외관과 기능 사이 균형을 같이 짚어 드립니다.
@ 위례동 도어락 교체 제품 선택

# 비용은 무엇으로 정해지나
비용은 제품 종류와 설치 상태에 따라 달라집니다. / 숫자를 미리 정해 두기보다 문을 보고 말씀드립니다.
- 선택하신 제품의 종류와 기능
- 기존 도어락 철거 여부
- 문 가공이 필요한지
- 방문 시간대와 위치
이 항목을 하나씩 짚어서 말씀드리고, 동의하신 뒤에 시작합니다.

# 나중에 추가 비용이 붙지 않게
설치가 끝난 뒤에 처음 얘기 안 한 항목이 붙으면 곤란합니다. / 작업 전에 설명하고 동의받은 범위만 진행합니다.
작업 중에 추가로 바꿔야 할 부품이 보이면 손대기 전에 먼저 여쭙습니다. / 마음에 안 드시면 그 자리에서 멈춥니다.
진행 순서는 [이용안내](guide.html)에 정리되어 있습니다.

# 전화로 물어보시면 좋은 것
- 지금 쓰는 도어락 브랜드나 모양
- 원하는 기능(지문, 카드, 번호 등)
- 문 사진(바깥, 안쪽, 측면)
- 위례동에서 대략 어느 쪽인지
사진 몇 장이면 설명이 훨씬 구체적이 됩니다. / 문을 못 열 때가 아닌 교체 상담이라면 여유 있게 문의하셔도 됩니다.

# 사시는 분인지 확인
교체 작업도 사시는 분이 맞는지 확인하고 진행합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로울 수 있지만 이웃과 집 주인을 지키는 절차입니다.

# 설치할 때 이렇게 진행합니다
기존 도어락을 상하지 않게 분리하고 새 제품을 맞춰 설치합니다. / 문과 문틀에 불필요한 흠이 나지 않게 주의합니다.
설치 후에는 잠금, 열림, 소리, 등록한 번호를 함께 시험합니다. / 불편한 부분이 있으면 그 자리에서 조정합니다.
@ 성남 출장열쇠 위례동 도어락 교체 설치

# 설치가 끝난 뒤 확인하는 것
설치가 끝난 뒤 하루 이틀은 평소보다 더 자주 열고 닫아 보며 적응해 보세요. / 이상한 점이 있으면 바로 연락 주시면 확인하고 조정해 드립니다.
- 번호와 카드가 정확히 등록됐는지
- 문을 닫았을 때 자동 잠금이 되는지
- 배터리 교체 방법과 비상 전원 위치
- 가족 모두 번호를 아는지
사용법을 같이 한 번 해 봐야 나중에 헷갈리지 않습니다. / 분실 대비 보조 방법도 하나 정해 두세요.

# 도어락 교체 후 관리
처음에는 신기해서 잘 챙기지만 몇 달 지나면 소홀해지기 쉽습니다. / 배터리는 해가 바뀔 때쯤 한 번에 전부 교체하는 것이 좋습니다.
경고음이 나면 미루지 말고 그날 바로 확인하세요. / 이상이 있으면 [도어락 교체](doorlock-replace.html) 안내도 다시 한 번 참고해 보시면 됩니다.
