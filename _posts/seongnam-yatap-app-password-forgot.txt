# 번호도 모르는데 앱 비밀번호까지 생각이 안 날 때
야탑역에서 내려 집으로 걸어오는 길에 번호판 앞에서 멈추는 순간이 있습니다. / 번호가 헷갈려 휴대폰 앱으로 열어 보려 했는데 앱 로그인 비밀번호마저 떠오르지 않는 경우입니다.
도어락에 앱을 붙여 쓰는 집이 늘면서 이런 상황이 늘었습니다. / 번호판과 앱, 두 군데 비밀번호가 모두 막히면 어디서부터 풀어야 할지 막막해집니다.
이 글은 야탑동에서 도어락 앱 비밀번호까지 잊었을 때 침착하게 확인할 순서를 적었습니다. / 지금 문 앞이시면 2번과 4번부터 보셔도 됩니다.
@ 야탑동 도어락 앱 로그인 화면과 번호판

# 번호판 비밀번호와 앱 비밀번호는 서로 다릅니다
도어락 번호판에 누르는 숫자와 앱에 로그인하는 비밀번호는 별개입니다. / 앱 비밀번호를 찾는다고 현관 번호가 알려지지는 않습니다.
앱은 보통 도어락을 등록해 둔 계정에 묶여 있습니다. / 계정 비밀번호를 되찾으면 앱에서 문을 열 수 있는 제품도 있고, 그렇지 않은 제품도 있습니다.
그래서 두 가지를 따로 놓고 어느 쪽이 가장 빨리 풀리는지 보는 게 좋습니다.
예를 들어 번호는 몇 개 후보가 있는데 앱 계정은 전혀 기억이 안 난다면 번호판 쪽을 정해진 횟수만 시도하는 게 낫습니다. / 반대로 번호는 완전히 지워졌는데 앱 인증 문자가 바로 온다면 앱부터 푸는 게 빠릅니다.
어느 쪽이든 오래 붙잡고 있지 않고 시간을 정해 두고 해 보시길 권합니다.

# 문 앞에서 먼저 확인할 세 가지
당황하면 같은 번호를 계속 누르게 됩니다. / 그 전에 아래를 살펴보세요.
- 번호판에 불이 들어오는지, 안 켜지면 배터리 문제인지
- 같은 번호를 여러 번 눌러 입력 잠금이 걸린 건 아닌지
- 휴대폰과 연결된 도어락 열림 기능이 이 제품에 있는지
번호를 서너 번 틀리면 도어락이 잠시 입력을 막아 버립니다. / 그때는 몇 분 쉬었다 다시 눌러 보는 것이 맞습니다.

# 앱 계정 비밀번호 찾기, 어떻게 해볼까
앱 로그인 화면의 비밀번호 찾기 기능으로 먼저 시도해 볼 수 있습니다. / 가입할 때 쓴 이메일이나 휴대폰 번호로 인증을 받으면 재설정되는 경우가 많습니다.
다만 인증 문자나 메일을 받는 번호가 바뀌었거나 이메일 접근이 안 되면 시간이 걸립니다. / 출근길이나 한밤에는 이 방법을 붙잡고 있지 않는 게 좋습니다.
비밀번호 관리 앱이나 가족 공용 메모에 저장해 두었을 수도 있으니 한 번 찾아보세요.
@ 야탑동 가족 공용 비밀번호 메모 확인

# 가족이나 함께 사는 분에게 먼저 물어보세요
앱이나 번호는 가족 중 한 사람이 바꿔 두었을 가능성이 큽니다. / 연락이 닿으면 바뀐 번호를 물어보는 것이 가장 빠릅니다.
같은 집에 사는 분이 이미 안에 있다면 문을 안에서 열어 주시면 됩니다. / 이웃이나 관리사무소에 도움을 청하는 방법도 있습니다.
혼자 사는 경우에도 부모님이나 집주인이 번호를 알고 있을 수 있습니다. / 임대 집이라면 집주인께 먼저 여쭤보셔도 좋습니다.

# 이렇게 하면 일이 커집니다
비밀번호를 떠올리려고 무작정 반복 입력하다 보면 입력 잠금이 길어집니다. / 도어락이 오작동 모드로 들어가면 오히려 더 오래 못 열 수도 있습니다.
도어락 덮개를 억지로 열거나 드라이버로 번호판을 분해하려 하지 마세요. / 한번 분해하면 방수와 센서가 흐트러져 고장이 납니다.
앱 비밀번호를 재설정하는 과정에서 인증이 계속 실패하면 계정이 잠길 수도 있습니다. / 안 풀리면 멈추고 전화 주세요.

# 도어락 제품마다 열어 보는 다른 길
번호판 말고 다른 통로가 있는 제품도 많습니다. / 열쇠 구멍이 숨어 있는 제품, 카드키를 쓰는 제품, 지문으로 여는 제품이 있습니다.
- 번호판 아래 덮개 안에 열쇠 구멍이 있는지 살펴보기
- 등록해 둔 카드키나 태그가 가방이나 지갑에 있는지 찾기
- 지문이 등록돼 있다면 손을 닦고 다시 대 보기
이런 방법으로 열리면 비밀번호와 앱은 문이 열린 뒤에 천천히 정리하셔도 됩니다.

# 연락하실 때 알려주실 것
위 방법이 모두 안 되면 도어락 모양과 앱 이름을 함께 알려주세요. / 사진을 문자로 보내주시면 챙겨갈 장비를 맞추기 쉽습니다.
- 야탑역 쪽인지, 안쪽 주택가인지 대략의 위치
- 동, 호수 또는 건물 입구 모양
- 도어락 앞면 사진과 앱 아이콘 이름
- 번호판이 켜지는지, 소리가 나는지
- 집 안에 아이나 반려동물이 있는지
앱 계정까지 막혔다는 말씀을 해 주시면 어느 쪽으로 풀지 미리 가늠해 두고 출발합니다.

# 먼저 사시는 분인지 확인합니다
문 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.

# 비용은 열기 전에, 못 열면 받지 않습니다
도어락 종류와 문 상태를 보고 먼저 말씀드린 다음 괜찮다고 하시면 시작합니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 열고 난 뒤 말없이 붙는 비용은 없습니다.
@ 야탑동 출장열쇠 도어락 비밀번호 분실 개문

# 열린 뒤에 번호와 앱을 정리하는 순서
문이 열리면 먼저 도어락 번호를 안쪽에서 새로 등록하고 기존 번호는 지웁니다. / 앱을 쓰시는 경우에는 계정 비밀번호를 같이 재설정하는 것이 좋습니다.
새 비밀번호는 가족 공용 메모에 적어 두거나 비밀번호 관리 앱에 저장해 두세요. / 앱 계정 이메일이 지금 쓰는 주소인지도 한 번 확인하세요.
비밀번호를 쉽게 바꿀 수 없는 오래된 제품이라면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)가 필요한지 같이 봅니다.

# 다시는 이런 일이 없도록 하는 정리 습관
번호와 앱 계정은 따로 기록하되 한곳에 모아 두면 편합니다. / 단, 현관 근처 눈에 띄는 곳에 적어 붙여 두는 것은 피해야 합니다.
- 번호판 비밀번호와 앱 계정 비밀번호를 서로 다르게 정하기
- 가족 한 명 이상이 두 가지를 모두 알고 있도록 공유하기
- 예비 카드키나 열쇠를 집 밖 믿을 수 있는 곳에 따로 보관하기
- 비밀번호를 바꾼 날에는 가족 모두에게 바로 알려주기
자세한 정리 방법은 [이용안내](guide.html)와 [현관문 개문](door-open.html) 페이지에서도 볼 수 있습니다.

# 야탑동 말고 성남 어디든 갑니다
야탑동 옆 이매동, 서현동, 도촌동, 금광동, 상대원동도 다닙니다. / 성남 안이면 24시간 출동합니다.
다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 자주 묻는 질문
? 앱 비밀번호를 몰라도 문을 열 수 있나요? | 네, 앱과 관계없이 문 상태를 보고 여는 방법을 정합니다. 위치와 상황만 알려주세요.
? 앱 계정까지 복구해 주시나요? | 계정 복구는 서비스 회사 절차라 도와드릴 수 없고, 문을 연 뒤 번호 재설정과 정리를 도와드립니다.
? 문을 못 열면 비용은 어떻게 되나요? | 못 열면 비용은 받지 않습니다. 비용은 열기 전에 먼저 말씀드립니다.
? 한밤이나 새벽에도 오시나요? | 24시간 전화를 받습니다. 시간 상관없이 연락 주세요.
? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.
