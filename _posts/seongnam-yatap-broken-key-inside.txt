# 야탑동에서 열쇠가 부러졌다면 먼저 멈추세요
야탑역 일대 상가와 주택, 오피스텔 출입문은 열쇠로 여는 곳이 아직 많습니다. / 그러다 보니 열쇠가 문 앞에서 똑 하고 부러지는 일도 종종 생깁니다.
열쇠가 부러지면 머리 쪽은 손에 있고, 몸통 조각은 열쇠구멍 안에 박힌 채로 남습니다. / 이때 가장 중요한 것은 안에 남은 조각을 더 깊이 밀어 넣지 않는 것입니다.
이 글은 야탑동에서 열쇠가 부러졌을 때 직접 해볼 수 있는 일과 하면 안 되는 일, 출장열쇠를 부르면 어떻게 진행되는지 정리했습니다. / 지금 문 앞이라면 2번과 3번부터 보셔도 됩니다.
@ 야탑동 출장열쇠 부러진 열쇠 제거

# 부러진 열쇠가 문제를 키우는 이유
열쇠 조각이 구멍 안에 있으면 열쇠가 더 이상 안 들어가는 것은 물론, 조각이 안쪽 핀에 걸려 구멍이 막힙니다. / 이 상태에서 문을 열 방법이 없으니 문 안으로 못 들어가는 일이 됩니다.
조각이 구멍 입구 가까이 있다면 빼내기 쉽지만, 안쪽 깊이 들어가면 작업이 한 단계 어려워집니다. / 그래서 처음 부러진 순간에 얼마나 조심하느냐가 중요합니다.
부러진 조각을 바로 빼려고 이쑤시개나 핀셋을 쓰는 분들이 있습니다. / 입구에 조각이 보이더라도 억지로 하면 조각이 더 안으로 밀려 들어갑니다.

# 지금 바로 하지 말아야 할 행동
급한 마음에 하기 쉬운 행동입니다. / 아래만 피하셔도 해결이 훨씬 쉬워집니다.
- 열쇠 머리로 구멍을 계속 돌려 보는 것
- 바늘이나 이쑤시개, 핀으로 조각을 건드리는 것
- 접착제로 조각을 붙여 빼내려는 것
- 열쇠구멍에 윤활제를 잔뜩 뿌리는 것
특히 접착제는 구멍 전체를 굳게 만들어 자물쇠를 통째로 바꿔야 할 수도 있게 합니다. / 윤활제를 많이 넣는 것도 조각이 안쪽으로 미끄러질 수 있어 피하시는 편이 좋습니다.
@ 야탑역 근처 열쇠 부러짐 출장 개문

# 부러진 열쇠 머리는 버리지 마세요
손에 남은 열쇠 머리와 부러진 조각은 작업에 도움이 됩니다. / 부러진 위치를 보면 안쪽 조각이 얼마나 남아 있는지 짐작할 수 있기 때문입니다.
머리 쪽은 새 열쇠를 맞출 때 기준으로도 쓸 수 있습니다. / 비닐에 담아 보관해 두었다가 보여주세요.
조각이 깨끗하게 하나로 부러졌는지, 여러 조각으로 갈라졌는지도 알려주시면 좋습니다. / 진행 방법이 달라질 수 있습니다.

# 열쇠는 왜 부러질까
열쇠가 부러지는 데는 대개 이유가 있습니다. / 갑자기 일어난 일 같아도 이전에 신호가 있었던 경우가 많습니다.
- 오래 쓰면서 열쇠 목 부분에 금이 간 경우
- 뻑뻑한 열쇠구멍을 힘으로 계속 돌려 쓴 경우
- 문이 처져서 열쇠에 계속 힘이 걸리던 경우
- 복사본의 복사본처럼 재질이 약해진 경우
평소에 열쇠가 뻑뻑하게 돌아간다고 느꼈다면 새 열쇠를 만들기 전에 문과 구멍부터 점검해 보시는 것이 좋습니다. / 열쇠만 바꾸면 같은 일이 되풀이됩니다.

# 전화하실 때 알려주세요
부러진 상태를 설명해 주시면 챙겨 갈 장비가 달라집니다. / 모르는 부분은 건너뛰어도 괜찮습니다.
- 조각이 구멍 입구에서 보이는지, 안 보이는지
- 열쇠가 어디쯤에서 부러졌는지(머리 쪽 길이)
- 도어락과 열쇠를 같이 쓰는 문인지
- 건물 종류와 층, 야탑동 위치
- 안에 사람이나 반려동물이 있는지
사진 한 장만 있어도 큰 도움이 됩니다. / 열쇠구멍을 가까이서 찍어 문자로 보내주세요.

# 도착하면 이렇게 진행합니다
먼저 구멍 안을 확인해 조각이 어디에 있고 어떤 상태인지 봅니다. / 입구 가까이 있으면 전용 도구로 조심스럽게 빼냅니다.
깊이 들어가 있거나 구멍이 막힌 경우에는 자물쇠 일부를 분해해서 해결해야 할 수도 있습니다. / 어떤 방법을 쓰는지, 그에 드는 비용은 얼마인지 시작 전에 말씀드립니다.
조각을 빼낸 뒤에는 열쇠를 새로 맞추는 작업까지 이어서 합니다. / 열쇠 상태가 약하다면 복사본이 아니라 원본 기준으로 맞춰 드립니다.
[출장 열쇠](key-call.html) 작업이 어떻게 이뤄지는지 페이지에 적어 두었습니다. / 문을 못 여는 상황이면 [현관문 개문](door-open.html)과 함께 진행됩니다.

# 비용은 열기 전에 말씀드립니다
조각 위치와 자물쇠 종류를 본 뒤에 작업 방법과 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니라면 그대로 돌아갑니다.
문을 끝내 못 여는 경우에는 비용을 받지 않습니다. / 작업이 끝난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 할 때는 바꾸기 전에 반드시 먼저 여쭤봅니다. / 자물쇠 전체 교체는 꼭 필요할 때만 권합니다.

# 신분 확인은 꼭 합니다
문을 열거나 자물쇠를 만지는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소나 우편물, 관리사무소 확인 중 하나면 됩니다.
상가나 사무실이라면 사업자 관련 서류나 임대 관련 서류로 확인하는 방법도 안내해 드립니다. / 확인이 어려운 경우에는 미리 말씀해 주세요.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다. / 처음 부르시는 분들이 먼저 읽어 보시면 도움이 됩니다.
@ 야탑동 열쇠 교체 후 점검

# 다시 부러지지 않게 하는 방법
작업이 끝난 뒤에는 같은 일이 되풀이되지 않게 몇 가지를 같이 알려 드립니다. / 대부분 아주 간단한 것들입니다.
- 새 열쇠는 원본 기준으로 맞춘 것을 쓰고, 복사본은 한 번만 만들기
- 열쇠가 뻑뻑하면 바로 점검받기
- 열쇠를 꽂은 채 문을 강하게 흔들지 않기
- 문이 처졌다면 열쇠보다 먼저 문 상태를 점검하기
열쇠가 뻑뻑한 이유가 문 처짐이라면 열쇠를 아무리 새로 만들어도 같은 증상이 계속됩니다. / 그래서 부러진 김에 문 상태도 같이 확인해 보시는 분들이 많습니다.

# 야탑동 말고 성남 어디든 갑니다
야탑동 바로 옆 이매동, 서현동, 구미동, 금광동과 판교, 위례, 수정구, 중원구까지 성남 전 지역에 출동합니다. / 위치를 알려주시면 도착 시간을 먼저 말씀드립니다.
성남 안내는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

열쇠구멍 사진과 위치를 문자로 보내주시면 도착 전에 필요한 장비를 챙길 수 있습니다. / 24시간 받고, 서울·경기 전 지역에 출동합니다.
