# 우편함 열쇠는 작아서 더 잘 잃어버립니다
야탑동에서 우편함이나 사물함 열쇠를 잃어버렸다고 연락 주시는 분이 가끔 계십니다. / 현관 열쇠와 달리 가끔만 쓰다 보니 어디 두었는지 기억이 안 나는 일이 많습니다.
우편함이 안 열리면 고지서나 택배 안내문을 못 받아 은근히 불편합니다. / 이 글은 우편함과 사물함 자물쇠가 안 열릴 때 확인할 것을 정리했습니다.
혼자 해볼 수 있는 것과 [성남 출장열쇠](seongnam.html)를 부르는 편이 나은 경우를 나눠 적었습니다. / 억지로 열기 전에 먼저 읽어 보세요.

# 우편함 잠금은 어떻게 생겼나
아파트 우편함은 작은 원통형 열쇠 구멍이 달린 것이 흔합니다. / 번호를 맞추는 다이얼식이나 카드로 여는 방식도 있습니다.
사물함과 보관함은 자물쇠를 따로 걸어 쓰는 형태와 문에 잠금이 붙은 형태로 나뉩니다. / 어느 쪽인지에 따라 열 때 쓰는 방법이 달라집니다.
열쇠 구멍은 작아서 먼지와 습기가 들어가기 쉽고 한번 뻑뻑해지면 잘 안 돌아갑니다. / 가끔 쓰는 곳일수록 이런 일이 더 자주 생깁니다.

# 열쇠가 있는데 안 돌아갈 때
열쇠를 끝까지 꽂았는지, 맞는 열쇠가 맞는지 먼저 확인합니다. / 비슷하게 생긴 열쇠가 여럿이면 한 번쯤 다른 것을 꽂아 보게 됩니다.
열쇠를 꽂은 채로 문을 살짝 눌러 주면서 돌리면 열리는 경우가 있습니다. / 우편함 문이 조금 휘어 잠금과 맞지 않아서 그런 경우가 많습니다.
열쇠가 휘었거나 닳아 있으면 억지로 돌리지 마세요. / 부러지면 조각이 구멍에 남아 열기가 더 어려워집니다.

# 열쇠를 잃어버렸을 때
우선 마지막으로 쓴 곳과 평소 두는 곳을 차분히 떠올려 보세요. / 현관 열쇠와 같이 매달려 있는 경우도 있으니 열쇠 꾸러미를 한 번 더 살펴보세요.
관리사무소에 우편함 비상 열쇠가 있는 단지도 있습니다. / 먼저 관리사무소에 문의해 보시면 간단하게 해결되는 경우가 있습니다.
그래도 없다면 열쇠집에서 자물쇠를 상하지 않게 열거나 새 열쇠를 만들어 드릴 수 있습니다. / 어떤 방법이 맞는지는 우편함 종류를 보고 정합니다.

# 우편함을 부수지 않는 것이 중요한 이유
우편함은 단지나 건물 공용 시설인 경우가 많습니다. / 함부로 부수면 다른 사람에게 폐해가 가거나 원상 복구를 요구받을 수 있습니다.
우편함 문은 얇은 철판이라 한번 휘면 다시 맞추기 어렵습니다. / 가능하면 자물쇠만 열고 우편함은 그대로 두는 방법을 씁니다.
새 열쇠나 새 자물쇠로 바꾸는 방법도 있어서 우편함을 상하게 하는 일은 거의 필요하지 않습니다. / 먼저 상태를 보고 말씀드리겠습니다.

# 사물함이나 보관함이 안 열릴 때
사물함은 번호 자물쇠가 달린 경우가 있어 번호를 잊은 경우가 많습니다. / 번호를 떠올리려고 비슷한 숫자를 몇 번씩 눌러 보는 것은 시간이 오래 걸립니다.
소유자가 맞는지 확인이 되어야 열어드릴 수 있습니다. / 사물함이 내 것이라는 것을 확인할 수 있는 자료가 있으면 챙겨 두세요.
공용 사물함이라면 관리하는 곳에 먼저 알리는 것이 좋습니다. / 관리하는 곳 허락 없이 열면 문제가 생길 수 있습니다.

# 전화하실 때 알려주면 좋은 것
우편함인지 사물함인지, 열쇠식인지 번호식인지 알려주세요. / 사진을 문자로 보내주시면 챙겨 갈 도구를 고르기 쉽습니다.
열쇠를 잃어버렸는지, 열쇠는 있는데 안 돌아가는지도 알려주세요. / 상황에 따라 필요한 준비가 달라집니다.
야탑동 안에서 건물 위치와 대략 야탑역에서 어느 쪽인지 알려주시면 도착이 빨라집니다. / 건물 이름 대신 길이나 상가 이름을 알려주셔도 됩니다.

# 도착하면 본인 것인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증이나 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
우편함은 남의 우편물이 들어 있을 수 있어서 이 절차를 더 조심합니다. / 번거로우셔도 서로를 지키는 확인이라 생각해 주세요.
확인이 끝나면 상태를 보고 얼마가 드는지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 못 열면 비용은 받지 않습니다.

# 최대한 안 상하게 엽니다
자물쇠 종류를 먼저 보고 가장 덜 상하는 방법부터 차례로 시도합니다. / 열린 뒤에는 새 열쇠를 만들거나 자물쇠를 바꿀지 사시는 분이 정하시게 합니다.
방식은 [현관문 개문](door-open.html) 페이지에 적은 것과 같은 원칙입니다. / 문이든 우편함이든 상하지 않게 여는 것이 먼저입니다.
열쇠 복사나 새 자물쇠가 필요하면 [출장 열쇠](key-call.html)에서 같이 처리합니다. / 바꾸기 전에는 꼭 먼저 여쭙니다.

# 열고 난 뒤 같이 점검합니다
자물쇠가 열렸으면 열쇠가 부드럽게 돌아가는지 몇 번 시험합니다. / 구멍이 뻑뻑하면 안쪽 먼지나 부품 문제인지 설명드립니다.
고쳐서 쓸 수 있으면 부품만 손보는 쪽을 권하고, 너무 낡았다면 그때 새것을 말씀드립니다. / 현관문 잠금도 같은 방식으로 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)로 안내합니다.
열쇠를 새로 만들었다면 현관 열쇠와 분리해서 보관하는 방법을 알려드립니다. / 한 꾸러미에 모으되 이름표를 붙이면 잃어버려도 찾기 쉽습니다.

# 열쇠를 덜 잃어버리는 방법
열쇠는 항상 같은 자리에 두는 습관이 가장 효과가 좋습니다. / 현관 근처에 열쇠 거치대를 하나 두면 편합니다.
복사 열쇠를 한 개 더 만들어 믿을 수 있는 가족에게 맡겨 두면 마음이 놓입니다. / 우편함 열쇠도 같은 방식으로 관리해 보세요.
열쇠에 눈에 띄는 고리를 달아 두면 가방 속에서 찾기 쉽습니다. / 작은 것이지만 큰 도움이 됩니다.

성남에서 다니는 동네는 [성남시 출장열쇠](seongnam.html) 페이지에 정리해 두었습니다. / 서울과 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
