# 야탑동 현관문이 꽉 안 닫히는 겨울 앞의 고민
야탑역 근처 골목과 주택가에서 가을이 깊어지면 현관 틈새 바람부터 막는 분이 늘어납니다. / 문풍지를 붙이고 고무 패킹을 새로 둘렀는데 문이 끝까지 닫히지 않는다는 연락이 이 시기에 생깁니다.
바람을 막으려다 문이 안 닫히면 도어락이 걸쇠를 못 내려 오히려 보안이 헐거워집니다. / 이 글은 야탑동에서 이런 일이 생겼을 때 직접 확인할 순서를 적었습니다.
@ 야탑동 현관문 문풍지 고무 패킹 두께 확인

# 두꺼운 패킹이 문을 밀어내는 원리
문 가장자리에 붙인 패킹은 문이 닫힐 때 눌려야 합니다. / 너무 두꺼우면 눌리는 힘이 문을 바깥쪽으로 되밀어서 걸쇠가 문틀 구멍에 닿기 전에 멈춥니다.
문이 닫힌 것처럼 보여도 걸쇠 머리가 반쯤만 들어가 있는 경우도 있습니다. / 이때는 도어락이 잠금 신호를 받지 못해 모터가 헛돌거나 경고음이 날 수 있습니다.

# 닫히지 않는 증상을 이렇게 구분하세요
먼저 손으로 문을 살짝 눌러 보세요. / 누르는 동안만 걸쇠가 들어가고 손을 떼면 튀어나온다면 패킹 반발이 원인일 가능성이 큽니다.
- 문을 세게 닫으면 닫히는데 살살 닫으면 안 되는 경우
- 위쪽은 닫히는데 아래쪽만 벌어지는 경우
- 패킹을 뗀 자리로 문을 닫으면 정상인 경우
세 번째처럼 패킹을 임시로 떼어 보고 닫힌다면 원인은 확실합니다. / 이때는 도어락을 의심하지 않으셔도 됩니다.

# 문풍지는 얇고 납작한 것으로 바꿔 보세요
문풍지는 종류가 많은데 폭과 두께가 문틈보다 큰 것을 고르면 문이 닫히지 않습니다. / 틈새가 손가락 한 마디가 아니라 종이 한두 장 들어가는 정도라면 얇은 제품으로 충분합니다.
문을 닫고 종이를 틈에 끼워 보아 살짝 걸리는 정도면 적당합니다. / 종이가 아예 빠지지 않으면 이미 너무 빡빡한 상태입니다.

# 붙이는 위치만 바꿔도 달라집니다
문짝 쪽에 붙이던 패킹을 문틀 안쪽 면으로 옮기면 눌림이 줄어듭니다. / 경첩 쪽 가장자리는 문이 회전하는 축이라 두꺼운 패킹이 가장 잘 문제를 만듭니다.
걸쇠가 들어가는 쪽과 경첩 쪽을 분리해서 생각해 보세요. / 경첩 쪽은 얇게, 손잡이 쪽만 조금 두껍게 하는 방식도 있습니다.

# 사례로 보는 야탑동의 흔한 상황
퇴근 후 현관 틈새 바람을 막겠다고 주말에 패킹을 두 겹으로 둘렀다가, 월요일 아침 문이 닫히지 않아 출근이 늦어진 경우가 있습니다. / 한 겹으로 줄이니 바로 닫혔던 사례처럼, 겹쳐 붙인 것이 원인인 일이 많습니다.
이사 온 집에 이미 붙어 있던 낡은 패킹 위에 새 패킹을 덧붙여 두꺼워진 경우도 있습니다. / 새로 붙이기 전에 기존 것을 먼저 떼어 내는 것이 좋습니다.
오래된 패킹은 굳어서 눌리지 않고 문을 밀어내기도 합니다. / 이럴 때는 두께 문제가 아니라 낡음 문제라 교체가 맞습니다.

# 바닥 하단 고무와 문턱 높이도 봅니다
아래쪽 틈을 막는 하단 고무가 문턱에 끌리면 문이 닫히다 멈춥니다. / 신발을 놓는 현관 바닥 쪽이 높아졌거나 매트가 두꺼워도 같은 증상이 생깁니다.
매트를 치우고 닫아 보면 바로 알 수 있습니다. / 매트가 원인이면 문 반경 안에는 두지 않는 편이 낫습니다.

# 붙이기 전에 두께부터 재 보세요
문을 닫은 상태에서 문과 문틀 사이 틈을 자나 종이로 가늠해 보세요. / 틈보다 2배쯤 두꺼운 패킹이 눌려서 들어갈 수 있는 한계라고 보시면 됩니다.
상품 설명에 적힌 두께는 눌리기 전 기준이니 여유 있게 얇은 것을 고르세요. / 붙이는 면이 깨끗하게 닦여 있어야 나중에 떨어지거나 울지 않습니다.

# 하지 말아야 할 것
닫히지 않는다고 문을 어깨로 밀어 닫는 습관은 좋지 않습니다. / 걸쇠와 문틀 구멍이 어긋난 채 눌려서 도어락 내부 부품에 힘이 쏠립니다.
두꺼운 패킹 위에 테이프를 더 붙이는 것도 반대 방향입니다. / 도어락 자체는 멀쩡한데 패킹 때문에 고장 난 것처럼 보이는 경우가 많습니다.
@ 야탑동 도어락 걸쇠가 문틀 구멍에 들어가는 위치

# 도어락 걸쇠와 문틀 구멍 위치 확인
패킹을 떼도 안 닫히면 걸쇠와 문틀 구멍(스트라이크) 위치를 봅니다. / 문을 열어 걸쇠를 누르며 구멍 한가운데로 들어가는지 확인하세요.
걸쇠 머리에 쓸린 자국이 한쪽으로 치우쳐 있다면 문이 처졌다는 신호입니다. / 이런 경우는 [문 안 열림 상담](door-open.html) 전에 사진을 찍어 두면 설명이 쉽습니다.

번호판은 켜지는데 잠금 소리가 나지 않고, 밖에서 열어도 걸쇠가 반쯤 걸려 있는 상태가 있습니다. / 이럴 때는 문을 당겨 걸쇠 쪽을 풀어 준 뒤 다시 천천히 닫아 보세요.
그래도 걸쇠가 빠지지 않으면 억지로 당기지 마시고 연락 주세요. / 문틀이 상하지 않게 푸는 것이 우선입니다.

# 전화 주실 때 알려주면 좋은 정보
야탑동 어디쯤인지와 함께 아래 내용을 알려주시면 출동 준비가 빠릅니다.
- 문풍지와 패킹을 언제 붙였는지
- 패킹을 뗐을 때 문이 닫히는지
- 번호판과 경고음 상태
- 위쪽과 아래쪽 중 어디가 벌어지는지
도어락 사진과 문 옆면 사진이 있으면 장비를 맞춰 챙기기 좋습니다.

문을 열어야 하는 상황이면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업이 어려운 점은 미리 알려 드립니다. / 신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 먼저 부탁해 두셔도 됩니다. / 이웃과 집을 지키기 위한 절차이니 양해 부탁드립니다.

# 비용과 진행 순서
현장에서 문과 도어락 상태를 보고 문 열기 전에 먼저 비용을 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 문을 못 열면 비용은 받지 않습니다.
패킹 때문이면 도어락을 손대지 않고 위치만 조정하는 선에서 끝나는 일도 많습니다. / 수리나 교체가 필요해 보이면 [도어락 수리](doorlock-repair.html)와 [도어락 교체](doorlock-replace.html) 중 맞는 쪽을 먼저 설명드립니다.
@ 야탑동 출장열쇠 방문 점검 모습

# 겨울 앞두고 미리 해 둘 점검
외풍을 막는 일과 문이 잘 닫히는 일은 함께 가야 합니다. / 틈이 막혀도 문이 반쯤 걸려 있다면 의미가 없습니다.
겨울에는 문이 차가워져 패킹이 딱딱해지고 반발이 더 세집니다. / 따뜻한 날 맞춰 둔 두께가 추울 때는 맞지 않을 수 있으니 여유를 남겨 두세요.
추워지기 전에 문이 한 번에 부드럽게 닫히는지 확인하세요. / 한겨울에는 문이 수축해서 증상이 더 심해지기도 합니다.
- 패킹을 붙인 뒤 문을 열고 닫기를 열 번쯤 해 보기
- 걸쇠가 소리 없이 들어가는지 귀로 확인
- 도어락 배터리도 같이 교체
[성남 출장열쇠](seongnam.html) 지역 안내와 [이용안내](guide.html)에서 방문 절차를 볼 수 있습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
