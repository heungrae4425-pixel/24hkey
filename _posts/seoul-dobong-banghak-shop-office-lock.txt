# 방학동 가게 앞, 셔터는 올렸는데 유리문이 안 열린다면
방학동은 아파트 단지 사이로 큰길가 상가와 골목 안 작은 가게, 2층 사무실이 촘촘히 이어진 동네입니다. / 방학역을 오가는 길목에도 아침 일찍 문을 여는 가게가 많습니다.
가게 문은 집 현관과 사정이 다릅니다. / 손님이 오기 전에 열어야 하고, 셔터와 유리문, 안쪽 사무실 문처럼 잠금이 여러 겹인 경우가 많습니다.
이 글은 방학동 상가나 사무실 출입문이 안 열릴 때 문 종류별로 먼저 볼 것과, [도봉구 출장열쇠](seoul-dobong.html)를 부를 때 준비할 것을 정리했습니다.
@ 방학동 상가 유리문 셔터 출입문 잠김

# 어느 문에서 막혔는지 먼저 나눠 주세요
가게는 한 곳에 잠금장치가 두세 개씩 붙어 있습니다. / 어느 문에서 막혔는지에 따라 챙겨 갈 공구와 걸리는 시간이 완전히 다릅니다.
- 바깥 셔터 (열쇠로 여는 것, 리모컨으로 올리는 것)
- 유리문 아래쪽 바닥 열쇠나 가운데 손잡이 열쇠
- 도어락이 달린 사무실 철문이나 나무문
- 건물 공용 출입문과 계단 쪽 방화문
전화로 이 중 어느 것인지만 말씀해 주셔도 준비가 한결 쉬워집니다.

# 유리문 바닥 열쇠가 안 돌아갈 때
유리문 아래쪽에 바닥으로 박히는 잠금이 있는 가게가 많습니다. / 먼지와 모래가 구멍에 쌓이면 열쇠가 끝까지 안 들어가거나 돌다 멈춥니다.
겨울 아침에는 금속이 줄어들어 평소보다 더 빡빡하게 느껴지기도 합니다. / 열쇠를 꽂은 채로 문을 살짝 들거나 바깥으로 밀면서 돌려 보세요. / 문 무게가 걸쇠를 누르고 있으면 그것만으로 풀리기도 합니다.
힘으로 비틀다 열쇠가 부러지면 일이 커집니다. / 두세 번 해 보고 안 되면 멈추고 연락 주세요.

# 셔터가 중간에 걸렸을 때
셔터 열쇠는 돌아가는데 셔터가 반쯤 올라가다 멈추는 경우가 있습니다. / 이건 잠금보다 레일이나 스프링 쪽 문제일 때가 많습니다.
걸린 셔터를 억지로 밀어 올리면 날개가 휘어 아예 안 내려갈 수 있습니다. / 셔터 자체 고장으로 보이면 셔터를 다루는 곳에 맡기시는 게 맞고, 잠금 부분 문제면 저희가 봅니다.
@ 방학동 가게 셔터 열쇠 유리문 바닥 잠금

# 사무실 도어락이 꺼졌거나 번호를 모를 때
2층이나 지하 사무실은 도어락을 다는 곳이 늘었습니다. / 주말 동안 배터리가 다 됐거나, 누군가 번호를 바꿔 놓고 공유하지 않은 경우가 흔합니다.
번호판이 꺼졌다면 바깥 비상 단자에 9V 건전지를 대 보세요. / 번호를 모르는 상황이라면 마지막으로 바꾼 사람이 누구인지 먼저 연락해 보시는 게 빠릅니다.
경고음이 길게 나면서 입력이 막혔다면 몇 분 기다렸다가 다시 시도하세요. / 계속 누르면 막히는 시간이 길어지는 제품도 있습니다.

# 영업 시간을 알려 주시면 맞춰 갑니다
가게는 문 여는 시간이 정해져 있어 "몇 시까지 열어야 한다"가 가장 중요합니다. / 전화하실 때 그 시간을 꼭 말씀해 주세요.
손님이 이미 기다리고 있다면 그것도 알려 주세요. / 작업 순서를 정할 때 참고합니다.
밤늦게 마감하다 문이 안 잠겨 퇴근을 못 하는 경우도 연락 주시면 됩니다. / 열리지 않는 것만큼 잠기지 않는 것도 사업장에서는 급한 일입니다.

# 건물 공용 출입문이 잠긴 경우
2층 이상 사무실은 건물 1층 공용 출입문부터 막히는 일이 있습니다. / 이 문은 건물 전체가 함께 쓰는 문이라 세입자 한 분이 마음대로 손대기 어렵습니다.
이럴 때는 건물 관리인이나 건물주께 먼저 연락해 열쇠나 번호가 있는지 여쭤보세요. / 관리하는 분이 함께 계시거나 전화로 허락해 주시면 그때 공용 문 작업을 진행합니다.
비상계단 방화문은 함부로 잠그거나 고정하면 안 되는 문이라 열기만 하고 잠금 방식은 바꾸지 않습니다. / 이 점은 현장에서 따로 말씀드립니다.
@ 방학동 상가 건물 공용 출입문 확인

# 사업장은 이렇게 확인합니다
가게와 사무실은 집과 확인 방법이 조금 다릅니다. / 아래 중 하나를 보여 주시면 됩니다.
- 사업자등록증 (주소가 해당 가게와 같은 것)
- 임대차 계약서 사본이나 사진
- 건물 관리인이나 건물주 확인
- 대표자 연락 확인 (직원이 부른 경우)
- 가게 이름과 주소가 함께 나온 영수증이나 공과금 고지서
직원분이 혼자 계실 때는 대표나 점장께 전화로 확인을 받기도 합니다. / 번거로워도 남의 가게 문을 함부로 열지 않기 위한 절차입니다.

# 작업 전에 금액부터 말씀드립니다
어느 문인지, 잠금장치가 어떤 것인지 보고 금액을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 영업이 가능한 상황이라면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
가게 장부 처리를 위해 작업 내용을 문자로 남겨 달라고 하시면 그렇게 해 드립니다. / 어느 문을 어떻게 손봤는지 적어 두면 나중에 건물주와 이야기할 때도 편합니다.

# 직원이 바뀌었다면 번호와 열쇠도 정리하세요
직원이 그만둔 뒤에도 같은 번호와 같은 열쇠를 쓰는 가게가 생각보다 많습니다. / 문제가 생기기 전에 번호를 바꾸고 열쇠가 몇 개 나가 있는지 세어 보세요.
도어락은 관리자 번호와 일반 번호를 나눠 쓸 수 있는 제품도 있습니다. / 열쇠 잠금은 실린더만 바꿔도 예전 열쇠가 안 맞게 됩니다.
여분 열쇠가 필요하면 [출장 열쇠](key-call.html)에서, 도어락을 새로 달 생각이면 [도어락 설치](doorlock-install.html)에서 보실 수 있습니다.

# 상가에서 자주 보는 고장
상가 문은 하루에도 수십 번 열리고 닫혀서 집 현관보다 빨리 닳습니다. / 특히 아래 같은 증상은 미루면 어느 날 갑자기 안 열리는 문으로 이어집니다.
- 유리문 손잡이 열쇠가 점점 뻑뻑해짐
- 도어락 손잡이가 처지거나 헛도는 느낌
- 셔터 열쇠를 돌릴 때 걸리는 지점이 생김
- 문이 끝까지 안 닫혀 걸쇠가 덜 물림
조짐이 보일 때 [도어락 수리](doorlock-repair.html)로 손보시면 영업 중에 멈추는 일을 줄일 수 있습니다.
@ 방학동 사무실 도어락 점검 출입문 수리

# 문이 열린 뒤 같이 보는 것
열고 나면 셔터, 유리문, 안쪽 문이 모두 정상으로 잠기고 풀리는지 차례로 확인합니다. / 마감 때 잠그다 막히는 일이 없게 마지막 문까지 한 번씩 돌려 봅니다. / 열쇠가 여러 개라면 어느 열쇠가 어느 문 것인지 표시해 두시길 권합니다.
배터리가 원인이었다면 새것으로 바꾸고, 번호 문제였다면 관리자 번호부터 새로 정해 드립니다.

# 방학동 말고 도봉구 다른 상가도
창동, 쌍문동, 도봉동 상가와 사무실도 같은 방식으로 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 가게·사무실 문 열기에 대해 묻는 것
? 영업 시작 전에 꼭 열어야 하는데 가능할까요? | 위치와 몇 시까지인지 말씀해 주시면 도착 시간을 먼저 알려 드립니다.
? 직원이 혼자 있는데 불러도 되나요? | 네, 다만 대표나 점장께 전화로 확인을 받은 뒤 진행합니다.
? 셔터가 걸린 것도 봐 주시나요? | 잠금 부분 문제는 저희가 보고, 셔터 날개나 모터 고장은 셔터 다루는 곳을 안내해 드립니다.
? 그만둔 직원이 열쇠를 안 돌려줬어요. | 실린더를 바꾸거나 도어락 번호를 새로 정하는 방법이 있습니다. 문 상태를 보고 말씀드립니다.
? 못 열면 출장 비용이 나오나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.

# 방학동 사장님께 드리는 한마디
가게 문이 안 열리면 어느 문인지, 몇 시까지 열어야 하는지, 확인 서류가 무엇인지 세 가지만 정리해 주세요. / 나머지는 현장에서 함께 풀어 가면 됩니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 다닙니다. / 문 여는 시간 전에 010-3664-5455로 연락 주세요.
