# 창동역 가는 길, 현관에서 도어락이 머뭇거린다면
창동은 창동역을 중심으로 오래된 아파트 단지가 넓게 퍼져 있고, 골목 안쪽으로 빌라와 다세대 주택이 이어지는 동네입니다. / 복도나 계단이 바깥 공기와 바로 닿는 집도 적지 않아 한파가 오면 현관 도어락이 먼저 추위를 탑니다.
기온이 영하로 떨어진 아침, 번호를 누르면 불이 한 박자 늦게 들어오거나 모터가 힘없이 돌다 마는 일이 생깁니다. / 저녁에 돌아왔을 때 번호판이 아예 안 켜지는 경우도 있습니다.
이 글은 창동에서 한파 때 도어락 반응이 느려지거나 꺼질 때 왜 그런지, 문 앞에서 무엇을 해 볼 수 있는지 정리했습니다. / 끝내 안 열리면 [도봉구 출장열쇠](seoul-dobong.html)를 부르시면 됩니다.
@ 창동 한파 도어락 번호판 반응 느림

# 추위가 배터리 힘을 빼앗는 이유
도어락에 들어가는 건전지는 안에서 화학 반응으로 전기를 만듭니다. / 날이 추우면 이 반응이 느려져 같은 건전지라도 낼 수 있는 힘이 줄어듭니다.
따뜻한 날에는 충분했던 건전지가 영하의 아침에는 모터를 끝까지 돌리지 못하는 겁니다. / 낮이 되어 기온이 오르면 다시 멀쩡해지기도 해서 고장인지 헷갈리게 됩니다.
특히 교체한 지 오래된 건전지일수록 추위에 더 약합니다. / 가을까지는 경고음 없이 잘 버티다가 첫 한파에 한꺼번에 티가 나는 경우가 많습니다.

# 한파 때 나타나는 순서가 있습니다
추위로 배터리가 약해질 때는 보통 아래 순서로 증상이 나타납니다.
- 번호판 불이 평소보다 늦게, 흐리게 들어옴
- 버튼 소리가 작아지거나 끊겨 들림
- 모터가 돌다 중간에 멈추고 다시 돌기
- 번호는 맞는데 걸쇠가 반만 빠져 문이 무거움
- 번호판이 아예 켜지지 않음
앞쪽 증상이 보이는 단계에서 배터리를 바꾸면 문 앞에서 막히는 일을 거의 피할 수 있습니다. / 맨 끝 단계에 와서야 알아차리는 분이 많아 아쉽습니다.

# 문 앞에서 먼저 해 볼 일
번호판이 느리게라도 켜진다면 천천히 한 번에 정확하게 눌러 보세요. / 급하게 여러 번 누르면 입력이 꼬여 처음부터 다시 해야 합니다.
모터가 힘없이 돌다 멈춘다면 문을 안쪽으로 살짝 밀면서 다시 번호를 눌러 보세요. / 걸쇠가 문틀에 눌려 있으면 약한 모터로는 빠져나오지 못하는데, 밀어 주면 부담이 줄어듭니다.
번호판이 아예 꺼졌다면 바깥쪽 비상 단자에 9V 건전지를 대 보세요. / 단자 위치는 번호판 아래쪽이나 옆면에 있는 경우가 많습니다.
@ 창동 도어락 비상 단자 9V 건전지

# 비상용 건전지도 추위를 탑니다
차 안이나 가방 바깥 주머니에 넣어 둔 9V 건전지는 한파에 같이 얼어 있습니다. / 대 봐도 반응이 약하다면 건전지를 손에 쥐거나 안주머니에 잠깐 넣어 체온으로 데운 뒤 다시 대 보세요.
몇 분만 데워도 힘이 꽤 돌아옵니다. / 건전지 단자를 비상 접점에 댈 때는 흔들리지 않게 꾹 눌러 붙인 채로 번호를 누르셔야 중간에 끊기지 않습니다. / 다만 불을 쬐거나 뜨거운 곳에 올려 데우는 건 위험하니 절대 하지 마세요.

# 하면 안 되는 겨울철 행동
- 드라이기나 손난로를 번호판에 바로 대기
- 뜨거운 물을 부어 녹이기
- 번호판을 손바닥으로 세게 두드리기
- 손잡이를 힘껏 당기며 번호 누르기
뜨거운 바람이나 물은 녹은 뒤 다시 얼면서 안쪽에 물기를 남깁니다. / 그 물기가 다음 날 아침 더 큰 고장으로 이어지기도 합니다. / 손잡이를 당기며 누르면 걸쇠가 문틀에 더 꽉 눌려 약한 모터가 아예 이기지 못하게 됩니다.

# 집 안에 들어갔다면 배터리는 한꺼번에
문이 열렸다면 그날 안에 안쪽 배터리를 모두 새것으로 바꿔 주세요. / 네 개 중 두 개만 바꾸면 남은 오래된 배터리가 새 배터리 힘까지 끌어내립니다.
같은 종류, 같은 날 산 배터리로 맞춰 넣는 게 좋습니다. / 넣을 때 방향을 한 번 더 확인하시고, 배터리 칸 접점에 하얀 가루나 녹이 보이면 마른 천으로 닦아 주세요.
배터리 덮개 안쪽에 바꾼 날짜를 적어 두면 다음 교체 시기를 잊지 않습니다. / 남은 배터리는 현관 신발장보다 거실 서랍처럼 따뜻한 곳에 보관하세요. 차가운 현관에 둔 새 배터리는 넣자마자 제 힘을 못 내기도 합니다.

# 결로가 같이 오는 집이라면
한파 때 집 안을 따뜻하게 하면 현관문 안쪽에 물방울이 맺히는 집이 있습니다. / 이 물기가 도어락 안쪽 몸체로 스며들면 배터리 문제와 겹쳐 증상이 더 복잡해집니다.
현관 쪽 문틈과 도어락 주변에 물기가 보이면 아침저녁으로 마른 천으로 닦아 주세요. / 중문이 있다면 닫아 두는 것만으로도 현관 온도 차가 줄어듭니다.
@ 창동 현관문 안쪽 결로 도어락 물기

# 오래된 도어락은 겨울에 더 힘들어합니다
창동 오래된 단지에서는 입주 때 단 도어락을 지금까지 쓰는 집도 있습니다. / 이런 도어락은 모터와 걸쇠가 닳아 같은 배터리로도 더 많은 힘을 써야 합니다.
새 배터리를 넣었는데도 한파 때마다 반응이 느리다면 배터리보다 도어락 자체를 봐야 합니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)로 점검하고, 부품이 없다면 [도어락 교체](doorlock-replace.html)를 함께 상의드립니다.

# 전화로 이 세 가지만 알려 주세요
번호판이 켜지는지, 모터 소리가 나는지, 비상 건전지를 대 봤는지를 말씀해 주세요. / 마지막으로 배터리를 언제 바꿨는지 기억나시면 그것도 알려 주세요.
아파트인지 빌라인지, 동과 호수, 공동현관 번호가 있는지도 함께 알려 주시면 도착이 빨라집니다. / 추운 날이니 기다리시는 동안은 따뜻한 곳에 계시고, 도착하면 전화를 드립니다.

# 문을 열기 전 확인과 금액
도착하면 신분증 주소, 주소가 적힌 우편물, 관리사무소 세대 확인 중 하나로 사시는 분인지 먼저 봅니다. / 신분증이 집 안에 있다면 문이 열린 직후 보여 주셔도 됩니다.
도어락 상태를 확인한 뒤 작업 전에 금액을 먼저 말씀드립니다. / 동의하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 한겨울을 덜 막히게 보내는 습관
- 첫 한파가 오기 전에 배터리를 모두 새것으로
- 경고음이 한 번이라도 나면 그날 바로 교체
- 비상용 9V 건전지는 가방 안쪽 주머니에
- 아침에 반응이 느렸던 날은 저녁에 미리 교체
- 현관 결로가 심하면 도어락 주변 물기 닦기
작은 습관이지만 영하의 아침에 문 앞에 서 있는 시간을 크게 줄여 줍니다. / 가족 모두 이 습관을 알고 있으면 누가 먼저 알아채든 바로 손쓸 수 있습니다.
@ 창동 겨울 도어락 배터리 미리 교체

# 창동 말고 도봉구 어디든
쌍문동, 방학동, 도봉동에서도 한파 때 똑같이 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

한파 때 도어락이 머뭇거리면 배터리부터 의심하세요. / 문 앞에서는 천천히 누르고, 문을 살짝 밀고, 비상 건전지를 데워서 대 보시면 됩니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 다닙니다. / 영하의 새벽이라도 010-3664-5455로 연락 주세요.
