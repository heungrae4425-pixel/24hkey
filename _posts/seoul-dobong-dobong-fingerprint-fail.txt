# 도봉동 부모님 댁, 손가락을 몇 번이나 대 보셨나요
도봉동은 도봉산역 쪽으로 단독주택과 다가구 주택이 많고, 큰길 쪽에는 아파트와 빌라가 이어지는 동네입니다. / 오래 사신 어르신 댁이 많아 번호 외우기 힘드시다며 지문 도어락으로 바꾼 집도 자주 봅니다.
그런데 막상 쓰다 보면 어르신 지문만 유독 잘 안 읽히는 일이 생깁니다. / 몇 번씩 손가락을 대다 결국 자녀에게 전화하시는 경우가 적지 않습니다.
이 글은 도봉동에서 지문 인식이 잘 안 될 때 손과 센서를 어떻게 살피고, 다시 등록할 때 무엇을 바꾸면 좋은지 정리했습니다. / 문이 아예 안 열리면 [도봉구 출장열쇠](seoul-dobong.html)를 부르시면 됩니다.
@ 도봉동 어르신 지문 도어락 인식 확인

# 나이 들면 지문이 옅어지는 게 자연스럽습니다
지문은 손끝 피부에 있는 가는 결입니다. / 나이가 들거나 손을 많이 쓰는 일을 오래 하면 이 결이 얕아지고 매끄러워집니다.
텃밭 일, 손빨래, 설거지를 자주 하시는 분이라면 더 그렇습니다. / 그래서 처음 등록할 때는 잘 되다가 몇 달 지나 인식이 떨어지는 경우도 있습니다.
이건 도어락이 고장 난 게 아니라 손과 센서가 서로 맞지 않게 된 것입니다. / 등록을 다시 하거나 손가락을 바꾸면 나아지는 일이 많습니다.

# 겨울에는 손이 마르면서 더 안 읽힙니다
찬바람이 불기 시작하면 손끝이 갈라지고 건조해집니다. / 센서는 손끝이 너무 마르면 결을 제대로 읽지 못합니다.
문 앞에서 손을 가볍게 비비거나 입김을 한 번 불어 살짝 촉촉하게 한 뒤 대 보세요. / 그것만으로 한 번에 열리는 경우가 꽤 있습니다.
반대로 핸드크림을 바른 직후에는 크림이 센서에 묻어 오히려 흐려집니다. / 크림은 집 안에 들어온 뒤에 바르시는 게 좋습니다.

# 손가락을 대는 자세부터 다시 보세요
어르신들은 손가락 끝만 살짝 대거나, 반대로 세게 눌러 비트는 경우가 많습니다. / 센서는 손가락 첫 마디 가운데가 평평하게 닿아야 잘 읽습니다.
- 손가락을 세우지 말고 눕혀서 첫 마디 전체를 올리기
- 누르지 말고 가볍게 대고 1초쯤 기다리기
- 대는 동안 손가락을 움직이지 않기
- 등록할 때와 같은 방향으로 대기
옆에서 한 번 같이 해 보시며 자세를 맞춰 드리면 금방 익숙해지십니다. / 손이 떨리시는 분은 다른 손으로 손목을 살짝 받치고 대시면 훨씬 안정적으로 읽힙니다.
@ 도봉동 지문 센서 손가락 대는 자세

# 센서 표면도 닦아 주세요
지문 센서는 매일 여러 손이 닿아 기름과 먼지가 쌓입니다. / 주택 대문에 달린 도어락은 비와 흙먼지까지 맞아 더 빨리 흐려집니다.
부드러운 마른 천으로 센서를 가볍게 닦아 주세요. / 물티슈나 세정제를 바로 뿌리면 틈으로 스며들 수 있으니 피하는 게 좋습니다.
센서 표면에 긁힌 자국이 보이면 닦는 것으로는 한계가 있습니다. / 이럴 때는 센서 부품을 점검받아 보셔야 합니다.

# 주택 대문에 단 지문 도어락은 날씨를 탑니다
도봉동 단독주택은 현관보다 바깥 대문에 지문 도어락을 다는 집도 있습니다. / 이런 도어락은 비, 눈, 햇볕을 그대로 맞아 아파트 현관 안쪽보다 센서가 빨리 지칩니다.
비 온 직후에는 센서 위 물기 때문에, 한겨울 아침에는 차가워진 센서 표면 때문에 인식이 늦어지기도 합니다. / 이럴 때는 마른 천으로 닦고 손바닥으로 잠시 감싸 온기를 준 뒤 다시 대 보세요.
대문 도어락 위에 작은 비가리개를 달아 두면 센서 수명이 한결 길어집니다. / 대문과 현관 모두 지문을 쓴다면 두 곳에 같은 손가락을 등록해 두셔야 헷갈리지 않습니다.

# 등록은 이렇게 다시 하면 잘 됩니다
인식이 계속 떨어진다면 지문을 지우고 새로 등록하는 게 가장 확실합니다. / 이때 몇 가지만 바꾸면 훨씬 잘 읽힙니다.
- 한 손가락만 하지 말고 양손 검지와 엄지까지 여러 개 등록
- 같은 손가락을 각도를 조금씩 바꿔 두 번 등록
- 손을 씻고 완전히 말린 뒤, 너무 마르지 않은 상태에서 등록
- 평소 문 앞에서 서는 자세 그대로 등록
지문을 지우고 다시 넣는 방법은 제품마다 다릅니다. / 설명서가 없다면 안쪽 몸체의 제품 이름을 알려 주시면 순서를 안내해 드립니다.

# 지문만 믿지 말고 번호도 남겨 두세요
지문 도어락이라도 번호나 카드 같은 다른 방법을 꼭 하나는 살려 두세요. / 손을 다치거나 밴드를 붙였을 때, 장갑을 낀 겨울날에 지문만으로는 들어갈 수 없습니다.
어르신이 번호를 외우기 어려우시다면 카드를 하나 지갑에 넣어 드리는 것도 방법입니다. / 번호는 가족 중 한두 명이 따로 알고 있으면 급할 때 전화로 알려 드릴 수 있습니다.

# 배터리가 약해도 인식이 떨어집니다
지문 센서는 번호 버튼보다 전기를 더 씁니다. / 배터리가 약해지면 번호는 눌리는데 지문만 잘 안 읽히는 일이 먼저 나타납니다.
경고음이 아직 안 났더라도 지문 인식이 갑자기 나빠졌다면 배터리부터 새것으로 바꿔 보세요. / 의외로 이것만으로 해결되는 집이 많습니다.
@ 도봉동 지문 도어락 배터리 교체

# 자녀가 멀리 산다면 미리 해 둘 것
도봉동 부모님 댁에 자주 못 가는 자녀분이라면 다음에 들렀을 때 아래를 챙겨 두세요. / 작은 준비로 급한 전화를 줄일 수 있습니다.
- 어르신 손가락을 세 개 이상 등록
- 비상용 카드 하나를 어르신 지갑에
- 번호는 가족 한두 명이 공유
- 배터리 교체 날짜를 배터리 덮개에 적기
가까운 이웃이나 다른 가족 연락처를 어르신 휴대폰 첫 화면에 저장해 두는 것도 좋습니다.

# 문이 끝내 안 열린다면
지문도 번호도 안 되고 카드도 없다면 그때는 출장을 부르셔야 합니다. / 어르신 혼자 문 앞에 계신다면 자녀분이 대신 전화 주셔도 됩니다.
도착하면 사시는 분인지 신분증 주소나 주소가 적힌 우편물로 먼저 확인합니다. / 자녀분이 부르신 경우 어르신과도 직접 확인한 뒤 진행합니다.
도어락 상태를 보고 작업 전에 금액을 먼저 말씀드리고, 끝내 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 있습니다.

# 문을 연 뒤 같이 점검하는 것
센서 상태와 배터리, 등록된 지문을 함께 확인합니다. / 필요하면 그 자리에서 어르신 지문을 다시 등록해 드리고, 번호도 새로 정해 드립니다.
센서 부품이 상했다면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 봅니다. / 제품이 너무 오래돼 부품이 없다면 어르신이 쓰기 편한 제품으로 [도어락 교체](doorlock-replace.html)를 상의드립니다.
@ 도봉동 도어락 지문 재등록 점검

# 도봉동 외 도봉구 다른 동네
창동, 쌍문동, 방학동 부모님 댁도 똑같이 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 어르신 지문 인식, 이런 질문이 많습니다
? 지문이 아예 안 나오는 분도 쓸 수 있나요? | 지문이 많이 옅으면 인식이 어려울 수 있습니다. 이럴 때는 카드나 번호를 함께 쓰시길 권합니다.
? 등록을 다시 하면 예전 지문은 지워지나요? | 제품마다 다릅니다. 지우고 새로 넣는 쪽이 깔끔해서 보통 그렇게 도와드립니다.
? 장갑을 끼면 안 되나요? | 일반 장갑은 인식이 안 됩니다. 겨울에는 한 손 장갑만 벗거나 번호를 쓰세요.
? 자녀가 대신 불러도 되나요? | 네, 다만 어르신과도 직접 확인한 뒤 진행합니다.
? 못 열면 비용이 나오나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.

# 도봉동에서 지문이 안 먹힐 때
손을 살짝 촉촉하게, 손가락은 눕혀서, 센서는 마른 천으로, 이 세 가지를 먼저 해 보세요. / 그래도 안 되면 배터리를 바꾸고, 여러 손가락을 다시 등록해 두시면 됩니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 다닙니다. / 부모님 댁 문이 안 열리면 010-3664-5455로 연락 주세요.
