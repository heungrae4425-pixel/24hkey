# 긴 연휴 끝, 도봉동 집 앞에서 번호판이 조용하다면
도봉동은 도봉산역 쪽으로 주택가와 다세대가 이어지고, 아파트도 함께 있는 동네입니다. / 명절이나 휴가철이 지나면 며칠 비워 둔 집에 돌아와 문 앞에서 막히는 연락이 몰립니다.
짐가방을 든 채로, 아이들은 피곤하다고 보채고, 장거리 운전으로 몸은 무겁습니다. / 이럴 때일수록 번호를 마구 눌러 보거나 손잡이를 세게 흔들기 쉬운데 그러면 오히려 시간이 더 걸립니다.
이 글은 집을 비웠다 돌아왔을 때 현관문이 안 열리는 흔한 이유와 확인 순서, 그리고 [도봉구 출장열쇠](seoul-dobong.html)를 부를 때 알려주시면 좋은 것을 적었습니다.
@ 도봉동 명절 귀가 현관 도어락 확인

# 비워 둔 집에서 문이 안 열리는 이유
- 비어 있던 동안 배터리가 조금씩 닳아 다 된 경우
- 떠나기 전 안쪽 보조 잠금이나 걸쇠까지 걸어 둔 경우
- 날씨가 갑자기 추워지거나 비가 와서 번호판이 오작동하는 경우
- 출발 직전 가족 중 누가 비밀번호를 바꿔 둔 경우
- 외출 모드나 이중 잠금 기능을 켜 두고 잊은 경우
도어락은 아무도 드나들지 않아도 대기 전력을 계속 씁니다. / 출발 전부터 배터리가 약했다면 며칠 사이에 완전히 꺼질 수 있습니다.

# 짐을 내려놓고 번호판부터 깨워 보세요
번호판을 손바닥으로 덮어 불이 들어오는지 확인합니다. / 불이 안 들어오면 배터리, 들어오는데 안 열리면 다른 원인으로 나눠 생각하시면 됩니다.
번호를 누를 때마다 짧게 삑 하는지, 길게 경고음이 나는지도 들어 보세요. / 소리 차이가 원인을 좁히는 데 큰 단서가 됩니다.
찬 바람을 오래 맞은 번호판은 반응이 늦을 수 있습니다. / 손으로 몇 초 감싸 데운 뒤 천천히 다시 눌러 보세요.

# 번호판이 꺼져 있다면 비상 전원을 대 보세요
대부분의 도어락은 바깥쪽 아래에 9V 건전지를 대는 비상 단자가 있습니다. / 건전지를 대고 있는 동안에만 전원이 들어오니 그 사이 번호를 누르시면 됩니다.
도봉산역 주변이나 가까운 편의점에서 9V 건전지를 구할 수 있습니다. / 늦은 밤이라 구하기 어렵거나 단자가 없으면 그때 전화 주세요.
문이 열리면 안쪽 건전지를 전부 새것으로 바꿔 주세요. / 연휴 동안 다 닳았다는 건 나머지도 수명이 거의 끝났다는 뜻입니다.
@ 도봉동 도어락 9V 비상 전원 단자

# 떠나기 전 걸어 둔 잠금을 떠올려 보세요
긴 외출 전에는 마음이 놓이지 않아 안쪽 보조 잠금을 하나 더 걸어 두는 분이 있습니다. / 그런데 안에서 걸어 둔 잠금은 바깥에서 풀 수 없습니다.
마지막으로 나간 사람이 어느 문으로 나갔는지 가족끼리 확인해 보세요. / 베란다나 뒷문으로 나갔다면 현관은 안에서 잠긴 채일 수 있습니다.
외출 모드나 이중 잠금 기능이 있는 제품은 설정을 켜 두면 평소 번호로 안 열리기도 합니다. / 설명서나 제품 이름을 알려주시면 해제 방법을 같이 찾아봅니다.

# 가족이 번호를 바꾸지는 않았나요
출발 직전에 "이번 기회에 바꾸자" 하며 번호를 바꿔 놓고 공유를 깜빡하는 일이 있습니다. / 가족 단체 대화방이나 메모장을 한 번 확인해 보세요.
몇 번 틀리면 도어락이 일정 시간 입력을 막습니다. / 확실하지 않은 번호를 연달아 넣지 말고, 기억나는 후보를 정리한 뒤 차분히 하나씩 넣어 보세요.

# 주택이라면 대문도 같이 확인하세요
도봉동 단독주택은 대문과 현관문이 둘 다 잠겨 있는 경우가 많습니다. / 대문 번호키도 같은 기간 동안 배터리가 닳았을 수 있으니 두 문을 모두 살펴보세요.
대문이 열렸는데 현관이 안 열리는지, 대문부터 막혔는지에 따라 준비할 것이 달라집니다. / 전화하실 때 어느 문인지 먼저 말씀해 주세요.

# 이런 상황이면 먼저 말씀해 주세요
집 안에 반려동물을 두고 다녀왔거나 돌봐 주는 분이 드나들던 집이라면 꼭 알려주세요. / 안에 생명이 있는 상황은 다른 일보다 먼저 움직입니다.
돌아와 보니 문 주변이 긁혀 있거나 평소와 다른 흔적이 보인다면 손대지 말고 경찰에 먼저 알리는 게 맞습니다. / 확인이 끝난 뒤에 문 작업을 진행합니다.
@ 도봉구 도봉동 장기 외출 후 출장열쇠 요청

# 전화하실 때 이렇게 말씀해 주세요
- 집을 비운 기간 (며칠, 몇 주)
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 대문과 현관 중 어느 문인지
- 도어락 사진 한 장
- 도봉산역 기준 대략 위치와 주소
짐이 많으시면 차 안이나 가까운 곳에서 기다리셔도 됩니다. / 도착 무렵 다시 연락드립니다.
연휴 끝자락에는 같은 시간대에 연락이 몰릴 수 있어 도착 예정 시간을 먼저 말씀드립니다. / 기다리기 어려운 사정이 있으면 그것도 편하게 말씀해 주세요.

# 거주 확인 후에 문을 엽니다
명절 직후는 출장 요청이 몰리는 때라 확인 절차를 더 꼼꼼하게 지킵니다. / 신분증 주소, 주소가 적힌 우편물이나 택배 송장, 관리사무소 세대 확인 중 하나를 보여 주세요.
여행 가방 안에 신분증이 있다면 미리 꺼내 두시면 바로 시작할 수 있습니다.
신분증이 집 안에 두고 간 경우라면 문이 열린 직후 안에서 확인하는 방법으로 진행합니다. / 다세대라면 집주인 연락으로 확인하는 방법도 있습니다.

# 비용 안내와 작업 시작
도어락과 문 상태를 보고 작업 내용과 비용을 손대기 전에 말씀드립니다. / 동의하시면 시작하고, 끝내 열지 못하면 비용은 받지 않습니다.
문을 여는 방법은 [현관문 개문](door-open.html)에, 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 문이 열린 뒤 집 안에서 할 일
문이 열렸다면 짐을 들이기 전에 도어락이 안팎에서 제대로 잠기고 풀리는지 두세 번 시험해 보세요. / 연휴 동안 추위나 습기를 맞은 도어락은 한 번 열린 뒤에도 반응이 늦을 수 있습니다.
배터리를 바꿀 때는 같은 날 산 새 건전지로 한꺼번에 넣어 주세요. / 집에 굴러다니던 건전지를 섞어 넣으면 며칠 못 가 다시 경고음이 납니다.
돌봐 주는 분이나 친척에게 임시 번호를 알려 주셨다면 이 자리에서 지우고 새 번호로 바꿔 두시는 게 좋습니다. / 연휴가 끝나면 그 번호를 쓸 일이 없기 때문입니다.
베란다 창과 뒷문도 출발 때처럼 잠겨 있는지 한 바퀴 둘러보세요. / 오래 비운 집은 작은 변화도 확인해 두는 편이 마음이 편합니다.
@ 도봉동 귀가 후 도어락 건전지 교체와 번호 정리

# 다음 연휴를 위한 출발 전 점검
- 출발 이틀 전쯤 도어락 건전지 새것으로 교체
- 안쪽 보조 잠금은 걸지 않거나 가족 모두 알고 나가기
- 비밀번호 변경은 돌아온 뒤에 하기
- 비상용 9V 건전지는 차나 가방에 하나
- 대문 번호키 배터리도 함께 확인
도어락이 자주 말썽이라면 이번 기회에 [도어락 수리](doorlock-repair.html) 점검을 받아 보시는 것도 방법입니다. / 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 비교해 드립니다.

? 안에서 걸쇠를 걸고 나왔는데 열 수 있나요? | 문 구조를 보고 방법을 정합니다. 사진을 보내 주시면 미리 알려드립니다.
? 대문과 현관 둘 다 잠겼어요. | 두 문 모두 열어 드립니다. 어떤 문인지 각각 알려주세요.
? 문을 못 열면 비용은요? | 받지 않습니다.

# 마무리
도봉동에서 연휴를 보내고 돌아와 문이 안 열리면 짐부터 내려놓고 번호판 상태를 확인해 보세요. / 비상 전원으로 안 되면 위치와 상황만 알려주시면 됩니다.
창동, 쌍문동, 방학동까지 도봉구 전체를 다니고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
