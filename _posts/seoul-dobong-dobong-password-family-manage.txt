# 도봉동 대가족 현관, 번호 하나에 여러 사람
도봉동은 도봉산역 쪽으로 단독주택과 다세대가 오래 자리 잡은 동네라 부모님과 자녀, 손주까지 한집이나 가까운 집에 사는 경우가 많습니다. / 현관 번호 하나를 여러 세대가 함께 쓰다 보면 누가 언제 바꿨는지 헷갈리는 일이 생깁니다.
번호를 오래 안 바꾸면 버튼 닳은 자국으로 번호가 드러나기도 하고, 반대로 너무 자주 바꾸면 어르신이 따라오기 힘들어집니다. / 그 사이 어딘가에 집안에 맞는 균형점이 있습니다.
이 글은 비밀번호를 바꾸는 주기, 가족과 나누는 방법, 바꾼 뒤 생기는 문제를 줄이는 요령을 정리했습니다. / 번호를 잊어 문이 안 열리는 상황이라면 [도봉구 출장열쇠](seoul-dobong.html)로 바로 연락 주세요.
@ 도봉동 주택 현관 도어락 번호판

# 왜 번호를 바꿔야 할까요
같은 번호를 몇 년씩 쓰면 자주 누르는 버튼만 반들반들해지거나 색이 바랩니다. / 가까이서 보면 어떤 숫자를 쓰는지 짐작이 갈 정도가 됩니다.
그동안 번호를 알게 된 사람도 늘어납니다. / 집수리 기사, 이삿짐 일꾼, 잠시 돌봐 준 이웃처럼 한때 필요해서 알려 준 사람들이 모두 같은 번호를 알고 있을 수 있습니다.
불안하게 생각하실 일은 아니지만 정기적으로 한 번씩 정리해 두면 마음이 편합니다.
진행 순서나 출장 때 확인하는 절차는 [이용안내](guide.html)에 정리해 두었습니다.

# 바꾸는 주기는 집안 사정에 맞추세요
정해진 정답은 없습니다. / 아래처럼 계기가 생길 때 바꾸는 것을 기본으로 하시면 무리가 없습니다.
- 계절이 바뀔 때나 해가 바뀔 때 한 번
- 공사, 수리, 이사 등으로 외부인에게 번호를 알려 준 뒤
- 가족 중 누가 독립하거나 새로 함께 살게 됐을 때
- 버튼 닳은 자국이 눈에 띌 때
- 돌봄 인력이나 도우미가 바뀌었을 때
어르신이 계신 집이라면 너무 잦은 변경보다 계기가 있을 때만 바꾸는 쪽이 낫습니다. / 대신 바꿀 때마다 확실히 알려 드리는 것이 중요합니다.

# 어르신도 기억하기 쉬운 번호 고르기
생일, 전화번호 뒷자리, 집 번지처럼 남이 쉽게 알 수 있는 숫자는 피하는 게 좋습니다. / 그렇다고 너무 복잡하면 어르신이 문 앞에서 막히십니다.
가족만 아는 기억을 숫자로 바꿔 보세요. / 처음 이 집에 이사 온 해의 뒷자리와 손주 이름 글자 수를 이어 붙이는 식이면 남은 모르고 가족은 떠올리기 쉽습니다.
번호 앞뒤에 아무 숫자나 덧붙여 눌러도 열리는 기능이 있는 제품도 많습니다. / 진짜 번호를 다른 숫자 사이에 숨겨 누르면 옆에서 보더라도 알기 어렵습니다.
@ 도봉동 도어락 비밀번호 가리고 누르기

# 바꾼 번호는 이렇게 나누세요
가족 단체 대화방에 번호를 그대로 올리면 휴대폰을 잃어버렸을 때 함께 새어 나갈 수 있습니다. / 직접 말로 전하거나 전화로 알려 드리는 쪽이 낫습니다.
어르신께는 종이에 적어 드리되, 현관 근처나 지갑 겉면에는 두지 않도록 말씀드리세요. / 집 안 서랍처럼 정해진 자리를 함께 정해 두시면 좋습니다.
번호를 바꾼 날에는 가족 모두가 한 번씩 직접 눌러 보게 하세요. / 알려 준 것과 실제로 누를 수 있는 것은 다를 때가 많습니다.

# 사람마다 다른 방법을 쓰는 것도 방법입니다
번호 하나에 모두가 매달릴 필요는 없습니다. / 어르신은 카드, 학생 자녀는 지문, 부모는 번호처럼 나눠 두면 번호를 바꿀 때 영향받는 사람이 줄어듭니다.
카드나 지문은 사람별로 등록하고 지울 수 있어 관리가 편합니다. / 독립한 자녀의 지문만 지우는 식으로 정리할 수 있습니다.
지문 인식이 잘 안 되는 어르신도 계십니다. / 그럴 때는 카드를 기본으로 하고 번호를 보조로 알려 드리는 쪽이 편합니다.

# 임시 번호 기능을 써 보세요
제품에 따라 한 번만 쓰고 사라지는 번호나 기간을 정한 번호를 따로 만들 수 있습니다. / 집수리나 택배 보관, 잠깐 들르는 친척에게 쓰기 좋습니다.
이 기능이 없다면 손님이 다녀간 뒤 원래 번호를 바꾸는 습관을 들이세요. / 오늘 하루 편하자고 미루면 결국 아무도 안 바꾸게 됩니다.

# 따로 사는 자녀와 번호를 나눌 때
도봉동 부모님 댁을 자주 드나드는 자녀가 따로 사는 경우도 많습니다. / 부모님이 번호를 바꾸시면 자녀가 소식을 늦게 듣는 일이 흔합니다.
부모님께 번호를 바꾸시면 꼭 한 사람에게는 전화로 알려 달라고 미리 약속해 두세요. / 그 한 사람이 나머지 가족에게 전하는 식으로 정하면 빠지는 사람이 줄어듭니다.
자녀 쪽에서 원격으로 확인할 수 있는 제품이라면 출입 기록을 가끔 살펴 부모님이 문 앞에서 오래 막히신 적은 없는지 보는 것도 방법입니다.

# 번호를 바꾼 직후 자주 생기는 일
- 새 번호 등록 중 마지막 확인 단계를 빠뜨려 예전 번호가 그대로인 경우
- 가족 한 명이 소식을 못 들어 문 앞에서 막힌 경우
- 새 번호를 여러 번 틀려 도어락이 잠시 입력을 막은 경우
- 건전지가 약한 상태에서 등록하다 설정이 저장되지 않은 경우
등록이 끝나면 문을 연 상태에서 바깥쪽 번호판으로 새 번호를 눌러 보세요. / 안쪽에서 확인을 끝내고 문을 닫아야 밖에서 막히는 일이 없습니다.
@ 도봉구 도봉동 새 비밀번호 등록 확인

# 대문과 현관이 둘 다 번호키라면
도봉동 주택은 대문과 현관에 각각 번호키를 단 집도 있습니다. / 두 번호를 똑같이 하면 편하지만 하나가 알려지면 둘 다 열립니다.
두 번호를 다르게 하되 연결된 규칙을 하나 두면 기억하기 쉽습니다. / 대문은 앞 네 자리, 현관은 거기에 두 자리를 더하는 식입니다.
대문 번호키는 바깥에 있어 버튼 닳음이 더 빨리 보입니다. / 현관보다 조금 더 자주 바꾸셔도 좋습니다.

# 번호를 잊어 문이 안 열렸다면
여러 번 틀리면 한동안 입력이 막히니 서너 번에서 멈추세요. / 가족에게 연락해 최근에 바꾼 사람이 있는지 먼저 확인하시는 게 빠릅니다.
그래도 안 되면 전화 주세요. / 도착하면 신분증 주소, 주소가 적힌 우편물, 관리사무소나 집주인 확인 가운데 하나로 사시는 분인지 확인한 뒤 엽니다.
비용은 상태를 보고 손대기 전에 먼저 말씀드리고, 못 열면 받지 않습니다. / 문이 열리면 새 번호 등록까지 함께 도와드립니다.

# 도어락 자체가 오래됐다면
오래된 제품은 번호 등록 개수가 적거나 임시 번호 기능이 없는 경우가 많습니다. / 버튼이 눌리는 감도도 떨어져 어르신이 누르기 힘들어하시기도 합니다.
고칠 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 기능이 부족하면 [도어락 교체](doorlock-replace.html)를 비교해 드립니다. / 어떤 기능이 집에 맞을지는 [도어락 설치](doorlock-install.html)에서도 미리 보실 수 있습니다.
@ 도봉동 오래된 도어락 버튼 감도 점검

# 마무리
도봉동처럼 여러 세대가 함께 쓰는 현관이라면 번호를 자주 바꾸는 것보다 바꿀 때 확실히 나누는 것이 더 중요합니다. / 사람마다 카드, 지문, 번호를 나눠 두면 관리가 한결 수월합니다.
창동, 쌍문동, 방학동까지 도봉구 전 지역을 다니며, 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
