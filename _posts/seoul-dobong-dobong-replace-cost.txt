# 도봉동에서 도어락을 바꿀까 고민 중이라면
도봉동은 도봉산역 쪽으로 주택가가 길게 이어지고, 다세대와 단독주택이 골목마다 섞여 있는 동네입니다. / 대문과 현관문이 따로 있는 집, 오래전에 단 손잡이 일체형 도어락을 그대로 쓰는 집이 많습니다.
도어락이 자꾸 말썽을 부리면 새것으로 바꾸고 싶은 마음이 먼저 듭니다. / 그런데 막상 알아보면 제품도 많고 설명도 제각각이라 무엇을 기준으로 정해야 할지 막막해집니다.
이 글은 바꾸기 전에 확인할 것, 그리고 [도봉구 출장열쇠](seoul-dobong.html)에서 비용을 어떤 순서로 안내하는지를 정리했습니다. / 숫자보다 판단 순서를 알려드리는 글이라고 생각하시면 됩니다.
@ 도봉동 주택 현관 도어락 교체 상담

# 정말 바꿔야 하는지부터 확인하세요
도어락 고장이라고 해서 모두 교체가 답은 아닙니다. / 배터리 접점 녹, 번호판 습기, 걸쇠 어긋남처럼 손보면 다시 잘 쓰는 경우가 생각보다 많습니다.
- 배터리를 새로 갈아도 증상이 그대로인지
- 비 오는 날이나 추운 아침에만 이상한지
- 문을 꽉 밀어야만 잠기는지
- 같은 증상이 최근 몇 주 사이에 갑자기 생겼는지
문을 밀어야만 잠긴다면 도어락보다 문틀이나 경첩 쪽 문제일 가능성이 큽니다. / 이때 도어락만 새로 달면 새 제품도 같은 자리에서 똑같이 걸립니다.

# 수리가 맞는 경우와 교체가 맞는 경우
수리로 충분한 경우는 대체로 이렇습니다. / 배터리 칸 접점 청소, 번호판 연결선 정리, 걸쇠 위치 조정처럼 부품 하나를 손보면 되는 경우입니다.
교체를 권해 드리는 경우도 분명히 있습니다. / 부품이 더 이상 나오지 않는 오래된 제품, 몸체 안 회로가 습기로 상한 제품, 외관이 깨져 비바람이 들어가는 제품이 그렇습니다.
도봉동 주택가는 처음 집을 지을 때 단 제품을 오래 쓰는 집이 많아 두 경우가 다 나옵니다. / 그래서 현장에서 직접 보고 어느 쪽이 맞는지 먼저 말씀드립니다.
수리 범위는 [도어락 수리](doorlock-repair.html), 교체 진행은 [도어락 교체](doorlock-replace.html) 페이지에 나눠 적어 두었습니다.

# 문 두께와 구멍 위치를 먼저 봐야 합니다
새 도어락은 문에 맞아야 제대로 잠깁니다. / 주택 현관문은 아파트 문보다 두께와 재질이 제각각이라 이 확인이 특히 중요합니다.
- 문 두께 (줄자로 문 옆면을 재기)
- 지금 도어락이 뚫어 놓은 구멍 크기와 위치
- 문 재질이 철인지, 나무인지, 유리가 섞였는지
- 문이 바깥으로 열리는지 안으로 열리는지
기존 구멍을 그대로 쓸 수 있는 제품을 고르면 문에 새로 손댈 일이 줄어듭니다. / 구멍을 더 넓혀야 하는 제품은 나중에 다른 제품으로 바꿀 때도 선택이 좁아질 수 있습니다.
@ 도봉동 현관문 두께 측정과 기존 구멍 확인

# 보조키를 남길지 함께 정하세요
주택 현관은 도어락 위나 아래에 열쇠로 여는 보조키를 함께 다는 집이 많습니다. / 교체할 때 이 보조키를 그대로 둘지, 떼고 구멍을 막을지, 새로 바꿀지 정해야 합니다.
보조키를 그대로 쓰신다면 새 도어락 몸체와 부딪치지 않는지 미리 봐야 합니다. / 위치가 너무 가까우면 새 제품의 크기에 제약이 생깁니다.
설치 전 확인 항목은 [도어락 설치](doorlock-install.html) 페이지에 더 자세히 있습니다.

# 오래 쓴 제품은 부품부터 확인합니다
도봉동 주택가에서 자주 보는 오래된 손잡이 일체형 도어락은 같은 부품이 이미 단종된 경우가 있습니다. / 이럴 때는 고장 난 부품 하나 때문에 전체를 바꿔야 하는 상황이 생깁니다.
반대로 비슷한 규격의 부품이 남아 있으면 그것만 바꿔 몇 년 더 쓰실 수도 있습니다. / 제품 안쪽에 적힌 이름과 제조 시기를 보면 대략 판단이 섭니다.
전화 주실 때 도어락 안쪽 배터리 덮개 근처를 사진으로 찍어 보내 주시면 부품 여부를 미리 알아볼 수 있습니다. / 현장에 와서 부품이 없어 헛걸음하는 일을 줄일 수 있습니다.
@ 도봉동 오래된 손잡이 일체형 도어락 부품 확인

# 대문과 현관문이 따로라면
도봉동 단독주택은 대문과 현관문을 모두 잠그는 집이 많습니다. / 현관 도어락만 바꿀지, 대문 잠금도 함께 손볼지에 따라 상담 내용이 달라집니다.
대문은 비바람을 그대로 맞는 자리라 실내 현관용 제품을 그대로 달면 오래 못 가는 경우가 있습니다. / 바깥용인지, 방수가 되는지 따져서 골라야 합니다.
대문은 철문이나 무거운 문이 많아 문이 처지면서 걸쇠가 어긋나는 경우도 흔합니다. / 이 경우는 잠금장치를 바꾸기 전에 문이 제자리에 닫히는지부터 봐야 합니다.

# 비용은 이런 순서로 안내드립니다
전화로는 지금 증상과 문 상태를 듣고 수리 가능성이 높은지, 교체 쪽인지 대략 말씀드립니다. / 정확한 금액은 현장에서 문과 제품을 직접 본 뒤 정해집니다.
- 도착 후 문, 도어락, 보조키 상태 확인
- 수리로 될지 교체가 필요한지 설명
- 작업 내용과 비용을 손대기 전에 먼저 안내
- 동의하시면 그때 작업 시작
- 중간에 추가 부품이 필요하면 다시 여쭤봄
설명을 듣고 생각해 보겠다고 하셔도 괜찮습니다. / 작업하지 않으면 그냥 돌아가며, 안내한 내용 밖에서 말없이 붙는 비용은 없습니다.
@ 도봉구 도봉동 도어락 교체 비용 사전 안내

# 비교할 때 금액만 보지 마세요
여러 곳에 물어보시는 건 당연한 일입니다. / 다만 비교할 때는 같은 내용을 비교하고 있는지 꼭 확인하세요.
기존 도어락 철거, 구멍 보수, 보조키 처리, 설치 뒤 등록과 점검까지 포함인지가 곳마다 다를 수 있습니다. / 이런 부분을 물어보시면 저희도 하나씩 설명드립니다.
가장 싼 제품이 문에 안 맞아 구멍을 새로 뚫어야 한다면 결국 일이 커질 수 있습니다. / 문에 맞는지, 오래 쓸 수 있는지를 함께 보고 정하시길 권합니다.
설치 뒤 문제가 생겼을 때 어떻게 하는지도 미리 물어 두시는 게 좋습니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 교체 당일 준비해 주시면 좋은 것
교체는 문을 여는 일이 아니라도 집 출입과 관련된 작업이라 사시는 분인지 확인합니다. / 신분증 주소나 우편물을 준비해 주시고, 세입자라면 집주인과 미리 이야기해 두세요.
가족 모두의 지문이나 카드를 새로 등록해야 하니 가능하면 가족이 함께 있는 시간으로 정하시면 편합니다. / 기존 도어락 설명서나 카드가 있다면 같이 꺼내 두세요.

# 바꾼 뒤 꼭 확인하실 것
- 문 안팎에서 여러 번 잠그고 열어 보기
- 문을 살살 닫았을 때도 자동으로 잠기는지
- 비밀번호, 카드, 지문 등록이 모두 되는지
- 비상 전원 단자 위치 알아 두기
설치 직후에는 문틀과 걸쇠가 잘 맞아도 며칠 쓰다 보면 미세하게 걸리는 경우가 있습니다. / 이상하면 참지 마시고 바로 말씀해 주세요.

# 자주 묻는 질문

? 고쳐 쓸 수 있으면 교체를 권하지 않나요? | 네, 수리로 충분하면 수리를 먼저 말씀드립니다.
? 대문 잠금도 같이 봐 주시나요? | 네, 현관문과 대문을 함께 확인해 드립니다.
? 세입자인데 도어락을 바꿔도 되나요? | 계약 내용에 따라 다르니 집주인과 먼저 상의해 주세요. 상의가 끝나면 진행해 드립니다.
? 설명만 듣고 안 해도 되나요? | 네, 작업하지 않으시면 그냥 돌아갑니다.

# 마무리
도봉동에서 도어락 교체를 생각하신다면 먼저 고쳐 쓸 수 있는지, 문과 보조키에 맞는지부터 확인하세요. / 비용은 직접 보고 손대기 전에 먼저 말씀드립니다.
도봉동 외에 창동, 쌍문동, 방학동 등 도봉구 전 지역을 다니며, 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 문의 주세요.
