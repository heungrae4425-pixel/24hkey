# 교체를 고민하고 있다면 먼저 읽어 주세요
청량리동은 청량리역 일대 상가 건물과 오래된 다세대, 재개발로 새로 들어선 아파트가 함께 있는 동네입니다. / 건물마다 처음 달린 도어락의 연식과 종류가 달라 교체 시기도 집집마다 다릅니다.
도어락이 자꾸 말썽이면 아예 새것으로 바꿀까 싶어집니다. / 그런데 막상 알아보면 제품도 많고, 비용이 어떻게 정해지는지 몰라 결정을 미루게 됩니다.
이 글은 청량리동에서 도어락 교체를 생각할 때 정말 바꿔야 하는지 가르는 기준과, 교체 비용을 안내받는 방식을 정리했습니다. / 문이 지금 안 열려 급하다면 [동대문 출장열쇠](seoul-dongdaemun.html)로 먼저 연락 주세요.
@ 청량리동 도어락 교체 상담

# 정말 교체가 필요한지부터
불편함이 있다고 해서 모두 교체해야 하는 건 아닙니다. / 증상의 원인이 도어락 안쪽인지, 문이나 건전지 같은 바깥 요인인지를 먼저 가르는 게 순서입니다.
같은 증상이라도 원인이 다르면 해결 방법도 비용도 크게 달라집니다. / 그래서 교체 상담을 받으시더라도 처음에는 지금 증상을 있는 그대로 설명해 주시는 게 좋습니다.

# 수리로 충분한 경우
아래와 같은 경우는 부품 손질이나 조정으로 다시 쓰는 경우가 많습니다.
- 건전지를 갈고 나면 한동안 괜찮아지는 경우
- 문이 처져서 걸쇠가 문틀에 걸리는 경우
- 번호판 한두 개 버튼만 잘 안 눌리는 경우
- 손잡이가 헐거워졌지만 잠금 자체는 잘 되는 경우
이런 증상은 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 그래도 반복될 때 교체를 생각하셔도 늦지 않습니다.

# 교체를 권하는 경우
반대로 아래 상황이라면 고쳐 쓰기보다 바꾸는 편이 길게 봐서 낫습니다.
- 회로나 모터가 상했는데 같은 부품을 더 이상 구할 수 없는 경우
- 습기나 물이 들어가 번호판과 몸체 안쪽이 함께 상한 경우
- 번호를 잊을 때마다 초기화가 어려운 오래된 제품인 경우
- 가족이 늘거나 생활이 바뀌어 지문, 카드 같은 다른 방식이 필요해진 경우
교체 여부는 직접 보고 말씀드리며, 굳이 바꾸지 않아도 될 때는 그렇게 말씀드립니다.

# 견적 전에 재 두면 좋은 것
교체 비용은 제품과 문 상태에 따라 달라집니다. / 아래 내용을 미리 알려 주시면 통화 단계에서 대략의 방향을 함께 잡을 수 있습니다.
- 문 두께: 문 옆면을 줄자로 재면 됩니다
- 지금 도어락 제품 이름이나 사진
- 원하는 여는 방식: 번호, 지문, 카드, 앱 가운데 무엇
- 손잡이 형태: 손잡이 일체형, 버튼형, 밀고 당기는 형
문 안쪽과 바깥쪽을 한 장씩 찍어 보내 주시면 기존 구멍 위치까지 확인할 수 있어 더욱 정확해집니다.
@ 청량리동 현관문 두께 측정 도어락 교체 전

# 기존 구멍과 보조키는 어떻게 할까
다세대나 오래된 문은 예전 도어락과 보조키를 떼어 낸 구멍이 여러 개 남아 있는 경우가 많습니다. / 새 제품이 이 구멍을 다 덮지 못하면 보강판을 대거나 구멍을 메우는 작업이 따로 필요합니다.
보조키를 계속 쓸지, 떼어 내고 도어락 하나로 정리할지도 미리 정해 두세요. / 떼어 낸다면 그 자리를 어떻게 마감할지도 함께 의논합니다.
이런 부분은 문을 직접 봐야 정확히 알 수 있어서 방문해서 확인한 뒤 말씀드립니다.

# 비용을 가르는 부분
도어락 교체 비용은 크게 제품, 문 상태, 추가 작업 세 가지로 나뉩니다. / 어떤 부분 때문에 금액이 달라지는지 알고 계시면 안내를 들을 때 이해가 쉽습니다.
제품은 여는 방식과 기능 수, 소재에 따라 차이가 납니다. / 문 상태는 두께와 구멍 위치, 문틀이 맞는지에 따라 작업량이 달라집니다.
추가 작업은 보강판, 구멍 메우기, 걸쇠 받침 위치 조정, 보조키 제거 같은 것들입니다. / 필요 없는 작업은 하지 않으며, 필요한 경우에도 미리 설명드립니다.

# 비용 안내는 이렇게 진행됩니다
전화로는 문 상태를 다 알 수 없어 대략의 방향까지만 말씀드립니다. / 방문해서 문과 기존 도어락을 직접 본 뒤 정확한 비용을 먼저 안내합니다.
안내를 들으신 뒤 괜찮다고 하시면 그때 작업을 시작합니다. / 마음에 안 드시면 그 자리에서 정리하고 돌아가니 부담 갖지 않으셔도 됩니다.
작업 도중에 생각지 못한 상황이 생기면 손대기 전에 다시 말씀드리고 여쭙습니다. / 말없이 금액이 바뀌는 일은 없습니다. 진행 순서는 [이용안내](guide.html)에도 있습니다.

# 추가로 물어보면 좋은 질문
안내를 들으실 때 아래 질문을 함께 해 보시면 나중에 서로 오해가 없습니다.
- 안내받은 금액에 제품, 설치, 기존 도어락 철거가 모두 들어 있는지
- 보강판이나 구멍 메우기가 필요한지
- 설치 후 문제가 생기면 어떻게 연락하면 되는지
- 떼어 낸 기존 도어락은 어떻게 처리하는지
궁금한 게 있으면 언제든 물어보셔도 괜찮습니다. / 이해가 될 때까지 설명드리는 것이 먼저입니다.

# 상가나 세입자라면 먼저 의논할 것
청량리동 상가 건물 가게나 사무실이라면 출입문 교체 전에 건물 관리하시는 분과 이야기해 두시는 게 좋습니다. / 공용 출입문인지 우리 가게만 쓰는 문인지에 따라 결정하는 사람이 달라질 수 있습니다.
세입자분이라면 교체 전에 집주인과 미리 상의해 두시면 나중에 퇴거할 때 서로 편합니다. / 누가 비용을 부담할지는 계약 내용과 당사자 간 합의에 따라 다르니 미리 정해 두세요.

# 교체 당일은 이 순서로
방문하면 먼저 문 두께와 구멍 위치를 재고, 고르신 제품이 문에 맞는지 확인합니다. / 맞으면 기존 도어락을 떼고 새 제품을 단 뒤 걸쇠와 문틀 홈이 맞는지 조정합니다.
설치가 끝나면 번호와 지문, 카드 등록을 함께 해 드립니다. / 가족 모두 한 번씩 직접 열어 보시도록 권합니다.
@ 동대문 출장열쇠 청량리동 도어락 교체 설치

# 교체 후 꼭 확인할 것
새 도어락이 달린 뒤 문을 열어 둔 채로 잠금과 열림을 여러 번 시험해 보세요. / 문을 닫은 상태에서도 바깥과 안쪽에서 각각 열어 봐야 합니다.
건전지 칸 위치와 비상 단자 위치, 비상 열쇠가 있다면 보관 장소도 함께 정해 두세요. / 설명서는 버리지 말고 건전지 칸 근처나 서랍에 넣어 두시면 나중에 설정을 바꿀 때 쓸모가 있습니다.
설치 관련 자세한 내용은 [도어락 교체](doorlock-replace.html)와 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.

# 청량리동 말고 동대문구 어디든
청량리동과 가까운 제기동, 전농동, 회기동은 물론 휘경동, 이문동, 답십리동, 장안동, 용신동까지 출동합니다. / 동대문구 안내는 [동대문구 출장열쇠](seoul-dongdaemun.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 전화로 정확한 교체 비용을 알 수 있나요? | 문 상태를 봐야 정확히 알 수 있어 전화로는 방향만 말씀드리고, 방문 후 작업 전에 먼저 안내합니다.
? 안내받고 안 하겠다고 해도 되나요? | 네, 괜찮습니다. 동의하실 때만 작업합니다.

? 고쳐 쓸 수 있는데 교체를 권하시나요? | 고쳐 쓸 수 있으면 수리를 먼저 말씀드립니다.
? 상가 출입문도 교체하시나요? | 네, 가게와 사무실 출입문도 갑니다. 건물 관리 쪽과 먼저 이야기해 두시면 좋습니다.
