# 도어락은 풀렸는데 문이 꿈쩍 않는다면
회기동은 회기역 주변으로 대학가 원룸과 오래된 다세대가 촘촘하게 들어선 동네입니다. / 혼자 사는 집이 많고 방범을 위해 도어락 아래에 보조키나 안쪽 걸쇠를 하나 더 다는 경우가 흔합니다.
번호를 누르면 띠리릭 소리까지 나는데 문이 열리지 않는다면 도어락이 아니라 다른 잠금장치가 원인일 수 있습니다. / 이럴 때 무엇이 걸렸는지 먼저 알아야 엉뚱한 곳을 건드리지 않습니다.
이 글은 회기동에서 보조키나 걸쇠 때문에 막혔을 때 구분하는 방법과 [동대문 출장열쇠](seoul-dongdaemun.html)를 부르는 순서를 담았습니다.
@ 회기동 원룸 현관 보조키 걸쇠 잠김

# 보조키와 걸쇠, 무엇이 걸렸는지부터
현관문에 붙는 잠금장치는 생각보다 여러 겹입니다. / 상황마다 문의 움직임이 달라서 손으로 살짝만 밀어 봐도 어느 쪽인지 짐작할 수 있습니다.
- 주 도어락: 번호나 카드로 여는 전자식 잠금
- 보조키: 도어락 위나 아래에 따로 붙은 열쇠식 또는 돌림식 잠금
- 안쪽 걸쇠: 문이 조금만 열리게 막는 고리형, 막대형, 체인형 장치
문을 당겼을 때 손잡이만 돌고 문이 전혀 안 움직이는지, 한 뼘쯤 열리다가 탁 멈추는지를 먼저 봐 주세요.

# 한 뼘 열리고 멈췄다면 걸쇠입니다
문이 손바닥 폭만큼 열리고 더 안 나간다면 안쪽 걸쇠가 걸려 있는 상태입니다. / 걸쇠는 안에서만 걸 수 있으니 누군가 안에 있거나, 문을 닫는 충격에 고리가 저절로 넘어간 경우입니다.
요즘 나오는 막대형 걸쇠는 문을 세게 닫을 때 막대가 내려앉아 걸리는 일이 종종 있습니다. / 집에 아무도 없는데 걸쇠가 걸렸다면 대개 이런 경우입니다.
이때 열린 틈으로 손이나 물건을 넣어 억지로 밀어 올리면 걸쇠 받침이 휘거나 손을 다칠 수 있습니다. / 틈은 그대로 두고 문을 살짝 당겨 놓은 채로 연락을 주세요.

# 문이 아예 안 움직이면 보조키 쪽
번호가 맞았는데 문이 처음부터 꽉 붙어 있다면 보조키가 잠긴 쪽을 의심합니다. / 보조키 열쇠를 갖고 계신다면 열쇠를 끝까지 넣고 천천히 돌려 보세요.
열쇠가 반쯤 돌다 멈추면 문을 몸쪽으로 살짝 당기거나 반대로 밀면서 다시 돌려 봅니다. / 문이 처져서 보조키 빗장이 문틀에 눌려 있을 때 이렇게 하면 풀리는 경우가 있습니다.
열쇠를 잃어버렸거나 처음부터 받지 않은 보조키라면 바깥에서 할 수 있는 일이 거의 없습니다. / 돌림식 보조키는 안에서만 잠기는 구조라 더욱 그렇습니다.
@ 회기동 현관문 보조키 열쇠 돌리기

# 룸메이트나 가족이 안에 있을 때
안에 누군가 있다면 걸쇠나 보조키를 풀어 달라고 부탁하면 끝나는 문제입니다. / 다만 자고 있거나 이어폰을 끼고 있어 못 듣는 경우가 많습니다.
초인종보다는 전화나 메시지를 여러 번 보내는 쪽이 잘 통합니다. / 문을 계속 두드리면 같은 층 이웃이 놀랄 수 있으니 간격을 두고 해 주세요.
안에 있는 분이 아프거나 응답이 전혀 없어 걱정된다면 망설이지 말고 119에도 함께 알리시는 게 맞습니다. / 사람이 다쳤을 수 있는 상황은 문 열기보다 안전 확인이 먼저입니다.

# 아무도 없는데 보조키가 잠긴 까닭
혼자 사는 집에서 보조키가 잠겼다면 나갈 때 습관처럼 돌려 놓고 잊은 경우가 가장 많습니다. / 안팎 모두 열쇠로 여는 보조키라면 바깥에서 잠그고 나왔을 수 있습니다.
이사 들어온 집이라면 예전 세입자가 쓰던 보조키를 그대로 둔 채 열쇠를 받지 못한 경우도 있습니다. / 이런 보조키는 쓰지 않을 거라면 아예 떼어 내는 것도 방법입니다.
돌림식 보조키는 손잡이가 작아서 짐을 들고 나가다 팔꿈치나 가방에 스쳐 반쯤 돌아가기도 합니다. / 그 상태로 문을 닫으면 빗장이 문틀 홈에 걸려 다음에 안 열리는 원인이 됩니다.

# 바깥에서 걸쇠를 풀려고 할 때 생기는 일
인터넷에 고무줄이나 끈으로 걸쇠를 푸는 방법이 돌아다닙니다. / 제품 모양이 다 달라서 실제로 되는 경우는 드물고 시간만 흘러갑니다.
철사나 옷걸이를 문틈에 넣다가 문틀 고무가 찢어지면 그 뒤로 바람과 소음이 새어 들어옵니다. / 걸쇠 받침이 휘면 다음부터 걸쇠가 제대로 걸리지 않아 방범 효과도 떨어집니다.
- 문틈에 철사, 옷걸이, 카드 넣지 않기
- 걸린 상태에서 문을 반복해서 세게 당기지 않기
- 경첩 쪽 틈을 벌리려 하지 않기

# 회기역 근처 건물 위치 설명 요령
회기동 원룸 골목은 비슷한 건물이 이어져 있어 주소만으로는 찾기 어려울 때가 있습니다. / 건물 이름이나 외벽 색, 1층에 무엇이 있는지 같이 알려 주시면 큰 도움이 됩니다.
- 도로명 주소와 건물 이름, 호수
- 회기역에서 어느 방향인지
- 공동 현관 비밀번호가 필요한 건물인지
- 걸린 것이 보조키인지 걸쇠인지, 문이 몇 센티쯤 열리는지
문틈으로 보이는 걸쇠 사진을 찍어 보내 주시면 맞는 도구를 골라 가기 쉽습니다.

# 사시는 분 확인을 먼저 합니다
걸쇠나 보조키를 푸는 일도 문을 여는 일이라 거주 확인을 거칩니다. / 신분증에 적힌 주소나 주소가 나온 우편물, 임대차 관련 서류 사진 가운데 하나를 보여 주시면 됩니다.
원룸은 관리하시는 분이나 건물주와 연락이 닿으면 확인이 더 쉬워집니다. / 신분증이 방 안에 있다면 문이 열린 뒤 바로 보여 주셔도 됩니다.

# 비용은 시작 전에 정합니다
걸쇠인지 보조키인지, 보조키라면 어떤 형식인지에 따라 작업이 달라집니다. / 상태를 본 뒤 비용을 먼저 말씀드리고, 괜찮다고 하시면 그때 시작합니다.
열지 못하면 비용은 받지 않습니다. / 자세한 진행 방식은 [이용안내](guide.html)에서 보실 수 있습니다.
@ 동대문 출장열쇠 회기동 걸쇠 보조키 해제

# 열린 뒤 보조키를 계속 쓸지 정하기
문이 열리면 걸쇠 받침이 휘지 않았는지, 보조키가 부드럽게 도는지 같이 봅니다. / 막대형 걸쇠가 저절로 내려앉는 제품이면 각도를 조금 손보는 것만으로 재발을 줄일 수 있습니다.
보조키 열쇠가 없다면 실린더만 바꾸거나 떼어 내는 방법이 있습니다. / 원룸이라면 보조키를 바꾸거나 떼기 전에 건물주와 한 번 상의해 두시면 나중에 퇴거할 때 서로 편합니다. / 떼어 낸 자리에 구멍이 남는지도 미리 확인해 드립니다.
도어락과 보조키를 하나로 정리하고 싶다면 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html) 안내를 참고하세요.

# 동대문구 다른 동네도 다닙니다
회기동 바로 옆 휘경동, 이문동, 청량리동은 물론 제기동, 전농동, 답십리동, 장안동, 용신동도 다닙니다. / 동대문구 동네 안내는 [동대문구 출장열쇠](seoul-dongdaemun.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
