# 손가락을 대도 빨간 불만 깜빡일 때
제기동은 청량리역 생활권과 맞닿은 동네로 오래된 주택과 다세대, 새로 지은 아파트가 골목을 사이에 두고 함께 있습니다. / 집 모양은 달라도 요즘은 지문 도어락을 다는 집이 부쩍 늘었습니다.
지문 도어락은 편하지만 어느 날부터 손가락을 몇 번씩 대야 열리거나, 아예 실패음만 나는 경우가 있습니다. / 고장인가 싶어 걱정되지만 실제로는 손이나 센서 상태 때문인 경우가 훨씬 많습니다.
이 글은 제기동에서 지문 인식이 잘 안 될 때 혼자 확인해 볼 순서와, [동대문 출장열쇠](seoul-dongdaemun.html)를 불러야 하는 신호를 정리했습니다.
@ 제기동 지문 도어락 인식 실패

# 지문이 안 읽히는 흔한 이유
지문 센서는 손가락 표면의 굴곡을 읽어 등록된 모양과 비교합니다. / 그래서 손끝 표면이 평소와 달라지거나 센서 창이 흐려지면 같은 사람이라도 다르게 읽힙니다.
- 손이 너무 건조하거나 젖어 있음
- 손끝에 상처, 굳은살, 물집이 생김
- 센서 창에 기름, 먼지, 물기가 묻음
- 손가락을 대는 위치와 각도가 등록할 때와 다름
- 추운 날 손이 차갑게 굳음
대부분은 이 가운데 하나라서 몇 가지만 바꿔도 다시 잘 열립니다.
처음 설치했을 때는 한 번에 열리다가 몇 달 지나 점점 실패가 늘었다면 센서 창이 서서히 흐려졌을 가능성이 큽니다. / 반대로 어느 날 갑자기 모든 식구가 실패한다면 센서나 회로 쪽을 먼저 의심해 봐야 합니다.

# 손 상태부터 살펴보세요
설거지나 손빨래를 막 마친 손, 핸드크림을 듬뿍 바른 손은 인식이 잘 안 됩니다. / 마른 수건으로 손끝을 가볍게 닦고 몇 초 뒤 다시 대 보세요.
겨울에 손끝이 갈라질 만큼 건조하면 반대로 입김을 살짝 불어 손끝에 약간의 습기를 주면 나아지기도 합니다. / 장갑을 막 벗은 손은 잠깐 비벼 체온을 올린 뒤 대는 게 좋습니다.
요리나 공예, 현장 일처럼 손을 많이 쓰는 분은 손끝이 자주 변합니다. / 이런 분은 한 손가락에만 기대지 말고 덜 쓰는 손가락을 함께 등록해 두세요.

# 센서 창은 이렇게 닦습니다
센서 창은 작은 유리나 플라스틱 판이라 손자국이 금방 쌓입니다. / 안경닦이처럼 부드럽고 마른 천으로 살살 닦아 주세요.
물티슈나 세정제를 바로 뿌리면 틈으로 물기가 스며들 수 있습니다. / 꼭 써야 한다면 천에 아주 조금 묻혀 닦고 마른 천으로 한 번 더 훔쳐 냅니다.
비 오는 날 우산을 들고 들어오다 센서에 물방울이 맺히기도 합니다. / 이때는 손가락 대기 전에 손등으로 한 번 쓱 닦기만 해도 효과가 있습니다.
@ 제기동 지문 센서 창 마른 천 청소

# 손가락 대는 자세 바꿔 보기
등록할 때 손가락 가운데를 댔다면 열 때도 가운데가 닿아야 합니다. / 급하게 손끝만 톡 대면 등록된 부분과 겹치는 면적이 작아 실패하기 쉽습니다.
센서를 꾹 누르지 말고 손가락 첫마디가 평평하게 닿도록 가볍게 올려 두세요. / 너무 세게 누르면 지문 골이 눌려 오히려 읽기 어려워집니다.
손가락을 대자마자 떼지 말고 짧은 확인음이 날 때까지 잠깐 기다리는 것도 중요합니다.
짐을 든 손으로 팔꿈치를 비틀어 대거나 새끼손가락 쪽으로 기울여 대면 실패가 잦아집니다. / 짐을 잠시 내려놓고 손을 바로 세워 대는 것만으로도 성공률이 눈에 띄게 올라갑니다.

# 계절 따라 달라지는 인식
같은 집에서도 여름과 겨울의 인식률이 다르다고 느끼시는 분이 많습니다. / 여름에는 땀과 습기, 겨울에는 건조함과 찬 손이 원인입니다.
현관문이 바깥 공기에 바로 닿는 다세대나 주택이라면 겨울철 센서 자체도 차가워져 반응이 느려질 수 있습니다. / 계절이 바뀔 때 한 번씩 손가락을 다시 등록해 두면 한결 수월해집니다.
현관 앞에 햇볕이 강하게 드는 집이라면 센서 창에 직사광선이 비칠 때 인식이 흔들리기도 합니다. / 손바닥으로 그늘을 만들어 주고 대 보면 차이가 나는지 확인해 보세요.

# 지문 대신 쓸 수 있는 수단
지문이 계속 안 되면 일단 다른 수단으로 문부터 여세요. / 대부분의 지문 도어락에는 번호 입력이 함께 있고, 카드나 태그를 쓰는 제품도 많습니다.
평소 지문만 쓰다 보면 번호를 잊어버리기 쉽습니다. / 지문이 잘 될 때 번호도 가끔 직접 눌러 보며 기억을 유지해 두세요.
번호도 기억나지 않고 카드도 없다면 번호판을 반복해서 누르기보다 바로 연락 주시는 게 낫습니다. / 여러 번 틀리면 입력 제한이 걸려 시간이 더 걸립니다.

# 다시 등록할 때의 요령
문이 열린 뒤에는 잘 안 되던 손가락을 지우고 새로 등록해 보세요. / 등록할 때 손가락을 조금씩 각도를 바꿔 여러 번 대면 다양한 자세를 기억해 둡니다.
- 손을 씻고 완전히 말린 뒤 등록하기
- 한 사람당 두세 손가락 등록하기
- 가운데, 왼쪽, 오른쪽으로 조금씩 굴려 대기
- 등록 후 문을 연 채로 열 번쯤 시험해 보기
아이 지문은 자라면서 크기가 변하니 계절마다 다시 등록해 주시는 게 좋습니다.
등록 메뉴에 들어가려면 관리자 번호가 필요한 제품이 많습니다. / 관리자 번호를 모르면 초기화를 해야 할 수도 있으니 설명서를 미리 찾아 두시거나 방문 때 함께 정리해 달라고 말씀해 주세요.

# 센서 고장일 수 있는 신호
아래 증상이 함께 나타나면 손이나 청소 문제가 아닐 수 있습니다.
- 손가락을 대도 아무 반응이나 불빛이 없음
- 등록된 적 없는 손가락에도 열리거나 반대로 모두 실패
- 센서 창에 금이 가거나 안쪽에 김이 서림
- 번호판은 정상인데 지문만 계속 안 됨
이럴 때는 [도어락 수리](doorlock-repair.html)로 센서 상태를 점검하는 게 좋습니다.

# 문 앞에서 끝내 막혔다면
번호도 카드도 없이 지문만 안 되는 상황이면 연락을 주세요. / 도착하면 사시는 분인지 신분증 주소나 주소가 적힌 우편물, 관리사무소 확인으로 먼저 확인합니다.
도어락 상태를 본 뒤 비용을 먼저 말씀드리고 동의하시면 시작합니다. / 열지 못하면 비용은 받지 않으며, 진행 흐름은 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 동대문 출장열쇠 제기동 지문 도어락 점검

# 수리로 갈지 교체로 갈지
센서만 문제라면 부품을 손봐 다시 쓰는 경우가 많습니다. / 다만 오래된 제품이라 부품을 구하기 어렵거나 센서와 회로가 함께 상했다면 교체를 생각해 볼 때입니다.
교체를 하신다면 지문 외에 번호와 카드를 함께 쓸 수 있는 제품을 권합니다. / 고르는 방법은 [도어락 교체](doorlock-replace.html) 페이지를 참고해 주세요.

# 제기동 가까운 동네도 갑니다
제기동과 이웃한 청량리동, 용신동, 전농동은 물론 회기동, 휘경동, 이문동, 답십리동, 장안동까지 동대문구 어디든 출동합니다. / 동대문구 안내는 [동대문구 출장열쇠](seoul-dongdaemun.html), 다른 지역은 [출장 지역](area.html)에 있습니다.

? 손가락을 다쳤는데 어떻게 하죠? | 다른 손가락이나 번호, 카드로 여시고, 낫고 나면 다시 등록해 주세요.
