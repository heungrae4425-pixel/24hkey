# 아침에 바꾼 번호, 저녁에 누가 모르고 있을까
전농동은 청량리역 생활권에 붙어 있어 새 아파트와 오래된 다세대, 골목 주택이 가까이 모여 있는 동네입니다. / 출퇴근 시간이 제각각인 식구가 한집에 사는 경우가 많아 현관 번호 하나에도 사정이 여럿 얽힙니다.
누군가 아침에 번호를 바꿨는데 밤늦게 들어오는 식구가 그 사실을 모르면 문 앞에서 전화를 돌리게 됩니다. / 이 글은 번호를 언제 바꾸고 누가 챙기며 어떻게 알릴지, 집안 규칙으로 정리하는 방법을 적었습니다.
번호 관리가 엉켜 문이 안 열릴 때 [동대문구 출장열쇠](seoul-dongdaemun.html)를 부르는 순서도 뒤에 함께 넣었습니다.
@ 전농동 도어락 비밀번호 가족 공유 관리

# 번호 관리는 한 사람이 맡는 게 편합니다
식구 모두가 아무 때나 번호를 바꿀 수 있으면 언젠가 꼭 엇갈립니다. / 관리자 비밀번호나 등록 버튼을 다룰 사람을 한 명 정해 두면 그런 일이 크게 줄어듭니다.
담당자가 바꾸고, 바꾼 뒤 알리는 것까지 맡는 식입니다. / 다른 식구는 번호를 바꾸고 싶으면 담당자에게 말하기만 하면 됩니다.
담당자가 출장이나 여행으로 집을 비우는 기간에는 대신 맡을 사람을 한 명 더 정해 두세요. / 관리자 번호를 아는 사람이 아무도 집에 없으면 등록 하나 바꾸는 일도 미뤄지기 때문입니다.

# 언제 바꿀지 달력에 박아 두기
주기를 몇 달로 할지는 집마다 달라도, 날짜를 정해 두는 것이 핵심입니다. / 계절이 바뀌는 달 첫 주말처럼 기억하기 쉬운 날로 잡으면 미루지 않게 됩니다.
그날 건전지 상태도 같이 보면 일이 하나로 묶여 편합니다. / 경고음이 나기 전 바꿔 두면 번호를 새로 누르다 전원이 꺼지는 일도 피할 수 있습니다.
정해 둔 날이 아니어도 바꿔야 할 때가 있습니다. / 집을 드나들던 사람이 바뀌었거나 번호를 누르는 모습을 누가 본 것 같다면 날짜를 기다리지 마세요.

# 새벽에 들어오는 식구를 먼저 챙기세요
전농동처럼 역세권 생활을 하는 집은 교대 근무나 늦은 아르바이트로 한밤에 귀가하는 식구가 있곤 합니다. / 번호를 바꾼 날은 그 식구가 집에 들어올 때까지 예전 번호를 잠깐 남겨 두는 것도 방법입니다.
두 개의 번호를 등록할 수 있는 제품이라면 새 번호를 먼저 넣고, 모두 확인한 다음 날 예전 번호를 지우면 됩니다. / 한 개만 되는 제품이라면 바꾸는 시간을 식구가 모두 집에 있는 저녁으로 잡아 주세요.
@ 전농동 다세대 현관 도어락 번호 변경

# 알리는 방법은 말과 글 두 번
바꾼 번호는 가족 대화방에 바로 올리기보다 얼굴 보고 한 번, 확인 문자 한 번으로 나눠 알리는 편이 안전합니다. / 대화방은 휴대폰을 잃어버렸을 때 다른 사람 손에 들어갈 수 있기 때문입니다.
문자에는 번호 자체보다 바꿨다는 사실과 힌트만 적어 두는 집도 있습니다. / 식구끼리만 아는 힌트라면 잊었을 때 떠올리기에도 좋습니다.
알린 뒤에는 각자 문 앞에서 한 번씩 직접 눌러 보게 하세요. / 머리로 아는 것과 손에 익은 것은 다르기 때문입니다.

# 카드와 지문 등록 목록도 함께 정리
번호만 바꾸고 카드나 지문은 그대로 두는 집이 많습니다. / 잃어버린 카드가 아직 등록돼 있다면 번호를 아무리 바꿔도 의미가 반으로 줄어듭니다.
누구에게 카드 몇 장이 있는지, 누가 지문을 등록했는지 종이 한 장에 적어 두세요. / 번호 바꾸는 날 이 목록을 함께 보고 안 쓰는 카드는 지웁니다.
목록 정리 기능이 제품 설명서에 없다면 전체 삭제 후 다시 등록하는 방식일 수 있습니다. / 이럴 때는 식구가 모두 모인 자리에서 한꺼번에 하는 게 좋습니다.

# 공동현관 번호와 집 번호는 따로
새 아파트나 일부 다세대는 건물 입구에도 번호가 있습니다. / 두 번호를 똑같이 맞춰 두면 하나가 알려졌을 때 나머지도 같이 알려지는 셈입니다.
공동현관 번호는 택배나 배달 기사님에게도 쓰이는 번호라는 점을 기억해 주세요. / 집 현관 번호만큼은 그와 다른 숫자로 따로 두는 게 기본입니다.

# 쉽게 맞힐 수 있는 번호는 피하기
생일, 전화번호 뒷자리, 같은 숫자 반복은 누구나 먼저 떠올리는 조합입니다. / 대신 식구끼리만 아는 사건이나 장소에서 숫자를 뽑아 이어 붙이면 기억도 쉽고 남이 맞히기도 어렵습니다.
입력할 때 앞뒤로 아무 숫자나 덧붙여도 열리는 기능이 있다면 써 보세요. / 번호판에 남는 손자국을 흐리는 데 도움이 됩니다.
@ 전농동 도어락 번호판 지문 카드 등록 정리

# 아이와 어르신에게는 따로 한 번 더
초등학생 자녀는 새 번호를 들어도 며칠은 예전 번호를 손이 먼저 누릅니다. / 바꾼 첫 주에는 하교 시간에 맞춰 한 번 같이 눌러 보는 것만으로 실수가 크게 줄어듭니다.
연세 드신 식구에게는 숫자를 종이에 크게 적어 드리고 싶어지지만, 그 종이가 지갑이나 현관 근처에 남는 건 피하는 게 좋습니다. / 대신 기억하기 쉬운 이야기로 묶어 말씀드리고, 카드 한 장을 함께 쥐여 드리면 번호가 떠오르지 않는 날에도 들어가실 수 있습니다.

# 바꾸다가 문 앞에서 막혔다면
등록 버튼을 누르는 순서를 놓쳐 번호가 저장되지 않은 채 문을 닫는 일이 종종 있습니다. / 이럴 땐 번호를 여러 번 눌러 보지 마시고 서너 번에서 멈춰 주세요.
안에 식구가 있다면 안쪽에서 열어 달라고 한 뒤 다시 등록하면 됩니다. / 아무도 없고 카드나 지문도 안 되면 그때 연락 주시면 됩니다.

# 출장 때는 사시는 분인지 확인합니다
도착하면 문을 열기 전에 그 집에 사시는 분인지 먼저 확인합니다. / 주소가 적힌 신분증이나 우편물, 관리사무소 확인 중 하나면 충분합니다.
문을 어떻게 여는지, 얼마인지는 손대기 전에 먼저 말씀드리고 괜찮다고 하실 때 시작합니다. / 끝내 열지 못하면 비용은 받지 않으며, 진행 순서는 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 적어 두었습니다.

# 문이 열린 뒤 다시 정리하기
열고 나면 새 번호 등록과 예전 번호 삭제를 식구와 함께 마무리합니다. / 등록 방법이 헷갈리는 제품이면 순서를 직접 보여 드립니다.
등록이 자꾸 실패하거나 버튼이 먹통이면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 기능이 부족해 번호 관리가 계속 불편하다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 전농동 말고 동대문구 다른 동네도
전농동과 가까운 답십리동, 청량리동, 제기동, 용신동은 물론 회기동, 휘경동, 이문동, 장안동까지 다닙니다. / 동대문구 안이면 시간과 상관없이 출동합니다.
다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
