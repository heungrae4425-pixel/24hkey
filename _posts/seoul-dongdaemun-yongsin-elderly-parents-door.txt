# 부모님이 문 앞에서 머뭇거리신다면
용신동은 오래된 다세대와 상가 건물, 재개발로 새로 올라간 아파트가 가까이 붙어 있는 동네입니다. / 한곳에 오래 사신 부모님 댁은 처음 달았던 도어락을 손보지 않고 그대로 쓰시는 경우가 많습니다.
번호를 누르시다 손이 멈추거나, 삑 소리를 못 들으셔서 문이 열렸는지 다시 당겨 보시는 모습을 보셨다면 설정을 바꿀 때가 된 것입니다. / 이 글은 새 도어락을 사기 전에 지금 제품에서 바꿔 드릴 수 있는 설정부터 하나씩 적었습니다.
설정만으로 부족할 때 [동대문구 출장열쇠](seoul-dongdaemun.html)에 점검을 맡기는 방법도 끝에 정리했습니다.
@ 용신동 부모님 댁 도어락 점검 설정

# 먼저 함께 한 번 열고 닫아 보기
설정을 만지기 전에 부모님이 평소처럼 문을 여닫는 모습을 옆에서 지켜봐 주세요. / 어디서 멈칫하시는지가 바꿀 설정을 알려 줍니다.
- 번호판을 깨우는 데 오래 걸리시는지
- 숫자를 누르는 순서를 헷갈리시는지
- 열림 소리를 듣지 못하고 다시 손잡이를 당기시는지
- 안에서 나갈 때 잠금 버튼을 잘못 누르시는지
이 네 가지만 봐도 무엇부터 손볼지 대부분 정해집니다. / 부모님께는 시험한다는 느낌보다 같이 확인해 보자는 말투가 편하십니다.

# 소리 크기는 대부분 올릴 수 있습니다
많은 도어락은 버튼음과 열림음 크기를 몇 단계로 바꿀 수 있습니다. / 기본값이 작게 맞춰진 제품이라면 한두 단계만 올려도 문이 열렸는지 훨씬 잘 아십니다.
설명서가 없으면 제품 안쪽 몸체 덮개 안에 설정 버튼과 짧은 안내가 붙어 있는 경우가 있습니다. / 모델명을 알려 주시면 어떤 버튼을 누르는지 전화로도 안내해 드릴 수 있습니다.
다세대 계단처럼 소리가 울리는 곳이라면 이웃에게 크게 들릴 수 있어 중간 정도가 알맞습니다. / 너무 작으면 부모님이, 너무 크면 이웃이 불편하니 함께 들어 보며 맞추세요.

# 번호 자릿수는 너무 짧지도 길지도 않게
번호를 잊으실까 봐 네 자리로 줄이고 싶어지지만, 짧은 번호는 남이 맞히기도 쉽습니다. / 부모님께 의미 있는 숫자 두 개를 이어 붙여 여섯 자리 안팎으로 정하면 기억도 쉽고 안전합니다.
번호를 바꾼 첫 주에는 자녀분이 전화로 한 번씩 여쭤봐 드리세요. / 손에 익을 때까지만 챙겨 드리면 그다음부터는 걱정이 줄어듭니다.
@ 용신동 도어락 번호판 소리 설정 어르신

# 안쪽 잠금 버튼이 오히려 문제일 때
일부 도어락은 안쪽에서 버튼을 누르면 밖에서 번호를 눌러도 열리지 않는 이중 잠금이 걸립니다. / 부모님이 밤에 안전하라고 눌러 두셨다가 그 사실을 잊고 외출하시면 자녀가 와도 문을 못 엽니다.
이 기능을 쓰실지, 끄실지는 부모님 생활에 맞춰 정해 주세요. / 혼자 계시는 시간이 길다면 가족이 밖에서 열 수 있도록 끄는 쪽을 권하는 경우가 많습니다.

# 자동 잠김이 너무 빠르진 않나요
문이 닫히자마자 잠기는 설정은 편하지만, 장바구니를 든 채 잠깐 복도에 나가셨다가 갇히시는 일로 이어지기도 합니다. / 쓰레기를 버리러 나가실 때 휴대폰을 두고 나가시는 분이라면 더 그렇습니다.
제품에 따라 자동 잠김을 끄거나 몇 초 늦출 수 있습니다. / 어느 쪽이 나을지는 부모님이 문단속을 직접 챙기시는 편인지에 따라 정해 드리면 됩니다.
자동 잠김을 끄셨다면 외출하실 때 잠금 버튼을 누르는 습관을 함께 들여 드려야 합니다. / 문 안쪽에 작은 안내 스티커를 붙여 두면 깜빡하시는 일이 줄어듭니다.

# 지문과 카드는 보조로 생각하세요
연세가 드시면 지문이 얕아져 인식이 잘 안 되는 일이 생깁니다. / 지문을 등록하신다면 손가락을 두세 개 넣어 두시고, 번호는 늘 함께 기억하시게 해 주세요.
카드나 태그는 번호를 잊으셨을 때 든든한 대안이 됩니다. / 지갑보다는 목걸이 줄이나 열쇠고리에 달아 드리면 찾기 쉬우십니다.

# 건전지는 자녀가 날짜를 챙기기
부모님은 경고음을 들어도 다음에 바꾸지 하고 넘기시는 일이 많습니다. / 명절이나 생신처럼 정해진 방문 날에 자녀분이 건전지를 갈아 드리면 깜빡할 일이 없습니다.
건전지 칸 안쪽에 교체한 날짜를 적어 두면 다음 방문 때 바로 알 수 있습니다. / 바깥쪽 비상 단자 위치도 부모님께 한 번 손으로 짚어 알려 드리세요.
@ 용신동 부모님 집 도어락 건전지 교체 날짜

# 안에서 나가는 손잡이는 쉬워야 합니다
불이 났거나 급하게 나가셔야 할 때 안쪽 손잡이가 뻑뻑하면 큰일이 됩니다. / 밀거나 당기는 힘이 많이 들거나 돌리는 방향이 헷갈리는 제품이라면 점검이 필요합니다.
걸쇠나 보조 잠금이 여러 개 달려 있다면 꼭 필요한 것만 남겨 두는 편이 낫습니다. / 잠금이 많을수록 급할 때 풀어야 할 것도 늘어납니다.

# 상가 위층 다세대라면 현관 앞 밝기도
용신동처럼 상가 건물 위층에 집이 있는 경우, 계단과 현관 앞이 어두운 곳이 있습니다. / 번호판에 불이 들어와도 손끝이 잘 안 보이면 누르는 순서를 헷갈리시기 쉽습니다.
센서등이 있다면 켜지는 시간이 너무 짧지 않은지 확인해 주세요. / 건물 관리 쪽에 이야기할 수 있는 부분이면 함께 부탁해 두시면 좋습니다.

# 부모님이 문 앞에서 전화하셨다면
부모님이 문이 안 열린다고 연락하시면 먼저 번호판에 불이 들어오는지만 여쭤보세요. / 불이 안 들어오면 건전지, 들어오는데 안 열리면 번호나 안쪽 잠금 버튼을 의심해 볼 수 있습니다.
멀리 계셔서 바로 가기 어렵다면 부모님 댁 주소와 상황을 알려 주시고 저희를 불러 주세요. / 현장에서는 부모님 본인의 신분증이나 우편물로 거주를 확인한 뒤 진행합니다.
문을 여는 과정은 [현관문 개문](door-open.html)에 적어 두었고, 덜 상하는 방법부터 차례로 씁니다. / 기다리시는 동안 부모님께 이웃집이나 경비실처럼 따뜻한 곳에 계시라고 전해 주세요.

# 점검을 맡기실 때의 순서와 비용
도착하면 도어락 상태와 문틀, 손잡이, 건전지를 함께 봅니다. / 설정으로 해결되는 부분은 그 자리에서 바꿔 드리고, 부품을 손봐야 하면 [도어락 수리](doorlock-repair.html) 범위를 먼저 설명드립니다.
제품이 너무 오래돼 설정 기능이 없다면 [도어락 교체](doorlock-replace.html)를 의논하되, 결정은 가족과 상의하신 뒤 하셔도 됩니다. / 어떤 작업이든 금액은 시작 전에 먼저 말씀드리고, 문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 용신동 말고 동대문구 다른 동네도
용신동과 가까운 제기동, 청량리동, 전농동, 답십리동은 물론 장안동, 회기동, 휘경동, 이문동까지 다닙니다. / 부모님 댁이 다른 구나 경기라면 [출장 지역](area.html)에서 확인해 보세요.
