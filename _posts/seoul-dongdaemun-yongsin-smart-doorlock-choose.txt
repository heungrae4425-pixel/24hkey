# 용신동에서 도어락을 새로 고를 때
용신동은 오래된 다세대와 상가 건물, 재개발로 새로 올라간 아파트가 가까이 붙어 있는 동네입니다. / 같은 동네 안에서도 현관문 두께와 모양이 집마다 크게 달라 도어락을 고를 때 따져 볼 게 많습니다.
매장이나 인터넷에서 보면 지문, 카드, 얼굴, 앱 연동까지 기능이 끝도 없이 늘어서 있습니다. / 그런데 막상 달고 나면 쓰는 기능은 한두 가지뿐이고, 정작 문에 안 맞아 고생하는 경우도 있습니다.
이 글은 용신동에서 스마트 도어락을 고를 때 기능보다 먼저 볼 것과, 여는 방식별로 어떤 집에 맞는지를 정리했습니다. / 설치나 교체가 필요하면 [동대문 출장열쇠](seoul-dongdaemun.html)로 문의 주셔도 됩니다.
@ 용신동 스마트 도어락 고르는 기준

# 기능보다 먼저 우리 집 문부터
도어락은 문에 맞아야 달 수 있습니다. / 제품을 고르기 전에 아래 네 가지를 먼저 확인해 두면 선택지가 확 줄어들어 오히려 고르기 쉬워집니다.
- 문 두께: 얇은 철문인지, 두꺼운 방화문인지
- 기존 구멍: 예전 도어락이나 보조키를 뗀 자리가 어디에 있는지
- 손잡이 형태: 손잡이 일체형을 원하는지, 버튼형이나 밀고 당기는 형을 원하는지
- 문 여는 방향: 바깥으로 밀어 여는지, 안으로 당겨 여는지
다세대 철문은 두께가 얇고 예전 구멍이 여러 개 남아 있는 경우가 많습니다. / 이런 문은 기존 구멍을 덮어 주는 크기의 제품이 깔끔하게 마무리됩니다.

# 번호 방식은 기본 중의 기본
어떤 스마트 도어락이든 번호 입력은 거의 다 들어 있습니다. / 다른 방식이 안 될 때 마지막으로 기대는 수단이라 번호판 품질을 꼭 보셔야 합니다.
터치식은 매끈하고 청소가 쉽지만 손가락이 차거나 젖으면 반응이 늦을 수 있습니다. / 버튼식은 누르는 감이 확실해 어르신이 쓰시기 편한 편입니다.
번호를 앞뒤로 덧붙여 눌러도 열리는 허수 입력 기능이 있는지도 확인해 보세요. / 번호판에 남는 손자국 걱정을 많이 덜 수 있습니다.

# 지문 방식이 잘 맞는 집
손에 짐을 자주 들고 다니거나 번호를 외우기 귀찮아하는 식구가 있다면 지문이 편합니다. / 손가락 하나 대면 열리니 아이들도 금방 익숙해집니다.
다만 손에 상처가 잦거나 손끝이 많이 건조한 분, 어르신 가운데는 지문이 잘 안 읽히는 경우가 있습니다. / 식구 모두 손가락을 대 볼 수 있는 매장에서 미리 시험해 보시면 좋습니다.
지문은 한 사람이 손가락 두세 개를 등록해 두는 게 안전합니다. / 한 손가락을 다쳐도 다른 손가락으로 열 수 있습니다.
@ 용신동 지문 인식 도어락 등록

# 카드와 태그가 편한 경우
번호도 지문도 어려운 어르신이나 어린 자녀에게는 카드나 동그란 태그가 쉽습니다. / 가방이나 목걸이에 달아 두고 번호판에 대기만 하면 됩니다.
대신 잃어버리면 주운 사람도 쓸 수 있다는 점을 기억하셔야 합니다. / 잃어버렸을 때 그 카드만 지울 수 있는 제품인지 꼭 확인하세요.
여분 카드를 몇 장까지 등록할 수 있는지도 보시면 좋습니다. / 식구 수보다 한두 장 넉넉해야 나중에 편합니다.

# 앱과 블루투스 연동은 이렇게 따져 보세요
휴대폰으로 문을 열고 누가 언제 드나들었는지 알림을 받는 기능은 편리합니다. / 맞벌이로 아이 귀가를 확인하고 싶은 집이나 혼자 사는 분에게 쓸모가 있습니다.
하지만 앱 기능은 휴대폰, 집 공유기, 제조사 서버가 모두 잘 돌아가야 제대로 작동합니다. / 하나라도 문제가 생기면 결국 번호나 지문으로 열어야 하니 앱만 믿고 다른 수단을 소홀히 하지 마세요.
건전지 소모가 일반 제품보다 빠른 편이라는 점도 알아 두시면 좋습니다.
앱을 쓰신다면 가족 가운데 누가 관리자 계정을 갖고 있을지 미리 정해 두세요. / 관리자 휴대폰을 바꾸거나 잃어버렸을 때 다시 연결하는 방법도 처음 설정할 때 함께 확인해 두면 나중에 당황하지 않습니다.

# 얼굴 인식 같은 새 방식은
최근에는 얼굴이나 손바닥 정맥을 읽는 제품도 나옵니다. / 손을 쓰지 않아도 돼서 편하지만 아직은 가격대와 크기, 건전지 소모를 함께 따져 봐야 합니다.
현관 조명이 어둡거나 역광이 드는 문이라면 인식이 들쭉날쭉할 수 있습니다. / 새 방식을 고르시더라도 번호와 카드 같은 기본 수단은 꼭 함께 쓰실 수 있는 제품으로 고르세요.

# 식구 구성에 맞춰 조합하기
결국 좋은 도어락은 우리 집 식구가 모두 불편 없이 쓰는 도어락입니다. / 아래처럼 생각해 보시면 방향이 잡힙니다.
- 혼자 사는 집: 번호와 지문, 필요하면 앱 알림
- 어린 자녀가 있는 집: 지문이나 태그에 귀가 알림
- 어르신이 계신 집: 버튼식 번호와 카드, 큰 글씨 번호판
- 드나드는 사람이 많은 집: 사용자별로 등록과 삭제가 쉬운 제품
기능이 많을수록 설정 메뉴도 복잡해지니, 실제로 쓸 기능 위주로 고르는 게 현명합니다.

# 다세대 오래된 문이라면 꼭 볼 것
문이 처지거나 문틀이 틀어진 상태에서 새 도어락을 달면 비싼 제품도 금방 말썽을 부립니다. / 걸쇠가 문틀 홈에 제대로 안 맞으면 모터에 무리가 가기 때문입니다.
그래서 오래된 문이라면 제품을 고르기 전에 문이 매끄럽게 닫히는지부터 보셔야 합니다. / 필요하면 경첩과 문틀을 먼저 손보고 도어락을 다는 순서가 맞습니다.
@ 동대문 출장열쇠 용신동 다세대 현관 도어락 설치

# 전원과 비상 수단 확인
어떤 제품이든 건전지로 움직입니다. / 건전지 칸이 열기 쉬운지, 바깥에 9V 비상 단자가 있는지, 비상 열쇠 구멍이 있는지 확인해 두세요.
건전지가 다 될 때 미리 알려 주는 경고음이 분명한 제품이 좋습니다. / 소리가 너무 작으면 놓치기 쉽습니다.
건전지 칸이 몸체 아래쪽에 있어 허리를 숙여야 하는 제품도 있고, 덮개를 밀어 위에서 바로 여는 제품도 있습니다. / 어르신이 직접 가실 집이라면 이런 작은 차이도 따져 볼 만합니다.

# 설치를 맡기실 때와 비용 안내
설치를 맡기시면 먼저 문 두께와 기존 구멍을 재고, 고르신 제품이 맞는지 봅니다. / 비용은 제품과 문 상태를 확인한 뒤 작업 전에 먼저 말씀드립니다.
제품을 이미 사 두셨다면 상자 그대로 두고 연락 주세요. / 문에 맞지 않으면 달기 전에 말씀드립니다. 자세한 내용은 [도어락 설치](doorlock-install.html), [도어락 교체](doorlock-replace.html), [이용안내](guide.html)에 있습니다.

# 용신동 말고 동대문구 다른 동네도
용신동과 가까운 제기동, 청량리동, 전농동, 답십리동은 물론 장안동, 휘경동, 회기동, 이문동까지 출동합니다. / 동대문구 안내는 [동대문구 출장열쇠](seoul-dongdaemun.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
