# 주말에 부모님 댁 현관을 다시 보게 될 때
부모님 댁에 들렀다가 어머니가 번호판 앞에서 한참 손가락을 멈추고 계신 모습을 보면 마음이 쓰입니다. / 아버지가 경고음이 며칠째 울렸는데 그냥 두셨다는 이야기를 들으면 더 그렇습니다.
동작구 대방동에도 부모님만 따로 지내시는 댁이 적지 않습니다. / 자녀가 가끔 들르는 날 현관을 한 번 같이 살펴 두면 평소에 문 앞에서 막히는 일을 많이 줄일 수 있습니다.
이 글은 부모님 댁에 갔을 때 도어락에서 무엇을 보면 좋은지, 어르신이 쓰기 편하게 어떤 설정을 바꾸면 좋은지 정리했습니다.
@ 대방동 부모님 댁 도어락 점검

# 들른 김에 10분 점검 목록
아래 순서대로 보면 10분 정도면 충분합니다. / 부모님과 함께 하나씩 해 보시면 사용법도 자연스럽게 다시 익히게 됩니다.
- 번호판 불이 밝게 켜지는지, 반응이 느리지 않은지
- 배터리를 언제 바꿨는지, 경고음이 난 적 있는지
- 문을 닫았을 때 한 번에 잠기는지
- 안쪽 손잡이와 잠금 버튼이 어렵지 않은지
- 비상 단자 위치를 부모님이 알고 계신지
하나라도 애매하면 그날 바로 손보는 게 좋습니다. / 다음 방문까지 미루면 그사이에 문제가 생기기 쉽습니다.

# 배터리는 자녀가 직접 갈아 드리세요
어르신 댁 도어락 문제는 배터리가 다 된 경우가 가장 많습니다. / 경고음이 나도 무슨 소리인지 모르시거나, 덮개를 여는 방법이 어려워 그냥 두시는 경우가 많습니다.
방문할 때마다 날짜를 확인하고, 해가 바뀔 즈음 한 번에 전부 새것으로 바꿔 드리세요. / 배터리 칸 안쪽에 바꾼 날짜를 적어 두면 다음에 오는 가족도 알 수 있습니다.
여분 배터리는 현관 가까운 서랍에 한 묶음 두고 위치를 알려 드리면 좋습니다.
바깥 비상 단자에 대는 9V 건전지도 하나 같이 두면 좋습니다. / 장바구니나 자주 드시는 가방 안쪽 주머니에 넣어 드리면 번호판이 꺼진 날에도 바로 쓰실 수 있습니다.

# 번호는 부모님이 기억하기 쉬운 것으로
너무 복잡한 번호는 오히려 문 앞에서 막히는 원인이 됩니다. / 그렇다고 생일이나 전화번호 뒷자리처럼 남이 짐작하기 쉬운 번호는 피하세요.
부모님께 의미 있는 숫자를 조합하되, 바깥사람은 떠올리기 어려운 것으로 함께 정하는 게 좋습니다. / 번호를 바꿨다면 자녀 중 한 사람은 꼭 알고 있어야 합니다.
번호판 숫자가 잘 안 보이신다면 글자가 크고 밝은 제품으로 바꾸는 것도 생각해 볼 만합니다.
@ 대방동 어르신 도어락 번호 설정

# 카드나 태그가 더 편한 분도 계십니다
번호를 자주 잊으시거나 손가락이 불편하신 분께는 카드나 태그가 가장 쉽습니다. / 열쇠고리에 달아 드리면 지갑을 찾지 않아도 됩니다.
카드를 잃어버리실 때를 대비해 등록 카드 개수를 메모해 두세요. / 잃어버렸다면 자녀가 방문해 등록을 지우고 새 카드를 넣어 드리면 됩니다.
지문은 연세가 드실수록 지문이 옅어져 인식이 잘 안 될 수 있습니다. / 지문을 쓰신다면 여러 손가락을 등록하고 번호나 카드도 꼭 함께 쓰게 해 드리세요.

# 소리 크기와 자동 잠김 설정
경고음이 너무 작으면 배터리 알림을 못 들으십니다. / 반대로 너무 크면 놀라시니 적당한 크기로 맞춰 드리세요.
자동 잠김은 문단속을 잊지 않게 해 주지만, 잠깐 나가실 때 갇히는 일이 생길 수 있습니다. / 쓰레기를 버리러 자주 나가시는 분이라면 번호나 카드를 꼭 들고 다니시게 하거나 수동 잠금으로 바꾸는 것도 방법입니다.
설정 방법은 제품마다 달라서 설명서를 보며 함께 해 보시는 게 좋습니다. / 바꾼 설정은 작은 종이에 적어 배터리 덮개 안쪽에 붙여 두시면 다음에 다시 찾기 쉽습니다.

# 안쪽 손잡이와 보조키도 살펴보세요
급할 때 안에서 문을 열기 어려우면 위험할 수 있습니다. / 안쪽 손잡이가 뻑뻑하거나 잠금 버튼이 작아 누르기 힘든지 직접 해 보세요.
보조키나 걸쇠를 잠그고 주무시는 습관이 있다면 바깥에서 가족이 열기 어렵습니다. / 그 점을 부모님과 미리 이야기해 두면 좋습니다.
현관 바닥에 신발이나 물건이 많으면 문을 열고 닫을 때 걸려 넘어지시기 쉽습니다. / 도어락 점검하는 김에 문 앞 정리도 함께 해 드리면 좋습니다.

# 자녀가 멀리 있을 때 정해 둘 것
가까이 사는 친척이나 이웃 한 분에게 연락처를 알려 두세요. / 문이 안 열린다고 연락이 오면 그분이 먼저 가 볼 수 있습니다.
출장열쇠 번호를 부모님 휴대폰에 저장해 드리는 것도 도움이 됩니다. / 신분증을 현관 가까운 곳에 두시게 하면 확인 절차도 빨라집니다.
부모님이 혼자 계실 때 낯선 사람이 문을 열어 주겠다고 찾아오면 꼭 자녀에게 먼저 전화하시도록 말씀드려 두세요. / 부르지 않은 방문은 일단 문을 열지 않는 것이 안전합니다.

# 대방동에서 점검을 맡기실 때
- 부모님 댁 주소와 층, 공동현관 출입 방법
- 도어락 앞뒤 사진과 대략 쓴 기간
- 불편해하시는 점(번호, 소리, 손잡이 등)
- 방문 가능한 날과 부모님이 계신 시간
자녀가 대신 연락하셔도 됩니다. / 점검하는 날에는 부모님이 직접 써 보시면서 설명을 들으실 수 있게 시간을 맞춥니다.

# 사시는 분 확인은 꼭 거칩니다
문을 여는 일이 생기면 부모님이 사시는 분인지 신분증이나 주소가 적힌 우편물, 관리사무소 확인으로 먼저 봅니다. / 자녀만 계신 경우에는 부모님과 통화로 확인하거나 관련 서류를 함께 봅니다.
번거로우셔도 어르신 댁을 지키는 절차입니다. / 부모님이 놀라지 않으시도록 도착 전에 자녀가 미리 전화로 알려 드리면 좋습니다.

# 비용은 점검 전에 말씀드립니다
배터리 교체와 설정 정리로 끝나는지, 부품이나 제품을 바꿔야 하는지 확인한 뒤 비용을 먼저 알려 드립니다. / 부모님과 자녀가 함께 들으시고 결정하시면 됩니다.
문을 열어야 하는 상황에서 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 정리했습니다.
@ 동작 출장열쇠 대방동 어르신 댁 도어락 교체 상담

# 바꿀지 고칠지 고르는 기준
지금 쓰시는 도어락이 익숙하시다면 고쳐서 계속 쓰시는 편이 낫습니다. / 손잡이나 배터리 칸처럼 일부만 문제라면 [도어락 수리](doorlock-repair.html)로 해결합니다.
번호판이 너무 작거나 지문만 되는 제품이라 불편하시다면 [도어락 교체](doorlock-replace.html)로 카드와 큰 번호판이 있는 제품을 권해 드립니다. / 문이 잠겨 급한 상황이라면 [현관문 개문](door-open.html)을 먼저 보세요.

# 대방동 말고 동작구 전 지역
대방동과 가까운 노량진동, 신대방동, 상도동, 흑석동, 사당동 부모님 댁도 다닙니다. / 동작구 동네는 [동작구 출장열쇠](seoul-dongjak.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
