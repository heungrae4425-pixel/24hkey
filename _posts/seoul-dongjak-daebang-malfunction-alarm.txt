# 소리는 요란한데 문은 꿈쩍하지 않을 때
번호를 눌렀더니 평소와 다른 멜로디가 나오거나, 윙 하는 모터 소리만 길게 나고 문이 그대로인 날이 있습니다. / 노량진동과 맞닿은 대방동은 아파트와 빌라, 원룸 건물이 섞여 있어 도어락 종류도 집마다 제각각입니다.
제품은 달라도 도어락이 내는 소리에는 대체로 공통된 뜻이 있습니다. / 이 글은 대방동에서 도어락이 이상한 소리를 낼 때 소리의 종류로 원인을 나눠 보고, 집에서 해 볼 수 있는 일과 [동작구 출장열쇠](seoul-dongjak.html)를 부를 때를 정리했습니다.
@ 대방동 도어락 경고음 모터 소리 점검

# 먼저 휴대폰으로 소리를 녹음해 두세요
도어락 소리는 한 번 지나가면 정확히 설명하기 어렵습니다. / 번호를 누를 때 휴대폰 녹음이나 동영상을 켜 두면 나중에 상황을 전하기가 훨씬 쉽습니다.
영상에는 번호판 불빛과 문 옆면 잠금쇠 움직임이 함께 담기면 좋습니다. / 이것만 있어도 배터리 문제인지 기계 문제인지 많이 좁혀집니다.
소리가 나는 때가 언제인지도 같이 기억해 두세요. / 번호를 누를 때만인지, 문을 닫을 때인지, 아무것도 안 했을 때인지에 따라 살펴볼 곳이 완전히 달라집니다.
아침과 저녁에 소리가 다르게 난다면 그 차이도 함께 알려 주시면 좋습니다.

# 짧은 삐 소리가 여러 번 이어질 때
번호를 누른 뒤 삐삐삐 하고 짧게 여러 번 울리면 입력이 틀렸다는 뜻인 경우가 많습니다. / 번호판을 덮은 뒤 너무 빨리 누르거나 숫자 하나가 덜 눌린 것일 수 있습니다.
천천히 다시 눌러도 같은 소리가 나면 번호가 바뀌었을 가능성도 생각해 보세요. / 함께 사는 가족이 최근 번호를 바꾸지 않았는지 먼저 물어보는 것이 빠릅니다.
여러 번 틀리면 일정 시간 입력이 막히는 제품이 많습니다. / 막힌 동안 계속 누르면 막히는 시간이 늘어날 수 있으니 잠시 기다려 주세요.

# 띠리리 멜로디가 반복되면 배터리 신호
번호를 누를 때마다 평소에 없던 멜로디나 긴 알림음이 붙는다면 배터리 교체 알림인 경우가 대부분입니다. / 이 소리가 들리기 시작해도 며칠은 열리지만 언제 멈출지 모릅니다.
알림이 처음 들린 날 안쪽 배터리를 전부 새것으로 바꿔 주세요. / 일부만 바꾸면 알림이 금방 다시 울립니다.

# 윙 소리만 나고 잠금쇠가 안 움직일 때
모터는 도는데 잠금쇠가 빠지지 않는 경우는 두 가지를 의심합니다. / 하나는 배터리가 약해 끝까지 당기지 못하는 것, 다른 하나는 잠금쇠가 문틀에 눌려 꼼짝하지 않는 것입니다.
문을 안쪽으로 살짝 밀면서 번호를 다시 눌러 보세요. / 이렇게 해서 열린다면 문틀과 잠금쇠가 어긋난 것이어서 나중에 점검이 필요합니다.
모터 소리가 점점 짧아지거나 툭툭 끊긴다면 안쪽 기어가 닳았을 수 있습니다. / 이 경우는 같은 동작을 반복할수록 상태가 나빠지니 몇 번 해 보고 멈추는 게 좋습니다.
@ 대방동 도어락 모터 헛돎 잠금쇠 확인

# 딸깍 소리 뒤 아무 반응이 없을 때
번호가 맞다는 소리는 나는데 손잡이를 돌려도 문이 안 열린다면 손잡이와 잠금쇠를 잇는 부품을 의심합니다. / 손잡이가 평소보다 가볍게 헛돌면 이 경우일 가능성이 큽니다.
밀고 당기는 방식 도어락이라면 손잡이를 끝까지 밀거나 당겼는지 다시 해 보세요. / 반쯤만 움직이면 잠금이 풀린 상태여도 문이 열리지 않습니다.

# 아무도 안 만졌는데 혼자 울릴 때
밤중에 도어락이 혼자 길게 울리면 놀라게 됩니다. / 이럴 때 가장 흔한 원인은 문이 덜 닫혀 문 열림 경고가 울리는 것입니다.
문을 한 번 활짝 열었다가 끝까지 닫아 보세요. / 그래도 울리면 번호판에 물기나 먼지가 끼어 혼자 눌린 것으로 인식했을 수 있어 마른 천으로 닦아 봅니다.
일부 제품은 바깥에서 억지로 열려는 충격이나 높은 온도를 감지하면 경보를 냅니다. / 이런 경보가 났다면 문 바깥에 이상한 흔적이 없는지도 한번 살펴보시는 게 좋습니다.

# 집에서 해 볼 수 있는 순서
- 녹음 켜고 번호를 천천히 한 번 더 누르기
- 문을 안쪽으로 살짝 밀며 다시 시도하기
- 집 안에 있다면 안쪽 배터리 전부 새것으로 바꾸기
- 번호판 표면 물기와 먼지 닦기
위 순서로도 그대로라면 더 손대지 말고 연락 주세요. / 같은 시도를 오래 반복하는 것보다 그 편이 고치는 범위가 작습니다.
반대로 아래 행동은 상태를 더 나쁘게 만들 수 있습니다.
소리가 시끄럽다고 바깥 번호판을 손으로 세게 누르거나 두드리지 마세요. / 번호판 아래 회로가 눌려 진짜 고장으로 이어질 수 있습니다.
안쪽 몸체를 열어 선을 뽑아 보는 것도 권하지 않습니다. / 다시 꽂을 때 방향이 바뀌면 문이 열린 채 잠기지 않는 일이 생깁니다.
배터리를 뺐다 넣었다 여러 번 하는 것도 피해 주세요. / 일부 제품은 설정이 지워져 번호를 처음부터 다시 등록해야 합니다.

# 대방동에서 연락하실 때 알려 주실 것
- 대방동 위치와 아파트, 빌라, 원룸 중 어떤 건물인지
- 들리는 소리와 그때 번호판 불빛 상태
- 지금 문 안인지 밖인지
- 녹음이나 영상이 있다면 문자로 전송
소리 녹음을 미리 들으면 어떤 부품을 챙겨야 할지 알 수 있어 한 번에 끝내기 좋습니다.

# 문을 여는 경우 거주 확인
밖에서 막혀 문을 열어야 한다면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 가운데 하나면 됩니다.
원룸 건물은 건물 관리인 확인으로도 가능합니다. / 확인이 끝나야 작업을 시작할 수 있으니 미리 떠올려 두세요.

# 점검 전에 금액부터 알려 드립니다
소리와 증상을 확인한 뒤 수리 범위와 비용을 먼저 말씀드립니다. / 배터리나 청소만으로 끝나는 경우도 있고, 부품을 바꿔야 하는 경우도 있습니다.
문을 열어야 하는 상황에서 끝내 열지 못하면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 동작 출장열쇠 대방동 도어락 수리 점검

# 고칠지 바꿀지 가르는 기준
모터와 기어만 지쳐 있고 번호판과 회로가 멀쩡하면 [도어락 수리](doorlock-repair.html)로 다시 쓰는 경우가 많습니다. / 경고음이 여러 종류로 섞여 나고 설정까지 자주 지워진다면 회로 쪽이 약해진 것일 수 있습니다.
부품을 구하기 어려운 오래된 제품이라면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 바꿀지 말지는 설명을 들으신 뒤에 정하시면 됩니다.

# 대방동 이웃 동네도 갑니다
노량진동, 신대방동, 상도동, 흑석동, 사당동까지 동작구 어디든 24시간 출동합니다. / 동작구 안내는 [동작구 출장열쇠](seoul-dongjak.html), 그 밖의 지역은 [출장 지역](area.html)에 있습니다.
