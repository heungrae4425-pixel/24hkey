# 문을 닫으려는데 쇠막대가 툭 튀어나와 있다
현관문을 열어 둔 채 정리하다 보면 옆면의 네모난 쇠막대가 나온 채로 들어가지 않는 경우가 있습니다. / 반대로 문이 닫힌 채 막대가 문틀 안에 박혀 바깥에서 아무리 번호를 눌러도 빠지지 않는 경우도 있습니다.
이 막대를 데드볼트라고 부릅니다. / 흑석역 주변 아파트든 흑석동 골목 다세대든, 도어락이나 보조키가 달린 문이라면 어느 집에서나 생길 수 있는 증상입니다.
이 글은 흑석동에서 데드볼트가 멈췄을 때 지금 내가 문 안에 있는지 밖에 있는지에 따라 무엇을 해 보면 좋은지, 언제 [동작구 출장열쇠](seoul-dongjak.html)를 부르면 되는지 적었습니다.
@ 흑석동 현관문 데드볼트 멈춤 점검

# 손잡이 걸쇠와 데드볼트는 다른 부품
문 옆면을 보면 비스듬히 깎인 걸쇠와 네모난 막대가 따로 있는 경우가 많습니다. / 비스듬한 걸쇠는 문을 닫으면 저절로 들어갔다 나오고, 네모난 막대는 도어락이나 열쇠가 움직여야만 나오고 들어갑니다.
그래서 데드볼트가 멈추면 손잡이를 아무리 돌려도 문이 열리지 않습니다. / 증상을 말씀하실 때 어느 쪽 부품이 멈췄는지만 알려 주셔도 원인이 훨씬 좁혀집니다.

# 내가 문 안쪽에 있다면
집 안에서 나가려는데 막대가 안 빠지는 상황이라면 안쪽 손잡이나 엄지 돌리개를 천천히 끝까지 돌려 보세요. / 중간에서 걸리면 문을 몸 쪽으로 살짝 당기거나 바깥쪽으로 살짝 밀면서 다시 돌립니다.
문이 문틀 한쪽으로 쏠려 있으면 막대가 받이 구멍 벽에 눌려 꼼짝하지 않습니다. / 누르는 힘이 풀리는 방향을 찾으면 생각보다 쉽게 움직입니다.
도어락이라면 안쪽 열림 버튼을 누른 뒤 모터가 도는 소리가 나는지 들어 보세요. / 소리는 나는데 막대가 안 움직이면 위와 같이 문을 살짝 밀거나 당기면서 한 번 더 눌러 봅니다.

# 내가 문 바깥에 있다면
바깥에서는 할 수 있는 일이 많지 않습니다. / 번호를 누르면서 다른 손으로 문을 안쪽으로 살짝 밀어 보는 정도가 안전한 시도입니다.
모터 소리가 한 번 크게 나고 멈춘다면 막대가 걸려 있다는 신호입니다. / 같은 동작을 여러 번 되풀이하면 모터가 지치고 배터리도 빨리 닳습니다.
열쇠로 여는 보조키라면 열쇠를 끝까지 꽂고 문을 살짝 민 채로 돌려 보세요. / 열쇠를 세게 비틀면 열쇠가 휘거나 부러질 수 있어 두세 번 시도하고 멈추는 게 좋습니다.

# 문이 열린 채로 막대가 안 들어갈 때
이 경우는 집 안에 계셔서 급하지는 않지만 문을 닫을 수가 없습니다. / 억지로 문을 닫으면 막대가 문틀에 부딪혀 문틀 철판이 찌그러집니다.
도어락이면 배터리를 먼저 확인해 보세요. / 배터리가 약하면 막대를 내보낸 뒤 다시 당기지 못하고 멈추는 일이 있습니다.
수동 보조키라면 돌리개를 반대로 끝까지 돌려 보고, 뻑뻑하면 그 자리에서 멈춰 주세요. / 안쪽 부품이 빠졌거나 휘었을 수 있어 무리하게 돌리면 손잡이만 헛돌게 됩니다.
@ 흑석동 도어락 데드볼트 문틀 받이 확인

# 받이 구멍과 문틀 철판 살펴보기
문을 열어 둔 상태에서 문틀 쪽 받이 구멍을 들여다보세요. / 구멍 안에 먼지 뭉치나 작은 나사가 떨어져 있으면 막대가 끝까지 들어가지 못합니다.
받이 철판에 막대가 긁힌 자국이 한쪽으로만 나 있다면 문이 처져 위치가 어긋났다는 뜻입니다. / 이럴 때는 막대보다 경첩이나 받이 위치를 바로잡는 쪽이 맞습니다.
받이 철판 나사가 헐거워 철판이 들떠 있는 경우도 있습니다. / 나사를 조금 조이는 것만으로 막대가 부드럽게 드나들기도 합니다.

# 이 방법은 피해 주세요
막대 틈에 식용유나 아무 기름이나 뿌리지 마세요. / 기름이 먼지와 섞여 끈적해지면 처음보다 더 뻑뻑해집니다.
드라이버를 문틈에 넣어 막대를 밀어 넣으려는 시도도 권하지 않습니다. / 문틀 마감이 벌어지고 막대 끝이 뭉개져 다음에 더 잘 걸리게 됩니다.
도어락 몸체 나사를 풀어 속을 열어 보는 것도 멈춰 주세요. / 안쪽 연결 부품이 어긋나면 손잡이와 막대가 따로 놀게 됩니다.

# 오래된 다세대 현관에서 자주 보는 원인
오래 쓴 현관문은 경첩이 조금씩 처지면서 문 끝이 내려앉습니다. / 처음 설치할 때 맞춰 둔 받이 구멍과 막대 높이가 몇 밀리만 어긋나도 막대가 문틀에 걸립니다.
도어락을 새로 바꾸면서 받이를 예전 것 그대로 쓴 집도 비슷한 증상이 생길 수 있습니다. / 이런 경우는 받이 위치를 다시 맞추거나 새 받이로 바꾸는 작업이 필요합니다.
문을 닫을 때마다 쾅 소리가 크게 나는 집이라면 충격이 쌓여 막대 끝이 조금씩 휘기도 합니다. / 막대 모서리가 둥글게 닳았거나 한쪽이 눌려 있다면 이 경우를 의심해 볼 수 있습니다.

# 흑석동에서 연락 주실 때
아래 내용을 알려 주시면 맞는 부품과 장비를 챙겨 갑니다.
- 문 안에 계신지, 밖에 계신지
- 도어락의 막대인지, 따로 단 보조키의 막대인지
- 막대가 반쯤 나온 상태인지, 완전히 나온 상태인지
- 아파트인지 다세대인지, 몇 층인지
문 옆면과 문틀 받이 사진을 함께 보내 주시면 상황을 빨리 파악할 수 있습니다.

# 문을 열 때는 거주 확인을 거칩니다
바깥에서 막혀 문을 열어야 하는 경우라면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 가운데 하나면 됩니다.
집 안에 계신 상태에서 점검만 하는 경우에도 같은 원칙으로 진행합니다. / 번거로우셔도 이웃 모두를 위한 절차입니다.

# 손대기 전에 금액부터 말씀드립니다
막대 상태와 문틀을 본 뒤 무엇을 고치면 되는지, 얼마인지 먼저 안내드립니다. / 받이 조정으로 끝날 수도 있고 부품 교체가 필요할 수도 있습니다.
열어야 하는 상황에서 끝내 열지 못하면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 동작 출장열쇠 흑석동 데드볼트 수리

# 수리로 끝날지 교체가 맞을지
막대가 걸리는 원인이 문틀이나 받이에 있다면 도어락은 그대로 쓰는 경우가 많습니다. / 막대를 움직이는 안쪽 부품이 닳았다면 [도어락 수리](doorlock-repair.html)로 부품만 바꿀 수 있는지 먼저 봅니다.
부품을 구하기 어렵거나 모터까지 지쳐 있다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 교체를 하더라도 받이 위치를 함께 맞춰야 같은 증상이 다시 생기지 않습니다.

# 흑석동 이웃 동네도 다닙니다
상도동, 노량진동, 대방동, 사당동, 신대방동까지 동작구 전 지역 24시간 출동합니다. / 동작구 안내는 [동작구 출장열쇠](seoul-dongjak.html), 다른 지역은 [출장 지역](area.html)에 있습니다.
