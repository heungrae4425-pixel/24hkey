# 손에 열쇠 머리만 남았을 때
열쇠를 돌리는 순간 딱 소리가 나고 손에는 머리 부분만 남는 일이 있습니다. / 남은 반쪽은 열쇠구멍 안에 박혀 보이기만 하고 손톱으로는 잡히지 않습니다.
노량진역 주변 원룸과 고시원은 아직 열쇠로 여는 방문이나 보조키가 꽤 남아 있습니다. / 오래 쓴 열쇠나 복사를 여러 번 한 열쇠는 금이 가 있다가 어느 날 갑자기 부러지기 쉽습니다.
이 글은 열쇠가 부러져 안에 박혔을 때 바로 해야 할 것과 피해야 할 것, 출장으로 조각을 빼는 과정을 정리했습니다. / 지금 문 앞이라면 두 번째와 세 번째 단락부터 보셔도 됩니다.
@ 노량진동 열쇠 부러짐 열쇠구멍 조각

# 부러진 직후 가장 먼저 할 일
남은 열쇠 머리는 버리지 말고 잘 챙겨 두세요. / 조각을 빼낸 뒤 맞춰 보면 부러진 위치를 알 수 있고, 새 열쇠를 만들 때도 참고가 됩니다.
조각이 열쇠구멍 밖으로 조금 튀어나와 있는지 휴대폰 손전등으로 비춰 보세요. / 튀어나온 정도와 방향을 사진으로 찍어 두면 전화로 설명할 때 그대로 보여 드릴 수 있습니다.
문이 잠긴 상태인지 열린 상태인지도 확인해 주세요. / 잠그다가 부러졌는지, 열다가 부러졌는지에 따라 작업 순서가 달라집니다.
열쇠가 몇 도쯤 돌아간 상태에서 부러졌는지도 기억해 두세요. / 거의 다 돌린 뒤였는지, 넣자마자였는지에 따라 실린더 안 조각 위치가 다릅니다.

# 이것만은 하지 마세요
- 다른 열쇠나 클립을 구멍에 같이 밀어 넣기
- 순간접착제를 바른 이쑤시개로 조각 붙여 빼기
- 남은 머리를 맞대고 다시 돌려 보기
- 윤활제를 구멍 안에 많이 뿌리기
이런 방법은 조각을 더 깊이 밀어 넣거나 실린더 안 핀을 굳게 만듭니다. / 특히 접착제는 조각 대신 실린더 내부에 붙어 버려 실린더를 통째로 바꿔야 하는 경우가 생깁니다.
인터넷에서 본 방법을 따라 하다가 일이 커져 연락 주시는 경우가 의외로 많습니다. / 조각이 박힌 채로 두는 것은 당장 불편해도 상태를 더 나쁘게 만들지는 않습니다.

# 조각이 보일 때와 안 보일 때
조각 끝이 구멍 바깥쪽에 살짝 보인다면 전용 도구로 비교적 쉽게 빼낼 수 있습니다. / 다만 집게나 핀셋으로 직접 잡아당기다 미끄러지면 더 안으로 들어가니 조심해야 합니다.
조각이 구멍 깊이 들어가 끝이 안 보인다면 실린더 안 핀 사이에 끼어 있는 상태입니다. / 이때는 핀을 정렬한 뒤 가는 갈고리로 조각을 걸어 빼내는 작업이 필요합니다.
드물게 조각이 실린더를 반쯤 돌린 채 걸려 있으면 문이 반만 잠긴 상태가 되기도 합니다. / 이 경우 문을 세게 당기지 말고 그대로 두는 게 좋습니다.
열쇠가 휘어서 부러진 경우에는 조각 끝이 비스듬히 꺾여 있기도 합니다. / 이런 조각은 빼는 방향을 잘못 잡으면 핀에 걸려 버리니 각도를 보고 천천히 빼야 합니다.
@ 노량진동 실린더 부러진 열쇠 조각 빼기

# 고시원 방문이라면 총무님께 먼저
고시원이나 원룸 건물은 관리인이나 총무가 여분 열쇠를 보관하는 곳이 많습니다. / 방문 열쇠가 부러졌다면 여분 열쇠로 다른 쪽 잠금을 풀 수 있는지 먼저 물어보세요.
여분 열쇠가 있어도 같은 구멍에 조각이 박혀 있으면 열쇠가 들어가지 않습니다. / 이럴 때는 조각을 먼저 빼야 하니 무리하게 넣지 마세요.
관리인 연락처를 함께 알려 주시면 건물 출입과 확인이 수월해집니다. / 늦은 시간이라 연락이 안 되더라도 사시는 분인지 확인되면 진행할 수 있습니다.

# 왜 열쇠가 안에서 부러질까
열쇠는 대부분 얇은 금속이라 같은 자리에 힘이 반복해서 걸리면 조금씩 금이 갑니다. / 열쇠고리에 무거운 물건을 많이 달면 꽂아 둔 채로 열쇠가 휘기도 합니다.
복사한 열쇠는 원래 열쇠보다 홈이 조금 덜 맞아서 돌릴 때 힘이 더 듭니다. / 실린더 안이 먼지로 뻑뻑해진 상태라면 그만큼 열쇠에 무리가 갑니다.
돌릴 때 걸리는 느낌이 들기 시작했다면 그때가 실린더 점검 시기입니다.
겨울에는 금속이 차가워져 조금 더 쉽게 부러지기도 합니다. / 찬바람이 부는 날 뻑뻑한 열쇠를 힘껏 비틀지 않는 것만으로도 부러지는 일을 줄일 수 있습니다.

# 출장 요청 시 알려주실 것
- 노량진동 건물 위치와 층, 방 번호
- 현관 열쇠인지, 방문이나 보조키인지
- 잠긴 상태에서 부러졌는지
- 조각이 보이는지, 남은 열쇠 머리 사진
- 관리인 연락처
사진은 열쇠구멍을 정면에서 한 장, 비스듬히 한 장 찍어 주시면 좋습니다.
방 안에 꼭 필요한 약이나 물건이 있다면 그것도 함께 말씀해 주세요. / 급한 정도를 알면 도착 순서를 정하는 데 참고합니다.

# 도착하면 거주 여부부터 봅니다
문을 여는 작업이 함께 필요한 경우가 많아 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리인 확인 가운데 하나면 됩니다.
고시원처럼 방 번호가 주소에 안 나오는 곳은 관리인 확인이 가장 깔끔합니다. / 이웃 방까지 지키는 절차라 꼭 거칩니다. / 학원 수강증처럼 이름만 있는 서류보다는 주소가 나온 것을 준비해 주세요.

# 비용은 조각을 빼기 전에 말씀드립니다
조각 위치와 실린더 상태를 본 뒤 어떤 작업이 필요한지, 비용이 얼마인지 먼저 알려 드립니다. / 들어 보시고 괜찮을 때만 시작합니다. / 조각만 빼면 되는지, 실린더까지 손봐야 하는지를 나눠서 설명드립니다.
끝내 열지 못하면 비용은 받지 않습니다. / 자세한 순서는 [이용안내](guide.html)에 정리했습니다.
@ 동작 출장열쇠 노량진동 열쇠 조각 제거

# 빼낸 뒤 실린더를 계속 쓸 수 있을까
조각만 깨끗이 빠지고 핀이 멀쩡하면 실린더는 그대로 씁니다. / 새 열쇠만 준비하시면 됩니다. / 부러진 열쇠의 원래 열쇠가 남아 있다면 그것을 기준으로 맞추는 편이 잘 맞습니다.
조각을 빼는 과정에서 핀이 상했거나 원래 실린더가 많이 닳았다면 실린더 교체를 말씀드립니다. / 손잡이나 몸체까지 상했다면 [도어락 수리](doorlock-repair.html) 범위로 봅니다.
열쇠 대신 번호키로 바꾸고 싶으시면 [도어락 교체](doorlock-replace.html)도 함께 안내해 드립니다. / 문 여는 과정은 [현관문 개문](door-open.html)에서 보실 수 있습니다.

# 다시 부러지지 않게 하려면
- 돌릴 때 걸리면 힘으로 밀지 말고 열쇠를 살짝 뺐다 다시 넣기
- 금이 보이거나 휜 열쇠는 바로 새로 맞추기
- 열쇠고리는 가볍게 유지하기
- 복사 열쇠보다 원래 열쇠를 기준으로 새로 만들기
열쇠를 꽂은 채로 문을 밀거나 당기지 않는 것도 중요합니다. / 문 무게가 그대로 열쇠에 실려 휘어지기 쉽습니다.

# 노량진동 말고 동작구 전 지역
노량진동과 가까운 대방동, 흑석동, 상도동, 신대방동, 사당동도 다닙니다. / 동작구 동네는 [동작구 출장열쇠](seoul-dongjak.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
