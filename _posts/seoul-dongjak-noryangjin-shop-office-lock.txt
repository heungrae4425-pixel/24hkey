# 첫 수업 전에 교실 문이 안 열린다면
노량진역 주변에는 학원과 독서실, 작은 사무실이 층마다 들어선 건물이 많습니다. / 이른 아침 문을 여는 사람이 번호판 앞에서 막히면 뒤에 오는 수강생과 직원들까지 복도에서 기다리게 됩니다.
상가나 사무실 출입문은 집 현관과 달리 쓰는 사람이 여럿이고 문 종류도 다양합니다. / 이 글은 노량진동 상가와 사무실 출입문이 안 열릴 때 문 종류별로 확인할 것, 사업장 확인 방법, [동작구 출장열쇠](seoul-dongjak.html)를 부를 때 알려 주실 내용을 정리했습니다.
@ 노량진동 학원 사무실 출입문 도어락 개방

# 우리 사업장 문은 어느 쪽일까
- 강화유리문에 바닥이나 위쪽으로 잠기는 도어락이 달린 경우
- 철문이나 방화문에 일반 현관용 도어락이 달린 경우
- 바깥 셔터를 올린 뒤 안쪽에 유리문이 하나 더 있는 경우
- 건물 층 출입구에 공용 카드 잠금이 따로 있는 경우
문 종류에 따라 잠금 위치와 여는 방법이 다릅니다. / 전화 주실 때 이 중 어디에 해당하는지만 말씀하셔도 준비가 빨라집니다.

# 유리문 도어락은 잠금 위치부터 보세요
강화유리문 도어락은 문 위쪽이나 아래쪽에 잠금쇠가 숨어 있는 경우가 많습니다. / 번호가 맞는 소리는 났는데 문이 안 열리면 위아래 잠금쇠 쪽에 걸림이 있는지 봐야 합니다.
유리문을 세게 밀고 당기면 문 위 경첩 축이나 바닥 힌지에 무리가 갑니다. / 문이 한쪽으로 기울면 잠금쇠 위치가 어긋나 더 열리지 않습니다.
양쪽 여닫이 유리문이라면 고정된 한쪽 문이 살짝 풀려 있는 것만으로도 잠금쇠가 맞물리지 않을 수 있습니다. / 두 문 사이 높이가 맞는지 눈으로 먼저 확인해 보세요.

# 철문 사무실은 집 현관과 비슷합니다
철문에 달린 도어락은 집 현관용과 구조가 거의 같습니다. / 번호판이 꺼졌다면 비상 전원 단자에 9V 건전지를 대 보는 것부터 시작합니다.
다만 사무실 문은 하루에도 수십 번 열리고 닫혀 배터리가 집보다 빨리 닳습니다. / 주말을 지나 월요일 아침에 꺼져 있는 일이 특히 많습니다.
번호판은 켜지는데 모터 소리만 나고 안 열린다면 문이 안쪽으로 살짝 밀려 잠금쇠가 눌렸을 수 있습니다. / 문을 반대쪽으로 가볍게 밀어 준 채 다시 눌러 보세요.

# 셔터를 올렸는데 안쪽 문이 막혔을 때
바깥 셔터는 열쇠나 리모컨으로 올렸는데 안쪽 유리문 도어락이 안 열리는 경우가 있습니다. / 셔터와 안쪽 문은 별개의 잠금이라 어느 쪽 문제인지 나눠서 봐야 합니다.
셔터 모터나 리모컨 고장은 셔터 설비 쪽에서 다루는 경우가 많습니다. / 안쪽 출입문 도어락이 문제라면 저희가 바로 볼 수 있습니다.
셔터를 올린 상태로 오래 기다리게 된다면 가게 앞을 비우지 않도록 한 사람은 문 앞에 남아 주세요. / 열린 셔터 아래로 지나가는 사람이 많은 시간대라면 더 그렇습니다.
@ 노량진동 상가 유리문 도어락 잠금쇠 점검

# 번호를 여러 사람이 쓰면 생기는 일
강사나 직원이 여럿인 곳은 누군가 번호를 바꾸고 공유를 놓치는 일이 생깁니다. / 퇴근하면서 장난처럼 설정을 눌렀다가 번호가 바뀐 줄 모르는 경우도 있습니다.
여러 번 틀리면 입력이 한동안 막히니 서너 번 해 보고 멈추세요. / 그사이 최근에 번호를 바꾼 사람이 있는지 단체 대화방에 먼저 물어보는 것이 빠릅니다.
카드나 태그로 여는 사무실이라면 퇴사한 사람의 카드가 그대로 등록돼 있는지도 이번 기회에 점검해 보시는 게 좋습니다.
번호를 바꿀 때는 누가, 언제 바꿨는지를 한곳에 적어 두는 규칙만 있어도 이런 일이 크게 줄어듭니다. / 관리 책임자 한 사람이 번호 변경을 맡는 방식도 많이 씁니다.

# 업무 공간에서 억지로 열면 손해가 큽니다
유리문을 발로 차거나 틈에 공구를 넣으면 유리가 깨지거나 금이 갈 수 있습니다. / 유리문 교체는 도어락 수리보다 훨씬 시간이 오래 걸려 영업에 더 큰 지장을 줍니다.
철문 사무실도 문틀을 비틀면 다시 잠기지 않는 일이 생깁니다. / 문이 안 잠기면 그날 퇴근도 못 하게 되니 무리하지 마시고 연락 주세요.

# 사업장 확인은 이렇게 합니다
집이 아니라 사업장 문을 여는 것이므로 그 공간을 쓰시는 분인지 확인합니다. / 사업자등록증, 임대차 계약서, 건물 관리실 확인 가운데 하나면 됩니다.
서류가 사무실 안에 있다면 건물 관리실이나 대표자와 통화로 확인하는 방법도 있습니다. / 직원이 대신 요청하실 때는 대표자나 관리 책임자와 연락이 닿게 해 주세요.
확인이 끝나기 전에는 작업을 시작하지 않습니다. / 같은 층의 다른 사업장을 지키는 절차이기도 합니다.

# 노량진동에서 연락하실 때 알려 주실 것
- 건물 위치와 노량진역에서 어느 방향인지
- 몇 층인지, 건물 공용 출입구는 열려 있는지
- 유리문인지 철문인지, 도어락 모양
- 번호판 상태와 최근 번호를 바꾼 적이 있는지
- 수업이나 영업 시작 시각
시작 시각을 알려 주시면 그 시간에 맞출 수 있는지 먼저 말씀드립니다. / 도어락 사진을 보내 주시면 맞는 장비를 바로 챙깁니다.

# 금액은 시작하기 전에 정합니다
문 종류와 도어락 상태를 보고 작업 내용과 비용을 먼저 말씀드립니다. / 듣고 괜찮으실 때만 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html), 문 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 영업에 지장이 덜 가게 진행합니다
수업이나 영업 시간이 가까우면 문을 여는 것부터 먼저 하고, 점검은 사람이 덜 드나드는 시간으로 미룰 수 있습니다. / 한 번에 끝낼지 나눠서 할지 상황을 보고 같이 정하시면 됩니다.
문을 연 뒤에는 잠금과 열림이 제대로 되는지 여러 번 시험하고, 번호를 새로 정해 필요한 사람에게만 알리시도록 도와드립니다.
밤늦게 마지막 수업이 끝난 뒤 문이 안 잠기는 경우도 연락 주세요. / 문을 열어 둔 채 퇴근할 수는 없으니 잠금이 되게 하는 것부터 먼저 맞춥니다.

# 고장 났다면 고칠지 바꿀지
유리문 도어락은 잠금쇠나 바닥 힌지만 손보면 다시 쓰는 경우가 많습니다. / 부품만 바꾸면 되는지 [도어락 수리](doorlock-repair.html)로 먼저 봅니다.
출입하는 사람이 많아 번호 관리가 계속 문제라면 카드나 지문 방식으로 바꾸는 것도 방법입니다. / 그럴 때는 [도어락 교체](doorlock-replace.html)를 함께 상의합니다.
