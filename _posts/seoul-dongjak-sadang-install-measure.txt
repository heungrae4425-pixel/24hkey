# 마음에 드는 도어락을 골랐다면 문부터 보세요
사당역과 이수역 사이 주택가에는 오래된 다세대와 단독주택, 새로 지은 빌라가 섞여 있습니다. / 집마다 현관문 재질과 두께가 달라서 같은 도어락이라도 어떤 집에는 딱 맞고 어떤 집에는 들어가지 않습니다.
설치하는 날 문에 맞지 않아 제품을 다시 바꾸는 일은 생각보다 흔합니다. / 이 글은 사당동 주택 현관에 도어락을 달기 전에 집에서 직접 재 볼 수 있는 치수와 보조키 확인법을 정리했습니다.
미리 확인한 내용을 사진과 함께 보내 주시면 [동작구 출장열쇠](seoul-dongjak.html)에서 맞는 제품인지 설치 전에 말씀드릴 수 있습니다.
@ 사당동 주택 현관문 도어락 설치 전 치수

# 설치가 꼬이는 네 가지 경우
설치가 어려워지는 경우는 대개 아래 넷 중 하나입니다. / 먼저 우리 집이 어디에 해당하는지 짐작해 보세요.
- 문이 제품 허용 두께보다 얇거나 두꺼운 경우
- 기존 구멍 위치가 새 제품과 달라 구멍을 더 내야 하는 경우
- 보조키가 너무 가까이 있어 몸체가 겹치는 경우
- 문 앞이나 옆에 벽, 신발장이 있어 손잡이가 걸리는 경우
넷 다 집에서 미리 볼 수 있는 것들입니다. / 하나씩 확인하는 방법을 아래에 적었습니다.
세입자라면 설치 전에 집주인과 미리 이야기해 두는 것도 잊지 마세요. / 구멍을 새로 내야 할 수도 있어서 미리 정해 두면 나중에 서로 편합니다.

# 문 두께는 문 옆면에서 잽니다
현관문을 활짝 열고 경첩 반대쪽 옆면에 줄자를 대 보세요. / 바깥 면에서 안쪽 면까지 곧게 잰 값이 문 두께입니다.
문 가장자리에 고무나 테두리가 붙어 있다면 그것까지 포함해 재는 게 아니라 문짝 본체만 잽니다. / 손잡이 주변이 볼록하게 튀어나온 문이라면 손잡이 자리 근처에서 한 번 더 재 두세요.
대부분 도어락은 맞는 문 두께 범위를 설명서나 상자에 적어 둡니다. / 이 범위를 벗어나면 연장 부품이 필요하거나 아예 맞지 않을 수 있습니다.

# 오래된 철문과 새 방화문은 다릅니다
사당동 오래된 주택 현관은 얇은 철판 문이나 나무문인 경우가 있습니다. / 이런 문은 안쪽이 비어 있거나 보강재가 없는 자리가 있어 나사가 단단히 물리지 않을 수 있습니다.
새로 지은 빌라의 방화문은 두껍고 속이 꽉 차 있습니다. / 새 구멍을 내야 할 때 작업 시간이 더 걸리고, 문 안쪽 구조를 먼저 확인해야 합니다.
문을 손가락 마디로 두드려 보면 대략 짐작이 됩니다. / 통통 울리면 속이 빈 쪽, 둔하게 막힌 소리면 속이 찬 쪽에 가깝습니다.

# 지금 달린 손잡이와 구멍을 살펴봅니다
기존 손잡이나 도어락을 떼지 않아도 바깥에서 사진만 찍으면 구멍 크기와 위치를 짐작할 수 있습니다. / 바깥 면, 안쪽 면, 문 옆면 세 장을 찍어 주세요.
줄자로 바닥에서 손잡이 중심까지 높이, 문 끝에서 손잡이 중심까지 거리를 재 두면 좋습니다. / 새 제품의 기준 위치와 비교할 때 이 두 값이 가장 많이 쓰입니다.
@ 사당동 현관문 기존 구멍 보조키 위치 확인

# 보조키는 떼어 낼지 남길지 먼저 정하세요
주키 도어락 위나 아래에 열쇠식 보조키가 따로 달린 집이 많습니다. / 새 도어락을 달면서 보조키를 그대로 둘지, 떼어 내고 구멍을 막을지 정해야 합니다.
보조키를 남긴다면 새 도어락 몸체와 겹치지 않는지 간격을 봐야 합니다. / 기존 보조키 중심과 손잡이 중심 사이 거리를 재 두시면 설치 가능 여부를 빨리 판단할 수 있습니다.
보조키를 떼어 낸다면 남은 구멍을 어떻게 막을지도 함께 정합니다. / 덮개로 가릴지, 그 자리에 보조 도어락을 새로 달지에 따라 준비할 부품이 달라집니다.

# 문 앞과 옆 공간도 재 두세요
주택가 현관은 계단참이 좁거나 문 바로 옆에 벽이 붙어 있는 경우가 있습니다. / 손잡이가 크게 튀어나오는 제품은 문을 열 때 벽에 닿을 수 있습니다.
문을 끝까지 열었을 때 손잡이 쪽 문 끝과 벽 사이 간격을 재 보세요. / 안쪽에 신발장이나 중문이 가까이 있으면 안쪽 몸체 크기도 따져 봐야 합니다.
밀고 당기는 방식 도어락은 손잡이 모양이 달라 공간을 더 차지하기도 합니다. / 공간이 빠듯하다면 사진을 보내 주시면 맞는 모양을 같이 골라 드립니다.

# 문 열림 방향과 문틀 상태
문이 바깥으로 열리는지 안으로 열리는지, 경첩이 왼쪽인지 오른쪽인지도 확인합니다. / 제품에 따라 방향을 바꿔 다는 설정이나 부품이 필요할 수 있습니다.
문을 닫았을 때 문과 문틀 사이 틈이 위아래로 고른지도 봐 두세요. / 틈이 한쪽만 넓다면 문이 처진 것이어서 설치 전에 경첩이나 받이를 먼저 맞춰야 할 수 있습니다.
도어클로저가 달린 문이라면 문이 닫히는 힘도 한번 느껴 보세요. / 너무 세게 닫히면 새 도어락 잠금쇠가 받이에 부딪히며 빨리 상하고, 너무 약하면 덜 닫혀 잠금이 안 될 수 있습니다.
현관 위쪽에 우편 투입구나 작은 창이 붙은 문도 있습니다. / 이런 문은 새 몸체가 그 자리와 겹치지 않는지 높이를 함께 봐야 합니다.

# 사진은 이렇게 보내 주시면 됩니다
- 문 바깥 전체 한 장, 안쪽 전체 한 장
- 기존 손잡이와 보조키를 가까이서 한 장씩
- 문 옆면 두께가 보이게 줄자를 댄 사진
- 문 앞 공간이 보이는 넓은 사진 한 장
사진과 잰 값을 함께 문자로 보내 주시면 설치 가능 여부와 필요한 작업을 미리 말씀드립니다.

# 설치 날 진행 순서
도착하면 먼저 사진으로 본 내용과 실제 문이 같은지 확인합니다. / 기존 제품을 떼고 구멍 상태를 본 다음, 새 제품을 맞춰 달고 잠금과 열림을 여러 번 시험합니다.
설치 일정과 방식은 [도어락 설치](doorlock-install.html) 페이지에도 정리해 두었습니다. / 지금 달린 것을 바꾸는 경우라면 [도어락 교체](doorlock-replace.html)도 참고해 보세요.

# 비용은 문을 확인하고 먼저 말씀드립니다
문 상태와 구멍 작업 여부에 따라 작업 범위가 달라집니다. / 확인한 뒤 금액을 먼저 말씀드리고, 동의하실 때만 시작합니다.
제품을 직접 사 두셨다면 그 제품으로 설치해 드립니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
@ 동작 출장열쇠 사당동 도어락 설치 작업

# 설치 뒤 함께 해 두는 일
새 비밀번호를 등록하고 카드나 지문을 쓰는 제품이면 식구 수만큼 등록합니다. / 기존 도어락의 번호와 카드는 이제 쓸 수 없으니 함께 사는 분들께 꼭 알려 주세요.
문을 열고 닫으며 잠금쇠가 받이에 부드럽게 들어가는지, 자동 잠김이 제때 되는지 같이 확인합니다. / 이상한 소리나 걸림이 있으면 그 자리에서 다시 맞춥니다.

# 사당동 말고 동작구 다른 동네도
노량진동, 상도동, 흑석동, 대방동, 신대방동까지 동작구 어디든 24시간 다닙니다. / 동작구 안내는 [동작구 출장열쇠](seoul-dongjak.html), 다른 지역은 [출장 지역](area.html)에서 보세요.
