# 모두 잠든 시간, 현관 앞에서
야근을 마치고 돌아왔거나 늦은 약속 뒤에 집에 왔는데 현관문이 안 열리면 시간부터 걱정됩니다. / 이 시간에 전화를 받아 줄 곳이 있을지, 이웃을 깨우지는 않을지 이런저런 생각이 듭니다.
동작구 신대방동에서도 자정이 넘어 문 앞에서 연락 주시는 분이 계십니다. / 늦은 시간일수록 통화 한 번에 필요한 내용을 정확히 전하면 도착과 작업이 빨라집니다.
이 글은 한밤이나 새벽에 문이 안 열렸을 때 전화 전에 정리할 것, 통화할 때 말하면 좋은 것, 기다리는 동안 할 일을 순서대로 적었습니다.
@ 신대방동 새벽 현관문 잠김 출장 연락

# 전화하기 전 30초 정리
급할수록 먼저 숨을 한 번 고르고 아래 세 가지만 확인해 보세요. / 전화로 설명할 내용이 저절로 정리됩니다.
- 번호판에 불이 들어오는지, 아예 꺼져 있는지
- 번호를 누르면 어떤 소리가 나는지
- 안에 사람이나 반려동물이 있는지
이 세 가지만 알아도 배터리 문제인지, 번호 문제인지, 걸쇠 문제인지 대략 나뉩니다. / 안에 누가 있다면 그 사실을 가장 먼저 말씀해 주세요.
보조키를 함께 쓰는 집이라면 나올 때 보조키를 잠갔는지도 떠올려 보세요. / 도어락만 잠긴 것과 보조키까지 잠긴 것은 준비할 장비가 다릅니다.

# 휴대폰 배터리부터 아끼세요
밤에 밖에 서 있으면 휴대폰으로 검색하고 메시지를 보내느라 배터리가 빨리 닳습니다. / 출장열쇠 연락이 닿았다면 화면 밝기를 낮추고 다른 앱은 잠시 꺼 두세요.
배터리가 얼마 남지 않았다면 통화 첫마디에 주소부터 말씀해 주세요. / 중간에 끊겨도 주소만 받아 두면 찾아갈 수 있습니다.
휴대폰을 집 안에 두고 나왔다면 편의점이나 이웃에게 전화를 잠시 빌려도 됩니다. / 그때는 다시 걸 수 있는 번호를 꼭 함께 알려 주세요. / 빌린 전화라면 도착 무렵 그 번호로 연락드려도 되는지도 미리 여쭤봐 주시면 좋습니다.

# 통화할 때 이 순서로 말해 주세요
늦은 시간 통화는 짧고 정확한 게 가장 좋습니다. / 아래 순서대로 말씀해 주시면 몇 가지 질문만으로 끝납니다.
- 신대방동 주소와 건물 형태, 층과 호수
- 지금 어떤 상태인지 (꺼짐, 경고음, 번호 분실 등)
- 도어락 모양과 보조키가 있는지
- 공동현관 출입이 가능한지
- 문자로 사진을 보낼 수 있는지
도어락 사진을 보내 주시면 맞는 장비를 챙겨 갈 수 있어 현장 시간이 줄어듭니다.
어두워서 사진이 잘 안 나오면 휴대폰 손전등을 켜고 앞면을 정면에서 찍어 주세요. / 번호판 모양과 손잡이 위치만 보여도 충분합니다.
@ 신대방동 한밤 도어락 사진 문자 전송

# 도착 시간을 물어보세요
통화할 때 언제쯤 도착하는지 꼭 물어보세요. / 밤에는 도로 사정이 낮과 달라 예상 시간을 미리 들어 두면 기다리기 덜 막막합니다.
비용도 통화에서 대략 여쭤보셔도 됩니다. / 정확한 비용은 문과 도어락 상태를 본 뒤에 먼저 말씀드리고, 동의하실 때만 시작합니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 통화에서 확답을 피하는 곳보다 진행 방식을 분명히 말해 주는 곳이 마음이 편합니다.

# 도착 전까지 문 앞에서 할 일
번호판이 꺼져 있다면 가까운 편의점에서 9V 건전지를 사 와 비상 단자에 대 볼 수 있습니다. / 이것으로 열리면 출장 연락을 취소하셔도 괜찮습니다.
번호가 기억나지 않는다면 계속 눌러 보지는 마세요. / 여러 번 틀리면 입력이 막혀 오히려 시간이 늘어납니다.
신분증이 지갑에 있는지 확인해 두세요. / 주소가 다르게 적혀 있다면 주소가 나온 우편물이나 택배 문자도 도움이 됩니다.
함께 사는 가족이 다른 곳에 있다면 번호를 알고 있는지 메시지로 물어보는 것도 방법입니다. / 새벽이라 바로 답이 없더라도 그사이 출장 준비는 이어서 진행됩니다.

# 늦은 밤 혼자 기다릴 때 안전
복도나 건물 입구가 어둡다면 불이 켜진 곳에서 기다리세요. / 건물 밖에서 기다리는 것이 불편하면 가까운 편의점 안에 계셔도 됩니다.
도착하면 다시 전화를 드리니 그때 나오셔도 늦지 않습니다. / 차가 도착하면 업체 이름과 통화한 내용이 맞는지 한 번 확인해 보세요. / 가족이나 친구에게 지금 상황과 기다리는 위치를 메시지로 남겨 두면 더 안심이 됩니다.

# 이웃을 덜 깨우는 방법
문 앞에서 문을 두드리거나 손잡이를 세게 흔들면 소리가 복도 전체에 울립니다. / 도어락 경고음이 계속 울리면 번호 입력을 멈추고 기다려 주세요.
작업 중에도 가능한 조용한 방법부터 씁니다. / 공동현관 앞에서 기다리실 때도 인터폰으로 다른 집을 부르기보다는 출장 기사에게 전화를 주시는 편이 낫습니다. / 늦은 시간이라 소리에 더 신경 쓰며 진행합니다.

# 밤에도 거주 확인은 똑같이
밤이라고 해서 확인 절차를 건너뛰지는 않습니다. / 신분증 주소, 주소가 나온 우편물, 관리실 확인 가운데 하나로 사시는 분인지 확인합니다.
신분증이 집 안에 있다면 문을 연 직후 바로 보여 주시면 됩니다. / 이 경우에도 이름과 주소는 처음에 말씀해 주세요.

# 작업 전에 금액부터 말씀드립니다
문과 도어락을 본 뒤 비용을 먼저 말씀드립니다. / 늦은 시간이라고 말없이 붙는 비용은 없습니다. / 부품 교체처럼 추가 작업이 필요해 보이면 그 자리에서 따로 여쭙고, 원하지 않으시면 문 열기까지만 하고 마칩니다.
못 열면 비용은 받지 않습니다. / 자세한 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.
@ 동작 출장열쇠 신대방동 야간 문 열기

# 문이 열린 뒤 그 자리에서 할 일
배터리가 원인이었다면 새 배터리로 바로 바꿔 둡니다. / 번호를 잊어서 열었다면 안쪽에서 새 번호를 등록하고 예전 번호는 지웁니다.
다음 날 다시 같은 일이 생기지 않도록 잠금과 열림을 몇 번 반복해 확인합니다. / 고칠 곳이 보이면 [도어락 수리](doorlock-repair.html), 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 그때 말씀드립니다.
문 여는 과정은 [현관문 개문](door-open.html) 페이지에서 보실 수 있습니다.

# 밤에 다시 막히지 않으려면
- 배터리는 경고음이 나기 전에 미리 교체
- 9V 건전지 하나를 가방이나 차에 넣어 두기
- 번호를 잊을 때를 대비해 가족과 공유
- 휴대폰 보조배터리 챙기기
특히 늦게 귀가하는 날이 많다면 이 네 가지만 지켜도 새벽에 문 앞에서 막히는 일이 크게 줄어듭니다.
출장열쇠 번호를 휴대폰에 미리 저장해 두는 것도 좋습니다. / 급할 때 검색하느라 배터리와 시간을 쓰지 않아도 됩니다.

# 신대방동 말고 동작구 어디든
신대방동과 가까운 대방동, 노량진동, 상도동, 흑석동, 사당동도 다닙니다. / 동작구 동네는 [동작구 출장열쇠](seoul-dongjak.html), 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.

? 휴대폰 배터리가 거의 없어요. | 주소부터 먼저 말씀해 주세요. 끊겨도 찾아갈 수 있습니다.
? 통화로 비용을 알 수 있나요? | 대략 안내드리고, 정확한 비용은 문 상태를 본 뒤 시작 전에 말씀드립니다.
? 새벽에 와서 못 열면 출장비만 내나요? | 못 열면 받지 않습니다.
? 기다리는 동안 해 볼 게 있나요? | 번호판이 꺼졌다면 9V 건전지를 대 보시고, 신분증을 미리 챙겨 두세요.
