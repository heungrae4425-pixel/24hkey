# 불광동, 잠깐 나온 사이 문이 철컥 닫혔을 때
불광동 빌라에 사는 분들 중에는 1층 분리수거장에 쓰레기를 내놓거나 계단 아래 택배를 가지러 슬리퍼 차림으로 나오는 분이 많습니다. / 정말 1분이면 끝날 일인데, 돌아서는 순간 등 뒤에서 현관문이 철컥 잠깁니다.
손에는 빈 쓰레기봉투나 택배 상자 하나, 휴대폰과 열쇠는 집 안 탁자 위에 있는 경우가 대부분입니다. / 번호키라면 번호만 누르면 되지만, 번호를 몰라 지문이나 카드로만 다니던 집이라면 바로 막힙니다.
이 글은 불광동에서 잠깐 나왔다가 문이 잠겼을 때 어떤 순서로 움직이면 되는지 정리했습니다. / 연락이 되면 [은평구 출장열쇠](seoul-eunpyeong.html)로 전화 주시면 됩니다.
@ 불광동 빌라 택배 분리수거 중 문 잠김

# 자동 잠금이 이런 상황을 만듭니다
요즘 도어락은 대부분 문이 닫히면 저절로 잠기는 자동 잠금이 기본입니다. / 외출할 때 잠그는 걸 잊지 않게 해 주는 편리한 기능이지만, 잠깐 나올 때는 함정이 됩니다.
바람이 세게 부는 날 복도 창이 열려 있으면 문이 생각보다 빨리 닫힙니다. / 도어클로저가 문을 끝까지 당겨 주는 집은 손을 떼는 순간 바로 잠깁니다.
안에 아무도 없다면 밖에서 열 수 있는 방법은 비밀번호, 카드, 지문, 열쇠 중 지금 가진 것뿐입니다. / 하나도 없다면 이제부터는 연락 수단을 찾는 게 먼저입니다.

# 휴대폰이 없다면 연락부터 해결하세요
휴대폰이 집 안에 있으면 가족 번호도, 출장 번호도 바로 떠오르지 않습니다. / 이웃집 초인종을 눌러 사정을 말하고 전화를 잠깐 빌리는 것이 가장 빠른 방법입니다.
불광동 큰길 쪽 편의점이나 가게에 가서 부탁하는 것도 방법입니다. / 저희 번호 010-3664-5455나 가족 번호 하나는 외워 두면 이럴 때 크게 도움이 됩니다.
통화가 되면 위치와 상황을 짧게 말씀해 주세요. / 그리고 이웃 전화번호로 다시 연락드려도 되는지, 아니면 문 앞에서 기다리실지 알려주시면 됩니다.

# 슬리퍼 차림에 추운 날이라면
겨울 저녁이나 비 오는 날에 반팔과 슬리퍼로 밖에 서 있으면 금방 몸이 식습니다. / 빌라 공동현관 안쪽이나 계단처럼 바람이 덜 드는 곳에서 기다리세요.
이웃이 잠깐 들어와 있으라고 하면 사양하지 말고 도움을 받는 것도 괜찮습니다. / 저희가 도착하기 전에 그 집 호수를 알려주시면 그쪽으로 연락드립니다.
아이와 함께 나왔다면 아이 체온부터 챙겨 주세요. / 기다리는 시간이 길어질 것 같으면 도착 예상 시간을 듣고 따뜻한 곳으로 옮겨 계셔도 됩니다.
@ 불광동 문 잠김 휴대폰 없을 때 연락 방법

# 안에 켜 둔 불이나 물이 걱정될 때
가스레인지에 냄비를 올려 두고 나왔거나, 욕조에 물을 틀어 놓고 나왔다면 상황이 다릅니다. / 연기가 나거나 타는 냄새가 나면 망설이지 말고 119에 먼저 연락하세요.
위험할 정도는 아니어도 불이나 물이 걱정된다면 전화하실 때 꼭 먼저 말씀해 주세요. / 그런 경우는 순서를 앞당겨 움직입니다.
반려동물이 안에 있다면 그것도 함께 알려주세요. / 문 앞에서 소리가 나도 놀라지 않게 조심해서 작업합니다.

# 가족에게 열 방법이 있는지 확인
가족과 연락이 닿는다면 가까이 있는 사람이 있는지부터 물어보세요. / 번호를 알고 있는 가족이 있다면 전화로 번호를 불러 주는 것만으로 끝납니다.
누군가 비상 카드나 열쇠를 가지고 있다면 그 사람이 오는 시간과 출장이 도착하는 시간을 비교해 보세요. / 가족이 금방 올 수 있다면 기다리시는 게 낫고, 멀다면 출장이 빠를 수 있습니다.

# 문 앞에서 하지 말아야 할 것
- 문틈에 택배 상자 조각이나 카드 밀어 넣기
- 번호를 짐작으로 계속 눌러 입력 잠금 만들기
- 손잡이를 잡고 세게 흔들거나 문을 차기
- 창문이나 베란다로 들어가려 하기
특히 빌라 외벽이나 창문으로 들어가려는 시도는 정말 위험합니다. / 2층 높이라도 다칠 수 있으니 절대 하지 마세요.

# 기다리는 동안 이웃과 공용 공간
계단이나 복도에서 기다리시면 지나다니는 이웃이 놀랄 수 있습니다. / 마주치면 문이 잠겨 출장을 기다리는 중이라고 한마디 해 두시면 서로 편합니다.
분리수거하다 나왔다면 쓰레기봉투는 정해진 곳에 마저 두고 오세요. / 택배 상자는 문 앞 한쪽에 세워 두면 됩니다.

# 연락하실 때 알려주실 것
- 불광동 건물 이름이나 번지, 층, 호수
- 불광역 쪽인지 연신내역 쪽인지
- 지금 쓰고 계신 연락처 (이웃 번호여도 됩니다)
- 도어락 종류 (번호키, 지문, 카드)
- 집 안에 사람이나 동물, 켜 둔 불이 있는지
공동현관이 잠기는 건물이면 저희가 어떻게 들어가야 하는지도 같이 말씀해 주세요.

# 신분증이 집 안에 있다면
문을 열기 전에는 사시는 분인지 확인하는 절차가 꼭 필요합니다. / 그런데 잠깐 나온 상황이라 신분증도 우편물도 전부 집 안에 있는 경우가 대부분입니다.
이럴 때는 집주인이나 건물 관리하시는 분께 확인을 부탁드리거나, 문을 연 직후 집 안에서 신분증이나 우편물을 보여주시는 방법으로 진행합니다. / 이웃이 사시는 분을 알아봐 주시는 것도 참고가 됩니다.
번거로우시겠지만 다른 사람이 남의 집 문을 열어 달라고 하는 일을 막기 위한 절차입니다.

# 비용은 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 시작 전에 먼저 말씀드립니다. / 괜찮다고 하시면 그때 열고, 끝내 못 열면 비용은 받지 않습니다.
여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 적어 두었습니다. / 지갑까지 안에 있어도 문을 연 뒤에 처리하시면 됩니다.

# 다음엔 이렇게 막아 보세요
- 잠깐 나갈 때도 휴대폰은 손에 들기
- 가족 번호와 출장 번호 하나는 외워 두기
- 지문이나 카드만 쓰더라도 비밀번호는 꼭 외워 두기
- 비상 카드나 열쇠를 믿을 만한 이웃이나 가족에게 맡기기
- 쓰레기 버리러 갈 때 문 사이에 신발을 끼우는 습관은 피하기
마지막 항목은 의외일 수 있지만, 문을 걸쳐 두면 도어락 걸쇠와 문틀이 상하고 방범에도 좋지 않습니다. / 차라리 비밀번호를 외워 두는 쪽이 안전합니다. 도어락을 손볼 일이 있다면 [도어락 수리](doorlock-repair.html)에서 기준을 보세요.
@ 불광동 잠깐 외출 문 잠김 출장열쇠 개문
