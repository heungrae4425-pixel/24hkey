# 불광동 현관 앞, 손가락을 대도 반응이 없을 때
불광동은 불광역과 연신내역 사이로 빌라가 촘촘하게 이어진 동네입니다. / 오래된 빌라라도 도어락은 지문형으로 바꾼 집이 꽤 있어서, 손가락 하나로 드나드는 데 익숙한 분이 많습니다.
그런데 어느 날 센서에 손을 올려도 빨간 불만 깜빡이거나 "다시 시도하세요" 소리만 나면 순간 당황하게 됩니다. / 지문은 비밀번호처럼 잊어버릴 일이 없다고 믿었던 만큼 더 그렇습니다.
이 글은 지문 인식이 잘 안 될 때 문 앞에서 차례로 해볼 것과 [은평구 출장열쇠](seoul-eunpyeong.html)를 불러야 하는 때를 나눠 적었습니다. / 지금 밖에 서 계시다면 3번과 6번 소제목부터 보셔도 됩니다.
@ 불광동 지문 도어락 인식 실패 현관 앞

# 지문 센서가 손가락을 못 알아보는 이유
지문 도어락은 손가락 표면의 굴곡을 읽어 등록해 둔 모양과 비교합니다. / 그래서 손가락 쪽이 달라져도, 센서 쪽이 달라져도 맞춰 보지 못합니다.
- 손이 너무 마르거나 반대로 젖어 있는 경우
- 손끝에 상처, 굳은살, 밴드가 붙어 있는 경우
- 센서 창에 먼지, 기름때, 물기가 묻은 경우
- 배터리가 약해져 센서가 제대로 켜지지 않는 경우
- 등록할 때 손가락 한쪽 면만 찍어 둔 경우
대부분은 고장이 아니라 이런 조건이 겹쳐서 생깁니다. / 하나씩 지워 가면 의외로 쉽게 풀리는 일이 많습니다.

# 손 상태부터 살펴보세요
겨울에 밖에서 오래 있다 들어오면 손끝이 차고 건조해서 지문 굴곡이 얕아집니다. / 양손을 비벼 따뜻하게 하고 입김을 살짝 불어 준 뒤 다시 대 보세요.
반대로 비를 맞았거나 손을 막 씻고 나왔다면 물기를 옷이나 손수건으로 닦아 주세요. / 핸드크림을 바른 직후에도 기름막 때문에 인식이 떨어집니다.
손가락을 꾹 누르거나 비비듯 움직이면 오히려 읽기 어렵습니다. / 등록할 때처럼 손가락 가운데를 센서 중앙에 평평하게 올리고 잠깐 멈추는 게 요령입니다.

# 센서 창은 이렇게 닦습니다
불광동 빌라처럼 현관이 골목이나 계단에 바로 닿아 있으면 센서 창에 먼지가 잘 앉습니다. / 손때와 먼지가 쌓이면 손가락이 깨끗해도 실패가 이어집니다.
부드러운 천이나 안경닦이로 센서 창을 가볍게 훔쳐 주세요. / 물티슈를 쓰셨다면 마른 천으로 한 번 더 닦아 물기를 남기지 않아야 합니다.
날카로운 물건으로 긁거나 알코올을 흠뻑 묻혀 문지르는 건 피하세요. / 센서 표면 코팅이 상하면 그때부터는 닦아도 회복이 안 됩니다.

# 등록할 때 손가락 하나만 넣었다면
지문을 한 손가락만, 그것도 한 번만 찍어 등록해 둔 집이 많습니다. / 그러면 손가락을 조금만 비뚤게 대도 인식이 안 될 수 있습니다.
문이 열린 뒤에는 자주 쓰는 손가락을 각도를 바꿔 가며 다시 등록해 두세요. / 오른손 검지와 왼손 검지처럼 양손에 하나씩 넣어 두면 한쪽 손을 다쳤을 때도 들어갈 수 있습니다.
가족마다 손가락 하나씩만 넣어 두기보다 두 개씩 여유를 두는 편이 낫습니다. / 등록 개수가 꽉 찼다면 안 쓰는 지문부터 지우고 넣으면 됩니다.

# 비밀번호와 카드로 우회하기
지문 도어락은 대부분 번호 입력이나 카드 태그도 함께 됩니다. / 지문이 계속 안 될 때는 손가락을 붙잡고 있지 말고 다른 방법으로 먼저 들어가세요.
번호판 덮개를 열거나 손바닥으로 화면을 덮으면 숫자가 켜지는 모델이 많습니다. / 번호를 모르신다면 함께 사는 가족에게 먼저 물어보시는 게 빠릅니다.
지갑이나 휴대폰 케이스에 카드키를 넣어 다니셨다면 그것도 대 보세요. / 다만 지문 실패를 여러 번 반복하면 잠시 입력이 막히는 제품이 있으니 서너 번에서 멈추는 게 좋습니다.

# 번호판도 같이 꺼졌다면 배터리 쪽입니다
지문도 안 되고 숫자도 안 켜진다면 센서보다 전원 문제일 가능성이 큽니다. / 지문 센서는 번호판보다 전기를 많이 써서 배터리가 약해지면 먼저 둔해집니다.
바깥쪽 아래나 옆에 9V 비상 단자가 있으면 건전지를 대 보세요. / 불광역 쪽 편의점에서 구할 수 있고, 전원이 들어오면 번호나 지문으로 열 수 있습니다.
열고 나서는 안쪽 배터리를 한꺼번에 새것으로 갈아 주세요. / 요즘 들어 인식이 느려졌다고 느끼셨다면 그 신호가 배터리였을 수 있습니다.
@ 불광동 지문 도어락 센서 닦기 배터리 비상 전원

# 계절 따라 인식률이 흔들리는 집
지문 인식은 겨울에 유독 나빠지는 집이 많습니다. / 손이 건조하고 차가운 데다 배터리도 추위에 힘이 떨어지기 때문입니다.
여름에는 땀과 습기 때문에 센서 창이 뿌옇게 흐려지기도 합니다. / 장마철 빌라 계단은 바람이 잘 안 통해서 현관 쪽에 습기가 오래 머뭅니다.
계절이 바뀔 때마다 실패가 늘어난다면 손가락을 다시 등록하고 배터리를 미리 갈아 두는 게 효과가 있습니다. / 그래도 계속되면 센서 자체를 점검받을 때가 된 겁니다.

# 이럴 때는 집에서 그만 붙잡으세요
- 센서 불은 켜지는데 어떤 손가락도 안 읽히는 경우
- 지문이 맞았다는 소리는 나는데 걸쇠가 안 빠지는 경우
- 번호와 카드까지 모두 안 되는 경우
- 센서 창이 깨졌거나 들뜬 경우
이런 상황은 문 앞에서 오래 시도해도 풀리지 않는 경우가 많습니다. / 억지로 손잡이를 당기거나 틈을 벌리면 도어락과 문틀만 상합니다.
문을 열어야 하는 상황이면 [현관문 개문](door-open.html)으로, 센서 고장이 의심되면 [도어락 수리](doorlock-repair.html)로 이어서 봐 드립니다.

# 연락 주실 때 알려주시면 좋은 것
불광동은 골목마다 빌라가 비슷하게 생겨서 건물 찾는 데 시간이 걸릴 수 있습니다. / 아래 내용을 짧게 알려주시면 도착이 빨라집니다.
- 건물 이름이나 번지, 층과 호수
- 불광역, 연신내역 중 어느 쪽에 가까운지
- 지문 센서 불이 켜지는지, 숫자판은 켜지는지
- 도어락 앞면 사진 한 장
- 집 안에 아이나 반려동물이 있는지
공동현관이 따로 잠기는 건물이면 들어오는 방법도 같이 말씀해 주세요.

# 사시는 분 확인과 비용 안내
문을 여는 일이라 도착하면 이 집에 사시는 분이 맞는지 먼저 봅니다. / 주소가 나온 신분증이나 우편물을 보여주시면 되고, 둘 다 안에 있으면 집주인이나 관리인 확인으로 대신할 수 있습니다.
비용은 도어락 종류와 상태를 보고 시작 전에 먼저 말씀드립니다. / 들어 보시고 괜찮을 때만 진행하고, 끝내 못 열면 비용은 받지 않습니다.
센서 부품을 바꿔야 하는 경우도 손대기 전에 따로 여쭤봅니다. / 자세한 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 지문 다시 등록할 때 요령
문이 열리면 기존 지문을 지우고 새로 등록하는 것까지 같이 해 드립니다. / 직접 하실 때는 아래 순서를 참고하세요.
- 손을 씻고 완전히 말린 뒤 등록하기
- 손가락 가운데, 조금 위, 조금 옆을 나눠 여러 번 찍기
- 양손에 하나씩, 가족마다 두 개씩 넣어 두기
- 등록 후 바로 열고 닫기를 몇 번 해 보기
지문만 믿지 말고 비밀번호는 가족이 모두 외우는 번호로 하나 남겨 두세요. / 오래된 제품이라 센서가 자주 말썽이면 그때 [도어락 교체](doorlock-replace.html)를 함께 상의드립니다.
@ 불광동 지문 재등록 도어락 점검 출장열쇠

# 불광동 말고 은평 어디든 갑니다
불광동 가까이 녹번동, 갈현동, 대조동, 역촌동은 물론 응암동, 구산동, 진관동까지 은평구 안이면 다 다닙니다. / 진관동처럼 길이 긴 곳은 위치를 받고 도착 시간을 먼저 말씀드립니다.
은평에서 다니는 동네는 [은평구 출장열쇠](seoul-eunpyeong.html)에, 다른 곳은 [출장 지역](area.html) 지도에 정리했습니다. / 서울, 경기 전 지역 24시간 출동합니다.

# 자주 묻는 질문
? 지문이 갑자기 안 되는데 고장인가요? | 대부분은 손 상태나 센서 오염, 배터리 때문입니다. 닦고 말려도 계속 안 되면 점검이 필요합니다.
? 지문 말고 번호로도 열 수 있나요? | 지문형 도어락 대부분은 번호 입력도 됩니다. 숫자판이 켜지는지 먼저 확인해 보세요.
? 손을 다쳐서 등록한 손가락을 못 써요. | 번호나 카드로 들어가신 뒤 다른 손가락을 추가 등록하시면 됩니다.
? 열지 못하면 돈을 내나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 늦은 밤에도 불광동까지 오시나요? | 네, 24시간 받습니다. 위치를 알려주시면 도착 시간을 말씀드립니다.
