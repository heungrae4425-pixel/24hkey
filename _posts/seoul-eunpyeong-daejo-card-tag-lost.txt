# 대조동, 지갑 속 카드 한 장이 사라졌을 때
대조동은 연신내역과 불광역 사이 생활권에 빌라가 골목마다 들어선 동네입니다. / 번호 대신 카드나 동그란 태그를 대서 드나드는 집이 많아, 열쇠고리나 휴대폰 케이스에 붙여 둔 태그를 잃어버리면 바로 불편해집니다.
문제는 들어가는 것만이 아닙니다. / 잃어버린 카드가 아직 도어락에 등록된 상태라면 그 카드를 주운 누군가도 문을 열 수 있다는 점이 더 신경 쓰입니다.
이 글은 대조동에서 카드키, 태그, 공동현관 리모컨을 잃어버렸을 때 오늘 안에 해 둘 정리와 [은평구 출장열쇠](seoul-eunpyeong.html)가 필요한 경우를 순서대로 담았습니다.
@ 대조동 빌라 도어락 카드키 태그 분실

# 들어가는 길이 남아 있는지부터
카드를 잃어버렸다고 바로 문이 막히는 건 아닙니다. / 우리 집 도어락이 카드 말고 어떤 방법을 함께 쓰는지 떠올려 보세요.
- 비밀번호를 같이 쓰는 제품이라면 번호로 들어가기
- 지문을 등록해 둔 식구가 있다면 그 사람에게 연락
- 보조키 열쇠를 따로 쓰는 문이라면 열쇠 확인
- 가족이 가진 카드나 태그로 열기
대부분 이 중 하나는 남아 있습니다. / 카드만 쓰고 번호를 등록하지 않은 집이라면 그때 출장이 필요합니다.

# 카드만 쓰던 집이라면
번호 없이 카드로만 다니던 집이라면 밖에서 열 방법이 없습니다. / 이럴 때는 가족에게 남은 카드가 있는지 먼저 확인하고, 없으면 연락 주세요.
건물 이름이나 번지, 층과 호수를 알려 주시고, 도어락 번호판 사진을 보내 주시면 맞는 장비를 챙겨 갑니다. / 도착하면 신분증이나 우편물로 사시는 분인지 확인한 뒤 진행합니다.
비용은 손대기 전에 먼저 말씀드리고, 끝내 못 열면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 왜 등록 삭제가 먼저일까
잃어버린 카드에는 집 주소가 적혀 있지 않은 경우가 많아 크게 걱정하지 않는 분도 있습니다. / 하지만 카드가 열쇠고리에 집 열쇠, 차 키와 같이 달려 있었다면 이야기가 다릅니다.
카드가 도어락에 등록된 채로 남아 있는 동안은 그 카드로 문이 열립니다. / 집에 들어가셨다면 가장 먼저 등록된 카드를 정리하는 게 좋습니다.
열쇠고리에 보조키 열쇠까지 함께 달려 있었다면 카드 정리만으로는 부족합니다. / 보조키 실린더를 바꾸거나 열쇠를 새로 맞추는 일까지 같이 생각해 보셔야 합니다.
어디서 잃어버렸는지 짐작이 된다면 그곳에 먼저 물어보는 것도 방법입니다. / 다만 찾았더라도 한동안 누구 손에 있었는지 모른다면 다시 등록해 두는 편이 마음 편합니다.

# 카드 하나만 골라 지울 수 있을까
많은 도어락은 카드를 하나씩 골라 지우는 기능이 없습니다. / 대신 등록된 카드를 전부 지우고 남은 카드를 다시 등록하는 방식으로 정리합니다.
안쪽 몸체 건전지 덮개를 열면 등록 버튼이 있는 제품이 많습니다. / 설명서에 나온 순서대로 카드 전체 삭제를 한 뒤, 가족이 가진 카드를 하나씩 다시 대서 등록하면 됩니다.
설명서가 없다면 몸체에 붙은 모델명을 확인해 주세요. / 모델명 사진을 보내 주시면 순서를 안내해 드리거나 직접 가서 정리해 드립니다.
@ 대조동 도어락 카드 전체 삭제 재등록

# 재등록할 때 꼭 확인할 것
식구 수만큼 카드를 모두 손에 쥐고 시작해야 합니다. / 한 장이라도 빠지면 그 사람은 다음 날 문 앞에서 막힙니다.
- 남은 카드와 태그를 모두 모으기
- 전체 삭제 후 한 장씩 다시 등록
- 잃어버린 카드는 다시 등록하지 않기
- 등록 뒤 문 밖에서 카드마다 한 번씩 열어 보기
- 비밀번호나 지문도 그대로 살아 있는지 확인
카드 전체 삭제를 할 때 비밀번호나 지문까지 함께 지워지는 제품도 있습니다. / 지우기 전에 설명서에서 꼭 확인하시고, 헷갈리면 연락 주세요.

# 스티커 태그와 휴대폰 케이스 태그
요즘은 휴대폰 뒷면이나 케이스 안에 얇은 스티커 태그를 붙여 쓰는 분이 많습니다. / 휴대폰을 잃어버렸다면 태그도 같이 잃어버린 것이니 카드와 똑같이 정리해야 합니다.
새 태그는 같은 방식의 제품이어야 등록됩니다. / 아무 태그나 사 오면 도어락이 인식하지 못하니 기존 태그와 같은 종류인지 먼저 확인하세요.

# 빌라 공동현관 리모컨이나 카드
대조동 빌라 중에는 1층 공동현관을 리모컨이나 카드로 여는 곳도 있습니다. / 공동현관은 건물 전체가 함께 쓰는 장치라 내 마음대로 초기화하면 다른 세대가 모두 못 들어갈 수 있습니다.
공동현관 리모컨을 잃어버렸다면 집주인이나 건물을 관리하는 분께 먼저 알리세요. / 등록을 어떻게 정리할지는 건물 쪽과 상의해서 정하는 게 맞습니다.
세대 현관 정리는 저희가 도와드릴 수 있고, 공동현관 작업이 필요하면 건물 쪽 동의를 받은 뒤 진행합니다.

# 세입자라면 집주인에게도 한 줄
전월세로 사는 집이라면 카드를 잃어버렸다는 사실과 정리한 내용을 집주인께 짧게 알려 두세요. / 이사 나갈 때 넘겨받은 카드 개수가 맞지 않으면 이야기가 길어질 수 있습니다.
새로 산 카드나 태그가 있다면 그 개수도 같이 적어 두시면 됩니다.

# 카드가 자주 없어지는 집이라면
카드를 몇 번씩 잃어버리는 집이라면 출입 방식을 바꾸는 것도 방법입니다. / 지문이나 비밀번호를 함께 쓰는 제품이라면 카드는 비상용으로만 두고 평소에는 다른 방법을 쓰면 됩니다.
카드만 되는 오래된 제품이라면 [도어락 교체](doorlock-replace.html)를 생각해 볼 만합니다. / 카드 인식이 들쭉날쭉한 거라면 [도어락 수리](doorlock-repair.html)로 먼저 봐 드립니다.
@ 은평 대조동 카드 도어락 등록 정리 출장

# 진행과 비용 안내
등록 정리만 하는 경우에도 방문하면 사시는 분인지 먼저 확인합니다. / 도어락 종류와 해야 할 작업을 본 뒤 비용을 먼저 말씀드리고, 동의하시면 시작합니다.
새 카드나 태그를 함께 마련해야 한다면 기존 도어락과 맞는 종류인지 현장에서 확인한 뒤 말씀드립니다. / 진행 순서는 [이용안내](guide.html)에서 보실 수 있습니다.

# 대조동과 이웃한 은평 동네도
대조동과 같은 생활권인 불광동, 갈현동은 물론 역촌동, 구산동, 녹번동, 응암동, 진관동까지 은평구 어디든 갑니다. / 서울, 경기 전 지역 24시간 출동합니다.
은평에서 다니는 동네는 [은평구 출장열쇠](seoul-eunpyeong.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
