# 응암동 새집 열쇠를 받은 날 먼저 할 일
응암동은 응암역을 중심으로 빌라가 골목마다 이어진 동네라 이사 들고 나는 집이 꾸준합니다. / 짐 정리에 정신이 없다 보면 현관 도어락은 전에 쓰던 번호 그대로 두고 지내는 경우가 많습니다.
하지만 도어락 안에는 전에 살던 분의 비밀번호, 카드키, 지문이 그대로 남아 있을 수 있습니다. / 새집에서 마음 편히 지내려면 이삿날이나 그다음 날 안에 정리해 두시는 게 좋습니다.
이 글은 응암동으로 이사한 뒤 도어락을 초기화하고 새 번호를 등록하는 순서, 그리고 혼자 하기 어려울 때 [은평구 출장열쇠](seoul-eunpyeong.html)를 부르는 방법을 정리했습니다.
@ 응암동 이사 후 도어락 초기화 새 비밀번호

# 전 세입자 번호가 아직 살아 있을 수 있습니다
집주인이나 중개 쪽에서 번호를 알려 주며 "바꿔 놨다"고 해도 실제로는 하나만 바꾼 경우가 있습니다. / 도어락은 비밀번호 외에도 카드나 태그를 여러 장 등록해 둘 수 있기 때문입니다.
전에 살던 분이 카드 한 장을 반납하지 않았거나, 청소나 수리 기사에게 알려준 임시 번호가 남아 있을 수도 있습니다. / 누가 그걸 쓸지는 알 수 없지만, 모르는 출입 수단이 남아 있는 상태는 정리하는 게 맞습니다.
그래서 이사 후에는 번호만 바꾸기보다 전체 초기화를 한 번 하고 새로 등록하는 방식을 권해 드립니다.

# 초기화와 비밀번호 변경은 다릅니다
비밀번호 변경은 기존 번호 하나를 새 번호로 덮어쓰는 것입니다. / 이때 등록된 카드나 지문은 그대로 남아 있는 제품이 많습니다.
초기화는 등록된 번호와 카드, 지문을 한꺼번에 지우고 처음 상태로 되돌리는 것입니다. / 그 뒤에 새 번호와 내 카드만 다시 넣으면 출입 수단이 내 것만 남습니다.
제품마다 초기화 방법이 달라서, 설명서가 없으면 모델명을 먼저 확인해야 합니다. / 안쪽 몸체 배터리 덮개 안쪽이나 옆면에 모델명이 적힌 스티커가 붙어 있는 경우가 많습니다.

# 안쪽 몸체에서 등록 버튼 찾기
대부분의 도어락은 실내 쪽 몸체 배터리 덮개를 열면 작은 등록 버튼이나 설정 버튼이 있습니다. / 이 버튼을 길게 누르거나 정해진 순서로 누르면 초기화나 등록 모드로 들어갑니다.
- 배터리 덮개를 열고 버튼 위치 확인
- 모델명을 확인해 제조사 안내 방법 찾아보기
- 문을 연 상태에서 작업하기
- 작업이 끝나면 문 밖에서 새 번호로 실제 열어 보기
문을 닫은 채 설정하다가 순서가 꼬이면 밖에서 못 들어오는 일이 생깁니다. / 반드시 문을 열어 둔 상태로, 집 안에 누가 있을 때 해 보세요.

# 카드키와 지문 등록도 같이 정리
카드형이나 태그형 도어락이라면 받은 카드 개수부터 세어 보세요. / 계약할 때 몇 장을 넘겨받았는지 집주인에게 물어봐 두면 나중에 헷갈리지 않습니다.
초기화 후에는 지금 손에 있는 카드만 다시 등록합니다. / 지문형이면 전에 등록된 지문이 남아 있지 않게 전체 삭제가 됐는지 꼭 확인하세요.
리모컨이나 휴대폰 앱이 연결되는 제품은 앱 쪽 연결도 끊어야 할 수 있습니다. / 전 거주자 계정이 붙어 있으면 알림이나 원격 열림이 남아 있을 수 있어서입니다.
@ 응암동 빌라 도어락 등록 버튼 카드키 정리

# 새 번호를 정할 때 피할 것
새 번호는 가족 모두가 외울 수 있으면서 남이 짐작하기 어려운 조합이 좋습니다. / 생일, 같은 숫자 반복, 1234처럼 순서대로 이어지는 번호는 피하세요.
번호판에 자주 누르는 자리만 지문이 묻어 번질 수 있으니 가끔 닦아 주시고, 앞뒤에 아무 숫자나 덧붙여 누르는 허수 기능이 있으면 써 보세요. / 이사 직후에는 번호를 휴대폰 메모에 적어 두되, 문 근처나 우편함에 붙여 두지는 마세요.

# 빌라 공동현관 번호는 따로 확인
응암동 빌라 중에는 건물 1층 공동현관에 별도 도어락이 달린 곳이 있습니다. / 이 번호는 내 집이 아니라 건물 전체가 함께 쓰는 것이라 내가 마음대로 바꿀 수 없습니다.
번호를 모르면 집주인이나 건물 관리하시는 분께 여쭤보세요. / 공동현관이 고장 나서 못 들어가는 경우도 연락 주시면 함께 봐 드립니다.

# 보조키와 열쇠 꾸러미 정리
오래된 빌라는 도어락 위나 아래에 열쇠로 여는 보조키가 따로 달린 집이 있습니다. / 이 보조키 열쇠는 전에 살던 분이 복사해 두었을 수도 있어서 넘겨받은 개수만으로는 다 회수됐는지 알기 어렵습니다.
보조키를 계속 쓰실 거라면 실린더만 바꾸는 방법도 있습니다. / 쓰지 않을 거라면 아예 잠그지 않고 두거나 정리하는 것도 방법입니다.

# 이삿날 문이 안 열리는 일도 있습니다
짐을 옮기느라 문을 여러 번 열고 닫다 보면 배터리가 약했던 도어락이 갑자기 꺼지기도 합니다. / 받은 번호가 틀려서 문 앞에서 막히는 경우도 생각보다 많습니다.
이럴 때는 먼저 집주인이나 중개 쪽에 번호를 다시 확인해 보세요. / 그래도 안 되면 바깥쪽 9V 비상 단자로 전원을 넣어 보고, 그것도 안 되면 연락 주시면 됩니다.

# 혼자 하기 어려울 때 부르는 방법
설명서가 없거나 버튼을 눌러도 반응이 없으면 무리하게 계속하지 않는 게 좋습니다. / 순서가 꼬이면 아무 번호로도 안 열리는 상태가 될 수 있습니다.
전화 주실 때 건물 이름이나 번지, 층, 호수와 응암역 쪽인지 다른 방향인지 알려주세요. / 도어락 앞면과 안쪽 몸체 사진을 보내 주시면 맞게 준비해 갑니다.
초기화와 새 번호 등록, 카드 재등록까지 한 번에 해 드립니다. / 문이 잠긴 상태라면 [현관문 개문](door-open.html)부터 진행합니다.

# 이사 직후 사시는 분 확인은 이렇게
문을 여는 경우에는 이 집에 사시는 분인지 먼저 확인합니다. / 이사한 지 얼마 안 돼 신분증 주소가 예전 집으로 되어 있으면 임대차 계약서나 집주인 확인으로 대신할 수 있습니다.
계약서를 휴대폰 사진으로 찍어 두셨다면 그것도 도움이 됩니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 손대기 전에 말씀드립니다
초기화만 할지, 부품까지 바꿀지는 도어락 상태를 보고 정합니다. / 무엇을 하는지와 비용을 먼저 말씀드리고, 괜찮다고 하실 때만 시작합니다.
문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 연식이 오래돼 새 제품이 낫겠다 싶으면 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html) 방향도 함께 말씀드립니다.
