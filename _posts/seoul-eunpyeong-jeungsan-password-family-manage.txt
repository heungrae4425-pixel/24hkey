# 증산동 집, 마지막으로 번호를 바꾼 게 언제였나요
증산동 빌라에 사는 식구들에게 현관 비밀번호를 언제 바꿨냐고 물어보면 대답이 금방 나오지 않는 경우가 많습니다. / 처음 이사 와서 정한 번호를 몇 해째 그대로 쓰고 있는 집도 흔합니다.
번호를 오래 쓰면 잊을 일은 없지만, 그동안 누구에게 알려 줬는지는 점점 흐려집니다. / 반대로 누군가 혼자 번호를 바꾸면 다른 식구가 문 앞에서 막히는 일도 생깁니다.
이 글은 증산동에서 가족이 함께 쓰는 도어락 번호를 어떻게 바꾸고 나누면 덜 헷갈리는지, 막혔을 때 [은평구 출장열쇠](seoul-eunpyeong.html)에 연락하는 시점까지 정리했습니다.
@ 증산동 빌라 가족 도어락 비밀번호 관리

# 달력보다 사람의 출입을 기준으로
번호를 몇 개월마다 바꿔야 한다는 정답은 없습니다. / 그보다는 번호를 아는 사람이 바뀌었을 때를 기준으로 삼는 편이 현실적입니다.
- 이사 들어온 날, 또는 집을 고친 공사가 끝난 날
- 집을 봐 주던 친척이나 도우미가 일을 그만둔 뒤
- 자녀가 친구에게 번호를 알려 줬다고 말한 날
- 번호판 앞에 낯선 사람이 오래 서 있었던 걸 본 뒤
이런 일이 없다면 계절이 한 번 바뀔 때쯤 가족끼리 이야기를 꺼내 보는 정도면 충분합니다. / 정해 둔 날이 있으면 미루는 일이 줄어듭니다.

# 한 사람이 정하고 모두가 동의하기
번호는 식구 중 한 사람이 바꾸되, 바꾸기 전에 모두에게 미리 알리는 게 원칙입니다. / 퇴근길에 문 앞에서야 바뀐 걸 알게 되는 상황이 가장 난감합니다.
바꾸는 날은 식구가 대부분 집에 있는 저녁이 좋습니다. / 새 번호를 그 자리에서 각자 한 번씩 직접 눌러 보게 하면 확실합니다.

# 번호를 알리는 방법이 더 중요합니다
가족 단체 대화방에 번호를 그대로 적어 보내는 집이 많습니다. / 편하긴 하지만 휴대폰을 잃어버리거나 누가 대화방을 엿보면 그대로 노출됩니다.
가능하면 얼굴을 보고 말로 전하고, 부득이하면 보낸 뒤 바로 지우는 습관을 들이세요. / 냉장고나 신발장 안쪽에 번호를 적어 두는 것도 피하는 게 좋습니다.
떨어져 사는 가족에게 알려야 한다면 번호 전체가 아닌 힌트로 주고받는 방법도 있습니다. / 가족만 아는 날짜나 기억을 바탕으로 정하면 힌트만으로도 떠올릴 수 있습니다.

# 아이에게는 손가락 순서로 익히게
초등학생 아이는 숫자보다 번호판 위 손가락 움직임으로 외우는 경우가 많습니다. / 새 번호를 정하면 아이와 함께 서너 번 직접 눌러 보며 익히게 해 주세요.
아이가 친구 앞에서 번호를 누를 때 손을 가리는 습관도 같이 알려 주면 좋습니다. / 강요하기보다 놀이처럼 알려 주면 오래 갑니다.
@ 증산동 아이와 함께 새 비밀번호 익히기

# 어르신에게는 쓰기 편한 방법을 따로
번호가 바뀌는 걸 가장 부담스러워하시는 분이 부모님인 경우가 많습니다. / 함께 사는 어르신이 계시다면 지문이나 카드를 따로 등록해 드려서 번호가 바뀌어도 상관없게 해 드리는 방법이 있습니다.
그래도 번호를 쓰셔야 한다면 바꾸는 주기를 길게 잡고, 바꾼 다음 날 한 번 더 직접 확인해 드리세요. / 문 앞에서 막히셨을 때 바로 전화할 가족 번호를 휴대폰 첫 화면에 두시게 하는 것도 도움이 됩니다.

# 가족마다 번호를 따로 줄 수 있는지 확인
도어락 중에는 비밀번호를 여러 개 등록할 수 있는 제품이 있습니다. / 이런 제품이라면 식구마다 다른 번호를 주고, 누군가 번호를 흘렸을 때 그 번호만 지우면 됩니다.
우리 집 제품이 되는지는 설명서나 안쪽 몸체 덮개 안 안내 문구에서 확인할 수 있습니다. / 모델을 모르시면 도어락 앞뒤 사진을 보내 주세요.

# 식구가 아닌 사람에게는 가족 번호를 주지 않기
반찬을 가져다주시는 친척, 아이를 봐 주시는 분, 수리 기사처럼 잠깐 드나드는 사람에게 가족 번호를 그대로 알려 주는 일이 많습니다. / 그 순간은 편하지만, 번호를 아는 사람이 하나 늘어난 셈입니다.
임시 번호나 일회용 번호 기능이 있는 제품이라면 그 기능을 쓰고, 없다면 방문이 끝난 뒤 가족 번호를 바꾸는 쪽을 권합니다. / 바꾸는 날 이유를 식구들과 나누면 다음에도 자연스럽게 지켜집니다.

# 번호판에 남는 흔적도 관리 대상
같은 번호를 오래 누르면 자주 누른 숫자 자리만 반질반질해지거나 얼룩이 남습니다. / 번호판을 가끔 마른 천으로 닦아 주면 이런 흔적이 덜 남습니다.
번호 앞뒤에 아무 숫자를 덧붙여 눌러도 열리는 허수 기능이 있는 제품이라면 그 기능을 써 보세요. / 옆에서 누가 보고 있어도 진짜 번호를 짐작하기 어려워집니다.

# 바꾼 뒤 일주일은 이렇게
새 번호에 익숙해지는 동안은 예전 번호를 습관처럼 누르게 됩니다. / 여러 번 틀리면 도어락이 잠시 입력을 막는 제품이 많으니 두세 번 틀리면 멈추고 가족에게 확인하세요.
- 바꾼 날 저녁에 식구 모두 한 번씩 직접 눌러 보기
- 예전 번호가 정말 지워졌는지 한 번 눌러 보기
- 카드키와 지문은 그대로 살아 있는지 확인
- 일주일 동안은 비상 연락이 되게 휴대폰 챙기기
예전 번호가 여전히 먹힌다면 바꾼 게 아니라 하나를 더한 것일 수 있습니다. / 이 경우 설명서대로 예전 번호를 따로 지워야 합니다.

# 그래도 문 앞에서 막혔다면
새 번호를 잘못 기억했거나 등록 과정에서 실수가 있었다면 문이 안 열릴 수 있습니다. / 이럴 때는 가족에게 먼저 연락해 보고, 연락이 안 되면 그때 전화 주세요.
도착하면 신분증이나 우편물로 사시는 분인지 먼저 확인하고, 비용은 문 열기 전에 말씀드립니다. / 끝내 못 열면 비용은 받지 않습니다. 진행 방식은 [이용안내](guide.html), 여는 방법은 [현관문 개문](door-open.html)에 있습니다.

# 번호 등록이 자꾸 꼬이는 도어락이라면
번호를 바꿀 때마다 등록이 안 되거나, 바꾼 번호가 며칠 뒤 풀려 버리는 제품도 있습니다. / 이럴 때는 기판이나 버튼 쪽 문제일 수 있어 [도어락 수리](doorlock-repair.html)로 먼저 봐 드립니다.
연식이 오래돼 여러 번호 기능이 없는 제품이라면 가족이 함께 쓰기 편한 제품으로 [도어락 교체](doorlock-replace.html)를 생각해 볼 만합니다.
@ 은평 증산동 도어락 비밀번호 변경 출장

# 증산동 이웃 동네와 은평 어디든
증산동과 함께 수색동, 신사동, 응암동, 역촌동, 녹번동, 불광동, 진관동까지 은평구 전 지역을 다닙니다. / 서울, 경기 전 지역 24시간 출동합니다.
은평에서 다니는 곳은 [은평구 출장열쇠](seoul-eunpyeong.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
