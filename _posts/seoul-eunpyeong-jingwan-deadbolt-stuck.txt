# 진관동 현관 데드볼트가 말을 안 들을 때
진관동은 구파발역 주변으로 은평뉴타운 아파트가 넓게 자리 잡은 동네입니다. / 비교적 새 아파트가 많아 도어락 고장과는 거리가 멀 것 같지만, 잠금 막대가 걸리는 문제는 새집에서도 종종 생깁니다.
문을 닫고 잠그려는데 "철컥" 소리 없이 모터만 헛돌거나, 반대로 번호를 눌렀는데 잠금 막대가 안 빠져 문이 꼼짝 안 하는 경우입니다. / 이 막대를 데드볼트라고 부릅니다.
이 글은 진관동에서 데드볼트가 안 들어가거나 안 빠질 때 원인을 나눠 보고, 직접 볼 것과 [은평구 출장열쇠](seoul-eunpyeong.html)를 부를 때를 정리했습니다.
@ 진관동 아파트 도어락 데드볼트 걸림

# 데드볼트와 래치는 다른 부품입니다
도어락 옆면을 보면 문틀 쪽으로 튀어나오는 쇠붙이가 보통 두 종류입니다. / 비스듬하게 깎인 것이 래치, 네모나고 두툼한 것이 데드볼트입니다.
래치는 문이 닫힐 때 툭 걸려서 문을 붙잡아 두는 역할을 합니다. / 데드볼트는 도어락이 잠길 때 모터나 손잡이 힘으로 문틀 깊숙이 밀려 들어가 문을 단단히 잠급니다.
문이 닫히긴 하는데 잠기지 않는다면 데드볼트 쪽 문제이고, 문이 아예 덜 닫힌다면 래치나 경첩 쪽일 가능성이 큽니다. / 이 둘을 나눠서 보면 원인을 훨씬 빨리 찾을 수 있습니다.

# 데드볼트가 안 들어갈 때, 잠금이 안 되는 경우
문을 닫았는데 잠금 소리가 나다 말거나 "잠기지 않았습니다" 안내가 나오는 경우입니다. / 데드볼트가 나오려다 문틀 구멍 가장자리에 부딪혀 멈춘 상태입니다.
- 문이 끝까지 닫히지 않아 구멍과 위치가 안 맞는 경우
- 문틀 받이 구멍 안에 먼지나 이물질이 찬 경우
- 문이 처져 데드볼트 높이와 구멍 높이가 어긋난 경우
- 배터리가 약해 모터 힘이 모자란 경우
이대로 외출하면 잠긴 줄 알았던 문이 열려 있을 수 있습니다. / 잠금 안내가 이상하면 손잡이를 당겨 실제로 잠겼는지 꼭 확인하세요.

# 데드볼트가 안 빠질 때, 문이 안 열리는 경우
번호는 맞았고 모터도 도는데 문이 열리지 않는다면 데드볼트가 문틀에 눌려 빠지지 않는 상황일 수 있습니다. / 문 쪽으로 힘이 실려 있으면 막대가 구멍 벽에 꽉 물려서 모터가 이기지 못합니다.
번호를 누른 직후 문을 몸 쪽으로 살짝 당기거나 안쪽으로 살짝 밀어 보세요. / 막대에 걸린 힘이 풀리는 순간 빠지는 경우가 있습니다.
그래도 안 되면 데드볼트를 움직이는 내부 부품이 닳았거나 부러졌을 수 있습니다. / 이때는 계속 눌러 모터를 혹사하지 말고 연락 주시는 게 좋습니다.

# 문틀 받이 구멍과 높이가 어긋났다면
문틀 쪽에는 데드볼트가 들어가는 쇠 받이가 붙어 있습니다. / 이 받이 주변에 긁힌 자국이 한쪽으로 몰려 있다면 막대가 위나 아래로 비껴 들어가고 있다는 뜻입니다.
경첩 나사가 풀려 문이 조금 처지면 이런 일이 생깁니다. / 받이 위치를 조금 옮기거나 경첩을 바로잡으면 해결되는 경우가 많습니다.
@ 진관동 도어락 문틀 받이 데드볼트 위치

# 새 아파트에서도 생기는 이유
새로 지은 건물도 입주 뒤 계절을 몇 번 지나면 문과 문틀이 미세하게 움직입니다. / 현관문은 무거운 방화문이라 경첩에 걸리는 무게도 커서, 조금씩 처지는 일이 낯설지 않습니다.
입주할 때 단 도어락을 그대로 쓰는 집이라면 받이 위치를 한 번도 조정하지 않았을 수 있습니다. / 처음엔 잘 맞던 것이 어느 날부터 걸리기 시작하는 건 이 때문입니다.
겨울에 유독 잘 안 잠기고 여름에 괜찮다면 계절에 따른 문틀 변화일 가능성도 있습니다.

# 집 안에 계실 때 확인할 것
안에 계시다면 문을 열어 둔 채로 확인해 볼 수 있습니다. / 아래 순서로 보세요.
- 문을 연 상태에서 잠금 버튼을 눌러 데드볼트가 끝까지 나오는지
- 다시 열림 버튼을 눌러 막대가 끝까지 들어가는지
- 문틀 받이 구멍 안에 먼지나 부스러기가 있는지
- 배터리를 새것으로 바꾼 뒤 같은 동작이 더 힘차게 되는지
문을 연 상태에서는 잘 움직이는데 닫으면 걸린다면 도어락보다 문 위치 문제입니다. / 열어 둔 상태에서도 막대가 덜 나온다면 도어락 내부를 봐야 합니다.

# 밖에 계실 때 해볼 수 있는 것
밖에서는 할 수 있는 게 많지 않습니다. / 번호판이 켜지는지 보고, 번호를 누른 뒤 문을 살짝 밀거나 당겨 보는 정도까지만 해 주세요.
가족이 안에 있다면 안쪽 수동 레버나 열림 버튼을 눌러 달라고 하세요. / 안에서도 데드볼트가 안 빠진다면 내부 부품 문제라 출장이 필요합니다.

# 수동 레버를 힘으로 돌리지 마세요
안쪽 몸체의 수동 잠금 레버는 데드볼트를 손으로 움직이게 해 줍니다. / 그런데 막대가 문틀에 꽉 물린 상태에서 레버를 힘껏 돌리면 내부 기어가 부러질 수 있습니다.
레버가 뻑뻑하면 문을 살짝 움직여 막대의 힘을 풀어 준 뒤 다시 돌려 보세요. / 그래도 안 되면 손을 떼고 연락 주시는 게 수리 범위를 줄이는 길입니다.

# 진관동은 도착 시간을 먼저 말씀드립니다
진관동은 은평구 안에서도 길이 길게 이어지는 쪽이라 출발 위치에 따라 걸리는 시간이 다릅니다. / 위치를 받으면 예상 도착 시간을 먼저 말씀드리고, 늦은 시간에도 출동합니다.
전화 주실 때 아파트 동과 호수, 구파발역 쪽인지 다른 방향인지 알려주세요. / 데드볼트가 나와 있는 상태인지, 들어가 있는 상태인지 말씀해 주시면 준비가 빨라집니다.

# 사시는 분 확인과 비용 안내
문이 안 열리는 상황이면 도착 후 사시는 분인지 먼저 확인합니다. / 신분증 주소, 우편물, 관리사무소 세대 확인 중 하나면 됩니다.
그다음 데드볼트 상태를 보고 무엇을 할지와 비용을 손대기 전에 말씀드립니다. / 동의하실 때만 시작하고 끝내 못 열면 비용은 받지 않습니다. 여는 과정은 [현관문 개문](door-open.html), 순서는 [이용안내](guide.html)에 있습니다.

# 받이 조정으로 끝날지, 부품을 바꿀지
받이 위치나 경첩만 손보면 되는 경우가 생각보다 많습니다. / 이럴 때는 도어락을 바꾸지 않고 [도어락 수리](doorlock-repair.html)로 마무리합니다.
데드볼트를 움직이는 기어나 모터가 닳았다면 부품 교체가 필요합니다. / 부품을 구하기 어려운 연식이거나 같은 문제가 반복되면 [도어락 교체](doorlock-replace.html)를 그때 함께 말씀드립니다.
@ 진관동 데드볼트 수리 도어락 점검 출장열쇠

# 진관동 말고 은평 다른 동네도 갑니다
진관동 가까이 구산동, 갈현동, 불광동은 물론 대조동, 역촌동, 응암동, 수색동까지 은평구 전 지역을 다닙니다. / 서울, 경기 전 지역 24시간 출동합니다.
은평에서 다니는 곳은 [은평구 출장열쇠](seoul-eunpyeong.html)에서, 그 밖의 지역은 [출장 지역](area.html)에서 확인하세요.
