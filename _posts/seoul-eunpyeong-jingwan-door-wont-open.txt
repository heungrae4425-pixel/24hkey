# 진관동 아파트 복도, 문 앞에서 멈춰 섰을 때
진관동은 구파발역 주변으로 은평뉴타운 아파트가 넓게 자리 잡은 동네입니다. / 비교적 새 아파트가 많아 밀고 당기는 형 도어락을 쓰는 집이 대부분이고, 평소에는 손잡이를 밀기만 하면 열리던 문입니다.
그런데 어느 날 손잡이를 밀어도 꿈쩍하지 않으면 머릿속이 하얘집니다. / 문이 안 열리는 원인은 생각보다 몇 가지로 정리되고, 증상을 보면 어느 쪽인지 대부분 가려낼 수 있습니다.
이 글은 진관동 아파트에서 현관문이 안 열릴 때 원인 다섯 가지를 증상으로 나누는 방법과 [은평구 출장열쇠](seoul-eunpyeong.html)를 부르는 순서를 정리했습니다.
@ 진관동 아파트 현관문 안 열림 원인 확인

# 먼저 공동현관인지 세대 현관인지
아파트에서는 1층 공동현관과 내 집 현관 두 곳에서 막힐 수 있습니다. / 공동현관이 안 열리는 거라면 경비실이나 관리사무소 쪽 문제일 가능성이 큽니다.
공동현관은 다른 주민이 드나들 때 함께 들어가거나 경비실 호출 버튼으로 해결되는 경우가 많습니다. / 아래 내용은 세대 현관, 즉 내 집 문 앞에서 막힌 경우를 기준으로 합니다.

# 원인 하나, 전원이 나갔다
번호판을 손바닥으로 덮거나 눌러도 불이 전혀 안 들어오면 건전지가 바닥난 경우가 대부분입니다. / 며칠 전부터 경고음이 났는데 미뤘다면 거의 확실합니다.
바깥 몸체 아래쪽에 비상 전원 단자가 있는지 찾아보세요. / 9V 건전지를 대고 있는 동안 번호를 누르면 열리는 제품이 많습니다.
단자가 없거나, 건전지를 대도 반응이 없으면 다음 단계로 넘어가지 말고 연락 주시면 됩니다.

# 원인 둘, 번호가 맞지 않는다
불은 들어오는데 번호를 누르면 틀렸다는 소리가 나면 비밀번호 쪽입니다. / 식구 중 누가 번호를 바꿨는지 먼저 확인해 보세요.
여러 번 틀리면 도어락이 몇 분 동안 입력을 막습니다. / 서너 번 틀렸다면 멈추고 가족에게 연락하는 편이 시간을 아낍니다.
카드키나 지문을 같이 등록해 둔 집이라면 그 방법을 먼저 써 보세요. / 번호와 상관없이 열리는 경우가 많습니다.

# 원인 셋, 열림 소리는 나는데 문이 안 밀린다
번호가 맞아 열림 소리나 모터 소리가 나는데 손잡이를 밀어도 문이 안 열리는 경우입니다. / 걸쇠가 문틀 구멍에 꽉 끼어 있거나, 모터가 힘이 부족해 걸쇠를 끝까지 못 당기는 상황입니다.
문을 몸 쪽으로 살짝 당겨 걸쇠에 걸린 힘을 덜어 준 다음, 다시 번호를 누르고 밀어 보세요. / 이 동작 하나로 열리는 경우가 꽤 있습니다.
그래도 안 되면 모터나 걸쇠 부품 쪽이라 혼자서는 해결이 어렵습니다.
@ 진관동 밀고 당기는 도어락 걸쇠 확인

# 원인 넷, 안쪽에서 잠금이 걸려 있다
문이 손가락 한두 마디만큼 열리다가 턱 걸린다면 안쪽 걸쇠나 안전고리가 걸려 있는 겁니다. / 집 안에 가족이 있다면 불러서 풀어 달라고 하시면 끝입니다.
집이 비어 있는데 이런 증상이라면 마지막으로 나간 사람이 다른 문으로 나갔거나, 도어락 안쪽 수동 잠금이 걸린 상태일 수 있습니다. / 틈 사이로 손이나 도구를 넣어 억지로 풀려고 하면 고리와 문이 상하니 연락 주세요.
아이가 안에서 장난으로 잠금 버튼을 눌렀다면 문 너머로 차분하게 말을 걸어 주세요. / 아이 혼자 있다면 통화하실 때 꼭 먼저 말씀해 주시면 서두르겠습니다.

# 원인 다섯, 문과 문틀이 서로 눌린다
계절이 바뀌거나 비가 이어진 뒤 문이 평소보다 뻑뻑하게 느껴졌다면 문틀 쪽을 봅니다. / 새 아파트도 입주 뒤 몇 해 동안 건물이 자리를 잡으면서 문과 문틀 사이가 조금씩 달라지기도 합니다.
문 위아래 틈이 한쪽만 좁아졌거나, 닫을 때 마지막에 툭 걸리는 느낌이 있었다면 이쪽일 가능성이 큽니다. / 문을 연 뒤에 경첩과 받이를 맞추면 다시 부드러워집니다.

# 원인을 가리는 한 줄 요약
- 불이 안 켜진다 → 전원
- 불은 켜지는데 틀렸다고 한다 → 비밀번호
- 열림 소리는 나는데 안 밀린다 → 걸쇠나 모터
- 조금 열리다 걸린다 → 안쪽 잠금
- 평소에도 뻑뻑했다 → 문틀과 경첩
통화하실 때 이 중 어디에 해당하는지만 말씀해 주셔도 준비가 빨라집니다.
두 가지가 겹치는 경우도 있습니다. / 예를 들어 건전지가 약해진 상태에서 문틀까지 뻑뻑하면 모터가 걸쇠를 끝까지 당기지 못해 열림 소리만 나고 멈추기도 합니다.

# 문 앞에서 하지 말아야 할 것
문틈에 카드나 드라이버를 넣어 걸쇠를 밀어 보는 방법은 아파트 현관문에서는 거의 통하지 않습니다. / 오히려 문 테두리와 고무 패킹을 상하게 해 나중에 바람이 새는 문이 됩니다.
발로 차거나 어깨로 미는 것도 걸쇠를 더 꽉 물리게 할 뿐입니다. / 비밀번호를 연달아 틀리는 것도 입력 잠금만 길어지게 합니다.

# 진관동은 도착 시간을 먼저 말씀드립니다
진관동은 은평구 안에서도 위치에 따라 오가는 길이 길어질 수 있습니다. / 위치를 받으면 예상 도착 시간을 먼저 말씀드리니, 그동안은 복도보다 따뜻한 곳에서 기다리셔도 됩니다.
아파트 이름과 동, 호수, 공동현관 출입 방법을 함께 알려 주세요. / 밤 시간이면 경비실에 미리 말해 두시면 공동현관 통과가 수월합니다.

# 관리사무소 확인과 비용 안내
문을 열기 전에 사시는 분인지 확인합니다. / 신분증 주소나 우편물이 없다면 관리사무소에 세대 확인을 부탁드리는 방법이 아파트에서는 가장 깔끔합니다.
확인이 끝나면 원인과 도어락 상태를 보고 비용을 손대기 전에 먼저 말씀드립니다. / 동의하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다. 진행 순서는 [이용안내](guide.html)에 있습니다.

# 열린 뒤 원인별 마무리
전원이었다면 건전지를 모두 새것으로 갈고, 비밀번호였다면 새 번호를 넣은 뒤 바깥에서 한 번 더 눌러 봅니다. / 걸쇠나 모터 쪽이었다면 부품 상태를 보고 [도어락 수리](doorlock-repair.html)로 끝날지, [도어락 교체](doorlock-replace.html)가 나을지 말씀드립니다.
문틀이 원인이었다면 경첩과 받이를 함께 맞춰 같은 일이 다시 안 생기게 합니다. / 여는 방식이 궁금하시면 [현관문 개문](door-open.html)을 참고하세요.
@ 은평 진관동 아파트 현관문 개문 출장

# 진관동부터 은평 끝까지
진관동과 함께 구산동, 갈현동, 대조동, 불광동, 녹번동, 응암동, 수색동까지 은평구 전 지역을 다닙니다. / 서울, 경기 전 지역 24시간 출동합니다.
은평에서 다니는 동네는 [은평구 출장열쇠](seoul-eunpyeong.html), 다른 지역은 [출장 지역](area.html)에서 보세요.
