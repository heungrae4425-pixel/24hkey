# 인수동, 자정 넘어 문 앞에 섰다면
인수동은 북한산 자락 아래로 다세대 빌라와 단독주택이 이어지고, 수유역 쪽으로 내려가는 길을 따라 생활권이 펼쳐진 동네입니다. / 밤이 깊으면 골목이 조용해지고 산 쪽에서 내려오는 바람도 꽤 찹니다.
막차를 타고 수유역에서 내려 걸어 올라왔는데 번호판이 반응하지 않으면 머릿속이 하얘집니다. / 낮이라면 이웃이나 관리인에게 물어보겠지만 이 시간에는 그것도 쉽지 않습니다.
이 글은 인수동에서 한밤이나 새벽에 문이 막혔을 때 전화를 걸기 전후로 무엇을 하면 좋은지 순서대로 적었습니다. / 지금 문 앞이라면 두 번째와 세 번째 단락부터 읽으셔도 됩니다.
@ 인수동 새벽 현관문 잠김 출장열쇠

# 전화보다 먼저, 내 몸이 있을 자리
한겨울 새벽이나 비 오는 밤이라면 문 앞 계단에 오래 앉아 있지 마세요. / 산 가까운 골목은 바람이 차서 금방 몸이 식습니다.
빌라라면 계단실 안쪽이 바깥보다 낫습니다. / 단독주택이라 대문 밖에 서 있어야 한다면 큰길 쪽 밝은 곳이나 문을 연 편의점 근처에서 기다리는 편이 안전합니다.
휴대폰 배터리가 얼마 남았는지도 바로 확인해 주세요. / 남은 양이 적으면 화면 밝기를 낮추고, 통화와 문자 외에는 잠시 쓰지 않는 게 좋습니다.

# 휴대폰이 집 안에 있다면
휴대폰까지 안에 두고 나온 경우라면 사정이 더 급합니다. / 가까운 편의점이나 아직 불이 켜진 가게에 전화를 빌려 달라고 부탁해 보세요.
이웃 문을 두드리는 건 새벽에는 조심스럽습니다. / 평소 인사를 나누던 이웃이 아니라면 큰길 쪽 가게를 먼저 찾는 쪽이 서로 편합니다.
빌린 전화로 연락하실 때는 다시 걸 수 있는 번호인지 말씀해 주세요. / 도착 직전에 위치를 다시 여쭤볼 일이 있기 때문입니다.

# 통화가 연결되면 이 순서로 말해 주세요
늦은 시간 통화는 짧고 정확할수록 도착이 빨라집니다. / 아래 순서대로 말씀해 주시면 받는 쪽에서 되묻는 일이 줄어듭니다.
- 지금 있는 곳의 동네와 가까운 큰길이나 건물 특징
- 빌라인지, 단독주택인지, 몇 층인지
- 번호판이 꺼졌는지, 켜지는데 안 열리는지
- 집 안에 아이나 어르신, 반려동물이 있는지
- 신분증을 지금 가지고 있는지
골목이 굽은 곳은 내비게이션이 큰길에서 멈추는 경우가 있습니다. / 들어오는 길에 보이는 표지나 가게를 하나 알려주시면 헤매지 않습니다.

# 늦은 밤에 자주 생기는 막힘
새벽에 막히는 이유는 낮과 크게 다르지 않지만 몇 가지가 겹치기 쉽습니다. / 미리 알아 두면 전화로 설명하기가 수월합니다.
추운 밤에는 건전지 힘이 떨어져서 번호판이 아예 안 켜지거나 몇 번 깜빡이다 꺼집니다. / 피곤한 상태에서 번호를 여러 번 틀려 도어락이 입력을 잠시 막는 일도 많습니다.
집에 먼저 들어온 식구가 안쪽 걸쇠를 걸고 잠든 경우도 있습니다. / 이럴 때는 문을 열기 전에 안에 있는 식구와 연락이 닿는지부터 확인해 보세요.
@ 강북 인수동 한밤 도어락 번호판 꺼짐

# 9V 건전지는 지금 구할 수 있을 때만
번호판이 완전히 꺼졌다면 바깥쪽 아래 비상 전원 단자에 9V 건전지를 대 볼 수 있습니다. / 건전지를 대고 있는 동안 전원이 들어와 번호를 누를 수 있습니다.
다만 새벽에 문을 연 가게를 찾아 멀리 걸어가야 한다면 굳이 무리하지 마세요. / 그 사이에 전화를 걸어 두면 기다리는 시간이 겹쳐서 오히려 빠릅니다.
건전지를 대도 아무 반응이 없으면 더 붙잡고 있지 않는 게 좋습니다. / 단자 쪽이 젖었거나 몸체 안쪽 문제일 수 있습니다.

# 조용한 골목에서 피해야 할 행동
밤에 문이 안 열리면 손잡이를 세게 흔들거나 문을 두드리게 됩니다. / 소리도 크고 걸쇠가 더 꽉 물려서 열기가 어려워질 수 있습니다.
비밀번호를 계속 바꿔 가며 누르는 것도 멈춰 주세요. / 경고음이 길게 울리면 이웃이 놀라고, 도어락도 한동안 입력을 받지 않습니다.
드라이버나 카드로 문틈을 벌리는 건 낮이든 밤이든 권하지 않습니다. / 문틀이 상하면 열고 나서도 손볼 일이 늘어납니다.

# 기다리는 동안 챙겨 둘 것
전화를 끊고 기다리는 동안 신분 확인에 쓸 것을 미리 꺼내 두세요. / 지갑 속 신분증의 주소가 지금 집 주소와 같은지 한 번 봐 두시면 좋습니다.
주소가 다르다면 휴대폰에 저장된 전자 계약서나 주소가 찍힌 고지서 사진도 도움이 됩니다. / 빌라는 관리사무소가 없는 곳이 많아 이런 자료가 특히 중요합니다.
도착할 즈음 다시 전화를 드리면 지금 계신 곳을 한 번 더 알려 주세요. / 어두운 골목에서는 휴대폰 불빛을 잠깐 흔들어 주셔도 찾기 쉽습니다.

# 도착하면 먼저 확인부터 합니다
문을 여는 일이라 시간이 늦어도 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 집 안 식구와의 통화 중 하나로 확인할 수 있습니다.
확인이 되지 않으면 아무리 급해도 작업을 시작하지 않습니다. / 번거로우시겠지만 같은 건물에 사는 이웃 모두를 지키는 절차입니다.
진행 순서는 [이용안내](guide.html)에 자세히 적어 두었습니다.

# 새벽이라고 비용이 달라지나요
비용은 문과 도어락 상태를 본 뒤 작업 전에 먼저 말씀드립니다. / 들으시고 괜찮을 때만 시작하고, 원하지 않으시면 그대로 돌아갑니다.
끝내 문을 열지 못하면 비용은 받지 않습니다. / 작업 중 부품을 바꿔야 할 상황이 보이면 손대기 전에 따로 여쭤봅니다.
현관문을 어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.
@ 인수동 야간 출장열쇠 신분 확인 후 개문

# 문이 열린 뒤 바로 해 둘 일
배터리가 원인이었다면 그 자리에서 안쪽 건전지를 전부 새것으로 바꿔 두세요. / 하나만 바꾸면 며칠 뒤 같은 시간에 또 막힐 수 있습니다.
번호를 잊어 연 경우라면 새 번호를 등록하고 예전 번호는 지워 둡니다. / 졸린 상태라도 등록한 번호는 문을 열어 둔 채 두세 번 확인해 보세요.
도어락 자체가 말썽이었다면 날이 밝은 뒤 [도어락 수리](doorlock-repair.html)로 다시 점검받는 편이 안심됩니다. / 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 그때 상의하셔도 됩니다.

# 늦게 다니는 분께 권하는 작은 준비
야근이나 교대 근무로 늦게 들어오는 날이 많다면 몇 가지만 챙겨 두세요. / 새벽에 문 앞에서 막히는 일이 눈에 띄게 줄어듭니다.
- 가방 안주머니에 9V 건전지 하나
- 휴대폰에 출장열쇠 번호 저장
- 식구와 걸쇠 거는 시간 약속
- 겨울 들어서기 전 건전지 미리 교체

# 인수동 말고 강북구 어디든
인수동과 가까운 수유동, 우이동은 물론 미아동, 번동, 삼양동, 송중동까지 강북구 전체로 밤낮없이 갑니다. / 강북구에서 다니는 동네는 [강북구 출장열쇠](seoul-gangbuk.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

# 자주 묻는 질문
? 새벽 네 시에 전화해도 받나요? | 네, 24시간 받습니다. 시간 걱정하지 말고 걸어 주세요.
? 휴대폰이 꺼져 가는데 어떻게 하죠? | 위치와 상황을 먼저 짧게 말씀해 주시고, 도착 전까지는 휴대폰을 아껴 두세요.
? 신분증이 집 안에 있으면 어떻게 하나요? | 주소가 나온 고지서 사진이나 계약서, 식구와의 통화로 확인할 수 있는지 함께 찾아봅니다.
? 식구가 안에서 걸쇠를 걸고 잠들었어요. | 먼저 전화나 문자로 깨워 보시고, 그래도 안 되면 상황을 말씀해 주세요.
? 문을 못 열면 출장 온 비용을 내야 하나요? | 아닙니다. 열지 못하면 비용은 받지 않습니다.

# 마무리
인수동 밤길에서 문이 막혔다면 먼저 몸을 따뜻하고 밝은 곳에 두고, 위치와 문 상태를 차례대로 알려 주세요. / 혼자 오래 붙잡고 있는 것보다 일찍 전화하는 쪽이 대부분 빠릅니다.
24시출장열쇠는 산자락 골목의 늦은 새벽에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
