# 인수동 현관에 새 도어락을 달기로 했다면
인수동은 북한산 자락 아래로 다세대 빌라와 단독주택이 이어지고, 수유역 쪽으로 내려가는 길을 따라 생활권이 펼쳐진 동네입니다. / 오래 쓴 번호식 도어락을 바꾸면서 지문이나 카드가 되는 제품으로 넘어가려는 집이 많습니다.
매장이나 인터넷을 보면 기능 이름이 너무 많아 무엇이 우리 집에 필요한지 헷갈립니다. / 비싼 기능이 꼭 편한 기능은 아니어서, 고르는 순서를 잡아 두면 판단이 쉬워집니다.
이 글은 인수동에서 스마트 도어락을 고를 때 식구 생활과 동네 환경에 맞춰 따져 볼 것들을 정리했습니다.
@ 인수동 스마트 도어락 지문 카드 선택

# 식구들의 하루 동선을 먼저 그려 보기
제품 사진을 보기 전에 식구마다 하루에 몇 번, 어떤 손으로 문을 여는지 떠올려 보세요. / 고르는 기준은 결국 여기서 나옵니다.
- 아침 일찍 나가고 밤늦게 들어오는 식구가 있는지
- 학교 끝나고 혼자 들어오는 아이가 있는지
- 손힘이 약하거나 버튼이 잘 안 보이시는 어르신이 있는지
- 장바구니나 유모차를 자주 끌고 들어오는지
- 돌봄 선생님이나 가족이 정기적으로 드나드는지
한 사람에게 편한 방식이 다른 식구에게는 불편할 수 있습니다. / 그래서 한 가지 방식만 되는 제품보다 두세 가지를 함께 쓸 수 있는 제품이 무난합니다.

# 번호식, 가장 무난한 출발점
번호만 누르면 되는 방식은 따로 챙길 물건이 없어 누구나 쓰기 쉽습니다. / 손님에게 임시 번호를 알려 주기도 편합니다.
대신 번호가 퍼지기 쉽고, 손이 닿는 자리가 번호판에 남는다는 단점이 있습니다. / 번호 앞뒤에 아무 숫자를 섞어 눌러도 열리는 기능이 있는지 확인해 보세요.
식구들이 이미 번호식에 익숙하다면 번호를 기본으로 두고 다른 방식을 하나 더하는 쪽이 적응이 빠릅니다.

# 카드와 태그, 아이와 어르신에게
카드나 동그란 태그를 대기만 하면 열리는 방식은 번호를 외우기 어려운 식구에게 잘 맞습니다. / 아이 가방이나 어르신 열쇠고리에 달아 두면 번호를 잊을 걱정이 줄어듭니다.
잃어버리면 바로 지워야 한다는 점은 기억해 두세요. / 카드 한 장만 골라 지울 수 있는 제품인지, 전부 지우고 다시 등록해야 하는 제품인지도 살펴볼 만합니다.
@ 강북 인수동 도어락 카드키 태그 등록

# 지문, 손은 자유롭지만 계절을 탑니다
지문 방식은 아무것도 챙기지 않아도 되고 번호가 새어 나갈 걱정도 적습니다. / 짐을 들고 들어오는 일이 잦은 집에서 특히 편합니다.
다만 겨울에 손이 차고 건조하면 인식이 잘 안 되는 날이 있습니다. / 산바람이 매서운 인수동에서는 이 점을 미리 알고 고르시는 게 좋습니다.
손가락을 두세 개씩 등록해 두고, 번호나 카드 같은 다른 방법을 꼭 같이 쓰도록 하세요. / 어르신이나 어린아이는 지문이 얕아 인식률이 낮을 수 있습니다.

# 앱 연동, 정말 필요할까
휴대폰으로 출입 알림을 받거나 멀리서 문을 열어 주는 기능은 편리해 보입니다. / 아이 귀가를 확인하고 싶거나 부모님 댁 출입을 챙기려는 집이라면 쓸모가 큽니다.
그렇지 않다면 꼭 필요하지 않을 수 있습니다. / 공유기와 거리, 연결 모듈 자리, 휴대폰 설정까지 관리할 거리가 늘어나기 때문입니다.
쓰실 거라면 현관 앞에서 와이파이 신호가 얼마나 잡히는지 미리 확인해 두세요. / 벽이 두꺼운 단독주택은 신호가 약한 경우가 있습니다.

# 추운 산자락 동네라 더 볼 사양
인수동처럼 겨울이 찬 동네에서는 건전지가 빨리 지칩니다. / 건전지 칸을 쉽게 열 수 있는지, 잔량 경고가 넉넉히 미리 뜨는지 살펴보세요.
단독주택 대문이나 계단실이 바깥과 바로 통하는 빌라라면 바깥 몸체가 비와 눈에 강한지도 중요합니다. / 제품 설명에 방수나 사용 온도 범위가 적혀 있다면 꼭 확인해 보세요.
비상 전원 단자 위치도 미리 봐 두면 좋습니다. / 장갑 낀 손으로도 찾기 쉬운 자리에 있으면 한겨울에 덜 당황합니다.

# 손잡이 모양도 고르는 기준입니다
같은 방식이라도 손잡이 모양에 따라 쓰는 느낌이 크게 다릅니다. / 밀고 당기는 형은 한 손으로 열기 편하고, 레버형은 익숙한 동작이라 어르신이 편해하십니다.
손잡이가 따로 없는 버튼형은 몸체가 작아 좁은 현관에 잘 맞습니다. / 현관 공간과 식구 손 사용을 함께 놓고 고르시면 됩니다.
@ 인수동 현관 도어락 손잡이 형태 비교

# 비상 수단은 두 가지 이상
어떤 방식을 고르든 한 가지가 막혔을 때 쓸 다른 길이 있어야 합니다. / 지문이 안 될 때 번호, 번호를 잊었을 때 카드처럼 서로 받쳐 주는 구성이 좋습니다.
비상 열쇠가 함께 오는 제품이라면 보관할 곳을 정해 두세요. / 집 안에만 두면 정작 필요할 때 쓸 수 없으니 믿을 만한 식구에게 하나 맡겨 두는 방법도 있습니다.

# 기능 이름에 휘둘리지 않기
상세 설명에는 비슷한 보안 기능이 여러 이름으로 적혀 있습니다. / 이름보다 실제로 무엇을 막아 주는지를 보는 게 중요합니다.
- 번호를 섞어 눌러도 열리는지
- 연속으로 틀리면 입력을 잠시 막는지
- 안쪽에서 바깥 입력을 막는 기능이 있는지
- 문이 덜 닫혔을 때 알려 주는지
우리 집에 꼭 필요한 두세 가지가 있으면 충분합니다. / 쓰지 않을 기능이 많을수록 설정만 복잡해집니다.

# 사기 전에 문 사진부터
마음에 드는 제품을 골랐다면 주문하기 전에 문에 맞는지 확인해야 합니다. / 문 두께, 지금 뚫린 구멍, 보조키 유무에 따라 달 수 있는 제품이 달라집니다.
현관 바깥과 안쪽, 문 옆면 사진을 보내 주시면 맞는 범위를 먼저 알려 드립니다. / 자세한 확인 방법은 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.

# 설치와 교체는 이렇게 진행합니다
도착하면 사시는 분인지 신분증이나 우편물로 먼저 확인하고, 문 상태를 본 뒤 비용을 말씀드립니다. / 괜찮으실 때만 시작하고, 추가로 손볼 곳이 생기면 손대기 전에 따로 여쭤봅니다.
쓰던 도어락을 떼고 새 제품을 다는 과정은 [도어락 교체](doorlock-replace.html)에서 보실 수 있습니다. / 지금 제품이 고장만 났다면 [도어락 수리](doorlock-repair.html)로 해결되는지 먼저 봐 드립니다. / 전체 순서는 [이용안내](guide.html)에 있습니다.

# 인수동 말고 강북구 어디든
인수동과 이웃한 수유동, 우이동은 물론 번동, 미아동, 삼양동, 송중동까지 강북구 어디든 다닙니다. / 강북구 안내는 [강북구 출장열쇠](seoul-gangbuk.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
