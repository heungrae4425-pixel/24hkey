# 미아동, 주머니가 가벼운 걸 알아챈 순간
미아동은 미아역과 미아사거리역 사이로 아파트 단지와 빌라, 상가 건물이 넓게 이어진 강북구 중심 동네입니다. / 번호식 도어락이 흔해졌지만 빌라 보조키, 오래된 원룸 현관, 창고 문처럼 아직 열쇠를 쓰는 문이 꽤 남아 있습니다.
집 앞에서 열쇠를 찾으려고 가방을 뒤집어 봐도 없을 때가 있습니다. / 그 열쇠가 어딘가에 떨어졌는지, 아니면 집 안 신발장 위에 그대로 있는지에 따라 할 일이 꽤 달라집니다.
이 글은 미아동에서 열쇠 때문에 문 앞에 막혔을 때 두 경우를 나눠 정리했습니다. / 지금 당장 들어가야 한다면 [강북구 출장열쇠](seoul-gangbuk.html)로 바로 연락 주셔도 됩니다.
@ 미아동 열쇠 분실 현관문 잠김

# 잃어버린 걸까, 두고 나온 걸까
먼저 마지막으로 열쇠를 손에 쥐었던 때를 떠올려 보세요. / 집을 나서며 문을 잠근 기억이 분명하다면 밖에서 잃어버린 쪽이고, 문이 저절로 잠기는 구조라면 안에 두고 나왔을 수 있습니다.
- 문을 열쇠로 잠그고 나왔다 → 밖에서 잃어버린 쪽
- 문을 닫기만 했는데 자동으로 잠겼다 → 안에 두고 나왔을 수 있음
- 열쇠고리에 다른 열쇠도 함께 사라졌다 → 꾸러미째 분실
두 경우는 문을 여는 방법은 비슷하지만 열고 난 뒤 할 일이 다릅니다. / 그래서 처음에 이 구분을 해 두는 것이 좋습니다.

# 밖에서 잃어버렸다면 되짚어 볼 곳
오늘 들렀던 곳을 거꾸로 짚어 보세요. / 의외로 가까운 곳에서 찾는 일이 많습니다.
- 마지막으로 계산한 가게 계산대 주변
- 버스나 지하철을 탔다면 내린 역의 역무실
- 회사 책상 서랍이나 외투 주머니
- 차를 탔다면 좌석 틈과 문 옆 수납함
지하철에서 잃어버린 것 같다면 역무실에 물어보는 것도 방법입니다. / 다만 찾는 동안 집에 못 들어가는 시간이 길어질 수 있으니 문을 먼저 열고 천천히 찾으셔도 됩니다.

# 열쇠에 주소가 붙어 있었나요
열쇠고리에 이름표나 주소, 동 호수가 적혀 있었다면 조금 더 신경을 써야 합니다. / 주운 사람이 어느 집 열쇠인지 알 수 있기 때문입니다.
이 경우에는 문을 연 뒤 열쇠 구멍 부분인 실린더를 바꾸는 쪽을 권합니다. / 주소가 붙어 있지 않았고 길에서 잃어버린 것이라면 상황에 따라 판단하시면 됩니다.
앞으로는 열쇠고리에 주소 대신 휴대폰 번호 끝자리만 적어 두는 편이 낫습니다.
@ 강북 미아동 열쇠 실린더 교체 판단

# 안에 두고 문을 닫았다면
문이 닫히면서 저절로 잠기는 구조라면 열쇠를 안에 두고 나오기 쉽습니다. / 쓰레기를 버리러 잠깐 나오거나 택배를 받으러 나왔을 때 가장 많이 생깁니다.
이 경우 열쇠는 집 안에 있으니 문만 열면 끝납니다. / 실린더를 바꿀 필요는 없고, 다음부터 같은 일이 없게 습관만 바꾸면 됩니다.
식구 중 열쇠를 가진 사람이 가까이 있다면 먼저 연락해 보세요. / 퇴근 시간이 얼마 남지 않았다면 기다리는 게 나을 수도 있습니다.
상가 건물 위층 원룸처럼 건물 입구에 관리인이 있는 곳이라면 관리인에게 여벌 열쇠가 있는지도 물어보세요. / 관리인이 갖고 있는 열쇠로 열 수 있다면 출장을 부르지 않아도 됩니다.

# 문 앞에서 하지 말아야 할 것
열쇠가 없다고 철사나 카드로 열쇠 구멍을 쑤셔 보는 건 권하지 않습니다. / 안쪽 핀이 상하면 나중에 맞는 열쇠가 와도 잘 돌아가지 않습니다.
문틈에 드라이버를 넣어 벌리는 것도 피해 주세요. / 빌라 철문은 문틀이 휘기 쉬워 열고 나서 문이 제대로 닫히지 않게 됩니다.
이웃에게 비슷한 열쇠를 빌려 꽂아 보는 것도 소용이 없습니다. / 겉모양이 같아 보여도 안쪽 홈은 집마다 다릅니다.
억지로 꽂은 남의 열쇠가 안에서 걸려 빠지지 않으면 일이 두 배가 됩니다. / 손에 맞는 열쇠가 없을 때는 그냥 두는 게 가장 빠른 길입니다.

# 연락 주실 때 알려 주실 것
열쇠 문제는 문 모양을 알면 준비가 훨씬 빨라집니다. / 아래 내용을 짧게 말씀해 주세요.
- 미아동 어느 쪽인지, 아파트인지 빌라인지 상가 건물인지
- 잠긴 것이 손잡이 열쇠인지, 보조키인지, 둘 다인지
- 잃어버렸는지, 안에 두고 나왔는지
- 번호식 도어락도 함께 달린 문인지
열쇠 구멍 모양을 사진으로 보내 주시면 맞는 장비를 챙겨 갈 수 있습니다.

# 사시는 분인지 먼저 확인합니다
열쇠가 없는 상황에서 문을 여는 일이라 확인 절차가 꼭 필요합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 세대 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 문을 연 뒤 바로 보여 주시는 방식도 가능한지 상황을 보고 판단합니다. / 확인이 되지 않으면 작업을 시작하지 않습니다.

# 비용은 문을 열기 전에 말씀드립니다
문과 잠금장치 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 원하지 않으시면 그대로 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 전체 순서는 [이용안내](guide.html)에서 보실 수 있습니다.
@ 미아동 출장열쇠 보조키 열쇠 개문

# 열고 나서, 새로 맞출까 바꿀까
안에 두고 나온 경우라면 열쇠를 찾아 그대로 쓰시면 됩니다. / 여벌 열쇠가 하나뿐이었다면 이참에 하나 더 복사해 두세요.
밖에서 잃어버렸고 주소가 붙어 있었다면 실린더를 바꾸는 게 마음이 편합니다. / 문짝과 손잡이는 그대로 두고 열쇠 부분만 새것으로 바뀝니다.
열쇠 분실이 잦다면 열쇠 없이 쓰는 번호식이나 카드식으로 바꾸는 것도 생각해 볼 만합니다. / 제품을 바꾸는 일은 [도어락 교체](doorlock-replace.html)와 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.

# 세입자라면 집주인에게 알릴 것
빌라나 원룸에 사신다면 실린더를 바꾸기 전에 집주인에게 알려 두세요. / 집주인이 여벌 열쇠를 갖고 있는 경우가 많아, 바꾼 사실을 모르면 서로 곤란할 수 있습니다.
새 열쇠를 집주인에게 한 벌 드릴지는 서로 이야기해서 정하시면 됩니다. / 정한 내용은 문자로 남겨 두면 나중에 헷갈리지 않습니다.

# 같은 일을 줄이는 열쇠 습관
열쇠 문제는 작은 습관으로 많이 줄일 수 있습니다. / 아래 중 하나만 지켜도 문 앞에서 막히는 일이 드물어집니다.
- 나갈 때 휴대폰, 지갑, 열쇠를 한 번에 확인하는 순서 만들기
- 여벌 열쇠 하나는 가까이 사는 식구에게 맡기기
- 열쇠고리에 소리 나는 방울이나 눈에 띄는 고리 달기
- 자동으로 잠기는 문은 잠깐 나갈 때도 열쇠 챙기기

# 미아동 말고 강북구 어디든
미아동과 이웃한 송중동, 삼양동, 번동부터 수유동, 우이동, 인수동까지 강북구 전체로 24시간 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

? 보조키 열쇠만 잃어버렸어요. | 보조키만 따로 열고 실린더를 바꿀 수 있습니다. 보조키 모양 사진을 보내 주세요.
