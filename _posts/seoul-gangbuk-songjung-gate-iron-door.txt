# 송중동 골목, 집 문보다 바깥문이 먼저 막힐 때
송중동은 미아역과 미아사거리역 생활권 가까이에 빌라와 아파트, 단독주택이 함께 있는 동네입니다. / 빌라는 건물 입구에 공동 출입문이 있고, 주택은 길가에 철대문이 따로 서 있는 경우가 많습니다.
내 집 현관까지 가기도 전에 바깥문에서 막히면 당황스럽습니다. / 게다가 이 문은 나 혼자 쓰는 문이 아닐 때가 많아 함부로 손대기도 어렵습니다.
이 글은 송중동에서 공동 출입문과 철대문이 말썽일 때 문의 종류에 따라 무엇부터 할지 정리했습니다.
@ 송중동 빌라 공동 출입문 도어락

# 이 문은 누구의 문인가
바깥문 문제는 고치기 전에 관리하는 사람이 누구인지부터 따져야 합니다. / 그래야 연락할 사람과 비용을 나눌 사람이 분명해집니다.
- 여러 세대가 함께 쓰는 빌라 공동 출입문
- 우리 집 혼자 쓰는 단독주택 철대문
- 상가와 주택이 같이 쓰는 건물 입구 철문
- 마당을 나눠 쓰는 두세 집의 공용 대문
공동 출입문은 집주인, 건물 관리인, 입주민 대표 중 누가 맡고 있는지 알아 두세요. / 세입자라면 일단 집주인에게 알리는 게 순서입니다.

# 공동 출입문 번호가 안 먹힐 때
빌라 입구 번호식 도어락이 반응하지 않는다면 건전지부터 의심해 볼 만합니다. / 여러 세대가 하루에도 수십 번 드나드는 문이라 집 현관보다 건전지가 빨리 닳습니다.
번호판은 켜지는데 번호가 틀렸다고 나온다면 최근에 누가 번호를 바꿨을 수 있습니다. / 건물 단체 대화방이나 계단 게시물에 안내가 올라와 있는지 먼저 확인해 보세요.
늦은 밤이라 아무와도 연락이 닿지 않으면 같은 건물 이웃이 들어올 때를 기다리는 것도 방법입니다. / 다만 추운 날 오래 서 있어야 한다면 그때는 연락 주세요.

# 공동 번호를 아는 사람이 너무 많다면
택배, 배달, 수리 기사, 이사 업체까지 공동 출입문 번호를 아는 사람은 시간이 갈수록 늘어납니다. / 번호가 퍼진 것 같으면 입주민끼리 상의해 정기적으로 바꾸는 편이 좋습니다.
바꿀 때는 한 사람이 맡아 바꾸고, 모든 세대에 같은 날 알리도록 정해 두세요. / 알림을 못 받은 세대가 밤늦게 문 앞에서 막히는 일이 가장 흔한 문제입니다.
@ 강북 송중동 공동현관 번호 변경

# 철대문 자물쇠가 뻑뻑해졌다면
단독주택 철대문은 비와 눈을 그대로 맞아 열쇠 구멍 안쪽에 녹과 먼지가 쌓입니다. / 열쇠가 반쯤만 들어가거나 돌릴 때 힘이 많이 든다면 그 신호입니다.
열쇠 구멍에 마른 흑연 가루나 열쇠 전용 윤활제를 조금 넣고 열쇠를 몇 번 꽂았다 빼 보세요. / 식용유나 일반 기름은 먼지를 끌어당겨 나중에 더 뻑뻑해집니다.
그래도 돌아가지 않으면 힘으로 비틀지 마세요. / 열쇠가 부러져 안에 박히면 일이 더 커집니다.

# 대문이 처져 걸쇠가 안 맞을 때
오래된 철대문은 무게 때문에 경첩이 조금씩 내려앉습니다. / 문을 들어 올리듯 당겨야 겨우 잠기거나 열린다면 대문 처짐을 의심해 보세요.
대문 아래가 바닥에 끌린 자국이 있는지, 위쪽 틈이 넓어졌는지 보면 짐작할 수 있습니다. / 이런 경우 자물쇠만 바꿔서는 해결되지 않고 경첩과 걸쇠 받이 위치를 함께 맞춰야 합니다.
잠깐씩 들어 올려 쓰다 보면 손잡이와 자물쇠까지 상합니다. / 불편함이 느껴질 때 일찍 점검을 받는 편이 결국 손이 덜 갑니다.

# 바람에 쾅 닫히는 바깥문
송중동처럼 골목이 길게 이어진 곳은 바람이 한 방향으로 몰아치는 날이 있습니다. / 공동 출입문이나 대문이 바람에 세게 닫히면 걸쇠와 도어락이 충격을 받습니다.
공동 출입문에 도어클로저가 달려 있다면 닫히는 속도가 너무 빠르지 않은지 봐 주세요. / 속도 조절은 관리하는 분과 상의한 뒤 조금씩 맞추는 게 좋습니다.
철대문은 열어 둘 때 고정 고리를 꼭 걸어 두세요. / 반쯤 열린 채 바람에 흔들리면 경첩이 빨리 처집니다.

# 겨울 아침, 철문이 얼어붙었다면
밤사이 눈비가 내린 뒤 기온이 떨어지면 철대문 틈이나 열쇠 구멍이 얼기도 합니다. / 열쇠가 들어가지 않거나 손잡이가 굳은 느낌이면 얼어붙은 경우일 수 있습니다.
뜨거운 물을 붓는 건 피해 주세요. / 잠깐 녹았다가 더 단단히 얼고, 철문 도장도 상합니다.
손으로 열쇠를 잠시 따뜻하게 쥐었다가 천천히 꽂아 보는 정도가 무난합니다. / 그래도 안 되면 무리하지 말고 연락 주세요.
공동 출입문 번호판도 추운 아침에는 반응이 느려집니다. / 겨울 들어서기 전에 관리하는 분께 건전지 교체를 한 번 부탁드려 두면 출근길 막힘을 줄일 수 있습니다.
@ 송중동 단독주택 철대문 자물쇠 점검

# 바깥문 출장 요청 때 말씀하실 것
바깥문은 현관과 달라서 상황 설명이 조금 더 필요합니다. / 아래를 말씀해 주시면 맞는 부품과 장비를 챙겨 갑니다.
- 공동 출입문인지, 우리 집 대문인지
- 번호식인지, 열쇠식인지, 둘 다 있는지
- 문이 철문인지 유리문인지, 처진 느낌이 있는지
- 관리하는 분에게 연락이 됐는지
사진 한두 장이면 대부분 가늠할 수 있습니다.
공동 출입문이라면 건물 이름이나 입구 옆 표지를, 철대문이라면 대문 색깔이나 옆집과 구별되는 특징을 함께 알려 주세요. / 비슷한 건물이 이어진 골목에서는 이 한마디가 도착 시간을 꽤 줄여 줍니다.

# 공동 출입문은 확인 절차가 조금 다릅니다
집 현관을 열 때는 사시는 분인지 신분증 주소나 우편물로 확인합니다. / 공동 출입문은 그 건물에 사시는 분이 맞는지 같은 방식으로 확인하고, 수리나 교체는 관리하는 분과 이야기된 경우에 진행합니다.
비용은 상태를 본 뒤 손대기 전에 먼저 말씀드립니다. / 끝내 열지 못하면 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html)에서 보실 수 있습니다.

# 고칠지 바꿀지 판단하는 기준
녹이 조금 슬었거나 걸쇠 위치만 틀어졌다면 손봐서 쓰는 경우가 많습니다. / 이럴 때는 [도어락 수리](doorlock-repair.html) 쪽으로 먼저 봐 드립니다.
공동 출입문 도어락이 자주 꺼지거나 철대문 자물쇠가 심하게 삭았다면 교체를 생각해 볼 때입니다. / 바깥문용 제품을 고르는 일은 [도어락 교체](doorlock-replace.html)와 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.
집 현관까지 함께 막혔다면 [현관문 개문](door-open.html)으로 이어서 진행합니다.

# 송중동 말고 강북구 어디든
송중동과 붙어 있는 미아동, 삼양동, 번동부터 수유동, 우이동, 인수동까지 강북구 전체로 다닙니다. / 강북구 안내는 [강북구 출장열쇠](seoul-gangbuk.html), 다른 지역은 [출장 지역](area.html)에 있습니다.

# 자주 묻는 질문
? 세입자인데 공동 출입문을 고쳐 달라고 직접 불러도 되나요? | 여는 일은 가능하지만 수리나 교체는 집주인이나 관리하는 분과 먼저 이야기해 주세요.
? 철대문 열쇠 구멍에 기름을 넣어도 되나요? | 일반 기름은 먼지가 엉겨 더 뻑뻑해집니다. 흑연 가루나 열쇠 전용 윤활제를 쓰세요.
? 공동 출입문 번호는 얼마나 자주 바꾸면 좋을까요? | 정해진 주기보다 번호가 많이 퍼졌다고 느낄 때 입주민끼리 상의해 바꾸시면 됩니다.
? 대문이 처져서 들어 올려야 잠겨요. | 경첩 처짐일 가능성이 높아 자물쇠와 함께 경첩, 걸쇠 받이를 같이 봐야 합니다.
? 얼어붙은 철문에 뜨거운 물을 부어도 되나요? | 다시 얼어 더 굳을 수 있어 권하지 않습니다.

# 마무리
