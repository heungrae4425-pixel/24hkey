# 송중동 우리 집 번호, 누구에게 얼마나 알려 줄까
송중동은 미아역과 미아사거리역 생활권 가까이에 빌라와 아파트, 주택이 함께 있는 동네입니다. / 맞벌이 가정이나 어르신을 모시는 집이 많아서 낮 시간에 다른 사람이 집에 드나드는 일이 흔합니다.
아이 하원을 도와주는 선생님, 일주일에 몇 번 오시는 가사도우미, 부모님 댁을 살펴 주는 요양보호사처럼 믿고 맡기는 분들이 있습니다. / 그런데 가족이 쓰는 번호를 그대로 알려 주면 나중에 정리하기가 어렵습니다.
이 글은 송중동 집에서 손님과 돌봄 인력에게 임시 비밀번호를 쓰는 방법을 정리했습니다. / 도어락 설정이 막히거나 번호가 꼬였을 때는 [강북구 출장열쇠](seoul-gangbuk.html)로 연락 주셔도 됩니다.
@ 송중동 도어락 임시 비밀번호 설정

# 가족 번호를 그대로 주면 생기는 일
한 번 알려 준 번호는 그분이 그만둔 뒤에도 기억 속에 남습니다. / 악의가 없더라도 메모해 둔 종이나 휴대폰 메모가 다른 사람 눈에 띌 수 있습니다.
가족 번호를 바꾸려고 하면 식구 모두에게 새 번호를 알려야 하는 번거로움도 따라옵니다. / 그래서 처음부터 사람마다 번호를 따로 쓰는 것이 깔끔합니다.
번호를 따로 두면 문제가 생겼을 때 어느 번호로 열렸는지 짐작하기도 쉽습니다. / 열림 기록을 보여 주는 제품이라면 누가 언제 다녀갔는지까지 확인할 수 있어서 서로 오해할 일이 줄어듭니다.

# 우리 집 도어락이 번호를 몇 개 받는지 확인
요즘 도어락은 비밀번호를 여러 개 등록할 수 있는 제품이 많습니다. / 반대로 오래된 제품은 번호를 하나만 받는 경우도 있습니다.
배터리 덮개 안쪽이나 설명서에 등록 버튼과 방법이 적혀 있으니 먼저 살펴보세요. / 제품 이름을 알면 제조사 안내에서 방법을 찾기도 쉽습니다.
- 사용자 번호를 여러 개 받는 제품
- 한 번만 쓰고 사라지는 일회용 번호 기능이 있는 제품
- 카드나 태그를 여러 장 등록할 수 있는 제품
- 휴대폰 앱으로 방문자 번호를 보내는 제품
우리 집 제품이 어떤 쪽인지 알면 아래 방법 가운데 맞는 것을 고를 수 있습니다.

# 일회용 번호는 손님에게
친척이 잠깐 들르거나 택배 기사님께 물건을 안에 넣어 달라고 할 때는 일회용 번호가 잘 맞습니다. / 한 번 열고 나면 번호가 저절로 사라지는 방식이라 따로 지울 필요가 없습니다.
이 기능이 없는 제품이라면 잠깐 쓸 번호를 하나 등록했다가 그날 저녁에 지우는 방법을 쓰면 됩니다. / 지우는 걸 잊지 않도록 휴대폰 알람을 맞춰 두세요.
명절처럼 친척이 며칠 머무는 경우라면 머무는 동안만 쓸 번호를 하나 정해 두고 떠나는 날 지우시면 됩니다.

# 정기적으로 오시는 분께는 전용 번호를
매주 오시는 가사도우미나 돌봄 선생님께는 그분만 쓰는 번호를 따로 등록해 드리는 것이 좋습니다. / 가족 번호와 다르게 정하면 일을 그만두실 때 그 번호 하나만 지우면 끝납니다.
번호 대신 카드나 태그를 한 장 드리는 방법도 있습니다. / 카드는 돌려받기 쉽고, 잃어버렸다면 그 카드만 등록에서 빼면 됩니다.
@ 강북 송중동 돌봄 인력 카드키 등록

# 어르신 댁에 오는 요양보호사라면
부모님 댁에 매일 요양보호사가 오신다면 번호보다 카드가 편할 때가 많습니다. / 어르신이 번호를 바꾸셨다는 사실을 잊으셔도 카드는 그대로 쓸 수 있기 때문입니다.
담당 선생님이 바뀌면 카드를 돌려받고 새 분께 다른 카드를 드리면 됩니다. / 돌려받지 못한 카드는 그날 바로 지워 주세요.
멀리 사는 자녀분이라면 도어락 앱 연동 제품을 고려해 볼 수도 있습니다. / 누가 언제 문을 열었는지 확인할 수 있어 마음이 놓인다는 분들이 많습니다.

# 번호를 정할 때 피할 것
임시 번호라도 쉽게 짐작되는 번호는 피해 주세요. / 동 호수, 생일, 같은 숫자 반복, 1234 같은 번호는 지나가던 사람도 떠올릴 수 있습니다.
- 집 주소와 이어지는 숫자는 쓰지 않기
- 가족 번호와 앞자리를 똑같이 하지 않기
- 문자로 보낸 번호는 상대가 확인한 뒤 지우도록 부탁하기
- 번호판에 손자국이 남지 않게 가끔 닦아 두기
번호를 누르기 전이나 후에 아무 숫자를 더 섞어 누를 수 있는 기능이 있다면 함께 알려 드리세요. / 옆에서 누가 보고 있어도 진짜 번호를 알아채기 어렵습니다.

# 그만두실 때 꼭 정리할 것
정기적으로 오시던 분이 그만두시면 그분 번호와 카드부터 정리합니다. / 미루다 보면 누구 번호가 아직 살아 있는지 잊어버리게 됩니다.
번호 하나만 지우는 방법을 모르겠다면 전체를 지우고 가족 번호만 다시 등록하는 방법도 있습니다. / 이때는 가족 모두가 집에 있을 때 하시는 게 좋습니다.
정리한 날짜와 내용을 냉장고 옆 메모판 같은 곳에 적어 두면 다음 번에 헷갈리지 않습니다.

# 설정이 꼬였을 때
번호를 등록하다가 기존 번호까지 지워져 문 밖에서 막히는 일이 가끔 있습니다. / 등록 중에는 문을 열어 둔 채로 작업하시면 이런 일을 피할 수 있습니다.
- 등록 버튼을 오래 누르면 초기화되는 제품이 있으니 주의
- 등록 후 문을 닫기 전에 새 번호로 한 번 열어 보기
- 경고음이 계속 나면 배터리 상태부터 확인
문 밖에서 막혔다면 번호를 여러 번 누르지 말고 연락 주세요. / 틀린 입력이 쌓이면 한동안 입력이 막힙니다.

# 문을 열러 가면 이렇게 진행합니다
도착하면 사시는 분이 맞는지 신분증이나 주소가 적힌 우편물로 먼저 확인합니다. / 돌봄 선생님 혼자 계신 상황이라면 가족분과 통화로 확인하는 과정을 거칩니다.
문과 도어락을 보고 비용을 먼저 말씀드리고, 괜찮으시면 시작합니다. / 끝내 못 열면 비용은 받지 않습니다. / 자세한 순서는 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 있습니다.

# 사람이 자주 드나드는 집에 맞는 도어락
번호를 하나만 받는 오래된 도어락이라면 사람별 관리가 어렵습니다. / 여러 사람이 드나드는 집이라면 사용자 번호를 여러 개 받거나 카드를 쓰는 제품으로 바꾸는 것도 생각해 볼 만합니다.
지금 도어락이 멀쩡하다면 굳이 바꾸지 않으셔도 됩니다. / 고장이 잦다면 [도어락 수리](doorlock-repair.html), 바꿀 때가 됐다면 [도어락 교체](doorlock-replace.html) 안내를 참고해 주세요.
@ 송중동 다중 사용자 도어락 교체 상담
