# 수유동, 문은 열리는데 알림만 조용하다면
수유동은 수유역을 중심으로 상가와 골목 안 빌라, 단독주택, 아파트가 함께 어울린 동네입니다. / 아이 하교 시간이나 부모님 댁 출입을 휴대폰으로 확인하려고 알림 기능이 있는 도어락을 쓰는 집도 늘었습니다.
그런데 어느 날부터 아이가 들어왔는데도 알림이 오지 않거나, 앱을 열면 기기가 연결되지 않았다는 문구만 뜨기도 합니다. / 문이 잘 열리고 닫히니 고장인지 아닌지 헷갈립니다.
이 글은 수유동에서 도어락 알림과 앱 연동이 끊겼을 때 집에서 차례로 확인할 것과 점검을 부를 시점을 정리했습니다.
@ 수유동 스마트 도어락 앱 알림 연동

# 먼저 문 자체는 정상인지 나누기
앱 문제와 도어락 문제는 따로 생각하는 게 좋습니다. / 번호, 카드, 지문으로 문이 평소처럼 열리고 잠긴다면 잠금 기능은 살아 있는 것입니다.
이 경우 급하게 문을 열 일은 없습니다. / 차분히 연결 쪽만 하나씩 보면 됩니다.
반대로 알림이 끊긴 즈음부터 번호판 반응도 느리고 경고음이 났다면 건전지부터 의심해 보세요. / 많은 제품이 건전지가 약해지면 통신 기능을 먼저 줄여 잠금 기능을 지킵니다.

# 연결 방식이 무엇인지 알아 두기
알림이 오는 도어락은 대개 둘 중 하나의 방식으로 휴대폰과 이어집니다. / 어떤 방식인지에 따라 확인할 곳이 다릅니다.
- 도어락이 집 공유기에 직접 붙는 방식
- 안쪽 몸체나 거실 콘센트에 따로 꽂는 연결 모듈을 거치는 방식
- 휴대폰이 가까이 있을 때만 블루투스로 이어지는 방식
블루투스만 쓰는 방식이라면 밖에서 알림을 받지 못하는 게 정상입니다. / 설명서나 앱의 기기 정보 화면에서 방식을 먼저 확인해 보세요.

# 공유기와 도어락 사이 거리
현관은 집 안에서 공유기와 가장 먼 곳인 경우가 많습니다. / 수유동 단독주택처럼 현관과 거실 사이에 벽이 여러 겹이면 신호가 약해지기 쉽습니다.
공유기를 옮기거나 새로 바꾼 뒤부터 알림이 끊겼다면 이게 원인일 가능성이 큽니다. / 공유기 이름이나 비밀번호가 바뀌면 도어락은 예전 정보로 계속 접속하려다 실패합니다.
현관 앞에 서서 휴대폰 와이파이 세기를 봐 두세요. / 휴대폰에서도 신호가 한두 칸이라면 도어락은 더 약하게 받고 있을 수 있습니다.

# 공유기 주파수 설정도 확인
요즘 공유기는 두 가지 주파수를 함께 내보내는 경우가 많습니다. / 도어락 같은 작은 기기는 그중 한쪽만 지원하는 제품이 있습니다.
휴대폰이 다른 쪽 주파수에 붙어 있는 상태에서 등록하면 연결이 되지 않기도 합니다. / 설명서에 적힌 지원 주파수를 확인하고 그 이름의 와이파이로 다시 등록해 보세요.
@ 강북 수유동 현관 도어락 와이파이 신호

# 연결 모듈이 있다면 전원부터
따로 꽂는 연결 모듈을 쓰는 집이라면 모듈의 불빛을 먼저 보세요. / 콘센트가 빠졌거나 멀티탭 스위치가 꺼져 있는 일이 의외로 많습니다.
청소하다 멀티탭을 옮겼거나 대청소 뒤 다른 자리에 꽂았다면 거리가 멀어졌을 수도 있습니다. / 모듈은 현관과 공유기 사이 중간쯤에 두는 편이 안정적입니다.
모듈 전원을 뽑았다 다시 꽂고 몇 분 기다린 뒤 앱을 새로 고침해 보세요. / 그래도 안 되면 앱에서 모듈만 다시 등록하는 메뉴가 있는지 찾아봅니다.

# 휴대폰 쪽 알림 설정
도어락과 연결은 살아 있는데 알림만 오지 않는다면 휴대폰 설정을 의심해 보세요. / 휴대폰을 바꾸거나 운영체제를 업데이트한 뒤 알림 권한이 꺼지는 일이 있습니다.
- 휴대폰 설정에서 해당 앱 알림 허용 확인
- 배터리 절약 모드에서 앱이 제외돼 있는지
- 방해 금지 시간대에 알림이 막혀 있지 않은지
- 앱 안의 출입 알림 항목이 켜져 있는지
식구 휴대폰 중 한 대만 알림이 안 온다면 그 휴대폰 설정 문제일 가능성이 높습니다.

# 식구 계정과 공유 권한
알림을 받는 휴대폰이 여러 대라면 앱에서 공유 권한이 어떻게 설정돼 있는지도 봐야 합니다. / 처음 등록한 사람만 관리 권한을 갖고, 나머지는 초대를 받아야 알림이 오는 제품이 많습니다.
관리자로 등록한 식구가 휴대폰을 바꾸면서 앱 계정을 새로 만들었다면 공유가 끊길 수 있습니다. / 관리자 휴대폰에서 다시 초대를 보내 주세요.
@ 수유동 도어락 앱 가족 공유 설정

# 이사 들어온 집이라면 이전 계정부터
수유동에서 전세나 월세로 새로 들어온 집이라면 도어락이 이전 사시던 분 계정에 묶여 있을 수 있습니다. / 이 상태로는 새로 등록이 되지 않거나, 출입 기록이 엉뚱한 사람에게 갈 수도 있습니다.
집주인이나 이전 세입자에게 연락해 계정에서 기기를 지워 달라고 부탁하는 게 먼저입니다. / 연락이 어렵다면 안쪽 몸체 초기화가 필요한데, 이때는 등록된 번호와 카드도 함께 지워집니다.

# 초기화 버튼은 마지막에
앱이 안 된다고 바로 초기화 버튼을 누르는 분이 있습니다. / 초기화를 하면 비밀번호, 카드, 지문이 모두 지워질 수 있어서 식구들이 다시 들어오지 못하는 일이 생깁니다.
초기화를 하더라도 반드시 문을 열어 둔 상태에서 하고, 바로 새 번호부터 등록해 주세요. / 방법이 헷갈리면 직접 하기보다 점검을 부르는 편이 안전합니다.

# 이럴 땐 점검을 받아 보세요
연결 문제처럼 보여도 도어락 안쪽 통신 부품이 상한 경우도 있습니다. / 아래에 해당하면 [도어락 수리](doorlock-repair.html)로 상태를 보시길 권합니다.
- 공유기 가까이 옮겨도 연결이 전혀 안 될 때
- 건전지를 새로 넣은 뒤에도 앱에 기기가 안 보일 때
- 알림 기능과 함께 번호판 반응도 불안정할 때
- 앱에서 문 열기 명령이 들어갔다 안 들어갔다 할 때
연동 기능이 처음부터 없는 제품을 바꾸고 싶다면 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html)에서 방식을 비교해 보실 수 있습니다.

# 문까지 안 열린다면
앱 문제와 함께 문까지 열리지 않는 상황이라면 그때는 연락 주세요. / 도착하면 사시는 분인지 신분증이나 주소가 적힌 우편물로 먼저 확인하고, 비용을 말씀드린 뒤 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 수유동 말고 강북구 어디든
수유동과 이웃한 인수동, 우이동, 번동, 미아동, 삼양동, 송중동까지 강북구 전체로 다닙니다. / 강북구 안내는 [강북구 출장열쇠](seoul-gangbuk.html), 다른 지역은 [출장 지역](area.html)에 있습니다.
