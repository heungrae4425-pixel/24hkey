# 우이동 현관문이 열렸다고 끝난 게 아닙니다
우이동은 북한산으로 오르는 길목을 따라 단독주택과 다세대 빌라가 모여 있는 강북구 끝자락 동네입니다. / 산이 가까워 겨울바람이 차고 습기도 많은 편이라 현관 잠금장치가 계절을 많이 탑니다.
문이 안 열려 한참 애태우다 겨우 열리면 그 순간 긴장이 풀립니다. / 그래서 왜 안 열렸는지 따져 보지 않고 그냥 들어가 버리는 경우가 많습니다.
그런데 원인을 그대로 두면 며칠 뒤 같은 자리에서 같은 일이 되풀이됩니다. / 이 글은 우이동에서 문을 연 직후 꼭 확인할 것과 다시 막히지 않게 하는 습관을 정리했습니다. / 점검이 필요하시면 [강북구 출장열쇠](seoul-gangbuk.html)로 연락 주세요.
@ 우이동 현관문 개방 후 도어락 점검

# 열린 문을 바로 닫지 마세요
문이 열리면 일단 활짝 연 채로 두고 안쪽 상태부터 봅니다. / 원인을 모른 채 문을 닫았다가 다시 잠기면 처음으로 돌아가게 됩니다.
특히 도어락이 이상하게 반응해서 열린 경우라면 안쪽 손잡이로 여닫기를 몇 번 해 보세요. / 걸쇠가 매끄럽게 들어가고 나오는지 확인한 다음에 문을 닫아도 늦지 않습니다.

# 원인에 따라 확인할 곳이 다릅니다
왜 안 열렸는지에 따라 점검할 곳이 달라집니다. / 아래에서 우리 집 경우를 찾아 해당하는 것만 보셔도 됩니다.
- 배터리가 다 됐던 경우: 건전지 전부 교체, 단자 녹 확인
- 비밀번호를 잊었던 경우: 새 번호 등록, 이전 번호 삭제
- 걸쇠가 안 빠졌던 경우: 문틀 받이 쇠판, 경첩 처짐 확인
- 열쇠가 안 돌았던 경우: 실린더 먼지와 열쇠 휘어짐 확인
- 안쪽 보조키가 걸렸던 경우: 걸쇠 위치와 사용 습관 점검
원인이 두 가지 이상 겹쳐 있는 경우도 있습니다. / 하나만 고치고 끝내지 말고 나머지도 한 번씩 봐 주세요.

# 배터리는 일부가 아니라 전부
배터리 때문에 문이 안 열렸다면 건전지를 모두 새것으로 바꿔야 합니다. / 몇 개만 바꾸면 남은 헌 건전지가 새 건전지 힘까지 끌어내립니다.
배터리 칸을 열었을 때 하얀 가루나 녹이 보이면 마른 천으로 닦아 주세요. / 단자가 더러우면 새 건전지를 넣어도 전원이 고르게 들어가지 않습니다.
우이동처럼 기온이 낮은 동네는 겨울이 오기 전에 미리 갈아 두는 편이 좋습니다. / 바꾼 날짜를 배터리 덮개 안쪽에 적어 두면 다음 교체 때를 놓치지 않습니다.

# 비밀번호는 새로, 이전 것은 지우기
번호를 잊어 문을 열었다면 새 번호를 등록하는 것까지 마쳐야 끝입니다. / 새 번호만 더하고 이전 번호를 그대로 두면 누가 어떤 번호를 아는지 다시 헷갈립니다.
등록하는 동안 문은 열어 둡니다. / 새 번호로 바깥에서 한 번 열어 보고 나서 닫으시면 안전합니다.
@ 강북 우이동 비밀번호 재등록 확인

# 걸쇠와 문틀은 눈으로 확인
문을 반쯤 닫은 상태에서 걸쇠가 문틀 받이 쇠판 구멍 가운데로 들어가는지 봐 주세요. / 위나 아래 가장자리에 닿는다면 문이 처졌거나 쇠판이 어긋난 겁니다.
쇠판 둘레에 긁힌 자국이 반짝이면 그동안 걸쇠가 힘겹게 드나들었다는 신호입니다. / 그대로 두면 다시 걸쇠가 물려 문이 안 열리는 일이 생깁니다.
경첩 나사가 풀렸는지도 함께 확인합니다. / 문을 연 상태에서 손잡이를 위아래로 흔들어 덜컹거림이 느껴지면 손볼 때입니다.

# 열쇠를 쓰는 문이라면
우이동 주택은 대문이나 현관을 열쇠로 여는 집이 아직 많습니다. / 열쇠가 잘 안 돌았던 문이라면 열쇠구멍 안에 먼지와 흙이 쌓였을 가능성이 높습니다.
- 마른 흑연 가루 같은 윤활제를 조금만 넣고 열쇠를 몇 번 돌리기
- 휘거나 금 간 열쇠는 바로 새로 맞추기
- 복사본을 다시 복사한 열쇠는 원래 열쇠로 새로 맞추기
기름을 넣으면 먼지가 들러붙어 오히려 더 뻑뻑해집니다. / 대문 열쇠구멍이 비를 직접 맞는다면 덮개를 다는 것도 도움이 됩니다.

# 문 여는 과정에서 손댄 곳 확인
출장으로 문을 열었다면 작업한 부분을 함께 확인합니다. / 도어락 외관, 손잡이, 문틀에 이상이 없는지 그 자리에서 같이 봐 주세요.
부품을 바꿨다면 새 부품이 잘 움직이는지, 이전 부품과 어떻게 다른지 설명을 들어 두시면 좋습니다. / 궁금한 점은 그 자리에서 물어보시는 게 가장 확실합니다.
직접 열었다면 문틈에 무언가를 끼웠던 자리가 휘지 않았는지도 살펴보세요.

# 여벌 열쇠와 비상 수단 챙기기
한 번 막혀 본 집은 다음 비상 수단을 준비해 두는 게 좋습니다. / 큰 비용이 드는 것이 아니라 작은 준비 몇 가지입니다.
- 9V 건전지 하나를 가방이나 차에 넣어 두기
- 여벌 열쇠나 카드는 믿을 만한 가족에게 맡기기
- 비밀번호를 가족 한 명과 공유해 두기
- 출장열쇠 번호를 휴대폰에 저장하기
현관 앞 화분 아래나 우편함에 여벌 열쇠를 숨기는 건 권하지 않습니다. / 누구나 먼저 떠올리는 곳이기 때문입니다.
@ 우이동 여벌 열쇠와 비상 전원 준비

# 산 가까운 집이라 더 챙길 것
북한산 쪽 집은 해가 일찍 지고 밤 기온이 빨리 떨어집니다. / 안팎 온도 차이로 현관문 안쪽에 물방울이 맺히면 도어락 안쪽 몸체에도 습기가 스며듭니다.
문을 연 날 번호판이나 안쪽 몸체에 물기가 보였다면 마른 수건으로 닦고 잠시 말려 두세요. / 현관 근처에 젖은 우산이나 등산 장비를 오래 두지 않는 것만으로도 습기가 꽤 줄어듭니다.
낙엽과 흙먼지가 많은 계절에는 대문 열쇠구멍과 도어락 아래쪽 틈을 가끔 털어 주세요. / 작은 이물질이 쌓여 걸쇠 움직임을 방해하는 일이 생각보다 많습니다.

# 고칠지 바꿀지 판단하기
문을 열고 점검해 보면 도어락을 계속 써도 될지 판단이 섭니다. / 원인이 배터리나 번호 문제였다면 대부분 그대로 쓰셔도 됩니다.
같은 고장이 짧은 간격으로 반복되거나 부품을 구하기 어려운 오래된 제품이라면 바꾸는 것을 생각해 볼 만합니다. / 손볼 곳이 분명하면 [도어락 수리](doorlock-repair.html), 바꿀 때가 됐다면 [도어락 교체](doorlock-replace.html)를 참고해 주세요.

# 점검을 부탁하실 때
직접 확인하기 어렵다면 점검만 따로 부탁하셔도 됩니다. / 도착하면 사시는 분이 맞는지 신분증이나 주소가 적힌 우편물로 먼저 확인합니다.
상태를 보고 비용을 먼저 말씀드리고, 괜찮으시면 그때 손봅니다. / 문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 우이동 말고 강북구 어디든
우이동 옆 인수동, 수유동부터 번동, 미아동, 삼양동, 송중동까지 강북구 전체로 출동합니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

# 자주 묻는 질문

? 배터리를 몇 개만 바꿔도 될까요? | 전부 바꾸셔야 합니다. 헌 건전지가 섞이면 금방 다시 꺼질 수 있습니다.
? 걸쇠 쪽에 긁힌 자국이 있어요. | 문이 처졌거나 받이 쇠판이 어긋났을 수 있습니다. 미루지 말고 점검을 받아 보세요.
? 열쇠구멍에 식용유를 넣어도 되나요? | 권하지 않습니다. 먼지가 엉겨서 더 뻑뻑해집니다. 마른 윤활제를 조금만 쓰세요.
? 점검만 따로 받아도 되나요? | 네, 점검만 부탁하셔도 됩니다. 상태를 보고 필요한 것만 말씀드립니다.

# 마무리
우이동에서 문이 열렸다면 그 자리에서 원인을 짚고, 배터리와 번호, 걸쇠와 문틀, 열쇠 상태를 차례로 확인해 주세요. / 몇 분만 들이면 같은 문 앞에서 다시 막히는 일을 막을 수 있습니다.
