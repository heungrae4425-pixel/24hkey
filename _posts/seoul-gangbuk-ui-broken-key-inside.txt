# 우이동 대문 앞에서 열쇠가 똑 하고 부러졌다면
우이동은 북한산 자락 아래로 단독주택과 다세대가 이어지는 강북구 북쪽 동네입니다. / 수유역에서 산 쪽으로 올라갈수록 대문이나 현관을 아직 열쇠로 여는 집이 많습니다.
오래 쓴 열쇠는 겉보기에 멀쩡해도 목 부분에 가는 금이 가 있는 경우가 있습니다. / 그런 열쇠를 평소처럼 돌리다가 손에는 머리만 남고 몸통이 구멍 안에 박히는 일이 생깁니다.
이 글은 우이동에서 열쇠가 부러졌을 때 무엇을 하지 말아야 하는지, 그리고 [강북구 출장열쇠](seoul-gangbuk.html)가 어떤 순서로 처리하는지 적었습니다.
@ 우이동 열쇠구멍 부러진 열쇠 빼내기

# 손에 남은 열쇠 머리는 주머니에 넣어 두세요
부러진 머리 쪽 조각은 새 열쇠를 맞출 때 중요한 단서가 됩니다. / 이의 모양과 열쇠 종류를 확인할 수 있어서 버리지 말고 챙겨 두시는 게 좋습니다.
같은 열쇠가 꾸러미에 하나 더 있다면 그것도 함께 보여 주세요. / 여벌이 있으면 조각을 뺀 뒤 바로 문을 열 수 있습니다.
여벌 열쇠를 가족이나 이웃에게 맡겨 둔 기억이 있다면 지금 연락해 보세요. / 조각을 빼는 동안 여벌이 도착하면 새 열쇠를 맞추는 일까지 한 번에 정리할 수 있습니다.
머리 조각을 들고 이리저리 맞춰 보는 것도 조심해야 합니다. / 부러진 면이 날카로워서 손을 베기 쉬우니 휴지에 싸서 보관해 주세요.

# 핀셋이나 실핀을 넣고 싶어도 참아 주세요
조각 끝이 살짝 보이면 집에 있는 핀셋이나 머리핀으로 집어내고 싶어집니다. / 그런데 열쇠구멍 안은 아주 좁아서 집으려는 순간 조각이 더 깊이 밀려 들어가기 쉽습니다.
- 접착제를 묻힌 막대를 넣으면 구멍 안이 굳어 버림
- 드라이버로 비틀면 안쪽 핀이 휘어 실린더를 바꿔야 함
- 다른 열쇠를 위에 꽂아 돌리면 조각이 끼어서 더 단단해짐
- 망치로 두드리면 문과 잠금장치가 같이 상함
조각이 밖으로 반쯤 나와 손가락으로 쉽게 잡히는 경우만 살살 당겨 보시고, 아니면 그대로 두세요.

# 부러지는 열쇠에는 이유가 있습니다
열쇠가 부러지는 건 대부분 열쇠보다 잠금장치 쪽에서 먼저 신호를 보낸 결과입니다. / 돌릴 때 뻑뻑했던 날이 여러 번 있었다면 안쪽에 먼지가 쌓였거나 핀이 닳았을 가능성이 높습니다.
우이동처럼 산이 가까운 동네는 겨울에 기온이 많이 떨어집니다. / 차가워진 쇠 열쇠는 잘 휘지 않고 부러지기 쉬워서 추운 아침에 이런 일이 더 잦습니다.
복사한 열쇠를 다시 복사해서 쓰는 집도 조심해야 합니다. / 여러 번 거친 열쇠는 이 모양이 조금씩 어긋나서 구멍 안에서 힘을 더 받게 됩니다.

# 지금 문이 잠긴 상태인지, 열린 상태인지
조각이 박힌 순간 문이 잠긴 쪽이었는지 열린 쪽이었는지에 따라 할 일이 다릅니다. / 열리던 중이었다면 문이 이미 열려 있을 수도 있으니 손잡이를 살짝 당겨 보세요.
문이 열려 있다면 서둘 필요는 없습니다. / 문을 닫지 말고 그대로 둔 채 연락 주시면 집 안쪽에서 실린더를 풀어 보는 방법도 있습니다.
잠긴 상태라면 집 안에 들어갈 다른 길이 있는지 먼저 떠올려 보세요. / 뒷문이나 다른 출입구가 있는 단독주택이라면 그쪽으로 들어가 안에서 여는 것이 가장 간단합니다.
@ 강북 우이동 대문 실린더 점검

# 전화하실 때 알려 주실 것
우이동은 골목이 굽고 비탈이 있어서 위치를 자세히 알려 주시면 찾기가 쉽습니다. / 차가 들어오기 어려운 골목이면 가까운 큰길을 같이 말씀해 주세요.
- 대문인지 현관문인지, 철문인지 나무문인지
- 열쇠 조각이 구멍 밖으로 보이는지
- 지금 문이 잠긴 상태인지 열린 상태인지
- 같은 문에 도어락이 함께 달려 있는지
- 손에 남은 열쇠 머리 사진
사진을 문자로 보내 주시면 열쇠 종류를 미리 알 수 있어 맞는 공구를 챙겨 갑니다.

# 도착해서 먼저 하는 일
문 앞에 도착하면 사시는 분이 맞는지부터 확인합니다. / 신분증 주소나 주소가 적힌 우편물, 임대차 계약서 가운데 하나를 보여 주시면 됩니다.
서류가 집 안에 있다면 이웃이나 집주인 확인으로 대신하는 방법도 함께 찾아봅니다. / 확인 없이 문을 열지는 않으니 번거로우셔도 양해 부탁드립니다.
그다음 열쇠구멍 안을 작은 불빛으로 비춰 조각이 어느 깊이에 있는지 살핍니다. / 조각 방향과 이가 보이는 쪽을 확인하고 나서 어떤 방법을 쓸지 설명드립니다.

# 비용 이야기는 작업 전에 끝냅니다
조각만 빼면 되는지, 실린더를 바꿔야 하는지 보고 먼저 알려 드립니다. / 들어 보시고 원하실 때만 시작합니다.
조각을 빼고도 문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 손대기 전에 따로 여쭤봅니다.

# 조각은 이렇게 빼냅니다
얇은 전용 공구를 열쇠 이 사이로 넣어 조각을 걸어서 천천히 끌어냅니다. / 안쪽 핀이 다치지 않게 힘을 나눠 쓰는 것이 중요합니다.
조각이 깊이 박혔거나 녹이 슬어 붙어 있으면 실린더를 풀어서 빼는 방법을 씁니다. / 어느 쪽이든 문과 잠금장치가 덜 상하는 방법부터 시도합니다.
대문처럼 바깥에 있는 잠금은 녹과 흙먼지가 섞여 있는 경우가 많습니다. / 조각을 뺀 다음 구멍 안을 한 번 털어 내고 나서 열쇠가 끝까지 들어가는지 확인합니다.
현관문을 여는 과정 전반은 [현관문 개문](door-open.html), 열쇠 관련 안내는 [열쇠 출장](key-call.html) 페이지에 적어 두었습니다.

# 빼낸 뒤 새 열쇠 맞추기
조각을 빼고 나면 실린더가 부드럽게 도는지 확인합니다. / 안쪽이 닳아 있으면 새 열쇠를 맞춰도 같은 일이 다시 생길 수 있어서 상태를 솔직하게 말씀드립니다.
실린더가 괜찮다면 남은 조각과 머리를 기준으로 새 열쇠를 맞춰 드립니다. / 오래된 대문이라 열쇠를 자주 잃어버리셨다면 이참에 [도어락 설치](doorlock-install.html)를 함께 상담하셔도 됩니다.
@ 우이동 새 열쇠 맞춤과 실린더 교체

# 다시 부러지지 않게 하려면
열쇠가 뻑뻑하게 돌기 시작하면 그때가 손볼 때입니다. / 억지로 돌리는 날이 쌓이면 열쇠든 실린더든 어느 한쪽이 먼저 버티지 못합니다.
- 열쇠구멍에는 흑연 가루처럼 마른 윤활제만 쓰기
- 휘거나 금 간 열쇠는 바로 새로 맞추기
- 열쇠 꾸러미를 너무 무겁게 매달지 않기
- 겨울 아침에는 열쇠를 손으로 잠깐 데운 뒤 돌리기
기름을 넣으면 먼지가 엉겨 붙어서 오히려 더 뻑뻑해집니다. / 대문 열쇠구멍이 비를 직접 맞는다면 작은 덮개를 달아 두는 것도 도움이 됩니다.

# 우이동 말고 강북구 다른 동네도
우이동과 맞닿은 인수동, 수유동은 물론 번동, 미아동, 삼양동, 송중동까지 강북구 어디든 갑니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

# 자주 묻는 질문

? 부러진 열쇠로 새 열쇠를 만들 수 있나요? | 조각 상태가 괜찮으면 그걸 기준으로 맞출 수 있습니다. 머리 쪽 조각을 버리지 말아 주세요.
? 실린더를 꼭 바꿔야 하나요? | 조각을 빼고 실린더가 잘 돌면 바꾸지 않아도 됩니다. 안쪽이 상했을 때만 말씀드립니다.
? 산 쪽 골목 안인데 차가 못 들어가요. | 가까운 큰길에 차를 두고 걸어서 갑니다. 큰길 위치를 함께 알려 주시면 됩니다.
? 조각을 못 빼서 문도 못 열면 어떻게 되나요? | 그런 경우 비용은 받지 않습니다.
