# 둔촌동 세 들어 사는 집, 도어락이 말썽일 때
둔촌동은 새 아파트 단지가 들어선 동네라 새로 입주하면서 전세나 월세로 들어온 집도 적지 않습니다. / 새 집이든 오래된 집이든 도어락이 고장 나면 누가 연락하고 누가 비용을 낼지부터 고민이 됩니다.
이 문제는 집마다 계약 내용과 고장 원인이 달라 한 줄로 답하기 어렵습니다. / 그래서 이 글은 정답을 정해 드리기보다, 양쪽이 대화하기 전에 확인해 두면 좋은 것들을 순서대로 모았습니다.
법적인 판단이 필요한 부분은 계약서와 전문 상담 창구를 통해 확인하시길 권합니다. / 여기서는 출장 현장에서 자주 보는 상황과 [강동구 출장열쇠](seoul-gangdong.html)를 부를 때 도움이 되는 정리법을 적었습니다.
@ 둔촌동 전월세 도어락 고장 정리

# 먼저 지금 급한 일인지 나누기
문이 안 열려 집에 못 들어가는 상황이라면 비용 이야기는 잠시 미뤄 두셔도 됩니다. / 사는 사람이 집에 들어가는 게 먼저이고, 정리는 문을 연 뒤에 해도 늦지 않습니다.
반대로 문은 열리는데 잠금이 불안하거나 경고음이 계속 나는 정도라면 시간 여유가 있습니다. / 이때는 집주인과 먼저 연락해 어떻게 할지 이야기한 뒤 부르시는 편이 정리가 깔끔합니다.

# 계약서에서 찾아볼 문장
계약서 특약에 수리나 시설물에 관한 문장이 있는지 먼저 살펴보세요. / 소모품은 누가, 큰 고장은 누가 맡는다는 식으로 적어 둔 경우가 있습니다.
- 시설물 수리 책임에 대한 특약 문장
- 입주할 때 도어락 상태를 적은 기록이 있는지
- 열쇠, 카드키를 몇 개 받았는지 적은 부분
- 퇴거할 때 원상 복구에 대한 문장
특약이 없거나 애매하다면 그 자체를 집주인과 이야기할 출발점으로 삼으면 됩니다. / 해석이 엇갈릴 때는 지역 상담 창구나 전문가에게 물어보시는 게 안전합니다.

# 고장 원인을 기록으로 남기기
누가 비용을 낼지는 결국 왜 고장 났는지와 이어지는 경우가 많습니다. / 그래서 원인을 짐작할 수 있는 기록을 남겨 두는 게 양쪽 모두에게 도움이 됩니다.
도어락 앞면과 안쪽 몸체, 배터리 칸, 문 옆면을 사진으로 찍어 두세요. / 경고음이나 이상한 소리가 난다면 짧은 영상도 좋습니다.
언제부터 증상이 있었는지, 배터리는 언제 갈았는지도 날짜로 메모해 두면 대화가 수월합니다. / 기억에만 의존하면 서로 다른 이야기를 하게 되기 쉽습니다.
@ 강동 둔촌동 도어락 고장 사진 기록

# 배터리와 소모품, 고장의 차이
배터리가 다 돼 번호판이 꺼진 것은 대개 사는 사람이 챙기는 일로 여겨집니다. / 다만 이것도 집마다 약속이 다를 수 있으니 계약서와 대화로 확인하세요.
오래 써서 모터나 기판이 닳은 경우, 처음부터 불량이 있던 경우, 사용 중 부딪혀 깨진 경우는 서로 다르게 볼 여지가 있습니다. / 출장 기사가 현장에서 본 상태를 설명해 드릴 수는 있지만, 누구 책임인지 판단해 드리지는 않습니다.
현장에서 보이는 사실, 예를 들어 배터리 상태, 부품 마모, 외관 파손 여부는 사진과 함께 정리해 드릴 수 있습니다. / 그 자료를 가지고 두 분이 이야기하시면 됩니다.

# 세입자가 먼저 연락할 때
- 집주인에게 증상과 사진을 먼저 보내기
- 문이 안 열리는 급한 상황이면 출장부터 부르고 집주인에게 알리기
- 작업 전 비용 안내를 받아 집주인과 공유하기
- 작업 뒤 영수증과 작업 내용 보관하기
문자나 메신저로 남긴 연락은 나중에 기록이 됩니다. / 전화로 이야기했다면 짧게라도 내용을 문자로 다시 정리해 보내 두세요.

# 집주인이 먼저 연락받았을 때
세입자에게 증상을 듣고 사진을 받아 보시면 어떤 일인지 짐작이 됩니다. / 직접 업체를 정해 보내고 싶으시면 그 뜻을 세입자에게 빨리 알려 주시는 게 좋습니다.
집주인이 출장을 부르시는 경우에도 문을 여는 작업이라면 현장에서 거주 확인을 합니다. / 세입자가 함께 있거나 통화로 확인해야 진행할 수 있습니다.
@ 둔촌동 집주인 세입자 도어락 수리 연락

# 대화할 때 서로 편한 방식
도어락 문제는 금액이 크지 않아도 서운한 마음이 쌓이기 쉬운 일입니다. / 누가 잘못했는지보다 지금 상태와 해결 방법을 먼저 이야기하면 대화가 부드러워집니다.
사진과 날짜를 먼저 공유하고, 비용 안내를 받은 뒤 함께 정하는 순서가 무난합니다. / 서로 바쁘다면 정해진 시간에 짧게 통화하기로 약속해 두는 것도 좋습니다.
의견이 끝내 맞지 않으면 감정적으로 밀어붙이기보다 제삼자의 도움을 받는 편이 낫습니다. / 지역의 주택 관련 상담 창구를 이용해 보시는 것도 방법입니다.

# 현장에서 확인하는 절차
문을 여는 일이면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 임대차 계약서, 관리사무소 세대 확인 중 하나면 됩니다.
전입 신고 전이라 신분증 주소가 다르다면 계약서를 보여 주셔도 됩니다. / 이사 직후에 이런 경우가 많아 미리 챙겨 두시면 좋습니다.

# 비용 안내는 시작 전에
도어락 상태를 보고 비용을 먼저 말씀드립니다. / 집주인과 상의가 필요하시면 그 자리에서 통화하실 시간을 드립니다.
동의하실 때 시작하고, 문을 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 교체 전에 따로 여쭤봅니다.
작업이 끝나면 어떤 일을 했는지 적은 영수증을 드립니다. / 그대로 집주인께 전달하시면 정리가 쉽습니다.

# 수리로 갈지 교체로 갈지
양쪽 부담을 생각하면 고쳐서 쓸 수 있는지부터 보는 게 좋습니다. / 배터리 칸 접점, 손잡이 연결부, 문틀 쇠판처럼 간단한 곳은 [도어락 수리](doorlock-repair.html)로 끝나는 경우가 많습니다.
부품이 단종됐거나 같은 고장이 반복된다면 [도어락 교체](doorlock-replace.html)를 함께 상의합니다. / 교체할 때는 문 두께와 기존 구멍을 보고 맞는 제품을 고르니 집주인 의견을 미리 들어 두시면 좋습니다.

# 번호와 카드키 관리는 누가
세입자가 바뀔 때 번호와 카드키 정리는 꼭 필요합니다. / 새로 들어오는 분은 입주 당일 번호를 새로 등록하고, 받은 카드키 개수를 확인해 두세요.
- 입주 때 받은 카드키, 열쇠 개수를 사진으로 남기기
- 이전 세입자 번호와 카드는 모두 지우기
- 퇴거 때 받은 개수 그대로 돌려 드리기
번호 등록이나 카드 정리가 어렵다면 연락 주세요. / 현장에서 기존 등록을 지우고 새로 등록해 드립니다.

# 둔촌동 말고 강동구 어디든
둔촌동 옆 길동, 성내동, 천호동은 물론 명일동, 고덕동, 상일동, 강일동, 암사동도 다닙니다. / 진행 방식은 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
@ 둔촌동 출장열쇠 도어락 교체 상담
