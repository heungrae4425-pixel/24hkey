# 강일동 현관 앞에서 숫자가 떠오르지 않을 때
강일동은 강동구 안에서도 아파트가 많이 모인 동네라 현관마다 번호식 도어락이 달려 있습니다. / 고덕역 쪽 생활권과 이어져 있어 출퇴근길에 비밀번호 때문에 발이 묶였다는 연락이 들어오곤 합니다.
매일 손가락이 기억하던 번호가 어느 날 갑자기 막히는 일은 생각보다 흔합니다. / 피곤한 날, 새 휴대폰 비밀번호와 헷갈린 날, 가족이 번호를 바꾸고 말을 안 한 날이 대표적입니다.
이 글은 강일동에서 번호를 잊었을 때 문 앞에서 해볼 일과 [강동구 출장열쇠](seoul-gangdong.html)를 부르는 시점을 순서대로 적었습니다.
@ 강일동 도어락 비밀번호 분실 출장 개방

# 번호를 잊은 건지, 바뀐 건지부터 나눠 보기
비슷해 보여도 두 경우는 푸는 길이 다릅니다. / 내가 잊은 거라면 기억을 더듬어 볼 여지가 있고, 누가 바꾼 거라면 그 사람에게 연락하는 게 가장 빠릅니다.
최근 집에 누가 드나들었는지 떠올려 보세요. / 배우자, 자녀, 부모님, 수리 기사처럼 번호를 만질 수 있었던 사람이 있었다면 바뀐 쪽일 가능성이 큽니다.
아무도 손댄 적이 없다면 내 기억이 엉킨 경우가 많습니다. / 이때는 조급하게 숫자를 이어 누르지 않는 게 중요합니다.

# 오입력 잠금이 걸리기 전에 멈추세요
대부분의 도어락은 틀린 번호가 몇 번 이어지면 일정 시간 동안 입력을 받지 않습니다. / 경고음이 길게 울리면서 버튼이 먹통이 되는데, 고장이 아니라 보호 기능입니다.
잠금이 걸린 상태에서 계속 누르면 기다리는 시간만 늘어납니다. / 두세 번 해보고 안 되면 손을 떼고 아래 방법으로 넘어가 주세요.
번호를 누를 때마다 버튼 소리가 나는지도 같이 봐 두면 좋습니다. / 소리가 안 나는 버튼이 있다면 기억이 아니라 버튼 문제일 수도 있습니다.

# 기억을 되살리는 작은 요령
가장 먼저 해볼 것은 예전 번호입니다. / 번호를 바꾸고 얼마 안 됐다면 손이 옛 번호를 누르고 있을 수 있습니다.
- 바꾸기 전에 쓰던 번호를 한 번 눌러 보기
- 휴대폰 메모, 가족 단체 대화방에 남긴 기록 찾아보기
- 끝자리에 별표나 확인 버튼을 빠뜨리지 않았는지 보기
- 숫자 앞뒤에 덧붙이는 허수 입력 기능을 쓰고 있었는지 떠올리기
번호 앞뒤에 아무 숫자나 붙여 엿보기를 막는 기능을 쓰는 집도 있습니다. / 이 경우 입력 방식 자체를 잊어 막히기도 하니 평소 누르던 손 모양을 천천히 떠올려 보세요.

# 가족이 번호를 바꿨다면 연락이 먼저
가족 중 누가 번호를 바꿨다면 전화 한 통으로 끝날 일입니다. / 연락이 닿지 않으면 그 사람이 돌아올 시간을 가늠해 보고 기다릴지 정하시면 됩니다.
아이가 장난으로 설정 버튼을 눌러 번호가 바뀐 경우도 있습니다. / 안쪽 몸체의 등록 버튼은 손이 닿기 쉬운 곳에 있어 아이가 여러 번 누르다 보면 바뀌기도 합니다.
부모님 댁처럼 따로 사는 집이라면 근처에 사는 형제자매가 번호를 아는지 물어보세요. / 강동구 안에 가족이 산다면 기다리는 편이 문을 여는 것보다 빠를 수도 있습니다.

# 카드나 지문이 등록돼 있는지 확인하기
번호만 막혔을 뿐 다른 열림 방법이 살아 있는 집이 많습니다. / 강일동 아파트에서 쓰는 밀고 당기는 형 도어락은 카드나 지문을 같이 쓰는 제품이 흔합니다.
지갑 속 카드키, 가족의 지문이 등록돼 있다면 그쪽으로 먼저 열어 보세요. / 열쇠 구멍이 있는 제품이라면 비상 열쇠를 어디 뒀는지도 떠올려 볼 만합니다.
@ 강동 강일동 현관 도어락 카드키 지문 확인

# 힘으로 해결하려는 시도는 피해 주세요
번호가 막히면 손잡이를 흔들거나 문틈에 무언가를 끼우고 싶어집니다. / 그렇게 하면 도어락 외관과 문틀에 흠이 생기고 나중에 수리 범위가 커집니다.
도어락을 분해하려고 바깥 나사를 찾는 분도 계십니다. / 바깥쪽은 일부러 분해가 어렵게 만들어져 있어 부품만 상하고 열리지는 않습니다.

# 출장열쇠를 부르는 게 나은 순간
아래에 해당하면 혼자 붙잡고 있기보다 전화 주시는 편이 낫습니다.
- 번호를 바꾼 가족과 오늘 안에 연락이 어려울 때
- 카드나 지문 같은 다른 방법이 등록돼 있지 않을 때
- 집 안에 불을 켜 둔 가스레인지나 혼자 있는 아이가 있을 때
- 밤이 늦어 기다릴 곳이 마땅치 않을 때
전화 주실 때 도어락 제조사 이름이나 모양을 알려주시면 맞는 장비를 챙겨 갑니다. / 번호판 사진 한 장이면 더 정확합니다.
기다리시는 동안 엘리베이터 앞이나 단지 안 밝은 곳에 계셔 주세요. / 도착 직전에 다시 전화를 드려 계신 곳을 확인합니다.
@ 강동구 강일동 출장열쇠 번호 분실 출동

# 강일동 위치 알려주실 때
아파트가 많은 동네라 동과 호수를 정확히 말씀해 주시면 헤매지 않습니다. / 공동현관 비밀번호가 따로 있다면 그것도 미리 알려주세요.
공동현관 번호까지 기억이 안 나면 경비실이나 관리사무소에 먼저 연락해 두시면 수월합니다. / 늦은 밤에는 경비실에 출장 기사가 온다고 말해 두시는 것도 도움이 됩니다.

# 문을 열기 전에 하는 확인
현관을 여는 일이라 사시는 분이 맞는지 꼭 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소의 세대 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 문을 연 직후 안에서 보여 주셔도 되는지 먼저 상의합니다. / 확인이 끝나기 전에는 작업을 마무리하지 않습니다.

# 비용 이야기는 시작 전에
도어락 종류와 문 상태를 보고 비용을 먼저 말씀드립니다. / 들으시고 괜찮을 때만 시작하고, 아니라면 그대로 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 번호 재등록처럼 추가로 필요한 일이 생기면 그때 따로 여쭤봅니다.

# 열린 뒤 새 번호를 정하는 법
문이 열리면 안쪽에서 기존 번호를 지우고 새 번호를 등록해 드립니다. / 가족 모두가 쓸 번호라면 그 자리에서 같이 정하시는 게 좋습니다.
@ 강일동 도어락 비밀번호 재등록 점검
- 생일, 전화번호 끝자리처럼 짐작하기 쉬운 숫자는 피하기
- 정한 번호는 가족만 보는 곳에 짧게 적어 두기
- 번호를 바꿀 사람은 꼭 단체 대화방에 알리기로 약속하기
- 카드나 지문을 하나 더 등록해 두기
도어락이 너무 오래돼 번호 등록이 자꾸 실패한다면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 고치기 어려운 상태일 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 강일동 말고 강동구 어디든
강일동 옆 상일동, 고덕동, 명일동은 물론 암사동, 천호동, 성내동, 길동, 둔촌동까지 다닙니다. / 문 열기 진행 방식은 [현관문 개문](door-open.html)에, 이용 순서는 [이용안내](guide.html)에 정리해 두었습니다.
다른 구나 경기 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
