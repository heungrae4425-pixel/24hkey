# 명일동 첫 한파 아침, 번호판이 느릿느릿할 때
기온이 영하로 뚝 떨어진 아침이면 도어락이 평소와 다르게 굼뜨게 움직이는 집이 생깁니다. / 번호를 누르고 한참 뒤에야 소리가 나거나, 모터가 힘없이 돌다 멈추기도 합니다.
명일동은 강동구 아파트 생활권에 속해 현관 도어락을 쓰는 집이 대부분입니다. / 현관 앞이 바깥과 바로 이어진 복도식 구조라면 바깥바람이 그대로 들어 추위의 영향을 더 많이 받습니다.
이 글은 명일동에서 한파 때 도어락이 이상할 때 추위 탓인지 가려내는 법과, 그래도 안 열릴 때 [강동구 출장열쇠](seoul-gangdong.html)를 부르는 순서를 정리했습니다.
@ 명일동 한파 도어락 반응 느림

# 추위가 도어락에 하는 일
도어락에 들어가는 건전지는 추우면 힘이 약해집니다. / 같은 배터리라도 따뜻한 날에는 넉넉하던 힘이 영하에서는 모자라게 됩니다.
그래서 배터리가 반쯤 남은 상태라면 한파 첫날 갑자기 경고음이 울리거나 번호판이 꺼지기도 합니다. / 날이 풀리면 다시 괜찮아져 그냥 넘어가기 쉬운데, 이건 배터리가 거의 다 됐다는 신호입니다.
추위는 문과 문틀에도 영향을 줍니다. / 철문은 차가워지면서 조금 줄어들고, 걸쇠와 문틀 구멍 사이가 빡빡해지거나 반대로 헐거워집니다.

# 추위 탓일 때 보이는 모습
아래 모습이 아침에만 나타나고 낮에는 사라진다면 추위의 영향일 가능성이 큽니다.
- 번호를 누르면 소리가 한 박자 늦게 남
- 번호판 불이 흐리게 켜지거나 깜빡임
- 모터 소리가 평소보다 느리고 둔함
- 문이 열리기는 하는데 손잡이가 뻑뻑함
- 문 안쪽 금속 부분에 서리가 낌
반대로 날씨와 상관없이 늘 그렇다면 추위보다는 배터리나 부품 자체를 의심해 봐야 합니다. / 언제 그런지 기억해 두시면 원인을 좁히기 쉽습니다.
@ 강동 명일동 겨울 도어락 번호판 깜빡임

# 문 앞에서 바로 해볼 것
번호판이 느리게라도 반응한다면 손바닥으로 번호판을 감싸 잠시 데워 보세요. / 몇십 초만 지나도 반응이 조금 나아지는 경우가 있습니다.
입김을 직접 불어 넣는 건 피해 주세요. / 따뜻한 숨이 차가운 번호판에 닿으면 물방울이 맺혀 오히려 오작동이 생길 수 있습니다.
번호판이 아예 꺼졌다면 바깥 아래쪽 9V 비상 단자에 건전지를 대 보세요. / 주머니에 넣어 따뜻하게 한 건전지가 힘을 더 잘 냅니다.

# 걸쇠가 문틀에 물려 있을 때
번호가 인식되고 모터 소리는 나는데 문이 안 열린다면 걸쇠가 문틀에 빡빡하게 물린 경우일 수 있습니다. / 추위로 문이 줄어들면서 생기는 일입니다.
문을 안쪽으로 살짝 밀거나 몸 쪽으로 당기면서 다시 번호를 눌러 보세요. / 걸쇠에 걸린 힘이 빠지면 모터가 쉽게 당겨 문이 열립니다.
몇 번 해도 같다면 반복하지 말고 멈추세요. / 추운 날 모터를 계속 돌리면 배터리가 더 빨리 닳고 기어에도 무리가 갑니다.

# 뜨거운 물과 드라이기는 금물
드라이기나 뜨거운 물로 도어락을 녹이려는 분이 계십니다. / 급격한 온도 변화로 안쪽에 물이 맺혀 기판이 상할 수 있습니다.
열쇠 구멍에 뜨거운 물을 붓는 것도 피해 주세요. / 물이 구멍 안에 남아 다시 얼면 다음 날 더 큰 문제가 됩니다.
문을 세게 흔들거나 발로 차는 것도 마찬가지입니다. / 추운 날 금속은 평소보다 약해져 손잡이 축이 쉽게 휩니다.
라이터 불로 열쇠를 데워 넣는 방법도 들어 보셨겠지만 권하지 않습니다. / 열쇠 구멍 주변 플라스틱이 녹거나 그을음이 남을 수 있습니다.

# 추운 문 앞에서 버티지 않아도 될 때
- 비상 전원을 대도 번호판이 켜지지 않을 때
- 번호판은 켜지는데 모터가 아예 안 돌 때
- 밤새 영하라 문 앞에서 오래 기다리기 힘들 때
- 어르신이나 아이와 함께 밖에 있을 때
한파 때는 비슷한 연락이 겹칠 수 있습니다. / 위치를 받으면 도착 예상 시간을 먼저 말씀드리니, 그동안 단지 안 따뜻한 곳에서 기다려 주세요.
@ 명일동 출장열쇠 한파 현관문 개방

# 명일동에서 전화 주실 때
- 아파트 동과 호수, 복도식인지 계단식인지
- 번호판 상태와 비상 전원을 대 봤는지
- 마지막으로 배터리를 간 때
- 문 앞에서 기다릴 수 있는 곳이 있는지
도어락 사진을 보내 주시면 제품에 맞는 장비를 챙겨 갑니다. / 공동현관 번호가 있다면 미리 알려주세요.
휴대폰 배터리도 추위에 빨리 닳으니 통화는 짧게 하시고 주머니 안쪽에 넣어 두세요. / 도착 전에 다시 연락드릴 때 전화가 꺼져 있으면 찾기 어려워집니다.

# 도착 후 진행
먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
그다음 비용을 먼저 말씀드리고 동의하실 때 시작합니다. / 못 열면 비용은 받지 않습니다.
여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다. / 추운 날일수록 문과 도어락이 상하지 않게 천천히 진행합니다.

# 열린 뒤에는 배터리부터
한파에 말썽을 부렸다면 배터리를 모두 새것으로 바꾸는 게 첫 번째입니다. / 아직 남은 것 같아도 겨울을 버티기엔 모자란 경우가 많습니다.
배터리 칸에 서리나 물기가 있으면 마른 천으로 닦고 완전히 마른 뒤 넣어 주세요. / 단자에 녹이 보이면 함께 닦아 냅니다.
새 배터리를 넣고 나면 문을 몇 번 열고 닫아 보며 모터 소리를 들어 봅니다. / 소리가 또렷하고 빨라졌다면 추위와 약해진 배터리가 겹친 경우였던 겁니다.
걸쇠가 문틀에 자주 물린다면 문틀 쇠판 위치를 조금 조정합니다. / 이런 작업은 [도어락 수리](doorlock-repair.html)에서 하는 일과 같습니다.

# 복도식 현관이라면 더 신경 쓸 것
바깥바람이 그대로 들어오는 복도식 현관은 겨울에 도어락이 더 빨리 지칩니다. / 배터리 교체 주기를 계단식 현관보다 짧게 잡는 게 좋습니다.
현관문 안쪽에 결로가 자주 생긴다면 실내 습도를 조금 낮추고 환기를 자주 해 주세요. / 결로가 도어락 안으로 스며들면 겨울 내내 오작동이 이어질 수 있습니다.
@ 명일동 복도식 현관 겨울 결로 도어락

# 겨울이 오기 전 해 둘 일
- 늦가을에 배터리를 미리 모두 교체
- 9V 건전지 하나를 가방 안쪽에 넣어 두기
- 문이 끝까지 닫히는지, 걸쇠가 빡빡하지 않은지 확인
- 경고음이 한 번이라도 났다면 그 주에 교체
- 오래된 제품은 겨울 전에 점검받기
한파 전 한 번의 교체가 영하의 아침 문 앞에서 떠는 일을 막아 줍니다. / 특히 혼자 사시는 어르신 댁이라면 가족이 대신 챙겨 드리면 좋습니다.
오래돼 겨울마다 말썽인 제품이라면 [도어락 교체](doorlock-replace.html)도 함께 생각해 볼 만합니다.

# 명일동 말고 강동구 어디든
명일동과 붙어 있는 고덕동, 암사동, 상일동, 강일동은 물론 천호동, 성내동, 길동, 둔촌동도 다닙니다. / 이용 순서는 [이용안내](guide.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 드라이기로 녹여도 되나요? | 안쪽에 물이 맺힐 수 있어 권하지 않습니다. 손으로 감싸 천천히 데워 주세요.

? 복도식 아파트는 배터리를 더 자주 갈아야 하나요? | 바깥 추위를 더 받으니 교체 주기를 짧게 잡는 게 좋습니다.
? 한파 때 출동이 늦어지기도 하나요? | 연락이 겹칠 수 있어 위치를 받으면 도착 예상 시간을 먼저 말씀드립니다.
