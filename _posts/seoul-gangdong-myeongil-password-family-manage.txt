# 명일동 맞벌이 집 현관 번호, 몇 명이 알고 있을까
아침에는 부모가 먼저 나가고, 오후에는 아이가 학교에서 돌아오고, 저녁 전에는 조부모나 돌봄 선생님이 들르십니다. / 맞벌이 집 현관 번호는 생각보다 많은 사람이 알고 있습니다.
명일동은 강동구 아파트 생활권에 속해 현관마다 번호식 도어락을 쓰는 집이 대부분입니다. / 번호 하나로 온 식구가 드나들다 보니 한 번 정한 번호를 몇 해씩 그대로 두는 집도 흔합니다.
그렇다고 자주 바꾸면 이번에는 누군가 새 번호를 몰라 문 앞에서 막힙니다. / 이 글은 번호를 바꿀 때와 알리는 방법을 정해 두고, 바꾼 날 생기는 혼선을 줄이는 요령을 정리했습니다.
@ 명일동 아파트 맞벌이 가족 도어락 비밀번호

# 지금 번호를 아는 사람 적어 보기
번호를 바꾸기 전에 지금 번호를 누가 아는지 종이에 적어 보세요. / 가족, 조부모, 돌봄 선생님, 이사 때 도와준 분, 수리하러 왔던 기사까지 떠올려 보면 목록이 꽤 길어집니다.
이 목록이 다음 번호를 누구에게 알려야 하는지도 정해 줍니다. / 이제는 오지 않는 분이 있다면 그분이 번호를 바꿀 첫 번째 이유가 됩니다.
목록은 번호와 함께 적지 말고 이름만 적어 두세요. / 이 종이가 남의 손에 들어가도 번호가 새지 않게 하기 위해서입니다.

# 바꾸기 좋은 때는 이렇게 정합니다
날짜를 정해 놓고 바꾸는 집도 있고, 일이 생길 때마다 바꾸는 집도 있습니다. / 맞벌이 집이라면 두 가지를 섞는 편이 현실적입니다.
- 계절이 바뀌거나 아이 새 학기가 시작될 때
- 돌봄 선생님이나 도우미가 바뀌었을 때
- 이사 도움, 집 수리처럼 번호를 알려 준 일이 끝났을 때
- 번호판에 손때가 묻어 자주 누르는 숫자가 보일 때
마지막 경우는 의외로 많습니다. / 번호판을 비스듬히 비춰 보면 자주 누른 자리만 반질반질해 보일 수 있으니 가끔 닦아 주세요.

# 번호를 바꾸는 사람은 한 명만
식구 누구나 번호를 바꿀 수 있으면 편할 것 같지만, 실제로는 혼선이 가장 많이 생깁니다. / 아빠가 바꿨는데 엄마는 모르고, 아이는 학원에서 돌아와 문 앞에서 서 있게 됩니다.
번호를 바꾸는 사람을 한 명 정하고, 그 사람이 바꾼 뒤 바로 알리는 것까지 맡도록 하세요. / 다른 식구가 바꿔야 할 일이 생기면 담당자에게 먼저 말하고 바꾸는 식입니다.
@ 명일동 도어락 번호 변경 담당자 정하기

# 알리는 곳도 한 군데로
새 번호를 알리는 곳은 하나로 정합니다. / 가족 단체 대화방이 가장 흔하고, 메시지 맨 위에 고정해 두면 찾기 쉽습니다.
돌봄 선생님이나 조부모께는 따로 문자로 보내되, 번호만 보내고 주소는 함께 쓰지 않습니다. / 누가 받았는지 확인했다는 답장을 받아 두면 빠진 사람이 없는지 알 수 있습니다.
현관 근처, 신발장, 냉장고에 번호를 적어 붙이는 건 피해 주세요. / 집에 들어오는 누구나 볼 수 있는 자리입니다.

# 아이가 외우기 쉬운 번호와 남이 짐작하기 어려운 번호 사이
아이가 혼자 귀가하는 집은 번호가 너무 어려우면 안 됩니다. / 그렇다고 생일이나 동 호수처럼 금방 짐작할 수 있는 숫자도 곤란합니다.
식구끼리만 아는 숫자를 섞으면 두 가지를 다 챙길 수 있습니다. / 예를 들어 반려견이 처음 집에 온 날이나 가족 여행을 간 해처럼 밖에서는 모르는 숫자입니다.
새 번호를 정했다면 아이와 함께 문 앞에서 두세 번 눌러 보게 하세요. / 손가락이 기억하면 머리로 외운 것보다 오래갑니다.

# 사람마다 번호를 따로 쓰는 방법
사용자 번호를 여러 개 저장할 수 있는 도어락이라면 식구마다, 또는 돌봄 선생님 몫을 따로 둘 수 있습니다. / 이 경우 그분이 그만두시면 그 번호만 지우면 되니 온 식구 번호를 바꿀 필요가 없습니다.
지원하는지는 배터리 덮개 안쪽 안내나 설명서에서 확인할 수 있습니다. / 기능이 없다면 카드나 태그를 사람마다 하나씩 나눠 쓰는 것도 같은 효과가 있습니다.
카드는 몇 장을 누구에게 줬는지 메모해 두세요. / 잃어버렸을 때 무엇을 지워야 할지 바로 알 수 있습니다.

# 바꾼 날 지킬 순서
번호는 반드시 문을 열어 둔 상태에서 바꿉니다. / 바꾼 뒤 문을 연 채로 바깥 번호판에서 새 번호를 눌러 걸쇠가 움직이는지 확인하고 나서야 문을 닫으세요.
그다음 정해 둔 곳에 새 번호를 알리고, 받았다는 답을 모두에게서 받습니다. / 바꾼 첫 주는 식구들이 옛 번호를 누르는 일이 잦으니, 저녁마다 한 번씩 "새 번호 기억나?" 하고 물어보는 것도 방법입니다.
@ 명일동 현관 열어 둔 채 새 비밀번호 확인

# 잠깐 알려 준 번호는 그날 정리하기
인테리어 공사, 가전 설치, 이사 청소처럼 집을 비운 사이 번호를 알려 줘야 하는 날이 있습니다. / 이런 날은 일이 끝나고 저녁에 바로 번호를 바꾸는 것을 한 세트로 생각해 두세요.
일회용 번호 기능이 있는 제품이라면 처음부터 그 번호를 알려 주는 편이 훨씬 편합니다. / 한 번 쓰고 나면 저절로 지워지니 따로 정리할 필요가 없습니다.

# 그래도 누군가 문 앞에서 막혔다면
새 번호를 모르는 식구가 막혔다면 먼저 전화로 번호를 알려 주시면 됩니다. / 틀린 번호를 여러 번 누르면 도어락이 잠시 입력을 막으니, 알려 주기 전까지는 누르지 말라고 해 주세요.
번호를 바꾸다 저장이 안 된 채 문이 닫혔거나, 아무도 새 번호를 모르는 상황이라면 출장으로 문을 열어야 합니다. / 사시는 분인지 확인한 뒤 열고, 번호를 다시 등록하는 것까지 함께 해 드립니다.
금액은 문을 본 뒤 손대기 전에 먼저 말씀드리고, 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html), 문 여는 과정은 [현관문 개문](door-open.html)에 있습니다.

# 오래 쓴 도어락이라면 기능부터 살펴보기
몇 해 쓴 도어락은 번호를 하나밖에 저장하지 못하거나, 바꾸는 방법이 번거로운 경우가 있습니다. / 식구가 많고 드나드는 사람이 자주 바뀐다면 사용자 번호나 일회용 번호, 앱 알림 기능이 있는 제품이 관리하기 편합니다.
지금 제품을 고쳐 쓸 수 있는지는 [도어락 수리](doorlock-repair.html)에서, 새 제품을 고민한다면 [도어락 교체](doorlock-replace.html)에서 먼저 살펴보세요. / 교체를 서두를 필요는 없고, 지금 쓰는 기능만 잘 활용해도 충분한 집이 많습니다.
@ 명일동 사용자 번호 여러 개 저장 도어락

# 명일동 이웃 동네까지
명일동과 맞닿은 고덕동, 암사동, 길동은 물론 상일동, 강일동, 천호동, 성내동, 둔촌동까지 다닙니다. / 강동구 안내는 [강동구 출장열쇠](seoul-gangdong.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
