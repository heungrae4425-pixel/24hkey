# 성내동 현관, 잠금쇠가 중간에서 멈출 때
성내동은 강동역 생활권 안쪽으로 다세대와 빌라가 이어지는 주택가입니다. / 오래 쓴 현관문이 많고 손잡이 일체형 도어락이 흔해서 잠금쇠가 걸린다는 연락이 종종 들어옵니다.
데드볼트는 문을 잠글 때 문 옆면에서 튀어나와 문틀 구멍으로 들어가는 네모난 쇠막대입니다. / 이게 끝까지 나오지 않으면 문이 안 잠기고, 들어간 채 빠지지 않으면 문이 안 열립니다.
이 글은 성내동에서 데드볼트가 걸렸을 때 왜 그런지, 집에서 확인할 것과 [강동구 출장열쇠](seoul-gangdong.html)를 부를 때를 정리했습니다.
@ 성내동 도어락 데드볼트 걸림 점검

# 데드볼트와 걸쇠는 다릅니다
현관 도어락 옆면을 보면 쇠붙이가 두 개 있는 경우가 많습니다. / 비스듬히 깎인 것은 문을 닫으면 저절로 걸리는 걸쇠이고, 네모나고 두툼한 것이 데드볼트입니다.
걸쇠는 손잡이를 돌리면 들어가고, 데드볼트는 도어락 모터나 안쪽 돌림 손잡이로 움직입니다. / 어느 쪽이 걸렸는지에 따라 손볼 곳이 다르니 전화 주실 때 같이 말씀해 주세요.

# 안 들어가는 경우와 안 빠지는 경우
증상은 크게 두 가지입니다. / 문이 열려 있는데 잠금이 안 되는 경우와, 잠긴 채 열리지 않는 경우입니다.
- 문을 닫았는데 데드볼트가 반쯤 나오다 멈춤, 도어락이 경고음을 냄
- 문을 닫으면 데드볼트가 문틀에 부딪혀 덜컥 소리만 남
- 번호를 눌렀는데 데드볼트가 안 들어가 문이 그대로 잠겨 있음
- 안쪽 돌림 손잡이가 뻑뻑해 손으로도 잘 안 돌아감
앞의 두 경우는 대개 문틀과 구멍이 어긋난 탓이고, 뒤의 두 경우는 문틀에 눌리거나 도어락 안쪽 부품이 닳은 탓이 많습니다.

# 문틀 구멍과 어긋나는 이유
오래된 문은 경첩이 조금씩 처지면서 문짝이 아래로 내려앉습니다. / 그러면 데드볼트 높이와 문틀 구멍 높이가 몇 밀리미터씩 어긋나기 시작합니다.
여름과 겨울에 문이 늘었다 줄었다 하는 것도 원인입니다. / 계절에 따라 잘 잠기다 안 잠기다를 반복한다면 이 경우일 가능성이 큽니다.
문틀 구멍 안에 먼지나 페인트, 작은 이물질이 쌓여 데드볼트가 끝까지 못 들어가기도 합니다. / 성내동처럼 오래된 건물은 문틀을 다시 칠하면서 구멍이 좁아진 경우도 있습니다.
@ 강동 성내동 현관 문틀 스트라이크 구멍 어긋남

# 문이 열려 있을 때 해볼 수 있는 확인
문이 열린 상태라면 원인을 직접 볼 수 있습니다. / 아래 순서대로 천천히 확인해 보세요.
- 문을 연 채 안쪽 돌림 손잡이로 데드볼트를 끝까지 내밀어 보기
- 잘 나온다면 도어락은 정상, 문틀 쪽 문제일 가능성이 큼
- 문틀 구멍 안에 이물질이 있는지 손전등으로 비춰 보기
- 문을 닫을 때 위아래 틈이 고르게 맞는지 보기
문을 연 채로는 잘 나오는데 닫으면 걸린다면 문틀 구멍 위치를 조금 손보는 것으로 해결되는 경우가 많습니다. / 문틀 쇠판의 나사를 풀고 위치를 옮기는 작업이라 오래 걸리지 않습니다.

# 잠긴 채 안 빠질 때 문 앞에서
밖에 계신데 번호는 맞고 데드볼트만 안 들어간다면 문이 문틀에 눌려 있는 경우가 많습니다. / 문을 안쪽으로 살짝 밀거나 몸 쪽으로 당기면서 다시 번호를 눌러 보세요.
그 순간 데드볼트를 누르던 힘이 빠지면서 모터가 쉽게 당길 수 있게 됩니다. / 두세 번 해봐도 같으면 그만두시고 연락 주세요.
반복해서 누르면 모터와 기어에 무리가 가서 열 수 있던 문도 더 어려워집니다. / 배터리도 빠르게 닳습니다.

# 하지 않는 게 좋은 것
데드볼트가 걸렸다고 문틈에 드라이버를 넣어 쇠막대를 밀어 넣으려는 분이 있습니다. / 데드볼트는 밖에서 밀리지 않게 만들어져 있어 문틀만 상하게 됩니다.
윤활유를 데드볼트에 잔뜩 뿌리는 것도 권하지 않습니다. / 먼지가 엉겨 붙어 나중에 더 뻑뻑해지고, 도어락 안으로 흘러 들어가면 기판이 상할 수 있습니다.
@ 성내동 데드볼트 윤활 주의 도어락 내부

# 성내동에서 전화 주실 때
주택가 골목은 비슷한 건물이 많아 건물 이름이나 근처 큰길을 알려주시면 빨리 찾습니다. / 강동역 쪽인지, 길동이나 천호동 쪽에 가까운지도 말씀해 주세요.
- 데드볼트가 안 들어가는지, 안 나오는지
- 문이 지금 열려 있는지, 잠겨 있는지
- 증상이 언제부터, 계절 따라 달라지는지
- 도어락 옆면과 문틀 구멍 사진
문이 열려 있다면 옆면 사진을 꼭 보내 주세요. / 데드볼트 모양과 길이를 보면 맞는 부품을 미리 챙길 수 있습니다.

# 도착하면 이렇게 봅니다
문이 잠긴 상태라면 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 건물 관리인 확인 중 하나면 됩니다.
그다음 비용을 먼저 말씀드리고, 괜찮으실 때 [현관문 개문](door-open.html)으로 문을 엽니다. / 못 열면 비용은 받지 않습니다.
문이 열리면 데드볼트가 왜 걸렸는지 문틀과 도어락 양쪽을 같이 봅니다. / 원인이 문틀이라면 도어락은 그대로 두고 문틀만 손봅니다.

# 수리로 끝나는 경우가 대부분입니다
데드볼트 걸림은 도어락을 바꾸지 않고도 해결되는 일이 많습니다. / 문틀 쇠판 위치 조정, 구멍 넓히기, 경첩 나사 조이기 정도로 끝납니다.
도어락 안쪽 기어가 닳아 데드볼트를 끝까지 못 미는 경우에는 [도어락 수리](doorlock-repair.html)로 부품을 봅니다. / 부품이 더 나오지 않는 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 같이 상의합니다.

# 경첩과 도어클로저도 함께
데드볼트가 자주 걸리는 집은 경첩 나사가 풀려 있거나 도어클로저가 문을 끝까지 당기지 못하는 경우가 많습니다. / 문이 닫히다 말고 살짝 떠 있으면 데드볼트가 문틀에 부딪힙니다.
문이 끝까지 닫히는지 손으로 한 번 밀어 보는 것만으로도 걸림이 줄어듭니다. / 닫힘 속도가 너무 빠르거나 느리면 도어클로저 조정이 필요합니다.
경첩 쪽 문틈이 위는 넓고 아래는 좁다면 문이 처졌다는 신호입니다. / 경첩 나사를 다시 조이고 높이를 맞추면 데드볼트 높이도 함께 돌아옵니다.
@ 성내동 현관문 경첩 처짐 도어클로저 조정

# 다시 걸리지 않게 하는 관리
- 문을 닫을 때 끝까지 닫혔는지 한 번 확인하기
- 문틀 구멍 안 먼지를 가끔 털어 내기
- 계절이 바뀔 때 잠금이 뻑뻑해지면 미루지 않기
- 데드볼트가 반만 나온 채 경고음이 나면 바로 점검받기
반만 나온 상태로 계속 쓰면 문이 잠긴 것처럼 보여도 실제로는 제대로 잠기지 않은 상태입니다. / 방범을 위해서도 바로 손보시는 게 좋습니다.

# 성내동 말고 강동구 어디든
성내동 옆 천호동, 길동, 둔촌동은 물론 암사동, 명일동, 고덕동, 상일동, 강일동도 다닙니다. / 진행 방식은 [이용안내](guide.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 데드볼트가 반만 나오고 경고음이 울려요. | 대부분 문틀 구멍과 높이가 어긋난 경우라 문틀 쪽 위치를 조정하면 좋아집니다.
? 계절마다 잠기다 안 잠기다 해요. | 문이 온도와 습도에 따라 늘고 줄어서 생기는 일이라 문틀 구멍 여유를 조금 넓혀 드립니다.
? 데드볼트에 기름을 뿌려도 되나요? | 먼지가 엉겨 더 뻑뻑해질 수 있어 권하지 않습니다.
? 도어락을 바꿔야 할까요? | 문틀 조정으로 끝나는 경우가 많고, 내부 부품이 닳았을 때만 교체를 상의합니다.
? 문이 열려 있을 때 어떤 사진을 보내면 되나요? | 도어락 옆면과 문틀 구멍이 함께 보이게 찍어 보내 주세요.
