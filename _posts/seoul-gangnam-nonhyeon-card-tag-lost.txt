# 논현동에서 카드 한 장이 사라졌을 때
논현동은 원룸과 오피스텔, 사무실 건물이 촘촘하게 이어진 강남구 동네입니다. / 이런 건물은 공동현관 출입 태그와 집이나 사무실 도어락 카드가 따로인 경우가 많아, 카드 한 장을 잃어버려도 정리할 일이 두 갈래로 나뉩니다.
카드를 잃어버리면 당장 집에 들어가는 것도 문제지만, 누군가 그 카드를 주웠을 때가 더 마음에 걸립니다. / 그래서 들어가는 방법과 분실 카드를 무효로 만드는 방법을 함께 챙겨야 합니다.
이 글은 논현동에서 카드키, 태그, 리모컨을 잃어버렸을 때 무엇부터 정리하면 되는지 순서대로 적었습니다. / 문이 막혀 들어가지 못한다면 [강남 출장열쇠](seoul-gangnam.html)로 연락 주세요.
@ 논현동 오피스텔 카드키 분실 정리

# 잃어버린 것이 어떤 카드인지부터
같은 모양의 카드라도 쓰는 곳에 따라 정리하는 쪽이 다릅니다. / 먼저 잃어버린 카드가 어디에 쓰던 것인지 나눠 보세요.
- 건물 공동현관이나 엘리베이터용 태그 → 건물 관리실에서 정리
- 집이나 사무실 현관 도어락 카드 → 도어락에서 직접 삭제
- 주차장 차단기나 셔터 리모컨 → 관리실이나 설치 업체 확인
- 하나의 카드로 건물과 집을 모두 여는 경우 → 두 곳 모두 정리
건물용과 집용을 한 열쇠고리에 같이 달고 다녔다면 둘 다 잃어버린 셈입니다. / 어느 쪽부터 막을지 순서를 정하는 것이 첫 단계입니다.

# 건물 출입 태그는 관리실에 먼저
오피스텔이나 사무실 건물의 공동현관 태그는 대개 관리실에서 등록을 관리합니다. / 분실 사실을 알리면 잃어버린 태그의 등록을 막고 새 태그를 받을 수 있는지 안내해 줍니다.
관리실 운영 시간이 끝난 밤이라면 다음 날 아침 일찍 연락해 두세요. / 그사이 건물에 들어가야 한다면 같은 건물 이웃이나 경비 근무자에게 도움을 청할 수 있습니다.
세입자라면 집주인이나 임대 관리하는 분에게도 알려 두는 것이 좋습니다. / 건물에 따라 태그 재발급을 집주인 확인 후 해 주는 곳도 있습니다.

# 잃어버린 곳을 떠올려 보는 것도 방법
정리를 시작하기 전에 마지막으로 카드를 쓴 곳을 차분히 떠올려 보세요. / 회사 출입구, 편의점 계산대, 택시 안처럼 지갑이나 휴대폰을 꺼냈던 곳에서 빠지는 일이 많습니다.
카드에 집 주소나 호수가 적혀 있지 않았다면 주운 사람이 어느 집 카드인지 알기는 어렵습니다. / 그렇다고 그대로 두기보다는 오늘 안에 등록을 정리해 두는 편이 마음이 편합니다.
카드 지갑에 주소가 적힌 명함이나 우편물이 함께 들어 있었다면 정리를 더 서둘러 주세요. / 이 경우는 카드 등록 삭제와 함께 번호도 새로 바꿔 두는 것을 권합니다.

# 집 도어락 카드는 남은 카드로 정리
도어락 카드는 보통 개별 삭제보다 전체 삭제 후 다시 등록하는 방식이 많습니다. / 잃어버린 카드 한 장만 골라 지우는 기능이 없는 제품도 있기 때문입니다.
- 지금 갖고 있는 카드를 모두 모으기
- 도어락 안쪽에서 등록 카드 전체 삭제
- 갖고 있는 카드만 하나씩 다시 등록
- 바깥에서 카드마다 열리는지 시험하기
다시 등록한 뒤에는 잃어버린 카드로는 열리지 않습니다. / 나중에 그 카드를 찾더라도 다시 등록해야 쓸 수 있습니다.
@ 논현동 도어락 카드 전체 삭제 후 재등록

# 남은 카드가 하나도 없다면
마지막 카드까지 잃어버렸어도 번호로 열 수 있다면 큰 문제는 없습니다. / 안으로 들어가 등록 카드를 전체 삭제해 두면 잃어버린 카드는 더 이상 쓸 수 없습니다.
새 카드는 같은 도어락 제조사에서 쓰는 방식의 카드나 스티커형 태그를 구해 등록하면 됩니다. / 도어락에 따라 맞는 카드 종류가 달라서, 모르시겠다면 모델명을 알려 주세요.

# 번호도 모르고 카드도 없을 때
평소 카드로만 열어서 번호를 잊었거나 번호 기능을 꺼 둔 경우가 있습니다. / 이럴 때는 바깥에서 들어갈 방법이 없으니 문을 여는 작업이 필요합니다.
[현관문 개문](door-open.html)으로 문을 연 다음, 안쪽에서 카드 전체 삭제와 새 등록을 함께 해 드립니다. / 번호도 새로 정해 두시면 다음에 카드를 잃어도 들어갈 길이 하나 남습니다.

# 사무실 출입 카드라면
논현동 사무실은 직원 여럿이 카드나 태그를 나눠 쓰는 경우가 많습니다. / 직원 한 명이 카드를 잃어버리면 전체를 다시 등록해야 하는 일이 생깁니다.
누구에게 카드를 몇 장 나눠 줬는지 명단을 만들어 두면 이런 정리가 훨씬 수월합니다. / 퇴사자 카드를 돌려받지 못했을 때도 같은 방식으로 정리하면 됩니다.
사무실 문을 여는 경우에는 사업자 등록증, 임대차 계약서, 재직 확인 등으로 사용 권한을 확인합니다.

# 주차 리모컨과 셔터 리모컨
주차장 차단기나 상가 셔터 리모컨은 건물 설비라서 관리실이나 설치한 쪽에서 등록을 관리합니다. / 잃어버렸다면 관리실에 먼저 알리고 등록 해제와 새 리모컨을 요청하세요.
집 현관 도어락 리모컨을 쓰셨다면 그것은 도어락에서 정리할 수 있습니다. / 리모컨도 카드처럼 전체 삭제 후 다시 등록하는 방식이 많습니다.
@ 논현동 사무실 출입 태그 리모컨 분실

# 카드를 덜 잃어버리게 하는 방법
- 건물용 태그와 집 카드를 다른 색 고리에 나눠 달기
- 휴대폰 케이스 안에 스티커형 태그 붙여 두기
- 여분 카드 한 장은 집 안 정해진 곳에 보관
- 번호 기능도 함께 켜 두고 번호를 기억하기
카드는 작고 가벼워서 주머니에서 빠져도 모르기 쉽습니다. / 카드 한 가지에만 기대지 않도록 번호나 지문을 하나 더 등록해 두는 것이 가장 좋은 대비입니다.

# 카드 분실로 연락하실 때
- 건물 이름 또는 주소, 호수
- 잃어버린 것이 건물 태그인지 집 카드인지
- 지금 공동현관을 통과할 수 있는지
- 번호로 열 수 있는지, 번호도 모르는지
- 도어락 모델이나 사진
공동현관이 막혀 있다면 관리실이나 이웃에게 미리 부탁해 두시면 도착 후 바로 올라갈 수 있습니다.

# 사용자 확인과 금액 안내
문을 열기 전에는 사시는 분이 맞는지 신분증 주소, 우편물, 관리실 확인 가운데 하나로 확인합니다. / 사무실은 사용 권한을 확인할 서류를 준비해 주세요.
작업 전에 비용을 먼저 말씀드리고, 동의하실 때만 시작합니다. / 문을 열지 못하면 비용은 받지 않으며 진행 방식은 [이용안내](guide.html)에 있습니다.
카드 인식이 계속 불안정하다면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 카드 방식이 맞지 않는 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 함께 상의해 보셔도 됩니다.

# 논현동 말고 강남구 다른 동네도
신사동, 압구정동, 청담동, 역삼동, 삼성동, 대치동, 도곡동, 개포동, 일원동, 수서동, 세곡동도 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 자주 묻는 질문
? 잃어버린 카드 한 장만 골라서 지울 수 있나요? | 제품마다 다릅니다. 안 되는 제품은 전체 삭제 후 남은 카드만 다시 등록합니다.
? 건물 공동현관 태그도 출장열쇠에서 정리해 주나요? | 건물 설비는 관리실에서 관리하니 관리실에 먼저 알려 주세요.
? 카드만 쓰다가 번호를 잊었어요. | 문을 연 뒤 카드 정리와 함께 새 번호도 등록해 드립니다.
? 새 카드는 아무 카드나 등록되나요? | 도어락마다 맞는 방식이 달라 모델명을 보고 알려 드립니다.
? 사무실 문도 열어 주시나요? | 네, 사용 권한을 확인할 서류가 있으면 진행합니다.
