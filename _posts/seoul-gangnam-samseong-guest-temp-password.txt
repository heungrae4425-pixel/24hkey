# 삼성동 집, 내가 없을 때 문을 열 사람이 있다면
삼성동은 삼성역과 선릉역 주변으로 사무실과 오피스텔, 주거 건물이 함께 있는 강남구 동네입니다. / 출근한 사이 가사도우미가 오시거나, 지방에서 올라온 가족이 먼저 도착하거나, 인테리어 기사가 낮에 작업하러 오는 일이 생깁니다.
그때마다 내 비밀번호를 그대로 알려 주면 편하긴 해도 나중에 마음이 쓰입니다. / 이 글은 임시 번호를 주는 방법과 다시 거두는 방법을 상황별로 나눠 정리했습니다.
도어락마다 기능 이름과 누르는 순서가 달라서, 여기서는 원리와 순서 위주로 적었습니다. / 정확한 버튼 순서는 제품 설명서나 안쪽 몸체에 붙은 안내 스티커를 함께 보시면 됩니다.
@ 삼성동 오피스텔 도어락 임시 비밀번호 설정

# 우리 집 도어락이 할 수 있는 일부터
임시 번호를 쓰려면 먼저 도어락이 어떤 기능을 지원하는지 알아야 합니다. / 대체로 아래 셋 중 하나 이상이 있습니다.
- 한 번 쓰면 사라지는 일회용 번호
- 주인 번호와 따로 등록하는 사용자 번호
- 등록과 삭제가 쉬운 카드나 태그
배터리 칸 덮개 안쪽이나 몸체 옆면에 기능 버튼이 모여 있는 경우가 많습니다. / 모델 이름을 확인해 두시면 설명서를 찾거나 전화로 물어볼 때 훨씬 수월합니다.

# 하루만 오는 손님에게는 일회용 번호
친구나 친척이 하루 들렀다 가는 정도라면 일회용 번호가 가장 깔끔합니다. / 한 번 문을 열고 나면 번호가 저절로 지워져서 따로 정리할 일이 없습니다.
다만 손님이 짐을 가지러 다시 나갔다 들어와야 한다면 두 번째에는 안 열립니다. / 이럴 때는 집 안에 계신 동안 문을 완전히 닫지 않게 안내하거나, 사용자 번호를 잠시 주는 편이 낫습니다.
손님이 머무는 동안 집 안에서 문을 잠그는 방법도 미리 알려 드리세요. / 안쪽 잠금 버튼이나 보조키를 잘못 눌러 두면 나중에 바깥에서 주인 번호로도 안 열리는 일이 생깁니다.
떠날 때는 문이 끝까지 닫히고 잠김 소리가 나는지 확인해 달라고 한마디 덧붙이면 좋습니다.

# 정기적으로 오시는 분에게는 사용자 번호
일주일에 몇 번 오시는 가사도우미나 아이 하원을 돕는 돌봄 선생님께는 따로 등록한 사용자 번호를 드리는 것이 편합니다. / 주인 번호와 겹치지 않게 정하고, 생일이나 전화번호 끝자리처럼 짐작하기 쉬운 숫자는 피하세요.
번호를 드릴 때는 메신저 대화방에 오래 남지 않게 하는 것도 신경 쓸 부분입니다. / 처음 오시는 날 직접 알려 드리고, 혹시 메시지로 보냈다면 확인 후 지워 달라고 부탁해도 실례가 아닙니다.
@ 삼성동 가사도우미 돌봄 사용자 번호 등록

# 수리 기사나 이삿짐 작업이라면
집수리나 가구 설치처럼 하루 이틀 드나드는 작업이라면 작업 기간에만 쓸 번호를 따로 만드세요. / 작업이 끝난 날 저녁에 바로 지우는 것을 원칙으로 두면 잊어버릴 일이 없습니다.
작업 중에는 문을 열어 두는 시간이 길어서 자동 잠김이 계속 걸리는 경우가 있습니다. / 그날만 자동 잠김을 잠시 끄고, 작업이 끝나면 다시 켜 두세요.

# 오피스텔이라면 공동현관도 함께 생각하세요
삼성동 오피스텔은 건물 입구에 출입 장치가 따로 있는 곳이 많습니다. / 집 현관 번호만 알려 드리고 공동현관 출입 방법을 빠뜨리면 손님이 건물 밖에서 기다리게 됩니다.
관리실에 방문 예정인 분 이름을 미리 말해 두면 출입이 수월한 건물도 있습니다. / 공동현관 번호를 따로 바꿀 수 없는 건물이라면 그 번호는 꼭 필요한 분께만 알려 주세요.

# 번호를 거두는 날 해야 할 일
임시 번호는 주는 것보다 거두는 것이 더 중요합니다. / 도우미 분이 그만두시거나, 작업이 끝나거나, 손님이 떠난 날 아래 순서로 정리하세요.
- 사용자 번호를 삭제하고 지워졌는지 바깥에서 한 번 눌러 보기
- 드렸던 카드나 태그를 돌려받고 등록에서도 지우기
- 자동 잠김, 소리 설정이 바뀌지 않았는지 확인하기
- 오래 함께하신 분이었다면 주인 번호도 이참에 바꾸기
- 지문을 등록해 드렸다면 그 지문도 함께 삭제하기
삭제가 잘 안 되거나 메뉴가 헷갈리면 무리하게 버튼을 누르지 마세요. / 여러 번 잘못 누르다 전체 초기화가 되는 일이 있습니다.

# 일회용 번호가 없는 도어락이라면
오래된 도어락은 번호를 하나만 저장하는 경우도 있습니다. / 이럴 때는 손님이 오는 동안만 주인 번호를 잠시 바꿨다가 떠난 뒤 다시 바꾸는 방법이 있습니다.
번거롭다면 카드 한 장을 손님용으로 따로 등록해 두는 것도 방법입니다. / 사용자 관리가 자주 필요한 집이라면 [도어락 교체](doorlock-replace.html) 때 번호를 여러 개 받는 제품을 고르시면 편합니다.
@ 삼성동 손님용 카드키 따로 등록

# 임시 번호가 안 먹혀 손님이 문 앞에 있다면
손님이 번호를 눌렀는데 안 열린다고 연락이 오면 먼저 번호판에 불이 들어오는지 물어보세요. / 불이 안 들어오면 배터리 문제이고, 불은 들어오는데 틀렸다는 소리가 나면 번호 등록 문제일 가능성이 큽니다.
일회용 번호를 이미 한 번 쓴 경우도 많습니다. / 그래도 안 되면 손님이 혼자 계속 누르지 않게 하고, 저희에게 연락 주시면 사시는 분과 통화해 의뢰를 확인한 뒤 진행합니다.

# 문을 열 때 확인은 이렇게 합니다
집주인이 현장에 없을 때는 전화로 사시는 분임을 확인하고, 현장에서 신분증 사진이나 관리실 세대 확인 같은 방법을 함께 씁니다. / 확인이 되지 않으면 손님이 기다리더라도 문을 열 수 없습니다.
비용은 상태를 보고 작업 전에 먼저 말씀드리고, 못 열면 받지 않습니다. / 문 여는 과정은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 번호 설정이 꼬였을 때
등록을 하다가 어디까지 됐는지 모르게 되었다면 그 상태로 문을 닫지 마세요. / 문을 열어 둔 채 안쪽에서 정리하는 것이 안전합니다.
배터리가 약하면 등록 도중에 저장이 안 되는 일도 있으니, 설정을 바꾸기 전에 배터리부터 새것으로 바꿔 두세요.
혼자 정리하기 어려우면 [도어락 수리](doorlock-repair.html)로 방문해 등록 상태를 정리해 드립니다.

# 삼성동 말고 강남구 다른 동네도
청담동, 대치동, 역삼동은 물론 신사동, 압구정동, 논현동, 도곡동, 개포동, 일원동, 수서동, 세곡동까지 다닙니다. / 강남 출장 동네는 [강남구 출장열쇠](seoul-gangnam.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 임시 번호, 자주 묻는 질문
? 일회용 번호는 몇 번까지 쓸 수 있나요? | 대부분 한 번 열면 사라집니다. 손님이 여러 번 드나들면 사용자 번호를 잠시 주세요.
? 도우미 번호만 골라서 지울 수 있나요? | 사용자 번호를 따로 받는 제품이면 가능합니다. 하나만 받는 제품이면 주인 번호를 바꾸는 수밖에 없습니다.
? 집주인이 회사에 있는데 손님 대신 문을 열어 주시나요? | 사시는 분과 통화로 의뢰를 확인하고, 거주 확인이 된 뒤에 진행합니다.
? 공동현관 번호도 바꿔 주시나요? | 공동현관은 건물 관리 쪽 장치라 관리실과 상의하셔야 합니다. 집 현관 도어락은 바로 봐 드립니다.
? 손님용 카드를 잃어버렸어요. | 등록에서 그 카드를 지우면 됩니다. 한 장만 지우기 어려우면 전체 삭제 후 남은 카드를 다시 등록합니다.

# 마무리
삼성동처럼 낮에 집을 비우는 시간이 긴 집은 임시 번호를 주는 일보다 거두는 일을 습관으로 만드는 것이 중요합니다. / 주는 날과 거두는 날을 달력에 같이 적어 두면 빠뜨리지 않습니다.
24시출장열쇠는 손님이 문 앞에서 막힌 급한 순간에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
