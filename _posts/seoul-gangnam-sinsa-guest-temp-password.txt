# 신사동 집 현관 번호, 누구에게 얼마나 알려 주고 계신가요
신사동은 압구정역과 가까운 강남구 북쪽 동네로, 맞벌이 가정이나 혼자 사는 직장인이 집을 비우는 낮 시간이 긴 편입니다. / 그 시간에 가사도우미, 아이 하원을 돕는 돌봄 선생님, 반려견 산책 도우미가 대신 문을 여는 집이 적지 않습니다.
처음에는 가족 번호를 그대로 알려 주고 시작하는 경우가 많습니다. / 그러다 도우미가 바뀌거나 계약이 끝났을 때 그 번호를 그대로 두는 일이 생깁니다.
이 글은 신사동에서 집에 드나드는 외부 인력에게 번호를 어떻게 주고 어떻게 거둘지 정리한 글입니다. / 번호가 꼬여 문이 안 열릴 때 [강남 출장열쇠](seoul-gangnam.html)에 어떻게 연락하면 되는지도 뒤쪽에 적었습니다.
@ 신사동 현관 도어락 임시 비밀번호 설정

# 가족 번호를 그대로 알려 주면 생기는 일
가족이 쓰는 번호를 외부 사람과 같이 쓰면 나중에 그 사람만 빼는 방법이 없습니다. / 번호를 바꾸는 순간 가족 모두가 새 번호를 다시 외워야 합니다.
그래서 바꾸기를 미루게 되고, 몇 달 전 그만둔 분도 여전히 번호를 아는 상태가 이어집니다. / 사람을 의심해서가 아니라 관리가 흐트러지는 구조라는 점이 문제입니다.
처음부터 가족 번호와 외부 인력 번호를 나눠 두면 이런 고민이 훨씬 줄어듭니다.

# 내 도어락이 번호를 몇 개까지 받는지 먼저 확인
도어락마다 등록할 수 있는 번호 개수와 방식이 다릅니다. / 사용 설명서나 안쪽 몸체 배터리 덮개 근처의 모델명을 보면 기능을 확인할 수 있습니다.
- 사용자 번호를 여러 개 따로 등록할 수 있는 제품
- 한 번만 쓰고 사라지는 일회용 번호를 지원하는 제품
- 휴대폰 앱에서 시간을 정해 번호를 보내는 제품
- 번호가 하나뿐이라 바꾸는 방법밖에 없는 제품
번호가 하나뿐인 제품이라면 카드키를 한 장 따로 드리는 방법이 대안이 됩니다. / 카드는 돌려받거나 등록을 지우면 바로 끝나서 관리가 단순합니다.

# 역할마다 다른 번호를 주는 방식
여러 분이 드나든다면 사람마다 번호를 따로 정하는 것이 가장 깔끔합니다. / 누가 언제 그만두든 그 번호 하나만 지우면 됩니다.
- 매주 정해진 요일에 오시는 가사도우미 번호
- 평일 오후 아이와 함께 들어오는 돌봄 선생님 번호
- 출장 기간에만 들르는 반려동물 돌봄 번호
- 하루 이틀 묵고 가는 지방 친척 손님 번호
번호마다 누구에게 줬는지 휴대폰 메모에 적어 두세요. / 도어락 화면에는 이름이 안 나오기 때문에 기록이 없으면 어떤 번호를 지워야 할지 헷갈립니다.

# 번호를 전할 때 조심할 표현
번호는 직접 받는 분에게만 개인 메시지로 보내는 편이 좋습니다. / 가족 단체방이나 업체 공용 대화방에 올리면 받을 필요가 없는 사람까지 알게 됩니다.
메시지에 집 주소와 번호를 한 줄에 같이 적는 것도 피해 주세요. / 주소는 처음 한 번만 알려 드리고 번호는 따로 보내면 휴대폰을 잃어버렸을 때도 덜 걱정됩니다.
번호를 알려 드릴 때 언제까지 쓰는 번호인지 함께 말해 두면 서로 오해가 없습니다.

# 돌봄 선생님이 아이와 함께 들어올 때
하원 시간에 선생님이 아이 손을 잡고 문 앞에 섰는데 번호가 안 먹히면 둘 다 복도에서 기다려야 합니다. / 이런 상황이 가장 마음 쓰이는 경우라 미리 대비해 두는 게 좋습니다.
선생님께 번호판이 안 켜질 때 9V 건전지를 바깥 단자에 대는 방법을 한 번 알려 드리세요. / 배터리 경고음이 들렸다면 바로 알려 달라고 부탁해 두는 것도 도움이 됩니다.
그래도 열리지 않으면 부모님이 직접 저희에게 연락하셔서 상황을 알려 주시면 됩니다.
@ 신사동 돌봄 선생님 현관 도어락 번호 안내

# 그만두거나 계약이 끝난 날 바로 할 일
외부 인력 번호는 마지막 방문일에 지우는 것까지 마쳐야 정리가 끝납니다. / 다음에 생각나면 지우자고 미루면 대부분 잊어버립니다.
- 그분께 드렸던 번호를 도어락에서 삭제
- 따로 드린 카드키가 있으면 돌려받거나 등록 해제
- 휴대폰 메모의 번호 기록도 함께 정리
- 새 분이 오시면 새 번호를 따로 만들어 전달
삭제 방법이 설명서와 달라 잘 안 될 때는 무리하게 버튼을 누르지 마세요. / 관리자 번호까지 같이 지워지면 처음부터 다시 등록해야 합니다.

# 번호가 꼬여 문이 안 열리는 경우
번호를 지우고 새로 넣다가 가족 번호까지 덮어써서 아무도 못 들어가는 일이 생깁니다. / 등록 버튼을 길게 눌러 초기화가 되어 버린 경우도 있습니다.
이럴 때는 바깥에서 할 수 있는 일이 거의 없습니다. / 번호를 계속 바꿔 눌러 보면 입력 제한이 걸리니 몇 번 해 보고 멈추시는 게 낫습니다.
[현관문 개문](door-open.html)으로 문을 연 뒤 안쪽에서 번호를 다시 정리해 드립니다.

# 신사동에서 연락하실 때 알려 주실 것
강남구는 오피스텔과 원룸 건물이 많아 건물 출입과 집 현관을 따로 확인해야 하는 경우가 많습니다. / 공동현관을 지나올 수 있는지부터 알려 주시면 준비가 빨라집니다.
- 건물 이름 또는 주소, 호수
- 공동현관 출입 방법과 경비실 유무
- 도어락 번호판이 켜지는지, 경고음이 나는지
- 최근에 번호를 바꾸거나 지운 일이 있는지
- 주변에 차를 잠깐 세울 곳이 있는지

# 문 앞에서 거주 확인을 먼저 합니다
번호를 맡긴 분이 대신 연락하셨더라도 문은 사시는 분이 확인된 뒤에 엽니다. / 신분증 주소나 주소가 나온 우편물, 관리사무소 확인 가운데 하나가 필요합니다.
집주인이 출근해 계신다면 통화로 직접 의뢰를 확인하고 진행할 수 있습니다. / 도우미나 손님 혼자 요청하시는 경우에는 사시는 분 확인 없이 열지 않습니다.
@ 신사동 출장열쇠 거주 확인 후 개문

# 비용 이야기는 작업 전에 끝냅니다
도어락 종류와 문 상태를 본 다음, 손대기 전에 금액부터 말씀드립니다. / 듣고 나서 괜찮다고 하실 때만 시작합니다.
문을 열지 못하고 돌아가게 되면 비용은 청구하지 않습니다. / 번호 재등록이나 부품 교체처럼 추가할 일이 생기면 그때 다시 여쭙습니다.
진행 과정은 [이용안내](guide.html)에 따로 정리해 두었습니다.

# 임시 번호 관리를 편하게 해 주는 도어락
외부 인력이 자주 바뀌는 집이라면 번호를 여러 개 받거나 앱으로 시간 지정 번호를 보내는 제품이 편합니다. / 지금 도어락이 오래돼 이런 기능이 없다면 바꿀 때 같이 고려해 보세요.
[도어락 교체](doorlock-replace.html)를 생각하신다면 집에 드나드는 사람 수와 방식부터 알려 주세요. / 기능이 지나치게 많은 제품보다 쓰기 쉬운 제품이 오래 갑니다.

# 신사동 말고 강남구 다른 동네도 갑니다
압구정동, 청담동, 논현동, 역삼동, 삼성동, 대치동, 도곡동, 개포동, 일원동, 수서동, 세곡동까지 강남구 어디든 출동합니다. / 강남에서 다니는 동네는 [강남구 출장열쇠](seoul-gangnam.html) 페이지에, 다른 지역은 [출장 지역](area.html)에 정리했습니다.
