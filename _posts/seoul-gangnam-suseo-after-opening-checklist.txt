# 수서동, 문이 열린 뒤 5분이 더 중요합니다
수서동은 강남구 동남쪽 끝자락의 주거 동네입니다. / 문이 안 열려 한참을 기다렸다가 드디어 열리면 대부분 안도의 한숨부터 쉬고 집 안으로 들어가십니다.
그런데 원인을 그대로 둔 채 문을 닫으면 며칠 뒤 같은 자리에서 다시 막히는 일이 생깁니다. / 그래서 문이 열린 직후 몇 분 동안 확인할 것들을 정리해 두었습니다.
이 글은 수서동에서 현관문을 연 뒤에 해야 할 점검과 다시 막히지 않게 하는 습관을 적었습니다. / [강남 출장열쇠](seoul-gangnam.html)로 문을 연 경우라면 기사와 함께 이 순서대로 보시면 됩니다.
@ 수서동 현관문 개방 후 도어락 점검

# 왜 막혔는지 한 문장으로 정리하기
점검의 시작은 원인을 분명히 하는 것입니다. / 배터리였는지, 번호였는지, 걸쇠였는지, 안쪽 잠금이었는지를 짚어 두면 다음 할 일이 정해집니다.
원인이 하나가 아닐 때도 있습니다. / 배터리가 약한데 문틀까지 처져 있어 모터가 걸쇠를 끝까지 못 당긴 경우처럼 두 가지가 겹치기도 합니다.
작업을 맡기셨다면 기사에게 원인을 꼭 물어보세요. / 한 줄로라도 들어 두면 다음에 비슷한 신호가 왔을 때 알아차리실 수 있습니다.

# 문이 열린 상태에서 잠김 시험
문을 활짝 연 상태에서 안쪽 손잡이나 버튼으로 잠금과 열림을 몇 번 시험해 보세요. / 걸쇠가 끝까지 나오고 끝까지 들어가는지 눈으로 확인합니다.
- 걸쇠가 나올 때 걸리거나 멈칫하는지
- 모터 소리가 일정하고 힘 있게 나는지
- 잠김과 열림 알림음이 평소처럼 나는지
걸쇠가 반쯤만 나온다면 모터나 내부 기어를 봐야 합니다. / 이 상태로 쓰면 문이 닫혀도 제대로 잠기지 않을 수 있습니다.

# 문을 닫고 바깥에서 다시 열어 보기
안쪽 시험이 끝나면 직접 밖으로 나가 문을 닫고 바깥에서 열어 보세요. / 실제로 쓰는 방식대로 해 봐야 문틀과 걸쇠가 맞는지 알 수 있습니다.
닫히는 순간 끝에서 툭 걸리거나, 잠김 소리가 늦게 난다면 받침판이나 경첩 조정이 필요합니다. / 번호, 카드, 지문 가운데 쓰시는 방식을 하나씩 다 시험해 보세요.

# 배터리는 전부 새것으로
배터리가 원인이었다면 한두 개가 아니라 들어 있는 것을 전부 교체해야 합니다. / 새 건전지와 헌 건전지를 섞어 쓰면 금세 다시 약해집니다.
배터리 덮개 안쪽에 교체한 날짜를 적어 두세요. / 다음 교체 때 언제 바꿨는지 몰라 고민하는 일이 없어집니다.
원인이 배터리가 아니었더라도 오래 쓴 건전지라면 이참에 같이 바꾸는 게 좋습니다.
@ 수서동 도어락 배터리 교체 날짜 기록

# 번호를 잊어서 막혔다면 새로 등록
비밀번호를 몰라서 연 경우라면 안쪽에서 새 번호를 등록하고 예전 번호는 지워야 합니다. / 누가 알고 있었는지 모르는 번호를 그대로 둘 이유가 없습니다.
새 번호는 가족 모두가 기억하기 쉬우면서 남이 짐작하기 어려운 조합으로 정하세요. / 등록이 끝나면 가족에게 직접 알려 주고, 단체 대화방에는 올리지 않는 편이 좋습니다.
새 번호를 넣은 뒤에는 바로 문을 닫지 말고, 문을 연 채로 바깥 번호판에서 한 번 눌러 보세요. / 등록이 제대로 됐는지 확인하지 않고 닫았다가 또 갇히는 일을 막을 수 있습니다.
가족 가운데 번호를 자주 잊는 분이 있다면 지문이나 카드를 하나 더 등록해 두는 것이 좋습니다. / 방법이 하나뿐이면 그 방법이 막히는 순간 다시 문 앞에 서게 됩니다.

# 카드키와 지문 등록도 다시 보기
열쇠나 카드를 잃어버려서 문을 연 경우라면 등록된 카드 목록을 정리해야 합니다. / 잃어버린 카드가 등록돼 있으면 주운 사람이 그대로 쓸 수 있습니다.
전체 삭제 후 지금 갖고 있는 카드만 다시 등록하는 방식이 가장 확실합니다. / 지문도 오래 등록해 둔 것이 많다면 같은 방식으로 정리하세요.

# 안쪽 잠금 버튼 위치 확인
안쪽 수동 잠금이 원인이었다면 그 버튼이 어디 있는지 가족 모두에게 알려 두세요. / 아이나 어르신이 무심코 눌러 두는 일이 가장 흔합니다.
쓸 일이 거의 없다면 설정에서 수동 잠금을 끄거나 덮개로 가려 두는 방법이 있습니다. / 모델마다 방법이 달라 현장에서 같이 정해 드립니다.
안전고리나 체인이 원인이었다면 그것도 마찬가지입니다. / 혼자 사는 집이 아니라면 누가 언제 걸어 두는지 가족끼리 정해 두면 밖에 있는 사람이 막히는 일이 줄어듭니다.
아이 방문이나 화장실 문처럼 안에서 잠기는 다른 문도 이 기회에 같이 확인해 두시면 좋습니다. / 바깥에서 여는 비상 구멍이 있는지, 열 수 있는 도구가 집에 있는지 알아 두면 당황할 일이 줄어듭니다.

# 문틀과 경첩도 한 번 살피기
문이 열린 김에 경첩 나사와 문틀 받침판도 손으로 만져 보세요. / 헐거운 나사가 있다면 걸쇠가 문틀에 물리는 원인이 됩니다.
문을 닫았을 때 위아래 틈이 고르지 않다면 문이 처진 것입니다. / 지금 당장 문제가 없어도 다음 문 잠김의 원인이 될 수 있으니 조정해 두는 편이 낫습니다.
@ 수서동 현관문 경첩 문틀 받침판 점검

# 문을 열 때 생긴 흔적 확인
덜 상하게 여는 방법을 쓰더라도 작업 후에는 도어락 외관과 문틀을 함께 확인합니다. / 긁힘이나 들뜬 부분이 없는지 사시는 분과 같이 보는 것이 순서입니다.
궁금한 점이 있으면 그 자리에서 물어보세요. / 작업 방식은 [현관문 개문](door-open.html)에 따로 설명해 두었습니다.

# 수리와 교체는 이렇게 판단합니다
점검하다 보면 손볼 곳이 보일 수 있습니다. / 부품 하나로 해결되면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드리고, 바꾸는 쪽이 나은 경우만 [도어락 교체](doorlock-replace.html)를 권합니다.
어떤 작업이든 손대기 전에 비용을 먼저 알려 드리고, 원하지 않으시면 하지 않습니다. / 문을 열지 못했다면 비용은 받지 않으며 진행 방식은 [이용안내](guide.html)에 있습니다.

# 다시 막히지 않게 해 주는 습관
- 배터리 경고음을 들은 날 바로 교체하기
- 새 건전지 한 세트와 9V 건전지 하나를 집과 가방에 나눠 두기
- 번호를 바꾸면 그날 가족 모두에게 직접 알리기
- 비상용 카드키 하나를 가까운 가족에게 맡기기
- 문 닫을 때 걸리는 느낌이 들면 미루지 않기
이 다섯 가지만 지켜도 문 앞에서 막히는 일이 크게 줄어듭니다. / 특히 비상용 카드키는 생각보다 자주 쓸모가 있으니 맡길 사람을 오늘 정해 두세요.

# 수서동 말고 강남구 다른 곳도
일원동, 세곡동, 개포동, 대치동, 도곡동, 역삼동, 삼성동, 청담동, 압구정동, 신사동, 논현동도 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
