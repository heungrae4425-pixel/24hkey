# 수서동 문 앞, 전화 걸기 전 2분
수서동은 강남구 동남쪽 끝자락에 자리한 주거 동네입니다. / 문이 안 열려 당황하면 전화부터 걸고 싶지만, 통화 중에 무엇을 말해야 할지 몰라 같은 질문을 여러 번 주고받게 되는 경우가 많습니다.
전화 걸기 전 2분만 써서 휴대폰 메모에 몇 줄 적어 두면 통화가 짧아지고 출발도 빨라집니다. / 맞는 장비를 처음부터 챙겨 오니 현장에서 기다리는 시간도 줄어듭니다.
이 글은 메모에 적을 항목을 상태, 문 종류, 위치, 사람, 사진 순서로 나눠 정리했습니다. / 아래 예시를 그대로 따라 적으셔도 됩니다.
@ 수서동 현관 도어락 상태 메모 정리

# 메모 첫 줄, 지금 무슨 일이 생겼는지
첫 줄에는 한 문장으로 상황을 적습니다. / 길게 쓸 필요 없이 '번호 눌러도 안 열림', '배터리 꺼짐', '열쇠 안에 두고 나옴'처럼 짧으면 충분합니다.
언제부터 그랬는지도 함께 적어 주세요. / 아침에 나올 때는 괜찮았는지, 며칠 전부터 경고음이 났는지에 따라 원인이 달라집니다.
가족이 비밀번호를 바꿨을 가능성이 있는지도 한 번 떠올려 보세요. / 그렇다면 전화하기 전에 가족에게 먼저 연락해 보는 것이 가장 빠릅니다.

# 둘째 줄, 번호판과 소리 상태
문 앞에서 아래 세 가지를 직접 해 보고 결과를 적어 두세요.
- 번호판을 손바닥으로 덮었을 때 불이 켜지는지
- 번호를 누르면 어떤 소리가 나는지 (삑, 삐삐삐, 아무 소리 없음)
- 열림 소리가 났을 때 손잡이나 몸체가 움직이는지
불이 아예 안 켜지면 배터리 쪽, 틀렸다는 소리가 나면 번호 쪽, 열림 소리는 나는데 안 열리면 걸쇠나 보조키 쪽일 가능성이 큽니다. / 이 한 줄만 있어도 전화로 원인을 반쯤 좁힐 수 있습니다.

# 셋째 줄, 문과 도어락 종류
도어락 모양을 적습니다. / 손잡이를 돌리는 형인지, 몸체를 밀거나 당기는 형인지, 번호판이 위로 열리는 덮개형인지 보시면 됩니다.
보조키나 손잡이 자물쇠가 따로 있는지도 적어 주세요. / 평소 보조키를 함께 잠그는 집이라면 꼭 말씀해 주셔야 합니다.
현관 앞에 중문이나 공동현관이 있다면 어느 문에서 막혔는지 구분해 주세요. / 막힌 문이 어디인지에 따라 챙길 장비가 다릅니다.
@ 수서동 도어락 형태 보조키 확인

# 넷째 줄, 정확한 위치
아파트라면 단지 이름과 동, 호수를 적습니다. / 공동현관 출입 방법과 경비실 위치까지 알면 더 좋습니다.
주택이나 빌라라면 건물 이름과 가까운 큰길, 눈에 띄는 건물을 함께 적어 주세요. / 내비게이션이 큰길에서 멈추는 곳이라면 들어오는 골목도 한 줄로 적어 두시면 됩니다.
차를 세울 곳이 있는지도 알려 주시면 도착 후 주차 자리를 찾느라 늦어지는 일이 없습니다.

# 다섯째 줄, 집 안과 문 앞 사람
집 안에 아이나 어르신, 반려동물이 있는지 꼭 적습니다. / 가스레인지나 다리미처럼 켜 두고 나온 것이 있다면 그것도 함께 적어 주세요.
이런 상황은 출발 순서를 앞당기는 이유가 됩니다. / 불, 물, 가스처럼 위험이 있는 상황이라면 열쇠집보다 119에 먼저 연락하셔야 합니다.
문 앞에 계신 분이 누구인지도 적어 두세요. / 사시는 분이 직접 계신지, 가족이 대신 기다리는지에 따라 거주 확인 방법이 달라집니다.

# 사진은 두 장이면 충분합니다
메모를 다 적었다면 사진 두 장을 찍어 둡니다. / 한 장은 바깥 번호판 정면, 다른 한 장은 문 전체가 보이게 한 걸음 물러서서 찍으면 됩니다.
번호판 아래쪽에 비상 전원 단자나 열쇠 구멍이 있다면 그 부분이 보이게 찍어 주세요. / 어두운 복도라면 휴대폰 손전등을 켜고 찍으면 훨씬 잘 보입니다.
사진은 통화가 끝난 뒤 같은 번호로 문자로 보내 주시면 됩니다. / 흐리게 나와도 괜찮습니다.
@ 수서동 출장열쇠 번호판 사진 문자 전송

# 메모 예시
아래처럼 적어 두시면 됩니다.
- 상황: 퇴근 후 번호 눌러도 안 열림, 어제부터 경고음
- 소리: 불은 켜지고 열림 소리 남, 문은 안 움직임
- 종류: 밀고 당기는 형, 보조키 없음
- 위치: 수서동 ○○아파트 ○동 ○호, 공동현관 비밀번호 있음
- 집 안: 고양이 한 마리
이 다섯 줄을 읽어 주시기만 하면 통화가 1분 안에 끝납니다. / 적어 둔 메모는 문이 열린 뒤에도 지우지 말고 두세요. 같은 일이 다시 생겼을 때 지난번과 무엇이 달랐는지 비교하기 좋습니다.

# 늦은 밤이나 날씨가 궂은 날이라면
밤이나 새벽에는 메모에 한 줄을 더 적어 주세요. / 복도 불이 꺼지는 건물인지, 경비실이 밤에도 열려 있는지 알려 주시면 도착 후 헤매지 않습니다.
비나 눈이 오는 날은 번호판에 물기가 묻어 오작동하는 경우도 있습니다. / 마른 수건이나 휴지로 번호판을 닦고 몇 분 뒤 다시 눌러 본 결과도 메모에 적어 두시면 원인을 가리는 데 도움이 됩니다.
추운 날 밖에서 오래 기다리셔야 한다면 가까운 편의점이나 경비실 안에서 기다리셔도 됩니다. / 도착하면 그 번호로 바로 전화드립니다.

# 통화할 때 물어보시면 좋은 것
메모를 읽어 주신 뒤에는 아래를 물어보세요. / 대략 언제 도착하는지, 비용은 언제 알려 주는지, 못 열면 비용이 있는지입니다.
저희는 도착 예정 시간을 먼저 말씀드리고, 비용은 현장에서 상태를 본 뒤 작업 전에 알려 드립니다. / 문을 끝내 못 열면 비용은 받지 않습니다.

# 기다리는 동안 챙길 것
거주 확인에 쓸 것을 미리 떠올려 두세요. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 경비실이나 관리사무소에 미리 말해 두시면 도착 후 확인이 빨리 끝납니다. / 번호를 계속 눌러 보는 것은 입력이 막힐 수 있으니 멈춰 주세요. / 손잡이를 세게 당기거나 문틈에 도구를 넣는 것도 도어락과 문틀을 상하게 하니 그대로 두고 기다려 주세요.

# 도착하면 이렇게 진행됩니다
거주 확인을 마치고 상태를 본 뒤 비용을 먼저 말씀드립니다. / 동의하시면 덜 상하는 방법부터 [현관문 개문](door-open.html)을 진행하고, 연 뒤에는 도어락이 다시 잘 잠기는지 함께 확인합니다.
고장이 보이면 [도어락 수리](doorlock-repair.html)로 손볼지, [도어락 교체](doorlock-replace.html)가 나을지 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 수서동에서 강남구 북쪽 끝까지
일원동, 세곡동, 개포동, 대치동은 물론 도곡동, 역삼동, 삼성동, 청담동, 압구정동, 신사동, 논현동까지 다닙니다. / 강남 출장 동네는 [강남구 출장열쇠](seoul-gangnam.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 전화 전 준비, 자주 묻는 질문
? 메모 없이 바로 전화해도 되나요? | 물론입니다. 질문을 순서대로 드리니 답만 해 주셔도 됩니다. 메모가 있으면 조금 더 빨라질 뿐입니다.
? 사진은 꼭 보내야 하나요? | 필수는 아닙니다. 보내 주시면 맞는 장비를 미리 챙길 수 있습니다.
? 공동현관 비밀번호를 알려 드려야 하나요? | 아니요. 도착할 때 열어 주시거나 경비실에 말해 두셔도 됩니다.
? 고양이가 있는데 문을 열 때 나가지 않을까요? | 작업 전에 위치를 함께 정하고 문을 조금만 열어 들어가도록 하겠습니다.
? 준비를 다 했는데도 못 열면 어떻게 되나요? | 아닙니다. 열지 못하면 비용은 받지 않습니다.

# 마무리

24시출장열쇠는 메모가 없어도, 한밤중이어도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
