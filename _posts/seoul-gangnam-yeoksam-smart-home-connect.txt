# 역삼동, 문 열림 알림이 어느 날부터 조용해졌다면
역삼동은 역삼역과 선릉역 사이로 사무실 건물과 원룸, 오피스텔이 빽빽하게 들어선 강남구 동네입니다. / 혼자 사는 분이 많아서 집을 비운 동안 문이 열리고 닫히는 알림을 휴대폰으로 받아 보는 집도 늘었습니다.
그런데 어느 날부터 알림이 오지 않거나, 앱에서 도어락이 연결 끊김으로만 보이는 경우가 있습니다. / 문 자체는 잘 열리니 미루기 쉽지만, 알림을 믿고 지내던 분에게는 꽤 신경 쓰이는 일입니다.
이 글은 앱 연동이 안 될 때 어디부터 확인하면 되는지 순서대로 정리했습니다. / 제품마다 메뉴 이름은 다르지만 확인하는 흐름은 비슷합니다.
@ 역삼동 오피스텔 도어락 앱 알림 연동 확인

# 연동은 생각보다 여러 단계를 거칩니다
도어락에서 휴대폰까지 알림이 오려면 몇 단계를 거쳐야 합니다. / 하나라도 끊기면 알림이 오지 않습니다.
- 도어락 안쪽의 통신 모듈이 신호를 보냄
- 집 안의 중계 장치나 공유기가 신호를 받음
- 인터넷을 거쳐 제조사 서버로 전달됨
- 서버가 휴대폰 앱으로 알림을 보냄
어느 단계에서 끊겼는지 알면 해결이 빨라집니다. / 아래 순서는 손쉬운 것부터 차례로 적었습니다.

# 가장 먼저 휴대폰 쪽을 보세요
의외로 가장 흔한 원인은 휴대폰 설정입니다. / 휴대폰을 바꿨거나 운영체제를 업데이트한 뒤 알림 권한이 꺼지는 경우가 많습니다.
휴대폰 설정에서 그 앱의 알림 허용, 백그라운드 실행 허용, 배터리 절약 예외를 확인해 보세요. / 앱에 다시 로그인해야 하는 경우도 있으니 한 번 로그아웃했다가 들어가 보는 것도 방법입니다.
가족 계정으로 공유받아 쓰는 경우에는 공유한 사람이 권한을 바꿨는지도 확인해 보세요. / 앱 자체 업데이트가 밀려 있으면 그것부터 마치고 다시 보세요.

# 도어락 배터리가 약해도 통신이 먼저 멈춥니다
배터리가 줄어들면 도어락은 문을 여닫는 기본 기능을 지키려고 통신 기능부터 줄이는 경우가 있습니다. / 경고음이 아직 안 났어도 알림이 띄엄띄엄 온다면 배터리를 의심해 볼 만합니다.
통신 기능을 쓰는 도어락은 일반 번호키보다 배터리를 빨리 씁니다. / 알림이 이상하다면 들어 있는 건전지를 한꺼번에 새것으로 바꾸고 다시 확인해 보세요.
@ 역삼동 도어락 배터리 교체 후 앱 재연결

# 공유기와 중계 장치 확인
도어락이 직접 와이파이에 붙는 제품도 있고, 집 안에 작은 중계 장치를 따로 꽂아 쓰는 제품도 있습니다. / 중계 장치가 있다면 콘센트에서 빠지지 않았는지, 불빛이 평소와 같은지 먼저 보세요.
공유기를 새것으로 바꿨거나 와이파이 이름과 비밀번호를 바꿨다면 도어락은 예전 정보로 계속 접속하려다 실패합니다. / 이 경우 앱에서 기기를 다시 등록하는 과정이 필요합니다.
도어락이 지원하는 와이파이 종류가 정해져 있는 제품도 있습니다. / 공유기 설정이 바뀐 뒤 갑자기 끊겼다면 이 부분도 제품 설명서에서 한 번 확인해 보세요.

# 오피스텔은 거리와 벽이 변수입니다
원룸과 오피스텔은 공유기를 방 안쪽 깊숙이 두는 경우가 많습니다. / 현관과 공유기 사이에 벽이나 붙박이장이 있으면 신호가 약해져 연결이 들쭉날쭉해집니다.
현관 가까운 곳으로 공유기나 중계 장치를 옮겨 보거나, 잠시 현관 앞에서 휴대폰 와이파이 세기를 확인해 보세요. / 신호가 겨우 잡히는 정도라면 위치를 옮기는 것만으로 해결되는 경우가 많습니다.
건물에서 제공하는 공용 인터넷을 쓰는 오피스텔은 기기 접속에 제한이 있는 경우도 있습니다. / 이럴 때는 관리실에 기기 등록이 가능한지 물어보셔야 합니다.

# 다시 등록할 때 조심할 점
앱에서 기기를 지우고 다시 등록하면 대부분 해결됩니다. / 다만 순서를 잘못 밟으면 도어락에 저장된 번호나 카드까지 함께 지워지는 제품이 있습니다.
- 다시 등록하기 전에 문을 열어 두고 안쪽에서 작업하기
- 지금 쓰는 번호와 카드가 무엇인지 적어 두기
- 설명서에서 '기기 초기화'와 '통신 초기화'가 따로인지 확인하기
- 등록이 끝나면 바깥에서 번호로 한 번 열어 보기
도어락 전체 초기화를 하면 번호가 공장 상태로 돌아갈 수 있습니다. / 문을 닫은 상태에서 이 작업을 하다가 바깥에서 못 들어오는 일이 생기니 꼭 문을 열어 둔 채로 하세요.

# 원격 열림 기능을 쓰고 있다면
앱으로 멀리서 문을 열어 주는 기능은 편하지만, 연결이 불안정할 때는 오히려 걱정거리가 됩니다. / 손님이 문 앞에 있는데 원격 열림이 안 되면 대신 쓸 방법을 하나 더 마련해 두세요.
일회용 번호나 손님용 카드처럼 통신 없이도 쓸 수 있는 방법을 함께 준비해 두면 마음이 편합니다. / 원격 기능을 거의 쓰지 않는다면 꺼 두는 것이 배터리와 보안 면에서 낫습니다.
@ 역삼동 원룸 도어락 원격 열림 대체 방법

# 알림은 오는데 기록이 이상할 때
문을 열지 않았는데 열림 알림이 왔다면 먼저 당황하지 말고 시간을 확인해 보세요. / 배터리를 바꾸거나 설정을 만진 시간에 맞춰 기록이 남는 경우가 있습니다.
그래도 이해되지 않는 기록이 반복된다면 등록된 번호와 카드를 정리하고, 필요하면 비밀번호를 바꾸세요. / 불안한 마음이 크시면 점검을 받아 등록 상태를 함께 확인해 드립니다.

# 이럴 땐 점검을 받아 보세요
앱 설정, 배터리, 공유기를 다 확인했는데도 연결이 안 된다면 도어락 안쪽 통신 모듈 문제일 수 있습니다. / 모듈이 따로 끼워지는 제품은 모듈만 바꾸면 되고, 몸체와 한 덩어리인 제품은 수리 범위가 달라집니다.
점검은 [도어락 수리](doorlock-repair.html)로 진행하고, 오래된 제품이라 부품을 구하기 어려우면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 비용은 상태를 본 뒤 작업 전에 먼저 말씀드립니다.

# 연동이 꼬여 문이 안 열린다면
초기화나 재등록 도중에 번호가 바뀌어 문이 닫혀 버렸다면 혼자 계속 누르지 마세요. / 사시는 분인지 신분증이나 우편물, 관리실 확인으로 확인한 뒤 [현관문 개문](door-open.html)을 진행하고, 연 뒤에 등록을 다시 정리해 드립니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 역삼동 말고 강남구 어디든
논현동, 삼성동, 대치동, 도곡동은 물론 신사동, 압구정동, 청담동, 개포동, 일원동, 수서동, 세곡동까지 다닙니다. / 강남 출장 동네는 [강남구 출장열쇠](seoul-gangnam.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
