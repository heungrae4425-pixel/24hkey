# 발산동 새집, 현관 번호는 누가 알고 있을까
발산역 주변으로 이사를 오면 짐 정리보다 먼저 챙겨야 할 것이 하나 있습니다. / 바로 현관 도어락에 누구의 번호와 카드가 남아 있는지입니다.
전에 살던 분, 집을 보여 준 중개 쪽, 입주 청소를 맡았던 분, 도배나 수리를 했던 분까지 번호를 알았을 수 있습니다. / 나쁜 뜻이 없더라도 내 집 번호를 여러 사람이 아는 상태는 정리해 두는 게 좋습니다.
이 글은 발산동에서 이사한 날 도어락을 초기화하고 새 번호를 넣는 순서를 시간 흐름대로 적었습니다. / 문이 막혔을 때는 [강서구 출장열쇠](seoul-gangseo.html)로 연락 주시면 됩니다.
@ 발산동 이사 후 도어락 초기화 비밀번호 재설정

# 짐이 들어오기 전, 도어락 앞뒤 사진부터
이삿짐 차가 오기 전 비어 있는 현관에서 도어락 바깥쪽과 안쪽을 한 장씩 찍어 두세요. / 제조사 이름이나 모델명이 보이면 그 부분도 가까이 찍습니다.
이 사진이 있으면 설명서를 찾을 때도, 나중에 고장이 나서 전화할 때도 훨씬 수월합니다. / 이전 세입자가 붙여 둔 스티커나 메모가 있다면 그것도 같이 남겨 둡니다.
배터리 덮개를 열어 건전지가 언제 들어간 것인지 모르겠다면 이 기회에 새것으로 바꾸는 편이 낫습니다. / 이사 첫 주는 문을 여닫는 횟수가 평소보다 훨씬 많아서 남은 건전지가 금방 바닥나기 쉽습니다.
바꿀 때는 같은 규격으로 전부 한꺼번에 넣고, 덮개 안쪽에 넣은 날짜를 적어 두세요.

# 초기화 버튼은 대개 안쪽 몸체에 있습니다
대부분의 도어락은 안쪽 배터리 덮개 근처나 덮개 안에 작은 등록 버튼이나 초기화 버튼이 있습니다. / 버튼 모양과 누르는 시간은 제품마다 달라서 사진으로 모델을 확인하는 게 먼저입니다.
초기화를 하면 등록된 번호, 카드, 지문이 한꺼번에 지워지는 제품이 많습니다. / 일부 제품은 번호만 바뀌고 카드는 남기도 하니 끝난 뒤 하나씩 확인해야 합니다.
설명서가 없어도 모델명으로 찾으면 순서가 나오는 경우가 많습니다. / 그래도 모르겠다면 사진을 보내 주시면 순서를 알려드립니다.

# 문은 반드시 열어 둔 채로 작업하세요
초기화와 번호 등록은 꼭 현관문을 열어 둔 상태에서 하세요. / 중간에 순서가 꼬였는데 문이 닫혀 있으면 이사 첫날부터 밖에 서 있게 됩니다.
문이 바람에 닫히지 않게 신발이나 상자로 받쳐 두면 안심이 됩니다. / 새 번호를 넣은 뒤에도 문을 연 채로 바깥 번호판에서 두세 번 눌러 열림 동작을 확인합니다.

# 이삿짐이 오가는 동안 번호는 잠시 미뤄도 됩니다
이삿짐 직원들이 드나드는 동안에는 문이 계속 열려 있는 경우가 많습니다. / 이때 새 번호를 넣어 두면 직원에게 다시 알려줘야 하는 일이 생기기도 합니다.
짐이 다 들어오고 사람들이 나간 뒤 차분히 초기화하는 순서가 더 깔끔합니다. / 대신 짐 들이는 동안 도어락이 자동으로 잠기지 않게 문 고정만 신경 써 주세요.
@ 발산동 새집 현관 도어락 등록 버튼 확인

# 새 번호 정할 때 피할 조합
- 생일, 전화번호 뒷자리처럼 남이 짐작할 수 있는 숫자
- 같은 숫자 반복이나 1234 같은 순서대로 누르는 번호
- 이전 집에서 쓰던 번호를 그대로 옮겨 오는 것
- 너무 길어서 가족이 자꾸 틀리는 번호
가족이 같이 정하고 한 번씩 직접 눌러 보게 하면 첫 주에 막히는 일이 줄어듭니다. / 번호를 누른 뒤 아무 숫자를 더 누르는 허수 입력 기능이 있다면 그것도 익혀 두세요.

# 카드와 지문은 사람 수대로 다시 등록
이전 세입자가 쓰던 카드는 초기화로 지운 뒤 우리 식구 카드만 새로 넣습니다. / 카드를 몇 장 받았는지, 지금 몇 장을 등록했는지 적어 두면 분실했을 때 정리가 쉽습니다.
지문을 쓰는 도어락이라면 손가락마다 한두 개씩 넉넉히 등록하세요. / 손을 다치거나 겨울에 손이 트면 한 손가락만으로는 인식이 안 될 때가 있습니다.
카드나 지문만 믿고 번호를 등록하지 않는 집도 있는데, 하나쯤은 꼭 넣어 두세요. / 카드를 두고 나오거나 지문이 안 먹는 날 번호가 마지막 길이 됩니다.

# 열쇠 구멍과 보조키도 잊지 마세요
도어락 비상 열쇠 구멍이나 별도의 보조키가 있다면 그 열쇠를 누가 갖고 있는지도 생각해야 합니다. / 이전 사람이 복사해 둔 열쇠가 있을 수 있기 때문입니다.
열쇠까지 깔끔하게 정리하고 싶다면 실린더만 바꾸는 방법도 있습니다. / 도어락 자체가 오래됐다면 이참에 [도어락 교체](doorlock-replace.html)를 함께 생각해 보셔도 됩니다.

# 번호를 몰라 처음부터 못 들어갈 때
열쇠만 받고 번호를 전달받지 못했거나, 받은 번호가 맞지 않는 경우가 있습니다. / 이럴 때는 집주인이나 중개 쪽에 먼저 확인해 보세요.
연락이 안 되거나 받은 번호가 계속 틀린다면 여러 번 누르지 마시고 연락 주세요. / 입력을 반복하면 한동안 번호판이 잠겨 기다려야 합니다.
이삿짐 차가 밖에서 기다리고 있다면 그 상황도 같이 말씀해 주세요. / 도착 예상 시간을 먼저 알려드려 짐을 내릴지 기다릴지 정하실 수 있게 합니다.

# 거주 확인은 이사 직후라 더 꼼꼼히
이사 첫날에는 신분증 주소가 아직 예전 집으로 되어 있는 경우가 대부분입니다. / 이럴 때는 임대차 계약서나 매매 계약서, 관리사무소 확인, 새 주소로 온 우편물 중 하나로 확인합니다.
계약서 사진을 휴대폰에 찍어 두셨다면 그것도 도움이 됩니다. / 확인이 되어야 문을 열 수 있으니 미리 꺼내 두세요.

# 비용과 진행은 문을 보고 먼저 말씀드립니다
문을 여는 일인지, 초기화와 등록만 도와드리면 되는 일인지에 따라 작업이 달라집니다. / 어느 쪽이든 상태를 보고 비용을 먼저 말씀드린 뒤 동의하실 때 시작합니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 자세한 순서는 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 적어 두었습니다.

# 일주일 뒤 한 번 더 점검
새 번호로 일주일쯤 지내 보면 불편한 점이 보입니다. / 아이가 자꾸 틀린다면 카드를 하나 더 만들고, 번호판 반응이 느리다면 배터리를 다시 봅니다.
번호를 바꿨다는 사실을 가족 단체 대화방에 남겨 두면 누가 언제 바꿨는지 헷갈리지 않습니다. / 아이 학원 선생님이나 돌봄 선생님처럼 꼭 알아야 하는 분께는 따로 전해 주세요.
잠금이 한 번에 안 되거나 소리가 이상하면 [도어락 수리](doorlock-repair.html)로 점검을 받아 두세요. / 이사 초기에 잡아 두면 오래 편하게 씁니다.
@ 발산동 이사 후 새 비밀번호 등록 점검

# 발산동 말고 강서구 다른 곳도
발산동과 붙어 있는 마곡동, 가양동, 화곡동은 물론 공항동, 방화동, 등촌동, 염창동까지 다닙니다. / 강서구 바깥은 [출장 지역](area.html)에서 확인해 보세요.

? 이전 세입자 번호만 골라 지울 수 있나요? | 사용자 번호를 따로 관리하는 제품이 아니라면 전체 초기화 후 새로 등록하는 편이 확실합니다.
? 이사 첫날이라 신분증 주소가 달라요. | 계약서, 관리사무소 확인, 새 주소 우편물로도 확인할 수 있습니다.
? 초기화만 도와주셔도 되나요? | 네, 문이 열려 있는 상태에서 설정만 도와드릴 수 있습니다.
? 열지 못하면 비용이 나오나요? | 열지 못하면 받지 않습니다.
