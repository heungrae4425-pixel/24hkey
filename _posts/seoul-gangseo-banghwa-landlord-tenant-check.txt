# 방화동 셋집 도어락이 고장 났을 때
방화동은 강서구 서쪽 끝자락에 주택과 빌라, 아파트가 섞여 있는 동네로 세를 들어 사는 집도 적지 않습니다. / 셋집 도어락이 고장 나면 문을 여는 일보다 누구와 먼저 이야기해야 하는지가 더 고민이 됩니다.
집주인은 멀리 살고 세입자는 당장 문을 써야 하는 상황이 흔합니다. / 서로 연락이 엇갈리다 보면 작은 고장이 감정 다툼으로 번지기도 합니다.
이 글은 방화동에서 도어락 문제가 생겼을 때 집주인과 세입자가 차분히 정리할 수 있도록 확인할 것을 순서대로 적었습니다. / 비용 부담이나 책임은 계약 내용과 상황에 따라 달라서 여기서 단정하지 않고, 이야기를 나눌 때 필요한 사실을 모으는 데 초점을 맞췄습니다.
@ 방화동 빌라 현관 도어락 고장 상태 확인

# 먼저 계약서를 펼쳐 보세요
도어락처럼 집에 붙어 있는 설비를 누가 손볼지는 계약서에 적혀 있는 경우가 있습니다. / 특약란에 수리나 소모품 이야기가 있는지 먼저 확인해 보세요.
계약서에 따로 적힌 것이 없다면 서로 의논해서 정하게 됩니다. / 판단이 어렵다면 계약을 중개한 곳이나 관련 상담 창구에 물어보는 방법도 있습니다.
여기서는 어느 쪽이 부담해야 한다고 말씀드리지 않습니다. / 다만 의논할 때 필요한 사실을 정리해 두면 이야기가 훨씬 빨라집니다.

# 고장 상태를 기록해 두는 법
의논을 시작하기 전에 지금 상태를 있는 그대로 남겨 두세요. / 나중에 언제부터, 어떻게 고장 났는지를 두고 기억이 엇갈리는 일을 막을 수 있습니다.
- 번호판이 켜지는지, 꺼졌는지 사진이나 짧은 영상
- 경고음이 나면 소리가 들리게 찍은 영상
- 도어락 앞면과 안쪽 몸체, 제품 이름이 보이는 사진
- 증상이 처음 나타난 날짜와 그 뒤 변화
- 배터리를 언제 바꿨는지
영상은 짧아도 괜찮습니다. / 번호를 눌렀을 때 어떤 반응인지가 보이면 원인을 짐작하는 데 큰 도움이 됩니다.

# 소모품 문제인지 고장인지 가려 보기
도어락이 안 될 때 가장 흔한 원인은 배터리 방전입니다. / 배터리는 쓰는 사람이 갈아 끼우는 소모품으로 보는 경우가 많아, 먼저 새 배터리로 바꿔 보는 것이 순서입니다.
배터리를 바꿨는데도 같은 증상이라면 부품 고장일 수 있습니다. / 이때부터는 집주인에게 알리고 함께 방법을 정하는 편이 좋습니다.
문틀이 처져서 걸쇠가 걸리는 경우처럼 건물 상태가 원인인 일도 있습니다. / 방화동 오래된 주택에서는 도어락보다 문과 경첩 쪽이 먼저 문제인 경우도 있어 원인을 정확히 보는 것이 중요합니다.
@ 방화동 주택 현관문 경첩 처짐 걸쇠 확인

# 집주인에게 알릴 때 담을 내용
연락은 문자나 메신저처럼 기록이 남는 방식이 좋습니다. / 통화로 이야기했더라도 끝난 뒤 요점을 문자로 한 번 정리해 보내 두세요.
알릴 때는 이렇게 담으면 됩니다. / 언제부터 어떤 증상인지, 배터리는 바꿔 봤는지, 지금 문을 쓸 수 있는지, 사진과 영상을 함께 보낸다는 것입니다.
집주인이 직접 업체를 부를지, 세입자가 부르고 나중에 정리할지도 이때 정하시면 됩니다. / 미리 정해 두지 않으면 같은 날 두 곳이 오거나 아무도 오지 않는 일이 생깁니다.

# 문이 잠겨 급할 때는 어떻게 하나
퇴근했는데 문이 안 열리고 집주인과 연락이 안 되는 밤도 있습니다. / 이럴 때는 우선 들어가야 하니 출장열쇠를 부르시면 됩니다.
현장에서는 사시는 분이 맞는지 신분증 주소, 우편물, 계약서 등으로 확인한 뒤 엽니다. / 집주인 허락이 없어도 거주가 확인되면 문을 여는 것은 가능합니다.
다만 문을 연 뒤 도어락을 바꾸거나 큰 수리를 하는 것은 집주인과 이야기해 본 다음에 하시길 권합니다. / 급하게 결정하면 나중에 서로 서운한 일이 생길 수 있습니다.

# 현장에서 받아 두면 좋은 것
출장열쇠가 와서 원인을 확인하면 무엇이 문제였는지 설명을 들으세요. / 배터리였는지, 부품 고장인지, 문틀 문제인지를 알면 집주인과 이야기하기 훨씬 쉽습니다.
작업 전과 후 사진을 찍어 두시는 것도 좋습니다. / 저희는 작업 전에 비용을 먼저 말씀드리니 그 내용도 메모해 두시면 정리에 도움이 됩니다.
작업 내용과 비용을 적은 영수증이나 확인 문자를 받아 두세요. / 나중에 정산 이야기를 할 때 근거가 됩니다.
@ 방화동 출장열쇠 작업 전후 기록 정리

# 수리와 교체를 의논할 때
고쳐 쓸 수 있는 상태라면 수리가 서로에게 부담이 적습니다. / 부품을 구하기 어렵거나 고장이 반복된다면 교체를 의논하게 됩니다.
교체를 한다면 어떤 제품으로 할지, 기존 구멍에 맞는지, 비밀번호나 카드는 누가 관리할지까지 같이 정해 두세요. / 수리 기준은 [도어락 수리](doorlock-repair.html), 교체 기준은 [도어락 교체](doorlock-replace.html)에 정리했습니다.
현장에서 상태를 보고 수리로 될지 먼저 말씀드립니다. / 집주인께 직접 설명이 필요하시면 통화로 상황을 전해 드릴 수도 있습니다.

# 세입자가 바뀔 때 챙길 것
이사 나가는 날에는 등록한 카드와 번호를 지우고 받은 열쇠를 모두 돌려 드리세요. / 새로 들어오는 분이 이전 번호를 그대로 쓰지 않도록 하는 배려이기도 합니다.
집주인 입장에서는 새 세입자가 들어오기 전에 도어락 초기화와 배터리 교체를 해 두면 좋습니다. / 들어오는 날 바로 새 번호를 등록할 수 있게 설정 방법을 알려 드리면 첫날부터 편해집니다.

# 서로 편해지는 작은 약속
- 배터리 교체는 누가 할지 미리 정해 두기
- 고장 연락은 기록이 남는 문자로 하기
- 급할 때 세입자가 먼저 불러도 되는 범위 정하기
- 여벌 열쇠나 카드를 누가 갖고 있을지 정하기
작은 약속이지만 있으면 고장이 나도 다툼 없이 넘어갈 가능성이 커집니다. / 계약을 새로 하거나 연장할 때 이런 내용을 특약으로 적어 둘지 중개한 곳과 함께 이야기해 보시는 것도 방법입니다.
집주인이 여러 세대를 관리한다면 세대마다 도어락 제품과 교체 날짜를 표로 정리해 두세요. / 어느 집에서 연락이 와도 바로 상황을 짐작할 수 있습니다.

# 비용 안내와 진행 방식
저희는 문과 도어락을 본 뒤 작업 전에 비용을 먼저 말씀드리고, 동의하실 때만 진행합니다. / 집주인과 상의가 필요하시면 통화하실 시간을 드립니다.
문을 열지 못하면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에, 개방 과정은 [현관문 개문](door-open.html)에 있습니다.

# 방화동 말고 강서구 어디든
방화동과 가까운 공항동, 마곡동, 발산동은 물론 염창동, 등촌동, 화곡동, 가양동까지 다닙니다. / 강서구 안내는 [강서구 출장열쇠](seoul-gangseo.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 집주인께 직접 설명해 주실 수 있나요? | 원하시면 통화로 상태를 전해 드립니다.

# 마무리
