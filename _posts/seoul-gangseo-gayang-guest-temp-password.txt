# 가양동 집 번호, 누군가에게 알려줘야 할 때
가양동은 가양역 주변으로 아파트 단지가 넓게 들어선 동네라 맞벌이 가정과 어르신 혼자 사시는 집이 함께 많습니다. / 그러다 보니 가사도우미, 아이 돌봄 선생님, 어르신 방문 요양 선생님처럼 가족이 아닌 분이 현관을 드나드는 일이 흔합니다.
매번 문을 열어 드리기 어려우면 결국 비밀번호를 알려 드리게 됩니다. / 이때 가족이 쓰는 번호를 그대로 알려 주기보다 임시 번호를 따로 만들어 두면 관리가 훨씬 편해집니다.
이 글은 가양동 아파트 도어락에서 임시 비밀번호를 쓰는 방법과 정리하는 요령을 담았습니다. / 설정이 막히면 [강서구 출장열쇠](seoul-gangseo.html)로 물어보셔도 됩니다.
@ 가양동 아파트 도어락 임시 비밀번호 설정

# 왜 가족 번호를 그대로 알려주면 곤란할까
한 번 알려 준 번호는 생각보다 오래 남습니다. / 도우미 선생님이 바뀌거나 손님이 다녀간 뒤에도 그 번호를 계속 쓰고 있다면 누가 알고 있는지 정리하기 어렵습니다.
가족 번호를 바꾸면 그날부터 가족 모두 새 번호를 외워야 합니다. / 어르신이나 아이가 있는 집은 번호가 바뀔 때마다 문 앞에서 헷갈리는 일이 생깁니다.
임시 번호를 따로 두면 가족 번호는 그대로 두고 외부 분 번호만 지우거나 바꾸면 됩니다. / 사람이 바뀔 때마다 집 전체를 흔들지 않아도 되는 셈입니다.

# 우리 집 도어락이 지원하는지 먼저 보기
도어락마다 임시 번호를 다루는 방식이 다릅니다. / 크게 보면 아래 세 가지 중 하나인 경우가 많습니다.
- 사용자 번호를 여러 개 등록할 수 있는 제품
- 한 번 쓰면 사라지는 일회용 번호를 만들 수 있는 제품
- 번호는 하나뿐이고 카드나 태그를 추가로 등록하는 제품
안쪽 몸체 배터리 덮개 근처에 설정 버튼이 있고 제품 이름이 적혀 있는 경우가 많습니다. / 제품명을 모르면 앞뒤 사진을 찍어 보내 주시면 어떤 방식인지 알려드립니다.

# 여러 번호를 등록할 수 있다면
사용자 번호를 추가할 수 있는 도어락이라면 가족용과 외부용을 나눠 두세요. / 외부용 번호는 가족 번호와 겹치는 숫자가 적게 정하는 것이 좋습니다.
돌봄 선생님이 바뀌면 그 번호만 삭제하고 새 번호를 등록하면 됩니다. / 등록과 삭제는 대개 문이 열린 상태에서 안쪽 설정 버튼으로 합니다.
어떤 번호를 누구에게 줬는지 휴대폰 메모에 적어 두세요. / 몇 달 지나면 기억이 흐려져서 정리할 때 헷갈립니다.
@ 가양동 현관 도어락 사용자 번호 추가 등록

# 번호가 하나뿐인 도어락이라면
사용자 번호를 하나만 쓸 수 있다면 방법이 조금 달라집니다. / 외부 분이 오시는 기간에만 쓸 번호로 잠시 바꿨다가 끝나면 가족 번호로 되돌리는 식입니다.
번거롭다면 카드나 태그를 한 장 더 등록해 외부 분께 드리는 것도 방법입니다. / 그분이 그만두실 때 카드를 돌려받고, 혹시 못 받았다면 등록을 지우면 됩니다.
카드를 지울 때는 대부분 전체 삭제 후 남은 카드만 다시 등록해야 합니다. / 가족 카드도 같이 지워지니 다시 등록할 카드를 미리 모아 두세요.

# 일회용 번호를 쓸 때 주의할 점
택배 기사님이나 잠깐 들르는 손님처럼 한 번만 들어오면 되는 경우에는 일회용 번호가 편합니다. / 한 번 문을 열면 자동으로 사라지는 기능이라 따로 지울 필요가 없습니다.
다만 손님이 문을 열고 나갔다가 다시 들어와야 하는 상황이면 두 번째에는 번호가 먹지 않습니다. / 쓰기 전에 몇 번 드나드실지 미리 여쭤보는 게 좋습니다.

# 번호를 알려줄 때 같이 전할 것
번호만 알려 드리고 끝내면 현장에서 막히는 일이 생깁니다. / 아래 내용을 함께 전해 두세요.
- 번호를 누르기 전에 번호판을 손으로 덮어 켜는 방식인지
- 번호 입력 후 별표나 확인 버튼을 눌러야 하는지
- 나갈 때 자동으로 잠기는지, 버튼을 눌러야 하는지
- 경고음이 나면 어디로 연락해야 하는지
- 안쪽 보조키는 건드리지 말아 달라는 부탁
문자로 보내실 때는 번호와 동 호수를 한 메시지에 같이 쓰지 않는 편이 낫습니다. / 메시지가 다른 사람에게 보이더라도 어느 집 번호인지 바로 알 수 없게 하는 작은 습관입니다.

# 보조키는 외부 분께 맡기지 않는 게 편합니다
가양동 아파트 중에는 도어락 위나 아래에 보조키를 따로 단 집이 있습니다. / 외부 분이 실수로 보조키를 잠그고 나가시면 가족이 돌아와 열쇠 없이 막히게 됩니다.
보조키를 쓰지 않는 기간이라면 아예 열린 상태로 두고 알려 드리는 게 안전합니다. / 혹시 잠겼다면 열쇠 위치를 확인해 보시고, 열쇠가 없으면 그때 연락 주세요.

# 부모님 댁에 오시는 선생님께 알려드릴 때
자녀가 멀리 살고 부모님 댁에 방문 요양 선생님이 오시는 경우라면 번호 관리를 누가 할지 먼저 정해 두세요. / 부모님이 직접 설정하기 어려우시면 자녀가 들를 때 한 번에 정리하는 편이 낫습니다.
부모님이 번호를 자주 잊으신다면 선생님용 번호와 부모님 번호를 비슷하게 만들지 않는 것이 오히려 덜 헷갈립니다. / 누구 번호인지 메모를 냉장고 같은 집 안쪽에 붙여 두시면 도움이 됩니다.

# 계약이 끝나면 바로 정리하세요
돌봄이나 도우미 일이 끝난 날 외부용 번호와 카드를 정리하는 것을 습관으로 삼으세요. / 미루다 보면 몇 달이 지나도 그대로 남아 있게 됩니다.
정리할 때는 외부용 번호 삭제, 추가 카드 회수나 삭제, 메모 정리까지 한 번에 하시면 됩니다. / 가족 번호도 오래됐다면 이참에 함께 바꿔 두는 것도 좋습니다. / 정리한 날짜를 메모에 남겨 두면 다음에 누가 언제까지 번호를 알았는지 바로 확인할 수 있습니다.
@ 가양동 도어락 임시 번호 삭제와 카드 정리

# 설정하다가 문이 잠겼다면
번호를 바꾸다 순서를 틀려 새 번호도 옛 번호도 안 먹는 경우가 가끔 있습니다. / 문이 열린 상태에서 설정하면 이런 일을 대부분 피할 수 있습니다.
이미 밖에서 잠긴 상황이라면 억지로 여러 번 누르지 말고 연락 주세요. / 도착하면 사시는 분인지 신분증이나 관리사무소 세대 확인으로 먼저 확인하고, 비용을 말씀드린 뒤 엽니다.
열지 못하고 돌아가면 비용은 받지 않습니다. / 개방 과정은 [현관문 개문](door-open.html)에, 진행 방식은 [이용안내](guide.html)에 있습니다.

# 이참에 도어락을 바꾸고 싶다면
지금 도어락이 번호 하나만 쓸 수 있어 불편하다면 사용자 번호를 여러 개 지원하는 제품으로 바꾸는 것도 방법입니다. / 문 두께와 기존 구멍을 보고 맞는 제품을 말씀드리며, 자세한 내용은 [도어락 교체](doorlock-replace.html)에 있습니다.

# 가양동 말고 강서구 어디든
가양동과 이어진 등촌동, 염창동, 마곡동은 물론 화곡동, 발산동, 공항동, 방화동까지 출동합니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 도우미 선생님 번호만 지울 수 있나요? | 사용자 번호를 여러 개 지원하는 제품이라면 그 번호만 지울 수 있습니다.
? 카드 한 장만 골라 삭제가 되나요? | 제품에 따라 다르며, 대개는 전체 삭제 후 필요한 카드만 다시 등록합니다.
? 설정하다 잠겨 버렸어요. | 여러 번 누르지 마시고 연락 주세요. 확인 후 상하지 않게 엽니다.
? 번호 설정만 부탁해도 되나요? | 네, 문이 열린 상태에서 설정만 도와드릴 수도 있습니다.
