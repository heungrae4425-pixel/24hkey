# 가양동 현관문이 마지막 한 뼘을 못 채울 때
가양역 주변에는 오래 사람이 살아온 아파트 단지가 넓게 자리 잡고 있습니다. / 이런 집 현관문은 도어락보다 문 위쪽의 도어클로저와 옆쪽 경첩이 먼저 지치는 경우가 많습니다.
문을 놓으면 스르르 닫히다가 마지막에 멈추거나, 문틀에 툭 부딪히고 튕겨 나오는 증상이 대표적입니다. / 그러면 자동 잠김 도어락이 잠그지 못하고, 밤새 문이 살짝 열린 채로 있게 되기도 합니다.
이 글은 가양동 아파트에서 현관문이 덜 닫힐 때 도어클로저와 경첩을 어떤 순서로 보면 좋은지 정리했습니다. / 문이 아예 잠겨 버렸다면 [강서구 출장열쇠](seoul-gangseo.html)로 연락 주세요.
@ 가양동 아파트 현관문 도어클로저 점검

# 증상을 세 가지로 나눠 보세요
같은 "덜 닫힘"이라도 모양이 다르면 원인이 다릅니다. / 문을 여러 번 열었다 놓으며 어디에 가까운지 지켜보세요.
- 끝에서 멈춤: 문이 문틀 직전까지 와서 더 이상 안 밀고 멈춘다
- 튕김: 문이 빠르게 와서 문틀에 부딪힌 뒤 살짝 되돌아 나온다
- 걸림: 문이 문틀 한쪽에 긁히며 마지막에 힘을 줘야 닫힌다
끝에서 멈춤과 튕김은 도어클로저 쪽, 걸림은 경첩이나 문틀 쪽을 먼저 의심합니다. / 둘이 섞여 있는 집도 있으니 하나씩 확인해 보는 게 좋습니다.

# 도어클로저는 문을 닫는 속도 조절기
현관문 위 안쪽에 붙은 상자 모양 장치가 도어클로저입니다. / 문을 열면 안의 스프링이 눌렸다가, 놓으면 기름이 천천히 빠지면서 문을 닫아 줍니다.
대부분 옆면이나 끝에 작은 조절 나사가 한두 개 있습니다. / 하나는 문이 크게 움직일 때의 속도, 다른 하나는 마지막 닫히기 직전의 속도를 맡는 경우가 많습니다.
마지막 구간이 너무 느리면 문이 끝에서 멈추고, 너무 빠르면 튕깁니다. / 그래서 이 나사를 아주 조금 돌리는 것만으로 나아지는 경우가 꽤 있습니다.

# 나사를 돌리기 전에 꼭 알아 둘 것
조절 나사는 한 번에 많이 돌리지 마세요. / 시계 방향과 반대 방향 중 어느 쪽이 빠르게 하는지는 제품마다 달라서, 조금 돌리고 문을 닫아 보고, 다시 조금 돌리는 식으로 해야 합니다.
나사를 너무 많이 풀면 안의 기름이 새어 나올 수 있습니다. / 기름이 새면 도어클로저는 다시 쓰기 어려워 교체해야 합니다.
조절 전에 나사 홈 방향을 사진으로 찍어 두면 원래 자리로 되돌리기 쉽습니다. / 자신이 없다면 손대지 않고 점검을 받는 편이 안전합니다.
@ 가양동 도어클로저 속도 조절 나사 위치

# 기름 자국은 교체 신호
도어클로저 몸통 아래나 문 위쪽에 끈적한 기름 자국이 있다면 안쪽 기름이 새고 있는 것입니다. / 이 상태에서는 속도 조절이 잘 안 되고 문이 쾅 닫히기 시작합니다.
기름이 바닥이나 신발장으로 떨어지기도 하니 신문지나 천을 받쳐 두세요. / 이런 경우는 조절보다 도어클로저를 바꾸는 쪽으로 생각하셔야 합니다.

# 팔 연결부 나사도 확인
도어클로저와 문틀을 잇는 쇠막대, 흔히 팔이라고 부르는 부분의 연결 나사가 풀리면 문이 덜컹거리며 닫힙니다. / 문을 반쯤 열고 팔을 손으로 살짝 흔들어 보세요.
흔들림이 크다면 연결부 나사만 조여도 증상이 줄어듭니다. / 다만 팔이 휘었거나 금이 갔다면 부품 교체가 필요합니다.

# 문을 고정해 두는 습관이 클로저를 망칩니다
환기나 짐 옮기기 때문에 현관문을 활짝 열어 말굽 스토퍼로 오래 고정해 두는 집이 있습니다. / 이렇게 하면 도어클로저 안 스프링과 기름에 계속 힘이 걸려 수명이 짧아집니다.
이삿날이나 택배 정리처럼 오래 열어 둘 일이 있다면 팔 연결부를 잠시 풀어 두는 방법도 있습니다. / 방법이 낯설다면 점검받을 때 같이 여쭤보세요.
복도식 구조에서 바람이 세게 부는 날 문이 갑자기 닫히며 충격을 받는 것도 도어클로저를 지치게 합니다.

# 경첩 처짐은 위쪽 틈으로 봅니다
문을 닫은 상태에서 문 위쪽과 문틀 사이 틈을 왼쪽부터 오른쪽까지 훑어보세요. / 손잡이 쪽 틈은 좁고 경첩 쪽은 넓다면 문이 아래로 처진 것입니다.
처진 문은 손잡이 쪽 아래 모서리가 문틀이나 바닥에 먼저 닿습니다. / 그래서 마지막에 힘을 줘야 닫히고, 걸쇠도 문틀 구멍보다 아래로 내려가 잘 안 잠깁니다.
경첩 나사가 헐거워진 정도라면 조이는 것만으로 좋아지기도 합니다. / 나사가 헛돌 만큼 구멍이 넓어졌다면 보강이 필요합니다.

# 바닥 끌림과 문틀 긁힘 자국
현관 바닥 타일이나 문턱에 반원 모양 긁힘이 있다면 문이 처져 끌리고 있다는 뜻입니다. / 문틀 걸쇠 쇠판 주변이 반짝이게 닳았다면 걸쇠가 매번 긁히며 들어가는 중입니다.
중문이 따로 있는 집은 중문 쪽 바닥도 함께 보세요. / 현관문과 중문이 동시에 처지는 경우는 드물어서 어느 문이 문제인지 가르기 쉬워집니다.
이런 자국은 증상을 설명할 때 좋은 단서가 됩니다. / 휴대폰으로 찍어 두셨다가 전화하실 때 보내 주세요.

# 덜 닫힌 문이 도어락에 주는 부담
문이 끝까지 안 닫힌 상태에서 자동 잠김이 시도되면 걸쇠가 문틀에 부딪히며 모터에 힘이 걸립니다. / 이런 일이 반복되면 도어락 모터가 먼저 지쳐 경고음이 나거나 걸쇠가 중간에 멈춥니다.
그래서 문 닫힘 문제는 도어락 고장을 막는 일이기도 합니다. / 문을 먼저 바로잡고 나서 도어락을 보면 [도어락 수리](doorlock-repair.html)로 끝나는 경우가 많습니다.

# 문이 잠긴 채 안 열릴 때는 다르게
문이 덜 닫힌 상태에서 억지로 잠갔다가 걸쇠가 문틀에 꽉 물려 안 열리는 경우가 있습니다. / 이럴 때는 손잡이를 세게 당기기보다 문을 문틀 쪽으로 살짝 밀며 다시 열어 보세요.
걸쇠에 걸린 힘이 풀리면 열리기도 합니다. / 그래도 안 되면 그대로 두고 연락 주세요. / 문을 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.
도어락이 오래돼 걸쇠가 자주 걸린다면 문을 바로잡은 뒤 [도어락 교체](doorlock-replace.html)까지 함께 생각해 볼 수 있습니다.

# 점검을 부르실 때와 진행 방식
도어클로저에서 기름이 새거나, 경첩 나사가 헛돌거나, 문이 잠긴 채 안 열린다면 연락 주세요. / 도어클로저 사진, 경첩 쪽 사진, 바닥 긁힘 사진이 있으면 준비가 빠릅니다.
문이 잠겨 들어가지 못한 상황이라면 신분증이나 우편물, 관리사무소 확인으로 사시는 분인지 먼저 확인합니다. / 작업 전에는 상태를 보고 비용을 먼저 말씀드리며, 끝내 열지 못하면 비용은 받지 않습니다. / 자세한 순서는 [이용안내](guide.html)에 있습니다.
@ 가양동 현관문 경첩 처짐 출장 점검

# 가양동 말고 강서구 다른 동네
가양동 옆 등촌동, 염창동, 마곡동부터 발산동, 화곡동, 공항동, 방화동까지 강서구 전 지역 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 문이 쾅 닫혀서 아이 손이 걱정돼요. | 마지막 구간 속도를 늦추면 나아지는 경우가 많습니다. 기름이 샌다면 교체가 필요합니다.
