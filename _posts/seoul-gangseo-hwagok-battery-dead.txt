# 화곡동 골목 끝 현관, 번호판이 캄캄할 때
화곡역에서 골목을 몇 번 꺾어 들어가야 나오는 빌라와 다세대 건물이 화곡동에는 유난히 많습니다. / 늦게 귀가해 계단을 올라왔는데 번호판을 만져도 불이 안 들어오면 순간 머릿속이 하얘집니다.
이럴 때 가장 먼저 의심할 것은 배터리입니다. / 도어락이 고장 난 것처럼 보여도 실제로는 건전지가 다 닳아 아무 반응을 못 하는 경우가 대부분입니다.
이 글은 화곡동에서 번호판이 꺼졌을 때 9V 건전지로 비상 전원을 넣는 순서와 들어간 뒤 건전지를 바꾸는 요령, 그래도 안 될 때 [강서구 출장열쇠](seoul-gangseo.html)를 부르는 방법을 적었습니다.
@ 화곡동 빌라 도어락 번호판 꺼짐 배터리 방전

# 꺼지기 전에 도어락이 보낸 신호들
배터리는 하루아침에 다 닳지 않습니다. / 대부분의 도어락은 꺼지기 며칠에서 몇 주 전부터 신호를 보냅니다.
- 문을 열 때 평소와 다른 멜로디나 짧은 경고음이 섞인다
- 번호를 누르고 문이 열리기까지 한 박자 늦다
- 모터 소리가 힘없이 늘어진다
- 번호판 불빛이 예전보다 흐리다
이 중 하나라도 있었다면 오늘 꺼진 건 배터리 때문일 가능성이 훨씬 높습니다. / 이 기억은 전화로 설명할 때도 그대로 도움이 됩니다. / 식구 중 누군가 며칠 전 경고음을 들었다고 한다면 그것도 같이 알려 주세요.

# 왜 9V 건전지가 먼저인지
많은 도어락은 바깥쪽 번호판 아래나 옆에 작은 금속 단자 두 개가 있습니다. / 여기에 9V 건전지를 대면 그 순간만큼 전원이 들어와 번호를 누를 수 있습니다.
배터리 칸은 집 안쪽에 있어서 밖에서는 바꿀 수 없습니다. / 그래서 바깥에서 할 수 있는 거의 유일한 방법이 비상 전원입니다.
이 방법으로 열리면 출장을 부를 필요 없이 바로 들어갈 수 있습니다. / 늦은 밤이라면 기다리는 시간도 아낄 수 있습니다.

# 9V 건전지는 어디서 구할까
9V 건전지는 편의점이나 동네 가게에서 파는 경우가 많아 집 근처에서 구할 수 있을 때가 많습니다. / 네모난 모양에 위쪽에 똑딱이 단자 두 개가 달린 건전지를 찾으면 됩니다.
휴대폰 배터리가 넉넉하다면 지도 앱으로 가장 가까운 편의점을 찾아보세요. / 밤늦은 시간에는 문을 연 곳이 한정되니 미리 위치를 알아 두면 좋습니다.
가방이나 차에 9V 건전지 하나를 넣어 다니는 분도 있습니다. / 다만 오래 묵으면 힘이 빠지니 해마다 한 번씩 새것으로 바꿔 두세요.

# 단자에 대는 요령
건전지 윗면의 두 단자를 도어락 비상 단자 두 개에 동시에 닿게 대고 꾹 누릅니다. / 방향이 맞지 않으면 반응이 없으니 뒤집어서 한 번 더 대 보세요.
번호판에 불이 들어오면 건전지를 계속 댄 채로 번호를 누릅니다. / 손을 떼면 다시 꺼지기 때문에 한 손으로 대고 다른 손으로 누르는 게 편합니다.
문이 열렸는데도 손잡이를 돌려야 하는 제품이라면 건전지를 떼지 말고 바로 손잡이를 돌리세요.
@ 화곡동 도어락 9V 비상 전원 단자 위치

# 단자가 안 보이거나 반응이 없다면
제품에 따라 비상 단자가 번호판 아래 덮개 안에 숨어 있거나 아예 없는 경우도 있습니다. / 덮개가 있다면 손톱으로 살짝 밀어 열어 보세요. / 비상 열쇠 구멍이 있는 제품도 있지만 열쇠를 집 안에 두었다면 쓸 수 없습니다.
건전지를 대도 불이 전혀 안 들어온다면 건전지가 오래됐거나 도어락 쪽 회로 문제일 수 있습니다. / 새 건전지로 한 번만 더 해 보고, 그래도 안 되면 무리하지 말고 연락 주세요.

# 이것만은 하지 마세요
번호판이 꺼졌다고 손잡이를 세게 당기거나 문을 발로 차는 건 피해 주세요. / 걸쇠가 더 꽉 물려 나중에 여는 시간이 길어집니다.
번호판 커버를 드라이버로 벗겨 직접 전원을 연결하려는 시도도 위험합니다. / 회로가 상하면 수리로 끝날 일이 교체로 커질 수 있습니다.
건전지 단자에 열쇠나 동전을 대서 전기를 이어 보려는 것도 효과가 없고 단자만 상하게 합니다.

# 들어가면 건전지는 전부 한꺼번에
문이 열렸다면 바로 안쪽 배터리 덮개를 열어 건전지를 모두 새것으로 바꿔 주세요. / 네 개 중 두 개만 바꾸면 남은 헌 건전지가 새것의 힘까지 끌어내려 금방 다시 꺼집니다.
같은 종류, 같은 크기의 알칼라인 건전지를 쓰는 게 기본입니다. / 충전식 건전지는 전압이 조금 낮아 경고음이 일찍 울리거나 모터 힘이 약해질 수 있어 설명서에서 권하지 않는 제품이 많습니다.
넣을 때는 플러스와 마이너스 방향을 덮개 안쪽 그림에 맞춰 하나씩 확인하세요. / 한 개만 거꾸로 들어가도 전원이 안 들어옵니다.

# 접점과 덮개도 한 번 살피기
건전지를 뺐을 때 접점에 하얀 가루나 초록빛 녹이 보이면 건전지가 샌 흔적입니다. / 마른 천이나 면봉으로 닦아 내고 새 건전지를 넣어 주세요.
접점 스프링이 눌려 납작해졌다면 건전지가 헐겁게 끼어 전원이 끊기기도 합니다. / 이럴 때는 점검을 받아 보시는 게 좋습니다.
덮개 안쪽에 교체한 날짜를 펜으로 적어 두면 다음 교체 시기를 잊지 않습니다. / 남은 헌 건전지는 일반 쓰레기와 섞지 말고 따로 모아 버려 주세요.

# 골목 안 빌라라 위치 설명이 중요합니다
화곡동은 비슷한 빌라가 이어져 있어 주소만으로는 건물을 찾기 어려울 때가 있습니다. / 아래를 같이 알려 주시면 도착이 빨라집니다.
- 지번 주소와 건물 이름이나 외벽 색
- 가까운 큰길이나 편의점 같은 기준점
- 몇 층인지, 공동현관 번호가 있는지
- 도어락 앞쪽 사진 한 장
반지하나 꼭대기 층처럼 계단을 따로 내려가거나 올라가야 하는 집이라면 그것도 말씀해 주세요.

# 문 앞에서 거주 확인과 비용 안내
도착하면 사시는 분인지 먼저 확인합니다. / 신분증, 주소가 나온 우편물이나 택배 송장, 집주인 확인 중 하나면 됩니다.
그다음 도어락 상태를 보고 비용을 먼저 말씀드리고 동의하실 때 시작합니다. / 끝내 열지 못하면 비용은 받지 않습니다. / 여는 과정은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.
@ 화곡동 출장열쇠 배터리 방전 도어락 개방

# 연 다음 같이 보는 것
문이 열리면 새 건전지를 넣고 잠금과 열림이 제대로 되는지 몇 번 확인합니다. / 건전지를 바꿨는데도 경고음이 계속되면 회로나 접점 문제일 수 있어 [도어락 수리](doorlock-repair.html)로 손볼지 말씀드립니다.
오래 써서 부품을 구하기 어려운 제품이라면 [도어락 교체](doorlock-replace.html)도 함께 안내드립니다. / 고쳐 쓸 수 있으면 교체는 권하지 않습니다.

# 화곡동 말고 강서구 전체
화곡동 옆 등촌동, 발산동, 염창동부터 가양동, 마곡동, 공항동, 방화동까지 강서구 어디든 24시간 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
