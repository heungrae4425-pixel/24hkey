# 마곡동에서 혼자 살거나 나눠 살 때
마곡동은 마곡역 주변으로 오피스텔과 업무 건물이 많이 들어선 동네라 혼자 사는 직장인과 학생이 적지 않습니다. / 방 하나를 쓰는 자취, 큰 집을 여럿이 나눠 쓰는 쉐어하우스까지 사는 방식도 다양합니다.
이런 집은 들어가기까지 문이 두세 개입니다. / 건물 공동현관, 세대 현관, 쉐어하우스라면 각자 방문까지 있어서 어느 문에서 막혔는지에 따라 해결 방법이 달라집니다.
이 글은 마곡동 자취방과 쉐어하우스에서 출입문이 막혔을 때 차례로 확인할 것을 정리했습니다. / 출동 안내는 [강서구 출장열쇠](seoul-gangseo.html)에 있습니다.
@ 마곡동 오피스텔 자취방 출입문 잠김

# 어느 문에서 막혔는지 먼저 나눠 보세요
같은 잠김이라도 막힌 문이 어디냐에 따라 연락할 곳이 다릅니다.
- 건물 공동현관에서 막혔다면 관리실이나 건물 관리 담당
- 세대 현관 도어락이 안 열리면 출장열쇠
- 쉐어하우스 개인 방문이 잠겼다면 운영자나 집주인에게 먼저 확인
- 방문 열쇠가 없고 운영자도 연락이 안 되면 출장열쇠
공동현관은 건물 설비라서 함부로 열 수 없습니다. / 관리실 연락처가 엘리베이터나 우편함 근처에 붙어 있는 경우가 많으니 먼저 찾아보세요.

# 오피스텔 세대 도어락이 꺼졌을 때
자취방 도어락은 혼자 쓰다 보니 배터리 경고음을 듣고도 미루기 쉽습니다. / 출근길에 한 번 울리고 퇴근길에 꺼져 있는 일이 생각보다 흔합니다.
번호판 아래쪽에 비상 전원 단자가 있다면 9V 건전지를 대고 번호를 눌러 보세요. / 건물 1층 편의점이나 가까운 가게에서 구할 수 있는 경우가 많습니다.
들어가시면 안쪽 배터리를 모두 새것으로 바꿔 두세요. / 남은 배터리를 섞어 쓰면 금방 다시 경고음이 납니다.

# 쉐어하우스 방문이 잠겼을 때
쉐어하우스 방문은 일반 방문 손잡이 자물쇠부터 작은 번호 도어락까지 집마다 다릅니다. / 방문은 운영자가 관리하는 경우가 많아서 여벌 열쇠를 운영자가 갖고 있기도 합니다.
그래서 방문이 잠겼다면 운영자나 집주인에게 먼저 연락해 보는 게 순서입니다. / 연락이 안 되거나 늦은 시간이라 기다리기 어려우면 그때 연락 주세요.
방문을 열 때도 그 방을 쓰는 분이 맞는지 확인합니다. / 계약서나 입주 안내 문자처럼 그 방에 사는 것을 보여 줄 수 있는 것을 준비해 주시면 됩니다.
@ 마곡동 쉐어하우스 개인 방문 잠금 확인

# 함께 사는 사람이 번호를 바꿨다면
쉐어하우스 공용 현관 번호를 누군가 바꿔 놓고 공유를 깜빡하는 일도 있습니다. / 이럴 땐 다른 입주자나 운영자에게 먼저 물어보는 것이 가장 빠릅니다.
번호 변경은 단체 대화방처럼 모두가 보는 곳에 남기는 규칙을 정해 두면 좋습니다. / 바꾼 사람과 날짜를 같이 적어 두면 헷갈릴 일이 줄어듭니다.
아무도 번호를 모르는 상황이라면 문을 연 뒤 새 번호를 등록해야 합니다. / 새 번호를 정할 때는 운영자와 입주자 모두 동의한 번호로 정하세요. / 누군가 이사를 나가면 그때도 번호를 한 번 바꾸는 것을 규칙으로 정해 두면 서로 마음이 편합니다.

# 고시원과 원룸 건물의 공동 출입문
고시원이나 원룸 건물은 층마다 출입문이 있고 번호나 카드로 여는 곳이 많습니다. / 이런 문은 건물 관리 쪽에서 번호를 정하고 바꾸기 때문에 관리자 확인이 먼저입니다.
관리자 연락처를 휴대폰에 저장해 두지 않으면 막혔을 때 찾기 어렵습니다. / 입주하는 날 관리자 번호, 공용문 번호, 쓰레기 버리는 곳 문 번호를 한꺼번에 메모해 두세요.

# 혼자 살수록 챙겨 둘 것
자취를 하면 문이 잠겼을 때 도와줄 사람이 가까이 없는 경우가 많습니다. / 아래 몇 가지를 미리 해 두면 막혔을 때 훨씬 수월합니다.
- 도어락 앞뒤 사진을 휴대폰에 저장해 두기
- 관리실과 집주인 연락처를 즐겨찾기에 넣기
- 여벌 카드나 열쇠를 회사 서랍이나 가족에게 맡기기
- 배터리 경고음이 나면 그날 바로 교체하기
- 신분증 사진이나 계약서 사진을 휴대폰에 보관하기
사진이 있으면 전화로 상황을 설명하기도, 현장에서 확인받기도 쉬워집니다.

# 마곡동 오피스텔 출입은 미리 알려 주세요
마곡동 오피스텔은 공동현관에 출입 카드나 번호가 필요한 곳이 많습니다. / 출동하는 쪽이 건물 안으로 들어갈 수 있는지 미리 알려 주시면 문 앞에서 기다리는 시간이 줄어듭니다.
공동현관 밖에서 만나 함께 들어가도 됩니다. / 몇 동 몇 층인지와 엘리베이터 위치까지 알려 주시면 더 빨리 찾아갑니다.

# 열기 전 거주 확인과 비용 안내
자취방이든 쉐어하우스 방이든 그곳에 사는 분인지 먼저 확인합니다. / 신분증 주소가 다른 경우가 많아서 임대차 계약서, 입주 확인 문자, 관리실 확인 같은 방법을 함께 씁니다.
확인이 되면 문과 도어락을 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 끝내 못 열면 비용을 받지 않습니다.
진행 방식은 [이용안내](guide.html)에, 개방 과정은 [현관문 개문](door-open.html)에 정리했습니다.
@ 마곡동 자취방 도어락 개방 전 거주 확인

# 연 뒤에는 번호와 배터리를 정리합니다
문이 열리면 도어락이 제대로 잠기고 풀리는지 확인하고 배터리 상태를 같이 봅니다. / 번호를 잊었던 경우라면 새 번호를 등록하는 순서를 옆에서 알려드립니다.
쉐어하우스 공용 현관이라면 새 번호를 정할 때 운영자에게도 꼭 알려 주세요. / 도어락 고장이 반복된다면 [도어락 수리](doorlock-repair.html) 쪽으로 손을 볼지 말씀드립니다.

# 입주와 퇴실 때 한 번씩
새 자취방에 들어가는 날에는 이전 입주자가 쓰던 번호가 남아 있지 않은지 확인하세요. / 쉐어하우스라면 방문 열쇠가 몇 개인지 운영자에게 물어보는 것도 좋습니다.
퇴실할 때는 등록한 카드와 번호를 지우고 열쇠를 반납하면 깔끔합니다. / 열쇠를 새로 맞추거나 여벌을 만드는 일은 [출장 열쇠](key-call.html) 안내를 참고해 보세요.

# 늦은 밤 문 앞에서 기다리는 동안
퇴근이 늦어 밤에 문 앞에서 막히면 복도에서 오래 서 있기 부담스럽습니다. / 오피스텔 1층 로비나 건물 앞 밝은 곳에서 기다리셔도 되니 만날 장소를 알려 주세요.
휴대폰 배터리가 얼마 남지 않았다면 위치와 호수를 먼저 문자로 보내 두세요. / 통화가 끊기더라도 찾아갈 수 있습니다.
기다리는 동안 문틈에 카드를 넣어 보거나 손잡이를 세게 흔드는 일은 피해 주세요. / 도어락 외관이 상하면 퇴실할 때 원상 복구 이야기가 나올 수 있습니다.

# 마곡동 말고 강서구 전체
마곡동 옆 발산동, 가양동, 공항동, 방화동은 물론 염창동, 등촌동, 화곡동까지 강서구 어디든 갑니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
