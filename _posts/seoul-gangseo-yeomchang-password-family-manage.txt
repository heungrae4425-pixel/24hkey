# 염창동 우리 집 번호, 마지막으로 바꾼 게 언제인가요
염창동은 강서구 동쪽에 아파트 단지와 빌라가 함께 있어 가족 단위로 사는 집이 많은 동네입니다. / 식구가 많을수록 현관 번호는 한 번 정하면 몇 년이고 그대로 쓰는 경우가 흔합니다.
번호를 바꾸지 않는 가장 큰 이유는 귀찮아서라기보다 가족 중 누군가 헷갈릴까 봐서입니다. / 실제로 번호를 바꾼 날 학원에서 돌아온 아이가 문 앞에서 기다리거나, 부모님이 들르셨다가 못 들어가시는 일이 생깁니다.
이 글은 염창동 가정에서 도어락 비밀번호를 언제 바꾸면 좋은지, 바꾼 뒤 가족과 어떻게 나누면 덜 헷갈리는지를 정리했습니다. / 막혔을 때 출동 안내는 [강서구 출장열쇠](seoul-gangseo.html)에 있습니다.
@ 염창동 가족 현관 도어락 비밀번호 변경

# 번호를 바꿀 만한 때
정해진 주기를 지키는 것도 좋지만, 아래 같은 일이 있을 때 바꾸는 것이 더 실용적입니다.
- 인테리어나 수리 기사가 며칠 드나든 뒤
- 가사도우미나 돌봄 선생님이 그만두신 뒤
- 친척이나 지인에게 번호를 알려 준 적이 있을 때
- 번호판 특정 숫자가 눈에 띄게 닳았을 때
- 가족 중 누가 번호를 메모해 둔 지갑을 잃어버렸을 때
이런 일이 없더라도 계절이 바뀔 때쯤 한 번씩 바꾸는 집도 있습니다. / 배터리 교체와 같은 날로 정해 두면 잊지 않고 챙기기 좋습니다.

# 바꾸기 전에 가족 일정부터 보기
번호를 바꾸는 날은 가족이 모두 집에 있는 저녁이 가장 좋습니다. / 누군가 밖에 있는 동안 바꾸면 그 사람은 새 번호를 모른 채 돌아오게 됩니다.
아이 하원이나 학원 귀가 시간이 있다면 그 전에 바꾸지 않도록 하세요. / 부모님이 자주 들르시는 집이라면 다음 방문 전에 미리 알려 드려야 합니다.
급하게 바꿔야 하는 상황이라면 바꾼 즉시 가족 모두에게 알리고, 받았다는 답을 꼭 확인하세요. / 메시지를 못 본 채 귀가하는 일을 막을 수 있습니다.

# 문을 열어 둔 채로 바꾸세요
번호를 바꿀 때는 반드시 문을 열어 둔 상태에서 안쪽 설정 버튼으로 진행하세요. / 순서를 틀려 새 번호가 저장되지 않아도 문이 열려 있으면 다시 하면 됩니다.
새 번호를 저장한 뒤에는 문을 연 채로 바깥 번호판에 새 번호를 눌러 걸쇠가 움직이는지 확인합니다. / 이 확인을 두세 번 해 본 뒤에 문을 닫는 것이 안전합니다.
설정 방법을 모르겠다면 도어락 안쪽 몸체 사진을 보내 주세요. / 제품에 맞는 순서를 알려드립니다.
@ 염창동 도어락 안쪽 설정 버튼으로 번호 저장

# 가족이 기억하기 쉬운 번호 정하기
너무 어려운 번호는 가족 중 누군가 꼭 잊어버립니다. / 그렇다고 생일, 결혼기념일, 전화번호 뒷자리처럼 남이 짐작할 수 있는 숫자는 피하는 게 좋습니다.
가족만 아는 이야기에서 숫자를 뽑는 방법이 있습니다. / 예를 들어 처음 키운 반려동물이 온 해, 가족 여행을 간 곳의 버스 번호처럼 밖에서는 알기 어려운 숫자입니다.
번호 앞뒤에 아무 숫자나 더 누를 수 있는 기능이 있다면 아이에게도 알려 주세요. / 누가 옆에서 보더라도 진짜 번호를 알아보기 어렵게 됩니다.

# 새 번호를 가족에게 나누는 방법
가족 단체 대화방에 번호를 그대로 올리는 집이 많습니다. / 편하긴 하지만 대화방이 다른 사람에게 보일 수 있으니 동 호수와 번호를 한 메시지에 같이 쓰지 않는 편이 낫습니다.
아이에게는 휴대폰보다 직접 몇 번 같이 눌러 보며 외우게 하는 것이 좋습니다. / 문 앞에서 함께 연습하면 다음 날 혼자 들어올 때 덜 긴장합니다.
부모님께는 큰 글씨로 적은 메모를 지갑 안쪽에 넣어 드리되, 주소는 적지 않도록 하세요. / 메모를 잃어버려도 어느 집 번호인지 알 수 없게 하는 것입니다.

# 사용자 번호를 나눠 쓰는 집이라면
도어락에 따라 여러 개의 사용자 번호를 등록할 수 있습니다. / 부모와 아이, 자주 오시는 조부모님 번호를 각각 두면 한 사람 번호만 바꾸기 쉬워집니다.
다만 번호가 여러 개면 누가 어떤 번호인지 기록이 필요합니다. / 등록한 날짜와 대상자를 휴대폰 메모에 정리해 두세요.
카드나 지문을 함께 쓰는 집은 번호를 잊었을 때 다른 방법으로 들어갈 수 있어 마음이 편합니다. / 지문은 아이가 자라면서 인식이 떨어질 수 있으니 가끔 다시 등록해 주세요.

# 바꾼 뒤 며칠은 이렇게
새 번호로 바꾼 뒤 며칠은 가족 중 누군가 옛 번호를 누르는 일이 생깁니다. / 몇 번 틀리면 도어락이 잠시 입력을 막기 때문에 당황하지 말고 기다렸다가 다시 누르라고 알려 주세요.
처음 일주일은 가족 대화방에 새 번호로 바꿨다는 사실만 한 번 더 상기시켜 주는 것도 방법입니다. / 번호 자체를 다시 보내지 않고 바꿨다는 말만 남기면 됩니다.
@ 염창동 현관 번호판 새 비밀번호 입력 연습

# 가족 구성이 바뀔 때도 번호를 돌아보세요
자녀가 독립해 따로 살게 되거나, 반대로 부모님이 들어와 함께 사시게 되면 번호를 아는 사람이 달라집니다. / 이럴 때가 번호 관리 방식을 다시 정하기 좋은 시점입니다.
따로 사는 자녀가 가끔 들르는 정도라면 그 자녀만 쓰는 사용자 번호를 두는 방법이 있습니다. / 함께 사시게 된 부모님께는 번호보다 카드가 편할 수 있으니 어떤 방식이 좋을지 여쭤보세요.
결혼이나 이사로 식구가 늘었다면 등록된 카드와 지문을 한 번 정리하고 새로 시작하는 것도 깔끔합니다. / 누가 어떤 방법으로 드나드는지 가족 모두 알고 있으면 막힐 일이 줄어듭니다.

# 그래도 문 앞에서 막혔다면
번호를 바꾸다 저장이 꼬였거나 가족이 새 번호를 몰라 문 앞에서 기다리는 경우가 있습니다. / 집 안에 가족이 있다면 안에서 열어 주는 것이 가장 빠릅니다.
아무도 없고 번호도 확실하지 않다면 여러 번 누르지 말고 연락 주세요. / 도착하면 사시는 분인지 신분증이나 우편물, 아파트라면 관리사무소 세대 확인으로 먼저 확인합니다.
문을 보고 비용을 먼저 말씀드린 뒤 동의하시면 엽니다. / 열지 못하면 비용은 받지 않으며, 개방 과정은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 연 다음 번호 정리까지
문을 연 뒤에는 기존 번호를 지우고 새 번호를 다시 등록하는 것까지 함께 해 드립니다. / 가족 모두가 쓸 번호로 정하시도록 옆에서 순서를 안내합니다.
도어락이 오래돼 설정이 자꾸 꼬인다면 [도어락 수리](doorlock-repair.html)로 상태를 보거나 사용자 번호 관리가 쉬운 제품으로 바꾸는 것도 생각해 볼 수 있습니다. / 교체 기준은 [도어락 교체](doorlock-replace.html)에 있습니다.

# 염창동 말고 강서구 전체
염창동 옆 등촌동, 가양동부터 화곡동, 마곡동, 발산동, 공항동, 방화동까지 강서구 어디든 다닙니다. / 이용 방법은 [이용안내](guide.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
