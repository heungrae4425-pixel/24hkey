# 염창동 도어락, 바꿀 때가 됐는지부터
염창동은 강서구 동쪽에서 가양동, 등촌동과 맞닿아 있고 아파트와 빌라가 한 동네 안에 섞여 있는 곳입니다. / 같은 동네라도 집마다 문 재질과 도어락 연식이 제각각이라 교체 이야기가 나오는 이유도 다 다릅니다.
번호판이 가끔 먹통이 되거나 잠길 때 모터가 힘겹게 도는 소리가 나면 슬슬 바꿔야 하나 싶어집니다. / 그런데 막상 알아보려 하면 무엇을 기준으로 골라야 하는지, 비용은 어떻게 정해지는지가 막막합니다.
이 글은 염창동에서 도어락을 바꾸기 전에 집에서 먼저 살펴볼 부분과, [강서구 출장열쇠](seoul-gangseo.html)를 불렀을 때 비용 이야기가 어떤 순서로 오가는지를 적었습니다.
@ 염창동 현관 도어락 교체 상담 전 점검

# 교체보다 수리가 맞는 경우가 꽤 있습니다
도어락이 이상하다고 해서 모두 통째로 바꿔야 하는 것은 아닙니다. / 원인이 배터리 접점, 헐거운 나사, 문틀과의 어긋남 같은 작은 부분이라면 손보는 것으로 끝나기도 합니다.
반대로 회로판이 물을 먹었거나 모터가 닳아 힘을 못 쓰는 상태라면 부품만 갈아도 오래 못 갑니다. / 부품을 구하기 어려운 오래된 모델도 교체 쪽이 현실적입니다.
그래서 현장에서는 먼저 고장 원인을 짚고 수리로 될지 말씀드립니다. / 고쳐서 쓸 수 있는 상태라면 교체를 권하지 않는 것이 원칙이고, 수리 내용은 [도어락 수리](doorlock-repair.html)에 따로 정리해 두었습니다.

# 이런 신호가 겹치면 교체를 생각해 볼 만합니다
한 가지 증상만으로 판단하기보다 여러 신호가 같이 나타나는지 보시는 게 좋습니다.
- 새 건전지를 넣어도 몇 주 만에 경고음이 다시 울린다
- 번호를 정확히 눌러도 두세 번에 한 번꼴로 반응이 없다
- 잠금 버튼을 눌렀을 때 걸쇠가 끝까지 나오지 않는다
- 번호판 숫자가 닳아 자주 누르는 자리가 눈에 보인다
- 비 오는 날이나 추운 아침마다 증상이 심해진다
두세 개 이상 해당된다면 점검을 받아 보시고 교체 여부를 함께 결정하시면 됩니다. / 아직 한 가지뿐이라면 배터리와 접점부터 확인해도 늦지 않습니다.

# 문 두께와 기존 구멍을 먼저 봅니다
새 도어락이 우리 집 문에 맞는지는 문 두께와 이미 뚫려 있는 구멍 위치에 달려 있습니다. / 기존 타공 자리에 그대로 맞는 제품을 고르면 문에 새 구멍을 낼 일이 줄어듭니다.
염창동 빌라처럼 예전에 열쇠 손잡이를 쓰다가 도어락을 단 집은 아래쪽에 옛 구멍이 남아 있기도 합니다. / 이런 자리는 커버로 가릴 수 있는지까지 같이 봐야 깔끔하게 마무리됩니다.
보조키를 따로 쓰고 있다면 위치가 새 도어락 몸체와 겹치지 않는지도 확인합니다. / 설치 전 확인 순서는 [도어락 설치](doorlock-install.html)에 자세히 적어 두었습니다.
@ 염창동 현관문 두께 타공 위치 측정

# 어떤 방식으로 바꿀지 정해 두면 상담이 짧아집니다
번호만 쓸지, 카드나 지문도 쓸지에 따라 제품 범위가 크게 달라집니다. / 가족 중 번호를 자주 잊는 분이 있는지, 아이가 혼자 드나드는지 생각해 두시면 고르기 쉽습니다.
손잡이를 돌리는 형과 밀고 당기는 형 중 무엇이 편한지도 미리 떠올려 보세요. / 양손에 짐을 들고 들어오는 일이 많은 집은 밀고 당기는 형을 선호하기도 합니다.
꼭 비싼 기능이 필요한 것은 아닙니다. / 쓰지 않을 기능은 빼고 필요한 것만 남기면 선택이 단순해집니다.

# 전화로 물어보실 때 알려 주시면 좋은 것
처음 연락하실 때 아래 내용을 함께 주시면 대략적인 방향을 먼저 잡을 수 있습니다.
- 지금 쓰는 도어락 앞면과 안쪽 몸체 사진
- 문이 철문인지, 방화문인지, 나무문인지
- 보조키나 걸쇠를 함께 쓰는지 여부
- 원하는 방식(번호, 카드, 지문)과 손잡이 형태
- 지금 문이 열리는 상태인지, 잠겨서 못 들어가는 상태인지
사진만 봐도 기존 구멍에 맞는 제품군이 좁혀지는 경우가 많습니다. / 문이 잠겨 있는 상태라면 개방이 먼저라서 진행 순서가 달라집니다.

# 비용은 이렇게 정해지고, 이렇게 안내드립니다
교체 비용은 고르시는 제품, 문 상태, 추가 작업이 필요한지에 따라 달라집니다. / 그래서 전화로 정확한 금액을 단정하기보다 현장에서 문을 보고 항목별로 말씀드립니다.
제품값과 설치 작업, 기존 구멍을 메우거나 보강하는 작업이 있으면 무엇이 포함되는지 하나씩 설명드립니다. / 들으시고 괜찮다고 하실 때만 작업을 시작합니다.
설명을 듣고 생각해 보시겠다고 하셔도 괜찮습니다. / 그 자리에서 결정을 재촉하지 않고, 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 작업 도중 추가 비용이 생길 때
문을 열어 보니 안쪽 보강판이 상해 있거나 문틀 받침이 어긋난 경우가 가끔 있습니다. / 이럴 때는 손대기 전에 멈추고 무엇이 왜 필요한지 먼저 여쭤봅니다.
말씀 없이 항목이 늘어나는 일은 없습니다. / 추가 작업을 원하지 않으시면 지금 상태에서 할 수 있는 범위만 마무리합니다.

# 잠긴 상태에서 교체를 원하실 때
도어락이 고장 나 문이 안 열리는 상태에서 교체를 원하시는 경우도 있습니다. / 이때는 먼저 문을 덜 상하게 여는 일부터 하고, 그다음 교체로 넘어갑니다.
문을 열 때는 사시는 분인지 신분증이나 주소가 적힌 우편물로 먼저 확인합니다. / 아파트라면 관리사무소 세대 확인으로도 진행할 수 있고, 개방 과정은 [현관문 개문](door-open.html)에 설명해 두었습니다.
끝내 문을 열지 못하면 비용은 청구하지 않습니다. / 이 원칙은 교체를 함께 맡기시는 경우에도 같습니다.
@ 염창동 고장 도어락 개방 후 교체 진행

# 교체 후 꼭 같이 확인하는 것
새 도어락을 달고 나면 문을 여러 번 열고 닫으며 걸쇠가 문틀에 정확히 들어가는지 봅니다. / 안쪽 버튼, 바깥 번호판, 수동 잠금이 모두 제대로 되는지도 함께 확인합니다.
비밀번호와 카드 등록은 사시는 분이 직접 하시도록 옆에서 순서를 알려드립니다. / 등록이 끝나면 기존에 쓰던 번호가 남아 있지 않은지도 확인합니다.
설명서와 비상 전원 단자 위치도 알려드리니 가족 모두 한 번씩 보아 두시면 좋습니다. / 교체 관련 내용은 [도어락 교체](doorlock-replace.html)에서도 보실 수 있습니다.

# 염창동에서 교체를 미루면 생기는 일
불안한 도어락을 계속 쓰다 보면 하필 늦은 밤이나 비 오는 날 완전히 멈추는 일이 생깁니다. / 그때는 개방과 교체를 한꺼번에 해야 해서 시간도 더 걸리고 마음도 급해집니다.
증상이 가벼울 때 점검을 받아 두면 수리로 끝날 가능성도 높아집니다. / 미리 알아본 상태라면 갑자기 바꿔야 할 때도 제품 선택에서 헤매지 않습니다.

# 강서구 다른 동네도 똑같이 갑니다
염창동과 붙어 있는 등촌동, 가양동은 물론 화곡동, 마곡동, 발산동, 공항동, 방화동까지 강서구 어디든 출동합니다. / 동네가 동서로 넓어서 위치를 먼저 듣고 도착 시간을 말씀드립니다.
강서구 안내는 [강서구 출장열쇠](seoul-gangseo.html) 페이지에 있고, 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
