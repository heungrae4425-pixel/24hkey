# 염창동에서 도어락을 새로 들일 때 먼저 할 질문
염창역 주변은 출퇴근하는 직장인 가구와 아이 키우는 집이 함께 사는 동네입니다. / 같은 동네라도 집마다 현관을 드나드는 사람과 시간이 다릅니다.
스마트 도어락을 고를 때 기능 목록부터 보면 끝이 없습니다. / 그보다 "우리 집은 누가, 언제, 무엇을 들고 문을 여는가"를 먼저 떠올리면 고를 범위가 확 줄어듭니다.
이 글은 염창동 가정에서 지문, 카드, 번호, 앱 연동 방식 가운데 무엇이 맞는지 생활 패턴별로 나눠 적었습니다. / 설치나 교체 상담은 [도어락 설치](doorlock-install.html) 페이지에서 보실 수 있습니다.
@ 염창동 스마트 도어락 지문 카드 고르기

# 문 여는 방식 네 가지를 짧게 정리하면
- 번호: 가장 기본이고 모든 제품에 있지만, 잊거나 엿보일 걱정이 있습니다
- 카드·태그: 대기만 하면 열려 편하지만, 두고 나오거나 잃어버릴 수 있습니다
- 지문: 몸만 있으면 되지만, 손 상태에 따라 인식이 흔들립니다
- 앱·원격: 밖에서 열어 줄 수 있지만, 연결과 설정을 관리해야 합니다
대부분의 스마트 도어락은 이 중 두세 가지를 같이 씁니다. / 어떤 것을 주로 쓰고 어떤 것을 예비로 둘지 정하는 것이 고르는 일의 핵심입니다.

# 맞벌이로 아침이 바쁜 집
출근 시간이 겹치는 집은 문 앞에서 머무는 시간을 줄이는 게 중요합니다. / 가방과 커피를 든 채로 번호를 누르기보다 지문이나 카드가 손이 덜 갑니다.
다만 둘 다 같은 방식만 쓰면 그 방식이 안 될 때 함께 막힙니다. / 한 사람은 지문, 한 사람은 카드처럼 나눠 두거나, 번호는 꼭 함께 기억해 두세요.
퇴근 시간이 늦는 날이 많다면 밤에 번호판 불빛이 잘 보이는 제품인지도 확인해 볼 만합니다.

# 초등학생 아이가 혼자 드나드는 집
아이가 학교나 학원을 혼자 오가면 카드나 태그를 목걸이처럼 걸고 다니게 하는 집이 많습니다. / 번호를 외우게 하는 것보다 실수가 적기 때문입니다.
그래도 카드를 잃어버리는 날을 대비해 번호 하나는 꼭 알려 두세요. / 아이 전용 사용자 번호를 따로 만들 수 있는 제품이면 나중에 그 번호만 바꾸기 편합니다.
카드를 가방 안쪽 주머니에 넣어 두면 꺼내다가 흘리는 일이 줄어듭니다. / 지문은 아이 손가락이 자라면서 인식이 달라질 수 있습니다. / 아이에게 지문을 쓰게 한다면 몇 달에 한 번 다시 등록해 주는 게 좋습니다.
@ 염창동 아이 카드키 도어락 사용자 번호

# 부모님이 자주 오시거나 함께 사는 집
어르신은 작은 숫자 버튼이나 복잡한 순서를 어려워하십니다. / 버튼이 크고 눌렀을 때 소리와 불빛이 분명한 제품이 편합니다.
나이가 들면 지문이 옅어져 인식이 잘 안 되는 경우가 있습니다. / 부모님께는 지문보다 카드나 번호를 주 방식으로 해 드리는 편이 덜 답답하실 수 있습니다.
음성 안내가 있는 제품이라면 소리 크기를 조절할 수 있는지도 확인해 보세요. / 귀가 어두우신 분께는 크게, 밤늦게 드나드는 집이라면 작게 맞출 수 있어야 편합니다.

# 겨울 장갑과 젖은 손을 생각하면
겨울에 장갑을 낀 채로는 지문과 번호 모두 불편합니다. / 장갑을 벗기 싫은 분이라면 카드나 태그를 주 방식으로 두는 편이 낫습니다.
비 오는 날이나 손을 씻고 바로 나왔을 때도 지문이 잘 안 읽힙니다. / 지문만 믿기보다 다른 방식 하나를 꼭 같이 쓰세요.

# 반려견 산책과 택배가 잦은 집
강아지 산책을 자주 나가는 집은 휴대폰 하나만 들고 나가는 경우가 많습니다. / 이럴 때는 지문이 가장 손이 덜 가는 방식입니다.
택배나 배달을 받으며 문을 자주 여닫는다면 자동 잠김이 확실하게 되는지가 중요합니다. / 문을 닫자마자 잠기는지, 잠긴 걸 소리로 알려 주는지 살펴보세요.

# 앱 연동은 꼭 필요한 집에만
밖에서 문을 열어 줘야 할 일이 잦은 집, 예를 들어 돌봄 선생님이 오가거나 아이가 혼자 귀가하는 집이라면 앱 연동이 쓸모 있습니다. / 열림 알림을 받아 볼 수 있는 것도 장점입니다.
대신 와이파이나 중계 장치, 앱 업데이트를 관리해야 합니다. / 이런 관리가 번거로운 집이라면 앱 없는 제품이 오히려 오래 편합니다.

# 보안 기능은 어디까지 따질까
스마트 도어락 설명서에는 허수 입력, 이중 잠금, 침입 경보 같은 기능이 길게 적혀 있습니다. / 다 있으면 좋지만, 실제로 매일 쓰게 되는 건 그중 한두 가지입니다.
번호를 쓰는 집이라면 앞뒤로 아무 숫자를 섞어 누를 수 있는 허수 입력 기능은 챙겨 볼 만합니다. / 번호판에 손자국이 남아도 진짜 번호를 짐작하기 어려워집니다.
안에서 잠금 버튼을 누르면 밖에서 번호로도 안 열리는 이중 잠금은 밤에 쓰기 좋습니다. / 다만 식구가 늦게 들어오는 날에는 이 기능을 켜 두면 안 되니 쓰는 법을 같이 익혀 두세요.

# 우리 집 문에 맞는지가 먼저입니다
마음에 드는 제품을 골라도 문에 맞지 않으면 달 수 없습니다. / 특히 아래 세 가지는 미리 확인해야 합니다.
- 문 두께와 재질, 기존 구멍 위치
- 보조키 자리를 그대로 쓸지 막을지
- 손잡이형인지 밀고 당기는 푸시풀형으로 바꿀지
기존 구멍과 맞지 않으면 새로 뚫거나 덮개를 덧대야 합니다. / 사진 몇 장이면 맞는 제품군을 미리 말씀드릴 수 있습니다.

# 전원이 꺼져도 들어갈 수 있게
스마트 도어락은 결국 건전지로 움직입니다. / 기능이 많을수록 전기를 더 쓰기 때문에 배터리 교체 주기도 조금 짧아질 수 있습니다.
바깥에서 9V 건전지로 비상 전원을 넣을 수 있는지, 비상 열쇠가 있는지 확인하세요. / 이 두 가지가 있으면 배터리가 다 돼도 문 앞에서 오래 서 있을 일이 줄어듭니다.

# 상담과 설치는 이렇게 진행합니다
문 사진과 원하시는 방식을 알려 주시면 맞는 제품을 먼저 추려 드립니다. / 식구 수와 주로 쓰실 방식, 앱 연동이 필요한지만 말씀해 주셔도 충분합니다. / 현장에서 문 상태를 보고 비용을 먼저 말씀드린 뒤, 결정하실 때 작업합니다.
기존 도어락을 떼어 낼지 고쳐 쓸지는 상태를 보고 정합니다. / 고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html), 바꾸는 게 낫다면 [도어락 교체](doorlock-replace.html)로 안내드립니다.
설치를 마치면 식구 수대로 번호, 카드, 지문 등록까지 그 자리에서 함께 해 드립니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.
@ 염창동 스마트 도어락 설치 등록 안내

# 염창동 말고 강서구 어디든
염창동 옆 등촌동, 가양동부터 화곡동, 발산동, 마곡동, 공항동, 방화동까지 강서구 전 지역으로 갑니다. / 강서구 안내는 [강서구 출장열쇠](seoul-gangseo.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 얼굴 인식 제품도 있나요? | 있습니다. 다만 가격과 전력 소모, 문 앞 조명 조건을 같이 따져 보셔야 합니다.
? 기존 구멍에 그대로 달 수 있나요? | 문 사진과 두께를 보면 맞는 제품을 먼저 추려 드릴 수 있습니다.
