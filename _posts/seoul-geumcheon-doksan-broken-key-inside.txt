# 독산동 현관 앞, 열쇠 반쪽만 손에 남았다면
독산동은 독산역에서 언덕을 따라 오르면 다세대 건물이 빼곡한 동네입니다. / 도어락을 달았어도 보조키나 건물 출입문은 여전히 열쇠로 여는 집이 많습니다.
오래 쓴 열쇠는 어느 날 돌리다가 뚝 하고 부러집니다. / 손에는 손잡이 쪽 반쪽만 남고, 나머지는 구멍 안에 박혀 버립니다.
이 글은 열쇠가 부러졌을 때 처음 몇 분 동안 해도 되는 일과 하면 안 되는 일을 나눠 적었습니다. / 그다음 [금천구 출장열쇠](seoul-geumcheon.html)가 어떻게 빼내고 마무리하는지도 정리했습니다.
@ 독산동 보조키 열쇠 부러짐 구멍 박힘

# 왜 하필 지금 부러졌을까
열쇠가 부러지는 데는 대개 이유가 쌓여 있습니다. / 갑자기 생긴 일처럼 보여도 그전부터 신호가 있었던 경우가 많습니다.
- 열쇠를 복사해서 만든 복사 열쇠를 오래 쓴 경우
- 구멍 안이 녹슬거나 먼지가 차서 돌릴 때 뻑뻑했던 경우
- 문이 처져 보조키 걸쇠가 문틀에 눌린 채로 돌린 경우
- 겨울에 언 상태로 힘주어 돌린 경우
특히 문이 처진 상태라면 열쇠만 새로 만들어도 또 부러질 수 있습니다. / 그래서 빼낸 뒤에 원인까지 같이 보는 것이 중요합니다.

# 처음 1분, 이것만은 하지 마세요
부러진 열쇠를 보면 본능적으로 남은 반쪽을 다시 구멍에 넣어 보게 됩니다. / 그러면 안에 박힌 조각이 더 깊이 밀려 들어가 빼기 훨씬 어려워집니다.
- 남은 열쇠 반쪽을 다시 꽂아 밀어 넣기
- 이쑤시개나 핀을 넣어 쑤시기
- 순간접착제로 반쪽을 붙여 빼내려 하기
- 기름이나 윤활제를 구멍에 잔뜩 뿌리기
접착제는 조각과 실린더 안쪽까지 붙여 버려 실린더를 통째로 바꿔야 하는 일이 생깁니다. / 기름은 먼지와 엉겨 조각을 더 꽉 물게 할 수 있습니다.

# 조각이 얼마나 나와 있는지 보기
구멍을 정면에서 비춰 보면 조각 끝이 보이는지 알 수 있습니다. / 휴대폰 손전등을 켜고 비스듬히 보면 잘 보입니다.
조각 끝이 구멍 밖으로 살짝 나와 있다면 비교적 쉽게 빠지는 편입니다. / 구멍 안쪽 깊이 들어가 있다면 전용 공구가 필요합니다.
이 모습을 사진으로 찍어 보내주시면 챙겨 갈 공구가 정해집니다. / 남은 반쪽 열쇠도 버리지 말고 같이 보여 주세요.
@ 독산동 실린더 안 부러진 열쇠 조각 확인

# 열쇠 방향이 어느 쪽에서 멈췄는지
부러질 때 열쇠가 잠그는 쪽으로 돌아간 상태였는지, 원래 자리였는지가 중요합니다. / 원래 꽂았던 자리에서 부러졌다면 조각이 일직선이라 빼기가 수월합니다.
반쯤 돌아간 상태에서 부러졌다면 실린더 안쪽도 같이 돌아가 있습니다. / 이때는 조각을 빼기 전에 실린더를 원래 자리로 돌려놓는 작업이 먼저 필요합니다.
기억나는 대로 말씀해 주시면 됩니다. / 잘 모르겠다면 그것도 그대로 알려주세요.

# 문이 잠긴 상태인지 열린 상태인지
문을 잠그다가 부러졌다면 문은 잠겨 있고, 집 안에 못 들어가는 상황입니다. / 이때는 다른 문이 없다면 조각을 빼거나 실린더를 열어야 들어갈 수 있습니다.
열다가 부러졌는데 문은 이미 열린 상태라면 급하지 않습니다. / 집 안에 들어가 계시면서 편한 시간에 불러 주셔도 됩니다.
도어락은 잘 되는데 보조키만 문제라면 당분간 보조키를 쓰지 않고 지내셔도 됩니다. / 다만 조각이 박힌 채 오래 두면 녹이 슬어 빼기 더 어려워집니다.

# 대문이나 건물 출입문 열쇠라면
독산동 다세대 중에는 건물 출입문이나 옥상 문, 창고 문을 열쇠로 쓰는 곳도 있습니다. / 여러 집이 함께 쓰는 문이라면 집주인이나 관리인에게 먼저 알려주세요.
공용 문 열쇠는 여러 사람이 복사해 쓰다 보니 열쇠가 닳아 있는 경우가 많습니다. / 이번에 실린더를 바꾸면서 열쇠를 새로 나눠 갖는 것도 방법입니다.
이 경우에는 비용을 누가 부담하는지 미리 이야기가 되어 있어야 합니다. / 현장에서 상태를 보고 집주인과 통화로 상의하기도 합니다.

# 도착하면 이렇게 진행합니다
먼저 사시는 분인지 신분증이나 주소가 적힌 우편물로 확인합니다. / 집 안에 서류가 있다면 문을 연 직후 보여 주시면 됩니다.
다음으로 조각 위치를 보고 전용 공구로 빼내는 방법을 정합니다. / 실린더를 다치지 않게 빼는 것이 먼저이고, 안 되면 실린더를 열어 꺼냅니다.
조각을 빼면 실린더가 잘 돌아가는지, 핀이 상하지 않았는지 확인합니다. / 실린더가 상했다면 바꿀지 여부를 그때 말씀드립니다.
작업하는 동안 문 주변을 넓게 비워 두시면 좋습니다. / 계단참이 좁은 다세대는 짐이나 신발이 놓여 있으면 공구를 펼칠 자리가 부족하기 때문입니다.

# 비용은 손대기 전에 알려드립니다
조각을 빼는 작업만으로 끝나는지, 실린더나 열쇠까지 바꿔야 하는지 보고 비용을 먼저 안내합니다. / 동의하실 때 시작하고, 원치 않으시면 진행하지 않습니다.
끝내 열지 못하면 비용은 받지 않습니다. / 자세한 순서는 [이용안내](guide.html)에 있습니다.

# 빼낸 뒤 새 열쇠는 이렇게
실린더가 멀쩡하다면 남은 반쪽과 조각을 맞춰 새 열쇠를 만들 수 있는 경우도 있습니다. / 원래 열쇠가 있다면 그것을 기준으로 만드는 것이 가장 정확합니다.
복사 열쇠를 또 복사하는 것은 피하세요. / 깎일 때마다 오차가 커져 다시 부러지기 쉽습니다.
열쇠 관련 출장은 [출장 열쇠](key-call.html)에 따로 정리해 두었습니다.
@ 금천 독산동 열쇠 조각 제거 후 실린더 점검

# 이참에 도어락으로 바꿀까 고민된다면
보조키를 자주 쓰지 않는다면 이번에 정리하는 분도 있습니다. / 반대로 도어락 하나만 쓰기 불안하다면 보조키는 남겨 두는 편이 낫습니다.
보조키 대신 도어락을 다는 경우는 [도어락 설치](doorlock-install.html)를 참고해 주세요. / 문 상태를 보고 어느 쪽이 맞는지 같이 말씀드립니다.

# 다시 부러지지 않게 하는 습관
- 열쇠가 뻑뻑하면 힘주지 말고 그날 바로 점검받기
- 겨울에 언 것 같으면 손으로 열쇠를 잠시 데운 뒤 돌리기
- 문이 처져 걸쇠가 눌리면 문을 살짝 밀면서 돌리기
- 원래 열쇠는 따로 보관하고 복사 열쇠로만 다니기
작은 이상을 넘기지 않는 것만으로도 부러지는 일은 크게 줄어듭니다. / 열쇠 몸통에 금이 간 게 보이거나 끝이 휘었다면 아직 멀쩡하게 돌아가더라도 미리 새로 만들어 두세요.
열쇠고리에 열쇠를 너무 많이 달아 두는 것도 피하는 게 좋습니다. / 무게 때문에 꽂힌 열쇠가 아래로 처지면서 구멍 안에서 조금씩 휘기 때문입니다.

# 독산동 말고 금천 다른 동네도
가산동 디지털단지 사무실 출입문, 시흥동 주택가 대문 열쇠도 똑같이 빼 드립니다. / 차가 들어가기 어려운 골목이면 가까운 큰길을 알려주세요.
다른 지역은 [출장 지역](area.html)에서 확인해 보세요.
