# 독산동 셋집 도어락, 고장 나면 누구에게 먼저 말할까
독산동은 독산역 쪽 큰길에서 언덕을 따라 다세대 건물이 촘촘히 이어진 동네입니다. / 한 건물에 집주인이 살고 위아래 층에 세입자가 사는 경우도 있고, 집주인이 멀리 살며 관리만 하는 건물도 많습니다.
이런 집에서 현관 도어락이 말썽을 부리면 문을 여는 일보다 "누가 연락하고 누가 정하나"가 먼저 걸립니다. / 이 글은 집주인과 세입자가 서로 얼굴 붉히지 않도록 미리 맞춰 두면 좋은 것들을 정리했습니다.
비용 부담이나 책임은 계약 내용과 상황에 따라 달라서 이 글에서 단정하지 않습니다. / 대신 현장에서 자주 보는 일을 바탕으로 확인해 둘 것을 적었습니다.
@ 독산동 다세대 셋집 현관 도어락

# 기준은 계약서와 서로의 대화
도어락 문제를 누가 맡을지는 계약서에 적힌 내용과 두 분의 약속이 기준이 됩니다. / 계약서에 시설 수리에 관한 내용이 있는지 먼저 펼쳐 보세요.
적힌 게 없다면 이번 기회에 간단히라도 문자로 정리해 두는 편이 좋습니다. / 말로만 정하면 나중에 기억이 서로 달라지기 쉽습니다.
판단이 어렵거나 다툼이 생길 것 같다면 부동산 중개사무소나 관련 상담 창구에 물어보시는 것을 권합니다. / 저희는 도어락 상태와 원인을 설명해 드리는 역할까지 합니다.

# 입주 첫날 남겨 둘 기록
세입자라면 들어가는 날 도어락 사진을 앞뒤로 찍어 두세요. / 번호판, 손잡이, 안쪽 몸체, 보조키까지 한 장씩이면 충분합니다.
번호판이 잘 눌리는지, 문을 닫으면 자동으로 잠기는지, 경고음이 나는지도 한 번씩 확인해 봅니다. / 이상이 있으면 그날 집주인에게 사진과 함께 문자로 알려 두세요.
카드나 열쇠를 몇 개 받았는지도 적어 둡니다. / 나갈 때 돌려줄 개수를 두고 헷갈리는 일이 줄어듭니다.

# 고장이 났을 때 세입자가 할 일
도어락이 이상해지면 먼저 배터리를 새것으로 바꿔 보세요. / 그것만으로 돌아오는 경우가 꽤 많습니다.
배터리를 바꿔도 같으면 증상을 짧게 적어 집주인에게 알립니다. / "번호는 눌리는데 모터 소리만 난다", "문을 닫아도 안 잠긴다"처럼 구체적일수록 좋습니다.
문이 안 열리는 급한 상황이 아니라면 집주인과 연락이 닿은 뒤에 출장을 정하는 편이 서로 편합니다. / 급한 상황이라면 아래 연락이 안 될 때 항목을 봐 주세요.
@ 독산동 도어락 고장 증상 사진 기록

# 집주인이 챙겨 두면 좋은 것
집주인이라면 세대마다 어떤 도어락을 언제 달았는지 적어 두시면 좋습니다. / 모델명과 설치 시기를 알면 수리할지 바꿀지 판단이 훨씬 빨라집니다.
세입자에게 연락 받을 번호와 연락이 안 될 때 대신 판단할 사람을 정해 두는 것도 도움이 됩니다. / 멀리 사시거나 출장이 잦다면 더 그렇습니다.
언덕 위 다세대는 같은 시기에 같은 제품을 단 경우가 많습니다. / 한 세대가 고장 나면 다른 세대도 비슷한 때가 왔을 수 있어 같이 점검해 보시길 권합니다.

# 배터리와 소모품은 어떻게 나눌까
배터리처럼 쓰면서 닳는 것은 사는 분이 챙기는 집이 많습니다. / 다만 이것도 집마다 약속이 다를 수 있으니 처음에 한 줄로 정해 두세요.
카드를 잃어버려 새로 등록해야 하는 경우도 미리 정해 두면 좋습니다. / 잃어버린 카드는 지워야 하니 집주인에게도 알리는 것이 서로 안심됩니다.
배터리를 제때 갈지 않아 안쪽 접점에 녹이 슬거나 액이 샌 경우는 판단이 갈리기 쉽습니다. / 배터리 칸에 교체 날짜를 적어 두는 습관이 이런 때 서로의 기억을 맞춰 줍니다.

# 수리냐 교체냐를 같이 정하는 법
고장의 원인이 부품 하나라면 수리로 끝나는 경우가 있습니다. / 반대로 오래돼 부품을 구하기 어렵다면 교체 이야기가 나옵니다.
점검을 맡기면 원인과 함께 수리로 되는지, 교체가 필요한지 이유를 말씀드립니다. / 이 설명을 집주인과 세입자가 같이 듣고 정하면 오해가 적습니다.
현장에 한 분만 계시면 통화를 연결해 함께 설명을 들으셔도 됩니다. / [도어락 수리](doorlock-repair.html)와 [도어락 교체](doorlock-replace.html) 페이지에 진행 방식을 적어 두었습니다.

# 출장을 부를 때 누가 현장에 있을까
문을 여는 일이라면 사시는 분이 현장에 계셔야 합니다. / 신분증 주소, 계약서, 주소가 적힌 우편물 중 하나로 확인합니다.
집주인 혼자 비어 있는 세대를 열어 달라고 하시는 경우에는 바로 진행하지 않습니다. / 세입자가 사는 집이라면 세입자의 확인이 필요합니다.
수리나 교체만 하는 경우라도 사는 분과 집주인이 미리 일정을 맞춰 두면 하루 만에 끝낼 수 있습니다. / 비용은 손대기 전에 먼저 말씀드리고, 동의하실 때만 진행합니다.
@ 금천 독산동 세입자 집주인 도어락 점검

# 작업 뒤 남겨 둘 자료
작업이 끝나면 무엇을 고쳤는지, 어떤 부품을 바꿨는지 사진으로 남겨 두세요. / 영수증도 함께 보관하시면 나중에 정리할 때 편합니다.
새 도어락을 달았다면 모델명과 설명서를 집주인과 세입자 모두 가지고 있으면 좋습니다. / 다음에 같은 일이 생겼을 때 설명이 짧아집니다.
사진과 영수증은 한 사람만 갖고 있지 말고 문자로 서로 보내 두세요. / 휴대폰을 바꾸거나 연락처가 바뀌어도 기록이 남습니다.

# 세입자가 바뀔 때 번호와 카드 정리
세입자가 나가고 새 세입자가 들어올 때는 번호와 카드를 반드시 정리해야 합니다. / 이전 번호와 카드를 그대로 두면 서로 마음이 편하지 않습니다.
나가는 세입자는 받았던 카드와 열쇠 개수를 맞춰 돌려주고, 입주 때 찍은 사진과 지금 상태를 비교해 보세요. / 그 사이 생긴 고장이 있다면 미리 알리는 편이 정리가 빠릅니다.
들어오는 날 새 세입자가 직접 번호를 정하고, 예전 카드는 모두 지우는 것이 깔끔합니다. / 방법이 어렵다면 방문해서 초기화와 등록을 같이 도와드립니다.

# 서로 연락이 안 될 때
밤늦게 문이 안 열리는데 집주인과 연락이 안 된다면 기다리기 어렵습니다. / 이럴 때는 [금천 출장열쇠](seoul-geumcheon.html)로 연락 주시면 사시는 분인지 확인한 뒤 먼저 열어 드립니다.
열고 난 뒤 고장 원인을 사진으로 남겨 두시고 다음 날 집주인에게 알리면 됩니다. / 부품 교체처럼 바로 하지 않아도 되는 일은 그때 같이 정하셔도 늦지 않습니다.

# 독산동과 이웃한 금천 동네들
독산동 옆 시흥동 다세대, 가산동 사무실과 원룸도 다닙니다. / 언덕 골목은 차를 댈 큰길을 알려 주시면 더 빨리 찾아갑니다.
다른 지역은 [출장 지역](area.html)에서 보실 수 있고, 진행 순서는 [이용안내](guide.html)에 있습니다.
