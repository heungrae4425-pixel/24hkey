# 독산동 우리 집 번호, 마지막으로 바꾼 게 언제인가요
독산동은 독산역 쪽 큰길에서 언덕으로 올라가며 다세대 건물이 이어진 동네입니다. / 한 건물에 여러 세대가 살고 계단을 함께 쓰다 보니 현관 번호를 누르는 손이 남의 눈에 띄기 쉽습니다.
그런데 막상 물어보면 이사 온 날 정한 번호를 몇 년째 그대로 쓰는 집이 많습니다. / 바꾸려고 해도 식구들이 헷갈릴까 봐, 등록 방법을 몰라서 미루게 됩니다.
이 글은 독산동 집에서 도어락 비밀번호를 언제 바꾸면 좋은지, 가족끼리 어떻게 나누면 덜 헷갈리는지 정리한 것입니다.
@ 독산동 다세대 현관 도어락 비밀번호 변경

# 같은 번호를 몇 년씩 쓰면
같은 번호를 오래 누르면 자주 누르는 숫자 버튼만 반들반들해지거나 손자국이 남습니다. / 번호판을 비스듬히 보면 어떤 숫자를 쓰는지 짐작이 가기도 합니다.
이사 전 세입자, 예전에 집을 고쳐 준 사람, 잠깐 다녀간 손님이 번호를 알고 있을 수도 있습니다. / 누가 알고 있는지 모르는 상태가 길어지는 것이 가장 마음에 걸리는 부분입니다.
번호판을 마른 천으로 자주 닦고, 번호를 누른 뒤 아무 숫자나 몇 개 더 눌러 두는 습관도 도움이 됩니다. / 앞뒤로 아무 숫자를 덧붙여 눌러도 열리는 기능이 있는 제품이 많아 한 번 시험해 보세요.
다세대 계단은 폭이 좁아 뒤에 올라오는 이웃이 손 바로 옆에 서게 되는 경우가 있습니다. / 이럴 때는 손바닥으로 번호판 위를 살짝 가리고 누르는 것만으로도 충분히 조심할 수 있습니다.

# 바꾸는 때를 미리 정해 두기
언제 바꿀지 막연하면 계속 미루게 됩니다. / 그래서 바꾸는 때를 달력에 붙여 두는 방법을 권합니다.
- 계절이 바뀌어 배터리를 갈 때 번호도 같이
- 집에 드나들던 사람이 바뀌었을 때
- 번호를 누르다 누가 본 것 같다고 느꼈을 때
- 아이가 친구에게 번호를 말했다고 할 때
배터리 교체와 번호 변경을 한 번에 묶으면 잊어버리지 않습니다. / 배터리 칸 안쪽에 바꾼 날짜를 적어 두면 다음 때를 알기 쉽습니다.

# 식구 모두가 있는 날 바꾸기
번호는 식구가 다 집에 있는 날 바꾸는 것이 가장 안전합니다. / 한 사람이 혼자 바꿔 두면 밖에 있던 식구가 문 앞에서 막히게 됩니다.
저녁 먹고 다 같이 있을 때 새 번호를 정하고, 한 사람씩 직접 눌러 열어 보게 하세요. / 손으로 한 번 눌러 본 번호는 머리로만 외운 번호보다 훨씬 오래 기억납니다.

# 새 숫자 조합, 이것만은 빼기
생일, 전화번호 뒷자리, 집 호수처럼 남이 쉽게 알 수 있는 숫자는 피하는 게 좋습니다. / 1234나 같은 숫자 반복도 마찬가지입니다.
그렇다고 너무 복잡하면 식구들이 기억하지 못합니다. / 가족끼리만 아는 의미가 있는 숫자를 섞되, 밖에서 짐작하기 어려운 조합이면 충분합니다.
번호 자리 수를 조금 늘리는 것도 방법입니다. / 제품마다 설정할 수 있는 길이가 달라 모델을 확인해 보세요.
@ 독산동 도어락 비밀번호 가족 공유 관리

# 아이에게 알려 줄 때
아이에게 번호를 알려 줄 때는 "친구에게도, 쪽지에도 쓰지 않는다"는 약속을 같이 해 주세요. / 가방이나 필통에 번호를 적어 두는 일이 생각보다 많습니다.
아이가 번호를 자꾸 잊는다면 번호 대신 카드나 태그를 하나 따로 주는 방법도 있습니다. / 잃어버리면 그 카드만 지우면 되니 부담이 적습니다.
언덕길을 오르내리며 학교를 다니는 아이라면 비 오는 날 젖은 손으로 번호를 누르다 틀리는 일도 있습니다. / 이럴 때 침착하게 다시 누르는 법을 미리 알려 주세요.

# 따로 사는 가족과 나눌 때
가끔 들르는 부모님이나 형제에게 번호를 알려 드리는 집도 있습니다. / 이럴 때는 식구들이 쓰는 번호와 따로 둘 수 있는지 먼저 확인해 보세요.
제품에 따라 번호를 여러 개 등록하거나, 한동안만 쓰는 임시 번호를 둘 수 있습니다. / 방문이 끝나면 그 번호만 지우면 되어 식구 번호를 바꿀 필요가 없습니다.
따로 사는 가족에게 번호를 문자로 보낼 때는 집 주소와 같은 메시지에 넣지 마세요. / 전화로 직접 불러 드리거나 만났을 때 알려 드리는 편이 더 낫습니다.

# 번호와 카드, 지문을 섞어 쓰기
번호만 쓰는 집이라면 카드나 지문을 함께 쓰는 것도 생각해 볼 만합니다. / 식구마다 편한 방법이 다르기 때문입니다.
예를 들어 부모는 지문, 아이는 카드, 손님은 임시 번호처럼 나누면 관리가 단순해집니다. / 지금 쓰는 도어락이 이런 기능을 지원하지 않는다면 [도어락 설치](doorlock-install.html) 상담 때 같이 살펴볼 수 있습니다.

# 바꾼 뒤 꼭 시험해 볼 것
새 번호를 등록한 뒤에는 문을 연 채로 바깥에서 몇 번 눌러 보세요. / 문을 닫고 시험했다가 등록이 안 됐으면 바로 문 밖에 갇히게 됩니다.
예전 번호가 지워졌는지도 확인해야 합니다. / 새 번호를 추가만 하고 예전 번호를 남겨 두는 실수가 흔합니다.
식구가 각자 한 번씩 문을 닫은 상태에서 열어 보는 것까지 해 두면 마음이 놓입니다. / 이때 배터리 경고음이 나는지도 같이 들어 보고, 소리가 나면 그날 바로 새 배터리로 갈아 주세요.
바꾼 번호를 휴대폰 메모에 그대로 적어 두는 것은 피하는 게 좋습니다. / 꼭 적어야 한다면 집 주소와 함께 두지 말고, 식구만 알아볼 수 있는 힌트 정도로만 남겨 두세요.

# 누가 바꿨는지 몰라 막혔을 때
식구 중 한 명이 번호를 바꾼 걸 모르고 나갔다가 들어오지 못하는 경우도 있습니다. / 먼저 다른 식구에게 연락해 보시고, 연락이 안 되면 번호를 여러 번 누르지 말고 멈춰 주세요.
여러 번 틀리면 도어락이 한동안 입력을 막아 버립니다. / 그래도 들어가야 하면 [금천 출장열쇠](seoul-geumcheon.html)로 연락 주시면 사시는 분인지 확인한 뒤 열어 드립니다.
문을 끝내 못 열면 비용은 받지 않고, 비용은 손대기 전에 먼저 말씀드립니다. / 열린 뒤에는 새 번호 등록까지 같이 도와드립니다.
@ 금천 독산동 비밀번호 재설정 출장

# 등록 방법이 헷갈린다면
도어락마다 번호 바꾸는 버튼 위치와 순서가 다릅니다. / 설명서를 잃어버렸다면 배터리 칸 근처의 모델명을 사진으로 찍어 보내 주세요.
간단한 방법은 전화로 안내해 드립니다. / 방문이 필요한 경우 진행 순서는 [이용안내](guide.html)에 적어 두었고, 버튼이 안 먹히거나 등록이 계속 실패하면 [도어락 수리](doorlock-repair.html) 점검으로 이어서 봐 드립니다.

# 독산동 밖 금천 동네까지

다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
