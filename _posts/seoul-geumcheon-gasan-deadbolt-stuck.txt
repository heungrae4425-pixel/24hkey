# 가산동에서 잠금쇠가 반쯤 나온 채 멈췄다면
가산동은 가산디지털단지역 주변으로 사무실 건물이 이어지고, 골목 안쪽에는 사람이 사는 집과 원룸이 섞여 있는 동네입니다. / 퇴근하며 사무실 문을 잠그려는데 철컥 소리 대신 드르륵 소리만 나고 잠금쇠가 반쯤에서 멈추는 일이 있습니다.
집 현관에서도 비슷합니다. / 번호를 눌렀는데 잠금쇠가 안 빠져서 문이 안 열리거나, 반대로 문을 닫았는데 잠기지 않고 헛도는 경우입니다.
이 글은 데드볼트라고 부르는 잠금쇠가 안 들어가거나 안 빠질 때 어디부터 살피면 좋은지 차례대로 정리했습니다.
@ 가산동 현관 데드볼트 잠금쇠 걸림

# 데드볼트가 뭔지 먼저 짚고
데드볼트는 문 옆면에서 문틀 쪽으로 튀어나와 문을 단단히 잠그는 네모난 쇠막대입니다. / 손잡이를 돌리면 들어가는 둥근 걸쇠와 달리, 도어락 모터나 열쇠를 돌려야만 움직입니다.
이 쇠막대가 문틀에 있는 구멍에 쏙 들어가야 문이 잠기고, 다시 빠져나와야 문이 열립니다. / 그래서 쇠막대 자체보다 쇠막대가 들어가는 길에 문제가 생기는 경우가 많습니다.
문 옆면을 열린 상태에서 보면 쇠막대가 들어갔다 나오는 모습을 직접 볼 수 있습니다. / 이 모습을 한 번 봐 두면 뒤에 나오는 확인이 훨씬 쉬워집니다.

# 안 들어가는 경우와 안 빠지는 경우
먼저 지금 어떤 상황인지 나눠 보세요. / 문이 열린 상태에서 잠그려는데 쇠막대가 안 나오는지, 문이 잠긴 상태에서 쇠막대가 안 들어가 문이 안 열리는지입니다.
문이 열려 있는데 쇠막대가 안 나온다면 도어락 쪽 문제를 먼저 의심합니다. / 문이 닫혀 있을 때만 걸린다면 문과 문틀이 맞물리는 부분을 의심합니다.
문이 안 열리는 쪽이 훨씬 급합니다. / 이때는 아래 확인 몇 가지만 해 보고 오래 붙잡지 말고 연락 주세요.

# 문을 연 상태에서 잠가 보기
문이 열려 있다면 문을 연 채로 안쪽 잠금 버튼이나 번호를 눌러 보세요. / 쇠막대가 시원하게 나왔다 들어간다면 도어락은 정상일 가능성이 큽니다.
그런데 문을 닫으면 잠기지 않는다면 쇠막대가 문틀 구멍에 부딪히고 있다는 뜻입니다. / 문틀 쪽 쇠판에 긁힌 자국이 있는지 보면 어느 방향으로 어긋났는지 짐작할 수 있습니다.
문을 연 상태에서도 쇠막대가 반쯤만 나온다면 도어락 안쪽 기어나 모터를 의심해 볼 수 있습니다. / 이 경우는 점검이 필요합니다.

# 모터 소리는 나는데 쇠가 안 움직일 때
번호를 누르면 윙 하는 모터 소리는 나는데 쇠막대가 꿈쩍하지 않는 경우가 있습니다. / 배터리가 약해 힘이 모자라거나, 쇠막대가 문틀에 꽉 눌려 있을 때 자주 생깁니다.
배터리 경고음이 났던 적이 있다면 배터리부터 의심해 보세요. / 문이 잠긴 상태라면 바깥 비상 단자에 9V 건전지를 대고 다시 시도해 볼 수 있습니다.
배터리를 바꿔도 같다면 도어락 안쪽 부품 문제일 수 있습니다. / 이때는 [도어락 수리](doorlock-repair.html)로 점검을 받으시는 편이 좋습니다.
@ 가산동 도어락 모터 소리 데드볼트 안 빠짐

# 문틀 받침쇠 구멍이 어긋났을 때
오래 쓴 문은 경첩 쪽이 조금씩 처지면서 쇠막대 높이와 문틀 구멍 높이가 어긋납니다. / 처음엔 살짝 걸리다가 점점 세게 걸리게 됩니다.
문을 닫은 상태에서 문을 몸 쪽으로 당기거나 반대로 밀면서 번호를 눌러 보세요. / 그때 잠금쇠가 움직인다면 처짐이나 어긋남이 원인일 가능성이 큽니다.
이 경우 받침쇠 위치나 경첩을 조금 조정하면 다시 부드럽게 맞물립니다. / 도어락을 바꿀 필요가 없는 경우가 많습니다.

# 사무실 출입문에서 자주 보는 모습
가산동 사무실은 하루에도 수십 번 여닫는 문이 많습니다. / 문이 저절로 닫히게 하는 장치가 약해지면 문이 끝까지 닫히지 않은 채 잠금쇠가 나와 문틀에 부딪힙니다.
유리문이나 테두리가 얇은 문은 잠금쇠가 바닥이나 위쪽으로 들어가는 구조도 있습니다. / 이런 문은 바닥 구멍에 먼지나 작은 돌이 끼어 쇠막대가 끝까지 안 들어가기도 합니다.
업무가 끝난 뒤 문이 안 잠기면 그대로 두고 퇴근하기도 어렵습니다. / 사무실 문은 업무 시간이 끝난 뒤에도 출동하니 상황을 알려 주세요.

# 수동 손잡이로 돌려 보기
안쪽에 있다면 도어락 안쪽 몸체의 돌리는 손잡이를 손으로 천천히 돌려 보세요. / 모터 대신 손힘으로 쇠막대를 움직일 수 있습니다.
돌릴 때 중간에서 딱 걸리는 느낌이 있다면 그 지점이 문틀과 부딪히는 곳입니다. / 문을 살짝 밀거나 당기며 다시 돌려 보세요.
너무 세게 비틀면 안쪽 기어가 상할 수 있습니다. / 손가락 힘으로 안 되면 멈추는 것이 좋습니다.

# 이런 대처는 피해 주세요
잠금쇠가 걸렸다고 문을 어깨로 밀거나 발로 차는 분이 있습니다. / 그러면 쇠막대가 휘거나 문틀 쇠판이 찌그러져 수리가 더 커집니다.
문틈에 드라이버를 넣어 쇠막대를 밀어 넣으려는 것도 좋지 않습니다. / 문 옆면과 도어락 외관에 흠집이 남고, 쇠막대 끝이 망가지기 쉽습니다.
윤활제를 도어락 안쪽에 많이 뿌리는 것도 권하지 않습니다. / 전자 부품에 스며들면 다른 고장으로 이어질 수 있습니다.

# 전화 전에 메모해 둘 세 가지
아래 세 가지를 알려 주시면 원인을 빨리 짚을 수 있습니다.
- 문이 열린 상태인지 잠긴 상태인지
- 모터 소리가 나는지, 아무 소리도 안 나는지
- 집 현관인지 사무실 출입문인지, 문 재질은 무엇인지
문 옆면 잠금쇠와 문틀 쇠판을 사진으로 보내 주시면 더 좋습니다. / 사무실이라면 건물 출입이 되는지도 같이 알려 주세요.
@ 금천 가산동 사무실 출입문 잠금쇠 점검

# 확인 후 비용 안내와 여는 방식
도착하면 먼저 사시는 분이나 사무실을 쓰시는 분인지 확인합니다. / 신분증, 주소가 적힌 우편물, 관리실 확인, 임대 계약서 중 하나면 됩니다.
문이 잠긴 채 쇠막대가 안 빠진다면 덜 상하는 방법부터 차례로 시도합니다. / 여는 과정은 [현관문 개문](door-open.html)에 적어 두었습니다.
비용은 상태를 본 뒤 손대기 전에 먼저 말씀드리고, 끝내 못 열면 받지 않습니다. / 부품을 바꿔야 할 때도 바꾸기 전에 따로 여쭙니다.

# 고친 뒤 다시 걸리지 않게
문이 다시 잘 맞물리면 몇 번 열고 닫으며 잠금쇠가 부드럽게 드나드는지 같이 확인합니다. / 문이 끝까지 닫히는지, 닫히는 속도가 적당한지도 봅니다.
문이 다시 끌리거나 잠금이 한 번에 안 될 때 미루지 않는 것이 가장 좋은 예방입니다. / 도어락이 너무 오래돼 부품을 구하기 어렵다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 가산동 말고 금천 어디라도
가산동과 이어진 독산동, 금천구청역 쪽 시흥동 다세대도 다닙니다. / 금천에서 다니는 곳은 [금천구 출장열쇠](seoul-geumcheon.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
