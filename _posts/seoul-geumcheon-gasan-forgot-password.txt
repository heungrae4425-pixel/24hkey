# 가산동 문 앞에서 번호가 하얗게 지워졌다면
가산동은 가산디지털단지역 주변으로 사무실 건물이 몰려 있고, 그 틈에 집과 원룸이 섞여 있는 동네입니다. / 하루에 문을 몇 번씩 여닫다 보니 오히려 매일 누르던 번호가 갑자기 생각나지 않는 순간이 찾아옵니다.
피곤한 퇴근길, 오랜만에 출근한 월요일 아침, 휴가를 다녀온 날에 특히 그렇습니다. / 이 글은 가산동 집 현관이나 사무실 출입문 번호를 잊었을 때, 또는 누가 번호를 바꿔 놓았을 때 차례로 해 볼 것을 정리했습니다.
@ 가산동 도어락 비밀번호 분실 현관

# 잊은 것인지, 바뀐 것인지부터
먼저 내가 번호를 잊은 건지, 누군가 바꾼 건지를 나눠 보세요. / 해결 방법이 다르기 때문입니다.
어제까지 잘 열리던 번호가 오늘 갑자기 틀렸다고 나온다면 누가 바꿨을 가능성이 있습니다. / 반대로 오랜만에 온 집이나 사무실이라면 내 기억이 흐려진 쪽일 수 있습니다.
번호를 누를 때 삑 하고 틀렸다는 소리가 나는지, 번호판 자체가 반응이 없는지도 구분해 주세요. / 번호판이 꺼져 있다면 번호보다 배터리 문제일 가능성이 큽니다.

# 번호판이 꺼져 있다면 전원부터
번호를 아무리 맞게 눌러도 번호판에 불이 안 들어오면 소용이 없습니다. / 이 경우는 번호를 잊은 게 아니라 배터리가 다 된 것일 수 있습니다.
도어락 바깥쪽 아래에 9V 건전지를 대는 비상 단자가 있는지 찾아보세요. / 가산디지털단지역 주변 편의점에서 건전지를 구해 단자에 대고 있으면 잠깐 전원이 들어옵니다.
전원이 들어온 뒤에도 틀렸다는 소리가 난다면 그때부터 번호를 다시 떠올려 보시면 됩니다. / 들어가신 뒤에는 안쪽 배터리를 전부 새것으로 바꿔 주세요.

# 손이 기억하는 번호를 떠올리는 법
머리로는 안 떠올라도 손가락이 기억하는 경우가 많습니다. / 번호판을 보지 말고 평소처럼 손을 올려 리듬대로 눌러 보세요.
그래도 안 되면 예전에 쓰던 번호, 다른 곳에서 쓰는 번호, 가족 생일을 섞은 번호를 떠올려 봅니다. / 사무실이라면 회사에서 쓰는 다른 문 번호와 헷갈렸을 수도 있습니다.
휴대폰 메모, 메신저에 남긴 기록, 이사나 입주 때 받은 문자를 찾아보는 것도 방법입니다. / 의외로 오래전 대화방에 번호가 남아 있는 경우가 있습니다.

# 몇 번까지 눌러 봐도 될까
대부분 도어락은 여러 번 틀리면 한동안 입력을 막습니다. / 서너 번쯤 틀렸다면 잠시 멈추고 떠오르는 번호를 차분히 정리한 뒤 다시 시도하세요.
막 누르다 보면 맞는 번호를 눌렀는데도 입력이 막혀 있어서 안 열린 건지 헷갈립니다. / 시도한 번호를 휴대폰에 적어 가며 하면 같은 번호를 반복하지 않습니다.

# 입력이 잠겼을 때 기다리는 시간
입력이 막히면 번호판에서 경고음이 나거나 아예 반응이 없어집니다. / 이때 계속 누르면 막히는 시간이 더 길어지는 제품도 있습니다.
몇 분 기다렸다가 다시 눌러 보세요. / 기다리는 동안 가족이나 동료에게 연락을 먼저 돌리는 편이 시간을 아낍니다.
@ 가산동 도어락 입력 잠김 경고음

# 사무실 출입문 번호를 누가 바꿨다면
가산동 사무실은 직원이 바뀌거나 보안 점검이 있을 때 출입문 번호를 바꾸는 일이 많습니다. / 공지를 놓쳤거나 단체방 메시지를 못 봤을 수 있으니 먼저 동료에게 물어보세요.
담당자나 대표에게 연락이 닿으면 대부분 거기서 해결됩니다. / 건물 관리실에서 출입문 관리를 같이 하는 곳이라면 관리실에도 확인해 보세요.
아무에게도 연락이 안 되는 밤이나 주말이라면 출장을 부르실 수 있습니다. / 이때는 그 사무실을 쓰는 분이라는 확인이 필요해서 사원증이나 임대 계약서, 관리실 확인 중 하나를 준비해 주세요.

# 집 번호를 가족이 바꿨다면
식구 중 한 명이 번호를 바꾸고 미처 알리지 못한 경우가 생각보다 많습니다. / 아침에 나간 사이 바뀌었다면 저녁에 문 앞에서 막히게 됩니다.
먼저 가족에게 전화나 메시지로 확인해 보세요. / 회의 중이거나 잠들어 연락이 안 될 수 있으니 조금 기다려 보는 것도 방법입니다.
번호를 바꾼 가족에게 연락이 닿았다면 전화로 번호를 불러 달라고 하기보다 문자로 받는 편이 낫습니다. / 복도에서 소리 내어 번호를 따라 말하면 지나가는 사람이 들을 수 있습니다.
급하게 들어가야 할 사정이 있다면 그때 연락 주세요. / 집 안에 아이나 반려동물이 혼자 있다면 꼭 먼저 말씀해 주세요.

# 카드나 지문이 같이 등록돼 있다면
번호를 잊었어도 카드나 지문이 등록돼 있다면 그쪽으로 열 수 있습니다. / 지갑이나 휴대폰 케이스에 카드가 끼워져 있지 않은지 확인해 보세요.
지문은 손이 차거나 젖어 있으면 잘 안 됩니다. / 손을 닦고 따뜻하게 한 뒤 다시 대 보세요.
번호, 카드, 지문 중 하나만 살아 있어도 문은 열 수 있습니다. / 평소에 두 가지 이상을 등록해 두면 이런 날 든든합니다.

# 연락이 다 안 될 때 부르는 순서
가족도 동료도 연락이 안 되고 기다릴 수 없다면 [금천 출장열쇠](seoul-geumcheon.html)로 전화 주세요. / 지금 계신 곳과 문 종류, 번호판 상태를 알려 주시면 됩니다.
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙기기 좋습니다. / 사무실이라면 건물 출입이 되는지, 관리실이 열려 있는지도 같이 알려 주세요.

# 신분 확인과 비용
도착하면 먼저 사시는 분, 사용하시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리실 확인 중 하나면 됩니다.
신분증이 안에 있다면 문을 연 직후 바로 보여 주시는 방식으로 진행합니다. / 비용은 문 상태를 본 뒤 시작 전에 먼저 말씀드리고, 끝내 못 열면 받지 않습니다.
여는 과정은 [현관문 개문](door-open.html)에, 전체 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
@ 금천 가산동 비밀번호 분실 문 열기 출장

# 열린 뒤 번호를 다시 정리하는 법
문이 열리면 안쪽에서 새 번호를 등록하고, 예전 번호는 지워 둡니다. / 문을 연 상태로 바깥에서 새 번호를 몇 번 눌러 시험해 본 뒤 닫으세요.
사무실이라면 바꾼 번호를 누구에게 언제 알릴지 정해 두면 같은 일이 반복되지 않습니다. / 집이라면 식구가 모두 있는 날 다시 한 번 같이 눌러 보는 것을 권합니다.
버튼이 잘 안 눌리거나 등록이 자꾸 실패한다면 도어락 자체 고장일 수 있습니다. / 이때는 [도어락 수리](doorlock-repair.html)로 먼저 점검해 드립니다.

# 가산동 말고 금천 곳곳
가산동 옆 독산동, 금천구청역 쪽 시흥동 주택가도 다닙니다. / 금천 어디서든 24시간 연락 주시면 됩니다.
다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

# 마무리
