# 시흥동 현관에서 지문이 또 빨간불이라면
시흥동은 금천구청역 생활권과 언덕 위 다세대, 주택가가 넓게 퍼져 있는 동네입니다. / 계단을 올라와 손가락을 댔는데 빨간불과 함께 실패음이 나면 기운이 쭉 빠집니다.
지문 도어락은 열쇠를 챙기지 않아도 돼 편하지만, 한 번 말썽을 부리기 시작하면 매일 문 앞에서 몇 번씩 손을 대게 됩니다. / 대부분은 고장이 아니라 손 상태나 센서 표면, 처음 등록할 때의 방식에서 원인이 나옵니다.
이 글은 지문 인식이 자꾸 실패할 때 집에서 차례로 점검해 볼 것을 정리했습니다. / 점검해도 나아지지 않을 때 [금천구 출장열쇠](seoul-geumcheon.html)에 맡기는 기준도 함께 적었습니다.
@ 시흥동 지문 도어락 인식 실패 점검

# 실패하는 순간을 먼저 떠올려 보기
언제 잘 안 되는지 떠올리면 원인이 금방 좁혀집니다. / 아래 중 해당하는 것이 있는지 보세요.
- 겨울 아침이나 찬바람 맞고 들어올 때만 잘 안 된다
- 설거지나 손 씻은 직후에 잘 안 된다
- 특정 식구 손가락만 유독 안 된다
- 어느 날부터 모든 식구가 다 잘 안 된다
앞의 세 가지는 손이나 등록 문제일 가능성이 크고, 마지막은 센서나 기기 쪽을 의심해 볼 만합니다. / 이 구분만 해 두어도 전화로 설명하기가 훨씬 쉬워집니다.

# 손이 너무 건조하거나 젖어 있을 때
지문 센서는 손가락 표면의 굴곡을 읽습니다. / 손이 바싹 마르면 굴곡이 흐려지고, 젖어 있으면 물기 때문에 번져서 읽힙니다.
겨울철 언덕길을 올라오면 손끝이 차고 건조해지기 쉽습니다. / 손가락을 입김으로 살짝 데우거나 손바닥에 비벼 따뜻하게 한 뒤 대 보세요.
손을 씻은 직후라면 옷에 가볍게 닦고 대면 됩니다. / 핸드크림을 듬뿍 바른 직후에도 센서가 미끄러워지니 조금 스며든 뒤 대는 게 좋습니다.

# 센서 표면을 닦는 법
센서 유리에는 손때와 먼지가 계속 쌓입니다. / 눈으로 보기엔 깨끗해도 비스듬히 비춰 보면 얼룩이 보이는 경우가 많습니다.
마른 부드러운 천으로 가볍게 닦아 주세요. / 안경 닦는 천 정도면 충분합니다.
물이나 세정제를 직접 뿌리는 것은 피하세요. / 틈으로 스며들면 센서 아래 부품까지 상할 수 있습니다.
센서 표면에 긁힌 자국이 깊게 나 있다면 닦는 것만으로는 돌아오지 않습니다. / 이때는 점검을 받아 보시는 게 좋습니다.
@ 시흥동 지문 센서 표면 닦기

# 손가락 대는 방법도 영향이 큽니다
센서에 손끝만 살짝 대면 읽을 면적이 너무 좁습니다. / 손가락 첫마디 가운데, 지문 소용돌이가 있는 부분이 센서 한가운데 오도록 대 주세요.
너무 세게 누르면 굴곡이 눌려 오히려 잘 안 읽힙니다. / 평소 스마트폰 화면을 누르는 정도의 힘이면 충분합니다.
대자마자 떼지 말고 짧게 멈췄다가 떼 보세요. / 성급하게 떼면 읽기 전에 실패로 처리되는 경우가 있습니다.
등록할 때와 같은 각도로 대는 것도 중요합니다. / 서서 등록했는데 몸을 숙이고 대면 손가락이 비스듬히 닿아 실패가 잦아집니다.

# 등록할 때 이렇게 하면 실패가 줄어듭니다
처음 등록할 때 같은 자리만 여러 번 대면 조금만 비켜 대도 인식이 안 됩니다. / 등록하면서 손가락을 조금씩 위아래, 좌우로 옮겨 가며 대 주시는 게 좋습니다.
한 사람당 손가락 두세 개를 등록해 두세요. / 하나가 다치거나 반창고를 붙였을 때도 다른 손가락으로 열 수 있습니다.
등록한 지 오래됐다면 지우고 다시 등록해 보는 것도 방법입니다. / 아이들은 손이 자라면서 인식이 떨어지기 때문에 가끔 새로 등록해 주는 게 좋습니다.

# 식구 한 명만 유독 안 될 때
특정 식구만 자주 실패한다면 그분 손 상태 문제일 가능성이 큽니다. / 손끝 피부가 얇거나 굳은살이 많은 분, 손을 많이 쓰는 일을 하시는 분은 지문이 흐릿한 경우가 있습니다.
이런 분은 지문만 고집하지 말고 번호나 카드를 함께 쓰시는 편이 편합니다. / 매일 실패하며 스트레스를 받는 것보다 훨씬 낫습니다.
손을 다쳐 붕대를 감았거나 손끝이 갈라진 기간에는 다른 손 손가락을 미리 등록해 두세요. / 오른손잡이라도 왼손 검지 하나쯤 등록해 두면 짐을 든 날에도 쓸모가 있습니다.
어르신이 함께 사신다면 지문 대신 카드를 하나 드리는 것도 좋은 방법입니다. / 나이가 들수록 손끝 지문이 옅어지는 분이 많기 때문입니다.

# 모든 식구가 다 안 된다면
누구 손가락이든 다 실패한다면 센서나 기기 쪽 문제일 수 있습니다. / 배터리가 약해도 센서 반응이 둔해지니 배터리부터 새것으로 바꿔 보세요.
그래도 안 되면 센서 불이 들어오는지, 손가락을 댈 때 반응음이 나는지 확인해 보세요. / 아예 반응이 없다면 센서 부품 고장일 가능성이 있습니다.
이 단계에서는 [도어락 수리](doorlock-repair.html)로 센서를 점검받는 것이 좋습니다. / 센서만 바꿀 수 있는 제품도 있어 무조건 교체할 필요는 없습니다.

# 문 앞에서 지문이 끝내 안 될 때
지문이 안 된다고 번호까지 잊으셨다면 서너 번만 시도하고 멈추세요. / 계속 실패하면 일정 시간 입력이 잠깁니다.
번호판이 꺼져 있다면 9V 건전지를 비상 단자에 대 보세요. / 이때 번호를 알면 열리고, 지문은 배터리가 약하면 잘 안 될 수 있습니다.
그래도 안 되면 위치와 상황을 알려주세요. / 문을 열기 전에 사시는 분인지 신분증이나 우편물로 확인하고, 비용을 먼저 말씀드린 뒤 진행합니다.
@ 금천 시흥동 지문 도어락 문 안 열림 출장

# 비용은 원인을 보고 먼저 안내합니다
닦고 다시 등록하는 것으로 끝나는지, 센서나 기기를 손봐야 하는지에 따라 다릅니다. / 현장에서 원인을 보여 드리고 비용을 먼저 말씀드린 뒤 동의하실 때 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 자세한 순서는 [이용안내](guide.html)에 있습니다.

# 지문 도어락을 바꿀 때 볼 것
오래 쓴 지문 도어락은 센서 성능이 떨어져 있을 수 있습니다. / 새로 바꾸신다면 지문과 함께 번호, 카드를 같이 쓸 수 있는 제품이 무난합니다.
센서가 손이 닿기 쉬운 위치에 있는지, 겨울에도 반응이 괜찮은지 같이 보세요. / 바꾸는 과정은 [도어락 교체](doorlock-replace.html)에 정리해 두었습니다.

# 지문 인식을 오래 잘 쓰는 습관
- 일주일에 한 번 마른 천으로 센서 닦기
- 겨울에는 손을 데운 뒤 대기
- 식구마다 손가락 두세 개씩 등록하기
- 번호도 함께 쓸 수 있게 기억해 두기
- 배터리 경고가 나면 바로 바꾸기
지문은 편한 방법일 뿐 유일한 방법이 되면 안 됩니다. / 번호 하나는 꼭 기억해 두셔야 지문이 안 되는 날에도 문 앞에서 막히지 않습니다.

# 시흥동 말고 금천 어디든
독산동 언덕 다세대, 가산동 디지털단지 쪽 집과 사무실까지 금천구 전체를 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 보세요.
