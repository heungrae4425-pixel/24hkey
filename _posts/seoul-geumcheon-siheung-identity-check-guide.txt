# 시흥동에서 문을 열기 전에 꼭 거치는 일
시흥동은 금천구청역 생활권과 언덕 위 다세대, 주택가가 넓게 이어진 동네입니다. / 문이 잠겨 연락을 주시면 도착해서 가장 먼저 하는 일이 사시는 분인지 확인하는 것입니다.
급한 마음에 왜 바로 안 열어 주느냐고 서운해하시는 분도 계십니다. / 그런데 이 절차가 있어야 내 집도, 옆집도 남이 함부로 열 수 없게 됩니다.
이 글은 [금천구 출장열쇠](seoul-geumcheon.html)가 시흥동에서 문을 열기 전에 무엇을 확인하는지, 준비물이 없을 때는 어떻게 하는지 정리했습니다. / 미리 알고 계시면 현장에서 기다리는 시간이 훨씬 줄어듭니다.
@ 시흥동 출장열쇠 문 열기 전 신분 확인

# 확인 절차가 있는 진짜 이유
문 여는 기술은 누구에게 쓰이느냐에 따라 도움이 되기도 하고 위험이 되기도 합니다. / 그래서 전화를 받은 순간부터 집에 사시는 분이 맞는지 살피는 것이 기본입니다.
다세대 건물은 같은 층에 비슷한 문이 나란히 있습니다. / 호수를 착각하거나, 이미 이사 나간 분이 예전 집을 열어 달라고 하는 일을 막으려면 확인이 꼭 필요합니다.
이 절차는 의심해서가 아니라 모두를 지키기 위한 약속입니다. / 확인이 되면 그다음부터는 빠르게 진행합니다.

# 가장 간단한 방법, 신분증 주소
가장 흔하고 빠른 방법은 신분증에 적힌 주소를 보는 것입니다. / 주민등록증이나 운전면허증 주소가 지금 문 앞 주소와 같으면 바로 확인이 끝납니다.
모바일 신분증도 주소가 보이면 똑같이 쓸 수 있습니다. / 휴대폰을 들고 나오셨다면 미리 화면을 열어 두시면 좋습니다.
주소를 옮기지 않아 신분증 주소가 다르다면 아래 다른 방법을 같이 씁니다. / 전입 신고를 아직 못 한 분이 의외로 많아서 걱정하지 않으셔도 됩니다.

# 신분증 주소가 다를 때 쓰는 서류
이사 온 지 얼마 안 됐거나 주소를 옮기지 않은 분은 다른 자료로 확인합니다. / 아래 중 하나라도 있으면 됩니다.
- 이 집 주소와 이름이 같이 적힌 우편물이나 고지서
- 임대차 계약서나 계약서를 찍어 둔 사진
- 휴대폰에 저장된 관리비, 공과금 문자나 앱 화면
- 택배 앱에 남은 이 주소 배송 기록
여러 개를 함께 보여 주시면 더 빨리 끝납니다. / 이름이 가족 명의로 되어 있다면 그 가족과 통화로 한 번 더 확인하기도 합니다.

# 신분증이 집 안에 있을 때
문이 잠겨 있으니 지갑과 서류가 모두 안에 있는 경우가 제일 많습니다. / 이럴 때는 문을 연 직후에 확인하는 방법으로 진행합니다.
문을 열어 드리면 들어가지 마시고 현관에서 신분증을 꺼내 보여 주시면 됩니다. / 확인 전에는 짐을 옮기거나 다른 방으로 가지 않도록 부탁드립니다.
문을 연 뒤에도 확인이 안 되면 그 자리에서 함께 다른 방법을 찾습니다. / 그래도 맞지 않으면 다시 잠그고 관련 기관에 알리는 것이 원칙입니다.
@ 시흥동 다세대 현관 신분증 우편물 확인

# 집주인이나 관리인이 도와줄 수 있는 경우
다세대나 원룸 건물은 집주인이 같은 건물이나 근처에 사시는 경우가 있습니다. / 집주인이 나와서 세입자가 맞다고 확인해 주시면 그것으로도 충분합니다.
건물 관리인 연락처가 현관 게시판에 붙어 있는 곳도 있습니다. / 전화로 세대 확인을 부탁하는 방법도 함께 씁니다.
늦은 밤이라 연락이 어렵다면 다른 서류 쪽으로 방법을 바꿉니다. / 억지로 깨우지 않아도 되도록 여러 갈래를 준비해 두는 편입니다.

# 가족이 대신 요청하는 경우
멀리 사는 자녀가 부모님 집 문을 열어 달라고 연락하시는 경우도 있습니다. / 이때는 집에 사시는 부모님이 현장에 계시는지가 가장 중요합니다.
부모님이 문 앞에 계시면 부모님 신분증으로 확인합니다. / 아무도 없는 빈집을 대신 열어 달라는 요청은 받기 어렵습니다.
아이가 안에 혼자 있다는 연락이라면 서둘러 가되, 도착해서 보호자 확인은 똑같이 거칩니다. / 이 경우는 통화할 때 꼭 먼저 말씀해 주세요.

# 사무실이나 가게 문이라면
금천구에는 사무실과 가게도 많아 영업장 출입문 연락도 들어옵니다. / 이때는 그 공간을 쓰는 분이 맞는지 확인하는 서류가 필요합니다.
사업자등록증, 임대계약서, 재직이 확인되는 사원증 등이 쓰입니다. / 대표나 관리자와 통화가 되면 확인이 훨씬 빠릅니다.
야간에 혼자 남아 있다가 문이 잠긴 직원이라면 출입 기록이나 건물 관리실 확인도 함께 씁니다. / 어떤 자료가 있는지 통화할 때 말씀해 주시면 미리 알려 드립니다.

# 확인을 거절하면 어떻게 되나요
확인 없이 바로 열어 달라고 하시면 죄송하지만 작업을 시작하지 않습니다. / 이것만큼은 어떤 시간, 어떤 상황에서도 바꾸지 않습니다.
대신 확인할 방법을 함께 찾아 드리는 데는 시간을 아끼지 않습니다. / 대부분은 우편물 한 장, 문자 한 통으로 해결됩니다.

# 전화하실 때 미리 말씀해 주시면 좋은 것
통화할 때 아래를 같이 알려주시면 현장에서 확인이 빨라집니다. / 미리 알면 필요한 쪽으로 준비를 해 갑니다.
- 신분증을 지금 가지고 계신지, 집 안에 있는지
- 주소지가 이 집으로 되어 있는지
- 집주인이나 관리인 연락이 되는지
- 사시는 분 본인인지, 가족이 대신 요청하는 건지
금천구청역 쪽 큰길이나 근처 표지도 같이 알려주시면 언덕 골목에서 헤매지 않습니다.

# 평소에 챙겨 두면 든든한 것
문이 잠기는 날은 미리 알 수 없으니 평소에 조금만 준비해 두시면 좋습니다. / 큰 수고 없이 할 수 있는 것들입니다.
- 휴대폰에 모바일 신분증을 등록해 두기
- 임대차 계약서 첫 장을 사진으로 찍어 앨범에 보관하기
- 관리비나 공과금 안내를 문자나 앱으로 받아 두기
- 집주인, 관리인 연락처를 휴대폰에 저장해 두기
휴대폰만 들고 나와도 확인이 되는 상태를 만들어 두는 것이 핵심입니다. / 쓰레기를 버리러 잠깐 나왔다가 문이 닫힌 날에도 이 준비 덕분에 금방 해결됩니다.

# 확인 뒤에는 비용부터 말씀드립니다
사시는 분 확인이 끝나면 문과 도어락 상태를 보고 비용을 먼저 안내합니다. / 동의하실 때 작업을 시작하고, 원치 않으시면 그대로 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 전체 흐름은 [이용안내](guide.html)에 정리해 두었습니다.
문을 여는 방법은 [현관문 개문](door-open.html)에서 보실 수 있습니다. / 열고 나서 도어락이 이상하면 [도어락 수리](doorlock-repair.html)로 이어서 봐 드립니다.
@ 금천 시흥동 현관문 개문 진행 순서

# 시흥동 말고 금천 다른 동네도
독산동 언덕 위 다세대, 가산동 디지털단지 사무실까지 금천구 어디든 다닙니다. / 차가 들어가기 힘든 골목이면 가까운 큰길에서 만나기도 합니다.
다른 지역은 [출장 지역](area.html)에서 확인해 보세요.

# 자주 묻는 질문
? 전입 신고를 아직 안 했는데 열어 주시나요? | 네, 계약서나 이 주소로 온 우편물, 관리비 문자 같은 자료로 확인하면 됩니다.
? 신분증이 집 안에 있으면 못 여나요? | 문을 연 직후 현관에서 바로 보여 주시는 방식으로 진행합니다.
? 집주인 허락을 꼭 받아야 하나요? | 사시는 분인지만 확인되면 됩니다. 집주인 확인은 여러 방법 중 하나일 뿐입니다.
? 부모님 집을 제가 대신 열어 달라고 해도 되나요? | 부모님이 현장에 계셔야 합니다. 빈집을 대신 열어 드리지는 않습니다.
? 새벽에도 같은 절차를 거치나요? | 네, 시간과 상관없이 같습니다. 대신 확인 방법을 함께 빨리 찾아 드립니다.
