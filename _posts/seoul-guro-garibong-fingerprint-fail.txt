# 가리봉동 현관, 손가락을 대도 빨간 불만 뜰 때
가리봉동은 디지털단지 사무실 건물과 가까이 붙어 있는 주택가입니다. / 퇴근길에 손에 짐을 든 채 지문 하나로 문을 여는 게 편해서 지문 도어락으로 바꾼 집이 꽤 있습니다.
그런데 어느 날부터 손가락을 대도 띠링 하는 실패음만 나고, 몇 번을 다시 대야 겨우 열립니다. / 심한 날은 끝내 안 열려 번호를 꾹꾹 눌러 들어가게 됩니다.
지문이 안 먹히는 원인은 손가락, 센서, 등록 상태, 도어락 부품 네 군데 중 하나인 경우가 대부분입니다. / 이 글은 가리봉동에서 지문 인식이 자꾸 실패할 때 이 순서대로 짚어 보는 방법과 [구로 출장열쇠](seoul-guro.html)를 부를 때를 정리했습니다.
@ 가리봉동 지문 도어락 인식 실패

# 오늘만 안 되는지, 점점 안 되는지
먼저 언제부터 그랬는지 떠올려 보세요. / 원인을 찾는 가장 빠른 실마리가 여기 있습니다.
- 오늘 갑자기 안 됨: 손가락이 젖었거나, 센서가 더러워졌거나, 배터리 문제
- 몇 주에 걸쳐 점점 안 됨: 손가락 피부 변화나 등록한 지문이 오래된 경우
- 특정 사람만 안 됨: 그 사람 등록 상태 문제
- 모두 다 안 됨: 센서나 도어락 쪽 문제
가족 중 한 명이라도 잘 열린다면 센서보다는 손가락이나 등록 쪽을 먼저 보면 됩니다.

# 손가락이 원인인 경우
지문 센서는 손끝의 굴곡을 읽는데, 그 굴곡이 잠깐 흐려지면 인식이 떨어집니다.
- 손을 씻고 바로 대서 물기가 남은 경우
- 겨울에 손끝이 갈라지고 건조한 경우
- 핸드크림이나 기름이 묻어 있는 경우
- 일하면서 손끝이 닳거나 굳은살이 생긴 경우
- 작은 상처나 반창고가 손끝에 있는 경우
손끝을 옷에 한 번 문지르고 다시 대 보세요. / 너무 건조하다면 입김을 살짝 불어 준 뒤 대면 인식이 나아지기도 합니다.

# 대는 방법도 생각보다 중요합니다
손가락을 너무 세게 누르면 굴곡이 눌려 납작해집니다. / 반대로 끝만 살짝 대면 읽을 면적이 모자랍니다.
등록할 때와 같은 각도, 같은 손가락 면으로 센서 가운데를 덮듯이 대 주세요. / 손끝이 아니라 첫째 마디 가운데가 센서 중심에 오도록 하면 잘 읽히는 제품이 많습니다.
급하게 여러 번 연달아 대면 도어락이 잠시 지문 입력을 막기도 합니다. / 두세 번 실패했다면 몇 초 쉬었다가 다시 대 보세요.
@ 가리봉동 지문 센서 손가락 대는 위치

# 센서 창의 얼룩과 긁힘
매일 손이 닿는 센서 창에는 손기름과 먼지가 얇게 쌓입니다. / 겉으로는 깨끗해 보여도 비스듬히 비춰 보면 뿌옇게 얼룩이 보입니다.
안경 닦는 천처럼 부드러운 마른 천으로 가볍게 닦아 주세요. / 물티슈나 알코올을 쓰면 표면 코팅이 상하는 제품이 있으니 제품 설명을 먼저 확인하는 게 좋습니다.
센서 창에 긁힌 자국이 깊게 났다면 닦아서는 나아지지 않습니다. / 이 경우는 센서 부품 교체를 생각해야 합니다.
비 오는 날이나 겨울 아침에 센서 창에 습기가 맺히는 집도 있습니다. / 창이 흐려 보이면 마른 천으로 닦은 뒤 잠시 기다렸다 대 보세요.
센서 덮개가 있는 제품이라면 덮개가 끝까지 열렸는지도 확인하세요. / 덮개가 반쯤만 열려 손가락 일부가 가려지는 일이 생각보다 흔합니다.

# 등록 상태를 다시 보는 법
처음 등록할 때 손가락 끝만 대고 넣었다면, 지금 대는 면과 달라 실패가 잦을 수 있습니다. / 같은 손가락을 한 번 지우고 다시 등록하면 나아지는 경우가 많습니다.
- 한 사람당 손가락 두세 개 등록해 두기
- 양손에서 하나씩 등록해 두기
- 등록할 때 조금씩 각도를 바꿔 가며 대기
- 아이는 손이 자라니 몇 달마다 다시 등록하기
지문만 골라 지우기 어려운 제품이라면 전체를 지우고 다시 넣어야 합니다. / 이때는 문을 연 상태에서 번호가 살아 있는지 먼저 확인하고 시작하세요.

# 배터리가 약해도 지문부터 느려집니다
지문 센서는 번호판보다 전기를 더 씁니다. / 그래서 배터리가 약해지면 번호는 되는데 지문만 안 되는 시기가 먼저 옵니다.
지문 인식이 갑자기 느려지고 경고음이 함께 난다면 배터리를 전부 새것으로 바꿔 보세요. / 바꾼 뒤 바로 좋아진다면 원인은 배터리였습니다.

# 지금 문 앞이라면 번호로 들어가기
지문이 안 된다고 문 앞에서 오래 손가락을 대고 있을 필요는 없습니다. / 지문 도어락 대부분은 번호로도 열 수 있으니 번호를 눌러 들어가세요.
번호를 오래 안 써서 기억이 안 난다면 가족에게 먼저 물어보세요. / 번호도 모르고 지문도 안 되는 상황이라면 그때 연락 주시면 됩니다.
지문 도어락을 쓰다 보면 번호를 잊어버리는 집이 많습니다. / 들어간 뒤에는 번호를 휴대폰 메모가 아닌 가족끼리만 아는 곳에 적어 두고, 한 달에 한 번은 번호로 열어 보는 습관을 들이세요.

# 가리봉동에서 연락 주실 때
- 주택이나 빌라는 건물 이름이나 번지, 골목 입구 큰길
- 지문이 아예 반응이 없는지, 실패음이 나는지
- 번호로는 열리는지
- 도어락 제품 이름이나 앞면 사진
가리봉동 골목은 안쪽 건물이 많아 가까운 큰길이나 눈에 띄는 건물을 함께 알려 주시면 찾기 쉽습니다. / 실패할 때 번호판에 뜨는 표시나 소리를 짧은 영상으로 찍어 보내 주셔도 좋습니다.

# 문을 여는 경우 거주 확인부터
문을 열어야 하는 상황이라면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 집주인 확인 중 하나면 됩니다.
지문 재등록만 도와 드리는 경우에도 도어락 설정을 바꾸는 일이라 사시는 분 확인을 거칩니다.

# 비용은 손대기 전에 말씀드립니다
센서 청소와 재등록으로 끝나는지, 부품을 바꿔야 하는지에 따라 비용이 다릅니다. / 상태를 본 뒤 먼저 말씀드리고 동의하실 때 진행합니다.
문을 열어야 하는데 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 센서 고장이면 수리, 오래됐다면 교체
식구 모두 지문이 안 되고, 배터리를 바꾸고 센서를 닦아도 그대로라면 센서 부품을 의심합니다. / 부품을 구할 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
제품이 오래돼 부품이 없거나 다른 고장이 함께 있다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 잠긴 문을 열어야 할 때는 [현관문 개문](door-open.html)에 적은 대로 덜 상하는 방법부터 씁니다.
@ 구로 가리봉동 지문 센서 수리 교체 상담
