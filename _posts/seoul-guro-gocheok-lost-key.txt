# 고척동, 열쇠 꾸러미가 손에 없다는 걸 알았을 때
개봉동과 맞닿은 고척동은 빌라와 주택, 아파트가 골고루 섞여 있는 동네입니다. / 주택이나 오래된 빌라에 사는 집은 대문 열쇠, 현관 보조키, 우편함 열쇠까지 한 꾸러미로 들고 다니는 경우가 많습니다.
그 꾸러미를 통째로 잃어버리면 문 하나가 아니라 여러 곳이 한꺼번에 막힙니다. / 반대로 집 안 신발장 위에 꾸러미를 두고 문을 닫고 나왔다면 문 하나만 열면 끝나는 일입니다.
이 글은 고척동에서 열쇠가 없을 때 먼저 꾸러미에 무엇이 달려 있었는지 정리하고, 어떤 순서로 움직이면 좋은지 적었습니다. / 문 앞에서 막혔다면 [구로 출장열쇠](seoul-guro.html)로 연락 주세요.
@ 고척동 열쇠 꾸러미 분실 현관 보조키

# 꾸러미에 무엇이 달려 있었는지 적어 보기
당황한 상태에서는 무엇을 잃어버렸는지조차 헷갈립니다. / 휴대폰 메모장에 꾸러미에 달려 있던 것을 하나씩 적어 보세요.
- 현관 보조키나 손잡이 열쇠
- 대문이나 공동현관 열쇠
- 도어락 비상 열쇠
- 우편함, 자전거, 창고 열쇠
- 차 키나 회사 출입 카드
이 목록이 있어야 문을 연 뒤 무엇을 바꿀지, 누구에게 알릴지가 정해집니다. / 회사 출입 카드나 차 키가 함께 달려 있었다면 그쪽 분실 신고도 따로 챙겨야 합니다.

# 안에 두고 나온 건지 한 번 더 확인
꾸러미를 정말 밖에서 잃어버렸는지, 집 안에 두고 문이 닫힌 건지 먼저 가려 보세요. / 문을 닫으면 저절로 잠기는 손잡이나 오토락 도어락이라면 안에 두고 나와도 문이 잠깁니다.
나오기 직전 열쇠를 어디에 내려놨는지 떠올려 보세요. / 신발장 위, 현관 옆 걸이, 전날 입은 외투 주머니가 가장 흔한 자리입니다.
기억이 확실하지 않다면 일단 밖에서 잃어버렸다고 생각하고 움직이는 편이 안전합니다. / 문을 연 뒤 집 안에서 꾸러미가 나오면 그때 안심하시면 됩니다.

# 고척동에서 되짚어 볼 곳
열쇠는 마지막으로 꺼낸 곳 근처에서 나오는 경우가 많습니다.
- 개봉역이나 탔던 버스, 지하철
- 들렀던 편의점, 마트, 식당 계산대
- 자전거를 세운 곳이나 차 안
- 대문 앞 바닥, 계단 난간, 우편함 위
대문 열쇠로 대문을 연 뒤 현관 앞에서 없어졌다면 대문과 현관 사이를 먼저 찾아보세요. / 대문을 지나며 꾸러미를 우편함 위에 잠깐 올려 두는 일이 꽤 있습니다.
역이나 버스에서 잃어버린 것 같다면 분실물 센터에 문의해 보는 것도 방법입니다. / 다만 찾는 데 시간이 걸리니 문은 먼저 여는 쪽으로 정하세요.

# 여벌 열쇠를 가진 사람
가족, 같은 건물에 사는 집주인, 가까이 사는 친척 중 여벌을 가진 사람이 있는지 떠올려 보세요. / 30분 안에 올 수 있다면 기다리는 편이 가장 간단합니다.
집주인이 가진 열쇠는 전에 바꾼 실린더 이전 것일 수도 있습니다. / 오기 전에 최근 열쇠를 바꾼 적이 있는지 한마디 물어보세요.
@ 고척동 여벌 열쇠 대문 현관 열쇠

# 대문과 현관 중 어느 쪽이 막혔는지
대문이 있는 주택이라면 대문부터 막혔는지, 대문은 지났는데 현관이 막혔는지를 나눠야 합니다. / 둘 다 막혔다면 문 두 개를 차례로 열어야 해서 시간이 조금 더 걸립니다.
대문이 철문이고 오래돼 녹이 슬었다면 실린더가 뻑뻑할 수 있습니다. / 이 점을 미리 말씀해 주시면 맞는 도구를 챙겨 갑니다.
빌라 공동현관이 열쇠로 여는 문이라면 같은 건물 이웃에게 잠깐 열어 달라고 부탁해 보세요. / 공동현관만 지나도 기다리는 동안 바람을 피할 수 있고, 기사도 현관 앞까지 바로 올라갈 수 있습니다.

# 열쇠 없이 해 보면 안 되는 것
- 열쇠 구멍에 머리핀이나 철사 넣어 돌리기
- 담이나 창문을 넘어 들어가기
- 대문을 발로 차거나 흔들기
- 이웃 집 열쇠를 꽂아 보기
열쇠 구멍 안쪽 핀이 상하면 나중에 열쇠를 찾아도 안 들어갑니다. / 담을 넘다 다치면 문을 여는 것보다 훨씬 큰일이 됩니다.

# 고척동에서 연락 주실 때
- 주택이나 빌라는 건물 이름이나 번지, 아파트는 동과 호수
- 개봉역이나 가까운 큰길에서 어느 쪽인지
- 막힌 문이 대문인지 현관인지, 몇 개인지
- 열쇠로만 여는 문인지, 도어락에 보조키가 있는지
- 잃어버린 건지 안에 두고 나온 건지
잠금장치 사진을 보내 주시면 맞는 장비를 고르기 쉽습니다. / 사진이 어렵다면 열쇠 구멍이 손잡이에 있는지, 손잡이 위에 따로 있는지만 말씀해 주셔도 됩니다.

# 열쇠가 없을수록 거주 확인은 꼼꼼하게
열쇠가 없다는 이야기는 누구든 할 수 있어서 사시는 분인지 꼭 확인합니다. / 신분증 주소, 주소가 나온 우편물, 집주인이나 관리하시는 분 확인 중 하나면 됩니다.
지갑까지 꾸러미와 함께 잃어버렸다면 문을 연 뒤 집 안 우편물이나 서류로 확인해도 됩니다. / 그 경우 확인이 끝나기 전까지 기사가 문 앞에 함께 있습니다.

# 비용은 잠금장치를 보고 먼저 안내
문 개수와 잠금장치 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮으실 때만 진행하고, 끝내 못 열면 비용은 받지 않습니다.
열쇠를 새로 만들거나 실린더를 바꾸는 일은 문을 연 뒤 따로 여쭤보고 정합니다. / 진행 순서는 [이용안내](guide.html), 출장 방식은 [열쇠 출장](key-call.html)에 적어 두었습니다.

# 문을 연 뒤 무엇을 바꿀지
꾸러미를 집 안에서 찾았다면 바꿀 것은 없습니다. / 밖에서 잃어버렸다면 처음에 적어 둔 목록을 보며 하나씩 정합니다.
- 꾸러미에 주소나 호수가 적혀 있었다면 현관 실린더 교체를 권합니다
- 대문 열쇠도 함께였다면 대문 실린더도 같이 생각해 보세요
- 집 근처에서 잃었다면 바꾸는 쪽이 마음 편합니다
- 먼 곳에서 잃었고 표시도 없었다면 그대로 쓰셔도 됩니다
열쇠 대신 번호로 여는 방식을 원하시면 문 두께와 구멍을 보고 [도어락 설치](doorlock-install.html)를 상담해 드립니다. / 문을 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 구로 고척동 실린더 교체 도어락 전환 상담

# 다음을 위한 꾸러미 관리
- 꾸러미는 작게, 꼭 필요한 열쇠만
- 열쇠고리에 주소나 호수 적지 않기
- 여벌 하나는 믿을 만한 가족에게
- 현관 안쪽에 열쇠 거는 자리 정해 두기
- 오토락 문이라면 나갈 때 꾸러미를 손에 쥐고 문 닫기
꾸러미가 무거우면 열쇠가 휘고 실린더도 빨리 닳습니다. / 오래된 도어락이 열쇠에 많이 기대고 있다면 [도어락 교체](doorlock-replace.html)도 방법입니다.

# 고척동 말고 구로구 어디든
신도림동, 구로동, 가리봉동, 개봉동, 오류동, 수궁동, 항동까지 구로구 전 지역에 24시간 출동합니다.
구로구 출동 동네는 [구로구 출장열쇠](seoul-guro.html), 그 밖의 지역은 [출장 지역](area.html)에서 확인하세요.
