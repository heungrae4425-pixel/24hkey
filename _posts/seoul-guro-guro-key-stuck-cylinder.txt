# 열쇠가 반쯤 돌다 멈췄다면
구로동 골목 빌라에는 아직 열쇠로 여는 보조키나 손잡이 열쇠를 함께 쓰는 집도 있습니다. / 평소처럼 열쇠를 꽂았는데 반쯤 돌다 딱 멈추거나, 열고 나서 열쇠가 안 빠져 문 앞에 서 있게 되는 날이 있습니다.
열쇠가 꽂히는 둥근 부분을 실린더라고 합니다. / 실린더 안에는 작은 핀들이 줄지어 있어서 맞는 열쇠가 들어가면 핀이 한 줄로 정렬되며 돌아가는 구조입니다.
이 글은 구로동에서 열쇠가 안 돌아가거나 안 빠질 때 원인별로 해 볼 것과 [구로 출장열쇠](seoul-guro.html)를 부르는 때를 적었습니다. / 구로디지털단지역에서 퇴근하는 길에 막혔다면 아래 순서대로 보세요.
@ 구로동 현관 보조키 열쇠 안 돌아감 실린더

# 맞는 열쇠인지 먼저 확인
의외로 많은 경우가 열쇠를 바꿔 꽂은 것입니다. / 현관 열쇠와 보조키 열쇠, 회사 열쇠가 한 꾸러미에 있으면 모양이 비슷해 헷갈립니다.
- 열쇠 머리 모양과 색이 평소 쓰던 것과 같은지
- 최근에 복사한 열쇠인지, 원래 열쇠인지
- 같은 열쇠로 어제까지 잘 열렸는지
복사한 열쇠는 원래 열쇠보다 홈이 아주 조금 다를 수 있습니다. / 새로 복사한 열쇠로만 안 된다면 원래 열쇠로 한 번 해 보세요.
열쇠를 뒤집어 꽂아도 되는 양면 열쇠인지, 한쪽 방향만 맞는 열쇠인지도 확인해 보세요. / 한쪽만 맞는 열쇠를 거꾸로 꽂으면 들어가기는 해도 돌아가지 않습니다.

# 안 돌아가는 이유 몇 가지
맞는 열쇠인데도 안 돌아간다면 아래를 의심해 볼 수 있습니다.
- 실린더 안에 먼지나 녹이 쌓여 핀이 뻑뻑함
- 열쇠 끝이 닳거나 휘어서 핀을 제대로 못 밀어 올림
- 문이 처져서 잠금쇠가 문틀에 눌려 있음
- 누군가 이물질을 넣어 구멍이 막힘
- 추운 날 실린더 안 물기가 얼어붙음
열쇠를 꽂을 때부터 뻑뻑하게 들어갔다면 실린더 안쪽 문제일 가능성이 큽니다. / 꽂히는 건 부드러운데 돌릴 때만 막힌다면 문틀과 잠금쇠 쪽을 먼저 봐야 합니다.

# 집 앞에서 해 볼 수 있는 것
- 열쇠를 끝까지 꽂았다가 머리카락 한 올 굵기만큼 살짝 빼고 돌려 보기
- 문을 몸 쪽으로 당기거나 반대로 밀면서 돌려 보기
- 열쇠를 꽂은 채 위아래로 아주 살짝 흔들며 돌려 보기
문이 처진 집은 당기거나 밀기만 해도 잠금쇠에 걸린 힘이 풀려 열쇠가 돌아갑니다. / 어느 방향이든 힘을 세게 주지 말고 가볍게 시도하세요.

# 연필심 가루는 괜찮고 기름은 피하세요
실린더가 뻑뻑할 때는 연필심을 열쇠 홈에 문질러 꽂아 보는 방법이 있습니다. / 흑연 가루가 핀 사이를 미끄럽게 해 주는 원리입니다.
열쇠 홈 양쪽에 연필심을 여러 번 문지르고 꽂았다 빼기를 몇 번 해 보세요. / 조금씩 부드러워지면 그때 천천히 돌려 봅니다. / 연필은 심이 진한 것일수록 가루가 잘 묻어납니다.
추운 날 얼어서 안 돌아가는 것 같다면 열쇠를 손에 쥐어 잠시 데운 뒤 꽂아 보세요. / 뜨거운 물을 붓는 것은 다시 얼어붙어 더 나빠집니다.
@ 구로동 실린더 뻑뻑함 연필심 흑연 가루

식용유나 뿌리는 윤활유를 열쇠 구멍에 넣으면 당장은 부드러워질 수 있습니다. / 하지만 기름에 먼지가 엉겨 붙어 며칠 뒤에는 더 뻑뻑해지는 일이 많습니다.
특히 겨울에는 기름이 굳어서 핀이 아예 안 움직이기도 합니다. / 실린더에는 마른 흑연 가루나 전용 건식 윤활제 정도만 쓰는 것이 좋습니다.

# 열쇠가 안 빠질 때
문은 열렸는데 열쇠가 실린더에서 안 빠지는 경우도 있습니다. / 이때는 열쇠가 처음 꽂았던 방향으로 완전히 돌아와 있는지 확인하세요.
반쯤 돌아간 상태에서는 핀이 열쇠를 붙잡고 있어서 빠지지 않습니다. / 열쇠 머리가 처음 꽂을 때와 같은 방향인지 보고, 살짝 돌려 맞춘 뒤 곧게 당겨 보세요.
열쇠를 좌우로 비틀며 잡아당기면 열쇠가 부러질 수 있습니다. / 부러진 조각이 안에 남으면 일이 훨씬 커집니다.
열쇠가 안 빠진 채 외출해야 한다면 꽂힌 열쇠는 그대로 두고 꾸러미에서 다른 열쇠만 빼 두세요. / 매달린 무게가 줄면 실린더에 가는 부담도 줄어듭니다.

# 펜치와 망치는 쓰지 않습니다
열쇠가 안 돌아간다고 펜치로 잡고 돌리면 열쇠가 휘거나 부러집니다. / 망치로 열쇠 머리를 두드려 밀어 넣는 것도 실린더 안 핀을 망가뜨립니다.
열쇠가 휘었다면 손으로 펴서 다시 쓰지 마세요. / 휘었던 열쇠는 약해져서 다음에 꽂았을 때 부러지기 쉽습니다.

# 구로동에서 연락 주실 때
- 건물 이름이나 번지, 층과 호수
- 현관 손잡이 열쇠인지, 따로 달린 보조키인지
- 안 돌아가는지, 안 빠지는지, 꽂히지도 않는지
- 열쇠를 꽂은 채로 있는지
- 실린더와 열쇠 사진
열쇠를 꽂은 채 두셨다면 그대로 두고 기다리셔도 됩니다. / 억지로 빼다 부러지는 것보다 그 편이 낫습니다.

# 거주 확인을 거친 뒤 작업합니다
잠긴 문을 열거나 실린더를 다룰 때는 그 집에 사시는 분인지 먼저 확인합니다. / 신분증의 주소, 주소가 나온 우편물, 집주인이나 관리인 확인 중 하나면 됩니다.
문이 이미 열린 상태라면 집 안에서 서류를 보여 주시면 되어 금방 끝납니다.

# 비용은 먼저 말씀드린 뒤 진행
실린더 상태와 잠금장치 종류를 보고 비용을 먼저 안내합니다. / 동의하실 때 시작하고, 아니면 그대로 돌아갑니다.
잠긴 문을 끝내 못 열면 비용은 받지 않습니다. / 실린더를 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다. 진행 순서는 [이용안내](guide.html)에 있습니다.

# 현장에서는 이렇게 풉니다
먼저 열쇠와 실린더를 살펴 핀이 막힌 것인지, 문틀이 누르고 있는 것인지 가립니다. / 문틀 문제라면 문을 받쳐 힘을 풀고 돌리고, 실린더 문제라면 안쪽을 청소하거나 부품을 손봅니다.
잠긴 채 문이 안 열리면 덜 상하는 방법으로 엽니다. / 개방 방식은 [현관문 개문](door-open.html), 열쇠 출장은 [열쇠 출장](key-call.html)에서 보실 수 있습니다.
@ 구로 구로동 실린더 점검 보조키 열쇠 출장

# 실린더를 오래 쓰는 법과 바꿀 때
- 열쇠는 끝까지 꽂고 천천히 돌리기
- 한 해에 한 번 흑연 가루로 실린더 손질
- 열쇠가 휘거나 닳았으면 원래 열쇠로 새로 복사
- 열쇠 꾸러미를 너무 무겁게 매달지 않기
무거운 꾸러미는 꽂힌 열쇠를 아래로 끌어당겨 실린더를 조금씩 상하게 합니다.
실린더가 자주 말썽이라면 열쇠 없이 쓰는 도어락을 생각해 보실 수도 있습니다. / 문 구멍과 두께를 [도어락 설치](doorlock-install.html)에서 먼저 확인해 보세요.

# 구로동 말고 구로구 다른 동네도 갑니다
신도림동, 가리봉동, 고척동, 개봉동, 오류동, 수궁동, 항동까지 구로구 어디든 24시간 출동합니다. / 디지털단지 사무실 열쇠 문제도 갑니다.
구로구 동네는 [구로구 출장열쇠](seoul-guro.html), 다른 지역은 [출장 지역](area.html)에서 보세요.
