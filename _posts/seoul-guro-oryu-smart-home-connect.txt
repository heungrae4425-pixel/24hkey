# 오류동 집, 문은 열리는데 휴대폰이 조용하다면
오류동역 생활권인 오류동은 오래된 주택과 빌라, 아파트가 골목을 사이에 두고 섞여 있는 동네입니다. / 낡은 도어락을 바꾸면서 휴대폰으로 출입 알림을 받는 제품을 단 집도 늘었습니다.
그런데 어느 날부터 아이가 하교해 문을 열어도 알림이 오지 않거나, 앱에서 문 상태가 계속 연결 끊김으로 뜨는 일이 생깁니다. / 문은 멀쩡히 열리는데 휴대폰만 모르는 상태라 더 신경이 쓰입니다.
이 글은 오류동에서 도어락 앱 연동이 말썽일 때 집에서 차례로 짚어 볼 것을 적었습니다. / 문까지 안 열리는 상황이라면 [구로 출장열쇠](seoul-guro.html)로 바로 연락 주세요.
@ 오류동 스마트 도어락 앱 알림 연동 점검

# 알림 문제와 문 고장은 따로 생각하기
앱 연동이 끊겼다고 해서 도어락이 고장 난 것은 아닙니다. / 번호, 카드, 지문으로 여닫는 기능은 대부분 휴대폰 연결과 상관없이 따로 움직입니다.
그래서 먼저 문 앞에서 번호로 한 번 열어 보세요. / 잘 열린다면 지금 고칠 것은 문이 아니라 연결 쪽입니다.
반대로 번호도 안 먹히고 앱도 안 된다면 배터리나 도어락 자체를 먼저 봐야 합니다. / 이 둘을 섞어서 생각하면 엉뚱한 곳을 오래 붙잡게 됩니다.

# 오류동 주택에서 자주 걸리는 거리 문제
단독주택이나 오래된 빌라는 벽이 두껍고, 공유기가 안방이나 거실 깊숙이 놓인 경우가 많습니다. / 현관까지 와이파이가 겨우 닿다가 날씨나 가구 배치에 따라 끊기기도 합니다.
현관 앞에 서서 휴대폰 와이파이 칸이 몇 개 뜨는지 보세요. / 한두 칸이거나 자주 끊긴다면 도어락도 같은 사정일 가능성이 큽니다.
- 공유기를 현관 쪽 방으로 옮겨 보기
- 공유기와 현관 사이 큰 수납장이나 냉장고 위치 확인
- 이층 주택이라면 공유기가 다른 층에 있지 않은지
공유기를 옮기기 어렵다면 현관 가까운 곳에 신호를 이어 주는 장치를 두는 방법도 있습니다.

# 허브를 쓰는 제품이라면 허브부터
도어락이 직접 와이파이에 붙지 않고 작은 허브를 거쳐 연결되는 제품이 있습니다. / 이 경우 허브 전원이 빠지거나 허브가 너무 멀면 알림이 끊깁니다.
허브의 불빛 색이 평소와 다른지 보세요. / 전원을 뽑았다가 잠시 뒤 다시 꽂으면 다시 붙는 경우가 많습니다.
청소하다 멀티탭을 끄거나 허브 자리를 옮긴 뒤부터 안 된다면 그 일이 원인일 가능성이 큽니다.
@ 오류동 도어락 허브 전원 와이파이 거리 확인

# 공유기를 바꾼 날을 떠올려 보세요
인터넷 업체를 바꾸거나 공유기를 새것으로 바꾸면 와이파이 이름과 비밀번호가 달라집니다. / 도어락은 예전 이름을 계속 찾고 있으니 당연히 연결이 안 됩니다.
이럴 때는 앱에서 도어락 와이파이 설정을 처음부터 다시 해야 합니다. / 많은 제품이 2.4GHz 와이파이만 잡기 때문에 공유기에서 그 이름을 골라 연결해야 합니다.
공유기 이름이 두 개 보인다면 뒤에 5G가 붙지 않은 쪽을 고르면 되는 경우가 많습니다.

# 도어락 배터리가 약해도 알림부터 끊깁니다
배터리가 줄면 도어락은 문을 여닫는 힘을 아끼려고 통신부터 줄이는 경우가 있습니다. / 문은 아직 열리는데 알림이 들쭉날쭉하다면 배터리를 먼저 바꿔 보세요.
배터리는 몇 개만이 아니라 전부 같은 날 새것으로 넣는 게 좋습니다. / 바꾼 뒤 앱에서 배터리 표시가 올라오는지 확인하면 연결이 살아났는지도 함께 알 수 있습니다.

# 휴대폰 설정이 알림을 막는 경우
도어락과 허브가 멀쩡해도 휴대폰이 알림을 숨기면 소용이 없습니다.
- 앱 알림 허용이 꺼져 있지 않은지
- 절전 모드에서 앱이 잠들도록 되어 있지 않은지
- 방해 금지 시간이 하루 종일로 맞춰져 있지 않은지
- 운영체제 업데이트 뒤 앱 권한이 초기화되지 않았는지
휴대폰을 새로 바꿨다면 앱만 깔아서는 안 되고, 계정으로 다시 로그인해 도어락을 불러와야 합니다.

# 가족 계정과 관리자 권한 정리
앱 연동 도어락은 처음 등록한 사람이 관리자가 되고, 나머지 가족은 초대받아 쓰는 방식이 많습니다. / 관리자 휴대폰을 바꾸거나 계정을 지우면 가족 모두 연결이 끊기기도 합니다.
누가 관리자였는지부터 확인하고, 그 계정으로 가족을 다시 초대하세요. / 이사 온 집이라면 전에 살던 분 계정이 관리자로 남아 있을 수 있어 초기화가 필요합니다.

# 원격 열림 기능은 조심해서 쓰기
앱으로 밖에서 문을 열 수 있는 기능은 편하지만, 연결이 불안정할 때 기대면 곤란합니다. / 손님이 문 앞에 왔는데 연결이 끊겨 열어 주지 못하는 일이 생깁니다.
원격 열림을 쓰더라도 번호나 카드 같은 다른 방법 하나는 꼭 남겨 두세요. / 연결 문제는 대개 그 순간에는 고치기 어렵기 때문입니다.
또 하나 조심할 것은 급한 마음에 하는 손질입니다. / 연결을 살리려고 도어락 몸체를 열어 선을 만지거나 초기화 버튼을 길게 누르는 분이 있습니다. / 초기화하면 가족 번호와 카드까지 모두 지워지는 제품이 많습니다.
초기화가 필요하다면 문을 연 상태에서 가족 번호를 메모해 두고 진행하세요. / 문이 닫힌 상태에서 초기화하면 밖에서 들어올 방법이 사라질 수 있습니다.

# 오류동에서 연락 주실 때
- 주택이나 빌라는 건물 이름이나 번지, 아파트는 동과 호수
- 오류동역에서 어느 방향인지
- 문이 열리는데 앱만 안 되는지, 문도 안 열리는지
- 도어락 제품 이름과 허브 유무
앱 화면에 뜨는 오류 문구를 캡처해 보내 주시면 원인을 짐작하는 데 도움이 됩니다. / 공유기와 허브가 어디에 놓여 있는지 사진 한 장을 더해 주시면 거리 문제인지도 미리 가늠할 수 있습니다.

# 거주 확인과 비용은 먼저
문을 열어야 하거나 도어락을 초기화하는 일은 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 집주인 확인 중 하나면 됩니다.
작업 내용을 보고 비용을 먼저 말씀드린 뒤 동의하실 때 진행합니다. / 문을 열어야 하는데 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 고칠지, 다른 제품으로 갈지
통신 부품이 고장이라면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 먼저 봅니다. / 집 구조상 연결이 계속 불안정하다면 허브 방식이나 다른 제품으로 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.
문이 잠겨 들어가지 못하는 상황이라면 [현관문 개문](door-open.html)부터 진행합니다.
@ 구로 오류동 스마트 도어락 수리 교체 상담
