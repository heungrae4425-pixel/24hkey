# 언덕을 다 올라왔는데 번호판이 대답이 없을 때
봉천동은 서울대입구역과 봉천역, 낙성대역에서 내려 언덕길을 한참 올라가야 닿는 집이 많은 동네입니다. / 막차를 타고 내려 지친 걸음으로 올라왔는데 현관 앞에서 번호판이 꺼져 있으면 다리에 힘이 풀립니다.
새벽에는 문을 연 열쇠 가게도 없고, 가족에게 전화하기도 미안한 시간입니다. / 그래서 출장열쇠에 전화를 거는데, 무슨 말부터 해야 할지 막막해지기 쉽습니다.
이 글은 봉천동에서 한밤이나 새벽에 문이 안 열렸을 때 통화를 짧고 정확하게 하는 요령을 정리했습니다. / 전화 한 번으로 필요한 것이 다 전해지면 도착도 그만큼 빨라집니다.
@ 봉천동 새벽 현관문 안 열림 출장열쇠 전화

# 전화 전에 30초, 숨부터 고르세요
늦은 시간에 문이 안 열리면 마음이 급해서 번호를 계속 누르게 됩니다. / 몇 번 틀리면 도어락이 한동안 입력을 막아 버리니 세 번쯤에서 멈추세요.
- 번호판을 손바닥으로 덮어 불이 들어오는지
- 누르면 어떤 소리가 나는지
- 보조키나 안쪽 걸쇠가 잠겼을 일이 있는지
이 세 가지만 보고 나서 전화하셔도 늦지 않습니다. / 이것만 알아도 통화가 훨씬 짧아집니다.

# 첫마디는 "어디, 어떤 문"부터
통화가 연결되면 인사보다 위치와 문 종류를 먼저 말씀해 주세요. / 예를 들면 이렇게 말하시면 됩니다.
"봉천동 봉천역 쪽 빌라 3층인데, 번호판이 아예 안 켜져요." / 이 한 문장에 위치, 건물 종류, 층, 증상이 다 들어 있습니다.
아파트라면 동과 호수, 원룸 건물이라면 건물 이름이나 번지를 붙여 주세요. / 언덕 위 골목은 비슷한 건물이 많아 큰길 이름이나 근처 가게 하나만 더해도 찾기 쉬워집니다.

# 두 번째로 말할 것은 지금 상황
위치를 말한 다음에는 지금 어떤 상태인지 이어서 알려 주세요. / 아래 가운데 해당되는 것만 말씀하시면 됩니다.
- 혼자 밖에 있는지, 안에 가족이 자고 있는지
- 안에 아이나 반려동물이 있는지
- 휴대폰 배터리가 얼마나 남았는지
- 지금 서 있는 곳이 춥거나 어두운지
안에 아이가 혼자 있다거나 가스레인지를 켜 둔 것 같다면 꼭 먼저 말씀해 주세요. / 그런 경우는 순서를 앞당겨 움직입니다.

# 비용과 도착 시간은 직접 물어보셔도 됩니다
새벽 전화라 비용 이야기를 꺼내기 어색해하는 분이 많습니다. / 하지만 궁금한 것은 통화에서 바로 물어보셔도 됩니다.
도착 예상 시간은 위치를 듣고 바로 말씀드립니다. / 비용은 문과 도어락 상태를 직접 본 뒤 손대기 전에 정확히 알려 드리고, 동의하실 때만 시작합니다.
끝내 문을 못 열면 비용은 받지 않습니다. / 열고 나서 말없이 붙는 비용도 없습니다.

# 기다리는 동안 어디에 계실지
언덕 위 골목은 밤이면 꽤 어둡고 춥습니다. / 문 앞에서 오래 서 계시기보다 밝고 따뜻한 곳을 정해 두세요.
- 큰길가 편의점이나 건물 1층 현관 안쪽
- 아파트라면 경비실 근처나 공동현관 안
- 어디서 기다리는지 문자로 남겨 두기
휴대폰 배터리가 얼마 없다면 편의점에서 잠시 충전하며 기다리시는 것도 방법입니다. / 연락이 끊기면 도착해서 서로 찾느라 시간이 더 걸립니다.
@ 봉천동 밤 귀가 언덕길 기다리는 곳

# 기사가 도착하면 이렇게 확인하세요
혼자 사는 분이라면 늦은 밤 처음 보는 사람을 만나는 것이 불안할 수 있습니다. / 도착 전에 기사가 전화를 드리니, 통화한 번호와 같은 번호인지 확인하세요.
불안하시면 가족이나 친구와 통화를 이어 둔 채 기다리셔도 괜찮습니다. / 기사도 그런 걱정을 잘 알고 있어 서두르지 않고 설명부터 드립니다.
작업하는 동안 문 앞에 꼭 붙어 계실 필요는 없습니다. / 계단참이나 조금 떨어진 밝은 자리에서 지켜보셔도 되고, 무엇을 하는지 궁금하면 언제든 물어보세요.
아파트라면 경비실에 출장열쇠를 불렀다고 미리 한마디 해 두시면 서로 마음이 편합니다. / 새벽에 공동현관을 드나드는 낯선 사람을 경비원께서 걱정하지 않으셔도 됩니다.
@ 봉천동 새벽 도착 기사 번호 확인

# 새벽 작업은 소리를 줄이는 쪽으로
봉천동 빌라와 원룸은 벽 하나 너머에 이웃이 잠들어 있습니다. / 새벽에는 소리가 덜 나는 방법부터 써서 이웃 잠을 깨우지 않게 신경 씁니다.
통화하실 때나 기다리실 때도 목소리를 조금 낮춰 주시면 좋습니다. / 복도에서 문을 두드리거나 큰 소리로 가족을 부르는 것은 피해 주세요.
문은 [현관문 개문](door-open.html) 방식 가운데 덜 상하는 쪽부터 씁니다.

# 문 열기 전에는 사시는 분인지 봅니다
새벽이어도 사시는 분인지 확인하는 절차는 같습니다. / 신분증 주소나 우편물로 확인하고, 신분증이 집 안에 있다면 문을 연 뒤 바로 보여 주시면 됩니다.
아파트라면 경비실 확인도 방법입니다. / 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 새벽에 하지 말아야 할 것
지치고 급한 새벽일수록 무리한 방법이 떠오릅니다. / 아래는 꼭 피해 주세요.
- 베란다나 창문을 타고 들어가기
- 드라이버나 카드로 문틈 벌리기
- 손잡이를 힘껏 비틀거나 문을 발로 차기
- 비슷해 보이는 옆집 문을 두드려 확인하기
빌라 저층이라도 창문으로 들어가다 다치는 일이 생깁니다. / 문 앞에서 기다리는 것이 가장 안전합니다.
@ 봉천동 새벽 출장열쇠 무리한 시도 피하기

# 열고 나서 그 자리에서 할 것
문이 열리면 원인을 같이 보고 다시 같은 일이 없도록 정리합니다. / 배터리 문제였다면 새것으로 모두 바꾸고, 번호를 잊었다면 새 번호를 등록해 드립니다.
도어락이 오래돼 자주 말썽이라면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 먼저 봅니다. / 새벽에 큰 작업을 하기 어렵다면 그날은 문만 열고, 낮에 다시 와서 [도어락 교체](doorlock-replace.html)를 상담할 수도 있습니다.

# 다음 새벽을 위해 해 둘 것
늦게 귀가하는 날이 잦다면 몇 가지만 준비해 두세요.
- 지갑이나 가방에 9V 건전지 하나
- 가족이나 친구에게 현관 번호를 맡기는 방법 정해 두기
- 출장열쇠 번호를 휴대폰 즐겨찾기에
- 경고음이 나면 그날 바로 배터리 교체
도어락 경고음은 밤에 들으면 귀찮아 넘기기 쉽지만, 그다음 날 새벽이 위험합니다. / 경고음을 들은 날 저녁에 바로 갈아 두는 것만으로 새벽 통화 한 번을 줄일 수 있습니다.

# 봉천동 말고 관악구 어디든
봉천동 옆 신림동 원룸 골목, 관악산 쪽 남현동 주택가도 새벽에 다닙니다. / 관악구 다니는 동네는 [관악구 출장열쇠](seoul-gwanak.html)에서, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 새벽 세 시에 전화해도 받나요? | 네, 24시간 받습니다. 시간 걱정 말고 연락 주세요.
? 통화에서 무엇부터 말해야 하나요? | 동네와 가까운 역, 건물 종류와 층, 번호판 상태 순서로 말씀해 주시면 됩니다.
? 새벽이라 비용이 따로 붙나요? | 문 상태를 본 뒤 손대기 전에 비용을 먼저 말씀드리고, 동의하실 때만 시작합니다.
? 기사님이 맞는지 어떻게 알죠? | 도착 전에 통화한 번호로 전화를 드립니다. 같은 번호인지 확인하세요.
? 휴대폰이 꺼질 것 같아요. | 기다릴 장소를 먼저 문자로 남기고, 편의점에서 충전하며 기다려 주세요.

# 마무리
봉천동에서 새벽에 문이 안 열리면 번호를 계속 누르지 말고 위치, 건물, 층, 번호판 상태를 한 문장으로 정리해 전화해 주세요. / 기다리는 동안은 밝고 따뜻한 곳에 계시면 됩니다.
24시출장열쇠는 막차가 끊긴 시간에도 봉천동 언덕 위까지 찾아갑니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
