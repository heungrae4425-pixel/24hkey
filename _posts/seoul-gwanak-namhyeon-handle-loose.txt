# 손잡이가 손 안에서 조금씩 노는 느낌
남현동은 관악산 자락 아래 단독주택과 빌라가 이어지고, 사당역과 낙성대역 쪽으로 오가는 분이 많은 동네입니다. / 지은 지 꽤 된 집이 많아 현관 손잡이도 십수 년을 같은 자리에서 버틴 경우가 흔합니다.
처음에는 잡을 때 살짝 흔들리는 정도라 그냥 넘깁니다. / 그러다 어느 날 손잡이를 돌렸는데 걸쇠가 안 빠지고 손잡이만 빙글 돌아가 버립니다.
손잡이는 매일 수십 번 잡고 돌리는 부분이라 도어락에서 가장 먼저 지칩니다. / 이 글은 남현동 집에서 흔한 손잡이 모양별로 무엇을 보면 되는지, 어디까지 직접 하고 어디서 멈춰야 하는지 적었습니다.
@ 남현동 현관 손잡이 헐거움 헛돎

# 흔들림과 헛돎은 서로 다른 신호입니다
먼저 지금 증상이 둘 가운데 어느 쪽인지 나눠 보세요.
- 흔들림: 손잡이를 돌리면 걸쇠는 빠지는데 손잡이가 덜렁거린다
- 헛돎: 손잡이가 돌아가긴 하는데 걸쇠가 꿈쩍하지 않는다
흔들림은 대개 고정 나사가 풀린 것이라 일찍 잡으면 간단히 끝납니다. / 헛돎은 손잡이와 걸쇠를 잇는 안쪽 부품이 닳거나 빠진 것이라 손이 조금 더 갑니다.
흔들림을 오래 두면 결국 헛돎으로 넘어갑니다. / 덜렁거릴 때 손보는 것이 가장 쉽고 덜 듭니다.

# 둥근 손잡이에 열쇠 구멍이 있는 집
남현동 오래된 주택에는 동그란 손잡이 가운데 열쇠 구멍이 있는 현관 손잡이가 아직 많습니다. / 이 손잡이는 안쪽 둘레나 장식판 옆에 작은 나사나 누름 홈이 있는 경우가 많습니다.
문이 열린 상태에서 안쪽 장식판 둘레를 살펴보세요. / 나사가 보인다면 그것이 풀려 흔들리는 것일 수 있습니다.
나사가 안 보이고 작은 홈만 있다면 손잡이를 빼는 구조입니다. / 이 경우는 무리하게 빼다 다시 끼우지 못하는 일이 많아 사진을 보내 주시는 편이 낫습니다.

# 레버형 손잡이는 아래로 처지는지 보세요
일자로 된 레버 손잡이는 놓았을 때 수평으로 돌아오는지가 중요합니다. / 손을 떼도 아래로 축 처져 있다면 안쪽 스프링이 약해졌거나 부러진 것입니다.
처진 레버는 걸쇠를 끝까지 돌려 놓지 못해 문이 덜 닫히거나 덜 열립니다. / 이 상태에서 손잡이를 위로 들어 올리며 쓰는 분도 있는데, 그러면 남은 부품까지 빨리 닳습니다.
레버 뿌리 쪽 둘레에 작은 고정 나사가 있다면 그것부터 확인해 보세요.
@ 남현동 레버 손잡이 처짐 스프링 확인

# 도어락 일체형 손잡이라면
번호판과 손잡이가 한 몸인 도어락은 안쪽 몸체를 고정하는 긴 나사가 문을 관통해 바깥 몸체를 잡고 있습니다. / 이 나사가 풀리면 바깥 손잡이째 흔들립니다.
안쪽 몸체 아래쪽이나 배터리 칸 근처에 나사가 보이는 제품이 많습니다. / 배터리 칸을 열어야 보이는 제품도 있으니 덮개를 먼저 열어 보세요.
일체형은 손잡이 축이 모터와 연결돼 있어 헛돌 때 원인이 여러 갈래입니다. / 번호는 맞는데 손잡이만 헛돈다면 직접 분해하지 말고 연락 주세요.

# 직접 조여도 되는 경우
문이 열린 상태이고, 나사가 눈에 보이고, 걸쇠는 정상으로 빠진다면 조여 보셔도 됩니다. / 아래 순서로 하시면 됩니다.
- 나사 머리 모양에 꼭 맞는 드라이버 고르기
- 안쪽 손잡이를 반듯하게 잡은 채로 조이기
- 끝까지 꽉 조인 뒤 반 바퀴만 더 돌리고 멈추기
- 조인 뒤 손잡이를 여러 번 돌려 걸쇠가 잘 빠지는지 확인
너무 세게 조이면 손잡이가 뻑뻑해지거나 나사산이 뭉개집니다. / 한쪽만 꽉 조이지 말고 나사가 두 개라면 번갈아 조금씩 조이세요.

# 직접 하지 말아야 할 경우
아래 상황이라면 드라이버를 내려놓으세요.
- 문이 닫힌 상태에서 손잡이가 헛돌아 안 열린다
- 나사를 조여도 바로 다시 풀린다
- 손잡이 안에서 쇳조각 굴러다니는 소리가 난다
- 풀다 보니 부품이 여러 개 쏟아졌다
문이 닫힌 채 헛도는 상황에서 손잡이를 계속 돌리면 남은 연결 부품까지 갈려 나갑니다. / 이때는 안에서도 밖에서도 열기 어려워질 수 있으니 바로 연락 주세요.

# 안쪽과 바깥쪽 가운데 어디가 문제인지
안에서는 잘 열리는데 밖에서만 헛돈다면 바깥 손잡이 쪽 연결이 문제입니다. / 반대라면 안쪽 손잡이나 안쪽 축이 닳은 것입니다.
양쪽 다 헛돈다면 가운데 걸쇠 뭉치가 망가진 것일 수 있습니다. / 이 차이를 말씀해 주시면 어떤 부품을 챙겨 갈지 미리 정할 수 있습니다.

# 집 안에서 갇힐 수도 있습니다
바깥 손잡이만 생각하기 쉽지만, 안쪽 손잡이가 헛돌면 집 안에서 나가지 못하는 일이 생깁니다. / 혼자 사시는 어르신 댁이라면 특히 조심해야 합니다.
안쪽 손잡이가 덜렁거리기 시작했다면 미루지 말고 손보세요. / 그사이에는 문을 완전히 닫기 전에 손잡이가 잘 도는지 한 번씩 확인하는 습관이 도움이 됩니다.
@ 남현동 주택 안쪽 손잡이 헛돎 갇힘 주의

# 손잡이를 오래 쓰는 작은 습관
손잡이가 빨리 지치는 집에는 대개 공통된 습관이 있습니다. / 무거운 장바구니를 손잡이에 걸어 두거나, 문을 손잡이로 끌어당겨 쾅 닫는 경우입니다.
문을 닫을 때는 손잡이 대신 문짝을 가볍게 밀어 주세요. / 아이들이 손잡이에 매달려 노는 집이라면 그것만 줄여도 수명이 꽤 늘어납니다.
계절이 바뀔 때 한 번씩 손잡이를 잡고 위아래로 흔들어 보세요. / 처음 느끼는 작은 흔들림을 그때 잡으면 나사 하나로 끝납니다.
@ 남현동 현관 손잡이 계절 점검 습관

# 연락 주실 때 알려 주시면 좋은 것
남현동 골목은 길이 꺾이고 비슷한 주택이 이어져 있어 위치를 자세히 알려 주시면 빨리 찾아갑니다. / 사당역과 낙성대역 가운데 어디가 가까운지, 근처 큰길이나 눈에 띄는 건물을 말씀해 주세요.
- 손잡이 모양(둥근형, 레버형, 도어락 일체형)
- 흔들리는지, 헛도는지, 어느 쪽 손잡이인지
- 지금 문이 열려 있는지, 닫혀 있는지
손잡이 안쪽과 바깥쪽 사진을 한 장씩 보내 주시면 맞는 부품을 챙겨 갑니다.

# 확인과 비용 안내 후 손봅니다
문이 닫혀 열어야 하는 상황이라면 사시는 분인지 먼저 신분증이나 우편물로 확인합니다. / 문이 열려 있고 손잡이만 손보는 경우에도 집주인이나 사시는 분과 이야기한 뒤 시작합니다.
나사 조임으로 끝날지, 부품을 바꿔야 할지 보고 비용을 손대기 전에 말씀드립니다. / 동의하실 때만 진행하고, 끝내 못 열면 비용은 받지 않으며 흐름은 [이용안내](guide.html)에 정리해 두었습니다.
닫힌 문을 여는 방식은 [현관문 개문](door-open.html)에 있습니다. / 고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 끝내고, 손잡이와 몸체가 함께 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 남현동 말고 관악구 다른 동네도
남현동 아래 봉천동 아파트와 빌라, 신림동 원룸 손잡이도 같은 방식으로 봐 드립니다. / 관악구 다니는 동네는 [관악구 출장열쇠](seoul-gwanak.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

? 나사를 조였는데 일주일 만에 또 풀렸어요. | 나사산이나 안쪽 받침이 닳았을 수 있습니다. 부품 점검을 받아 보세요.
? 레버가 아래로 처져 안 올라와요. | 안쪽 스프링이 약해진 경우가 많습니다. 들어 올리며 쓰지 말고 점검을 받아 보세요.
? 문이 닫힌 채로 손잡이가 헛돌아요. | 더 돌리지 말고 바로 연락 주세요. 거주 확인 후 열고 부품까지 손봐 드립니다.
? 손잡이만 바꿀 수도 있나요? | 네, 문 구멍과 맞는 크기라면 손잡이만 바꿉니다. 비용은 먼저 말씀드립니다.

# 마무리
남현동에서 현관 손잡이가 덜렁이기 시작했다면 흔들림인지 헛돎인지 먼저 가르고, 문이 열려 있을 때 보이는 나사부터 조여 보세요. / 닫힌 채 헛돈다면 더 돌리지 말고 연락 주시면 됩니다.
24시출장열쇠는 관악산 아래 오래된 집 손잡이까지 찾아가 손봐 드립니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
