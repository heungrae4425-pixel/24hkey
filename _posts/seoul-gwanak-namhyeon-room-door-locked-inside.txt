# 아무도 없는 방인데 문이 잠겨 있을 때
남현동은 관악산 자락 아래 단독주택과 빌라가 이어지고, 사당역과 낙성대역 쪽으로 오가는 분이 많은 동네입니다. / 오래 사신 집이 많아 방문 손잡이도 처음 집을 지을 때 달았던 그대로인 경우가 흔합니다.
청소하다 바람에 방문이 닫혔는데 안쪽 잠금 버튼이 눌려 있었다면 방이 통째로 잠깁니다. / 아이가 장난으로 화장실 문을 잠그고 나온 경우도 있습니다.
현관문과 달리 방문은 대부분 바깥에서 풀 수 있는 장치가 있습니다. / 이 글은 손잡이 모양별로 무엇을 확인하면 되는지, 안에 사람이 있을 때는 어떻게 해야 하는지 정리했습니다.
@ 남현동 방문 화장실 문 안에서 잠김

# 사람이 안에 있는지부터 확인하세요
가장 먼저 할 일은 문 너머에 누가 있는지 확인하는 것입니다. / 아이나 어르신이 안에 있다면 대처 순서가 달라집니다.
- 아무도 없다: 아래 손잡이 확인부터 차분히
- 아이가 안에 있다: 말을 걸며 안심시키고, 안에서 버튼을 다시 눌러 보게 하기
- 어르신이 안에 계신데 대답이 없다: 문 열기보다 119에 먼저 연락
특히 화장실 안에서 대답이 없거나 넘어지는 소리가 났다면 기다리지 마세요. / 이럴 때는 열쇠집보다 119가 먼저입니다.

# 바깥 손잡이 가운데를 들여다보세요
방문 손잡이 바깥쪽 가운데나 아래에는 작은 구멍이나 홈이 있는 경우가 많습니다. / 이것이 비상시에 바깥에서 잠금을 푸는 자리입니다.
- 작고 동그란 구멍: 가는 핀이나 펴진 클립을 곧게 밀어 넣는 방식
- 일자 홈: 동전이나 일자 드라이버 끝을 넣고 돌리는 방식
- 아무 구멍도 없음: 바깥에서 풀 장치가 없는 손잡이
구멍이 있다면 손잡이를 살짝 돌리는 방향으로 힘을 주면서 핀을 밀거나 홈을 돌려 보세요. / 딸깍하는 느낌이 나면 풀린 것입니다.
@ 남현동 방문 손잡이 바깥 비상 구멍

# 동그란 구멍은 곧게, 끝까지
핀을 넣는 방식은 구멍 안쪽 깊은 곳에 있는 버튼을 눌러야 풀립니다. / 비스듬히 넣으면 옆벽만 긁고 버튼에 닿지 않습니다.
펴진 옷핀이나 클립을 일자로 곧게 편 뒤 구멍 방향 그대로 천천히 밀어 넣어 보세요. / 걸리는 느낌이 나면 조금 더 꾹 누르면서 손잡이를 돌립니다.
이쑤시개처럼 부러지기 쉬운 것은 넣지 마세요. / 안에서 부러지면 구멍이 막혀 버립니다.

# 일자 홈은 동전 하나면 됩니다
화장실 손잡이 가운데 바깥쪽에 일자 홈이 보이는 것은 동전으로 돌리게 만든 것입니다. / 동전을 홈에 맞게 세워 넣고 시계 방향이나 반대 방향으로 천천히 돌려 보세요.
한쪽으로 안 돌면 반대로 돌려 보시면 됩니다. / 너무 세게 돌리면 홈이 뭉개지니 손목 힘만 쓰세요.
동전이 홈보다 두꺼워 안 들어간다면 더 얇은 동전이나 버터나이프 끝처럼 납작한 것을 써 봅니다. / 날카로운 칼끝은 손을 다치기 쉬우니 피하세요.
홈이 이미 닳아 동그랗게 뭉개져 있다면 오래 써서 그런 것이니 열린 뒤 손잡이를 바꿔 두는 편이 좋습니다.
@ 남현동 화장실 손잡이 일자 홈 동전으로 풀기

# 오래된 주택 방문은 열쇠 구멍이 있기도
남현동 오래된 집 가운데는 방문 손잡이에 작은 열쇠 구멍이 있는 경우가 있습니다. / 처음 이사 왔을 때 받은 작은 열쇠 꾸러미 안에 방문 열쇠가 들어 있었을 수 있습니다.
서랍이나 신발장 위 열쇠 바구니를 한번 뒤져 보세요. / 같은 모양 손잡이가 여러 방에 달려 있다면 열쇠 하나로 모두 열리는 경우도 있습니다. / 열쇠를 찾았다면 꽂은 뒤 억지로 돌리지 말고 살살 좌우로 움직여 맞는 방향을 찾으세요.

# 이렇게 열려고 하면 문이 상합니다
급하다고 아래 방법을 쓰면 방문 자체를 바꿔야 할 수 있습니다.
- 어깨로 밀거나 발로 차기
- 문틈에 칼이나 드라이버를 넣어 비틀기
- 경첩 핀을 빼서 문짝을 떼어 내기
- 손잡이를 망치로 내리치기
방문은 현관문보다 얇고 가벼워 문틀이 쉽게 쪼개집니다. / 경첩을 떼는 방법도 다시 다는 과정에서 문이 처지는 일이 많습니다.

# 화장실 창문으로 들어가는 건 위험합니다
주택 화장실은 바깥으로 작은 창이 난 집이 있어 그쪽으로 들어가려는 분도 계십니다. / 높이가 있고 발 디딜 곳이 미끄러워 다치기 쉬우니 하지 마세요.
아이를 창문으로 들여보내는 것도 피해야 합니다. / 문 앞에서 기다리는 쪽이 훨씬 안전합니다.

# 아이가 안에 있을 때 말 거는 법
아이가 안에서 잠근 경우에는 겁먹지 않게 목소리를 낮춰 계속 말을 걸어 주세요. / "손잡이 가운데 동그란 거 다시 눌러 볼래?"처럼 할 일을 하나씩만 알려 줍니다.
아이가 못 하겠다고 하면 억지로 시키지 말고 바깥에서 풀 방법을 찾으면 됩니다. / 연락 주실 때 아이가 안에 있다는 것을 먼저 말씀해 주시면 서둘러 갑니다.
@ 남현동 화장실 안 아이 안심시키며 문 열기

# 그래도 안 풀리면 연락 주세요
구멍도 홈도 없는 손잡이이거나, 해 봤는데 끝내 안 풀린다면 그때 불러 주세요. / 손잡이 바깥쪽 사진을 한 장 보내 주시면 맞는 공구를 챙겨 갑니다.
위치는 남현동 어느 길 쪽인지, 사당역과 낙성대역 중 어디가 가까운지 말씀해 주시면 됩니다. / 몇 층, 어느 방 문인지도 함께 알려 주세요.

# 집 안 문이라도 비용은 먼저 말씀드립니다
방문이나 화장실 문은 현관보다 간단히 풀리는 경우가 많습니다. / 그래도 손대기 전에 비용을 먼저 말씀드리고, 괜찮다고 하실 때 시작합니다.
현관이 열려 있어 집 안 문만 문제라면 사시는 분 확인도 간단히 끝납니다. / 끝내 못 열면 비용은 받지 않으며 진행 순서는 [이용안내](guide.html)에 있습니다.
손잡이가 낡아 자꾸 잠기거나 헛돈다면 이참에 [도어락 수리](doorlock-repair.html)와 함께 손잡이를 바꿔 드릴 수도 있습니다. / 현관이 잠긴 경우라면 [현관문 개문](door-open.html)부터 진행합니다.

# 다시 갇히지 않게 해 두는 것
한 번 잠긴 문은 같은 일이 또 생기기 쉽습니다. / 아래만 해 두셔도 다음엔 혼자 풀 수 있습니다.
- 펴진 클립이나 동전을 화장실 문 옆 높은 선반에 하나 두기
- 아이 방과 화장실은 바깥에서 풀 수 있는 손잡이로 바꾸기
- 방문 열쇠는 현관 열쇠 꾸러미와 따로 이름 붙여 보관
- 어르신 혼자 쓰는 화장실은 잠금을 쓰지 않도록 이야기 나누기
현관 잠금장치까지 함께 바꾸고 싶다면 [도어락 교체](doorlock-replace.html)도 상담해 드립니다.

# 남현동 말고 관악구 다른 동네도
남현동 아래 봉천동 아파트와 빌라, 신림동 원룸의 방문과 화장실 문도 같은 방식으로 봐 드립니다. / 관악구 다니는 동네는 [관악구 출장열쇠](seoul-gwanak.html)에 정리해 두었고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 마무리
남현동에서 방문이나 화장실 문이 안에서 잠겼다면 먼저 안에 누가 있는지 확인하고, 바깥 손잡이 가운데 구멍이나 홈을 찾아보세요. / 핀이나 동전으로 안 풀리면 문을 밀지 말고 연락 주시면 됩니다.
24시출장열쇠는 관악산 아래 골목 집 안 문까지 찾아가 풀어 드립니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
