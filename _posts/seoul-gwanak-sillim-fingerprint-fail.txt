# 손가락을 대도 빨간 불만 깜빡일 때
신림동은 신림역 주변으로 원룸 건물과 다세대 주택이 빽빽한 동네라 혼자 사는 분이 많습니다. / 요즘은 원룸에도 지문 도어락이 달린 건물이 적지 않습니다.
처음엔 손만 대면 열리던 문이 어느 날부터 두세 번, 다섯 번을 대야 겨우 열립니다. / 결국 번호를 눌러 들어가면서 "지문이 망가졌나" 싶어집니다.
지문 인식이 잘 안 되는 이유는 대부분 손, 센서, 등록 상태 가운데 하나입니다. / 이 글은 신림동 원룸에서 혼자 확인해 볼 순서와, 혼자 사는 집이라 더 챙겨야 할 백업 방법을 적었습니다.
@ 신림동 원룸 지문 도어락 인식 실패

# 오늘 내 손 상태부터 보세요
지문 인식이 갑자기 나빠졌다면 센서보다 손을 먼저 의심해 보세요. / 같은 손가락이라도 그날 상태에 따라 인식률이 크게 달라집니다.
- 겨울이라 손끝이 트고 갈라졌는지
- 손을 막 씻어 물기가 남았는지
- 핸드크림을 바르고 바로 댔는지
- 설거지나 주방 일을 오래 해서 손끝이 불었는지
- 종이 상자를 많이 만져 손끝이 거칠어졌는지
신림동에는 카페나 식당, 편의점에서 일하고 늦게 들어오는 분도 많습니다. / 물일이나 상자 정리를 오래 한 날 지문이 안 먹는 것은 흔한 일입니다.

# 손끝을 정리하고 다시 대 보기
손이 젖었다면 옷이나 휴지로 손끝을 꼼꼼히 말립니다. / 반대로 손이 너무 건조하다면 손끝을 입김으로 살짝 데우거나 손을 비벼 체온을 올려 보세요.
핸드크림을 막 발랐다면 손끝만 닦아 냅니다. / 기름기가 센서에 묻으면 다음 사람이 대도 인식이 떨어집니다.
손가락은 센서 한가운데에 평평하게, 1초쯤 가만히 대세요. / 손끝 끝부분만 콕 찍듯이 대면 등록할 때와 닿는 면이 달라 실패하기 쉽습니다.

# 센서 표면을 닦아 주세요
센서 위에 먼지, 기름 자국, 손때가 쌓이면 손가락을 제대로 읽지 못합니다. / 마른 안경닦이나 부드러운 천으로 가볍게 닦아 주세요.
- 물티슈나 알코올 솜으로 문지르지 않기
- 손톱이나 뾰족한 것으로 긁지 않기
- 세제를 뿌리지 않기
센서 표면에 흠집이 깊게 났다면 닦아도 나아지지 않습니다. / 그 경우는 센서 부품 점검이 필요합니다.
@ 신림동 지문 도어락 센서 표면 닦기

# 겨울과 장마에 더 나빠지는 이유
날이 추우면 손끝이 차고 말라서 지문 골이 얕게 읽힙니다. / 반대로 장마철에는 손에 습기가 남아 번지듯 읽히기도 합니다.
신림동 원룸은 현관이 복도나 계단과 바로 맞닿은 건물이 많아 겨울 복도가 꽤 찹니다. / 바깥에서 오래 걷다 들어온 날이라면 장갑을 벗고 손을 잠시 녹인 뒤 대 보세요.
계절마다 같은 시기에만 안 된다면 고장보다 계절 탓일 가능성이 큽니다.

# 등록을 다시 하면 나아지는 경우
처음 등록할 때 급하게 했다면 손가락 한쪽 면만 등록돼 있을 수 있습니다. / 이럴 때는 기존 지문을 지우고 다시 등록하는 것만으로 확 좋아집니다.
다시 등록할 때는 아래를 지켜 주세요.
- 손을 씻고 완전히 말린 뒤 등록하기
- 손가락을 대는 각도를 조금씩 바꿔 가며 여러 번 대기
- 자주 쓰는 손가락 두 개 이상 등록하기
- 양손에서 하나씩 등록해 두기
짐을 들고 들어오는 날이 많다면 짐을 안 드는 손 손가락도 꼭 넣어 두세요. / 등록 방법은 도어락마다 달라 안쪽 몸체의 설명 스티커나 제품 이름을 확인해 보세요.

# 이전 세입자 지문이 남아 있지 않나요
원룸은 세입자가 자주 바뀌어 이전 사람 지문이 지워지지 않은 채 남아 있는 경우가 있습니다. / 등록 칸이 꽉 차면 새 지문이 제대로 들어가지 않기도 합니다.
입주하면서 등록을 한 번도 정리하지 않았다면 전체 삭제 후 다시 등록하는 것을 권합니다. / 집주인이 단 도어락이라면 정리하기 전에 한 번 알려 두시면 서로 편합니다.
@ 신림동 원룸 지문 등록 정리 전체 삭제

# 혼자 사는 집일수록 백업이 중요합니다
지문만 믿고 번호를 잊어버리면 지문이 안 되는 날 문 앞에서 막힙니다. / 혼자 사는 원룸은 안에서 열어 줄 사람이 없어 더 그렇습니다.
- 백업 번호를 한 달에 한 번은 직접 눌러 보기
- 번호는 휴대폰 메모 말고 다른 곳에도 적어 두기
- 카드키가 되는 도어락이라면 지갑에 카드 한 장
- 9V 비상 단자 위치 확인해 두기
번호를 한동안 안 쓰면 손이 기억하지 못합니다. / 일부러 일주일에 한두 번은 번호로 열어 보는 습관이 도움이 됩니다.

# 배터리가 약해도 지문부터 흔들립니다
지문 센서는 번호판보다 전기를 조금 더 씁니다. / 그래서 배터리가 약해지기 시작하면 번호는 눌리는데 지문만 자꾸 실패하는 일이 생깁니다.
경고음이 나지 않았더라도 마지막으로 배터리를 바꾼 지 오래됐다면 한꺼번에 새것으로 갈아 보세요. / 새 배터리로 바꾼 뒤 바로 나아진다면 원인은 센서가 아니라 전원이었던 것입니다.
배터리를 갈 때는 같은 종류 새것으로 모두 바꾸고, 헌것과 섞지 마세요. / 배터리 칸 뚜껑 안쪽에 바꾼 달을 적어 두면 다음 교체 때를 잊지 않습니다.
@ 신림동 지문 도어락 배터리 교체 후 인식 확인

# 이런 증상은 고장 쪽입니다
손과 센서를 다 정리했는데도 아래 증상이 있다면 부품 문제를 의심합니다.
- 손가락을 대도 아무 불빛이나 소리가 없다
- 등록 단계에서 계속 실패한다
- 지문은 인식했다는 소리가 나는데 문이 안 열린다
- 번호로도 열리지 않는다
인식 소리는 나는데 안 열린다면 지문이 아니라 모터나 걸쇠 쪽 문제입니다. / 이때는 [도어락 수리](doorlock-repair.html)로 점검받아 보세요.

# 문 앞에서 끝내 안 열린다면
지문도 번호도 안 되면 번호를 계속 눌러 잠금을 걸지 말고 연락 주세요. / 도어락 앞면 사진과 함께 신림역 쪽 위치, 건물 이름이나 번지, 층과 호수를 알려 주시면 됩니다.
도착하면 사시는 분인지 신분증이나 우편물, 계약서로 확인합니다. / 이후 문과 도어락 상태를 본 뒤 비용을 손대기 전에 말씀드리고, 동의하실 때 시작합니다.
끝내 못 열면 비용은 받지 않습니다. / 문은 [현관문 개문](door-open.html) 방식 가운데 덜 상하는 쪽부터 쓰며, 자세한 흐름은 [이용안내](guide.html)에 있습니다.

# 지문 도어락을 새로 고르신다면
센서가 낡았거나 등록이 자꾸 실패해 바꾸기로 했다면, 지문과 번호, 카드를 함께 쓸 수 있는 제품이 혼자 사는 집에 편합니다. / 원룸이라면 교체 전에 집주인과 먼저 이야기해 두세요.
설치와 상담은 [도어락 교체](doorlock-replace.html)에서 안내해 드립니다.

# 신림동 말고 관악구 어디든
신림동과 맞닿은 봉천동 아파트와 빌라, 남현동 주택가의 지문 도어락도 같은 방식으로 봐 드립니다. / 관악구 다니는 동네는 [관악구 출장열쇠](seoul-gwanak.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

# 자주 묻는 질문
? 손을 씻고 나면 지문이 안 먹어요. | 손끝 물기를 완전히 말린 뒤 대 보세요. 젖은 손은 인식이 크게 떨어집니다.
? 겨울에만 인식이 잘 안 돼요. | 손끝이 차고 건조해서 그럴 수 있습니다. 손을 녹이고 대 보시고, 겨울 전에 다시 등록해 두면 좋습니다.
? 이전 세입자 지문을 지울 수 있나요? | 네, 전체 삭제 후 다시 등록하면 정리됩니다. 방법을 모르시면 제품 사진을 보내 주세요.
? 지문 센서만 따로 고칠 수 있나요? | 제품에 따라 다릅니다. 상태를 보고 수리와 교체 가운데 무엇이 나은지 먼저 말씀드립니다.
? 백업 번호도 기억이 안 나요. | 여러 번 누르지 말고 연락 주세요. 거주 확인 후 열고 새 번호 등록까지 도와드립니다.

# 마무리
신림동 원룸 지문 도어락이 말을 안 들으면 손끝 상태와 센서 표면부터 정리하고, 그래도 안 되면 지문을 다시 등록해 보세요. / 혼자 사는 집이라면 백업 번호를 손에 익혀 두는 것이 가장 든든한 대비입니다.
24시출장열쇠는 신림역 골목 원룸까지 찾아가 지문 도어락을 봐 드립니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
