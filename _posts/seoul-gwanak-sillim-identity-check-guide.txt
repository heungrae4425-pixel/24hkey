# 신림동 원룸 앞에서 "여기 사시는 거 맞으시죠?"
신림동은 신림역을 중심으로 원룸 건물과 다세대 주택이 골목마다 빽빽한 동네입니다. / 혼자 사는 분이 많고, 계약 기간이 짧아 이사가 잦은 건물도 흔합니다.
그래서 문을 열러 가면 꼭 한 가지를 먼저 여쭙니다. / 이 방에 사시는 분이 맞는지입니다.
급한 상황에 질문부터 받으면 서운하실 수 있습니다. / 이 글은 신림동 원룸과 다세대에서 거주 확인이 어떤 순서로 이루어지는지, 무엇을 보여 주시면 되는지 미리 정리한 것입니다.
@ 신림동 원룸 출장열쇠 문 열기 전 거주 확인

# 비슷한 문이 줄지어 있는 건물이라서
신림동 원룸 건물은 한 층에 같은 모양 현관문이 여러 개 나란히 있습니다. / 밖에서 보면 어느 문이 누구 방인지 구별할 방법이 없습니다.
만약 확인 없이 문을 열어 준다면 남의 방 문도 똑같이 열릴 수 있습니다. / 거주 확인은 지금 연락 주신 분뿐 아니라 옆방, 아랫집 이웃의 방을 지키는 절차이기도 합니다.
24시출장열쇠가 어떤 시간에 불려 가도 이 순서를 건너뛰지 않는 이유입니다.

# 확인에 쓰는 것은 세 갈래입니다
아래 가운데 하나만 맞으면 대부분 진행할 수 있습니다.
- 지금 사는 주소가 적힌 신분증
- 이 주소로 온 우편물, 고지서, 택배 송장
- 건물 관리인이나 집주인의 확인
신분증 주소가 이 방과 같으면 가장 빠르게 끝납니다. / 나머지 두 가지는 신분증 주소가 다르거나 신분증이 손에 없을 때 쓰는 길입니다.

# 전입신고 전이라 주소가 예전 집일 때
신림동은 학기나 계약 시작에 맞춰 막 이사 온 분이 많아 신분증 주소가 아직 예전 집인 경우가 흔합니다. / 이때는 휴대폰에 저장해 둔 임대차 계약서 사진이 큰 도움이 됩니다.
계약서에 적힌 주소와 호수, 계약자 이름이 신분증 이름과 맞으면 확인할 수 있습니다. / 계약서 사진이 없다면 부동산이나 집주인에게 문자로 받아 두셔도 됩니다.
관리비나 공과금을 앱으로 내고 계시다면 그 화면에 나온 주소도 참고가 됩니다. / 다만 한 가지만으로 애매하면 다른 것을 하나 더 여쭐 수 있습니다.

# 신분증이 잠긴 방 안에 있다면
택배를 가지러 1층에 내려갔다가 문이 잠기면 지갑도 휴대폰도 방 안에 있기 마련입니다. / 이럴 때는 이름과 생년월일을 먼저 여쭙고 문을 엽니다.
문이 열리면 들어가서 신분증이나 우편물을 바로 보여 주시면 됩니다. / 보여 주실 때까지 기사는 문 앞에서 기다리고, 확인이 끝난 뒤에 작업을 마무리합니다.
방 안에서 확인할 것이 하나도 나오지 않으면 건물 관리인이나 집주인에게 연락을 부탁드릴 수 있습니다.
@ 신림동 원룸 현관 신분증 우편물 확인

# 친구나 애인이 대신 불러 주는 경우
휴대폰이 없어서 친구 전화로 연락하시는 경우도 많습니다. / 연락은 누가 하셔도 괜찮지만, 문 앞에서 확인을 받는 분은 그 방에 사는 본인이어야 합니다.
사는 분이 지방에 가 있고 친구가 짐을 가지러 왔다면 이야기가 다릅니다. / 사는 분이 직접 통화해 주시고, 건물 관리인이나 집주인 확인까지 받을 수 있어야 진행합니다.
번거로워도 이 경우는 쉽게 넘기지 않습니다. / 비어 있는 방 문을 여는 일이라 더 조심합니다.

# 집주인이 같은 건물에 사신다면
신림동 다세대 가운데는 집주인이 꼭대기 층이나 1층에 함께 사는 건물이 있습니다. / 이런 건물이라면 집주인께서 "이 방 세입자 맞다"고 한마디만 해 주셔도 확인이 쉽습니다.
늦은 밤에 집주인을 깨우기 어렵다면 다른 방법을 먼저 써 보고, 정 안 되면 그때 부탁드립니다. / 관리업체가 따로 있는 건물은 대표 번호로 연락해 보시는 것도 방법입니다.
집주인 연락처를 휴대폰에만 저장해 두었다면 방 안에 있는 휴대폰 때문에 연락이 끊깁니다. / 지갑 속 작은 메모나 가족 휴대폰에도 집주인 번호를 하나 적어 두시면 이런 날 요긴합니다.
계약을 새로 하실 때 관리인 번호가 건물 입구나 우편함 근처에 붙어 있는지도 한 번 봐 두세요. / 붙어 있다면 사진을 찍어 두는 것만으로 다음에 큰 수고를 덜 수 있습니다.
@ 신림동 다세대 건물 관리인 연락처 확인

# 공동 출입문부터 막혔을 때
1층 공동 출입문 번호를 몰라 건물에 못 들어가는 상황도 있습니다. / 이때는 건물 출입 권한이 있는지부터 확인하고, 이웃이나 관리인의 도움을 먼저 권합니다.
공동 출입문은 여러 세대가 같이 쓰는 문이라 한 분 말씀만으로 손대기 어렵습니다. / 관리인 확인이 되면 그다음 방 현관까지 이어서 봐 드립니다.

# 전화하실 때 미리 말씀해 주시면 빨라요
통화할 때 아래를 알려 주시면 도착해서 확인이 짧아집니다.
- 건물 이름이나 번지, 몇 층 몇 호인지
- 신분증 주소가 이 방과 같은지, 계약서 사진이 있는지
- 신분증이 지금 손에 있는지, 방 안에 있는지
- 함께 사는 사람이나 집주인 연락이 되는지
신림역에서 몇 번 출구 쪽인지, 근처에 보이는 큰길이 무엇인지도 말씀해 주세요. / 비슷한 건물이 많은 골목이라 찾아가는 시간이 줄어듭니다.

# 확인이 끝나면 비용을 먼저 말씀드립니다
거주 확인이 되면 문과 도어락 상태를 보고 비용을 손대기 전에 알려 드립니다. / 괜찮다고 하시면 시작하고, 생각해 보시겠다면 그냥 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에도 정리해 두었습니다.

# 확인이 끝나지 않으면 문을 열지 않습니다
어떤 방법으로도 사시는 분이라는 것을 확인할 수 없으면 작업을 하지 않습니다. / 시간이 늦었어도, 사정이 딱해 보여도 이 원칙은 같습니다.
이럴 때는 관리인이나 집주인과 연락이 닿을 때까지 기다렸다가 다시 부르시는 편이 낫습니다. / 기다리는 동안 따뜻한 곳에 계시도록 근처 편의점이나 카페 위치를 함께 찾아 드리기도 합니다.

# 문을 연 다음에 하는 일
문은 [현관문 개문](door-open.html) 방식 가운데 덜 상하는 쪽부터 씁니다. / 열고 나면 도어락이 다시 잘 잠기는지 같이 확인합니다.
번호를 잊어서 연 경우라면 새 번호 등록까지 도와드립니다. / 도어락이 오래돼 자주 말썽이라면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 권해 드리되, 원룸이라면 집주인과 먼저 상의하시도록 말씀드립니다.
@ 신림동 원룸 문 연 뒤 도어락 작동 확인

# 신림동 말고 관악구 다른 동네도
신림동과 맞닿은 봉천동 아파트와 빌라, 관악산 아래 남현동 주택가도 같은 확인 절차로 다닙니다. / 관악구 다니는 동네는 [관악구 출장열쇠](seoul-gwanak.html)에 정리해 두었습니다.
다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
