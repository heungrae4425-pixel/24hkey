# 군자역 골목, 오래 쓴 현관문이 보내는 신호
군자동은 군자역을 중심으로 다세대와 빌라, 오래된 단독주택이 골목을 따라 이어진 동네입니다. / 지은 지 꽤 된 건물이 많아 현관문과 문틀도 그만큼 세월을 겪었습니다.
오래된 문은 어느 날 갑자기 안 열리는 게 아니라 조금씩 신호를 보냅니다. / 문을 닫을 때 끝에서 툭 걸리거나, 번호를 누르고 손잡이를 내릴 때 예전보다 힘이 더 들어가는 식입니다.
그러다 비가 많이 온 날이나 추운 아침에 걸쇠가 문틀에 꽉 물려 끝내 안 열리게 됩니다. / 이 글은 군자동 오래된 현관문이 문틀이나 경첩 때문에 안 열릴 때 무엇을 보고, 어떻게 손보는지 정리했습니다.
@ 군자동 오래된 다세대 현관문 문틀 처짐

# 도어락 고장인지 문 문제인지 가르는 법
문이 안 열리면 대부분 도어락부터 의심합니다. / 하지만 오래된 집에서는 도어락은 멀쩡한데 문과 문틀이 어긋나 생기는 경우가 꽤 많습니다.
문이 열려 있을 때 번호를 누르거나 손잡이를 돌려 보세요. / 걸쇠가 부드럽게 들어갔다 나온다면 도어락은 정상이고, 닫혔을 때만 문제가 생기는 겁니다.
반대로 문을 열어 둔 상태에서도 걸쇠가 덜 움직이거나 모터 소리가 힘겹다면 도어락 쪽을 먼저 봐야 합니다. / 이 구분 하나로 손볼 곳이 확 달라집니다.

# 문짝이 내려앉았을 때 나타나는 모습
문을 오래 쓰면 무게 때문에 손잡이 쪽 문짝이 조금씩 아래로 처집니다. / 문을 닫고 위쪽 틈과 아래쪽 틈을 비교해 보세요.
- 위쪽 틈은 넓은데 아래쪽은 바닥에 닿을 듯할 때
- 손잡이 쪽 문 모서리가 문틀에 쓸린 자국이 있을 때
- 닫을 때 끝에서 한 번 들어 올려야 맞물릴 때
이런 모습이 보이면 걸쇠 높이와 문틀 구멍 높이가 어긋나 있을 가능성이 큽니다. / 걸쇠가 구멍 위나 아래 모서리에 걸린 채로 눌려 있어 안 빠지는 겁니다.

# 경첩 나사가 헐거워진 경우
문짝이 처지는 가장 흔한 원인은 경첩을 고정한 나사가 헐거워진 것입니다. / 특히 위쪽 경첩 나사가 풀리면 문 전체가 손잡이 쪽으로 기울어집니다.
문을 연 상태에서 손잡이를 잡고 위아래로 살짝 흔들어 보세요. / 경첩 쪽에서 덜컥거리는 느낌이 있다면 나사가 풀렸거나 나사 구멍이 헐거워진 상태입니다.
나사를 조여서 잡히면 다행이지만, 구멍이 넓어져 헛도는 경우도 있습니다. / 이럴 때는 더 긴 나사로 바꾸거나 구멍을 보강하는 작업이 필요합니다.

# 계절 따라 심해지는 이유
오래된 문은 계절에 따라 증상이 오락가락하기도 합니다. / 장마철에는 습기 때문에 문틀과 마감재가 살짝 부풀고, 겨울에는 안팎 온도 차로 철문이 미세하게 휘기도 합니다.
여름에만 뻑뻑하고 가을이면 괜찮아지는 문이라면 맞물림 여유가 거의 없는 상태입니다. / 다음 계절에 더 심해지기 전에 한 번 손봐 두시는 게 좋습니다.
겨울 아침에만 안 열리는 문이라면 해가 들고 현관이 조금 데워진 낮에는 멀쩡한 경우도 있습니다. / 이럴 때 괜찮아졌다고 넘기기 쉬운데, 같은 증상이 반복되면 문틀 쪽 여유가 줄었다는 뜻이니 점검을 받아 두세요.
@ 군자동 현관문 경첩 나사 헐거움 점검

# 문 앞에서 해 볼 수 있는 것
문이 닫힌 채 안 열린다면 아래 방법을 순서대로 해 보세요. / 걸쇠에 걸린 힘을 덜어 주는 것이 핵심입니다.
- 번호를 누르면서 손잡이 쪽 문을 위로 살짝 들어 올리기
- 문을 안쪽으로 밀었다가 당기면서 손잡이 내리기
- 경첩 반대쪽 문 모서리를 손바닥으로 가볍게 누르기
힘을 크게 줄 필요는 없습니다. / 걸쇠가 문틀 모서리에서 살짝 떨어지는 순간 풀리는 경우가 많습니다.

# 이런 행동은 문틀을 더 망가뜨립니다
급한 마음에 어깨로 문을 밀거나 발로 차면 문틀이 더 틀어집니다. / 한 번 휜 철문틀은 원래대로 돌리기가 어렵습니다.
문틈에 드라이버나 쇠붙이를 넣어 비트는 것도 피해 주세요. / 문틀 페인트와 고무 패킹이 상하고, 걸쇠가 들어가는 판이 휘어 다음부터 잘 안 잠기게 됩니다.

# 연락 주실 때 알려 주시면 좋은 것
군자동은 비슷한 다세대가 이어져 있어 도로명 주소와 건물 이름을 먼저 여쭙니다. / 아래 내용을 함께 말씀해 주시면 맞는 장비를 챙겨 갈 수 있습니다.
- 번호를 누를 때 소리나 반응이 평소와 같은지
- 최근 문 닫을 때 걸리는 느낌이 있었는지
- 문 위아래 틈 사진, 경첩 쪽 사진
- 집 안에 아이나 어르신이 계신지
공동현관이 있는 건물이라면 출입 방법도 같이 알려 주세요. / 골목이 좁으면 차를 세울 만한 곳도 말씀해 주시면 도움이 됩니다.

# 도착 후 확인과 금액 안내
문을 열어야 할 때는 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 임대차 계약서 중 하나를 보여 주시면 됩니다.
문과 문틀 상태를 보고 작업 전에 금액을 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 끝내 열지 못하면 비용은 받지 않습니다. 진행 흐름은 [이용안내](guide.html)에 있습니다.

# 문을 여는 순서
먼저 걸쇠에 걸린 힘을 덜어 주는 방법으로 열어 봅니다. / 그래도 안 되면 문과 문틀이 덜 상하는 방법부터 차례로 시도합니다.
오래된 문일수록 작은 힘에도 마감재가 쉽게 상하기 때문에 조심스럽게 다룹니다. / 여는 방식은 [현관문 개문](door-open.html)에 자세히 적어 두었습니다.

# 열린 뒤 문틀과 경첩을 손보는 일
문이 열리면 다시 같은 일이 생기지 않게 문과 문틀을 맞춰 봅니다. / 경첩 나사를 조이거나 보강하고, 필요하면 걸쇠가 들어가는 문틀 쪽 판의 위치를 옮깁니다.
경첩이 닳았거나 휘었다면 경첩 교체를 함께 말씀드립니다. / 문이 끝까지 안 닫히는 문제가 같이 있다면 도어클로저 속도도 함께 봅니다.
도어락이 오래돼 걸쇠 힘이 약해진 경우라면 [도어락 수리](doorlock-repair.html)를 먼저 하고, 부품을 구하기 어려우면 [도어락 교체](doorlock-replace.html)를 권해 드립니다. / 무엇을 할지는 상태를 보여 드린 뒤 직접 고르시면 됩니다.

# 오래된 문 오래 쓰는 습관
문을 닫을 때 쾅 닫지 말고 손잡이를 잡고 끝까지 밀어 닫아 주세요. / 충격이 줄어들면 경첩 나사가 덜 풀립니다.
- 계절이 바뀔 때 문 위아래 틈을 한 번씩 보기
- 경첩에서 삐걱 소리가 나면 나사부터 확인
- 닫을 때 걸리는 느낌이 생기면 미루지 말고 점검
작은 어긋남일 때 손보면 작업도 간단하고 문틀도 덜 상합니다.
세 들어 사신다면 처짐이 보이는 날 사진을 찍어 집주인께 미리 알려 두시면 나중에 손볼 때 이야기가 한결 쉬워집니다.
@ 광진 군자동 문틀 걸쇠판 위치 조정

# 군자동 말고 광진구 어디든
중곡동, 능동, 화양동, 자양동, 구의동, 광장동까지 광진구라면 어디든 갑니다. / 지역 안내는 [광진구 출장열쇠](seoul-gwangjin.html), 다른 곳은 [출장 지역](area.html)에서 확인하실 수 있습니다.

? 경첩만 따로 손봐 주시나요? | 네, 문을 열 일이 없어도 경첩과 문틀 점검만 따로 해 드립니다.
? 오래된 철문도 문틀을 맞출 수 있나요? | 휜 정도에 따라 다르며, 상태를 보고 조정으로 될지 먼저 말씀드립니다.

? 못 열면 출장비가 나오나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.
