# 내 집이 아닌 집의 도어락이 고장 났을 때
구의동은 구의역 주변으로 아파트와 다세대, 원룸이 함께 있어 전세나 월세로 사는 분도 많은 동네입니다. / 살다 보면 도어락이 고장 나거나 번호판이 낡아 바꿔야 할 때가 오는데, 이때 누가 어떻게 처리할지 막막해지곤 합니다.
도어락은 집에 붙어 있는 설비이면서 매일 세입자가 쓰는 물건이라 애매한 부분이 생깁니다. / 비용을 누가 부담할지는 계약 내용과 고장 원인, 서로의 합의에 따라 달라서 이 글에서 한쪽으로 단정하지는 않습니다.
대신 양쪽이 나중에 얼굴 붉히지 않도록 미리 맞춰 볼 것과 기록해 둘 것을 정리했습니다. / 문이 잠겨 급하다면 정리는 나중에 하시고 먼저 [광진구 출장열쇠](seoul-gwangjin.html)로 연락 주세요.
@ 구의동 전월세 도어락 고장 정리

# 먼저 계약서를 꺼내 보세요
계약서 특약에 수리나 시설 관련 내용이 적혀 있는지 확인해 보세요. / 도어락이라는 단어가 없더라도 소모품, 시설 수선 같은 표현이 들어 있을 수 있습니다.
특약이 없다면 일반적인 관례나 서로의 이야기로 정하게 됩니다. / 판단이 어렵다면 계약을 중개한 부동산이나 공인된 상담 창구에 여쭤보시는 게 정확합니다. / 같은 고장이라도 집마다 계약 조건이 달라 이웃집 사례를 그대로 따르기는 어렵습니다.
열쇠 기사는 고장 상태를 설명해 드릴 수는 있지만 누가 부담해야 한다고 판단해 드리지는 않습니다. / 그 부분은 두 분이 정하실 일이라는 점을 미리 말씀드립니다.

# 고장이 난 순간 기록해 둘 것
나중에 이야기를 나눌 때 가장 도움이 되는 건 그때 상황을 적어 둔 기록입니다. / 기억은 시간이 지나면 흐려지고, 서로 다르게 기억하기도 합니다.
- 언제부터 어떤 증상이 있었는지 날짜와 함께
- 번호판, 손잡이, 걸쇠 상태를 찍은 사진이나 짧은 영상
- 배터리를 언제 갈았는지
- 누가 마지막으로 문을 열고 닫았는지
사진은 앞면과 안쪽 몸체를 모두 찍어 두세요. / 증상이 소리로 나타나는 고장이라면 경고음이나 모터 소리를 짧게 녹음해 두는 것도 좋은 기록이 됩니다. / 모델명이 보이게 찍으면 제품이 얼마나 오래됐는지 짐작하는 데도 쓰입니다.

# 집주인께 알릴 때는 이렇게
고장을 알게 되면 되도록 빨리, 그리고 기록이 남는 방식으로 알려 드리는 게 좋습니다. / 전화로 말씀드렸더라도 문자로 한 번 더 남겨 두면 서로 확인이 쉽습니다.
문자에는 증상, 사진, 지금 문을 쓸 수 있는지 여부를 짧게 적어 주세요. / 수리 기사를 부를 생각이라면 그 계획도 같이 말씀드리면 오해가 줄어듭니다. / 집주인이 따로 아는 기사가 있다면 그쪽을 먼저 쓰자고 하실 수도 있으니 의견을 여쭤보세요.
집주인 입장에서도 문제를 늦게 알게 되면 더 큰 수리로 번질 수 있어 빠른 연락을 반기는 경우가 많습니다. / 연락이 바로 닿지 않는다면 보낸 시각이 남는 문자가 특히 쓸모 있습니다.
@ 구의동 도어락 고장 사진 기록

# 급한 상황이면 먼저 문부터
문이 잠겨 들어갈 수 없거나 문이 잠기지 않아 집을 비울 수 없는 상황이라면 기다리기 어렵습니다. / 이럴 때는 사시는 분이 먼저 기사를 불러 문을 해결하고, 비용 정리는 나중에 하는 경우가 많습니다.
집주인과 연락이 닿지 않아도 사시는 분이 확인되면 문을 열어 드립니다. / 신분증 주소, 이 집 주소가 나온 우편물, 계약서 사진, 관리사무소 확인 중 하나로 봅니다.
작업 금액은 문 상태를 본 뒤 시작하기 전에 알려 드리고, 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 정리돼 있습니다.

# 고장 원인을 알아 두면 의논이 쉬워집니다
기사가 문을 보고 나면 원인이 어디에 가까운지 대략 설명드릴 수 있습니다. / 오래 써서 닳은 것인지, 습기나 결로 영향인지, 충격을 받은 흔적이 있는지 같은 것들입니다.
이 설명을 그대로 메모하거나 사진과 함께 정리해 두시면 두 분이 이야기할 때 도움이 됩니다. / 다만 기사의 설명은 상태에 대한 의견일 뿐 책임을 정하는 판단은 아니라는 점은 함께 알고 계셔야 합니다.

# 수리로 갈지 교체로 갈지
부품 하나만 바꿔 쓸 수 있는 경우가 생각보다 많습니다. / 배터리 접점, 손잡이 스프링, 걸쇠 쪽 부품처럼 부분 교체로 끝나는 고장이라면 [도어락 수리](doorlock-repair.html)가 부담이 적습니다.
제품이 너무 오래돼 부품을 구하기 어렵거나 같은 고장이 되풀이된다면 교체를 이야기하게 됩니다. / 이때는 집주인께 어떤 제품으로 바꿀지 미리 의견을 여쭤보세요.
문 두께와 기존 구멍 위치에 맞는 제품을 골라야 문에 흠이 덜 생깁니다. / [도어락 교체](doorlock-replace.html) 상담 때 맞는 제품 범위를 함께 알려 드립니다.

# 비밀번호와 카드는 누구 것일까
세입자가 바뀔 때 도어락 비밀번호와 카드를 어떻게 넘길지도 미리 정해 두면 좋습니다. / 이전 세입자 번호가 그대로 남아 있으면 새로 들어온 분이 불안해할 수 있습니다.
입주 때 초기화를 하고 새 번호를 등록하는 것을 기본으로 삼으면 서로 깔끔합니다. / 퇴거 때는 쓰던 카드를 돌려드리고 번호를 지운 뒤 나가는 방식이 많이 쓰입니다.
집주인이 관리용 번호를 따로 두고 싶다면 그 점도 처음에 서로 이야기해 두세요. / 말없이 남아 있는 번호는 나중에 오해의 씨앗이 됩니다. / 집 상태를 보러 오시거나 수리 기사가 드나들 일이 있을 때도 미리 날짜를 정해 함께 계시는 편이 서로 편합니다.

# 세입자가 직접 바꾸고 싶을 때
보안이 걱정돼 세입자가 스스로 도어락을 바꾸고 싶어 하는 경우도 있습니다. / 이때도 바꾸기 전에 집주인께 한 번 말씀드리는 편이 좋습니다.
퇴거할 때 원래 도어락으로 되돌려 놓을지, 새 도어락을 그대로 두고 갈지 미리 정해 두세요. / 기존 도어락을 보관해 둘 계획이라면 부품을 빠짐없이 챙겨 상자에 넣어 두시면 됩니다. / 나사와 고정판까지 함께 넣어 두어야 나중에 되돌려 달 때 문에 새 구멍을 뚫지 않아도 됩니다.
@ 광진 구의동 도어락 교체 상담

# 기사에게 받아 둘 수 있는 것
작업이 끝나면 무엇을 했는지 짧게 정리해 달라고 요청하실 수 있습니다. / 바꾼 부품, 작업 내용, 날짜 정도만 있어도 나중에 이야기할 때 훨씬 수월합니다.
작업 전후 사진을 직접 찍어 두시는 것도 좋습니다. / 기사도 필요한 경우 상태를 같이 보여 드리며 설명합니다. / 떼어 낸 옛 부품을 버릴지 보관할지도 그 자리에서 정해 주세요. 집주인께 보여 드려야 한다면 버리지 않고 봉투에 담아 두는 편이 좋습니다.

# 구의동 말고 광진구 어디든
자양동, 광장동, 화양동, 군자동, 중곡동, 능동까지 광진구 전 지역을 다닙니다. / 서울, 경기 전 지역 24시간이며 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.
