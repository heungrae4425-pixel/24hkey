# 번호는 맞는데 위잉 소리만 날 때
구의역 둘레의 구의동에는 아파트와 다세대, 오래된 주택이 한데 섞여 있습니다. / 오래 쓴 도어락과 몇 해 전에 바꾼 신형 제품이 한 골목 안에 같이 있는 경우가 많습니다.
퇴근길에 번호를 눌렀더니 띠리릭 소리 대신 위잉 하는 모터 소리만 길게 나고 문이 꿈쩍도 안 하면 당황스럽습니다. / 어떤 날은 잘 열리고 어떤 날은 안 열리는 식으로 들쭉날쭉하기도 합니다.
도어락이 내는 소리와 반응은 원인을 짐작하는 데 꽤 쓸모 있는 단서입니다. / 이 글은 구의동 현관 앞에서 들리는 소리별로 무엇을 의심하고 어디까지 해 볼 수 있는지 정리했습니다.
@ 구의동 현관 도어락 모터 소리 오작동

# 소리부터 귀 기울여 들어 보기
같은 고장처럼 보여도 소리가 다르면 원인이 다릅니다. / 문 앞에서 아래 중 어떤 경우인지 먼저 들어 보세요.
- 모터가 돌다가 중간에 멈추는 소리
- 모터는 끝까지 도는데 걸쇠가 안 빠지는 느낌
- 삐삐삐 하는 짧은 경고음이 반복
- 아무것도 안 눌렀는데 혼자 울리는 소리
소리를 짧게 녹음하거나 영상으로 찍어 두면 전화로 설명하기가 한결 쉬워집니다. / 기사도 어떤 장비를 챙길지 미리 정할 수 있습니다.

# 모터가 돌다 멈추면 걸쇠가 눌려 있는 경우
가장 흔한 원인은 걸쇠가 문틀에 꽉 눌려 있는 상태입니다. / 문이 바깥쪽이나 안쪽으로 살짝 밀려 있으면 모터 힘만으로는 걸쇠를 빼내지 못합니다.
이럴 때는 번호를 누르면서 문을 몸 쪽으로 살짝 당기거나 반대로 밀어 보세요. / 걸쇠에 걸리던 힘이 빠지면서 한 번에 풀리는 경우가 많습니다.
겨울에 현관 안팎 온도 차가 크거나 문을 세게 닫은 다음 이런 일이 잦습니다. / 계속 반복된다면 걸쇠가 들어가는 문틀 쪽 판의 위치를 조금 옮겨야 할 수도 있습니다.

# 모터 힘이 약하다면 배터리부터
모터 소리가 평소보다 느리고 힘없이 들린다면 배터리가 다 돼 가는 신호일 수 있습니다. / 번호판 불은 들어와도 모터를 끝까지 돌릴 힘이 모자란 겁니다.
문 앞이라면 바깥쪽 아래 비상 단자에 9V 건전지를 대고 다시 눌러 보세요. / 구의역 근처나 동네 편의점에서 쉽게 구할 수 있습니다.
문이 열리면 안쪽 배터리를 한꺼번에 전부 새것으로 바꿔 주세요. / 일부만 바꾸면 남은 약한 배터리 때문에 같은 증상이 금방 돌아옵니다.

# 짧은 경고음이 반복될 때
삐삐삐 하는 짧은 소리가 이어진다면 제품이 무언가를 알려 주는 중입니다. / 배터리 부족, 비밀번호 여러 번 틀림, 문이 덜 닫힘 알림이 대표적입니다.
번호를 여러 번 틀렸다면 잠시 기다렸다 다시 눌러야 합니다. / 제품마다 기다리는 시간이 달라 몇 분 정도는 손대지 않고 두는 편이 좋습니다.
문이 다 닫히지 않았다는 알림이라면 문을 한 번 끝까지 밀어 닫아 보세요. / 도어클로저가 약해져 마지막에 덜 닫히는 집이라면 경첩과 클로저 점검도 함께 생각해 볼 만합니다.
@ 구의동 도어락 경고음 반복 원인 확인

# 아무것도 안 했는데 혼자 울린다면
한밤중에 도어락이 혼자 울리면 놀랄 수밖에 없습니다. / 대부분은 번호판에 물기나 먼지가 남아 버튼이 눌린 것으로 잘못 알아듣는 경우입니다.
비 온 뒤나 현관 청소를 한 다음에 생겼다면 마른 천으로 번호판을 닦고 한동안 두어 보세요. / 안쪽 몸체의 경보 기능이 켜져 있는지도 설명서를 보고 확인해 보시면 좋습니다.
닦아도 계속 울리면 회로 쪽 문제일 수 있으니 무리하게 분해하지 말고 점검을 받으세요. / 안쪽 몸체를 열다 배선이 빠지면 수리가 더 번거로워집니다.

# 혼자 해 볼 때 지킬 선
급하다고 이것저것 해 보다 보면 고장이 커집니다. / 아래는 피해 주시면 좋습니다.
- 모터 소리가 날 때 손잡이를 세게 비틀기
- 번호판을 드라이버로 떼어 내기
- 물티슈로 번호판을 문지르기
- 경고음을 멈추려고 배터리를 넣었다 뺐다 반복하기
특히 습기가 원인일 때 물티슈를 쓰면 물기가 더 들어갑니다. / 마른 천으로만 닦아 주세요.

# 연락 주실 때 알려 주시면 좋은 것
구의동은 비슷한 건물이 많아 도로명 주소나 단지 동, 호수를 먼저 여쭙니다. / 함께 아래 내용을 말씀해 주시면 상담이 짧아집니다.
- 어떤 소리가 나는지, 녹음이나 영상이 있는지
- 언제부터 그랬는지, 배터리는 언제 바꿨는지
- 도어락 모양 (번호판형, 밀고 당기는 형)
- 지금 문 밖인지 안인지
집 안에서 문이 안 열리는 상황이라면 꼭 먼저 말씀해 주세요. / 안쪽에서 해 볼 수 있는 것을 전화로 먼저 안내해 드립니다.

# 사시는 분 확인과 금액 안내
문을 열어야 하는 상황이면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
도어락 상태를 보고 작업 전에 금액을 먼저 말씀드리고, 괜찮다고 하실 때만 진행합니다. / 끝내 열지 못하면 비용은 받지 않습니다. 자세한 흐름은 [이용안내](guide.html)에 있습니다.

# 고쳐서 다시 쓰는 쪽을 먼저
걸쇠 위치 조정, 단자 청소, 모터 쪽 점검만으로 다시 잘 쓰는 경우가 많습니다. / 이럴 때는 교체를 권하지 않고 [도어락 수리](doorlock-repair.html)로 마무리합니다.
문이 닫힌 채 열리지 않는다면 먼저 문을 연 뒤 원인을 봅니다. / 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 이럴 때는 교체가 나을 수 있습니다
모터가 자주 멈추고 회로까지 약해진 오래된 제품이라면 고쳐도 같은 고장이 다시 올 수 있습니다. / 부품을 구하기 어려운 제품도 마찬가지입니다.
이 경우 수리와 교체를 나란히 놓고 각각 어떻게 다른지 말씀드린 뒤 고르시게 합니다. / 바꾸기로 하시면 [도어락 교체](doorlock-replace.html) 순서대로 문 두께와 구멍 자리부터 맞춰 봅니다.

# 평소 소리를 알아 두면 고장이 빨리 보입니다
도어락이 잘 될 때 어떤 소리를 내는지 가족 모두 한 번 들어 두시면 좋습니다. / 열릴 때 모터가 도는 길이, 잠길 때 나는 소리를 알고 있으면 조금만 달라져도 바로 알아챌 수 있습니다.
소리가 길어지거나 힘이 빠진 느낌이 들면 그 주 안에 배터리를 갈고 걸쇠 쪽 먼지를 털어 주세요. / 완전히 멈추기 전에 손보면 문 밖에 갇히는 일을 대부분 막을 수 있습니다.
배터리 칸 덮개 안쪽에 교체한 날짜를 적어 두는 것도 작은 도움이 됩니다. / 다음 교체 시기를 따로 기억하지 않아도 됩니다.
@ 광진 구의동 도어락 걸쇠 위치 조정 수리

자양동, 광장동, 화양동, 군자동, 중곡동, 능동까지 광진구 어디든 출동합니다. / 지역 안내는 [광진구 출장열쇠](seoul-gwangjin.html), 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 모터 소리만 나고 안 열리면 배터리 문제인가요? | 배터리일 수도 있지만 걸쇠가 눌린 경우가 더 흔합니다. 문을 살짝 밀거나 당기면서 눌러 보세요.
? 경고음이 밤새 울려서 이웃에게 미안해요. | 마른 천으로 번호판을 닦고, 그래도 계속되면 전화 주세요. 시간 상관없이 받습니다.
? 소리를 녹음해서 보내도 되나요? | 네, 짧은 영상이나 녹음이 있으면 원인을 좁히는 데 도움이 됩니다.
? 고치면 얼마나 더 쓸 수 있나요? | 제품 상태마다 달라 점검 뒤 수리로 충분한지, 교체가 나은지 그대로 말씀드립니다.
? 못 고치면 비용이 나오나요? | 문을 끝내 못 열면 비용은 받지 않으며, 수리 금액은 작업 전에 먼저 말씀드립니다.

# 마무리
구의동에서 도어락이 위잉 소리만 내거나 경고음이 그치지 않으면 소리 종류부터 들어 보고, 문을 살짝 밀거나 당기면서 다시 눌러 보세요. / 그래도 안 되면 녹음이나 영상과 함께 연락 주시면 됩니다.
