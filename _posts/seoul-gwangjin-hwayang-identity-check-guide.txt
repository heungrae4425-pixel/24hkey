# 문 앞에서 신분증부터 찾는 이유
화양동은 건대입구역 주변으로 원룸과 자취방이 빽빽하게 들어선 동네입니다. / 학교나 직장 때문에 잠깐 사는 분이 많아서 주소지와 실제 사는 곳이 다른 경우도 흔합니다.
그런데 문을 열어 달라고 부르면 열쇠 기사는 가장 먼저 사시는 분이 맞는지부터 묻습니다. / 급한 마음에 서운할 수 있지만, 이 확인이 없다면 누구든 남의 방 앞에서 같은 부탁을 할 수 있게 됩니다.
이 글은 화양동 같은 원룸 동네에서 신분 확인이 어떻게 이뤄지는지, 무엇을 준비하면 빨라지는지를 정리했습니다. / 지금 문 앞에서 기다리는 중이라면 아래 목록부터 보시고 [광진구 출장열쇠](seoul-gwangjin.html)로 연락 주세요.
@ 화양동 원룸 출장열쇠 신분 확인 절차

# 확인 없이 열면 생길 수 있는 일
헤어진 연인, 사이가 틀어진 룸메이트, 계약이 끝난 전 세입자가 문을 열어 달라고 하는 경우를 생각해 보면 이해가 쉽습니다. / 본인은 사는 사람이라고 말해도 실제로는 그 방에 들어갈 권리가 없을 수 있습니다.
열쇠 기사가 확인 없이 문을 열면 안에 있는 사람과 물건이 위험해집니다. / 그래서 바쁜 새벽이라도 이 단계는 건너뛰지 않습니다.
이 확인은 지금 문 앞에 서 계신 분만을 위한 게 아닙니다. / 언젠가 내 방 앞에 엉뚱한 사람이 서 있을 때 나를 지켜 주는 장치이기도 합니다.

# 가장 간단한 방법, 신분증 주소
신분증에 적힌 주소와 문을 열 집 주소가 같으면 확인이 바로 끝납니다. / 주민등록증, 운전면허증처럼 주소가 나오는 신분증이면 됩니다.
휴대폰 안의 모바일 신분증도 주소가 확인되면 같이 볼 수 있습니다. / 화면을 보여 주실 때 이름과 주소 부분만 확인하고 다른 정보는 따로 기록하지 않습니다. / 학생증이나 사원증처럼 주소가 없는 신분증은 이름 확인용으로만 쓰고, 주소는 다른 자료로 한 번 더 맞춰 봅니다.

# 주소가 다를 때 대신 쓰는 방법
원룸에 사는 분 중에는 본가 주소가 신분증에 그대로 남아 있는 분이 많습니다. / 이럴 때는 아래 중 하나로 사시는 곳을 보여 주시면 됩니다.
- 이름과 이 집 주소가 함께 찍힌 우편물이나 택배 송장
- 휴대폰에 저장된 임대차 계약서 사진
- 관리비나 공과금 고지서, 문자 안내
- 건물 관리인이나 집주인의 확인 전화
한 가지로 애매하면 두 가지를 같이 보기도 합니다. / 집주인 연락이 안 되더라도 사시는 분임이 확인되면 문을 열어 드립니다. / 새벽에 집주인께 전화를 돌리기 어려운 사정은 충분히 알고 있으니, 가지고 계신 자료부터 차분히 찾아봐 주세요.
@ 화양동 원룸 택배 송장 우편물 주소 확인

# 신분증이 방 안에 있는 경우
지갑째로 방 안에 두고 나온 분이 가장 많습니다. / 이럴 때는 휴대폰에 남은 계약서 사진이나 배달 앱 주소 기록, 택배 문자처럼 이 집 주소와 이름이 연결된 자료를 먼저 찾아봅니다.
그래도 부족하면 건물 관리인이나 이웃 확인을 함께 씁니다. / 문을 연 직후 방 안에 들어가 신분증을 꺼내 보여 주시는 것으로 마무리하기도 합니다.
이때 기사는 문 앞에서 기다리고, 신분증을 확인한 뒤에야 작업을 마무리합니다. / 방 안의 물건에는 손대지 않습니다. / 신분증을 찾는 동안 시간이 걸려도 재촉하지 않으니 천천히 찾으셔도 됩니다.

# 친구나 가족이 대신 부를 때
본인이 해외에 있거나 병원에 있어서 친구가 대신 연락하는 경우도 있습니다. / 이럴 때는 실제 사는 분과 통화로 직접 확인하는 과정이 꼭 필요합니다.
사시는 분이 영상 통화로 얼굴과 신분증을 보여 주시고, 문을 열어도 된다는 뜻을 직접 말씀해 주시는 식입니다. / 본인과 연락이 전혀 안 되면 아무리 가까운 사이라도 문을 열지 않습니다.

# 룸메이트와 같이 사는 방이라면
둘이 함께 쓰는 방인데 계약서에는 한 사람 이름만 올라가 있는 경우가 있습니다. / 이때 계약자가 아닌 분이 문을 열어 달라고 하시면 계약자와 통화로 확인하거나, 이 집 주소로 받은 택배 기록처럼 함께 산다는 걸 보여 주는 자료를 봅니다.
두 사람 사이가 틀어진 상황이라면 문 앞에서 사정을 먼저 여쭙니다. / 한쪽이 반대하는 상태에서 억지로 문을 여는 일은 하지 않습니다.

# 공동현관이 따로 있는 건물이라면
화양동 원룸 건물은 1층 공동현관과 호실 도어락이 따로인 곳이 많습니다. / 공동현관 번호를 모르면 건물 안까지 들어가는 것부터 막힙니다.
이웃이 들어갈 때 함께 들어가거나 건물 관리인께 열어 달라고 부탁해 주세요. / 건물에 들어가는 것과 호실 문을 여는 것은 별개라서 호실 문 앞에서 다시 확인 절차를 거칩니다.

# 확인이 끝까지 안 되면
여러 방법을 써도 사시는 분인지 알 수 없으면 문을 열 수 없습니다. / 이 경우에는 작업하지 않고 돌아가며 비용도 받지 않습니다.
대신 어떤 자료가 있으면 되는지 알려 드리니, 그걸 챙겨 다시 연락 주시면 됩니다. / 집주인이나 관리인이 아침에 연락될 것 같다면 그때 다시 오는 방법도 있습니다. / 그사이 지내실 곳이 마땅치 않으면 근처 친구 집이나 찜질방처럼 따뜻한 곳에서 기다리시길 권해 드립니다.

# 확인을 마치면 진행 순서
사시는 분임이 확인되면 도어락 종류와 문 상태를 보고 금액을 먼저 말씀드립니다. / 괜찮다고 하시면 그때부터 손을 대고, 마음에 안 드시면 그냥 돌아갑니다.
여는 방법은 문과 도어락이 덜 상하는 쪽부터 차례로 해 봅니다. / 끝내 열지 못하면 비용은 받지 않으며, 자세한 흐름은 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 적어 두었습니다.
@ 광진 화양동 원룸 도어락 개문 진행

# 개인정보는 이렇게 다룹니다
신분증이나 우편물은 눈으로 확인만 하고 사진을 찍거나 복사하지 않습니다. / 주소와 이름이 맞는지만 보면 되기 때문입니다.
혹시 불편하신 부분이 있으면 확인 전에 말씀해 주세요. / 가릴 수 있는 정보는 가리고 필요한 부분만 보여 주셔도 됩니다. / 주민등록번호 뒷자리처럼 확인에 필요 없는 부분은 손가락으로 덮고 보여 주셔도 충분합니다.

# 평소에 준비해 두면 좋은 것
- 계약서 사진을 휴대폰 사진첩에 따로 보관하기
- 이사하면 주소 변경을 미루지 않기
- 비밀번호는 도어락 점검이나 [도어락 수리](doorlock-repair.html) 때 비밀번호도 함께 바꾸기
- 공동현관 번호를 휴대폰 메모에 적어 두기
이것만 챙겨도 문이 잠겼을 때 확인 시간이 짧아집니다. / 계약을 새로 하거나 연장했다면 바뀐 계약서도 다시 찍어 두세요. / 기다리는 시간이 줄면 그만큼 빨리 방에 들어가실 수 있습니다.

# 화양동 근처 광진구 어디든
자양동, 구의동, 광장동, 군자동, 중곡동, 능동까지 광진구 전 지역을 다닙니다. / 서울, 경기 전 지역 24시간이며 다른 곳은 [출장 지역](area.html)에서 확인하세요.

? 집주인 연락이 안 되는데 열어 주시나요? | 사시는 분이라는 게 확인되면 집주인 연락 없이도 진행합니다.

? 신분증 사진을 찍어 가시나요? | 아닙니다. 눈으로 확인만 하고 따로 남기지 않습니다.
? 확인이 안 돼서 못 열면 비용이 있나요? | 없습니다. 작업하지 않으면 비용도 받지 않습니다.
