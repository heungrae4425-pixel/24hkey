# 건대입구역 근처 자취방, 열쇠가 말을 안 들을 때
화양동은 건대입구역 주변으로 원룸과 다세대가 골목마다 이어진 동네입니다. / 학생과 사회 초년생이 많이 살고, 방을 옮길 때마다 열쇠를 넘겨받아 쓰는 일이 흔합니다.
번호키를 쓰는 방이 늘었지만 보조키나 열쇠식 자물쇠를 같이 쓰는 건물도 아직 많습니다. / 그러다 보니 열쇠가 반쯤 돌다 멈추거나, 꽂은 채로 빠지지 않아 문 앞에서 한참 씨름하는 경우가 생깁니다.
열쇠 문제는 힘을 줄수록 나빠지는 경우가 대부분입니다. / 이 글은 화양동 원룸 현관에서 열쇠가 말을 안 들을 때 무엇부터 보고, 어디서 손을 멈춰야 하는지 정리했습니다.
@ 화양동 원룸 현관 열쇠 안 돌아감

# 안 돌아가는 것과 안 빠지는 것은 따로 봅니다
열쇠가 끝까지 들어가긴 하는데 돌아가지 않는 경우가 있고, 돌아가긴 했는데 다시 빠지지 않는 경우가 있습니다. / 둘은 원인이 겹치기도 하지만 손쓰는 방법이 조금 다릅니다.
안 돌아가는 쪽은 열쇠 모양, 실린더 안 먼지, 문틀에 눌린 걸쇠를 먼저 의심합니다. / 안 빠지는 쪽은 열쇠가 처음 넣은 위치로 완전히 돌아오지 않은 경우가 가장 흔합니다.
어느 쪽인지 먼저 정해 두면 전화로 설명할 때도 훨씬 수월합니다. / 그다음 아래 순서대로 하나씩 확인해 보세요.

# 넘겨받은 열쇠, 몇 번째 복사본일까
원룸 열쇠는 이전에 살던 분이나 집주인이 복사해서 준 것인 경우가 많습니다. / 복사본을 다시 복사하면 열쇠 홈이 조금씩 무뎌져 안에서 걸리는 일이 잦아집니다.
열쇠를 불빛에 비춰 보고 홈 끝이 둥글게 닳았는지, 옆면에 거친 부분이 있는지 봐 주세요. / 다른 열쇠가 있다면 같은 자물쇠에 넣어 비교해 보는 것도 좋습니다.
다른 열쇠로는 잘 돌아간다면 자물쇠가 아니라 그 열쇠가 문제입니다. / 원래 열쇠를 가진 집주인께 새로 복사를 부탁하거나, 실린더를 바꾸는 쪽을 생각해 볼 수 있습니다.

# 열쇠를 끝까지 넣었는지 확인
열쇠가 끝까지 들어가지 않은 채 돌리면 안쪽 핀이 맞지 않아 돌아가지 않습니다. / 열쇠 손잡이 쪽 어깨 부분이 자물쇠 겉면에 닿을 때까지 들어갔는지 봐 주세요.
뭔가에 걸려 끝까지 안 들어간다면 실린더 안에 이물질이 있을 수 있습니다. / 골목 공사 먼지나 껌 같은 것이 들어간 경우도 있어 억지로 밀어 넣지 마세요.

# 문을 밀거나 당기면서 돌려 보기
문틀이 조금 처졌거나 문이 바람에 밀려 있으면 걸쇠가 문틀에 눌려 열쇠가 잘 돌지 않습니다. / 이럴 때는 손잡이를 잡고 문을 살짝 몸 쪽으로 당기거나 반대로 밀면서 열쇠를 돌려 보세요.
한쪽으로 힘을 주자 부드럽게 돌아간다면 자물쇠보다 문과 문틀 맞물림이 원인입니다. / 이런 문은 열쇠만 바꿔서는 해결이 안 되고 걸쇠가 들어가는 쪽 위치를 손봐야 합니다.
@ 화양동 다세대 보조키 실린더 상태 확인

# 열쇠가 꽂힌 채 안 빠질 때
먼저 열쇠를 처음 넣었던 방향, 보통 열쇠 홈이 위나 아래로 똑바로 선 상태로 되돌려 보세요. / 조금만 덜 돌아와 있어도 핀이 걸려 빠지지 않습니다.
되돌린 뒤 열쇠를 살짝 안쪽으로 밀었다가 천천히 빼면 빠지는 경우가 많습니다. / 좌우로 흔들며 세게 잡아당기면 열쇠가 휘거나 부러질 수 있으니 피해 주세요.
그래도 안 빠지면 열쇠를 꽂아 둔 채로 연락 주셔도 됩니다. / 억지로 뺀 뒤 부러져 안에 남는 것보다 훨씬 낫습니다.

# 윤활제는 아무거나 쓰지 마세요
뻑뻑하다고 식용유나 일반 기름을 넣으면 당장은 부드러워져도 먼지가 엉겨 붙어 더 나빠집니다. / 실린더 전용 윤활제나 흑연 가루처럼 끈적이지 않는 것을 써야 합니다.
전용 제품이 없다면 넣지 말고 그대로 두는 편이 낫습니다. / 점검 때 실린더 상태를 보고 청소로 될지 교체가 필요한지 말씀드립니다.

# 추운 아침에 유독 안 돌아간다면
한겨울 아침에만 열쇠가 뻑뻑하다면 실린더 안에 맺힌 물기가 얼었을 수 있습니다. / 복도 창문 쪽에 붙은 방이나 바깥바람이 바로 닿는 현관에서 자주 생깁니다.
이럴 때는 열쇠를 손으로 감싸 잠시 데운 뒤 다시 넣어 보세요. / 라이터나 드라이어 뜨거운 바람을 바로 대면 실린더 안 부품이 상할 수 있어 피하시는 게 좋습니다.
날이 풀리면 괜찮아졌다가 추워지면 반복된다면 실린더 안을 한 번 청소해 물기가 덜 머물게 해 두는 편이 낫습니다.

# 여기서 멈춰야 할 때
아래 상황이라면 더 손대지 말고 연락 주세요. / 무리하면 작업이 커지고 시간도 더 걸립니다.
- 열쇠가 휘었거나 금이 간 게 보일 때
- 이미 열쇠 일부가 부러져 안에 남았을 때
- 돌릴 때 안에서 딸깍하는 이상한 소리가 날 때
- 문이 안 열려 집에 못 들어가는 상황일 때
특히 부러진 조각이 남았다면 핀셋이나 실핀으로 꺼내려고 하지 마세요. / 조각이 더 깊이 밀려 들어가면 빼내기가 훨씬 어려워집니다.

# 원룸 건물이라면 공동현관도 함께
화양동 원룸 건물은 건물 공동현관과 방 현관이 따로인 경우가 많습니다. / 연락 주실 때 어느 문에서 열쇠가 말을 안 듣는지, 공동현관은 지나갈 수 있는지 알려 주세요.
건물 이름과 호수, 공동현관 비밀번호나 출입 방법을 같이 말씀해 주시면 헤매지 않고 갑니다. / 열쇠 사진을 한 장 보내 주시면 맞는 장비를 챙겨 갈 수 있습니다.

# 거주 확인과 금액 안내
문을 열어야 하는 상황이면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 임대차 계약서 중 하나면 되고, 집주인 연락이 안 돼도 확인만 되면 진행합니다.
실린더 상태를 보고 작업 전에 금액을 먼저 말씀드리며, 괜찮다고 하실 때만 시작합니다. / 끝내 열지 못하면 비용은 받지 않습니다. 진행 순서는 [이용안내](guide.html)에 있습니다.

# 실린더만 바꾸면 되는 경우
열쇠와 자물쇠가 모두 닳았다면 실린더, 즉 열쇠가 들어가는 부분만 새것으로 바꾸는 방법이 있습니다. / 문이나 도어락 전체를 바꾸지 않아도 돼 작업이 간단합니다.
이전 세입자가 열쇠를 몇 개 갖고 있었는지 모른다면 이 기회에 바꾸는 것도 방법입니다. / 다만 세 들어 사신다면 집주인께 먼저 알리고 진행하시는 게 좋습니다.
아예 열쇠 없는 번호키로 바꾸고 싶다면 [도어락 설치](doorlock-install.html)에서 문 두께와 구멍 자리부터 확인해 보세요. / 고장 난 번호키 쪽 문제라면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
@ 광진 화양동 실린더 교체 후 열쇠 작동 확인
