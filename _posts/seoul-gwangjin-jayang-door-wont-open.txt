# 증상 하나가 원인을 절반쯤 알려 줍니다
건대입구역에서 한강 쪽으로 내려가면 자양동 아파트 단지와 다세대가 넓게 펼쳐집니다. / 신형 밀고 당기는 형 도어락부터 오래된 번호판형까지 집집마다 쓰는 제품이 다양합니다.
현관문이 안 열린다는 말은 같아도 실제 원인은 여러 갈래입니다. / 번호판이 꺼져 있는지, 소리가 나는지, 문이 조금이라도 움직이는지만 봐도 원인을 꽤 많이 좁힐 수 있습니다.
이 글은 자양동 현관 앞에서 보이는 증상을 다섯 가지로 나누고, 증상마다 의심할 곳과 해 볼 수 있는 것을 정리했습니다. / 지금 문 앞이라면 해당하는 증상만 골라 읽으셔도 됩니다.
@ 자양동 현관문 안 열림 증상 확인

# 증상 가. 번호판이 아예 안 켜진다
손바닥으로 번호판을 덮거나 눌러도 불이 전혀 안 들어온다면 배터리가 다 됐을 가능성이 가장 큽니다. / 며칠 전부터 경고음이 났는데 미뤄 둔 경우가 많습니다.
바깥쪽 아래에 있는 비상 단자에 9V 건전지를 대고 다시 눌러 보세요. / 건전지를 대는 동안 전원이 들어와 번호를 누를 수 있습니다.
건전지를 대도 반응이 없다면 단자가 녹슬었거나 회로 쪽 문제일 수 있습니다. / 이때는 더 손대지 말고 연락 주시는 편이 낫습니다.

# 증상 나. 켜지는데 누르면 경고음만 난다
번호판은 켜지는데 번호를 누를 때마다 경고음이 나면 번호가 틀렸거나 입력이 잠시 막힌 상태일 수 있습니다. / 가족 중 누가 최근에 번호를 바꾸지 않았는지 먼저 물어보세요.
여러 번 틀린 뒤라면 몇 분 동안 손대지 말고 기다렸다가 다시 눌러 보세요. / 그사이에도 계속 누르면 막히는 시간이 길어지는 제품이 있습니다.
번호가 확실히 맞는데도 경고음이 난다면 번호판에 물기나 먼지가 있어 버튼을 잘못 읽는 경우일 수 있습니다. / 마른 천으로 닦고 천천히 한 자리씩 눌러 보세요.

# 증상 다. 열리는 소리는 나는데 문이 안 움직인다
띠리릭 소리가 나고 모터도 도는데 문이 꿈쩍 않는다면 걸쇠가 문틀에 꽉 눌려 있는 경우가 많습니다. / 문이 바깥이나 안쪽으로 살짝 밀린 채로 잠기면 모터 힘만으로는 걸쇠를 못 뺍니다.
번호를 누르면서 문을 몸 쪽으로 당기거나 반대로 밀어 보세요. / 걸쇠에 걸린 힘이 빠지는 순간 열리는 경우가 많습니다.
보조키가 따로 있는 집이라면 보조키가 잠겨 있지 않은지도 확인해 보세요. / 번호키는 풀렸는데 보조키가 잡고 있어 안 열리는 경우도 흔합니다.
@ 자양동 도어락 걸쇠 문틀 눌림 확인

# 증상 라. 문이 한 뼘만 열리고 멈춘다
문이 조금 열리다 툭 걸린다면 안쪽 안전고리나 걸쇠가 걸려 있는 겁니다. / 집 안에 있던 가족이 습관처럼 걸어 두었거나, 문을 닫을 때 걸쇠가 저절로 넘어간 경우입니다.
안에 사람이 있다면 문을 한 번 닫고 걸쇠를 풀어 달라고 부탁하세요. / 아무도 없는데 걸쇠가 걸렸다면 밖에서 손을 넣어 풀려고 하지 마세요. 걸쇠가 휘거나 손을 다칠 수 있습니다.
이 경우는 연락 주실 때 안전고리가 걸린 것 같다고 먼저 말씀해 주세요. / 작업 방법이 일반 개문과 달라 미리 알면 시간을 줄일 수 있습니다.

# 증상 마. 집 안에서도 안 열린다
안쪽 손잡이나 열림 버튼을 눌러도 문이 안 열린다면 걸쇠가 끼었거나 안쪽 몸체가 고장 났을 수 있습니다. / 이럴 때도 문을 살짝 밀거나 당기면서 다시 눌러 보세요.
안쪽 몸체에 수동 열림 손잡이나 비상 레버가 있는 제품도 있습니다. / 제품 모양을 사진으로 보내 주시면 어디를 돌리면 되는지 전화로 먼저 안내해 드립니다.
집 안에 갇혀 급한 상황이라면 기다리지 말고 바로 연락 주세요. / 아이나 어르신이 혼자 안에 계신 경우도 꼭 먼저 말씀해 주세요.

# 증상을 헷갈리게 만드는 실수
급하면 여러 가지를 한꺼번에 해 보게 되는데, 그러면 원인이 더 흐려집니다. / 번호를 계속 바꿔 누르거나 손잡이를 세게 흔들면 입력 막힘과 걸쇠 눌림이 겹쳐 버립니다.
문틈에 카드나 드라이버를 넣는 것도 피해 주세요. / 문틀과 고무 패킹이 상하고, 걸쇠가 들어가는 판이 휘어 다음부터 잘 안 잠길 수 있습니다.

# 자양동에서 위치를 알려 주실 때
자양동은 단지와 다세대가 촘촘해 주소를 정확히 받는 게 먼저입니다. / 단지라면 동과 호수, 다세대라면 도로명 주소나 건물 이름을 알려 주세요.
- 위에서 고른 증상 가에서 마 중 어느 것인지
- 도어락 모양과 보조키가 있는지
- 집 안에 사람이나 반려동물이 있는지
- 공동현관 출입 방법
증상만 정확히 말씀해 주셔도 통화가 짧아지고 맞는 장비를 챙겨 갈 수 있습니다. / 사진이 있으면 문자로 보내 주세요.

# 도착하면 사시는 분 확인부터
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 찍힌 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 경비실이나 관리사무소에 세대 확인을 먼저 부탁해 두세요. / 문을 연 직후 안에서 꺼내 보여 주셔도 됩니다.

# 시작 전 금액, 덜 상하는 개문
증상과 도어락 상태를 보고 작업 전에 금액을 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하며, 끝내 열지 못하면 비용은 받지 않습니다.
문은 덜 상하는 방법부터 차례로 시도합니다. / 자세한 방식은 [현관문 개문](door-open.html), 진행 흐름은 [이용안내](guide.html)에 정리해 두었습니다.

# 원인에 따라 달라지는 마무리
배터리 때문이었다면 전부 새것으로 바꾸고, 번호 문제였다면 새 번호를 등록합니다. / 걸쇠가 문틀에 눌렸던 거라면 걸쇠판 위치를 손봐 같은 일이 덜 생기게 합니다.
도어락 몸체가 고장 났다면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 먼저 봅니다. / 오래돼 부품을 구하기 어렵다면 [도어락 교체](doorlock-replace.html)를 함께 말씀드리고, 고르시는 대로 진행합니다.
@ 광진 자양동 현관 도어락 걸쇠판 조정

# 다음엔 문 앞에서 덜 막히려면
같은 증상이 다시 오지 않게 작은 습관 몇 가지를 들여 두세요. / 대부분 일 분도 안 걸리는 일입니다.
- 경고음이 나면 그날 바로 배터리 전부 교체
- 번호를 바꾸면 가족 모두에게 바로 알리기
- 안전고리는 집에 사람이 있을 때만 걸기
- 문을 닫을 때 끝까지 밀어 닫기
9V 건전지 하나를 가방이나 차에 넣어 두면 번호판이 꺼진 날에도 혼자 해결할 수 있습니다.
가족마다 안 열렸던 날의 증상을 한 줄씩 적어 두면 다음에는 어느 증상인지 금방 알아볼 수 있습니다. / 같은 증상이 두 번 이상 되풀이된다면 그때는 점검을 받아 두시는 편이 낫습니다.

# 자양동 이웃 동네도 다닙니다
구의동, 화양동, 광장동, 군자동, 중곡동, 능동까지 광진구라면 어디든 갑니다. / 지역 안내는 [광진구 출장열쇠](seoul-gwangjin.html), 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.

? 증상을 잘 모르겠으면요? | 번호판 상태와 소리만 알려 주셔도 충분합니다. 나머지는 통화로 함께 좁혀 갑니다.
? 자양동 밤늦게도 오시나요? | 네, 24시간 전화 받고 출동합니다.
