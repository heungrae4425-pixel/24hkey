# 자양동 새집 열쇠, 받은 그대로 쓰고 계신가요
자양동은 아파트 단지가 넓게 자리 잡고 건대입구역 쪽으로 가면 원룸과 상가가 이어지는 동네입니다. / 이사철이면 짐 정리보다 먼저 챙겨야 할 것이 현관 도어락이라는 걸 놓치는 분이 많습니다.
전에 살던 분이 쓰던 번호, 부동산이 알려준 임시 번호, 관리하시는 분이 가진 카드가 그대로 살아 있을 수 있습니다. / 누가 들어올 수 있는지 모르는 상태로 지내는 셈이라 첫 주 안에 정리해 두는 편이 마음이 놓입니다.
이 글은 이삿날부터 며칠 사이에 도어락을 초기화하고 새로 등록하는 흐름을 적었습니다. / 버튼을 찾지 못하거나 초기화 뒤 문이 말을 안 들으면 [광진구 출장열쇠](seoul-gwangjin.html)로 연락 주시면 됩니다.
@ 자양동 이사 후 도어락 초기화 비밀번호 재설정

# 이삿날 남아 있을 수 있는 출입 수단
도어락은 번호 하나만 있는 게 아니라 여러 방식이 함께 등록돼 있는 경우가 많습니다. / 하나만 바꾸고 나머지를 두면 정리가 반쪽짜리가 됩니다. / 특히 카드와 태그는 눈에 잘 띄지 않아 몇 장이 등록돼 있는지 아무도 모르는 경우가 많습니다.
- 전 거주자가 쓰던 주 비밀번호
- 이사 기간에 열어 두려고 만든 임시 번호
- 예전 가족이 쓰던 카드키나 스티커형 태그
- 지문 인식 도어락이라면 다른 사람 지문
- 기계식 비상 열쇠, 보조키 열쇠
이사 들어오며 받은 물건이 무엇인지 먼저 종이에 적어 두세요. / 부동산이나 집주인께 넘겨받은 목록을 한 번 더 여쭤 보는 것도 방법입니다. / 카드 몇 장, 열쇠 몇 개를 받았는지 알면 나중에 빠진 게 있는지 확인하기 쉽습니다.

# 초기화와 번호 변경은 다릅니다
번호만 새로 바꾸면 기존 번호는 사라지지만 카드나 지문은 남아 있는 제품이 있습니다. / 초기화는 등록된 정보를 한꺼번에 지우고 공장 출고 상태로 돌리는 작업입니다.
그래서 이사 직후라면 번호 변경보다 초기화를 먼저 하고 새로 등록하는 순서가 깔끔합니다. / 제품마다 방법이 달라서 설명서나 제조사 안내를 같이 보시는 게 좋습니다. / 설명서가 없으면 몸체에 적힌 모델명을 찾아 두시면 전화로 여쭐 때도 한결 수월합니다.

# 버튼은 보통 안쪽 몸체에 숨어 있습니다
초기화 버튼이나 등록 버튼은 대부분 실내 쪽 몸체의 배터리 덮개 안쪽에 있습니다. / 작은 구멍 안에 들어가 있어 이쑤시개나 볼펜 끝으로 눌러야 하는 제품도 있습니다.
덮개를 열 때는 손톱으로 억지로 비틀기보다 홈이 있는 쪽을 찾아 밀어 주세요. / 플라스틱 걸림쇠가 부러지면 덮개가 덜렁거려 습기와 먼지가 들어갑니다.
초기화 중에는 문을 열어 둔 상태로 진행하세요. / 닫은 채로 하다가 순서가 꼬이면 안쪽에 있어도 밖에 있는 사람이 못 들어오는 일이 생깁니다.

# 새 번호를 정하기 전에 가족과 먼저 이야기하기
이사 첫날은 정신이 없어서 한 사람이 혼자 번호를 정하고 알려주는 걸 잊는 일이 잦습니다. / 같이 사는 식구가 퇴근해 문 앞에 섰는데 번호가 바뀌어 있으면 바로 전화가 옵니다.
번호는 주소나 생일, 전화번호 뒷자리처럼 쉽게 짐작되는 숫자는 피해 주세요. / 대신 가족끼리만 아는 기억법을 하나 정해 두면 잊어버릴 일이 줄어듭니다.
@ 자양동 아파트 현관 도어락 안쪽 등록 버튼 확인

# 카드와 지문은 남김없이 다시 등록
카드키는 초기화 뒤에 쓸 카드만 하나씩 다시 대서 등록합니다. / 받은 카드 중 쓰지 않을 것은 따로 모아 두거나 버려서 섞이지 않게 하세요.
지문 도어락은 식구마다 손가락을 두 개씩 등록해 두면 다쳤을 때도 대비가 됩니다. / 아이 손가락은 자라면서 인식이 떨어질 수 있으니 몇 달 뒤 한 번 더 등록해 주세요.

# 공동현관 출입 방식도 함께 확인
자양동 아파트나 원룸 건물은 현관 도어락과 건물 입구 출입 방식이 따로인 경우가 많습니다. / 집 도어락만 바꿔 놓고 공동현관 카드는 전 거주자 것이 그대로인 일도 있습니다.
건물 출입 카드나 번호는 관리사무소나 건물 관리하시는 분께 여쭤 정리하시면 됩니다. / 집 도어락과 건물 입구를 한날 같이 정리하면 빠지는 부분이 없습니다. / 택배 보관함이나 주차장 출입처럼 따로 등록하는 것이 있다면 그것도 목록에 함께 적어 두세요.

# 이럴 땐 직접 하지 말고 불러 주세요
초기화를 하다가 아래 같은 일이 생기면 더 누르지 말고 멈추는 게 좋습니다.
- 버튼을 눌러도 아무 소리 없이 반응이 없을 때
- 초기화 뒤 문이 닫힌 채 걸쇠가 안 빠질 때
- 경고음이 계속 울리며 멈추지 않을 때
- 설명서가 없고 제조사 표시도 지워져 있을 때
특히 문을 닫은 상태에서 잠겼다면 [현관문 개문](door-open.html)이 먼저입니다. / 이사 당일 짐이 문 앞에 쌓여 있으면 그 상황도 함께 알려 주세요.

# 오래된 도어락이라면 교체도 생각해 볼 만합니다
이사 들어온 집의 도어락이 언제 달렸는지 모르는 경우가 많습니다. / 번호판 글자가 닳아 지워졌거나 배터리를 넣어도 반응이 느리면 손보기보다 바꾸는 편이 나을 수 있습니다.
무조건 바꾸라고 권하지는 않습니다. / 쓸 만하면 [도어락 수리](doorlock-repair.html)로 손보고, 낡았으면 [도어락 교체](doorlock-replace.html)를 그때 말씀드립니다.

# 문을 열어야 할 때 거치는 확인
초기화 도중 잠겨서 문을 열어야 한다면 사시는 분인지부터 봅니다. / 이사 직후라 신분증 주소가 바뀌지 않았다면 계약서나 전입 관련 서류, 관리사무소 확인으로 대신할 수 있습니다.
가격은 상태를 본 다음 손대기 전에 먼저 알려드립니다. / 끝내 못 열게 되면 비용은 받지 않으며, 진행 방식은 [이용안내](guide.html)에 정리돼 있습니다.
@ 광진 자양동 출장열쇠 이사 도어락 점검

# 등록을 마친 뒤 며칠은 이렇게 지켜보세요
새 번호와 카드를 넣었다고 바로 끝난 건 아닙니다. / 처음 며칠은 식구마다 실제로 문을 열어 보면서 누락된 사람이 없는지 확인하는 기간으로 두세요.
출근하는 사람, 학교 가는 아이, 가끔 들르는 부모님까지 각자 한 번씩 밖에서 열어 보는 게 가장 확실합니다. / 누군가 막히면 그 자리에서 바로 다시 등록하면 되니 번거로운 일이 커지지 않습니다.
배터리도 이때 같이 새것으로 바꿔 두면 좋습니다. / 전 거주자가 언제 넣었는지 모르는 배터리는 이사 후 한두 달 만에 경고음을 내는 일이 많고, 교체한 날짜를 덮개 안쪽에 적어 두면 다음 교체 때 헷갈리지 않습니다.

# 자양동에서 가까운 광진구 다른 동네도 다닙니다
구의동, 광장동, 화양동, 군자동, 중곡동, 능동까지 광진구 어느 동네든 출동합니다. / 서울, 경기 전 지역 24시간 다니며 다른 곳은 [출장 지역](area.html)에서 보실 수 있습니다.
