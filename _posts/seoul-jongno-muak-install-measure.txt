# 무악동에서 도어락을 고르기 전에 줄자부터
무악동은 독립문역과 가까운 동네로, 언덕을 따라 주택과 다세대, 여러 동이 모인 주거 건물이 함께 있습니다. / 건물 연식이 제각각이라 같은 동네 안에서도 현관문 두께와 구조가 많이 다릅니다.
인터넷에서 마음에 드는 도어락을 먼저 사 두었다가 문에 안 맞아 반품하는 분이 적지 않습니다. / 사기 전에 문을 한 번만 재 두면 이런 수고를 덜 수 있습니다.
이 글은 무악동 현관문에 도어락을 달기 전에 직접 확인할 것들을 순서대로 정리했습니다. / 재기 어렵거나 헷갈리면 사진만 보내 주셔도 [종로 출장열쇠](seoul-jongno.html)에서 맞는지 봐 드립니다.
@ 무악동 현관문 두께 측정 도어락 설치

# 준비물은 줄자와 휴대폰이면 됩니다
따로 공구가 필요하지 않습니다. / 줄자 하나와 사진을 찍을 휴대폰만 있으면 대부분 확인할 수 있습니다.
- 줄자 또는 30센티 이상 되는 자
- 휴대폰 카메라
- 메모할 종이나 휴대폰 메모장
문은 열어 둔 상태에서 재는 게 편합니다. / 한 사람이 문을 잡아 주면 더 정확하게 잴 수 있습니다.

# 문 두께는 문 옆면에서 잽니다
문을 활짝 연 다음, 경첩 반대편 옆면에 줄자를 대고 안쪽 면에서 바깥쪽 면까지 잽니다. / 손잡이나 기존 도어락 바로 옆을 재는 것이 가장 정확합니다.
문 표면에 장식 테두리가 튀어나와 있다면 그 부분은 빼고 평평한 면 기준으로 재 주세요. / 도어락 몸체가 붙는 자리가 평평한 면이기 때문입니다.
대부분 도어락은 맞는 문 두께 범위를 상자나 설명서에 적어 둡니다. / 잰 두께가 그 범위 안에 들어오는지 꼭 확인하세요.
범위를 벗어나면 별도 부품이 필요하거나 아예 달 수 없는 경우도 있습니다. / 이때는 무리하게 맞추기보다 다른 제품을 고르는 게 낫습니다.

# 지금 문에 뚫린 구멍 확인하기
기존 손잡이나 도어락을 떼면 문에 구멍이 남아 있습니다. / 새 도어락이 이 구멍을 그대로 쓸 수 있는지가 설치를 쉽게 할지 어렵게 할지를 가릅니다.
기존 제품을 떼기 전이라면 앞뒤 사진을 찍고, 몸체 크기를 가로와 세로로 재 두세요. / 새 제품 몸체가 기존 것보다 작으면 예전 구멍이나 자국이 드러날 수 있습니다.
- 손잡이 구멍의 위치와 지름
- 문 옆면 걸쇠가 나오는 자리의 높이
- 문틀 쪽 걸쇠 받이 홈의 크기
구멍을 새로 뚫어야 한다면 문 재질이 무엇인지도 봐야 합니다. / 철문, 나무문, 방화문에 따라 작업 방식이 달라집니다.
@ 종로 무악동 기존 도어락 구멍 위치 확인

# 보조키 자리가 남아 있는지
무악동 오래된 주택이나 다세대는 도어락 위나 아래에 쇠 열쇠로 여는 보조키가 따로 달린 문이 많습니다. / 새 도어락을 달 때 이 보조키를 그대로 둘지, 뗄지 먼저 정해야 합니다.
보조키를 그대로 두면 이중 잠금이 되어 든든하지만, 도어락 몸체가 보조키와 겹쳐 붙지 않을 수 있습니다. / 두 장치 사이 간격을 재서 새 도어락 높이와 비교해 보세요.
보조키를 떼면 문에 구멍이 남습니다. / 구멍을 덮는 커버를 쓰거나 도어락 몸체로 가려지는지 미리 확인하면 깔끔하게 마무리됩니다.

# 문 재질과 방화문 여부
문을 손가락 마디로 가볍게 두드려 보면 소리로 재질을 어느 정도 짐작할 수 있습니다. / 묵직하게 막힌 소리가 나면 철문이나 방화문, 가볍게 울리면 나무문인 경우가 많습니다.
방화문은 안쪽에 채움재가 들어 있어 구멍을 새로 뚫을 때 작업이 까다롭습니다. / 문 옆면이나 경첩 쪽에 붙은 표시 스티커가 있다면 사진을 함께 보내 주세요.
나무문은 오래되면 구멍 주변이 갈라져 있기도 합니다. / 새 도어락 나사가 단단히 박힐 자리가 남아 있는지 미리 보는 게 좋습니다.

# 문이 어느 쪽으로 열리는지
안에서 봤을 때 경첩이 왼쪽에 있는지 오른쪽에 있는지 확인해 주세요. / 밀어서 여는지 당겨서 여는지도 함께 봅니다.
푸시풀 도어락은 손잡이를 밀거나 당겨 여는 방식이라 문 방향에 따라 설정이 달라집니다. / 대부분 설치할 때 방향을 바꿀 수 있지만, 제품에 따라 한쪽만 되는 경우도 있습니다.
문 옆에 벽이나 신발장이 가까이 붙어 있다면 손잡이가 튀어나온 만큼 공간이 있는지도 봐 주세요. / 문을 열 때 손잡이가 벽에 부딪히면 매일 불편합니다.

# 문틀과 문 사이 틈도 봐 두세요
문을 닫았을 때 문과 문틀 사이 틈이 위아래로 고른지 살펴보세요. / 위쪽은 넓고 아래쪽은 좁다면 문이 처진 것입니다.
처진 문에 새 도어락을 달면 걸쇠가 문틀 홈에 제대로 안 들어가 잠금 실패가 잦아집니다. / 설치 전에 경첩을 조정해 문 높이를 먼저 맞추는 게 순서입니다.
도어클로저가 너무 세게 닫히는 문도 새 도어락에 충격을 줍니다. / 닫히는 속도가 빠르면 설치할 때 같이 조정하는 게 좋습니다.

# 사진은 이렇게 찍어 보내 주세요
직접 재기가 어렵다면 사진으로도 상당 부분 확인할 수 있습니다. / 아래 네 장이면 충분합니다.
- 바깥에서 본 문 전체
- 안쪽에서 본 기존 도어락과 보조키
- 문 옆면, 걸쇠가 나오는 부분을 가까이
- 문틀 쪽 걸쇠 받이 홈
사진 옆에 줄자를 대고 찍으면 크기를 짐작하기 훨씬 쉽습니다. / 문 두께 숫자만 메모로 함께 보내 주셔도 됩니다.

# 제품을 먼저 사 두셨다면
이미 사 두신 도어락이 있다면 제품 이름과 상자 사진을 보내 주세요. / 맞는 문 두께와 필요한 구멍 크기를 보고 설치가 되는지 미리 말씀드립니다.
설치가 어렵다고 판단되면 그 이유를 설명드립니다. / 억지로 맞춰 달았다가 잠금이 불안하면 오히려 손해이기 때문입니다.

# 방문 설치는 이렇게 진행됩니다
도착하면 문 두께와 구멍, 문틀 상태를 다시 한 번 재고 확인합니다. / 설치 비용은 이때 먼저 말씀드리고, 동의하시면 시작합니다.
기존 도어락을 떼고, 필요하면 구멍을 다듬은 뒤 새 제품을 답니다. / 다 단 다음에는 번호와 카드를 등록하고 잠금을 여러 번 시험합니다.
설치와 교체 과정은 [도어락 설치](doorlock-install.html)와 [도어락 교체](doorlock-replace.html) 페이지에 더 자세히 적어 두었습니다. / 지금 쓰는 도어락이 고쳐 쓸 만하다면 [도어락 수리](doorlock-repair.html)를 먼저 권해 드립니다.
@ 무악동 새 도어락 설치 후 잠금 시험

# 설치 당일 확인할 것
설치를 마친 뒤에는 꼭 문을 닫은 상태에서 밖에서 열어 보세요. / 안에서 잘 되더라도 밖에서 번호, 카드, 지문을 모두 써 봐야 진짜 끝입니다.
비상 열쇠가 함께 오는 제품이라면 열쇠도 직접 꽂아 돌려 보세요. / 사용 설명서와 비상 열쇠는 집 안 한곳에 같이 보관해 두면 나중에 찾기 쉽습니다.
진행 방식은 [이용안내](guide.html)에서도 미리 보실 수 있습니다.

? 구멍을 새로 뚫어야 하나요? | 기존 구멍을 쓸 수 있는 경우가 많습니다. 안 맞으면 다듬거나 새로 뚫습니다.
