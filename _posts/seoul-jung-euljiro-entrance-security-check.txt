# 을지로동 출입문, 겁먹기보다 습관으로
을지로동은 오래된 상가와 작은 사무실, 작업장이 층층이 들어선 건물이 많은 동네입니다. / 위층에 사람이 사는 건물도 있어서 한 건물 안에 일터 문과 집 현관이 같이 있기도 합니다.
방범이라고 하면 비싼 장비부터 떠올리기 쉽지만, 실제로는 잠금장치가 제대로 걸리는지 확인하는 습관이 더 중요합니다. / 문이 덜 닫힌 채 퇴근하거나 보조 잠금을 안 걸고 나가는 일이 더 흔하기 때문입니다.
이 글은 을지로동 사무실과 집 현관을 과하지 않게 점검하는 방법을 적었습니다. / 손볼 곳이 보이면 [서울 중구 출장열쇠](seoul-jung.html)로 상담하셔도 됩니다.
@ 을지로동 사무실 현관 잠금 점검

# 점검은 이렇게 생각하면 쉽습니다
방범 점검은 결국 세 가지 질문으로 정리됩니다. / 문이 끝까지 닫히는지, 잠금이 제대로 걸리는지, 열쇠와 번호를 누가 알고 있는지입니다.
이 셋만 꾸준히 챙겨도 대부분의 걱정은 줄어듭니다. / 장비를 새로 들이는 건 그다음에 생각해도 늦지 않습니다.
아래 항목은 퇴근하면서, 외출하면서 5분 안에 볼 수 있는 것들입니다. / 한 번에 다 하지 않아도 되니 하나씩 습관으로 만들어 보세요.

# 문이 끝까지 닫히는지 보기
도어클로저가 달린 문은 저절로 닫히는 것처럼 보여도 마지막 몇 센티에서 멈추는 경우가 있습니다. / 이러면 잠금쇠가 문틀에 들어가지 못해 잠긴 것처럼 보이기만 합니다.
- 문을 놓고 끝까지 닫히는지 한 번 지켜보기
- 닫힌 뒤 손잡이를 당겨 덜컥거리지 않는지 확인
- 문 아래나 옆 틈으로 빛이 크게 새지 않는지 보기
닫힘이 약하다면 도어클로저 속도 조절이나 경첩 점검이 필요합니다. / 이 부분은 오래된 건물일수록 자주 생깁니다.

# 잠금이 제대로 걸렸는지 확인
도어락은 닫히면 자동으로 잠기는 제품이 많지만, 설정이 수동으로 바뀌어 있을 수도 있습니다. / 나갈 때 잠기는 소리가 났는지 귀로 한 번 확인하는 습관이 좋습니다.
보조키나 걸쇠가 따로 있다면 퇴근할 때 함께 거는지 정해 두세요. / 사무실처럼 마지막에 나가는 사람이 매일 바뀌는 곳은 이 부분이 자주 빠집니다.
문에 마지막 퇴실자 확인표를 붙여 두는 사무실도 있습니다. / 복잡한 장치보다 간단한 약속이 효과가 좋습니다.
@ 을지로동 도어락 보조키 잠금 확인

# 번호와 열쇠, 누가 알고 있나요
사무실은 직원이 바뀌고, 집은 공사나 이사로 사람이 드나듭니다. / 그때마다 번호와 열쇠가 어디까지 퍼졌는지 모르는 상태가 되기 쉽습니다.
- 퇴사자나 이전 세입자가 알던 번호가 그대로인지
- 복사한 열쇠가 몇 개인지, 누가 가지고 있는지
- 청소나 수리 업체에 알려 준 번호를 바꿨는지
하나라도 애매하면 번호를 바꾸는 것이 가장 쉬운 정리입니다. / 열쇠식이라면 실린더만 바꿔도 예전 열쇠는 쓸 수 없게 됩니다.

# 번호판과 손잡이 상태 살피기
번호판에서 자주 누르는 숫자만 반들반들하게 닳아 있다면 번호를 짐작하기 쉬워집니다. / 번호를 바꾸거나 누른 뒤 손으로 한 번 쓸어 주는 것도 방법입니다.
손잡이나 몸체가 흔들리면 고정 나사가 풀린 것입니다. / 흔들리는 상태로 오래 쓰면 내부 부품까지 헐거워질 수 있습니다.
경고음이 나는데 무시하고 지냈다면 건전지부터 바꿔 주세요. / 건전지가 약하면 잠금 동작이 덜 되는 경우도 있습니다.

# 오래된 건물에서 자주 보이는 것
을지로동 오래된 건물은 문틀이 처져 잠금쇠가 반만 들어가는 경우가 있습니다. / 겉보기엔 잠긴 것 같아도 손잡이를 세게 당기면 덜컥거립니다.
열쇠 실린더가 너무 오래돼 열쇠가 헐겁게 도는 경우도 있습니다. / 이런 부분은 점검 때 같이 보시면 좋습니다.
문 자체보다 계단실 출입문이나 건물 뒷문이 늘 열려 있는 경우도 있습니다. / 이 부분은 건물 관리 쪽과 이야기해 보실 일입니다.

# 걱정을 키우지 않는 범위에서
방범 점검은 불안해하기 위해서가 아니라 마음 편히 문을 닫고 나가기 위한 것입니다. / 이미 잘 잠기는 문에 장치를 계속 덧붙일 필요는 없습니다.
지금 쓰는 도어락이 제대로 동작하고, 번호를 아는 사람이 정리돼 있다면 기본은 된 셈입니다. / 거기에 문 닫힘만 잘 챙기면 충분한 경우가 많습니다.
점검을 받아 보면 손볼 곳이 하나도 없는 문도 많습니다. / 그럴 때는 그대로 쓰시라고 말씀드리고, 굳이 바꾸지 않아도 되는 부품을 권하지 않습니다.
@ 을지로동 출입문 닫힘 상태 확인

# 점검 상담 요청할 때 알려 주실 것
현장을 보기 전에 아래를 알려 주시면 필요한 부품과 시간을 가늠할 수 있습니다. / 사진이 있으면 더 좋습니다.
- 사무실인지 집인지, 건물 몇 층인지
- 도어락 종류와 보조키 유무
- 문이 덜 닫히는지, 손잡이가 흔들리는지
- 번호 변경이나 실린더 교체를 원하시는지
@ 을지로동 출장열쇠 현관 점검 상담

# 작업 전 확인하는 것
번호 변경이나 실린더 교체도 그 문을 쓰시는 분인지 확인한 뒤 진행합니다. / 사무실은 사업자 서류나 건물 관리 쪽 확인, 집은 신분증 주소나 우편물이면 됩니다.
남의 문 잠금장치를 바꿔 주는 일이 없도록 하는 절차라 번거로우셔도 이해 부탁드립니다. / 대표자가 자리에 없다면 전화로 확인을 받는 방법도 있습니다.
세입자분이 실린더를 바꾸실 때는 건물주와 미리 이야기해 두시면 나중에 열쇠를 돌려줄 때 편합니다.

# 비용 안내 방식
점검해 보고 손볼 곳을 하나씩 말씀드린 다음, 무엇을 할지 고르시게 합니다. / 금액은 작업 전에 먼저 알려 드리고, 원하지 않는 작업은 하지 않습니다.
잠긴 문을 여는 출동이었다면 못 열 경우 비용은 받지 않습니다. / 자세한 흐름은 [이용안내](guide.html)에 있습니다.
여러 문을 한 번에 점검받고 싶다면 전화로 문 개수와 종류를 미리 알려 주세요. / 사무실 출입문, 창고 문, 위층 집 현관처럼 나눠 말씀해 주시면 순서를 정해 한 번에 봐 드립니다.
영업 중에 작업하기 어려운 곳이라면 퇴근 뒤나 이른 아침처럼 편한 시간을 잡으셔도 됩니다.

# 손볼 곳이 나왔다면
도어락이 아직 쓸 만하면 [도어락 수리](doorlock-repair.html)로 손보는 쪽을 먼저 권합니다. / 너무 오래돼 부품이 없으면 [도어락 교체](doorlock-replace.html)를, 지금 문에 도어락이 없다면 [도어락 설치](doorlock-install.html)를 안내합니다.
문이 잠겨서 못 들어가는 상황이라면 [현관문 개문](door-open.html)부터 진행합니다.

# 을지로동 주변 중구 동네
을지로동과 가까운 명동, 필동, 회현동은 물론 신당동, 황학동, 청구동, 약수동, 다산동, 중림동까지 출동합니다. / 중구 안내는 [서울 중구 출장열쇠](seoul-jung.html), 전체 지역은 [출장 지역](area.html)에서 보세요.

# 자주 묻는 질문
? 사무실 직원이 바뀌면 번호를 꼭 바꿔야 하나요? | 번호를 아는 사람이 정리되지 않았다면 바꾸는 게 가장 간단한 정리입니다.
? 문이 끝까지 안 닫히는 것도 봐 주시나요? | 도어클로저 속도와 경첩, 잠금쇠 위치를 함께 봐 드립니다.
? 점검만 받아도 되나요? | 네, 손볼 곳을 말씀드리고 원하시는 작업만 진행합니다.
? 열쇠 복사본이 너무 많아졌어요 | 실린더를 바꾸면 기존 열쇠는 모두 쓸 수 없게 됩니다.
? 비용은 언제 알 수 있나요? | 문 상태를 본 뒤 작업 전에 먼저 말씀드립니다.

# 마무리
을지로동 사무실과 집 현관은 문 닫힘, 잠금 확인, 번호 관리 세 가지만 챙겨도 훨씬 든든해집니다. / 손볼 곳이 보이거나 문이 잠겨 들어가지 못하면 편하게 전화 주세요.
점검은 한 번으로 끝내기보다 계절이 바뀔 때마다 짧게 되풀이하는 편이 효과가 오래갑니다.
