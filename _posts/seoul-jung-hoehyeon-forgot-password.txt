# 회현동 문 앞에서 번호가 하얘졌을 때
회현동은 명동과 맞닿아 있으면서 아파트와 주택, 사무실 건물이 함께 있는 동네입니다. / 낮에는 일터로, 밤에는 집으로 쓰이는 건물이 섞여 있어 도어락 번호를 여러 개 외우고 사는 분이 많습니다.
회사 번호, 부모님 댁 번호, 우리 집 번호가 머릿속에서 엉키면 정작 내 집 앞에서 손가락이 멈춥니다. / 가족 중 누군가 번호를 바꿔 놓고 말을 안 했다면 더 답답합니다.
이 글은 회현동에서 비밀번호 때문에 문이 안 열릴 때 무엇을 먼저 해 보고, 언제 [서울 중구 출장열쇠](seoul-jung.html)를 부르면 되는지 정리했습니다.
@ 회현동 도어락 비밀번호 분실 문 앞

# 잊은 건지 바뀐 건지부터 구분
번호가 생각나지 않는 상황은 크게 둘로 나뉩니다. / 어느 쪽인지에 따라 해 볼 수 있는 일이 다릅니다.
내가 쓰던 번호가 아예 기억나지 않는다면 기억을 되살리는 쪽이 먼저입니다. / 반대로 분명히 맞는 번호인데 틀렸다고 나온다면 누군가 바꿨을 가능성을 생각해 보세요.
가족 중 한 명이 최근 번호를 바꿨다는 말을 흘렸는지, 이사나 공사로 사람이 드나든 적은 없는지 떠올려 보시면 실마리가 잡힙니다.

# 기억을 되살리는 작은 요령
번호를 억지로 떠올리기보다 손이 기억하게 두는 편이 낫습니다. / 번호판 앞에서 평소처럼 서서 숫자를 보지 말고 손가락 움직임만 따라가 보세요.
- 번호판 위 손때가 묻은 숫자가 어디인지 살펴보기
- 예전에 쓰던 번호에서 한 자리만 바꾼 건 아닌지 떠올리기
- 휴대폰 메모나 가족 대화방에 번호를 적어 둔 적이 있는지 찾기
- 생일, 기념일, 차 번호처럼 자주 쓰는 숫자 조합 떠올리기
다만 이것저것 마구 눌러 보는 건 피하세요. / 몇 번 틀리면 도어락이 입력을 막아 버립니다.

# 틀리면 입력이 잠기는 이유
대부분의 도어락은 번호를 연속으로 여러 번 틀리면 일정 시간 동안 버튼을 받지 않습니다. / 낯선 사람이 번호를 맞히려고 계속 누르는 걸 막기 위한 기능입니다.
이때 경고음이 크게 울리기도 해서 밤에는 이웃이 놀라기도 합니다. / 입력이 막혔다면 몇 분 기다렸다가 다시 시도하되, 확실하지 않은 번호는 누르지 마세요.
세 번쯤 해 보고도 안 되면 그 자리에서 멈추는 게 좋습니다. / 계속 누를수록 잠기는 시간이 길어지는 제품도 있습니다.
@ 회현동 도어락 입력 잠금 경고음

# 가족에게 먼저 연락해 보기
같이 사는 가족이 번호를 바꿨을 가능성이 있다면 전화 한 통이 가장 빠른 해결입니다. / 출근 중이거나 연락이 안 되더라도 문자로 남겨 두면 나중에 답이 옵니다.
부모님이 자녀 집 번호를 대신 바꿔 준 경우, 반대로 자녀가 부모님 댁 번호를 바꾼 경우도 흔합니다. / 회현동처럼 가족이 가까이 따로 사는 동네라면 서로 집 번호를 챙겨 주다가 엇갈리기도 합니다.
가족도 번호를 모른다면 그때 출장을 부르셔도 늦지 않습니다.

# 카드나 지문으로는 열리나요
번호 말고 다른 방법이 등록된 도어락이라면 그걸로 먼저 들어가세요. / 카드키를 열쇠고리에 달고 다니는 분이 의외로 많습니다.
지문이 등록돼 있다면 손가락 물기를 닦고 천천히 대 보세요. / 비상 열쇠 구멍이 있는 제품이라면 집 밖 어딘가에 열쇠를 맡겨 두지 않았는지도 생각해 보세요.
이 중 하나라도 되면 안으로 들어가서 번호를 새로 등록하면 끝납니다.
카드나 지문도 안 된다면 도어락 전원부터 의심해 보세요. / 번호판 불빛이 평소보다 흐리면 건전지가 약해진 것이라 9V 건전지 비상 전원을 대고 다시 해 볼 수 있습니다.

# 하지 않으셨으면 하는 행동
번호판을 뜯어 보거나 건전지를 뺐다 넣으면 번호가 지워질 거라 생각하는 분도 있습니다. / 실제로는 바깥에서 건전지를 꺼낼 수 없고, 번호도 그렇게 지워지지 않습니다.
드라이버로 도어락 틈을 벌리면 외관만 상하고 문은 그대로입니다. / 인터넷에 떠도는 초기화 방법도 대부분 문 안쪽에서 해야 하는 일입니다.

# 출장 요청 전에 알려 주실 것
회현동은 건물마다 출입 방식이 달라서 미리 들으면 시간을 아낄 수 있습니다. / 짧게 아래만 말씀해 주세요.
- 아파트, 주택, 사무실 겸용 건물 중 어디인지
- 건물 입구 출입 카드가 따로 필요한지
- 도어락이 번호만 되는지, 카드나 지문도 되는지
- 지금 입력이 잠겨 있는지, 경고음이 계속 나는지
도어락 앞면 사진을 보내 주시면 맞는 방법을 미리 고를 수 있습니다.
@ 회현동 출장열쇠 도어락 사진 문자 안내

# 본인 확인은 꼭 거칩니다
번호를 모르는 상황일수록 사시는 분인지 확인하는 절차가 중요합니다. / 신분증 주소, 이름이 적힌 우편물, 관리사무소나 경비실 확인 중 하나를 준비해 주세요.
신분증이 안에 있다면 문을 연 직후 보여 주셔도 됩니다. / 가족이 대신 확인해 줄 수 있다면 전화 연결도 도움이 됩니다.

# 금액은 시작 전에 정합니다
도어락 종류를 보고 문 여는 데 드는 비용을 먼저 말씀드립니다. / 들으시고 괜찮을 때만 시작하며, 못 열면 비용은 받지 않습니다.
새 번호 등록처럼 함께 해 드리는 일도 미리 말씀드립니다. / 진행 흐름은 [이용안내](guide.html)에, 개문 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 들어가서 새 번호 정하는 법
문이 열리면 안쪽 등록 버튼으로 기존 번호를 지우고 새 번호를 넣습니다. / 가족이 모두 있는 자리에서 정하면 다음에 엇갈릴 일이 줄어듭니다.
- 생일이나 전화번호 끝자리처럼 남이 짐작하기 쉬운 숫자는 피하기
- 여섯 자리 이상으로 정하고 가족만 아는 곳에 적어 두기
- 번호를 누른 뒤 번호판을 한 번 손으로 쓸어 손때 흔적 줄이기
번호 바꾸는 주기와 가족끼리 나누는 방법은 [도어락 수리](doorlock-repair.html) 상담 때 같이 여쭤보셔도 됩니다.

# 번호판이 낡았다면
오래 쓴 도어락은 자주 누르는 숫자만 닳아서 번호가 드러나 보이기도 합니다. / 버튼이 잘 안 눌리거나 몇 개만 반응이 늦다면 번호판 교체나 [도어락 교체](doorlock-replace.html)를 생각해 볼 때입니다.
번호를 정확히 눌렀는데도 틀렸다고 나온다면 기억이 아니라 버튼 쪽 문제일 수도 있습니다. / 특정 숫자를 눌렀을 때 삑 소리가 안 나거나 두 번 눌린 것처럼 들리면 꼭 말씀해 주세요.
이런 경우는 번호를 바꾸는 것만으로는 해결되지 않아서, 문을 연 뒤 번호판 상태를 함께 봐 드립니다. / 새로 바꾸기 전에 접점 청소나 부품 손질로 되살릴 수 있는지부터 확인합니다.

# 회현동 주변 중구도 다닙니다
회현동 옆 명동과 필동, 을지로동은 물론 중림동, 신당동, 약수동, 청구동, 다산동, 황학동까지 중구 전역에 갑니다. / 중구 안내는 [서울 중구 출장열쇠](seoul-jung.html)에서, 다른 곳은 [출장 지역](area.html)에서 보세요.
