# 황학동 현관문 소리가 거슬린다면
황학동은 신당동과 맞닿은 동네로, 아파트와 오래된 건물, 상가가 한데 모여 있습니다. / 사람과 물건이 많이 오가는 곳이라 현관문도 하루에 수십 번씩 열리고 닫히는 집이 많습니다.
그러다 보면 어느 날부터 문이 쾅 하고 닫히거나, 열 때마다 끼익 하는 소리가 나기 시작합니다. / 밤늦게 귀가할 때 이 소리 때문에 이웃 눈치가 보인다는 분도 많습니다.
소리는 문이 보내는 신호라서, 어떤 소리인지 알면 어디가 지쳤는지 대략 짐작할 수 있습니다. / 이 글은 황학동 현관문 소리를 종류별로 나눠 원인과 손볼 곳을 정리했습니다. 직접 하기 어렵다면 [서울 중구 출장열쇠](seoul-jung.html)로 연락 주세요.
@ 황학동 현관문 닫힘 소리 점검

# 소리를 먼저 구분해 보세요
문에서 나는 소리는 크게 네 가지로 나뉩니다. / 문을 천천히 여닫으면서 어느 순간에 어떤 소리가 나는지 들어 보세요.
- 닫힐 때 마지막에 쾅 하고 세게 부딪히는 소리
- 열거나 닫을 때 끼익 하고 길게 나는 소리
- 닫힐 때 툭 걸리면서 덜컥하는 소리
- 손잡이를 돌리거나 잠글 때 드르륵 긁히는 소리
각각 원인이 다르고 손볼 곳도 다릅니다. / 두 가지 이상이 같이 나는 문도 있으니 하나씩 짚어 보세요.

# 쾅 소리는 도어클로저부터
문 위에 달린 도어클로저는 문이 저절로 천천히 닫히게 해 주는 장치입니다. / 안쪽 기름이 줄거나 속도 조절 나사가 풀리면 마지막 구간에서 문이 확 빨라지며 쾅 닫힙니다.
클로저 옆면을 보면 작은 조절 나사가 두세 개 있는 경우가 많습니다. / 하나는 전체 닫힘 속도, 하나는 마지막 몇 센티 속도를 맡습니다.
드라이버로 아주 조금씩, 4분의 1바퀴 정도만 돌리며 문을 닫아 보세요. / 한 번에 많이 돌리면 나사가 빠지면서 기름이 샐 수 있습니다.
클로저 몸통 아래에 기름 자국이 번져 있다면 안쪽이 이미 상한 것이라 조절만으로는 돌아오지 않습니다. / 이때는 클로저 자체를 바꿔야 합니다.
@ 황학동 도어클로저 속도 조절 나사

# 끼익 소리는 경첩이 마른 것
문을 움직일 때마다 길게 끼익 하는 소리가 나면 경첩 핀이 말랐거나 녹이 슨 경우가 많습니다. / 위쪽 경첩에서 나는지 아래쪽에서 나는지 귀를 대 보면 대개 구분됩니다.
경첩 틈에 윤활제를 조금 넣고 문을 여러 번 여닫아 주면 소리가 줄어듭니다. / 너무 많이 뿌리면 흘러내려 문과 바닥이 지저분해지니 조금씩만 쓰세요.
윤활제를 넣어도 소리가 계속되거나 오히려 문이 내려앉는 느낌이 들면 경첩 핀이 닳은 것입니다. / 그럴 땐 경첩 점검이 필요합니다.

# 덜컥 걸린다면 문 위치가 틀어진 것
닫힐 때 툭 걸리면서 한 번 더 밀어야 잠긴다면 문이 처졌거나 문틀이 조금 틀어진 것입니다. / 문틀 쪽 잠금쇠 받이에 긁힌 자국이 있는지 확인해 보세요.
긁힌 자국이 한쪽으로 몰려 있다면 그쪽으로 문이 기운 것입니다. / 경첩 나사가 풀렸는지 먼저 보고, 풀렸다면 살짝 조여 주세요.
이 상태로 계속 세게 밀어 닫으면 잠금쇠와 문틀이 함께 닳습니다. / 나중에는 잠금이 덜 걸리거나 아예 안 잠기는 일이 생깁니다.

# 드르륵 소리는 잠금쇠와 도어락 쪽
손잡이를 돌리거나 문이 잠길 때 드르륵 긁히는 소리가 나면 잠금쇠가 받이에 비스듬히 들어가는 것입니다. / 도어락 모터가 평소보다 오래 돌거나 힘겨운 소리를 내기도 합니다.
이 소리는 도어락 건전지가 약할 때도 납니다. / 건전지를 새로 바꿔도 같다면 잠금쇠 위치를 맞춰야 할 때입니다.
그대로 두면 모터에 무리가 가서 [도어락 수리](doorlock-repair.html)가 필요해질 수 있습니다.
@ 황학동 도어락 잠금쇠 받이 긁힘

# 계절 따라 뻑뻑해지는 문
여름에는 습기와 열기로, 겨울에는 찬 공기로 철문과 문틀 틈이 달라집니다. / 그래서 특정 계절에만 문이 뻑뻑하거나 소리가 커지는 집이 있습니다.
낮에는 괜찮다가 아침저녁으로만 걸린다면 온도 차이 탓일 가능성이 큽니다. / 해마다 같은 계절에 같은 증상이 반복되면 문 위치를 한 번 맞춰 두는 것이 좋습니다.
현관 바닥 매트가 두꺼워 문 아래가 쓸리는 경우도 있습니다. / 의외로 매트만 바꿔도 뻑뻑함이 사라지는 집이 있습니다.

# 직접 해도 되는 것과 아닌 것
경첩에 윤활제 조금, 클로저 조절 나사 살짝, 경첩 나사 조임 정도는 집에서 해 보셔도 됩니다. / 다만 아래는 혼자 하지 않으시는 편이 안전합니다.
- 도어클로저를 문에서 떼어 내기
- 경첩을 풀어 문을 들어내기
- 문틀을 두드려 맞추기
- 도어락 몸체를 분해하기
철문은 무겁고 클로저는 안에 힘이 걸려 있어서 잘못 풀면 다칠 수 있습니다. / 해 보다가 조금이라도 불안하면 그 자리에서 멈추고 연락 주세요.

# 황학동 점검 요청할 때 알려 주실 것
전화로 아래를 말씀해 주시면 맞는 부품을 챙겨 갈 수 있습니다. / 문을 여닫는 짧은 영상을 보내 주시면 소리까지 들을 수 있어 더 좋습니다.
- 어떤 소리가 언제 나는지
- 도어클로저가 달려 있는지, 기름이 새는지
- 문이 잘 잠기는지, 한 번 더 밀어야 하는지
- 아파트, 빌라, 상가 중 어디인지
@ 황학동 출장열쇠 현관문 소리 영상

# 작업 전 확인
점검과 수리도 그 문을 쓰시는 분인지 간단히 확인한 뒤 시작합니다. / 집이라면 신분증이나 우편물, 상가라면 운영하시는 분 확인이면 됩니다.
건물 공용 출입문의 도어클로저라면 관리하시는 분과 먼저 이야기가 돼 있어야 합니다. / 여러 세대가 함께 쓰는 문은 혼자 정할 수 없는 경우가 많기 때문입니다.
세 들어 사는 집이라면 클로저나 경첩을 바꾸기 전에 집주인께 알려 두시면 나중에 서로 편합니다.

# 비용은 이렇게 안내합니다
소리 원인을 찾은 뒤 조절로 끝날지, 부품을 바꿔야 할지 나눠서 먼저 말씀드립니다. / 금액도 작업 전에 알려 드리고, 원하시는 것만 진행합니다.
문이 잠겨 열어야 하는 상황이라면 못 열 경우 비용은 받지 않습니다. / 자세한 흐름은 [이용안내](guide.html)에, 잠긴 문 여는 방법은 [현관문 개문](door-open.html)에 있습니다.

# 오래 조용히 쓰는 습관
- 문을 놓아서 닫지 말고 손으로 끝까지 잡아 주기
- 바람 부는 날 창문을 열어 둘 때 현관문이 세게 닫히지 않게 주의
- 해마다 한 번 경첩 나사와 클로저 기름 자국 확인
- 도어락 경고음이 나면 그날 바로 건전지 교체
문 소리가 처음 들릴 때 손보면 부품을 갈지 않고 끝나는 경우가 많습니다. / 도어락까지 오래돼 함께 바꿀 생각이 있다면 [도어락 교체](doorlock-replace.html)도 함께 상담해 드립니다.

# 황학동 가까운 중구 동네
황학동과 이웃한 신당동, 청구동, 약수동, 다산동은 물론 명동, 을지로동, 필동, 회현동, 중림동까지 출동합니다. / 중구 안내는 [서울 중구 출장열쇠](seoul-jung.html), 다른 지역은 [출장 지역](area.html)에서 보세요.
