# 신당동 도어락 알림이 조용해졌다면
신당동은 신당역을 중심으로 아파트와 빌라, 주택, 상가가 넓게 퍼져 있는 동네입니다. / 새로 도어락을 바꾸면서 휴대폰으로 출입 알림을 받거나 밖에서 문을 여는 기능을 쓰는 집도 늘었습니다.
그런데 어느 날부터 아이가 하교했는데도 알림이 안 오거나, 앱에서 도어락이 오프라인으로 뜨는 일이 생깁니다. / 문은 멀쩡히 열리는데 연결만 끊긴 경우가 대부분이라, 순서대로 짚어 보면 집에서 풀리는 일이 많습니다.
이 글은 신당동에서 도어락 앱 연동과 알림 문제가 생겼을 때 확인할 순서를 적었습니다. / 문까지 안 열린다면 [서울 중구 출장열쇠](seoul-jung.html)로 바로 연락 주세요.
@ 신당동 스마트 도어락 앱 알림 끊김

# 문이 열리는지부터 나누기
연동 문제와 도어락 고장은 따로 봐야 합니다. / 번호나 카드로 문이 정상적으로 열리고 닫힌다면 도어락 본체는 괜찮고, 연결 고리 어딘가가 끊긴 것입니다.
반대로 번호판도 반응이 없고 문도 안 열린다면 연동이 아니라 전원이나 도어락 자체 문제입니다. / 이 경우는 앱을 만지기보다 문을 여는 일이 먼저입니다.
아래 내용은 문은 열리는데 알림이나 원격 기능만 안 되는 경우를 기준으로 적었습니다.

# 휴대폰 쪽부터 확인
가장 흔한 원인은 휴대폰 설정입니다. / 운영체제 업데이트 뒤에 알림 권한이 꺼지거나 배터리 절약 기능이 앱을 멈추는 일이 잦습니다.
- 앱 알림 권한이 켜져 있는지
- 배터리 절약이나 절전 모드에서 앱이 제외돼 있는지
- 앱이 최신 버전인지, 로그인이 풀리지 않았는지
- 블루투스와 위치 권한이 필요한 앱이라면 켜져 있는지
가족 중 한 사람만 알림이 안 온다면 거의 휴대폰 쪽 문제입니다. / 모두 안 온다면 집 쪽 연결을 의심해 보세요.

# 집 공유기 바꾼 적 있나요
와이파이로 연결하는 도어락은 공유기 이름이나 비밀번호가 바뀌면 연결이 끊깁니다. / 인터넷 회사를 바꿨거나 공유기를 새로 단 뒤부터 알림이 안 온다면 이 경우일 가능성이 큽니다.
공유기가 현관에서 멀거나 벽이 두꺼우면 신호가 약해 자주 끊길 수 있습니다. / 공유기를 거실 안쪽 방에 둔 집이나 현관이 긴 복도 끝에 있는 집에서 이런 일이 종종 있습니다.
도어락은 대개 2.4GHz 대역 와이파이만 잡는 제품이 많습니다. / 공유기가 5GHz 신호만 내보내도록 설정돼 있다면 연결이 안 될 수 있습니다.
@ 신당동 현관 도어락 와이파이 신호

# 중계 장치나 허브가 있다면
도어락과 공유기 사이에 작은 중계 장치를 꽂아 쓰는 제품도 있습니다. / 이 장치의 플러그가 빠졌거나 멀티탭 전원이 꺼져 있으면 알림이 끊깁니다.
대청소를 하다가 콘센트를 바꿔 꽂았는지, 멀티탭 스위치를 껐는지 떠올려 보세요. / 장치 불빛이 평소와 다른 색이라면 다시 꽂고 몇 분 기다려 보세요.
중계 장치를 현관 쪽 콘센트로 옮기기만 해도 연결이 안정되는 경우가 있습니다.

# 도어락 건전지가 약하면 연결이 먼저 끊깁니다
건전지가 약해지면 도어락은 문을 여닫는 데 전기를 우선 쓰고 통신 기능을 줄이기도 합니다. / 그래서 문은 열리는데 알림만 늦거나 안 오는 증상이 먼저 나타납니다.
경고음이 나지 않았더라도 건전지를 바꾼 지 오래됐다면 새것으로 한꺼번에 갈아 보세요. / 이것만으로 알림이 돌아오는 경우가 꽤 많습니다.
통신 모듈이 따로 건전지를 쓰는 제품도 있으니 설명서나 덮개 안쪽을 확인해 보세요.

# 다시 연결하는 기본 순서
위를 다 확인했는데도 안 된다면 연결을 처음부터 다시 잡는 방법이 있습니다. / 제품마다 방법이 조금씩 다르니 앱 안내를 따라가시면 됩니다.
- 앱에서 기존 도어락 등록을 지우기
- 도어락 안쪽 등록 버튼으로 연결 모드 들어가기
- 휴대폰을 현관 가까이 두고 새로 등록하기
- 등록 뒤 가족 계정을 다시 초대하기
연결 모드에 들어가는 버튼을 잘못 누르면 비밀번호나 지문이 지워지는 제품도 있습니다. / 버튼 위치가 헷갈린다면 무리하지 말고 상담을 받는 편이 안전합니다.
@ 신당동 도어락 앱 재연결 순서

# 원격 열림을 쓸 때 주의할 점
앱으로 밖에서 문을 열 수 있는 기능은 편하지만, 연결이 끊기면 그 기능에만 기대던 가족이 문 앞에서 막힙니다. / 원격 열림을 쓰더라도 번호나 카드는 꼭 함께 쓰도록 해 두세요.
가족 계정을 너무 많이 초대해 두지 않는 것도 중요합니다. / 이사 간 사람이나 예전에 잠깐 쓴 사람의 계정은 정리해 두세요.
휴대폰을 바꿀 때는 새 폰에서 로그인이 되는지 확인한 뒤 옛 폰을 정리하세요.

# 알림 기록을 똑똑하게 쓰는 법
연결이 다시 잡히면 알림 기록을 한 번 훑어보세요. / 끊겼던 동안의 출입 기록이 나중에 한꺼번에 들어오는 제품도 있고, 아예 비어 있는 제품도 있습니다.
기록이 비어 있다고 해서 누가 드나들었다는 뜻은 아닙니다. / 연결이 끊긴 시간에는 기록이 남지 않는 경우가 많으니 지나치게 걱정하지 않으셔도 됩니다.
알림이 너무 많아 끄고 싶다면 전부 끄기보다 문 열림 알림만 남겨 두는 방식을 권합니다. / 아이가 혼자 귀가하는 집이라면 그 알림 하나가 가장 쓸모 있습니다.

# 출장 점검이 필요한 경우
아래처럼 집에서 풀기 어려운 경우라면 점검을 받는 게 낫습니다. / 연결 문제와 도어락 문제가 함께 섞여 있을 때가 많습니다.
- 재연결을 해도 몇 시간 만에 다시 끊기는 경우
- 알림 기록에 실제와 다른 출입이 찍히는 경우
- 연결 모드 버튼을 찾을 수 없거나 눌러도 반응이 없는 경우
- 통신 기능이 고장 나 도어락까지 오작동하는 경우
이런 경우 [도어락 수리](doorlock-repair.html)로 먼저 확인하고, 통신 부품을 구할 수 없으면 [도어락 교체](doorlock-replace.html)를 상의합니다.

# 신당동 출장 요청할 때 알려 주실 것
아래를 미리 말씀해 주시면 점검 시간이 줄어듭니다. / 앱 화면을 캡처해 보내 주셔도 좋습니다.
- 도어락 제품 사진과 앱 이름
- 문은 열리는지, 알림만 안 오는지
- 공유기나 인터넷을 최근에 바꿨는지
- 아파트, 빌라, 주택 중 어디인지

# 확인과 비용 안내
도어락 설정을 만지는 작업도 그 집에 사시는 분인지 먼저 확인합니다. / 신분증 주소나 우편물, 관리사무소 확인 중 하나면 됩니다.
점검해 보고 무엇이 문제인지, 무엇을 할지, 얼마인지 먼저 말씀드린 뒤 동의하시면 진행합니다. / 잠긴 문을 여는 출동이라면 못 열 경우 비용은 없습니다. 자세한 흐름은 [이용안내](guide.html)에 있습니다.

# 신당동 주변 중구도 다닙니다
신당동 가까운 황학동, 청구동, 약수동, 다산동은 물론 명동, 을지로동, 필동, 회현동, 중림동까지 다닙니다. / 중구는 [서울 중구 출장열쇠](seoul-jung.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
