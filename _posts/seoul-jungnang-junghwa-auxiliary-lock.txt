# 중화동 현관문이 한 뼘만 열리고 멈췄다면
번호를 누르니 도어락은 분명 열렸는데 문이 한 뼘쯤 열리다 덜컥 멈추는 경우가 있습니다. / 틈으로 들여다보면 안쪽 걸쇠가 문틀 고리에 걸려 팽팽하게 버티고 있습니다.
반대로 문이 아예 꿈쩍하지 않는데 도어락은 열렸다는 소리를 내는 날도 있습니다. / 이럴 때는 손으로 돌려 잠그는 보조키가 잠겨 있는 경우가 많습니다.
중화역 근처 빌라와 아파트에서 자주 듣는 상황입니다. / 이 글은 걸쇠와 보조키에 막혔을 때 해 볼 일과 손을 멈춰야 할 때를 나눠 적었습니다.
@ 중화동 현관 걸쇠 보조키 걸림 출장열쇠

# 보조키와 걸쇠는 생김새부터 다릅니다
같은 보조 잠금이라도 종류에 따라 막히는 모습이 다릅니다. / 우리 집 문 안쪽에 무엇이 달려 있는지 떠올려 보세요.
- 손잡이를 돌려 잠그는 보조키: 잠기면 문이 전혀 안 열림
- 문틀 고리에 거는 U자 모양 걸쇠: 문이 한 뼘쯤 열리다 멈춤
- 사슬을 홈에 끼우는 체인 걸쇠: 문이 손가락 몇 개 틈만큼 열림
보조키는 밖에서 열쇠로 풀 수 있는 제품도 있지만, 걸쇠는 대부분 안에서만 풀 수 있게 만들어져 있습니다. / 그래서 걸쇠가 걸렸다면 밖에서 할 수 있는 일이 많지 않습니다.

# 먼저 안에 누가 있는지 확인하세요
걸쇠가 걸려 있다는 것은 누군가 안에서 걸었다는 뜻일 가능성이 큽니다. / 문틈으로 이름을 부르거나 식구에게 전화를 걸어 보세요.
안에서 대답이 있다면 걸쇠를 풀어 달라고 하면 끝납니다. / 아이라면 문을 조금 닫아야 걸쇠가 풀린다는 것을 차근차근 알려 주세요.
걸쇠는 문이 팽팽하게 당겨진 상태에서는 잘 안 빠집니다. / 밖에서 문을 살짝 밀어 닫아 주면 안에서 풀기가 훨씬 쉬워집니다.
체인 걸쇠라면 사슬 끝 동그란 머리를 홈 끝까지 밀어서 빼야 풀립니다. / 문이 당겨져 있으면 사슬이 팽팽해 빠지지 않으니 이때도 문을 먼저 살짝 닫아 주세요.
어르신께 전화로 설명할 때는 걸쇠를 위로 들어 올리는지, 옆으로 밀어서 빼는지 생김새를 먼저 여쭤보세요. / 우리 집 걸쇠 모양을 미리 알아 두면 설명이 짧아집니다.

# 안에서 대답이 없다면
어르신이나 몸이 불편한 식구가 혼자 계신 집인데 대답이 없다면 걱정이 앞섭니다. / 이런 경우는 열쇠 문제보다 사람의 안전이 먼저이니 119에 먼저 연락하세요.
주무시고 계시거나 소리를 못 들으시는 경우도 많습니다. / 전화를 여러 번 걸어 보고, 그래도 연락이 안 되면 바로 저희에게도 상황을 말씀해 주세요.

# 아무도 없는데 걸쇠가 걸렸다면
드물지만 사람이 없는데도 걸쇠가 걸리는 일이 있습니다. / U자 걸쇠가 헐거워져 덜렁거리다가 문이 닫힐 때 고리에 저절로 얹히는 경우입니다.
나갈 때 문을 세게 닫았거나 바람에 문이 쾅 닫혔다면 이런 일이 생길 수 있습니다. / 그날 아침 걸쇠를 만진 사람이 없는데 걸려 있다면 이 경우를 떠올려 보세요.
이렇게 걸린 걸쇠는 밖에서 풀기가 쉽지 않습니다. / 문틈으로 무리하게 건드리지 말고 연락 주세요.

# 틈으로 손이나 도구를 넣지 마세요
한 뼘 틈이 있으니 손을 넣어 걸쇠를 풀어 보고 싶어집니다. / 하지만 팽팽하게 걸린 걸쇠는 손으로 밀어지지 않고, 문이 바람에 밀려 닫히면 손가락을 다칠 수 있습니다.
옷걸이나 막대를 넣어 걸쇠를 들어 올리는 것도 권하지 않습니다. / 걸쇠 고정 나사가 문틀에서 뜯겨 나오거나 문 안쪽 마감이 긁혀 수리할 곳이 늘어납니다.
@ 중화동 문틈 걸쇠 무리하게 풀지 않기

# 보조키가 잠기고 열쇠가 없을 때
안에서 보조키를 돌려 잠근 채 다른 문으로 나간 식구가 있거나, 아이가 장난으로 돌려 놓았을 수 있습니다. / 바깥쪽에 열쇠 구멍이 있는 보조키라면 가족 중 누가 열쇠를 갖고 있는지 먼저 물어보세요.
바깥쪽에 열쇠 구멍이 없는 보조키라면 안에서만 풀 수 있는 구조입니다. / 이 경우는 상하지 않게 여는 방법을 찾아야 하니 사진과 함께 연락 주세요.

# 열쇠는 있는데 보조키가 안 돌 때
보조키 열쇠를 꽂았는데 반쯤만 돌고 멈춘다면 문이 처져 보조키 잠금쇠가 문틀에 물려 있는 경우가 많습니다. / 문을 몸 쪽으로 살짝 당기거나 밀면서 다시 돌려 보세요.
그래도 안 돌면 힘을 더 주지 마세요. / 오래 쓴 열쇠는 이때 휘거나 부러지기 쉽고, 부러지면 일이 하나 더 늘어납니다.
열쇠 구멍 안이 오래돼 뻑뻑하다면 흑연 가루처럼 마른 윤활제를 조금 넣는 방법도 있습니다. / 식용유나 일반 기름은 먼지가 엉겨 더 막히게 하니 쓰지 마세요.

# 걸쇠 사진과 함께 전할 내용
아래 내용을 짧게 알려 주시면 맞는 도구를 챙겨 갑니다. / 문틈으로 걸쇠를 찍은 사진이 있으면 더 좋습니다.
- 걸쇠 때문에 한 뼘 열리는지, 보조키 때문에 전혀 안 열리는지
- 안에 사람이나 반려동물이 있는지
- 중화역에서 어느 쪽인지, 건물 이름이나 아파트 동 호수
- 바깥쪽에 보조키 열쇠 구멍이 있는지

# 사시는 분 확인, 그리고 비용
도착하면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
걸쇠 종류와 문 상태를 보고 비용을 문 열기 전에 먼저 말씀드립니다. / 끝내 열지 못하면 비용은 받지 않습니다.
여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 적어 두었습니다. / 보조키 열쇠 쪽 작업은 [열쇠 출장](key-call.html)에서 보실 수 있습니다.

# 연 뒤에 걸쇠와 보조키 손보기
걸쇠가 저절로 걸렸던 경우라면 고정 나사를 조이고 덜렁거리지 않게 바로잡아 둡니다. / 헐거운 걸쇠는 같은 일이 다시 생기기 쉽습니다.
보조키가 문틀에 물려 있었다면 받침쇠 위치를 맞추고 경첩도 같이 봅니다. / 보조키가 낡아 자주 걸린다면 도어락 하나로 정리하는 방법도 말씀드립니다.
도어락 쪽까지 손볼 일이 있다면 [도어락 수리](doorlock-repair.html), 바꾸기로 하셨다면 [도어락 교체](doorlock-replace.html)를 참고해 주세요.
@ 중화동 걸쇠 고정 나사 보조키 받침쇠 점검

# 걸쇠를 쓰는 작은 습관
걸쇠는 집에 있을 때 마음을 놓게 해 주는 장치지만, 쓰는 습관에 따라 문 앞에서 막히는 원인이 되기도 합니다. / 아래 정도만 지켜도 걸쇠 때문에 막히는 일은 크게 줄어듭니다.
- 식구가 아직 안 들어왔을 때는 걸쇠를 걸지 않기
- 외출 전에 걸쇠가 문틀 고리에서 떨어져 있는지 보기
- 아이에게 걸쇠를 장난으로 걸지 않도록 알려 주기
- 걸쇠가 덜렁거리면 바로 나사 조이기

# 중화동 말고 중랑구 어디든
중화동 옆 묵동, 상봉동부터 면목동, 망우동, 신내동까지 다닙니다. / [중랑구 출장열쇠](seoul-jungnang.html)와 [출장 지역](area.html)에서 다니는 곳을 보실 수 있습니다.
