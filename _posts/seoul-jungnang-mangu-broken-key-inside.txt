# 망우동에서 열쇠가 반 토막 났다면
망우역 쪽 빌라 골목은 도어락과 함께 열쇠로 여는 보조 자물쇠를 아직 쓰는 집이 많습니다. / 오래 쓴 열쇠는 어느 날 힘을 조금 더 줬을 뿐인데 딱 하고 두 동강이 나기도 합니다.
손에는 열쇠 머리만 남고, 나머지는 자물쇠 구멍 속에 들어가 버립니다. / 이 순간 가장 많이 하는 실수가 남은 조각을 손톱이나 다른 열쇠로 밀어 보는 것입니다.
이 글은 망우동에서 열쇠가 부러졌을 때 조각을 더 깊이 밀어 넣지 않고 기다리는 요령을 적었습니다. / 부러진 자리가 현관인지, 공동현관인지, 방문인지에 따라 달라지는 점도 나눠 두었습니다.
@ 망우동 빌라 보조키 열쇠 부러짐 출장열쇠

# 어디서 부러졌는지에 따라 급한 정도가 다릅니다
같은 부러진 열쇠라도 어느 문이냐에 따라 오늘 밤 해결해야 할 일이 다릅니다. / 먼저 아래 중 어느 쪽인지 생각해 보세요.
- 현관 보조 자물쇠: 문이 잠긴 채라면 집에 못 들어가는 상황
- 빌라 1층 공동현관: 건물 안으로 들어갈 다른 길이 있는지가 먼저
- 집 안 방문이나 창고 문: 당장 급하지 않다면 낮에 봐도 되는 경우
- 도어락 아래 비상 열쇠 구멍: 도어락 번호로 열리는지 먼저 확인
현관이 잠긴 상태라면 바로 연락 주시는 게 낫고, 집 안쪽 문이라면 조금 기다리셔도 괜찮습니다.

# 조각이 얼마나 보이는지 들여다보기
휴대폰 손전등을 켜고 자물쇠 구멍을 비춰 보세요. / 조각 끝이 구멍 바깥으로 튀어나와 있는지, 구멍 입구와 나란한지, 안쪽으로 들어가 있는지 봅니다.
끝이 밖으로 꽤 튀어나와 있다면 손가락으로 집어서 곧게 당기면 빠지는 경우도 있습니다. / 이때 비틀거나 좌우로 흔들지 말고 열쇠가 들어간 방향 그대로 한 번만 당기세요.
입구와 나란하거나 안쪽으로 들어가 있다면 손대지 않는 것이 좋습니다. / 여기서 건드리면 조각이 핀 사이로 더 파고듭니다.

# 문이 열린 채라면 그대로 두세요
문을 열고 나서 잠그다가 부러진 경우라면 문을 닫지 마세요. / 닫는 순간 들어갈 방법이 하나 줄어듭니다.
열린 채로 집 안에 들어가 계시면 급할 일이 없습니다. / 그날 밤은 다른 잠금장치로 문을 걸어 두고, 조각 빼는 일은 편한 시간에 맡기셔도 됩니다.
도어락과 보조 자물쇠를 같이 쓰는 집이라면 도어락만으로 잠가 두시면 됩니다. / 보조 자물쇠 쪽은 손대지 않은 상태로 두는 게 나중에 빼기 쉽습니다.

# 접착제나 자석은 왜 안 되나
조각 끝에 순간접착제를 묻힌 막대를 대서 끌어내는 방법이 인터넷에 돌기도 합니다. / 접착제가 핀 사이로 흘러 들어가면 자물쇠가 통째로 굳어 버려 실린더를 바꿔야 할 수 있습니다.
자석은 열쇠 재질에 따라 붙지 않는 경우가 많고, 붙더라도 핀에 걸린 조각을 당길 힘은 없습니다. / 실핀이나 이쑤시개는 부러져서 조각이 하나 더 생기기 쉽습니다.
@ 망우동 자물쇠 구멍 열쇠 조각 손대지 않기

# 보조키 실린더에서 부러졌을 때
빌라 현관에 따로 달린 보조키는 열쇠가 깊이 들어가는 구조라 조각이 안쪽에 머무는 경우가 많습니다. / 핀이 열쇠 조각을 물고 있는 상태라 바깥에서 당기는 힘만으로는 잘 안 빠집니다.
이럴 때는 핀을 정리하면서 조각을 빼는 전용 도구로 작업합니다. / 조각만 빠지면 실린더는 그대로 쓰는 경우도 많습니다.
다만 오래 써서 실린더 안이 많이 닳아 있었다면 조각을 빼도 다른 열쇠가 잘 안 돌 수 있습니다. / 이때는 실린더 교체를 먼저 여쭤봅니다.

# 빌라 공동현관 열쇠라면
1층 공동현관 자물쇠는 여러 세대가 같이 쓰는 문입니다. / 내 열쇠가 부러졌어도 다른 세대 열쇠까지 막히기 때문에 건물 관리하시는 분께 먼저 알려 주세요.
공용 출입문 자물쇠를 손보는 일은 관리하시는 분이나 집주인 확인이 있어야 진행합니다. / 일단 건물 안으로 들어가야 한다면 이웃이나 관리하시는 분 도움을 먼저 받아 보세요.

# 방문이나 창고 문 열쇠라면
집 안 방문 손잡이나 베란다 창고 문은 열쇠가 짧고 얇아서 쉽게 부러집니다. / 대신 구멍이 얕은 편이라 조각이 입구 가까이에 머무는 경우가 많습니다.
방 안에 아무도 없고 급한 물건이 없다면 서두르지 않으셔도 됩니다. / 아이가 안에 있거나 가스 불을 켜 둔 방이라면 바로 말씀해 주세요.
손잡이 자물쇠는 조각을 빼는 것보다 손잡이째 바꾸는 편이 깔끔할 때도 있습니다. / 어느 쪽이 나은지는 보고 나서 먼저 여쭤봅니다.

# 열쇠가 휘어 있었다면 복사 열쇠를 의심해 보세요
부러진 열쇠를 보면 그 전에 이미 살짝 휘어 있거나 금이 가 있던 경우가 많습니다. / 복사한 열쇠를 다시 복사해 쓰면 홈이 조금씩 무뎌져 힘을 더 줘야 돌아갑니다.
남은 열쇠도 같은 원본에서 복사한 것이라면 오래 쓰지 말고 원본에서 새로 복사해 두세요. / 열쇠 하나에 무거운 열쇠고리를 여러 개 다는 것도 휘어지는 원인이 됩니다.
돌릴 때 걸리는 느낌이 들기 시작했다면 그 열쇠는 이미 지쳐 가고 있다는 신호입니다. / 그때 바꿔 두면 오늘 같은 일을 피할 수 있습니다.

# 망우역 쪽에서 전화 주실 때
위치는 건물 이름과 함께 망우역에서 어느 방향인지 알려 주시면 찾기 쉽습니다. / 아래 내용도 같이 말씀해 주세요.
- 부러진 자물쇠가 어느 문의 어느 자리인지
- 문이 잠긴 상태인지, 열린 상태인지
- 손에 남은 열쇠 머리가 있는지
- 구멍 속 조각이 보이는지, 안 보이는지
손에 남은 열쇠 머리와 구멍 사진을 같이 보내 주시면 맞는 도구를 챙겨 갑니다.

# 거주 확인과 비용
현관이 잠겨 열어야 하는 상황이라면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 집주인 확인 중 하나면 됩니다.
조각만 빼면 되는지, 실린더를 바꿔야 하는지 보고 비용을 시작 전에 먼저 말씀드립니다. / 끝내 열지 못하면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html), 열쇠 쪽 작업은 [열쇠 출장](key-call.html)에 적어 두었습니다.
@ 망우동 열쇠 조각 빼기 실린더 점검

# 조각을 뺀 뒤 실린더 상태 보기
조각을 빼고 나면 남은 열쇠를 꽂아 몇 번 돌려 봅니다. / 걸리지 않고 부드럽게 돌아가면 그대로 쓰셔도 됩니다.
돌릴 때 여전히 뻑뻑하거나 열쇠가 끝까지 안 들어간다면 실린더 안쪽이 상했을 수 있습니다. / 이 경우 실린더만 바꾸는 방법과 보조키 대신 도어락으로 정리하는 방법을 같이 말씀드립니다.
도어락으로 바꾸기로 하셨다면 [도어락 설치](doorlock-install.html) 내용을, 기존 도어락까지 함께 손볼 일이 있다면 [도어락 수리](doorlock-repair.html) 내용을 참고해 주세요.

# 망우동 말고 중랑구 다른 동네
망우동 옆 상봉동, 신내동, 면목동부터 중화동, 묵동까지 다닙니다. / [중랑구 출장열쇠](seoul-jungnang.html)와 [출장 지역](area.html)에서 다니는 곳을 보실 수 있습니다.
