# 면목동 빌라 철문, 잠금쇠가 반쯤 걸린 채 멈췄다면
문을 닫고 번호를 눌렀는데 드르륵 소리가 길게 나다가 잠김 소리 없이 끝나는 날이 있습니다. / 반대로 집에 돌아와 번호를 눌렀더니 모터는 도는데 문이 꿈쩍도 안 하는 날도 있습니다.
두 경우 모두 문 옆면에서 들락날락하는 굵은 잠금쇠, 데드볼트가 제자리를 못 찾고 있는 것입니다. / 면목역 주변처럼 오래 쓴 빌라 철문이 많은 동네에서 자주 듣는 증상입니다.
이 글은 데드볼트가 걸렸을 때 원인을 하나씩 가려내는 순서를 적었습니다. / 집에서 해 볼 수 있는 것과 손대지 않는 게 나은 것을 나눠 두었습니다.
@ 면목동 빌라 현관 데드볼트 걸림 출장열쇠

# 데드볼트는 어디에 있는 부품일까
문을 열어 둔 채 옆면을 보면 손잡이 근처에 비스듬한 걸쇠가 있고, 그 위나 아래에 네모나고 굵은 쇠막대가 하나 더 있습니다. / 이 굵은 막대가 데드볼트입니다.
걸쇠는 문을 닫을 때 저절로 들어갔다 나오고, 데드볼트는 잠글 때만 문틀 쪽으로 깊이 나갑니다. / 그래서 문이 잠겼는지 아닌지를 실제로 정하는 부품이 데드볼트입니다.
도어락이 모터로 데드볼트를 움직이는 제품도 있고, 안쪽 손잡이를 손으로 돌려 움직이는 수동 보조키도 있습니다. / 우리 집이 어느 쪽인지 알면 원인을 좁히기가 쉬워집니다.

# 안 나오는지, 안 빠지는지부터 나누기
증상은 크게 두 가지입니다. / 같은 데드볼트 문제라도 어느 쪽이냐에 따라 급한 정도가 다릅니다.
- 문은 닫혔는데 데드볼트가 덜 나와 잠기지 않는 경우
- 잠긴 채로 데드볼트가 안 빠져 문이 안 열리는 경우
첫 번째는 집에 있는 상태라 조금 여유가 있습니다. / 두 번째는 밖에서 못 들어가는 경우가 많아 서둘러야 합니다.
어느 쪽이든 문을 손잡이 반대쪽으로 살짝 밀거나 몸 쪽으로 당기면서 다시 잠그거나 열어 보세요. / 문이 처져 데드볼트가 받침쇠 구멍 가장자리에 걸린 경우라면 이것만으로 풀리기도 합니다.

# 빌라 철문은 계절 따라 조금씩 달라집니다
철문은 한여름 볕을 받으면 조금 늘어나고 한겨울에는 조금 줄어듭니다. / 남향이나 서향 현관이라 오후 햇빛을 오래 받는 집이라면 오후에만 잠금이 뻑뻑해지는 일이 생깁니다.
아침에는 괜찮은데 오후에만 걸린다면 이런 경우를 떠올려 보세요. / 받침쇠 구멍을 조금 넓히거나 위치를 맞추면 계절이 바뀌어도 덜 걸립니다.

# 받침쇠 구멍 안을 들여다보기
문틀 옆면에 데드볼트가 들어가는 네모난 구멍이 있습니다. / 손전등으로 비춰 보면 먼지나 페인트 덩어리, 부러진 나사 머리 같은 것이 막고 있는 경우가 있습니다.
마른 붓이나 칫솔로 털어 내면 나아지는 경우도 많습니다. / 막힌 게 없는데도 데드볼트가 구멍 둘레에 긁힌 자국을 남기고 있다면 위치가 어긋난 것입니다.
윤활제는 데드볼트 쇠막대 표면에 아주 조금만 쓰세요. / 기름을 많이 뿌리면 먼지가 엉겨 붙어 오히려 더 뻑뻑해집니다.
@ 면목동 문틀 받침쇠 구멍 데드볼트 위치 확인

# 수동 보조키라면 손에 전해지는 느낌으로
안쪽 손잡이를 돌려 잠그는 보조키는 돌릴 때 느낌으로 상태를 알 수 있습니다. / 끝까지 부드럽게 돌다가 마지막에 툭 걸리면 문틀 쪽 문제, 처음부터 무거우면 보조키 몸체 안쪽 문제인 경우가 많습니다.
밖에서 열쇠로 여는 보조키라면 열쇠가 반쯤만 돌고 멈추는지도 봅니다. / 이때 열쇠에 힘을 더 주면 열쇠가 휘거나 부러질 수 있으니 멈추세요.

# 모터 소리가 길게 나다 멈출 때
도어락이 모터로 데드볼트를 움직이는 제품이라면 소리가 단서가 됩니다. / 평소보다 길고 힘겨운 소리가 나다가 멈춘다면 모터 힘이 모자라는 것입니다.
가장 흔한 원인은 배터리가 약해진 것입니다. / 번호판은 켜지는데 모터가 끝까지 못 미는 단계가 먼저 오기 때문에 배터리를 바꾸면 돌아오는 경우가 많습니다.
새 배터리로 바꿔도 같은 소리가 난다면 문틀 쪽에서 데드볼트를 붙잡고 있거나 모터 쪽이 지친 것입니다. / 이때부터는 점검을 받아 보시길 권합니다.

# 문이 열린 상태에서 데드볼트가 튀어나왔다면
문을 열어 둔 채로 잠금 버튼을 눌렀거나 아이가 장난을 쳐서 데드볼트가 나온 채 멈춰 있을 수 있습니다. / 이 상태로 문을 세게 닫으면 데드볼트가 문틀에 부딪혀 휘어집니다.
문을 닫기 전에 안쪽에서 열림 버튼을 눌러 데드볼트를 먼저 넣어 주세요. / 버튼을 눌러도 안 들어간다면 문을 닫지 말고 그대로 연락 주세요.

# 이렇게 하면 데드볼트가 휘어집니다
잠긴 문이 안 열린다고 손잡이를 잡고 온몸으로 당기는 분이 있습니다. / 데드볼트가 받침쇠에 물린 상태에서 당기면 쇠막대가 휘거나 문틀 쪽 받침쇠가 뜯겨 나옵니다.
문틈에 드라이버를 넣어 데드볼트를 밀어 넣으려는 것도 피해 주세요. / 빌라 철문은 틈이 좁아 문 가장자리 도장만 벗겨지고 데드볼트는 움직이지 않습니다.
번호를 계속 눌러 모터를 여러 번 돌리는 것도 좋지 않습니다. / 걸린 상태에서 모터가 계속 밀면 안쪽 톱니가 상할 수 있으니 두세 번 해 보고 멈추세요.

# 연락 주실 때 알려 주실 것
면목동은 비슷한 빌라가 이어져 있어 건물 이름이나 1층 가게를 같이 알려 주시면 찾기 쉽습니다. / 아래 내용도 짧게 말씀해 주세요.
- 안 나오는 쪽인지, 안 빠지는 쪽인지
- 모터식 도어락인지, 손으로 돌리는 보조키인지
- 모터 소리가 나는지, 아무 소리가 없는지
- 오후에만 그런지, 하루 종일 그런지
문 옆면 데드볼트와 문틀 받침쇠 사진을 함께 보내 주시면 맞는 부품을 챙겨 갑니다.

# 거주 확인과 비용
잠긴 문을 열어야 하는 상황이라면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 집주인 확인 중 하나면 됩니다.
받침쇠 조정으로 끝날지 부품을 바꿔야 할지 보고 비용을 손대기 전에 말씀드립니다. / 끝내 열지 못하면 비용은 받지 않습니다.
여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 바로잡은 뒤 같이 확인하는 것
손본 뒤에는 문을 여러 번 닫고 잠가 보면서 데드볼트가 끝까지 나오는지 함께 봅니다. / 손잡이를 당겼을 때 문이 덜컹거리지 않으면 제대로 걸린 것입니다.
문이 처진 게 원인이었다면 경첩도 같이 조여 둡니다. / 그래야 몇 주 뒤에 같은 일이 다시 생기지 않습니다.
모터 쪽이 지쳤다면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 오래돼 부품을 구하기 어렵다면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.
@ 면목동 데드볼트 조정 후 잠금 확인

# 면목동 말고 중랑구 다른 동네
면목동 옆 상봉동, 중화동부터 묵동, 망우동, 신내동까지 다닙니다. / 다니는 동네는 [중랑구 출장열쇠](seoul-jungnang.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
