# 면목동 빌라 1층 문 앞에서 멈춰 섰다면
면목역에서 골목으로 들어서면 빌라와 다세대가 줄지어 서 있습니다. / 이런 건물은 집 현관 말고도 1층 공동 출입문, 옥상이나 지하로 통하는 철문까지 문이 여러 겹입니다.
그래서 "문이 안 열린다"는 연락을 받으면 어느 문인지부터 여쭙니다. / 공동 출입문인지, 우리 집 철문인지에 따라 확인할 곳과 들고 갈 장비가 달라집니다.
이 글은 면목동 빌라와 다세대에서 자주 막히는 공동 출입문과 철문을 문 종류별로 나눠 적었습니다. / 지금 문 앞에 계시면 두 번째와 세 번째 소제목부터 보셔도 됩니다.
@ 면목동 빌라 공동 출입문 철문 출장열쇠

# 막힌 문이 어느 쪽인지 먼저 가려 주세요
빌라에서 잠기는 문은 대개 세 가지 중 하나입니다.
- 1층 공동 출입문: 번호키나 카드, 열쇠로 여는 건물 입구 문
- 세대 현관 철문: 도어락과 보조키가 같이 달린 집 문
- 계단실이나 옥상, 지하 창고로 통하는 쇠문
공동 출입문만 막혔다면 같은 건물 이웃이 안에서 열어 줄 수도 있습니다. / 세대 현관이 막힌 경우와는 해결 방법이 완전히 다르니 전화 주실 때 꼭 구분해서 말씀해 주세요.

# 공동 출입문 번호키가 반응하지 않을 때
건물 입구 번호키는 여러 세대가 하루에도 여러 번 누르는 장치입니다. / 그만큼 버튼이 닳거나 전원 쪽이 약해지는 일이 집 도어락보다 잦습니다.
번호를 눌렀는데 소리가 안 나면 전원 문제, 소리는 나는데 문이 안 풀리면 걸쇠나 전기 잠금 쪽 문제일 가능성이 큽니다. / 공동 번호가 최근에 바뀌었는지 건물 단체 대화방이나 집주인에게 먼저 물어보세요.
공동 출입문은 건물 전체가 쓰는 설비라 고치거나 바꾸는 일은 건물주나 관리하시는 분과 상의해서 정합니다. / 저희도 그분과 연락이 닿는지 먼저 확인한 뒤 작업합니다.

# 오래된 세대 철문이 무거워졌다면
중랑구 빌라는 오래 쓴 철문이 많아서 도어락보다 문틀과 경첩이 먼저 지칩니다. / 문이 아래로 처지면 걸쇠가 문틀 구멍에 비스듬히 걸려 번호가 맞아도 문이 안 열립니다.
문을 몸 쪽으로 살짝 당기거나 반대로 밀면서 손잡이를 돌려 보세요. / 이렇게 해서 열린다면 도어락 고장이 아니라 문 처짐이 원인입니다.
열린 뒤에도 그대로 쓰시면 같은 일이 반복됩니다. / 경첩 조정이나 걸쇠 구멍 손질로 끝나는 경우가 많으니 [도어락 수리](doorlock-repair.html)로 먼저 보시는 걸 권합니다.

# 철문 열쇠 구멍이 뻑뻑할 때
보조키로 쓰는 열쇠 구멍은 몇 년씩 안 쓰다가 갑자기 쓰면 잘 안 돌아갑니다. / 먼지와 녹이 안에서 굳어 있기 때문입니다.
열쇠를 끝까지 넣었는지, 앞뒤를 바꿔 넣어 봤는지 확인해 주세요. / 그래도 안 돌아가면 힘을 더 주지 말고 멈추는 게 좋습니다.
식용유나 일반 윤활유를 구멍에 붓는 분들이 있는데 먼지와 엉겨 더 뻑뻑해집니다. / 열쇠가 휘거나 부러지기 전에 전화 주시는 편이 훨씬 수월합니다.
@ 면목동 세대 철문 보조키 열쇠 구멍 점검

# 문을 두드리거나 비틀면 생기는 일
철문은 단단해 보여도 문틀과 맞물리는 부분은 생각보다 약합니다. / 발로 차거나 어깨로 밀면 문틀이 벌어져 나중에 잠금이 헐거워집니다.
틈에 드라이버를 넣어 벌리면 철판이 휘고 도장이 벗겨집니다. / 그 자리부터 녹이 올라와 문 전체 수명이 줄어듭니다.
공동 출입문 유리를 손바닥으로 세게 치는 것도 피해 주세요. / 이웃이 놀라기도 하고 유리 고정 부분이 상할 수 있습니다.
안에 계신 이웃에게 연락할 방법이 있다면 그쪽이 훨씬 빠릅니다. / 같은 층 이웃이나 집주인 번호를 휴대폰에 저장해 두면 이럴 때 요긴합니다.

# 면목동 골목에서 위치 알려 주는 법
면목동은 비슷한 빌라가 이어져 있어 주소만으로는 건물을 찾기 어려울 때가 있습니다. / 아래를 같이 알려 주시면 골목 안에서 헤매지 않습니다.
- 도로명 주소와 건물 이름, 호수
- 면목역 몇 번 출구 쪽인지, 근처 큰길이나 눈에 띄는 건물
- 막힌 문이 공동 출입문인지 세대 철문인지
- 문 앞 차를 댈 수 있는지, 골목이 좁은지
문과 잠금장치 사진을 문자로 보내 주시면 맞는 장비를 챙기기 좋습니다. / 밤이라 어두우면 휴대폰 불빛을 켜고 찍어 주셔도 됩니다.

# 사시는 분인지는 이렇게 확인합니다
문을 여는 일이라 도착하면 거주 확인을 먼저 합니다. / 신분증 주소나 주소가 적힌 우편물, 집주인 확인 중 하나면 됩니다.
공동 출입문만 여는 경우에도 그 건물에 사시는지는 확인합니다. / 다른 세대와 건물 전체의 안전이 걸린 일이라 양해 부탁드립니다.
신분증이 집 안에 있다면 집주인께 전화로 세대 확인을 부탁드리는 방법도 있습니다. / 빌라는 관리사무소가 없는 곳이 많아 집주인 연락처가 가장 확실합니다.
진행 방식은 [이용안내](guide.html)에 따로 정리해 두었습니다.

# 비용 이야기는 작업 전에 끝냅니다
문 종류와 잠금장치 상태를 보고 얼마가 드는지 먼저 말씀드립니다. / 듣고 괜찮으실 때만 시작하고, 아니시면 그대로 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 작업 중에 부품을 바꿔야 할 것 같으면 그 전에 따로 여쭙니다.

# 철문을 여는 방식
덜 상하는 방법부터 하나씩 해봅니다. / 철문은 한번 휘면 원래대로 펴기 어려워서 문틀과 철판을 건드리지 않는 쪽을 먼저 고릅니다.
현관문 여는 과정은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다. / 열쇠 자체가 필요한 경우는 [열쇠 출장](key-call.html)에서 보실 수 있습니다.
@ 중랑 면목동 철문 비파손 개문 작업

# 열린 다음에 꼭 같이 보는 곳
문이 열리면 도어락과 보조키가 몇 번이고 매끄럽게 잠기는지 확인합니다. / 걸쇠가 문틀 구멍 가운데로 들어가는지도 눈으로 봅니다.
경첩 나사가 풀렸으면 조여 두고, 처짐이 심하면 조정 방법을 말씀드립니다. / 도어락이 너무 낡았다면 그때 [도어락 교체](doorlock-replace.html) 이야기를 꺼냅니다.

# 빌라 문을 덜 막히게 쓰는 습관
- 철문 경첩에 녹이 보이면 마른 천으로 닦고 상태 살피기
- 안 쓰는 보조키 구멍도 가끔 열쇠를 넣어 돌려 주기
- 공동 출입문 번호가 바뀌면 세대끼리 바로 공유하기
- 문이 쾅 닫히면 도어클로저 속도 점검하기
작은 손질이 큰 고장을 막습니다. / 특히 겨울 전에 한 번 열고 닫아 보며 소리와 느낌을 확인해 두세요.
철문은 날이 추워지면 조금 줄어들고 여름엔 늘어나서 계절마다 닫히는 느낌이 달라집니다. / 계절이 바뀔 때 유난히 뻑뻑해졌다면 그 무렵에 한 번 손봐 두는 게 좋습니다.

# 면목동 말고 중랑구 다른 동네도 갑니다
상봉동, 중화동, 묵동, 망우동, 신내동까지 중랑구 어디든 출동합니다. / 빌라 골목이든 아파트 단지든 위치만 알려 주시면 됩니다.
중랑구에서 다니는 곳은 [중랑구 출장열쇠](seoul-jungnang.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

? 철문이 처져서 안 열리는 것도 해결되나요? | 대부분 문을 연 뒤 경첩과 걸쇠 위치를 맞추면 나아집니다. 상태를 보고 말씀드립니다.
? 열쇠 구멍에 기름을 넣어도 되나요? | 일반 기름은 먼지와 엉겨 더 뻑뻑해집니다. 넣지 말고 그대로 두세요.
