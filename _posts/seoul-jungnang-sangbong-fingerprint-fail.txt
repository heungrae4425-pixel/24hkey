# 상봉동 지문 도어락이 오늘따라 손가락을 모른 척할 때
상봉역에서 집까지 걸어와 늘 하던 대로 손가락을 댔는데 삐 소리만 나고 문이 안 열리는 날이 있습니다. / 두 번, 세 번 대 봐도 마찬가지면 지문이 지워진 건 아닌지 걱정이 됩니다.
지문 도어락은 열쇠도 번호도 필요 없어 편하지만, 손가락과 센서 상태에 따라 인식이 들쭉날쭉할 수 있습니다. / 특히 날이 차고 건조해지는 늦가을부터 겨울 사이에 이런 연락이 늘어납니다.
이 글은 상봉동에서 지문 인식이 잘 안 될 때 집 앞에서 해 볼 것과 다시 등록하는 방법을 정리했습니다. / 지문만 믿고 쓰다 막히지 않도록 다른 열림 방법을 챙기는 이야기도 담았습니다.
@ 상봉동 지문 도어락 인식 실패 출장열쇠

# 인식이 실패하는 흔한 이유
지문 인식이 안 되는 이유는 대부분 손가락이나 센서 쪽 문제입니다. / 도어락 자체가 고장 난 경우는 생각보다 적습니다.
- 손가락이 너무 건조하거나 반대로 물기가 있는 경우
- 센서 창에 손때, 먼지, 핸드크림이 묻은 경우
- 손가락에 상처나 굳은살이 생긴 경우
- 등록할 때와 다른 각도나 위치로 대는 경우
- 배터리가 약해 센서 반응이 둔해진 경우
하나씩 지워 나가면 원인이 금방 좁혀집니다. / 아래 순서대로 해 보세요.

# 센서 창부터 닦아 보세요
센서 창은 손가락이 닿는 자리라 생각보다 빨리 더러워집니다. / 안경 닦는 천처럼 부드러운 천으로 가볍게 닦아 주세요.
물티슈를 쓰셨다면 마른 천으로 한 번 더 닦아 물기를 없애야 합니다. / 알코올이나 세정제를 직접 뿌리면 센서 표면 코팅이 상할 수 있어 피하는 게 좋습니다.
센서 창에 긁힌 자국이 많다면 닦아도 인식이 잘 안 될 수 있습니다. / 열쇠 꾸러미를 센서 근처에 부딪히지 않게 조심하는 것만으로도 오래 쓸 수 있습니다.

# 손가락 상태도 인식에 영향을 줍니다
겨울에는 손끝이 건조해져 지문 골이 얕아집니다. / 손가락을 입김으로 살짝 데우거나 손바닥으로 비벼 온기를 준 뒤 대 보세요.
손을 씻은 직후나 비를 맞은 날에는 반대로 물기가 문제입니다. / 옷에 손가락을 한 번 닦고 대면 나아지는 경우가 많습니다.
요리하다 손끝을 베었거나 밴드를 붙였다면 다른 손가락을 써야 합니다. / 그래서 처음 등록할 때 손가락을 여러 개 등록해 두는 것이 중요합니다.
@ 상봉동 지문 센서 창 닦기 손가락 상태

# 대는 방법을 바꿔 보기
지문은 손가락 끝이 아니라 첫 마디 가운데 넓은 부분으로 대야 잘 읽힙니다. / 손끝만 콕 찍듯이 대면 읽히는 면적이 좁아 실패하기 쉽습니다.
너무 세게 누르지 말고 가볍게 평평하게 올려놓는 느낌으로 대세요. / 센서가 다 읽을 때까지 손가락을 움직이지 않고 잠깐 기다리는 것도 중요합니다.
등록할 때 손가락을 어떤 방향으로 댔는지 떠올려 보세요. / 문을 바라보고 섰을 때 손가락 방향이 등록 때와 많이 다르면 인식률이 떨어집니다.

# 지문을 하나만 등록해 두셨다면
식구마다 손가락 하나씩만 등록해 둔 집이 많습니다. / 그 손가락을 다치거나 상태가 나빠지면 문 앞에서 막히게 됩니다.
한 사람당 양손에서 두세 개씩 등록해 두면 훨씬 든든합니다. / 자주 쓰는 손가락은 각도를 조금씩 바꿔 두 번 등록해 두는 방법도 있습니다.
장바구니를 든 채 문을 여는 일이 많다면 오른손과 왼손에서 하나씩 등록해 두세요. / 손에 짐이 있을 때 반대 손으로 바로 열 수 있어 편합니다.
저장할 수 있는 지문 수는 제품마다 정해져 있습니다. / 이사 오기 전 사람이 등록한 지문이 남아 자리를 차지하고 있다면 전체를 지우고 식구 지문만 새로 등록하는 편이 깔끔합니다.

# 다시 등록하는 순서
문이 열린 상태에서 안쪽 몸체의 등록 버튼을 찾습니다. / 제품마다 버튼 위치와 순서가 다르니 배터리 덮개 안쪽 모델명을 보고 설명서를 확인하세요.
대부분은 관리자 확인을 거친 뒤 같은 손가락을 여러 번 대서 등록합니다. / 이때 매번 손가락 위치를 조금씩 바꿔 대면 다양한 각도가 저장되어 나중에 인식이 좋아집니다.
등록이 끝나면 문을 열어 둔 채로 바깥에서 몇 번 대 보세요. / 문을 닫고 시험했다가 안 되면 다시 막히니 꼭 열어 둔 상태에서 확인합니다.

# 어르신과 아이 지문은 따로 신경 써 주세요
어르신은 지문이 옅어져 인식이 잘 안 되는 경우가 많습니다. / 지문만 고집하지 말고 카드나 쉬운 번호를 같이 쓰실 수 있게 해 드리세요.
아이는 자라면서 손가락 크기가 바뀌어 예전에 등록한 지문이 잘 안 맞을 수 있습니다. / 한 해에 한 번쯤 다시 등록해 주시면 좋습니다.
아이가 혼자 하교하는 집이라면 지문이 안 될 때 쓸 번호를 아이와 함께 연습해 두세요. / 문 앞에서 당황하지 않고 다음 방법으로 넘어갈 수 있습니다.

# 번호나 카드 같은 다른 길을 꼭 남겨 두세요
지문 도어락이라도 번호나 카드 열림을 같이 쓸 수 있는 제품이 대부분입니다. / 지문만 쓰다 보면 번호를 잊어버려 정작 필요할 때 못 쓰는 일이 생깁니다.
식구 모두 번호를 한 번씩 눌러 열어 보고, 잊지 않게 가끔 번호로도 열어 보세요. / 비밀번호 관리 요령은 [이용안내](guide.html)에도 적어 두었습니다.

# 배터리가 약하면 센서도 둔해집니다
배터리가 거의 다 되면 번호판은 켜져도 지문 센서 반응이 느려지는 경우가 있습니다. / 평소보다 인식이 한 박자 늦어졌다면 배터리부터 의심해 보세요.
배터리를 바꿀 때는 전부 한꺼번에 새것으로 바꾸세요. / 일부만 바꾸면 얼마 안 가 같은 증상이 다시 나타납니다.

# 문 앞에서 다 해 봐도 안 될 때
손가락을 닦고 데워도, 다른 손가락을 대도, 번호를 눌러도 안 된다면 무리하지 마세요. / 여러 번 실패하면 도어락이 한동안 입력을 막기 때문에 오히려 시간이 더 걸립니다.
센서 창에 금이 갔거나 아무 반응이 없다면 센서 쪽 고장일 수 있습니다. / 이때는 [도어락 수리](doorlock-repair.html)로 먼저 보고, 부품을 구하기 어렵다면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.

# 연락 주실 때와 거주 확인, 비용
도어락 사진과 함께 지문, 번호, 카드 중 무엇이 되고 무엇이 안 되는지 알려 주세요. / 상봉역에서 어느 쪽인지, 건물 이름이나 아파트 동 호수도 같이 말씀해 주시면 됩니다.
문을 열 때는 사시는 분이 맞는지 신분증이나 주소가 나온 우편물로 확인합니다. / 비용은 문 열기 전에 먼저 말씀드리고, 끝내 못 열면 받지 않습니다.
여는 방식은 [현관문 개문](door-open.html)에 자세히 있습니다.
@ 상봉동 지문 도어락 재등록 수리 출장

# 상봉동 말고 중랑구 어디든
상봉동 옆 면목동, 망우동, 중화동부터 묵동, 신내동까지 다닙니다. / [중랑구 출장열쇠](seoul-jungnang.html)와 [출장 지역](area.html)에서 다니는 곳을 보실 수 있습니다.
