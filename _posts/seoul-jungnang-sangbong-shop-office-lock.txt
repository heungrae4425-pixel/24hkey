# 상봉동 가게 문, 아침에 안 열리면 하루가 밀립니다
상봉역 주변에는 1층 가게와 위층 사무실이 함께 있는 건물이 많습니다. / 아침에 문을 열러 왔는데 도어락이 반응하지 않거나 열쇠가 안 돌아가면 영업 준비부터 줄줄이 늦어집니다.
상가와 사무실 문은 집 현관과 생김새도, 쓰는 사람 수도 다릅니다. / 그래서 같은 고장이라도 확인할 곳과 정리할 것이 조금 다릅니다.
이 글은 상봉동에서 자주 보는 유리문, 철문, 셔터 옆 쪽문을 나눠서 정리했습니다. / 가게를 새로 열거나 사무실을 옮기면서 잠금장치를 바꾸려는 분께도 참고가 될 겁니다.
@ 상봉동 상가 사무실 출입문 도어락 출장열쇠

# 상가 문은 왜 집 문보다 빨리 지칠까
가게 문은 하루에도 손님과 직원이 셀 수 없이 드나듭니다. / 손잡이와 걸쇠, 도어클로저가 집 현관보다 훨씬 많이 움직입니다.
문을 열어 둔 채 고정해 두는 시간이 길어 경첩과 도어클로저에 무리가 쌓이기도 합니다. / 길가에 면한 문은 먼지와 비바람도 더 많이 맞습니다.
그래서 처음에는 조금 뻑뻑한 정도였다가 어느 날 아침 갑자기 안 열리는 식으로 고장이 옵니다. / 작은 신호를 놓치지 않는 게 중요합니다.
문이 닫힐 때 예전보다 세게 부딪히거나, 잠근 뒤 문을 당겨 보면 덜컹 흔들린다면 점검할 때가 된 것입니다.

# 강화유리문에 달린 잠금장치
유리문은 문틀 대신 바닥이나 위쪽에 걸쇠가 들어가는 구조가 많습니다. / 바닥 쪽 구멍에 먼지나 작은 돌이 끼면 걸쇠가 끝까지 내려가지 않아 잠기지도, 풀리지도 않는 일이 생깁니다.
유리문용 도어락은 유리에 구멍을 내지 않고 끼워 다는 제품이 많습니다. / 오래 쓰면 고정이 헐거워져 도어락 자체가 기울면서 걸쇠 위치가 어긋납니다.
유리는 한번 깨지면 손쓸 방법이 없으니 문을 세게 흔들거나 발로 밀지 마세요. / 기울어 보이면 그대로 두고 사진을 찍어 보내 주세요.

# 사무실 철문과 번호식 도어락
위층 사무실은 집 현관과 비슷한 철문에 번호식이나 카드식 도어락을 단 곳이 많습니다. / 여러 사람이 같은 번호를 쓰다 보니 번호판 특정 버튼만 닳아 보이는 일도 흔합니다.
퇴근할 때 마지막 사람이 잠갔는지 헷갈리는 일도 많아 자동 잠금을 켜 두는 사무실이 많습니다. / 자동 잠금 상태에서 열쇠나 카드를 두고 나오면 그대로 갇히게 됩니다.
번호판이 꺼졌다면 바깥 비상 전원 단자부터 확인해 보세요. / 사무실은 주말 내내 비어 있다가 월요일에 배터리가 다 된 걸 알게 되는 경우가 잦습니다.
@ 상봉동 사무실 철문 번호식 도어락 점검

# 셔터 옆 쪽문과 뒷문
셔터를 내리는 가게는 셔터 옆 작은 쪽문이나 건물 뒤편 문으로 드나드는 경우가 많습니다. / 이 문들은 열쇠식 자물쇠를 오래 쓰는 곳이 많아 구멍이 녹슬거나 굳어 있기 쉽습니다.
비 오는 날 셔터 아래로 빗물이 들이치면 쪽문 자물쇠까지 젖습니다. / 마른 뒤 뻑뻑해졌다면 그 영향일 수 있습니다.
셔터 자체의 고장은 셔터 전문 업체가 보는 경우가 많습니다. / 저희는 쪽문, 뒷문, 출입문 잠금장치 쪽을 맡고, 셔터 문제는 그렇게 따로 안내드립니다.

# 영업 시간을 지켜야 할 때
가게 문은 하루 손님을 받느냐 못 받느냐가 걸려 있어 시간이 가장 급합니다. / 전화 주실 때 몇 시까지 문을 열어야 하는지 말씀해 주시면 그에 맞춰 순서를 잡습니다.
문을 열고 나서 당장 잠금장치를 바꾸기 어렵다면 일단 열어서 영업하시고, 바꾸는 일은 영업이 끝난 뒤로 미룰 수도 있습니다. / 상황에 맞게 정하시면 됩니다.
반대로 밤늦게 마감하다가 문이 안 잠기는 경우도 있습니다. / 가게를 열어 둔 채 퇴근할 수는 없으니 그럴 때도 시간 상관없이 연락 주세요. 잠금이 되게 손보는 것부터 합니다.

# 건물주와 임차인 중 누가 정하나
상가 출입문은 건물 쪽 설비인지, 가게가 따로 단 잠금장치인지에 따라 정할 사람이 달라집니다. / 계약 내용이나 건물 사정은 곳마다 달라서 저희가 단정할 수는 없습니다.
잠금장치를 바꾸기 전에는 건물주나 관리하시는 분과 한 번 이야기해 두시는 게 좋습니다. / 문을 여는 일만 필요하다면 사용하시는 분인지 확인한 뒤 바로 진행합니다.

# 상봉동에서 연락 주실 때
- 건물 이름과 층, 가게나 사무실 이름 대신 호수나 위치
- 상봉역 기준 대략 어느 쪽인지
- 문 종류: 유리문, 철문, 셔터 옆 쪽문, 뒷문
- 잠금장치 종류: 번호식, 카드식, 열쇠식
- 몇 시까지 열어야 하는지
문과 잠금장치를 가까이, 멀리 한 장씩 찍어 보내 주시면 맞는 장비를 챙겨 갑니다. / 큰길가라 차 대기 어려운 곳이면 미리 말씀해 주세요.

# 사용하시는 분인지 먼저 확인합니다
상가와 사무실도 문을 여는 일이라 확인 절차를 거칩니다. / 사업자등록증, 임대차 계약서, 건물 관리하시는 분 확인 중 하나를 준비해 주세요.
직원분이 혼자 문을 열러 오신 경우라면 대표나 관리자와 통화로 확인하는 방법도 있습니다. / 확인이 안 되면 작업할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 시작 전에 먼저
문 종류와 잠금장치 상태를 보고 얼마인지 먼저 말씀드립니다. / 듣고 괜찮으실 때만 진행합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 부품을 바꿔야 할 때도 바꾸기 전에 따로 여쭙니다. 진행 순서는 [이용안내](guide.html)에 있습니다.

# 열고 난 뒤 정리할 것
문을 열고 나면 잠금장치가 몇 번이고 매끄럽게 잠기고 풀리는지 확인합니다. / 유리문이라면 바닥 걸쇠 구멍 청소와 도어락 고정 상태를 같이 봅니다.
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 손보고, 너무 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 새로 다는 경우는 [도어락 설치](doorlock-install.html)에서 순서를 보실 수 있습니다.
@ 중랑 상봉동 상가 유리문 도어락 교체

# 직원이 바뀌거나 가게를 넘겨받았을 때
직원이 그만두거나 가게를 인수했다면 번호와 카드부터 정리하세요. / 예전 사람이 알던 번호나 가진 카드가 그대로 살아 있으면 마음이 편하지 않습니다.
열쇠식이라면 실린더만 바꿔 새 열쇠로 정리하는 방법도 있습니다. / 열쇠가 몇 개 돌았는지 모를 때는 이쪽이 확실합니다.
출입 기록이 남는 도어락이라면 누가 언제 드나들었는지 확인하기도 쉬워집니다. / 직원이 여럿인 사무실이라면 이런 기능을 갖춘 제품을 고려해 볼 만합니다.
- 번호는 사람이 바뀔 때마다 새로 정하기
- 카드는 전부 지우고 지금 쓰는 사람 것만 다시 등록하기
- 열쇠 사본이 몇 개인지 적어 두기

# 상봉동 말고 중랑구 다른 곳
면목동, 중화동, 묵동, 망우동, 신내동까지 중랑구 전 지역 상가와 사무실에 출동합니다. / 중랑구 안내는 [중랑구 출장열쇠](seoul-jungnang.html), 다른 지역은 [출장 지역](area.html)에 있습니다.
