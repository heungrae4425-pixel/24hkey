# 신내동 현관, 한 번 둘러볼 때가 됐다면
신내동은 중랑구에서 아파트 단지가 넓게 자리한 동네입니다. / 입주한 지 오래된 집일수록 현관 도어락과 문은 처음 그대로인데 사는 식구와 생활 방식은 많이 바뀌어 있습니다.
현관 방범이라고 하면 거창한 장비부터 떠올리기 쉽지만, 대부분은 평소 습관과 작은 손질로 챙길 수 있습니다. / 이 글은 신내동 아파트에서 사시는 분이 직접 둘러볼 수 있는 점검 목록을 정리했습니다.
불안해하실 필요는 없습니다. / 이미 잘 쓰고 계신 부분은 그대로 두고, 빠진 부분만 하나씩 채우시면 됩니다.
@ 신내동 아파트 현관 방범 점검 도어락

# 겁낼 일이 아니라 습관을 보는 일
아파트 현관은 공동현관과 경비, 엘리베이터 같은 여러 단계를 거쳐야 닿는 곳입니다. / 그래서 집 앞에서 챙길 것은 대단한 장비보다 문이 제대로 잠기는지, 번호가 쉽게 드러나지 않는지 같은 기본입니다.
아래 항목은 한 번에 다 하실 필요가 없습니다. / 오늘은 두세 개만 확인하고 다음 주에 나머지를 보셔도 충분합니다.

# 번호판에 남은 손자국
번호판을 비스듬히 비춰 보면 자주 누르는 숫자에만 손때가 몰려 있는 경우가 있습니다. / 손자국만 봐도 어떤 숫자가 쓰이는지 짐작할 수 있게 됩니다.
마른 천으로 가끔 닦아 주시면 됩니다. / 물이나 세정제를 뿌리지 말고 천에 살짝 묻혀 닦는 정도면 충분합니다.
번호판 덮개가 있는 제품이라면 누르고 난 뒤 덮개를 닫는 습관도 도움이 됩니다. / 덮개가 헐거워 저절로 열린다면 손볼 때가 된 것입니다.

# 번호를 누를 때 가리는 습관
복도에 사람이 있을 때 번호를 누르면 손 모양만으로도 번호가 드러날 수 있습니다. / 다른 손이나 가방으로 살짝 가리고 누르는 습관이면 충분합니다.
번호 앞뒤로 아무 숫자를 더 눌러도 열리는 허수 기능이 있는 제품이 많습니다. / 우리 집 도어락에 이 기능이 있는지 설명서나 모델명으로 확인해 보세요.
가족 중 누군가 매번 같은 손가락 순서로 누른다면 함께 이야기해 두는 것도 좋습니다. / 아이에게도 번호를 누를 때는 주위를 한 번 보라고 알려 주세요.

# 문이 닫히고 잠기는 소리 듣기
나갈 때 문이 닫힌 뒤 도어락이 잠기는 소리가 나는지 한 번만 귀 기울여 보세요. / 자동 잠금 소리가 없거나 경고음이 난다면 문이 덜 닫혔을 수 있습니다.
문이 끝까지 닫히지 않는 일이 잦다면 도어클로저나 경첩이 지쳐 있는 경우가 많습니다. / 이럴 때는 도어락보다 문 쪽을 먼저 손봐야 합니다.
자동 잠금을 꺼 둔 채 쓰는 집도 있습니다. / 일부러 끈 게 아니라면 설정을 다시 확인해 보세요.
@ 신내동 현관 도어락 자동 잠금 소리 확인

# 보조 걸쇠와 비상 열쇠 구멍
안쪽 보조 걸쇠는 집에 있을 때, 특히 밤에 걸어 두면 마음이 놓입니다. / 다만 외출할 때 걸쇠가 걸린 채 문을 닫으면 들어올 때 막히니 나갈 때는 꼭 풀어 두세요.
도어락 아래 비상 열쇠 구멍이 있는 제품이라면 덮개가 제대로 닫혀 있는지 보세요. / 덮개가 빠져 있거나 구멍 주변이 긁혀 있다면 한 번 점검을 받아 두시면 좋습니다.
비상 열쇠를 어디에 두었는지도 식구들과 확인해 두세요. / 현관 신발장 안처럼 누구나 짐작할 만한 곳보다는 가족만 아는 자리가 낫습니다.

# 문 아래 틈과 오래된 투입구
오래된 현관문 중에는 아래쪽에 작은 투입구가 남아 있거나 문 아래 틈이 넓은 경우가 있습니다. / 이런 곳은 막아 두거나 덮개를 달아 두면 바람도 덜 들어오고 마음도 편합니다.
문 아래 틈이 손가락이 들어갈 만큼 넓다면 문이 처졌을 수 있습니다. / 이때는 경첩 점검을 같이 받아 보세요.

# 잃어버린 카드가 등록돼 있지 않은지
예전에 잃어버린 카드나 태그가 아직 도어락에 등록돼 있을 수 있습니다. / 몇 장이 등록돼 있는지 모르겠다면 전체를 지우고 지금 쓰는 카드만 다시 등록하는 방법이 가장 확실합니다.
가족이 쓰는 카드를 한자리에 모아 놓고 하면 빠뜨리지 않습니다. / 정리한 뒤 카드마다 한 번씩 열어 보고 마무리하세요.

# 번호를 아는 사람 세어 보기
이사 오면서 받은 번호를 그대로 쓰고 있지 않은지, 예전에 손님이나 일하시는 분께 알려 준 번호가 남아 있지 않은지 생각해 보세요. / 번호를 아는 사람이 떠오르지 않을 만큼 많다면 바꿀 때가 된 것입니다.
번호를 바꿀 때는 식구 모두가 있을 때 정하고 그 자리에서 각자 한 번씩 열어 보세요. / 한 사람만 바꾸고 알리지 않으면 다른 식구가 문 앞에서 막힙니다.

# 공동현관과 복도에서 챙길 것
아파트는 집 현관보다 먼저 공동현관을 거칩니다. / 공동현관 번호를 택배 상자나 우편함에 적어 두는 집이 있는데, 이런 메모는 떼어 두는 편이 좋습니다.
공동현관이 고장 나 열린 채로 있거나 닫히는 속도가 지나치게 느리다면 관리사무소에 알려 주세요. / 공용 설비는 관리사무소가 손보는 곳이라 세대에서 따로 고치기보다 알리는 게 빠릅니다.
복도식 아파트라면 현관 옆 창문이 잠겨 있는지도 같이 보세요. / 환기하려고 열어 두었다가 외출할 때 그대로 두는 경우가 생각보다 많습니다.
현관 앞에 비상 열쇠나 번호를 적은 쪽지를 숨겨 두는 습관도 이번에 정리해 두세요. / 화분 아래나 신발장 위처럼 누구나 떠올리는 자리는 숨긴 것이 아닙니다.

# 택배 상자와 오래 비울 때
현관 앞에 택배 상자가 며칠씩 쌓여 있으면 집이 비어 있다는 표시가 될 수 있습니다. / 여행이나 출장으로 집을 비울 때는 택배를 미루거나 받아 줄 사람을 정해 두세요.
오래 비우기 전에는 도어락 배터리를 새것으로 바꿔 두는 것도 잊지 마세요. / 돌아온 날 번호판이 꺼져 있으면 방범보다 들어가는 일이 먼저 걱정이 됩니다.

# 점검이 필요하다고 느껴지면
둘러보다가 도어락이 헐겁게 흔들리거나 잠기는 소리가 시원찮다면 점검을 받아 보세요. / 점검만 하는 경우에도 사시는 분이 맞는지 신분증이나 우편물로 확인합니다.
손볼 곳이 있으면 무엇을 왜 해야 하는지와 비용을 손대기 전에 먼저 말씀드립니다. / 필요 없는 교체는 권하지 않고, 문이 잠겨 여는 일이라면 끝내 못 열었을 때 비용은 받지 않습니다.
고칠 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 함께 상의합니다. / 진행 순서는 [이용안내](guide.html)에 있습니다.
@ 신내동 도어락 점검 수리 교체 상담

# 신내동 말고 중랑구 다른 곳
신내동 옆 묵동, 망우동, 상봉동부터 중화동, 면목동까지 다닙니다. / [중랑구 출장열쇠](seoul-jungnang.html)와 [출장 지역](area.html)에서 다니는 동네를 보실 수 있습니다.
