# 손가락이 번호를 기억하지 못하는 날
신내동 아파트 현관 앞에서 늘 누르던 번호를 눌렀는데 삐삐 틀렸다는 소리가 나는 날이 있습니다. / 한 번 더 눌러도 마찬가지면 그때부터 머릿속이 하얘집니다.
비밀번호 문제는 크게 두 가지입니다. / 내가 번호를 잊은 경우, 그리고 가족 누군가 번호를 바꿔 놓고 미처 알려 주지 않은 경우입니다.
두 경우 모두 도어락은 정상이라 차분히 짚어 보면 의외로 쉽게 풀리기도 합니다. / 이 글은 문 앞에서 해볼 순서와, 결국 못 떠올렸을 때 어떻게 진행되는지 적었습니다.
@ 신내동 도어락 비밀번호 분실 현관문

# 먼저 숨 한 번 고르세요
틀렸다는 소리가 연달아 나면 손이 빨라지고, 손이 빨라지면 더 틀립니다. / 도어락은 여러 번 연속으로 틀리면 한동안 입력을 막는 제품이 많습니다.
두세 번 틀렸다면 잠시 멈추고 아래를 하나씩 떠올려 보세요. / 입력 제한이 걸렸다면 몇 분 지나야 다시 누를 수 있으니 그동안 생각을 정리하시면 됩니다.
추운 날이나 늦은 밤이면 마음이 더 급해집니다. / 그럴수록 엘리베이터 앞이나 복도 한쪽으로 자리를 옮겨 잠깐 쉬었다가 다시 시도하세요.

# 내가 잊은 거라면 이것부터
- 최근에 번호를 바꾼 적이 있는지, 바꿨다면 그 전 번호는 무엇이었는지
- 휴대폰 메모, 사진첩, 가족 대화방에 번호를 남긴 적이 있는지
- 회사 출입문이나 다른 집 번호와 헷갈리고 있지는 않은지
- 끝에 별표나 샵 버튼을 누르는 제품인데 빠뜨리지 않았는지
의외로 많은 경우가 마지막 확인 버튼 하나 때문입니다. / 번호를 다 누르고 확인 버튼까지 눌러야 열리는 제품이 있으니 평소 손동작을 떠올려 보세요.
손가락이 번호판의 어느 위치를 눌렀는지 몸이 기억하는 경우도 있습니다. / 숫자보다 누르던 모양을 따라 천천히 눌러 보세요.

# 가족이 번호를 바꿨다면
번호가 분명 맞는데 틀렸다고 나온다면 집에 누가 먼저 와서 바꿨을 수 있습니다. / 식구들에게 차례로 연락해 보세요.
연락이 닿으면 그 자리에서 해결됩니다. / 연락이 안 되면 기다릴지, 출장을 부를지 정하셔야 합니다.
가족이 일하는 중이라 전화를 못 받는다면 문자로 번호만 보내 달라고 남겨 두세요. / 그사이 다른 방법을 찾다가 답이 오면 그걸로 여시면 됩니다.
어르신이 사시는 집에서는 자녀가 번호를 바꿔 드리고 어르신이 잊어버리시는 일도 잦습니다. / 이럴 땐 번호를 바꾼 자녀에게 먼저 연락하는 게 가장 빠릅니다.
특히 아이가 장난으로 설정 버튼을 눌러 번호를 바꿔 버리는 일이 있습니다. / 아이가 혼자 집에 있다면 안에서 문을 열어 달라고 차분히 부탁해 보세요.
@ 신내동 가족이 바꾼 도어락 번호 확인

# 번호 말고 다른 열림 방식이 있는지
번호만 쓰고 계셨더라도 처음 설치할 때 카드나 지문을 같이 등록했을 수 있습니다. / 지갑 속 카드, 열쇠고리 태그를 한 번씩 대 보세요.
앱이 연결된 도어락이라면 가족 휴대폰에서 문을 열어 줄 수도 있습니다. / 보조 열쇠 구멍이 있는 제품이라면 비상 열쇠가 어디 있는지도 떠올려 보세요.
비상 열쇠를 차 안이나 회사 서랍에 두셨다면 가지러 가는 시간과 출장 도착 시간을 견주어 정하시면 됩니다.

# 이렇게 하면 번호가 더 꼬입니다
- 기억나는 숫자를 섞어 가며 계속 눌러 보기
- 번호판 덮개를 억지로 열거나 분해하기
- 안쪽 설정 버튼을 바깥에서 건드리려고 문틈을 벌리기
도어락은 바깥에서 번호를 초기화할 수 없게 만들어져 있습니다. / 그래야 다른 사람도 바깥에서 번호를 바꿀 수 없으니까요. 바깥에서 뭘 해도 번호가 풀리지는 않습니다.

# 그래도 못 떠올렸다면
여기까지 해서 안 되면 출장을 부르시는 게 시간도 덜 듭니다. / 번호를 잊은 경우는 도어락이 멀쩡한 상태라 대부분 상하지 않게 엽니다.
문 앞에서 오래 서 계시기 어렵다면 경비실이나 단지 상가에서 기다리셔도 됩니다. / 출발하면서 다시 연락드리겠습니다.
기다리는 사이에 번호가 떠오르거나 가족과 연락이 닿으면 바로 전화 주세요. / 문이 열렸다면 그대로 알려 주시면 됩니다.

# 신내동에서 연락 주실 때
- 동 번호와 호수, 신내동 어느 쪽 단지인지
- 번호를 내가 잊었는지, 가족이 바꿨는지
- 카드나 지문, 앱 같은 다른 방식이 등록돼 있는지
- 입력 제한이 걸렸는지
- 집 안에 아이나 반려동물이 혼자 있는지
도어락 앞면 사진을 보내 주시면 제품에 맞는 방법을 미리 준비합니다. / 아이가 혼자 있다면 그 사실부터 먼저 말씀해 주세요.
입력 제한이 걸린 상태라면 그것도 알려 주세요. / 제한 시간이 얼마나 남았는지에 따라 진행 방법이 조금 달라집니다.

# 거주 확인이 꼭 필요한 이유
번호를 모르는 상태에서 문을 여는 일은 누구에게나 똑같이 할 수 있으면 안 됩니다. / 그래서 사시는 분인지 반드시 확인합니다.
신분증 주소, 주소가 적힌 우편물, 관리사무소 세대 확인 중 하나면 됩니다. / 신분증이 집 안에 있으면 문을 연 직후 확인하고, 확인 전에는 안으로 들어가지 않습니다.

# 비용은 문 열기 전에 먼저
도어락 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮으실 때만 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 자세한 순서는 [이용안내](guide.html)에, 여는 과정은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 열고 나서 번호 정리하기
문이 열리면 안쪽에서 새 번호를 등록하고, 예전 번호와 가족이 바꾼 번호를 모두 지웁니다. / 그 자리에서 가족 모두가 아는 번호 하나로 맞춥니다.
번호는 생일이나 집 호수처럼 남이 짐작하기 쉬운 숫자는 피하세요. / 대신 가족끼리만 아는 숫자 조합을 정하면 잊어버릴 일도 줄어듭니다.
번호판에 손때가 묻어 자주 누르는 숫자가 드러나 보이는지도 함께 봅니다. / 그렇다면 번호판을 닦아 두거나, 번호 앞뒤에 아무 숫자나 덧붙여 눌러도 열리는 기능이 있는지 확인해 드립니다.
도어락 반응이 느리거나 소리가 이상하다면 이참에 [도어락 수리](doorlock-repair.html)로 같이 봅니다.
@ 중랑 신내동 도어락 새 비밀번호 등록

# 다음에 잊지 않으려면
- 번호를 바꾸면 그날 가족 대화방에 바로 알리기
- 설정 버튼은 어른만 누르기로 정하기
- 카드나 지문 하나는 번호와 따로 등록해 두기
- 번호를 바꿀 때는 이전 번호를 일주일쯤 메모해 두기
- 아이에게는 번호 대신 카드나 태그를 주기
번호 관리가 계속 어렵다면 지문이나 카드를 주로 쓰는 도어락으로 바꾸는 방법도 있습니다. / 필요하시면 [도어락 교체](doorlock-replace.html)에서 순서를 보세요.

# 신내동 말고 중랑구 다른 곳
면목동, 상봉동, 중화동, 묵동, 망우동까지 중랑구 전 지역에 출동합니다. / 중랑구 안내는 [중랑구 출장열쇠](seoul-jungnang.html), 다른 지역은 [출장 지역](area.html)에 있습니다.
