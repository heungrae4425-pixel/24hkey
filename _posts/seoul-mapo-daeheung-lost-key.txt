# 주머니가 비어 있다는 걸 알았을 때
대흥동은 아파트와 빌라, 오래된 주택이 섞여 있는 마포 동네입니다. / 현관은 번호키여도 보조키나 1층 대문, 옥상 문은 아직 열쇠를 쓰는 건물이 꽤 남아 있습니다.
집 앞에 와서야 열쇠 꾸러미가 없다는 걸 알면 머릿속이 하얘집니다. / 잃어버린 건지 집 안에 두고 문만 잠근 건지도 헷갈립니다.
이 글은 대흥동에서 열쇠가 없어 문 앞에 섰을 때 오늘 밤 할 일과, 들어간 뒤 내일 정리할 것을 나눠 적었습니다. / 들어갈 방법이 없으면 [마포 출장열쇠](seoul-mapo.html)를 불러 주세요.
@ 대흥동 빌라 현관 열쇠 분실

# 잃어버린 걸까, 두고 나온 걸까
먼저 열쇠가 집 안에 있는지 밖 어딘가에 있는지 떠올려 보세요. / 이 차이에 따라 들어간 뒤 할 일이 완전히 달라집니다.
- 나올 때 문을 열쇠로 잠갔다면 열쇠는 밖에 있었던 것
- 문이 저절로 잠기는 방식이라면 안에 두고 나왔을 수 있음
- 오늘 들른 가게, 버스, 택시를 차례로 떠올려 보기
- 가방 안쪽 주머니, 외투 안주머니 한 번 더 확인
안에 두고 나온 것이라면 들어가기만 하면 끝입니다. / 밖에서 잃어버렸다면 들어간 뒤에도 할 일이 남습니다.

# 문 앞에서 바로 해볼 수 있는 것
집에 같이 사는 가족이나 여분 열쇠를 가진 사람이 있는지 먼저 연락해 보세요. / 가까운 곳에 사는 가족이 있다면 기다리는 편이 가장 덜 번거롭습니다.
세입자라면 집주인이 여분 열쇠를 갖고 있는 경우도 있습니다. / 늦은 밤이라 연락이 어렵다면 다음 방법으로 넘어가세요.
현관이 번호키라면 번호로 열리는지부터 확인합니다. / 열쇠는 보조키에만 쓰는데 보조키를 잠그고 나왔다면 번호를 눌러도 문은 안 열립니다.

# 잃어버린 곳에 연락하는 순서
버스나 지하철에서 잃어버렸다면 분실물 센터에 문의해 볼 수 있습니다. / 택시라면 결제 내역으로 차량을 찾는 방법이 있습니다.
가게나 카페에 들렀다면 그곳에 전화를 걸어 두세요. / 다음 날 찾게 되더라도 오늘 밤 들어가는 일은 따로 해결해야 합니다.
열쇠에 주소나 이름표를 달아 두셨다면 조금 더 서두르는 게 좋습니다. / 누가 주웠는지 모르는 열쇠가 집 주소와 함께 돌아다니는 셈이기 때문입니다.
@ 대흥동 잃어버린 열쇠 꾸러미 확인

# 기다리는 동안 챙겨 둘 것
휴대폰 배터리가 얼마 남지 않았다면 밝기를 낮추고 쓰지 않는 앱을 꺼 두세요. / 출장 기사와 통화하고 위치를 주고받으려면 배터리가 꼭 필요합니다.
날씨가 춥거나 늦은 시간이라면 근처 편의점처럼 불이 켜진 곳에서 기다리셔도 됩니다. / 도착할 때쯤 다시 전화드리니 건물 앞에 서 계실 필요는 없습니다.
그사이 신분증이나 주소가 보이는 자료가 손에 있는지 한 번 더 확인해 두세요. / 지갑까지 잃어버렸다면 그 사실도 미리 말씀해 주시면 다른 확인 방법을 같이 찾습니다.

# 억지로 들어가려는 시도는 그만
창문이나 베란다로 들어가려는 분이 있는데 빌라 2층 이상이라면 정말 위험합니다. / 1층이라도 방범창을 뜯다가 다치거나 창틀이 상하는 일이 생깁니다.
문틈에 카드나 드라이버를 넣어 걸쇠를 미는 것도 권하지 않습니다. / 열리지 않고 문틀만 찌그러지는 경우가 대부분입니다.
보조키 구멍에 다른 열쇠를 넣고 돌리는 것도 피하세요. / 맞지 않는 열쇠가 안에서 걸리거나 부러지면 일이 더 커집니다.

# 출장 부를 때 말씀해 주실 것
- 도로명 주소와 건물 이름, 층과 호수
- 잠긴 문이 현관 보조키인지, 손잡이 열쇠인지, 1층 대문인지
- 열쇠를 밖에서 잃어버렸는지, 안에 두고 나왔는지
- 집 안에 사람이나 반려동물이 있는지
대흥동 골목은 비슷한 빌라가 이어져 있어 근처 큰 가게나 공원을 같이 알려주시면 좋습니다. / 문 사진을 한 장 보내 주시면 잠금장치 종류를 미리 봅니다.
오래된 주택이라면 대문과 현관문 가운데 어느 쪽이 잠겼는지도 꼭 알려주세요. / 두 문이 모두 열쇠식이면 둘 다 열어야 할 수도 있어 시간을 넉넉히 잡습니다.

# 도착하면 먼저 확인하는 것
열쇠가 없어 들어가지 못하는 상황이라 사시는 분인지 확인이 먼저입니다. / 신분증 주소, 주소가 나온 우편물, 집주인이나 관리하는 분 확인 가운데 하나면 됩니다.
신분증이 집 안에 있다면 휴대폰에 저장된 계약서나 택배 주소 화면도 도움이 됩니다. / 확인이 어려우면 작업을 시작할 수 없으니 미리 챙겨 두세요.

# 비용과 여는 방식
문과 잠금장치를 보고 비용을 먼저 말씀드립니다. / 동의하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다.
여는 방식은 덜 상하는 쪽부터 차례로 시도합니다. / 어떤 방식으로 여는지는 [현관문 개방](door-open.html)과 [열쇠 출장](key-call.html) 페이지에 적어 두었습니다.
진행 순서 전체는 [이용안내](guide.html)에서 볼 수 있습니다.

# 안에 두고 나온 경우라면 여기서 끝
들어가서 열쇠가 신발장 위나 식탁에 있으면 정말 다행입니다. / 이 경우 잠금장치를 바꿀 필요는 없습니다. / 문이 열린 김에 보조키가 부드럽게 잠기고 풀리는지만 한 번 같이 봐 드립니다.
다음부터 같은 일을 줄이려면 여분 열쇠를 믿을 만한 가족에게 하나 맡겨 두세요. / 집 밖 화분이나 우편함에 숨겨 두는 것은 권하지 않습니다.
@ 대흥동 현관 보조키 열쇠 여분 보관

# 밖에서 잃어버렸다면 내일 바꿀 것
잃어버린 열쇠가 어디 있는지 모른다면 그 열쇠로 열리는 잠금장치는 바꾸는 편이 안심입니다. / 보조키라면 실린더만 바꿔도 기존 열쇠는 더 이상 맞지 않습니다.
현관을 번호키 하나로 정리하고 싶다면 이번에 도어락으로 바꾸는 방법도 있습니다. / 문 두께와 구멍을 보고 [도어락 설치](doorlock-install.html)가 되는지 확인해 드립니다.
공동 대문 열쇠를 잃어버렸다면 건물 관리하는 분이나 집주인에게도 알려 주세요. / 혼자 판단해 바꾸기보다 건물 사람들과 함께 정하는 것이 맞습니다.

# 꾸러미에 같이 있던 다른 열쇠도
현관 열쇠만 생각하기 쉬운데 꾸러미에는 여러 열쇠가 같이 달려 있습니다. / 차 열쇠, 회사 사무실 열쇠, 자전거 자물쇠, 우편함 열쇠까지 한 번 적어 보세요.
사무실 열쇠가 있었다면 회사에도 알려야 합니다. / 우편함이나 창고 열쇠는 급하지 않더라도 이번에 함께 정리해 두면 나중이 편합니다.

# 대흥동에서 마포 다른 동네까지
염리동, 공덕동, 도화동, 용강동, 아현동과 서교동, 합정동, 망원동, 연남동, 상암동까지 다닙니다. / 마포구 안이면 24시간 출동합니다.
마포 안내는 [마포구 출장열쇠](seoul-mapo.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 지갑째 잃어버려 신분증이 없어요. | 집주인 확인이나 휴대폰 속 계약서, 주소가 보이는 화면으로도 확인할 수 있습니다.
? 실린더만 바꾸면 잃어버린 열쇠는 못 쓰나요? | 네, 실린더가 바뀌면 기존 열쇠로는 열리지 않습니다.

? 못 열면 출장비만 받나요? | 아닙니다. 끝내 못 열면 비용은 받지 않습니다.

# 마무리
대흥동에서 열쇠가 없어 문 앞에 섰다면 잃어버린 건지 두고 나온 건지부터 가려 보세요. / 오늘은 들어가는 일, 내일은 잠금장치를 바꿀지 정하는 일로 나누면 덜 막막합니다.
