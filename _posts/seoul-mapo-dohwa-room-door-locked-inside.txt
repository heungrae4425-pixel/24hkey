# 현관이 아니라 방문이 잠겼다면
도화동은 공덕동, 용강동과 이웃한 마포 동네로 아파트와 오피스텔, 사무실 건물이 함께 서 있습니다. / 현관 도어락은 번호로 열리는데, 정작 집 안 방문이나 화장실 문이 잠겨 곤란해지는 집이 있습니다.
아이가 놀다가 안쪽 버튼을 누르고 나왔거나, 바람에 문이 닫히면서 잠긴 채 걸리는 경우가 흔합니다. / 안에 사람이 있는지, 비어 있는지에 따라 서둘러야 하는 정도가 달라집니다.
이 글은 도화동 집 안에서 방문이 잠겼을 때 손잡이 종류를 먼저 살피고 해볼 수 있는 것을 적었습니다. / 잘 안 되면 [마포 출장열쇠](seoul-mapo.html)를 불러 주세요.
@ 도화동 방문 손잡이 안쪽 잠김

# 안에 누가 있는지 먼저 확인
가장 먼저 볼 것은 문 안쪽에 사람이 있는지입니다. / 어린아이, 어르신, 몸이 불편한 가족이 안에 있다면 문 여는 순서보다 안심시키는 일이 먼저입니다.
문 너머로 계속 말을 걸어 주시고 안쪽 손잡이를 억지로 흔들지 말라고 알려 주세요. / 아이라면 손잡이 가운데 버튼을 한 번만 눌러 보라고 천천히 설명해 볼 수도 있습니다.
화장실 안에서 몸이 안 좋다는 말이 들리면 문보다 119가 먼저입니다. / 문 여는 일은 그다음에 해도 늦지 않습니다.

# 우리 집 방문 손잡이는 어떤 모양일까
방문과 화장실 문 손잡이는 겉모양으로 잠금 방식을 짐작할 수 있습니다. / 바깥쪽 손잡이 가운데를 자세히 들여다보세요.
- 가운데 작은 구멍이 뚫린 둥근 손잡이
- 가운데 일자 홈이 파인 둥근 손잡이
- 레버형 손잡이 아래쪽에 동전 홈이 있는 것
- 바깥쪽에 아무 표시가 없는 손잡이
대부분의 실내 손잡이는 비상시 바깥에서 풀 수 있게 만들어져 있습니다. / 구멍이나 홈이 있다면 집에서 풀어 볼 수 있는 가능성이 큽니다.

# 작은 구멍이 있다면 곧은 핀으로
둥근 손잡이 가운데 작은 구멍이 있다면 안쪽 잠금 버튼과 이어진 통로입니다. / 곧게 편 클립이나 얇은 막대를 넣어 끝에 닿는 곳을 살짝 밀어 보세요.
밀면서 손잡이를 같이 돌리면 잠금이 풀리는 방식이 많습니다. / 어떤 손잡이는 밀지 않고 끝을 걸어 돌려야 풀리기도 합니다.
너무 굵거나 휘어진 막대는 안에서 걸려 빠지지 않을 수 있습니다. / 안 들어가면 억지로 밀어 넣지 마세요.
@ 도화동 화장실 손잡이 비상 구멍

# 일자 홈이나 동전 홈이라면
가운데에 일자 홈이 있다면 납작한 드라이버나 동전 끝을 맞춰 돌리는 방식입니다. / 홈에 딱 맞는 크기를 골라 천천히 돌려 보세요.
홈보다 작은 도구를 쓰면 미끄러지면서 홈이 뭉개집니다. / 한두 번 미끄러지면 더 하지 말고 멈추는 게 낫습니다.
레버형 손잡이는 아래쪽이나 옆쪽에 작은 홈이 숨어 있는 경우가 있습니다. / 손전등으로 비춰 보며 찾아보세요.

# 문틈에 카드 넣기는 조심해서
드라마처럼 문틈에 카드를 넣어 걸쇠를 미는 방법을 떠올리는 분이 많습니다. / 실내 방문은 걸쇠 모양에 따라 되는 경우도 있지만, 안 되는 문에서 오래 하면 문틀만 긁힙니다.
화장실 문처럼 문틀에 몰딩이 덧대어진 문은 카드가 들어가지도 않는 경우가 많습니다. / 몇 번 해보고 안 되면 다른 방법으로 넘어가세요.
칼이나 얇은 쇠붙이를 문틈에 꽂는 것은 위험합니다. / 손을 다치거나 문틀이 깨질 수 있습니다.

# 바깥에 아무 표시가 없다면
바깥쪽 손잡이에 구멍도 홈도 없다면 집에서 풀기는 어렵습니다. / 오래된 문이나 따로 달아 둔 걸쇠, 빗장이 잠긴 경우가 여기에 해당합니다.
안쪽에 고리형 걸쇠를 걸어 둔 문이라면 바깥에서는 손댈 곳이 거의 없습니다. / 이때는 경첩 쪽이나 문 아래쪽을 보고 상하지 않게 여는 방법을 찾아야 합니다.
이런 경우 무리해서 손잡이를 뜯기보다는 바로 연락 주시는 편이 문을 아끼는 길입니다.

# 아이 방에서 자주 생기는 일
아이 방 손잡이는 아이 손이 닿는 높이에 잠금 버튼이 있어 쉽게 눌립니다. / 놀다가 누르고 나와 문을 닫으면 방이 통째로 잠깁니다.
안에 반려동물이 있다면 문 앞에서 큰 소리를 내지 말아 주세요. / 놀란 동물이 문을 긁거나 물건을 쓰러뜨릴 수 있습니다.
한 번 겪었다면 아이 방은 잠금 기능이 없는 손잡이로 바꾸는 것도 방법입니다. / 바꿀 때 문 두께와 구멍 크기를 같이 확인해야 맞는 손잡이를 고를 수 있습니다.
@ 도화동 아이 방 손잡이 잠금 해제

# 오피스텔 방문은 이렇게 다릅니다
도화동 오피스텔은 방 하나에 현관과 화장실 문만 있는 구조가 많습니다. / 화장실 문이 잠기면 세면도구와 세탁기까지 못 쓰게 되어 생활이 바로 막힙니다.
관리실에 비상 열쇠나 손잡이용 공구가 있는 건물도 있으니 먼저 물어보세요. / 건물에서 해결이 안 되면 그때 출장을 부르셔도 됩니다.
샤워 중 습기로 화장실 문이 부풀어 걸쇠가 꽉 물린 경우도 있습니다. / 이럴 때는 잠금 버튼은 풀렸는데도 문이 안 열리니, 환풍기를 켜 두고 잠시 기다린 뒤 문을 몸 쪽으로 당기며 손잡이를 돌려 보세요.
그래도 꿈쩍하지 않으면 손잡이 축이 부러졌을 수 있습니다. / 손잡이가 헛돈다면 그 느낌까지 전화로 말씀해 주세요.

# 출장을 부르실 때 알려주실 것
- 아파트나 오피스텔 이름과 동, 호수
- 잠긴 문이 방문인지 화장실 문인지
- 바깥 손잡이 모양과 가운데 구멍이나 홈 여부
- 안에 사람이나 반려동물이 있는지
손잡이 바깥쪽을 가까이 찍은 사진 한 장이면 맞는 도구를 고르기 쉽습니다. / 안에 아이가 있다면 그 사실을 맨 먼저 말씀해 주세요.

# 도착하면 이렇게 진행합니다
현관 안쪽까지 들어가는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소나 우편물, 관리사무소 확인 가운데 하나면 됩니다.
손잡이와 문 상태를 보고 비용을 먼저 말씀드린 뒤, 동의하시면 시작합니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
방문은 문틀과 문이 얇아 상하기 쉬워서 덜 상하는 방법부터 차례로 씁니다. / 진행 방식은 [이용안내](guide.html)와 [현관문 개방](door-open.html)에 적어 두었습니다.

# 열고 난 뒤 손잡이 정리
문이 열리면 손잡이 잠금이 다시 제대로 풀리고 잠기는지 확인합니다. / 걸쇠가 뻑뻑해 저절로 잠기는 상태라면 손잡이만 바꾸는 쪽을 말씀드립니다.
현관 도어락도 함께 점검하고 싶다면 [도어락 수리](doorlock-repair.html)에서 어떤 걸 보는지 확인해 보세요. / 새로 달고 싶다면 [도어락 설치](doorlock-install.html)도 참고하시면 됩니다.

# 도화동 말고 마포 어디든
공덕동, 용강동, 아현동, 대흥동, 염리동은 물론 서교동, 연남동, 망원동, 상암동까지 갑니다. / 마포구 안이면 24시간 출동합니다.
마포 안내는 [마포구 출장열쇠](seoul-mapo.html), 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.

# 마무리
도화동 집 안에서 방문이 잠겼다면 안에 누가 있는지 먼저 확인하고, 바깥 손잡이 모양을 살펴보세요. / 구멍이나 홈이 있다면 집에서 풀 수 있는 경우가 많고, 없다면 무리하지 않는 게 좋습니다.
24시출장열쇠는 현관뿐 아니라 방문, 화장실 문도 봅니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
