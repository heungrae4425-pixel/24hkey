# 망원동 우리 집 번호, 마지막으로 바꾼 게 언제인가요
망원동은 망원역 주변으로 빌라 골목과 주택이 이어지는 마포 동네입니다. / 한집에 부모와 자녀, 가끔 들르는 친척까지 여러 사람이 같은 현관 번호를 쓰는 집이 많습니다.
번호를 오래 그대로 두면 누가 알고 있는지 점점 흐려집니다. / 반대로 한 사람이 혼자 번호를 바꾸면 다른 가족이 문 앞에서 막힙니다.
이 글은 가족이 함께 쓰는 도어락 번호를 언제 바꾸고 어떻게 나누면 좋은지 정리했습니다. / 번호 문제로 문이 이미 안 열린다면 [마포 출장열쇠](seoul-mapo.html)로 바로 연락 주세요.
@ 망원동 가족 공유 도어락 비밀번호 관리

# 번호를 바꾸기 좋은 때
날짜를 정해 두지 않으면 번호는 몇 년이고 그대로 남습니다. / 아래 같은 때를 기준으로 삼으면 잊지 않고 바꿀 수 있습니다.
- 이사 들어온 직후
- 집수리나 인테리어 작업이 끝난 뒤
- 가사도우미, 돌봄 선생님 등 외부 사람이 그만둔 뒤
- 번호판 특정 숫자만 닳아 보일 때
- 누가 번호 누르는 걸 본 것 같을 때
이 외에는 계절이 바뀔 때 건전지를 갈면서 같이 바꾸는 집도 있습니다. / 일 년에 한두 번이면 충분합니다.
너무 자주 바꾸면 오히려 가족이 헷갈려 메모를 남기게 됩니다. / 현관 근처나 지갑에 번호를 적은 쪽지가 생기면 바꾼 의미가 없어지니 횟수보다 계기를 기준으로 삼으세요.

# 바꾸기 전에 가족과 먼저 정하세요
가장 흔한 실수는 한 사람이 혼자 바꾸고 알리지 않는 것입니다. / 늦게 들어온 가족이 문 앞에서 한참을 서 있게 됩니다.
번호를 바꿀 날과 새 번호를 미리 가족과 정해 두세요. / 바꾸는 순간에는 가능하면 가족 한 명이 집 안에 있을 때 하는 것이 안전합니다.
어르신이 함께 사신다면 외우기 어려운 번호는 피하는 게 좋습니다. / 대신 지문이나 카드처럼 번호 없이 여는 방법을 같이 등록해 드리세요.
멀리 사는 가족이 가끔 들른다면 그분께도 바꾼 사실을 알려야 합니다. / 주말에 왔다가 문 앞에서 기다리는 일이 생각보다 자주 생깁니다.

# 새 번호는 이렇게 알리세요
단체 대화방에 번호를 그대로 적어 올리는 것은 편하지만 조심스럽습니다. / 휴대폰을 잃어버리거나 대화방에 다른 사람이 초대되면 번호가 함께 새어 나갑니다.
가능하면 얼굴을 보고 직접 알려주거나 전화로 말해 주세요. / 문자로 보낸다면 확인한 뒤 지우는 습관을 들이면 좋습니다.
아이에게 알려줄 때는 번호를 적은 쪽지를 가방에 넣지 않도록 해 주세요. / 대신 몇 번 함께 눌러 보며 외우게 하는 편이 낫습니다.
@ 망원동 도어락 새 번호 가족에게 알리기

# 이런 번호는 피하세요
- 생일, 결혼기념일 같은 가족 기념일
- 전화번호 끝자리나 집 호수
- 1234, 0000처럼 이어지거나 같은 숫자
- 예전 집에서 쓰던 번호
가족이 외우기 쉬운 번호와 남이 짐작하기 쉬운 번호는 다릅니다. / 가족끼리만 아는 이야기에서 숫자를 따오면 외우기도 쉽고 짐작도 어렵습니다.

# 번호판 손자국도 관리 대상입니다
같은 번호를 오래 누르면 그 숫자 자리만 반질반질해지거나 닳습니다. / 이를 보고 어떤 숫자가 쓰이는지 짐작할 수 있습니다.
번호판을 가끔 마른 천으로 닦아 주세요. / 허수 번호 기능이 있다면 진짜 번호 앞뒤로 아무 숫자나 섞어 누르는 습관도 도움이 됩니다.
번호판 덮개가 있는 제품이라면 누를 때 손으로 살짝 가리는 것만으로도 충분합니다.

# 바꾼 뒤에는 꼭 시험해 보세요
번호를 새로 등록했다면 문을 연 상태에서 안쪽 잠금을 몇 번 해 보세요. / 그다음 밖으로 나가 새 번호로 직접 열어 봅니다.
가족 모두가 한 번씩 눌러 보는 것이 가장 확실합니다. / 이때 예전 번호로도 열리는지 한 번 시험해 보세요. 열리면 지워지지 않은 것입니다.
제품에 따라 번호를 여러 개 등록할 수 있어서 새 번호가 예전 번호 옆에 추가만 되는 경우가 있습니다. / 이럴 땐 전체 번호 삭제 후 새로 등록하는 순서로 다시 해야 합니다.
지문과 카드가 함께 등록된 제품이라면 그것들도 정리가 필요한지 확인하세요. / 그만둔 외부 사람의 카드가 남아 있으면 번호를 바꿔도 소용이 없습니다.

# 임시 번호가 되는 제품이라면
일부 도어락은 정해진 기간이나 횟수만 쓸 수 있는 임시 번호를 따로 만들 수 있습니다. / 손님이나 수리 기사가 올 때 가족 번호를 알려주지 않아도 됩니다.
지금 도어락에 이런 기능이 있는지 모르겠다면 모델 이름을 알려주세요. / 기능이 없는데 꼭 필요하다면 바꿀 때 참고할 수 있게 설명드립니다.

# 번호가 헷갈려 문이 안 열릴 때
가족이 번호를 바꿨는데 들은 적이 없거나, 새 번호가 기억나지 않을 수 있습니다. / 먼저 가족에게 전화해 보는 것이 가장 빠릅니다.
여러 번 틀리면 도어락이 잠시 입력을 막습니다. / 서너 번 해 봐도 안 되면 멈추고 기다리거나 연락해 주세요.
가족과 연락이 닿지 않으면 출장으로 열 수 있습니다. / 여는 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 망원동 빌라에서 위치 알려주기
망원동 빌라 골목은 비슷한 건물이 이어져 있어 처음 가는 곳은 헷갈립니다. / 건물 이름과 도로명 주소, 근처 큰 가게나 공원을 함께 알려주세요.
공동현관 번호가 따로 있다면 미리 알려주시거나 내려와 열어 주시면 됩니다. / 망원역 몇 번 출구 쪽인지만 말씀하셔도 도움이 됩니다.

# 열기 전에 사는 분인지 확인합니다
도착하면 신분증 주소, 주소가 나온 우편물, 관리하는 분 확인 가운데 하나로 사시는 분인지 확인합니다. / 가족 중 한 분만 계셔도 이 확인이 되면 진행합니다.
문과 도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 동의하실 때만 시작하고, 못 열면 비용은 받지 않습니다. 진행 순서는 [이용안내](guide.html)에 있습니다.

# 문을 연 뒤 번호 정리까지
문을 열면 그 자리에서 가족이 정한 새 번호를 등록해 드립니다. / 예전 번호와 남아 있던 카드, 지문 가운데 지울 것을 함께 정리합니다.
번호 변경이 너무 번거로운 오래된 제품이라면 손보는 방법과 바꾸는 방법을 함께 말씀드립니다. / [도어락 수리](doorlock-repair.html)와 [도어락 교체](doorlock-replace.html)에서 미리 살펴보셔도 됩니다.
@ 망원동 출장열쇠 비밀번호 재등록 정리

# 망원동 말고 마포구 어디든
합정동, 서교동, 연남동, 성산동처럼 가까운 동네와 공덕동, 아현동, 상암동까지 다닙니다. / 마포구 안이면 24시간 출동합니다.
지역 안내는 [마포구 출장열쇠](seoul-mapo.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
