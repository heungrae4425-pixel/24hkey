# 늘 카드만 대던 문 앞에서
서교동은 홍대입구역 생활권으로 빌라 골목과 상가 건물이 촘촘하게 붙어 있는 마포 동네입니다. / 1층 공동현관부터 집 현관까지 카드나 스티커 태그 하나로 드나드는 분이 많습니다.
카드에 익숙해지면 현관 번호를 거의 누르지 않게 됩니다. / 그러다 카드가 든 휴대폰 케이스나 지갑을 잃어버리면, 그제야 번호가 기억나지 않는다는 걸 알게 됩니다.
이 글은 서교동에서 카드만 쓰던 분이 카드를 잃어버렸을 때 문 앞에서 할 일과 들어간 뒤 정리 순서를 적었습니다. / 들어갈 방법이 남아 있지 않다면 [마포 출장열쇠](seoul-mapo.html)를 불러 주세요.
@ 서교동 빌라 카드키 태그 분실

# 카드가 어디 붙어 있었나요
요즘은 카드를 따로 들고 다니기보다 휴대폰 뒤나 케이스 안에 붙여 쓰는 분이 많습니다. / 그래서 카드를 잃어버린 게 아니라 휴대폰을 통째로 잃어버린 경우도 있습니다.
- 휴대폰 케이스 안쪽에 끼워 둔 카드
- 열쇠고리에 단 동그란 태그
- 지갑 속 교통카드와 겹쳐 둔 카드
- 차 키에 같이 달아 둔 리모컨형 태그
휴대폰째 잃어버렸다면 휴대폰 찾기 기능으로 위치부터 확인해 보세요. / 다른 사람 휴대폰을 빌려 내 번호로 전화를 걸어 보는 것도 방법입니다.

# 번호를 떠올리는 몇 가지 방법
카드만 쓰던 집이라도 도어락에는 번호가 하나쯤 등록돼 있는 경우가 많습니다. / 이사 올 때 정했던 번호, 가족 생일, 예전 집 번호를 차례로 떠올려 보세요.
같이 사는 가족이나 룸메이트에게 물어보는 것이 가장 빠릅니다. / 휴대폰 메모나 메신저 대화방에 번호를 적어 둔 적이 있는지도 찾아보세요.
여러 번 틀리면 도어락이 잠시 입력을 막습니다. / 서너 번 해보고 안 되면 멈추고 다음 방법으로 넘어가는 게 좋습니다.
@ 서교동 도어락 번호 입력 제한 확인

# 공동현관에서부터 막혔다면
빌라라면 1층 공동현관부터 못 들어가는 경우가 있습니다. / 이웃이 드나들 때 함께 들어가거나 집주인, 건물 관리하는 분께 연락해 보세요.
공동현관 카드는 집 현관 도어락과 등록하는 곳이 다릅니다. / 집 현관을 열어도 공동현관 카드는 건물 쪽에서 따로 정리해야 합니다.
상가 건물 위층 집이나 작업실이라면 밤에 건물 출입문이 잠기는 시간도 있습니다. / 건물 출입이 되는지 먼저 확인해 두시면 출장을 불렀을 때 기다리는 시간이 줄어듭니다.

# 혹시 누가 주웠을까 걱정된다면
카드나 태그만으로는 어느 집 것인지 알기 어렵습니다. / 다만 카드에 호수를 적어 두었거나 주소가 적힌 물건과 같이 잃어버렸다면 들어간 뒤 바로 정리하는 편이 안심입니다.
걱정이 크다고 밤새 문 앞에서 기다릴 필요는 없습니다. / 들어간 뒤 잃어버린 카드를 도어락에서 지우면 그 카드로는 더 이상 열리지 않습니다.

# 들어갈 방법이 없을 때 전화 요령
- 도로명 주소와 건물 이름, 층과 호수
- 공동현관부터 막혔는지, 집 현관만 막혔는지
- 도어락 모양과 카드 대는 위치
- 번호를 아예 모르는지, 헷갈리는 정도인지
서교동 골목은 비슷한 건물이 이어져 있어 근처 큰 가게나 골목 입구를 같이 알려주시면 좋습니다. / 도어락 사진을 보내 주시면 맞는 장비를 미리 챙깁니다.

# 카드도 번호도 없을 때 현장 순서
카드와 번호가 모두 없는 상황이라 사시는 분인지 확인이 꼭 필요합니다. / 신분증 주소, 주소가 나온 우편물, 집주인이나 건물 관리하는 분 확인 가운데 하나면 됩니다.
도어락 상태를 보고 비용을 먼저 말씀드린 뒤, 동의하시면 시작합니다. / 끝내 못 열면 비용은 받지 않습니다.
문을 여는 방식은 [현관문 개방](door-open.html), 진행 순서 전체는 [이용안내](guide.html)에 적어 두었습니다.

# 들어간 뒤 첫 번째, 카드 정리
문이 열리면 가장 먼저 잃어버린 카드가 도어락에 남지 않게 정리합니다. / 제품에 따라 카드를 한 장씩 지우기도 하고, 전체를 지운 뒤 남은 카드를 다시 등록하기도 합니다.
전체를 지우는 방식이라면 가족이 가진 카드를 모두 모아 두고 시작하세요. / 빠뜨린 카드는 나중에 다시 등록해야 합니다.
정리가 끝나면 남은 카드로 바깥에서 실제로 열리는지 한 장씩 대 보세요. / 잃어버린 카드와 같은 묶음이던 카드가 따로 있다면 그것도 확인합니다.
@ 서교동 도어락 카드 삭제 재등록

# 두 번째, 번호도 새로 정하기
이번 일로 번호를 기억 못 한다는 걸 알았다면 새 번호를 정해 두세요. / 카드가 또 없어져도 번호로 들어갈 수 있게 하는 것이 목적입니다.
너무 쉬운 생일이나 같은 숫자 반복은 피하고, 가족만 아는 숫자로 정합니다. / 룸메이트와 함께 산다면 둘 다 기억하기 쉬운 숫자인지도 같이 따져 보세요. / 정한 번호는 휴대폰 잠금이 걸린 메모나 가족끼리만 알게 남겨 두세요.

# 새 카드는 아무거나 되나요
도어락마다 맞는 카드 방식이 있어 아무 카드나 등록되지는 않습니다. / 쓰던 것과 같은 종류의 카드나 태그를 준비하는 것이 가장 확실합니다.
교통카드나 사원증을 등록해 쓰는 분도 있는데, 되는 제품과 안 되는 제품이 있습니다. / 맞는 카드를 모르겠다면 도어락을 보고 알려드립니다.
카드 인식이 자주 안 되거나 제품이 오래됐다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 함께 고민해 볼 수 있습니다.

# 리모컨형 태그를 잃어버렸다면
차 키에 같이 달아 쓰는 리모컨형 태그나 버튼식 리모컨은 카드보다 값이 나가고 등록 방식도 조금 다릅니다. / 집 도어락용인지, 건물 주차장이나 공동현관용인지부터 구분해 주세요.
집 도어락용이라면 카드와 같은 방식으로 안쪽에서 정리할 수 있는 경우가 많습니다. / 주차장이나 건물 출입용은 건물 쪽 장치라 집주인이나 관리하는 분께 분실 사실을 알리고 다시 받는 것이 순서입니다.

# 다음에는 덜 당황하도록
- 카드는 두 장 이상 등록하고 한 장은 집 밖 믿을 곳에 맡기기
- 휴대폰 케이스와 지갑에 카드를 나눠 두기
- 카드에 호수나 주소를 적지 않기
- 한 달에 한 번은 번호로 직접 열어 보며 기억해 두기
번호를 가끔 눌러 보는 습관이 생각보다 큰 도움이 됩니다. / 카드에만 기대지 않는 것이 카드를 잃어버렸을 때 가장 좋은 대비입니다.

# 서교동에서 마포 어디든
합정동, 연남동, 망원동, 성산동과 공덕동, 아현동, 대흥동, 상암동까지 다닙니다. / 마포구 안이면 24시간 출동합니다.
마포 안내는 [마포구 출장열쇠](seoul-mapo.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
