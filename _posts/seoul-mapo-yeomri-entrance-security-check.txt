# 걱정보다 점검이 먼저
염리동은 아파트와 빌라가 함께 있는 마포 동네로, 공덕동과 대흥동, 아현동이 둘레에 있습니다. / 현관 방범이라고 하면 거창하게 들리지만, 실제로는 매일 쓰는 문이 제대로 닫히고 잠기는지 확인하는 일이 대부분입니다.
뉴스에서 무서운 이야기를 들으면 비싼 장치부터 떠올리게 됩니다. / 그런데 많은 경우는 문이 덜 닫혀 있거나 도어락이 자동으로 잠기지 않는 작은 틈에서 시작됩니다.
이 글은 염리동 집 현관을 주말에 10분 정도로 살펴볼 수 있게 순서대로 적었습니다. / 점검하다 손볼 곳이 보이면 [마포 출장열쇠](seoul-mapo.html)에 맡기셔도 됩니다.
@ 염리동 현관 도어락 방범 점검

# 1단계, 문이 정말 끝까지 닫히나요
현관문을 열었다가 손을 놓고 끝까지 닫히는지 지켜보세요. / 마지막 한 뼘에서 멈추거나 문틀에 살짝 걸려 덜 닫힌다면 그것부터가 방범 구멍입니다.
도어클로저 힘이 약해졌거나 경첩이 처지면 문이 덜 닫힙니다. / 이 상태에서는 도어락이 잠긴 것처럼 소리를 내도 걸쇠가 문틀 구멍에 다 들어가지 않을 수 있습니다.
닫힌 문을 바깥에서 살짝 당겨 보세요. / 덜컥거리며 움직인다면 걸쇠와 받이쇠 위치를 맞춰야 합니다.

# 2단계, 자동 잠금이 켜져 있나요
대부분의 번호키는 문이 닫히면 저절로 잠기는 기능이 있습니다. / 그런데 이사하면서 설정이 꺼졌거나 누군가 수동으로 바꿔 둔 채 쓰는 집도 있습니다.
문을 닫고 몇 초 기다린 뒤 잠기는 소리가 나는지 들어 보세요. / 소리가 없다면 안쪽 몸체에서 자동 잠금 설정을 확인해야 합니다.
설정 방법은 제품마다 달라 설명서를 보는 것이 가장 정확합니다. / 설명서가 없다면 도어락 사진을 보내 주시면 위치를 알려드립니다.

# 3단계, 번호판에 손자국이 남았나요
번호판을 비스듬히 비춰 보면 자주 누르는 숫자에만 손때가 남아 있는 경우가 있습니다. / 매일 같은 번호를 누르니 당연한 일이지만, 숫자 범위가 좁혀 보일 수 있습니다.
마른 천으로 번호판을 가끔 닦아 주세요. / 번호 앞뒤에 아무 숫자를 섞어 누르는 기능이 있는 제품이라면 그 기능을 쓰는 것도 도움이 됩니다.
누를 때 손으로 살짝 가리는 습관도 좋습니다. / 복도나 계단에서 다른 사람이 지나갈 때 특히 그렇습니다.
@ 염리동 도어락 번호판 손자국 확인

# 4단계, 안쪽 걸쇠와 보조키
현관 안쪽에 고리형 걸쇠나 보조키가 있다면 잘 움직이는지 확인하세요. / 오래 안 쓰면 뻑뻑해져서 정작 필요할 때 잘 안 걸립니다.
집에 있는 동안 걸쇠를 걸어 두는 습관은 도움이 됩니다. / 다만 아이나 어르신이 혼자 있을 때 걸쇠를 걸면 바깥에서 열기 어려워진다는 점도 함께 기억해 두세요.
걸쇠 나사가 헐거우면 걸어 두어도 힘을 받지 못합니다. / 손으로 흔들어 보고 움직인다면 나사를 다시 조여 주세요.

# 5단계, 문 아래와 옆 틈
문 아래 틈이 넓으면 바람과 소리가 들어오는 것은 물론 문 전체가 처졌다는 신호이기도 합니다. / 문을 닫은 채 위, 옆, 아래 틈을 눈으로 비교해 보세요.
한쪽 틈만 유난히 넓다면 경첩 쪽을 손봐야 합니다. / 틈을 막는 문풍지를 붙일 때 도어락 걸쇠 자리는 비워 두세요.
문 아래로 바깥 불빛이 많이 새어 들어온다면 문 하단 고무 패킹이 닳았을 수도 있습니다. / 패킹은 비교적 간단히 갈 수 있는 부분이라 점검할 때 같이 봐 드립니다.

# 6단계, 문 앞에 남는 흔적
현관 앞에 전단지나 택배 상자가 오래 쌓여 있으면 집이 비어 있다는 표시가 될 수 있습니다. / 여행을 떠날 때는 이웃이나 관리실에 부탁해 정리해 달라고 하는 것도 방법입니다.
문이나 도어락 주변에 원래 없던 스티커, 표시가 붙어 있다면 떼어 내세요. / 대부분 광고지만 굳이 남겨 둘 이유도 없습니다.
도어스코프가 있다면 안쪽 덮개가 닫혀 있는지도 확인해 보세요. / 덮개가 없는 제품이라면 안쪽에 가림 스티커를 붙여 두면 됩니다.

# 7단계, 빌라라면 공동현관도
염리동 빌라는 1층 공동현관과 각 집 현관이 따로 있는 건물이 많습니다. / 공동현관 문이 저절로 닫히지 않거나 번호가 오래 바뀌지 않았다면 건물 전체의 틈이 됩니다.
공동현관 문 닫힘이 약하다면 집주인이나 관리하는 분께 알려 주세요. / 공동 설비는 혼자 바꾸기보다 건물 사람들과 함께 정하는 것이 맞습니다.
@ 염리동 빌라 공동현관 출입문 점검

# 8단계, 번호와 카드 관리 상태
마지막으로 번호를 바꾼 것이 언제인지 떠올려 보세요. / 이사 온 뒤 한 번도 안 바꿨다면 이번 기회에 바꾸는 게 좋습니다.
등록된 카드나 태그가 몇 개인지, 지금 누가 갖고 있는지도 정리해 보세요. / 잃어버렸거나 주인이 불분명한 카드는 지우고 다시 등록하는 것이 깔끔합니다.

# 가족과 정해 두면 좋은 약속
점검이 끝나면 가족끼리 현관 쓰는 규칙을 몇 가지 정해 두세요. / 장치를 바꾸지 않아도 습관만으로 막을 수 있는 일이 꽤 있습니다.
- 마지막으로 나가는 사람이 문 닫힘 소리까지 듣고 출발하기
- 번호는 가족 안에서만 말로 나누고 메모로 남기지 않기
- 낯선 방문객에게는 문을 열기 전에 인터폰이나 도어스코프로 먼저 확인하기
- 카드를 잃어버리면 그날 바로 가족에게 알리기
아이가 있는 집이라면 혼자 있을 때 누가 와도 문을 열지 않는다는 약속을 한 번 더 이야기해 두세요. / 겁을 주기보다 차분하게 설명하는 편이 오래 기억에 남습니다.

# 점검하다 보이는 손볼 곳
- 문이 덜 닫히거나 걸쇠가 덜컥거림
- 자동 잠금이 안 되고 수동으로만 잠김
- 걸쇠, 보조키 나사가 헐거움
- 도어락 경고음이 자주 울림
이런 것들은 대부분 조정이나 부품 하나로 해결됩니다. / 고칠 수 있는 것은 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품일 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 점검을 맡기실 때
아파트는 단지 이름과 동, 호수를, 빌라는 도로명 주소와 건물 이름을 알려주세요. / 어느 부분이 마음에 걸리는지 미리 말씀해 주시면 그 부분부터 봅니다.
도착하면 사시는 분인지 신분증이나 우편물로 먼저 확인합니다. / 점검 뒤 손볼 곳과 비용을 먼저 말씀드리고, 동의하실 때만 작업합니다.
문이 잠겨 부르신 경우라면 끝내 못 열 때 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 염리동 둘레 마포 동네
공덕동, 대흥동, 아현동, 도화동, 용강동과 서교동, 합정동, 연남동, 상암동까지 다닙니다. / 마포구 안이면 24시간 출동합니다.
마포 안내는 [마포구 출장열쇠](seoul-mapo.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
