# 염리동 새집, 현관 번호는 누가 알고 있을까
염리동은 공덕역과 가까운 마포 동네로 아파트와 빌라가 함께 있는 곳입니다. / 이사철이면 짐을 옮기느라 바빠 현관 도어락은 뒤로 미루는 집이 많습니다.
그런데 지금 쓰는 번호는 이전에 살던 사람, 부동산 중개인, 인테리어 기사, 이삿짐 일꾼까지 알 수 있습니다. / 카드키와 지문도 이전 사람 것이 그대로 남아 있을 수 있습니다.
그래서 이사 들어간 날 가장 먼저 할 일 중 하나가 도어락 정리입니다. / 이 글에 순서를 적어 두었고, 혼자 어렵다면 [마포 출장열쇠](seoul-mapo.html)에 맡기셔도 됩니다.
@ 염리동 이사 도어락 초기화 새 비밀번호

# 입주 첫날 도어락 정리 순서
아래 순서대로 하면 빠뜨리는 것 없이 정리할 수 있습니다. / 짐 정리가 덜 됐어도 이것만은 첫날 해 두세요.
- 안쪽 몸체에서 제품 이름과 모델 확인
- 배터리 칸 열고 건전지 상태 확인
- 등록된 카드, 지문, 번호 전부 삭제 또는 초기화
- 새 번호 등록 후 안팎에서 여러 번 열어 보기
- 가족 카드와 지문 다시 등록
모델 이름은 대개 안쪽 몸체 아래나 배터리 칸 안쪽에 적혀 있습니다. / 사진을 찍어 두면 나중에 설명서를 찾을 때 편합니다.

# 번호만 바꾸면 끝이 아닙니다
많은 분들이 비밀번호만 새로 바꾸고 끝내십니다. / 하지만 카드키와 지문은 번호를 바꿔도 그대로 남는 제품이 많습니다.
이전 거주자가 쓰던 카드나 태그가 있다면 그것으로 여전히 문이 열릴 수 있습니다. / 부동산에서 카드를 몇 장 받았는지, 원래 몇 장이었는지 확인해 보세요.
지문식 도어락이라면 등록된 지문을 전부 지우는 기능이 따로 있습니다. / 이 기능을 쓰지 않으면 예전 사람 지문이 계속 남습니다.

# 초기화 버튼은 어디 있을까
대부분의 도어락은 안쪽 몸체 배터리 칸 근처에 작은 등록 버튼이나 초기화 버튼이 있습니다. / 제품에 따라 버튼을 길게 누르거나 특정 순서로 눌러야 초기화됩니다.
초기화하면 번호, 카드, 지문이 모두 지워지고 공장 설정으로 돌아갑니다. / 이후 새 번호를 처음부터 다시 등록해야 합니다.
설명서가 없다면 모델 이름으로 제조사 안내를 찾아보세요. / 순서를 잘못 누르면 설정이 꼬일 수 있으니 문을 열어 둔 상태에서 해 보시는 게 안전합니다.
@ 염리동 도어락 안쪽 초기화 버튼 위치

# 문은 열어 둔 채로 작업하세요
초기화나 번호 변경은 반드시 문을 연 상태에서 하세요. / 중간에 문이 닫혀 버리면 새 번호도 옛 번호도 안 맞아 밖에서 열 수 없게 됩니다.
새 번호를 등록했다면 바로 문을 닫지 말고 안쪽에서 여러 번 잠그고 풀어 보세요. / 그다음 밖으로 나가 번호로 한 번 열어 봐야 확실합니다.
가족이 함께 있을 때 해 두면 서로 번호를 바로 확인할 수 있습니다. / 혼자 할 때는 휴대폰 메모에 새 번호를 적어 두고 시작하세요.

# 마스터 번호를 모를 때
일부 도어락은 번호를 바꾸려면 관리자 번호, 흔히 마스터 번호를 먼저 넣어야 합니다. / 이전 거주자가 바꿔 두었다면 그 번호를 모를 수 있습니다.
이럴 때는 이전 집주인이나 부동산을 통해 물어보는 것이 먼저입니다. / 연락이 안 되면 초기화로 처음부터 다시 설정해야 합니다.
초기화가 버튼 하나로 안 되는 제품도 있습니다. / 몸체를 분리해야 하거나 제조사 전용 방법이 필요한 경우라면 맡기시는 편이 낫습니다.

# 세입자라면 미리 확인할 것
전세나 월세라면 도어락 번호를 바꾸는 것 자체는 대개 문제가 없습니다. / 다만 집주인이 관리 목적으로 번호를 알고 싶어 하는 경우가 있으니 한 번 이야기해 두세요.
도어락을 아예 바꾸고 싶다면 집주인과 상의하는 것이 좋습니다. / 퇴거할 때 원래 제품을 돌려놓아야 하는지도 미리 정해 두면 나중에 다툼이 없습니다.

# 공동현관 번호도 함께
빌라나 아파트는 건물 공동현관 번호가 따로 있습니다. / 이것은 개인이 바꿀 수 없고 관리사무소나 건물주가 관리합니다.
공동현관 번호가 너무 오래 그대로라면 관리하는 쪽에 바꿀 수 있는지 문의해 보세요. / 개인 현관과 공동현관 번호를 같게 정하지 않는 것도 좋습니다.

# 이사하면서 이런 문제도 같이 발견됩니다
이삿짐을 옮기다 보면 문을 오래 열어 두거나 세게 부딪히는 일이 생깁니다. / 그 뒤로 도어락 반응이 이상해졌다면 아래를 확인해 보세요.
- 문을 닫아도 자동으로 안 잠기는 경우
- 손잡이를 돌리면 걸리는 느낌이 드는 경우
- 번호판이 깜빡이거나 소리가 작아진 경우
이삿짐이 문틀이나 도어락에 부딪혀 위치가 살짝 틀어지면 걸쇠가 잘 맞지 않습니다. / 이런 경우에는 [도어락 수리](doorlock-repair.html)로 위치만 다시 맞추면 해결되기도 합니다.

# 출장으로 초기화를 맡기면
도착하면 이 집에 사시는 분인지 먼저 확인합니다. / 이사 직후라 주소지가 안 바뀌었다면 임대차 계약서나 매매 계약서, 관리사무소 확인으로도 됩니다.
작업 범위를 듣고 얼마인지 먼저 말씀드립니다. / 동의하시면 초기화, 새 번호, 카드와 지문 재등록까지 한 번에 진행합니다.
번호를 잊어 문이 안 열리는 상태라면 문을 여는 것부터 합니다. / 여는 방법은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 있습니다.
@ 염리동 출장열쇠 도어락 재설정 출장

# 새 도어락으로 바꿀 때
이전 거주자가 쓰던 도어락이 오래됐거나 마음에 들지 않는다면 이사 때가 바꾸기 좋은 시기입니다. / 짐이 들어오기 전이면 작업도 훨씬 수월합니다.
지금 문에 맞는 제품인지 먼저 확인하고 권해 드립니다. / 교체 과정은 [도어락 교체](doorlock-replace.html)에서 보실 수 있습니다.

# 새 번호 정할 때 피할 것
- 생일, 전화번호 뒷자리, 동 호수처럼 짐작하기 쉬운 번호
- 이전 집에서 쓰던 번호를 그대로 옮기는 것
- 공동현관 번호와 같은 번호
번호판에 손자국이 남는 자리를 보면 번호를 짐작할 수 있습니다. / 허수 번호 기능이 있다면 켜 두시는 것도 방법입니다.
허수 번호는 진짜 번호 앞뒤로 아무 숫자나 덧붙여 눌러도 열리게 하는 기능입니다. / 옆에서 누가 지켜봐도 실제 번호를 알아채기 어렵게 해 줍니다.
번호를 정했다면 가족끼리만 공유하고, 이사를 도와준 지인이나 기사에게는 알려주지 마세요.

# 염리동 이웃 동네까지 출동
아현동, 대흥동, 공덕동, 도화동처럼 바로 옆 동네와 망원동, 연남동, 성산동, 상암동까지 갑니다. / 마포구 안이면 24시간 출동합니다.
마포 지역은 [마포구 출장열쇠](seoul-mapo.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.

# 자주 묻는 질문
? 번호만 바꾸면 이전 카드는 안 되나요? | 제품에 따라 다릅니다. 카드와 지문이 따로 남는 경우가 많으니 함께 지우셔야 합니다.
? 초기화 버튼을 눌렀는데 아무 반응이 없어요. | 누르는 시간이나 순서가 제품마다 다릅니다. 모델 이름을 알려주시면 방법을 말씀드립니다.
? 이사 전 주소라 신분증 주소가 달라요. | 계약서나 관리사무소 확인으로 대신할 수 있습니다.
? 세입자가 도어락을 바꿔도 되나요? | 번호 변경은 대개 괜찮고, 제품 교체는 집주인과 미리 상의하시는 것을 권합니다.
? 초기화 작업 비용은 언제 알 수 있나요? | 도어락 종류와 작업 범위를 듣고 작업 전에 말씀드립니다.
