# 우리 집 번호를 남에게 알려줘야 할 때
용강동은 아파트 단지가 많은 마포 동네라 맞벌이 가정이나 아이 키우는 집이 적지 않습니다. / 낮 시간에 가사도우미, 아이 돌봄 선생님, 반려동물 돌봄 이웃이 드나들어야 하는 집도 있습니다.
그럴 때마다 가족이 쓰는 번호를 그대로 알려주자니 마음이 쓰이고, 매번 문을 열어 주러 오기도 어렵습니다. / 다행히 요즘 도어락은 가족 번호와 손님 번호를 나눠 쓰는 방법이 여럿 있습니다.
이 글은 용강동 집에서 외부 사람에게 번호를 줄 때 쓰기 좋은 방법과 끝난 뒤 정리하는 순서를 적었습니다. / 설정이 어렵거나 기능이 없는 도어락이라면 [마포 출장열쇠](seoul-mapo.html)에 맡기셔도 됩니다.
@ 용강동 아파트 도어락 임시 비밀번호 설정

# 가족 번호를 그대로 주면 생기는 일
한 번 알려준 번호는 일이 끝나도 상대 기억에 남아 있습니다. / 사람을 믿고 말고를 떠나서, 번호가 어디까지 전해졌는지 알 수 없게 되는 것이 문제입니다.
메모지에 적어 건네거나 문자로 보낸 번호는 다른 사람 눈에 띌 수도 있습니다. / 돌봄을 맡긴 분이 바뀔 때마다 가족 번호를 다시 바꾸는 것도 번거롭습니다.
그래서 처음부터 외부용 번호를 따로 두는 쪽이 관리가 쉽습니다. / 가족끼리 쓰는 번호는 가족 안에서만 돌게 하는 것이 기본입니다.

# 내 도어락에 어떤 기능이 있는지
같은 번호키라도 제품마다 손님용 기능이 다릅니다. / 안쪽 몸체나 배터리 덮개 안에 붙은 설명 스티커, 설명서를 먼저 찾아보세요.
- 정해진 횟수만 쓰고 지워지는 일회용 번호
- 따로 등록해 두고 필요 없을 때 지우는 보조 번호
- 사람마다 다르게 등록하는 카드나 태그
- 휴대폰 앱으로 시간을 정해 여는 기능
기능 이름은 회사마다 달라도 대부분 위 네 가지 가운데 하나입니다. / 무엇이 있는지 모르겠다면 도어락 앞면과 안쪽 사진을 보내 주시면 확인해 드립니다.

# 하루짜리 손님에게는 일회용 번호
부모님이 잠깐 다녀가시거나 택배 기사님께 현관 안쪽 보관을 부탁할 때는 일회용 번호가 편합니다. / 한 번 문이 열리면 그 번호는 바로 쓸 수 없게 되는 방식이 많습니다.
설정할 때는 안쪽 등록 버튼을 누르고 정해진 순서로 번호를 넣습니다. / 제품마다 순서가 달라 설명서를 보고 따라 하시는 게 안전합니다.
설정한 뒤에는 바깥에서 직접 한 번 눌러 보지 말고, 같은 방식으로 등록만 되었는지 화면이나 소리로 확인하세요. / 한 번 눌러 열어 보면 그 번호가 바로 지워질 수 있습니다.

# 매주 오는 분에게는 보조 번호나 카드
가사도우미나 돌봄 선생님처럼 정해진 요일에 오는 분께는 일회용보다 보조 번호가 맞습니다. / 가족 번호와 다른 번호를 하나 더 등록해 두는 방식입니다.
카드나 태그를 쓰는 도어락이라면 그분 몫의 카드를 따로 하나 등록해 드리는 것도 좋습니다. / 그만두실 때는 제품에 따라 그 카드만 지우거나, 전체를 지운 뒤 가족 카드만 다시 등록하면 됩니다.
카드는 어느 분께 몇 번 카드를 드렸는지 적어 두세요. / 나중에 지울 때 어느 것을 지워야 할지 헷갈리지 않습니다.
@ 용강동 돌봄 인력 카드키 따로 등록

# 앱으로 시간을 정해 여는 방식
앱 연동이 되는 도어락은 정해진 시간에만 열리는 번호를 보내는 기능이 있기도 합니다. / 출근한 뒤에도 휴대폰으로 문이 열렸는지 알림을 받을 수 있어 마음이 편합니다.
다만 집 와이파이나 연결 장치가 끊기면 알림이 늦게 오거나 안 올 수 있습니다. / 앱만 믿지 말고 번호나 카드 같은 다른 방법을 하나 더 남겨 두세요.

# 반려동물 돌봄을 맡길 때
여행이나 출장으로 며칠 집을 비우면 이웃이나 돌봄 서비스에 반려동물 밥을 부탁하기도 합니다. / 이때는 맡기는 기간 동안만 쓰는 보조 번호를 만들고, 돌아오는 날 바로 지우는 것이 깔끔합니다.
떠나기 전날 그 번호로 실제 문이 열리는지 함께 확인해 두세요. / 집을 비운 사이 배터리가 약해지면 번호를 알아도 문이 안 열리니, 출발 전에 배터리도 새것으로 바꿔 두면 안심입니다.

# 번호를 알려줄 때 지킬 것
- 문자보다는 직접 말로 알려주기
- 현관 앞이나 신발장에 번호를 적어 두지 않기
- 번호를 누를 때 가림막이나 손으로 가리고 누르도록 안내
- 비밀번호 앞뒤에 아무 숫자를 덧붙여 누르는 기능이 있으면 알려주기
번호 앞뒤에 숫자를 섞어 누르는 기능은 번호판에 손자국이 남는 것을 줄여 줍니다. / 지원하는 제품인지는 설명서에서 확인해 보세요.

# 일이 끝나면 꼭 해야 할 정리
돌봄을 맡긴 기간이 끝나면 그 사람 몫의 번호와 카드를 지우는 것이 마무리입니다. / 지우지 않고 두면 몇 달 뒤에도 그 번호로 문이 열립니다.
지운 뒤에는 바깥에서 그 번호를 한 번 눌러 열리지 않는지 확인하세요. / 가족 번호와 카드가 그대로 잘 열리는지도 같이 봅니다.
번호를 지우는 방법이 전체 초기화밖에 없는 제품도 있습니다. / 이때는 가족 번호와 카드를 다시 등록해야 하니 시간을 넉넉히 잡으세요.

# 설정하다 막히는 흔한 경우
등록 버튼을 길게 눌렀더니 모든 번호가 지워졌다는 분이 있습니다. / 짧게 누를 때와 길게 누를 때 기능이 다른 제품이 많아서 그렇습니다.
등록 중간에 시간이 지나 처음으로 돌아가는 경우도 있습니다. / 번호를 미리 정해 두고 한 번에 이어서 누르면 덜 헷갈립니다.
설정이 엉켜 가족 번호까지 안 먹는다면 문 안쪽에서 해결하기 어려울 수 있습니다. / 문이 닫힌 뒤라면 그대로 두고 연락 주세요.
@ 용강동 도어락 등록 버튼 비밀번호 설정 점검

# 용강동에서 출장 부르실 때
아파트 이름과 동, 호수, 그리고 원하는 설정 내용을 알려주세요. / 손님용 번호를 새로 만들지, 기존 번호를 지울지 미리 정해 두시면 금방 끝납니다.
도어락 앞면과 안쪽 몸체 사진을 보내 주시면 제품에 손님 기능이 있는지 미리 봐 드립니다. / 기능이 없는 오래된 제품이라면 [도어락 교체](doorlock-replace.html)와 [도어락 설치](doorlock-install.html) 안내도 참고해 보세요.

# 방문하면 먼저 확인하는 것
비밀번호와 카드를 다루는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소나 주소가 나온 우편물, 관리사무소 확인 가운데 하나면 됩니다.
작업 내용과 비용은 손대기 전에 먼저 말씀드립니다. / 문이 잠겨 부르신 경우라면 못 열 때 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 용강동 근처 마포 동네
도화동, 대흥동, 염리동, 공덕동, 아현동과 서교동, 합정동, 망원동, 상암동까지 다닙니다. / 마포구 안이면 24시간 출동합니다.
마포 안내는 [마포구 출장열쇠](seoul-mapo.html), 다른 지역은 [출장 지역](area.html)에서 확인하세요.
