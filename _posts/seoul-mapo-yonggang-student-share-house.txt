# 용강동 자취방 문 앞에서 혼자 막혔다면
용강동은 공덕역 생활권에 붙어 있는 마포 동네로 아파트와 빌라, 작은 원룸 건물이 섞여 있습니다. / 학교나 회사 때문에 혼자 지내거나 여럿이 한 집을 나눠 쓰는 분도 적지 않습니다.
혼자 사는 집은 문이 잠기면 열어 줄 사람이 없습니다. / 쉐어하우스는 내 방문, 현관, 건물 공동 출입문까지 문이 여러 겹이라 어디가 막혔는지부터 헷갈립니다.
이 글은 자취방, 고시원, 쉐어하우스처럼 작은 공간에서 문이 막혔을 때의 순서를 적었습니다. / 혼자 해결하기 어려우면 [마포 출장열쇠](seoul-mapo.html)에 바로 연락하셔도 됩니다.
@ 용강동 자취방 원룸 출입문 잠김

# 막힌 문이 어느 문인지 먼저 구분하세요
같은 "문이 안 열려요"라도 어느 문인지에 따라 연락할 곳이 다릅니다. / 아래 셋 가운데 어디인지 먼저 정리해 보세요.
- 건물 1층 공동 출입문
- 집 또는 쉐어하우스 전체 현관문
- 내 방문, 고시원 개인실 문
공동 출입문은 대개 건물주나 관리하는 분이 비밀번호를 바꿀 수 있습니다. / 현관문과 방문은 사는 사람이 직접 연락해야 하는 경우가 많습니다.

# 쉐어하우스라면 함께 사는 사람에게 먼저
쉐어하우스 현관이 안 열린다면 같이 사는 사람에게 연락해 보세요. / 누군가 안에 있으면 문을 열어 줄 수 있고, 번호가 바뀌었는지도 알 수 있습니다.
운영하는 분이 따로 있는 쉐어하우스는 단체 대화방이나 관리 연락처가 있습니다. / 비밀번호가 바뀌었다는 공지를 놓친 경우도 꽤 있으니 한 번 확인해 보세요.
아무에게도 연락이 닿지 않고 급하다면 그때 출장을 부르시면 됩니다. / 다만 같이 사는 사람의 물건이 있는 공간이니 신분 확인은 더 꼼꼼하게 합니다.

# 고시원 개인실 문이 잠겼다면
고시원 방문은 열쇠나 작은 번호키가 달린 경우가 대부분입니다. / 총무실이나 관리하는 분이 여분 열쇠를 가지고 있을 수 있으니 먼저 물어보세요.
늦은 밤이라 관리하는 분이 자리에 없을 때가 문제입니다. / 이럴 때 출장으로 열 수 있지만, 건물 규칙상 관리자 확인이 필요한지도 함께 봐야 합니다.
방문 손잡이가 안에서 눌러 잠그는 형태라면 문을 닫는 순간 잠깁니다. / 잠깐 화장실에 갈 때도 열쇠나 카드를 챙기는 습관이 필요합니다.
@ 용강동 고시원 쉐어하우스 방문 잠금

# 자취방 도어락이 안 열리는 흔한 이유
원룸 현관 도어락이 안 열리는 원인은 대부분 정해져 있습니다. / 아래 중 무엇인지 보시면 전화할 때 설명하기 쉽습니다.
- 배터리가 다 돼서 번호판이 꺼진 경우
- 이사 오고 번호를 바꾸지 않아 이전 번호를 헷갈리는 경우
- 카드키를 방 안에 두고 나온 경우
- 문이 덜 닫혀 걸쇠가 문틀에 걸린 경우
번호판이 꺼졌다면 바깥쪽 비상 단자에 9V 건전지를 대 보세요. / 편의점에서 쉽게 구할 수 있습니다.
건전지를 대고 번호를 누를 때는 손을 떼지 말고 끝까지 대고 있어야 합니다. / 문이 열리면 안쪽 배터리를 모두 새것으로 갈아 주세요.

# 혼자 사는 집, 이런 행동은 피하세요
혼자 있으면 조급해져서 무리한 방법을 쓰게 됩니다. / 그러다 다치거나 문이 더 망가지기도 합니다.
창문이나 베란다로 들어가려는 시도는 하지 마세요. / 원룸 건물이라도 높이가 있는 곳이 많고, 이웃이 오해할 수도 있습니다.
문틈에 카드나 옷걸이를 넣어 걸쇠를 밀어 보는 것도 권하지 않습니다. / 도어락 안쪽이 상하면 그다음에는 정상 번호로도 안 열립니다.

# 통화에서 말해 줄 다섯 가지
아래 내용을 말씀해 주시면 장비와 도착 시간을 바로 정할 수 있습니다. / 짧게만 말씀하셔도 괜찮습니다.
- 건물 이름과 도로명 주소, 층과 호수
- 막힌 문의 종류 (공동 출입문, 현관, 방문)
- 도어락 모양 또는 열쇠 구멍 사진
- 공동 출입문 비밀번호를 아는지
- 신분증을 지금 가지고 있는지
용강동은 빌라와 원룸 골목이 이어져 있어 건물 이름만으로는 찾기 어려울 때가 있습니다. / 근처 큰길이나 공원 같은 기준을 함께 알려주시면 좋습니다.

# 문을 열기 전 확인 절차
원룸과 쉐어하우스는 같은 건물에 사는 사람이 많아 확인을 더 꼼꼼히 합니다. / 신분증의 주소, 이 주소로 온 우편물이나 택배 송장, 계약서 사진 가운데 하나를 보여 주세요.
전입 신고 전이라 신분증 주소가 다르다면 임대 계약서나 건물주 확인으로 대신할 수 있습니다. / 어느 것도 확인이 어렵다면 작업을 진행하지 않으니 이해 부탁드립니다.

# 비용은 열기 전에 먼저
문과 잠금장치 종류를 보고 얼마인지 먼저 말씀드립니다. / 학생이라 부담이 걱정되시면 전화로 먼저 물어보셔도 됩니다.
못 열면 비용은 받지 않습니다. / 연 뒤에 말없이 붙는 금액도 없습니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 작은 문도 상하지 않게 엽니다
방문이나 고시원 문은 현관문보다 얇아서 쉽게 상합니다. / 그래서 손잡이와 문짝을 상하지 않게 여는 방법부터 씁니다.
현관 도어락도 마찬가지로 덜 상하는 방법부터 시도합니다. / 자세한 내용은 [현관문 개문](door-open.html)에 있습니다.
@ 용강동 원룸 도어락 비파손 개문

# 이사 왔다면 번호부터 바꾸세요
자취방이나 쉐어하우스에 처음 들어갔다면 현관 번호를 바꿀 수 있는지 확인해 보세요. / 이전에 살던 사람이 번호를 알고 있을 수 있습니다.
쉐어하우스는 마음대로 바꾸면 다른 사람이 못 들어올 수 있으니 운영하는 분과 상의하세요. / 내 방 잠금장치는 바꿔도 되는지 먼저 물어보는 것이 좋습니다.
번호 바꾸는 방법이 어렵거나 초기화가 필요하면 [도어락 수리](doorlock-repair.html) 쪽으로 도와드립니다. / 아예 새로 달아야 한다면 [도어락 설치](doorlock-install.html)를 참고하세요.

# 혼자 사는 분의 비상 대비
작은 준비 몇 가지로 문 앞에서 막히는 일을 크게 줄일 수 있습니다.
- 현관 비밀번호를 믿을 수 있는 가족에게 알려 두기
- 9V 건전지 하나를 가방에 넣고 다니기
- 카드키 여분은 지갑에 따로 보관
- 공동 출입문 번호가 바뀌면 바로 메모해 두기
휴대폰을 방 안에 두고 나와 연락할 방법이 없을 때를 대비해 가족 번호 하나는 외워 두세요. / 이웃이나 편의점에서 전화를 빌려 연락 주셔도 똑같이 출동합니다.

# 용강동 바깥 마포 동네도 갑니다
도화동, 공덕동, 대흥동, 염리동은 물론 서교동, 합정동, 연남동, 성산동까지 갑니다. / 마포구 안이면 24시간 출동합니다.
지역 정보는 [마포구 출장열쇠](seoul-mapo.html), 다른 곳은 [출장 지역](area.html)에서 보세요.

# 마무리
용강동 자취방이나 쉐어하우스에서 문이 막히면 어느 문인지부터 구분하고, 같이 사는 사람이나 관리하는 분에게 먼저 연락해 보세요. / 연락이 안 되거나 급하면 그때 전화 주시면 됩니다.
24시출장열쇠는 혼자 사는 분의 늦은 밤 연락도 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
