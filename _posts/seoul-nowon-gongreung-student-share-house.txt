# 공릉역 근처 작은 방 앞에서 멈췄을 때
공릉동은 공릉역 주변으로 원룸 건물이 많고 혼자 사는 분이 많은 동네입니다. / 자취방 한 칸, 고시원 방 한 칸, 여럿이 부엌을 같이 쓰는 쉐어하우스까지 사는 모양도 제각각입니다.
이런 집은 문이 하나가 아니라는 점이 아파트와 다릅니다. / 건물 입구, 층 복도, 내 방 문이 따로 잠기니 어디서 막혔는지에 따라 연락할 사람이 달라집니다.
이 글은 공릉동 작은 방에서 문이 안 열릴 때 누구에게 먼저 알리면 좋은지 정리했습니다. / 그래도 안 풀리면 [노원 출장열쇠](seoul-nowon.html)를 어떻게 부르면 되는지도 이어서 적었습니다.
@ 공릉동 자취방 원룸 출입문 잠김

# 먼저 어느 문에서 막혔는지 나눠 보세요
같은 "문이 안 열린다"도 위치에 따라 사정이 완전히 다릅니다. / 숨 한 번 고르고 지금 서 있는 곳이 어디인지부터 짚어 보세요.
- 건물 1층 공동 출입문: 비밀번호가 바뀌었거나 카드가 안 먹는 경우
- 고시원 층 입구: 운영자가 관리하는 번호나 열쇠가 따로 있는 경우
- 내 방 문: 도어락 건전지, 번호 분실, 열쇠를 안에 둔 경우
- 쉐어하우스 현관: 함께 사는 사람이 번호를 바꾼 경우
막힌 곳이 공동 출입문이라면 문을 여는 것보다 번호를 아는 사람에게 연락하는 편이 빠릅니다. / 같은 건물에 사는 이웃이 들어가는 길에 함께 들어가는 것도 방법이지만, 처음 보는 사람에게 문을 열어 달라고 하기 어렵다면 무리하지 마세요.
내 방 문에서 막혔다면 그때부터가 출장열쇠가 할 일입니다. / 다만 그 방이 누구 관리인지에 따라 미리 알릴 사람이 있으니 아래 순서를 한 번 보고 연락하셔도 늦지 않습니다.

# 자취방이라면 집주인 연락처부터
원룸 건물은 건물주나 관리하는 분이 여분 열쇠나 관리자 번호를 가지고 있는 경우가 있습니다. / 늦은 밤이 아니라면 문자 한 통으로 해결되기도 합니다.
연락이 안 되거나 여분이 없다고 하면 그때 출장을 부르셔도 늦지 않습니다. / 집주인과 통화가 됐다면 출장 불러도 되는지, 도어락을 바꿔야 할 때 누가 정할지 미리 한마디 나눠 두면 나중이 편합니다.

# 고시원은 운영자가 열쇠를 쥐고 있습니다
고시원은 방마다 번호키나 열쇠를 운영하는 쪽에서 관리하는 경우가 많습니다. / 총무실이나 운영자 연락처가 입구에 붙어 있으니 먼저 확인해 보세요.
고시원 방문은 같은 모양 잠금장치를 여러 칸에 쓰는 일이 흔합니다. / 그래서 운영자 허락 없이 따로 바꾸거나 손대면 곤란해질 수 있으니 출장을 부르기 전에 꼭 알려 두세요.
@ 공릉동 고시원 방문 번호키 열쇠

# 쉐어하우스는 같이 사는 사람과 먼저
여럿이 사는 집은 누군가 현관 번호를 바꾸고 단체방에 알리는 것을 깜빡하는 일이 생깁니다. / 문 앞에서 번호가 계속 틀린다면 같이 사는 사람에게 먼저 물어보세요.
내 방 문까지 따로 잠기는 구조라면 내 방 열쇠는 나만 가지고 있을 가능성이 큽니다. / 이 경우는 같이 사는 사람이 도와줄 수 없으니 관리하는 분이나 출장 쪽으로 넘어가야 합니다.

# 문 앞에서 혼자 해 볼 만한 것
작은 방 도어락도 원리는 같아서 번호판이 꺼졌다면 건전지부터 의심해 볼 수 있습니다. / 바깥 아래쪽에 9V 건전지 단자가 있는지 살펴보고, 공릉역 근처 편의점에서 하나 사서 대 보세요.
번호를 몇 번 틀렸다면 잠시 멈춰야 합니다. / 계속 누르면 도어락이 한동안 입력을 막아서 기다리는 시간만 늘어납니다.
열쇠로 여는 방이라면 가방 안쪽 주머니, 외투 주머니, 오늘 들른 곳을 한 번 더 떠올려 보세요. / 고시원 방 열쇠는 작고 가벼워서 다른 물건 사이에 끼어 있는 일이 의외로 많습니다.

# 좁은 복도라서 더 조심할 것
원룸과 고시원 복도는 폭이 좁아 문을 세게 흔들거나 두드리면 소리가 그대로 옆방에 전해집니다. / 늦은 시간이면 이웃이 놀라 신고하는 일도 있으니 힘으로 열려고 하지 마세요.
카드나 자로 문틈을 긁으면 얇은 방문은 금방 패이고 흠집이 남습니다. / 퇴거할 때 원상복구 이야기가 나올 수 있으니 그대로 두는 편이 낫습니다.

# 출장을 부를 때 알려 주실 것
공릉동 원룸 건물은 이름이 없거나 비슷한 건물이 붙어 있는 경우가 많습니다. / 도로명 주소와 함께 아래 내용을 알려 주시면 찾기 쉽습니다.
- 건물 주소, 층, 호수 또는 방 번호
- 건물 공동 출입문을 열 수 있는지
- 막힌 문이 건물 입구인지 내 방인지
- 도어락 모양과 번호판 상태
- 집주인이나 운영자에게 연락했는지
문 사진을 한 장 보내 주시면 맞는 장비를 챙겨 가기 좋습니다.

# 사는 사람인지는 이렇게 확인합니다
작은 방은 계약서나 우편물이 방 안에 있는 경우가 많아 확인이 어려울 때가 있습니다. / 신분증 주소가 다르다면 집주인이나 운영자와 통화로 확인하는 방법도 씁니다.
같이 사는 사람이 있다면 그분 확인도 도움이 됩니다. / 확인이 안 되면 문을 열 수 없으니 미리 양해 부탁드립니다.
휴대폰에 전자 계약서나 월세 이체 내역이 남아 있다면 그것도 참고 자료가 됩니다. / 어떤 것으로 확인할지 통화할 때 미리 상의하시면 현장에서 시간이 덜 걸립니다.

# 비용 안내와 진행 순서
방문 종류와 도어락 상태를 본 뒤 손대기 전에 비용부터 말씀드립니다. / 듣고 결정하시면 되고, 그만두셔도 됩니다.
끝내 못 열면 비용은 받지 않습니다. / 여는 방법은 [현관문 개문](door-open.html)에, 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.
@ 공릉동 쉐어하우스 방문 도어락 개방

# 열린 뒤 작은 방에서 해 둘 일
번호를 잊어서 열었다면 새 번호를 정하고, 같이 사는 사람과 공유할지 정해 두세요. / 건전지가 원인이었다면 남은 것까지 한꺼번에 새것으로 바꾸는 게 좋습니다.
도어락이 낡아 자주 말썽이라면 집주인과 이야기해서 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 정하세요. / 세입자가 마음대로 바꾸기보다 먼저 상의하는 편이 나중에 깔끔합니다.

# 혼자 사는 방, 미리 해 두면 편한 것
- 집주인이나 운영자 연락처를 휴대폰과 수첩에 함께 저장
- 친한 사람 한 명에게 비상 연락처 알려 두기
- 열쇠 방이라면 여분 하나를 믿을 만한 곳에 맡기기
- 번호판 경고음이 나면 그날 건전지 교체
휴대폰까지 방에 두고 나왔을 때를 생각해서 연락처 하나쯤은 외워 두면 든든합니다. / 쉐어하우스라면 현관 번호를 바꿀 때 꼭 단체방에 남기자는 규칙을 하나 정해 두세요.

# 공릉동 이웃 노원구 동네
공릉동과 붙은 하계동, 월계동, 그리고 중계동, 상계동까지 노원구 전 지역을 다닙니다. / 다니는 동네는 [출장 지역](area.html)에서 보실 수 있습니다.
