# 큰일이 생기기 전에 한 번 둘러보기
중계동은 중계역 주변으로 큰 아파트 단지와 학원가가 함께 있는 동네입니다. / 낮에는 아이들끼리 집에 있는 시간이 있고, 밤에는 늦게 귀가하는 식구가 있는 집도 많습니다.
현관 방범이라고 하면 거창하게 들리지만 실제로는 매일 쓰는 문이 제대로 잠기는지 확인하는 일에 가깝습니다. / 걱정을 키우기보다 주말 십여 분 동안 차분히 살펴보는 것만으로 충분합니다.
이 글은 중계동 아파트 현관을 혼자 둘러볼 때 볼 곳을 여섯 군데로 나눴습니다. / 손볼 곳이 보이면 [노원 출장열쇠](seoul-nowon.html)에 상담하셔도 됩니다.
@ 중계동 아파트 현관 방범 점검

# 첫째, 문이 끝까지 닫히는지
가장 먼저 볼 것은 도어락이 아니라 문 자체입니다. / 문을 놓았을 때 스스로 끝까지 닫히고 "철컥" 하고 잠기는지 여러 번 확인해 보세요.
문이 마지막 한 뼘에서 멈추거나 살짝 떠 있으면 잠긴 줄 알고 그냥 지나치기 쉽습니다. / 이런 집은 대개 문 위쪽 닫힘 장치가 약해졌거나 경첩이 처져 있습니다.
닫힘 속도가 너무 빨라 쾅 부딪히는 것도 좋지 않습니다. / 충격이 쌓이면 잠금쇠가 조금씩 밀려나 결국 잠김이 헐거워집니다.

# 둘째, 자동 잠김이 켜져 있는지
요즘 도어락은 문이 닫히면 저절로 잠기는 기능이 있습니다. / 그런데 청소나 이사 때 수동으로 바꿔 놓고 그대로 둔 집도 있습니다.
안쪽 몸체의 스위치나 설정에서 자동 잠김이 켜져 있는지 확인해 보세요. / 수동으로 써야 하는 사정이 있다면 나갈 때마다 잠금 버튼을 누르는 습관을 식구 모두가 함께 들여야 합니다.
자동 잠김이 켜져 있는데도 가끔 안 잠긴다면 문이 끝까지 닫히지 않아서일 수 있습니다. / 첫째 항목과 둘째 항목은 이렇게 서로 이어져 있어서 함께 보는 편이 좋습니다.

# 셋째, 번호판 위 손자국
번호판을 비스듬히 비춰 보면 자주 누르는 숫자에만 손때가 남아 있는 경우가 있습니다. / 마른 천으로 가볍게 닦아 두기만 해도 번호가 쉽게 읽히지 않습니다.
번호를 누르기 전에 아무 숫자를 몇 개 더 누르는 허수 입력 기능이 있다면 써 보세요. / 대부분 제품에서 맞는 번호가 중간에 들어 있으면 열리게 되어 있습니다.
@ 중계동 도어락 번호판 손자국 닦기

# 넷째, 안쪽 걸쇠와 보조 잠금
문 안쪽 위쪽에 달린 안전 걸쇠가 헐겁게 흔들리지 않는지 손으로 잡아 보세요. / 나사가 빠지기 직전이라면 드라이버로 조여 두는 정도는 직접 하셔도 됩니다.
걸쇠는 문을 조금만 열어 택배를 받을 때 쓰기 좋습니다. / 다만 아이가 혼자 걸어 버리면 바깥에서 열기 어려우니, 아이가 손 닿는 높이인지도 함께 봐 두세요.
열쇠로 잠그는 보조키가 따로 있다면 그 열쇠가 지금 몇 개이고 누구에게 있는지도 세어 보세요. / 쓰지 않는 보조키라면 잠긴 채 잊히는 일이 없도록 열린 상태로 두는 편이 낫습니다.

# 다섯째, 문틀과 잠금쇠 받이
문을 열고 문틀 쪽 잠금쇠가 들어가는 구멍을 보세요. / 받이쇠가 들뜨거나 나사가 헐거우면 잠금쇠가 제대로 물리지 않습니다.
문을 닫은 상태에서 손잡이를 밀고 당겨 봤을 때 덜컹거림이 크다면 받이 위치가 어긋났을 수 있습니다. / 이런 부분은 혼자 맞추기 어려우니 다른 볼일로 부를 때 함께 봐 달라고 하셔도 됩니다.

# 여섯째, 건전지와 경고음
건전지가 약해지면 도어락은 경고음으로 먼저 알려 줍니다. / 이 소리를 며칠 미루다 번호판이 꺼져 문 앞에서 막히는 경우가 가장 흔합니다.
주말 점검 때 건전지 칸을 열어 교체 날짜 메모가 있는지 보세요. / 한 해 가까이 됐다면 경고음이 없어도 한꺼번에 새것으로 바꿔 두는 편이 마음 편합니다.
바꿀 때 접점에 하얀 가루나 녹이 묻어 있으면 마른 천으로 닦아 주세요. / 접점이 깨끗해야 새 건전지도 제 힘을 냅니다.

# 비밀번호와 카드 정리도 방범입니다
예전에 일하러 왔던 분, 잠깐 같이 살았던 친척, 이사 전 세대가 번호를 알고 있을 수 있습니다. / 마지막으로 번호를 바꾼 게 언제인지 기억나지 않는다면 이번 기회에 바꿔 두세요.
카드키를 몇 장 등록했는지, 그중 지금 누가 들고 있는지도 확인해 보세요. / 잃어버린 카드가 있다면 그 카드만 지우기 어려운 제품이 많아 전체 삭제 후 다시 등록하는 편이 깔끔합니다.

# 집을 오래 비우기 전에 덧붙일 것
여행이나 명절로 며칠 집을 비운다면 떠나기 전날 건전지 상태부터 확인하세요. / 비어 있는 동안에도 도어락은 조금씩 전기를 쓰기 때문에, 돌아온 날 번호판이 꺼져 있는 일이 생깁니다.
현관 앞에 택배가 며칠씩 쌓이지 않게 배송 일정을 조정하거나 경비실 보관을 부탁해 두는 것도 좋습니다. / 문 앞이 깔끔하면 집을 비웠다는 티가 덜 납니다.
떠나기 직전에는 문을 닫고 바깥에서 손잡이를 한 번 당겨 잠김을 직접 확인하세요. / 짐을 들고 서두르다 보면 문이 덜 닫힌 채 엘리베이터에 오르는 경우가 있습니다.

# 지나치게 걱정하지 않아도 되는 것
현관 방범은 문이 제대로 닫히고 잠기는지, 번호와 카드가 정리돼 있는지가 거의 전부입니다. / 큰 단지에는 경비실과 공동 현관도 있으니 기본만 지켜도 충분히 안심하고 지낼 수 있습니다.
값비싼 장치를 여러 개 더 다는 것보다 매일 쓰는 도어락과 문이 제대로 움직이게 두는 것이 먼저입니다. / 필요 없는 장치를 권하지 않으니 편하게 상담하셔도 됩니다.

# 이런 경우는 점검을 받아 보세요
- 잠금 버튼을 눌러도 모터 소리만 나고 잠금쇠가 덜 나올 때
- 문을 닫아도 자동 잠김이 될 때도 있고 안 될 때도 있을 때
- 손잡이를 당기면 잠긴 상태에서도 문이 조금 움직일 때
- 번호판이 가끔 혼자 켜지거나 삑 소리를 낼 때
이런 증상은 [도어락 수리](doorlock-repair.html)로 손보면 되는 경우가 많습니다. / 부품을 구하기 어려울 만큼 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.

# 방문 점검을 부를 때
중계동은 단지마다 동이 많으니 단지 이름, 동, 호수를 알려 주세요. / 어떤 증상이 보였는지 메모해 두셨다가 말씀해 주시면 바로 그 부분부터 봅니다.
방문하면 먼저 사시는 분인지 신분증이나 우편물, 관리사무소 확인으로 확인합니다. / 점검 뒤 손볼 곳이 있으면 작업 전에 비용을 먼저 말씀드리고, 원하지 않으시면 점검만으로 마칩니다.
문이 잠겨 열어야 하는 상황이라면 끝내 못 열었을 때 비용은 받지 않습니다. / 자세한 진행은 [이용안내](guide.html)에 있습니다.
@ 중계동 현관 도어락 방문 점검
