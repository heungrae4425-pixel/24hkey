# 현관 안쪽이 축축한 집의 도어락
중계동은 중계역을 중심으로 큰 아파트 단지가 이어진 동네라 겨울이면 난방을 오래 켜 두는 집이 많습니다. / 바깥은 차고 집 안은 따뜻하니 현관문 안쪽 철판에 물방울이 맺히는 일이 흔합니다.
장마철에는 반대로 바깥 습기가 계단실과 복도를 채우고, 현관 앞에 세워 둔 우산이 습기를 더합니다. / 계절은 달라도 도어락이 축축한 공기 속에 놓인다는 점은 같습니다.
이 글은 중계동 아파트에서 습기 때문에 도어락이 이상해질 때 집 안 어디서 습기가 오는지, 어떤 습관이 도움이 되는지, 언제 [노원 출장열쇠](seoul-nowon.html)를 부르면 되는지 정리했습니다.
@ 중계동 현관문 결로 도어락 습기 오작동

# 습기가 원인일 때 보이는 모습
습기 때문에 생기는 오작동은 날씨나 시간대를 따라 움직인다는 특징이 있습니다. / 아래 모습이 보이면 습기를 먼저 의심해 보세요.
- 비 오는 날만 번호 몇 개가 잘 안 눌린다
- 아무도 안 만졌는데 번호판이 혼자 켜지거나 삑 소리가 난다
- 겨울 아침 안쪽 몸체 아래에 물자국이 남아 있다
- 건전지 덮개 안쪽이 뿌옇거나 접점이 거뭇하다
- 해가 들고 집이 마르면 다시 괜찮아진다
특히 "혼자 울리는" 증상은 번호판 사이로 들어간 물기가 접점을 이어 버려서 생기는 경우가 많습니다. / 고장이라기보다 젖어서 헷갈리는 상태에 가깝습니다.

# 우리 집 습기는 어디서 올까
도어락 주변 습기는 바깥 날씨만으로 생기지 않습니다. / 집 안 생활에서 생긴 습기가 현관으로 모이는 경우도 많습니다.
겨울에 거실이나 현관 쪽에 빨래를 널어 말리면 그 습기가 차가운 현관문에 닿아 물방울이 됩니다. / 가습기를 현관 가까이 두는 것도 같은 결과를 냅니다.
요리할 때 나는 김, 욕실 문을 열어 두고 샤워하는 습관도 현관까지 습기를 보냅니다. / 현관이 집에서 가장 차가운 곳이라 습기가 그곳에 맺히기 쉽습니다.
환기를 짧게라도 하루 두어 번 해 주면 집 안 습도가 내려가 현관 결로도 함께 줄어듭니다. / 추운 날에는 창문을 오래 열기보다 몇 분씩 자주 여는 편이 낫습니다.

# 겨울 결로가 생길 때
현관문 안쪽에 물방울이 맺히기 시작하면 아침마다 마른 수건으로 한 번 닦아 주세요. / 특히 도어락 몸체 아래쪽과 문 경첩 쪽 모서리에 물이 고이기 쉽습니다.
현관 중문이 있다면 밤에는 닫아 두는 것이 좋습니다. / 거실의 따뜻하고 습한 공기가 차가운 현관문에 바로 닿지 않게 막아 줍니다.
결로 방지 시트를 붙이실 때는 도어락 몸체와 걸쇠 구멍 둘레는 비워 두세요. / 시트가 걸쇠를 덮으면 문이 덜 닫히고, 덜 닫힌 문은 또 다른 경고음을 부릅니다.
보일러를 아주 높게 틀어 두는 날일수록 결로가 심해집니다. / 실내 온도를 조금만 낮춰도 현관문에 맺히는 물방울 양이 눈에 띄게 줄어듭니다.

# 장마철 습기가 찰 때
젖은 우산과 우비는 현관 안쪽이 아닌 욕실이나 베란다에서 말려 주세요. / 문 옆에 세워 두면 물기가 도어락 바로 아래로 흘러 고입니다.
비에 젖은 손으로 번호판을 누르는 것도 습기를 직접 넣는 일입니다. / 옷에 손을 한 번 닦고 누르는 습관만으로도 차이가 납니다.
제습기가 있다면 장마철 며칠은 현관 쪽을 향해 틀어 두는 것도 방법입니다. / 신발장 안에 습기 제거제를 넣어 두면 현관 전체가 덜 눅눅해집니다.
@ 중계동 장마철 현관 습기 도어락 번호판

# 번호판이 혼자 울릴 때 해 볼 것
마른 수건으로 번호판 표면을 가볍게 눌러 닦아 주세요. / 세게 문지르면 틈 사이로 물기가 더 밀려 들어갈 수 있습니다.
그다음 몇 분 기다린 뒤 다시 눌러 봅니다. / 습기가 날아가면서 저절로 정상으로 돌아오는 경우가 꽤 있습니다.
드라이기를 쓴다면 차가운 바람이나 약한 바람으로 멀리서 잠깐만 대 주세요. / 뜨거운 바람을 가까이 오래 대면 번호판 코팅이 상합니다.
물티슈나 세정제로 닦는 것도 피해 주세요. / 남은 물기와 성분이 틈으로 스며들어 오히려 증상을 늘립니다.

# 건전지 칸도 열어 보세요
습기가 오래 머물면 건전지 칸 접점에 녹이 생깁니다. / 덮개를 열었을 때 접점이 초록색이나 갈색으로 변해 있으면 습기가 들어온 흔적입니다.
가벼운 변색이면 마른 천으로 닦고 새 건전지를 넣어 보세요. / 녹이 깊거나 건전지에서 액이 샌 흔적이 있으면 직접 긁어내지 말고 점검을 받는 게 안전합니다.

# 문이 아예 안 열린다면
번호판이 꺼졌다면 바깥쪽 비상 단자에 9V 건전지를 대 봅니다. / 이때 단자와 건전지 모두 물기가 없어야 합니다.
번호판은 켜지는데 눌러도 반응이 엉뚱하다면 억지로 계속 누르지 마세요. / 잘못 입력이 쌓이면 도어락이 한동안 입력을 막습니다.
그 상태로 십 분쯤 말려도 안 되면 그때 전화 주시면 됩니다.
집 안에 가족이 있다면 안쪽 손잡이로 열어 달라고 하는 것이 가장 빠릅니다. / 안쪽에서 열리면 번호판이 마를 때까지 문을 잠시 열어 두고 바람을 통하게 해 주세요.

# 이런 상태면 점검을 받으세요
- 말린 뒤에도 같은 증상이 하루 넘게 이어질 때
- 번호판 안쪽에 김이 서리거나 물이 찬 것처럼 보일 때
- 건전지를 새로 넣었는데 며칠 만에 다시 꺼질 때
- 모터 소리가 평소보다 거칠고 느릴 때
물기가 회로 깊숙이 들어간 채 쓰면 나중에는 고칠 수 없는 상태가 되기도 합니다. / 그 전에 [도어락 수리](doorlock-repair.html)로 손보면 교체까지 가지 않고 끝나는 경우가 많습니다.

# 연락 주실 때 함께 알려 주실 것
중계동 단지 이름과 동, 호수, 그리고 증상이 언제 주로 나타나는지 말씀해 주세요. / "비 오는 날만", "겨울 아침만" 같은 정보가 원인을 짚는 데 큰 도움이 됩니다.
현관에 중문이 있는지, 문 안쪽에 결로가 자주 생기는지도 알려 주세요. / 번호판과 건전지 칸 사진이 있으면 더 좋습니다.

# 사시는 분 확인과 비용
문을 열어야 하는 상황이라면 먼저 사시는 분인지 확인합니다. / 신분증 주소나 주소가 적힌 우편물, 관리사무소 확인 가운데 하나면 됩니다.
습기 문제는 말리고 접점 손질로 끝나는 경우도 있어, 상태를 본 뒤 비용을 먼저 말씀드립니다. / 동의하신 뒤 시작하고, 문을 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 고칠 수 있으면 고쳐서 씁니다
문이 잠긴 상태면 [현관문 개문](door-open.html)으로 먼저 열고, 그다음 번호판과 몸체 안쪽 습기를 확인합니다. / 접점 손질과 건전지 교체로 끝나는 일이 적지 않습니다.
회로가 상해 같은 증상이 계속되거나 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 함께 살펴봅니다.
@ 노원 중계동 출장열쇠 도어락 습기 점검

# 중계동 이웃 동네도 갑니다
상계동, 하계동, 공릉동, 월계동 등 노원구 어디든 출동합니다. / 서울, 경기 전 지역 24시간이며 출동 지역은 [출장 지역](area.html)에 정리해 두었습니다.
