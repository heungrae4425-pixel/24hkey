# 이삿짐 차가 떠난 뒤 가장 먼저 할 일
상계동은 상계역과 노원역을 끼고 큰 아파트 단지가 길게 이어진 동네라 이삿날이면 사다리차가 줄지어 서는 모습을 자주 봅니다. / 짐을 다 들이고 한숨 돌리면 가장 먼저 현관 도어락을 손봐야 합니다.
전에 살던 분, 중개하신 분, 이사업체, 인테리어 기사님까지 이 집 번호를 아는 사람이 꽤 많기 때문입니다. / 카드키나 지문이 등록돼 있었다면 그것도 그대로 남아 있습니다.
이 글은 상계동에서 이사 첫날 도어락을 새로 정리하는 순서를 적었습니다. / 버튼을 찾기 어렵거나 진행이 막히면 [노원 출장열쇠](seoul-nowon.html)를 부르시면 됩니다.
@ 상계동 이사 첫날 도어락 초기화

# 번호만 바꾸면 남는 것들
많은 분이 비밀번호만 새로 바꾸고 끝냅니다. / 그런데 도어락은 번호 말고도 카드, 태그, 지문, 리모컨, 앱 계정처럼 여러 가지 열쇠를 따로 기억합니다.
번호만 바꾸면 전 세대가 쓰던 카드 한 장으로 여전히 문이 열릴 수 있습니다. / 그래서 이사 후에는 "전체를 지우고 내 것만 다시 넣는다"는 생각으로 정리하는 편이 확실합니다.

# 시작 전에 손에 들고 있을 것
작업 도중 문이 잠겨 버리면 곤란하니 문은 열어 둔 채로 시작하세요. / 아래 것을 미리 챙겨 두면 중간에 끊기지 않습니다.
- 새 건전지 한 묶음 (약한 상태에서 하면 등록이 중간에 멈춥니다)
- 정해 둔 새 비밀번호 메모
- 우리 가족 카드나 태그
- 도어락 모델명 (안쪽 몸체 옆면이나 건전지 칸 근처 스티커)
모델명을 알면 제조사 설명서를 휴대폰으로 바로 찾아볼 수 있습니다. / 전 세대가 설명서를 신발장이나 두꺼비집 근처에 두고 가는 경우도 있으니 한 번 둘러보세요.
작업은 식구가 모두 집에 있을 때 하는 편이 좋습니다. / 지문과 카드를 한자리에서 같이 등록할 수 있어서 나중에 따로 다시 설정할 일이 줄어듭니다.

# 안쪽 몸체에서 등록 버튼 찾기
초기화와 등록은 대개 집 안쪽 몸체에서만 할 수 있습니다. / 건전지 덮개를 열면 그 안이나 옆에 작은 버튼이 숨어 있는 경우가 많습니다.
버튼 옆에 "등록", "설정", "R" 같은 글자가 적혀 있기도 합니다. / 이 버튼을 짧게 누르는지, 길게 누르는지에 따라 기능이 갈리니 설명서를 한 번 확인하세요.
@ 상계동 아파트 도어락 안쪽 등록 버튼

# 대략적인 정리 흐름
제조사마다 다르지만 큰 흐름은 비슷합니다. / 처음 해 보시는 분은 아래 순서를 기억해 두시면 설명서 읽기가 쉬워집니다.
- 문을 연 상태에서 건전지를 새것으로 교체
- 등록 버튼으로 전체 초기화 또는 사용자 전체 삭제
- 새 비밀번호 입력 후 확인 버튼
- 카드, 태그, 지문을 하나씩 다시 등록
- 문을 닫고 바깥에서 새 번호로 열리는지 확인
마지막 확인은 꼭 문을 닫고 해 보셔야 합니다. / 열어 둔 상태에서만 확인하면 실제로 잠겼을 때 다르게 움직이는 경우를 놓칩니다.

# 카드와 지문은 한 명씩 차분히
카드키는 두세 장을 한 번에 겹쳐 대면 등록이 엉킵니다. / 한 장씩 대고 소리를 들은 뒤 다음 장으로 넘어가세요.
지문은 손가락 하나당 여러 번 대야 하는 제품이 많습니다. / 주로 쓰는 손가락과 다른 손 손가락을 하나씩 넣어 두면 짐을 들고 있을 때도 편합니다.
등록을 마치면 카드와 지문이 각각 몇 개 들어갔는지 메모해 두세요. / 나중에 카드 한 장을 잃어버렸을 때 무엇을 지워야 하는지 헷갈리지 않습니다.

# 상계동 큰 단지에서 함께 챙길 것
현관 도어락을 정리했다면 공동 현관 출입 방식도 한 번 확인해 보세요. / 단지마다 공동 현관 카드나 세대 등록을 관리사무소에서 따로 받는 경우가 있습니다.
전 세대 카드가 공동 현관에 그대로 등록돼 있을 수 있으니 관리사무소에 이사 사실을 알리고 정리해 달라고 하시면 됩니다. / 이 부분은 단지 규정에 따르니 출장열쇠가 대신 바꾸기는 어렵습니다.
현관 앞 택배함이나 우편함 열쇠, 자전거 보관대 번호도 전 세대에게서 받은 그대로라면 같은 날 바꿔 두세요. / 이사 첫 주가 지나면 이런 작은 것들은 잊고 넘어가기 쉽습니다.

# 새 번호 정하는 작은 요령
생일, 전화번호 뒷자리, 1234 같은 번호는 피하는 게 좋습니다. / 대신 가족 모두가 떠올리기 쉬운 숫자 묶음을 조합해 보세요.
번호를 누르기 전에 아무 숫자를 몇 개 섞어 누르는 기능이 있는 도어락도 많습니다. / 번호판에 손자국이 남아 번호가 읽히는 일을 줄여 줍니다.
아이가 있는 집이라면 아이가 외울 수 있는 길이인지도 생각해 주세요. / 너무 길고 복잡하면 결국 현관 근처에 적어 두게 되어 바꾼 의미가 줄어듭니다.

# 여기서 막히면 무리하지 마세요
- 등록 버튼을 눌러도 아무 소리가 안 날 때
- 초기화 후 문이 닫히자마자 잠겨 버렸을 때
- 이전 세대가 관리자 번호를 걸어 둬서 설정 메뉴가 안 열릴 때
- 건전지를 갈아도 번호판이 깜빡이기만 할 때
이럴 때는 버튼을 계속 눌러 보기보다 연락 주시는 편이 낫습니다. / 잘못 누르다 설정이 꼬이면 처음부터 다시 해야 하는 경우가 생깁니다.

# 연락 주실 때 알려 주실 것
상계동은 단지가 크고 동 번호가 많아 위치를 자세히 알려 주시면 빨리 찾아갑니다.
- 단지 이름, 동, 호수
- 도어락 모델명이나 사진
- 문이 지금 열려 있는지 잠겨 있는지
- 어디까지 해 보셨는지
이사 직후라 짐이 현관을 막고 있다면 미리 말씀해 주세요. / 엘리베이터를 이삿짐 때문에 잡아 둔 시간이라면 도착 시간을 그에 맞춰 조정해 드립니다.

# 확인과 비용 안내
이사 첫날은 신분증 주소가 아직 바뀌지 않았을 때가 많습니다. / 이럴 때는 임대차 계약서나 매매 서류, 관리사무소 입주 확인으로 사는 분인지 확인합니다.
설정만 도와드리는지, 문을 열어야 하는지, 부품을 바꿔야 하는지에 따라 달라서 시작 전에 비용을 말씀드립니다. / 잠긴 문을 끝내 못 열면 비용은 받지 않습니다.
@ 상계동 출장열쇠 입주 도어락 재설정

# 너무 오래된 도어락이라면
전 세대가 오래 쓴 도어락은 초기화가 되더라도 부품이 낡아 얼마 못 가 말썽을 부리기도 합니다. / 이사를 계기로 새로 바꾸는 집도 많습니다.
바꾸기 전에 고쳐 쓸 수 있는지 먼저 보시려면 [도어락 수리](doorlock-repair.html)를, 새로 바꿀 생각이면 [도어락 교체](doorlock-replace.html)와 [도어락 설치](doorlock-install.html)를 참고하세요. / 진행 순서는 [이용안내](guide.html)에 있습니다.

# 상계동 말고 노원구 다른 동네도
상계동과 맞닿은 중계동, 하계동, 그리고 공릉동, 월계동까지 노원구 어디든 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
