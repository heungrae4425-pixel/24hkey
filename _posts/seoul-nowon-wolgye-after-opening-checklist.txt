# 문이 열렸다고 끝난 게 아닙니다
한참을 복도에서 기다리다 문이 열리면 안도감에 그대로 들어가 쉬고 싶어집니다. / 그런데 왜 잠겼는지 짚지 않고 넘어가면 며칠 뒤 같은 자리에서 또 멈추는 일이 생깁니다.
월계동처럼 노원구 안에서도 아파트와 빌라가 섞인 동네에서는 문 종류도 원인도 집집마다 다릅니다. / 그래서 열고 난 뒤 점검도 우리 집 상황에 맞게 해야 합니다.
이 글은 월계동에서 현관문을 연 그날 저녁 해 두면 좋은 일을 목록으로 정리했습니다. / 기사님이 아직 계신다면 이 목록을 보며 함께 확인하셔도 좋습니다.
@ 월계동 현관문 개방 후 점검

# 기사님이 계실 때 꼭 물어볼 세 가지
현장에서 문을 연 사람이 원인을 가장 잘 압니다. / 떠나시기 전에 아래 세 가지는 꼭 물어보세요.
- 왜 안 열렸는지, 건전지인지 번호인지 부품인지
- 지금 도어락을 그대로 써도 되는지
- 당장은 괜찮아도 곧 손봐야 할 곳이 있는지
대답을 휴대폰 메모에 적어 두면 나중에 다시 연락할 때 설명이 쉬워집니다. / 24시출장열쇠는 문을 연 뒤 원인과 상태를 먼저 말씀드리고 마칩니다.

# 첫 번째 확인, 잠금과 열림을 다섯 번
문이 열린 직후 도어락이 정상인지 보려면 여러 번 반복해 보는 것이 가장 확실합니다. / 문을 닫고, 바깥에서 번호로 열고, 다시 닫고 잠기는지 다섯 번쯤 해 보세요.
한 번이라도 모터 소리만 나고 잠금쇠가 덜 움직였다면 그냥 넘기지 마세요. / 다음번에는 그 한 번이 문 앞에서 일어날 수 있습니다.
안쪽에서도 손잡이와 잠금 버튼이 부드럽게 움직이는지 확인하세요. / 걸리는 느낌이 있다면 그날 바로 말씀해 주셔야 함께 볼 수 있습니다.

# 두 번째 확인, 건전지 전부 새것으로
건전지 때문에 잠겼다면 남은 칸까지 전부 새것으로 바꿔야 합니다. / 한두 개만 바꾸면 헌 건전지가 새것의 힘까지 끌어내려 금방 다시 경고음이 납니다.
교체한 날짜를 건전지 덮개 안쪽에 네임펜으로 적어 두세요. / 다음 교체 시기를 따로 기억하지 않아도 됩니다.
건전지를 넣을 때 방향이 하나라도 뒤집히면 번호판이 켜지지 않거나 힘이 약하게 들어갑니다. / 덮개를 닫기 전에 그림대로 들어갔는지 한 번 더 보세요.
@ 월계동 도어락 건전지 교체 날짜 메모

# 세 번째 확인, 번호와 카드 다시 정리
비밀번호를 잊어서 열었다면 이번 기회에 새 번호로 바꾸고 가족과 함께 정해 두세요. / 한 사람만 알고 있는 번호는 그 사람이 없을 때 또 문제가 됩니다.
카드키나 태그를 잃어버려서 연 경우라면 잃어버린 카드가 아직 등록돼 있다는 점을 기억하세요. / 전체 삭제 후 남은 카드만 다시 등록하는 편이 안전합니다.
문을 열기 위해 여러 사람이 번호를 시도했다면 그 번호도 이미 여러 사람이 본 셈입니다. / 이 경우에도 새 번호로 바꿔 두시는 게 좋습니다.

# 네 번째 확인, 문과 문틀 상태
도어락은 멀쩡한데 문이 처져서 잠금쇠가 문틀에 걸린 경우도 있습니다. / 문을 닫을 때 끝에서 툭 걸리거나 힘을 줘야 닫힌다면 문틀과 경첩 쪽을 봐야 합니다.
문 위쪽 닫힘 장치가 너무 빠르거나 너무 느리지 않은지도 함께 보세요. / 빨리 닫히면 충격으로, 느리면 덜 닫혀서 잠금 문제가 생기기 쉽습니다.
문틀 쪽 받이쇠 나사가 헐거워 덜렁거린다면 드라이버로 조여 두는 정도는 직접 하셔도 됩니다. / 다만 받이쇠 위치 자체가 어긋나 보이면 혼자 옮기지 말고 점검을 받으세요.

# 다섯 번째 확인, 비상 전원 단자 위치
번호판이 꺼졌을 때 쓸 수 있는 비상 전원 단자가 어디 있는지 미리 알아 두세요. / 대개 바깥 번호판 아래쪽에 작은 홈으로 숨어 있습니다.
9V 건전지 하나를 가방이나 차에 넣어 두면 다음에 번호판이 꺼져도 혼자 해결할 가능성이 커집니다. / 단자가 없는 제품이라면 그것도 알아 두는 것 자체가 도움이 됩니다.
식구들에게도 단자 위치를 한 번씩 보여 주세요. / 막상 급할 때는 손전등을 켜고 한참 찾게 되는 자리라서 미리 봐 둔 사람과 아닌 사람의 차이가 큽니다.

# 빌라에 산다면 함께 볼 것
빌라라면 세대 현관만 보고 끝내지 말고 건물 입구 출입문도 함께 떠올려 보세요. / 공동 출입문 번호를 휴대폰에 저장해 두었는지, 바뀐 적은 없는지 확인해 두면 좋습니다.
세입자라면 이번 일을 집주인에게 짧게라도 알려 두세요. / 도어락이 오래돼 다시 손봐야 할 때 이야기를 꺼내기가 쉬워집니다. / 기사님이 말해 준 원인을 그대로 전하면 집주인도 판단하기가 수월합니다.

# 아이와 어르신이 있는 집이라면
아이가 혼자 집에 오는 날이 있다면 오늘 바꾼 번호를 아이가 확실히 외웠는지 두세 번 같이 눌러 보세요. / 카드를 쓰게 하려면 가방 안쪽에 고정해 두는 편이 잃어버릴 걱정이 적습니다.
어르신이 사시는 집이라면 번호판 숫자가 잘 보이는지, 누르는 힘이 충분히 전해지는지도 확인해 주세요. / 불편하시면 다음 점검 때 쓰기 편한 설정을 함께 말씀드릴 수 있습니다.

# 그날 밤 해 두면 좋은 연락
- 가족 단체방에 새 번호나 카드 정리 내용을 알리기
- 집주인이나 관리하는 분에게 있었던 일을 짧게 전하기
- 비상시 연락할 열쇠 출장 번호를 휴대폰에 저장하기
- 여분 카드나 열쇠를 믿을 만한 가족에게 맡기기
이 네 가지는 오 분이면 끝나지만 다음번 막막함을 크게 줄여 줍니다. / 특히 혼자 사는 분이라면 여분을 맡길 사람 한 명을 정해 두는 것만으로도 마음이 놓입니다.

# 이런 신호가 보이면 다시 연락 주세요
열고 나서 며칠 안에 아래 같은 일이 보이면 미루지 말고 연락 주세요. / 같은 원인이 남아 있다는 뜻일 수 있습니다.
- 새 건전지인데 경고음이 다시 날 때
- 번호를 맞게 눌렀는데 한 번에 안 열릴 때
- 잠금쇠가 나왔다 들어갔다 하는 소리가 길어질 때
고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로, 부품이 낡았다면 [도어락 교체](doorlock-replace.html)로 안내해 드립니다.

# 다시 부르실 때 진행 방식
다시 방문할 때도 사시는 분인지 신분증이나 우편물, 관리사무소 확인으로 확인합니다. / 상태를 본 뒤 손대기 전에 비용을 먼저 말씀드리고 동의하실 때만 진행합니다.
잠긴 문을 끝내 못 열면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에서 보실 수 있습니다.
@ 월계동 출장열쇠 도어락 재점검

# 월계동 말고 노원구 어디서든
월계동과 이어진 공릉동, 하계동, 그리고 중계동, 상계동까지 노원구 전 지역을 다닙니다. / 다른 지역은 [노원 출장열쇠](seoul-nowon.html)와 [출장 지역](area.html)에서 보실 수 있습니다.

# 마무리

24시출장열쇠는 연 뒤에도 궁금한 점이 있으면 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
