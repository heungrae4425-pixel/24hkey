# 슬리퍼 차림으로 복도에 서 있다면
분리수거 봉투를 들고 잠깐 나왔는데 등 뒤에서 "철컥" 하고 문이 잠기는 순간이 있습니다. / 휴대폰도 지갑도 집 안에 있고, 발에는 슬리퍼뿐인 상황입니다.
월계동처럼 아파트와 빌라가 함께 있는 동네에서는 이런 연락이 계절을 가리지 않고 들어옵니다. / 대부분 자동 잠금 도어락이 문이 닫히자마자 스스로 잠기면서 생기는 일입니다.
이 글은 노원구 월계동에서 잠깐 외출했다가 잠긴 분이 빈손으로 할 수 있는 일을 차례로 적었습니다. / 연락이 닿는 대로 [노원 출장열쇠](seoul-nowon.html)가 바로 움직입니다.
@ 월계동 택배 받으러 나왔다가 현관문 잠김

# 왜 잠깐 사이에 잠길까
요즘 도어락은 대부분 문이 닫히면 몇 초 뒤 자동으로 걸쇠가 나옵니다. / 문을 살짝 걸쳐 두었다고 생각해도 바람이나 문 무게로 닫히면 그대로 잠깁니다.
택배 기사님과 이야기하느라 문에서 손을 뗀 사이, 혹은 쓰레기 봉투를 내려놓느라 문을 놓친 사이에 많이 일어납니다. / 복도 창문이 열려 있는 날에는 문이 생각보다 세게 닫힙니다.
문 아래에 슬리퍼를 끼워 두었다가 발로 빼는 사이에 닫히는 일도 있습니다. / 짐을 두 손에 들고 있으면 문을 붙잡을 틈이 없어 이런 일이 더 자주 생깁니다.
번호를 알고 있다면 다행이지만 번호판이 꺼져 있거나 가족만 아는 새 번호라면 이야기가 달라집니다. / 그래서 아래 순서대로 확인해 보세요.

# 첫 번째로, 번호와 다른 열림 방법
지문이나 카드키, 휴대폰 태그를 함께 쓰는 도어락이라면 번호 말고 다른 방법이 남아 있는지 생각해 보세요. / 주머니에 카드키가 들어 있는 경우가 의외로 많습니다.
지문 등록이 되어 있다면 손가락에 물기나 먼지가 묻지 않았는지 옷에 닦고 다시 대 보세요. / 분리수거를 하고 나면 손이 젖거나 더러워져 인식이 잘 안 되는 일이 많습니다.
번호판이 켜지지 않는다면 건전지가 닳은 상태입니다. / 이때는 9V 건전지가 있어야 하는데, 지금은 지갑이 없으니 이웃이나 경비실의 도움이 필요합니다.

# 두 번째로, 집 안에 누가 있는지
가족이 자고 있거나 샤워 중이라 못 들었을 수도 있습니다. / 초인종을 몇 번 누르고 문을 가볍게 두드려 보세요.
아이만 집에 있다면 문을 열어 달라고 부르기 전에 아이가 손잡이를 돌릴 수 있는 나이인지 생각해 보세요. / 안쪽에서 손잡이만 돌리면 열리는 구조라면 차분하게 방법을 알려 주시면 됩니다.
가족이 곧 퇴근하거나 돌아올 시간이라면 기다리는 것도 방법입니다. / 다만 언제 올지 모르거나 연락이 안 된다면 오래 기다리기보다 출장을 부르시는 편이 낫습니다.

# 휴대폰이 없을 때 연락하는 방법
가장 빠른 곳은 단지 경비실이나 관리사무소입니다. / 사정을 이야기하면 전화를 빌려 쓰는 데 대개 어려움이 없습니다.
빌라라면 같은 층이나 아래층 이웃에게 부탁하는 수밖에 없습니다. / 낯선 이웃이라도 "문이 잠겨서 전화 한 통만 부탁드린다"고 하면 대부분 도와주십니다.
근처 편의점에 가서 전화를 부탁하는 방법도 있습니다. / 이때 연락할 번호 010-3664-5455는 휴대폰 없이도 기억하기 쉽게 이 글 끝에도 적어 두었습니다.
@ 월계동 휴대폰 없이 문 잠김 경비실 연락

# 빌린 전화로 짧게 말할 것
남의 휴대폰이니 통화를 짧게 끝내는 것이 좋습니다.
- 월계동 어느 단지나 건물, 몇 동 몇 호인지
- 휴대폰이 없어서 이 번호로 다시 연락이 어렵다는 것
- 어디에서 기다리고 있을지 (문 앞, 경비실 앞, 1층 현관)
- 번호판이 켜지는지, 안에 사람이나 동물이 있는지
특히 "휴대폰이 없다"는 말을 꼭 해 주세요. / 그러면 도착해서 전화를 걸지 않고 말씀하신 장소로 바로 찾아갑니다.

# 기다리는 동안 몸부터 챙기세요
슬리퍼에 얇은 옷 차림이라면 복도나 계단은 금방 춥습니다. / 경비실이나 1층 공동현관 안쪽, 엘리베이터 앞처럼 바람이 덜 드는 곳에서 기다려 주세요.
여름이라면 반대로 계단실이 덥고 답답합니다. / 그늘진 곳이나 공동현관 근처에서 기다리셔도 됩니다.
장소를 옮겼다면 경비실에 "출장열쇠가 오면 여기 있다고 전해 달라"고 부탁해 두시면 서로 엇갈리지 않습니다.
가스레인지에 냄비를 올려 두고 나왔다면 그건 기다릴 일이 아닙니다. / 연기나 타는 냄새가 나면 바로 119에 알리고 경비실에도 함께 말해 주세요.

# 문을 열려고 애쓰지 않아도 됩니다
문틈에 쓰레기 봉투 끈이나 택배 상자 조각을 넣어 보는 분이 있습니다. / 요즘 도어락은 그런 방법으로 열리지 않고 문 고무 패킹만 상합니다.
번호를 짐작으로 여러 번 누르는 것도 피해 주세요. / 일정 횟수를 넘기면 입력이 한동안 막히고, 경보음이 울려 이웃이 놀랄 수 있습니다.
베란다나 창문으로 들어가려는 생각도 접어 주세요. / 저층이라도 넘어가다 다치는 일이 문 하나 여는 것보다 훨씬 큰 일입니다.

# 지갑이 없으니 확인은 이렇게
문을 열기 전에는 사시는 분인지 꼭 확인합니다. / 신분증이 집 안에 있다면 관리사무소나 경비실의 세대 확인이 가장 간단합니다.
빌라라서 관리사무소가 없다면 문이 열린 뒤 집 안에서 신분증이나 주소가 나온 우편물을 바로 보여 주시는 방식으로 진행합니다. / 이웃이 얼굴을 알아봐 주시는 것도 도움이 됩니다.
확인 절차는 짧게 끝나니 걱정하지 않으셔도 됩니다. / 다른 사람이 남의 집 문을 열지 못하게 하려는 최소한의 약속입니다.

# 지갑을 두고 나왔어도 괜찮습니다
도착해서 도어락 상태를 본 뒤 비용을 먼저 말씀드립니다. / 동의하시면 시작하고, 결제는 문이 열린 뒤 집 안에서 하시면 됩니다.
끝내 열지 못하면 비용은 받지 않습니다. / 진행 방법은 [이용안내](guide.html)에서도 보실 수 있습니다.

# 문과 도어락을 상하지 않게
잠깐 나왔다 잠긴 경우는 도어락이 멀쩡한 경우가 대부분입니다. / 그래서 도어락을 부수지 않는 방법으로 열고, 다 열린 뒤에도 그대로 쓰실 수 있게 합니다.
여는 방식은 [현관문 개문](door-open.html)에 설명해 두었습니다.
@ 노원 월계동 출장열쇠 비파손 현관문 개문

# 같은 일을 막는 작은 준비
- 쓰레기 버리러 나갈 때도 휴대폰은 꼭 챙기기
- 도어락 자동 잠금을 수동으로 바꿀 수 있는지 확인하기
- 카드키 하나는 신발장 밖 가족 차나 직장에 따로 두기
- 번호판 경고음이 울리면 그날 건전지 바꾸기
- 가족끼리 번호를 바꿨을 때 바로 공유하기
자동 잠금 설정을 바꾸는 방법이 어렵다면 [도어락 수리](doorlock-repair.html) 때 함께 봐 드립니다. / 오래된 제품이라 설정이 안 된다면 [도어락 교체](doorlock-replace.html)를 상담하셔도 됩니다.

# 월계동 말고 노원구 어디서든
상계동, 중계동, 하계동, 공릉동까지 노원구 전역에 갑니다. / 서울, 경기 전 지역 24시간이며 출동 지역은 [출장 지역](area.html)에서 확인하세요.
