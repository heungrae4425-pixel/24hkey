# 잠원동, 슬리퍼 차림으로 복도에 서 있다면
잠원동은 한강 쪽으로 아파트가 이어진 서초구의 주거 동네입니다. / 저녁이면 분리수거장으로 내려가는 사람, 현관 앞 택배를 들이는 사람이 엘리베이터를 바쁘게 오르내립니다.
이런 잠깐 사이에 문이 닫혀 버리는 일이 생각보다 흔합니다. / 자동 잠김 도어락은 문이 닫히는 순간 잠기기 때문에, 문을 살짝 걸쳐 두었다가 바람에 닫히면 그대로 잠깁니다.
손에는 재활용 봉투나 택배 상자뿐이고 휴대폰과 열쇠는 집 안에 있습니다. / 이 글은 잠원동에서 그런 순간을 맞았을 때 순서대로 할 일을 적었습니다. / 바로 연락이 필요하면 [서초 출장열쇠](seoul-seocho.html)로 전화 주세요.
@ 잠원동 아파트 분리수거 중 현관문 잠김

# 먼저 번호를 알고 있는지 떠올리기
당황하면 평소 누르던 번호도 기억이 안 납니다. / 잠깐 숨을 고르고 손가락이 기억하는 대로 천천히 눌러 보세요.
카드나 지문만 쓰던 집은 번호를 아예 정해 두지 않았을 수 있습니다. / 이럴 때는 번호 입력을 여러 번 시도하지 말고 다음 순서로 넘어가세요.
번호판이 아예 꺼져 있다면 건전지 방전일 수 있습니다. / 경비실에 9V 건전지가 있는지 물어보고 바깥 비상 단자에 대 보는 것도 해 볼 만합니다.
번호를 서너 번 틀리면 입력이 한동안 막히는 제품이 많습니다. / 막히고 나면 맞는 번호를 떠올려도 바로 열 수 없으니 그 전에 멈추는 것이 좋습니다.

# 휴대폰이 집 안에 있을 때 전화 빌리기
가장 먼저 할 일은 연락 수단을 찾는 것입니다. / 아파트라면 도움을 청할 곳이 여러 군데 있습니다.
- 경비실이나 관리사무소에 내려가 전화 부탁하기
- 같은 층 이웃에게 사정을 말하고 전화 빌리기
- 단지 상가나 가까운 편의점에 부탁하기
가족 번호를 외우고 있다면 가족에게 먼저 걸어 보세요. / 번호를 가진 가족이 가까이 있으면 그 사람이 오는 게 가장 빠르고 문도 안 상합니다.
가족이 회사나 학교에 있어 오기 어렵다면 무리하게 부르지 마세요. / 오가는 시간보다 출장이 빠른 경우가 많습니다.

# 가족 번호도 모른다면
요즘은 번호를 휴대폰에만 저장해 두어 가족 번호조차 외우지 못하는 경우가 많습니다. / 그래도 괜찮습니다. 경비실에서 저희 번호를 찾아 주시거나 이웃 휴대폰으로 검색해 연락 주시면 됩니다.
이번 일을 계기로 가족 번호 하나, 저희 번호 하나 정도는 외우거나 현관 안쪽이 아닌 지갑에 적어 두세요. / 010-3664-5455처럼 끝자리만이라도 기억해 두면 찾기 쉽습니다.
@ 잠원동 경비실 전화 빌려 출장열쇠 연락

# 집 안에 불이나 물을 켜 두고 나왔다면
가스레인지에 냄비를 올려 두었거나 욕조에 물을 받고 있었다면 상황이 다릅니다. / 이 경우는 전화할 때 가장 먼저 말씀해 주세요.
불이 걱정되거나 타는 냄새가 나면 망설이지 말고 119에 먼저 알리세요. / 물이 넘칠 수 있다면 관리사무소에 말해 세대 수도를 잠글 수 있는지 물어보는 것도 방법입니다.

# 아이나 반려동물이 안에 있다면
잠깐 쓰레기만 버리고 오려다 아이를 집에 두고 나온 경우도 있습니다. / 문 너머로 계속 말을 걸어 아이가 놀라지 않게 해 주세요.
아이가 안에서 문을 열 수 있는 나이라면 손잡이를 돌리라고 차분히 알려 주세요. / 못 하겠다고 하면 재촉하지 말고 기다리게 하시면서 연락 주세요. 아이가 있다고 하시면 먼저 출동합니다.

# 기다리는 동안 하지 말 것
- 베란다나 창문으로 들어가려 하기
- 문틈에 카드나 옷걸이를 넣어 걸쇠 밀기
- 번호를 계속 바꿔 가며 눌러 보기
- 손잡이를 세게 당기거나 문을 발로 차기
아파트 바깥으로 넘어가는 시도는 정말 위험합니다. / 몇 층이든 하지 마시고, 문은 저희가 열어 드리니 안전한 곳에서 기다려 주세요.
문틈에 무언가를 넣는 시도도 대부분 문 가장자리 고무만 찢고 끝납니다. / 나중에 바람이 새는 문이 되니 그냥 두시는 편이 낫습니다.

# 추운 날 기다리는 곳
겨울 저녁 슬리퍼와 얇은 옷차림으로 복도에 오래 서 있으면 몸이 금방 식습니다. / 경비실이나 관리사무소 안, 단지 상가처럼 따뜻한 곳에서 기다려도 됩니다.
도착하면 연락드릴 번호만 정해 주시면 됩니다. / 이웃이나 경비실 번호를 알려 주셔도 괜찮습니다. / 택배 상자나 재활용 봉투는 경비실에 잠시 맡겨 두면 손이 가벼워집니다.

# 위치는 이렇게 알려 주세요
잠원동은 비슷한 모양의 동이 이어진 단지가 많아 정확한 위치가 중요합니다.
- 단지가 있는 길과 동, 호수
- 지금 계신 곳(문 앞, 경비실, 상가)
- 연락받을 전화번호
- 도어락 모양과 번호판 상태
- 집 안에 사람이나 반려동물, 켜 둔 불이 있는지
이 다섯 가지만 알려 주시면 출발과 동시에 준비를 마칠 수 있습니다. / 이웃 휴대폰으로 도어락 사진을 찍어 보내 주시면 더 좋습니다.

# 신분증도 집 안에 있을 때 거주 확인
문을 열기 전에는 그 집에 사시는 분인지 확인합니다. / 신분증이 집 안에 있다면 관리사무소나 경비실에서 세대 확인을 해 주시면 됩니다.
그것도 어렵다면 문을 연 뒤 집 안의 신분증이나 주소가 찍힌 우편물로 바로 확인하는 방법도 있습니다. / 어느 쪽으로 할지 도착해서 함께 정합니다. / 이웃을 위해 꼭 거치는 절차이니 양해 부탁드립니다.
@ 잠원동 출장열쇠 관리사무소 세대 확인

# 비용은 열기 전에 먼저 알려 드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 지갑이 집 안에 있으면 문을 연 뒤 정산하셔도 됩니다.
끝내 열지 못하면 비용은 받지 않습니다. / 자세한 순서는 [이용안내](guide.html)와 [현관문 개방](door-open.html)에서 보실 수 있습니다.

# 다시 같은 일을 겪지 않으려면
잠깐 나갈 때 문을 걸쳐 두는 습관이 가장 흔한 원인입니다. / 짧게 나가더라도 휴대폰이나 카드 하나는 주머니에 넣는 습관을 들여 보세요.
번호를 정해 두지 않은 집이라면 이번에 꼭 번호를 등록하세요. / 카드나 지문만 쓰면 둘 다 없을 때 들어갈 방법이 사라집니다.
도어락이 자동 잠김 대신 수동 잠김을 고를 수 있는 제품이라면 생활에 맞게 바꾸는 것도 방법입니다. / 설정이 어렵거나 도어락이 오래됐다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html) 때 함께 상의하세요.
