# 양재역에서 돌아왔는데 호실 문이 안 열린다면
양재동은 양재역 둘레로 사무실 건물이 많고, 그 뒤편 골목에 원룸 건물과 오피스텔이 자리한 동네입니다. / 직장과 가까워 혼자 지내는 분이 많고, 늦게 퇴근하는 날도 잦습니다.
오피스텔과 원룸은 집이 작은 만큼 문제도 단순해 보이지만, 연락할 곳이 여러 갈래입니다. / 건물 관리실, 집주인, 관리 업체가 각각 맡는 부분이 다르기 때문입니다.
이 글은 양재동 오피스텔이나 원룸에서 호실 문이 안 열릴 때 어떤 차례로 연락하면 좋은지 적었습니다. / 바로 열어야 하는 상황이라면 [서초 출장열쇠](seoul-seocho.html)로 연락 주세요.
@ 양재동 오피스텔 호실 도어락 잠김

# 오피스텔과 원룸은 연락 길이 다릅니다
오피스텔은 대개 건물 관리실이 있고, 원룸 건물은 집주인이 직접 관리하는 곳이 많습니다. / 우리 건물이 어느 쪽인지에 따라 첫 전화가 달라집니다.
- 오피스텔: 건물 관리실, 낮에는 관리 사무실, 밤에는 경비나 보안 담당
- 원룸 건물: 집주인이나 집주인이 맡긴 관리인
- 중개로 들어온 단기 임대: 계약을 맡은 중개 쪽이나 임대 관리 업체
관리실에서 예비 카드나 관리자 번호를 갖고 있는 경우도 있습니다. / 먼저 물어보면 문을 열 필요 없이 끝날 수도 있습니다.

# 무엇이 막혔는지 먼저 가려 보기
건물 1층 출입이 안 되는 것과 내 호실 문이 안 열리는 것은 다른 문제입니다. / 1층은 들어왔는데 호실 앞에서 막혔는지 먼저 확인하세요.
- 번호판이 아예 꺼짐: 건전지 방전 가능성
- 번호를 눌러도 경고음만 남: 번호가 바뀌었거나 입력 제한
- 카드를 대도 반응 없음: 카드 분실·고장이나 인식부 문제
- 열림 소리는 나는데 문이 안 밀림: 안쪽 걸쇠나 이중 잠금
번호판이 꺼졌다면 바깥쪽 비상 단자에 9V 건전지를 대 보는 것부터 해 보세요. / 양재역 근처 편의점에서 구할 수 있습니다.

# 입주 때 받은 번호가 바뀐 경우
원룸은 세입자가 바뀔 때마다 집주인이 번호를 새로 정해 주는 곳이 많습니다. / 그런데 관리 차원에서 번호를 다시 바꾸고 알림을 늦게 주는 일이 있습니다.
최근에 집주인이나 관리실에서 문자가 왔는지 한 번 확인해 보세요. / 공용 게시판에 안내가 붙어 있는 건물도 있습니다.
같은 층 이웃이 같은 날 같은 일을 겪었다면 건물 전체 번호 정책이 바뀌었을 가능성이 큽니다. / 이럴 때는 문을 열기보다 새 번호를 받는 것이 먼저입니다.

# 늦은 밤 관리실도 집주인도 연락이 안 될 때
퇴근이 늦어 밤 열한 시가 넘으면 관리실이 닫혀 있고 집주인도 전화를 안 받을 수 있습니다. / 이럴 때는 기다리기보다 출장을 부르시는 편이 낫습니다.
사시는 분이 맞다는 확인만 되면 집주인 허락 없이도 문을 열어 드립니다. / 다만 계약상 집주인에게 알려야 하는 부분이 있다면 다음 날 연락해 두세요.
밤에 혼자 문 앞에서 오래 기다리기 불안하다면 1층 로비나 가까운 편의점처럼 밝은 곳에 계시다가 도착 연락을 받으셔도 됩니다.
@ 양재동 원룸 늦은 밤 출장열쇠 연락

# 작은 집이라 더 조심할 것
원룸과 오피스텔은 복도가 좁고 호실 문이 바짝 붙어 있습니다. / 문 앞에서 오래 번호를 누르거나 문을 두드리면 옆집에 소리가 그대로 전해집니다.
번호를 서너 번 틀렸다면 그만 누르고 기다려 주세요. / 잠시 입력이 막히는 제품이 많아 계속 누르면 시간만 길어집니다.
문틈에 카드를 넣어 걸쇠를 밀어 보는 방법은 권하지 않습니다. / 문틀 고무와 도어락 외관이 상해 나중에 퇴거할 때 원상 복구 문제가 생길 수 있습니다.

# 집 안에 휴대폰과 지갑이 다 있을 때
쓰레기를 버리러 잠깐 나왔다가 문이 닫혀 버리는 경우가 흔합니다. / 휴대폰이 없으면 관리실이나 이웃, 1층 편의점에 전화를 부탁해 보세요.
번호를 외워 두지 않았다면 집주인 번호를 모를 수 있습니다. / 그래도 저희 번호 하나만 알면 됩니다. 010-3664-5455는 휴대폰 메모와 별개로 수첩이나 지갑에 적어 두셔도 좋습니다.

# 전화 주실 때 이렇게 말씀해 주세요
양재동은 비슷한 이름의 건물이 이어진 골목이 있어 위치를 자세히 알려 주시면 좋습니다.
- 건물 이름과 호수, 양재역에서 어느 방향인지
- 1층 출입이 되는지, 호실 앞까지 왔는지
- 번호판 상태(꺼짐, 경고음, 카드 무반응)
- 관리실이나 집주인에게 연락을 해 봤는지
도어락 사진을 보내 주시면 맞는 장비를 챙겨 가기 좋습니다.

# 사시는 분인지 확인합니다
오피스텔과 원룸은 드나드는 사람이 많아 거주 확인을 더 꼼꼼히 합니다. / 주소가 나온 신분증, 임대차 계약서, 주소가 찍힌 우편물이나 택배 송장, 관리실 확인 가운데 하나를 준비해 주세요.
전입 신고 전이라 신분증 주소가 다르다면 계약서 사진도 괜찮습니다. / 휴대폰에 저장된 계약서도 확인할 수 있습니다.
휴대폰까지 집 안에 있다면 관리실이나 집주인 확인으로 대신할 수 있으니 연락이 닿는 쪽을 알려 주세요.
@ 양재동 오피스텔 거주 확인 후 문 열기

# 비용은 열기 전에 먼저 알려 드립니다
문과 도어락 상태를 보고 어떻게 열지, 비용이 얼마인지 손대기 전에 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 자세한 순서는 [이용안내](guide.html)와 [현관문 개방](door-open.html)에 적어 두었습니다.

# 열린 뒤 원룸·오피스텔에 맞춘 정리
문이 열리면 번호를 새로 등록할지, 기존 번호를 그대로 쓸지 정합니다. / 집주인이 번호를 관리하는 건물이라면 바꾼 번호를 집주인에게도 알려 두는 편이 나중에 오해가 없습니다.
건전지가 원인이었다면 그 자리에서 새것으로 바꿉니다. / 도어락이 자주 말썽이라면 집주인과 상의해 [도어락 수리](doorlock-repair.html)를 받거나 교체를 고려해 보세요.

# 퇴거 전에 도어락 상태를 남겨 두기
나갈 때 도어락 문제로 실랑이가 생기지 않도록 상태를 기록해 두면 좋습니다. / 입주 때와 문을 연 뒤 도어락 앞뒤 사진을 찍어 두세요.
출장으로 문을 열었다면 어떤 작업을 했는지 저희가 말씀드린 내용을 메모해 두셔도 됩니다. / 손상 없이 열었다는 것을 나중에 설명하기 쉬워집니다.
받았던 카드와 열쇠 개수도 입주 때 그대로 돌려줄 수 있는지 미리 세어 두세요.

# 양재동 밖 서초구도 갑니다
양재동 옆 내곡동, 서초동, 방배동, 반포동, 잠원동까지 서초구 전 지역 출동합니다. / 서초구 안내는 [서초구 출장열쇠](seoul-seocho.html), 다른 지역은 [출장 지역](area.html)을 보세요.
