# 북가좌동 집, 알림이 조용해졌다면
북가좌동은 가좌역 생활권에 아파트와 빌라가 모여 있는 동네로, 바로 옆 남가좌동과 생활권이 이어집니다. / 요즘은 이 동네에서도 문이 열리고 닫힐 때마다 휴대폰으로 알림을 받는 도어락을 쓰는 집이 늘었습니다.
평소엔 아이가 학교에서 돌아오면 알림이 오던 집이 어느 날부터 조용해지면 신경이 쓰입니다. / 앱으로 문을 열어 주던 기능까지 안 되면 불편이 훨씬 커집니다.
이 글은 북가좌동에서 도어락 앱 알림이나 원격 기능이 끊겼을 때 집에서 점검할 순서를 정리했습니다. / 문 자체가 안 열리는 상황이라면 아래 내용은 나중에 보시고 [서대문 출장열쇠](seoul-seodaemun.html)에 먼저 연락 주세요.
@ 북가좌동 스마트 도어락 앱 알림 점검

# 알림이 끊겼을 때 먼저 할 일 하나
가장 먼저 번호나 지문으로 문이 평소처럼 열리고 잠기는지 확인해 보세요. / 이게 된다면 도어락 본체는 살아 있고, 연결 쪽 문제일 가능성이 큽니다.
문이 잘 열리고 잠긴다면 급할 일은 아닙니다. / 하나씩 차근차근 보셔도 됩니다.
반대로 번호도 안 먹고 번호판도 꺼져 있다면 연결보다 전원이 먼저입니다. / 이 경우는 앱 설정을 만지기 전에 건전지부터 보셔야 합니다.

# 최근에 집 인터넷을 바꾸지 않으셨나요
알림이 갑자기 끊기는 가장 흔한 이유 중 하나가 공유기 교체입니다. / 인터넷 회사를 바꾸거나 공유기를 새로 달면 와이파이 이름과 비밀번호가 바뀌어 도어락이 길을 잃습니다.
도어락은 사람처럼 새 와이파이를 알아서 찾지 못합니다. / 앱에서 기기 연결을 다시 해 줘야 새 공유기와 이어집니다.
공유기 위치를 옮긴 것만으로도 신호가 약해질 수 있습니다. / 현관이 공유기에서 멀거나 중간에 벽이 여러 개 있으면 알림이 늦거나 빠지는 일이 생깁니다.
휴대폰을 현관 앞에 들고 가서 와이파이 신호가 몇 칸인지 보면 대략 짐작할 수 있습니다. / 현관에서 신호가 한두 칸이라면 공유기를 현관 쪽으로 조금 옮기거나 중계기를 두는 것만으로 나아지기도 합니다.
아파트 관리사무소나 건물 쪽에서 공동 인터넷 공사를 한 뒤에 끊기는 일도 있습니다. / 이웃집도 비슷하다면 집 안 문제가 아닐 가능성이 큽니다.

# 휴대폰을 바꿨거나 설정을 손봤다면
새 휴대폰으로 옮긴 뒤 알림이 안 오는 경우도 많습니다. / 앱은 옮겨졌어도 로그인이 풀려 있거나 알림 허용이 꺼져 있는 상태일 수 있습니다.
- 앱에 로그인이 되어 있는지
- 휴대폰 설정에서 그 앱 알림이 허용되어 있는지
- 절전 모드나 방해 금지 모드가 켜져 있지 않은지
- 앱을 오래 열지 않아 휴대폰이 자동으로 멈춰 두지 않았는지
이 네 가지만 봐도 알림 문제의 상당수는 풀립니다. / 앱을 최신 상태로 업데이트하는 것도 잊지 마세요.

# 도어락 쪽에서 볼 것
도어락 건전지가 약해지면 문 여닫는 기능은 버티는데 무선 연결부터 먼저 꺼지는 제품이 있습니다. / 알림이 끊긴 시기와 건전지 경고음이 난 시기가 비슷하다면 건전지를 새것으로 바꿔 보세요.
연결 모듈이 따로 꽂혀 있는 제품이라면 그 모듈이 헐겁게 빠지지 않았는지도 봅니다. / 안쪽 몸체 덮개를 열었을 때 작은 부품이 덜렁거리면 사진을 찍어 보내 주세요.
@ 북가좌동 도어락 와이파이 연결 모듈 확인

# 가족 계정이 꼬였을 때
가족이 같이 쓰는 앱이라면 대표 계정과 초대받은 계정이 나뉘어 있는 경우가 많습니다. / 대표 계정을 가진 분이 휴대폰을 바꾸거나 계정을 지우면 다른 가족도 알림을 못 받게 됩니다.
누가 대표 계정을 가지고 있는지 가족끼리 먼저 확인해 보세요. / 대표 계정 쪽에서 다시 초대를 보내면 해결되는 일이 많습니다.
이사 오면서 이전 집주인 계정이 그대로 남아 있는 경우도 있습니다. / 이럴 때는 도어락을 초기화하고 새로 등록하는 것이 깔끔합니다.

# 연결을 다시 하기 전에 기억할 것
앱에서 기기를 지우고 다시 등록하면 등록된 번호나 지문이 같이 지워지는 제품이 있습니다. / 다시 연결하기 전에 지금 쓰는 번호를 가족 모두 알고 있는지 확인하세요.
연결을 다시 하다 실수로 초기화가 되면 갑자기 문이 안 열리는 일이 생깁니다. / 그러니 문을 열어 둔 상태에서, 안쪽에서 작업하시는 편이 안전합니다.
설명서가 없으면 제품 이름으로 제조사 안내를 찾아보시는 게 정확합니다. / 버튼을 오래 누르는 시간이나 순서가 제품마다 달라서 짐작으로 누르다 보면 엉뚱한 설정이 바뀝니다.

# 원격 열림이 안 될 때 문 밖에 서 있다면
앱으로 문을 열어 주려던 상황인데 연결이 안 되면 문 밖 사람은 들어오지 못합니다. / 아이나 어르신이 밖에 계시다면 번호나 카드 같은 다른 방법이 있는지 먼저 떠올려 보세요.
다른 방법이 모두 막혀 있다면 그때는 문을 여는 일이 먼저입니다. / 위치와 함께 누가 밖에 있는지 알려주시면 순서를 앞당겨 출발합니다.

# 북가좌동 위치 알려주실 때
아파트라면 단지 이름과 동, 호수를 알려주세요. / 빌라라면 건물 이름과 함께 가좌역 쪽인지, 어느 큰길 쪽인지 말씀해 주시면 됩니다.
도어락 제품 이름이나 안쪽 몸체 사진을 같이 보내 주시면 연결 방식까지 미리 보고 출발합니다.

# 출장 점검은 이렇게 진행됩니다
도착하면 사시는 분이 맞는지 신분증이나 주소가 적힌 우편물, 관리사무소 확인으로 먼저 확인합니다. / 문이 닫혀 있는 상황이라면 이 확인을 거친 뒤 문을 엽니다.
작업 전에 무엇을 할지와 비용을 먼저 말씀드리고, 끝내 열지 못하면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
연결 문제는 도어락 고장이 아닌 경우가 많습니다. / 그래서 부품을 바꾸기보다 설정과 전원을 먼저 손보고, 그래도 안 될 때만 수리를 말씀드립니다.

# 문이 닫힌 채 앱도 번호도 안 될 때
연결 문제와 전원 문제가 겹치면 문이 아예 안 열립니다. / 이럴 때는 무리하지 말고 연락 주세요. 손상이 적은 방법부터 차례로 시도합니다.
여는 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다. / 열고 난 뒤에는 연결까지 다시 되는지 같이 확인합니다.
@ 서대문 북가좌동 도어락 원격 열림 점검

# 알림 도어락을 오래 편하게 쓰려면
- 공유기를 바꾸면 그날 도어락 연결도 같이 다시 하기
- 대표 계정은 가족 중 휴대폰을 자주 바꾸지 않는 분이 갖기
- 건전지 경고음이 나면 연결이 끊기기 전에 바로 교체하기
- 앱 알림이 며칠 조용하면 일부러 문을 한 번 여닫아 확인하기
연결 기능이 자주 말썽이라면 제품 자체가 맞지 않을 수 있습니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)로 먼저 보시고, 바꾸실 생각이면 [도어락 교체](doorlock-replace.html)도 상담해 드립니다.
