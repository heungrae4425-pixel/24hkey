# 천연동 현관 너머에서 아이 목소리가 들릴 때
천연동은 독립문역 가까이 아파트와 빌라, 주택이 어우러진 동네입니다. / 어린아이를 키우거나 반려동물과 함께 사는 집이 많아서, 문이 잠겼다는 연락 가운데 "안에 아이가 있어요"라는 말이 붙는 경우가 적지 않습니다.
아이만 두고 잠깐 내려갔다 왔는데 문이 안 열리거나, 아이가 장난으로 안쪽 잠금을 건 경우가 대부분입니다. / 강아지가 문 앞에서 뛰다가 안쪽 버튼을 건드려 잠기는 일도 있습니다.
이럴 때는 문을 여는 방법보다 누구에게 먼저 연락하느냐가 더 중요합니다. / 이 글은 그 순서를 정리했습니다.
@ 천연동 아이 반려동물 집 안 현관문 잠김

# 위급한지부터 30초 안에 가늠하기
문 앞에서 아래 세 가지를 먼저 떠올려 보세요.
- 안에서 가스 불, 다리미, 욕조 물을 켜 둔 것이 있는지
- 아이가 몇 살이고, 지금 울거나 대답을 하는지
- 아이가 창문이나 베란다 쪽에 갈 수 있는 상황인지
셋 중 하나라도 걱정된다면 위급한 상황으로 보고 움직여야 합니다. / 아무것도 켜 두지 않았고 아이가 대답을 잘 한다면 조금은 마음을 놓고 다음 순서로 넘어가셔도 됩니다.

# 119가 먼저인 경우
불이나 물을 켜 둔 채 나왔거나, 아기가 대답하지 못할 만큼 어리거나, 창가에 혼자 있을 수 있다면 119에 먼저 연락해 주세요. / 생명과 안전이 걸린 일은 열쇠집보다 구조가 우선입니다.
119에 연락한 뒤 저희에게도 알려주시면 함께 움직입니다. / 어느 쪽이 먼저 도착하든 문을 여는 데 필요한 정보를 같이 나누면 됩니다.
아파트라면 관리사무소나 경비실에도 바로 알려 주세요. / 같은 층 이웃이 베란다 쪽에서 아이 모습을 살펴봐 줄 수 있는지도 물어볼 수 있습니다.

# 아이가 안에서 잠금을 걸었을 때 말 거는 법
아이가 말을 알아듣는 나이라면 문 너머로 차분하게 말을 걸어 주세요. / 목소리가 떨리면 아이도 덩달아 무서워합니다.
"엄마 여기 있어, 금방 열어 줄게"처럼 짧고 같은 말을 반복하는 것이 좋습니다. / 아이가 문 앞에서 멀어지지 않게 좋아하는 노래나 이야기를 계속 들려주는 방법도 있습니다.
아이가 걸쇠를 풀 수 있을 것 같으면 "위에 있는 동그란 거 옆으로 밀어 볼래"처럼 쉬운 말로 한 번만 부탁해 보세요. / 몇 번 해도 안 되면 더 시키지 마시고 칭찬해 주면서 기다리게 해 주세요.

# 아이에게 시키지 말아야 할 것
의자를 밟고 올라가 위쪽 잠금장치를 풀어 보라고 하는 것은 피해 주세요. / 넘어지면 문을 여는 일보다 훨씬 큰일이 됩니다.
가위나 칼 같은 도구를 가져오라고 하거나, 창문을 열어 보라고 하는 것도 안 됩니다. / 아이에게 맡기는 일은 문 앞에서 기다리기, 대답하기 정도로 충분합니다.
@ 천연동 현관 문 너머 아이와 대화하며 기다리기

# 반려견이 문 앞에서 버튼을 건드린 경우
강아지가 현관에서 반기다가 안쪽 몸체의 잠금 버튼이나 이중 잠금 레버를 누르는 일이 있습니다. / 이렇게 되면 바깥에서 번호를 눌러도 안쪽 잠금이 걸려 있어 열리지 않습니다.
번호를 맞게 눌렀는데 짧은 경고음과 함께 안 열린다면 이 경우를 의심해 볼 수 있습니다. / 이때 번호를 계속 누르면 강아지가 소리에 놀라 더 흥분할 수 있으니 잠깐 멈추세요.
문 앞에서 이름을 부르며 진정시키고, 강아지가 문을 긁거나 짖는 소리가 잦아들면 연락 주시면 됩니다.
이웃집에 짖는 소리가 들릴까 걱정되시겠지만, 사정을 말씀드리면 대부분 이해해 주십니다. / 강아지가 좋아하는 간식 봉지 소리를 문밖에서 들려주면 금방 조용해지기도 합니다.

# 고양이나 작은 동물만 있을 때
고양이나 작은 동물은 소리보다 낯선 사람 냄새와 움직임에 더 놀랍니다. / 문이 열리는 순간 밖으로 뛰쳐나가는 일이 있어서 문을 열 때 보호자가 바로 옆에 서 계셔야 합니다.
이동장이 집 안에 있다면 문이 열린 뒤 바로 넣을 수 있게 위치를 기억해 두세요.
복도 쪽 공동현관이나 계단 문도 미리 닫아 두면 혹시 빠져나가더라도 멀리 가지 않습니다. / 작은 일 같지만 이런 준비가 문을 연 뒤의 소동을 크게 줄여 줍니다.

# 전화로 꼭 먼저 알려주실 것
- 집 안에 누가 있는지, 아이라면 나이
- 켜 둔 불이나 물이 있는지
- 안쪽 잠금이 걸린 것 같은지, 번호판 반응은 어떤지
- 천연동 아파트 동·호수 또는 빌라 위치
이 내용을 먼저 들으면 출동 순서를 앞당기고 필요한 장비를 바로 챙깁니다. / 통화가 길어지면 아이가 불안해하니 핵심만 짧게 말씀해 주셔도 됩니다.

# 도착하면 안의 아이 상태부터 봅니다
도착하면 먼저 문 너머로 아이 목소리를 확인합니다. / 작업하는 소리에 아이가 놀라지 않게 보호자가 계속 말을 걸어 주시는 것이 큰 도움이 됩니다.
문 여는 방법은 덜 상하는 방법부터 차례로 씁니다. / 아이가 문 바로 뒤에 붙어 있으면 다칠 수 있어서 한 걸음 물러나 있게 해 달라고 부탁드리기도 합니다.
문이 열리면 보호자가 먼저 들어가 아이를 안아 주시고, 그다음에 도어락과 잠금 상태를 함께 살펴봅니다. / 아이가 놀랐다면 정리는 조금 뒤에 해도 괜찮습니다.

# 거주 확인은 이렇게 간단히
문을 여는 일이라 사시는 분인지 확인하는 절차는 그대로 거칩니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
서류가 집 안에 있다면 문을 연 직후 확인해도 됩니다. / 아이가 안에 있는 급한 상황이라 확인 때문에 시작이 늦어지지 않게 순서를 조정합니다.

# 비용 안내와 문 여는 방식
도어락 종류와 잠금 상태를 본 뒤 비용을 먼저 말씀드리고 시작합니다. / 끝내 열지 못하면 비용은 받지 않습니다.
현관문 여는 과정은 [현관문 개문](door-open.html), 전체 진행은 [이용안내](guide.html)에 정리해 두었습니다.
@ 천연동 현관문 개방 아이 보호자 함께 확인

# 같은 일을 막는 현관 설정
- 아이 손이 닿는 높이의 걸쇠는 쓰지 않거나 위치를 높이기
- 반려동물이 자주 오가는 현관이면 안쪽 잠금 버튼 덮개를 확인
- 아이에게 맡길 때는 휴대폰 위치 공유나 이웃 연락처 미리 남기기
- 비상 출입 수단을 하나 더 두기, 예를 들어 카드키를 가족에게 하나
안쪽 잠금 버튼이 너무 쉽게 눌리는 제품이라면 [도어락 수리](doorlock-repair.html)로 설정을 바꿀 수 있는지 먼저 보고, 어렵다면 [도어락 교체](doorlock-replace.html) 때 이 부분을 꼭 살펴보세요.
