# 천연동 현관에서 지문이 자꾸 튕긴다면
천연동은 독립문역 가까이 아파트와 빌라, 주택이 어우러진 동네입니다. / 짐을 들고 오르내리는 길이 많아 손을 쓰지 않고 손가락만 대면 열리는 지문 도어락을 반기는 집이 많습니다.
그런데 장바구니를 들고 겨우 손가락을 댔는데 삐 하고 실패음이 나면 기운이 빠집니다. / 몇 번 반복되면 고장인가 싶어 번호를 누르게 됩니다.
이 글은 천연동에서 지문 인식이 잘 안 될 때 원인을 손, 센서, 전원 순서로 좁히는 방법을 정리했습니다. / 지문도 번호도 안 돼 문 밖에 계시다면 [서대문 출장열쇠](seoul-seodaemun.html)에 먼저 연락 주세요.
@ 천연동 지문 도어락 인식 실패 점검

# 실패가 언제부터, 누구에게 생겼나요
원인을 찾을 때 가장 먼저 볼 것은 실패하는 사람과 시기입니다. / 이 두 가지만 정리해도 방향이 반쯤 잡힙니다.
가족 중 한 사람만 자꾸 실패한다면 그 사람의 손가락 상태나 등록 상태를 의심합니다. / 가족 모두가 어느 날부터 같이 실패한다면 센서나 전원 쪽 문제일 가능성이 큽니다.
계절이 바뀔 즈음부터 실패가 늘었다면 손 상태와 날씨의 영향이 큽니다. / 반대로 하루아침에 갑자기 안 된다면 센서 오염이나 건전지를 먼저 봅니다.

# 손가락 쪽에서 흔한 이유
지문 센서는 손가락 표면의 굴곡을 읽습니다. / 그 굴곡이 평소와 달라지면 같은 손가락이라도 다른 사람처럼 읽힙니다.
- 겨울에 손이 건조해 지문이 갈라진 경우
- 설거지나 샤워 직후 손가락이 불어 있는 경우
- 손가락에 로션이나 기름기가 묻은 경우
- 작은 상처나 굳은살로 지문 일부가 덮인 경우
손이 너무 마르면 입김을 살짝 불거나 손을 비빈 뒤 대 보세요. / 젖어 있다면 잘 닦고 잠시 뒤에 대는 편이 낫습니다.

# 대는 방법만 바꿔도 달라집니다
급하면 손가락 끝만 톡 대고 떼는 경우가 많습니다. / 센서는 손가락 가운데 넓은 면을 읽어야 해서 끝만 대면 실패가 잦습니다.
손가락 첫 마디 가운데를 센서 중앙에 평평하게 올리고, 1초 정도 가만히 두세요. / 너무 세게 누르면 지문이 눌려 퍼지고, 너무 살짝 대면 일부만 읽힙니다.
처음 등록할 때 댄 각도와 지금 대는 각도가 다르면 실패할 수 있습니다. / 등록했던 자세를 떠올려 비슷하게 대 보시면 의외로 잘 됩니다.

# 센서 쪽에서 확인할 것
센서 표면에 먼지, 손때, 물기가 쌓이면 모든 가족이 같이 실패합니다. / 부드러운 마른 천으로 센서를 가볍게 닦아 보세요.
물티슈나 세정제를 바로 뿌리는 건 피해 주세요. / 틈으로 물기가 스며들어 다른 고장을 부를 수 있습니다.
센서 표면에 긁힌 자국이 보인다면 닦아서 해결되지 않을 수 있습니다. / 이럴 때는 사진을 찍어 보내 주시면 수리로 될지 먼저 봐 드립니다.
@ 천연동 지문 센서 표면 닦기 마른 천

# 건전지가 약해도 지문이 먼저 흔들립니다
건전지 힘이 떨어지면 번호는 그럭저럭 되는데 지문 인식부터 불안해지는 제품이 있습니다. / 지문은 센서를 켜고 읽는 데 전기를 더 쓰기 때문입니다.
최근에 건전지 경고음을 들은 기억이 있다면 새것으로 한꺼번에 바꿔 보세요. / 일부만 바꾸면 남은 헌 건전지 때문에 금방 다시 약해집니다.
겨울철 추운 아침에만 실패가 잦다면 추위로 건전지 힘이 일시적으로 떨어진 것일 수 있습니다.

# 어르신 손가락은 따로 신경 써 주세요
나이가 들면 지문이 얕아지고 손이 쉽게 건조해집니다. / 부모님 댁 지문 도어락이 자꾸 실패하는 이유가 여기에 있는 경우가 많습니다.
어르신은 한 손가락만 등록하기보다 양손에서 두세 손가락을 등록해 두시는 편이 좋습니다. / 그날 상태가 좋은 손가락으로 열 수 있게 됩니다.
그래도 실패가 잦다면 번호나 카드처럼 다른 방법을 함께 쓰시게 하는 것이 마음 편합니다. / 손에 힘이 없으셔도 쓰기 쉬운 카드가 도움이 될 때가 많습니다.

# 아이 지문은 자라면서 바뀝니다
아이 손가락은 크면서 지문 크기와 모양이 조금씩 달라집니다. / 몇 해 전에 등록한 지문이 요즘 잘 안 된다면 다시 등록해 주세요.
아이가 혼자 집에 들어오는 일이 많다면 지문 외에 번호도 함께 외우게 해 두세요. / 지문이 실패하는 날에도 문 밖에서 기다리지 않게 됩니다.
아이 손이 작아 센서 가운데에 잘 맞추지 못한다면 부모가 손을 잡고 몇 번 같이 연습해 보세요. / 대는 위치만 익혀도 실패가 눈에 띄게 줄어듭니다.

# 지문이 실패할 때 쓸 다른 방법
지문 도어락이라도 대부분 번호나 카드, 열쇠 같은 보조 방법이 있습니다. / 지문이 계속 안 되면 고집하지 말고 다른 방법으로 먼저 들어가세요.
들어간 뒤에 지문을 지우고 다시 등록하면 좋아지는 경우가 많습니다. / 등록 방법은 제품마다 달라서 안쪽 몸체 덮개 안쪽의 설명이나 제조사 안내를 참고하세요.

# 다시 등록할 때 이렇게 하면 오래갑니다
등록할 때는 손을 깨끗이 씻고 물기를 완전히 말린 상태에서 하세요. / 너무 건조한 겨울이라면 손을 살짝 비벼 온기를 돌린 뒤가 좋습니다.
같은 손가락을 조금씩 각도를 바꿔 여러 번 대라고 안내하는 제품이 많습니다. / 이때 똑같이만 대지 말고 살짝 기울이거나 위치를 옮겨 가며 대면 평소 아무렇게나 대도 잘 읽힙니다.
가족마다 최소 두 손가락씩 등록해 두면 한 손에 짐을 들었을 때도 다른 손으로 열 수 있습니다. / 저장할 수 있는 지문 개수가 정해진 제품이라면 쓰지 않는 예전 지문부터 지우세요.

# 지문도 번호도 안 될 때
모든 방법이 막혀 문 밖에 서 있다면 그때는 문을 여는 것이 먼저입니다. / 위치와 함께 지문, 번호판 상태를 알려주시면 출발 전에 준비할 것을 챙깁니다.
천연동 아파트라면 단지와 동, 호수를, 빌라라면 건물 이름과 독립문역 쪽 어느 길인지 알려주세요. / 도착하면 신분증, 주소가 적힌 우편물, 관리사무소 확인 중 하나로 사시는 분인지 먼저 확인합니다.
작업 전에 비용을 먼저 말씀드리고, 끝내 열지 못하면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 센서 수리와 교체는 이렇게 판단합니다
센서 표면만 오염됐거나 연결이 헐거운 경우라면 손봐서 다시 쓸 수 있습니다. / 이 경우는 [도어락 수리](doorlock-repair.html)로 안내합니다.
센서가 깨졌거나 오래 써서 인식률이 계속 떨어진다면 교체를 생각해 볼 만합니다. / 가족 모두가 지문을 잘 쓰지 않는다면 지문 없는 제품이 더 맞을 수도 있어서, 바꾸실 때는 [도어락 교체](doorlock-replace.html)에서 함께 고민해 드립니다.
@ 서대문 천연동 지문 도어락 재등록 안내
