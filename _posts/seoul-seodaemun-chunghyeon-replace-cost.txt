# 충현동에서 도어락을 바꿀까 고민 중이라면
충현동은 서대문구 남쪽, 북아현동과 맞닿은 동네로 아파트와 빌라, 오래된 주택이 함께 있습니다. / 집마다 문을 단 시기가 달라서 도어락도 새 제품부터 꽤 오래 쓴 제품까지 섞여 있습니다.
번호판 반응이 느려지거나 잠금 소리가 예전 같지 않으면 바꿀 때가 됐나 싶어집니다. / 그런데 막상 알아보려 하면 얼마가 드는지, 무엇을 기준으로 정하는지부터 막막합니다.
이 글은 충현동에서 도어락 교체를 앞두고 미리 알아 두면 좋은 것과, [서대문 출장열쇠](seoul-seodaemun.html)가 비용을 어떤 순서로 안내하는지 정리했습니다. / 숫자보다 판단 순서에 초점을 맞췄습니다.
@ 충현동 도어락 교체 상담 출장열쇠

# 바꾸기 전에 고칠 수 있는지부터
도어락 문제의 상당수는 교체까지 가지 않고 끝납니다. / 건전지 접점을 닦거나 걸쇠 위치를 맞추는 것만으로 다시 잘 쓰는 집이 많습니다.
- 건전지를 새로 넣었더니 증상이 사라진 경우
- 문틀이 처져 걸쇠가 걸리던 경우
- 손잡이 나사가 풀려 헐거웠던 경우
- 번호판에 먼지나 물기가 끼어 있던 경우
이런 경우라면 [도어락 수리](doorlock-repair.html)로 충분합니다. / 저희는 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.

# 교체를 권하는 경우
반대로 아래처럼 바꾸는 편이 오히려 덜 번거로운 때도 있습니다. / 여러 가지가 겹치면 교체 쪽으로 기울게 됩니다.
모터나 회로 쪽이 상해 같은 고장이 몇 번씩 반복되는 경우가 대표적입니다. / 오래된 제품이라 부품을 구하기 어려운 경우도 그렇습니다.
가족 구성이 바뀌어 지문이나 카드 같은 기능이 필요해진 때도 교체를 생각해 볼 만합니다. / 이때는 고장 여부보다 생활에 맞는지가 기준이 됩니다.
문을 새로 바꾸거나 현관 공사를 하는 김에 도어락도 같이 바꾸는 경우도 있습니다. / 이럴 때는 문 공사가 끝난 뒤 문 두께와 구멍을 보고 제품을 고르는 편이 실수가 적습니다.

# 견적에 영향을 주는 것들
도어락 교체 비용은 제품값만으로 정해지지 않습니다. / 문 상태와 기존 도어락 구조에 따라 작업 범위가 달라지기 때문입니다.
- 원하시는 제품의 방식(번호, 지문, 카드, 앱 연동)
- 기존 구멍을 그대로 쓸 수 있는지, 새로 맞춰야 하는지
- 문 두께와 재질, 보조키가 따로 있는지
- 기존 도어락을 떼어 낼 때 손볼 곳이 있는지
그래서 전화로는 대략의 방향만 말씀드리고, 정확한 비용은 문을 직접 본 뒤 알려드립니다. / 이 순서가 나중에 말이 달라지는 일을 막는 가장 확실한 방법입니다.

# 사진을 보내 주시면 준비가 빨라집니다
문 바깥 번호판, 안쪽 몸체, 문 옆면 걸쇠 부분을 각각 찍어 보내 주세요. / 문 전체가 나오게 한 장 더 있으면 문 크기도 짐작할 수 있습니다.
사진을 보면 기존 구멍을 살릴 수 있는 제품이 무엇인지 어느 정도 가늠이 됩니다. / 원하시는 기능을 같이 적어 주시면 맞는 제품 몇 가지를 추려 말씀드립니다.
@ 충현동 도어락 교체 전 문 두께 사진 확인

# 현장에서 비용을 듣는 순서
도착하면 문과 도어락 상태부터 봅니다. / 고쳐서 될지, 바꿔야 할지를 먼저 말씀드리고 각각의 차이를 설명합니다.
교체로 정하시면 제품과 작업 내용, 비용을 한 번에 알려드립니다. / 듣고 나서 생각할 시간이 필요하시면 그날 결정하지 않으셔도 됩니다.
작업을 시작한 뒤 예상하지 못한 손볼 곳이 나오면 손대기 전에 다시 여쭤봅니다. / 말없이 늘어나는 금액은 없습니다.
여러 제품 사이에서 고민하신다면 각각 무엇이 다르고 어떤 집에 맞는지를 먼저 설명드립니다. / 비싼 제품이 꼭 우리 집에 맞는 것은 아니어서, 쓰실 분의 습관을 듣고 함께 고르는 편이 만족도가 높습니다.

# 직접 산 도어락을 달아 달라고 할 때
인터넷으로 제품을 미리 사 두고 설치만 부탁하시는 분도 있습니다. / 이 경우도 가능하지만, 사시기 전에 문 두께와 구멍 크기에 맞는지 먼저 확인하시는 편이 좋습니다.
맞지 않는 제품을 억지로 달면 문에 구멍을 더 내야 하거나 걸쇠가 문틀과 어긋납니다. / 고민되시면 제품 이름을 보내 주세요. 맞는지 먼저 봐 드립니다.
설치 전 확인할 것은 [도어락 설치](doorlock-install.html) 페이지에 자세히 적어 두었습니다.

# 충현동 집 형태별로 볼 것
아파트 현관은 문이 두껍고 무거운 편이라 밀고 당기는 형 도어락이 잘 맞습니다. / 기존 제품과 같은 방식이면 구멍을 그대로 쓰는 경우가 많습니다.
빌라와 주택은 문 두께와 재질이 집마다 달라 제품 선택 폭이 조금 좁아질 수 있습니다. / 오래된 나무문이나 얇은 철문은 무거운 제품을 달면 문이 처질 수 있어서 함께 살펴봅니다.
보조키가 따로 달린 문이라면 보조키를 그대로 둘지, 새 도어락 하나로 합칠지도 정해야 합니다. / 보조키를 떼면 남는 구멍을 어떻게 마감할지도 미리 말씀드립니다.

# 교체 날 미리 준비해 두면 좋은 것
- 가족이 함께 쓸 새 비밀번호
- 지문을 등록할 가족이 집에 있는 시간
- 카드나 태그를 쓸 사람 수
- 기존 도어락을 따로 보관할지 여부
가족이 다 모인 저녁 시간에 교체하시면 지문과 카드 등록까지 한 번에 끝낼 수 있습니다.
현관 앞 신발장이나 짐이 문 여닫는 범위에 있다면 잠시 치워 두세요. / 작업 공간이 넓으면 시간이 덜 걸립니다.

# 문이 안 열려서 교체를 생각하게 됐다면
지금 문이 안 열리는 상황이라면 교체보다 문을 여는 일이 먼저입니다. / 열고 나서 원인을 보면 교체까지 필요 없는 경우도 많습니다.
도착하면 사시는 분이 맞는지 신분증이나 주소가 적힌 우편물로 확인하고, 끝내 열지 못하면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 떼어 낸 도어락은 어떻게 하나요
기존 도어락은 원하시면 정리해서 가져갑니다. / 다른 문에 다시 쓰실 생각이면 그대로 두고 갑니다.
떼어 낸 제품이 아직 쓸 만하다면 작은 방이나 창고 문에 옮겨 다는 방법도 있습니다. / 이 경우 그 문에 맞는지도 같이 봐 드립니다.
세입자라면 집주인과 이야기가 필요할 수 있습니다. / 원래 제품을 보관해 달라고 하는 경우도 있으니 미리 확인해 보세요.
@ 서대문 충현동 기존 도어락 철거 새 제품 설치

# 바꾸고 나서 확인할 것
설치가 끝나면 안팎에서 여러 번 열고 잠가 봅니다. / 걸쇠가 문틀에 부드럽게 들어가는지, 자동 잠금이 제대로 되는지 같이 봅니다.
번호와 지문, 카드를 등록한 뒤 가족 한 분씩 직접 열어 보시게 합니다. / 비상 전원 단자 위치와 건전지 교체 방법도 알려드립니다. 진행 방식 전체는 [이용안내](guide.html)에 있습니다.
