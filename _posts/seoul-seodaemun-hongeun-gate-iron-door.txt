# 홍은동에서 현관보다 먼저 막히는 문
홍은동은 홍제역 생활권에서 조금 안쪽으로 들어가 빌라와 주택이 이어지는 동네입니다. / 집 현관에 닿기 전에 대문이나 건물 철문, 공동 출입문을 한 번 더 지나야 하는 집이 많습니다.
현관 도어락은 멀쩡한데 바깥 대문이 안 열려 집 앞에서 멈춰 서는 일이 생각보다 자주 있습니다. / 반대로 대문이 제대로 안 잠겨서 밤새 신경이 쓰인다는 연락도 있습니다.
이 글은 홍은동에서 대문, 철문, 공동 출입문이 말썽일 때 문 종류별로 먼저 살펴볼 곳을 정리했습니다. / 지금 문 앞에 계시다면 [서대문 출장열쇠](seoul-seodaemun.html)로 바로 연락 주셔도 됩니다.
@ 홍은동 주택 대문 철문 잠금 출장열쇠

# 어떤 문인지부터 나눠 보세요
같은 "대문"이라도 구조가 다르면 원인과 여는 방법이 완전히 달라집니다. / 통화할 때 아래 중 어느 쪽인지 말씀해 주시면 준비가 빨라집니다.
- 주택 마당 앞 철제 대문, 열쇠나 번호키로 잠그는 문
- 빌라 1층 철문, 세대마다 번호나 카드를 쓰는 공동 출입문
- 위아래 빗장이나 걸쇠를 손으로 거는 오래된 대문
- 초인종과 연결돼 안에서 버튼으로 여는 전기식 문
대문 사진을 바깥에서 한 장, 잠금장치 가까이서 한 장 찍어 보내 주시면 가장 정확합니다. / 밤이라 어두우면 휴대폰 불빛을 비춰 찍으셔도 충분합니다.

# 철제 대문이 안 열리는 흔한 이유
마당 앞 철제 대문은 비와 햇볕을 그대로 맞아서 잠금장치 안쪽이 녹슬기 쉽습니다. / 녹이 쌓이면 열쇠가 끝까지 들어가지 않거나 들어가도 돌아가지 않습니다.
대문 자체가 아래로 처지는 일도 많습니다. / 경첩이 닳으면 문짝이 기울어 걸쇠가 받이에 꽉 물려 버립니다. 이럴 때는 문을 살짝 들어 올리면서 열쇠를 돌리면 풀리기도 합니다.
겨울에는 물기가 얼어 잠금장치가 굳는 날도 있습니다. / 뜨거운 물을 붓거나 불로 녹이는 건 피해 주세요. 마르면서 다시 얼거나 도장이 상합니다.

# 빌라 공동 출입문이 막혔을 때
공동 출입문은 여러 세대가 같이 쓰는 문이라 내 번호만의 문제가 아닐 수 있습니다. / 이웃도 못 들어가고 있다면 전원이나 기계 쪽 문제일 가능성이 큽니다.
번호를 눌러도 반응이 없다면 건물 전기 상태부터 생각해 보세요. / 정전이나 차단기가 내려간 경우에는 문만 손봐서는 해결되지 않습니다.
카드는 되는데 번호가 안 되거나 그 반대라면 인식부 한쪽만 고장 났을 수 있습니다. / 이웃에게 어떤 방법으로 들어오셨는지 물어보면 원인이 금방 좁혀집니다.
공동 출입문은 건물 관리를 맡은 분이나 건물주와 상의해서 손보는 것이 순서입니다. / 저희에게 연락 주실 때도 관리하시는 분 연락처를 함께 알려주시면 진행이 수월합니다.

# 전기식 대문은 안쪽 버튼부터
초인종 옆 버튼으로 안에서 열어 주는 대문이라면 집 안에 계신 가족에게 먼저 눌러 달라고 해 보세요. / 버튼을 눌러도 딸깍 소리가 안 나면 전원이나 배선 쪽, 소리는 나는데 안 열리면 걸쇠 쪽 문제입니다.
집에 아무도 없다면 바깥에서 할 수 있는 일은 많지 않습니다. / 무리하게 흔들면 전기 잠금장치가 상하니 그대로 두고 연락 주세요.
@ 홍은동 빌라 공동 출입문 번호키 점검

# 대문 앞에서 하면 안 되는 것
급한 마음에 대문을 넘어가는 분들이 있습니다. / 담이나 대문 위는 생각보다 미끄럽고 철 모서리가 날카로워 다치기 쉽습니다.
철문 틈에 막대나 공구를 넣어 비트는 것도 피해 주세요. / 문틀이 벌어지면 잠금이 헐거워져 나중에 문이 제대로 잠기지 않습니다.
열쇠가 뻑뻑하다고 식용유를 넣으면 먼지가 엉겨 더 굳습니다. / 윤활이 필요하면 열쇠 구멍 전용 제품을 아주 조금만 쓰는 편이 낫습니다.

# 문이 잠기지 않을 때도 연락 주세요
대문이 안 열리는 것만큼 안 잠기는 것도 불편합니다. / 밤새 대문이 덜 닫힌 채로 있으면 마음이 편할 리 없습니다.
잠기지 않는 이유는 대부분 걸쇠와 받이가 어긋난 경우입니다. / 경첩을 조정하거나 받이 위치를 옮겨서 해결하는 일이 많고, 잠금장치 자체가 닳았으면 부품을 바꿉니다.
도어클로저가 달린 철문이 끝까지 안 닫힌다면 클로저 힘이 약해진 것일 수 있습니다. / 이 경우도 문을 열고 닫아 보면서 같이 맞춰 드립니다.

# 홍은동 위치 설명은 골목 기준으로
홍은동은 비슷한 골목이 이어지고 경사가 있는 길이 많습니다. / 큰길에서 어느 쪽으로 들어와 몇 번째 골목인지 알려주시면 좋습니다.
차가 들어가기 어려운 길이라면 가까운 큰길에서 만나는 방법도 있습니다. / 대문 색이나 모양, 옆집 특징을 한 가지만 알려주셔도 찾기가 훨씬 쉬워집니다.

# 사시는 분인지 확인하는 방법
대문 안쪽이 개인 주택이라면 그 집에 사시는 분이 맞는지 확인합니다. / 신분증 주소나 주소가 적힌 우편물, 집안 가족과의 통화 중 하나면 됩니다.
공동 출입문은 해당 건물에 사시는 분인지, 건물 관리를 맡은 분의 동의가 있는지 확인합니다. / 이웃과 건물 모두를 위한 절차이니 양해 부탁드립니다.
세입자라면 계약서 사진도 거주 확인에 쓸 수 있습니다. / 신분증이 대문 안 집에 있다면 가족이나 집주인과 통화 연결을 해 주셔도 됩니다.

# 비용은 작업 전에 알려드립니다
대문 종류와 잠금장치 상태를 보고 어떤 작업이 필요한지 먼저 말씀드립니다. / 듣고 괜찮으시면 시작하고, 아니면 그냥 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 나서 부품 교체가 필요하면 그때 따로 여쭤봅니다. 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 대문을 여는 순서
대문도 현관문처럼 손상이 적은 방법부터 차례로 시도합니다. / 녹이 심한 잠금장치는 억지로 돌리지 않고 상태를 보면서 천천히 풉니다.
열고 나면 같은 일이 반복되지 않도록 걸쇠와 경첩 상태를 같이 봅니다. / 여는 방식은 [현관문 개문](door-open.html) 페이지에도 정리해 두었습니다.
@ 서대문 홍은동 대문 개문 경첩 점검

# 대문 잠금장치를 바꿀 때 생각할 것
오래된 열쇠식 대문을 번호키로 바꾸고 싶어 하시는 분도 많습니다. / 대문은 비를 맞는 곳이라 바깥용으로 나온 제품인지, 문틀 두께에 맞는지 먼저 봐야 합니다.
가족이 열쇠를 자주 잃어버린다면 번호키가 편하고, 어르신이 쓰시는 집이라면 버튼이 크고 단순한 제품이 낫습니다. / 설치 전 확인할 것은 [도어락 설치](doorlock-install.html)에 적어 두었습니다.
지금 잠금장치를 손봐서 더 쓸 수 있다면 굳이 바꾸지 않습니다. / 이 경우는 [도어락 수리](doorlock-repair.html)로 먼저 안내합니다.
