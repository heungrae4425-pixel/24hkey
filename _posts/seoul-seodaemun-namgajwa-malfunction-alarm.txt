# 남가좌동 밤중에 현관에서 들리는 낯선 소리
남가좌동은 가좌역 생활권에 아파트와 빌라가 함께 있는 동네입니다. / 조용한 밤에 현관 쪽에서 삐삐 소리가 이어지거나 위잉 하는 모터 소리가 반복되면 잠이 확 깹니다.
도어락은 문제가 생기면 대부분 소리로 먼저 알려 줍니다. / 그 소리를 구분할 줄 알면 지금 당장 무엇을 해야 하는지, 아침까지 기다려도 되는지 판단하기 쉬워집니다.
이 글은 남가좌동에서 도어락이 이상한 소리를 낼 때 소리별로 짐작할 수 있는 원인과, [서대문 출장열쇠](seoul-seodaemun.html)를 부를 시점을 정리했습니다.
@ 남가좌동 도어락 경고음 오작동 점검

# 먼저 소리를 휴대폰으로 녹음해 두세요
소리가 나는 동안 휴대폰으로 10초 정도만 녹음하거나 영상으로 찍어 두세요. / 전화로 "삐삐 소리가 나요"라고 설명하는 것보다 훨씬 정확하게 전달됩니다.
번호판 불빛이 깜빡이는 모양도 함께 찍히면 더 좋습니다. / 소리가 언제 멈췄는지, 몇 번째 눌렀을 때 났는지도 같이 적어 두면 원인을 좁히는 데 도움이 됩니다.

# 짧은 멜로디가 반복된다면 배터리 신호
문을 열거나 닫을 때마다 평소와 다른 짧은 멜로디가 붙는다면 배터리 교체 알림인 경우가 많습니다. / 제품에 따라 번호판에 건전지 모양 불이 함께 들어오기도 합니다.
이 단계에서는 아직 문이 잘 열립니다. / 그날 바로 안쪽 건전지를 전부 새것으로 바꾸시면 대부분 조용해집니다.
일부만 바꾸면 남은 건전지가 먼저 닳아서 며칠 뒤 같은 소리가 다시 납니다. / 같은 종류, 같은 날 산 건전지로 한꺼번에 바꿔 주세요.

# 삐삐삐 연속음이 멈추지 않을 때
번호를 여러 번 틀리면 도어락이 경고음을 내며 입력을 잠시 막습니다. / 이럴 때는 몇 분 그대로 두었다가 천천히 다시 눌러 보세요.
아무도 번호를 틀리지 않았는데 연속음이 이어진다면 이야기가 다릅니다. / 번호판에 물기나 먼지가 끼어 버튼이 눌린 것처럼 인식되거나, 안쪽 회로가 불안정할 수 있습니다.
마른 천으로 번호판을 가볍게 닦고 잠시 지켜보세요. / 그래도 계속 울리면 오작동 쪽으로 보고 점검을 받으시는 게 좋습니다.

# 문이 닫혀 있는데 '열림' 경고가 뜬다면
문을 분명히 닫았는데 도어락이 문이 열려 있다는 식의 경고를 내는 경우가 있습니다. / 문틀에 붙은 감지 부분과 도어락 위치가 어긋났을 때 흔히 생깁니다.
남가좌동처럼 오래 산 집과 새집이 섞인 동네에서는 문짝이 조금 처져서 이런 일이 생기기도 합니다. / 문을 한 번 더 꾹 밀어 닫았을 때 경고가 멈춘다면 문 처짐을 의심해 볼 만합니다.
이 경우 도어락보다 문짝과 경첩 쪽을 손봐야 해결되는 일이 많습니다. / 경고를 그대로 두면 자동 잠금이 제대로 걸리지 않은 채 지내게 될 수 있으니 미루지 않는 편이 좋습니다.

# 위잉 하는 모터 소리만 나고 걸쇠가 그대로일 때
번호가 맞아 모터는 도는데 문이 안 열리는 경우입니다. / 걸쇠가 문틀 쪽 받이에 꽉 물려 있거나 모터 안쪽 기어가 헛돌 때 이런 소리가 납니다.
문을 바깥에서 몸 쪽으로 살짝 당기거나 안쪽으로 살짝 밀면서 다시 번호를 눌러 보세요. / 걸쇠에 걸린 힘이 풀리면서 열리는 경우가 있습니다.
두세 번 해도 같다면 더 반복하지 마세요. / 모터를 계속 돌리면 기어가 더 닳고 배터리도 빨리 떨어집니다.
겨울철 찬 바람이 들이치는 현관이라면 추위로 모터 힘이 약해져 같은 소리가 날 때도 있습니다. / 이럴 때는 배터리부터 새로 바꿔 보는 것이 순서입니다.
@ 남가좌동 도어락 모터 헛돎 걸쇠 확인

# 아무도 안 눌렀는데 번호판이 켜지는 경우
한밤중에 번호판 불이 혼자 켜졌다 꺼지면 누가 만진 건 아닌지 걱정되실 수 있습니다. / 실제로는 습기나 결로, 햇빛 때문에 터치 부분이 잘못 반응하는 경우가 많습니다.
걱정이 된다면 문 안쪽에서 걸쇠나 보조키를 잠가 두시고 아침에 확인하셔도 됩니다. / 현관 쪽 창으로 햇빛이 강하게 드는 집이라면 한낮에만 이런 일이 생기는지도 살펴보세요. / 같은 일이 며칠씩 반복되면 번호판 쪽 점검을 받아 보세요.

# 경고음을 끄려고 건전지를 빼기 전에
소리가 시끄러워 건전지를 빼 버리고 싶을 때가 있습니다. / 집 안에 계실 때는 괜찮지만, 그 상태로 외출하면 바깥에서 문을 열 수 없게 됩니다.
건전지를 뺐다면 다시 넣고 번호와 잠금이 정상인지 꼭 확인한 뒤 나가세요. / 일부 제품은 건전지를 뺐다 넣으면 설정이 바뀌는 경우도 있으니 등록 번호도 한 번 눌러 보세요.

# 집 안에 있을 때와 밖에 있을 때 대처가 다릅니다
집 안에 계신다면 급하게 움직일 필요는 없습니다. / 안쪽 몸체의 열림 손잡이나 버튼으로 문이 열리는지만 먼저 확인해 두세요.
밖에 계신데 소리만 나고 문이 안 열린다면 억지로 버튼을 계속 누르지 말고 연락 주세요. / 남가좌동 골목이나 단지 안 어느 쪽인지 알려주시면 도착 시간을 먼저 말씀드립니다.

# 연락 주실 때 함께 알려주실 것
- 녹음한 소리나 영상, 또는 소리 모양 설명
- 소리가 난 시각과 그전에 한 일
- 번호판 불이 켜지는지, 깜빡이는지
- 지금 집 안인지 밖인지
- 도어락 앞면 사진
아파트라면 동과 호수, 빌라라면 건물 이름과 가까운 큰길을 같이 말씀해 주세요. / 공동현관 비밀번호가 따로 있는 건물이면 그것도 미리 알려주시면 문 앞까지 바로 올라갈 수 있습니다.

# 현장에서 확인과 비용 안내
문을 열어야 하는 상황이면 먼저 사시는 분인지 확인합니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나를 준비해 주세요.
소리가 나는 원인을 살펴본 뒤 어떤 작업이 필요한지, 비용이 얼마인지 먼저 말씀드립니다. / 동의하실 때만 시작하고, 끝내 문을 못 열면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 수리로 끝나는 경우, 교체를 말씀드리는 경우
배터리, 접점 청소, 문 처짐 조정으로 끝나는 오작동이 꽤 많습니다. / 이런 경우는 [도어락 수리](doorlock-repair.html)로 손보고 그대로 쓰시면 됩니다.
모터나 회로가 닳아 같은 증상이 반복되거나 부품을 구하기 어려운 오래된 제품이라면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 바꿀지 말지는 설명을 들으신 뒤 정하시면 됩니다.
@ 남가좌동 도어락 수리 교체 상담

# 남가좌동 이웃 동네도 다닙니다
바로 옆 북가좌동을 비롯해 연희동, 홍제동, 홍은동, 신촌동, 천연동, 충현동, 북아현동까지 서대문구 전 지역을 다닙니다. / 구 안에서 다니는 곳은 [서대문구 출장열쇠](seoul-seodaemun.html) 페이지에, 다른 지역은 [출장 지역](area.html)에 정리했습니다.

# 오작동 소리에 대해 자주 듣는 질문
? 새 건전지로 바꿨는데도 멜로디가 계속 나요. | 건전지 방향이나 접점이 헐거운 경우가 있습니다. 한 번 빼서 다시 끼워 보시고, 그래도 나면 점검이 필요합니다.
? 밤에 혼자 삐 소리가 나는데 누가 만진 걸까요? | 습기나 결로로 번호판이 잘못 반응하는 경우가 많습니다. 걱정되시면 안쪽 걸쇠를 잠가 두세요.
? 모터 소리만 나면 도어락을 바꿔야 하나요? | 꼭 그렇지는 않습니다. 걸쇠가 문틀에 물린 경우라면 조정으로 해결되기도 합니다.
? 소리 녹음은 어떻게 보내나요? | 전화 후 문자로 보내 주시면 됩니다. 영상이면 더 좋습니다.
? 문은 열리는데 소리만 이상해도 불러도 되나요? | 네, 완전히 멈추기 전에 보는 편이 오히려 수월합니다.
