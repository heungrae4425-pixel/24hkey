# 신촌동 골목 안 부모님 댁 현관
신촌동은 신촌역을 중심으로 학교와 가게, 원룸 건물이 촘촘한 동네입니다. / 젊은 사람이 많은 곳처럼 보이지만, 골목 안쪽에는 오래 사신 어르신들의 주택과 건물도 적지 않습니다.
건물 위층에 직접 사시면서 아래층 방을 세놓는 부모님도 계십니다. / 이런 집은 하루에도 여러 사람이 드나들어서 현관 도어락이 생각보다 바쁘게 일합니다.
이 글은 신촌동 부모님 댁에 들렀을 때 자녀가 함께 보면 좋은 도어락 점검과, 어르신이 쓰기 편하게 바꿀 수 있는 설정을 정리했습니다. / 손볼 곳이 보이면 [서대문 출장열쇠](seoul-seodaemun.html)에 맡기셔도 됩니다.
@ 신촌동 부모님 댁 현관 도어락 점검

# 방문했을 때 같이 눌러 보세요
부모님께 "문 한번 열어 보세요"라고 부탁드리고 옆에서 지켜보세요. / 평소 쓰시는 모습을 보면 어디가 불편한지 금방 보입니다.
- 번호를 한 번에 누르시는지, 여러 번 고쳐 누르시는지
- 버튼을 누른 뒤 소리가 들리는지 고개를 기울이시는지
- 손잡이를 돌리거나 문을 미는 데 힘이 많이 드시는지
- 문이 닫힌 뒤 잠겼는지 다시 당겨 확인하시는지
부모님은 불편해도 원래 그렇다고 생각하고 지나치시는 경우가 많습니다. / 자녀가 먼저 알아채 드리는 것이 중요합니다.

# 번호판 글씨와 불빛이 잘 보이시는지
터치식 번호판은 불이 들어와야 숫자가 보입니다. / 눈이 어두우신 분께는 숫자가 작고 불빛이 흐리면 누르기가 꽤 어렵습니다.
특히 현관 앞이 어두운 집이라면 밤에 번호판 찾기부터 힘드실 수 있습니다. / 현관 앞에 센서 등을 달아 드리거나, 숫자가 큰 번호판으로 바꾸는 것을 생각해 볼 만합니다.

# 버튼음 크기는 크게
귀가 어두워지시면 버튼음과 잠김 소리를 잘 못 들으십니다. / 그러면 눌렸는지 몰라 같은 번호를 두 번 누르게 되고, 결국 번호가 틀렸다며 문이 안 열립니다.
많은 도어락은 안쪽 설정으로 소리 크기를 바꿀 수 있습니다. / 이웃에 불편을 줄 정도가 아니라면 가장 크게 맞춰 드리는 편이 좋습니다.
설정 방법은 제품마다 달라서 설명서가 없으면 모델 이름으로 찾아보시거나 점검 때 물어보세요.

# 번호 자릿수는 외우기 쉬운 쪽으로
보안만 생각해 너무 긴 번호를 정하면 부모님이 잊어버리시기 쉽습니다. / 생일이나 전화번호 뒷자리처럼 남이 쉽게 짐작하는 번호는 피하되, 부모님께 의미가 있는 숫자로 정해 드리세요.
번호 앞뒤에 아무 숫자나 덧붙여 눌러도 열리는 기능이 있는 제품이라면 번호는 짧게 두고 앞에 숫자를 몇 개 더 누르시도록 알려드리는 방법도 있습니다. / 옆에서 누가 봐도 진짜 번호를 알기 어렵습니다.
@ 신촌동 어르신 도어락 번호와 버튼음 설정

# 지문보다 카드가 편한 분도 있습니다
지문은 편해 보이지만 어르신 손가락은 건조하거나 지문이 옅어져 인식이 잘 안 되는 경우가 있습니다. / 몇 번 실패하시면 아예 안 쓰시게 됩니다.
이럴 때는 카드나 태그를 열쇠고리에 달아 드리는 것이 더 편할 수 있습니다. / 카드를 대기만 하면 열리니 번호를 기억하지 않으셔도 됩니다.
카드를 잃어버리실 때를 대비해 등록된 카드 목록을 자녀가 알고 있으면 좋습니다. / 잃어버린 카드만 지우고 새 카드를 넣으면 됩니다.

# 자동 잠금과 안쪽 이중 잠금 설정
자동 잠금이 꺼져 있으면 문을 닫고도 잠기지 않은 채 지내실 수 있습니다. / 부모님 댁은 자동 잠금을 켜 두는 쪽을 권합니다.
반대로 안쪽 이중 잠금이나 걸쇠는 조심해야 합니다. / 부모님이 안에서 걸어 두신 상태로 쓰러지시거나 하면 가족도 바깥에서 문을 열 수 없습니다.
걸쇠를 쓰지 않으시도록 말씀드리거나, 걸쇠 습관이 있다면 어떤 상황에서 쓰시는지 여쭤 두세요.
밤에 혼자 계실 때 불안해서 거는 거라면, 자동 잠금이 확실히 걸리는 것을 함께 확인해 드리는 것만으로도 마음을 놓으시는 경우가 있습니다.

# 세입자가 드나드는 건물이라면
건물 위층에 사시고 아래층에 세입자가 있다면 공동현관 번호와 부모님 댁 번호를 반드시 다르게 해 두세요. / 공동현관 번호는 여러 사람이 알게 되니 바꿔야 할 때가 자주 옵니다.
세입자가 나갈 때마다 공동현관 번호를 바꾸고, 바꾼 번호를 자녀도 알 수 있게 적어 두면 좋습니다. / 부모님이 혼자 바꾸기 어려우시면 점검 때 함께 바꿔 드릴 수 있습니다.

# 건전지 교체는 누가 언제 할지 정하기
어르신 혼자 사시는 집은 건전지 경고음이 나도 그냥 두시는 일이 많습니다. / 덮개 여는 법이 어렵거나 건전지를 사러 가기 번거로우시기 때문입니다.
자녀가 들를 때마다 건전지 칸을 열어 보고, 바꾼 날짜를 덮개 안쪽에 적어 두세요. / 계절이 바뀌는 무렵에 한 번씩 바꾼다고 정해 두면 잊지 않습니다.

# 휴대폰 첫 화면에 연락처 남기기
부모님 휴대폰 단축번호나 첫 화면에 자녀 번호와 함께 출장열쇠 번호를 저장해 드리세요. / 문이 안 열리면 검색할 필요 없이 바로 누르시면 됩니다.
현관 안쪽 벽에 작은 메모로 붙여 두는 것도 방법입니다. / 글씨는 크고 진하게 써 드려야 급할 때 바로 눈에 들어옵니다.
휴대폰을 집에 두고 나오시는 일이 잦은 분이라면 지갑에도 같은 메모를 한 장 넣어 드리세요. / 이웃에게 전화를 빌리실 때 바로 꺼내 보실 수 있습니다.

# 문이 잠겼다는 전화를 받았을 때
부모님이 문 밖에서 전화를 주시면 먼저 어디에 서 계신지 여쭤 주세요. / 추운 날이면 건물 안이나 가까운 가게 안에서 기다리시게 하는 것이 좋습니다.
자녀가 대신 연락 주셔도 됩니다. / 문을 열 때는 사시는 분인지 신분증이나 우편물, 가족 통화로 확인하고, 비용은 도착해서 먼저 말씀드립니다. 못 열면 비용은 받지 않습니다.
자세한 순서는 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 있습니다.

# 점검이나 교체를 맡길 때 진행
설정만 바꾸면 되는 경우, 부품을 손보면 되는 경우, 제품을 바꾸는 게 나은 경우를 나눠 말씀드립니다. / 고쳐 쓸 수 있는 도어락이면 [도어락 수리](doorlock-repair.html)로 손보고, 번호판이 너무 작거나 오래돼 불편하다면 [도어락 교체](doorlock-replace.html)를 함께 상담합니다.
가능하면 부모님과 자녀가 함께 계실 때 설정을 마무리하시는 것이 좋습니다. / 바뀐 사용법을 두 분이 같이 들어 두시면 나중에 헷갈리지 않습니다.
@ 신촌동 부모님 댁 도어락 교체 상담

# 신촌동 근처 동네
신촌동과 이웃한 연희동을 비롯해 홍제동, 홍은동, 남가좌동, 북가좌동, 천연동, 충현동, 북아현동까지 서대문구 어디든 다닙니다. / 구 안의 동네는 [서대문구 출장열쇠](seoul-seodaemun.html)에, 다른 지역은 [출장 지역](area.html)에 있습니다.

# 부모님 댁 도어락, 자녀분들이 묻는 것
? 부모님이 번호를 자꾸 잊어버리세요. | 카드나 태그를 열쇠고리에 달아 드리면 번호 없이도 여실 수 있습니다.
? 버튼음 크기도 바꿀 수 있나요? | 많은 제품이 안쪽 설정으로 바꿀 수 있습니다. 점검 때 맞춰 드립니다.
? 제가 멀리 사는데 대신 연락해도 되나요? | 네, 자녀분이 연락 주셔도 됩니다. 현장에서는 부모님 거주 확인을 함께 합니다.
? 공동현관 번호와 집 번호를 같게 써도 되나요? | 다르게 두시는 것을 권합니다. 공동현관 번호는 여러 사람이 알게 됩니다.
? 걸쇠를 아예 떼어 드려도 될까요? | 부모님 생활 습관을 먼저 여쭤 보시고, 쓰지 않으신다면 떼거나 쓰지 않도록 말씀드리는 방법이 있습니다.
