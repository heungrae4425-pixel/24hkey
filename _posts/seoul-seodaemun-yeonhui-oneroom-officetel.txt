# 연희동 원룸, 문이 두 겹 세 겹인 집
연희동에는 신촌 쪽 생활권과 이어지는 원룸 건물, 그리고 단독주택을 나눠 세를 놓은 다가구 주택이 많습니다. / 그래서 방에 들어가기까지 대문, 공동현관, 방 현관문을 차례로 지나야 하는 집이 흔합니다.
늦게 들어왔는데 어느 한 곳에서 막히면 혼자 사는 분은 기댈 곳이 마땅치 않습니다. / 휴대폰 배터리까지 얼마 안 남았다면 더 초조해집니다.
이 글은 연희동 원룸에서 문이 잠겼을 때 어느 문에서 막혔는지 나누고, 문마다 무엇을 해 볼 수 있는지 정리했습니다. / 곧바로 도움이 필요하시면 [서대문 출장열쇠](seoul-seodaemun.html)로 연락 주세요.
@ 연희동 원룸 공동현관 방 현관문 잠김 출장열쇠

# 어느 문에서 막혔는지가 먼저입니다
원룸 잠김은 막힌 문에 따라 해결 방법이 완전히 달라집니다. / 전화하실 때 아래 중 어디인지 먼저 말씀해 주세요.
- 골목에 면한 대문이나 건물 1층 출입문
- 건물 안 공동현관 번호키
- 내 방 현관문 도어락
- 방 안 보조 걸쇠가 걸린 경우
대문이나 공동현관에서 막혔다면 이웃이나 건물주가 열어 줄 수 있는지가 첫 번째 열쇠입니다. / 내 방 문에서 막혔다면 그때부터가 출장열쇠가 할 일입니다.

# 대문과 공동현관에서 막혔을 때
다가구 주택 대문은 주인 세대가 같은 건물 위층이나 아래층에 사는 경우가 있습니다. / 늦은 시간이 아니라면 주인 세대에 먼저 부탁해 보세요.
공동현관 번호를 잊었다면 같은 건물 이웃에게 문자로 물어보거나, 건물주에게 연락해 보세요. / 다른 세입자가 들어올 때 함께 들어가는 방법도 있지만, 낯선 분이라면 사정을 짧게 설명하는 편이 서로 편합니다.
공동현관 번호키가 고장 나 아무도 못 들어가는 상황이라면 건물 관리 쪽 일입니다. / 저희가 손볼 때도 건물주나 관리인 동의를 먼저 확인합니다.

# 내 방 현관문, 번호판부터 보세요
방 현관문 앞까지 왔다면 번호판 상태를 먼저 확인합니다. / 불이 안 들어오면 건전지, 불은 들어오는데 안 열리면 번호나 걸쇠 쪽입니다.
원룸 도어락은 이전 세입자가 쓰던 제품을 그대로 쓰는 경우가 많아 건전지 교체 시기를 모르는 분이 많습니다. / 들어온 뒤 한 번도 바꾼 적이 없다면 건전지가 원인일 가능성이 큽니다.
바깥 아래쪽 비상 단자에 9V 건전지를 대 보세요. / 근처 편의점에서 구할 수 있습니다.
번호를 잊은 거라면 서너 번만 차분히 눌러 보고 멈추세요. / 계속 틀리면 도어락이 한동안 입력을 막아 버려서, 생각난 번호도 바로 쓸 수 없게 됩니다.
번호는 맞는데 모터 소리만 나고 안 열린다면 안쪽 걸쇠가 문틀에 물렸을 수 있습니다. / 문을 살짝 밀면서 다시 눌러 보세요.

# 카드키만 쓰던 방이라면
원룸 중에는 번호 대신 카드나 태그만 쓰는 방도 있습니다. / 카드를 방 안에 두고 나왔거나 잃어버리면 번호를 몰라 막히게 됩니다.
카드 등록은 건물주가 관리하는 경우가 많습니다. / 건물주에게 여분 카드가 있는지 먼저 물어보시고, 없다면 문을 연 뒤 새 카드를 등록해야 합니다.
@ 연희동 원룸 카드키 도어락 확인

# 혼자 있는 밤, 기다리는 동안
늦은 밤 골목에서 오래 기다리는 건 누구에게나 불편합니다. / 근처에 밝고 사람이 있는 곳이 있다면 그쪽에서 기다리시다가 도착 연락을 받으셔도 됩니다.
도착 시간을 먼저 말씀드리고, 가까워지면 다시 연락드립니다. / 휴대폰 배터리가 얼마 남지 않았다면 통화할 때 미리 말씀해 주세요. 문자 위주로 연락드리겠습니다.
추운 날이나 비 오는 밤이라면 그 사정도 말씀해 주세요. / 기다리실 곳을 정해 두시면 도착해서 바로 찾아뵙겠습니다.

# 연희동 원룸 위치 알려주는 요령
연희동 골목은 굽이지고 비슷한 주택이 이어져 처음 오면 헷갈립니다. / 건물 이름이 없는 다가구 주택도 많아서 번지와 함께 특징을 알려주시면 좋습니다.
대문 색이나 모양, 1층에 무엇이 있는지, 몇 층 몇 호인지 말씀해 주세요. / 반지하나 옥탑처럼 입구가 따로 있는 방이라면 그 입구 위치도 알려주세요. / 큰길에서 몇 번째 골목으로 들어오는지도 알려주시면 헤매는 시간이 줄어듭니다.

# 방에 사는 분인지 확인합니다
원룸은 같은 건물에 여러 분이 살기 때문에 확인 절차를 꼭 거칩니다. / 신분증 주소, 임대차 계약서, 그 호수로 온 우편물 중 하나면 충분합니다.
모두 방 안에 있다면 건물주와 통화 연결로 확인할 수도 있습니다. / 이웃과 세입자 모두를 위한 절차이니 양해 부탁드립니다.

# 비용은 문을 보기 전에 말하지 않습니다
도어락 종류와 문 상태를 보고 어떤 작업이 필요한지, 비용이 어떻게 되는지 시작 전에 말씀드립니다. / 듣고 괜찮으실 때만 작업합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 나서 말없이 늘어나는 금액도 없습니다. 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 원룸 문은 얇아서 더 조심합니다
원룸 현관문은 아파트 문보다 얇은 경우가 많아 무리하면 문짝이 휘거나 문틀이 벌어집니다. / 그래서 손상을 줄이는 방법부터 차례로 시도합니다.
방 안에서 보조 걸쇠가 걸려 있다면 걸쇠 쪽을 먼저 풀어야 합니다. / 여는 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.

# 문이 열린 뒤 원룸에서 정리할 것
건전지가 원인이었다면 전부 새것으로 바꿉니다. / 번호를 잊었던 경우라면 새 번호를 등록하고 이전 번호는 지웁니다.
카드를 잃어버렸다면 잃어버린 카드 등록을 지우고 새 카드를 등록합니다. / 건물주가 관리하는 카드라면 건물주께도 알려 두세요.
다가구 주택이라 대문 열쇠까지 잃어버린 경우에는 대문 쪽도 함께 봐 드립니다. / 대문은 건물 전체가 쓰는 문이라 건물주와 이야기한 뒤 진행합니다.
도어락이 낡아 자주 말썽이라면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 세입자라면 교체는 건물주와 상의한 뒤 [도어락 교체](doorlock-replace.html)를 진행하시길 권합니다.
@ 서대문 연희동 원룸 도어락 새 번호 등록

# 혼자 사는 집 비상 대비
- 현관 번호는 휴대폰 메모가 아닌 다른 곳에도 하나 적어 두기
- 비상용 9V 건전지 하나를 가방에 넣어 두기
- 건물주와 이웃 한 명의 연락처를 저장해 두기
- 카드키만 쓰는 방이라면 번호도 함께 등록해 두기
작은 준비 하나가 밤 골목에서 기다리는 시간을 크게 줄여 줍니다.
이사 들어온 첫날 건전지를 새로 넣고 번호를 내 번호로 바꿔 두는 것도 잊지 마세요. / 이전 세입자가 쓰던 번호가 그대로 남아 있는 원룸이 의외로 많습니다.
