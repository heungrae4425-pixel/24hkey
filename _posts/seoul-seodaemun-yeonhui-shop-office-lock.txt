# 연희동 골목 가게 문이 아침에 안 열린다면
연희동은 신촌과 홍제동 사이에 자리한 동네로, 단독주택과 원룸 사이사이에 작은 가게와 사무실이 들어서 있습니다. / 주택 1층을 고쳐 쓰는 가게나 2층 작업실처럼 출입문 구조가 제각각인 곳이 많습니다.
문 여는 시간에 맞춰 도착했는데 번호판이 반응하지 않으면 손님 응대부터 꼬입니다. / 사무실이라면 직원들이 문 앞에 줄지어 서 있게 됩니다.
이 글은 연희동 상가와 사무실 출입문이 말썽일 때 먼저 볼 것, 그리고 [서대문 출장열쇠](seoul-seodaemun.html)에 연락할 때 알려주시면 좋은 것을 정리했습니다. / 집 현관문과 다른 점 위주로 적었습니다.
@ 연희동 상가 사무실 출입문 도어락 출장열쇠

# 가게 문은 집 문과 무엇이 다를까
상가 출입문은 하루에도 수십 번 여닫히고 손님 손을 많이 탑니다. / 그래서 집 도어락보다 손잡이와 걸쇠가 빨리 닳습니다.
유리문, 철문, 나무문처럼 재질이 다양하고 위아래에 보조 잠금이 따로 달린 경우도 있습니다. / 주택을 고친 가게는 원래 현관문을 그대로 쓰는 곳도 있어서 집 도어락과 상가용 잠금장치가 섞여 있기도 합니다.
그러니 "문이 안 열린다"보다 어떤 문, 어떤 잠금장치인지가 먼저입니다. / 이 차이를 알면 전화 통화가 훨씬 짧아집니다.
사무실이 건물 안쪽에 있다면 건물 공동 출입문과 사무실 문을 따로 봐야 합니다. / 공동 출입문은 건물 관리 쪽 소관인 경우가 많아서, 어느 문에서 막혔는지 먼저 나눠 주시면 좋습니다.

# 연희동 사업장에서 흔한 막힘 네 가지
가게와 사무실에서 자주 듣는 상황은 대략 이렇습니다.
- 주말 내내 닫아 뒀다가 월요일에 번호판이 꺼진 경우
- 직원이 바꾼 비밀번호를 다른 사람이 모르는 경우
- 유리문 아래 바닥 잠금이 빠지지 않는 경우
- 마감하면서 안쪽 보조키까지 잠그고 나온 경우
이 중 무엇인지 짐작이 가면 통화할 때 바로 말씀해 주세요. / 챙겨 갈 장비가 달라집니다.
주택 가게는 대문과 가게 출입문이 따로 잠기는 곳도 있습니다. / 대문은 열렸는데 가게 문만 막힌 것인지, 대문부터 막힌 것인지도 같이 알려주세요.

# 문 앞에서 먼저 볼 세 가지
급할수록 짧게 확인하고 연락하시는 편이 빠릅니다.
번호판을 손바닥으로 덮어 불이 들어오는지 봅니다. / 불이 안 들어오면 전원 쪽 문제일 가능성이 큽니다.
유리문이라면 문 아래쪽 바닥 잠금과 위쪽 잠금이 어떤 상태인지 들여다봅니다. / 문짝이 살짝 흔들리는지 보면 어디가 물려 있는지 짐작할 수 있습니다.
같이 일하는 분들께 최근에 번호를 바꾼 사람이 있는지 단체 대화방에 물어보세요. / 의외로 이것 하나로 해결되는 날도 있습니다.

# 셔터와 유리문을 억지로 흔들지 마세요
문이 안 열리면 유리문을 세게 당기거나 셔터를 위로 밀어 올리고 싶어집니다. / 유리문은 경첩과 바닥 축에 무리가 가면 문짝이 기울어져 나중에 닫히지 않게 됩니다.
철문 틈에 드라이버를 넣어 비트는 것도 피해 주세요. / 문틀 페인트가 벗겨지고 걸쇠 자리가 벌어져 결국 잠금이 헐거워집니다.
@ 연희동 가게 유리문 보조 잠금 점검

# 가게 주인인지 확인하는 방법
사업장 문을 여는 일이라 운영하는 분이 맞는지 먼저 확인합니다. / 아래 중 하나를 보여 주시면 됩니다.
- 사업자등록증 사진이나 사본
- 상가 임대차 계약서
- 대표자 신분증과 사업장 주소가 연결되는 서류
- 건물주나 관리인의 확인 전화
직원이 대신 연락하는 경우라면 대표님과 통화가 되도록 해 주세요. / 대표님 확인이 되면 직원분 안내로 작업을 진행할 수 있습니다.

# 위치는 골목 기준으로 알려주세요
연희동은 골목이 굽이져 있고 비슷한 주택이 많아서 번지만으로는 찾기 어렵습니다. / 가게 이름보다 건물 모양과 주변 길을 알려주시는 편이 빠릅니다.
큰길에서 몇 번째 골목인지, 1층인지 계단 위 2층인지 말씀해 주세요. / 차를 댈 수 있는 곳이 있는지도 알려주시면 도착 후 시간이 줄어듭니다.
출입문 사진을 문자로 보내 주시면 잠금장치 종류를 미리 보고 출발합니다.
바깥 번호판과 안쪽이 보이는 유리 너머 몸체를 같이 찍어 주시면 더 좋습니다. / 셔터가 내려져 있다면 셔터 잠금 부분도 한 장 부탁드립니다.

# 영업 시간 전에도, 마감 후에도 갑니다
가게 문 문제는 이른 아침이나 늦은 밤에 몰리는 편입니다. / 시간 신경 쓰지 말고 연락 주세요.
마감 후라면 다음 날 영업에 지장이 없게 그날 밤 정리하는 것을 목표로 합니다. / 부품이 필요해 바로 끝나지 않는 경우에는 임시로 잠글 수 있게 해 두고 다음 일정을 말씀드립니다.
밤에 혼자 가게를 마감하다 문이 잠기지 않는 경우도 연락 주셔도 됩니다. / 문을 열어 둔 채 자리를 비울 수 없으니, 잠금이 되도록 손보는 일도 같은 출장 안에서 해 드립니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 종류와 잠금장치를 보고 어떤 작업이 필요한지, 비용이 어떻게 되는지 먼저 알려드립니다. / 들어 보시고 괜찮다고 하실 때 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 작업 도중 부품 교체가 필요해지면 그때 다시 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 연희동 사업장 문 여는 방식
상가 문도 손상을 줄이는 방법부터 차례로 시도합니다. / 유리문은 특히 깨지거나 기울지 않게 조심스럽게 다룹니다.
도어락 쪽이 원인이면 전원과 걸쇠부터 확인하고, 보조 잠금이 원인이면 그쪽부터 풉니다. / 어떤 순서로 여는지는 [현관문 개문](door-open.html) 페이지에서도 보실 수 있습니다.

# 문이 열린 뒤 직원 번호 정리
문이 열리면 도어락에 등록된 번호와 카드를 같이 정리하는 것이 좋습니다. / 그만둔 직원이 쓰던 번호나 카드가 그대로 남아 있는 사업장이 생각보다 많습니다.
대표 번호 하나와 직원용 번호를 따로 두는 제품이라면 각각 다시 설정해 드립니다. / 카드는 지금 쓰는 것만 남기고 나머지는 지웁니다.
손잡이가 헐겁거나 걸쇠가 닳았다면 [도어락 수리](doorlock-repair.html)로 손보고, 사업장에 맞는 제품으로 바꾸고 싶으시면 [도어락 설치](doorlock-install.html)도 상담해 드립니다.
@ 서대문 연희동 사무실 도어락 번호 정리

# 가게 문 오래 쓰는 작은 습관
- 휴무가 길어지기 전 건전지를 확인하고 나가기
- 비밀번호를 바꾸면 날짜와 함께 운영자끼리 공유하기
- 유리문 바닥 잠금 홈에 쌓인 먼지와 모래를 가끔 털어내기
- 문이 닫힐 때 쾅 소리가 나면 도어클로저 점검하기
비상용 9V 건전지 하나를 차나 가방에 넣어 두시면 번호판이 꺼졌을 때 바로 써 볼 수 있습니다.
