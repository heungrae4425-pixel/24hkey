# 안암동 원룸 문 앞에서 전화 걸기 전 3분
안암동은 고려대역과 안암역 사이로 대학가 원룸 건물과 오래된 주택이 빽빽하게 이어진 동네입니다. / 비슷한 외벽의 건물이 많아서 골목 하나만 잘못 들어가도 찾는 데 시간이 걸립니다.
문이 안 열려 당황스러운 순간에도 전화 걸기 전 3분만 준비하면 도착과 작업이 눈에 띄게 빨라집니다. / 어떤 사진을 찍고, 위치를 어떻게 알리고, 문 상태를 어떻게 말하면 좋은지 차례로 적어 두었습니다.
지금 문 앞에 서 계시다면 사진 세 장과 위치 공유 부분만 먼저 보셔도 충분합니다. / 준비가 덜 됐어도 괜찮으니 일단 [성북구 출장열쇠](seoul-seongbuk.html)로 전화 주셔도 됩니다.
@ 안암동 출장열쇠 부르기 전 준비 목록

# 준비가 왜 도착 시간을 바꾸는지
출장을 나가는 쪽은 도착하기 전까지 문을 직접 볼 수 없습니다. / 도어락 종류를 미리 알면 맞는 공구를 챙기고, 모르면 여러 가지를 다 들고 가야 합니다.
건물 입구를 헤매는 시간도 생각보다 깁니다. / 안암동처럼 원룸이 골목마다 모인 곳은 건물 이름 하나, 입구 사진 하나가 몇 분을 줄여 줍니다.
문 상태를 미리 들으면 현장에서 시도할 방법의 순서도 정해 둘 수 있습니다. / 배터리 쪽이면 전원부터, 보조키가 잠겼다면 그쪽부터 보는 식으로 헛걸음 없이 바로 손을 댈 수 있습니다.

# 사진 한 장, 번호판 정면
가장 먼저 바깥쪽 도어락을 정면에서 한 장 찍어 주세요. / 번호판 불이 들어온 상태라면 손을 대서 켠 다음 찍으면 더 좋습니다.
- 번호 버튼이 보이는지, 덮개를 올리는 형태인지
- 아래쪽에 비상 전원 단자가 있는지
- 제조사 글씨나 로고가 보이는지
글씨가 작아도 괜찮습니다. / 모양만으로도 어떤 방식의 도어락인지 대부분 짐작할 수 있습니다.
복도가 어두우면 플래시를 켜고 찍되 번호판에 빛이 반사되지 않게 비스듬히 비춰 주세요. / 흔들린 사진 여러 장보다 또렷한 한 장이 더 쓸모 있습니다.

# 사진 두 장, 손잡이와 보조키
두 번째 사진은 손잡이 쪽을 조금 떨어져서 찍어 주세요. / 손잡이 일체형인지, 밀고 당기는 형인지, 따로 열쇠 구멍이 있는지가 보이면 됩니다.
도어락 위아래에 열쇠로 여는 보조키가 하나 더 달린 집이 있습니다. / 보조키를 잠갔는지 아닌지 기억나지 않으면 그 사실도 메모해 두세요.

# 사진 세 장, 건물 입구와 호수 표시
마지막으로 건물 공동현관이나 대문을 한 장 찍어 주세요. / 건물 이름이 적힌 간판, 공동현관 번호판, 우편함 쪽 호수 표시가 같이 나오면 가장 좋습니다.
반지하나 옥탑처럼 입구가 따로 있는 집은 그 입구를 따로 찍어 주세요. / 겉에서 보이지 않는 계단이 있으면 어느 쪽으로 돌아가는지도 한 줄 적어 주시면 됩니다.
@ 안암동 원룸 건물 입구 사진 위치 안내

# 소리와 불빛은 메모로
사진으로 안 담기는 것은 짧게 적어 두세요. / 전화로 여쭤볼 때 이 메모를 읽어 주시면 됩니다.
- 번호판이 아예 안 켜짐, 켜지지만 반응 없음, 켜지고 경고음
- 번호를 누르면 모터 도는 소리가 나는지
- 문이 한 뼘 열리다 걸쇠에 걸렸는지
- 마지막으로 정상 작동한 때가 언제인지
경고음을 휴대폰으로 녹음해 두셔도 좋습니다. / 소리 하나로 배터리 문제인지 모터 문제인지 가려지는 경우가 있습니다.
집 안에 켜 둔 전열기나 가스레인지, 혼자 남은 반려동물이 있다면 그것도 메모 첫 줄에 적어 주세요. / 급한 사정이 있으면 출동 순서를 앞당겨 정합니다.

# 위치는 지도 앱 공유가 가장 빠릅니다
주소를 말로 불러 주시는 것보다 지도 앱의 위치 공유를 문자로 보내 주시는 쪽이 정확합니다. / 휴대폰이 집 안에 있다면 같이 있는 분 휴대폰으로 보내 주셔도 됩니다.
위치 공유가 어려우면 고려대역, 안암역 중 어디에서 몇 분쯤 걸어오는지 알려주세요. / 근처에 큰 건물이나 학교 정문이 보이면 그것도 도움이 됩니다.

# 공동현관 비밀번호와 관리인 연락처
원룸 건물은 공동현관부터 막힐 때가 많습니다. / 공동현관 번호를 알면 미리 알려주시고, 모르면 건물주나 관리인 연락처를 찾아 두세요.
공동현관 자체를 여는 일은 건물 관리 쪽과 함께 정하는 게 원칙입니다. / 관리인과 통화가 되면 대부분 금방 해결됩니다.
학기 초나 방학처럼 이사가 잦은 때에는 공동현관 번호가 바뀌었는데 공지를 못 본 경우도 있습니다. / 건물 단체 대화방이나 우편함 옆 안내문에 새 번호가 적혀 있지 않은지 한 번 살펴보세요.

# 거주 확인 서류, 집 안에 있다면
문을 열기 전에는 사시는 분이 맞는지 꼭 확인합니다. / 신분증 주소, 주소가 찍힌 우편물이나 택배 상자, 임대차 계약서 사진 중 하나면 됩니다.
신분증 주소가 본가로 돼 있는 학생도 많습니다. / 그럴 때는 휴대폰에 저장된 계약서 사진이나 건물주 통화로 확인할 수 있으니 미리 찾아 두세요.

# 전화로 여쭤보는 순서
전화를 주시면 대략 이 순서로 여쭤봅니다. / 미리 알고 계시면 통화가 짧아집니다.
지금 계신 위치, 문이 잠긴 상태, 도어락 모양, 집 안에 사람이나 동물이 있는지, 거주 확인 방법입니다. / 그다음 도착 예상 시간을 말씀드립니다.
통화 중에 사진을 보낼 번호도 함께 알려드립니다. / 문자가 어려우시면 통화로만 설명하셔도 충분합니다.

# 기다리는 동안 해 둘 일
기다리는 동안 번호를 계속 눌러 보시면 도어락이 입력을 잠가 버릴 수 있습니다. / 두세 번 해 보고 안 되면 그대로 두는 편이 낫습니다.
늦은 시간이라면 밝은 곳이나 건물 1층 안쪽에서 기다리셔도 됩니다. / 도착 직전에 전화를 드리니 휴대폰 소리만 켜 두세요.
휴대폰 배터리가 얼마 안 남았다면 통화를 짧게 하고 화면 밝기를 낮춰 두세요. / 근처 편의점에서 충전을 부탁해 두는 것도 방법입니다.
룸메이트나 가족이 열쇠를 갖고 있을 수도 있으니 그사이 연락을 돌려 보셔도 됩니다. / 먼저 열리면 전화 한 통만 주시면 출동을 멈춥니다.

# 비용과 진행 방식
도착하면 문과 도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그냥 돌아갑니다.
여는 방법은 덜 상하는 쪽부터 시도하고, 끝내 못 열면 비용은 받지 않습니다. / 문 여는 방식은 [현관문 개문](door-open.html), 전체 순서는 [이용안내](guide.html)에 정리해 두었습니다.
열쇠를 잃어버린 경우라면 [열쇠 출장](key-call.html) 안내도 함께 보시면 좋습니다.
@ 성북구 안암동 출장열쇠 비용 먼저 안내

# 안암동과 이웃 동네
안암동 옆 보문동, 종암동, 돈암동을 비롯해 길음동, 정릉동, 성북동, 월곡동, 장위동, 석관동까지 성북구 전 지역을 다닙니다. / 서울 다른 구와 경기는 [출장 지역](area.html)에서 보실 수 있습니다.
