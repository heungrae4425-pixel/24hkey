# 보문동, 지난여름 현관문이 무거웠던 기억
보문역 근처 골목에는 다세대와 아파트가 섞여 있어 현관문 종류도 집마다 제각각입니다. / 지난여름 한낮에 문이 꽉 끼어서 어깨로 밀어야 열렸던 집이라면 이 글이 도움이 될 겁니다.
날이 선선해지면 문이 다시 부드러워져서 대부분 잊어버립니다. / 그런데 원인이 그대로 남아 있으면 내년 장마와 더위에 같은 일이 되풀이되고, 해마다 조금씩 더 심해집니다.
그래서 이번 글은 여름에 문이 뻑뻑해지는 이유를 하나씩 가려 보고, 지금처럼 바람이 서늘할 때 미리 손봐 둘 것을 정리했습니다. / 한여름 문 앞에서 급하게 열어야 할 때 쓰는 요령도 중간에 넣었습니다.
@ 보문동 여름 현관문 뻑뻑함 점검

# 더위가 문에 하는 일 네 가지
여름 열기와 습기는 문의 여러 부분에 동시에 영향을 줍니다. / 우리 집은 어느 쪽이었는지 떠올려 보세요.
- 햇볕을 받은 철문이 조금 늘어나 문틀과 닿는 면이 빡빡해진다
- 문 둘레 고무 패킹이 부풀어 닫을 때 밀어내는 힘이 커진다
- 나무 문이나 나무 문틀이 습기를 먹어 부피가 늘어난다
- 도어락 걸쇠가 받침쇠에 눌려 손잡이가 무겁게 돈다
하나만 원인일 때보다 두세 가지가 겹친 집이 많습니다. / 그래서 한 곳만 손보고 끝내면 다음 여름에 또 비슷한 증상이 나옵니다.

# 철문은 늘어나고 문틀은 그대로
철은 열을 받으면 아주 조금 늘어납니다. / 눈으로 보이지 않을 정도지만 원래 틈이 좁게 맞춰진 문이라면 그 차이만으로도 문틀에 닿기 시작합니다.
특히 오후 햇볕이 현관문에 바로 드는 집, 복도식으로 바깥에 문이 그대로 드러난 집이 그렇습니다. / 이런 집은 저녁이 되면 다시 괜찮아지는 경우가 많습니다.
문틀 위쪽이나 손잡이 반대편 모서리에 페인트가 벗겨진 자국이 있다면 그곳이 닿는 자리입니다. / 사진을 찍어 두시면 점검할 때 바로 짚어 볼 수 있습니다.

# 나무 문과 방화문은 다르게 반응
오래된 다세대 중에는 나무 현관문을 쓰는 집도 있습니다. / 나무는 열보다 습기에 더 크게 반응해서 장마철에 아래쪽이 바닥에 끌리기도 합니다.
방화문은 안이 채워진 무거운 문이라 경첩이 받는 힘이 큽니다. / 여름에 뻑뻑했던 문이 사실은 경첩이 처져서 생긴 문제인 경우도 있으니 둘을 함께 봐야 합니다.

# 걸쇠가 받침쇠에 눌릴 때 나는 느낌
문틀 쪽 받침쇠와 도어락 걸쇠가 꽉 맞물리면 손잡이를 돌릴 때 끝에서 버티는 느낌이 납니다. / 버튼식 도어락이라면 모터가 평소보다 오래 윙 하고 돌다가 겨우 열립니다.
이 상태가 계속되면 걸쇠 끝이 닳고 모터에도 무리가 가며, 건전지도 평소보다 빨리 닳습니다. / 여름에 유독 모터 소리가 길었다면 받침쇠 위치를 조금 옮겨 주는 것만으로 나아지기도 합니다.

# 한낮에만 그랬다면, 저녁에도 그랬다면
원인을 가르는 가장 쉬운 방법은 시간입니다. / 한낮에만 뻑뻑하고 해가 지면 괜찮았다면 열기 쪽, 비 오는 날 내내 그랬다면 습기 쪽일 가능성이 큽니다.
계절과 상관없이 늘 조금씩 걸렸는데 여름에 더 심했다면 문 처짐이나 경첩 쪽이 바탕에 깔려 있는 경우입니다. / 이 경우는 선선한 지금도 살짝 걸리는 느낌이 남아 있을 겁니다.
기억이 흐릿하다면 지금 문을 천천히 닫아 보며 걸리는 곳이 있는지 손으로 느껴 보세요. / 아무 데도 닿지 않고 잠금 소리가 한 번에 난다면 열기 쪽이었을 가능성이 더 큽니다.
@ 보문동 현관 걸쇠 받침쇠 마찰 확인

# 문 앞에서 당장 열어야 할 때
한여름에 문이 안 열려 급할 때는 손잡이를 돌리면서 문을 경첩 쪽으로 살짝 밀어 보세요. / 걸쇠가 받침쇠에서 조금 떨어지면서 풀리는 경우가 있습니다.
버튼식이라면 번호를 누른 뒤 문을 안쪽으로 가볍게 밀며 기다려 보세요. / 밖에서 당기는 방향이라면 아주 살짝만 당겨 걸쇠에 걸린 힘을 덜어 줍니다.
손에 힘을 주기보다 방향을 바꿔 가며 살살 해 보는 것이 요령입니다. / 두세 번 해서 안 되면 멈추는 게 좋습니다. / 그 뒤는 [현관문 개문](door-open.html) 방식으로 문을 상하지 않게 엽니다.

# 해서는 안 되는 힘쓰기
급한 마음에 문을 발로 차거나 몸으로 들이받으면 경첩이 더 처집니다. / 문틀 틈에 드라이버를 넣어 벌리면 문틀 마감이 찌그러져 다음부터 더 잘 걸립니다.
걸쇠에 기름이나 스프레이를 뿌리는 것도 피해 주세요. / 도어락 안쪽으로 흘러들면 여름 습기와 섞여 오히려 고장을 부릅니다.

# 선선한 지금 손봐 두면 좋은 이유
문이 부드러운 계절에는 원래 맞물림 상태를 정확히 볼 수 있습니다. / 한여름에 손보면 그날 상태에 맞추게 되어 겨울에 오히려 헐거워지기도 합니다.
작업 소음도 창문을 닫고 지내는 계절이 이웃에게 덜 부담스럽습니다. / 내년 여름 전에 한 번 점검해 두면 급하게 문 앞에서 씨름할 일이 줄어듭니다.
겨울을 앞두고 있다는 점도 이유가 됩니다. / 추위가 오면 이번에는 문이 줄어들고 패킹이 굳어서, 여름에 맞춰 둔 틈이 반대로 헐거워지는 집이 있기 때문입니다.

# 점검 때 보는 곳
선선할 때 점검을 부르시면 아래 순서로 봅니다.
- 문과 문틀 사이 틈이 위아래로 고른지
- 경첩 나사가 단단한지, 문이 처지지 않았는지
- 패킹이 딱딱하게 굳거나 한쪽만 두툼하게 부풀었는지
- 걸쇠와 받침쇠가 가운데로 맞물리는지
- 도어락 모터가 열고 닫을 때 무리 없이 도는지
도어락 자체가 지쳐 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 너무 오래돼 부품을 구하기 어려우면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 연락 주실 때 알려 주실 것
보문동 어느 쪽인지, 건물 이름과 호수, 문이 철문인지 나무 문인지 알려주세요. / 지난여름 언제 가장 심했는지, 지금도 걸리는 느낌이 남아 있는지도 함께 말씀해 주시면 좋습니다.
문이 잠겨 열어야 하는 상황이라면 사시는 분인지 먼저 확인합니다. / 신분증, 주소가 나온 우편물, 관리실이나 집주인 확인 중 하나를 준비해 주세요.

# 비용과 범위
문 상태를 보고 조정으로 끝날지, 부품을 바꿔야 할지 먼저 말씀드립니다. / 비용도 작업 전에 알려드리고 동의하실 때만 시작합니다.
손볼 곳이 없으면 그대로 쓰셔도 된다고 말씀드립니다. / 문을 열러 갔는데 끝내 못 열면 비용은 받지 않습니다. 진행 순서는 [이용안내](guide.html)에 있습니다.
