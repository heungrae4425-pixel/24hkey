# 장위동 전월세 집에서 도어락이 말썽일 때
장위동은 재개발로 들어선 새 아파트와 오래된 다세대 골목이 함께 있는 동네라 전세, 월세로 사는 집이 많습니다. / 그만큼 도어락이 고장 났을 때 누가 연락하고 누가 정할지 애매해지는 일도 자주 생깁니다.
세입자는 당장 문이 안 열려 급하고, 집주인은 멀리 살아 상황을 바로 보기 어렵습니다. / 서로 좋은 뜻이어도 기록이 없으면 나중에 이야기가 엇갈리기 쉽습니다.
이 글은 도어락 문제가 생겼을 때 양쪽이 같이 보면 좋은 정리 순서를 적은 것입니다. / 비용을 누가 부담하는지 같은 판단은 계약 내용과 두 분의 합의에 달린 일이라 여기서 정하지 않습니다.
@ 장위동 전월세 도어락 고장 기록

# 먼저 누구 물건인지부터
이야기를 시작하기 전에 지금 달린 도어락이 언제, 누가 단 것인지 확인해 두면 편합니다. / 입주할 때 이미 달려 있던 것인지, 세입자가 살면서 직접 바꾼 것인지에 따라 대화의 출발점이 달라집니다.
- 입주 당시 사진이나 체크 목록에 도어락이 나와 있는지
- 계약서 특약에 도어락, 열쇠, 시설 수리 이야기가 있는지
- 살면서 바꿨다면 그때 받은 영수증이나 문자가 남아 있는지
기억만으로는 서로 다르게 떠올리는 경우가 많습니다. / 남아 있는 자료를 먼저 꺼내 놓으면 대화가 짧아집니다.
중개사무소를 통해 계약했다면 그쪽에 입주 당시 자료가 남아 있는지 물어보는 것도 방법입니다. / 사진 한 장이 오래된 기억보다 정확할 때가 많습니다.

# 고장 난 날 바로 남겨 둘 기록
문제가 생긴 날 아래 몇 가지만 남겨 두세요. / 휴대폰 메모와 사진 몇 장이면 충분합니다.
- 날짜와 시간, 어떤 상황이었는지 한두 줄
- 번호판, 손잡이, 문틀 쪽 사진
- 경고음이나 모터 소리가 났다면 짧은 영상
- 직접 해 본 것 (건전지 교체, 비상 전원 등)
특히 건전지를 바꿨는지는 꼭 적어 두세요. / 건전지 문제였는지 부품 고장이었는지가 이후 이야기에서 자주 나오는 부분입니다.

# 집주인에게 연락할 때 담을 내용
문자나 메신저로 연락하면 내용이 남아서 좋습니다. / 전화로 이야기했다면 끝나고 짧게 문자로 정리해 보내 두세요.
언제부터 어떤 증상인지, 지금 문을 쓸 수 있는지, 직접 해 본 것은 무엇인지를 담으면 됩니다. / 사진을 같이 보내면 멀리 있는 집주인도 상황을 금방 이해합니다.
집주인 쪽에서는 수리 업체를 직접 정할지, 세입자가 부르도록 할지 답을 주시면 일이 빨라집니다. / 답이 늦어지면 세입자는 더 기다려야 하니 가능한 한 빨리 방향을 정해 주시는 게 좋습니다.

# 급하게 문부터 열어야 하는 날
한밤중이나 출근 직전처럼 기다릴 수 없는 때도 있습니다. / 이럴 때는 문을 여는 일과 도어락을 고치거나 바꾸는 일을 나눠 생각하시면 정리가 쉽습니다.
문만 먼저 열고, 수리나 교체는 집주인과 이야기한 뒤 정하는 방법이 있습니다. / 저희도 문을 열 때는 도어락을 덜 상하게 여는 쪽부터 시도해 그 뒤 선택지를 넓게 남겨 둡니다.
문을 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 수리와 교체, 견적을 나눠 받는 이유
현장에서 상태를 보고 고쳐 쓸 수 있는지, 바꾸는 게 나은지 따로 말씀드립니다. / 수리로 끝나는 경우와 교체가 필요한 경우를 나눠 들으면 집주인에게 전달하기도 편합니다.
고칠 수 있으면 교체는 권하지 않습니다. / 수리 쪽은 [도어락 수리](doorlock-repair.html), 교체 쪽은 [도어락 교체](doorlock-replace.html)에서 진행 방식을 미리 보실 수 있습니다.
집주인이 현장에 없을 때는 통화를 연결해 직접 설명드릴 수도 있습니다. / 원하시면 말씀해 주세요.
@ 장위동 도어락 수리 교체 견적 설명

# 작업 확인서와 영수증 챙기기
작업이 끝나면 무엇을 했는지 확인할 수 있는 내용을 받아 두세요. / 어떤 증상이었고 어떤 부품을 손봤는지, 교체했다면 어떤 제품을 달았는지가 들어가면 됩니다.
작업 전후 사진도 함께 남겨 두시면 좋습니다. / 집주인에게 전달할 때 말보다 사진이 훨씬 정확합니다.
떼어 낸 부품을 보관해 달라는 집주인도 있습니다. / 필요하면 작업 전에 말씀해 주시면 버리지 않고 봉투에 담아 드립니다.

# 비밀번호와 카드키 정리
도어락을 손보거나 바꾸면 비밀번호와 카드키를 새로 등록하게 됩니다. / 이때 예전 번호와 예전 카드를 모두 지웠는지 꼭 확인하세요.
집주인이 비상용으로 번호나 카드를 갖고 있어야 하는지는 두 분이 정할 일입니다. / 정했다면 문자로 남겨 두시면 나중에 오해가 줄어듭니다.

# 퇴거할 때 도어락 원상태 이야기
살면서 도어락을 바꾼 경우 이사 나갈 때 그대로 두고 갈지, 예전 것으로 되돌릴지 이야기가 나오곤 합니다. / 이 부분도 계약 내용과 두 분의 합의에 따르는 일입니다.
미리 정해 두지 않았다면 바꿀 때 한 번 물어 두시는 게 좋습니다. / 예전 도어락을 버리지 않고 보관해 두는 분들도 있습니다.
이사 나가는 날에는 등록해 둔 지문과 카드, 개인 비밀번호를 지우고 초기 상태를 집주인과 함께 확인하시면 깔끔합니다. / 다음 세입자가 들어오기 전에 번호를 바꾸는 일은 집주인 쪽에서 챙기시면 됩니다.

# 저희가 판단하지 않는 부분
저희는 문을 열고 도어락을 점검하고 고치는 일을 합니다. / 누구 책임인지, 비용을 누가 내야 하는지는 정해 드릴 수 없습니다.
의견이 크게 엇갈린다면 주택 임대차 관련 공공 상담 창구에 문의해 보시는 것도 방법입니다. / 그때 위에서 남겨 둔 기록과 작업 확인 내용이 도움이 됩니다.

# 현장 확인 절차
문을 열어야 하는 경우 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 임대차 계약서 사진, 집주인 통화 중 하나면 됩니다.
집주인이 직접 부르셨는데 세입자가 안에 없는 상황이라면 세입자 동의 여부를 먼저 여쭤봅니다. / 사는 사람의 확인 없이 문을 여는 일은 하지 않습니다.
번거롭게 느껴지실 수 있지만 세입자와 집주인 모두를 지키는 절차입니다. / 확인 방법이 마땅치 않으면 전화로 미리 상의해 주세요.

# 비용 안내 방식
도어락과 문 상태를 본 뒤 작업 전에 비용을 먼저 말씀드립니다. / 세입자와 집주인이 상의할 시간이 필요하면 기다렸다가 정해 주시는 대로 진행합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 전체 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.
@ 성북구 출장열쇠 장위동 비용 먼저 안내

# 장위동 주변 성북구
장위동과 이어진 석관동, 월곡동과 종암동, 길음동, 돈암동, 정릉동, 안암동, 보문동, 성북동까지 [성북구 출장열쇠](seoul-seongbuk.html)가 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 비용은 누가 내는 건가요? | 계약 내용과 두 분의 합의에 따르는 부분이라 저희가 정하지 않습니다.

? 집주인이 원격으로 통화만 해도 되나요? | 됩니다. 현장에서 연결해 상태를 직접 설명드립니다.
? 문을 못 열어도 비용이 나오나요? | 못 열면 받지 않습니다.
