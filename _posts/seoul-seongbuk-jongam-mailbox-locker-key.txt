# 종암동 우편함 앞에서 열쇠가 없을 때
종암동은 고려대역과 월곡역 사이 생활권으로, 아파트와 원룸, 다세대 건물이 함께 있는 동네입니다. / 현관 도어락은 번호로 여는데, 우편함만은 작은 열쇠로 여는 집이 아직 많습니다.
그 작은 열쇠는 자주 안 쓰다 보니 어디 뒀는지 잊기 쉽습니다. / 고지서나 등기 안내문이 우편함 안에 쌓여 있는데 꺼낼 수가 없으면 은근히 신경이 쓰입니다.
이 글은 우편함과 건물 사물함, 보관함 열쇠 문제를 만났을 때 누구에게 먼저 물어볼지, 무엇을 확인할지 적었습니다. / 직접 해결이 안 되면 [성북구 출장열쇠](seoul-seongbuk.html)도 우편함 자물쇠를 봅니다.
@ 종암동 아파트 원룸 우편함 자물쇠

# 우편함은 누구 것인지부터
우편함은 집 안에 있는 물건이 아니라 건물 공용 공간에 붙은 설비입니다. / 그래서 자물쇠를 바꾸거나 열기 전에 관리 주체를 먼저 확인하는 게 순서입니다.
아파트라면 관리사무소, 원룸이나 다세대라면 집주인이나 건물 관리인이 우편함을 관리하는 경우가 많습니다. / 여분 열쇠를 보관하고 있는 곳도 대개 그쪽입니다.
먼저 여쭤봤는데 여분이 없다고 하면 그때 자물쇠를 열거나 바꾸는 방법을 찾으시면 됩니다. / 이 순서를 지키면 나중에 이웃과 오해가 생기지 않습니다.

# 우편함 자물쇠 종류 알아보기
우편함 자물쇠는 크게 세 가지가 흔합니다. / 어떤 종류인지에 따라 해결 방법이 다릅니다.
- 작은 열쇠를 꽂아 반 바퀴 돌리는 원통형 자물쇠
- 숫자 다이얼을 맞추는 번호 자물쇠
- 우편함 고리에 거는 작은 맹꽁이 자물쇠
원통형은 같은 크기 자물쇠로 바꾸기 쉽고, 번호 자물쇠는 번호만 다시 맞추면 되는 경우가 많습니다. / 맹꽁이 자물쇠는 고리 쪽을 상하지 않게 푸는 게 중요합니다.

# 번호 자물쇠 번호를 잊었다면
다이얼 번호 자물쇠는 이사 올 때 받은 번호를 그대로 쓰는 집이 많습니다. / 입주 서류나 계약서 사이에 번호가 적힌 종이가 있는지 먼저 찾아보세요.
전에 살던 분이 번호를 바꿔 놓고 알려주지 않은 경우도 있습니다. / 이럴 때는 관리사무소나 집주인에게 초기화 방법을 아는지 물어보세요.
번호를 하나씩 다 돌려 보는 건 시간도 오래 걸리고 다이얼이 헐거워질 수 있어 권하지 않습니다.
@ 종암동 우편함 번호 자물쇠 초기화

# 열쇠가 꽂히는데 안 돌아갈 때
우편함은 건물 입구나 계단 아래처럼 바깥 공기에 닿는 곳에 있는 경우가 많습니다. / 비 오는 날 습기나 먼지가 들어가 원통 안이 굳으면 맞는 열쇠도 잘 안 돌아갑니다.
이럴 때 힘을 주어 비틀면 작은 열쇠는 쉽게 휘거나 부러집니다. / 반 바퀴 정도만 살살 좌우로 움직여 보시고, 안 되면 그대로 두세요.
열쇠가 부러져 구멍 안에 남았다면 더 건드리지 말고 연락 주세요. / 조각을 빼내고 자물쇠를 새것으로 바꾸면 됩니다.

# 건물 사물함과 무인 보관함
요즘 아파트에는 택배를 넣어 두는 무인 보관함, 원룸 건물에는 자전거나 짐을 넣는 사물함이 있는 경우가 있습니다. / 이런 설비는 대부분 관리사무소나 설치 업체가 비밀번호와 열쇠를 관리합니다.
보관함이 안 열리면 화면에 나오는 안내 번호나 관리사무소에 먼저 연락하는 게 가장 빠릅니다. / 전자식 보관함을 밖에서 억지로 열면 다른 칸까지 고장 날 수 있습니다.
저희가 볼 수 있는 것은 열쇠식 사물함이나 개인이 단 자물쇠입니다. / 공용 전자 보관함은 관리 쪽 확인이 먼저입니다.

# 급한 우편물이 안에 있다면
우편함 안에 등기 도착 안내문이나 꼭 내야 할 고지서가 들어 있으면 마음이 더 급해집니다. / 이럴 때는 우편함을 여는 일과 우편물을 받는 일을 나눠서 생각해 보세요.
등기 안내문은 우체국에 전화해 재배달이나 방문 수령을 부탁할 수 있는 경우가 많습니다. / 고지서는 대부분 앱이나 홈페이지에서도 확인할 수 있습니다.
급한 불을 끈 뒤에 우편함은 여분 열쇠를 찾거나 자물쇠를 바꾸는 쪽으로 차분히 해결하시면 됩니다. / 무리하게 문을 젖히다 우편함이 망가지면 오히려 우편물을 더 못 받게 됩니다.

# 해보지 않는 게 좋은 방법
- 일자 드라이버로 우편함 문을 젖혀 열기
- 우편함 틈으로 철사를 넣어 우편물 꺼내기
- 망치로 자물쇠 원통 두드리기
- 남의 우편함 열쇠로 맞는지 돌려 보기
우편함 문은 얇은 철판이라 한 번 휘면 잘 안 닫히고, 그러면 우편물이 밖으로 보입니다. / 개인 정보가 적힌 우편물이 많으니 문이 제대로 닫히는 게 무엇보다 중요합니다.

# 출장 부르실 때 알려주실 것
우편함 작업도 출장이라 위치와 상황을 미리 알려주시면 좋습니다.
- 아파트 단지 이름과 동, 우편함 위치, 또는 원룸 건물 이름
- 자물쇠 종류 (원통형, 번호식, 맹꽁이)
- 열쇠가 아예 없는지, 있는데 안 돌아가는지, 부러졌는지
- 관리사무소나 집주인에게 이미 확인했는지
자물쇠를 가까이서 찍은 사진을 보내 주시면 맞는 크기의 새 자물쇠를 챙겨 갑니다. / 현관 도어락도 같이 보고 싶으시면 함께 말씀해 주세요.

# 확인 절차와 비용 안내
우편함도 개인 우편물이 들어 있는 곳이라 사시는 분인지 확인합니다. / 신분증 주소나 우편함 호수와 같은 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
자물쇠를 열기만 할지, 새것으로 바꿀지에 따라 작업이 다르니 시작 전에 비용을 먼저 말씀드립니다. / 못 열면 비용은 받지 않습니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
@ 종암동 우편함 자물쇠 교체 작업

# 바꾼 뒤 관리하는 요령
새 자물쇠로 바꿨다면 열쇠를 두 개 이상 받아 하나는 현관 근처 서랍에 두세요. / 우편함 열쇠는 작고 가벼워 현관 열쇠고리에 함께 달아 두면 잃어버릴 일이 줄어듭니다.
이사 나갈 때는 우편함 열쇠도 꼭 다음 분이나 집주인에게 넘겨 주세요. / 번호 자물쇠라면 번호를 적어 함께 전달하면 됩니다.
비 오는 날이 잦은 계절에는 우편함 자물쇠 구멍 주변을 마른 천으로 한 번씩 닦아 주세요. / 먼지와 물기가 덜 쌓여 열쇠가 굳는 일을 줄일 수 있습니다.

# 현관 열쇠와 같이 점검하면 좋은 것
우편함 열쇠를 잃어버렸다면 같은 꾸러미에 있던 현관 보조키 열쇠도 같이 없어졌는지 보세요. / 보조키 열쇠까지 잃었다면 실린더를 바꾸는 것을 함께 생각해 보시는 게 좋습니다.
현관 도어락 번호도 이참에 바꾸고 싶으시면 출장 때 함께 해 드립니다. / 현관이 잠긴 상황이면 [현관문 개문](door-open.html), 도어락 손질은 [도어락 수리](doorlock-repair.html)를 참고해 주세요.
보조키 대신 번호식으로 바꾸고 싶다면 [도어락 설치](doorlock-install.html)에서 확인할 것을 보실 수 있습니다.
