# 석관동에서 문이 꿈쩍 안 할 때
석관동은 성북구 동쪽 끝자락에서 아파트와 다세대 주택이 이어진 동네로, 월곡역 쪽 생활권과도 가깝습니다. / 집마다 도어락 종류가 달라 같은 "문이 안 열려요"라도 원인은 제각각입니다.
문 앞에서 무엇부터 봐야 할지 모르면 이것저것 눌러 보다가 시간이 갑니다. / 이 글은 원인을 다섯 갈래로 나누고, 갈래마다 확인할 것을 순서대로 적었습니다.
위에서부터 하나씩 따라오시다 막히는 곳이 원인입니다. / 그 지점에서 [성북구 출장열쇠](seoul-seongbuk.html)로 전화 주시면 설명이 짧아집니다.
@ 석관동 현관문 안 열림 원인 체크

# 첫째 갈래, 번호판에 불이 들어오나
번호판을 손바닥으로 덮거나 아무 숫자나 눌러 보세요. / 불이 전혀 안 들어오면 전원 문제, 들어오면 다음 갈래로 넘어갑니다.
불이 안 들어온다면 거의 대부분 건전지 방전입니다. / 바깥 아래쪽에 9V 건전지 단자가 있으면 건전지를 댄 채 번호를 눌러 보세요.
단자가 없거나 대도 반응이 없으면 여기서 멈추고 연락 주시면 됩니다. / 이 경우 원인은 거의 정해져 있어 작업도 길지 않습니다.

# 둘째 갈래, 번호는 받아들이나
불은 켜지는데 번호를 누르면 삐삐 하고 거부한다면 번호가 틀린 것입니다. / 가족이 최근에 번호를 바꾸지 않았는지 먼저 연락해 보세요.
숫자 하나가 눌러도 반응이 없거나 늦게 눌린다면 번호판 쪽 고장일 수 있습니다. / 이럴 땐 맞는 번호를 눌러도 계속 틀렸다고 나옵니다.
서너 번 틀리면 입력이 한동안 막히니 그 전에 멈추세요. / 막힌 상태에서 계속 누르면 막히는 시간만 길어집니다.

# 셋째 갈래, 열림 소리는 나나
번호가 맞아서 띠리릭 소리가 나는데 손잡이가 안 움직인다면 걸쇠가 못 빠진 것입니다. / 이때는 문을 안쪽으로 살짝 밀면서 다시 번호를 눌러 보세요.
그래도 안 되면 문을 내 쪽으로 당기면서도 한 번 해보세요. / 어느 한쪽에서 열린다면 문이 처졌거나 쏠려서 걸쇠가 눌린 것입니다.
양쪽 다 안 되고 모터 소리만 길게 난다면 도어락 안쪽 부품 쪽입니다. / 이 경우 손으로 해볼 것은 더 없습니다.
@ 석관동 도어락 걸쇠 눌림 확인

# 넷째 갈래, 안쪽에서 무언가 잠겼나
도어락은 분명 풀렸는데 문이 살짝만 움직이고 멈춘다면 안쪽 보조키나 걸쇠가 걸린 것입니다. / 집 안에 가족이 있다면 안쪽 걸쇠를 풀어 달라고 하시면 됩니다.
아무도 없는데 안쪽이 잠겼다면 나올 때 보조키가 저절로 걸렸거나 아이가 걸어 둔 경우입니다. / 밖에서 해볼 것은 없으니 그대로 연락 주세요.
문틈으로 안쪽 걸쇠를 풀어 보려고 철사나 옷걸이를 넣는 것은 피해 주세요. / 문틀 고무가 찢어지고 걸쇠가 더 꽉 물리기도 합니다.

# 다섯째 갈래, 문 자체가 버티나
모든 게 정상인데 문이 무겁게 버틴다면 문틀이나 경첩 문제입니다. / 오래 쓴 다세대 현관문이나 철문에서 자주 보입니다.
문 아래쪽이 바닥에 긁힌 자국, 문 위쪽 틈이 한쪽만 넓은 모습이 보이면 처짐을 의심해 보세요. / 한여름이나 비 온 다음 날 유난히 심하면 열기와 습기 영향도 겹친 것입니다.
이 경우 문을 위로 살짝 들어 올리듯 잡고 번호를 눌러 보면 열리기도 합니다.
다만 한 번 열렸다고 끝난 게 아닙니다. / 문이 버티는 원인이 그대로라 며칠 안에 같은 일이 생기기 쉬우니, 열린 김에 경첩과 받침쇠를 손보시길 권합니다.

# 갈래를 건너뛰면 생기는 일
번호판이 꺼진 줄 모르고 문을 당기기만 하거나, 걸쇠 문제인데 건전지만 계속 바꾸는 경우가 있습니다. / 원인을 잘못 짚으면 시간도 들고 문도 상합니다.
위 순서대로 보시면 대부분 2~3분 안에 어느 갈래인지 알 수 있습니다. / 어디서 막혔는지만 알려주셔도 저희는 필요한 장비를 정확히 챙겨 갑니다.

# 열쇠집보다 먼저 연락해 볼 곳
갈래를 짚어 본 뒤에도 바로 전화하기 망설여진다면 가족에게 먼저 연락해 보세요. / 집 안에 누가 있거나, 비밀번호를 바꾼 사람이 있거나, 비상 카드를 가진 사람이 가까이 있을 수 있습니다.
아파트라면 관리사무소나 경비실에 상황을 알려 두는 것도 좋습니다. / 문을 열 때 세대 확인을 바로 해 줄 수 있어 기다리는 시간이 줄어듭니다.
다세대라면 집주인이나 건물 관리인에게 비상 열쇠가 있는지 물어보세요. / 보조키 열쇠를 집주인이 하나 갖고 있는 경우가 생각보다 많습니다.
이렇게 해도 해결이 안 되면 그때 저희에게 연락 주시면 됩니다. / 이미 확인한 내용을 말씀해 주시면 같은 질문을 되풀이하지 않습니다.

# 문 앞에서 피하셨으면 하는 행동
- 손잡이를 잡고 온몸으로 당기기
- 문을 발로 차거나 어깨로 밀기
- 드라이버를 문틈에 끼워 벌리기
- 열쇠 구멍에 아무 열쇠나 꽂아 돌리기
이런 행동은 열 수 있던 문을 못 열게 만들기도 합니다. / 특히 걸쇠가 문틀에 박혀 휘면 여는 데 시간이 훨씬 더 걸립니다.

# 석관동에서 전화하실 때
어느 갈래에서 막혔는지와 함께 아래를 알려주세요.
- 아파트라면 단지 이름과 동, 호수, 다세대라면 건물 이름과 층
- 큰길에서 들어오는 방향, 가까운 역
- 집 안에 사람이나 반려동물이 있는지
- 도어락 모양과 보조키가 따로 있는지
도어락 앞면을 찍어 보내 주시면 같은 제품의 여는 방식을 미리 확인합니다. / 늦은 밤이나 새벽에도 전화를 받습니다.

# 도착 후 신분 확인과 비용
문을 열기 전에 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 집주인 확인 중 하나면 됩니다.
원인을 보고 작업 방법과 비용을 먼저 말씀드리고, 동의하시면 시작합니다. / 끝내 못 열면 비용은 받지 않습니다.
여는 방식은 [현관문 개문](door-open.html), 전체 진행은 [이용안내](guide.html)에 정리해 두었습니다.
@ 석관동 출장열쇠 신분 확인 후 개문

# 원인별로 열고 난 뒤 하는 일
건전지 문제였다면 안쪽 건전지를 전부 바꾸고 경고음이 사라졌는지 확인합니다. / 번호 문제였다면 새 번호를 등록하고 옛 번호는 지웁니다.
보조키가 저절로 걸렸던 집은 걸림 방식을 바꾸거나 손잡이 위치를 조정해서 나갈 때 다시 걸리지 않게 합니다. / 어떻게 바꿨는지는 사시는 분이 직접 해보시며 확인하실 수 있게 보여 드립니다.
걸쇠가 눌렸던 문은 받침쇠 위치와 경첩을 손봐 다시 눌리지 않게 맞춥니다. / 도어락 부품이 상했다면 [도어락 수리](doorlock-repair.html)로 고치고, 고칠 수 없을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 석관동 근처 성북구 다른 동네
석관동 옆 장위동, 월곡동, 종암동부터 길음동, 돈암동, 정릉동, 안암동, 보문동, 성북동까지 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 안 열리는 문, 자주 묻는 것
? 번호판은 켜지는데 왜 안 열리나요? | 걸쇠가 문틀에 눌렸거나 안쪽 보조키가 걸린 경우가 많습니다. 문을 밀거나 당기며 한 번 해보세요.
? 건전지를 바꿨는데도 안 열려요. | 건전지가 아니라 번호판이나 모터 쪽일 수 있습니다. 증상을 알려주시면 원인을 같이 짚어 봅니다.
? 다세대 건물 공동현관도 잠겨 있으면요? | 건물 출입 방법이나 관리인 연락처를 알려주시면 함께 해결합니다.
? 못 열면 돈을 받나요? | 못 열면 받지 않습니다.
? 원인을 모르겠는데 그냥 불러도 되나요? | 네, 막힌 곳만 말씀해 주셔도 충분합니다.

# 정리
석관동에서 문이 안 열리면 번호판, 번호, 열림 소리, 안쪽 잠금, 문 자체 순서로 짚어 보세요. / 막힌 곳에서 멈추고 연락 주시는 게 가장 빠릅니다.
