# 성북동 언덕 다가구, 맨 위 방 문이 안 열릴 때
성북동은 한성대입구역 쪽에서 언덕을 따라 올라가며 단독주택과 다가구 주택이 이어진 동네입니다. / 큰 집 한 채를 여러 칸으로 나눠 원룸으로 쓰는 건물도 있어서, 대문을 지나 바깥 계단을 올라야 내 방 문이 나오는 구조가 흔합니다.
이런 집은 오피스텔처럼 관리실이 따로 있지 않습니다. / 문이 잠기면 대문, 계단 입구, 방 출입문 가운데 어디서 막혔는지에 따라 연락할 사람과 여는 방법이 달라집니다.
이 글은 성북동 같은 언덕 다가구 원룸에서 출입문이 잠겼을 때 차례로 볼 것을 정리했습니다. / 혼자 해결이 어려우면 [성북구 출장열쇠](seoul-seongbuk.html)로 연락 주시면 길 안내부터 같이 맞춰 갑니다.
@ 성북동 언덕 다가구 원룸 출입문

# 성북동 원룸은 아파트형 원룸과 다릅니다
역 앞 원룸 건물은 공동현관 하나를 지나면 복도에 호실이 나란히 있습니다. / 반면 언덕 다가구는 대문, 마당, 바깥 계단, 방문으로 출입 경로가 길고 집마다 모양이 다릅니다.
대문은 집주인이 관리하는 번호식이나 열쇠식이고, 방문은 세입자마다 다른 도어락이나 열쇠를 쓰는 일이 많습니다. / 반지하 방은 대문 옆 따로 난 계단으로, 옥탑 방은 건물 바깥 계단으로 들어가기도 합니다.
그래서 전화로 "원룸 문이 잠겼다"고만 하시면 어느 문인지 짐작하기 어렵습니다. / 아래 순서로 한 번 가려 보시면 설명이 훨씬 쉬워집니다.

# 대문, 계단, 방문 중 어디서 막혔나
- 대문 번호판이 안 먹히거나 대문 열쇠가 없다
- 대문은 통과했는데 계단 입구 문이 잠겨 있다
- 내 방 문 번호판이 꺼졌거나 번호가 틀리다고 한다
- 방 열쇠를 안에 두고 문을 닫았다
대문에서 막혔다면 집주인이나 같은 건물 이웃이 가장 빠른 해결책입니다. / 방문에서 막혔다면 그때부터 저희가 돕는 일이 많아집니다.
두 곳이 모두 막힌 날도 있습니다. / 대문 번호도 모르고 방 열쇠도 안에 있다면 집주인 연락을 먼저 돌려 두고, 그사이 저희에게 방문 쪽 상황을 알려주시면 시간이 덜 걸립니다.

# 대문 번호가 바뀌었을 때
다가구 대문은 세입자가 바뀔 때 집주인이 번호를 바꾸는 경우가 있습니다. / 공지 문자를 놓쳤거나 단체 대화방이 없으면 모르는 채로 막히게 됩니다.
먼저 집주인에게 연락해 새 번호를 물어보세요. / 연락이 안 되면 같은 건물 다른 방 이웃에게 부탁해 보는 것도 방법입니다.
대문 자체를 여는 일은 건물 전체가 쓰는 문이라 집주인 동의를 먼저 받는 것이 원칙입니다. / 동의가 확인되면 대문 잠금도 함께 봐 드립니다.

# 방문 번호판이 꺼진 경우
방문 도어락 번호판이 손을 대도 안 켜지면 건전지가 다 된 경우가 가장 많습니다. / 바깥쪽 아래에 비상 전원 단자가 있다면 9V 건전지를 대서 번호를 눌러 보세요.
언덕 위 동네라 편의점까지 내려갔다 오기가 번거로울 수 있습니다. / 그래도 9V 하나로 해결되는 일이 많으니 한 번은 시도해 볼 만합니다.
단자가 없거나 대도 반응이 없으면 그때 연락 주세요. / 번호를 여러 번 틀리면 입력이 잠기니 서너 번에서 멈추는 게 좋습니다.
@ 성북동 원룸 방문 도어락 비상 전원

# 열쇠식 방문, 열쇠를 안에 두고 나왔을 때
오래된 다가구는 방문에 도어락 대신 열쇠 손잡이나 보조키만 달린 곳도 있습니다. / 문을 닫으면 저절로 잠기는 손잡이라면 열쇠를 안에 두고 나오는 순간 막힙니다.
집주인이 여분 열쇠를 갖고 있는지 먼저 물어보세요. / 여분이 없으면 손잡이와 보조키 종류를 사진으로 보내 주시면 맞는 방법을 준비해 갑니다.
열쇠 자체를 잃어버렸다면 문을 연 뒤 실린더나 손잡이를 바꿀지도 함께 정하시면 됩니다. / 열쇠 관련 안내는 [열쇠 출장](key-call.html)에 따로 적어 두었습니다.

# 집주인이 같은 건물에 산다면
언덕 다가구는 집주인이 1층이나 맨 위층에 함께 사는 경우가 꽤 있습니다. / 이때는 초인종 한 번으로 해결되는 일도 많으니 먼저 문을 두드려 보세요.
늦은 밤이라 깨우기 미안하시다면 문자를 먼저 남겨 두고 저희에게 연락 주셔도 됩니다. / 문을 연 뒤 집주인이 알아야 할 내용은 정리해서 알려 드립니다.
집주인이 멀리 산다면 통화를 스피커로 연결해 두시면 확인과 설명이 한 번에 끝납니다. / 대문 쪽 문제까지 함께 이야기하기도 편합니다.

# 오르막에서 기다릴 때
겨울 밤 언덕길은 바람이 세고 어둡습니다. / 기다리는 동안 대문 앞에 서 계시기보다 가로등이 밝은 큰길 쪽이나 가까운 가게 안에서 기다리셔도 됩니다.
휴대폰 배터리가 얼마 안 남았다면 위치만 먼저 보내 두시고 통화는 짧게 해 주세요. / 눈이나 비가 온 뒤라면 비탈 계단이 미끄러우니 서두르지 말고 천천히 움직이세요. / 도착 전에 전화를 드리니 어디에 계신지만 알려주시면 됩니다.

# 길 안내가 도착 시간을 정합니다
성북동 언덕길은 내비게이션이 큰길에서 멈추거나 차가 못 들어가는 골목으로 안내하는 일이 있습니다. / 차가 어디까지 올라갈 수 있는지, 마지막에 걸어서 몇 걸음인지 알려주시면 큰 도움이 됩니다.
가까운 큰길 이름, 근처에 보이는 학교나 성당, 공원 같은 큰 건물을 말씀해 주세요. / 대문 색깔이나 바깥 계단 위치처럼 눈에 띄는 것을 한마디 덧붙여 주시면 찾기가 쉬워집니다.

# 들어가기 전 확인
방문을 열기 전에는 사시는 분이 맞는지 꼭 확인합니다. / 신분증 주소, 주소가 찍힌 우편물이나 택배 상자, 임대차 계약서 사진, 집주인 통화 중 하나면 됩니다.
전입신고 전이라 신분증 주소가 다르다면 계약서 사진이나 집주인 통화로 확인할 수 있습니다. / 확인이 안 되면 문을 열 수 없으니 미리 준비해 주세요.

# 비용
문과 잠금장치 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
여는 방법은 문과 도어락이 덜 상하는 쪽부터 시도합니다. / 끝내 못 열면 비용은 받지 않습니다. 자세한 진행은 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 있습니다.
@ 성북구 출장열쇠 성북동 원룸 개방

# 다시 막히지 않게
문이 열리면 새 건전지로 바꾸고 번호를 다시 정하는 것까지 함께 해 드립니다. / 대문 번호와 방문 번호를 휴대폰 잠금 메모에 따로 적어 두시면 다음에 덜 당황합니다.
문을 닫으면 저절로 잠기는 열쇠 손잡이가 불편하다면 [도어락 설치](doorlock-install.html)를 알아보시는 것도 방법입니다. / 세입자라면 바꾸기 전에 집주인과 먼저 이야기해 두세요.

# 성북동 말고 성북구 다른 동네
성북동 아래 돈암동, 안암동, 보문동과 정릉동, 길음동, 종암동, 월곡동, 장위동, 석관동까지 성북구 어디든 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
