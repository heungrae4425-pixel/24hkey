# 월곡동 현관, 한 번쯤 천천히 들여다보기
월곡동은 월곡역을 중심으로 아파트와 다세대 주택이 함께 있는 동네입니다. / 매일 드나드는 현관문인데도 도어락이 어떤 상태인지 찬찬히 본 적은 많지 않습니다.
현관 방범이라고 하면 거창하게 들리지만, 대부분은 이미 달려 있는 잠금장치가 제대로 일하는지 보는 것입니다. / 겁낼 일도, 큰돈 들 일도 아닌 경우가 훨씬 많습니다.
이 글은 집에서 10분 정도면 해볼 수 있는 점검 순서를 적었습니다. / 손봐야 할 곳이 보이면 그때 [성북구 출장열쇠](seoul-seongbuk.html)에 물어보시면 됩니다.
@ 월곡동 현관 도어락 방범 점검

# 점검 전에 알아둘 마음가짐
현관 점검은 불안해서 하는 게 아니라 생활을 편하게 하려고 하는 것입니다. / 문이 잘 닫히고, 잘 잠기고, 내가 원할 때 잘 열리면 그걸로 충분합니다.
새 제품으로 바꾸는 것보다 지금 있는 장치를 제대로 쓰는 것이 먼저입니다. / 아래 항목 중 이상이 없는 것이 대부분이라면 그대로 쓰셔도 됩니다.
점검하다 이상한 곳이 하나 보였다고 바로 큰 문제라는 뜻도 아닙니다. / 하나씩 차분히 보시면 됩니다.

# 첫째, 문이 끝까지 닫히는지
현관문을 손으로 밀지 말고 저절로 닫히게 두어 보세요. / 마지막에 딸깍 소리와 함께 걸쇠가 들어가면 정상입니다.
중간에 멈추거나 살짝 덜 닫힌 채로 서 있다면 도어클로저나 경첩 쪽을 봐야 합니다. / 덜 닫힌 문은 도어락이 잠긴 것처럼 보여도 실제로는 걸쇠가 문틀에 안 들어간 상태일 수 있습니다.
특히 바쁜 아침에 문을 닫고 바로 돌아서는 습관이 있다면 이 항목을 꼭 확인해 보세요. / 닫힌 뒤 손잡이를 한 번 당겨 보는 습관만으로도 충분히 확인됩니다.

# 둘째, 자동 잠금이 제대로 켜져 있는지
많은 도어락은 문이 닫히면 몇 초 뒤 저절로 잠기는 자동 잠금 기능이 있습니다. / 그런데 언젠가 수동으로 바꿔 두고 잊은 집도 있습니다.
문을 닫은 뒤 잠금 소리가 나는지 들어 보세요. / 소리가 안 나면 설정이 수동으로 되어 있을 수 있으니 설명서나 제품 안쪽 스위치를 확인해 보세요.
아이가 있는 집은 일부러 수동으로 두기도 합니다. / 어느 쪽이든 가족이 모두 같은 방식으로 알고 있으면 됩니다.
@ 월곡동 도어락 자동 잠금 설정 확인

# 셋째, 걸쇠와 문틀 구멍 상태
문을 열어 둔 채 도어락 걸쇠를 손가락으로 눌러 보세요. / 부드럽게 들어갔다 나오면 괜찮고, 뻑뻑하거나 비스듬하게 움직이면 손볼 때가 된 것입니다.
문틀 쪽 걸쇠 구멍 받침쇠의 나사가 풀려 있지는 않은지도 보세요. / 받침쇠가 헐거우면 문을 세게 당겼을 때 걸쇠가 쉽게 빠질 수 있습니다.
나사가 조금 풀린 정도라면 드라이버로 살짝 조여 주시면 됩니다. / 나사 구멍이 헛돌면 그때 보강이 필요합니다.

# 넷째, 보조키와 안쪽 걸쇠
도어락 위나 아래에 보조키가 따로 있다면 열쇠가 부드럽게 돌아가는지 확인해 보세요. / 몇 해 동안 안 쓴 보조키는 막상 필요할 때 굳어 있는 경우가 있습니다.
안쪽 걸쇠나 체인도 잘 걸리고 잘 풀리는지 한 번 움직여 보세요. / 잘 쓰지 않는다면 누가 실수로 걸었을 때 바깥에서 열기 어려워진다는 점도 함께 기억해 두시면 좋습니다.
보조키 열쇠가 집에 몇 개 있는지, 누가 갖고 있는지도 이참에 세어 보세요.
처음 받은 개수보다 적다면 어디 있는지 가족에게 물어보시고, 끝내 못 찾으면 실린더만 바꾸는 방법도 있습니다. / 잃어버린 열쇠가 하나라도 있으면 마음이 쓰이니 정리해 두시는 게 편합니다.

# 다섯째, 비밀번호와 출입 수단
비밀번호를 정한 지 오래됐다면 바꿔 보시는 것도 좋습니다. / 번호판 특정 숫자만 닳아 보이면 그 숫자를 덜 쓰는 번호로 바꾸는 것도 방법입니다.
도어락에 등록된 카드나 지문이 몇 개인지도 확인해 보세요. / 이사 오기 전 사람이나 예전에 잠깐 함께 지낸 사람의 카드가 남아 있다면 지워 두시면 됩니다.
번호를 누를 때 손으로 가리는 습관, 허수 번호를 앞뒤로 붙이는 기능도 써 볼 만합니다.
번호를 바꿨다면 가족에게 한 사람씩 직접 알려 주세요. / 단체 대화방에 번호를 그대로 적어 두는 것보다 말로 전하는 편이 낫습니다.

# 여섯째, 건전지와 비상 단자
건전지를 언제 바꿨는지 기억나지 않는다면 이참에 한 번에 다 바꿔 두세요. / 경고음이 나기 전에 바꾸면 문 앞에서 막힐 일이 줄어듭니다.
바깥쪽 비상 전원 단자 위치도 미리 알아 두세요. / 손전등으로 비춰 보면 대부분 번호판 아래쪽에 있습니다.
건전지를 바꿀 때는 건전지 칸 접점에 하얀 가루나 녹 같은 것이 없는지도 같이 보세요. / 접점이 지저분하면 새 건전지를 넣어도 전원이 들쭉날쭉할 수 있어 마른 천으로 살살 닦아 주시면 됩니다.
바꾼 날짜를 건전지 덮개 안쪽에 적어 두면 다음 점검 때 바로 알 수 있습니다. / 가족 중 누가 바꿨는지 몰라 헷갈리는 일도 줄어듭니다.

# 점검하다 손대지 않는 게 좋은 곳
도어락 바깥 몸체 나사를 풀어 안을 열어 보는 것은 권하지 않습니다. / 방수 부분이 상하거나 다시 조립할 때 배선이 눌릴 수 있습니다.
걸쇠에 기름을 뿌리는 것도 피해 주세요. / 먼지가 엉겨 오히려 뻑뻑해집니다.
도어클로저 조절 나사를 많이 돌리면 기름이 새기도 합니다. / 반 바퀴씩만 돌려 보시고, 잘 모르겠으면 그대로 두세요.

# 손봐야 할 곳이 보였다면
점검 결과를 메모해 두셨다가 전화로 말씀해 주세요. / 어떤 부분이 이상한지만 알려주셔도 출장이 필요한지, 직접 하실 수 있는지 말씀드립니다.
- 아파트 단지 이름과 동, 호수, 또는 다세대 건물 이름
- 이상이 보인 항목 (닫힘, 자동 잠금, 걸쇠, 보조키 등)
- 도어락 앞뒤 사진
작업이 필요하면 비용은 시작 전에 먼저 말씀드립니다. / 진행 순서는 [이용안내](guide.html)에 있습니다.
@ 월곡동 현관 걸쇠 받침쇠 조정 출장

# 손보는 방법은 이렇게 나뉩니다
걸쇠나 받침쇠, 도어클로저 조정처럼 작은 손질은 [도어락 수리](doorlock-repair.html)로 대부분 끝납니다. / 부품을 구하기 어려울 만큼 오래됐거나 기능이 부족하다고 느끼시면 [도어락 교체](doorlock-replace.html)를 함께 상의하면 됩니다.
보조키를 새로 달거나 위치를 바꾸고 싶다면 문 두께와 기존 구멍을 먼저 봐야 합니다. / 확인할 것은 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.
어느 쪽이든 꼭 필요한 것만 말씀드립니다. / 손본 뒤에는 위 여섯 항목을 사시는 분과 함께 한 번 더 확인하고 마칩니다.

# 월곡동 주변 성북구 동네
월곡동 옆 종암동, 장위동, 석관동부터 길음동, 돈암동, 정릉동, 안암동, 보문동, 성북동까지 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.

# 현관 점검에 대해 묻는 것
? 점검만 받아도 되나요? | 네, 손볼 곳이 없으면 그대로 쓰시라고 말씀드립니다.
? 도어락을 꼭 새것으로 바꿔야 안전한가요? | 아닙니다. 지금 장치가 잘 닫히고 잘 잠기면 충분한 경우가 많습니다.
? 비밀번호는 얼마나 자주 바꾸면 좋을까요? | 정해진 기준은 없지만 이사, 공사, 손님 출입 뒤에 한 번씩 바꾸시면 좋습니다.
? 출장을 불렀는데 손볼 게 없으면요? | 상태를 말씀드리고, 작업이 없으면 그에 맞게 안내합니다.
? 밤에도 문 잠김이 있으면 오시나요? | 네, 24시간 출동합니다.
