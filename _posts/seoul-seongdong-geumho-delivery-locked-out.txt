# 금호동, 슬리퍼 차림으로 복도에 서 있다면
금호동은 옥수동과 이웃한 아파트 단지가 넓게 자리한 동네입니다. / 저녁에 분리수거 봉투를 들고 내려가거나 문 앞 택배를 들이려다 등 뒤에서 철컥 소리를 듣는 일이 생각보다 자주 생깁니다.
요즘 도어락은 문이 닫히면 저절로 잠기는 자동 잠금이 기본인 경우가 많습니다. / 열쇠도 휴대폰도 집 안에 두고 나왔다면 말 그대로 빈손으로 복도에 서게 됩니다.
이 글은 금호동에서 이런 일을 겪었을 때 무엇부터 하면 되는지 차례대로 적었습니다. / 연락이 닿으면 [성동 출장열쇠](seoul-seongdong.html)가 위치를 받아 바로 움직입니다.
@ 금호동 아파트 복도 현관문 자동 잠금

# 우선 숨 한 번 고르고 상황부터 보세요
당황하면 문고리를 계속 당기거나 번호판을 마구 누르게 됩니다. / 그 전에 아래를 차분히 확인해 보세요.
- 집 안에 누가 있는지, 가족이 곧 들어올 시간인지
- 가스레인지나 다리미처럼 켜 둔 것이 있는지
- 아이나 반려동물이 안에 혼자 남았는지
- 주머니에 카드키나 차 열쇠라도 있는지
켜 둔 불이 있거나 아이가 혼자라면 연락할 때 그 이야기부터 해 주세요. / 그 경우는 순서를 앞당겨 갑니다.

# 번호를 아는데도 안 열린다면
비밀번호를 알고 있다면 당연히 먼저 눌러 보시면 됩니다. / 그런데 번호가 맞는데도 안 열린다면 안쪽 보조 잠금이나 걸쇠가 걸려 있을 수 있습니다.
분리수거 나가면서 습관처럼 안쪽 걸쇠를 걸어 둔 채 문을 당기는 경우가 있습니다. / 이 경우는 바깥에서 번호를 눌러도 걸쇠가 문을 붙잡고 있어 열리지 않습니다.
도어락이 이중 잠금 상태로 설정돼 있을 때도 비슷한 일이 생깁니다. / 몇 번 눌러도 같다면 더 시도하지 말고 연락 주시는 것이 좋습니다.

# 휴대폰이 없을 때 연락하는 방법
금호동 아파트 단지라면 경비실이나 관리사무소가 가장 가까운 도움입니다. / 사정을 말하면 전화를 빌려주거나 세대 확인을 도와주는 곳이 많습니다.
이웃집 문을 두드리는 것도 방법입니다. / 늦은 시간이라면 인터폰으로 먼저 양해를 구하면 놀라지 않으십니다.
번호를 외우지 못했다면 경비실에 붙은 안내문이나 이웃 휴대폰으로 검색해 보시면 됩니다. / 24시출장열쇠 번호는 010-3664-5455입니다.

# 기다리는 동안 해 두면 좋은 것
연락을 마쳤다면 도착 전까지 할 일이 몇 가지 있습니다. / 이것만 해 두면 문 앞에서의 시간이 짧아집니다.
경비실에 출장 기사가 올 거라고 미리 말해 두세요. / 공동현관을 열어 주거나 동 위치를 알려 주기가 수월해집니다.
방금 받은 택배 상자가 있다면 버리지 말고 들고 계세요. / 상자에 적힌 주소와 이름이 거주 확인에 도움이 되기도 합니다.
겨울이라면 경비실이나 1층 로비처럼 따뜻한 곳에서 기다리세요. / 얇은 옷으로 복도에 오래 서 있으면 감기 들기 쉽습니다.
@ 금호동 경비실 연락 출장열쇠 기다리기

# 문틈을 벌리거나 카드를 넣지 마세요
인터넷에서 본 방법이라며 문틈에 카드를 밀어 넣는 분이 있습니다. / 요즘 현관문은 문틈이 좁고 걸쇠 구조가 달라 대부분 열리지 않고 문틀만 긁힙니다.
드라이버나 쇠붙이로 번호판을 뜯는 것도 피해 주세요. / 경보음이 울리거나 기판이 상해 열고 나서 교체해야 하는 일이 생깁니다.
베란다로 넘어가려는 시도는 절대 하지 마세요. / 아파트 층과 상관없이 몹시 위험합니다.

# 공동현관 밖까지 나왔다면
분리수거장이 건물 바깥에 있는 단지라면 집 현관뿐 아니라 1층 공동현관도 막힙니다. / 이때는 같은 동 주민이 드나들 때 함께 들어가거나 경비실에 문을 열어 달라고 부탁하는 수밖에 없습니다.
출장 기사도 공동현관을 지나야 집 앞에 닿습니다. / 연락할 때 공동현관 밖에 계신지, 집 앞 복도에 계신지를 같이 말해 주시면 만날 자리를 정하기 쉽습니다.
동 번호와 라인, 층을 정확히 알려 주시는 것도 중요합니다. / 금호동처럼 비슷한 건물이 줄지어 선 단지는 동 번호 하나 차이로 헤매기 쉽습니다.

# 도착하면 이렇게 진행합니다
현관 앞에 도착하면 도어락 종류와 걸쇠 상태를 먼저 살핍니다. / 그다음 사시는 분인지 확인하고 비용을 말씀드립니다.
비용은 문을 열기 전에 알려 드리고, 동의하실 때만 시작합니다. / 문을 끝내 열지 못하면 비용을 받지 않습니다.
여는 방식은 문과 도어락이 덜 상하는 쪽부터 씁니다. / 어떤 방법을 쓰는지는 [현관문 개문](door-open.html)에서도 보실 수 있습니다.

# 사시는 분인지 확인하는 방법
신분증이 집 안에 있는 경우가 대부분이라 미리 걱정하시는 분이 많습니다. / 경비실이나 관리사무소에서 세대 확인을 해 주면 그것으로 진행할 수 있습니다.
택배 상자의 주소와 이름, 문이 열린 뒤 집 안의 신분증으로 확인하는 방법도 있습니다. / 절차는 [이용안내](guide.html)에 자세히 적어 두었습니다.

# 자동 잠금, 꺼도 될까요
같은 일이 반복된다면 자동 잠금을 끄고 싶어지실 수 있습니다. / 하지만 끄면 깜빡하고 문을 안 잠그고 나가는 일이 생깁니다.
대신 쓰레기를 버리거나 택배를 들일 때만 문을 열림 상태로 고정하는 기능이 있는지 보세요. / 많은 도어락이 안쪽 버튼으로 잠시 잠금을 멈출 수 있습니다.
기능이 있는지 모르겠다면 출장 때 함께 확인해 드립니다. / 설정은 집 사정에 맞게 고르시면 됩니다.

# 반복되지 않게 바꿀 수 있는 습관
현관 신발장 위에 작은 바구니를 두고 휴대폰을 넣는 자리로 정해 보세요. / 나갈 때 손이 가는 곳에 두면 들고 나가기 쉬워집니다.
- 분리수거 날은 문을 나서기 전 휴대폰을 주머니에 먼저 넣기
- 택배는 문을 활짝 열어 두지 말고 한 발을 문에 걸친 채 들이기
- 손목에 차는 카드키나 태그를 따로 등록해 두기
- 가까이 사는 가족에게 비상 열쇠나 번호를 맡겨 두기
태그나 카드를 쓰는 도어락이라면 손목밴드형 태그가 꽤 쓸모 있습니다. / 쓰레기 봉투를 들고도 손목만 대면 문이 열립니다.
@ 금호동 현관 도어락 카드 태그 등록

# 열린 뒤 확인할 것
문이 열리면 도어락이 다시 제대로 잠기는지 몇 번 시험합니다. / 걸쇠 때문이었다면 걸쇠가 문틀에 걸리는 각도도 같이 봅니다.
도어락 자체에 이상이 보이면 [도어락 수리](doorlock-repair.html)로 손볼지 말씀드립니다. / 자동 잠금이 제멋대로 작동하는 오래된 제품이라면 [도어락 교체](doorlock-replace.html)를 상의할 수 있습니다.
