# 행당동 현관문, 오늘 처음 안 열린 건가요
행당동은 행당역과 왕십리역 사이로 아파트 단지와 주택가가 넓게 이어진 동네입니다. / 오래 산 집도, 이사 온 지 얼마 안 된 집도 많아 현관문이 안 열리는 사정도 제각각입니다.
문 앞에서 원인을 찾을 때 가장 먼저 던져 볼 질문이 있습니다. / "오늘 갑자기 이런가, 아니면 며칠 전부터 조금씩 이상했나"입니다.
이 질문 하나로 의심할 곳이 크게 갈립니다. / 아래에서 원인을 여섯 갈래로 나눠 차례로 짚어 보고, 손으로 안 되면 [성동 출장열쇠](seoul-seongdong.html)로 연락 주세요.
@ 행당동 현관문 안 열림 원인 확인

# 갑자기 안 열린 경우와 조금씩 나빠진 경우
어제까지 멀쩡했는데 오늘 갑자기 안 열린다면 건전지 방전, 번호 변경, 안쪽 걸쇠처럼 한순간에 생기는 원인이 많습니다. / 대부분 문 앞에서 확인할 수 있고 빨리 풀리는 편입니다.
며칠 전부터 문이 뻑뻑했거나 모터 소리가 길어졌다면 부품이 닳았거나 문이 처진 경우가 많습니다. / 이 경우는 문을 연 뒤에도 손봐야 할 것이 남아 있습니다.
어느 쪽인지 떠올리기 어렵다면 최근 일주일 동안 문을 열 때 평소와 다른 느낌이 있었는지만 생각해 보세요. / 그 기억이 전화로 설명하실 때 큰 단서가 됩니다.

# 전원 문제, 불빛이 없거나 흐릴 때
번호판을 손으로 덮었는데 불이 아예 안 들어오면 전원부터 의심합니다. / 불이 들어와도 평소보다 흐리거나 깜빡이며 꺼진다면 건전지가 바닥 직전입니다.
바깥쪽 아래나 옆면의 비상 단자에 9V 건전지를 대 보세요. / 켜지면 번호를 누르고, 문이 열린 뒤 안쪽 건전지를 전부 새것으로 바꾸면 됩니다.
행당역 주변이나 단지 상가 편의점에서 9V를 구할 수 있습니다. / 새 건전지를 대도 조용하다면 전원 외 원인으로 넘어갑니다.

# 입력 문제, 번호나 카드나 지문이 거부될 때
불은 켜지는데 번호를 누르면 틀렸다는 소리가 난다면 번호가 바뀌었을 가능성을 먼저 봅니다. / 가족 중 누가 최근에 번호를 바꾸지 않았는지 연락해 보세요.
카드는 되는데 번호만 안 되거나, 번호는 되는데 지문만 안 된다면 그 방식만 문제입니다. / 다른 방식으로 열 수 있는지 먼저 시도해 보세요.
연달아 여러 번 틀리면 도어락이 잠시 입력을 막습니다. / 서너 번에서 멈추고 잠깐 기다리는 것이 좋습니다.

# 구동 문제, 윙 소리 뒤에 멈출 때
번호가 맞았다는 소리가 나고 모터가 돌아가는데 문이 안 열린다면 구동 쪽을 봅니다. / 모터 소리가 평소보다 길게 끌리다 멈춘다면 막대가 문틀에 걸려 있을 수 있습니다.
문을 몸 쪽으로 살짝 당기거나 안쪽으로 살짝 밀면서 다시 번호를 눌러 보세요. / 이렇게 해서 열린다면 문틀 받이 조정이 필요한 상태입니다.
밀고 당겨도 같은 소리만 반복된다면 도어락 안쪽 기어가 닳았을 가능성이 있습니다. / 이때는 더 시도하지 말고 연락 주세요.
@ 행당동 도어락 모터 소리 걸림 문 밀며 열기

# 걸림 문제, 문짝과 문틀이 서로 물고 있을 때
도어락은 풀린 것 같은데 문이 무겁게 버틴다면 문짝과 문틀이 맞물린 것입니다. / 계절이 바뀔 때나 비가 많이 온 다음 날 이런 일이 잦습니다.
문 위쪽 모서리를 손바닥으로 누르면서 손잡이를 당겨 보세요. / 처진 문이 잠깐 올라가면서 걸린 부분이 풀리기도 합니다.
그래도 안 되면 어깨로 밀거나 발로 차지 말아 주세요. / 경첩이 상하면 문을 연 뒤에도 문짝을 바로잡는 일이 커집니다.

# 안쪽 잠금 문제, 집 안에서 걸린 장치
번호가 맞고 모터도 돌았는데 문이 한 뼘 열리다 멈춘다면 안쪽 걸쇠입니다. / 아이가 놀다가 걸었거나, 집 안에 있던 가족이 무심코 걸었을 수 있습니다.
집 안에 사람이 있다면 걸쇠를 풀어 달라고 하면 되고, 아무도 없다면 문틈에 손을 넣지 말고 그대로 연락 주세요. / 문틈으로 무언가를 밀어 넣으면 걸쇠 고정 나사가 빠지거나 문틀이 패입니다.
안쪽 보조키를 열쇠로 잠근 경우도 같은 갈래로 봅니다. / 이때는 보조키 열쇠를 가진 가족이 가까이 있는지 먼저 연락해 보시면 문을 손대지 않고 끝날 수도 있습니다.

# 열쇠 문제, 실린더가 돌지 않을 때
열쇠로 여는 보조키나 손잡이라면 열쇠가 끝까지 들어가는지 먼저 보세요. / 끝까지 안 들어가면 구멍에 이물질이 있거나 다른 열쇠일 수 있습니다.
들어가는데 돌지 않는다면 억지로 비틀지 마세요. / 힘을 주다 열쇠가 부러지면 일이 하나 더 늘어납니다.
복사한 열쇠만 안 도는 경우라면 원래 열쇠로 한 번 시도해 보세요. / 겨울 아침에만 열쇠가 안 돈다면 구멍 안 습기가 얼었을 수 있어 손으로 열쇠를 잠시 데운 뒤 다시 넣어 보는 것도 방법입니다.

# 원인을 좁힌 다음 전화로 말씀하실 것
위 여섯 갈래 중 어디에 가까운지만 알려 주셔도 준비가 달라집니다. / 아래 내용을 짧게 말씀해 주세요.
- 갑자기인지, 며칠 전부터 이상했는지
- 번호판 불빛과 소리
- 문을 밀거나 당길 때 달라지는 점
- 동, 호수와 가까운 역이나 큰길
도어락 앞면 사진을 함께 보내 주시면 제품 방식을 미리 알 수 있습니다.

# 하지 말아야 할 세 가지
드라이버나 카드로 문틈을 벌리는 일, 손잡이를 세게 당기거나 문을 차는 일, 번호를 수십 번 눌러 보는 일입니다. / 세 가지 모두 원인을 찾기 어렵게 만들고 고칠 부분을 늘립니다.
문틈을 벌리면 걸쇠가 더 꽉 물리고 도어락 외관이 휩니다. / 손잡이를 세게 당기면 축이 틀어져 문이 열린 뒤에도 손잡이가 헛돌 수 있습니다.
번호를 계속 누르면 입력 제한이 길어지고 건전지도 빨리 닳습니다. / 막혔다 싶으면 손을 떼고 위 여섯 갈래 중 어디에 가까운지 떠올려 보는 것이 가장 빠른 길입니다.

# 거주 확인과 비용 순서
문을 열기 전 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나로 사시는 분인지 봅니다. / 신분증이 집 안에 있으면 관리사무소에 미리 말씀해 두세요.
원인과 문 상태를 본 뒤 비용을 먼저 말씀드리고 동의하시면 시작합니다. / 끝내 열지 못하면 비용은 받지 않으며 순서는 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 원인별로 열린 뒤 손보는 것
전원이 원인이면 건전지 교체로, 번호가 원인이면 새 번호 등록으로 마칩니다. / 걸림이 원인이면 받이와 경첩을 조정하고, 기어가 닳았다면 [도어락 수리](doorlock-repair.html)로 해당 부품을 손봅니다.
부품을 구하기 어렵거나 같은 고장이 반복된다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 행당동 현관 도어락 원인별 수리 점검

# 행당동 주변 성동구
행당동 가까이 왕십리동, 응봉동, 사근동과 마장동, 금호동, 옥수동, 성수동, 송정동, 용답동까지 갑니다. / 다른 서울, 경기 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 걸쇠가 걸린 것 같은데 문이 상하나요? | 덜 상하는 방법부터 시도하고 다른 방법이 필요하면 먼저 여쭙니다.
