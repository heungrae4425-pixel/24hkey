# 옥수동 현관, 잠금 막대가 문틀에 물려 있을 때
옥수동은 옥수역을 중심으로 아파트 단지가 넓게 자리 잡은 동네입니다. / 오래 쓴 현관문은 경첩과 문틀이 조금씩 움직이면서 도어락과 문틀 구멍의 자리가 어긋나기도 합니다.
번호를 눌렀더니 모터는 도는데 문이 꿈쩍하지 않는다면 데드볼트를 의심해 볼 만합니다. / 반대로 문을 닫았는데 잠김 소리가 끝까지 나지 않는 것도 같은 부품의 문제일 수 있습니다.
이 글은 데드볼트가 왜 걸리는지, 집에서 어디까지 확인해도 되는지를 정리했습니다. / 손으로 해결이 안 되면 [성동 출장열쇠](seoul-seongdong.html)로 연락 주세요.
@ 옥수동 현관 도어락 데드볼트 문틀 걸림

# 데드볼트는 어디 있는 부품인가
문 옆면을 보면 문을 닫을 때 문틀 구멍으로 쑥 들어가는 네모난 쇠막대가 있습니다. / 이것이 데드볼트이고, 문을 실제로 잠그는 역할을 합니다.
비스듬하게 생겨 문을 닫으면 저절로 눌렸다 튀어나오는 걸쇠와는 다른 부품입니다. / 걸쇠는 문을 붙잡아 두는 것이고, 데드볼트는 그 위에서 문을 단단히 묶어 둡니다.
도어락이 잠글 때는 모터가 이 막대를 밀어 넣고, 열 때는 당겨 빼냅니다. / 그래서 막대가 조금만 어긋나도 모터 힘만으로는 움직이지 못하는 일이 생깁니다.

# 안 빠질 때와 안 들어갈 때는 원인이 다릅니다
막대가 문틀 안에서 안 빠지는 경우는 대개 문짝이 문틀 한쪽으로 쏠려 막대를 누르고 있을 때입니다. / 막대 옆면이 문틀 구멍 벽에 꽉 끼어 모터가 당겨도 버티는 것입니다.
막대가 끝까지 안 들어가는 경우는 문틀 구멍이 막대보다 위나 아래로 어긋났을 때가 많습니다. / 문이 처지거나 경첩이 헐거워지면 몇 밀리만 내려가도 막대 끝이 구멍 테두리에 걸립니다.
둘 다 도어락 고장처럼 보이지만 실제로는 문과 문틀의 자리 문제인 경우가 꽤 됩니다. / 그래서 도어락을 새로 바꿔도 문 자리를 바로잡지 않으면 같은 걸림이 다시 생길 수 있습니다.
어느 쪽인지 헷갈린다면 문이 열린 상태에서 번호판의 잠금 버튼을 눌러 보세요. / 문을 열어 둔 채로 막대가 시원하게 나왔다 들어간다면 도어락보다는 문틀 쪽을 보시면 됩니다.

# 문을 몸 쪽으로 당기며 다시 열어 보기
안 빠지는 경우라면 가장 먼저 해볼 일은 문에 걸린 힘을 풀어 주는 것입니다. / 손잡이를 잡고 문을 내 쪽으로 살짝 당기거나 반대로 안쪽으로 살짝 밀면서 번호를 다시 눌러 보세요.
문이 어느 쪽으로 쏠려 있는지에 따라 당기는 쪽이 맞기도 하고 미는 쪽이 맞기도 합니다. / 두 방향을 각각 한두 번씩만 해 보면 됩니다.
문 위쪽 모서리를 손바닥으로 지그시 누르면서 열면 풀리는 집도 있습니다. / 처진 문이 잠깐 제자리로 올라가면서 막대가 빠져나오는 원리입니다.

# 문틀 구멍 안쪽을 들여다보세요
문이 열린 상태에서 막대가 잘 안 들어간다면 문틀 쪽 구멍을 손전등으로 비춰 보세요. / 먼지 뭉치, 떨어진 나사, 페인트 덩어리가 구멍을 막고 있는 일이 의외로 있습니다.
구멍 둘레의 쇠판에 반짝이는 긁힌 자국이 한쪽에만 나 있다면 막대가 그쪽으로 비껴 들어가고 있다는 뜻입니다. / 사진을 찍어 두시면 전화로 설명하실 때 큰 도움이 됩니다.
@ 옥수동 문틀 데드볼트 구멍 긁힘 자국 확인

# 모터 소리는 나는데 막대가 꼼짝 않는다면
번호가 맞고 윙 하는 소리까지 나는데 막대가 그대로라면 원인은 두 갈래입니다. / 막대가 문틀에 눌려 있거나, 도어락 안쪽 기어가 헛도는 경우입니다.
문을 밀고 당기며 시도해도 같은 소리만 반복된다면 내부 부품 쪽일 가능성이 높아집니다. / 이때는 더 누르지 말고 멈추는 것이 좋습니다.
같은 동작을 수십 번 되풀이하면 모터가 과열되거나 건전지가 빨리 닳습니다. / 문 앞에서 막힌 상태라면 그대로 두고 연락 주세요.

# 안쪽 엄지 돌림 손잡이도 확인
집 안에 계신 상태라면 도어락 안쪽의 수동 잠금 손잡이를 돌려 보세요. / 엄지로 돌리는 작은 레버가 있는 제품은 모터 대신 손힘으로 막대를 움직일 수 있습니다.
이 레버가 뻑뻑하게 반쯤만 돌아간다면 막대가 어딘가에 걸려 있다는 신호입니다. / 억지로 끝까지 돌리면 레버 축이 부러질 수 있어 무리하지 마세요.
집 안에 갇힌 것처럼 느껴져 당황스러우시겠지만 밖에서 들어오는 사람은 문을 상하지 않게 여는 방법이 있습니다. / 안에서 레버를 그대로 두신 채 연락 주시면 됩니다.

# 날씨가 추워지면 더 자주 걸립니다
겨울에는 쇠로 된 문틀과 문짝이 조금씩 줄어들고 바람에 문이 한쪽으로 눌리기도 합니다. / 여름에는 반대로 습기를 먹어 문이 뻑뻑해지는 일이 있습니다.
계절이 바뀔 때만 막대가 걸린다면 받이 위치를 조금 조정하는 것만으로 나아지는 경우가 많습니다. / 해마다 같은 시기에 반복된다면 메모해 두셨다가 점검 때 알려 주세요.

# 윤활제를 뿌리기 전에 생각할 것
막대가 뻑뻑하다고 식용유나 아무 기름이나 넣으면 먼지가 엉겨 붙어 더 나빠집니다. / 도어락 몸체 안쪽으로 흘러 들어가면 전자 부품에도 좋지 않습니다.
꼭 쓰시려면 마른 천에 소량만 묻혀 막대 겉면을 닦아 내는 정도로 그치세요. / 구멍 안이나 도어락 틈에 직접 뿌리는 것은 피해 주세요.

# 연락하실 때는 소리와 위치를 함께
전화 주실 때 아래 내용을 말씀해 주시면 원인을 미리 좁힐 수 있습니다.
- 지금 문 밖에 계신지 안에 계신지
- 막대가 안 빠지는지, 끝까지 안 들어가는지
- 번호를 누를 때 나는 소리 (윙, 딸깍, 무음)
- 문을 밀거나 당길 때 달라지는 점
- 동, 호수와 옥수역 기준 대략 방향

# 확인 절차와 비용 안내
문을 여는 상황이라면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
막대 상태와 도어락 종류를 본 뒤 비용을 먼저 말씀드리고, 동의하실 때 시작합니다. / 끝내 열지 못하면 비용은 받지 않으며 자세한 순서는 [이용안내](guide.html)에 있습니다.

# 손보는 방법은 받이, 구동부, 교체 순서
가장 가벼운 방법은 문틀 쪽 받이 쇠판을 조금 옮겨 막대가 똑바로 들어가게 하는 것입니다. / 경첩 나사를 조여 문 처짐을 줄이는 작업을 함께 하기도 합니다.
막대를 움직이는 안쪽 부품이 닳았다면 [도어락 수리](doorlock-repair.html)로 해당 부분만 손봅니다. / 도어락 자체가 오래돼 부품을 구하기 어렵다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문 밖에서 막혀 있는 상황이라면 먼저 [현관문 개문](door-open.html)으로 문을 연 뒤 같은 순서로 봅니다.
@ 옥수동 도어락 받이 조정 경첩 점검

# 옥수동 근처 성동구 동네
옥수동 옆 금호동, 응봉동과 행당동, 왕십리동, 성수동, 마장동, 사근동, 송정동, 용답동까지 다닙니다. / 다른 서울, 경기 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
