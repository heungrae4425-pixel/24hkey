# 사근동에서 도어락을 고르기 전, 우리 집 문 앞 장면 떠올리기
사근동은 성동구 안쪽의 주거 동네로, 혼자 사는 집과 가족이 사는 집이 골목마다 섞여 있습니다. / 그만큼 현관문 앞에서 벌어지는 장면도 집마다 다릅니다.
장을 봐서 양손에 봉지를 든 채 문 앞에 서는 집, 늦게 들어와 어두운 복도에서 번호를 누르는 집, 아이가 학교에서 혼자 돌아오는 집이 있습니다. / 스마트 도어락은 이 장면에 맞춰 고르는 것이 가장 실패가 적습니다.
이 글은 기능별로 장단점을 나누고, 설치 전에 문에서 확인할 것을 정리했습니다. / 상담이 필요하시면 [성동 출장열쇠](seoul-seongdong.html)로 언제든 연락 주세요.
@ 사근동 스마트 도어락 고르기 현관 생활 동선

# 비밀번호식은 여전히 기본입니다
지문이든 카드든 대부분의 스마트 도어락은 비밀번호 입력을 같이 지원합니다. / 다른 방법이 안 될 때 마지막으로 기대는 것이 번호라서, 번호판이 눌리기 쉽고 잘 보이는지가 생각보다 중요합니다.
번호를 누르기 전에 아무 숫자나 섞어 누르게 하는 허수 입력 기능이 있으면 버튼 닳은 자국으로 번호가 드러나는 일을 줄일 수 있습니다. / 번호판에 손바닥을 대야 켜지는 방식인지, 가까이 가면 켜지는 방식인지도 매장에서 직접 눌러 보며 확인해 보세요.

# 지문 인식, 손에 따라 편차가 있습니다
양손에 짐이 많은 집, 열쇠나 카드를 자주 잃어버리는 집에는 지문이 편합니다. / 손가락 하나만 대면 되니 아이도 쉽게 씁니다.
다만 손끝이 건조하거나 굳은살이 있는 분, 손을 많이 쓰는 일을 하는 분은 인식이 잘 안 될 수 있습니다. / 겨울에는 손이 차고 말라서 평소보다 실패가 잦아지기도 합니다.
가족 중 인식이 잘 안 되는 사람이 있다면 그 사람은 번호나 카드를 주로 쓰게 정해 두는 편이 낫습니다. / 손가락을 두세 개씩 등록해 두면 다친 날에도 쓸 수 있습니다.

# 카드와 태그, 잃어버릴 때를 같이 생각하기
카드나 태그는 대기만 하면 열리니 어르신이나 어린 자녀에게 편합니다. / 공동현관과 같은 카드를 쓰는 건물이라면 하나로 두 문을 여는 셈이라 더 간단합니다.
대신 잃어버렸을 때 그 카드를 지우는 방법을 알아 두셔야 합니다. / 카드를 하나씩 지울 수 있는 제품인지, 전부 지우고 다시 등록해야 하는 제품인지 고를 때 물어보세요.

# 앱과 원격 기능은 필요할 때만
휴대폰으로 출입 기록을 보거나 멀리서 문을 열어 주는 기능은 분명히 편리합니다. / 아이 귀가를 확인하고 싶거나 가족이 아닌 사람이 집에 드나드는 일이 잦은 집에는 쓸모가 있습니다.
하지만 집 와이파이, 별도 통신 장치, 앱 업데이트까지 관리할 것이 늘어납니다. / 쓰지 않을 기능이라면 굳이 고르지 않아도 됩니다.
원격 기능을 쓰신다면 앱 로그인 비밀번호를 도어락 번호와 다르게 정해 두세요. / 휴대폰을 바꿀 때 앱 계정을 옮기는 방법도 미리 알아 두시면 연동이 끊기는 일을 줄일 수 있습니다.

# 푸시풀과 버튼형, 손 쓰임의 차이
밀고 당기는 푸시풀 형은 손잡이를 잡은 채로 밀기만 하면 열려서 손이 편합니다. / 문 앞 공간이 넉넉하고 문짝이 튼튼한 아파트 현관에 잘 맞습니다.
버튼형이나 손잡이 일체형은 기존 손잡이 자리를 그대로 쓰는 경우가 많아 오래된 현관에도 달기 쉽습니다. / 어느 쪽이 맞는지는 지금 달린 도어락의 타공 자리를 보고 함께 정합니다.
@ 사근동 푸시풀 도어락 손잡이 일체형 비교

# 자동 잠금과 안쪽 잠금 설정도 따져 보기
대부분의 스마트 도어락은 문이 닫히면 저절로 잠기는 자동 잠금을 지원합니다. / 편하지만 분리수거나 택배를 받으러 잠깐 나갔다가 문이 잠겨 버리는 일의 원인이 되기도 합니다.
수동 잠금으로 바꿀 수 있는지, 잠기기까지 시간을 조절할 수 있는지 확인해 두면 좋습니다. / 아이가 안에서 문을 잠그지 못하게 하는 설정이 있는 제품도 있어 어린 자녀가 있는 집이라면 눈여겨볼 만합니다.
설정은 고르는 날보다 설치하는 날 직접 손으로 해 보셔야 익숙해집니다. / 설치 때 함께 바꿔 보며 우리 집에 맞는 쪽으로 정해 드립니다.

# 세입자라면 바꾸기 전에 확인할 것
전셋집이나 월셋집이라면 도어락을 바꾸기 전에 집주인과 한 번 이야기해 두시는 편이 좋습니다. / 바꾼 도어락을 퇴거 때 두고 갈지, 원래 것을 다시 달지 미리 정해 두면 나중에 얼굴 붉힐 일이 줄어듭니다.
원래 도어락은 버리지 말고 상자에 보관해 두세요. / 계약 내용에 따라 정리 방법이 다를 수 있으니 계약서도 같이 살펴보시면 됩니다.

# 문 규격이 선택지를 먼저 정합니다
마음에 드는 제품이 있어도 우리 집 문에 맞지 않으면 달 수 없습니다. / 문 두께, 문 옆면의 기존 구멍 위치, 문이 열리는 방향, 방화문 여부를 먼저 봐야 합니다.
기존 타공이 새 제품과 맞지 않으면 구멍을 새로 내야 해서 문에 흔적이 남습니다. / 이 부분은 [도어락 설치](doorlock-install.html) 상담 때 사진으로 먼저 확인해 드립니다.

# 비상 전원과 기계식 열쇠가 있는지
건전지가 다 됐을 때 바깥에서 전원을 넣을 수 있는 비상 단자가 있는지 꼭 보세요. / 9V 건전지 단자인지, 휴대폰 충전 단자인지도 제품마다 다릅니다.
비상 열쇠 구멍이 있는 제품은 번호판이 고장 나도 들어갈 길이 하나 더 있는 셈입니다. / 대신 열쇠 구멍이 있으면 그만큼 관리할 부분도 늘어나니 생활에 맞게 고르세요.

# 고른 뒤 설치하는 날 하는 일
설치가 끝나면 가족 모두의 번호, 지문, 카드를 그 자리에서 등록합니다. / 관리자 번호와 사용자 번호가 나뉘는 제품이라면 누가 관리자를 맡을지도 정합니다.
문을 열고 닫으며 자동 잠금이 제때 걸리는지, 안쪽 버튼으로 잘 열리는지 확인합니다. / 설명서는 버리지 말고 신발장 안쪽처럼 찾기 쉬운 곳에 두세요.

# 비용은 어떻게 안내하나요
제품 종류와 문 상태, 타공 작업이 필요한지에 따라 비용이 달라집니다. / 사진으로 문을 먼저 보고 대략을 말씀드리고, 현장에서 확인한 뒤 작업 전에 다시 정확히 안내합니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.
지금 도어락을 고쳐 쓸 수 있는 상태라면 굳이 바꾸시라고 권하지 않습니다. / 수리와 교체 중 무엇이 맞는지는 [도어락 수리](doorlock-repair.html), [도어락 교체](doorlock-replace.html) 페이지에서도 비교해 보실 수 있습니다.
@ 사근동 스마트 도어락 설치 후 지문 카드 등록

# 사근동 주변 성동구
사근동 가까이 마장동, 행당동, 왕십리동과 용답동, 송정동, 성수동, 응봉동, 금호동, 옥수동까지 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인하세요.
