# 왕십리동, 문이 열린 뒤 10분이 다음을 정합니다
왕십리동은 왕십리역을 중심으로 아파트와 오피스텔, 다세대, 상가가 함께 모여 있는 성동구의 한가운데 동네입니다. / 사람과 집이 많은 만큼 현관문이 잠겨 연락 주시는 경우도 시간대를 가리지 않습니다.
문이 열리면 대부분 안도의 한숨부터 쉬고 바로 집 안으로 들어가십니다. / 그런데 그 자리에서 10분만 같이 점검하면 같은 일로 다시 문 앞에 서는 일을 크게 줄일 수 있습니다.
이 글은 문을 연 직후 무엇을 확인하면 좋은지 차례대로 정리한 목록입니다. / 저희가 열어 드린 경우가 아니더라도 그대로 따라 해 보셔도 됩니다.
@ 왕십리동 현관문 개방 후 도어락 점검

# 원인을 한 줄로 적어 두기
가장 먼저 할 일은 이번에 왜 안 열렸는지를 짧게 남기는 것입니다. / "건전지 방전", "가족이 번호 변경", "안쪽 걸쇠", "모터 소리만 남"처럼 한 줄이면 충분합니다.
휴대폰 메모나 도어락 건전지 덮개 안쪽에 날짜와 함께 적어 두세요. / 몇 달 뒤 비슷한 일이 생겼을 때 이 기록이 원인을 바로 짚어 줍니다.
원인이 확실하지 않았다면 그것도 그대로 적어 두세요. / "원인 모름, 9V 대니 열림"처럼 남겨 두면 다음 점검 때 무엇을 볼지 정하기 쉽습니다.

# 잠금과 열림을 다섯 번씩 해 보기
문을 열어 둔 채로 안쪽에서 잠금 버튼을 눌러 막대가 시원하게 나오는지 보세요. / 그다음 문을 닫고 바깥에서 번호로 여는 동작을 몇 차례 반복합니다.
한 번은 되고 한 번은 안 된다면 아직 문제가 남아 있다는 뜻입니다. / 특히 모터 소리가 길게 끌리거나 중간에 멈칫하는 소리가 섞이면 그냥 넘기지 마세요.
문을 닫을 때 걸쇠가 문틀에 딸깍 하고 걸리는 소리가 또렷한지도 같이 들어 보세요. / 소리가 둔하면 문이 끝까지 닫히지 않고 있을 수 있습니다.

# 건전지는 전부, 같은 종류로
건전지 때문이었든 아니든 문을 연 날 건전지를 한꺼번에 새것으로 바꾸는 것을 권합니다. / 반만 바꾸면 헌 건전지가 새 건전지 힘까지 끌어내려 금방 다시 경고음이 납니다. / 충전식 건전지는 전압이 조금 낮아 도어락이 방전으로 잘못 알아듣기도 하니 일반 알칼라인을 쓰세요.
같은 종류, 같은 날 산 건전지를 한 묶음으로 넣으세요. / 덮개 안쪽에 교체한 날짜를 적어 두면 다음 교체 때를 잊지 않습니다.
@ 왕십리동 도어락 건전지 일괄 교체 날짜 기록

# 비밀번호와 카드, 지문 다시 정리
번호를 몰라 연 경우라면 새 번호를 등록하고 예전 번호가 지워졌는지 꼭 확인합니다. / 바깥에서 예전 번호를 눌러 봐서 안 열리면 제대로 지워진 것입니다.
등록된 카드나 지문 중 지금 쓰지 않는 것이 있다면 이참에 정리하세요. / 잃어버린 카드가 그대로 남아 있는 집이 생각보다 많습니다.
새 번호는 가족 모두가 한 번씩 직접 눌러 보게 하는 것이 좋습니다. / 말로만 전하면 다음 날 또 누군가 문 앞에서 막힙니다.

# 걸쇠와 데드볼트가 문틀에 닿는 자리
문을 열어 둔 채 문틀 쪽 걸쇠 받이 쇠판을 살펴보세요. / 한쪽에만 반짝이는 긁힌 자국이 있다면 걸쇠가 비스듬히 들어가고 있다는 뜻입니다.
이 상태가 이어지면 모터가 막대를 밀고 당길 때 힘이 더 들고, 결국 모터만 도는 증상으로 이어집니다. / 받이 위치를 조금 조정하는 것만으로 나아지는 경우가 많습니다.
받이 구멍 안에 먼지나 떨어진 나사가 들어 있지 않은지도 손전등으로 한 번 비춰 보세요. / 작은 이물질 하나가 막대 끝을 막아 잠김을 반쯤 걸리게 만들기도 합니다.

# 문 닫힘 속도와 경첩
문을 놓았을 때 저절로 끝까지 닫히는지, 마지막에 툭 걸리며 멈추는지 보세요. / 끝까지 닫히지 않으면 자동 잠금이 걸리지 않거나 걸쇠가 반만 걸린 채 남습니다.
문 위쪽 도어클로저에서 기름이 새거나 경첩 나사가 헐거우면 함께 손보는 편이 좋습니다. / 오래된 다세대 현관일수록 이 부분이 잠김 문제의 숨은 원인인 경우가 있습니다.

# 안쪽 보조 잠금은 어떻게 쓸지 정하기
이번 일이 안쪽 걸쇠나 보조키 때문이었다면 앞으로 언제 걸지 가족끼리 정해 두세요. / 예를 들어 밤에 모두 들어온 뒤에만 걸고, 낮에는 걸지 않는 식입니다.
아이가 손이 닿는 높이에서 걸쇠를 장난처럼 돌린다면 위치를 바꾸거나 잠금 방지 설정이 있는지 확인합니다.
혼자 사는 집이라면 걸쇠를 건 채 잠든 사이 아플 때 밖에서 들어오기 어렵다는 점도 생각해 두세요. / 걸쇠 대신 도어락의 이중 잠금 기능을 쓰는 것도 한 방법입니다.
오피스텔이나 원룸처럼 관리실이 있는 건물이라면 비상시 연락할 가족 번호를 관리실에 남겨 두는 것도 도움이 됩니다.

# 열쇠와 비상 수단 보관
비상 열쇠가 있는 도어락이라면 그 열쇠가 지금 어디 있는지 확인하세요. / 집 안 서랍에 있다면 정작 필요할 때 쓸 수 없습니다.
가족 한 명은 카드나 비상 열쇠를 지갑에 넣고 다니고, 9V 건전지 하나는 차나 가방에 넣어 두세요. / 이 두 가지만 있어도 문 앞에서 막히는 일이 크게 줄어듭니다.
여벌 카드는 열쇠고리처럼 눈에 띄게 달아 두지 마시고 지갑 안쪽에 넣어 두세요. / 잃어버렸을 때 어느 집 것인지 드러나지 않는 편이 낫습니다.

# 같은 일이 다시 생기면 기록이 도움이 됩니다
처음에 적어 둔 한 줄 기록을 두세 번 쌓이면 패턴이 보입니다. / 추운 날 아침에만, 비 온 다음 날에만, 누가 번호를 바꾼 뒤에만처럼 원인이 좁혀집니다.
점검을 부르실 때 이 기록을 보여 주시면 원인을 훨씬 빨리 찾습니다. / 같은 원인으로 세 번째라면 그때는 부품을 손볼 때입니다. / 반대로 한 번뿐이었다면 너무 걱정하지 않으셔도 됩니다.

# 수리와 교체는 서두르지 않기
문을 연 날 바로 도어락을 바꾸라는 권유는 하지 않습니다. / 건전지나 받이 조정으로 해결되는 경우가 많기 때문입니다.
반응이 계속 불안하면 [도어락 수리](doorlock-repair.html)로 해당 부분을 먼저 손보고, 부품을 구하기 어려울 만큼 오래된 제품일 때만 [도어락 교체](doorlock-replace.html)를 이야기합니다.
@ 왕십리동 걸쇠 받이 조정 문 닫힘 점검

# 처음 연락부터 개방까지는 이렇게
연락을 주시면 위치와 도어락 상태를 듣고 출발합니다. / 도착하면 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나로 사시는 분인지 먼저 봅니다.
문 상태를 보고 비용을 먼저 말씀드린 뒤 동의하시면 엽니다. / 끝내 열지 못하면 비용은 받지 않으며, 여는 방식은 [현관문 개문](door-open.html), 전체 순서는 [이용안내](guide.html)에 있습니다.

# 왕십리동 주변 성동구
왕십리동 가까이 행당동, 마장동, 사근동과 응봉동, 금호동, 옥수동, 성수동, 송정동, 용답동까지 갑니다. / 지역 안내는 [성동구 출장열쇠](seoul-seongdong.html)와 [출장 지역](area.html)에 있습니다.
