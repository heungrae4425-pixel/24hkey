# 왕십리동 집 안, 이번엔 방문이 말썽입니다
현관은 멀쩡한데 집 안 방문이나 화장실 문이 열리지 않는 일도 생각보다 자주 있습니다. / 왕십리역 생활권의 아파트와 다세대 집에서도 아이가 장난으로 손잡이 버튼을 누르고 문을 닫거나, 창문 바람에 방문이 쾅 닫히며 잠기는 일이 생깁니다.
현관문과 달리 방문은 집 안이라 덜 급해 보이지만, 안에 아이가 있다면 이야기가 달라집니다. / 화장실 안에서 아이가 울기 시작하면 부모 마음도 함께 다급해집니다.
이 글은 왕십리동 집에서 방문이나 화장실 문이 안에서 잠겼을 때 손잡이 모양별로 해볼 일과 연락할 때를 정리했습니다. / 안 되면 [성동 출장열쇠](seoul-seongdong.html)로 바로 전화 주세요.
@ 왕십리동 방문 손잡이 안쪽 잠금

# 안에 누가 있는지부터
가장 먼저 확인할 것은 문 안쪽에 사람이 있는지입니다. / 상황에 따라 서두를 정도가 크게 다릅니다.
- 아이가 안에 있고 스스로 못 여는 경우
- 어르신이 안에 계신데 대답이 없는 경우
- 사람은 없고 바람에 닫혀 잠긴 경우
- 반려동물만 안에 남은 경우
어르신이 대답이 없으시거나 아이가 다친 것 같다면 119에 먼저 연락하세요. / 단순히 잠긴 것이라면 아래 순서로 차분히 해 보시면 됩니다.

# 아이가 안에 있을 때 말 거는 법
아이가 놀라 울고 있으면 문 너머에서 차분한 목소리로 계속 이야기해 주세요. / 엄마 아빠가 바로 앞에 있다는 걸 알면 금방 진정합니다.
손잡이 가운데 버튼을 다시 누르거나 돌려 보라고 알려 주세요. / 대여섯 살 이상이면 이렇게 스스로 여는 경우가 꽤 있습니다.
못 하겠다고 하면 재촉하지 마세요. / 바닥에 앉아 기다리게 하고, 그동안 밖에서 여는 방법을 찾으면 됩니다.

# 손잡이 모양부터 확인하세요
방문 손잡이는 겉모습으로 잠금 방식을 어느 정도 짐작할 수 있습니다. / 바깥쪽 손잡이를 자세히 들여다보세요.
가운데 작은 구멍이 뚫려 있다면 비상 해제가 되는 제품일 가능성이 큽니다. / 일자 홈이 파여 있다면 동전이나 일자 드라이버로 돌려 푸는 구조인 경우가 많습니다.
아무 구멍도 홈도 없다면 바깥에서 쉽게 풀 수 없는 구조입니다. / 이때는 손잡이를 무리하게 돌리지 말고 연락 주세요.

# 작은 구멍이 있는 손잡이라면
작은 구멍형은 가늘고 곧은 막대를 똑바로 밀어 넣어 안쪽 버튼을 누르는 방식이 많습니다. / 일부 제품은 넣은 뒤 살짝 돌려야 풀리기도 합니다.
비상 해제용 작은 막대가 손잡이 포장에 함께 들어 있었을 수 있으니 서랍을 찾아보세요. / 없으면 펼친 클립처럼 가늘고 단단한 것을 쓰기도 합니다.
힘을 세게 주면 막대가 안에서 휘거나 부러질 수 있습니다. / 몇 번 해서 안 되면 멈추는 편이 낫습니다.
@ 왕십리동 화장실 문 손잡이 비상 해제 구멍

# 일자 홈이 있는 손잡이라면
화장실 손잡이에 많은 방식입니다. / 홈에 동전이나 일자 드라이버를 꽂고 천천히 돌리면 잠금이 풀립니다.
돌리는 방향은 제품마다 다르니 한쪽으로 안 되면 반대쪽으로 돌려 보세요. / 홈이 페인트나 때로 막혀 있으면 먼저 살살 긁어 내고 시도합니다.
동전이 홈보다 두꺼워 안 들어간다면 얇은 일자 드라이버가 낫습니다. / 돌릴 때 딸깍 하고 걸림이 풀리는 느낌이 오면 그 상태로 손잡이를 잡고 문을 밀어 보세요.

# 카드로 문틈을 밀어 보는 방법은
방문 걸쇠가 비스듬한 모양이면 얇은 카드를 문틈에 넣어 걸쇠를 밀어 여는 방법이 알려져 있습니다. / 실제로 일부 방문에서는 통하기도 합니다.
다만 문틈 마감재가 긁히고 카드가 부러져 틈에 끼는 일이 많습니다. / 아이가 안에 있어 마음이 급할 때는 오히려 시간만 더 걸립니다.
걸쇠 모양을 모르겠다면 이 방법은 건너뛰시는 것이 좋습니다. / 바로 연락 주시면 손잡이 모양을 듣고 맞는 방법을 말씀드립니다.

# 하지 말아야 할 것
방문을 발로 차거나 어깨로 들이받는 것은 피해 주세요. / 방문은 속이 빈 구조가 많아 쉽게 쪼개지고, 문틀까지 깨지면 공사가 커집니다.
손잡이를 펜치로 잡고 비트는 것도 안 됩니다. / 안쪽 축이 부러지면 바깥에서 여는 방법이 더 줄어듭니다.
아이에게 창문으로 나오라거나 높은 곳에 올라가 보라고 하지 마세요. / 조금 기다리더라도 안전한 방법을 쓰는 것이 우선입니다.
화장실 안에 아이가 있다면 물을 틀거나 세제를 만지지 않도록 일러 주세요. / 기다리는 동안 미끄러운 바닥에서 넘어지지 않게 가만히 앉아 있으라고 해 두시면 안심이 됩니다.

# 바람에 닫혀 잠긴 경우
왕십리동처럼 아파트 고층이나 큰길 쪽을 보는 집은 바람이 세게 드는 날이 있습니다. / 창문을 열어 둔 방에서 맞바람이 불면 방문이 세게 닫히며 버튼이 눌린 채로 잠기기도 합니다. / 안에 사람이 없으니 급하진 않지만, 그 방에 휴대폰이나 지갑을 두셨다면 곤란합니다.
같은 일이 반복된다면 문 아래에 문 멈춤 장치를 두거나 버튼이 없는 손잡이로 바꾸는 것을 생각해 보세요. / 아이가 있는 집은 잠금이 아예 없는 손잡이가 오히려 편할 수 있습니다.

# 연락하실 때 알려 주실 것
아래를 알려 주시면 전화로 먼저 해볼 방법을 말씀드리거나 맞는 장비를 챙겨 갑니다. / 가능하면 손잡이 사진을 문자로 보내 주세요.
- 방문인지 화장실 문인지
- 바깥 손잡이에 구멍이나 홈이 있는지
- 안에 아이, 어르신, 반려동물이 있는지
- 왕십리동 주소와 동 호수, 건물 이름
아이가 안에 혼자 있다면 그 사실부터 말씀해 주세요. / 순서를 앞당겨 갑니다.
@ 왕십리동 출장열쇠 방문 잠김 사진 확인

# 출장 시 확인과 비용
방문이라도 집 안에 들어가 작업하는 것이라 사시는 분이 맞는지 확인합니다. / 이미 집 안에 계신 경우가 대부분이라 신분증이나 우편물로 간단히 확인합니다.
비용은 손잡이와 문 상태를 본 뒤 시작 전에 먼저 말씀드립니다. / 열지 못하면 받지 않고, 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 연 뒤에 손잡이를 어떻게 할지
연 뒤에는 손잡이 잠금이 다시 제대로 풀리는지 확인합니다. / 버튼이 제멋대로 눌리는 손잡이라면 바꾸시는 편이 낫습니다.
아이 방과 화장실은 바깥에서 쉽게 풀 수 있는 손잡이로 바꾸는 것을 권해 드립니다. / 현관 도어락도 함께 봐 드릴 수 있으니 [도어락 수리](doorlock-repair.html)나 [현관문 개문](door-open.html)도 참고해 보세요.

# 왕십리동 말고 성동구 전역에 갑니다
왕십리동과 붙은 행당동, 마장동, 사근동을 비롯해 금호동, 옥수동, 성수동, 응봉동, 송정동, 용답동까지 다닙니다. / 방문이나 화장실 문 하나 때문에도 출동합니다.
지역 안내는 [성동구 출장열쇠](seoul-seongdong.html)와 [출장 지역](area.html)에서 보실 수 있습니다.
