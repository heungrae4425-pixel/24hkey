# 방이동 집 안에서 문 하나가 안 열릴 때
현관은 멀쩡한데 집 안의 방문이나 화장실 문이 안 열려서 연락 주시는 분이 꽤 있습니다. / 청소하다 문이 닫혔는데 손잡이 버튼이 눌려 있었다거나, 아이가 안에서 잠그고 못 푸는 경우가 대표적입니다.
방이동은 빌라와 상가 건물이 골목을 따라 이어지고 아파트도 함께 있는 동네라, 집마다 방문 손잡이가 제각각입니다. / 손잡이 모양만 알아도 직접 풀 수 있는지 금방 가늠이 됩니다.
이 글은 방이동에서 방문이나 화장실 문이 안에서 잠겼을 때 손잡이 종류별로 해 볼 일과 [송파구 출장열쇠](seoul-songpa.html)를 부르는 때를 정리했습니다.
@ 방이동 방문 화장실 문 안에서 잠김

# 안에 사람이 있는지부터 확인하세요
가장 먼저 볼 것은 문 너머에 누가 있느냐입니다. / 아무도 없는 빈 방이 잠긴 것이라면 시간을 두고 천천히 해결해도 됩니다.
아이나 어르신이 안에 있다면 이야기가 다릅니다. / 문 너머로 계속 말을 걸어 주면서 안에서 손잡이 가운데 버튼을 다시 눌러 보거나 돌려 보라고 차분히 알려 주세요.
화장실 안에서 몸이 불편해 쓰러진 것 같다거나 대답이 없다면 열쇠보다 119 신고가 먼저입니다. / 문 여는 일은 그다음에 생각해도 늦지 않습니다.

# 우리 집 방문 손잡이는 어떤 모양인가요
- 둥근 손잡이 가운데 누름 버튼이 있는 형
- 레버형 손잡이 안쪽에 작은 돌림 꼭지가 있는 형
- 열쇠 구멍이 바깥에 따로 있는 형
- 미닫이 방문에 걸쇠만 달린 형
바깥쪽 손잡이 가운데를 보세요. / 작은 구멍이나 일자 홈이 보인다면 비상용으로 풀 수 있게 만든 손잡이일 가능성이 높습니다.
오래된 빌라는 처음 지을 때 달아 둔 손잡이를 그대로 쓰는 집이 많습니다. / 반대로 최근에 집을 고친 곳은 레버형이나 디자인 손잡이로 바뀌어 비상 구멍 위치가 아래쪽이나 옆면에 숨어 있기도 하니 손잡이 둘레를 한 바퀴 살펴보세요.

# 바깥에 작은 구멍이 있다면
누름 버튼형 방문은 바깥 손잡이 가운데에 작은 구멍이 있는 경우가 많습니다. / 여기에 가늘고 곧은 막대를 똑바로 밀어 넣으면 안쪽 버튼이 튕겨 나오며 풀립니다.
펴진 클립이나 얇은 육각렌치처럼 끝이 뭉툭한 것이 좋습니다. / 이쑤시개나 나무 꼬치는 안에서 부러질 수 있어서 피하세요.
밀어 넣은 채로 손잡이를 돌려야 풀리는 제품도 있습니다. / 한 손으로는 막대를 누르고 다른 손으로 손잡이를 천천히 돌려 보세요.

# 일자 홈이 있는 손잡이
구멍 대신 일자 홈이 있다면 동전이나 일자 드라이버 끝을 넣고 돌리는 방식입니다. / 홈에 꼭 맞는 크기를 골라야 홈이 뭉개지지 않습니다.
돌리는 방향을 모르겠다면 양쪽으로 아주 조금씩만 힘을 줘 보세요. / 한쪽이 부드럽게 돌아가면 그쪽이 맞는 방향입니다.
@ 방이동 방문 손잡이 비상 해제 구멍

# 화장실 문은 왜 더 자주 말썽일까
화장실은 습기가 많아 손잡이 안쪽 스프링과 걸쇠가 빨리 녹습니다. / 처음에는 버튼이 뻑뻑하다가 어느 날 눌린 채로 안 돌아오면서 문이 잠긴 채 닫히는 일이 생깁니다.
샤워 뒤 문을 꽉 닫아 두는 습관이 있다면 문짝도 습기를 먹어 조금 부풉니다. / 이러면 걸쇠가 풀려도 문이 문틀에 끼어 잘 안 열립니다.
이때는 손잡이를 돌린 채 문을 몸 쪽으로 살짝 당기거나 밀어 보면 빠지기도 합니다.
겨울에는 반대로 문짝이 마르면서 걸쇠와 문틀 구멍 위치가 어긋나 버튼이 제대로 안 걸리기도 합니다. / 계절마다 손잡이 느낌이 달라진다면 걸쇠 받이 쪽 조정이 필요하다는 뜻입니다.

# 문틈 공략은 생각보다 위험합니다
방문은 현관보다 틈이 넓어 플라스틱 카드를 넣어 걸쇠를 밀어 보려는 분이 많습니다. / 비스듬한 걸쇠라면 되기도 하지만 대부분은 문틀 칠만 벗겨집니다.
칼이나 드라이버로 틈을 벌리면 문 가장자리가 쪼개질 수 있습니다. / 세 들어 사는 집이라면 원상 복구 문제까지 생기니 더 조심하세요.
경첩 핀을 뽑아 문짝을 떼어 내는 방법도 있지만 문짝이 무거워 다치기 쉽습니다. / 혼자서는 권하지 않습니다.

# 이럴 때는 직접 하지 말고 불러 주세요
- 바깥에 비상 구멍이나 홈이 아예 없는 손잡이
- 비상 구멍에 막대를 넣어도 아무 반응이 없는 경우
- 안에 아이가 있는데 겁을 먹고 울고 있는 경우
- 손잡이가 헛돌거나 덜렁거리는 경우
아이가 안에 있다면 전화하실 때 꼭 먼저 말씀해 주세요. / 그런 연락은 가장 앞에 두고 움직입니다.

# 방이동에서 전화 주실 때 알려 주실 것
- 아파트인지 빌라인지, 동과 호수 또는 건물 주소
- 잠긴 문이 방문인지 화장실 문인지
- 바깥 손잡이 모양과 구멍이나 홈이 있는지
- 안에 사람이나 반려동물이 있는지
손잡이 사진을 문자로 보내 주시면 맞는 도구를 챙겨 갑니다. / 방문 손잡이는 종류가 많아서 사진이 있으면 시간이 줄어듭니다.
바깥쪽과 문 옆면 걸쇠가 보이는 쪽을 각각 한 장씩 찍어 주시면 가장 좋습니다. / 상가 건물 위층 집이라면 출입구 위치도 함께 알려 주세요.

# 도착하면 거주 확인을 먼저 합니다
방문이라도 집 안에서 하는 작업이라 그 집에 사시는 분인지 확인합니다. / 신분증, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
집 안이라 서류를 꺼내 보여 주시기 쉬운 편입니다. / 미리 탁자 위에 꺼내 두시면 바로 시작할 수 있습니다.
다만 서류를 둔 방이 하필 잠긴 방이라면 관리사무소나 집주인 확인으로 대신합니다. / 이런 경우도 흔하니 걱정하지 말고 전화로 미리 말씀해 주세요.

# 비용은 열기 전에 알려 드립니다
손잡이 종류와 문 상태를 본 뒤 비용을 먼저 말씀드리고, 괜찮다고 하시면 시작합니다. / 끝내 열지 못하면 받지 않습니다.
손잡이를 바꿔야 할 정도로 녹슬었다면 그것도 따로 여쭤본 뒤에 진행합니다. / 진행 방식은 [이용안내](guide.html)에서 보실 수 있습니다.
@ 방이동 출장열쇠 방문 개문 손잡이 교체

# 같은 일이 또 생기지 않게
- 아이 방과 화장실은 바깥에서 풀 수 있는 손잡이로 쓰기
- 비상 해제용 막대를 문 위 틀 같은 높은 곳에 올려 두기
- 화장실 손잡이 버튼이 뻑뻑해지면 미리 바꾸기
- 샤워 뒤에는 문을 조금 열어 습기 빼기
현관 도어락도 같이 손보고 싶다면 [도어락 수리](doorlock-repair.html)와 [현관문 개문](door-open.html) 안내를 함께 보세요. / 현관 도어락이 오래돼 새로 달 생각이라면 [도어락 교체](doorlock-replace.html)도 참고하실 수 있습니다.
