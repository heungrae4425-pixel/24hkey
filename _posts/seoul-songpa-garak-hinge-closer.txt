# 가락동 현관문이 한 뼘 남기고 멈출 때
가락시장역 쪽 대단지에 사는 분들 가운데 현관문이 끝까지 닫히지 않는다는 이야기를 하시는 분이 있습니다. / 손을 놓으면 문이 스르르 오다가 마지막에 툭 멈추고, 도어락 잠금이 안 걸립니다.
바쁜 아침에는 그냥 나갔다가 저녁에 문이 살짝 열려 있는 걸 보고 놀라기도 합니다. / 반대로 문이 너무 세게 닫혀 쾅 소리가 복도에 울리는 집도 있습니다.
두 증상 모두 대개 문 위에 달린 도어클로저나 옆쪽 경첩에서 시작됩니다. / 이 글은 가락동에서 문이 덜 닫히거나 세게 닫힐 때 살펴볼 곳을 정리했고, 문이 아예 안 열리면 [송파구 출장열쇠](seoul-songpa.html)로 연락하시면 됩니다.
@ 가락동 현관문 도어클로저 경첩 점검

# 도어클로저가 하는 일
현관문 위쪽 안쪽에 달린 길쭉한 장치가 도어클로저입니다. / 문을 놓으면 천천히 끌어당겨 닫아 주는 역할을 합니다.
안에는 기름과 스프링이 들어 있어서 문이 닫히는 속도를 단계별로 조절합니다. / 처음엔 빠르게, 마지막 구간에선 천천히 닫히게 맞춰져 있는 경우가 많습니다.
이 속도가 틀어지면 문이 덜 닫히거나 반대로 세게 부딪힙니다. / 오래 쓰면 기름이 새거나 스프링 힘이 약해져서 같은 증상이 나타납니다.

# 덜 닫힘인지 걸림인지 먼저 구분하기
문이 닫히다 멈추는 이유는 두 가지로 나뉩니다. / 도어클로저 힘이 모자란 경우와, 문이 어딘가에 걸리는 경우입니다.
멈춘 문을 손가락 하나로 살짝 밀어 보세요. / 가볍게 닫히며 잠금이 걸리면 도어클로저 쪽이고, 손에 힘이 들어갈 만큼 뻑뻑하면 걸림 쪽입니다.
걸림이라면 문틀 위아래 어디에 닿는지, 걸쇠가 받이 구멍에 안 맞는지를 봐야 합니다. / 문 가장자리와 문틀에 생긴 긁힌 자국이 단서가 됩니다.

# 경첩 처짐은 틈으로 확인합니다
현관문은 무게가 있어서 오래 쓰면 경첩이 조금씩 닳아 문짝이 아래로 처집니다. / 문을 닫고 위쪽 틈과 아래쪽 틈, 손잡이 쪽 세로 틈을 눈으로 비교해 보세요.
손잡이 쪽 위 틈은 넓은데 아래 틈이 좁다면 처짐을 의심할 수 있습니다. / 이 상태로는 걸쇠가 받이 구멍 아래쪽에 부딪혀 잠금이 잘 안 걸립니다.
경첩 나사가 헐거워진 것만으로도 비슷한 증상이 납니다. / 경첩 쪽 나사를 맞는 드라이버로 살짝 조여 보는 정도는 직접 해 볼 수 있지만 세게 돌려 나사산을 망가뜨리지는 마세요.
@ 송파 가락동 현관문 경첩 처짐 틈 확인

# 쾅 닫히는 문은 속도 조절부터
문이 너무 세게 닫히면 도어락 걸쇠와 받이가 빨리 닳습니다. / 아이 손이 끼일 수 있어 위험하기도 합니다.
도어클로저 몸통 옆이나 끝에는 속도를 조절하는 작은 나사가 있습니다. / 제품에 따라 1번, 2번처럼 구간별 나사가 따로 있습니다.
한 번에 크게 돌리지 말고 4분의 1바퀴씩 돌려 보며 맞추는 게 원칙입니다. / 너무 많이 풀면 안에 든 기름이 새어 나와 장치를 통째로 바꿔야 할 수 있습니다.
어느 나사인지 확실치 않다면 손대지 않는 편이 안전합니다.

# 기름이 샌 자국이 보이면
도어클로저 아래 문짝이나 바닥에 기름 얼룩이 있다면 안쪽 밀봉이 상한 것입니다. / 이 경우 속도 나사를 돌려도 금방 다시 빨라지거나 힘이 빠집니다.
기름이 샌 장치는 고쳐 쓰기보다 바꾸는 게 일반적입니다. / 같은 크기와 힘을 가진 제품을 골라야 문에 맞으니 혼자 사기 전에 모델을 확인해 보세요.

# 걸쇠 위치가 어긋난 경우
문을 닫았을 때 도어락에서 나오는 걸쇠가 받이 구멍에 정확히 들어가야 잠금이 걸립니다. / 받이가 살짝 위나 아래로 어긋나면 걸쇠가 문틀 쇠판에 닿아 멈춥니다.
받이 쇠판에 반짝이게 닳은 자국이 한쪽으로 쏠려 있다면 어긋남의 흔적입니다. / 받이 위치를 조금 옮기거나 구멍을 다듬는 작업으로 해결되기도 합니다.
도어락을 새로 단 뒤부터 덜 닫힌다면 설치할 때 걸쇠 높이가 예전과 달라졌을 수 있습니다. / 이럴 땐 도어클로저를 손보기 전에 받이부터 맞춰 보는 게 순서입니다.
@ 가락동 도어락 걸쇠 받이 어긋남 확인

# 겨울과 여름에 달라지는 이유
날씨가 추우면 도어클로저 안 기름이 굳어서 문이 평소보다 천천히 닫힙니다. / 여름에는 반대로 기름이 묽어져 빨리 닫히는 집이 있습니다.
계절마다 조금씩 달라지는 정도는 자연스러운 일입니다. / 하지만 같은 계절 안에서 갑자기 바뀌었다면 장치 문제를 의심하는 게 맞습니다.
아파트는 현관 밖 복도와 집 안 공기 흐름 차이 때문에 바람이 문을 밀거나 당기기도 합니다. / 창문을 열어 둔 날만 문이 덜 닫힌다면 도어클로저보다 실내 바람 영향일 가능성이 큽니다.
그런 날엔 창을 조금 닫고 다시 문을 놓아 보세요. / 그래도 똑같이 멈춘다면 그때 장치 쪽을 의심하면 됩니다.

# 이럴 땐 손대지 말고 부르세요
- 문이 처져서 바닥에 끌리는 소리가 나는 경우
- 도어클로저 팔이 빠지거나 덜렁거리는 경우
- 기름이 흘러 문짝을 타고 내려오는 경우
- 덜 닫힌 채로 잠금이 아예 안 걸리는 경우
이런 상태에서 억지로 문을 세게 밀면 경첩이나 팔 부품이 더 휘어집니다. / [도어락 수리](doorlock-repair.html)에서 도어클로저와 경첩, 걸쇠를 함께 봐 드립니다.

# 가락동에서 연락 주실 때
대단지는 동 번호가 많아 단지 이름과 동, 호수를 알려주셔야 빨리 찾습니다. / 아래 내용도 같이 말씀해 주세요.
- 문이 덜 닫히는지, 세게 닫히는지, 아예 안 열리는지
- 도어클로저에 기름 자국이 있는지
- 언제부터 그랬는지, 갑자기인지 서서히인지
문 위쪽 장치와 경첩을 찍은 사진이 있으면 판단이 훨씬 빠릅니다.
@ 가락동 도어클로저 속도 조절 출장 점검

# 문을 열어야 하는 상황이라면
덜 닫힘이 심해져 걸쇠가 문틀에 끼어 문이 안 열리는 경우도 있습니다. / 이때는 사시는 분인지 신분증 주소, 우편물, 관리사무소 확인 중 하나로 먼저 확인합니다.
얼마가 드는지는 작업 전에 말씀드리고 동의하실 때 시작합니다. / 끝내 못 열면 비용을 받지 않으며, 순서는 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 있습니다.

# 교체가 꼭 필요한지는 따져 봅니다
도어클로저나 받이 조정만으로 해결되면 도어락은 그대로 씁니다. / 걸쇠가 오래 부딪혀 도어락 내부까지 상했다면 그때 [도어락 교체](doorlock-replace.html)를 함께 이야기합니다.

# 가락동 말고 송파 어디든 갑니다
문정동, 송파동, 석촌동, 오금동, 잠실동, 신천동, 방이동, 장지동, 풍납동, 거여동, 마천동도 다닙니다. / 다른 지역은 [출장 지역](area.html)을 확인해 주세요.
