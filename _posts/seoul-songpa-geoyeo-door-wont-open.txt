# 거여동 현관 앞에서 무엇이 막고 있는지
거여역 둘레 거여동은 아파트와 빌라, 주택이 함께 있는 송파구 동쪽 동네입니다. / 집 모양이 다양한 만큼 현관문이 안 열리는 이유도 집마다 조금씩 다릅니다.
문이 안 열릴 때는 무작정 번호를 다시 누르기보다 어디가 막고 있는지부터 나눠 보는 게 빠릅니다. / 크게 보면 번호판 쪽, 손잡이와 걸쇠 쪽, 문틀과 보조 잠금 쪽 세 갈래입니다.
이 글은 거여동에서 현관문이 안 열릴 때 세 갈래로 나눠 원인을 짚는 방법과, 손으로 안 될 때 [송파구 출장열쇠](seoul-songpa.html)를 부르는 순서를 정리했습니다.
@ 거여동 현관문 안 열림 원인 확인

# 첫 번째 갈래, 번호판이 말을 듣는지
번호판에 손을 대 보세요. / 불이 들어오고 숫자를 누를 때마다 소리가 난다면 번호판은 살아 있는 겁니다.
아무 반응이 없다면 전원 문제입니다. / 바깥 아래쪽 비상 단자에 9V 건전지를 대고 번호를 눌러 보세요.
불은 들어오는데 숫자 몇 개만 안 눌린다면 번호판 안쪽 접점이 닳았거나 물기가 들어간 경우입니다. / 마른 천으로 닦고 잠시 기다렸다가 다시 눌러 보세요.
번호판 불이 켜졌다 꺼지기를 되풀이한다면 건전지 힘이 바닥 근처에서 오르내리는 겁니다. / 이럴 때도 비상 전원을 함께 대고 누르면 한 번에 열리는 경우가 많습니다.

# 번호가 맞는지 다시 한 번 의심해 보기
번호판이 멀쩡한데 틀렸다는 소리만 난다면 번호 자체를 의심해 볼 차례입니다. / 가족이 최근에 번호를 바꾸지 않았는지 단체방이나 문자를 찾아보세요.
여러 번 틀리면 도어락이 한동안 입력을 막습니다. / 서너 번에서 멈추고, 생각나는 번호를 종이에 적어 하나씩 지워 가며 시도하는 편이 낫습니다.
- 예전 집 번호나 차 번호, 생일 같은 자주 쓰는 숫자
- 번호 앞뒤에 덧붙여 둔 숫자가 있었는지
- 번호를 누른 뒤 마지막에 별표나 확인 버튼을 눌러야 하는지

# 두 번째 갈래, 걸쇠가 빠지는 소리가 나는지
번호가 맞으면 도어락 안에서 모터가 돌며 걸쇠를 당기는 소리가 납니다. / 그 소리가 나는데도 문이 안 열린다면 걸쇠가 문틀에 눌려 빠지지 못하는 경우가 많습니다.
문을 안쪽으로 살짝 밀면서 다시 번호를 눌러 보세요. / 걸쇠에 걸린 힘이 풀리면서 열리는 일이 흔합니다.
모터 소리가 평소보다 짧거나 약하다면 건전지가 거의 다 된 겁니다. / 비상 전원을 함께 대고 눌러 보면 차이가 납니다.
@ 거여동 도어락 걸쇠 모터 소리

# 손잡이가 헛도는지, 뻑뻑한지
손잡이 일체형 도어락은 번호가 맞아도 손잡이를 돌려야 문이 열립니다. / 손잡이가 아무 저항 없이 빙빙 돈다면 안쪽 연결 부품이 풀리거나 부러진 겁니다.
반대로 손잡이가 너무 뻑뻑해 안 돌아간다면 걸쇠가 문틀에 끼어 있거나 손잡이 축이 휘었을 수 있습니다. / 억지로 비틀면 축이 더 휘니 세게 돌리지 마세요.
푸시풀 도어락이라면 손잡이를 미는 방향과 당기는 방향을 한 번씩 바꿔 보세요. / 제품마다 여는 동작이 조금씩 다릅니다.

# 세 번째 갈래, 문틀과 문짝 상태
번호판도 손잡이도 정상인데 문이 안 열린다면 문 자체를 봐야 합니다. / 문이 처져서 아래쪽이 바닥에 닿거나, 위쪽이 문틀에 끼어 있으면 걸쇠가 빠져도 문이 안 움직입니다.
문과 문틀 사이 틈을 위아래로 훑어보세요. / 한쪽은 넓고 한쪽은 거의 붙어 있다면 경첩이 처진 겁니다.
여름에는 습기로 문짝이 부풀고, 겨울에는 바닥과 문틀이 수축하면서 맞물림이 달라지기도 합니다. / 계절 따라 유독 뻑뻑해진다면 이 경우일 가능성이 큽니다.
오래된 주택이나 빌라는 건물이 조금씩 내려앉으면서 문틀 자체가 기울기도 합니다. / 이런 집은 문을 살짝 들어 올리듯 당기면서 손잡이를 돌리면 열리기도 하지만, 몇 번 해도 안 된다면 그만두세요.

# 보조키나 걸쇠가 걸려 있지는 않은지
도어락은 열리는 소리가 났는데 문이 꿈쩍 않는다면 열쇠로 잠그는 보조키가 잠긴 경우도 있습니다. / 마지막으로 나간 가족이 습관처럼 돌렸을 수 있으니 먼저 전화해 보세요.
문이 조금 열리다 멈춘다면 안쪽 걸쇠가 걸린 겁니다. / 안에 누군가 있다면 문을 살짝 닫은 뒤 걸쇠를 풀어 달라고 하세요.
아무도 없는 집에서 걸쇠가 걸렸다면 문이 닫히는 충격에 고리가 저절로 넘어간 경우입니다. / 이때는 틈으로 손을 넣지 말고 바로 연락 주시는 게 안전합니다.

# 이 단계에서는 손을 떼세요
- 드라이버나 카드로 문틈 벌리기
- 손잡이를 발로 차거나 몸으로 밀기
- 번호판 덮개를 열고 안쪽 만지기
- 열쇠 구멍에 맞지 않는 열쇠 넣기
세 갈래를 다 봤는데도 안 열린다면 혼자 할 수 있는 일은 거의 끝난 겁니다. / 그때부터 무리하면 문과 도어락 수리 범위만 넓어집니다.
특히 문틈을 벌리다 생긴 흠은 나중에 도어락을 바꿔도 그대로 남습니다. / 세 들어 사는 집이라면 퇴거할 때 이야기가 될 수 있으니 더 조심하세요.

# 거여동에서 전화하실 때 정리해 주실 것
- 아파트 동과 호수, 빌라나 주택이라면 주소
- 세 갈래 중 어디에서 막혔는지
- 번호판 불빛, 모터 소리, 손잡이 느낌
- 안에 아이나 반려동물이 있는지
위에서 확인한 내용을 말씀해 주시면 원인을 거의 짐작한 채로 출발할 수 있습니다. / 도어락 앞면 사진이 있으면 더 좋습니다.

# 확인 절차를 거친 뒤 엽니다
문을 열기 전 그 집에 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 집주인 확인 중 하나면 됩니다.
서류가 집 안에 있다면 문을 연 직후 확인하는 방법도 함께 정합니다. / 확인 없이는 열지 않습니다.
번거롭게 느껴지실 수 있지만, 같은 방법으로 다른 사람이 문을 열지 못하게 막는 절차입니다.

# 원인을 본 뒤 비용을 먼저 안내합니다
원인과 문 상태를 본 뒤 비용을 먼저 말씀드리고, 괜찮다고 하시면 시작합니다. / 끝내 열지 못하면 받지 않습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html), 개문 방식은 [현관문 개문](door-open.html)에 있습니다.
@ 거여동 출장열쇠 현관문 개문 비용 안내

# 열린 뒤 원인에 맞게 손봅니다
번호판 쪽이 원인이었다면 건전지와 접점을 손보고 새 번호 등록을 도와드립니다. / 걸쇠와 손잡이 쪽이었다면 부품 상태를 보고 [도어락 수리](doorlock-repair.html)로 해결할 수 있는지 먼저 봅니다.
문틀과 경첩이 원인이라면 문 맞물림을 조정합니다. / 도어락이 너무 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 거여동 가까운 송파구 동네
마천동, 오금동, 장지동, 문정동, 가락동, 방이동, 송파동, 석촌동, 잠실동, 신천동, 풍납동까지 다닙니다. / 다른 지역은 [출장 지역](area.html)을 보세요.
