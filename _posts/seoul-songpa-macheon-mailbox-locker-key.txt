# 마천동, 작은 열쇠 하나가 사라졌을 때
현관 열쇠는 늘 챙기지만 우편함이나 사물함 열쇠는 어디 뒀는지 잊기 쉽습니다. / 이사 올 때 받은 작은 열쇠를 서랍 어딘가에 넣어 두고 몇 달 뒤에 찾으면 보이지 않습니다.
마천동은 송파구 안에서도 빌라와 주택, 아파트가 함께 있는 동네라 우편함 모양도 건물마다 다릅니다. / 집 안에도 서랍장, 신발장 사물함, 작은 금고형 캐비닛처럼 열쇠를 쓰는 가구가 있습니다.
이 글은 마천동에서 우편함이나 사물함 열쇠를 잃어버렸을 때, 혹은 열쇠가 안 돌아갈 때 해볼 것을 정리했습니다. / 현관까지 막혔다면 [송파구 출장열쇠](seoul-songpa.html)로 바로 연락 주세요.
@ 마천동 우편함 사물함 열쇠 분실

# 우편함 열쇠는 누가 갖고 있을까
빌라 1층 우편함은 건물을 지을 때 함께 달린 경우가 많습니다. / 열쇠는 보통 세대마다 한두 개씩 나눠 주고, 집주인이나 관리인이 여분을 갖고 있기도 합니다.
세입자라면 먼저 집주인에게 여분 열쇠가 있는지 물어보세요. / 이전 세입자가 열쇠를 반납하지 않고 나간 경우라면 집주인도 그 사실을 알고 있을 수 있습니다.
아파트 우편함은 관리사무소가 여분 열쇠나 열쇠 번호를 관리하는 곳이 있습니다. / 관리사무소에 세대 확인을 받고 문의해 보는 게 가장 빠릅니다.

# 우편함 열쇠 번호를 찾아보세요
작은 자물쇠 중에는 열쇠 몸통이나 자물쇠 앞면에 번호가 새겨진 제품이 있습니다. / 같은 번호로 맞는 열쇠를 다시 만들 수 있는 경우가 있어 번호가 있다면 사진을 찍어 두세요.
번호가 지워졌거나 아예 없는 제품이라면 자물쇠 뭉치를 새것으로 바꾸는 편이 깔끔합니다. / 우편함 자물쇠는 대부분 규격이 단순해서 교체가 어렵지 않습니다.
바꿀 때는 우편함 문 두께와 자물쇠 구멍 크기, 걸쇠가 돌아가는 방향을 맞춰야 합니다. / 같은 건물 다른 칸과 모양을 맞추고 싶다면 이웃 칸 사진을 참고로 보여 주셔도 됩니다.
번호식 자물쇠로 바꾸는 집도 있습니다. / 열쇠를 또 잃어버릴 걱정이 없지만, 번호를 가족끼리 함께 알아 두어야 합니다.
@ 마천동 우편함 자물쇠 교체 규격 확인

# 열쇠는 있는데 안 돌아갈 때
우편함은 건물 1층 입구나 바깥에 있어 먼지와 습기를 그대로 맞습니다. / 오래 안 쓰다 보면 작은 자물쇠 안이 굳어서 열쇠가 끝까지 안 들어가거나 안 돌아갑니다.
열쇠를 뺐다가 다시 꽂고 위아래로 살짝 흔들며 천천히 돌려 보세요. / 작은 열쇠는 쉽게 휘거나 부러지니 손목에 힘을 빼고 해야 합니다.
일반 기름은 먼지를 붙잡아 더 굳게 만듭니다. / 건조형 윤활제가 없다면 연필심 가루를 열쇠 홈에 문질러 꽂아 보는 방법도 있습니다.
@ 송파 마천동 빌라 우편함 자물쇠 열쇠 구멍

# 우편함을 억지로 열면
급하게 중요한 우편물을 꺼내야 할 때 드라이버로 우편함 문을 젖히는 분이 있습니다. / 얇은 철판이라 한 번 휘면 원래대로 펴지지 않고, 이웃 우편함까지 같이 휘기도 합니다.
공용으로 쓰는 우편함 묶음은 건물 공용 설비라서 내 칸이라도 망가뜨리면 집주인과 이야기할 일이 생깁니다. / 급하다면 우편물 투입구로 보이는 우편물만 조심히 꺼내 보고, 나머지는 자물쇠를 손본 뒤에 꺼내세요.

# 중요한 우편물이 걱정된다면
우편함 열쇠를 잃어버린 기간에 카드 명세서나 공과금 고지서가 쌓이면 신경이 쓰입니다. / 그동안은 우편물을 전자 고지서로 바꿔 두는 것도 방법입니다.
열쇠를 잃어버린 장소가 집 밖이라면 우편함 자물쇠를 바꾸는 쪽을 권합니다. / 누군가 주운 열쇠로 우편함을 열 수 있는 상태로 두지 않는 게 마음 편합니다.

# 집 안 사물함과 서랍장 열쇠
신발장이나 붙박이장 속 작은 사물함, 책상 서랍장에도 열쇠가 달려 있습니다. / 이런 가구용 자물쇠는 처음 살 때 받은 열쇠 두 개가 전부인 경우가 많습니다.
열쇠가 없을 때 서랍을 억지로 당기면 앞판이 쪼개지거나 레일이 휩니다. / 서랍 위쪽에 틈이 있다면 손전등으로 비춰 안쪽 걸쇠 모양을 확인해 보세요.
가구 자물쇠는 대체로 구조가 단순해서 출장 때 함께 열어 드릴 수 있습니다. / 연 다음 같은 크기의 자물쇠로 바꿔 열쇠를 새로 받는 방법도 있습니다.
@ 마천동 서랍장 사물함 가구 자물쇠 열기

# 작은 금고나 잠금 캐비닛
번호와 열쇠를 함께 쓰는 작은 금고나 문서 캐비닛은 일반 사물함과 다릅니다. / 제품마다 구조가 달라 현장에서 보고 가능한 방법을 말씀드립니다.
금고는 구매 증빙이나 설명서가 있으면 함께 보여 주세요. / 본인 물건이라는 확인이 필요하고, 확인이 어려우면 작업을 하지 않습니다.

# 사무실 캐비닛과 직원 사물함
사무실 직원용 사물함은 열쇠를 개인이 갖고 있다가 퇴사하면서 반납하지 않는 일이 생깁니다. / 마스터 열쇠가 있는 제품인지 먼저 확인해 보세요.
마스터 열쇠가 없다면 칸마다 자물쇠를 바꾸는 방법이 있습니다. / 회사 쪽 담당자 확인이 있어야 작업을 진행합니다.
앞으로를 위해 칸 번호와 열쇠 번호를 적은 목록을 하나 만들어 두세요. / 사람이 바뀔 때 열쇠를 받았는지 체크만 해도 같은 일이 크게 줄어듭니다.
운동 시설이나 공용 시설의 사물함이라면 그곳 관리자에게 먼저 말하는 게 순서입니다. / 시설 물건이라 이용자가 직접 출장을 부르는 경우는 드뭅니다.

# 마천동에서 연락 주실 때
- 마천동 안 건물 이름이나 도로명 주소
- 우편함인지, 집 안 사물함인지, 사무실 캐비닛인지
- 열쇠를 잃어버렸는지, 있는데 안 돌아가는지
- 자물쇠 앞면이나 열쇠 번호 사진
작은 자물쇠도 모양이 다양해서 사진이 있으면 맞는 부품을 챙기기 쉽습니다.

# 확인 절차와 비용
우편함은 그 집에 사시는 분인지, 사물함과 캐비닛은 물건 주인인지 먼저 확인합니다. / 신분증 주소, 우편물, 집주인이나 관리사무소 확인 가운데 하나면 됩니다.
상태를 보고 얼마인지 먼저 말씀드리고 동의하시면 시작합니다. / 끝내 열지 못하면 비용은 받지 않으며, 진행 순서는 [이용안내](guide.html)에 있습니다.

# 열쇠 복사와 자물쇠 교체
열쇠가 하나 남아 있다면 미리 복사해 두는 게 가장 좋습니다. / 열쇠 관련 작업은 [출장 열쇠](key-call.html) 페이지에 자세히 적어 두었습니다.
현관 도어락까지 같이 손보고 싶다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 함께 상담해 드립니다. / 현관이 잠긴 상황이면 [현관문 개문](door-open.html)을 참고하세요.

# 마천동 말고 송파 어디든 갑니다
거여동, 오금동, 방이동, 가락동, 문정동, 장지동, 잠실동, 신천동, 석촌동, 송파동, 풍납동도 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.

? 우편함 열쇠가 반쯤 들어가다 멈춰요. | 안쪽이 굳었을 가능성이 큽니다. 기름 대신 건조형 윤활제를 쓰고, 안 되면 억지로 돌리지 마세요.

? 우편함 열쇠를 밖에서 잃어버렸는데 그냥 둬도 될까요? | 마음이 쓰인다면 자물쇠를 바꾸는 편이 낫습니다. 주운 사람이 열 수 없게 됩니다.
? 열지 못하면 돈이 드나요? | 들지 않습니다. 못 열면 받지 않습니다.

# 마무리
마천동에서 우편함이나 사물함 열쇠를 잃어버렸다면 집주인이나 관리사무소 여분부터 확인하고, 열쇠 번호가 있는지 보세요. / 안 돌아가는 열쇠는 힘으로 돌리지 말고 사진과 함께 알려주시면 됩니다.
24시출장열쇠는 서울, 경기 전 지역 24시간 다닙니다. / 작은 자물쇠 문의도 010-3664-5455로 편하게 주세요.
