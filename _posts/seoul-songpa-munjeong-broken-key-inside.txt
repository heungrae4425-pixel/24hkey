# 문정동에서 열쇠 머리만 손에 남았을 때
문정역 둘레 문정동은 대단지 아파트와 지식산업센터 사무실이 함께 있는 동네입니다. / 집 현관 보조키든 사무실 출입문 열쇠든, 매일 돌리던 열쇠가 어느 순간 뚝 하고 끊어지는 일이 생깁니다.
손에는 머리만 남고 나머지 쇠 조각은 열쇠구멍 안에 박혀 있습니다. / 이럴 때 많은 분들이 손톱이나 핀셋으로 바로 빼 보려 하는데, 그 몇 분이 이후 작업 시간을 좌우합니다.
이 글은 문정동에서 열쇠가 부러져 구멍 안에 남았을 때 손대기 전에 알아둘 것, 문 상태에 따라 달라지는 대처, [송파구 출장열쇠](seoul-songpa.html)를 부르면 진행되는 순서를 정리했습니다.
@ 문정동 열쇠 부러짐 열쇠구멍 조각

# 지금 문은 잠긴 상태인가요, 열린 상태인가요
가장 먼저 가려야 할 것은 문 상태입니다. / 같은 부러짐이라도 문이 열려 있는 상태라면 급할 것이 없고, 잠긴 채 밖에 서 있다면 개문이 먼저입니다.
문이 열린 상태에서 잠그려다 부러졌다면 문을 닫지 말고 그대로 두세요. / 닫아 버리면 그때부터는 잠긴 문을 여는 일로 바뀝니다.
잠긴 문을 열려다 부러졌다면 열쇠구멍 속 조각이 돌다 만 위치에 걸려 있을 수 있습니다. / 이 상태에서 조각을 억지로 돌리면 안쪽 핀이 같이 상합니다.
안에 가족이 있다면 안쪽 손잡이나 걸쇠로 열어 달라고 부탁해 보세요. / 보조키 열쇠구멍만 막혔다면 안에서는 대개 돌림 손잡이로 풀 수 있습니다.

# 조각 끝이 보이는지 들여다보세요
휴대폰 불빛으로 열쇠구멍을 비춰 보세요. / 조각 끝이 구멍 바깥으로 살짝 나와 있는지, 안쪽 깊이 들어가 있는지만 확인하면 됩니다.
끝이 밖으로 확실히 나와 있고 손가락으로 집힐 정도라면 그대로 곧게 당겨 보는 것까지는 괜찮습니다. / 비틀지 말고 들어간 방향 그대로 천천히 빼야 합니다.
조금도 집히지 않는다면 거기서 멈추세요. / 무언가를 밀어 넣는 순간 조각이 더 깊이 들어갑니다.

# 하지 말아야 할 세 가지
- 순간접착제를 바른 막대로 조각을 붙여 빼기
- 바늘이나 클립으로 조각 옆을 후비기
- 남은 열쇠 머리를 구멍에 다시 꽂아 돌리기
접착제는 조각만 붙는 게 아니라 열쇠구멍 안쪽 핀까지 굳혀 버립니다. / 이렇게 되면 조각만 빼면 될 일이 실린더 전체를 바꾸는 일로 커집니다.
머리를 다시 맞대 돌리면 부러진 면끼리 미끄러져 안쪽이 더 긁힙니다. / 마음은 급해도 이 세 가지만은 피해 주세요.
@ 문정동 열쇠구멍 부러진 열쇠 하지 말 것

# 부러진 머리는 꼭 챙겨 두세요
손에 남은 열쇠 머리는 버리지 말고 주머니에 넣어 두세요. / 조각을 뺀 뒤 머리와 맞춰 보면 같은 열쇠를 다시 깎을 수 있는지 판단할 수 있습니다.
여벌 열쇠가 집이나 사무실 어딘가에 있다면 그것도 떠올려 보세요. / 조각을 빼고 나면 여벌 열쇠로 다시 쓸 수 있는 경우가 많습니다.
여벌 열쇠가 집 안에 있다면 문이 열리는 대로 바로 꺼내 확인하시면 됩니다. / 가족이 하나씩 나눠 갖고 있다면 누가 가장 가까이 있는지 연락을 돌려 보세요.

# 왜 하필 오늘 부러졌을까
열쇠는 갑자기 부러지는 것처럼 보여도 대개 오래전부터 힘을 받고 있었습니다. / 구멍이 뻑뻑해서 늘 힘을 주어 돌렸거나, 복사한 열쇠의 홈이 원래와 조금 달라 매번 걸렸던 경우가 흔합니다.
사무실 문처럼 하루에도 여러 사람이 여닫는 문은 열쇠가 빨리 닳습니다. / 열쇠 몸통에 실금이 보이거나 휘어 있었다면 그때 이미 신호가 있었던 셈입니다.
문이 처져서 걸쇠가 문틀에 눌린 채로 열쇠를 돌리는 습관도 원인이 됩니다. / 열쇠에 실리는 힘이 커지기 때문입니다.

# 사무실 출입문이라면 이것부터
지식산업센터나 상가 사무실 문이라면 같은 문 열쇠를 가진 사람이 또 있는지 확인해 보세요. / 다른 사람 열쇠가 있어도 조각이 박혀 있으면 들어가지 않으니, 조각을 뺄 때까지는 출입문을 쓸 수 없다는 점을 동료들에게 알려 두셔야 합니다.
건물 관리실에 공용 출입 통제가 있다면 관리실에도 상황을 말해 두세요. / 작업할 때 관리실 확인이 필요한 건물도 있습니다.

# 문정동에서 전화 주실 때
- 집인지 사무실인지, 동과 호수 또는 건물 이름과 층
- 문이 지금 잠겨 있는지 열려 있는지
- 조각 끝이 보이는지, 남은 머리가 있는지
- 열쇠구멍이 보조키인지 도어락에 붙은 비상 열쇠구멍인지
열쇠구멍과 손에 남은 머리를 같이 찍어 보내 주시면 맞는 공구를 챙겨 갑니다. / 사진이 있으면 현장에서 헤매는 시간이 줄어듭니다.

# 사용자 확인을 먼저 하고 시작합니다
집이라면 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나로 사시는 분인지 확인합니다. / 사무실이라면 재직 확인이 되는 자료나 건물 관리실 확인이 필요합니다.
확인이 되지 않으면 조각만 빼는 일이라도 시작하지 않습니다. / 문을 지키는 일과 같은 무게로 보기 때문입니다.
늦은 밤 사무실 문이라면 대표나 관리 담당자와 통화로 확인하는 방법도 있습니다. / 연락이 닿을 사람을 미리 정해 두시면 좋습니다.

# 비용은 손대기 전에 말씀드립니다
조각이 얼마나 깊이 들어갔는지, 문이 잠겼는지를 보고 비용을 먼저 안내합니다. / 동의하신 다음에 작업하고, 끝내 열지 못하면 받지 않습니다.
실린더를 바꿔야 할 상황이면 바꾸기 전에 다시 여쭤봅니다. / 진행 순서는 [이용안내](guide.html)에 있습니다.

# 조각을 빼고 난 다음
조각을 빼면 안쪽 핀이 상하지 않았는지 열쇠를 넣어 몇 번 돌려 봅니다. / 멀쩡하면 여벌 열쇠로 그대로 쓰시고, 걸리는 느낌이 남으면 실린더 교체를 말씀드립니다.
잠긴 문을 열어야 했다면 [현관문 개문](door-open.html) 방식으로 최대한 상하지 않게 엽니다. / 열쇠 대신 번호로 여는 방식으로 바꾸고 싶다면 [도어락 설치](doorlock-install.html)도 함께 상담하실 수 있습니다.
@ 문정동 출장열쇠 부러진 열쇠 빼기 실린더

# 열쇠가 다시 부러지지 않게
- 열쇠가 뻑뻑하게 돌면 힘으로 밀지 말고 점검 받기
- 복사 열쇠가 걸리면 원래 열쇠로 다시 복사하기
- 휘거나 실금이 간 열쇠는 바로 바꾸기
- 문을 밀거나 당겨 걸쇠가 편할 때 열쇠 돌리기
보조키를 자주 안 쓰는 집이라면 가끔 돌려서 안쪽이 굳지 않게 해 주는 것도 도움이 됩니다. / 열쇠구멍이 유난히 뻑뻑하다면 [도어락 수리](doorlock-repair.html)에서 실린더 점검 방식을 함께 보세요.
열쇠고리에 열쇠를 너무 많이 달아 두는 것도 좋지 않습니다. / 꽂아 둔 채로 무거운 꾸러미가 아래로 처지면 열쇠 목 부분에 계속 힘이 실립니다.

# 문정동 둘레 송파구도 다닙니다
가락동, 장지동, 거여동, 마천동, 오금동, 석촌동, 송파동, 방이동, 잠실동, 신천동, 풍납동까지 출동합니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
