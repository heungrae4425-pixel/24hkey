# 문정동에서 현관을 한 번 둘러보는 날
문정역 주변 문정동은 대단지 아파트와 지식산업센터 사무실이 함께 있는 동네입니다. / 집 현관도, 사무실 출입문도 매일 여닫지만 정작 문 자체를 찬찬히 들여다볼 일은 드뭅니다.
방범 점검이라고 해서 거창한 장비가 필요한 건 아닙니다. / 문이 제대로 닫히고 잠기는지, 번호가 쉽게 드러나지 않는지 정도만 봐도 대부분의 빈틈이 보입니다.
이 글은 겁을 주려는 목적이 아니라 문정동 집과 사무실 문을 스스로 점검하는 순서를 정리한 것입니다. / 손볼 곳이 보이면 [송파구 출장열쇠](seoul-songpa.html)에 상담을 요청하시면 됩니다.
@ 문정동 현관 방범 점검 도어락 확인

# 점검은 열 때보다 닫을 때가 중요합니다
도어락이 아무리 좋아도 문이 덜 닫히면 잠금이 걸리지 않습니다. / 그래서 점검은 문이 끝까지 닫히는지부터 시작합니다.
문을 그냥 놓아 보고 스스로 닫히며 잠금음이 나는지 들어 보세요. / 몇 번에 한 번씩 멈춘다면 도어클로저나 걸쇠 위치를 손봐야 할 때입니다.
급하게 나가면서 등 뒤로 닫는 습관이 있다면 하루 이틀은 돌아서서 잠김을 확인해 보세요. / 의외로 살짝 열린 채 외출한 날이 있었다는 걸 알게 됩니다.

# 걸쇠가 얼마나 깊이 들어가는지
문을 닫으면 도어락 옆에서 쇠뭉치가 나와 문틀 구멍에 들어갑니다. / 이 쇠뭉치가 끝까지 들어가야 바깥에서 문을 당겨도 버팁니다.
문을 닫고 손잡이를 밖으로 당겨 보세요. / 덜컹거리며 몇 밀리씩 움직인다면 걸쇠가 얕게 걸려 있을 수 있습니다.
문틀 받이 쇠판이 헐겁게 흔들리는지도 손으로 만져 봅니다. / 나사가 풀린 받이는 걸쇠를 단단히 잡아 주지 못합니다.

# 번호판에 남는 흔적
자주 누르는 숫자 버튼은 손때가 묻거나 반질반질하게 닳습니다. / 밝은 곳에서 비스듬히 보면 어떤 숫자를 쓰는지 짐작이 될 정도로 남아 있기도 합니다.
번호를 누를 때 앞뒤로 아무 숫자나 섞어 누를 수 있는 기능이 있는 제품이 많습니다. / 이 기능을 쓰면 실제 번호 앞뒤로 다른 숫자가 남아 흔적만으로는 알기 어렵습니다.
번호판을 가끔 마른 천으로 닦아 주는 것도 단순하지만 효과가 있습니다.
@ 송파 문정동 도어락 번호판 흔적 닦기

# 비밀번호와 카드 관리 습관
같은 번호를 오래 쓰면 지나간 손님이나 수리 기사, 예전 가사 도우미가 알고 있을 수 있습니다. / 계절이 바뀔 때쯤 번호를 바꾸는 습관이 가장 쉬운 방범입니다.
생일, 전화번호 끝자리, 같은 숫자 반복은 피하세요. / 가족이 기억하기 쉬우면서도 남이 짐작하기 어려운 조합을 함께 정하는 게 좋습니다.
카드키를 잃어버렸다면 등록 목록에서 바로 지워야 합니다. / 하나만 지우는 기능이 없다면 전체 삭제 후 남은 카드를 다시 등록하세요.

# 문 아래 틈과 우유 투입구
오래된 현관문 중에는 아래쪽에 우유 투입구나 넓은 틈이 있는 경우가 있습니다. / 이 틈으로 안쪽 손잡이를 건드릴 수 있는 구조인지 한 번 살펴보세요.
안쪽 손잡이를 돌리면 바로 열리는 도어락이라면 안쪽 잠금 버튼이나 이중 잠금 기능을 활용해 보세요. / 제품마다 이름이 달라 설명서에서 안쪽 강제 잠금 항목을 찾으시면 됩니다.
쓰지 않는 투입구는 안쪽에서 막아 두는 집도 있습니다.
문 아래 바람막이 고무가 찢어져 틈이 넓어졌다면 그 부분만 새로 붙여도 됩니다. / 소음과 찬 바람도 같이 줄어드는 덤이 있습니다.
@ 문정동 현관문 아래 틈 우유 투입구 확인

# 보조키와 걸쇠는 밤에 쓰세요
도어락 하나만 쓰기보다 안쪽 걸쇠나 보조키를 함께 쓰면 마음이 놓입니다. / 다만 걸쇠를 건 채 외출하는 일은 구조상 없으니, 밤에 집에 있을 때 쓰는 용도로 생각하면 됩니다.
가족 중 늦게 들어오는 사람이 있다면 걸쇠를 언제 걸지 미리 정해 두세요. / 서로 몰라서 밖에서 못 들어오는 일이 생기면 오히려 번거롭습니다.

# 사무실 출입문은 사람 기준으로 점검
문정동 지식산업센터처럼 여러 사람이 드나드는 사무실은 문보다 사람 관리가 먼저입니다. / 퇴사자나 계약이 끝난 외부 인력의 카드와 번호가 남아 있지 않은지 확인하세요.
공용 번호 하나를 모두가 쓰는 방식이라면 사람이 바뀔 때마다 번호를 바꾸는 규칙을 정하세요. / 마지막 퇴근자가 잠금을 확인하는 순서도 정해 두면 좋습니다.
건물 공용 출입 관리와 호실 출입문은 관리 주체가 다르니, 호실 문은 입주 회사가 챙겨야 합니다.
주말이나 연휴 앞에는 문이 잠겼는지 사진 한 장을 남기고 퇴근하는 회사도 있습니다. / 누가 마지막이었는지 헷갈릴 때 확인이 쉬워집니다.
사무실 도어락 배터리는 집보다 여닫는 횟수가 많아 빨리 닳습니다. / 교체 담당자를 한 명 정해 두면 출근길에 번호판이 꺼져 있는 아침을 줄일 수 있습니다.

# 도어락 자체가 오래됐다면
경고음이 자주 나거나 잠금이 한 번에 안 걸리는 도어락은 점검 시기가 된 것입니다. / 고장이 잦은 제품은 잠금이 덜 걸린 채로 남는 일이 생길 수 있습니다.
수리로 해결되면 [도어락 수리](doorlock-repair.html)로 손보고, 부품이 없을 만큼 오래됐다면 [도어락 교체](doorlock-replace.html)를 상담해 보세요. / 새로 달 때 문 두께와 보조키 자리는 [도어락 설치](doorlock-install.html) 안내를 참고하시면 됩니다.

# 지나친 걱정은 내려놓으세요
방범 점검은 생활 습관을 한 번 정리하는 정도면 충분합니다. / 이상한 흔적이 있다고 바로 큰일이 난 건 아니고, 대부분 오래 써서 생긴 자국입니다.
걱정되는 부분이 있으면 사진을 찍어 문자로 보내주세요. / 손볼 필요가 있는지 없는지를 먼저 말씀드립니다.
필요 없는 장치를 더 달자고 권하지 않습니다. / 지금 있는 문과 도어락을 제대로 쓰는 것이 먼저입니다.

# 출장 점검을 부르실 때
- 문정동 아파트인지 사무실인지, 동이나 호실
- 도어락 앞면과 안쪽 몸체 사진
- 덜 닫힘, 경고음, 걸쇠 흔들림 등 신경 쓰이는 점
사무실이라면 출입 권한이 있는 분이 함께 계셔야 작업할 수 있습니다.
@ 문정동 사무실 출입문 도어락 점검 상담

# 확인 절차와 비용 안내
집은 사시는 분, 사무실은 사용 권한이 있는 분인지 먼저 확인합니다. / 신분증과 주소가 나온 우편물, 사무실은 임대 계약서나 관리실 확인으로 갈음합니다.
작업이 필요하면 얼마인지 먼저 말씀드리고 동의하실 때만 진행합니다. / 문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않으며, 자세한 순서는 [이용안내](guide.html)에 있습니다.

# 문정동 말고 송파 어디든 갑니다
가락동, 장지동, 거여동, 마천동, 오금동, 잠실동, 신천동, 방이동, 석촌동, 송파동, 풍납동도 다닙니다. / 그 밖의 서울, 경기 지역은 [출장 지역](area.html)에서 확인하세요.
