# 신천동 현관 앞, 귀에 먼저 들어오는 소리
신천동은 잠실역과 가까운 동네로 아파트와 오피스텔, 빌라가 함께 섞여 있습니다. / 사는 집 모양은 달라도 도어락이 고장 날 때 내는 소리는 비슷합니다.
번호를 눌렀는데 위잉 하고 모터만 돌고 걸쇠는 안 빠진다거나, 아무것도 안 눌렀는데 삐삐 하고 울리면 덜컥 겁이 납니다. / 그런데 이 소리들은 꽤 정직하게 원인을 알려 줍니다.
이 글은 신천동에서 도어락이 이상한 소리를 낼 때 소리별로 무엇을 의심할지, 어디까지 직접 해 보고 언제 [송파구 출장열쇠](seoul-songpa.html)를 부를지 정리했습니다.
@ 신천동 도어락 경고음 오작동 점검

# 소리를 들으면 절반은 알 수 있습니다
도어락은 문제가 생기면 저마다 다른 소리를 냅니다. / 휴대폰으로 소리를 녹음해 두면 전화로 설명할 때 훨씬 편합니다.
- 짧은 삑삑이 여러 번: 배터리가 약하다는 신호인 경우가 많음
- 길게 이어지는 경보음: 문이 덜 닫혔거나 억지로 열려 했다고 판단한 경우
- 위잉 모터 소리 뒤 멈춤: 모터는 도는데 걸쇠가 걸려 못 빠지는 경우
- 딸깍 소리만 나고 조용함: 손잡이 쪽 연결이 풀렸을 수 있음
모델마다 조금씩 다르니 정답처럼 믿기보다는 방향을 잡는 정도로 보시면 됩니다.

# 짧은 삑삑음은 건전지부터 바꿔 보세요
가장 흔한 원인은 건전지입니다. / 전원이 약해지면 도어락은 경고음을 내면서도 한동안 버티다가 어느 날 모터를 끝까지 못 돌립니다.
문이 열리는 상태라면 안쪽 덮개를 열고 건전지를 전부 새것으로 바꿔 주세요. / 한두 개만 바꾸면 남은 낡은 건전지 때문에 금방 다시 울립니다.
건전지를 바꾼 뒤에도 같은 소리가 계속 난다면 접점이 녹슬었거나 회로 쪽 문제일 수 있습니다.

# 모터만 돌고 문이 안 열릴 때 해 볼 것
번호는 맞는데 모터 소리만 나고 문이 꿈쩍 않는다면 걸쇠가 문틀에 눌려 있는 경우가 많습니다. / 문을 안쪽으로 살짝 밀면서 다시 번호를 눌러 보세요.
반대로 바깥으로 당기면서 눌러야 풀리는 문도 있습니다. / 두 방향 모두 한 번씩만 시도해 보시고, 세게 흔들지는 마세요.
그래도 안 되면 모터 기어가 닳았거나 걸쇠가 휘었을 가능성이 있습니다. / 이때부터는 손으로 해결하기 어렵습니다.
모터 소리가 평소보다 길고 힘겹게 들렸다면 며칠 전부터 신호가 있었던 셈입니다. / 그 소리를 기억해 두셨다가 전화로 말씀해 주시면 챙겨 갈 부품을 고르는 데 도움이 됩니다.

# 문이 닫혀 있는데 경보가 울린다면
문이 다 닫히지 않은 채 잠금을 시도하면 도어락이 문 열림으로 판단해 길게 울리기도 합니다. / 문을 끝까지 밀어 닫고 잠금 버튼을 다시 눌러 보세요.
오피스텔처럼 복도 바람이 센 곳은 문이 살짝 덜 닫히는 일이 잦습니다. / 문 위 도어클로저가 약해졌다면 문이 마지막에 힘없이 멈춥니다.
이 경우 도어락보다 문 닫힘을 먼저 손봐야 경보가 멈춥니다.
@ 신천동 도어락 모터 소리 문 안 열림

# 한밤중 혼자 울리는 도어락
새벽에 아무도 안 건드렸는데 도어락이 울려 놀라는 집이 있습니다. / 건전지가 거의 다 됐거나, 번호판에 물기가 맺혀 버튼이 눌린 것처럼 읽히는 경우가 대부분입니다.
겨울 아침에 유독 그렇다면 결로를 의심해 보세요. / 마른 천으로 번호판을 닦고 잠시 두었다가 다시 확인하면 조용해지기도 합니다.
반복된다면 이웃에게도 불편이 가니 미루지 말고 점검을 받는 게 좋습니다.
오피스텔이나 빌라처럼 벽이 맞붙은 집은 소리가 옆집까지 잘 넘어갑니다. / 급한 대로 건전지를 잠깐 빼 두면 소리는 멈추지만, 그동안은 번호로 문을 열 수 없으니 외출 전에는 꼭 다시 끼워 두세요.

# 이런 행동은 고장을 키웁니다
- 소리가 멈출 때까지 버튼을 계속 눌러 대기
- 번호판을 손바닥으로 두드리기
- 덮개를 열고 전선이나 기판을 만지기
- 걸쇠 틈에 기름을 뿌리기
특히 기름은 먼지를 붙잡아 나중에 걸쇠를 더 뻑뻑하게 만듭니다. / 소리만 나고 안 열리는 상황이라면 그대로 두고 연락 주시는 편이 안전합니다.

# 신천동에서 전화하실 때 알려 주실 것
- 건물 종류(아파트, 오피스텔, 빌라)와 동, 호수
- 들리는 소리가 어떤지, 녹음이 있는지
- 지금 문이 열린 상태인지 잠긴 상태인지
- 건전지를 언제 바꿨는지
밖에서 문이 안 열려 서 계신다면 그 점을 먼저 말씀해 주세요. / 출동 순서를 정할 때 참고합니다.
도어락 앞면과 안쪽 몸체를 찍은 사진이 있으면 더 좋습니다. / 제조사 표시가 보이게 찍어 주시면 맞는 부품이 있는지 미리 알아볼 수 있습니다.

# 사시는 분인지 확인한 뒤 손을 댑니다
잠긴 문을 여는 경우에는 그 집에 사는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 가운데 하나를 보여 주시면 됩니다.
오피스텔은 관리실이나 경비실 확인으로도 가능합니다. / 서류가 집 안에 있다면 미리 관리실에 말해 두시면 기다리는 시간이 줄어듭니다.

# 비용 이야기는 작업 앞에서 끝냅니다
소리와 상태를 보고 수리로 될지, 문만 열면 될지 판단한 다음 비용을 먼저 말씀드립니다. / 동의하신 뒤에 작업을 시작하고, 열지 못하면 받지 않습니다.
작업 중에 예상과 다른 고장이 보이면 손대기 전에 다시 여쭤봅니다. / 처음 말씀드린 내용에서 슬쩍 늘어나는 일은 없게 합니다.
자세한 진행은 [이용안내](guide.html)에, 잠긴 문을 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 수리로 끝낼지 바꿀지 따져 봅니다
건전지 접점 청소나 걸쇠 조정으로 끝나는 경우가 생각보다 많습니다. / 고쳐서 쓸 수 있으면 굳이 바꾸자고 하지 않습니다.
모터나 기판이 상했고 오래 쓴 제품이라면 그때 교체를 같이 고민합니다. / 수리 방식은 [도어락 수리](doorlock-repair.html), 교체는 [도어락 교체](doorlock-replace.html)에서 보실 수 있습니다.
@ 신천동 도어락 수리 교체 상담

# 경고음이 다시 안 나게 하려면
- 건전지는 경고음이 처음 들린 날 바로 전부 교체
- 문이 끝까지 닫히는지 출입할 때마다 한 번씩 확인
- 번호판 물기는 마른 천으로 닦기
- 모터 소리가 예전보다 길어지면 미리 점검 받기
소리가 바뀌는 순간이 가장 좋은 점검 시기입니다. / 완전히 멈추고 나서 부르면 문 앞에서 기다리는 시간이 생깁니다.
가족이 여럿이라면 이상한 소리를 들은 사람이 바로 알리도록 약속해 두세요. / 각자 한 번씩만 듣고 넘기면 아무도 고장을 눈치채지 못합니다.

# 송파구 신천동 주변도 함께 다닙니다
잠실동, 석촌동, 송파동, 방이동, 풍납동, 오금동, 가락동, 문정동, 장지동, 거여동, 마천동 어디든 갑니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.

? 새벽에 혼자 울리는 건 고장인가요? | 건전지 부족이나 번호판 물기가 흔한 원인입니다. 반복되면 점검을 받아 보세요.

? 오피스텔도 출동하나요? | 네, 신천동 아파트, 오피스텔, 빌라 모두 갑니다.
