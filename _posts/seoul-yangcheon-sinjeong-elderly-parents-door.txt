# 신정동 부모님 댁, 도어락 설정은 그대로인가요
신정동은 신정네거리역 주변으로 다세대 주택과 빌라, 오래된 단독주택이 섞여 있는 동네입니다. / 오래 한 동네에 사신 어르신들이 많고, 자녀가 다른 동네로 나가 살면서 가끔 들르는 집도 흔합니다.
도어락은 처음 달 때 정해진 설정 그대로 몇 년씩 쓰는 경우가 많습니다. / 그런데 젊을 때 편하던 설정이 연세가 드시면 오히려 문 앞에서 헷갈리게 만드는 원인이 되기도 합니다.
이 글은 부모님 댁에 들렀을 때 도어락 설정을 어르신 손과 눈에 맞게 바꿔 드리는 순서를 적었습니다. / 직접 하기 어려운 부분은 [양천구 출장열쇠](seoul-yangcheon.html)로 맡기셔도 됩니다.
@ 신정동 부모님 댁 도어락 어르신 설정

# 먼저 부모님이 문 여시는 모습을 지켜보세요
설정을 바꾸기 전에 부모님이 평소처럼 밖에서 문을 여시는 모습을 한 번 지켜보세요. / 어디서 멈칫하시는지가 바로 고쳐 드릴 곳입니다.
번호판을 깨우는 데 한참 걸리시는지, 숫자를 누르고 확인 버튼을 잊으시는지 봅니다. / 손잡이를 돌리는 방향이 헷갈리시거나, 문이 닫힐 때 잠금 소리를 못 들으시는 경우도 있습니다.
지켜본 것을 짧게 적어 두면 무엇부터 바꿀지 순서가 정해집니다.

# 안내 소리는 크게, 버튼 소리는 또렷하게
청력이 약해지시면 도어락이 잠겼다는 소리를 못 들으셔서 문을 몇 번씩 다시 확인하십니다. / 대부분의 도어락은 안내음 크기를 몇 단계로 바꿀 수 있습니다.
설정 메뉴에서 소리를 가장 크게 하고, 무음 모드가 켜져 있다면 꺼 드리세요. / 이웃에게 너무 크다 싶으면 한 단계 낮추는 정도로 맞추면 됩니다.
소리 설정 방법은 제품마다 달라 설명서를 찾기 어려우면 도어락 사진을 보내 주세요. / 방법을 알려 드리거나 방문해서 맞춰 드립니다.

# 자동 잠금은 켜고, 이중 잠금은 다시 생각
문을 닫으면 저절로 잠기는 자동 잠금은 어르신 댁에서 켜 두는 편이 안심이 됩니다. / 잠갔는지 기억이 안 나 다시 나와 보시는 일이 줄어듭니다.
반면 안쪽에서 버튼을 눌러 거는 이중 잠금은 오히려 문제를 만들 수 있습니다. / 이중 잠금이 걸린 채 쓰러지시거나 깜빡 잠드시면 밖에서 번호로 열리지 않기 때문입니다.
가족이 함께 상의해서 이중 잠금 기능을 쓰지 않는 쪽으로 정해 두는 집이 많습니다. / 꼭 쓰셔야 한다면 쓰는 방법과 푸는 방법을 큰 글씨로 적어 문 안쪽에 붙여 두세요.
@ 신정동 어르신 댁 도어락 자동 잠금 설정

# 번호는 짧게 바꾸기보다 익숙하게
보안을 생각하면 긴 번호가 좋지만 어르신께는 외우기 쉬운 번호가 먼저입니다. / 다만 생일이나 집 주소처럼 남이 짐작하기 쉬운 숫자는 피해 주세요.
부모님이 오래 써 온 숫자 조합이 있다면 그 안에서 고르는 것이 좋습니다. / 번호를 바꾼 뒤에는 그 자리에서 대여섯 번 직접 눌러 보시게 하고, 며칠 뒤 전화로 한 번 더 여쭤보세요.
번호를 적은 쪽지를 지갑에 넣고 다니시는 분도 있습니다. / 그럴 때는 집 주소와 함께 적지 않도록 꼭 말씀드려 주세요.

# 번호 말고 다른 길도 하나 열어 두세요
번호만으로 여는 집은 번호를 잊으시는 순간 방법이 없어집니다. / 카드나 태그를 하나 등록해 열쇠고리에 달아 드리면 번호가 생각나지 않을 때 대신 쓸 수 있습니다.
지문은 손끝이 건조하거나 굳은살이 많으신 분께는 잘 안 읽히기도 합니다. / 등록할 때 같은 손가락을 두세 번 나눠 넣고, 다른 손 손가락도 하나 더 넣어 두면 인식이 나아집니다.
어느 방법이든 등록한 뒤 부모님이 혼자서 직접 열어 보시게 해야 합니다. / 자녀가 대신 해 드리고 끝내면 정작 혼자 계실 때 쓰지 못하십니다.

# 손잡이형과 밀고 당기는 형, 무엇이 편할까
손목 힘이 약해지신 분께는 손잡이를 돌리는 방식보다 밀거나 당기기만 하면 열리는 형이 편할 수 있습니다. / 반대로 오래 손잡이형을 쓰신 분은 새 방식이 낯설어 더 헷갈려하시기도 합니다.
바꾸기 전에 부모님께 직접 한 번 만져 보시게 하는 것이 가장 정확합니다. / 문 두께와 보조키 상태에 따라 달 수 있는 제품이 달라지니 [도어락 교체](doorlock-replace.html)에서 진행 방식을 먼저 보세요.

# 신정동 단독주택은 대문도 같이 봅니다
단독주택에 사시는 부모님이라면 대문과 현관 두 곳을 지나야 집 안에 들어오십니다. / 대문 열쇠가 뻑뻑하면 현관보다 대문 앞에서 더 오래 서 계시게 됩니다.
대문 자물쇠가 잘 돌아가는지, 대문이 끝까지 닫히는지도 함께 살펴 드리세요. / 계단이나 문턱이 높은 집은 문 앞에서 짐을 내려놓을 자리가 있는지도 생각해 두면 좋습니다.

# 건전지는 자녀 달력에 적어 두세요
어르신 댁 도어락이 멈추는 가장 흔한 이유는 건전지입니다. / 짧은 알림 소리가 나도 무슨 뜻인지 모르고 넘기시는 경우가 많습니다.
부모님 댁에 들를 때 건전지를 바꾸고, 바꾼 날짜를 자녀 휴대폰 달력에 넣어 두세요. / 다음 교체 시기가 되면 알림이 와서 잊지 않게 됩니다.
문 밖 9V 비상 단자 위치에 작은 스티커를 붙여 두는 것도 좋습니다. / 급할 때 이웃이나 경비원이 도와 드리기도 쉬워집니다.
@ 신정동 부모님 댁 도어락 건전지 교체

# 이런 모습이 보이면 점검을 받으세요
아래 같은 모습이 보이면 설정보다 도어락 자체를 점검할 때입니다.
- 번호판 숫자가 닳아 잘 안 보인다
- 번호를 여러 번 눌러야 겨우 인식된다
- 문이 닫혀도 잠기는 소리가 났다 안 났다 한다
- 손잡이가 헐거워져 돌릴 때 덜컥거린다
부모님은 불편해도 말씀을 안 하시는 경우가 많습니다. / 들를 때마다 한 번씩 직접 열고 닫아 보시는 것이 가장 확실한 점검입니다.
부품을 손보면 되는 상태라면 [도어락 수리](doorlock-repair.html)로 먼저 해결합니다.

# 자녀가 대신 연락하실 때
멀리 사는 자녀분이 대신 연락하셔도 됩니다. / 부모님 댁 주소와 도어락 사진, 부모님 연락처를 함께 알려 주세요.
방문했을 때는 부모님이 직접 계시는 상태에서 진행합니다. / 문이 잠긴 상황이라면 사시는 분인지 신분증 주소나 우편물로 확인하는 절차는 똑같이 거칩니다.
자세한 절차는 [이용안내](guide.html)에 정리해 두었습니다.

# 설정과 수리, 비용은 미리
설정만 바꾸는지, 부품을 손보는지, 제품을 바꾸는지에 따라 할 일이 다릅니다. / 상태를 보고 무엇이 필요한지와 비용을 먼저 말씀드리고 동의하실 때만 시작합니다.
문이 잠겨 여는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 부모님께 설명드릴 때도 천천히 다시 말씀드립니다.

# 양천구 다른 동네 부모님 댁도
신정동 단독주택과 다세대뿐 아니라 신월동 빌라, 목동 아파트에 사시는 부모님 댁도 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인해 보세요.

# 자주 묻는 질문

? 이중 잠금 기능을 아예 끌 수 있나요? | 제품에 따라 다릅니다. 끌 수 없다면 쓰는 법과 푸는 법을 문 안쪽에 적어 두는 걸 권합니다.
