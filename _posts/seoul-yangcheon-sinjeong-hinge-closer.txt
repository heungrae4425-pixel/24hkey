# 신정동 현관문이 마지막에 툭 멈춘다면
문을 놓았는데 마지막 한 뼘을 남기고 멈추거나, 반대로 쾅 소리를 내며 세게 닫히는 집이 있습니다. / 둘 다 문 위에 달린 도어클로저나 경첩이 보내는 신호입니다.
신정동은 신정네거리역 주변으로 빌라와 다세대, 단독주택이 많은 동네입니다. / 오래 쓴 철문과 도어클로저를 그대로 쓰는 집이 많아 이런 증상이 자주 보입니다.
이 글은 신정동에서 현관문이 덜 닫히거나 너무 세게 닫힐 때 어디를 보면 되는지 정리했습니다. / 문이 덜 닫히면 도어락이 제대로 잠기지 않으니 미루지 않는 편이 좋습니다.
@ 신정동 빌라 현관문 도어클로저 점검

# 덜 닫힌 문이 도어락에 주는 영향
도어락의 걸쇠는 문이 문틀에 딱 붙어야 제자리로 들어갑니다. / 문이 조금이라도 덜 닫히면 걸쇠가 문틀 구멍 가장자리에 걸리거나 아예 밖으로 튀어나온 채로 남습니다.
이 상태에서 자동 잠김이 되면 잠긴 것 같은데 실제로는 문이 밀리면 열리는 상황이 됩니다. / 다음에 번호를 눌렀을 때 걸쇠가 걸려 안 열리는 원인이 되기도 합니다.
그래서 문이 덜 닫히는 문제는 도어락 고장보다 먼저 손봐야 할 때가 많습니다. / 문을 고치고 나면 도어락 증상이 저절로 사라지는 경우도 꽤 있습니다.

# 도어클로저는 이렇게 생겼습니다
현관문 위쪽 안쪽에 붙어 있는 길쭉한 몸통과 꺾이는 팔이 도어클로저입니다. / 안에 기름이 들어 있어 문이 천천히 닫히도록 속도를 잡아 줍니다.
몸통 옆이나 아래에 작은 조절 나사가 두세 개 있는 제품이 많습니다. / 하나는 닫히는 전체 속도, 하나는 마지막 구간 속도를 조절하는 식입니다.
몸통 아래에 기름이 번져 있거나 바닥에 기름 자국이 떨어져 있다면 안의 기름이 새는 것입니다. / 이때는 조절로 해결되지 않고 교체가 필요합니다.

# 끝까지 안 닫힐 때 조절하는 법
마지막에 멈춘다면 마지막 구간 속도가 너무 느리게 잡혀 있을 가능성이 큽니다. / 조절 나사를 아주 조금씩, 한 번에 반 바퀴도 안 되게 돌려 가며 문을 닫아 보세요.
나사를 어느 쪽으로 돌리면 빨라지는지는 제품마다 다릅니다. / 몸통에 화살표나 표시가 있다면 그것을 따르고, 없다면 조금 돌려 보고 결과를 확인하는 식으로 맞춥니다.
- 한 번에 조금씩만 돌리기
- 돌릴 때마다 문을 열었다 놓아 확인하기
- 나사를 너무 많이 풀어 빠지지 않게 주의하기
나사를 끝까지 풀어 버리면 안의 기름이 새어 나올 수 있습니다. / 감이 오지 않으면 무리하지 말고 점검을 맡기는 편이 낫습니다.
@ 양천구 신정동 도어클로저 속도 조절 나사

# 너무 세게 닫힐 때
반대로 문이 쾅 닫힌다면 속도가 너무 빠르게 잡혔거나 기름이 빠져 힘을 못 잡는 상태입니다. / 계단실이 울릴 정도로 닫히면 이웃에게도 불편하고 도어락에도 충격이 쌓입니다.
조절 나사로 속도를 줄여도 그대로라면 도어클로저 수명이 다한 것입니다. / 오래된 빌라는 처음 달았던 도어클로저를 계속 쓰는 경우가 많아 이런 일이 흔합니다.
문이 세게 닫히면 도어락 안의 부품이 조금씩 흔들려 손잡이 헐거움이나 걸쇠 어긋남으로 이어지기도 합니다. / 소리만의 문제가 아니라는 점을 기억해 주세요.

# 경첩이 처졌는지 보는 방법
도어클로저를 조절해도 문이 문틀에 긁히거나 한쪽이 떠 있다면 경첩을 봐야 합니다. / 무거운 철문은 시간이 지나면서 경첩 쪽으로 조금씩 처집니다.
문을 닫고 문과 문틀 사이 틈을 위에서 아래까지 살펴보세요. / 위쪽 틈은 넓고 아래쪽 틈은 좁다면 문이 경첩 반대쪽으로 처진 것입니다.
문을 열고 손잡이 쪽을 위로 살짝 들어 보았을 때 덜컹거린다면 경첩 나사가 풀렸을 수 있습니다. / 이 경우 나사를 조이는 것만으로 나아지기도 합니다. / 나사 구멍이 헐거워져 계속 헛돈다면 같은 자리에 더 굵은 나사를 쓰거나 위치를 조금 옮겨야 하니 그때는 맡겨 주세요.
단독주택처럼 나무 문틀을 쓰는 집은 습기에 문틀이 부풀어 경첩이 밀리는 경우도 있습니다. / 철문과는 원인이 달라서 손보는 방법도 조금 다릅니다.

# 경첩에서 소리가 날 때
문을 열고 닫을 때 끼익 하는 소리가 나면 경첩 축이 마른 상태입니다. / 경첩용 윤활제를 축 위쪽에 조금 넣고 문을 몇 번 움직여 주면 대부분 줄어듭니다.
식용유처럼 끈적한 기름은 먼지를 모아 나중에 더 뻑뻑해지니 피해 주세요. / 소리가 나면서 문이 내려앉는 느낌까지 있다면 경첩 자체가 닳았을 수 있습니다.

# 계절에 따라 달라지는 문
여름에는 문이 조금 늘어나고 겨울에는 줄어듭니다. / 그래서 한여름에 맞춰 둔 도어클로저가 겨울에는 너무 빨리 닫히기도 하고, 반대 경우도 생깁니다.
겨울에는 도어클로저 안 기름이 굳어 문이 평소보다 느리게 닫히기도 합니다. / 계절이 바뀔 때 한 번씩 속도를 다시 맞춰 주면 좋습니다.

# 바람이 문을 미는 집이라면
계단실 창문이나 현관 맞은편 베란다 창을 열어 두면 바람이 문을 안쪽이나 바깥쪽으로 밀어 냅니다. / 도어클로저가 아무리 잘 맞춰져 있어도 맞바람이 세면 마지막 구간에서 문이 멈추기도 합니다.
이럴 때는 조절 나사를 건드리기 전에 창문을 닫고 다시 시험해 보세요. / 바람이 없을 때 잘 닫힌다면 도어클로저보다 바람이 원인입니다.
바람 때문에 속도를 너무 세게 맞춰 두면 바람이 없는 날 문이 쾅 닫힙니다. / 평소 상태를 기준으로 맞추고, 바람이 센 날만 창문을 조절하시는 편이 낫습니다.

# 이럴 때는 맡기시는 게 낫습니다
- 도어클로저에서 기름이 샐 때
- 경첩 나사를 조여도 금방 다시 처질 때
- 문이 문틀에 심하게 긁혀 페인트가 벗겨질 때
- 문이 덜 닫혀 도어락이 자주 말썽일 때
도어클로저 교체, 경첩 조정, 걸쇠 받침쇠 위치 맞추기는 함께 봐야 하는 경우가 많습니다. / [도어락 수리](doorlock-repair.html)로 연락 주시면 문과 도어락을 같이 살펴봅니다.

# 점검 방문 때 확인과 비용
방문하면 사시는 분인지 간단히 확인합니다. / 신분증 주소나 주소가 나온 우편물이면 충분합니다.
문과 도어클로저 상태를 본 뒤 비용을 먼저 말씀드리고 동의하실 때만 진행합니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었고, 문이 안 열리는 상황이라면 [현관문 개문](door-open.html)도 참고해 주세요.
@ 신정동 현관문 경첩 처짐 조정 수리

# 문을 오래 편하게 쓰는 습관
문을 손으로 밀어 세게 닫지 말고 도어클로저가 닫게 두세요. / 문을 열어 둔 채로 고정해 두는 습관도 도어클로저 팔에 무리를 줍니다.
현관문에 무거운 가방이나 옷걸이를 걸어 두는 것도 경첩 처짐을 빠르게 합니다. / 문 뒤에 거는 걸이를 쓰신다면 가벼운 것만 걸어 주세요.

# 신정동 말고 양천구 어디든
신정동 빌라와 주택은 물론 신월동 다세대, 목동 아파트 단지 현관문도 봐 드립니다. / [양천구 출장열쇠](seoul-yangcheon.html)와 [출장 지역](area.html)에서 다니는 동네를 확인하실 수 있습니다.
