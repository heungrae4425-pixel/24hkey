# 신월동 골목 빌라, 현관 앞에서 멈춰 섰다면
신월동은 양천구 서쪽에 빌라와 다세대 주택이 촘촘하게 들어선 동네입니다. / 오래된 건물은 열쇠 보조키와 도어락을 같이 쓰고, 새로 지은 건물은 밀고 당기는 형 도어락을 쓰는 등 문 사정이 집집마다 다릅니다.
그래서 똑같이 문이 안 열린다고 해도 원인은 제각각입니다. / 원인을 모른 채 이것저것 눌러 보다가 입력 제한까지 걸리면 더 오래 문 앞에 서 있게 됩니다.
이 글은 문 앞에서 눈과 귀로 확인할 수 있는 증상을 기준으로 원인을 나눴습니다. / 자기 증상에 맞는 칸만 읽고, 그래도 안 되면 [양천구 출장열쇠](seoul-yangcheon.html)로 연락 주세요.
@ 신월동 빌라 현관문 안 열림 원인 확인

# 먼저 세 가지만 보고 들으세요
문 앞에서 10초면 확인할 수 있는 것들입니다. / 이 세 가지 답이 원인을 거의 정해 줍니다.
- 번호판에 손을 대면 불이 들어오는가
- 번호를 누른 뒤 윙 하는 모터 소리가 나는가
- 손잡이나 문을 밀었을 때 조금이라도 움직이는가
답을 기억해 두셨다면 아래에서 맞는 경우를 찾아 읽어 보세요. / 통화할 때도 이 세 가지만 말씀해 주시면 설명이 금방 끝납니다.

# 경우 1. 불이 전혀 안 들어온다
번호판이 깜깜하다면 거의 대부분 건전지가 다 된 경우입니다. / 며칠 전부터 짧은 멜로디가 울렸다면 더 확실합니다.
바깥 번호판 아래쪽에 9V 건전지를 댈 수 있는 단자가 있는지 찾아보세요. / 건전지를 대고 있는 동안 번호를 누르면 열리는 제품이 많습니다.
단자가 없거나 건전지를 대도 깜깜하다면 안쪽 배선이나 기판 문제일 수 있습니다. / 이때는 손대지 말고 연락 주시는 편이 빠릅니다.

# 경우 2. 불은 켜지는데 번호가 틀렸다고 나온다
분명 맞게 눌렀는데 틀렸다는 소리가 나면 가족 중 누가 번호를 바꿨는지 먼저 확인해 보세요. / 집주인이 점검하면서 바꾼 경우도 있습니다.
번호판에 물기나 먼지가 묻어 일부 숫자가 안 눌렸을 수도 있습니다. / 마른 천으로 닦고 천천히 한 자리씩 다시 눌러 보세요.
서너 번 틀리면 도어락이 한동안 입력을 받지 않습니다. / 그 상태에서 계속 누르면 제한 시간이 길어지니 잠시 멈추는 것이 좋습니다.

# 경우 3. 번호는 맞는데 소리만 나고 그대로다
열림 소리와 모터 소리는 나는데 손잡이가 안 돌아간다면 걸쇠가 문틀에 물려 있는 경우가 많습니다. / 문이 살짝 처졌거나 바람에 눌려 걸쇠가 빠져나올 틈이 없는 상태입니다.
이럴 때는 문을 안쪽으로 살짝 밀거나 들어 올리는 느낌으로 잡고 다시 번호를 눌러 보세요. / 그래도 안 되면 모터나 걸쇠 부품 쪽을 봐야 하니 점검을 받는 편이 낫습니다.
@ 신월동 도어락 모터 소리 걸쇠 문틀 확인

# 경우 4. 도어락은 풀렸는데 문이 꿈쩍 않는다
도어락 쪽은 정상으로 풀렸는데 문이 안 열린다면 다른 잠금이 걸려 있을 가능성이 큽니다. / 신월동 빌라에서는 도어락 아래 열쇠 보조키가 잠긴 경우가 흔합니다.
가족 중 누가 나가면서 보조키까지 잠갔는지 물어보세요. / 열쇠가 있다면 보조키를 먼저 풀고 도어락 번호를 눌러야 열립니다.
보조키 열쇠가 집 안에 있다면 밖에서는 열 방법이 없습니다. / 이때는 무리하지 말고 연락 주시면 됩니다.

# 경우 5. 열쇠가 들어가는데 안 돌아간다
열쇠로만 여는 현관이라면 열쇠 자체가 닳았거나 실린더가 뻑뻑해진 경우입니다. / 열쇠를 끝까지 꽂았는지, 위아래가 바뀌지 않았는지 먼저 보세요.
열쇠를 살짝 뺐다가 다시 꽂으며 아주 조금씩 좌우로 흔들어 보는 정도는 괜찮습니다. / 펜치로 잡고 돌리거나 체중을 실으면 열쇠가 부러져 안에 박힐 수 있습니다.
최근에 열쇠를 복사했다면 복사한 열쇠만 안 맞는 경우도 있습니다. / 원래 열쇠가 집 밖 어딘가에 있다면 그것으로 먼저 해보세요.
여러 번 해봐도 반쯤만 돌다 걸린다면 실린더 안 부품이 닳은 것입니다. / 이 경우는 열고 나서 실린더를 바꾸는 쪽으로 이야기하게 됩니다.

# 경우 6. 안에서 걸쇠가 걸린 채 한 뼘만 열린다
문이 조금 열렸는데 안쪽 걸쇠 때문에 더 안 열린다면 집 안에 누가 걸어 둔 것입니다. / 안에 계신 분께 걸쇠를 풀어 달라고 하면 되지만, 대답이 없다면 상황이 달라집니다.
안에 아이나 어르신이 계신데 반응이 없다면 그 사실을 통화 첫마디로 말씀해 주세요. / 이런 경우는 다른 일보다 먼저 움직입니다.
걸쇠가 걸린 틈으로 손이나 막대를 넣어 풀어 보려다 손가락을 다치는 일이 있습니다. / 문틈에 손을 넣은 채 바람에 문이 밀리면 위험하니 틈은 그대로 두고 기다려 주세요.

# 문 앞에서 피해야 할 행동
급하다 보면 손이 먼저 나가기 쉽습니다. / 아래 행동은 오히려 문과 도어락을 상하게 해서 여는 시간을 늘립니다.
- 손잡이를 세게 잡아당기거나 문을 발로 차기
- 문틈에 카드나 드라이버 끼워 넣기
- 번호를 계속 바꿔 가며 수십 번 누르기
- 실린더에 식용유나 접착력 있는 액체 넣기
빌라 계단에서 큰 소리로 문을 두드리면 이웃이 놀라기도 합니다. / 기다리는 동안에는 문 사진을 찍어 두는 게 가장 쓸모 있는 일입니다.

# 전화로 알려 주실 내용
위의 세 가지 답과 함께 아래를 알려 주시면 됩니다.
- 빌라 건물 이름이나 번지, 골목 입구에서 보이는 큰길
- 몇 층인지, 계단만 있는 건물인지
- 도어락 모양과 보조키가 있는지
- 집 안에 사람이나 반려동물이 있는지
신월동은 비슷한 빌라가 골목마다 이어져 있어 건물 이름이 가장 확실한 길잡이입니다. / 건물 이름이 없으면 1층 가게나 주차장 같은 표시를 말씀해 주세요.
@ 신월동 빌라 위치 설명 출장열쇠

# 도착해서 하는 확인과 비용 안내
문을 열기 전에 사시는 분인지 신분증 주소나 우편물로 확인합니다. / 신분증이 집 안에 있다면 집주인 연락이나 계약서 사진으로도 가능합니다.
그다음 문과 도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 못 열면 비용은 받지 않습니다.
여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다. / 덜 상하는 방법부터 차례로 시도합니다.

# 열린 뒤 원인에 맞게 손보기
건전지가 원인이었다면 새것으로 모두 바꾸고, 걸쇠가 문틀에 물렸다면 걸쇠 자리를 맞춥니다. / 번호 문제였다면 새 번호 등록까지 함께 합니다.
부품이 닳아 같은 일이 반복될 것 같으면 [도어락 수리](doorlock-repair.html)를 먼저 권합니다. / 수리로 어려울 만큼 낡았다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 신월동 말고 양천구 다른 동네
신월동 빌라 골목뿐 아니라 신정동 다세대와 목동 아파트 단지까지 양천구 어디든 24시간 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인해 보세요.
