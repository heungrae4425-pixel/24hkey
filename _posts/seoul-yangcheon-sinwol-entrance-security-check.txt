# 신월동 빌라 현관, 한 번쯤 살펴볼 때
방범 점검이라고 하면 거창하게 들리지만 실제로는 매일 쓰는 현관문이 제대로 잠기는지 확인하는 일에 가깝습니다. / 대부분의 문제는 장치가 부족해서가 아니라 있는 장치가 제 역할을 못 해서 생깁니다.
신월동은 양천구 서쪽 끝에 다세대 주택과 빌라가 골목마다 이어진 동네입니다. / 건물마다 공동현관, 계단, 세대 현관이 따로 있어 챙길 문이 하나가 아닙니다.
이 글은 신월동 빌라에서 혼자서도 해볼 수 있는 현관 점검 다섯 가지를 정리했습니다. / 불안을 키우자는 이야기가 아니라 있는 것을 제대로 쓰자는 이야기입니다.
@ 신월동 빌라 현관문 방범 점검

# 점검 하나, 문이 끝까지 닫히는지
가장 먼저 볼 것은 문을 놓았을 때 끝까지 닫히느냐입니다. / 문이 문틀에 살짝 걸려 덜 닫히면 도어락이 잠긴 것처럼 보여도 걸쇠가 제자리에 들어가지 않습니다.
문을 닫은 뒤 바깥에서 손잡이를 당기지 말고 문을 가볍게 밀어 보세요. / 덜컹거리며 틈이 생긴다면 걸쇠가 덜 물린 상태일 수 있습니다.
오래된 빌라는 문틀이 조금씩 처지면서 이런 일이 생깁니다. / 도어클로저 속도가 너무 빠르거나 느려도 문이 끝까지 붙지 않습니다.
- 문이 닫힌 뒤 바깥에서 밀었을 때 흔들림이 있는지
- 문 위쪽과 아래쪽 틈이 눈에 띄게 다른지
- 닫힐 때 문틀에 긁히는 소리가 나는지

# 점검 둘, 도어락 자동 잠김 설정
대부분의 도어락은 문이 닫히면 저절로 잠기는 자동 잠김 기능이 있습니다. / 그런데 수동 모드로 바뀌어 있으면 문을 닫아도 잠기지 않은 채로 남습니다.
문을 닫았을 때 잠기는 소리가 나는지 한 번 들어 보세요. / 소리가 나지 않으면 안쪽 몸체의 설정 버튼이나 스위치를 확인해 볼 필요가 있습니다.
제품마다 설정 방법이 다르니 설명서를 보시는 게 가장 정확합니다. / 설명서가 없다면 제조사 이름을 찾아 홈페이지에서 모델 설명서를 받을 수 있는 경우가 많습니다.

# 점검 셋, 번호판에 남는 흔적
자주 누르는 숫자 버튼은 손때가 묻어 반들반들해집니다. / 번호판을 비스듬히 비춰 보면 어떤 숫자를 많이 쓰는지 드러나기도 합니다.
가끔 마른 천으로 번호판 전체를 닦아 주시면 좋습니다. / 허수 입력 기능이 있는 도어락이라면 진짜 번호 앞뒤로 아무 숫자나 섞어 누르는 습관도 도움이 됩니다.
번호를 누를 때 손으로 가볍게 가리는 것도 오래된 방법이지만 여전히 쓸모가 있습니다. / 신월동 빌라처럼 계단실이 좁은 곳에서는 뒤에 누가 서 있는지도 한 번 보게 됩니다.
@ 양천구 신월동 도어락 번호판 지문 흔적 닦기

# 점검 넷, 비밀번호와 출입 수단 정리
이사 온 뒤로 번호를 한 번도 바꾸지 않았다면 이번에 바꿔 보세요. / 전에 사시던 분, 공사하러 왔던 분, 가끔 오던 지인이 번호를 알고 있을 수 있습니다.
카드키나 태그를 쓰는 도어락이라면 등록된 개수를 확인해 보시면 좋습니다. / 잃어버린 카드가 등록된 채 남아 있다면 지우고 새로 등록하는 편이 깔끔합니다.
- 가족 외에 번호를 아는 사람이 있는지
- 등록된 카드나 태그가 몇 개인지
- 임시 번호를 준 적이 있다면 지웠는지
- 번호가 생일이나 같은 숫자 반복은 아닌지

# 점검 다섯, 보조키와 걸쇠 상태
도어락 위나 아래에 보조키가 따로 달린 집이 신월동 빌라에는 꽤 있습니다. / 보조키를 거의 안 쓰다 보면 열쇠 구멍이 뻑뻑해져 정작 필요할 때 돌아가지 않습니다.
한 달에 한 번쯤 보조키를 잠갔다 풀어 보세요. / 뻑뻑하면 흑연 가루나 열쇠 전용 윤활제를 조금 쓰고, 식용유나 일반 기름은 먼지를 모으니 피해 주세요.
안쪽 걸쇠나 체인은 집에 있을 때 걸어 두는 장치입니다. / 고정 나사가 헐거우면 제 역할을 못 하니 손으로 흔들어 보고 헐겁다면 조여 두세요.

# 공동현관도 같이 생각하세요
빌라 공동현관 도어락은 여러 세대가 같이 쓰다 보니 번호가 오래 바뀌지 않는 경우가 많습니다. / 문이 천천히 닫혀 열린 채로 있는 시간이 긴 건물도 있습니다.
택배 기사나 배달원에게 공동현관 번호를 알려 주는 일이 잦은 건물이라면 더 그렇습니다. / 번호를 가끔 바꾸는 것만으로도 드나드는 사람을 어느 정도 정리할 수 있습니다.
공동현관 문제는 혼자 정할 수 있는 일이 아니라 건물 관리인이나 이웃과 이야기해야 합니다. / 번호 변경 주기나 도어클로저 점검을 같이 정해 두면 서로 편합니다.

# 과하게 하지 않아도 되는 것들
현관 보안을 위해 잠금장치를 여러 개 덧다는 분들이 있습니다. / 그런데 잠금이 많아질수록 급할 때 여는 데 시간이 오래 걸리고, 고장 날 곳도 늘어납니다.
불이 나거나 응급 상황일 때 안에서 빨리 나갈 수 있는지도 같이 생각해야 합니다. / 아이나 어르신이 있는 집이라면 안쪽에서 한 번에 열리는 구조가 더 중요할 수 있습니다.
있는 도어락이 제대로 잠기고, 번호가 관리되고, 문이 끝까지 닫히면 기본은 충분히 지켜진 셈입니다.

# 점검 결과는 짧게 적어 두세요
다섯 가지를 다 보셨다면 휴대폰 메모에 날짜와 함께 결과를 한 줄씩 남겨 두세요. / 다음 점검 때 무엇이 달라졌는지 비교하기 쉬워집니다.
예를 들어 문 아래쪽 틈이 지난번보다 넓어졌다면 경첩이나 문틀이 조금씩 처지고 있다는 뜻일 수 있습니다. / 이런 변화는 매일 보는 사람일수록 알아채기 어렵습니다.
배터리 교체일, 번호 바꾼 날, 카드 등록 개수도 같이 적어 두면 따로 기억하지 않아도 됩니다. / 가족과 공유해 두면 누가 챙겨도 같은 기준으로 볼 수 있습니다.
계절이 바뀔 때마다 한 번, 일 년에 네 번 정도면 충분합니다. / 대청소하는 날 현관까지 같이 본다고 생각하시면 부담이 덜합니다.

# 혼자 보기 어려울 때
점검해 봤는데 문이 끝까지 안 닫히거나 자동 잠김이 들쭉날쭉하다면 손을 봐야 할 때입니다. / [양천구 출장열쇠](seoul-yangcheon.html)로 연락 주시면 도어락과 문틀, 도어클로저를 같이 봐 드립니다.
고쳐서 쓸 수 있는 것은 [도어락 수리](doorlock-repair.html)로 손보고, 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 무조건 바꾸자고 하지 않습니다.
@ 신월동 현관 도어락 자동 잠김 점검 출장

# 방문 점검 때 확인하는 것
점검으로 방문해도 사시는 분인지는 똑같이 확인합니다. / 신분증 주소나 주소가 나온 우편물 정도면 충분합니다.
비용은 점검 내용을 보고 작업 전에 먼저 말씀드립니다. / 동의하지 않으시면 진행하지 않고, 자세한 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 신월동 말고 양천구 어디든
신월동 빌라 외에도 신정동 주택가, 목동 아파트 단지까지 양천구 전 지역을 다닙니다. / 문이 안 열리는 급한 일은 24시간 출동하고, 다른 구와 경기도는 [출장 지역](area.html)에서 보실 수 있습니다.
