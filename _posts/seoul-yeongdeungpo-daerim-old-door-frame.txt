# 대림동 주택, 무거운 철문이 말을 안 들을 때
대림동은 신길동과 이웃한 주택가로, 골목마다 다세대 주택과 오래된 단독주택이 이어지는 동네입니다. / 이런 집 현관에는 묵직한 철제 문이 달린 경우가 많고, 문 무게를 경첩 두세 개가 오랫동안 받쳐 왔습니다.
세월이 지나면 그 무게 때문에 문짝이 아주 조금씩 아래로 내려앉습니다. / 처음에는 닫을 때 툭 걸리는 정도였다가 어느 날은 번호가 맞아도 문이 열리지 않습니다.
이 글은 대림동 주택에서 오래된 현관문이 처져 안 열릴 때 어디부터 봐야 하는지 순서대로 적었습니다. / 문 여는 일이 급하면 [영등포 출장열쇠](seoul-yeongdeungpo.html)로 바로 연락 주셔도 됩니다.
@ 대림동 주택 철제 현관문 처짐

# 철문은 나무문과 처지는 모양이 다릅니다
나무문은 습기를 먹고 부풀면서 문틀에 끼는 일이 많습니다. / 철문은 부풀기보다 무게 때문에 경첩 쪽이 벌어지고 손잡이 쪽 모서리가 내려가는 모양으로 처집니다.
그래서 철문이 처지면 바닥보다 걸쇠와 받이가 먼저 어긋납니다. / 도어락 걸쇠가 문틀 받이 구멍의 아래쪽 가장자리에 걸려 빠지지 않는 상태가 됩니다.
겨울에는 쇠가 차가워지며 조금 줄어들고, 여름에는 볕을 받아 늘어납니다. / 계절에 따라 증상이 심해졌다 덜해졌다 한다면 이미 여유가 거의 없다는 뜻입니다.

# 처짐을 알아차리는 작은 신호
문이 완전히 막히기 전에 대부분 먼저 신호를 보냅니다. / 아래 중 두 가지 이상이 있으면 점검 시기로 보시면 됩니다.
- 문을 닫을 때 손잡이 쪽을 들어 올리듯 밀어야 잠긴다
- 닫힌 문 위쪽 틈은 넓고 아래쪽 틈은 좁다
- 문틀 받이 주변에 긁힌 자국이 새로 생겼다
- 경첩 쪽에서 끼익 하는 소리가 커졌다
- 도어락 걸쇠가 끝까지 나오지 않고 중간에 멈춘다
틈의 넓이는 위아래를 손가락이나 종이 한 장으로 비교해 보면 쉽게 알 수 있습니다.

# 지금 안 열린다면 문을 들어 올려 보세요
번호를 누르고 열림음이 났는데 문이 안 밀린다면 손잡이를 잡고 문을 위쪽으로 살짝 들어 올리듯 힘을 줘 보세요. / 처진 문이 받이에서 떨어지면서 걸쇠가 빠질 때가 있습니다.
열쇠로 여는 자물쇠라면 같은 방법으로 문을 든 채 열쇠를 돌려 봅니다. / 들어 올리는 힘은 손바닥으로 받쳐 주는 정도면 충분합니다.
두세 번 해서 안 되면 멈추세요. / 반복하면 걸쇠 끝이 받이에 더 깊이 박혀 오히려 빼기 어려워집니다.
@ 대림동 현관문 걸쇠 받이 어긋남

# 경첩 쪽을 먼저 보는 이유
처짐의 출발점은 거의 경첩입니다. / 문이 열려 있는 상태라면 경첩 나사가 풀려 있지 않은지 살펴보세요.
위쪽 경첩 나사가 헐거우면 문 전체가 앞으로 기울면서 손잡이 쪽이 내려갑니다. / 십자 드라이버로 조여 보고, 나사가 헛돌면 구멍이 닳은 것이니 더 조이지 마세요.
경첩 핀이 닳아 위아래로 들썩인다면 경첩 자체를 바꿔야 할 수 있습니다. / 문 무게가 큰 철문은 혼자 경첩을 빼면 위험하니 직접 분리하지는 마세요.

# 문틀이 벌어진 경우도 있습니다
오래된 주택은 문 대신 문틀이 움직이는 경우도 있습니다. / 벽과 문틀 사이 마감이 갈라졌거나 문틀 모서리가 비틀려 보이면 문틀 쪽입니다.
이럴 때는 경첩만 조여서는 해결되지 않습니다. / 받이 위치를 문 처진 만큼 옮기거나 받이를 깎아 걸쇠가 지나갈 길을 넓히는 작업이 필요합니다.
벽 자체가 갈라진 정도라면 열쇠 작업 범위를 넘으니 그 부분은 따로 말씀드립니다.

# 해 보기 쉬운데 피해야 할 것
철문이라 튼튼해 보여서 세게 다뤄도 될 것 같지만 그렇지 않습니다. / 문보다 도어락과 경첩이 먼저 상합니다.
- 문을 어깨로 밀거나 발로 차기
- 문틈에 일자 드라이버를 넣어 지렛대처럼 벌리기
- 걸쇠 받이를 망치로 두드려 펴기
- 경첩에 기름을 잔뜩 뿌려 놓고 문을 세게 여닫기
특히 지렛대처럼 벌리면 철문 모서리가 휘어서 나중에 문이 아예 안 맞게 됩니다.

# 다세대 주택이라면 함께 알려 주세요
대림동 다세대 주택은 건물 출입문과 세대 현관문이 따로 있는 경우가 많습니다. / 건물 출입문 비밀번호가 따로 있으면 연락하실 때 같이 알려 주세요.
계단이 좁거나 층이 높으면 장비를 들고 올라가는 데 시간이 조금 걸립니다. / 몇 층인지, 계단으로만 다니는 건물인지 말씀해 주시면 미리 준비합니다.
같은 건물 다른 세대도 문이 처지는 증상이 있다면 건물 전체 문제일 수 있으니 집주인에게도 알리는 것이 좋습니다.
@ 대림동 다세대 주택 현관 출장열쇠

# 문을 열기 전 거주 확인
문이 고장 나서 열어 달라는 요청이라도 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소나 주소가 적힌 우편물 가운데 하나를 준비해 주세요.
세입자라도 그 집에 사시는 분이면 됩니다. / 다만 문틀을 깎거나 경첩을 바꾸는 일은 집주인과 상의하시라고 권해 드립니다.
절차는 [이용안내](guide.html)에 따로 정리해 두었습니다.

# 무엇을 할지 정하고 나서 비용 안내
처진 문은 받이만 조금 옮기면 되는 집도 있고 경첩까지 손봐야 하는 집도 있습니다. / 상태를 보고 할 일을 정한 뒤, 손대기 전에 비용부터 말씀드립니다.
끝내 못 열면 비용은 받지 않습니다. / 문을 연 뒤 추가 수리를 원하지 않으시면 거기서 마치면 됩니다.

# 열고 나서 손봐 드리는 것
문이 열리면 걸쇠가 받이 구멍 가운데로 들어가는지 확인합니다. / 어긋났다면 받이 위치를 맞추고 경첩 나사를 다시 잡아 줍니다.
도어락이 처진 문 때문에 무리하게 돌아가며 모터가 약해졌다면 [도어락 수리](doorlock-repair.html)로 점검합니다. / 문을 바로잡은 뒤에도 잠금이 불안하면 그때 [도어락 교체](doorlock-replace.html)를 이야기합니다.
문 여는 방식은 [현관문 개문](door-open.html)에서 더 보실 수 있습니다.

# 철문을 오래 쓰려면
경첩 나사는 해가 바뀔 때쯤 한 번씩 조여 주세요. / 문을 닫을 때 쾅 소리가 날 만큼 세게 닫는 습관이 처짐을 앞당깁니다.
도어클로저가 달려 있다면 닫히는 속도를 조금 느리게 맞춰 두는 것이 좋습니다. / 문이 받이에 부딪히는 힘이 줄어 걸쇠와 받이가 덜 닳습니다.
현관 앞에 무거운 우산꽂이나 짐을 문손잡이에 걸어 두는 습관도 줄여 주세요. / 작은 무게라도 날마다 손잡이 쪽에 걸리면 경첩이 버티는 힘이 그만큼 빨리 줄어듭니다.
문틀 받이 주변에 연필로 걸쇠 자리를 살짝 표시해 두면 다음에 처짐이 생겼는지 한눈에 보입니다.
@ 대림동 철문 경첩 나사 점검 관리

# 대림동 말고 영등포구 다른 동네도
신길동, 도림동, 영등포동, 문래동, 당산동, 양평동, 여의도동까지 영등포구 어디든 출동합니다. / 대림동 골목 안 주택도 주소만 주시면 찾아갑니다.
영등포구 안 동네는 [영등포구 출장열쇠](seoul-yeongdeungpo.html)에, 서울과 경기 다른 지역은 [출장 지역](area.html)에 모아 두었습니다.

# 자주 묻는 질문
? 철문도 처지나요? | 네, 무게 때문에 경첩 쪽이 벌어지면서 손잡이 쪽이 내려앉습니다.
? 문을 들어 올리면 열린다는데 계속 그렇게 써도 될까요? | 임시로는 되지만 점점 심해지니 받이나 경첩을 손보시는 게 좋습니다.
? 경첩을 제가 직접 바꿔도 되나요? | 철문은 무거워 혼자 분리하면 위험합니다. 나사 조이기까지만 권합니다.
? 다세대 건물 출입문도 열어 주시나요? | 건물 관리자나 집주인 확인이 되면 공동 출입문도 봅니다.
? 처진 문을 끝내 못 열고 돌아가시면요? | 그 경우 비용은 받지 않습니다.
