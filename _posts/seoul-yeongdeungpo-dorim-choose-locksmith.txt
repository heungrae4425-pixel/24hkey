# 도림동, 급할수록 첫 통화가 중요합니다
문 앞에 서서 휴대폰으로 열쇠집을 찾으면 비슷비슷한 이름과 번호가 줄줄이 나옵니다. / 마음은 급한데 어디에 전화해야 할지 고르기가 쉽지 않습니다.
도림동은 영등포구 안에서도 빌라와 주택 골목이 많은 편이라, 가게를 직접 찾아가기보다 출장으로 부르는 경우가 대부분입니다. / 얼굴을 보기 전에 전화 한 통으로 판단해야 하니 무엇을 물어볼지 미리 알아 두면 훨씬 덜 헤맵니다.
이 글은 열쇠집이나 출장열쇠를 고를 때 전화로 꼭 물어볼 다섯 가지와, 통화하면서 눈여겨볼 점을 정리했습니다.
@ 도림동 열쇠집 고르는 법 출장열쇠

# 첫째, 비용은 언제 알려 주는지
가장 먼저 물어볼 것은 얼마냐가 아니라 언제 비용을 알려 주느냐입니다. / 문 상태와 도어락 종류를 보기 전에는 정확한 금액을 말하기 어려운 게 사실이기 때문입니다.
좋은 답은 도착해서 문을 보고, 작업을 시작하기 전에 먼저 말씀드린다는 것입니다. / 그리고 그 금액이 마음에 안 들면 그냥 돌려보낼 수 있는지도 같이 물어보세요.
전화로 너무 낮은 금액만 강조하는 곳이라면 현장에서 항목이 붙는지 한 번 더 확인해 두는 게 좋습니다. / 작업이 끝난 뒤에 처음 듣는 비용이 나오는 것이 가장 곤란한 경우입니다.

# 둘째, 못 열면 어떻게 되는지
드물지만 문 상태에 따라 끝내 못 여는 경우도 있습니다. / 이때 출장비나 작업비를 따로 받는지 미리 물어보세요.
못 열면 비용을 받지 않는다고 분명히 말하는 곳이라면 부르는 쪽도 마음이 놓입니다. / 이 부분을 흐리게 넘어가는 곳이라면 한 번 더 생각해 보셔도 됩니다.
문을 열긴 했는데 도어락이나 문이 상한 경우 어떻게 하는지도 같이 물어볼 만합니다. / 미리 들어 두면 나중에 서로 다르게 기억하는 일이 생기지 않습니다.
통화 내용을 짧게 메모해 두거나 문자로 한 번 더 받아 두는 것도 방법입니다. / 급한 상황일수록 들은 말을 금방 잊기 쉽기 때문입니다.

# 셋째, 신분 확인을 하는지
문을 열어 주는 일은 그 집에 사는 사람에게만 해 줘야 하는 일입니다. / 그래서 제대로 된 곳일수록 도착하면 신분증이나 우편물로 거주자인지 확인합니다.
확인 없이 그냥 열어 준다는 곳은 편해 보여도, 반대로 생각하면 다른 사람이 우리 집 문을 열어 달라고 해도 열어 준다는 뜻입니다. / 신분 확인을 한다고 하면 번거롭게 여기지 말고 오히려 믿을 만한 신호로 보시면 됩니다.
@ 영등포 도림동 출장열쇠 신분 확인 절차

# 넷째, 어떤 방식으로 여는지
문을 여는 방법은 여러 가지가 있고, 덜 상하는 방법부터 해 보는 곳이 좋습니다. / 처음부터 도어락을 뜯어내자고 하는 경우라면 다른 방법은 없는지 물어보세요.
- 도어락이나 문을 상하지 않게 여는 방법을 먼저 쓰는지
- 부품을 바꿔야 할 때 미리 물어보는지
- 교체를 권한다면 그 이유를 설명해 주는지
고쳐 쓸 수 있는데 교체부터 권한다면 이유를 한 번 더 들어 보는 게 좋습니다. / 수리로 될 일과 교체가 필요한 일은 분명히 다릅니다.

# 다섯째, 얼마나 걸려 도착하는지
늦은 밤이나 비 오는 날에는 도착 시간이 생각보다 중요합니다. / 대략 언제쯤 도착하는지, 늦어지면 미리 연락을 주는지 물어보세요.
정확한 시간을 약속하기 어려운 날도 있습니다. / 그럴 때 솔직하게 대략적인 시간을 말해 주고, 출발할 때와 가까이 왔을 때 연락을 주는 곳이 기다리는 사람 입장에서 편합니다.

# 통화하면서 눈여겨볼 것
질문에 대한 답 말고도 통화 분위기에서 알 수 있는 것이 있습니다. / 내 상황을 먼저 물어보는지가 그중 하나입니다.
- 번호판 상태, 도어락 종류, 안에 사람이 있는지 등을 묻는지
- 사진을 보내 달라고 하는지
- 직접 해볼 수 있는 방법이 있으면 먼저 알려 주는지
배터리 문제처럼 9V 건전지로 해결될 수 있는 상황인데 그걸 먼저 알려 주는 곳이라면 믿을 만합니다. / 무조건 출동부터 하겠다고 하기보다 상황을 듣고 판단해 주는 곳이 좋습니다.

# 이런 경우는 한 번 더 생각해 보세요
아래와 같은 반응이 나오면 다른 곳에도 전화해 보시는 게 낫습니다.
- 비용을 물으면 와서 보자는 말만 하고 기준을 전혀 말하지 않음
- 신분 확인은 필요 없다고 먼저 말함
- 못 열었을 때 처리를 물으면 답을 피함
- 상황을 듣지도 않고 교체부터 이야기함
급한 마음에 첫 번째 통화로 정해 버리기 쉽지만, 한두 군데 더 물어보는 데 드는 시간은 몇 분입니다. / 그 몇 분이 나중의 곤란함을 막아 줍니다.

# 도림동에서 저희에게 연락하시면
24시출장열쇠는 위 다섯 가지를 먼저 말씀드리는 것을 원칙으로 합니다. / 전화를 받으면 상황부터 여쭙고, 직접 해볼 방법이 있으면 그것부터 알려드립니다.
- 골목이나 건물 이름, 층수와 호수
- 번호판 상태와 도어락 종류
- 집 안에 사람이나 반려동물이 있는지
- 가능하면 도어락 사진 한 장
도림동 골목이 좁은 곳이라면 가까운 큰길에서 다시 전화 드리고 찾아갑니다.

# 신분 확인과 비용 안내 방식
도착하면 신분증 주소, 주소가 적힌 우편물, 관리사무소나 집주인 확인 가운데 하나로 사시는 분인지 먼저 확인합니다. / 신분증이 집 안에 있다면 문을 연 직후 확인해도 됩니다.
문과 도어락 상태를 본 뒤 비용을 먼저 말씀드리고, 괜찮다고 하실 때만 시작합니다. / 끝내 못 열면 비용은 받지 않고, 부품을 바꿔야 하면 바꾸기 전에 여쭤봅니다.
자세한 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.
@ 도림동 출장열쇠 비용 사전 안내

# 문을 연 뒤에 무엇을 해 주는지
문을 열고 끝이 아니라 도어락이 잘 잠기고 열리는지 같이 확인합니다. / 비밀번호를 잊은 경우라면 새 번호 등록까지, 배터리가 원인이었다면 교체까지 함께 봅니다.
문 여는 방식은 [현관문 개문](door-open.html), 고장 수리는 [도어락 수리](doorlock-repair.html), 교체가 필요할 때는 [도어락 교체](doorlock-replace.html)에 정리해 두었습니다.

# 미리 저장해 두면 좋은 것
문이 막힌 다음에 찾기보다, 평소에 믿을 만한 번호 하나를 휴대폰에 저장해 두면 급할 때 덜 당황합니다. / 가족 휴대폰에도 같이 저장해 두세요.
도어락 앞면 사진과 모델명도 휴대폰 앨범에 하나 남겨 두면 통화할 때 바로 보낼 수 있습니다. / 작은 준비지만 실제로 막혔을 때 시간을 꽤 아껴 줍니다.

# 도림동 말고 영등포구 어디든 갑니다
도림동 가까운 문래동, 신길동, 대림동, 영등포동은 물론 당산동, 양평동, 여의도동까지 다닙니다. / 영등포구 안이면 시간 상관없이 출동합니다.
다니는 곳은 [영등포 출장열쇠](seoul-yeongdeungpo.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 못 열면 비용을 내나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
