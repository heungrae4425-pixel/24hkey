# 문래동, 어제까지 열리던 번호가 안 맞을 때
문래동은 아파트와 오래된 주택이 한 동네 안에 섞여 있고, 영등포역과 당산동 아파트 사이를 오가는 생활권입니다. / 집 형태가 다양한 만큼 현관에 달린 도어락도 번호식, 카드 겸용, 손잡이 일체형까지 제각각입니다.
퇴근하고 늘 누르던 번호를 눌렀는데 삐 소리와 함께 거절되면 처음엔 손가락이 미끄러진 줄 압니다. / 두세 번 해 봐도 안 되면 그때부터 머릿속이 하얘집니다.
이 글은 번호를 잊은 경우와 함께, 가족 중 누가 번호를 바꿔 두고 말을 안 한 경우를 따로 나눠 정리했습니다. / 집 안에 들어가는 방법은 [영등포 출장열쇠](seoul-yeongdeungpo.html) 페이지에도 모아 두었습니다.
@ 문래동 도어락 비밀번호 분실 현관 앞

# 잊은 건지, 바뀐 건지부터 가려 보세요
번호가 안 맞는 이유는 크게 두 갈래입니다. / 내가 기억을 못 하는 것인지, 누군가 번호를 새로 등록한 것인지에 따라 다음 행동이 달라집니다.
- 최근에 내가 번호를 바꾼 적이 있다면 기억 쪽 문제
- 같이 사는 사람이 있고 최근 집수리나 이사 손님이 다녀갔다면 변경 쪽 가능성
- 가족 단체 대화방에 번호 이야기가 오간 적이 있다면 바로 확인
- 번호판에서 거절음이 아니라 아무 반응이 없다면 번호보다 전원 문제
특히 전원이 꺼진 상태를 번호 문제로 착각하는 일이 꽤 많습니다. / 번호판에 손을 대 불이 들어오는지 한 번 보고 시작하세요.

# 가족에게 연락할 때 물어볼 것
가족이 바꿨을 가능성이 있다면 전화 한 통으로 끝날 수도 있습니다. / 다만 상대가 바로 받지 못하는 시간이라면 문자로 짧게 남겨 두는 게 좋습니다.
- 최근에 현관 번호를 새로 등록했는지
- 바꿨다면 몇 자리로 바꿨는지
- 예전 번호를 지웠는지, 두 개를 같이 쓰는지
- 카드키나 지문을 따로 등록해 둔 사람이 있는지
번호를 바꾼 사람도 자기가 바꾼 걸 잊고 있다가 질문을 받고서야 떠올리는 경우가 있습니다. / 몇 자리였는지 같은 구체적인 질문이 기억을 꺼내는 데 도움이 됩니다.

# 번호판 앞에서 자꾸 누르지 마세요
기억을 더듬으며 비슷한 번호를 이것저것 눌러 보고 싶어집니다. / 하지만 대부분의 도어락은 몇 번 연속으로 틀리면 한동안 입력을 막아 버립니다.
입력이 막힌 동안에는 맞는 번호를 눌러도 열리지 않습니다. / 가족에게서 번호를 받았는데도 안 열려서 더 혼란스러워지는 일이 이렇게 생깁니다.
두세 번 틀렸다면 잠시 손을 떼고 기다리세요. / 경고음이 길게 울리면 이웃이 놀랄 수 있으니 그 시간에 가족 연락을 먼저 해 두는 편이 낫습니다.

# 오래된 주택 현관이라면 열쇠 구멍도 살펴보세요
문래동 주택 가운데는 도어락 아래나 위에 예전 보조 자물쇠가 그대로 남은 집이 있습니다. / 이런 문은 도어락 번호와 상관없이 열쇠로 따로 잠그는 구조일 수 있습니다.
도어락 몸체에 열쇠 구멍 덮개가 달린 제품도 있습니다. / 비상 열쇠를 받아 둔 적이 있다면 서랍이나 차 안을 떠올려 보세요.
보조 자물쇠까지 잠겨 있다면 번호를 알아내도 문이 안 열립니다. / 이 경우 전화하실 때 자물쇠가 두 개라는 점을 꼭 같이 말씀해 주세요.
@ 문래동 현관 도어락 보조 자물쇠 확인

# 카드나 지문으로 들어갈 수 있는지
번호 말고 다른 방법이 등록돼 있으면 굳이 번호를 찾을 필요가 없습니다. / 지갑이나 휴대폰 케이스 안에 카드키가 끼워져 있지 않은지 한 번 보세요.
지문을 등록해 두었는데 인식이 잘 안 된다면 손을 비벼 따뜻하게 한 뒤 천천히 대 보세요. / 손이 차거나 젖어 있으면 인식률이 떨어집니다.
다만 번호를 바꾼 가족이 카드와 지문까지 모두 초기화했다면 다른 수단도 막혔을 수 있습니다. / 그때는 무리하게 시도하지 말고 연락 주시면 됩니다.

# 혼자 열어 보려다 일이 커지는 경우
문틈에 카드나 얇은 도구를 넣어 걸쇠를 밀어 보려는 분이 있습니다. / 요즘 도어락은 이런 방식으로 잘 열리지 않고, 문틈 고무와 도어락 외관에 흠만 남습니다.
번호판을 뜯어 배선을 만지는 것도 피해 주세요. / 회로가 상하면 번호 문제가 도어락 교체 문제로 바뀝니다.
손잡이를 세게 흔들거나 문을 어깨로 미는 것도 같은 이유로 권하지 않습니다. / 문을 연 뒤에 쓸 수 있는 상태로 남겨 두는 것이 비용을 아끼는 길입니다.

# 문래동에서 연락 주실 때 알려 주실 것
전화로 몇 가지만 들으면 어떤 장비를 챙겨야 할지 정해집니다. / 아래 내용을 미리 떠올려 두시면 통화가 짧아집니다.
- 아파트인지, 주택이나 빌라인지와 대략의 위치
- 번호판 불이 들어오는지, 거절음이 나는지
- 보조 자물쇠가 따로 있는지
- 도어락 앞면 사진을 보낼 수 있는지
- 집 안에 사람이나 반려동물이 있는지
가족과 연락이 닿을 것 같으면 그 사이 출발해서 기다리는 방법도 있습니다. / 번호가 확인되면 바로 말씀해 주시면 됩니다.

# 집에 사시는 분인지 확인한 뒤 엽니다
비밀번호를 모르는 상황은 집주인이 아닌 사람도 똑같이 말할 수 있는 상황입니다. / 그래서 문을 열기 전에 거주하시는 분인지 반드시 확인합니다.
주소가 적힌 신분증이나 우편물, 또는 관리사무소 세대 확인이면 충분합니다. / 신분증이 집 안에 있으면 문을 연 직후 바로 보여 주시는 조건으로 진행하기도 합니다.
가족이 함께 계시면 번호를 바꾼 가족과 통화 연결을 해 주셔도 좋습니다. / 이 절차는 [이용안내](guide.html)에도 적어 두었습니다.

# 얼마인지는 작업 전에 먼저
도어락 종류와 문 상태를 본 뒤 비용을 먼저 말씀드립니다. / 듣고 괜찮으시면 시작하고, 아니면 그냥 돌아가도 됩니다.
끝까지 못 열면 비용은 받지 않습니다. / 작업이 끝난 뒤 따로 덧붙는 항목도 없습니다.
문 여는 과정은 [현관문 개문](door-open.html) 페이지에서 미리 보셔도 됩니다.

# 열린 뒤에는 번호를 가족과 함께 정리
문이 열리면 안쪽에서 새 번호를 등록합니다. / 기존 번호는 지우고, 가족 모두가 알 수 있는 번호 하나만 남기는 것을 권합니다.
- 새 번호는 가족 대화방보다 직접 말로 전하기
- 바꾼 사람이 다른 가족에게 알렸는지 그날 바로 확인
- 카드키와 지문 등록 상태도 같이 정리
- 배터리 잔량도 이때 함께 점검
도어락이 오래돼 등록 버튼이 잘 안 눌린다면 [도어락 수리](doorlock-repair.html)로 손보고, 그래도 불안하면 [도어락 교체](doorlock-replace.html)를 이야기해 볼 수 있습니다.

# 번호 때문에 다시 막히지 않으려면
번호를 바꿀 때는 바꾼 날 저녁에 가족 모두가 한 번씩 직접 눌러 보게 하세요. / 머리로 아는 것과 손가락이 기억하는 것은 다릅니다.
휴대폰 메모에 번호를 그대로 적기보다 나만 알아볼 힌트로 남겨 두는 방법도 있습니다. / 카드키 하나는 믿을 만한 곳에 따로 보관해 두면 번호를 잊어도 들어갈 길이 생깁니다.

# 문래동 말고 영등포구 어디든 갑니다
문래동과 맞닿은 도림동, 당산동, 양평동은 물론 영등포동, 여의도동, 신길동, 대림동까지 영등포구 전 지역을 다닙니다. / 동네가 어디든 24시간 연락받습니다.
영등포구 안 동네는 [영등포구 출장열쇠](seoul-yeongdeungpo.html)에, 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

? 맞는 번호를 받았는데도 안 열려요 | 여러 번 틀려 입력이 잠긴 상태일 수 있습니다. 잠시 기다린 뒤 다시 눌러 보세요.
? 보조 자물쇠까지 잠겨 있어도 되나요? | 됩니다. 전화하실 때 자물쇠가 두 개라고 미리 알려 주세요.
? 신분증이 집 안에 있어요 | 관리사무소 확인이나 문을 연 직후 신분증 확인으로 진행할 수 있습니다.
? 못 열면 비용이 드나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
