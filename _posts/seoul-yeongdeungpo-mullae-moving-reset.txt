# 문래동 새집, 열쇠를 받았다고 끝이 아닙니다
문래동은 아파트와 오래된 주택이 섞여 있어 이사 오는 집의 모양도, 달려 있는 도어락도 제각각입니다. / 영등포역과 당산동 쪽을 오가기 편한 생활권이라 직장 때문에 이사 오는 분도 많습니다.
이사 날 공인중개사나 집주인에게 현관 번호를 건네받으면 일단 안심이 됩니다. / 그런데 그 번호는 전에 살던 사람도, 집을 보러 왔던 사람도, 도배하러 왔던 업체도 알고 있었을 수 있는 번호입니다.
이 글은 문래동에서 이사할 때 도어락 기록을 언제, 어떤 순서로 비워야 하는지 정리했습니다. / 혼자 하다 막히면 [영등포 출장열쇠](seoul-yeongdeungpo.html)로 연락 주시면 됩니다.
@ 문래동 이사 도어락 초기화 새 번호

# 도어락에 남아 있을 수 있는 것들
도어락은 번호 하나만 기억하는 장치가 아닙니다. / 제품에 따라 여러 가지 열 수 있는 수단이 함께 저장돼 있습니다.
- 사용자 비밀번호 한 개 또는 여러 개
- 등록된 카드키나 스티커형 태그
- 지문 여러 개
- 휴대폰 앱이나 리모컨 연결
- 손님용 일회용 번호
번호만 바꾸고 카드나 지문은 그대로 두면 예전 카드를 가진 사람은 여전히 문을 열 수 있습니다. / 그래서 이사 때는 하나만 바꾸는 게 아니라 전부 비우는 것을 기본으로 생각하셔야 합니다.

# 언제 하는 게 좋을까
가장 좋은 때는 이삿짐이 들어오기 전 빈집 상태일 때입니다. / 문을 활짝 열어 두고 안쪽 덮개를 편하게 열 수 있어 작업이 쉽습니다.
이삿짐이 들어오는 동안에는 문이 계속 열려 있어야 하니 자동 잠금이 오히려 방해가 됩니다. / 짐을 다 들인 뒤 저녁에 하려다 피곤해서 미루는 경우가 많으니, 가능하면 짐 들이기 전 짧게라도 끝내 두세요.
짐을 다 들인 뒤에 하더라도 그날을 넘기지 않는 것이 좋습니다.

# 공사 업체가 쓰던 번호도 지워야 합니다
입주 전에 도배나 장판, 욕실 공사를 했다면 업체가 드나들기 위해 임시 번호를 받았을 가능성이 큽니다. / 공사가 끝나도 그 번호를 따로 지우지 않으면 그대로 남습니다.
집주인이 공사를 맡겼다면 어떤 번호를 알려 줬는지 물어보세요. / 대답이 애매하면 전체 초기화를 하는 것이 가장 확실합니다.
@ 문래동 입주 전 공사 후 도어락 번호 정리

# 안쪽 덮개 아래 버튼을 찾아보세요
대부분 도어락은 안쪽 몸체의 배터리 덮개를 열면 등록 버튼이나 설정 버튼이 있습니다. / 버튼 이름은 제품마다 달라서 등록, 설정, 초기화, 별 모양 같은 표시로 되어 있습니다.
도어락 옆면이나 덮개 안쪽에 모델명이 적혀 있습니다. / 설명서가 없다면 모델명으로 제조사 안내를 찾아보면 초기화 방법이 나와 있는 경우가 많습니다.
버튼을 길게 누르는지 짧게 누르는지에 따라 기능이 달라지니 안내를 보고 그대로 따라 하세요. / 짐작으로 여러 번 누르면 원하지 않는 설정이 바뀌기도 합니다.

# 비우고 등록하는 순서
제품마다 조금씩 다르지만 흐름은 대체로 비슷합니다. / 아래 순서를 기준으로 생각하시면 됩니다.
- 문을 열어 둔 상태에서 안쪽 덮개 열기
- 전체 초기화 또는 사용자 전체 삭제 실행
- 새 비밀번호 등록 후 바깥에서 두세 번 확인
- 가족 카드키, 지문을 새로 등록
- 앱이나 리모컨은 마지막에 다시 연결
새 번호를 확인할 때는 반드시 문을 연 상태에서 바깥 번호판으로 눌러 보세요. / 문을 닫고 시험하다 번호가 제대로 안 들어갔으면 새집 앞에서 그대로 갇히게 됩니다.

# 관리자 번호가 따로 있는 제품
일부 제품은 사용자 번호와 별도로 관리자 번호나 마스터 카드가 있습니다. / 이걸 모르면 초기화가 막히거나, 초기화를 해도 관리자 번호는 남아 있을 수 있습니다.
관리자 번호를 전 거주자만 알고 있다면 집주인에게 물어보거나 제조사 방식대로 공장 초기화를 해야 합니다. / 이 단계에서 막히는 분이 많아 출장을 부르시는 경우가 흔합니다.

# 주택이라면 열쇠 자물쇠도 살펴보세요
문래동 오래된 주택은 도어락 외에 보조 자물쇠나 대문 자물쇠가 함께 있는 경우가 있습니다. / 이런 자물쇠는 열쇠가 몇 개 돌았는지 아무도 모릅니다.
열쇠 자물쇠는 번호처럼 지울 수 없으니 실린더를 바꾸는 방법밖에 없습니다. / 계속 쓰실 생각이면 이사하면서 함께 바꾸시는 게 마음 편합니다.
@ 문래동 주택 보조 자물쇠 실린더 교체

# 혼자 하다 막히는 지점
초기화가 안 되거나, 등록 버튼이 안 눌리거나, 새 번호가 저장되지 않는다면 억지로 반복하지 마세요. / 배터리가 약할 때 등록이 실패하는 경우도 많으니 새 배터리로 바꾸고 한 번 더 해 보세요.
그래도 안 되면 도어락 상태를 사진으로 찍어 보내 주세요. / 모델명이 보이면 미리 방법을 확인하고 갑니다.
초기화 도중 문을 닫아 버리면 등록된 번호가 하나도 없는 상태로 잠길 수 있습니다. / 작업하는 동안에는 문 아래에 신발이나 문 받침을 끼워 문이 닫히지 않게 해 두세요.
이삿짐 업체가 오가는 시간에 맞물리면 누군가 무심코 문을 닫는 일이 생기기 쉽습니다. / 작업 중이라고 한마디 알려 두시면 이런 일을 막을 수 있습니다.
@ 문래동 도어락 등록 버튼 초기화 작업

# 새 집 거주자인지 확인합니다
초기화와 재등록은 그 집에 들어와 사실 분인지 확인한 뒤 진행합니다. / 이사 직후라 신분증 주소가 바뀌지 않았다면 임대차 계약서나 매매 계약서, 관리사무소 입주 확인으로 대신할 수 있습니다.
자세한 절차는 [이용안내](guide.html)에 정리해 두었습니다.

# 비용은 작업 전에 알려 드립니다
초기화만 하면 되는지, 부품이나 실린더를 바꿔야 하는지 보고 비용을 먼저 말씀드립니다. / 동의하신 다음에만 시작합니다.
문이 잠겨 들어갈 수 없는 상태에서 못 열면 비용은 받지 않습니다. / 잠긴 경우의 진행 방식은 [현관문 개문](door-open.html)에서 보실 수 있습니다.

# 이사 첫 주에 정리해 둘 것
번호를 바꿨다면 가족 모두가 직접 한 번씩 눌러 보게 하세요. / 카드키는 몇 장을 등록했는지 적어 두면 나중에 잃어버렸을 때 정리가 쉽습니다.
도어락이 오래돼 등록이 자꾸 실패한다면 [도어락 수리](doorlock-repair.html)로 점검하거나, 이참에 [도어락 교체](doorlock-replace.html)를 고민해 보셔도 됩니다. / 새로 다는 경우라면 [도어락 설치](doorlock-install.html)에서 문 두께부터 확인해 보세요.

# 문래동 밖 영등포구도 다닙니다
도림동, 양평동, 당산동, 영등포동, 신길동, 대림동, 여의도동까지 영등포구 전 지역으로 갑니다. / 이사 날 저녁이든 다음 날 새벽이든 연락 주세요.
영등포구 안 동네는 [영등포구 출장열쇠](seoul-yeongdeungpo.html), 서울과 경기 다른 곳은 [출장 지역](area.html)에서 확인하실 수 있습니다.
