# 신길동, 손에 열쇠 반쪽만 남았다면
신길동은 재개발로 들어선 새 아파트와 오래된 주택이 섞여 있는 동네로, 신길역 생활권에 속한 곳이 많습니다. / 오래된 주택 현관에는 아직 열쇠로 여는 보조 자물쇠와 대문 자물쇠가 남아 있는 집이 적지 않습니다.
열쇠를 돌리는데 평소보다 뻑뻑하다 싶더니 딱 소리와 함께 손잡이 쪽만 손에 남는 일이 있습니다. / 남은 반쪽은 열쇠구멍 안에 박혀 보이기만 하고 손가락으로는 잡히지 않습니다.
이 글은 신길동에서 열쇠가 부러져 구멍에 남았을 때 하면 안 되는 일부터 적었습니다. / 이어서 [영등포 출장열쇠](seoul-yeongdeungpo.html)가 와서 어떻게 꺼내는지, 꺼낸 뒤에 무엇을 보는지 정리했습니다.
@ 신길동 열쇠구멍 부러진 열쇠 제거

# 열쇠는 왜 구멍 안에서 부러질까
열쇠가 부러지는 건 대개 한 번에 생기는 일이 아닙니다. / 오랫동안 쌓인 무리가 어느 날 한꺼번에 터지는 것입니다.
- 열쇠구멍 안에 먼지와 녹이 쌓여 돌릴 때마다 힘이 더 들었던 경우
- 복사한 열쇠의 홈이 조금 어긋나 억지로 돌려 왔던 경우
- 열쇠가 휘어 있었는데 그대로 쓴 경우
- 문이 처져서 자물쇠 혀가 문틀에 눌린 상태로 돌린 경우
신길동 오래된 주택처럼 같은 자물쇠를 오래 써 온 집에서는 이런 조건이 겹치기 쉽습니다. / 부러지기 전에 뻑뻑함이 있었다면 그게 신호였던 셈입니다.

# 순간접착제는 절대 쓰지 마세요
부러진 조각에 접착제를 묻혀 붙인 뒤 당겨 빼겠다는 생각을 많이들 합니다. / 하지만 접착제가 조각 주변으로 흘러 들어가면 실린더 안쪽 핀까지 굳어 버립니다.
그렇게 되면 조각을 빼더라도 열쇠구멍 자체를 다시 쓸 수 없습니다. / 꺼내기만 하면 됐을 일이 실린더 교체로 커집니다.
같은 이유로 녹 제거제나 기름을 많이 뿌리는 것도 피해 주세요. / 조각이 미끄러져 더 깊이 들어갈 수 있습니다.

# 핀셋이나 머리핀으로 파내지 마세요
조각 끝이 살짝 보이면 핀셋으로 집어 보고 싶어집니다. / 그런데 핀셋 끝이 조각을 밀어 넣는 방향으로 힘이 가는 경우가 대부분입니다.
머리핀이나 클립을 넣어 휘젓는 것도 마찬가지입니다. / 안쪽 핀이 어긋나거나 클립 끝이 부러져 구멍 안에 조각이 하나 더 늘어나기도 합니다.
조각이 바깥으로 1~2밀리 이상 나와 있고 손으로 잡히는 정도가 아니라면 그대로 두시는 게 낫습니다. / 손대지 않은 상태일수록 꺼내기가 쉽습니다.
@ 신길동 보조 자물쇠 열쇠 조각 상태

# 문이 잠긴 상태인지 열린 상태인지
부러진 순간 문이 잠겨 있었는지 풀려 있었는지가 중요합니다. / 이것에 따라 서둘러야 하는지가 갈립니다.
문이 열린 채로 부러졌다면 일단 집에 들어갈 수는 있습니다. / 이때는 자물쇠를 잠그지 말고 그대로 두었다가 시간 날 때 연락 주시면 됩니다.
잠긴 상태에서 부러졌다면 그 자물쇠로는 문을 열 수 없습니다. / 도어락이 따로 달려 있어도 보조 자물쇠가 잠겨 있으면 문은 안 열리니 출장이 필요합니다.

# 대문 자물쇠에서 부러진 경우
신길동 주택은 현관 앞에 대문이 따로 있는 집이 있습니다. / 대문 자물쇠는 비바람을 그대로 맞아 녹이 잘 슬고, 그만큼 열쇠가 부러지는 일도 잦습니다.
대문이 막히면 현관까지 가지도 못합니다. / 다른 세대와 같이 쓰는 대문이라면 이웃에게도 바로 알려 주셔야 합니다.
대문 열쇠를 여러 집이 나눠 쓰는 경우 새 열쇠가 몇 개 필요한지도 미리 생각해 두면 좋습니다. / 실린더를 바꾸게 되면 모든 세대 열쇠가 함께 바뀝니다.

# 연락하실 때 보내 주시면 좋은 사진
부러진 열쇠 반쪽과 열쇠구멍을 가까이서 찍은 사진이 가장 도움이 됩니다. / 조각이 구멍 안쪽 어디쯤 있는지 보이면 필요한 공구를 정할 수 있습니다.
- 손에 남은 열쇠 반쪽 사진
- 열쇠구멍 정면 사진
- 자물쇠 전체가 보이는 사진
- 문이 잠긴 상태인지 여부
- 현관인지, 대문인지, 보조 자물쇠인지
사진을 보내기 어려우면 전화로 상황만 말씀해 주셔도 됩니다.

# 집주인인지 확인하고 시작합니다
부러진 열쇠를 꺼내는 일도 결국 잠긴 문을 여는 일과 이어집니다. / 그래서 거주하시는 분인지 먼저 확인합니다.
신분증의 주소, 집 주소가 찍힌 우편물, 관리사무소 확인 중 하나면 됩니다. / 주택이라 관리사무소가 없다면 우편물이나 임대 계약서로도 확인할 수 있습니다.
진행 순서는 [이용안내](guide.html)에서 미리 보실 수 있습니다.

# 조각을 꺼내는 과정
전용 공구를 열쇠구멍 홈을 따라 넣어 조각에 걸고 천천히 빼냅니다. / 실린더 핀이 상하지 않도록 조각을 비트는 대신 곧게 당겨 내는 것이 핵심입니다.
조각이 깊이 박혀 있거나 이미 누가 손을 댔다면 시간이 조금 더 걸립니다. / 그래도 대부분은 실린더를 뜯지 않고 꺼낼 수 있습니다.
문이 잠긴 상태라면 조각을 뺀 뒤 문을 엽니다. / 열쇠구멍이 상해서 열 수 없으면 덜 상하는 방법으로 [현관문 개문](door-open.html)을 진행합니다.
@ 신길동 출장열쇠 열쇠 조각 빼내기 작업

# 비용은 꺼내기 전에 먼저 말씀드립니다
조각 위치와 자물쇠 상태를 본 뒤 비용을 미리 알려 드립니다. / 그 자리에서 결정하시면 되고, 원치 않으시면 진행하지 않습니다.
문을 못 열면 비용은 받지 않습니다. / 실린더 교체가 필요해 보이면 꺼내는 일과 따로 나눠서 여쭤봅니다.

# 꺼낸 뒤 실린더를 계속 써도 될까
조각을 빼고 나면 원래 열쇠 반쪽을 버리고 남은 열쇠로 몇 번 돌려 봅니다. / 부드럽게 돌아가면 그대로 쓰셔도 됩니다.
여전히 뻑뻑하다면 실린더 안쪽이 닳았거나 녹이 슨 것입니다. / 이때는 실린더만 바꾸거나, 이참에 보조 자물쇠를 도어락으로 정리하는 방법도 있습니다.
도어락으로 바꾸실 생각이면 [도어락 설치](doorlock-install.html)에서 문 두께와 구멍 위치를 먼저 확인해 보세요. / 지금 쓰는 도어락이 오래돼 같이 바꾸려면 [도어락 교체](doorlock-replace.html)를 참고하시면 됩니다.

# 다시 부러지지 않게 하려면
열쇠가 뻑뻑해지기 시작하면 그때가 손볼 시기입니다. / 흑연 가루처럼 열쇠구멍 전용 윤활제를 조금 넣으면 한결 부드러워집니다.
- 휘거나 홈이 닳은 열쇠는 새로 복사하기
- 복사 열쇠가 잘 안 맞으면 원본으로 다시 복사하기
- 열쇠를 돌릴 때 문을 살짝 당겨 혀가 눌리지 않게 하기
- 대문 자물쇠는 비 온 뒤 물기를 털어 주기
여분 열쇠 하나는 집 밖 믿을 만한 곳에 두면 부러지는 날에도 덜 막막합니다. / 가족 중 한 명이 갖고 있어도 충분합니다.
@ 신길동 열쇠구멍 윤활 관리 여분 열쇠

# 신길동 밖 영등포구도 다닙니다
신길동과 맞닿은 대림동, 도림동, 영등포동은 물론 여의도동, 당산동, 문래동, 양평동까지 영등포구 전 지역에 갑니다. / 주택가 골목 안도 위치만 알려 주시면 찾아갑니다.
영등포구 안 동네는 [영등포구 출장열쇠](seoul-yeongdeungpo.html), 서울과 경기 다른 곳은 [출장 지역](area.html)을 보시면 됩니다.

# 마무리
신길동에서 열쇠가 부러졌다면 핀셋이나 접착제를 쓰지 말고 그 상태 그대로 사진부터 찍어 두세요. / 손대지 않은 열쇠구멍이 가장 빨리, 가장 덜 상하게 해결됩니다.
24시출장열쇠는 신길동 주택가 늦은 밤에도 출동합니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
