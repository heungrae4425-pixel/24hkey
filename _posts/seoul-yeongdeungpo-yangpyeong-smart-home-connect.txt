# 양평동, 앱 화면에 오프라인만 떠 있다면
양평동은 당산동과 이웃한 동네로 아파트와 빌라가 함께 있어, 집 구조에 따라 공유기와 현관 사이 거리도 제각각입니다. / 요즘은 이런 집에도 휴대폰 앱과 연결되는 도어락을 다는 경우가 많아졌습니다.
처음 설치했을 때는 문이 열릴 때마다 알림이 바로 오고, 밖에서 문 상태도 확인돼서 편합니다. / 그런데 어느 날부터 앱에 연결 끊김이 뜨거나 알림이 몇 시간 뒤에 몰려오기 시작합니다.
이 글은 양평동에서 도어락 앱 연동이 말썽일 때 휴대폰, 연결 장치, 도어락 순서로 하나씩 짚어 보는 방법을 적었습니다. / 문 자체가 안 열리는 상황이면 [영등포 출장열쇠](seoul-yeongdeungpo.html)로 먼저 연락 주세요.
@ 양평동 스마트 도어락 앱 연결 끊김

# 문은 열리는지부터 확인하세요
앱이 안 돼도 번호나 카드, 지문으로 문이 열린다면 급한 상황은 아닙니다. / 연동은 편의 기능이고 잠금 자체는 도어락이 따로 하고 있기 때문입니다.
반대로 앱도 안 되고 번호판도 꺼져 있다면 배터리 문제일 가능성이 큽니다. / 이때는 연동보다 전원부터 해결해야 합니다.
이 구분만 먼저 해 두면 지금 당장 무엇을 해야 할지 정해집니다. / 대부분은 시간을 두고 천천히 확인해도 되는 경우입니다.

# 도어락은 어떤 길로 휴대폰과 이어질까
연동 방식을 알아야 어디서 끊겼는지 찾을 수 있습니다. / 제품 설명서나 앱 설정 화면에서 아래 중 어떤 방식인지 확인해 보세요.
- 도어락이 직접 집 와이파이에 붙는 방식
- 도어락 옆이나 거실에 작은 연결 장치를 두는 방식
- 휴대폰과 블루투스로 가까이서만 연결되는 방식
- 집 전체 스마트홈 기기와 함께 묶인 방식
블루투스 방식이라면 집 밖 멀리서는 원래 연결이 안 됩니다. / 밖에서 문 상태가 안 보이는 게 고장이 아닐 수도 있다는 뜻입니다.

# 휴대폰 설정이 알림을 막는 경우
알림이 아예 안 오거나 늦게 몰려온다면 휴대폰 쪽을 먼저 의심해 보세요. / 앱은 멀쩡한데 휴대폰이 앱을 잠재우고 있는 경우가 많습니다.
- 배터리 절약 모드에서 해당 앱이 제외돼 있는지
- 앱 알림 권한이 꺼져 있지 않은지
- 휴대폰을 바꾸거나 앱을 다시 깔고 로그인했는지
- 앱 업데이트를 미뤄 둔 상태인지
휴대폰 운영체제를 업데이트한 직후 알림 설정이 초기화되는 일도 있습니다. / 최근 업데이트가 있었다면 앱 알림 설정을 다시 켜 보세요.
@ 양평동 휴대폰 도어락 앱 알림 설정

# 공유기와 연결 장치 쪽 확인
와이파이 방식이나 연결 장치 방식이라면 집 인터넷이 바뀌었는지가 중요합니다. / 통신사를 바꾸거나 공유기를 새로 달았다면 도어락은 예전 공유기를 계속 찾고 있습니다.
연결 장치의 표시등이 꺼져 있거나 빨갛게 깜빡이면 전원이나 인터넷 연결 문제입니다. / 전원을 뽑았다가 잠시 뒤 다시 꽂아 보세요.
현관이 공유기에서 멀거나 사이에 벽이 여러 겹 있으면 신호가 약해 자주 끊깁니다. / 연결 장치를 현관 쪽으로 조금 옮기는 것만으로도 나아질 때가 있습니다.

# 도어락 배터리가 통신을 먼저 멈춥니다
도어락 배터리가 줄어들면 잠금 기능은 유지하면서 통신부터 줄이는 제품이 많습니다. / 그래서 문은 잘 열리는데 앱만 자꾸 끊긴다면 배터리가 원인일 수 있습니다.
배터리 경고음이 아직 안 났더라도 새 배터리로 바꿔 보세요. / 통신 기능을 쓰는 도어락은 배터리가 일반 도어락보다 빨리 닳습니다.
배터리를 갈 때 통신 모듈이 따로 달린 제품은 모듈 쪽 배터리도 확인해야 합니다. / 모듈 배터리는 따로 떨어져 있어 놓치기 쉽습니다.

# 가족 초대와 권한이 꼬였을 때
가족을 앱에 초대했는데 상대에게만 알림이 안 가거나 문 열기가 안 된다면 권한 설정을 보세요. / 초대받은 사람이 보기만 가능한 권한으로 등록된 경우가 있습니다.
처음 등록한 사람의 계정을 지우거나 휴대폰 번호를 바꾸면 가족 공유가 통째로 풀리기도 합니다. / 관리자 계정이 누구인지 가족끼리 정해 두는 것이 좋습니다.
@ 양평동 도어락 가족 공유 권한 확인

# 원격 열기는 신중하게 쓰세요
밖에서 앱으로 문을 열 수 있는 기능은 편하지만 휴대폰을 잃어버리면 그만큼 위험해집니다. / 휴대폰 화면 잠금을 꼭 걸어 두세요.
연동이 자꾸 끊겨 원격 열기가 불안정하다면 그 기능에 기대지 말고 번호나 카드를 함께 쓰는 게 낫습니다. / 손님에게 문을 열어 주는 용도라면 임시 번호 기능이 더 안전합니다.
앱에 남는 출입 기록도 가끔 훑어보세요. / 가족이 아닌 이름이나 기억에 없는 시간대 기록이 보이면 등록된 카드와 번호를 한 번 정리할 때가 된 것입니다.
기록이 자꾸 빠지거나 시간이 엉뚱하게 찍힌다면 연결 장치 시계가 어긋났을 수 있습니다. / 연결 장치를 다시 켜서 시간이 맞춰지는지 확인해 보세요.
@ 양평동 도어락 출입 기록 원격 열기 점검

# 출장 점검이 필요한 경우
아래 같은 증상이라면 휴대폰이나 공유기 문제가 아니라 도어락 쪽을 직접 봐야 합니다.
- 배터리를 바꾸고 공유기도 다시 연결했는데 계속 오프라인
- 연결 장치는 정상인데 도어락만 등록이 안 됨
- 앱에서 문을 열면 모터 소리만 나고 안 열림
- 통신 모듈이 헐겁게 덜렁거림
점검은 [도어락 수리](doorlock-repair.html)로 문의하시면 됩니다.

# 찾아뵙기 전 사시는 분인지 확인
도어락 설정을 바꾸는 작업이라 거주하시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 가운데 하나면 됩니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 비용은 원인을 확인한 뒤에
연결만 다시 잡으면 되는지 부품을 바꿔야 하는지 확인하고 비용을 먼저 말씀드립니다. / 들어 보시고 결정하시면 됩니다.
문이 잠겨 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 문 여는 과정은 [현관문 개문](door-open.html)에 있습니다.

# 연동을 오래 안정적으로 쓰려면
공유기를 바꿀 계획이 있으면 바꾸는 날 도어락 연결도 같이 다시 잡는다고 생각해 두세요. / 앱은 업데이트를 미루지 말고, 가족 계정은 한 사람이 관리하도록 정해 두면 꼬일 일이 줄어듭니다.
제품이 오래돼 앱 지원이 끝났다면 연동이 계속 불안할 수 있습니다. / 그럴 때는 [도어락 교체](doorlock-replace.html)를 검토해 볼 만합니다.

# 양평동 밖 영등포구 전 지역
당산동, 문래동, 영등포동, 여의도동, 도림동, 신길동, 대림동까지 영등포구 어디든 갑니다. / 연동 점검처럼 급하지 않은 일은 편한 시간을 정해 찾아뵙습니다.
영등포구 안 동네는 [영등포구 출장열쇠](seoul-yeongdeungpo.html), 서울과 경기 다른 곳은 [출장 지역](area.html)에서 볼 수 있습니다.

# 자주 묻는 질문
? 알림이 몇 시간 뒤에 몰려와요 | 휴대폰 절전 설정이 앱을 잠재우는 경우가 많습니다. 절전 예외에 넣어 보세요.
? 통신사를 바꿨더니 앱이 끊겼어요 | 공유기가 바뀌었다면 도어락을 새 와이파이에 다시 연결해야 합니다.
? 가족 한 명만 알림을 못 받아요 | 초대 권한이 보기 전용인지, 그분 휴대폰 알림이 꺼져 있는지 확인해 보세요.
? 앱이 안 되면 문도 안 열리나요? | 대부분은 번호, 카드, 지문으로 따로 열립니다. 전원이 꺼진 경우만 예외입니다.
? 문을 못 열면 비용이 나오나요? | 아닙니다. 못 열면 비용은 받지 않습니다.

# 마무리
양평동에서 도어락 앱이 말썽이면 문이 열리는지부터 보고, 휴대폰, 공유기, 배터리 순서로 차분히 짚어 보세요. / 그래도 안 되면 증상과 제품 사진을 보내 주시면 됩니다.
24시출장열쇠는 양평동 어느 집이든 찾아갑니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
