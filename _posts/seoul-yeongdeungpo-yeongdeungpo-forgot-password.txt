# 영등포동 현관 앞에서 번호가 하얗게 지워졌다면
영등포역에서 내려 집까지 걸어오는 동안에도 아무 생각 없이 누르던 번호인데, 막상 현관 앞에 서면 첫 자리부터 막히는 날이 있습니다. / 머리로 기억하던 번호가 아니라 손가락이 외우던 번호라서 더 그렇습니다.
영등포동은 역 주변 생활권이라 늦게 들어오는 분이 많고, 피곤한 상태에서 번호가 꼬이는 일이 생기기 쉽습니다. / 이 글은 비밀번호가 떠오르지 않거나 가족이 번호를 바꿔 둔 상황에서 문을 덜 상하게, 빨리 여는 순서를 적었습니다.
급하다면 4번과 5번부터 보시고, 시간 여유가 있다면 처음부터 차례대로 따라와 주세요.
@ 영등포동 도어락 비밀번호 분실 출장열쇠

# 번호를 연달아 틀리면 생기는 일
대부분의 도어락은 번호를 몇 번 연속으로 틀리면 잠시 입력을 받지 않습니다. / 이때 경고음이 길게 울리고 번호판 불이 꺼지거나 깜빡입니다.
잠시 기다리면 다시 입력할 수 있지만, 같은 일을 반복하면 막히는 시간이 점점 길어지는 제품도 있습니다. / 밤늦은 시간에는 경고음 때문에 이웃 눈치도 보이게 됩니다.
그래서 떠오르는 숫자를 마구 눌러 보기보다는 후보를 서너 개로 좁힌 뒤에 차분히 눌러 보는 편이 낫습니다. / 그래도 안 되면 그 자리에서 멈추는 것이 문과 도어락 모두에게 좋습니다.

# 손가락이 기억하는 번호를 꺼내는 방법
번호를 머리로 떠올리기 어렵다면 손의 움직임을 떠올려 보세요. / 번호판 위에서 손가락이 위로 갔는지, 대각선으로 움직였는지 그림처럼 생각하면 돌아오는 경우가 있습니다.
- 휴대폰 잠금 번호나 카드 비밀번호와 같은 숫자인지
- 예전 집 현관 번호를 그대로 옮겨 쓴 건 아닌지
- 가족 생일, 결혼기념일, 차량 번호 뒷자리인지
- 마지막에 별표나 샵을 눌러야 하는 제품인지
의외로 마지막 확인 버튼을 빼먹어서 안 열리는 경우도 있습니다. / 번호는 맞게 눌렀는데 아무 반응이 없다면 확인 버튼부터 다시 떠올려 보세요.

# 가족이 번호를 바꿔 둔 경우
번호가 틀린 게 아니라 누군가 바꿔 둔 경우도 흔합니다. / 배우자나 자녀가 보안 때문에 바꾸고 미처 알리지 못했을 수 있습니다.
이럴 때는 문 앞에서 더 누르기보다 가족에게 먼저 연락해 보는 게 가장 빠릅니다. / 연락이 닿지 않는다면 메신저 대화방이나 메모 앱에 바꾼 번호를 남겨 두었는지 찾아보세요.
같이 사는 분이 일 때문에 바로 전화를 못 받는 상황이라면 잠깐 근처에서 기다려 보는 것도 방법입니다. / 출장열쇠를 부르는 것보다 그쪽이 더 간단하게 끝날 수 있습니다.

# 번호판이 켜지는지부터 확인하세요
번호를 잊은 줄 알았는데 사실은 배터리가 다 된 경우도 있습니다. / 번호판을 손바닥으로 덮거나 눌렀을 때 불이 제대로 들어오는지 먼저 보세요.
불은 들어오는데 숫자를 누를 때마다 소리가 약하거나 끊긴다면 배터리가 바닥에 가까운 상태입니다. / 이때는 바깥쪽 비상 단자에 9V 건전지를 대고 다시 눌러 볼 수 있습니다.
번호판이 멀쩡히 켜지고 경고음만 난다면 그때는 정말 번호 문제라고 보시면 됩니다.

# 카드키나 지문이 따로 등록돼 있다면
번호 말고 카드키나 지문을 함께 쓰는 도어락이라면 다른 방법이 남아 있습니다. / 지갑이나 차 안에 카드키를 넣어 두지 않았는지 찾아보세요.
가족 중 지문을 등록해 둔 사람이 있다면 그 사람이 오는 것이 가장 확실합니다. / 반대로 아무것도 등록돼 있지 않고 번호만 쓰는 제품이라면 안에서 열어 줄 사람이 없는 이상 출장열쇠를 부르셔야 합니다.

# 억지로 열려다 생기는 손상
문틈에 카드를 밀어 넣거나 드라이버로 번호판을 들어 올리려는 분들이 있습니다. / 그러면 번호판 외관이 깨지거나 걸쇠가 비틀어져서 문을 연 뒤에도 도어락을 쓸 수 없게 됩니다.
도어락 덮개를 열어 보려다 배선이 끊어지는 일도 있습니다. / 이렇게 되면 원래는 번호만 다시 등록하면 끝날 일이 수리나 교체로 커집니다.
@ 영등포 도어락 번호 분실 문 열기

# 전화 주실 때 말씀해 주시면 좋은 것
영등포동에서 연락 주실 때 아래 내용을 알려주시면 상황 파악이 빨라집니다. / 사진을 문자로 보내주셔도 좋습니다.
- 집 형태 (아파트, 빌라, 오피스텔, 상가 위 주택)
- 영등포역 기준 대략 어느 쪽인지와 건물 이름
- 번호판에 불이 들어오는지, 경고음이 나는지
- 보조키나 안쪽 걸쇠를 함께 잠갔는지
- 집 안에 사람이나 반려동물이 있는지
공동현관이 따로 있는 건물이라면 공동현관 비밀번호나 호출 방법도 알려주세요. / 그래야 도착해서 건물 밖에서 기다리는 시간이 줄어듭니다.

# 문 열기 전, 거주자 확인 절차
문을 여는 일이라 도착하면 이 집에 사시는 분이 맞는지부터 확인합니다. / 신분증에 적힌 주소나 주소가 찍힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있어도 괜찮습니다. / 문을 연 뒤 바로 보여주시거나, 관리사무소나 경비실에 세대 확인을 부탁하는 방법도 있습니다.
@ 영등포동 현관 도어락 번호 재등록

# 얼마인지는 시작 전에 먼저 알려드립니다
도어락 종류와 문 상태를 본 뒤 비용을 먼저 말씀드리고, 괜찮다고 하실 때만 작업을 시작합니다. / 금액이 부담스러우시면 그냥 돌아가도 됩니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 문이 열린 뒤에 말없이 더해지는 항목도 없고, 부품을 바꿔야 하면 그 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 열고 나면 번호 정리까지
문이 열리면 안쪽에서 기존 번호를 지우고 새 번호를 등록하는 것까지 같이 해드립니다. / 가족이 각자 다른 번호를 쓰고 있었다면 이참에 하나로 정리하는 것도 좋습니다.
비상 열림 방법이 없는 제품이었다면 카드키나 지문을 하나 더 등록해 두시길 권합니다. / 문 여는 방식은 [현관문 개문](door-open.html), 번호 등록 방법은 [도어락 수리](doorlock-repair.html) 페이지에서 보실 수 있습니다.
도어락이 너무 오래돼 번호 등록이 자꾸 풀린다면 그때 [도어락 교체](doorlock-replace.html)를 함께 상의해 보셔도 됩니다.

# 다음에 같은 일을 막는 작은 습관
번호를 바꾸는 사람이 생기면 가족 대화방에 바로 남기는 규칙을 정해 두세요. / 종이에 적어 둘 거라면 현관 근처가 아니라 지갑 속 같은 곳에 두는 게 낫습니다.
가족 중 한 사람은 카드키나 지문을 꼭 등록해 두면 번호를 잊어도 열 방법이 하나 남습니다. / 번호는 너무 쉽게 정하지 말되 가족 모두가 기억할 수 있는 규칙으로 만드는 것이 좋습니다.

# 영등포동 말고 영등포구 어디든 갑니다
영등포동 가까운 당산동, 문래동, 양평동, 도림동은 물론 여의도동, 신길동, 대림동까지 다닙니다. / 영등포구 안이면 동네 상관없이 24시간 출동합니다.
영등포구에서 다니는 곳은 [영등포 출장열쇠](seoul-yeongdeungpo.html) 페이지에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

# 마무리
영등포동에서 비밀번호가 떠오르지 않으면 마구 누르기보다 후보를 좁히고, 가족에게 먼저 연락해 보세요. / 그래도 안 되면 번호판 상태와 위치만 알려주시면 바로 출동 여부를 말씀드립니다.
