# 영등포동, 열쇠가 자물쇠 안에서 멈춰 버렸다면
영등포동은 영등포역을 중심으로 한 생활권이라 오가는 사람이 많고 주변 건물 형태도 다양한 동네입니다. / 도어락이 대세가 된 요즘에도 보조 자물쇠나 건물 출입문, 방화문 자물쇠는 여전히 열쇠로 씁니다.
그 열쇠가 어느 날 끝까지 들어가기는 하는데 돌아가지 않거나, 반쯤 돌다가 멈추거나, 돌린 뒤 빠지지 않으면 손이 굳어 버립니다. / 힘을 더 주면 될 것 같은데 열쇠가 휘는 느낌이 들어 겁이 나기도 합니다.
이 글은 영등포동에서 열쇠가 안 돌거나 안 빠질 때 원인을 나눠 보고 순서대로 해볼 일을 정리했습니다. / 혼자 해결이 어려우면 [영등포 출장열쇠](seoul-yeongdeungpo.html)로 연락 주시면 됩니다.
@ 영등포동 자물쇠 열쇠 안 돌아감

# 안 도는 것과 안 빠지는 것은 다른 문제
열쇠가 안 돌아가는 건 대부분 실린더 안 핀이 제자리에 맞지 않아서입니다. / 열쇠가 안 빠지는 건 실린더가 처음 위치로 완전히 돌아오지 못했기 때문인 경우가 많습니다.
둘은 같이 나타나기도 합니다. / 반쯤 돌다 멈춘 열쇠는 돌아가지도 빠지지도 않는 상태에 갇혀 버립니다.
어느 쪽인지 먼저 알아 두면 다음에 할 일을 고르기 쉽습니다. / 지금 열쇠가 꽂혀 있는 각도를 한 번 보세요.

# 열쇠부터 살펴보세요
문제가 자물쇠가 아니라 열쇠에 있는 경우가 생각보다 많습니다. / 꽂기 전이라면 열쇠를 손에 들고 아래를 확인해 보세요.
- 열쇠 몸통이 살짝 휘어 있지 않은지
- 홈 끝이 닳아 둥글어지지 않았는지
- 최근에 새로 복사한 열쇠인지
- 같은 열쇠 꾸러미의 다른 열쇠와 헷갈리지 않았는지
복사 열쇠로 안 되던 문이 원본 열쇠로는 부드럽게 열리는 경우가 흔합니다. / 집에 원본이 있다면 그걸로 다시 복사해 두시는 게 좋습니다.

# 문을 밀거나 당긴 채 돌려 보세요
자물쇠 혀가 문틀 받이에 눌려 있으면 실린더가 돌아가는 힘을 혀가 버텨 버립니다. / 문이 조금 처졌거나 바람 때문에 문이 밀려 있을 때 자주 생깁니다.
문손잡이를 잡고 몸 쪽으로 살짝 당긴 채 열쇠를 돌려 보세요. / 안 되면 반대로 문을 안쪽으로 살짝 민 채 돌려 봅니다.
이 방법은 힘보다 방향이 중요합니다. / 문을 아주 조금만 움직여도 혀에 걸린 압력이 풀리면서 열쇠가 쉽게 돌아갑니다.
@ 영등포동 보조키 실린더 문 당기며 열기

# 열쇠를 아주 조금만 넣었다 빼 보세요
열쇠를 끝까지 꽂은 상태에서 1밀리 정도만 살짝 뺀 다음 돌려 보는 방법도 있습니다. / 실린더 안 핀 높이가 미세하게 맞지 않을 때 이걸로 맞아떨어지기도 합니다.
열쇠를 위아래로 아주 살짝 흔들면서 돌리는 것도 같은 원리입니다. / 단, 흔드는 폭은 정말 작아야 하고 돌리는 힘은 손끝 정도로만 줍니다.
두세 번 해 보고 반응이 없으면 그만두세요. / 반복할수록 열쇠 홈이 실린더 안을 긁어 상태가 나빠집니다.

# 반쯤 돌다 멈춘 열쇠가 안 빠질 때
열쇠가 비스듬한 각도에 멈춰 안 빠지면 처음 꽂았던 위치로 되돌리는 것이 먼저입니다. / 열쇠는 꽂았던 각도에서만 빠지게 만들어져 있습니다.
천천히 원래 방향으로 돌려 세로나 가로 원위치를 맞춰 보세요. / 원위치에서 손끝으로 곧게 당기면 빠지는 경우가 많습니다.
원위치까지 안 돌아오면 억지로 비틀어 빼지 마세요. / 비틀면 열쇠가 그대로 부러져 구멍 안에 남을 수 있습니다.

# 기름보다 전용 윤활제를 쓰세요
뻑뻑할 때 식용유나 일반 기름을 넣는 분이 많습니다. / 처음에는 부드러워지지만 기름에 먼지가 달라붙어 나중에는 더 뻑뻑해집니다.
열쇠구멍에는 흑연 가루나 자물쇠 전용 윤활제를 조금만 쓰세요. / 넣은 뒤 열쇠를 몇 번 꽂았다 빼면서 고르게 퍼지게 합니다.
이미 기름을 넣었다면 더 넣지 말고 그대로 연락 주세요. / 실린더를 닦아 내야 할 수도 있습니다.

# 힘으로 해결하면 남는 것
열쇠에 펜치를 물려 돌리거나 손잡이에 무언가를 끼워 지렛대처럼 쓰는 건 피해 주세요. / 열쇠가 부러지거나 실린더 자체가 돌아 버려서 자물쇠를 통째로 바꿔야 합니다.
열쇠구멍을 드라이버로 쑤시는 것도 마찬가지입니다. / 핀이 휘면 맞는 열쇠로도 다시 안 열립니다.
열쇠가 꽂힌 채 안 빠지는데 외출해야 한다면 열쇠를 그대로 두고 나가지 마세요. / 누구든 돌릴 수 있는 상태가 되니, 집에 사람이 남거나 연락을 먼저 주시는 편이 안전합니다.
추운 날 바깥 자물쇠가 얼어서 안 도는 경우도 있습니다. / 이때는 손으로 열쇠 머리를 잠시 감싸 데우거나 따뜻한 바람을 멀리서 잠깐 쐬어 주면 풀리기도 하지만, 뜨거운 물을 붓는 건 다시 얼어붙으니 피하세요.
@ 영등포동 열쇠구멍 무리한 시도 주의

# 영등포동에서 전화하실 때
열쇠가 꽂혀 있다면 그 상태 그대로 사진을 찍어 보내 주세요. / 열쇠 각도와 자물쇠 모양만 보여도 준비가 많이 달라집니다.
- 현관 보조키인지, 건물 출입문이나 방화문인지
- 열쇠가 꽂힌 채인지, 빠진 상태인지
- 문이 잠긴 상태인지 열린 상태인지
- 몇 층이고 건물 출입이 자유로운지
건물 출입문 자물쇠라면 관리하시는 분 연락처도 함께 알려 주시면 좋습니다.
@ 영등포동 출장열쇠 실린더 점검 사진

# 사시는 분인지 먼저 여쭙습니다
잠긴 자물쇠를 다루는 일이라 거주하시는 분이거나 관리 권한이 있는 분인지 먼저 확인합니다. / 주소가 나온 신분증, 우편물, 관리사무소 확인 가운데 하나면 됩니다.
건물 공용 출입문은 건물주나 관리인 확인이 필요합니다. / 자세한 절차는 [이용안내](guide.html)에 있습니다.

# 작업 전에 비용을 말씀드리고 시작합니다
열쇠를 빼기만 하면 되는지, 실린더를 바꿔야 하는지 보고 나서 비용을 먼저 알려 드립니다. / 들어 보시고 결정하시면 됩니다.
문을 열지 못하면 비용은 받지 않습니다. / 문 여는 방법은 [현관문 개문](door-open.html)에서도 보실 수 있습니다.

# 실린더를 바꿀지, 도어락으로 정리할지
열쇠를 빼고 문을 연 뒤에도 실린더가 계속 뻑뻑하면 실린더만 바꾸는 것이 가장 간단합니다. / 기존 열쇠는 쓸 수 없게 되니 필요한 개수를 미리 정해 두세요.
보조 자물쇠를 이참에 없애고 도어락 하나로 정리하고 싶다면 [도어락 설치](doorlock-install.html) 전에 문 두께와 기존 구멍 위치를 확인합니다. / 이미 달린 도어락이 오래됐다면 [도어락 교체](doorlock-replace.html)도 함께 볼 수 있습니다.

# 영등포동 말고 영등포구 다른 곳도
영등포동과 가까운 당산동, 문래동, 신길동을 비롯해 여의도동, 양평동, 도림동, 대림동까지 영등포구 전 지역을 다닙니다. / 시간 상관없이 연락 주세요.
영등포구 안 동네는 [영등포구 출장열쇠](seoul-yeongdeungpo.html), 서울과 경기 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.

# 자주 묻는 질문
? 열쇠가 반쯤 돌다 멈췄어요 | 처음 꽂았던 각도로 천천히 되돌린 뒤 곧게 당겨 보세요. 비틀어 빼지는 마세요.
? 식용유를 넣어도 되나요? | 먼지가 붙어 나중에 더 뻑뻑해집니다. 전용 윤활제를 조금만 쓰세요.
? 복사 열쇠만 잘 안 돼요 | 원본 열쇠로 다시 복사하면 해결되는 경우가 많습니다.
? 건물 출입문 자물쇠도 보시나요? | 관리하시는 분 확인이 되면 공용 출입문도 봅니다.
? 열지 못하면 비용이 있나요? | 없습니다. 못 열면 비용은 받지 않습니다.

# 마무리
영등포동에서 열쇠가 안 돌거나 안 빠지면 힘을 빼고 문을 살짝 밀거나 당긴 채 다시 해 보세요. / 그래도 안 되면 꽂힌 그대로 두고 사진과 함께 연락 주시면 됩니다.
24시출장열쇠는 영등포동 어느 건물이든 밤늦게도 출동합니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
