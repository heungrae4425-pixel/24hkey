# 내가 없는 사이 누군가 들어와야 하는 날
청파동은 언덕길을 따라 원룸 건물과 오래된 주택이 촘촘하게 들어선 동네라 혼자 사는 분이 많습니다. / 혼자 살다 보면 내가 집에 없는 시간에 누군가 문을 열고 들어와야 하는 날이 생각보다 자주 생깁니다.
지방에서 올라오신 부모님이 먼저 도착하시는 날, 출장 중 고양이 밥을 부탁한 친구, 격주로 오는 청소 도우미, 보일러를 보러 오는 수리 기사까지 경우는 다양합니다. / 그때마다 내 번호를 그대로 알려 주면 편하긴 하지만, 나중에 정리하기가 까다로워집니다.
이 글은 청파동 원룸과 주택에서 임시 비밀번호를 만들어 쓰고 깔끔하게 지우는 방법을 상황별로 나눴습니다.
@ 청파동 원룸 현관 도어락 임시 비밀번호

# 내 번호를 알려 주면 남는 것
한 번 알려 준 번호는 상대가 지우지 않는 한 상대의 기억과 휴대폰에 남습니다. / 악의가 없어도 메모가 다른 사람 눈에 띄거나 휴대폰을 잃어버리는 일은 언제든 있습니다.
게다가 번호를 바꾸려면 내 번호도 같이 바꿔야 해서, 손님 한 번 받을 때마다 새 번호를 외워야 하는 번거로움이 생깁니다. / 그래서 손님용 번호와 내 번호를 따로 두는 것이 기본입니다.

# 우리 집 도어락에 있는 기능부터 확인
요즘 도어락은 대부분 비밀번호를 여러 개 등록할 수 있습니다. / 제품에 따라 한 번 쓰면 사라지는 일회용 번호나, 정해 둔 기간만 쓸 수 있는 번호를 지원하기도 합니다.
안쪽 몸체 배터리 덮개 근처에 모델명이 적혀 있으니 사진을 찍어 두세요. / 설명서가 없어도 모델명으로 등록 방법을 찾을 수 있고, 저희에게 보내 주셔도 순서를 알려 드립니다.
원룸은 집주인이 달아 둔 도어락이라 어떤 제품인지 모르는 경우가 많습니다. / 처음 입주할 때 한 번 확인해 두면 손님이 올 때마다 헤매지 않습니다.

# 한 번 들르는 손님에게는 일회용 번호
부모님이 먼저 도착하시거나 친구가 택배만 받아 주기로 한 날처럼 딱 한 번 들어오는 경우에는 일회용 번호가 가장 깔끔합니다. / 상대가 문을 열고 나면 번호가 저절로 사라지기 때문에 지울 일도 없습니다.
일회용 기능이 없는 제품이라면 손님용 번호를 하나 추가로 등록하고, 손님이 다녀간 날 바로 지우면 됩니다. / 지우는 걸 깜빡하지 않게 휴대폰 알림을 그 자리에서 맞춰 두세요.
손님용 번호는 내 번호와 앞자리부터 전혀 다르게 정하는 편이 좋습니다. / 비슷하게 만들면 손님이 내 번호를 짐작할 실마리가 됩니다.
@ 청파동 도어락 손님용 비밀번호 등록 화면

# 정해진 요일에 오는 분께는 따로 정한 번호
청소 도우미나 반려동물 돌봄 인력처럼 정기적으로 오는 분께는 그분 전용 번호를 하나 드리는 것이 좋습니다. / 내 번호와 섞이지 않으니 그분이 그만두시면 그 번호만 지우면 됩니다.
기간을 정해 둘 수 있는 제품이라면 계약한 기간까지만 쓰이도록 맞춰 두세요. / 기간이 끝났는데 계속 오시게 되면 그때 다시 늘리면 됩니다.

# 공동현관 번호도 함께 생각하기
청파동 원룸 건물은 건물 입구에 공동현관 번호가 따로 있는 곳이 많습니다. / 내 방 번호만 알려 주고 공동현관 번호를 빠뜨려 손님이 건물 밖에서 기다리는 일이 자주 생깁니다.
공동현관 번호는 내가 마음대로 바꿀 수 없는 경우가 대부분입니다. / 그래서 손님에게 알려 줄 때는 꼭 필요한 사람에게만 전하고, 메시지는 손님이 다녀간 뒤 지워 달라고 부탁해 두세요.

# 번호를 보낼 때 지킬 것
번호는 주소와 같은 메시지에 함께 보내지 않는 것이 좋습니다. / 주소는 미리 보내고, 번호는 도착하기 직전에 따로 보내면 혹시 메시지가 잘못 전달되더라도 위험이 줄어듭니다.
문 옆 벽이나 우편함, 신발장 위에 번호를 적은 쪽지를 두는 것은 피하세요. / 원룸 건물 복도는 여러 사람이 지나다니는 곳입니다.
받는 사람이 번호를 휴대폰 메모에 저장했다면 일이 끝난 뒤 지워 달라고 한마디 덧붙여 주세요. / 대부분 흔쾌히 지워 주시고, 그 말 한마디로 번호가 오래 떠돌 일이 줄어듭니다.
@ 청파동 현관 비밀번호 메시지 따로 보내기

# 수리 기사가 올 때는 가능하면 함께
보일러나 수도를 고치러 오는 기사에게까지 번호를 드려야 하는 날도 있습니다. / 가능하다면 시간을 맞춰 직접 문을 열어 드리는 것이 가장 좋습니다.
어쩔 수 없이 번호를 드려야 한다면 그날만 쓰는 번호를 만들고, 작업이 끝났다는 연락을 받는 즉시 지우세요. / 집주인이 기사를 보내는 경우라면 누가 몇 시에 오는지 미리 물어 두면 마음이 편합니다.

# 손님이 다녀간 날 할 일
손님용 번호를 지운 뒤에는 꼭 바깥에서 그 번호를 눌러 보세요. / 문이 안 열리는 것까지 확인해야 정말 지워진 것입니다.
손님이 여럿 다녀간 달이라면 한 달에 한 번쯤 등록된 번호 목록을 처음부터 정리하는 것도 좋습니다. / 누구 번호인지 기억나지 않는 것이 하나라도 있으면 지우고, 내 번호와 정기적으로 오는 분 번호만 다시 넣으세요.
카드나 태그를 빌려줬다면 돌려받는 것만으로는 부족합니다. / 도어락 안쪽에서 등록된 카드를 정리해야 복사본이 있더라도 쓰지 못합니다.

# 설정하다 문이 잠겨 버렸을 때
번호를 지우다 내 번호까지 지워 버리거나, 초기화 버튼을 잘못 눌러 문이 안 열리는 일이 가끔 있습니다. / 설정은 반드시 문을 열어 둔 상태에서 하시고, 바깥에서 새 번호가 되는지 시험한 뒤 닫으세요.
이미 잠겨 버렸다면 손잡이를 세게 당기지 말고 연락 주세요. / [용산 출장열쇠](seoul-yongsan.html)로 상하지 않게 열고, 그 자리에서 번호 정리까지 마무리해 드립니다.

# 출장 때 확인하는 것과 비용
문을 열기 전에는 사시는 분이 맞는지 신분증 주소나 우편물, 임대차 계약서로 확인합니다. / 원룸이라 주소지를 아직 옮기지 않으셨다면 계약서나 집주인 통화로도 됩니다.
비용은 문을 본 뒤 시작하기 전에 먼저 말씀드리고, 못 열면 받지 않습니다. / 진행 방식은 [이용안내](guide.html), 여는 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 임시 번호 기능이 없는 오래된 제품이라면
번호를 하나밖에 못 넣는 오래된 도어락은 손님이 올 때마다 내 번호를 바꿔야 해서 불편합니다. / 부품이 멀쩡하면 그대로 쓰셔도 되고, 손님이 잦다면 여러 번호를 등록할 수 있는 제품으로 바꾸는 것을 집주인과 상의해 보세요.
교체를 하게 되면 기존 구멍에 맞는 제품을 먼저 찾습니다. / 자세한 내용은 [도어락 교체](doorlock-replace.html)에 있습니다.
@ 용산 청파동 원룸 도어락 설정 출장

# 청파동 말고 용산 다른 동네도
청파동과 붙어 있는 후암동, 효창동, 용문동을 비롯해 원효로동, 이촌동, 서빙고동, 한남동, 이태원동, 보광동까지 용산구 어디든 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 마무리
청파동 원룸에서 손님을 들일 때는 내 번호 대신 손님용 번호를 쓰고, 다녀간 날 지우고, 바깥에서 한 번 눌러 보는 것까지가 한 세트입니다. / 이 세 가지만 지켜도 번호가 어디까지 퍼졌는지 걱정할 일이 없습니다.
서울, 경기 전 지역 24시간 다니며 언덕 골목 원룸도 걸어서 찾아갑니다. / 설정이 막히거나 문이 잠기면 010-3664-5455로 전화 주세요.
