# 청파동 새 집, 짐보다 먼저 볼 것
청파동은 언덕을 따라 원룸 건물과 오래된 주택이 빼곡하게 이어지는 동네라 이사 들고 나는 일이 잦습니다. / 혼자 사는 분이 많고 계약 기간이 짧은 집도 있어서, 같은 현관 도어락을 여러 사람이 차례로 거쳐 간 경우가 흔합니다.
이삿짐을 다 들이기 전에 해 둘 일이 하나 있습니다. / 이전 세입자나 공사 인부가 알던 비밀번호, 등록해 둔 카드와 지문을 모두 지우는 초기화입니다.
아래에는 청파동 원룸과 주택에서 도어락을 초기화하고 새 번호를 넣는 순서, 그리고 중간에 막혔을 때 어떻게 하면 되는지를 정리했습니다. / 직접 하기 어려우면 [용산 출장열쇠](seoul-yongsan.html)로 연락 주셔도 됩니다.
@ 청파동 원룸 이사 첫날 도어락 초기화

# 왜 번호만 바꾸면 부족할까
비밀번호를 새로 바꾸면 이전 번호는 대개 사라집니다. / 하지만 카드키, 태그, 지문은 따로 저장돼 있어서 번호를 바꿔도 그대로 남는 제품이 많습니다.
이전 사람이 카드 하나를 돌려주지 않았다면 그 카드로 여전히 문이 열릴 수 있습니다. / 그래서 이사할 때는 번호 변경이 아니라 저장된 것을 한꺼번에 비우는 초기화를 권합니다. / 집을 보러 다닐 때 중개인이나 집주인이 알려 준 임시 번호도 마찬가지라, 계약 뒤에는 그 번호를 아는 사람이 생각보다 여럿일 수 있습니다.

# 초기화 버튼은 안쪽 몸체에 있습니다
대부분의 도어락은 집 안쪽 몸체의 배터리 덮개를 열면 작은 버튼이 보입니다. / 등록, 설정, 리셋처럼 이름이 적혀 있거나 아무 글자 없이 구멍만 있기도 합니다.
버튼 위치와 누르는 시간은 제조사마다 다릅니다. / 몸체 옆이나 아래에 적힌 제조사 이름과 모델명을 먼저 확인해 두면 설명서를 찾기 쉽습니다.
- 버튼을 몇 초 누르면 안내음이 나는 방식
- 버튼을 누른 채 배터리를 뺐다 끼우는 방식
- 바깥 번호판에서 특정 순서로 입력하는 방식
어느 쪽인지 모르겠다면 무작정 누르지 말고 모델명부터 찾아보세요.
@ 청파동 도어락 안쪽 배터리 덮개 초기화 버튼

# 초기화 전에 문을 꼭 열어 두세요
가장 흔한 실수는 문을 닫은 채로 초기화하는 것입니다. / 초기화 직후 새 번호를 등록하기 전에 문이 잠기면 바깥에서는 어떤 번호로도 열 수 없게 됩니다.
문을 활짝 열어 두고, 걸쇠가 튀어나와 있으면 손으로 열림 상태를 확인한 뒤 진행하세요. / 이사 날에는 짐 나르는 사람이 문을 무심코 닫는 일도 있으니 문 앞에 받침을 두는 게 좋습니다. / 자동 잠금 기능이 켜진 제품은 문이 닫히는 순간 저절로 잠기니, 초기화가 끝날 때까지는 휴대폰도 꼭 손에 들고 계세요.

# 새 비밀번호를 넣는 순서
초기화가 끝나면 새 번호를 넣습니다. / 문이 열린 상태에서 하나씩 확인하면서 진행하세요.
먼저 설정 버튼을 누르고 새 번호를 입력한 뒤 확인을 누르는 식이 일반적입니다. / 등록이 끝나면 문을 연 채로 걸쇠를 바깥에서 잠그고 다시 열어 보는 시험을 두세 번 합니다. / 새 번호는 휴대폰 메모가 아니라 종이에 적어 지갑처럼 따로 들고 다니는 물건에 넣어 두면 휴대폰을 집에 두고 나왔을 때도 덜 막막합니다.
문을 닫기 전에 바깥에서 새 번호가 먹히는지 꼭 보세요. / 이 단계를 건너뛰면 처음 문을 닫는 순간 문 밖에 서게 될 수 있습니다.

# 언덕 원룸에서 피해야 할 번호
- 건물 호수나 생일처럼 우편물에서 짐작할 수 있는 숫자
- 1234나 같은 숫자 반복
- 공동 현관과 같은 번호
청파동처럼 비슷한 원룸 건물이 붙어 있는 곳은 우편함만 봐도 호수와 이름이 드러납니다. / 번호는 그런 정보와 겹치지 않게 정하고, 입력할 때 앞뒤로 아무 숫자나 덧붙이는 허수 기능이 있다면 켜 두세요.

# 카드키와 지문도 새로 등록하기
초기화 뒤에는 카드와 지문도 다시 넣어야 합니다. / 받은 카드가 몇 장인지 세어 보고, 이전 사람에게서 넘겨받지 못한 카드가 있다면 초기화가 더 중요해집니다.
지문은 손가락 하나만 넣지 말고 양손에서 한 개씩 넣어 두는 게 좋습니다. / 짐을 들고 있거나 손을 다쳤을 때 다른 손으로 열 수 있습니다. / 남는 카드는 집 안 서랍에 두지 말고 믿을 수 있는 가족이나 회사 책상처럼 집 밖에 하나 맡겨 두면 비상용으로 쓸 수 있습니다.

# 버튼을 눌러도 아무 반응이 없다면
초기화 버튼을 눌렀는데 안내음이 안 나면 배터리가 약한 경우가 많습니다. / 이사 날 새 배터리로 전부 갈고 다시 해 보세요.
그래도 반응이 없거나 번호판에 오류 표시가 계속 나오면 기판 쪽 문제일 수 있습니다. / 이때는 억지로 여러 번 누르기보다 상태를 사진으로 찍어 두고 연락 주세요. / 배터리를 넣을 때 극 방향이 뒤집혀 있거나 한 칸만 헐겁게 끼워져 있어 반응이 없는 경우도 있으니 그것부터 한 번 살펴보시면 좋습니다.

# 이미 잠겨 버렸을 때
초기화하다가 문이 닫혀 버렸거나, 이사 온 날 받은 번호가 안 맞아 못 들어가는 경우도 있습니다. / 이런 때는 문을 상하지 않게 여는 것부터 합니다. 과정은 [현관문 개문](door-open.html)에 적어 두었습니다.
열고 나면 그 자리에서 초기화와 새 번호 등록까지 마무리해 드립니다. / 끝내 못 열면 비용은 받지 않습니다.

# 출장 때는 거주 확인부터
이사 첫날이라 신분증 주소가 아직 바뀌지 않았을 수 있습니다. / 이럴 때는 임대차 계약서, 집주인 확인 전화, 관리인 확인 같은 방법으로도 됩니다.
누구나 남의 집 도어락을 초기화할 수 있으면 안 되기 때문에 이 절차는 빼지 않습니다. / 계약서 사진을 휴대폰에 저장해 두시면 가장 간단합니다. / 집주인과 연락이 어려운 늦은 시간이라면 이삿짐 업체 영수증처럼 오늘 이사 온 걸 보여 줄 수 있는 자료도 함께 챙겨 두세요.

# 비용은 손대기 전에 말씀드립니다
초기화와 번호 등록만 하는지, 문 열기까지 하는지, 부품을 바꿔야 하는지에 따라 달라집니다. / 현장을 보고 무엇을 할지 먼저 설명드린 뒤 동의하실 때만 진행합니다.
초기화 버튼 자체가 고장 나서 부품을 바꿔야 한다면 그것도 미리 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 오래된 도어락이라면 이참에
이전 세입자 시절부터 쓰던 낡은 제품이라 초기화가 안 되거나 경고음이 잦다면 바꾸는 쪽을 고민해 볼 만합니다. / 세입자라면 바꾸기 전에 집주인과 먼저 이야기하시고, 수리로 될 부분은 [도어락 수리](doorlock-repair.html), 교체는 [도어락 교체](doorlock-replace.html)를 참고하세요.
@ 청파동 이사 후 새 비밀번호 등록 시험
