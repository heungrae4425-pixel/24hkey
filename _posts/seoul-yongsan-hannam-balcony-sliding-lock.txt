# 현관 말고 집 안 문이 잠겼을 때
한남동은 아파트 단지와 언덕 위 주택, 그 사이 골목길이 섞여 있는 동네입니다. / 현관문은 멀쩡한데 거실과 베란다 사이 미닫이문, 아이 방 문, 드레스룸 문이 안 열려서 연락하시는 일도 생각보다 많습니다.
집 안 문은 현관보다 잠금장치가 단순해서 손으로 풀리는 경우가 많습니다. / 대신 종류가 제각각이라 어떤 장치인지부터 알아야 엉뚱한 힘을 주지 않습니다.
이 글은 한남동 아파트와 주택에서 베란다 미닫이, 방문, 창호 잠금이 말썽일 때 볼 곳을 장치별로 나눴습니다. / 혼자 안 될 때는 [용산 출장열쇠](seoul-yongsan.html)로 연락 주시면 됩니다.
@ 한남동 베란다 미닫이문 잠금장치 점검

# 우리 집 문에 달린 장치부터 알아 두기
미닫이와 방문에 쓰이는 잠금은 대체로 네 가지입니다. / 생김새만 알면 어느 방향으로 돌리고 눌러야 하는지 짐작이 됩니다.
- 창틀 가운데 반달 모양 손잡이를 돌려 거는 크레센트
- 문 옆면에서 갈고리가 튀어나와 걸리는 훅 걸쇠
- 손잡이 가운데 누름 단추가 있는 방문 손잡이
- 열쇠 구멍이 따로 달린 미닫이 전용 자물쇠
사진 한 장만 보내 주셔도 어떤 종류인지 바로 알려드립니다. / 한 집 안에서도 거실 창은 크레센트, 다용도실 쪽은 훅 걸쇠처럼 서로 다른 장치를 쓰는 경우가 흔하니 잠긴 문 하나만 찍어 주시면 됩니다.

# 베란다 미닫이 크레센트가 안 돌아갈 때
크레센트는 반달 쇠가 맞은편 걸이 쇠에 물리는 방식입니다. / 문짝이 레일 위에서 조금 밀려 있으면 쇠끼리 꽉 끼어서 손잡이가 꿈쩍하지 않습니다.
이럴 때는 문짝을 잠금 반대쪽으로 아주 살짝 밀어 주면서 손잡이를 돌려 보세요. / 끼어 있던 힘이 풀리면서 부드럽게 돌아가는 경우가 대부분입니다.
나사가 풀려 크레센트 몸통이 덜렁거린다면 무리하게 돌리지 마세요. / 안쪽 톱니가 빠져 반쯤 걸린 채 멈출 수 있습니다. / 이중창이라면 바깥 창과 안쪽 창에 크레센트가 각각 달려 있으니 어느 쪽이 걸렸는지도 확인해 보세요. 안쪽만 풀고 바깥은 걸린 채 밀다가 레일에서 문짝이 빠지는 일이 있습니다.

# 레일에 먼지가 쌓이면 잠금도 뻑뻑해집니다
창을 자주 열어 두는 베란다는 레일 틈에 흙먼지와 낙엽 부스러기가 쉽게 고입니다. / 바퀴가 제대로 안 굴러가면 문짝이 기울고, 기운 만큼 걸쇠 위치도 틀어집니다.
마른 붓이나 청소기 틈새 솔로 레일을 훑어 내고 다시 여닫아 보세요. / 물걸레로 바로 닦으면 먼지가 진흙처럼 뭉치니 마른 상태에서 먼저 털어 내는 게 낫습니다. / 레일 끝부분 배수 구멍이 막혀 있으면 비 온 뒤 물이 고여 바퀴가 녹슬기도 하니 같이 뚫어 두세요.
@ 한남동 베란다 레일 먼지 청소 후 잠금 확인

# 베란다에 나가 있다가 문이 잠겼다면
아이가 장난으로 거실 쪽에서 걸쇠를 걸어 버리는 일이 있습니다. / 바깥에 갇힌 분은 먼저 아이에게 차분하게 반달 손잡이를 반대로 돌리라고 말해 주세요.
아이가 어리거나 겁을 먹었다면 억지로 시키지 말고 휴대폰으로 가족이나 관리사무소에 먼저 연락하세요. / 겨울이나 비 오는 날에는 오래 기다리지 말고 바로 전화 주시는 것이 좋습니다.
베란다 유리를 깨는 건 마지막 방법으로 남겨 두세요. / 파편 때문에 다칠 수 있고, 미닫이 유리는 교체가 까다롭습니다.

# 방문이 안에서 잠겼을 때
방문 손잡이 가운데 단추를 누르고 닫으면 밖에서는 안 열립니다. / 바깥 손잡이 가운데 작은 구멍이 있다면 비상 해제용이라 가는 막대로 풀 수 있습니다.
구멍이 일자 홈이면 동전이나 일자 드라이버 끝을 넣고 돌리면 됩니다. / 동그란 구멍이면 펴진 클립이나 가는 육각렌치를 끝까지 넣어 누르면 풀립니다.
안에 아이가 있다면 문 너머로 계속 말을 걸어 주세요. / 물을 틀어 놓았거나 불을 켠 상태라면 전화로 먼저 알려주셔야 순서를 앞당길 수 있습니다.

# 이렇게 하면 손잡이가 더 망가집니다
- 잠긴 손잡이를 반대로 세게 비틀기
- 문틈에 카드나 칼을 끼워 걸쇠를 긁기
- 해제 구멍에 이쑤시개처럼 부러지기 쉬운 걸 넣기
특히 나무 이쑤시개는 구멍 안에서 부러지면 꺼내기가 어려워 작업이 길어집니다. / 해 보다가 손잡이가 덜컹거리기 시작했다면 거기서 멈추고 연락 주세요. 그 상태까지는 대부분 손잡이를 상하지 않고 풀 수 있습니다.

# 오래된 주택 미닫이는 사정이 다릅니다
한남동 언덕 쪽 주택은 나무 미닫이나 알루미늄 새시에 열쇠 자물쇠를 따로 단 곳이 있습니다. / 열쇠를 잃었거나 자물쇠가 녹슬어 안 돌아가면 손으로 풀기는 어렵습니다.
이런 자물쇠는 문을 상하지 않게 열고 같은 크기 자물쇠로 바꾸는 쪽이 낫습니다. / 크기가 맞는 부품이 있는지 미리 보려면 사진과 대략적인 폭을 알려주세요. / 언덕길 위쪽 집이라면 차를 세울 수 있는 곳도 같이 말씀해 주시면 걸어 올라가는 시간을 줄일 수 있습니다.

# 전화하실 때 이것만 알려주세요
- 잠긴 문이 베란다 쪽인지, 방문인지, 드레스룸인지
- 문 안쪽에 사람이 있는지
- 잠금장치 사진과 손잡이 모양
- 아파트라면 동과 호수, 주택이라면 가까운 큰길
현관 출입이 되는지도 같이 알려주세요. / 공동 현관 비밀번호가 필요한 건물이면 미리 말씀해 주셔야 도착 후 기다리는 시간이 줄어듭니다.

# 사시는 분 확인과 비용 안내
집 안 문이라도 작업 전에는 거주 확인을 합니다. / 신분증 주소나 우편물, 관리사무소 세대 확인 가운데 편한 방법으로 하시면 됩니다.
어떤 장치를 어떻게 풀지 보고 나서 비용을 먼저 말씀드립니다. / 동의하실 때만 시작하고, 끝내 못 열면 비용은 받지 않습니다. / 잠금장치를 새로 바꿔야 할 것 같으면 그 부분은 따로 떼어 여쭤보고, 오늘은 열기만 하고 부품은 나중에 바꾸셔도 됩니다.

# 열고 난 뒤 손보는 것
풀린 다음에는 왜 걸렸는지 같이 봅니다. / 크레센트 나사를 다시 조이고, 레일 바퀴 높이를 맞춰 문짝이 똑바로 서게 합니다.
방문 손잡이가 헐거워 단추가 저절로 눌린 경우라면 손잡이를 바꾸는 편이 낫습니다. / 아이가 있는 집은 단추 잠금이 없는 손잡이나 바깥에서 쉽게 풀리는 형태로 바꾸는 방법도 말씀드립니다. / 현관 도어락까지 함께 보고 싶으시면 [도어락 수리](doorlock-repair.html)나 [도어락 설치](doorlock-install.html) 안내를 참고해 주세요.
@ 한남동 방문 손잡이 비상 해제 구멍 확인
