# 원효로동 현관, 손잡이 느낌이 이상하다면
원효로동은 용산역 생활권과 가까운 큰길을 따라 아파트와 다세대, 1층에 가게를 둔 상가주택이 나란히 있는 동네입니다. / 손잡이 일체형 도어락이나 레버 손잡이를 오래 쓴 집이라면 손잡이가 흔들리거나 헛도는 일을 한 번쯤 겪게 됩니다.
처음에는 살짝 덜렁거리는 정도라 그냥 쓰기 쉽습니다. / 하지만 헐거움이 심해지면 어느 날 손잡이를 돌려도 걸쇠가 꼼짝하지 않아 문 안팎 어느 쪽에서도 열리지 않는 상황이 됩니다.
이 글은 원효로동에서 현관 손잡이가 헐겁거나 헛돌 때 어디부터 보면 되는지, 그리고 [용산 출장열쇠](seoul-yongsan.html)를 부를 때 무엇을 알려주면 좋은지 정리했습니다.
@ 원효로동 현관 도어락 손잡이 헐거움 점검

# 흔들림과 헛돎은 다른 증상입니다
손잡이가 흔들린다는 건 손잡이를 잡고 위아래나 앞뒤로 움직였을 때 유격이 느껴진다는 뜻입니다. / 대개 손잡이를 문에 붙잡아 두는 나사가 풀린 경우라 비교적 간단히 해결됩니다.
헛돈다는 건 손잡이는 끝까지 돌아가는데 걸쇠가 따라 움직이지 않는 상태입니다. / 안쪽에서 힘을 전해 주는 축이나 부품이 닳거나 빠진 경우라 손잡이를 떼어 봐야 원인을 알 수 있습니다.
둘이 함께 오는 경우도 많습니다. / 흔들림을 오래 방치하면 축이 비스듬히 힘을 받아 닳고, 결국 헛도는 단계까지 가는 식입니다.

# 안쪽 손잡이 나사부터 살펴보기
집 안에 계신다면 안쪽 손잡이 아래나 옆면에 작은 나사가 있는지 보세요. / 손잡이를 고정하는 나사가 반 바퀴만 풀려도 손잡이 전체가 흔들립니다.
육각렌치를 쓰는 작은 무두 나사인 경우가 많습니다. / 맞는 크기의 렌치로 천천히 조여 보고, 너무 세게 돌려 나사 머리가 뭉개지지 않게 주의하세요.
도어락 몸체를 문에 붙잡는 큰 나사도 함께 확인해 보세요. / 몸체가 문에서 떠 있으면 손잡이까지 같이 흔들립니다. / 조였는데도 금세 다시 풀린다면 나사 구멍이 넓어졌거나 나사산이 닳은 것이라, 같은 나사를 계속 조이기보다 한 치수 긴 나사나 보강이 필요합니다.

# 손잡이가 헛돌면 문 열림부터 확인
헛도는 손잡이는 문이 열린 상태일 때 미리 손보는 것이 가장 좋습니다. / 혹시 지금 문이 열려 있다면 닫지 말고 그대로 둔 채 연락 주세요.
이미 문이 닫혀 있고 손잡이가 헛돈다면 걸쇠가 문틀에 걸린 채로 멈춰 있는 것입니다. / 손잡이를 여러 번 세게 돌리면 남아 있던 부품까지 닳아 버리니 두세 번 해 보고 멈추세요.
번호를 눌러 잠금은 풀렸는데 손잡이만 헛도는 경우도 있습니다. / 이때는 도어락 안쪽에서 손잡이와 걸쇠를 이어 주는 부품이 문제라 전자 쪽보다는 기계 쪽 고장입니다.

# 축이 닳는 이유
손잡이와 걸쇠는 네모난 쇠막대 같은 축으로 연결돼 있습니다. / 손잡이를 돌리면 이 축이 함께 돌면서 걸쇠를 당기는 구조입니다.
오래 쓰면 축의 모서리가 닳아 둥글어지고, 손잡이 구멍과 헐겁게 맞물리게 됩니다. / 그러면 손잡이는 돌아가도 축은 덜 돌거나 아예 안 돌게 됩니다.
문을 손잡이로 세게 잡아당겨 닫는 습관, 손잡이에 가방을 걸어 두는 습관이 축을 빨리 닳게 합니다. / 레버를 아래로 누른 채 기대거나 몸무게를 싣는 일도 같은 영향을 줍니다. / 아이들이 손잡이에 매달려 노는 집은 축이 휘는 일도 있어서, 손잡이 높이가 좌우로 미묘하게 달라 보이면 그것도 신호입니다.
@ 원효로동 도어락 손잡이 축 마모 확인

# 상가주택 계단 출입문은 사정이 다릅니다
1층에 가게가 있는 상가주택은 계단 쪽 공용 출입문 손잡이를 여러 사람이 하루 종일 씁니다. / 세대 현관보다 훨씬 빨리 헐거워지고, 비바람을 맞는 자리라 나사가 녹슬어 풀리기도 합니다.
공용 출입문은 건물주나 관리인이 관리하는 경우가 많습니다. / 가게 영업 시간에 맞춰 문을 여닫는 건물이라면 손님 출입이 적은 시간대를 골라 작업하는 편이 서로 편합니다. / 고장이 났다면 먼저 그분께 알리고, 출장을 부를 때도 누가 확인해 주실지 미리 정해 주세요.

# 레버 손잡이가 아래로 처져 있다면
레버 손잡이가 수평으로 돌아오지 않고 아래로 처져 있다면 손잡이를 되돌려 주는 스프링이 약해진 것입니다. / 쓰는 데 당장 지장은 없어 보여도, 걸쇠가 끝까지 튀어나오지 않아 문이 제대로 잠기지 않을 수 있습니다.
문을 닫은 뒤 바깥에서 살짝 당겨 보세요. / 문이 덜컥 열리거나 덜 물린 느낌이 들면 잠금이 제대로 되지 않은 것이니 빨리 손보는 게 좋습니다. / 처짐은 바깥 손잡이보다 자주 잡는 안쪽 손잡이에서 먼저 나타나는 편이라 양쪽을 번갈아 비교해 보세요.

# 직접 손대지 않는 게 나은 경우
- 손잡이를 떼어 내니 안에서 작은 부품이 떨어진 경우
- 축이 부러져 반쪽만 남은 경우
- 손잡이 자체에 금이 갔거나 휜 경우
- 문이 닫힌 채로 손잡이가 완전히 헛도는 경우
부품이 빠진 상태에서 다시 끼워 맞추다 보면 순서가 틀려 오히려 더 안 열리는 일이 생깁니다. / 떼어 낸 부품은 버리지 말고 봉투에 담아 두셨다가 보여 주세요.

# 연락하실 때 알려주시면 좋은 것
원효로동은 큰길과 골목이 섞여 있어서 건물 이름이나 번지, 가까운 큰길을 알려주시면 빨리 찾아갑니다. / 상가주택이라면 1층 가게 옆 계단인지, 뒤쪽 출입구인지도 말씀해 주세요.
손잡이 사진과 함께 지금 문이 열려 있는지 닫혀 있는지가 가장 중요합니다. / 흔들리는지, 헛도는지, 처져 있는지도 짧게 적어 보내 주시면 맞는 부품을 챙겨 갑니다.

# 거주 확인과 비용 안내
문을 열거나 도어락을 손볼 때는 그 집에 사시는 분인지 먼저 확인합니다. / 신분증 주소, 이름과 주소가 함께 적힌 우편물, 집주인이나 관리인 확인 가운데 하나면 됩니다.
현장에서 손잡이를 떼어 보고 원인을 말씀드린 뒤 비용을 안내합니다. / 동의하실 때만 시작하며, 닫힌 문을 끝내 못 열면 비용은 받지 않습니다. 진행 방식은 [이용안내](guide.html)에 정리했습니다.

# 고칠지 바꿀지는 이렇게 봅니다
나사만 풀린 경우는 그 자리에서 조이고 풀림 방지 처리를 해 드립니다. / 축이나 스프링이 닳았다면 같은 규격 부품으로 갈아 끼우는 [도어락 수리](doorlock-repair.html)로 끝나는 경우가 많습니다.
도어락 몸체 안쪽 부품까지 상했거나 오래된 단종 제품이라면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다. / 닫힌 문을 여는 과정은 [현관문 개문](door-open.html)에 적어 두었습니다.
@ 원효로동 손잡이 축 교체 후 작동 시험
