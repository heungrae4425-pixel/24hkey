# 현관은 멀쩡한데 집 안 문이 말을 안 들을 때
용문동은 효창동, 원효로동과 맞붙은 동네로 오래된 주택과 다세대, 아파트가 골목마다 섞여 있습니다. / 집이 지어진 시기가 제각각이라 베란다 창, 거실 미닫이 중문, 방 미닫이문에 달린 잠금장치도 모양이 다 다릅니다.
이런 잠금장치는 현관 도어락처럼 매일 신경 쓰는 부분이 아니라서, 어느 날 갑자기 안 돌아가거나 안 풀리면 어디서부터 봐야 할지 막막합니다. / 이 글은 용문동 집에서 흔히 보는 베란다·미닫이 잠금장치를 종류별로 나누고, 직접 손볼 수 있는 곳과 맡기는 게 나은 곳을 구분했습니다.
@ 용문동 베란다 창 잠금장치 점검

# 먼저 문 종류를 구분해 두기
잠금장치를 보기 전에 어떤 문인지부터 나눠 보세요. / 같은 미닫이라도 구조가 달라서 손볼 곳이 다릅니다.
- 베란다 창: 알루미늄이나 플라스틱 창틀에 반달 모양 잠금이 달린 창
- 거실 미닫이 중문: 현관과 거실 사이 유리 미닫이, 손잡이 옆에 잠금이 있는 문
- 방 미닫이문: 벽 안으로 들어가거나 옆으로 밀리는 방문, 걸고리나 작은 잠금이 있는 문
- 다세대 베란다 철문: 옥상이나 뒤 베란다로 나가는 여닫이 철문
종류를 알면 전화로 설명하기도 쉬워지고, 사진 한 장으로 미리 판단할 수 있는 경우도 많습니다.

# 베란다 창 반달 잠금이 안 돌아갈 때
베란다 창 가운데에 있는 반달 모양 잠금은 두 창틀이 정확히 겹쳐야 부드럽게 돌아갑니다. / 창이 끝까지 닫히지 않은 상태에서 돌리면 걸쇠가 받침에 걸려 뻑뻑해집니다.
먼저 창을 양쪽 끝까지 밀어 닫은 뒤 다시 돌려 보세요. / 그래도 안 돌아가면 걸쇠와 받침 사이에 먼지나 벌레 사체가 끼어 있지 않은지 손전등으로 비춰 봅니다.
힘을 줘서 억지로 돌리면 플라스틱 손잡이가 부러지기 쉽습니다. / 부러진 잠금은 같은 나사 간격 제품으로 바꿔야 해서 일이 커집니다.
@ 용문동 베란다 창 반달 잠금 걸쇠 받침 확인

# 창이 무거워졌다면 바퀴부터 의심하기
창을 밀 때 예전보다 무겁고 덜컹거린다면 아래쪽 바퀴가 닳았거나 레일에 이물질이 쌓인 것입니다. / 창이 한쪽으로 기울어 닫히면 잠금 위치도 어긋나게 됩니다.
레일은 마른 솔이나 청소기로 먼지를 빼 주는 것만으로도 한결 나아집니다. / 기름을 레일에 바로 뿌리면 먼지가 더 달라붙으니 피하세요.
레일 양 끝 배수 구멍이 막혀 있으면 비 온 뒤 물이 고여 바퀴가 빨리 상합니다. / 청소할 때 그 구멍까지 같이 뚫어 주시면 좋습니다.
바퀴 높이를 조절하는 나사가 창 아래쪽 옆면에 있는 제품도 있습니다. / 어디인지 모르겠다면 무리하게 돌리지 말고 사진으로 먼저 물어봐 주세요.

# 거실 미닫이 중문 잠금이 안 풀릴 때
현관과 거실 사이 유리 미닫이 중문에는 아이가 현관으로 나가지 못하게 잠금을 달아 둔 집이 있습니다. / 손잡이 옆 작은 레버나 버튼 방식이 많고, 바깥에서 풀 수 없는 제품도 있습니다.
아이가 거실 쪽에서 잠그고 어른이 현관 쪽에 있게 되면 곤란해집니다. / 이럴 때는 아이에게 레버를 반대로 밀어 보라고 차분히 말해 보시고, 안 되면 유리를 건드리지 말고 연락 주세요.
유리 중문은 문틈에 무엇을 끼워 넣다가 유리가 깨질 수 있어 특히 조심해야 합니다. / 아이가 유리 가까이 서 있다면 뒤로 물러나 있으라고 먼저 말해 주세요.

# 방 미닫이문 걸고리가 안쪽에서 걸렸을 때
벽 쪽으로 밀어 여는 방 미닫이문은 안쪽에 간단한 걸고리나 작은 회전 잠금이 달린 경우가 많습니다. / 안에서 걸고 나왔다가 문이 닫히면 밖에서 풀기 어렵습니다.
문과 문틀 사이 틈이 조금 있다면 얇은 플라스틱 자를 위에서 아래로 쓸어 올려 걸고리를 들어 올리는 방법이 통하기도 합니다. / 쇠붙이나 칼은 문짝 칠을 긁어 놓으니 쓰지 마세요.
틈이 전혀 없거나 회전식 잠금이라면 문을 레일에서 빼야 할 수 있습니다. / 이 작업은 문짝이 무거워 혼자 하다 다치기 쉬우니 맡기시는 편이 안전합니다.

# 다세대 뒤 베란다 철문이 뻑뻑할 때
다세대 건물 중에는 뒤 베란다나 옥상으로 나가는 철문이 따로 있는 집이 있습니다. / 바깥 비바람을 맞는 문이라 경첩과 손잡이 잠금이 녹슬어 뻑뻑해지기 쉽습니다.
손잡이가 아예 안 돌아간다면 열쇠 구멍 안쪽이 녹슨 것일 수 있습니다. / 이때 힘으로 돌리면 열쇠가 부러질 수 있으니 멈추고 연락 주세요.
경첩에서 끼익 소리가 나고 문이 바닥을 긁는다면 철문이 조금 처진 것입니다. / 공용으로 쓰는 문이라면 혼자 고치기보다 건물 관리하시는 분께 먼저 알리고 함께 손보는 편이 뒤탈이 없습니다.
@ 용문동 다세대 뒤 베란다 철문 경첩과 손잡이

# 베란다에 나가 있는데 안쪽이 잠겼다면
빨래를 널러 베란다에 나갔다가 안쪽 문이 닫히며 잠기는 경우도 있습니다. / 휴대폰이 손에 있다면 바로 연락 주시고, 없다면 창문 너머 이웃에게 도움을 청하세요.
추운 날에는 오래 서 있지 않도록 이불이나 수건으로 몸을 감싸고 기다리세요. / 베란다 난간 쪽으로 몸을 내밀어 옆집으로 넘어가려는 시도는 절대 하지 마세요.

# 직접 해도 되는 일, 맡기는 게 나은 일
아래처럼 나눠 생각하면 판단이 쉽습니다. / 애매할 때는 사진을 먼저 보내 주세요.
- 직접: 레일 먼지 청소, 창 끝까지 닫고 다시 돌려 보기, 걸쇠 받침 이물질 빼기
- 맡기기: 부러진 잠금 교체, 레일에서 문짝 빼기, 유리 중문 잠금 해제, 녹슨 철문 열쇠 구멍
@ 용산 용문동 미닫이 중문 잠금 해제 출장

# 연락 주실 때와 도착한 뒤
어떤 문인지, 지금 문이 닫힌 채 안 열리는지 아니면 잠금만 안 되는지 알려 주세요. / 잠금장치 사진과 문 전체 사진 두 장이면 충분하고, 골목 안 주택이라면 가까운 큰길도 함께 알려 주세요.
집 안 문이라도 사시는 분인지 확인한 뒤 작업합니다. / 신분증이나 주소가 나온 우편물이면 되고, 비용은 시작 전에 먼저 말씀드립니다. 못 열면 받지 않습니다.
진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 손보고 나면 함께 해 두는 것
잠금장치를 고치거나 바꾼 뒤에는 창과 문을 여러 번 열고 닫으며 잠금이 정확히 맞물리는지 확인합니다. / 아이가 있는 집이라면 어른 손으로만 풀 수 있는 위치에 보조 잠금을 다는 것도 상의해 볼 수 있습니다.
현관 도어락도 같이 봐 달라고 하시면 함께 점검합니다. / 현관 문제는 [현관문 개문](door-open.html)과 [도어락 수리](doorlock-repair.html)에 정리해 두었습니다.

# 용문동 말고 용산 어디든
용문동과 맞붙은 효창동, 원효로동을 비롯해 청파동, 후암동, 이촌동, 서빙고동, 한남동, 이태원동, 보광동까지 용산 전 동네를 다닙니다. / 동네 안내는 [용산구 출장열쇠](seoul-yongsan.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
