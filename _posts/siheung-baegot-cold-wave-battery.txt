# 배곧동 바닷바람이 차가워지는 계절
배곧동은 바다와 가까운 새 아파트와 오피스텔이 모여 있는 동네입니다. / 겨울이 되면 바다 쪽에서 불어오는 바람이 차고 습해서, 바깥에 드러난 현관이나 건물 입구 장치가 먼저 영향을 받습니다.
도어락도 그중 하나입니다. / 찬 바람을 맞는 번호판은 반응이 느려지고, 건전지는 추위에 힘을 덜 쓰게 되어 퇴근길에 번호판이 꺼져 있는 일이 생깁니다.
이 글은 배곧동처럼 바람과 습기가 함께 오는 동네에서 겨울에 도어락이 말썽일 때 미리 챙길 것을 정리했습니다. / 오피스텔처럼 공동현관과 호실 문을 두 번 거쳐야 하는 집의 대처도 따로 적었습니다.
@ 배곧동 겨울 바닷바람 도어락 반응 느림

# 찬 바람과 습기가 함께 오는 동네
바다 가까운 동네는 같은 기온이라도 바람 때문에 체감이 더 춥습니다. / 장치도 마찬가지라 바람을 직접 맞는 번호판은 실내 쪽 몸체보다 훨씬 빨리 차가워집니다.
여기에 습기가 더해지면 낮과 밤 기온 차이로 번호판 틈에 물기가 맺히기 쉽습니다. / 추위와 물기가 겹치면 건전지가 멀쩡해도 반응이 이상해질 수 있습니다.
그래서 배곧동에서는 겨울 도어락 문제를 볼 때 건전지와 습기를 함께 보는 편이 맞습니다. / 한쪽만 손보면 다음 한파에 또 비슷한 일이 생깁니다.

# 일시적인 추위 탓인지, 건전지 수명인지
번호판이 느려졌을 때 가장 먼저 가려야 할 것은 이게 추위 때문에 잠깐 그런 건지, 건전지가 다 돼 가는 건지입니다. / 구분하는 방법은 의외로 간단합니다.
- 해가 뜨고 낮이 되면 다시 또렷해진다: 추위 영향이 큰 쪽
- 낮에도 느리고 경고음이 난다: 건전지 수명이 다한 쪽
- 실내 쪽 열림 버튼도 힘이 없다: 건전지 쪽
- 바깥만 느리고 안쪽은 멀쩡하다: 바깥 번호판이 찬 바람을 맞는 쪽
추위 영향이 큰 쪽이라도 반쯤 쓴 건전지라면 바꿔 두는 게 안전합니다. / 한겨울 깊은 밤에는 낮보다 훨씬 더 떨어지기 때문입니다.

# 바람을 정면으로 맞는 현관
복도가 바깥으로 열려 있거나 계단실 창이 늘 열려 있는 건물은 현관문이 찬 바람을 그대로 맞습니다. / 이런 집은 같은 단지 안에서도 다른 집보다 겨울 문제가 먼저 나타납니다.
현관 앞 공용 창을 이웃과 상의해 겨울에만이라도 닫아 두면 도움이 됩니다. / 번호판 앞을 막는 덮개를 직접 붙이는 것은 습기가 갇힐 수 있어 권하지 않습니다.

# 오피스텔은 문이 두 번 막힙니다
배곧동 오피스텔은 건물 공동현관을 카드나 번호로 통과한 뒤 호실 도어락을 다시 열어야 하는 구조가 많습니다. / 한파에는 둘 중 하나, 또는 둘 다 말썽을 부릴 수 있습니다.
공동현관에서 막혔다면 관리실이나 경비실, 같은 건물 입주자에게 먼저 도움을 청하세요. / 건물 공용 장치는 관리 쪽이 맡는 부분이라 그쪽 확인이 가장 빠릅니다.
공동현관은 통과했는데 호실 번호판이 꺼졌다면 그때는 아래 비상 전원 순서를 따라 해 보시고, 안 되면 연락 주세요. / 저희가 가야 할 때는 건물 출입이 되는지 꼭 미리 알려 주세요.
@ 배곧동 오피스텔 공동현관 호실 도어락

# 공동현관 카드가 안 읽힐 때
추운 날 공동현관 카드 리더가 카드를 잘 못 읽는 일도 있습니다. / 카드를 지갑에서 꺼내 리더 정면에 바짝 대고 잠깐 멈춰 보세요.
여러 장의 카드가 겹쳐 있으면 서로 신호가 엉켜 안 읽히기도 합니다. / 출입 카드 하나만 따로 대 보시고, 그래도 안 되면 번호 입력이 되는지 확인해 보세요.
휴대폰 케이스에 카드를 끼워 쓰는 분은 케이스째 대면 잘 안 읽히는 일도 있습니다. / 카드를 빼서 대 보시면 차이가 바로 드러납니다.

# 얼굴인식·지문형은 전기를 더 씁니다
새 아파트에는 얼굴인식이나 지문 방식 도어락을 쓰는 집이 많습니다. / 이런 방식은 카메라와 센서를 켜야 해서 번호만 쓰는 도어락보다 전기를 더 씁니다.
겨울에는 건전지 힘이 떨어지는 데다 쓰는 전기는 많으니 교체 주기가 짧아집니다. / 충전식 배터리를 쓰는 제품이라면 겨울에는 충전 표시를 더 자주 확인해 주세요.
인식이 자꾸 실패한다면 손이나 얼굴 상태보다 전원 쪽을 먼저 의심해 보세요. / 번호 입력으로는 열리는지 함께 확인하면 원인이 좁혀집니다.

# 비상 전원 넣는 자세
번호판이 완전히 꺼졌다면 바깥쪽 아래 비상 단자에 9V 사각 건전지를 대 보세요. / 바람이 센 날에는 몸으로 바람을 막듯 번호판 앞에 서서 대면 손이 덜 떨리고 단자에서 덜 미끄러집니다.
9V 건전지도 차가우면 힘이 약하니 주머니에 넣어 잠깐 데운 뒤 대세요. / 단자에 물기가 있다면 휴지로 먼저 닦아 주세요.
대는 동안 손을 떼지 말고 번호를 끝까지 입력합니다. / 열리면 그날 안쪽 건전지를 전부 새것으로 바꿔 주세요.

# 추운 날 피해야 할 것
라이터나 핫팩을 번호판에 오래 대 두는 것, 뜨거운 물을 붓는 것, 드라이기 뜨거운 바람을 가까이서 쐬는 것은 피해 주세요. / 갑자기 데우면 안쪽에 물방울이 맺혀 겨울 내내 말썽을 부리게 됩니다.
번호를 계속 누르는 것도 좋지 않습니다. / 여러 번 틀리면 입력이 한동안 막혀 추운 곳에서 기다리는 시간만 길어집니다.

# 겨울 건전지 관리 달력
배곧동처럼 바람이 센 동네라면 아래처럼 해 두시면 편합니다.
- 첫 추위 전: 건전지 전부 새것으로, 날짜 적어 두기
- 한겨울 한가운데: 번호판 반응과 경고음 한 번 확인
- 눈이나 비가 온 다음 날: 번호판 틈 물기 닦기
- 봄이 오기 전: 건전지 칸 접점에 녹이나 가루가 없는지 보기
비상용 9V는 차보다 늘 들고 다니는 가방에 넣어 두세요. / 주차장에 세운 차 안은 바깥만큼 차가워집니다.

# 연락하실 때
배곧동 어느 단지인지 또는 오피스텔 건물 이름과 호수를 알려주세요. / 공동현관에서 막혔는지 호실 문에서 막혔는지, 9V를 대 봤는지도 함께 말씀해 주시면 됩니다.
도착하면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 관리실 확인 중 하나를 준비해 주세요.

끝내 못 열면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 진행 순서는 [이용안내](guide.html)에 있습니다.
