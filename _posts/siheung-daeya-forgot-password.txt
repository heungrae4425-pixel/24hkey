# 대야동에서 비밀번호가 갑자기 생각나지 않을 때
대야동은 오래된 주택가와 상가, 새로 들어선 아파트가 함께 있는 동네입니다. / 도어락을 새로 바꾼 지 얼마 안 됐거나 오랜만에 집에 오면 번호가 순간적으로 떠오르지 않는 일이 생깁니다.
번호를 여러 번 틀렸다면 도어락이 잠시 입력을 막아 더 막막해집니다. / 이 글은 대야동에서 비밀번호를 잊었을 때 직접 해볼 수 있는 방법과 전화하는 기준을 정리했습니다.
[시흥 출장열쇠](siheung.html)가 도착해서 진행하는 순서도 함께 적었습니다. / 지금 문 앞이시라면 3번부터 보셔도 됩니다.
@ 대야동 출장열쇠 비밀번호 분실 도어락

# 번호가 생각 안 나는 이유는 대개 단순합니다
너무 오래 같은 번호를 쓰면 손가락이 기억하는데 머리로는 떠오르지 않는 일이 있습니다. / 이럴 때는 휴대폰을 잠시 내려놓고 문 앞에서 손이 가는 대로 한 번 눌러 보는 것이 도움이 됩니다.
가족이 번호를 바꾼 걸 모르는 경우도 아주 흔합니다. / 문 열기 전에 가족에게 전화해서 최근에 번호를 바꾼 적이 있는지 먼저 물어보세요.
예전 집이나 직장 번호가 섞여서 헷갈리는 경우도 있습니다. / 옛날 번호부터 한 번씩 떠올려 보는 방법도 있습니다.

# 도어락이 입력을 막았을 때
틀린 번호를 몇 번 입력하면 일정 시간 동안 번호 입력을 받지 않는 제품이 많습니다. / 이때는 계속 누르지 말고 몇 분 쉬었다가 다시 시도하세요.
화면에 경고 불빛이나 소리가 길게 나는 경우에는 설명서에 해제 방법이 있습니다. / 제품마다 시간이 다르니 서너 번 이상은 시도하지 않는 것이 좋습니다.
막힌 상태에서 번호를 마구 누르면 도어락이 더 오래 잠길 수도 있습니다. / 급해도 한두 분 기다리는 것이 오히려 빠릅니다.

# 비밀번호 대신 다른 방법이 있는지 확인
도어락에 카드, 지문, 열쇠 구멍이 같이 있다면 그쪽으로 열어 보세요. / 열쇠는 지갑이나 가방 구석에 있는 경우가 많으니 한 번 더 찾아봅니다.
스마트폰 앱과 연결된 제품이라면 앱으로 문을 열거나 임시 번호를 만들 수 있습니다. / 앱 로그인 정보도 기억나지 않으면 그때 전화 주세요.
카드키를 가족 중 누가 가지고 있는지 확인하는 것도 방법입니다. / 집 안에 있는 가족이 안쪽에서 열어 주는 것이 가장 빠릅니다.
@ 대야동 도어락 비밀번호 잊었을 때

# 집 안에 가족이 있다면
가족이 집에 있다면 초인종이나 전화로 먼저 연락해서 열어 달라고 하세요. / 문을 못 열면 아이가 혼자 있는 경우 특히 서둘러야 합니다.
가족이 외출 중이면 번호를 알고 있는 사람에게 문자로 번호를 보내 달라고 부탁합니다. / 번호를 문자로 주고받는 것이 걱정되면 전화로 직접 듣는 방법도 있습니다.
가족 모두 번호를 모르는 상황이라면 그때는 열쇠집이 필요합니다.

# 직접 하면 안 되는 것
도어락을 분해하거나 건전지를 뺐다 끼웠다 하는 것은 권하지 않습니다. / 일부 제품은 건전지를 빼면 설정이 초기화되기도 하고 고장 날 수도 있습니다.
드라이버로 도어락 외관을 비틀어 열려고 하면 문과 도어락이 상합니다. / 교체 비용이 더 커지는 지름길입니다.
인터넷에서 찾은 초기화 방법을 따라 하다가 오히려 잠기는 경우도 있습니다. / 제품 종류가 다르면 방법이 다르니 확실하지 않으면 멈추세요.

# 전화하실 때 알려 주실 것
대야동은 주택가 골목이 많아서 위치 설명이 정확해야 도착이 빠릅니다. / 지도 앱의 주소를 문자로 보내 주시는 것이 가장 좋습니다.
- 도어락 모양과 제조사 이름이 보이면 알려 주세요
- 번호판 상태(켜짐, 꺼짐, 경고음)
- 열쇠 구멍이 있는지 없는지
- 집 안에 아이나 반려동물이 있는지
- 가족 중 번호를 아는 사람과 연락이 되는지
도어락 사진을 문자로 보내 주시면 필요한 장비를 챙겨 가기 좋습니다. / 사진이 없어도 전화로 설명해 주시면 됩니다.

# 도착하면 이렇게 진행합니다
먼저 도어락 종류와 문 상태를 확인합니다. / 번호를 모르는 상태에서도 도어락과 문을 최대한 상하지 않게 여는 방법을 순서대로 시도합니다.
문을 열고 나면 새 비밀번호를 등록하는 것까지 도와드립니다. / 예전 번호는 지우고 새 번호만 남겨 둡니다.
자세한 방법은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 작업 중에 부품을 바꿔야 하면 바꾸기 전에 먼저 말씀드립니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 집인지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 나온 우편물, 관리하는 분의 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집주인 모두를 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
신분증이 집 안에 있다면 관리사무소나 집주인에게 확인을 부탁하는 방법도 있습니다.

# 비용은 열기 전에 말씀드립니다
도어락 상태와 문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하면 따로 여쭤보고 진행합니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
열고 난 뒤 말없이 붙는 비용은 없습니다.
@ 시흥 대야동 출장 개문 작업

# 열고 난 뒤 번호 다시 정하기
새 번호는 가족이 기억하기 쉬우면서 남이 추측하기 어려운 것이 좋습니다. / 생일이나 전화번호 끝자리, 같은 숫자 반복은 피하세요.
번호를 종이에 적어 문 근처에 붙이는 일은 하지 마시고 휴대폰 메모에만 남기세요. / 가족 두 명 이상이 알고 있으면 이런 일이 생겨도 금방 해결됩니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 도어락이 자주 말썽이면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래됐으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 비밀번호를 잊지 않는 방법
- 가족 단체방에 번호를 직접 쓰지 말고 힌트만 남기기
- 번호를 바꾸면 가족 모두에게 바로 알리기
- 카드키나 지문 같은 다른 방법도 함께 등록하기
- 비상용 열쇠를 믿을 수 있는 사람에게 맡기기
- 배터리 교체 때마다 번호도 한 번씩 입력해 보기
이렇게 해 두면 번호 때문에 문 앞에서 막히는 일이 크게 줄어듭니다.

# 대야동 말고 시흥 어디든 갑니다
대야동 옆 신천동, 은행동, 정왕동, 배곧동, 목감동, 장곡동, 능곡동, 월곶동까지 다닙니다. / 시흥 안이면 동네 상관없이 24시간 출동합니다.
시흥에서 다니는 동네는 [시흥시 출장열쇠](siheung.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
