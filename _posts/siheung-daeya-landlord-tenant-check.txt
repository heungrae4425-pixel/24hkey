# 대야동 다가구에서 도어락 이야기가 꼬이기 전에
대야동은 시흥대야역 쪽 상가와 오래된 주택가, 새로 들어선 아파트가 한 동네에 섞여 있습니다. / 1층은 가게, 위층은 살림집인 상가주택이나 여러 세대가 사는 다가구도 많아서 세를 주고 사는 집이 흔합니다.
도어락이 고장 나면 사는 사람은 당장 불편하고, 집주인은 상황을 직접 못 봐서 답답합니다. / 처음에는 별일 아니던 이야기가 기록 없이 오가다 보면 나중에 서로 기억이 달라지는 일이 생깁니다.
이 글은 고장을 처음 알아챈 날부터 작업이 끝난 뒤까지 단계별로 남겨 두면 좋은 것을 정리했습니다. / 누가 비용을 부담하는지 같은 판단은 계약 내용과 당사자 합의의 문제라 여기서는 다루지 않습니다.
@ 대야동 임대 주택 도어락 고장 기록

# 공용 문과 우리 집 문을 나눠 봅니다
다가구와 상가주택은 문이 여러 겹입니다. / 건물 입구 공동현관, 계단실 문, 각 세대 현관문이 따로 있고 관리하는 사람도 다를 수 있습니다.
- 공동현관이나 계단실 문: 여러 세대가 함께 쓰는 문
- 세대 현관문: 그 집에 사는 사람이 매일 쓰는 문
- 1층 가게 출입문: 가게를 쓰는 사람이 따로 관리하는 문
고장 난 문이 어느 쪽인지에 따라 먼저 연락할 사람이 달라집니다. / 공용 문이라면 집주인이나 건물 관리 쪽에 바로 알리는 게 순서입니다.
아파트라면 공동현관은 관리사무소가 맡는 경우가 대부분입니다. / 세대 현관 도어락만 고장 났다면 관리사무소보다 집주인과 먼저 이야기하시면 됩니다.

# 1단계, 고장을 처음 알아챈 날
문제를 처음 알아챈 날 휴대폰으로 간단히 남겨 두세요. / 거창할 필요 없이 날짜, 증상, 사진 두세 장이면 충분합니다.
번호판이 꺼졌는지, 경고음이 나는지, 걸쇠가 덜 들어가는지처럼 눈에 보이는 상태를 적어 주세요. / 건전지를 바꿔 봤다면 그 사실과 날짜도 같이 남깁니다.
고장이 아니라 문이 처지거나 문틀이 틀어져서 생긴 일일 수도 있습니다. / 문 둘레 틈이 고르지 않거나 바닥에 끌리는 자국이 있다면 그것도 사진으로 남겨 두세요.

# 2단계, 첫 연락은 짧고 구체적으로
집주인에게 처음 연락할 때는 문자처럼 남는 방식이 좋습니다. / 길게 쓰기보다 언제부터, 어떤 증상인지, 지금 문을 쓸 수 있는지를 세 줄로 정리해 보내 보세요.
사진과 짧은 영상을 함께 보내면 멀리 있는 집주인도 상황을 금방 이해합니다. / 통화로 이야기했다면 끝나고 정한 내용을 한 줄로 다시 문자로 남겨 두세요.
집주인 쪽에서는 업체를 직접 부를지, 사는 분이 부르게 할지를 빨리 정해 주시면 좋습니다. / 답이 늦어지면 그만큼 불편한 날이 길어집니다.

# 3단계, 현장 점검 결과를 함께 듣기
점검을 부르면 현장에서 원인과 가능한 방법을 설명드립니다. / 집주인이 그 자리에 없다면 전화를 스피커로 연결해 같이 들으시는 방법을 권합니다.
한 사람이 듣고 다른 사람에게 옮기면 내용이 줄거나 바뀌기 쉽습니다. / 같이 들으면 궁금한 점도 그 자리에서 바로 물어볼 수 있습니다.
@ 대야동 도어락 점검 결과 설명

# 4단계, 고칠지 바꿀지 정하는 대화
점검 뒤에는 보통 수리로 끝나는 방법과 교체하는 방법을 나눠 말씀드립니다. / 고쳐 쓸 수 있으면 교체는 권하지 않습니다.
수리 내용은 [도어락 수리](doorlock-repair.html), 교체가 필요한 경우는 [도어락 교체](doorlock-replace.html)에서 미리 보실 수 있습니다. / 두 방법을 나란히 놓고 정하시면 대화가 짧아집니다.
결정에 시간이 필요하다면 그날은 문만 쓸 수 있게 해 두고, 나중에 다시 날을 잡는 것도 가능합니다. / 급할수록 한 번에 다 정하려고 하지 않는 편이 낫습니다.

# 5단계, 작업 뒤 남길 것
작업이 끝나면 무엇을 했는지 정리된 내용과 전후 사진을 받아 두세요. / 어떤 증상이었는지, 어떤 부품을 손봤는지, 새로 달았다면 어떤 제품인지가 들어가면 됩니다.
이 기록은 집주인에게 전달할 때도, 나중에 같은 문제가 다시 생겼을 때도 쓸모가 있습니다. / 이사 나갈 때 정리하는 자료로도 도움이 됩니다.
새 비밀번호와 카드를 등록했다면 예전 것이 모두 지워졌는지도 그 자리에서 함께 확인하세요. / 이전 세입자가 쓰던 번호가 남아 있는 일을 막을 수 있습니다.

# 세입자가 직접 단 스마트 도어락
살면서 지문이나 카드 도어락으로 바꾼 세입자도 많습니다. / 이런 경우 고장이 나면 누가 처리할지, 이사 나갈 때 어떻게 할지가 자주 이야기에 오릅니다.
바꿀 때 집주인과 미리 이야기했는지, 그때 어떻게 정했는지 남겨 둔 것이 있으면 꺼내 보세요. / 정해 둔 게 없다면 지금이라도 문자로 한 번 정리해 두시면 나중이 편합니다.
떼어 낸 예전 도어락을 보관해 두는 분들도 있습니다. / 버리기 전에 집주인에게 한 번 물어보시는 게 좋습니다.

# 집주인이 비상 번호를 원할 때
집주인이 급한 일에 대비해 비상 번호나 카드를 갖고 싶어 하는 경우가 있습니다. / 사는 분 입장에서는 부담스러울 수 있어서 이 부분은 두 분이 충분히 이야기해 정하셔야 합니다.
정했다면 누가 무엇을 갖고 있는지 문자로 남겨 두세요. / 번호를 바꿀 때 서로 알리는 방식도 같이 정해 두면 오해가 줄어듭니다.

# 이야기가 길어질 때 참고할 곳
의견이 크게 엇갈리면 주택 임대차 관련 공공 상담 창구에 물어보시는 방법이 있습니다. / 그때 위 단계마다 남겨 둔 날짜와 사진, 작업 내용이 이야기를 정리하는 데 도움이 됩니다.
저희는 문을 열고 도어락을 점검하고 고치는 일을 하며, 책임이나 부담을 정해 드리지는 않습니다. / 다만 현장에서 본 상태는 있는 그대로 설명해 드립니다.

# 문 열기 전 확인
문이 잠겨 열어야 하는 상황이라면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 임대차 계약서 사진, 집주인 통화 중 하나면 됩니다.
집주인이 부르셨는데 사는 분이 안 계신 경우에는 사는 분과 연락이 되는지부터 여쭤봅니다. / 사는 분 확인 없이 문을 여는 일은 하지 않습니다.

# 비용을 말씀드리는 때
비용은 상태를 본 뒤 작업 전에 먼저 말씀드립니다. / 두 분이 상의할 시간이 필요하면 기다렸다가 정해 주시는 대로 진행합니다.
끝내 문을 못 열면 비용은 받지 않습니다. / 문 여는 방식은 [현관문 개문](door-open.html), 전체 순서는 [이용안내](guide.html)에 정리돼 있습니다.
@ 시흥 출장열쇠 대야동 비용 사전 안내

# 대야동 밖 시흥
대야동과 이웃한 신천동, 은행동을 비롯해 목감동, 정왕동, 배곧동, 장곡동, 능곡동, 월곶동까지 [시흥 출장열쇠](siheung.html)가 다닙니다. / 시흥 밖 다른 지역은 [출장 지역](area.html)에서 확인하세요.
