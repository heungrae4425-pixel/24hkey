# 슬리퍼에 반팔, 손에는 빈 재활용 봉투뿐
은행동에서 저녁 먹고 분리수거하러 잠깐 내려갔다 올라왔는데 현관문이 꽉 잠겨 있는 일이 있습니다. / 자동으로 잠기는 도어락이라 문이 닫히는 순간 이미 잠긴 겁니다.
이럴 때 가장 곤란한 건 문보다 연락 수단입니다. / 휴대폰은 거실 탁자 위에 있고, 주머니에는 아무것도 없는 경우가 대부분입니다.
이 글은 연락할 방법을 먼저 찾는 순서부터, 문 앞에서 하지 말아야 할 것, 다음에 같은 일을 막는 습관까지 정리했습니다. / 지금 이웃 휴대폰을 빌려 보고 계신다면 아래 내용을 차례로 따라와 주세요.
@ 은행동 분리수거 나왔다 현관문 잠김

# 왜 잠깐 사이에 잠길까
요즘 도어락은 문이 닫히면 몇 초 뒤 저절로 잠기는 자동 잠금이 기본으로 켜져 있습니다. / 열쇠를 꽂고 돌려야 잠기던 예전 문과 달리, 손이 비어 있어도 그대로 잠깁니다.
바람이 불어 문이 저절로 닫히거나, 무거운 짐을 들고 나가다 등 뒤에서 문이 닫혀 버리는 일이 흔합니다. / 문을 살짝 열어 두려고 신발을 끼워 뒀다가 그게 빠지는 경우도 있습니다.
번호를 알고 있다면 아무 문제가 없습니다. / 문제는 번호 대신 카드나 지문만 쓰던 집, 혹은 번호판이 마침 꺼진 날입니다.
지문으로만 열던 집은 손이 젖었거나 차가우면 인식이 잘 안 되기도 합니다. / 분리수거를 하다 손에 물기가 묻었다면 옷에 잘 닦고 몇 번 더 대 보세요.

# 1. 연락 수단부터 확보하세요
휴대폰이 없다면 가장 먼저 연락할 길을 만드는 게 순서입니다.
- 같은 층이나 아래층 이웃에게 휴대폰을 잠시 빌리기
- 아파트라면 경비실이나 관리사무소로 가기
- 가까운 편의점이나 가게에 사정을 말하고 전화 빌리기
휴대폰을 빌릴 때는 짧게 쓰고 돌려드리겠다고 먼저 말씀하시면 이웃도 마음 편히 빌려줍니다. / 통화가 길어질 것 같으면 문자로 위치를 남겨 두는 방법도 있습니다.
가족 번호를 외우고 있지 않다면 저희 번호로 먼저 전화 주셔도 됩니다. / 010-3664-5455, 이 번호 하나는 외워 두시면 이런 날 요긴합니다.

# 2. 집 안에 누가 있는지 떠올려 보세요
가족이 잠들어 있거나 이어폰을 끼고 있어서 초인종 소리를 못 듣는 경우가 있습니다. / 초인종을 몇 번 누르고, 문을 손바닥으로 가볍게 두드려 보세요.
반려동물만 있다면 문 너머로 낮은 목소리로 말을 걸어 주세요. / 낯선 소리에 놀라 짖거나 문을 긁을 수 있으니, 출장을 부르실 때 그 사실을 꼭 알려 주세요.

# 3. 다른 열림 방법이 남아 있는지
- 번호 입력이 되는 제품인데 번호를 기억하는지
- 가족이 가진 카드나 열쇠를 가지고 올 수 있는지
- 휴대폰 앱이 가족 휴대폰에도 연결돼 있는지
가족이 가까이 있다면 기다리는 게 가장 빠를 수 있습니다. / 멀리 있다면 출장을 부르는 쪽이 낫습니다.
가족이 퇴근 중이라면 도착 예상 시간을 물어보세요. / 출장 도착과 가족 귀가 중 어느 쪽이 빠를지 견주어 정하시면 됩니다.
@ 은행동 현관 도어락 자동 잠금 확인

# 문 앞에서 이건 피하세요
- 손잡이를 세게 잡아당기거나 흔들기
- 문틈에 전단지나 카드를 밀어 넣어 걸쇠를 건드려 보기
- 생각나는 숫자를 마구 눌러 입력 제한 걸기
- 베란다나 창문으로 들어가려고 시도하기
특히 창문이나 베란다 쪽으로 들어가려는 건 위험합니다. / 1층이라도 방범창이나 난간에 걸려 다칠 수 있으니 절대 하지 마세요.
옆집 베란다를 건너가는 방법은 더더욱 안 됩니다. / 문은 조금 기다리면 열리지만 다친 몸은 쉽게 낫지 않습니다.

# 날씨가 나쁘거나 밤이 깊다면
겨울 저녁에 반팔로 나왔다면 오래 문 앞에 서 있지 마세요. / 경비실이나 관리사무소, 가까운 가게처럼 따뜻한 곳에서 기다리셔도 됩니다.
도착하기 전에 전화로 어디 계신지 다시 여쭙겠습니다. / 빌려 쓴 휴대폰 번호를 알려 주시면 그 번호로 연락드립니다.
휴대폰을 돌려드려야 해서 연락이 어렵다면 기다리실 장소를 정확히 정해 두세요. / 경비실 앞, 건물 1층 입구처럼 찾기 쉬운 곳이 좋습니다.

# 은행동에서 연락 주실 때
- 건물 이름과 호수, 아파트인지 빌라인지
- 지금 어디서 기다리고 계신지
- 연락받을 수 있는 번호
- 집 안에 아이, 어르신, 반려동물이 있는지
- 불이나 가스를 켜 둔 채 나왔는지
가스레인지나 다리미를 켜 둔 채 나왔다면 그 사실부터 말씀해 주세요. / 그 경우에는 순서를 앞당기고, 필요하면 관리사무소에 먼저 알리시도록 안내드립니다.

# 신분 확인은 어떻게 하나요
휴대폰도 지갑도 집 안에 있는 상황이 대부분이라 걱정하시는 분이 많습니다. / 아파트라면 관리사무소 세대 확인으로 할 수 있습니다.
빌라라면 집주인 확인이나, 문을 연 직후 집 안 신분증으로 확인하는 방법이 있습니다. / 어느 쪽이든 확인이 끝나기 전에는 집 안으로 들어가지 않습니다.
집 안 신분증으로 확인할 때는 문 앞에서 가져와 보여 주시면 됩니다.

# 비용은 열기 전에
도어락 상태를 보고 얼마인지 먼저 말씀드리고, 괜찮다고 하실 때 시작합니다. / 지갑이 집 안에 있어도 괜찮습니다. 문을 연 뒤 정산하시면 됩니다.
끝내 열지 못하면 비용은 받지 않습니다. / 자세한 순서는 [이용안내](guide.html)에, 문 여는 과정은 [현관문 개문](door-open.html)에 있습니다.

# 문이 열린 다음 해 둘 것
들어가셨다면 도어락 설정부터 한 번 보세요. / 번호 입력이 꺼져 있었다면 켜 두고, 가족 모두가 아는 번호를 정합니다.
자동 잠금이 꼭 필요하지 않은 집이라면 수동 잠금으로 바꿔 쓰는 방법도 있습니다. / 다만 깜빡하고 안 잠그는 일이 생길 수 있으니 생활 습관에 맞춰 정하세요.
번호판이 꺼져서 생긴 일이었다면 건전지를 전부 새것으로 바꿔 두세요. / 경고음이 났는데 미루다 이런 일을 겪는 집이 적지 않습니다. / 바꾼 날짜도 덮개 안쪽에 적어 두세요.
도어락 반응이 늦거나 걸쇠가 덜 들어간다면 [도어락 수리](doorlock-repair.html)로 함께 봅니다.
@ 시흥 은행동 도어락 번호 설정 다시 확인

# 다음에는 이렇게
- 문 밖에 나갈 때는 휴대폰보다 번호를 먼저 기억하기
- 분리수거나 택배 받으러 나갈 땐 문을 받쳐 두기보다 번호를 한 번 떠올리고 나가기
- 신발장 위에 카드나 태그를 두고 나갈 때마다 집어 들고 나가기
- 가까운 가족이나 이웃에게 여분 카드 맡겨 두기
- 출장열쇠 번호 하나 외워 두기
도어락이 오래돼 번호판이 자주 꺼지는 집이라면 이참에 [도어락 교체](doorlock-replace.html)를 고려해 보셔도 좋습니다.

# 은행동 말고 시흥 어디든
정왕동, 배곧동, 대야동, 신천동, 목감동, 장곡동, 능곡동, 월곶동까지 시흥 전 지역에 출동합니다. / 시흥 안내는 [시흥시 출장열쇠](siheung.html), 다른 지역은 [출장 지역](area.html)에 있습니다.
