# 장곡동 원룸 앞에서 막혔다면 먼저 층과 호수부터
장곡동은 아파트 단지와 빌라, 주택가가 이어진 시흥의 주거 동네로, 빌라 안의 원룸이나 작은 오피스텔에 혼자 사는 분들도 적지 않습니다. / 혼자 사는 집은 문이 잠기면 안에서 열어 줄 사람이 없다는 점이 가장 큰 차이입니다.
문 앞에서 당황하면 어디가 막혔는지조차 헷갈립니다. / 건물 1층 출입구인지, 내 방 현관인지, 둘 다인지부터 나눠 보세요.
이 글은 원룸과 오피스텔에서 문이 잠겼을 때 막힌 곳에 따라 달라지는 순서를 정리했습니다. / 연락은 언제든 [시흥 출장열쇠](siheung.html)로 주시면 됩니다.
@ 장곡동 원룸 건물 공동현관 호실 출입문

# 원룸 건물에는 지나야 할 문이 둘 이상입니다
대부분의 원룸 건물은 1층에 공동현관 문이 있고, 계단을 올라 각 호실 현관이 따로 있습니다. / 오피스텔은 여기에 엘리베이터 카드나 층 출입문까지 더해지기도 합니다.
공동현관은 건물 전체가 함께 쓰는 문이라 내 마음대로 손댈 수 없습니다. / 반면 호실 현관은 내가 사는 공간의 문이라 사시는 분 확인만 되면 바로 열 수 있습니다.
어느 문에서 막혔는지에 따라 먼저 연락할 곳이 달라집니다. / 아래에서 두 경우를 따로 보겠습니다.

# 공동현관에서 막혔을 때
공동현관 번호가 갑자기 안 먹힌다면 건물주나 관리인이 번호를 바꿨을 수 있습니다. / 건물 단체 대화방이나 문자에 안내가 왔는지 먼저 확인해 보세요.
같은 건물 사는 이웃이 들어가거나 나올 때 함께 들어가는 것도 방법입니다. / 이때는 이웃에게 몇 호에 사는지 말씀하시고 양해를 구하세요.
공동현관을 지나 내 방 문은 잘 열린다면 그날 밤 일은 거기서 끝납니다.
공동현관 도어락 자체가 꺼져 있거나 고장이라면 건물 전체의 문제입니다. / 관리인에게 먼저 알리고, 관리인이 연락을 주시면 그쪽 요청으로 출동합니다.

# 호실 현관에서 막혔을 때
건물 안까지는 들어왔는데 내 방 문이 안 열린다면 번호판 불빛부터 보세요. / 꺼져 있으면 9V 비상 전원, 켜져 있는데 틀렸다고 나오면 번호나 카드 문제입니다.
원룸 도어락은 입주 때 관리인이 번호를 정해 주고 그대로 쓰는 경우가 많습니다. / 최근에 번호를 바꾼 기억이 없는데 안 된다면 관리인이 점검 중 번호를 바꿨는지도 물어보세요.
열쇠식 손잡이나 보조키가 달린 원룸이라면 열쇠를 두고 나온 것은 아닌지 가방과 주머니를 한 번 더 뒤져 보세요.
@ 장곡동 원룸 호실 도어락 번호판 확인

# 관리인 연락처, 평소 어디에 두시나요
원룸에 살면 관리인이나 건물주 번호가 가장 먼저 필요합니다. / 그런데 그 번호가 휴대폰에만 있고 휴대폰은 방 안에 있는 경우가 흔합니다.
입주하자마자 관리인 번호를 지갑 속 종이나 가족 휴대폰에도 하나 적어 두세요. / 공동현관 안쪽 게시판에 연락처가 붙어 있는 건물도 있으니 지나갈 때 사진으로 남겨 두면 좋습니다.

# 관리실이 있는 오피스텔이라면
오피스텔은 관리실이나 경비실이 있는 건물이 많습니다. / 문이 잠겼다면 관리실에 먼저 들러 세대 확인을 부탁해 두세요.
관리실이 세대 확인을 해 주면 신분증이 방 안에 있어도 진행이 훨씬 수월합니다. / 늦은 밤 관리실이 비어 있다면 그때는 다른 확인 방법을 같이 찾습니다.
건물에 따라 외부 출장 기사가 들어오는 것을 관리실에 미리 알려야 하는 곳도 있습니다. / 연락 주실 때 관리실이 있는 건물인지 말씀해 주시면 도착 전에 그쪽과 통화할 준비를 해 둡니다.

# 계약자 이름과 실제 사는 사람이 다를 때
부모님 이름으로 계약했거나 회사에서 얻어 준 방이라면 계약서 이름과 사는 분 이름이 다릅니다. / 이럴 때는 신분증만으로는 확인이 어려울 수 있습니다.
주소가 나온 택배 상자나 우편물, 관리인과의 통화, 계약자와의 통화 중 하나로 확인합니다. / 미리 알려 주시면 그에 맞게 준비해 갑니다. / 계약자가 멀리 있어도 전화 한 통으로 확인되는 경우가 많으니 걱정하지 않으셔도 됩니다.

# 좁은 복도에서 하지 말 것
원룸 건물 복도는 좁고 소리가 잘 울립니다. / 문을 세게 두드리거나 발로 차면 이웃이 놀라고, 문짝도 상합니다.
문틈에 카드나 쇠자를 넣는 것도 피해 주세요. / 원룸 문은 문틀 사이가 좁아 걸쇠가 더 단단히 물리는 일이 생깁니다.
창문으로 들어가 보려는 생각은 저층이라도 접어 두세요. / 방범창에 걸리거나 떨어져 다치는 일이 문 하나 여는 것보다 훨씬 큰일입니다.

# 연락하실 때 알려 주실 것
- 공동현관인지 호실 문인지, 혹은 둘 다인지
- 건물 주소와 호수, 층수
- 번호판 불빛과 소리
- 관리인이나 관리실과 연락이 됐는지
- 계약자와 사는 분이 같은지
이 다섯 가지만 들으면 출발 전에 필요한 것을 대부분 챙길 수 있습니다.

# 확인과 비용 안내
도착하면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리인이나 관리실 확인 중 하나면 됩니다.
문 상태를 보고 비용을 먼저 말씀드리고 동의하시면 엽니다. / 끝내 열지 못하면 비용은 받지 않으며, 순서는 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 열린 뒤 세입자가 해 둘 일
문이 열리면 새 번호를 정하고 예전 번호가 지워졌는지 확인합니다. / 원룸이라면 번호를 바꾼 사실을 관리인에게 알릴지, 알린다면 언제 알릴지 정해 두세요.
도어락이 고장 난 것이라면 그 사실을 관리인이나 건물주에게 알리고, 수리 내용을 사진으로 남겨 두세요. / 고장 부품은 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 바꿔야 할 상태라면 [도어락 교체](doorlock-replace.html)를 관리인과 상의하시면 됩니다.
@ 장곡동 원룸 도어락 개방 후 새 번호 등록

# 혼자 사는 방이라 미리 해 둘 것
혼자 사는 원룸은 문이 잠기면 안에서 도와줄 사람이 없으니 바깥에 비상 수단을 하나 두는 것이 좋습니다. / 카드키를 쓰는 도어락이라면 여벌 카드 한 장을 지갑에, 열쇠식이라면 여벌 열쇠를 가까운 가족에게 맡겨 두세요.
번호만 쓰는 도어락이라면 번호를 휴대폰에만 적어 두지 마세요. / 휴대폰까지 방 안에 두고 나오는 날이 꼭 한 번은 옵니다.
건전지 경고음은 혼자 사는 집일수록 바로 챙겨야 합니다. / 출근길에 들었다면 퇴근길 편의점에서 새 건전지를 사 들어오는 습관을 들이세요.
야간 근무나 교대 근무를 하는 분이라면 새벽에 돌아와 막히는 일이 없도록 근무 전날 건전지 상태를 한 번 보는 것도 방법입니다.

# 장곡동과 이웃한 시흥 동네
장곡동 가까이 능곡동, 목감동과 정왕동, 배곧동, 은행동, 대야동, 신천동, 월곶동까지 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
