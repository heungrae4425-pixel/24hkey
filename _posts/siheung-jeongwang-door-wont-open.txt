# 정왕동, 집마다 다른 현관 사정
정왕동은 원룸 건물과 다가구 주택, 상가 위 주거층, 아파트 단지가 한 동네에 모두 있는 곳입니다. / 그래서 "문이 안 열려요"라는 같은 말 뒤에 있는 현관문 모양이 집마다 전혀 다릅니다.
원룸에는 작은 번호키나 열쇠식 손잡이가, 아파트에는 밀고 당기는 푸시풀 도어락이 많이 달려 있습니다. / 문 종류가 다르면 안 열리는 원인과 문 앞에서 해볼 수 있는 일도 달라집니다.
이 글은 정왕동에서 자주 보는 현관 형태별로 원인을 나눠 정리했습니다. / 우리 집 문에 해당하는 부분만 골라 읽으시고, 손으로 안 되면 [시흥 출장열쇠](siheung.html)로 연락 주세요.
@ 정왕동 현관문 안 열림 문 종류별 원인

# 문 앞에서 30초만 관찰하기
어떤 문이든 먼저 30초만 가만히 관찰해 보세요. / 번호판에 불이 들어오는지, 누를 때 어떤 소리가 나는지, 손잡이를 잡았을 때 어떤 느낌인지입니다.
이 세 가지를 보고 나면 아래 문 종류 중 어디를 읽어야 할지 정해집니다. / 서두르며 번호를 계속 누르기보다 이 30초가 훨씬 빨리 문을 열게 해 줍니다.
가능하면 번호판과 손잡이 사진을 한 장씩 찍어 두세요. / 나중에 전화로 설명할 때 그대로 보내 주시면 됩니다.

# 원룸 번호키가 아무 반응이 없을 때
작은 번호키는 건전지 칸이 작아 생각보다 빨리 닳습니다. / 불이 전혀 안 들어온다면 거의 대부분 방전입니다.
번호키 아래쪽에 9V 건전지 접점이 있는지 찾아보세요. / 있다면 9V를 대고 있는 동안 번호를 누르면 열리고, 없다면 그대로 연락 주시면 됩니다.
반응은 있는데 계속 틀렸다고 나온다면 건물주나 관리인이 번호를 바꾼 것은 아닌지 물어보세요. / 원룸은 세입자가 바뀔 때 관리 쪽에서 번호를 새로 정하는 경우가 많습니다. / 입주하면서 받은 번호를 그대로 쓰고 있다면 관리인이 점검하러 들어왔다가 번호를 바꾸고 알리지 않았을 수도 있습니다.
작은 번호키는 버튼이 오래 눌려 숫자 하나가 잘 안 먹히는 일도 있습니다. / 특정 숫자를 누를 때만 소리가 안 난다면 그 버튼 쪽 고장입니다.

# 열쇠식 손잡이가 안 돌 때
오래된 원룸이나 다가구 주택은 열쇠로 여는 손잡이가 달린 곳이 아직 있습니다. / 열쇠가 끝까지 들어가는데 안 돈다면 실린더 안쪽 핀이 닳았거나 이물질이 끼었을 수 있습니다.
문을 몸 쪽으로 살짝 당기며 다시 돌려 보세요. / 문짝이 문틀에 눌려 걸쇠가 꽉 물린 경우라면 이것만으로 풀리기도 합니다.
그래도 안 돌면 억지로 비틀지 마세요. / 열쇠가 부러져 구멍 안에 남으면 일이 하나 더 생깁니다.
복사 열쇠라면 원래 열쇠보다 홈이 조금 어긋나 있어 실린더가 닳을수록 더 안 맞게 됩니다. / 원래 열쇠를 가진 관리인이나 가족이 있다면 그 열쇠로 한 번 시도해 보세요.

# 아파트 푸시풀 도어락이 당겨지지 않을 때
푸시풀은 번호를 누른 뒤 손잡이를 밀거나 당겨야 열리는 방식입니다. / 번호가 맞았다는 소리가 났는데 손잡이가 안 움직인다면 손잡이 안쪽 연결 부품이 헐거워졌을 수 있습니다.
번호를 누른 직후 몇 초 안에 손잡이를 움직여야 하는 제품도 있습니다. / 조금 천천히 했다가 다시 잠긴 것은 아닌지 한 번 더 해 보세요.
모터 소리가 길게 끌리다 멈춘다면 막대가 문틀에 걸려 있는 경우입니다. / 문을 살짝 밀면서 다시 번호를 눌러 보시면 됩니다.
@ 정왕동 아파트 푸시풀 도어락 손잡이 안 당겨짐

# 문짝이 내려앉아 보일 때
문과 문틀 사이 틈을 위에서 아래까지 눈으로 훑어보세요. / 위쪽 틈은 넓고 아래쪽 틈은 좁다면 문이 경첩 쪽에서 처진 것입니다.
문이 처지면 걸쇠와 막대가 문틀 구멍과 어긋나 도어락이 풀려도 문이 버팁니다. / 문 위쪽 모서리를 손바닥으로 누르며 손잡이를 당기면 열리기도 합니다.
열렸다면 그냥 넘어가지 말고 경첩 점검을 받아 두세요. / 처짐은 시간이 갈수록 심해집니다.
바닥 쪽에 문이 긁힌 자국이 반달 모양으로 남아 있다면 처짐이 꽤 진행된 상태입니다. / 이런 문은 도어락만 바꿔서는 해결되지 않으니 경첩부터 바로잡아야 합니다.

# 집 안 걸쇠가 걸린 듯할 때
도어락은 풀렸는데 문이 한 뼘 열리다 멈춘다면 안쪽 걸쇠입니다. / 같이 사는 사람이 안에서 걸었거나, 나가면서 다른 출입구를 쓴 경우입니다.
안에 사람이 있다면 풀어 달라고 하면 되고, 아무도 없다면 문틈에 손이나 도구를 넣지 마세요. / 걸쇠 고정부가 빠지거나 문틀이 패여 나중에 손볼 곳이 늘어납니다.

# 카드키나 태그가 먹히지 않을 때
카드를 대도 반응이 없다면 카드를 번호판 가운데에 천천히 대 보세요. / 지갑 속 다른 카드와 겹쳐 대면 인식이 안 되는 경우가 많습니다.
번호는 되는데 카드만 안 된다면 카드 등록이 지워졌거나 카드가 휘었을 수 있습니다. / 이때는 번호로 열고 들어가서 카드를 다시 등록하면 됩니다. / 카드만 쓰고 번호를 모르는 집이라면 그때는 연락 주셔야 합니다.
휴대폰 케이스에 카드를 넣어 쓰는 분은 케이스를 빼고 카드만 따로 대 보세요.

# 손대지 않는 게 좋은 순간
아래 상황이라면 문 앞에서 더 시도하지 말고 연락 주세요.
- 번호판이 꺼졌는데 9V 접점이 없거나 대도 조용할 때
- 열쇠가 반쯤만 돌고 더 안 돌 때
- 모터 소리가 반복되고 손잡이가 헛돌 때
- 문이 한 뼘 열린 채 걸쇠에 걸렸을 때

# 정왕동 위치는 이렇게 알려 주세요
정왕동은 비슷한 원룸 건물이 많아 건물 이름보다 도로명 주소와 호수가 정확합니다. / 정왕역이나 오이도역 기준 방향, 1층에 있는 가게 업종 정도를 함께 말씀해 주시면 찾기 쉽습니다.
공동현관이 있는 건물이라면 번호를 알려 주시거나 내려와 계셔 주시면 됩니다. / 밤늦은 시간이라면 건물 입구 불빛 아래에서 기다려 주세요.

# 사시는 분 확인, 그다음 비용 안내
문을 열기 전 신분증 주소, 주소가 나온 우편물, 관리인 확인 중 하나로 사시는 분인지 봅니다. / 상태를 보고 비용을 먼저 말씀드리고 동의하시면 시작합니다.
끝내 열지 못하면 비용은 받지 않습니다. / 순서는 [이용안내](guide.html), 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 원인에 맞춘 마무리 작업
건전지라면 교체, 번호라면 새 번호 등록, 처짐이라면 경첩과 받이 조정으로 마칩니다. / 손잡이 연결부나 실린더가 닳았다면 [도어락 수리](doorlock-repair.html)로 해당 부분만 손봅니다.
원룸 세입자라면 고장 내용을 관리인에게 알리고, 교체가 필요하면 관리인과 상의해 [도어락 교체](doorlock-replace.html)를 정하시면 됩니다.
@ 정왕동 원룸 현관 경첩 조정 도어락 수리

# 정왕동 말고 시흥 전역
정왕동 가까이 배곧동, 월곶동과 장곡동, 능곡동, 목감동, 은행동, 대야동, 신천동까지 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문
? 원룸 번호키에 9V 접점이 안 보여요. | 접점이 없는 제품도 있어 그대로 연락 주시면 됩니다.
? 푸시풀 손잡이가 헛도는 느낌이에요. | 손잡이 연결 부품 문제일 수 있어 무리하게 당기지 말고 연락 주세요.
? 문 위아래 틈이 달라 보여요. | 문 처짐일 가능성이 높아 경첩 점검을 권합니다.
? 공동현관 번호를 모르는데 와 주시나요? | 내려와 계시거나 관리인과 연락이 되면 진행할 수 있습니다.
? 이것저것 해 보셨는데도 안 열리면 비용은요? | 열지 못하면 비용은 받지 않습니다.

# 마무리
