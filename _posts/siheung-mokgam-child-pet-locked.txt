# 목감동에서 아이가 집 안에 혼자 있는데 문이 안 열릴 때
목감동은 새 아파트 단지가 들어서면서 어린 자녀를 둔 가족이 많이 사는 동네입니다. / 아이가 안쪽에서 문을 잠가 버리거나 밖에서 문이 닫히는 일이 생기면 부모님은 크게 놀라십니다.
이런 상황에서 가장 중요한 것은 서두르지 않고 순서를 지키는 것입니다. / 이 글은 아이나 반려동물이 집 안에 있을 때 문이 잠겼을 때의 대처법을 정리했습니다.
[시흥 출장열쇠](siheung.html)에 연락하실 때 꼭 알려 주셔야 하는 정보도 함께 적었습니다.
@ 목감동 출장열쇠 아이 반려동물 문 잠김

# 가장 먼저 해야 할 일은 아이를 안심시키는 것
문 너머로 아이에게 침착한 목소리로 계속 말을 걸어 주세요. / 아이가 울고 있어도 부모가 곁에 있다는 것을 알려 주는 것이 가장 중요합니다.
아이에게 문을 열려고 만지거나 무엇을 하도록 시키지 마세요. / 손잡이나 도어락을 자꾸 만지면 오히려 상황이 악화될 수 있습니다.
아이가 걸을 수 있는 나이라면 문에서 떨어진 안전한 곳에 있도록 부드럽게 안내해 주세요. / 큰 목소리로 재촉하거나 혼내는 것은 피하세요.

# 불이 켜져 있거나 위험 물건이 있을 때
집 안에 가스 불을 켜 둔 상태이거나 위험한 물건이 있는 상황이라면 바로 119에 연락하세요. / 열쇠집보다 119가 먼저 대응해야 하는 경우입니다.
안전이 급하지 않은 일반적인 잠김이라면 열쇠집을 바로 부르셔도 됩니다. / 판단이 어려울 때는 일단 119에 상황을 설명하고 안내를 받으세요.
열쇠집에 연락할 때도 집 안 위험 요소가 있다면 꼭 먼저 말씀해 주세요. / 급한 순서가 달라집니다.
@ 목감동 도어락 아이 안전 개문

# 반려동물이 집 안에 있는 경우
반려동물은 문 앞에서 짖거나 긁어서 문이 더 상할 수 있습니다. / 불안해하는 동물을 문 너머에서 목소리로 달래 주세요.
무더운 여름이나 한겨울에는 집 안 온도가 반려동물에게 위험할 수 있어서 서둘러야 합니다. / 이런 때는 시간 여유가 없다고 꼭 말씀해 주세요.
문을 열 때 반려동물이 놀라서 뛰쳐나가지 않도록 문 앞에서 지켜봐 주세요. / 열리는 순간 갑자기 나가려 하는 동물이 많습니다.
고양이는 특히 문틈이 벌어지는 순간 계단이나 복도로 빠져나가기 쉬우니 가슴높이에서 막아 주세요.

# 안쪽에서 아이가 보조키를 잠갔을 때
어린아이가 호기심에 안쪽 보조키를 돌려 잠가 버리는 일이 가장 흔합니다. / 아이는 문을 다시 열 줄 몰라서 당황하고 부모는 밖에서 열 수 없게 됩니다.
도어락 번호가 맞는데 문이 안 열리면 안쪽 보조키가 잠긴 것일 가능성이 큽니다. / 이 경우는 번호를 알아도 밖에서 열 수 없습니다.
아이가 보조키를 돌릴 수 있는 나이라면 반대로 돌려 열도록 문 너머로 천천히 알려 줄 수도 있습니다. / 쉽지 않으면 무리하지 말고 열쇠집을 부르세요.

# 전화하실 때 꼭 알려 주실 것
- 집 안에 아이가 몇 살인지, 혼자 있는지
- 반려동물이 있는지, 종류와 상태
- 가스 불이나 전열기가 켜져 있는지
- 문이 안쪽에서 잠겼는지 밖에서 닫혔는지
- 번호판과 소리 상태
이 정보를 먼저 말씀해 주시면 도착 우선순위를 정할 수 있습니다. / 목감동 주소와 동, 호수는 지도 앱 주소로 문자를 보내 주시면 가장 빠릅니다.

# 이런 행동은 피해 주세요
창문이나 베란다로 들어가려고 하는 것은 매우 위험합니다. / 특히 높은 층에서는 절대 시도하지 마세요.
문을 힘으로 열려고 하면 아이가 놀라고 문도 상합니다. / 문틀이 틀어지면 문을 바꿔야 할 수도 있습니다.
아이가 안쪽에서 문을 두드릴 때 달래지 않고 계속 문을 흔들면 아이가 겁을 먹습니다. / 침착하게 대화하며 기다려 주세요.
아이의 이름을 부르며 곧 열어 준다고 말해 주시고, 가능하면 좋아하는 노래나 이야기를 문 너머로 들려 주세요. / 아이가 긴장을 풀면 구조 자체도 훨씬 수월해집니다.
부모님이 당황한 목소리를 내면 아이도 따라서 불안해집니다. / 숨을 한 번 크게 쉬고 천천히 말씀해 주세요.

# 도착하면 이렇게 진행합니다
도착하면 먼저 집 안 아이 상태를 확인합니다. / 아이가 놀라지 않게 목소리를 낮추고 작업 소리가 크지 않은 방법부터 시도합니다.
도어락이나 보조키를 최대한 상하지 않게 여는 것이 먼저입니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 말씀드립니다.
자세한 방법은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 이 집에 사시는 분인지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 아이가 있는 집일수록 꼭 필요한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 방법을 생각해 두세요.
@ 시흥 목감동 출장 개문 작업

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고 끝내 못 열면 비용은 받지 않습니다.
아이가 안에 있는 급한 상황에서도 열기 전에 비용은 말씀드립니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문이 열린 뒤 안전 점검
문이 열리면 아이나 반려동물이 괜찮은지 먼저 확인하세요. / 놀란 아이는 안아 주고 잠시 쉬게 해 주시는 것이 좋습니다.
도어락이 정상인지도 같이 점검합니다. / 아이가 만지기 쉬운 높이의 보조키는 잠금 방지 장치를 달 수 있는지 안내해 드립니다.
아이가 도어락 번호판을 장난으로 눌러 입력이 막힌 경우에도 같이 점검합니다. / 아이가 자주 만지는 집이라면 번호판 위치와 잠금 설정을 한번 정리해 두시면 좋습니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 필요하면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 아이가 있는 집에서 미리 해 두면 좋은 것
- 안쪽 보조키는 아이 손이 닿지 않는 높이에 달거나 잠금 방지 장치 사용
- 도어락의 자동 잠금 기능과 문이 닫히는 방식 확인
- 아이에게 문이 안 열릴 때 소리 내어 부르는 법 알려 주기
- 부모 휴대폰 번호를 아이가 외우게 하기
- 이웃에게 비상 연락처 알려 두기
이런 준비를 해 두면 막상 문이 잠겼을 때 훨씬 침착하게 대응할 수 있습니다.
아이가 어느 정도 크면 문이 안 열릴 때 119나 부모님께 전화하는 연습을 한 번씩 해 보는 것도 좋습니다. / 놀이처럼 해 두면 실제 상황에서도 당황하지 않고 움직입니다.

# 목감동 말고 시흥 어디든 갑니다
목감동 옆 장곡동, 능곡동, 월곶동, 정왕동, 배곧동, 은행동, 대야동, 신천동까지 다닙니다. / 시흥 안이면 동네 상관없이 24시간 출동합니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
