# 능곡동 현관, 맞는 번호인데 안 열린다면
능곡동은 아파트와 주택이 함께 있는 동네로, 시흥시청역 쪽에서 버스나 차로 들어오는 분이 많습니다. / 늘 누르던 번호를 눌렀는데 짧은 경고음과 함께 문이 꿈쩍하지 않으면 잠깐 내가 틀렸나 싶어집니다.
두세 번 더 눌러도 안 되면 그때부터 머릿속이 복잡해집니다. / 내가 번호를 잊은 건지, 누가 번호를 바꾼 건지, 도어락이 고장 난 건지 알 수가 없습니다.
이 글은 능곡동에서 비밀번호 때문에 문이 안 열릴 때 원인을 좁혀 가는 순서와, [시흥 출장열쇠](siheung.html)를 부를 때를 정리했습니다.
@ 능곡동 도어락 비밀번호 분실 현관문

# 정말 번호가 바뀐 걸까
번호 문제인지 확인하려면 번호판 반응부터 보세요. / 번호판이 잘 켜지고, 누를 때마다 버튼 소리가 나고, 마지막에 짧은 경고음이 난다면 번호가 맞지 않은 것입니다.
번호판이 흐릿하거나 버튼 소리가 늘어진다면 번호보다 건전지 쪽을 먼저 의심해야 합니다. / 맞는 번호를 눌렀는데 모터 소리만 나고 안 열린다면 번호는 맞은 것이고 걸쇠 쪽 문제입니다.
이 세 가지 가운데 어디에 해당하는지만 알아도 다음에 할 일이 정해집니다. / 전화로 연락 주실 때도 이 구분을 말씀해 주시면 무엇을 챙겨 갈지 바로 정할 수 있습니다.

# 손이 기억하는 번호와 머리가 기억하는 번호
매일 누르는 번호는 머리보다 손이 기억합니다. / 그래서 막상 번호를 떠올리려고 하면 헷갈리고, 생각 없이 누르면 오히려 맞는 경우가 있습니다.
잠깐 숨을 고르고, 평소처럼 자연스럽게 한 번 눌러 보세요. / 그래도 안 되면 이전에 쓰던 번호, 다른 집이나 회사에서 쓰는 번호와 헷갈리지 않았는지 떠올려 보세요.
번호 끝에 누르는 확인 버튼이 별표인지 우물 정자인지도 제품마다 다릅니다. / 최근에 도어락을 바꿨다면 이 부분에서 실수하기 쉽습니다.

# 최근에 번호를 바꿀 만한 일이 있었나
가족이 번호를 바꾸는 데에는 대개 이유가 있습니다. / 아래 같은 일이 최근에 있었는지 떠올려 보세요.
- 집을 고치러 기사님이 드나들었다
- 손님이나 친척이 며칠 머물다 갔다
- 이웃에게 번호를 잠깐 알려준 적이 있다
- 가족 중 누가 번호가 노출된 것 같다고 말했다
이런 일 뒤에 번호를 바꾸는 것은 좋은 습관입니다. / 세를 사는 집이라면 수리 뒤 집주인과 번호 이야기가 오갔는지도 떠올려 보세요. / 다만 바꾼 사람이 다른 가족에게 알리는 것을 깜빡하는 경우가 많습니다.

# 가족에게 물어볼 때 이렇게
가족에게 전화할 때는 "번호 바꿨어?"보다 "지금 번호가 뭐야?"라고 물어보세요. / 바꾼 기억이 없다는 대답이 나와도 실제로 바꿨을 수 있습니다.
가족이 번호를 알려줄 때는 문자로 받아 그대로 보며 누르는 것이 정확합니다. / 통화하면서 누르면 숫자를 잘못 듣기 쉽습니다.
번호를 받고 나서는 그 문자를 지워 두세요. / 휴대폰을 잃어버리면 번호까지 같이 잃는 셈입니다.
@ 능곡동 가족에게 도어락 번호 확인 문자

# 입력이 막혔다면 기다리기
번호를 여러 번 틀리면 대부분의 도어락은 일정 시간 동안 입력을 받지 않습니다. / 이때 계속 누르면 막히는 시간이 늘어나는 제품도 있습니다.
경고음이 길게 나거나 번호판이 반응하지 않는다면 몇 분 기다렸다가 천천히 다시 눌러 보세요. / 그 사이에 가족에게 연락하는 것이 시간을 아끼는 방법입니다.

# 카드·지문·비상 열쇠 다른 길
번호 말고도 문을 여는 방법이 있는지 떠올려 보세요. / 카드나 태그를 등록해 둔 집이라면 지갑이나 차 열쇠고리에 있지 않은지 찾아보세요.
지문을 등록해 두었다면 손을 닦고 대 보세요. / 비상 열쇠 구멍이 있는 도어락이라면 그 열쇠를 가족 누가 가지고 있는지도 물어보세요. / 휴대폰 앱과 연결된 도어락이라면 가족 휴대폰에서 원격으로 열어 줄 수 있는지도 확인해 볼 만합니다.

# 아무에게도 연락이 안 될 때
가족이 일하는 중이라 전화를 못 받거나, 혼자 사시는 집이라 물어볼 사람이 없을 수 있습니다. / 이럴 때는 무리해서 번호를 맞추려 하지 말고 연락 주세요.
아파트라면 관리사무소나 경비실에 먼저 말해 두시면 거주 확인이 빨라집니다. / 날씨가 쌀쌀하니 기다리는 동안은 공동현관 안쪽이나 따뜻한 곳에 계세요.

# 번호를 찍어 맞추지 마세요
생일, 전화번호, 예전 번호를 이것저것 넣어 보는 분이 많습니다. / 몇 번은 괜찮지만 계속하면 입력이 오래 막히고, 그사이 문 앞에서 시간만 흐릅니다.
드라이버로 번호판을 떼거나 문틈을 벌리는 것도 피해 주세요. / 도어락과 문틀이 상하면 문을 연 뒤에 고칠 일이 더 늘어납니다.

# 연락과 도착 후 확인
- 번호판 반응과 경고음 모양
- 가족과 연락이 됐는지, 번호가 바뀌었을 가능성
- 카드나 지문 같은 다른 수단이 있는지
- 능곡동 아파트 동·호수 또는 주택 위치
도착하면 사시는 분인지 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나로 확인합니다. / 도어락 상태를 보고 비용을 먼저 말씀드린 뒤 동의하시면 시작하고, 끝내 못 열면 비용은 받지 않습니다.
진행 순서는 [이용안내](guide.html), 문 여는 방식은 [현관문 개문](door-open.html)에 정리했습니다.

# 문을 연 뒤 번호를 다시 정하는 법
문이 열리면 안쪽에서 새 번호를 등록합니다. / 기존 번호를 지우고 가족 모두가 알 수 있는 새 번호로 바꾸는 것까지 함께 해 드립니다.
등록 방법은 제품마다 달라서 설명서가 없으면 헤매기 쉽습니다. / 이 자리에서 가족과 통화하며 번호를 같이 정하시면 다음에 같은 일이 생기지 않습니다.
번호 등록 버튼이 잘 안 눌리거나 등록이 저장되지 않는다면 [도어락 수리](doorlock-repair.html)로 점검하고, 오래된 제품이라면 [도어락 교체](doorlock-replace.html)를 함께 상담할 수 있습니다.

# 가족이 번호를 바꿀 때 지킬 약속
- 바꾸는 사람이 그날 바로 가족 모두에게 알리기
- 바꾼 뒤 한 사람에게라도 확인 답장을 받기
- 번호는 문자로 보내되, 확인 후 지우기
- 아이에게는 직접 만나서 알려주기
작은 약속 하나로 가족이 문 앞에서 기다리는 일을 막을 수 있습니다. / 가족 단체 대화방이 있다면 번호 자체보다 "번호 바꿨어요, 따로 연락할게요"처럼 바꾼 사실만 올리고 번호는 각자에게 따로 보내는 편이 안전합니다.
@ 능곡동 가족 도어락 번호 공유 약속
