# 능곡동에서 문이 제대로 닫히지 않는다면
능곡동은 새로 지은 아파트와 연식이 있는 주택이 함께 있는 동네라 문 상태도 집마다 다릅니다. / 현관문을 닫았는데 덜컥 하고 튕겨 나오거나 도어락이 잠기는 소리가 나지 않는 일이 생기면 외출이 불안해집니다.
문이 닫히지 않는 문제는 도어락 자체보다 문틀, 경첩, 걸쇠, 문 처짐이 원인인 경우도 많습니다. / 이 글은 능곡동에서 문이 안 닫히거나 잠기지 않을 때 직접 확인할 것을 정리했습니다.
[시흥 출장열쇠](siheung.html)가 와서 점검하는 순서도 같이 적었습니다.
@ 능곡동 출장열쇠 현관문 안 닫힘

# 먼저 문이 어디에 닿는지 보세요
문을 천천히 닫으면서 문틀 어디에서 걸리는지 눈으로 확인하세요. / 위쪽이 걸리면 문이 아래로 처진 것이고, 아래쪽이 걸리면 바닥 쪽 문제일 수 있습니다.
걸쇠가 튀어나오는 부분이 문틀 구멍에 정확히 맞는지도 보세요. / 문틀 구멍과 걸쇠가 어긋나면 문은 닫혀도 잠기지 않습니다.
문을 닫은 채로 손잡이를 위아래로 살짝 눌러 보았을 때 걸쇠가 움직이는 느낌이 있으면 높이가 맞지 않는다는 뜻입니다. / 이 느낌을 전화로 알려 주시면 도움이 됩니다.
문틀 구멍 주변에 칠이 벗겨졌거나 눌린 자국이 있다면 오랫동안 어긋난 상태로 쓰고 있었다는 뜻입니다.
이런 흔적이 보이면 갑자기 생긴 문제가 아니라 서서히 진행된 것이니 조정만으로 해결되는 경우가 많습니다. / 사진으로 찍어 두면 상담할 때 도움이 됩니다.

# 문 처짐이 원인인 경우
오래 쓴 문은 무게 때문에 경첩 쪽이 점점 내려앉습니다. / 문이 아래로 처지면 걸쇠 높이가 달라져 문틀 구멍에 걸리지 않습니다.
경첩 나사가 헐거워진 경우에는 나사를 조여 주는 것만으로 나아지기도 합니다. / 다만 구멍이 헐렁하게 벌어졌다면 단순히 조여서는 해결되지 않습니다.
경첩이 문 위, 중간, 아래에 보통 세 곳 달려 있는데 위쪽 경첩이 가장 먼저 헐거워지는 경우가 많습니다. / 위쪽부터 확인해 보세요.
비가 많이 온 뒤나 습한 계절에는 문이 부풀어 문틀에 낄 수도 있습니다. / 이럴 때는 날씨가 마르면 저절로 돌아오기도 합니다.
@ 능곡동 현관문 걸쇠 점검

# 걸쇠와 문틀 구멍이 문제일 때
걸쇠가 눌려서 제대로 튀어나오지 않거나 잘 들어가지 않는 경우가 있습니다. / 손으로 걸쇠를 눌러 보고 부드럽게 들어갔다 나오는지 확인하세요.
먼지나 오래된 윤활유가 굳어 걸쇠가 뻑뻑해지는 경우도 흔합니다. / 이럴 때는 접점 세정제를 소량 뿌려 주면 나아지는 경우가 있지만, 잘 모르시면 손대지 마세요.
문틀 쪽 걸쇠받이(스트라이크)가 틀어져 있는 경우에는 위치를 조정해야 합니다.

# 도어락 자체에서 잠기지 않는 경우
문은 닫히는데 도어락이 잠기는 소리가 나지 않으면 내부 모터나 센서가 문제일 수 있습니다. / 번호판은 켜지는데 잠금이 안 되는 경우가 대표적입니다.
자동 잠금 기능이 꺼져 있거나 설정이 바뀐 경우도 있습니다. / 건전지를 교체하는 과정에서 설정이 초기화되기도 합니다.
도어락이 반쯤 잠기다 멈추는 증상은 걸쇠가 문틀에 눌려 있는 것과 구분해야 합니다. / 사진이나 동영상으로 증상을 보여 주시면 훨씬 빠르게 원인을 찾습니다.

# 이렇게 하면 문이 더 상합니다
문을 세게 닫으면 해결될 것 같아서 쾅 닫는 분이 많습니다. / 걸쇠와 문틀이 더 눌려서 상태가 나빠지고 소음이 이웃에게 갈 수 있습니다.
문틀을 칼이나 사포로 깎아 맞추려는 시도도 하지 마세요. / 깎은 부분은 되돌릴 수 없고 틈이 생겨 단열과 방음이 떨어집니다.
경첩 나사를 너무 세게 조이다 나사 머리가 망가지는 경우도 있습니다.

# 전화하실 때 알려 주실 것
능곡동은 단지와 주택이 섞여 있어 주소와 동, 호수를 정확히 알려 주세요. / 지도 앱의 위치를 문자로 보내 주시면 가장 빠릅니다.
- 문이 어느 쪽에서 걸리는지
- 걸쇠가 튀어나오는지 들어가는지
- 도어락 번호판이 켜지는지
- 최근에 이사나 인테리어를 했는지
- 문을 닫았을 때 어떤 소리가 나는지
문이 안 닫힌 채로 외출해야 하는 상황이라면 빈 집이 걱정되므로 먼저 말씀해 주세요. / 급한 순서로 정해 출동하겠습니다.

# 도착하면 이렇게 진행합니다
먼저 문이 닫히는 모양을 눈으로 보고 걸리는 부분을 찾습니다. / 경첩, 걸쇠, 문틀 구멍, 도어락 순서로 점검해 원인을 좁힙니다.
조정만으로 해결되면 그대로 마무리하고, 부품을 바꿔야 하면 손대기 전에 여쭤봅니다. / 문이 완전히 닫히고 잠기는지 몇 번 여닫아서 같이 확인합니다.
자세한 방법은 [도어락 수리](doorlock-repair.html) 페이지에 정리해 두었습니다.

# 사시는 분인지 먼저 확인합니다
문과 도어락 관련 작업이라 사시는 집인지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.
@ 시흥 능곡동 출장 점검 문 조정

# 비용은 시작 전에 말씀드립니다
점검 후 원인과 작업 내용을 설명하고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고 말없이 붙는 비용은 없습니다.
부품을 더 바꿔야 하면 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 임시로 문을 잠가 두고 싶을 때
고장 수리가 바로 안 되는 시간에 외출해야 한다면 보조키만이라도 잠가 두세요. / 보조키가 없으면 문 안쪽 걸쇠나 체인을 이용해 닫아 둘 수 있습니다.
집을 비우지 못한다면 가족 중 한 명이 남아 있는 것이 가장 안전합니다. / 문이 열려 있는 채로 오래 두는 것은 권하지 않습니다.
출장 시간이 길어지는 야간이라면 현관에 테이프로 임시 고정하는 방법도 쓰지만, 이는 응급일 뿐입니다.

# 같은 문제가 반복되지 않으려면
- 문을 세게 닫지 않고 손으로 잡고 부드럽게 닫기
- 일 년에 한 번 경첩 나사 조여 주기
- 걸쇠와 문틀 구멍에 이물질이나 낙서가 쌓이지 않게 하기
- 도어락 자동 잠금 설정을 한 번씩 확인하기
- 문 아래쪽이 바닥에 끌리면 바로 점검받기
작은 증상일 때 손보면 비용도 시간도 훨씬 적게 듭니다. / 방치하면 문틀까지 틀어져 문을 새로 맞춰야 할 수도 있습니다.

# 교체까지 가야 하는 경우
도어락 내부 모터가 약해졌거나 걸쇠가 닳아 더 이상 제대로 작동하지 않는 경우가 있습니다. / 이럴 때는 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 상태를 보고 정직하게 설명해 드립니다.

# 능곡동 말고 시흥 어디든 갑니다
능곡동 옆 장곡동, 월곶동, 목감동, 정왕동, 배곧동, 은행동, 대야동, 신천동까지 다닙니다. / 시흥 안이면 동네 상관없이 24시간 출동합니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
