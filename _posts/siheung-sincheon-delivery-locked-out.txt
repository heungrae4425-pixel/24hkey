# 신천동에서 잠깐 나갔다가 문이 닫혔다면
신천동은 아파트와 빌라, 상가 주택이 섞여 있어 집집마다 현관 구조가 다릅니다. / 택배를 받으러 현관 밖으로 나온 사이에 문이 닫혀 버리는 일이 의외로 자주 생깁니다.
휴대폰도 열쇠도 집 안에 있고 슬리퍼 차림이면 막막함이 몇 배가 됩니다. / 이 글은 신천동에서 잠깐 나갔다가 문이 잠겼을 때 순서대로 해볼 것을 정리했습니다.
[시흥 출장열쇠](siheung.html)가 도착해서 하는 일도 함께 적었습니다.
@ 신천동 출장열쇠 택배 문 잠김

# 먼저 침착하게 확인할 것
문이 완전히 닫혔는지, 도어락이 자동으로 잠기는 방식인지 확인하세요. / 일부 도어락은 문이 닫히면 몇 초 뒤에 자동으로 잠깁니다.
번호를 알고 있다면 번호를 눌러서 열어 보세요. / 열쇠가 없어도 번호식이면 그냥 열리는 경우가 대부분입니다.
번호식이 아니라 열쇠식 자물쇠이거나 번호를 모르면 다른 방법이 필요합니다.
복도식 아파트라면 옆집 문 앞에서 소란을 피우기보다 관리사무소를 먼저 찾아가는 편이 낫습니다. / 늦은 밤이라면 이웃이 놀라지 않도록 초인종을 길게 누르지 말고 짧게 한 번만 눌러 주세요.
문이 닫힌 지 얼마 안 됐다면 도어락이 아직 완전히 잠기지 않은 경우도 있습니다. / 손잡이를 천천히 돌려 보고 안 되면 더 시도하지 마세요.
집 안에 가족이 있다면 문을 두드리거나 전화를 걸어 보세요.

# 휴대폰이 집 안에 있을 때
이웃에게 전화를 빌려서 가족이나 열쇠집에 연락할 수 있습니다. / 이웃에게 부탁하기가 어렵다면 경비실이나 관리사무소를 이용하는 방법도 있습니다.
근처 편의점이나 상가에서 전화를 빌리는 분도 많습니다. / 열쇠집 번호를 알고 있으면 바로 연락하면 됩니다.
혹시 몰라 열쇠집 번호는 지갑이나 외투 주머니에 종이로 하나 넣어 두면 이런 때 도움이 됩니다.
번호를 외워 두는 것이 가장 좋고, 가족 휴대폰 번호도 하나쯤은 외워 두세요.
@ 신천동 도어락 문 잠김 출장

# 아파트와 빌라는 확인할 것이 다릅니다
아파트는 관리사무소에 세대 확인을 부탁해서 도움을 받을 수 있는 경우가 많습니다. / 경비실이 있는 단지라면 경비실에 먼저 상황을 말씀해 두면 수월합니다.
빌라나 다가구 주택은 집주인이나 관리하는 분에게 여분 열쇠가 있는지 확인해 보세요. / 연락이 닿지 않으면 그때 열쇠집을 부르시면 됩니다.
공동현관이 따로 있는 건물은 공동현관에서 먼저 막힌 건 아닌지도 구분해 주세요.
공동현관 비밀번호는 알지만 세대 문만 잠긴 경우와 공동현관부터 못 들어가는 경우는 대처가 다릅니다. / 어디서 막혔는지 전화로 말씀해 주시면 출동 준비가 빨라집니다.
택배 기사님이나 이웃이 공동현관을 열어 줄 때는 그 틈에 들어가 계시면 됩니다. / 다만 모르는 사람의 출입은 서로 조심해야 하니 지켜보는 분이 있는지 확인하세요.

# 이런 행동은 피해 주세요
문틈에 카드나 얇은 철사를 넣어 보려는 분들이 있습니다. / 문과 문틀이 상하고 걸쇠가 더 꽉 물릴 수 있습니다.
창문으로 들어가려고 베란다 쪽으로 올라가는 것은 매우 위험합니다. / 특히 높은 층이면 절대 하지 마세요.
문을 발로 차거나 어깨로 미는 것도 문틀이 틀어져 큰 비용이 듭니다. / 안전하게 기다리시는 편이 훨씬 낫습니다.

# 전화하실 때 알려 주실 것
신천동은 건물이 비슷한 곳이 많아 주소와 동, 호수를 정확히 알려 주세요. / 지도 앱 주소 문자 전송이 가장 빠릅니다.
- 현관 도어락 종류(번호식, 열쇠식, 카드식)
- 문이 자동으로 잠기는 방식인지
- 보조키가 같이 잠겼는지
- 지금 어디에서 연락하고 계신지
- 집 안에 아이나 반려동물이 있는지
집 안에 아이가 혼자 있거나 불을 켜 둔 상황이면 꼭 먼저 말씀해 주세요. / 급한 순서를 정하는 데 중요한 정보입니다.

# 도착하면 이렇게 진행합니다
먼저 문 상태와 잠금장치 종류를 살핍니다. / 가장 덜 상하는 방법부터 차례로 시도합니다.
열기 전에 비용을 말씀드리고 허락하시면 시작합니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 말씀드립니다.
자세한 방법은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 문을 연 뒤에는 도어락이 잘 잠기고 열리는지도 함께 확인합니다.
닫힌 문이 계속 같은 증상으로 잠긴다면 도어락 자동 잠금 설정이나 문 처짐이 원인일 수 있어 같이 봅니다. / 원인을 잡아 두면 다음에 같은 일이 생기지 않습니다.

# 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 집인지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
슬리퍼 차림으로 나오셔서 신분증이 집 안에 있다면 관리사무소나 가족, 집주인을 통한 확인을 함께 찾아봅니다. / 확인이 어려우면 작업을 할 수 없으니 미리 방법을 생각해 두세요.

# 비용은 열기 전에 말씀드립니다
문과 도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고 끝내 못 열면 비용은 받지 않습니다.
부품을 바꿔야 하면 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 시흥 신천동 출장 개문 작업

# 같은 일이 또 생기지 않으려면
- 문을 완전히 닫기 전에 열쇠나 카드를 꼭 가지고 있는지 확인하기
- 택배를 받으러 나갈 때 문틈에 슬리퍼나 신문지를 끼워 두기
- 현관 도어락에 지문이나 카드 방식 추가하기
- 믿을 수 있는 이웃이나 가족에게 비상 열쇠 맡기기
- 휴대폰은 항상 손에 들고 나가기
습관 하나만 바꿔도 잠깐 나갔다 갇히는 일이 크게 줄어듭니다. / 자동으로 잠기는 도어락은 자동 잠금 시간을 늘리는 설정도 가능합니다.
분리수거나 쓰레기를 버리러 나갈 때도 똑같은 일이 생기니 현관 앞에 잠깐 서 있을 때도 열쇠를 챙기는 습관을 들이세요. / 현관 옆에 작은 고리를 달아 열쇠를 항상 같은 자리에 걸어 두는 분도 많습니다.

# 문이 열린 뒤 도어락 확인
문이 열리면 도어락이 정상인지 확인합니다. / 번호가 맞는데 안 열리는 문제라면 배터리나 모터 문제일 수 있어 같이 점검합니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 자주 문제가 생기면 [도어락 수리](doorlock-repair.html)로 먼저 손보고 너무 오래됐으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
열쇠를 새로 맞추거나 복사해 두고 싶으시면 [출장 열쇠](key-call.html) 서비스를 이용하세요.

# 신천동 말고 시흥 어디든 갑니다
신천동 옆 대야동, 은행동, 정왕동, 배곧동, 목감동, 장곡동, 능곡동, 월곶동까지 다닙니다. / 시흥 안이면 동네 상관없이 24시간 출동합니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
