# 신천동 현관에서 지문이 자꾸 튕겨 나올 때
신천동은 신천역 주변으로 아파트와 빌라, 상가주택이 섞여 있어 가족 구성도 집마다 다양합니다. / 지문 도어락을 단 집에서는 식구 가운데 한 사람만 유독 인식이 안 된다는 이야기를 자주 합니다.
지문 인식은 손가락 상태, 센서 상태, 처음 등록한 방법 세 가지가 맞아야 잘 됩니다. / 그래서 같은 도어락이라도 누구 손이냐에 따라 결과가 달라집니다.
이 글은 가족별로 지문이 잘 안 되는 이유와 다시 등록할 때의 요령을 정리했습니다. / 밖에서 문이 아예 안 열릴 때 [시흥 출장열쇠](siheung.html)를 부르는 순서도 뒤에 적었습니다.
@ 신천동 지문 도어락 인식 실패 점검

# 지문 인식이 실패하는 순간들
먼저 언제 실패하는지 떠올려 보세요. / 실패하는 때가 일정하면 원인을 찾기 쉬워집니다.
- 아침에 손을 씻은 직후나 핸드크림을 바른 직후
- 겨울에 밖에서 들어와 손이 차갑고 건조할 때
- 요리나 청소를 하고 나서 손끝이 불었을 때
- 특정 가족만 거의 매번 실패할 때
- 처음에는 잘 되다가 몇 달 지나 점점 안 될 때
앞의 세 가지는 손 상태 문제이고, 네 번째는 등록 문제, 마지막은 센서나 전원 쪽일 가능성이 큽니다. / 아래에서 하나씩 살펴보겠습니다.

# 손끝이 거칠어지는 일을 하신다면
요리, 미용, 공사 현장처럼 손을 많이 쓰는 일을 하시면 손끝 결이 닳거나 갈라지기 쉽습니다. / 결이 흐려지면 센서가 등록된 모양과 맞춰 보지 못해 실패가 잦아집니다.
이런 분은 비교적 덜 쓰는 손가락, 예를 들어 반대 손 약지 같은 손가락을 하나 더 등록해 두시면 좋습니다. / 손을 잠깐 비벼 따뜻하게 한 뒤 대는 것만으로도 인식이 나아지기도 합니다.
손끝이 심하게 갈라지는 계절에는 잠들기 전에 손을 보습해 두면 아침 인식이 한결 낫습니다. / 대신 문을 열기 직전에 크림을 바르면 센서에 기름막이 남으니 시간을 띄워 주세요.

# 어르신 손가락은 결이 얕아집니다
나이가 들면 손끝 피부가 얇아지고 결이 얕아져 지문이 잘 안 읽히는 일이 흔합니다. / 손가락을 세게 누르면 결이 눌려서 오히려 더 안 됩니다.
손가락을 센서에 가볍게 올려 1초 정도 가만히 두는 것이 요령입니다. / 그래도 자주 실패한다면 어르신께는 번호나 카드를 함께 쓰시도록 해 두는 편이 마음이 놓입니다.

# 아이 지문은 자라면서 달라집니다
어릴 때 등록한 아이 지문은 손이 자라면서 크기와 모양이 조금씩 바뀝니다. / 처음에는 잘 되다가 한두 해 지나 실패가 늘었다면 다시 등록할 때가 된 것입니다.
아이가 손가락 끝만 살짝 대는 습관이 있다면 손가락 가운데 볼록한 부분이 센서에 닿게 알려 주세요. / 아이에게도 번호 하나는 꼭 외워 두게 하시는 게 좋습니다.
센서가 아이 키보다 높은 위치에 있으면 손가락을 비스듬히 대게 되어 실패가 늘어납니다. / 이럴 때는 아이가 평소 서는 자세 그대로 등록해 두면 도움이 됩니다.

# 다친 손가락, 밴드를 붙인 날
손가락을 베이거나 밴드를 붙인 날에는 등록한 손가락이 아예 안 읽힐 수 있습니다. / 화상이나 상처가 아문 뒤에도 흉터 때문에 인식이 달라지기도 합니다.
그래서 한 사람당 양손에서 손가락 하나씩, 두 개 이상 등록해 두시길 권합니다. / 한쪽을 다쳐도 다른 손으로 열 수 있습니다.
깁스나 붕대로 한동안 손을 못 쓰게 된다면 그 기간에는 카드나 번호를 주로 쓰시고, 다 나은 뒤 지문을 다시 등록하시면 됩니다.
@ 신천동 지문 도어락 손가락 두 개 등록

# 다시 등록할 때 잘 되는 요령
다시 등록할 때는 손을 깨끗이 씻고 물기를 완전히 말린 상태에서 하세요. / 핸드크림을 바른 직후는 피하는 게 좋습니다.
등록하라는 안내가 여러 번 나올 때 매번 같은 자리에 똑같이 대지 말고, 조금씩 위아래, 좌우로 각도를 바꿔 대 주세요. / 평소 문을 열 때 손가락이 닿는 여러 모양을 미리 넣어 두는 셈이라 인식률이 올라갑니다.
예전에 등록한 지문이 잘 안 된다면 지우고 새로 등록하는 편이 낫습니다. / 지우고 등록하는 방법은 제품마다 달라 설명서를 보시거나, 관리자 비밀번호가 필요할 수 있으니 미리 확인하세요.

# 센서를 닦는 법
센서 유리면에 손때나 먼지가 쌓이면 모든 가족의 인식이 함께 떨어집니다. / 마른 안경닦이나 부드러운 천으로 가볍게 닦아 주세요.
알코올이나 세제를 뿌리면 센서 코팅이 상할 수 있습니다. / 긁힘이 깊게 났다면 닦아서는 돌아오지 않으니 점검을 받아 보세요.

# 건전지와 인식률
건전지가 약해지면 지문 센서가 먼저 둔해지는 제품이 있습니다. / 손 상태도 괜찮고 센서도 깨끗한데 요즘 들어 모든 가족이 자주 실패한다면 건전지를 전부 새것으로 바꿔 보세요.
겨울에는 추위 때문에 건전지 힘이 떨어져 이런 일이 더 자주 생깁니다. / 건전지를 바꾸고 나서 바로 나아진다면 원인은 전원이었던 것입니다. / 그 뒤로는 경고음이 나기 전에 미리 바꾸는 습관을 들이시면 됩니다.

# 지문 말고 열 수단 하나 더
지문 도어락을 쓰는 집도 번호나 카드 같은 다른 열림 수단을 꼭 함께 정해 두세요. / 지문만 믿고 번호를 잊어버린 상태에서 인식이 안 되면 문 앞에서 막히게 됩니다.
가족끼리 번호를 정할 때는 생일이나 전화번호 끝자리처럼 쉽게 짐작되는 숫자는 피해 주세요. / 카드는 지갑이나 휴대폰 케이스에 하나씩 넣어 두시면 편합니다.

# 밖에서 아예 안 열릴 때
지문도 번호도 안 된다면 번호판이 켜지는지부터 보세요. / 꺼져 있다면 바깥쪽 아래 비상 단자에 9V 건전지를 대고 번호를 입력해 볼 수 있습니다.
지문을 수십 번 반복해서 대거나 센서를 손톱으로 긁는 것은 피해 주세요. / 실패가 쌓이면 입력이 한동안 잠기고, 센서가 상하면 고치는 일이 커집니다. 안 되면 그대로 두고 연락 주세요.

# 확인과 비용
도착하면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 집주인 확인 중 하나면 됩니다.
문과 도어락 상태를 보고 비용을 먼저 말씀드리고, 괜찮다고 하실 때만 시작합니다. / 끝내 못 열면 비용은 받지 않습니다. 여는 방식은 [현관문 개문](door-open.html), 순서는 [이용안내](guide.html)에 있습니다.
센서가 상했다면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 먼저 보고, 어렵다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 시흥 출장열쇠 신천동 지문 도어락 수리

# 신천동 주변 시흥
신천동과 붙어 있는 대야동, 은행동부터 목감동, 장곡동, 능곡동, 정왕동, 배곧동, 월곶동까지 시흥 어디든 다닙니다. / 시흥 밖 지역은 [출장 지역](area.html)에서 확인하세요.
