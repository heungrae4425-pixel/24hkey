# 월곶동 저녁, 분리수거 봉투 들고 나왔다가
월곶동은 월곶역 주변 아파트와 바다 쪽으로 이어진 상가, 주택이 함께 있는 동네입니다. / 저녁에 분리수거 봉투와 음식물 쓰레기를 양손에 들고 나왔다가 등 뒤에서 철컥 소리를 듣는 일이 생각보다 흔합니다.
택배 상자를 들이러 잠깐 문을 열었다가 바람에 문이 닫히는 경우도 있습니다. / 휴대폰까지 집 안에 두고 나왔다면 막막함이 두 배가 됩니다.
이 글은 그런 순간에 문 밖에서 할 수 있는 일을 차례로 적었습니다. / 손에 든 것을 내려놓는 데서 시작해 연락 방법, 기다리는 요령, [시흥 출장열쇠](siheung.html)를 부를 때 준비할 것까지 정리했습니다.
@ 월곶동 분리수거 나왔다가 현관문 잠김

# 자동 잠금이 생각보다 빠른 이유
요즘 도어락은 대부분 문이 닫히면 몇 초 안에 저절로 잠기도록 설정돼 있습니다. / 문을 살짝 걸쳐 둔 줄 알았는데 바람이나 도어클로저 힘으로 끝까지 닫히면 그대로 잠깁니다.
특히 복도 창을 열어 둔 아파트나 계단실 바람이 드는 빌라는 문이 예상보다 세게 닫힙니다. / 이건 고장이 아니라 원래 설정대로 움직인 것이니 자책하실 일은 아닙니다.
문 아래 말굽이나 고정 장치를 내려 두었는데도 닫혔다면 고정 장치가 헐거워졌을 수 있습니다. / 문이 열리면 그 부분도 같이 봐 두시면 좋습니다.

# 손에 든 것부터 내려놓고 정리
먼저 손에 든 쓰레기 봉투나 택배 상자를 내려놓으세요. / 분리수거라면 버리러 가던 길을 마저 다녀오셔도 됩니다.
두 손이 비면 마음도 조금 가라앉습니다. / 그다음 아래 순서대로 하나씩 확인해 보세요.
택배 상자는 복도에 그대로 두면 이웃이 지나다니기 불편할 수 있습니다. / 문 옆 벽 쪽으로 붙여 두거나 경비실에 잠시 맡겨 두시면 됩니다.

# 주머니와 문 주변을 다시 한 번
바지와 외투 주머니에 휴대폰이나 카드키가 들어 있지 않은지 다시 만져 보세요. / 급할 때는 손에 쥐고 있어도 모르는 경우가 있습니다.
도어락에 지문이나 카드가 등록돼 있다면 그쪽으로도 시도해 보세요. / 번호를 기억한다면 번호판이 켜지는지 확인하고 천천히 눌러 봅니다.
현관 앞 화분이나 소화전 안에 여분 열쇠를 숨겨 두는 방법은 권하지 않습니다. / 지금 당장은 아쉽더라도 다음을 위해 다른 방법을 정해 두시는 게 좋습니다.

# 휴대폰이 없다면 빌릴 곳
휴대폰이 집 안에 있다면 연락 수단부터 구해야 합니다. / 아파트라면 경비실이나 관리사무소, 빌라라면 같은 층 이웃이나 1층 가게에 전화를 빌려 달라고 해 보세요.
가족 가운데 번호를 외우고 있는 사람이 있다면 그분께 먼저 연락해 보세요. / 가까이 있는 가족이 번호나 카드를 갖고 오면 출장 없이 끝나기도 합니다.
가족에게 연락하려는데 번호가 기억나지 않는다면 저희에게 먼저 전화 주셔도 됩니다. / 상황을 듣고 할 수 있는 방법을 같이 찾아봅니다.
전화를 빌린 분의 번호로 다시 연락을 드려야 할 수 있으니 그분께 미리 양해를 구해 주세요. / 오래 걸리지 않게 위치와 상황만 짧게 말씀해 주시면 됩니다.

# 집 안 사정 떠올리기
문이 잠긴 뒤 집 안에 무엇이 켜져 있는지 떠올려 보세요. / 가스불, 다리미, 욕실 물, 혼자 남은 아이나 반려동물이 있다면 그 사실을 전화 첫마디에 말씀해 주세요.
불이나 물이 걱정되는 상황이라면 119나 관리사무소에도 함께 알리시는 게 좋습니다. / 급한 사정이 있으면 출동 순서를 앞당겨 정합니다.
@ 월곶동 현관 잠김 집 안 상황 확인

# 빌라와 아파트, 기다리는 자리
아파트라면 경비실이나 1층 공동현관 안쪽에서 기다리셔도 됩니다. / 공동현관이 닫혀 다시 들어가기 어렵다면 관리사무소에 도움을 청하세요.
분리수거장이 단지 바깥쪽에 있는 경우라면 돌아오는 길에 공동현관 번호를 몰라 한 번 더 막힐 수 있습니다. / 이럴 때도 경비실이 가장 가까운 도움입니다.
빌라나 상가주택이라면 건물 입구 쪽이 찾기 쉽습니다. / 골목 안쪽 건물이라면 큰길에서 보이는 간판이나 건물 색깔을 함께 알려 주세요. / 도착하기 전에 전화를 드리니 어디에 계실지만 알려주시면 됩니다.

# 바닷바람 부는 겨울 저녁이라면
월곶동은 바다가 가까워 겨울 저녁 바람이 차갑습니다. / 반팔에 슬리퍼 차림으로 나왔다면 밖에 서 계시기보다 건물 안쪽이나 가까운 가게 안에서 기다리세요.
이웃에게 겉옷을 빌리는 것도 부끄러운 일이 아닙니다. / 아이와 함께 나왔다면 아이 체온부터 챙겨 주세요. / 오래 기다릴수록 몸이 식으니 따뜻한 곳부터 찾으시는 게 먼저입니다.

# 문 앞에서 피할 일
문틈에 신용카드나 철사를 넣어 걸쇠를 밀어 보는 것, 손잡이를 세게 당기는 것은 피해 주세요. / 문틀과 도어락이 상하면 열고 난 뒤 고칠 일이 늘어납니다.
번호를 여러 번 틀리면 입력이 한동안 막힙니다. / 서너 번 해 보고 안 되면 멈추세요.
이웃집 베란다를 건너거나 창문으로 들어가려는 시도는 위험하니 절대 하지 마세요. / 저층이라도 미끄러지거나 다칠 수 있습니다.

# 전화로 알려 주실 것과 확인
월곶동 어느 쪽인지, 아파트라면 동과 호수, 빌라라면 건물 이름과 층을 알려주세요. / 도어락이 번호식인지, 지문이나 카드도 되는지, 보조키를 잠갔는지도 함께 말씀해 주시면 됩니다.
문을 열기 전에는 사시는 분이 맞는지 확인합니다. / 신분증이 집 안에 있다면 관리사무소 세대 확인이나 집주인 통화로 대신하고, 문을 연 직후 신분증을 보여 주시는 방법도 있습니다.

# 지갑이 안에 있어도 괜찮습니다
문과 도어락 상태를 보고 얼마인지 먼저 말씀드리고, 괜찮다고 하시면 시작합니다. / 지갑도 집 안에 있다면 문을 연 뒤에 정리하셔도 됩니다.
끝내 못 열면 비용은 받지 않습니다. / 여는 방식은 [현관문 개문](door-open.html), 전체 순서는 [이용안내](guide.html)에 정리해 두었습니다.
@ 시흥 출장열쇠 월곶동 현관문 개문

# 문이 열리고 나서 바꿔 볼 습관
분리수거나 택배를 받으러 나갈 때는 휴대폰 하나만이라도 주머니에 넣는 습관을 들여 보세요. / 휴대폰이 있으면 웬만한 일은 바로 해결됩니다.
번호를 가끔 잊는 가족이 있다면 카드키 하나를 지갑이나 휴대폰 케이스에 넣어 두시면 좋습니다. / 도어락에 카드 기능이 없다면 [도어락 교체](doorlock-replace.html)나 설정 변경을 같이 의논해 볼 수 있습니다.
자동 잠금을 끄는 것은 편할 수 있지만 잠그는 것을 잊기 쉽습니다. / 생활 습관에 맞춰 정하시고, 켜 둔다면 번호와 카드를 확실히 챙겨 두는 쪽을 권합니다.

# 월곶동 주변 시흥
월곶동과 가까운 배곧동, 정왕동부터 장곡동, 능곡동, 은행동, 대야동, 신천동, 목감동까지 시흥 어디든 갑니다. / 시흥 밖 지역은 [출장 지역](area.html)에서 확인하세요.
