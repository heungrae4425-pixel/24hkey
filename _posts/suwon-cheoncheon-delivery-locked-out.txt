# 딱 일 분 나왔을 뿐인데
천천동에서 성균관대역 쪽으로 출근하기 전, 현관 앞에 놓인 택배를 집어 들려고 잠깐 문을 열고 나왔습니다. / 손에는 상자, 주머니에는 아무것도 없는데 뒤에서 문이 철컥 닫히는 소리가 납니다.
이런 일은 누구에게나 한 번쯤 일어날 수 있습니다. / 중요한 건 놀란 마음을 가라앉히고 순서대로 움직이는 것입니다.
이 글은 잠깐 나왔다 잠긴 상황에서 먼저 할 일, 하면 안 되는 일, 연락 방법을 적었습니다. / 문 앞에 계시다면 바로 2번부터 보세요.
@ 천천동 택배 수령 중 현관문 잠김 출장열쇠

# 숨 한 번 쉬고 주머니부터 확인
문이 닫히면 먼저 몸에 휴대폰이나 열쇠, 카드가 있는지 확인합니다. / 슬리퍼 차림이라면 주머니가 비어 있을 가능성이 큽니다.
휴대폰이 있다면 문 앞에서 바로 전화를 주시면 됩니다. / 없다면 다음 방법으로 연락 수단을 마련해야 합니다.
당황해서 문을 마구 당기거나 걷어차지는 마세요. / 큰 소리가 나면 이웃이 놀라 신고로 이어지는 일도 있습니다. / 걸쇠가 이미 잠긴 문은 힘으로 열리지 않고 문만 상합니다.

# 정말 잠겼는지 한 번 확인해 보세요
번호를 눌러서 열리지 않는지 시도해 봅니다. / 도어락이 자동 잠금이라면 번호를 알고 있을 테니 문이 열려야 합니다.
번호판이 아예 꺼졌거나 비밀번호가 기억나지 않는 경우에 도움이 필요합니다. / 보조키가 안쪽에서 잠겼다면 번호를 눌러도 열리지 않습니다.
상황을 알면 전화로 설명하기 쉽고 도착해서 바로 작업에 들어갈 수 있습니다. / 특히 번호판이 켜지는지 꺼졌는지만 알려 주셔도 준비가 달라집니다.

# 번호키인지 열쇠 구멍인지 먼저 알려 주세요
택배를 받으러 나왔다가 잠기는 가장 흔한 경우는 자동 잠금 도어락입니다. / 번호는 아는데 휴대폰이나 카드가 없어서 연락이 어려운 상황입니다.
번호를 알고 있다면 문이 열릴 가능성이 높으니 먼저 다시 눌러 보세요. / 번호를 제대로 입력했는데도 안 열리면 보조키가 걸린 것일 수 있습니다.
열쇠로만 여닫는 문이라면 열쇠 없이는 방법이 없으니 연락이 필요합니다. / 이때는 열쇠 구멍 모양을 사진으로 보내 주시면 도움이 됩니다.

# 휴대폰이 집 안에 있을 때
이웃에게 전화를 한 번 빌려 달라고 부탁하는 방법이 가장 빠릅니다. / 복도식이라면 옆집 초인종을 눌러도 좋습니다.
엘리베이터 홀이나 로비 쪽 경비실이 있으면 거기서도 도움을 받을 수 있습니다. / 이웃에게는 문이 잠겼다고만 말하면 대부분 이해해 줍니다. / 잠시 앉을 곳이나 따뜻한 물을 부탁하는 일도 어렵지 않습니다.
이웃에게 휴대폰을 빌렸다면 이 글 맨 아래 연락처를 정확히 눌러 주시면 됩니다. / 번호는 마무리에 적어 두었습니다.
@ 천천동 이웃 전화 빌려 출장열쇠 연락

# 집 안에 누가 있는지 먼저 떠올리기
아이나 어르신, 반려동물이 안에 있다면 상황이 달라집니다. / 이 경우는 시간이 중요하니 전화로 곧바로 알려 주세요.
가스불이나 전기 제품이 켜져 있는지도 함께 말씀해 주시면 작업 순서를 정하는 데 도움이 됩니다. / 문틈으로 계속 말을 걸어 안쪽 사람이 놀라지 않게 해 주세요.
가족이 있다면 안쪽에서 문을 열어 주는 것이 가장 빠른 해결입니다. / 아이가 혼자 있을 때는 문 너머로 천천히 따라 말하게 해 주세요.

# 가족에게 연락해서 해결되는 경우
같이 사는 가족이 곧 귀가하거나 근처에 있다면 기다리는 편이 빠를 수 있습니다. / 비밀번호를 아는 가족이 문을 열어 주기만 하면 끝나는 일이기 때문입니다.
다만 오래 기다려야 한다면 추위나 더위가 걱정되니 출장을 요청하는 쪽이 낫습니다. / 기다리는 동안 위치를 정확히 알려 두세요.
가족에게 평소에 쓰는 비상 연락처를 미리 알려 둘 수도 있습니다. / 외우기 어려우면 가족 단체방 상단에 고정해 두는 방법도 있습니다.

# 문틈에 카드를 넣거나 드라이버로 여는 건 피하세요
영화에서처럼 신용카드로 문을 여는 방법은 현관문에는 통하지 않습니다. / 걸쇠 모양이 달라 카드가 끼어 부러지거나 문틈만 상합니다.
드라이버로 문을 벌리면 문틀과 도어락 외관이 손상되고 교체 비용이 따로 생길 수 있습니다. / 상태가 나빠지기 전에 전화로 상담하는 편이 결과적으로 이득입니다.
비파손으로 열 수 있는 문을 억지로 망가뜨리는 경우가 가장 아쉬운 사례입니다. / 급해도 일단 손을 멈추고 전화부터 하는 것이 결과적으로 빠릅니다.
@ 천천동 현관문 비파손 개문 작업

# 전화로 알려 주시면 좋은 것
- 천천동 건물 이름과 동, 호수
- 성균관대역 방향인지 다른 쪽인지 대략적인 위치
- 번호판 상태(켜짐, 꺼짐, 경고음)
- 도어락 모양과 열쇠 구멍 유무
- 집 안에 사람이나 반려동물이 있는지
이 정도면 상황 파악이 거의 끝납니다. / 사진이 있으면 문자로 보내 주세요. / 문 앞이 어두우면 휴대폰 불빛으로 도어락 전체가 나오게 찍어 주시면 좋습니다.

# 도착하면 사시는 분인지부터 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
슬리퍼 차림에 신분증이 집 안에 있는 경우가 흔합니다. / 이때는 관리사무소나 경비실에 세대 확인을 부탁하는 방법이 있습니다.
확인이 어려우면 작업을 할 수 없으니 미리 방법을 생각해 두세요. / 택배 송장에 적힌 주소나 휴대폰 속 계약서 사진도 참고가 됩니다.

# 비용은 열기 전에 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 말씀드립니다. / 동의하실 때만 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않고, 열고 난 뒤에 말없이 붙는 비용도 없습니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.
열 때 도어락이나 문이 상하지 않는 방법을 먼저 씁니다. / 자세한 설명은 [현관문 개문](door-open.html) 페이지에 있습니다.

# 문이 열린 뒤에 다시 겪지 않으려면
- 현관 앞 택배를 받을 땐 문 사이에 신발이나 작은 고무를 끼워 두기
- 휴대폰을 주머니에 넣는 습관 만들기
- 보조키를 잠가 두는 습관이 있다면 나가기 전에 풀려 있는지 확인
- 비밀번호를 가족과 공유하고 카드키 하나는 믿을 만한 곳에 따로 맡겨 두기
문틈에 끼우는 고무 도어스토퍼는 아주 작은 물건이지만 도움이 큽니다. / 쓰레기를 버리러 나갈 때도 똑같이 쓸 수 있습니다.
도어락 배터리가 약해진 상태에서 나갔다가 닫히는 경우도 있으니 평소에 점검해 두세요. / 자세한 점검법은 [도어락 수리](doorlock-repair.html)에서 볼 수 있습니다.

# 천천동 말고 수원 어디든
천천동 옆 율전동, 조원동은 물론 수원 전 지역에서 24시간 연락을 받습니다. / 성균관대역, 수원역, 영통역, 광교중앙역 근처도 마찬가지입니다.
다니는 동네는 [수원시 출장열쇠](suwon.html)에 정리했고, 다른 지역은 [출장 지역](area.html)에서 확인하세요.
