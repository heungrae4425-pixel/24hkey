# 번호만으로는 불안하다면 이중 인증
천천동은 성균관대역 가까운 생활권이라 학생과 직장인, 가족 세대가 함께 사는 집이 많습니다. / 그래서 현관 보안을 한 단계 더 올리고 싶다는 문의가 이어집니다.
이 글은 번호와 카드를 함께 확인해야 열리는 이중 인증 기능이 무엇인지, 설정 전에 확인할 것과 막혔을 때 대처를 정리했습니다. / 제품마다 이름과 방식이 달라 일반적인 흐름 위주로 적었습니다.
설정 자체는 어렵지 않지만 순서를 놓쳐 문 앞에서 막히는 일이 의외로 많습니다. / 천천히 읽고 문을 열어 둔 채로 따라 해 보세요.
@ 천천동 도어락 이중 인증 설정
# 이중 인증이란 무엇인가
한 가지가 아니라 두 가지 방법을 모두 맞춰야 문이 열리는 방식입니다. / 예를 들어 카드를 먼저 태그하고 비밀번호를 누르는 식으로 순서가 정해져 있습니다.
누가 번호를 어깨너머로 봐도 카드가 없으면 열리지 않고, 카드를 주워도 번호를 모르면 열리지 않습니다. / 다만 모든 도어락이 이 기능을 지원하는 것은 아닙니다.
오래된 모델이나 기본형 제품에는 카드 기능 자체가 없는 경우도 있습니다. / 먼저 내 도어락이 어떤 종류인지부터 알아보는 것이 순서입니다.
# 우리 집 도어락이 지원하는지 확인
- 제품 설명서에 이중 인증이나 복합 인증 설명이 있는지
- 설정 메뉴에 카드와 번호 조합 항목이 있는지
- 카드 등록 기능이 되는 모델인지
- 모델명이 어떻게 되는지
설명서가 없으면 제품 앞면이나 뒷면 라벨에서 모델명을 사진으로 남기세요. / 이 정보가 있으면 설정 순서를 훨씬 빠르게 찾을 수 있습니다.
모델명을 모를 때는 도어락 전체 사진과 번호판 사진을 보내 주셔도 됩니다.
# 설정하기 전에 꼭 해 둘 준비
문을 열어 둔 상태에서 안쪽 설정 버튼을 눌러야 하는 제품이 대부분입니다. / 문이 닫힌 채 설정하다 잘못되면 밖에서 열 수 없게 됩니다.
카드는 가족 수보다 한두 장 더 준비하고, 하나는 따로 보관하세요. / 카드를 잃어버렸을 때 대신 쓸 수단이 없으면 이중 인증이 오히려 불편해집니다.
설정 전에 기존 번호와 카드를 어떻게 정리할지 가족과 이야기해 두면 좋습니다. / 쓰지 않는 카드는 이 기회에 삭제하세요.
# 설정의 일반적인 순서
제품마다 다르지만 대개 아래와 같은 흐름입니다.
- 관리자 모드에 들어가 기존 설정을 확인
- 카드를 먼저 등록하고 사용할 번호를 입력
- 복합 인증 방식 선택
- 설정이 끝났음을 알리는 소리나 표시등 확인
@ 천천동 카드 등록과 번호 입력
# 설정 후에는 문을 열어 둔 채 시험하기
설정을 마친 뒤에는 문을 열어 둔 채로 카드와 번호를 순서대로 사용해 열리는지 확인합니다. / 닫힌 상태에서 처음 시험하면 막혔을 때 대안이 없습니다.
순서를 바꿔 입력하면 어떻게 반응하는지도 한 번 보세요. / 가족 모두가 같은 순서로 쓰도록 정해 두는 것이 중요합니다.
순서를 현관 안쪽에 작은 메모로 붙여 두는 집도 있습니다. / 다만 바깥에서 보이는 곳에는 붙이지 마세요.
# 이중 인증이 불편해지는 순간
아이가 카드만 들고 번호를 모르는 경우나 어르신이 순서를 헷갈리는 경우입니다. / 장보기 짐을 든 채로 카드를 꺼내기 어려울 때도 있습니다.
이럴 땐 모든 출입에 이중 인증을 쓰기보다 야간에만 켜는 방식이 가능한지 설명서를 확인해 보세요. / 가족 구성에 맞게 편의와 보안 사이의 균형을 잡는 것이 좋습니다.
학생이나 늦게 귀가하는 가족이 있다면 그 사람 기준으로 쓰기 편한지 먼저 시험해 보세요.
# 카드를 잃어버렸을 때
이중 인증 상태에서 카드를 잃어버리면 번호만으로는 열 수 없을 수 있습니다. / 이럴 때 억지로 번호를 여러 번 누르면 입력 잠금이 걸려 더 오래 막힙니다.
먼저 분실한 카드를 삭제하고 새 카드를 등록해야 하는데, 문이 잠겨 있으면 안쪽 설정에 들어갈 수 없습니다. / 이 경우는 문을 먼저 열어야 합니다.
설정 모드에서 나오는 방법을 모르면 건전지를 뺐다 끼우는 식으로 초기화하려는 분도 있지만, 제품에 따라 등록 정보가 지워지거나 문이 닫힌 채 잠길 수 있어 권하지 않습니다.
# 문이 안 열릴 때 확인 순서
- 번호판 불이 들어오는지
- 카드를 태그했을 때 반응 소리가 나는지
- 번호를 눌렀을 때 소리가 나는지
- 배터리가 약해 경고음이 나는지
카드는 반응하는데 번호가 안 먹으면 번호 쪽, 반대로면 카드 쪽 문제입니다.
카드를 지갑 안쪽에 넣어 다니면 태그 거리가 안 맞는 경우가 있으니 꺼내서 번호판에 바짝 대 보세요. / 둘 다 반응하지 않으면 배터리 방전을 의심하고 9V 건전지 비상 전원을 시도해 보세요.
# 신분 확인부터 진행합니다
이중 인증이 걸린 문을 열 때도 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.
번거롭지만 이웃과 가족을 지키는 절차입니다. / 서류가 집 안에 있다면 관리사무소 확인을 부탁하는 방법도 있습니다.
# 비용은 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 필요한 작업을 설명한 뒤 비용을 말씀드립니다. / 동의하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 하기 전에 따로 여쭙습니다. 진행 순서는 [이용안내](guide.html)에서 보실 수 있습니다.
@ 천천동 출장열쇠 복합 인증 도어락
# 이중 인증 지원이 안 되는 도어락이라면
기능이 없는 제품에는 억지로 흉내를 낼 방법이 없습니다. / 원한다면 [도어락 교체](doorlock-replace.html)로 지원하는 제품을 고르는 방법이 있습니다.
고를 때는 카드 장수, 번호 길이, 야간만 켜는 기능이 되는지를 비교해 보세요.
먼저 지금 쓰는 제품을 [도어락 수리](doorlock-repair.html)로 고쳐서 쓸 수 있는지 보고, 필요할 때만 교체를 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
설정 모드에서 나오는 방법을 모르면 건전지를 뺐다 끼우는 식으로 초기화하려는 분도 있습니다. / 제품에 따라 모든 등록 정보가 지워지거나 문이 닫힌 채 잠길 수 있어 권하지 않습니다.
화면 안내나 소리가 이해되지 않으면 상태를 그대로 두고 연락 주세요. / [출장열쇠](key-call.html) 상담에서 모델을 보고 순서를 안내해 드립니다.
# 천천동 말고 수원 어디든 갑니다
영통동, 율전동, 조원동, 정자동, 인계동까지 수원 안이면 24시간 출동합니다. / [수원시 출장열쇠](suwon.html) 페이지와 [출장 지역](area.html)에서 지역을 확인하시고, 문이 안 열릴 때는 [현관문 개문](door-open.html)도 참고하세요.
