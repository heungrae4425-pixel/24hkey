# 천천동에서 폰을 대도 문이 반응하지 않을 때
성균관대역 쪽으로 오가는 천천동 생활권에는 휴대폰으로 문을 여는 도어락을 쓰는 가정이 늘고 있습니다. / 어제까지 폰을 대면 열리던 문이 오늘은 아무 반응이 없으면 당황스럽습니다.
이 글은 NFC나 블루투스로 열던 도어락이 갑자기 안 열릴 때, 어디부터 확인하고 언제 연락하면 되는지 정리한 글입니다.
@ 천천동 스마트폰을 도어락에 대도 반응이 없는 모습

# NFC와 블루투스는 방식이 다릅니다
NFC는 폰을 도어락 가까이 바짝 댈 때만 인식됩니다. / 블루투스는 조금 떨어져도 되지만 폰과 도어락이 먼저 연결되어 있어야 합니다.
증상이 어떻게 다른지에 따라 원인이 달라집니다. / 내 도어락이 어느 방식인지 모르겠다면 앱 설정이나 설명서를 먼저 확인해 보세요.

# 폰 쪽에서 먼저 확인할 것
문제는 도어락보다 폰 쪽에 있는 경우가 훨씬 많습니다.
- NFC나 블루투스 기능이 꺼져 있지 않은지
- 절전 모드나 배터리 최적화로 앱이 꺼져 있지 않은지
- 케이스에 금속판이나 카드가 들어 있어 신호를 막고 있지 않은지
- 최근 폰 운영체제나 앱 업데이트가 있었는지
폰 화면이 켜져 있고 잠금이 풀린 상태에서 다시 대 보면 인식되는 경우가 있습니다. / 케이스를 벗기고 대 보는 것도 가장 간단한 시험입니다. / 폰을 껐다 켜는 것만으로 되살아나는 경우도 적지 않습니다.

# 폰 위치에 따라 인식이 달라집니다
폰을 대는 시간도 영향을 줍니다. / 스치듯 대는 것보다 한 번 대고 잠깐 멈추는 편이 인식이 잘 됩니다.
NFC 안테나는 폰마다 위치가 다릅니다. / 뒷면 위쪽 가운데에 있는 폰도 있고 아래쪽에 있는 폰도 있습니다.
도어락의 인식 부분도 번호판 위쪽인지 아래쪽인지 제품마다 다릅니다. / 천천히 위치를 옮겨 가며 대 보면 인식되는 자리를 찾을 수 있습니다.

# 도어락 쪽에서 확인할 것
도어락 배터리가 약해지면 번호판은 켜져도 폰 인식 기능이 먼저 약해지는 경우가 있습니다. / 번호판 불빛이 평소보다 어둡다면 배터리 상태를 의심해 보세요.
번호 입력으로는 열리는지 한 번 시험해 봅니다. / 번호로는 열리는데 폰만 안 된다면 폰 연동 쪽 문제일 가능성이 높습니다. / 반대로 번호도 카드도 모두 안 된다면 도어락 본체나 전원 문제로 봐야 합니다. / 어느 쪽인지 알려 주시면 전화 상담이 훨씬 빨라집니다.
@ 도어락 인식부와 번호판 불빛 상태를 살피는 장면

# 폰을 바꾼 뒤에 안 될 때
새 폰으로 바꾸고 나서 갑자기 안 열리는 경우가 가장 흔합니다. / 도어락에 등록된 것은 폰 자체이거나 앱 계정이기 때문에 새 폰은 다시 등록해야 하는 경우가 있습니다.
이전 폰이 아직 있다면 그 폰으로 먼저 문을 열고 새 폰을 추가하는 것이 가장 쉽습니다. / 이전 폰이 없으면 도어락 본체에서 등록 절차를 새로 해야 할 수 있습니다.

# 이럴 때는 억지로 시도하지 마세요
겨울에는 손이 시려 폰을 잡은 채 오래 문 앞에 서 있다가 폰 배터리까지 줄어드는 경우가 있습니다. / 배터리가 얼마 남지 않았다면 먼저 따뜻한 곳에서 충전해 두세요.
폰을 도어락에 세게 대거나 반복해서 두드리는 분들이 있습니다. / 그런다고 인식이 좋아지지 않고, 폰과 도어락 모두 상할 수 있습니다.
앱 연동을 여러 번 지웠다 다시 등록하다가 기존 등록이 꼬이는 경우도 있습니다. / 한두 번 시험해서 안 되면 멈추고 다른 열기 방법을 먼저 생각해 보세요.

# 문 앞에서 쓸 수 있는 다른 방법
번호, 카드키, 보조 열쇠 중 쓸 수 있는 방법이 있는지 확인해 보세요. / 가족 폰에 등록되어 있다면 그 폰으로 열 수도 있습니다.
번호판이 아예 꺼져 있다면 배터리부터 의심합니다. / 비상 전원 단자가 있는 제품이면 9V 건전지를 대어 번호를 눌러 볼 수 있습니다.

# 출장열쇠에 전화할 때 알려 주실 것
- 도어락 모양과 제조사 (사진이 가장 좋습니다)
- NFC인지 블루투스인지, 둘 다 안 되는지
- 번호 입력은 되는지
- 폰 기종과 최근 바꾼 것 (폰 교체, 업데이트, 앱 재설치)
위치는 천천동 어디쯤인지와 가까운 역이나 건물 방향을 알려 주시면 도착이 빨라집니다. / 연락처는 문자로도 받을 수 있습니다. / 사진이 어렵다면 도어락 겉면에 적힌 제품 이름을 읽어 주셔도 됩니다. / 이미 시도해 본 방법을 말씀해 주시면 같은 시험을 반복하지 않아도 됩니다.

# 신분 확인과 비용은 먼저 설명드립니다
문 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요. / 신분증이 집 안에 있다면 관리사무소 확인도 방법입니다.
도어락 상태를 보고 필요한 작업과 비용을 먼저 말씀드립니다. / 동의하실 때만 시작하고, 열지 못하면 비용은 받지 않습니다.
폰 연동만 다시 등록하면 되는 경우와 부품 교체가 필요한 경우를 나눠 설명드립니다. / 열고 난 뒤에 말없이 붙는 비용은 없습니다. / 추가 작업이 필요해 보이면 하기 전에 꼭 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 도어락 연동 등록을 다시 진행하는 장면

# 열고 난 뒤에 폰 연동 다시 잡기
문이 열리면 도어락 안쪽에서 폰 등록을 처음부터 다시 정리해 드립니다. / 쓰지 않는 예전 폰은 목록에서 지워 두는 것이 안전합니다.
번호 입력, 카드키 같은 다른 방법도 같이 시험해 보세요. / 새로 등록한 폰으로 문 밖에서 한 번, 안쪽에서 한 번 열어 보며 정상 동작을 확인합니다. / 가족 폰이 있다면 같이 등록해 두면 한 사람 폰이 꺼져도 문 앞에서 막히지 않습니다. / 고장이 의심되면 [도어락 수리](doorlock-repair.html)로, 오래된 제품이면 [도어락 교체](doorlock-replace.html)로 안내해 드립니다.

# 폰으로 여는 도어락 평소 관리법
- 도어락과 폰 앱을 최신 상태로 맞춰 두기
- 폰을 바꾸기 전에 이전 폰으로 새 폰 먼저 등록하기
- 번호와 카드키는 폰 말고 따로 남겨 두기
- 배터리 경고음이 나면 그날 바로 교체하기
폰이 꺼지거나 잃어버려도 문 앞에서 막히지 않으려면 다른 열기 방법을 꼭 하나 남겨 두세요. / 폰 케이스에 카드를 꽂아 다니는 분은 NFC 인식이 약해질 수 있으니 따로 시험해 보세요. / 스마트 도어락을 고르는 기준은 [도어락 설치](doorlock-install.html) 안내에서 볼 수 있습니다.

# 천천동 말고 수원 어디든 갑니다
밤늦게 학교나 일터에서 돌아오는 시간대에도 출동 요청을 받습니다. / 폰이 꺼져 연락이 어렵다면 이웃의 전화를 빌려 연락 주셔도 됩니다.
천천동과 가까운 율전동, 영통동, 정자동, 조원동 등 수원 안이면 24시간 출동합니다. / 다니는 동네는 [수원 출장열쇠](suwon.html) 페이지에 정리해 두었습니다.

? 밤늦게 전화해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 연락 주세요.
? 세입자인데 되나요? | 사시는 분인지 확인되면 됩니다. 신분증이나 우편물을 준비해 주세요.
