# 천천동에서 열쇠집을 부를 때 가장 걱정되는 것
천천동은 성균관대역과 가까운 생활권이라 학생과 직장인, 가족 단위 세대가 섞여 있는 동네입니다. / 늦은 시간에 문이 안 열려 열쇠집에 전화할 때 가장 마음에 걸리는 건 결국 비용입니다.
얼마가 나올지 모른 채 문 앞에서 기다리는 것만큼 불안한 일도 없습니다. / 이 글은 비용 이야기를 어떤 순서로 듣고 확인하면 되는지를 정리한 글입니다.
@ 천천동 출장열쇠 작업 전 비용 안내

# 전화 한 통에서 정해지는 것과 정해지지 않는 것
전화로 상황을 듣고 나면 대략의 방향은 말씀드릴 수 있습니다. / 하지만 문과 도어락을 직접 보기 전에는 확정할 수 없는 부분이 있습니다.
- 도어락 종류와 문 두께
- 배터리 문제인지, 부품 문제인지
- 문틀이나 걸쇠가 눌려 있는지
- 집 안에 사람이나 반려동물이 있는지
전화에서 말하는 내용은 어디까지나 출발점입니다. / 정확한 안내는 도착해서 살펴본 뒤 작업 시작 전에 드립니다.

# 전화할 때 이 다섯 가지는 꼭 물어보세요
묻는 것은 실례가 아닙니다. / 어느 열쇠집이든 이 정도는 분명히 대답할 수 있어야 합니다.
- 문을 못 열면 비용을 받는지
- 도착해서 보고 비용을 먼저 말해 주는지
- 부품을 바꿔야 하면 따로 물어보는지
- 도착까지 대략 얼마나 걸리는지
- 주소와 신분 확인이 필요한지
이 질문에 머뭇거리거나 답이 흐릿하면 한번 더 생각해 보세요. / 다른 열쇠집을 고르는 방법은 [출장열쇠 부르는 방법](key-call.html)에서 더 자세히 볼 수 있습니다.

# 도착 후에는 비용 이야기가 먼저입니다
기사가 도착하면 바로 공구를 꺼내지 않고 먼저 문과 도어락을 확인합니다. / 그다음에 어떤 방법으로 열지, 비용은 어느 정도인지 말씀드립니다.
이 단계에서 "괜찮다"고 하셔야 작업이 시작됩니다. / 마음에 들지 않으면 그냥 돌려보내셔도 되고, 그에 대해 불이익은 없습니다.
이미 마음이 급한 상황이라 대충 넘기기 쉽지만 이 순간이 제일 중요합니다. / 질문이 있다면 작업 전에 말씀해 주세요.

# 작업 중간에 바뀔 수 있는 부분
문을 열다 보면 처음에 생각한 것과 다른 상태가 드러날 수 있습니다. / 예를 들어 열고 보니 도어락 안쪽 부품이 이미 망가져 있는 경우입니다.
이런 때는 하던 작업을 멈추고 상황을 다시 설명드립니다. / 말없이 다른 작업이 추가되는 일은 없고, 추가 부분은 새로 동의를 받은 뒤에만 진행합니다.
부품을 바꾸는 이야기가 나오면 바꾸기 전에 반드시 따로 여쭤봅니다. / 꼭 바꿔야 하는 부품인지, 당장 안 바꿔도 되는지도 같이 설명해 드립니다.

# 열기만 하는 작업과 부품이 필요한 작업은 다릅니다
단순히 문을 여는 작업과 도어락을 고치거나 바꾸는 작업은 성격이 다릅니다. / 같은 출장이라도 이 둘을 나눠서 이야기해야 헷갈리지 않습니다.
문 열기만으로 끝나면 그 부분의 안내로 마무리됩니다. / 이후 고장이 걱정되면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 따로 상담하시면 됩니다.
그날 바로 결정하지 않아도 괜찮습니다. / 일단 문을 열고, 나머지는 다음 날 차분히 정해도 됩니다.
@ 천천동 도어락 현장 확인 후 안내

밤늦은 시간이라고 해서 안내 방식이 달라지지는 않습니다. / 새벽이든 낮이든 도착해서 살펴보고, 작업 전에 말씀드리는 순서는 같습니다.
혹시 안내를 듣고도 이해가 안 되는 부분이 있다면 "그게 무슨 뜻인지 다시 설명해 달라"고 말씀하셔도 됩니다. / 천천동처럼 학생과 직장인이 많은 동네에서는 처음 불러 보는 분이 많아서 이런 질문이 자연스럽습니다.
급하다는 이유로 확인 없이 진행하는 것이 가장 후회가 남습니다. / 잠깐 멈추고 묻는 시간은 길어야 1~2분이면 충분합니다.

# 못 열면 비용을 받지 않는다는 말의 의미
24시출장열쇠는 문을 끝내 열지 못한 경우에는 비용을 받지 않습니다. / 이 기준은 전화로도, 도착해서도 똑같이 말씀드립니다.
다만 이미 중간에 부품 교체에 동의하셨다면 그 부품 이야기는 별개일 수 있어서 동의 전에 설명을 드립니다. / 헷갈리는 부분은 작업 전에 물어보시면 됩니다.

# 신분 확인은 비용 이야기와 함께 진행됩니다
문을 여는 일이라 사시는 분이 맞는지 확인이 필요합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 되지 않으면 작업은 진행할 수 없습니다. / 이웃이나 다른 사람 집을 보호하기 위한 절차이니 이해 부탁드립니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

# 안내받은 내용을 메모해 두세요
작업 전에 들은 내용은 간단히 메모하거나 문자로 남겨 달라고 하셔도 됩니다. / 나중에 확인할 일이 있을 때 도움이 됩니다.
- 어떤 작업을 할지
- 비용은 어떻게 안내받았는지
- 바꾸는 부품이 있는지
- 작업 후 확인할 것이 있는지
급한 마음에 지나가기 쉬운 내용이라 한 줄씩만 적어도 충분합니다.

혼자 판단하기 어려우면 같이 사는 가족이나 룸메이트에게 통화를 넘겨 설명을 함께 들어도 좋습니다. / 두 사람이 같은 내용을 들으면 나중에 서로 다르게 기억하는 일이 없습니다.
작업이 끝난 뒤에도 궁금한 점이 있으면 편하게 다시 전화 주세요. / 안내받은 내용과 실제 작업이 같았는지 확인하는 것도 중요합니다.
처음 이용하는 분일수록 이 순서를 알고 계시면 훨씬 덜 불안합니다.

# 비교하고 싶으면 이렇게 하세요
여러 곳에 전화해서 비교해 보고 싶은 마음도 이해합니다. / 다만 같은 상황인지를 맞춰서 물어봐야 비교가 됩니다.
도어락 사진과 현재 증상을 똑같이 설명하고 같은 질문을 던지면 차이가 보입니다. / 숫자만 비교하지 말고 "문을 못 열면 어떻게 되는지", "도착해서 어떻게 안내하는지"도 같이 비교해 보세요.
@ 천천동 비용 확인 후 문 열기 진행

# 천천동에서 연락할 때 위치는 이렇게
천천동은 길이 비슷한 구간이 많아서 위치를 정확히 알려주시면 도착이 빨라집니다. / 건물 이름 대신 도로명이나 가까운 성균관대역 방향을 함께 알려주셔도 됩니다.
- 정확한 주소와 동, 호수
- 문 앞 상황과 도어락 모양
- 집 안에 사람이나 반려동물이 있는지
- 연락 가능한 번호
사진을 먼저 보내주시면 맞는 장비를 챙기기 좋습니다.

# 천천동 말고 수원 어디든 갑니다
천천동 가까운 율전동, 영통동, 조원동은 물론 수원 전 지역을 다닙니다. / 24시간 전화를 받으니 밤늦게라도 연락 주세요.
다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있고, 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
