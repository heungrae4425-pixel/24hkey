# 금곡동 지문 도어락, 왜 어떤 날은 안 읽힐까
금곡동에서 지문 도어락을 쓰는 분들이 가끔 "어제는 잘 됐는데 오늘은 안 된다"고 말씀하십니다. / 수원역 쪽으로 출퇴근하는 길에 손이 젖었거나, 겨울이라 손이 갈라진 날에 특히 그렇습니다.
기계가 고장 난 것 같아 보여도 손의 상태가 원인인 경우가 꽤 있습니다. / 이 글은 손이 젖었을 때와 건조할 때 각각 어떻게 하면 되는지 정리했습니다.
@ 금곡동 지문 도어락 인식 점검

# 지문 인식이 되는 원리를 간단히
지문 도어락은 손가락의 무늬를 읽어 미리 등록된 모양과 비교합니다. / 무늬가 흐리거나 센서 표면 상태가 바뀌면 같은 손가락이어도 다르게 읽을 수 있습니다.
제품에 따라 빛으로 읽는 방식과 전기 신호로 읽는 방식이 있습니다. / 방식에 따라 젖은 손과 마른 손에 반응하는 정도가 달라서 일률적으로 말하기는 어렵습니다.

# 손이 젖었을 때 생기는 일
설거지를 하다 나왔거나 비를 맞고 들어올 때 물기가 문제가 됩니다. / 물기가 지문의 골을 메우면 센서가 무늬를 제대로 구별하지 못합니다.
- 손끝에 물이 맺혀 무늬가 번져 보임
- 센서 표면에도 물방울이 남아 있음
- 장갑이나 소매에서 물이 흘러내려 센서가 젖음
이럴 때는 수건으로 손과 센서를 먼저 닦고 다시 대 보세요. / 급하다고 센서를 문질러 닦으면 표면이 긁힐 수 있으니 마른 부드러운 천으로 가볍게 닦으세요.

# 손이 건조할 때는 반대로 문제가 생깁니다
겨울철에는 손이 바싹 마르고 갈라져서 지문이 얕아집니다. / 이때는 센서가 무늬를 읽을 수 있는 접촉면이 줄어듭니다.
손에 핸드크림을 바른 직후에도 비슷한 문제가 생길 수 있습니다. / 오히려 번들거리는 막이 생겨 읽기 어려워지기 때문입니다.
손을 잠깐 비벼 따뜻하게 한 뒤 대 보거나 입김을 살짝 불어주면 나아지는 경우도 있습니다. / 너무 세게 누르지 않고 평소처럼 대는 것이 좋습니다.

# 대는 방법도 점검해 보세요
센서에 대는 각도와 위치가 조금씩 달라지면 인식률이 떨어집니다. / 처음 등록할 때와 같은 자세로 대는지 생각해 보세요.
- 손가락 가운데 부분이 센서 정중앙에 닿는지
- 너무 비스듬히 대거나 손끝만 대는지
- 누르는 시간이 너무 짧은지
- 같은 손가락이 아닌 다른 손가락을 대고 있는지
지문 등록 때 한 손가락을 여러 각도로 넣어 두면 인식률이 좋아집니다. / 등록 방법은 제품마다 달라서 설명서를 보시거나 [도어락 수리](doorlock-repair.html) 상담에서 물어보세요.

# 등록은 두세 손가락 이상으로
손가락 하나만 등록해 두면 그 손가락이 다치거나 젖었을 때 곤란합니다. / 다른 손의 손가락도 한두 개씩 더 등록해 두면 훨씬 안심됩니다.
공사를 하거나 요리를 자주 해서 손이 거친 분들은 특히 그렇습니다. / 등록한 손가락 가운데 상처가 났을 때 쓸 수 있는 다른 손가락이 하나 있도록 해 두세요.
@ 금곡동 센서 청소와 손가락 등록

# 센서 표면이 더러운 것도 흔한 원인입니다
오래 쓰다 보면 센서에 기름기나 먼지가 쌓입니다. / 이 막이 지문을 가려서 인식이 떨어지는 경우가 많습니다.
부드러운 마른 천이나 안경 닦는 천으로 가볍게 닦아 주세요. / 알코올이나 세제를 직접 뿌리는 것은 제품에 따라 맞지 않을 수 있어 권하지 않습니다.
센서 표면에 긁힘이 있다면 인식 문제가 계속될 수 있습니다. / 이때는 부품 점검이 필요해서 따로 상담을 받는 것이 좋습니다.

# 배터리가 약해도 지문이 이상해집니다
배터리가 거의 다 되면 지문 센서가 먼저 둔해지는 제품이 있습니다. / 평소보다 인식이 느리거나 삑 소리가 늦게 나면 배터리를 의심해 보세요.
배터리 경고음이 나는데도 미루고 있었다면 이번 기회에 한꺼번에 바꾸세요. / 일부만 바꾸면 얼마 못 가 같은 일이 생깁니다.

# 지문이 안 될 때를 대비한 다른 출입 방법
지문 하나에만 의존하면 위험합니다. / 대부분의 지문 도어락에는 번호 입력이나 카드, 보조키 같은 다른 방식이 함께 있습니다.
- 비밀번호가 기억나는지 먼저 떠올리기
- 카드키가 지갑이나 가방에 있는지 확인
- 보조키 열쇠를 어디에 두었는지
- 가족이 집 안에 있는지
지문 이외의 방법이 모두 막혀 있을 때만 연락 주세요. / 자세한 호출 방법은 [출장열쇠 부르는 방법](key-call.html)에 적어 두었습니다.

아이나 어르신이 쓰는 집이라면 인식 문제가 더 잦을 수 있습니다. / 아이는 손가락이 작고 자라면서 지문 모양이 달라지고, 어르신은 지문이 옅어지는 경우가 있습니다.
이런 집에서는 지문만 믿지 말고 번호나 카드를 같이 쓰도록 하는 것이 낫습니다. / 지문이 안 될 때 번호로 바로 들어갈 수 있으면 문 앞에서 기다리는 일이 사라집니다.
요리나 청소, 운동 직후에 손이 달라진 날에는 잠깐 손을 말린 뒤 다시 대 보세요. / 잠깐의 여유만으로 해결되는 경우가 생각보다 많습니다.

# 하지 않는 편이 좋은 것들
센서를 힘껏 누르거나 문질러도 인식이 좋아지지 않습니다. / 오히려 표면이 상할 수 있습니다.
센서를 분해하거나 접착제 같은 것으로 붙이는 것도 피하세요. / 손으로 해결하려다 부품이 못쓰게 되는 일이 있습니다.
비밀번호를 여러 번 틀리면 입력이 한동안 막힙니다. / 서너 번 해 보고 안 되면 멈추는 것이 좋습니다.

지문이 안 읽히는 일이 며칠째 계속된다면 손 상태 때문이 아닐 수도 있습니다. / 센서 내부 문제나 연결 불량일 때는 닦거나 다시 대는 것만으로는 해결되지 않습니다.
이럴 때는 사용 상황과 증상을 간단히 적어 두었다가 상담할 때 말씀해 주세요. / 언제부터, 어떤 손가락이, 젖었을 때만 그런지 같은 정보가 원인을 찾는 데 큰 도움이 됩니다.

# 문 앞에서 막혔다면 신분 확인이 먼저입니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 진행할 수 없습니다. / 이웃과 집을 보호하는 절차이니 미리 챙겨 두시기를 부탁드립니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하는 경우에도 바꾸기 전에 따로 여쭤봅니다.
센서가 고장 난 것으로 보이면 [도어락 교체](doorlock-replace.html) 쪽도 안내해 드리지만 꼭 바꾸라고 권하지는 않습니다.
@ 금곡동 지문 인식 불량 출장 점검

# 금곡동 말고 수원 어디든 갑니다
금곡동 가까운 동네는 물론 수원 전 지역을 24시간 다닙니다. / 다니는 동네는 [수원시 출장열쇠](suwon.html)에서 확인하실 수 있습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
