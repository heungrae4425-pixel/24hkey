# 공사 소리가 나기 시작하면 현관부터 챙겨야 합니다
금곡동에서 도배, 바닥, 욕실 공사를 하다 보면 사람이 하루에도 수십 번 현관을 드나듭니다. / 자재를 나르고 공구를 옮기는 문이 결국 도어락이 달린 현관문입니다.
수원역이나 가까운 역에서 출퇴근하며 공사를 맡기신 분들은 현장을 매일 보지 못합니다. / 그래서 현관 도어락이 어떤 상태로 공사를 견디는지 미리 정해 두는 편이 좋습니다.
이 글은 수원 금곡동 인테리어와 리모델링 중에 도어락이 망가지거나 잠겨 버리는 일을 줄이는 방법을 모았습니다. / 공사 시작 전, 공사 중, 공사 끝난 뒤 순서대로 읽으시면 됩니다.
@ 금곡동 인테리어 공사 현관 도어락 보호

# 공사 중에 도어락이 자주 상하는 이유
도어락이 고장 나는 건 대부분 부주의가 쌓여서입니다. / 몇 가지 흔한 경우를 먼저 보겠습니다.
- 자재 때문에 문을 활짝 열어 둔 채 오래 세워 두어 경첩이 처지는 경우
- 먼지와 페인트가 번호판과 손잡이 틈에 들어가는 경우
- 작업자가 문을 발이나 몸으로 밀어 걸쇠가 휘는 경우
- 비닐 보양을 하다 번호판 센서를 가려 버리는 경우
먼지는 특히 조심해야 합니다. / 가루가 모터 부분이나 열쇠 구멍에 들어가면 공사가 끝난 뒤 잘 안 돌아가는 증상으로 나타납니다.

# 공사 시작 전에 사진 몇 장 남겨 두기
시작하기 전에 현관문 안쪽과 바깥쪽, 도어락 모양, 문틀 상태를 사진으로 찍어 두세요. / 나중에 상태가 달라졌는지 비교할 때 큰 도움이 됩니다.
도어락 제조사나 모델명이 적힌 안쪽 스티커도 찍어 두면 좋습니다. / 부품이나 배터리 종류를 확인할 때 바로 쓸 수 있습니다.
현재 등록된 비밀번호와 카드키 개수도 적어 둡니다. / 공사 팀에 알려 줄 번호와 가족이 쓰는 번호를 나누어 정리해 두면 편합니다.

# 공사 팀에게 주는 번호는 따로 만들어 두세요
도어락 중에는 번호를 여러 개 등록할 수 있는 제품이 많습니다. / 공사용 번호를 새로 하나 만들어 쓰면 끝나고 그 번호만 지우면 됩니다.
가족이 쓰는 번호를 공사 팀에게 그대로 알려 주면 나중에 바꾸는 일이 번거로워집니다. / 공사 기간만 쓸 임시 번호를 따로 두는 쪽이 훨씬 깔끔합니다.
여러 사람이 드나드는 현장에서는 번호가 새어 나가기 쉽습니다. / 공사가 끝나면 임시 번호를 지우고 새 번호로 정리하는 것까지 하나의 일로 생각하세요.

# 보양은 하되 덮지 말아야 할 곳
먼지와 도장 작업이 있다면 도어락 겉면을 비닐로 감싸는 분들이 많습니다. / 이 방법은 좋지만 덮는 곳과 덮지 않는 곳을 구분해야 합니다.
- 번호판 앞면은 얇은 보양 필름을 붙이되 눌러 쓸 수 있게 두기
- 열쇠 구멍과 비상 전원 단자는 테이프가 남지 않게 가볍게 가리기
- 손잡이 아래 틈은 먼지가 들어가지 않게만 막기
- 안쪽 배터리 덮개는 열 일이 생기니 접착 테이프를 세게 붙이지 않기
테이프가 남으면 끈적임이 번호판에 오래 남습니다. / 마스킹 테이프를 쓰고 며칠 안에 떼는 것이 좋습니다.

# 도어락을 아예 떼고 공사한다면
도장이나 문 교체 때문에 도어락을 잠시 떼야 할 때가 있습니다. / 이때는 임시 잠금 상태를 어떻게 유지할지 먼저 정해야 합니다.
도어락을 떼고 나면 문이 잠기지 않아 빈집 상태가 될 수 있습니다. / 공사 팀이 상주하는 시간과 비는 시간을 나눠 임시 잠금 방법을 생각해야 합니다.
떼어 낸 도어락은 나사와 부속을 한 봉지에 모아 보관하세요. / 다시 달 때 나사가 하나만 빠져도 헐거워지는 경우가 많습니다.
도어락을 떼고 다시 다는 작업은 [도어락 설치](doorlock-install.html) 페이지 내용을 참고하시면 순서를 이해하기 쉽습니다.
@ 수원 금곡동 도어락 탈거 보관 임시 잠금

# 공사 중에 문이 안 열릴 때 가장 많은 사례
공사 기간에 가장 흔한 일은 일하는 분이 문을 닫고 간 뒤 번호를 모르는 사람이 돌아와 못 들어가는 경우입니다. / 또는 보양 필름 때문에 번호판이 반응하지 않기도 합니다.
이럴 땐 보양 필름을 먼저 떼고 번호를 다시 눌러 보세요. / 그래도 안 되면 비상 전원 단자에 9V 건전지를 대 보는 방법이 있습니다.
공사 때문에 소음이 크면 도어락 경고음을 못 듣는 경우도 있습니다. / 경고음이 나는 도어락은 현장에서도 한 번쯤 확인해 주세요.

# 전화하실 때 알려주면 빠른 것들
공사 중인 집은 일반 집과 상황이 다릅니다. / 아래 내용을 알려 주시면 출동 준비가 훨씬 수월합니다.
- 금곡동 어느 건물인지와 층, 호수
- 현관문 앞 통로가 막혀 있지는 않은지
- 도어락을 떼었는지 붙어 있는지
- 번호판이 보양으로 가려져 있는지
- 집 안에 공사 팀이나 사람이 남아 있는지
공사 현장은 자재 때문에 문 앞이 좁은 경우가 많습니다. / 작업할 공간이 있는지 알려 주시면 도착해서 헤매지 않습니다.
@ 금곡동 출장열쇠 공사 현장 현관문 개문 준비

# 사시는 분인지 확인하는 절차는 공사 중에도 같습니다
공사 중이라 집이 어수선해도 문을 여는 일은 같은 절차로 진행합니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나는 꼭 필요합니다.
공사로 세입자나 가족이 다른 곳에 머물고 있다면 계약서나 공사 계약 관련 서류가 도움이 될 수 있습니다. / 어떤 서류가 가능한지 전화로 먼저 물어보세요.
집주인이 공사를 맡기고 현장에 없으면 휴대폰으로 연락해 확인하는 방법을 같이 찾아봅니다. / 확인이 안 되면 작업을 할 수 없는 점은 미리 알려 드립니다.

# 비용은 문 열기 전에 말씀드립니다
공사 중 문을 여는 일도 문 상태와 도어락 종류를 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품 교체가 필요하면 바꾸기 전에 먼저 여쭤봅니다. / 자세한 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 공사가 끝난 뒤 꼭 해야 할 점검
공사가 끝나면 먼저 도어락을 처음 상태로 돌려놓아야 합니다. / 아래 순서로 확인해 보세요.
- 번호판을 닦고 눌렀을 때 소리와 불빛이 정상인지
- 안쪽 손잡이와 보조키가 부드럽게 돌아가는지
- 문을 닫을 때 걸쇠가 문틀 구멍에 정확히 들어가는지
- 임시로 등록한 공사용 번호를 지웠는지
- 배터리 잔량이 충분한지
공사 중 먼지가 들어갔다면 소리가 달라지거나 뻑뻑할 수 있습니다. / 이럴 때는 억지로 쓰지 말고 [도어락 수리](doorlock-repair.html)로 점검받으시는 게 낫습니다.

# 이 기회에 도어락을 바꿀지 생각해 볼 때
리모델링을 하면서 문 색깔이나 분위기가 바뀌면 도어락 교체를 고민하게 됩니다. / 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.
다만 너무 오래돼 잔고장이 잦다면 이때가 교체하기 좋은 시점입니다. / 공사 팀이 있을 때 한꺼번에 하면 문을 두 번 만지지 않아도 됩니다.
어떤 제품을 고를지는 [도어락 교체](doorlock-replace.html) 글에서 확인할 점을 정리해 두었습니다. / 문 두께와 보조키 위치는 사진으로 먼저 보여 주시면 판단이 빠릅니다.

# 금곡동 말고 수원 어디든 갑니다
금곡동뿐 아니라 영통동, 권선동, 광교동, 호매실동, 인계동 등 수원 어디든 출동합니다. / 수원 안이면 동네 상관없이 24시간 전화를 받습니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에서 확인하세요. / 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
