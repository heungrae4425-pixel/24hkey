# 아기방 문이 잠겼다는 걸 알았을 때
광교동은 광교중앙역 주변으로 아이 키우는 가정이 많이 사는 동네입니다. / 그만큼 아기방이나 아이 방 문이 안에서 잠겼다는 연락도 마음이 급한 상황으로 이어지기 쉽습니다.
잠깐 한눈판 사이 문이 닫히고 안쪽 버튼이 눌렸다면, 부모는 가장 먼저 아이 걱정부터 하게 됩니다. / 그럴수록 순서를 지켜 침착하게 움직이는 것이 중요합니다.
이 글은 광교동에서 아기방 문이 안쪽에서 잠겼을 때 확인할 것과 [수원 출장열쇠](suwon.html)에 연락하는 방법을 정리한 것입니다. / 아이가 안에 있는 경우는 일반 문 열기와 다르게 접근해야 합니다.
@ 광교동 아기방 방문 손잡이와 안쪽 잠금 버튼

# 가장 먼저 아이 상태를 확인하세요
문 너머로 아이 이름을 부르며 소리나 움직임이 있는지 들어 봅니다. / 울음소리가 들리면 의식이 있다는 뜻이니 우선 안도하셔도 됩니다.
아무 소리도 없고 이상한 느낌이 든다면 시간을 지체하지 말고 바로 전화하세요. / 필요하다고 판단되면 119에 먼저 연락하는 것이 우선입니다.
아이가 놀라지 않도록 부모는 목소리를 낮추고 평소처럼 말을 걸어 주세요. / 문 앞에서 허둥대는 모습이 보이지 않아도 아이는 분위기를 느낍니다.

# 방문이 잠기는 구조 알아두기
집 안의 방문은 현관문과 달리 단순한 구조인 경우가 많습니다. / 손잡이 가운데나 안쪽에 누름 버튼이나 돌림 버튼이 있는 형태가 흔합니다.
이런 방문은 바깥쪽에 작은 구멍이 있어 가는 도구로 풀 수 있게 만든 경우가 많습니다. / 비상용 해제 구멍이 있는지 손잡이 바깥쪽을 살펴보세요.
다만 구멍이 없거나 구조가 다르면 억지로 시도하다 손잡이가 망가질 수 있습니다. / 그래서 아이가 안에 있을 때는 더 신중해야 합니다.

# 아이가 말을 알아듣는 나이라면
아이가 말을 어느 정도 알아듣는 나이라면 문 너머로 직접 알려줄 수 있습니다. / 손잡이 가운데 동그란 버튼을 반대로 돌려 보라고 천천히 안내하는 방법입니다.
그림이나 모양으로 설명해 주면 이해하기 쉽습니다. / 버튼을 한 번 누르거나 돌리면 철컥 소리가 난다는 식으로 소리로 설명해 보세요.
아이가 짜증을 내거나 울기 시작하면 중단하고 잠깐 숨을 고르게 하세요. / 억지로 시키면 오히려 버튼을 더 단단히 건드릴 수 있습니다.

# 아직 말을 못 하는 아기라면
돌 전후의 아기가 방 안에 있을 때는 안내가 불가능합니다. / 이때는 안쪽 사람이 문을 풀어줄 수 없으니 밖에서 열어야 합니다.
방 안에 침대나 이불처럼 아기가 안전하게 있는 공간인지 떠올려 보세요. / 위험한 물건이 닿는 곳인지 판단하는 데도 도움이 됩니다.
혼자 열려고 문틈에 도구를 넣거나 손잡이를 흔드는 일은 삼가세요. / 소리가 커지면 아기가 놀라 울어서 상황이 더 긴박해집니다.

# 하지 말아야 할 행동
문을 어깨로 밀거나 발로 차서 여는 방법은 위험합니다. / 문이 갑자기 열리며 안쪽 아이에게 부딪힐 수 있고, 문과 문틀도 크게 망가집니다.
카드나 칼로 문틈을 벌리는 것도 피해 주세요. / 방문 손잡이가 상하면 나중에 수리 범위가 넓어집니다.
창문으로 베란다를 통해 들어가려는 시도도 권하지 않습니다. / 낮은 층이 아니라면 매우 위험합니다.
@ 광교동 방문 비상 해제 구멍에 가는 도구를 넣는 방법 설명

손잡이 바깥쪽에 작은 구멍이 있다면 가는 막대로 풀 수 있는 구조일 수 있습니다. / 구멍 모양이 일자인지 점 모양인지에 따라 쓰는 도구가 다릅니다.
같은 집에 방문 열쇠 모양 도구가 따로 있을 수 있으니 서랍을 한번 찾아 보세요. / 입주할 때 받은 작은 도구가 어딘가에 있는 경우가 많습니다.
돌려 보다 안 풀리면 억지로 힘을 주지 마세요. / 부품이 휘면 일반 해제도 어려워집니다.

# 전화하실 때 꼭 알려주실 것
아이가 안에 있는 상황이라는 점을 가장 먼저 말씀해 주세요. / 출동 준비와 대응 방법이 달라집니다.
- 광교동 어느 쪽인지, 광교중앙역 방향 등 대략 위치
- 아이 나이와 지금 들리는 소리
- 방문 손잡이 모양과 비상 구멍 유무
- 방문이 잠긴 지 얼마나 됐는지
- 현관문은 열려 있는지
방문 손잡이를 사진으로 보내주시면 맞는 장비를 챙기기 쉽습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
아이가 안에 있어 마음이 급하시더라도 이 절차는 꼭 거칩니다. / 신분증이 같은 방 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다.
확인이 어려우면 작업을 할 수 없으니 가능한 한 미리 챙겨 두세요.

# 최대한 안 상하게 엽니다
방문은 손잡이를 분해하지 않고 여는 방법부터 시도합니다. / 아이가 놀라지 않게 큰 소리가 나지 않는 방법을 먼저 고릅니다.
문이 열리면 아이 상태를 먼저 보시고 안아 주세요. / 그 뒤에 손잡이와 문 상태를 함께 확인합니다.
방문 개방은 [현관문 개문](door-open.html)과 구조가 달라 작업 방식도 다릅니다. / 필요하다면 현장에서 어떤 방법을 쓰는지 미리 설명해 드립니다.
@ 광교동 방문 손잡이 비파손 개방 작업

# 비용은 문 열기 전에 말씀드립니다
방문 구조를 보고 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
손잡이를 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 난 뒤 잠금장치를 다시 살펴보세요
아이가 쉽게 건드리는 높이에 잠금 버튼이 있는 방문이라면 구조를 점검하는 편이 좋습니다. / 안에서 잠겨도 바깥에서 쉽게 풀 수 있는 형태로 바꾸는 것도 방법입니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 필요하면 [도어락 교체](doorlock-replace.html)를 안내해 드립니다.
아이 방 문에는 잠금 기능이 없는 손잡이를 쓰는 집도 많습니다. / 가족 사정에 맞춰 상담해 드립니다.

# 같은 일을 막는 집안 습관
아이가 방에 있을 때 방문 안쪽 버튼을 만지지 못하게 해 두면 좋습니다. / 문 아래쪽이나 높은 위치로 잠금 위치를 바꿀 수 있는지 살펴보세요.
- 방문 비상 해제 도구를 눈에 띄는 곳에 보관
- 아이가 문을 닫고 노는 습관이 생기면 잠금 버튼 확인
- 가족 모두가 비상 해제 방법을 알아 두기
- 문이 덜 닫히거나 삐걱거리면 미리 점검
작은 준비가 한밤중의 다급한 상황을 막아 줍니다.

# 광교동 말고 수원 어디든 갑니다
광교동 바로 옆 영통동, 원천동, 매탄동을 포함해 수원 안이면 다닙니다. / 24시간 출동합니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

? 방문 손잡이가 망가지나요? | 손잡이를 상하지 않게 여는 방법부터 시도하고, 부품을 바꿔야 하면 먼저 여쭙습니다.
? 아기가 이상할 정도로 조용하면 어떻게 하나요? | 지체하지 말고 119에 먼저 연락하시고, 저희에게도 상황을 알려 주세요.
