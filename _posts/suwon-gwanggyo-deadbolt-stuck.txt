# 광교동에서 잠금 빗장이 안 움직일 때
광교동은 광교중앙역과 호수공원 주변으로 비교적 새 아파트와 오피스텔, 상가가 이어지는 동네입니다. / 도어락 기능은 좋은데 문과 문틀 사이가 미세하게 틀어지는 일이 생기기도 합니다.
번호를 누르면 모터 소리는 나는데 문이 안 열리거나, 문을 닫아도 잠금 빗장이 안 튀어나오는 일이 있습니다. / 데드볼트라고 부르는 이 빗장이 문틀 구멍에 걸려 문을 단단히 잠급니다.
이 글은 광교동에서 데드볼트가 안 들어가거나 안 빠질 때 직접 확인할 것과 [수원 출장열쇠](suwon.html)의 진행 순서를 적었습니다. / 문이 잠긴 채 안 열릴 때에도 도움이 됩니다.
@ 광교동 출장열쇠 데드볼트 점검

# 데드볼트가 하는 일
현관문 옆면에는 두 종류의 걸쇠가 있습니다. / 손잡이로 여닫는 둥근 걸쇠와, 잠글 때 길게 튀어나오는 네모난 데드볼트입니다.
데드볼트는 문을 잠글 때만 나와서 문틀 구멍에 깊게 박히는 장치입니다. / 문이 열려 있을 때는 들어가 있고 닫힌 뒤 잠글 때 나옵니다.
이 빗장이 문틀 구멍과 어긋나면 나오지 않거나, 나오더라도 들어가지 않는 일이 생깁니다. / 문이 열려 있을 때만 나오는지 닫혀 있을 때도 나오는지가 원인을 가르는 단서입니다.

# 이런 증상이 있을 때
- 문을 열어 둔 상태에서 잠금을 누르면 빗장이 나오는데 닫으면 안 걸리는 경우
- 번호를 눌렀는데 소리만 나고 빗장이 안 들어가는 경우
- 문을 닫을 때 빗장이 문틀에 부딪히는 소리가 나는 경우
- 잠글 때마다 문을 들어 올리거나 밀어야 잠기는 경우
네 번째 증상은 문이 처져서 빗장과 구멍이 어긋난 신호입니다. / 그대로 쓰면 구멍 주변과 빗장이 닳아서 점점 더 안 맞게 됩니다.
문을 열어 두고 잠금 장치를 눌렀을 때 빗장이 잘 나온다면 도어락은 정상이고 문 쪽이 원인입니다. / 이 구분만으로 원인의 절반은 좁혀집니다.
@ 수원 광교 문틀 받이 구멍 확인

# 문틀 받이 구멍이 어긋나는 이유
문과 문틀 사이는 계절 변화와 건물 진동으로 조금씩 움직입니다. / 몇 년 지나면 처음 맞춘 위치에서 몇 밀리미터씩 벗어나는 일이 흔합니다.
경첩 나사가 풀려 문이 아래로 처지면 빗장 위치가 같이 내려옵니다. / 빗장은 정확히 구멍에 들어가야 하니 작은 차이에도 걸립니다.
입주 직후에는 새 건물이 안정되면서 문틀이 미세하게 움직이기도 합니다. / 새 아파트라도 문 맞춤이 한두 번 필요한 경우가 있습니다.

# 직접 해볼 수 있는 간단한 확인
문을 닫은 상태에서 손잡이를 잡고 문을 위로 살짝 들어 올리듯 밀어 보세요. / 이때 잠금이 되거나 열린다면 문이 처진 것이 원인입니다.
문틀 받이 구멍의 위치를 눈으로 보고, 빗장 자국이 구멍 가운데에 남아 있는지 봅니다. / 자국이 구멍 한쪽 끝에 몰려 있으면 위치가 어긋났다는 뜻입니다.
빗장에 연필 가루를 묻혀 문을 닫았다가 열어 보면 닿는 위치가 구멍 어디인지 알 수 있습니다. / 사진을 찍어 두시면 출장 상담에도 도움이 됩니다.

# 해서는 안 되는 것
빗장이 안 들어가는데 문을 세게 밀어 열면 빗장이나 받이가 휘고 문틀이 갈라질 수 있습니다. / 이미 걸려 있다면 힘보다 각도를 바꾸는 방법이 낫습니다.
문틈에 얇은 도구를 넣어 빗장을 밀어 넣는 방법은 도어락 외관과 문틀을 상하게 합니다. / 열리더라도 나중에 보수 비용이 더 들 수 있습니다.
도어락 모터가 작동하는 중에 손잡이를 강제로 잡고 돌리면 모터 기어가 상합니다. / 기어가 상하면 부품 교체가 필요해집니다.

# 모터 소리는 나는데 안 열릴 때
번호를 누르면 윙 하고 모터 소리가 나는데 빗장이 안 움직이면 두 가지를 의심합니다. / 하나는 빗장이 문틀에 눌려 있는 경우, 다른 하나는 모터와 빗장을 잇는 부품이 빠진 경우입니다.
문에 체중을 싣지 않은 상태에서 번호를 눌러 보세요. / 문틀에 눌려 있던 경우에는 이때 열리기도 합니다.
그래도 안 열리면 안쪽 부품 문제일 수 있으니 억지로 반복하지 않는 것이 좋습니다. / 모터를 계속 돌리면 배터리도 빨리 닳고 부품도 상합니다.

# 광교동에서 부르시면 이렇게 점검합니다
먼저 문을 열고 닫아 보며 빗장이 어디에서 걸리는지 봅니다. / 문 처짐인지, 받이 위치인지, 도어락 내부인지부터 구분합니다.
문틀 받이를 아주 조금 옮기거나 경첩 나사를 조여 위치를 맞추는 것으로 끝나는 일이 많습니다. / 도어락 쪽 부품이 원인이면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
부품이 너무 낡아 수리가 어렵다면 [도어락 교체](doorlock-replace.html)를 설명드립니다. / 바꾸기 전에는 꼭 먼저 여쭤봅니다.

# 사시는 분 확인은 먼저 합니다
문을 여는 일이 포함되기 때문에 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우시더라도 이웃과 집 주인 모두를 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 시작하기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 24시출장열쇠 광교동 도어락 점검

# 고친 뒤 확인하는 것
빗장이 나왔다 들어가는 동작을 여러 번 반복해서 부드러운지 확인합니다. / 문을 세게 닫았을 때와 천천히 닫았을 때 모두 잠기는지 봅니다.
받이 구멍과 빗장이 가운데에서 만나는지 연필 가루로 한 번 더 확인합니다. / 위치가 맞으면 소리도 훨씬 조용해집니다.
번호 입력과 열쇠 두 가지 방식 모두로 열리는지 같이 확인합니다. / 한쪽만 되면 다시 손봅니다.

# 데드볼트 문제를 줄이는 습관
문을 닫을 때 항상 끝까지 닫힌 뒤에 잠금을 누르는 습관이 좋습니다. / 덜 닫힌 상태에서 잠그면 빗장과 받이가 부딪혀 닳습니다.
택배나 짐을 문에 기대어 두지 마세요. / 문틀이 조금씩 눌려서 위치가 변합니다.
문이 한쪽으로 처진 느낌이 들면 조기에 경첩 나사를 조여 두세요. / 처진 채로 오래 쓰면 빗장 주변이 눈에 띄게 닳습니다.

# 광교동 말고 수원 어디든 갑니다
광교동 바로 옆 원천동, 이의동, 영통동, 매탄동도 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
수원에서 다니는 동네는 [수원 출장열쇠](suwon.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
