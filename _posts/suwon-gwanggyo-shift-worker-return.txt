# 모두가 잠든 시간에 현관 앞에 선 사람
광교중앙역에서 내려 광교동 집까지 걸어오는 새벽길은 조용합니다. / 교대근무나 야근이 많은 분들에게 현관 앞은 하루를 마무리하는 마지막 관문입니다.
이 시간에 도어락이 말썽을 부리면 연락할 곳도, 도움을 청할 이웃도 마땅치 않습니다. / 소리를 내는 것도 조심스러워 더 막막해집니다.
이 글은 교대근무자나 새벽에 귀가하는 분들이 도어락을 쓰면서 알아 두면 좋은 점을 적었습니다. / 소음을 줄이는 법, 평소 점검 요령, 문 앞에서 막혔을 때의 순서까지 담았습니다.
@ 광교동 새벽 귀가 도어락 사용 요령

# 새벽 귀가가 도어락에 주는 부담
밤새 일하고 돌아오는 사람은 졸음과 피로로 평소보다 실수를 많이 합니다. / 번호를 틀리거나 문을 쾅 닫거나 열쇠를 어디 뒀는지 잊는 일이 생깁니다.
이런 작은 실수가 반복되면 도어락에 불필요한 부담이 쌓입니다. / 반대로 사용 습관을 몇 가지만 다듬어도 고장 가능성이 크게 줄어듭니다. / 특별한 장비 없이 오늘 밤부터 바로 할 수 있는 것들만 모았습니다.
특히 새벽에는 소음이 크게 들리므로 이웃을 배려하는 설정도 중요합니다.

# 도어락 소리를 줄이는 방법
대부분의 도어락은 버튼음과 열림음의 크기를 조절할 수 있습니다. / 설정 메뉴에서 소리를 낮추거나 끄면 새벽 귀가가 한결 조용해집니다.
다만 경고음까지 끄면 배터리 부족 알림을 놓칠 수 있습니다. / 일반 버튼음만 줄이고 경고음은 살려 두는 것이 안전합니다.
설정 방법은 제품마다 다르니 설명서를 보거나 상담을 받아 보세요. / 사진을 보내 주시면 어떤 버튼으로 들어가는지 알려 드립니다.

# 문을 살살 닫는 습관이 문을 오래 씁니다
피곤한 상태에서는 문을 손으로 놓아 버리는 일이 많습니다. / 도어클로저가 있는 문이라도 끝까지 닫힐 때까지 손으로 받쳐 주면 소리가 훨씬 줄어듭니다.
문이 쾅 닫히면 경첩과 문틀, 도어락 내부 부품에 충격이 쌓입니다. / 또한 복도 전체에 소리가 울려 이웃에게 방해가 됩니다.
작은 습관이지만 문 수명과 이웃과의 관계에 모두 도움이 됩니다. / 문 아래에 소리를 줄이는 고무 범퍼가 붙어 있다면 떨어지지 않았는지도 가끔 보세요.

# 배터리는 새벽에 꺼지기 쉽습니다
배터리가 약해지면 가장 먼저 반응이 느려지는 때는 소리가 조용한 한밤입니다. / 평소에 경고음을 놓치면 어느 날 새벽에 번호판이 꺼져 있는 일을 겪게 됩니다.
경고음이 나기 시작하면 그날 안에 배터리를 바꾸는 것이 원칙입니다. / 남은 건전지로 며칠 더 쓸 수 있다고 미루다 낭패를 보는 분이 많습니다.
교대 근무표에서 쉬는 날을 확인해서 그날 배터리를 교체하도록 달력에 적어 두세요. / 해가 바뀔 때 한 번에 전부 갈아 두는 방법이 가장 단순합니다. / 일부만 바꾸면 낡은 것이 먼저 힘이 빠져 같은 일이 되풀이됩니다.
@ 광교동 도어락 배터리 교체 시점 점검

# 비상 전원을 꼭 가방에 넣어 두세요
번호판이 꺼졌을 때 9V 건전지를 바깥 단자에 대면 임시로 번호를 누를 수 있는 제품이 많습니다. / 새벽에는 편의점이 멀 수도 있으니 미리 하나 챙겨 두는 것이 좋습니다.
건전지는 직사광선이 드는 차 안보다 가방 속이 낫습니다. / 사용하고 나면 새것으로 다시 채워 두세요.
단자가 없는 제품이라면 열쇠 구멍이 있는지, 보조 열쇠를 어디 두는지 알아 두세요. / 보조 열쇠는 집 안 서랍에만 두지 말고 믿을 만한 가족에게도 하나 맡겨 두면 좋습니다.

# 번호판이 어두워 잘못 누르는 일 줄이기
새벽엔 번호판이 어두워 숫자를 잘 못 누르는 일도 있습니다. / 번호판에 불이 들어오는 위치를 손으로 먼저 덮어 보는 것도 방법입니다.
번호를 눌러도 반응이 없으면 손가락 끝에 땀이나 물기가 있는지 확인하세요. / 손을 한 번 닦고 다시 누르는 것만으로 되는 경우가 많습니다.
계속 안 되면 서두르지 말고 몇 분 멈췄다가 다시 해 보세요. / 여러 번 틀리면 도어락이 입력을 한동안 막는 기능이 켜지는 제품도 있습니다. / 졸린 상태에서 연달아 누르면 오히려 잠금 시간이 길어지니 한 박자 쉬세요.

# 문 앞에서 막혔을 때 전화하는 요령
한밤에 문 앞에서 통화하면 복도에 소리가 울려 이웃에게 방해가 될 수 있습니다. / 가능하면 로비나 계단 쪽으로 이동해 조용히 통화하세요.
위치는 건물 이름, 동, 호수, 광교중앙역 방향인지를 말씀해 주시면 빠릅니다. / 24시간 전화를 받으니 시간은 걱정하지 마세요. / 새벽이라고 미안해하실 필요 없이 편하게 연락 주세요.
번호판 상태와 최근 배터리 교체 시기를 알려 주시면 준비가 쉬워집니다.

# 이런 상황은 한밤에도 바로 불러 주세요
- 번호판이 켜지지 않고 비상 전원으로도 열리지 않을 때
- 번호는 맞는데 모터 소리만 나고 걸쇠가 빠지지 않을 때
- 보조키를 잠근 채 문을 닫고 나온 것 같을 때
- 집 안에 아이나 반려동물이 혼자 있을 때
특히 집 안에 아이가 있다면 지체하지 말고 알려 주세요. / 시간대는 상관없이 같은 기준으로 움직입니다. / 한밤에 출동하더라도 소리를 최대한 줄여 작업하고 이웃에게 방해가 가지 않게 합니다.

# 도착하면 사시는 분인지부터 확인합니다
한밤이라도 문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 경비실에 먼저 말해 두면 수월합니다. / 이웃과 건물 모두를 위한 절차이니 양해 부탁드립니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 동의하실 때만 시작하며, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않고, 열고 난 뒤에 말없이 붙는 비용도 없습니다. / 안내 방식은 [이용안내](guide.html)에 정리했습니다.
조용히 열 수 있는 방법을 먼저 쓰고, 개문 방식은 [현관문 개문](door-open.html)에 적었습니다.

# 열린 뒤에는 피곤한 사람을 위한 설정으로
문이 열리면 비밀번호를 외우기 쉬운 것으로 바꾸고 싶은 경우가 많습니다. / 피곤할 때도 손이 기억하는 번호가 좋습니다.
자동 잠금 시간을 조금 늦추는 설정을 원하는 분도 계시니 상황을 말씀해 주세요. / 소리 설정과 배터리 상태도 같이 정리해 드립니다.
고장 부위가 보이면 [도어락 수리](doorlock-repair.html)로 고쳐서 쓰도록 먼저 권하고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 설명합니다.
@ 광교동 24시 출장열쇠 새벽 개문 후 점검

# 광교동 말고 수원 어디든
광교동 옆 원천동, 영통동은 물론 수원 전 지역을 다닙니다. / 광교중앙역, 수원역, 영통역, 성균관대역 근처도 같은 방식입니다.
다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 있고, 다른 지역은 [출장 지역](area.html)에서 보세요.

# 자주 묻는 질문
? 새벽 두세 시에도 오나요? | 24시간 전화를 받고 출동합니다.
? 도어락 소리를 끄고 싶은데 괜찮나요? | 버튼음은 줄여도 되지만 배터리 경고음은 살려 두는 것이 안전합니다.
? 비상 건전지는 어떤 걸 쓰나요? | 많은 제품이 9V 건전지를 씁니다. 제품마다 다르니 사진을 보내 주시면 확인해 드립니다.
? 못 열면 비용을 내나요? | 못 열면 비용은 받지 않습니다.
? 신분증이 집 안에 있으면요? | 관리사무소나 경비실에서 세대 확인을 받을 수 있는지 알아봐 주세요.
