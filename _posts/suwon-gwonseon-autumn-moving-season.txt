# 가을은 이삿짐센터만큼 도어락도 바쁜 계절입니다
날이 선선해지면 권선동에서도 이사 일정이 몰립니다. / 수원역을 오가는 직장인, 학교 따라 옮기는 가족까지 비슷한 시기에 짐을 쌉니다.
이삿날은 하루에 많은 일이 겹치기 때문에 도어락 문제가 터지면 일정 전체가 흔들립니다. / 그래서 이사 날짜를 잡을 때 도어락 일정도 같이 넣어 두면 훨씬 편합니다.
이 글은 권선동 이사철에 도어락을 언제, 무엇부터 챙기면 좋은지 날짜 순서로 풀어 썼습니다. / 이미 이사 당일이라면 뒤쪽 비상 대처 부분을 먼저 보셔도 됩니다.
@ 권선동 이사철 도어락 점검 출장열쇠

# 이사 2주 전 해야 할 일
달력에 이사 날짜를 적었다면 그 2주 전쯤 새 집 도어락을 먼저 확인합니다. / 집주인이나 부동산을 통해 방문 일정을 잡을 수 있으면 가장 좋습니다.
- 도어락 종류가 번호키, 카드키, 열쇠 중 무엇인지
- 보조키가 따로 달려 있는지
- 전 입주자 비밀번호가 그대로 남아 있을 가능성
- 배터리가 새것인지, 마지막으로 바꾼 때가 언제인지
이 네 가지만 알아도 이삿날 놀랄 일이 크게 줄어듭니다. / 확인이 어려우면 사진으로라도 받아 두세요.

# 이삿날 아침에 도어락이 먼저 열려야 합니다
짐이 먼저 도착해 놓고 문이 안 열려 기다리는 상황이 가장 곤란합니다. / 이삿짐 팀은 시간이 곧 일정이어서 대기 시간이 길어지면 모두 지칩니다.
이삿날 한두 시간 일찍 새 집에 가서 문부터 열어 보세요. / 배터리 상태, 비밀번호, 카드키를 미리 시험해 두면 짐이 도착했을 때 바로 들어갑니다.
번호가 안 맞거나 반응이 없으면 그 시간에 해결할 여유가 생깁니다. / 일찍 가는 것만으로도 절반은 해결된다고 보시면 됩니다.

# 입주하면서 비밀번호를 새로 만드는 순서
전 입주자가 쓰던 번호는 반드시 지우고 새 번호로 바꿔야 합니다. / 이전 번호를 누가 아는지 알 수 없기 때문입니다.
- 안쪽 설정 버튼으로 등록 모드에 들어가기
- 기존 번호와 카드키를 전부 삭제하기
- 새 번호를 정하고 한 번 더 확인해 보기
- 가족 구성원에게 새 번호를 알리고 시험해 보기
제품마다 설정 방법이 달라 안내음이 나오는 대로 따라가야 합니다. / 설명서가 없으면 제조사명과 모델명 사진을 보여 주시면 순서를 안내합니다. 자세한 내용은 [도어락 설치](doorlock-install.html) 글도 참고하세요.

# 열쇠를 몇 개 받았는지 세어 두기
도어락에 보조키나 비상 열쇠가 있다면 몇 개를 받았는지 확인해 둡니다. / 전 입주자가 복사해 둔 열쇠가 있는지도 같이 물어보세요.
복사본이 어디 있는지 알 수 없다면 열쇠 구멍 부분만 교체하는 방법도 있습니다. / 전체 도어락을 바꾸지 않고도 불안을 줄일 수 있는 방법입니다.
이삿날 정신이 없어 열쇠를 짐 상자에 넣어 버리는 일이 의외로 잦습니다. / 현관 열쇠는 상자에 넣지 말고 몸에 지니고 계세요.
@ 수원 권선동 입주 도어락 비밀번호 재설정

# 이사 나가는 집에서 챙길 것
나가는 집도 그냥 비워 두면 안 됩니다. / 내 번호를 지우지 않은 채 나오면 나중에 걱정이 남습니다.
나가기 전에 등록한 비밀번호와 카드키를 모두 삭제하고, 받은 열쇠와 카드는 전부 돌려주는 것이 좋습니다. / 배터리를 빼서 가져가면 안 되고, 도어락은 집에 설치된 그대로 두는 것이 일반적입니다.
임대차 관련해서 누가 무엇을 부담하는지는 계약마다 달라서 여기서 단정하기 어렵습니다. / 애매한 부분은 계약서와 집주인과의 대화로 정리하시고, 우리는 현재 상태 확인만 도와드립니다.

# 이삿날 문이 안 열릴 때 비상 대처
당일에 문이 안 열리면 먼저 숨을 고르세요. / 급하게 힘을 쓰면 오히려 더 상합니다.
번호판이 꺼져 있으면 비상 단자에 9V 건전지를 대 보세요. / 번호를 모르면 부동산이나 집주인에게 연락해 전달받은 번호가 맞는지 다시 확인합니다.
손잡이가 걸리는 느낌이 있으면 문을 살짝 밀면서 돌려 보고, 그래도 안 되면 전화 주세요. / 이삿짐 팀이 기다리고 있다면 상황을 먼저 알려 두시면 서로 편합니다.

# 권선동에서 출장을 부를 때 위치 알려주는 법
권선동은 주택가와 대로변이 섞여 있어 건물을 찾기 어려운 경우가 있습니다. / 아래 정보를 알려 주시면 도착이 빨라집니다.
- 건물 이름 대신 길 이름이나 가까운 역, 큰 건물 기준 위치
- 층과 호수
- 이삿짐 차량이 세워진 곳
- 도어락 모양과 번호판 상태
- 이삿짐 팀이 대기 중인지 여부
이삿날에는 주차 자리가 부족합니다. / 차를 세울 곳을 알려 주시면 시간이 덜 걸립니다.
@ 권선동 이삿날 출장열쇠 현관문 개방 위치 안내

# 문 열기 전 신분 확인이 필요합니다
이사 직후에는 아직 집 안에 서류가 없는 경우가 많습니다. / 그래도 문을 열려면 사시는 분인지 확인이 필요합니다.
신분증에 새 주소가 없다면 계약서, 입주 안내문, 새 주소가 적힌 우편물이 도움이 됩니다. / 관리사무소가 있는 건물이면 입주 확인을 부탁하는 방법도 있습니다.
확인이 어려우면 작업할 수 없지만 어떤 서류가 가능한지는 전화로 미리 알려 드립니다.

# 비용은 문 열기 전에 먼저 안내합니다
이사철에는 문 열기와 번호 재설정, 교체를 한꺼번에 부탁하는 분들이 많습니다. / 필요한 일을 전부 살펴본 뒤 하나씩 비용을 먼저 말씀드립니다.
모두 맡기지 않아도 되고, 필요한 것만 골라 하셔도 됩니다. / 문을 끝내 열지 못하면 비용은 받지 않습니다.
부품을 바꿔야 한다면 바꾸기 전에 먼저 여쭤봅니다. / 과정은 [이용안내](guide.html)에서 확인할 수 있습니다.

# 교체와 수리 중 무엇이 나을지
입주하는 집 도어락이 오래돼 보여도 바로 바꿀 필요는 없습니다. / 작동이 부드럽고 소리가 정상이면 번호만 재설정해도 충분합니다.
작동이 불안하거나 부품이 없어진 제품이라면 [도어락 교체](doorlock-replace.html)를 고민할 때입니다. / 반대로 일부만 고장이라면 [도어락 수리](doorlock-repair.html)로 해결되는 경우가 많습니다.
어느 쪽이 맞을지는 현장에서 직접 눌러 보고 말씀드립니다. / 무리한 교체를 권하지 않습니다.

# 이사 마치고 일주일 안에 하면 좋은 일
짐을 푸는 동안에도 현관은 계속 쓰입니다. / 첫 주에 아래 일을 해 두면 오래 편합니다.
- 가족 모두가 새 번호를 정확히 아는지 시험하기
- 안쪽 배터리 교체 날짜를 적어 두기
- 문이 덜 닫히거나 걸리는 소리가 없는지 확인하기
- 택배 기사나 이사 도우미에게 알려 준 번호가 있다면 지우기
이 정도만 해도 이사 직후 흔한 사고를 막을 수 있습니다. / 불안하면 언제든 전화로 물어보세요.

# 권선동 말고 수원 어디든 갑니다
권선동 외에도 세류동, 인계동, 영통동, 광교동, 호매실동까지 수원 전역으로 출동합니다. / 수원 안이면 동네 상관없이 24시간 전화를 받습니다.
다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리했고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
