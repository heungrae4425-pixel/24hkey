# 권선동 여름철 현관문이 뻑뻑할 때
권선동은 수원 서쪽으로 아파트 단지와 빌라, 오래된 주택이 이어지는 넓은 동네입니다. / 오래된 건물이 많아서 계절이 바뀔 때마다 문 상태가 달라지는 일이 흔합니다.
여름이 되면 문이 뻑뻑해져서 잘 안 닫히거나 닫아도 걸쇠가 안 걸리는 일이 생깁니다. / 겨울에는 멀쩡하던 문이 갑자기 이러면 고장이 났다고 생각하기 쉽습니다.
이 글은 권선동에서 더위와 습기 때문에 현관문이 뻑뻑할 때 확인할 것과 [수원 출장열쇠](suwon.html)의 점검 순서를 정리했습니다. / 계절 때문에 생기는 문제라 시기를 알면 대처가 쉽습니다.
@ 권선동 출장열쇠 여름 현관문 점검

# 여름에 문이 뻑뻑해지는 이유
문은 나무나 철, 합판 등으로 만들어지고 습기와 열을 받으면 조금씩 부풀거나 늘어납니다. / 몇 밀리미터 차이라도 문과 문틀 사이가 빡빡해지면 닫기가 어려워집니다.
장마철에는 공기 중 습기가 많아 문틀 목재가 부풀어 문과 부딪힙니다. / 아래쪽이나 걸쇠가 닿는 쪽이 특히 잘 걸립니다.
오래된 문은 겉에 칠한 페인트가 두꺼워져 틈이 더 줄어든 경우도 있습니다. / 여러 번 덧칠한 문일수록 여름에 더 잘 걸립니다.

# 이런 증상이면 습기와 열 때문일 수 있습니다
- 여름과 장마철에만 문이 뻑뻑하다가 건조한 계절에는 괜찮은 경우
- 문을 닫을 때 위쪽이나 아래쪽 모서리가 문틀에 스치는 경우
- 걸쇠가 받이 구멍에 들어가려다 걸리는 경우
- 열쇠나 번호는 맞는데 문이 안 열리고 힘을 줘야 열리는 경우
이런 증상이 며칠 지속되다 건조한 날 다시 좋아진다면 계절의 영향이 큽니다. / 해마다 같은 시기에 반복된다면 문 자체를 한 번 손봐 두는 것이 좋습니다.
@ 수원 권선동 문틀 습기 점검

# 직접 확인해 볼 수 있는 것
문을 닫고 문과 문틀 사이의 틈 간격을 위, 가운데, 아래에서 살펴보세요. / 어느 한 곳이 유독 좁다면 그 곳이 걸리는 자리입니다.
문틀 모서리에 문이 스친 자국이나 벗겨진 페인트가 있는지도 보세요. / 자국이 있는 자리가 바로 닿는 곳입니다.
제습기나 에어컨을 켜서 습도를 낮추면 문이 조금 나아지는지 확인해 보세요. / 습도에 따라 상태가 달라지면 계절 영향이 확실합니다.

# 해서는 안 되는 것
문이 안 닫힌다고 문을 힘으로 세게 닫으면 경첩과 문틀이 같이 상합니다. / 한 번 처지기 시작한 문은 계속 더 처집니다.
문 가장자리를 칼이나 사포로 갈아 내는 방법은 되돌릴 수 없습니다. / 계절이 지나면 틈이 너무 커질 수 있으니 신중해야 합니다.
윤활제를 걸쇠 주변에 많이 뿌리면 먼지가 엉겨서 오히려 더 뻑뻑해집니다. / 경첩 핀에만 아주 조금 쓰는 정도가 적당합니다.

# 걸쇠가 안 걸리는 경우
습기로 문틀이 부풀면 받이 구멍과 걸쇠 높이가 어긋나 문이 닫혀도 걸리지 않는 일이 있습니다. / 이때는 문이 살짝 열려 있는 채로 닫혔다고 착각하기 쉽습니다.
잠금 상태가 불완전하면 방범에도 좋지 않아 그날 안에 점검하는 것이 좋습니다. / 걸쇠가 문틀에 충분히 들어갔는지 확인해 주세요.
문을 닫고 손잡이를 당겨 봤을 때 약간이라도 열리면 완전히 걸린 것이 아닙니다. / 이럴 때는 받이 위치를 조정하는 것으로 해결되는 경우가 많습니다.

# 권선동에서 부르시면 이렇게 점검합니다
먼저 문을 여닫으며 어디에서 닿고 걸리는지 확인합니다. / 경첩 나사, 문틀 받이, 걸쇠 위치를 차례로 봅니다.
받이를 조금 옮기거나 경첩을 조이는 것으로 해결되면 그 자리에서 마무리합니다. / 문틀 자체가 많이 부풀었다면 임시로 어떻게 쓸지, 계절이 지나 어떻게 할지 설명드립니다.
도어락이 같이 말썽이면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 24시출장열쇠 권선동 문틀 받이 조정

# 사시는 분 확인은 먼저 합니다
문을 만지는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 이웃과 집 주인 모두를 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 시작하기 전에 말씀드립니다
문 상태와 필요한 작업을 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문이 잠겨 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 손본 뒤 확인하는 것
문을 여러 번 닫아 보며 걸쇠가 부드럽게 걸리는지 확인합니다. / 위아래 틈 간격이 고르게 맞는지도 봅니다.
습도가 높은 날과 낮은 날 모두 괜찮을 정도로 여유를 두고 맞춥니다. / 너무 딱 맞추면 다음 장마에 다시 걸립니다.
도어락과 열쇠로 잠그고 여는 동작이 모두 정상인지 같이 확인합니다. / 한쪽만 되면 다시 손봅니다.

# 계절을 타는 문을 오래 쓰는 방법
장마가 오기 전에 경첩 나사를 한 번 조이고 문틀 틈을 살펴보세요. / 미리 맞춰 두면 장마철 내내 편합니다.
문 아래쪽 바닥에 물이 고이거나 젖어 있지 않은지도 보세요. / 문 하단이 젖으면 문 재질이 부풀어 더 심해집니다.
에어컨이나 제습기로 집 안 습도를 적당히 유지하면 문도 덜 변합니다. / 문틀이 나무로 된 집일수록 효과가 큽니다.

# 오래된 주택은 더 자세히 봅니다
권선동 오래된 주택은 문틀이 나무이거나 문 자체가 무거운 철문인 경우가 많습니다. / 이런 문은 한 번 처지면 경첩만 조여서는 해결되지 않을 때가 있습니다.
경첩 위치를 조금 옮기거나 보강 부품을 쓰는 방법도 현장에서 설명드립니다. / 문 전체를 바꾸지 않고 맞추는 방법을 먼저 찾아봅니다.

# 권선동 말고 수원 어디든 갑니다
권선동 바로 옆 세류동, 곡반정동, 서둔동, 호매실동도 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
수원에서 다니는 동네는 [수원 출장열쇠](suwon.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
