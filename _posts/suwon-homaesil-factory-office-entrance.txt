# 사무동 문은 집 현관과 다르게 생각해야 합니다
호매실동은 수원역 방면으로 오가는 분들의 생활권이면서 작은 사업장이 있는 곳도 있는 동네입니다. / 공장이나 작업장 한쪽에 사무동을 두고 출입문을 따로 쓰는 곳이 있습니다.
이런 문은 집 현관과 달리 여러 사람이 드나들고, 퇴근 뒤에는 잠그고, 아침에 열어야 하는 사람이 정해져 있습니다. / 그래서 문제가 생기면 누가 열 권한이 있는지부터 따져야 합니다.
이 글은 공장 사무동 출입문이 안 열리거나 야간에 잠겨 곤란할 때의 확인 순서를 정리했습니다. / 도움이 필요하면 [수원 출장열쇠](suwon.html)로 연락 주세요.

# 이런 상황이 자주 생깁니다
사무동 출입문에서 생기는 일은 주택과 겹치면서도 조금씩 다릅니다. / 아래는 대표적인 경우입니다.
- 야근하고 나오며 문을 닫았는데 열쇠나 카드를 안에 둔 경우
- 아침에 출근했더니 번호판이 꺼져 있는 경우
- 담당자가 번호를 바꿨는데 다른 직원이 모르는 경우
- 출입 카드가 갑자기 인식되지 않는 경우
- 문이 덜 닫혀 야간에 잠금이 풀린 것 같아 불안한 경우
어떤 경우든 먼저 권한이 있는 사람에게 확인하는 것이 순서입니다.
@ 호매실동 공장 사무동 출입문 도어락

# 가장 먼저 연락할 곳은 관리 담당자
사무동 문이 안 열리면 억지로 열 방법을 찾기보다 열쇠나 번호를 관리하는 담당자에게 먼저 연락해 보세요. / 사장님이나 총무 담당, 시설 담당이 번호를 알고 있을 수 있습니다.
비밀번호를 바꿨는데 공지가 안 된 경우는 생각보다 자주 있는 일입니다. / 담당자와 통화만 해도 해결되는 일이 많습니다.
담당자와 연락이 안 닿을 때는 건물 관리인이나 경비 담당이 보관 열쇠를 가지고 있는지 확인하세요. / 보관 열쇠 위치를 평소에 알아 두는 것도 좋은 준비입니다.

# 번호판과 카드 인식부터 간단히 확인
번호판이 아예 꺼져 있으면 건전지가 다 된 경우가 많습니다. / 바깥쪽 비상 단자가 있는지 확인하고 9V 건전지를 대 보는 방법이 있습니다.
카드를 대는 방식이라면 카드를 두세 번 천천히 대 보세요. / 그래도 반응이 없다면 카드 자체나 인식부 문제일 수 있습니다.
번호를 여러 번 틀리면 입력이 잠깐 막힐 수 있으니 서너 번 이상 연속으로 누르지 마세요. / 한 번 멈췄다가 천천히 다시 해 보는 편이 낫습니다.
공장 작업장 먼지나 기름기가 번호판에 묻어 있으면 오작동할 수 있으니 마른 천으로 가볍게 닦아 보세요.

# 공장 환경에서 도어락이 상하는 이유
사무동이라도 작업장과 가까우면 먼지, 분진, 습기가 도어락에 영향을 줍니다. / 평소 관리가 어려워 번호판 틈에 이물질이 쌓이기 쉽습니다.
출입이 잦은 문은 사용 횟수도 많아 건전지가 일반 가정집보다 빨리 닳을 수 있습니다. / 교체 주기를 담당자가 따로 정해 두면 좋습니다.
문을 힘껏 여닫는 일이 많은 곳은 걸쇠와 문틀 위치가 어긋나기도 합니다. / 이런 증상은 [도어락 수리](doorlock-repair.html)로 먼저 점검해 볼 수 있습니다.
@ 호매실동 작업장 인접 출입문 먼지 점검

# 야간 출입이 필요한 경우의 원칙
밤에 사무동에 들어가야 하는데 문이 안 열릴 때는 급하더라도 반드시 권한 확인이 먼저입니다. / 사업장 문은 개인 집보다 안에 보관된 물건이 많아 더 신중하게 다뤄야 합니다.
야간에 연락 주실 때는 본인이 누구인지, 이 사무동과 어떤 관계인지 먼저 말씀해 주세요. / 사업주나 임차인, 관리 담당자임을 설명할 수 있어야 합니다.
확인되지 않은 상태에서는 문을 열 수 없다는 점을 미리 알아 주세요. / 이웃 사업장 사람의 요청이나 전화로만 전해진 부탁은 신분 확인으로 보지 않습니다.

# 신분과 권한을 이렇게 확인합니다
문을 여는 일이라 이 사무동을 쓰는 분이 맞는지 먼저 확인합니다. / 신분증과 함께 사업자 관련 우편물, 임대차 관련 서류, 건물 관리 측 확인 중 하나면 됩니다.
서류가 사무실 안에 있다면 건물 관리인에게 확인을 부탁하는 방법이 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 두세요.
번거로우실 수 있지만 사업장 보안과 이웃 모두를 위한 절차입니다. / 근무자 한 명이 확인되었다고 해서 다른 사람의 요청까지 대신하지는 않습니다.

# 연락하실 때 알려 주실 것
호매실동은 건물과 길이 넓게 퍼져 있어 위치 설명이 중요합니다. / 가까운 큰길이나 건물 입구 모양, 안내 간판 없이 설명하기 어렵다면 지도 위치를 보내 주세요.
- 사무동이 별도 건물인지, 작업장과 붙어 있는지
- 문 종류(유리문, 철문, 목문)와 도어락 모양
- 번호판 또는 카드 인식부 상태
- 안에 사람이나 중요한 설비가 남아 있는지
- 담당자 연락처와 확인 가능한 서류
안에 기계가 가동 중이라면 작업 전에 꼭 말씀해 주세요. / 안전을 위해 순서를 조정해야 할 수 있습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 종류와 도어락 상태를 보고 얼마가 드는지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 호매실동 출장열쇠 사무동 출입문 개방

# 문을 최대한 상하지 않게 엽니다
유리문이나 철문이 달린 사무동은 문틀을 상하게 하면 보수가 번거롭습니다. / [현관문 개문](door-open.html) 방식은 도어락과 문틀이 덜 상하는 방법부터 차례로 해봅니다.
출입 시스템과 연결된 장비라면 임의로 작업하기 전에 담당자와 먼저 상의합니다. / 연동 장치가 있는지는 현장에서 확인한 뒤 말씀드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 너무 오래돼서 자주 문제가 생긴다면 그때 [도어락 교체](doorlock-replace.html)를 설명드립니다.

# 열고 난 뒤 정리해 둘 것
문이 열리면 번호를 누가 알고 있는지, 카드는 몇 장이 돌아다니는지 정리해 보세요. / 퇴사한 직원이 알고 있는 번호는 이 기회에 바꾸는 편이 좋습니다.
- 번호 변경 담당자 한 명 정하기
- 변경 때마다 근무자에게 알리는 방법 정하기
- 보관 열쇠 위치 기록해 두기
- 건전지 교체 주기 정해 두기
사업장에서는 이런 작은 규칙이 야간에 막히는 일을 크게 줄여 줍니다.
번호를 바꿀 때는 바꾼 사람, 바꾼 날짜, 알려야 할 사람을 간단히 적어 두세요. / 종이 한 장이나 업무용 메모면 충분하고, 누구에게 물어야 하는지 바로 알 수 있습니다.
카드키를 쓰는 곳이라면 카드 분실이 생겼을 때 해당 카드를 막는 방법을 미리 확인해 두면 좋습니다.

# 호매실동 말고 수원 어디든 갑니다
호매실동 주변은 물론 권선동, 세류동, 화서동, 인계동, 영통동, 정자동까지 다닙니다. / 수원 안이면 동네와 상관없이 24시간 연락을 받습니다.
다니는 곳은 [출장 지역](area.html)에서 볼 수 있습니다.
