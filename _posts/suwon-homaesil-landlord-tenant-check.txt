# 호매실동 전월세 집에서 도어락이 말썽일 때
호매실동은 수원에서도 서쪽 끝 신도시 쪽이라 새 아파트와 빌라, 임대로 나온 집이 골고루 섞여 있습니다. / 그래서 문이 안 열린다는 연락 중에는 사시는 분과 집주인이 서로 다른 경우가 꽤 많습니다.
도어락은 쓰던 사람이 바뀌어도 그대로 붙어 있는 물건입니다. / 그래서 고장이 났을 때 누가 연락해야 하는지부터 막히는 일이 생깁니다.
이 글은 호매실동에서 세입자와 집주인이 도어락 문제를 만났을 때 먼저 확인할 것을 정리했습니다. / 누구 잘못인지 따지는 글이 아니고, 불필요한 다툼 없이 문을 열고 고치기까지 순서를 적었습니다.
@ 호매실동 출장열쇠 도어락 확인

# 먼저 문 상태부터 같이 확인하세요
세입자든 집주인이든 급한 것은 문을 여는 일입니다. / 누가 부담할지는 문을 연 다음에 이야기해도 늦지 않습니다.
번호판이 켜지는지, 소리가 나는지, 보조키가 잠겨 있는지만 확인해도 원인이 좁혀집니다. / 이 내용을 문자로 정리해 두면 나중에 서로 이야기할 때 도움이 됩니다.
배터리 문제인지 부품 고장인지에 따라 해야 할 일도 달라집니다. / 배터리면 새것으로 바꾸는 정도로 끝나는 경우가 많습니다.

# 누가 연락해야 하는지 정하는 요령
도어락 고장 처리를 누가 하는지는 계약 내용과 집 상태에 따라 다릅니다. / 저희가 이쪽이라고 단정해서 말씀드릴 수는 없습니다.
대신 사시는 분이 연락하시면 신분 확인을 거쳐 문을 열어드리고, 어떤 부품이 문제인지 설명해 드립니다. / 그 설명을 집주인에게 그대로 전달하시면 이야기가 훨씬 쉬워집니다.
집주인이 대신 연락하는 경우에도 그 집에 사시는 분이 확인해 주셔야 작업을 시작할 수 있습니다. / 사시는 분께 문 앞에서 확인을 받는 절차는 꼭 필요합니다.

# 작업 전에 사진을 남겨 두세요
도어락과 문 상태를 사진으로 남겨 두면 좋습니다. / 번호판 모양, 제조사 표시, 문 안쪽 모습 정도면 충분합니다.
고장 난 부분이 처음부터 그랬는지, 최근에 생겼는지 서로 이야기할 때 사진이 기준이 됩니다. / 작업 후에도 같은 자리에서 한 장 더 찍어 두시면 비교가 쉽습니다.
저희가 도착하면 어떤 점검을 했는지도 말씀드립니다. / 그 내용을 문자로 받아 두셔도 좋습니다.
@ 호매실동 현관문 도어락 점검

# 열 수 있는지와 고쳐야 하는지는 다른 문제입니다
문을 여는 일과 도어락을 고치거나 바꾸는 일은 따로 판단합니다. / 문부터 열고 나서 상태를 보고 말씀드립니다.
배터리나 비밀번호 문제라면 그 자리에서 정리되는 경우가 많습니다. / 모터나 걸쇠가 고장 난 경우에는 [도어락 수리](doorlock-repair.html)로 먼저 손볼 수 있는지 봅니다.
너무 오래된 제품이라 고쳐 쓰기 어렵다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 바꾸는 일은 두 분이 같이 정하셔야 하는 경우가 많아서, 저희가 먼저 권하지는 않습니다.

# 비밀번호는 입주 때 바꿔 두세요
이전에 사시던 분이 쓰던 번호가 그대로 남아 있는 집도 있습니다. / 새로 들어가시면 기존 번호를 지우고 본인 번호만 남겨 두는 편이 안전합니다.
집주인이나 관리하는 분이 쓰는 번호가 따로 있다면 서로 알고 있는 것이 좋습니다. / 급한 일이 생겼을 때 집 안으로 들어가야 하는 경우도 있기 때문입니다.
번호를 바꿨다면 누구에게 알려 줄지도 정해 두시길 권합니다. / 공유할 사람이 많을수록 나중에 정리하기 어렵습니다.

# 이런 경우는 먼저 말씀해 주세요
세입자가 연락이 안 되고 집주인만 계신 경우가 있습니다. / 이때는 그 집에 사시는 분이 맞는지 확인할 방법이 있어야 작업할 수 있습니다.
집주인이 집을 비운 사이 문이 안 열린다는 연락도 있습니다. / 신분이 확인되지 않으면 작업이 어렵다는 점은 미리 알고 계시면 좋습니다.
문 안쪽에 사람이 있는지도 꼭 알려 주세요. / 아이나 반려동물이 있다면 서두르는 순서가 달라집니다.

# 호매실동 위치는 이렇게 알려주세요
호매실동은 단지와 동 번호가 길어서 위치를 정확히 알려 주시는 것이 중요합니다. / 건물 이름, 동, 호수와 함께 지금 상황을 짧게 말씀해 주세요.
- 건물 이름 또는 주소와 동, 호수
- 사시는 분이 직접 연락하시는지, 집주인이 대신 연락하시는지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 보조키가 잠겨 있는지
- 문 안쪽에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙기기 좋습니다. / 호매실동을 포함한 수원 서쪽 생활권 어디든 출동합니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인하는 것이 먼저입니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
계약서 사본이나 공과금 고지서를 보여 주셔도 됩니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요.
번거로우실 수 있지만 이웃과 집주인 모두를 위한 절차입니다. / 확인이 어렵다면 작업을 할 수 없다는 점을 이해해 주세요.
@ 호매실동 24시 출장열쇠 신분 확인

# 비용은 문을 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 비용을 먼저 안내해 드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭤봅니다. / 누가 부담하는지는 두 분이 정하시고, 저희는 필요한 작업 내용과 이유를 설명드립니다.

# 작업이 끝나면 점검 내용을 정리해 드립니다
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 어떤 점이 문제였는지, 앞으로 어떻게 하면 되는지도 설명드립니다.
집주인에게 전달할 내용이 있다면 문자로 간단히 정리해 드릴 수 있습니다. / 사진과 함께 보내시면 서로 오해할 일이 줄어듭니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 오래 문제 없이 쓰려면
도어락은 쓰는 사람이 바뀌어도 관리가 이어져야 오래 갑니다. / 입주할 때 배터리를 새것으로 바꿔 두면 첫해에 걱정할 일이 줄어듭니다.
- 입주하면 기존 비밀번호를 지우고 새 번호 등록
- 배터리 교체 날짜를 도어락 안쪽에 적어 두기
- 경고음이 나면 그날 바로 교체
- 보조키 열쇠를 누가 갖고 있는지 서로 확인
- 문이 덜 닫히면 경첩부터 점검
퇴거할 때는 새로 들어올 분을 위해 본인 비밀번호를 지워 두는 것도 좋습니다. / 문 열기 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.

# 호매실동 말고 수원 어디든 갑니다
호매실동 바로 옆 금곡동, 서둔동, 탑동 쪽도 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
