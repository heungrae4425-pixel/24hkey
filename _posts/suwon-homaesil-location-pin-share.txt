# 호매실동에서 길 설명이 어려운 이유
호매실동은 수원 서쪽에 넓게 자리 잡은 동네라 수원역이나 광교중앙역과 비교하면 생활권이 사뭇 다릅니다. / 동네 안에서도 구역마다 길 모양이 달라서 말로 위치를 설명하기가 의외로 어렵습니다.
문이 잠겨 당황한 상황에서는 더 그렇습니다. / 주소가 정확히 떠오르지 않거나, 문 앞이 아니라 건물 입구에 서 계신 경우도 있습니다.
이 글은 [수원 출장열쇠](suwon.html)를 부를 때 휴대폰으로 위치를 정확하게 보내는 요령을 정리한 것입니다. / 위치만 정확해도 도착 시간이 눈에 띄게 줄어듭니다.
@ 호매실동 휴대폰 위치 공유 화면

# 말로 설명하는 위치가 어긋나는 흔한 경우
전화로 "큰 건물 옆이에요"라고 하면 듣는 사람은 어느 건물인지 알 수 없습니다. / 같은 이름으로 불리는 길이나 건물이 한 동네에 여러 개일 수도 있습니다.
- 지도 앱의 이름과 현장에서 부르는 이름이 다른 경우
- 건물은 맞는데 출입구가 여러 개인 경우
- 도로명 주소와 지번 주소를 섞어서 말하는 경우
- 지금 서 있는 곳과 사는 곳이 다른 경우
이런 어긋남은 위치 한 번 보내시는 것으로 거의 정리됩니다.
특히 밤에는 주변이 어두워 건물 간판이나 표지를 읽기 어렵습니다. / 그래서 글자로 된 설명보다 지도 위의 한 점이 훨씬 믿을 만합니다.
저희도 위치를 받으면 가는 길과 도착 예상 시간을 먼저 말씀드립니다. / 기다리시는 동안 어디에서 대기하면 좋은지도 같이 안내해 드립니다.

# 지도 앱에서 현재 위치를 보내는 순서
스마트폰 지도 앱을 열면 내 위치가 파란 점으로 보입니다. / 그 점을 눌러 공유 버튼을 누르고 문자나 메신저를 선택하시면 됩니다.
위치를 보낸 뒤에는 말로 한 번 더 확인해 주세요. / "지금 파란 점 있는 곳이 제가 서 있는 현관 앞입니다" 정도면 충분합니다.
인터넷이 잘 안 잡히는 곳이면 문자로 주소 글자만 먼저 보내셔도 됩니다. / 휴대폰 배터리가 얼마 안 남았으면 이 단계부터 먼저 하세요.

# 메신저 위치 공유 기능을 쓰는 방법
메신저 대화창의 더하기 버튼을 누르면 위치 공유 메뉴가 있습니다. / 현재 위치를 보내면 지도와 주소가 같이 전송됩니다.
실시간 위치 공유는 잠깐만 켜 두시면 됩니다. / 도착한 뒤에는 꺼 두시는 게 좋습니다. 개인 정보이기 때문입니다.
메신저가 서툴러도 걱정 마세요. / 문자 한 통으로도 충분하고, 전화로 불러 주셔도 도와드립니다.

# 위치와 함께 꼭 알려주실 정보
위치 핀만 받으면 어느 집인지까지는 알기 어렵습니다. 아래를 같이 말씀해 주세요.
- 건물 종류와 동, 호수 또는 몇 층인지
- 건물 출입구 번호나 공동현관 방식
- 문 앞에 있는 특징(우편함, 계단, 엘리베이터 위치 등)
- 번호판이 꺼져 있는지, 경고음이 나는지
- 집 안에 아이나 반려동물이 있는지
문 앞 사진을 한 장 보내시면 도어락 종류를 미리 알아보고 맞는 장비를 챙겨 갑니다.

# 건물 입구까지는 갔는데 공동현관이 닫혀 있다면
호매실동 같은 주거 지역은 공동현관 비밀번호나 카드가 필요한 건물이 많습니다. / 출장열쇠가 도착해도 건물 안으로 들어가지 못하면 진행이 멈춥니다.
입구에서 기다리시거나 관리실, 이웃에게 문을 열어 달라고 미리 부탁해 두세요. / 늦은 시간이면 경비실에 미리 말씀해 두시는 것도 방법입니다.
공동현관 방식을 알려주시면 도착 후 기다리지 않고 바로 올라갈 수 있습니다.
@ 호매실동 공동현관 입구 위치 확인

# 위치 공유가 잘 안 될 때 대신 쓸 수 있는 방법
- 근처 편의점이나 약국처럼 눈에 잘 띄는 곳 이름과 방향 알려주기
- 건물 입구에서 찍은 사진 한 장 보내기
- 휴대폰 위치 권한이 꺼져 있는지 설정에서 확인하기
- 이웃에게 부탁해서 대신 보내기
위치 권한이 꺼져 있으면 지도 앱이 파란 점을 못 잡습니다. / 설정에서 위치를 켜고 다시 열어 보시면 됩니다.
위치가 몇십 미터씩 어긋나 보일 때는 비행기 모드를 잠깐 켰다 끄거나, 건물 밖으로 한두 걸음 나와서 다시 잡아 보세요. / 실내에서는 위치가 부정확하게 나오는 일이 흔합니다.

# 휴대폰 배터리가 얼마 남지 않았다면
문이 잠겨 있으면 충전기가 집 안에 있어서 휴대폰마저 꺼져 가는 경우가 있습니다. / 이럴 때는 위치를 먼저 보내고 통화는 짧게 하세요.
절전 모드를 켜고 화면 밝기를 낮추면 조금 더 오래 갑니다. / 편의점이나 카페에서 잠깐 충전을 부탁드리는 방법도 있습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
위치를 정확히 보내주셨더라도 집 안 사람인지 확인하는 절차는 똑같이 진행됩니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요.

# 비용은 문 열기 전에 말씀드립니다
문과 도어락 상태를 보고 먼저 비용을 말씀드린 뒤에 시작합니다. / 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 나서 말없이 붙는 비용도 없고, 부품 교체가 필요하면 바꾸기 전에 따로 여쭙니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열기 전에 확인하는 것과 열기 방법
도어락 종류와 문 상태를 보고 문과 도어락이 상하지 않는 방법부터 차례로 시도합니다. / 급하다고 힘으로 여는 방식은 쓰지 않습니다.
개방 방식은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다. / 열쇠를 잃어버린 경우는 [열쇠 출장](key-call.html) 페이지도 참고해 주세요.
@ 호매실동 출장열쇠 도어락 작업

# 위치를 미리 저장해 두면 다음에 편합니다
평소에 집 주소를 메모 앱이나 즐겨찾기에 저장해 두면 급할 때 바로 복사해서 보낼 수 있습니다. / 가족에게도 같은 내용을 공유해 두면 누가 문제를 겪어도 빠릅니다.
- 도로명 주소와 동, 호수를 한 줄로 저장
- 공동현관 비밀번호나 방식을 가족끼리만 공유
- 문 앞 사진을 한 장 찍어 앨범에 즐겨찾기
- 비상 연락처에 24시출장열쇠 번호 저장
번호를 저장해 두는 것만으로도 밤길에 당황하는 시간이 줄어듭니다.
가족 중 어르신이 계시면 메신저 사용이 어려울 수 있으니 문자 보내는 연습을 한 번 해 보시면 좋습니다. / 위치 보내기 화면을 캡처해서 보관해 두는 분도 있습니다.
이웃에게 부탁하는 경우를 대비해 평소 인사를 나누어 두는 것도 작은 대비가 됩니다.

# 호매실동 말고 수원 어디든 갑니다
호매실동 옆 금곡동, 권선동, 세류동은 물론 영통동, 광교동까지 수원 안이면 24시간 출동합니다. / 지역별 안내는 [수원시 출장열쇠](suwon.html) 페이지와 [출장 지역](area.html) 지도에 정리해 두었습니다.
