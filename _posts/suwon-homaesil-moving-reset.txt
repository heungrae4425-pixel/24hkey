# 이사 첫날, 도어락부터 점검하세요
호매실동으로 이사를 오면 짐 정리에 정신이 없어 도어락은 그대로 쓰기 쉽습니다. / 하지만 이전 입주자의 번호나 카드가 남아 있을 수 있어서 가장 먼저 확인할 일입니다.
이 글은 수원 권선구 호매실동 쪽 새집이나 이사한 집에서 도어락을 안전하게 쓰기 위한 순서를 정리했습니다. / 어렵지 않으니 천천히 따라 해 보세요.
@ 호매실동 도어락 비밀번호 초기화 출장열쇠

# 이전 입주자 번호가 남아 있는 이유
도어락은 등록된 번호와 카드를 자동으로 지우지 않습니다. / 이사 나간 사람이 번호를 바꾸지 않고 두면 그대로 남아 있습니다.
카드키나 태그도 이전 사람이 가지고 있으면 문을 열 수 있는 상태가 됩니다. / 새로 입주한 분은 번호를 새로 정하는 것이 안전합니다.

# 먼저 번호가 어떻게 되어 있는지 확인
집주인이나 이전 입주자에게 받은 번호가 있으면 한 번 눌러 봅니다. / 번호를 모르면 입주 때 받은 안내문이나 문자를 찾아보세요.
번호를 아무거나 눌러 보는 것은 입력이 막힐 수 있어 권하지 않습니다. / 모르는 경우에는 초기화를 진행하는 방법을 택합니다.

# 초기화 방법은 제품마다 다릅니다
안쪽 덮개를 열면 작은 초기화 버튼이 있는 제품이 많습니다. / 버튼을 몇 초간 누르면 등록된 번호와 카드가 모두 지워집니다.
제품에 따라 순서가 달라서 설명서나 제조사 안내를 확인하세요. / 설명서가 없다면 도어락 모양을 사진으로 보내 주시면 알려 드립니다.
@ 수원 호매실동 출장열쇠 이사 도어락

# 초기화한 뒤 새 번호 정하기
초기화가 끝나면 기본 번호만 남아 있거나 아무 번호도 없는 상태가 됩니다. / 이때 새 번호를 등록하는 방법은 제품 안내에 따라 진행합니다.
생일, 전화번호 뒷자리처럼 짐작하기 쉬운 숫자는 피하세요. / 가족이 외우기 쉬우면서 남이 짐작하기 어려운 숫자가 좋습니다.

# 카드키와 지문도 같이 정리
이전 입주자가 쓰던 카드키가 집에 남아 있으면 버리지 말고 새로 등록하지 않는 것이 좋습니다. / 초기화하면 이전 카드는 쓸 수 없게 되는 것이 일반적입니다.
지문 등록이 있는 제품이면 이전 지문이 남아 있는지 확인하고 모두 지웁니다. / 새로 쓰는 가족의 지문만 다시 등록하세요.

# 초기화가 안 되거나 번호를 모를 때
버튼이 없는 제품이거나 초기화 방식이 복잡하다면 출장열쇠를 부르는 편이 빠릅니다. / 이사 날은 정신이 없으니 혼자 오래 붙잡지 마세요.
문이 안 열리는 상황이면 먼저 문부터 열어야 합니다. / 방법은 [현관문 개문](door-open.html)에서 설명합니다.

# 하지 말아야 할 일
번호판을 뜯어서 초기화 부분을 찾으려 하지 마세요. / 안쪽 부품이 상할 수 있습니다.
인터넷에 올라온 다른 제품의 초기화 방법을 그대로 따라 하는 것도 위험합니다. / 제품마다 순서가 달라 오히려 잠길 수 있습니다.

# 전화로 알려주세요
- 호매실동 어디쯤인지, 근처 큰 건물이나 학교
- 번호판 모양과 제조사 표시
- 번호를 모르는지, 초기화 버튼을 찾았는지
- 문이 열린 상태인지 아닌지
사진을 같이 보내주시면 맞는 장비를 챙겨 갑니다. / 이사 날짜와 시간이 정해져 있다면 미리 알려주세요.

# 사시는 분인지 확인합니다
이사한 집이라도 문을 여는 일이라 신분증이나 계약서, 주소가 나온 우편물을 확인합니다. / 입주 안내문이나 관리사무소 확인도 가능합니다.
번거로울 수 있지만 안전을 위한 절차입니다. / 확인이 어려우면 작업을 진행하지 못합니다.

# 비용은 시작 전에 말씀드립니다
도어락 종류와 상태를 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 말없이 붙는 비용은 없습니다. [이용안내](guide.html)에 진행 방식을 적어 두었습니다.

# 오래된 도어락이라면 교체도 고려
이사 오면서 도어락이 너무 낡았다고 느껴진다면 교체를 고민해 볼 수 있습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
교체가 필요하면 [도어락 교체](doorlock-replace.html)에서 안내하는 순서로 진행합니다. / 새로 달고 싶다면 [도어락 설치](doorlock-install.html)도 참고하세요.
@ 호매실동 24시 출장열쇠 010-3664-5455

# 이사 후 같이 해볼 것
- 현관 보조키가 있는지 확인하고 상태 점검
- 도어락 배터리를 새것으로 한 번 교체
- 가족 모두에게 새 번호 알리기
- 비상 열쇠나 카드를 안전한 곳에 보관
이 정도만 해두면 입주 첫날부터 마음이 놓입니다.

# 호매실동 말고 수원 어디든 갑니다
권선, 장안, 영통, 팔달 등 수원 전 지역을 24시간 다닙니다. / 수원에서 다니는 동네는 [수원 출장 지역](suwon.html)에 정리해 두었습니다.
수원 밖은 [출장 지역](area.html) 지도에서 확인하세요.

# 이사 당일 체크리스트
짐이 들어오기 전에 도어락 번호부터 새로 정해 두면 이삿짐 업체 직원에게 번호를 알려 줄 때도 편합니다. / 이삿짐이 다 들어온 뒤에는 번호를 한 번 더 바꾸는 것도 좋습니다.
이사 과정에서 여러 사람이 드나들었다면 번호를 바꾸는 것이 안전합니다. / 가족 외에 번호를 아는 사람이 없도록 정리하세요.
새집 현관문의 보조키와 문틈 상태도 같이 살펴보면 입주 후 문제를 줄일 수 있습니다.
@ 호매실동 이사 당일 도어락 점검
새집에 들어갈 때 설레는 마음이 크지만, 도어락만큼은 입주 첫날 점검하는 것이 좋습니다. / 이전 입주자가 쓰던 번호와 카드가 남아 있으면 마음 편히 지낼 수 없기 때문입니다.
호매실동처럼 새 단지가 있는 곳은 시공사에서 설치한 도어락의 기본 번호가 그대로인 경우도 있습니다. / 기본 번호는 꼭 바꾸시고, 문이 열리지 않거나 방법을 모르겠다면 위치만 알려주세요. 이사 날에도 빠르게 가겠습니다.
