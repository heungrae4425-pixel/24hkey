# 호매실동, 야간 근무가 끝난 새벽의 현관
호매실동은 수원 서쪽에 자리해 수원역이나 광교 쪽 병원, 시설로 오가는 분들의 출퇴근 길이 긴 동네입니다. / 밤새 일하고 돌아온 새벽에 도어락이 반응하지 않으면 피로가 한꺼번에 몰려옵니다.
간호사나 요양보호사, 돌봄 일을 하는 분들은 교대 시간이 불규칙해서 집에 들어오는 시간도 제각각입니다. / 이 글은 그런 귀가 시간에 문이 잠겼을 때 차분히 대처하는 순서를 정리했습니다.
@ 호매실동 야간 근무 후 귀가 도어락

# 퇴근길에 문이 안 열리는 이유가 따로 있습니다
근무 중에는 집이 비어 있는 시간이 길어서 도어락도 힘들어집니다. / 며칠 연속으로 야간 근무를 하면 배터리 경고음을 놓치는 경우가 많습니다.
- 경고음을 못 듣고 배터리가 방전된 경우
- 피곤해서 번호를 잘못 누르다 입력이 막힌 경우
- 출근할 때 보조키를 잠그고 나온 경우
- 근무복 주머니나 사물함에 열쇠를 두고 온 경우
원인을 먼저 가르면 대처가 빨라집니다. / 하나씩 보면서 해당하는 것을 찾아보세요.

# 먼저 숨을 고르고 번호판부터 보세요
피곤할 때는 같은 번호를 계속 누르게 됩니다. / 그러면 제품이 입력을 막고 한참 동안 반응하지 않기도 합니다.
손으로 번호판을 한번 덮어 불이 들어오는지만 보세요. / 불이 들어오면 번호를 천천히 한 번만 눌러 보고, 안 되면 멈추는 것이 좋습니다.
번호판이 아예 꺼져 있다면 배터리가 방전된 쪽에 가깝습니다. / 이 경우 문을 흔들거나 당기는 건 도움이 되지 않습니다.

# 비상 건전지를 대 보는 방법
많은 도어락은 바깥쪽 아래에 비상 단자가 있어서 9V 건전지를 대면 잠깐 전원이 들어옵니다. / 단자가 없는 제품도 있으니 눈으로 먼저 찾아보세요.
새벽에는 건전지를 파는 곳이 드뭅니다. / 근무 가방에 비상용 건전지 하나를 넣어 두면 이런 날 큰 도움이 됩니다.
건전지를 대도 반응이 없으면 더 붙잡지 말고 연락 주세요. / 무리하게 하다 보면 단자 주변이 상하기도 합니다.

# 근무복 주머니를 먼저 뒤져 볼까요
급할 때 의외로 많은 경우가 열쇠나 카드가 근무복에 그대로 있는 것입니다. / 사물함, 가운 주머니, 보조 가방 안쪽까지 한 번만 확인해 보세요.
혹시 근무지에 두고 왔다면 시설에 연락해 맡아 달라고 부탁하는 방법도 있습니다. / 다만 퇴근한 몸으로 다시 가는 건 부담이어서 상황에 따라 판단하시면 됩니다.
어느 쪽이든 문 앞에서 오래 서 있지 말고 안전한 곳에서 연락하세요.

# 새벽에 전화할 때 말씀해 주시면 좋은 것
졸린 상태에서 전화하면 설명이 빠지기 쉽습니다. / 아래 항목만 짧게 말씀해 주셔도 충분합니다.
- 호매실동 안의 대략적인 위치와 동, 호수
- 번호판이 꺼졌는지, 소리가 나는지
- 보조키를 잠갔는지 기억나는지
- 집 안에 아이나 반려동물이 있는지
사진을 문자로 먼저 보내두시면 도착해서 더 빠르게 시작할 수 있습니다. / 상세한 호출 요령은 [출장열쇠 부르는 방법](key-call.html)에 적어 두었습니다.
@ 호매실동 새벽 귀가 출장열쇠 호출

교대 근무가 몰리는 주간에는 출근 전에 도어락을 한 번 점검해 두면 좋습니다. / 번호판이 평소보다 어둡거나 버튼 반응이 느려졌다면 이미 배터리가 약해진 신호입니다.
출근하는 날 현관을 나서며 문이 제대로 잠겼는지만 확인하고, 퇴근 후 쓰일 비상 수단을 가방에 넣었는지도 같이 확인하세요. / 이 두 가지 습관만 있어도 새벽 귀가길 곤란을 상당히 줄일 수 있습니다.
가족이나 동거인이 있다면 퇴근 시간을 미리 공유해 두세요. / 안에서 열어 줄 사람이 있다면 가장 빠르게 해결되는 경우도 많습니다.

# 혼자 사는 분은 안전한 곳에서 기다리세요
깜깜한 새벽에 문 앞에 혼자 서 있는 것은 위험할 수 있습니다. / 건물 입구나 밝은 공용 공간, 편의점 같은 곳에서 기다리는 편이 낫습니다.
도착 예정 시간을 들으면 근처에서 쉬었다가 맞춰 나오시면 됩니다. / 낯선 곳에서 기다리기 불안하면 가족이나 친구에게 현재 위치를 공유해 두세요.

# 집에 돌봄이 필요한 가족이 있다면
집 안에 아이나 어르신, 반려동물이 있는 상태에서 문이 안 열리면 우선순위가 달라집니다. / 이런 상황은 꼭 먼저 말씀해 주세요.
문 너머로 계속 말을 걸어 안심시키는 것이 좋습니다. / 안에서 열 수 있다면 안쪽 손잡이를 돌려 보라고 알려주세요. 보조키가 잠긴 것이라면 안쪽에서 풀 수 있습니다.
몸이 불편해 보이는 사람이 안에 있다면 이 글보다 119 등 응급 연락이 먼저입니다.

# 도착하면 신분 확인이 먼저입니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
퇴근길이라 지갑이나 신분증을 근무지에 두고 온 경우도 있습니다. / 이럴 때는 휴대폰에 저장된 주소 자료나 관리사무소 확인 방법을 같이 찾아 드립니다.
확인이 어려우면 작업을 할 수 없으니 이 점은 미리 알아 두세요.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 새벽 시간이라도 말없이 붙는 비용은 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 자세한 내용은 [이용안내](guide.html)에 적어 두었습니다.
@ 호매실동 24시 도어락 개방 작업

# 문이 열린 뒤에 바로 해 둘 일
열렸다고 바로 쓰러져 자고 싶겠지만 몇 가지만 같이 하면 다음 날이 편해집니다. / 배터리를 전부 새것으로 바꾸고, 번호를 새로 정하는 것이 우선입니다.
- 배터리 전부 교체와 날짜 적어 두기
- 보조키는 평소 열쇠를 어디에 두는지 정하기
- 근무 가방에 비상 건전지 넣어 두기
- 경고음이 나면 미루지 않고 그날 바로 조치하기
고장이 반복된다면 [도어락 수리](doorlock-repair.html)로 먼저 점검하고 필요하면 [도어락 교체](doorlock-replace.html)를 상담하세요.

# 교대 근무자에게 맞는 도어락 사용 습관
일정이 불규칙하면 배터리 교체를 놓치기 쉽습니다. / 한 달에 한 번 정해진 날에 번호판을 점검하는 습관이 도움이 됩니다.
지문이나 카드로 열 수 있는 제품은 피곤한 상태에서도 번호를 떠올리지 않아도 됩니다. / 다만 한 가지 방식에만 의존하지 말고 다른 방식도 같이 쓰는 것이 좋습니다.

# 호매실동 말고 수원 어디든 갑니다
호매실동 가까운 동네는 물론 수원 전 지역을 24시간 다닙니다. / 다니는 동네는 [수원시 출장열쇠](suwon.html)에서 확인하실 수 있습니다.
다른 지역에서 근무하다 돌아오는 경우에도 [출장 지역](area.html)에서 지원 지역을 보실 수 있습니다.
