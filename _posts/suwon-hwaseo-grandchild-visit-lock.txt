# 화서동 어르신 댁, 손주가 오는 날의 현관
화서동에는 오래 한 집에 사시는 어르신 댁이 많이 있고, 주말이면 손주들이 찾아오는 모습도 흔합니다. / 수원역 쪽으로 오가는 가족이 많아서 방문 시간이 불규칙한 집도 적지 않습니다.
아이가 먼저 도착했는데 할머니 할아버지가 잠깐 시장에 가 계셔서 문 앞에서 기다리게 되는 일이 있습니다. / 이럴 때를 대비해 쓰기 쉬운 번호를 정해 두면 서로 마음이 편합니다.
@ 화서동 손주 방문 도어락 간단 번호

# 번호가 어려우면 아이는 오히려 못 외웁니다
어른은 긴 번호도 익숙해지지만 아이는 다릅니다. / 여러 숫자를 외우다 틀리면 당황해서 더 틀리게 됩니다.
그렇다고 너무 쉬운 번호를 쓰면 불안합니다. / 중간 정도의 길이에, 가족끼리만 아는 규칙으로 만든 번호가 알맞습니다.

# 번호 정하는 세 가지 요령
기억하기 쉽지만 남이 짐작하기 어려운 번호가 좋습니다. / 아래 요령을 참고해 보세요.
- 생일이나 전화번호 뒷자리처럼 쉽게 알아낼 수 있는 숫자는 피하기
- 가족만 아는 의미로 묶이는 숫자 고르기 (예를 들어 처음 같이 간 여행 날짜의 일부)
- 같은 숫자가 연달아 반복되는 것은 피하기
이 가운데 하나를 골라 손주와 함께 소리 내어 읽어 보면 외우기 쉽습니다. / 한 번에 외우게 하려 하지 말고 오는 날마다 같이 눌러 보며 익히는 방법을 권합니다.

# 임시 번호를 쓸 수 있는 도어락이라면
제품에 따라 한 번만 쓰거나 기간을 정해서 쓰는 임시 번호를 등록할 수 있는 것도 있습니다. / 손주가 오는 주말에만 쓰는 번호를 따로 두면 평소 번호를 알려주지 않아도 됩니다.
방문이 끝나면 임시 번호를 지우는 것을 잊지 마세요. / 지우는 방법은 제품마다 달라서 설명서나 모양 사진을 보고 확인하셔야 합니다.
어르신 혼자 설정하기 어려우면 가족이 방문한 김에 같이 해 두는 것을 권합니다.

# 카드나 태그가 더 편할 수도 있습니다
번호 대신 카드나 태그로 여는 제품은 숫자를 외울 필요가 없습니다. / 초등학생 정도의 아이에게 열쇠고리 모양 태그를 주면 쉽게 쓰는 경우도 있습니다.
다만 잃어버릴 수 있다는 점은 감안해야 합니다. / 태그를 잃어버리면 그 태그만 지우고 새로 등록하면 되지만, 그 방법을 알아야 합니다.
어떤 제품이 좋을지 고민된다면 [도어락 설치](doorlock-install.html) 페이지에서 종류를 살펴보세요.

처음 몇 번은 어른이 문 뒤에서 지켜보며 같이 눌러 주세요. / 아이가 혼자 해냈다는 기분이 들면 번호도 오래 기억하고 문 앞에서 당황하는 일도 줄어듭니다.
번호를 종이에 적어 아이 가방 깊숙한 곳에 넣어 두는 방법도 있지만, 겉에서 보이는 곳에 적어 두는 것은 피하세요. / 열쇠고리나 가방 겉면에 번호를 쓰면 잃어버렸을 때 곤란해집니다.
번호를 바꿀 때는 손주에게도 바로 알려야 합니다. / 어르신이 번호를 바꿨다는 것을 잊고 있다가 방문 당일에 못 들어가는 일이 의외로 많습니다.

# 어르신이 불편하지 않아야 합니다
손주가 쓰기 쉽게 만드는 것도 좋지만 먼저 어르신 본인이 불편하지 않아야 합니다. / 번호판의 숫자가 잘 보이는지, 버튼 소리가 들리는지부터 점검하세요.
- 번호판이 어두운 곳이라면 주변 조명 확인
- 버튼이 너무 작아 잘못 누르는 일이 잦은지
- 소리가 작아 눌렀는지 확인이 어려운지
- 안쪽 손잡이를 돌리는 힘이 부담스럽지 않은지
이런 부분은 설치나 점검을 하면서 같이 봐 드릴 수 있어서 [도어락 수리](doorlock-repair.html) 상담에서 물어보셔도 됩니다.
@ 화서동 어르신 댁 현관 번호판 점검

번호를 정한 날에는 어르신과 손주가 같이 한 번씩 문을 열고 닫아 보세요. / 정말 열리는지, 닫고 나서 잠기는 소리가 나는지까지 확인해야 안심이 됩니다.
손주가 올 때마다 새 번호를 알려주는 것은 번거롭고 헷갈립니다. / 방문용 번호는 바꾸지 않고 오래 쓰되 가끔만 점검하는 편이 낫습니다.

# 손주가 번호를 아무에게나 말하지 않게
아이에게는 번호가 비밀이라는 점을 가볍게 알려주세요. / 겁을 주기보다는 "우리 집 비밀 암호야" 정도로 말해 주는 편이 오래갑니다.
친구들과 같이 와서 번호를 누르는 일은 되도록 막는 것이 좋습니다. / 문 앞에서 번호를 누를 때는 손으로 가리고 누르는 습관도 같이 알려주세요.

# 아이가 문 앞에서 못 들어갈 때 어른이 할 일
손주가 도착해서 번호를 눌렀는데 안 열린다는 연락이 오는 경우가 있습니다. / 이때는 먼저 번호판이 켜지는지, 삑 소리가 나는지만 물어보세요.
번호판이 꺼져 있으면 배터리 문제일 가능성이 큽니다. / 아이가 직접 건전지를 사거나 만지지 않게 하고 어른이 올 때까지 기다리게 하세요.
번호가 틀려서 입력이 막힌 경우에도 계속 누르지 말라고 알려주세요. / 시간이 지나면 풀리는 제품이 많습니다.

# 아이만 있는 상황에서 문이 안 열릴 때
손주 혼자 문 밖에 있다면 안전이 가장 먼저입니다. / 건물 안에 있다면 가까운 이웃이나 경비실에 도움을 청하게 하세요.
집 안에 어르신이 계신데 문을 못 열어 주는 상황도 있습니다. / 이럴 때는 상황을 먼저 알려주셔야 합니다. 몸이 불편해 보이는 경우에는 119 등 먼저 필요한 도움이 우선입니다.
문 여는 일은 [현관문 개문](door-open.html) 페이지에 설명한 것처럼 도어락과 문을 상하지 않게 하는 방식을 먼저 고려합니다.

# 문 열 때 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
어르신 댁은 신분증을 어디에 두셨는지 헷갈리는 경우가 있어 미리 알려드립니다. / 손주가 대신 연락했다면 어르신이 직접 확인에 응해 주셔야 합니다.
@ 화서동 출장열쇠 도착 후 신분 확인

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 본 뒤에 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 갑자기 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 가족이 같이 정해 두면 좋은 약속
번호와 임시 번호, 태그의 위치까지 한 번에 정리해 두면 서로 편합니다. / 기억에만 의존하지 말고 종이에 적어 안전한 곳에 두는 방법도 있습니다.
- 손주가 오는 날 연락 순서
- 어르신 댁에 누가 비상 번호를 알고 있는지
- 배터리 교체 날짜를 가족 누가 챙기는지
- 번호를 바꿀 때 서로에게 알리는 방법
작은 약속이지만 문 앞에서 오래 기다리는 일을 많이 줄여 줍니다.

# 화서동 말고 수원 어디든 갑니다
화서동 가까운 동네는 물론 수원 전 지역에서 24시간 연락을 받습니다. / 수원역 가는 길이든 영통 쪽이든 어디서든 전화 주시면 됩니다.
다니는 동네는 [수원시 출장열쇠](suwon.html)에서 확인하실 수 있습니다.
