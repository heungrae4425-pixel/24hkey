# 화서동 집에 다른 사람이 드나들어야 할 때
맞벌이 가정의 가사도우미, 아이나 부모님을 돌보는 분, 인테리어 기사님처럼 집에 사람이 드나들 일이 있습니다. / 화서동에서도 이런 사정으로 현관 비밀번호를 알려줘야 하는 일이 흔합니다.
번호를 알려주는 것은 편하지만 그 뒤에 번호를 어떻게 관리하느냐가 더 중요합니다. / 이 글은 임시 비밀번호를 쓰는 방법과 끝난 뒤 정리하는 순서를 적었습니다.
도어락 설정이 어렵거나 번호가 이미 오래 같았다면 [수원 출장열쇠](suwon.html)에 문의하셔도 됩니다. / 먼저 아래 내용부터 확인해 보세요.

# 임시 비밀번호를 쓰는 이유
평소 쓰는 번호를 그대로 알려주면 그 사람이 언제든 다시 올 수 있다는 뜻이 됩니다. / 일이 끝나고 관계가 끝나도 번호가 그대로면 마음이 편하지 않습니다.
임시 번호를 따로 만들어 쓰면 평소 번호는 지키면서 필요한 사람에게만 열어줄 수 있습니다. / 기간이 끝나면 임시 번호만 지우면 됩니다.
가족이 쓰는 번호와 손님이 쓰는 번호를 나눠 두는 것이 기본입니다.
@ 화서동 출장열쇠 도어락 임시 비밀번호

# 제품에 따라 가능한 방식이 다릅니다
모든 도어락이 임시 번호를 따로 등록할 수 있는 것은 아닙니다. / 제품마다 등록 가능한 번호 개수와 방법이 다릅니다.
- 번호를 여러 개 저장할 수 있는 제품은 임시 번호를 추가로 등록
- 한 번만 열리는 일회용 번호를 지원하는 제품은 방문 한 번에 맞게 사용
- 카드키나 태그를 따로 발급해 주는 방식도 있습니다
- 번호가 하나뿐인 제품은 번호를 바꿨다가 끝난 뒤 다시 바꿔야 합니다
제품 설명서가 없다면 모델명을 확인해 알려주세요. / 설정 방법을 같이 찾아드립니다.

# 임시 번호를 만들 때 좋은 번호는
아무 번호나 쓰면 쉽게 추측됩니다. / 아래처럼 만드시면 안전합니다.
- 생일, 전화번호 뒷자리, 1111·1234 같은 쉬운 번호는 피하기
- 평소 쓰는 번호와 앞뒤 자리가 겹치지 않게 만들기
- 도우미 분마다 다른 번호를 만들어 누가 드나들었는지 구분하기
- 너무 어려워서 본인도 잊어버리지 않게 메모해 안전한 곳에 보관
번호를 문자로 보낼 때는 받은 뒤 지우시고, 단체 대화방에 올리는 것은 피하세요.

# 번호를 알려줄 때 함께 정해 두면 좋은 것
번호만 알려주지 말고 기본 약속도 같이 정하면 오해가 줄어듭니다.
- 방문 요일과 시간
- 나갈 때 문이 완전히 닫히고 잠겼는지 확인해 달라는 부탁
- 번호를 다른 사람에게 알려주지 않기
- 일이 끝나는 날짜
말로만 하지 말고 짧게 문자로 남겨 두면 나중에 서로 편합니다.

# 화서동 위치는 이렇게 알려주세요
도어락 설정이나 점검 때문에 연락 주실 때는 아래를 알려주시면 좋습니다.
- 화서동 건물 이름이나 도로명 주소, 몇 층 몇 호인지
- 도어락 모양과 제조사 이름이 보이면 함께
- 지금 등록된 번호가 몇 개인지, 카드키가 있는지
- 방문하는 분이 지금 문 앞에서 막혀 있는지 여부
화서역 쪽이든 주택가 쪽이든 위치를 알려주시면 도착 시간을 먼저 말씀드립니다. / 사진을 문자로 보내주시면 맞는 방법을 찾기 쉽습니다.
@ 화서동 도어락 설정 번호 등록 확인

# 도우미 분이 문 앞에서 못 열 때
번호를 알려줬는데 문이 안 열린다고 연락이 오는 경우가 있습니다. / 대부분은 번호를 잘못 눌렀거나 도어락이 입력을 잠시 막은 상태입니다.
- 번호판을 천천히 한 번에 하나씩 누르도록 안내하기
- 여러 번 틀렸다면 잠시 기다렸다가 다시 시도하기
- 배터리 경고음이 나는지 확인하기
- 집 안에 있는 가족이 있다면 대신 열어주기
계속 안 열리면 사시는 분이 직접 연락하셔야 합니다. / 출장 시에는 사시는 분인지 먼저 확인하는 절차가 있습니다.

# 끝난 뒤 반드시 해야 할 정리
일이 끝났다면 임시 번호는 바로 지워야 합니다. / 미루다 보면 잊어버리고 그대로 두게 됩니다.
- 등록했던 임시 번호 삭제하기
- 평소 쓰는 번호도 바꾸고 싶다면 이때 같이 변경하기
- 발급한 카드키나 태그는 돌려받기
- 번호를 문자로 보냈다면 그 문자를 지우기
번호를 한 번 알려준 이후에는 몇 달에 한 번이라도 바꾸는 습관이 좋습니다.

# 번호가 이미 많이 퍼져 있다면
오래 같은 번호를 쓰다 보면 누가 알고 있는지 모르게 되는 경우가 있습니다. / 이사 오기 전 사람이나 공사한 분들이 알고 있을 수도 있습니다.
이럴 때는 한 번에 번호를 정리하는 것이 가장 마음이 편합니다. / 기존 번호를 모두 지우고 새 번호만 남기면 됩니다.
번호를 잊어버려 못 들어가는 상황이 되면 [현관문 개문](door-open.html)이 필요할 수 있습니다.
@ 수원 화서동 24시 출장열쇠 현관문 점검

# 출장이 필요한 경우에는 이렇게 진행합니다
도어락 설정이 막히거나 문이 안 열리면 전화 주세요. / 도착해서 사시는 분인지 먼저 확인합니다.
신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다. / 비용은 문을 열거나 작업하기 전에 먼저 말씀드립니다.
문을 못 열면 비용은 받지 않습니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 오래된 도어락이라면 점검도 같이
임시 번호를 쓰려는데 도어락이 자꾸 오작동하거나 반응이 느리다면 도어락 자체를 점검할 때입니다. / 배터리나 번호판, 모터가 원인일 수 있습니다.
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다. / 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
번호를 여러 개 저장하는 기능이 있는 제품으로 바꾸는 방법도 있습니다.

# 화서동 말고 수원 어디든 갑니다
화서동뿐 아니라 수원 전 지역이 출동 범위입니다. / 팔달구, 장안구, 권선구, 영통구 위치를 알려주시면 도착 시간을 먼저 말씀드립니다.
다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
@ 화서동 24시 출장열쇠 010-3664-5455
