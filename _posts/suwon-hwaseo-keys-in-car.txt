# 차 열쇠와 집 열쇠가 한 꾸러미일 때
화서동은 수원역 쪽 생활권으로 차를 두고 오가는 분도 많은 동네입니다. / 차 문을 잠그고 보니 집 열쇠까지 한 꾸러미로 차 안에 있는 상황이 생기기도 합니다.
차 문은 안 열리고, 집 현관 열쇠도 없으니 이중으로 곤란해집니다. / 이 글은 화서동에서 차 안에 열쇠를 두고 문을 잠갔을 때 현관 대응을 중심으로 정리했습니다.
차량 문 문제는 다른 분야이지만, 집 문을 먼저 해결해야 차 문 일도 풀리는 경우가 있습니다. / 어떤 것부터 풀지 순서를 정해 두면 훨씬 수월합니다.
@ 화서동 차 안에 둔 열쇠 꾸러미

# 먼저 무엇이 필요한지 정리하세요
상황마다 필요한 것이 다릅니다. / 급한 순서를 정하면 대응이 쉬워집니다.
- 집 안에 사람이 기다리고 있는지
- 집 현관을 열 방법이 열쇠뿐인지, 비밀번호도 있는지
- 차 안에 반드시 꺼내야 할 물건이 있는지
- 지금 몸이 춥거나 위험한 환경인지
도어락이 번호식이라면 열쇠 없이도 집은 들어갈 수 있습니다. / 열쇠만 쓰는 구조라면 집 문이 먼저 문제입니다.

# 번호식 도어락이라면 집부터 들어가세요
비밀번호를 알고 있다면 현관은 열 수 있습니다. / 집에 들어가 예비 열쇠를 찾는 것이 차 문 문제를 푸는 첫걸음입니다.
집 안 서랍이나 가족이 가진 예비 열쇠를 확인해 보세요. / 가족이 가까이 있다면 전화로 열쇠를 가져다줄 수 있는지 물어보세요.
차 문 예비 열쇠를 평소 어디 두었는지 떠올려 보는 것도 방법입니다.
차량 일은 자동차 제조사 서비스나 차량 전문 출장 쪽이 맞습니다. 집에 들어가 몸을 녹이고 휴대폰을 충전한 뒤 차분히 연락하시는 편이 훨씬 수월합니다. 급하게 서두르다 차량이나 현관을 상하게 하는 것이 가장 손해입니다.

# 열쇠 방식 현관이라면
현관이 열쇠로만 열리는 방식이라면 집 문부터 전문가가 필요합니다. / 이때는 차 열쇠 꾸러미와 별도로 집 문을 열 방법이 있는지 확인하세요.
가족이 집 안에 있다면 안에서 열어달라고 부탁하는 것이 가장 빠릅니다. / 아무도 없다면 [수원 출장열쇠](suwon.html)에 연락하는 것이 순서입니다.
집에 들어가면 예비 열쇠를 찾아 차 문 문제도 정리할 수 있습니다.

24시출장열쇠는 주택 현관문과 도어락을 중심으로 합니다. / 차량 문 개방은 차종과 장치가 달라 차량 전문 쪽이 맞습니다.
그래서 차 문은 보험사의 긴급 서비스나 차량 제조사 서비스에 문의하시길 권합니다. / 저희는 집 문에서 도움을 드립니다.
차 문과 집 문 중 하나만 해결하면 되는 경우가 대부분이라 순서가 중요합니다. / 아래 사례를 참고해 보세요.
@ 화서동 차량과 현관 열쇠 순서 정리

# 이런 순서로 풀렸던 경우가 많습니다
번호식 도어락을 쓰는 집이라면 비밀번호로 집에 들어가 예비 열쇠를 찾는 순서가 가장 쉽습니다. / 차 문은 그다음에 정리하면 됩니다.
열쇠식 현관이고 가족이 집에 없는 경우에는 집 문을 먼저 열고 예비 열쇠를 확인하는 순서가 됩니다. / 그 뒤에 차량 쪽 도움을 받으면 됩니다.
집 안에 아이가 혼자 있는 상황이라면 집 문이 최우선입니다. / 차는 나중으로 미루고 바로 연락 주세요.

# 하지 말아야 할 행동
차 유리를 깨거나 억지로 문틈을 벌리는 행동은 피해 주세요. / 차량이 상하고 수리 비용이 더 커집니다.
집 현관을 드라이버나 공구로 억지로 열려는 것도 위험합니다. / 도어락과 문틀이 상해 교체까지 가는 경우가 많습니다.
추운 날씨나 더운 날씨에 오래 밖에서 기다리지 마세요. / 가까운 실내로 이동해 상황을 정리하며 연락하시는 것이 안전합니다.

# 전화하기 전에 정리할 것
상황을 짧게 전하면 도착이 빨라집니다. / 아래 정보만 있으면 충분합니다.
- 동, 호수와 건물 형태
- 현관이 번호식인지 열쇠식인지
- 번호판이 정상인지, 비밀번호를 알고 있는지
- 집 안에 사람이나 반려동물이 있는지
- 연락 가능한 휴대폰 번호
도어락 사진이 있다면 문자로 보내주시면 좋습니다.

# 화서동에서 이런 연락이 옵니다
주차장에서 짐을 내리다 열쇠를 차에 두고 문이 잠긴 경우가 있습니다. / 현관 열쇠가 같은 꾸러미라면 집으로 들어가지도 못합니다.
세차나 주유 중에 열쇠를 차에 둔 채 문을 닫는 경우도 있습니다. / 이럴 때는 집에 가족이 있는지부터 확인하세요.
휴대폰까지 차 안에 있어서 이웃의 전화를 빌려 연락하시는 분도 있습니다. / 괜찮습니다. 위치와 상황만 알려주시면 됩니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증도 차에 있다면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두시면 수월합니다.
확인이 어려우면 작업을 할 수 없는 점은 양해 부탁드립니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
현관문 상태와 도어락 종류를 보고 어떻게 진행할지 먼저 설명드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다.

# 현관은 최대한 안 상하게 엽니다
문 여는 방법은 여러 가지가 있고 덜 상하는 방법부터 차례로 해봅니다. / 도어락과 문틀이 그대로인 채 열리는 것이 목표입니다.
현관문 개문 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 말씀드립니다.
@ 화서동 출장열쇠 현관문 개문

# 열린 뒤에 해두면 좋은 것
집에 들어가면 예비 열쇠의 위치를 다시 정리하세요. 차 열쇠와 집 열쇠, 그리고 예비 열쇠가 각각 어디 있는지 가족 모두가 알아 두면 좋습니다. / 집 열쇠와 차 열쇠를 한 꾸러미에서 분리하는 것만으로도 같은 일이 줄어듭니다.
열쇠식 현관이라면 번호식으로 바꾸는 방법도 있으니 [도어락 설치](doorlock-install.html)를 참고하세요. / 이미 고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 점검합니다.
예비 열쇠를 믿을 만한 이웃이나 가족에게 맡겨 두는 것도 하나의 방법입니다. 열쇠 꾸러미에 번호를 적어 두는 일은 분실 때 위험하니 피하세요.

# 화서동 말고 수원 어디든 갑니다
화서동 옆 세류동, 권선동, 인계동, 우만동도 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
