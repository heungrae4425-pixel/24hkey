# 화서동 현관문, 해가 바뀔 때 한 번만 챙겨도
화서동에서 화서역 쪽으로 오가는 분들은 아침저녁으로 현관문을 하루에도 몇 번씩 여닫습니다. / 그만큼 도어락은 쉬지 않고 일하는 물건인데도, 고장 나기 전에는 누구도 들여다보지 않습니다.
문이 안 열리고 나서 부르는 것보다 문이 멀쩡할 때 한 번 점검하는 쪽이 훨씬 조용하게 끝납니다. / 이 글은 달력에 표시해 두고 따라 할 수 있는 점검 루틴을 적은 것입니다.
특별한 공구는 필요 없고, 손전등과 마른 수건, 새 건전지 정도면 됩니다. / 해가 바뀔 때 한 번, 계절이 바뀔 때 한 번이면 충분합니다.
@ 화서동 도어락 점검 루틴 24시출장열쇠

# 왜 사람들은 점검을 미루게 될까
도어락은 평소에 아무 문제가 없으면 존재를 잊게 됩니다. / 그래서 배터리가 얼마나 남았는지, 문이 얼마나 처졌는지 아는 사람이 거의 없습니다.
고장은 대개 바쁜 날 아침이나 짐을 든 퇴근길에 한꺼번에 찾아옵니다. / 미리 정해 둔 날짜에 점검하면 그런 날을 피할 수 있습니다.
점검이라고 해서 거창한 일이 아니라, 소리와 불빛과 움직임을 확인하는 정도입니다. / 일 년에 몇 분만 쓰면 되는 일이라 부담도 적습니다. / 한 번 습관이 들면 퇴근길 엘리베이터 안에서도 떠올릴 만큼 가벼운 일이 됩니다.

# 달력에 적어 둘 네 번의 날짜
루틴은 단순할수록 오래 갑니다. / 아래처럼 계절이 바뀌는 시기에 맞춰 두면 잊지 않습니다.
- 연초: 배터리 전체 교체와 번호판 청소, 비밀번호 점검
- 봄: 번호판 먼지 닦기와 문틈 이물질 확인
- 여름 끝: 습기 자국과 경첩 소리 확인
- 늦가을: 한파 대비로 배터리 상태와 비상 건전지 확인
연초에 가족 생일이나 휴대폰 알림에 같이 묶어 두면 잊을 일이 없습니다. / 이웃과 같은 날 하자고 약속해 두는 분도 있습니다. / 복도를 같이 쓰는 집끼리 맞추면 서로 안부도 확인할 수 있어 좋습니다.

# 연초 점검, 배터리는 전부 한꺼번에
배터리는 일부만 바꾸면 남은 낡은 것이 먼저 힘이 빠져 며칠 만에 같은 일이 생깁니다. / 칸에 들어가는 건전지를 전부 새것으로 바꾸고, 같은 종류끼리 맞춰 넣어 주세요.
바꾸고 나서는 문을 연 채로 번호를 눌러 열림과 잠김 소리를 두세 번 확인합니다. / 모터가 힘차게 돌고 소리가 평소와 같으면 정상입니다.
교체한 날짜를 배터리 칸 덮개 안쪽이나 작은 스티커에 적어 두세요. / 다음 점검 때 기준이 되어 줍니다.

# 번호판과 센서는 마른 수건으로만
번호판에는 손기름과 먼지가 쌓여 반응을 둔하게 만듭니다. / 마른 수건이나 안경 닦는 천으로 부드럽게 닦으면 대부분 개선됩니다.
알코올이나 세정제를 직접 뿌리면 틈으로 스며들어 오히려 고장 원인이 됩니다. / 물기가 있는 천은 쓰지 않는 것이 안전합니다.
지문 인식부가 있는 제품이라면 센서 표면도 같은 방법으로만 닦아 주세요. / 날카로운 것으로 긁는 일은 절대 피해야 합니다.
@ 화서동 현관문 번호판 배터리 교체 점검

# 문이 스스로 닫히는지 보는 법
점검 중에 의외로 놓치는 것이 문이 닫히는 속도와 방향입니다. / 문을 반쯤 열었다가 손을 떼었을 때 끝까지 부드럽게 닫혀 걸쇠가 들어가야 합니다.
중간에 멈추거나 쾅 닫히면 도어클로저나 경첩에 문제가 생기고 있다는 신호입니다. / 이때 도어락만 탓하다 시간을 허비하는 분이 많습니다.
문이 덜 닫힌 채로 있으면 도어락이 잠긴 것으로 인식하지 못하는 경우도 있습니다. / 닫힘 상태는 [도어락 수리](doorlock-repair.html) 점검에서도 가장 먼저 보는 부분입니다.

# 경첩 소리와 문틀 간격 확인
문을 열고 닫을 때 끼익 소리가 나면 경첩이 마르고 있다는 뜻입니다. / 무리해서 쓰면 문이 조금씩 처지고 걸쇠 위치가 어긋납니다. / 그 상태로 몇 달을 지나면 도어락 모터까지 힘들어하게 됩니다.
문을 닫은 상태에서 문과 문틀 사이 간격을 위아래로 살펴보세요. / 한쪽만 유난히 좁거나 넓으면 처짐이 진행 중일 수 있습니다.
경첩 나사가 헐거워진 경우 드라이버로 살짝 조여 주는 것만으로 나아지기도 합니다. / 힘을 세게 주면 나사산이 뭉개지니 조금씩 조이는 게 좋습니다.
@ 화서동 현관문 경첩 문틀 간격 확인

# 비밀번호와 카드키도 이때 정리합니다
연초는 비밀번호를 정리하기 좋은 때입니다. / 오래전에 잠깐 알려 준 사람이 있었다면 그 번호는 바꾸는 편이 마음이 편합니다.
가족이 모두 현재 번호를 알고 있는지도 같이 확인하세요. / 번호를 바꾸고 한 사람만 모르는 일이 문 앞 사고의 흔한 시작입니다.
카드키나 리모컨이 몇 개인지 세어 보고, 보이지 않는 것이 있으면 등록을 지우는 방법을 알아 둡니다. / 분실 시 대처는 [출장열쇠](key-call.html) 안내 페이지에도 정리해 두었습니다.

# 점검 중 이런 신호가 나오면 전화 주세요
다음 신호는 혼자 해결하려 하지 말고 상담하시는 것이 좋습니다.
- 새 배터리를 넣어도 번호판이 켜졌다 꺼지는 경우
- 열림 소리는 나는데 걸쇠가 늦게 움직이는 경우
- 평소에 없던 경고음이 반복되는 경우
- 열쇠를 꽂았을 때 뻑뻑하게 걸리는 경우
이런 증상은 내부 부품이 닳았을 때 나오는 경우가 많습니다. / 완전히 멈추기 전에 손보면 선택할 수 있는 방법도 넓습니다. / 부품 하나만 손봐서 끝나는 경우가 많고, 그러면 교체까지 갈 일이 없습니다.

# 점검만 부탁해도 괜찮습니다
집에서 확인하기 어렵다면 화서동으로 방문해 점검만 받으셔도 됩니다. / 꼭 교체나 수리를 해야 하는 것은 아닙니다.
상태를 보고 고쳐서 쓸 수 있으면 그대로 쓰시라고 말씀드립니다. / 교체가 필요하다고 판단되면 이유를 설명드리고 선택은 사시는 분이 합니다.
비용은 작업 전에 먼저 말씀드리고, 동의하신 뒤에만 진행합니다. / 안내 방식은 [이용안내](guide.html)에 자세히 적혀 있습니다.

# 방문 전에 준비하실 것과 신분 확인
도착하면 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
점검 때는 급한 상황이 아니니 미리 챙겨 두시면 시간이 짧게 끝납니다. / 도어락 모델명이 보이면 사진으로 찍어 두세요.
문을 열어야 하는 상황이라면 [현관문 개문](door-open.html) 페이지의 순서대로 진행합니다. / 문을 끝내 못 열면 비용은 받지 않습니다.

# 화서동 말고 수원 어디든
화서동 옆 동네는 물론 영통동, 광교동, 인계동, 호매실동까지 수원 전 지역을 다닙니다. / 수원역, 영통역, 광교중앙역, 성균관대역 근처 어디서든 연락 주시면 됩니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에서 볼 수 있습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
