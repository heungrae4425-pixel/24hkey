# 화서동 식당 사장님이 새벽에 마주치는 문 문제
화서동에서 수원역 방면으로 이어지는 생활권에는 식당과 작은 가게가 많아 새벽 준비 시간에 문 앞에서 막히는 일이 종종 생깁니다. / 손님이 드나드는 정문보다 주방 뒷문과 창고 문이 먼저 말썽을 부리는 경우가 흔합니다.
이 글은 식당 주방 뒷문과 창고 열쇠가 안 열리거나 안 잠길 때 확인할 순서를 정리한 글입니다. / 영업 시간이 걸려 있으니 순서를 짧게 정리했습니다.
@ 화서동 식당 주방 뒷문 앞에서 열쇠가 돌아가지 않는 모습

# 주방 뒷문이 유독 자주 고장 나는 이유
주방 뒷문은 하루에도 여러 번 열고 닫고, 재료와 쓰레기를 들고 나가며 발이나 어깨로 밀기도 합니다. / 기름기와 습기, 열기 때문에 열쇠 구멍과 경첩이 쉽게 상합니다.
열쇠 구멍 안에 기름때가 굳으면 열쇠가 뻑뻑하게 돌거나 아예 들어가지 않습니다. / 정문과 달리 닦을 일이 적어 오래 방치되기 쉬운 부분입니다.

# 열쇠가 안 돌아갈 때 먼저 볼 것
열쇠를 억지로 돌리기 전에 아래를 확인해 보세요.
- 열쇠가 끝까지 들어가는지, 중간에 걸리는지
- 문을 안쪽으로 살짝 밀면서 돌리면 돌아가는지
- 열쇠 모양이 닳아 모서리가 둥글어지지 않았는지
- 최근에 문이 처졌거나 부딪힌 일이 있었는지
문을 살짝 들어 올리며 돌리면 걸쇠 위치가 맞아 열리는 경우도 있습니다. / 그래도 안 되면 힘을 더 주지 말고 멈추는 편이 안전합니다. / 열쇠를 꽂은 채 망치로 두드리는 분도 있는데, 그러면 구멍 안쪽 핀이 상해 열쇠를 새로 맞춰도 소용없게 됩니다. / 영업이 급해도 몇 분만 참고 상태를 그대로 두세요.

# 열쇠가 부러지거나 낀 경우는 따로 생각합니다
열쇠를 세게 돌리다 구멍 안에서 부러지면 일이 커집니다. / 부러진 조각이 남아 있으면 그 상태로 다시 꽂지 마세요.
조각이 보이면 사진을 찍어 두고 손대지 않은 채 연락 주시는 것이 좋습니다. / 억지로 빼려다 구멍 안쪽 부품이 상하는 경우가 많습니다.

# 창고 문 열쇠는 왜 헷갈리나
식당에서는 쌀, 냉동 재료, 소모품 창고처럼 열쇠가 여러 개 필요합니다. / 창고 문은 하루 중 열고 닫는 횟수는 적어도 무거운 물건을 옮기다 문에 부딪히는 일이 많습니다. / 열쇠 꾸러미가 커지면 직원들이 서로 다른 열쇠를 들고 있다가 막히는 경우가 생깁니다.
누가 마지막으로 문을 잠갔는지, 열쇠를 누가 갖고 있는지가 불분명할 때 문제가 커집니다. / 영업이 끝날 때 열쇠 인수인계를 정해 두면 이런 일이 줄어듭니다.
@ 창고 문 자물쇠와 열쇠 꾸러미를 확인하는 장면

# 직원이 열쇠를 갖고 퇴사했을 때
아르바이트생이나 주방 직원이 그만두면서 열쇠를 돌려주지 않는 경우가 있습니다. / 악의가 있어서가 아니라 깜빡 잊은 경우도 많지만, 가게를 비운 사이 누가 열 수 있는지 모르는 상태는 불안합니다.
이럴 때는 주방 뒷문과 창고 자물쇠의 속 부분만 교체하거나 번호 방식으로 바꾸는 방법이 있습니다. / 어떤 방법이 맞는지는 문 종류를 보고 정합니다. 자세한 안내는 [도어락 교체](doorlock-replace.html)에도 정리해 두었습니다.

# 영업 중에 문이 막혔을 때 우선순위
손님이 이미 있는 시간대에 뒷문이 막히면 비상구 역할이 걸립니다. / 안전과 직결되므로 바로 연락 주시는 것이 좋습니다.
주방 안쪽에서 열리지 않으면 가장 먼저 사람이 안에 갇혀 있지 않은지 확인하세요. / 급한 마음에 문을 발로 차거나 도구로 때리면 문틀이 상해 오히려 더 늦어집니다.

가게 문은 닫혀 있는 시간이 곧 손해로 이어지니 빨리 열고 싶어 하시는 마음을 압니다. / 그래도 문과 문틀을 상하게 하지 않는 방식부터 차례로 시도합니다.
문 여는 방식은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다. / 상가 문은 구조가 일반 현관과 달라 현장에서 확인하고 방법을 정합니다.

# 출장 요청 때 알려 주실 것
- 가게 위치 (화서동 어느 쪽 길, 가까운 역 방향)
- 문의 종류 (주방 뒷문, 창고, 철문, 유리문)
- 잠금 방식 (열쇠, 도어락, 자물쇠)
- 안쪽에 사람이 있는지, 영업 시작까지 남은 시간
문 사진을 문자로 보내주시면 필요한 부품을 챙겨 가기 좋습니다. / 열쇠 구멍 가까이 찍은 사진과 문 전체 사진을 한 장씩 보내주시면 더 좋습니다. / 연락 주실 때 영업 시작 시간을 같이 말씀해 주시면 도착 시간을 맞춰 안내드립니다.

# 도착하면 먼저 사장님 확인을 합니다
가게 문도 사시는 분이나 운영하시는 분이 맞는지 먼저 확인합니다. / 사업자등록증, 영업 관련 서류, 신분증, 건물 관리인 확인 중 가능한 것으로 확인합니다.
임대인이나 건물 관리자와 연락이 닿는 경우에는 그쪽 확인도 방법입니다. / 새벽 준비 중이라 서류가 가게 안에 있다면 폰으로 찍어 둔 사진도 참고합니다. / 무엇이 필요한지는 전화로 미리 안내드립니다. / 확인이 어렵다면 작업을 할 수 없으니 미리 준비해 두세요.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 잠금 종류를 보고 필요한 작업과 비용을 먼저 말씀드립니다. / 동의하실 때만 시작합니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 부품 교체가 필요한 경우에는 바꾸기 전에 따로 여쭤봅니다.
@ 주방 뒷문 잠금장치 상태를 점검하는 장면

# 열고 난 뒤에 점검할 것
문이 열린 뒤에는 열쇠가 부드럽게 돌아가는지, 문이 끝까지 잘 닫히는지 같이 봅니다. / 문틀이 처졌거나 경첩이 헐거우면 그 부분도 함께 말씀드립니다.
문이 열린 뒤에는 영업 준비를 이어 가실 수 있도록 작업 시간을 가능한 짧게 잡습니다. / 주방 바닥에 떨어진 부스러기는 작업 후 정리해 두고 갑니다.
고쳐서 쓸 수 있는 부분은 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 교체가 필요하면 이유를 설명드립니다. / 열쇠는 여분을 따로 보관해 두세요. / 영업을 마친 뒤 마감 점검 목록에 뒷문 잠금 확인을 한 줄 넣어 두면 좋습니다. / 열쇠를 복사할 때는 닳은 열쇠 말고 원본에 가까운 것으로 복사하세요.

# 주방 문을 오래 쓰는 관리법
- 열쇠 구멍 주변을 마른 천으로 가끔 닦기
- 잠금장치에 기름을 많이 뿌리지 않기 (먼지가 더 붙습니다)
- 문 닫을 때 발로 밀지 않기
- 마감 담당과 열쇠 보관자를 정해 두기
- 여분 열쇠는 가게 안이 아닌 다른 곳에 두기
기름 많은 주방은 자주 닦는 것만으로 열쇠 구멍 수명이 달라집니다. / 손님이 많은 주말 전에는 미리 열쇠를 한 번씩 돌려 보며 점검하는 것을 권합니다. / 겨울과 장마철에는 문이 부풀거나 얼어 평소와 다르게 움직일 수 있습니다. / 문이 평소보다 뻑뻑해졌다면 영업 시작 전에 미리 점검해 보세요.

# 화서동 말고 수원 어디든 갑니다
화서동 주변은 물론 인계동, 권선동, 세류동, 영통동 등 수원 안이면 24시간 출동합니다. / 다니는 동네는 [수원 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. 진행 방식은 [이용안내](guide.html)에도 있습니다.
