# 빌라는 문이 두 개라서 원인도 두 갈래입니다
화서동에는 빌라와 다세대주택이 모여 있는 골목이 많습니다. / 화서역 쪽에서 걸어 들어오다 보면 건물마다 공동 출입문이 하나씩 달려 있습니다.
이런 건물은 건물 입구의 공동 출입문과 집 앞의 세대 현관문, 이렇게 문이 두 겹입니다. / 어디에서 막혔는지에 따라 해결 방법과 연락할 곳이 달라집니다.
이 글은 수원 화서동 빌라와 다세대 건물에서 공동 현관과 세대 현관이 잠겼을 때 순서대로 확인하는 법을 정리했습니다. / 지금 문 앞이라면 어느 문이 문제인지부터 가려 보세요.
@ 화서동 빌라 공동현관 출입문 잠김

# 어느 문에서 막혔는지 먼저 가립니다
같은 건물에서도 문제가 생기는 곳은 다릅니다. / 어느 쪽인지 알아야 누구에게 연락할지 정해집니다.
- 건물 밖 공동 출입문이 안 열리는 경우
- 공동 출입문은 열렸는데 우리 집 현관이 안 열리는 경우
- 공동 출입문을 지나 집 앞에서 비밀번호가 안 먹는 경우
- 공동 출입문이 닫히면서 안에 남은 경우
우리 집 문은 내 책임이지만 공동 출입문은 건물 전체가 함께 쓰는 문입니다. / 이 차이를 알아 두면 연락과 비용 정리가 쉬워집니다.

# 공동 출입문이 안 열릴 때는 혼자 판단하지 마세요
공동 출입문은 여러 세대가 같이 쓰기 때문에 한 집이 마음대로 손대기 어렵습니다. / 특히 도어락이 달려 있는 경우 공동 번호가 바뀌었을 가능성도 있습니다.
먼저 같은 건물 이웃이나 관리하는 분에게 번호가 바뀌었는지 확인해 보세요. / 이웃에게 부탁해 안에서 열어 달라고 하는 방법이 가장 간단합니다.
이웃 연락처를 모른다면 우편함이나 건물 안내판에 적힌 연락처를 찾아봅니다. / 건물 관리 주체가 따로 있다면 그쪽에 먼저 알리는 것이 순서입니다.

# 배터리 때문에 공동 출입문이 멈추는 경우
공동 출입문 도어락도 배터리가 다 되면 번호판이 꺼집니다. / 여러 사람이 쓰는 문이라 배터리가 일반 가정보다 빨리 닳습니다.
비상 단자가 있다면 9V 건전지를 대고 번호를 눌러 볼 수 있습니다. / 이런 시도는 건물 사정을 아는 분이 같이 있을 때가 안전합니다.
공동 출입문 배터리는 누가 교체하는지 정해지지 않은 건물이 많습니다. / 한 번 멈추고 나서야 누가 맡을지 이야기하게 되는 경우가 흔합니다.

# 세대 현관이 안 열릴 때는 우리 집 문부터 보세요
공동 출입문은 통과했는데 집 앞에서 막혔다면 이제는 우리 집 문제입니다. / 평소처럼 번호판 상태를 확인하세요.
번호판이 꺼져 있으면 배터리 문제가 가장 흔합니다. / 소리는 나는데 안 열리면 보조키가 잠겨 있지는 않은지 살펴보세요.
빌라는 현관문이 오래된 경우가 많아 문틀이 처지거나 경첩이 헐거운 경우도 있습니다. / 문을 살짝 밀면서 손잡이를 돌려 보면 열리기도 합니다.
@ 수원 화서동 빌라 세대 현관 도어락 확인

# 계단과 복도에서 문을 두드릴 때 생각할 것
빌라는 방음이 약해 한밤에 문 앞에서 소리를 내면 이웃에게 크게 들립니다. / 벨을 계속 누르거나 문을 세게 두드리면 다른 세대가 놀랍니다.
늦은 시간이라면 이웃에게 양해를 구하고 차분히 처리하는 편이 좋습니다. / 전화로 먼저 상황을 알려 주시면 소리를 최소로 하는 방법을 같이 고민합니다.
작업 중에도 복도 소음은 가능한 줄이도록 하고 있습니다. / 이웃과의 관계는 오래 가므로 서로 배려하는 것이 중요합니다.

# 건물 안에서 열쇠를 나누어 쓰는 경우
작은 빌라는 공동 출입문 열쇠를 세대마다 한 개씩 나눠 쓰는 곳이 있습니다. / 열쇠가 분실되면 건물 전체가 영향을 받을 수 있습니다.
- 공동 열쇠를 잃어버렸다면 다른 세대에 먼저 알리기
- 열쇠를 복사해 가진 사람이 누구인지 정리하기
- 열쇠 구멍만 교체할지, 방식을 바꿀지 건물 사람들과 이야기하기
- 새 열쇠를 나눌 때 몇 개를 어디에 줬는지 기록하기
공동 시설은 한 집이 결정하기 어려운 일이 많습니다. / 협의가 필요한 부분은 우리가 대신 결정하지 않고 방법만 안내합니다.

# 임대와 소유가 섞인 건물에서의 정리
다세대 건물에는 집주인이 사는 집과 임차인이 사는 집이 함께 있습니다. / 공동 출입문의 수리와 교체를 누가 부담하는지는 건물마다 다르게 정해져 있습니다.
법적 판단을 여기서 단정할 수는 없습니다. / 계약서와 건물 내 합의를 확인해 보시고, 모르겠다면 집주인에게 먼저 물어보세요.
출장을 부르기 전에 집주인이나 관리하는 분에게 알려 두면 나중에 오해가 적습니다. / 작업 후 어떤 일이 있었는지도 사진과 함께 공유하면 좋습니다.

# 전화하실 때 이렇게 알려주세요
빌라는 건물 이름이 없는 곳도 많아 위치를 정확히 알리는 것이 중요합니다. / 아래 내용을 알려 주시면 찾아가기가 훨씬 쉽습니다.
- 화서동 어느 길인지, 가까운 역이나 큰 건물 기준 위치
- 건물 외관 특징과 몇 층 몇 호인지
- 공동 출입문이 문제인지 세대 현관이 문제인지
- 도어락 모양과 번호판 상태
- 이웃이나 건물 관리하는 분과 연락이 되는지
공동 출입문이 문제라면 문 앞 사진을 보내주시면 좋습니다. / 도어락이 없고 열쇠 방식이라면 열쇠 구멍 모양도 같이 알려 주세요.

# 신분 확인은 공동 출입문에서도 같습니다
문을 여는 일이라 사시는 분인지 반드시 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나는 필요합니다.
빌라는 관리사무소가 없는 경우가 많으니 우편물이나 계약서가 중요한 서류가 됩니다. / 공동 출입문이라면 건물에 사는 이웃 확인이 보조로 도움이 될 수 있습니다.
확인이 어려우면 작업을 할 수 없는 점은 미리 알려 드립니다. / 어떤 서류가 가능한지는 전화로 안내합니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
공동 출입문인지 세대 현관인지, 도어락 종류가 무엇인지 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 마음에 안 들면 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품 교체가 필요하면 바꾸기 전에 먼저 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 문을 열고 난 뒤 건물 단위로 점검할 것
문이 열린 뒤에는 같은 문제가 또 생기지 않게 확인해야 합니다. / 특히 공동 출입문이라면 건물 사람들이 모두 쓸 수 있는지 시험해야 합니다.
- 번호나 열쇠가 모든 세대에서 문제없이 되는지
- 문이 닫힐 때 걸쇠가 정확히 들어가는지
- 배터리 교체 담당을 정해 두었는지
- 비밀번호가 바뀌었다면 모든 세대에 알렸는지
이런 사항은 [도어락 수리](doorlock-repair.html)나 [열쇠 출장](key-call.html) 안내를 참고해 정리해 두면 좋습니다. / 단톡방이나 안내문에 정리해 붙여 두면 다음 사람이 편합니다.
@ 화서동 출장열쇠 공동 출입문 점검 후 안내

# 화서동 말고 수원 어디든 갑니다
화서동 외에 인계동, 세류동, 권선동, 조원동, 영통동까지 수원 전역으로 출동합니다. / 수원 안이면 시간이 늦어도 전화를 받습니다.
[수원시 출장열쇠](suwon.html)에서 다니는 동네를 확인하시고, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
