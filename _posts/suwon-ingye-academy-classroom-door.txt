# 수업 시작 전 문이 안 열리는 아침
인계동은 수원역과 가까운 생활권이라 상가 건물마다 학원과 교습소가 층층이 들어서 있는 동네입니다. / 학생이 오기 전에 원장이나 강사가 먼저 출근해 문을 열어야 하는데, 그 문이 안 열리면 하루 일정이 흔들립니다.
학원 출입문은 집 현관문과 다르게 사람이 많이 드나들고 여러 명이 비밀번호를 공유하는 경우가 많습니다. / 그래서 고장의 원인도 집과 조금 다르게 나타납니다.
이 글은 인계동에서 학원이나 교습소 출입문, 강의실 문이 안 열릴 때 확인할 것과 [수원 출장열쇠](suwon.html)가 돕는 방식을 정리한 것입니다.
@ 인계동 상가 건물 학원 출입문과 도어락

# 학원 문은 집 문과 무엇이 다른가
학원 출입문은 아침부터 밤까지 열고 닫는 횟수가 훨씬 많습니다. / 하루에도 수십 번 쓰다 보니 도어락과 경첩, 도어클로저가 집보다 빨리 닳습니다.
출입 인원이 많아 비밀번호를 아는 사람도 늘어납니다. / 누가 언제 바꿨는지 모르는 번호 때문에 다툼이나 혼란이 생기기도 합니다.
강의실 문은 또 다른 성격을 갖습니다. / 소리가 새지 않도록 두껍거나 밀폐된 문을 쓰는 곳이 있어 열고 닫는 방식이 따로 있습니다.

# 가장 흔한 원인 세 가지
첫째는 배터리입니다. / 드나드는 횟수가 많은 만큼 일반 가정보다 배터리가 빨리 닳습니다.
둘째는 비밀번호 혼선입니다. / 직원이 바뀌거나 번호를 새로 정했는데 일부만 전달된 경우입니다.
셋째는 도어락 자체의 오작동입니다. / 모터가 헛돌거나 걸쇠가 문틀에 걸려 움직이지 않는 일입니다.
이 세 가지를 먼저 떠올리고 하나씩 지워 가면 원인이 금방 좁혀집니다.

# 문 앞에서 1분 점검
번호판에 불이 들어오는지부터 확인하세요. / 아무 반응이 없으면 배터리 방전 가능성이 큽니다.
- 번호를 눌렀을 때 소리가 나는지
- 경고음이 평소와 다른지
- 어제 퇴근할 때 마지막으로 잠근 사람이 누구인지
- 보조키나 걸쇠를 걸었는지
퇴근한 직원에게 전화해서 마지막 상황을 물어보면 의외로 빨리 풀립니다. / 어제 번호를 바꿨는지, 잠금 모드를 켰는지도 같이 확인해 보세요.

# 강의실 문이 안에서 잠겼을 때
강의실 문은 안쪽에서 잠그기 쉬운 구조가 많습니다. / 수업 중에 잠그고 나간 뒤 다시 열리지 않는 일이 생깁니다.
안에 학생이 있는 경우라면 가장 먼저 학생 상태를 확인해야 합니다. / 안쪽 사람에게 문 가운데 잠금 버튼을 돌려 보라고 안내해 보세요.
소리가 외부로 안 나가는 방음 문은 안쪽 목소리가 잘 안 들릴 수 있습니다. / 이런 경우는 휴대폰으로 연락하는 방법을 먼저 써보세요.
@ 인계동 강의실 문 손잡이와 안쪽 잠금 장치

# 하지 말아야 할 것
수업 시간이 급하다고 문을 힘으로 열려 하지 마세요. / 상가 출입문은 유리나 알루미늄 틀이 많아 힘을 주면 파손되기 쉽습니다.
도어락에 반복해서 번호를 틀리게 입력하면 입력 잠금이 걸릴 수 있습니다. / 몇 번 해보고 안 되면 멈추는 게 좋습니다.
건물 관리인이나 이웃 점포에서 임의로 공구를 빌려 시도하는 것도 권하지 않습니다. / 잘못 건드리면 건물 공용 설비까지 문제가 번집니다.

학원은 대부분 건물을 빌려 쓰는 경우입니다. / 출입문을 바꾸거나 손대기 전에 건물주나 관리 쪽에 알려야 하는 사항이 있는지 생각해 두세요.
공용 복도 쪽 문이면 건물 관리 주체가 따로 있을 수 있습니다. / 점포 안쪽 문은 사용하는 쪽이 관리하는 경우가 많습니다.
계약서나 관리 규정에 도어락 변경 조건이 있는지 한 번 살펴보시면 좋습니다. / 법적인 판단은 단정하지 않으니 의문이 있다면 건물 관리 쪽과 확인하세요.

# 전화하실 때 알려주실 내용
학원이나 상가라는 점과 몇 시까지 열어야 하는지를 먼저 말씀해 주세요. / 시간이 급할수록 필요한 정보만 짧게 정리해 두면 좋습니다.
- 인계동 어느 쪽인지, 수원역 방향 등 대략 위치
- 건물 몇 층인지, 입구 문인지 강의실 문인지
- 도어락 종류 (번호식, 카드식, 지문식)
- 번호판 상태와 소리
- 안에 사람이 있는지 여부
도어락 사진을 보내주시면 맞는 장비를 챙기기 좋습니다.

# 도착하면 먼저 확인하는 것
문을 여는 일이라 이 공간을 사용하는 분이 맞는지 먼저 확인합니다. / 사업자 관련 서류나 계약서, 관리 사무소 확인 중 하나면 됩니다.
개인 사업자라면 사업장 주소가 적힌 서류가 도움이 됩니다. / 신분증도 함께 준비해 주세요.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다. / 직원이 대신 요청할 때는 원장이나 대표자께 먼저 연락드릴 수 있습니다.

# 비용은 문 열기 전에 말씀드립니다
문 종류와 상태를 보고 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 인계동 출장열쇠 상가 출입문 비파손 개방

# 최대한 안 상하게 엽니다
학원은 영업이 걸려 있어 문이 상하면 곧바로 손해로 이어집니다. / 그래서 덜 상하는 방법부터 차례로 시도합니다.
도어락과 문틀, 유리가 상하지 않게 하는 것을 우선합니다. / 작업 중 바꿔야 할 부품이 보이면 손대기 전에 말씀드립니다.
상가 출입문 개방 방식은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다. / 업장 상황에 맞춰 시간대를 조율할 수 있는지 전화로 말씀해 주세요.

# 열고 난 뒤 정리할 것
문이 열리면 도어락이 정상으로 잠기고 열리는지 같이 봅니다. / 배터리가 원인이면 새것으로 모두 바꿨는지도 확인합니다.
출입하는 사람이 많은 곳이라면 번호를 새로 정리해 두는 것이 좋습니다. / 그만둔 직원 번호는 지우고 지금 일하는 사람만 남겨 두세요.
자주 고장 나면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 학원 규모에 맞는 방식은 상담해 드립니다.

# 학원 출입문 관리 요령
번호를 여러 사람이 쓰는 곳은 주기적으로 정리해야 합니다. / 직원이 바뀔 때 번호를 바꾸는 습관이 있으면 혼선이 줄어듭니다.
- 배터리는 학기 시작 전에 한 번에 교체
- 경고음이 나면 그날 바로 확인
- 수업 중 강의실 문은 잠금 버튼 위치를 학생에게 알려 두기
- 마지막 퇴근자가 잠금 확인 후 단체 대화방에 한 줄 남기기
출입문 도어클로저가 너무 빠르거나 느리면 사고로 이어질 수 있어 함께 살펴 주세요.

# 인계동 말고 수원 어디든 갑니다
인계동 바로 옆 매탄동, 권선동, 세류동과 영통동, 광교동까지 수원 안이면 다닙니다. / 24시간 출동합니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
