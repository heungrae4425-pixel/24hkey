# 분명 아는 번호였는데 안 눌러질 때
인계동에서 수원역 방향으로 걸어 퇴근하다 보면 집 앞에서 번호를 누르다 갑자기 멈칫하는 순간이 있습니다. / 늘 누르던 숫자인데 손이 기억하지 못하거나, 번호를 눌러도 경고음만 나는 경우입니다.
피곤하거나 술자리를 마치고 돌아온 밤이면 이런 일이 더 잦습니다. / 당황해서 계속 눌러 보면 입력이 잠깐 막혀 더 곤란해집니다.
이 글은 비밀번호를 잊었을 때와 가족이 모르게 바꿔 놓았을 때 순서대로 해볼 것, 그리고 [수원 출장열쇠](suwon.html)를 부르는 때를 정리했습니다.
@ 인계동 도어락 비밀번호 분실

# 일단 손을 멈추고 숨 고르기
잘못 눌러도 서너 번까지는 괜찮지만 그 이상 틀리면 제품에 따라 잠금이 걸립니다. / 몇 분에서 길게는 그 이상 아무 입력도 받지 않는 제품도 있습니다.
먼저 번호판을 손으로 닦고 손가락도 닦은 뒤 천천히 한 자리씩 눌러 보세요. / 습기나 땀 때문에 숫자가 정확히 눌리지 않았을 수도 있습니다.
그래도 안 되면 번호를 억지로 떠올리려 하지 말고 다른 방법을 찾는 편이 빠릅니다.

# 번호를 기억해 내는 단서
손가락이 번호판 위를 지나가는 모양을 떠올려 보는 것도 방법입니다. / 숫자는 잊어도 손이 움직이던 궤적은 기억에 남아 있는 경우가 있습니다.
다만 이것도 한두 번 해보고 안 되면 곧바로 멈추세요. / 너무 오래 붙잡고 있으면 오히려 더 헷갈립니다.
집 안 어딘가에 번호를 적어 둔 메모가 있다면 가족에게 사진을 찍어 보내 달라고 부탁해 보세요.
사람마다 번호를 정하는 방식이 있어서 단서를 따라가면 떠오르는 경우가 있습니다. / 생각나는 대로 계속 눌러 보는 것보다 후보를 적어 보는 쪽이 낫습니다.
- 이사 직후에 처음 등록한 번호인지, 나중에 바꾼 번호인지
- 가족이 마지막으로 바꾼 사람이 누구인지
- 번호 앞이나 뒤에 별표나 샵 키를 눌렀는지
- 이전 집에서 쓰던 번호를 그대로 옮겨 쓴 건 아닌지
가족에게 전화로 물어보면 의외로 바로 해결되는 경우가 많습니다. / 휴대폰이 있다면 먼저 가족 대화방에서 번호를 찾아보세요.

# 가족이 몰래 바꿨을 수도 있습니다
가족 대화방을 거슬러 올라가 보면 번호를 바꾼다는 이야기가 지나가듯 적혀 있는 경우도 있습니다. / 먼저 대화 기록을 검색창에 번호나 도어락이라고 입력해 찾아보세요.
누군가 번호를 바꾸고 알려주지 않은 채 외출해서 문 앞에서 막히는 일도 있습니다. / 악의가 있는 것이 아니라 바꾼 사실을 말하는 걸 잊은 경우가 대부분입니다.
이럴 때는 모든 가족에게 연락해 한 명씩 확인하세요. / 그래도 아무도 번호를 모르면 도어락 쪽을 살펴보는 수밖에 없습니다.
한 번 바꾸면 반드시 가족 대화방에 알려 두는 규칙을 정해 두면 이런 일이 크게 줄어듭니다.

# 비상 열쇠가 있는지 먼저 찾아보세요
회사 사물함이나 부모님 댁에 맡겨 둔 여분 열쇠가 있는지도 떠올려 보세요. / 가까운 곳에 있다면 가져오는 편이 더 빠를 수 있습니다.
단, 늦은 시간에 무리하게 이동하는 것보다 안전하게 대기하는 것이 먼저입니다.
많은 도어락은 번호 외에 열쇠 구멍이나 카드, 지문 같은 다른 방법도 함께 쓰도록 되어 있습니다. / 현관 근처에 보관해 둔 카드나 열쇠가 있다면 번호가 없어도 열 수 있습니다.
차 안, 가방 안쪽 주머니, 다른 가족의 지갑까지 한 번씩 확인해 보세요. / 열쇠 구멍은 번호판 덮개 아래에 숨겨진 제품도 있습니다.
이런 방법이 없고 등록된 카드도 없다면 번호를 아는 사람이 올 때까지 기다리거나 전화 주세요.
@ 수원 인계동 도어락 번호 재설정 점검

# 하면 안 되는 시도
무작위로 계속 눌러 대면 도어락이 경보를 울리거나 일정 시간 완전히 먹통이 되기도 합니다. / 그러면 열 방법이 오히려 줄어드니 조심하세요.
번호를 한 자리씩 순서대로 무작위로 눌러 보는 것은 시간만 걸리고 잠금이 걸릴 위험이 큽니다. / 도어락 덮개를 억지로 열거나 드라이버로 풀려고 하는 것도 피해 주세요.
문틈에 카드를 넣어 밀어 보는 방법은 최신 도어락에는 거의 통하지 않고 문틀만 상합니다. / 오히려 나중에 교체해야 할 부품을 늘릴 수 있습니다.
인터넷에서 본 방법을 따라 하다 도어락 내부 부품이 틀어지는 일도 있으니 조심하세요.

# 전화하실 때 알려주면 빠른 정보
- 인계동 어느 쪽인지 (수원역 방향, 인계동 먹자 골목 근처 등 대략)
- 아파트나 빌라, 호수
- 도어락 모양과 번호판 상태
- 번호를 아는 가족이 연락 가능한지
- 집 안에 아이나 반려동물이 있는지
상황을 짧게 정리해 주시면 출동 시간과 필요한 장비를 바로 안내해 드립니다. / 도어락 사진을 문자로 보내주시면 더 정확합니다.

# 사시는 분 확인은 꼭 거칩니다
비밀번호를 잊어서 문을 여는 경우는 특히 사시는 분이 맞는지 확인이 중요합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하시거나 이웃에게 도움을 받으실 수 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락 종류를 본 뒤 비용을 먼저 안내합니다. / 괜찮으시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙습니다.
진행 순서는 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html) 페이지에 있습니다.

# 열고 나서 번호를 새로 정하는 방법
문이 열리면 안쪽에서 마스터 번호나 사용자 번호를 새로 등록합니다. / 기존 번호는 지우고 새 번호만 남겨서 이전에 알던 사람이 더는 쓰지 못하게 합니다.
번호는 생일이나 전화번호 뒷자리 같은 쉬운 숫자를 피하고, 가족이 함께 외울 수 있는 형태로 정하세요. / 새로 정한 번호는 가족 대화방에 바로 공유해 두는 것이 좋습니다.
@ 인계동 출장열쇠 새 비밀번호 등록

# 번호 분실이 반복된다면
같은 일이 자주 생긴다면 번호 방식 자체를 바꿔 보세요. / 카드키나 지문을 함께 쓰면 번호를 잊어도 문이 열립니다.
이런 방식은 [도어락 설치](doorlock-install.html) 때 문 두께와 보조키까지 확인하고 맞는 제품을 고르게 도와드립니다. / 기존 제품이 고장 나 있다면 [도어락 수리](doorlock-repair.html)를 먼저, 그다음 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 인계동 말고 수원 어디든
인계동과 가까운 매탄동, 우만동, 권선동, 세류동도 다닙니다. / 수원 전 지역 24시간 출동입니다.
다니는 동네는 [수원시 출장열쇠](suwon.html)에, 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

# 마무리
인계동에서 번호가 기억나지 않으면 계속 눌러 보기보다 잠시 멈추고 가족과 카드, 열쇠부터 확인해 보세요. / 그래도 안 되면 위치와 상황만 알려주시면 바로 출동 여부를 말씀드립니다.
