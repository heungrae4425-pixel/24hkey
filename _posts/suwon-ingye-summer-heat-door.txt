# 여름만 되면 문이 말을 안 듣는다
수원 인계동은 수원역과 가까워 늦게까지 오가는 사람이 많고 건물이 빽빽하게 이어진 곳입니다. / 한여름 무더위나 긴 장마철이 오면 현관문이 평소보다 뻑뻑해졌다는 연락이 늘어납니다.
겨울에는 멀쩡하던 문이 여름에 갑자기 말썽을 부리는 것은 대개 계절 탓입니다. / 이 글은 인계동에서 더운 날씨에 현관문이 안 열리거나 덜 닫힐 때 원인을 하나씩 짚어 본 것입니다.
@ 인계동 여름 현관문 뻑뻑함 열기 습기

# 문이 부풀고 늘어난다
목재 문이나 합판 문은 습기를 머금으면 미세하게 부풀어 오릅니다. / 쇠로 된 문도 햇볕을 많이 받으면 열에 의해 조금씩 팽창합니다.
이 작은 변화가 문틀과 문 사이의 틈을 줄여 문이 문틀에 끼듯 닫힙니다. / 평소에는 여유롭던 간격이 부족해지는 것입니다.
문을 닫을 때 평소보다 힘이 들거나, 열 때 문틀과 쓸리는 소리가 나면 이 경우일 가능성이 있습니다. / 억지로 세게 밀어 닫는 것은 피하세요.
오전에는 멀쩡하다가 해가 드는 오후에 더 뻑뻑해진다면 열 팽창을 의심해 볼 수 있습니다. / 반대로 비 오는 날만 심하다면 습기가 원인일 가능성이 높습니다.
이렇게 시간대와 날씨에 따라 증상이 달라지는 것은 고장보다 계절 영향이라는 단서가 됩니다. / 전화하실 때 언제 심한지 말씀해 주시면 원인을 가늠하는 데 큰 도움이 됩니다.

# 쓸리는 위치를 먼저 찾아봅니다
문이 어디에서 닿는지 알면 원인이 훨씬 빨리 보입니다. / 문틀과 문 사이에 얇은 종이를 끼워 보며 걸리는 곳을 확인해 보세요.
- 위쪽 모서리가 닿는지, 아래쪽 모서리가 닿는지
- 손잡이 쪽 가장자리가 문틀과 부딪히는지
- 경첩 쪽 틈이 한쪽으로 쏠려 있는지
- 문 아래가 바닥이나 문턱에 닿는지
위쪽 반대편이 닿는다면 경첩이 처져서 문 전체가 내려앉은 경우일 수 있습니다. / 이런 경우는 습기 문제가 아니라 [도어락 수리](doorlock-repair.html)나 경첩 점검이 필요할 수 있습니다.

# 걸쇠와 받이 위치가 어긋나는 문제
문이 조금만 부풀거나 처져도 걸쇠가 받이 구멍에 정확히 들어가지 못합니다. / 그러면 문은 닫혔는데 잠기지 않거나, 잠겼는데 열리지 않는 일이 생깁니다.
번호를 눌러 모터 소리는 나는데 걸쇠가 빠지지 않는다면 이 어긋남이 원인일 수 있습니다. / 이때 문을 안쪽으로 살짝 밀면서 손잡이를 돌리면 열리기도 합니다.
이 증상이 여름철에만 심하다면 계절 영향이 크다고 볼 수 있습니다. / 날씨가 선선해지면 줄지만 같은 일이 해마다 반복되면 위치를 손보는 게 좋습니다.
@ 인계동 현관문 걸쇠 받이 어긋남 점검

# 도어락 번호판에 생기는 습기 문제
더운 날 에어컨 실내와 바깥의 온도 차로 번호판 표면에 물방울이 맺히기도 합니다. / 이 물기 때문에 번호가 눌리지 않거나 한 번 누르면 여러 번 눌린 것처럼 입력되기도 합니다.
마른 수건으로 번호판을 닦고 잠시 두었다가 다시 누르면 돌아오는 경우가 많습니다. / 헤어드라이어로 센 열을 직접 쏘는 것은 부품을 상하게 할 수 있어 권하지 않습니다.
비가 많이 오는 날 문 위로 물이 흘러내리는 구조라면 번호판 쪽으로 물이 들어가는 경우도 있습니다. / 지붕이나 처마가 없는 현관 형태라면 더 조심해야 합니다.

# 배터리도 여름에 방전이 빠르다
더위는 건전지 성능에도 영향을 줍니다. / 뜨거운 환경에서는 건전지 수명이 짧아질 수 있습니다.
번호판이 어둡거나 반응이 느려졌다면 배터리 교체 시기를 의심해 보세요. / 9V 건전지를 바깥 단자에 대면 임시로 전원이 들어옵니다.
교체할 때는 전부 새것으로 바꾸고 다른 종류를 섞어 쓰지 마세요.

# 하지 말아야 할 대처들
급한 마음에 윤활제를 열쇠 구멍이나 번호판 안에 뿌리는 분이 있습니다. / 기름 성분이 먼지를 붙여 나중에 더 심하게 막히는 경우가 있어 권하지 않습니다.
문틀을 칼이나 줄로 깎아 내는 것도 위험합니다. / 한 번 깎으면 되돌릴 수 없고 날씨가 선선해지면 틈이 너무 벌어질 수 있습니다.
문을 발로 차거나 어깨로 밀어 열려 하면 걸쇠가 휘어 더 큰 일이 됩니다. / 안 되면 멈추고 연락 주시는 게 좋습니다.

# 인계동에서 이렇게 알려주세요
인계동은 건물이 가깝게 붙어 있어 위치를 정확히 말씀해 주시면 도착이 빨라집니다. / 아래 정보를 말씀해 주세요.
- 건물 이름 대신 길 이름이나 수원역 방면 등 대략적인 방향
- 층과 호수, 공동 현관 비밀번호 여부
- 번호판 상태와 문이 걸리는 위치
- 열쇠를 갖고 있는지, 보조키가 잠겨 있는지
- 집 안에 아이나 반려동물이 있는지

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다. / 이웃과 집 모두를 지키기 위한 절차이니 이해 부탁드립니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 원인을 보고 먼저 안내합니다. / 괜찮다고 하시면 시작하고 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꾸거나 조정이 필요하면 하기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 문은 덜 상하는 방법으로 엽니다
문이 끼어 있는 상태라도 문과 도어락이 덜 상하는 방법부터 차례로 해봅니다. / 억지로 힘을 쓰지 않고 걸리는 부분을 풀어 엽니다.
[현관문 개문](door-open.html) 페이지에 방법을 정리해 두었습니다. / 작업 중에 알게 된 문제는 끝나고 사실대로 말씀드립니다.

문이 열린 뒤에는 걸쇠 위치와 경첩 상태를 같이 봅니다. / 간단한 조정으로 해결되면 부품을 바꾸지 않고 그대로 정리합니다.
처짐이 심하거나 도어락이 오래돼 불안하다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 계절 영향이 큰 경우에는 선선해진 뒤 한 번 더 점검하는 방법도 안내합니다.
@ 인계동 경첩 걸쇠 조정 문 점검

# 여름을 안전하게 나는 관리 요령
작은 습관으로 여름철 문 문제를 많이 줄일 수 있습니다. / 어렵지 않으니 한두 가지만이라도 해 보세요.
- 번호판과 문 아랫부분을 마른 수건으로 가끔 닦기
- 비가 들이치는 문이라면 틈새로 물이 들어오는지 확인
- 문이 뻑뻑해졌을 때 억지로 닫지 않고 위치부터 살피기
- 장마 전에 배터리 점검
- 경첩 나사가 헐거워졌는지 가끔 확인

# 인계동 말고 수원 어디든 갑니다
인계동 근처 우만동, 매탄동, 세류동까지 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
[수원시 출장열쇠](suwon.html) 페이지와 [출장 지역](area.html)에서 다니는 동네를 볼 수 있습니다.

? 번호판에 물이 맺혔는데 써도 되나요? | 마른 수건으로 닦고 잠시 기다린 뒤 눌러 보세요. 계속 오작동하면 점검을 받으세요.
? 윤활제를 뿌려도 되나요? | 권하지 않습니다. 먼지가 붙어 더 막힐 수 있습니다.
