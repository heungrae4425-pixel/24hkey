# 인계동 창고와 컨테이너 사무실, 문 한 번 막히면 하루가 멈춥니다
인계동은 수원역 생활권과 이어져 상가와 업무 건물이 많고, 골목 안쪽에 창고나 컨테이너로 쓰는 작은 사무실도 눈에 띄는 동네입니다. / 이런 곳은 집 현관문과 달리 열쇠 하나로 오래 쓰는 일이 많아 잠금장치가 고장 나면 일이 바로 멈춥니다.
이 글은 창고나 컨테이너 사무실 출입문이 안 열릴 때 확인할 것과 연락하는 방법을 정리했습니다. / 현관 도어락 이야기와 구조가 다른 부분을 중심으로 적었습니다.
@ 인계동 창고 컨테이너 출입문 잠금장치

# 창고와 컨테이너 문은 집 현관문과 이렇게 다릅니다
컨테이너 문은 철판이 두껍고 바깥으로 여는 구조라 쓰는 열쇠 모양도 다릅니다. / 자물쇠를 바깥에 걸어 잠그는 방식과 문에 박힌 잠금장치를 쓰는 방식이 섞여 있습니다.
- 막대형 걸쇠에 맹꽁이자물쇠를 거는 방식
- 문 가장자리에 잠금 막대가 올라가는 방식
- 일반 실린더를 달아 쓰는 개조 방식
- 슬라이딩 문이나 셔터 옆 쪽문에 다는 방식
어떤 방식인지에 따라 여는 방법도, 필요한 장비도 달라집니다.

# 안 열리는 흔한 원인을 구분해 보세요
창고 문은 비바람에 그대로 노출되는 만큼 고장 이유도 비슷합니다.
- 열쇠가 들어가긴 하는데 돌아가지 않는 경우
- 비나 녹 때문에 자물쇠 안쪽이 굳은 경우
- 문 틈새가 틀어져 걸쇠가 팽팽하게 물린 경우
- 열쇠를 잃어버렸거나 열쇠 관리자가 바뀐 경우
계절이 바뀌는 시기에는 쇠가 줄었다 늘었다 하면서 평소보다 뻑뻑해집니다. / 겨울 아침에 갑자기 안 열리는 일도 이래서 생깁니다.

# 전화하기 전에 해볼 만한 것
먼저 열쇠를 꽂을 때 걸리는 느낌이 있는지, 헛도는지 확인합니다. / 힘을 주어 돌리는 것은 열쇠가 부러지는 원인이 됩니다.
문을 살짝 안쪽으로 밀면서 열쇠를 돌려 보면 걸쇠가 풀리는 때가 있습니다. / 문이 힘을 받고 있으면 걸쇠가 빠지지 않는 구조가 많습니다.
자물쇠에 기름을 많이 뿌리는 것은 권하지 않습니다. / 먼지가 달라붙어 나중에 더 굳을 수 있습니다.

# 열쇠가 부러지거나 박혔을 때
열쇠가 안에서 부러졌다면 억지로 빼려고 하지 말고 그대로 두세요. / 핀셋이나 송곳으로 건드리면 조각이 더 안쪽으로 들어갑니다.
부러진 조각이 보이면 사진을 찍어 두시면 장비를 챙겨 가기 좋습니다. / 박힌 열쇠를 빼고 같은 열쇠를 새로 만들 수 있는지도 같이 봅니다.
관련 사례는 [열쇠 출장](key-call.html) 안내에도 간단히 적어 두었습니다.

# 자물쇠와 걸쇠는 이렇게 열고 바꿉니다
맹꽁이자물쇠 같은 외부 자물쇠는 열쇠가 없으면 부수는 방법밖에 없다고 생각하기 쉽습니다. / 현장에서는 먼저 상하지 않게 열 수 있는지 확인하고, 불가능할 때만 절단 방법을 말씀드립니다.
문에 박힌 실린더 방식은 열리면 안쪽 부품을 확인합니다. / 닳아 있으면 같은 규격으로 바꿀지 그대로 쓸지 여쭤봅니다.
컨테이너는 문이 얇은 판이 아니라 두꺼운 철판이라 구멍을 새로 뚫는 작업은 신중하게 합니다. / 필요하면 작업 전에 어떻게 할지 먼저 설명합니다.
@ 인계동 철제 문 자물쇠 개방 작업

# 도어락을 달아 쓰고 싶을 때 확인할 것
요즘은 컨테이너 사무실에도 디지털 도어락을 다는 곳이 늘고 있습니다. / 다만 철판 문에는 일반 현관문과 같은 도어락이 그대로 맞지 않을 수 있습니다.
- 문 두께와 안쪽 구조(철판인지 합판 덧댐인지)
- 비 가림이 되는지, 바깥에서 물이 닿는지
- 전기가 필요한지 배터리로 충분한지
설치 가능 여부는 현장을 보고 말씀드립니다. / 일반 설치 안내는 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.

# 이런 상황이라면 바로 연락 주세요
혼자 오래 붙잡고 있을수록 문이 더 상합니다.
- 일하러 나왔는데 열쇠가 안 맞고 장비가 안에 있는 경우
- 퇴근하며 닫았는데 다음 날 열쇠가 안 도는 경우
- 임차인이 바뀌어 열쇠가 하나밖에 없는 경우
- 열쇠를 가진 사람이 연락이 안 되는 경우
이런 때 "오늘 안에 열어야 한다"는 사정도 말씀해 주세요. / 시간에 맞춰 우선순위를 정하는 데 도움이 됩니다.

# 위치를 알려주실 때 이렇게 말씀해 주세요
문 상태를 말로 설명하기 어려우면 전화를 끊지 않고 사진만 먼저 보내셔도 됩니다. / 아래 항목을 참고해 주세요.
창고나 컨테이너는 주소로만은 찾기 어려운 곳이 많습니다. / 인계동 어느 골목인지, 근처에 눈에 띄는 큰 길이나 건물이 무엇인지 알려 주세요.
- 대략의 위치와 수원역 쪽 방향인지
- 문의 모양(여닫이인지, 미닫이인지, 셔터인지)
- 자물쇠 사진 한 장
- 안에 사람이나 동물이 있는지
사진 한 장이면 어떤 장비를 챙겨 갈지 정하기 쉽습니다. / 모양을 모르겠으면 모르겠다고만 하셔도 됩니다.

# 도착하면 문을 열어도 되는 분인지 확인합니다
창고나 사무실은 임대로 쓰는 곳이 많아 누가 열어 달라고 하는지가 중요합니다. / 사업자등록증, 계약서, 신분증, 관리하는 곳의 확인 중 하나를 보여 주시면 됩니다.
소유주와 이용자가 다른 경우 두 분이 통화로 확인하는 방법도 있습니다. / 확인이 어려우면 작업을 할 수 없습니다.
사진이나 서류는 문 열기 전에 확인하는 용도로만 씁니다.

# 비용은 열기 전에 먼저 말씀드립니다
문 형태와 자물쇠 종류, 필요한 작업을 보고 얼마인지 먼저 말씀드립니다. / 동의하시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다.
작업 방식은 [현관문 개문](door-open.html) 페이지와 [이용안내](guide.html)에 같은 기준으로 적어 두었습니다.
@ 인계동 사무실 출입문 비용 안내 전 확인

# 창고 문 오래 쓰는 관리법
컨테이너 문은 비바람과 햇빛을 그대로 맞는 만큼 관리 차이가 바로 드러납니다. / 아래 몇 가지만 해 두어도 갑자기 막히는 일이 크게 줄어듭니다.
작은 관리만 해도 문이 막히는 일이 크게 줄어듭니다.
- 겨울 전에 자물쇠 구멍에 먼지 털고 마른 상태 유지
- 열쇠는 복사본을 따로 보관하고 한 곳에 모아 두지 않기
- 문이 처지지 않게 경첩 나사 확인
- 걸쇠에 녹이 보이면 초기에 닦아 내기
- 열쇠 관리자가 바뀌면 번호나 열쇠를 같이 정리
복사본 열쇠는 문이 정말 안 열릴 때 가장 빨리 해결해 줍니다. / 한 개만 쓰는 곳일수록 미리 만들어 두세요.

# 인계동 말고 수원 어디든 갑니다
인계동 가까운 권선동, 세류동, 우만동, 화서동은 물론 수원 안이면 동네 상관없이 갑니다. / 동네 정리는 [수원시 출장열쇠](suwon.html) 페이지에 있습니다.
서울과 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인할 수 있습니다.
