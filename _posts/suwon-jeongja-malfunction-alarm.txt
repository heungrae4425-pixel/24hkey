# 삑 삑 소리는 나는데 문은 그대로입니다
정자동 집 앞에서 번호를 눌렀는데 소리는 나는데 문이 열리지 않습니다. / 불은 들어오니 배터리는 아닌 것 같고, 그렇다고 고장이라고 단정하기도 어렵습니다.
이 글은 수원 장안구 정자동 쪽에서 이런 경험을 한 분들을 위해 소리로 원인을 짐작하는 방법을 적었습니다. / 도어락은 소리로 상태를 알려 주는 경우가 많아서, 귀 기울이면 힌트가 있습니다.
@ 정자동 도어락 오작동 경고음 출장열쇠

# 먼저 소리를 구분해 보세요
짧게 삑 한 번은 입력이 됐다는 뜻이 대부분입니다. / 길게 삐이 하거나 연속으로 삐삐삐 울리면 경고나 오류인 경우가 많습니다.
어떤 소리가 나는지 휴대폰으로 녹음해 두면 전화로 설명하기 편합니다. / 제품마다 소리의 의미가 달라서 설명서가 있다면 한 번 찾아보세요.

# 연속 경고음이 울릴 때
번호를 여러 번 틀렸거나 배터리가 부족할 때 연속 경고음이 나옵니다. / 이럴 때는 번호를 더 누르지 말고 잠시 기다립니다.
일정 시간이 지나면 입력이 다시 풀리는 제품이 많습니다. / 그 뒤에도 같으면 배터리가 거의 바닥인 경우를 의심합니다.

# 모터 소리만 윙 하고 날 때
번호는 맞고 모터가 도는 소리도 들리는데 문이 안 열리면 걸쇠 쪽 문제입니다. / 모터가 돌아도 걸쇠를 빼 주지 못하는 상태입니다.
문이 문틀에 눌려 있거나, 안쪽 보조키가 잠겨 있을 수도 있습니다. / 이때는 문을 살짝 밀면서 손잡이를 돌려 보세요.
@ 수원 정자동 출장열쇠 도어락 모터

# 아무 소리도 안 나는 경우
번호판은 켜지는데 눌러도 아무 반응이 없다면 입력부나 내부 연결 문제일 수 있습니다. / 비 오는 날 습기가 번호판 안으로 들어가 생기는 일도 있습니다.
마른 수건으로 번호판을 닦고 잠시 기다린 뒤 다시 눌러 보세요. / 그래도 안 되면 배터리와 접점을 점검해야 합니다.

# 건전지 비상 전원으로 확인
바깥 아래쪽에 9V 건전지 단자가 있으면 건전지를 대고 번호를 눌러 보세요. / 이렇게 열리면 배터리 문제로 좁혀집니다.
열리지 않고 소리만 난다면 도어락 내부나 걸쇠 쪽을 의심해야 합니다. / 이 경우는 억지로 시도하지 말고 전화 주시는 편이 안전합니다.

# 하면 안 되는 일
번호판을 세게 두드리거나 분해해 보는 것은 권하지 않습니다. / 안에 있는 연결선이 빠지면 간단했던 문제가 커집니다.
손잡이를 계속 돌리며 당기면 걸쇠가 문틀에 더 깊이 물릴 수 있습니다. / 소리가 이상하면 멈추고 상태를 기록해 두세요.

# 전화 주실 때 알려주세요
- 정자동 어디쯤인지, 근처 큰 건물이나 학교
- 어떤 소리가 나는지(짧은 삑, 긴 삐, 연속음, 모터 소리)
- 번호판 불이 켜지는지
- 안쪽에 아이나 반려동물이 있는지
도어락 모양과 제조사 표시를 사진으로 보내주시면 원인 짐작에 도움이 됩니다.

# 현장에서 하는 순서
문 상태와 도어락 종류를 보고 문이 상하지 않는 방법부터 해봅니다. / 방법은 [현관문 개문](door-open.html)에서 설명합니다.
열리고 나면 소리가 났던 원인을 같이 찾아봅니다. / 배터리, 걸쇠, 내부 연결 중 어디가 문제인지 확인해 드립니다.
작업 중에 부품을 바꿔야 하면 손대기 전에 미리 여쭤봅니다.

# 사시는 분인지 확인합니다
신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나를 부탁드립니다. / 문을 여는 일이라 꼭 필요한 절차입니다.
확인이 어렵다면 작업을 진행하지 못하니 미리 준비해 주세요.

# 비용은 시작 전에 말씀드립니다
문 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. [이용안내](guide.html)에서 진행 방식을 볼 수 있습니다.

# 고쳐 쓸지 바꿀지는 상태를 보고
소리의 원인이 배터리나 접점이라면 간단히 손보고 끝나는 경우가 많습니다. / 이런 경우는 [도어락 수리](doorlock-repair.html)로 충분합니다.
같은 증상이 반복되고 제품이 너무 오래됐다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 정자동 24시 출장열쇠 010-3664-5455

# 오작동을 줄이는 관리
경고음이 나면 바로 배터리를 확인해 새것으로 바꿉니다. / 번호판에 물기가 남지 않게 닦는 것도 도움이 됩니다.
- 비 오는 날 후에 번호판 상태 확인
- 번호판에 손때가 심하면 마른 수건으로 닦기
- 배터리는 한꺼번에 전부 새것으로 교체
- 평소와 다른 소리가 나면 미루지 않기

# 정자동 말고 수원 어디든 갑니다
장안, 팔달, 권선, 영통 등 수원 전 지역을 24시간 다닙니다. / 수원에서 다니는 동네는 [수원 출장 지역](suwon.html)에 정리해 두었습니다.
수원 밖은 [출장 지역](area.html) 지도에서 확인하세요.

# 자주 묻는 질문
? 소리만 나고 안 열리면 고장인가요? | 배터리, 걸쇠, 보조키 등 원인이 여러 가지입니다. 현장에서 확인하고 말씀드립니다.
? 소리를 녹음해 두는 게 도움이 되나요? | 네, 전화로 설명하실 때 원인을 짐작하기 쉬워집니다.
? 못 열면 비용을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 열고 나서 수리도 해주시나요? | 네, 원인을 찾아 수리하거나 교체가 필요한 경우 미리 말씀드립니다.
? 한밤중에도 오시나요? | 24시간 전화를 받습니다. 시간 신경 쓰지 말고 연락 주세요.

# 마무리
도어락이 소리로 알려 주는 단서를 먼저 기억해 두세요. / 그래도 안 열리면 위치와 소리만 알려주셔도 출동 여부를 바로 말씀드립니다.
24시출장열쇠는 서울, 경기 전 지역에서 24시간 전화를 받습니다. / 전화 010-3664-5455
