# 카드 한 장으로 시작하는 고민
조원동에서 가족이 늘거나 자녀가 처음 혼자 등하교하게 되면 카드키를 한 장 더 만들고 싶어집니다. / 반대로 카드키를 잃어버렸을 때는 그 카드로 문이 열리지 않게 막고 싶습니다.
두 경우 모두 도어락에 카드를 추가 등록하거나 기존 카드를 지우는 과정을 거칩니다. / 이 글은 그 순서와 조심할 점을 차근차근 적었습니다.
막히는 부분이 생기면 [수원 출장열쇠](suwon.html)에서 도와드립니다.
@ 조원동 카드키 태그 추가 등록

# 카드키 도어락이 카드를 기억하는 방식
카드키는 도어락 안에 등록된 정보와 카드의 정보가 맞을 때 열립니다. / 카드 한 장마다 고유한 값이 있고, 도어락은 그 값을 목록처럼 저장해 둡니다.
그래서 같은 모양의 카드라도 등록하지 않은 카드는 열리지 않습니다. / 또 등록하지 않은 카드를 아무리 많이 대도 도어락이 반응하지 않는 것이 정상입니다.
도어락마다 저장할 수 있는 카드 수가 달라서 기억 용량이 가득 차면 새 카드가 안 들어가기도 합니다.

# 추가 등록을 하기 전 확인할 것
등록 모드에 들어가려면 보통 관리자 번호나 마스터 버튼이 필요합니다. / 관리자 번호를 잊었다면 먼저 그 문제부터 해결해야 합니다.
- 설명서나 도어락 안쪽 덮개에 등록 방법이 적혀 있는지
- 관리자 번호나 기존 비밀번호를 알고 있는지
- 새로 등록할 카드가 도어락과 같은 방식인지
- 도어락 배터리가 충분한지
배터리가 약하면 등록 중에 전원이 꺼져 설정이 꼬일 수 있습니다. / 등록하기 전에 새 배터리로 바꿔 두면 안전합니다.

# 일반적인 추가 등록 순서
제품마다 다르지만 대체로 비슷한 흐름입니다. / 정확한 순서는 도어락 설명서를 우선으로 하세요.
먼저 도어락 안쪽 덮개를 열어 등록 버튼을 찾거나 번호판으로 관리자 모드에 들어갑니다. / 안내음이 나면 등록할 카드를 번호판 부근 인식 부분에 가볍게 댑니다.
등록음이 나면 완료이고, 이어서 다른 카드도 같은 방식으로 댑니다. / 마치고 나서 문을 연 상태로 등록한 카드를 하나씩 직접 테스트하세요.
@ 수원 조원동 도어락 카드 등록 순서

# 문을 닫아 둔 채 테스트하면 안 되는 이유
등록 직후 확인은 반드시 문이 열린 상태에서 해야 합니다. / 닫힌 채로 시험하다가 등록이 안 되어 있으면 집에 들어가지 못할 수 있습니다.
카드를 대고 잠금이 풀리는 소리와 모터 동작을 확인합니다. / 안쪽과 바깥쪽에서 각각 한 번씩 열고 잠가 보세요.
등록이 잘 안 되었다면 다시 등록 모드로 들어가 처음부터 시도합니다. / 이때도 문을 열어 둔 채 진행하는 것이 안전합니다.

조원동에서도 가족이 함께 쓰는 카드가 늘면 누가 어떤 카드를 갖고 있는지 헷갈리기 쉽습니다. / 이름표 대신 카드 뒷면에 작은 표시를 해두면 분실 때 어떤 카드인지 구분하기 편합니다.

# 분실했을 때 가장 먼저 할 일
카드키를 잃어버렸다면 줍는 사람이 그 카드로 문을 열 가능성이 있습니다. / 불안하시겠지만 대부분은 카드에 주소가 적혀 있지 않아 위치를 알기 어렵습니다.
그래도 안전을 위해 분실한 카드를 도어락에서 지우는 것이 좋습니다. / 도어락에 따라 카드를 한 장씩 지우는 것은 안 되고 전체를 지운 뒤 남은 카드를 다시 등록해야 하는 경우도 있습니다.
이럴 때는 남은 카드를 모두 모아서 다시 등록해야 합니다.

# 초기화가 필요한 경우와 주의점
초기화는 카드와 번호를 모두 지우는 큰 작업입니다. / 필요한 경우에만 하고 하기 전에 새로 등록할 번호와 카드를 준비해 두세요.
초기화를 하면 기존에 등록된 모든 카드가 사라져서 가족 카드도 다시 등록해야 합니다. / 임시로 쓴 번호나 손님 번호도 함께 지워집니다.
이사한 뒤나 전 세입자가 쓰던 카드가 남아 있을 수 있을 때는 초기화가 가장 안전합니다. / 초기화 후 [도어락 설치](doorlock-install.html)에서 말하는 것처럼 새 번호 등록을 바로 마치세요.

등록 과정에서 안내음이 평소와 다르거나 아무 소리가 나지 않으면 일단 멈추세요. / 중간에 여러 번 눌러 설정이 꼬이는 것보다 상태를 말씀해 주시는 편이 훨씬 빠릅니다.

# 직접 하기 어려울 때
설명서가 없거나 도어락 모델이 오래되어 등록 방법을 모르겠는 경우가 있습니다. / 억지로 버튼을 여러 번 눌러 보다가 오히려 설정이 잠기는 일도 있습니다.
이럴 때는 도어락 사진을 보내주시면 모델을 보고 방법을 안내해 드립니다. / 출장이 필요한 경우 먼저 전화로 판단하고 필요한 장비를 챙겨 갑니다.
관리자 번호를 잊어 등록 모드에 못 들어갈 때도 있는데, 이 경우는 [현관문 개문](door-open.html)과 함께 확인 절차가 필요할 수 있습니다.

# 도착 후 신분 확인과 비용 안내
도어락 설정을 바꾸는 일이라 사시는 분인지 먼저 확인합니다. / 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나를 준비해 주세요.
확인이 끝나면 작업 내용과 비용을 시작하기 전에 설명드립니다. / 마음에 안 드시면 돌아가고, 문을 열지 못한 경우에는 비용을 받지 않습니다.
부품을 교체해야 한다면 교체 전에 따로 여쭙습니다. / 진행 과정은 [이용안내](guide.html)에서도 볼 수 있습니다.

# 카드를 새로 사려면
카드키는 도어락 제품과 맞는 방식이어야 등록됩니다. / 같은 모양이라도 인식 방식이 다르면 안 됩니다.
스티커형 태그나 팔찌형 등 모양은 달라도 도어락이 읽는 방식이 같은지만 맞으면 됩니다. / 구매 전에 도어락 사진을 보여주고 문의하시면 맞는 종류를 알려드립니다.
너무 싼 호환 카드는 인식률이 떨어지는 경우가 있으니 확인 후 구입하세요.
@ 조원동 출장열쇠 카드키 태그 종류 확인

# 수리와 교체 사이의 판단
카드가 잘 안 읽히거나 등록 후에도 반응이 약하다면 도어락의 인식 부분 문제일 수 있습니다. / 이때는 [도어락 수리](doorlock-repair.html)로 먼저 점검하는 것이 순서입니다.
도어락이 너무 오래되어 카드를 인식하는 기능이 약해졌다면 [도어락 교체](doorlock-replace.html)를 고려할 수 있습니다. / 필요 이상으로 교체를 권하지 않고, 고쳐서 쓸 수 있으면 그렇게 말씀드립니다.

# 카드키를 오래 편하게 쓰는 방법
카드키는 작아서 잃어버리기 쉽습니다. / 가족 수만큼 등록하되 보관 위치를 정해 두는 것이 좋습니다.
- 카드마다 사용하는 사람이 누구인지 가족이 알아 두기
- 지갑에 카드와 신분증을 함께 두지 않기
- 분실한 즉시 도어락에서 등록 정보 정리하기
- 카드키 하나는 집 안 정해진 곳에 따로 보관하기
이사나 세입자 교체가 있다면 반드시 초기화하고 카드를 다시 등록하세요.

# 조원동에서 수원 어디든
조원동 가까이 화서동, 율전동, 천천동도 다닙니다. / 수원 안이라면 24시간 출동합니다.
수원 전체 안내는 [수원시 출장열쇠](suwon.html)에서, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
