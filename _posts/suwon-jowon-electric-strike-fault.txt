# 조원동 전기 걸쇠 문, 눌러도 안 풀릴 때
조원동은 성균관대역 쪽 생활권으로 이어지는 동네이고, 상가와 사무실, 공동 출입구에 전기로 풀리는 문을 쓰는 곳이 있습니다. / 이런 문은 걸쇠를 전기로 풀어 주는 전기정(전기 걸쇠)이 달려 있어 일반 도어락과 고장 모양이 다릅니다.
이 글은 전기정이 달린 출입문이 버튼이나 카드를 대도 안 풀릴 때의 원인과 점검 순서를 정리했습니다. / 일반 도어락이 아닌 전기로 여닫는 출입문을 쓰는 분께 도움이 됩니다.
@ 조원동 전기정 출입문 걸쇠 구조

# 전기정이 뭔지 먼저 알아볼까요
전기정은 문틀 쪽에 달려 있는 작은 걸쇠 받이로, 전기가 들어오면 걸쇠를 풀어 주는 장치입니다. / 문 안쪽 버튼, 카드 리더기, 인터폰 열림 버튼 같은 것이 신호를 보내면 걸쇠가 풀립니다.
- 전기가 들어올 때 풀리는 방식
- 전기가 끊겨야 풀리는 방식
- 문 가장자리에 턱이 있어 걸쇠를 잡는 구조
- 문을 당기거나 미는 힘이 걸쇠를 누르고 있는 상태
어느 방식인지에 따라 고장일 때 문이 잠기는지, 열리는지 결과가 다릅니다.

# 눌러도 안 풀리는 흔한 원인
전기 장치는 증상이 비슷해도 원인이 여러 곳에 있을 수 있습니다.
- 전원 공급 장치나 어댑터가 꺼졌거나 고장 난 경우
- 버튼 스위치나 카드 리더기가 먹통인 경우
- 전기정이 문틀에 맞지 않아 걸쇠가 눌려 있는 경우
- 배선이 헐거워졌거나 습기로 접촉이 약해진 경우
버튼을 누를 때 문 쪽에서 딸깍 소리가 나는지 먼저 들어 보세요. / 소리가 나는데 안 열리면 기계적인 문제, 소리가 없으면 전기 쪽 문제일 가능성이 큽니다.

# 딸깍 소리가 나는데 문이 안 열릴 때
전기정은 풀려도 문이 걸쇠를 누르고 있으면 못 열립니다. / 문을 살짝 안쪽으로 밀어 걸쇠의 눌림을 줄인 상태에서 버튼을 눌러 보세요.
- 버튼을 누르는 동안 문을 살짝 당기거나 밀기
- 두 사람이 한 명은 버튼, 한 명은 문을 잡고 해 보기
- 문이 처졌는지 아래쪽 틈 확인
문이 처져서 문틀에 걸리면 전기정 힘으로는 부족합니다. / 이런 때는 경첩과 문틀 점검이 먼저입니다.
@ 버튼 누르며 문을 살짝 밀어 확인

# 소리조차 안 날 때는 전원을 의심하세요
전기가 끊긴 상태라면 버튼도 카드도 반응하지 않습니다. / 건물 전체가 정전인지, 이 문만 안 되는지 먼저 확인합니다.
- 같은 건물의 다른 전기 장치(인터폰, 조명)는 정상인지
- 전원 장치에 불이 들어와 있는지
- 차단기가 내려가 있지 않은지
- 전원 장치 주변에 습기나 물 샌 흔적이 있는지
정전이라면 전기가 돌아와야 해결되는 문제입니다. / 건물 관리하는 곳에 확인을 부탁하세요.

# 전기가 끊기면 열리는 방식과 닫히는 방식
전기정은 전기가 끊겼을 때 열리는 방식과 잠기는 방식이 있어서 상황이 완전히 다릅니다.
- 전기가 끊기면 열리는 방식은 화재 시 대피를 위해 쓰는 경우가 많음
- 전기가 끊기면 잠기는 방식은 도난 방지를 중시하는 경우
- 방식을 모르면 전원 차단 전에 먼저 사진을 찍어 설명하기
함부로 전원을 내리거나 배선을 만지면 안 열리거나 감전의 위험도 있습니다. / 전기 배선은 직접 만지지 말고 연락 주세요.

# 직접 만지지 말아야 할 것
전기가 흐르는 장치라 일반 도어락보다 조심할 부분이 더 많습니다. / 급해도 아래는 하지 말아 주세요.
급하다고 문 근처 장치를 건드리는 분들이 있습니다.
- 전기정 덮개를 열고 선을 만지는 것
- 문틀 쪽 금속 부분을 드라이버로 비트는 것
- 걸쇠를 얇은 금속으로 밀어 넣는 것
- 전원 장치를 임의로 분리하는 것
금속이 들어가면 합선이나 장치 파손이 생길 수 있습니다. / 한번 상한 전기정은 교체해야 하는 경우가 많아 비용도 늘어납니다.

# 이런 때 출장열쇠를 부르세요
혼자서 전기 장치를 오래 만지는 것보다 상태를 알리고 맡기는 쪽이 빠릅니다. / 특히 영업 시간이나 출근 시간이 걸린 문이라면 더 그렇습니다.
전기정 문은 일반 현관문보다 급할 때가 많습니다.
- 가게나 사무실 문이 안 열려 영업을 못 하는 경우
- 공동 출입구라 여러 사람이 통행해야 하는 경우
- 밤 시간에 직원이나 입주자가 못 들어오는 경우
- 버튼은 눌리는데 문이 그대로인 경우
이때 가게인지 사무실인지 공동 출입구인지 말씀해 주세요. / 장소에 맞는 준비를 해서 갑니다.

# 전화로 알려주시면 좋은 것
출장 전에 파악하면 한 번에 해결할 확률이 높아집니다.
- 문이 열리는 방향(밀어서 여는지, 당겨서 여는지)
- 버튼이나 카드를 대었을 때 소리가 나는지
- 문 옆 전원 장치나 인터폰 상태
- 정전이나 공사가 있었는지
문틀 사진을 한 장 보내 주시면 전기정 모양을 미리 볼 수 있습니다. / 모양을 모르겠으면 문 전체 사진만 보내도 됩니다.

# 도착하면 열어도 되는 분 확인과 비용 안내
출입문을 여는 일이라 이용하시는 분이 맞는지 먼저 확인합니다. / 신분증, 사업자등록증, 계약서, 건물 관리하는 곳의 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요. / 건물주와 임차인이 다르면 통화로 확인하는 방법도 있습니다.

문 구조와 전기정 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮으시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
@ 조원동 전기정 점검 및 개방 작업

# 문을 열고 난 뒤의 수리와 교체
문이 열리면 전기정이 왜 안 풀렸는지 원인을 확인합니다. / 걸쇠만 닦으면 되는 경우도 있고, 전기정 자체를 바꿔야 하는 경우도 있습니다.
- 걸쇠 받이의 이물이나 녹 제거
- 전기정 위치와 문 닫힘 높이 맞추기
- 전원 장치와 버튼 스위치 확인
- 필요하면 같은 규격 전기정으로 교체
교체 방식은 [도어락 교체](doorlock-replace.html) 안내와 비슷하게, 바꾸기 전에 먼저 말씀드립니다. / 문 열기 방식은 [현관문 개문](door-open.html)에도 적어 두었습니다.

# 전기정 출입문 오래 쓰는 관리
작은 점검으로 갑자기 안 열리는 일을 줄일 수 있습니다.
- 월 1회 버튼과 카드로 열림 확인
- 문틀 걸쇠 받이에 먼지나 이물이 쌓이지 않게 청소
- 정전 시 열쇠로 여는 방법을 직원들과 공유
- 비상용 열쇠를 안전한 곳에 하나 보관
비상 열쇠가 있는 곳을 아는 사람이 한 명뿐이면 그 사람이 없을 때 곤란합니다. / 두세 명이 알고 있으면 좋습니다.

# 조원동 말고 수원 어디든 갑니다
조원동 가까운 정자동, 율전동, 천천동, 화서동은 물론 수원 안이면 동네 상관없이 갑니다. / 동네 정리는 [수원시 출장열쇠](suwon.html) 페이지에 있습니다.
서울과 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
