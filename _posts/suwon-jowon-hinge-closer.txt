# 조원동 현관문이 덜 닫힌다면
조원동은 아파트와 빌라가 섞인 주거지입니다. / 현관문이 끝까지 안 닫히거나 닫힐 때 걸리는 소리가 나면 도어락보다 문 자체에 문제가 있는 경우가 많습니다.
이 글은 조원동에서 문이 덜 닫힐 때 살펴볼 것과 직접 해볼 수 있는 일을 적었습니다. / 어디까지 직접 하고 어디서 전화할지도 함께 정리했습니다.
@ 조원동 현관문 경첩 도어클로저 점검

# 문이 덜 닫히면 생기는 일
문이 덜 닫힌 채로 지내면 외풍과 소음이 들어오고 난방비에도 영향이 있습니다. / 이웃에게 불편을 주는 쾅 닫히는 소리도 같이 생기기 쉽습니다. / 작은 문제처럼 보여도 일상에 계속 영향을 주는 부분입니다.
문이 완전히 닫히지 않으면 도어락 걸쇠가 문틀에 제대로 물리지 않습니다. / 그러면 잠긴 줄 알았는데 열려 있거나, 반대로 안 열리는 일이 생깁니다.
단순히 불편한 정도가 아니라 보안에도 영향이 있어서 일찍 손보는 게 좋습니다.

# 닫힘 문제의 원인은 보통 세 가지입니다
- 경첩이 헐거워져 문이 처진 경우
- 도어클로저(문 닫는 장치)의 힘이 약해졌거나 세진 경우
- 문틀이나 바닥이 변해서 문이 걸리는 경우
어느 쪽인지에 따라 해결 방법이 다릅니다.

# 문이 처졌는지 간단히 보는 법
문을 닫은 뒤 위쪽과 아래쪽 틈의 폭을 눈으로 비교해 보세요. / 한쪽이 유난히 좁으면 문이 처진 것입니다.
손잡이 높이의 걸쇠가 문틀 구멍에 정확히 들어가는지도 확인합니다. / 어긋나 있으면 닫혀도 걸쇠가 덜 들어갑니다.

# 경첩 나사가 풀렸을 때
오래 쓴 문의 경첩 나사가 헐거워지면 문이 조금씩 처집니다. / 나사만 다시 조이면 해결되는 경우도 많습니다.
나사 구멍이 닳아서 헛돌면 다른 방법이 필요합니다. / 이 경우는 무리하게 조이지 말고 전화 주세요.

# 도어클로저가 너무 세거나 약할 때
문 위쪽에 달린 도어클로저는 문이 닫히는 속도와 힘을 조절합니다. / 너무 세면 쾅 닫히면서 소리가 크고 약하면 덜 닫힙니다.
조절 나사가 있는 제품은 조금씩 돌려 맞출 수 있습니다. / 처음 보는 분이 무리하게 돌리면 더 나빠지기도 해서 어렵다면 점검을 부탁하세요.

# 겨울과 장마에 더 심해지는 이유
문과 문틀은 습도와 온도에 따라 미세하게 부풀거나 줄어듭니다. / 같은 문이 계절에 따라 닫히는 느낌이 달라질 수 있습니다.
특히 여름 장마철에는 문이 부풀어 걸리는 일이 잦습니다. / 일시적이라면 날씨가 개면 괜찮아지기도 합니다.

# 문이 닫혔는데 안 열리는 경우
걸쇠가 문틀에 지나치게 꽉 물려 있으면 열 때 힘이 듭니다. / 문을 안쪽으로 조금 밀면서 손잡이를 돌리면 열리기도 합니다.
이 증상이 자주 반복되면 문틀 위치를 손봐야 합니다. / 열고 난 뒤 점검하러 다시 오시라고 하셔도 됩니다.
@ 조원동 걸쇠 문틀 조정

# 전화할 때 이렇게 말씀해 주세요
문이 덜 닫히는지, 쾅 닫히는지, 걸리는 소리가 나는지 말씀해 주세요. / 위쪽에 도어클로저가 달려 있는지도 알려주시면 좋습니다.
문 사진을 문자로 보내주시면 필요한 부품을 미리 챙겨 갈 수 있습니다. / 어느 쪽 경첩이 문제인지 추정하는 데도 도움이 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 점검하고 손보는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소나 주소가 나온 우편물 중 하나면 됩니다.
문이 열려 있어서 작업 자체가 위험하지 않더라도 이 절차는 같습니다. / 서류가 없으면 관리하는 분의 확인도 가능합니다.

# 비용은 작업 전에 말씀드립니다
문 상태와 필요한 작업을 확인한 뒤 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 아니면 그냥 돌아갑니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 말없이 붙는 비용은 없고, 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 조원동 경첩 도어클로저 교체 비용 안내

# 도어락과 같이 살펴봅니다
문이 덜 닫히는 원인이 도어락이 아니어도 걸쇠 위치가 맞는지 함께 봅니다. / 도어락이 처진 문 때문에 무리하게 작동하는 경우도 있기 때문입니다.
도어락 자체가 말썽이면 [도어락 수리](doorlock-repair.html)로 해결하고, 낡았다면 [도어락 교체](doorlock-replace.html)를 안내합니다.

# 문을 오래 쓰려면
문 손잡이를 잡고 흔들어 보았을 때 덜컹거리는 느낌이 있으면 경첩이나 손잡이 고정이 느슨해진 것입니다. / 이때 나사만 조여도 훨씬 부드러워지는 경우가 있습니다. / 무리하지 말고 어려우면 점검을 부탁하세요.
- 경첩 나사를 해마다 한 번씩 조여 보기
- 문을 세게 닫지 않기
- 도어클로저는 닫히는 속도가 이상하면 바로 점검
- 문과 바닥 사이에 걸리는 물건이 없는지 확인
- 비가 많은 철에는 문 아래쪽 물기 닦기
문은 서서히 변해서 처음에는 잘 모르지만 작은 관리가 큰 고장을 막아 줍니다.

# 조원동 말고 수원 어디든 갑니다
영통, 광교, 인계동, 권선동, 화서동까지 수원 전 지역을 다닙니다. / 수원 안이면 24시간 출동합니다.
전체 안내는 [수원 출장열쇠](suwon.html)에 있고, 문이 잠기거나 안 열릴 때는 [현관문 개문](door-open.html)을 보세요. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

# 자주 묻는 질문
? 문이 덜 닫히는 것만 봐 주시나요? | 네, 문이 안 열릴 때뿐 아니라 닫힘 문제도 점검해 드립니다.
? 경첩만 바꾸나요? | 상태를 보고 조이는 정도로 되는지, 부품을 바꿔야 하는지 먼저 말씀드립니다.
? 도어클로저도 되나요? | 조절과 점검이 가능하고, 바꿔야 하면 바꾸기 전에 여쭤봅니다.
? 밤에도 오시나요? | 24시간 받습니다.
? 못 고치면 비용이 드나요? | 작업 전에 비용을 말씀드리고, 문을 못 여는 경우는 비용을 받지 않습니다.
