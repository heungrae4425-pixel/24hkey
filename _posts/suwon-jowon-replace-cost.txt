# 도어락 바꿀 때가 됐나 싶을 때
조원동에서 오래 쓴 도어락이 자꾸 말썽이면 바꿔야 하나 고민하게 됩니다. / 수리로 충분한지, 교체가 나은지 판단이 서지 않는 분들이 많습니다.
이 글은 수원 장안구 조원동 쪽에서 도어락 교체를 생각하는 분들을 위해 확인할 것을 순서대로 정리했습니다. / 비용을 어떻게 안내받게 되는지도 미리 알아 두면 마음이 편합니다.
@ 조원동 도어락 교체 출장열쇠

# 교체가 필요한 신호
같은 고장이 몇 번 반복되거나 부품이 단종돼 수리가 어려운 경우입니다. / 번호판이 자주 먹통이 되고 배터리를 갈아도 금방 방전된다면 점검해 볼 때입니다.
손잡이가 헐거워지거나 잠금 소리가 달라졌다면 내부가 낡았을 수 있습니다. / 이런 증상이 겹치면 교체를 고민해도 좋습니다.

# 먼저 수리로 되는지 확인
배터리나 접점 문제 정도면 [도어락 수리](doorlock-repair.html)로 해결되는 일이 많습니다. / 고쳐서 쓸 수 있으면 굳이 바꿀 필요가 없습니다.
현장에서 상태를 보고 수리가 낫다고 판단되면 그렇게 말씀드립니다. / 교체를 강하게 권하지 않습니다.

# 교체 전에 확인할 문의 조건
문 두께와 기존 구멍 크기에 따라 맞는 제품이 달라집니다. / 같은 모양이라도 안쪽 부품 위치가 다른 경우가 있습니다.
- 문이 목재인지 철제인지
- 문 두께와 기존 도어락 구멍 모양
- 보조키가 따로 있는지 여부
- 손잡이 방향(좌측 여닫이인지 우측인지)
이 정보가 맞아야 설치 후 어긋나지 않습니다.

# 제품은 어떤 기준으로 고를지
번호키만 쓸지, 지문이나 카드까지 쓸지 가족 구성으로 정합니다. / 아이가 있거나 손이 자주 바쁜 집은 지문이나 카드가 편합니다.
배터리 교체 주기와 비상 전원 단자 유무도 중요하게 봅니다. / 설치 후에도 오래 쓰려면 쉽게 구할 수 있는 건전지를 쓰는 제품이 편합니다.
@ 수원 조원동 출장열쇠 도어락 설치

# 사진을 보내주시면 편합니다
현재 쓰는 도어락과 문 옆면, 안쪽 모양을 사진으로 보내주세요. / 어떤 제품이 맞는지 미리 짐작할 수 있습니다.
제조사 이름이 보이면 함께 알려주세요. / 사진만으로 확정하기 어려운 경우에는 현장에서 한 번 더 확인합니다.

# 비용은 이렇게 안내합니다
교체는 제품 종류와 문 상태에 따라 달라서 정해진 값을 앞세우지 않습니다. / 현장에서 문과 기존 도어락을 보고 얼마인지 먼저 말씀드립니다.
괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다. / 말없이 붙는 비용은 없습니다.
부품을 추가해야 하는 상황이면 바꾸기 전에 반드시 여쭤봅니다. [이용안내](guide.html)에도 같은 방식이 적혀 있습니다.

# 설치에 걸리는 시간
기존 도어락을 떼고 새 제품을 맞춰 끼우는 과정이라 문 상태에 따라 차이가 납니다. / 구멍을 넓히거나 보조키를 손봐야 하면 시간이 더 걸립니다.
작업 전에 대략 어느 정도 걸릴지 말씀드립니다. / 집을 비워야 하는 시간이 있다면 미리 알려주세요.

# 설치 후 같이 확인하는 것
문이 잘 닫히고 잠기는지 몇 번 반복해 봅니다. / 번호와 카드를 등록하고 한 번씩 직접 눌러 보시게 합니다.
비상 전원이 어디 있는지 알려드립니다. / 배터리 교체 방법과 경고음이 울릴 때 하는 일도 설명드립니다.
@ 조원동 24시 출장열쇠 010-3664-5455

# 교체하지 않아도 되는 경우
문이 상하거나 경첩이 처져 생긴 문제라면 도어락을 바꿔도 해결되지 않습니다. / 이때는 문 상태부터 손봐야 합니다.
불필요한 교체는 권하지 않으니 안심하고 상태부터 보여 주세요. / 설치 방법은 [도어락 설치](doorlock-install.html)에서 자세히 설명하고 있습니다.

# 이미 문이 안 열리는 상태라면
교체하려는데 문이 먼저 안 열리는 상황이면 먼저 문부터 엽니다. / 방법은 [현관문 개문](door-open.html)에서 설명합니다.
문을 열고 나서 교체 여부를 같이 정하시면 됩니다. / 문을 못 열면 비용은 받지 않습니다.

# 교체 후 보안 습관
처음 설정한 번호를 그대로 쓰지 말고 새로 정하세요. / 이전 번호나 임시 번호는 남기지 않는 것이 안전합니다.
- 등록한 카드와 지문은 가족 수만큼만 남기기
- 번호는 가족만 아는 숫자로 정하기
- 배터리 교체 날짜를 적어 두기
- 비상 열쇠가 있다면 따로 보관

# 조원동 말고 수원 어디든 갑니다
장안, 팔달, 권선, 영통 등 수원 전 지역을 24시간 다닙니다. / 수원에서 다니는 동네는 [수원 출장 지역](suwon.html)에 정리해 두었습니다.
수원 밖은 [출장 지역](area.html) 지도에서 확인하세요.

# 교체 전에 꼭 정해 두면 좋은 것
도어락을 바꾸기 전에 지금 쓰는 방식 중 불편했던 점을 적어 보세요. / 배터리가 자주 닳았는지, 번호가 보이는 게 싫었는지 같은 불편을 기준으로 삼으면 제품 고르기가 쉬워집니다.
가족 중에 열쇠를 자주 잃어버리는 사람이 있는지, 아이가 혼자 문을 열어야 하는지도 생각해 보세요. / 이런 사정에 따라 필요한 기능이 달라집니다.
설치 당일에 집에 있을 사람과 시간을 정해 두면 작업이 빠르게 끝납니다.
@ 조원동 도어락 교체 준비 점검
교체 상담은 부담 없이 사진 한 장으로 시작하셔도 됩니다. / 지금 쓰는 도어락과 문 옆면을 찍어 보내 주시면 수리로 충분한지, 교체가 나은지 먼저 말씀드립니다.
조원동처럼 주택과 빌라, 아파트가 섞인 동네는 문 규격이 다양해서 현장 확인이 중요합니다. / 확인 없이 제품을 먼저 사 두면 맞지 않아 낭비가 될 수 있으니, 구매 전에 문의해 주시면 맞는 제품을 알려드립니다.

? 제가 산 제품을 달아도 되나요? | 가능한 경우가 많습니다. 문과 제품이 맞는지 먼저 확인해 드립니다.
? 비용은 언제 알려주시나요? | 작업을 시작하기 전에 문과 제품을 보고 먼저 말씀드립니다.
