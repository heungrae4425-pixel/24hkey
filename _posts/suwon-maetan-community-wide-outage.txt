# 매탄동에서 갑자기 단지 전체가 정전되면
매탄동은 영통역과 수원역 방향을 오가는 사람이 많은 주거 지역이라 퇴근 시간대에 단지 정전이 나면 한꺼번에 많은 집이 불편을 겪습니다. / 엘리베이터가 서고 복도 불이 꺼진 상태에서 문 앞에 서면 평소보다 훨씬 막막합니다.
이 글은 단지 전체가 정전됐을 때 세대 도어락에 어떤 일이 생기는지, 각자 문 앞에서 무엇을 확인할지를 정리했습니다. / 혼자 해결이 어려우면 [수원 출장열쇠](suwon.html)를 부르는 순서까지 적었습니다.
@ 매탄동 단지 정전 복도와 세대 현관

# 정전이 되어도 도어락은 바로 꺼지지 않습니다
건전지로 움직이는 도어락은 단지 전기가 나가도 대부분 그대로 작동합니다. / 그래서 정전이 났다는 이유만으로 문이 안 열린다고 단정할 필요는 없습니다.
다만 복도가 어두워서 번호판 위치를 못 찾거나 번호를 잘못 누르는 일이 많아집니다. / 휴대폰 손전등부터 켜고 침착하게 시작해 보세요.
전기선으로 연결된 방식이거나 별도 전원을 쓰는 제품이라면 사정이 다르니 설명서를 확인해 보세요.

# 정전 때 도어락에서 생기는 문제들
- 번호판이 켜지지 않아 번호를 눌러도 반응이 없는 경우
- 전기가 다시 들어오는 순간 도어락이 초기화되거나 이상 동작을 하는 경우
- 공동현관이나 주차장 출입이 막혀 집 문 앞까지 못 오는 경우
- 인터폰이나 월패드가 꺼져 가족과 연락이 안 되는 경우
이 가운데 도어락 자체 문제는 일부이고, 상당수는 단지 설비가 멈춰서 생기는 불편입니다. / 어디서 막혔는지 구분하는 것이 먼저입니다.

# 공동현관이 막혔다면 관리사무소부터
공동현관 문은 보통 단지 전원으로 움직입니다. / 정전이 되면 비상 전원이 따로 있는지에 따라 열리는 방식이 달라질 수 있습니다.
이 경우 열쇠집이 아니라 관리사무소나 경비실에 먼저 문의하는 것이 맞습니다. / 단지 설비는 관리 주체가 책임지고 해결해야 하는 부분입니다.
관리사무소에 이미 문의가 몰려 있을 수 있으니 세대 문 문제는 따로 전화하는 편이 빠를 수 있습니다.
@ 공동현관 앞에서 관리사무소에 문의

# 세대 문 앞 1분 점검
- 휴대폰 손전등으로 번호판을 비춰 보고 불이 들어오는지 확인
- 번호를 누를 때 소리가 나는지 확인
- 소리는 나는데 안 열리면 문을 살짝 밀며 손잡이를 돌려 보기
- 바깥 비상 단자가 있으면 9V 건전지를 대고 번호 입력
번호판이 안 켜지면 정전과 상관없이 건전지가 방전된 것일 수 있습니다. / 마침 정전과 겹쳐 원인을 헷갈리는 경우도 흔합니다.

# 전기가 다시 들어올 때 생길 수 있는 일
정전이 풀리는 순간 전기가 불안정해지면서 전자 기기가 이상 동작을 하는 경우가 있습니다. / 도어락 번호판이 깜빡이거나 경고음이 계속 울리는 일이 그 예입니다.
전기가 돌아왔는데 도어락이 이상하면 건전지를 뺐다가 다시 끼워 보는 것도 방법입니다. / 그래도 정상이 아니면 무리하게 만지지 말고 점검을 받으세요.
복구 직후에는 이웃 집도 같은 증상을 겪을 수 있으니 안내방송이나 공지를 먼저 확인해 보세요.

# 어두운 복도에서 하지 말아야 할 일
정전 때는 이웃들도 같은 복도에서 불안해하고 있습니다. / 소란을 줄이고 차분히 움직이는 것이 모두에게 도움이 됩니다.
- 번호를 급하게 계속 눌러 보는 것 (여러 번 틀리면 입력이 막힘)
- 손잡이를 세게 당기거나 문을 두드리고 차는 것
- 이웃집 문을 두드려 소란을 만드는 것
- 촛불이나 라이터를 번호판 가까이 들이대는 것
어둠 속에서는 서두를수록 실수가 늘어납니다. / 먼저 불빛을 확보하고 천천히 하나씩 확인해 보세요.

# 엘리베이터가 멈췄을 때 문을 여는 일
엘리베이터에 갇힌 경우는 문 여는 문제가 아니라 안전 문제입니다. / 이 경우는 안전 관련 기관이나 관리사무소 연락이 우선입니다.
계단으로 올라온 뒤 문 앞에서 막힌 경우에는 숨을 고르고 번호판부터 확인해 주세요. / 고층일수록 지치기 쉬워 실수가 잦습니다.
어르신이나 아이가 함께라면 계단을 오르내리는 동안 손을 꼭 잡아 주세요. / 어르신이나 아이가 함께라면 안전한 곳에서 기다리게 한 뒤 연락 주시는 것이 좋습니다.

# 연락하실 때 알려주실 내용
- 매탄동 어느 쪽인지, 몇 층 몇 호인지
- 단지 정전인지 우리 집만 정전인지
- 번호판 상태 (꺼짐, 깜빡임, 경고음)
- 도어락 모양과 비상 단자 유무
- 집 안에 아이나 반려동물이 있는지
정전이 여러 집에 퍼졌다면 출동 순서를 정하는 데 도움이 됩니다. / 같은 층 이웃도 비슷한 문제라면 함께 있다고 알려주세요. / 한 번에 여러 집을 돌아볼 수 있어 시간이 줄어듭니다. / 사진을 문자로 보내주시면 맞는 장비를 챙기기 쉽습니다.
@ 도어락 번호판과 비상 단자 사진 전달

# 도착하면 사시는 분인지부터 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
정전 중에는 관리사무소와 연락이 어려울 수 있으니 신분증이나 우편물 사진을 미리 챙겨 두면 좋습니다. / 확인이 어려우면 작업을 할 수 없습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 정전이라 어두운 상황이어도 작업 전 설명은 똑같이 드립니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 복구된 뒤 도어락 상태 확인
전기가 돌아오면 도어락이 잘 잠기고 열리는지 한 번씩 확인해 보세요. / 안쪽에서 잠금 버튼과 보조키를 돌려 보는 것도 같이 하면 좋습니다.
정전을 겪은 뒤 경고음이 잦아졌다면 건전지부터 새것으로 바꿔 보세요. / 그래도 불안하면 [도어락 수리](doorlock-repair.html)로 접점과 모터를 살핍니다.
너무 오래된 제품이라면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 다음 정전에 대비하는 작은 준비와 출동 지역
- 비상용 9V 건전지를 현관 서랍이나 가방에 하나 넣어 두기
- 휴대폰 손전등과 보조 배터리 충전 상태 유지
- 도어락 건전지를 해가 바뀔 때 한꺼번에 교체
- 비밀번호는 가족 모두 외우고 메모는 집 밖에 두지 않기
- 카드나 열쇠 하나를 믿을 만한 곳에 따로 보관
준비는 거창할 필요 없이 한두 가지면 충분합니다. / 매탄동 말고도 영통동, 원천동, 광교동, 인계동 등 수원 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다. / 정전은 한 번 겪고 나면 다음에는 훨씬 침착하게 넘길 수 있습니다.

# 자주 묻는 질문
? 단지가 정전이면 도어락도 다 꺼지나요? | 건전지식은 대부분 그대로 작동하지만 번호판이 안 보이거나 다른 설비가 멈춰 불편할 수 있습니다.
? 정전 때 공동현관이 안 열리면 열쇠집을 불러야 하나요? | 단지 설비는 관리사무소에 먼저 문의하시는 것이 맞습니다. 세대 문은 따로 연락 주세요.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에도 전화해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
? 정전이 풀린 뒤 도어락이 이상하면요? | 건전지를 다시 끼워 보고 그래도 이상하면 억지로 만지지 말고 전화 주세요.
