# 현관에서 찬바람이 든다면 문부터 의심해 보세요
매탄동에서 영통역이나 수원역 쪽으로 오가다 보면 계절마다 집 안 공기가 현관 쪽에서 달라지는 걸 느끼는 분들이 있습니다. / 늦가을부터 현관 앞 바닥이 유난히 차갑거나, 바람 부는 날 문 쪽에서 휘파람 같은 소리가 난다는 이야기입니다.
이런 증상은 난방이 약해서가 아니라 문이 틀에 딱 맞게 닫히지 않아서 생기는 경우가 많습니다. / 도어락 고장과도 이어질 수 있어 한 번 점검해 둘 만합니다.
이 글은 틈새 바람과 소음의 원인을 문 닫힘 상태 중심으로 정리했습니다. / 집에서 확인할 수 있는 방법과 부를 때의 기준까지 순서대로 적었습니다.
@ 매탄동 현관문 틈새 바람 소음 점검

# 틈이 어디에서 생기는지부터 찾기
문 둘레는 위, 아래, 경첩 쪽, 손잡이 쪽 네 변으로 나뉩니다. / 어느 변에서 바람이 드는지 알아야 원인을 좁힐 수 있습니다.
얇은 종이를 문틈에 끼우고 문을 닫아 보세요. / 종이가 쉽게 빠지는 곳이 틈이 큰 곳입니다.
향을 피우거나 휴지를 얇게 찢어 문틈 가까이 대면 바람의 방향도 보입니다. / 위쪽에서 들어오는지 아래쪽에서 들어오는지가 원인 구분의 첫 단서가 됩니다.

# 위쪽 틈이 크고 아래 틈이 작다면 처짐
문이 한쪽으로 처지면 위 모서리 쪽 틈이 벌어지고 아래 모서리는 문틀에 닿습니다. / 반대로 아래가 벌어지고 위가 좁으면 다른 문제입니다.
방화문은 무겁기 때문에 경첩에 하중이 계속 걸려 시간이 지나면 조금씩 내려앉습니다. / 이 경우 걸쇠도 받침 구멍과 높이가 어긋나 뻑뻑하게 잠깁니다.
문을 열고 닫을 때 바닥에 긁히는 소리가 난다면 처짐이 꽤 진행된 상태입니다.

# 패킹이 닳으면 바람과 소리가 새어 들어옵니다
문 둘레에는 고무나 실리콘으로 된 패킹이 붙어 있어 틈을 막아 줍니다. / 오래되면 단단해지고 갈라져 문이 닫혀도 완전히 밀착되지 않습니다.
패킹이 찢어지거나 일부가 떨어져 나왔는지 손가락으로 훑어 보세요. / 눌렀을 때 탄력이 없고 납작하게 굳어 있으면 교체 시기입니다.
패킹만 바꿔도 소음과 외풍이 줄어드는 집이 많습니다. / 새 패킹을 붙일 때는 기존 접착 자국을 깨끗이 닦아야 잘 붙습니다.
@ 매탄동 현관문 패킹 밀착 상태 확인

# 도어클로저가 약하면 덜 닫힙니다
문 위쪽에 달린 도어클로저는 문이 끝까지 닫히도록 힘을 줍니다. / 이 힘이 약해지면 문이 마지막 몇 센티미터를 남기고 멈춥니다.
문을 반쯤 열고 손을 놓았을 때 걸쇠 소리가 날 때까지 닫히는지 확인해 보세요. / 중간에 멈춘다면 도어락이 잠기지 않거나 외풍이 드는 원인이 됩니다.
도어클로저의 조절 나사는 마음대로 돌리면 문이 쾅 닫혀 위험해질 수 있습니다. / 조정이 필요하면 상담을 권합니다. / 닫히는 속도는 어린이와 반려동물 안전과도 이어지니 신중하게 다뤄야 합니다.

# 걸쇠와 받침이 맞지 않을 때
걸쇠가 받침 구멍에 완전히 들어가야 문이 틀에 붙어서 닫힙니다. / 살짝만 걸쳐 있으면 겉으론 닫힌 듯 보여도 바람이 새고 손으로 밀면 흔들립니다.
문을 닫고 안쪽에서 손으로 가볍게 밀어 보세요. / 달그락거리거나 움직이면 완전히 걸리지 않은 것입니다.
받침 안의 이물질도 한 번 확인해 보세요. / 얇은 막대로 털어 내는 것만으로 좋아지기도 합니다.

# 소음이 나는 부분별로 구분하기
- 윙윙 휘파람 같은 소리는 문틈이나 패킹 쪽
- 끼익 하는 소리는 경첩이 마른 경우
- 덜컥거리는 소리는 걸쇠와 받침 어긋남
- 쿵 하는 둔한 소리는 도어클로저 조절 문제
소리의 모양을 구분해 두면 전화로 설명하기도 쉽습니다. / 소리가 나는 때가 문을 열 때인지 닫을 때인지도 같이 메모해 두세요. / 날씨나 시간대에 따라 달라지는지도 알려 주시면 단서가 됩니다.

집에서 해볼 수 있는 간단한 방법도 있습니다. / 경첩에서 소리가 날 때 소량의 윤활제를 발라 주면 도움이 됩니다. / 너무 많이 뿌리면 흘러내려 바닥과 문을 더럽히니 조금씩만 쓰세요.
외풍은 문틈에 시판 문풍지를 붙이는 것으로 임시로 줄일 수 있습니다. / 다만 문이 덜 닫히는 근본 원인은 그대로이니 잠깐의 처방으로만 보세요.
문턱 위에 쌓인 먼지와 이물질을 쓸어 내는 것도 닫힘에 영향을 줍니다. / 신발장 앞 매트가 문 아래를 스치지 않는지도 한 번 보세요.

# 틈새 때문에 도어락이 이상해지는 경우
문이 밀착되지 않으면 도어락 센서가 닫힘을 제대로 읽지 못할 수 있습니다. / 자동 잠금이 가끔 안 되거나 경고음이 반복되는 증상으로 나타납니다.
이럴 땐 도어락을 바꾸기 전에 문 닫힘 상태를 먼저 점검하는 쪽이 낫습니다. / 도어락 자체는 멀쩡한데 문이 문제인 사례가 적지 않기 때문입니다.
도어락 쪽 증상이 계속되면 [도어락 수리](doorlock-repair.html)에서 상태별로 설명하는 내용을 참고하세요.

# 이럴 땐 전화 주세요
- 문이 문틀에 긁히며 닫히거나 열릴 때 힘이 드는 경우
- 걸쇠가 받침에 걸리지 않아 문이 저절로 열리는 경우
- 패킹이 심하게 닳아 눈에 띄게 틈이 보이는 경우
- 이전 점검 이후 틈이 계속 커지는 경우
이런 증상은 오래 두면 문 자체가 변형될 수 있습니다. / 상황을 알려 주시면 필요한 점검만 합니다. / 고칠 부분이 없으면 없다고 솔직하게 말씀드립니다.

# 문 앞에서 막혔다면
틈새를 살피다가 문이 안 열리는 상황이 생기면 억지로 당기지 마세요. / 번호판 상태와 문을 살짝 밀며 손잡이를 돌렸을 때의 느낌을 알려 주시면 됩니다.
위치는 매탄동 건물 이름과 동, 호수, 영통역 방향인지 수원역 방향인지 말씀해 주세요. / 도어락 사진이 있으면 문자로 보내 주세요.
현관문이 열리지 않을 때의 기본 순서는 [현관문 개문](door-open.html)에도 적어 두었습니다.

# 도착하면 사시는 분인지부터 확인합니다
문을 여는 작업이 필요하면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.
@ 매탄동 24시 출장열쇠 현관문 점검 신분 확인

# 비용은 시작 전에 먼저 알려 드립니다
문 상태를 보고 비용을 먼저 말씀드립니다. / 동의하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않으며, 부품이 필요하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 정리했습니다.
고쳐서 쓸 수 있다면 교체는 권하지 않고, 정말 필요할 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 매탄동 말고 수원 어디든
매탄동 옆 원천동, 영통동은 물론 수원 전 지역을 다닙니다. / 영통역, 수원역, 광교중앙역, 성균관대역 근처도 같은 방식입니다.
다니는 동네는 [수원시 출장열쇠](suwon.html)에서 보시고, 다른 지역은 [출장 지역](area.html)을 확인하세요.
