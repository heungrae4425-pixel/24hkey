# 매탄동 원룸 앞에서 문이 안 열릴 때
매탄동은 원룸과 다세대 건물이 골목마다 이어진 동네입니다. / 퇴근이 늦거나 약속이 길어져 밤에 돌아왔는데 문이 안 열리면 몸보다 마음이 먼저 급해집니다.
이 글은 매탄동 원룸에서 현관문이 잠겼을 때 해볼 것과 피할 것을 순서대로 적었습니다. / 끝까지 안 열리면 [수원 출장열쇠](suwon.html)를 부르는 과정도 함께 설명합니다.
@ 매탄동 원룸 출장열쇠 현관문 개문

# 원룸 문이 유난히 자주 잠기는 이유
방이 작고 짐이 적어서 열쇠나 카드를 한곳에 두지 않고 들고 다니는 경우가 많습니다. / 그러다 외투를 갈아입거나 가방을 바꾸는 날 카드를 두고 나오는 일이 생깁니다. / 같은 층에 여러 호실이 모여 있어 문이 닫히는 소리를 못 듣고 지나치기도 합니다.
원룸은 문이 닫히는 순간 자동으로 잠기는 도어락이 많습니다. / 쓰레기를 버리러 잠깐 나왔다가 그대로 닫히는 일이 가장 흔합니다.
손에 휴대폰이 없으면 연락할 방법도 막힙니다. / 이럴 때는 이웃에게 전화를 빌리면 훨씬 빨리 해결됩니다.

# 먼저 문 앞에서 살펴볼 세 가지
아래 세 가지만 보셔도 원인이 어느 쪽인지 가늠할 수 있습니다.
- 번호판이 켜지는지, 아니면 아예 꺼져 있는지
- 손잡이가 돌아가는데 문이 안 빠지는지
- 문이 밀리는 느낌이 있는지, 꽉 막혀 있는지
번호판이 꺼져 있으면 배터리, 소리는 나는데 안 열리면 걸쇠 쪽을 먼저 의심합니다.

# 공동현관과 호실 문은 따로 생각하세요
건물 입구 공동현관이 안 열리는 것과 호실 문이 안 열리는 것은 원인이 전혀 다릅니다. / 어디서 막혔는지 먼저 정리해서 말씀해 주시면 상담이 빨라집니다.
공동현관이 건물 공용 장치라면 관리하는 분께 먼저 연락하는 게 맞는 경우도 있습니다. / 호실 안쪽 문만 막혔다면 바로 연락 주셔도 됩니다.

# 집주인에게 먼저 알려야 하는 경우
세입자로 사는 집이라면 문을 열고 나서 집주인에게 알려 두는 편이 마음이 편합니다. / 도어락 교체나 부품 교환이 필요한 경우에는 특히 그렇습니다.
출동을 부르는 일 자체는 사는 분 본인이 하셔도 됩니다. / 신분 확인만 되면 작업에 문제가 없습니다.
@ 매탄동 다세대 도어락 문 열기

# 번호키인지 열쇠인지 먼저 알려주세요
번호키 도어락인지 열쇠를 꽂는 방식인지에 따라 챙겨 가는 장비가 달라집니다. / 문 사진을 문자로 보내 주시면 맞는 준비를 하고 갑니다.
손잡이 일체형인지 문 옆에 따로 달린 보조 잠금인지도 알려주시면 좋습니다. / 문 윗부분에 별도 잠금이 있는지도 같이 봐 주세요.

# 밤늦게 귀가했을 때 해두면 좋은 것
늦은 시간이라 망설여지는 분이 많지만 24시간 전화를 받습니다. / 시간 신경 쓰지 말고 매탄동 위치와 건물 모양만 알려주세요.
골목 안쪽이라 차가 들어오기 어려운 곳이면 큰길 쪽 기준점도 같이 알려주시면 좋습니다. / 편의점이나 건물 이름을 말씀해 주시면 헤매지 않고 도착합니다.

# 하지 말아야 할 행동
건물 창문이나 베란다로 넘어 들어가려는 시도는 정말 위험합니다. / 특히 저층이 아니라면 추락 사고로 이어질 수 있어 절대 하지 마세요. / 문 앞에서 기다리는 편이 훨씬 안전하고 빠릅니다.
카드나 도구로 문틈을 억지로 벌리는 분들이 있습니다. / 문과 문틀이 상하면 열고 난 뒤에 고칠 일이 더 커집니다.
비밀번호를 연달아 틀리면 도어락이 일정 시간 입력을 막기도 합니다. / 서너 번 해보고 안 되면 멈추는 게 좋습니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 적힌 우편물, 관리하는 분의 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 휴대폰에 저장된 사진이나 전입 서류도 도움이 됩니다. / 확인이 어려우면 작업을 못 하니 미리 챙겨 두면 좋습니다.
@ 수원 출장열쇠 원룸 신분 확인 후 개문

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 본 다음 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 붙는 숨은 비용은 없습니다. 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 난 뒤 같이 확인하는 것
문이 열리면 도어락이 잘 잠기고 열리는지 한 번 더 확인합니다. / 배터리가 원인이었다면 새것으로 바꿨는지도 함께 봅니다.
원룸은 문이 자동으로 잠기는 구조가 많아서 열쇠나 카드를 몸에 지니는 습관이 중요합니다. / 자세한 개문 방법은 [현관문 개문](door-open.html) 페이지에 있습니다.

# 오래 쓰면 생기는 고장은 수리로 먼저
도어락이 자꾸 말썽이면 바로 교체를 권하지 않고 고쳐 쓸 수 있는지부터 봅니다. / [도어락 수리](doorlock-repair.html)로 해결되면 그게 가장 부담이 적습니다.
너무 오래된 제품이라 부품이 없을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 원룸 생활에서 문 앞 사고 줄이는 습관
- 현관 앞에 여분 열쇠를 숨기지 말고 믿을 수 있는 사람에게 맡기기
- 번호키 배터리는 계절이 바뀔 때 한 번에 교체
- 쓰레기 버리러 나갈 때도 휴대폰은 꼭 들고 나가기
- 카드키는 지갑과 가방에 하나씩 나눠 보관
작은 습관 몇 가지로 한밤에 문 앞에서 막히는 일이 크게 줄어듭니다.

# 매탄동 말고 수원 어디든 갑니다
영통, 광교, 인계동, 권선동, 화서동까지 수원 전 지역을 다닙니다. / 수원 안이면 동네를 가리지 않고 24시간 출동합니다.
서울과 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
