# 여러 사람이 쓰는 문은 기록이 먼저입니다
수원 매탄동에는 영통역과 수원역 방면을 오가는 직장인이 함께 쓰는 작은 사무실이나 공유 공간이 있습니다. / 사람이 여럿이면 문 하나를 둘러싼 크고 작은 혼선이 생기기 쉽습니다.
누가 열쇠를 갖고 있는지, 비밀번호를 누가 아는지 아무도 정확히 모르는 때가 가장 위험합니다. / 이 글은 매탄동에서 공동 공간을 운영하는 분들이 열쇠와 번호를 정리하는 순서를 적었습니다.
거창한 시스템이 아니라 종이 한 장에서 시작해도 충분합니다.
@ 매탄동 공동 사무실 출입문 열쇠 관리

# 현재 상태부터 목록으로 만듭니다
정리의 첫걸음은 지금 어떤 열쇠와 번호가 돌아다니는지 파악하는 일입니다. / 기억에 의존하지 말고 한 번에 적어 보세요.
- 도어락 비밀번호를 아는 사람의 수와 이름
- 실물 열쇠와 카드가 몇 개 있고 누가 들고 있는지
- 이미 그만둔 사람이 쓰던 번호가 남아 있는지
- 비상으로 문을 열어 줄 수 있는 사람이 누구인지
적고 나면 생각보다 번호가 오래 방치돼 있다는 걸 알게 되는 경우가 많습니다. / 이 목록이 이후 모든 정리의 기준이 됩니다.

# 사람이 바뀔 때마다 번호도 바꿉니다
공동 공간에서 가장 흔한 문제는 나간 사람이 번호를 그대로 아는 것입니다. / 악의가 없어도 관리 면에서는 바꾸는 쪽이 깔끔합니다.
입주자나 팀원이 바뀔 때 번호를 새로 정하는 규칙을 미리 만들어 두세요. / 규칙이 있으면 번호를 바꾸자고 말하는 것이 껄끄럽지 않습니다.
번호를 바꿀 때는 모두에게 한꺼번에 알려서 누군가 문 앞에서 막히지 않게 합니다. / 한 명이라도 못 들으면 다음 날 아침 문 앞에서 전화가 옵니다.

# 개인별 번호가 가능한 제품이라면
도어락 중에는 사람마다 따로 번호를 등록할 수 있는 제품이 있습니다. / 이런 제품은 한 사람이 나가도 그 사람 번호만 지우면 됩니다.
개인별 번호를 쓸 수 없는 제품이라면 공용 번호를 주기적으로 바꾸는 쪽을 권합니다. / 기존 제품에서 어떤 방식이 가능한지는 사진을 보내 주시면 확인해 드립니다.
교체를 고민하신다면 [도어락 교체](doorlock-replace.html) 전에 필요한 기능부터 정해 두세요. / 사용 인원, 출입 시간대, 기록 필요 여부가 기준이 됩니다.
@ 매탄동 사무실 도어락 개인 번호 등록

# 열쇠 복사와 카드 발급 규칙
열쇠를 복사해 나눠 줄 때는 누구에게 몇 개를 줬는지 반드시 적어 두세요. / 복사본이 늘어날수록 회수하기가 어려워집니다.
카드키는 한 장씩 번호나 이름이 매겨진 상태로 관리하면 분실 때 어떤 카드를 지울지 알 수 있습니다. / 이름 없는 카드가 여러 장이면 모두 지우고 다시 등록해야 할 수 있습니다.
퇴사나 계약 종료 때 반납받는 절차를 정해 두면 서로 편합니다. / 반납받은 열쇠가 없어졌다면 즉시 번호를 바꾸는 것이 안전합니다.

# 문 앞에서 막혔을 때 누구에게 연락하나
이른 아침이나 야근한 밤에 혼자 문 앞에서 막히면 누구에게 연락할지 정해 두었는지가 중요합니다. / 관리자가 해외에 있거나 연락이 안 되면 모두가 문 밖에 서 있게 됩니다.
비상 연락 담당을 두 사람 이상 정해 두세요. / 건물에 관리사무소가 있으면 그 번호도 같이 적어 둡니다.
도어락 배터리 교체 주기를 한 사람이 맡아서 달력에 적어 두는 것도 도움이 됩니다. / 공용 문일수록 모두가 서로 관리하겠거니 하다가 배터리가 먼저 다 되는 일이 흔합니다.

# 공동 공간 문이 안 열릴 때 확인할 것
번호판이 꺼졌는지, 소리는 나는데 안 열리는지 먼저 봅니다. / 오래 쓰는 공동 출입문은 사용 횟수가 많아 걸쇠나 모터가 먼저 닳기도 합니다.
- 번호판 불빛 여부와 경고음 종류
- 안쪽에서 보조 잠금을 걸었는지
- 문이 완전히 닫히지 않고 걸리는지
- 마지막으로 나간 사람이 누구이고 어떻게 잠갔는지
이 정보만 알려주셔도 출장 전에 원인을 어느 정도 짐작할 수 있습니다. / 상황이 급하면 바로 전화 주세요.
@ 매탄동 상가 사무실 출입문 안 열림 점검

# 오픈 시간을 맞춰야 할 때의 요령
출근이나 영업 시작 시간이 정해져 있다면 문 문제가 곧 일정 문제입니다. / 미리 점검받아 두는 것이 문 앞에서 급히 부르는 것보다 훨씬 낫습니다.
[도어락 수리](doorlock-repair.html)가 필요한 징후가 있으면 시작 전 한가한 시간에 보시길 권합니다. / 번호 입력이 한 번에 안 되거나 모터 소리가 느려지면 미루지 마세요.
여러 사람이 쓰는 문은 한 사람이 이상을 느껴도 다른 사람은 모르고 지나치기 쉽습니다. / 문이 평소보다 뻑뻑하거나 소리가 달라졌다면 공용 메신저에 한 줄 남겨 두는 것만으로 큰 고장을 막을 수 있습니다.
점검을 받을 때는 평소 문을 가장 많이 쓰는 분이 같이 계시면 증상을 정확히 전달할 수 있어 좋습니다.

# 신분 확인은 공동 공간에서도 같습니다
공동 사무실 문을 열어 달라는 요청은 누가 이 공간을 쓰는 사람인지 확인하는 일이 더 까다롭습니다. / 계약서, 사업자 관련 서류, 건물 관리자 확인 같은 방법을 안내합니다.
개인 주거 현관문은 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다. / 공동 공간은 상황이 다양해서 현장에서 맞는 방법을 함께 찾습니다.
확인 없이는 열지 않는 이유는 그 공간에 있는 물건과 사람을 지키기 위해서입니다. / 번거로우셔도 이해 부탁드립니다.

# 비용 안내와 못 열 때
출동하면 문과 도어락 상태를 보고 비용을 열기 전에 말씀드립니다. / 괜찮다고 하시면 시작하고 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하는 경우는 바꾸기 전에 따로 여쭤봅니다.
[이용안내](guide.html)에 진행 순서를 적어 두었습니다.

# 최대한 상하지 않게 엽니다
영업 공간 문은 다시 닫고 쓸 수 있어야 하니 문과 도어락이 상하지 않는 방법을 우선합니다. / 문이 열린 뒤 바로 다시 잠기고 열리는지 확인합니다.
어떻게 여는지는 [현관문 개문](door-open.html)에 설명해 두었습니다. / 작업 중 알게 된 문제는 끝나고 사실대로 말씀드립니다.

# 열고 난 뒤 정리하면 좋은 것
문을 열고 나면 공동 번호와 열쇠 목록을 한 번 정리하기 좋은 때입니다. / 이참에 오래된 번호를 지우고 새로 정하세요.
배터리를 전부 새것으로 바꾸고 날짜를 적어 둡니다. / 비상용 열쇠나 카드는 한 사람에게만 맡기지 말고 두 곳에 나눠 보관합니다.
번호가 바뀌었다는 안내는 메신저 공지로 한 번에 전하되 번호 자체는 개인 메시지로 보내는 편이 낫습니다.

# 매탄동 말고 수원 어디든 갑니다
매탄동 근처 영통동, 원천동, 우만동, 인계동까지 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
[수원시 출장열쇠](suwon.html) 페이지에 다니는 동네를 적어 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 주세요.

매탄동에서 문이 안 열리거나 점검이 필요하면 24시출장열쇠에 연락 주세요. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455입니다.
