# 문이 저절로 잠겼다는 연락이 의외로 많습니다
망포동은 영통역 생활권과 이어져 있어 출퇴근과 등하교로 문을 자주 여닫는 집이 많은 동네입니다. / 그래서 문이 닫히자마자 잠긴다거나, 반대로 잠기지 않는다는 이야기가 자주 나옵니다.
대부분 고장이 아니라 자동 잠김 설정이 원인입니다. / 이 글은 그 설정이 헷갈릴 때 확인할 순서를 적었고, 직접 안 되면 [수원 출장열쇠](suwon.html)를 부르는 때도 함께 담았습니다.
@ 망포동 도어락 자동 잠김 설정 확인

# 자동 잠김이란 무엇인가
문이 닫히고 정해진 시간이 지나면 도어락이 스스로 걸쇠를 내보내 잠그는 기능입니다. / 열쇠를 안 챙겨도 문이 잠겨 있어 편하지만, 설정을 모르면 오히려 곤란합니다.
제품마다 이름이 다릅니다. / 자동 잠금, 오토락, 자동 잠김 시간 설정 등으로 부르니 설명서의 표현을 같이 살펴보세요.

# 쓰레기 버리러 나왔다가 갇히는 흔한 패턴
자동 잠김을 켜 둔 집에서 가장 흔한 일은 잠깐 문밖에 나갔다가 닫히는 경우입니다. / 분리수거를 하러 나가면서 문을 살짝 열어 둔 줄 알았는데 이미 잠겨 버립니다.
이때 열쇠나 번호를 모르면 문 앞에 서 있게 됩니다. / 식구가 안에 있다면 문을 열어 달라고 하면 되지만 혼자라면 막막합니다.

# 시간이 짧게 설정된 경우
자동 잠김 시간이 몇 초로 짧게 맞춰진 집이 있습니다. / 이런 집은 문을 잡고 있는 사이에도 걸쇠가 튀어나와 짐을 든 채 드나들기 힘듭니다.
문이 반쯤 닫힌 상태에서 걸쇠가 문틀을 쳐서 소리가 나기도 합니다. / 이 소리를 고장으로 오해하는 분이 많습니다.

# 자동 잠김이 꺼져 있어 안 잠기는 경우
반대로 아무리 닫아도 잠기지 않는다고 하시는 분도 있습니다. / 이럴 때는 설정이 꺼져 있거나, 이사 오기 전 사람이 꺼 둔 채로 쓰고 있는 경우가 많습니다.
안쪽 잠금 버튼을 눌러야 잠기는 방식으로 바뀌어 있는지도 봅니다. / 한 번 눌러서 잠기는 모델은 그것만으로 해결되기도 합니다.

# 설정을 바꾸기 전에 먼저 확인할 것
설정 방법은 제품마다 다르니 겉으로만 보고 누르지 않는 게 좋습니다. / 잘못 누르면 비밀번호가 초기화되거나 다른 모드로 들어가기도 합니다.
- 안쪽 덮개를 열면 설정 버튼이 있는지
- 도어락 앞면이나 안쪽에 모델명이 적혀 있는지
- 설명서나 제조사 안내 문구를 가지고 있는지
- 지금 번호가 몇 개인지, 가족이 모두 아는지
모델명을 알면 전화로 설정 방법을 설명드리기 훨씬 쉽습니다.

# 설정 중에는 문을 열어 둔 채로
설정을 바꾸는 동안에는 문을 열어 둔 상태에서 작업하세요. / 안쪽 문고리 부분을 확인하면서 바꾸고, 끝나면 문 밖에서 번호를 눌러 정상인지 확인합니다.
설정이 잘못됐을 때 밖으로 나가 닫아 버리면 바로 갇히게 됩니다. / 가족이 안에 있을 때 하는 게 안전합니다.
@ 망포동 도어락 설정 버튼 위치

아이가 있는 집은 문이 닫히자마자 잠기는 쪽이 안전하다고 느낄 수 있습니다. / 반대로 어른이 짐을 자주 들고 드나드는 집은 시간이 조금 여유 있는 편이 편합니다.
반려동물이 문 쪽으로 자주 오는 집은 자동 잠김 때문에 문이 완전히 닫히지 못해 틈이 생기기도 합니다. / 생활 모습에 맞춰 정하는 게 가장 좋습니다.

# 이럴 땐 설정 문제가 아닙니다
가족 구성에 따라 알맞은 설정도 다릅니다. / 아이가 있는 집은 문이 닫히자마자 잠기는 쪽이 안심되고, 어른이 짐을 자주 들고 드나드는 집은 시간이 조금 여유 있는 편이 편합니다.
설정을 바꾼 뒤에는 가족 모두에게 알려 주세요. / 한 사람만 모르면 그 사람이 문 앞에서 잠기는 일을 겪기 쉽습니다.
현관 안쪽에 간단한 메모를 붙여 두는 것도 방법입니다. / 자동 잠김이 켜져 있으니 열쇠나 번호를 꼭 챙기라는 한 줄이면 충분합니다.
설정 시간을 바꿨는데도 이전 방식대로 움직인다면 저장이 안 된 것일 수 있습니다. / 이럴 때는 설정 순서를 처음부터 다시 따라가 보세요.
설정과 상관없이 문제가 되는 증상도 있습니다. / 아래와 같다면 설정이 아니라 부품 쪽을 의심합니다.
- 설정은 켜져 있는데 잠기는 소리가 전혀 안 나는 경우
- 모터 소리는 나는데 걸쇠가 나오지 않는 경우
- 잠긴 뒤 안쪽에서 손잡이가 돌아가지 않는 경우
이런 때는 직접 분해하지 마시고 [도어락 수리](doorlock-repair.html)를 알아보시는 편이 좋습니다.

# 이미 잠겨서 못 들어갈 때
자동 잠김 때문에 갇혔을 때 가장 먼저 해볼 것은 가족이나 동거인에게 연락해 안에서 열어 달라고 하는 것입니다. / 안쪽에서는 손잡이를 돌리거나 잠금 버튼을 누르면 대부분 열립니다.
혼자 살고 열쇠도 번호도 기억나지 않는다면 이웃에게 전화를 빌리는 방법도 있습니다. / 늦은 시간이라 망설여지더라도 문 앞에서 오래 기다리는 것보다 낫습니다.
앞으로는 문을 나설 때 주머니의 열쇠나 카드부터 만져 보는 습관을 들이면 같은 일을 줄일 수 있습니다.
설정 때문에 잠겨 버렸다면 먼저 가족과 연락해 번호를 확인합니다. / 번호가 생각나지 않으면 여러 번 누르지 말고 멈추세요.
입력을 계속 틀리면 도어락이 한동안 막힙니다. / 이때는 전화 주시면 위치와 상태를 듣고 바로 방향을 말씀드립니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분인지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
집 안에 두고 나왔다면 관리사무소에 세대 확인을 부탁해 두세요. / 확인이 어려우면 작업을 할 수 없는 점은 양해 부탁드립니다.

# 비용은 문을 열기 전에 먼저 말씀드립니다
비용 이야기가 나오면 부담스러우시겠지만 미리 말씀드리는 것이 원칙입니다. / 설정만 바로잡으면 되는 일인지, 부품이 필요한지에 따라 달라지기 때문에 먼저 상태를 보고 안내합니다.
전화로 설명을 들으시고 결정하셔도 되고, 현장에서 보고 정하셔도 됩니다. / 어느 쪽이든 동의 없이 시작하는 일은 없습니다.
문 상태를 보고 먼저 말씀드린 뒤 동의하시면 시작합니다. / 끝내 못 열면 비용은 받지 않습니다.
열고 나서 말없이 붙는 비용은 없고, 부품 교체가 필요하면 먼저 여쭙습니다. / 진행 순서는 [이용안내](guide.html)에서 볼 수 있습니다.
@ 망포동 출장열쇠 비파손 개문

# 열린 뒤 설정을 같이 정리해 드립니다
문이 열리면 도어락이 어떤 설정으로 되어 있는지 같이 봅니다. / 원하는 방식으로 자동 잠김을 맞추고, 가족이 쓰는 번호도 정리할 수 있습니다.
설정만 바꾸면 되는 경우에는 교체를 권하지 않습니다. / 너무 낡았거나 기능이 부족하면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 망포동 말고 수원 어디든 갑니다
망포동 가까운 영통동, 원천동, 매탄동, 광교동도 다닙니다. / 수원 안이면 24시간 출동합니다.
다니는 동네는 [수원시 출장열쇠](suwon.html)에, 다른 지역은 [출장 지역](area.html)에 정리했습니다.
