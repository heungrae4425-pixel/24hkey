# 망포동에서 어르신 방문이 안에서 안 열린다는 전화
망포동은 영통역 생활권과 이어져 있어 부모님을 모시고 사는 집과 어르신 혼자 사는 집이 함께 섞여 있는 동네입니다. / 퇴근하고 들어와 보니 방문이 닫힌 채 안에서 대답이 없거나, 안에서 "문이 안 열린다"고 하시는 일이 종종 있습니다.
이 글은 어르신이 방 안에서 문을 못 열고 계실 때 가족이 문 밖에서 할 수 있는 일을 순서대로 적은 글입니다. / 현관이 아니라 방문, 안방 문, 화장실 문처럼 집 안쪽 문이 대상입니다.
먼저 말씀드리면 문 여는 일보다 안에 계신 분의 안전 확인이 우선입니다. / 아래 순서를 차분히 따라 주세요.
@ 망포동 어르신 방문 안쪽 잠김 출장열쇠

# 가장 먼저 할 일은 말을 걸어 상태를 확인하는 것
문 앞에서 이름을 부르고 "문 옆에 와 계세요, 천천히 하세요"처럼 짧게 말씀드립니다. / 대답이 또렷하면 급한 상황은 아닙니다.
대답이 없거나 말이 어눌하거나 신음 소리가 들리면 상황이 다릅니다. / 쓰러지셨을 가능성이 있으니 문 여는 연락보다 119 신고가 먼저입니다.
119 대원이 도착해도 문은 열어야 하므로, 신고한 뒤에 저희에게도 연락 주시면 같이 대비할 수 있습니다. / 이런 경우는 전화로 "안에 사람이 쓰러져 있는 것 같다"고 꼭 먼저 알려 주세요.

# 방문이 안 열리는 흔한 이유 네 가지
어르신 방문은 오래된 손잡이를 그대로 쓰는 경우가 많아 고장 모양이 비슷합니다.
- 손잡이 가운데 버튼을 눌러 잠갔는데 풀리는 방법을 잊으신 경우
- 손잡이 안쪽 스프링이 약해져 돌려도 걸쇠가 안 들어가는 경우
- 문이 습기나 처짐으로 문틀에 꽉 끼어 손잡이가 헛도는 경우
- 안쪽에 작은 고리나 걸쇠를 걸어 두고 잊으신 경우
어르신은 힘이 모자라서 손잡이를 끝까지 못 돌리시는 때도 있어, 고장이 아닌데 안 열리는 것처럼 보이기도 합니다.

# 문 밖에서 안쪽 상황을 알아내는 질문
전화나 문 너머 대화로 몇 가지만 여쭤보면 원인을 많이 좁힐 수 있습니다.
- 손잡이 가운데나 옆에 튀어나온 버튼이 눌려 있는지
- 손잡이가 돌아가긴 하는데 문이 안 당겨지는지, 아예 안 돌아가는지
- 손잡이 아래나 문 위쪽에 작은 고리가 걸려 있는지
한꺼번에 여러 가지를 물으시면 당황하실 수 있으니 하나씩 천천히 여쭤보세요. / 손잡이 사진을 가족에게 문자로 받아 보는 것도 방법입니다.

# 안에서 풀 수 있는 잠금은 이렇게 안내해 드리세요
버튼형 잠금은 손잡이를 돌리면 풀리는 것이 많습니다. / 한 손으로 버튼을 당기듯 누르고 다른 손으로 손잡이를 돌려 보시라고 말씀드립니다.
문이 안쪽으로 열리는 구조인지 바깥쪽으로 열리는 구조인지도 확인합니다. / 당겨야 하는데 계속 밀고 계시는 경우가 의외로 많습니다.
고리가 걸려 있으면 고리를 위로 들어 올리면서 문을 살짝 밀어 주시라고 안내합니다. / 어르신이 직접 하시기 어려워 보이면 억지로 시키지 말고 그만두는 게 좋습니다.
@ 방문 손잡이 버튼 잠금 풀기 안내

# 밖에서 문을 두드리거나 어깨로 밀지 마세요
조급한 마음에 문을 세게 밀거나 발로 차는 가족이 있습니다. / 안에 계신 분이 놀라 더 당황하시고, 문 뒤에 쓰러져 계시면 다치실 수도 있습니다.
특히 문 바로 뒤에 어르신이 서 계시거나 앉아 계실 수 있어 문이 갑자기 열리면 위험합니다. / 문에서 한 걸음 떨어지시라고 먼저 말씀드린 뒤에 작업합니다.
드라이버로 손잡이를 억지로 뜯으면 문과 손잡이가 모두 상하고 나중에 안쪽 잠금이 더 안 풀립니다. / 그대로 두고 연락 주시는 편이 훨씬 낫습니다.

# 이런 상황이면 바로 출장열쇠를 부르세요
아래 경우는 혼자 해결하려 하지 말고 전화 주시는 게 안전합니다.
- 안에서 대답은 하시는데 손잡이가 아예 돌아가지 않는 경우
- 방 안에 화장실이 없어 오래 계시면 곤란한 경우
- 혼자 계신 어르신이 점점 불안해하시는 경우
- 가족이 멀리 있어 이웃이 대신 연락해 주는 경우
어르신이 불안해하시면 전화를 끊지 말고 문 너머로 계속 대화를 이어가 주세요. / 도착할 때까지 목소리만으로도 안정이 됩니다.

# 방문 개방은 문을 상하지 않게 하는 것이 기본
집 안쪽 방문은 현관문보다 구조가 단순해 대부분 문과 손잡이를 상하지 않게 열 수 있습니다. / 먼저 손잡이 구멍이나 틈으로 잠금 부위만 풀어 보고, 안 되면 다른 방법으로 넘어갑니다.
방문 손잡이는 열고 난 뒤 잘 작동하는지 확인합니다. / 고장 난 손잡이는 고쳐 쓸 수 있는지 먼저 보고, 어려우면 [도어락 수리](doorlock-repair.html) 방법으로 손봅니다.
작업 방식이 궁금하시면 [현관문 개문](door-open.html) 페이지에 같은 원칙이 적혀 있습니다.

# 도착하면 가족인지 확인합니다
집 안이라도 문을 여는 일이라 사시는 분의 가족인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
이웃이 대신 연락을 주셨다면 가족과 통화로 확인할 수 있게 해 주세요. / 확인이 어려우면 작업을 할 수 없습니다.
어르신이 쓰러지신 응급 상황이면 119와 함께 움직이므로 순서가 바뀔 수 있으니 상황을 먼저 말씀해 주세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
손잡이 종류와 문 상태를 확인한 뒤 얼마인지 먼저 말씀드립니다. / 괜찮으시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 갑자기 붙는 비용도 없습니다.
손잡이를 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
@ 망포동 방문 손잡이 점검 후 마무리

# 같은 일이 또 생기지 않게 바꿔 둘 것
어르신 방 손잡이는 이 정도를 권해 드립니다.
- 안에서 잠그는 버튼식 대신 잠금 없는 손잡이로 교체
- 안쪽 손잡이를 레버형으로 바꿔 힘이 약해도 쉽게 내리도록
- 문 아래가 걸리지 않게 문틀과 경첩 점검
- 밤에 길을 알 수 있게 문 주변 작은 조명 두기
꼭 교체가 필요한 것은 아니고 지금 손잡이가 멀쩡하면 그대로 쓰셔도 됩니다. / 다만 자주 갇히는 일이 있었다면 [도어락 교체](doorlock-replace.html)와 비슷한 방식으로 손잡이만 바꾸는 것도 상담해 드립니다.

# 평소에 가족이 해 두면 좋은 약속
어르신과 미리 정해 두면 위급할 때 도움이 됩니다.
- 방문은 완전히 닫고 주무시지 않기, 살짝 열어 두기
- 안에서 문이 안 열리면 큰 소리로 부르거나 벨 누르기
- 휴대폰은 늘 손 닿는 곳에 두고 가족 번호를 단축키로 저장
- 이웃에게 비상 연락을 부탁해 두기
어르신께는 "문이 안 열려도 잘못이 아니다, 전화하면 된다"고 말씀드려 주세요. / 부끄러워서 오래 참으시다가 더 힘들어지는 경우가 있습니다.

# 망포동 말고 수원 어디든 갑니다
망포동 가까운 영통동, 매탄동, 원천동, 광교동은 물론 수원 안이면 동네 상관없이 갑니다. / 지역 정리는 [수원시 출장열쇠](suwon.html) 페이지에 있습니다.
서울과 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
