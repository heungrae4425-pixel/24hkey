# 번호가 분명 맞는데 안 열립니다
망포동에서 집에 왔는데 늘 누르던 번호가 갑자기 낯설게 느껴지는 경우가 있습니다. / 오랜만에 쓰는 번호이거나 가족이 바꿨는데 모르고 있었다면 더 그렇습니다.
이 글은 수원 망포동 쪽에서 비밀번호가 기억나지 않아 문 앞에 선 분들을 위해 정리했습니다. / 서두르지 않고 순서대로 하면 문을 상하지 않고 들어갈 수 있습니다.
@ 망포동 도어락 비밀번호 분실 출장열쇠

# 우선 번호를 연달아 누르지 마세요
틀린 번호를 여러 번 누르면 도어락이 일정 시간 입력을 막습니다. / 막히면 맞는 번호를 알아도 한동안 소용이 없어집니다.
세 번 정도 해보고 안 되면 잠시 멈추고 생각을 정리하는 편이 낫습니다. / 차단 시간은 제품마다 달라서 몇 분이 걸리기도 합니다.

# 기억을 되살리는 작은 방법
가족이나 룸메이트가 바꿨는지 먼저 연락해 보세요. / 휴대폰 메모나 가족 대화방에 번호를 적어 둔 적이 없는지도 찾아봅니다.
평소 쓰던 번호 두세 개를 떠올려 보되 서너 번 시도 후에는 멈춥니다. / 도어락에 따라 숫자 앞뒤에 다른 숫자를 섞어 눌러도 열리는 제품이 있지만, 막히는 위험이 있어 권하지 않습니다.

# 번호 말고 다른 열림 수단이 있는지 확인
카드키, 태그, 리모컨, 지문, 앱처럼 번호 외에 쓰는 방법이 있는지 떠올려 보세요. / 가방 안쪽 주머니나 지갑에 카드키가 남아 있는 경우가 의외로 많습니다.
비상 열쇠 구멍이 있는 제품이면 예비 열쇠가 집 안이나 가족에게 있을 수 있습니다. / 이런 수단이 있으면 굳이 문을 열 필요 없이 바로 들어가면 됩니다.

# 번호를 몰라도 열 방법이 있습니다
도어락 종류를 보고 문과 장치가 상하지 않는 방법부터 차례로 해봅니다. / 억지로 부수는 방식이 아니라서 열고 난 뒤에도 그대로 쓰실 수 있는 경우가 많습니다.
방법은 [현관문 개문](door-open.html) 페이지에서도 설명하고 있습니다. / 어떤 방식인지는 현장에서 상태를 보고 먼저 말씀드립니다.
@ 수원 망포동 출장열쇠 비밀번호 재설정

# 하지 말아야 할 일
번호판을 뜯어 보려고 드라이버를 쓰지 마세요. / 한번 상하면 번호를 몰라도 열 수 있던 문이 더 어려워집니다.
인터넷에서 본 따라 하기 방법을 시도하다 안쪽 부품이 휘는 경우도 있습니다. / 급하더라도 억지로 힘을 쓰는 것은 피하세요.

# 전화 주실 때 말씀해 주세요
- 망포동 어디쯤인지, 근처 역이나 큰 건물
- 번호판 불이 켜지는지, 삑 소리나 경고음이 나는지
- 도어락 모양(번호만, 지문, 카드, 손잡이 일체형 등)
- 집 안에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 필요한 장비를 챙겨 갑니다. / 위치만 확실하면 도착 시간은 바로 말씀드립니다.

# 문을 열기 전에 확인하는 것
사시는 분이 맞는지 신분증이나 주소가 나온 우편물로 확인합니다. / 관리사무소 확인도 가능하니 늦은 시간이면 경비실에 먼저 말씀해 두세요.
이 절차는 모두가 안전하게 지내기 위한 것이라 양해 부탁드립니다. / 확인이 안 되면 작업은 진행하지 않습니다.

# 비용은 시작 전에 말씀드립니다
문 상태와 도어락 종류를 보고 먼저 비용을 말씀드립니다. / 동의하시면 진행하고, 아니면 돌아갑니다.
문을 못 열면 비용을 받지 않습니다. / 부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭤봅니다. [이용안내](guide.html)에 진행 방식을 적어 두었습니다.

# 문이 열린 뒤에는 번호를 바로 새로 정합니다
들어가시면 기존 번호를 지우고 새 번호를 등록하는 것까지 도와드립니다. / 이때 가족과 번호를 어떻게 나눌지 같이 정하시면 좋습니다.
번호가 겹치거나 쉬운 숫자 나열은 피하는 편이 안전합니다. / 생일이나 전화번호 뒷자리처럼 남이 짐작하기 쉬운 번호는 권하지 않습니다.

# 같은 일이 또 생기지 않게
- 새 번호를 가족 모두가 아는지 확인
- 비상용 열쇠나 카드키 한 개를 안전한 곳에 보관
- 번호를 바꾸면 가족 대화방에 바로 알리기
- 도어락 배터리 경고음이 나면 바로 교체
비밀번호를 정기적으로 바꾸는 것도 좋지만 바꾼 즉시 공유하는 것이 더 중요합니다.

# 고장이 의심될 때
번호가 확실한데 안 열리면 고장이나 배터리를 의심해야 합니다. / 이 경우엔 [도어락 수리](doorlock-repair.html)로 먼저 점검해 봅니다.
너무 오래돼 자주 말썽이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 망포동 24시 출장열쇠 010-3664-5455

# 망포동 말고 수원 어디든 갑니다
영통, 광교, 권선, 장안까지 수원 전 지역을 24시간 다닙니다. / 수원에서 다니는 동네는 [수원 출장 지역](suwon.html)에 정리해 두었습니다.
다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.

# 번호가 기억나지 않는 일을 줄이는 방법
번호를 한 번 정했다면 가족과 같이 정한 규칙으로 기억하기 쉽게 만들어 두세요. / 휴대폰 메모에 힌트만 적어 두는 것도 방법이지만 번호 자체를 적어 두는 것은 권하지 않습니다.
오랫동안 번호를 바꾸지 않으면 오히려 헷갈릴 때가 많습니다. / 바꿀 때마다 가족 대화방이나 현관 안쪽 메모에 힌트를 남겨 두면 도움이 됩니다.
번호를 잊기 쉬운 사람이 있다면 카드나 지문처럼 번호 없이 열리는 수단을 하나 더 등록해 두세요.
@ 망포동 도어락 번호 재설정 점검
비밀번호가 기억나지 않는 일은 누구에게나 생기고, 특히 이사나 번호 변경 직후에 잦습니다. / 부끄러워하지 말고 편하게 전화 주세요. 문을 열고 새 번호를 정하는 것까지 한 번에 도와드립니다.
망포동처럼 출퇴근이 바쁜 동네에서는 번호를 급하게 바꾸고 잊는 경우가 많습니다. / 새 번호를 정한 즉시 가족에게 알리고, 도어락 안쪽에 번호가 아닌 힌트만 적어 두는 정도로 정리해 보세요. 한 번 정리해 두면 같은 일이 훨씬 줄어듭니다.
