# 번호가 맞는데 문이 안 열린다면
망포동은 영통역 방향 생활권과 맞닿아 있고 새로 지은 아파트와 오피스텔이 많은 동네입니다. / 비교적 최근에 설치한 스마트 도어락이 많아서, 고장이 아닌데도 안 열리는 일이 종종 생깁니다.
그 이유 중 하나가 수동 잠금 모드입니다. / 도어락이 일부러 입력을 막아 둔 상태인데 본인은 그걸 모르고 계신 경우가 있습니다.
이 글은 망포동에서 수동 잠금 모드가 켜져 문이 안 열릴 때 확인하는 순서를 정리한 것입니다. / 풀리지 않을 때 [수원 출장열쇠](suwon.html)가 어떻게 돕는지도 적었습니다.
@ 망포동 도어락 번호판에 잠금 표시가 켜진 모습

# 수동 잠금 모드가 무엇인가
수동 잠금은 외부에서 번호나 카드를 눌러도 문이 열리지 않게 막아 두는 기능입니다. / 제품에 따라 외출 모드, 휴가 모드, 이중 잠금처럼 이름이 다릅니다.
안쪽에서 잠금 버튼이나 레버를 누르면 켜지는 구조가 많습니다. / 바깥에서는 번호가 맞아도 모터가 움직이지 않고 경고음이 날 수 있습니다.
방범에는 도움이 되는 기능이지만 모르고 켜 두면 가족이 못 들어옵니다. / 그래서 이 모드의 존재를 식구 모두가 알아 두시는 편이 좋습니다.

# 누가 켰는지부터 생각해 보세요
혼자 사는 집이 아니라면 가족 중 누군가가 실수로 켰을 수 있습니다. / 아이가 안쪽 버튼을 장난으로 눌렀을 수도 있습니다.
외출할 때 나가면서 습관처럼 잠금 레버를 올렸는지 떠올려 보세요. / 며칠 집을 비우면서 일부러 켜 둔 것을 잊은 경우도 많습니다.
식구에게 전화를 걸어 집 안에 누가 있는지, 안쪽 버튼을 만졌는지 물어보세요. / 안쪽 사람이 있다면 직접 풀어 줄 수 있어 가장 빠릅니다.

# 문 앞에서 구분하는 신호들
수동 잠금이 켜진 도어락은 평소와 다른 반응을 보입니다. / 번호판은 켜지는데 번호를 누르면 길게 삑 하는 소리가 나거나 잠금 표시등이 계속 켜져 있습니다.
- 번호판 불은 들어오는데 열림 소리가 안 나는 경우
- 입력할 때마다 경고음이 이어지는 경우
- 잠금 표시등이 평소와 다르게 켜진 경우
- 손잡이가 아예 돌아가지 않고 단단히 고정된 경우
배터리 방전이면 번호판 자체가 꺼지지만, 수동 잠금이면 불은 켜진다는 점이 큰 차이입니다. / 이 차이만 봐도 원인을 어느 정도 나눌 수 있습니다.

# 풀어 보는 순서
도어락마다 방식이 달라서 정답은 하나가 아닙니다. / 가능한 방법을 순서대로 해보시길 권합니다.
먼저 등록한 카드키나 지문이 있다면 번호 대신 시도해 보세요. / 수동 잠금이 번호 입력만 막는 제품도 있습니다.
다음으로 번호판 쪽에 잠금 해제 버튼이나 특정 키 조합이 있는지 설명서를 떠올려 보세요. / 별표 키나 샵 키를 길게 누르면 해제되는 제품이 있습니다.
설명서가 없어서 확인이 어렵다면 임의로 키를 마구 누르지 마세요. / 잘못된 조합이 초기화로 이어질 수도 있습니다.
@ 망포동 도어락 안쪽 잠금 레버와 버튼 위치

# 하지 말아야 할 것
번호를 계속 틀리게 입력하면 오히려 입력 제한이 길어집니다. / 서너 번 해보고 안 되면 멈추세요.
초기화 버튼을 눌러 보는 방법도 쉽게 권하지 않습니다. / 등록된 번호와 카드가 전부 지워질 수 있고, 지운 뒤 다시 등록할 방법이 없으면 더 막막해집니다.
손잡이를 세게 돌리거나 문을 발로 차는 일도 피해 주세요. / 잠금 상태의 걸쇠에 힘을 주면 부품이 휘거나 부러질 수 있습니다.

수동 잠금처럼 보여도 사실은 걸쇠나 모터 문제인 경우도 있습니다. / 번호는 받아들이는데 안쪽에서 모터 소리만 나고 열리지 않으면 부품 쪽을 의심해야 합니다.
안쪽 보조키가 돌아가 있는 경우도 겉으로 보기엔 비슷합니다. / 보조키는 바깥에서 열쇠로 풀어야 하는데, 열쇠가 없으면 방법이 막힙니다.
원인이 확실치 않을 때는 전화로 증상을 설명해 주시면 구분을 도와드립니다. / 사진을 같이 보내주시면 훨씬 정확합니다.

# 집 안에 사람이 있을 때와 없을 때
안에 가족이 있다면 안쪽에서 잠금 해제를 해 달라고 부탁하는 것이 가장 쉽습니다. / 안쪽 레버를 원래 위치로 돌리거나 해제 버튼을 누르면 됩니다.
집 안에 아무도 없는데 문이 안 열리는 경우가 훨씬 어렵습니다. / 이럴 때는 억지로 풀려 하지 말고 차분히 연락 주세요.
아이가 혼자 안에 있고 문이 안 열리는 상황이라면 가장 먼저 말씀해 주세요. / 문 너머로 계속 말을 걸어 아이가 놀라지 않게 해 주시면 도움이 됩니다.

# 전화하실 때 알려주실 내용
짧게라도 상황을 정리해 주시면 출동이 빨라집니다. / 사진이 있으면 더 좋습니다.
- 망포동 어느 쪽인지, 근처 큰길이나 영통역 방향
- 번호판이 켜져 있는지, 어떤 소리가 나는지
- 집 안에 사람이 있는지, 아이나 반려동물은 없는지
- 도어락 모양 (버튼형, 터치형, 손잡이 일체형)
- 최근에 누가 잠금 모드를 건드렸을 가능성

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 늦은 시간이면 경비실에 먼저 말해 두시면 수월합니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 상태를 보고 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다. / 문 여는 방법은 [현관문 개문](door-open.html)에서 볼 수 있습니다.
@ 망포동 출장열쇠 도어락 잠금 해제 작업

# 열린 뒤에 같이 확인할 것
문이 열리면 잠금 모드를 풀고 도어락이 정상으로 열리고 잠기는지 같이 봅니다. / 가족이 헷갈리지 않게 어떤 버튼이 잠금인지도 알려 드립니다.
원인이 단순 해제 실수라면 도어락은 그대로 쓰시면 됩니다. / 고장이 의심되면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
비밀번호를 정리하고 싶으시면 이때 새 번호 등록도 같이 해드립니다. / 기존 번호는 지우고 새 번호만 남겨 둡니다.

# 앞으로 같은 일이 없도록
잠금 모드를 쓰는 집이라면 가족 모두가 해제하는 방법을 알고 있어야 합니다. / 도어락 설명서를 사진으로 찍어 가족 대화방에 올려 두는 것도 좋습니다.
- 외출 전 잠금 모드를 켰는지 습관처럼 확인
- 아이가 만지기 쉬운 안쪽 버튼 위치는 가족이 인지해 두기
- 카드키는 한 장 따로 보관
- 배터리 경고음이 나면 그날 바로 교체
이런 작은 습관이 늦은 밤 문 앞에서 막히는 일을 줄여 줍니다.

# 망포동 말고 수원 어디든 갑니다
망포동 바로 옆 영통동, 매탄동, 원천동과 광교동까지 수원 안이면 다닙니다. / 24시간 출동합니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
