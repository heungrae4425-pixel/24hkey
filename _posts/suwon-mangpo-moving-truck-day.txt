# 망포동 이삿짐 나르는 날의 현관문
망포동은 영통역 쪽 생활권으로 이어져 이사가 잦은 동네입니다. / 이사 날 아침이면 사다리차가 오가고, 현관문은 하루 종일 열려 있거나 반쯤 걸쳐 있는 채로 지나갑니다.
이렇게 문이 열려 있는 동안은 도어락과 문이 평소와 다른 상태로 쓰이게 됩니다. / 짐을 다 나르고 닫으려는데 문이 안 닫히거나, 닫았는데 안 열리는 일이 이때 생깁니다.
이 글은 이삿짐이 오가는 동안 문이 반쯤 열려 있을 때 생기는 문제와 [수원 출장열쇠](suwon.html)를 부르는 기준을 정리했습니다.
@ 망포동 이사 당일 열려 있는 현관문

# 문을 열어 둘 때 쓰는 물건이 문제의 시작
현관문이 닫히지 않게 문틈에 신발, 박스, 벽돌, 우산을 끼워 두는 경우가 많습니다. / 걸쇠가 튀어나온 채 눌려 있거나 문과 문틀이 물건에 눌려 틀어지는 일이 자주 생깁니다.
- 문틈에 끼운 물건이 걸쇠를 누르고 있어 걸쇠가 안 돌아오는 경우
- 사다리차 작업으로 문이 활짝 젖혀져 경첩에 무리가 간 경우
- 짐을 나르는 사람의 몸이 손잡이를 쳐서 헐거워진 경우
- 반쯤 열린 문에 짐이 끼어 번호판이 눌린 경우
문이 오래 열려 있었다면 마지막에 닫으면서 어딘가 어긋나 있는지 한 번 살펴 주세요.

# 짐 다 옮기고 문 닫을 때 보세요
이사 마무리 시점에는 지치고 마음이 급해 문을 세게 닫기 쉽습니다. / 한 번 천천히 닫아 보며 아래를 확인해 주세요.
- 걸쇠가 문틀 홈으로 부드럽게 들어가는지
- 닫힐 때 문이 문틀에 쓸리는 소리가 나는지
- 번호판 불이 정상으로 켜지는지
- 안쪽 손잡이가 눌렸다가 돌아오는지
이 중 하나라도 이상하다면 일단 문을 억지로 여닫지 마세요. / 문이 닫혀 있다면 그대로 두고, 열려 있다면 사람이 곁에서 지키며 상태를 점검하세요.
@ 망포동 걸쇠가 문틀 홈에 걸리는 부분

# 반쯤 열린 문이 안 닫힐 때
문이 중간에서 멈추며 더 이상 안 닫힌다면 바닥이나 문틀에 이물이 있는지 보세요. / 이삿짐 포장 조각, 테이프, 작은 돌이 바닥 문턱에 끼어 있는 일이 의외로 많습니다.
이물이 없는데 안 닫히면 경첩이 처졌거나 문이 틀어진 겁니다. / 문 위 도어클로저가 있는 집은 팔 연결부가 빠져 문이 닫히다 멈추기도 합니다.
이럴 땐 문을 들어 올려 닫아 보는 방법을 써 볼 수 있습니다. / 그래도 안 되면 [도어락 수리](doorlock-repair.html)가 필요한 상태인지 상담해 보세요.

# 닫았는데 안 열릴 때
잠금이 걸린 상태에서 문이 안 열리면 대부분 걸쇠가 문틀에 물려 있기 때문입니다. / 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보면 열리기도 합니다.
번호는 맞는데 소리만 나고 열리지 않는다면 모터나 걸쇠 쪽 문제일 가능성이 큽니다. / 비밀번호를 여러 번 틀리면 입력이 막힐 수 있으니 서너 번 해보고 멈추세요.
새 집 도어락이라면 초기 비밀번호나 설정을 아직 안 바꿨을 수도 있습니다. / 사용설명서에 적힌 초기 순서를 한 번 확인해 보세요.

# 힘으로 밀거나 도구로 비집지 마세요
이삿짐 정리 중이라 손에 드라이버나 공구가 있어서 도어락 쪽을 건드려 보고 싶어지기도 합니다. / 하지만 도어락 외관이나 걸쇠가 상하면 문이 더 크게 안 열릴 수 있습니다.
문틈에 얇은 판이나 카드를 밀어 넣는 방법은 문틀이 긁히고 보증에도 영향을 줄 수 있습니다. / 특히 임대 집이라면 원상 복구 문제까지 번질 수 있어 조심하세요.
새 집에 처음 들어가는 날이라 더 속상하겠지만, 천천히 한 단계씩 확인하는 게 빠릅니다.

# 이삿짐 업체와 책임을 따지기 전에
짐 나르던 분들이 문을 건드린 것 같아 속상할 수 있습니다. / 우선은 문 상태를 사진으로 남겨 두시고, 책임 문제는 따로 정리하시길 권합니다.
출장열쇠는 누구 책임인지 판단하지 않고, 문과 도어락 상태를 보고 필요한 작업을 안내드립니다. / 사진은 이삿짐 업체와 이야기할 때도 참고 자료가 됩니다.
이사 직후라 낯선 건물에서 관리실 위치조차 모를 수 있습니다. / 위치와 연락처는 입주 안내문에서 확인해 보세요.

# 이사 날 문 앞을 지키는 사람
문이 열려 있는 동안에는 집이 비어 있는 것이나 마찬가지입니다. / 짐을 나르는 사이에 누군가 한 명은 현관 근처에 남아 있는 것이 안전합니다.
귀중품과 열쇠, 카드는 이삿짐 상자에 넣지 말고 몸에 지니거나 따로 챙겨 두세요. / 이삿짐 트럭에 열쇠를 실어 보내고 문이 잠겨 버리는 경우도 의외로 있습니다.
마지막으로 집을 나서기 전에 문을 닫고 잠긴 소리를 한 번 확인하면 마음이 놓입니다.
이삿짐 업체 직원과 가족 중 누가 마지막으로 문을 닫을지 미리 정해 두면 서로 닫은 줄 알고 그냥 가는 일이 없습니다.
비어 있는 집에 누가 드나들었는지 알 수 없게 되는 것이 가장 불안한 부분입니다. / 문을 오래 열어 두었다면 마지막에 안쪽을 한 번 둘러보세요.

# 연락할 때 말씀해 주세요
- 동네와 건물, 몇 층 몇 호인지
- 문이 열려 있는지, 닫혀 있는지
- 번호판 상태와 입력음, 경고음
- 짐 때문에 문이나 도어락에 눌림이 있는지
- 집 안에 아이나 반려동물이 있는지
도어락과 문틈 사진을 보내주시면 맞는 장비를 챙기는 데 도움이 됩니다. / 연락 요령은 [출장 호출 안내](key-call.html)에도 정리했습니다.
@ 망포동 새 집 도어락 번호판 확인

# 사는 분인지 확인하고 시작합니다
이사 직후라 우편물이 아직 안 왔을 수 있습니다. / 이럴 땐 임대차계약서나 매매계약서, 이사 확인서 같은 서류 사진이 도움이 됩니다. 신분증 주소가 이전 주소라면 계약서와 함께 보여 주세요.
관리사무소에 입주 사실을 확인받는 방법도 있습니다. / 어떤 방법으로도 확인이 어렵다면 작업은 할 수 없습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문과 도어락 상태를 보고 필요한 작업과 비용을 먼저 설명드립니다. / 동의하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 이사 날 같이 하면 좋은 도어락 정리
이사한 김에 비밀번호도 새로 정하는 분이 많습니다. / 이전 거주자나 공사 인력에게 알려졌던 번호를 그대로 쓰지 않는 것이 안전합니다.
- 입주 당일 도어락 비밀번호 새로 등록
- 이전에 쓰던 카드키와 열쇠 정리
- 건전지 교체 시점 확인
- 낡았거나 맞지 않는 도어락은 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html) 상담
짐이 많은 날에 바로 하기 어렵다면 이삿짐이 다 나간 뒤 편하신 시간에 하셔도 됩니다.

# 망포동 말고 수원 어디든 갑니다
망포동 가까운 영통동, 매탄동, 원천동은 물론 수원 안이면 어디든 갑니다. / 수원 안내는 [수원시 출장열쇠](suwon.html)에 있고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
