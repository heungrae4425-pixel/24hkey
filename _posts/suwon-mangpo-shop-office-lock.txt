# 망포동 가게 문이 안 열리면 하루가 멈춥니다
망포동은 새 상가와 사무실이 나란히 들어선 곳입니다. / 아침에 문을 열어야 하는데 도어락이 반응하지 않으면 영업 준비가 통째로 밀립니다.
이 글은 망포동 상가와 사무실 출입문이 안 열릴 때 먼저 볼 것과 연락하는 요령을 적었습니다. / 급한 상황이라 순서대로 읽기 어려우시면 3번과 4번만 보셔도 됩니다.
@ 망포동 상가 출입문 출장열쇠

# 가게 문이 막히는 흔한 순간
새로 문을 연 가게일수록 직원이 자주 바뀌고 번호가 여러 사람에게 퍼져 있습니다. / 마감하는 사람과 오픈하는 사람이 다를 때 인수인계가 빠지면 생기는 일입니다. / 이런 경우는 문 앞에서 서로 번호를 확인하는 것만으로도 풀리기도 합니다.
출근하자마자 문이 안 열리는 경우가 가장 많습니다. / 밤새 도어락 배터리가 다 닳았거나 직원이 비밀번호를 바꾸고 알리지 않은 일이 원인이기도 합니다.
유리문은 문틀 모서리의 잠금 장치가 따로 있어서 일반 현관문과 구조가 다릅니다. / 어떤 문인지 알려주시면 상담이 빨라집니다.

# 전화 전에 확인할 세 가지
- 번호판이나 지문 인식부에 불이 들어오는지
- 문이 안쪽에서 따로 잠겨 있지는 않은지
- 직원이나 공동 사용자가 번호를 바꿨는지
셋 중 하나만 확인돼도 원인을 훨씬 빨리 좁힐 수 있습니다.

# 사무실 문은 누가 열 수 있는지가 먼저입니다
사무실이나 가게 문은 사는 집과 달리 사용하는 분이 여럿인 경우가 많습니다. / 임차인인지, 관리하는 분인지 먼저 확인합니다.
사업자등록증이나 계약서, 건물 관리실 확인 중 하나면 대부분 충분합니다. / 문을 여는 일이라 이 절차는 꼭 지킵니다.
@ 망포동 사무실 도어락 개문

# 유리문과 금속 문은 방법이 다릅니다
유리 출입문은 바닥이나 문틀에 달린 잠금이 따로 있어서 열 때 조심해야 합니다. / 힘으로 열면 유리가 상할 수 있어 천천히 접근합니다.
금속 문이나 방화문은 문 두께와 잠금 방식에 따라 시간이 더 걸릴 수 있습니다. / 작업 전에 걸리는 시간을 가늠해서 말씀드립니다.

# 영업 중이라면 이렇게 알려주세요
가게 앞에 이미 손님이 서 있다면 임시로 안내문을 붙여 두는 것도 방법입니다. / 도착하는 시간을 미리 말씀드리면 그 시간에 맞춰 손님에게 안내할 수 있습니다. / 여러 가게가 입주한 건물이라면 호수와 층을 꼭 알려주세요.
손님이 기다리고 있거나 영업 시작 시간이 임박해 있다면 먼저 말씀해 주세요. / 우선순위를 두고 최대한 빨리 가도록 맞춥니다.
가게 이름이나 간판 위치, 근처 건물 이름을 같이 알려주시면 헤매지 않고 도착합니다.

# 도착하면 확인하는 것
문을 여는 일이라 사용하시는 분이 맞는지 확인합니다. / 사업자등록증, 임대 계약서, 건물 관리 쪽 확인 중 하나를 준비해 주세요.
관련 서류가 가게 안에 있다면 사진이나 사본, 건물 관리실 연락처도 도움이 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두는 게 좋습니다.

# 비용은 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭤봅니다.
@ 망포동 상가 도어락 수리 교체

# 열고 난 뒤 꼭 같이 하는 점검
문이 열린 뒤에는 퇴근하는 날 문을 잠그는 순서도 같이 확인합니다. / 영업 마감 때 잘 잠기지 않으면 가게를 비운 사이 위험이 생깁니다. / 새 번호는 책임자만 아는 것이 원칙이고 직원은 필요한 만큼만 알려주세요.
문이 열리면 도어락이 다시 잘 열리고 잠기는지 같이 봅니다. / 배터리가 원인이었다면 전부 새것으로 바꾸는 것까지 안내합니다.
여럿이 쓰는 번호는 열고 난 뒤 새로 정해 두는 게 좋습니다. / 떠난 직원이 알고 있던 번호를 그대로 쓰면 보안이 느슨해집니다.

# 고쳐서 쓸지 바꿀지는 상태를 보고 정합니다
고쳐서 쓸 수 있는 도어락이면 [도어락 수리](doorlock-repair.html)로 먼저 해결합니다. / 오래돼서 부품이 없으면 [도어락 교체](doorlock-replace.html)를 권해 드립니다.
새로 설치하는 가게라면 [도어락 설치](doorlock-install.html)도 함께 상담됩니다.

# 가게 도어락을 오래 쓰는 방법
- 배터리는 영업이 없는 날에 한 번에 교체
- 번호는 직원이 바뀔 때마다 새로 정하기
- 비 오는 날 문 앞이 젖지 않게 매트와 물기 관리
- 문이 뻑뻑해지면 그날 바로 점검 요청
- 비상용 열쇠나 카드는 가게 밖에 두지 말고 책임자가 보관
가게 문은 하루만 막혀도 손해가 커서 미리 손보는 편이 훨씬 낫습니다.

# 망포동 말고 수원 전 지역 갑니다
영통, 광교, 인계동, 권선동, 화서동까지 수원 어디든 다닙니다. / 수원 안이면 24시간 출동합니다.
다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있고, 전체 안내는 [수원 출장열쇠](suwon.html) 페이지에 있습니다.
