# 명절 연휴, 현관문이 평소와 다르게 바쁜 날
수원 파장동에서 성균관대역 쪽으로 오가는 분들도 명절만큼은 집에서 식구들을 맞느라 정신이 없습니다. / 이럴 때 현관문이 가장 많이 바뀌는 건 문을 열고 닫는 횟수입니다.
평소 서너 명이 쓰던 문을 친척 열 명 넘게 드나들면 작은 일이 하나둘 생깁니다. / 번호를 알려 줬는데 누가 잘못 눌러 막히거나, 마지막 사람이 문을 잠그고 나가 버리기도 합니다.
이 글은 명절에 친척이 모이는 집에서 번호를 어떻게 나누고, 문이 잠겼을 때는 어떻게 해야 하는지 적었습니다. / 연휴 전에 읽어 두시면 당일 당황할 일이 줄어듭니다.
@ 파장동 명절 가족 모임 현관 신발 정리된 모습

# 명절에 생기는 문 문제의 유형
명절 현관 사고는 크게 세 갈래로 나뉩니다.
- 번호를 잘못 눌러 도어락이 입력을 한동안 막은 경우
- 안에 있는 줄 알고 문을 잠가 버려 밖에 있던 사람이 못 들어온 경우
- 손님이 문을 거칠게 닫아 걸쇠나 보조키가 걸린 경우
이 가운데 번호 입력 제한이 가장 흔합니다. / 여러 사람이 번갈아 누르다 보면 눈치채지 못한 오입력이 쌓입니다.
기계가 고장 난 것이 아니라 정상적으로 잠깐 멈춘 상태인 경우가 많습니다.

# 번호를 알려 줄 때 지키면 좋은 방법
친척 모두에게 집 번호를 알려 주는 것은 부담스러운 일입니다. / 연휴 끝나고 번호를 바꾸게 될 것을 생각하면 처음부터 신중한 게 좋습니다.
가능하면 한 사람씩 개별 번호를 임시로 만들어 줄 수 있는 제품이면 그 기능을 쓰세요. / 그렇지 않다면 직접 문을 열어 주거나 카드키를 빌려주는 쪽이 안전합니다.
번호를 문자로 보낼 때는 받는 사람 이름과 사용 기간을 함께 적어 두세요. / 연휴가 끝나면 지워야 한다는 것을 잊지 않게 됩니다.

# 연휴 시작 전에 해 둘 점검
명절 전날 5분만 투자하면 연휴 내내 편합니다.
- 도어락 배터리 잔량 확인, 경고음이 있었다면 미리 교체
- 문이 부드럽게 닫히는지, 걸쇠가 헛돌지 않는지 확인
- 현관 바닥에 신발이 많아져도 문이 걸리지 않게 정리
- 비상용 9V 건전지 하나 준비
한 번도 배터리를 안 바꾼 도어락이라면 연휴 전에 갈아 주세요. / 문을 자주 열수록 배터리는 평소보다 빨리 닳습니다.

# 한 사람이 나가며 문을 잠가 버렸을 때
쓰레기를 버리러 잠깐 나갔는데 안에 있던 사람이 자동 잠금 기능이 켜진 걸 모르고 있는 경우가 있습니다. / 자동 잠금 도어락은 문이 닫히면 몇 초 뒤 스스로 잠깁니다.
밖에 있는 사람이 번호를 모르고, 안의 사람은 손잡이를 돌리지 못하는 상황이 생기기도 합니다. / 이때는 안에 있는 식구가 안쪽 손잡이를 돌려서 열어 주면 해결됩니다.
번호를 모르는 손님이 나갔다가 못 들어오면 연락이 닿는 식구가 문을 열어 주세요. / 전화가 닿지 않으면 그때 전화 주셔도 됩니다.

# 아이들이 많은 날의 위험 포인트
명절에는 평소 오지 않던 아이들이 집에서 뛰어 노는 일이 많습니다. / 아이가 안쪽 보조키를 돌려 잠그는 일이 이런 때 가장 많이 생깁니다.
아이가 문을 잠그고 나오지 못하면 놀라서 울 수 있습니다. / 문 너머에서 차분하게 말을 걸어 주시고, 이때는 전화할 때 꼭 먼저 알려 주세요.
아이 손이 닿는 안쪽 보조키는 모임 전에 한 번 확인해 두는 것도 좋습니다. / 장난으로 눌러도 잘 잠기지 않는지 점검해 두세요.

# 짐이 많은 날 문 앞에서 생기는 일
명절 음식과 선물 보따리를 양손에 든 채 번호를 누르다 틀리는 일이 흔합니다. / 짐을 잠깐 내려놓고 한 번에 천천히 누르는 것이 오히려 빠릅니다.
문이 열린 채로 오가는 손님을 위해 문 아래 걸림 장치를 놓는 집도 있습니다. / 이때 문이 자동으로 잠기지 않게 해두면 좋지만, 비운 채 자리를 뜨는 것은 피하세요.
한 사람이 문을 붙잡고 있는 동안 다른 사람이 짐을 옮기게 해보세요. / 번호를 반복해서 누르는 횟수 자체가 줄어듭니다.

# 번호를 여러 번 틀려 막혔다면
도어락은 번호를 연속으로 틀리면 잠깐 입력을 막는 기능이 있습니다. / 몇 분 뒤 풀리는 제품이 많으니 그 사이에는 번호판을 건드리지 마세요.
막혔을 때 계속 누르면 시간이 더 늘어나는 제품도 있습니다. / 이럴 때는 기다렸다가 천천히 한 번씩만 눌러 보세요.
한참 기다려도 풀리지 않거나 번호를 정말 모르겠다면 전화 주세요. / 상황을 듣고 먼저 판단해 드립니다.
@ 파장동 도어락 번호판 입력 제한 상태

# 연휴 중에 열쇠집이 문을 닫았을 때
명절 당일은 문을 닫는 업체가 많아 막막해지는 때가 많습니다. / 24시출장열쇠는 명절 연휴에도 전화를 받고 가능 여부를 말씀드립니다.
다만 연휴에는 평소보다 연락이 몰릴 수 있어서, 급한 상황인지 먼저 말씀해 주시는 것이 좋습니다. / 아이가 안에 있거나 노부모님이 밖에서 기다리는 경우처럼요.
[수원 출장열쇠](suwon.html)에서 출동 지역을 미리 확인해 두면 편합니다. / 파장동뿐 아니라 수원 어디든 갑니다.

@ 파장동 명절 연휴 현관 앞 짐과 도어락

# 전화할 때 알려 주면 빠른 것
통화는 짧을수록 좋습니다. / 아래 세 가지를 먼저 말씀해 주세요.
- 파장동 안의 위치와 건물 종류, 동·호수
- 도어락 모양과 번호판이 켜지는지
- 안에 사람이 있는지, 노인이나 아이가 있는지
친척이 많은 날은 현장에 오는 길을 알려 주는 사람이 따로 있으면 훨씬 빠릅니다.

# 도착하면 신분 확인이 먼저입니다
명절이라 친척이 많이 있어도 문을 여는 일은 사시는 분이 확인돼야 시작합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
손님이 대신 연락했다면 사시는 분의 확인을 어떻게 할지 먼저 정해 주세요. / 집주인이 전화로 승낙해 주시는 방법도 상황에 따라 안내드립니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 열기 전에 말씀드립니다
연휴라도 문 상태를 보고 먼저 비용을 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용도 없습니다.
부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 나와 있습니다.

# 연휴가 끝나면 번호부터 정리
손님들이 돌아간 뒤에는 잠깐 시간을 내서 번호를 바꿔 두세요. / 친척에게 알려 줬던 번호는 연휴가 끝나는 순간 정리하는 것이 깔끔합니다.
- 임시로 만든 번호는 삭제
- 가족 번호도 한 번 바꿔 새로 공유
- 카드키가 돌아다녔다면 회수 확인
방법을 모르겠다면 [도어락 수리](doorlock-repair.html)에서 번호 재설정을 같이 도와드립니다. / 오래된 도어락이 명절 사용량을 못 견뎠다면 [도어락 교체](doorlock-replace.html)도 상담해 보세요.

파장동 주변은 물론 영통동, 광교동, 인계동 등 수원 곳곳으로 다닙니다. / 지역 정리는 [출장 지역](area.html)에서도 볼 수 있습니다.
명절 연휴 중에도 수원 안이면 동네 상관없이 전화를 받습니다. / 연휴 전에 번호를 저장해 두면 편합니다.
어르신이 오래 문 앞에 서 계시면 번호가 안 맞을 때 일찍 연락해 주세요. / 날씨가 추운 날에는 기다리는 시간이 길수록 위험해집니다.
