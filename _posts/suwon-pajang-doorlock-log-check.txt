# 아이가 집에 잘 들어왔는지 궁금할 때
파장동은 성균관대역 쪽 생활권과 가까워 맞벌이 가정과 학생이 있는 집이 많은 동네입니다. / 부모님이 퇴근하기 전에 아이 혼자 먼저 귀가하는 경우도 흔합니다.
전화를 걸자니 수업 중일까 망설여지고, 연락이 없으면 걱정이 앞섭니다. / 이럴 때 도어락의 출입 기록 기능이 도움이 되는 경우가 있습니다.
이 글은 파장동 가정에서 도어락의 출입 기록 기능을 활용하는 방법과 알아둘 점을 정리한 것입니다. / 기능이 없는 제품이거나 설정이 막힐 때는 [수원 출장열쇠](suwon.html)가 확인해 드립니다.
@ 파장동 도어락 출입 기록 확인 화면

# 출입 기록 확인 기능이란
일부 스마트 도어락은 누가 언제 문을 열었는지 기록을 남깁니다. / 번호로 열었는지, 카드나 지문으로 열었는지가 시간과 함께 저장됩니다.
기록을 보는 방식은 제품마다 다릅니다. / 앱으로 확인하는 제품이 있고, 도어락 본체에서 음성이나 화면으로 알려 주는 제품도 있습니다.
모든 도어락에 이 기능이 있는 것은 아닙니다. / 먼저 우리 집 제품이 지원하는지부터 확인해야 합니다.

# 우리 집 도어락이 지원하는지 확인하는 방법
- 도어락 본체나 설명서에 기록, 이력, 로그 같은 단어가 있는지
- 제조사 앱에 연결해 쓰는 제품인지
- 앱에서 '출입 기록' 메뉴가 보이는지
- 안쪽 설정 모드에 기록 확인 항목이 있는지
기능이 있어도 설정을 켜지 않으면 기록되지 않는 제품도 있습니다. / 처음 설치할 때 한 번 확인해 두는 것이 좋습니다.
제품 이름을 모르겠다면 도어락 사진을 보내 주세요. 모델을 보고 알려 드립니다.
안쪽 덮개를 열면 라벨이 붙어 있는 경우가 많으니 그 부분을 찍어 주셔도 됩니다. / 이미 앱을 쓰고 있다면 앱 화면 캡처도 도움이 됩니다.

# 사용자별로 번호를 나누면 더 정확합니다
가족 모두 같은 번호를 쓰면 기록은 남아도 누구인지 알기 어렵습니다. / 아이는 아이 번호, 부모님은 부모님 번호처럼 각자 따로 등록하면 기록이 훨씬 쓸모 있어집니다.
사용자 이름을 붙이는 기능이 있으면 '첫째', '할머니'처럼 구분할 수 있습니다. / 등록 가능한 번호 개수는 제품마다 다르니 미리 확인하세요.
번호를 나누면 퇴거한 사람 번호만 지우는 일도 쉬워집니다.

# 알림을 받는 방법과 한계
앱과 연동되는 제품은 문이 열릴 때 휴대폰으로 알림을 보내기도 합니다. / 아이가 학원이나 학교에서 돌아오는 시간에 맞춰 알림을 받아 두면 안심됩니다.
다만 와이파이가 끊기거나 앱이 오래 켜져 있지 않으면 알림이 늦게 오기도 합니다. / 알림이 안 온다고 해서 꼭 문제가 생긴 것은 아니니 너무 놀라지 마세요.
알림이 안 올 때는 연결 상태, 휴대폰 알림 권한, 도어락 배터리를 차례로 확인하세요.
@ 파장동 스마트 도어락 앱 알림 설정

# 가족과 먼저 이야기해 두세요
출입 기록은 편리하지만 가족이 어떻게 받아들이는지가 중요합니다. / 아이나 부모님이 감시당한다고 느끼지 않도록 목적을 미리 설명해 두세요.
- 안전하게 귀가했는지 확인하기 위한 용도라는 점
- 기록을 누가 볼 수 있는지
- 언제까지 기록을 남기는지
- 불편하면 같이 조정할 수 있다는 점
특히 청소년이라면 사생활을 존중한다는 태도를 보여 주는 것이 좋습니다. / 기록은 걱정을 줄이는 도구이지 추궁하는 근거가 아닙니다.

# 부모님 집에서는 이렇게 활용해 보세요
혼자 지내시는 부모님 집이라면 하루에 한 번이라도 문이 열린 기록이 있는지 보는 것만으로 안부 확인이 됩니다. / 전화를 못 받으시는 날에도 기록이 있으면 먼저 마음을 놓을 수 있습니다.
기록이 오랫동안 없을 때는 바로 놀라지 말고 먼저 전화나 이웃 연락을 해 보세요. / 정말 긴급한 상황이면 가족이 같이 가서 확인하는 것이 안전합니다.
어르신이 쓰기 편한 설정은 [출장 안내](key-call.html)에서 이어서 상담해 드립니다.

# 기록이 이상하게 남을 때
- 아무도 열지 않았는데 기록이 남은 경우
- 시간이 현재와 맞지 않는 경우
- 기록이 중간에 비어 있는 경우
- 앱에는 안 보이고 본체에만 남은 경우
시간이 틀어져 있으면 도어락 시계 설정을 맞추면 해결됩니다. / 배터리가 약해지면 기록이 누락되는 일도 있으니 배터리부터 확인해 보세요.
이상한 기록이 반복되면 도어락 점검을 권합니다. [도어락 수리](doorlock-repair.html) 안내를 참고해 주세요.

기록 기능을 쓸 때는 개인정보 관리도 신경 써 주세요.
출입 기록은 가족의 생활 시간이 담긴 정보입니다. / 앱 계정 비밀번호는 쉬운 숫자로 하지 않는 것이 좋습니다.
휴대폰을 바꾸거나 처분할 때는 앱 로그인을 꼭 해제해 주세요. / 이사할 때는 이전 사용자의 계정 연결을 끊고 새로 등록하는 것이 안전합니다.
공유 계정으로 여러 명이 함께 쓰는 것보다 각자 계정을 쓰는 편이 정리하기 쉽습니다.
기록은 필요한 만큼만 보시고, 오래된 기록은 정리해 두는 습관을 들이면 좋습니다. / 아이가 커서 스스로 관리하고 싶어 하면 그때 설정을 같이 조정해 주세요.
출입 기록은 가족의 안심을 위한 도구라는 점만 기억하시면 됩니다.

# 전화하실 때 알려주실 내용
- 파장동 위치와 건물 종류
- 도어락 제조사나 모양
- 앱을 쓰고 있는지, 안 되는 증상이 무엇인지
- 문이 지금 열리는 상태인지
문이 열리는 상태라면 방문해서 설정을 같이 보는 방법을 안내합니다. / 문이 잠긴 상태라면 먼저 열고 나서 설정을 확인합니다.

# 도착하면 먼저 사시는 분인지 확인합니다
출입 기록과 번호를 다루는 작업이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주시면 좋습니다.

# 비용은 작업 전에 먼저 말씀드립니다
작업 내용을 보고 먼저 비용을 말씀드린 뒤 시작합니다. / 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. 진행 방식은 [이용안내](guide.html)에서도 보실 수 있습니다.
@ 파장동 출장열쇠 도어락 설정 점검

# 기록 기능이 없다면 바꾸는 선택도 있습니다
지금 도어락에 기록 기능이 없는데 꼭 필요하다면 지원하는 제품으로 바꾸는 방법이 있습니다. / 필요 없는데 교체를 권하지는 않고, 기능과 가정 상황을 보고 고르는 방법을 알려 드립니다.
교체 전에 문 두께와 보조키 위치를 보는 과정이 필요합니다. / 자세한 내용은 [도어락 교체](doorlock-replace.html), 새로 다는 경우는 [도어락 설치](doorlock-install.html) 페이지를 참고하세요.

# 파장동 말고 수원 어디든 갑니다
파장동 가까운 율전동, 천천동, 조원동은 물론 영통동, 광교동, 호매실동까지 수원 어디든 24시간 출동합니다. / 지역별 안내는 [수원시 출장열쇠](suwon.html) 페이지와 [출장 지역](area.html) 지도에 있습니다.

# 자주 묻는 질문

? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤에도 설정 상담이 되나요? | 24시간 전화를 받습니다. 방문 작업은 상황에 맞춰 안내합니다.
? 아이 번호만 따로 만들 수 있나요? | 제품이 여러 사용자 등록을 지원하면 가능합니다.
? 기록을 가족이 같이 봐도 되나요? | 앱 계정 공유 방식에 따라 다릅니다. 각자 계정으로 쓰는 방법을 권합니다.
