# 파장동 대문과 철문이 안 열릴 때
파장동은 장안구 쪽 주택가와 다세대가 많은 동네라 대문과 철문을 쓰는 집이 많습니다. / 아파트 현관문과 달리 대문은 바깥에서 비와 바람을 그대로 맞기 때문에 고장이 빨리 옵니다.
열쇠를 꽂았는데 뻑뻑하게 돌거나 아예 안 돌아가서 연락 주시는 분들이 많습니다. / 공동 출입문 도어락이 안 열려서 부르는 경우도 있습니다.
이 글은 파장동에서 대문, 철문, 공동 출입문이 안 열릴 때 먼저 확인할 것을 정리했습니다. / 그다음 [출장 열쇠](key-call.html)를 부르면 어떻게 진행되는지도 적었습니다.
@ 파장동 출장열쇠 대문 철문

# 열쇠가 뻑뻑하게 돌아가는 이유
대문 열쇠는 먼지와 녹이 가장 큰 문제입니다. / 열쇠 구멍 안에 먼지가 쌓이면 열쇠가 끝까지 안 들어가거나 돌아가다 걸립니다.
오래 쓴 열쇠는 날이 닳아서 구멍 안 핀을 제대로 밀지 못합니다. / 열쇠 복사본이 원래 열쇠보다 조금 어긋나 있는 경우도 있습니다.
비가 많이 오거나 겨울에 문이 얼면 뻑뻑함이 더 심해집니다. / 갑자기 안 돌아간다면 날씨를 같이 떠올려 보세요.

# 억지로 돌리지 마세요
열쇠가 뻑뻑하다고 힘을 세게 주면 열쇠가 부러질 수 있습니다. / 열쇠가 구멍 안에서 부러지면 작업이 훨씬 복잡해집니다.
다른 열쇠가 있다면 바꿔서 꽂아 보세요. / 그래도 안 돌아가면 구멍 쪽 문제일 가능성이 큽니다.
기름을 아무거나 뿌리는 것도 피하는 편이 좋습니다. / 먼지와 엉겨서 더 막힐 수 있습니다.

# 문을 위아래로 눌러 보세요
대문은 오래되면 문이 조금씩 처집니다. / 처진 문은 잠금 핀이 문틀에 눌려서 열쇠가 안 돌아갑니다.
문을 위로 살짝 들어 올리거나 안쪽으로 밀면서 열쇠를 돌려 보세요. / 이렇게 해서 풀리면 열쇠 문제가 아니라 문틀 문제입니다.
경첩이 느슨해졌거나 바닥이 기울어서 생기는 경우가 많습니다. / 이 경우는 열고 난 뒤에 경첩과 문틀을 같이 점검하는 것이 좋습니다.
@ 파장동 철문 열쇠 안 돌아감

# 공동 출입문 도어락이 안 열릴 때
빌라와 다세대 건물은 공동 출입문에 도어락을 쓰는 곳이 많습니다. / 번호가 바뀌었거나 배터리가 다 돼서 안 열리는 경우가 있습니다.
건물 관리하는 분이나 이웃에게 먼저 번호가 바뀌었는지 확인해 보세요. / 배터리 문제라면 바깥에서도 비상 전원을 연결할 수 있는 형이 있습니다.
공동 출입문은 건물에 사는 모든 분이 쓰는 문이라 작업 전에 확인할 것이 있습니다. / 사시는 분인지 확인하는 절차를 거치고, 필요하면 관리하는 분께 알리고 진행합니다.

# 이런 상황에서 출장열쇠를 부릅니다
혼자 해결하려고 오래 붙잡고 있지 않는 편이 낫습니다. / 아래 같은 경우라면 연락 주세요.
열쇠가 구멍 안에서 부러진 경우가 있습니다. / 이때는 그대로 두고 연락 주시면 열쇠 조각을 빼는 것부터 진행합니다.
대문이 안에서 잠겨 못 들어가는데 집 안에 사람이 없는 경우도 있습니다. / 사시는 분 확인 후 문을 상하지 않게 여는 방법을 씁니다.
대문 자물쇠를 새것으로 바꾸고 싶은 경우도 있습니다. / 열쇠 복사본이 많이 돌아다녀 걱정이라면 [도어락 교체](doorlock-replace.html)를 같이 보세요.

# 열쇠를 복사할 때 알아 둘 것
대문 열쇠가 안 돌아가는 이유가 복사본 때문인 경우가 의외로 많습니다. / 복사본을 다시 복사하면 어긋남이 쌓여서 점점 잘 안 돌아갑니다.
가능하면 원래 열쇠에서 바로 복사하시는 것이 좋습니다. / 복사한 열쇠가 뻑뻑하면 억지로 쓰지 말고 다시 맞춰 보세요.
열쇠가 여러 개 돌아다닌다면 누가 갖고 있는지 한번 정리해 두시길 권합니다. / 걱정되면 자물쇠 자체를 바꾸는 방법도 있습니다.

# 파장동 위치는 이렇게 알려주세요
파장동은 골목과 주택가가 이어져 있어 위치를 정확히 알려 주시는 것이 중요합니다. / 주소나 가까운 건물, 차를 세울 곳을 같이 말씀해 주세요.
- 주소 또는 가까운 건물과 골목 모양
- 대문인지 철문인지 공동 출입문인지
- 열쇠를 꽂아도 안 돌아가는지, 도어락이 안 열리는지
- 열쇠가 부러졌는지 여부
- 집 안에 사람이나 반려동물이 있는지
문 사진을 문자로 보내 주시면 맞는 장비를 챙기기 좋습니다. / 파장동과 장안구 쪽 어디든 출동합니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 건물주 확인 중 하나면 됩니다.
공동 출입문이라면 건물에 사시는 분이라는 확인이 필요합니다. / 번거로우실 수 있지만 이웃과 집 모두를 위한 절차입니다.
@ 파장동 24시 출장열쇠 신분 확인

# 비용은 작업 전에 말씀드립니다
문 종류와 잠금 상태를 보고 비용을 먼저 안내해 드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 작업 후에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭤봅니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 대문은 최대한 상하지 않게 엽니다
철문은 한번 상하면 보기에도 좋지 않고 보수가 번거롭습니다. / 덜 상하는 방법부터 차례로 해봅니다.
오래된 대문이라면 자물쇠 구멍이 상해 있을 수 있어 작업 중에 상태를 보면서 말씀드립니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 먼저 여쭤봅니다.
현관문 개문 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 대문은 구조가 달라 상황에 맞게 진행합니다.

# 열고 난 뒤에는 자물쇠와 문틀을 점검합니다
문이 열리면 열쇠가 부드럽게 돌아가는지 다시 확인합니다. / 먼지가 쌓인 구멍은 청소하고, 닳은 부품은 말씀드립니다.
열쇠가 닳아서 문제였다면 새로 복사하는 것도 도와드립니다. / 복사본 수가 많다면 자물쇠를 바꾸는 쪽을 권해 드릴 때도 있습니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 고장이 반복되면 [도어락 수리](doorlock-repair.html)를 먼저 보시길 권합니다.

# 대문 자물쇠 오래 쓰는 관리법
대문은 바깥 환경에 노출돼서 관리가 중요합니다. / 가끔 손만 봐도 오래 갑니다.
- 열쇠 구멍에 먼지가 쌓이지 않게 가끔 불어 내기
- 문이 처졌다면 경첩과 문틀 상태 점검
- 비 오는 날 이후에는 구멍 안에 물기가 남지 않게 마른 수건으로 닦기
- 열쇠가 뻑뻑해지면 억지로 돌리지 말고 점검 받기
- 여분 열쇠는 한 곳에 모아 보관
겨울에는 문틀이 얼어서 문이 안 열리기도 합니다. / 억지로 당기지 말고 미지근한 물로 얼음을 녹여 보세요.

# 파장동 말고 수원 어디든 갑니다
파장동 바로 옆 율전동, 천천동, 조원동 쪽도 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 대문 자물쇠를 새것으로 바꿀 수 있나요? | 네, 사진을 보내 주시면 맞는 제품과 순서를 먼저 알려 드립니다.
? 공동 출입문도 열어 주시나요? | 네, 건물에 사시는 분인지 확인되면 작업합니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
