# 파장동 새 가구 들이다 현관이 상했다면
파장동은 성균관대역 쪽 북수원 생활권으로 오가는 분들이 많이 사는 동네입니다. / 새 소파나 장롱, 침대를 들이는 날이면 현관문을 활짝 열어 두고 여러 번 드나들게 됩니다.
그러다 모서리가 문틀을 긁거나 도어락을 툭 치는 일이 생깁니다. / 그 순간에는 별일 없어 보여도 저녁이 되어 문을 닫아 보면 이상이 드러나기도 합니다.
이 글은 가구를 옮기다 문틀이나 도어락이 상했을 때 무엇을 살피고, 어디까지 직접 해보고, 언제 [수원 출장열쇠](suwon.html)를 부르면 되는지 순서대로 적었습니다. / 문이 안 닫히거나 안 열리는 상황이라면 아래 목차에서 필요한 부분부터 보셔도 됩니다.
@ 파장동 가구 반입 중 문틀에 생긴 긁힘

# 가구 반입 날 현관에서 자주 생기는 일
큰 가구를 들일 때는 문을 최대한 넓게 열어 고정해 둡니다. / 이때 문이 경첩 한계를 넘어 젖혀지거나 벽에 부딪히면서 틀어지기도 합니다.
- 가구 모서리에 도어락 바깥판이 눌리거나 긁힌 경우
- 문을 고정하려 끼운 물건 때문에 걸쇠가 문틀 쪽에서 밀린 경우
- 문을 너무 젖혀 경첩이 휘고 문이 아래로 처진 경우
- 비닐과 박스 끈에 손잡이가 걸려 당겨진 경우
어느 쪽이든 겉으로는 작아 보여도 문이 닫히는 위치가 달라졌다면 안쪽 부품이 영향을 받았을 수 있습니다.

# 일을 마치고 문을 닫았는데 이상하다면
반입이 끝나고 문을 닫았을 때 평소보다 소리가 크거나 덜컹거리면 바로 알아차릴 수 있습니다. / 아래 증상은 가구를 옮긴 직후에 특히 자주 나옵니다.
- 문이 끝까지 닫히지 않고 중간에 걸리는 느낌
- 닫히긴 하는데 잠금 소리가 나지 않는 경우
- 번호를 눌렀는데 모터 소리만 나고 걸쇠가 움직이지 않는 경우
- 손잡이가 평소보다 헐겁거나 눌러도 되돌아오지 않는 경우
이런 증상이 있으면 그날은 무리하게 여닫지 않는 편이 낫습니다. / 반복해서 닫으면 걸쇠와 문틀이 서로 더 깊게 긁히기 때문입니다.

# 문틀이 긁혔을 때 도어락과 무슨 관계가 있을까
도어락의 걸쇠는 문틀에 뚫린 홈에 정확히 들어가야 잠깁니다. / 문틀이 눌리거나 문이 처지면 걸쇠와 홈의 위치가 어긋나서 잠기지도, 열리지도 않는 일이 생깁니다.
그래서 도어락 자체는 멀쩡한데 문만 안 열리는 경우가 있습니다. / 이럴 때는 도어락을 새로 바꾸기 전에 문의 위치부터 확인해야 불필요한 교체를 피할 수 있습니다.
문틀에 칠이 벗겨진 정도라면 기능에는 문제가 없는 경우가 대부분입니다. / 홈 주변이 찌그러졌는지, 문과 문틀 사이 틈이 위아래로 다른지를 눈으로 보시면 됩니다.

# 직접 해볼 수 있는 확인 세 가지
전화하기 전에 아래 세 가지를 보시면 상황을 설명하기 쉽습니다.
- 문을 닫을 때 손잡이를 살짝 위로 들어 올리면 닫히는지
- 문 가장자리 틈이 위쪽과 아래쪽에서 비슷한지
- 번호판이 정상으로 켜지고 입력음이 나는지
문을 들어 올리며 닫았을 때만 닫힌다면 경첩 쪽 처짐이 원인일 가능성이 큽니다. / 번호판이 꺼져 있거나 입력음이 없다면 가구에 부딪히면서 내부 선이 빠졌을 수도 있습니다.
확인이 끝나면 더 만지지 말고 상태를 사진으로 남겨 두세요. / 나중에 어디가 어떻게 상했는지 설명하기 좋습니다.

# 이럴 땐 힘주어 밀거나 당기지 마세요
안 닫히는 문을 어깨로 밀어 닫거나, 걸쇠가 걸린 문을 세게 흔들면 상태가 나빠집니다. / 걸쇠가 휘면 열쇠로도 열리지 않는 일까지 생길 수 있습니다.
도어락 틈에 드라이버를 끼워 눌러 보는 분도 계시지만 외관이 긁히고 안쪽 부품이 상할 수 있습니다. / 비밀번호를 연달아 틀리면 잠시 입력을 막는 제품도 많으니 서너 번 해보고 멈추세요.
@ 파장동 도어락 바깥판 눌림 확인

# 문이 안 열릴 때와 안 닫힐 때는 접근이 다릅니다
안 닫히는 문은 급하지 않은 편입니다. / 임시로 문을 닫아 두고 잠금 없이 하루를 보내는 것이 불안하다면 문을 열어 둔 채 사람이 지키거나, 그날 바로 연락 주시는 편이 안전합니다.
안 열리는 문은 상황이 다릅니다. / 집 안에 아이나 반려동물, 불 켜 둔 가스레인지가 있다면 지체하지 말고 먼저 알려 주세요.
어느 쪽이든 문 앞 상황을 짧게 정리해서 말씀해 주시면 [현관문 개문](door-open.html)이 필요한지, 점검만으로 충분한지 판단하기 쉽습니다.

# 출장열쇠를 부르면 이런 순서로 봅니다
도착하면 먼저 문과 문틀의 어긋남, 걸쇠 위치, 도어락 작동 소리를 차례로 봅니다. / 원인이 문의 처짐인지, 도어락 내부인지, 문틀 홈인지 가려내는 것이 첫 순서입니다.
문을 못 열고 있다면 상하지 않게 여는 방법부터 시도합니다. / 열고 난 뒤에 도어락을 분해해 보지 않고는 원인을 알 수 없는 경우도 있어, 그럴 때는 손대기 전에 말씀드립니다.
전화 상담에서 상황을 정리해 드리는 [출장 호출 안내](key-call.html)도 참고해 보세요.
@ 파장동 걸쇠와 문틀 홈 위치 점검

# 도착하면 사는 분인지 먼저 확인합니다
새로 이사했거나 가구를 막 들인 집이라 우편물이 아직 없을 수 있습니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
계약서나 이삿짐 업체 서류를 함께 보여 주시면 도움이 되는 경우가 있습니다. / 그래도 확인이 어렵다면 작업은 할 수 없으니 미리 챙겨 두시면 좋습니다.
집 안에 신분증이 있다면 관리사무소에 세대 확인을 부탁하는 방법이 있습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문과 도어락 상태를 보고 어떤 작업이 필요한지 먼저 설명드립니다. / 그 내용에 동의하시면 시작하고, 아니라면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙고, 말없이 늘어나는 항목은 없습니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 고칠지 바꿀지는 이렇게 가립니다
가구에 눌린 외관만 긁혔고 작동이 정상이면 그대로 쓰셔도 됩니다. / 걸쇠나 모터가 문제라면 먼저 [도어락 수리](doorlock-repair.html)로 해결되는지 봅니다.
수리가 어렵거나 안쪽 부품이 여럿 상했을 때만 [도어락 교체](doorlock-replace.html)를 권해 드립니다. / 새 제품을 달 때는 문 두께와 구멍 위치를 먼저 확인합니다.
문틀 자체가 심하게 찌그러졌다면 도어락과 별개로 문 쪽 보수가 필요할 수 있습니다. / 그런 범위는 솔직하게 말씀드리고 가능한 선만 도와드립니다.

# 다음 가구 반입 때 미리 해둘 것
이사나 가구 교체는 한 번으로 끝나지 않습니다. / 다음 반입 때를 위해 아래 습관을 기억해 두시면 좋습니다.
- 문 고정은 문틈에 끼우는 물건 말고 전용 스토퍼로
- 도어락 바깥판에 두꺼운 보호 천이나 박스를 대기
- 큰 가구는 손잡이 높이를 피해 비스듬히 들이기
- 작업이 끝나면 문을 열었다 닫으며 잠금 소리 확인
- 반입 전 문틀 상태를 사진으로 찍어 두기
이렇게 해두면 나중에 문이 이상해졌을 때 언제 생긴 변화인지 비교하기 쉽습니다.

# 파장동 말고 수원 어디든 갑니다
파장동 옆 조원동, 율전동, 천천동, 정자동은 물론 영통동, 광교동 등 수원 안이면 동네와 상관없이 다닙니다. / 수원에서 다니는 지역은 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다.
수원 밖 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
