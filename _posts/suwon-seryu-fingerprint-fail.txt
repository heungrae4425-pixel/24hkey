# 세류동에서 지문 인식이 갑자기 안 될 때
세류동은 수원역과 가까워 출퇴근하는 분들이 많은 동네입니다. / 바쁜 아침이나 늦은 저녁에 지문 도어락이 안 열려 당황하는 연락이 가끔 옵니다.
어제까지 잘 되던 지문이 오늘 안 되면 고장인지 손 문제인지 헷갈립니다. / 대부분은 손 상태나 센서 표면 때문이라 먼저 확인해 볼 수 있는 것이 있습니다.
이 글은 세류동에서 지문 인식 도어락이 안 열릴 때 확인할 순서를 정리했습니다. / 그래도 안 되면 [출장 열쇠](key-call.html)를 부르는 방법도 적었습니다.
@ 세류동 출장열쇠 지문 도어락

# 가장 흔한 원인은 손 상태입니다
손이 젖었거나 땀이 많이 나면 지문이 흐려져 인식이 잘 안 됩니다. / 겨울에 손이 건조해도 지문이 얕아져서 인식률이 떨어집니다.
손가락을 다쳤거나 굳은살이 생겼거나 지문이 닳은 경우도 있습니다. / 요리나 청소를 하고 온 직후에는 지문에 이물질이 묻어 있을 수 있습니다.
손을 마른 수건으로 닦고 다시 대 보세요. / 한 손가락이 안 되면 다른 손가락으로 바꿔 보는 것도 방법입니다.

# 센서 표면을 확인하세요
지문 센서에 먼지나 기름, 물방울이 묻으면 인식이 떨어집니다. / 부드러운 마른 천으로 센서 표면을 가볍게 닦아 주세요.
물이나 세제를 직접 뿌리는 것은 피해 주세요. / 센서 안으로 습기가 들어가면 고장이 날 수 있습니다.
센서 표면에 긁힌 자국이 많으면 인식이 점점 나빠질 수 있습니다. / 이런 경우는 센서 교체가 필요할 수 있습니다.
@ 세류동 지문 센서 점검

# 손가락 대는 방법을 바꿔 보세요
센서에 대는 각도와 힘에 따라 인식이 달라집니다. / 손가락을 센서에 평평하게 대고 약간 누르면서 1~2초 가만히 있어 보세요.
너무 세게 누르거나 대충 스치면 오히려 인식이 안 됩니다. / 등록할 때와 같은 위치와 각도로 대는 것이 중요합니다.
처음 등록할 때 한 손가락을 여러 각도로 여러 번 등록해 두면 인식률이 올라갑니다. / 이번 기회에 같은 손가락을 다시 등록해 두는 것도 좋습니다.

# 번호나 카드로 열 수 있는지 확인하세요
지문 도어락은 대부분 비밀번호나 카드키로도 열립니다. / 지문이 안 될 때는 번호를 눌러 보세요.
번호도 안 눌리고 번호판이 아예 꺼져 있으면 배터리 문제일 가능성이 큽니다. / 이때는 바깥 아래쪽 비상 단자에 9V 건전지를 대 보세요.
건전지를 대고 있는 동안 전원이 들어와 번호나 지문으로 열 수 있습니다. / 열린 뒤에는 안쪽 배터리를 모두 새것으로 바꿔 주세요.

# 지문 등록이 사라졌을 때
배터리가 완전히 방전된 뒤 충전하면 설정이 초기화되는 제품도 있습니다. / 그런 경우 등록해 둔 지문이 지워져 있을 수 있습니다.
번호 등록이 남아 있는지 먼저 확인해 보세요. / 번호도 지워졌다면 관리자 모드로 다시 등록해야 합니다.
제품마다 초기화와 재등록 방법이 달라서 모델을 확인하는 것이 중요합니다. / 도어락 사진을 보내 주시면 방법을 안내해 드립니다.

# 이런 상황에서 출장열쇠를 부릅니다
혼자 해결하려고 오래 붙잡고 있지 않는 편이 낫습니다. / 아래 같은 경우라면 연락 주세요.
번호도 지문도 카드도 안 되는데 집 밖에 있는 경우가 있습니다. / 배터리를 바꿔도 소리만 나고 열리지 않는 경우도 있습니다.
센서가 고장 난 것 같은데 모델을 모르겠다는 경우도 있습니다. / 이때는 사진을 보내 주시면 맞는 점검 방법을 알려 드립니다.

# 세류동 위치는 이렇게 알려주세요
세류동은 역 주변과 주택가, 아파트 단지가 이어져 있어 위치를 정확히 알려 주시는 것이 중요합니다. / 건물 이름, 동, 호수와 함께 지금 상황을 짧게 말씀해 주세요.
- 건물 이름 또는 주소와 동, 호수
- 지문 외에 번호나 카드는 되는지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 도어락 모양과 제조사 표시
- 집 안에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙기기 좋습니다. / 수원역과 세류동 어디든 출동합니다.

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집 모두를 위한 절차입니다. / 신분 확인이 어려우면 작업을 시작할 수 없다는 점을 이해해 주세요.
@ 세류동 24시 출장열쇠 신분 확인

# 비용은 작업 전에 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 안내해 드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 작업 후에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭤봅니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 문을 여는 방법과 점검
문 여는 방법은 여러 가지가 있고, 덜 상하는 방법부터 차례로 해봅니다. / 지문 도어락은 전자 부품이 들어 있어서 특히 조심해서 다룹니다.
문이 열리면 센서와 도어락이 다시 정상으로 작동하는지 같이 확인합니다. / 배터리가 원인이었다면 새 배터리로 바꾸는 것까지 함께 합니다.
현관문 개문 방식은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다. / 센서 문제라면 [도어락 수리](doorlock-repair.html)로 먼저 손볼 수 있는지 봅니다.

# 센서가 많이 닳았다면
센서 표면이 심하게 긁혔거나 인식이 계속 떨어지면 교체를 고민할 시기입니다. / 오래된 제품은 부품을 구하기 어려울 수도 있습니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 정말 바꿔야 하는 경우에만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
바꿀 때는 지문 방식 외에 번호나 카드도 함께 쓸 수 있는 제품을 권해 드립니다. / 한 가지 방법에만 의존하면 이런 상황이 다시 생길 수 있기 때문입니다.

# 지문 도어락 오래 쓰는 관리법
작은 습관으로 인식률을 오래 유지할 수 있습니다. / 아래 정도만 해 두셔도 도움이 됩니다.
- 센서를 가끔 마른 천으로 닦기
- 손이 젖었을 때는 닦고 대기
- 한 손가락을 여러 각도로 등록해 두기
- 번호나 카드도 함께 등록해 두기
- 배터리는 해가 바뀔 때쯤 한 번에 교체
여러 손가락을 등록해 두면 하나가 안 될 때 다른 손가락으로 열 수 있습니다. / 가족 지문도 가능하면 두 개 이상 등록해 두세요.

# 세류동 말고 수원 어디든 갑니다
세류동 바로 옆 권선동, 매산로, 인계동 쪽도 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
