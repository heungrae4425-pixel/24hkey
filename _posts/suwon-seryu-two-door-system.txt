# 세류동 현관에 문이 두 개, 어느 쪽이 안 열리는 걸까
세류동은 수원역 생활권에 가까워 아파트와 빌라가 함께 있고, 현관에 철제 방화문 바깥으로 얇은 방풍문을 한 겹 더 단 집도 있습니다. / 문이 두 겹이면 따뜻하고 조용한 장점이 있지만, 잠금이 두 군데라 문제가 생기면 어디가 막혔는지부터 헷갈립니다.
이 글은 현관 이중문이 안 열릴 때 방화문 문제인지 방풍문 문제인지 구분하고 순서대로 푸는 방법을 정리했습니다. / 전화하기 전에 확인하면 상담이 훨씬 빨라집니다.
@ 세류동 현관 이중문 방화문 방풍문 구조

# 이중문 구조부터 이해하면 쉽습니다
안쪽 문은 보통 철제 방화문이고 도어락과 보조키가 달려 있습니다. / 바깥쪽 문은 방풍문, 중문이라고 부르는 얇은 문으로 별도 열쇠나 작은 잠금이 달려 있기도 합니다.
- 방화문은 도어락과 보조키로 잠기는 안쪽 문
- 방풍문은 유리나 얇은 철판에 손잡이 잠금이 있는 바깥 문
- 두 문 사이는 신발이나 짐을 두는 좁은 공간
- 문마다 열쇠가 다르거나 같은 열쇠를 같이 쓰는 경우
어느 문 앞에 서 있는지, 그 사이 공간에 들어와 있는지에 따라 상황이 달라집니다.

# 첫째, 방풍문이 안 열리는 경우
방풍문은 바깥에서 열쇠로 열고 안에서는 손잡이로 여는 간단한 구조가 많습니다. / 열쇠가 안 돌아가거나 걸쇠가 문틀에 눌려 있으면 못 엽니다.
- 열쇠가 들어가는데 돌아가지 않는 경우
- 문틀이 처져 걸쇠가 문틀에 눌려 있는 경우
- 안쪽에서 잠금장치를 걸어 두고 나온 경우
방풍문이 닫혀 있어도 방화문 앞까지는 못 갑니다. / 방풍문부터 열어야 방화문 문제를 확인할 수 있어 순서가 중요합니다.

# 둘째, 방화문 도어락이 안 열리는 경우
방풍문은 열렸는데 안쪽 방화문 번호가 안 먹는 경우입니다. / 이 경우는 일반 현관문과 같은 원인이 대부분입니다.
- 번호판이 꺼져 배터리가 다 된 경우
- 번호는 맞는데 모터 소리만 나는 경우
- 안쪽 보조키나 걸쇠가 걸려 있는 경우
- 비밀번호를 가족이 바꾼 것을 몰랐던 경우
방풍문 때문에 방화문 번호판에 닿는 빛이 줄어 화면이 안 보이는 일도 있어 휴대폰 손전등을 비춰 보세요.

# 셋째, 두 문이 서로 닿아서 못 여는 경우
문 사이 공간이 좁은 집은 방풍문이 열리는 각도에 방화문이 닿아 걸리기도 합니다. / 문을 열 때 다른 문에 부딪히는 소리가 나면 이런 경우입니다.
이때는 먼저 닫힌 문을 조금 더 열었다가 닫는 식으로 순서를 바꿔 보세요. / 짐이나 우산이 두 문 사이에 끼어 문이 안 닫히는 일도 있습니다.
@ 방풍문과 방화문 사이 좁은 공간 점검

# 방풍문과 방화문 열쇠를 헷갈렸을 때
이중문 집은 열쇠가 두 개라 서로 바꿔 넣는 일이 많습니다. / 열쇠가 안 맞는다고 억지로 돌리면 부러지는 원인이 됩니다.
- 열쇠 머리 모양과 색으로 구분해 두기
- 한쪽은 도어락 번호, 한쪽은 열쇠로 쓰는 집이 많음
- 열쇠가 하나뿐이라면 새로 만들기 전에 어느 문 것인지 확인
열쇠 문제는 [열쇠 출장](key-call.html)으로 상담하실 수 있습니다. / 두 문 열쇠를 하나로 맞추는 것도 가능한지 현장에서 봅니다.

# 두 문 사이 공간에 갇힌 경우
방풍문을 닫고 들어왔는데 방화문이 안 열려서 사이 공간에 서 있게 되는 일이 있습니다. / 이때 방풍문 안쪽 손잡이가 열려야 밖으로 나갈 수 있습니다.
방풍문이 바깥에서만 열쇠를 쓰는 구조면 안쪽에서도 손잡이가 안 돌아가 갇힐 수 있습니다. / 추운 날이나 짐이 있는 상태면 서둘러 전화 주세요.
급한 환자나 아이가 같이 있으면 119가 먼저입니다.

# 하지 말아야 할 행동
이중문은 두 겹이라 한쪽을 손상시키면 다른 쪽에도 영향이 갑니다.
- 방풍문 유리를 두드리거나 깨는 것
- 방화문 손잡이를 세게 당기거나 발로 차는 것
- 얇은 문 틈으로 카드나 드라이버를 넣는 것
- 비밀번호를 연달아 틀려 도어락을 잠가 버리는 것
방풍문은 유리나 얇은 판이라 힘을 주면 깨지거나 휘기 쉽습니다. / 그러면 열쇠 문제가 아니라 문 교체 문제가 됩니다.

# 전화로 이렇게 말씀해 주세요
어느 문이 어떤 상태인지 알려 주시면 준비가 정확해집니다.
- 지금 서 있는 곳이 방풍문 바깥인지, 두 문 사이인지
- 안 열리는 문이 방풍문인지, 방화문인지, 둘 다인지
- 번호판이나 열쇠 구멍 상태(켜짐, 꺼짐, 경고음)
- 집 안에 아이나 반려동물이 있는지
문 두 개를 사진으로 한 장씩 보내 주시면 더욱 좋습니다. / 문 모양을 모르면 그냥 현관 사진만 보내셔도 됩니다.

# 도착하면 사시는 분 확인과 비용 안내
집 문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
이중문은 외부에서 문 사이 공간으로 사람이 들어가기 쉬운 구조라 확인을 더 꼼꼼히 합니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.

어느 문을 어떻게 열어야 하는지 보고 얼마인지 먼저 말씀드립니다. / 괜찮으시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용은 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 이중문을 상하지 않게 여는 순서
두 문을 함께 여는 일은 순서가 중요합니다. / 보통 바깥 방풍문부터 상하지 않게 열고, 그다음 방화문을 같은 방법으로 엽니다.
방풍문이 이미 열려 있으면 방화문만 작업하므로 시간이 줄어듭니다. / 방풍문 유리나 틀은 건드리지 않고 잠금 부위만 풉니다.
방법은 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
@ 세류동 방화문 도어락 상하지 않게 개방

# 열고 난 뒤 두 문 모두 점검합니다
문이 열리면 두 문이 각각 잘 잠기고 열리는지 확인합니다. / 방풍문이 방화문에 닿지 않는지, 닫는 속도가 알맞은지도 같이 봅니다.
- 방화문 도어락 배터리와 번호 상태
- 방풍문 열쇠 구멍과 걸쇠 움직임
- 두 문의 경첩과 문틀 틈
- 문 닫는 속도와 부딪힘 소리
고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 것은 그때 말씀드립니다.

문이 두 겹이라 한쪽만 신경 쓰다 다른 쪽 고장을 놓치기 쉽습니다.
- 겨울 전에 방풍문 경첩에 마른 기름칠
- 방풍문 열쇠 한 개는 가족 중 한 명이 따로 보관
- 두 문 사이에 물건을 쌓아 두지 않기
- 배터리는 해가 바뀔 때쯤 한 번에 교체
방풍문은 평소에 잠그지 않는 집도 많습니다. / 그런 경우 열쇠 구멍이 굳어 있다가 막상 필요할 때 안 돌아가는 일이 있습니다.

# 세류동 말고 수원 어디든 갑니다
세류동 가까운 권선동, 인계동, 화서동은 물론 수원 안이면 동네 상관없이 갑니다. / 동네 정리는 [수원시 출장열쇠](suwon.html) 페이지에 있습니다.
서울과 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
