# 우만동에서 관리사무소가 퇴근한 뒤에 문이 잠기면
수원역 방면으로 오가는 우만동 생활권의 공동주택에서는 관리사무소 퇴근 시간이 지나면 신분 확인 방법이 막막해지는 일이 있습니다. / 열쇠도 신분증도 집 안에 두고 나왔다면 더 그렇습니다.
이 글은 관리사무소가 문을 닫은 저녁이나 밤에 문이 잠겼을 때, 신분을 확인받고 문을 여는 순서를 정리한 글입니다.
@ 우만동 저녁 시간 아파트 출입구와 현관문 앞

# 왜 관리사무소 확인이 자주 나오는가
문을 열어 달라는 요청은 사시는 분이 맞는지 확인이 되어야 진행할 수 있습니다. / 옆집이나 다른 사람의 집을 대신 여는 일을 막기 위한 절차입니다.
신분증 주소가 지금 사는 곳과 같으면 쉽게 확인됩니다. / 이사한 지 얼마 안 되어 신분증 주소가 이전 주소로 남아 있다면 다른 증빙이 필요합니다.

# 퇴근 후에도 쓸 수 있는 확인 방법
관리사무소가 닫혀도 아래 방법 중 하나로 확인이 가능한 경우가 있습니다.
- 주소가 적힌 신분증, 운전면허증
- 지금 주소로 온 우편물이나 고지서 사진
- 임대차 계약서 사본 (폰에 사진으로 있으면 가능)
- 경비실이나 야간 당직 근무자의 세대 확인
- 같은 건물 이웃이 아는 사이임을 말해 주는 경우
어느 하나라도 준비되면 진행이 빨라집니다. / 집 안에 서류가 모두 있어도 폰 앨범이나 메신저 대화에 사진이 남아 있는 경우가 많습니다. / 택배 송장이나 이사 때 받은 안내문 사진도 현재 주소를 보여 주는 자료가 될 수 있습니다. / 어떤 자료가 인정되는지는 현장에서 같이 판단하니 일단 가진 것을 말씀해 주세요.

# 경비실이나 야간 당직이 있는지 먼저 확인
관리사무소는 퇴근해도 경비실은 24시간 운영되는 곳이 있습니다. / 경비실에서 입주자 확인을 해 줄 수 있는지 문의해 보세요.
확인이 어려운 건물이라면 이웃에게 부탁해 지금 내가 이 집에 산다는 사실을 말해 달라고 청할 수도 있습니다. / 이웃이 곤란해하면 억지로 부탁하지 않아도 됩니다. / 이웃 사이에 서로 얼굴을 아는 분위기라면 한 마디가 큰 도움이 됩니다.

# 휴대폰이 집 안에 있는 경우
열쇠와 폰이 모두 집 안에 있다면 연락하기부터 막힙니다. / 이웃에게 정중히 전화를 빌리거나 근처 편의점에서 도움을 청하세요.
번호를 외우고 있는 가족이나 지인이 있으면 대신 연락해 달라고 부탁합니다. / [출장열쇠 요청](key-call.html) 안내에 연락 방법을 정리해 두었습니다.

# 문 앞에서 먼저 해볼 일
도어락이 있는 집이라면 번호 입력부터 차분히 해 보세요. / 번호판이 꺼져 있으면 배터리 문제일 가능성이 큽니다.
비상 전원 단자가 있으면 9V 건전지를 대어 볼 수 있지만, 이 시간에 구하기 어려울 수 있습니다. / 편의점이 가까우면 구해 볼 수 있습니다. / 열쇠 방식이면 열쇠 구멍을 억지로 건드리지 말고 상태만 확인하세요.
@ 도어락 번호판 상태를 살피며 확인하는 모습

문을 힘으로 열려고 두드리거나 차는 일은 이웃에게 소음 피해를 주고 문도 상하게 합니다. / 늦은 시간에는 복도 소리가 크게 울립니다. / 큰 소리로 다투듯 문을 두드리면 이웃이 놀라 경비실에 연락할 수도 있습니다.
인터넷에서 본 방법으로 카드나 도구를 문틈에 넣는 것도 권하지 않습니다. / 문틀과 도어락이 상하면 나중에 수리 범위가 커집니다.

# 전화할 때 알려 주실 것
- 우만동 어느 건물인지 (단지 이름 대신 길이나 건물 형태로 설명하셔도 됩니다)
- 지금 들어갈 수 있는 확인 서류가 있는지
- 도어락 종류와 번호판 상태
- 집 안에 아이나 반려동물이 있는지
위치를 정확히 알려 주시면 도착이 빨라집니다. / 서류가 하나도 없다고 해도 일단 상황을 말씀해 주세요. / 신분 확인이 끝내 안 되는 경우에는 작업을 하지 않으며 이 경우 비용도 받지 않습니다. / 그전에 가능한 방법을 최대한 같이 찾아 드립니다. 가능한 확인 방법을 같이 찾아 봅니다.

# 도착하면 신분 확인부터 합니다
출장 기사가 도착하면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 끝나지 않으면 작업을 할 수 없으니 미리 준비해 주세요. / 번거롭지만 이웃과 다른 가구를 지키는 절차입니다. / 확인에 시간이 걸려도 이 단계를 생략하지 않습니다. / 서류 준비가 안 되어 있더라도 일단 도착한 뒤 방법을 같이 찾아봅니다.

# 비용은 문 열기 전에 말씀드립니다
문과 도어락 상태를 보고 필요한 작업과 비용을 먼저 말씀드립니다. / 동의하실 때만 시작하고, 문을 열지 못하면 비용은 받지 않습니다.
열고 난 뒤에 말없이 붙는 비용은 없습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.
@ 신분증과 우편물로 거주 확인을 하는 장면

# 문은 최대한 상하지 않게 엽니다
밤에 하는 작업이라도 도어락과 문틀을 상하게 하지 않는 방법부터 순서대로 시도합니다. / 부품을 바꿔야 할 때는 먼저 이유를 설명드립니다.
문 개방 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다. / 이웃 소음이 걱정되는 늦은 시간에는 조용히 작업하도록 신경 씁니다. / 공동주택 복도는 소리가 울리니 대화도 낮은 목소리로 합니다.

# 열린 뒤에 해둘 일
문이 열리면 도어락이 정상으로 잠기고 열리는지 확인합니다. / 배터리 방전이 원인이었다면 새 배터리로 바꿨는지도 함께 봅니다.
비밀번호를 바꿔야 하는 상황이면 새 번호를 등록해 드립니다. / 고장이 반복되면 [도어락 수리](doorlock-repair.html)로, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)로 안내해 드립니다.

# 다음에 같은 일이 없도록 미리 해둘 일
- 신분증과 주소 확인용 우편물 사진을 폰에 보관해 두기
- 관리사무소와 경비실 운영 시간, 야간 연락처 알아 두기
- 열쇠나 카드키 하나를 믿을 만한 가족이나 이웃에게 맡기기
- 도어락 배터리를 해마다 한 번에 교체하기
- 문을 닫기 전에 열쇠와 폰이 주머니에 있는지 확인하기
작은 준비 하나가 밤늦은 시간의 곤란을 크게 줄여 줍니다. / 한 번 겪고 나면 누구나 챙기게 되지만, 겪기 전에 해 두는 편이 훨씬 낫습니다. / 임대 중인 집이라면 집주인 연락처도 폰에 저장해 두세요.

# 우만동 말고 수원 어디든 갑니다
관리사무소 운영 시간은 건물마다 다르니 평소 알아 두면 좋습니다. / 야간이나 주말에는 비상 연락처를 안내문으로 붙여 두는 곳도 있습니다. / 현관 근처 게시판에서 한 번 확인해 보세요.
우만동 주변은 물론 인계동, 매탄동, 영통동, 연무동 등 수원 안이면 24시간 출동합니다. / 다니는 동네는 [수원 출장열쇠](suwon.html) 페이지에 정리해 두었습니다.

? 신분증이 집 안에 있어요. | 폰 속 사진, 우편물, 경비실 확인 등 가능한 방법을 같이 찾아 봅니다. 먼저 상황을 말씀해 주세요.
