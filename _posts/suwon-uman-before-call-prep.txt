# 우만동에서 전화 걸기 전에 1분만 쓰세요
문 앞에서 당황한 상태로 전화를 걸면 무엇을 말해야 할지 막막합니다. / 몇 가지만 미리 챙겨 두면 통화가 짧아지고 도착도 빨라집니다.
수원 우만동은 주택가와 상가, 아파트가 가까이 섞여 있어 위치 설명이 헷갈리기 쉬운 동네입니다. / 그래서 전화 전에 알려줄 내용을 정리해 두는 것이 도움이 됩니다.
이 글은 [수원 출장열쇠](suwon.html)를 부르기 전에 준비할 것들을 순서대로 적었습니다. / 지금 문 앞이시라면 2번과 3번만 먼저 보셔도 됩니다.

# 가장 먼저 알려줄 것은 정확한 위치입니다
위치는 도로 이름이나 건물 이름 한 줄이면 충분합니다. / 우만동 안에서도 골목이 여러 갈래라 큰길에서 어느 쪽인지 같이 알려주시면 좋습니다.
아파트나 빌라라면 건물 이름과 동, 호수를 함께 말씀해 주세요. / 단독주택이라면 대문 색이나 근처 가게 이름이 길 찾는 데 큰 도움이 됩니다.
지도 앱의 위치 공유를 문자로 보내 주시면 가장 정확합니다. / 말로 설명하기 어려우면 그냥 위치 링크만 보내셔도 됩니다.

# 문 상태를 사진으로 보내 주세요
번호판이 켜지는지, 손잡이 모양이 어떤지 사진 한 장이면 대부분 파악됩니다. / 도어락 정면과 문 전체가 나오게 한 장씩 찍어 보내 주세요.
어떤 장비를 챙겨 갈지가 사진을 보고 정해지기 때문에 현장에서 헛걸음이 줄어듭니다. / 사진을 찍기 어려우면 모양을 말로 설명하셔도 괜찮습니다.
문이 어두운 복도에 있다면 휴대폰 손전등을 켜고 찍어 주세요. / 번호판이 꺼진 상태라도 도어락 윗부분에 적힌 글씨가 보이면 기종을 가늠하는 데 도움이 됩니다.
@ 우만동 출장열쇠 도어락 사진 상태 확인

# 번호판 불빛과 소리를 알려주세요
번호판이 아예 꺼져 있는지, 켜지지만 소리만 나는지에 따라 원인이 다릅니다. / 전화로 이 부분만 말씀해 주셔도 상황을 크게 좁힐 수 있습니다.
- 번호판이 전혀 안 켜진다 → 배터리 쪽
- 켜지는데 열리지 않는다 → 모터나 걸쇠 쪽
- 경고음이 길게 난다 → 배터리 부족이나 오류 신호
- 번호는 맞는데 거부한다 → 등록 번호가 바뀌었을 수 있음
이 정도만 알려주셔도 도착해서 확인하는 시간이 줄어듭니다.

# 아이나 반려동물이 안에 있는지 꼭 말씀해 주세요
집 안에 아이나 반려동물이 혼자 있으면 순서가 달라집니다. / 문을 여는 방식과 서두르는 정도를 상황에 맞게 정해야 하기 때문입니다.
불이나 가스를 켜 둔 채 나왔다면 그 말도 먼저 해 주세요. / 안전이 걸린 문제는 다른 모든 것보다 앞서 처리합니다. 문 너머로 계속 말을 걸어 아이를 안심시켜 주시면 큰 도움이 됩니다.

# 열쇠를 어디에 두고 나왔는지도 알려주세요
열쇠가 집 안에 있는지, 잃어버렸는지, 아예 없는지에 따라 진행이 달라집니다. / 열쇠를 잃어버린 경우라면 문을 연 뒤 열쇠를 새로 맞출지도 같이 정하게 됩니다.
가족이나 룸메이트가 열쇠를 가지고 있다면 연락이 되는지 확인해 보세요. / 가족이 곧 도착한다면 굳이 부르지 않아도 되는 경우도 있습니다. / 다만 안에 아이나 반려동물이 있거나 급한 일정이 있다면 기다리지 말고 먼저 연락 주세요.

# 신분 확인에 쓸 것을 준비해 두세요
문을 여는 일이라 사시는 분이 맞는지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 휴대폰 속 택배 기록이나 고지서 사진도 참고가 될 수 있습니다. / 어떤 걸로 확인이 가능한지는 현장에서 같이 정합니다.
이 절차 설명은 [이용안내](guide.html)에도 적어 두었습니다. / 번거로우셔도 이웃과 손님 모두를 위한 순서입니다.
@ 수원 우만동 문 열기 전 신분 확인 안내

# 전화로 이런 말씀은 안 하셔도 됩니다
도어락 상표나 정확한 모델명을 모르셔도 괜찮습니다. / 사진과 증상만 있으면 현장에서 확인합니다.
몇 번 시도했는지, 어디를 건드렸는지는 솔직하게 말씀해 주시는 게 도움이 됩니다. / 문제를 키울까 봐 숨기시면 오히려 원인 찾기가 어려워집니다.

# 통화는 이렇게 짧게 하셔도 됩니다
말을 잘 정리하지 못하셔도 괜찮습니다. / "우만동 큰길 쪽 빌라 앞이고, 번호판이 꺼졌고, 열쇠는 집 안에 있어요" 정도면 충분합니다.
위치, 문 상태, 열쇠 유무, 이 세 가지만 들어 있으면 나머지는 제가 묻겠습니다. / 숨이 찰 만큼 급하시면 위치만 말씀하셔도 먼저 출발 준비를 합니다.
이웃 전화를 빌려 거신 경우라면 그 번호로 다시 연락드릴 수 있게 번호를 불러 주세요. / 휴대폰이 집 안에 있어 연락이 어려운 상황도 자주 있습니다.
@ 수원 우만동 출장열쇠 전화 위치 안내

# 먼저 해 볼 수 있는 것과 하지 말아야 할 것
번호판이 꺼졌다면 9V 건전지를 비상 단자에 대 보는 것까지는 괜찮습니다. / 그 외에 문틈에 도구를 넣거나 손잡이를 세게 당기는 일은 피해 주세요.
카드나 드라이버로 문틈을 벌리면 문틀과 도어락에 흠이 남습니다. / 안 상하게 여는 방법이 있으니 그대로 두고 연락 주시는 게 낫습니다.
자세한 개문 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 급한 마음에 먼저 건드리지 않는 것이 가장 도움이 됩니다.

# 도착하면 이런 순서로 진행합니다
도착해서 문과 도어락 상태를 먼저 직접 확인합니다. / 어떤 방법으로 열지, 부품을 바꿔야 하는지 판단한 뒤 비용을 말씀드립니다. 작업 중에 시간이 걸리는 부분이 생기면 그 이유도 바로 설명드립니다.
괜찮다고 하시면 그때 작업을 시작합니다. / 안 상하게 여는 쪽부터 차례로 해 보고, 바꿔야 할 부분이 보이면 손대기 전에 먼저 여쭙니다.
문이 열린 뒤에는 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 해결합니다.

# 비용은 문 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 마음에 안 드시면 그냥 돌아가도 됩니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용은 없습니다.
부품을 바꿔야 한다고 판단되면 어떤 부품이 왜 필요한지 먼저 보여드립니다. / 필요 없다고 생각되시면 거절하셔도 되고, 그때는 열어 드린 것까지만 정리합니다.

# 전화하기 전 준비 요약
급할수록 아래 다섯 가지만 챙기시면 됩니다.
- 우만동 안의 정확한 위치(건물 이름이나 지도 링크)
- 도어락과 문을 찍은 사진 두 장
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집 안에 아이나 반려동물이 있는지
- 신분 확인에 쓸 서류나 우편물
수원 다른 동네도 같은 순서로 준비하시면 됩니다. / 지역별 안내는 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
