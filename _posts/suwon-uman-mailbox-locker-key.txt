# 우만동에서 우편함과 사물함이 안 열릴 때
우만동은 아주대 쪽 원룸과 다세대, 아파트가 가깝게 모여 있어 우편함과 사물함을 쓰는 집이 많습니다. / 현관문은 열리는데 우편함 열쇠를 잃어버려 우편물을 못 꺼내는 연락이 가끔 옵니다.
관리비 고지서나 택배 안내문처럼 급히 확인해야 하는 우편물이 안에 있을 때는 더 마음이 급해집니다. / 이사 오면서 열쇠를 못 받았거나 이전 사람 열쇠만 남아 있는 경우도 있습니다.
이 글은 우만동에서 우편함, 사물함, 보관함 열쇠 문제가 생겼을 때 먼저 확인할 것을 정리했습니다. / 그다음 [출장 열쇠](key-call.html)를 부르면 어떻게 진행되는지도 적었습니다.
@ 우만동 출장열쇠 우편함 사물함

# 우편함 잠금은 종류가 여러 가지입니다
건물마다 우편함 모양이 다릅니다. / 어떤 종류인지 알아야 열 수 있는 방법을 말씀드릴 수 있습니다.
- 열쇠로 여는 실린더형
- 번호를 맞춰 여는 다이얼형
- 도어락처럼 번호판이 달린 형
- 걸쇠에 자물쇠를 따로 건 형
사물함도 비슷합니다. / 열쇠형인지 번호형인지만 알아도 전화로 설명하기가 훨씬 쉬워집니다.

# 열쇠를 잃어버렸을 때 먼저 찾아볼 곳
우편함 열쇠는 현관 열쇠와 따로 달려 있지 않은 경우가 많습니다. / 서랍이나 신발장, 이사 올 때 받은 봉투를 먼저 확인해 보세요.
건물 관리하는 분이나 집주인에게 여분이 있는지 물어보는 것도 방법입니다. / 이전에 살던 분이 우편함 열쇠를 두고 갔을 수도 있습니다.
그래도 없다면 우편함 자체를 열어야 합니다. / 열고 난 뒤에는 새 열쇠를 만드는 것까지 같이 정리할 수 있습니다.

# 다이얼 번호를 잊었을 때
번호를 맞춰 여는 우편함은 번호를 잊으면 열 수 없습니다. / 처음 받은 번호 안내문이 있는지 먼저 찾아보세요.
번호를 하나씩 돌려 보면서 감을 찾는 분도 있는데, 너무 오래 매달리면 번호판이 상할 수 있습니다. / 서너 번 해 보고 안 되면 멈추는 것이 좋습니다.
번호형 잠금은 열고 난 뒤에 새 번호로 다시 맞춰 둘 수 있습니다. / 이때는 기억하기 쉬운 번호를 가족과 함께 정해 두세요.
@ 우만동 우편함 번호 잠금 점검

# 억지로 열려고 하지 마세요
우편함 문을 도구로 비틀어 열면 문이 휘어서 다시 잠기지 않습니다. / 우편함은 건물 공용 시설인 경우가 많아 상하면 문제가 커질 수 있습니다.
드라이버로 구멍을 헤집거나 열쇠가 아닌 물건을 억지로 밀어 넣는 것도 피해 주세요. / 잠금 부품이 안에서 걸리면 오히려 열기 어려워집니다.
열쇠가 구멍에서 부러지면 작업이 더 복잡해집니다. / 열쇠가 뻑뻑하면 더 돌리지 말고 그대로 두고 연락 주세요.

# 이런 상황에서 출장열쇠를 부릅니다
혼자 해결하려고 오래 붙잡고 있지 않는 편이 낫습니다. / 아래 같은 경우라면 연락 주세요.
이사 와서 열쇠를 못 받았는데 우편물이 계속 쌓이는 경우가 있습니다. / 우편함 열쇠를 새로 맞추는 것까지 도와드립니다.
사물함 열쇠를 잃어버려 안에 든 물건을 못 꺼내는 경우도 있습니다. / 사물함 주인이 맞는지 확인한 뒤 작업합니다.
열쇠가 안 돌아가거나 구멍에서 부러진 경우도 있습니다. / 이때는 더 힘주지 말고 사진을 먼저 보내 주세요.

# 우만동 위치는 이렇게 알려주세요
우만동은 원룸과 다세대가 골목마다 이어져 있어 위치를 정확히 알려 주시는 것이 중요합니다. / 건물 이름이나 주소, 가까운 큰길을 같이 말씀해 주세요.
- 건물 이름 또는 주소와 호수
- 우편함인지 사물함인지 보관함인지
- 잠금 방식 (열쇠형, 다이얼형, 번호판형)
- 열쇠를 잃어버렸는지, 있는데 안 돌아가는지
- 건물 공용 우편함인지, 우리 집 전용인지
우편함 사진을 문자로 보내 주시면 맞는 장비를 챙기기 좋습니다. / 아주대 쪽과 우만동 어디든 출동합니다.

# 도착하면 주인이 맞는지 먼저 확인합니다
남의 우편물이 들어 있는 곳이라 주인이 맞는지 확인하는 것이 먼저입니다. / 신분증 주소, 주소가 나온 우편물, 임대차 계약서, 관리사무소 확인 중 하나면 됩니다.
자기 호수 우편함이라는 것이 확인되어야 작업할 수 있습니다. / 번거로우실 수 있지만 이웃의 우편물을 지키기 위한 절차입니다.
@ 우만동 24시 출장열쇠 신분 확인

# 공용 우편함은 관리하는 분께 알려 둡니다
건물에 우편함이 한꺼번에 설치된 경우에는 다른 집 우편함과 같은 구조입니다. / 하나를 열 때 다른 우편함이 상하지 않게 조심해서 작업합니다.
공용 설비라서 필요하면 건물 관리하는 분께 먼저 알려 드리는 것이 좋습니다. / 나중에 열쇠를 새로 만들어도 관리하는 분이 알고 있으면 정리가 쉽습니다.
원룸 건물이라면 집주인에게 간단히 문자를 남겨 두시길 권합니다. / 우편함이 상하지 않았다는 것도 사진으로 남겨 두면 좋습니다.

# 비용은 작업 전에 말씀드립니다
우편함 종류와 잠금 상태를 보고 비용을 먼저 안내해 드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 작업 후에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭤봅니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 난 뒤에는 새 열쇠를 만듭니다
우편함이 열리면 잠금 부품이 다시 잘 작동하는지 확인합니다. / 열쇠를 새로 만들거나 번호를 새로 맞추는 일까지 같이 진행합니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 부품이 너무 닳았다면 그때 [도어락 교체](doorlock-replace.html)처럼 부품을 바꾸는 방법을 말씀드립니다.
여분 열쇠는 한 개 더 만들어 따로 보관하시길 권합니다. / 열쇠를 하나만 두면 잃어버렸을 때 같은 일이 다시 생깁니다.

# 우편함과 사물함 오래 쓰는 관리법
작은 열쇠라 소홀하기 쉽지만 한번 문제가 생기면 번거롭습니다. / 아래 정도만 해 두셔도 도움이 됩니다.
- 우편함 열쇠를 현관 열쇠고리에 같이 달아 두기
- 여분 열쇠를 따로 한 개 보관하기
- 번호형은 번호를 가족이 같이 아는 곳에 기록해 두기
- 열쇠가 뻑뻑하면 억지로 돌리지 말고 점검 받기
- 이사 갈 때 열쇠를 다음 사람에게 넘기거나 관리하는 분께 반납하기
습한 날이 이어지면 우편함 안쪽 녹이 생기기도 합니다. / 잠금 구멍에 먼지가 쌓이지 않게 가끔 닦아 두세요.
문 여는 방식은 [현관문 개문](door-open.html) 페이지에도 자세히 적어 두었습니다. / 우편함은 구조가 달라 상황에 맞게 진행합니다.

# 우만동 말고 수원 어디든 갑니다
우만동 바로 옆 인계동, 매탄동, 원천동 쪽도 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

? 다른 집 우편함도 열어 주시나요? | 아닙니다. 본인 호수라는 것이 확인되어야 작업합니다. 신분증이나 주소가 나온 우편물을 준비해 주세요.

? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 밤늦게나 새벽에도 연락해도 되나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
