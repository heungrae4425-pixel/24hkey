# 번호판이 어렵다고 느끼시는 어르신들께
우만동에서 수원역 쪽으로 장 보러 다니시는 어르신들은 손에 짐을 들고 현관 앞에서 번호를 누르는 일이 잦습니다. / 눈이 침침하거나 손끝 감각이 둔해지면 같은 번호도 자꾸 틀리게 됩니다.
도어락이 어렵다기보다 처음 설정이 젊은 사람 기준으로 맞춰져 있는 경우가 많습니다. / 소리, 불빛, 번호 구성만 바꿔도 훨씬 쉽게 쓰실 수 있습니다.
이 글은 어르신이 눌러 쓰기 편하게 맞추는 방법과 안 열릴 때 [수원 출장열쇠](suwon.html)를 부르는 요령을 정리했습니다.
@ 우만동 어르신 도어락 번호판 사용

# 안내음 크기가 맞아야 안심이 됩니다
설정을 바꾼 뒤에는 어르신이 직접 두세 번 눌러 보시고 편한지 말씀해 주시게 하세요. / 소리가 편하다는 확인이 되어야 설정이 끝난 것입니다.
번호를 누를 때 나는 삑 소리가 너무 작으면 눌렸는지 안 눌렸는지 알 수 없어 같은 숫자를 두 번 누르게 됩니다. / 반대로 소리가 너무 크면 밤에 이웃에게 신경이 쓰입니다.
많은 제품에는 소리 크기를 줄이거나 키우는 설정이 있습니다. / 제품마다 방법이 달라서 설명서를 보거나 모델을 알려주시면 안내해 드립니다.
귀가 어두운 분은 소리보다 불빛이 보이는 것이 편할 수 있어 소리와 불빛을 함께 확인해 보세요.

# 번호판 불빛이 잘 보여야 합니다
번호판 위에 붙은 오래된 스티커나 필름이 반사되어 숫자가 가려지는 일도 있습니다. / 이런 경우 떼어 내기만 해도 훨씬 잘 보입니다.
저녁이나 비 오는 날 번호판이 잘 안 보이면 어르신이 헤매시게 됩니다. / 번호판 표면에 쌓인 먼지나 기름기를 마른 천으로 닦아만 줘도 훨씬 선명해집니다.
불빛이 약해지는 것은 배터리가 약해졌다는 신호일 수 있습니다. / 번호판이 어두워졌다면 배터리를 전부 새것으로 바꿔 주세요.
현관 앞 조명이 어두운 경우 번호판 위치를 손으로 더듬어 찾기 쉽게 작은 스티커를 붙여 두는 방법도 있습니다.

# 번호는 짧고 규칙적으로
자릿수가 너무 길면 외우기도 어렵고 누르는 도중 틀리기 쉽습니다. / 안전을 해치지 않는 범위에서 기억하기 편한 길이로 정하세요.
숫자 배열이 한쪽으로 몰리지 않으면 기억하기 어려워서 규칙이 있는 번호를 쓰고 싶어 하시지만, 지나치게 쉬운 번호는 남도 알아맞히기 쉽습니다. / 어르신이 오래 기억하는 숫자를 섞어 정하는 것이 좋습니다.
번호를 바꿨으면 가족에게 꼭 알리고, 종이에 적은 번호는 집 안 안전한 곳에 보관해 주세요.

# 누를 때 생기는 흔한 실수
어르신 손가락 끝이 번호판보다 넓은 느낌이 든다면 손톱 쪽이 아닌 손가락 배로 눌러 보시게 안내해 주세요. / 한 자리씩 천천히 눌러야 정확합니다.
- 손가락 끝이 번호판 옆 칸에 걸려 다른 숫자가 눌린다
- 번호를 누르다 중간에 멈춰 다시 처음부터 눌러야 한다
- 마지막에 눌러야 하는 확인 키를 안 누른다
- 손이 젖었거나 장갑을 낀 채로 눌러 인식이 안 된다
이런 실수는 어르신 탓이 아닙니다. / 제품 설정이 맞지 않은 것일 뿐이니 천천히 한 자리씩 눌러 보시게 안내해 주세요.
@ 수원 우만동 도어락 안내음 설정 확인

# 지문이나 카드, 어르신께 맞을까
카드를 쓰신다면 지갑보다 열쇠고리에 달아 한곳에 두는 습관이 중요합니다. / 어르신 목걸이나 가방 고리에 달아 두는 방식도 있습니다.
지문을 등록할 때는 손가락 한두 개가 아니라 여러 개를 등록해 두세요. / 한 손이 다치거나 젖어 있어도 다른 손가락으로 열 수 있습니다.
번호 대신 카드나 지문을 쓰면 편해지는 분도 있고 오히려 불편해지는 분도 있습니다. / 지문은 손이 건조하면 잘 안 읽히고, 카드는 잃어버리기 쉽습니다.
처음에는 번호를 기본으로 두고 카드나 지문을 보조로 쓰는 방식이 안정적입니다. / 한 가지 방법이 안 될 때 다른 방법으로 열 수 있기 때문입니다.
바꾸고 싶으시면 [도어락 설치](doorlock-install.html)에서 문 두께와 보조키를 확인하고 맞는 제품을 안내해 드립니다.

# 문이 안 열릴 때 어르신이 하실 일
번호가 안 맞거나 문이 안 열리면 계속 누르지 말고 한 번 멈추세요. / 여러 번 틀리면 도어락이 잠시 입력을 막아 더 불안해지실 수 있습니다.
가까운 이웃이나 경비실에 도움을 청해 편하게 앉아 계시는 것이 먼저입니다. / 날이 춥거나 더울 때는 오래 서 계시지 않도록 하세요.
자녀분이 계시면 전화해서 번호판 상태를 알려주면 빠르게 정리됩니다.

# 전화하실 때 이렇게 말씀하세요
복잡하게 설명하지 않으셔도 됩니다. / 아래 정도만 알려주시면 출동 준비를 합니다.
- 우만동이라는 말과 아파트나 빌라 이름, 호수
- 번호판이 꺼졌는지 켜졌는지
- 소리가 나는지 안 나는지
- 어르신 혼자 계신지, 옆에 가족이나 이웃이 계신지
통화가 어려우시면 자녀나 이웃이 대신 전화하셔도 됩니다.

# 신분 확인은 꼭 거칩니다
어르신 댁이라도 사시는 분 확인은 필요합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 경비실이나 관리사무소, 이웃의 도움을 받아 세대 확인을 하실 수 있습니다. / 확인이 어려우면 작업할 수 없으니 미리 안내해 드립니다.

# 비용 안내와 못 열 때의 원칙
문 열기 전에 상태를 보고 비용을 먼저 말씀드립니다. / 천천히 들으시고 괜찮을 때만 시작합니다.
문을 못 열면 비용은 받지 않습니다. / 부품을 교체해야 하면 바꾸기 전에 따로 여쭙습니다.
진행 순서는 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html)에 적어 두었습니다.
@ 우만동 출장열쇠 어르신 댁 도어락 설정

# 열고 난 뒤 같이 맞추는 설정
문이 열리면 소리 크기, 번호 길이, 배터리 상태를 어르신 옆에서 함께 확인합니다. / 새로 정한 번호는 천천히 눌러 보며 익숙해지실 때까지 같이 연습합니다.
도어락이 너무 오래돼 설정이 안 되거나 자주 말썽이면 [도어락 수리](doorlock-repair.html)를 먼저 권하고, 필요할 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 평소에 해두면 좋은 준비
- 배터리는 해가 바뀔 때 한꺼번에 교체
- 경고음이 나면 그날 바로 교체
- 번호를 쓴 종이는 현관 근처 눈에 안 띄는 곳에 두기
- 이웃에게 연락처를 알려 두기
- 비상시 전화할 번호를 큰 글씨로 붙이기
작은 준비가 갑자기 문 앞에서 막히는 일을 줄여 줍니다.

# 우만동 말고 수원 어디든
우만동 가까운 인계동, 매탄동, 권선동, 세류동도 다닙니다. / 수원 전 지역 24시간 출동합니다.
다니는 동네는 [수원시 출장열쇠](suwon.html)에, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
