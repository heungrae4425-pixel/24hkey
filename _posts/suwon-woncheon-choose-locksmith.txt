# 원천동에서 열쇠집을 찾는 분들께
원천동은 아파트와 상가, 학교와 대학가가 어우러진 곳입니다. / 문이 안 열려 급하게 검색하다 보면 어느 곳에 연락할지 망설여집니다.
이 글은 원천동에서 열쇠집이나 출장열쇠를 고를 때 어떤 점을 보면 좋은지 적었습니다. / 급하더라도 이 몇 가지만 확인하면 훨씬 안심하고 맡길 수 있습니다.
@ 원천동 열쇠집 출장열쇠 고르는 법

# 급할수록 확인할 것이 있습니다
문 앞에 서 있으면 아무 곳에나 연락하고 싶은 마음이 듭니다. / 하지만 잠깐만 확인해도 나중에 곤란해지는 일을 피할 수 있습니다.
통화 한 번으로 많은 것을 알 수 있으니 전화로 물어보는 습관이 중요합니다.

# 전화로 먼저 물어보면 좋은 것
- 지금 위치까지 대략 얼마나 걸리는지
- 비용은 문 열기 전에 알려주는지
- 문을 못 열면 어떻게 되는지
- 도어락이 상하지 않게 여는지
이 네 가지에 막힘없이 대답하는 곳이면 믿고 맡기기에 좋습니다.

# 비용을 말하지 않는 곳은 조심하세요
전화로 상황을 설명했는데도 비용에 대한 말이 없다면 한 번 더 물어보세요. / 문을 열고 난 뒤에 말이 달라지는 경우가 가장 흔한 불만입니다.
저희는 문과 도어락 상태를 본 뒤 열기 전에 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 아니면 그냥 돌아갑니다.
@ 원천동 출장열쇠 비용 안내 먼저

# 못 열면 어떻게 하는지도 물어보세요
방문하고도 문을 못 열었을 때 출장 비용을 받는지는 곳마다 다릅니다. / 미리 물어보면 나중에 서로 곤란한 일이 없습니다.
24시출장열쇠는 끝내 못 열면 비용을 받지 않습니다. / 이 점은 전화로도 분명하게 말씀드립니다.

# 문을 상하게 하는 방법을 쓰는지
문과 도어락을 부수는 방식으로 여는 곳도 있습니다. / 급하다고 이런 방법에 동의하면 열고 난 뒤에 교체 비용이 따로 듭니다.
덜 상하는 방법부터 차례로 해보고, 정말 필요할 때만 부품 교체를 말씀드리는 곳이 좋습니다. / 부품을 바꾸기 전에 먼저 물어보는지도 보세요.

# 신분 확인을 하는 곳이 믿을 만합니다
문을 열어 주는 일이라 사시는 분인지 확인하는 절차가 있어야 정상입니다. / 아무 확인 없이 열어 주겠다는 곳은 오히려 조심해야 합니다.
저희는 신분증 주소, 주소가 나온 우편물, 관리하는 분 확인 중 하나를 요청합니다. / 이웃과 손님 모두를 위한 절차입니다.
@ 원천동 신분 확인 후 문 열기

# 후기와 사진은 이렇게 보세요
광고처럼 보이는 글보다 구체적인 설명이 있는 글이 믿을 만합니다. / 어떤 문을 어떻게 열었는지 적힌 곳이 대체로 실제 작업을 하는 곳입니다.
이 블로그 글들도 상황과 순서, 비용 안내 방식을 구체적으로 적어 두었습니다. / 판단은 읽어 보시고 직접 하시면 됩니다.

# 전화번호와 상호가 분명한지
상호와 전화번호가 분명히 적혀 있는지 확인하세요. / 통화할 때 가게 이름을 먼저 말하는지도 중요한 단서입니다.
24시출장열쇠는 전화를 받을 때도, 문자를 보낼 때도 상호를 분명히 밝힙니다. / 번호는 010-3664-5455입니다.

# 도착한 뒤 확인할 것
- 전화로 들은 설명과 같은 내용인지
- 비용을 작업 전에 말해 주는지
- 사시는 분 확인을 하는지
- 도어락 상태를 보고 필요한 부분만 이야기하는지
이 중에서 하나라도 어긋나면 작업을 멈추고 한 번 더 물어보셔도 됩니다.

# 열고 난 뒤에도 확인하세요
문이 열린 뒤 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새것으로 바꿨는지도 함께 봅니다.
고쳐서 쓸 수 있으면 교체를 권하지 않습니다. / 먼저 [도어락 수리](doorlock-repair.html)로 해결해 보고, 정말 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 원천동 근처 대학가와 주거지 모두 갑니다
원천동 아파트와 상가, 그리고 근처 주택가까지 모두 출동합니다. / 대학가 원룸이나 하숙집, 오피스텔 문도 문제없이 갑니다.
위치가 애매하면 가까운 큰길이나 건물 이름을 알려주세요. / 헤매지 않고 도착할 수 있도록 안내해 드립니다.

# 원천동 말고 수원 전 지역 갑니다
영통, 광교, 인계동, 권선동, 화서동까지 수원 어디든 다닙니다. / 수원 안이면 24시간 출동합니다.
전체 안내는 [수원 출장열쇠](suwon.html)에 있고, 서울과 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 이용 절차는 [이용안내](guide.html)에도 적어 두었습니다.
