# 집을 비운 사이 누군가 들어와야 할 때
원천동에서 맞벌이를 하시거나 부모님 댁을 돌보시다 보면 내가 없는 시간에 다른 사람이 집에 들어와야 할 일이 생깁니다. / 영통역이나 광교중앙역 쪽으로 출근하는 낮 시간에 가사도우미, 방문 돌봄 선생님, 수리 기사님이 오는 경우가 대표적입니다.
열쇠를 복사해서 건네기엔 찜찜하고, 내 번호를 그대로 알려주기엔 더 불안합니다. / 그래서 도어락의 임시 번호 기능을 알아 두면 마음이 훨씬 편해집니다.
이 글은 임시 비밀번호를 만들고 거두는 방법과 문제가 생겼을 때 [수원 출장열쇠](suwon.html)를 부르는 요령을 정리했습니다.
@ 원천동 임시 비밀번호 도어락 설정

# 내 번호를 그대로 알려주면 생기는 일
예를 들어 한 달 전 인테리어 기사님에게 알려준 번호를 그대로 쓰고 있는 집을 생각해 보세요. / 기사님이 무슨 마음이 있어서가 아니라도, 번호를 아는 사람이 계속 늘어나는 구조 자체가 불안 요소입니다.
한 번 알려준 번호는 상대가 누구에게 말했는지 확인할 방법이 없습니다. / 일이 끝난 뒤에도 같은 번호가 계속 쓰이면 집 주인은 누가 들어올 수 있는지 알 수가 없습니다.
가족과 함께 쓰는 번호라면 바꾸는 일도 번거롭습니다. / 가족 모두에게 다시 알려야 하니 미루다가 그대로 쓰는 집이 많습니다.
그래서 손님이나 도우미에게는 처음부터 가족 번호와 분리된 번호를 주는 편이 낫습니다.

# 도어락마다 임시 번호 기능이 다릅니다
제품에 따라 한 번만 쓸 수 있는 번호, 정해진 시간 동안만 열리는 번호, 별도 사용자 번호를 추가하는 방식이 있습니다. / 모든 제품에 시간 제한 기능이 있는 것은 아닙니다.
- 사용자 번호를 하나 더 추가했다가 나중에 삭제하는 방식
- 한 번 쓰면 자동으로 사라지는 일회용 번호
- 앱으로 기간을 정해 두는 방식 (연동 제품에 한함)
내 도어락이 어떤 방식인지 모르겠다면 안쪽 설명서나 제품 이름을 확인해 보세요. / 사진을 문자로 보내주시면 어떤 기능이 있는지 같이 봐드릴 수 있습니다.

# 도우미 선생님께 번호를 전할 때의 순서
처음 몇 번은 방문 시간에 맞춰 도착 연락을 받는 것도 좋습니다. / 서로 얼굴이 익숙해지면 번호를 맡기는 부담도 줄어듭니다.
방문하시는 분이 번호를 다른 곳에 적어 두지 않도록 부탁드리는 것도 예의 바른 방법입니다. / 문자를 지우도록 안내하면 안심하고 맡길 수 있습니다.
집 안에 귀중품이 있다면 방문 전에 정리해 두는 것이 서로에게 편합니다. / 믿음과 관리는 따로 가는 일입니다.
번호는 말로 전달하지 말고 문자로 남기는 편이 정확합니다. / 구두로 부르면 숫자를 잘못 듣는 일이 의외로 많습니다.
처음 방문하는 날에는 가능하면 집에 있다가 직접 문 앞에서 번호를 한 번 눌러 보게 하세요. / 문이 제대로 열리는지, 나갈 때 잠기는지까지 같이 확인하면 이후에 전화 올 일이 줄어듭니다.
방문이 끝난 날에는 그날 번호를 삭제하거나 바꿉니다. / 정기적으로 오는 분이라도 일정 기간이 지나면 한 번씩 번호를 갈아 두면 부담이 없습니다.

# 이렇게 하면 헷갈립니다
같은 번호를 여러 사람에게 돌려 쓰는 것입니다. / 누가 언제 들어왔는지 알 수 없고, 한 명이 그만둘 때 모두에게 다시 알려야 합니다.
생일이나 전화번호 뒷자리처럼 쉬운 숫자도 피해 주세요. / 임시 번호라도 누구나 짐작할 수 있는 숫자는 의미가 없습니다.
@ 수원 원천동 방문 도우미 도어락 번호 관리

# 아이나 어르신이 집에 있을 때 특히 신경 쓸 것
아이나 거동이 불편한 어르신이 집에 계시면 낯선 사람이 번호를 눌러 들어오는 상황이 놀라울 수 있습니다. / 방문 시간을 미리 알려드리고 도착 연락을 먼저 받도록 약속해 두세요.
돌봄 인력이 오는 집이라면 안에 계신 분이 문을 열어 주기 어려울 때를 대비해야 합니다. / 이때 임시 번호가 있으면 어르신이 직접 문을 열러 나올 필요가 없어 편합니다.
다만 안쪽 보조키나 걸쇠를 걸어 두면 바깥에서 번호를 눌러도 열리지 않습니다. / 방문 시간에는 보조키를 풀어 두는 것이 좋습니다.

# 번호가 안 열린다는 전화를 받았을 때
도우미나 손님에게서 문이 안 열린다는 연락이 오면 먼저 번호판이 켜지는지 물어보세요. / 불이 안 들어오면 배터리, 소리는 나는데 안 열리면 보조키나 걸쇠가 원인일 수 있습니다.
번호를 다시 한 번 천천히 눌러 보게 하고, 안 되면 몇 번 시도했는지도 확인합니다. / 여러 번 틀리면 도어락이 잠시 입력을 막을 수 있습니다.
집주인이 외출 중이라 직접 확인이 어렵다면 상황을 정리해 전화 주세요. / 이럴 때는 문을 열 수 있는 사람이 본인이 맞는지 확인이 필요합니다.

# 주인이 없을 때 문을 열어야 한다면
집주인이 아닌 사람이 문 앞에서 전화를 주시는 경우에는 사시는 분이 맞는지부터 확인합니다. / 집주인과 통화하거나, 신분증, 우편물, 관리사무소 확인 중 가능한 방법을 안내해 드립니다.
도우미라고 말씀하셔도 집주인 확인 없이 문을 열어 드리지는 않습니다. / 불편하시더라도 집을 지키기 위한 절차이니 이해 부탁드립니다.
확인이 끝나면 비파손 방법으로 시작하고, 비용은 문 열기 전에 먼저 말씀드립니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
문 여는 과정은 [현관문 개문](door-open.html) 페이지에 있습니다.

# 임시 번호를 정리하는 습관
- 방문 날짜와 번호를 메모해 두기
- 일이 끝나면 그날 번호를 바로 삭제하기
- 정기 방문이라면 한 달에 한 번쯤 번호 바꾸기
- 가족 번호와 손님 번호는 항상 분리하기
- 번호를 바꿨으면 가족 대화방에 알리기
이 정도만 해도 열쇠를 여러 개 복사하는 것보다 훨씬 관리하기 쉽습니다. / 잃어버릴 열쇠가 없다는 것도 큰 장점입니다.

# 작업 뒤에 같이 확인하는 것
문이 열리고 나면 새 번호를 등록하고 기존 번호를 지우는 일까지 함께 해드립니다. / 배터리가 약하면 이 자리에서 바꾸는 편이 낫습니다.
도어락이 너무 오래돼 임시 번호 기능이 없다면 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html)를 필요한 만큼만 안내합니다. / 고쳐서 쓸 수 있다면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드립니다.
@ 수원 원천동 도어락 번호 삭제 후 점검

# 원천동 말고 수원 어디든
원천동 가까운 영통동, 매탄동, 망포동, 광교동도 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에, 서울과 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
