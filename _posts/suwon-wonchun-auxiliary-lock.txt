# 번호는 맞는데 문이 꿈쩍도 하지 않습니다
원천동 집 앞에서 도어락 번호를 눌렀는데 삑 소리는 나도 문이 안 열립니다. / 이런 경우 안쪽 보조키가 잠겨 있을 가능성을 의심해야 합니다.
이 글은 수원 영통구 원천동 쪽에서 보조키 때문에 문이 안 열려 곤란한 분들을 위해 정리했습니다. / 대학가 주변 원룸이나 주택에서도 자주 있는 일입니다.
@ 원천동 보조키 잠김 출장열쇠 현관문 개문

# 보조키가 무엇인지부터
현관문에는 도어락 말고도 위쪽이나 아래쪽에 안쪽에서만 돌리는 잠금장치가 하나 더 있는 경우가 많습니다. / 이것을 보조키라고 부릅니다.
안에서 돌려 잠가 두면 밖에서 번호를 눌러도 문이 열리지 않습니다. / 도어락이 문제가 아니라 보조키가 걸려 있는 것입니다.

# 어떻게 잠기게 되는지
밖에서 보조키를 잠글 수는 없지만, 안에서 잠근 채 문을 닫고 나가면 같은 상황이 됩니다. / 급하게 나가다 손이 걸려 돌아간 경우도 있습니다.
같이 사는 가족이 이미 잠가 둔 줄 모르고 들어오다 겪는 일도 많습니다. / 먼저 가족에게 집에 있는지 연락해 보세요.

# 먼저 해볼 것
집에 누가 있으면 안에서 풀어 달라고 부탁하는 것이 가장 빠릅니다. / 소리가 들리는지 문에 귀를 대고 확인해 봅니다.
아무도 없다면 문을 살짝 밀면서 손잡이를 돌려 보세요. / 문틀이 처져 걸쇠가 걸리는 경우는 이렇게 열리기도 합니다.
이것으로 안 되면 힘으로 밀거나 당기지 말고 전화로 상태를 말씀해 주세요.

# 하지 말아야 할 행동
문을 세게 당기거나 어깨로 밀면 보조키 걸쇠가 문틀 쪽으로 더 깊게 물립니다. / 그러면 열기가 훨씬 어려워집니다.
카드나 칼을 문틈에 넣어 벌리는 것도 문틀이 파이고 도어락이 상하는 원인입니다. / 급해도 힘을 쓰는 것은 피하세요.
@ 수원 원천동 도어락 보조키 문 열기

# 전화하실 때 알려주세요
- 원천동 어디쯤인지, 가까운 학교나 큰 건물
- 번호를 누르면 어떤 소리가 나는지
- 안에 누가 있는지, 아이나 반려동물은 없는지
- 문이 아래위로 흔들리는지, 걸쇠 소리가 나는지
도어락과 보조키 사진을 문자로 보내주시면 필요한 장비를 챙겨 갑니다.

# 문을 상하지 않게 여는 방법
보조키는 위치와 종류에 따라 열 수 있는 방법이 다릅니다. / 문과 장치가 상하지 않는 쪽부터 차례로 해봅니다.
어떤 방식으로 하는지는 현장에서 문을 보고 먼저 말씀드립니다. / 방법은 [현관문 개문](door-open.html)에서도 설명합니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 여쭤봅니다.

# 사시는 분인지 확인합니다
문을 여는 일이라 신분증, 주소가 나온 우편물, 관리사무소 확인 중 하나를 부탁드립니다. / 번거로워도 안전을 위한 절차입니다.
확인이 어렵다면 작업을 진행하지 않으니 미리 챙겨 두면 좋습니다.

# 비용은 작업 전에 먼저
문 상태를 보고 얼마인지 먼저 말씀드리고, 괜찮다고 하실 때 시작합니다. / 마음에 안 드시면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다. 자세한 진행은 [이용안내](guide.html)에 적어 두었습니다.

# 열린 뒤에 확인하는 것
보조키가 잘 돌아가고 걸리지 않는지 확인합니다. / 걸쇠가 문틀에 부딪혀 뻑뻑하면 위치를 손봅니다.
문이 잘 닫히는지, 도어락과 보조키가 서로 간섭하지 않는지도 같이 봅니다. / 이상이 있으면 [도어락 수리](doorlock-repair.html)로 이어서 점검할 수 있습니다.

# 보조키를 안전하게 쓰는 습관
밤에 잘 때만 잠그고, 나갈 때는 풀고 나가는 습관을 들이세요. / 가족과 정한 규칙을 현관 안쪽에 적어 두는 것도 방법입니다.
- 나가기 전에 보조키 위치를 한 번 손으로 확인
- 아이가 있는 집은 손이 닿지 않는 높이로 점검
- 걸쇠가 뻑뻑하면 미리 손보기
작은 습관이 문 앞에서 막히는 일을 줄여 줍니다.

# 도어락 교체가 필요한 경우
보조키와 도어락이 함께 낡아 자주 걸린다면 문 전체를 점검해 보는 편이 낫습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
교체가 필요하면 [도어락 교체](doorlock-replace.html)에서 안내하는 순서로 진행합니다.
@ 원천동 24시 출장열쇠 010-3664-5455

# 원천동 말고 수원 어디든 갑니다
영통, 광교, 권선, 장안까지 수원 전 지역을 24시간 다닙니다. / 수원에서 다니는 동네는 [수원 출장 지역](suwon.html)에 정리해 두었습니다.
수원 밖은 [출장 지역](area.html) 지도에서 확인하세요.
