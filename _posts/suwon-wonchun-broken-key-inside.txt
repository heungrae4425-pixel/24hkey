# 원천동에서 열쇠가 부러졌을 때
원천동은 아주대 쪽 학교 주변과 아파트, 빌라, 작은 상가가 이어지는 동네입니다. / 열쇠를 쓰는 철문, 방문, 상가 출입문이 아직 많이 남아 있는 곳이기도 합니다.
열쇠가 돌아가지 않아 힘을 주다 보면 어느 순간 딱 소리와 함께 열쇠가 부러집니다. / 반 토막이 구멍에 박혀 있으면 눈앞이 캄캄해지지만 순서대로 하면 대부분 해결됩니다.
이 글은 원천동에서 열쇠가 부러졌을 때 지금 할 일과 하지 말 일, [수원 출장열쇠](suwon.html)의 진행 순서를 정리했습니다. / 지금 문 앞이라면 바로 다음 항목부터 보셔도 됩니다.
@ 원천동 출장열쇠 부러진 열쇠 제거

# 지금 바로 멈추세요
열쇠가 부러졌다면 더 이상 문을 건드리지 않는 것이 가장 중요합니다. / 박힌 조각을 빼겠다고 이것저것 넣어 보면 구멍 안이 더 상합니다.
부러진 조각이 구멍 밖으로 조금이라도 나와 있다면 그대로 두세요. / 손톱이나 도구로 건드리면 안쪽으로 밀려 들어갈 수 있습니다.
어느 쪽이 부러졌는지, 조각이 얼마나 보이는지만 사진으로 남겨 두세요. / 전화로 알려주시면 챙겨 갈 장비를 정하기 쉬워집니다.

# 부러지는 흔한 상황
- 안 돌아가는 열쇠에 힘을 주다 부러진 경우
- 오래돼 가늘어진 열쇠를 돌리다 부러진 경우
- 열쇠를 꽂은 채 문을 세게 당기다 부러진 경우
- 겨울에 얼어붙은 구멍에 힘을 준 경우
부러지기 전에는 거의 항상 이상 신호가 있습니다. / 평소에 뻑뻑하거나 돌릴 때 걸리는 느낌이 있었다면 그때 점검하는 편이 낫습니다.
열쇠 몸통에 가는 금이나 휨이 보이면 부러지기 직전이라고 보시면 됩니다. / 그런 열쇠는 새로 복사해 두는 쪽이 좋습니다.

# 집에서 하면 안 되는 것
순간접착제로 부러진 조각을 붙이려는 분이 있는데, 접착제가 구멍 안으로 흘러 들어가면 구멍 전체를 바꿔야 할 수 있습니다. / 이것이 가장 피해야 할 행동입니다.
핀셋이나 바늘, 철사로 조각을 빼려는 시도도 조각이 더 깊이 들어가는 경우가 많습니다. / 열쇠 구멍 안은 아주 정밀해서 작은 힘에도 핀이 휩니다.
망치로 두드리거나 드라이버로 구멍을 비트는 것은 문 전체를 상하게 합니다. / 억지로 열려다 문 손상으로 번지는 일은 피하셔야 합니다.

# 조각이 보일 때와 안 보일 때
조각이 구멍 밖으로 보이면 전용 도구로 잡아서 조심스럽게 뺄 수 있는 경우가 많습니다. / 이때는 구멍과 문을 그대로 두고 조각만 빼는 것이 목표입니다.
조각이 안쪽 깊이 들어가 보이지 않으면 방법이 달라집니다. / 구멍 일부를 분해해서 조각을 꺼내는 방법을 먼저 말씀드립니다.
열쇠 구멍이 이미 상했다면 구멍만 새로 바꾸는 방법도 있습니다. / 문 전체를 바꾸지 않아도 되는 경우가 대부분입니다.
@ 수원 원천동 열쇠 구멍 분해 작업

# 문이 잠긴 채 열쇠가 부러졌다면
문이 잠긴 상태에서 열쇠가 부러지면 열쇠가 있어도 못 여는 상황이 됩니다. / 안쪽에서 열 수 있는지, 도어락이 같이 달려 있는지 먼저 확인합니다.
도어락이 같이 있다면 번호나 카드로 열 수 있을 수 있습니다. / 상황을 알려주시면 방법을 말씀드립니다. 자세한 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.
열쇠로만 여는 문이라면 열쇠 구멍을 상하지 않게 풀어서 여는 순서로 진행합니다. / 이 방법이 어려운 문은 현장에서 다시 말씀드립니다.

# 원천동에서 부르시면 이렇게 진행합니다
도착해서 조각 상태와 구멍 상태를 먼저 확인합니다. / 가장 덜 상하는 방법부터 시도하고 방법이 바뀌면 그 전에 말씀드립니다.
조각을 빼고 나면 구멍이 정상인지 새 열쇠로 돌려 보며 확인합니다. / 구멍이 상했다면 그 자리에서 교체 여부를 상의합니다.
새 열쇠를 맞춰야 하면 원본을 기준으로 필요한 개수만 맞춥니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 사시는 분 확인은 먼저 합니다
문을 열거나 구멍을 분해하는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로워도 이웃과 집 주인 모두를 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 시작하기 전에 말씀드립니다
조각 위치와 구멍 상태, 문 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 필요 없는 교체는 권하지 않습니다.
@ 24시출장열쇠 원천동 열쇠 구멍 교체

# 작업을 마친 뒤 확인
새 열쇠나 구멍이 부드럽게 돌아가는지 여러 번 확인합니다. / 안쪽 잠금과 바깥 열쇠가 같이 맞는지도 봅니다.
부러진 열쇠의 원본이 남아 있다면 홈 모양을 비교해서 새 열쇠를 맞춥니다. / 원본이 없어도 구멍 기준으로 맞출 수 있는 경우가 많습니다.
같은 일이 반복되지 않도록 열쇠가 얼마나 닳았는지도 봐 드립니다. / 닳은 열쇠를 계속 쓰는 것이 부러짐의 가장 큰 이유입니다.

# 열쇠가 부러지지 않게 하려면
돌아가는 느낌이 뻑뻑해졌을 때가 점검할 때입니다. / 그때 구멍을 청소하거나 열쇠를 새로 맞추면 부러지는 일을 막을 수 있습니다.
열쇠를 꽂은 채 문손잡이처럼 잡고 문을 당기지 마세요. / 열쇠 머리에 힘이 쏠려 몸통이 부러지기 쉽습니다.
예비 열쇠를 집 밖의 믿을 수 있는 곳에 따로 보관해 두세요. / 부러지거나 잃어버려도 당황하지 않게 됩니다.

# 방문과 상가 철문에서도 같은 일이 생깁니다
부러진 열쇠는 현관문뿐 아니라 방문, 작은 사무실 문, 상가 철문, 사물함에서도 생깁니다. / 문 종류가 달라도 조각을 구멍 안에서 꺼내는 순서는 비슷하지만 분해 방법이 조금씩 다릅니다.
원천동 학교 주변 원룸이나 작은 가게는 열쇠를 오래 쓰는 곳이 많아 열쇠 구멍도 함께 닳아 있는 경우가 흔합니다. / 이럴 때는 조각을 빼는 김에 구멍 상태까지 함께 확인해 드립니다.
여러 문에 같은 열쇠를 쓰고 있다면 다른 문에서도 같은 일이 생길 수 있어 미리 새로 맞추는 쪽을 권해 드립니다. / 원본이 아직 있을 때가 가장 정확하게 맞출 수 있습니다.

# 원천동 말고 수원 어디든 갑니다
원천동 바로 옆 매탄동, 영통동, 광교동, 이의동 쪽도 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
수원에서 다니는 동네는 [수원 출장열쇠](suwon.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
