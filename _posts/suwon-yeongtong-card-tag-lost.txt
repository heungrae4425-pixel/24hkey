# 지갑에 있던 카드가 사라졌다면
영통동에서 영통역으로 출퇴근하는 분들은 현관 카드키를 교통카드나 사원증 옆에 넣고 다니는 일이 많습니다. / 어느 날 가방을 뒤져 봐도 카드가 보이지 않으면 가슴이 철렁합니다.
도어락 카드키, 태그, 리모컨은 작아서 잃어버리기도 쉽고 누가 주웠는지 알 수도 없습니다. / 그래서 문이 열리는 문제와 안전 문제를 같이 생각해야 합니다.
이 글은 분실 직후 순서와 등록 삭제, 문 열기, 재등록까지 한 흐름으로 적었습니다. / 지금 문 앞에 계시다면 5번부터 보셔도 됩니다. / 차분히 읽을 시간이 있다면 처음부터 보시길 권합니다.
@ 영통동 도어락 카드키 태그 분실 대처

# 가장 먼저 할 일은 잃어버린 곳 되짚기
카드가 사라진 것을 알았다면 먼저 오늘 동선을 짚어 봅니다. / 마지막으로 현관을 열었던 순간, 가방과 옷 주머니, 차 안을 차례로 찾아보세요.
카페나 편의점 계산대에 두고 온 경우도 의외로 많습니다. / 짐작되는 곳이 있으면 먼저 전화로 확인해 보는 편이 빠릅니다. / 분실물 보관 여부는 몇 시간 안에 알 수 있는 경우가 많습니다.
다만 오래 찾느라 안 열리는 문 앞에서 시간을 보내는 것은 피하세요. / 일정 시간 지나도 못 찾으면 다음 단계로 넘어가는 게 낫습니다.

# 카드 하나만 잃었다면 등록 삭제부터
많은 도어락은 카드마다 고유 번호를 등록해 두는 방식입니다. / 분실한 카드를 삭제하면 그 카드로는 더 이상 문이 열리지 않습니다.
삭제는 기능 설정 메뉴에서 이루어지는데 제품마다 방법이 다릅니다. / 설명서가 있다면 카드 삭제나 전체 초기화 항목을 찾아보세요.
카드마다 개별 삭제가 되는 제품도 있고, 전체를 지우고 남은 카드를 다시 등록하는 제품도 있습니다. / 어느 쪽인지 확인하는 것이 첫걸음입니다.

# 번호는 열리는데 카드만 없는 경우
카드를 잃었어도 비밀번호가 살아 있다면 집에는 들어갈 수 있습니다. / 이때는 급한 것이 아니니 천천히 정리하셔도 됩니다.
다만 누가 주운 카드가 우리 집 문에 쓰이는 일은 거의 없어도, 등록을 삭제해 두면 마음이 편합니다. / 안쪽에서 설정 메뉴로 들어가 분실 카드를 지워 주세요.
번호도 이참에 바꾸고 싶다면 가족에게 공유하는 일까지 같이 하세요.
@ 영통동 도어락 카드 등록 삭제 설정

# 번호도 모르고 카드도 없는 경우
이사 직후나 번호를 바꾼 직후에 카드가 없어지면 문 앞에서 완전히 막힙니다. / 이럴 땐 억지로 문을 건드리기보다 전화를 주세요.
번호를 몇 번 틀리면 도어락이 입력을 한동안 막기도 하니 서너 번에서 멈추세요. / 보조 열쇠가 있다면 열쇠로 열 수 있는지도 확인하세요.
열쇠 구멍이 있는 제품이라면 가족에게 열쇠를 가져와 달라고 부탁하는 방법도 있습니다. / 없다면 출장으로 문을 열어야 합니다.

# 태그와 카드는 방식이 다릅니다
카드는 얇은 판 모양이고 도어락 번호판 근처에 대면 읽히는 방식입니다. / 태그는 열쇠고리에 달 수 있는 작은 모양으로 같은 방식을 씁니다.
둘 다 신호를 읽는 부위에 가까이 댔을 때 열리고, 등록 방식도 비슷합니다. / 제품에 따라 등록 가능한 개수가 정해져 있습니다. / 가족이 많다면 처음부터 개수를 확인해 두는 것이 좋습니다.
리모컨은 거리가 먼 곳에서도 열 수 있지만 분실 시 위험은 더 큽니다. / 등록 삭제를 더 서둘러 주세요.

# 리모컨을 잃었다면 더 서둘러 정리
리모컨은 눌러서 문을 여는 방식이라 주운 사람이 사용법을 알면 열 수 있습니다. / 다만 같은 제품을 쓰는 집과 주소를 연결하기는 어려워 실제 위험은 낮은 편입니다.
그래도 가능한 한 빨리 해당 리모컨의 등록을 지우는 게 좋습니다. / 지우는 방법을 모르면 전화로 알려 드립니다.
등록 삭제가 안 되는 제품이라면 비밀번호나 도어락 자체를 바꾸는 선택지를 설명드립니다.

# 카드를 잃은 날, 이것만은 하지 마세요
- 도어락을 분해해서 등록 칩을 찾으려는 일
- 새 카드를 아무 데서나 사서 등록하려는 일
- 번호판을 여러 번 세게 누르거나 두드리는 일
- 문틈에 카드를 끼워 열려는 일
카드로 문틈을 벌리는 방식은 현관문에서는 통하지 않고 오히려 문틀만 상합니다. / 급할수록 손을 멈추고 상담을 먼저 받으세요. / 도어락 내부는 작은 부품이 많아 한 번 분해하면 되돌리기 어렵습니다.

# 문을 여는 순서와 비용 안내
문이 안 열리는 상태라면 사시는 분인지 확인한 뒤 비파손 방식부터 시도합니다. / 열기 전에 비용을 먼저 말씀드리고, 동의하신 뒤에만 작업합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 자세한 진행은 [이용안내](guide.html)에 정리했습니다.
문 열기 방식은 [현관문 개문](door-open.html)에서 상황별로 설명하고 있습니다.

# 도착하면 사시는 분인지부터 확인합니다
문을 여는 일이라 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
카드가 없어서 신분증도 같이 없는 경우가 있습니다. / 이럴 땐 관리사무소에 세대 확인을 부탁하는 방법을 먼저 알아봐 주세요.
확인이 어려우면 작업을 할 수 없으니 미리 방법을 챙겨 두세요.
@ 영통동 24시 출장열쇠 카드키 분실 상담

# 열린 뒤에는 등록을 깨끗이 정리합니다
문이 열리면 분실한 카드를 포함해 등록된 카드를 점검합니다. / 필요하면 전체를 지우고 지금 갖고 있는 카드만 다시 등록합니다.
비밀번호도 같이 바꿀지 물어보고 원하시면 새 번호를 등록합니다. / 배터리가 오래됐다면 이때 새것으로 같이 갈아 드립니다.
등록이 잘 되었는지 카드를 대어 열림과 잠김을 두세 번 확인합니다. / 분실한 카드를 대어 열리지 않는 것까지 확인되면 마무리입니다. / 이 단계를 거치면 새 카드를 가족에게 나눠 드려도 안심입니다.

# 새 카드를 만들 때 알아둘 점
도어락마다 호환되는 카드 규격이 달라서, 아무 카드나 쓸 수는 없습니다. / 사용하던 카드와 같은 규격인지 확인하는 게 우선입니다.
등록 개수 제한도 있으니 가족 구성원 수에 맞춰 여유를 두세요. / 처음 만들 때 예비 카드를 하나 더 두면 잃어버렸을 때 대신 쓸 수 있습니다.
관리 습관도 중요합니다. / 예비 카드는 지갑이 아닌 집 밖 안전한 곳이나 믿을 만한 가족에게 맡겨 두세요.

카드를 열쇠고리에 달아 두면 열쇠와 함께 다니니 분실 확률이 줄어듭니다. / 반대로 카드를 교통카드와 겹쳐 두면 서로 간섭할 수 있으니 따로 두세요.
가끔 카드 개수를 세어 보고 사라진 것이 없는지 확인하는 것도 좋은 습관입니다. / 오래 쓰지 않는 카드는 등록을 정리해 두세요.
도어락 쪽 문제가 의심되면 [도어락 수리](doorlock-repair.html)에서 증상별로 확인하세요.

# 영통동 말고 수원 어디든
영통동 옆 매탄동, 망포동은 물론 수원 전 지역을 다닙니다. / 영통역, 수원역, 광교중앙역, 성균관대역 근처도 같습니다.
다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 있고, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
