# 영통동 가게 뒷문, 영업 전에 막히면 난감합니다
영통동은 영통역 주변으로 가게가 촘촘해서 새벽부터 물건을 들이는 소형 점포가 많습니다. / 그런 곳은 앞문보다 뒷문과 창고문을 먼저 쓰는 날이 많아 이쪽이 막히면 영업 준비가 통째로 멈춥니다.
이 글은 편의점이나 소형 마트의 뒷문, 창고문이 안 열리거나 잠겼을 때 확인할 것을 적었습니다. / 해결이 어려우면 [수원 출장열쇠](suwon.html)를 부르는 순서도 정리했습니다.
@ 영통동 소형 점포 뒷문 출입구

# 뒷문과 창고문이 앞문과 다른 점
영통동 소형 가게는 건물 구조상 뒷문이 골목이나 계단 쪽으로 나 있는 곳이 많습니다. / 비나 눈이 들이치기 쉬워 잠금장치가 더 빨리 상합니다.
앞문은 손님이 보는 문이라 자주 점검하지만 뒷문은 쓰는 사람이 정해져 있고 쓰는 시간도 불규칙합니다. / 그래서 고장이 나도 한참 뒤에야 알아채는 일이 많습니다.
물건을 들이는 시간대에는 카트나 박스가 문 앞을 막고 있는 경우도 많습니다. / 문 앞이 정리돼 있어야 작업이 빨라지니 가능하면 비워 두세요.
창고문은 물건을 싣고 내리느라 문을 밀거나 발로 닫는 일도 잦습니다. / 문틀과 잠금장치에 가해지는 힘이 현관문보다 큰 편입니다.
도어락, 일반 열쇠 실린더, 빗장이나 걸쇠 등 형태도 제각각이라 먼저 어떤 종류인지 보는 것이 우선입니다.

# 열쇠 구멍 문인지 도어락 문인지 구분하기
- 열쇠를 꽂아 돌리는 실린더형: 열쇠가 안 돌아가거나 안 빠지는 문제가 많음
- 번호판이나 카드 도어락: 배터리와 번호 입력 문제가 많음
- 안쪽 빗장이나 걸쇠: 밖에서는 열 방법이 마땅치 않을 수 있음
종류에 따라 연락할 때 필요한 정보가 달라집니다. / 같은 가게라도 앞문은 도어락, 뒷문은 열쇠형처럼 섞여 있는 경우가 흔합니다. / 지금 막힌 문이 어느 쪽인지 정확히 말씀해 주시면 챙겨 갈 장비를 맞추기 쉽습니다. / 사진 한 장이 있으면 설명이 훨씬 빨라집니다.

# 열쇠가 안 돌아갈 때 먼저 해볼 것
뒷문 실린더는 먼지와 물기가 잘 들어가 뻑뻑해지는 경우가 많습니다. / 열쇠를 끝까지 넣었다가 아주 조금 빼서 다시 돌려 보면 돌아가기도 합니다.
세게 비틀면 열쇠가 부러져 구멍 안에 박힐 수 있습니다. / 그러면 문을 여는 일이 한 단계 더 어려워지니 힘을 주지 마세요.
기름을 아무거나 뿌리는 것도 먼지가 엉겨 더 나빠질 수 있어 피하는 편이 좋습니다.

# 도어락 문이면 배터리부터 확인
뒷문 도어락은 사람이 적게 드나들어 건전지를 잊고 지내기 쉽습니다. / 번호판이 안 켜지면 배터리가 방전됐을 가능성이 큽니다.
비상 전원 단자가 있으면 9V 건전지를 대고 번호를 눌러 보세요. / 영통역 주변 가까운 가게에서 구할 수 있지만 같은 업종이라고 빌려 쓰기 어렵다면 바로 연락 주시는 게 낫습니다.
@ 점포 뒷문 도어락과 비상 전원 단자

# 점주님이 하지 말아야 할 일
영업 전 짧은 시간에 해결하려는 마음이 클수록 무리한 방법을 쓰기 쉽습니다. / 먼저 숨을 한 번 돌리고 아래 내용을 떠올려 보세요.
영업 시간이 급해 발로 차거나 어깨로 밀고 싶은 마음이 들 수 있습니다. / 그렇게 하면 문틀이 휘고 잠금장치가 더 꽉 물립니다.
지렛대로 틈을 벌리는 방법도 문과 틀에 흠을 남기고 방범에 구멍이 생깁니다. / 가게 문은 나중에 고치는 비용도 영업에 영향을 주니 처음부터 상하지 않게 여는 편이 낫습니다.

# 가게 사정에 맞춰 알려주실 정보
- 영통동 어느 건물, 몇 층, 뒷문인지 창고문인지
- 열쇠형인지 도어락형인지
- 영업 시작이나 물건 입고까지 남은 시간
- 문 안쪽에 사람이 있는지 여부
- 문에 달린 다른 자물쇠나 셔터가 있는지
문 안에 냉장 식품이 있거나 시간이 급한 경우에는 꼭 먼저 말씀해 주세요. / 급한 정도를 알면 출동 순서를 정하는 데 도움이 됩니다. / 뒷문이 건물 공용 통로로 이어져 있다면 건물 관리 쪽에 미리 알려 두시는 것도 좋습니다.

# 도착하면 가게 주인인지 먼저 확인합니다
가게 문이라 영업하시는 분인지, 관리하는 분인지 확인합니다. / 사업자 관련 서류, 건물 관리인 확인, 가게 안 연락처 중 가능한 것으로 확인하면 됩니다.
직원이시라면 점주님과 통화해서 확인할 수도 있습니다. / 건물 관리하시는 분이 계시면 그분의 확인도 도움이 됩니다. / 확인 서류나 연락처를 한 곳에 정리해 두면 급할 때 바로 꺼낼 수 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 종류와 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 최대한 상하지 않게 엽니다
문이 상하면 영업에도 손해이므로 덜 상하는 방법부터 차례로 해봅니다. / 도어락이나 실린더가 망가지는 일을 최소로 하는 것이 먼저입니다.
도어락이든 열쇠형이든 같은 원칙으로 진행합니다. / 열기 전에 상태를 보고 방법을 말씀드립니다.
방법은 [현관문 개문](door-open.html) 안내에도 정리해 두었습니다. / 가게 뒷문은 [출장 요청 방법](key-call.html) 페이지에서 전화 전 준비를 확인하실 수 있습니다.
@ 비파손으로 점포 뒷문 여는 작업

# 열고 난 뒤 같이 점검합니다
작업이 끝나면 영업 중에도 문제없이 여닫히는지 직접 몇 번 써 보시도록 권합니다. / 물건을 들고 드나드는 동선이라 한 번에 잘 되는지가 중요합니다.
문이 열리면 열쇠가 부드럽게 돌아가는지, 도어락이 정상 작동하는지 같이 확인합니다. / 닫히는 소리나 걸쇠 걸림이 있으면 말씀드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않고 [도어락 수리](doorlock-repair.html)를 먼저 봅니다. / 너무 오래돼 불안하면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 가게 뒷문 관리 습관
- 뒷문 건전지는 계절이 바뀔 때 한꺼번에 교체
- 열쇠 구멍에 먼지가 보이면 가볍게 털어 내기
- 문틀과 경첩에 물건이 닿지 않게 비워 두기
- 여벌 열쇠는 가게 밖 안전한 곳에 하나 보관
- 직원 교대 때 번호를 함께 정리하기
새로 입사한 직원에게 뒷문 사용법을 알려줄 때 문을 세게 닫지 않는 것까지 같이 말해 주세요. / 문을 쾅 닫는 습관 하나가 도어락과 문틀 수명을 크게 좌우합니다.
작은 점검이 영업 시작 전 당황할 일을 줄여 줍니다.
