# 영통동 열쇠가 들어가는데 헛돈다면
영통동은 영통역 주변 상가와 주거지가 이어져 출퇴근 오가는 사람이 많은 동네입니다. / 아침마다 쓰는 열쇠가 어느 날부터 들어가긴 하는데 돌릴 때 헛도는 느낌이 난다면 실린더가 닳았을 수 있습니다.
실린더는 열쇠가 들어가는 둥근 원통 부분으로, 안에 든 작은 핀이 열쇠 홈과 맞아야 돌아갑니다. / 오래 쓰면 이 핀과 열쇠 홈이 모두 닳아서 맞물림이 어긋납니다.
이 글은 영통동에서 열쇠가 헛돌 때 직접 확인할 것과 [수원 출장열쇠](suwon.html)가 점검하는 순서를 정리했습니다.
@ 영통동 현관 실린더에 열쇠를 꽂은 모습

# 실린더가 닳는다는 건 어떤 상태인가
쇠끼리 수천 번 맞물려 도는 부품이다 보니 시간이 지나면 모서리가 둥글어집니다. / 열쇠 쪽도 같이 닳아서 처음의 정확한 굴곡이 사라집니다.
- 열쇠를 꽂아도 돌아가는 감촉이 푹 꺼지듯 느슨한 경우
- 특정 각도로 흔들어야 겨우 돌아가는 경우
- 열쇠를 돌리면 헛돌기만 하고 걸쇠가 안 움직이는 경우
- 열쇠를 뺄 때 걸리거나 뻑뻑한 경우
처음에는 가끔 그러다가 점점 잦아지는 경우가 많습니다. / 그러다 어느 날 아예 안 열려서 문 앞에서 막히게 됩니다.

# 헛도는 소리와 느낌으로 구분해 보기
같은 헛돎이라도 원인이 다를 수 있습니다. / 아래처럼 구분해 보시면 상담이 쉬워집니다.
- 열쇠가 돌긴 하는데 걸쇠가 안 들어가는 소리면, 실린더 뒤쪽 연결부가 마모된 쪽
- 열쇠가 돌아가지 않고 덜컥대면, 핀이 닳았거나 열쇠가 닳은 쪽
- 돌아가다 중간에 멈추면, 이물이 끼었거나 데드볼트가 걸린 쪽
- 안쪽 손잡이는 잘 도는데 열쇠만 안 되면, 실린더 쪽 문제 가능성이 큼
정확한 판단은 열어서 봐야 하지만 이 정도만 알려주셔도 준비할 장비가 달라집니다.

# 가장 먼저 해볼 일, 복사한 열쇠 말고 원본으로
열쇠를 복사해 쓰는 경우 복사본이 원본과 미세하게 달라 헛도는 일이 많습니다. / 원본이나 처음 받은 열쇠가 있다면 그것으로 먼저 돌려 보세요.
복사본은 한 번 닳은 열쇠를 다시 베껴 만든 경우도 있어 오차가 쌓입니다. / 원본으로 부드럽게 돌아간다면 실린더가 아니라 복사본이 문제입니다.
이때는 새로 열쇠를 만들어 두면 해결될 때가 있습니다. / 관련해서는 [열쇠 호출](key-call.html) 안내도 참고하세요.

# 기름이나 윤활제, 아무거나 뿌리지 마세요
뻑뻑해서 기름을 뿌려 보는 분이 많지만 오래된 실린더에는 오히려 먼지가 엉겨 더 막히는 일이 있습니다. / 식용유나 일반 방청제는 특히 끈적임이 남아 핀을 붙게 만듭니다.
쓰신다면 열쇠 구멍 전용 건식 윤활제를 소량만 쓰는 것이 낫습니다. / 그래도 헛돎은 닳아서 생기는 것이라 윤활만으로 해결되지는 않습니다.
열쇠를 억지로 돌리다 부러지는 사고도 조심해야 합니다. / 부러지면 일이 훨씬 커지니 안 돌아가면 힘주지 마세요.
@ 영통동 닳은 열쇠 홈 비교

# 열쇠가 부러질 것 같은 느낌이 들 때
열쇠를 돌릴 때 손끝에서 휘는 느낌이 나면 이미 한계입니다. / 이 상태에서 한 번 더 돌리면 열쇠가 실린더 안에서 부러질 수 있습니다.
부러진 열쇠 조각이 안에 박히면 문 열기와 조각 빼내기를 따로 해야 합니다. / 그래서 이상을 느낀 날 문이 열려 있을 때 미리 점검을 받는 편이 훨씬 편합니다.
문 밖에서 이미 안 열리는 상황이라면 열쇠를 더 쓰지 말고 연락 주세요. / 상황별 접근은 [현관문 개문](door-open.html) 안내에 정리되어 있습니다.

# 이런 날 특히 조심하세요
비가 온 뒤나 한겨울 아침에는 실린더 안이 젖거나 얼어 평소보다 더 뻑뻑해집니다. / 이때 닳은 열쇠를 세게 돌리면 평소에는 버티던 열쇠가 부러지기 쉽습니다.
약속에 늦은 아침이나 짐을 든 채 문을 여는 순간처럼 마음이 급할 때 힘이 더 들어갑니다. / 그럴수록 한 번 숨을 돌리고 열쇠를 똑바로 끝까지 꽂았는지 확인해 주세요.
@ 영통동 열쇠 구멍 이물 확인

# 출장열쇠가 와서 하는 확인
도착하면 열쇠를 꽂아 돌리는 느낌과 걸쇠 움직임을 먼저 봅니다. / 문 밖에서 상하지 않게 열 수 있는 방법을 고른 뒤에 열기 시작합니다.
문이 열리면 실린더를 분리해 핀과 홈의 닳은 정도를 확인합니다. / 청소로 되살릴 수 있는지, 핀만 교체하면 되는지, 실린더 전체를 바꿔야 하는지를 나누어 설명드립니다.
확인을 위해 분리해야 할 때도 분리 전에 먼저 말씀드립니다.

# 신분 확인은 꼭 하고 시작합니다
문을 여는 작업이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁해 보세요. / 확인이 어렵다면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.
세입자시라도 거주하시는 것이 확인되면 진행할 수 있습니다.

# 비용은 문 열기 전에 말씀드립니다
열쇠 구멍 상태를 보고 필요한 작업이 무엇인지 먼저 설명드립니다. / 청소만 하는지, 부품을 바꾸는지에 따라 달라지기 때문에 시작 전에 비용을 말씀드립니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꾸기 전에 따로 여쭙고, 말없이 항목을 늘리지 않습니다. 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 실린더만 바꿀까, 도어락 전체를 바꿀까
열쇠 구멍만 닳았다면 실린더만 바꾸는 방법이 있습니다. / 도어락 본체는 멀쩡하다면 이 쪽이 부담이 덜합니다.
본체까지 오래되어 잔고장이 잦다면 [도어락 교체](doorlock-replace.html)를 함께 고려할 수 있습니다. / 새 제품을 달기 전에 [도어락 설치](doorlock-install.html)에서 문 두께와 구멍 규격을 확인하는 순서를 안내해 드립니다.
고쳐서 쓸 수 있으면 억지로 교체를 권하지는 않습니다. / 부분 수리로 충분한 경우는 [도어락 수리](doorlock-repair.html)로 먼저 안내합니다.

# 실린더를 오래 쓰는 습관
교체한 뒤에도 습관에 따라 수명이 달라집니다.
- 열쇠를 꽂은 채 문에 기대지 않기
- 열쇠고리에 무거운 물건 여러 개 달고 돌리지 않기
- 비스듬히 꽂아 돌리지 않고 끝까지 밀어 넣은 뒤 돌리기
- 복사는 가급적 원본에서 한 번만 하기
- 헛돎이 처음 느껴질 때 미루지 말고 점검받기
열쇠고리 무게가 의외로 큰 원인이 됩니다. / 문 열 때마다 열쇠 구멍에 계속 하중이 실리기 때문입니다.

# 영통동 말고 수원 어디든 갑니다
영통동 가까운 매탄동, 원천동, 망포동, 광교동은 물론 수원 안이면 어디든 갑니다. / 수원 안내는 [수원시 출장열쇠](suwon.html)에 있고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
