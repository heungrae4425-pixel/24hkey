# 영통동 번호판이 갑자기 꺼졌다면
영통동은 영통역을 중심으로 아파트 단지가 길게 이어진 동네입니다. / 입주한 지 오래된 집일수록 도어락 배터리가 한꺼번에 약해지는 일이 흔합니다.
저녁에 장을 보고 들어오는데 번호판에 아무 불빛도 없으면 그 자리에서 멈춰 서게 됩니다. / 이 글은 그런 순간에 무엇부터 해보고, 언제 [수원 출장열쇠](suwon.html)를 부르면 되는지 순서대로 적었습니다.
배터리 문제라면 5분 안에 해결되는 경우가 많습니다. / 그래서 전화하기 전에 아래 내용을 먼저 보시길 권합니다.
@ 영통동 도어락 번호판 꺼짐 출장열쇠

# 배터리가 다 되면 이런 신호가 먼저 옵니다
도어락은 어느 날 갑자기 죽는 것처럼 보여도 대개 예고가 있습니다. / 돌이켜 보면 며칠 전부터 이상한 점이 있었다는 분이 많습니다.
- 번호를 누를 때 불빛이 평소보다 어둡거나 깜빡임
- 문이 열릴 때 모터 소리가 느리고 힘없이 들림
- 열렸다 닫힐 때 경고음이 짧게 반복됨
- 번호를 눌러도 두세 번에 한 번만 반응함
이런 신호가 보이면 문이 잠기기 전에 배터리를 바꾸는 게 가장 좋습니다. / 이미 꺼진 뒤라면 다음 순서로 가시면 됩니다.

# 먼저 번호판 주변을 확인합니다
번호판이 꺼졌다고 바로 배터리 탓으로 단정하지 마세요. / 번호판 위에 손바닥을 대고 몇 번 눌러 보면 희미한 불이 들어오는 경우도 있습니다.
카드키나 지문 인식이 되는 모델이라면 그쪽을 먼저 시도해 보세요. / 번호판만 죽고 다른 방식은 살아 있는 기종도 있습니다.
현관 안쪽 문 손잡이를 돌려서 잠금이 풀렸는지도 확인해 보세요. / 밖에서 안 열리는 이유가 안쪽 보조키가 걸려서인 경우도 의외로 많습니다.

# 9V 건전지로 비상 전원 넣기
번호판 아래쪽이나 옆면에 작은 접점 두 개가 있는 모델이 많습니다. / 여기에 9V 건전지의 단자를 맞대면 잠시 전원이 들어옵니다.
건전지를 대고 있는 상태에서 비밀번호를 누르면 문이 열립니다. / 손이 떨려 접점이 떨어지면 불이 꺼지니 단단히 붙인 채로 입력하세요.
영통역 근처 편의점이나 단지 상가에서 9V 건전지를 구할 수 있습니다. / 집에 하나 두면 급할 때 큰 도움이 됩니다.
접점이 없는 기종이나 건전지를 대도 불이 안 들어오면 다른 원인일 수 있습니다. / 그때는 무리하지 마시고 전화 주세요.
@ 수원 열쇠집 9V 비상 전원 도어락

# 해서는 안 되는 행동
급하면 문을 세게 두드리거나 손잡이를 힘으로 비틀고 싶어집니다. / 그러면 도어락 내부의 걸쇠가 틀어져 배터리 문제가 부품 고장으로 번질 수 있습니다.
- 번호판 틈에 드라이버를 넣어 비집기
- 문과 문틀 사이에 카드를 밀어 넣기
- 안 열린다고 비밀번호를 수십 번 연속 입력하기
- 배터리 커버를 억지로 뜯기
비밀번호를 여러 번 틀리면 도어락이 잠시 입력을 막기도 합니다. / 그럴 때는 몇 분 쉬었다가 다시 해 보세요.

# 이럴 땐 건전지를 대도 소용이 없습니다
배터리가 원인이 아닌 경우도 분명히 있습니다. / 비상 전원을 대도 반응이 없다면 아래 쪽을 의심합니다.
번호판과 본체를 잇는 선이 끊어졌거나 번호판 회로 자체가 고장 난 경우입니다. / 물이 스며든 뒤 마르지 않았을 때도 같은 증상이 나옵니다.
소리는 나는데 문이 안 열리면 모터나 걸쇠 쪽 문제일 가능성이 큽니다. / 이런 경우는 [도어락 수리](doorlock-repair.html)가 필요할 수 있습니다.

# 겨울철이면 더 자주 생기는 일
날이 추워지면 건전지의 힘이 평소보다 빨리 떨어집니다. / 한여름엔 멀쩡하던 도어락이 첫 추위에 갑자기 불을 못 켜는 일이 있는 이유입니다.
영통동처럼 현관이 바깥 복도에 면한 집은 찬 공기를 더 직접 받습니다. / 찬바람이 불기 전에 배터리를 미리 점검해 두면 안심입니다.

# 영통동에서 위치를 알려주실 때
영통동은 길 하나를 사이에 두고 단지가 나뉘어 있어서 설명이 어긋나기 쉽습니다. / 통화할 때 아래 네 가지만 말씀해 주시면 도착이 빨라집니다.
- 영통역에서 어느 쪽으로 가까운지
- 동과 호수, 현관 앞에 계신지 여부
- 번호판 상태(전혀 안 켜짐, 켜졌다 꺼짐, 경고음)
- 집 안에 아이나 반려동물이 있는지
사진을 한 장 찍어 문자로 보내주시면 챙겨 갈 장비를 고르기 좋습니다. / 도어락 모양만 봐도 어떤 방식으로 열지 대략 가늠할 수 있습니다.

# 출장열쇠를 부르는 기준
9V 건전지를 대도 안 되거나 소리만 나고 안 열리면 부르시는 게 맞습니다. / 열쇠를 집 안에 두고 나왔는데 보조키까지 걸린 경우도 마찬가지입니다.
어린 아이나 반려동물이 집 안에 혼자 있다면 지체하지 마세요. / 이럴 땐 전화하면서 상황부터 먼저 말씀해 주세요.
수원 안이라면 영통동뿐 아니라 매탄동, 망포동, 광교동까지 이어서 다닙니다. / 동네 구분 없이 24시간 전화를 받습니다.

# 도착하면 이렇게 진행됩니다
먼저 도어락 종류와 문 상태를 살피고, 어떻게 열지 설명드립니다. / 비용은 문을 열기 전에 먼저 말씀드리고 동의하시면 시작합니다.
열기 전에 거주자 확인을 합니다. / 신분증이나 우편물, 관리실 확인 중 하나면 됩니다. 자세한 절차는 [이용안내](guide.html)에 있습니다.
가능한 한 문과 도어락이 상하지 않는 방법부터 씁니다. / 방법은 [현관문 개문](door-open.html) 페이지에서 볼 수 있습니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 나서 갑자기 붙는 비용도 없습니다.
@ 영통동 현관문 개문 24시간 출동

# 문이 열린 뒤 바로 할 일
들어오자마자 새 배터리로 바꾸세요. / 이때 기존 배터리 일부만 남기지 말고 전부 같은 날 새것으로 갈아야 합니다.
알카라인 건전지가 일반적으로 무난합니다. / 충전식 전지는 전압이 낮아 도어락이 일찍 경고를 낼 수 있어 권하지 않습니다.
교체 후에는 문을 열고 닫으며 잠금이 정상인지 몇 번 확인해 보세요. / 경고음이 계속 나면 접점 불량일 수 있으니 말씀해 주세요.

# 같은 일을 또 겪지 않으려면
배터리 칸에 교체 날짜를 적은 작은 스티커를 붙여 두세요. / 해가 바뀔 때 한 번에 갈아주는 것도 쉬운 방법입니다.
- 경고음이 나는 날 바로 교체
- 여행이나 출장 전에 배터리 상태 보기
- 가족 모두에게 비상 전원 위치 알려두기
- 9V 건전지 하나를 현관 서랍에 보관
- 카드키나 열쇠 하나는 도어락과 다른 곳에 두기
도어락이 너무 오래돼 자주 말썽이라면 [도어락 교체](doorlock-replace.html)를 고려할 때가 된 것입니다. / 고쳐 쓸 수 있다면 교체를 먼저 권하지는 않습니다.

# 영통동 말고 수원 어디든
영통동 옆 매탄동, 원천동, 망포동은 물론 권선동, 인계동, 화서동까지 갑니다. / 수원 안이면 24시간 출동합니다.
다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리했고, 서울·경기 전체는 [출장 지역](area.html) 지도에서 보실 수 있습니다.
