# 늦은 밤 독서실 문 앞에서
수원 영통동은 영통역 주변으로 학원과 독서실, 스터디카페가 모여 있는 생활권입니다. / 시험 기간이면 늦은 밤까지 불이 켜져 있다가 어느 날 출입문이 안 열리는 일이 생깁니다.
문이 안 열리는 사람은 두 부류입니다. / 안으로 들어가야 하는 운영자나 관리자, 그리고 밖에 나왔다가 못 들어가는 이용자입니다.
이 글은 영통동 독서실이나 스터디카페에서 출입문이 잠겼을 때 각자 무엇부터 해야 하는지 적었습니다. / 개인 집 문과 달라서 알아 둘 점이 몇 가지 있습니다.
@ 영통동 스터디카페 출입문 야간 모습

# 독서실 출입문이 집 문과 다른 점
독서실이나 스터디카페는 보통 출입 방식이 여러 겹입니다.
- 카드나 QR로 들어오는 출입 통제 장치
- 번호 입력식 도어락
- 안쪽에서 열리는 문 손잡이나 버튼
- 건물 공용 출입구와 매장 출입구가 따로 있는 구조
어느 문이 안 열리는지에 따라 대처가 달라집니다. / 같은 가게라도 건물 공용문인지 매장 문인지 먼저 구별해야 합니다.

# 운영자가 먼저 확인할 순서
오픈 전이나 마감 후에 문이 안 열릴 때 아래 순서로 살펴보세요.
- 출입 장치 전원이 켜져 있는지
- 카드나 번호 인식이 되는지, 경고음이 나는지
- 열쇠 구멍이 있다면 보조 열쇠로 열리는지
- 문틀과 문 사이에 걸리는 곳이 있는지
정전이나 차단기 문제로 전원이 꺼진 경우도 있습니다. / 이럴 때는 문 자체 고장이 아니라 전기가 끊긴 것이라 순서가 달라집니다.

# 이용자가 문 밖에서 못 들어올 때
화장실이나 휴게 공간에 나갔다가 출입 카드를 안에 두고 나온 경우가 있습니다. / 이럴 때는 안에 있는 다른 이용자나 직원에게 연락해 열어 달라고 부탁하세요.
무인으로 운영되는 곳이라면 운영 앱이나 안내 번호로 문의하는 방법이 있습니다. / 운영자가 원격으로 열어 줄 수 있는 곳도 있습니다.
모르는 사람에게 문을 열어 달라고 부탁받더라도 이용자 확인이 안 되면 열어 주지 않는 것이 맞습니다. / 안전을 위해 정해진 절차가 있는 곳입니다.

# 번호 입력식에서 흔한 실수
많은 사람이 같이 쓰는 번호식 도어락은 번호가 자주 바뀝니다. / 바뀐 번호를 못 받은 사람이 여러 번 틀려 입력이 막히기도 합니다.
번호가 막히면 한참 기다리면 풀리는 제품이 많습니다. / 그 사이에는 번호판을 건드리지 말고 운영자에게 먼저 연락하세요.
운영자라면 번호를 바꾼 뒤 이용자에게 알림을 꼭 보내세요. / 변경 내용을 한곳에 공지해 두는 것이 가장 확실합니다.
@ 영통동 독서실 번호판 입력 제한 상태

# 배터리와 전원 문제 구별
번호판이 전혀 켜지지 않는다면 배터리 방전일 수 있습니다. / 비상 전원 단자가 있으면 9V 건전지를 대고 번호를 눌러 보세요.
전기를 쓰는 출입 장치 전체가 꺼졌다면 배터리가 아니라 전원 공급 문제입니다. / 이때는 건물 관리실이나 전기 담당자에게 먼저 확인이 필요합니다.
도어락 본체만 반응이 없다면 모터나 회로 문제일 수 있습니다. / 이런 경우 억지로 열지 말고 연락해 주세요.

# 개별 사물함과 룸 도어도 같이 봅니다
독서실 안에는 출입문 말고도 사물함이나 개인 룸 문이 있는 경우가 있습니다. / 이런 문은 열쇠를 잃어버리거나 번호를 잊는 일이 잦습니다.
이용자가 맡긴 짐이 들어 있을 수 있어 운영자 확인이 더 중요합니다. / 본인 소유 확인 없이 열어 줄 수는 없습니다.
이용자는 먼저 운영자에게 사정을 말하고 운영자가 요청하는 방식을 따르세요. / 이 점이 개인 집 문과 가장 다릅니다.

# 시험 기간에 특히 조심할 것
시험 기간에는 새벽까지 이용자가 많아서 문이 평소보다 훨씬 자주 열립니다. / 닳는 속도가 빠르니 배터리를 일찍 갈아 두는 것이 좋습니다.
문을 쾅 닫는 사람이 많으면 걸쇠가 헐거워지거나 문틀이 어긋날 수 있습니다. / 문이 덜 닫히는 느낌이 들면 미리 점검해 두세요.
이용자들이 급하게 나가며 문을 잠그지 않고 나가는 경우도 있습니다. / 그렇다고 해서 반대로 안에 사람이 있는데 잠가 버리는 일이 없도록 안내문을 붙여 두면 좋습니다.

@ 영통동 독서실 비상 시 안쪽 문 손잡이

# 사람이 안에 갇힌 것 같을 때
안쪽에서 문이 안 열려 사람이 나오지 못하는 상황은 일반 요청과 다릅니다. / 이때는 전화 첫마디에 안에 사람이 있다고 말씀해 주세요.
몸이 불편한 분이 안에 있거나 상황이 위급해 보이면 119에 먼저 연락하는 것이 맞습니다. / 소방 출동이 필요한 상황을 우선합니다.
안에 있는 분에게 문 너머로 계속 말을 걸어 안심시켜 주세요. / 문을 억지로 흔들면 오히려 상황이 나빠집니다.

# 출장열쇠를 부르기 전에 정리할 것
전화하기 전에 아래를 정리해 두시면 훨씬 빨라집니다.
- 영통동 안의 대략적인 위치와 건물 이름이 아닌 위치 설명 (영통역에서 어느 방향, 몇 층)
- 어느 문이 문제인지 (공용 출입구인지 매장 문인지)
- 출입 장치의 종류와 증상
- 운영자 본인인지 이용자인지
[수원 출장열쇠](suwon.html)는 영통동 어디든 24시간 전화를 받습니다. / 야간 학습 시간대에도 연락하셔도 됩니다.

# 운영자 신분 확인
문을 여는 일이라 운영하시는 분인지 먼저 확인합니다. / 사업자등록증, 임대차 서류, 건물 관리실 확인 중 가능한 것이면 됩니다.
이용자 한 사람의 요청만으로는 출입문을 열 수 없습니다. / 운영자나 건물 관리자와 먼저 연락이 닿아야 합니다.
확인이 어려우면 작업을 할 수 없으니 미리 서류 사진이라도 챙겨 두시면 좋습니다. / 이웃 가게와 건물 전체의 안전을 지키는 절차입니다.

# 비용은 열기 전에 말씀드립니다
문 종류와 장치를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니라면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 문을 연 뒤 재발 방지
열고 나서 출입 장치가 다시 잘 작동하는지 함께 점검합니다. / 배터리가 원인이면 새것으로 바꾸는 것도 확인합니다.
- 번호 변경 시 이용자 공지 방법 정리
- 비상시 안에서 문을 열 수 있는 방법 직원 모두 숙지
- 배터리 교체 날짜 기록
자주 말썽인 장치는 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래되면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 문 열기 방식은 [현관문 개문](door-open.html)에서 볼 수 있습니다.

영통동 주변은 물론 매탄동, 망포동, 광교동 등 수원 곳곳으로 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
야간 학습 시간대에 연락이 어려운 운영자를 위해, 비상 연락처를 출입문 안쪽 눈에 띄는 곳에 붙여 두세요. / 이용자가 갇히거나 못 들어올 때 가장 먼저 쓰이는 정보입니다.
정전이나 점검처럼 미리 알 수 있는 일은 이용자에게 공지해 두면 문 앞에서 혼란이 줄어듭니다.
