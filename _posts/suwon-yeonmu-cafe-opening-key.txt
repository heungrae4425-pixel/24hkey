# 오픈 30분 전, 가게 문이 안 열린다
수원 연무동에서 카페를 여는 분들은 수원역이나 성균관대역 쪽에서 출근하는 경우도 많습니다. / 이른 아침 불도 안 켜진 가게 앞에서 열쇠가 안 돌아가면 하루 시작이 그대로 무너집니다.
오픈 시간은 정해져 있고 손님은 기다립니다. / 그래서 매장 문이 안 열리는 일은 집 문이 안 열리는 것보다 마음이 더 급해집니다.
이 글은 카페나 작은 가게 사장님이 오픈 직전에 출입문이 안 열릴 때 무엇을 먼저 보고, 어떻게 연락하면 빠른지 적었습니다. / 가게 열기 전에 한 번 읽어 두시면 좋습니다.
@ 연무동 카페 오픈 전 출입문 앞 모습

# 매장 출입문이 안 열리는 흔한 이유
카페 출입문은 하루에도 수십 번 열고 닫는 문이라 집보다 닳는 속도가 빠릅니다.
- 열쇠를 꽂았는데 뻑뻑하거나 끝까지 돌아가지 않는 경우
- 도어락 번호판이 꺼졌거나 경고음만 나는 경우
- 문이 처져서 잠금장치가 문틀에 걸리는 경우
- 어제 마감하며 보조 잠금을 하나 더 걸어 놓은 걸 잊은 경우
의외로 마지막 경우가 많습니다. / 마감할 때 평소와 다르게 잠갔다면 아침에 그것부터 떠올려 보세요.

# 먼저 열쇠를 다시 한번 살펴보기
카페 열쇠는 하나만 오래 쓰면 이가 닳아 걸리는 일이 있습니다. / 같은 열쇠 복사본이 있다면 다른 열쇠로 바꿔 꽂아 보세요.
열쇠를 억지로 돌리다가 안에서 부러지면 일이 훨씬 커집니다. / 힘이 걸리는 느낌이 들면 멈추는 쪽이 낫습니다.
잠금 장치 구멍에 이물질이 낀 것처럼 보이면 일단 건드리지 마세요. / 상황을 말씀해 주시면 먼저 판단해 드립니다.

# 도어락이라면 배터리와 번호판 확인
번호식이나 카드식 도어락을 쓰는 가게라면 배터리 확인이 먼저입니다. / 번호판이 안 켜지면 비상 전원 단자에 9V 건전지를 대 보세요.
카페는 직원이 번갈아 출입하는 곳이라 번호를 여러 번 누르게 됩니다. / 그만큼 배터리가 빨리 줄기 때문에 경고음이 났을 때 미루지 않는 게 중요합니다.
번호는 맞는데 모터 소리만 나면 도어락 안쪽 문제일 수 있습니다. / 이럴 때는 억지로 열지 말고 연락해 주세요.

# 오픈 시간이 임박했다면 이렇게 하세요
시간이 급할수록 순서를 지켜야 합니다.
- 1분만 열쇠와 번호판 확인
- 안 열리면 손대지 말고 바로 연락
- 가게 앞에서 대기하며 직원이나 협력 업체에 지연 알리기
- 손님이 줄을 서면 안내문을 문에 붙여 두기
오픈 시간이 늦어지는 것은 안타깝지만, 문을 상하게 해서 수리까지 하는 것보다는 낫습니다. / 서둘러 도구로 문틈을 벌리다가 문과 잠금장치가 모두 상한 경우가 많습니다.
@ 연무동 카페 출입문 잠금장치 확인

# 하면 안 되는 행동
출입문을 어깨로 밀거나 발로 차는 방법은 피하세요. / 유리문이면 깨질 위험까지 있습니다.
인터넷에서 본 방법으로 카드나 철사를 문틈에 넣는 것도 권하지 않습니다. / 잠금장치가 상하면 가게를 며칠 쉬어야 할 수도 있습니다.
모르는 사람이 지나가다 열어 주겠다며 접근해도 응하지 마세요. / 사시는 분, 즉 가게 운영자 확인 없이 문을 여는 곳은 오히려 위험합니다.

# 출장열쇠를 부를 때 알려 주면 좋은 정보
가게 문은 집과 달라서 알려 주실 것이 조금 다릅니다.
- 연무동 안의 대략 위치와 건물 종류 (상가 건물, 단독 점포)
- 문 종류 (유리문, 철문, 목문)와 잠금장치 종류
- 오픈 시간까지 남은 시간
- 안에 사람이나 냉장·냉동 식재료가 있는지
식재료가 걸려 있으면 말씀해 주세요. / 상황의 급한 정도를 판단하는 데 도움이 됩니다.

# 전화할 때 오픈 시간을 알려 주세요
오픈이 몇 시인지, 지금 몇 분 남았는지 말씀해 주세요. / 시간이 촉박하면 가장 빠른 방법부터 판단해 드립니다.
도착 시간은 길 사정에 따라 달라지니 출발 후에도 계속 안내드립니다. / 수원 안이면 연무동이 아니어도 [수원 출장열쇠](suwon.html)로 연락 주시면 됩니다.
번호는 010-3664-5455입니다. / 가게 문에 붙여 두면 직원도 쓸 수 있습니다.

# 가게 문이라도 신분 확인은 필요합니다
상가라고 해도 문을 여는 일이라 운영하시는 분인지 먼저 확인합니다. / 사업자등록증, 임대차 서류, 건물 관리실 확인 중 가능한 것을 보여 주시면 됩니다.
서류가 가게 안에 있다면 건물 관리인이나 집주인의 확인을 받는 방법도 있습니다. / 확인이 어렵다면 작업을 할 수 없으니 미리 사진으로라도 챙겨 두면 좋습니다.
번거로우셔도 가게와 이웃 모두를 지키는 절차입니다.

# 비용은 열기 전에 말씀드립니다
문 종류와 잠금장치를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니라면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 갑자기 붙는 비용도 없습니다.
잠금장치를 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에서 볼 수 있습니다.

# 영업 중 문제는 다르게 접근합니다
오픈 전이 아니라 영업 도중에 문이 잠기거나 걸리는 경우도 있습니다. / 손님이 안에 있다면 안전과 동선이 먼저라서 순서가 달라집니다.
이런 때는 전화 첫마디에 손님이 안에 있다고 말씀해 주세요. / 손님이 보지 않는 곳에서 조용히 진행하는 방법을 먼저 찾습니다.
@ 연무동 영업 중인 카페 출입문 안쪽

# 가게 문 여는 방법도 최대한 상하지 않게
유리문이나 오래된 철문은 덜 상하는 방법부터 차례로 해봅니다. / 가게 외관과 영업에 지장이 가지 않게 하는 것이 먼저입니다.
작업 중 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다. / 문 여는 과정은 [현관문 개문](door-open.html) 페이지에서 확인하실 수 있습니다.
열쇠를 잃어버렸거나 부러졌다면 [열쇠 출장](key-call.html)도 참고하세요.

# 열고 난 뒤 재발 방지
문이 열리면 잠금장치가 다시 잘 잠기고 열리는지 함께 점검합니다. / 열쇠나 도어락이 원인이면 고쳐 쓸 수 있는지 먼저 봅니다.
- 열쇠가 닳았다면 여분 열쇠 정리와 교체 상담
- 도어락 배터리는 가게 달력에 교체 날짜 적어 두기
- 마감 때 보조 잠금 여부를 직원들과 공유
자주 말썽이면 [도어락 수리](doorlock-repair.html)로 손보고, 너무 오래되면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

연무동 주변은 물론 영통동, 광교동, 인계동 등 수원 곳곳으로 다닙니다. / 수원 안이면 동네 상관없이 전화를 받습니다.
마감할 때 잠금 순서를 한 장에 적어 문 안쪽에 붙여 두면 직원이 바뀌어도 같은 방식으로 잠글 수 있습니다. / 아침에 문이 안 열리는 원인의 상당수는 전날 마감 습관에서 시작됩니다.
마지막으로 나가는 사람이 문을 확인하고 열쇠를 누가 보관하는지 정해 두는 것도 도움이 됩니다.

# 마무리
오픈 시간에 문이 안 열리면 마음이 급하지만 억지로 열려는 시도는 오히려 시간을 더 쓰게 만듭니다. / 열쇠와 번호판 확인 후 안 되면 바로 연락 주세요.
연무동에서 카페나 작은 가게 출입문이 안 열린다면 24시출장열쇠가 운영자 확인 후 문을 열어 드립니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.
@ 연무동 24시 출장열쇠 010-3664-5455
