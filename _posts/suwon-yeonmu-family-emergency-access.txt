# 연무동 가족 응급 상황, 문 앞에서 막히지 않으려면
연무동은 수원역과 광교중앙역 쪽 생활권을 오가는 가족이 많아 집이 비는 시간이 깁니다. / 그 사이 집 안에 혼자 있던 가족에게 갑자기 일이 생기는 경우를 한 번쯤 생각해 보게 됩니다.
쓰러졌거나 연락이 닿지 않는데 문이 잠겨 있다면 몇 분이 아주 길게 느껴집니다. / 이 글은 그런 일이 생기기 전에 미리 정해 둘 출입 방법을 정리한 글입니다.
@ 연무동 가족 응급 대비 현관 출입

# 가장 중요한 것은 119가 먼저라는 점
가족이 위험한 상태로 의심되면 열쇠 연락보다 119에 먼저 신고해야 합니다. / 구급대는 필요하면 문을 열고 들어갈 수 있도록 현장에서 판단합니다.
24시출장열쇠는 그 이후나 동시에 현장 도움이 필요할 때 연락받는 곳이라고 이해해 주세요. / 응급 상황의 순서를 헷갈리지 않는 게 먼저입니다.
열쇠를 부르기 전에 119, 그다음 가족과 관리사무소 순으로 연락하는 습관을 만들어 두세요.
위 중 하나라도 해당되면 지금 우리 집의 출입 방법이 어떻게 되어 있는지 한 번 적어 보세요. / 번호를 아는 사람, 열쇠를 가진 사람, 연락할 곳을 종이에 쓰면 빈틈이 보입니다.

# 어떤 상황을 미리 떠올려 두면 좋을까
- 혼자 사는 부모님과 오래 연락이 안 되는 경우
- 집에 있는 아이가 현관문을 열어주지 못하는 경우
- 화장실이나 방 안에서 사람이 쓰러진 경우
- 몸이 불편한 가족이 밤에 도움을 요청한 경우
이런 일을 떠올리는 것이 불안을 키우자는 뜻은 아닙니다. / 미리 정해 두면 막상 일이 생겼을 때 판단 시간이 줄어듭니다.

# 비밀번호를 한 사람만 알면 위험합니다
번호를 혼자만 알고 있으면 정작 필요할 때 가족이 들어가지 못합니다. / 가까운 가족 한두 명에게는 번호를 공유해 두는 편이 안전합니다.
다만 번호를 아무에게나 알려주라는 뜻은 아니고, 믿을 수 있는 사람으로 좁혀서 정하라는 뜻입니다. / 정기적으로 번호를 바꾸면서 공유 범위를 다시 정리하면 더 좋습니다.
공유한 번호는 대화방에 그대로 남겨 두지 말고 따로 안전한 곳에 적어 두세요.
번호를 공유한다고 해서 보안이 약해지는 것은 아닙니다. / 누구에게 알려 두었는지를 내가 알고 있으면 오히려 관리가 쉬워집니다.
공유받은 가족도 번호를 휴대폰 메모나 대화방에 그대로 남기지 않도록 서로 약속해 두세요.

# 보조키와 카드키의 보관 위치
예비 열쇠를 아무도 모르는 곳에 숨겨 두면 오히려 찾지 못합니다. / 현관 앞 화분 밑이나 우편함 속처럼 누구나 떠올리는 곳은 방범 면에서도 좋지 않습니다.
믿을 수 있는 가까운 가족이나 이웃에게 맡겨 두는 방법이 가장 무난합니다. / 어디에 맡겼는지는 가족끼리 서로 알아야 합니다.
@ 예비 열쇠와 카드키 가족 공유
가족 구성원이 모두 같은 휴대폰 앱이나 대화방을 쓴다면 긴급 연락 순서를 정해 두세요. / 누가 먼저 119에 신고하고 누가 집 쪽으로 가는지만 정해도 혼란이 줄어듭니다.
집 주소를 말로 정확히 전달하는 연습도 도움이 됩니다. / 아이와 어르신에게는 주소와 호수를 종이에 크게 적어 눈에 띄는 곳에 붙여 두세요.

# 관리사무소와 이웃에게 미리 알려 두기
혼자 사는 어르신이 계신 집이라면 관리사무소나 이웃과 연락처를 서로 주고받아 두면 든든합니다. / 며칠 동안 소식이 없으면 서로 확인해 줄 수 있는 관계가 만들어집니다.
이웃에게 번호나 열쇠를 맡길 때는 신뢰할 수 있는 사람인지 신중히 판단하세요. / 맡기는 대신 "연락이 안 되면 이 번호로 알려달라"고 부탁하는 정도로 시작하는 것도 방법입니다.

# 도어락이 응급 때 방해가 되는 경우
문이 안쪽에서 보조키로 잠겨 있으면 바깥에서 번호를 눌러도 열리지 않습니다. / 이 때문에 가족이 쓰러진 줄 알면서도 문을 못 여는 일이 생깁니다.
배터리가 나가서 번호판이 꺼진 상태라면 더 어려워집니다. / 평소에 배터리를 챙기고 보조키 사용 습관을 가족과 맞춰 두는 게 중요합니다.
어르신이 쓰기 편한 설정은 [도어락 교체](doorlock-replace.html)나 [도어락 수리](doorlock-repair.html)로 상담하실 수 있습니다.
어르신 댁이라면 보조키를 평소에 잠그지 않는 습관을 가족이 함께 정해 두는 것도 방법입니다. / 외출할 때만 잠그고 집에 있을 때는 풀어 두면 안쪽에서 닫힌 문이 가족의 접근을 막는 일이 줄어듭니다.

# 출장열쇠에 전화하실 때 말씀해 주실 내용
급한 상황일수록 짧게 핵심만 말씀해 주시면 됩니다. / 먼저 안에 사람이 있는지와 위급 정도를 알려주세요.
- 연무동 대략적인 위치와 동, 호수
- 안에 사람이 있고 연락이 안 되는지
- 119에 이미 연락했는지
- 도어락 상태(꺼짐, 켜짐, 경고음)
위급하다고 판단되면 119를 먼저 부르시라고 안내드릴 수 있습니다. / 도착 가능 여부는 전화로 바로 말씀드립니다.
전화를 거는 동안에도 문 너머로 계속 말을 걸어 안의 반응을 확인해 주세요. / 소리가 있는지 없는지가 판단에 큰 도움이 됩니다.

# 도착하면 사시는 분인지 확인합니다
응급에 가까운 상황이어도 문을 여는 일이라 사시는 분의 가족인지 확인하는 절차는 필요합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
가족이 아닌 사람이 문을 여는 일을 막는 절차이니 양해 부탁드립니다. / 확인이 어려우면 작업을 할 수 없는 경우도 있습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니라면 그냥 돌아갑니다.
끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭙습니다.
@ 연무동 문 열기 전 신분 확인과 비용 안내
응급 상황이 정리된 뒤에 도어락을 고치느라 또 시간을 쓰는 일은 피하는 게 좋습니다. / 그래서 문을 열 때도 가능한 한 장비가 상하지 않게 진행합니다.
작업 중에 안에 있는 분의 상태가 걱정되면 언제든 작업을 멈추고 구급대에 맡기시라고 안내드립니다. / 현장 판단은 항상 사람의 안전이 먼저입니다.

# 문을 상하지 않게 여는 이유
응급 후에도 집은 계속 쓰셔야 하니 문과 도어락이 상하지 않아야 합니다. / 비파손 방식으로 먼저 시도하고, 시간이 중요한 때는 상황을 보고 판단합니다.
진행 방식은 [이용안내](guide.html)와 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 일이 지나간 뒤에 해둘 점검
- 응급 때 알게 된 불편한 점을 가족과 함께 정리
- 비밀번호 공유 범위를 다시 정하고 번호 바꾸기
- 도어락 배터리를 새것으로 교체
- 예비 열쇠 보관 위치를 모두가 아는지 확인
- 휴대폰 긴급 연락처에 가족과 관리사무소 등록
한 번 겪고 나면 같은 일이 생겨도 훨씬 차분하게 대응할 수 있습니다. / 평소에 가끔 점검하는 습관을 들이세요.

# 연무동 말고 수원 어디든 갑니다
연무동 외에도 수원 전 지역을 24시간 다닙니다. / 동네별 안내는 [수원시 출장열쇠](suwon.html) 페이지에서 볼 수 있습니다.
다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
