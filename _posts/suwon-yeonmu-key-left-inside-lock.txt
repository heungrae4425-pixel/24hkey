# 연무동에서 안쪽 열쇠 때문에 문이 안 열릴 때
연무동은 수원역과 성균관대역 쪽을 오가는 분들이 많이 사는 동네입니다. / 출퇴근길에 집에 도착해 열쇠를 꺼냈는데 구멍에 들어가지 않는 일이 의외로 자주 생깁니다.
열쇠가 맞는데도 안 들어간다면 안쪽 실린더에 열쇠가 꽂힌 채 돌려져 있을 가능성을 먼저 생각해 보세요. / 이 글은 그런 경우의 원인, 해볼 수 있는 것, 하면 안 되는 것을 순서대로 적었습니다.
@ 연무동 현관문 안쪽 열쇠 꽂힘 출장열쇠

# 안쪽에 열쇠가 꽂혀 있으면 왜 바깥에서 안 될까
일부 현관문 잠금장치는 안쪽에서 열쇠를 꽂은 채 돌려 두면 바깥쪽 열쇠가 끝까지 들어가거나 돌아가는 것을 막습니다. / 안쪽 열쇠가 걸림쇠 역할을 하면서 실린더 내부 부품을 한쪽으로 밀어 두기 때문입니다.
도어락이 달린 집이라도 보조키 자리에 열쇠가 꽂혀 돌아가 있으면 같은 일이 생깁니다. / 번호는 맞게 눌렀는데 문이 꿈쩍도 하지 않는다면 이 경우일 수 있습니다.

# 이런 순간에 많이 생깁니다
- 가족 중 한 명이 안에서 열쇠로 잠그고 잠들어 있는 경우
- 밤에 안쪽 열쇠를 돌려 둔 채 아침에 그대로 나간 경우
- 아이가 장난으로 안쪽 열쇠를 돌려 놓은 경우
- 열쇠를 안쪽에 꽂아 둔 채 문을 닫고 잠깐 나온 경우
집 안에 사람이 있는지 없는지에 따라 대처가 달라집니다. / 안에 누가 있다면 문 너머로 불러 안쪽 열쇠를 돌려 달라고 부탁하는 것이 가장 빠릅니다.
이런 일은 대개 서두르는 아침이나 늦은 밤처럼 마음이 급할 때 생깁니다. / 평소 습관대로 한 동작인데 그날따라 열쇠 위치가 달랐던 경우가 많습니다.

# 전화 전에 먼저 해볼 확인 순서
먼저 집 안에 사람이 있는지 확인하고, 있다면 휴대폰으로 연락해 안쪽 열쇠를 반대로 돌리게 해 주세요. / 안에서 열쇠를 반대로만 돌려도 바깥 열쇠가 들어가는 경우가 많습니다.
안에 아무도 없다면 다음 순서로 살펴보세요.
- 바깥 열쇠를 끝까지 넣지 말고 반쯤 넣었다가 뺐다 다시 넣어 보기
- 열쇠 모양이 맞는지, 휘거나 닳지 않았는지 보기
- 번호판이 켜지는지, 보조키 구멍이 하나인지 둘인지 확인하기
여기까지 해서 안 되면 억지로 돌리지 말고 멈추는 것이 좋습니다.
열쇠가 안 들어갈 때 구멍 안을 손전등으로 비춰 보는 것도 도움이 됩니다. / 안쪽으로 뭔가 걸려 있거나 이물질이 보이면 그대로 알려 주세요.

# 열쇠를 힘으로 돌리면 부러집니다
안 들어가는 열쇠를 세게 밀어 넣거나 비틀면 열쇠가 휘거나 구멍 안에서 부러질 수 있습니다. / 열쇠 조각이 박히면 단순한 잠김이 부품 문제로 번집니다.
열쇠 구멍에 윤활제나 기름을 급하게 뿌리는 분도 있는데, 먼지가 엉겨 더 뻑뻑해지는 일이 많습니다. / 그대로 두고 연락 주시는 편이 안전합니다.
@ 연무동 열쇠 구멍 실린더 점검 모습

# 문틈으로 도구를 넣는 것도 피해 주세요
카드나 얇은 철사로 문틈을 벌리면 문틀 고무와 도어락 외관이 상하고, 잠금 부품이 더 깊이 물릴 수 있습니다. / 한 번 상한 문틀은 나중에 소음과 바람 새는 소리로 남기도 합니다.
안쪽 열쇠가 꽂힌 상태에서는 어차피 한쪽이 막혀 있어서 무리한 시도가 결과를 바꾸지 못하는 경우가 많습니다.
문틀과 문 사이 틈이 평소보다 좁거나 넓어 보이면 문이 처졌을 수도 있습니다. / 그런 경우에는 열쇠 문제와 문틀 문제가 겹쳐 있을 수 있어 현장에서 함께 봅니다.

# 안쪽 열쇠가 꽂힌 문은 이렇게 엽니다
출장열쇠가 도착하면 먼저 문 종류와 잠금 구조를 보고, 상하지 않는 방법부터 차례로 시도합니다. / 안쪽 열쇠를 건드리지 않고 걸쇠만 풀 수 있는지부터 봅니다.
방법이 정해지면 문 열기 전에 비용부터 말씀드립니다. / 문을 끝내 열지 못하면 비용은 받지 않습니다.
자세한 개방 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 집 안에 사람이 있을 때는 이렇게
안에서 응답이 없으면 먼저 그 사실을 전화로 알려 주세요. / 어르신이나 아이가 혼자 있다면 시간이 중요하니 가장 먼저 말씀해 주세요.
문 너머로 안정적인 목소리로 계속 말을 걸고, 안쪽에서 열쇠를 돌릴 수 있는지 물어봐 주세요. / 상황이 급해 보이면 119 연락을 먼저 하셔도 됩니다.
안에서 응답이 있으면 열쇠를 돌리는 방향을 천천히 말로 알려 주세요. / 잠기는 쪽과 풀리는 쪽이 헷갈리면 열쇠를 아예 빼 보라고 하는 것도 방법입니다.

# 연무동 위치를 알려 주실 때
단독 주택과 다세대, 아파트가 섞여 있는 동네라 층과 호수, 출입구 모양을 알려 주시면 도착이 빨라집니다.
- 건물 종류와 층, 호수
- 수원역 쪽인지 성균관대역 쪽인지 대략적인 방향
- 안쪽에 열쇠가 꽂혀 있을 것 같은지, 안에 사람이 있는지
- 문 앞 열쇠 구멍 사진이 있으면 문자로 보내기

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인하는 절차가 있습니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁하는 방법이 있습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 열고 난 뒤에 꼭 점검할 것
문이 열리면 안쪽 열쇠 구멍이 부드럽게 도는지, 바깥 열쇠가 끝까지 들어가는지 같이 확인합니다. / 열쇠가 닳았다면 복사 열쇠를 새로 맞추는 방법도 말씀드립니다.
잠금 부품이 무뎌졌거나 자꾸 걸린다면 [도어락 수리](doorlock-repair.html)로 손볼 수 있는지 먼저 봅니다. / 너무 오래돼 불안하면 그때 [도어락 교체](doorlock-replace.html)를 안내해 드립니다.
안쪽 실린더에 열쇠를 꽂은 채 돌려 두는 습관이 있다면 이번 기회에 어디에 두는지 가족과 정해 두세요. / 정리만 해도 같은 일이 훨씬 줄어듭니다.

# 같은 일을 줄이는 생활 습관
- 밤에 안쪽 열쇠로 잠갔다면 아침에 나가기 전 반드시 원위치로 돌리기
- 안쪽 열쇠는 꽂아 둔 채 두지 말고 정해진 자리에 걸어 두기
- 가족 모두에게 안쪽 열쇠를 돌려 두면 바깥에서 못 연다는 사실 알려 주기
- 여분 열쇠는 한 벌 따로 믿을 만한 곳에 맡기기
잠금 방식이 헷갈린다면 [이용안내](guide.html)에서 출장 순서를 먼저 보셔도 좋습니다.

# 연무동 말고도 수원 어디든 갑니다
연무동 바로 옆 동네는 물론 영통동, 매탄동, 인계동, 광교동 등 수원 안이면 24시간 출동합니다. / 수원의 다른 동네 소식은 [수원 출장열쇠](suwon.html) 페이지에 있습니다.
다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
@ 수원 출장열쇠 연무동 현관문 출동
