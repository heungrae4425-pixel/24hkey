# 연무동 신혼집, 짐보다 먼저 도어락을 보세요
연무동에서 새 살림을 시작하는 분들은 수원역 쪽 생활권을 오가며 이사 날짜를 맞추느라 바쁩니다. / 가구와 가전은 꼼꼼히 챙기는데 정작 매일 쓰는 현관 도어락은 마지막까지 미뤄지는 경우가 많습니다.
이 글은 신혼집에 들어가기 전후에 도어락에서 무엇을 확인하면 좋은지 순서대로 적었습니다. / 문제가 생기면 [수원 출장열쇠](suwon.html)에 연락하는 방법도 함께 정리했습니다.
@ 연무동 신혼집 현관 도어락 입주 점검

# 전에 살던 사람의 번호가 남아 있을 수 있습니다
새 집이라고 해도 이전 세입자나 공사 인력, 중개 과정에서 쓰던 번호가 그대로 남은 경우가 있습니다. / 입주 전에 모르는 번호가 몇 개나 등록돼 있는지 확인해 두는 것이 좋습니다.
등록된 번호와 카드가 여러 개라면 새로 정리하는 편이 마음 편합니다. / 정리 방법은 제품마다 달라 설명서의 등록 삭제 항목을 먼저 보세요.

# 입주 당일 문 앞에서 확인할 다섯 가지
- 번호를 눌렀을 때 소리가 나고 문이 한 번에 열리는지
- 안쪽에서 손잡이나 버튼으로 잠그고 푸는 동작이 부드러운지
- 보조키가 있다면 돌아가는지
- 건전지 칸을 열어 건전지 상태 확인
- 열쇠나 카드가 몇 개 있는지 세어 보기
이 다섯 가지만 보아도 입주 날 문 앞에서 당황할 일이 많이 줄어듭니다. / 한 가지라도 이상하면 짐을 들이기 전에 먼저 해결해 두세요. / 이삿짐이 들어온 뒤에는 문을 계속 열어 두어야 해서 점검할 틈이 거의 없습니다.
신혼집은 두 사람이 같이 쓰는 첫 집이라 열쇠와 카드가 몇 개인지 서로 알고 있는 것이 중요합니다. / 중개사나 전 집주인에게 받은 열쇠가 있다면 모두 모아 개수를 적어 두세요.

# 건전지는 이사 전에 새것으로
이사 당일에는 문을 하루에도 수십 번 여닫습니다. / 이때 건전지가 약하면 한창 짐을 나르는 중에 경고음이 울릴 수 있습니다.
건전지를 한꺼번에 새것으로 바꾸고 날짜를 적어 두면 한동안 신경 쓸 일이 없습니다. / 비상용 9V 건전지 하나는 부부 중 한 명의 가방에 넣어 두세요.

# 부부가 각자 쓰기 편한 번호와 카드 정하기
번호는 두 사람이 모두 외우기 쉬우면서 생일이나 전화번호 같은 남이 짐작하기 쉬운 숫자는 피하는 것이 좋습니다. / 문 앞에서 한 사람이 번호를 잊었을 때 대신 쓸 수단도 정해 두면 든든합니다.
- 번호는 두 사람이 정하고 서로 메모 없이 말할 수 있는지 확인
- 카드나 태그를 쓰는 제품이면 한 사람당 하나씩 등록
- 남는 카드 하나는 집 밖 안전한 곳에 따로 보관
@ 도어락 비밀번호 등록과 카드 설정 화면

# 이삿짐 업체와 가족에게 번호를 알려줄 때
이삿날에는 짐을 나르는 분들이 드나들어야 해서 번호를 알려줘야 할 때가 있습니다. / 이때는 사용 후 바로 지울 수 있는 임시 번호를 쓰면 훨씬 안전합니다.
부모님이나 친구에게 알려준 번호는 입주 한두 주 뒤 한 번 더 점검해 보세요. / 필요 없는 번호는 그때 정리하면 됩니다.
이삿짐 업체 분들이 번호를 알게 된 채로 두면 마음에 걸리기 마련입니다. / 사용이 끝나는 대로 바로 바꾸는 습관이 가장 확실합니다.
임시 번호 기능이 없다면 이사가 끝난 날 본 번호를 바꾸는 것이 가장 단순합니다.

# 보조키와 걸쇠 연결 상태 보기
새집 문은 겉보기엔 멀쩡해도 실제로 써 보면 작은 불편이 하나둘 드러납니다. / 입주 전 한 번만 직접 여닫아 보면 미리 알 수 있습니다.
신혼집은 입주 전 청소와 도배를 마친 직후라 문틀에 먼지가 쌓이거나 도배지가 닿아 문이 뻑뻑한 경우가 있습니다. / 도어락만 보지 말고 문이 틀에 부드럽게 들어가는지도 확인해 보세요.
보조키를 돌렸을 때 걸쇠가 한 번에 들어가고 풀리면 정상입니다. / 중간에 걸리는 느낌이 있다면 억지로 돌리지 말고 점검을 받는 쪽이 낫습니다.

# 입주 날 문이 안 열릴 때 하지 말 것
- 손잡이를 세게 당기거나 문을 발로 차는 것
- 드라이버나 카드로 문틈을 벌리는 것
- 번호를 계속 눌러 보는 것 (여러 번 틀리면 입력이 한동안 막힘)
새집 문에 흠이 생기면 속상함이 오래갑니다. / 서너 번 해보고 안 되면 멈추고 상황을 알려주세요.

# 도어락을 새로 달고 싶을 때 확인할 것
신혼집이 되면서 지문이나 카드 도어락으로 바꾸고 싶은 분들이 많습니다. / 기존 문의 두께와 보조키 위치, 타공 크기에 따라 달 수 있는 제품이 달라집니다.
먼저 현재 도어락 사진을 보내주시면 맞는 제품을 말씀드리기 쉽습니다. / 자세한 내용은 [도어락 설치](doorlock-install.html) 안내에 적어 두었습니다.

# 연락하실 때 알려주실 내용
- 연무동 어느 쪽인지, 호수와 가까운 역 방향
- 지금 문 상태 (번호판 꺼짐, 경고음, 열쇠가 안 돌아감)
- 도어락 모양과 보조키 유무
- 안에 사람이나 반려동물이 있는지
- 이사 일정이 있다면 시간대
사진 한 장이면 대부분 설명이 짧아집니다. / 이사 업체 일정과 겹치는 시간이라면 그 사실도 함께 알려주세요. / 시간에 쫓기는 상황을 알면 출동 순서를 맞추는 데 도움이 됩니다.
@ 현관문과 도어락 상태를 사진으로 전달

# 도착하면 사시는 분인지부터 확인합니다
입주 직후라 신분증 주소가 아직 이전 집일 수 있습니다. / 그런 경우 계약서, 입주 안내문, 관리사무소 확인 중 가능한 것을 말씀해 주세요.
이웃과 집 주인을 모두 지키는 절차라 번거로워도 꼭 필요합니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 종류와 문 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
진행 순서는 [이용안내](guide.html)에, 문 여는 방식은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 열고 난 뒤 설정까지 같이 마무리 및 출동 지역
문이 열리면 도어락이 잘 잠기는지 확인하고 번호를 새로 정리하는 것까지 도와드립니다. / 기존 번호는 지우고 두 사람이 정한 번호만 남깁니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 작동이 불안하면 [도어락 수리](doorlock-repair.html)를 먼저 보고, 너무 오래됐으면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.


연무동 말고도 영통동, 광교동, 인계동, 권선동 등 수원 안이면 동네 상관없이 24시간 출동합니다. / 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 볼 수 있습니다.
