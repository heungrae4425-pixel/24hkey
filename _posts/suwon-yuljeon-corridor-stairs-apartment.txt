# 같은 도어락인데 집마다 고장이 다른 까닭
율전동은 성균관대역 쪽으로 오가는 분들이 많아 원룸부터 아파트까지 주거 형태가 다양합니다. / 같은 제품을 달아도 복도식 집과 계단식 집은 문이 겪는 환경이 꽤 다릅니다.
문을 여는 사람의 수, 바깥 바람과 비, 복도를 오가는 짐과 먼지가 모두 다르기 때문입니다. / 그래서 고장 나는 부위도 조금씩 달라집니다.
이 글은 구조별로 흔한 문제와 점검 요령을 적은 것입니다. / 내 집이 어느 쪽에 가까운지 보고 필요한 부분만 읽으셔도 됩니다.
@ 율전동 복도식 계단식 아파트 현관문 점검

# 먼저 우리 집 구조를 가늠해 보세요
복도식은 한 층에 여러 집의 현관이 한 줄로 이어진 구조입니다. / 계단식은 계단과 엘리베이터 주변에 두세 집만 마주 보는 구조입니다.
복도식은 바깥 공기와 직접 맞닿는 복도 쪽이 열려 있는 경우가 많습니다. / 계단식은 홀이 안쪽에 있어 바람과 비의 영향이 상대적으로 적습니다.
구조를 알아 두면 문제가 생겼을 때 원인을 짐작하기 쉬워집니다. / 이 구분은 점검 우선순위를 정하는 데 도움이 됩니다. / 복도식은 물기와 바람, 계단식은 경첩과 문틀을 먼저 본다고 기억하시면 편합니다.

# 복도식 현관, 바람과 습기가 먼저 닿습니다
복도가 바깥으로 열려 있으면 장마철 비바람이 도어락에 바로 닿습니다. / 겨울 찬바람 때문에 번호판이 느려지는 일도 복도식에서 더 자주 말씀하십니다.
이럴 때는 번호판을 마른 천으로 자주 닦고, 물기가 남지 않게 해 주세요. / 도어락 윗부분에 빗물이 고이는 구조라면 틈을 한 번 살펴보는 것도 좋습니다.
복도를 지나다니는 사람이 많아 사생활 걱정으로 비밀번호를 자주 바꾸는 분도 많습니다. / 바꾸는 습관은 좋지만 가족이 모르는 일이 없게 같이 공유해야 합니다.

# 계단식 현관, 문이 조용해서 오히려 놓칩니다
계단식은 바깥 환경이 순해 도어락 외관은 오래 깨끗한 편입니다. / 그래서 오히려 경첩이나 문틀 변형 같은 구조적인 문제를 늦게 알아챕니다.
엘리베이터 홀이 가까워 쾅 닫는 소리를 들은 이웃이 말해 줘서야 아는 경우도 있습니다. / 문이 닫히는 소리가 이상하면 그날 바로 확인해 보세요.
문을 닫을 때 걸쇠가 문틀에 딱 맞게 들어가는지 소리로 들어 보는 연습이 도움이 됩니다.
@ 율전동 계단식 아파트 현관 도어락 경첩 확인

# 방화문 무게가 문에 미치는 영향
아파트 현관문은 방화 기능 때문에 생각보다 무겁습니다. / 무거운 문은 경첩에 하중이 계속 걸려 시간이 지나면 조금씩 처집니다.
처진 문은 걸쇠가 문틀 홈의 위쪽이나 아래쪽에 닿아 뻑뻑하게 잠깁니다. / 열쇠가 안 돌아가거나 번호는 맞는데 열림이 늦어지는 증상으로 나타납니다.
복도식이든 계단식이든 문의 무게는 같으니 경첩 점검은 구조와 상관없이 필요합니다. / 문틀 간격이 위아래로 다르게 보이면 처짐을 의심해 볼 만합니다. / 닫힌 문을 안쪽에서 보면서 위쪽 틈과 아래쪽 틈을 비교해 보면 눈으로도 알 수 있습니다.

# 택배 짐과 문이 부딪치는 일
복도식에서는 짐을 든 채로 문을 몸으로 밀며 들어오는 일이 잦습니다. / 문이 벽이나 난간에 부딪히면 경첩과 도어클로저에 충격이 쌓입니다.
한 번 부딪혔다고 바로 고장 나지는 않지만 반복되면 문이 덜 닫히기 시작합니다. / 문 뒤에 벽 보호 고무를 붙여 두는 것도 간단한 예방법입니다.
짐을 들고 문을 닫을 땐 손잡이를 놓치기 쉬우니 천천히 닫히도록 해 주세요. / 바람이 센 날 복도식에서는 문이 세게 닫히는 일도 있어 손으로 한 번 받쳐 주는 게 좋습니다.

# 이웃 문과 헷갈려 생기는 일들
복도식은 문이 한 줄로 늘어서 있어 같은 모양의 현관문이 이어집니다. / 술 한잔한 늦은 밤이나 피곤한 퇴근길에는 층이나 호수를 착각하는 일이 생깁니다.
번호를 여러 번 틀리면 도어락이 입력을 막기도 합니다. / 우리 집 문이 맞는지 호수를 한 번 더 보는 습관이 있으면 헛수고를 줄입니다.
문 옆에 작은 표식을 붙여 두면 어두운 복도에서도 쉽게 구별됩니다. / 이름처럼 개인 정보가 드러나는 표식은 피하는 게 좋습니다.

# 문이 안 열릴 때 구조별 확인 순서
- 번호판 불빛이 켜지는지 먼저 확인
- 복도식이라면 번호판에 물기나 서리가 있는지 확인
- 계단식이라면 문을 살짝 밀면서 손잡이를 돌려 걸쇠 상태 확인
- 안쪽 보조키나 걸쇠를 잠그고 나온 건 아닌지 떠올려 보기
이 순서로 보면 전화하기 전에 원인을 어느 정도 좁힐 수 있습니다. / 억지로 당기거나 드라이버를 쓰는 것은 피해 주세요.

# 밤늦게 복도에서 전화하실 때
복도는 소리가 울려 한밤에 통화하면 이웃에게 방해될 수 있습니다. / 가능하면 계단이나 로비 쪽으로 자리를 옮겨 전화를 주세요.
위치는 건물 이름과 동, 호수, 가까운 역 방향을 알려 주시면 빠릅니다. / 성균관대역 쪽인지 다른 방향인지 대략 말씀해 주세요.
도어락 사진이 있으면 장비 준비가 쉬워집니다. / 집 안에 아이나 반려동물이 있다면 꼭 먼저 말씀해 주세요.

# 도착하면 사시는 분인지부터 확인합니다
문을 여는 일이라 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있으면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 이웃과 건물 전체를 위한 절차이니 양해 부탁드립니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요. / 집 안에 가족이 있다면 안쪽에서 신분증을 문틈으로 보여 주는 방법도 있습니다.
@ 율전동 24시 출장열쇠 신분 확인 후 개문

# 비용은 시작 전에 먼저 알려드립니다
문 상태를 보고 비용을 먼저 말씀드리고, 동의하실 때만 시작합니다. / 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다.
자세한 진행은 [이용안내](guide.html)에 적어 두었고, 개문 방법은 [현관문 개문](door-open.html) 페이지에 있습니다.

# 문을 열고 난 뒤 구조에 맞는 관리
열린 뒤에는 도어락이 잘 잠기고 열리는지 함께 확인합니다. / 복도식이라면 물기 방지, 계단식이라면 경첩 점검에 더 신경을 씁니다.
남은 배터리가 오래된 것이면 이 기회에 전부 새것으로 바꿔 드립니다. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 해결하고, 너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
비밀번호를 바꾼 경우 가족에게 꼭 알려 주세요. / 새 번호는 안쪽에서 직접 등록하시도록 안내해 드립니다.

# 율전동 말고 수원 어디든
율전동 옆 천천동, 조원동은 물론 수원 전 지역을 다닙니다. / 성균관대역, 수원역, 영통역 근처 어디서든 연락 주세요.
다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리했습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
