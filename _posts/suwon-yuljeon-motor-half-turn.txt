# 윙 하다가 멈추는 소리, 이런 증상입니다
율전동은 성균관대역 쪽 생활권이라 학생과 직장인이 많이 오가는 동네입니다. / 번호를 누르면 모터가 윙 하고 돌다가 중간에 멈추고 문이 안 열리는 증상으로 연락이 옵니다.
소리는 나는데 걸쇠가 끝까지 빠지지 않는 모습입니다. / 완전히 고장 난 것은 아니라 원인을 가려 대응하면 해결이 쉬운 경우도 있습니다.
이 글은 율전동에서 도어락 모터가 반쯤 돌다 멈출 때 확인할 순서를 정리했습니다. / 마지막에는 [수원 출장열쇠](suwon.html)가 오면 어떻게 진행하는지도 적었습니다.
@ 율전동 도어락 모터 반쯤 돌다 멈춤

# 모터가 멈추는 이유 네 가지
모터가 도는 중간에 멈추는 이유는 크게 나뉩니다. / 원인에 따라 해결 방법이 다릅니다.
- 배터리 전력이 부족해 모터가 끝까지 힘을 내지 못하는 경우
- 걸쇠가 문틀 받침판에 강하게 물려 있어 힘이 모자란 경우
- 문이 처져서 걸쇠와 받침판의 위치가 맞지 않는 경우
- 모터나 안쪽 기어가 마모된 경우
배터리와 문틀 문제는 집에서 확인할 수 있고, 기어 문제는 전문가가 봐야 합니다.

# 배터리가 먼저입니다
모터는 전기를 가장 많이 쓰는 부품입니다. / 배터리가 약해지면 번호판은 켜져도 모터를 끝까지 돌릴 힘이 모자랄 수 있습니다.
안쪽 배터리 덮개를 열어 건전지를 전부 새것으로 바꿔 보세요. / 일부만 바꾸면 힘이 균일하지 않아 증상이 그대로일 수 있습니다.
새 건전지를 넣고 바로 정상으로 돌아오면 원인이 배터리였던 것입니다. / 건전지는 서로 종류와 새것 여부를 맞춰서 넣어야 합니다.

# 문을 밀며 눌러보기
번호를 누르는 동안 문을 바깥쪽에서 살짝 밀거나 당겨 보세요. / 걸쇠가 문틀에 눌려 있다면 힘을 빼 주는 순간 모터가 마저 돌아갑니다.
이 방법으로 열리면 걸쇠 쪽 압력 문제가 원인입니다. / 이후에는 문이 반복해서 같은 증상을 보일 수 있으니 문틀 점검이 필요합니다.
열리지 않을 때 억지로 계속 반복하면 모터가 과열되거나 기어가 상합니다. / 서너 번 시도해 보고 안 되면 멈추세요.
@ 현관문 걸쇠와 받침판의 위치 확인

# 문틀 처짐을 어떻게 알아보나
문을 닫은 채 걸쇠 부분을 보면 위치가 한쪽으로 쏠려 있는 경우가 있습니다. / 문과 문틀 사이 틈이 위쪽과 아래쪽에서 다르게 보이면 처짐 신호입니다.
문을 닫을 때 걸쇠가 받침판 구멍 가장자리를 긁는 소리가 나기도 합니다. / 손으로 문을 가볍게 들어 올리듯 밀면서 닫아 보면 느낌이 달라집니다.
이런 증상은 [도어클로저와 경첩](doorlock-repair.html) 점검과 함께 보는 것이 맞습니다. / 도어락만 바꿔서는 해결되지 않을 수 있습니다.

밖에서는 안 열려도 안쪽에서는 손잡이로 열리는 경우가 많습니다. / 안쪽 손잡이까지 반쯤 돌다 걸린다면 걸쇠 자체가 끼어 있을 수 있습니다.
이때는 손잡이를 돌린 채 문을 안쪽으로 살짝 밀고 당기며 틈을 만들어 보세요. / 힘을 세게 주면 손잡이 축이 휠 수 있어 부드럽게 해야 합니다.
안쪽에서도 전혀 움직이지 않으면 내부 부품이 꼈다고 보고 전화 주세요.

# 하지 말아야 할 행동
번호를 연속으로 계속 누르는 것은 피하세요. / 모터가 쉬지 못해 열이 나고 배터리도 더 빨리 닳습니다.
드라이버로 도어락 틈을 벌리거나 손잡이를 뜯으려는 시도는 하지 마세요. / 외관이 상하고 안쪽 부품이 어긋나 수리가 어려워집니다.
윤활제를 도어락 안쪽으로 뿌리는 것도 권하지 않습니다. / 전자 부품에 기름이 스며들면 더 큰 고장이 됩니다.

# 이런 상황에서 전화가 옵니다
퇴근길에 번호를 눌렀더니 윙 하다가 멈춰 문 앞에서 한참 서 계시는 경우가 많습니다. / 몇 번 반복하다 결국 연락 주시는 분이 대부분입니다.
아침에는 열렸는데 저녁에 같은 증상이 나타나 놀라는 분도 계십니다. / 하루 중 기온이 달라지면 배터리 힘이나 문 상태가 바뀌기도 합니다.
자취방 도어락에서 이 증상이 생겨 집주인께 연락하기 곤란하다는 분도 있습니다. / 상황을 말씀해 주시면 어떻게 정리하면 좋을지 같이 이야기해 드립니다.

# 전화하실 때 알려주세요
율전동은 학생이 많이 사는 건물도 많아서 건물 형태를 알려주시면 도착이 빨라집니다. / 가까운 큰길이나 방향을 짧게 말씀해 주세요.
- 동, 호수와 건물 형태
- 모터 소리가 어느 정도 나고 어디서 멈추는지
- 번호판 상태와 경고음 유무
- 최근에 배터리를 교체했는지
- 집 안에 아이나 반려동물이 있는지
소리를 휴대폰으로 짧게 녹음해 두시면 원인을 가늠하는 데 도움이 됩니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 자취방이라면 건물 관리인의 확인도 도움이 됩니다.
확인이 어려우면 작업을 할 수 없는 점은 양해 부탁드립니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
도어락 상태를 보고 어떻게 진행할지 먼저 설명드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품 교체가 필요하면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열린 뒤 도어락을 어떻게 판단하나
문이 열린 뒤에는 모터가 끝까지 돌아가는지 여러 번 시험합니다. / 배터리를 새것으로 바꿔도 같은 증상이 남는지 확인하는 것이 중요합니다.
기어나 모터 문제로 판단되면 [도어락 수리](doorlock-repair.html)가 되는지부터 봅니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
너무 오래되어 부품 구하기가 어렵다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 문 여는 방법이 궁금하시면 [현관문 개문](door-open.html) 페이지를 참고하세요.

# 재발을 줄이는 습관
모터가 힘들어하기 전에 신호를 읽는 것이 중요합니다. / 평소와 다른 소리가 나기 시작하면 미루지 마세요.
- 배터리는 부분 교체가 아니라 전부 새것으로
- 문을 닫을 때 세게 닫지 않기
- 걸쇠가 문틀에 긁히면 경첩 점검
- 모터 소리가 느려지면 그날 배터리부터 확인
이런 습관만으로도 문 앞에서 막히는 일이 많이 줄어듭니다.

# 율전동 말고 수원 어디든 갑니다
율전동 옆 정자동, 천천동, 조원동, 영통동도 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
수원에서 다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
@ 율전동 24시 출장열쇠 도어락 점검

? 자취방인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 부품 교체는 집주인과 상의하시길 권합니다.
? 밤늦게도 오시나요? | 24시간 받습니다. 시간 신경 쓰지 말고 전화 주세요.
