# 어떤 도어락을 달아야 할지 막막할 때
율전동에서 도어락을 새로 달려고 알아보면 종류가 너무 많아 고르기 어렵습니다. / 지문, 카드, 번호, 앱까지 방식이 섞여 있어 처음엔 비교하기도 힘듭니다.
이 글은 수원 장안구 율전동 쪽 원룸, 빌라, 아파트에서 도어락을 고민하는 분들을 위해 기준을 정리했습니다. / 광고 문구보다 우리 집 생활에 맞는지부터 따져 보세요.
@ 율전동 지문 도어락 선택 출장열쇠

# 번호키가 가장 무난합니다
숫자만 누르면 되니 열쇠나 카드를 들고 다닐 필요가 없습니다. / 처음 도어락을 쓰는 분이나 가족 모두에게 쉽게 알려 줄 수 있는 방식입니다.
다만 번호를 누르는 모습을 남이 볼 수 있어서 습관을 조금 조심해야 합니다. / 번호판에 손때가 남는 것도 신경 쓰이는 부분입니다.

# 지문은 어떤 집에 맞을까
손이 자주 바쁘거나 아이가 번호를 헷갈리는 집에서 편합니다. / 손가락만 대면 열려서 열쇠나 카드를 찾지 않아도 됩니다.
손이 젖거나 거칠 때, 손에 상처가 있을 때는 인식이 잘 안 되기도 합니다. / 그래서 지문 제품도 번호 입력을 같이 쓰는 경우가 대부분입니다.
@ 수원 율전동 출장열쇠 도어락 설치

# 카드키와 태그는 이럴 때 좋습니다
번호나 지문 없이 카드만 대면 되어 아이나 어르신에게 쉽습니다. / 분실하면 새로 등록해야 하니 여분을 어디 둘지 정해 두세요.
원룸이나 자취방은 카드 여러 장을 관리하는 부담이 있을 수 있습니다. / 이사 갈 때 카드를 어떻게 정리할지도 같이 생각해 두세요.

# 앱이나 스마트폰 연동은 필요한가
밖에서 문 상태를 확인하거나 임시 번호를 보내고 싶을 때 쓸모 있습니다. / 집을 자주 비우거나 손님이 오가는 경우에 편합니다.
다만 휴대폰 배터리, 앱 업데이트, 통신 문제에 영향을 받을 수 있습니다. / 기본 번호나 비상 수단은 꼭 따로 갖춰 두는 것이 안전합니다.

# 가족 구성부터 따져 보세요
혼자 사는 집, 부부, 아이가 있는 집, 어르신이 계신 집은 맞는 방식이 다릅니다. / 가장 서툴러 하는 사람이 쓰기 편한 방식을 기준으로 잡으세요.
- 혼자 사는 집: 번호나 지문, 비상 열쇠
- 아이가 있는 집: 카드나 지문, 번호 혼용
- 어르신이 계신 집: 큰 숫자판, 단순한 조작
- 세입자: 설치 전 집주인 확인

# 세입자라면 허락부터
셋집이면 도어락을 바꾸기 전에 집주인에게 알리는 것이 좋습니다. / 나중에 떼어 갈 수 있는 방식으로 설치할 수 있는지도 같이 물어보세요.
원래 달려 있던 도어락은 버리지 말고 보관해 두는 것이 안전합니다. / 이사 갈 때 원래대로 돌려놓아야 할 수도 있기 때문입니다.

# 문 두께와 보조키 확인이 먼저
제품이 마음에 들어도 문 두께나 구멍 모양이 맞지 않으면 설치가 어렵습니다. / 사진을 보내주시면 맞는 제품인지 미리 확인해 드립니다.
보조키를 유지할지, 도어락 하나로 단순하게 할지도 정해야 합니다. / 설치 순서는 [도어락 설치](doorlock-install.html)에서 설명합니다.

# 비용은 제품과 문을 보고 말씀드립니다
같은 지문 도어락이라도 문 상태에 따라 작업 내용이 달라집니다. / 현장에서 문과 제품을 보고 먼저 얼마인지 말씀드립니다.
괜찮다고 하시면 시작하고, 아니면 돌아갑니다. / 말없이 붙는 비용은 없습니다. 진행 방식은 [이용안내](guide.html)에 있습니다.

# 이미 달린 도어락을 바꾸는 경우
기존 도어락을 떼고 새 제품으로 바꾸는 것은 [도어락 교체](doorlock-replace.html)에서 안내합니다. / 구멍이 맞지 않으면 문을 손봐야 할 수도 있습니다.
교체 전에 현재 도어락 사진을 미리 찍어 두면 설명이 쉽습니다.

# 설치 후에 꼭 해볼 것
문을 닫고 번호와 지문을 몇 번씩 눌러 보며 잠기는지 확인합니다. / 카드나 지문은 가족이 직접 한 번씩 등록해 보세요.
비상 전원 단자 위치와 배터리 교체 방법도 알아 둡니다. / 경고음이 어떤 소리인지도 한 번 들어 두면 나중에 당황하지 않습니다.

# 보안 습관도 같이
번호는 생일이나 전화번호처럼 짐작하기 쉬운 숫자를 피하세요. / 처음 받은 임시 번호는 꼭 바꾸세요.
카드와 지문은 필요한 만큼만 등록하고, 이사 후에는 정리합니다. / 정기적으로 번호를 바꾸고 가족에게 바로 알리는 것이 좋습니다.

# 문 앞에서 막혔다면
새 도어락을 달기 전에 이미 문이 안 열리는 상황이면 먼저 문부터 엽니다. / 방법은 [현관문 개문](door-open.html)에서 설명합니다.
문을 못 열면 비용은 받지 않습니다. / 열고 난 뒤 설치 여부를 같이 정하시면 됩니다.

# 율전동 말고 수원 어디든 갑니다
장안, 팔달, 권선, 영통 등 수원 전 지역을 24시간 다닙니다. / 수원에서 다니는 동네는 [수원 출장 지역](suwon.html)에 정리해 두었습니다.
수원 밖은 [출장 지역](area.html) 지도에서 확인하세요.
