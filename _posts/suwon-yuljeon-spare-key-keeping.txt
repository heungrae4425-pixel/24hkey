# 여분 열쇠가 있어도 막히는 이유
수원 율전동은 성균관대역 쪽을 오가는 학생과 직장인이 많아 열쇠를 잃어버렸다는 전화가 자주 오는 생활권입니다. / 그런데 여분 열쇠를 어딘가에 두었는데도 막상 필요할 때 쓰지 못하는 경우가 의외로 많습니다.
어디에 뒀는지 기억나지 않거나, 맡긴 사람이 연락이 안 되거나, 아예 보관한 곳이 안전하지 않은 경우입니다. / 이 글은 율전동에서 여분 열쇠와 보조 카드를 어떻게 두면 좋은지 기준을 정리한 것입니다.
@ 율전동 여분 열쇠 보조 카드 보관 방법

# 흔하지만 피해야 할 보관 장소
예전부터 많이 쓰는 방법 중에는 요즘 기준으로 권하기 어려운 것들이 있습니다. / 편하다는 이유로 굳어진 습관일수록 한 번 되돌아볼 만합니다.
- 현관 신발장 위나 화분 밑처럼 문 바로 옆
- 소화전 함이나 가스 계량기 함처럼 공용 설비 안
- 우편함 안쪽이나 문틀 위
- 자전거나 오토바이 같은 밖에 세워 둔 물건
이런 곳은 누구든 마음만 먹으면 찾을 수 있습니다. / 열쇠가 어디에 있는지 한 번 알려진 곳은 보안으로서 의미가 줄어듭니다.

# 가까운 사람에게 맡길 때 알아둘 것
가족이나 가까운 친구에게 맡기는 방법은 가장 단순하고 믿을 만합니다. / 다만 맡기는 사람과 받는 사람이 같은 이해를 가져야 합니다.
맡은 사람이 열쇠를 어디에 두는지도 정리돼 있어야 합니다. / 예를 들어 맡은 분 집의 현관 근처 열쇠함에 아무 표시 없이 걸어 두는 것이 낫습니다.
열쇠에 주소나 호수를 적은 이름표를 달지 마세요. / 잃어버렸을 때 누구든 집을 알 수 있게 됩니다.
@ 율전동 현관 열쇠 맡기기 보관함 위치

# 맡길 곳을 고르는 기준 세 가지
어디에 맡기든 아래 기준으로 고르면 후회가 적습니다. / 편한 곳과 안전한 곳이 다를 때는 안전한 쪽을 택하는 게 좋습니다.
- 필요할 때 바로 연락이 닿는 사람이나 곳인지
- 열쇠가 어느 집 것인지 모르게 보관할 수 있는지
- 시간이 지나 사정이 바뀌어도 회수할 수 있는지
이 세 가지가 맞으면 대부분의 보관 방법이 무난합니다. / 하나라도 걸리면 다른 곳을 찾아보세요.

# 보조 카드와 태그는 더 조심스럽게
카드키나 태그는 열쇠보다 모양이 작아 잃어버리기 쉽습니다. / 게다가 어느 집 카드인지 겉으로는 알 수 없지만 가까이 대기만 하면 열린다는 점에서 열쇠와 위험이 다릅니다.
카드를 지갑이나 가방에 여러 장 넣어 다니면 분실했을 때 어떤 카드를 지워야 하는지 헷갈립니다. / 카드마다 사용하는 사람을 정해 두고 등록 현황을 기록해 두세요.
카드 한 장을 잃어버리면 그 카드만 삭제하고 새로 등록할 수 있는지 먼저 확인합니다. / 방법은 [도어락 교체](doorlock-replace.html) 전에 지금 제품에서 가능한지부터 알아보시면 됩니다.

# 대학가 원룸에서 특히 흔한 일
방학이 되어 집을 비우는 학생이 열쇠를 부모님께 맡기거나 룸메이트에게 넘기는 경우가 있습니다. / 이런 때 누가 마지막으로 열쇠를 갖고 있는지 불분명해지기 쉽습니다.
퇴실이나 이사 때 받은 열쇠 개수를 서로 확인하고 사진으로 남겨 두세요. / 개수가 안 맞으면 도어락 번호를 새로 정하는 것이 가장 깔끔합니다.
임대한 집이라면 열쇠를 어떻게 돌려줄지 미리 이야기해 두는 것도 좋습니다.

# 열쇠를 아예 안 두는 방법도 있습니다
번호 방식 도어락이 있다면 여분 열쇠 자체를 줄일 수 있습니다. / 대신 비밀번호를 가족과 나눠 쓸 때 관리하는 부분이 새로 생깁니다.
비상 상황용으로 비밀번호를 믿을 만한 가족 한 명만 알고 있게 하는 방법도 있습니다. / 임시 번호 기능이 있다면 필요할 때만 쓰고 바로 지우는 방식이 편합니다.
어느 쪽이든 완전히 편하면서 완전히 안전한 방법은 없고, 사정에 맞게 고르는 게 현실적입니다.
혼자 사는 분이라면 비상용으로 믿을 만한 가족에게 번호나 열쇠를 알려 두는 정도가 적당합니다. / 룸메이트와 함께 산다면 서로 어떤 방식으로 문을 쓰는지 처음에 한 번 이야기해 두면 나중에 오해가 줄어듭니다.
휴대폰 메모장에 비밀번호를 그대로 적어 두는 것은 권하지 않습니다. / 힌트만 적거나 가족에게 구두로 전하는 쪽이 낫습니다.
외출이 잦은 분은 열쇠를 늘 같은 주머니나 같은 자리에 두는 습관만 들여도 분실이 눈에 띄게 줄어듭니다. / 현관을 나서기 전에 열쇠, 휴대폰, 카드 세 가지를 손으로 한 번씩 만져 확인하는 것도 간단하면서 효과가 좋은 방법입니다.

# 그래도 열쇠를 잃어버렸다면
여분이 없는 상태에서 문 앞에 서게 되었다면 억지로 문을 건드리지 마세요. / 잠금장치를 건드리면 오히려 상태가 나빠질 수 있습니다.
먼저 집 안에 사람이 있는지, 보조키를 잠갔는지, 누가 여분을 가지고 있는지 확인해 보세요. / 그래도 안 되면 [출장열쇠 호출](key-call.html)로 연락 주시면 순서를 안내합니다.
@ 율전동 열쇠 분실 문 열기 출장

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있으면 학교나 건물 관리 쪽에서 거주 사실을 확인받을 수 있는지도 물어봅니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 먼저 안내합니다. / 괜찮다고 하시면 시작하고 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 문은 덜 상하는 방법부터 엽니다
열쇠가 없어서 문을 여는 일이라도 문과 도어락을 최대한 그대로 두는 것이 목표입니다. / 방법은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.
열린 뒤에는 도어락이 잘 잠기고 열리는지, 열쇠가 어디 있는지 한 번 더 점검합니다. / 열쇠를 분실한 경우라면 번호를 새로 정하거나 열쇠를 다시 맞추는 방법을 같이 말씀드립니다.

# 여분 열쇠 관리 체크리스트
이 정도만 해 두면 문 앞에서 막히는 일이 크게 줄어듭니다.
- 여분 열쇠는 집 밖 눈에 띄는 곳에 두지 않기
- 열쇠에 주소나 호수 적지 않기
- 맡긴 사람과 위치를 가족과 함께 정리해 두기
- 열쇠 개수를 사진으로 남기기
- 연 2회쯤 배터리와 카드 등록 현황 점검
점검할 때 문에 이상이 느껴지면 [도어락 수리](doorlock-repair.html)로 먼저 확인해 보세요.

# 율전동 말고 수원 어디든 갑니다
율전동 근처 천천동, 조원동, 화서동까지 다닙니다. / 수원 안이면 동네 상관없이 24시간 출동합니다.
[수원시 출장열쇠](suwon.html) 페이지에서 동네를 확인하실 수 있습니다. / 다른 지역은 [출장 지역](area.html)을 참고해 주세요.

? 열쇠 없이 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
