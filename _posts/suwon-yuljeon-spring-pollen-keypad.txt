# 꽃가루 날리는 계절, 번호판이 뻑뻑해졌다면
율전동은 성균관대역 가까이에 있어 학교 쪽으로 오가는 길에 나무와 화단이 많은 동네입니다. / 봄에 꽃가루가 날리고 황사까지 겹치면 현관문 번호판에도 얇은 먼지가 내려앉습니다.
어느 날부터 버튼이 한 번에 안 눌리거나, 세게 눌러야 반응하는 느낌이 들 수 있습니다. / 이 글은 꽃가루와 황사 뒤에 번호판 버튼이 안 눌릴 때의 원인과 확인 순서를 정리했습니다.
수원역 쪽으로 출퇴근하는 분도, 학교 근처에서 지내는 분도 봄 한철은 현관문에 먼지가 쌓이기 쉬운 계절입니다.
@ 율전동 번호판 먼지와 꽃가루
# 먼지가 번호판에 미치는 영향
버튼 틈새로 들어간 미세 먼지는 접점에 쌓이며 반응을 둔하게 만듭니다. / 터치식은 표면의 얇은 막이 감지를 방해하고, 버튼식은 눌린 뒤 튀어나오는 힘이 약해집니다.
꽃가루는 끈적한 성분이 있어 비와 만나면 더 달라붙기 쉽습니다.
봄비가 내린 다음 날 아침에 증상이 갑자기 심해지는 것도 이 때문입니다. / 황사는 입자가 고와 틈마다 스며들어 쌓입니다.
현관이 복도식이거나 바깥 바람이 직접 닿는 구조라면 쌓이는 속도가 더 빠릅니다. / 환기를 자주 하는 집도 비슷합니다.
# 고장인지 먼지인지 구분하기
- 봄철과 황사 뒤에만 증상이 심해졌는지
- 특정 숫자 몇 개만 둔한지, 전체가 느린지
- 배터리 경고음이나 안내 음성이 없었는지
- 닦으면 잠시 나아졌다가 다시 나빠지는지
앞의 두 가지가 맞으면 먼지 쪽일 가능성이 큽니다. / 경고음이 있었다면 배터리를 먼저 갈아 봐야 합니다.
봄에는 겨울 동안 약해진 배터리가 한계에 이르는 시기이기도 합니다. / 먼지와 배터리가 함께 원인일 때가 많아 두 가지를 같이 확인하는 편이 좋습니다.
# 청소 전에 알아 둘 것
도어락 청소는 표면만, 마른 천으로만 하는 것이 기본입니다. / 물이나 세정제를 틈으로 흘려 넣으면 회로가 상할 수 있습니다.
전원을 끌 수 있는 제품이 아니라면 청소 중에 오입력이 생길 수 있으니 문을 열어 둔 상태에서 하세요. / 닫힌 상태에서 하다가 잠금이 걸리는 일도 있습니다.
청소 도중 버튼을 눌러 입력이 쌓이면 잠시 입력 정지가 걸리는 제품도 있으니 천이 버튼을 스치지 않게 살살 닦으세요.
# 표면 먼지를 닦는 순서
부드러운 마른 천이나 안경닦이로 번호판 겉면을 한 방향으로 닦습니다. / 문지르기보다 먼지를 쓸어내는 느낌이 좋습니다.
황사처럼 입자가 거친 먼지는 천으로 힘주어 문지르면 표면에 긁힌 자국이 남을 수 있습니다. / 먼저 부드러운 붓이나 마른 솔로 털어낸 뒤 천으로 마무리하세요.
@ 율전동 도어락 버튼 청소 순서
# 버튼 사이 틈새는 어떻게 할까
틈새에 낀 가루는 가는 붓이나 부드러운 솔로 털어냅니다. / 이쑤시개나 바늘 같은 뾰족한 도구는 쓰지 않는 편이 안전합니다.
압축 공기를 쓴다면 멀리서 짧게 불어 먼지만 날리고, 가까이 대고 세게 불면 안쪽으로 밀려 들어갑니다. / 가능하면 청소기 호스를 바깥에서 대고 빨아내는 것이 낫습니다.
# 하지 말아야 할 행동
- 알코올이나 물을 번호판에 직접 뿌리는 것
- 버튼을 반복해서 세게 눌러 먼지를 뚫으려는 것
- 도어락 덮개를 열어 안쪽까지 청소하는 것
- 번호를 여러 번 틀려 입력 잠금을 거는 것
세게 누른다고 반응이 좋아지지 않고 오히려 버튼 고무가 상합니다. / 안쪽은 전문가가 볼 영역입니다.
청소하다 버튼 하나가 아예 들어가 버렸다면 더 누르지 말고 그대로 연락 주세요. / 억지로 빼려다 부품이 휘는 경우가 있습니다.
# 청소해도 안 눌린다면
먼지를 털어 내도 같은 숫자가 계속 안 눌린다면 접점이 닳았거나 오염이 깊은 경우입니다. / 이럴 때는 그 숫자를 쓰지 않는 번호로 바꾸는 방법도 있지만 임시 방편입니다.
근본 원인을 잡지 않으면 다른 숫자도 차례로 둔해질 수 있습니다.
배터리가 약한 상태에서는 먼지 영향이 더 크게 나타나므로 새 건전지로 교체해 보세요. / 그래도 안 되면 [도어락 수리](doorlock-repair.html)로 상태를 보는 편이 낫습니다.
# 문 앞에서 막혔을 때
번호가 안 눌려 문이 잠긴 채 밖에 서 있다면 9V 건전지를 비상 단자에 대 보세요. / 전원이 보강되면 둔하던 버튼이 반응하는 경우도 있습니다.
카드키나 열쇠가 있다면 그쪽으로 먼저 열어 보세요. / 모두 없거나 해도 안 열리면 전화로 상황을 알려 주세요.
도어락 사진과 번호판 상태를 함께 알려 주시면 출동 준비가 빨라집니다. / 집 안에 아이나 반려동물이 있다면 꼭 먼저 말씀해 주세요.
# 신분 확인은 꼭 거칩니다
문을 여는 일이므로 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없습니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.
번거로우실 수 있지만 이웃과 집 모두를 지키기 위한 절차입니다.
# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 필요한 작업을 설명한 뒤 비용을 말씀드립니다. / 동의하시면 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. 진행 순서는 [이용안내](guide.html)에서 보실 수 있습니다.
@ 율전동 출장열쇠 번호판 점검
# 봄이 지나고 하면 좋은 관리
- 꽃가루가 많은 시기에는 일주일에 한 번 번호판 겉면 털기
- 황사 예보가 있었던 날 저녁에 마른 천으로 닦기
- 현관 앞 먼지를 쓸어 바람에 날리지 않게 하기
- 배터리는 해가 바뀔 때 전부 교체하기
- 버튼이 둔해지면 그날 바로 상태 확인하기
이 정도만 해도 먼지가 오래 쌓이는 것을 막을 수 있습니다. / 작은 관리가 문 앞에서 막히는 일을 줄여 줍니다.
청소한 날짜를 달력에 표시해 두면 다음 시기를 잡기 쉽습니다.
가족 모두가 같은 방법으로 닦도록 알려 두면 한 사람이 힘주어 닦다 표면을 긁는 일도 막을 수 있습니다.
자주 쓰는 숫자 몇 개만 유난히 닳아 반응이 둔해지는 경우가 많으니 가끔 번호를 바꿔 주는 것도 방법입니다.
수리를 해도 버튼이 자꾸 둔해지는 오래된 번호판이라면 교체를 생각해 볼 수 있습니다. / [도어락 교체](doorlock-replace.html) 안내에 확인할 것을 정리해 두었습니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 문 두께와 보조키 위치를 먼저 보고 맞는 제품을 설명드립니다.
수리를 해도 버튼이 자꾸 둔해지는 오래된 번호판이라면 교체를 생각해 볼 수 있습니다.
# 율전동 말고 수원 어디든 갑니다
영통동, 천천동, 조원동, 정자동, 인계동까지 수원 안이면 24시간 출동합니다. / [수원시 출장열쇠](suwon.html) 페이지와 [출장 지역](area.html)에서 지역을 확인하시고, [현관문 개문](door-open.html) 설명도 참고하세요.
