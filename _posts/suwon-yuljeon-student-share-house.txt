# 율전동 자취방 문 앞에서 막혔다면
율전동은 성균관대역 가까이에 있어 학생과 사회초년생이 자취하는 방이 많습니다. / 고시원이나 쉐어하우스처럼 한 건물에 여러 사람이 사는 구조도 흔합니다.
늦게까지 공부하거나 일하고 돌아왔는데 방문이 안 열리면 당황스럽습니다. / 이 글은 자취방과 공동 주거 형태에서 문이 안 열릴 때 확인할 것을 적었습니다.
[수원 출장열쇠](suwon.html)를 부르기 전에 먼저 아래 내용을 보세요.

# 자취방 출입문은 구조가 다양합니다
같은 율전동이라도 방마다 문 종류가 다릅니다. / 어떤 방식인지 알아야 대처도 달라집니다.
- 건물 현관문이 따로 있고 방문에도 별도 도어락이 있는 경우
- 방문 하나만 있는 원룸형
- 고시원처럼 복도 문과 방문이 따로 있는 구조
- 쉐어하우스처럼 공동 현관 번호와 개인 방 열쇠를 따로 쓰는 경우
어느 문이 안 열리는지 정확히 알려주시면 전화 상담이 쉬워집니다.
@ 율전동 출장열쇠 자취방 도어락 개문

# 먼저 집주인이나 관리인에게 연락해야 하는 경우
자취방은 내 집이 아니라 빌려 쓰는 공간이라 확인할 것이 있습니다. / 건물 공용 출입문이나 방 열쇠를 집주인이 관리하는 경우가 많습니다.
- 공용 현관 비밀번호는 집주인이나 관리인이 알고 있는지
- 방 열쇠를 집주인이 여분으로 가지고 있는지
- 도어락 교체나 수리를 마음대로 해도 되는지
- 쉐어하우스라면 운영자에게 먼저 알리기
도어락 고장 수리나 교체는 집주인과 먼저 이야기해 두시는 것이 좋습니다. / 이 글은 법적 판단이 아니라 일반적인 확인 순서를 적은 것입니다.

# 문 앞에서 해볼 수 있는 것
무리한 시도는 피하되 간단한 확인은 해볼 수 있습니다.
- 번호키라면 번호를 천천히 한 번에 하나씩 눌러 보기
- 번호판이 안 켜지면 배터리 방전을 의심해 비상 전원 단자 찾아보기
- 열쇠 문이라면 열쇠가 끝까지 들어가는지, 돌아가는지 확인하기
- 룸메이트나 같은 층 사람이 안에 있는지 연락해 보기
열쇠가 부러졌거나 안 돌아가는 상태에서 억지로 돌리지 마세요. / 부러진 열쇠가 안에서 더 깊이 박힐 수 있습니다.

# 율전동 위치는 이렇게 알려주세요
위치를 정확히 알려주시면 도착 시간을 먼저 말씀드립니다.
- 율전동 건물 이름이나 도로명 주소, 몇 층 몇 호(방 번호)인지
- 성균관대역 방향인지 같은 대략적인 위치
- 어떤 문이 안 열리는지 (건물 현관인지 방문인지)
- 도어락 모양과 번호판 상태
- 안에 룸메이트나 반려동물이 있는지
집주인에게 연락이 닿았다면 그 내용도 알려주세요. / 사진을 문자로 보내주시면 필요한 장비를 챙겨 갑니다.
@ 율전동 도어락 방문 열기 출장

# 사는 사람이 맞는지 확인이 필요합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 임대 관련 서류, 관리인 확인 중 하나면 됩니다.
자취를 막 시작했다면 전입 신고나 우편물이 아직 없을 수 있습니다. / 이럴 때는 집주인이나 관리인 확인으로 대신하는 방법을 같이 찾아봅니다.
확인이 어려우면 작업을 할 수 없으니 계약서 사진 한 장은 휴대폰에 보관해 두시면 좋습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고 마음에 안 드시면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 문은 최대한 상하지 않게 엽니다
자취방 문은 집주인 재산이라 상하지 않게 여는 것이 더 중요합니다. / 덜 상하는 방법부터 차례로 해봅니다.
도어락 종류와 문 상태에 따라 걸리는 시간은 다릅니다. / 자세한 설명은 [현관문 개문](door-open.html) 페이지에 있습니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.

# 쉐어하우스에서 지켜야 할 것
여러 사람이 같이 쓰는 집은 비밀번호가 쉽게 퍼집니다. / 이사 나간 사람이 번호를 알고 있을 수도 있습니다.
- 사람이 바뀔 때마다 공용 번호 바꾸기
- 개인 방은 개인 열쇠나 번호를 따로 쓰기
- 번호를 단체 대화방에 올린 뒤 오래 두지 않기
- 문제가 생기면 운영자와 같이 정리하기
공용 도어락 수리는 한 사람이 정하기보다 같이 사는 사람들과 의논하는 것이 좋습니다.

# 열고 난 뒤 같이 점검하는 것
문이 열리면 도어락이 다시 잘 잠기고 열리는지 확인합니다. / 필요하면 배터리 상태도 같이 봅니다.
번호를 잊어서 연 경우에는 새 번호를 등록하는 것까지 도와드립니다. / 기존 번호는 지우고 새 번호만 남겨 둡니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 집주인과 상의가 필요하면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html) 정보를 안내해 드립니다.
@ 수원 율전동 24시 출장열쇠 도어락 점검

# 자취방 열쇠 관리 습관
자취를 오래 하려면 작은 습관이 큰 차이를 만듭니다.
- 여분 열쇠나 카드를 믿을 만한 곳에 따로 보관
- 번호는 외워 두고 휴대폰 메모에도 안전하게 저장
- 배터리 경고음이 나면 바로 교체하기
- 이사 나갈 때 열쇠와 번호를 정리해 인계하기
열쇠를 잃어버렸다면 같은 열쇠가 여러 개 돌아다닐 수 있으니 교체를 집주인과 상의해 보세요.

# 율전동 말고 수원 어디든 갑니다
율전동뿐 아니라 수원 전 지역이 출동 범위입니다. / 영통, 광교, 인계동, 권선동 위치를 알려주시면 도착 시간을 먼저 말씀드립니다.
다니는 동네는 [수원시 출장열쇠](suwon.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
@ 율전동 24시 출장열쇠 010-3664-5455
