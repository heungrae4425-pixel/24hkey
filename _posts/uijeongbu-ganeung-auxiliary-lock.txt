# 가능동 현관문에 보조키가 두 개 달려 있다면
가능동은 의정부역 가까이 오래된 주택가와 빌라가 함께 있는 동네입니다. / 이런 집들은 도어락 위에 열쇠를 쓰는 보조키가 하나 더 달려 있는 경우가 많습니다.
평소엔 도어락만 쓰다가 보조키를 잠근 채 잊고 외출하면 문 앞에서 낭패를 봅니다. / 번호를 정확히 눌러도 안 열리는 이유가 이것일 때가 의외로 많습니다.
이 글은 보조키 때문에 문이 안 열릴 때의 확인 순서와 개문, 점검 방법을 정리했습니다. / 지금 문 앞이라면 앞쪽 항목부터 보세요.
@ 가능동 24시 출장열쇠 보조키 잠금 개문

# 도어락은 풀렸는데 문이 안 열리는 경우
번호를 눌렀을 때 도어락 소리는 나는데도 문이 안 열린다면 보조키가 잠겨 있을 가능성이 큽니다. / 문 윗부분이나 손잡이 위쪽의 열쇠구멍을 살펴보세요.
열쇠를 가지고 있다면 보조키 방향으로 돌려 잠금을 풀어 보세요. / 한 번 돌렸다가 반대로 돌려야 풀리는 제품도 있습니다.
열쇠를 집에 두고 나왔거나 잃어버렸다면 이 방법은 쓸 수 없습니다. / 이때는 전화 주세요.

# 보조키 열쇠가 안 돌아갈 때
열쇠를 끝까지 넣고 살짝 빼 다시 천천히 돌려 보세요. / 깊이가 맞아야 돌아가는 제품이 있습니다.
문이 처지거나 눌려 있어 잠금이 어긋나 있는 경우도 많습니다. / 문을 안쪽으로 살짝 밀면서 돌리면 풀리기도 합니다.
그래도 안 돌아간다면 억지로 힘을 쓰지 마세요. / 열쇠가 부러지면 일이 커집니다.
@ 가능동 보조키 열쇠 점검 출장

# 보조키는 왜 필요한가
도어락은 전자식이라 배터리나 오류에 취약한 반면 보조키는 열쇠로 직접 걸리는 기계식입니다. / 두 가지가 겹쳐 있으면 방범이 더 든든합니다.
다만 두 잠금 중 하나라도 이상이 생기면 문이 안 열릴 수 있어 관리가 필요합니다. / 평소에 둘 다 잘 동작하는지 가끔 확인하세요.
보조키를 아예 쓰지 않는다면 걸쇠 위치를 확인해서 불필요하게 잠기지 않게 하는 것이 좋습니다. / 이 부분은 점검 때 같이 봐 드립니다.

# 전화할 때 알려 주세요
통화에서 도움이 되는 정보는 이런 것입니다. / 이것만 있으면 도착 준비가 빨라집니다.
- 도어락 번호판이 정상인지, 소리는 나는지
- 보조키 열쇠가 있는지, 있다면 돌아가는지
- 문 모양 (철문, 나무문, 대문 유무)
- 집 안에 사람이나 반려동물이 있는지
문 전체와 도어락, 보조키 부분을 함께 찍어 보내 주시면 필요한 장비를 챙기기 쉽습니다. / 사진이 어렵다면 보이는 대로만 말씀해 주세요.

# 하면 안 되는 일
급한 마음에 문을 발로 차거나 보조키 부분을 망치로 치는 분이 있습니다. / 문틀이 틀어지고 도어락 안쪽 부품이 상합니다.
드라이버나 칼로 틈을 벌리려 하는 것도 문 표면과 외관을 망가뜨립니다. / 나중에 수리 비용이 더 듭니다.
옆집이나 이웃에게 다른 열쇠를 빌려 억지로 돌려 보는 것도 권하지 않습니다. / 열쇠구멍이 상할 수 있습니다.

# 오래된 주택이라면 확인할 것
대문과 현관문이 따로 있는 집은 어느 문의 보조키가 잠겼는지 먼저 확인하세요. / 두 곳 모두 잠겨 있을 수도 있습니다.
오래된 문은 문틀이 틀어져 걸쇠와 보조키가 서로 어긋나는 경우가 있습니다. / 이럴 땐 열고 나서 위치를 조정해야 합니다.
주택 담벼락 쪽이나 창문 등 다른 출입구가 열려 있다는 이유로 무리하게 들어가려 하지 마세요. / 다치거나 이웃 오해를 살 수 있습니다.

# 가능동 주택가에서 자주 듣는 사례
출근길에 보조키를 잠그고 나와 퇴근 뒤 번호를 눌렀는데 문이 안 열린다는 연락이 가장 많습니다. / 열쇠를 안 가지고 나온 날이라면 더 난감합니다.
가족 중 마지막으로 나간 사람이 보조키를 잠갔는지 먼저 물어보세요. / 집 안에 사람이 있다면 안쪽에서 열어 줄 수 있습니다.
이웃에게 맡겨 둔 여벌 열쇠가 있는지도 떠올려 보세요. / 가까운 곳에 있다면 그것이 가장 빠를 수 있습니다.
아무도 없고 열쇠도 없다면 전화 주세요. / 위치와 문 사진을 보내 주시면 준비가 빨라집니다.

# 신분 확인은 꼭 합니다
문을 여는 일이라서 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
오래된 주택이면 우편물이나 집 앞 명패, 이웃의 확인도 참고합니다. / 번거로우셔도 집을 지키기 위한 절차입니다.
확인이 안 되면 작업을 할 수 없는 점은 미리 말씀드립니다. / 신분증은 항상 가까이에 두세요.

# 비용은 열기 전에 말씀드립니다
문 상태와 잠금 종류를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니라고 하시면 돌아갑니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 다시 여쭙습니다. / 열고 난 뒤 말없이 붙는 비용은 없습니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 문은 이렇게 엽니다
도어락과 보조키, 문이 상하지 않는 방법부터 차례로 시도합니다. / 보조키는 열쇠구멍이 상하지 않게 신경 써서 다룹니다.
작업 중에 보이는 문제가 있으면 손대기 전에 먼저 말씀드립니다. / 갑자기 부품을 뜯거나 바꾸는 일은 없습니다.
자세한 개방 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 비파손 개방을 기본으로 합니다.

# 열고 난 뒤 보조 잠금 점검
문이 열리면 보조키가 부드럽게 돌아가는지, 걸쇠가 문틀 구멍에 잘 맞는지 확인합니다. / 필요하면 위치를 살짝 조정하거나 부품을 손봅니다.
열쇠를 잃어버렸다면 [출장 열쇠](key-call.html)에서 새 열쇠를 맞추거나 열쇠구멍 부품을 바꿀 수 있습니다. / 바꾸기 전에는 꼭 먼저 여쭙고 진행합니다.
자주 고장이 나면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 판단은 상태를 보고 솔직하게 알려드립니다.
@ 가능동 24시 출장열쇠 보조키 점검 후 마무리

# 보조키를 안전하게 쓰는 요령
외출할 때 보조키를 잠갔는지 안 잠갔는지 가족끼리 정해 두면 헷갈리지 않습니다. / 문 안쪽에 작은 표시를 붙여 두는 집도 있습니다.
여벌 열쇠는 한 곳에 몰아 두지 말고 가족에게 나눠 두세요. / 모두 잃어버리는 일을 막을 수 있습니다.
열쇠가 닳았거나 구멍이 뻑뻑하면 부러지기 전에 점검을 받으세요. / 부러진 뒤보다 훨씬 간단하고 부담이 적습니다.

# 가능동 말고 의정부 어디든 갑니다
가능동 말고도 의정부동, 호원동, 장암동, 신곡동, 용현동, 민락동, 녹양동, 송산동까지 의정부 전 지역으로 다닙니다. / 24시간 받으니 밤늦게도 전화 주세요.
의정부에서 다니는 동네는 [의정부시 출장열쇠](uijeongbu.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
