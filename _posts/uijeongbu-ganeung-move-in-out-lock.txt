# 가능동 주택으로 이사하는 날, 문이 몇 개인지부터 세기
가능동은 가능역 가까이 오래된 주택가와 빌라가 이어진 의정부의 생활 동네입니다. / 이런 집은 아파트와 달리 대문, 건물 출입문, 현관문처럼 지나야 할 문이 여러 개인 경우가 많습니다.
이사하는 날 짐보다 먼저 해 둘 일은 우리 집에 문이 몇 개이고 각각 무엇으로 여는지 세어 보는 것입니다. / 번호로 여는 문, 열쇠로 여는 문, 카드로 여는 문을 나눠 적어 두면 놓치는 것이 없습니다.
이 글은 입주하는 날과 나가는 날 도어락과 열쇠를 어떻게 정리하면 좋을지 목록으로 정리했습니다. / 손이 필요한 작업은 [의정부 출장열쇠](uijeongbu.html)에 맡기셔도 됩니다.
@ 가능동 주택 입주 현관 대문 열쇠 확인

# 입주 전에 집주인에게 받을 것 목록
계약을 마치고 열쇠를 받을 때 아래 항목을 하나씩 확인해 보세요. / 받는 자리에서 직접 열어 보는 것이 가장 확실합니다.
- 현관 도어락 번호와 관리자 번호가 따로 있는지
- 등록된 카드나 태그가 몇 장인지
- 대문 열쇠와 보조키 열쇠가 각각 몇 개인지
- 공동 출입문이 있다면 그 번호나 열쇠
- 도어락 설명서나 제품 이름을 알 수 있는 사진
받은 열쇠는 문마다 실제로 꽂아 돌려 보세요. / 비슷하게 생긴 열쇠가 섞여 있어 정작 맞는 열쇠가 빠져 있는 일이 있습니다.

# 대문과 현관, 열쇠가 따로 노는 집
주택은 대문 열쇠가 현관 열쇠와 다르고, 위층과 아래층이 대문을 같이 쓰기도 합니다. / 대문 열쇠는 다른 세대도 가지고 있으니 내 마음대로 바꾸기 어렵습니다.
대문 자물쇠가 뻑뻑하거나 녹슬어 있다면 입주 전에 집주인에게 알려 두세요. / 이사 당일 짐을 나르다 대문이 안 잠기거나 안 열리면 하루가 꼬입니다.
현관 쪽은 내가 사는 공간이니 번호와 열쇠 관리를 내 기준으로 다시 정해도 됩니다.

# 도어락 관리자 번호와 사용자 번호
요즘 도어락은 설정을 바꾸는 관리자 번호와 문을 여는 사용자 번호가 나뉜 제품이 많습니다. / 사용자 번호만 바꾸고 관리자 번호를 그대로 두면 예전 사람이 설정을 다시 바꿀 수 있습니다.
입주하는 날 두 번호를 모두 새로 정하세요. / 관리자 번호를 모르면 도어락을 초기화한 뒤 처음부터 등록해야 합니다.
초기화 방법은 제품마다 다릅니다. / 잘못 누르면 문이 잠긴 채 번호가 지워지는 일도 있어 자신이 없으면 맡기시는 편이 안전합니다.
@ 가능동 빌라 현관 도어락 관리자 번호 초기화

# 등록된 카드와 지문은 모두 지우기
예전 세입자의 카드나 지문이 도어락에 남아 있을 수 있습니다. / 눈에 보이지 않으니 더 신경 써야 하는 부분입니다.
카드와 지문을 전부 지우고 우리 가족 것만 다시 등록하세요. / 하나씩 지울 수 없는 제품이라면 전체 삭제 후 재등록이 가장 깔끔합니다.
지운 뒤에는 예전 카드가 있다면 직접 대 보고 반응이 없는지 확인하세요. / 지문은 등록한 사람마다 두 손가락씩 넣어 두면 손을 다친 날에도 쓸 수 있습니다.

# 보조키 실린더, 바꿀까 그대로 둘까
현관에 열쇠식 보조키가 달려 있다면 그 열쇠가 예전에 몇 개나 복사됐는지 알 수 없습니다. / 마음이 쓰인다면 실린더만 바꾸는 방법이 있습니다.
실린더를 바꾸면 새 열쇠 세트를 받게 되고 예전 열쇠는 더 이상 맞지 않습니다. / 다만 세 든 집이라면 바꾸기 전에 집주인과 한 번 이야기해 두세요.

# 짐 나르는 날 문 열어 두기 주의
이삿짐을 나르는 동안 현관문을 열어 두려고 도어락 걸쇠를 테이프로 막거나 문 사이에 물건을 끼우는 경우가 있습니다. / 테이프 끈적임이 걸쇠에 남거나 문짝이 휘는 원인이 됩니다.
자동 잠금을 잠시 끄거나 문 고정 기능을 쓰는 편이 낫습니다. / 짐을 다 나른 뒤에는 자동 잠금을 다시 켰는지 꼭 확인하세요.
이삿짐 업체 직원이 번호를 알아야 한다면 임시로 쓸 번호를 따로 정해 두고, 이사가 끝나면 바로 지우세요.

# 입주 첫 주에 해 볼 작은 시험
새집에 들어가 첫 주 동안은 문을 열고 닫을 때 소리와 느낌을 조금 더 신경 써서 보세요. / 문이 끝까지 닫히는지, 잠김 소리가 또렷한지, 번호판 반응이 느리지 않은지입니다.
건전지를 언제 갈았는지 모르는 도어락이라면 입주하면서 새것으로 한꺼번에 바꿔 두는 것이 좋습니다. / 이사 후 며칠 만에 경고음이 나 번호판이 꺼지는 일을 막을 수 있습니다.
가족 모두에게 번호를 직접 눌러 보게 하고, 아이에게는 카드 대는 법도 같이 알려 주세요. / 오래된 주택은 겨울에 문이 뻑뻑해지기도 하니 첫 겨울 아침 한 번은 문 상태를 살펴보시길 권합니다.

# 퇴거하는 날 원래 상태로 돌려놓을 것
나가는 날에는 내가 등록한 번호, 카드, 지문을 지우고 처음 받았던 상태에 가깝게 돌려놓습니다. / 집주인이 새 번호를 정해 다음 세입자에게 넘길 수 있게 하는 것입니다.
받았던 열쇠와 카드는 받은 개수 그대로 돌려드리세요. / 잃어버린 것이 있다면 미리 말씀드리고 어떻게 할지 함께 정하는 것이 좋습니다.

# 도어락을 내가 바꿔 달았다면
살면서 도어락을 새로 달았다면 퇴거 때 두고 갈지, 원래 것을 다시 달지 정해야 합니다. / 이 부분은 계약 내용이나 집주인과의 약속에 따라 달라서 미리 이야기해 두시는 편이 서로 편합니다.
원래 도어락을 보관해 두었다면 다시 달아 드리는 작업도 할 수 있습니다. / 문 타공이 달라졌다면 그 점도 미리 말씀드립니다.

# 열쇠 반납과 기록 남기기
퇴거 날 열쇠와 카드를 돌려드릴 때 사진을 한 장 찍어 두세요. / 몇 개를 돌려드렸는지, 도어락이 정상으로 작동했는지 짧은 메모와 함께 남겨 두면 나중에 오해가 줄어듭니다.
입주 날에도 같은 방식으로 받은 열쇠와 도어락 상태를 기록해 두면 좋습니다. / 두 기록을 나란히 두면 살면서 생긴 일과 원래 있던 일을 구분하기 쉽습니다.

# 출장 때 확인과 비용 안내
이삿날 문이 잠겨 버렸다면 계약서나 집주인 확인으로 사시는 분인지 확인합니다. / 전입 신고 전이라 신분증 주소가 다르더라도 계약서와 집주인 통화로 진행할 수 있습니다.
작업 내용을 보고 비용을 먼저 말씀드리고 동의하시면 시작합니다. / 문을 열어야 하는 상황에서 끝내 열지 못하면 비용은 받지 않으며, 순서는 [이용안내](guide.html)에 있습니다.
초기화와 번호 재설정은 [도어락 수리](doorlock-repair.html), 실린더나 도어락을 바꾸는 일은 [도어락 교체](doorlock-replace.html), 잠긴 문을 여는 일은 [현관문 개문](door-open.html)에서 자세히 보실 수 있습니다.
@ 가능동 이사 퇴거 도어락 열쇠 반납 기록

# 가능동 말고 의정부 다른 동네
가능동 가까이 의정부동, 녹양동과 호원동, 장암동, 신곡동, 용현동, 민락동, 송산동까지 의정부 전역을 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인하세요.
