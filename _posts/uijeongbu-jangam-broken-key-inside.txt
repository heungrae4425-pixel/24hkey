# 장암동에서 열쇠가 부러졌다면 먼저 멈추세요
장암동은 오래된 주택과 연립, 빌라가 많아 열쇠로 여는 현관문이 아직 많이 남아 있는 동네입니다. / 오래 쓴 열쇠는 이가 닳고 금이 가 있다가 어느 날 열쇠구멍 안에서 똑 부러지기도 합니다.
열쇠 머리만 손에 남고 나머지가 구멍 안에 박히면 누구나 당황합니다. / 이때 가장 중요한 것은 아무것도 더 하지 않는 것입니다.
이 글은 열쇠가 부러졌을 때 하면 안 되는 일과 안전하게 빼서 문을 여는 순서를 정리했습니다. / 지금 문 앞이라면 첫 번째와 두 번째 항목부터 보세요.
@ 장암동 24시 출장열쇠 부러진 열쇠 제거 개문

# 먼저 열쇠구멍을 그대로 두세요
부러진 열쇠 조각을 어떻게든 빼내려고 핀이나 바늘로 쑤시면 안 됩니다. / 조각이 더 안쪽으로 밀려 들어가면 빼기가 훨씬 어려워집니다.
접착제나 본드로 붙이려는 시도도 절대 하지 마세요. / 열쇠구멍 내부가 굳어 도어락 전체를 바꿔야 할 수 있습니다.
조각이 밖으로 조금 튀어나와 있다면 그대로 두고 전화 주세요. / 상태를 보고 안전하게 빼내는 방법을 정합니다.

# 부러진 열쇠 머리는 버리지 마세요
손에 남은 열쇠 머리와 부러진 단면은 중요한 단서입니다. / 열쇠 모양과 홈을 그대로 알 수 있어 새 열쇠를 맞추기 편합니다.
작은 봉투에 담아 잃어버리지 않게 보관해 두세요. / 구멍 안에 남은 조각은 따로 빼내서 같이 맞춰 봅니다.
사진을 찍어 두면 더 확실합니다. / 열쇠구멍에 박힌 모양도 같이 찍어 보내 주세요.
@ 장암동 부러진 열쇠 조각 보관 후 새 열쇠 맞춤

# 열쇠는 왜 부러질까
오래 쓴 열쇠는 이가 닳아 열쇠구멍 안에서 잘 안 맞는데도 힘으로 돌리다 부러집니다. / 처음에는 뻑뻑한 정도지만 쓸수록 약해집니다.
열쇠구멍 안에 먼지나 녹이 쌓여 있어도 같은 일이 생깁니다. / 특히 비를 맞는 대문 열쇠구멍은 더 그렇습니다.
복사한 열쇠를 다시 복사한 열쇠는 오차가 커져 더 잘 걸립니다. / 이런 열쇠는 처음부터 정확히 새로 맞추는 편이 좋습니다.

# 전화할 때 알려 주세요
통화에서 도움이 되는 정보는 이런 것입니다. / 이것만 있으면 도착 준비가 빨라집니다.
- 부러진 조각이 구멍 안에 남아 있는지, 밖으로 나와 있는지
- 현관문과 대문 중 어디의 열쇠인지
- 열쇠구멍 모양 (일자형, 점이 많은 형 등 보이는 대로)
- 집 안에 사람이나 반려동물이 있는지
열쇠구멍이 정면으로 보이게 사진을 찍어 보내 주시면 큰 도움이 됩니다. / 어떤 도구가 필요한지 미리 준비할 수 있습니다.

# 도어락이 함께 있는 문이라면
열쇠구멍 옆에 번호판이 있는 도어락이라면 번호로 열 수도 있습니다. / 이 경우 열쇠 문제는 나중에 해결하고 일단 번호로 들어가세요.
번호를 모르거나 안 열리면 열쇠구멍 쪽을 같이 다뤄야 합니다. / 이때도 힘을 주지 말고 전화 주세요.
도어락이 없는 순수 열쇠 방식 문이라면 열쇠구멍 쪽이 유일한 통로입니다. / 상하지 않게 여는 방법을 우선 시도합니다.

# 하면 안 되는 일 정리
열쇠 조각을 이빨이나 펜치로 억지로 뽑지 마세요. / 부러진 조각이 더 안쪽으로 부러지면 일이 커집니다.
구멍에 기름을 마구 붓는 것도 좋지 않습니다. / 먼지가 달라붙어 부품이 굳을 수 있습니다.
문을 발로 차거나 어깨로 미는 것도 피하세요. / 문틀이 상하고 이웃도 놀랍니다.

# 여벌 열쇠가 있다면 먼저 떠올려 보세요
가족이나 가까운 이웃, 직장에 맡겨 둔 여벌 열쇠가 있는지 생각해 보세요. / 다만 구멍 안에 조각이 남아 있으면 여벌 열쇠도 들어가지 않습니다.
이 경우에는 조각부터 빼내야 하므로 여벌 열쇠를 가져오기 전에 먼저 전화 주세요. / 헛걸음을 줄일 수 있습니다.
대문과 현관문이 따로 있는 집은 어느 쪽 열쇠가 부러졌는지에 따라 접근 방법이 달라집니다. / 통화에서 알려 주시면 준비가 빨라집니다.
부러진 열쇠가 집 안쪽 방문이나 창고 열쇠라면 급하지 않은 경우가 많습니다. / 그래도 구멍을 건드리지 말고 상태만 알려 주세요.

# 신분 확인은 꼭 합니다
문을 여는 일이라서 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
오래된 주택이면 우편물이나 집 앞 명패, 이웃의 확인도 참고합니다. / 번거로우셔도 집을 지키기 위한 절차입니다.
확인이 안 되면 작업을 할 수 없는 점은 미리 말씀드립니다. / 신분증은 항상 가까이에 두세요.

# 비용은 열기 전에 말씀드립니다
문 상태와 열쇠구멍 상태를 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니라고 하시면 돌아갑니다.
열쇠구멍 속 부품을 바꿔야 하면 바꾸기 전에 다시 여쭙습니다. / 열고 난 뒤 말없이 붙는 비용은 없습니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 문은 이렇게 엽니다
부러진 조각을 안전하게 빼내고 열쇠구멍이 상하지 않는 방법으로 엽니다. / 조각이 깊이 박혀 있으면 시간이 조금 더 걸릴 수 있습니다.
작업 중에 보이는 문제가 있으면 손대기 전에 먼저 말씀드립니다. / 갑자기 부품을 뜯거나 바꾸는 일은 없습니다.
자세한 개방 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 비파손 개방을 기본으로 합니다.

# 열고 난 뒤 새 열쇠를 맞춥니다
부러진 열쇠의 원래 모양을 기준으로 새 열쇠를 정확하게 맞춥니다. / 필요하면 열쇠구멍 속 부품을 새로 바꾸는 방법도 말씀드립니다.
[출장 열쇠](key-call.html) 쪽에서 열쇠 복사와 교체를 같이 처리할 수 있습니다. / 바꾸기 전에는 꼭 먼저 여쭙고 진행합니다.
열쇠구멍이 심하게 닳았다면 도어락을 새로 다는 것이 나을 수도 있습니다. / 필요하면 [도어락 설치](doorlock-install.html)도 안내합니다.
@ 장암동 24시 출장열쇠 새 열쇠 맞춤 후 마무리

# 같은 일이 생기지 않게 하는 요령
열쇠가 뻑뻑하거나 구멍에서 잘 안 빠지면 부러지기 전에 점검하세요. / 부러진 뒤보다 훨씬 간단하고 부담이 적습니다.
열쇠는 해마다 한 번 상태를 보고 닳았다면 새로 맞추는 것이 좋습니다. / 여벌 열쇠도 같이 확인하세요.
열쇠 하나를 가족이 돌려 쓰지 말고 한 사람이 하나씩 갖는 것이 닳음을 줄입니다. / 잃어버리는 것도 막을 수 있습니다.

# 장암동 말고 의정부 어디든 갑니다
장암동 말고도 의정부동, 호원동, 신곡동, 용현동, 민락동, 녹양동, 가능동, 송산동까지 의정부 전 지역으로 다닙니다. / 24시간 받으니 급할 때는 바로 전화 주세요.
의정부에서 다니는 동네는 [의정부시 출장열쇠](uijeongbu.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
