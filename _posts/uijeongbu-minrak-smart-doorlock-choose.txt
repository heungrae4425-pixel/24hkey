# 민락동에서 도어락을 바꾸기로 했다면 질문부터
민락동은 아파트 단지가 많은 의정부의 주거 지역으로, 가족 단위로 사는 집이 많습니다. / 처음 달려 있던 도어락이 슬슬 말썽을 부리면서 이참에 지문이나 얼굴인식 같은 스마트 도어락으로 바꾸려는 분들이 늘었습니다.
매장이나 인터넷에서 제품을 보면 기능 목록이 끝없이 이어집니다. / 그런데 실제로 매일 쓰는 기능은 한두 가지이고, 나머지는 거의 손대지 않는 경우가 많습니다.
이 글은 제품 이름보다 우리 집 생활에 어떤 방식이 맞는지 스스로 답해 볼 질문들을 정리했습니다. / 설치나 교체 상담은 [의정부 출장열쇠](uijeongbu.html)로 연락 주시면 됩니다.
@ 민락동 아파트 스마트 도어락 선택

# 질문 하나, 집에 들어올 때 손이 비어 있나요
장바구니나 아이를 안고 들어오는 일이 잦다면 손을 덜 쓰는 방식이 편합니다. / 얼굴인식이나 휴대폰을 가까이 대기만 하면 열리는 방식이 여기에 해당합니다.
반대로 대부분 빈손으로 출퇴근하는 집이라면 번호나 지문만으로도 충분합니다. / 굳이 비싼 기능을 고를 이유가 줄어듭니다.
손잡이를 밀고 당겨 여는 형은 문을 여는 동작이 한 번으로 끝나 짐이 많을 때 편합니다. / 민락동처럼 아파트가 많은 곳은 이 방식이 흔합니다.

# 질문 둘, 가족 중 지문이 잘 안 읽히는 사람이 있나요
지문 인식은 편하지만 손이 자주 젖거나 거친 사람, 어르신, 어린아이는 인식이 잘 안 될 수 있습니다. / 요리나 청소를 자주 하는 분도 손끝이 거칠어져 실패가 잦아지기도 합니다.
이런 가족이 있다면 지문만 믿지 말고 카드나 번호를 함께 쓰는 제품이 맞습니다. / 사람마다 편한 방법을 고를 수 있게 두 가지 이상 지원하는지 확인하세요.
매장에서 체험해 볼 수 있다면 가족 중 인식이 어려울 것 같은 사람이 직접 대 보는 게 가장 정확합니다.

# 질문 셋, 카드를 자주 잃어버리나요
카드키는 아이와 어르신이 쓰기 쉬운 방식입니다. / 번호를 외울 필요 없이 대기만 하면 되니까요.
하지만 잃어버리면 주운 사람도 열 수 있다는 점이 약점입니다. / 카드를 자주 잃어버리는 집이라면 분실한 카드만 따로 지울 수 있는지, 전체를 지우고 다시 등록해야 하는지 확인해 두세요.
아파트 공동현관 카드와 세대 도어락 카드를 하나로 쓸 수 있는지도 관리사무소에 물어보세요. / 단지마다 사정이 달라 미리 알아 두면 카드 개수를 줄일 수 있습니다.
@ 민락동 도어락 카드키 등록과 분실 대비

# 질문 넷, 휴대폰 앱이 정말 필요한가요
앱 연동은 아이가 집에 들어왔는지 알림으로 확인하거나, 멀리서 손님에게 문을 열어 줄 때 쓸모가 있습니다. / 맞벌이 가정이나 부모님 댁을 챙기는 분께 특히 편합니다.
그 대신 공유기, 연결 장치, 앱 업데이트처럼 신경 쓸 거리가 늘어납니다. / 알림이 갑자기 안 오거나 등록이 풀리는 일도 생길 수 있습니다.
"있으면 좋겠다" 정도라면 앱 없이 쓰는 기본 기능이 탄탄한 제품을 고르시는 편이 오래 만족스럽습니다.

# 질문 다섯, 얼굴인식이 우리 집 현관에 맞을까
얼굴인식은 손을 쓰지 않아 편하지만 현관 밝기와 키 차이의 영향을 받습니다. / 복도가 어둡거나 역광이 드는 현관이라면 인식이 늦어질 수 있습니다.
키가 작은 아이와 키가 큰 어른이 함께 쓰려면 카메라가 볼 수 있는 높이 범위도 확인해야 합니다. / 마스크나 모자를 쓴 채로 인식되는지도 따져 보세요.
얼굴인식 제품도 번호나 카드를 함께 쓸 수 있는지 꼭 확인하세요. / 인식이 안 될 때 다른 방법이 있어야 문 앞에서 막히지 않습니다.

# 질문 여섯, 건전지 갈아 줄 사람이 있나요
기능이 많을수록 건전지를 빨리 씁니다. / 얼굴인식, 앱 연동, 알림 기능이 늘 켜져 있으면 번호키보다 교체 주기가 짧아집니다.
집안에 이런 관리를 챙기는 사람이 있다면 큰 문제는 아닙니다. / 하지만 어르신 혼자 사시는 집이나 아무도 신경 쓰지 않는 집이라면 건전지가 오래가는 단순한 제품이 오히려 안전합니다.
충전식 배터리를 쓰는 제품도 있으니 건전지와 충전식 가운데 어느 쪽이 집에 편한지도 생각해 보세요. / 충전식은 충전을 잊으면 마찬가지로 꺼진다는 점은 같습니다.

# 공통으로 확인할 안전 기능
- 바깥 9V 비상 전원 단자 위치
- 안쪽에서 문 열 때 실수 방지 기능 (아이 장난 방지)
- 번호를 틀렸을 때 입력 제한
- 번호 앞뒤로 아무 숫자를 덧붙여 눌러도 되는 기능
- 화재 등 비상시 안쪽에서 바로 열리는 구조
이런 기능은 제품 설명 맨 아래에 작게 적혀 있는 경우가 많습니다. / 화려한 기능보다 이쪽을 먼저 보세요.
특히 아이가 있는 집은 안쪽 손잡이를 아이가 혼자 열 수 없게 하는 기능이 있는지 꼭 물어보세요.

# 설치 전에 문 규격을 꼭 봅니다
아무리 좋은 제품이라도 문에 안 맞으면 설치할 수 없습니다. / 민락동 아파트 현관은 대체로 비슷한 철문이지만 처음 단 도어락의 구멍 크기와 보조키 유무는 집마다 다릅니다.
- 문 두께 재기
- 지금 도어락 구멍 위치와 크기 사진
- 보조키가 따로 있는지
- 문이 열리는 방향
기존 구멍을 그대로 쓸 수 있는 제품이면 문에 새로 손댈 일이 줄어듭니다. / 확인 항목은 [도어락 설치](doorlock-install.html)에 더 자세히 있습니다.
@ 의정부 민락동 현관문 두께와 기존 구멍 측정

# 지금 도어락을 꼭 바꿔야 할까
교체를 생각하게 된 이유가 고장이라면 먼저 고쳐 쓸 수 있는지 보세요. / 배터리 접점, 걸쇠 위치, 번호판 습기처럼 손보면 다시 잘 쓰는 경우도 많습니다.
고장보다 기능 때문에 바꾸시는 거라면 지금 제품이 몇 년이나 됐는지 생각해 보세요. / 아직 쌩쌩하다면 기능 하나 때문에 바꾸는 게 아까울 수 있습니다.
수리 범위는 [도어락 수리](doorlock-repair.html), 교체 과정은 [도어락 교체](doorlock-replace.html)에서 보실 수 있습니다.

# 상담과 비용 안내는 이렇게 합니다
전화로 가족 구성, 원하는 방식, 지금 문 사진을 알려주시면 맞을 만한 방식을 먼저 좁혀 드립니다. / 현장에서 문을 직접 보고 설치할 수 있는지 확인한 뒤 비용을 손대기 전에 먼저 말씀드립니다.
들어 보시고 결정하시면 되고, 작업하지 않으셔도 괜찮습니다. / 진행 순서는 [이용안내](guide.html)에 정리돼 있습니다.

# 설치한 날 꼭 해 둘 것
- 가족 모두 각자 쓸 방법으로 등록
- 관리자 번호는 두 사람이 알고 있기
- 비상 전원 단자 위치 가족에게 알려 주기
- 설명서는 버리지 말고 보관
- 첫 주 동안 잠김 소리가 이상하지 않은지 지켜보기
설치는 사시는 분 확인 후 진행합니다. / 신분증 주소나 우편물, 관리사무소 세대 확인 중 하나를 준비해 주세요.
@ 민락동 새 도어락 가족별 지문 카드 등록

# 마무리
민락동에서 스마트 도어락을 고를 때는 기능 목록보다 우리 가족이 문을 어떻게 드나드는지 먼저 떠올려 보세요. / 질문 다섯 개에 답하고 나면 필요한 방식이 꽤 분명해집니다.
민락동 외에 신곡동, 용현동, 녹양동, 가능동, 송산동까지 의정부 전 지역을 다니고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455.
