# 용현동 새 집에 들어가기 전에 해 둘 일
이사 날은 짐과 사람으로 정신이 없어 문 잠금 점검을 놓치기 쉽습니다. / 그런데 새 집 현관문의 도어락은 이전에 살던 사람이 쓰던 그대로일 수 있습니다.
이전 거주자와 중개한 분, 청소를 맡았던 분이 같은 번호를 알고 있다면 방범에 구멍이 생긴 셈입니다. / 입주하는 날 바로 정리해 두는 것이 가장 안전합니다.
이 글은 이사하면서 도어락과 열쇠를 어떻게 정리할지 순서대로 정리했습니다. / 이사를 앞두셨다면 체크리스트처럼 쓰셔도 됩니다.
@ 용현동 24시 출장열쇠 이사 도어락 초기화 점검

# 입주 첫날 가장 먼저 할 것
현관 도어락의 기존 번호와 등록된 카드, 지문을 전부 지워 주세요. / 이전에 등록된 정보가 남아 있으면 누가 들어올 수 있는지 알 수 없습니다.
도어락 설명서에서 초기화 방법을 찾거나 제품 이름으로 검색해 보세요. / 제품마다 초기화 절차가 달라 섞어 따라 하면 오히려 오류가 날 수 있습니다.
어렵다면 사진을 보내 주세요. / 모델을 확인하고 맞는 방법을 알려 드립니다.

# 비밀번호 초기화가 안 되는 경우
버튼을 눌러도 반응이 없거나 초기화 단계가 안 나온다면 배터리가 약할 수 있습니다. / 새 건전지로 바꾼 뒤 다시 시도해 보세요.
이전 거주자가 관리자 번호를 따로 설정해 두었다면 초기화 과정이 막히는 제품도 있습니다. / 이럴 때는 억지로 하지 말고 전화 주세요.
오래된 제품은 아예 초기화 기능이 없는 경우도 있습니다. / 이 경우는 점검 후 수리나 교체를 상담해 드립니다.
@ 용현동 도어락 초기화 불가 시 점검

# 열쇠도 같이 정리하세요
번호는 바꿨는데 열쇠구멍이 있는 문이라면 이전 열쇠가 그대로 통할 수 있습니다. / 이전 거주자나 관리인에게 열쇠가 몇 개 남아 있는지 알 수 없습니다.
완전히 안심하려면 열쇠구멍 속 부품을 새로 바꾸는 방법이 있습니다. / 도어락 전체를 바꾸는 것보다 부담이 작은 경우가 많습니다.
[출장 열쇠](key-call.html) 쪽에서 열쇠 복사와 교체를 같이 안내합니다. / 어떤 것이 필요한지는 문 상태를 보고 솔직하게 말씀드립니다.

# 이사 나가는 쪽이라면
집을 비울 때는 번호를 초기 상태로 돌려 놓지 말고, 새 입주자나 집주인에게 방법을 알려 주는 것이 좋습니다. / 등록한 카드와 지문은 지우고 나가세요.
열쇠는 몇 개를 돌려주는지 기록해 두면 나중에 분쟁을 막을 수 있습니다. / 복사한 열쇠가 있다면 같이 돌려 주세요.
도어락을 직접 달아 쓰셨다면 떼어 가도 되는지 집주인과 먼저 이야기하세요. / 계약 내용에 따라 다릅니다.

# 임대차 집이라면 확인할 것
세 들어 사는 집은 도어락이나 열쇠를 바꿔도 되는지 집주인에게 먼저 물어보세요. / 허락 없이 바꾸면 나갈 때 곤란해질 수 있습니다.
집주인이 직접 관리하는 번호가 있다면 입주 전에 정리 방법을 정해 두세요. / 서로 불필요한 오해를 줄일 수 있습니다.
교체 비용을 누가 낼지도 처음에 정해 두는 것이 좋습니다. / 영수증은 꼭 보관하세요.

# 이사 당일 문이 안 열릴 때
새 집인데 받은 번호가 안 맞거나 열쇠가 안 돌아가는 경우가 가끔 있습니다. / 이럴 때는 번호를 여러 번 누르지 말고 한 번 멈춰서 확인하세요.
중개한 분이나 이전 거주자에게 정확한 번호와 순서를 다시 물어보세요. / 별표나 샵 버튼을 먼저 눌러야 하는 제품도 있습니다.
그래도 안 되면 전화 주세요. / 이사 일정이 급할수록 억지로 하지 마시고 위치와 상태를 알려 주세요.

# 이사 날 하면 안 되는 일
짐 때문에 급하다고 문을 발로 차거나 도어락을 분해하지 마세요. / 새 집 문에 처음부터 흠집이 나면 나갈 때 비용이 생길 수 있습니다.
인터넷에서 본 방법으로 임의 초기화를 반복하면 도어락이 잠겨 버릴 수 있습니다. / 한두 번 시도해 보고 안 되면 멈추세요.
이사 업체에 도어락을 맡기는 것도 권하지 않습니다. / 문 관련 작업은 전문 업체에 맡기는 편이 안전합니다.

# 신분 확인은 꼭 합니다
문을 여는 일이라서 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 임대차 계약서, 관리사무소 확인 중 하나면 됩니다.
이사 직후라 주소지가 바뀌지 않았다면 계약서를 보여 주시면 됩니다. / 번거롭지만 이웃과 집을 지키기 위한 절차입니다.
확인이 안 되면 작업을 할 수 없는 점은 미리 말씀드립니다. / 이사 전날에 서류를 챙겨 두면 편합니다.

# 비용은 시작 전에 말씀드립니다
문 상태와 필요한 작업을 보고 비용을 먼저 안내합니다. / 괜찮다고 하시면 시작하고, 아니라고 하시면 돌아갑니다.
부품이나 열쇠 교체가 필요하면 바꾸기 전에 다시 여쭙습니다. / 작업 뒤에 말없이 붙는 비용은 없습니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 있습니다.

# 문은 이렇게 엽니다
문과 도어락이 상하지 않는 방법부터 차례로 시도합니다. / 이사 당일에는 시간이 가장 중요하니 도착 시간을 먼저 말씀드립니다.
작업 중에 보이는 문제가 있으면 손대기 전에 먼저 말씀드립니다. / 갑자기 부품을 뜯거나 바꾸는 일은 없습니다.
자세한 개방 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 비파손 개방을 기본으로 합니다.

# 정리 뒤 도어락을 새로 달고 싶다면
번호와 열쇠를 바꿔도 불안하거나 도어락이 너무 오래됐다면 새로 다는 것이 맞을 수 있습니다. / 이사 시기에는 문 규격과 방식을 함께 정하면 한 번에 끝납니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 자주 고장이 나면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 용현동 24시 출장열쇠 도어락 교체 상담

# 이사 후 일주일 안에 할 일
등록된 번호와 카드가 몇 개인지 가족과 함께 확인하세요. / 여벌 열쇠 위치도 한 번 정해 두세요.
배터리 교체 시기를 메모해 두면 입주 몇 달 뒤 곤란을 막을 수 있습니다. / 이사 당일 새 건전지로 바꿔 두는 분도 많습니다.
이웃과 인사를 나누며 공동현관이나 출입 방법을 확인해 두세요. / 필요할 때 큰 도움이 됩니다.

# 용현동 말고 의정부 어디든 갑니다
용현동 말고도 의정부동, 호원동, 장암동, 신곡동, 민락동, 녹양동, 가능동, 송산동까지 의정부 전 지역으로 다닙니다. / 24시간 받으니 이사 날 새벽에도 전화 주세요.
의정부에서 다니는 동네는 [의정부시 출장열쇠](uijeongbu.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
