# 부곡동 가게 문 앞, 열쇠를 꽂았는데 꿈쩍 않을 때
의왕역 쪽 부곡동은 주택과 빌라 사이로 동네 가게와 작은 사무실, 작업장이 자리 잡은 곳입니다. / 집 현관과 달리 가게 문은 아침에 제때 열리지 않으면 그날 영업이 통째로 밀립니다.
문이 안 열리는 아침만 문제가 아닙니다. / 저녁 마감 때 도어락이 잠기지 않으면 가게를 비워 두고 퇴근하기가 영 불안합니다.
이 글은 부곡동에서 가게나 사무실 출입문이 말썽일 때 영업 전과 마감 후로 나눠 챙길 점, 여러 사람이 쓰는 문의 번호 관리, [의왕 출장열쇠](uiwang.html)를 부르는 순서를 정리했습니다.
@ 부곡동 가게 사무실 출입문 도어락

# 가게 문은 집 문과 구조가 다릅니다
- 유리 강화문: 바닥에 묻힌 힌지로 돌고, 위아래로 잠금이 들어가는 경우가 많음
- 철제 셔터: 바깥에 한 겹 더 내려 열쇠로 잠금
- 철문: 작업장이나 창고에 흔하고, 보조 자물쇠를 함께 쓰기도 함
- 사무실 도어락: 건물 복도 쪽 일반 현관과 비슷한 번호식이나 카드식
문 종류에 따라 원인도, 가져가야 할 공구도 다릅니다. / 전화하실 때 어떤 문인지 먼저 말씀해 주시면 준비가 빨라집니다.

# 영업 시작 전, 문이 안 열릴 때
번호식이라면 번호판이 켜지는지부터 보세요. / 꺼져 있다면 비상 단자에 9V 건전지를 대 볼 수 있고, 근처 편의점에서 쉽게 구할 수 있습니다.
번호판은 켜지는데 틀렸다고 나온다면 다른 직원이 번호를 바꾸지 않았는지 확인해 보세요. / 단체 대화방에 공지가 있었는지 거슬러 올라가 보면 의외로 쉽게 풀립니다.
열쇠식 잠금이라면 열쇠를 반쯤 넣고 문을 살짝 밀거나 당기며 돌려 보세요. / 유리문은 밤사이 온도 차로 위아래 잠금 위치가 조금 어긋나기도 합니다.
가게 안에 직원이 먼저 와 있다면 안쪽에서 열어 줄 수 있는지 확인하세요. / 안쪽 손잡이나 돌림 꼭지로 열리는 구조라면 그것만으로 영업은 시작할 수 있고, 점검은 손님이 뜸한 시간에 받으셔도 됩니다.

# 마감 때 안 잠긴다면 오늘 밤 넘기는 법
걸쇠가 문틀 구멍에 안 들어가거나 도어락이 잠금 신호를 내지 않는다면, 먼저 문이 끝까지 닫혔는지 확인하세요. / 유리문은 닫히는 속도를 붙잡는 장치가 약해지면 마지막 한 뼘에서 멈춥니다.
끝까지 닫았는데도 안 잠긴다면 셔터나 보조 자물쇠처럼 다른 잠금 장치가 있는지 떠올려 보세요. / 그것만 걸어 두고 다음 날 아침 점검을 받는 것도 방법입니다.
다른 잠금이 없다면 밤이라도 연락 주세요. / 가게를 열어 둔 채 퇴근하는 것보다는 그날 손보는 편이 마음 편합니다.

# 유리문과 셔터에서 자주 보는 일
유리 강화문은 바닥 힌지와 위쪽 잠금 쇠가 맞아야 잠깁니다. / 문이 조금이라도 처지면 위쪽 잠금이 구멍을 못 찾고 헛돌게 됩니다.
셔터 열쇠 구멍은 비와 먼지를 그대로 맞아 녹슬기 쉽습니다. / 열쇠가 뻑뻑하다고 아무 기름이나 넣으면 먼지가 엉겨 더 나빠지니 피하세요.
셔터가 중간에 걸려 안 내려오거나 안 올라간다면 잠금보다 셔터 자체 문제일 수 있습니다. / 이럴 때는 무리하게 당기지 말고 사진과 함께 상황을 알려 주세요.
@ 부곡동 상가 유리문 셔터 잠금 점검

# 작업장과 창고 문이라면
작업장이나 창고 철문은 무겁고 자주 여닫혀서 경첩과 걸쇠가 빨리 닳습니다. / 문이 처져 바닥에 끌리거나 걸쇠가 문틀에 긁힌다면 잠금 문제가 곧 따라옵니다.
보조 자물쇠를 여러 개 함께 쓰는 곳은 어느 열쇠가 어느 자물쇠인지 헷갈리기 쉽습니다. / 열쇠마다 표시를 해 두면 급할 때 시간을 아낄 수 있습니다.
먼지가 많이 나는 작업장이라면 도어락 번호판과 열쇠 구멍에 가루가 쌓여 버튼이 덜 눌리기도 합니다. / 마른 솔로 가끔 털어 주기만 해도 고장이 줄어듭니다.

# 여러 사람이 쓰는 문, 번호는 이렇게
- 번호를 바꿀 때는 바꾼 사람과 날짜를 단체방에 남기기
- 그만둔 직원이 있으면 그날 번호 바꾸기
- 사람마다 다른 번호나 카드를 쓸 수 있는 제품이면 따로 등록하기
- 관리자 번호는 대표와 책임자만 알기
번호 하나를 모두가 나눠 쓰면 누가 언제 바꿨는지 알 길이 없어 아침에 막히는 일이 생깁니다. / 사람마다 카드를 나눠 주는 방식이 관리하기 훨씬 편합니다.

# 이것만은 하지 마세요
- 유리문 틈에 칼이나 드라이버 넣기
- 셔터를 발로 차거나 몸으로 들어 올리기
- 도어락 덮개를 열고 전선 만지기
- 열쇠 구멍에 아무 기름이나 넣기
유리 강화문은 가장자리에 충격이 가면 한 번에 깨질 수 있습니다. / 급해도 틈을 벌리는 일은 피해 주세요.
깨진 유리문은 잠금보다 훨씬 큰 공사가 되고, 그동안 가게를 비워 둘 수도 없게 됩니다.

# 부곡동에서 연락 주실 때
- 가게나 사무실 주소와 건물 이름, 층
- 유리문, 셔터, 철문, 사무실 도어락 중 어떤 문인지
- 안 열리는지, 안 잠기는지
- 영업 시작 시간처럼 급한 사정이 있는지
문 전체와 잠금 부분 사진을 보내 주시면 맞는 부품을 미리 챙겨 갑니다. / 영업 전이라면 몇 시까지 열어야 하는지 말씀해 주세요.
가게 앞에 차를 잠시 댈 수 있는지도 알려 주시면 도착이 수월합니다.

# 사용자 확인은 이렇게 합니다
가게나 사무실 문을 여는 일이라 그곳을 쓰는 분인지 확인합니다. / 임대차 계약서, 사업자 등록 서류, 건물 관리인 확인 가운데 하나면 됩니다.
직원이 대신 부르는 경우라면 대표나 책임자와 통화로 확인하는 방법도 씁니다. / 확인이 안 되면 열지 않습니다.
서류가 가게 안에 있다면 휴대폰에 저장해 둔 계약서 사진이나 사업자 등록 사진도 괜찮습니다. / 평소에 한 장씩 찍어 두시면 이럴 때 요긴합니다.

# 비용은 작업 전에 먼저
문 종류와 고장 부위를 본 뒤 비용을 먼저 말씀드리고, 동의하시면 시작합니다. / 끝내 열지 못하면 받지 않습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 부곡동 가게 출입문 출장열쇠 비용 안내

# 고친 뒤 오래 쓰려면
문을 연 뒤에는 잠금이 한 번에 걸리는지, 유리문이라면 위아래 잠금이 제자리에 들어가는지 여러 번 확인합니다. / 도어락이 낡아 자주 멈춘다면 [도어락 수리](doorlock-repair.html)로 손볼지, 직원 관리가 편한 카드식으로 [도어락 교체](doorlock-replace.html)를 할지 함께 봅니다.
문 닫히는 속도가 빨라지거나 셔터 열쇠가 뻑뻑해지는 것처럼 작은 신호가 보이면 그때 점검을 받아야 일이 가장 작게 끝납니다. / 영업 중에 갑자기 멈추면 손님 앞에서 문을 붙잡고 씨름하게 됩니다.

# 부곡동 말고 의왕 다른 동네도
내손동, 포일동, 오전동, 고천동, 청계동, 학의동까지 의왕 어디든 갑니다. / 다른 지역은 [출장 지역](area.html)을 확인하세요.
