# 학의동에서 비파손이라는 말을 들었다면
문이 잠겨 출장열쇠에 전화하면 비파손으로 열어 드린다는 말을 자주 듣게 됩니다. / 그런데 정확히 무엇을 안 부순다는 건지, 어디까지 믿어도 되는지는 잘 설명되지 않습니다.
의왕 학의동은 백운호수가 가까운 동네로, 마당 있는 주택과 공동주택이 함께 있는 곳입니다. / 대문과 현관이 따로 있는 집도 있어서 어느 문을 어떻게 여느냐에 따라 이야기가 조금씩 달라집니다.
이 글은 비파손 개방이 무슨 뜻인지, 실제로 어떤 순서로 진행되는지, 어떤 때는 예외가 생기는지 정리했습니다. / 지금 문이 잠긴 상황이라면 바로 [의왕 출장열쇠](uiwang.html)로 연락 주세요.
@ 학의동 비파손 현관문 개방 설명

# 비파손은 무엇을 지킨다는 뜻일까
비파손 개방은 문짝, 문틀, 도어락 몸체를 부수거나 뜯지 않고 문을 연다는 뜻입니다. / 연 뒤에도 그 문과 도어락을 그대로 다시 쓸 수 있게 하는 것이 목표입니다.
드릴로 도어락에 구멍을 뚫거나 문틀을 벌려 걸쇠를 빼는 방식과 반대되는 말입니다. / 그런 방식은 빠를 수는 있어도 연 뒤에 도어락을 새로 달아야 하는 일이 생깁니다.
다만 비파손은 결과를 약속하는 말이라기보다 순서를 정하는 원칙에 가깝습니다. / 덜 상하는 방법부터 차례로 시도하고, 그래도 안 될 때만 다음 방법을 상의한다는 뜻입니다.

# 왜 부수지 않고 여는 게 좋을까
문을 부수고 열면 그날 밤 문을 제대로 잠그지 못하는 일이 생깁니다. / 새 도어락을 달 때까지 집을 비우기도 어렵고, 비용도 따로 들게 됩니다.
문틀이 한 번 휘면 새 도어락을 달아도 걸쇠가 잘 맞지 않습니다. / 그래서 조금 더 시간이 걸려도 상하지 않게 여는 편이 길게 보면 이득입니다.
세입자라면 집주인에게 설명해야 할 일도 줄어듭니다. / 문과 도어락이 그대로 남아 있으니 원상 복구를 걱정할 필요가 없습니다.
주택은 현관문이 바깥에 바로 닿아 있어 문이 상하면 비바람과 찬 공기가 그 틈으로 바로 들어옵니다. / 그날 저녁부터 집 안이 불편해지니 주택일수록 상하지 않게 여는 일이 더 중요합니다.

# 실제로는 이런 순서로 진행됩니다
도착하면 먼저 사시는 분인지 확인합니다. / 신분증 주소나 주소가 적힌 우편물, 관리 쪽 확인 중 하나면 됩니다.
그다음 도어락 종류와 문 상태, 보조키가 있는지를 봅니다. / 이때 어떤 방법으로 열지와 비용을 먼저 말씀드리고 괜찮다고 하시면 시작합니다.
작업은 문 밖에서 손잡이나 문틈, 도어락 구조를 이용해 안쪽 잠금을 푸는 방식으로 합니다. / 구체적인 방법은 문마다 다르고 보안 때문에 자세히 공개하지 않습니다.
@ 학의동 도어락 비파손 개방 진행 순서

# 도어락 종류마다 다른 점
손잡이가 달린 일체형 도어락은 손잡이 구조를 이용하는 방법이 있어 비교적 덜 상하게 열리는 편입니다. / 밀고 당기는 형 도어락은 구조가 달라 다른 방식을 써야 합니다.
열쇠로 잠그는 보조키가 같이 잠겨 있으면 그 보조키부터 풀어야 합니다. / 열쇠 실린더는 비파손으로 여는 방법이 있지만 실린더가 오래 낡았다면 시간이 더 걸립니다.
대문은 현관과 구조가 또 다릅니다. / 학의동 주택처럼 대문 자물쇠가 따로 있는 집은 대문과 현관 중 어디가 잠겼는지 통화 때 꼭 알려 주세요.

# 예외가 생기는 경우도 솔직하게
아주 드물게 비파손으로 열 수 없는 경우가 있습니다. / 도어락 내부가 이미 고장 나서 걸쇠가 꽉 물려 있거나, 보안 등급이 높은 잠금장치인 경우입니다.
이럴 때는 작업을 멈추고 상황을 그대로 말씀드립니다. / 부품 하나를 상하게 해야 열 수 있다면 어느 부품인지, 그 뒤에 무엇을 해야 하는지까지 설명드리고 동의를 받습니다.
말없이 다른 방법으로 넘어가지 않습니다. / 동의하지 않으시면 그대로 돌아가고, 그 경우 비용은 받지 않습니다.

# 작은 흔적과 손상은 다릅니다
비파손으로 열어도 도어락 겉면에 아주 작은 자국이 남는 경우는 있습니다. / 문을 쓰는 데는 영향이 없는 정도라 손상이라고 하지는 않습니다.
흔적이 걱정되신다면 시작 전에 말씀해 주세요. / 문 상태를 함께 보면서 어디에 어떤 도구가 닿을지 미리 알려 드립니다.
열고 난 뒤에는 도어락이 정상으로 잠기고 열리는지 여러 번 같이 확인합니다. / 걸쇠 움직임과 번호판 반응, 손잡이 느낌이 잠기기 전과 같은지 직접 만져 보시게 합니다. / 조금이라도 다르게 느껴지면 그 자리에서 다시 봅니다.

# 비파손이라는 말만 믿지 말고 물어볼 것
전화로 비파손이라는 말을 들었다면 아래를 함께 물어보시면 좋습니다.
- 못 열었을 때 비용이 나오는지
- 비용은 언제 말해 주는지, 문 앞에서 바뀌는지
- 부품을 상하게 해야 할 때 미리 물어보는지
- 열고 난 뒤 도어락 점검까지 해 주는지
24시출장열쇠는 못 열면 비용을 받지 않고, 비용은 시작 전에 먼저 말씀드립니다. / 진행 방식은 [이용안내](guide.html)에 그대로 적어 두었습니다.
@ 학의동 출장열쇠 비파손 문의 확인

# 기다리는 동안 하지 않는 게 좋은 일
비파손으로 열려면 도착했을 때 문과 도어락이 그대로인 것이 가장 좋습니다. / 기다리는 사이 직접 손을 대다가 상하게 만드는 일이 생각보다 흔합니다.
- 드라이버로 도어락 덮개를 뜯기
- 문틈에 카드나 쇠막대를 넣어 비틀기
- 손잡이를 세게 잡아당기거나 발로 차기
- 번호를 수십 번 눌러 입력 제한 걸리게 하기
번호판이 꺼진 경우라면 9V 건전지로 비상 전원을 대 보는 정도는 괜찮습니다. / 그 이상은 그대로 두고 기다려 주세요.

# 학의동에서 연락하실 때
아래 내용을 알려 주시면 도착 전에 방법을 미리 정할 수 있습니다.
- 학의동 주소와 집 형태, 대문이 있는지
- 잠긴 문이 현관인지 대문인지
- 도어락 모양과 보조키가 있는지
- 집 안에 아이나 반려동물이 있는지
도어락 사진 한 장을 문자로 보내 주시면 도움이 많이 됩니다. / 백운호수 쪽에서 들어오는 길처럼 찾아오는 길을 알려 주셔도 좋습니다.

# 열고 난 뒤 이어지는 일
문이 열리면 원인에 맞게 정리합니다. / 건전지가 원인이면 새것으로 바꾸고, 번호를 잊은 경우라면 새 번호 등록까지 돕습니다.
도어락이 이미 낡아 다시 막힐 것 같으면 [도어락 수리](doorlock-repair.html)를 먼저 권합니다. / 고칠 수 없을 만큼 상했을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문 여는 방식을 더 알고 싶다면 [현관문 개문](door-open.html) 페이지를 봐 주세요.

# 학의동 말고 의왕 어디든
학의동 주택뿐 아니라 내손동, 포일동 아파트와 오전동, 고천동, 부곡동 주택가, 청계동 전원주택까지 의왕 어디든 다닙니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인해 보세요.
