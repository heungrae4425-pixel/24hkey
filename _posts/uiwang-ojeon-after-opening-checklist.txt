# 오전동 현관이 열린 순간, 아직 할 일이 남았습니다
오전동은 주택가와 빌라가 많은 의왕 동네입니다. / 문이 잠겨 한참 애를 태우다가 드디어 열리면 누구나 그대로 들어가 쉬고 싶어집니다.
그런데 문이 왜 잠겼는지 원인을 그대로 둔 채 지나가면 며칠 뒤 같은 자리에서 또 막히기 쉽습니다. / 건전지가 원인이었다면 건전지가, 번호가 원인이었다면 번호 관리가, 걸쇠가 원인이었다면 문 맞물림이 아직 그대로이기 때문입니다.
이 글은 오전동에서 잠긴 문을 연 뒤 꼭 확인할 항목과 원인별 재발 방지 방법을 정리했습니다. / 문을 여는 일부터 필요하다면 [의왕 출장열쇠](uiwang.html)로 연락 주세요.
@ 오전동 현관문 개방 후 도어락 점검

# 열렸다고 끝이 아닌 이유
문이 안 열렸던 이유는 대개 하나가 아닙니다. / 건전지가 약해진 데다 걸쇠가 문틀에 눌려 있었다거나, 번호를 잊은 데다 비상 열쇠도 어디 있는지 몰랐던 식으로 두세 가지가 겹쳐 있습니다.
문을 여는 건 그중 하나를 넘긴 것뿐입니다. / 나머지를 그 자리에서 함께 정리해 두어야 다음에 문 앞에서 막히지 않습니다.
아래 항목은 저희가 문을 연 뒤 함께 보는 순서이기도 합니다. / 직접 여신 경우라도 그대로 따라 해 보시면 됩니다.

# 하나, 문을 연 채로 잠금을 여러 번
가장 먼저 문을 열어 둔 상태에서 잠금과 열림을 몇 번 반복해 보세요. / 걸쇠가 끝까지 나왔다가 부드럽게 들어가는지, 모터 소리가 힘없이 끊기지 않는지 봅니다.
그다음 문을 닫고 안에서 잠갔다 열어 보고, 마지막으로 밖에서 번호로 열어 봅니다. / 이 순서를 지켜야 확인하다가 또 갇히는 일이 없습니다.
밖에서 시험할 때는 집 안에 가족이 한 명 남아 있거나, 휴대폰과 열쇠를 손에 쥔 채로 나가세요. / 확인하려다 다시 문밖에 서게 되는 일이 생각보다 자주 있습니다.

# 둘, 건전지는 전부 새것으로
문이 안 열렸던 이유가 건전지가 아니었더라도 이참에 한 번 바꿔 두는 게 좋습니다. / 개방 과정에서 도어락이 여러 번 작동하면서 건전지 힘을 꽤 썼을 수 있습니다.
덮개를 열었을 때 접점에 하얀 가루나 녹이 보이면 마른 천으로 닦아 주세요. / 심하게 부식됐다면 점검을 받는 게 낫습니다.
바꾼 날짜는 덮개 안쪽에 적어 두세요. / 다음에 경고음이 울렸을 때 얼마 만에 닳았는지 알 수 있어, 도어락 안에서 전기가 새는지 가늠하는 데도 도움이 됩니다.

# 셋, 번호를 새로 정하고 예전 번호는 지우기
번호를 잊어서 문을 열었다면 새 번호를 정해 등록하고, 남아 있던 예전 번호는 지워야 합니다. / 기억나지 않던 번호가 어딘가에 적혀 있거나 다른 사람이 알고 있을 수도 있기 때문입니다.
새 번호는 가족 모두 같은 날 함께 알도록 하세요. / 한 사람만 알고 있으면 다음에 다른 식구가 같은 일을 겪습니다.
@ 오전동 도어락 새 비밀번호 등록 예전 번호 삭제

# 넷, 카드와 지문 목록 정리
카드나 태그, 지문을 쓰는 도어락이라면 등록된 목록도 한 번 정리하세요. / 잃어버린 카드나 이제 같이 살지 않는 사람의 지문이 남아 있을 수 있습니다.
목록을 하나씩 지우기 어려운 제품이라면 전부 지우고 지금 쓰는 것만 다시 등록하는 편이 깔끔합니다. / 제품마다 방법이 달라서 설명서나 제품 이름으로 찾아보시면 됩니다.
지문을 다시 넣을 때는 손가락 대는 각도를 조금씩 바꿔 가며 등록해 두면 나중에 실패가 줄어듭니다.

# 다섯, 걸쇠와 문틀이 맞물리는지
문을 닫았을 때 걸쇠가 문틀 구멍에 걸리지 않고 쑥 들어가는지 보세요. / 문을 살짝 밀어야만 잠긴다면 걸쇠와 구멍이 어긋나 있는 겁니다.
오전동처럼 오래된 주택과 빌라가 많은 곳은 문이 조금씩 처지면서 이런 어긋남이 생깁니다. / 문틀 쪽 쇠판에 긁힌 자국이 반짝인다면 매번 걸쇠가 그 자리를 긁고 있다는 뜻입니다.
그대로 두면 모터가 늘 힘을 더 써서 건전지가 빨리 닳고, 결국 또 문이 안 열리는 날이 옵니다.

# 여섯, 보조키와 안쪽 걸쇠도
보조키가 있는 집이라면 열쇠가 부드럽게 돌아가는지 확인하세요. / 쓰지 않는 보조키라면 가족이 무심코 잠그지 않도록 정해 두는 게 좋습니다.
안쪽 쇠고리 걸쇠가 헐거워 문 닫는 충격에 저절로 넘어간다면 위치를 다시 잡거나 바꿔야 합니다. / 아무도 없는 집에 걸쇠가 걸리면 밖에서 풀기가 어렵습니다.
걸쇠를 쓰는 집이라면 외출할 때 걸쇠가 풀려 있는지 한 번 눈으로 보고 나가는 습관을 들여 보세요.

# 원인별로 다시 막히지 않는 법
- 건전지였다면: 경고음이 처음 난 날 바로 전부 교체
- 번호였다면: 새 번호를 가족과 함께 정하고 휴대폰 메모에 힌트만 남기기
- 열쇠였다면: 여벌 열쇠를 집 밖 믿을 만한 곳에 하나 두기
- 걸쇠였다면: 문 맞물림 조정 후 몇 주 동안 잠금 느낌 지켜보기
원인을 하나로 단정하기 어렵다면 그 자리에서 함께 이야기해 정하면 됩니다.
같은 원인으로 두 번 이상 막혔다면 습관보다 도어락이나 문 자체의 문제일 가능성이 큽니다. / 그때는 수리나 교체를 진지하게 따져 볼 때입니다.

# 일곱, 비상 수단을 하나 더 만들어 두기
번호만 쓰던 집이라면 카드나 지문을, 지문만 쓰던 집이라면 번호를 하나 더 등록해 두세요. / 들어갈 방법이 둘이면 하나가 막혀도 문 앞에서 오래 서 있지 않아도 됩니다.
비상용 9V 건전지 하나를 가방이나 차에 넣어 두는 것도 좋은 습관입니다. / 비상 단자가 바깥 어디에 있는지도 이참에 같이 확인해 두세요.

# 세 들어 사는 집이라면 기록 남기기
도어락이나 손잡이에 문제가 있었다면 어떤 상태였는지 사진으로 남겨 두세요. / 집주인에게 알릴 때도, 나중에 퇴거할 때 이야기할 때도 도움이 됩니다.
수리가 필요하다면 누가 맡을지 집주인과 먼저 상의해 보시는 게 좋습니다. / 수리 방식은 [도어락 수리](doorlock-repair.html), 바꿔야 한다면 [도어락 교체](doorlock-replace.html)를 참고하세요.

# 문을 여는 단계부터 필요하다면
아직 문이 잠겨 있는 상황이라면 먼저 그 집에 사시는 분인지 신분증 주소, 우편물, 집주인 확인 가운데 하나로 확인한 뒤 엽니다. / 비용은 문 상태를 보고 시작 전에 말씀드리고, 끝내 열지 못하면 받지 않습니다.
여는 방식은 [현관문 개문](door-open.html), 전체 진행은 [이용안내](guide.html)에 정리해 두었습니다. / 문을 연 뒤에는 위 항목을 함께 하나씩 확인해 드립니다.
@ 오전동 출장열쇠 개방 후 점검 재발 방지
