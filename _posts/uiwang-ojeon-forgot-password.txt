# 오전동에서 번호가 갑자기 떠오르지 않을 때
퇴근하고 현관 앞에 섰는데 손가락이 번호판 위에서 멈추는 일은 생각보다 흔합니다. / 평소에는 손이 알아서 누르던 번호가 막상 생각하려 하면 사라져 버립니다.
오전동은 의왕역 쪽 생활권과 이어진 주택가와 빌라가 많은 동네라, 문 앞에서 이런 일을 겪고 전화 주시는 분이 꾸준히 계십니다. / 이 글은 번호가 기억나지 않을 때 어떻게 해야 문이 덜 상하고 일이 빨리 끝나는지 적었습니다.
먼저 당황하지 않으셔도 됩니다. / 문을 부수지 않고 여는 방법이 있고, 열고 난 뒤 새 번호를 정하는 것까지 같이 해드립니다.

# 틀린 번호를 계속 누르면 생기는 일
번호를 여러 번 틀리면 도어락이 한동안 입력을 막아 버립니다. / 그 상태에서 계속 누르면 대기 시간이 길어지고, 소리까지 계속 울려 이웃 눈치가 보입니다.
서너 번 눌러 보고 안 되면 잠깐 손을 떼고 숨을 돌리는 편이 낫습니다. / 잠금이 풀리는 시간은 제품마다 달라서, 기다리는 동안 아래 내용을 먼저 떠올려 보시면 됩니다.
번호판에 손자국이 진하게 남아 있으면 어떤 숫자를 자주 눌렀는지 대충 짐작이 되기도 합니다. / 다만 그 흔적을 보고 하나씩 대입하는 것은 권하지 않습니다.
@ 오전동 도어락 비밀번호 분실 출장열쇠

# 먼저 떠올려 볼 만한 번호
번호를 잊었을 때 의외로 도움이 되는 것은 마지막으로 번호를 바꾼 때를 떠올리는 일입니다. / 이사 직후였는지, 도어락을 새로 달았을 때였는지에 따라 후보가 좁혀집니다.
- 이사 들어올 때 임시로 넣어 둔 번호
- 가족 구성원이 함께 쓰기로 정한 번호
- 도어락을 처음 설치했을 때의 초기 설정 번호
- 예전 집에서 쓰던 번호와 비슷한 패턴
이 중에서 한두 가지만 시도해 보고, 그래도 안 열리면 더 누르지 않는 편이 안전합니다.

# 가족이 바꿔 놓았을 수도 있습니다
같이 사는 가족이 번호를 바꾸고 말하지 않은 경우도 많습니다. / 아이가 장난으로 바꿨거나, 부모님이 외우기 쉽게 고쳐 놓았을 수도 있습니다.
전화가 닿는 가족이 있다면 먼저 한 번만 물어보시는 게 가장 빠릅니다. / 연락이 안 되거나 번호를 아무도 모르면 그때 전화 주시면 됩니다.
번호를 바꾼 사람이 정확한 숫자를 알려줘도 안 열리면 번호판 쪽 문제일 수 있습니다. / 이 경우는 번호 분실이 아니라 도어락 고장이라서 진행 방식이 달라집니다.

# 번호판 상태로 원인 가려 보기
번호 분실인지 고장인지 가르는 방법이 있습니다. / 번호판을 눌렀을 때 불이 들어오고 삑 소리가 나면 전원은 살아 있다는 뜻입니다.
불은 들어오는데 눌러도 열리지 않으면 번호가 틀린 것입니다. / 아예 불이 안 들어오면 배터리 방전을 먼저 의심해야 합니다.
배터리가 원인이면 번호는 그대로 살아 있으니 비상 전원만 대도 열립니다. / 이 구분만 해도 전화로 상황을 설명하기가 훨씬 쉬워집니다.

# 오전동 주택가 현관은 이런 점이 다릅니다
빌라나 주택가 현관은 도어락 외에 보조키가 따로 달려 있는 집이 많습니다. / 번호를 잊었는데 보조키까지 잠겨 있으면 두 곳을 모두 풀어야 하니 미리 말씀해 주세요.
오래된 건물은 문틀이 조금씩 틀어져 있어서 잠금장치가 평소보다 빡빡하게 걸리기도 합니다. / 이런 문은 손잡이를 세게 당기면 걸쇠가 더 물리니 힘을 주지 않는 편이 좋습니다.
현관 앞 계단이나 좁은 복도에서 작업하게 되는 집도 있어서, 도착하면 작업할 공간부터 같이 살펴봅니다.
@ 의왕 출장열쇠 오전동 현관문 개문

# 전화하실 때 이것만 말씀해 주세요
정확한 주소와 지금 상황을 짧게 알려주시면 출동 준비가 빨라집니다. / 길게 설명하지 않으셔도 아래 몇 가지면 충분합니다.
- 건물 형태(빌라, 주택, 상가 등)와 몇 층인지
- 번호판 상태(불이 들어오는지, 소리가 나는지)
- 현관에 보조키가 따로 있는지
- 집 안에 아이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙겨 가기 좋습니다. / 의왕 어디든 24시간 받으니 늦은 시간이어도 괜찮습니다.

# 도착하면 신분 확인부터 합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리실 확인 중 하나면 됩니다.
번거로우시겠지만 이웃과 집주인을 지키는 절차라서 생략하지 않습니다. / 신분증이 집 안에 있다면 휴대폰에 저장된 계약서나 우편물 사진으로 대신하는 방법도 상의해 볼 수 있습니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다. / 이 과정은 [이용안내](guide.html)에도 적어 두었습니다.

# 문은 최대한 상하지 않게 엽니다
번호를 몰라도 도어락과 문틀을 상하게 하지 않고 여는 방법을 먼저 시도합니다. / 덜 상하는 방법부터 차례로 해보고, 그래도 안 될 때만 다음 방법으로 넘어갑니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 먼저 말씀드립니다. / 허락 없이 부품을 교체하거나 갑자기 비용을 붙이는 일은 없습니다.
열리는 방식이 궁금하시면 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.

# 비용은 열기 전에 말씀드립니다
현관문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
번호 하나 잊은 일로 도어락을 통째로 바꾸라고 권하지 않습니다. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.

# 열고 나서 새 번호 정하기
문이 열리면 안쪽에서 새 번호를 등록하는 것까지 도와드립니다. / 기존 번호는 지우고 새 번호만 남겨 둡니다.
새 번호는 생일이나 전화번호 뒷자리처럼 남이 짐작하기 쉬운 숫자는 피하는 편이 좋습니다. / 대신 가족이 모두 기억할 수 있는 규칙을 하나 정해 두면 같은 일이 줄어듭니다.
번호를 정하면 닫힌 문 앞에서 한 번, 열린 상태에서 한 번 직접 눌러 보고 확인합니다. / 이 확인을 건너뛰면 다음 날 같은 일이 생기기 쉽습니다.
@ 오전동 도어락 새 번호 등록 점검

# 같은 일이 또 생기지 않게 하는 방법
번호를 자주 잊는 분은 번호 외에 열 수 있는 방법을 하나 더 만들어 두시면 좋습니다.
- 카드키나 태그를 지갑이나 가방에 하나 따로 보관
- 가족과 번호를 같이 정하고 바꿀 때는 꼭 알리기
- 배터리는 해가 바뀔 때 한 번에 교체
- 비상용 9V 건전지 하나를 가방에 넣어 두기
도어락을 새로 달 계획이라면 [도어락 교체](doorlock-replace.html) 페이지를 먼저 보시고 상담하셔도 됩니다.

# 오전동 말고 의왕 어디든 갑니다
오전동 바로 옆 고천동, 부곡동, 내손동, 포일동도 다닙니다. / 의왕 안이면 동네 상관없이 24시간 출동합니다.
의왕에서 다니는 동네는 [의왕시 출장열쇠](uiwang.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

# 자주 묻는 질문
? 비밀번호를 몰라도 문을 안 상하게 열 수 있나요? | 네, 도어락과 문틀이 상하지 않는 방법부터 시도합니다. 상태를 보고 먼저 말씀드립니다.
? 번호를 여러 번 틀렸는데 계속 눌러도 되나요? | 서너 번 눌러 보고 안 되면 멈추세요. 계속 누르면 입력이 오래 막힙니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
? 세입자인데 집주인 허락이 필요한가요? | 사시는 분인지만 확인되면 됩니다. 신분증이나 주소가 적힌 우편물을 준비해 주세요.
? 열고 나서 번호도 바꿔 주시나요? | 네, 새 번호 등록과 확인까지 같이 해드립니다.
