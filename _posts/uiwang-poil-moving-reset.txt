# 포일동 입주, 짐보다 먼저 챙길 현관 설정
포일동은 새 아파트가 많은 동네라 입주하는 날 현관에는 이미 도어락이 달려 있습니다. / 편하긴 하지만 그 도어락이 지금까지 누구에게 열려 왔는지는 한 번 생각해 볼 일입니다.
입주 전 점검, 인테리어 공사, 줄눈 시공, 입주 청소처럼 여러 사람이 드나드는 동안 임시 번호가 오갔을 수 있습니다. / 이 글은 포일동 아파트에 들어간 뒤 도어락 번호와 카드, 공동현관, 앱 연동까지 다시 맞추는 순서를 체크리스트처럼 정리했습니다.
@ 포일동 아파트 입주 도어락 번호 재설정

# 입주 전후로 번호를 알게 된 사람들
번호를 바꿔야 하는 이유는 누가 번호를 알고 있는지 다 셀 수 없기 때문입니다. / 한 번 떠올려 보세요.
- 입주 전 점검 때 함께 들어온 가족이나 지인
- 인테리어, 가구 설치, 가전 설치 기사
- 입주 청소나 줄눈 시공 업체
- 이사 업체 직원
- 전세나 월세라면 전 거주자와 집주인, 부동산
이분들이 문제를 일으킨다는 뜻은 아닙니다. / 다만 이사가 끝나면 그 번호는 더 이상 필요 없으니 깔끔하게 정리하는 게 맞습니다.

# 체크 하나, 새 비밀번호 등록
새 아파트 도어락은 안쪽 몸체 배터리 덮개 근처에 등록 버튼이 있는 경우가 많습니다. / 입주 안내문이나 설명서가 함께 왔다면 그 순서를 먼저 따르세요.
- 문을 활짝 연 상태에서 시작하기
- 등록 버튼을 누르고 안내음이 나면 새 번호 입력
- 확인 버튼으로 저장하고 열린 상태에서 새 번호 시험
- 예전 번호를 눌러 안 열리는 것까지 확인
문을 닫고 시험하는 것만은 피해 주세요. / 등록이 덜 됐을 때 바깥에서 들어갈 방법이 없어집니다.

# 체크 둘, 세대 카드와 태그 정리
입주할 때 받은 카드키가 몇 장인지 세어 보세요. / 인테리어 기간에 업체에 맡겼던 카드가 있다면 돌려받았는지도 확인해야 합니다.
카드는 하나씩 지우기 어려운 제품이 많아 전체 삭제 후 가지고 있는 카드만 다시 등록하는 것이 확실합니다. / 돌려받지 못한 카드가 있어도 이렇게 하면 그 카드로는 더 이상 열리지 않습니다.
@ 의왕 포일동 세대 카드키 다시 등록

# 체크 셋, 공동현관과 연결된 카드라면
아파트에 따라 세대 카드 하나로 공동현관과 세대 현관을 함께 여는 경우가 있습니다. / 이럴 때 세대 도어락에서 카드를 지워도 공동현관 쪽은 따로 남아 있을 수 있습니다.
공동현관 등록은 대부분 관리사무소에서 관리합니다. / 세대 쪽 정리를 마친 뒤 관리사무소에 카드 목록 정리를 함께 요청하시면 됩니다.
반대로 카드를 새로 추가할 때도 공동현관은 관리사무소 등록이 필요할 수 있으니 미리 알아 두세요.

# 체크 넷, 지문과 앱 연동
지문 도어락이라면 지문도 전체 삭제한 뒤 가족 지문을 다시 등록합니다. / 한 사람당 손가락 두 개 정도를 등록해 두면 손을 다쳤을 때도 열 수 있습니다.
휴대폰 앱이나 집 안 월패드와 연동되는 도어락이라면 연동 계정도 확인해 주세요. / 이전 거주자 계정이 남아 있으면 출입 알림이 그쪽으로 갈 수도 있습니다.
연동을 새로 할 때는 공유기 연결과 앱 로그인을 함께 맞춰야 하니 시간이 조금 걸립니다.
인터넷 개통이 이사 며칠 뒤로 잡혀 있다면 앱 연동은 개통 뒤로 미뤄도 괜찮습니다. / 번호와 카드 정리만 먼저 끝내 두면 그동안 출입에는 문제가 없습니다.
월패드에서 현관 열림 기록이 보이는 집이라면 입주 후 며칠 동안 기록을 한 번씩 살펴보세요. / 정리한 뒤로 모르는 시간에 열린 기록이 없다면 안심하셔도 됩니다.

# 체크 다섯, 배터리 새것으로
입주 전 몇 달 동안 비어 있던 집이라면 배터리가 생각보다 닳아 있을 수 있습니다. / 입주 날 한꺼번에 새것으로 바꾸고 교체한 날을 덮개 안쪽에 적어 두세요.
이사 첫 달은 문을 여닫는 일이 평소보다 훨씬 많아 배터리가 더 빨리 줄어듭니다. / 경고음이 들리면 미루지 말고 바로 바꿔 주세요.
배터리는 같은 종류로 한 번에 모두 바꾸는 것이 좋습니다. / 들어 있던 배터리 몇 개만 바꾸면 남은 헌 배터리 때문에 금방 다시 경고음이 납니다.

# 하자 기간이라면 관리사무소부터
입주한 지 얼마 안 된 새 아파트에서 도어락이 이상하다면 먼저 관리사무소나 하자 접수 창구에 알려 주세요. / 기본으로 설치된 도어락은 하자 처리 대상일 수 있습니다.
하자 접수가 오래 걸리는데 당장 문이 안 열리는 상황이라면 그때 출장을 부르셔도 됩니다. / 문을 연 뒤 상태를 사진으로 남겨 두면 하자 접수에도 도움이 됩니다.

# 혼자 설정하다 막혔다면
등록 버튼을 눌렀는데 안내음이 계속 울리거나, 설정 중에 이전 번호까지 안 먹히는 일이 생길 수 있습니다. / 그럴 때는 문을 열어 둔 상태 그대로 멈추고 연락 주세요.
이미 문이 닫혀 잠겼다면 억지로 열지 마시고 상황만 알려주시면 됩니다. / 문을 연 뒤 등록까지 마무리해 드립니다.

# 포일동에서 출장 설정을 부르실 때
입주 날 바쁘셔서 설정을 맡기고 싶다면 아래 내용을 알려주세요.
- 아파트 이름, 동, 호수, 공동현관 출입 방법
- 도어락 앞뒤 사진과 모델명
- 쓰는 방식 (번호, 카드, 지문, 앱)
- 필요한 카드 개수와 등록할 가족 수
설명서가 있다면 사진을 함께 보내 주시면 더 빠릅니다. / 이삿짐이 현관을 막고 있다면 도어락 앞만 조금 비워 두셔도 충분합니다.
@ 포일동 입주 도어락 출장 설정

# 입주자 확인과 비용 안내
도어락 설정을 바꾸는 일은 그 집에 들어가 사는 분만 맡길 수 있습니다. / 신분증 주소, 분양이나 임대차 계약서, 관리사무소 입주 확인 가운데 하나로 확인합니다.
번호 재설정만 할지, 카드 추가나 앱 연동까지 할지 정한 뒤 비용을 먼저 말씀드리고 동의하실 때만 진행합니다. / 잠긴 문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에 있습니다.

# 입주 첫 달에 함께 해 두면 좋은 것
가족 번호는 하나로 정하고, 손님이나 도우미에게 알려 줄 번호는 따로 정해 두세요. / 임시 번호 기능이 있는 제품이라면 그 기능을 쓰는 것이 편합니다.
카드키를 누구에게 몇 장 줬는지 휴대폰 메모에 적어 두면 하나를 잃어도 바로 정리할 수 있습니다. / 도어락이 마음에 안 들어 바꾸고 싶다면 [도어락 교체](doorlock-replace.html)나 [도어락 설치](doorlock-install.html), 기능 이상은 [도어락 수리](doorlock-repair.html) 안내를 참고해 주세요.

# 포일동 말고 의왕 어디든 갑니다
포일동 가까운 내손동, 청계동, 학의동은 물론 오전동, 고천동, 부곡동까지 다닙니다. / 의왕 안이면 동네 상관없이 24시간 출동합니다.
의왕에서 다니는 곳은 [의왕시 출장열쇠](uiwang.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
