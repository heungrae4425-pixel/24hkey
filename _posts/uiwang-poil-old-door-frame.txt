# 포일동 현관문, 새 집인데 왜 걸릴까
포일동은 새 아파트가 많은 의왕 동네입니다. / 오래된 문틀 이야기는 낡은 주택에서나 나오는 줄 알지만, 입주하고 몇 해가 지나면 새 아파트 현관문도 조금씩 변합니다.
처음엔 손끝으로 밀어도 사뿐히 닫히던 문이 어느새 끝에서 턱 걸리고, 잠글 때 문을 한 번 더 밀어야 걸쇠가 들어갑니다. / 그대로 쓰다 보면 어느 날 걸쇠가 문틀에 꽉 물려 번호를 눌러도 문이 안 열리는 일이 생깁니다.
이 글은 포일동 아파트에서 현관문이 처지거나 경첩이 헐거워졌을 때 살펴볼 곳과, 문이 안 열릴 때의 대처를 정리했습니다. / 손으로 안 되면 [의왕 출장열쇠](uiwang.html)로 연락 주세요.
@ 포일동 아파트 현관문 처짐 경첩

# 새 문도 처지는 이유
아파트 현관문은 철판으로 만든 데다 안에 단열재가 들어 있어 꽤 무겁습니다. / 이 무게를 옆쪽 경첩 몇 개가 하루에도 수십 번씩 버텨 냅니다.
여닫을 때마다 경첩 나사에 조금씩 힘이 실리고, 시간이 지나면 나사가 아주 조금 풀리거나 경첩 축이 닳습니다. / 그 작은 차이가 문 끝에서는 눈에 보일 만큼 커집니다.
건물이 자리를 잡는 동안 문틀이 미세하게 틀어지기도 하고, 계절마다 철판이 늘었다 줄었다 하는 것도 영향을 줍니다. / 그래서 새 아파트라도 몇 해에 한 번은 문 맞물림을 다시 볼 필요가 있습니다.

# 처지기 시작했다는 신호
- 문을 닫을 때 마지막에 턱 하고 걸리는 느낌
- 잠글 때 문을 밀거나 들어 올려야 걸쇠가 들어감
- 문 아래쪽이 바닥이나 문턱에 살짝 끌리는 소리
- 문 위쪽 틈과 아래쪽 틈 넓이가 눈에 띄게 다름
- 문틀 쪽 걸쇠 받이 쇠판에 반짝이는 긁힘 자국
이 가운데 하나라도 보인다면 문이 처지기 시작한 겁니다. / 아직 잘 열리고 잠긴다면 이때가 손보기 가장 쉬운 시기입니다.
식구 가운데 누군가 문을 닫을 때 늘 어깨로 툭 밀어 닫는다면, 그것도 처짐을 알려 주는 신호일 수 있습니다. / 몸이 먼저 불편함을 알아채고 습관을 바꾼 셈입니다.

# 틈을 눈으로 확인하는 법
문을 닫은 채로 문과 문틀 사이 틈을 위에서 아래로 훑어보세요. / 경첩 반대쪽, 즉 손잡이 쪽 틈이 위는 넓고 아래는 좁다면 문 끝이 아래로 내려앉은 겁니다.
저녁에 집 안 불을 켜고 바깥에서 보면 틈으로 새어 나오는 빛의 굵기로 더 쉽게 알 수 있습니다. / 빛이 위쪽에서만 굵게 새고 아래쪽은 거의 안 보인다면 처짐이 꽤 진행된 상태입니다.
@ 포일동 현관문 틈 확인 문틀 맞물림

# 경첩 나사부터 보세요
문을 활짝 열고 경첩을 살펴보세요. / 나사 머리가 조금 튀어나와 있거나, 문을 위아래로 살짝 흔들 때 경첩 쪽이 덜컥거린다면 나사가 풀린 겁니다.
나사가 조금 풀린 정도라면 맞는 드라이버로 조여 주는 것만으로 나아지기도 합니다. / 다만 너무 세게 조이다 나사 구멍이 뭉개지면 오히려 고정이 약해지니 손힘으로 적당히만 조이세요.
나사를 조였는데도 문이 그대로라면 경첩 자체의 높이나 각도를 조정해야 합니다. / 이 작업은 무거운 문을 받친 채 해야 해서 혼자 하기는 어렵습니다.
경첩 둘레 문틀에 금이 가 있거나 칠이 들떠 있다면 나사가 박힌 바탕이 약해진 경우입니다. / 이럴 때는 나사만 조여서는 오래 버티지 못하니 점검을 받아 보세요.

# 도어클로저도 문을 끌어당깁니다
문 위쪽 도어클로저는 문이 닫히는 힘을 조절하는데, 힘이 너무 세면 문이 문틀에 세게 부딪히며 경첩에 충격을 줍니다. / 매번 쾅 하고 닫히는 문은 처짐도 빨리 옵니다.
반대로 클로저 힘이 약해지면 문이 끝까지 닫히지 않아 걸쇠가 받이에 반쯤만 걸립니다. / 처짐과 클로저 문제가 겹치면 증상이 더 헷갈리니 둘을 함께 보는 게 좋습니다.

# 걸쇠와 받이가 어긋났을 때
문이 처지면 걸쇠 높이도 같이 내려갑니다. / 걸쇠가 문틀 구멍 아래 가장자리에 닿으면서 긁히고, 결국 구멍에 들어가지 못합니다.
받이 쇠판 위치를 조금 옮겨 맞추는 방법도 있지만, 처짐을 그대로 둔 채 받이만 옮기면 몇 달 뒤 또 어긋납니다. / 경첩부터 바로잡고 그다음 받이를 보는 순서가 맞습니다.
걸쇠 끝이 이미 둥글게 닳아 있다면 받이에 들어가도 깊이 물리지 않아 잠금이 얕아집니다. / 이 경우는 조정과 함께 걸쇠 쪽 부품 상태도 봐야 합니다.

# 문이 안 열릴 때 해 볼 것과 피할 것
번호는 맞는데 모터 소리만 나고 안 열린다면 걸쇠가 문틀에 눌려 있는 겁니다. / 손잡이 쪽을 살짝 들어 올리듯 밀거나 당기면서 다시 번호를 눌러 보세요.
몇 번 해도 안 된다면 거기서 멈추세요. / 문을 발로 차거나 어깨로 밀면 걸쇠가 더 휘고 경첩에도 무리가 갑니다.
- 문틈에 드라이버나 쇠자 넣지 않기
- 걸쇠 틈에 기름 뿌리지 않기
- 경첩 나사를 전부 풀어 보지 않기

# 입주 초기라면 관리 쪽에도 물어보세요
입주한 지 오래되지 않은 단지라면 문과 문틀 문제를 관리사무소에 먼저 알려 보세요. / 단지마다 처리 방식이 달라서, 어떻게 진행되는지 확인해 두시면 됩니다.
문이 안 열려 당장 들어가야 하는 상황이라면 그 문제부터 해결하고, 나머지는 그다음에 관리 쪽과 이야기하셔도 늦지 않습니다.

# 포일동에서 연락 주실 때
- 아파트 동과 호수
- 문이 안 열리는지, 뻑뻑하기만 한지
- 위에서 본 신호 가운데 어떤 것이 보이는지
- 문 전체, 경첩, 걸쇠 받이 사진
사진이 있으면 조정으로 끝날지, 부품을 바꿔야 할지 미리 가늠할 수 있습니다. / 늦은 시간이라도 문이 안 열린다면 바로 전화 주세요.
문이 열린 채로 안 닫히는 상황이라면 그 점도 꼭 알려 주세요. / 밤새 문을 열어 둘 수는 없으니 먼저 잠글 수 있게 손보는 것부터 합니다.

# 확인과 비용 안내 후 시작합니다
잠긴 문을 열어야 한다면 그 집에 사시는 분인지 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 가운데 하나로 먼저 확인합니다. / 확인 없이 문을 열지는 않습니다.
문과 경첩 상태를 본 뒤 비용을 먼저 말씀드리고, 괜찮다고 하시면 시작합니다. / 끝내 열지 못하면 받지 않습니다. / 자세한 진행은 [이용안내](guide.html)와 [현관문 개문](door-open.html)에 있습니다.
@ 포일동 출장열쇠 경첩 조정 문틀 점검

# 조정한 뒤 지켜볼 것
경첩과 받이를 맞춘 뒤에는 문을 여러 번 여닫으며 걸림 없이 닫히는지, 도어락이 한 번에 잠기는지 확인합니다. / 몇 주 동안 잠금 느낌이 다시 무거워지지 않는지 지켜봐 주세요.
걸쇠가 이미 많이 닳았다면 [도어락 수리](doorlock-repair.html)로 손보고, 도어락까지 낡았다면 [도어락 교체](doorlock-replace.html)를 함께 말씀드립니다.

# 포일동 말고 의왕 다른 동네도
내손동, 오전동, 고천동, 부곡동, 청계동, 학의동까지 의왕 어디든 갑니다. / 다른 지역은 [출장 지역](area.html)에서 확인하세요.
