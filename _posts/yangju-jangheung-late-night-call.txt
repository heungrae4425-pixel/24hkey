# 장흥면 밤길 끝, 불 꺼진 현관 앞에서
장흥면은 양주 남쪽에 계곡과 숲을 끼고 전원주택과 펜션, 주말 주택이 흩어져 있는 곳입니다. / 낮에는 오가는 차가 있어도 밤이 깊으면 가로등이 드문 길이 이어지고 이웃집과 거리도 멉니다.
그런 시간에 현관이나 대문이 안 열리면 도시 아파트보다 훨씬 막막하게 느껴집니다. / 누구를 불러야 할지, 불러도 이 시간에 여기까지 와 줄지부터 걱정이 됩니다.
이 글은 장흥면에서 한밤과 새벽에 문이 안 열려 전화할 때 무엇부터 말하면 되는지 세 가지로 정리했습니다. / 시간 걱정 없이 [양주 출장열쇠](yangju.html)로 연락 주세요.
@ 장흥면 전원주택 한밤중 현관 안 열림

# 첫째로 말할 것, 지금 안전한지
통화가 이어지면 가장 먼저 지금 계신 곳이 안전한지 말씀해 주세요. / 밤 기온이 많이 내려갔는지, 차 안에 계신지, 바깥에 서 계신지가 중요합니다.
겨울밤 장흥면 골짜기는 시내보다 기온이 낮게 느껴지는 곳이 많습니다. / 차가 있다면 차 안에서 기다리시고, 차가 없다면 바람을 피할 수 있는 처마 아래나 현관 앞에 계세요.
집 안에 아이나 어르신, 반려동물이 있다면 그것도 이때 함께 말씀해 주세요. / 이런 경우에는 다른 일보다 먼저 움직입니다.

# 둘째로 말할 것, 들어오는 길
장흥면은 주소만으로는 찾아가기 어려운 집이 꽤 있습니다. / 내비게이션이 마을 입구까지만 안내하고, 그다음 갈림길에서 헤매는 일이 흔합니다.
주소와 함께 큰길에서 들어오는 길을 짧게 알려 주세요. / 어느 다리를 건너는지, 갈림길에서 어느 쪽인지, 집 앞에 무엇이 보이는지 정도면 충분합니다.
휴대폰 지도 앱의 내 위치 공유 기능을 쓰실 수 있다면 문자로 위치를 보내 주셔도 좋습니다. / 거리가 있는 곳이라 위치를 받고 도착 시간을 먼저 말씀드립니다.
@ 장흥면 밤길 위치 설명 출장열쇠

# 셋째로 말할 것, 어느 문이 어떻게 막혔는지
전원주택은 대문, 현관, 차고 문처럼 드나드는 곳이 여럿입니다. / 어느 문에서 막혔는지에 따라 챙겨 갈 도구가 달라집니다.
- 대문인지 현관인지, 둘 다인지
- 번호판이 꺼졌는지, 켜지는데 안 열리는지
- 열쇠 자물쇠라면 열쇠를 잃었는지, 안 돌아가는지
- 안쪽 걸쇠나 이중 잠금이 걸렸을 수 있는지
도어락 사진을 찍을 수 있다면 플래시를 켜고 한 장 보내 주세요. / 어두운 곳에서는 번호판 모양만 보여도 큰 도움이 됩니다.

# 세 가지를 말한 뒤에 기다리는 법
통화가 끝나면 도착 시간을 알려 드립니다. / 기다리는 동안 휴대폰 배터리를 아끼려면 화면 밝기를 낮추고 다른 앱은 닫아 두세요.
집 앞 길이 어둡다면 도착 시간 즈음 휴대폰 손전등이나 차 비상등을 켜 두세요. / 멀리서도 어느 집인지 알아보기 쉬워집니다.
혼자 기다리는 게 불안하시면 가족이나 지인에게 지금 상황과 위치를 문자로 남겨 두세요. / 도착하면 집 앞에서 먼저 전화를 드립니다.

# 기다리는 동안 해볼 수 있는 것
번호판이 꺼졌다면 9V 건전지로 비상 전원을 대 볼 수 있습니다. / 차 안이나 가방에 9V 건전지가 있다면 바깥 번호판 아래 단자에 대고 번호를 눌러 보세요.
밤에 가게를 찾기 어려운 곳이라 건전지를 사러 나서지는 마세요. / 어두운 길을 오가는 것보다 그대로 기다리시는 편이 안전합니다.
번호가 안 맞는다면 서너 번 시도하고 멈추세요. / 계속 누르면 입력 제한이 걸려 한동안 반응하지 않습니다.

# 오래 비운 집에서 밤에 막히는 이유
장흥면은 주말이나 계절마다 찾는 집이 많아 오랜만에 밤늦게 도착하는 경우가 흔합니다. / 비어 있는 동안 건전지가 다 돼 번호판이 꺼져 있는 일이 가장 많습니다.
겨울에는 추위로 건전지 힘이 더 빨리 떨어지고, 여름 장마 뒤에는 번호판에 습기가 차기도 합니다. / 출발하기 전날 낮에 도착 시간을 정해 두고, 밤 도착이라면 9V 건전지 하나를 꼭 챙기세요.
@ 장흥면 주말 주택 밤 도착 도어락

# 문 앞에서 하지 말아야 할 일
어두운 곳에서 손잡이를 세게 당기거나 문을 차면 다치기 쉽습니다. / 창문을 넘어 들어가려는 것도 밤에는 특히 위험합니다.
드라이버나 돌로 도어락을 건드리면 문이 상해 그날 밤 문을 다시 잠그지 못할 수 있습니다. / 외딴 집일수록 문을 제대로 잠그는 것이 중요하니 그대로 두고 기다려 주세요.
대문을 넘어 마당으로 들어가는 것도 밤에는 권하지 않습니다. / 담장 위나 마당 바닥 상태가 잘 보이지 않아 넘어지기 쉽고, 들어가도 현관이 잠겨 있으면 다시 나오기 어렵습니다.
마당에서 개를 키우는 집이라면 주인이 대문 밖에 있는 동안 개가 놀라 크게 짖기도 합니다. / 도착하는 쪽에도 미리 알려 주시면 조심해서 다가갑니다.

# 도착하면 확인부터 합니다
밤이라도 확인 절차는 똑같습니다. / 신분증 주소, 주소가 나온 우편물, 집주인이나 관리하시는 분 확인 중 하나면 됩니다.
펜션처럼 운영하는 곳이라면 사업자등록증이나 운영자 확인으로도 가능합니다. / 신분증이 집 안에 있다면 휴대폰에 저장된 계약서 사진도 도움이 됩니다.
주말 주택이라 우편물이 다른 주소로 가는 집이라면 등기부나 재산세 고지서 사진처럼 그 집 주소가 나온 자료를 찾아 두세요. / 그런 자료도 없다면 통화할 때 미리 말씀해 주시면 확인 방법을 함께 정합니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 밤에도 비용 안내 방식은 같습니다
문과 도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하실 때만 시작하고, 끝내 못 열면 비용은 받지 않습니다.
덜 상하는 방법부터 차례로 시도하고, 밤에는 장비 소리도 줄입니다. / 문 여는 방식은 [현관문 개문](door-open.html)에서 보실 수 있습니다.

# 문이 열린 뒤 그날 밤 해 둘 일
문이 열리면 도어락이 잘 잠기고 열리는지 확인하고 건전지를 새것으로 바꿉니다. / 대문과 현관 모두 문제가 있었다면 두 곳 다 점검합니다.
손볼 부품이 있다면 그날 밤 할지, 날이 밝은 뒤에 할지 함께 정합니다. / 고장이 잦은 도어락이라면 [도어락 수리](doorlock-repair.html)를 먼저 권합니다.

# 다음 밤을 위해 준비해 둘 것
- 차 안에 9V 건전지와 작은 손전등 하나 두기
- 집 밖 믿을 만한 곳에 여벌 열쇠나 카드 맡겨 두기
- 대문과 현관 건전지를 같은 날 바꾸고 날짜 적기
- 출장 번호를 휴대폰 즐겨찾기에 저장하기
이 네 가지만 해 두셔도 밤길 끝에서 막히는 일이 훨씬 줄어듭니다. / 현관 앞에 센서 등이 있다면 전구가 살아 있는지도 가끔 확인해 주세요, 밤에 번호판을 누를 때 생각보다 큰 도움이 됩니다.

# 장흥면 말고 양주 어디든
장흥면뿐 아니라 옥정동, 고읍동, 삼숭동과 백석읍, 광적면, 남면까지 양주 어디든 밤낮없이 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 보세요.
