# 삼숭동 베란다 문과 미닫이문 잠금장치, 현관만큼 중요합니다
현관문 도어락은 신경을 쓰면서도 베란다 문이나 미닫이문의 잠금장치는 잊고 지내는 집이 많습니다. / 그러다 어느 날 문이 안 잠기거나 안 열리면 그때서야 불편함이 크게 다가옵니다.
삼숭동처럼 주택과 빌라가 섞여 있는 동네는 베란다와 뒷문, 방문까지 잠금장치 종류가 다양합니다. / 이 글은 [양주 출장열쇠](yangju.html)를 부르기 전에 확인할 것을 문 종류별로 정리했습니다.
현관이 아니라고 가볍게 넘기지 말고 안에서 잠긴 문이라면 바로 읽어 보세요. / 집 안에 사람이 있는데 문이 막혔다면 7번 소제목부터 보시면 됩니다.
@ 삼숭동 베란다 미닫이문 잠금장치 출장열쇠

# 문 종류마다 잠금장치가 다릅니다
베란다 샷시는 크레센트라고 부르는 걸어 잠그는 장치를 많이 씁니다. / 미닫이 방문이나 욕실 문은 안쪽에서 누르거나 돌려 잠그는 간단한 장치가 흔합니다.
뒷문이나 창고 문은 열쇠형 자물쇠를 쓰는 집도 있어서 종류에 따라 접근 방법이 다릅니다. / 어느 문의 어떤 장치인지 알려주시면 챙길 장비가 정확해집니다.
사진을 한 장 찍어 두면 전화로 설명하기가 훨씬 편해집니다.
같은 집이라도 거실 베란다와 방 베란다의 장치가 서로 다른 경우가 있습니다. / 여러 문이 함께 문제라면 한 번 출동했을 때 같이 보는 편이 시간도 아낍니다.

# 베란다 문이 안 잠기는 흔한 이유
- 샷시가 처져 잠금 걸림쇠가 맞는 자리에 닿지 않는 경우
- 잠금 장치 속 부품이 닳아 돌려도 걸림이 약한 경우
- 문 아래 바퀴가 닳아 문이 한쪽으로 기울어진 경우
- 틈에 먼지가 쌓여 문이 끝까지 닫히지 않는 경우
문이 안 잠기는 상태로 지내면 방범과 냉난방 모두에 불안이 생깁니다. / 겨울철 찬바람과 여름 비 때문에라도 일찍 손보는 편이 좋습니다.
태풍이나 장마가 오기 전에 베란다 문이 제대로 잠기는지 확인해 두면 안심이 됩니다. / 잠금이 약한 문은 바람이 세게 불 때 덜컹거리다가 장치가 더 상하기도 합니다.

# 문을 끝까지 밀어 봐도 안 닫힌다면
미닫이 문의 아래 레일에 먼지와 이물질이 끼면 문이 끝까지 닫히지 않습니다. / 레일을 청소기나 솔로 먼저 정리해 보세요.
문이 레일에서 벗어난 듯 기울어 있다면 무리하게 밀지 말고 그대로 두세요. / 억지로 밀면 바퀴가 부러지거나 샷시가 휘는 일이 생깁니다.
잠금은 문이 제자리에 있어야 걸리는 구조라 위치부터 바로잡는 것이 먼저입니다.
@ 삼숭동 샷시 잠금장치 점검 양주 출장

# 잠금장치가 안 풀려 문이 안 열릴 때
안쪽에서 잠근 크레센트가 돌아가지 않으면 문을 열 수 없습니다. / 장치가 뻑뻑해졌거나 부품이 어긋난 경우가 많습니다.
이럴 때 손잡이를 세게 돌리면 장치가 부러져 오히려 더 안 열리게 됩니다. / 힘을 빼고 위아래로 살짝 흔들어 보며 걸림이 풀리는지 보세요.
그래도 안 되면 억지로 하지 말고 상황을 알려주세요.

# 방문과 욕실 문이 안에서 잠겨 버렸다면
미닫이 방문이나 욕실 문은 안쪽 잠금을 누른 채 문이 닫혀 버리는 일이 잦습니다. / 가장 걱정되는 것은 안에 아이나 어르신이 있는 경우입니다.
이때는 문 너머로 계속 말을 걸어 안정시키고 안쪽에서 열 수 있는 방법을 천천히 알려주세요. / 상황이 급하거나 안에 계신 분의 안전이 걱정되면 먼저 119에 연락하는 것이 우선입니다.
급하지 않은 잠김이라면 연락 주세요. / 문을 상하지 않게 여는 방법부터 차례로 시도합니다.

# 하지 말아야 할 일
잠금이 안 풀린다고 문을 발로 차거나 어깨로 미는 것은 피해 주세요. / 샷시는 유리가 있어 깨지기 쉽고 다치는 일이 생길 수 있습니다.
칼이나 드라이버로 틈을 벌리려는 것도 문과 잠금장치를 모두 상하게 합니다. / 잠금장치에 기름을 많이 뿌리면 먼지가 엉겨 오히려 더 뻑뻑해집니다.
어떤 방법이든 힘이 많이 들어가야 한다면 거기서 멈추는 것이 안전합니다.

# 전화하실 때 알려주실 것
- 베란다, 방, 욕실, 뒷문 중 어느 문인지
- 안쪽에서 잠겼는지, 바깥에서 막혔는지
- 문이 열려 있는지, 완전히 닫혀 있는지
- 안에 아이나 어르신, 반려동물이 있는지
- 삼숭동 안에서 대략 어느 쪽인지
사진을 보내주시면 장치 종류를 알 수 있어 정확히 준비할 수 있습니다. / 위치를 받으면 예상 도착 시간을 먼저 말씀드립니다.

# 도착하면 사시는 분인지 확인합니다
집 안의 문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리인 확인 중 하나면 됩니다.
확인이 어려우면 작업을 하지 못하니 미리 준비해 두시면 좋습니다.

# 비용은 손대기 전에 말씀드립니다
문 종류와 잠금장치 상태를 보고 얼마가 드는지 먼저 알려드립니다. / 괜찮다고 하시면 시작하고 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하는 경우에는 바꾸기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 열고 난 뒤 이렇게 마무리합니다
문이 열리면 잠금장치가 다시 잘 돌아가는지, 문이 레일에서 어긋나지 않았는지 같이 봅니다. / 간단한 조정으로 해결되는 경우가 많아서 부품을 바꾸자는 말부터 하지 않습니다.
장치 자체가 낡았다면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)처럼 맞는 방법을 말씀드립니다. / 현관문 쪽 문제도 함께 있다면 [현관문 개문](door-open.html) 페이지를 참고하세요.
@ 삼숭동 베란다문 방문 잠금 수리 양주

# 잠금장치를 오래 쓰는 법
- 한 해에 두 번 레일과 잠금 부분을 청소하기
- 문을 닫을 때 끝까지 밀고 잠금이 걸렸는지 확인하기
- 안에서 잠그는 장치를 어린아이가 장난으로 돌리지 않게 가르치기
- 이상한 소리나 뻑뻑함이 느껴지면 일찍 점검하기
베란다 문은 쓰지 않는 계절이 길어 고장이 생겨도 늦게 발견되곤 합니다. / 계절이 바뀔 때 한 번씩 열고 닫아 보는 습관이 도움이 됩니다.
문틈에 낀 먼지는 마른 천으로 닦고 레일은 솔로 쓸어 내는 것만으로도 수명이 달라집니다. / 잠금 부분은 액체 세제보다 마른 천으로 닦는 쪽이 부품을 덜 상하게 합니다. / 닦다가 헐거운 부분이 보이면 그대로 두지 말고 꼭 알려주세요.

# 삼숭동 말고 양주 어디든 갑니다
삼숭동 가까운 고읍동, 옥정동은 물론 백석읍, 광적면, 장흥면, 남면까지 출동합니다. / 양주시 안이면 24시간 연락을 받습니다.
다니는 동네는 [양주시 출장열쇠](yangju.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
