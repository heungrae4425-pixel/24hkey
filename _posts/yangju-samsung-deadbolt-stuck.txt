# 삼숭동 현관, 잠금 막대가 중간에서 멈춘다면
삼숭동은 양주역, 덕정역 쪽 생활권과 이어진 양주 동네로 주택과 빌라가 섞여 있습니다. / 집마다 도어락과 열쇠 보조 자물쇠를 함께 쓰거나 하나만 쓰는 등 현관 사정이 다릅니다.
데드볼트는 문을 잠글 때 문틀 쪽으로 쑥 나가 박히는 굵은 잠금 막대입니다. / 이 막대가 끝까지 안 나가거나, 나간 채로 안 들어오면 문이 안 잠기거나 안 열리는 일이 생깁니다.
이 글은 데드볼트 문제를 만났을 때 도어락 탓인지 문 탓인지 먼저 가르는 방법과 그 다음 할 일을 적었습니다. / 지금 문이 안 열린다면 [양주 출장열쇠](yangju.html)로 바로 연락 주세요.
@ 삼숭동 현관 데드볼트 잠금 막대 걸림

# 문이 열려 있다면 이렇게 시험해 보세요
문이 열린 상태에서 막대 문제를 발견했다면 운이 좋은 편입니다. / 문을 연 채로 잠금과 열림을 해보면 원인을 바로 가를 수 있습니다.
문을 활짝 연 상태에서 번호를 누르거나 열쇠를 돌려 막대가 끝까지 나왔다 들어가는지 보세요. / 이때 막대가 부드럽게 끝까지 움직인다면 도어락이나 자물쇠는 멀쩡한 것입니다.
그런데 문을 닫으면 막대가 걸린다면 문틀 쪽 구멍과 막대 위치가 어긋난 것입니다. / 문이 열린 상태에서도 막대가 중간에 멈춘다면 그때는 도어락이나 자물쇠 안쪽을 봐야 합니다.

# 막대가 문틀에 안 들어갈 때
문을 닫고 잠그려는데 막대가 반쯤 나가다 멈추며 경고음이 난다면 문틀 받이 구멍과 높이가 안 맞는 경우가 대부분입니다. / 문이 처졌거나 문틀이 조금 틀어지면 이렇게 됩니다.
문을 손으로 끝까지 밀어 붙인 상태에서 다시 잠가 보세요. / 그렇게 해서 잠긴다면 문이 문틀에 덜 붙는 것이 원인입니다.
문을 위로 살짝 들어 올린 채 잠갔을 때 잠긴다면 문이 아래로 처진 것입니다. / 이 경우 문틀 받이 판을 아래로 조금 옮기거나 경첩을 손보면 해결됩니다.

# 막대가 나간 채로 안 들어올 때
잠긴 상태에서 열려고 하는데 막대가 안 들어온다면 막대가 문틀 구멍 안에서 눌려 있는 상태입니다. / 바람이 문을 밀거나 문이 처지면서 막대 한쪽이 구멍 벽에 꽉 끼게 됩니다.
번호를 누르거나 열쇠를 돌리면서 문을 내 쪽으로 당기거나 반대로 밀어 보세요. / 막대에 걸리던 힘이 빠지면서 쑥 들어오는 경우가 많습니다.
두세 번 해서 안 되면 멈추세요. / 문을 세게 흔들면 막대가 휘거나 도어락 안쪽 톱니가 상할 수 있습니다.
@ 삼숭동 데드볼트 안 빠짐 문 밀고 당기기

# 도어락 데드볼트와 보조 자물쇠는 다릅니다
도어락에서 막대가 나오는 경우에는 모터가 막대를 움직입니다. / 건전지가 약하면 모터 힘이 부족해 막대를 끝까지 못 당기거나 못 밀어냅니다.
열쇠로 돌리는 보조 자물쇠라면 손힘이 막대를 움직입니다. / 열쇠가 뻑뻑하게 돌고 막대가 중간에서 멈춘다면 자물쇠 안이 닳았거나 문틀 구멍에 걸린 것입니다.
빌라 철문은 무거워서 보조 자물쇠 막대가 문 무게를 받아 더 쉽게 걸리기도 합니다. / 어느 쪽 막대인지에 따라 손볼 곳이 다르니 통화할 때 꼭 말씀해 주세요. / 둘 다 있는 문이라면 어느 쪽이 걸렸는지 사진으로 보내 주시면 됩니다.

# 건전지부터 바꿔 보세요
도어락 데드볼트가 느리게 움직이거나 중간에서 멈춘다면 건전지를 먼저 의심합니다. / 모터 소리가 평소보다 힘없이 들린다면 거의 틀림없습니다.
문이 열려 있다면 건전지를 전부 새것으로 바꾸고 다시 시험해 보세요. / 그래도 똑같다면 건전지 문제가 아닙니다.
문이 잠긴 채 바깥에 계신다면 번호판 아래 비상 단자에 9V 건전지를 대고 열어 보는 방법이 있습니다. / 비상 전원으로는 모터 힘이 넉넉하지 않을 수 있으니 문을 살짝 밀어 막대에 걸리는 힘을 덜어 주면서 해보세요.
열리고 나면 안쪽 건전지를 곧바로 모두 갈아 주셔야 같은 일이 되풀이되지 않습니다.

# 문틀 구멍 안을 들여다보세요
문틀 쪽 받이 구멍을 손전등으로 비춰 보세요. / 먼지나 페인트 덩어리, 작은 조각이 들어 있으면 막대가 끝까지 들어가지 못합니다.
마른 솔이나 면봉으로 안을 털어 내는 정도는 괜찮습니다. / 송곳이나 드라이버로 긁어내면 받이 판이 휘어질 수 있어 피해 주세요.
받이 판 둘레에 반짝이게 긁힌 자국이 있다면 막대가 그 자리를 계속 긁고 지나간 흔적입니다. / 자국 위치를 보면 막대가 위로 걸리는지 아래로 걸리는지 알 수 있습니다.
@ 삼숭동 문틀 받이 구멍 긁힌 자국

# 계절마다 심해진다면
여름에는 문과 문틀이 늘어나 막대가 들어갈 틈이 좁아집니다. / 겨울에는 반대로 줄어들어 문이 덜 붙으면서 잠금이 헐거워지기도 합니다.
삼숭동 주택처럼 현관이 바깥 공기에 바로 닿는 집은 이 변화가 더 큽니다. / 특정 계절에만 막대가 걸린다면 받이 위치를 그 계절에 맞춰 넉넉하게 조정해 두는 것이 좋습니다.

# 기름과 드라이버는 넣지 마세요
막대가 뻑뻑하다고 일반 기름을 뿌리면 당장은 부드러워지지만 먼지가 달라붙어 금방 더 나빠집니다. / 도어락 안쪽으로 흘러 들어가면 기판까지 상할 수 있습니다.
문틈에 드라이버를 넣어 막대를 밀어내려는 것도 피해 주세요. / 막대가 휘면 도어락을 열 수 있어도 다시 잠그지 못하게 됩니다.

# 삼숭동에서 연락하실 때
아래만 알려 주시면 맞는 부품과 도구를 챙겨 갈 수 있습니다.
- 삼숭동 주소, 주택인지 빌라인지, 몇 층인지
- 막대가 안 들어가는지, 안 빠지는지
- 도어락 막대인지 열쇠 자물쇠 막대인지
- 문이 지금 열려 있는지, 잠겨 있는지
문틀 쪽 받이와 문 옆면 사진을 한 장씩 보내 주시면 도움이 많이 됩니다.

# 확인 절차와 비용 안내
문이 잠긴 상황이면 도착해서 사시는 분인지 신분증 주소나 우편물로 먼저 확인합니다. / 진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
받이 조정으로 끝날지, 경첩까지 손볼지, 부품을 바꿔야 할지 보고 비용을 먼저 말씀드립니다. / 동의하신 뒤에만 시작하고, 문을 못 열면 비용은 받지 않습니다.

# 고친 뒤 막대를 오래 쓰는 법
조정이 끝나면 문을 닫고 잠그기를 여러 번 반복해 막대가 걸림 없이 드나드는지 같이 확인합니다. / 손볼 부품이 있었다면 [도어락 수리](doorlock-repair.html)로 그 자리에서 정리합니다.
- 문을 쾅 닫지 않고 끝까지 밀어 닫기
- 계절이 바뀔 때 한 번씩 문을 연 채 잠금 시험하기
- 받이 구멍에 쌓인 먼지 털어 내기
- 경고음이 나면 그날 건전지 교체
도어락이 너무 낡아 막대 부품을 구하기 어렵다면 [도어락 교체](doorlock-replace.html)도 함께 안내해 드립니다.

# 삼숭동 말고 양주 어디든
삼숭동뿐 아니라 옥정동, 고읍동과 백석읍, 광적면, 장흥면, 남면까지 양주 어디든 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 보세요.
