# 옥천면, 현관까지 가기도 전에 대문에서 막힐 때
옥천면은 아신역 생활권을 품은 양평의 면 지역으로, 마당과 대문을 갖춘 주택이나 농가가 많은 곳입니다. / 이런 집은 현관 도어락보다 바깥 대문이 먼저 비바람과 추위를 맞습니다.
늦가을부터는 아침마다 대문 걸쇠가 뻑뻑해지고, 대문 도어락 번호판이 느려지는 집이 늘어납니다. / 퇴근길 어두운 마당 앞에서 대문이 안 열리면 차를 세울 곳도 마땅치 않아 곤란해집니다.
이 글은 옥천면에서 철대문과 대문 도어락, 공동 출입문이 안 열릴 때 확인할 부분과 겨울 전에 해 둘 일을 적었습니다. / 문이 막혀 급하다면 [양평 출장열쇠](yangpyeong.html)로 연락 주세요.
@ 옥천면 주택 마당 철대문 잠금

# 대문 앞에서 막혔을 때 첫 5분
대문이 안 열리면 먼저 아래를 차례로 보세요. / 몇 가지만 봐도 혼자 풀 수 있는 일인지 아닌지가 갈립니다.
- 대문 도어락 번호판에 불이 들어오는지
- 열쇠 자물쇠라면 열쇠가 끝까지 들어가는지
- 대문이 아래로 처져 바닥에 닿아 있지 않은지
- 걸쇠나 빗장에 얼음이나 서리가 끼었는지
- 집 안에 대문을 안에서 열어 줄 사람이 있는지
가족이 안에 있다면 안쪽 손잡이나 빗장을 열어 달라고 하는 게 가장 빠릅니다. / 혼자라면 아래 내용을 하나씩 보세요.

# 얼어붙은 걸쇠와 빗장
철대문은 쇠라서 밤사이 기온이 떨어지면 걸쇠와 빗장 틈에 맺힌 물기가 얼어붙습니다. / 열쇠는 돌아가는데 걸쇠가 안 빠지거나, 빗장이 손으로 밀리지 않는다면 이 경우입니다.
손으로 감싸 녹이거나 핫팩을 잠깐 대 두면 풀리는 경우가 많습니다. / 시간 여유가 있다면 해가 들 때까지 기다리는 것도 방법입니다.
뜨거운 물을 붓는 건 피해 주세요. / 잠깐은 녹지만 흘러내린 물이 걸쇠 아래에서 다시 얼어 다음 날 더 단단히 붙습니다.
@ 옥천면 철대문 걸쇠 결빙 겨울

# 처진 대문은 걸쇠 높이가 어긋납니다
마당 철대문은 문짝이 크고 무거워 기둥 쪽 경첩에 무게가 실립니다. / 해가 지나면 문짝 끝이 조금씩 내려가 걸쇠와 받이 높이가 맞지 않게 됩니다.
대문 아래가 바닥을 긁은 자국이 있거나, 닫을 때 들어 올려야 걸린다면 처짐입니다. / 지금 안 열린다면 문짝 끝을 살짝 들어 올린 채 열쇠를 돌리거나 번호를 눌러 보세요.
처짐을 그대로 두면 걸쇠가 매번 받이에 부딪혀 닳고, 결국 잠긴 채 안 풀리는 날이 옵니다. / 겨울 전에 경첩과 높이를 잡아 두시는 게 좋습니다.

# 대문 도어락은 현관 도어락보다 고단합니다
대문에 단 도어락은 비, 눈, 햇볕을 그대로 맞습니다. / 같은 제품이라도 현관에 달린 것보다 수명이 짧고 건전지도 빨리 닳습니다.
번호판이 느려졌거나 버튼 몇 개가 잘 안 눌리면 겨울이 오기 전에 건전지부터 새것으로 바꾸세요. / 추위가 오면 약한 건전지는 하루아침에 힘을 잃습니다.
번호판 위에 작은 덮개나 차양이 없다면 하나 달아 두는 것만으로도 고장이 크게 줄어듭니다. / 대문용으로 나온 방수형 제품인지도 한 번 확인해 보세요.
대문과 현관 도어락 건전지를 같은 날 함께 바꾸는 습관을 들이면 어느 쪽을 언제 갈았는지 헷갈리지 않습니다.

# 열쇠를 여러 사람이 나눠 쓰는 대문
농가나 주택은 가족, 일 도와주는 분, 이웃까지 대문 열쇠를 나눠 가진 경우가 있습니다. / 열쇠가 몇 개 돌았는지 모르면 하나를 잃어버려도 알아채기 어렵습니다.
복사 열쇠를 여러 번 다시 복사하면 홈이 조금씩 어긋나 자물쇠가 뻑뻑해지는 원인이 됩니다. / 원본 열쇠를 한 개 따로 보관하고 복사는 원본으로만 하세요.
나눠 쓰는 사람이 많다면 대문을 번호식 도어락으로 바꾸고 사람마다 번호를 달리 주는 방법도 있습니다. / 이 경우 [도어락 설치](doorlock-install.html)에서 대문 두께와 기둥 모양을 먼저 확인합니다.

# 여러 세대가 쓰는 공동 출입문
면 지역에도 다가구 주택이나 작은 빌라가 있어 건물 공동 출입문을 함께 쓰는 집이 있습니다. / 공동 출입문은 열고 닫는 횟수가 많아 도어클로저와 걸쇠가 빨리 닳습니다.
공동 출입문이 안 열린다면 집주인이나 관리하시는 분에게 먼저 알려 주세요. / 다른 세대도 같이 막혔을 수 있고, 수리는 건물 관리 쪽에서 결정할 일입니다.
@ 옥천면 다가구 공동 출입문 도어락

# 담을 넘거나 대문을 들어 올리지 마세요
급한 마음에 담을 넘거나 대문을 들어 레일에서 빼려는 분이 있습니다. / 철대문은 생각보다 훨씬 무겁고, 넘어지면 크게 다칩니다.
대문 틈으로 손을 넣어 안쪽 빗장을 당기는 것도 손이 끼일 수 있어 위험합니다. / 쇠 지렛대로 걸쇠를 비틀면 대문 전체가 틀어져 나중에 맞추기 어렵습니다.
어두운 시간이라면 차 전조등을 대문 쪽으로 비춰 두고 기다리세요. / 마당 앞 길이 좁은 마을이라면 다른 차가 지나갈 수 있게 차를 비켜 세워 두는 것도 잊지 마세요.
@ 옥천면 대문 앞 야간 출장열쇠 대기

# 옥천면 위치는 이렇게 알려 주세요
면 지역은 큰길에서 마을 안쪽으로 들어가는 길이 여러 갈래라 위치 설명이 중요합니다. / 아래 내용을 함께 알려 주시면 됩니다.
- 정확한 주소와 마을 이름
- 큰길에서 들어오는 방향과 눈에 띄는 표지
- 대문 종류: 여닫이, 미닫이, 쪽문
- 열쇠식인지 도어락인지
- 대문 사진 한 장
위치를 받으면 도착 시간을 먼저 말씀드립니다.

# 사시는 분인지 먼저 확인합니다
대문을 여는 일도 집 출입과 같아서 사시는 분인지 확인한 뒤 진행합니다. / 신분증 주소, 주소가 적힌 우편물, 고지서 가운데 하나를 준비해 주세요.
공동 출입문은 집주인이나 관리하시는 분 확인이 필요할 수 있습니다. / 절차는 [이용안내](guide.html)에 정리해 두었습니다.

# 비용은 작업 전에 말씀드립니다
대문 상태를 보고 무엇을 할지 정한 뒤 비용부터 알려 드립니다. / 들으시고 괜찮으면 시작하고, 아니면 그냥 돌아갑니다.
못 열면 비용은 받지 않습니다. / 여는 방법은 [현관문 개문](door-open.html)과 비슷하게 덜 상하는 순서로 합니다.

# 겨울 전에 해 두면 좋은 대문 점검
한파가 오기 전에 아래만 챙겨 두셔도 겨울 내내 대문 앞에서 막힐 일이 많이 줄어듭니다.
- 대문 도어락 건전지 전부 새것으로 교체
- 걸쇠와 빗장에 자물쇠 전용 윤활제 조금 바르기
- 경첩 나사 조이기와 문짝 높이 확인
- 번호판 위 차양이나 덮개 달기
- 원본 열쇠 따로 보관하기
대문 도어락이 오래돼 자꾸 말썽이면 [도어락 수리](doorlock-repair.html)로 점검하고, 방수형이 아니라면 [도어락 교체](doorlock-replace.html)도 고려해 볼 만합니다.

# 옥천면 말고 양평 어디든
양평읍, 양서면, 서종면, 강상면, 강하면, 용문면, 지평면까지 양평 전 지역에 출동합니다. / 대문, 현관, 창고 문 모두 봅니다.
양평에서 다니는 동네는 [양평군 출장열쇠](yangpyeong.html), 서울과 경기 다른 곳은 [출장 지역](area.html)에서 확인하세요.
