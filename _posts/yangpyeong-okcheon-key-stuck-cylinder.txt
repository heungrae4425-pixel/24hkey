# 열쇠가 안 돌아가는 순간의 당황스러움
열쇠는 분명 맞는데 돌아가지 않으면 갑자기 문 앞에서 막막해집니다. / 옥천면 주택과 농가, 창고처럼 열쇠 방식 자물쇠를 아직 많이 쓰는 곳에서 자주 생기는 일입니다.
이럴 때 가장 먼저 해야 할 일은 힘을 주지 않는 것입니다. / 급한 마음에 세게 돌리면 열쇠가 부러져 일이 두 배로 커집니다.
이 글은 열쇠가 안 돌아갈 때 직접 확인할 것과 전화하는 시점을 정리했습니다.

# 열쇠가 안 돌아가는 흔한 이유
같은 증상이라도 원인은 여러 가지입니다.
- 열쇠 날이 닳아서 내부 핀을 못 맞추는 경우
- 열쇠구멍 안에 먼지와 이물질이 낀 경우
- 문이 처져서 걸쇠가 눌려 있는 경우
- 겨울에 얼거나 여름에 습기로 녹이 슨 경우
어느 쪽인지에 따라 대처가 달라지니 증상을 정확히 기억해 두세요.
@ 옥천면 열쇠 안 돌아감 자물쇠 점검

# 먼저 문 상태를 확인해 보세요
열쇠를 돌릴 때 문을 살짝 안쪽으로 밀거나 당겨 보면 걸쇠가 풀리는 경우가 있습니다. / 문이 처져서 걸쇠가 문틀 구멍에 눌려 있으면 열쇠 문제가 아닌데도 안 돌아갑니다.
문을 들어 올리듯 조금 당기면서 돌려 보세요. / 이때도 힘으로 돌리는 것이 아니라 가볍게 시도하는 정도여야 합니다.
이 방법으로도 안 되면 더 이상 시도하지 말고 그만두는 것이 안전합니다.

# 하지 말아야 할 일
급할수록 하기 쉬운 행동이 있습니다.
- 열쇠를 힘으로 비틀어 돌리기
- 망치나 도구로 자물쇠를 두드리기
- 기름이나 윤활제를 한꺼번에 많이 뿌리기
- 여러 열쇠를 아무거나 꽂아 보기
이런 행동은 상황을 더 어렵게 만듭니다. / 특히 부러진 열쇠가 구멍 안에 남으면 빼는 과정이 길어집니다.

# 윤활제는 소량만 쓰세요
뻑뻑한 열쇠구멍에 윤활제를 조금 넣으면 도움이 될 때가 있습니다. / 하지만 한꺼번에 많이 넣으면 먼지와 엉겨 오히려 굳을 수 있습니다.
기름보다는 열쇠 전용 분말 윤활제가 낫다고 하는 분도 많습니다. / 한 번 시도해서 안 되면 더 넣지 마시고 상태를 알려주세요.
흘러내린 기름은 닦아 두셔야 문에 얼룩이 남지 않습니다.

# 열쇠를 살펴보세요
열쇠 날이 심하게 닳았거나 휘어 있으면 구멍 안에서 제대로 맞지 않습니다. / 복사본으로 쓰던 열쇠라면 복사 정밀도 때문에 원본보다 안 맞을 수도 있습니다.
원본 열쇠나 다른 복사본이 있으면 한번 써 보세요. / 다른 열쇠로 돌아간다면 열쇠가 문제였던 것입니다.
닳은 열쇠는 새로 복사해 두는 것이 안전합니다.
@ 옥천면 열쇠 복사 마모 확인

# 열쇠가 부러졌다면
열쇠가 부러져 일부가 구멍 안에 남았다면 더 넣거나 빼려고 하지 마세요. / 핀셋으로 억지로 당기다가 더 깊이 들어가는 경우가 많습니다.
부러진 조각이 보이는 상태라면 사진을 찍어 보내 주세요. / 조각을 빼낸 뒤 자물쇠가 정상인지 확인하고 필요하면 열쇠를 새로 만듭니다.
빼내는 작업은 자물쇠를 상하지 않게 하는 방향으로 진행합니다.

# 전화하실 때 알려주실 것
아래 내용을 알려주시면 출동 준비가 빨라집니다.
- 주소와 큰길에서 들어오는 길
- 어느 문이 안 열리는지(현관, 대문, 창고 등)
- 열쇠가 부러졌는지, 안 돌아가기만 하는지
- 자물쇠 사진
옥천면 어디든 24시간 받으니 늦은 시간에도 괜찮습니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 소유나 임대 확인 서류 중 하나를 보여 주시면 됩니다.
번거로우시겠지만 집을 지키기 위한 절차라서 생략하지 않습니다. / 서류가 집 안에 있다면 휴대폰에 저장된 사본 등 대안을 같이 찾아봅니다.
자세한 절차는 [이용안내](guide.html)에 적어 두었습니다.

# 문은 최대한 상하지 않게 엽니다
자물쇠와 문틀을 상하지 않게 여는 방법부터 시도합니다. / 덜 상하는 방법부터 차례로 해 보고, 필요하면 그때 다음 방법으로 넘어갑니다.
작업 중 바꿔야 할 부품이 보이면 손대기 전에 먼저 말씀드립니다. / 개문 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.
열린 뒤에는 열쇠가 부드럽게 돌아가는지까지 함께 확인합니다.
@ 옥천면 자물쇠 파손 없이 개문

# 비용은 열기 전에 말씀드립니다
자물쇠 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 바꿔야 할 때만 [도어락 교체](doorlock-replace.html)를 상의합니다.

# 열쇠 문제를 줄이는 평소 습관
- 열쇠구멍에 먼지가 쌓이지 않게 가끔 확인
- 뻑뻑해지기 시작하면 바로 전용 윤활제를 소량 사용
- 열쇠 복사본은 믿을 만한 곳에 따로 보관
- 처진 문은 문제가 커지기 전에 점검
뻑뻑하다고 느낀 시점이 점검하기 가장 좋은 때입니다.

# 옥천면 말고 양평 어디든 갑니다
옥천면 가까이의 양평읍, 강상면, 용문면도 다닙니다. / 서종면, 지평면, 양서면, 강하면처럼 거리가 먼 곳도 위치를 받고 도착 시간을 먼저 말씀드립니다.
다니는 동네는 [양평군 출장열쇠](yangpyeong.html) 페이지에 있습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.

# 농가 창고와 대문 자물쇠는 더 신경 쓰세요
옥천면의 농가에는 창고와 헛간, 대문처럼 오래된 자물쇠가 여러 곳에 달려 있는 경우가 많습니다. / 비바람을 그대로 맞는 자물쇠는 속에 흙먼지와 녹이 쌓여 어느 날 갑자기 열쇠가 안 돌아가기도 합니다.
이런 자물쇠는 일 년에 한두 번이라도 열쇠를 넣었다 빼며 상태를 보는 것이 좋습니다. / 뻑뻑해지는 느낌이 들 때가 바로 손볼 시기입니다.
농기구나 비료가 든 창고가 안 열리면 농사 일정이 밀리기 쉬우니 부담 없이 먼저 연락 주세요. / 자물쇠를 상하지 않게 열고, 고쳐서 쓸 수 있는지 먼저 살펴 드립니다.
창고 열쇠는 한 벌만 두지 말고 집 안 정해진 곳에 복사본을 하나 더 보관해 두세요. / 열쇠를 잃어버렸을 때도 당황하지 않고 대처할 수 있습니다.
오래된 자물쇠는 같은 모양의 열쇠를 다시 구하기 어려울 때가 있어 미리 새것으로 바꿔 두는 분도 있습니다.
