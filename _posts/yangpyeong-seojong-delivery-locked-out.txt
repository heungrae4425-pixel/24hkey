# 마당 하나 건넜을 뿐인데 문이 닫혀 있을 때
서종면은 북한강을 끼고 산자락을 따라 전원주택과 펜션이 띄엄띄엄 자리 잡은 동네입니다. / 집과 대문 사이에 마당이 있고, 택배는 대문 앞이나 마을 입구 쪽에 놓이는 경우가 많습니다.
택배 상자를 가지러 대문까지 나갔거나 분리수거장에 쓰레기를 내놓고 돌아왔는데 현관문이 닫혀 잠겨 있습니다. / 바람에 문이 밀려 닫혔거나, 습관처럼 문을 당겨 닫고 나왔을 수 있습니다.
도시처럼 옆집이 가깝지 않아 도움을 청할 곳도 마땅치 않습니다. / 이 글은 전원주택에서 잠깐 나왔다가 문이 잠겼을 때 무엇부터 할지 순서대로 정리했습니다.
@ 서종면 출장열쇠 전원주택 현관 잠김

# 다른 문이 열려 있는지 먼저 돌아보세요
전원주택은 현관 말고도 드나들 문이 있는 경우가 많습니다. / 바로 업체를 찾기 전에 집 둘레를 한 바퀴 돌아보세요.
- 데크나 테라스로 이어지는 거실 미닫이
- 주방 쪽 뒷문이나 다용도실 문
- 차고와 집 안이 연결된 문
- 열어 둔 채 나온 창문
열려 있는 문이 있다면 그쪽으로 들어가면 됩니다. / 다만 창문은 높이가 있거나 방충망을 뜯어야 한다면 무리하지 마세요.
데크 미닫이는 안쪽 걸쇠만 걸려 있지 않으면 바깥에서 밀어 열리는 경우도 있습니다. / 유리문을 세게 흔들지 말고 손잡이 쪽을 살살 밀어 보는 정도까지만 해 보세요.

# 휴대폰을 갖고 나왔는지 확인하세요
휴대폰이 손에 있다면 상황은 훨씬 쉽습니다. / 가족에게 연락하거나 저희에게 바로 전화하시면 됩니다.
휴대폰도 집 안에 있다면 가장 가까운 이웃집이나 마을 가게를 찾아 전화를 빌려야 합니다. / 서종면은 집 사이 거리가 꽤 되는 곳도 있으니 밤이라면 어두운 길을 혼자 오래 걷지 마세요.
차 열쇠를 갖고 나오셨다면 차 안에서 기다리는 것도 방법입니다. / 차에 휴대폰 충전 케이블이나 비상 연락처 메모가 있는지도 떠올려 보세요.

# 비밀번호와 카드부터 시도해 보세요
현관 도어락이 번호식이라면 번호만 누르면 열립니다. / 당황해서 번호 누를 생각을 못 하고 문만 당겨 보는 분도 계십니다.
번호를 기억하지 못한다면 차 열쇠고리에 카드키나 태그를 함께 달아 두지 않았는지 확인해 보세요. / 이런 일을 대비해 카드 하나를 차에 두는 집도 있습니다.
번호판이 꺼져 있다면 배터리 문제일 수 있습니다. / 바깥쪽 비상 단자에 9V 건전지를 대면 전원이 들어오는 제품이 많으니 차 안이나 창고에 건전지가 있는지 찾아보세요.
@ 서종면 주택 도어락 번호판 비상 전원

# 집 안에 불이나 물을 켜 둔 채 나왔다면
쓰레기를 들고 나가기 전 가스레인지에 무언가 올려 두셨다면 문 여는 일보다 그쪽이 급합니다. / 연기나 냄새가 나기 시작하면 망설이지 말고 119에 먼저 연락하세요.
욕조에 물을 틀어 둔 경우나 난로를 켜 둔 경우도 마찬가지입니다. / 통화하실 때 이 사실을 가장 먼저 말씀해 주시면 출동 순서를 거기에 맞춥니다.
반려동물이 집 안에 있다면 그것도 함께 알려 주세요. / 문을 열 때 놀라서 뛰쳐나오지 않게 미리 준비합니다.

# 가족이나 관리인에게 먼저 연락할 때
양평읍이나 서울에 사는 가족이 여분 열쇠나 번호를 알고 있다면 먼저 연락해 보세요. / 다만 거리가 멀어 가족이 오기까지 오래 걸린다면 출장이 더 빠를 수 있습니다.
펜션이나 별장을 관리해 주는 분이 따로 있다면 그분께도 연락해 보세요. / 비상용 번호나 열쇠를 갖고 계신 경우가 있습니다.
기다리는 시간과 출장 도착 시간을 비교해 보고 정하시면 됩니다. / 전화 주시면 도착까지 얼마나 걸릴지 먼저 말씀드립니다.

# 겨울에는 기다리는 동안이 더 중요합니다
서종면은 강과 산이 가까워 겨울 저녁에 기온이 빠르게 떨어집니다. / 얇은 옷차림으로 나왔다면 오래 밖에 서 있지 마세요.
차 안이나 창고, 비닐하우스처럼 바람을 피할 곳이 있다면 그 안에서 기다리세요. / 이웃집에 사정을 말씀드리고 잠시 안에서 기다리는 것도 방법입니다.
기다리는 위치는 통화하실 때 꼭 알려 주세요. / 도착하면 그곳으로 먼저 찾아갑니다.

# 데크 창문과 2층 베란다는 위험합니다
- 데크 위 창문을 억지로 비틀어 열기
- 2층 베란다로 사다리 없이 올라가기
- 현관 유리나 중문 유리를 깨고 손 넣기
- 도어락을 돌이나 공구로 두드리기
특히 겨울에는 데크와 계단이 얼어 미끄럽습니다. / 높은 곳에 오르다 떨어지면 혼자 있는 시골집에서는 도움을 받기도 어렵습니다.
급한 마음은 이해하지만 다치거나 집이 더 상하면 일이 커집니다. / 문은 상하지 않게 여는 방법이 있으니 기다리시는 편이 낫습니다.

# 강가 길에서도 헤매지 않게
서종면은 길이 갈라지는 곳이 많아 정확한 위치가 중요합니다.
- 도로명 주소나 지번, 펜션이라면 객실 위치
- 큰길에서 들어오는 길, 대문 위치와 차를 세울 곳
- 지금 기다리고 있는 장소
- 다시 연락할 수 있는 전화번호
내비게이션에 잘 안 잡히는 집이라면 근처 눈에 띄는 건물이나 다리 이름을 말씀해 주세요. / 도착 시간은 위치를 받고 바로 알려 드립니다.

# 이웃이나 관리인 확인 후 금액 안내
신분증이 집 안에 있다면 먼저 이웃이나 관리인, 가족 통화로 확인하고, 문을 연 뒤 실내에서 신분증이나 주소가 나온 우편물을 함께 봅니다. / 확인 절차는 [이용안내](guide.html)에 정리해 두었습니다.
문과 도어락 상태를 보고 비용을 먼저 말씀드리고, 괜찮다고 하실 때 시작합니다. / 끝내 못 열면 비용은 받지 않습니다.

# 열고 나서 배터리까지 확인합니다
도어락과 문이 상하지 않는 방법부터 차례로 시도합니다. / 여는 과정은 [현관문 개문](door-open.html)에, 보조키 열쇠까지 잠긴 경우는 [열쇠 출장](key-call.html)에 적어 두었습니다.
열고 나면 도어락이 잘 잠기고 열리는지 확인합니다. / 배터리가 약했다면 새것으로 바꾸고, 고장이 보이면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
@ 양평 출장열쇠 서종면 현관문 비파손 개방

# 다음에 같은 일이 없게 하려면
- 마당에 나갈 때도 휴대폰을 주머니에 넣는 습관 들이기
- 차 안에 비상용 카드키나 9V 건전지 하나 두기
- 자동 잠금이 불편하면 수동 잠금으로 바꿔 쓰기
- 가까운 이웃이나 관리인과 비상 연락처 나눠 두기
자동 잠금을 끄고 싶다면 문을 연 김에 설정을 같이 봐 드립니다. / 오래된 도어락이라 설정이 안 된다면 [도어락 교체](doorlock-replace.html)를 그때 상의합니다.

# 서종면 말고 양평 어디든 갑니다
서종면 가까운 양서면과 양평읍, 강상면, 강하면, 옥천면, 용문면, 지평면까지 다닙니다. / 양평에서 다니는 범위는 [양평군 출장열쇠](yangpyeong.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.

? 거리가 멀어서 오래 걸리지 않나요? | 위치를 받으면 도착 시간을 먼저 말씀드리니 가족이 오는 시간과 비교해 정하세요.
? 끝내 못 열면 출장비가 있나요? | 못 열면 비용은 받지 않습니다.
