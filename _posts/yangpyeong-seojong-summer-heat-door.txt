# 여름이면 문이 말썽을 부리는 이유
서종면처럼 산과 물이 가까운 동네는 여름 습기가 집 안까지 들어옵니다. / 그래서 장마가 지나고 나면 현관문이 뻑뻑하다거나 잘 안 닫힌다는 연락이 늘어납니다.
문은 나무나 합판이 들어간 경우가 많아 습기를 먹으면 조금씩 부풉니다. / 문이 부풀면 문틀과 간격이 좁아져 걸쇠가 맞지 않게 됩니다.
이 글은 여름에 문이 뻑뻑해졌을 때 확인할 것과 부르는 시점을 정리했습니다.

# 문이 부풀면 생기는 증상
습기와 더위가 문에 주는 영향은 눈에 잘 띄지 않아도 증상으로는 분명합니다.
- 문을 닫을 때 평소보다 힘이 든다
- 도어락 걸쇠가 문틀 구멍에 걸린다
- 열쇠는 들어가는데 돌리기 뻑뻑하다
- 문틀과 문 사이 틈이 한쪽만 좁다
이런 증상이 여러 개 겹치면 문 자체가 부풀었을 가능성이 큽니다.
@ 서종면 현관문 습기 부풀음 점검

# 도어락이 고장 난 것은 아닐 수 있습니다
문이 뻑뻑하다고 도어락부터 의심하는 분이 많습니다. / 하지만 도어락은 멀쩡한데 문이 틀어져서 안 닫히는 경우가 훨씬 많습니다.
도어락을 바꿔도 문이 그대로면 같은 증상이 반복됩니다. / 그래서 먼저 문이 문제인지 도어락이 문제인지 구분하는 것이 중요합니다.
문을 열어 둔 상태에서 도어락만 눌러 보고 걸쇠가 부드럽게 들어가고 나오는지 확인해 보세요.

# 간단히 구분하는 방법
문을 열어 둔 채 걸쇠를 직접 눌러 보세요. / 걸쇠가 부드럽게 들어갔다 나오면 도어락 자체는 정상입니다.
이 상태에서 문을 닫을 때만 걸리면 문틀이나 문 쪽 문제입니다. / 걸쇠가 열린 상태에서도 뻑뻑하다면 도어락 내부 문제를 의심해야 합니다.
두 경우를 구분해서 알려주시면 출동 준비가 훨씬 정확해집니다.

# 더위가 도어락에 주는 영향
여름 무더위는 도어락 내부 회로에도 부담을 줍니다. / 햇빛이 직접 닿는 현관문은 번호판 표면이 뜨거워져 반응이 느려지기도 합니다.
배터리도 높은 온도에서는 소모가 빨라지는 경우가 있습니다. / 한여름에 갑자기 경고음이 늘었다면 배터리를 점검해 보세요.
번호판이 뜨거워서 만지기 어려울 정도면 식힌 뒤에 눌러 보시는 것이 좋습니다.

# 직접 해볼 수 있는 조치
먼저 문틀 주변의 먼지와 이물질을 닦아 내 보세요. / 걸쇠가 들어가는 문틀 구멍에 이물질이 끼어 있는지 확인합니다.
문과 문틀 사이에 얇은 종이를 끼워 보아 한쪽만 꽉 끼는지 살펴볼 수도 있습니다. / 한쪽만 꽉 낀다면 경첩 쪽이 처졌을 가능성이 있습니다.
다만 문을 깎거나 경첩을 직접 만지는 것은 전문가에게 맡기는 편이 안전합니다.
@ 서종면 현관문 경첩 처짐 문틀 간격 확인

# 전화하실 때 알려주실 것
아래 내용을 알려주시면 출동 준비가 빨라집니다.
- 주소와 큰길에서 들어오는 길
- 문이 안 닫히는지, 안 열리는지
- 열린 상태에서 걸쇠가 부드러운지
- 현관문과 도어락 사진
서종면 어디든 24시간 받으니 늦은 시간에도 괜찮습니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 소유나 임대 확인 서류 중 하나를 보여 주시면 됩니다.
번거로우시겠지만 집을 지키기 위한 절차라서 생략하지 않습니다. / 서류가 집 안에 있다면 휴대폰에 저장된 사본 등 대안을 같이 찾아봅니다.
자세한 절차는 [이용안내](guide.html)에 적어 두었습니다.

# 문은 최대한 상하지 않게 엽니다
문이 잠겨 열리지 않을 때도 도어락과 문틀을 상하지 않게 여는 방법부터 시도합니다. / 덜 상하는 방법부터 차례로 해 보고, 필요하면 그때 다음 방법으로 넘어갑니다.
작업 중 바꿔야 할 부품이 보이면 손대기 전에 먼저 말씀드립니다. / 개문 방식은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.
부풀어서 꽉 낀 문은 천천히 풀어야 해서 평소보다 시간이 걸릴 수 있습니다.

# 비용은 열기 전에 말씀드립니다
문 상태와 도어락을 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
문 쪽 문제를 도어락 교체로 연결하지 않습니다. / 도어락이 원인이라면 고쳐서 쓸 수 있는지 [도어락 수리](doorlock-repair.html)로 먼저 봅니다.

# 열고 난 뒤 손봐 두면 좋은 곳
문이 열리면 걸쇠 위치와 문틀 구멍이 맞는지 다시 확인합니다. / 필요하면 문틀 쪽 구멍 위치를 조정해 부드럽게 닫히도록 맞춥니다.
도어락 자체가 오래되어 교체가 필요하면 [도어락 교체](doorlock-replace.html) 페이지에서 상담해 드립니다.
작업 후에는 문을 여러 번 열고 닫으며 걸쇠가 매끄러운지 같이 확인합니다.
@ 서종면 도어락 걸쇠 위치 조정 후 확인

# 장마 전후에 해두면 좋은 점검
- 현관문과 문틀 사이 틈이 한쪽만 좁아지지 않았는지 보기
- 걸쇠가 들어가는 구멍에 이물질이 끼지 않았는지 확인
- 번호판 주변에 빗물이 직접 튀지 않게 하기
- 도어락 배터리 상태를 장마 전에 한 번 점검
이런 확인만으로도 한여름에 문 앞에서 낭패를 보는 일을 줄일 수 있습니다.

# 서종면 말고 양평 어디든 갑니다
서종면 가까이의 양서면, 양평읍, 옥천면도 다닙니다. / 용문면, 지평면, 강상면, 강하면처럼 먼 곳도 위치를 받고 도착 시간을 먼저 말씀드립니다.
다니는 동네는 [양평군 출장열쇠](yangpyeong.html) 페이지에 있습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

# 방충망 문과 현관 앞 환경도 살펴보세요
서종면의 전원주택은 현관 앞에 방충망 문이나 바깥 문을 한 겹 더 달아 두는 집이 많습니다. / 이런 구조에서는 바깥 문과 안쪽 현관문이 서로 부딪쳐 닫히지 않는 경우도 있습니다.
여름에는 문틀 주변에 거미줄과 벌레 집, 흙먼지가 쌓여 걸쇠가 들어가는 구멍을 막기도 합니다. / 가끔 구멍 안을 들여다보고 이물질을 털어 내는 것만으로도 증상이 나아지는 경우가 있습니다.
현관 앞 바닥 단차나 신발장이 문이 닫히는 길을 막고 있지는 않은지도 확인해 보세요. / 문 쪽 문제는 도어락 교체로 해결되지 않으니 원인부터 구분하는 것이 순서입니다.
비가 많이 온 뒤에는 문틀 아래쪽에 물이 고여 목재가 더 부풀 수 있어 배수 상태도 같이 보시길 권합니다.

24시출장열쇠는 늦은 밤과 새벽에도 전화를 받습니다. / 서울, 경기 전 지역 24시간, 전화 010-3664-5455로 연락 주세요.

문이 안 닫히거나 안 열릴 때 억지로 힘을 쓰지 마시고 상황을 그대로 알려주세요. / 서종면 위치를 받고 도착 시간을 먼저 안내드립니다.
장마가 끝난 뒤나 환절기에 한 번 점검받아 두시면 마음이 편합니다. / 도어락과 문틀을 함께 보고 어느 쪽 손질이 필요한지 정확히 말씀드립니다.
