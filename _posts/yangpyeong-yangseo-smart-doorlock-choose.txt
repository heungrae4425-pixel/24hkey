# 새 도어락을 고르기 전에 먼저 물어볼 것
양서면은 아파트와 전원주택, 한강 변 주택이 섞여 있어 현관문 모양이 집마다 다릅니다. / 그래서 도어락을 바꾸고 싶다는 상담을 받으면 제품 이름보다 문 상태부터 여쭙니다.
같은 제품이라도 문 두께와 문틀 상태에 따라 설치가 되기도 하고 안 되기도 합니다. / 이 글은 스마트 도어락을 고를 때 알아두면 좋은 점을 순서대로 정리했습니다.
검색으로 제품부터 정하기 전에 아래 내용을 먼저 확인해 보시면 헛걸음을 줄일 수 있습니다.

# 스마트 도어락이라고 다 같은 것은 아닙니다
스마트 도어락은 휴대폰 연결, 지문, 카드, 번호 같은 여러 방식을 묶어 부르는 말입니다. / 방식이 많다고 무조건 좋은 것이 아니라 우리 집 사용 습관에 맞는 것이 좋습니다.
- 번호만 쓰는 단순한 방식
- 지문과 번호를 함께 쓰는 방식
- 카드나 스티커를 쓰는 방식
- 휴대폰과 연결해 기록을 보는 방식
쓰지 않을 기능이 많은 제품은 가격만 올리고 고장 요인만 늘릴 수 있습니다.
@ 양서면 스마트 도어락 종류 비교

# 가족 구성원부터 떠올려 보세요
아이가 있는 집은 지문이나 카드가 편하고, 어르신이 계신 집은 큰 번호판이 편합니다. / 혼자 사시는 분은 휴대폰 연결로 출입 기록을 확인하는 기능이 마음에 놓일 수 있습니다.
사용자가 누구인지 정리하면 필요한 기능이 자연스럽게 좁혀집니다. / 가족마다 불편한 점을 한 번씩 물어보시면 선택이 쉬워집니다.
기능이 단순할수록 고장 날 곳도 적다는 점은 기억해 두세요.

# 문 상태를 먼저 확인해야 합니다
도어락은 문에 구멍을 내고 끼우는 장치라 문 두께와 기존 구멍 크기가 맞아야 합니다. / 오래된 문은 구멍 위치가 달라 문을 추가로 가공해야 하는 경우도 있습니다.
문이 처졌거나 문틀이 틀어져 있으면 새 도어락을 달아도 걸쇠가 잘 맞지 않습니다. / 이럴 때는 도어락보다 문 상태를 먼저 손봐야 합니다.
현관문 전체 사진과 기존 도어락 사진을 보내 주시면 설치 가능 여부를 먼저 말씀드립니다.

# 설치 전에 사진으로 확인합니다
정확한 상담을 위해 몇 가지 사진을 부탁드립니다.
- 현관문 전체가 나오는 사진
- 기존 도어락 바깥쪽과 안쪽 사진
- 문 옆면의 걸쇠 부분
- 문이 열리는 방향과 손잡이 위치
사진만 있어도 필요한 부품을 미리 챙겨 한 번에 끝낼 수 있습니다. / 문 두께를 아신다면 같이 알려주세요.
@ 양서면 도어락 교체 전 현관문 사진 확인

# 보안 면에서 볼 점
편의성만큼 중요한 것이 보안입니다. / 번호가 쉽게 노출되지 않는지, 번호판에 손때가 남아 번호를 짐작할 수 있는지도 생각해 보세요.
번호를 여러 사람이 알게 되는 구조라면 주기적으로 바꿀 수 있어야 합니다. / 임시 번호를 만들 수 있는 기능은 택배나 청소 도우미에게 잠깐 열어 줄 때 유용합니다.
허술한 비밀번호 설정은 어떤 제품이든 보안을 약하게 만듭니다.

# 전원 방식과 배터리도 살펴보세요
대부분의 도어락은 건전지로 움직이지만 제품마다 건전지 종류와 교체 주기가 다릅니다. / 외부 전원 단자가 있는지, 비상 시 건전지를 어디에 대는지도 알아두면 좋습니다.
배터리가 약해지면 경고음으로 알려주는 제품이 안전합니다. / 경고음이 나온 뒤 며칠은 더 쓸 수 있는지도 상담 때 물어보세요.
전원이 끊겼을 때 열쇠로 열 수 있는 보조 방식이 있는 제품이 마음이 놓입니다.

# 전화하실 때 알려주실 것
아래 내용을 알려주시면 상담이 빨라집니다.
- 건물 형태와 현관문 종류
- 원하는 기능(지문, 카드, 번호 등)
- 기존 도어락 사진
- 교체를 원하는 시기
양서면 어디든 24시간 상담을 받습니다.

# 방문하면 이렇게 진행합니다
현장에 오면 문과 기존 도어락 상태부터 확인합니다. / 설치가 가능한지, 추가 가공이 필요한지를 먼저 말씀드립니다.
그다음 제품 선택지를 보여 드리고 설치 비용을 설명드립니다. / 괜찮다고 하시면 그때 작업을 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
허락 없이 부품을 바꾸거나 비용을 붙이는 일은 없습니다. / 자세한 진행은 [이용안내](guide.html)에 적어 두었습니다.
@ 양서면 도어락 교체 설치 후 작동 확인

# 고쳐서 쓸 수 있는지도 같이 봅니다
교체가 꼭 정답은 아닙니다. / 배터리나 센서 문제처럼 간단한 원인이면 [도어락 수리](doorlock-repair.html)로 해결되기도 합니다.
오래 써서 부품이 단종되었거나 고장이 반복되면 그때 교체를 권합니다. / 교체 방식은 [도어락 교체](doorlock-replace.html) 페이지에 정리해 두었습니다.
수리와 교체의 차이를 설명드리고 선택은 직접 하시도록 합니다.

# 설치 후 꼭 확인할 것
설치가 끝나면 문을 닫은 상태에서 여러 번 열고 잠가 보며 확인합니다. / 안쪽 잠금 레버, 번호 등록, 카드 등록이 제대로 되는지 같이 봅니다.
번호는 설치 직후 바로 바꿔서 쓰시는 것이 안전합니다. / 기본 번호를 그대로 두면 보안이 약해집니다.
사용법이 헷갈리면 그 자리에서 물어보세요. / 설명서가 어려우시면 쉬운 말로 한 번 더 알려드립니다.

# 평소 관리 습관
- 번호판은 마른 천으로 자주 닦기
- 배터리는 경고음이 나기 전에 미리 교체
- 비상용 건전지나 열쇠 보관 위치를 가족과 공유
- 번호는 가끔 바꾸고 기록은 안전한 곳에 보관
이런 습관이 도어락을 오래, 안전하게 쓰는 방법입니다.

# 양서면 말고 양평 어디든 갑니다
양서면 가까이의 양평읍, 강상면, 옥천면도 다닙니다. / 서종면, 용문면, 지평면, 강하면처럼 먼 곳도 위치를 받고 도착 시간을 먼저 말씀드립니다.
다니는 동네는 [양평군 출장열쇠](yangpyeong.html) 페이지에 있습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

# 아파트와 단독주택, 고르는 기준이 다릅니다
양서면의 아파트 현관문은 규격이 비슷해 제품 선택이 비교적 쉬운 편입니다. / 반면 단독주택이나 빌라 현관문은 두께와 모양이 제각각이라 사진 확인이 더 중요합니다.
아파트는 공용 현관 출입 방식과 연동되는 제품이 있는지도 관리사무소에 한 번 확인해 보세요. / 단독주택은 비바람에 노출되는 정도에 따라 방수가 잘 되는 제품이 유리합니다.
현관문이 철문인지 목문인지에 따라 설치 방법과 시간이 달라지기도 합니다. / 이런 차이를 미리 알려주시면 상담이 정확해지고 방문 횟수도 줄일 수 있습니다.
한강 가까운 집은 습기가 많을 수 있어 번호판 마감이 튼튼한 제품을 권하기도 합니다.

상담만 받아 보셔도 괜찮으니 부담 없이 연락 주세요. / 기능과 설치 조건을 쉬운 말로 정리해 드립니다.
