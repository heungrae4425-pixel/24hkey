# 북내면에서 열쇠가 안 돌아가는 순간
여주 북내면은 마을과 단독주택, 농가와 창고가 이어진 면 지역입니다. / 대문이나 창고, 현관문에 아직 열쇠를 쓰는 집이 많습니다.
열쇠를 넣었는데 돌아가지 않거나, 돌려놓은 열쇠가 빠지지 않아 손에 힘만 들어가는 순간이 있습니다. / 이때 당황해서 세게 비틀면 상황이 더 나빠집니다.
이 글은 북내면에서 열쇠가 안 돌아가거나 안 빠질 때 먼저 볼 것을 정리했습니다. / 정리를 읽고도 안 되면 [여주 출장열쇠](yeoju.html)가 오는 순서도 적어 두었습니다.

# 열쇠가 안 돌아가는 이유는 몇 가지로 나뉩니다
열쇠 날이 닳아 자물쇠 안 핀을 제대로 밀어 올리지 못하는 경우가 가장 흔합니다. / 복사본의 복사본을 쓰면 오차가 더 커져 이런 일이 쉽게 생깁니다.
자물쇠 안쪽에 먼지, 녹, 오래된 윤활제가 굳어 있는 경우도 많습니다. / 바깥에 노출된 대문은 비와 먼지를 계속 맞습니다.
열쇠가 휘었거나 끝이 둥글어진 경우도 있습니다. / 눈으로 보면 열쇠 날이 평평하지 않다면 위험 신호입니다.

# 열쇠가 안 빠질 때는 따로 원인이 있습니다
열쇠를 돌려 놓은 채 빼려는데 걸려서 안 빠지는 일이 있습니다. / 열쇠를 원래 위치로 돌려놓지 않았거나 핀이 어긋난 경우가 많습니다.
열쇠가 반쯤 들어가다 멈추거나 잡아당길 때 단단히 걸리면 자물쇠 안쪽이 이미 상한 것일 수 있습니다. / 이때 힘으로 당기면 열쇠가 부러질 위험이 큽니다.
열쇠 날이 닳아 핀 사이에 끼어 버리기도 합니다. / 살살 앞뒤로 움직이며 위치를 찾아보세요.
@ 여주 북내면 열쇠구멍 자물쇠 실린더

# 먼저 이렇게 해보세요
열쇠를 끝까지 넣었다가 아주 조금 뒤로 뺀 위치에서 돌려 보세요. / 열쇠가 정확히 맞는 위치는 한 곳이라 이 방법으로 돌아가는 일이 많습니다.
열쇠를 돌리며 문을 안쪽으로 살짝 밀거나 당겨 보세요. / 문이 눌려 걸쇠가 문틀에 닿아 있으면 열쇠가 돌아가지 않습니다.
열쇠가 안 빠질 때는 열쇠를 살짝 돌렸다가 원래 위치로 돌려서 다시 당겨 보세요. / 힘을 주지 않고 작은 움직임으로 시도하는 것이 핵심입니다.

# 하지 말아야 할 일
망치로 열쇠를 두드리거나 펜치로 돌리는 것은 열쇠를 부러뜨리는 가장 빠른 방법입니다. / 부러진 열쇠가 안에 박히면 문 여는 일이 훨씬 어려워집니다.
열쇠구멍에 오일을 듬뿍 부으면 먼지와 섞여 굳을 수 있습니다. / 윤활제를 쓰더라도 아주 조금 쓰시고, 가능하면 건식 제품을 쓰세요.
다른 열쇠나 철사를 넣어 돌려 보는 것도 위험합니다. / 안쪽 부품이 상하거나 다른 열쇠도 걸려 못 쓰게 될 수 있습니다.

열쇠가 구멍 안에서 반쯤 부러져 남았다면 더 건드리지 마세요. / 남은 조각을 빼내려다 안으로 더 밀려 들어가면 해결이 어려워집니다.
부러진 조각이 밖으로 나와 있다면 버리지 말고 잘 보관해 주세요. / 열쇠를 다시 만들 때 참고가 됩니다.
이 경우는 직접 해결하지 마시고 바로 연락 주세요. / 상태를 보고 안전하게 빼내는 방법을 정합니다.

# 이런 상황이면 북내면이라도 바로 연락 주세요
열쇠가 안 돌아가는데 문 앞에 오래 계신 경우, 열쇠가 안 빠지는데 문을 못 닫은 경우입니다. / 집 안에 아이나 어르신, 가축이 있어 급한 경우도 같습니다.
밤이나 새벽에도 24시간 받습니다. / 위치와 열쇠 상태를 말씀해 주시면 출동 여부와 도착 시간을 먼저 말씀드립니다.
문 열기 전에 비용도 먼저 말씀드립니다. / 못 열면 비용은 받지 않습니다.

# 전화할 때 알려 주실 내용
북내면은 마을마다 길이 달라 위치 설명이 도착 시간을 좌우합니다. / 큰길에서 들어오는 방향이나 눈에 띄는 건물을 같이 말씀해 주세요.
- 대문, 현관문, 창고 중 어느 문인지
- 열쇠가 안 돌아가는지, 안 빠지는지, 부러졌는지
- 열쇠를 넣었을 때 느낌(걸림, 헐거움, 뻑뻑함)
- 집 안에 사람이나 반려동물이 있는지
자물쇠와 열쇠 사진을 문자로 보내 주시면 챙겨 갈 장비를 정하는 데 도움이 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 마을 이장님이나 이웃 확인 중 하나면 됩니다.
번거로우실 수 있지만 집 주인을 지키기 위한 절차입니다. / 확인이 어려우면 작업할 수 없으니 미리 준비해 두세요.
창고나 농막처럼 사람이 살지 않는 공간이라면 소유 확인이 가능한 자료가 필요합니다. / 미리 말씀해 주시면 순서를 맞춰 안내합니다.

# 자물쇠를 상하지 않게 여는 방법
먼저 열쇠와 자물쇠 상태를 살펴 덜 상하는 방법부터 차례로 해봅니다. / 처음부터 부수는 방식은 쓰지 않습니다.
자물쇠 종류와 상태에 따라 걸리는 시간은 다릅니다. / 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다.
방식은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다. / 못 열면 비용은 받지 않습니다.

# 비용은 열기 전에 먼저 말씀드립니다
자물쇠 종류와 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
열고 난 뒤에 말 없이 붙는 비용은 없습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 난 뒤에는 열쇠를 새로 만듭니다
문이 열리면 열쇠가 왜 안 돌아갔는지 원인을 확인합니다. / 열쇠가 닳았다면 새 열쇠를 만들고, 자물쇠 안쪽이 상했다면 부품을 바꾸는 방법을 말씀드립니다.
열쇠 제작과 자물쇠 교체는 [출장 열쇠](key-call.html) 페이지에서 보실 수 있습니다. / 바꾸기 전에는 꼭 먼저 여쭙고 진행합니다.
번호 도어락으로 바꾸고 싶다면 문 규격을 확인한 뒤 [도어락 설치](doorlock-install.html)로 안내해 드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 같은 일이 생기지 않게 하는 열쇠 관리
- 열쇠는 날이 닳기 전에 원본으로 새로 복사해 두기
- 열쇠가 뻑뻑해지면 그날 바로 점검받기
- 열쇠구멍 주변을 가끔 털어 먼지가 쌓이지 않게 하기
- 열쇠를 돌릴 때는 힘을 주지 않고 작은 움직임으로 돌리기
작은 습관만으로 열쇠가 부러지거나 끼는 일이 많이 줄어듭니다. / 열쇠가 뻑뻑하다고 느껴질 때가 점검 시기입니다.

# 북내면 말고 여주 어디든 갑니다
여흥동, 중앙동, 오학동, 가남읍, 점동면, 세종대왕면, 대신면까지 여주 전 지역을 다닙니다. / 면 지역은 거리가 있어 위치를 받고 도착 시간을 먼저 말씀드립니다.
여주에서 다니는 지역은 [여주시 출장열쇠](yeoju.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.
