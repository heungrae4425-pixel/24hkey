# 점동면 오래된 집에서 문이 갑자기 뻑뻑해졌다면
여주 점동면은 들과 마을이 이어진 면 지역으로 오래 살아온 단독주택이 많습니다. / 집은 오래됐는데 도어락은 몇 번 바꿔서, 문과 잠금 장치가 서로 맞지 않는 일이 생깁니다.
어느 날부터 문이 끝까지 닫히지 않거나 열쇠가 걸려서 안 돌아가는 증상이 나타납니다. / 도어락이 고장 난 것 같지만 사실 문틀과 경첩이 원인인 경우가 많습니다.
이 글은 점동면에서 문틀이 처져 현관문이 안 열릴 때 먼저 볼 것을 정리했습니다. / 끝까지 읽으시면 [여주 출장열쇠](yeoju.html)를 부르는 순서도 알 수 있습니다.
@ 점동면 오래된 현관문 문틀 출장열쇠

# 문틀이 처지는 이유
나무 문틀과 문은 계절에 따라 습기를 먹고 말리는 일을 반복합니다. / 그러다 보면 조금씩 휘거나 내려앉아서 문이 닫힐 때 위치가 어긋납니다.
문 자체의 무게와 오래 쓴 경첩의 헐거움도 한몫합니다. / 경첩 나사 구멍이 닳으면 문이 아래로 쏠립니다.
집 기초가 미세하게 움직인 경우에도 문틀이 비틀리는 수가 있습니다. / 이럴 때는 문만 만져서는 해결되지 않을 수 있습니다.

# 어디가 처졌는지 눈으로 먼저 보세요
문을 닫은 채로 문 위쪽과 아래쪽 틈 간격을 비교해 보세요. / 한쪽만 좁거나 넓다면 문이나 문틀이 기울어진 것입니다.
걸쇠가 들어가는 구멍과 걸쇠 위치가 어긋났는지도 살펴보세요. / 걸쇠 끝에 긁힌 자국이 있다면 구멍을 제대로 못 찾고 있다는 뜻입니다.
바닥에 문이 닿아 생긴 줄무늬가 보이는지도 확인해 보세요. / 이런 자국이 있으면 경첩 쪽이 많이 내려앉은 것입니다.
@ 여주 점동면 현관문 경첩 걸쇠

# 문을 살짝 들어 올리며 열어 보기
문손잡이를 잡고 문 전체를 위로 살짝 들어 올리듯이 당기면서 열쇠를 돌려 보세요. / 처진 문이 제 위치로 올라가면 걸쇠가 풀리는 일이 있습니다.
반대로 문을 안쪽으로 밀면서 돌리면 열리는 경우도 있습니다. / 어느 쪽이든 힘으로 세게 하지 말고 천천히 시도하세요.
무리하게 당기면 경첩이 더 헐거워지거나 문틀이 갈라질 수 있습니다. / 두세 번 해보고 안 되면 멈추는 것이 좋습니다.

# 해보면 안 되는 일
문틈에 드라이버나 쇠막대를 넣어 비트는 분이 많습니다. / 문 가장자리와 문틀이 상해서 나중에 수리 범위가 더 넓어집니다.
문을 발로 차는 것도 위험합니다. / 경첩이 빠지거나 도어락이 파손되고 다칠 수도 있습니다.
기름을 걸쇠에 잔뜩 뿌리면 먼지가 엉겨 더 안 움직일 수 있습니다. / 윤활제를 쓰더라도 아주 조금만 쓰세요.

# 이런 경우에는 점동면이라도 바로 연락 주세요
열쇠를 돌려도 반응이 없거나, 문이 한쪽으로 쏠린 채 완전히 막혀 버렸을 때입니다. / 집 안에 어르신이나 아이가 계시다면 오래 기다리게 하지 않는 것이 좋습니다.
밤 시간이나 날씨가 나쁜 날도 마찬가지입니다. / 24시간 받으니 시간 걱정은 하지 않으셔도 됩니다.
위치와 문 상태를 말씀해 주시면 출동 여부와 도착 시간을 먼저 말씀드립니다. / 문 열기 전에 비용도 먼저 말씀드립니다.

# 전화하실 때 이 정도만 알려 주세요
점동면은 마을마다 길이 달라 위치 설명이 도착 시간을 좌우합니다. / 큰길에서 어느 쪽으로 들어오는지, 눈에 띄는 건물이 근처에 있는지 말씀해 주세요.
- 대문과 현관문이 따로 있는지
- 문이 어느 쪽으로 처졌는지, 닫을 때 소리가 나는지
- 도어락 종류와 열쇠가 따로 있는지
- 집 안에 사람이나 반려동물이 있는지
사진을 문자로 보내 주시면 챙겨 갈 부품을 정하는 데 도움이 됩니다.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 마을 이장님이나 이웃의 확인 중 하나면 됩니다.
번거로우실 수 있지만 집 주인과 이웃을 모두 지키는 절차입니다. / 확인이 어려우면 작업할 수 없으니 미리 준비해 두세요.
부모님 댁이라면 자녀분이 연락하셔도 되지만 도착했을 때 부모님이나 확인할 수 있는 분이 필요합니다. / 미리 말씀해 주시면 순서를 맞춰 드립니다.
@ 점동면 24시 출장열쇠 현관문 개문

# 문을 열고 문틀 상태까지 같이 봅니다
먼저 문을 덜 상하게 여는 방법부터 해봅니다. / 열고 나면 경첩, 걸쇠, 문틀 상태를 함께 살펴봅니다.
경첩 나사만 조여도 해결되는 경우도 있고, 부품 교체나 문틀 보강이 필요한 경우도 있습니다. / 어떤 경우인지 말씀드리고 하나씩 여쭙고 진행합니다.
문 여는 방식은 [현관문 개문](door-open.html) 페이지에서도 확인하실 수 있습니다. / 못 열면 비용은 받지 않습니다.

# 비용은 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
열고 난 뒤에 말 없이 붙는 비용은 없습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 문틀이 문제라면 도어락만 바꿔서는 안 됩니다
문이 처져 있는데 새 도어락을 달아도 같은 증상이 다시 생깁니다. / 그래서 [도어락 수리](doorlock-repair.html)와 문 조정을 먼저 해보는 것이 맞습니다.
도어락이 너무 오래돼서 부품을 구하기 어렵거나 안쪽이 상했다면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
오래된 문은 도어락 구멍 크기가 맞지 않을 수도 있어 설치 전에 확인이 필요합니다. / 설치 방식은 [도어락 설치](doorlock-install.html)에 정리해 두었습니다.

# 문이 더 처지지 않게 하는 관리
- 경첩 나사를 해마다 한 번 조여 보기
- 장마철 전후에 문이 닫힐 때 걸리는지 확인하기
- 문 아래쪽이 바닥에 긁히지 않는지 보기
- 문을 세게 닫지 않고 손으로 받쳐서 닫기
작은 습관만으로도 문틀이 더 틀어지는 속도를 늦출 수 있습니다. / 이상한 소리가 나면 그날 바로 확인하세요.

# 점동면 말고 여주 어디든 갑니다
여흥동, 중앙동, 오학동, 가남읍, 세종대왕면, 대신면, 북내면까지 여주 전 지역을 다닙니다. / 면 지역은 거리가 있어 위치를 받고 도착 시간을 먼저 말씀드립니다.
여주에서 다니는 지역은 [여주시 출장열쇠](yeoju.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하세요.

오래된 문틀은 나무가 마르고 휘면서 걸쇠 위치가 조금씩 어긋납니다. / 한 번에 고치기보다 어긋난 정도를 먼저 확인하는 것이 순서입니다.
문틀을 크게 손보지 않고도 걸쇠 위치만 맞추면 해결되는 일이 많습니다. / 사진을 보내 주시면 상태를 보고 방향을 먼저 말씀드립니다.
