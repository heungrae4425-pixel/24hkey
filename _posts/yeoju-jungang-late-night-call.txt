# 새벽 두 시, 문 앞에 혼자 서 있을 때
중앙동은 여주 시내 중심으로 상가와 아파트, 주택이 함께 모여 있는 동네입니다. / 늦게까지 문을 여는 가게가 있어 밤늦게 귀가하는 분도 적지 않습니다.
회식이나 야간 근무를 마치고 새벽에 집에 왔는데 번호판이 꺼져 있거나 번호가 틀렸다고 나오면 막막해집니다. / 가족을 깨우기도 어렵고, 이 시간에 받는 곳이 있을까 싶어 전화를 망설이게 됩니다.
24시출장열쇠는 새벽에도 전화를 받습니다. / 이 글은 한밤에 문이 안 열릴 때 통화 한 번으로 필요한 내용을 정리하는 요령과 기다리는 동안 챙길 것을 적었습니다.
@ 중앙동 출장열쇠 새벽 현관문 안 열림

# 전화 걸기 전 30초만 확인하세요
급해도 아래 세 가지는 먼저 보고 전화하시면 통화가 짧아집니다.
- 번호판에 손을 대면 불이 들어오는지
- 번호를 누르면 어떤 소리가 나는지
- 문이 아예 안 움직이는지, 조금 열리다 멈추는지
불이 아예 안 들어오면 배터리, 틀렸다는 소리가 나면 번호, 소리는 맞는데 안 열리면 걸쇠나 모터 쪽입니다. / 이 구분만 전해 주셔도 맞는 장비를 챙겨 출발할 수 있습니다.
번호판이 꺼져 있다면 근처 편의점에서 9V 건전지를 사서 바깥 비상 단자에 대 보세요. / 그것만으로 열리면 출장을 부르지 않아도 됩니다.

# 통화는 이 순서로 말씀해 주세요
한밤에는 말이 꼬이기 쉽습니다. / 아래 순서대로 말씀해 주시면 됩니다.
- 위치: 중앙동 어느 쪽인지, 아파트라면 단지와 동, 호수
- 상태: 번호판 꺼짐, 번호 틀림, 소리만 남 중 어느 것인지
- 사람: 지금 혼자인지, 집 안에 누가 있는지
- 연락처: 휴대폰 배터리가 얼마나 남았는지
택시나 대리운전으로 막 도착하셨다면 기사님이 떠나기 전에 잠시 상황을 살펴보시는 것도 좋습니다. / 문이 안 열리면 휴대폰 충전이나 가까운 편의점까지 이동에 도움을 받을 수 있습니다.
마지막 항목을 꼭 말씀해 주세요. / 휴대폰이 곧 꺼질 것 같다면 만날 장소와 시간을 통화 중에 미리 정해 둡니다.

# 휴대폰 배터리가 얼마 없다면
새벽에 문 앞에서 검색하고 통화하다 보면 휴대폰 배터리가 빠르게 줄어듭니다. / 통화를 마친 뒤에는 화면 밝기를 낮추고 다른 앱은 꺼 두세요.
저희가 도착 전에 다시 연락드릴 수 있으니 전화가 꺼지지 않게 아껴 두시는 게 좋습니다. / 근처에 24시간 편의점이 있다면 충전기를 빌릴 수 있는지 물어보는 것도 방법입니다.
@ 중앙동 아파트 한밤 도어락 출장 전화

# 기다리는 동안 있을 곳
새벽 시간에 아파트 복도나 주택 골목에서 오래 서 있는 것은 춥고 불안합니다. / 기다리는 동안 있을 곳을 먼저 정하세요.
아파트라면 1층 공동 현관 안쪽이나 경비실 근처가 낫습니다. / 경비실에 사정을 말씀드려 두면 도착했을 때 출입도 수월해집니다. / 공동 현관 번호를 모를 때도 경비실 도움이 가장 빠릅니다.
주택이라면 불이 켜진 큰길 쪽 가게 앞이나 편의점 안에서 기다리셔도 됩니다. / 그럴 때는 기다리는 위치를 꼭 알려 주세요.
술을 드신 상태라면 계단에 오래 앉아 있지 마시고, 몸이 너무 춥거나 불편하면 망설이지 말고 119에 도움을 청하세요.

# 이웃이 자고 있는 시간이라는 것
한밤에 문을 두드리거나 번호를 반복해서 누르면 경고음이 복도에 크게 울립니다. / 잠든 이웃에게는 꽤 큰 소리입니다.
번호를 여러 번 틀리면 도어락이 입력을 막고 경고음을 내는 제품이 많습니다. / 서너 번 해서 안 되면 손을 떼고 전화를 주시는 편이 낫습니다.
저희도 작업할 때 소리를 최대한 줄이는 방법부터 씁니다. / 새벽 작업이라 더 조심합니다. / 작업 전 이웃에게 소리가 날 수 있다는 점을 고려해 장비도 조용한 것부터 꺼냅니다.

# 집 안에 가족이 자고 있다면
가족이 집 안에서 자고 있는데 번호가 바뀌었거나 휴대폰을 무음으로 해 둬서 연락이 안 되는 경우도 있습니다. / 이럴 때는 출장을 부르기 전에 문을 가볍게 두드리거나 집 전화로 몇 번 더 연락해 보세요.
안쪽 보조 걸쇠가 걸려 있다면 바깥에서 번호를 맞게 눌러도 문이 조금만 열리고 멈춥니다. / 이 경우도 가족을 깨우는 것이 가장 빠른 방법입니다.
가족과 끝내 연락이 안 되고 걱정되는 상황이라면 문 문제보다 안전 확인이 먼저입니다. / 이럴 때는 119나 112에 먼저 연락하세요.

# 새벽에도 확인 절차는 줄이지 않습니다
새벽이라도 확인 절차는 똑같이 거칩니다. / 주소가 나온 신분증이나 우편물, 관리사무소나 경비실 확인 중 하나면 됩니다.
신분증이 지갑에 있다면 금방 끝납니다. / 집 안에 있다면 경비실 확인으로 먼저 진행하고, 문을 연 뒤 실내에서 신분증을 함께 봅니다.
확인 방법은 [이용안내](guide.html)에 정리해 두었습니다.

# 비용은 새벽에도 먼저 말씀드립니다
문과 도어락 상태를 보고 비용을 먼저 말씀드립니다. / 늦은 시간이라고 말없이 붙는 비용은 없습니다.
들어 보시고 괜찮다고 하실 때 시작하고, 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 할 때도 바꾸기 전에 따로 여쭙습니다.

# 문은 조용하고 상하지 않게
도어락과 문이 상하지 않는 방법부터 차례로 시도합니다. / 새벽이라 소리가 적게 나는 방법을 먼저 고릅니다.
여는 과정은 [현관문 개문](door-open.html)에 자세히 적어 두었습니다. / 열쇠를 잃어버린 경우라면 [열쇠 출장](key-call.html)도 함께 보세요.

# 열고 난 뒤 꼭 하고 주무세요
문이 열리면 도어락이 다시 잘 잠기는지 확인합니다. / 배터리가 원인이었다면 새것으로 바꾸고, 번호를 잊었다면 새 번호를 등록합니다.
새벽에 바꾼 번호는 아침에 잊어버리기 쉽습니다. / 휴대폰 잠금이 된 메모에 바로 적어 두세요. / 함께 사는 가족에게도 아침에 꼭 알려 주세요.
고장이 보이면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이라면 날이 밝은 뒤 [도어락 교체](doorlock-replace.html)를 천천히 상의하셔도 됩니다.
@ 여주 출장열쇠 중앙동 새벽 도어락 개문

# 밤늦게 막히지 않으려면
- 배터리 경고음이 나면 그날 바로 교체하기
- 지갑이나 차에 비상용 9V 건전지 하나 넣어 두기
- 번호 외에 카드나 지문을 하나 더 등록하기
- 출장열쇠 번호를 휴대폰에 미리 저장해 두기
늦게 귀가하는 날이 잦다면 특히 첫 번째와 두 번째가 중요합니다. / 새벽 문제의 상당수가 배터리에서 시작되기 때문입니다.

# 중앙동 말고 여주 어디든 갑니다
중앙동 가까운 여흥동, 오학동 시내와 가남읍, 점동면, 세종대왕면, 대신면, 북내면까지 다닙니다. / 여주에서 다니는 범위는 [여주시 출장열쇠](yeoju.html)에, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

# 자주 묻는 질문

? 새벽이라 비용이 더 붙나요? | 비용은 문을 보고 시작 전에 먼저 말씀드리고, 말없이 붙는 비용은 없습니다.
? 휴대폰 배터리가 거의 없어요. | 통화 중에 만날 장소와 시간을 정해 두고, 전화는 아껴 두세요.
? 경비실이 비어 있으면 어떻게 확인하나요? | 신분증이나 주소가 나온 우편물, 문을 연 뒤 실내 확인 등 다른 방법을 함께 씁니다.
? 못 열면 그냥 가시나요? | 네, 못 열면 비용은 받지 않습니다.
