# 오학동에서 비밀번호가 갑자기 생각나지 않을 때
여주 오학동은 시내와 가까운 주택과 빌라, 아파트가 섞여 있는 동네입니다. / 여주역 쪽으로 오가는 분들이 많아 집에 돌아오는 시간이 제각각입니다.
평소에는 손이 먼저 번호를 누르는데, 어느 날 갑자기 머릿속이 하얘지는 일이 있습니다. / 바꾼 지 얼마 안 됐거나 오랜만에 집에 오면 더 그렇습니다.
이 글은 오학동에서 비밀번호가 기억나지 않을 때 전화하기 전에 해볼 것을 먼저 적었습니다. / 그래도 안 되면 [여주 출장열쇠](yeoju.html)가 어떤 순서로 문을 여는지도 이어서 적어 두었습니다.
@ 오학동 도어락 비밀번호 분실 출장열쇠

# 번호를 잊는 일은 생각보다 흔합니다
비밀번호는 매일 쓰다 보면 손가락이 기억하고 머리는 잊어버립니다. / 번호판을 눈으로 보면서 누르려고 하면 오히려 헷갈리는 이유입니다.
가족 중 누가 번호를 바꿨는데 말을 안 한 경우도 많습니다. / 이사 직후나 도어락을 새로 단 뒤에 특히 자주 생깁니다.
번호를 여러 번 틀리면 도어락이 잠시 입력을 막아 버리기도 합니다. / 그래서 같은 번호를 계속 누르는 것은 좋지 않습니다.

# 먼저 휴대폰 메모와 가족 연락부터
메모 앱이나 사진첩, 메신저 나와의 채팅에 번호를 적어 두는 분이 많습니다. / 도어락을 설치한 날 찍어 둔 설명서 사진에 번호가 남아 있는 경우도 있습니다.
같이 사는 가족에게 전화를 걸어 보는 것이 가장 빠릅니다. / 번호가 바뀌었는지, 마지막으로 누가 바꿨는지 물어보세요.
집 안에 누가 있다면 문 안쪽에서 열어 달라고 하는 방법도 있습니다. / 혼자 사는 집이면 이 단계는 건너뛰어도 됩니다.
@ 여주 오학동 현관문 도어락 번호판

# 카드키나 열쇠가 따로 있는지 확인
도어락 중에는 번호 외에 카드키나 열쇠로도 열리는 제품이 많습니다. / 지갑이나 가방 앞주머니에 카드가 있는지 한번 찾아보세요.
번호판 아래쪽에 열쇠구멍 덮개가 있는 제품이라면 평소 쓰던 열쇠가 있을 수도 있습니다. / 열쇠로 열 수 있다면 일단 문은 열립니다.
들어간 다음에 천천히 새 비밀번호를 정하시면 됩니다. / 서두르지 않는 것이 번호를 다시 잊지 않는 방법입니다.

# 번호를 계속 눌러 보는 건 3~4번까지만
기억나는 번호를 몇 번 눌러 보는 것은 괜찮습니다. / 다만 너무 많이 틀리면 도어락이 입력을 막고 경고음을 내기도 합니다.
잠금이 걸리면 한동안 번호가 먹히지 않아 문 앞에서 더 오래 기다리게 됩니다. / 서너 번 해보고 안 되면 멈추고 다른 방법을 찾아보세요.
번호판에 손자국이 많이 묻은 곳을 보고 번호를 짐작하는 방법도 있지만 정확하지 않습니다. / 차라리 연락하시는 편이 시간이 덜 걸립니다.

# 이럴 땐 오학동이라도 바로 전화 주세요
가족과 연락이 안 되고 카드키도 없다면 더 오래 붙잡고 있을 필요가 없습니다. / 특히 밤늦은 시간이나 날씨가 궂은 날은 일찍 연락 주시는 편이 낫습니다.
집 안에 불을 켜 두었거나 가스, 전기를 쓰는 상황이면 먼저 말씀해 주세요. / 아이나 반려동물이 안에 있다면 꼭 먼저 알려 주세요.
전화로 위치와 도어락 모양만 말씀해 주시면 출동 여부를 바로 알려 드립니다. / 문 열기 전에 비용을 먼저 말씀드립니다.

# 전화로는 이렇게 설명해 주세요
오학동은 주택과 빌라, 아파트가 나뉘어 있어 건물 종류를 먼저 알려 주시면 좋습니다. / 몇 동 몇 호인지, 건물 이름 대신 근처에서 알아볼 수 있는 곳을 말씀해 주세요.
- 건물 종류와 대략 어느 쪽인지(여주역 방향 등)
- 도어락 모양(손잡이 일체형, 번호판만 있는 형, 밀고 당기는 형)
- 번호판이 켜지는지, 어떤 소리가 나는지
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙겨 갑니다.
@ 여주 오학동 출장열쇠 현관문 개문

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리실 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 집 주인을 모두 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.
신분증이 집 안에 있다면 휴대폰에 저장된 계약서나 공과금 고지서도 도움이 됩니다. / 건물에 관리인이 있다면 대신 확인을 부탁하는 방법도 있습니다.

# 문을 여는 방법은 덜 상하는 순서로
도어락과 문 상태를 먼저 살피고 흠집이 가장 적은 방법부터 해봅니다. / 처음부터 힘으로 여는 방식은 쓰지 않습니다.
도어락 종류에 따라 걸리는 시간은 다르지만, 작업 중에 바꿔야 할 부품이 보이면 손대기 전에 말씀드립니다. / 못 열면 비용은 받지 않습니다.
문 여는 방식이 궁금하시면 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.

# 비용은 열기 전에 먼저 말씀드립니다
현관문 상태와 도어락 종류를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
열고 난 뒤에 말 없이 붙는 비용은 없습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭤봅니다.
진행 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 문이 열린 뒤에는 새 번호를 같이 등록합니다
비밀번호를 잊어서 연 경우라면 안쪽에서 새 번호를 등록하는 것까지 도와드립니다. / 기존 번호는 지우고 새 번호만 남겨 둡니다.
번호를 정할 때는 생일이나 전화번호처럼 쉬운 조합은 피하시는 것이 좋습니다. / 가족이 함께 쓰는 번호라면 같이 정해서 공유해 두세요.
배터리가 많이 닳아 있으면 같이 교체해 드립니다. / 번호판이 불안정하면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.

# 번호를 다시 잊지 않는 방법
도어락 안쪽 덮개 안에 번호를 적어 두는 분이 있는데 그것은 권하지 않습니다. / 가족 단체방에 비밀번호 힌트만 남겨 두는 정도가 적당합니다.
카드키나 열쇠 하나는 집 밖 믿을 만한 곳에 따로 맡겨 두세요. / 외출할 때 휴대폰에 입력해 두는 방법도 있지만 휴대폰 잠금을 꼭 걸어 두셔야 합니다.
오래된 도어락이라 번호판 반응이 느려졌다면 [도어락 교체](doorlock-replace.html)를 생각해 볼 때입니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 오학동 말고 여주 어디든 갑니다
여흥동, 중앙동, 가남읍, 점동면, 세종대왕면, 대신면, 북내면까지 여주 전 지역을 다닙니다. / 읍면 쪽은 거리가 있어 위치를 받고 도착 시간을 먼저 말씀드립니다.
여주에서 다니는 지역은 [여주시 출장열쇠](yeoju.html)에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
