# 원룸은 문이 두 번 잠겨 있습니다
오학동은 여주 시내와 가까운 쪽으로 주택과 빌라, 아파트가 섞여 있고 원룸 건물도 곳곳에 있는 동네입니다. / 학교나 직장 때문에 여주역 쪽을 오가며 혼자 사는 분들이 많이 지냅니다.
원룸 건물은 대개 1층 공동 출입문을 지나 계단이나 엘리베이터로 올라가야 내 방 현관이 나옵니다. / 그래서 "문이 안 열린다"는 상황도 두 갈래로 나뉩니다.
건물 공동 출입문에서 막혔는지, 내 방 현관에서 막혔는지에 따라 연락할 곳과 걸리는 시간이 달라집니다. / 이 글은 원룸에서 문이 잠겼을 때 건물 출입부터 챙겨야 하는 이유와 순서를 정리했습니다.
@ 오학동 출장열쇠 원룸 현관 잠김

# 첫 번째 문, 건물 공동 출입문
공동 출입문 번호가 기억나지 않거나 카드를 잃어버렸다면 내 방 현관까지 갈 수가 없습니다. / 이때 가장 먼저 연락할 곳은 같은 건물 이웃이나 집주인입니다.
마침 드나드는 이웃이 있다면 사정을 말하고 함께 들어가셔도 됩니다. / 건물 단체 대화방이 있다면 공동 현관 번호가 공지로 올라와 있는지 확인해 보세요.
공동 출입문 번호판이 아예 꺼져 있다면 건물 쪽 배터리 문제일 수 있습니다. / 이 경우는 건물 전체가 같은 불편을 겪으니 집주인에게 바로 알려 주세요. / 비상 단자가 있다면 9V 건전지로 잠시 전원을 넣어 열 수도 있습니다.

# 두 번째 문, 내 방 현관
건물 안까지는 들어왔는데 내 방 현관이 안 열린다면 이제 내 문 문제입니다. / 원룸 현관 도어락에서 흔한 원인은 이렇습니다.
- 배터리가 다 돼 번호판이 꺼진 경우
- 비밀번호를 잊었거나 입주 때 받은 번호를 바꾸지 않아 헷갈리는 경우
- 안쪽 보조 걸쇠를 건 채 문이 닫힌 경우
- 열쇠식 보조키까지 잠근 채 열쇠를 안에 두고 나온 경우
번호판 불이 들어오는지, 번호를 누르면 어떤 소리가 나는지 먼저 보세요. / 이 내용을 전화로 알려 주시면 맞는 장비를 챙겨 갑니다.

# 왜 건물 출입부터 챙겨야 할까
저희가 도착했는데 공동 출입문이 잠겨 있으면 내 방 현관 앞까지 가지 못합니다. / 문 앞까지 와서 다시 집주인 연락을 기다리는 일이 생기면 시간이 배로 걸립니다.
그래서 내 방 현관 문제로 전화 주실 때도 공동 출입문을 열 방법이 있는지 함께 여쭙습니다. / 번호를 아시는지, 이웃이나 집주인이 열어 줄 수 있는지 미리 정해 두면 도착 후 바로 올라갈 수 있습니다.
공동 출입문 번호를 알고 계시면 통화할 때 알려 주셔도 됩니다. / 작업이 끝나면 그 번호는 따로 남기지 않습니다.
@ 오학동 원룸 건물 공동 출입문 확인

# 관리실이 있는 건물이라면
오피스텔처럼 관리실이 있는 건물은 공동 출입문 문제를 관리실에서 바로 풀 수 있는 경우가 많습니다. / 관리실 운영 시간이 지난 밤이라면 비상 연락처가 게시판이나 엘리베이터 안에 붙어 있는지 확인해 보세요.
관리실에서 세대 거주자를 확인해 주면 신분 확인도 함께 끝납니다. / 연락해 둔 뒤 저희가 도착할 때 관리실 쪽에서 출입을 열어 주시면 가장 빠릅니다.
건물마다 외부 작업자 출입 규칙이 따로 있는 곳도 있습니다. / 관리실에 출장열쇠가 온다는 것을 미리 알려 두시면 입구에서 기다리는 일이 줄어듭니다.

# 세입자가 휴대폰에 저장해 둘 연락처
원룸에 사는 분이라면 아래 연락처를 평소에 저장해 두시면 이런 날 큰 도움이 됩니다.
- 집주인이나 관리를 맡은 부동산 연락처
- 같은 건물에서 알고 지내는 이웃 한 명
- 가까이 사는 가족이나 친구
- 출장열쇠 번호
집주인 연락처는 계약할 때 받아 두지만 막상 필요할 때 찾지 못하는 경우가 많습니다. / 이름에 "집주인"이라고 붙여 저장해 두시면 바로 찾을 수 있습니다. / 건물 이름과 호수를 함께 적어 두면 더 좋습니다.

# 입주 때 받은 번호를 그대로 쓰고 있다면
원룸은 세입자가 자주 바뀌어서 입주할 때 받은 비밀번호를 그대로 쓰는 분이 적지 않습니다. / 이전 세입자나 다른 사람이 그 번호를 알고 있을 수 있습니다.
문을 연 김에 새 번호로 바꿔 두시는 것을 권합니다. / 등록된 카드나 지문이 있다면 내 것만 남기고 지우는 것도 함께 해 드립니다.
도어락 자체를 바꾸는 일은 집주인과 먼저 이야기하시는 편이 좋습니다. / 번호 변경과 달리 기기 교체는 건물 시설을 바꾸는 일이기 때문입니다.

# 건물 이름과 층, 호수가 먼저입니다
오학동은 비슷한 건물이 붙어 있는 곳이 있어 건물 이름과 층, 호수를 꼭 알려 주세요.
- 건물 이름이나 번지, 가까운 큰길
- 막힌 곳이 공동 출입문인지, 내 방 현관인지
- 공동 출입문을 열 방법이 있는지
- 번호판 상태와 도어락 모양
위치를 받으면 도착 시간을 먼저 말씀드립니다. / 기다리는 동안 추우면 건물 안 계단이나 가까운 가게에서 기다리셔도 됩니다.

# 원룸 거주 확인은 계약서로도 됩니다
원룸이라도 사시는 분인지 먼저 확인합니다. / 주소와 호수가 나온 신분증이나 우편물, 임대차 계약서 사진, 집주인 확인 중 하나면 됩니다.
전입신고 전이라 신분증 주소가 다르면 계약서 사진이나 집주인 통화로 보완합니다. / 진행 순서는 [이용안내](guide.html)에 정리해 두었습니다.

# 비용은 문을 보고 먼저
도어락 종류와 상태를 보고 비용을 먼저 말씀드립니다. / 들어 보시고 괜찮을 때만 시작합니다.
끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙고, 집주인과 상의가 필요하면 기다려 드립니다.

# 원룸 도어락을 여는 순서
원룸 현관 도어락은 제품이 다양해서 맞는 방법을 골라 덜 상하는 쪽부터 시도합니다. / 여는 과정은 [현관문 개문](door-open.html)에 적어 두었습니다.
열고 나면 도어락이 잘 잠기는지, 배터리 상태는 어떤지 함께 봅니다. / 고장이 보이면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 열쇠식 보조키 문제라면 [열쇠 출장](key-call.html)으로 정리합니다.
@ 여주 출장열쇠 오학동 원룸 도어락 점검

# 원룸 문 앞에서 막히지 않는 습관
- 공동 출입문 번호와 내 방 번호를 같은 숫자로 쓰지 않기
- 입주하자마자 내 방 번호 바꾸기
- 카드키 하나는 지갑에 따로 넣어 두기
- 배터리 경고음이 나면 그날 바로 교체하기
배터리는 집주인이 아니라 사는 분이 챙기는 경우가 많습니다. / 교체 날짜를 배터리 칸 안쪽에 적어 두면 잊어버리지 않습니다.
도어락 교체를 집주인과 이야기하게 된다면 [도어락 교체](doorlock-replace.html) 안내를 함께 보여 드려도 좋습니다.

# 오학동 말고 여주 어디든 갑니다
오학동 가까운 여흥동, 중앙동 시내와 가남읍, 점동면, 세종대왕면, 대신면, 북내면까지 다닙니다. / 여주에서 다니는 범위는 [여주시 출장열쇠](yeoju.html)에, 다른 지역은 [출장 지역](area.html)에 정리해 두었습니다.
