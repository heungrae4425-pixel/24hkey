# 전화 걸기 전 3분이 도착 뒤 30분을 줄입니다
여흥동은 여주 시내 한가운데로 아파트와 주택, 상가가 모여 있고 여주역 쪽으로 오가는 분이 많은 동네입니다. / 시내라 출동 거리는 짧은 편이지만, 막상 도착해서 맞는 장비가 없으면 다시 챙기러 가는 시간이 생깁니다.
그래서 문 앞에서 전화를 걸기 전에 휴대폰으로 몇 가지만 남겨 두시면 상담이 짧아지고 작업도 빨라집니다. / 이 글은 여흥동에서 출장을 부르기 전에 준비하면 좋은 것을 사진, 영상, 위치, 서류 순서로 정리했습니다.
급한 상황이라면 모든 걸 다 하실 필요는 없습니다. / 사진 두 장과 주소만 있어도 충분합니다.
@ 여흥동 출장열쇠 요청 전 도어락 사진 찍기

# 먼저 급한 상황인지부터 판단하기
준비보다 앞서는 것이 있습니다. / 아래 경우라면 사진을 찍느라 시간을 쓰지 말고 바로 전화 주세요.
- 집 안에 아이나 거동이 불편한 가족이 혼자 있는 경우
- 가스불이나 난방기를 켜 둔 채 문이 잠긴 경우
- 반려동물이 안에 있고 집 안이 덥거나 추운 경우
불이나 연기가 걱정되면 119가 먼저입니다. / 그 외의 경우라면 아래 준비를 차근차근 해 두셔도 늦지 않습니다.

# 한 줄 요약부터 만들어 두기
전화를 받으면 가장 먼저 여쭙는 것은 지금 문이 어떤 상태인지입니다. / 머릿속으로 한 줄만 정리해 두세요.
예를 들면 "번호판이 아예 안 켜져요", "번호는 맞다는데 문이 안 열려요", "안쪽 보조키를 잠그고 나왔어요" 같은 식입니다. / 이 한 줄만 들어도 원인을 꽤 좁힐 수 있습니다.
여기에 언제부터 그랬는지를 덧붙이면 더 좋습니다. / 아침에는 됐는데 저녁에 갑자기 안 됐는지, 며칠 전부터 경고음이 났는지에 따라 짐작하는 원인이 달라집니다.

# 사진은 정면과 옆면 두 장이면 됩니다
첫 번째 사진은 도어락 바깥쪽을 정면에서 찍어 주세요. / 번호판 모양과 손잡이 형태, 제조사 표시가 보이면 됩니다.
두 번째 사진은 문 옆쪽에서 문틀과 문 사이 틈이 보이게 비스듬히 찍어 주세요. / 문이 처졌는지, 보조키가 있는지가 이 사진에서 드러납니다.
밤이라 어둡다면 플래시를 켜고 찍으시면 됩니다. / 조금 흐려도 모양만 알아볼 수 있으면 되니 너무 신경 쓰지 마세요.
@ 여흥동 현관 도어락 정면과 옆면 사진

# 소리가 나는 증상이면 짧은 영상이 낫습니다
번호를 누를 때 경고음이 나거나 모터 소리만 들린다면 사진보다 10초 남짓한 영상이 훨씬 도움이 됩니다. / 번호판에 손을 댄 순간부터 소리가 날 때까지만 찍어 보내 주세요.
"띠리릭" 하고 끝나는지, "윙" 소리가 길게 나다 멈추는지, 아무 소리도 없는지에 따라 배터리, 모터, 걸쇠 가운데 어디를 볼지 정할 수 있습니다. / 비밀번호가 영상에 찍히지 않게 손으로 살짝 가리고 누르세요.
손잡이를 돌릴 때 걸리는 느낌이 있다면 그 동작도 함께 찍어 주세요. / 손잡이가 끝까지 내려가는지, 중간에서 멈추는지만 보여도 걸쇠 쪽 문제인지 금방 알 수 있습니다.
@ 여흥동 도어락 번호 누를 때 소리 영상

# 위치는 주소에 한 줄을 더해서
여흥동은 시내라 주소만으로도 찾아갈 수 있지만, 한 줄을 더해 주시면 헤매지 않습니다. / 아래 가운데 해당하는 것을 덧붙여 주세요.
- 아파트: 동, 호수와 공동현관 출입 방법
- 주택: 대문 쪽에서 보이는 큰 표시나 가까운 큰길
- 상가: 건물 몇 층인지, 건물 출입구가 앞쪽인지 뒤쪽인지
- 차를 세울 곳이 있는지
주차 자리가 마땅치 않은 골목이면 그것도 미리 말씀해 주세요. / 가까운 곳에 세우고 걸어서 갑니다.
주소를 문자로 보내 주시면 통화로 불러 주는 것보다 틀릴 일이 적습니다. / 지도 앱에서 현재 위치를 공유해 주셔도 됩니다.

# 확인 서류는 지금 어디 있는지 떠올리기
문을 열기 전에는 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 가운데 하나면 됩니다.
신분증이 집 안에 있다면 그렇다고 미리 말씀해 주세요. / 문을 연 직후 보여 주시거나, 관리사무소나 이웃 확인으로 대신할 수 있습니다.
상가라면 사업자등록증이나 임대차 계약서 사진이 도움이 됩니다. / 대표가 아닌 직원이 혼자 있다면 대표와 통화가 되도록 준비해 주세요.
@ 여흥동 출장열쇠 거주 확인 신분증 우편물

# 휴대폰 배터리와 기다릴 곳
휴대폰 배터리가 얼마 남지 않았다면 통화는 짧게 하고 문자로 주고받는 쪽이 낫습니다. / 가까운 편의점이나 가게에서 잠깐 충전을 부탁해 보셔도 좋습니다.
추운 날이나 비 오는 날에는 문 앞에서 기다리지 말고 따뜻한 곳에서 기다리세요. / 어디 계신지 알려 주시면 도착해서 그쪽으로 연락드립니다.

# 해 두면 오히려 곤란한 준비
기다리는 동안 무엇이라도 해 보려고 드라이버로 번호판을 뜯거나, 열쇠 구멍에 기름을 넣는 분이 있습니다. / 이런 시도는 상하지 않게 여는 방법을 쓸 수 없게 만들기도 합니다.
번호를 계속 눌러 입력 잠금이 길어지게 하는 것도 피해 주세요. / 서너 번 해 보고 안 되면 그대로 두시는 게 가장 좋은 준비입니다.
여러 업체에 동시에 출동을 부탁해 두는 것도 피해 주세요. / 비교는 통화로 하시고, 정한 한 곳에만 출동을 부탁하시는 편이 서로 시간을 아낍니다.

# 전화 뒤 진행 순서
보내 주신 사진과 상황을 보고 도착 예상 시간을 먼저 말씀드립니다. / 도착하면 거주 확인을 하고, 문과 도어락 상태를 본 뒤 시작 전에 비용을 말씀드립니다.
괜찮으시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다. / 문을 끝내 못 열면 비용은 받지 않습니다.
자세한 순서는 [이용안내](guide.html), 여는 방법은 [현관문 개문](door-open.html)에 있습니다.

# 문이 열린 뒤 이어지는 일
열고 나면 원인을 함께 확인합니다. / 배터리였다면 새것으로 바꾸고, 번호를 몰랐다면 새 번호 등록까지 도와 드립니다. / 미리 보내 주신 사진은 작업이 끝나면 지우셔도 됩니다.
부품이 상했다면 [도어락 수리](doorlock-repair.html)로 고쳐 쓸 수 있는지 먼저 보고, 어렵다면 그때 교체를 말씀드립니다.

# 미리 저장해 두면 편한 것
평소 휴대폰에 도어락 사진 한 장과 모델명을 저장해 두면, 다음에 문제가 생겼을 때 문 앞에서 찍을 필요가 없습니다. / 관리사무소 번호와 출장열쇠 번호도 같은 폴더에 넣어 두세요.
가족 단체방에 도어락 사진과 모델명을 한 번 올려 두면, 다른 식구가 문 앞에서 막혔을 때도 같은 자료를 바로 꺼내 쓸 수 있습니다. / 배터리를 간 날짜도 함께 적어 두면 다음 교체 시기를 놓치지 않습니다.

# 여흥동 말고 여주 어디든
여흥동과 이어진 중앙동, 오학동 시내는 물론 가남읍, 점동면, 세종대왕면, 대신면, 북내면까지 여주 전 지역을 다닙니다. / 동네 안내는 [여주 출장열쇠](yeoju.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

서울, 경기 전 지역 24시간 출동합니다. / 전화 010-3664-5455로 연락 주세요.
