# 닫았다고 생각했는데 문이 살짝 떠 있었다
청산면은 연천에서도 단독주택이 많은 곳이라 현관문과 대문, 뒷문까지 바깥 날씨를 그대로 받는 문이 여럿입니다. / 겨울이 길고 추운 지역이라 문이 끝까지 닫히지 않으면 찬 바람이 먼저 알려 줍니다.
현관에서 신발을 벗고 돌아섰는데 문이 손가락 한 마디만큼 떠 있거나, 도어락이 잠기는 소리를 내지 않는 날이 있습니다. / 처음에는 가끔이다가 점점 자주 그러면 문 어딘가가 조금씩 틀어지고 있다는 신호입니다.
이 글은 청산면 주택에서 문이 덜 닫힐 때 틈을 확인하는 간단한 방법과, 경첩과 도어클로저를 차례로 점검하는 순서를 정리했습니다.
@ 청산면 단독주택 현관문 덜 닫힘 틈

# 덜 닫힌 문이 불러오는 일
문이 덜 닫히면 도어락 걸쇠가 문틀 구멍에 들어가지 못해 잠기지 않습니다. / 자동 잠금 도어락은 잠그려다 실패하고 경고음을 내거나, 아무 소리 없이 열린 채로 남기도 합니다.
겨울에는 틈으로 찬 공기가 들어와 현관이 차가워지고 결로도 늘어납니다. / 도어락 배터리도 추위를 더 타게 되어 연천 겨울에는 이중으로 손해입니다.
그러니 덜 닫히는 것을 느꼈다면 큰 고장이 아니라도 미루지 않는 편이 좋습니다. / 외출할 때 문을 한 번 당겨 잠겼는지 확인하는 습관도 함께 들여 두세요.

# 종이 한 장으로 틈 재 보기
문이 어디에서 뜨는지 확인하는 가장 쉬운 방법은 종이 한 장입니다. / 문을 연 상태에서 문틀에 종이를 대고 문을 닫은 뒤 종이를 당겨 보세요.
위쪽, 가운데, 아래쪽, 손잡이 쪽, 경첩 쪽을 차례로 해 봅니다. / 종이가 쉽게 빠지는 곳이 문이 떠 있는 곳이고, 꽉 물려 안 빠지는 곳이 문이 닿는 곳입니다.
손잡이 쪽 아래가 꽉 물리고 위쪽이 헐렁하다면 문이 경첩 반대편 아래로 처진 것입니다. / 대부분의 덜 닫힘은 이 모양에서 시작되니, 어느 쪽이 헐렁했는지 메모해 두시면 전화로 설명하기도 쉽습니다.
@ 청산면 현관문 종이 끼워 틈 확인하기

# 경첩부터 보는 이유
문의 무게는 모두 경첩이 받칩니다. / 특히 위쪽 경첩은 문이 앞으로 기울려는 힘을 혼자 버티고 있어서 나사가 먼저 풀립니다.
문을 열고 위쪽 경첩을 손으로 잡은 채 문을 위아래로 살짝 흔들어 보세요. / 덜컥거리는 느낌이 있다면 경첩 나사가 풀린 것입니다.
드라이버로 위쪽 경첩 나사부터 조이고, 그다음 가운데와 아래를 조입니다. / 조인 뒤 다시 종이로 틈을 재 보면 차이가 바로 보입니다.
드라이버는 나사 머리 홈에 꼭 맞는 크기를 쓰세요. / 작은 드라이버로 세게 돌리면 홈이 뭉개져 나중에는 풀지도 조이지도 못하게 됩니다.
@ 청산면 현관문 위쪽 경첩 덜컥거림 확인

# 나사가 헛돌 때는 더 조이지 않기
나사를 돌리는데 계속 헛돌면서 조여지지 않는다면 나사가 박힌 구멍이 닳은 것입니다. / 오래된 나무 문틀이나 여러 번 조였다 푼 자리에서 흔히 생깁니다.
이럴 때 더 큰 힘으로 돌리면 구멍만 넓어집니다. / 구멍을 메우고 다시 박거나 조금 긴 나사로 바꿔야 하니 이 단계에서는 맡기시는 편이 낫습니다.

# 오래된 철문 경첩은 사정이 다릅니다
오래된 주택 철문이나 대문은 경첩이 문에 용접되어 있어 나사로 조일 수 없는 경우가 있습니다. / 이런 경첩은 축이 닳아 문이 아래로 내려앉으면서 바닥을 긁기도 합니다.
축 부분에 녹이 보이고 문을 열 때 끼익 소리가 크다면 축에 윤활제를 넣어 주는 것만으로 움직임이 나아집니다. / 내려앉은 높이를 되돌리려면 경첩 축에 받침을 넣거나 경첩을 바꿔야 해서 맡기셔야 합니다.

# 도어클로저가 있다면 팔 연결부를 확인
문 위에 도어클로저가 달려 있다면 먼저 몸통과 문을 잇는 팔 부분을 보세요. / 팔 관절이나 문틀 쪽 고정 받침 나사가 풀리면 클로저가 힘을 제대로 전하지 못해 문이 끝까지 안 닫힙니다.
문을 열어 둔 채 팔 관절을 손으로 잡고 흔들어 보세요. / 헐렁하다면 고정 나사를 조여 주는 것만으로 해결되는 경우가 많습니다.
@ 연천 청산면 도어클로저 팔 연결부 고정 나사

# 클로저 힘 자체가 약해졌다면
팔 연결부가 단단한데도 문이 끝에서 멈춘다면 클로저 안쪽 스프링 힘이 약해진 것일 수 있습니다. / 추운 겨울에는 안에 든 기름이 굳어 같은 증상이 더 심해지기도 합니다.
몸통 아래나 옆에 기름이 번진 자국이 있다면 안쪽이 상한 것입니다. / 이 경우에는 조절로 되돌리기 어려워 클로저를 바꿔야 합니다.
청산면 주택처럼 현관 바로 앞이 마당인 집은 바람이 문을 밀어 클로저 힘을 이기는 경우도 있습니다. / 바람이 센 날만 덜 닫힌다면 클로저 힘이 문에 비해 약한 것이라 한 단계 센 제품으로 바꾸는 것을 생각해 볼 만합니다.

# 문틀 받이와 패킹도 함께
경첩과 클로저를 손봤는데도 마지막에 걸린다면 도어락 걸쇠가 문틀 받이 구멍과 어긋나 있는 것입니다. / 받이 쇠판에 긁힌 자국을 보면 걸쇠가 어디를 치는지 알 수 있습니다.
문 둘레 고무 패킹이 겨울에 딱딱하게 굳어 문을 밀어내는 경우도 있습니다. / 패킹이 갈라졌거나 너무 두껍다면 바꾸는 것만으로 문이 부드럽게 닫힙니다.
외풍을 막으려고 문틈에 덧댄 바람막이가 오히려 문을 밀어내는 경우도 있습니다. / 최근에 붙였다면 걸쇠 쪽과 경첩 쪽 바람막이를 살짝 떼어 내고 다시 닫아 보세요.

# 직접 할 수 있는 범위
- 경첩 나사 조이기 (헛돌지 않을 때까지만)
- 경첩 축에 윤활제 넣기
- 도어클로저 팔 고정 나사 조이기
- 종이로 틈 다시 재 보기
여기까지 해 보고도 덜 닫히면 연락 주세요. / 무리해서 문을 들어 올리거나 경첩을 떼어 내는 것은 문이 무거워 다치기 쉽습니다.

# 청산면에서 연락 주실 때
거리가 있는 곳이라 위치를 받으면 도착 시간을 먼저 말씀드립니다. / 어느 문인지, 종이로 재 봤을 때 어디가 떠 있는지, 도어클로저가 있는지 알려 주시면 맞는 부품을 챙겨 갑니다.
비용은 문 상태를 보고 시작 전에 먼저 말씀드리고, 손볼 수 없으면 받지 않습니다. / 문이 잠겨 열어야 한다면 사시는 분인지 신분증이나 우편물로 확인한 뒤 진행합니다. 진행 순서는 [이용안내](guide.html), 여는 방법은 [현관문 개문](door-open.html)에 있습니다.

# 손본 뒤 겨울을 나는 습관
겨울이 오기 전에 경첩 나사와 클로저 팔을 한 번씩 조여 주세요. / 종이 틈 재기를 계절마다 한 번 해 보면 문이 틀어지기 시작하는 것을 일찍 알 수 있습니다.
문을 손으로 끝까지 밀어 닫는 습관은 클로저와 경첩 모두의 수명을 늘려 줍니다. / 도어락 반응이 느려졌다면 [도어락 수리](doorlock-repair.html)도 함께 받아 보세요.

# 청산면 말고 연천 어디든
청산면과 가까운 전곡읍, 연천읍을 비롯해 군남면, 백학면, 미산면까지 연천 전 지역을 다닙니다. / 동네 안내는 [연천 출장열쇠](yeoncheon.html), 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
