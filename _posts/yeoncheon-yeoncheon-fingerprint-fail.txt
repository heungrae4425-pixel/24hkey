# 연천읍, 지문이 갑자기 안 먹힐 때
연천읍은 연천역 주변 주택과 아파트, 원룸이 모여 있는 곳입니다. / 최근에 지문 도어락으로 바꾼 집도 늘어서 지문 인식 문제로 연락 주시는 분이 있습니다.
어제까지 잘 되던 지문이 오늘 갑자기 인식이 안 되면 당황하게 됩니다. / 손가락을 여러 번 대 봐도 계속 실패하면 문 앞에서 시간만 흘러갑니다.
이 글은 연천읍에서 지문 인식이 안 될 때 원인을 어떻게 가르는지 정리했습니다. / 직접 해볼 수 있는 확인과 [도어락 수리](doorlock-repair.html)를 부르는 때도 나눠 적었습니다.
@ 연천 연천읍 지문 도어락 인식 실패

# 먼저 손 상태를 보세요
지문 인식은 손가락 표면 상태에 크게 영향을 받습니다.
- 손이 너무 건조하거나 갈라진 경우
- 손에 물기나 땀, 로션이 묻은 경우
- 손가락에 상처나 밴드가 붙은 경우
- 추운 날 손이 얼어서 피부가 굳은 경우
- 일을 많이 해서 지문이 닳은 경우
농사나 공사처럼 손을 많이 쓰는 일을 하시는 분은 지문이 닳아 인식이 잘 안 될 수 있습니다. / 이런 분은 지문 대신 번호키를 쓰는 쪽이 더 안정적이기도 합니다.

# 손을 정리하고 다시 대 보기
- 마른 수건으로 손과 센서를 닦기
- 손가락을 센서 가운데에 평평하게 대기
- 너무 세게 누르지 말고 적당한 힘으로 대기
- 손가락을 바꿔 가며 등록된 다른 손가락 시도
- 한 번에 안 되면 약간 위치를 옮겨 다시 대기
추운 날에는 손을 비벼 따뜻하게 한 뒤 대 보세요. / 손가락이 차가우면 피부가 굳어 센서가 읽기 어렵습니다.
@ 연천읍 지문 센서 손 상태 확인

# 센서 쪽 문제일 때
센서 표면에 기름때나 먼지가 쌓이면 지문이 흐리게 읽힙니다. / 안경 닦는 천처럼 부드러운 천으로 가볍게 닦아 주세요.
센서에 흠집이 나거나 틈에 물이 들어간 경우에는 닦아도 소용이 없습니다. / 물기가 들어갔다면 말릴 시간이 필요합니다.
알코올이나 세정제를 직접 뿌려 닦는 건 피하세요. / 센서 아래로 스며들면 부품이 상할 수 있습니다.

# 배터리가 약해졌을 때
지문 도어락은 번호키보다 전기를 더 씁니다. / 배터리가 약해지면 지문 인식이 먼저 느려지거나 실패하는 경우가 많습니다.
번호키 입력은 되는데 지문만 안 된다면 배터리가 약해진 것일 수 있습니다. / 경고음이 나는지, 번호판 불빛이 약한지도 같이 보세요.
배터리를 새것으로 바꾸고도 증상이 그대로면 센서 자체 문제일 가능성이 큽니다. / 이때는 직접 건드리기보다 연락 주시는 게 좋습니다.

# 지문을 다시 등록해야 하는 경우
시간이 지나면서 손가락 상태가 바뀌어 처음 등록한 지문이 맞지 않는 경우가 있습니다. / 이럴 때는 지문을 삭제하고 새로 등록하면 해결됩니다.
등록할 때는 손가락을 여러 각도로 나눠 여러 번 등록하는 게 좋습니다. / 한 손가락을 두세 번 나눠 등록하면 인식률이 올라갑니다.
가족이 쓰는 경우에는 아이와 어르신 손가락도 별도로 등록하세요. / 아이는 자라면서 지문이 변하니 가끔 다시 등록하는 게 좋습니다.

# 지문이 안 될 때 번호키와 열쇠가 있는지 확인
지문 도어락이라도 번호키와 열쇠 구멍이 같이 있는 제품이 많습니다. / 지문이 안 될 때를 대비해 번호와 열쇠를 항상 챙겨 두세요.
번호나 열쇠가 없는 상황에서 지문이 안 되면 문 앞에서 막힙니다. / 이럴 때는 억지로 열지 말고 연락 주세요.
지문만으로 되는 제품은 비상 열쇠나 건전지 단자가 있는지 확인해 두세요.

# 오작동이 반복될 때 의심할 것
- 지문이 안 되다가 갑자기 되는 경우
- 센서 불빛이 깜박이기만 하고 인식이 없는 경우
- 다른 사람 지문이 열리는 경우
- 문 열리는 소리가 약하거나 늦는 경우
이런 증상이 반복되면 부품 점검이 필요합니다. / 다른 사람 지문이 열리는 경우는 보안 문제라 바로 점검 받으시는 게 좋습니다.

# 직접 분해하지 마세요
지문 센서는 얇은 부품이라 분해하다 상하기 쉽습니다. / 안쪽 덮개를 열고 센서 케이블을 만지다 빠지는 일도 있습니다.
센서가 이상하다고 판단되면 그대로 두고 연락 주세요. / 한 번 분해하면 원래대로 조립하기 어려워 수리비가 커질 수 있습니다.

지문 인식은 한 번 실패한다고 바로 고장이라고 단정하기 어렵습니다. / 같은 손가락으로 연달아 시도하면 센서가 더 헷갈릴 수 있으니 한 번 쉬었다가 다시 해 보세요.
센서에 직사광선이 강하게 닿거나 습기가 낀 날에는 인식률이 떨어지기도 합니다. / 날씨가 바뀐 날에만 증상이 심하다면 환경 영향을 의심해 볼 수 있습니다.
증상이 며칠 이어지면 미루지 말고 점검 받으시는 편이 안전합니다.

# 전화하실 때 알려주실 것
연천읍 안에서 어느 쪽인지 알려주시면 도착 시간을 말씀드릴 수 있습니다.
- 연천읍 안 대략 위치와 건물 종류
- 지문이 안 되는 시점과 증상
- 번호키나 열쇠가 되는지 여부
- 도어락 모양과 제조사
- 배터리를 갈아 봤는지
사진을 보내주시면 챙겨 갈 부품을 맞출 수 있습니다.
@ 연천읍 지문 도어락 점검

문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소나 우편물 중 하나면 됩니다.
번거로우시겠지만 안전을 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요.

# 비용은 시작 전에 말씀드립니다
도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 수리가 먼저, 교체는 그다음
센서만 문제인 경우에는 센서를 손보면 됩니다. / 전체를 바꾸지 않아도 되는 경우가 많습니다.
오래된 제품이거나 부품을 구하기 어려우면 그때 [도어락 교체](doorlock-replace.html)를 권합니다. / 어떤 쪽이 나은지 상태를 보고 말씀드립니다.

# 연천읍 말고 연천 어디든 갑니다
전곡읍, 청산면, 백학면, 군남면, 미산면도 다닙니다. / 거리가 먼 곳이 많아 위치를 받으면 도착 시간을 먼저 말씀드립니다.
연천에서 다니는 곳은 [연천군 출장열쇠](yeoncheon.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
현관문 개문 방법은 [현관문 개문](door-open.html) 페이지에도 적어 두었습니다.

연천읍에서는 겨울에 손이 건조해지는 시기에 지문 문의가 늘어나는 편입니다. / 핸드크림을 바른 직후에는 센서 인식이 흐려질 수 있으니 완전히 흡수된 뒤에 대 보세요.
지문이 안 될 때를 대비해 번호와 열쇠 중 한 가지는 늘 쓸 수 있게 챙겨 두는 습관이 도움이 됩니다.
