# 보정동 현관 도어락의 흠집, 그냥 두어도 될까요
보정동은 죽전역과 기흥역 사이 생활권이라 두 방향으로 오가는 분들이 많은 동네입니다. / 매일 쓰는 현관 도어락은 시간이 지나면 열쇠 자국, 가방에 긁힌 흔적, 벗겨진 도장이 생기기 마련입니다.
흠집이 작다면 기능에는 문제없지만 번호판 주변이 벗겨지면 습기가 스며들어 점차 상할 수 있습니다. / 외관 문제인지 성능 문제인지 구분하는 것부터 시작해 보세요.
이 글은 외관 흠집을 어떻게 판단하는지, 도어락을 바꿀 때 남는 타공 자국은 어떻게 정리하는지를 적었습니다. / 교체가 필요한지 고민 중이시라면 [도어락 교체](doorlock-replace.html) 글도 함께 참고하세요.
@ 보정동 도어락 외관 흠집 확인

# 흠집은 세 가지로 나눠서 보세요
외관 흠집이라고 다 같은 문제는 아닙니다.
- 표면만 살짝 긁힌 잔 흠집
- 도장이나 코팅이 벗겨져 속 금속이 드러난 부분
- 충격으로 찌그러지거나 금이 간 손상
첫 번째는 대부분 기능에 영향이 없습니다. / 두 번째는 시간이 지나면서 부식이 번질 수 있고, 세 번째는 내부 부품까지 영향이 갔는지 확인해야 합니다.
손톱이 걸릴 정도로 깊은지 만져 보면 대략 짐작이 됩니다.

# 닦아서 해결되는 흠집인지 먼저 확인
손기름과 먼지가 쌓여 흠집처럼 보이는 경우도 많습니다. / 마른 극세사 천으로 닦은 뒤 부드러운 천에 물을 살짝 묻혀 다시 닦아 보세요.
세정제는 번호판 틈이나 접점으로 스며들지 않게 천에 묻혀서 쓰는 것이 원칙입니다. / 직접 뿌리면 내부로 들어가 고장의 원인이 될 수 있습니다.
거친 연마제나 세척 가루는 도장을 더 상하게 하니 피하세요. / 닦아서 사라지지 않는 흠집은 다음 단계로 넘어갑니다.

# 보수용 도료는 신중하게 쓰세요
작은 터치업 도료로 가린다고 흠집이 사라지는 것은 아닙니다. / 색이 조금만 달라도 오히려 더 눈에 띄는 경우가 많습니다.
번호판이나 센서 주변에 도료가 묻으면 기능에 문제가 생길 수 있습니다. / 센서와 접점이 있는 부분은 가급적 건드리지 않는 것이 좋습니다.
손잡이나 몸체의 넓은 면은 직접 칠하기 어렵고 얼룩이 생기기 쉽습니다. / 외관 개선이 목적이면 부분 보수보다 부품 교체나 전체 교체를 고려하는 편이 낫습니다.

# 외관만 새것으로 바꾸는 방법은 제한적입니다
도어락은 외관 덮개와 내부 기구, 전자부가 한 세트로 설계된 경우가 많습니다. / 덮개만 따로 구하기 어려운 제품도 많습니다.
같은 모델의 외관 부품이 아직 나오는지는 제품마다 다릅니다. / 오래된 모델은 부품 자체가 단종되어 구하기 어렵기도 합니다.
부품 교체가 가능한지는 현장에서 모델명을 확인해야 정확히 말씀드릴 수 있습니다. / 모델명이 적힌 라벨 사진을 보내 주시면 방문 전에 가능성을 가늠해 볼 수 있습니다.
@ 보정동 도어락 모델명 라벨 확인

# 도어락을 바꾸면 남는 타공 자국이란
도어락을 새로 바꿀 때 기존 제품과 같은 규격이면 구멍이 그대로 맞아 깔끔합니다. / 하지만 다른 규격이나 크기로 바꾸면 이전 구멍 흔적이 문에 남기도 합니다.
타공 자국은 문 표면에 뚫린 구멍, 나사 구멍, 이전 제품의 얼룩 등을 말합니다. / 새 제품이 이전 구멍을 완전히 덮지 못할 때 눈에 띕니다.
교체 전에 새 제품이 기존 구멍을 얼마나 덮을지 확인해 두면 자국 걱정을 많이 줄일 수 있습니다.

# 교체 전에 꼭 확인할 세 가지
도어락 교체가 외관 때문이라면 아래 세 가지를 먼저 보세요.
- 현재 문 두께와 도어락이 들어가는 구멍 크기
- 새 제품의 외관 크기가 기존 흔적을 덮는지
- 기존 보조키와 문 모서리의 모양
이 세 가지를 알면 새 제품이 깔끔하게 들어갈지 대략 보입니다. / 정확한 판단은 현장에서 해야 하며, 잘 맞지 않으면 대체 방법을 설명드립니다. 자세한 확인법은 [도어락 설치](doorlock-install.html) 안내에 정리해 두었습니다.

# 자국을 가리는 방법들
가리는 방법은 여러 가지가 있고 문 재질에 따라 적합한 방법이 다릅니다.
- 외관이 더 큰 제품을 골라 기존 흔적을 덮는 방법
- 같은 색의 보수 필름이나 스티커로 가리는 방법
- 구멍이 있는 부분에 마개나 덮개를 끼우는 방법
- 문 전체에 새 시트를 입히는 방법
간단히 가리는 방법이 있고 문 전체를 정리하는 방법도 있으니 원하는 수준을 말씀해 주세요. / 어느 정도 흔적이 남을 수 있다는 점은 미리 알고 선택하시는 것이 좋습니다.

# 철문과 목문은 흔적 처리가 다릅니다
철문은 도장이 벗겨진 곳에 녹이 생길 수 있어 노출된 부분을 막는 처리가 중요합니다. / 목문이나 도장문은 구멍 주변이 갈라지지 않게 마감하는 것이 중요합니다.
문 재질에 따라 어울리는 보수 방법이 다르므로 사진을 보내 주시면 방향을 잡기 쉽습니다. / 문의 겉면과 옆면, 도어락이 붙은 부분을 각각 한 장씩 찍어 주세요.
@ 보정동 현관문 타공 자국 보수 상태

# 외관 흠집 때문에 서둘러 교체할 필요는 없습니다
기능이 정상이고 흠집이 표면에 그치면 교체를 권하지 않습니다. / 고쳐서 쓸 수 있으면 먼저 그렇게 하는 것이 낭비를 줄이는 방법입니다.
다만 번호판이 깨졌거나 금속이 심하게 부식되는 경우, 센서 주변이 손상된 경우에는 교체를 말씀드릴 수 있습니다. / 이럴 때는 이유를 설명드리고 선택은 직접 하시도록 합니다.
도어락의 외관은 기능과 별개로 집의 첫인상이라 신경 쓰이는 것도 당연합니다. / 그런 마음까지 포함해서 상담해 드립니다.

# 전화하실 때 이렇게 알려주세요
외관 상담은 사진이 가장 정확합니다.
- 도어락 앞면과 옆면, 안쪽면 사진
- 모델명이 적힌 라벨이 있다면 그 사진
- 흠집이 생긴 위치와 깊이
- 교체할지 외관만 정리할지 고민 중인지
- 문 재질과 색상
방문 일정은 상황을 듣고 말씀드립니다.

# 방문하면 이렇게 진행합니다
도착하면 먼저 사시는 분인지 신분증 주소, 우편물, 관리사무소 확인 중 하나로 확인합니다. / 이후 도어락 상태와 문 표면을 함께 살펴봅니다.
비용은 작업을 시작하기 전에 먼저 말씀드리며, 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. / 열고 난 뒤 말없이 붙는 비용은 없습니다.
기능에 문제가 있으면 [도어락 수리](doorlock-repair.html)로 먼저 고쳐 쓸 수 있는지 봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 보정동 말고 용인 어디든 갑니다
죽전동, 구갈동, 상현동, 동백동까지 용인 안이라면 24시간 연락 받습니다. / 다니는 지역은 [용인시 출장열쇠](yongin.html) 페이지에 정리해 두었습니다.

교체를 고민 중이라면 타공 자국이 어떻게 남을지 미리 확인하는 것이 중요합니다. / 보정동 도어락 상담은 24시출장열쇠 전화 010-3664-5455로 연락 주시고, 다니는 지역은 [출장 지역](area.html)에서 확인하세요.
