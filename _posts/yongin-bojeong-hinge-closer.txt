# 보정동 현관문이 끝까지 안 닫힌다면
보정동은 죽전역과 기흥역 사이, 보정동 카페거리 주변으로 주택과 아파트가 섞여 있는 동네입니다. / 문이 반쯤 닫히다 마는 증상은 도어락 문제로 오해하기 쉽지만, 경첩이나 도어클로저가 원인인 경우가 많습니다.
이 글은 보정동에서 문이 덜 닫힐 때 직접 점검할 수 있는 부분과 연락해야 하는 시점을 적었습니다. / 문이 한 번에 잠기지 않는 분이라면 3번부터 보셔도 됩니다.
@ 보정동 현관문 덜 닫힘 경첩 도어클로저 점검

# 문이 덜 닫힐 때 생기는 일
문이 완전히 닫히지 않으면 자동으로 잠기는 도어락이 잠기지 않습니다. / 잠긴 줄 알고 나갔다가 문이 열려 있던 경우도 적지 않습니다.
도어락이 고장 난 것처럼 보여도 사실은 문이 정위치에 오지 않아서 생기는 증상입니다. / 그래서 도어락을 바꾸기 전에 문 자체를 먼저 점검해야 합니다.
- 문이 닫히다 중간에 멈추는 경우
- 쿵 소리와 함께 문틀에 걸리는 경우
- 문이 저절로 열리거나 반쯤 닫혀 있는 경우
- 잠금 걸쇠가 문틀 구멍에 맞지 않는 경우

# 경첩이 처졌는지 보는 방법
문을 닫은 상태에서 문틈 간격을 위아래로 살펴보세요. / 위쪽 틈이 아래보다 넓거나 문 모서리가 문틀에 닿아 있으면 경첩이 처진 것입니다.
오래된 문은 무게 때문에 경첩 나사가 헐거워지면서 서서히 처집니다. / 경첩 나사가 헐겁다면 드라이버로 조여 보세요.
나사 구멍이 이미 닳아 있으면 더 조여도 소용이 없습니다. / 이때는 나사 구멍을 보강해야 하니 전문가에게 맡기는 편이 안전합니다.

# 도어클로저가 문제일 때
문 위쪽에 팔처럼 달린 장치가 도어클로저입니다. / 이 장치가 약해지면 문이 천천히 닫히다 마지막에 걸립니다.
클로저 옆면에 속도를 조절하는 나사가 있는 제품이 많습니다. / 조금씩 돌려 가며 확인하되 한 번에 많이 돌리지는 마세요.
기름이 새는 흔적이 있으면 내부가 상한 것이라 조정으로 해결되지 않습니다. / 이럴 때는 교체가 필요할 수 있습니다.
@ 보정동 도어클로저 경첩 문 닫힘 조정

# 걸쇠가 문틀 구멍에 안 맞을 때
문틀에 있는 받이판 구멍과 걸쇠 위치가 어긋나면 문이 닫혀도 잠기지 않습니다. / 문이 처졌거나 문틀이 틀어졌을 때 흔히 생깁니다.
걸쇠 높이를 눈으로 비교해 보면 한두 밀리미터 어긋난 경우가 많습니다. / 받이판 나사를 풀고 위치를 조정하면 해결되는 때도 있습니다.
이 작업은 정확한 위치가 중요해서 무리하게 줄로 갈아 내지는 마세요. / 문틀이 상하면 오히려 더 큰 수리가 필요해집니다.

# 겨울과 여름에 달라지는 문
계절이 바뀌면 문이 팽창하거나 수축해서 닫힘 상태가 달라질 수 있습니다. / 갑자기 문이 뻑뻑해졌다면 이런 이유일 수 있습니다.
장마철 습기로 문과 문틀이 부풀면 걸쇠가 맞지 않기도 합니다. / 날씨가 좋아지면 다시 돌아오는 경우도 있습니다.
- 여름 장마철에 갑자기 뻑뻑해졌다면 습기부터 의심
- 겨울 추위에 문틈이 벌어졌다면 수축 가능성
- 계절과 상관없이 점점 심해지면 경첩과 클로저 점검
- 갑자기 한쪽만 걸린다면 문틀이 틀어졌을 가능성

# 도어락이 문제인지 문이 문제인지 구분하기
문을 열어 놓은 상태에서 도어락 걸쇠만 손으로 눌러 보세요. / 걸쇠가 부드럽게 들어갔다 나오면 도어락은 정상일 가능성이 큽니다.
걸쇠가 뻑뻑하게 움직이거나 중간에 멈추면 도어락 내부 문제입니다. / 이때는 [도어락 수리](doorlock-repair.html)를 상담해 보세요.
문이 닫혀야 잠기는 자동 잠금 도어락이라면 문이 정확히 닫히는지가 첫 번째 확인 사항입니다. / 이 순서를 지키면 불필요한 교체를 피할 수 있습니다.

# 연락 주시면 좋은 때
직접 해볼 만한 점검을 다 했는데 똑같다면 연락 주세요. / 억지로 문을 세게 닫으면 문틀과 도어락 모두 상할 수 있습니다.
특히 문이 열리지 않고 갇힌 상태라면 바로 연락 주세요. / 이때는 경첩이나 걸쇠가 걸려 있을 가능성이 큽니다.
위치와 증상을 알려주시면 필요한 장비를 챙겨 갑니다. / 문 사진을 한두 장 보내주시면 더 정확합니다.

# 연락할 때 알려주면 좋은 정보
보정동은 주택과 상가, 아파트가 섞여 있어서 위치 설명이 중요합니다. / 아래 순서로 알려주시면 도착이 빨라집니다.
- 길 이름 또는 가까운 역(죽전역, 기흥역 쪽 등)
- 건물 형태(아파트, 빌라, 단독주택)
- 문이 어떻게 안 닫히는지
- 도어락 종류
- 집 안에 사람이 있는지

# 사시는 분인지 확인합니다
문과 도어락을 만지는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우실 수 있지만 이웃과 본인을 지키는 절차입니다. / 확인이 어려우면 작업을 할 수 없는 점은 양해 부탁드립니다.

# 비용은 시작 전에 말씀드립니다
문 상태와 필요한 작업을 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 못 열어야 하는 상황이었는데 끝내 못 열면 비용은 받지 않습니다. / 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.
@ 용인 열쇠집 보정동 경첩 도어락 점검 출장

# 수리와 교체는 이렇게 나눕니다
문이 덜 닫히는 증상은 경첩, 클로저, 걸쇠 위치 조정으로 해결되는 경우가 많습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
도어락이 너무 낡았거나 내부 부품이 이미 상했을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 부품을 바꾸기 전에는 따로 여쭤봅니다.
[현관문 개문](door-open.html) 방식도 같은 원칙으로 문과 도어락이 덜 상하는 방법부터 진행합니다.

# 문을 오래 쓰는 관리법
문이 한 번 처지면 계속 더 처집니다. / 처음 증상이 보일 때 손보는 것이 가장 쌉니다.
- 경첩 나사를 반 년에 한 번 조여 보기
- 문에 무거운 것을 매달지 않기
- 도어클로저 속도 조절은 조금씩만
- 문틀과 바닥 사이 이물질 치우기
- 문이 뻑뻑하면 바로 상담

# 보정동 말고 용인 어디든 갑니다
보정동 옆 죽전동, 구성동, 마북동과 기흥구 전역을 다닙니다. / 수지, 처인구도 위치를 알려주시면 도착 시간을 먼저 말씀드립니다.
다니는 동네는 [용인시 출장열쇠](yongin.html)에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
