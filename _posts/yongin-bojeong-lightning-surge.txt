# 보정동 천둥번개 뒤 도어락이 이상하다면
보정동은 죽전역과 기흥역 사이에 걸쳐 있어 두 역을 오가는 분들이 모두 생활권으로 삼는 동네입니다. / 비가 세차게 내리거나 천둥번개가 친 다음 날 아침 도어락이 평소와 다르게 반응하는 일이 있습니다.
번호판이 깜박이거나 한 번에 안 열리고 이상한 소리가 나면 낙뢰나 전기 서지를 의심해 볼 수 있습니다. / 이 글은 그런 날 이후 도어락 상태를 차근히 확인하는 방법을 정리했습니다.
혼자 해결이 안 되면 [용인 출장열쇠](yongin.html)에 연락하는 시점도 같이 적었습니다.
@ 보정동 낙뢰 후 도어락 번호판 점검

# 서지란 무엇이고 도어락에 왜 영향을 줄까
서지는 전기선을 타고 갑자기 들어오는 짧고 강한 전압 변화를 말합니다. / 낙뢰나 대형 전기 설비의 개폐, 정전 후 복구 때 생길 수 있습니다.
건전지로 움직이는 도어락은 바깥 전기와 직접 연결되지 않아 영향이 작다고 알려져 있습니다. / 그렇더라도 전기를 쓰는 인터폰, 현관 센서, 외부 전원을 쓰는 제품은 영향을 받을 수 있습니다.
도어락이 전선으로 건물 전원과 이어진 경우에는 상황이 다릅니다. / 어떤 방식인지 모르겠다면 뚜껑을 열어 배터리가 들어 있는지 먼저 보세요.

# 가장 먼저 번호판과 불빛부터 보세요
천둥번개가 친 뒤 달라진 점은 대개 눈에 보이는 곳에서 먼저 나타납니다. / 번호판을 켜 보고 평소와 같은지 비교해 보세요.
- 번호판이 켜지지 않거나 일부 숫자만 켜지는 경우
- 불빛이 계속 깜박이는 경우
- 번호를 누를 때 소리가 평소와 다르거나 아예 안 나는 경우
- 켜지는 데 오래 걸리는 경우
이런 변화가 한 가지라도 있으면 서지 때문일 가능성을 열어 두고 확인해야 합니다. / 아직 문 안에 계신다면 급히 나가지 말고 이 상태를 먼저 점검해 두세요.

# 모터 소리와 잠김 상태도 같이 들어 보세요
번호를 누르고 모터가 돌 때 소리가 평소와 같은지 들어 봅니다. / 소리가 약해졌거나 중간에 멈추면 내부 회로나 모터가 영향을 받았을 수 있습니다.
문을 닫았을 때 자동 잠금이 되는지도 확인하세요. / 잠기는 소리가 나는데 걸쇠가 덜 나오는 경우도 있습니다.
안에서 손잡이를 돌려 열어 보고 걸림이 없는지도 보세요. / 안쪽에서는 열리는데 밖에서만 안 된다면 번호판 쪽 문제일 수 있습니다.
이상하다고 느낀 순간을 메모해 두면 나중에 설명하기 편합니다.

# 전원부터 가볍게 다시 연결해 보기
천둥번개 뒤에는 일시적인 오류로 먹통이 되는 경우도 있습니다. / 이때는 건전지를 한 번 뺐다가 다시 끼우는 것이 가장 단순한 확인입니다.
- 안쪽 덮개를 열고 건전지를 모두 뺀다
- 몇 십 초 기다렸다가 같은 방향으로 다시 끼운다
- 번호판이 켜지는지, 소리가 정상인지 확인한다
- 설정이 초기화되었다면 다시 등록한다
이렇게 한다고 모든 문제가 풀리는 건 아니지만 간단히 해볼 수 있는 점검입니다. / 건전지 방향이 바뀌지 않게 + − 표시를 꼭 맞춰 주세요.

# 하지 말아야 할 것
번개가 치는 도중에 도어락 덮개를 열거나 전기 부품을 만지지 마세요. / 안전하게 지나간 뒤 천천히 살펴보는 게 맞습니다.
젖은 손이나 젖은 수건으로 번호판을 만지는 것도 피해야 합니다. / 마른 수건으로 물기를 닦고 잠시 두면 돌아오는 경우도 있습니다.
번호판이 안 켜진다고 같은 번호를 계속 반복해서 누르는 것도 좋지 않습니다. / 입력이 여러 번 틀리면 도어락이 한동안 입력을 막습니다.
드라이버로 도어락 본체를 열어 부품을 만지는 것도 권하지 않습니다.
@ 보정동 도어락 건전지 전원 재연결

# 아파트와 빌라, 구조에 따라 다른 점
공동주택은 건물 전체의 전기 설비를 공유해서 서지의 영향 범위가 넓을 수 있습니다. / 이웃 몇 집이 같은 증상을 겪고 있다면 건물 쪽 문제일 수 있습니다.
관리사무소에 천둥번개나 정전이 있었는지 한번 물어보세요. / 이웃의 이야기를 들으면 원인을 좁히는 데 도움이 됩니다.
단독 건물이나 빌라는 외부 전선 상태를 바로 알기 어렵습니다. / 인터폰이나 조명이 평소와 다르면 같이 점검 대상으로 보세요.

# 비 때문에 생긴 문제와 구별하기
번개와 함께 내린 비 때문에 번호판에 습기가 찬 경우도 많습니다. / 서지와 습기는 증상이 비슷해서 구별하기 어렵습니다.
마른 수건으로 번호판 주변을 닦은 뒤 잠시 기다려 보세요. / 습기 문제라면 시간이 지나며 증상이 사라집니다.
건조 후에도 증상이 계속되면 전기적인 원인일 가능성이 더 큽니다. / 비 오는 날 문이 잘 안 열리는 사례는 [도어락 수리](doorlock-repair.html) 페이지에 정리해 두었습니다.

# 이런 때는 전화 주세요
점검했는데도 번호판이 꺼진 채이거나, 소리는 나는데 문이 열리지 않으면 전화 주세요. / 9V 건전지를 대는 비상 단자가 있는 제품이라면 한번 대 보고 연락하셔도 좋습니다.
- 번호판이 전혀 켜지지 않고 비상 전원도 반응 없음
- 모터 소리가 나지만 걸쇠가 움직이지 않음
- 한 번 열린 뒤 다시 잠기지 않음
- 경고음이 멈추지 않음
집 안에 사람이 갇혀 있거나 아이, 반려동물이 있다면 꼭 먼저 말씀해 주세요. / 그런 경우는 순서를 앞당겨 서둘러 갑니다.

# 도착 후 신분 확인과 비용 안내
문을 여는 일이라 해당 집에 사시는 분이 맞는지 먼저 봅니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 이웃과 집 주인 모두를 지키는 절차입니다.

도어락 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없고, 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다. / 현관문 개방은 [현관문 개문](door-open.html) 페이지에서 확인하실 수 있습니다.

# 수리와 교체, 어떻게 결정할까
서지로 회로가 상했다면 부품을 손보거나 본체를 바꿔야 할 수 있습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
- 전원부만 문제인 경우: 전원 모듈 점검으로 끝날 수 있음
- 번호판이 일부만 나오는 경우: 판 교체나 수리 검토
- 여러 번 같은 일이 반복되는 경우: 오래된 제품이면 [도어락 교체](doorlock-replace.html) 논의
교체를 하더라도 미리 문 두께와 보조키 위치를 확인해 두면 준비가 수월합니다. / 새 제품을 고를 때 기준은 [도어락 설치](doorlock-install.html) 페이지에 적어 두었습니다.
@ 보정동 도어락 회로 수리 작업

# 다음 번개를 대비하는 생활 습관
천둥번개가 많은 계절에는 작은 준비가 마음을 편하게 해줍니다. / 큰돈이 드는 일이 아니라 습관의 문제입니다.
- 건전지는 전부 새것으로 교체하고 날짜 적어 두기
- 비상용 9V 건전지를 현관 서랍에 따로 두기
- 번개 친 다음 날에는 외출 전에 번호판 한 번 확인하기
- 열쇠형 보조키가 있다면 어디 있는지 가족과 공유하기
정전이 있었던 날에도 같은 방식으로 확인해 보시면 됩니다. / 문을 닫고 나가기 전에 한 번 열어 보는 습관이 가장 간단합니다.

# 보정동 말고 용인 어디든 갑니다
보정동 인근과 용인 안이면 동네 상관없이 24시간 출동합니다. / 다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에, 서울과 경기 다른 지역은 [출장 지역](area.html) 지도에 있습니다.
