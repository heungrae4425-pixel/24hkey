# 봄이 되면 번호판이 말을 안 듣는 이유
보정동은 죽전역과 기흥역 사이 생활권이라 출퇴근하며 현관문을 하루에도 여러 번 여닫는 분이 많습니다. / 봄이 되면 창문을 자주 열고 바깥 먼지가 집 안팎으로 들어오면서 도어락에도 영향을 줍니다.
황사와 미세먼지, 꽃가루가 번호판 틈에 쌓이면 버튼이 뻑뻑해지거나 눌러도 반응이 한 박자 늦어집니다. / 그러다 어느 아침에 번호가 안 먹힌다며 당황하게 되는 일이 생깁니다.
이 글은 보정동 가정에서 봄철 번호판이 둔해졌을 때 어떻게 닦고 점검하면 되는지 정리했습니다. / 고장일 때와 먼지 문제일 때를 구분하는 방법도 담았습니다.
@ 보정동 봄철 도어락 번호판 먼지 점검

# 먼지가 번호판에 미치는 영향
번호판은 손가락이 닿는 면이 얇은 만큼 이물질에 민감합니다. / 미세한 가루가 버튼 가장자리에 끼면 누른 느낌이 둔해지거나 두 번 눌러야 입력되는 경우가 생깁니다.
터치식 번호판은 먼지와 습기가 섞이면 표면이 끈적해져 인식이 불안해지기도 합니다. / 버튼식 번호판은 틈 사이에 쌓인 가루가 버튼을 덜 눌리게 만듭니다.
터치식은 손가락이 닿는 면이 넓어서 먼지가 얇게 덮여도 인식이 흔들립니다. / 장갑을 낀 손이나 로션이 묻은 손으로 누르면 같은 증상이 더 심해지기도 합니다.
이런 증상은 고장이 아니라 청소로 돌아오는 경우가 많습니다. / 먼저 닦아 보고 나서 부품 문제인지 판단해도 늦지 않습니다.

# 닦기 전에 알아 둘 주의점
번호판을 닦을 때 물을 직접 뿌리는 것은 피해 주세요. / 도어락 안으로 물이 스며들면 회로가 상할 수 있습니다.
알코올이나 세정제도 바로 대면 표면 코팅이 벗겨지는 제품이 있습니다. / 마른 부드러운 천을 기본으로 하고 때가 심하면 천에 물을 살짝 적셔 짜서 쓰세요.
날카로운 도구로 버튼 틈을 긁는 것도 하지 마세요. / 면봉이나 부드러운 솔 정도가 알맞습니다.

# 순서대로 닦는 방법
- 먼저 마른 천으로 번호판 겉면의 가루를 털어 냅니다
- 부드러운 솔이나 면봉으로 버튼 가장자리 틈을 쓸어 냅니다
- 천을 물에 적셔 꼭 짠 뒤 가볍게 한 번 닦습니다
- 마른 천으로 물기를 다시 닦고 잠시 말립니다
- 번호를 눌러 소리와 반응을 확인합니다
물기를 닦은 뒤 바로 눌러 보기보다 잠깐 기다렸다 확인하는 것이 좋습니다. / 습기가 남아 있으면 일시적으로 오작동할 수 있습니다.
@ 보정동 도어락 번호판 마른 천으로 닦기

# 꽃가루가 많은 날에는
꽃가루는 끈적한 성분이 있어 마른 천으로만 닦으면 잘 떨어지지 않을 때가 있습니다. / 이럴 때는 천을 살짝 적셔 닦고 곧바로 마른 천으로 마무리하세요.
출입이 잦은 문일수록 날마다 가볍게 닦는 습관이 도움이 됩니다. / 외출하고 돌아와 신발을 벗을 때 번호판을 한 번 훑는 정도면 충분합니다.
문 위쪽이나 번호판 위에 쌓인 먼지가 비에 씻기면서 흘러내려 얼룩을 만들기도 합니다. / 비 온 날 뒤에는 한 번 확인해 보세요.

출입문 바로 옆에 신발장이나 화분이 있는 집은 먼지가 더 잘 쌓입니다. / 베란다 창을 열어 두는 날이 많다면 바람이 현관 쪽으로 들어와 번호판에 가루를 실어 오기도 합니다.
도어락 겉면만 닦지 말고 문틈 쪽 걸쇠 주변도 가볍게 쓸어 두면 좋습니다. / 걸쇠 틈에 쌓인 가루가 뭉치면 문이 덜 닫히는 원인이 되기도 합니다.

# 닦아도 반응이 없을 때
청소했는데도 번호판이 반응하지 않으면 다른 원인을 의심해야 합니다.
- 소리도 불빛도 없다면 배터리가 다 됐을 가능성이 큽니다
- 불빛은 들어오는데 소리가 없다면 번호판 안쪽 접촉 문제일 수 있습니다
- 소리는 나는데 문이 안 열리면 잠금 장치나 걸쇠 쪽을 봐야 합니다
- 특정 숫자만 안 눌리면 해당 버튼 아래 부품이 약해진 것입니다
번호판이 꺼져 있다면 바깥쪽 비상 단자에 9V 건전지를 대 보세요. / 죽전역이나 기흥역 주변 편의점에서 쉽게 구할 수 있습니다.

# 문 앞에서 서둘러 하면 안 되는 일
번호가 안 눌린다고 버튼을 세게 연타하면 오히려 내부가 상할 수 있습니다. / 손톱이나 뾰족한 물건으로 누르는 것도 피해 주세요.
틀린 번호를 여러 번 넣으면 도어락이 입력을 막아 더 오래 기다리게 됩니다. / 서너 번 해보고 안 되면 멈추는 것이 좋습니다.
문을 발로 차거나 어깨로 미는 것은 문틀과 도어락 모두 상하게 합니다. / 그대로 두고 전화 주시면 문을 상하게 하지 않고 여는 방법으로 진행합니다.

# 전화 주실 때 알려주실 것
보정동에서 연락 주실 때는 아래 내용을 알려주시면 도착이 빨라집니다.
- 동과 호수, 죽전역 쪽인지 기흥역 쪽인지
- 번호판 종류 (터치식, 버튼식)
- 닦아 보셨는지, 어떤 반응이 있는지
- 비상 단자에 건전지를 대 보셨는지
도어락 사진을 문자로 보내 주시면 필요한 장비를 챙겨 가기 좋습니다.

# 사는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로워 보여도 이웃과 가족 모두를 위한 절차입니다. / 확인이 어렵다면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 열기 전에 먼저 말씀드립니다
도어락과 문 상태를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 마음에 들지 않으면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에서 볼 수 있고, 문 여는 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다.

# 열고 난 뒤의 점검과 수리
문이 열리면 번호판을 정리하고 버튼 반응을 하나씩 눌러 확인합니다. / 먼지가 원인이었다면 닦은 뒤에 반응이 돌아오는지 같이 봅니다.
반응이 계속 둔하면 [도어락 수리](doorlock-repair.html)로 번호판 부품부터 손봅니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않고, 너무 오래된 제품일 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 보정동 도어락 번호판 반응 확인 후 마무리

# 봄철에 해두면 좋은 관리 습관
- 일주일에 한 번 마른 천으로 번호판 닦기
- 꽃가루 많은 날에는 외출 후 바로 한 번 닦기
- 창문을 열어 둔 날은 현관 신발장 먼지도 함께 털기
- 배터리는 해가 바뀔 때 전부 한꺼번에 교체하기
- 경고음이 나면 그날 바로 교체하기
이렇게 하면 먼지 때문에 번호판이 둔해지는 일을 많이 줄일 수 있습니다.

# 보정동 말고 용인 어디든
보정동 옆 마북동, 구갈동, 죽전동, 동백동도 다닙니다. / 용인 안이면 어느 동네든 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html)에 모아 두었습니다. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
