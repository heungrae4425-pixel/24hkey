# 동백동 도어락 경고음, 멈추지 않으면 이렇게 보세요
동백동은 동백역 주변으로 단지와 상가, 빌라가 이어진 동네라 늦은 시간에도 귀가하는 사람이 많습니다. / 현관문 앞에서 삑삑 소리가 멈추지 않으면 이웃 눈치도 보이고 마음이 급해집니다.
도어락이 울리는 데에는 대개 이유가 있습니다. / 이유를 모르고 번호만 계속 누르면 소리가 더 길어지는 경우도 있습니다.
이 글은 동백동에서 경고음이 계속 울릴 때 원인을 좁히는 순서를 정리한 것입니다. / 해결이 안 될 때 [용인 출장열쇠](yongin.html)를 부르는 방법도 적었습니다.
@ 동백동 도어락 경고음 확인

# 소리 종류부터 구별해 보세요
경고음이라고 다 같은 뜻이 아닙니다. / 어떤 소리가 나는지 듣는 것이 첫 단계입니다.
소리가 나는 위치가 바깥 번호판인지 안쪽 본체인지도 구별해 보세요. / 안쪽에서 나는 소리라면 문 닫힘 감지나 잠금 장치 쪽일 가능성이 있습니다.
- 짧게 한두 번 삑 하고 마는 소리: 배터리 부족 안내인 경우가 많음
- 일정한 간격으로 계속 울리는 소리: 잠금 이상이나 입력 제한 상태일 수 있음
- 모터가 윙 하다가 멈추는 소리: 걸쇠나 잠금 장치가 걸린 상태일 수 있음
- 문을 닫았는데도 울리는 소리: 문 닫힘 감지가 안 되는 경우
제품마다 소리가 다르니 설명서나 도어락 안쪽 스티커의 안내를 참고하면 정확합니다.
설명서가 없다면 제품 이름이 적힌 스티커를 사진으로 찍어 두세요. / 전화로 설명하실 때 큰 도움이 됩니다. / 모델명을 알면 같은 증상의 경우 어떤 부품이 문제인지 미리 짐작해 볼 수 있습니다.

# 배터리 부족 때문에 울리는 경우
가장 흔한 원인은 배터리 부족입니다. / 번호판은 켜지는데 누를 때마다 길게 울리거나 음성으로 안내가 나온다면 먼저 의심해 보세요.
배터리는 한두 개가 아니라 전부 새것으로 바꿔야 오래갑니다. / 새 배터리를 넣었는데도 울리면 다른 원인이 있다는 뜻입니다.
배터리를 바꿀 때는 극성(+, -)을 확인해 주세요. / 거꾸로 끼우면 반응이 아예 없거나 계속 소리만 날 수 있습니다.

# 입력이 막혀서 울리는 경우
번호를 여러 번 틀리면 도어락이 입력을 한동안 막아 버립니다. / 이때 번호를 누르면 계속 경고음이 나고 열리지 않습니다.
이 상태에서 계속 누르면 막힌 시간이 늘어날 수 있습니다. / 손을 떼고 잠시 기다린 뒤 정확한 번호를 천천히 한 번만 눌러 보세요.
번호가 가물가물하다면 가족에게 먼저 확인하는 것이 낫습니다. / 같이 사는 가족이 번호를 바꿨는지도 확인해 보세요.

# 문이 덜 닫혀서 울리는 경우
문이 끝까지 닫히지 않으면 도어락이 이상 상태로 판단해 계속 울릴 수 있습니다. / 문틀이 처졌거나 경첩이 헐거워진 집에서 자주 생깁니다.
문을 안쪽으로 가볍게 당기며 닫아 보고 걸쇠가 문틀 구멍에 맞는지 확인하세요. / 걸쇠가 문틀에 긁힌 자국이 있다면 맞물림이 틀어진 것입니다.
이런 경우는 [경첩과 문틀 점검](doorlock-repair.html)을 같이 보는 편이 재발이 적습니다. / 도어락만 바꿔서는 해결되지 않습니다.
@ 동백동 현관문 도어락 문틀 맞물림

# 소리를 멈추려고 건전지를 빼도 될까
급한 마음에 배터리를 빼서 소리를 끄려는 분들이 있습니다. / 잠시 조용해지지만 문제는 그대로 남아 있습니다.
오히려 문이 잠긴 상태에서 전원이 끊기면 다시 들어갈 때 번호판이 켜지지 않아 곤란해질 수 있습니다. / 집 안에 계실 때만 시도하고, 문 밖이라면 빼지 않는 것이 좋습니다.
소리를 끄는 것보다 원인을 확인하는 것이 먼저입니다.
배터리 덮개를 열었다면 원래 자리에 정확히 닫아 두세요. / 덮개가 덜 닫히면 접촉이 불안정해져 소리가 다시 나는 일도 있습니다.

# 하지 말아야 할 것
소리가 계속 나면 도어락을 두드리거나 분해하고 싶어집니다. / 하지만 몇 가지는 피해 주세요.
- 번호판을 세게 누르거나 때리는 것
- 드라이버로 외관을 뜯어 보는 것
- 물을 뿌려 닦는 것 (습기가 들어가 더 고장 납니다)
- 같은 번호를 쉬지 않고 계속 누르는 것
외관이 상하면 고칠 수 있었던 것도 교체해야 할 수 있습니다. / 의심되는 부분이 있으면 손대지 말고 사진만 찍어 두세요.

# 전화 주실 때 알려주면 빠른 정보
소리가 어떤 식으로 나는지 말로 설명하거나 짧은 동영상을 찍어 보내 주시면 도움이 됩니다. / 원인을 대략 짐작할 수 있어 필요한 부품을 챙겨 갈 수 있습니다.
- 동백역 쪽인지 다른 방향인지 대략적인 위치
- 몇 동 몇 호인지
- 소리 패턴 (짧게, 길게, 반복)
- 번호판이 켜지는지
- 최근 배터리를 바꿨는지
도어락 사진도 같이 보내 주시면 제품을 확인하기 좋습니다.
소리가 언제부터 났는지도 말씀해 주세요. / 문을 닫은 직후부터인지, 배터리를 만진 뒤부터인지에 따라 원인이 크게 갈립니다.
집 안에 사람이 있는지도 알려주세요. / 안에서 도와줄 수 있으면 안쪽 손잡이와 보조키 상태를 전화로 같이 확인할 수 있습니다.

# 한밤에 울려서 이웃이 신경 쓰일 때
새벽에 경고음이 길게 울리면 이웃에게도 불편을 줍니다. / 우선 문 앞에서 소리가 작아지도록 번호판을 손으로 덮어 보는 정도만 해 보세요.
소리가 계속되면 이웃에게 양해를 구하는 쪽지를 붙이고 연락 주세요. / 24시간 전화를 받으니 시간은 신경 쓰지 않으셔도 됩니다.
[열쇠 출장](key-call.html)으로 요청하시면 도착 전에 할 수 있는 일을 전화로 안내해 드립니다.

# 도착하면 신분 확인부터 합니다
문을 여는 일이 포함되면 사시는 분이 맞는지 먼저 확인합니다. / 신분증의 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로울 수 있지만 이웃과 집 모두를 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 문 열기 전에 먼저 말씀드립니다
소리의 원인과 도어락 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다.

# 고쳐서 쓸지 바꿀지는 상태를 보고
같은 소리가 자주 반복되면 내부 부품이 오래된 신호일 수 있습니다. / 먼저 수리로 해결되는지 보고, 그래도 어려울 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 동백동 도어락 수리와 교체 점검

# 동백동 말고도 용인 어디든 갑니다
동백동 바로 옆 영덕동, 마북동, 보정동, 구갈동도 다닙니다. / 용인 안이라면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
