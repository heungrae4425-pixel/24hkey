# 동백동에서 도어락 앱이 갑자기 먹통이 됐다면
동백동처럼 입주한 지 오래되지 않은 동네는 휴대폰과 연동되는 도어락을 쓰는 집이 꽤 많습니다. / 그래서 어느 날 아침 앱에 오류 표시가 뜨거나 알림이 한 번도 안 오면 당황하게 됩니다.
출근길 동백역으로 걸어가다 "문이 제대로 잠겼나" 하고 앱을 열었는데 연결 실패라고 나오면 더 마음이 불편해집니다. / 이 글은 앱과 알림이 안 될 때 집에서 먼저 확인할 것을 순서대로 적었습니다.
확인해도 해결이 안 되거나 문 자체가 안 열리면 [용인 출장열쇠](yongin.html)로 연락하시면 됩니다. / 지금 문 앞이라면 3번과 9번을 먼저 보셔도 됩니다.
@ 동백동 도어락 앱 연동 알림 출장열쇠

# 앱과 알림은 이렇게 움직입니다
스마트폰과 연동되는 도어락은 보통 두 가지 방식 중 하나로 연결됩니다. / 휴대폰과 도어락이 블루투스로 직접 이야기하거나, 도어락 옆의 작은 중계기가 와이파이를 통해 앱으로 소식을 전해 줍니다.
알림이 오는 도어락은 대부분 중계기가 있는 방식입니다. / 중계기, 공유기, 인터넷 중 하나만 멈춰도 앱에는 "연결 안 됨"이 뜹니다.
중요한 점은 앱이 안 돼도 도어락 본체는 별개로 작동한다는 것입니다. / 번호, 카드, 열쇠로 열리는 기능은 통신과 상관없이 따로 돌아갑니다.

# 가장 먼저 도어락 본체가 열리는지 확인하세요
앱이 안 될 때 제일 먼저 할 일은 번호판을 눌러 보는 것입니다. / 번호를 누르면 삑 소리가 나고 문이 열린다면 본체는 멀쩡하다는 뜻입니다.
이 경우는 급한 상황이 아니라서 천천히 원인을 찾아도 됩니다. / 문이 열리지 않는다면 그때는 통신 문제가 아니라 본체나 배터리 문제로 봐야 합니다.
번호판이 아예 꺼져 있다면 [도어락 수리](doorlock-repair.html) 쪽 상황일 수 있으니 9번 항목을 봐 주세요.

# 휴대폰 쪽에서 흔한 원인
앱이 오래된 버전이면 도어락과 맞지 않아 연결이 끊기는 경우가 있습니다. / 앱 스토어에서 업데이트가 있는지 먼저 보시면 좋습니다.
휴대폰의 블루투스를 껐거나 앱의 근처 기기 권한이 꺼져 있어도 연결이 안 됩니다. / 설정에서 블루투스와 해당 앱의 권한이 켜져 있는지 확인해 주세요.
절전 모드나 배터리 최적화가 앱을 백그라운드에서 꺼 버리면 알림이 안 오기도 합니다. / 이 앱만 절전에서 제외하면 알림이 다시 오는 경우가 많습니다.
휴대폰을 새로 바꾼 뒤부터 안 된다면 새 휴대폰에서 도어락을 다시 등록해야 하는 경우도 있습니다.

# 공유기와 와이파이가 원인일 때
중계기를 쓰는 도어락은 집 공유기가 멈추면 같이 멈춥니다. / 공유기 전원을 뽑았다가 1분쯤 기다린 뒤 다시 꽂아 보는 것이 가장 쉬운 방법입니다.
공유기 이름이나 비밀번호를 바꿨다면 중계기도 새 정보로 다시 연결해야 합니다. / 인터넷 회사를 바꾸거나 공유기를 교체한 직후에 앱이 끊기는 일이 이 때문에 많이 생깁니다.
중계기가 와이파이 신호가 약한 곳에 있으면 연결이 오락가락합니다. / 문 가까이에 둔 중계기가 현관 안쪽 벽 때문에 신호를 못 받는 경우가 있습니다.

# 도어락 배터리가 약하면 통신부터 끊깁니다
통신 기능은 전기를 꽤 씁니다. / 그래서 배터리가 줄어들면 문은 열리는데 앱 연결과 알림만 먼저 끊기는 현상이 생깁니다.
앱에 배터리 잔량이 나온다면 확인해 보시고, 낮다면 새 건전지 네 알을 한꺼번에 갈아 주세요. / 일부만 바꾸면 며칠 못 가서 같은 일이 반복됩니다.
교체한 뒤에는 앱에서 연결이 자동으로 돌아오는 경우도 있고, 다시 짝을 맞춰야 하는 경우도 있습니다.
@ 동백동 스마트 도어락 배터리 교체 점검

# 앱에서 삭제하고 다시 등록하기 전에
연결이 안 된다고 앱에서 도어락을 지우고 새로 등록하려는 분이 많습니다. / 이 방법은 마지막에 쓰는 게 좋습니다.
삭제하면 등록해 둔 사용자와 임시 비밀번호가 같이 사라지는 제품이 있기 때문입니다. / 가족 번호를 따로 적어 두지 않았다면 다시 만들어야 할 수 있습니다.
먼저 앱을 완전히 종료했다가 다시 켜 보고, 휴대폰을 껐다 켜 보세요. / 그래도 안 되면 그때 제조사 안내 순서대로 다시 등록해도 늦지 않습니다.

# 번호나 카드로는 열리는데 앱만 안 될 때
이 경우는 집 안 사정으로는 불편하지만 급하지는 않습니다. / 앱 알림이 중요한 분들은 위 순서대로 하나씩 확인해 보시면 됩니다.
혼자 해결하기 어렵다면 점검 날짜를 잡고 불러 주셔도 됩니다. / 이때는 문을 여는 일이 아니라 도어락 상태를 보는 점검이라서 급하게 서두르지 않으셔도 됩니다.
통신 부분은 제품마다 다르니 어떤 제품인지 사진으로 보내 주시면 설명하기가 쉽습니다.

# 본체가 안 열린다면 이야기가 달라집니다
번호판이 꺼져 있거나 번호를 눌러도 반응이 없다면 통신이 아니라 본체 쪽 문제입니다. / 비상 전원 단자에 9V 건전지를 대 보는 방법이 먼저입니다.
그래도 안 열리면 억지로 힘을 주지 마시고 연락 주세요. / 손잡이를 세게 당기거나 문틈에 도구를 끼우면 문틀과 도어락이 상합니다.
이런 상황의 개방 방법은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다. / 못 열면 비용은 받지 않습니다.

# 동백역 쪽 퇴근길에 문이 안 열릴 때
동백역에서 내려 집까지 걸어오는 동안 앱으로 문을 열려고 했다가 안 열리는 일이 있습니다. / 이때는 앱을 포기하고 번호나 카드로 먼저 열어 보세요.
번호를 잊었거나 카드가 없는데 앱이 유일한 방법이었다면 그때는 연락 주시면 됩니다. / 위치와 도어락 모양을 알려주시면 도착 시간을 말씀드립니다.

# 출장 요청 전에 이것만 알려주세요
용인은 넓어서 위치를 정확히 알려주시면 도착이 빨라집니다. / 동과 호수, 가까운 역이나 큰 길 이름을 같이 말씀해 주세요.
- 도어락 앞면 사진이나 제품 이름
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 앱이 안 되는지, 본체도 안 되는지
- 집 안에 아이나 반려동물이 있는지
- 건전지 교체 여부
사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다.

# 도착하면 신분 확인부터 합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 이웃과 집을 위한 절차이니 미리 챙겨 두시면 좋습니다. / 확인이 어려우면 작업을 할 수 없습니다.
@ 동백동 출장열쇠 신분 확인 후 개문

# 비용은 시작하기 전에 말씀드립니다
상태를 보고 얼마인지 먼저 말씀드린 뒤 괜찮다고 하시면 시작합니다. / 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하는 상황이면 바꾸기 전에 여쭤봅니다.
고쳐서 쓸 수 있는 도어락은 교체를 권하지 않습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 연동 기능을 오래 안정적으로 쓰는 법
앱 업데이트 알림이 오면 가능한 한 빨리 해 두세요. / 오래 미루면 도어락과 앱 버전이 어긋나 연결이 끊기기 쉽습니다.
건전지는 해가 바뀔 때쯤 한 번에 교체하는 습관을 들이면 통신 오류도 줄어듭니다. / 교체한 날짜를 배터리 칸에 적어 두면 잊지 않습니다.
공유기를 바꾸거나 인터넷을 옮길 때는 도어락 중계기부터 챙겨 주세요. / 가족 번호는 앱에만 의존하지 말고 따로 적어 두는 것이 안전합니다.
앱이 안 될 때를 대비해 카드키나 열쇠 하나를 따로 보관하면 마음이 편합니다.
