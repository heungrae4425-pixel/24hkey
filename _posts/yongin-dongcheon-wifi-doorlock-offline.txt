# 동천동 와이파이 도어락이 오프라인이라고 뜰 때
동천동은 수지구청역 생활권으로 이어지는 주거지라 스마트 도어락을 쓰는 집이 늘고 있습니다. / 앱으로 문 상태를 확인하고 임시 번호를 보내는 기능이 편하지만, 어느 날 오프라인이라고 뜨면 당황스럽습니다.
오프라인이라고 해서 문이 못 열리는 것은 아닌 경우가 많습니다. / 도어락 본체의 번호나 카드는 정상인데 앱과의 통신만 끊긴 상황이 흔하기 때문입니다.
이 글은 오프라인이 뜰 때 원인을 가르는 순서를 정리했습니다. / 직접 해결이 안 될 때 [용인 출장열쇠](yongin.html)가 어떻게 점검하는지도 적었습니다.
@ 동천동 와이파이 도어락 앱 오프라인 표시

# 먼저 문 자체가 열리는지부터 확인하세요
앱이 안 된다고 문까지 안 열리는 것은 아닙니다. / 번호판이나 카드, 지문으로 정상적으로 열리는지 먼저 확인하세요.
본체가 정상이라면 급한 상황은 아닙니다. / 앱 연결 문제는 차분히 순서대로 풀어도 늦지 않습니다.
반대로 번호판도 반응이 없다면 오프라인이 아니라 배터리 방전이 원인일 수 있습니다. / 이 경우는 통신 설정보다 전원이 먼저입니다.

# 오프라인이 뜨는 대표 원인 다섯 가지
도어락은 직접 와이파이에 붙는 제품과 별도의 연결 장치를 통하는 제품으로 나뉩니다. / 어느 구조든 원인은 비슷한 몇 가지로 좁혀집니다.
- 배터리 잔량이 부족해 통신 모듈이 꺼진 경우
- 공유기를 바꾸거나 재설정해 연결 정보가 달라진 경우
- 공유기와 도어락 사이 거리나 벽 때문에 신호가 약한 경우
- 앱 업데이트 후 로그인이 풀리거나 권한이 바뀐 경우
- 연결 장치(허브, 브리지)의 전원이 빠졌거나 멈춘 경우
이 다섯 가지 중에서 최근에 우리 집에 달라진 것이 무엇인지 떠올려 보면 원인이 빨리 보입니다.

# 공유기가 바뀌었는지 가장 먼저 떠올려 보세요
통신사를 바꾸거나 공유기를 새로 설치하면 와이파이 이름과 비밀번호가 달라집니다. / 도어락은 이전 연결 정보를 그대로 기억하고 있어서 연결이 끊어집니다.
이 경우에는 도어락 쪽에서 새 와이파이를 다시 등록해야 합니다. / 제품마다 등록 방법이 달라 설명서를 보며 순서대로 하는 것이 좋습니다.
와이파이가 두 가지 주파수 대역으로 나뉘어 있으면 일부 도어락은 한쪽만 인식합니다. / 어느 쪽에 연결하는지 확인해 보세요.
@ 동천동 공유기와 도어락 연결 거리 확인

# 신호가 약한 현관은 거리와 벽이 원인입니다
현관은 집 안쪽 공유기에서 가장 먼 곳이 되기 쉽습니다. / 철문과 두꺼운 벽 두 가지가 겹치면 신호가 크게 줄어듭니다.
스마트폰을 현관 안쪽에 들고 가서 와이파이 신호가 어느 정도인지 확인해 보세요. / 신호가 한두 칸이거나 끊긴다면 그것이 원인일 가능성이 큽니다.
공유기를 현관 쪽으로 옮기거나 중계기를 달면 해결되는 경우가 있습니다. / 도어락 자체를 만지기 전에 이 환경을 먼저 개선해 보는 것이 순서입니다.

# 배터리가 줄면 통신부터 멈춥니다
많은 스마트 도어락은 배터리가 부족해지면 문 열고 닫는 기능은 유지하면서 통신 기능을 먼저 줄입니다. / 그래서 오프라인이 뜨는 것이 배터리 교체 신호인 경우가 있습니다.
배터리를 한꺼번에 새것으로 갈고 몇 분 뒤 앱을 다시 확인해 보세요. / 연결이 돌아오는 데 시간이 걸리는 제품도 있으니 잠시 기다려 보세요.
새 배터리를 넣고도 계속 오프라인이라면 배터리 때문이 아닐 가능성이 높습니다. / 그때는 다음 단계인 앱과 계정 설정을 확인해 보세요.

# 앱과 계정을 점검하는 순서
앱이 최신 버전인지 확인하고, 앱을 완전히 종료한 뒤 다시 열어 보세요. / 단순 오류는 이것만으로 풀리기도 합니다.
로그인이 풀렸거나 다른 기기에서 접속했다면 연결이 끊긴 것으로 보일 수 있습니다. / 가족이 같은 계정을 나눠 쓰는 경우 한 사람이 기기를 바꾸면서 영향을 줄 수도 있습니다.
휴대폰의 절전 모드와 백그라운드 제한 설정도 확인하세요. / 알림이 안 오는 원인이 도어락이 아니라 휴대폰 설정인 경우도 흔합니다.

# 하지 말아야 할 것들
초기화 버튼을 눌러 모든 설정을 지우는 것은 마지막 수단입니다. / 등록된 번호, 카드, 지문이 모두 사라질 수 있습니다.
- 원인 파악 전에 공장 초기화부터 하지 않기
- 문을 닫아 둔 채로 설정을 시험하지 않기
- 본체를 열어 기판을 만지지 않기
- 비밀번호를 여러 번 틀려 입력 잠금이 걸리지 않게 하기
문을 열어 둔 상태에서 설정을 시험해야 혹시 잠겨도 곤란하지 않습니다. / 초기화가 꼭 필요하면 기존 등록 정보를 메모해 두고 진행하세요.
@ 동천동 스마트 도어락 설정 점검하는 모습

# 임시 번호나 알림이 안 올 때 생기는 문제
오프라인 상태에서는 앱으로 임시 번호를 만들어도 도어락에 전달되지 않을 수 있습니다. / 손님이나 가사 도우미에게 번호를 줬는데 안 열리는 상황이 생길 수 있습니다.
이런 일을 막으려면 중요한 약속이 있는 날 전에 연결 상태를 한 번 확인해 두세요. / 필요하면 임시 번호를 본체에서 직접 등록하는 방법도 알아 두면 좋습니다.
알림 기능에 의존해 아이가 귀가했는지 확인하는 집이라면 더 신경 쓰세요. / 알림이 없다고 아이가 못 들어온 것은 아니니 먼저 전화로 확인하세요.

# 출장열쇠에 연락할 때 알려주시면 좋은 내용
통신 문제인지 본체 문제인지 구분할 정보가 있으면 방문이 빨라집니다. / 아래 항목을 알려 주세요.
- 도어락 상표와 모델이 보이면 그 정보
- 앱에서 뜨는 문구(오프라인, 연결 실패 등)
- 최근 공유기를 바꾸거나 이사한 일이 있는지
- 번호판과 카드는 정상으로 열리는지
앱 화면과 도어락 사진을 같이 보내 주시면 확인에 도움이 됩니다. / 문을 어떻게 여는지는 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 도착하면 이렇게 확인합니다
사시는 분인지 신분증 주소, 우편물, 관리사무소 확인 중 하나로 먼저 확인합니다. / 이후 본체의 전원과 배터리, 통신 모듈 상태를 차례로 봅니다.
공유기와의 거리나 신호 문제로 보이면 설치 환경을 어떻게 바꿀지 설명드립니다. / 본체 문제라면 고쳐서 쓸 수 있는지 먼저 확인하고, 필요할 때만 교체를 말씀드립니다.
비용은 작업을 시작하기 전에 먼저 말씀드리며, 못 열거나 못 고치면 비용은 받지 않습니다. / 도어락 종류별 점검은 [도어락 수리](doorlock-repair.html), 스마트 도어락으로 바꾸는 방법은 [도어락 교체](doorlock-replace.html) 페이지에 적어 두었습니다.

# 오프라인을 미리 막는 평소 습관
배터리는 해가 바뀔 때쯤 한꺼번에 교체하고 날짜를 적어 두세요. / 공유기를 바꿀 계획이 있으면 도어락 재연결 순서를 미리 확인하세요.
도어락 앱의 알림을 켜 두고 낮은 배터리 알림이 오면 미루지 마세요. / 앱에 의존하지 않고 번호나 카드로도 열 수 있도록 평소에 기본 열기 방법을 익혀 두세요.
