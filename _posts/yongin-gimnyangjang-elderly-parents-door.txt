# 김량장동 부모님 댁 현관문, 한 번쯤 살펴보셨나요
김량장동은 오래 사신 분들이 많은 동네로, 시장과 골목을 따라 주택과 작은 건물이 이어져 있습니다. / 부모님이 혼자 지내시는 집이라면 도어락이 잘 작동하는지 자녀 입장에서 늘 마음에 걸립니다.
평소엔 잘 열리다가도 어느 날 갑자기 번호판이 꺼지거나 손잡이가 헛도는 일이 생깁니다. / 그때 부모님이 혼자 계시다면 당황하셔서 더 큰일이 되기도 합니다.
이 글은 부모님 댁 도어락을 미리 점검하는 방법, 어르신이 쓰기 편한 설정, 문이 안 열릴 때의 대처를 정리했습니다. / 도움이 필요하면 [용인 출장열쇠](yongin.html)가 어떻게 진행되는지도 같이 적었습니다.
@ 김량장동 부모님 집 도어락 점검 출장

# 어르신이 도어락에서 자주 겪는 어려움
어르신들은 새 기기에 적응하는 데 시간이 걸리기도 합니다. / 번호판의 작은 숫자가 잘 안 보이거나, 버튼을 누르는 힘이 약해 인식이 안 되는 일도 있습니다.
번호를 여러 번 틀려서 입력이 막혔는데 방법을 몰라 당황하시기도 합니다. / 경고음이 울려도 무슨 뜻인지 몰라 그냥 두는 경우도 많습니다.
이런 어려움은 설정을 조금만 바꿔도 크게 줄일 수 있습니다. / 어르신에게 맞춰 단순하게 정리해 두는 것이 좋습니다.

# 자녀가 먼저 확인해 볼 점검 목록
부모님 댁에 갈 때 5분만 시간을 내서 아래를 확인해 보세요.
- 번호판이 선명하게 켜지는지, 버튼이 잘 눌리는지
- 배터리 경고음이 울린 적이 있는지
- 손잡이가 헐겁거나 문이 덜 닫히지 않는지
- 부모님이 현재 번호를 확실히 기억하고 계신지
- 비상 연락처와 여분 열쇠를 누가 갖고 있는지
하나라도 마음에 걸리는 부분이 있다면 지금 손봐 두는 것이 낫습니다. / 갑자기 문이 안 열리는 날이 오기 전에 미리 대비하는 편이 훨씬 편합니다.

# 번호는 단순하게, 하지만 너무 쉽지 않게
어르신이 외우기 쉬운 번호를 쓰면 안심되지만, 너무 단순한 번호는 보안에 약합니다. / 생일이나 전화번호 뒷자리처럼 남이 쉽게 알 수 있는 번호는 피하는 게 좋습니다.
숫자를 외우기 어려워하신다면 번호를 종이에 적어 안전한 곳에 두는 방법이 있습니다. / 문 근처에 적어 두면 누구에게나 보일 수 있으니 장소는 신중히 고르세요.
자녀와 부모님이 함께 번호를 정하고 직접 눌러 보며 익히는 것이 가장 확실합니다.
@ 김량장동 도어락 번호 설정 어르신 점검

# 소리와 불빛은 알아보기 쉽게
번호판 소리가 너무 작으면 잘 눌렸는지 알기 어렵습니다. / 반대로 너무 크면 밤에 놀라시기도 하니 적당한 크기로 맞추는 것이 좋습니다.
제품에 따라 작동음 크기나 불빛 밝기를 조절할 수 있는 것도 있습니다. / 설정 방법은 설명서에 나와 있고, 어려우면 전화로 문의하셔도 됩니다.
배터리가 약해졌을 때 나는 경고음이 무슨 뜻인지 부모님께 미리 알려 두세요. / 경고음이 울리면 바로 자녀에게 연락하도록 말씀드리는 것이 중요합니다.

# 배터리는 해가 바뀔 때 한꺼번에
어르신 댁은 배터리 교체를 미루다 갑자기 문이 안 열리는 일이 많습니다. / 일부만 바꾸면 며칠 만에 또 문제가 생길 수 있으니 한 번에 전부 새것으로 바꿔 주세요.
배터리 칸 안쪽이나 뚜껑에 교체한 날짜를 적어 두면 잊지 않습니다. / 명절이나 생신처럼 정해 둔 날에 바꾸는 습관을 들이면 좋습니다.
비상용 9V 건전지를 집 안 한쪽에 두고 위치를 부모님께 알려 두는 것도 방법입니다.

# 문이 안 열려서 부모님이 안에 계신다면
부모님이 집 안에 계신데 문이 안 열린다고 연락이 온다면 먼저 침착하게 상황을 파악해야 합니다. / 안에서도 문을 못 여시는지, 밖에서만 안 열리는지를 확인해 보세요.
몸이 불편하시거나 응급 상황이 의심된다면 열쇠집보다 먼저 119에 연락하는 것이 맞습니다. / 상황이 급하지 않다면 전화를 주시고 안에 계신 분이 안전한지 먼저 말씀해 주세요.
위치와 상황을 알려 주시면 출동 시간을 바로 말씀드립니다. / 안에 계신 분과 통화를 이어 가며 안심시켜 드리는 것도 도움이 됩니다.
@ 김량장동 어르신 댁 현관문 개방 출동

# 부모님이 밖에서 못 들어오실 때
장을 보고 오시다가 문이 안 열려서 혼자 문 앞에 계신 경우도 있습니다. / 이럴 때는 이웃이나 근처 가게에 잠시 앉아 계시게 하고 자녀가 연락하는 것이 좋습니다.
어르신 본인이 신분을 확인할 수 있으면 직접 통화해 주셔도 됩니다. / 자녀가 대신 연락할 때는 위치와 상황, 부모님 연락처를 같이 알려 주세요.
추운 날이나 더운 날에는 오래 서 계시지 않도록 서둘러 연락해 주세요.

# 위치와 상황은 이렇게 알려 주세요
김량장동은 시장과 골목이 가까워 길이 복잡할 수 있습니다. / 위치를 정확히 알려 주시면 도착이 훨씬 빨라집니다.
- 가까운 큰길이나 시장 쪽 눈에 띄는 가게
- 건물 이름 또는 대문 모양, 몇 층인지
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집 안에 어르신이 계시는지, 연락이 되는지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙겨 가기 좋습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 주변 확인 중 하나면 됩니다.
어르신 댁은 자녀가 대신 연락한 경우가 많은데, 이때도 거주하시는 분 본인의 확인이 필요합니다. / 본인과 통화하거나 현장에서 직접 확인하는 방식으로 진행합니다.
번거롭더라도 어르신과 이웃 모두를 위한 절차이니 이해해 주세요. / 확인이 어려우면 작업을 할 수 없는 점은 미리 알려 드립니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
현관문 상태와 도어락 종류를 확인한 뒤 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 난 뒤에는 어르신이 쓰기 편하게 정리합니다
문이 열리면 도어락이 잘 작동하는지 같이 확인합니다. / 어르신이 쓰기 어려운 부분이 있다면 소리나 번호 설정을 단순하게 바꾸는 방법도 알려 드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 고장이 잦거나 너무 오래된 제품이라면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 필요하면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
문 여는 방법은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 미리 준비해 두면 좋은 것
부모님 댁에 문제가 생겼을 때 빨리 대응하려면 평소에 준비해 두는 것이 있습니다.
- 자녀 연락처를 문 안쪽이나 눈에 띄는 곳에 적어 두기
- 이웃이나 가까운 친척에게 비상 연락 부탁해 두기
- 여분 열쇠나 카드키를 믿을 수 있는 사람에게 맡겨 두기
- 도어락 제품명과 사진을 자녀 휴대폰에 저장해 두기
이런 준비가 있으면 막상 문제가 생겼을 때 훨씬 빠르게 움직일 수 있습니다.
@ 김량장동 부모님 댁 도어락 비상 연락 준비

# 마무리

혹시 문이 안 열려 곤란하시다면 위치와 상황을 알려 주세요. / 용인 어디든 24시간, 전화 010-3664-5455로 연락 주세요. 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
