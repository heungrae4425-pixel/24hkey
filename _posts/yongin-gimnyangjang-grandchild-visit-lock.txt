# 손주가 오는 날 문 앞에서
김량장동은 용인 시내 생활권이라 시장과 병원, 오래된 주택가가 가까이 있는 동네입니다. / 어르신 댁에 자녀와 손주들이 주말마다 오가는 모습도 흔히 봅니다.
손주가 혼자 오거나 먼저 도착했는데 문이 안 열리면 어르신도 아이도 당황합니다. / 번호를 알려 줬는데 아이가 헷갈려 하는 경우가 생각보다 많습니다.
이 글은 손주가 편하게 드나들면서도 안전한 도어락 번호를 정하는 방법을 정리했습니다. / [용인 출장열쇠](yongin.html)에 연락하는 경우와 직접 바꿀 때의 요령도 함께 적었습니다.
@ 김량장동 손주 방문 도어락 번호 정하기

어른은 번호 여섯 자리를 외워도 아이는 금방 잊어버립니다. / 문 앞에서 번호가 기억나지 않으면 한참 서성이다 전화를 걸게 됩니다.
그렇다고 너무 단순한 번호로 정하면 안전에 불안이 생깁니다. / 쉽게 기억하되 남이 추측하기는 어려운 균형이 필요합니다.
손주의 나이에 따라서도 기준이 조금 달라집니다. / 초등학생이면 짧고 리듬 있는 번호가, 중고등학생이면 조금 더 긴 번호도 무리 없이 외웁니다.

# 피해야 할 번호 유형
뻔한 번호는 가능하면 피하시는 게 좋습니다.
- 1234처럼 숫자가 순서대로 이어진 번호
- 0000이나 1111처럼 같은 숫자 반복
- 생일, 결혼기념일처럼 남이 알기 쉬운 날짜
- 전화번호 뒷자리나 현관 호수
- 이전에 쓰던 번호를 한두 자리만 바꾼 것
기억하기 쉬운 번호일수록 남도 추측하기 쉽다는 점을 기억해 두세요. / 가족만 아는 의미가 있는 조합이 좋습니다.

# 가족만 아는 규칙으로 정해보세요
숫자 자체보다 규칙을 정하면 외우기 쉽습니다. / 예를 들어 손주가 좋아하는 놀이나 가족 모임 날짜를 변형하는 식입니다.
아이에게는 노래처럼 박자를 붙여서 알려 주면 오래 기억합니다. / 숫자가 아니라 이야기로 기억하게 하는 방법입니다.
어르신이 직접 정한 번호라야 헷갈리지 않습니다. / 자녀가 대신 정해 주더라도 어르신이 반드시 이해하신 뒤에 등록하세요.
@ 가족 모두 기억하기 쉬운 번호 정하기

# 번호를 말로 알려줄 때 조심할 점
번호를 아이에게 전화로 알려 줄 때는 주변에 다른 사람이 없는지 확인해 주세요. / 엘리베이터나 복도에서 번호를 소리 내어 누르는 아이들도 많습니다.
번호를 문자로 보내 놓으면 휴대폰이 분실됐을 때 문제가 될 수 있습니다. / 메시지는 읽은 뒤 지우도록 아이에게 알려 주세요.
번호를 종이에 적어 가방에 넣어 두는 것도 피하세요. / 학원 가방이나 책가방은 잃어버리기 쉽습니다.

# 임시 번호를 쓰는 방법
손주가 오는 날에만 따로 쓰는 임시 번호가 있는 도어락도 있습니다. / 기본 번호와 별도로 하나 더 등록할 수 있는 제품이 많습니다.
방문이 끝나면 임시 번호를 지우는 습관을 들이면 안심이 됩니다. / 기본 번호는 건드리지 않고 필요할 때만 쓰는 방식입니다.
제품마다 등록 방법이 다르니 설명서를 먼저 확인해 보세요. / 등록이 어려우면 연락 주시면 방법을 안내해 드립니다.

# 번호를 바꾸다 막혔을 때
번호를 바꾸다가 중간에 멈추면 이전 번호와 새 번호가 섞여 아무것도 안 열리는 경우가 있습니다. / 이럴 때 억지로 이것저것 눌러 보면 입력이 한동안 막힐 수 있습니다.
번호 변경은 문을 열어 놓은 상태에서 하는 것이 안전합니다. / 문이 열린 채로 새 번호를 등록하고, 닫은 뒤 한두 번 시험해 보세요.
시험 전에 문이 닫혀 있다면 안쪽 열쇠나 카드를 곁에 두고 하세요.

# 문이 안 열릴 때 손주에게 알려줄 순서
아이에게는 간단한 행동 지침을 알려 두세요. / 어른이 곁에 없을 때 침착하게 움직일 수 있게 도와줍니다.
- 번호를 천천히 한 번 다시 눌러 보기
- 안 되면 문을 세게 흔들지 말고 멈추기
- 부모나 할머니 할아버지께 전화하기
- 근처 경비실이나 이웃 어른에게 도움 청하기
번호를 여러 번 틀리면 도어락이 잠시 입력을 막는다는 것도 알려 주세요. / 아이가 당황해서 계속 누르는 일을 막을 수 있습니다.

# 연락하실 때 알려주실 것
김량장동은 골목이 좁고 오래된 주택이 많아 위치 설명이 중요합니다. / 대략 어느 골목인지 눈에 띄는 가게나 병원 방향으로 알려 주셔도 됩니다.
- 김량장동 안 대략 위치와 몇 층인지
- 도어락 사진
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집 안에 어르신이나 아이가 있는지
연세가 있으신 분이 직접 전화하기 어렵다면 자녀분이 대신 연락해도 좋습니다. / 이 경우에도 현장에서는 사시는 분 확인이 필요합니다.

# 현장에서 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
어르신 댁이라면 신분증이 집 안에 있는 경우가 많습니다. / 주소가 적힌 우편물이나 건강보험 관련 서류를 미리 찾아 두시면 수월합니다.
자녀분이 대신 연락하신 경우에도 사시는 분 확인 방법을 같이 안내해 드립니다.
@ 김량장동 어르신 댁 도어락 번호 변경

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 본 뒤 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용도 없습니다.
번호만 바꾸는 간단한 일이라면 그렇게 말씀드리고 진행합니다. / 진행 방식은 [이용안내](guide.html)에도 정리해 두었습니다.

# 어르신이 쓰기 편한 도어락으로 바꿀 때
버튼이 작거나 번호판이 어두워서 불편하다면 큰 버튼 제품을 고려해 볼 수 있습니다. / 번호판 불빛이 밝고 소리가 또렷한 제품은 손주도 쓰기 쉽습니다.
지금 도어락이 아직 쓸 만하다면 바꾸지 않고 [도어락 수리](doorlock-repair.html)로 손보는 방법을 먼저 말씀드립니다. / 오래돼 쓰기 어려우면 [도어락 교체](doorlock-replace.html)를, 처음 다는 경우는 [도어락 설치](doorlock-install.html)를 안내해 드립니다.

# 번호 정리 후 지켜야 할 습관
- 번호는 반년이나 일 년에 한 번 정도 바꾸기
- 손주 방문 임시 번호는 방문 후 지우기
- 배터리는 해가 바뀔 때 전부 교체
- 번호를 아는 사람 목록을 가족끼리 정리
- 도어락 경고음이 나면 그날 바로 확인
배터리 칸에 교체한 날짜를 적어 두면 놓치지 않습니다. / 번호를 아는 사람이 누구인지만 가족이 알고 있어도 안심이 됩니다.

# 김량장동 말고 용인 어디든 갑니다
김량장동 옆 역북동 등 처인구 일대와 마북동, 신갈동도 다닙니다. / 용인 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
