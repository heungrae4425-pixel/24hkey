# 김량장동 집수리 끝낸 날, 현관이 말썽인 이유
김량장동은 용인 처인구 시내 쪽 생활권으로, 오래된 건물을 고쳐 쓰는 집과 상가가 많아 도배나 페인트 작업이 자주 있는 동네입니다. / 작업이 끝나 깨끗해진 집에 들어가려는데, 도어락 번호가 반응이 느리거나 문이 뻑뻑해졌다는 연락이 가끔 옵니다.
이 글은 도배나 페인트 작업 뒤 도어락 틈에 이물질이 들어갔을 때 확인할 것을 정리했습니다. / 그리고 [용인 출장열쇠](yongin.html)가 오면 어떻게 하는지도 적었습니다.
@ 김량장동 도배 페인트 후 도어락 이물질

# 작업 뒤 이물질이 생기는 방식
도배용 풀, 페인트 방울, 퍼티 가루, 실리콘 조각은 눈에 잘 안 보이는 틈으로 들어갑니다. / 현관 쪽을 가리는 작업(마스킹)이 덜 된 채 문 가까이에서 롤러를 쓰면 번호판 가장자리나 걸쇠 구멍에 묻습니다.
마르면 딱딱해지는 재료라서, 처음에는 괜찮다가 며칠 뒤 갑자기 문제가 되기도 합니다. / 그래서 공사 직후보다 한참 뒤에 이상이 느껴지는 경우도 있습니다.

# 이런 증상이면 이물질을 의심하세요
- 번호 버튼 하나만 눌림이 뻑뻑하거나 안 돌아오는 경우
- 걸쇠가 끝까지 나오지 않아 문이 덜 잠기는 경우
- 열쇠 구멍에 열쇠가 들어가다 막히는 경우
- 문을 닫으면 도어락 부근에서 긁히는 소리가 나는 경우
이 중 하나라도 해당되면 이물질이 걸려 있을 가능성이 있습니다. / 배터리나 고장이 아닐 수도 있으니 우선 겉을 살펴보세요.

# 눈으로 보고 손으로 만지기 전에
불을 켜고 번호판 틈, 손잡이 아래쪽, 걸쇠 끝을 가까이서 봅니다. / 하얗거나 색이 있는 얇은 막이 굳어 있다면 페인트나 풀입니다.
굳은 이물질을 칼로 긁어내는 분이 있는데, 그러면 도어락 표면이 긁히고 안쪽으로 부스러기가 더 들어갑니다. / 눈에 보이는 부분이라도 먼저 닦아 보는 정도로만 하세요.
@ 도어락 걸쇠 틈 굳은 풀 페인트 확인

# 집에서 해 볼 수 있는 안전한 정리
- 마른 천이나 면봉으로 번호판 겉면의 가루 닦기
- 아직 굳지 않은 물질은 물 묻힌 천을 꽉 짜서 살짝만 닦기
- 걸쇠 쪽은 문을 열어 둔 상태에서 눈에 보이는 부분만 정리
- 전용 윤활제를 쓴다면 아주 소량만, 번호판 속으로 흘러들지 않게
물을 많이 쓰거나 분무기를 번호판에 뿌리는 것은 피하세요. / 전기가 흐르는 부품에 물이 들어가면 작은 이물질보다 더 큰 문제가 됩니다.

특히 도어락을 새로 단 직후에 도배나 페인트가 이어진 집이라면 설치 흔적에도 가루가 많이 앉아 있습니다. / 이럴 때는 마른 솔로 쓸듯이 털어 낸 뒤 확인하세요.
이물질을 닦을 때는 한 방향으로만 가볍게 문지르세요. / 왔다 갔다 하면 부스러기가 틈으로 더 밀려 들어갑니다.

# 하지 말아야 할 것
시너나 강한 세정제를 쓰면 도어락 겉면과 고무 부품이 녹습니다. / 번호판 안쪽까지 들어가면 회로가 상할 수 있습니다.
드라이버로 번호판을 분해해 보려는 시도도 하지 마세요. / 한번 뜯으면 방수와 밀착이 달라져 이후 결로나 습기로 오작동하기 쉽습니다.

# 문이 이미 안 열리는 상태라면
번호를 눌러도 소리만 나고 열리지 않거나, 걸쇠가 이물질에 붙어 움직이지 않는 상황도 있습니다. / 이럴 때는 힘으로 손잡이를 돌리지 마세요.
위치와 도어락 모양, 어떤 작업을 했는지 말씀해 주시면 상황이 빨리 정리됩니다. / 도배인지 페인트인지, 몇 시간 전쯤이었는지도 알려 주시면 도움이 됩니다.

# 위치를 알려주실 때
- 건물 형태(주택, 상가, 다세대)와 호수
- 문 앞 도어락 사진
- 번호판 상태와 어떤 소리가 나는지
- 공사한 업체가 남긴 연락처가 있다면 그것도 메모
작업하신 분께 먼저 문의해 볼 수도 있습니다. / 해결이 안 되거나 급할 때 연락 주시면 됩니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
공사 중이라 우편물이 아직 새 주소로 안 왔다면 임대차 관련 서류나 건물 관리하는 분 확인으로 맞춰 보겠습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
이물질 정도와 도어락 상태를 직접 보고 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다. 진행 방식은 [이용안내](guide.html)에 있습니다.

굳은 재료만 걷어 내면 되는 경우가 대부분이라 교체까지 갈 일은 많지 않습니다. / 먼저 [도어락 수리](doorlock-repair.html)로 정리하고 작동을 확인합니다.
이물질이 안쪽 모터나 회로 쪽까지 들어가 있고 되돌릴 수 없는 상태라면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 문을 여는 일 자체는 [현관문 개문](door-open.html)에서 설명한 방식으로 덜 상하게 진행합니다.
이물질이 굳기 전 하루 안에 연락 주시면 훨씬 가볍게 정리됩니다. / 시간이 지날수록 딱딱해져서 떼어 내는 과정에서 도어락 표면이 상하기 쉽습니다.

# 문틀과 경첩 쪽 이물질도 놓치기 쉽습니다
도어락만 보고 끝내는 경우가 많지만 문틀의 걸쇠 받이 구멍과 경첩에도 페인트가 흘러 굳는 일이 있습니다. / 걸쇠가 들어가는 구멍이 좁아지면 문이 닫혀도 완전히 잠기지 않습니다.
경첩에 굳은 페인트가 붙으면 문을 열 때 삐걱거리거나 문이 살짝 처져 보입니다. / 이럴 때 도어락이 원인이라고 생각해 번호판만 계속 바꾸는 분이 있어 안타깝습니다.
눈으로 보고 걸쇠 받이 구멍이 매끈한지, 경첩 사이에 하얀 막이 있는지 확인해 보세요. / 잘 모르겠으면 사진을 찍어 보내 주시면 같이 봐 드립니다.
@ 김량장동 문틀 걸쇠 받이 구멍 페인트

# 다음 공사 때는 이렇게 부탁하세요
- 작업 전 도어락 전체를 비닐과 테이프로 감싸 달라고 요청하기
- 번호판은 떼어 놓기보다 가려서 두기
- 작업 마지막 날 현관 도어락이 정상인지 같이 확인
- 마른 뒤에도 하루 이틀 뒤 한 번 더 점검
도어락이 달린 쪽 문틀도 같이 가려 달라고 하면 풀이 걸쇠 구멍에 들어가는 것을 막을 수 있습니다. / 작은 요청이지만 나중에 문 앞에서 당황하는 일을 크게 줄입니다.

# 김량장동 말고 용인 어디든 갑니다
김량장동 가까이 역북동, 포곡읍, 모현읍, 남사읍 쪽도 다닙니다. / 용인 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html)에, 다른 지역은 [출장 지역](area.html) 지도에 정리해 두었습니다.
