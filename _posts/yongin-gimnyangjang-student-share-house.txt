# 혼자 사는 방의 문이 안 열리는 순간
김량장동은 용인 시내 중심 생활권이라 자취방과 고시원, 작은 원룸이 모여 있어 혼자 사는 분이 많습니다. / 혼자 살면 문이 잠겨도 도와줄 사람이 곁에 없어 더 막막합니다.
이 글은 자취방, 고시원, 쉐어하우스처럼 여럿이 건물을 나누는 곳에서 문이 잠겼을 때의 대처를 정리했습니다. / 어디에 먼저 연락해야 하는지가 일반 주택과 조금 다릅니다.
먼저 알아 둘 점은 방 안쪽 문과 건물 출입문이 다르다는 것입니다. / 어느 문이 안 열리는지에 따라 풀이가 완전히 달라집니다.
@ 김량장동 자취방 고시원 출입문 잠김

# 어느 문이 막혔는지 구분하기
건물 현관의 공동 출입문과 내 방 문, 방 안의 화장실 문은 각각 다른 열쇠나 번호를 씁니다. / 어느 쪽이 안 열리는지부터 정확히 하세요.
공동 출입문은 건물 관리자가 관리하는 경우가 많습니다. / 방 문은 입주자가 쓰는 열쇠나 번호로 열리는 방식이 보통입니다.
고시원은 방마다 열쇠를 쓰는 곳과 전자식인 곳이 섞여 있습니다. / 어떤 방식인지 알아 두면 연락이 쉬워집니다.
입주할 때 받은 안내문이나 계약서에 문 열람 방법이 적혀 있는 경우도 있습니다. / 급할 때 찾기 쉽게 사진으로 찍어 휴대폰에 넣어 두세요.

# 먼저 연락할 곳 정하기
쉐어하우스나 고시원은 관리자가 따로 있는 곳이 많습니다. / 관리자가 열쇠를 가지고 있는지 먼저 확인하세요.
계약서에 관리자 연락처나 비상 열쇠 안내가 있는지도 보세요. / 이 방법이 가장 빠르고 비용이 들지 않는 경우도 있습니다.
관리자와 연락이 안 되거나 밤늦은 시간이라면 그때 연락 주시면 됩니다. / [용인 출장열쇠](yongin.html)가 24시간 받고 있습니다.

# 룸메이트나 하우스메이트가 있는 경우
같이 사는 사람이 있다면 먼저 전화로 문을 열어 줄 수 있는지 물어보세요. / 가장 간단하고 빠른 방법입니다.
공동 공간의 현관 번호는 모두가 알고 있는지 확인해 보세요. / 번호를 바꾼 사람이 있는데 공유가 안 된 일이 의외로 자주 생깁니다.
여럿이 쓰는 번호는 변경할 때마다 한꺼번에 공유하는 규칙을 정해 두면 좋습니다. / 메신저 공지방에 올려 두는 방식도 편합니다.
@ 김량장동 쉐어하우스 현관 번호 공유

# 열쇠를 잃어버렸을 때
자취방 열쇠를 잃어버렸다면 방 열쇠인지 건물 열쇠인지 먼저 구분합니다. / 건물 열쇠까지 잃어버렸다면 관리자에게 알리는 것이 좋습니다.
다른 사람이 주워 쓸 수 있다는 걱정이 있다면 방 열쇠를 바꾸는 방법이 있습니다. / 다만 방 구조를 바꾸는 일이라 관리자나 집주인과 먼저 이야기해야 합니다.
법적인 판단은 드릴 수 없지만, 비용이나 교체 범위는 당사자끼리 정리하시도록 권해 드립니다. / 저희는 문을 여는 일과 방법 안내까지만 도와드립니다.
열쇠를 새로 맞추는 일은 방 구조상 관리자의 동의가 필요한 경우가 많습니다. / 먼저 연락해 보시고 필요한 만큼만 진행하는 것이 좋습니다.

# 비밀번호를 모르는 경우
전자식 방 문의 번호를 모르면 입주 때 받은 안내문이나 문자를 찾아보세요. / 임시 번호를 받았다면 그대로 쓰고 있는 사람도 있습니다.
번호가 바뀌었다면 관리자가 알고 있을 가능성이 큽니다. / 이름과 호실을 말씀드리면 확인해 주는 곳이 많습니다.
번호를 여러 번 틀리면 입력이 잠깐 막힙니다. / 서너 번 해 보고 안 되면 멈추는 것이 좋습니다.

# 문 앞에서 하지 말아야 할 일
- 문틈에 칼이나 카드를 넣어 억지로 벌리기
- 문을 발로 차거나 어깨로 밀기
- 다른 방 문을 같이 열어 보는 것
- 건물 다른 입주자에게 문 열어 달라고 부탁하는 것
이런 시도는 문을 상하게 하고 건물 전체의 안전 문제로 번질 수 있습니다. / 특히 다른 입주자의 방은 절대 건드리지 마세요.
소란이 나면 이웃에게 불편을 주고 오해를 사기도 합니다. / 차분히 연락하는 편이 훨씬 빠릅니다.
특히 새벽이나 밤늦은 시간에 복도에서 문을 두드리면 다른 입주자가 놀랄 수 있습니다. / 조용히 연락하시고 도착 전까지는 가까운 곳에서 기다려 주세요.

# 도착하면 사시는 분인지 먼저 확인합니다
여러 사람이 사는 건물이라 확인은 더 엄격하게 합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소나 관리자 확인 중 하나면 됩니다.
자취생은 주소를 옮기지 않았거나 우편물이 없는 경우가 있습니다. / 이때는 계약서나 관리자 확인으로 대신할 수 있습니다.
확인이 어려우면 진행하지 않으니 미리 준비해 주세요. / 다른 사람의 방을 열지 않기 위한 절차입니다.

# 비용은 열기 전에 말씀드립니다
문 종류와 상태를 보고 비용을 먼저 말씀드립니다. / 동의하신 뒤에 시작하고, 아니면 돌아갑니다.
문을 못 열면 비용은 받지 않고, 열고 난 뒤에 갑자기 붙는 항목도 없습니다. / 부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에서 확인하실 수 있습니다.

# 최대한 상하지 않게 엽니다
세 들어 사는 방은 문이 망가지면 책임 문제가 얽히기 쉽습니다. / 그래서 문과 잠금장치를 상하지 않게 여는 방법부터 시도합니다.
[현관문 개문](door-open.html)에 개방 방식이 설명되어 있고, 방 문은 구조에 따라 현장에서 판단합니다. / 작업 중에 이상이 보이면 손대기 전에 말씀드립니다.
@ 김량장동 원룸 출입문 개방 작업

# 열린 뒤에 확인할 것
문이 열리면 열쇠나 번호가 정상인지 함께 봅니다. / 건전지가 원인이었다면 새것으로 바꾸는 것까지 도와드립니다.
도어락이 계속 오작동한다면 [도어락 수리](doorlock-repair.html) 쪽으로 확인해 볼 수 있습니다. / 다만 세 들어 사는 곳이라면 교체나 변경은 집주인이나 관리자와 먼저 상의하세요.
잠금장치를 바꾸는 일은 사시는 분 마음대로 하기 어려운 경우가 많습니다. / 허락을 받은 뒤에 [도어락 교체](doorlock-replace.html)를 상의하시면 됩니다.
퇴실할 때는 열쇠와 카드, 번호를 모두 반납하고 설정을 정리했는지 확인하세요. / 반납 기록을 사진으로 남겨 두면 나중에 오해가 생기지 않습니다.

# 자취방 문을 덜 잠그게 하는 습관
외출할 때 열쇠, 휴대폰, 지갑을 문 앞에서 한 번 확인하세요. / 문을 닫기 전 주머니를 두드리는 짧은 습관이 가장 효과적입니다.
쓰레기를 버리거나 택배를 받을 때도 문이 닫히는 순간 열쇠를 가졌는지 보세요. / 짧은 외출에서 가장 많이 잠깁니다.
예비 열쇠나 비밀번호는 믿을 만한 가족이나 친구에게 알려 두세요. / 관리자 연락처는 휴대폰에 저장해 두는 것이 좋습니다.
건전지 경고음이 나면 관리자에게 알려 바꾸도록 요청하세요. / 미루다 새벽에 꺼지면 가장 곤란합니다.

# 김량장동 말고 용인 어디든 갑니다
김량장동 옆 역북동, 포곡읍, 모현읍 쪽을 비롯해 용인 어디든 다닙니다. / 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
