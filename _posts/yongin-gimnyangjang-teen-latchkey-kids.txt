# 열쇠 없이 하교하는 아이, 번호 하나로 집에 들어옵니다
김량장동은 용인 도심 생활권이라 학교와 학원을 오가는 학생이 많은 동네입니다. / 기흥역이나 동백역 쪽으로 나가는 부모님이 출근한 뒤에 아이 혼자 먼저 집에 들어오는 가정도 흔합니다.
요즘은 열쇠를 들고 다니다 잃어버릴 걱정이 없어 번호 하나로 들어오게 해 둔 집이 많습니다. / 그런데 그 번호 하나를 아이가 잊거나 잘못 누르면 문 앞에서 오도 가도 못하게 됩니다.
이 글은 열쇠 없이 하교하는 학생이 있는 집에서 번호를 어떻게 정하고 관리하면 좋은지 적은 글입니다. / 이미 문 앞에서 막혔다면 뒤쪽의 순서를 먼저 보셔도 됩니다.
@ 김량장동 하교 시간 혼자 현관 번호를 누르는 학생

# 아이 번호를 정할 때 지켜야 할 기준
아이가 외우기 쉽다고 생년월일이나 집 전화번호 끝자리를 쓰는 경우가 많습니다. / 그런 번호는 주변 사람이 짐작하기도 쉬워서 권하지 않습니다.
- 아이가 소리 내어 외울 수 있는 길이일 것
- 생일, 전화번호, 1234처럼 흔한 조합은 피할 것
- 학교 친구들 앞에서 입력해도 알아보기 어려운 번호일 것
- 가족 모두가 똑같이 알고 있을 것
짧은 문장을 숫자로 바꾸거나 부모와 아이만 아는 규칙을 정해 두면 외우기 쉽습니다. / 번호는 한 번 정하면 한동안 유지하되, 아이가 헷갈려 하면 바로 단순하게 고쳐 주세요.

# 키패드를 누를 때 옆 사람이 보지 못하게 하는 습관
하교 시간에는 같은 층 아이들이나 친구가 같이 올라오는 경우가 있습니다. / 번호를 누를 때 손바닥으로 번호판 위쪽을 가리는 습관을 들이면 훨씬 안전합니다.
번호를 누른 뒤 아무 숫자나 몇 개 더 누르고 마무리하는 도어락도 있습니다. / 이런 기능이 있는지 설명서나 제조사 안내에서 확인해 보세요.
친구를 집에 데려올 때도 번호는 문 앞에서 말하지 않도록 미리 이야기해 두세요. / 아이에게 번호는 비밀이라는 점을 야단치듯이 말하기보다 규칙으로 알려 주는 편이 오래갑니다.

# 번호를 잊었을 때 아이가 할 수 있는 행동
번호가 갑자기 기억나지 않으면 아이는 당황해서 계속 눌러 보기 쉽습니다. / 여러 번 틀리면 도어락이 입력을 한동안 막기 때문에 오히려 더 늦어집니다.
먼저 아이에게 세 번까지만 눌러 보고 멈추라고 알려 주세요. / 그다음 부모님께 전화하는 것이 가장 빠른 순서입니다.
- 번호를 두세 번 눌러 보고 안 되면 멈추기
- 부모님이나 가까운 보호자에게 전화하기
- 계단이나 현관 앞 안전한 곳에서 기다리기
- 낯선 사람이 도와주겠다고 하면 정중히 거절하기
특히 마지막 항목은 꼭 미리 말해 두세요. / 모르는 사람이 문을 열어 주겠다고 접근하는 상황은 드물어도 대비해 두면 좋습니다.

# 부모님이 전화로 번호를 알려줄 때 주의할 점
문 앞에서 우는 아이를 달래려고 번호를 크게 불러 주다 보면 주변 복도에 다 들립니다. / 가능하면 아이가 이어폰을 끼거나 한쪽 귀에 전화를 바싹 대고 듣게 해 주세요.
부모님이 퇴근 전이라 통화가 어렵다면 번호를 적은 쪽지를 가방 안쪽 주머니에 넣어 두는 방법도 있습니다. / 다만 쪽지에 집 주소를 같이 적지 않아야 잃어버렸을 때 걱정이 없습니다.
@ 김량장동 부모님과 전화 통화하며 번호를 확인하는 아이

# 비상용 카드키나 태그를 함께 쓰는 방법
번호 입력이 서툰 어린 학생이라면 카드키나 태그를 가방에 매달아 쓰는 방법도 있습니다. / 번호를 못 외워도 대기만 하면 열리니 부담이 줄어듭니다.
대신 카드키는 잃어버리기 쉬워서 번호와 함께 쓰는 것이 안전합니다. / 카드를 잃어버렸다면 새 카드를 등록하면서 기존 카드는 삭제해 두어야 합니다.
카드 분실 때 어떻게 하는지는 [도어락 수리](doorlock-repair.html) 안내와 함께 보시면 도움이 됩니다. / 도어락 종류에 따라 카드 삭제 방법이 달라 사진을 보내 주시면 확인해 드립니다.

# 배터리가 먼저 떨어지면 아이가 가장 곤란합니다
부모님이 계실 때는 경고음이 울려도 그냥 지나치기 쉽습니다. / 그러나 아이 혼자 들어오는 시간에 배터리가 떨어지면 번호판이 켜지지 않아 아무것도 할 수 없습니다.
배터리 교체는 날짜를 정해 두고 한꺼번에 하는 편이 좋습니다. / 연말이나 학기가 바뀔 때 같은 기준을 하나 정해 두면 잊지 않습니다.
아이에게도 번호판에서 평소와 다른 소리가 나면 부모님께 바로 알리라고 가르쳐 두세요. / 경고음은 곧 배터리가 끝난다는 신호일 때가 많습니다.

# 학기 중 번호를 바꿔야 하는 순간
아이가 번호를 친구에게 알려 줬거나 잃어버린 쪽지에 번호가 적혀 있었다면 번호를 바꾸는 것이 좋습니다. / 큰 사고가 나지 않았더라도 마음이 편해지는 쪽을 택하세요.
번호를 바꿀 때는 가족이 함께 있는 저녁 시간에 하는 것이 좋습니다. / 아이에게 새 번호를 직접 눌러 보게 하고 한 번 더 확인하면 다음날 문 앞에서 헤매지 않습니다.
이미 바꿨다면 예전 번호가 남아 있지 않은지도 확인해 보세요. / 도어락에 따라 번호가 여러 개 저장되는 기종이 있어 오래된 번호가 그대로 남기도 합니다.

# 전화하기 전에 문 앞에서 확인할 것
번호를 잊은 경우가 아니라 도어락이 반응하지 않는다면 다른 원인일 수 있습니다. / 상황을 말씀해 주시면 전화로 원인을 좁히는 데 도움이 됩니다.
- 번호판에 불이 들어오는지 여부
- 번호를 누를 때 삑 소리가 나는지
- 소리는 나는데 모터가 돌다 멈추는지
- 안쪽 보조키가 잠겨 있을 가능성이 있는지
아이가 문 앞에 있고 보호자가 멀리 있는 경우라면 먼저 그 사실을 알려 주세요. / 아이 상태에 따라 출동 순서를 정하는 데 큰 도움이 됩니다.
@ 김량장동 번호판 상태를 확인하는 현관문 앞

# 출장열쇠를 부르면 이런 순서로 진행됩니다
[용인 출장열쇠](yongin.html)에 전화하시면 위치와 현재 상황을 먼저 여쭙니다. / 아이가 혼자 있다면 아이가 안전한 곳에 있는지부터 확인합니다.
도착하면 도어락 상태를 보고 열 수 있는 방법과 비용을 먼저 말씀드립니다. / 괜찮다고 하셔야 작업을 시작하고, 못 열면 비용은 받지 않습니다.
문을 여는 방식은 [현관문 개문](door-open.html) 페이지에서 자세히 볼 수 있습니다. / 최대한 문과 도어락이 상하지 않는 방법부터 차례로 해봅니다.

# 신분 확인은 이렇게 합니다
아이만 있는 집이라면 출장 기사가 문을 열어도 되는지 보호자가 직접 확인해야 합니다. / 보호자와 통화가 어려우면 작업을 미룰 수 있다는 점을 미리 알려 드립니다.
사시는 분인지 확인하기 위해 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나를 준비해 주세요. / 보호자가 도착하지 않았다면 전화로 확인한 뒤 진행합니다.
아이에게 직접 신분증을 달라고 하지는 않습니다. / 보호자와 통화로 마무리하는 것을 기본으로 하니 걱정하지 않으셔도 됩니다.

# 문이 열린 뒤 번호를 다시 정리하는 방법
문을 연 뒤에는 도어락이 다시 잘 열리고 잠기는지 같이 확인합니다. / 필요하면 새 번호를 등록하고 예전 번호는 지워 둡니다.
번호를 바꿨다면 가족 모두가 같은 번호를 알고 있는지 그날 저녁에 한 번 더 확인하세요. / 아이가 직접 눌러 보며 기억하는 것이 가장 확실한 방법입니다.
오래 써서 자주 고장 나는 도어락이라면 [도어락 교체](doorlock-replace.html)를 고민해 볼 수 있습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 김량장동 말고 용인 어디든 갑니다
김량장동 가까운 역북동, 마북동, 신갈동은 물론 포곡읍, 모현읍, 남사읍까지 다닙니다. / 수지구청역 근처 풍덕천동, 죽전역 근처 죽전동도 24시간 출동합니다.
용인에서 다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
