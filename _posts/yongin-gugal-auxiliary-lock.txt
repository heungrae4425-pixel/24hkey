# 번호는 맞게 눌렀는데 문이 꿈쩍도 안 할 때
구갈동에서 기흥역으로 가는 길에 쓰레기를 버리러 나갔다가 문이 닫혀 버린 경험, 한 번쯤 들어 보셨을 겁니다. / 번호를 정확히 눌렀고 삑 소리까지 났는데 문이 열리지 않으면 원인을 알기 어렵습니다.
이럴 때 의심해 볼 것이 보조키와 걸쇠입니다. / 도어락 번호가 맞아도 보조키가 잠겨 있으면 문은 절대 열리지 않습니다.
이 글은 보조키와 걸쇠가 걸려 문이 안 열릴 때 확인하는 순서를 적었습니다. / 번호가 틀린 줄 알고 계속 누르다 입력이 막히기 전에 먼저 이 점을 살펴보세요.
@ 구갈동 보조키 걸쇠 걸림 출장 개문

# 보조키와 걸쇠는 무엇이 다른가요
두 가지는 이름이 비슷하지만 하는 일이 다릅니다. / 어디가 걸렸는지 알아야 해결 방법도 정해집니다.
- 보조키: 도어락 위나 아래에 달린 별도의 잠금 장치로 안쪽에서 돌리거나 눌러 잠급니다
- 걸쇠: 도어락 안에서 문틀 구멍에 걸리는 금속 조각으로 문을 고정합니다
- 안전고리: 문을 조금만 열 수 있게 걸어 두는 체인이나 고리입니다
보조키는 사용자가 직접 잠그는 장치이고, 걸쇠는 도어락의 모터가 움직이는 장치입니다. / 같은 증상이라도 보조키는 사람이 잠근 것이고 걸쇠는 기계가 물린 것이라는 점이 다릅니다.

# 번호가 맞는지 틀린지 먼저 구분하는 법
번호를 누르고 모터 소리가 나는지 귀를 기울여 보세요. / 소리가 나는데 문이 안 열린다면 번호는 맞고 다른 곳이 걸린 것입니다.
아무 소리 없이 경고음만 울리면 번호가 틀렸거나 입력이 막힌 상태일 수 있습니다. / 이럴 때는 몇 분 기다렸다가 다시 눌러 보세요.
번호판이 켜지지 않으면 배터리 문제가 먼저입니다. / 이 경우는 보조키와 별개로 비상 전원부터 해결해야 합니다.
이렇게 상태를 나누어 두면 전화로 설명하기 훨씬 쉬워집니다.

# 보조키가 잠긴 채로 나온 날의 상황들
보조키가 잠겨 있는 상태에서 문이 닫혀 버리는 일은 생각보다 흔합니다. / 잠그는 습관이 있는 분은 특히 조심해야 합니다.
외출하며 습관적으로 보조키를 돌려 잠그고 나와 번호를 눌러도 안 열리는 경우가 있습니다. / 아이가 안에서 장난으로 돌려 잠근 경우도 있습니다.
가족이 집에 있다고 생각해 안쪽에서 잠가 두었는데 실제로는 나간 상태일 수도 있습니다. / 이럴 때는 집 안에 누가 있는지 먼저 확인해 보세요.
안쪽 사람이 있으면 문 너머로 대화하여 보조키를 풀어 달라고 부탁하는 것이 가장 쉬운 방법입니다.
@ 용인 구갈동 도어락 보조키 잠금 해제

# 걸쇠가 문틀에 물려서 안 빠질 때
번호도 맞고 보조키도 풀렸는데 문이 안 열리면 걸쇠가 문틀에 꽉 물렸을 가능성이 있습니다. / 문이 처졌거나 문틀이 틀어져 걸쇠가 받이 구멍에 눌린 경우입니다.
이럴 때는 번호를 누르는 동안 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요. / 걸쇠에 걸리는 힘이 풀리면서 열리는 경우가 있습니다.
반대로 문을 당기거나 흔들면 걸쇠가 더 깊이 물릴 수 있으니 힘을 한 방향으로 주지 마세요. / 몇 번 시도해서 안 되면 멈추는 것이 좋습니다.

# 이 방법은 쓰지 마세요
급한 마음에 문틈에 카드를 넣거나 얇은 도구로 걸쇠를 밀어 열려는 분이 있습니다. / 이 방법은 문틀과 도어락 외관을 긁거나 파손하기 쉽습니다.
문을 발로 차거나 어깨로 밀면 문틀이 틀어져 걸쇠가 더 심하게 걸립니다. / 나중에 문을 고치는 비용이 훨씬 커집니다.
번호를 여러 번 틀리면 입력이 막히니 서너 번 눌러 보고 안 되면 멈추세요. / 잠시 멈추는 것도 하나의 방법입니다.
안전고리나 체인이 걸려 문이 조금만 열리는 경우는 열린 틈으로 기구를 넣기보다 안쪽 가족에게 풀어 달라고 하세요.

# 구갈동 위치와 상황은 이렇게 알려 주세요
구갈동은 기흥역 주변과 안쪽 주택가가 이어져 있어 위치를 구체적으로 알려 주시면 도착이 빨라집니다. / 아래 정보를 말씀해 주세요.
- 건물 이름과 동, 호수 (단지 이름만 알아도 됩니다)
- 번호를 누르면 어떤 소리가 나는지
- 보조키가 있는지, 잠근 기억이 있는지
- 안쪽에 사람이나 반려동물이 있는지
- 문 모양 (철문, 방화문)과 도어락 모양
보조키 모양을 찍은 사진이 있으면 도구를 정확히 챙길 수 있습니다. / 사진이 어렵다면 말씀으로 설명해 주셔도 됩니다.

# 안에 사람이 있을 때는 먼저 알려 주세요
보조키가 잠긴 집에는 사람이 안에 있을 가능성이 높습니다. / 어린아이나 어르신이 안에 있다면 먼저 그 사실을 알려 주세요.
문 너머로 계속 말을 걸어 안심시키고 보조키를 돌려 보게 안내해 주세요. / 아이가 놀라면 더 어렵습니다.
혹시 안에서 응답이 전혀 없고 건강 문제가 의심되면 개문보다 119에 먼저 연락해 주세요. / 이후 개문이 필요하면 바로 이어서 진행합니다.

# 사시는 분 확인은 이렇게 합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소나 경비실에 세대 확인을 부탁하세요. / 확인이 안 되면 작업은 시작하지 않습니다.
번거롭지만 같은 건물 이웃을 보호하는 절차입니다. / 미리 준비해 두면 도착 후 곧바로 진행됩니다.
@ 구갈동 도어락 보조키 신분 확인 후 개문

# 비용은 시작 전에 말씀드리고 못 열면 받지 않습니다
보조키 잠금인지 걸쇠 걸림인지에 따라 열기 방법이 다르고 시간도 다릅니다. / 현장을 보고 방법과 비용을 먼저 말씀드린 뒤 동의하실 때만 시작합니다.
문을 상하지 않게 열 수 있는 방법부터 차례로 해봅니다. / 방법을 바꿔야 할 때는 이유를 설명드립니다.
끝내 못 열면 비용은 받지 않습니다. / 자세한 진행 방식은 [이용안내](guide.html)와 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다.

# 열린 뒤 확인할 것과 고칠 것
문이 열리면 보조키가 부드럽게 돌아가는지, 걸쇠가 문틀 받이에 정확히 들어가는지 봅니다. / 처짐이 원인이었다면 경첩과 받이 위치를 함께 조정합니다.
보조키가 고장 나서 잠긴 것이라면 장치 자체를 점검하고 필요하면 바꾸는 방법을 말씀드립니다. / 일부만 손보면 되는 경우에는 교체를 권하지 않습니다.
도어락 자체가 오래돼 걸쇠 동작이 둔하다면 [도어락 수리](doorlock-repair.html)로 먼저 확인하세요. / 정말 필요한 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 잠그고 나오는 일을 줄이는 습관
작은 습관으로 보조키 때문에 겪는 불편을 크게 줄일 수 있습니다. / 아래 방법을 가족과 함께 정해 두세요.
- 외출할 때는 보조키를 잠그지 않기로 약속하기
- 나가기 전에 문 안쪽 잠금 상태를 한 번 확인하기
- 쓰레기를 버리러 나갈 때는 문이 닫히지 않게 고정하기
- 아이가 보조키를 만지지 않게 높이나 장치를 점검하기
- 집 근처에 맡겨 둘 수 있는 믿을 만한 열쇠 보관처 정해 두기
짧은 외출에도 항상 같은 순서로 문을 나서면 실수가 줄어듭니다. / 바깥에서 막혔을 때 연락할 사람도 정해 두면 마음이 편합니다.

# 구갈동 말고 용인 어디든 갑니다
구갈동 가까운 신갈동, 보정동, 영덕동과 기흥역 주변은 물론 용인 전역을 다닙니다. / 용인 안이라면 24시간 연락받습니다.
용인 전체 지역은 [용인시 출장열쇠](yongin.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 확인하세요.
