# 죽전동, 배달 마치고 밤늦게 돌아왔는데 문이 안 열린다면
죽전동은 죽전역 주변으로 주택과 빌라, 상가가 이어진 동네입니다. / 배달 일을 하는 가족은 저녁 늦게나 한밤에 일을 마치고 돌아오는 경우가 많습니다.
하루 종일 비바람 속에서 일하고 돌아왔는데 번호판이 꺼져 있거나 문이 안 열리면 몸도 마음도 지칩니다. / 이 글은 죽전동에서 이런 상황이 생겼을 때 이웃을 깨우지 않고 차분하게 해결하는 순서를 적었습니다.
급하면 [용인 출장열쇠](yongin.html)에 바로 연락 주세요.
@ 죽전동 늦은 밤 현관 도어락 앞

# 늦은 시간에 문 앞에서 먼저 할 일
밤늦게는 이웃이 자고 있는 시간이라 소리를 내지 않는 것이 먼저입니다. / 번호를 세게 두드리거나 문을 흔들면 주변에 불편을 줍니다.
숨을 고르고 번호판이 켜지는지, 눌렀을 때 무슨 소리가 나는지만 확인해 보세요. / 이 두 가지로 배터리 문제인지 다른 문제인지 구분이 됩니다.

# 배달 일과 도어락 배터리의 관계
배달 일을 하면 하루에도 여러 번 집을 드나듭니다. / 번호를 많이 누르는 만큼 배터리가 빨리 닳을 수 있습니다.
장갑을 낀 채 번호를 누르다가 잘못 눌러 틀리는 일도 잦습니다. / 틀린 입력이 쌓이면 도어락이 한동안 입력을 막습니다.
- 번호판이 흐려졌거나 반응이 느렸던 날이 있었는지
- 장갑 때문에 번호를 여러 번 틀렸는지
- 비 오는 날 번호판에 물이 들어갔는지

# 비에 젖은 번호판 때문에 안 될 때
비 오는 날 일을 하고 오면 손도 젖고 번호판에도 물기가 묻습니다. / 물기가 있으면 터치 번호판은 엉뚱하게 반응하거나 아예 안 눌릴 수 있습니다.
마른 천이나 옷 안쪽으로 번호판을 닦고 손도 닦은 뒤 천천히 눌러 보세요. / 장갑을 벗고 맨손으로 누르는 것이 더 정확한 경우가 많습니다.
그래도 안 눌리면 잠시 기다렸다가 다시 해 보세요.

퇴근하면서 짐이 많아 번호를 급히 누르다가 틀리기도 합니다. / 가방을 내려놓고 한 손으로 천천히 누르는 것이 오히려 빠릅니다.
열쇠를 같이 쓰는 집이라면 열쇠 뭉치에서 다른 열쇠를 꽂는 일도 있습니다. / 모양이 비슷한 열쇠를 혼동해 구멍에 억지로 넣다가 걸리는 경우를 조심하세요.
열쇠가 구멍에 안 들어가면 힘을 주지 말고 다른 열쇠인지 확인하세요.

# 9V 건전지가 있으면 비상 전원
번호판이 아예 꺼져 있다면 바깥 비상 단자에 9V 건전지를 대 볼 수 있습니다. / 죽전역 근처 편의점에서 구할 수 있지만 늦은 밤이면 문을 닫은 곳도 있습니다.
- 평소 오토바이 수납함이나 가방에 하나 넣어 두기
- 건전지 접촉면을 마른 천으로 닦아 사용하기
- 비상 단자가 없는 모델은 건너뛰고 연락하기
이렇게 해서 문이 열리면 안쪽 배터리를 새것으로 모두 갈아 주세요.
@ 죽전동 도어락 비상 단자 9V 건전지

# 문이 열렸는데 걸쇠가 안 빠진다면
번호는 맞고 모터 소리도 나는데 문이 안 열릴 때가 있습니다. / 이때 문을 안쪽으로 살짝 밀면서 손잡이를 돌려 보세요.
안쪽 보조키나 걸쇠를 걸고 나온 것은 아닌지도 떠올려 보세요. / 가족 누군가가 안에서 걸었을 수도 있어서 집 안에 사람이 있는지 확인하세요.
억지로 당기거나 발로 차지는 마세요.

# 가족이 안에 자고 있을 때
집 안에 가족이 자고 있다면 전화나 문자로 조용히 깨워 안에서 열어 달라고 부탁하는 방법이 있습니다. / 벨을 길게 누르면 이웃까지 깨우니 짧게 한두 번만 누르세요.
안쪽에서 열 수 있는 상황이면 가장 빠릅니다. / 안에서도 걸쇠가 안 풀리거나 보조키가 걸린 경우는 연락 주세요.
아이나 반려동물이 안에 있다면 놀라지 않게 먼저 말씀해 주세요.

# 전화하실 때 알려주실 것
밤늦은 시간에는 조용히 접근해야 하므로 위치가 정확해야 합니다. / 죽전동 안에서 죽전역 기준 대략 어느 방향인지 말씀해 주세요.
- 건물 형태와 몇 층인지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 집 안에 사람이 있는지, 깨울 수 있는지
- 일을 마친 직후라 어디서 기다릴 수 있는지
오토바이나 짐이 있으면 안전한 곳에 세워 두고 기다려 주세요.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
일 하는 중에 신분증을 두고 나오는 분도 많습니다. / 휴대폰에 있는 서류나 가족 확인이 가능한 경우도 있으니 먼저 말씀해 주세요.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 출근 전에 미리 해두면 좋은 습관
늦게 돌아오는 날이 많은 가족이라면 집을 나서기 전에 도어락 상태를 한 번 보는 것이 가장 좋습니다. / 번호판이 평소보다 어둡거나 반응이 느리면 그날 바로 배터리를 확인하세요.
가족끼리 귀가 시간을 대략 공유해 두면 안에서 열어 줄 사람을 정해 두기 쉽습니다. / 밤늦게 돌아올 때 문 앞에서 막히는 일이 확 줄어듭니다.
짐이 많은 날에는 현관 앞에 가방을 내려놓고 번호를 누르는 습관도 도움이 됩니다. / 열쇠 대신 번호를 쓰는 집이라면 번호를 바꿀 때 꼭 가족에게 먼저 알려주세요.
@ 죽전동 퇴근길 현관문 앞 가방과 헬멧

# 비용은 문 열기 전에 말씀드립니다
문과 도어락 상태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html)에 적어 두었습니다.

한밤에는 이웃이 자는 시간이라 소음이 적은 방법부터 시도합니다. / 문과 도어락이 상하지 않게 덜 상하는 방법부터 차례로 합니다.
작업 중에 바꿔야 할 부품이 보이면 손대기 전에 미리 말씀드립니다. / 한밤 시간대 연락 요령은 [열쇠 부르기 안내](key-call.html)에도 적어 두었습니다.

# 열고 난 뒤 다시 막히지 않게
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 눌러 봅니다. / 배터리가 원인이었다면 새 배터리로 바꿨는지 함께 봅니다.
- 배터리는 한꺼번에 모두 교체하기
- 번호판이 느려지면 그날 바로 점검하기
- 가족과 비밀번호를 같이 정하고 카드키 하나는 따로 보관
- 비상용 9V 건전지 하나를 가방에 넣기
고장이 잦다면 [도어락 수리](doorlock-repair.html)로 먼저 보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 죽전동 말고 용인 어디든 갑니다
죽전동 가까운 풍덕천동, 보정동, 마북동, 기흥역 쪽도 다닙니다. / 용인 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html)에, 서울·경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
