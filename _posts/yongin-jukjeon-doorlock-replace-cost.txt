# 죽전동에서 도어락을 바꿔야 하나 고민된다면
죽전동은 죽전역을 중심으로 입주한 지 시간이 지난 아파트와 빌라가 함께 있는 동네입니다. / 도어락이 오래되면 한 번 바꿔야 하나 고민하는 분이 꾸준히 계십니다.
이 글은 교체를 결정하기 전에 확인할 것과, 교체가 필요할 때 비용을 어떻게 안내하는지 정리한 글입니다. / 꼭 바꾸지 않아도 되는 경우도 같이 적었습니다.
@ 죽전동 도어락 교체 출장열쇠

# 바꾸지 않고 고칠 수 있는 증상
도어락이 이상하다고 모두 교체해야 하는 건 아닙니다. / 배터리가 닳았거나 번호판 접점이 더러워서 생기는 문제는 손만 보면 해결됩니다.
- 번호판이 가끔 먹통이 되는데 배터리를 안 갈았을 때
- 문이 덜 닫히는 느낌이 있을 때
- 손잡이가 헐렁하게 돌아갈 때
이런 경우는 수리로 끝나는 일이 많아서 [도어락 수리](doorlock-repair.html)를 먼저 권합니다.

# 교체를 생각해 볼 만한 때
고쳐도 다시 같은 증상이 나온다면 교체를 이야기할 때입니다. / 부품을 구하기 어려울 만큼 오래된 제품도 마찬가지입니다.
번호를 눌러도 반응이 들쭉날쭉하거나, 모터 소리가 점점 약해지는 것도 신호입니다. / 이사 후 이전 사용자가 등록한 키를 모두 지우고 싶을 때도 교체를 많이 합니다.
어느 쪽인지는 직접 보고 말씀드립니다.

# 교체 전에 문 두께를 먼저 확인하세요
도어락은 문 두께에 맞는 제품이어야 합니다. / 얇은 문과 두꺼운 문은 쓰는 본체가 달라서, 맞지 않는 제품을 사면 설치가 안 됩니다.
안쪽 손잡이 방향이 오른쪽인지 왼쪽인지도 확인해야 합니다. / 이 두 가지만 알아도 제품을 고르는 시간이 줄어듭니다.
@ 용인 죽전동 도어락 설치 열쇠집

# 교체 전에 사진 두 장만 찍어 두세요
지금 도어락의 바깥쪽과 안쪽 모습을 각각 한 장씩 찍어 두세요. / 손잡이 모양과 본체 크기를 알면 어떤 제품이 들어갈지 미리 가늠할 수 있습니다.
문 옆면의 걸쇠 쪽도 한 장 찍어 두면 좋습니다. / 사진을 문자로 받으면 출발하기 전에 필요한 부품을 챙길 수 있어 현장에서 기다리는 시간이 줄어듭니다.
사진이 없다면 그냥 전화로 말씀해 주셔도 괜찮습니다.

# 제품을 직접 사서 부르실 때 알려주실 것
직접 구매한 제품이 있다면 모델명이나 사진을 미리 보내주세요. / 구멍 크기가 맞는지 확인하고 출발하면 헛걸음을 줄일 수 있습니다.
제품이 아직 없다면 문 사진과 지금 도어락 사진을 보내주셔도 됩니다. / 어떤 형태가 어울리는지 설명해 드립니다.
꼭 새 제품을 권하지는 않습니다.

# 주키·보조키 방식, 이렇게 달라요
도어락은 크게 번호 입력형, 카드형, 지문형으로 나뉘고, 손잡이 일체형과 버튼형으로도 나뉩니다. / 용도에 맞게 고르면 됩니다.
가족이 많거나 아이가 열쇠를 자주 잃어버리는 집은 카드나 번호형이 편합니다. / 손이 젖거나 장갑을 자주 끼는 분은 지문형이 불편할 수 있습니다.
무엇이 좋다고 정해 드리기보다 사시는 방식을 듣고 말씀드립니다. / 죽전역 근처 빌라나 오래된 단지는 문 두께와 모양이 제각각이라 직접 보고 고르는 게 가장 정확합니다.

# 비용은 문을 열기 전에 말씀드립니다
작업 전에 제품과 작업 내용을 설명하고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
작업 중에 말없이 비용이 붙는 일은 없습니다. / 문틀을 손봐야 하거나 부품이 더 필요하면 해당 작업 전에 먼저 여쭤봅니다.
@ 죽전동 도어락 교체 비용 안내

# 같은 도어락을 오래 쓸수록 생기는 일
도어락은 하루에도 수십 번 여닫는 장치라 부품이 조금씩 닳습니다. / 번호판은 멀쩡한데 안쪽 모터나 걸쇠 쪽이 먼저 약해지는 일도 흔합니다.
문을 닫을 때 소리가 예전과 다르거나, 열릴 때 힘이 느껴지지 않는다면 점검 시기입니다. / 갑자기 안 열리기 전에 미리 보는 편이 시간도 마음도 덜 쓰입니다.

# 교체하는 날 진행 순서
1) 기존 도어락을 확인하고 교체 가능 여부를 봅니다.
2) 제품과 작업 내용, 비용을 말씀드립니다.
3) 동의하시면 기존 제품을 떼고 새 제품을 설치합니다.
4) 새 번호나 카드를 등록하고 여닫아 봅니다.
작업이 끝나면 한 번 더 문을 닫아 보면서 걸쇠 위치도 확인합니다. / 설치 방법은 [도어락 설치](doorlock-install.html)에도 적어 두었습니다.

# 교체 말고 번호판만 손봐도 되는 경우
번호판 한 부분만 눌리지 않는 경우는 본체 전체를 바꾸지 않고 접점만 정리해도 돌아오기도 합니다. / 물기가 스며든 흔적이 있으면 말려서 쓸 수 있는지도 먼저 봅니다.
아이들이 자주 만지는 집은 버튼 표면이 닳아 반응이 둔해지기도 합니다. / 이런 증상은 현장에서 확인해야 정확하게 말씀드릴 수 있습니다.

# 이전 번호와 카드는 모두 지우세요
교체한 뒤에는 이전에 등록된 번호나 카드가 남아 있는지 확인합니다. / 이사 오신 집이라면 이 부분이 특히 중요합니다.
새로 설치한 도어락은 새 번호만 남기도록 정리합니다. / 가족이 쓸 번호는 직접 정해 주시면 안쪽에서 등록하는 방법까지 알려드립니다.

# 교체 후 첫 한 달이 중요합니다
새 도어락도 처음엔 문 틈이나 걸쇠 위치가 안 맞아 헐거울 수 있습니다. / 사용하다가 이상하면 말씀 주세요.
배터리 교체 시기를 달력에 적어 두는 것도 방법입니다. / 번호판이 느려지거나 경고음이 나면 그날 바로 건전지를 바꾸세요.
- 건전지는 전부 같은 날 새것으로 교체
- 번호판은 마른 수건으로만 닦기
- 문을 세게 닫지 않기

# 죽전동 말고 용인 어디든
죽전동 바로 옆 풍덕천동, 상현동, 보정동, 마북동, 구갈동도 다닙니다. / 용인 안이면 동네 상관없이 24시간 출동합니다.
용인 지역은 [용인시 출장열쇠](yongin.html)에 정리해 두었고, 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 문 개문이 먼저 필요하면 [현관문 개문](door-open.html)도 보세요.
