# 평소에는 몰랐던 문 안쪽의 문제
죽전동은 죽전역 주변으로 주거지와 상가가 이어져 있어 늦은 시간까지 사람이 오가는 곳입니다. / 그런 동네에서도 정작 집 안쪽에서 문이 잘 열리는지 점검해 본 분은 드뭅니다.
문 열림은 보통 바깥에서 들어올 때만 생각하게 됩니다. / 그러나 비상시에는 안에서 얼마나 빨리 나갈 수 있는가가 더 중요해집니다.
이 글은 죽전동 집에서 비상 상황을 가정해 안쪽 문이 잘 열리는지 점검하는 순서를 정리했습니다. / 불안을 키우려는 글이 아니라 한 번 확인해 두자는 취지입니다.
@ 죽전동 집 현관문 안쪽 손잡이와 보조키

# 점검은 평소 조용한 낮에
점검은 가족이 모두 집에 있고 서두를 일이 없는 낮 시간에 하는 것이 좋습니다. / 급한 상황이 아닐 때 해 봐야 문제를 차분히 볼 수 있습니다.
점검표를 따로 만들 필요는 없고, 확인한 것만 휴대폰 메모에 적어 두면 충분합니다. / 나중에 상담할 때 증상을 설명하기가 쉬워집니다.
점검하기 전에 가족에게 알려 두세요. / 아이나 어르신이 놀라지 않도록 미리 말해 두는 것이 예의입니다.
문 바깥에 사람이 갇히는 일이 없게 문밖을 먼저 확인하고 시작하세요.

# 안쪽 손잡이를 한 번에 돌려 보기
현관문 안쪽 손잡이를 돌렸을 때 걸쇠가 한 번에 빠지는지 봅니다. / 잠겨 있던 문이라면 돌림 하나로 열려야 정상입니다.
돌리는 도중에 걸리거나 힘을 많이 줘야 한다면 이상 신호입니다. / 손잡이가 헐겁게 헛도는 것도 점검 대상입니다. / 손잡이를 놓았을 때 원래 자리로 돌아오지 않는 것도 부품이 닳았다는 신호입니다.
- 손잡이를 돌릴 때 걸리는 소리나 느낌이 있는지
- 한 번에 열리는지, 두 번 이상 돌려야 하는지
- 문을 밀 때 문틀에 걸리지는 않는지

# 보조키와 안쪽 잠금 풀기
도어락 아래에 따로 달린 보조키는 안쪽 손잡이 하나로 풀리는 형태가 일반적입니다. / 열쇠가 있어야만 풀리는 구조라면 비상시에 불편할 수 있습니다.
아이나 어르신이 혼자 있을 때 풀기 어려운 방식인지도 생각해 보세요. / 비밀번호 방식 도어락이라도 안쪽 레버는 열쇠 없이 열려야 합니다.
안쪽 잠금이 이상하게 뻑뻑하다면 방치하지 말고 점검받는 것이 좋습니다. / 평소 한 손으로 쉽게 열 수 있는지, 두 손이 필요한지 기억해 보세요.
불이 꺼진 어두운 상황을 떠올리며 눈을 감고 손잡이 위치를 찾아 보는 연습도 도움이 됩니다. / 위치를 몸이 기억하고 있으면 급할 때 덜 당황합니다.

# 문틀과 경첩 처짐 확인
문이 처지면 안쪽에서 풀어도 걸쇠가 문틀에 걸려 안 빠질 수 있습니다. / 문을 닫고 걸쇠가 들어가는 구멍과 걸쇠 높이가 맞는지 눈으로 보세요.
- 문 윗부분 틈이 한쪽만 좁은지
- 경첩 나사가 풀려 있는지
- 문을 닫을 때 바닥에 쓸리는 소리가 나는지
틈이 한쪽으로 쏠리면 경첩이나 문틀 쪽 점검이 필요합니다. / 이런 경우 [현관문 점검](door-open.html)을 먼저 상담해 보세요.
@ 현관문 윗부분 틈과 경첩 나사 확인

# 문 앞에 짐을 쌓아 두지 않기
복도식이든 계단식이든 현관 앞에 자전거나 상자를 쌓아 두면 비상 때 방해가 됩니다. / 문이 끝까지 열려야 하는데 물건에 막히면 점검하나 마나입니다.
현관 안쪽도 마찬가지입니다. / 신발장이나 우산통이 문 열림 반경을 가리지는 않는지 보세요.
공용 복도에는 개인 짐을 두지 않는 것이 이웃 모두를 위한 약속입니다. / 관리 규정이 있으면 따르시기 바랍니다.
문 안쪽에 걸어 둔 가방이나 옷이 손잡이에 걸려 열림을 방해하는 일도 있습니다. / 평소 손잡이 주변을 비워 두세요.

# 비밀번호와 카드 없이도 나갈 수 있어야
도어락이 고장 나 먹통이 되더라도 안쪽에서는 열려야 합니다. / 안쪽에서 번호를 눌러야만 열리는 구조는 비상용으로 맞지 않습니다.
평소에 안쪽 레버나 버튼 방식이 어떻게 되는지 가족 모두가 알고 있는지 확인하세요. / 특히 어린 아이는 한 번 연습해 보면 좋습니다. / 연습할 때는 놀이처럼 가볍게 하고, 평소에 문 근처에서 장난치지 않게 알려 주세요.
어르신이 계신 집이라면 손잡이가 무겁지 않은지도 같이 봐 주세요. / 손힘이 약한 분은 작은 걸림에도 열기 어려울 수 있습니다.
배터리가 방전된 상태에서도 안쪽 손잡이는 움직이는지 한 번쯤 생각해 두세요.

# 시험으로 해 볼 것과 하지 말 것
점검은 열리는지 보는 것이지, 문을 실험하는 것이 아닙니다. / 다음 행동은 피해 주세요.
- 문을 닫은 채 공구로 걸쇠를 억지로 건드리는 것
- 잠금 상태에서 손잡이를 세게 비틀어 보는 것
- 도어락을 분해해서 확인하는 것
- 번호를 여러 번 일부러 틀려 보는 것
이상이 느껴지면 더 만지지 말고 상태를 메모해 두세요. / 어떤 때 어떻게 걸렸는지 적어 두면 설명이 쉬워집니다.
문이 안쪽에서 안 열리는 상황이 실제로 생기면 침착하게 안에서 구조를 요청하는 것이 먼저입니다. / 위급하면 119에 먼저 연락하세요.

# 이상이 있을 때 출장열쇠를 부르세요
점검하다 걸림이나 헛돎이 확인되면 [죽전동 용인 출장열쇠](yongin.html)에 상태를 알려 주세요. / 도어락 부품을 보는 것은 [도어락 수리](doorlock-repair.html)에서 안내합니다.
전화하실 때는 아래를 알려 주시면 됩니다.
- 안쪽 손잡이를 돌렸을 때의 증상
- 도어락 종류(손잡이형, 푸시풀형, 보조키 유무)
- 문 상태(처짐, 틈, 소리)
- 아이나 어르신이 집에 있는지
사진을 문자로 보내 주시면 맞는 부품과 도구를 챙길 수 있습니다.

# 신분 확인과 비용 안내
점검 상담 때도 사시는 분인지 확인합니다. / 신분증 주소, 우편물, 관리사무소 확인 중 하나면 충분합니다.
비용은 상태를 보고 작업 전에 먼저 말씀드립니다. / 동의하시면 진행하고 아니면 그대로 돌아갑니다.
끝내 해결하지 못하면 비용은 받지 않습니다. / 부품을 교체해야 하면 바꾸기 전에 따로 여쭤봅니다.
@ 죽전동 도어락 안쪽 레버 점검 작업

# 한번 점검한 뒤의 관리
점검이 끝나면 문제가 없더라도 반기에 한 번 정도 다시 해 보세요. / 날이 풀리거나 추워질 때 문틀이 바뀌기도 합니다.
- 가족에게 비상시 문 여는 방법을 한 번 설명하기
- 배터리는 해가 바뀔 때쯤 교체하기
- 문 앞 통로 비워 두기
- 이상이 있으면 미루지 말고 연락하기
[도어락 교체](doorlock-replace.html)가 필요할 만큼 오래된 제품이라면 그때 말씀드립니다. / 쓸 수 있는 제품이면 교체를 권하지 않습니다.

# 죽전동 말고 용인 어디든
죽전동과 가까운 풍덕천동, 상현동, 성복동, 보정동도 다닙니다. / 죽전역, 수지구청역, 기흥역, 동백역 근처 어디든 연락 주세요.
다른 지역은 [출장 지역](area.html)을 보시고, 진행 안내는 [이용안내](guide.html)에서 확인하세요.

# 자주 묻는 질문
? 안쪽 문이 잘 열리는지 점검만 부탁해도 되나요? | 네, 상태를 보고 필요한 부분만 말씀드립니다. 사진을 먼저 보내 주셔도 됩니다.
? 점검 후 아무 문제가 없으면 비용이 드나요? | 작업 전에 비용을 먼저 말씀드리고 동의하신 뒤에 진행합니다. 못 해결하면 받지 않습니다.
? 안쪽 손잡이가 헛돌아요. | 더 돌리지 마시고 그대로 연락 주세요. 손잡이 축 문제일 수 있습니다.
? 아이가 혼자 문을 열 수 있게 바꿀 수 있나요? | 도어락 종류에 따라 안쪽 해제 방식이 다릅니다. 상태를 보고 말씀드립니다.
? 밤에도 상담이 되나요? | 24시간 받습니다. 문이 안 열려 급한 상황이라면 바로 전화 주세요.
