# 죽전동 소형 운동 공간, 출입문이 멈추면 하루가 멈춥니다
죽전역 주변 생활권에는 작은 헬스장과 필라테스 스튜디오처럼 소규모로 운영하는 운동 공간이 여럿 있습니다. / 원장님 한 분이 열고 닫는 곳이 많아서 출입문이 한 번 말썽이면 수업 전체가 흔들립니다.
새벽 수업을 여는 날 문이 안 열리거나 회원이 입장하는 도중 도어락이 먹통이 되면 곤란해집니다. / 그래서 원인을 빨리 가르는 요령을 알아 두면 도움이 됩니다.
이 글은 소규모 운동 공간 출입문이 잠기거나 안 열릴 때의 확인 순서를 적었습니다. / 미리 점검해 둘 습관과 함께 [용인 출장열쇠](yongin.html)를 부를 때 진행 방식도 담았습니다.
@ 죽전동 소형 필라테스 스튜디오 출입문

# 운동 공간 출입문이 유난히 고장 나기 쉬운 이유
출입 횟수가 일반 가정보다 훨씬 많습니다. / 회원이 오가며 문을 밀고 당기다 보면 도어락 부품과 문 닫힘 장치에 부담이 쌓입니다.
땀과 습기가 많은 환경도 영향을 줍니다. / 샤워실이나 탈의 공간 쪽 습기가 출입문 쪽 번호판과 접점에 영향을 주기도 합니다.
문 앞에 짐이나 매트를 두는 일이 잦아 문이 끝까지 닫히지 않은 채 방치되기도 합니다. / 이런 사소한 반복이 걸쇠와 센서에 무리를 줍니다.

# 도어락 종류별로 고장 양상이 다릅니다
가게 출입문에는 번호식, 카드식, 지문식, 열쇠식이 섞여 쓰입니다. / 어떤 방식이냐에 따라 먼저 의심할 곳이 달라집니다.
- 번호식은 배터리 방전과 번호판 마모
- 카드식은 카드 인식부 오염과 등록 카드 수 관리
- 지문식은 센서 오염과 땀, 물기 영향
- 열쇠식은 실린더 마모와 열쇠 복사본 불량
회원 카드나 지문을 여러 명이 함께 쓰는 곳이라면 등록 정보 관리도 중요합니다. / 퇴사한 강사의 카드가 계속 살아 있지 않은지도 한번 점검해 보세요.

# 문이 안 열릴 때 1분 확인
번호판이 켜지는지, 눌렀을 때 소리가 나는지부터 보세요. / 켜지지 않으면 배터리 문제, 소리는 나는데 안 열리면 모터나 걸쇠 문제일 수 있습니다.
문이 문틀에 꽉 끼어 있지는 않은지도 확인해 보세요. / 한 손으로 문을 안쪽으로 살짝 밀면서 손잡이를 돌리면 열리는 경우가 있습니다.
수업 시작 직전에는 마음이 급해져서 손잡이를 세게 당기게 되는데 그러면 더 꽉 물립니다. / 한 번 숨을 고르고 순서대로 보시는 것이 오히려 빠릅니다.

# 수업 중 안에 사람이 있을 때는 이렇게 하세요
안에 회원이 있는데 문이 잠겨 열리지 않는다면 먼저 안에 있는 분께 안쪽 손잡이나 잠금장치를 확인해 달라고 하세요. / 밖에서만 보지 말고 안쪽 상태를 전달받는 것이 중요합니다.
안전과 관련된 상황이면 망설이지 말고 119에 먼저 연락하는 것이 우선입니다. / 단순히 문이 안 열리는 상황이라면 안에 있는 분이 침착하게 기다릴 수 있도록 계속 소통해 주세요.
@ 죽전동 헬스장 출입문 도어락 점검

# 비상구와 출입문은 구분해서 생각하세요
운동 공간에는 평소 쓰는 출입문과 비상시 쓰는 문이 따로 있을 수 있습니다. / 두 문을 같은 방식으로 잠그고 열면 안 되는 경우가 있습니다.
비상구는 안쪽에서 항상 열 수 있어야 하는 것이 기본 원칙입니다. / 잠금장치를 추가하거나 바꾸려면 건물과 시설 규정을 먼저 확인하는 것이 좋습니다.
정확한 기준은 관리 주체나 관련 기관에 문의하셔야 하고, 저희는 규정을 대신 판단해 드리지는 않습니다. / 다만 현장에서 문이 어떻게 구성돼 있는지 보고 작업 가능한 범위를 설명드립니다.

# 출근하는 사람이 여럿일 때 번호 관리
강사가 여럿이면 번호를 공유하는 일이 많습니다. / 한 번호를 오래 같이 쓰면 누가 마지막에 문을 잠갔는지 알기 어렵습니다.
가능하다면 사람별 번호나 카드를 따로 등록해 쓰는 방식이 낫습니다. / 사람이 바뀔 때 해당 번호만 지우면 되기 때문입니다.
번호 변경 날짜를 정해 두고 직원이 바뀔 때마다 갱신하는 습관도 좋습니다. / 이는 도어락 교체 상담을 받을 때도 유용한 기준이 됩니다.

# 영업 마치고 잠그는 순서를 정해 두세요
마감 때 뒷정리를 하다 보면 문 닫힘 확인을 빼먹기 쉽습니다. / 문이 완전히 닫혔는지 소리와 눈으로 한 번씩 확인하는 습관이 필요합니다.
- 마감 전 안쪽 조명과 장비 전원 점검
- 문이 걸쇠까지 끝까지 닫혔는지 확인
- 번호판이나 카드 인식부에 물기가 있으면 닦기
- 보조 잠금장치가 있다면 열쇠를 어디에 두는지 정해 두기
열쇠를 안에 두고 나와 잠기는 일도 마감 때 자주 생깁니다. / 열쇠 보관 위치를 고정해 두면 이런 실수가 크게 줄어듭니다.

# 도어클로저와 문 닫힘 상태도 같이 보세요
상가나 스튜디오 문에는 문이 천천히 닫히게 하는 도어클로저가 달려 있는 경우가 많습니다. / 클로저가 너무 빠르거나 약하면 걸쇠가 제대로 들어가지 않습니다.
문이 닫히다 마지막에 살짝 걸리는 느낌이 있다면 도어락보다 클로저와 경첩 문제일 수 있습니다. / 이럴 때는 [도어락 수리](doorlock-repair.html)를 요청하시면 문 전체 상태를 같이 봅니다.
@ 죽전동 상가 출입문 도어클로저 걸쇠 확인

# 가게 문 앞에서도 신분 확인은 합니다
임대 공간이라 명의가 다르거나 대표자가 따로 있는 경우도 있습니다. / 문을 열기 전에 이 공간을 쓰는 분이 맞는지 확인하는 절차는 가정집과 같습니다.
사업자등록증이나 계약서, 운영 중임을 보여 주는 서류, 건물 관리 쪽 확인 가운데 가능한 것으로 확인합니다. / 개인 신분증과 함께 주소가 나온 우편물을 준비하시면 수월합니다.
확인이 어려우면 작업을 할 수 없으니 방문 전에 미리 알려 주세요. / 신원 확인은 이웃 점포와 건물 모두를 위한 안전장치입니다.

# 전화하실 때 알려주시면 좋은 내용
운동 공간은 시간이 곧 수업이라 빠른 파악이 중요합니다. / 아래 내용을 알려 주시면 준비가 훨씬 빨라집니다.
- 건물 위치와 층, 호실
- 번호식, 카드식, 지문식, 열쇠식 중 어느 방식인지
- 번호판 상태와 들리는 소리
- 안에 사람이 있는지, 몇 시 수업이 있는지
- 문이 유리문인지, 철문인지, 목문인지
문 사진을 한 장 보내 주시면 챙겨 갈 장비를 정하기 좋습니다.

# 비용 안내와 진행 방식
문 종류와 도어락 방식, 작업 난이도를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
끝내 열지 못하면 비용은 받지 않으며, 열고 난 뒤 말없이 붙는 비용도 없습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에, 문을 여는 방법은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.
