# 도어락은 사기 전에 문부터 봐야 합니다
죽전동은 죽전역과 근처 상가 생활권을 따라 아파트와 빌라가 이어지는 동네입니다. / 도어락을 새로 달거나 바꾸려는 분들이 제품부터 고르다가 문에 안 맞아서 낭패를 보는 일이 종종 있습니다.
도어락은 디자인이나 기능보다 먼저 내 현관문에 들어갈 수 있는지가 기준입니다. / 이 글은 설치 전에 집에서 직접 해볼 수 있는 확인 방법을 순서대로 정리했습니다.
설치 자체가 궁금하시면 [도어락 설치](doorlock-install.html) 페이지도 같이 보세요.
@ 죽전동 도어락 설치 전 문 두께 확인

# 문 두께는 어디서 어떻게 재나
문을 열고 문이 닫히는 쪽 가장자리를 보면 문의 옆면이 보입니다. / 이 옆면의 폭이 문 두께입니다.
줄자를 문 옆면에 직각으로 대고 밀리미터 단위까지 확인해 보세요. / 도어락마다 지원하는 문 두께 범위가 정해져 있어서 이 숫자가 중요합니다.
문 가장자리에 덧댄 몰딩이나 방풍 고무 때문에 폭이 달라 보이기도 합니다. / 가능하면 손잡이 근처 평평한 곳에서 재는 것이 정확합니다.
측정이 어렵거나 숫자가 애매하면 사진을 찍어 두었다가 전화 때 말씀해 주세요.
줄자가 없다면 자나 카드 같은 물건을 옆에 두고 사진을 찍어도 대략 가늠할 수 있습니다. / 두꺼운 문과 얇은 문은 쓸 수 있는 제품 범위가 달라서 이 숫자 하나가 선택을 크게 줄여 줍니다.

# 기존 도어락 구멍 모양 확인하기
이미 도어락이 달려 있다면 바깥에서 몸체를 보세요. / 손잡이 일체형인지, 버튼만 있는 형인지, 밀고 당기는 형인지에 따라 필요한 구멍이 다릅니다.
안쪽 몸체를 열어 보면 문에 뚫린 큰 구멍이 보입니다. / 그 구멍의 지름과 위치가 새 제품의 부품과 맞아야 합니다.
구멍이 크게 어긋나면 문을 다시 뚫어야 할 수 있어서 설치 전에 반드시 확인해야 합니다. / 이런 경우는 문 상태와 함께 현장에서 보고 방법을 말씀드립니다.
문 안쪽에 덧댄 판이나 보강재가 있는 집도 있습니다. / 처음 설치한 시기가 달라 같은 단지에서도 구멍 위치가 다른 경우가 있으니 이웃집 사례를 그대로 믿지 마세요.

# 보조키가 있는 문과 없는 문의 차이
보조키는 도어락 위쪽이나 아래쪽에 따로 달린 열쇠형 잠금입니다. / 있는 문이라면 도어락과 보조키를 같이 쓸지, 보조키를 떼고 하나로 정리할지 먼저 정합니다.
보조키 위치가 새 도어락 몸체와 겹치면 설치할 수 없는 경우도 있습니다. / 이럴 땐 높이 차이를 확인한 뒤 맞는 제품을 고릅니다.
보조키를 유지하는 것이 방범과 고장 대비에 도움이 되는 집도 있습니다. / 판단은 현장에서 문을 보고 함께 정합니다.
보조키를 빼고 구멍을 막는 마감 작업이 필요한 집도 있습니다. / 이 경우 문 색과 맞는 마감재가 있는지도 같이 봅니다.
@ 용인 죽전동 현관문 보조키 구멍 확인

# 문 재질이 설치 방법을 바꿉니다
철문, 목재문, 방화문처럼 재질마다 단단한 정도와 속 구조가 다릅니다. / 철문은 구멍을 새로 뚫기 어렵고, 속이 비어 있는 문은 나사 고정이 약할 수 있습니다.
특히 방화문은 구멍을 함부로 넓히면 안 되는 경우가 있습니다. / 어떤 문인지 사진으로 알려 주시면 사전에 판단하기 수월합니다.
죽전동 같은 아파트 단지는 같은 동 안에서도 문 재질이 층마다 다를 수 있습니다. / 이웃집 문이 괜찮았다고 우리 집도 괜찮다고 보기는 어렵습니다.

# 전화하면 이런 것을 여쭤봅니다
설치 문의를 하면 몇 가지를 먼저 물어봅니다. / 미리 알고 계시면 통화가 짧아집니다.
- 지금 달려 있는 도어락이 있는지, 처음 다는 것인지
- 문 두께를 재 봤는지
- 보조키가 있는지, 그대로 둘지
- 지문, 카드, 비밀번호 중 쓰고 싶은 방식
- 전체 사용 인원과 집 안에 노약자나 아이가 있는지
이 정보가 모이면 맞는 제품을 몇 가지 추려서 말씀드릴 수 있습니다. / 한 가지 제품만 권하는 방식이 아니라 상황에 맞는 선택지를 보여 드립니다.

# 미리 정해 두면 좋은 쓰임새
가족이 몇 명인지, 손님이 자주 오는지에 따라 필요한 기능이 다릅니다. / 아이 혼자 들어오는 집이면 카드나 지문이 편합니다.
어르신이 쓰는 집은 번호가 큰 번호판이나 소리 안내가 있는 제품이 낫습니다. / 기능이 많다고 무조건 좋은 것은 아닙니다.
스마트 기능을 꼭 써야 하는지도 한번 생각해 보세요. / 고르는 법은 [도어락 교체](doorlock-replace.html) 페이지에도 정리해 두었습니다.

# 비용 이야기는 보고 나서 먼저 드립니다
문 두께와 구멍 상태, 제품 종류에 따라 설치 비용이 달라지므로 전화만으로 정할 수 없습니다. / 현장에서 문을 확인한 뒤 열기 전에 먼저 말씀드립니다.
괜찮다고 하시면 진행하고, 아니면 그대로 돌아갑니다. / 말없이 추가되는 비용은 없습니다.
설치 도중 문 상태 때문에 부품이 더 필요해지면 하기 전에 따로 여쭙니다. / 자세한 진행은 [이용안내](guide.html)에 적어 두었습니다.
@ 죽전동 열쇠 출장 도어락 설치 진행

# 사시는 분 확인은 설치에서도 합니다
설치는 문을 건드리는 일이라 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
임대로 사시는 경우 집주인이 교체해도 되는지 미리 확인해 두시면 좋습니다. / 법적인 판단은 드릴 수 없으니 계약서와 집주인 의견을 먼저 확인해 주세요.
기존 도어락을 떼는 경우 원래 제품을 돌려드릴 수 있는지도 말씀해 주세요.
설치 도중 먼지나 부스러기가 생길 수 있으니 현관 앞 신발과 바닥을 미리 치워 두시면 좋습니다. / 작업은 보통 현관 앞에서 이루어지므로 집 안으로 들어가는 일은 많지 않습니다.

# 설치하는 날 진행 순서
도착하면 문 상태를 눈으로 확인하고 측정합니다. / 미리 알려 주신 정보와 다르면 그때 제품을 다시 맞춥니다.
기존 도어락을 떼고 구멍 상태를 보고, 새 제품을 맞춰 달아 봅니다. / 비밀번호나 카드를 등록하고 여러 번 잠그고 열어 보며 확인합니다.
설치 후에는 문이 정확히 닫히고 걸쇠가 문틀에 맞는지도 봅니다. / 문틀이 처져 있으면 도어락만 새것이어도 계속 문제가 생기기 때문입니다.

# 설치하고 나서 챙길 것
사용 설명서와 보증 내용은 서랍에 따로 두세요. / 비밀번호는 가족에게 공유하되 메모로 현관 근처에 붙여 두는 것은 피해 주세요.
카드나 열쇠는 한 개씩 가족 구성원이 나눠 갖고, 여분 한 개는 따로 보관합니다. / 배터리가 줄어들 때 나는 경고음이 어떤 소리인지도 한번 들어 두세요.
작동이 이상하면 바로 연락 주시면 [도어락 수리](doorlock-repair.html) 쪽으로 상태를 봐 드립니다. / 처음 설정을 잘 해 두면 이후 관리가 한결 쉽습니다.

# 죽전동 말고 용인 다른 동네도 같습니다
죽전동 옆 동천동, 풍덕천동, 상현동, 신봉동 같은 수지 쪽은 물론 기흥과 처인까지 다닙니다. / 용인 안이면 어디든 24시간 출동합니다.
동네 목록은 [용인 출장열쇠](yongin.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html) 안내에서 보실 수 있습니다.

? 비용은 언제 알 수 있나요? | 문을 확인한 뒤 작업하기 전에 먼저 말씀드립니다.
