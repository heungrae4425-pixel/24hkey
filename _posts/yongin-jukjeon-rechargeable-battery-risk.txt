# 죽전동 도어락, 충전식 건전지가 의심스러울 때
죽전동은 죽전역을 오가는 출퇴근 인구가 많고, 아파트와 빌라, 상가 건물이 골고루 섞여 있는 생활권입니다. / 이런 동네에서는 집 안 물건을 아껴 쓰려고 충전식 건전지를 도어락에 넣는 분들도 꽤 계십니다.
그런데 충전식 건전지를 넣은 뒤로 번호판이 갑자기 꺼지거나 경고음이 자주 울린다는 연락이 이어집니다. / 이 글은 그런 증상이 왜 생기는지, 문 앞에서 무엇부터 해볼지를 적었습니다.
[용인 출장열쇠](yongin.html)를 부르기 전에 읽어 두시면 불필요한 걱정을 줄일 수 있습니다.
@ 죽전동 도어락 충전식 건전지 교체 점검

# 일반 건전지와 충전식은 전압이 다릅니다
보통 도어락에 쓰는 일회용 알카라인 건전지는 한 알에 1.5V 정도이고, 충전식 니켈수소 건전지는 1.2V 정도입니다. / 숫자로는 작은 차이 같지만 네 알을 직렬로 넣으면 합계 전압이 확실히 낮아집니다.
도어락은 전압이 일정 수준 아래로 내려가면 배터리 부족 경고를 울리도록 만들어진 경우가 많습니다. / 그래서 충전식을 넣으면 새로 충전한 직후에도 경고음이 날 수 있습니다.
제품에 따라서는 처음부터 충전식을 쓰지 말라고 안내하기도 합니다. / 정확한 내용은 도어락 안쪽 덮개나 사용 설명서의 배터리 표기를 확인해 보시는 게 가장 확실합니다.

# 충전식을 넣었을 때 흔히 나타나는 증상
증상은 대체로 비슷하게 나타납니다. / 아래 중 해당하는 게 있는지 떠올려 보세요.
- 충전 직후에는 잘 되다가 며칠 만에 번호판이 꺼지는 경우
- 배터리 부족 경고음이 울리는데 실제로는 방금 충전한 경우
- 번호는 눌리는데 모터가 힘없이 돌다 멈추는 경우
- 낮에는 되다가 추운 아침에만 반응이 느린 경우
이런 증상은 고장이라기보다 전압이 모자라서 나오는 경우가 많습니다. / 그래서 도어락 본체를 뜯기 전에 전원부터 의심해 보는 편이 순서에 맞습니다.

# 충전식은 갑자기 꺼지는 성질이 있습니다
일회용 건전지는 쓸수록 전압이 서서히 내려가서 경고음이 미리 울려 줍니다. / 반면 충전식은 거의 끝까지 일정한 전압을 유지하다가 한순간에 떨어지는 편입니다.
경고를 받을 시간 없이 출근길이나 귀가 때 갑자기 번호판이 꺼질 수 있다는 뜻입니다. / 죽전역에서 걸어와 문 앞에 섰는데 반응이 없다면 이런 경우일 가능성이 있습니다.
또 충전식은 쓰지 않고 두어도 스스로 조금씩 방전됩니다. / 몇 주 집을 비웠다 돌아오면 이미 힘이 빠져 있을 수 있습니다.

# 문 앞에서 해볼 수 있는 순서
번호판이 꺼졌을 때는 차분하게 아래 순서로 보시면 됩니다. / 급하다고 손잡이를 세게 돌리면 오히려 걸쇠가 더 꽉 물립니다.
- 번호판을 손바닥으로 덮어 약하게라도 불이 들어오는지 확인
- 바깥쪽 아래에 9V 비상 단자가 있는지 확인
- 있다면 9V 건전지를 대고 번호 입력
- 문이 열리면 안쪽 배터리 칸을 열어 건전지를 모두 확인
비상 단자는 모든 제품에 있는 것이 아니라서, 없으면 그 방법은 쓸 수 없습니다. / 단자가 있는데도 반응이 없으면 그때 전화를 주시면 됩니다.

# 리튬이온 충전지나 다른 규격은 넣지 마세요
크기가 비슷하다고 다른 종류의 충전지를 넣는 분도 있습니다. / 규격이 맞지 않는 전지는 전압이 높거나 모양이 달라 접점이 상할 수 있습니다.
특히 전압이 높은 배터리를 억지로 끼우면 회로에 무리가 갑니다. / 도어락에 적혀 있는 규격 그대로만 쓰시길 권합니다.
같은 줄에 새것과 쓰던 것을 섞어 넣는 것도 피하세요. / 한 알만 약해도 전체가 금방 내려앉습니다.
@ 죽전동 번호판 꺼짐 9V 비상 전원

# 그래도 충전식을 쓰고 싶다면
환경을 생각해서 충전식을 꼭 쓰겠다는 분도 계십니다. / 그럴 때는 몇 가지만 지켜 주세요.
- 제품 설명서에서 충전식 사용 가능 여부 먼저 확인
- 네 알을 한 번에 같은 날 충전해서 같이 교체
- 충전 후 며칠 뒤에도 번호판이 잘 켜지는지 눈으로 확인
- 비상용 9V 건전지를 현관 서랍에 따로 두기
충전식이 맞지 않는 제품이라면 일회용 알카라인으로 돌아가는 편이 마음이 편합니다. / 도어락은 매일 문을 지키는 장치라서 예측 가능한 쪽이 낫습니다.

# 이럴 땐 억지로 하지 말고 전화 주세요
비상 전원을 대도 안 되거나, 소리는 나는데 걸쇠가 안 빠지면 전원 문제가 아닐 수 있습니다. / 그때는 도어락을 건드리지 말고 상태만 기억해 두셨다가 연락 주세요.
드라이버로 덮개를 벌리거나 카드를 문틈에 넣는 건 피하세요. / 문틀과 도어락 외관에 흠이 생기면 나중에 [도어락 수리](doorlock-repair.html)가 더 복잡해집니다.
집 안에 아이나 반려동물이 있다면 꼭 먼저 말씀해 주세요. / 그런 상황은 순서를 바꿔서 서둘러 가야 합니다.

# 전화하실 때 알려주면 빠른 내용
죽전동은 단지와 건물이 나뉘어 있어서 위치 설명이 정확할수록 도착이 빠릅니다. / 간단한 정보만 주셔도 충분합니다.
- 죽전역 기준 어느 방향인지, 건물 이름 대신 길 이름도 괜찮음
- 번호판이 켜지는지 꺼졌는지
- 최근에 건전지를 바꿨는지, 어떤 종류를 넣었는지
- 집 안에 사람이나 반려동물이 있는지
도어락 앞면과 배터리 칸을 찍어 문자로 보내 주시면 맞는 장비를 챙겨 가는 데 도움이 됩니다.

# 도착 후 신분 확인과 비용 안내
문을 여는 일이라 해당 집에 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 충분합니다.
번거로워 보여도 이웃과 집 주인 모두를 지키는 절차입니다. / 신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다.

문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 아니면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없고, 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.

# 문을 연 뒤에 같이 확인하는 것
문이 열리면 전원 상태를 먼저 같이 봅니다. / 배터리 접점이 지저분하거나 눌려 있지는 않은지도 확인합니다.
충전식 때문에 생긴 문제로 보이면 일회용 건전지로 바꾼 뒤 한동안 지켜보시길 권합니다. / 그래도 불안정하면 [도어락 교체](doorlock-replace.html)를 검토하되, 고쳐서 쓸 수 있으면 교체를 권하지 않습니다.
현관문을 여는 방식이 궁금하시면 [현관문 개문](door-open.html) 페이지를 참고하세요.
@ 죽전동 도어락 건전지 접점 확인

# 건전지 관리를 오래 편하게 하는 법
작은 습관이 문 앞에서 막히는 일을 많이 줄여 줍니다. / 아래 몇 가지만 해두면 충분합니다.
- 배터리 칸에 교체한 날짜 적어 두기
- 경고음이 나면 그날 바로 교체하기
- 오래 집을 비울 땐 출발 전에 전원 확인하기
- 9V 건전지 하나는 눈에 띄는 곳에 두기
가족과도 배터리 교체 담당을 정해 두면 서로 미루다가 방전되는 일을 막을 수 있습니다. / 열쇠 대신 번호를 쓰는 집일수록 전원이 곧 열쇠라고 생각하시면 됩니다.

# 죽전동 말고 용인 어디든 갑니다
죽전동 옆 동네는 물론 용인 안이면 동네와 상관없이 24시간 출동합니다. / 다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
