# 밤새 일하고 돌아온 문 앞에서
마북동은 죽전역과 기흥역 사이 생활권에서 출퇴근하는 분들이 많은 동네입니다. / 병원이나 요양시설, 돌봄 현장에서 밤을 새우고 아침 가까이 돌아오는 분들도 적지 않습니다.
몸은 지칠 대로 지쳤는데 번호를 눌러도 도어락이 반응하지 않으면 그 막막함은 말로 다 하기 어렵습니다. / 한숨 자고 다시 출근해야 하는 사람에게 문 앞에서 보내는 시간은 더 아깝습니다.
이 글은 야간 근무를 마치고 귀가한 길에 현관이 안 열릴 때 무엇부터 보고, 어떻게 연락하면 빨리 정리되는지 적었습니다. / [용인 출장열쇠](yongin.html)가 새벽에 어떻게 움직이는지도 함께 담았습니다.
@ 마북동 야간 근무 후 귀가 도어락 안 열림

# 야간 근무자에게 귀가 잠김이 잦은 이유
근무 시간이 불규칙한 분들은 집 도어락과 생활 리듬이 어긋나기 쉽습니다. / 며칠 연속 야간 근무를 하면 집에 머무는 시간이 짧아 배터리 경고음을 듣지 못하고 지나칩니다.
가족이 낮에 번호를 바꿨는데 알리지 못한 채 출근하신 경우도 있습니다. / 교대 근무라 서로 얼굴을 못 보는 가정에서 흔히 생기는 일입니다.
피곤한 상태에서는 번호를 한 자리씩 틀리게 누르기도 합니다. / 그래서 안 열린다고 느껴질 때 먼저 침착하게 확인하는 순서가 필요합니다.

# 문 앞에서 숨 고르고 확인할 세 가지
급할수록 순서를 지키면 오히려 빨라집니다. / 아래 세 가지만 보셔도 원인이 대부분 좁혀집니다.
- 번호판에 손바닥을 가져다 대면 불이 들어오는지
- 숫자를 누를 때 소리가 나는지, 경고음이 반복되는지
- 손잡이를 아래로 눌렀을 때 헛도는지, 딱딱하게 막혀 있는지
불이 아예 없다면 전원 문제일 가능성이 큽니다. / 소리는 나는데 안 열리면 모터나 걸쇠 쪽을 의심해 볼 수 있습니다.

# 근무복 주머니에 있어야 할 비상 대비
교대 근무하시는 분은 열쇠 한 벌을 휴대폰 케이스나 사물함에 넣어 두는 습관이 도움이 됩니다. / 도어락이 먹통이어도 기계식 열쇠가 있으면 문을 열 수 있는 제품이 많기 때문입니다.
번호판 아래에 9V 건전지를 대는 비상 단자가 있는 도어락도 많습니다. / 근처 편의점이 열려 있는 시간이라면 건전지를 사서 대 보고, 그래도 반응이 없을 때 연락 주시면 됩니다.
건전지로 문이 열리면 안쪽 배터리를 모두 새것으로 바꿔 두세요. / 일부만 바꾸면 며칠 뒤 같은 상황이 반복됩니다.

# 새벽에 하면 안 되는 행동
너무 피곤하고 짜증이 나더라도 손잡이를 세게 흔들거나 문을 두드리는 건 피해 주세요. / 새벽에는 소리가 이웃 집 안까지 울려서 민원으로 번지기 쉽습니다.
얇은 카드나 드라이버로 문틈을 벌리려는 분도 있지만 문틀과 도어락 외관이 먼저 상합니다. / 그러면 문은 열려도 수리할 곳이 생겨 일이 더 커집니다.
비밀번호를 여러 번 틀리면 도어락이 잠시 입력을 막습니다. / 서너 번 눌러 보고 안 되면 멈추고 숨을 돌리는 편이 낫습니다.
@ 새벽 귀가길 마북동 현관문 확인

# 이런 아침에 자주 연락이 옵니다
연락이 오는 상황은 비슷비슷합니다. / 내 경우와 닮았다면 혼자 오래 붙잡지 마시고 상황을 짧게 알려 주세요.
퇴근길에 편의점 다녀오다가 문이 닫혀 버린 경우가 있습니다. / 휴대폰과 열쇠가 모두 집 안에 있으면 이웃이나 경비실 전화를 빌려도 됩니다.
근무복 갈아입다 열쇠를 사물함에 두고 온 걸 집 앞에서 알아차린 경우도 있습니다. / 이럴 땐 전화로 열쇠 위치를 확인한 뒤 열기까지 얼마나 걸릴지 말씀드립니다.
잠든 가족이 있는데 초인종에 답이 없는 경우도 있습니다. / 이때는 안에 사람이 있다는 점을 꼭 먼저 알려 주세요.

# 연락하실 때 이 정도만 알려주세요
기운이 없을 때는 길게 설명하기도 힘듭니다. / 아래 항목만 짧게 말씀해 주시면 됩니다.
- 마북동 안 어느 동네나 단지 방향인지
- 아파트인지 빌라인지, 몇 층인지
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내 주시면 맞는 장비를 챙기기 좋습니다. / 건물 입구 비밀번호가 따로 있다면 함께 알려 주세요.

# 조용히 작업하는 게 먼저입니다
새벽 작업은 소리를 줄이는 게 기본입니다. / 문과 도어락을 상하지 않게 엽니다. 덜 상하는 방법부터 차례로 해봅니다.
이웃 잠을 깨우지 않도록 필요한 장비만 가져가서 짧게 끝내려고 합니다. / 계단이나 복도에서 불필요한 대화도 줄입니다.
현관문 개문이 어떤 방식인지는 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.
@ 조용히 진행하는 용인 출장열쇠 문 열기

# 도착하면 사시는 분인지 먼저 확인합니다
문을 여는 일이라 사시는 분이 맞는지 신분 확인을 먼저 합니다. / 신분증의 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
야간 근무 직후라 신분증을 근무처 사물함에 두고 오셨다면 미리 말씀해 주세요. / 휴대폰에 저장된 주소 서류나 관리사무소 확인으로 대신할 수 있는지 먼저 살펴봅니다.
번거로우셔도 이웃과 집주인 모두를 지키는 절차입니다. / 확인이 어려우면 작업을 하지 않습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 문을 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용은 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 열고 난 뒤, 다시 막히지 않게 정리
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리 때문이었다면 새 배터리로 바꿨는지도 봅니다.
가족이 바꾼 번호를 몰랐던 경우라면 이 기회에 가족 모두가 아는 번호로 정리해 두면 좋습니다. / 교대 근무 가족이 있다면 번호 변경 때 메신저로 바로 알리는 습관이 도움이 됩니다.
자주 고장 나는 제품이면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 낡았을 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 야간 근무자를 위한 도어락 관리 습관
- 배터리는 쉬는 날 한 번에 전부 교체
- 경고음이 들리면 그날 바로 교체
- 번호는 가족과 같이 정하고 바꾸면 즉시 공유
- 기계식 열쇠 한 벌은 도어락과 따로 보관
- 퇴근 후 졸린 상태일수록 번호판을 천천히 눌러 확인
배터리 칸에 교체한 날짜를 적어 두면 놓치지 않습니다. / 작은 습관이 새벽 문 앞의 시간을 크게 줄여 줍니다.

# 마북동 말고 용인 어디든 갑니다
마북동 옆 죽전동, 구갈동, 보정동, 신갈동도 다닙니다. / 용인 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에 정리해 두었습니다. / 서울, 경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
