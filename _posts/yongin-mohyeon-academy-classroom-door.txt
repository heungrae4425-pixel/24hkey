# 수업 시작 전에 문이 안 열린다면
모현읍은 읍 안 생활권에서 학원과 교습소가 학생들의 하원 시간에 맞춰 움직이는 곳입니다. / 수지구청역이나 기흥역 방면으로 오가는 학부모와 강사님도 많이 계십니다.
수업 시작 시간은 정해져 있는데 출입문이 안 열리면 원장님과 강사님 모두 마음이 급해집니다. / 학생들이 복도에서 기다리는 상황이면 더 서두르게 됩니다.
이 글은 학원이나 교습소의 출입문과 강의실 문이 말썽일 때 확인할 것을 정리했습니다. / [용인 출장열쇠](yongin.html)가 현장에서 어떻게 진행하는지도 함께 적었습니다.
@ 모현읍 학원 교습소 출입문 잠금 점검

# 학원 문은 문이 여러 개라는 점이 달라요
학원은 건물 입구, 학원 출입문, 강의실 문, 원장실, 보관실까지 문이 여러 겹입니다. / 각 문의 잠금 방식이 다르면 원인도 따로 찾아야 합니다.
출입문은 번호식 도어락이고 강의실은 단순한 레버 손잡이인 경우가 많습니다. / 원장실이나 보관실에는 열쇠식 잠금이 달려 있기도 합니다.
어느 문이 어떻게 막혔는지 먼저 정리하면 전화 한 통으로 끝낼 수 있습니다. / 문마다 몇 번째 문인지 메모해 보세요.

# 출입문 도어락이 반응하지 않을 때
번호판이 켜지지 않으면 배터리를 먼저 의심해 볼 수 있습니다. / 학원은 하루에 여러 사람이 드나들어 가정집보다 배터리가 빨리 닳는 경우가 있습니다.
9V 건전지를 대는 비상 단자가 있는 제품이라면 건전지로 일단 열어 볼 수 있습니다. / 열린 뒤에는 안쪽 배터리를 전부 교체해 두세요.
소리는 나는데 안 열리면 모터나 걸쇠 쪽 문제일 수 있습니다. / 이 경우 억지로 흔들지 마시고 연락 주세요.

# 많은 사람이 쓰는 번호의 함정
학원 출입문 번호를 강사, 직원, 셔틀 담당 등 여러 사람이 공유하는 경우가 많습니다. / 누군가 퇴사했는데 번호가 그대로라면 정리가 필요합니다.
번호를 자주 바꾸는 곳은 바꾼 걸 모르는 직원이 문 앞에서 막히기도 합니다. / 번호가 바뀌면 단체 메신저로 바로 공유하는 방법이 좋습니다.
번호 변경 후에 반드시 한 번 더 시험해 보세요. / 시험 없이 마감하면 다음 날 아침에 직원이 못 들어오는 일이 생깁니다.

# 강의실 문이 안에서 잠겼을 때
수업이 끝난 줄 알았는데 강의실 문이 안에서 잠긴 경우가 있습니다. / 학생이 문을 잠그고 나갔거나 장난으로 잠금 버튼을 눌러 둔 경우입니다.
방문형 레버 손잡이에는 바깥에서 푸는 비상 구멍이 있는 경우가 많습니다. / 가는 핀을 꽂으면 풀리는 구조인지 손잡이 모양을 살펴보세요.
안에 학생이나 교재가 남아 있는지 먼저 확인하세요. / 아이가 안에 있다면 놀라지 않게 말을 걸어 안내해 주세요.
@ 모현읍 학원 강의실 문 잠금장치

# 하지 말아야 할 행동
급하다고 문을 세게 두드리거나 손잡이를 힘으로 비트는 것은 피해 주세요. / 손잡이 안쪽 부품이 부러지면 열쇠로도 못 여는 상태가 됩니다.
학생들이 보는 앞에서 문을 발로 차거나 어깨로 밀면 안전 문제도 생깁니다. / 문짝이 갈라지면 수리 범위도 훨씬 커집니다.
카드나 도구를 억지로 넣어 열려는 시도도 문틀과 도어락 외관을 상하게 합니다. / 그대로 두고 상황을 알려 주시는 게 낫습니다.

강의실 안에 아이가 혼자 갇혀 있거나 몸이 불편해 보이는 학생이 있다면 가장 먼저 말씀해 주세요. / 이런 경우에는 안전 확인이 모든 작업보다 앞섭니다.
문 너머로 계속 말을 걸어 학생이 놀라지 않게 해 주시면 큰 도움이 됩니다. / 위급하다고 판단되면 119 같은 긴급 연락을 먼저 하셔야 합니다.
저희는 119를 대신하지는 못하지만 현장에서 문이 안 상하게 가장 빠른 방법을 찾습니다.

# 전화로 알려주시면 좋은 정보
모현읍은 건물과 길이 흩어져 있어 위치를 정확히 알려 주셔야 도착이 빠릅니다. / 눈에 띄는 가게나 도로 이름을 같이 말씀해 주세요.
- 모현읍 안 대략 위치와 학원이 몇 층인지
- 막힌 문이 출입문인지 강의실인지
- 번호판 상태(꺼짐, 켜짐, 경고음)
- 수업이 몇 시에 시작하는지
- 안에 학생이 있는지
도어락 사진이 있으면 문자로 보내 주세요. / 맞는 장비를 챙기기 쉬워집니다.

# 학원 운영자 본인 확인도 필요합니다
교육 공간이라 문을 열기 전에 운영자인지 확인합니다. / 사업자등록증, 임대차 계약서, 건물 관리인 확인 중 하나면 됩니다.
강사나 직원이 대신 연락했다면 원장님과 통화하거나 서류 확인을 부탁드립니다. / 번거로우셔도 학생과 학원 자산을 지키기 위한 절차입니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 개수와 잠금 방식을 확인한 뒤 열기 전에 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용도 없습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에서도 보실 수 있습니다.
@ 모현읍 학원 출입문 개문 현장 진행

# 현장에서는 수업에 방해되지 않게
학생들이 있는 시간이면 소리와 동선에 신경 씁니다. / 필요한 장비만 가져가 짧게 끝내고 작업 공간도 정리합니다.
수업이 끝난 뒤나 시작 전에 맞출 수 있다면 시간을 조율해 드립니다. / 급한 상황이면 먼저 가서 확인부터 합니다.
문 여는 방식이 궁금하시면 [현관문 개문](door-open.html) 페이지에 자세히 적어 두었습니다.

# 열고 난 뒤 점검과 교체 판단
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 확인합니다. / 배터리가 원인이었다면 새 배터리로 바꿨는지도 봅니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 반복해서 고장 나면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 낡았으면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
공간을 새로 열 때는 [도어락 설치](doorlock-install.html) 안내를 참고하시면 좋습니다.

# 학원 출입문 관리 습관
- 번호는 직원이 바뀔 때마다 변경하고 단체 공유
- 배터리는 방학 기간에 전부 교체
- 강의실 문은 마지막 퇴실자가 확인
- 열쇠는 원장실과 다른 곳에 한 벌 보관
- 문이 덜 닫히면 경첩과 도어클로저 점검
방학 때처럼 한가한 시간에 점검해 두면 학기 중에 급한 연락을 줄일 수 있습니다. / 작은 습관이 수업 시간을 지켜 줍니다.

# 모현읍 말고 용인 어디든 갑니다
모현읍 말고도 포곡읍, 마북동, 동백동 등 용인 곳곳을 다닙니다. / 용인 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
