# 카드키가 하나 더 필요해졌을 때
모현읍은 용인 동쪽 끝으로 외곽 주택과 연립, 아파트가 섞여 있는 동네입니다. / 가족이 늘거나 자녀가 학교에 다니게 되면 카드키가 하나 더 필요해지는 때가 옵니다.
카드키를 새로 등록하는 일은 어렵지 않아 보이지만, 방법을 잘못 알고 시작하면 기존 카드가 지워지거나 도어락이 먹통이 되는 일도 있습니다. / 그래서 시작하기 전에 알아 둘 것이 있습니다.
이 글은 모현읍 가정에서 카드키나 태그를 추가 등록하는 순서와 초기화할 때의 주의점을 정리했습니다. / 안 되거나 문이 안 열릴 때 [용인 출장열쇠](yongin.html)를 부르는 방법도 담았습니다.
@ 모현읍 도어락 카드키 태그 추가 등록

# 먼저 우리 도어락이 어떤 방식인지 보기
카드키 방식은 제품마다 달라서 같은 도어락 모양이어도 등록 순서가 다를 수 있습니다. / 가장 확실한 길은 도어락 안쪽 덮개 아래나 설명서에서 등록 순서를 확인하는 것입니다.
- 카드키를 대는 부분이 번호판 옆인지 아래인지
- 안쪽 뚜껑 안에 등록 버튼이나 설정 단추가 있는지
- 관리자 번호가 따로 있는 제품인지
- 카드키 말고 팔찌형이나 스티커형 태그를 쓰는지
설명서를 잃어버렸다면 제품 이름을 인터넷에서 찾아 순서를 확인해 보세요.

# 카드 추가와 전체 삭제는 다릅니다
등록 모드에는 새 카드를 더하는 기능과 기존 카드를 모두 지우고 다시 등록하는 기능이 함께 있는 제품이 많습니다. / 이 두 가지를 헷갈리면 가족이 쓰던 카드가 한꺼번에 무효가 됩니다.
추가가 목적이라면 기존 카드를 지우는 메뉴 근처는 건드리지 않는 것이 좋습니다. / 안내음이 나오는 제품이라면 소리를 잘 듣고 한 단계씩 진행하세요.
처음이라면 기존 카드를 대 보며 아직 열리는지 먼저 확인하세요. / 새 카드 등록 뒤에는 새 카드와 기존 카드를 각각 대 보며 둘 다 되는지 확인합니다.

# 등록하는 일반적인 순서
제품마다 다르지만 대략 아래와 같은 흐름을 따릅니다. / 실제 순서는 해당 제품 설명서를 우선하세요.
- 문을 열어 둔 채 안쪽에서 진행해 갇히지 않게 합니다
- 안쪽 뚜껑을 열어 등록 단추를 확인합니다
- 등록 모드로 들어가 안내음을 확인합니다
- 새 카드를 정해진 곳에 대고 등록음을 확인합니다
- 문을 닫고 새 카드로 열리는지 확인합니다
특히 문을 열어 둔 상태에서 등록하는 것이 중요합니다. / 등록이 틀어졌을 때 문이 잠겨 안팎으로 막히는 일을 막아 줍니다.
@ 모현읍 카드키 등록 순서 확인

# 카드를 잃어버렸다면 먼저 할 일
카드키를 잃어버렸을 때는 등록된 카드를 지우지 않으면 주운 사람이 쓸 수 있습니다. / 집 근처에서 잃어버렸다면 더욱 신경이 쓰입니다.
잃어버린 카드가 어떤 것인지 알 수 없다면 등록된 카드를 전부 지우고 가족 카드를 다시 등록하는 방법이 안전합니다. / 이때 초기화 절차를 거치게 됩니다.
번호도 함께 바꾸는 편이 더 안전합니다. / 카드와 번호는 서로 다른 수단이라 한쪽만 바꾸면 빈틈이 남을 수 있습니다.

# 초기화하기 전에 확인할 것
초기화는 등록된 정보를 모두 지우는 일이라 한 번 하면 되돌리기 어렵습니다. / 시작하기 전에 현재 사용하는 번호와 카드가 몇 개인지 가족과 함께 정리해 두세요.
- 초기화하면 번호가 공장 기본값으로 돌아가는 제품도 있습니다
- 지문이 함께 등록된 제품은 지문도 지워질 수 있습니다
- 초기화 직후에는 새 번호와 새 카드를 바로 등록하세요
- 기본 번호로 방치하면 다른 사람이 쓸 수도 있습니다
초기화 방법은 제품마다 달라서 단추를 누르는 순서와 시간이 다를 수 있습니다.

# 안 되는 이유를 짚어 보면
카드를 대도 등록이 안 되거나 등록한 카드가 열리지 않는 데는 몇 가지 흔한 이유가 있습니다.
- 카드 규격이 도어락과 맞지 않는 경우
- 배터리가 약해 등록 모드에 들어가지 못하는 경우
- 이미 등록 가능한 개수가 가득 찬 경우
- 대는 위치나 속도가 맞지 않은 경우
카드 규격은 겉으로 보기에 비슷해도 서로 호환되지 않을 수 있습니다. / 새 카드를 사기 전에 제품에 맞는 규격인지 확인하는 것이 먼저입니다.

등록 과정에서 문이 잠겼는데 안쪽이든 바깥쪽이든 열리지 않을 수 있습니다. / 이럴 때 무리해서 단추를 계속 누르면 상태가 더 꼬일 수 있습니다.
번호나 카드로 열리는지 하나씩만 천천히 시도해 보세요. / 그래도 안 되면 억지로 하지 말고 전화 주시면 됩니다.
모현읍 어디에서든 24시간 연락받고, 문이 안 열리면 덜 상하는 방법부터 진행합니다.

# 전화 주실 때 알려주실 정보
- 모현읍 어느 쪽인지 (큰길, 가까운 정류장, 건물 모양)
- 도어락 모양과 제품 이름이 보이는지
- 카드 등록을 시도하다 생긴 일인지
- 번호판 소리와 불빛 상태
- 집 안에 아이나 반려동물이 있는지
제품 이름이 적힌 스티커 사진을 보내 주시면 방법을 더 정확히 안내해 드릴 수 있습니다.

# 사시는 분인지 확인합니다
문을 열기 전에 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로워도 이웃과 가족 모두를 지키는 절차이니 양해 부탁드립니다. / 확인이 어렵다면 작업을 할 수 없으니 미리 챙겨 두세요.

# 비용은 열기 전에 먼저 말씀드립니다
도어락과 문 상태를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 들지 않으면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
자세한 진행은 [이용안내](guide.html)에 적어 두었습니다.

# 열린 뒤에 카드와 번호 정리하기
문이 열리면 카드 등록 상태부터 확인합니다. / 필요한 카드만 남기고 새 카드를 등록한 뒤 문밖에서 직접 눌러 확인해 드립니다.
번호 변경과 배터리 교체도 함께 살펴봅니다. / 문 여는 방식은 [현관문 개문](door-open.html)에 정리해 두었습니다.
카드 기능이 없는 제품이거나 고장이 잦다면 [도어락 설치](doorlock-install.html) 페이지에서 새 제품을 고를 때의 기준을 살펴보세요. / 고쳐서 쓸 수 있으면 [도어락 수리](doorlock-repair.html)를 먼저 권합니다.

모현읍 옆 포곡읍, 역북동, 김량장동도 다닙니다. / 용인 안이면 어느 동네든 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html)에서 볼 수 있고, 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
