# 모현읍에서 집을 비운 사이 누가 드나들어야 한다면
모현읍은 단독주택과 연립, 작은 아파트가 마을 단위로 모여 있어 이웃끼리 왕래가 잦은 곳입니다. / 부모님 댁에 돌봄 인력이 드나들거나 집을 비운 동안 지인이 화분을 봐 주는 일도 자주 생깁니다.
이럴 때 가장 먼저 고민되는 것이 문을 어떻게 열어 줄지, 그리고 비밀번호를 알려 주고 나서 어떻게 관리할지입니다. / 한 번 알려 준 번호를 계속 쓰면 나중에 불안해지기 마련입니다.
이 글은 임시 비밀번호를 쓰는 방법과 주의할 점, 번호가 맞는데도 안 열릴 때의 대처를 정리했습니다. / 도움이 필요하면 [용인 출장열쇠](yongin.html)가 어떻게 돕는지도 같이 적었습니다.
@ 모현읍 도어락 임시 비밀번호 설정 출장

# 임시 비밀번호가 필요한 상황
집에 다른 사람이 드나들어야 하는 경우는 생각보다 다양합니다. / 아래 같은 상황이면 가족 번호와 따로 쓰는 임시 번호를 만들어 두는 게 좋습니다.
- 가사도우미나 청소 인력이 정해진 요일에 오는 경우
- 부모님 댁에 방문 돌봄이나 간병 인력이 오는 경우
- 집을 비운 사이 화분이나 반려동물을 맡기는 경우
- 이사나 수리 업체가 짧은 시간만 출입하는 경우
이런 때 가족 비밀번호를 그대로 알려 주면 나중에 바꾸기도 번거롭습니다. / 따로 번호를 만들고 쓴 뒤에 지우는 방식이 훨씬 편합니다.

# 대부분의 도어락은 번호를 여러 개 등록할 수 있습니다
요즘 도어락은 비밀번호를 여러 개 저장하는 기능이 있는 제품이 많습니다. / 가족 번호와 손님용 번호를 따로 등록해 두고, 쓰고 나면 손님용만 지우면 됩니다.
제품에 따라 한 번 쓰면 자동으로 사라지는 일회용 번호, 정해진 시간만 쓸 수 있는 번호가 있는 것도 있습니다. / 이런 기능은 설명서에 방법이 나와 있으니 제품에 맞게 확인해 보세요.
기능이 없는 오래된 제품이라면 번호를 바꾸는 방식으로 관리해야 합니다. / 이럴 때는 사용 후 바로 새 번호로 바꿔 주세요.

# 번호를 알려 줄 때 지켜야 할 것
번호는 아무에게나 알려 주지 않는 것이 기본입니다. / 꼭 필요한 사람에게만, 필요한 기간만 알려 주세요.
메시지로 번호를 보낼 때는 받는 사람과 시간을 확인하고, 사용이 끝나면 대화 내용을 지우는 습관이 좋습니다. / 오래 남아 있는 메시지는 나중에 다른 사람 눈에 띌 수 있습니다.
같은 번호를 여러 사람에게 돌려 쓰는 것도 피해 주세요. / 누가 언제 드나들었는지 알 수 없게 됩니다.
@ 모현읍 도어락 번호 등록 삭제 점검

# 쓴 뒤에는 꼭 지우거나 바꿔 주세요
임시 번호의 핵심은 쓰고 나면 없애는 것입니다. / 일정이 끝났는데도 번호가 남아 있으면 임시가 아니게 됩니다.
달력에 번호 삭제 날짜를 같이 적어 두면 잊어버리지 않습니다. / 가족이 같이 쓰는 달력이라면 서로 확인해 줄 수도 있습니다.
삭제 방법이 기억나지 않으면 제품 설명서를 보거나 전화로 문의하셔도 됩니다.

# 번호가 맞는데 손님이 문을 못 열 때
임시 번호가 등록되었는데도 문이 안 열린다면 몇 가지를 확인해 볼 수 있습니다. / 등록이 제대로 저장되지 않았거나, 번호 길이가 맞지 않거나, 제품이 마스터 번호를 먼저 요구하는 경우가 있습니다.
도어락 배터리가 약해져서 번호판 반응이 느린 것일 수도 있습니다. / 이럴 때는 번호를 천천히, 한 자리씩 눌러 보도록 안내해 주세요.
손님 입장에서는 몇 번 틀리면 도어락이 잠시 막힐 수 있습니다. / 몇 분 기다렸다가 다시 시도하도록 알려 주는 것도 방법입니다.

# 등록 방법이 헷갈릴 때는
번호 등록 방법은 제품마다 달라서 같은 단계를 거치는 것이 아닙니다. / 버튼을 누르는 순서와 마스터 번호를 입력하는 방식이 제품마다 다릅니다.
잘못 눌러서 기존 번호가 지워지는 일도 간혹 생깁니다. / 확신이 서지 않으면 가족 번호는 건드리지 말고 설명서를 먼저 확인하세요.
그래도 어렵다면 전화로 제품 모양을 알려 주세요. / 방문해서 등록 방법을 같이 확인해 드립니다.
@ 모현읍 도어락 번호 등록 방법 안내

# 주의: 번호를 기억 못 해서 가족이 못 들어올 때
임시 번호를 만들다가 기존 번호를 지웠는데 새 번호는 기억나지 않는 일도 생깁니다. / 이런 경우에는 집 안에 들어갈 방법이 없어 곤란해집니다.
번호를 바꿀 때는 새 번호를 바로 메모하거나 가족에게 알려 두는 것이 좋습니다. / 바꾸고 나서 문 밖에서 새 번호로 열어 보는 확인도 해 두세요.
문이 안 열린다면 억지로 열려 하지 말고 전화로 상황을 알려 주세요. / 사시는 분인지 확인한 뒤 열어 드립니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소나 이웃 확인 중 하나면 됩니다.
가사도우미나 돌봄 인력이 문 앞에 있는 상황이라도, 집주인이나 거주자 본인의 확인이 필요합니다. / 본인이 직접 통화하고 확인하는 방식이면 진행에 도움이 됩니다.
번거롭더라도 모두를 위한 절차이니 이해해 주세요. / 확인이 어려우면 작업을 할 수 없는 점은 미리 알려 드립니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
현관문 상태와 도어락 종류를 확인한 뒤 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
끝내 열지 못하면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하는 상황이면 바꾸기 전에 따로 여쭤봅니다. / 진행 방식은 [이용안내](guide.html)에도 적어 두었습니다.

# 문을 열고 난 뒤 번호 정리까지 같이 합니다
문이 열리면 도어락이 잘 잠기고 열리는지 같이 확인합니다. / 번호 관리가 어려웠다면 가족 번호와 임시 번호를 나누는 방법도 알려 드립니다.
기능이 부족한 오래된 도어락이라면 [도어락 수리](doorlock-repair.html)나 [도어락 교체](doorlock-replace.html)를 말씀드릴 수 있습니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
도어락 상태를 보고 필요한 경우에만 말씀드립니다. / 문 여는 방법은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 오래된 도어락이라면 이렇게 관리하세요
번호를 여러 개 못 쓰는 오래된 제품에서도 최소한의 관리는 가능합니다.
- 임시 번호를 쓴 날마다 새 번호로 바꾸기
- 번호는 가족에게도 직접 알려 주기보다 말로 전달하기
- 손님이 가고 나면 문이 제대로 잠겼는지 한 번 확인하기
- 중요한 물건은 별도 잠금 가능한 곳에 보관하기
이런 작은 습관이 쌓이면 걱정이 줄어듭니다. / 새로 설치할 때는 번호를 여러 개 저장할 수 있는 제품을 고르시면 편합니다.
@ 모현읍 도어락 가족 손님 번호 구분

# 마무리
모현읍에서 손님이나 돌봄 인력에게 번호를 알려 줄 때는 필요한 사람에게만, 필요한 기간만 쓰는 것이 기본입니다. / 쓰고 나서 지우거나 바꾸는 습관이 있으면 마음이 훨씬 편해집니다.
번호가 헷갈리거나 문이 안 열리면 위치와 상황을 알려 주세요. / 용인 어디든 24시간, 전화 010-3664-5455로 연락 주세요. 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
