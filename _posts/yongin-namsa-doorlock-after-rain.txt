# 비 온 다음 날 번호판이 안 눌린다면
남사읍은 읍 생활권 안에서 단독주택과 빌라, 공장 인근 주거지가 섞여 있는 동네입니다. / 현관이 바깥에 그대로 드러난 집이 많아 비바람이 번호판에 직접 닿는 일이 흔합니다.
장마나 태풍 뒤에 번호판이 아예 안 켜지거나 눌러도 반응이 없으면 도어락이 망가졌나 걱정하게 됩니다. / 하지만 물이 닿은 직후에는 잠시 먹통이었다가 마르면 돌아오는 경우도 많습니다.
이 글은 남사읍에서 비를 맞은 도어락이 먹통일 때 하지 말아야 할 것과 말리는 방법, 전화해야 할 때를 정리했습니다. / [용인 출장열쇠](yongin.html)를 부르기 전에 읽어 보세요.
@ 남사읍 비에 젖은 도어락 외부 번호판

# 번호판이 먹통이 되는 이유
번호판 안쪽에는 전기 회로와 접점이 있습니다. / 방수 처리가 되어 있어도 오래 쓰면 틈으로 물기나 습기가 스며들 수 있습니다.
물이 접점에 닿으면 전기가 엉뚱한 곳으로 흘러 입력이 안 되거나, 번호가 눌리지 않아도 소리가 나기도 합니다. / 마르면서 정상으로 돌아오는 경우도 있지만 부식이 시작되면 오래 이어질 수 있습니다.
비를 맞은 직후 가장 먼저 할 일은 억지로 누르지 않는 것입니다.

# 하지 말아야 할 행동
급한 마음에 한 행동이 오히려 상태를 키우는 일이 있습니다.
- 번호판에 헤어드라이어의 뜨거운 바람을 가까이 대는 것
- 물기를 닦는다고 세게 문지르거나 압력을 주는 것
- 뚜껑을 열고 직접 분해해 내부를 닦는 것
- 전기가 흐르는 상태에서 물을 더 묻히는 것
뜨거운 바람은 내부 부품과 플라스틱을 상하게 합니다. / 천천히 마르게 두는 것이 안전합니다.

# 겉면 물기부터 닦아 주세요
번호판 표면의 물기를 마른 수건으로 가볍게 눌러 닦아 냅니다. / 문질러 닦기보다 눌러서 물기를 빨아들이는 느낌이 좋습니다.
홈에 고인 물은 휴지나 면봉 끝으로 살짝 빼 줍니다. / 손잡이 쪽 틈과 아래쪽 비상 단자 부분도 같이 닦으세요.
닦은 뒤 20분 정도 그대로 두고 상태를 보는 것이 일반적인 시작입니다.
@ 남사읍 번호판 틈 물기 닦는 마른 수건

# 자연 건조 시간 가늠하기
물기를 닦았다면 서늘하고 통풍이 되는 곳에서 자연스럽게 마르게 합니다. / 도어락 위치상 옮길 수 없으니 문을 열어 환기가 되도록 해 두는 정도입니다.
습한 날씨가 계속되면 마르는 데 더 오래 걸립니다. / 하루 정도 지나도 반응이 없으면 안쪽 접점 문제를 의심해야 합니다.
이때는 건조를 더 기다리기보다 점검을 받는 편이 낫습니다.

# 번호가 눌리는데 소리만 이상하다면
물이 닿은 뒤 번호는 눌리는데 경고음이 길게 나거나 이상한 소리가 나기도 합니다. / 접점이 젖어 오작동 신호가 나는 상태일 수 있습니다.
모터 소리만 나고 걸쇠가 안 빠지면 [도어락 수리](doorlock-repair.html)에서 안내하는 확인 순서를 따라가 보세요. / 소리 종류는 제품마다 달라서 어떤 소리인지 알려 주시면 도움이 됩니다.
소리가 계속 나는 동안에는 번호를 반복해서 누르지 마세요.

# 9V 건전지로 먼저 열어 보기
번호판이 먹통이어도 비상 단자에 9V 건전지를 대면 열리는 경우가 있습니다. / 바깥쪽 아래쪽에서 단자를 찾아 건전지를 꾹 눌러 대고 번호를 입력해 보세요.
단자 부분이 젖어 있다면 먼저 마른 수건으로 닦은 뒤 시도합니다. / 열리지 않으면 억지로 반복하지 말고 멈추세요.
단자가 없는 제품이거나 대도 반응이 없으면 전화 주시면 됩니다.

# 외부 번호판이 안 되면 열쇠 구멍은?
외부 번호판이 안 돼도 비상 열쇠 구멍이 있는 제품이라면 열쇠로 열 수 있습니다. / 열쇠 구멍은 번호판 아래 덮개 안에 숨어 있는 경우가 많습니다.
열쇠가 집 안에 있거나 분실했다면 [열쇠 출장](key-call.html) 안내를 참고하세요. / 보조키가 달려 있다면 그쪽 열쇠로 열리는지도 확인해 보세요.
문을 잠근 뒤에는 번호판 상태를 먼저 점검하고 외출하는 습관이 좋습니다.

# 한 번 젖은 번호판의 후속 점검
비가 그친 뒤에는 번호판 가장자리에 물자국이나 하얀 얼룩이 남지 않았는지 살펴보세요. / 얼룩이 보이면 안쪽까지 물이 들어갔다 마른 흔적일 수 있습니다.
번호판이 다시 켜졌다고 안심하기는 이릅니다. / 며칠 뒤 같은 증상이 반복되면 내부에 습기가 남아 있다는 신호입니다.
특히 비가 올 때마다 오작동한다면 번호판 가장자리 방수 마감을 점검받는 것이 좋습니다. / 오래된 제품이라면 [도어락 교체](doorlock-replace.html) 시점을 같이 보게 됩니다.
번호판에 빗물이 직접 닿지 않도록 처마나 가리개를 두는 방법도 있습니다.

# 이럴 땐 바로 전화 주세요
비를 맞은 도어락은 겉보기에 멀쩡해도 안쪽이 젖어 있을 수 있습니다. / 남사읍처럼 현관이 바깥에 드러난 집은 같은 일이 되풀이되기 쉬우니 증상이 의심되면 일찍 연락 주시는 편이 낫습니다.
아래 같은 경우에는 말리거나 기다리지 말고 바로 연락 주세요.
- 번호판에서 타는 냄새나 연기가 나는 경우
- 전원을 껐다 켜도 아무 불이 안 들어오는 경우
- 물이 다시 안쪽에서 새어 나오는 경우
- 문이 잠긴 채 열쇠도 번호도 안 되는 경우
집 안에 아이나 반려동물이 있다면 꼭 먼저 말씀해 주세요.

# 전화 때 알려 주시면 좋은 정보
- 남사읍 안의 위치와 건물 종류
- 번호판 상태 (꺼짐, 깜빡임, 경고음)
- 비를 맞은 시점과 비 온 양
- 도어락 모양과 비상 단자 유무
번호판 사진을 문자로 보내 주시면 맞는 장비를 챙겨 갈 수 있습니다.

# 신분 확인과 비용 안내
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
관리사무소가 없는 주택이라면 우편물이나 고지서로 확인하는 경우가 많습니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 주세요.

확인이 끝나면 번호판 상태를 보고 비용을 먼저 말씀드립니다. / 동의하신 뒤에 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 할 때도 바꾸기 전에 따로 여쭤봅니다.
이용 순서는 [이용안내](guide.html)에서 보실 수 있습니다.
@ 남사읍 출장열쇠 도어락 번호판 점검

# 남사읍 말고 용인 어디든 갑니다
비 오는 날은 도로 사정이 좋지 않을 수 있어 도착 시간을 넉넉히 안내드립니다. / 위치를 정확히 알려 주시면 그만큼 빨라집니다.
남사읍 가까이 포곡읍, 모현읍도 다닙니다. / 용인 안이면 어디든 24시간 출동합니다.
다니는 동네는 [출장 지역](area.html) 지도에서 확인하세요. / 문이 아예 안 열린다면 [현관문 개문](door-open.html)도 참고하시면 됩니다.
