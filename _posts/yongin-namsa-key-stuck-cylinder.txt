# 열쇠를 꽂았는데 꿈쩍도 하지 않을 때
남사읍은 전철 대신 버스와 차로 오가는 분이 많은 생활권이라 늦은 귀가가 흔합니다. / 집 앞에 도착해 열쇠를 꽂았는데 돌아가지 않거나 구멍에서 빠지지 않으면 당황하기 쉽습니다.
이럴 때 가장 흔한 실수는 힘을 주어 돌리는 것입니다. / 열쇠가 부러지거나 실린더가 망가지면 상황이 훨씬 어려워집니다.
이 글은 열쇠가 안 돌아가거나 안 빠질 때 순서대로 확인할 것을 정리했습니다. / 용인 지역 안내는 [용인 출장열쇠](yongin.html)에서 볼 수 있습니다.
@ 남사읍 열쇠 실린더 안 돌아감 출장열쇠

# 왜 열쇠가 안 돌아갈까
원인은 크게 몇 가지로 나뉩니다. / 어느 쪽에 가까운지에 따라 대응이 달라집니다.
- 열쇠가 휘었거나 닳아서 홈이 맞지 않는 경우
- 실린더 안에 먼지나 이물질이 쌓인 경우
- 문이 처져 걸쇠에 힘이 걸려 있는 경우
- 열쇠를 반만 꽂았거나 방향이 틀린 경우
- 겨울에 내부가 얼거나 습기가 찬 경우
먼저 열쇠를 끝까지 꽂았는지, 위아래 방향이 맞는지 다시 확인해 보세요. / 의외로 열쇠가 덜 들어간 채 돌리다가 막히는 일이 많습니다.
특히 어두운 곳에서 열쇠를 꽂으면 손의 감각만으로 들어갔다고 착각하기 쉽습니다. / 휴대폰 손전등으로 구멍 방향을 비추고 천천히 꽂아 보세요.

# 힘을 주기 전에 해볼 수 있는 가벼운 시도
열쇠를 살짝 뺐다가 다시 꽂아 천천히 돌려 보세요. / 열쇠를 아주 조금 당긴 상태로 돌리면 걸림이 풀리는 경우가 있습니다.
문을 안쪽으로 살짝 밀면서 돌리면 걸쇠에 걸린 압력이 줄어 돌아갈 수 있습니다. / 이때도 힘을 주지 않고 일정하게 돌립니다.
열쇠를 위아래로 살살 흔들며 돌려 보는 방법도 있습니다. / 이 시도를 두세 번 해도 안 되면 멈추는 것이 좋습니다.
@ 남사읍 현관문 열쇠 구멍 점검

# 열쇠가 휘었다면 그대로 쓰지 마세요
오래 쓴 열쇠는 닳거나 미세하게 휘어 있을 수 있습니다. / 다른 열쇠가 있다면 여분으로 시도해 보세요.
여분 열쇠로는 열리는데 원래 열쇠만 안 된다면 열쇠가 문제입니다. / 반대로 여분도 안 되면 실린더 쪽 문제일 가능성이 큽니다.
열쇠 날 부분에 은색 가루나 흠이 보이면 닳았다는 신호일 수 있습니다. / 새로 복사할 때는 닳은 열쇠가 아닌 처음 상태에 가까운 열쇠를 원본으로 삼는 것이 좋습니다.
휘어진 열쇠를 손으로 펴려고 하지 마세요. / 부러지면 열쇠 조각이 안에 남아 처리가 어려워집니다.

# 기름칠이나 이물질 제거를 함부로 하지 마세요
뻑뻑하다고 일반 윤활유를 많이 뿌리면 먼지가 엉겨 더 나빠지는 경우가 있습니다. / 실린더 전용 윤활제를 쓰더라도 아주 소량만 써야 합니다.
이쑤시개나 철사로 구멍 안을 쑤시는 것도 위험합니다. / 이물질이 더 깊이 들어가 처리가 어려워집니다.
가루 형태의 흑연 윤활제를 쓴다는 이야기도 있지만 습기에 약합니다. / 확신이 없으면 손대지 말고 연락 주시는 편이 안전합니다.
실린더를 직접 분해해 보려는 분도 있지만 작은 부품이 흩어지면 조립이 어렵습니다. / 한번 흩어지면 같은 상태로 되돌리기 어려우니 그대로 두세요.

# 겨울과 습한 날 특히 조심할 점
추운 날 실린더 안에 물기가 얼면 열쇠가 뻑뻑해지기도 합니다. / 따뜻한 손으로 열쇠를 잠시 쥐었다가 다시 시도해 보세요.
문 바깥이 그늘지고 바람이 센 곳이면 금속이 빨리 식어 더 뻑뻑해집니다. / 입김을 불어 따뜻하게 하는 정도는 괜찮지만 물을 쓰지는 마세요.
뜨거운 물을 붓는 방법은 권하지 않습니다. / 다시 얼거나 내부 부품이 상할 수 있습니다.
비가 오는 날 습기로 열쇠가 걸리는 경우도 있습니다. / 마른 천으로 닦고 천천히 다시 해 보세요.

# 열쇠가 빠지지 않을 때는 더 조심해야 합니다
열쇠가 꽂힌 채 돌아가지도 빠지지도 않으면 억지로 당기지 마세요. / 당기다가 열쇠 머리가 부러지는 일이 가장 흔한 사고입니다.
위아래로 아주 미세하게 움직여 가며 천천히 빼 보세요. / 그래도 움직이지 않으면 그 상태로 두고 연락하는 것이 낫습니다.
열쇠가 부러진 조각이 안에 남은 경우는 별도의 처리가 필요합니다. / 이 경우도 상황을 있는 그대로 말씀해 주세요.

# 연락할 때 이렇게 알려 주세요
증상을 정확히 말씀해 주시면 필요한 도구를 챙겨 가기 좋습니다. / 아래 항목을 참고해 주세요.
- 열쇠가 돌아가지 않는지, 빠지지 않는지
- 열쇠를 꽂았을 때 얼마나 들어가는지
- 도어락과 열쇠 구멍이 같이 있는 문인지
- 여분 열쇠로도 같은 증상인지
- 남사읍 어느 쪽인지, 동과 호수
남사읍은 주택과 공장이 함께 있는 구간이 많아 길 안내가 어려울 수 있습니다. / 눈에 띄는 큰 건물이나 길가 기준을 한 가지 말씀해 주세요.

# 도착하면 사시는 분인지 확인합니다
문을 여는 일이라 먼저 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 주세요. / 신분증이 집 안에 있다면 이웃이나 경비실을 통해 확인하는 방법도 있습니다.
@ 남사읍 열쇠 출장 신분 확인 개문

# 비용은 열기 전에 먼저, 못 열면 받지 않습니다
실린더 상태와 문 종류를 보고 작업 방법을 정한 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고 아니면 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭙습니다.
진행 순서는 [이용안내](guide.html)에서도 확인하실 수 있습니다.

# 문을 열고 난 뒤 실린더를 어떻게 할지
문이 열리면 열쇠와 실린더 상태를 같이 확인합니다. / 열쇠만 새로 만들면 되는 경우도 있고 실린더를 바꿔야 하는 경우도 있습니다.
문을 여는 과정은 [현관문 개문](door-open.html) 페이지에 정리해 두었습니다. / 고쳐 쓸 수 있으면 [도어락 수리](doorlock-repair.html)를 먼저 말씀드립니다.
부품이 너무 낡았다면 [도어락 교체](doorlock-replace.html)를 설명해 드립니다.

# 평소에 열쇠 구멍을 오래 쓰는 방법
- 열쇠는 항상 끝까지 꽂고 돌리기
- 열쇠 머리를 잡고 세게 비틀지 않기
- 열쇠고리에 무거운 장식을 주렁주렁 달지 않기
- 먼지가 많은 곳은 가끔 마른 천으로 닦기
- 뻑뻑해지기 시작하면 미루지 말고 점검
작은 주의가 열쇠와 실린더 수명을 늘려 줍니다. / 열쇠가 평소와 다르게 느껴지는 순간이 점검하기 가장 좋은 때입니다.
열쇠를 차 열쇠나 다른 열쇠와 한 고리에 무겁게 달고 다니면 구멍에 하중이 걸려 닳기 쉽습니다. / 집 열쇠만 따로 분리해 두면 훨씬 오래 갑니다.

# 남사읍 말고 용인 어디든 갑니다
남사읍 가까운 모현읍, 포곡읍, 역북동, 김량장동까지 처인 쪽을 모두 다닙니다. / 수지와 기흥도 같은 방식으로 움직입니다.
다른 지역은 [출장 지역](area.html) 안내를 참고해 주세요.

? 윤활유를 뿌려도 되나요? | 많이 뿌리면 오히려 나빠질 수 있어 권하지 않습니다.
