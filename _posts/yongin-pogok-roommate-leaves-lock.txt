# 같이 살던 사람이 나가고 나면
포곡읍은 수지구청역이나 기흥역 방면으로 출퇴근하는 분들도 있고 읍 안에서 생활하는 분들도 함께 사는 동네입니다. / 방을 나눠 쓰다가 룸메이트가 이사를 나가는 일은 어디서나 흔합니다.
짐은 다 뺐는데 정작 도어락에는 그 사람의 번호와 카드가 그대로 남아 있는 경우가 많습니다. / 헤어진 뒤에야 알아채고 마음이 불편해지는 분들이 적지 않습니다.
이 글은 룸메이트가 나간 뒤 도어락을 어떤 순서로 정리하면 좋은지 담았습니다. / [용인 출장열쇠](yongin.html)가 도울 수 있는 부분도 함께 적었습니다.
@ 포곡읍 룸메이트 이사 후 도어락 정리

# 가장 먼저 해야 할 일은 번호 변경
룸메이트가 쓰던 번호는 가능한 한 빨리 지우고 새 번호를 등록하는 것이 안전합니다. / 관계가 좋게 끝났더라도 번호를 아는 사람이 늘어난 상태로 두는 건 권하지 않습니다.
이사 당일에 함께 확인하면 가장 좋습니다. / 이미 시간이 지났다면 오늘 바로 처리해도 늦지 않습니다.
번호를 바꾼 뒤에는 남은 사람들끼리만 새 번호를 공유하세요. / 나간 사람에게 다시 알려 주는 일이 없도록 정리해 두면 좋습니다.

# 도어락에 등록된 것들 먼저 확인
도어락에는 번호만 등록되어 있지 않습니다. / 카드키, 태그, 지문 같은 다른 방식도 함께 남아 있을 수 있습니다.
- 룸메이트 전용 번호가 따로 있는지
- 카드키나 태그를 나눠 가졌는지
- 지문이 등록돼 있는지
- 열쇠 복사본이 있는지
- 앱이나 알림을 연결해 둔 적이 있는지
지문이 있는 제품이라면 등록된 지문을 모두 삭제하고 필요한 사람만 다시 등록하는 방법이 있습니다. / 제품마다 순서가 다르니 설명서를 먼저 확인해 보세요.

이사를 급히 나가서 카드키를 받지 못한 경우가 있습니다. / 이럴 때는 카드 정보를 도어락에서 삭제하면 그 카드로는 더 이상 열리지 않는 제품이 많습니다.
번호와 카드를 한꺼번에 초기화하는 기능이 있는 도어락도 있습니다. / 다만 초기화하면 남은 사람의 정보도 같이 사라지니 순서에 주의해야 합니다.
어느 방법이 맞는지 모르겠다면 먼저 사진을 찍어 두고 연락 주세요.

# 초기화하기 전에 알아둘 것
초기화는 간단해 보여도 실수하면 가족이나 남은 사람이 못 들어올 수 있습니다. / 새 번호를 바로 등록할 수 있는 상태에서 진행하는 게 안전합니다.
초기화 중에 배터리가 약하면 중간에 멈춰서 오히려 문제가 생기기도 합니다. / 먼저 배터리를 새것으로 바꿔 두면 좋습니다.
문이 열려 있는 상태에서 시도하고 안쪽에서 몇 번 열고 닫아 확인해 보세요. / 문 밖에서 초기화를 시도하다 막히는 분이 의외로 많습니다.
@ 포곡읍 룸메이트 번호 카드 초기화

# 하지 말아야 할 행동
화가 나거나 불안한 마음에 도어락 본체를 분해하려는 분들이 있습니다. / 나사를 잘못 풀면 오히려 도어락이 완전히 고장 납니다.
나간 룸메이트에게 다시 연락해서 번호를 확인하는 것도 불편하고 위험합니다. / 번호를 모르더라도 초기화나 재설정으로 정리할 수 있습니다.
임시로 문을 잠그지 않은 채 외출하는 것도 피해 주세요. / 도어락이 정리되기 전까지는 보조키를 같이 쓰는 편이 안심됩니다.

# 계약서와 관리 주체가 따로 있다면
집을 임대로 얻었다면 도어락 교체나 변경을 집주인과 먼저 이야기하는 게 좋습니다. / 도어락이 처음부터 달려 있었다면 설치된 제품이 누구 것인지도 확인해 보세요.
번호 변경이나 카드 삭제 같은 간단한 설정은 대개 문제가 없지만 제품을 바꾸는 일은 이야기가 필요합니다. / 법적인 판단이 필요한 부분은 계약서를 보시거나 집주인과 상의해 주세요.
저희는 그런 부분은 단정하지 않고, 현장에서 본인 확인이 되는 범위에서 도와드립니다.

# 이런 경우에 연락이 옵니다
- 룸메이트가 번호를 알려 주지 않고 나가서 초기화가 필요한 경우
- 카드키를 돌려받지 못해 새로 정리하고 싶은 경우
- 지문 등록을 지우는 방법을 몰라 막힌 경우
- 번호 변경을 시도하다 입력이 막혀 문이 안 열리는 경우
- 이사 나간 사람 때문에 비밀번호가 바뀐 줄 몰랐던 경우
문이 안 열리는 상황이라면 위치와 도어락 상태를 알려 주시면 순서를 같이 정리합니다.

# 전화로 알려주실 것
포곡읍은 마을과 길이 흩어져 있어 위치를 정확히 알려 주셔야 도착이 빠릅니다. / 근처 눈에 띄는 건물이나 길 이름을 함께 말씀해 주세요.
- 포곡읍 안 대략 위치와 층수
- 도어락 사진과 번호판 상태
- 번호를 바꾸려는지, 문이 안 열리는지
- 카드키나 열쇠를 돌려받았는지
일부만 정리하고 싶은지, 전체를 초기화하고 싶은지도 같이 말씀해 주세요. / 같이 사는 사람이 남아 있다면 그 사람의 정보는 남겨 두는 것이 원칙입니다.

# 현장에서는 사시는 분 확인이 먼저입니다
번호 정리나 문 열기 모두 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
룸메이트와 함께 계약한 경우라면 계약서나 우편물로 본인 거주가 확인되는지 미리 챙겨 두세요. / 번거로우셔도 이웃과 계약자 모두를 위한 절차입니다.
확인이 어려우면 작업을 할 수 없습니다.
@ 포곡읍 도어락 비밀번호 재설정 진행

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 열기 전에 먼저 말씀드립니다. / 번호 정리만 하는 간단한 일이라면 그렇게 말씀드리고 진행합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용도 없습니다.
부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙습니다. / 진행 방식은 [이용안내](guide.html)에서도 보실 수 있습니다.

# 정리 끝난 뒤 한 번 더 점검
새 번호를 등록하고 나면 밖에서 눌러서 열리는지 두세 번 확인합니다. / 안쪽에서 잠금이 정상인지도 함께 봅니다.
배터리가 약하면 이 기회에 새것으로 바꿉니다. / 남은 사람들이 모두 새 번호를 정확히 아는지도 확인하세요.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 고장이 반복되면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 낡았다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 앞으로 룸메이트를 구할 때 미리 정할 것
- 새 룸메이트가 들어올 때 번호를 따로 등록
- 나갈 때 카드와 열쇠를 반납하는 날짜 정해 두기
- 퇴실하는 날 함께 번호 변경하기
- 열쇠 복사본 개수를 서로 알려 두기
- 도어락 사용법을 간단히 적어 공유
이사 나가는 날 번호를 같이 바꾸기로 미리 약속해 두면 마음이 편합니다. / 서로 불편하지 않도록 처음부터 규칙을 정하는 것이 좋습니다.

# 포곡읍 말고 용인 어디든 갑니다
포곡읍 말고도 동백동, 보정동, 마북동 등 용인 곳곳을 다닙니다. / 용인 안이면 읍 면 동네 상관없이 24시간 출동합니다.
