# 현관보다 뒷문이 더 말썽일 때가 있습니다
포곡읍은 단독주택과 작은 건물이 많아 현관 말고도 뒷문이나 쪽문을 쓰는 집이 흔합니다. / 평소 잘 안 쓰던 문이라 막상 필요할 때 안 열려 당황하는 일이 생깁니다.
이 글은 뒷문, 쪽문, 후문의 잠금장치가 안 열리거나 안 잠길 때 확인할 것을 정리했습니다. / 현관문과 다른 점도 함께 적었습니다.
자주 쓰지 않는 문일수록 먼지와 녹이 먼저 쌓입니다. / 그래서 한 번 막히면 의외로 오래 고생합니다.
포곡읍 쪽은 단독주택 마당이나 골목 쪽으로 난 쪽문이 많다고들 합니다. / 이런 문은 겨울에 얼고 여름에 습기를 먹어 상태가 계절마다 달라집니다.
@ 포곡읍 뒷문 쪽문 잠금장치 점검

# 뒷문 잠금장치는 어떤 종류가 많을까
뒷문에는 오래된 실린더 방식, 빗장, 걸쇠, 간이 도어락이 섞여 있습니다. / 현관처럼 번호식이 아닌 경우가 많아 열쇠가 중요합니다.
빗장이나 고리는 안쪽에서만 잠가 밖에서는 열 수 없는 구조입니다. / 밖에서 잠겨 있다면 안쪽에서 누군가 잠갔을 가능성부터 확인하세요.
쪽문에는 작은 자물쇠를 따로 걸어 두는 경우도 있습니다. / 열쇠를 잃어버렸을 때는 자물쇠의 종류를 먼저 알려 주세요.
자물쇠 몸체에 적힌 글자나 모양을 사진으로 보내 주시면 도움이 됩니다. / 같은 모양이라도 안쪽 구조가 달라 현장에서 다시 확인합니다.

# 안 쓰던 문이 갑자기 안 열리는 이유
먼지, 녹, 습기가 쌓여 열쇠 구멍 안쪽이 뻑뻑해지면 열쇠가 돌아가지 않습니다. / 비바람이 직접 닿는 위치의 문은 특히 그렇습니다.
겨울에는 열쇠 구멍 속 물기가 얼어 열쇠가 들어가지 않는 일도 있습니다. / 이럴 때는 억지로 밀어 넣지 말고 체온이나 따뜻한 수건으로 천천히 녹여 주세요.
문이 계절을 지나며 조금씩 틀어져 걸쇠가 문틀에 물리는 일도 있습니다. / 한동안 닫아 둔 문은 경첩이 굳어 열릴 때 소리가 크게 나기도 합니다.
이럴 때 힘을 주어 열쇠를 돌리면 열쇠가 부러질 수 있습니다. / 부러진 열쇠가 안에 박히면 일이 훨씬 커지니 조심해 주세요.
@ 포곡읍 뒷문 열쇠 구멍 점검

# 열쇠가 뻑뻑할 때 해 볼 것
- 열쇠 날을 마른 천으로 닦고 다시 넣어 보기
- 열쇠를 끝까지 넣었다가 반 칸 빼서 돌려 보기
- 손잡이를 살짝 당기거나 밀면서 돌려 보기
- 구멍에 먼지를 가볍게 불어 내기
이 정도까지는 시도해도 괜찮습니다. / 그래도 안 되면 더 이상 힘을 주지 마세요.
열쇠 구멍에 일반 기름을 많이 뿌리는 것은 권하지 않습니다. / 먼지가 엉겨 붙어 나중에 더 뻑뻑해집니다.

# 안쪽에서 잠근 문과 밖에서 잠근 문
후문은 사용 패턴이 달라 누가 잠갔는지 헷갈릴 때가 많습니다. / 가족 중 누군가 안쪽 걸쇠나 빗장을 잠그고 다른 문으로 나갔을 수 있습니다.
밖에서 열 수 없는 구조라면 다른 문으로 들어가 안쪽에서 풀어 주는 것이 가장 빠릅니다. / 집 안에 사람이 있다면 먼저 연락해 보세요.
안쪽에서 풀 수 없는 상황이라면 그때 연락 주시면 됩니다. / 사진을 보내 주시면 구조 파악이 빨라집니다.
마당이 있는 집은 대문을 거쳐 뒷문으로 가는 길이 따로 있는 경우도 있습니다. / 어느 문으로 들어가야 하는지, 이미 열려 있는 다른 문이 있는지도 알려 주세요.

# 연락 주실 때 알려 주실 것
단독이나 소규모 건물은 위치 설명이 중요합니다. / 가까운 큰길이나 눈에 띄는 가게, 건물 모양을 말씀해 주세요.
- 뒷문인지 쪽문인지 후문인지
- 열쇠를 쓰는 방식인지, 번호나 빗장인지
- 열쇠가 있는지, 있는데 안 돌아가는지
- 집 안에 사람이나 반려동물이 있는지
- 문 주변에 사진을 찍을 수 있는 환경인지
[용인 출장열쇠](yongin.html)로 연락 주시면 준비해서 갑니다. / 장비가 달라질 수 있으니 문 종류는 꼭 알려 주세요.
대문과 뒷문이 한꺼번에 막혔다면 어느 쪽이 더 급한지도 말씀해 주세요. / 우선순위에 맞춰 진행 순서를 정해 드립니다.

# 도착하면 사시는 분인지 먼저 확인합니다
뒷문이라도 집으로 들어가는 문이므로 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물 중 하나를 요청드립니다.
포곡읍처럼 관리사무소가 없는 곳은 우편물이나 공과금 고지서로 확인하는 경우가 많습니다. / 임차인이라면 계약 관련 서류도 도움이 됩니다.
확인되지 않으면 진행하지 않으니 양해 부탁드립니다.
세입자는 집주인과 연락이 닿는다면 미리 상황을 알려 두시면 좋습니다. / 사시는 분인지 확인되는 것이 우선이며, 법적인 판단은 하지 않고 거주 확인만 합니다.

# 비용은 시작 전에 말씀드립니다
문 종류와 상태를 보고 비용을 먼저 말씀드립니다. / 동의하신 뒤에 시작하고, 아니면 돌아갑니다.
문을 못 열면 비용은 받지 않고, 열고 난 뒤에 갑자기 붙는 항목도 없습니다. / 부품을 바꿔야 한다면 바꾸기 전에 따로 여쭙습니다.
진행 방식은 [이용안내](guide.html)에서 확인하실 수 있습니다.

# 문은 최대한 상하지 않게 엽니다
오래된 뒷문은 문과 문틀이 약해져 있는 경우가 많습니다. / 그래서 힘을 쓰는 방법보다 덜 상하는 방법을 먼저 씁니다.
개방 방법은 [현관문 개문](door-open.html)에 정리해 두었지만, 뒷문은 구조가 다양해 현장에서 판단합니다. / 열리고 나서 문 상태에 이상이 있으면 알려 드립니다.
@ 포곡읍 후문 개방 작업

# 열린 뒤에는 이렇게 정리합니다
열쇠가 뻑뻑했다면 열쇠 구멍을 청소하거나 부품을 바꾸는 것이 좋은지 말씀드립니다. / 열쇠를 새로 만드는 방법도 안내해 드립니다.
뒷문 잠금이 약하다고 느끼시면 보조 잠금장치를 추가하는 방법도 있습니다. / [도어락 설치](doorlock-install.html) 안내를 참고하세요.
고쳐서 쓸 수 있는 부분은 고쳐서 쓰시도록 권해 드립니다. / 불필요한 교체는 권하지 않습니다.
오래된 자물쇠도 청소와 간단한 부품 교체로 충분히 더 쓸 수 있는 경우가 많습니다. / 열쇠를 새로 만들어야 하면 [열쇠 출장](key-call.html) 안내를 참고하세요.

# 뒷문을 오래 쓰는 관리법
한 달에 한 번쯤은 뒷문을 열고 닫아 보세요. / 자주 쓰지 않는 문일수록 움직여 줘야 굳지 않습니다.
열쇠는 현관 열쇠와 구분되게 표시해 두세요. / 어느 문 열쇠인지 모르면 위급할 때 더 헤맵니다.
비가 직접 닿는 곳이라면 열쇠 구멍에 덮개를 씌워 두는 방법도 있습니다. / 물기가 스며드는 것을 막아 줍니다.
뒷문을 잠그지 않고 다니는 습관은 피해 주세요. / 잠깐이라도 잠그고 다니는 것이 안전합니다.
쪽문 앞에 화분이나 자재를 쌓아 두면 정작 열어야 할 때 문이 막힙니다. / 문 앞 통로는 늘 비워 두는 편이 비상시에 도움이 됩니다.

# 포곡읍 밖 용인 어디든 갑니다
포곡읍 옆 모현읍, 역북동, 김량장동 쪽을 비롯해 용인 어디든 다닙니다. / 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.

? 쪽문에 걸린 자물쇠도 여나요? | 상황을 알려 주시면 가능한지 먼저 말씀드립니다.
? 안쪽에서 빗장이 걸렸어요 | 다른 문으로 들어가 풀 수 있는지 먼저 확인해 보세요.
? 못 열면 비용은 받나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
