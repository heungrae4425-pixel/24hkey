# 풍덕천동에서 문이 안 열리는데 번호는 맞다면
풍덕천동은 수지구청역 주변으로 아파트 단지와 상가가 빽빽하게 이어진 동네입니다. / 번호를 정확히 눌렀는데도 문이 꿈쩍하지 않는다면 도어락이 아니라 다른 잠금장치가 걸려 있을 수 있습니다.
이 글은 보조키와 걸쇠 때문에 문이 안 열릴 때 확인할 것을 순서대로 적었습니다. / 확인해도 안 되면 [용인 출장열쇠](yongin.html)를 부르는 기준도 같이 정리했습니다.
@ 풍덕천동 보조키 현관문 출장열쇠

# 보조키와 도어락은 따로 움직입니다
현관문에는 보통 두 가지 잠금이 있습니다. / 손잡이 쪽 메인 도어락과, 위나 아래에 달린 보조키입니다.
메인 도어락은 번호나 카드로 열고, 보조키는 안쪽 손잡이를 돌려 따로 잠급니다. / 그래서 번호가 맞아도 보조키가 잠겨 있으면 문이 그대로 닫혀 있습니다.
도어락에서 평소처럼 열리는 소리가 나는데 문만 안 움직인다면 보조키를 먼저 의심하세요. / 풍덕천동 단지 현관문은 대부분 이 두 가지를 함께 쓰기 때문에 헷갈리는 분이 많습니다.

# 안쪽에서 보조키를 잠그고 나온 경우
집 안에서 보조키를 잠가 둔 채 문을 닫고 나가는 일이 의외로 많습니다. / 급히 나가다가, 혹은 문이 닫히는 순간 손잡이가 같이 돌아가서 잠기기도 합니다.
이때는 바깥에서 도어락을 아무리 눌러도 열리지 않습니다. / 보조키는 바깥에서 열쇠로만 열리는 제품도 있고, 아예 안쪽에서만 풀 수 있는 제품도 있습니다.
어느 쪽인지 모르겠으면 무리해서 돌리지 말고 모양만 기억해 두세요.
@ 용인 풍덕천동 보조키 열쇠 개문

# 걸쇠가 문틀에 물려 안 빠지는 경우
문이 닫히면 튀어나온 걸쇠가 문틀 구멍으로 들어가 문을 잡아 줍니다. / 이 걸쇠가 문틀 구멍에 꽉 끼어 있으면 손잡이를 돌려도 빠지지 않습니다.
문이 조금 처졌거나 계절이 바뀌며 문틀이 틀어졌을 때 자주 생깁니다. / 손잡이를 돌린 채로 문을 살짝 안쪽으로 밀면 걸쇠가 풀리기도 합니다.
힘으로 당기기보다 밀었다 당기는 작은 움직임이 낫습니다.
문이 조금 처진 집은 손잡이를 돌린 채 문 아랫부분을 살짝 들어 올리듯 밀어 보면 걸쇠가 풀리기도 합니다. / 그래도 안 움직이면 더 시도하지 않는 편이 좋습니다.

# 1분 안에 해볼 수 있는 확인
전화하기 전에 아래 세 가지만 보셔도 원인을 좁힐 수 있습니다.
- 번호를 누르면 모터가 도는 소리가 나는지
- 손잡이를 아래로 돌렸을 때 가볍게 내려가는지
- 문을 안쪽으로 밀면서 돌리면 느낌이 달라지는지
모터 소리가 나는데 안 열리면 보조키나 걸쇠 쪽일 가능성이 높습니다. / 소리 자체가 안 나면 배터리 쪽을 먼저 보면 됩니다.

# 이렇게 하면 문이 더 상합니다
급한 마음에 손잡이를 세게 흔들거나 문틈에 카드를 밀어 넣는 분이 있습니다. / 걸쇠가 더 깊이 물리거나 손잡이 속 부품이 휘어 고장이 커질 수 있습니다.
얇은 철사나 드라이버를 문틈에 넣는 것도 피해 주세요. / 문틀 도장이 벗겨지고 도어락 외관에 흠이 남습니다.
되든 안 되든 서너 번 시도해 보고 멈추는 게 가장 안전합니다.

# 수지구청역에서 집까지 걸어오다 막히는 순간
퇴근길 수지구청역에서 내려 집 앞에 도착했는데 문이 안 열리면 하루의 피로가 한꺼번에 몰려옵니다. / 늦은 밤이라 근처 열쇠집이 문을 닫았다면 더 막막합니다.
이런 때일수록 문을 두드리거나 발로 차지 마세요. / 이웃에게도 폐가 되고, 문이 상하면 해결이 더 오래 걸립니다. / 풍덕천동처럼 밤에도 사람이 오가는 동네라면 문 앞에서 소란이 나는 것도 부담스럽습니다.
안에 휴대폰이 있고 밖에는 아무것도 없는 상황이라면 이웃에게 잠깐 전화를 빌려 연락 주셔도 됩니다.
24시출장열쇠는 밤에도 전화를 받으니 먼저 상황부터 말씀해 주세요.

# 전화 주실 때 알려주시면 좋은 것
짧게 말씀해 주시면 장비를 정확히 챙겨 갈 수 있습니다.
- 풍덕천동 몇 동 몇 호인지, 대략 어느 방향인지
- 번호를 누르면 나는 소리 (삑, 모터음, 무소리)
- 도어락 모양과 보조키가 있는지
- 집 안에 사람이나 반려동물이 있는지
도어락 사진을 문자로 보내주시면 훨씬 빠릅니다. / 안에 아이나 노인이 혼자 계신 상황이면 가장 먼저 말씀해 주세요.

# 도착하면 이런 순서로 합니다
먼저 사시는 분이 맞는지 확인합니다. / 신분증 주소나 우편물, 관리사무소 확인 중 하나면 충분합니다.
그다음 문과 도어락 상태를 보고, 어떤 방법으로 열지와 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니시면 그대로 돌아갑니다.
문을 못 열면 비용은 받지 않습니다. / 순서는 [이용안내](guide.html)에도 적어 두었습니다.

# 보조키가 자꾸 잠기는 집의 원인
같은 일이 반복된다면 습관이 아니라 장치가 문제일 수 있습니다. / 문이 닫히는 속도가 빨라지면 손잡이가 같이 돌아가 보조키가 잠기는 경우가 있습니다.
도어클로저가 너무 세게 닫히도록 맞춰져 있거나, 경첩이 헐거워 문이 처진 집도 비슷합니다.
이럴 때는 매번 열어 드리는 것보다 원인을 손봐야 합니다. / 개문 방법은 [현관문 개문](door-open.html)에 정리해 두었습니다.
@ 용인 보조키 걸쇠 도어락 점검 출장

# 열고 난 뒤 같이 보는 것
문이 열리면 도어락과 보조키가 각각 잘 잠기고 열리는지 확인합니다. / 걸쇠가 문틀에 끼던 집이라면 걸리는 위치도 같이 봅니다.
문이 열리고 나서 보조키만 따로 돌려 보면 어디가 뻑뻑한지 바로 알 수 있습니다. / 손잡이를 돌릴 때 걸리는 느낌이 있으면 안쪽 부품이 헐거운 경우가 많습니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 증상이 반복되는 도어락은 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

# 문 앞에서 막히지 않는 작은 습관
- 나갈 때 보조키를 잠근 채 닫지 않았는지 문을 닫기 전에 한 번 확인
- 문을 놓지 말고 손으로 받쳐 천천히 닫기
- 평소 열쇠 하나는 가족이나 믿을 만한 곳에 맡겨 두기
- 도어락에서 이상한 소리가 나면 그날 점검
- 비상용 9V 건전지를 현관 서랍에 두기
습관 몇 가지만 바꿔도 문 앞에서 허둥대는 일이 크게 줄어듭니다.

# 풍덕천동 말고 용인 어디든
풍덕천동 바로 옆 상현동, 성복동, 죽전동, 동천동, 신봉동도 다닙니다. / 용인 안이면 동네 상관없이 24시간 출동합니다.
용인 지역은 [용인시 출장열쇠](yongin.html)에 정리해 두었고, 서울과 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
