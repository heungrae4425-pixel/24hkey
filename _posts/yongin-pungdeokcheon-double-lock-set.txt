# 잠금장치가 둘인 집은 점검도 둘로 나눠야 합니다
풍덕천동은 수지구청역 생활권이라 출퇴근길에 지하철을 이용하는 분이 많은 동네입니다. / 오래 지내온 집일수록 도어락 위나 아래에 보조키가 하나 더 달려 있는 경우가 흔합니다.
문이 안 열릴 때 도어락 하나만 의심하면 원인을 놓치기 쉽습니다. / 어느 쪽이 걸렸는지에 따라 해야 할 일이 전혀 달라지기 때문입니다.
이 글은 도어락과 보조키를 함께 쓰는 집에서 문이 안 열릴 때 확인하는 순서를 적었습니다. / 위에서부터 차례로 따라가시면 원인을 빠르게 가를 수 있습니다.
@ 풍덕천동 도어락과 보조키가 함께 달린 현관문

# 먼저 어느 쪽이 걸렸는지 구분하세요
문이 안 열릴 때 가장 먼저 할 일은 도어락이 문제인지 보조키가 문제인지 가려내는 것입니다. / 두 가지를 한꺼번에 누르면서 이것저것 시도하면 상황이 더 꼬입니다.
- 도어락 번호판에 불이 들어오는지
- 번호를 누르면 모터 소리가 나는지
- 보조키 열쇠가 돌아가는지, 막힌 느낌인지
- 보조키 손잡이가 위로 올라가 있는지 내려와 있는지
번호판이 꺼져 있다면 도어락 쪽, 번호는 열렸는데 문이 안 당겨지면 보조키 쪽일 가능성이 큽니다. / 이 구분만 되어도 전화로 설명하기가 훨씬 쉬워집니다. / 두 장치가 모두 정상으로 보이는데도 문이 안 열린다면 문틀 처짐이 원인일 수 있습니다. / 문을 살짝 들어 올리듯 밀면서 열어 보면 걸림이 풀리는 경우도 있습니다.

# 보조키를 잠그고 나왔는지 기억을 더듬어 보세요
도어락만 믿고 나왔는데 보조키를 걸어 둔 채였다면 밖에서는 열 수 없습니다. / 보조키는 안쪽 손잡이로 돌려야만 풀리는 구조가 많기 때문입니다.
하지만 밖에서 열쇠를 꽂아 돌리는 방식의 보조키라면 열쇠가 있어야 합니다. / 열쇠가 집 안에 있는지, 다른 가방에 있는지 먼저 확인하세요.
가족 중 누군가 안에서 걸쇠를 걸었을 가능성도 있습니다. / 집에 사람이 있다면 안에서 풀어 달라고 연락해 보세요.

# 도어락만 먼저 정상인지 확인하는 방법
번호를 눌러 문이 열리는 소리가 나면 도어락은 정상입니다. / 이때 열리지 않는다면 보조키나 걸쇠가 문제라는 뜻입니다.
번호판이 안 켜지면 배터리를 의심해 볼 수 있습니다. / 9V 건전지를 바깥 단자에 대고 번호를 누르면 임시로 켜지는 기종이 있습니다.
번호는 눌러지는데 소리가 이상하거나 모터만 돈다면 안쪽 부품 문제일 수 있습니다. / 이 경우는 무리하게 당기지 말고 전화 주세요.

# 보조키가 막힌 느낌이라면
열쇠를 꽂았는데 돌아가지 않거나 중간에 걸리는 느낌이 들 수 있습니다. / 이럴 때 힘을 세게 주면 열쇠가 휘거나 부러질 위험이 있습니다.
열쇠에 먼지나 이물질이 묻었다면 닦고 다시 꽂아 보세요. / 문이 약간 처져서 데드볼트가 문틀에 끼어 있어도 열쇠가 안 돌아갈 수 있습니다.
문을 안쪽으로 살짝 밀면서 돌리면 풀리기도 합니다. / 그래도 안 되면 억지로 돌리지 말고 멈추는 것이 좋습니다.
@ 풍덕천동 보조키 열쇠 구멍을 살피는 모습

# 하지 말아야 할 행동
급한 마음에 도어락과 보조키를 동시에 건드리면 어느 쪽이 문제인지 알기 어려워집니다. / 아래 행동은 피해 주세요.
- 도어락 번호를 계속 반복해서 누르기
- 보조키에 기름이나 이물질을 임의로 넣기
- 드라이버로 문틈을 벌리거나 손잡이를 당겨 돌리기
- 문을 발로 차거나 어깨로 밀기
기름은 순간적으로 부드러워져도 먼지를 붙여 나중에 더 막힐 수 있습니다. / 문틈을 벌리면 외관이 상해 교체까지 이어질 수 있습니다.

# 보조키가 하나, 도어락이 하나일 때 열쇠 정리
두 잠금장치를 쓰는 집은 열쇠와 번호가 서로 다른 이야기가 됩니다. / 가족 모두가 둘 다 알고 있는지 한 번 점검해 보세요.
열쇠는 현관 근처에 두지 말고 가방 안쪽 주머니처럼 정해진 곳에 두는 습관이 좋습니다. / 열쇠 둘 곳이 분명하면 문 앞에서 찾느라 허둥대지 않습니다.
여분 열쇠는 믿을 수 있는 가족에게 맡겨 두세요. / 집 근처 우편함이나 화분 밑에 두는 방법은 위험하니 권하지 않습니다.

@ 풍덕천동 문 안쪽 걸쇠와 보조키 손잡이 위치

# 전화로 말씀해 주시면 좋은 것
두 개의 잠금장치가 달린 집이면 어떤 쪽이 막혔는지 알려 주시면 준비가 빨라집니다. / 문 사진을 문자로 보내 주시면 장비를 맞게 챙겨 갈 수 있습니다.
- 도어락 모양과 번호판 상태
- 보조키 종류(열쇠형, 안쪽 돌림형)
- 문 안쪽에 사람이 있는지
- 건물 이름은 쓰지 않고 동 이름과 가까운 역 방향
위치는 수지구청역 방향 등 대략의 방향만 알려 주셔도 됩니다. / 정확한 호수는 도착 전에 다시 여쭙니다. / 단독으로 열쇠만 쓰는 보조키인지, 안쪽 손잡이로 돌리는 보조키인지만 말씀해 주셔도 큰 도움이 됩니다.

# 출장열쇠를 부르면 이렇게 진행됩니다
[용인 출장열쇠](yongin.html)에 전화하시면 위치와 상태를 먼저 여쭙니다. / 이후 도착해서 도어락과 보조키를 각각 확인한 뒤 어떤 순서로 열지 정합니다.
도어락과 보조키를 둘 다 열어야 하는 문이라면 시간이 조금 더 걸릴 수 있습니다. / 방법과 비용은 작업 전에 먼저 말씀드립니다.
괜찮다고 하셔야 시작하고, 끝내 못 열면 비용은 받지 않습니다. / 문 열기 방식은 [현관문 개문](door-open.html) 페이지에도 자세히 적어 두었습니다.

# 신분 확인은 이렇게 합니다
문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로우셔도 이웃과 집주인을 모두 지키는 절차입니다. / 확인이 어려우면 작업이 불가할 수 있으니 미리 준비해 주세요.
신분증이 집 안에 있다면 관리사무소나 경비실 확인을 부탁해 보세요. / 늦은 시간에는 경비실에 먼저 알려 두면 수월합니다.

# 열고 난 뒤 두 장치를 함께 점검합니다
문이 열리면 도어락과 보조키가 각각 잘 잠기고 열리는지 같이 확인합니다. / 한쪽만 점검하면 다른 쪽에서 비슷한 일이 반복될 수 있습니다.
도어락 배터리가 원인이었다면 전부 새것으로 바꿔 둡니다. / 보조키 쪽은 열쇠 구멍 깊이까지 매끄럽게 들어가는지 봅니다.
둘 중 하나가 자주 고장 난다면 [도어락 수리](doorlock-repair.html)로 먼저 손보고, 너무 오래된 제품이면 [도어락 교체](doorlock-replace.html)를 말씀드립니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않습니다.

# 풍덕천동 말고 용인 어디든 갑니다
풍덕천동 가까운 상현동, 성복동, 죽전동, 동천동, 신봉동도 다닙니다. / 기흥역, 동백역 쪽 구갈동, 보정동, 동백동까지 24시간 출동합니다.
용인에서 다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에 정리해 두었습니다. / 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
