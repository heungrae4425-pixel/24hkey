# 상현동 베란다 문이 안 잠기거나 안 열린다면
상현동은 아파트 단지가 많아 베란다와 발코니 문을 쓰는 집이 많습니다. / 현관문은 멀쩡한데 베란다 쪽 잠금장치가 말썽인 연락도 꾸준히 옵니다.
미닫이문은 평소에 신경을 쓰지 않다가 어느 날 갑자기 안 열려서 당황하게 됩니다. / 이 글은 베란다와 미닫이 잠금장치를 직접 확인하는 순서를 적었습니다.
그래도 안 되면 [용인 출장열쇠](yongin.html)로 연락 주시면 됩니다. / 상현동은 24시간 출동합니다.
@ 상현동 출장열쇠 베란다 미닫이 잠금장치

# 잠금장치 종류부터 알아봅니다
베란다 문 잠금장치는 크게 세 가지로 나뉩니다. / 걸쇠처럼 올렸다 내리는 것, 손잡이를 돌려 잠그는 것, 위아래로 밀어 잠그는 것입니다.
어떤 종류인지에 따라 안 열리는 이유가 달라집니다. / 사진을 한 장 찍어 두시면 전화로 설명하기 쉽습니다.
- 위에서 아래로 내리는 걸쇠형
- 손잡이를 돌려 잠그는 크레센트형
- 열쇠로 잠그는 별도 잠금형
- 바닥이나 위쪽에 따로 달린 보조 잠금

# 레일에 먼지가 쌓여 뻑뻑한 경우
미닫이문은 레일에 먼지와 머리카락이 쌓이면 잘 안 밀립니다. / 잠금장치는 정상인데 문이 안 움직여서 잠긴 것처럼 느끼는 경우가 많습니다.
문을 들어 올리듯 살짝 밀면서 옆으로 당겨 보세요. / 레일을 진공청소기나 솔로 먼저 청소하면 의외로 쉽게 풀립니다.
기름을 많이 뿌리면 먼지가 더 엉겨 붙을 수 있으니 조금만 쓰세요. / 그래도 안 밀리면 바퀴가 빠졌거나 틀어진 경우를 생각해 볼 수 있습니다.

# 손잡이가 헛돌 때는 내부 부품 문제일 수 있습니다
손잡이를 돌려도 걸쇠가 움직이지 않으면 안쪽 연결 부품이 마모됐을 수 있습니다. / 억지로 세게 돌리면 부품이 완전히 부러져 일이 커집니다.
손잡이 쪽만 헐거운 것인지 걸쇠 쪽이 걸린 것인지 천천히 확인해 보세요. / 손잡이를 위아래로 살짝 눌러 보면 구분이 되는 경우도 있습니다.
부품이 부러졌다면 문을 열 때 다른 방법을 먼저 찾습니다. / 열고 나서 부품을 새로 맞춰 달 수 있는지 같이 봅니다.

# 문이 틀어져 걸쇠가 안 맞는 경우
오래된 집은 문과 틀이 조금씩 틀어져 잠금 위치가 안 맞는 경우가 있습니다. / 걸쇠가 들어갈 구멍과 어긋나서 잠기지 않는 것입니다.
문을 끝까지 밀어 닫은 상태에서 걸쇠 위치를 눈으로 확인해 보세요. / 한쪽으로 쏠려 있다면 문이 처진 것입니다.
틀어진 정도가 작으면 걸쇠 받침 위치를 손봐서 해결하기도 합니다. / 크게 틀어진 경우는 문틀 쪽 점검이 먼저 필요합니다.
@ 상현동 24시 출장열쇠 미닫이문 잠금 점검

# 겨울에 얼어서 안 열리는 경우
추운 날 창문과 문 사이에 물기가 얼면 잠금장치가 안 움직이기도 합니다. / 억지로 열면 유리나 프레임이 상할 수 있습니다.
따뜻한 수건을 대고 천천히 녹이는 방법이 안전합니다. / 뜨거운 물을 유리에 바로 붓는 것은 피하세요.
얼음이 녹으면 물기를 닦고 잠금장치 움직임을 확인합니다. / 같은 곳이 자주 얼면 결로 문제도 같이 살펴보는 것이 좋습니다.

# 열쇠로 잠그는 별도 잠금이 안 돌아갈 때
베란다에 열쇠로 잠그는 잠금을 따로 단 집이 있습니다. / 열쇠가 안 돌아가면 내부에 이물질이 있거나 열쇠가 닳았을 수 있습니다.
열쇠를 억지로 돌리면 부러질 위험이 있습니다. / 한 번에 안 돌아가면 힘을 주지 말고 멈추세요.
열쇠가 부러져 안에 박힌 경우에는 다른 방법으로 빼내야 합니다. / 이런 상황이라면 [출장 열쇠](key-call.html) 페이지를 참고하시고 전화 주세요.

# 전화하기 전에 알려 주시면 좋은 것
전화로 상황을 설명하실 때 아래 내용을 말씀해 주시면 도착이 빨라집니다. / 위치와 증상만 알아도 맞는 장비를 챙겨 갈 수 있습니다.
- 몇 층 몇 호인지, 베란다가 열려 있는지
- 어떤 종류의 잠금장치인지
- 안 열리는지, 안 잠기는지
- 집 안에 아이나 반려동물이 있는지

# 베란다 문이 안 잠기면 방범이 걱정되실 수 있습니다
저층이나 1층이라면 베란다가 안 잠기는 것이 특히 걱정됩니다. / 잠금장치를 새로 맞추거나 보조 잠금을 다는 방법을 상담해 드립니다.
꼭 큰 공사가 필요한 것은 아닙니다. / 현재 상태를 보고 간단히 해결 가능한지 먼저 말씀드립니다.
비용은 작업 전에 안내하고, 괜찮다고 하셔야 진행합니다. / 자세한 진행 방식은 [이용안내](guide.html)에서 확인할 수 있습니다.

# 문을 열 때는 사시는 분 확인이 먼저입니다
베란다로 들어가는 문이라도 집의 문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다. / 이웃과 세대 모두를 위한 절차입니다.
비파손으로 먼저 시도하고 못 열면 비용은 받지 않습니다. / 열고 나서 말없이 붙는 비용도 없습니다.
@ 상현동 도어락 현관문 비파손 개방

# 상현동 어디든 갑니다
상현동 아파트 단지와 주택가, 근처 상가까지 24시간 출동합니다. / 수지구청역 근처와 가까운 동네는 예상 도착 시간을 먼저 말씀드립니다.
현관문 문제는 [현관문 개문](door-open.html), 도어락 문제는 [도어락 수리](doorlock-repair.html) 페이지를 참고하세요. / 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.

# 베란다에 나갔다가 문이 잠겼을 때
빨래를 널거나 환기를 하려고 베란다에 나갔다가 문이 닫히며 잠기는 일이 있습니다. / 바깥에 갇힌 상태라 휴대폰이 집 안에 있으면 연락하기도 어렵습니다.
이웃에게 소리쳐 도움을 청하거나 옆집 베란다 쪽 사람에게 연락을 부탁하세요. / 높은 층이라면 난간을 넘거나 옆 칸으로 건너가려는 행동은 절대 하지 마세요.
구조가 필요한 위험한 상황이라면 119에 먼저 연락하는 것이 맞습니다. / 단순히 문이 잠긴 상황이라면 휴대폰을 가진 사람을 통해 전화 주시면 출동합니다.

# 베란다 잠금을 오래 쓰는 관리 요령
레일과 잠금 부분은 한 달에 한 번 정도 가볍게 닦아 주면 오래 갑니다. / 마른 천으로 먼지를 닦고 움직이는 부분이 뻑뻑한지 한 번씩 눌러 보세요.
잠금장치에서 평소와 다른 소리가 나기 시작하면 미루지 말고 점검하세요. / 완전히 고장 나기 전에 손보면 수리 범위도 작아집니다.
창문이 한쪽으로 쏠려 닫히는 느낌이 있다면 바퀴와 레일 상태를 먼저 의심해 볼 수 있습니다. / 상태에 따라 간단한 조정으로 해결되기도 합니다.

베란다는 현관문보다 덜 신경 쓰는 곳이라 문제가 생기면 한참 미루게 됩니다. / 작은 이상이 느껴지는 날 바로 점검해 두면 문 앞에서 막히는 일이 훨씬 줄어듭니다.
정확한 위치와 문 상태를 알려주시면 필요한 부품을 미리 챙겨 가기 때문에 한 번에 끝내기 쉽습니다.
