# 상현동, 퇴원하고 돌아온 집 문이 안 열린다면
상현동은 수지구청역 생활권과 이어지는 주택가와 빌라가 섞여 있는 동네입니다. / 병원에 오래 계셨던 부모님을 모시고 집으로 돌아왔는데 문이 안 열리면 모두 당황합니다.
입원 기간 동안 집은 비어 있었고 도어락도 쉬고 있었습니다. / 이 글은 상현동에서 퇴원해 돌아온 부모님 집 문이 안 열릴 때 무엇부터 살필지 적었습니다.
몸이 불편하신 부모님을 문 앞에 오래 세워 두지 않도록 서두르는 순서로 정리했습니다. / 급하면 [용인 출장열쇠](yongin.html)에 바로 연락 주세요.
@ 상현동 부모님 집 현관 앞 도어락 확인

# 부모님을 먼저 편히 앉히세요
문 앞에서 시간을 끌어야 한다면 부모님이 서 계시지 않게 하는 것이 먼저입니다. / 근처 계단 앞이나 건물 입구 의자, 차 안에서 기다리셔도 됩니다.
퇴원 직후에는 체력이 약하고 날씨가 쌀쌀한 시기라 오래 서 있기 어렵습니다. / 자녀분이 문을 살펴보는 동안 부모님은 쉬시게 하는 편이 좋습니다.
춥거나 힘들어 보이면 일단 따뜻한 곳으로 옮기고 연락 주셔도 됩니다.

# 오래 비어 있던 집에서 흔한 원인
몇 주 동안 비어 있던 집의 도어락은 배터리가 부족해진 경우가 많습니다. / 쓰지 않아도 전기를 조금씩 쓰기 때문입니다.
부모님이 입원 전에 외출 모드나 보조키를 걸어 두고 나왔을 수도 있습니다. / 병원에 급히 가시느라 평소와 다르게 잠그고 나온 경우입니다.
- 번호판이 켜지는지, 완전히 꺼져 있는지
- 입원 전에 보조키나 걸쇠를 걸었는지
- 번호를 부모님이 따로 바꿔 놓은 적이 있는지
- 열쇠는 어디에 보관했는지

# 비밀번호를 기억하지 못하실 때
입원이 길어지면 매일 쓰던 번호도 헷갈리실 수 있습니다. / 이럴 때 번호를 여러 번 틀리면 도어락이 입력을 막는 경우가 있습니다.
생일이나 전화번호 뒷자리처럼 평소 쓰던 조합을 두세 번만 눌러 보고 안 되면 멈추세요. / 틀린 번호를 반복하면 오히려 한동안 못 쓰게 됩니다.
번호를 적어 둔 곳이 있는지 부모님께 천천히 물어보시고, 재촉하지는 마세요.

# 배터리가 방전됐다면 9V 건전지로
번호판이 꺼져 있다면 바깥쪽 비상 단자에 9V 건전지를 대 볼 수 있습니다. / 전원이 들어오면 번호를 눌러 문을 열 수 있습니다.
수지구청역 근처 편의점에서 건전지를 구할 수 있습니다. / 단자가 안 보이거나 대도 반응이 없으면 전화 주세요.
문이 열린 뒤에는 안쪽 배터리를 전부 새것으로 바꿔 주세요.
@ 상현동 도어락 비상 전원 9V 건전지

# 급하다고 힘을 쓰지 마세요
문이 안 열릴 때 손잡이를 세게 당기거나 발로 차는 분이 있습니다. / 걸쇠가 더 꽉 물려 일이 커지고, 부모님이 놀라실 수도 있습니다.
- 손잡이를 세게 당기거나 문을 차기
- 드라이버나 카드로 문틈 벌리기
- 번호 여러 번 연속 입력하기
이런 행동은 문과 도어락을 상하게 합니다. / 그대로 두고 연락 주시는 편이 훨씬 빠릅니다.

# 이웃이나 관리 쪽에 도움 청하기
같은 건물 이웃이 열쇠를 맡아 두는 경우도 있습니다. / 입원 전에 가까운 분께 비상 열쇠를 맡겼는지 부모님께 여쭤보세요.
관리 주체가 있는 건물이면 세대 확인을 부탁해 둘 수도 있습니다. / 신분 확인 절차에서도 도움이 되는 경우가 많습니다.

# 전화하실 때 알려주실 것
부모님 상황을 간단히 말씀해 주시면 서두르는 정도를 맞춰서 움직일 수 있습니다. / 건강 상태까지 자세히 말씀하실 필요는 없고 기다릴 수 있는 환경인지만 알려주세요.
- 상현동 안에서 대략 어느 방향인지, 건물 형태
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 부모님이 기다리실 장소가 있는지
- 집 안에 반려동물이 있는지
도어락 사진을 보내주시면 필요한 장비를 챙기기 좋습니다.

# 도착하면 먼저 사시는 분인지 확인합니다
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
부모님 이름으로 된 집이면 부모님 신분증이나 가족 관계를 알 수 있는 서류를 준비해 주세요. / 입원 서류를 챙겨 나오다 신분증을 못 챙기셨다면 병원에서 쓰던 서류가 도움될 수 있습니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다.

# 병원에서 가져온 짐과 서류 챙기기
퇴원할 때는 약, 서류, 짐이 많아 정신이 없습니다. / 문 앞에서 소지품을 다 내려놓고 천천히 정리해 보세요.
열쇠나 신분증, 출입 카드가 가방 어딘가에 섞여 있을 수 있습니다. / 입원 서류 봉투 속에 들어 있는 경우도 있으니 한 번 더 살펴보세요.
부모님이 평소 쓰던 열쇠나 카드가 병원 보관함에 남아 있을 수도 있습니다. / 연락이 닿으면 병원에 확인해 두시는 것도 방법입니다.
@ 상현동 병원 퇴원 후 가방과 열쇠 정리

집에 들어온 뒤에는 부모님이 쉬실 자리와 현관 불부터 챙기시고, 문 문제는 그다음에 천천히 이야기 나눠도 늦지 않습니다. 급한 일이 없다면 서두르지 않으셔도 됩니다.

# 비용은 문 열기 전에 말씀드립니다
도어락 상태와 문 형태를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 아니면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말 없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 열고 난 뒤 부모님 집 점검
문이 열리면 도어락이 다시 잘 잠기고 열리는지 같이 눌러 봅니다. / 배터리가 원인이었다면 새것으로 바꿨는지도 함께 봅니다.
퇴원 직후에는 부모님이 쓰기 편한 방식으로 정리해 두면 좋습니다. / 번호를 쉽게 기억할 수 있게 하고 번호판 불이 잘 보이는지 확인합니다.
- 큰 글씨 메모는 문 안쪽에 적어 두기
- 자녀분께 임시 번호를 따로 등록하기
- 비상 열쇠는 믿을 수 있는 분께 맡기기
고장이 반복되면 [도어락 수리](doorlock-repair.html)를 먼저 보고, 너무 오래됐다면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.

손이 떨리거나 시력이 약해지신 경우 작은 번호판이 불편할 수 있습니다. / 번호 길이를 짧게 하거나 카드, 지문을 함께 쓰도록 정리하는 방법이 있습니다.
설정은 부모님과 함께 한 번씩 눌러 보며 익숙해지게 하는 것이 중요합니다. / 새로 정한 번호는 한 번에 외우시기 어려우니 메모와 함께 시작하세요.
퇴원 뒤 한동안은 자녀분이 자주 들르게 되니 가족 번호나 카드를 따로 하나 만들어 두면 서로 편합니다.

# 상현동 말고 용인 어디든 갑니다
상현동 가까운 풍덕천동, 성복동, 동천동, 죽전동도 다닙니다. / 용인 안이면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html)에, 서울·경기 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

? 상현동 어느 동네든 오시나요? | 네, 주택과 빌라 모두 갑니다. 대략 위치만 알려주세요.
