# 상현동 문 앞에서 기다려야 할 때
상현동은 수지구청역 생활권으로 오가는 분이 많은 주택가이고, 아파트와 빌라가 한 골목에 섞여 있는 곳도 있습니다. / 퇴근하고 집 앞에 도착했는데 문이 안 열리면 출장열쇠가 오기까지 짧게는 몇십 분을 밖에서 보내야 합니다.
그 시간을 계단참에 서서 보낼 수도 있지만, 이웃의 도움을 조금 받으면 훨씬 편해집니다. / 이 글은 문제를 해결하는 방법보다 기다리는 시간을 어떻게 보낼지에 맞춰 적었습니다.
이웃에게 무엇을 부탁해도 되는지, 어떻게 말을 꺼내야 부담이 적은지 순서대로 정리했습니다. / 문을 여는 방법 자체는 [현관문 개문](door-open.html) 페이지에서 따로 보실 수 있습니다.
@ 상현동 계단참에서 출장열쇠를 기다리는 모습

# 먼저 정해야 할 일, 전화는 어디서 걸까
휴대폰이 켜져 있다면 바로 전화하시면 됩니다. / 배터리가 얼마 남지 않았다면 통화 전에 화면 밝기를 낮추고 불필요한 앱을 끄세요.
휴대폰이 집 안에 있거나 꺼져 버렸다면 이웃 전화를 빌려야 합니다. / 이때는 번호를 외워 두지 않았더라도 010-3664-5455 하나만 불러 드리면 되니 어렵지 않습니다.
전화를 빌릴 때는 통화 내용을 길게 끌지 않는 것이 예의입니다. / 위치와 상황, 지금 있는 곳만 짧게 말하면 충분합니다.

# 이웃 문을 두드리기 전에 생각할 시간대
저녁 일곱 시에서 아홉 시 사이는 식사 시간이라 방문이 부담스러울 수 있습니다. / 그래도 사정을 말씀드리면 대부분 이해해 주십니다.
밤 열 시가 넘었다면 초인종을 한 번만 짧게 누르세요. / 안에서 인기척이 없으면 더 누르지 말고 다른 집이나 경비실로 가는 게 낫습니다.
아이가 자는 집은 문 두드리는 소리에 놀랄 수 있으니 되도록 인터폰을 이용하세요. / 인터폰이 없는 건물이라면 낮은 소리로 가볍게 노크합니다.

# 부탁은 이렇게 짧고 분명하게
처음 보는 이웃이라면 자기소개부터 해야 합니다. / 몇 층 몇 호에 사는 사람인데 문이 잠겨서 전화를 잠깐 빌릴 수 있는지 먼저 여쭙니다.
이어서 얼마나 기다려야 하는지 대략 말씀드리면 상대도 마음의 준비를 합니다. / 정확히 모르면 출장열쇠가 도착하는 대로 바로 나오겠다고 덧붙이세요.
거절당해도 서운해하지 않으셔도 됩니다. / 낯선 사람에게 문을 열기 어려운 사정이 있을 수 있으니 다른 방법을 찾으면 됩니다.

# 집 안으로 들어가지 않아도 되는 부탁들
이웃 집 안에 들어가는 것이 꼭 필요한 건 아닙니다. / 현관 앞에서 도움받을 수 있는 일이 의외로 많습니다.
- 휴대폰 잠깐 빌려 통화하기
- 휴대폰 충전기를 잠시 꽂아 두기
- 따뜻한 물 한 컵 부탁하기
- 건물 현관 비밀번호를 대신 눌러 맞이해 주기
- 출장열쇠가 도착하면 건물 출입문을 열어 주기
이 정도만 도움받아도 계단에서 떨며 기다리는 일은 피할 수 있습니다.

# 추운 날과 비 오는 날의 대기 요령
상현동도 한겨울에는 계단 바람이 매섭습니다. / 외투를 걸치지 못한 채 나왔다면 건물 안쪽 계단참이나 복도 모서리 같은 바람이 덜한 곳을 찾으세요.
비가 오는 날은 우산을 접어 둘 곳이 없으면 이웃에게 현관 앞에 놓아도 되는지 물어보세요. / 바닥이 젖어 미끄러우니 신발 밑창 물기도 한 번 털어 주시면 좋습니다.
@ 상현동 빌라 복도에서 이웃에게 부탁하는 장면

# 아이나 어르신이 함께 있을 때
아이가 같이 있다면 이웃 집에서 잠시 쉴 수 있는지 조심스럽게 여쭤보셔도 됩니다. / 낯선 집에 들어가야 한다면 보호자가 곁에 계속 머무는 것이 원칙입니다.
어르신이 서 계시기 힘든 상황이면 의자 하나만 빌려도 큰 도움이 됩니다. / 이럴 때는 전화에서 아이나 어르신이 함께 있다고 먼저 말씀해 주세요.
집 안에 아이나 반려동물이 남아 있다면 상황이 다릅니다. / 기다릴 틈 없이 바로 알려주셔야 하니 [아이와 반려동물이 잠긴 경우](yongin.html)도 먼저 확인해 보세요.

# 신분 확인에 이웃이 도움될 수 있습니다
출장열쇠가 도착하면 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있는 경우가 많은데, 이럴 때 관리사무소나 경비실이 있으면 거주 확인을 부탁할 수 있습니다. / 이웃이 얼굴을 아는 사이라면 옆에서 같이 말씀해 주시는 것도 도움이 됩니다.
다만 이웃의 말만으로 문을 열지는 않으니, 확인 방법은 미리 준비해 두세요. / 확인이 되지 않으면 작업을 할 수 없습니다.

# 기다리는 동안 해두면 좋은 일
시간을 허비하지 말고 아래 일들을 정리해 두세요. / 도착한 뒤 작업이 훨씬 빨라집니다.
- 도어락 사진 찍어 두기 (지금 휴대폰이 있다면)
- 번호판이 켜지는지, 경고음이 나는지 기억해 두기
- 마지막으로 문을 닫은 때와 상황 떠올리기
- 건물 출입 방법과 호수 메모하기
출장 요청 전에 준비할 것은 [출장 이용안내](guide.html)에도 정리해 두었습니다.

# 이웃에게 고마움 표하기
도움을 받았다면 끝나고 나서 짧게 인사를 드리세요. / 초인종을 눌러 감사 인사를 하는 것만으로 충분합니다.
작은 간식이나 음료를 건네는 것도 좋지만 꼭 필요한 건 아닙니다. / 전화를 빌렸다면 통화 기록에 남은 번호를 지워 달라고 부탁받는 일도 있으니 편하게 물어보세요.
앞으로 서로 도움을 주고받을 수 있게 연락처를 교환해 두는 분도 있습니다. / 열쇠를 이웃에게 맡겨 두는 방법도 있지만 반드시 신뢰할 수 있는 사이에서만 하세요.

# 같은 일이 반복되지 않게
다음에는 이런 상황을 피할 수 있도록 작은 습관을 들이시길 권합니다. / 큰 비용이나 수고가 드는 일이 아닙니다.
- 휴대폰 케이스에 집 호수와 비상 연락처 적은 메모 끼우기
- 도어락 배터리 교체 날짜 정해 두기
- 가까운 가족에게 번호 알려 두기
- 문 닫고 나가기 전에 열쇠나 카드 확인하기
키나 카드를 따로 보관하는 방법은 [열쇠 분실 출장](key-call.html)에서 확인하실 수 있습니다. / 고장이 반복된다면 [도어락 수리](doorlock-repair.html)로 먼저 점검받는 게 좋습니다.
@ 상현동 도어락 번호판과 비상 연락처 메모

# 비용은 문 열기 전에 말씀드립니다
도착해서 문과 도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다. / 가능한 한 문과 도어락이 상하지 않는 방법부터 시도합니다.

# 상현동 말고 용인 어디든 갑니다
상현동 옆 풍덕천동, 성복동, 동천동, 죽전동은 물론 용인 안이면 동네 상관없이 24시간 출동합니다. / 용인에서 다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에 정리해 두었습니다.
서울, 경기 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다.
