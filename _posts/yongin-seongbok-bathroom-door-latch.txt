# 화장실 문이 안 열릴 때 가장 먼저 할 일
성복동은 수지구청역 생활권과 이어져 가족 단위로 사는 집이 많은 동네입니다. / 아이들이 화장실을 쓰다 문이 걸리는 일도 그만큼 자주 생깁니다.
안에 있는 사람이 놀라지 않게 목소리를 계속 들려주는 것이 제일 먼저입니다. / 문을 두드리거나 세게 흔들면 더 겁을 먹고 걸쇠를 만지다 잘못될 수 있습니다.
이 글은 화장실 문 걸쇠가 안에서 걸렸을 때 상황별로 해볼 것과 부를 때를 적었습니다. / 현관이 아니라 실내 화장실 문을 다룹니다.
@ 성복동 집 화장실 문 걸쇠 손잡이 부분

# 안에 누가 있는지부터 확인
문 앞에서 "괜찮아요?" 하고 물어 안에 있는 사람이 대답하는지 봅니다. / 대답이 있으면 대부분 급한 상황이 아닙니다. / 안에서 불을 켠 채 가만히 있다면 단순히 걸쇠가 걸린 경우일 때가 많습니다.
대답이 없거나 넘어지는 소리가 났다면 얘기가 달라집니다. / 이 경우는 지체하지 말고 119에 먼저 연락하는 것이 맞습니다.
24시출장열쇠는 응급 구조 기관이 아니라 문을 여는 일을 합니다. / 사람의 안전이 걸린 상황은 구조 기관이 먼저입니다.

# 화장실 문 걸쇠는 이렇게 생겼습니다
화장실 문은 안쪽에서 누름 버튼이나 돌림 손잡이로 잠그는 구조가 많습니다. / 바깥쪽에는 가는 구멍이나 홈이 있어 비상시에 열 수 있게 되어 있는 경우가 많습니다. / 새 집이든 오래된 집이든 이 구멍의 위치는 손잡이 아래나 중앙에 있는 편입니다.
- 손잡이 가운데 누름 버튼식
- 손잡이 중앙 돌림식
- 위쪽에 거는 고리식 걸쇠
- 문틀에 걸리는 빗장식
어떤 종류인지에 따라 열 수 있는 방법이 다르니 먼저 확인하세요. / 화장실 문은 습기 때문에 부품이 녹슬기 쉬워 시간이 지날수록 뻑뻑해집니다.

# 바깥 구멍이 있다면 가는 막대로
돌림식이나 누름식은 바깥쪽 손잡이에 작은 구멍이 있는 경우가 많습니다. / 이 구멍은 비상 해제용으로 만들어진 것입니다.
가는 일자 드라이버나 비상 열쇠를 천천히 밀어 넣고 돌려 보세요. / 힘을 주지 않고 걸리는 느낌이 나는 곳에서 돌리는 것이 요령입니다. / 돌렸을 때 딸깍 소리가 나면 안쪽이 풀린 것입니다.
안쪽 걸쇠가 풀려도 손잡이가 바로 안 돌아가면 문을 살짝 밀면서 돌려 보세요.
구멍이 없는 모델이거나 열쇠를 찾을 수 없다면 억지로 하지 마세요. / 구멍 안에서 막대가 부러지면 오히려 열기가 어려워집니다.
막대를 넣었을 때 아무 느낌이 없다면 구멍이 가짜 장식일 수도 있으니 더 밀어 넣지 마세요.

# 고리식 걸쇠는 문틈 방향이 중요합니다
안쪽 고리가 문틀 걸이에 걸려 있는 경우는 문을 살짝 밀고 당기며 흔들면 고리가 흔들려 빠지기도 합니다. / 힘을 세게 주면 고리가 부러지거나 문틀이 뜯어집니다.
문틈이 너무 좁으면 얇은 플라스틱 카드가 도움이 되기도 하지만 문이 상하기 쉽습니다. / 자신이 없다면 시도하지 말고 맡기시는 편이 안전합니다.
@ 화장실 문틈과 안쪽 고리 걸쇠 확인

# 아이가 안에 있을 때의 요령
아이가 걸쇠를 잠그고 나오지 못하면 아이가 가장 놀랍니다. / 문 너머로 차분하게 말해 주세요.
- 손잡이를 반대로 돌려 보라고 천천히 알려 주기
- 안쪽 버튼을 눌러 보라고 안내하기
- 아이가 울면 먼저 달래고 시도는 잠시 미루기
- 문을 잡고 흔들지 못하게 하기
아이가 직접 열 수 없는 모양이면 서두르지 말고 전화 주세요. / 아이가 안에 있다는 사실을 먼저 말씀해 주시면 더 조심해서 작업합니다.

# 어르신이 안에 계실 때는
어르신이 화장실에서 문을 잠그고 대답이 없는 경우 걱정이 앞섭니다. / 이런 상황에서는 문을 여는 것보다 구조 요청이 우선일 수 있습니다.
의식이 있고 대화가 된다면 침착하게 안쪽 걸쇠 위치를 안내해 주세요. / 어르신은 다시 낯선 방식으로 돌려 보는 것이 어려울 수 있으니 천천히 말씀하세요. / 안쪽에서 손잡이를 짚고 일어서다 걸쇠를 건드려 잠긴 경우도 있습니다.

# 문을 부수기 전에 생각할 것
급한 마음에 문을 발로 차면 문틀과 문짝이 모두 상합니다. / 손잡이 축이 휘면 이후로도 문이 잘 안 열립니다.
화장실 문은 방문보다 얇은 경우가 많아 부서지면 파편이 날리기도 합니다. / 안에 계신 분이 다칠 수도 있습니다.
문 상태를 최대한 지키며 여는 방법을 먼저 찾는 것이 결과적으로 비용도 아낍니다. / 문 교체까지 가는 것보다 걸쇠만 손보는 편이 훨씬 가볍게 끝납니다.

# 출장열쇠를 부를 때 알려 주세요
[성복동 용인 출장열쇠](yongin.html)에 전화하시면 아래를 물어봅니다.
- 안에 누가 있는지, 대답이 되는지
- 손잡이 모양(누름식, 돌림식, 고리식)
- 바깥 구멍이 있는지
- 문 소재(합판, 목문, 유리 포함 여부)
사진을 문자로 주시면 맞는 도구를 챙길 수 있습니다. / 신분 확인은 집에 사시는 분인지 신분증 주소나 우편물, 관리사무소 확인 중 하나면 됩니다. / 이웃 집이 아니라 본인 세대의 문이라는 점만 확인되면 됩니다.

# 비용은 문을 열기 전에 먼저
상태를 보고 비용을 먼저 말씀드립니다. / 동의하시면 시작하고, 못 열면 비용은 받지 않습니다.
부품을 바꿔야 할 때는 바꾸기 전에 따로 여쭤봅니다. / 자세한 진행은 [이용안내](guide.html)에 있습니다.
@ 성복동 화장실 문 걸쇠 해제 작업

# 열고 난 뒤 걸쇠 상태 점검
문이 열리면 걸쇠가 왜 걸렸는지 같이 봅니다. / 걸쇠가 헐거워 자꾸 저절로 걸리는 경우도 있습니다.
- 걸쇠 스프링이 약해졌는지
- 문이 처져 걸이와 어긋나는지
- 손잡이 나사가 풀렸는지
필요하면 [도어락 수리](doorlock-repair.html), [도어락 교체](doorlock-replace.html), [현관문 개문](door-open.html) 상담을 도와드립니다. / 사용에 큰 문제가 없으면 교체는 권하지 않습니다.
걸쇠가 자주 걸리는 문은 한 번 고쳐 두면 오래 편하게 쓸 수 있습니다. / 문이 열린 뒤에는 안쪽 손잡이를 몇 번 돌려 부드럽게 움직이는지 같이 확인합니다.
욕실 습기가 심한 집은 환기를 자주 해 부품이 녹스는 속도를 늦추는 것도 도움이 됩니다.

# 같은 일을 줄이는 집안 습관
화장실 문은 가족이 모두 쓰는 문이라 사용 규칙을 정해 두면 좋습니다. / 아이에게는 안쪽 걸쇠를 잠그는 법과 푸는 법을 같이 알려 주세요.
- 비상 해제 열쇠나 도구를 화장실 밖 높은 곳에 두기
- 아이가 장난으로 잠그지 않도록 교육하기
- 걸쇠가 뻑뻑하면 미리 점검하기
문 위쪽에 도구를 올려 두는 것은 아이 손이 닿지 않아 좋은 방법입니다.
욕실 문 아래 환기구나 틈으로 안이 보이는 구조라면 더 빨리 상황을 파악할 수 있습니다.
@ 성복동 비상 해제 도구를 문 위에 보관한 모습

# 성복동 말고 용인 어디든
성복동 가까이 풍덕천동, 상현동, 죽전동, 동천동, 신봉동도 다닙니다. / 수지구청역, 죽전역, 기흥역, 동백역 생활권이면 어디든 연락 주세요.
다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.

화장실 문 걸쇠는 침착하게 안에 있는 사람을 안심시키는 것이 반입니다. / 구멍 하나, 버튼 하나를 확인하는 순서만 알아도 많이 도움이 됩니다.
24시출장열쇠는 용인 전 지역에서 24시간 전화를 받습니다. / 전화 010-3664-5455로 문 상태를 알려 주세요.
