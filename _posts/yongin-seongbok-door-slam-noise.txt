# 밤마다 현관문이 쿵 닫혀서 눈치가 보인다면
성복동에서 수지구청역까지 오가다 보면 늦은 시간에 귀가하는 일이 잦습니다. / 조용히 닫으려 해도 문이 쿵 소리를 내며 닫히면 복도 전체가 울려 이웃 눈치가 보입니다.
문소리는 단순히 시끄러운 문제가 아니라 문이 보내는 신호일 때가 많습니다. / 소리가 나는 위치와 종류만 구분해도 어디가 문제인지 대부분 짐작할 수 있습니다.
이 글은 쿵, 삐걱, 뻑뻑함을 나누어 원인과 집에서 해볼 수 있는 점검을 적었습니다. / 해결이 어려운 경우 언제 전화하면 되는지도 같이 정리했습니다.
@ 성복동 현관문 소음 점검 출장

# 소리 종류부터 구분해 보세요
같은 소음이라도 원인이 모두 다릅니다. / 문을 천천히 열고 닫아 보면서 어떤 소리인지 먼저 확인합니다.
- 닫히는 끝에서 쿵 하고 부딪히는 소리
- 열고 닫는 동안 계속 나는 삐걱 소리
- 걸쇠가 문틀에 긁히는 듯한 마찰음
- 손잡이를 돌릴 때 나는 덜그럭 소리
쿵 소리는 완충이 부족할 때, 삐걱 소리는 경첩 쪽, 마찰음은 걸쇠와 문틀 위치에서 나오는 경우가 많습니다. / 덜그럭하는 소리는 손잡이나 도어락 고정 쪽을 의심해 볼 수 있습니다.

# 쿵 소리의 가장 흔한 원인은 도어클로저
도어클로저는 문 위쪽에 달려 문이 천천히 닫히게 해 주는 장치입니다. / 이 장치의 속도 조절이 틀어지면 마지막에 문이 세게 닫힙니다.
클로저 몸체에는 보통 작은 조절 나사가 두 개쯤 있습니다. / 닫히는 속도와 마지막 걸리는 속도를 따로 조절하는 구조입니다.
클로저 쪽에서 기름이 번져 나온 흔적이 있다면 내부 유압이 샌 것이어서 조절만으로는 해결되지 않습니다. / 이럴 때는 클로저 자체를 바꾸는 편이 확실합니다.
나사를 무리하게 돌려 풀면 부품이 빠질 수 있으니 반 바퀴 정도씩만 건드려 보세요. / 모르겠으면 그대로 두고 문의하셔도 됩니다.

# 삐걱 소리는 경첩에서 시작되는 경우가 많습니다
경첩의 회전축에 먼지가 끼거나 마른 상태로 오래 쓰면 삐걱 소리가 납니다. / 경첩은 현관문 한쪽에 보통 두세 개씩 달려 있습니다.
소리가 어느 경첩에서 나는지 문을 천천히 움직이며 귀를 가까이 대 보세요. / 한 군데만 유독 크게 나면 그 경첩만 점검하면 됩니다.
가정용 기름을 많이 뿌리면 먼지가 엉겨 붙어 나중에 더 심해집니다. / 소량의 전용 윤활제를 축에만 아주 조금 쓰는 것이 좋습니다.
@ 용인 성복동 경첩 윤활 도어클로저 조정

# 뻑뻑하게 닫히는 문은 처짐을 의심하세요
문을 닫을 때 위쪽이나 아래쪽이 문틀에 스치듯 걸리면 문이 아래로 처진 것입니다. / 경첩 나사가 헐거워졌거나 문 무게로 경첩이 조금씩 휜 경우입니다.
처진 문은 걸쇠가 받이 구멍에 정확히 맞지 않아 닫기 힘들고, 결국 도어락 고장으로 이어집니다. / 소음 문제로 시작해 문이 안 열리는 문제까지 번지기도 합니다.
경첩 나사가 헐거우면 드라이버로 조여 주는 것만으로 좋아지기도 합니다. / 나사 구멍이 닳았다면 더 굵은 나사를 쓰거나 다른 위치를 잡아야 합니다.
이 부분은 자세한 문 상태 점검이 필요하므로 [도어락 수리](doorlock-repair.html) 페이지도 참고해 주세요.

# 걸쇠가 받이에 긁히는 소리
문이 닫힐 때 걸쇠가 문틀 받이 구멍에 닿으며 긁히는 소리가 나는 경우가 있습니다. / 받이 구멍의 높이가 걸쇠와 맞지 않으면 닫을 때마다 마찰이 생깁니다.
받이 금속판 주변에 닳은 흔적이나 반짝이는 긁힌 자국이 보이면 위치가 어긋난 증거입니다. / 이 흔적이 있으면 문이 처졌다는 신호와 함께 봐야 합니다.
받이 위치를 아주 조금 조정하거나 구멍을 다듬으면 소리가 확 줄어듭니다. / 이 작업은 도구가 필요하니 직접 하기보다는 맡기시길 권합니다.

# 문틈에 끼는 고무 몰딩도 확인해 보세요
문틀을 따라 붙어 있는 고무 몰딩이 오래돼 딱딱해지거나 들뜨면 문이 닫힐 때 걸리거나 소리를 냅니다. / 몰딩은 소음과 바람을 막는 부품이라 상태가 나쁘면 효과가 떨어집니다.
몰딩이 찢어졌거나 일부가 떨어져 나갔다면 그 부분만 새로 붙여도 개선됩니다. / 문 전체를 바꿀 일은 거의 없습니다.
겨울에는 몰딩이 굳어 문이 뻑뻑하고, 여름에는 늘어나 걸리기도 합니다. / 계절에 따라 문 느낌이 달라진다면 몰딩과 습기를 함께 의심해 보세요.

# 성복동 위치와 증상은 이렇게 알려 주세요
소음 문제는 급하지 않아 보이지만 정확히 설명할수록 한 번에 해결됩니다. / 아래 정보를 알려 주시면 챙겨 갈 부품을 미리 정할 수 있습니다.
- 아파트 단지 이름과 동, 호수
- 소리가 나는 때 (열 때, 닫을 때, 닫기 직전 중 언제인지)
- 문 위쪽에 도어클로저가 달려 있는지
- 문을 닫을 때 위나 아래가 문틀에 스치는지
- 최근에 문을 바꾸거나 도어락을 교체한 적이 있는지
문틀과 문이 만나는 곳을 찍은 사진이 있으면 더 좋습니다. / 소리는 사진에 안 나오므로 말씀으로 상황을 설명해 주세요.

# 방문하면 사시는 분인지 먼저 확인합니다
소음 점검이라도 집 안 문을 만지는 일이라 사시는 분인지 확인한 뒤 시작합니다. / 신분증 주소, 주소가 있는 우편물, 관리사무소 확인 중 하나면 됩니다.
집에 안 계실 때 대신 연락하신 가족이라면 입주민 확인이 되는 방법을 미리 상의하세요. / 안 되는 상황이면 작업을 시작하지 않습니다.
@ 성복동 24시출장열쇠 문 점검 방문

# 비용은 점검 후, 시작 전에 말씀드립니다
소리의 원인이 조절 나사 하나인 경우도 있고 부품 교체가 필요한 경우도 있습니다. / 문 상태를 본 뒤 어느 쪽인지 설명드리고 비용은 시작하기 전에 먼저 말씀드립니다.
마음에 안 드시면 그냥 돌아갑니다. / 열기 전에 말씀드리지 않은 비용이 나중에 붙는 일은 없습니다.
문이 아예 안 열리는 상황까지 번졌는데 끝내 열지 못하면 비용은 받지 않습니다. / 진행 방식은 [이용안내](guide.html)에서 확인하실 수 있습니다.

# 고친 뒤 확인하는 순서
조정을 마치면 문을 여러 번 여닫아 소리가 줄었는지 직접 확인합니다. / 아주 느리게 닫아 보고, 평소 속도로도 닫아 보고, 가볍게 밀어서도 닫아 봅니다.
걸쇠가 받이에 정확히 들어가는지, 도어락 번호가 잘 눌리는지까지 같이 봅니다. / 소음만 줄이고 잠금이 헐거워지면 안 되기 때문입니다.
클로저를 바꾼 경우 닫히는 속도가 알맞은지 방문자에게 물어보고 맞춥니다. / 어르신이나 아이가 쓰는 집이라면 조금 더 부드럽게 맞춥니다.

# 문 소리, 집에서 하는 예방 습관
문을 닫을 때 손잡이를 놓고 밀어 닫는 습관은 클로저와 걸쇠에 무리를 줍니다. / 손으로 끝까지 잡고 걸쇠가 들어갈 때까지 닫아 주세요.
- 계절이 바뀔 때 경첩 나사 조임 확인
- 문틀 몰딩 청소와 들뜬 곳 점검
- 비가 많은 철에는 문틀 아래쪽 물기 닦기
- 클로저 조절 나사에서 기름 흔적 확인
- 문에 무거운 물건을 걸어 두지 않기
문틀과 문이 균형을 이루면 도어락도 오래 갑니다. / 문 자체의 상태를 가볍게 보지 않는 것이 고장을 줄이는 길입니다.

# 성복동 말고 용인 어디든 갑니다
성복동과 가까운 동천동, 상현동, 풍덕천동은 물론 죽전과 기흥 쪽도 다닙니다. / 용인 안이면 시간에 상관없이 24시간 연락 주세요.
지역별 안내는 [용인시 출장열쇠](yongin.html) 페이지에 있고, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다. / 문이 아예 안 열리는 경우는 [현관문 개문](door-open.html)도 참고해 주세요.

? 윤활제를 직접 뿌려도 되나요? | 소량을 경첩 축에만 쓰는 정도는 괜찮지만 과하게 뿌리면 오히려 먼지가 붙으니 주의하세요.
? 도어클로저는 꼭 있어야 하나요? | 필수는 아니지만 문이 천천히 닫혀 소음과 걸쇠 마모를 줄여 줍니다.
? 문이 안 열릴 만큼 처졌어도 해결되나요? | 네, 문 상태를 보고 방법을 말씀드립니다. 못 열면 비용은 받지 않습니다.
