# 부모님 집 문, 마지막으로 살펴본 게 언제인가요
성복동은 수지구청역 쪽 생활권과 이어져 부모님을 가까이 모시고 사는 가족이 많은 동네입니다. / 자주 찾아뵙지 못하는 부모님 댁이라면 현관문과 도어락 상태는 오랫동안 아무도 들여다보지 않은 곳이 되기 쉽습니다.
어르신 혼자 사는 집에서 문이 안 열리면 본인이 느끼는 불안이 크고, 멀리 있는 자녀는 더 조급해집니다. / 그래서 문제가 생기기 전에 한 번 살펴보고 쓰기 편하게 맞춰 두는 것이 좋습니다.
이 글은 성복동 부모님 집 도어락을 점검할 때 확인할 것을 순서대로 정리했습니다. / 문이 안 열려 도움을 청하게 되었을 때의 연락 방법도 담았습니다.
@ 성복동 부모님 댁 현관 도어락 점검

# 방문하는 날 5분이면 되는 점검
부모님 댁을 찾아가신 김에 현관문 앞에서 아래 항목을 확인해 보세요. / 공구가 필요한 일은 없고, 직접 눌러 보고 들어 보는 것이 전부입니다.
- 번호를 누를 때 소리가 또렷하게 나는지
- 문이 닫힐 때 걸쇠가 끝까지 들어가는지
- 안쪽 잠금 손잡이가 부드럽게 돌아가는지
- 열쇠 구멍이 있다면 열쇠가 잘 들어가는지
- 번호판 불빛이 어둡지 않은지
하나라도 평소와 다르다면 사진이나 영상을 찍어 두세요. / 나중에 전화로 상태를 설명할 때 큰 도움이 됩니다.

# 배터리 교체는 자녀가 먼저 챙기기
어르신들은 경고음이 나도 고장이 아니라고 여기고 그냥 두는 경우가 많습니다. / 소리가 거슬리더라도 어떻게 해야 하는지 몰라 참고 지내기도 합니다.
방문하실 때마다 배터리를 새것으로 교체하고 날짜를 적어 두는 방법이 가장 확실합니다. / 건전지는 한꺼번에 모두 바꿔야 하며 일부만 바꾸면 곧 다시 약해집니다.
번호판이 꺼졌을 때 쓰는 9V 건전지를 현관 신발장 안쪽처럼 눈에 띄는 곳에 하나 두세요. / 어르신께는 쓰는 방법을 사진과 함께 큰 글씨로 적어 드리면 좋습니다.

# 번호는 짧고 익숙한 길이로
번호가 복잡하면 어르신이 헷갈려 여러 번 틀리게 되고, 틀린 횟수가 쌓이면 도어락이 잠시 입력을 막습니다. / 그럴수록 당황해 더 누르게 되는 악순환이 생깁니다.
부모님이 오래 기억하는 숫자를 바탕으로 하되 남이 쉽게 짐작할 숫자는 피하는 것이 좋습니다. / 정하는 과정에 부모님이 직접 참여하면 훨씬 잘 기억하십니다.
번호를 정했다면 자녀와 부모님이 함께 안팎에서 몇 번 눌러 보며 익히세요. / 말로 알려드리기보다 손으로 익히는 편이 오래 갑니다.

# 열쇠와 카드키를 두는 위치
번호를 잊었을 때를 대비해 열쇠나 카드키를 한 곳에 두고 가족이 위치를 알아 두면 좋습니다. / 문 밖 화분 밑처럼 누구나 짐작하는 곳은 피해 주세요.
가까이 사는 이웃이나 믿을 만한 친척에게 맡겨 두는 방법도 있습니다. / 급할 때 문을 열어 줄 사람이 가까이에 있다는 것만으로도 안심이 됩니다.
카드키를 함께 쓰는 제품이라면 분실했을 때 어떻게 하는지 미리 알아 두세요. / 자세한 내용은 [도어락 수리](doorlock-repair.html) 페이지를 참고하셔도 됩니다.
@ 성복동 어르신 집 도어락 번호 열쇠 정리

# 안쪽 보조키와 걸쇠 쓰는 습관
어르신 댁에서 흔한 일은 안쪽 보조키를 잠근 채 문을 닫고 나오는 경우입니다. / 외출하면서 잠금 손잡이를 돌려 두었다가 돌아와 문 앞에서 막힙니다.
보조키를 쓰는 습관이 있다면 외출할 때는 풀어 두는 것으로 규칙을 정하세요. / 손잡이에 눈에 띄는 작은 스티커를 붙여 두는 방법도 효과가 있습니다.
반대로 집 안에 계실 때는 보조키를 걸어 두는 것이 안전합니다. / 다만 안에서 쓰러지시는 일이 생겼을 때 외부에서 열기 어려워지니 이런 점도 가족이 알고 있어야 합니다.

# 어르신이 안에 계신데 문이 안 열릴 때
부모님이 안에 계시는데 연락이 안 되거나 문이 안 열리면 우선 침착하게 전화로 부모님 상태를 확인하세요. / 연락이 닿지 않으면 가까운 이웃이나 경비실, 관리사무소에 먼저 알려 안부를 확인하는 것이 순서입니다.
몸이 불편해 보이는 위급한 상황이라면 열쇠 부르기 전에 119에 먼저 연락하세요. / 그다음에 문을 여는 일은 저희가 도와드릴 수 있습니다.
이런 경우에는 전화로 먼저 상황을 꼭 말씀해 주세요. / 급한 정도에 따라 안내 순서가 달라집니다.

# 연락처를 문 안쪽에 붙여 두기
부모님이 당황하면 전화번호를 떠올리기 어려워집니다. / 현관 안쪽 잘 보이는 곳에 자녀 연락처와 관리사무소 번호를 큰 글씨로 적어 붙여 두세요.
문 앞에서 막혔을 때 누구에게 먼저 전화할지 순서까지 적어 두면 더욱 좋습니다. / 이웃에게 부탁해야 할 때를 위해 가까운 이웃의 호수도 함께 알아 두세요.
이런 작은 준비가 있으면 문이 잠겼을 때 부모님이 혼자 오래 불안해하는 시간을 줄일 수 있습니다.

# 문 열기를 부탁하실 때 알려주실 정보
성복동에서 부모님 집 문이 안 열려 연락 주실 때는 아래 내용이 도움이 됩니다.
- 동과 호수, 수지구청역 쪽인지 주변 큰길 쪽인지
- 부모님이 안에 계신지, 밖에 계신지
- 도어락 모양과 번호판 상태
- 열쇠 구멍이나 카드키가 있는지
- 부모님이 약이나 도움이 필요한 상황인지
부모님께 전화로 번호판 상태를 직접 물어보기 어렵다면 사진을 보내 달라고 부탁해 보세요.

# 신분 확인은 이렇게 합니다
자녀가 문 앞에 오신 경우에도 그 집 가족이 맞는지 확인이 필요합니다. / 부모님과 연락이 되면 통화로 허락을 받는 방법이 가장 빠릅니다.
부모님 신분증, 주소가 적힌 우편물, 관리사무소 확인 중 하나를 준비해 주세요. / 어르신이 직접 확인해 주시기 어려운 상황이면 관리사무소나 경비실을 통해 세대 확인을 받을 수 있습니다.
번거로워 보여도 이웃과 가족 모두를 지키는 절차입니다.

# 비용은 열기 전에 먼저
문과 도어락 상태를 보고 얼마인지 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 들지 않으면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
자세한 진행은 [이용안내](guide.html)에 적어 두었고, 문 열기 방식은 [현관문 개문](door-open.html) 페이지에서 볼 수 있습니다.

# 열고 난 뒤 부모님 집에서 할 일
문이 열리면 부모님이 쓰기 편하도록 한 번 더 손봅니다. / 번호가 헷갈리게 설정되어 있다면 짧고 외우기 쉬운 번호로 다시 등록해 드립니다.
경고음이 크고 자주 나면 어르신이 불편하실 수 있어 소리 설정을 확인합니다. / 필요하면 [도어락 교체](doorlock-replace.html)가 맞는지도 부담 없이 말씀드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다.
@ 성복동 부모님 댁 도어락 설정 마무리

# 성복동 말고 용인 어디든
성복동 이웃 동네인 상현동, 풍덕천동, 동천동, 죽전동도 다닙니다. / 용인 안이면 어느 동네든 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html)에서 볼 수 있고, 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
