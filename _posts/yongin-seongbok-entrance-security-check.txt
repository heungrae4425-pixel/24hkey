# 성복동 현관 방범, 어렵게 생각하지 않으셔도 됩니다
성복동은 새 아파트와 빌라가 함께 있는 동네라 도어락과 문 상태가 집마다 다릅니다. / 방범이라고 하면 큰 공사를 떠올리시지만 평소 상태를 한 번 눈으로 확인하는 것만으로도 도움이 됩니다.
이 글은 불안을 키우려는 글이 아닙니다. / 집에서 5분이면 해볼 수 있는 점검 순서만 정리했습니다.
도움이 필요하면 [용인 출장열쇠](yongin.html)에 연락 주세요. / 성복동은 24시간 출동합니다.
@ 성복동 출장열쇠 현관 방범 점검

# 먼저 도어락 번호판과 손잡이를 살펴보세요
번호판에 유독 많이 닳은 숫자가 있으면 쓰는 번호가 다른 사람에게 짐작될 수 있습니다. / 이런 경우 번호를 바꾸고 번호판을 마른 천으로 닦아 두면 좋습니다.
손잡이가 흔들리거나 헐겁다면 나사가 풀렸을 가능성이 큽니다. / 나사만 조여도 해결되는 경우가 있지만 안쪽 부품이 닳았다면 점검이 필요합니다.
번호판에서 이상한 소리가 나거나 반응이 느리면 배터리부터 확인하세요. / 배터리가 약해지면 오작동이 잦아집니다.
- 번호판이 깨끗하고 반응이 빠른지
- 손잡이가 흔들리지 않는지
- 배터리 경고음이 없는지
- 문을 닫을 때 잠금 소리가 또렷한지

# 문을 닫았을 때 완전히 잠기는지 확인합니다
문이 닫힌 뒤 걸쇠가 끝까지 들어가는지 소리로 확인해 보세요. / 소리가 약하거나 걸쇠가 덜 들어가면 문틀과 위치가 어긋난 것일 수 있습니다.
문을 살짝 밀어 봐서 흔들림 없이 닫혀 있는지 봅니다. / 틈이 크게 벌어져 있다면 경첩이나 문 처짐을 의심할 수 있습니다.
이런 상태는 눈에 띄는 고장은 아니지만 점검해 두는 것이 안전합니다. / 필요하면 위치를 조정해 드립니다.

# 보조키와 걸쇠도 같이 확인합니다
도어락과 별도로 달려 있는 보조키는 평소에 잘 안 쓰다가 고장 나 있기도 합니다. / 한 번씩 돌려서 부드럽게 움직이는지 확인해 보세요.
열쇠가 뻑뻑하거나 덜 들어간다면 먼지가 쌓였거나 열쇠가 닳았을 수 있습니다. / 억지로 돌리지 말고 연락 주세요.
보조키를 잠그고 외출하는 습관을 들이면 문 앞에서 닫힌 줄 모르고 나가는 일을 줄일 수 있습니다. / 다만 안에서 잠근 채 나오지 않도록 주의하세요.
@ 성복동 24시 출장열쇠 보조키 점검

# 문틈과 경첩을 눈으로 확인합니다
문 옆면과 문틀 사이 간격이 위아래로 같은지 보세요. / 한쪽만 넓다면 문이 한쪽으로 처졌다는 신호입니다.
경첩 나사가 풀려 있거나 녹이 보이는지도 확인합니다. / 경첩이 상하면 문 전체가 처져 잠금 위치까지 어긋납니다.
경첩 문제는 방치하면 나중에 도어락 고장으로 이어지기도 합니다. / 눈에 띄면 그때 바로 점검받는 편이 낫습니다.

# 번호를 오래 바꾸지 않았다면 바꿔 두세요
이사 온 뒤 번호를 한 번도 안 바꾼 집이 많습니다. / 전에 살던 분이나 공사하신 분이 알고 있을 수 있는 번호라면 새로 바꾸는 것이 안전합니다.
생일이나 전화번호처럼 쉽게 짐작되는 번호는 피하세요. / 가족과 함께 외우기 쉽지만 남이 짐작하기 어려운 번호가 좋습니다.
번호를 바꾼 뒤에는 가족에게 꼭 알려 주세요. / 모르는 사이에 바뀌어서 문 앞에서 막히는 일이 가장 흔합니다.

# 카드키와 열쇠 개수를 한 번 세어 보세요
등록된 카드키와 열쇠가 몇 개인지 알고 있는지 확인해 보세요. / 잃어버린 카드가 있다면 해당 카드를 삭제하고 새로 등록해 두는 것이 좋습니다.
오래 쓴 카드키는 잘 안 읽히기도 해서 문 앞에서 당황하게 됩니다. / 미리 새 카드를 만들어 두면 급한 날에 도움이 됩니다.
카드키 분실 상황은 [도어락 수리](doorlock-repair.html) 페이지에 적어 둔 내용과 비슷하게 처리합니다. / 정리는 전화로도 안내해 드립니다.

# 불안을 부추기는 광고는 조심하세요
방범 이야기를 하면서 비싼 제품을 무조건 권하는 곳도 있습니다. / 저희는 현재 문과 도어락 상태를 보고 필요한 만큼만 말씀드립니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 꼭 필요한 부분이 있을 때만 바꾸는 방법을 안내합니다.
궁금한 점이 있으면 사진 한 장만 보내 주세요. / 전화로 먼저 필요한 점검 범위를 말씀드립니다.

# 문 앞에서 열쇠 없이 막혔을 때
점검만 하다가 도어락이 갑자기 안 열리는 일은 드뭅니다. / 그래도 문이 안 열리는 날이 올 수 있으니 대비해 두는 것이 좋습니다.
문이 안 열릴 때는 [현관문 개문](door-open.html) 페이지에 적어 둔 순서대로 연락 주세요. / 사시는 분인지 확인한 뒤에 비파손으로 먼저 시도합니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.

# 이럴 땐 전문가에게 점검을 받아 보세요
스스로 확인해도 이유를 모르겠는데 문이 불안하게 느껴지는 경우가 있습니다. / 그럴 때는 사진과 상황만 알려 주셔도 상담이 가능합니다.
- 번호를 눌러도 가끔 반응이 없는 경우
- 문이 닫힐 때 걸쇠가 덜 들어가는 느낌
- 손잡이를 돌릴 때 이상한 소리가 나는 경우
- 열쇠가 뻑뻑해진 경우
현장에서 보고 필요한 부분만 손보도록 안내해 드립니다.
@ 성복동 도어락 현관문 점검 출장

# 성복동에서 점검 상담을 요청하는 방법
성복동 아파트와 빌라, 주택가 어디든 24시간 연락을 받습니다. / 죽전역과 수지구청역 쪽 가까운 동네도 위치를 받으면 예상 도착 시간을 먼저 말씀드립니다.
도어락 사진과 문 전체 사진을 보내 주시면 상담이 쉽습니다. / 집 안에 아이나 반려동물이 있는지도 알려 주세요.
다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다. / 진행 순서는 [이용안내](guide.html)에 적어 두었습니다.

# 비용은 작업 전에 먼저 말씀드립니다
점검만 받으셔도 어떤 부분을 손봐야 하는지 먼저 설명해 드립니다. / 비용은 작업 전에 안내하고, 괜찮다고 하셔야 진행합니다.
교체가 꼭 필요하다고 판단되면 이유를 말씀드립니다. / 사시는 분이 결정하시고 저희는 강요하지 않습니다.
필요 없는 부품을 권하는 일은 하지 않습니다. / 처음 안내한 내용에서 벗어나는 비용은 생기지 않도록 합니다.
