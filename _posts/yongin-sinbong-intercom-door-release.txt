# 인터폰 버튼은 눌렀는데 문이 안 열릴 때
신봉동은 수지구청역 방향으로 이어지는 주거지라 아파트와 연립이 어우러져 있고, 인터폰으로 현관을 열어 주는 집이 많습니다. / 택배나 가족이 밖에 서 있는데 열림 버튼을 눌러도 아무 소리가 없으면 난감합니다.
이 글은 인터폰 열림 버튼으로 문이 열리지 않을 때 세대 쪽 문제인지 출입구 쪽 문제인지 나눠서 확인하는 순서를 정리한 글입니다. / 우리 집 현관문이 안 열리는 경우와는 원인이 많이 다릅니다.
@ 신봉동 인터폰 열림 버튼 점검

# 열림 버튼이 하는 일을 먼저 이해하기
인터폰의 열림 버튼은 세대 안 장치에서 신호를 보내 출입구의 잠금을 풀어 주는 방식입니다. / 그래서 문제는 세대 장치, 연결선, 출입구 문 쪽 가운데 어디서든 생길 수 있습니다.
같은 인터폰이라도 현관 앞 공동 출입문을 여는 버튼과 우리 집 현관을 여는 버튼은 서로 다릅니다. / 어느 문을 열려는 상황인지부터 분명히 해 두면 원인을 훨씬 빨리 찾을 수 있습니다.

# 세대 안 인터폰 화면과 소리부터
먼저 집 안 인터폰이 정상인지 확인합니다. / 화면이 꺼져 있거나 통화 소리가 끊긴다면 인터폰 자체에 문제가 있을 가능성이 큽니다.
- 호출 소리와 화면이 정상적으로 나오는지
- 통화 중에 열림 버튼이 눌리는 소리나 표시가 나는지
- 다른 방 인터폰이나 앱이 있다면 그쪽도 되는지
열림 버튼을 누를 때 아무 반응이 없다면 버튼 접점이 닳았을 수도 있습니다. / 몇 번 천천히 눌러 보되 세게 반복해서 누르지는 마세요.

# 인터폰 전원과 연결 상태 확인
인터폰은 대개 벽 안의 전원과 연결선으로 동작합니다. / 전원이 꺼져 있거나 정전 직후에는 한동안 제대로 동작하지 않을 수 있습니다.
최근에 정전이 있었거나 인근에서 공사를 했다면 그 영향일 수 있습니다. / 잠시 기다린 뒤 다시 눌러 보면 돌아오는 경우도 있습니다.
인터폰 배선이나 단자함은 일반 세대에서 열어 만지는 것을 권하지 않습니다. / 선을 잘못 건드리면 다른 세대 연결에도 영향을 줄 수 있으니 관리사무소에 먼저 알려 주세요.

# 출입구 쪽 문제일 때 나타나는 모습
세대 안에서 버튼을 누르면 딸깍 소리나 표시가 나는데도 밖에서 문이 안 열린다면 출입구 쪽 문제를 의심해야 합니다. / 문 쪽 전기 잠금장치나 문이 걸리는 부분이 원인일 수 있습니다.
문이 틀에 꽉 끼어 있으면 잠금이 풀려도 문이 밀리지 않습니다. / 문틀이 처졌거나 문이 휜 경우 이런 일이 생기기도 합니다.
공동 출입문은 개인이 만지는 대상이 아니라 건물 관리 영역입니다. / 관리사무소나 건물 관리 주체에게 알려 주는 것이 먼저입니다.
@ 신봉동 공동현관문 열림 확인

# 우리 집 현관문이 안 열리는 경우와 헷갈리지 않기
인터폰이 안 되는 문제와 우리 집 현관문이 안 열리는 문제는 별개입니다. / 인터폰이 안 되더라도 현관 도어락이 정상이라면 번호나 카드로 직접 열 수 있습니다.
반대로 현관 도어락이 안 열리는데 인터폰으로 열어보려고 하는 경우도 있습니다. / 이럴 때는 현관 도어락 쪽부터 확인해야 합니다.
어느 쪽 문제인지 헷갈린다면 지금 막힌 곳이 어디인지부터 정리해 보세요. / 정리해서 말씀해 주시면 전화로 확인하는 시간도 줄어듭니다.

# 하지 말아야 할 행동
인터폰이 안 되면 출입문을 힘으로 열고 싶은 마음이 생길 수 있습니다. / 하지만 공동 출입문을 임의로 건드리면 건물 전체에 영향을 줄 수 있습니다.
- 공동 출입문을 발로 차거나 억지로 당기기
- 인터폰 본체를 분해하거나 선을 만지기
- 다른 사람이 들어갈 때 같이 따라 들어가기
- 열림 버튼을 연달아 세게 누르기
특히 다른 사람 출입에 맞춰 들어가는 것은 이웃의 안전에도 영향을 줍니다. / 관리사무소에 사정을 말하고 정식으로 열어 달라고 요청하는 편이 낫습니다.

# 관리사무소에서 도와줄 수 있는 것
공동 출입문과 인터폰 시스템은 보통 관리사무소가 관리합니다. / 인터폰 점검이 필요하면 관리사무소를 통해 담당 업체에 요청할 수 있습니다.
공동 출입문이 안 열리는 상황이라면 관리사무소에서 임시로 열어 줄 수 있는지도 먼저 물어보세요. / 늦은 시간이라면 경비실에 먼저 사정을 알려 두시면 됩니다.
관리사무소가 따로 없는 연립이나 소규모 건물은 건물주나 관리인에게 연락하는 것이 좋습니다. / 연락처가 건물 입구에 붙어 있는 경우가 많습니다.

저희가 하는 일은 우리 집 현관문 개문과 도어락 점검, 수리, 교체입니다. / 공동 출입문의 인터폰이나 전기 잠금장치는 건물 관리 영역이라 직접 손대지 않는 경우가 많습니다.
다만 세대 현관 도어락이 같이 말썽이거나, 문이 처져서 열림이 안 되는 상황이라면 현장을 보고 말씀드립니다. / 어디까지 도울 수 있는지는 전화로 상황을 들은 뒤 솔직하게 안내합니다.
[용인 출장열쇠](yongin.html)에 전화를 주시면 우리 집 문 문제인지부터 같이 가려 드립니다.

# 신봉동에서 전화하실 때 알려주실 것
상황을 말씀하실 때 아래 정보를 같이 알려주시면 빠릅니다. / 어느 문이 안 열리는지가 가장 중요합니다.
- 도로명 주소와 몇 동 몇 호인지
- 수지구청역 방향 등 대략 어느 쪽인지
- 인터폰 버튼을 눌렀을 때 소리나 표시가 나는지
- 현관 도어락 번호판이 켜지는지
- 공동 출입문인지, 우리 집 현관문인지
사진을 보내주시면 맞는 장비를 챙겨 가기 쉽습니다.

# 우리 집 현관문을 열어야 하는 경우의 진행
현관 도어락이 안 열려 출장을 요청하셨다면 도착해서 먼저 사시는 분인지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 준비해 두세요. / 인터폰이 안 되어 관리사무소와 연락이 어려운 경우에는 다른 방법을 같이 상의해 드립니다.
덜 상하는 방법부터 차례로 시도하고, 부품을 바꿔야 한다면 손대기 전에 먼저 여쭙니다. / 자세한 방식은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 비용은 문 열기 전에 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤에 말없이 붙는 비용도 없습니다.
진행 방식은 [이용안내](guide.html)에도 적어 두었습니다. / 도어락 문제로 판단되면 [도어락 수리](doorlock-repair.html)가 먼저인지 교체가 먼저인지도 함께 말씀드립니다.
@ 신봉동 현관 도어락 점검 출장

# 인터폰과 도어락 모두 오래 쓰는 습관
- 인터폰 화면이 흐려지거나 소리가 끊기면 미루지 말고 관리사무소에 알리기
- 열림 버튼은 한 번 눌러서 반응을 확인하기
- 현관 도어락 배터리는 정해 둔 날에 한꺼번에 교체
- 인터폰이 안 될 때를 대비해 가족 번호와 카드는 따로 챙기기
- 택배나 손님이 올 때는 미리 전화로 연락하기
인터폰 하나가 안 된다고 집 전체 출입이 막히는 구조는 피하는 것이 좋습니다. / 현관 도어락에 번호나 카드 같은 별도 수단을 갖춰 두면 이런 상황이 훨씬 편해집니다.

# 신봉동 말고 용인 어디든 갑니다
신봉동 가까운 성복동, 동천동, 상현동은 물론 용인 안이면 24시간 출동합니다. / 지역 정보는 [용인시 출장열쇠](yongin.html) 페이지에 정리해 두었습니다.
서울과 경기 다른 지역은 [출장 지역](area.html) 지도에서 확인하실 수 있습니다.
