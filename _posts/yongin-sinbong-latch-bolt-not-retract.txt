# 신봉동 현관문이 끝까지 안 닫힌다면 래치부터
신봉동은 수지구 안쪽 주거 지역이라 수지구청역 방향으로 오가는 분들이 많은 동네입니다. / 아침 출근길에 문이 제대로 안 닫히거나, 닫힌 줄 알았는데 살짝 열려 있는 일이 생기면 불안해집니다.
이런 증상은 대개 문틈에서 튀어나오는 래치, 즉 걸쇠가 제 위치로 들어가지 않기 때문에 생깁니다. / 원인을 알면 의외로 간단히 해결되기도 합니다.
이 글은 래치가 들어가지 않을 때 확인할 순서를 정리했습니다. / 직접 해결이 어렵다면 [용인 출장열쇠](yongin.html)가 어떻게 점검하는지도 함께 적었습니다.
@ 신봉동 현관문 래치 걸쇠 확인

# 래치는 문을 잡아 주는 작은 혀 모양 부품입니다
문 옆면에서 튀어나온 둥글거나 비스듬한 금속 부분이 래치입니다. / 문이 닫힐 때 문틀 구멍에 들어가 문을 붙잡는 역할을 합니다.
손잡이를 돌리면 래치가 안으로 들어가고, 놓으면 스프링이 다시 밀어냅니다. / 이 스프링과 움직임이 매끄럽지 않으면 문이 안 닫히거나 반대로 안 열립니다.
래치와 데드볼트는 다른 부품이니 헷갈리지 마세요. / 이 글에서 말하는 문제는 문이 닫힐 때 걸쇠가 들어가지 않는 쪽입니다.

# 증상별로 원인이 갈립니다
어떤 모양으로 안 닫히는지에 따라 의심할 곳이 달라집니다.
- 닫힐 때 래치가 문틀에 부딪혀 튕겨 나오는 경우
- 래치가 들어간 채로 다시 나오지 않아 문이 헐거운 경우
- 문을 세게 밀어야만 닫히는 경우
- 닫혔지만 손잡이를 돌려야 열리지 않고 그냥 밀면 열리는 경우
첫 번째는 문틀 구멍과 위치가 어긋났을 가능성이 크고, 두 번째는 래치 스프링이나 내부 부품 쪽입니다. / 세 번째는 문틀이나 경첩, 문 처짐을 의심해 볼 만합니다.

# 문틀 구멍과 어긋났는지 확인하는 방법
립스틱이나 색연필을 래치 끝에 얇게 바르고 문을 닫아 보세요. / 문틀 쪽에 묻은 자국이 구멍의 중앙인지 위쪽이나 아래쪽으로 치우쳤는지 볼 수 있습니다.
자국이 구멍 가장자리에 닿아 있다면 문이 처졌거나 문틀이 미세하게 움직인 것입니다. / 오래 쓴 문이나 계절 변화가 큰 집에서 흔합니다.
이 상태에서 억지로 문을 닫으려고 하면 래치와 문틀 모두 닳습니다. / 증상이 반복되면 그냥 두지 말고 위치를 바로잡아야 합니다.

# 경첩 나사가 풀렸는지 같이 보세요
경첩 나사가 헐거워지면 문이 아래로 처져 래치 높이가 틀어집니다. / 문을 열고 위쪽 경첩 나사를 손으로 조이는 방향으로 살짝 돌려 보세요.
나사가 헛돌면 구멍이 닳은 것이니 힘주어 돌리면 더 상합니다. / 이때는 나사 길이와 보강 방법을 현장에서 보고 판단해야 합니다.
문 윗부분과 문틀 사이 틈이 좌우로 다르게 보이면 처짐 신호입니다. / 눈으로만 봐도 대략 짐작이 되니 한 번 살펴보세요.
@ 신봉동 현관문 경첩 처짐 확인

# 래치가 들어간 채 안 나올 때
손잡이를 돌렸다 놓았는데 래치가 그대로 들어가 있다면 내부 스프링이나 이물질이 원인일 수 있습니다. / 먼지와 이물질이 쌓여 움직임이 뻑뻑해진 경우도 있습니다.
이럴 때 래치를 손으로 몇 번 눌러 보고, 매끄럽게 되돌아오는지 확인해 보세요. / 한쪽이 걸리면서 느리게 돌아온다면 부품이 낡았을 가능성이 있습니다.
윤활제를 많이 뿌리면 먼지가 엉겨 오히려 더 뻑뻑해질 수 있습니다. / 쓰신다면 아주 소량만 래치 표면에 바르고 닦아내는 정도로만 하세요.

# 절대 하지 말아야 할 것들
문이 안 닫힌다고 발로 차서 닫거나 힘껏 부딪치지 마세요. / 래치와 문틀 구멍이 찌그러져 문제가 더 커집니다.
- 문틀이나 래치를 드라이버로 억지로 벌리기
- 래치 날을 줄칼로 마음대로 깎기
- 테이프로 래치를 눌러 둔 채 방치하기
- 문이 덜 닫힌 채로 외출하기
테이프로 눌러 둔 채 외출하면 문이 사실상 잠기지 않은 상태가 됩니다. / 안전을 위해서도 끝까지 닫히는 상태가 확인될 때까지 해결하는 것이 먼저입니다.

# 도어락 본체 문제일 수도 있습니다
디지털 도어락 안쪽의 모터나 기구부가 어긋나면 래치가 정상 위치로 오지 않을 수 있습니다. / 번호판은 정상인데 래치가 움직이지 않는다면 이쪽을 의심해 봅니다.
배터리가 약할 때도 모터가 래치를 끝까지 밀어내지 못하는 경우가 있습니다. / 먼저 배터리를 새것으로 바꿔 보는 것이 가장 쉬운 시험입니다.
그래도 증상이 같다면 본체를 열어 기구부를 봐야 합니다. / 이때는 [도어락 수리](doorlock-repair.html)로 먼저 고쳐 쓸 수 있는지 확인합니다.

# 문이 안 닫혀서 밖에 서 있게 됐을 때
쓰레기를 버리러 나갔다가 문이 열린 채 걸쇠가 꼬여 다시 못 들어가는 상황도 있습니다. / 이런 일은 래치가 반쯤만 들어간 상태에서 문이 닫히며 생깁니다.
이때 문을 세게 당기면 상황이 더 나빠지니 손잡이를 돌리며 천천히 밀고 당기는 것부터 해 보세요. / 안 되면 억지로 하지 말고 상황을 전화로 알려 주세요.
@ 신봉동 현관문 덜 닫힘 문 앞 점검

# 출장열쇠에 전화하실 때
증상을 구체적으로 말씀해 주시면 도움이 됩니다.
- 문이 닫힐 때 어디가 걸리는지(위, 중간, 아래)
- 래치가 튕겨 나오는지, 들어간 채 안 나오는지
- 번호판은 정상인지, 소리가 나는지
- 최근에 문을 바꾸거나 수리한 일이 있는지
- 문틈이 한쪽으로 쏠려 보이는지
사진은 문 옆면과 문틀 구멍을 가까이 한 장씩 찍어 보내 주시면 좋습니다.

# 방문하면 먼저 신분을 확인합니다
문을 열거나 손보는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 시작할 수 없으니 미리 준비해 두시면 빠릅니다. / 관리사무소에서 세대 확인을 해 주는 경우가 있어 늦은 시간에는 경비실에 먼저 말씀해 두세요.
비용은 문 열기 전에, 작업 시작 전에 먼저 말씀드립니다. / 문을 못 열면 비용은 받지 않으며, 진행 방식은 [이용안내](guide.html)에서도 보실 수 있습니다.

# 현장에서는 이런 순서로 점검합니다
먼저 문을 닫아 보며 래치가 어디에서 걸리는지 확인합니다. / 이어서 문틀 구멍 위치, 경첩, 도어락 내부 움직임을 차례로 봅니다.
위치만 맞추면 되는 경우는 큰 작업 없이 마무리되기도 합니다. / 부품이 낡았다면 교체 전에 이유와 선택지를 설명드립니다.
교체가 필요하다고 판단되는 경우의 기준은 [도어락 교체](doorlock-replace.html) 글에 정리해 두었습니다. / 문을 어떻게 여는지는 [현관문 개문](door-open.html) 페이지에서 보실 수 있습니다.

# 재발을 줄이는 평소 습관
문을 닫을 때 세게 밀치지 말고 손으로 끝까지 닫아 주세요. / 아이가 있는 집은 문을 쾅 닫는 습관이 걸쇠와 경첩 수명을 줄입니다.
계절이 바뀌는 시기에 문이 뻑뻑해지면 그냥 넘기지 말고 점검해 보세요. / 래치 주변을 마른 천으로 닦아 주는 정도의 관리만 해도 도움이 됩니다.

? 문틀이 문제면 문틀까지 고치나요? | 현장에서 상태를 보고 가능한 범위를 설명드립니다.
? 문을 못 열면 돈을 내야 하나요? | 아닙니다. 못 열면 비용은 받지 않습니다.
