# 안에서 잠그는 손잡이가 말썽일 때
집 안에서 문을 잠글 때 돌리는 작은 손잡이가 있습니다. / 이 손잡이가 뻑뻑하게 돌아가거나 아무 저항 없이 헛돌면 문을 잠글 수도, 열 수도 없는 곤란한 상황이 됩니다.
신갈동은 기흥역과 신갈오거리를 오가는 분이 많은 동네라 아침저녁으로 문을 급하게 여닫는 일이 잦습니다. / 그만큼 안쪽 잠금 손잡이도 쉽게 지칩니다.
이 글은 안쪽 잠금 손잡이가 안 돌아가거나 헛돌 때의 원인과 직접 해볼 수 있는 점검을 순서대로 정리했습니다. / 안 풀릴 때 [용인 출장열쇠](yongin.html)를 부르는 방법도 함께 적었습니다.
@ 신갈동 현관 안쪽 잠금 손잡이 점검

# 안쪽 손잡이가 하는 일
안쪽 잠금 손잡이는 문 안에 있는 데드볼트, 즉 문틀로 튀어나오는 굵은 빗장을 움직이는 장치입니다. / 손잡이를 돌리면 연결된 축이 빗장을 밀거나 당깁니다.
이 축이 휘거나 부러지거나 연결이 풀리면 손잡이만 헛돌고 빗장은 그대로입니다. / 반대로 빗장이 문틀에 꽉 눌려 있으면 손잡이가 안 돌아갑니다.
그래서 증상만 같아도 원인이 전혀 다를 수 있어 상태를 구분해서 보는 것이 필요합니다.

# 안 돌아가는 경우와 헛도는 경우는 다릅니다
- 단단하게 막혀 안 돌아가면 빗장이 문틀에 눌렸거나 안쪽 부품에 이물질이 낀 경우
- 돌아가는데 가볍기만 하고 빗장이 안 움직이면 축이 풀렸거나 부러진 경우
- 중간까지 돌다 걸리면 문이 처져서 빗장 위치가 어긋난 경우
- 돌릴 때마다 딸깍 소리가 나면 내부 부품이 마모된 경우
손잡이의 느낌과 소리를 정확히 기억해 두세요. / 전화로 설명할 때 가장 도움이 되는 정보입니다.

# 문이 눌려 있을 때는 이렇게
안쪽 손잡이가 안 돌아갈 때 가장 흔한 원인은 문이 문틀에 눌려 빗장이 구멍에 꽉 끼는 경우입니다. / 문이 조금 처졌거나 계절에 따라 부풀었을 때 잘 생깁니다.
문을 바깥쪽으로 살짝 당기듯 잡고 손잡이를 돌려 보세요. / 문을 안쪽으로 밀면서 돌리는 것이 아니라, 문 무게를 덜어 주는 방향으로 힘을 빼는 것이 요령입니다.
힘으로 돌리면 축이 휘거나 손잡이가 부러질 수 있으니 부드럽게 시도하세요. / 한두 번 해보고 안 되면 멈추는 것이 좋습니다.
@ 신갈동 현관 데드볼트 손잡이 돌려 보기

# 헛돌 때 먼저 확인할 것
손잡이가 헛돈다면 손잡이를 고정한 나사가 풀렸는지 먼저 보세요. / 손잡이 몸통이 흔들리면 나사 문제일 수도 있습니다.
- 손잡이 아래쪽에 나사나 덮개가 보이는지
- 흔들림이 손잡이 자체인지 문 전체인지
- 빗장이 문틀에서 나와 있는지 들어가 있는지
- 열쇠로 바깥에서 돌렸을 때 빗장이 움직이는지
바깥에서 열쇠로 돌렸을 때 빗장이 움직이면 문제는 안쪽 손잡이 연결 쪽에 있을 가능성이 큽니다. / 이런 정보를 알려 주시면 원인을 좁히기 쉽습니다.

안쪽 손잡이가 문제인지 구분하는 간단한 방법이 있습니다. / 문을 연 상태에서 손잡이를 돌려 빗장이 나왔다 들어가는지 눈으로 보는 것입니다.
빗장이 잘 움직인다면 손잡이는 괜찮고 문이 닫힐 때 위치가 어긋나는 것이 원인입니다. / 빗장이 안 움직인다면 손잡이 연결 쪽을 점검받아야 합니다.

# 안에 갇힌 것 같을 때
안쪽 손잡이가 안 돌아가서 문이 열리지 않으면 안에 갇힌 듯한 불안이 듭니다. / 하지만 대부분은 빗장이 눌려 있는 것뿐이니 우선 침착하게 숨을 고르세요.
- 번호나 카드로 바깥처럼 열리는 도어락이라면 안쪽 열림 단추를 먼저 눌러 보기
- 문을 살짝 흔들어 빗장 위치를 맞추며 손잡이 돌려 보기
- 가족이 밖에 있다면 바깥에서 열쇠로 열어 보도록 부탁하기
- 아이가 안에 혼자 있다면 아이를 안심시키며 바로 연락하기
어떤 경우에도 몸으로 문을 밀거나 도구로 비집지 마세요.

# 하지 말아야 할 행동
손잡이가 안 돌아간다고 윤활유를 마구 뿌리면 오히려 먼지가 엉겨 붙어 더 뻑뻑해질 수 있습니다. / 특히 도어락 안쪽으로 기름이 스며들면 전자 부품이 상할 수 있습니다.
드라이버로 손잡이 틈을 벌리거나 망치로 두드리면 문이 상합니다. / 문틈을 카드로 벌리는 것도 도어락 외관과 문틀을 망가뜨립니다.
급해도 스스로 도어락을 분해하는 것은 권하지 않습니다. / 되돌리기 어려운 고장으로 이어지는 경우가 많습니다.

축이 부러진 경우에는 손잡이를 돌릴 때 아무 저항이 없고 빗장도 꿈쩍하지 않습니다. / 이럴 때는 안쪽 부품 교체가 필요한 경우가 많아 직접 해결하기 어렵습니다.
나사가 풀린 경우에는 손잡이가 덜렁거리지만 조이면 바로 좋아지기도 합니다. / 어느 쪽인지 구분이 안 되면 억지로 돌리지 말고 먼저 연락 주세요.

# 신갈동에서 전화 주실 때
- 동과 호수, 기흥역 쪽인지 신갈오거리 쪽인지
- 손잡이가 안 돌아가는지 헛도는지
- 바깥에서 열쇠나 번호로 열리는지
- 집 안에 사람이 갇혀 있는지, 아이나 반려동물이 있는지
- 도어락 모양과 사진
사진이나 짧은 영상을 보내 주시면 필요한 장비를 챙겨 가기 좋습니다.

# 사시는 분인지 확인합니다
문을 열기 전에 사시는 분이 맞는지 확인합니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
신분증이 집 안에 있다면 관리사무소에 세대 확인을 부탁하는 방법도 있습니다. / 번거로워도 이웃과 가족 모두를 위한 절차입니다.

# 비용은 열기 전에 먼저 말씀드립니다
도어락과 문 상태를 본 뒤 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 들지 않으면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 열고 난 뒤 말없이 붙는 비용도 없습니다.
자세한 진행은 [이용안내](guide.html)에, 문 여는 방법은 [현관문 개문](door-open.html)에 적어 두었습니다.

# 열린 뒤에는 연결 부위를 손봅니다
문이 열리면 안쪽 손잡이와 빗장이 정확히 연결되는지 확인합니다. / 나사가 풀린 것이라면 조여서 해결되는 경우가 많습니다.
축이 휘었거나 부러졌다면 해당 부품만 교체할 수 있는지 먼저 살펴봅니다. / 고쳐서 쓸 수 있으면 교체는 권하지 않고 [도어락 수리](doorlock-repair.html)로 진행합니다.
너무 오래되어 부품 구하기가 어려울 때만 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 신갈동 안쪽 잠금 손잡이 수리 후 확인

# 손잡이를 오래 쓰는 습관
- 잠글 때 손잡이를 끝까지 부드럽게 돌리기
- 문이 덜 닫힌 상태에서 억지로 잠그지 않기
- 손잡이를 잡고 문을 쾅 닫는 습관 줄이기
- 흔들림이 느껴지면 나사부터 점검하기
- 이상한 소리가 나면 미루지 말고 손보기
작은 습관 몇 가지가 안쪽 손잡이 수명을 크게 늘려 줍니다.

# 신갈동 밖에서도 용인 어디든
신갈동 가까운 구갈동, 보정동, 영덕동, 마북동도 다닙니다. / 용인 안이면 어느 동네든 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html)에서 볼 수 있고, 다른 지역은 [출장 지역](area.html)에서 확인하실 수 있습니다.
