# 신갈동으로 이사 왔다면 도어락부터
신갈동은 신갈역을 중심으로 이사가 활발한 동네입니다. / 새집에 짐을 옮기기 전에 가장 먼저 챙기면 좋은 일이 도어락 번호를 새로 정하는 것입니다.
이 글은 이사 후에 이전 사용자 번호를 지우고 새 번호를 설정하는 방법을 정리했습니다. / 초기화가 안 되거나 교체가 필요한 경우도 같이 적었습니다.
@ 신갈동 이사 도어락 비밀번호 재설정 출장열쇠

# 이사 직후 비밀번호를 바꿔야 하는 이유
이전에 살던 사람이나 인테리어 업체, 이전 세입자가 등록한 번호가 남아 있을 수 있습니다. / 도어락은 번호를 여러 개 저장해 두기 때문에 새 사람이 입주해도 이전 번호가 그대로 열릴 수 있습니다.
의심해서가 아니라 기본적인 정리 차원에서 번호를 새로 하는 게 좋습니다. / 이사 당일 짐이 오가는 동안에는 번호를 임시로 공유하는 일도 많아서 마무리 후에 꼭 바꿔 주세요. / 카드키나 지문도 같이 확인해 주세요.

# 먼저 도어락 종류를 확인하세요
번호 바꾸는 방법은 제품마다 다릅니다. / 안쪽 몸체에 등록 버튼이 있는 제품이 있고, 번호판에서 바로 설정하는 제품도 있습니다.
- 안쪽 덮개를 열면 등록 버튼이 있는 제품
- 번호판에서 마스터 번호를 입력하는 제품
- 스마트폰 앱으로 설정하는 제품
어느 쪽인지 모르겠다면 제품 이름이나 사진을 확인해 보세요.
@ 신갈동 도어락 초기화 열쇠집

# 초기화하면 모든 번호가 지워집니다
초기화는 저장된 번호와 카드를 모두 지우고 공장 상태로 돌리는 작업입니다. / 이후에는 처음 사용할 때처럼 새 번호를 등록해야 합니다.
제품에 따라 초기화 버튼을 몇 초간 눌러야 하는 등 방법이 다릅니다. / 설명서가 없으면 모델명을 확인해서 찾아보는 게 안전합니다.
초기화 직후에는 기본 번호가 설정되어 있는 제품도 있으니 바로 바꿔 두세요.

# 초기화가 안 될 때 확인할 것
- 배터리가 거의 다 닳지 않았는지
- 안쪽 덮개를 제대로 열었는지
- 등록 버튼 위치가 맞는지
- 마스터 번호나 관리자 모드가 따로 있는지
배터리가 약하면 초기화 도중에 멈춰 오류가 납니다. / 건전지를 전부 새것으로 바꾼 뒤 다시 해보세요.
그래도 안 되면 억지로 누르지 마시고 전화 주세요.

# 이전 사용자가 남긴 카드키가 있다면
도어락 카드는 번호와 별개로 따로 저장되어 있기도 합니다. / 이사 오면서 받은 카드가 몇 장인지 확인하고, 안 쓰는 카드는 삭제해 주세요.
카드를 삭제하는 방법도 제품마다 다릅니다. / 어떤 제품은 카드를 한 장씩 지울 수 있고, 어떤 제품은 전체 삭제만 가능합니다. / 설명서에 없다면 초기화 한 번으로 정리하는 편이 간단합니다.
@ 신갈동 도어락 번호 설정 출장

# 인테리어 업체가 쓰던 번호를 지우세요
이사 전 공사를 했다면 업체가 임시 번호를 등록해 놓고 간 경우가 많습니다. / 공사가 끝난 뒤에도 그 번호가 남아 있는 집이 종종 있습니다.
공사 중에 열쇠를 여러 개 복사해서 돌려받지 못한 집도 있습니다. / 이런 경우는 도어락 번호 정리와 함께 열쇠 교체 여부를 같이 생각해 보세요.

# 번호는 이렇게 정하세요
생일이나 전화번호 뒷자리는 피하세요. / 쉽게 짐작할 수 있는 번호는 안전하지 않습니다.
- 숫자가 순서대로이거나 같은 숫자가 반복되는 번호
- 집 호수와 같은 번호
- 가족 생일을 그대로 쓴 번호
이런 번호는 피하고, 가족끼리만 아는 6~8자리를 정하는 게 좋습니다. / 번호가 길수록 안전합니다.

# 새 번호를 가족과 공유하는 법
번호를 정했으면 가족에게 문자 대신 직접 말로 알려주는 게 안전합니다. / 메신저에 그대로 남기면 나중에 휴대폰 분실 때 노출될 수 있습니다.
아이가 있으면 번호를 외우기 쉬운 규칙으로 정해 주세요. / 잊어버렸을 때를 대비해 카드키 하나를 별도로 보관해 두면 안심됩니다.

# 직접 해보다 안 되면 전화 주세요
초기화를 하다가 번호판이 먹통이 되거나, 등록은 됐는데 문이 안 열리는 경우가 있습니다. / 이럴 때 계속 눌러 보면 입력이 잠깁니다.
서너 번 해보고 안 되면 멈추세요. / 번호를 여러 번 틀리면 도어락이 한동안 입력을 막아서 더 답답해질 수 있습니다. / 24시출장열쇠가 출동해서 상태를 보고 안 상하게 정리해 드립니다.

# 전화 주실 때 알려주시면 좋은 것
- 신갈동 어느 쪽인지, 신갈역에서 어느 방향인지
- 도어락 모양과 제조사 (보이면)
- 번호를 눌렀을 때 소리와 불빛
- 이사 온 날짜 (이전 사용자 정보가 남아 있는지 판단에 도움)
사진을 보내주시면 맞는 방법을 먼저 알려드릴 수 있습니다.

# 도착하면 어떻게 진행하나요
먼저 사시는 분이 맞는지 확인합니다. / 이사 오신 직후라면 계약서나 우편물로도 가능합니다.
도어락 상태를 보고 초기화로 될지, 부품을 바꿔야 할지 말씀드립니다. / 비용은 시작 전에 먼저 말씀드립니다.
문을 못 열면 비용은 받지 않습니다. / 순서는 [이용안내](guide.html)에도 정리해 두었습니다.

# 교체가 더 나은 경우
초기화가 안 되거나 버튼이 아예 먹히지 않으면 부품이 고장 난 겁니다. / 이사 전부터 말썽이던 도어락이라면 이번에 바꿔 두는 것도 방법입니다.
고쳐서 쓸 수 있으면 교체는 권하지 않습니다. / 먼저 [도어락 수리](doorlock-repair.html)로 해결되는지 보고, 안 되면 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
새로 달 때는 [도어락 설치](doorlock-install.html) 방식으로 진행합니다.
이사 오신 집의 현관문이 오래돼 문 자체가 헐렁하다면 같이 점검해 드립니다. / 문이 제대로 닫혀야 새 도어락도 오래 갑니다.

# 신갈동 말고 용인 어디든
신갈동 바로 옆 기흥역 쪽 구갈동, 보라동, 영덕동, 마북동도 다닙니다. / 용인 안이면 동네 상관없이 24시간 출동합니다.
용인 지역은 [용인시 출장열쇠](yongin.html)에 정리해 두었고, 다른 지역은 [출장 지역](area.html) 지도에서 보실 수 있습니다. / 문이 안 열릴 때는 [현관문 개문](door-open.html)을 먼저 보세요.
