# 신갈동 한겨울 밤, 문 앞에서 기다려야 한다면
신갈동은 기흥역 생활권으로 늦은 시간까지 오가는 사람이 많은 동네입니다. / 야근하고 돌아온 밤에 현관문이 안 열리면 추운 바람 속에서 한참을 서 있게 됩니다.
이럴 때 문을 열려는 마음만큼 중요한 것이 내 몸을 지키는 일입니다. / 추위 속에서 오래 기다리면 손이 곱아 번호를 제대로 누르기도 어려워집니다.
이 글은 신갈동에서 한겨울 밤 문 앞에서 기다릴 때 안전하게 버티는 요령을 정리한 것입니다. / 문을 여는 순서와 [용인 출장열쇠](yongin.html)를 부르는 방법도 같이 적었습니다.
@ 신갈동 한겨울 밤 현관문 앞

# 먼저 몸부터 챙기세요
문이 안 열린다는 걸 알았다면 일단 바람을 피할 곳을 찾으세요. / 계단참이나 건물 출입구 안쪽만 가도 체감 온도가 많이 달라집니다.
- 장갑이나 목도리가 있으면 바로 두르기
- 가방이나 박스를 바닥에 깔고 앉기
- 손은 주머니에 넣어 따뜻하게 유지
- 휴대폰 배터리가 줄지 않게 화면 밝기 낮추기
몸이 풀려야 침착하게 판단할 수 있습니다. / 서두르다 계단에서 미끄러지는 일이 없게 천천히 움직이세요.

# 휴대폰 배터리가 추위에 먼저 줄어듭니다
겨울 밤에는 휴대폰 배터리가 평소보다 빨리 닳습니다. / 문 앞에서 오래 검색하다가 꺼지면 연락할 수단이 사라집니다.
전화나 문자를 보내야 할 사람에게 먼저 연락하고 불필요한 화면은 끄세요. / 안주머니에 넣어 두면 배터리가 덜 닳습니다.
번호가 필요하면 가족에게 전화로 확인하고 짧게 끝내는 것이 좋습니다.

# 번호판이 안 켜지는 건 추위 탓일 수 있습니다
한파에는 도어락 배터리가 힘을 제대로 못 내서 번호판이 안 켜지는 일이 있습니다. / 낮에는 멀쩡하다가 밤에 갑자기 반응이 없는 경우가 이런 때입니다.
번호판을 손으로 덮고 잠시 체온으로 데운 뒤 다시 눌러 보세요. / 그래도 안 되면 바깥 아래의 비상 단자에 9V 건전지를 대고 번호를 눌러 봅니다.
건전지가 없다면 근처 편의점에서 구하는 방법이 있지만 몸이 얼었다면 먼저 따뜻한 곳으로 가세요.

# 억지로 열려다 다치는 경우
추워서 마음이 급하면 손잡이를 세게 당기거나 문을 어깨로 밀게 됩니다. / 어깨와 손목을 다칠 수 있고 걸쇠가 더 꽉 물리기도 합니다.
얼어붙은 문틈에 드라이버나 카드를 넣으면 손이 미끄러져 다칩니다. / 도어락 외관도 상해 나중에 고치는 일이 더 커집니다.
뜨거운 물을 문 손잡이나 도어락에 붓는 방법도 피하세요. / 급격한 온도 변화로 내부 부품이 상하거나 얼어서 더 막힐 수 있습니다.
@ 신갈동 한파 도어락 번호판 반응

# 문이 얼어붙은 경우와 고장은 다릅니다
겨울에 문틈이 얼어붙어 문이 안 떨어지는 일도 있습니다. / 손잡이는 돌아가는데 문이 밀리지 않는다면 문틀 고무가 붙은 것일 수 있습니다.
문을 안쪽으로 살짝 밀었다 당기면서 문틈 고무가 떨어지는지 보세요. / 힘을 세게 주지 말고 천천히 흔들어 보는 정도가 안전합니다.
번호판이 반응하고 모터 소리도 나는데 문이 안 움직이면 결로나 얼음 문제를 의심해 볼 수 있습니다.

# 집 안에 사람이 있는지 먼저 확인
가족이 집 안에 있다면 문 앞에서 전화나 인터폰으로 연락해 보세요. / 안쪽 손잡이를 돌려 열어 줄 수 있다면 가장 빠릅니다.
집에 혼자 사시는 분이라면 이웃이나 경비실에 도움을 청하는 것도 방법입니다. / 관리사무소가 열려 있는 시간이면 세대 확인을 부탁해 보세요.
아이나 어르신, 반려동물이 안에 혼자 있다면 전화 주실 때 가장 먼저 말씀해 주세요. / 순서를 바꿔 서둘러 움직입니다.

# 도착 시간 동안 어디서 기다릴까
출장 요청을 하면 도착 시간을 먼저 안내해 드립니다. / 그 시간 동안 문 앞에 서 있을 필요는 없습니다.
- 건물 로비나 계단 안쪽 등 바람이 덜한 곳
- 24시간 편의점처럼 따뜻하고 불이 켜진 곳
- 가까운 이웃이나 지인 집
도착 시간에 맞춰 문 앞에 나와 계시면 됩니다. / 위치를 정확히 알려주시면 헤매지 않고 찾아갈 수 있습니다.

# 전화하실 때 알려주면 빠른 정보
추운 밤에는 짧고 정확하게 말씀해 주시는 것이 서로에게 좋습니다. / 아래 내용만 말씀해 주세요.
- 신갈동 안에서 어느 쪽인지, 기흥역 방향인지 등
- 몇 동 몇 호인지, 건물 출입구는 열려 있는지
- 번호판 상태 (꺼짐, 켜짐, 경고음)
- 지금 기다릴 곳이 있는지
- 집 안에 사람이 있는지
도어락 사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다.

# 도착하면 먼저 신분부터 확인합니다
늦은 밤이라도 사시는 분이 맞는지 먼저 확인하고 엽니다. / 신분증 주소, 주소가 적힌 우편물, 관리사무소 확인 중 하나면 됩니다.
번거로울 수 있지만 이웃과 집 모두를 위한 절차입니다. / 신분증이 집 안에 있다면 경비실이나 관리사무소 확인을 같이 알아봅니다.
확인이 어려우면 작업을 할 수 없으니 가능하면 미리 챙겨 두면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 도어락 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다. / 문은 [현관문 개문](door-open.html) 방식으로 최대한 상하지 않게 엽니다.

# 열고 난 뒤 겨울을 나는 법
문이 열리면 배터리를 전부 새것으로 바꾸는 것부터 합니다. / 겨울을 앞두고 미리 바꿔 두면 한파에 더 안전합니다.
번호판 습기와 문틈 고무 상태도 같이 확인합니다. / 문이 끝까지 닫히는지 보고 이상이 있으면 [도어락 수리](doorlock-repair.html)로 먼저 손봅니다.
너무 오래된 제품이면 그때 [도어락 교체](doorlock-replace.html)를 말씀드립니다.
@ 신갈동 겨울철 도어락 배터리 교체

겨울이 오기 전에 아래처럼 준비해 두면 좋습니다.
- 배터리를 11월쯤 한 번에 전부 새것으로 교체
- 비상용 9V 건전지 하나를 가방에 넣어 두기
- 비밀번호를 가족 한 명 이상과 공유하고 연락처 확인
- 현관문 문틈 고무와 문틀 점검
- 여분 열쇠나 카드키를 믿을 수 있는 곳에 따로 보관
준비를 해 두면 한겨울 밤에 문 앞에서 떨 일이 많이 줄어듭니다.
특히 비상용 건전지는 차나 직장 가방처럼 집 밖에서 꺼낼 수 있는 곳에 있어야 쓸모가 있습니다. / 집 안 서랍에만 두면 정작 필요할 때 손이 닿지 않습니다.

# 신갈동 말고도 용인 어디든 갑니다
신갈동 바로 옆 구갈동, 보정동, 마북동, 영덕동도 다닙니다. / 용인 안이라면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
