# 영하의 아침, 번호판이 대답이 없습니다
역북동 주민들은 출근길에 용인 시내 쪽으로 이동하는 분이 많습니다. / 한파가 몰아친 새벽에 문을 나서려는데 도어락이 느리게 반응하거나 아예 꺼져 있어 당황하는 일이 겨울마다 반복됩니다.
추운 날에는 도어락이 정말 고장 난 것이 아니라 배터리가 추위를 못 견디는 경우가 많습니다. / 원인을 알면 대처도 한결 쉬워집니다.
이 글은 역북동에서 추위 때문에 도어락 상태가 이상할 때 확인할 것과 [용인 출장열쇠](yongin.html)를 부르는 기준을 적었습니다.
@ 역북동 한파 도어락 배터리 점검

# 추우면 배터리가 힘을 못 냅니다
건전지는 온도가 내려가면 내부 반응이 느려져서 평소보다 전기를 적게 내보냅니다. / 같은 건전지라도 따뜻한 낮에는 멀쩡하다가 새벽에 약해지는 이유입니다.
현관문 바깥쪽은 집 안보다 훨씬 차가워서 번호판이 있는 쪽이 특히 영향을 받습니다. / 문 안쪽 본체는 따뜻한데 바깥 번호판만 차가운 구조입니다.
- 번호판 불빛이 평소보다 어둡거나 깜빡이는 경우
- 번호를 누른 뒤 반응이 한참 늦게 오는 경우
- 열리는 소리가 힘없이 끊기는 경우
- 낮에는 되다가 아침에만 안 되는 경우

# 가장 먼저 손으로 번호판을 데워 보세요
번호판이 이상하다 싶으면 손바닥으로 번호판을 잠시 감싸 따뜻하게 해 보세요. / 체온만으로도 건전지 반응이 살아나서 열리는 경우가 있습니다.
차가운 금속 손잡이를 맨손으로 오래 잡고 있으면 손이 얼어 버튼을 누르기 어려워집니다. / 장갑을 낀 손 대신 손가락 끝으로 천천히 누르는 편이 정확합니다.
너무 급하게 연속으로 누르면 입력이 꼬여 잠시 막히기도 합니다. / 한 번 쉬었다가 다시 눌러 보세요.

# 건전지를 빼서 데웠다가 끼우는 방법
문이 열려 있는 상태라면 배터리를 빼서 주머니에 넣어 체온으로 데운 뒤 끼워 보세요. / 이 방법만으로도 한파 속 반응이 달라지는 경우가 있습니다.
다만 문이 잠긴 채 밖에서 시도하기는 어렵습니다. / 그럴 때는 바깥에 비상 단자가 있는지 먼저 확인합니다.
뜨거운 물에 담그거나 불에 대어 데우는 방법은 위험하니 절대 하지 마세요. / 건전지가 터지거나 샐 수 있습니다.
@ 용인 역북동 도어락 비상 전원 9V

# 9V 건전지로 비상 전원 넣기
많은 도어락 바깥 아래쪽에는 9V 건전지를 대는 비상 단자가 있습니다. / 건전지를 단자에 붙인 채로 번호를 누르면 열리는 방식입니다.
한파에는 비상용 건전지도 차가워서 반응이 약할 수 있습니다. / 손에 쥐고 있다가 사용하면 한결 낫습니다.
역북동 근처 편의점에서 9V 건전지를 구하기도 하지만 늦은 밤에는 닫는 곳도 있습니다. / 평소에 하나쯤 챙겨 두면 마음이 놓입니다.

# 추운 날 하면 안 되는 행동
- 번호판에 뜨거운 물을 부어 녹이는 것
- 드라이버로 도어락 틈을 벌려 보는 것
- 번호를 계속 틀려 입력을 막히게 하는 것
- 문을 발로 차거나 몸으로 치는 것
급하더라도 이런 행동은 도어락과 문을 상하게 합니다. / 온도 차가 큰 곳에 뜨거운 물이 닿으면 내부 부품이 깨지기도 합니다.

# 안쪽에서 열리는 문이 안 열릴 때
안에서 문을 열고 나가려는데 손잡이가 돌아가지 않는 경우도 있습니다. / 추위로 윤활유가 굳어 걸쇠 움직임이 둔해진 것일 수 있습니다.
손잡이를 서서히 돌리면서 문을 살짝 밀어 주면 움직이는 일이 많습니다. / 급하게 힘을 주면 부품이 상할 수 있습니다.
문틀 고무 패킹이 얼어붙었다면 미지근한 바람으로 녹이는 것이 안전합니다.

# 전화 주실 때 알려주실 것
역북동은 위치 설명이 길어질 수 있으니 동 이름과 호수 위주로 알려 주세요. / 가까운 큰길이나 생활권 방향을 함께 말씀해 주시면 더 빠릅니다.
- 번호판이 꺼졌는지, 느린지, 경고음이 나는지
- 문 밖에 계신지 안쪽에 계신지
- 건전지를 마지막으로 교체한 시기
- 안에 아이나 어르신이 있는지
- 지금 기온과 오래 기다릴 수 있는 상황인지
추운 날 문 밖에서 오래 기다리는 건 힘든 일입니다. / 이런 상황은 말씀해 주시면 우선 고려해 안내드립니다.

한파가 이어지는 주에는 아침마다 같은 일이 반복될 수 있습니다. / 한 번 약해진 건전지는 따뜻해진 낮에 잠깐 회복했다가 다시 떨어지므로 안심하고 넘어가지 마세요.
외출 전에 집 안에서 번호판 불빛이 선명한지, 열리는 소리가 또렷한지 한 번 확인하는 습관이 도움이 됩니다. / 이상하면 그날 바로 교체하고 나가는 편이 문 앞에서 떠는 것보다 낫습니다.
집을 오래 비우는 겨울 여행 전에도 건전지를 새것으로 바꿔 두면 돌아와서 낭패를 보지 않습니다.

# 문 열기 전 신분 확인
문을 여는 일이라 사시는 분이 맞는지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
추운 밤에 번거롭다고 느끼실 수 있지만 서로를 지키는 절차입니다. / 신분증이 집 안에 있다면 관리사무소에 부탁해 보세요.

# 비용은 열기 전에 먼저 말씀드립니다
도어락 상태를 보고 어떻게 진행할지 열기 전에 알려 드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 돌아갑니다.
문을 못 열면 비용은 받지 않으며, 열고 난 뒤 갑자기 붙는 비용도 없습니다. / 부품을 바꿀 때는 따로 여쭤봅니다. 진행 방식은 [이용안내](guide.html)에서 보실 수 있습니다.
최대한 상하지 않게 여는 방법은 [현관문 개문](door-open.html) 페이지에 적어 두었습니다.

# 열고 난 뒤에는 건전지부터 새것으로
문이 열렸다면 배터리 상태부터 점검합니다. / 한파를 겪은 건전지는 한쪽만 약한 경우가 많아 전부 같이 교체하는 편이 좋습니다.
건전지 종류가 다르거나 오래된 것과 새것이 섞여 있으면 금방 다시 약해집니다. / 같은 제품의 새 건전지로 맞춰 주세요.
교체한 날짜를 배터리 칸이나 달력에 적어 두면 다음 시기를 놓치지 않습니다.
@ 역북동 출장열쇠 배터리 교체 점검

전기가 아니라 열쇠 구멍으로 여는 방식이 있는 도어락이라면 겉에 달린 덮개를 열면 열쇠 구멍이 나옵니다. / 열쇠를 어디에 보관했는지 미리 알아 두면 한파 날에 큰 힘이 됩니다.

# 겨울 나기 전 점검 목록
- 가을이 끝나기 전에 배터리를 한꺼번에 교체
- 비상용 9V 건전지를 차나 가방에 보관
- 번호판 위의 서리나 얼음은 마른 천으로 닦기
- 경고음이 울리면 그날 바로 교체
- 열릴 때 소리가 힘없으면 미루지 말고 점검받기
도어락이 오래돼서 겨울마다 문제가 생긴다면 [도어락 수리](doorlock-repair.html)를 먼저 받아 보시고, 너무 낡았다면 [도어락 교체](doorlock-replace.html)를 상의합니다.

# 역북동 말고 용인 어디든
역북동 인근 김량장동, 모현읍은 물론 용인 전 지역을 24시간 다닙니다. / 다른 지역은 [출장 지역](area.html)에서 확인해 보세요.
