# 도어락 소리는 말을 합니다
역북동은 용인시청과 용인중앙시장 쪽 생활권에 가까워 원룸과 아파트, 상가가 섞여 있는 동네입니다. / 퇴근길에 문 앞에서 도어락이 삑삑 하고 평소와 다른 소리를 내면 무슨 뜻인지 몰라 불안해집니다.
도어락은 상태가 달라지면 소리나 불빛으로 알려 줍니다. / 이 글은 소리의 길이와 횟수에 따라 짐작할 수 있는 원인을 정리했습니다.
제품마다 소리가 조금씩 다르므로 정답이 아니라 참고용으로 읽어 주세요.
@ 역북동 도어락 경고음 소리 구분

# 소리를 듣기 전에 알아 둘 것
같은 짧은 소리도 제품에 따라 뜻이 다를 수 있습니다. / 설명서가 있다면 소리 안내 표를 먼저 찾아보세요.
설명서가 없다면 제조사 이름과 모델명을 도어락 안쪽이나 번호판 아래에서 확인할 수 있습니다. / 찍어 두었다가 전화 때 말씀해 주시면 도움이 됩니다.
소리를 들을 때는 번호판의 불빛도 같이 보세요. / 소리와 빛이 한 쌍이라 둘을 같이 보면 구분이 쉽습니다.

# 짧게 한 번 삑 하고 나는 소리
번호를 누를 때마다 짧게 한 번씩 나는 소리는 정상 입력음인 경우가 대부분입니다. / 문이 잠기거나 열릴 때도 짧은 소리가 날 수 있습니다.
다만 입력 소리가 평소보다 작거나 느려졌다면 배터리가 약해지는 신호일 수 있습니다. / 이런 변화는 며칠 전부터 서서히 나타나는 경우가 많습니다.

# 짧게 여러 번 이어지는 소리
삑삑삑 하고 짧은 소리가 이어지면 대개 배터리 부족이나 문이 덜 닫힘 같은 알림입니다. / 문이 끝까지 닫혔는지 먼저 밀어서 확인해 보세요.
배터리 부족이라면 문이 열릴 때마다 경고음이 함께 울리는 경우가 많습니다. / 이때는 그날 바로 새 배터리로 교체하는 것이 좋습니다.
번호판 불빛이 약하게 깜빡이면 방전이 가까워졌다는 뜻일 수 있습니다.
건전지 교체 후에도 같은 소리가 난다면 새 건전지가 다 쓴 제품이거나 규격이 안 맞는 것일 수 있습니다. / 건전지는 모두 같은 제품으로 한꺼번에 바꾸는 것이 좋습니다.
@ 용인 역북동 도어락 배터리 부족 경고

# 길게 한 번 삐- 하고 나는 소리
길게 울리는 소리는 입력 실패나 잠금 모드 알림인 경우가 많습니다. / 비밀번호를 틀렸거나 등록되지 않은 카드를 댔을 때 이렇게 울리는 제품이 있습니다.
같은 실패가 여러 번 쌓이면 도어락이 잠시 입력을 막는 경우도 있습니다. / 그럴 때는 서두르지 말고 한동안 기다렸다가 천천히 다시 입력해 보세요.
번호가 맞는데도 길게 울린다면 번호판 접촉이 불량한 것일 수 있습니다.

# 길게 계속 울리는 소리
경고음이 멈추지 않고 이어진다면 침입 감지, 강제 개방 시도, 내부 센서 오류 알림일 가능성이 있습니다. / 이 경우는 억지로 문을 열려고 하지 말고 상태를 확인하는 것이 먼저입니다.
문이 반쯤 열린 채 오래 두었거나 손잡이가 눌린 상태로 있으면 울리는 제품도 있습니다. / 손잡이와 문틈에 물건이 끼어 있지 않은지 살펴보세요.
소리가 멈추지 않으면 배터리를 잠시 분리해 보라는 설명서도 있지만 제품에 따라 다릅니다. / 확실하지 않으면 손대지 말고 연락 주세요.

# 소리가 나는데 문이 안 열릴 때
번호가 맞아서 소리는 났는데 문이 안 열린다면 모터나 걸쇠 쪽 문제일 수 있습니다. / 안쪽 보조키가 돌아가 있는지, 문틀이 처져 걸쇠가 눌렸는지 확인해 보세요.
- 문을 살짝 안쪽으로 밀며 손잡이 돌리기
- 보조키가 잠겼는지 문 안쪽 상태 짐작해 보기
- 비상 단자에 9V 건전지를 대고 다시 입력
- 두세 번 해보고 안 되면 멈추기
세게 당기거나 열쇠 구멍을 억지로 돌리는 것은 피해 주세요. / 도어락 모터 부품이 상하면 수리 범위가 커집니다.

# 소리가 전혀 나지 않을 때
번호판을 눌러도 소리가 없고 불도 안 들어온다면 전원이 끊긴 것입니다. / 배터리 방전이거나 내부 접점 문제일 수 있습니다.
이때는 비상 전원을 먼저 시도하는 것이 기본입니다. / 건전지를 대고도 반응이 없으면 연락 주세요.
비가 오거나 습한 날에는 번호판 안쪽으로 습기가 들어가 소리가 안 나는 경우도 있습니다.
원룸처럼 환기가 어려운 공간의 현관은 결로가 생기기 쉬워 겨울에도 같은 일이 생깁니다. / 마른 천으로 닦고 시간이 지난 뒤 다시 눌러 보세요.

# 전화할 때 소리를 이렇게 알려 주세요
소리 길이와 횟수를 말로 옮기기 어렵다면 휴대폰으로 녹음해 보내 주세요. / 짧게 세 번, 길게 한 번처럼 느낌대로 말씀하셔도 됩니다.
소리와 함께 번호판 불빛이 어땠는지도 알려 주세요. / 빨간색인지 깜빡이는지 같은 정보가 큰 단서가 됩니다.
언제부터 그랬는지, 최근에 배터리를 바꿨는지 알려 주시면 더 빨리 좁힐 수 있습니다.
@ 역북동 열쇠 출장 소리 설명 통화

# 도착하면 신분 확인부터 합니다
도어락을 만지고 문을 여는 일이라 사시는 분인지 먼저 확인합니다. / 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.
확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두시면 좋습니다. / 원룸에 사는 분은 계약서나 우편물 사진도 도움이 됩니다.
비용은 소리의 원인을 확인한 뒤 작업하기 전에 먼저 말씀드리고, 못 열면 비용은 받지 않습니다.

# 고칠지 바꿀지는 원인을 본 뒤에 말씀드립니다
배터리나 접점 문제는 간단히 정리되는 경우가 많습니다. / 진행 방식은 [이용안내](guide.html)에 정리해 두었습니다.
모터나 내부 회로가 낡아 반복해서 소리를 낸다면 [도어락 수리](doorlock-repair.html)로 상태를 보고 교체가 필요한지 말씀드립니다. / 교체가 맞으면 [도어락 교체](doorlock-replace.html)에서 고르는 기준을 설명해 드립니다.
고쳐 쓸 수 있는데 바꾸라고 권하지는 않습니다.

도어락 고장으로 문이 안 열릴 때도 문과 도어락을 상하지 않게 여는 방법을 먼저 찾습니다. / [현관문 개문](door-open.html) 페이지에 대략의 과정을 적어 두었습니다.
작업 중 새로 필요한 부품이 생기면 하기 전에 말씀드립니다.

# 소리 문제를 줄이는 습관
- 배터리는 해마다 한 번 전부 새것으로 교체
- 경고음이 나면 그날 바로 확인
- 번호판은 마른 천으로 가끔 닦기
- 문이 끝까지 닫히는지 평소에 확인
- 설명서의 소리 안내 표는 사진으로 찍어 두기
소리가 바뀌는 순간이 점검하기 가장 좋은 때입니다. / 작은 신호를 놓치지 않는 것만으로도 문 앞에서 막히는 일이 줄어듭니다.
가족 중 소리를 가장 잘 듣는 사람이 있다면 그 사람이 정기적으로 확인하도록 정해 두는 것도 방법입니다. / 어르신은 소리를 놓칠 수 있으니 불빛 변화를 함께 알려 드리면 좋습니다.

# 역북동 옆 동네도 같이 다닙니다
역북동 가까운 김량장동, 남사읍, 포곡읍, 모현읍까지 처인 쪽은 모두 다닙니다. / 수지와 기흥도 같은 방식입니다.
용인 전체 안내는 [용인 출장열쇠](yongin.html) 페이지에, 다른 지역은 [출장 지역](area.html) 안내에 있습니다.
