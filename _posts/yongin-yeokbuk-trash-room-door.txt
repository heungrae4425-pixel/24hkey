# 역북동 분리수거장 문이 안 열릴 때
역북동은 처인구 쪽 생활권으로, 기흥역이나 동백역 방면을 오가며 사는 분들도 많은 동네입니다. / 아파트와 빌라, 원룸 건물마다 분리수거장이나 쓰레기실이 따로 있는 곳이 많습니다.
쓰레기를 들고 나갔는데 분리수거장 문이 잠겨 있거나 열쇠가 말을 안 들으면 난감합니다. / 집 현관문과 달리 이런 문은 누가 관리하는지부터 헷갈립니다.
이 글은 역북동에서 분리수거장이나 쓰레기실 문 열쇠 문제가 생겼을 때 확인할 것을 정리한 것입니다. / 열쇠집을 불러야 할 때 [용인 출장열쇠](yongin.html)를 부르는 방법도 적었습니다.
@ 역북동 분리수거장 쓰레기실 문

# 먼저 이 문의 주인이 누구인지 확인하세요
분리수거장 문은 내 집 문이 아닙니다. / 건물을 관리하는 관리사무소, 집주인, 입주자 대표 등 정해진 관리 주체가 있는 경우가 많습니다.
허락 없이 문을 열거나 자물쇠를 바꾸면 곤란한 일이 생길 수 있습니다. / 먼저 관리하는 쪽이 어디인지 확인하는 것이 순서입니다.
- 관리사무소가 있는 단지라면 사무소에 먼저 문의
- 원룸·빌라라면 집주인이나 관리인에게 문의
- 입주자 대표나 총무가 열쇠를 보관하는지 확인
관리 주체가 확인되어야 문을 여는 일도 진행할 수 있습니다.
혼자서 판단하기 어렵다면 먼저 사진을 찍어 두고 관리하는 쪽에 상황을 알리세요. / 언제부터 안 열렸는지 기록해 두면 책임을 따질 때도 도움이 됩니다.

# 열쇠를 잃어버린 경우
분리수거장 열쇠는 공용이어서 누가 마지막으로 썼는지 모를 때가 많습니다. / 여러 사람이 돌려 쓰다가 잃어버리는 일이 흔합니다.
집에 들고 오지 않았는지, 마지막으로 쓴 사람은 누구인지 먼저 물어보세요. / 이웃이나 관리인이 여분 열쇠를 가지고 있을 수 있습니다.
열쇠가 완전히 없어졌다면 새로 만들거나 자물쇠를 바꾸는 방법을 같이 생각해야 합니다. / 열쇠를 복사하는 일은 [열쇠 출장](key-call.html) 상담에서 가능한지 알려 드립니다.

# 열쇠를 꽂았는데 안 돌아가는 경우
쓰레기실 자물쇠는 비바람과 음식물 냄새에 노출되어 쉽게 뻑뻑해집니다. / 열쇠가 들어가도 돌아가지 않는 일이 자주 생깁니다.
- 열쇠를 끝까지 넣었다가 아주 조금 빼서 돌려 보기
- 힘으로 비틀지 말고 좌우로 살살 맞추기
- 자물쇠를 손바닥으로 감싸 체온으로 데워 보기 (겨울철)
열쇠가 구멍 안에서 부러지면 자물쇠 전체를 바꿔야 할 수 있습니다. / 안 돌아가면 힘으로 밀어붙이지 마세요.
@ 역북동 쓰레기실 자물쇠 열쇠 구멍

# 비밀번호식 자물쇠일 때
요즘은 번호를 눌러 여는 도어락을 분리수거장에 쓰는 곳도 있습니다. / 이 경우 입주자가 번호를 공유해서 쓰는 경우가 많습니다.
번호가 바뀐 줄 모르고 누르면 입력이 막힐 수 있습니다. / 서너 번 눌러 보고 안 되면 멈추고 관리 쪽에 현재 번호를 문의하세요.
배터리가 다 돼 번호판이 안 켜지는 경우도 있습니다. / 공용 문이라면 배터리 교체는 관리 주체가 해야 하는 일인지 확인하세요.

# 자물쇠가 얼어붙거나 녹슬었을 때
겨울에는 자물쇠가 얼고 여름에는 습기로 녹이 슬어 열쇠가 안 들어갑니다. / 분리수거장은 야외나 반야외에 있어 환경 영향을 더 받습니다.
뜨거운 물을 붓는 방법은 피해 주세요. / 급격한 온도 변화로 자물쇠가 더 얼거나 부품이 상할 수 있습니다.
기름을 너무 많이 뿌리는 것도 먼지가 엉겨 오히려 막힐 수 있습니다. / 상태가 안 좋으면 손대지 말고 전문가에게 맡기는 편이 빠릅니다.

# 문이 휘거나 처져서 안 열리는 경우
쓰레기실 문은 자주 열리고 닫혀 경첩이 헐거워지기 쉽습니다. / 문이 처지면 자물쇠 위치가 문틀과 어긋나 열쇠를 돌려도 잘 안 빠집니다.
문을 살짝 들어 올리듯 밀면서 열쇠를 돌려 보세요. / 열리기도 하지만 자주 그렇다면 경첩과 문틀을 손봐야 합니다.
이런 점검은 [도어락 수리](doorlock-repair.html) 상담에서 같이 봅니다.

# 하지 말아야 할 것
급한 마음에 자물쇠를 부수거나 문을 걷어차는 분들이 있습니다. / 공용 시설은 부수면 책임 문제가 생길 수 있습니다.
- 관리 주체 모르게 자물쇠를 자르는 것
- 망치나 드라이버로 두드려 여는 것
- 임의로 새 자물쇠를 달아 버리는 것
- 열쇠를 세게 비틀어 돌리는 것
공용 문은 관리하는 쪽과 함께 정리하는 것이 가장 깔끔합니다.
쓰레기를 들고 있는 채로 문 앞에서 오래 실랑이하면 냄새와 위생 문제도 생깁니다. / 일단 쓰레기는 잠시 집으로 되돌려 놓고 천천히 정리하는 편이 낫습니다.

# 전화하실 때 알려주면 빠른 정보
어디 문인지 상황을 짧게 말씀해 주세요. / 아래 정보가 있으면 준비가 쉬워집니다.
- 역북동 안에서 대략 어느 쪽인지
- 건물 이름 대신 동과 위치, 문의 위치(지하, 외부 등)
- 열쇠식인지 비밀번호식인지
- 지금 관리 주체와 연락이 되는지
- 자물쇠 사진
자물쇠 모양을 사진으로 보내주시면 맞는 장비를 챙겨 가기 좋습니다.

# 문을 열기 전에 관리 확인부터 합니다
공용 문이므로 여는 사람이 관리 권한이 있는지 먼저 확인합니다. / 관리사무소 확인, 집주인이나 관리인 확인, 신분증 중 가능한 것을 준비해 주세요.
번거로울 수 있지만 이웃을 위한 절차입니다. / 확인이 어려우면 작업을 할 수 없으니 미리 챙겨 두면 좋습니다.

# 비용은 문 열기 전에 먼저 말씀드립니다
문 상태와 자물쇠 종류를 보고 비용을 먼저 말씀드립니다. / 괜찮다고 하시면 시작하고, 마음에 안 드시면 그대로 돌아갑니다.
문을 끝내 못 열면 비용은 받지 않습니다. / 부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
진행 방식은 [이용안내](guide.html)에 적어 두었습니다. / 문은 [현관문 개문](door-open.html) 방식으로 최대한 상하지 않게 엽니다.
@ 역북동 공용 시설 자물쇠 교체

# 열쇠를 새로 정할 때 알아 둘 것
열쇠를 잃어버려 자물쇠를 바꾼다면 새 열쇠를 나눌 대상부터 정하세요. / 입주자 모두에게 나눌지, 관리인만 보관할지에 따라 방식이 달라집니다.
번호식으로 바꾸면 열쇠 분실 걱정은 줄지만 번호 관리가 필요합니다. / [도어락 설치](doorlock-install.html)나 [도어락 교체](doorlock-replace.html) 상담 때 문 상태에 맞는 방법을 안내해 드립니다.
교체는 관리하는 쪽의 동의를 받은 뒤에 진행합니다.

# 역북동 말고도 용인 어디든 갑니다
역북동 바로 옆 김량장동 쪽도 다닙니다. / 용인 안이라면 동네 상관없이 24시간 출동합니다.
다니는 동네는 [용인시 출장열쇠](yongin.html) 페이지에, 다른 지역은 [출장 지역](area.html)에서 보실 수 있습니다.
