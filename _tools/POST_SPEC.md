# 블로그 글 작성 규격 (24시출장열쇠)

글은 `_posts/<파일명>.txt` 한 파일이 한 글이다. 형식·말투·구성은 `_posts/gunpo-sanbon-door-not-opening.txt`와 똑같이 맞춘다(먼저 읽을 것).

## 파일 형식
- 헤더: `title / date / place / region / photo / desc`, 다음 줄 `---`, 그 아래 본문.
- `place`: 썸네일 맨 위에 크게 나오는 동네 이름. 5글자 이내(예: `반송동`, `평촌동`, `포곡읍`). `동탄 반송동`이면 place는 `반송동`.
- `region`: 지역 페이지 slug (suwon, yongin, seongnam, gunpo, hwaseong, anyang, pyeongtaek, osan).
- `photo`: 1~20. 같은 도시 안에서 파일마다 다르게.
- `date`: 작성하는 날짜(YYYY-MM-DD).
- `desc`: 검색 결과에 보일 한두 문장(80~110자). 동네 이름 + 핵심 키워드 포함.
- 본문 문법: `# 소제목`, `문장 / 문장`(줄바꿈), `[글자](주소.html)`, `- 목록`, `? 질문 | 답`, `@ 사진 설명`.

## 분량·구성
- 공백 제외 2,600~3,200자. 소제목 12~16개(목차로 쓰임), `@ 사진 설명` 정확히 4개(본문 중간에 고르게), `? 질문 | 답` 5개, 내부 링크 5개 이상, 마무리에 전화 010-3664-5455.
- 내부 링크 주소: 해당 지역 `<region>.html`, `area.html`, `guide.html`, `door-open.html`, `key-call.html`, `doorlock-install.html`, `doorlock-replace.html`, `doorlock-repair.html`.
- 제목: `지역명 + 동 이름 + 핵심 키워드` 포함, 자연스러운 한 문장. 본문 첫 단락에 동 이름과 가까운 역/생활권을 자연스럽게 언급.

## 금지·주의
- 상호는 `24시출장열쇠`. '만능 24시 도어락' 금지. "못 열면 비용 없음" 유지, 신분 확인(신분증·우편물·관리사무소) 안내 유지.
- 가격 숫자(원, 만원 등) 금지. 비용은 "문 열기 전에 먼저 말씀드린다"까지만.
- 근거 없는 통계·후기·수상·"몇 년째/몇 건" 같은 허위 사실 금지. 실제 아파트 단지명·상호 금지(동 이름·역 이름만).
- 글끼리 복붙처럼 보이면 안 된다: 같은 주제라도 동네마다 소제목 순서·문장·사례·사진 설명이 완전히 달라야 한다. 문장 첫머리 반복 패턴, 같은 소제목 문구 반복을 피한다. 같은 도시에 이미 같은 주제·같은 동네 글이 있으면 다른 동네를 고르고 다른 각도로 쓴다(`_posts/`에서 같은 도시 파일을 먼저 확인).
- 빌드·커밋은 하지 않는다(파일 작성만).

## 분량 (중요)
- 지난번 글들이 평균 2,370자로 짧았다. 이번에는 공백 제외 **2,800자 이상**을 반드시 채운다. 쓴 뒤 `python3 -c "import re,sys;print(len(re.sub(r'\s','',open(sys.argv[1],encoding='utf-8').read().split('---',1)[1])))" 파일` 로 직접 세어 보고, 모자라면 문단·사례·확인 절차를 보태 늘린다. 소제목은 12~15개(16개 초과 금지).
