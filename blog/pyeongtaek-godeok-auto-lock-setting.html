1. 고덕동 도어락, 자동 잠김이 왜 이렇게 빠를까

고덕동에서 평택역이나 지제역 쪽으로 오가다 보면 새로 들어선 주거지에 도어락도 최신 형태가 많습니다.
그만큼 기능이 많아 설정이 헷갈린다는 문의도 늘었습니다.

그중에서도 자동 잠김은 편하지만 시간이 맞지 않으면 불편해지는 기능입니다.
짐을 들고 나오다 문이 벌써 잠겨 버렸다든지, 반대로 안 잠겨 있어 불안했다든지 하는 경우입니다.

이 글은 고덕동에서 자동 잠김 설정이 헷갈릴 때 확인할 순서를 정리했습니다.
설정을 바꾸다 문이 안 열리게 된 경우 대처법도 함께 적었습니다.

2. 자동 잠김이란 어떤 기능인가

문을 닫으면 정해 둔 시간이 지난 뒤 저절로 잠기는 기능입니다.
문을 닫았는지 신경 쓰지 않아도 되어 편리합니다.

모델마다 잠기는 시간 선택 폭이 다르고 켜고 끄는 방법도 다릅니다.
어떤 모델은 문이 닫히자마자 바로 잠기고, 어떤 모델은 몇 초를 두고 잠깁니다.

자동 잠김이 켜져 있다는 것은 문을 열어 둔 채 짐을 옮길 때도 주의해야 한다는 뜻입니다.
문이 닫히는 순간 잠기므로 열쇠나 카드를 몸에 지니고 있어야 합니다.

3. 설정이 헷갈리는 흔한 이유

설명서를 안 보고 안쪽 버튼 조합으로 설정을 바꾸는 경우가 많습니다.
이때 누른 순서가 달라 의도하지 않은 설정이 들어가기도 합니다.

  • 가족 중 한 명이 모르고 설정 모드에 들어간 경우
  • 이사 오기 전 쓰던 사람의 설정이 그대로 남은 경우
  • 배터리를 갈면서 설정이 바뀐 경우
  • 안쪽 스위치와 바깥 번호 입력 모드를 혼동한 경우

누가 언제 바꿨는지 모르는 설정이 가장 헷갈립니다.

고덕동처럼 새로 이사 온 가정이 많은 곳에서는 이전 세입자가 만든 설정이 남아 있는 경우도 있습니다.
이사 직후에 한 번 전체 설정을 확인해 두면 뒤에 헷갈릴 일이 크게 줄어듭니다.

가족 구성이 바뀌었다면 번호판 소리 크기나 잠기는 시간도 그에 맞게 다시 정해 보세요.
아이가 문을 자주 여닫는 집과 어르신만 사는 집은 편한 설정이 서로 다릅니다.

4. 자동 잠김이 안 걸린다면 먼저 문부터 확인

설정이 켜져 있어도 문이 완전히 닫히지 않으면 잠기지 않습니다.
문틀 쪽 걸쇠가 문틀 홈에 들어가는지 먼저 봐 주세요.

문이 살짝 덜 닫혀 있으면 도어락이 닫힘을 감지하지 못합니다.
이럴 땐 설정 문제가 아니라 문 닫힘 상태 문제입니다.

문을 세게 닫았을 때만 잠기고 살살 닫으면 안 잠긴다면 경첩이나 문틀을 점검해야 합니다.
이 부분은 도어락 수리 안내에도 정리해 두었습니다.

5. 너무 빨리 잠겨서 불편할 때

짐을 들고 나오거나 택배를 받는 동안 문이 닫혀 버려 곤란했다면 잠기는 시간이 짧은 것입니다.
설정으로 시간을 늘릴 수 있는 모델이라면 안쪽 설정 모드에서 조정합니다.

정확한 방법은 모델마다 다르니 설명서나 안쪽 덮개 안의 안내 스티커를 먼저 확인하세요.
모르는 상태에서 버튼을 여러 개 누르면 다른 설정이 바뀔 수 있습니다.

잠깐 문을 열어 둘 일이 많다면 자동 잠김을 끄는 방법도 있습니다.
다만 끄면 문을 닫았는지 직접 확인하는 습관이 필요합니다.

6. 설정을 바꾸다 문이 안 열릴 때

설정 모드에서 번호를 눌렀는데 비밀번호가 바뀌었는지 모르게 된 경우가 있습니다.
설정 모드에서 나오지 못하고 번호판이 계속 깜빡이는 상태도 있습니다.

이럴 때 같은 버튼을 계속 누르면 상황이 더 꼬입니다.
배터리를 잠깐 분리했다가 다시 끼우면 설정 모드가 풀리는 모델도 있지만 모델마다 다릅니다.

확실하지 않으면 더 건드리지 말고 상태를 사진으로 남겨 두세요.
전화로 설명하는 데 도움이 됩니다.

7. 하지 말아야 할 것

  • 설명서 없이 안쪽 버튼을 여러 개 동시에 오래 누르기
  • 설정을 되돌리려고 배터리를 며칠 빼 두기
  • 번호판을 열어 내부 스위치를 직접 만지기
  • 다른 모델 설명서를 보고 따라 하기

같은 제조사라도 모델이 다르면 버튼 조합이 다릅니다.
잘못된 조합이 등록 번호를 지우는 경우도 있습니다.

8. 문이 잠겨 밖에서 못 들어갈 때

자동 잠김 때문에 열쇠나 카드를 두고 나왔다가 잠긴 경우도 있습니다.
이럴 땐 억지로 문을 열려고 하지 마시고 먼저 이웃이나 가족에게 비밀번호를 아는 사람이 있는지 확인하세요.

그래도 못 열면 열쇠 호출 안내를 보고 전화 주세요.
문이 닫힌 상태로 자동 잠김이 걸린 도어락도 상하지 않게 여는 방법부터 씁니다.

9. 고덕동에서 전화할 때 알려주시면 좋은 것

  • 자동 잠김이 갑자기 달라졌는지, 처음부터 그랬는지
  • 안쪽 덮개 안에 설정 버튼이나 스위치가 있는지
  • 문이 열리는 상태인지, 닫혀서 안 열리는 상태인지
  • 번호판의 불빛과 소리 상태
  • 도어락 모양과 가능하면 사진

위치는 동, 호수와 가까운 큰길이나 역 방향을 말씀해 주세요.

10. 도착하면 사시는 분인지 확인합니다

문을 열어야 한다면 신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나로 사시는 분임을 확인합니다.
설정 점검만 하는 경우에도 도어락을 만지므로 같은 확인을 합니다.

이웃과 집을 지키기 위한 절차이니 미리 챙겨 두시면 좋습니다.

11. 점검과 재설정은 이렇게 합니다

먼저 현재 설정 상태와 모델을 확인합니다.
필요한 설정만 바꾸고 나머지는 그대로 두는 것을 원칙으로 합니다.

자동 잠김 시간, 번호판 소리, 등록 번호를 함께 보며 가족이 쓰기 편한 값으로 맞춥니다.
비용은 작업을 시작하기 전에 먼저 말씀드립니다.

문을 끝내 못 열면 비용은 받지 않습니다.
새 제품이 필요한지 살펴보시려면 도어락 설치 안내도 참고하세요.

12. 설정을 정리해 두는 습관

설정을 마쳤다면 가족이 함께 알 수 있게 정리해 두세요.

  • 자동 잠김 켜짐 또는 꺼짐 여부
  • 잠기는 시간 대략
  • 문이 안 닫힐 때 확인할 곳
  • 열쇠나 카드를 어디에 보관하는지

설명서는 버리지 말고 도어락 근처 서랍에 두면 좋습니다.

스마트폰으로 설정을 확인할 수 있는 모델이라면 현재 값을 캡처해 가족 대화방에 보관해 두세요.
나중에 설정이 달라졌을 때 어떤 값이 원래였는지 비교하기 쉽습니다.

설정을 바꾼 날짜도 메모해 두면 문제가 생겼을 때 원인을 찾는 시간이 짧아집니다.
이용 절차와 방법은 이용안내에서도 보실 수 있습니다.
