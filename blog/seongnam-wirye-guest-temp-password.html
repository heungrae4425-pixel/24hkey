1. 우리 집 비밀번호를 남에게 알려야 할 때

맞벌이나 육아로 낮에 집이 비어 있으면 가사도우미나 돌봄 선생님, 수리 기사님이 들어와야 할 때가 있습니다.
위례동처럼 비교적 새 아파트가 많은 동네는 이런 일로 도어락 설정을 문의하시는 분이 꾸준히 계십니다.

문제는 번호를 알려 준 뒤에 그 번호를 누가 어디까지 알고 있는지 점점 모르게 된다는 점입니다.
편하자고 알려 준 번호가 어느새 오래 남은 열쇠가 되기도 합니다.

이 글은 임시로 번호를 쓰는 방법과 정리하는 방법, 그리고 성남 출장열쇠가 도와드리는 범위를 정리했습니다.
설정 방법은 제품마다 다르니 큰 틀만 기억해 두세요.

2. 먼저 도어락이 어떤 기능을 갖고 있는지 보세요

요즘 도어락은 번호를 여러 개 등록할 수 있는 제품이 많습니다.
그런 제품이라면 가족용 번호와 손님용 번호를 따로 만들어 두는 것이 가장 깔끔합니다.

  • 번호를 여러 개 등록할 수 있는지
  • 임시 번호를 한 번만 쓰게 하거나 기간을 정할 수 있는지
  • 카드나 태그를 따로 등록할 수 있는지
  • 앱이나 문자로 열림 기록을 볼 수 있는지

이 네 가지만 확인하셔도 어떤 방식이 맞는지 정해집니다.
설명서가 없다면 제품 앞면 모양이나 모델 이름을 알려주시면 전화로도 같이 확인해 드립니다.

3. 한 번 쓰고 지우는 번호가 안전합니다

오래 쓸 사람이 아니라면 일회용에 가까운 번호가 좋습니다.
방문이 끝나면 바로 삭제할 수 있어 번호가 돌아다닐 일이 줄어듭니다.

정기적으로 오시는 분이라면 그분만의 번호를 따로 등록하세요.
가족용 번호를 같이 쓰게 하면 그분이 그만두신 뒤에 가족 번호까지 바꿔야 합니다.

번호는 눈에 띄는 숫자나 생일, 전화번호처럼 추측하기 쉬운 숫자를 피하세요.
같은 번호를 여러 사람에게 돌려 쓰는 것도 피하시는 편이 좋습니다.

4. 번호를 전달하는 방법도 신경 쓰세요

번호를 알려 줄 때는 말로 한 번 불러 주거나 짧은 메시지로 보내고, 보낸 메시지는 확인 뒤 지우세요.
단체 대화방이나 공개된 곳에 올려 두면 나중에 다른 사람이 볼 수 있습니다.

방문 시간을 미리 정해 두면 번호를 쓰는 시간이 짧아집니다.
방문이 끝나면 바로 연락을 받는 습관도 도움이 됩니다.

번호를 알려 준 사람 이름과 날짜를 휴대폰 메모에 적어 두세요.
나중에 어느 번호를 지워야 할지 헷갈리지 않습니다.

5. 돌봄이 끝나면 꼭 정리하세요

가사도우미나 돌봄 선생님이 그만두시거나 일정이 끝나면 번호를 정리해야 합니다.
일이 바빠 미루다 보면 몇 달씩 그대로 남아 있는 경우가 많습니다.

  • 그분이 쓰던 번호만 삭제하기
  • 번호를 여러 사람이 공유했다면 전체 번호를 새로 바꾸기
  • 카드나 태그를 나눠 줬다면 되돌려 받거나 등록 삭제하기
  • 문이 제대로 열리고 닫히는지 한 번 더 시험하기

번호를 바꾼 뒤에는 가족 모두에게 새 번호를 다시 알려 주세요.

6. 번호를 알려 줬는데 도어락이 안 열릴 때

방문하신 분이 번호를 눌렀는데 도어락이 안 열린다고 연락을 줄 수 있습니다.
이 경우 번호를 잘못 알려 줬거나 등록이 안 되어 있거나 배터리가 약한 경우가 대부분입니다.

먼저 번호가 정확한지, 등록을 마쳤는지, 번호판 불은 들어오는지부터 확인하세요.
번호를 여러 번 틀리면 도어락이 잠깐 잠기므로 서둘러 반복하지 않게 안내해 주세요.

이럴 때 집 안에 사람이 없고 방문하신 분이 밖에서 기다리고 있다면 상황이 조금 급해집니다.
이때는 사시는 분 본인이 연락하셔서 확인 절차를 거쳐야 하므로, 방문하신 분이 직접 요청하신다고 해서 문을 열어 드리지는 않습니다.

7. 위례동 위치는 이렇게 알려주세요

위례동은 대단지와 상가가 가깝게 이어져 있어 동, 호수를 정확히 말씀해 주시면 도착이 빨라집니다.
건물 이름과 동, 호수, 정문 위치를 알려주시고 현재 상태도 같이 말씀해 주세요.

  • 건물 이름과 동, 호수
  • 도어락 모양 (번호판형, 손잡이 일체형, 카드형)
  • 번호판 상태 (꺼짐, 켜짐, 경고음)
  • 방문하신 분이 밖에서 기다리고 있는지
  • 집 안에 아이나 반려동물이 있는지

사진을 문자로 보내주시면 맞는 장비를 챙겨 가기 좋습니다.

8. 설정 변경을 도와드릴 때 확인하는 것

도어락 번호를 바꾸거나 추가해 드리는 일은 사시는 분 본인이 맞는지 먼저 확인합니다.
신분증 주소, 주소가 나온 우편물, 관리사무소 확인 중 하나면 됩니다.

번호는 사시는 분이 직접 입력하시게 하고 저희는 화면을 보지 않습니다.
만든 번호는 저희가 따로 적어 가지 않습니다.

확인 절차는 이용안내에도 적어 두었습니다.
번거로워도 집을 지키는 절차라고 생각해 주세요.

9. 비용은 시작하기 전에 말씀드립니다

번호 설정을 도와 드리는지, 제품이 오래되어 수리가 필요한지에 따라 다르므로 현장에서 먼저 말씀드립니다.
괜찮다고 하시면 그때 시작하고, 마음에 안 드시면 그냥 돌아갑니다.

문을 열어야 하는 상황에서 끝내 못 열면 비용은 받지 않습니다.
열고 난 뒤에 말없이 붙는 비용도 없습니다.

부품을 바꿔야 하면 바꾸기 전에 따로 여쭤봅니다.
개문 방법은 현관문 개문 페이지에 자세히 적어 두었습니다.

10. 번호를 여러 개 쓰기 어려운 도어락이라면

오래된 도어락은 번호를 하나만 등록할 수 있는 경우가 있습니다.
이때는 가족 번호를 손님에게 알려 주지 않는 것이 원칙입니다.

방문이 잦다면 번호 여러 개를 등록할 수 있는 제품으로 바꾸는 방법도 있습니다.
고쳐서 쓸 수 있다면 도어락 수리를 먼저 권하고, 바꾸는 편이 낫다면 도어락 교체를 말씀드립니다.

결정은 언제나 사시는 분이 하십니다.
급하게 정하지 않으셔도 됩니다.

11. 열림 기록과 알림 기능은 이렇게 활용하세요

제품에 따라 문이 열릴 때 알림을 보내거나 기록을 남기는 기능이 있습니다.
이 기능을 켜 두면 방문하신 분이 도착하고 돌아가신 시간을 알 수 있어 안심이 됩니다.

다만 앱 연동이 서툴러 오히려 문제가 생기는 경우도 있습니다.
연결이 안 되거나 알림이 끊겼다면 그때는 도어락 수리 안내를 참고해 연락 주세요.

12. 평소에 해두면 좋은 습관

집에 사람이 드나들수록 아래 습관이 도움이 됩니다.

  • 가족 번호와 손님 번호를 반드시 분리하기
  • 번호를 알려 줄 때마다 날짜와 이름 메모하기
  • 일 년에 한 번은 전체 번호를 새로 바꾸기
  • 배터리 교체 시기를 달력에 적어 두기
  • 도어락에서 이상한 소리가 나면 미루지 않고 점검하기

습관 몇 가지만 바꿔도 불안이 많이 줄어듭니다.

13. 위례동 말고 성남 어디든 갑니다

위례동 바로 옆 단대동, 신흥동, 태평동과 분당 서현, 정자, 야탑 쪽도 24시간 출동합니다.
판교와 운중동, 백현동도 위치에 맞춰 도착 시간을 말씀드립니다.

성남에서 다니는 동네는 성남시 출장열쇠에 정리해 두었습니다.
다른 지역은 출장 지역 지도에서 확인하실 수 있습니다.
